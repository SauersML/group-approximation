# Every fixed-size window has collapsing dual gap on growing abelian quotients

Date: 2026-08-12

## 1. Outcome

The subgroup-twirl theorem gives dimension-free covariance rounding when
one controls the RMS defect over a whole finite abelian tangent subgroup.
It is tempting to derive that hypothesis from covariance on a fixed
generating window.  There is a sharp elementary obstruction: the dual
Cayley gap of every fixed-size generating window tends to zero on every
growing family of finite abelian groups.

Let `K` be a finite abelian group of order `N>=2`, generated by

```text
S={s_1,...,s_m}.                                      (FDG1)
```

Define the unnormalized dual character gap

```text
eta(K,S)=min_(1!=chi in dual(K))
              sum_(j=1)^m |chi(s_j)-1|^2.            (FDG2)
```

Put

```text
q=ceil(N^(1/m))-1.                                   (FDG3)
```

Then `q>=1`, `q^m<N`, and

```text
boxed: eta(K,S)<=4 pi^2 m/q^2.                       (FDG4)
```

In particular, for fixed `m`,

```text
eta(K,S)=O_m(N^(-2/m)).                              (FDG5)
```

Thus no fixed presentation window can have a uniform positive dual gap on
unbounded finite abelian phase quotients.  Any TRUE argument which upgrades
generatorwise covariance to the full-subgroup average must use additional
normal-`0/1` trace structure, a growing window, or a mechanism other than a
plain Poincare inequality.

The theorem also calibrates the remaining FALSE soft-clock route.  A cyclic
clock is not exceptional: near-trivial characters occur in every large
bounded-generator finite abelian tangent group.  The hard part is global
transport of such a character through the external cocycle, not its local
existence.

## 2. Simultaneous character approximation

Write every character value as

```text
chi(s_j)=exp(2 pi i theta_j(chi)),
theta_j(chi) in R/Z.                                  (FDG6)
```

The evaluation map

```text
Theta:dual(K)->(R/Z)^m,
chi |->(theta_1(chi),...,theta_m(chi))                (FDG7)
```

is injective because `S` generates `K`.

Partition the standard half-open cube `[0,1)^m` into `q^m` half-open boxes
of side length `1/q`.  Since `q^m<N=|dual(K)|`, two distinct characters
`chi_1,chi_2` have evaluation vectors in the same box.  Put

```text
nu=chi_1 chi_2^(-1).                                  (FDG8)
```

Injectivity makes `nu` nontrivial.  For every `j`, the two representatives
in the common box differ by at most `1/q`, so

```text
|nu(s_j)-1|
 <=2 pi/q.                                            (FDG9)
```

Squaring and summing proves `(FDG4)`.

The definition `(FDG3)` handles exact powers correctly.  If `N^(1/m)` is
an integer, then `q=N^(1/m)-1`; otherwise `q=floor(N^(1/m))`.  In both
cases `q^m<N` as required.

## 3. Spectral-gap form

For the normalized averaging operator on the character side, define

```text
lambda(K,S)=min_(1!=chi)
 (1/m)sum_j (1-Re chi(s_j)).                          (FDG10)
```

Since

```text
|z-1|^2=2(1-Re z),                                   (FDG11)
```

one has

```text
lambda(K,S)=eta(K,S)/(2m)
 <=2 pi^2/q^2.                                       (FDG12)
```

Conversely, a lower bound `eta(K,S)>=c>0` forces a cardinality bound.  From
`(FDG4)`,

```text
q<=2 pi sqrt(m/c),
N<=(q+1)^m
 <=(1+2 pi sqrt(m/c))^m.                             (FDG13)
```

So uniform fixed-window character separation and unbounded finite tangent
quotients are mutually exclusive.

The cardinality exponent is sharp.  Take

```text
K=(Z/qZ)^m.                                            (FDG13a)
```

with the standard coordinate generators.  A character is indexed by
`a=(a_1,...,a_m) in (Z/qZ)^m`, and its energy is

```text
sum_j |exp(2 pi i a_j/q)-1|^2.                       (FDG13b)
```

The least nonzero value is attained at `a=(1,0,...,0)` and equals

```text
4 sin^2(pi/q) asymptotic 4 pi^2 q^(-2)
 =4 pi^2 |K|^(-2/m).                                 (FDG13c)
```

Thus no bound with a better power of `|K|` can hold for all `m`-generated
finite abelian groups.  Only the factor depending on `m` in `(FDG4)` is
nonsharp.

## 4. Exact interface with subgroup twirling

Retain two representations `Phi_i:K->U(M)` in a finite tracial algebra and
`T in L^2(M)`.  Put

```text
Delta_S(T)^2
 =(1/m)sum_(j=1)^m
   ||Phi_0(s_j)T-T Phi_1(s_j)||_2^2.                 (FDG14)
```

On `L^2(M)`, let

```text
pi(k)X=Phi_0(k)X Phi_1(k)^*.                         (FDG15)
```

If `P_K` is projection onto the invariant vectors, the ordinary finite
Poincare inequality gives

```text
||T-P_KT||_2^2<=Delta_S(T)^2/(2 lambda(K,S)).         (FDG16)
```

The subgroup-twirl identity says

```text
E_K(T)^2
 =(1/|K|)sum_(k in K)
       ||Phi_0(k)T-T Phi_1(k)||_2^2
 =2||T-P_KT||_2^2.                                  (FDG17)
```

Therefore

```text
E_K(T)^2<=Delta_S(T)^2/lambda(K,S).                  (FDG18)
```

Equation `(FDG18)` is the best formal fixed-window upgrade supplied by the
Cayley Poincare inequality.  Equations `(FDG5)--(FDG12)` show why its
constant must deteriorate on growing bounded-generator abelian quotients.

When the two restricted character multiplicity vectors agree, the unitary
rounding theorem from `FALSE_FINITE_ABELIAN_COVARIANCE_TWIRL.md` gives an
exact `K`-intertwining unitary `V` with

```text
||T-V||_2<=E_K(T)
          <=Delta_S(T)/sqrt(lambda(K,S)).             (FDG19)
```

Thus a sufficient quantitative TRUE condition is

```text
Delta_S(T)=o(sqrt(lambda(K,S))).                      (FDG20)
```

Hyperlinearity alone supplies `Delta_S(T)->0` on each fixed window but no
rate relative to the model-dependent finite group `K`.  The dependence in
`(FDG20)` cannot be removed by character separation because `(FDG4)` is
universal.

## 5. Scope for the main problem

This theorem closes a tempting but invalid diagonal argument:

```text
fixed-window covariance -> full finite-subgroup covariance. (FDG21)
```

Such an implication is valid only with the rate loss in `(FDG18)`, and the
loss necessarily diverges along large bounded-generator abelian phase
groups.  Choosing increasingly accurate hyperlinear models does not by
itself solve this, because the size and dual gap of `K` are outputs of the
same model; no relation between defect and output dimension is part of the
definition of hyperlinearity.

The surviving universal TRUE target is therefore not generic finite-group
stability.  It must exploit a feature absent from `(FDG1)--(FDG20)`, most
plausibly the simultaneous regular-trace `0/1` law and its prefix-path
compatibility.  On the FALSE side, a construction must realize one of the
near-trivial characters guaranteed by `(FDG4)` coherently across the
nonliftable external bundle while retaining the marked fold.

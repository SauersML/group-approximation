# LIX lane reports

One file per lane of `notes/LIX_FULL_PROGRAM_2026-09-05.md`, named
`<lane>.md`, kept current by the lane.  Four sections, always:

1. **GREEN** — modules with the `Build completed successfully (N jobs)` count.
2. **AUTHORED, UNVERIFIED** — modules written but not yet green.
3. **NEEDS** — Lean signatures wanted from peers (name the lane).
4. **TRAPS** — anything that cost more than ten minutes, with the fix.

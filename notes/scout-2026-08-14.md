### Correction 2 — my "tracial 𝒞-action" route (§2.1) was already refuted in-repo

`notes/FALSE_HALO_ACTION_AUDIT.md` proves what it calls **locally sofic collapse**:
in Alekseev–Bradford's Definition 4.1/4.23 the target group `Λ` may be replaced by
the finitely generated `Λ_0 = <π_s(e)>`, so if the witnesses' targets are *locally
sofic* the action is already a sofic sofic-action. Finitely generated subgroups of
`U(n)` are linear, hence residually finite by Mal'cev, hence sofic — so swapping the
target class from sofic to hyperlinear, and labelling cosets by unitary/Pauli/Clifford
data, **cannot** establish the hypothesis. Their conclusion, verbatim: "If a
hyperlinear-action proof exists, then for some finite test its target `Λ_0` must
itself be a finitely generated hyperlinear nonsofic group. Producing that target
already solves the main problem."

`notes/NOTEPAD.md` (~20344) proves the sharper **single lamps recover the set
action**: if `G ↷ X` and `D = ⊕_X C_2` with `G` permuting coordinates, and the
automorphism action is a sofic `𝒞`-action for *any class `𝒞` whatsoever*, then
`G ↷ X` is a sofic action on a set — because injectivity of `π_s` on single-coordinate
lamps `δ_z` produces injective set labels `j_s(z) = π_s(δ_z)`, and the covariance
equation *is* the orbit-approximation equation.

**What survives.** Both arguments constrain the *target class* `Λ` while keeping the
action modelled by `φ : Γ → Sym(A)`. My proposal was to change `φ` itself — replace
the finite set `A` and `Sym(A)` by a diagonal masa `D_n ⊂ M_n` and `φ : G → U(n)`
approximately normalizing it in normalized HS. The lamp lemma then concludes only
that the coset action is a *tracial/HS action*, not a sofic one, so there is no
contradiction. But this is no longer a shortcut through an existing theorem: it
requires **defining** the tracial notion and **reproving** Alekseev–Bradford
Theorem 5.1 in the HS metric, and the lamp lemma warns that any such notion
immediately hands back a matching model of the coset action — i.e. the difficulty is
conserved, not removed. Treat §2.1 below as a research programme with a known
circularity hazard, not as an available route.

## Task 1 — new nonsoficity mechanisms / nonsofic constructions

### 1.1 OpenAI, "Nonsofic groups exist" `[ANNOUNCED]` — the first unconditional nonsofic group

- **Venue:** *Ten Advances in Mathematics and Theoretical Computer Science*, OpenAI,
  Chapter 3, **pp. 78–95 in the current (2026-08-06) PDF** — see Correction 1 above;
  "pp. 77–93" throughout this file is the original version's range. PDF:
  `https://cdn.openai.com/pdf/ten-proofs-oai.pdf`
  (document footer: "Updated August 6, 2026"; original at `ten-proofs-oai-original.pdf`).
  Cited in the literature as: OpenAI, *A counterexample to the soficity conjecture*,
  `https://openai.com/index/ten-advances-in-mathematics/`, 2026.
  (I fetched and read the full chapter text; the landing page itself returns HTTP 403.)
- **Theorem 1.1 (verbatim):** "The unit group `L_{F_2}(1,2)^×` is not sofic."
  Here `R = L_{F_2}(1,2) = F_2<s_0,s_1,t_0,t_1 | t_i s_j = δ_ij, s_0t_0 + s_1t_1 = 1>`.
- **What is actually proved:** a finitely generated subgroup `G := EL_D(R) = Θ_D(EL_9(R)) ≤ R^×`
  is nonsofic, where `D` is an explicit nine-word complete prefix code and
  `Θ_E : M_n(R) → R` is the prefix-code ring isomorphism. Property (T) for `EL_n(R)`,
  `n ≥ 3`, comes from Ershov–Jaikin-Zapirain (arXiv:0809.4095). Soficity passes to
  subgroups, so `R^×` is nonsofic.
- **The reusable criterion — Proposition 2.3 (verbatim):**
  > "Let `Γ ≤ G` be infinite groups, and suppose that `Γ` has property (T). Assume that
  > `G = <Γ, t_1, …, t_m>`, `t_i Γ t_i^{-1} ≤ Γ` (1 ≤ i ≤ m), m ≥ 1. Suppose further that a
  > finitely generated subgroup `J ≤ G` satisfies `[Γ,J] = 1`, `Γ ∩ J = {1}`, `t_1 J t_1^{-1} ≤ Γ`.
  > If `G` admits a sofic approximation `p_n : G → Sym(Y_n)` whose generator graphs for some
  > finite symmetric generating set differ in `o(|Y_n|)` edges from graphs on `Y_n` with
  > uniformly bounded degrees and a uniform positive expansion constant, then `J` is LEF."

  The paper adds: "Property (T) is required only of `Γ`. In our application, property (T)
  for `G` serves only to obtain the expanding approximation assumed in the proposition."
- **The new ingredient** (this is the actual mathematical advance over Kun–Thom): an
  *expander-matching* argument. Kun's decomposition (arXiv:1606.04471v5, Thm 1) gives
  *many* expanding Γ-components; Kun–Thom (arXiv:1901.03963) needs *one* expander on the
  whole set. The bridge is the median-normalized size function `f(z) = M(z)/(M(z)+µ)`,
  `M(z) = |C(z)|` the size of `z`'s Γ-component, `µ` a median. The inclusions `t_iΓt_i^{-1} ≤ Γ`
  make `f` almost nondecreasing along each `p_i` while Γ-generators almost preserve it;
  since permutations conserve total increase = total decrease, `f` is almost constant, so
  ambient expansion pins `f ≈ 1/2`, forcing each transported component `p_i(C)` to have
  approximately the size of its target `D` and hence to occupy more than half of it —
  giving an **injective matching** of components.
- **Realization:** `Γ` supported on the `[0]`-corner of `R`; `J ≅ V` (Thompson's V) acting
  by prefix replacements in the disjoint cylinder `[1000]`; `u` conjugates `J` into `[0001] ⊆ [0]`.
  `V` is finitely presented, infinite, simple, hence not LEF (Vershik–Gordon).
- **Independent engagement (evidence of soundness, not verification):** the chapter thanks
  Bradford, Chapman, Dogon, Fournier-Facio, Jaikin-Zapirain, Kun, and Thom. Two follow-up
  arXiv papers by Kun–Thom and Alekseev–Thom (below) build on it directly, and Kun–Thom
  posted v3 of arXiv:1901.03963 on 2026-08-04 ("Added Section 5, changed the introduction").
- **Relevance:** feeds `nonsofic-mechanism-mf-classification` (the one-sided-compression
  family now has a canonical unconditional member), `wreath-not-sofic`,
  `torsion-free-finitely-presented-non-mf`, and — see §1.2 — the whole
  `hyperlinear-nonsofic-group` subtree.

`[MY INFERENCE]` **Hyperlinearity of `L_{F_2}(1,2)^×` — equivalently Connes embeddability

The same passage also gives a **falsification test** worth knowing:

> "The Kervaire–Laudenbach conjecture asks whether every one-variable equation with
> coefficients in a group and nonzero total exponent of the variable has a solution in some
> larger group. It holds for every hyperlinear group [NT22, Theorem 1.3]. Consequently, it
> would hold for `R^×` if that group were hyperlinear, whereas its failure would exhibit a
> nonhyperlinear group."

(NT22 = Nitsche–Thom, *Universal solvability of group equations*, J. Group Theory 25 (2022) 1–10,
arXiv:1811.07737.) So a single Kervaire–Laudenbach counterexample over `R^×` refutes
hyperlinearity — a cheap, concrete no-go test to run before investing in microstates.
Lück's determinant conjecture and the algebraic eigenvalue conjecture are likewise
recorded as unsettled for `R^×`, and both hold for sofic groups.

### 1.3 Kun–Thom, arXiv:2608.06222 (2026-08-06) `[PROVED]` — **the most important finding for this repo**

*Nonsofic wreath products of residually finite groups*, Gábor Kun and Andreas Thom, 16 pp.
Read: full PDF text.

Abstract (verbatim): "This work builds on the breakthrough of OpenAI in finding the first
nonsofic group. We analyze the underlying proof mechanism and find further applications.
Let `Γ < G` be such that `{g ∈ G : gΓg^{-1} ≤ Γ}` generates `G` as a group, and suppose that
both `Γ` and `G` have property (T). If `Γ` is not normal, then the generalized wreath
product `(⊕_{G/Γ} ℤ/2ℤ) ⋊ G` is nonsofic. These hypotheses hold for explicit pairs of
elementary groups over polynomial and Laurent polynomial rings, in which both groups are
residually finite and Kazhdan."

Their vocabulary is **this repo's vocabulary**: "For a subgroup `Γ < G`, the set
`P_Γ = {g ∈ G : gΓg^{-1} ≤ Γ}` is a semigroup, called the **compression semigroup** of `Γ`.
We call `Γ` an **infranormal** subgroup of `G` if `P_Γ` generates `G` as a group."

Results (as read from the paper):

- **Theorem A.** `Γ` infranormal but not normal in `G`, both `Γ` and `G` Kazhdan
  ⟹ `(ℤ/2ℤ) ≀_{G/Γ} G` is not sofic.
- **Theorem B.** `G` sofic with (T), `Γ ≤ G` infranormal with (T) ⟹ `C_G(Γ)` is normal in `G`.
- **Theorem C.** `Γ` infranormal in `G`, both Kazhdan, `G ↷ (X,µ)` a sofic p.m.p. action
  ⟹ the fixed-point algebra `L^∞(X)^Γ` is `G`-invariant.
- **Corollary D.** Same hypotheses with `Γ` not normal: for any nontrivial standard
  probability space `(K,κ)`, the generalized Bernoulli action `G ↷ (K,κ)^{G/Γ}` is not sofic.
- **Corollary 3.2.** These groups admit free ergodic nonsofic p.m.p. actions that are
  strongly ergodic.
- **Theorem E (explicit pair).** "Let `q` be a prime power and let `r,d ≥ 3`. Put
  `R_+ = F_q[x_1,…,x_d]` and `R = F_q[x_1^{±1},…,x_d^{±1}]`, and let `SL_d(ℤ)` act on `R` by
  monomial substitutions. Then `Γ = EL_r(R_+)` and `G = EL_r(R) ⋊ SL_d(ℤ)` are residually
  finite Kazhdan groups, `Γ` is infranormal but not normal in `G`."

**Why this matters here.** `notes/NOTEPAD.md:31454` already records that the repo's wreath
candidate has `L(W_Y) = L^∞(T^Y, Haar^Y) ⋊ Q = L(ℤ^{(Y)} ⋊ Q)` and that "CE status is
equivalent to hyperlinearity of the split integral wreath candidate". Kun–Thom Theorem A
is *exactly* the nonsoficity half of that object with `ℤ/2` lamps and `Y = G/Γ`, proved
unconditionally, for an explicit residually finite Kazhdan pair. Theorem E is the same
`EL_r`-over-Laurent-ring / `SL_d(ℤ)`-monomial architecture the repo's non-MF work uses.

- `[MY INFERENCE]` `wreath-not-sofic` is very likely **citable-closed** by Theorem A, *provided*
  the repo's wreath candidate is checked to be of the form `(⊕_{G/Γ}A) ⋊ G` with `Γ`
  infranormal non-normal and both `Γ`, `G` Kazhdan. If the repo's lamp is `ℤ` rather than
  `ℤ/2`, the reduction needs one extra step (`ℤ ↠ ℤ/2` on lamps is a quotient of wreath
  products; nonsoficity does not pass to quotients, so this needs checking, not assuming).
- **Note on scope:** the paper mentions "hyperlinear" only three times, all in citations
  (Elek–Szabó [8], Pestov [17]), and "Connes" once (Connes–Weiss [5]). Kun and Thom make
  **no claim** about hyperlinearity or weak soficity of their nonsofic wreath products.
  (An HTML-render fetch of this paper gave me a *false negative* on "hyperlinear" and a

### 1.6 Chapman–Peled, arXiv:2509.21566 (2025-09-25, rev. 2025-12-04) `[CONDITIONAL]` — **a genuine second mechanism**

## Task 2 — hyperlinearity vs soficity directly; citations of Kun–Thom

### 2.1 The structural bottleneck, made precise

Chaining the verified results gives a single clean statement of where Q3.4 now stands.
Let `Γ < G` be a Kun–Thom pair (Theorem E), `W = (⊕_{G/Γ}ℤ/2) ⋊ G`.

1. `W` is **not sofic** — Kun–Thom Theorem A `[PROVED]`.
2. `W` is hyperlinear ⟺ `L(W) = L^∞({±1}^{G/Γ}) ⋊ G` is Connes-embeddable
   (Pestov Thm 8.5 for the first equivalence; the identification of `L(W)` with the
   generalized Bernoulli crossed product is standard and is already written out in this
   repo at `notes/NOTEPAD.md:31440–31454` for the `ℤ`-lamp/`T^Y` version). `[MY INFERENCE — but
   routine]`
3. So **Q3.4 ⟸ Connes embeddability of the generalized Bernoulli crossed product
   `L^∞({±1}^{G/Γ}) ⋊ G` for an explicit residually finite Kazhdan pair.**

Every existing permanence theorem that would deliver step 3 requires the coset action to
be a **sofic action**, and Kun–Thom Corollary D says precisely that this action is **not**
sofic. That is the entire gap. The relevant permanence results, all source-verified:

- **Hayes–Sale, arXiv:1608.02610** (Metric Approximations of Wreath Products) `[PROVED]`.
  Abstract verbatim: "Suppose that `H` is a sofic group and `G` is a countable, discrete
  group. If `G` is sofic, hyperlinear, weakly sofic, or linear sofic, then `G ≀ H` is also
  sofic, hyperlinear, weakly sofic, or linear sofic respectively." — **standard (regular)
  wreath product only**, and the *acting* group `H` must be sofic even when the conclusion
  is merely hyperlinearity.
- **Holt–Rees, arXiv:1601.01836**, Pacific J. Math. 287 (2017) 393–409 `[PROVED]`.
  Their wreath-product closure "is valid for weakly sofic groups, and we prove it
  separately for sofic groups" — i.e. **not** for hyperlinear. Standard restricted wreath
  product `G wr H` with `H` residually finite. Direct-product closure *is* proved for LEF,
  weakly sofic and hyperlinear.
- **Gao–Kunnawalkam Elayavalli–Patchell, arXiv:2401.04945** (Res. Math. Sci. 12 (2025) 48)
  `[PROVED]`. Soficity for *generalized* wreath products of sofic groups "where the
  underlying group action is sofic". Arbitrary actions of amenable groups and of free
  groups are sofic; so are actions of sofic groups with locally finite stabilizers.
- **Alekseev–Bradford, arXiv:2601.18742** (2026-01-26) `[PROVED]` — the current
  state of the art, and the framework to attack. Abstract verbatim: "We introduce the
  notion of a 'sofic 𝒞-action' of one group on another by automorphisms, for 𝒞 a class of
  groups. We show that if 𝒞 is the class of (i) sofic, (ii) hyperlinear, (iii) linear sofic
  or (iv) weakly sofic groups, then the class 𝒞 is closed under taking semidirect products
  with sofic 𝒞-action."
  Their Definition 4.23 (read in full) models the action by **`φ : Γ → Sym(A)` for a finite
  set `A`**, with injective partial homomorphisms `π_s : E ↪ Λ`, `Λ ∈ 𝒞`. So even for
  𝒞 = hyperlinear, the *action* is modelled by permutations of a finite set; only the
  *lamp/fibre* group is allowed to be merely hyperlinear. Their Example 1.3 covers exactly
  the permutational wreath product `Δ ≀_X Γ = (⊕_X Δ) ⋊ Γ`.

> **RETRACTED AS A SHORTCUT — see Correction 2 at the top of this file.**
> `notes/FALSE_HALO_ACTION_AUDIT.md` (locally sofic collapse) and `notes/NOTEPAD.md`
> (single lamps recover the set action) already show that changing only the *target
> class* is circular, and that any `𝒞`-action notion hands back a matching model of
> the coset action. What follows is a research programme with a known circularity
> hazard, not an available route.

`[MY INFERENCE]` **Proposed route — "tracial 𝒞-action".** Weaken Definition 4.23 by
replacing the finite set `A` and `Sym(A)` with a finite-dimensional tracial pair: a
diagonal masa `D_n ⊂ M_n(ℂ)` with minimal projections indexed by `A`, and
`φ : Γ → U(n)` approximately normalizing `D_n` in normalized-HS, with partial embeddings
`π_s : E ↪ U(m)` attached to the minimal projections. Then attempt the HS analogue of
Alekseev–Bradford Theorem 5.1: *`Δ`, `Γ` hyperlinear + `α` admits a tracial action model ⟹
`Δ ⋊_α Γ` hyperlinear.* Supply the model for the Kun–Thom coset action `G ↷ G/Γ`.
The reason to expect this to be possible where the sofic version provably fails: the
entire Kun/Kun–Thom obstruction is **Hamming-metric-specific** — it runs on the generator
*graph* of a tuple of permutations and its expander decomposition. A unitary tuple has no
generator graph, and this repo has already established the corresponding blindness results
(`NormTraceGap`, `trace-blindness-sharpness`, `finite-quotient-blindness`). This is the
first Q3.4 route I have seen where the nonsoficity side is a *citable unconditional
theorem* and the only remaining work is on the flexible/microstate side — i.e. exactly the
side `notes/OBSTRUCTIONS.md` §5 identifies as "the only side informative about Q3.4".

Feeds: `hyperlinear-wreath-model` (primary), `kun-thom-clifford-crossed-product-ce`
(the abelian/Bernoulli variant is a strictly easier sibling of the Clifford target — see
§2.2), `wreath-not-sofic` (now citable), `flexible-side-witness`, `radical-collision-route`.

### 3.2 Lubotzky–Salomon, arXiv:2607.17578 (2026-07-20) `[PROVED]` — flexible ≠ strict

- Relevance: `wreath-flexible-hs-stability`, `rigidity-route`. This is direct evidence that

### 3.3 Fournier-Facio–Gerasimova–Spaas, arXiv:2307.13155 `[PROVED]`

## Task 4 — post-MIP* Connes embedding, crossed products, explicit non-CE candidates

### 4.1 Manzoor, arXiv:2502.06697 v2 (rev. 2026-04-04) `[PROVED]` — the only explicit non-CE object found

*There Is An Equivalence Relation Whose von Neumann Algebra Is Not Connes Embeddable.*
Abstract verbatim: "The landmark quantum complexity result MIP*=RE was used to prove the
existence of a non Connes embeddable tracial von Neumann algebra. Recently, similar ideas
were used to give a negative solution to the Aldous–Lyons conjecture: there is a non
co-sofic IRS on any non-abelian free group. We define a notion of hyperlinearity for an IRS
and show that there is a non co-hyperlinear IRS on any non-abelian free group. As a
corollary, we prove that there is a relation whose von Neumann algebra is not Connes
embeddable. We do this by significantly simplifying the reduction of Aldous–Lyons to
non-local games, removing the need for subgroup tests entirely."

- **This is the closest existing thing to a second non-hyperlinearity mechanism**, and it is
  MIP*-based rather than (T)-based. But it lands on an *equivalence relation* / IRS, not on
  a group: the non-co-hyperlinear IRS is not supported on a normal subgroup, so it does not
  produce a non-hyperlinear group (same structural gap as Bowen–Chapman's surjunctivity
  example, §2.5).
- Feeds `non-hyperlinear-group` as a mechanism to study, and `mf-implies-hyperlinear` as a
  source of the current best non-CE constructions.

### 4.2 Manzoor, arXiv:2508.15154 v2 (rev. 2025-09-21) `[PROVED]`

*Invariant Random Subgroups, Soficity, and Lück's determinant conjecture.* "For every free
group, we prove the existence of an IRS satisfying the determinant conjecture that is not
co-hyperlinear, and hence not co-sofic. This provides evidence that satisfying the
determinant conjecture might be a weaker property than soficity for groups, and
consequently the conjecture possibly holds for all groups. We use techniques from non-local
games and MIP*=RE, showing more generally when the latter can be used to narrow down when a
von Neumann algebra (or IRS) contains a non-Connes embeddable object."
- The last clause is a general **transfer principle** for locating non-CE objects via MIP*.
  `[MY INFERENCE]` Worth reading in full as the only available machine for *proving*
  non-CE-ness of a concrete algebra — i.e. the tool one would aim at
  `L^∞({±1}^{G/Γ}) ⋊ G` if one wanted the *negative* answer to Q3.4-via-Kun–Thom.

### 4.3 Kahl–Schneider, arXiv:2504.10988 v2 (rev. 2026-01-05) `[PROVED]` — a positive tool

*Hyperlinearity via amenable near representations.* "Establishing an analogue of a theorem
about sofic groups by Elek and Szabó, we prove that a group is **hyperlinear if and only if
it admits an essentially free amenable near representation**. This answers a question raised
by Pestov and Kwiatkowska. For comparison, we also provide characterizations of Kirchberg's
factorization property, as well as Haagerup's property, along similar lines."

- **This is the most actionable positive tool in the sweep.** `hyperlinear-wreath-model`
  records that "the tools for proving `R^𝒰`-embeddability abstractly are thin" — this is a
  new, genuinely different criterion for hyperlinearity, dual to Elek–Szabó's
  characterization of soficity by essentially free amenable *actions*. It converts "build
  microstates" into "build one essentially free amenable near representation", which is a
  softer, more flexible object (amenability of a unitary representation in Bekka's sense,
  witnessed by an orthonormal basis carrying an invariant probability charge).
- `[MY INFERENCE]` **Route sketch for `hyperlinear-wreath-model`:** the Elek–Szabó/Kahl–Schneider
  pairing suggests the wreath problem in the form — the coset action `G ↷ G/Γ` fails to be
  a *sofic action* (Kun–Thom Cor. D) but might still support an *amenable near
  representation* on `ℓ²(G/Γ)`-like carriers, because the Bekka-amenability witness is a
  finitely-additive invariant charge rather than a finite equivariant partition. The eight
  dead architectures in §5 all tried to build finite carriers; a charge is exactly the
  object that can exist without one.
- Feeds `hyperlinear-wreath-model`, `mf-implies-hyperlinear`, `flexible-side-witness`.

> Let `Γ` be a countable discrete group and `A` be a finite abelian group. Assume:

"It is very tempting to try to prove that in a situation like (1.1), if `Γ` is stable,

## Addendum: Glebsky–Rivera 2009 primary read (debt closed)

arXiv:0709.1134 fetched and `pdftotext`'d. The original is **narrower than the phrasing
everyone quotes**.

> **Proposition 3.** If `G = ⟨x_1,…,x_k | w_i(x̄) = u_i(x̄), i = 1,…,r⟩` is sofic and
> System 2 is stable, then `G` is residually finite.

with the contrapositive as Theorem 2, second bullet: "If the group `G` is sofic but not
residually finite, then the system (2) is unstable in permutations."

**Their "stable" is Definition 1.3** — stability *of a system of equations in
permutations*: a rate `δ_ε → 0` independent of `n`, with the exact solution required in
the **same `S_n`**. That is **strict** permutation stability, not flexible, and it is a
property of a **finite presentation**, not of an abstract countable group.

So Glebsky–Rivera do **not** prove "sofic + stable in finite actions ⟹ residually
finite". Gohla–Thom's §3.2 form is strictly stronger on both axes (much weaker stability
hypothesis, arbitrary countable groups) and they state it as their own observation, with
no proof and no pinpoint into GR09. Chapman–Dikstein–Lubotzky's "[GR09]" tag inherits the
same over-attribution. Harmless in the end — cairn-literal has an in-repo proof, so
nothing now depends on the citation — but the attribution should be stated accurately
wherever it appears.

Two things worth keeping: for a **finitely presented** group, "sofic and not residually
finite ⟹ the defining system is unstable in permutations (strict sense)" is available
with no second-hand step at all, straight from Theorem 2; and the worked example printed
after Theorem 2 calls a system "unstable in permutations, because the corresponding group
is finite", contradicting their own first bullet — a typo in the source, do not quote it.

## Addendum 2: Glebsky J. Algebra 477 (2017), Corollary 19 — the manufactured metric

arXiv:1506.06940v2, `pdftotext`. **Last import debt on the weak-soficity thread, closed.**
Node: `research/glebsky-manufactured-invariant-length.md`.

The 2017 architecture is deliberately metric-free — Glebsky: "In the present article we
investigate the notion of approximation based on products of conjugacy classes without
direct use of length functions, see Definition 6." His Definition 6 (`K`-approximable) is
purely combinatorial, phrased with `n`-separation of sets of `n`-consequences, and
**Corollary 19** is the equation-solvability equivalence in those terms: "Let `K ⊆ Fin`
and `K.approx = (∏K).approx`. Then a group `G` is `K`-approximable if and only if any
`K`-system is solvable over `G`."

**Metrics enter only through Lemma 3**, whose proof contains the whole construction. Given
`X, Y ⊆ H` with `Y` `n`-separated from `X`: form `X^H = {x^h : x^{±1} ∈ X, h ∈ H}`, the
conjugation closure; let `d` be the shortest-path metric on the Cayley graph `Γ(H, X^H)`
(`∞` if no path); then

    ‖h‖ = min{ (1/n)·d(1,h), 1 }

is an invariant length with `‖x‖ = 1/n` on `X` and `‖y‖ = 1` on `Y`, and "one may convert
a `K`-approximation into a `(K,L)`-approximation where `L` consists of the above
constructed length functions."

**So the manufactured metric is a truncated, rescaled word metric with respect to a
conjugation-invariant generating set.** Nothing exotic. Three consequences for the
Hilbert-embeddability test (my inferences, flagged as such on the node): the `1/n`
rescaling is harmless since positive scalars preserve conditional negative definiteness;
the `min{·,1}` truncation is the suspect operation, since truncating a cnd kernel need not
stay cnd; and `X`, `Y`, `n` are all free subject only to `n`-separation, so there is no
"the" Glebsky length — which makes cairn-survivor's third formulation the right one and
gives it room to work. Glebsky's own remark that "the structure of the set of invariant
length functions on a group depends on the algebra of the conjugacy classes of this group"
puts this squarely in the character-theoretic setting their criterion uses.

## Addendum 3: the Fin-case instantiation (offer (a), taken)

Node: `research/glebsky-fin-case-instantiation.md`. Answers survivor's "does the freedom
reach into `proj_A(M)`" — yes, because the construction lives there.

**Corollary 19's hypothesis is free for `Fin`.** It needs `K.approx = (∏K).approx`; since
finite direct products of finite groups are finite, `∏Fin = Fin`. Corollary 6 says the
same from the compactness side, and the paper fixes "`Fin`-approximable groups are called
weakly sofic".

**The two sets are finite-window projections.** Proposition 5's proof, given finite `Φ ⊆ X`
and `n`: split `Φ_N = Φ ∩ N`, `Φ_0 = Φ \ N`; then `C_n(Φ_N,X) ∩ Φ_0 = ∅` because
`C_n(Φ_N,X) ⊆ N`; compactness gives `k` with
`C_n(Pr_1^k(Φ_N), Pr_1^k(X)) ∩ Pr_1^k(Φ_0) = ∅`. Feeding that into Lemma 3:

    H = Pr_1^k(X)          the finite window
    X = Pr_1^k(Φ ∩ N)      the ERROR set     → length 1/n
    Y = Pr_1^k(Φ \ N)      the SEPARATED set → length 1

So the error set is *determined* by `(Φ, n, k)`, not freely chosen; the free parameters
are `n` and `k`. Survivor's design problem is therefore not "choose a length" but "compute
the character expansion of a determined one as `n, k` vary".

**Why `Fin` gets the generic length.** For `Alt`/`Sym` the paper never uses Lemma 3. It
uses normalized Hamming plus two `Alt`-specific tools: Lemma 10 (`y ∉ C_n(X,A)` ⟹
`‖y‖/‖x‖ ≥ (n−1)/16`, proved from the fact that in a finite *simple* group powers of a
conjugacy class cover the group almost as fast as possible) and Lemma 11 (amplification
`h ↦ h^{⊗r}` on `[m]^r`, `1 − ‖h^{⊗r}‖ = (1−‖h‖)^r`, boosting separation to `≥ 1/2`).
**Lemma 10 has no analogue for general finite groups** — its proof consumes simplicity —
so the generic capped word length for `Fin` is forced, not incidental.

That is a concrete form of the sofic/weakly-sofic gap: sofic gets Hamming (Hilbert
embeddable, recovering sofic ⟹ hyperlinear), weakly sofic gets a capped
conjugate-word-length on an arbitrary finite group with no covering theorem to convert it.
Glebsky's remark that not every bi-invariant metric restricts from Hamming is the abstract
shadow of exactly this.

**Correction to Addendum 2:** in the `Alt` case separation `≥ 1/2` comes from
*amplification* (Lemma 11), not truncation. The truncation-is-separation observation holds
for the generic Lemma 3 construction, hence for `Fin`, but not for the sofic case.

# The same-model two-gauge fold cannot see a conjugate edge element

Date: 2026-08-11

## 1. Outcome

The folded projective-gauge criterion in
`FALSE_FOLDED_DOUBLE_PROJECTIVE_GAUGE_CRITERION.md` is a valid sufficient
criterion, but its proposed application to the current Kun--Thom fold is
sterile if the two vertices use the same projective model and differ only by
scalar generator gauges.

The reason is exact and independent of dimension, quotient, or multiplier.
The marked vertex element has the form

`h=t^(-1) gamma t`, `gamma in Gamma`.                 `(FGN1)`

Exponent sum is invariant under conjugation, so

`epsilon(h)=epsilon(gamma)`.                          `(FGN2)`

The amalgam relations already require the two vertex evaluations of `gamma`
to agree.  Under two scalar gauges their discrepancy is

`q^(epsilon(gamma))`, `q=t_2 t_1^(-1)`.               `(FGN3)`

But the marked fold discrepancy is exactly

`q^(epsilon(h))=q^(epsilon(gamma))`.                  `(FGN4)`

Thus its normalized Hilbert--Schmidt displacement equals one of the edge
defects and must tend to zero.  No Schur-multiplier phase in the common
projective vertex model changes this conclusion, because that phase cancels
between the two identical vertex evaluations.

## 2. General theorem

Let

`G=<x_1,...,x_d | r_1,...,r_ell>`

and let `Gamma<=G` be generated by word values `u_1,...,u_s`.  Form the
symmetric double and use the same projective vertex matrices `U` in both
copies, with scalar gauges `t_1,t_2`.  Put `q=t_2 t_1^(-1)`.

Suppose a marked word `h` satisfies

`epsilon(h)=sum_(a=1)^s c_a epsilon(u_a)`             `(FGN5)`

for fixed integers `c_a`.  Then

`|q^(epsilon(h))-1|`
` <=sum_a |c_a| |q^(epsilon(u_a))-1|`.                `(FGN6)`

Indeed `(FGN5)` gives

`q^(epsilon(h))=product_a q^(epsilon(u_a))^(c_a)`,    `(FGN7)`

and `(FGN6)` is the standard telescoping inequality on the unit circle.

**Theorem 1 (same-model gauge no-go).**  If all amalgam defects tend to
zero and `(FGN5)` holds, then the marked fold displacement tends to zero.
Consequently the same-model two-gauge criterion cannot prove FALSE for that
word.

For `(FGN1)`, take one edge word representing `gamma`; then `(FGN5)` holds
with one coefficient equal to one by `(FGN2)`.  Even if the selected finite
generating list for `Gamma` does not literally contain `gamma`, its word in
those generators yields `(FGN5)` because exponent sum is a homomorphism.

## 3. What a live projective construction must change

The obstruction identifies the missing datum precisely.  Scalar gauge
difference only sees abelianized word data, while the radical fold is a
conjugacy displacement invisible in abelianization.  A successful
projective model must therefore use genuinely different vertex multiplier
data, not one common projective representation with two scalar gauges.

Possible live forms are:

1. two projective vertex models whose multiplier classes have the same
   restriction to `Gamma` but differ on `h`;
2. a relative Schur class in the kernel of restriction from the vertex to
   the edge group; or
3. an explicit intertwiner between the two edge restrictions which does not
   identify the evaluations of the conjugate element `h`.

This returns the main target to the relative curvature quotient already
isolated in `FALSE_EQUIVARIANT_STEINBERG_GLOBALIZATION.md`:

`ker(H^2(G_k;T) -> H^2(Gamma_k;T))`,                  `(FGN8)`

with a marked pairing on the fold.  The explicit clock cocycle from
`FALSE_SPLIT_CLOCK_EXPLICIT_COCYCLE.md` is still useful, but it must survive
in `(FGN8)` rather than be used identically on both vertices and then
scalar-rephased.

## 4. Computational consequence

Do not run the `2d` scalar circle-repair optimization proposed for one common
curvature phase vector.  For the actual conjugate fold its optimum has marked
energy bounded by the edge energy through `(FGN6)`.

The correct finite computation is instead:

1. construct the restriction map on prime-power Schur characters from a
   finite vertex quotient to the finite positive-edge image;
2. compute its kernel;
3. evaluate kernel classes on the marked fold transgression; and
4. only then optimize the residual generator gauges needed to control the
   fixed vertex relators.

This is a relative `H^2`/Schur computation.  It cannot be replaced by two
scalar gauges applied to one vertex multiplier.

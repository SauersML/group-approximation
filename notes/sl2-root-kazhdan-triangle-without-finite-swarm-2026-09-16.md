## Setup

**The family.** `kazhdan-hyperbolic-sl2-root-triangles`, with `q = 2^f >= 8`, `k = F_q ⊂ F = F_{q^2}`,
`s ∈ F \ k`. The vertices are:
- `A_1 = SL_2(k)`, with `u, v` on `E_12, E_13`;
- `A_2 = SL_2(k)`, with `u, v` on `E_12, E_23`;
- `A_3 = SL_2(F)`, with `u` and `v(s·)` on `E_13, E_23`.

The gluings matter only through the relative twists `φ_e ∈ GL_f(F_2)`.

**The target.** Some member has no nontrivial finite quotient. It is OPEN, and it sits behind the
large-quotient barrier.

**Entering state.**
- The untwisted member maps onto `SL_2(q^2)`.
- A nontrivial 2-dimensional representation forces semilinear twists
  (`sl2-root-triangle-2dim-reps-force-semilinear-gluing`).
- So the candidates were understood as "some twist non-semilinear", with the semilinear members undecided.

## What was proved

1. **`sl2-root-triangle-char2-frobenius-spectrum-transport`**, in every dimension.
   - **Expansion.** For any representation in characteristic 2 and any root parametrization,
     `ρ(p(y)) = Π_a (1 + y^{2^a} X_a)`. The `X_a` are commuting and square-zero, and torus weights separate
     them.
   - **Spectrum.** `S_i = {a : X_a ≠ 0}` is a nonempty invariant of vertex `i`, with `|S_i| <= d(d-1)/2`.
   - **Transport.** `S_j = S_i + supp(φ_e^{-1})`, and `S_j = S_i + b` for each `b` in the support.
   - **Triangle.** `S_1` is stable under the group `H` generated by the support differences and the loop
     sum. For semilinear twists, `H = <hol>`, where `hol = a_12 + a_23 - a_13` is the Frobenius holonomy.
   - **Corollaries.**
     - `d = 2` forces semilinear twists and `hol = 0`. This gives a second proof of the semilinear claim,
       with no Hua identity.
     - For `f` prime and `H ≠ 0`, `S_i = Z/f` and `d(d-1)/2 >= f`.
     - For `f = 3`, `d >= 4`.
2. **`sl2-root-triangle-2dim-iff-zero-frobenius-holonomy`.** The following are equivalent:
   - a nontrivial 2-dimensional representation exists;
   - a vertex-injective map onto `SL_2(q^2)` exists;
   - all twists are semilinear and `hol = 0`.

   Sufficiency is an explicit configuration `ρ_i = conj_{g_i} ∘ Frob^{b_i}` with `b = (a_13, a_23, 0)`,
   `g_3 = d_τ`, `g_1 = h` and `g_2 = h u(1/P) d_ω`. It is machine-checked on all edge elements: 80/80 for
   `q = 8` and 40/40 for `q = 16`. By half-girth (iv) the kernel is torsion-free.
3. **`sl2-root-triangle-tensor-vertex-reps-force-2hol-zero`.** Take semilinear twists with `2·hol ≠ 0`.
   - **Statement.** No representation is simultaneously:
     - an irreducible twisted tensor module `L(T_1)` at `A_1`;
     - slot-diagonal at `A_2` and `A_3`, meaning `X^u_c` and `X^v_d` commute iff `c ≠ d`. This holds for direct
       sums of `L(T)`, with `T` injective mod `f` at `A_3`.

     In particular Steinberg-type gluings do not exist. For `q = 8` this covers all 6174 nonzero-holonomy
     semilinear triples.
   - **Proof.**
     - Exact transport along semilinear edges.
     - Each edge-23 operator `z_d` commutes with everything except `y_{c_1}` and `x_{c_1 - hol}`, so it lies in
       `span{1,x_{c_1}} ⊗ span{1,y_{c_1-hol}}`.
     - Then `[z_d, z_{d+hol}] = [x_{c_1}, y_{c_1}] ⊗ A ⊗ B ≠ 0` in three distinct slots, contradicting
       commutativity of one root group.
   - **Checks.** `tensor_gluing.py` checks the commutant dimension and the commutator ideal. It also shows the
     argument genuinely fails for `2·hol = 0 ≠ hol` (`f = 4`, commuting pair `x_0 + y_2`, `x_2 + y_0`).
4. **`sl2-root-triangle-tensor-reps-iff-zero-holonomy`.** For semilinear twists, a representation that is a twisted
   tensor module at all three vertices (`L(T_1)`, `L(T_2)`, and `L_F(T_3)` with `T_3` injective mod `f`) exists iff
   `hol = 0`.
   - **`hol = 0`.** Compose the map onto `SL_2(q^2)` with `L_F(T_3)`.
   - **`2·hol ≠ 0`.** This is item 3.
   - **`hol = f/2`.** The commutant step still confines `z_d` to two slots. The exact commutator scalars
     (`1` at `A_2`, `s^{2^t}` at `A_3`) force `z_d = β x_{c_1} + γ y_{c_1+h}`, with `β ∈ k^*` and `γ ∈ s^{2^t} k^*`.
     Commutativity of `z_d, z_{d+h}` then puts `w^{r-1}` or `w^{rq-1}` in `k^*` for `w = s^{2^t}`, `r = sqrt q`.
     Both exponents are coprime to `q+1`, so `w ∈ k`: contradiction.
   - **Checks.** `scalar_pairing.py`:
     - the exponent lemma for `f <= 12`;
     - all 7680 ratios over `F_256`;
     - the commutator identities mod 2.

   This settles the `hol = f/2` case left open by item 3, but only for tensor-type representations. For `q = 16`
   it adds the 54,000 triples with `hol = 2`.

**Effect on the target.**
- The `f^2 (q-1)^3` zero-holonomy semilinear triples are virtually torsion-free: 3087 for `q = 8`, 54000
  for `q = 16`. They are removed from the candidates.
- The semilinear `hol ≠ 0` triples, 6174 for `q = 8`, have no 2-dimensional representation. They join the
  non-semilinear ones as candidates.
- These triples also have no tensor-type representation (items 3 and 4). So a nontrivial finite quotient, if one
  exists, is not detected by tensor-type representations in characteristic 2.

## Approaches tried and where each dies

- **Dimension bounds from the transport.** For a candidate, `H ≠ 0` gives only `d(d-1)/2 >= |H|`: `d >= 4`
  for `f = 3`, and roughly `d >= sqrt(2f)` in general. Twisted tensor modules have dimension up to `q`, so
  these bounds are far too weak to exclude finite quotients. The spectrum is blind to all modules whose
  spectrum is all of `Z/f`, such as Steinberg.
- **Steinberg gluing (8-dimensional for `q = 8`).**
  - A common tensor decomposition at all three vertices forces the slot labels around the triangle to shift
    by `hol`, so it needs `hol = 0`.
  - Products of 2-dimensional representations (`SL_2(K)^f ⋊ S_f`) reduce to coordinates because `Λ` is
    perfect.
  - With `ρ_1 = St` fixed, the problem becomes a bilinear system of 56 equations in two units of the
    8-dimensional algebra `K[u(k)]`. Its expected dimension is negative, but deciding it over `F̄_2` needs
    elimination; only python3, sympy and numpy are available here. That approach dies here.
  - It was replaced by the commutant argument (item 3), which settles Steinberg-type and more general
    tensor-type gluings when `2·hol ≠ 0`. It needs exact transport and the tensor model at one vertex. So it
    says nothing about:
    - non-semilinear members;
    - `hol = f/2`, where an explicit commuting pair shows the local obstruction vanishes. Item 4 closes this case
      for tensor-type representations using the exact commutator scalars;
    - vertex modules like `S^2 V` whose coefficient operators are not slot-diagonal.
- **Search for configurations over `F_64` only.** Part (C) of the script confirms the holonomy prediction
  (6, 0, 6, 0, 6, 0, 6, 6 and 0 for the non-semilinear gluing). It is a calibration, not used in any proof.
- **The target itself.**
  - Excluding every finite quotient of a candidate is the large-quotient barrier of
    `hyperbolic-simple-triangle-group-without-finite-quotients`.
  - Vertex-injective quotients contain `SL_2(q^2)`, so a bounded search starts at order `262,080`.
  - A rigorous quotient count would decide Gromov's question
    (`convergent-quotient-count-decides-gromov-question`).

  Not attempted beyond the representation-theoretic reduction.

# A normal fixed-point character forces profiniteness and residual finiteness

Date: 2026-08-14

## 1. Outcome

Let `R` be an ergodic p.m.p. equivalence relation on a nonatomic standard
probability space `(X,mu)`, put

```text
A=L_infinity(X),                       M=L(R),         (NFC1)
```

and let `Lambda <= [R]` be a countable subgroup whose orbit relation is `R`.
For its canonical full-group unitaries `u_g in M`, define the fixed-point
character

```text
chi(g)=tau_M(u_g)=mu(Fix(g)).                           (NFC2)
```

There is a tempting replacement for the impossible essentially-free
groupification: allow infinite stabilizers, but require `chi` to extend to a
normal tracial state on `L(Lambda)`. Then the groupoid representation would
be a normal representation of the group von Neumann algebra.

That entire route is impossible for a non-Connes-embeddable relation factor.

**Theorem 1 (normal-character no-go).** Assume

```text
W*(u_g:g in Lambda)=M                                 (NFC3)
```

and that `chi` is normal on `L(Lambda)`. Then the action of `Lambda` on
`(X,mu)` is profinite and `Lambda` is residually finite. Consequently `M` is
Connes embeddable.

In particular, the canonical full-group unitaries of a non-CE ergodic
equivalence relation can never simultaneously W*-generate its relation
algebra and have a normal fixed-point character on `L(Lambda)`.

This closes both finite and infinite stabilizer versions of the
normal-character bridge. The earlier finite-stabilizer theorem in
`FALSE_FINITE_STABILIZER_FULL_GROUP_GROUPIFICATION.md` remains a direct
elementary special case which does not assume normality.

## 2. Fourier coefficients of a normal state vanish at infinity

Let `Gamma` be any countable group. Every normal functional `phi` on
`L(Gamma)` has a density `h in L^1(L(Gamma))`:

```text
phi(x)=tau(hx).                                        (NFC4)
```

Its Fourier coefficients

```text
hat(phi)(g)=phi(lambda_g)                              (NFC5)
```

belong to `c_0(Gamma)`. Indeed, choose `h_n in L^2(L(Gamma))` with
`||h-h_n||_1 -> 0`. The coefficients of `h_n` lie in `ell^2(Gamma)` by
Plancherel and hence vanish at infinity, while

```text
|tau((h-h_n)lambda_g)| <= ||h-h_n||_1                 (NFC6)
```

uniformly in `g`. Thus `(NFC5)` is a uniform limit of `c_0` functions.

Apply this to `(NFC2)`. The character `chi` is conjugation invariant. If
`chi(g)>0` and the conjugacy class of `g` were infinite, the same positive
value would occur at infinitely many points, contradicting `chi in c_0`.
Therefore

```text
mu(Fix(g))>0  ==>  g has finite conjugacy class.       (NFC7)
```

Write `FC(Lambda)` for the set of elements with finite conjugacy class.

## 3. Cartan expectation forces a profinite action

For a canonical full-group unitary, the Cartan expectation is

```text
E_A(u_g)=1_(Fix(g)).                                   (NFC8)
```

If `g` is not in `FC(Lambda)`, `(NFC7)` makes `(NFC8)` zero. If `g` is an FC
element, the `Lambda`-orbit of its fixed set is finite because

```text
h Fix(g)=Fix(hgh^(-1)).                                (NFC9)
```

Let `B <= A` be the von Neumann algebra generated by all fixed sets of FC
elements. Enumerating the FC elements and adjoining one finite orbit at a
time gives an increasing sequence

```text
B_1 <= B_2 <= ... <= A                                (NFC10)
```

of finite-dimensional `Lambda`-invariant algebras with
`B=(union_n B_n)''`.

Equations `(NFC7)--(NFC8)` give

```text
E_A(C[Lambda]) <= B.                                  (NFC11)
```

Normality of `E_A` then gives

```text
E_A(W*(u_g:g in Lambda)) <= B.                        (NFC12)
```

Under `(NFC3)`, every `a in A` belongs to the algebra on the left and
`a=E_A(a)`. Hence `A<=B`; the reverse inclusion is automatic, so

```text
A=B=(union_n B_n)''.                                  (NFC13)
```

This is exactly profiniteness of the p.m.p. action: its Cartan algebra is
generated by finite-dimensional invariant subalgebras.

## 4. Faithful profinite full-group actions are residually finite

For each `n`, the action on the finite set of atoms of `B_n` gives a
homomorphism

```text
rho_n:Lambda -> Sym(Atoms(B_n)).                       (NFC14)
```

Suppose `g` belongs to every `ker(rho_n)`. It fixes every `B_n` pointwise,
and `(NFC13)` implies that it fixes all of `A` pointwise. A full-group element
which acts trivially on `L_infinity(X)` is the identity almost everywhere.
Thus

```text
intersection_n ker(rho_n)={1}.                        (NFC15)
```

The finite quotients in `(NFC14)` separate points, proving that `Lambda` is
residually finite. This final algebraic implication is formalized source-first
as `residuallyFinite_of_separating_finite_actions` in
`GroupApproximation/Sofic/HyperlinearReduction.lean`. No build was run for
that edit. The preceding normal-Fourier and Cartan-expectation arguments are
not claimed to be formalized.

## 5. Normality would make the non-CE factor a group-factor summand

The canonical representation of `C[Lambda]` in `M` with cyclic trace vector
has character `chi`. If `chi` is normal on `L(Lambda)`, its GNS
representation extends to a normal *-homomorphism

```text
Theta:L(Lambda) -> M.                                 (NFC16)
```

Assumption `(NFC3)` makes `Theta` surjective. Since `M` is a factor, this
normal quotient is isomorphic to a central factor summand of `L(Lambda)`.

Residual finiteness makes `Lambda` sofic and hence hyperlinear, so
`L(Lambda)` is Connes embeddable. Connes embeddability passes to central
summands. Equation `(NFC16)` therefore makes `M` Connes embeddable, proving
Theorem 1.

The same argument shows why the initially attractive sufficient condition

```text
chi in ell^2(Lambda)                                  (NFC17)
```

cannot help: `(NFC17)` certainly makes `chi` normal, but normality alone
already triggers the no-go.

## 6. Consequence for the active program

There is no canonical full-group solution obtained by improving weak
containment to normal containment. Any such improvement would force the
action to be profinite, force the acting full-group subgroup to be residually
finite, and force the generated relation factor to be CE.

Therefore a conversion of Manzoor's non-CE relation into a nonhyperlinear
discrete group must use operators other than only its canonical full-group
unitaries, or embed the relation algebra into a group factor by a genuinely
noncanonical construction. The Pauli finite-multiplicity endpoint and the
perfect-completeness LCS endpoint remain unaffected.

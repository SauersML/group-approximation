# notes/ — the prose corpus

Derivations, audits, dead ends, session logs, thinking out loud. Everything
written in prose that is not a Cairn node lives here.

Searchable (`bin/cairn search --notes`) and citable: a route may cite a file
here via `artifacts:`, the same way it cites `research/artifacts/` or a Lean
module. Nothing here is compiled, so nothing here can change research state on
its own — a claim is established by its route and its Lean, never by a
paragraph in this directory asserting it.

`TRUE_*` and `FALSE_*` are the proof corpus proper: a result worked out far
enough to cite. The rest is reconnaissance, and the difference is legible from
the filename rather than from which directory the file sits in.

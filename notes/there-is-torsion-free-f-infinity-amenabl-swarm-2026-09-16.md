## What was proven (own proofs; artifact)

1. **Section-word lemma.** Each letter of `w` contributes exactly one letter to one section. The
   coordinate is `m(x) + (parity of earlier b-letters)`.
2. **One-coordinate words.** A freely reduced word with all sections in one coordinate is `a^k`,
   `a^k b`, `b^(−1) a^k` or `b^(−1) a^k b`.
3. `a` and `b` have infinite order. The exponent sums are well-defined, so `B^ab ≅ Z^2`.
4. **`B` is torsion-free** (induction on geodesic length).
5. `(x, y) ∈ B'` for all `x, y ∈ B'`, via `[a, b^2] = (1, [b, a])` and `b^(−1)(x, 1)b = (1, x)`.
   Hence `Z^(2^k) ≤ B` and `cd B = ∞`.
6. `σ(g) = (a^(ε_a(g)), g)` is an injective endomorphism with `σ(B) = ⟨a, b^2⟩`, and
   `[B : σ(B)] = ∞`.
7. `B~` has the normal form `t^p g t^(−q)`. It is torsion-free, `cd B~ = ∞`, and its Bass–Serre
   tree has infinite valence.

Convention finding: Bartholdi–Virág's relator `[[[a, t^(−1)], a], a]` holds in `B` when read with
`[x, y] = x^(−1) y^(−1) x y`, where it becomes `[[b, a], a]`, equivalent to `[a, a^b] = 1`. With
`[x, y] = x y x^(−1) y^(−1)` it is false in `B`.

## Homology computed (in the open hole)

- `σ_*` on `H_1(B) = Z^2` has matrix `[[0, 1], [2, 0]]` and `det(1 − σ_*) = −1`. Hence
  `H_1(B~) = Z` and `H_2(B~) = coker(1 − σ_*)` on `H_2(B)`.
- `N = ker χ` has `N^ab = Z[1/2]^2`, `H_1(N; F_2) = 0` and `H_1(N; Q) = Q^2`.
- **Degree 2, conditional sketch (not in the graph).**
  - Every relator `r_n = σ^n([a, a^b])` of Lemma 11 is a commutator, so `R ≤ [F, F]`. By Hopf's
    formula `H_2(B) = R/[F, R]`, which is generated by the images of the `r_n`, and `σ_*` shifts
    `r_n ↦ r_(n+1)`.
  - If these images are a free basis, which this lane has not verified, then `1 − σ_*` is
    injective with cokernel `Z`, so `H_2(B~) = Z`. Also `H_2(N) = colim ≅ Z[t^(±1)]`, free of
    rank 1.
  - This is consistent with the presentation complex of `B~`: `χ = 1` and `H_1 = Z` give rank 1
    for `H_2` of the complex, and `H_2(B~)` is a quotient of it.
  - Degree 3 would need the relations among the relators (the relation module), which the
    L-presentation does not display.

## Approaches and exactly where each dies

1. **Alexander-module test** (`H_k(N; F)` finitely generated over `F[t^(±1)]` for `k ≤ n`).
   Degrees 1 and 2 pass, degree 2 automatically. Degree 3 needs `colim_(σ_*) H_3(B; F)`, and no
   computation of `H_3(B)` is available. Not evaluated.
2. **Brown's criterion on the Bass–Serre tree.** The action is cocompact, with stabilizers
   conjugate to `B`. The infinite valence does not matter for the criterion.
   - Homotopical form (`F_n`): dies at degree 2, because `B` is not finitely presented (Erschler;
     see `fp-covers-of-grigorchuk-groups-are-large`).
   - Homological form (`FP_n`): "`B` is of type `FP_∞`" would suffice, but it is undecided. `B` is
     not of type `FP_2` if `H_2(B)` is infinitely generated. By the 5-term sequence for
     `G_n = ⟨a, b | r_0, …, r_(n−1)⟩ → B`, that holds iff `K_n ≠ [G_n, K_n]` for every `n`, where
     `K_n` is the normal closure of the `r_m` with `m ≥ n`.
     - The iff holds because `H_1(G_n) → H_1(B)` is an isomorphism, since every `r_m` lies in
       `[F, F]`, and `H_2(B) = R/[F, R]` is generated by the classes of the `r_m`.
     - A quotient of `G_n` in which every `r_m` with `m ≥ n` is central, and some is nontrivial,
       witnesses `K_n ≠ [G_n, K_n]`. Checking that involves infinitely many `r_m`, unless the
       quotient is compatible with `σ`.
     - Not tested; no GAP was available.
3. **Changing the base.** An ascending HNN description `B~ = B'*_τ` with `B'` of type `F_∞` would
   give `F_∞`. But such a `B'` contains a copy of `B`, so it is itself a torsion-free amenable non-EA
   group, and of type `F_∞` it would answer the target directly. No easier.
4. **Kropholler fence.** Proves no obstruction, only a constraint. Torsion-free, `cd = ∞` and
   `FP_∞` force `B~ ∉ H𝔉`, hence `B ∉ H𝔉`. Gandini's non-membership criterion (Theorem 4.7 and
   Corollary 4.10) needs jump rational cohomology of finite height, which `B` lacks because it
   contains `Z^n` for every `n`. So `B ∈ H𝔉` is undecided; if it holds, the hole is refuted.
5. **Euler characteristic and `L^2`.** The presentation complex has `χ = 1` and `b_1^(2) = 0`
   (amenable), so `b_2^(2) = 1` and the complex is not aspherical. No constraint on `FP_3`.
6. **Mod-p homology growth and Lück-type approximation.** These need residual chains of
   finite-index subgroups. Residual finiteness of `B~` is not known to this lane, and for amenable
   groups they give vanishing, not an obstruction. Dead as an obstruction.
7. **Sigma invariants.** `H^1(B~; R) = R`, so only `±χ` matter. `N` is not finitely generated, so
   at most one of them is in `Σ^1`. Putting it in `Σ^n` is the base-change problem of item 3
   (Bieri–Renz criterion recalled, not re-read).
8. **Locally finite tree (unchecked sketch).** The formula "`g` acts on the level-`n` extended
   tree as `σ^n(g)`" suggests `B~` acts on the 3-regular tree `⋃_n T^(n)`, the ascending union of
   rooted binary trees, with `t` shifting the root. This was not checked, and neither was the
   finite generation of vertex stabilizers. It is not in the graph.

**Sanity constraint on disproofs.** Thompson's `F` is torsion-free, of type `F_∞`, has `cd = ∞`,
lies outside `H𝔉`, and is an ascending HNN extension of a copy of itself with infinite-index image.
A no-go argument using only properties `F` shares contradicts Brown–Geoghegan. If it also uses
amenability, it would prove `F` non-amenable. A disproof must use features `F` lacks, such as the
base `B` not being finitely presented, or `B ∉ SG`.

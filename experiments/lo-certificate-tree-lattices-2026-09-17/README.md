# Non-left-orderability certificates for simple lattices in products of trees (2026-09-17)

This directory supports claim `rattaggi-simple-lattices-are-not-left-orderable`.
Requirements: Python 3 and python-sat (CaDiCaL 1.5.3). The verifier uses the Python standard
library only, plus the relator strings in `bmw.py`.

| file | role |
|---|---|
| `bmw.py` | one-vertex complete VH complexes, Bridson–Wise normal forms, relator lists (Rattaggi Λ, Σ, A6, Wise D) |
| `test_bmw.py` | relators evaluate to 1, associativity, inverses, commuting `F_2×F_2` |
| `lo_sat.py` | CNF builder: pair variables `P(g^-1) = ¬P(g)`, clauses `¬P(p) ∨ ¬P(q) ∨ P(pq)` |
| `lo_search.py` | ball (Bridson–Wise length ≤ L, parity kernel), triples with one short factor, CaDiCaL, core and deletion MUS |
| `verify_certificate.py` | independent check by relator rewriting and self-contained DPLL |
| `calib_promislow.py` | calibration: Promislow group UNSAT, `F_2×F_2` SAT |
| `certificate-*-kernel-L4.txt` | minimal certificates, one line per triple `p ; q ; r` |
| `run-*.log` | recorded outputs |

The certificate files were generated by `lo_search.py`, except that the Λ certificate was produced
by an earlier driver with the same ball and the same triple rule. It is in the same format and
verified by the same verifier.

Negative controls:
- Removing any single line gives `certificate INVALID`, since the certificates are minimal
  unsatisfiable sets.
- Altering a word gives the assertion `triple not a product`.

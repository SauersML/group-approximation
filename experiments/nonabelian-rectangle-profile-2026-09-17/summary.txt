== Obstruction (centralizer-rounding-cannot-bound-rank-distance-by-profile) ==
crossframes.py p : cross-slit pair on (Z/p)^2 x Z/2; for every primitive v with |v|_1 <= p-1 checks that
B = b^v1 c^v2 has cycle lengths in {p,2p}, nonempty 2p-part M_B, and |M_B \ g M_B| >= 2p (g = c if v1 != 0,
else b), which forces rank(c''-c) (resp. rank(b''-b)) >= 2p for every commuting (b'',c'') keeping B.
crossslit.py M : cylinder variant (base Z/L, fibre Z/l x Z/2), dist <= 1, exact rho, best exact
one-sided rounding over frames with entries <= M.

Reading: on random slit covers with non-abelian fibre, one-sided rounding stays within ~3.4 rho
(these covers have slits of length comparable to the base, so rho is large). The cross-slit pair shows
this is not a theorem: rho = 2, dist = 1, one-sided cost >= 2p in every frame of norm < p.

# Qudit stabilizer rounding constants: computations (2026-09-17, sw-078b)

These support `research/qudit-code-rounding-factor-one-plus-inv-sqrt-d.md`,
`research/qudit-weyl-rounding-constant-linear-upper-bound.md` and
`research/qudit-weyl-rounding-sharp-constant.md`. None of the proofs uses them. Every run was
single-threaded under `nice -n 10 timeout 1200` (1500 for `check_d5_n2`), with numpy and scipy (HiGHS).

`weyl.py` provides the shared helpers:
- Weyl operators `D(a,b) = omega^(2^(-1) ab) X^a Z^b`, which satisfy `D(-v) = D(v)^*`.
- Stabilizer states from a BFS Clifford orbit, generated by F, P, X and CSUM. The counts
  are 12 and 360 for `d=3`, `n=1,2`; 30 for `d=5, n=1`; 56 for `d=7, n=1`. They match
  `d^n prod (d^k+1)`.
- Expectation tables of Weyl operators on those states.

| script | what it does | result (log) |
|---|---|---|
| `dual_lp.py cc d n restarts steps seed` | CC dual `g(psi) = min g` such that a stabilizer mixture has `1 - tr(rho Pi_S) <= g(1 - <psi\|Pi_S\|psi>)` for all code projectors (12, 30, 480 of them); local search over `psi` | d=3,n=1: 1.5773502 = 1+1/sqrt3 (`cc_d3_n1.log`); d=5,n=1: 1.4472134 = 1+1/sqrt5 (`cc_d5_n1.log`); d=3,n=2 random restarts: 1.5451991 (`cc_d3_n2.log`) |
| `cc_seeded.py` | CC dual at d=3, n=2, seeded at (one-qutrit extremal) x (0, +, extremal, random) | every seed stays at 1.5773503 (`cc_seeded_d3_n2.log`) |
| `cc_postselect_check.py d n trials seed` | runs the proof's rounding (top eigenvector in the current code space, post-select on the most satisfied term, compress the rest, recurse) on random `H = sum w_a (I - Pi_a)` and compares against `gamma_d` | d=3,n=1: worst 1.577350; d=3,n=2 (1500 trials): 1.577350 against 1.6 (`check_d3_n2.log`); d=5,n=1: 1.447214; d=5,n=2 (400 trials, 4680 projectors): 1.447214 = gamma_5 (`check_d5_n2.log`); d=7,n=1 (400): 1.377964 = gamma_7 (`check_d7_n1.log`). There were no violations, and the sharp example is reached. |
| `dual_lp.py sr d n restarts steps seed [N_dir]` | SR dual `c(psi) = min c` such that a stabilizer mixture `m` has `\|m_v - (1+c)x_v\| <= c`; the modulus is a 16-gon, and rhs `c` / `c cos(pi/16)` give lower / upper values | d=3,n=1: 0.7500 / 0.763 (run not logged); d=3,n=2: 0.7491613 / 0.7564428 (`sr_d3_n2.log`); d=5,n=1: 1.3843045 / 1.3940456 (`sr_d5_n1.log`); d=7,n=1: 2.0475361 / 2.0667971 (`sr_d7_n1.log`) |
| `candidates.py` | primal ratios `(lambda_max - stab)/(W - lambda_max)` for antiparity, Harper and all-lines sums on one qudit | exploratory |
| `harper_lower_bound.py` | antiparity ratio `d/((d-2)(d+1))` and Harper `Z+Z^*+X+X^*` ratio `(lambda-2)/(4-lambda)` up to d=211 | Harper: 0.9351 (5), 1.5104 (7), 2.7650 (11), 3.3992 (13), 9.1220 (31), 18.6691 (61), 31.4006 (101), 66.4140 (211); antiparity 0.75 at d=3 (`harper_lower_bound.log`) |
| `pair_gap.py` | exact pair gap `eps_d = min(delta_u + delta_v)` for `uv = omega^s vu`, compared with the proved `sigma_d = sin(pi/d)/(1+2sin(pi/d))` | eps_d = 0.5858, 0.6340, 0.5168, 0.3984, 0.2656, 0.2273 for d=2,3,5,7,11,13 (output not logged; rerun takes seconds) |

The dual formulations hold by LP minimax, since each rounding inequality is monotone in
`lambda`. So `sup_psi` of the dual value is the optimal constant for that `(d, n)`, and
any value found at a particular `psi` is a lower bound for it.

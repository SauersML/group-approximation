# Two-cell character ideal: results (lane w10-048, 2026-09-18)

Supports `research/degree-one-two-cell-configs-evade-character-tests.md`.

The question: for a degree-one two-cell configuration with `ab ≠ 0`, is the ideal of
`Z[s^±, t^±]` generated by the abelianized cylinder row `c^ab` always proper? It is proper exactly
when some character kills `c`. It is not always proper.

## Scripts

| file | role | tier |
|---|---|---|
| `verify2.py` | Independent replay of every claim about (C2), which has `w = yxYXXyyxYXYxYYxyXy` and rank 5. It checks the word, both loops, `[u_1] = 2[u_0]`, all of `c^ab`, `c^ab · J^ab = 0`, the certificate `(1+s)c_a + s⁻²c_c = 1`, the free identity for `g ∈ P`, and the degree-9 G-set showing `g ∉ H`. | exact; used by the proof |
| `verify1.py` | The same checks for (C1), which has rank 4 and length 34. It also checks the `F_2` rank-2 kill, so (C1) is not admissible. | exact; used by the proof |
| `fc.py` | Library: graphs, fiber-product components, word building, the abelianized Fox row, Gröbner and resultant unimodularity over `Z`. | library |
| `census.py`, `census2.py` | Census of fiber-product configurations with `λ ∈ {2, 3/2, 4/3}` and `|w| ≤ LMAX`. `census2` decides unimodularity of `c^ab` exactly and labels each case `charq`, `Qbar`, `bad<primes>` (an `F̄_p` kill), `ZUNIT` or `noN` (undecided). | script output |
| `gL.py` | Index of `L = im(H → Z²)` and the order of `ḡ` modulo `L`. Every `ZUNIT` line has `L = Z²`. | script output |
| `reptest.py`, `cand1.py`, `nonab.py` | Full-rank test of the block row `(ρ(c_x))` over `F_p` for transitive permutation representations of degree `≤ KMAX`. | script output |
| `zq.py` | Unimodularity over `Z[Q]` for finite quotients `Q`, via the Hermite normal form of the regular representation. | script output |
| `ext.py` | Finite G-sets extending `Γ`. For (C2) there are none of degree 5 to 8, and 48 of degree 9. | script output |

## Data

- `cand1.line`, `cand2.line`, `cand3.line`, `w9.line` are single census lines: (C1), (C2), the
  length-74 rank-5 row, and the rank-3 core of
  `degree-one-two-cell-cores-with-ab-nonzero-exist`.
- `c2_4_3.out`, `c2_5_3.out`, `c2_4_4.out` and `c2_5_5.out` are census2 outputs, one line per
  configuration, of the form `n r |w| verdict ...`. The two 5-vertex runs stopped at the 1200 s
  limit.
- `rep_cand2_7.out`: (C2) survives every transitive representation of degree 2 to 7, which number
  3, 5, 17, 42, 191 and 818.
- `zq_cand2_7.out`: (C2) is unimodular over `Z[Q]` for every image `Q` that occurs. The orders are
  2, 3, 4, 5, 6, 7, 12, 20, 21, 24, 36 and 42.

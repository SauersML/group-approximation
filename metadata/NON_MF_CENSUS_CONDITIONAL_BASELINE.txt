# Conditional findings of `scripts/sentence_census.py --verify-unconditional`
# that are known and written up.  One line per accepted finding:
#
#     <detector> <declaration>  -- why it is accepted
#
# This register is not a budget.  A finding not listed here fails the gate, and
# a line here that matches nothing fails it too -- so a discharged item cannot
# be left behind to license its own return.  There is no count anywhere in the
# mechanism, so there is no number a reviewer can raise instead of discharging
# the debt.
#
# It is the companion of metadata/NON_MF_UNCONDITIONAL_BASELINE.txt, which
# registers the same kind of finding on the badge surface.  Two registers
# because they are two surfaces: the badge gate classifies the declarations the
# manuscript cites in `\leanverified`, and this one classifies the much larger
# set the sentence map names.  Sharing one file would make "stale" ambiguous.
#
# Opened 2026-08-30 by census-lane for issue #53, with every finding of the day
# listed, so that the two-status split lands without changing pass or fail and
# the interesting event -- a NEW conditional row -- fails from that day.
#

# a cited CARRIER (a `structure` or a `def ... : Prop` named as the thing that
# proves a sentence) was never classified at all, because `classify` reads
# premises and a carrier has none; and a REFUTATION was registered as a producer
# of the name it refutes, so proving a citation false made it read as available.

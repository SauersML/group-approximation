# The centre of the Pestov 9.1 witness ring is `𝔽₂` (blueprint v2, G3)

`WitnessRing = CrossedProduct toeplitzShift` is `LC(X, 𝔽₂) ⋊ ℤ` over the period-doubling Toeplitz
subshift `X`.  Artifact §1.4 computes its centre, and this module instantiates the σ-level
`crossedProduct_central_zero_or_one` with the Toeplitz dynamics of blueprint G1:

* `toeplitzShift_free`: nonzero powers of the shift fix no point, and `X` is nonempty;
* `toeplitzShift_dense_orbit`: every orbit is dense;
* `X` is totally separated.

`central_zero_or_one_witnessRing` is the hypothesis `hR` of
`SplitSimplicity.isSimpleGroup_elementaryGroup_crossedProduct` (G4).  `center_witness_eq_bot`
records the consequence `Z(EL₃(R)) = 1`, so the witness is `EL₃(R)` itself (D5).

/-- **G3.** Every central element of the witness ring is `0` or `1`. -/
theorem central_zero_or_one_witnessRing :
    ∀ c : WitnessRing, (∀ r : WitnessRing, r * c = c * r) → c = 0 ∨ c = 1 :=
  crossedProduct_central_zero_or_one toeplitzShift
    (fun j hj ↦ ⟨Classical.arbitrary ToeplitzSpace, toeplitzShift_free j hj _⟩)
    toeplitzShift_dense_orbit

/-- **The centre of the witness group is trivial**: `Z(EL₃(WitnessRing)) = 1`. -/
theorem center_witness_eq_bot : Subgroup.center ↥(elementaryGroup (Fin 3) WitnessRing) = ⊥ :=
  center_elementaryGroup_eq_bot_of_central_zero_or_one central_zero_or_one_witnessRing

Probe job template: message replay after artifact-cache restores (pc-infra, 2026-09-13; unreviewed, uncalibrated)

Target: tools/bc-swarm/remote/bcjob.template.sh, and every campaign copy of it (bc, fz, pc).

Observed on the shared campaign clone, probe 0913-021434-13436: an overlay module whose build outputs were restored
from the shared Lake artifact cache gets a synthetic trace ("synthetic": true, "log": []). None of its build messages
reach the job log. Two `#print axioms` lines of a restored module never printed, so the closure count check failed the
probe with rc=7 ("1 printed, 3 requested"). That is a false red.

Inferred, not observed: by the same mechanism, a Palomar-library module restored from the cache would not print its
incomplete-proof warning, and the hole gate (rc=6) would pass it. The Palomar libs build without warningAsError, so an
olean for such bytes exists and is cached after the first probe of those bytes. Probe 0913-022958-80841 built such a
module for real and failed rc=6 as expected. The restore case (H2) and the fixed template (H3) never ran: the campaign
stopped first.

Proposed fix. Insert after the `timeout 10800 nice -n 5 $TS lake build $MODS >> "$LOG" 2>&1; RC=$?` line and before
`echo "EXIT=$RC" >> "$LOG"`:

# Message replay: an overlay module restored from the shared artifact cache gets a synthetic trace with an empty log,
# so its warnings and `#print axioms` output never reach $LOG, and the hole gate below could pass an incomplete proof in
# a Palomar module. Every overlay module whose messages a gate reads (Palomar/*.lean outside *Challenge.lean, and any
# file with `#print axioms` lines) that this build did not Build has its outputs removed and is built once more with
# artifact restore off; a module still not Built fails the probe (rc=8).
if [ $RC -eq 0 ]; then
  : > "$CLONE/.nm/rebuild-$TAG"
  while IFS= read -r p; do
    case "$p" in *.lean) ;; *) continue;; esac
    need=0
    case "$p" in Palomar/*Challenge.lean) ;; Palomar/*.lean) need=1;; esac
    grep -q '^#print axioms ' "$CLONE/$p" && need=1
    [ $need = 1 ] || continue
    m=${p%.lean}; m=${m//\//.}
    { grep -qF "Built $m " "$LOG" || grep -qE "Built ${m//./\\.}\$" "$LOG"; } && continue
    b=".lake/build/lib/lean/${p%.lean}"; ir=".lake/build/ir/${p%.lean}"
    rm -f "$b.olean" "$b.olean.hash" "$b.ilean" "$b.ilean.hash" "$b.trace" "$ir.c" "$ir.c.hash"
    echo "$m" >> "$CLONE/.nm/rebuild-$TAG"
  done < "$CLONE/.nm/ovpaths-$TAG"
  if [ -s "$CLONE/.nm/rebuild-$TAG" ]; then
    echo "[job] replay: not Built by this build, so their messages did not print; rebuilding with artifact restore off: $(tr '\n' ' ' < "$CLONE/.nm/rebuild-$TAG")" >> "$LOG"
    LAKE_RESTORE_ARTIFACTS=false timeout 3600 nice -n 5 $TS lake build $(tr '\n' ' ' < "$CLONE/.nm/rebuild-$TAG") >> "$LOG" 2>&1; RC=$?
    while IFS= read -r m; do
      grep -qF "Built $m " "$LOG" || grep -qE "Built ${m//./\\.}\$" "$LOG" \
        || { echo "[job] replay: $m was still not Built after the restore-off rebuild" >> "$LOG"; [ $RC -ne 0 ] || RC=8; }
    done < "$CLONE/.nm/rebuild-$TAG"
  fi
  rm -f "$CLONE/.nm/rebuild-$TAG"
fi

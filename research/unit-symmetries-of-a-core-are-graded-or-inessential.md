**ESTABLISHED** through `unit-symmetries-of-a-core-are-graded-or-inessential-proof`. Refereed:
gq-referee-a PASS, proof-gap lens (report 8942e4e4b); gq-referee-b PASS, citation lens (report af0cad75d); nits
applied. Item 1 is the standard argument behind Jordan's Theorem O (D. A. Jordan, Comm. Algebra 12 (1984),
135--137, read through Bäck--Richter, arXiv:2207.07994v9, Theorem 3): `A[x^±1; σ]` is simple if and only if `A` is
`σ`-simple and no `σ^n`, `n != 0`, is inner by a `σ`-fixed unit. Item 1 produces exactly such a unit, `g_m`. The proof here is self-contained. No priority is
claimed.

**Setting.** `R` is a nonzero unital ring generated by a unital subring `A` and a unit `x` with `x A x^-1 = A`.
Put `σ = (a -> x a x^-1)`, an automorphism of `A`, and `T = A[x^±1; σ]`, the skew Laurent ring. Assume `A` has no
nonzero proper `σ`-invariant ideal, for example `A` simple. Let `π : T -> R` be the natural surjection and
`J = ker π`.

**Statement.**
1. **Dichotomy.** Either `J = 0`, so `R ≅ A[x^±1; σ]` is `Z`-graded with the unit `x` in degree `1`, or there are
   `m >= 1` and `g_1, ..., g_m in A` with `g_m` a unit, such that:
   - `b g_k = g_k σ^k(b)` for all `b in A` and `σ(g_k) = g_k`, so the `z_k = g_k x^k` are central in `R`;
   - `J` is generated by `1 + z_1 + ... + z_m`;
   - `σ^m(b) = g_m^-1 b g_m` for all `b`, so `σ^m` is inner.
2. **Graded case.** If `J = 0` and `Q ⊆ R`, then `graded-rings-with-degree-one-units-fail-the-k-budget` applies.
   Either `ker(Q^x -> K_1(R))` is not finitely generated, or no `E_N(R)`, `N >= 3`, is finitely presented.
3. **Inhomogeneous case.** If `J != 0`, with `m` as in item 1:
   - (a) `R = A ⊕ A x ⊕ ... ⊕ A x^(m-1)`, free of rank `m` as a left and as a right `A`-module;
   - (b) if `R` is generated by `x^±1` and a finite set `F ⊆ A`, then `A` is generated by the finite set
     `∪_(0 <= j < m) σ^j(F) ∪ {g_1, ..., g_m, g_m^-1}`;
   - (c) `σ^m` acts trivially on `K_n(A)` for every `n`, so `σ` acts on `K_0(A)` with finite order dividing `m`;
   - (d) restriction `K_0(R) -> K_0(A)` sends `[1_R]` to `m[1_A]`, and restriction after induction is
     `Σ_(0 <= k < m) σ^k_*`. If `Q ⊆ R`, then `Q ⊆ A`, and `ker(Q^x -> K_1(A)) ⊆ ker(Q^x -> K_1(R))`.
4. **For the gate.** Suppose `R` satisfies items 3--4 of `fp-simple-resolvent-ring-with-divisible-unit-class`
   (`[1]` of infinite order and divisible by every integer) and rational `K_1` detection. In the inhomogeneous
   case, `m[1_A]` has infinite order and is divisible by every integer in `K_0(A)`, and `A` inherits `K_1` detection.
   Here `A` is finitely generated without the symmetry, and `σ` produces only finitely many classes from each class
   of `K_0(A)`. So, in the inhomogeneous case, the core is already finitely generated and the symmetry adds no
   `K_0` classes; the graded case is killed by item 2. Finite presentation of `A` is not addressed.

## Scope

- **What is closed.** Designs that get finite presentation from a unit shift of the base or core, as with periodic
  graphs, whether the relations in the symmetry are homogeneous or not.
- **What is not closed.** Non-invertible shifts: isometric frames and register letters, as in `R_L` and the register
  completions. There the squeeze recorded on the gate applies: one register divides `[1]` at finitely many primes,
  and a two-register comparison is not simple. The singular and multi-type cases are still open.
- **Hypothesis.** `σ`-simplicity of `A` is used in item 1. It holds when `A` is simple. Unit symmetries of cores
  that are not `σ`-simple are not covered, and simplicity of `R` does not obviously exclude them.

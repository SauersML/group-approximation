Notation as in the target. Write `λ(y) = c` for `y ∈ L_c`.

**Step 1: one level of recursion.** `A` is `g`-invariant, so by (R1) `A = gA = gD ⊔ g²D ⊔ g³D`, and
hence `g³D = D`. Let `y ∈ g^j D` with `j ∈ {0,1,2}`, and put `z = g^{-j} y ∈ D`.
- The times `m` with `g^m y ∈ D` are exactly `m ≡ −j (mod 3)`. At all other times `λ = 0`, by (R3).
- By (R2), `g^{3t} z = Ψ g^t Ψ^{-1} z`.
- By (R4), `λ(Ψ w) = λ(w) + 1` for all `w ∈ A`.
- So `I(y)(3t − j) = I(Ψ^{-1} z)(t) + 1`.

Let `θ` be the map on sequences with `θ(s)(3t) = s(t) + 1` and `θ(s)(m) = 0` for `3 ∤ m`. Then
`I(y) = σ^j θ(I(y'))` with `y' = Ψ^{-1} z ∈ A`, where `(σ^j r)(m) = r(m + j)`.

**Step 2: all levels.** Using `θ ∘ σ^j = σ^{3j} ∘ θ` and iterating `k` times:
`I(y) = σ^{J_k} θ^k(s_k)`, with `s_k` an itinerary, `J_k ∈ [0, 3^k)` and `J_{k+1} ≡ J_k (mod 3^k)`.
By induction on `k`, for `n ≢ 0 (mod 3^k)` we have `θ^k(r)(n) = v_3(n) mod 3`. So `I(y)(m) = v_3(m + J_k) mod 3`
whenever `3^k ∤ (m + J_k)`.

Put `x = lim J_k ∈ Z_3`. If `m + x ≠ 0`, choose `k > v_3(m + x)`. Then `v_3(m + J_k) = v_3(m + x)`, so
`I(y)(m) = v_3(m + x) mod 3`, and hence `I(y) ∈ T_3`.

**Step 3: factor map.** `I` is continuous, since the `L_c` are clopen, and it satisfies `I ∘ g = σ ∘ I`. Its
image is a nonempty closed invariant subset of `T_3`.

`T_3` is closed and minimal.
- *Closed.* If `s_i → s` with parameters `x_i`, pass to a subsequence `x_i → x`. For `m + x ≠ 0`,
  `v_3(m + x_i) = v_3(m + x)` for large `i`, so `s` has parameter `x`.
- *Minimal.* Fix `x_0 ∈ Z_3 ∖ Z` and its sequence `t(m) = v_3(m + x_0) mod 3`. Let `s ∈ T_3` have
  parameter `x`, take a window `[−N, N]`, and let `K > max_{|m| ≤ N, m+x ≠ 0} v_3(m + x)`.
  - Choose `n ∈ Z` with `n + x_0 ≡ x (mod 3^K)`. Then `(σ^n t)(m) = v_3(m + n + x_0) = v_3(m + x)` at every
    `|m| ≤ N` with `m + x ≠ 0`.
  - If `x ∈ Z` and `|x| ≤ N`, the hole `m_0 = −x` has letter `c`. Choose instead `n` with
    `v_3(n + x_0 − x) = K'` for some `K' ≥ K` with `K' ≡ c (mod 3)`. This is possible because `Z` is dense
    in `Z_3`. Then the hole letter matches too.
  - So every `s ∈ T_3` is a limit of shifts of `t`. In particular every closed invariant subset is all of
    `T_3`, and all three fillings of each hole occur.

So the image of `I` is `T_3`, which proves item 1.

**Item 2 (Lemma A).** Let `h ∈ T_3` be a hole point, with parameter `x ∈ Z` and hole letter `c` at
`m_0 = −x`. The letter at `m_0` is locally constant on `T_3`. So on a neighbourhood `N_h` of `h`, every
`s` has `s(m_0) = c`, and for regular `s` this letter is `v_3(m_0 + p(s)) mod 3`. Hence
`p(N_h) ⊆ {u : u = p(h) or v_3(u − p(h)) ≡ c (mod 3)}`, a set with empty interior near `p(h)`.

If `J(y_0) = h` and `p∘J` were open at `y_0`, then `p(J(N))` would contain a neighbourhood of `p(h)` for
every neighbourhood `N` of `y_0`. But `J(N) ⊆ N_h` for small `N`, which is a contradiction.

**Item 3.**
- *Nekrashevych's hypotheses.* The dihedral action on `Z_3` is minimal (translations by `Z` are dense).
  `a` fixes `ξ = 0`. The pieces `P_j` are open, `a`-invariant, cover `Z_3 ∖ {0}` and each accumulates at
  `0`. `A_frag = {1, h_1, h_2, h_1h_2}` realises `{000, 110, 101, 011}`, and `B = {1, b}`.
- *Purely non-Hausdorff singularity.* By his Lemma `lem:germsofxi`, every germ at `ξ` of an element of
  `G_ξ` is the germ of some `h ∈ A_frag`. Each such `h` is the identity on one piece accumulating at `0`.
  So `ξ` is a purely non-Hausdorff singularity, and `G` is periodic (Theorem `th:main`).
- *Infinite and finitely generated.* `G`-orbits equal dihedral orbits, which are infinite, and `G` is
  generated by `h_1, h_2, b`.
- *Schreier subshift.* By Proposition `prop:embeddingfull`, `G` embeds in `[[σ]]` of its Schreier subshift
  `𝒲`. Along a regular orbital line `ζ, 1−ζ, ζ−1, 2−ζ, …`, the `b`-edges carry one constant label. The
  `a`-edge between `(k+1) − ζ` and `ζ − k − 1` carries the piece of `ζ − k − 1`, that is
  `v_3(ζ − 1 − k) = v_3(k + (1 − ζ))` mod 3. So the `a`-labels form the point of `T_3` with parameter
`1 − ζ`. So `𝒲` is
  the height-2 tower over `(T_3, σ)`. It is minimal, hence equal to the orbit closure used there.
- *Realising the tower in nV.* Conjugate `g` by the prefix map `x_1 ↦ 0x_1`, so that
  `A ⊆ [0] × C^{n−1}`, and let `κ` be the prefix swap `0 ↔ 1` in the first coordinate. Define `g'` to be
  `κ` on `A`, `g ∘ κ^{-1}` on `κ(A)`, and the identity elsewhere. Then `g' ∈ nV`, and `I` induces a factor
  map from `(A ⊔ κA, g')` onto `𝒲`.
- *Conclusion.* `𝒲` is infinite and minimal, hence aperiodic. `aperiodic-full-groups-lift-along-factor-maps`
  gives `G ≤ [[σ_𝒲]] ↪ [[g'|_{A ⊔ κA}]]`, and `brin-thompson-groups-contain-full-groups-of-their-elements`
  puts the latter in `nV`.

Direct proof (2026-09-12, lane `bh-char0-linear-reduction`).
- **Sources.** The Stacks Project tags below were read from `algebra.tex` and the
  `tags` file, fetched on MSI. Quillen's Theorem 4 was read from the journal PDF.
- **Setup.** Let `Γ <= GL_N(K)` be generated by `γ_1, ..., γ_g`, with `char K = 0`.

1. **Restriction of scalars.**
   - **The field.** Let `K_0 ⊂ K` be the field generated over `Q` by the entries of
     all `γ_i` and `γ_i^-1`. It is finitely generated over `Q`, so it has a
     transcendence basis `t_1, ..., t_k`, and `d = [K_0 : Q(t)]` is finite.
   - **The blocks.** Fix a `Q(t)`-basis of `K_0`. Left multiplication is an
     injective unital ring homomorphism `φ : K_0 -> M_d(Q(t))`.
   - **The matrices.** Applied entrywise, `φ` is an injective unital ring
     homomorphism `M_N(K_0) -> M_(Nd)(Q(t))`, because
     `φ(Σ_k a_ik b_kj) = Σ_k φ(a_ik) φ(b_kj)`. So `Γ` embeds in `GL_(Nd)(Q(t))`.

2. **Denominators.**
   - **The ring.** Let `f ∈ Z[t] \ 0` be a common denominator of the finitely many
     entries of the images of the `γ_i^(±1)`, and put `A = Z[t][1/f] ⊂ Q(t)`.
   - **The embedding.** Those images lie in `M_(Nd)(A)` and are inverse to each
     other, so `Γ` embeds in `GL_(Nd)(A)`.
   - **A presentation.** `A = Z[t, u]/(g)` with `g = u f - 1`. It is a domain with
     fraction field `Q(t)`.

3. **Nagata normalization over `Z`.** This is a direct proof; Stacks 07NA is the
   general form.
   - **Weights.** Write `f = Σ_a c_a t^a`.
     - Pick an integer `D >= 2` larger than every exponent `a_i` with `c_a ≠ 0`.
     - Give the monomial `u t^a` the weight `w(a) = 1 + Σ_i a_i D^i`. Different
       `a` have different base-`D` digits, so they have different weights.
     - Let `a*` have the largest weight among the `a` with `c_a ≠ 0`. Put
       `W = w(a*)` and `c = c_(a*) ∈ Z \ 0`.
   - **Substitution.** Put `s_i = t_i - u^(D^i)` in `A`.
     - Each `u t^a = u Π_i (s_i + u^(D^i))^(a_i)` is a polynomial in `u` over
       `Z[s]` of degree `w(a)`, with leading coefficient `1`.
     - The constant `-1` of `g` has degree `0 < W`. So in `A`

       ```text
       0 = g = c u^W + Σ_(j<W) h_j(s) u^j,   h_j ∈ Z[s_1, ..., s_k].
       ```

   - **Finiteness.** Put `A' = A[1/c]` and `P = Z[1/c][s_1, ..., s_k]`, mapping to
     `A'` by `s_i -> t_i - u^(D^i)`.
     - Since `t_i = s_i + u^(D^i)`, we have `A' = P[u]`.
     - Dividing the relation by `c` makes `u` integral over `P`, of degree `W`.
     - So `A'` is generated as a `P`-module by `1, u, ..., u^(W-1)`.
   - **Injectivity.** `Q(t) = Frac(A')` is algebraic over the subfield generated by
     the images of `s_1, ..., s_k`. So those `k` elements have transcendence degree
     `k` and are algebraically independent. So `P -> A'` is injective, and we
     regard `P ⊂ A'`.

4. **`A'` is finite projective over `P`.** Both rings are finitely generated
   `Z`-algebras, so both are Noetherian. Fix a prime `q` of `A'` and put `p = q ∩ P`.
   - **Regularity.** `Z[t_1, ..., t_k]` is regular. Take a prime `Q` of it.
     - If `Q ∩ Z = 0`, then `Z[t]_Q` is a local ring of `Q[t]`, which is regular
       (00OQ, with the definition 00OD).
     - If `Q ∩ Z = (ℓ)`, then `Z_(ℓ) -> Z[t]_Q` is flat and local, with regular base.
       Its fiber is a local ring of `F_ℓ[t]`, which is regular (00OQ). So `Z[t]_Q`
       is regular (031E).
     - `A'` is a localization of `Z[t]` and `P` of `Z[s]`, so every local ring of
       either is regular.
   - **Cohen--Macaulay.** `A'_q` is regular local, hence Cohen--Macaulay (00NQ).
   - **Normality.** `Z[1/c]` is a PID, hence a UFD (034V). So `P` is a UFD (0BC1),
     hence normal (0AFV).
   - **Dimension.**
     - `P ⊂ A'` is an integral extension of domains with `P` normal, so going down
       holds (00H8).
     - Since both rings are Noetherian, `dim A'_q = dim P_p + dim A'_q/pA'_q`
       (00ON).
     - The fiber `A'_q/pA'_q` is a localization of `A' ⊗_P κ(p)`. That is a
       finite-dimensional `κ(p)`-algebra, so all its primes are maximal.
     - So the fiber has dimension `0`, and `dim A'_q = dim P_p`.
   - **Miracle flatness.** `P_p -> A'_q` is a local homomorphism of Noetherian local
     rings, with `P_p` regular and `A'_q` Cohen--Macaulay. Since
     `m_(P_p) A'_q = p A'_q`, the dimension condition is the equality just proved.
     So `A'_q` is flat over `P_p` (00R4).
   - **Globally.** Flatness is local, so `A'` is flat over `P` (00HT). It is finite
     over the Noetherian ring `P`, hence finitely presented, hence finite projective
     (00NX).

5. **Freeness.**
   - **Quillen's theorem.** D. Quillen, *Projective modules over polynomial rings*,
     Invent. Math. 36 (1976), 167--171, Theorem 4: "If `k` is a principal ideal
     domain, then any finitely generated projective `k[T_1,...,T_n]`-module `M` is
     free."
   - **Here.** Take `k = Z[1/c]`. Then `A' ≅ P^r`, where `r = [Q(t) : Q(s)]` is the
     rank of `A' ⊗_P Frac(P) = Frac(A')`. Suslin proved the same theorem
     independently (Quillen's note added in proof).
   - **Without Quillen.** `A' ⊕ L ≅ P^R` for some finite projective `L`. Then
     `x -> x ⊕ 1` embeds `Aut_P(A'^(Nd))` in `Aut_P(A'^(Nd) ⊕ L^(Nd)) ≅ GL_(NdR)(P)`.
     The claim still holds, with `M = NdR`.

6. **Embedding.**
   - **The blocks.** Choose a `P`-basis `e_1, ..., e_r` of `A'`. Multiplication by
     `a ∈ A'` has a matrix `ψ(a) ∈ M_r(P)`, and `ψ` is an injective unital ring
     homomorphism.
   - **The composite.** Applying `ψ` entrywise, as in step 1, gives an injection

     ```text
     Γ <= GL_(Nd)(A) <= GL_(Nd)(A') -> GL_(Ndr)(Z[1/c][s_1, ..., s_k]).
     ```

   - **The numbers.** So the claim holds with `m = c` and `M = Ndr`. ∎

**Worked examples.**
- **Laurent coordinates.**
  - **Recipe.** `A = Z[t][1/t]`, so `f = t`, `D = 2` and `u = 1/t`. The substitution
    `s = t - t^-2` gives `u^3 + s u - 1 = 0`, with `c = 1`. So `Z[t^(+-1)]` is free
    over `Z[s]` with basis `1, u, u^2`, and `r = 3 = [Q(t) : Q(s)]`, since
    `s = (t^3 - 1)/t^2`.
  - **Better choice.** The symmetric choice `s = t + t^-1` gives rank `2`, with
    basis `1, t` (worked in the claim). So `SL_3(Z[t^(+-1)]) <= SL_6(Z[s])`.
- **Baumslag's ring.** `R = Z[x][1/(x + x^2)]`, so `D = 3`, `u = 1/(x + x^2)` and
  `s' = x - u^3`.
  - **Relation.** `u^7 + (1 + 2s')u^4 + (s' + s'^2)u - 1 = 0`, so `R` is free over
    `Z[s']` with basis `1, u, ..., u^6`.
  - **Consequence.** See `baumslag-char-zero-metabelian-group-satisfies-boone-higman`.

**ESTABLISHED NONZERO-ARM FINITE FENCE.**  Work in the finite coefficient
ring `E=M_3(F_2)` and write `E_rs` for its matrix units.  Set

```text
q   =E_11,
A_j =E_12,
A_i =E_11+E_12,
B_i =E_11,
D   =E_31,
C   =B_i+D=E_11+E_31,
a   =A_i+A_j=E_11.                                    (PAO1)
```

Every displayed arm is nonzero, including the private tag `D` and edge arm
`A_j`.  Direct multiplication gives the exact tagged table

```text
A_iB_i=q,       A_jB_i=0,
A_iD=A_jD=0,
aC=q,           A_jC=0.                               (PAO2)
```

Moreover `Ca=C` and `C^2=C`, so `(a,C)` is a partial inverse pair between
the corners `q` and `C`.  In `E_4(E)` define

```text
P=x_14(a)x_41(C)x_14(a),
R=x_14(A_j)x_41(C)x_14(A_j).                           (PAO3)
```

The word `P` is the genuine partial Whitehead for `(a,C)`.  Both `P` and
`R` contain the same nonzero private column before either coefficient
product is evaluated.  The A3 associator rows remain

```text
N(a,C)=x_14(q),               N(A_j,C)=1.              (PAO4)
```

All of `(PAO1)--(PAO4)` hold in the finite matrix group

```text
E_4(M_3(F_2)) <= GL_12(F_2).                           (PAO5)
```

The escape is already visible on the `(1,4)` coefficient block.  Direct
binary matrix multiplication gives

```text
P^2=R^2=1,                 (PR)^3=1,
P!=R,                      x_14(q)!=1.                 (PAO6)
```

Thus the two shared-private-arm Whiteheads close into a finite `S_3`
packet rather than forcing the mark to vanish.  Passing to the left regular
representation of the finite subgroup generated by the whole cell keeps
every displayed relation exact and gives

```text
||lambda(x_14(q))-1||_2=sqrt(2).                       (PAO7)
```

Consequently the first opposite-root cell in which the private address arm
appears before `aC=q`, and in which the edge arm is provably nonzero, still
does not supply a bounded-area chromatic decoder.  A successful next row
must use a full-Leavitt relation not valid in this finite coefficient
specialization—most naturally a second binary branch/completeness occurrence
which cannot be represented in any finite unital ring.  No Property `(T)`,
Kazhdan input, approximation theorem, trace hypothesis, or literature result
is used.

## Attempts

- **Compare the diagonal and edge Whiteheads directly.**  They are distinct,
  but their product has order three in `(PAO6)`; no mark collapse follows.
- **Prevent the old zero-arm specialization.**  This succeeds—`A_j,C,D`
  are all nonzero—but only enlarges the exact finite packet from the output
  `GL_4(F_2)` cell to a matrix group over `M_3(F_2)`.

**ESTABLISHED.** Let `k` be any field and `M = prod_omega M_(n_i)(k)` modulo rank-null
sequences, with rank function `rk`. Let `Gamma = <S>` be finitely generated, let `G` be
generated by elements of `P_Gamma = { g : g Gamma g^-1 <= Gamma }`, and let
`sigma : G -> M^x` be a homomorphism.

* **Free rounding.** `Fix_r(sigma(Gamma)) = eM` for an idempotent `e` with image the exact
  fixed subspaces of the generator matrices, and
  `rk((1-e)x) <= sum_(s in S) rk((sigma(s)-1)x)` for all `x` in `M`.
* **Conservation.** `sigma(G)` preserves `eM`, and every element of `<<Gamma>>_G` fixes
  it pointwise, so `Fix_r(sigma(Gamma)) = Fix_r(sigma(<<Gamma>>_G))`.
* **Every tensor degree.** The same holds for
  `sigma^(a,b) = sigma^(tensor a) (x) (sigma^(-T))^(tensor b)` in the rank ultraproduct at
  scale `n_i^(a+b)`. In degree `(1,1)` this is the linear-scale part of the commutant of
  `sigma(Gamma)`.

No property (T) is assumed. The proof is dimension counting: a compressor carries the
exact fixed subspace onto the fixed subspace of the conjugated generators, which contains
the original up to `o(n)` dimensions and has the same dimension (artifact Section 1).

In the language of Theorem 10 of the ladder artifact, (A1)-(A3) hold for fixed right
ideals with size `rk`, and (A4) fails. So the layer is too coarse to kill defects
(`linear-scale-rank-conservation-does-not-kill-defects`).

**1.** By `sl3-toeplitz-harmonic-ring-is-simple-and-k1-rational`:
- `R_T` is a unital subring of `C(X, Q) ⋊_alg Γ`, with `X` an infinite minimal subshift and
  `Γ = SL_3(Z)`;
- `LC(X, Z) ⊆ R_T` (part 1), so `R_T` contains every clopen indicator;
- `R_T` is a simple ring (part 2).

So `clopen-crossed-product-subrings-have-local-annihilation` applies, and `R_T` has local annihilation.
`local-annihilation-makes-projective-el-simple` (hypotheses `N >= 3`, a simple ring, local annihilation)
gives that every normal subgroup of `E_N(R_T)` is central or everything, and that `PE_N(R_T)` is simple.

It is infinite. `e_12(a) ↦ [e_12(a)]` is injective on `R_T`, because `[e_12(a-b), e_23(1)] = e_13(a-b)`
is trivial only for `a = b`. And `R_T ⊇ Q` is infinite.

**2.** By `q-algebra-elementary-quotients-contain-gl-n-q`, part 2, `Z(E_N(R_T)) = E_N(R_T) ∩ Z(R_T)^x I`.
- `Z(R_T) = Q` by part 2 of the ring node, so `Z(E_N(R_T)) = Λ_N(R_T)·I`.
- Part 3 of the ring node gives `Λ_N(R_T) ⊆ {±1}`.

**3.** `R_T` is finitely generated, so `E_N(R_T)` is too. For `N >= 3` it is generated by the `e_ij(g)`
with `g` in a finite generating set of the ring together with `1`, through
`[e_il(a), e_lj(b)] = e_ij(ab)` and additivity. Let `C = Z(E_N(R_T))`, which is finite.
- If `E_N(R_T)` is finitely presented, then so is `E_N(R_T)/C`: add the at most one extra relator.
- If `E_N(R_T)/C` is finitely presented, then `fg-central-extension-of-fp-group-is-fp` makes
  `E_N(R_T)` finitely presented.

**4.** `q-algebra-elementary-quotients-contain-gl-n-q`, part 4, since `Q ⊆ R_T`. ∎

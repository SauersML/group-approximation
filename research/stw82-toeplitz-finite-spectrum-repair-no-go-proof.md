## Step 1: place the Toeplitz obstruction in multiplier-projection form

Let `S` be the unilateral shift, `e=1-SS^*`, and use the algebras from the
claim.  The element `p=e tensor 1` is a projection of `M(A)` but not of `A`.
Since the ideal generated by `e` in `T` is `K(H)`,

```text
closure(ApA)=K(H) tensor K(H)=L.                         (FSPN1)
```

The ideal `L` is proper because `A/L=C(T) tensor K(H)`, and it is essential
because `K(H)` is essential in `T`; equivalently, the represented algebra
`A` contains `K(H tensor H)` as an essential ideal.  Thus `L` is not
complemented.  It is stable AF and has real rank zero.  The projection `p`
is nonfull by `(FSPN1)` and noncentral because `e` does not commute with
`S`.

Put `K=A+C p` and `J=L+C p`.  Then `J` is the ideal generated by `p` in
`K`, and quotienting gives `(FSN2)` with quotient `C(T) tensor K(H)`.

## Step 2: construct finite-spectrum positive quasicentral cuts

In the standard basis `(delta_j)_(j>=0)`, define the diagonal contraction
`a_n` by

```text
a_n delta_j = delta_j                         for 0<=j<n,
a_n delta_(n+k) = (1-k/n) delta_(n+k)         for 0<=k<n,
a_n delta_j = 0                               for j>=2n.
```

Repeated endpoint values are harmless.  The spectrum is finite and

```text
norm([a_n,S])<=1/n.                                      (FSPN2)
```

Moreover `(a_n)` is an approximate unit for `K(H)`.  Let `Q_n` be the
initial rank-`n` projection on the second copy of `H` and set `h_n` as in
`(FSN3)`.  Then `(h_n)` is an approximate unit for `L`, consists of finite-
spectrum positive contractions, and commutes with `p=e tensor 1` because
every `a_n` is diagonal.

It is quasicentral in `A=T tensor K(H)`.  Indeed, for elementary tensors,

```text
[h_n,x tensor k]
 =[a_n,x] tensor Q_n k + x a_n tensor [Q_n,k].           (FSPN3)
```

The first term tends to zero for `x=S` by `(FSPN2)`, hence for every
`x in T` by generation and approximation.  The second tends to zero for
every compact `k`.  Density proves `(FSN1)`.

The same cancellation as in the support-thickening theorem shows that

```text
g_n=p+(1-p)h_n
```

is a positive quasicentral approximate unit for `J` in `K`: it fixes `p`,
approximates `L`, and

```text
[g_n,a]=(1-p)[h_n,a]+[p,a](1-h_n)->0.
```

Its spectrum is finite because `p` commutes with `h_n`.  Thus even positive
finite-spectrum cuts for the actual extension ideal do not imply a
projectional repair.

## Step 3: every literal spectral repair loses quasicentrality maximally

Fix `t in (0,1]`.  Whenever

```text
r_(n,t)=chi_[t,1](h_n)
```

is nonzero, monotonicity of the diagonal entries gives

```text
r_(n,t)=P_(n,t) tensor Q_n,                              (FSPN4)
```

where `P_(n,t)` is a nonzero finite initial-coordinate projection.  For all
`n` with `e<=Q_n`,

```text
norm([r_(n,t),S tensor e])
 =norm([P_(n,t),S])=1.                                  (FSPN5)
```

Any sequence of such cuts which approximates `L` is eventually nonzero, so
`(FSPN5)` excludes quasicentrality.  Notice the quantitative sharpness:
the original commutator in `(FSPN2)` tends to zero, while the cutoff
commutator is exactly one.  The stagewise spectral gaps shrink at the same
scale as the taper, so finite spectrum by itself supplies no uniform
functional-calculus control.

## Step 4: the index boundary excludes every alternative projectional cut

The inclusion of the stabilized Toeplitz extension into `(FSN2)` gives a
commuting morphism of extensions

```text
0 -> L -> A -> C(T) tensor K(H) -> 0
|    |    |            identity
0 -> J -> K -> C(T) tensor K(H) -> 0.
```

For the upper extension, the index map sends the standard generator of
`K_1(C(T) tensor K(H))` to `+-[e tensor e]`, the nonzero generator of
`K_0(L)`.  Naturality sends this class to its image in `K_0(J)` for the
lower extension.

That image remains nonzero.  Indeed,

```text
0 -> L -> J -> C -> 0                                   (FSPN6)
```

has zero incoming boundary group `K_1(C)=0`, so exactness makes
`K_0(L)->K_0(J)` injective.  Therefore the index boundary of `(FSN2)` is
nonzero.

A quasidiagonal extension has zero index boundary: compression by a
quasicentral approximate unit of projections gives finite-corner lifts and
forces the boundary class of every quotient unitary to vanish.  Hence
`(FSN2)` is not quasidiagonal.  By
`stw82-raw-two-cut-reuse-iff-quasidiagonal`, no alternative projectional
quasicentral repair exists.  This proves that the obstruction in `(FSPN5)`
reflects the extension class rather than a poor choice of taper.

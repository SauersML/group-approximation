Standard facts about an action without inversions of a group on a tree `T`
(Serre, *Trees*, §I.6; Culler--Morgan, *Group actions on R-trees*, §1):

- **(F1) Translation length.** `ℓ(g) = min_x d(x, gx)` is conjugation invariant,
  and `ℓ(g^k) = |k| ℓ(g)`. `g` is elliptic, meaning it fixes a vertex, iff
  `ℓ(g) = 0`.
- **(F2) Fixed-point projection.** If a subgroup `N` fixes a vertex and
  `g normalizes N` with `g` elliptic, then `g` fixes a vertex of the subtree
  `Fix(N)`: `g` preserves `Fix(N)`, and the nearest-point projection of a fixed
  point of `g` onto `Fix(N)` is fixed.
- **(F3) Busemann homomorphism.** The stabilizer of an end `ξ` carries a
  homomorphism `β_ξ` to `Z`, whose kernel consists exactly of the elements
  fixing a subray to `ξ` pointwise. Such elements are elliptic.
- **(F4) All elements elliptic.** A finitely generated group all of whose
  elements are elliptic fixes a vertex (Serre, §I.6.5, Corollary 3).

## Item 1

**The generators are elliptic.** In `BG_n`, `a` is conjugate to `a^n` by `b`.
By (F1), `ℓ(a) = n ℓ(a)`, so `ℓ(a) = 0` and `a` is elliptic. `b = t a t^-1` is
conjugate to `a`, so it is elliptic too.

**The lamp subgroup.** Let `a_j = b^-j a b^j` for `j >= 0`. Since
`b a b^-1 = a^n`, we have `a_j = a_(j+1)^n`, so `<a_0> <= <a_1> <= ...`. Their
union `N` is the normal closure of `a` in `B`, a copy of `Z[1/n]`. Each `a_j` is
conjugate to `a`, hence elliptic. The fixed subtrees `T_j = Fix(a_j)` are
nonempty and decreasing, and `b T_j = Fix(b a_j b^-1) = T_(j-1)` for `j >= 1`.

**Case A: `∩_j T_j` is nonempty.** Then `N` fixes a vertex. `b` normalizes `N`
and is elliptic, so by (F2) it fixes a vertex `v` of `Fix(N)`. Then `B = N<b>`
fixes `v`.

**Case B: `∩_j T_j` is empty.**
- *A common end.* Fix a vertex `x` and let `p_j` be its projection to `T_j`.
  Because the `T_j` decrease, the geodesic `[x, p_(j+1)]` passes through `p_j`,
  so the `p_j` lie on a ray, which converges to an end `ξ`. Each `a_j` fixes
  `p_i` for all `i >= j`, so it fixes a subray to `ξ` and `N` fixes `ξ`.
- *The end is unique.* Suppose an end `η != ξ` lay in the boundary of every
  `T_j`. Each `T_j` is closed and convex and has `ξ` and `η` as ends, so it
  contains the line `(ξ, η)`. Then `∩_j T_j ⊇ (ξ, η)`, a contradiction.
- *`b` fixes `ξ`.* `b` shifts the family `(T_j)` and so maps its unique common
  end to itself.
- *Every element is elliptic.* `b` is elliptic and fixes `ξ`, so `β_ξ(b) = 0` by
  (F3). Every `a_j` fixes a subray to `ξ`, so `β_ξ` vanishes on `N`. Hence
  `β_ξ = 0` on `B = N<b>`, and by (F3) every element of `B` is elliptic.
- *The contradiction.* `B` is generated by `a` and `b`, so by (F4) it fixes a
  vertex `v`. Then `N` fixes `v`, so `v ∈ ∩_j T_j`, contradicting Case B.

So Case A always holds, and `B` fixes a vertex.

## Item 2

Suppose `BG_n <= Γ` and `Γ` acts on a tree `T`. Let `T'` be the barycentric
subdivision; `Γ` acts on `T'` without inversions. By item 1, applied to the
restricted action, `B` fixes a vertex `v` of `T'`.

- **`v` is a vertex of `T`.** Then `B` lies in a vertex stabilizer of `Γ`.
- **`v` is the midpoint of an edge `e` of `T`.** The subgroup of `B` fixing `e`
  pointwise has index at most 2, so it contains `<a^2, b^2>`, and it fixes the
  endpoints of `e`. In `B = Z[1/n] ⋊ <b>`, with `a = 1` and `b` acting by
  multiplication by `n`, the subgroup `<a^2, b^2>` is `2Z[1/n] ⋊ <b^2>`, a copy
  of `BS(1, n^2)`.

Either way a copy of `BS(1,m)` with `m >= 2` lies in a vertex stabilizer of `Γ`
for `T`, contradicting the hypothesis.

## Item 3

For `Γ ∈ BS_G`, vertex stabilizers of the Bass--Serre tree are conjugates of
vertex groups, which are commensurable with `G`.
- **The stabilizers.** If `G` is virtually free, abelian or nilpotent, so is
  every vertex stabilizer, and so is every subgroup of one.
- **`BS(1,m)` is none of these,** for `m >= 2`. It has exponential growth, so
  it is not virtually nilpotent, and in particular not virtually abelian. It is
  not virtually free: it contains the abelian group `Z[1/m]`, which is not
  finitely generated, whereas every abelian subgroup of a virtually free group
  is virtually cyclic.

Item 2 applies. `∎`

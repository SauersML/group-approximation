## Proof

1. **Restricted extension.** `M` is the preimage of `N`, so `1 → <z> → M → N → 1` is central with
   class `res c = c|_N`.
2. **Five-term sequence (standard; Brown, *Cohomology of Groups*, VII.6).** For a central extension
   by `Z`:

   ```text
   H_2(M;Z) → H_2(N;Z) --∂--> Z → H_1(M;Z) → H_1(N;Z) → 0,
   ```

   where `∂` is, up to sign, evaluation of the extension class, `∂(x) = ±⟨c|_N, x⟩`. So the image of
   `Z` in `H_1(M;Z)` is `Z/⟨c|_N, H_2(N;Z)⟩`.
3. **Naturality of the pairing.** `⟨c|_N, x⟩ = ⟨i^* c, x⟩ = ⟨c, i_* x⟩`. So the image of `z` in
   `H_1(M;Z)` has order `[Z : c(i_*H_2(N;Z))] = e(N)`. This is item 1.
4. **Finiteness.** The transfer `tr : H_2(K;Z) → H_2(N;Z)` satisfies `i_* ∘ tr = [K:N]·id`. So
   `c(i_*H_2(N)) ⊇ [K:N]·c(H_2(K))`, which is a nonzero subgroup of `Z` when `c(H_2(K)) != 0`. Hence
   `e(N)` divides `[K:N]·[Z : c(H_2(K))]` and is finite.
5. **Lower bound for the supremum.** Let `N` have finite index. `H_1(M;Z)` is an abelian group in
   which `z` has finite order `e(N)`. `M` is finitely generated whenever `K~` is, so `H_1(M)` is
   finitely generated and some finite quotient `H_1(M) → A` keeps `z` at order `e(N)`. The kernel
   `M'` of `M → A` has finite index in `K~`. Its normal core `C` is a finite-index normal subgroup
   with `C <= M'`, and `z` has order at least `e(N)` in `K~/C`, because `<z> ∩ C <= <z> ∩ M' = <z^{e(N)}>`.
   Here `M` is finitely generated because it has finite index in `K~`, which is generated by `z`
   and lifts of generators of `K`.
6. **Upper bound for the supremum.** Let `θ : K~ → Q` be finite with `θ(z)` of order `n`. Put
   `M_0 = Ker θ`, `M = M_0·<z>` and `N = M/<z> <= K`, of finite index. `M/M_0 ≅ <θ(z)>` is cyclic of
   order `n` and generated by the image of `z`. The surjection `H_1(M;Z) → M/M_0` sends `z` to a
   generator, so `n` divides the order of `z` in `H_1(M)`, which is `e(N)` by item 1.
7. **Normal subgroups suffice.** If `N' <= N` has finite index then `i_*H_2(N') <= i_*H_2(N)`, so
   `e(N') >= e(N)`. The normal core of `N` in `K` is contained in `N` and has finite index.
8. **Scaling.** `(mc)(i_*H_2(N)) = m·c(i_*H_2(N))`, so the index is multiplied by `|m|`. ∎

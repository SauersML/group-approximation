Let `E` be any directed graph of maximum out-degree `d=o(L)` on the `L`
simplex coordinates.  Fix a nonconstant affine character difference `z`, so
its support `S` has size `L/2`, and fix one `(chi,psi)` matrix block with
`chi+psi=z`.  For every output row `i`, define an operator residual array by

```text
 b_(i,j)=X on the (chi,psi) block if j in S minus N_E(i),
 b_(i,j)=0 otherwise.                                    (SES1)
```

Every sampled entry on `E` is zero.  But the dense affine-simplex inverse is

```text
 T_i(b)=((|S minus N_E(i)|)/|S|)X,                       (SES2)
```

whose normalized operator row/column norm tends to `||X||`, while the
normalized input pair norm stays comparable to `||X||`.  Hence no decoder
which sees only the sampled entries can approximate the dense inverse on its
full operator-array domain, even when `E` is a spectral expander.

Therefore affine-geometry or expander sparsification cannot preserve
`affine-simplex-riesz-inverse-is-uniformly-cb` merely by restricting or
unbiasedly sampling its pair table.  A positive sparse theorem must prove a
new cb estimate **on the nonlinear/gradient range generated by actual
occurrence defects**, or add auxiliary constraints that force arbitrary
residual arrays into that range.  Classical edge expansion and the
exterior-square estimate do not provide this range restriction.

Notation is that of the target. In the order `<`, `t ≤ x` means that `t` left-divides `x`.

**1. Stripping.**
- **One junction.** A word `x^{-1}y` with `x`, `y` positive has a single factor `s^{-1}s′`, at the junction, so
  reversing is forced to act there.
- **One step.** Write `x = s x_1`, `y = s′ y_1`.
  - If `s = s′`, the factor cancels, and the step strips `t = s` from both.
  - If `s < s′`, then `R̂` gives `s′ = s C` with `C = C_{s,s′}`, and `s^{-1}s′ → C`. The new pair is
    `(x_1, C y_1) = (s^{-1}x, s^{-1}y)`.
  - The case `s > s′` is symmetric. Either way the output is again negative–positive.
- **Termination** holds by Dehornoy (arXiv:1204.3211, §4). Right-triangular presentations are complete (his
  Proposition 4.4), and O-type monoids have common right multiples, so reversing of `u^{-1}v` terminates.
- **The count.** At the end one word is empty, say `x = 1`. Then `t_1 ⋯ t_m = u` and `u ≤ v`, so the product is
  `min(u, v)`. The case `y = 1` is symmetric. `m` is the number of steps.

**2. Convex subgroups.**
- Let `C` be convex and `g ∈ P ∩ C`, with `g = s_1 ⋯ s_r` for letters `s_i`. The partial products lie in
  `[1, g] ⊆ C`, so each `s_i` lies in `C`.
- If `s ∈ S ∩ C` and `s′ < s` in `S`, then `1 < s′ < s` gives `s′ ∈ C`. So `S ∩ C` is an initial segment.
- `C = (P ∩ C) ∪ (P ∩ C)^{-1} ∪ {1}` is generated by `S ∩ C`.
- Convex subgroups form a chain, and distinct ones have distinct initial segments.

**3. Homomorphisms.**
- **The kernel is convex.** If `1 < h < k` and `φ(k) = 0`, then `φ(h) ≥ 0` and `φ(k) − φ(h) = φ(h^{-1}k) ≥ 0`, so
  `φ(h) = 0`.
- **The bound.** `Σ φ(t_i) = φ(min(u, v))`. Since `min(u, v)` is `u` or `v`, a word of length at most `n`, this is
  at most `n · max φ`. Each stripped letter outside the kernel contributes at least `min{φ(s) : φ(s) > 0}`.
- **Torus knots.** A homomorphism with `φ ≥ 0` on `{a, b}` and the relation `a = b(a^p b)^q` gives
  `φ(a)(1 − pq) = (q+1)φ(b)`. For `pq > 1` the left side is at most 0 and the right side at least 0, so
  `φ(b) = 0`, and then `φ(a) = 0`.

**4. The family `a = b a^k b`.**
- **The steps.** Here `C_{b,a} = a^k b` and `b < a`. There are four kinds of step:
  - a top `a` facing a top `b`: the `a` becomes `a^k b` and the `b` is deleted;
  - the mirror case;
  - `a^{-1}a` cancels;
  - `b^{-1}b` cancels.
- **Runs.** After an unequal step, the rewritten word still starts with `a`. So the next step is unequal in the
  same direction (the other word starts with `b`), or cancels `a^{-1}a`, or the process ends.
  - Unequal steps therefore form runs, each followed by a cancellation `a^{-1}a` or by the end.
  - A run deletes leading letters `b` of one word, so its length is at most the current number of `b`s.
- **Letter counts.** The number of `b`s is non-increasing: an unequal step deletes one and creates one. So
  `U ≤ B_0 (E_a + 1)`. The number of `a`s changes by `k − 1` per unequal step and by `−2` per cancellation
  `a^{-1}a`, and it stays nonnegative. So `E_a ≤ (A_0 + (k−1)U)/2`.
- **`k = 1`.** `E_a ≤ A_0/2`, so `U ≤ B_0(A_0/2 + 1)`. The total is at most
  `U + E_a + B_0/2 ≤ n²/8 + 2n`.
- **`k = 2`, `B_0 = 1`.** `E_a ≤ (A_0 + E_a + 1)/2` gives `E_a ≤ A_0 + 1`, so `U ≤ A_0 + 2` and the total is `O(n)`.
  `∎`

Items 1–4 are self-contained apart from Dehornoy's termination theorem, which is cited and was read at source.

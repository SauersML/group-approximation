Lane proof, elementary given the cited inputs.

1. **Normalize `ℓ = 1`.** The map `x ↦ x/ℓ` conjugates `V(Γ,Λ,ℓ)` onto `V(ℓ^{-1}Γ, Λ, 1)`: slopes are
   unchanged, and breakpoints move from `Γ` to `ℓ^{-1}Γ`, which is again a `Λ`-invariant `Z·Λ`-module. It now
   contains `1`. So assume `ℓ = 1` and `1 ∈ Γ`.
2. **An interval exchange subgroup.** Let `γ ∈ Γ` be irrational (rational reals are computable). Put
   `α = γ − ⌊γ⌋ ∈ (0,1)`. Then `α ∈ Γ`, because `1 ∈ Γ`, so `Γ_α := Z + Zα ⊆ Γ`. Let `IE(Γ_α)` be the group of
   right-continuous bijections of `[0,1)` that are translations by elements of `Γ_α` on finitely many
   intervals with endpoints in `Γ_α`. Its elements have slope `1 ∈ Λ` and breakpoints in `Γ`, so
   `IE(Γ_α) ≤ V(Γ,Λ,1)`. This is also Tanner's Zappa--Szép decomposition `V = F ⋈ IE`, loc. cit. Hence
   `IE(Γ_α)' ≤ D(V(Γ,Λ,1))`.
3. **It is a Sturmian full group.** Let `S_α` be `[0,1)` with every point of `Γ_α mod 1` doubled, and
   `R_α` the rotation `x ↦ x + α mod 1`.
   - `(S_α, R_α)` is a Cantor minimal system, since orbits are dense.
   - The clopen partition `{[0,1−α), [1−α,1)}` generates: the cylinders of length `2n+1` are intervals cut
     at the points `−tα mod 1`, `|t| ≤ n`, which become dense. So the coding is a conjugacy onto the Sturmian
     subshift `X_α` of `continuum-many-infinite-minimal-binary-subshifts`.
   - A homeomorphism of `S_α` is locally a power of `R_α` exactly when it is a translation by `kα + m` on
     each piece of a finite partition of `S_α` into clopen intervals. Clopen intervals have endpoints in
     `Γ_α mod 1`. So the topological full group `G_T` of `X_α` is isomorphic to `IE(Γ_α)`, and
     `G_T' ≅ IE(Γ_α)'`.
   - `G_T'` is finitely generated (Matui; Grigorchuk--Medynets Theorem 1.1(1)).
4. **Decide the language.** By hypothesis the finitely generated group `G_T' ≅ IE(Γ_α)' ≤ D(V)` has
   solvable word problem. By `full-group-word-problem-iff-recursive-language` (Grigorchuk--Medynets, Theorem
   1.1(3)), `L(X_α)` is recursive. By `sturmian-language-is-turing-equivalent-to-angle`, `α` is computable.
   So `γ = α + ⌊γ⌋` is computable. This proves item 1.
5. **Item 2.** Take `Γ = Z[λ,λ^{-1}]`, `Λ = ⟨λ⟩`, `ℓ = 1`.
   - `Γ ⋊ Λ` is generated by the translation by `1` and the scaling by `λ`, since conjugating the first by
     powers of the second gives the translations by `λ^k`. So `D(V_λ)` is 2-generated and simple by
     Tanner's theorem.
   - It is infinite, since it contains `IE(Z+Zλ)'`.
   - If `D(V_λ)` had solvable word problem, so would its finitely generated subgroups, and item 1 would make
     `λ` computable.
   - A finitely presented simple group has solvable word problem (Kuznetsov), and so do the finitely
     generated subgroups of one (`simple-envelope-forces-solvable-word-problem`).
   - Only countably many reals are computable. ∎

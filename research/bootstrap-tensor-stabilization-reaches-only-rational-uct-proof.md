**Facts used.**

- **(F1) UCT sequence.** If `D` is separable and in the bootstrap class, then
  for every separable `B` there is a natural short exact sequence
  `0 -> Ext^1(K_*(D), K_{*+1}(B)) -> KK_*(D, B) -> Hom(K_*(D), K_*(B)) -> 0`.
  The second map sends a class to its induced map on K-theory, and this is
  compatible with Kasparov products (Rosenberg--Schochet).
- **(F2) Characterisation of the UCT class.** A separable `D` is
  KK-equivalent to a commutative algebra iff `KK_*(D, B) = 0` for every
  separable `B` with `K_*(B) = 0` (Rosenberg--Schochet; Meyer--Nest, the
  bootstrap class is the localizing subcategory generated by `C`, and its
  orthogonal is the K-contractible algebras).
- **(F3) Exterior tensor functor.** For separable `A` there is a functor
  `tau_A : KK(D, E) -> KK(A ⊗ D, A ⊗ E)` compatible with Kasparov products,
  with `tau_A(1_D) = 1_{A⊗D}` (Kasparov). Here `⊗` is the minimal tensor
  product, which agrees with the maximal one because `D, E` below are nuclear.
- **(F4)** `K_*(C ⊗ Q) = K_*(C) ⊗ Q` (continuity of K-theory along
  `C ⊗ M_{n!}`), and `K_*(Q) = (Q, 0)`.

**Step 1 (reduce to even degree).** If `K_0(C) ⊗ Q = 0`, then
`K_1(C) ⊗ Q ≠ 0`. Replace `C` by `SC`, which is in the bootstrap class with
`K_0(SC) = K_1(C)`. Then `A ⊗ SC = S(A ⊗ C)` satisfies the UCT iff `A ⊗ C`
does, by Bott periodicity in (F2). So assume `K_0(C) ⊗ Q ≠ 0`.

**Step 2 (Q is a KK-retract of C ⊗ Q).** Pick a nonzero
`v ∈ K_0(C) ⊗ Q = K_0(C ⊗ Q)`. Since `K_0(C) ⊗ Q` is a `Q`-vector space, there
is a `Q`-linear `f : K_0(C) ⊗ Q -> Q` with `f(v) = 1`.

- `Q` is in the bootstrap class. By (F1) there is `x ∈ KK(Q, C ⊗ Q)` whose
  K-theory map is `g : Q -> K_0(C ⊗ Q)`, `g(1) = v`.
- `C ⊗ Q` is in the bootstrap class, since the class is closed under tensor
  products with bootstrap algebras. By (F1) there is `y ∈ KK(C ⊗ Q, Q)`
  inducing `f` on `K_0` and `0` on `K_1`.

Then `z = x ⊗_{C⊗Q} y ∈ KK(Q, Q)` induces `f ∘ g = id` on `K_0(Q) = Q`.
The Ext term for `KK(Q, Q)` is
`Ext^1(K_0 Q, K_1 Q) ⊕ Ext^1(K_1 Q, K_0 Q) = Ext^1(Q, 0) ⊕ Ext^1(0, Q) = 0`.
So `KK(Q, Q) -> Hom(K_*(Q), K_*(Q))` is injective, and `z = 1_Q`.

**Step 3 (tensor the retract with A).** Apply (F3):
`X = tau_A(x) ∈ KK(A ⊗ Q, A ⊗ C ⊗ Q)` and
`Y = tau_A(y) ∈ KK(A ⊗ C ⊗ Q, A ⊗ Q)` satisfy
`X ⊗ Y = tau_A(z) = 1_{A ⊗ Q}`.

**Step 4 (A ⊗ C ⊗ Q satisfies the UCT).** Let `w ∈ KK(A ⊗ C, P)` be a
KK-equivalence with `P` commutative. Then `tau_Q(w)` is a KK-equivalence
`A ⊗ C ⊗ Q -> P ⊗ Q`. `P ⊗ Q` is an inductive limit of `M_{n!}(P)`, hence in
the bootstrap class, hence KK-equivalent to a commutative algebra.

**Step 5 (conclude).** Let `B` be separable with `K_*(B) = 0`. The maps
`X ⊗ - : KK_*(A ⊗ C ⊗ Q, B) -> KK_*(A ⊗ Q, B)` and
`Y ⊗ - : KK_*(A ⊗ Q, B) -> KK_*(A ⊗ C ⊗ Q, B)` compose to the identity of
`KK_*(A ⊗ Q, B)`. So `KK_*(A ⊗ Q, B)` is a retract of
`KK_*(A ⊗ C ⊗ Q, B)`, which is `0` by Step 4 and (F2). By (F2), `A ⊗ Q`
satisfies the UCT.

**Corollary.** Let `(A, tau)` be separable exact with `tau` faithful, amenable
and not quasidiagonal. By Corollary 4 of
`exact-x1-reduces-to-q-stable-algebras`, `A ⊗ Q` fails the UCT. Suppose
`C` is bootstrap with `K_*(C) ⊗ Q ≠ 0`. If `A ⊗ C` satisfied the UCT, the
Theorem would force `A ⊗ Q` to satisfy it, a contradiction.

If `C` has a tracial state `sigma`, it induces a homomorphism
`K_0(C) -> R`. When `C` is unital, `[1]` maps to `1`. In general, the class
of a projection `p` with `sigma(p) > 0` maps to `sigma(p) > 0`. So
`K_0(C) ⊗ Q ≠ 0` as soon as `C` has a projection with nonzero trace. That
is exactly what the pullback step of the reduction needs, since a unital
`C` is used there.

**Where the argument stops.** Step 2 uses the bootstrap property of `C` to
produce the functional `y`. For a non-bootstrap exact `C`,
`KK(C ⊗ Q, Q) -> Hom(K_0(C) ⊗ Q, Q)` need not be surjective. So the
Theorem says nothing about non-bootstrap `C`.

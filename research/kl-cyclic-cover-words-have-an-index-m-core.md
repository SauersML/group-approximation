Let `G` be a group, `m >= 1`, `F = G * <t>`, `G_i = t^i G t^(-i)`, and
`P = <G_0, ..., G_(m-1)> = G_0 * ... * G_(m-1)`.  For `C in P` put
`w = C t^m`, `H = F/<<w>>`, and let `D` be the image of `P` in `H`.

1. In `H`, `t` commutes with `C`, `t D t^(-1) = D`, and `D` is the kernel of
   the degree map `H -> C_m`.  So `D = Q_w`, and `G -> H` is injective iff
   `G_0 -> D` is.
2. `D = P/<<R_1, ..., R_(m-1)>>`, where `R_i = rho_i(C) C^(-1)` and `rho_i`
   is the homomorphism `P -> P` sending the copy `g_j` to `g_(j+i)` if
   `j + i < m`, and to `C^(-1) g_(j+i-m) C` otherwise.
3. If `m = 1`, `G -> H` is injective.
4. For `m = 2` and `C = a_1 b_1' ... a_K b_K'` (`a_i in G_0`, `b_i' in G_1`),
   the word is `w = a_1 t b_1 t^(-1) a_2 t ... t^(-1) a_K t b_K t`, of
   variable length `2K`, and `D` is the one-relator product
   `(G_0 * G_1)/<<R>>` with

   ```text
   R = a_1' C^(-1) b_1 C a_2' C^(-1) b_2 C ... a_K' C^(-1) b_K,
   ```

   of cyclically reduced free-product length `4K^2 - 4K + 2` when every
   `a_i, b_i` is nontrivial and `a_1 != b_K`.

The cyclic sign patterns of the `m = 2` window words are exactly the
`+-`-alternating patterns with a single `++`.  At length six this is the class
`+++-+-` of `length-five-kl-fence-for-leavitt-equations`, which had not been
examined.  The positive window shape `c_0 t c_1 t ... c_(m-1) t` is covered by
the positive-equation theorem of Levin, which that node cites in prose; it is
not used here.

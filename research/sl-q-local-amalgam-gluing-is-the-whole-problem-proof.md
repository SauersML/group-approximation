**Input (Steinberg).** For a field `F` and `m >= 3`, `SL_m(F)` is presented by
generators `x_ij(t)` (`i != j`, `t in F`) and the relations
- (R1) `x_ij(s) x_ij(t) = x_ij(s + t)`;
- (R2) `[x_ij(s), x_jk(t)] = x_ik(st)` for distinct `i, j, k`;
- (R3) `[x_ij(s), x_kl(t)] = 1` for `j != k`, `i != l`;
- (R4) `h_ij(t) h_ij(u) = h_ij(tu)` for `t, u in F^x`, where
  `w_ij(t) = x_ij(t) x_ji(-t^-1) x_ij(t)` and `h_ij(t) = w_ij(t) w_ij(1)^-1`.

(R1)--(R3) define `St_m(F)`; that (R4) generates the kernel of
`St_m(F) -> SL_m(F)` for a field is Steinberg's theorem (R. Steinberg,
*Lectures on Chevalley Groups*, §6, Theorem 8; equivalently Matsumoto's
description of unstable `K_2` of a field by symbols for non-symplectic root
systems; theorem numbers not re-checked at the source).

**(1).** Let `C` be the colimit of `𝒜_m` and `c : C -> SL_m(Q)` the canonical map.
Each `SL_I(Q)` is generated by its elementary matrices (over a field), and all
copies of `x_ij(t)` are identified in `C` through `SL_{ij}(Q)`, so `C` is
generated by the images `ξ_ij(t)` of the `x_ij(t)`. Each of (R1)--(R4) involves
generators whose indices lie in a set `I` with `|I| <= 4` ((R3) uses up to four
indices, (R2) three, (R1) and (R4) two), and it holds in `SL_I(Q)`, hence in
`C`. So `x_ij(t) ↦ ξ_ij(t)` defines a homomorphism `s : SL_m(Q) -> C`, onto
because the `ξ_ij(t)` generate. `c ∘ s` fixes every `x_ij(t)`, so `c ∘ s = id`
and `s` is injective. Hence `s` is an isomorphism and `c = s^-1`.

**(2)** is the universal property of the colimit. **(3):** for odd `m`,
`SL_m(Q)` is simple (`gl-n-q-root-needs-only-nontrivial-psl-maps`), so the
homomorphism of (2) is injective iff it is nontrivial, iff some `φ_I` is
nontrivial (the `SL_I(Q)` generate).

**Curvature remark.** In `SL_4(Q)`, `diag(t, t^-1, 1, 1)` in the root `SL_2` on
`{1,2}` and `diag(1, 1, u, u^-1)` in the root `SL_2` on `{3,4}` commute, and so
do the diagonal subgroups of the root groups on `{1,2}` and `{2,3}`
(`diag(t, t^-1, 1, 1)` and `diag(1, u, u^-1, 1)`). A commutation `a b a^-1 b^-1 = 1`
with `a, b` nontrivial in two edge groups is a 4-cycle in the vertex link, and it
persists in any group containing that vertex group. The two edge groups meet
trivially, so there is no 2-cycle; the girth is 4.

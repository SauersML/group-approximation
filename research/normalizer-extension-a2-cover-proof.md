Notation as in the target.

**Action.** Each `φ(w)` normalizes `Γ`, so `θ_w in Aut(Γ)`, and `θ` is a
homomorphism because `φ` is. The map `Π(γ, w) = γ φ(w)` is a homomorphism
`G~ -> Sym(Ω)`:

```text
Π((γ,w)(γ',w')) = γ θ_w(γ') φ(ww') = γ φ(w) γ' φ(w)^-1 φ(w) φ(w') = Π(γ,w) Π(γ',w').
```

Its image is `ΓQ`. `Π(γ, w) = 1` means `φ(w) = γ^-1 in Γ`, which gives the
stated kernel. Projecting it to `F_m` is injective with image `φ^-1(Q ∩ Γ)`.

**Finite presentation of `G~`.** Take a finite presentation of `Γ` and the free
basis `a_1, ..., a_m` of `F_m`. Add the relators `a_i x a_i^-1 = θ_(a_i)(x)` for
the generators `x` of `Γ`, each right side written as a fixed word. This is a
finite presentation of the semidirect product.

**Orbits on pairs.** `Γ <= ΓQ`, so every `G~`-orbit on `Ω x Ω` is a union of
`Γ`-orbits, and there are finitely many.

**Stabilizers.** Fix `x in Ω`. The elements `φ(w)` permute the finitely many
`Γ`-orbits on `Ω`. The projection of `Stab_(G~)(x)` to `F_m` has image
`{w : φ(w) x in Γ x}`, which contains the kernel of that finite permutation
action on orbits. So it is of finite index in `F_m`, hence finitely generated.
The kernel of the projection is `Stab_Γ(x) x {1}`, finitely generated by
hypothesis. An extension of a finitely generated group by a finitely generated
group is finitely generated.

**Image.** `Γ` is finitely generated and normal in `ΓQ`, and
`ΓQ/Γ ≅ Q/(Q ∩ Γ)`. If `ΓQ` were finitely presented, its quotient by the normal
closure of finitely many elements would be finitely presented. That quotient is
`Q/(Q ∩ Γ)`. `∎`

Let the fixed game acceptance compressor be

```text
T_game(G)=sum_(s=1)^N beta_s U_s G V_s               (CAR1)
```

as in `finite-game-gap-makes-the-cyclic-acceptance-compressor-strict`.
Choose one fixed positive integer `D` clearing all rational coefficients
and all fixed context-atom denominators, and define

```text
C_acc
 =D[T_game(G)-G]
 =sum_s (D beta_s)U_sGV_s-DG.                         (CAR2)
```

This is a single coefficient in the finite bimodule/coefficient ring
generated by the game words and the Gram symbol `G`.

## Smallest Steinberg packaging

The acceptance return needs no orthogonal row amplification.  Name the one
Steinberg root

```text
g_acc=x_12(C_acc).                                    (CAR3)
```

If expanding `(CAR1)` is undesirable, introduce the fixed finite sequence
of intermediate coefficient symbols

```text
G_0=G,
G_j=(I-L_j)G_(j-1),
C_acc=D(G_m-G_0).                                     (CAR4)
```

After clearing the same denominators, `(CAR4)` uses only `O(m)` finite ring
relations.  It does not change the marked coefficient `(CAR2)` or add any
dimension-dependent syntax.

For comparison, the OHR coefficient satisfies

```text
m||R_Q||_2^2=sum_j||D_j||_2^2.                        (CAR5)
```

Here no such identity block is needed.  The game gap directly gives

```text
||C_acc||_2^2
 >=D^2 kappa^2||G||_2^2.                              (CAR6)
```

Thus, if `||G||_2^2>=gamma q-o(1)`, coefficient
authentication would give the desired marked-mass payment from one root.

## The remaining root theorem is still CRB8

Making `(CAR3)` a relator supplies only a group-ultraproduct equality.  The
needed qualitative implication is

```text
For every canonical matrix-microstate sequence U_n,
Phi(x_12(C_acc))=1
  implies C_acc(U_n)=0 in L^2 of the matrix ultraproduct. (CAR7)
```

This is exactly the one-coordinate kernel-reflection interface `(CRB8)`,
with `C_acc` in place of `R_Q`.  If `(CAR7)` holds, `(CAR6)` kills every
positive marked Gram mass.  Conversely, a canonical root word which is a
relator has distance `o(1)` automatically, so any one-root normalized-HS
estimate forces precisely the conclusion of `(CAR7)`.

The cyclic product structure does not prove `(CAR7)`.  Its positivity gives
the **lower** estimate `(CAR6)` after `C_acc` has been decoded.  It gives no
upper estimate relating that decoded coefficient to the distance of the
root word `(CAR3)`.

## Exact D8-tensored decoupling model

The countermodel behind `(CRB13)` persists with all acceptance factors exact.
Choose any finite-dimensional exact PVM/involution tables for the fixed game.
They need not win the game.  On their Gram Hilbert space the finite game gap
gives

```text
||(T_game-I)K||_2>=kappa||K||_2                       (CAR8)
```

for every matrix `K`.

Tensor this matrix model with the left regular representation of the D8
Pauli group

```text
E_1=<X,Z,J | X^2=Z^2=J^2=1, [X,Z]=J, J central>,      (CAR9)
```

and put

```text
Q=(I+X)/2,
G=Q tensor I_game.                                    (CAR10)
```

Let every game acceptance operator act trivially on the D8 factor.  Then all
PVM, involution, and acceptance-compressor identities are exact, while

```text
||G||_2^2=1/2,
||C_acc||_2^2>=D^2 kappa^2/2.                         (CAR11)
```

Independently tensor an exact left-regular finite row-root packet and all of
its named finite shear normalizers.  Designate an identity root coordinate,
so its word distance is exactly zero and every finite root/Plancherel table
is exact.  The root packet acts on a different tensor factor and leaves
`(CAR11)` unchanged.

Therefore

```text
exact finite game acceptance projections
+ exact cyclic product structure and its contraction
+ exact finite root tables and canonical Plancherel data
+ a root coordinate equal to identity

do not imply C_acc=0.                                  (CAR12)
```

As in `(CRB13)`, this is a countermodel to those proposed proof inputs, not a
microstate of the full Steinberg coefficient presentation.  It proves that
the acceptance compressor has not supplied the missing **mixed** relation
which places `(CAR2)` in the same root multiplicity reservoir as `(CAR3)`.

## Exact completeness and precise gain

In the perfect tracial/commuting model, take the standard Gram vector
`G=I`.  Every rejection projection kills it, so

```text
T_game(I)=I,
C_acc=0.                                               (CAR13)
```

Thus the coefficient relator is semantically compatible with the exact
perfect witness.  The group-level exact extension still requires the usual
finite ring/Steinberg realization, but no proper-corner tracial extension is
being demanded by `(CAR13)`.

The net comparison is:

- relative to OHR, `(CAR2)` removes the fixed `M_m` row amplification and
  replaces many covariance terms by one sequential coefficient;
- relative to arbitrary `R_Q`, positivity supplies the uniform lower bound
  `(CAR6)` automatically;
- relative to `(CRB8)`, there is **no gain**: one mixed same-reservoir
  root-kernel reflection theorem is still necessary and sufficient.

Accordingly the smallest remaining construction target in this lane is one
ordinary group/Steinberg two-cell proving `(CAR7)` for the single coefficient
`(CAR2)`.  More acceptance factors, finite root tables, or canonical trace
bookkeeping cannot replace that coupling.

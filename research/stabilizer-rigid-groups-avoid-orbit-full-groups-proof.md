Write `g` for `rho(g)` and discard a null set so that `Lambda` acts freely.

**Step 1: fixed-point characters.** For a `Gamma`-invariant Borel `A` with
`mu(A) > 0`, put `tau_A(g) = mu(Fix g ∩ A) / mu(A)`.
- `tau_A(1) = 1`.
- *Class function:* `Fix(h g h^-1) = h(Fix g)`, and `h` preserves `mu` and `A`.
- *Positive definite:* for `g_1, ..., g_r` and `c ∈ C^r`,

  ```text
  sum_(i,j) c_i conj(c_j) tau_A(g_j^-1 g_i) mu(A)
     = ∫_A sum_(y ∈ Gamma x) | sum_i c_i [g_i x = y] |^2 dmu(x) >= 0,
  ```

  because `g_j^-1 g_i x = x` iff `g_i x = g_j x`.

**Step 2: a trivial summand forces finite orbits.** Let
`R_A = {(y, x) : x ∈ A, y ∈ Gamma x}` with the measure
`nu(B) = ∫_A #{y : (y, x) ∈ B} dmu(x)`, and let `(pi(g) f)(y, x) = f(g^-1 y, x)`.
This is a unitary representation, and with `xi = mu(A)^(-1/2) 1_(diagonal)`,
`<pi(g) xi, xi> = tau_A(g)`.

Suppose `tau_A = s 1 + (1 - s) delta_1` with `s > 0`. The GNS representation of
this function is the cyclic subspace of `1 ⊕ lambda_Gamma` generated by
`v = (s^(1/2), (1-s)^(1/2) delta_1)`. If `s < 1`, it contains the differences
`(0, (1-s)^(1/2)(delta_g - delta_h))`, whose span is dense in `ell^2(Gamma)`
because `Gamma` is infinite; so it contains `(s^(1/2), 0)`. If `s = 1`, `v` itself
is invariant. Either way the GNS representation has a nonzero invariant vector.
By uniqueness of GNS, the cyclic subspace of `pi` generated by `xi` has one too:
a nonzero `eta` in `L^2(R_A, nu)` with `eta(g^-1 y, x) = eta(y, x)` almost
everywhere, for every `g`. As `Gamma` is countable and `nu` fibres over counting
measure, for almost every `x` in `A` the function `eta(., x)` is constant on the
orbit `Gamma x` and square-summable there. It is nonzero for a set of `x` of
positive measure, and each such orbit is finite. A finite orbit of an infinite
simple group is a fixed point, since the kernel of the action on it is a normal
subgroup of finite index. So `A` contains a set of positive measure of global
fixed points.

**Step 3: freeness off the fixed set.** Let `F = {x : g x = x for all g}` and
`Y = X \ F`, both Borel and invariant. If `mu(Y) = 0`, we are done. Otherwise
`tau_Y` is a character, so `tau_Y = phi_s` by (CR). Step 2 with `A = Y` would give
global fixed points inside `Y`, which is impossible, so `s = 0`. That is,
`mu(Fix g ∩ Y) = 0` for all `g != 1`: `Gamma` acts essentially freely on `Y`.

**Step 4: a free action inside an amenable orbit relation.** Put
`Z = {(x, lambda) ∈ X × Lambda : lambda x ∈ Y}`, `m = mu × counting`, and
`g.(x, lambda) = (x, c_g(lambda x) lambda)`. As in
`kazhdan-subgroups-amenable-orbit-full-groups-rf-proof`, Steps 2 and 3, this is
an `m`-preserving action, and the Følner indicators `xi_Q = 1_(Z ∩ (X × Q))` are
almost invariant for `pi(g) f = f(g^-1 . .)`. That computation used only
finiteness of the ranges of `c_g`; it holds for any finite set of group elements,
without property (T).

The action on `Z` is essentially free: `(x, lambda)` is fixed by `g` iff
`lambda x ∈ Fix g ∩ Y`, a set of measure `sum_lambda mu(lambda^-1 (Fix g ∩ Y)) = 0`.
Remove the invariant null set of points with nontrivial stabilizer. Enumerate
`Lambda = {lambda_1, lambda_2, ...}` and let `D` be the set of `(x, lambda)` in `Z`
with `lambda = lambda_i` for the least `i` such that `lambda_i x ∈ Gamma lambda x`.
`D` is Borel, meets each orbit exactly once, and freeness gives
`Z = ⊔_(g ∈ Gamma) g . D`. So

```text
L^2(Z, m) ≅ L^2(D, m) ⊗ ell^2(Gamma),      pi(g) ≅ id ⊗ lambda_Gamma(g).
```

Let `xi_n` be almost invariant unit vectors, and put
`f_n(h) = ||xi_n(., h)||_(L^2(D))`. Then `f_n` is a unit vector of `ell^2(Gamma)` and,
by the triangle inequality in `L^2(D)` followed by summation,
`||lambda_Gamma(g) f_n - f_n|| <= ||pi(g) xi_n - xi_n||`. So `lambda_Gamma` has almost
invariant vectors and `Gamma` is amenable (Hulanicki--Reiter), a contradiction.
Therefore `mu(Y) = 0`. ∎

**Instance V.**
- (CR) is `thompson-v-character-simplex`, and simplicity is
  `thompson-v-finitely-presented-infinite-simple`.
- *V is not amenable.* It acts continuously on `C = {0,1}^N` by prefix
  replacement. The element `00 -> 0, 01 -> 10, 1 -> 11` maps `[00]` onto `[0]`,
  and the element `0 <-> 1` swaps `[0]` and `[1]`. An invariant probability
  measure would give `mu[0] = mu[00]`, hence `mu[01] = 0` and `mu[0] = 0`, hence
  `mu[1] = 0` and `mu(C) = 0`. An amenable group acting on a compact space has an
  invariant probability measure, so `V` is not amenable.
- *Groups containing V.* If `V ≤ S` and `rho : S -> W(Lambda ~ X)` has
  `mu(Fix rho(g)) < 1` for all `g != 1`, then its restriction to `V` contradicts the
  theorem. For simple `S`, the kernel of `S -> Aut(X, mu)` is trivial or `S`, so a
  realization that is nontrivial on a set of positive measure has that property.
- *Topological full groups.* With full support, a nontrivial element of
  `[[Lambda ~ X]]` has `mu(Fix g) < 1`, so `V` is not a subgroup. ∎

**Hypothesis checks.**
- *Non-amenability cannot be dropped:* `Lambda` embeds in `W(Lambda ~ X)` with
  infinite orbits, and an infinite simple amenable group would realize itself
  through its Bernoulli shift.
- *(CR) cannot be dropped:* the Elek--Monod dynamical alternating group of
  `elek-monod-near-hit-has-torsion-no-kazhdan-subgroup` is infinite, simple and
  non-amenable, and it lies in `[[Z^2 ~ X]]` for a free minimal subshift with a
  full-support invariant measure. So it must fail (CR), and indeed its
  fixed-point character `g -> mu(Fix g)` is neither trivial nor regular.
- *Simplicity is used* only in Step 2 (finite orbits are fixed points).

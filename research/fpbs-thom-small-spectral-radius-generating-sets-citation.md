Citation import, not a reproof. A. Thom, arXiv:1306.1767v1, Theorem 1
(page 2): "Let Γ be a finitely generated non-amenable group and Σ be a finite
symmetric generating set. For every k ∈ N there exists a symmetric set
S_k ⊂ Σ^k such that ρ(S_k) ≤ 4k · ln(|Σ|) · ρ(Σ)^k. Moreover, for every ε > 0,
there exists a finite symmetric generating set S ⊂ Γ such that ρ(S) < ε."

Page 1 defines `m(S) := |S|^{-1} sum_{s ∈ S} s` and `ρ(S) := ||m(S)||`, the
operator norm in the left-regular representation, for a symmetric subset `S`
(`S^{-1} = S`). Juschenko–Nagnibeda, arXiv:1206.2183v3, list the paper as
reference [19] (page 12).

Read from the PDF on 2026-09-12. This route asserts only that the cited theorem
says what the target records.

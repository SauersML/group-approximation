Let `R=L_(F_2)(1,2)`, let `D` be a finite maximal binary prefix code with `|D|>=2`,
choose `d_0 in D`, and let `F<=Sym(D)` be a finite transitive subgroup
in the standard prefix-permutation copy.  For `n>=2`, put

```text
H=<D_n(F),e_12(s_(d_0)),e_21(t_(d_0))> <= EL_n(R),
D_n(f)=diag(f,1,...,1).                                 (MLO1)
```

If `m=|D|`, then

```text
H isomorphic to GL_(m+1)(F_2),                           (MLO2)
```

acting trivially on the last `n-2` module coordinates.  In particular, for
the transitive order-`3^5` qutrit packet on `D_27`, the first literal
matched Leavitt opposite-root bridge is exactly

```text
H isomorphic to GL_28(F_2).                              (MLO3)
```

The two opposite roots alone generate
`GL_2(F_2) isomorphic to S_3`.

For `n>=5`, the subgroup of `St_n(R)` generated by the lifted qutrit
packet and the two standard root lifts is central-by-finite, amenable, and
hyperlinear.  Hence arbitrary additive overlaps supported by this package
cannot complete a no-CE atlas.

This is stronger than finite coefficient closure.  The unital
`F_2`-algebra generated by `s_(d_0),t_(d_0)` is infinite-dimensional,
but the matched source/range module chart turns the root package into a finite
scalar matrix group.  The first surviving opposite-root bridge must break
this alignment: its return coefficient may not be the exact matched identity
`t_(d_0)s_(d_0)=1`, nor may all packet translates be simultaneous scalar
arrows in one finite module chart.

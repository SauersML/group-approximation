Notation is as in the target claim. `K_∞ = F_p((t^-1))`, `O = t^-1 F_p[[t^-1]]`, and `deg` is the
degree in `t`, with `deg 0 = −∞`. So `K_∞ = A ⊕ O`, and `deg x ≤ −1` for `x ∈ O`.

## Step 0: the dual as a quotient of K_∞^2

Put `ι(α) = Σ_(k≥0) α_k t^(-k-1) ∈ O`, and let `res` be the coefficient of `t^-1`. Then
`<a, α> = res(a·ι(α))` for `a ∈ A`. So `ζ = (x, y) = (ι α, ι β)` identifies `M^_+` with `O^2`.

For `γ ∈ SL_2(A)` and `m ∈ M_+`:
`<m, γ·ζ> = <γ^-1 m, ζ> = res(m^T (γ^-1)^T ζ)`.

Polynomial vectors have zero residue against `m`. So `γ·ζ = (γ^-1)^T ζ mod A^2`. On generators:
- `e_12(r)` acts by `(x, y) ↦ (x, y − r x)`;
- `e_21(s)` acts by `(x, y) ↦ (x − s y, y)`.

Let `U_N = {ζ : deg x, deg y ≤ −N − 1}`. These sets form a neighbourhood basis of `0`, and `U_N`
is the set `{α_k = β_k = 0 for k < N}`. If `N ≥ 1` and `deg r, deg s ≤ 1`, then on `U_N` the
formulas above take values in `O^2`, so no reduction mod `A^2` occurs. The action is honestly
`K_∞`-linear there. Artifact check (A): 0 mismatches for `p = 2, 3, 5`. The control case
`ζ = (0, t^-1) ∉ U_1` does reduce.

For `ζ ≠ 0` put `d(ζ) = deg x − deg y ∈ Z ∪ {±∞}`, with `d = +∞` if `y = 0` and `d = −∞` if
`x = 0`. This is the valuation of the slope `x/y ∈ P^1(K_∞)`. Write `S_j = {ζ ≠ 0 : d(ζ) = j}`.

## Step 1: sector lemma

**Lemma S.** Let `N ≥ 1` and `0 ≠ ζ ∈ U_N`.
1. If `d(ζ) ≤ 0`, then `d(e_21(t)·ζ) = 1`.
2. If `d(ζ) ≥ 0`, then `d(e_12(t)·ζ) = −1`.
3. If `d(ζ) = 1`, then `d(e_12(1)·ζ) = 0`. This holds for every `ζ ≠ 0`, since `e_12(1)` has degree 0.

*Proof.*
1. Here `y ≠ 0` and `deg x ≤ deg y < deg(ty)`. So `x' = x − ty` has degree `deg y + 1`, and `y` is
   unchanged.
2. Here `x ≠ 0` and `deg y ≤ deg x < deg(tx)`. So `y' = y − tx` has degree `deg x + 1`.
3. Here `deg y < deg x`. So `y' = y − x` has degree `deg x`. ∎

Artifact check (B) tests these inclusions on random characters for `p = 2, 3, 5`, with 0 failures.
Check (C) tests the same statements for shears of general degree.

## Step 2: failure of relative (T) gives a sector-concentrated invariant mean

Let `Λ` be a countable group, generated by a finite set `T`, acting on `M_+` through a homomorphism
`L : Λ → SL_2(A)` whose image contains `Γ_0`. Put `G = M_+ ⋊ Λ`. For Theorem P, take `Λ = Γ_0` and
`L = id`. Suppose `(G, M_+)` fails relative (T).

Then there is a unitary representation `π` of `G` with no nonzero `M_+`-invariant vector, and unit
vectors `v_n` with `||π(g)v_n − v_n|| → 0` for each `g ∈ G`. It suffices to check this on the
finite generating set `{e_1, e_2} ∪ T`, since `M_+` is generated as a `Λ`-module by `e_1` and `e_2`
(see (c) below).

Let `μ_n` be the spectral measure of `v_n` on `M^_+`, so that
`<π(m)v_n, v_n> = ∫ ω^(χ(m)) dμ_n(χ)` with `ω = e^(2πi/p)`. Then:

- **(a) No atom at 0.** `μ_n({0}) = 0`, because the spectral projection of `{0}` is the projection
  onto the `M_+`-invariant vectors.
- **(b) Asymptotic invariance.** For `λ ∈ Λ`, `L(λ)_*μ_n` is the spectral measure of `π(λ)v_n`.
  So `||L(λ)_*μ_n − μ_n||_TV ≤ 2||π(λ)v_n − v_n|| → 0`.
- **(c) Concentration at 0.** For `m ∈ M_+`,
  `||π(m)v_n − v_n||^2 = ∫ |ω^(χ(m)) − 1|^2 dμ_n ≥ c_p μ_n({χ(m) ≠ 0})`, with `c_p = |ω − 1|^2`.
  Also `π(L(λ)m) = π(λ)π(m)π(λ)^-1`, so `||π(L(λ)m)v_n − v_n|| ≤ 2||π(λ)v_n − v_n|| + ||π(m)v_n − v_n||`.
  Every `t^k e_i` is a `±1`-combination of finitely many `Γ_0`-translates of `e_1` and `e_2`:
  - `e_21(t)(r, 0) − (r, 0) = (0, tr)`;
  - `e_12(t)(0, r) − (0, r) = (tr, 0)`.

  Artifact check (D) confirms this exactly for `k < 12`. Hence `μ_n({χ(t^k e_i) ≠ 0}) → 0` for all
  `k` and `i`, so `μ_n(U_N) → 1` for every `N`.

Take a nonprincipal ultrafilter `ω'` and put `m(B) = lim_(ω') μ_n(B ∖ {0})` for Borel
`B ⊆ X = M^_+ ∖ {0}`. Then `m` is a finitely additive probability on `X`. By (b) it is invariant
under `Γ_0`, which acts on `X` by homeomorphisms. By (c), `m(U_N ∖ {0}) = 1` for every `N`.

## Step 3: the count (proof of Theorem P)

Fix `N ≥ 1` and put `X_N = U_N ∖ {0}`, `P = X_N ∩ {d ≤ 0}` and `Q = X_N ∩ {d ≥ 0}`. Then
`P ∪ Q = X_N`, so `m(P) + m(Q) ≥ 1`. The following all use `Γ_0`-invariance of `m` and the fact
that `m` is carried by `X_N`:

- `e_21(t)` maps `P` into `S_1` (Lemma S.1), so `m(S_1) ≥ m(P)`.
- `S_(−1) ∩ X_N ⊆ P`, so `m(P) ≥ m(S_(−1))`.
- `e_12(t)` maps `Q` into `S_(−1)` (Lemma S.2), so `m(S_(−1)) ≥ m(Q)`.
- `S_1 ∩ X_N ⊆ Q`, so `m(Q) ≥ m(S_1)`.

So `m(S_1) = m(P) = m(S_(−1)) = m(Q) =: c`, and `c ≥ 1/2`.

By Lemma S.3, `e_12(1)` maps `S_1` into `S_0`, so `m(S_0) ≥ c ≥ 1/2`. But `S_(−1)`, `S_0` and `S_1`
are disjoint, so `m(X) ≥ 3/2`. This is a contradiction. Hence `(G, M_+)` has relative (T). ∎

The same proof works for any countable `Λ` acting through `L` as in Step 2. This is the form used in
Step 4. It replaces Lemma T of Theorem R.

## Remark 1 (p = 2 needs the third shear)

For `p = 2`, `e_12(1)` and `e_21(t)` are involutions, and their product has trace `t` and infinite
order. So `⟨e_12(1), e_21(t)⟩` is infinite dihedral, hence amenable, and the pair fails relative
(T). In the count this appears as follows: `e_12(1)` maps `{d ≥ 1}` into `S_0 ∩ {lc(x)/lc(y) = 1}`,
and applying it again cancels the leading terms and returns to `{d ≥ 1}`. Nothing is forced.

## Remark 2 (two shears suffice for p ≥ 3)

Let `Γ_1 = ⟨e_12(1), e_21(t)⟩` and `p ≥ 3`. This is the witness of
`free-linear-part-char-p-affine-pairs-have-relative-t`. Here is an elementary proof of relative (T)
for it.

- **Concentration.** Step 2(c) still holds: `e_12(1)e_2 − e_2 = e_1`, and alternating the
  differences for `e_21(t)` and `e_12(1)` gives `(0, t)`, `(t, 0)`, `(0, t^2)`, and so on.
- **Refined sectors.** For `ρ ∈ F_p^×` put `S_0^ρ = S_0 ∩ {lc(x)/lc(y) = ρ}`. Let `P` be as in Step 3
  and `P' = X_N ∖ P = X_N ∩ {d ≥ 1}`. Then:
  - `e_21(t)` maps `P` into `S_1`;
  - `e_12(1)` maps `P'` into `S_0^(−1)`, because `y' = y − x` has leading coefficient `−lc(x)`;
  - `S_0^(−1) ∩ X_N ⊆ P` and `S_1 ∩ X_N ⊆ P'`.

  So `m(S_0^(−1)) ≤ m(P) ≤ m(S_1) ≤ m(P') = 1 − m(P) ≤ m(S_0^(−1))`, and all of these equal `1/2`.
- **Contradiction.** `e_12(1)` maps `S_0^(−1)` into `S_0^(−1/2)`. Indeed
  `lc(y − x) = lc(y)(1 − ρ) = 2 lc(y) ≠ 0` since `p ≠ 2`, and the new ratio is
  `ρ/(1 − ρ) = −1/2`. Also `−1/2 ≠ −1` in `F_p`. So `m(S_0^(−1/2)) ≥ 1/2`, and together with
  `S_0^(−1)` and `S_1` this gives mass `3/2`. ∎

## Remark 3 (other degrees)

Lemma S generalizes, and check (C) of the artifact tests this. Let `deg s = a ≥ 1`, `deg r = b ≥ 1`
and `deg u = c ≥ 0`, and let `N ≥ max(a, b, c)`. Then on `U_N`:
- `e_21(s)` maps `{d ≤ 0}` into `S_a`;
- `e_12(r)` maps `{d ≥ 0}` into `S_(−b)`;
- `e_12(u)` maps `S_a` into `S_(−c)`;
- `e_21(u)` maps `S_(−b)` into `S_c`.

So the count of Step 3 works for `⟨e_21(s), e_12(r), e_12(u)⟩` with `c ≠ b`, and for
`⟨e_21(s), e_12(r), e_21(u)⟩` with `c ≠ a`. There is one proviso: the translates of finitely many
vectors must span a subgroup of `M_+` whose annihilators `U'_N` still form a neighbourhood basis of
`0`, so that Step 2(c) holds. This proviso is not needed for Theorems P and Q and is not pursued.

## Step 4: proof of Theorem Q

Let `Λ = ⟨g_1, g_2, g_3⟩ ≤ nV`. The following steps are imported from the proof of Theorem R in
`char-p-burger-lamp-realizations-refute-haagerup`, which uses nothing about `R^2` beyond its being a
countable `F_p`-module with a continuous dual `M^`.

1. **The homomorphism.** Since `φ` is affinely spanning, each `λ ∈ Λ` determines the affine map
   `q(λ)` with `φ∘λ = q(λ)∘φ`, and `q` is a homomorphism. Its linear part `L = lin∘q` has image
   `Γ_0` (generated by the `E_i`).
2. **Duality.** Put `ι(m)(x) = φ(x)(m)`, which lies in `C(C^n, F_p)`. By affine spanning, `ι` is
   injective and `ι(M_+)` meets the constants `Z ≅ F_p` only in `0`. Moreover
   `λ·ι(m) = ι(L(λ)m) + const`. So `M' = ι(M_+) ⊕ Z` is `Λ`-invariant, and `M'/Z ≅ M_+` as
   `Λ`-modules via `L`.
3. **Relative (T).** Step 3, in the form for `Λ` acting through `L`, gives relative (T) for
   `(M_+ ⋊ Λ, M_+)`.
4. **Finite central extension.** `Z` is finite and central in `M' ⋊ Λ`. By the finite-central step
   of Theorem R, `(M' ⋊ Λ, M')` has relative (T).
5. **Lamp lemma.** `C(C^n, F_p) ⋊ nV ≤ nV`, so `M' ⋊ Λ ≤ nV`. `M'` is infinite, and a Haagerup
   group has no pair with relative (T) on an infinite subgroup (Schoenberg). So `nV` is not Haagerup.

For a finite family of lifts whose linear parts generate a group containing `gΓ_0 g^-1`, with
`g ∈ GL_2(A)`: choose words `λ_j` with `L(λ_j) = g E_j g^-1`, pass to the finitely generated
subgroup `⟨λ_1, λ_2, λ_3⟩`, whose linear image is exactly `gΓ_0 g^-1`, and transport Step 3 by the
automorphism `g` of `M_+`. For `p ≥ 3` and `Γ_1`, use Remark 2. ∎

## Step 5: proof of Proposition L

`res : (F_p^2)^Z → (F_p^2)^N` is dual to the inclusion `M_+ ⊆ M = F_p[t,t^-1]^2`. Every
`γ ∈ Γ_0 ⊂ SL_2(A)` preserves `M_+`, so `res(γ·χ) = γ·res(χ)`, and `res` commutes with
translations. So a word `g` with `φ∘g = γ·φ + v` gives `φ_+∘g = γ·φ_+ + res(v)`. For
`0 ≠ m ∈ M_+`, `φ_+(x)(m) = φ(x)(m)` is not constant. So `φ_+` is affinely spanning. ∎

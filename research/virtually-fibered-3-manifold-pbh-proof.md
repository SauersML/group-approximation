Write `B_A` for the class of `boone-higman-type-a-class-closed-under-finite-extensions`.
That node gives closure of `B_A` under subgroups, finite direct products and
finite-index overgroups (parts 1 and 2). `char-zero-linear-groups-satisfy-permutational-boone-higman`
puts every finitely generated characteristic-zero linear group in `B_A`.

By part 2 it suffices to show `H = Z ⋉_phi Gamma` is in `B_A`, where
`Gamma = pi_1(Sigma)`. Write elements as `g t^k` with `g in Gamma` and
`t g t^-1 = phi(g)`, so `(g t^k)(h t^l) = g phi^k(h) t^(k+l)`.

**Genus 0.** `H = Z`, which is linear.

**Genus 1.** `Gamma = Z^2` and `phi in GL_2(Z)`. The map

```text
g t^k  |->  ( [[phi^k, g], [0, 1]] ,  [[1, k], [0, 1]] )  in  GL_3(Z) x GL_2(Z)
```

sends `g t^k` to the affine map `x |-> phi^k x + g` and to the translation by
`k`. Composition of affine maps gives `phi^k(phi^l x + h) + g`, so the map is a
homomorphism. Its kernel needs `k = 0` from the second factor and then `g = 0`.
So `H` is linear over `Z`.

**Genus g ≥ 2.** Define `Theta : H -> Aut(Gamma)` by
`Theta(g t^k) = inn_g ∘ phi^k`, where `inn_g(x) = g x g^-1`. Since
`phi^k ∘ inn_h ∘ phi^-k = inn_(phi^k(h))`,

```text
Theta(g t^k) Theta(h t^l) = inn_g inn_(phi^k(h)) phi^(k+l) = Theta(g phi^k(h) t^(k+l)),
```

so `Theta` is a homomorphism.

- **Case A: `phi` has infinite order in `Out(Gamma)`.** If
  `inn_g ∘ phi^k = id`, then `phi^k` is inner, so `k = 0`. Then `inn_g = id`, so
  `g` is central, and `g = 1` by part 1 of `based-dehn-nielsen-baer-for-closed-surfaces`.
  So `Theta` is injective. By part 2 of that node,
  `Aut(Gamma) = Mod^±(S_(g,1))`. This is the extended mapping class group of a
  surface with one puncture, which is in `B_A` by
  `punctured-surface-mcgs-satisfy-permutational-boone-higman` (BFFHZ Corollary B,
  first bullet, with the PBH conclusion of their Section 4). So `H` is in `B_A`.
- **Case B: `phi` has finite order `n ≥ 1` in `Out(Gamma)`.** Write
  `phi^n = inn_c` with `c in Gamma`. The subgroup `H_n` generated by `Gamma` and
  `t^n` has index `n` in `H`. Put `s = c^-1 t^n`. For `g in Gamma`,
  `s g s^-1 = c^-1 phi^n(g) c = g`, so `s` centralizes `Gamma`. The image of
  `s^m` in `Z` is `nm`, so `Gamma ∩ <s> = 1`, and `H_n = Gamma x <s>`, which is
  isomorphic to `Gamma x Z`. `Gamma` is linear over `Z` (item 5 of
  `three-manifold-groups-linear-unless-closed-graph-manifold`), so `H_n` is
  linear over `Z`, hence in `B_A`, and `H` is in `B_A` by part 2.

**3-manifold form.** Let `N' -> N` be a finite cover and `p : N' -> S^1` a
fibration. The fibre can be taken connected: if it has `k` components, `p`
factors through the connected `k`-fold cover of `S^1`. It is a closed surface,
orientable because `N'` and `S^1` are. Aschenbrenner--Friedl--Wilton,
arXiv:1205.0202, l.3158--3162: "We obtain a short exact sequence
1 → Γ := π1(Σ) → π = π1(N) → Z = π1(S1) → 1. This sequence splits and we see that
π is isomorphic to the semidirect product Z ⋉φ Γ". So `pi_1(N')` has the form
above, and it has finite index in `pi_1(N)`.

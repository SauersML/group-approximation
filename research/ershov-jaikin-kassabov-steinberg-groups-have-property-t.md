**ESTABLISHED (literature import).** Ershov--Jaikin-Zapirain--Kassabov, *Property (T) for groups
graded by root systems*, arXiv:1102.0031, Theorem `thm:main_Steinberg`:

> Let `Φ` be a reduced irreducible classical root system of rank `>= 2`. Let `R` be a finitely
> generated ring, which is commutative if `Φ` is not of type `A_n`. Then the Steinberg group
> `St_Φ(R)` and the elementary Chevalley group `E_Φ(R)` have Kazhdan's property (T).

Type `A_(n-1)` with `n >= 3` over any finitely generated ring is the earlier Ershov--Jaikin-Zapirain
result, which the same introduction credits (`\cite{EJ}`).

**Instance used in this graph.** For a prime power `q` and `r >= 3`, `d >= 1`, the Steinberg group
`St_r(F_q[x_1, ..., x_d])` has property (T), and so does every quotient of it.

**Inputs.** Kharlampovich--Myasnikov--Sapir, arXiv:1204.6506v5, read from the TeX source
(`KMS-322.tex`) this session: relations G5 b), G5 c), the operation `*` of G8, Lemma
`l654` (`z_(1,u) * w = z_(1,uw)`), the proof of Lemma `l9` (an `x_(u')` whose word
contains `A_0, ..., A_K` is central, "by G5 c)"), Lemma `l097` (the `x_(i,w)` are
linearly independent), and Theorem `tmm`(b) (equality of these elements is equality in
`S(M)`). The standard fact used about self-similar actions: for the action defined by a
virtual endomorphism `φ: H -> G`, the kernel is the `φ`-core, the largest subgroup
`N <= H` that is normal in `G` and satisfies `φ(N) <= N` (Nekrashevych, *Self-similar
groups*, §2.7; cited, not re-read).

1. **Center.** By Lemma `l654`, the displayed element equals the single basis element
   `x_(1, u')` with `u' = q_i A_0 a^m A_1 ... A_K`. By the proof of Lemma `l9` (G5 c) it
   commutes with every generator in `M_0, ..., M_K`, and with `T` because `T` is abelian.
   So it is central. By Theorem `tmm`(b) and Lemma `l097`, inequivalent configurations
   give distinct, linearly independent elements. So `Z_0 ≅ F_p[classes]`.
2. **Items 2 and 3.** Every subgroup of `Z_0` is normal (it is central), and every
   subgroup of `T` that is `Q`-invariant is normal (`T` is abelian). If a nonzero normal
   `N` lies in `H` with `φ(N) <= N`, it lies in the `φ`-core, so the action is not
   faithful. This gives item 3. For item 2, if `0 != z` had `φ^j(z) ∈ Z_0 ∩ H` for every
   `j`, the span of the orbit would be such an `N`.
3. **Item 4, structure.** Take a word `u` without `A_i`. G5 b) says `x_u^(a_i - 1) = x_u^(a_i')`.
   In additive notation on the abelian group `T`, `a_i'` acts as `a_i - 1` on the
   `<a_i, a_i'>`-module generated by `x_u`. Hence `a_i - 1` acts invertibly, and the
   module is a quotient of `R`. The G8 formula
   `f * a_i = f^(-1) f^(a_i) f^(-a_i^(-1)) f^((a_i')^(-1))` is additively multiplication by
   `-1 + a - a^(-1) + (a-1)^(-1) = (a^3 - 2a^2 + a + 1)/(a(a-1)) = P(a)`, a direct
   computation. The rational function `P` has poles exactly at `0, 1, ∞`, so
   `R` is finite and flat over `F_p[P]`, of rank 3, and free because `F_p[P]` is a
   principal ideal domain. Lemma `l097` (the three elements `x_(j,w)`, `j = 1, 2, 3`,
   over each word) is the statement that the cyclic module is all of `R`, with this rank.
   The characteristic polynomial of the block `z ↦ z^(a_i)` in KMS's formula `(ea)`,
   `[[1,-1,1],[1,1,0],[1,0,0]]`, is `λ^3 - 2λ^2 + λ + 1`, the numerator of `P`.
   Because `a`, `a'` commute and the coefficients lie in `F_p`, the Frobenius identity
   `μ(a, a')^p = μ(a^p, a'^p)` holds for every `μ` in `F_p[a^(±1), a'^(±1)]`. So a map
   with `φ(t^(λ^p)) = φ(t)^λ` sends appending `p` coins, `P(a^p) = P(a)^p`, to appending
   one coin. Zero tests are markers `A_j` acting by `1 + ε` with `ε^2 = 0`, and these are
   unaffected. Such maps, on the configuration module `F_p[classes] ⊗ R^(⊗K)`, are the
   digit-renormalization maps. They are defined on all of `T` with values in `T`, so
   item 3 applies whether or not they extend to homomorphisms of `G`.
4. **Item 5.** For `π ∈ F_p[G]` and central `z`, `z·π = ε(π) z`, where `ε` is the
   augmentation. If `ε(π) != 0`, then `Z_0 = π^n Z_0 <= π^n T` for every `n`, so `Z_0`
   lies in every iterated domain. Its conjugates are itself, and `φ(Z_0) = Z_0`, so
   `Z_0` is in the `φ`-core, which is nonzero by item 1. If `ε(π) = 0`, then `π` kills
   `Z_0 != 0`. Division by `π` is then not well defined, since `φ(π z) = z` would be
   forced for `z ∈ Z_0` while `π z = 0`.

The Frobenius and rank computations in step 3 are elementary. The rank-3 freeness
statement over `F_p[P]` uses Lemma `l097` only for words with no machine relations.

This is an obstruction to a whole class of approaches to
`hyperlinear-fg-bounded-exponent-groups-are-finite`. The class: turn an
approximation of `G` into an exact homomorphism into some ambient algebra
(`R^omega`, `prod_omega M_n(C)`, a rank ultraproduct `prod_omega M_n(F_p)`, `F[G]` itself), filter by
powers of ideals, build the graded Lie object, and run Zelmanov's
Engel/PI-identity argument there.

## Statement

Let `G` be finitely generated with `g^N = 1` for all `g`, and let `K` be its finite residual. By
`bounded-exponent-fg-group-residual-has-finite-index`, `K` has finite index, is perfect, and has no
proper finite-index subgroup.

Let `F` be a field, `A` a unital associative `F`-algebra, and `phi : G -> A^x` a group homomorphism. Write
`I_H` for the two-sided ideal of the subalgebra `F[phi(G)]` generated by `phi(h) - 1`, `h in H`. A
**multiplicative filtration** is a chain of two-sided ideals `J_1 ⊇ J_2 ⊇ ...` of any subalgebra `B ⊇ F[phi(G)]`
with `J_i J_j ⊆ J_{i+j}` and `I_G ⊆ J_1`. Its **dimension subgroups** are `D_j = { g : phi(g) - 1 in J_j }`.

1. **Idempotent residual augmentation.** `I_K = I_K^2` in every characteristic. So `phi(k) - 1 in J_j` for every
   `k in K` and every `j`: `K <= ⋂_j D_j` for every multiplicative filtration in every ambient algebra.
2. **Group-theoretic form.** If `G = G_1 >= G_2 >= ...` is any N-series (`[G_i, G_j] <= G_{i+j}`), then
   `K <= ⋂_j G_j`. The associated Lie ring `⊕ G_j/G_{j+1}` is a Lie ring of the finite group `G/⋂_j G_j`,
   which is a quotient of `G/K`. In particular Zelmanov's Zassenhaus Lie algebra `L_p(G)` equals `L_p(G/K)`.
3. **Characteristic-zero collapse.** If `N` is invertible in `F` (for instance `F = C`), then `I_G = I_G^2`.
   Every multiplicative filtration has `D_j = G` for all `j`, and every graded object `⊕ J_j/J_{j+1}`
   receives the zero map from `G`. For the power filtration `J_j = I^j` the degree-one layer is `G^ab ⊗ F = 0`.
4. **Metric linearization has no dimension-free contraction.** Let `N >= 3`. With the normalized
   Hilbert-Schmidt norm on `U(n)`, no constant `C` satisfies
   `||[u,v] - 1||_2 <= C ||u - 1||_2 ||v - 1||_2` for all `n` and all `u, v in U(n)` with `u^N = v^N = 1`.
   In the operator norm, every `u ≠ 1` with `u^N = 1` has `||u - 1||_op >= 2 sin(pi/N)`. So the Jordan/Zassenhaus
   neighbourhood of an exponent-`N` subgroup is trivial, and the only finiteness it gives is the packing
   count of `U(n)` by operator-norm balls of radius `sin(pi/N)`, which grows with `n`.

## Where every member of the class dies

A graded-Lie linearization proves finiteness of `G` only through a **separation step**: the filtration
separates `G` (`⋂_j D_j = 1`), or at least `⋂_j D_j` is finite. By part 1, `⋂_j D_j ⊇ K`.

- If `⋂_j D_j` is finite, `K` is finite, hence `G` is finite.
- Conversely, if `G` is infinite, `K` is infinite, and no filtration in any ambient separates it.

So the separation step is equivalent to the conclusion. Everything the Lie object can certify, such as
nilpotency, Engel identities or finite dimension, concerns `G/K`. That group is already finite by Zelmanov.

**Invariant.** `H_1(K; Z) = 0`: the finite residual is perfect. When `N` is invertible in `F`, the invariant is
instead `G^ab ⊗ F = 0`.

**Step.** The degree-one layer `J_1/J_2` sees `g ↦ (phi(g) - 1) + J_2`, which is a homomorphism of groups. On
`K` it is zero, so `phi(K) - 1` lies in every layer.

For a minimal counterexample (`G = K`: infinite, hyperlinear, exponent `N`, no finite quotients), every such
graded object receives the zero map from `G` in every characteristic (for the power filtration `J_j = I^j` it is identically zero). Hyperlinearity passes to `K`, so the target
reduces to this case.

**Metric variants.** Replacing ideal filtrations by norm neighbourhoods does not escape, by part 4:

- the Hilbert-Schmidt norm has no commutator contraction;
- the operator norm has a spectral gap, so its neighbourhoods are trivial and the count is dimension-dependent.

That dimension dependence is exactly what `bounded-dimension-microstates-bounded-exponent-group-is-finite`
uses and what the target lacks.

**What survives.** A proof of the target must use a mechanism that sees the perfect group `K` and not only
abelian layers. Examples are the trace or character values themselves (as in
`hyperlinear-bounded-exponent-trace-rigidity-iff-finiteness`), non-abelian simple quotients of `K`, or
non-linear geometric input. It cannot be a Lie-ring transfer of restricted Burnside.

## Model tests

- **`G` finite.** `K = 1`, and part 2 recovers the classical fact that the Zassenhaus filtration sees the maximal
  `p`-quotient.
- **`G = A_5`** (exponent 30). `K = G`, and `I_G = I_G^2` over every field. Every dimension subgroup is `A_5`,
  consistent with part 1.
- **Free Burnside `B(m,N)`, `N` large odd.** `K` is the kernel onto `R(m,N)`, infinite and perfect. By part 2 the
  Zassenhaus Lie algebras of `B(m,N)` and `R(m,N)` coincide, which matches Zelmanov's theorem being a statement
  about `R(m,N)` only.

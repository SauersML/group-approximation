Notation is that of the target.  Throughout, for a generating map
`p: F(B) -> H`, the letters `b in B` with `p(b) = 1` are **dummies**.  All
group identifications below are induced by isomorphisms of free groups that
commute with the maps to `H`.  Such an isomorphism carries the kernel onto
the kernel and hence induces an isomorphism of covers.

## Step 0: basis changes preserve covers

**(B0)** Let `p: F(B) -> H` and `p': F(B') -> H` be generating maps, and let
`phi: F(B) -> F(B')` be an isomorphism with `p' phi = p`.  Then
`phi(R_p) = R_(p')`, so `phi` induces `E(p) = E(p')` and `M(p) = M(p')`.

**(B1) Sliding.**  Let `B = B_0 u B_1` be a partition, and for each
`b in B_1` pick a word `w_b` in `F(B_0)`.  The endomorphism `phi` of
`F(B)` that fixes `B_0` and sends `b` to `b w_b^(-1)` for `b in B_1` is an
automorphism.  Its inverse `psi` fixes `B_0` and sends `b` to `b w_b`:
since `psi` fixes `F(B_0)`, we get `psi(phi(b)) = b w_b w_b^(-1) = b`, and
similarly `phi psi = id`.  If `p(b) = p(w_b)` for every `b in B_1`, then the
new basis `B_0 u phi(B_1)` consists of `B_0` together with dummies, and `p`
is unchanged.  Here the basis is allowed to be infinite; no step uses
finiteness of `B_1`.

## Step 1: dummies split off (item 1)

Take `k = 1`, with dummy `z`; the general case follows by induction, and
for `k = aleph_0` it holds as a direct limit.  Put `F_z = F(X) * <z>`, let
`R_z` be the kernel of `F_z -> G`, and set `E_z = F_z/[R_z,R_z]` and
`M_z = R_z/[R_z,R_z]`.

- **Retraction.**  The map `r: F_z -> F(X)` with `z -> 1` commutes with the
  maps to `G`.  So `r(R_z) = R`: it lands in `R`, and it fixes
  `R <= R_z`.  It follows that `r([R_z,R_z]) <= [R,R]`.  Hence `r` induces
  `bar r: E_z -> E`.  The inclusion `F(X) -> F_z` induces `i: E -> E_z`,
  since `R <= R_z`, and `bar r i = id`.  So `i` is injective and `E` is a
  retract of `E_z`.
- **The kernel of the retraction.**  `ker bar r` is the image of
  `ker r = <<z>>` in `E_z`.  Since `<<z>> <= R_z`, it lies in the abelian
  group `M_z`, and as a `ZG`-module it is generated by the class `[z]`.
- **Freeness.**  Define `D: R_z -> ZG` by `D(u) = image of (d u / d z)`, the
  Fox derivative pushed to `ZG`.
  - `D` is a homomorphism on `R_z`, because
    `d(uv)/dz = du/dz + u dv/dz` and `u -> 1` in `G`.
  - `D` vanishes on `[R_z,R_z]`, because its target is abelian.
  - `D` is `G`-equivariant, because `D(w u w^(-1)) = w D(u)` for `w in F_z`
    and `u in R_z`.
  - `D(z) = 1`.

  So the `ZG`-map `ZG -> ker bar r` given by `1 -> [z]` is surjective and
  has left inverse `D`.  Hence it is an isomorphism, and `ker bar r = ZG`,
  with `E` acting through `G` by left multiplication.
- **Conclusion.**  `E_z = ZG x| E`.
- **Relation module.**  `bar r` maps `M_z` onto `M`, because
  `r(R_z) = R`.  Its kernel on `M_z` is all of `ker bar r = ZG`, and `i`
  splits it.  The image `i(M)` is normalized by `i(E)`, and it commutes
  with the abelian group `ker bar r`.  So it is an `E_z`-submodule, and
  `M_z = i(M) (+) ZG` as `ZG`-modules.
- **Several dummies.**  For `Z_k` with `k` finite, iterate.  For
  `k = aleph_0`, run the same argument with one derivative `D_z` for each
  `z in Z_k`.  Then `ker(E_(G,X,k) -> E)` is the free module `ZG^(k)`
  with basis `{[z]}`, since `D_z([z']) = delta_(z z')`.

## Step 2: Tietze invariance (item 2)

Let `X` and `Y` be finite generating families of `G`, let `Z_k` be dummies,
and let `q: F(X u Y u Z_k) -> G` be the combined generating map.

- For each `y in Y`, pick a word `w_y` in `F(X)` with `q(y) = q(w_y)`.
- Slide as in (B1), with `B_0 = X u Z_k` and `B_1 = Y`.  The new basis is
  `X` together with `|Y| + k` dummies.
- By (B0), `E(q) = E_(G,X,|Y|+k)`.
- By symmetry, `E(q) = E_(G,Y,|X|+k)`.
- For `k = aleph_0`, this gives `E_(G,X,aleph_0) = E_(G,Y,aleph_0)`.

Suppose `E_(G,X,k)` is not MF.  By Step 1 it is a retract of
`E_(G,X,k+|Y|) = E_(G,Y,k+|X|)`, which is therefore not MF.  So stable DF
does not depend on the family.  Taking `k = 0` gives the last sentence of
item 2.

## Step 3: infinite-dummy normal form (item 3)

Let `p: F(B) -> H` have `B` countably infinite, and let `H` be finitely
generated.

- `H` is generated by `p(B)` and is finitely generated.  So a finite `B_0`
  in `B` already satisfies `p(F(B_0)) = H`.
- For each `b in B_1 = B \ B_0`, pick `w_b` in `F(B_0)` with
  `p(b) = p(w_b)`, and slide as in (B1).
- The new basis is `B_0` together with `aleph_0` dummies.
- By (B0) and Step 2, `E(p) = E_(H,B_0,aleph_0) = E_(H,X,aleph_0)` for every
  finite generating family `X`.

**Finite dummy covers sit inside.**  Let `Z_k` be finitely many of these
dummies, and set `F_k = F(B_0 u Z_k)` and `R_k = R_p cap F_k`.

- The retraction of `F(B_0 u Z_aleph_0)` onto `F_k` that kills the other
  dummies commutes with the maps to `H`.  So it maps `R_p` onto `R_k` and
  maps `[R_p,R_p]` into `[R_k,R_k]`.
- It is the identity on `F_k`, so `[R_p,R_p] cap F_k = [R_k,R_k]`.
- Hence `E_(H,B_0,k)` embeds in `E(p)`.
- Combined with Step 2, every `E_(H,X,k)` with `k` finite embeds in
  `E_(H,X,aleph_0)`.

## Step 4: subgroup monotonicity (item 4)

Let `H <= G` be finitely generated, and set `F_H = P^(-1)(H) <= F(X)`.

- `F_H` contains `R`, and it is free with a countable basis by
  Nielsen--Schreier.
- `P|: F_H -> H` is a generating map with kernel `R`.
- Since `[R,R] <= F_H`, the cover `E(P|) = F_H/[R,R]` is a subgroup of
  `F(X)/[R,R] = E_(G,X)`.

**(a) Infinite index.**  Suppose `[G:H] = infinity`.  We first show that
`F_H` has infinite rank.

Let `S` be the coset graph.  Its vertices are `G/H`, and it has an edge
`c -> x c` for each `x in X`.  Then `F_H` is the fundamental group of `S`
based at `H`.

- If `F_H` had finite rank, `S` would be a finite core with finitely many
  trees attached.
- `S` is infinite and locally finite, so it has vertices arbitrarily far
  from the core.  Each of them lies in an attached tree.
- `G` is not free, so there is `1 != u in R`.  Take it freely reduced, of
  length `l`.
- Since `P(u) = 1`, reading `u` from any vertex `c` gives a closed path.
  It has no backtracking, because the word is reduced and each vertex has
  exactly one outgoing and one incoming edge per letter.
- Start at a vertex at distance greater than `l` from the core.  The path
  never leaves its tree, so it is a closed non-backtracking path of positive
  length in a tree.  That is impossible.

So `F_H` has infinite rank.  By Step 3,
`F_H/[R,R] = E_(H,Y,aleph_0) >= E_(H,Y,k)` for every finite `k` and every
finite generating family `Y`.  If `H` is stably DF, then `E_(G,X)` has a
non-MF subgroup, so it is not MF.  This holds for every `X`.

**(b) Finite index `d`.**  Then `[E_(G,X) : F_H/[R,R]] = [F(X):F_H] = d`.

Pick a Schreier transversal `T` for `F_H`.  It exists because `S` is
connected.  Now pass to `F(X u Z_k)` and let `F_(H,k)` be the preimage of
`H`.

- Its coset graph is `S` with a loop at every vertex for each `z`.
- So Reidemeister--Schreier gives the basis
  ```text
  B_H u { t z t^(-1) : t in T, z in Z_k },
  ```
  where `B_H` is the Schreier basis of `F_H`, finite of rank `d(|X|-1)+1`.
- Each of the `dk` letters `t z t^(-1)` is a dummy.
- Hence `F_(H,k)/[R_k,R_k] = E_(H,B_H,dk)`, a subgroup of index `d` in
  `E_(G,X,k)`, where `R_k` is the kernel of `F(X u Z_k) -> G`.

For finite `j` and `Y`, Steps 1 and 2 give

```text
E_(H,Y,j) <= E_(H,Y,j+|B_H|) = E_(H,B_H,j+|Y|) <= E_(H,B_H,dk)
```

as long as `dk >= j+|Y|`.

**(c) MF passes to finite-index overgroups.**  Let `Gamma_0 <= Gamma` have
index `d`, and suppose `Gamma_0 <= U(A)` with `A = prod M_(k_n)/(+)M_(k_n)`.

- Kaloujnine--Krasner gives an embedding
  `Gamma -> Gamma_0 wr S_d = Gamma_0^d x| S_d`.
- The map `(u_1,...,u_d; sigma) -> diag(u_1,...,u_d) P_sigma` is an
  injective homomorphism into `U(M_d(A))`.  The block pattern recovers
  `sigma`, and the blocks then recover the `u_i`.
- Finally, `M_d(A) = prod M_(d k_n)/(+)M_(d k_n)`.

**(d) Commensurability.**

- *Upward.*  Suppose `H` is stably DF, say `E_(H,Y,j)` is not MF.  Then (b)
  puts it inside `E_(G,X,k)` for large `k`, so `G` is stably DF.
- *Downward.*  Suppose `E_(G,X,k)` is not MF.  Then its index-`d` subgroup
  `E_(H,B_H,dk)` is not MF by (c), so `H` is stably DF.

Two commensurable groups share a finite-index subgroup, so they are stably
DF together.

## Step 5: only free subgroups lift (item 5)

Let `p = P|: F_H -> H`, with basis `B` of `F_H` and cover
`E_H = F_H/[R,R]`.

**Free implies split.**  If `H` is free, lift a free basis of `H` to `E_H`.
The lifts generate a complement.

**Split implies free.**  Set `N = ZH^(B)` with basis `(e_b)`, and let
`partial: N -> I_H` be the Fox projection `e_b -> p(b) - 1`.

- **The Magnus map.**  The homomorphism `F_H -> N x| H` given by
  `b -> (e_b, p(b))` sends `w` to `(d(w), p(w))`.  Here
  `d(w) = sum_b (image of dw/db) e_b` is a derivation.
- **The fundamental formula.**  The Fox formula
  `sum_b (dw/db)(b-1) = w-1`, pushed to `ZH`, gives
  `partial d(w) = p(w) - 1`.
- The Magnus map sends `[R,R]` to `0`.  Indeed `R` maps into the abelian
  group `N x {1}`, since `p(R) = 1`.  So it factors through
  `mu: E_H -> N x| H`.
- **A splitting of `I_H`.**  Let `s: H -> E_H` be a homomorphic section.
  Then `mu s(h) = (delta(h), h)`, where `delta = d s` is a derivation
  `H -> N`.  Derivations `H -> N` are the same as `ZH`-maps `I_H -> N`, via
  `f(h-1) = delta(h)`.  By the fundamental formula,
  `partial f(h-1) = h - 1`.  So `partial f = id` on the generators `h-1` of
  `I_H`, and therefore on all of `I_H`.
- **Conclusion.**  `I_H` is a direct summand of the free module `N`, so it
  is projective.  Then `0 -> I_H -> ZH -> Z -> 0` is a projective
  resolution of length one, so `cd H <= 1`.  By Stallings--Swan, `H` is
  free.

**Consequence.**  A subgroup `S <= E_(G,X)` that maps isomorphically onto
`H <= G` lies in `P^(-1)(H)/[R,R] = E_H`, and it is a complement there.  So
`H` is free.

## Step 6: calibration (item 6)

**Amenable `H`.**  `E_(H,X,k)` is a free abelian extension of `H`, so it
is amenable.  For a countable amenable group `Gamma`, `C*(Gamma)` is
quasidiagonal by Tikuisis--White--Winter, and it is unital and separable.
So it embeds unitally into some `prod M_(k_n)/(+)M_(k_n)`, and `Gamma`
embeds in the unitary group.  So amenable groups are never stably DF.

**Free `H` of rank `m`.**  Here `R_p` is the normal closure of `Z_k` in
`F(X u Z_k)` with `X` a basis.  Step 1 gives `E_(H,X,k) = ZH^k x| H`, which
is `Z^k wr H`.  This is residually finite by Gruenberg, since `Z^k` and `H`
are residually finite, and so it is MF.  By Step 2 the same holds for every
generating family.  So free groups are never stably DF.

Together with Step 4, any subgroup witness `H` of stable DF must be neither
amenable nor free.  By Step 4(d), the same holds for every group
commensurable with such a witness.

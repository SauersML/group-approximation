Direct proof. Not independently reviewed. `Q-free` means "contains no subgroup
isomorphic to `(Q,+)`". Subgroups of Q-free groups are Q-free. Inside `Q^n`, a
subgroup isomorphic to `Q` has rank one and is divisible, so it is a full line
`Qv`. Hence a subgroup of `Q^n` is Q-free exactly when it contains no line.

## Step 1. The two groups of scalars

**(a)** If `S = Q^x`, the `S`-invariant subgroups of `Q` are `0` and `Q`, since
`Q^x` is transitive on `Q \ 0`.

**(b)** If `S` is the set of nonzero squares, the same holds. Let `L != 0` be
invariant and `x in L \ 0`. Every positive rational `m/k = mk/k^2` is a sum of
four rational squares, by Lagrange's theorem applied to `mk`. So
`(m/k)x = a_1^2 x + ... + a_4^2 x` lies in `L`. With negatives, `Qx = Q` lies in
`L`.

## Step 2. Part (A)

Put `D_i = D ∩ N_i`. Each `N_i` is normal in `E`, so each element of `N_E(D)`
maps `D_i` to itself. Hence `D_i` is `S`-invariant. Suppose, for contradiction,
that the only `S`-invariant subgroups of `D` are `0` and `D`.

Then `D_i` is `0` or `D` for every `i`. Since `D_0 = 0` and `D_k = D`, let `i`
be minimal with `D_i = D`, so `D ∩ N_{i-1} = 0`. Then `D <= N_i` maps
injectively to `N_i/N_{i-1}`.
- **Q-free factor.** This is a contradiction.
- **Central factor.** Take `t` inducing `s in S \ 1`. For `d in D`, the image
  of `d` in `E/N_{i-1}` is central. So `t d t^-1 d^-1 = (s-1)d` lies in
  `D ∩ N_{i-1} = 0`. Hence `(s-1)d = 0` for every `d`, which is impossible in
  the torsion-free group `D` with `s != 1`.

**Applications.**
- `Aff(Q)` acts by `x -> ax + b`. Take `D` = translations and `t_a` = the
  dilations, with `t_a τ_b t_a^-1 = τ_(ab)`, and use Step 1(a).
- `B_2(Q)` contains `{[[a,b],[0,1]]} ~ Aff(Q)`, and `GL_n(Q)` contains
  `B_2(Q)` as a block.
- `SL_2(Q)` has `diag(a,a^-1) [[1,b],[0,1]] diag(a,a^-1)^-1 = [[1,a^2 b],[0,1]]`,
  so use Step 1(b). `SL_n(Q)` contains `SL_2(Q)`.
- For `PGL_n(Q)` and `PSL_n(Q)`, the unipotent `D` meets the scalars trivially.
  So `D` and the action of `t` pass to the quotient.

If `H <= E` contains `D` together with these elements `t`, the subset `S` they
induce satisfies the hypothesis. So `H` does not embed in `E`.

## Step 3. A copy of `(Q,+)` in `GL_n(Q)` is unipotent

Let `D <= GL_n(Q)` with `D ~ (Q,+)`.
- **The semisimple part.** For commuting elements the Jordan decomposition is
  multiplicative. So `d -> d_s` is a homomorphism on `D`. Its image `I` is a
  quotient of `Q`, so it is `0`, isomorphic to `Q`, or a nonzero divisible
  torsion group.
- **Torsion quotients are excluded.** Finite-order elements of `GL_n(Q)` have
  bounded order (their eigenvalues are roots of unity of degree `<= n`). A
  nonzero divisible torsion group has elements of unbounded order.
- **`I ~ Q` is excluded.** `I` is a commuting family of semisimple matrices, so
  it is simultaneously diagonalizable over `Q-bar`. Take `d_s != 1` in `I`. Fix an
  eigenvalue `λ != 1` of `d_s`. For each `k` some `e in I` has `e^k = d_s`, so
  `λ` has a `k`-th root `μ_k` that is an eigenvalue of `e`, hence of degree
  `<= n`.
  - The Weil heights satisfy `h(μ_k) = h(λ)/k <= h(λ)`.
  - By Northcott's theorem only finitely many algebraic numbers have degree
    `<= n` and height `<= h(λ)`. So `μ_k = μ_l = μ` for some `k != l`.
  - Then `μ^k = μ^l = λ`, so `μ` is a root of unity, hence so is `λ`.
  - Every eigenvalue of `d_s` is therefore a root of unity of degree `<= n`. So
    `d_s` has finite order, which is impossible in `I ~ Q` since `d_s != 1`.

So `I = 1` and `D` is unipotent.

## Step 4. A unipotent `(Q,+)` preserving a full-rank `L` puts a line in `L`

Over `Q`, `log` is a bijection from unipotent to nilpotent matrices, and it is
additive on commuting elements. So `log D` is a divisible, torsion-free,
rank-one subgroup of `M_n(Q)`, that is `log D = Q N_0` with `N_0 != 0`
nilpotent.

Let `L` be `D`-invariant of rank `n`. Since `L` spans `Q^n`, pick `v in L` with
`N_0 v != 0`, and let `j >= 1` be maximal with `w = N_0^j v != 0`. For
`h in Q`, `L` contains
`(exp(hN_0) - 1)^j v = (hN_0)^j (1 + hN_0/2 + ...)^j v = h^j w`, because
`N_0^(j+1) v = 0`. The subgroup generated by `{h^j : h in Q}` contains
`a b^(j-1) · (1/b)^j = a/b` for all integers `a` and `b != 0`, so it is `Q`.
Hence `Qw <= L`.

## Step 5. Part (B)

- **(1) ⇒ (2).** `M = H ∩ N` is normal in `H` and Q-free, and `H/M` embeds in
  `E/N`.
- **(2) ⇒ (3).** Put `L = Q^n ∩ M`.
  - `L` is `Gamma`-invariant, because `M` is normal in `H`.
  - `L` contains no line, because `M` is Q-free.
  - `L` has rank `n`. Otherwise its span `V'` is proper; pick `v` outside `V'`.
    Then `Qv ∩ L = 0`, so `Qv` embeds in `Q^n/L <= H/M`, contradicting Q-free.
- **(3) ⇒ (1).** Take `E = H` and `N = L`. `L` is normal: translations commute
  with it and `Gamma` preserves it. `L` is Q-free, since it contains no line (see the top of this proof). Now suppose
  `D' ~ Q` lies in `H/L = (Q^n/L) x| Gamma`.
  - `Q^n/L` is torsion, since `L` has rank `n`. So `D'` maps to `Gamma` with
    kernel `D' ∩ (Q^n/L)`, a torsion subgroup of the torsion-free `D'`, which
    is `0`. So `D'` embeds in `Gamma`.
  - A copy of `Q` in `Gamma` would be unipotent by Step 3. Since it preserves
    the rank-`n` subgroup `L`, it would put a line in `L` by Step 4, which is
    impossible.

  Hence `H/L` is Q-free.
- **Finitely generated `N`.** If `N` is finitely generated abelian, then
  `L = Q^n ∩ N` is free abelian of rank `n`, a lattice. So `Gamma` lies in
  `GL(L) ~ GL_n(Z)`.
- **Examples.**
  - `Z_(q)^n` contains no line: `1/q^k` is missing from each coordinate.
  - `Z[1/m]^n` contains no line: `1/p` is missing for any prime `p` not
    dividing `m`.
  - `GL_n(Q)` and `SL_n(Q)` (`n >= 2`) contain the unipotent `(Q,+)` of
    elementary matrices, so they fail (3) by Step 4.
  - For `n = 1`, `Q^x` preserves only `0` and `Q`, by Step 1(a).

## Step 6. Part (C)

- **The series for `U_3(Q)`.** Write elements of `U_3(Q)` as `(a,b,c)` with
  `(a,b,c)(a',b',c') = (a+a', b+b', c+c'+ab')`.
  - `A_1 = e_13(Z)` is central.
  - `A_2 = {(a,b,c) : a,b in Z}` is a subgroup containing the centre
    `e_13(Q)`. It is normal, because `U_3(Q)` modulo its centre is abelian.
  - In `A_2/A_1` the cocycle `ab'` is an integer, so it vanishes mod `Z`. Hence
    `A_2/A_1 ~ Z^2 x Q/Z`. That group is Q-free: a divisible subgroup maps to
    `0` in `Z^2`, so it is torsion.
  - `U_3(Q)/A_2 ~ (Q/Z)^2`.
- **The series for `Q^n x| GL_n(Z)`.**
  - `Z^n` is normal, because `GL_n(Z)` preserves it.
  - The factors are `Z^n`, `(Q/Z)^n` and `GL_n(Z)`. The last is residually
    finite, so it is Q-free.

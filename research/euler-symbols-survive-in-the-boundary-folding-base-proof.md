**Item 1.**
- *The map.* `(l,u)^l` is generated by the `l^(l−i) u^i`, and `v_𝔭(l^(l−i) π^i) = (l−1)(l−i) + i >= l` for
  `0 <= i <= l`. So `u ↦ π` kills `(l,u)^l`, and `π_0 ↦ ζ`, `π_q ↦ ζ + ql`.
- *`K_2` of the target.* Dennis–Stein §12 (p. 254) gives `K_2(O_K/𝔭^n)` cyclic of order `l^t`, with
  `t = [(n−1)/(l−1)]` clamped to `[0,1]`. This is `1` for `n = l` and for `n = l + 1`. Reduction
  `K_2(O_K/𝔭^(l+1)) -> K_2(O_K/𝔭^l)` is onto, since both groups are generated by symbols of units and units lift. So
  it is an isomorphism of groups of order `l`.
- *The value.* By `euler-ring-symbols-in-small-finite-quotients`, item 2, the image of `{ζ, ζ + ql}` in
  `K_2(O_K/𝔭^(l+1))` has Hilbert symbol `ζ^(-q) ≠ 1`. So it is nonzero there, and hence in `K_2(O_K/𝔭^l)`. ∎

**Item 2.**
- *`τ` is a ring map.* With `E = Φ_l(1 + T)`, the Eisenstein polynomial of `π`, we need `E(π + l) ∈ 𝔭^l`.
  - The Taylor terms are `E^(k)(π) l^k/k!`.
  - For `k = 1`, `v_𝔭 >= (l−2) + (l−1) >= l`, the different of `Q_l(ζ)` being `𝔭^(l−2)`, and `l >= 3`.
  - For `k >= 2`, `v_𝔭(l^k/k!) >= k(l−1) − (l−1)v_l(k!) >= l`.
- *Its order.* `τ^m(π) = π + ml`, and `v_𝔭(ml) = (l−1)(1 + v_l(m)) >= l` exactly when `l | m`. So `τ` has order
  `l`.
- *The quotient map.* `u ↦ π` intertwines `σ` with `τ`, and `l | N`. So `F_(l,N) = C_l ⋊ Z/N -> G_l` is a ring map,
  onto since `π` and `X` generate. `|G_l| = l·|O_K/𝔭^l| = l^(l+1)`.
- *Blindness.* `τ_*` is an automorphism of `Z/l` of order dividing `l`, and `|Aut(Z/l)| = l − 1`. So `τ_* = id`.
  Restriction after induction is `Σ_(i<l) τ^i_* = l = 0`.

**Item 2, the case `l = 3`.**
- *The residue ring.* `π^2 = ζ^2 − 2ζ + 1 = −3ζ`. So in `O_K/𝔭^3`, `3π = 0`, `π^2 = −3` and `9 = 0`, and
  `O_K/𝔭^3 = Z/9 ⊕ (Z/3)π` has order 27. `τ(π) = π + 3` respects `π^2 = −3`, since `6π = 9 = 0`.
- *Units.* `G_3` is local with residue field `F_3`, and `1 + rad(G_3)` has order 27.
  - `ζ^3 = 1`, `X^3 = 1`, and `XζX^(-1) = ζ + 3 = 4ζ`, because `3π = 0`.
  - So `ζ` and `X` generate a Heisenberg group with centre `<4>`. Its elements `ζ^a X^b 4^c` are distinct, by
    comparing the `X`-degree and then the `π`-coefficient.
  - `K_1(G_3) = G_3^x/[G_3^x, G_3^x] = {±1} × (Z/3)^2`, by Vaserstein for local rings with residue field not
    `F_2` (textbook). The integer units `4` and `7 = 4^2` are commutators.
- *The generator.* Dennis–Stein's generator `{1 + uπ, 1 + π^(ℓ−1)}`, with `ℓ = pe/(p−1) = 3`, and `u = 1`, which is
  allowed because `z^3 − z ≡ 0` on `F_3`, is `{ζ, 1 + π^2} = {ζ, −2}`.
- *`c_q`.* `4 = τ(ζ) ζ^(-1)`, so `{ζ, 4} = {ζ, τζ}`, the image of `c_1`. Also `−2 = 4^2`. So `c_1 ↦ z^(1/2) = z^2`,
  and `c_q ↦ z^(±q)` in the same way. ∎

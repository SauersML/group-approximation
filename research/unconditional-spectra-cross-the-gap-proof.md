Notation is as in the claim. On `M_n(C*_r Γ)` write `τ(x) = sum_j τ(x_jj)`. On `K_0` this
gives `τ_*[e] = τ(e)` for idempotents: traces are similarity invariant, and
`τ(x ⊕ 0) = τ(x)`.

**1. Integer traces.**
- Let `e ∈ M_n(A)` be an idempotent.
- By `lafforgue-unconditional-assembly-for-reductive-lie-subgroups`, `mu_A` is surjective, so
  `[e] = mu_A(x)` for some `x`. The quoted identity `mu_r = i_* ∘ mu_A` (for involutive
  subalgebras of `C*_r`) gives `i_*[e] = mu_r(x)`.
- By `assembly-image-traces-are-integral-for-torsion-free-groups`, `τ_*(mu_r(x)) ∈ Z`.
- Since `τ_*(i_*[e]) = τ(i(e))`, we get `τ(i(e)) ∈ Z`.

**2. No idempotents.**
- Let `e ∈ A` be idempotent. In the unital C*-algebra `C*_r(Γ)`, `i(e)` is similar to a
  projection `p = s i(e) s^(-1)` (standard), so `τ(p) = τ(i(e)) ∈ Z` by step 1.
- `0 <= p <= 1` gives `0 <= τ(p) <= 1`.
- `τ` is faithful. If `τ(p) = 0` then `p = 0`. If `τ(p) = 1` then `τ(1 - p) = 0`, so `p = 1`.
- So `i(e) ∈ {0, 1}`, and `e ∈ {0, 1}` because `i` is injective and unital.
- **The algebraic statement.** Take `A = ℓ¹(Γ)`, which contains `C[Γ]`. For a field `k` of
  characteristic zero, an idempotent of `k[Γ]` has finitely many coefficients. They
  generate a finitely generated field, which embeds in `C`, as in
  `rank-one-bcc-implies-charzero-idempotent-proof`.

**3. Gap crossing.**
- Let `K` be the spectrum of `a` in `M_n(A)`, and suppose `L_c ∩ K = ∅`. Then
  `K = K_- ⊔ K_+` with `K_-` in `{Re z < c}` and `K_+` in `{Re z > c}`. If either piece is
  empty the conclusion is `τ ∈ {0, n}`.
- Choose disjoint open sets `U_± ⊇ K_±` inside the two half-planes. Put `f = 1` on `U_-`
  and `f = 0` on `U_+`. Then `f` is holomorphic on `U_- ∪ U_+`, and the Riesz–Dunford
  integral gives an idempotent `e = f(a) ∈ M_n(A)`.
- `M_n(i)` is a continuous unital homomorphism. So the spectrum of `i(a)` lies in `K`, and
  `M_n(i)(f(a)) = f(i(a))`, because the Cauchy integral commutes with continuous
  homomorphisms.
- `i(a)` is self-adjoint and `c` is not in its spectrum, so `f` agrees with `χ_(-∞,c)` on
  that spectrum. Holomorphic and continuous functional calculus agree there, so
  `f(i(a)) = χ_(-∞,c)(i(a))`.
- Step 1 gives `τ(χ_(-∞,c)(i(a))) = τ(M_n(i)(e)) ∈ Z`.

**4. Witness shape.** This is the contrapositive of step 3. For `n = 1`, let `c` lie in a
reduced gap with spectrum on both sides. By `reduced-projection-iff-gapped-spectral-measure`
(`supp μ_a = spec(a)`, faithful trace),
`τ(χ_(-∞,c)(λ(a))) = μ_a((-∞, c)) ∈ (0, 1)`, which is not an integer.

**5. Capacity.** Suppose a witness has `cap(σ_r(a)) < 1`. By
`small-capacity-kk-witnesses-are-algebraic-idempotents` it yields a nontrivial idempotent of
`Qbar[Γ] ⊆ ℓ¹(Γ)`, which step 2 excludes.

**6. Rapid decay subgroups.**
- Let `Λ` be generated by the support of `a`. It is again a torsion-free discrete subgroup of
  a reductive Lie group.
- If `Λ` has (RD) for a length function `ℓ`, then for large `s` the weighted completion
  `H^s_ℓ(Λ)` is an unconditional completion. It is an involutive subalgebra of `C*_r(Λ)`,
  dense, and closed under holomorphic calculus. (Imported from Gomez Aparicio–Julg–Valette
  §6.1.4, which cites Jolissaint and Valette's book, 8.15 and Example 10.5; primary sources
  not read.)
- So the spectrum of `a` in `H^s_ℓ(Λ)` is its spectrum in `C*_r(Λ)`. That equals its
  spectrum in `C*_r(Γ)`, by spectral permanence for C*-subalgebras.
- That spectrum is real, so every `c` outside it has `L_c` missing the `H^s_ℓ` spectrum.
- Step 3 applied to `Λ` makes every reduced spectral projection of `a` have integer trace,
  hence trace `0` or `1`. By step 4 there is no gap.

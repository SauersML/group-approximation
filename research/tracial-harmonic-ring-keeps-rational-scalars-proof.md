Lane proof (gq-deep-adelic-1). The notation is that of the target.
Throughout, `u^k χ_D u^(-k) = χ_(σ^k D)` for clopen `D`.

Two standard facts about an infinite minimal system `(X, σ)` are used throughout.
- `X` has no isolated points: an isolated point has an open orbit, which by minimality is all of
  `X`, so `X` would be countable and hence finite, as a compact space with every point isolated.
  This makes the sets `U_k ∖ U_(k+1)` nonempty along a subsequence, and lets (c) pick `y` outside
  a finite set.
- `σ` has no periodic points: a periodic orbit is closed and invariant, so by minimality it would
  be all of `X`, which is infinite.

## (a) Clopen indicators and Q lie in R_h

- **Clopen sets.** The indicator of `{x : x_t = a}` is `u^(-t) χ_[a] u^t`. Products of these give
  every cylinder. Every clopen subset of `X` is a finite disjoint union of cylinders, so
  `LC(X, Z) ⊆ R_h`. In particular each `χ_(C_m) ∈ R_h`.
- **One denominator on one piece.** `f` equals `1/m` on `C_m`, so `(1/m) χ_(C_m) = χ_(C_m) f ∈ R_h`.
- **Tiling.**
  - By minimality the translates `σ^k(C_m)`, `k ∈ Z`, cover `X`. By compactness finitely many do,
    say `σ^(k_1)(C_m), ..., σ^(k_r)(C_m)`.
  - Put `D'_i = σ^(k_i)(C_m) ∖ ∪_(j<i) σ^(k_j)(C_m)`. These are clopen, disjoint, and cover `X`.
  - Put `D_i = σ^(-k_i)(D'_i) ⊆ C_m`. Then
    `(1/m)·1 = Σ_i (1/m) χ_(D'_i) = Σ_i u^(k_i) (χ_(D_i) · χ_(C_m) f) u^(-k_i) ∈ R_h`.
- **Conclusion.** `1/m ∈ R_h` for every `m >= 1`, so `Q ⊆ R_h`. The element built above is the
  constant function `1/m`, so it lies in the ring `B` of (b).

## (b) Skew Laurent structure

- `B` is the ring generated by `LC(X, Z)` and the translates `f ∘ σ^k`.
  - Every generator is `Q`-valued, so `B ⊆ C(X, Q)`.
  - `B` is `σ`-invariant, and it contains `Q` by (a).
- Products stay in the sum: `(a u^j)(b u^k) = a (b ∘ σ^(-j)) u^(j+k)`. So `⊕_j B u^j` is a ring
  containing every generator, and `R_h ⊆ ⊕_j B u^j`.
- Conversely `B ⊆ R_h`, since `f ∘ σ^k = u^(-k) f u^k`. So the two rings are equal.
- The sum is direct: the coefficient of `u^j` is `E(x u^(-j))`, where `E` is the canonical
  conditional expectation onto `C(X)`.
- `f ∘ σ^k` is locally constant off the single point `σ^(-k) x_∞`. So every element of `B` is
  locally constant off a finite set.

## (c) Simplicity

Let `I` be a nonzero two-sided ideal.

- **A nonzero diagonal coefficient.** Choose `x = Σ_(j ∈ J) a_j u^j ∈ I`, nonzero, with `J`
  finite. Replacing `x` by `x u^(-j_0)`, assume `a_0 != 0`.
- **A good point.** Let `F` be the finite set off which `a_0` is locally constant. Since `a_0` is
  continuous and nonzero, it is nonzero on a nonempty open set, and `X` has no isolated points. So
  pick `y ∉ F` with `a_0(y) != 0`.
- **A good neighbourhood.** `σ` has no periodic points, so `σ^j(y) != y` for `j ∈ J ∖ {0}`. Pick a
  clopen `W ∋ y` such that:
  - `a_0 = r` is constant on `W`, with `r ∈ Q^x` (possible because `y ∉ F`);
  - `σ^j(W) ∩ W = ∅` for every `j ∈ J ∖ {0}`.
- **Compression.** `χ_W x χ_W = Σ_j χ_W a_j χ_(σ^j W) u^j = r χ_W`. So
  `χ_W = r^(-1) χ_W x χ_W ∈ I`, because `r^(-1) ∈ Q ⊆ R_h`.
- **Tiling again.** As in (a), `X = ⊔_i σ^(k_i)(D_i)` with clopen `D_i ⊆ W`. So
  `1 = Σ_i u^(k_i) (χ_(D_i) χ_W) u^(-k_i) ∈ I`, and `I = R_h`.

## (d) Centre

Let `z = Σ_j a_j u^j` be central.

- **Off-diagonal coefficients vanish.**
  - For clopen `W`, `z χ_W = Σ_j a_j χ_(σ^j W) u^j` and `χ_W z = Σ_j χ_W a_j u^j`.
  - Comparing coefficients gives `a_j (χ_(σ^j W) - χ_W) = 0`.
  - Fix `j != 0` and a point `y`. Then `σ^(-j) y != y`, so choose `W ∋ y` with `σ^(-j) y ∉ W`.
    Now `χ_W(y) = 1` and `χ_(σ^j W)(y) = 0`, so `a_j(y) = 0`. Hence `z = a_0 ∈ B`.
- **The diagonal coefficient is constant.** `u z = z u` gives `a_0 ∘ σ^(-1) = a_0`. A continuous
  invariant function on a minimal system is constant, and `a_0` is `Q`-valued, so `z ∈ Q`.
- Conversely `Q` is central.

## (e) Rational scalars and the Fuglede–Kadison determinant

- **A faithful trace.**
  - Let `μ` be an ergodic `σ`-invariant Borel probability measure. One exists: Krylov–Bogolyubov,
    then an extreme point of the invariant measures.
  - `μ` has full support, since its support is closed, invariant and nonempty.
  - So `τ = μ ∘ E` is a faithful tracial state on `A`.
- **A II_1 factor.** The GNS representation of `τ` is faithful on `A`. Its weak closure
  `M ≅ L^∞(X, μ) ⋊ Z` is a II_1 factor, because the action is free (no periodic points) and
  ergodic. This is the Murray–von Neumann group measure space construction (standard, not
  re-read).
- **Embedding.** So `R_h ⊆ A ⊆ M` unitally and injectively. Then `GL_N(R_h) ≤ GL(M_N(M))`, and
  `M_N(M)` is a II_1 factor with normalized trace `τ_N`.
- **The determinant.** Fuglede–Kadison, as quoted below:
  `Δ(X) = exp τ_N(log (X^* X)^(1/2))` on invertible `X`, with `Δ(XY) = Δ(X) Δ(Y)`. So `Δ` is a
  homomorphism into the abelian group `R_(>0)`, and it is trivial on commutators.
- **E_N is perfect.** For distinct `i, k, j` in `[N]` (here `N >= 3` is used),
  `e_ij(r) = [e_ik(r), e_kj(1)]`. So `E_N(R_h)` is perfect, and `Δ` is trivial on it.
- **Scalars.** `Δ(λ I_N) = exp log|λ| = |λ|`. If `λ I_N ∈ E_N(R_h)` then `|λ| = 1`, so `λ = ±1`.

**Alternative, without operator algebras (remark).** ABC Theorem 3.6
(`abc-twisted-laurent-k-theory-fibration`) gives `coker(1 - σ_* : K_1(B) -> K_1(B))` inside
`K_1(R_h)`. A unit `b ∈ B` with `b / (b ∘ σ^(-1)) = λ` would give
`∫ log|b| dμ = log|λ| + ∫ log|b| dμ`, so `|λ| = 1`. This is not needed above.

## (f) Part 5

- **E_N(R_h) is finitely generated.** Let `S` generate `R_h` as a ring and let `H` be generated by
  the `e_ij(±s)`, `s ∈ S ∪ {1}`. The set of `r` with `e_ij(r) ∈ H` for all `i != j` is closed
  under sums, and under products by `[e_ij(a), e_jk(b)] = e_ik(ab)` (`N >= 3`). So it is a subring
  containing `S`, which is all of `R_h`.
- **The rest.** Parts 2 and 4 of `q-algebra-elementary-quotients-contain-gl-n-q` apply because
  `Q ⊆ R_h` unitally, and `Z(E_N(R_h)) = E_N ∩ Z(R_h)^x I ⊆ {±I}` by (d) and (e).

## Source quoted

Fuglede–Kadison determinant, as stated in the Wikipedia article "Fuglede–Kadison determinant"
(fetched 2026-09-17), verbatim: "Δ(X) := exp τ(log(X*X)^1/2)" for invertible `X` in a finite
factor with normalized trace `τ`, and "Δ(XY) = Δ(X)Δ(Y)". The original source cited there is
B. Fuglede and R. V. Kadison, "Determinant theory in finite factors", Ann. of Math. (2) 55 (1952),
no. 3, 520–530. It was not re-read at the primary source.

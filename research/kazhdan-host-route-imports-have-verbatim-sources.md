**OPEN.** This is the citation gap found at audit (2026-09-17) in the route
`amenable-purely-infinite-groupoid-kazhdan-host-proof`. The mathematics of that route
was checked and holds; what is missing is source text for two imports.

**Claim.** Both of the following are supported by verbatim citations whose hypotheses
match the use made of them in the host route.

1. **Exact implies an amenable compact model.** If a countable discrete group `Γ` has
   exact reduced C*-algebra (equivalently, Yu's property A), then `Γ` admits a
   topologically amenable action on a compact metrizable space. The source must state
   the notion of exactness it uses, and it must match what the route supplies for
   `Γ = Z^3 ⋊ SL_3(Z)` (property A via Guentner–Tessera–Yu, C*_r exactness via Osajda).
   Likely references, not verified: Ozawa (2000), Higson–Roe (2000), Brown–Ozawa,
   *C*-algebras and finite-dimensional approximations*, Theorem 5.1.7.
2. **(T) plus Haagerup is finite.** A countable group with property (T) and the Haagerup
   property is finite. Likely reference, not verified: Cherix–Cowling–Jolissaint–Julg–
   Valette, *Groups with the Haagerup property*, which relies on Delorme–Guichardet.

Once both quotes are recorded (for instance by strengthening the source records of
`stw40-unital-nuclear-no-trace-iff-exact` and `thompson-v-has-haagerup-property`), this
claim can be closed by a citation route and the host route re-refereed.

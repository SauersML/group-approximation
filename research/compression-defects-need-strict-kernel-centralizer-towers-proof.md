Notation is that of the claim. Throughout, `s in Comp_G(L)`, so `s L s^-1 <= L`, and
`M = C_K(L)`.

## Step 0: the always-true inclusions (CT0)

- Since `K` is normal, `s C_K(X) s^-1 = C_K(s X s^-1)` for every `X <= G`.
- Since `s L s^-1 <= L`, anything centralizing `L` centralizes `s L s^-1`. So
  `M = C_K(L) <= C_K(s L s^-1) = s M s^-1`.
- The same argument in `G` gives `C_G(L) <= C_G(s L s^-1) = s C_G(L) s^-1`.

## Step 1: the commutator lands in the conjugated kernel centralizer

Let `z in C_G(L)` and put `w = [s,z] = s z s^-1 z^-1`.

- `w in K`, because `G/K` is abelian.
- `s z s^-1` centralizes `s L s^-1`.
- `z^-1` centralizes `L`, which contains `s L s^-1`.

So `w in K ∩ C_G(s L s^-1) = C_K(s L s^-1) = s M s^-1`.

## Step 2: the exact criterion (item 1)

*If.* Suppose `s M s^-1 = M` for every compressor `s`. Let `z in C_G(L)`.
- By Step 1, `w = [s,z] in M <= C_G(L)`.
- So `s z s^-1 = w z in C_G(L)`, and hence `s C_G(L) s^-1 <= C_G(L)`.
- With (CT0), `s C_G(L) s^-1 = C_G(L)`. Taking inverses, `s^-1` also normalizes `C_G(L)`.

So the group `G_comp(L)` generated by the compressors normalizes `C_G(L)`. Every generator
`[g z g^-1, l]` of the defect then commutes an element of `C_G(L)` with an element of `L`, so it
is `1`. Hence `D_G(L) = 1`.

*Only if.* Suppose `D_G(L) = 1`. Then `g z g^-1` centralizes `L` for all `g in G_comp(L)` and
`z in C_G(L)`.
- So `g C_G(L) g^-1 <= C_G(L)` for all `g in G_comp(L)`.
- The set `G_comp(L)` is closed under inverses, so equality holds and `G_comp(L)` normalizes
  `C_G(L)`.
- Intersecting with the normal subgroup `K` gives `s M s^-1 = M` for every compressor `s`.

The two normalization statements are therefore both equivalent to `D_G(L) = 1`.

## Step 3: the forced tower (item 2)

Suppose `D_G(L) != 1`. By Step 2 some compressor `s` has `s M s^-1 != M`, and by (CT0) the
inclusion `M < s M s^-1` is strict.

- **Strict compression of `L`.** If `s L s^-1 = L`, then `s M s^-1 = C_K(s L s^-1) = M`, a
  contradiction.
- **Strict tower.** Conjugation by `s^j` preserves strict inclusion. So
  `s^j M s^-j < s^(j+1) M s^-(j+1)`, and `s^j M s^-j = C_K(L_j)` with `L_j = s^j L s^-j`. These
  `L_j` are nested, by induction from `s L s^-1 <= L`.
- **Dual compression.** Conjugating `M < s M s^-1` by `s^-1` gives `s^-1 M s < M`.
- **The union.** `M_inf` is the union of a strictly ascending chain. A finite generating set would
  lie in one stage `s^j M s^-j`, which would then equal `M_inf` and contradict strictness. Each
  stage `C_K(L_j)` centralizes `L_j`, which contains `L_inf`.

## Step 4: finite outer order (item 3)

Take `s` as in Step 3. Suppose the automorphism `Ad(s)|_K` has order `n >= 1` in `Out(K)`.
- Then `Ad(s^n)|_K = Ad(gamma)` for some `gamma in K`.
- `gamma L gamma^-1 = s^n L s^-n <= L`.
- Conjugating (CT0) by powers of `s` gives
  `M < s M s^-1 <= s^2 M s^-2 <= ... <= s^n M s^-n = gamma M gamma^-1`.
- Strictness of `gamma L gamma^-1 < L` follows as in Step 3.

## Step 5: tame kernels kill every Kazhdan defect

Let `K` be tame and `G/K` torsion-free abelian, and let `L <= G` be Kazhdan.
- A Kazhdan group has finite abelianization. So the image of `L` in the torsion-free abelian
  group `G/K` is finite, hence trivial, and `L <= K`.
- If `D_G(L) != 1`, Step 3 gives a descending chain `L_j` of Kazhdan subgroups of `K` (conjugates
  of `L`) whose centralizers `C_K(L_j)` ascend strictly forever. This contradicts tameness.

## Step 6: subgroups of finite products of KCF and linear groups are tame

Let `H <= K_1 x ... x K_r`, with coordinate projections `pi_i`. Let `L_0 >= L_1 >= ...` be Kazhdan
subgroups of `H`.
- An element `z = (z_i)` of `H` centralizes `X` exactly when each `z_i` centralizes `pi_i(X)`. So
  `C_H(L_j) = H ∩ prod_i C_(K_i)(pi_i L_j)`, and it suffices that each coordinate chain
  `C_(K_i)(pi_i L_j)` is eventually constant.
- `pi_i L_j` is a quotient of a Kazhdan group, so it is Kazhdan, and it descends in `j`.
- *KCF factor.* `C_(K_i)(pi_i L_j)` is `1` while `pi_i L_j != 1`, and `K_i` once `pi_i L_j = 1`.
  Later terms inherit triviality of `pi_i L_j`. So the chain changes at most once.
- *Linear factor* `K_i <= GL_m(F)`. `C_(K_i)(X) = K_i ∩ C_(M_m(F))(X)`, where `C_(M_m(F))(X)` is
  a linear subspace. Along the descending chain these subspaces ascend. So they change at most
  `m^2` times, and the intersections with `K_i` change only when they do.

Hence `C_H(L_j)` is eventually constant, and `H` is tame.

**Non-KCF check.** If `K_1` and `K_2` are nontrivial Kazhdan groups, then in `K_1 x K_2` the
Kazhdan subgroup `K_1 x 1` has centralizer containing `1 x K_2`. So (AX) of
`abelian-extensions-kill-kcf-compression-defects` fails there, while Step 5 still applies.
Consequently, for `K_1` and `K_2` Titz Mite--Witzel kernels (KCF), every Kazhdan compression
defect vanishes in every mapping torus `(K_1 x K_2) semidirectProduct_phi Z`, for any `phi`.
This includes factor swaps when `K_1 = K_2`, and every torsion-free abelian extension such as `(K_1 x K_2) x Z^d`.

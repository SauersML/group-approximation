**OPEN.** For every group `B` generated by a bounded automaton over a finite alphabet, there is a finitely
presented group `P` generated by a finite automaton (finite, section-closed state set) with `B ↪ P`.

## Why it matters

- By `separated-automata-reduce-bh-to-fp-overgroups-of-the-base`, it makes every separated automaton group of
  linear activity Boone–Higman through a self-similar host, including every test case of this lane
  (spine-Grigorchuk, `M(Γ)`).
- Bounded automaton groups are contracting, so they are already Boone–Higman themselves
  (`rover-nekrashevych-finite-presentation-criteria`, FP2). The point is a host that is again an automaton
  group, so that it can serve as a base one degree up.

## Known constraints

- `P` is residually finite (it acts on a rooted tree). So Grigorchuk's finitely presented ascending HNN extension of
  `Γ`, which is not residually finite (Sapir–Wise 2002; Grigorchuk), is excluded.
- Every finitely presented automaton group has finitely presented germ groups at every closed stable family of
  rays (`nekrashevych-fp-iff-cycle-germ-groups-fp`, necessity via Scott FP1). So `P` must realize `Γ` without
  creating non-fp germs.
- Finitely presented automaton groups that contain infinite torsion subgroups are not recorded on main. The
  Grigorchuk group is the first test.

Notation is that of the claim. Matrices act on rows from the right, so a `k × n` matrix `A`
over `Q[G]` gives a map of left modules `R^k → R^n` for every ring `R` receiving `Q[G]`. Its rank
over `U = U(G)` is `rk_U(A) = dim_U im(U^k → U^n)`. For a subgroup `J ≤ G` and `A` over `Q[J]`,
`rk_{U(G)}(A) = rk_{U(J)}(A)` (Lück's induction formula: `U(G) ⊗_{U(J)} −` preserves `dim`).

## Item 1

*`rk_ε <= rk_φ`.* `ε = ev_{t=1} ∘ φ`. A `k × k` minor of `φ(A)` that is nonzero at `t = 1` is a
nonzero element of `Λ`, so `rank_Q ε(A) <= rank_{Q(t)} φ(A)`.

*(i) ⇒ (ii).* For locally indicable `G`, the division closure `D(G)` of `Q[G]` in `U(G)` is a
Hughes-free division ring (Jaikin-Zapirain–López-Álvarez), and it is the universal division
`Q[G]`-ring (Jaikin-Zapirain 2021). Both are recalled imports of
`flat-weak-bass-holds-exactly-for-locally-indicable-groups`. The map `Q[G] → Λ ⊂ Q(t)` is epic,
because `Q(t)` is the division ring generated by `Λ = φ(Q[G])`. By Cohn's specialization
property, a square matrix over `Q[G]` that is invertible over `Q(t)` is invertible over
`D(G)`. The rank of a matrix over a division ring is the largest size of an invertible square
submatrix, so `rk_φ(A) <= rank_{D(G)}(A)`. Finally `rank_{D(G)}(A) = rk_U(A)`, since `D(G)` is
a division subring of `U(G)` and `dim_U(U ⊗_{D(G)} D(G)^s) = s`.

*(ii) ⇒ (iii)* follows from `rk_ε <= rk_φ`. *(iii) ⇒ (i)* is item 1, (ii) ⇒ (i), of
`flat-weak-bass-holds-exactly-for-locally-indicable-groups`. For torsion-free `G` it is also the
Fox argument of item 2(b) below, applied to a finitely generated `J ≤ G`, `J ≠ 1`, with
`H_1(J; Q) = 0`.

*(ii) ⇒ (iv)* is restriction.

*(iv) ⇒ (v).* For `A` over `Q[L]`, `φ(A) = ε_L(A)`, since `φ` kills `L`. Also
`rk_{U(G)}(A) = rk_{U(L)}(A)`. So (iv) is RD(L, ε), and (iii) ⇒ (i) for the group `L` gives
that `L` is locally indicable.

*(v) ⇒ (i).* Let `J ≤ G` be finitely generated with `J ≠ 1`. If `φ(J) ≠ 0`, then `φ|_J` maps
onto `φ(J) ≅ Z`. Otherwise `J ≤ L`, and `J` maps onto `Z` because `L` is locally indicable.

## Item 2

*(a).* Suppose `L` were locally indicable. By (v) ⇒ (i), `H` is locally indicable. It is also
amenable of cd `<= 2`, and `H ≠ 1` because it has finite index in the infinite group `K`. By
`amenable-cd-two-kropholler-iff-locally-indicable`, `H` is `Z`, a noncyclic subgroup of `Q`, or
`BS(1, m)`. Each of these has `b_2 <= 1` and `χ_Q = 0`. But `b_1(K) = 0`, so
`χ_Q(K) = 1 + b_2(K) >= 1`. If `b_2(K) < ∞`, multiplicativity (target item 3) gives
`χ_Q(H) = [K:H] χ_Q(K) >= 1`, a contradiction. If `b_2(K) = ∞`, then `b_2(H) >= b_2(K) = ∞` by
transfer, again a contradiction.

So `L` is not locally indicable. Take a finitely generated `J ≤ L` with `J ≠ 1` and no
epimorphism onto `Z`. Then `H_1(J; Z)` is a finitely generated abelian group with no free part,
hence finite, and `H_1(J; Q) = 0`. `J` is amenable and torsion-free, and `cd J <= 2`. If
`cd J = 1`, then `J` is free and nontrivial by Stallings–Swan, so `b_1(J) >= 1`, which is
impossible. So `cd J = 2`, and `J` is a finitely generated amenable group of cd 2 with finite
abelianization. The same holds for every such `J`.

*(b).* Write `J = F(s_1, …, s_m)/R`. The exponent-sum map `R → Z^m` has image
`ker(Z^m → J^{ab})`, which has finite index because `J^{ab}` is finite. So there are
`w_1, …, w_m ∈ R` with linearly independent exponent-sum vectors. Put `C = (∂w_i/∂s_j)`, the
Fox matrix, mapped into `Z[J]`. Then `ε(∂w_i/∂s_j)` is the exponent sum of `s_j` in `w_i`, so
`det ε(C) ≠ 0`. The entries of `C` lie in `Z[L]`, so `φ(C) = ε(C)` is invertible over `Q(t)`,
and `rk_φ(C) = m`.

The fundamental formula of Fox calculus gives `Σ_j (∂w_i/∂s_j)(s_j − 1) = w_i − 1 = 0` in
`Z[J]`. So the column `v = (s_1 − 1, …, s_m − 1)^T` satisfies `C v = 0`. Some `s_j ≠ 1`, and it
has infinite order because `J` is torsion-free. So `s_j − 1` is invertible in `U(⟨s_j⟩) ⊂ U`,
since it is a nonzero element of `Q[Z]`. So `x ↦ v x` is injective `U → U^m`, and the kernel
of `C` on columns contains a copy of `U`. Since the rank of `C` does not depend on the side it
acts on (`dim_U` of image equals `m − dim_U` of kernel on either side, using the involution
`A ↦ A^*` and `rk_U(A) = rk_U(A^*)`), `rk_U(C) <= m − 1 < m = rk_φ(C)`.

*(c).* An argument of the stated kind, applied to `C`, would give `rk_φ(C) <= rk_U(C)`, which
(b) contradicts. `C` has entries in `Q[L]` and `φ(C)` has no `t`-dependence. So neither
averaging along `t`, nor localizing `Λ`, nor passing to `Q(t)` changes the comparison.

## Item 3

*`Z ≀ Z`.* `L = ⊕_{i ∈ Z} Z e_i`, with `t e_i = e_{i+1}`. `H_1(L; Q) = Q^{(Z)} = Λ`, so
`ρ_1 = 1`. `H_2(L; Q) = Λ²_Q(Q^{(Z)})` has basis `e_i ∧ e_j` with `i < j`, and `t` preserves
`d = j − i`. For each `d >= 1`, the vectors `e_i ∧ e_{i+d}` span a free `Λ`-module of rank 1. So
`H_2(L; Q) ≅ Λ^{(N)}` and `ρ_2 = ∞`. `Z ≀ Z` is amenable (metabelian) and locally indicable: a
finitely generated `J ≠ 1` either maps onto the top `Z` or lies in the free abelian group `L`.
So RD holds by (i) ⇒ (ii). Its cd is infinite, since `L` contains `Z^k` for every `k`.

*`F_2 × F_2`.* `ρ_2 − ρ_1 = 1` is the last row of the calibration table of
`cd-two-z-kernels-have-zero-or-free-alexander-h2`. A product of locally indicable groups is
locally indicable, since a finitely generated `J ≠ 1` has a nontrivial finitely generated
projection to one factor. So RD holds. Here `dim_U(U ⊗ P) = n − 1 + b_2^{(2)} − b_1^{(2)} = n`,
and the bound of item 4 becomes `r <= n`, which does not force `χ <= 0`.

The third case is items 1 and 2.

## Item 4

`P` is a countable projective module (a submodule of `Q[H]^n`, over a countable ring), so
`P ⊕ P'' ≅ F = Q[H]^{(N)}` for some `P''`: choose an epimorphism `F → P`. It splits because `P`
is projective, and `P''` is its kernel. Fix a finite `r' <= r = rank_Λ(Λ ⊗ P)`. Choose
`Λ`-independent `e_1, …, e_{r'} ∈ Λ ⊗ P`. Every element of `Λ ⊗_{Q[H]} P` has the form `1 ⊗ p`,
because `Λ` is a quotient of `Q[H]`. So `e_j = 1 ⊗ p_j` with `p_j ∈ P ⊂ F`. The `p_j` involve
finitely many coordinates `1, …, N'`, and form the rows of an `r' × N'` matrix `B` over
`Q[H]`.

`Λ ⊗ P → Λ ⊗ F` is split injective, so the rows of `φ(B)` are `Λ`-independent in `Λ^{N'}`,
and so `Q(t)`-independent. So `rk_φ(B) = r'`. RD for `B` gives `rk_U(B) >= r'`. The image of
`U^{r'} → U^{N'}` under `B` is the `U`-span of the images of the `p_j`, which lies in the image
of `U ⊗ P → U ⊗ F`. That map is injective because `P` is a summand. So
`rk_U(B) <= dim_U(U ⊗ P)`.

By item 2 of `amenable-cd-two-bass-defect-equals-euler-characteristic`, `D(P) = χ_Q(H)`, i.e.
`dim_U(U ⊗ P) = r − χ = n − 1` (`H` infinite amenable). So `r' <= n − 1` for every finite
`r' <= r`. Hence `r <= n − 1`, so `b_2 < ∞` and `χ_Q = r − (n − 1) <= 0`. Then
`ρ_2 − ρ_1 = χ_Q <= 0` by item 2 of `cd-two-z-kernels-have-zero-or-free-alexander-h2`.

Conversely, `rank_Λ(Λ ⊗ P) = r` (item 1 of that node). So the inequality
`rank_Λ(Λ ⊗ P) <= dim_U(U ⊗ P)` says exactly `χ_Q <= 0`. Applied to the core `P'` of `P`, it is
the inequality of `l2-finite-projectives-over-amenable-groups-satisfy-weak-bass`, since
finitely generated summands have defect 0 there. By items 1–2, RD for all matrices over `Q[L]`
fails in every counterexample. So the matrices `B` of this item must be special, built from rows
of a projective summand, for the comparison to hold.

## Calibrations

- `Z²`: `Q[Z²]` is a commutative domain. The determinant gives
  `rk_φ = rank_{Q(t)} φ <= rank_{Frac} = rk_U`.
- `HW × Z`: `L = HW` is torsion-free, amenable and not locally indicable (`b_1(HW) = 0`). So (iv)
  fails, by the Fox matrix of item 2(b) for `J = HW`. `Q[HW × Z]` is an Ore domain
  (Kropholler–Linnell–Moody, elementary amenable), so Ore localization does not by itself give
  RD.

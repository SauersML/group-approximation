title: "Zaremsky's Problem 1.19 for n = 1: if a finite-index subgroup of a right-angled Artin group maps onto Z with finitely generated kernel, so does the group"
distinct_from:
  raag-virtual-fn-kernel-implies-raag-fn-kernel: that is the conjecture for every n; this is its case n = 1, which is proved.

Let `L` be a finite flag complex and `H ≤ A_L` of finite index. If some epimorphism
`H → Z` has finitely generated kernel, then `L` is connected and the Bestvina--Brady
kernel `BB_L = ker(A_L → Z, v ↦ 1)` is finitely generated. So the conjecture of Zaremsky's
Problem 1.19 holds for `n = 1`.

The case `n = 1` of Problem 1.19 is not a separate root; the root's affirmative answer
needs every `n` (see `zaremsky-1-19-raag-virtual-fn-kernel-conjecture`).

The notation is that of the target. Vertices are identified with their images
under automorphisms. For an oriented edge `f = (x, y)`, `Y_f` is the set of vertices
whose geodesic to `x` passes through `y`. An automorphism fixing `x` and `y`
preserves `Y_f`.

**0. Two remarks on regularity.**

- **(R1) Transport of balls.** If `g = h` on `B_ρ(v)` with `h ∈ Aut(T)`, then
  `g(B_ρ(v)) = h(B_ρ(v)) = B_ρ(gv)`.
- **(R2) Uniqueness.** If `v` is regular for `g`, the element `h ∈ G` agreeing with `g`
  on `B_ρ(v)` is unique. Two such `h, h'` agree on the adjacent vertices `v` and `w`
  for any neighbour `w` of `v` (which exists, as `ρ ≥ 1` and `T` has an edge), so
  `h^{-1}h'` fixes two adjacent vertices and is `1`.

  If `v`, `w` are adjacent and both regular, with elements `h_v`, `h_w`, then both
  agree with `g` on `{v, w} ⊆ B_ρ(v) ∩ B_ρ(w)`, so `h_v = h_w`. Hence on each
  connected component of the regular vertices `g` agrees with one element of `G`.
  This is the "finitely many pieces" description of `Γ(G, ρ)`. It is not used below.

**1. Item 1.**

- **Products.** Let `v ∉ Sing(h)` with `h = k` on `B_ρ(v)`, `k ∈ G`, and
  `hv ∉ Sing(g)` with `g = k'` on `B_ρ(hv)`, `k' ∈ G`. By (R1),
  `h(B_ρ(v)) = B_ρ(hv)`, so `gh = k'k` on `B_ρ(v)`, and `k'k ∈ G`. So `v` is regular
  for `gh`. Contrapositively `Sing(gh) ⊆ Sing(h) ∪ h^{-1} Sing(g)`.
- **Inverses.** If `g = k` on `B_ρ(v)`, then by (R1) `g^{-1} = k^{-1}` on
  `B_ρ(gv) = g B_ρ(v)`. So `gv` is regular for `g^{-1}` whenever `v` is regular for
  `g`. That gives `Sing(g^{-1}) ⊆ g Sing(g)`, and applying it to `g^{-1}` gives
  equality.
- **Group.** `Sing(h) = ∅` for `h ∈ G`, since `h` agrees with itself. So `Γ(G, ρ)` is
  closed under products and inverses and contains `G`.
- **Property (P) for `ρ = 1`.** Let `g ∈ Γ(G, 1)` fix `x` and `y`, where `f = (x, y)`.
  Define `p = g` on `Y_f` and `p = id` off `Y_f`.
  - `p` is a bijection of the vertex set, since `g` preserves `Y_f`.
  - `p` preserves adjacency: edges inside `Y_f` or inside its complement clearly,
    and the only edge between them is `f`, fixed by `g` and by `id`.
  - For `v ∈ Y_f \ {y}`, every neighbour of `v` lies in `Y_f`, so `p = g` on `B_1(v)`
    and `v` is regular for `p` if it is regular for `g`.
  - For `v ∉ Y_f`, `v ≠ x`, every neighbour of `v` lies off `Y_f`, so `p = id ∈ G` on
    `B_1(v)`.
  - Hence `Sing(p) ⊆ Sing(g) ∪ {x, y}` is finite, and `p ∈ R(Y_f)`.
  - The same holds for `q = p^{-1} g`, which is `g` off `Y_f` and `id` on `Y_f`, and
    `q ∈ R(Y_{f̄})`. So `Γ(G, 1)_f = R(Y_f) · R(Y_{f̄})`, which is (P).
  - No local finiteness was used. For `ρ ≥ 2` and infinite valence the balls
    `B_ρ(x)` are infinite and this argument gives no finiteness; (P) is not claimed
    there.

**2. Item 2 (rigidity).** Let `Y = Y_{f'}` with `f' = (x', y')`, and let `r` fix every
vertex off `Y`. Suppose every vertex of `Y` is regular for `r`. We show `r = 1`.

- `r` fixes `x'` and permutes its neighbours. It fixes all of them except possibly
  `y'`, so it fixes `y'`.
- **Induction.** For `w ∈ Y` let `w^-` be its neighbour on the geodesic to `x'`
  (so `(y')^- = x'`). Suppose `r` fixes `w` and `w^-`. Since `w` is regular, some
  `h ∈ G` agrees with `r` on `B_ρ(w) ⊇ B_1(w)`. Then `h` fixes the adjacent vertices
  `w` and `w^-`, so `h = 1` because `G` is edge-free. So `r` fixes every neighbour of
  `w`.
- By induction on the distance from `y'`, `r` fixes every vertex of `Y`. It fixes
  every vertex off `Y` by assumption, so `r = 1`.

So a nontrivial `r ∈ R(Y)` has a singular vertex in `Y`.

**3. Item 3 (filtration).** Let `σ` be a vertex, or an edge whose two endpoints are
fixed. Every `h ∈ Γ_σ` is an isometry fixing `σ`, so `d_σ(hu) = d_σ(u)`.

- For `g, h ∈ Γ_σ`, item 1 gives `Sing(gh) ⊆ Sing(h) ∪ h^{-1} Sing(g)`, and
  `h^{-1}` preserves `d_σ`. So `D(gh) ≤ max(D(g), D(h))`. Also
  `D(g^{-1}) = D(g)`, because `Sing(g^{-1}) = g Sing(g)`. Put `D(g) = −1` when
  `Sing(g) = ∅`.
- So each `Γ_σ^{(k)} = {g ∈ Γ_σ : D(g) ≤ k}` is a subgroup. They increase with `k`,
  and their union is `Γ_σ`, since singular sets are finite.
- If `H ≤ Γ_σ` is generated by `s_1, ..., s_m`, then `H ≤ Γ_σ^{(k)}` with
  `k = max_i D(s_i)`.
- Let `Y` be a half-tree all of whose vertices are at distance `> k` from `σ`, and
  `r ∈ H ∩ R_Γ(Y)`. Every singular vertex of `r` is at distance `≤ k` from `σ`, so
  none lies in `Y`. By item 2, `r = 1`.

**4. Item 4.** Assume the hypotheses: (M) minimal, no fixed end, not a line; (N)
some `R_Γ(Y_0) ≠ 1`. `Γ` acts faithfully, being a group of automorphisms.

- **Reduction to an action without inversions.** The cited results of
  `micro-supported-tree-actions-self-embed-rigid-stabilizers` (Lemma A, and the
  transport of its item 1) assume an action without inversions, while `Γ ≤ Aut(T)`
  may invert edges. Let `Γ_0 ≤ Γ` be the type-preserving subgroup (elements preserving
  the bipartition of `T`). It is normal of index `≤ 2`, acts without inversions, and
  `Γ_0 ≤ Γ(G, ρ)`. An automorphism fixing a vertex preserves the parity of distances,
  so `Γ_0` contains every vertex stabilizer, edge stabilizer and rigid stabilizer of
  `Γ`: `(Γ_0)_v = Γ_v`, `(Γ_0)_f = Γ_f` and `R_{Γ_0}(Y) = R_Γ(Y)`. In particular
  (N) holds for `Γ_0` and `Γ_0 ≠ 1`. `Γ_0` satisfies (M):
  - If `Γ_0` has no hyperbolic element, then (acting without inversions) it fixes a
    vertex or fixes a unique end. In the first case its fixed subtree is nonempty and
    `Γ`-invariant, since `Γ_0` is normal, so it is `T` by minimality and `Γ_0 = 1`,
    a contradiction. In the second case that end is `Γ`-fixed, contradicting (M).
  - So `Γ_0` has hyperbolic elements, and its minimal invariant subtree (the union of
    their axes) is unique, hence `Γ`-invariant, hence `T`.
  - If `Γ_0` fixed an end, its fixed ends would number one (then `Γ`-fixed, contrary
    to (M)) or two (then every hyperbolic axis is the line joining them and `T`, the
    union of the axes, is a line, contrary to (M)).

  The statements of item 4 are about `Γ_v`, `Γ_f` and `R_Γ(Y)`, which are unchanged,
  so we may and do replace `Γ` by `Γ_0` below.

- **Deep half-trees.** Let `Z = Y_f` with `f = (x, y)`, let `σ` be a finite set of
  vertices and `k ≥ 0`. We find a half-tree `Y ⊆ Z` with `d(u, σ) > k` for all
  `u ∈ Y`.
  - By Lemma A of `micro-supported-tree-actions-self-embed-rigid-stabilizers-proof`,
    `Z` contains the axis `L` of a hyperbolic element. Let `q` be the vertex of `L`
    closest to `x`.
  - Choose an edge `f'' = (x'', y'')` of `L` with `y''` farther from `q` than `x''`
    and `d(q, x'') > k + max_{s ∈ σ} d(q, s)`. Put `Y = Y_{f''}`.
  - The geodesic from `q` to `x''` runs along `L` and misses `y''`, so `q ∉ Y`. For
    `u ∈ Y` the geodesic `[u, q]` therefore crosses `f''` and passes `x''`. So
    `d(u, s) ≥ d(u, q) − d(q, s) ≥ d(x'', q) − d(q, s) > k` for every `s ∈ σ`.
  - `[x, q]` meets `L` only at `q`, and `[q, u]` leaves `q` along `L`. So
    `[x, q] ∪ [q, u]` is the geodesic from `u` to `x`, and it passes `q ∈ Z`. The
    geodesic from `q` to `x` passes `y`, so the geodesic from `u` to `x` does, and
    `u ∈ Z`. Hence `Y ⊆ Z`.
- **Nontriviality.** By item 1 of `micro-supported-tree-actions-self-embed-rigid-stabilizers`
  (transport), `R_Γ(Y) ≠ 1` for every half-tree `Y`.
- **Rigid stabilizers.** Let `Z = Y_f`, `f = (x, y)`, and `σ = f`. Then
  `R_Γ(Z) ≤ Γ_f`, since its elements fix `x` and hence `y`. If `R_Γ(Z)` were
  generated by finitely many elements, item 3 would give `k` with
  `R_Γ(Z) ∩ R_Γ(Y) = 1` for all half-trees `Y` beyond depth `k`. But the deep
  `Y = Y_{f''} ⊆ Z` above satisfies `1 ≠ R_Γ(Y) ≤ R_Γ(Z)`. Contradiction.
- **Edge stabilizers.** Same argument with `H = Γ_f ⊇ R_Γ(Y_f)`.
- **Vertex stabilizers.** Let `σ = v`, and let `Z` be any half-tree not containing
  `v` (it exists since `T` is not a single vertex). The deep `Y ⊆ Z` satisfies
  `1 ≠ R_Γ(Y) ≤ Γ_v`, since elements of `R_Γ(Y)` fix `v`. If `Γ_v` were finitely
  generated, item 3 would give `R_Γ(Y) = Γ_v ∩ R_Γ(Y) = 1`. Contradiction.
- The last sentence of item 4 is item 3.

**5. Item 5.** Suppose `Γ ≤ Γ(G, ρ)` for some edge-free `G` and some `ρ`, the action
satisfies (M) and (P), and some edge stabilizer `Γ_f ≠ 1` is finitely generated.
By (P), `Γ_f = R_Γ(Y_f) R_Γ(Y_{f̄})`, so one of the two rigid stabilizers is
nontrivial, and (N) holds. Item 4 says `Γ_f` is not finitely generated.
Contradiction. ∎

**6. The calibrations of the target.**

- **Le Boudec's groups.** With a legal colouring of `T_d` and `F` semiregular,
  `U(F)` is edge-free: an element fixing `u` and a neighbour has local action at `u`
  in `F` fixing a colour, hence trivial, so it fixes the star of `u`; repeating along
  the tree, it is `1`. If `g` has local action `α ∈ F` at `v`, the element of `U(F)`
  sending `v` to `gv` with local action `α` at every vertex agrees with `g` on
  `B_1(v)`. So off the finite set where the local action is not in `F`, `g` is
  regular, and `G(F, F') ≤ Γ(U(F), 1)`. The same argument works for a countable
  colour set `S` and `F` acting freely on `S`. Property (P) for these groups: the
  piece `p` of item 1 has trivial local action at `x` and local action `σ(g, y)` at
  `y`, so it satisfies the same local rule.
- **Free products.** `A * B` acting on its Bass--Serre tree has trivial edge
  stabilizers, so it is edge-free and lies in `Γ(A * B, ρ)` with empty singular
  sets.
- **`Aut(T_d)`.** It has (M), (N) and (P), and its edge stabilizers are uncountable,
  hence not finitely generated; item 5 is not contradicted. Item 5 applies to every
  countable subgroup with (M), (P) and a nontrivial finitely generated edge group.

**Scope.**

- Edge-freeness of `G` is used only in item 2, at `h = 1`. It is exactly what the
  induction needs: an element of `G` fixing two adjacent vertices must fix the stars
  of both, and then, repeating, it is trivial.
- Finite generation of `Γ` itself is not addressed. Le Boudec's groups are finitely
  generated.
- Finite presentability is not addressed beyond the stabilizers.

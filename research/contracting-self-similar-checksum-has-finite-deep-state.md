Let `(G,X)` be a contracting self-similar group with finite nucleus `N`.
For every fixed finite set `F subset G`, there is a depth `d_F` such that

```text
g|_v in N                    (g in F, |v|>=d_F).       (CSF1)
```

Consequently a fixed finite family of recursively sectioned checksum words
has only finitely many local challenge states at all sufficiently deep
first-hit layers.

The same conclusion holds for an element of the associated Nekrashevych
prefix/full group.  Such an element has a finite prefix table with finitely
many labels `g_1,...,g_m in G`; after refining the table deeply enough, every
section label lies in the same finite nucleus `N`.

Thus contracting finite-state recursion can replicate a fixed local
contradiction on exponentially many cylinders, but it cannot make the local
challenge dimension, multiplication table, or semantic program grow without
bound.  If the finite nucleus packet has a stationary exact model, deeper
recursion merely reuses it.  Any unbounded adversarial challenge library must
therefore use a noncontracting/infinite-state section mechanism or encode the
growth in an additional coefficient/multiplicity system.

This does not assert that every Nekrashevych group is hyperlinear.  Prefix
rearrangements can add genuinely new global holonomy.  It rules out the
specific proposal that contraction/finite presentability by itself makes one
fixed word enumerate increasingly strong capacity breakers.

Direct proof (2026-09-13, lane `bh-metabelian`). Write `R = F_p[s_1, ..., s_k]` and
`K_2(n,S) = ker(St_n(S) -> E_n(S))`.

**Imports (literature, not re-proved).**
1. `steinberg-finite-presentation-and-kazhdan-theorem`. `St_n(S)` is finitely
   presented for every finitely presented unital ring `S` and `n >= 4`. `R` is a
   finitely presented ring: it is generated by `1, s_1, ..., s_k` subject to
   `p·1 = 0` and the commutation relations.
2. **Stability.** Weibel, *K-book* III, Remark 5.5.2, re-read here from the
   chapter PDF (p. 38): "The kernel of St_n(R) → E_n(R) is written as K_2(n,R),
   and there are natural maps K_2(n,R) → K_2(R). If R is noetherian of dimension
   d, or more generally has sr(R) = d+1, then the following stability result
   holds: K_2(n,R) ≅ K_2(R) for all n ≥ d+3." Here `dim R = k`.
3. **Homotopy invariance.** Weibel, *K-book* V, Theorem 6.3, re-read here from the
   chapter PDF (p. 40): "If R is a regular noetherian ring, then the base change
   K(R) → K(R[s]) is a homotopy equivalence, so K_n(R) ≅ K_n(R[s]) for all n."
   - Weibel IV, Cor. 1.7.1 identifies that `K_2` with the `K_2` of Chapter III (as
     in the reviewed route of import 2).
   - `F_p[s_1, ..., s_j]` is regular for every `j` (Stacks 00OQ: "A polynomial
     algebra in n variables over a field is a regular ring").
4. **Finite fields.** Weibel, *K-book* III, Corollary 6.1.1, re-read here (p. 48):
   "K_2(F_q) = 1 for every finite field F_q."

**Proof.**
1. By import 3 applied `k` times along `F_p ⊂ F_p[s_1] ⊂ ... ⊂ R`,
   `K_2(R) ≅ K_2(F_p)`, which is trivial by import 4.
2. By import 2, `K_2(n,R) -> K_2(R)` is injective, since `n >= k+3`.
3. So `K_2(n,R) = 0`, and `St_n(R) -> E_n(R)` is an isomorphism.
4. By import 1, `St_n(R)` is finitely presented, since `n >= 4`. So `E_n(R)` is. ∎

**Compare.** The characteristic-zero proof must pull kernel generators back from
`SL_n(Z[1/m])`, because `K_2(Z[1/m])` need not vanish. Over `F_p` the kernel is
already zero in this range.

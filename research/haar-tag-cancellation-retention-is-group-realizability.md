**ESTABLISHED.**

Let `(M,tau)` be a finite tracial von Neumann algebra generated by a finite
unitary tuple `u_s`, `s in S`.  Write `F=F(S)`, let

```text
pi:F -> U(M),                    eta:F -> H
```

be the payload and tag homomorphisms, where `H` is any countable group.  Let
`G` be the image of

```text
theta(w)=(pi(w),eta(w)) in U(M) x H,                   (HTC1)
```

and represent `G` in `M bar tensor L(H)` by

```text
rho(u,h)=u tensor lambda_H(h).                         (HTC2)
```

The trace of a tagged group element is

```text
(tau tensor tau_H)(rho(u,h))=tau(u) 1_{h=e}.           (HTC3)
```

Let `q:G -> eta(F)` be the second-coordinate quotient and `N=ker q`.  Then
the tagged trace in `(HTC3)` is the canonical trace of the abstract group
`G` **if and only if**

```text
tau(pi(n))=0 for every n in N\{e}.                    (HTC4)
```

Thus arbitrary Haar tags have an exact dichotomy.

1. If `N={e}`, then `q` is an isomorphism from `G` onto the tag group
   `eta(F)`.  The tagged generated algebra is just `L(G)` with its canonical
   trace and is independent of every payload moment.  This is total washout.
2. If `N` is nontrivial and `(HTC4)` fails, a tag-cancelling word has a
   nonzero nonidentity trace, so the tagged trace is not canonical.
3. If `N` is nontrivial and `(HTC4)` holds, then `n |-> pi(n)` is already a
   trace-preserving copy of the regular representation of `N` inside `M`:

   ```text
   L(N) ~= W*(pi(N)) subset M.                         (HTC5)
   ```

   Moreover the canonical conditional expectation `E_{L(N)}:L(G)->L(N)` is
   precisely Fourier truncation to tag degree zero.  Hence every payload
   object recovered entirely by exact tag cancellation lies in the already
   regular kernel group factor `L(N)`.

In particular, if a non-Connes-embeddable payload algebra is recovered
trace-preservingly in a nonzero corner of this degree-zero sector, then
`L(N)` is already non-Connes-embeddable and `N` is already non-hyperlinear.
The tags have not promoted the trace; their cancellation kernel has assumed
the desired conclusion.

Balanced tensor-power Haar tags exhibit the same washout on every fixed
algebraic decoder.  For a character `tau(w)=tau(pi(w))`, put

```text
V_k(w)=pi(w) tensor (pi(w) tensor bar(pi(w)))^(tensor k).  (HTC6)
```

Conditional expectation onto the first payload coordinate gives

```text
E_M(V_k(w))=pi(w)|tau(w)|^(2k).                        (HTC7)
```

If `K_tau={w:|tau(w)|=1}`, then `pi(w)=tau(w)1` for `w in K_tau`.  Therefore,
for every fixed finite word polynomial `sum_w c_w V_k(w)`, its payload
expectation converges to the scalar

```text
sum_{w in K_tau} c_w tau(w) 1.                        (HTC8)
```

So no bounded finite-word decoder retains a nonscalar payload at fixed
density through tensor-power Diracization.  Any genuinely positive-density
corner surviving outside this fixed algebraic regime is exactly the terminal
retention hypothesis of `fixed-density-polarization-retention-is-terminal`;
it would itself produce a canonical non-CE quotient rather than supplying a
formal tagging trick.

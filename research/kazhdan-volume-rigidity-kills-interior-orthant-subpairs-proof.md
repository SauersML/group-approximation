Notation is as in [[kazhdan-volume-rigidity-kills-interior-orthant-subpairs]].  `V = R^d` with Lebesgue
measure `dx`, and `O = R_+^d`.

## 0. The cone Q and its characteristic function

`K` is a closed convex cone containing `O`, so it spans `V`.  `L = K ∩ -K` is its lineality space, a linear
subspace, and `H`-invariant because `K` is.  `Q = π(K)` is closed, because `K = K + L`.  It is pointed,
because `L` is the full lineality space.  It has nonempty interior, because `K` spans `V`.  `n = dim V/L ≥ 1`
because `K ≠ V`.  The dual `Q* ⊆ (V/L)*` is then also pointed with nonempty interior.

Vinberg's characteristic function `φ_Q(y) = ∫_(Q*) e^(-<ξ, y>) dξ` is finite and continuous on `int Q`, and
positive there.  It is homogeneous of degree `-n`.  For every `A ∈ GL(V/L)` with `A Q = Q`,
`φ_Q(A y) = |det A|^(-1) φ_Q(y)`: substitute `ξ = A^* η`, since `A^*` preserves `Q*`.  For `g ∈ H` write
`ḡ` for the induced map on `V/L`.  It preserves `Q`.

*Positive characters.*  `g ↦ |det ḡ|` is a homomorphism `H → R_(>0)^×`.  If `H` has property (T), then
`H^ab` is finite, so the homomorphism is trivial and `φ_Q(ḡ y) = φ_Q(y)` for all `g ∈ H`.

## 1. The measure

Define `μ = w(x) dx` on `V`, with

```text
w(x) = exp( - φ_Q(π x)^(-1/n) )   if π x ∈ int Q,        w(x) = 0 otherwise.
```

`φ_Q(π x)^(-1/n)` is homogeneous of degree `1` in `x` and positive, so `w` decays along rays.

*Invariance.*  Under the character condition, `w(g x) = w(x)` for every `g ∈ H`: `π(g x) = ḡ π x`, `ḡ` maps
`int Q` onto `int Q`, and `φ_Q(ḡ y) = φ_Q(y)`.  `det g = 1`, so `dx` is `g`-invariant, and `μ` is `H`-invariant.

*Mass of the orthant.*  Write `x = t u` with `t = Σ x_i > 0` and `u ∈ Δ`, so that `dx = c_d t^(d-1) dt du`,
where `du` is Lebesgue measure on the simplex.  Put `Φ(u) = φ_Q(π u) ∈ (0, ∞]`.  Then
`φ_Q(π x)^(-1/n) = t Φ(u)^(-1/n)`, and substituting `t = Φ(u)^(1/n) s`,

```text
μ(O) = c_d ∫_Δ ∫_0^∞ exp(-t Φ(u)^(-1/n)) t^(d-1) dt du
     = c_d ∫_Δ Φ(u)^(d/n) du · ∫_0^∞ e^(-s) s^(d-1) ds
     = c_d (d-1)! · I(H).
```

Points with `Φ(u) = ∞` (that is, `π u ∈ ∂Q`) contribute `0` to the left side, because `w = 0` there.  They
form a null set of `Δ` whenever `I(H) < ∞`.  So `μ(O) < ∞` exactly when `I(H) < ∞`.  If `π(O \ 0) ⊆ int Q`,
then `Φ` is continuous on the compact set `Δ`, and `I(H) < ∞`.

*Positivity.*  `π` is a surjective linear map, hence open, so `π(int O) ⊆ int Q`.  Hence `w > 0` on the open
set `int O`.

## 2. (V1): a nonnegative element cannot compress the orthant

Let `g ∈ H_+`, so `g O ⊆ O`.  Assume the character condition, `L ∩ O = 0` and `I(H) < ∞`.  (`L ∩ O = 0` is
used only to make the statement meaningful for the reduction (V3); the measure argument itself needs just
`μ(O) < ∞`.)  By §1, `μ` is `g`-invariant and `μ(O) < ∞`, so

```text
μ(O \ g O) = μ(O) - μ(g O) = 0.
```

`g O` is a closed cone.  If `g O ≠ O`, then `O \ g O` is a nonempty relatively open subset of `O`.  Since
`int O` is dense in `O`, it contains a nonempty open subset of `int O`, where `w > 0`, so its `μ`-mass is
positive.  This is a contradiction, so `g O = O`.

A linear automorphism of `O` permutes its extreme rays: `g e_i = c_i e_(σ(i))` with `c_i > 0` and `σ` a
permutation.  `g` is integral, so `c_i ∈ Z_(>0)`, and `1 = det g = ± ∏ c_i` forces `c_i = 1`.  So `g` is a
permutation matrix.  If `H_+` generates `H`, then `H` is generated by permutation matrices, so `H` is finite.

## 3. (V2): compact action on V/L

Suppose `L ∩ O = 0` and the image `M_0` of `H` in `GL(V/L)` has compact closure `M`.  `M` preserves `Q`, a
closed condition.  Fix `ξ_0 ∈ int Q*` and put `ξ = ∫_M m^* ξ_0 dm` (Haar probability).  For small `η`,
`ξ + η = ∫_M m^*(ξ_0 + (m^*)^(-1) η) dm`, and `(m^*)^(-1)` is uniformly bounded on `M`, so `ξ + η ∈ Q*`.
Hence `ξ ∈ int Q*`, and `ξ > 0` on `Q \ 0`.  Put `λ = ξ ∘ π`.  It is `H`-invariant.  For `x ∈ O \ 0` we have
`π x ≠ 0` (since `L ∩ O = 0`) and `π x ∈ Q`, so `λ(x) > 0`.

Now run §2 with the density `w(x) = exp(-λ(x))` on `O`.  It is `H`-invariant with no character condition,
because `λ` itself is invariant.  The mass is `μ(O) < ∞`, because `λ ≥ c Σ x_i` on `O` for some `c > 0`, by
compactness of `Δ`.  So every `g ∈ H_+` is a permutation matrix.

## 4. (V3): lineality meeting the orthant

*`L ∩ O` is a face.*  If `x, y ∈ O` and `x + y ∈ L`, then `-x = y - (x + y) ∈ K`, so `x ∈ L`.  A face of the
orthant is a coordinate face, so `L ∩ O = O_J = R_+^J` for some `J ⊆ {1..d}`.

*`H` preserves `R^J`.*  `g ∈ H_+` preserves `O` and `L`, so `g O_J ⊆ O_J`, hence `g R^J ⊆ R^J`, with equality
because `g` is invertible.  If `H_+` generates `H`, then `H` preserves the rational subspace `R^J`.

*The pieces.*  In block form `g = [[a, b], [0, c]]` with respect to `Z^J ⊕ Z^(J^c)`.  For `g ∈ H_+` the blocks
`a` and `c` are nonnegative, so both `H_J = {a}` and `H' = {c}` are generated by nonnegative matrices.  For the
quotient piece, with orthant `O' = R_+^(J^c)` and cone `K' = image of K`, the closure of `cone(H' O')` lies in
`K'`, and its lineality `L''` lies in `L' = L / R^J` (the lineality space of `K'`, since `K = K + R^J`).  If
`x' ∈ L'' ∩ O'`, lift it to `x ∈ O` with `x ∈ L + R^J = L`.  Then `x ∈ O ∩ L = O_J`, so `x' = 0`.  So the
quotient piece satisfies `L'' ∩ O' = 0`, and (V1) or (V2) applies to it with its own cone.

*Assembling.*  If `H_J` and `H'` are finite, then a finite-index subgroup `H_1 ≤ H` has `a = 1` and `c = 1`.
`g ↦ b` is then an injective homomorphism `H_1 → Hom(Z^(J^c), Z^J)`, so `H_1` is abelian.  A Kazhdan group with a
finite-index abelian subgroup is finite.

## 5. (V4): the rank-three cone

`B = B_(H,k) = Ũ x| H` maps onto `H`, so if `B` is Kazhdan, then so is `H`.  By (N1) of
[[galois-psd-monomial-subpair-has-no-infranormal-trace]], for salient `K0` the trace `C` is infranormal in `B`
only if `H_+` generates `H`.  Theorem A of [[kt-pair-group-double-is-nonsofic]] needs both properties.  For
infinite `H`, (V1)–(V3) leave only the two cases listed in the claim.  By
[[atomic-exponent-monoids-kill-monomial-kazhdan-subpairs]], a survivor also needs a non-atomic `P` with a finite
atom set.

## 6. (V5): calibration

Take `Z[√2]` with basis `1, √2`.  Multiplication by `ε = 3 + 2√2` has matrix `[[3, 4], [2, 3]]`: it is
nonnegative, `det = 1`, and it has infinite order.  In the coordinates `(σ_1, σ_2)` the orthant is
`{|σ_2| ≤ σ_1}`, and `ε^n` scales `σ_1` by `ε^n` and `σ_2` by `ε^(-n)`.  So `K0 = {σ_1 > 0} ∪ {0}`, which is
salient, `L = {σ_1 = 0}`, which is irrational with `L ∩ O = 0`, and `n = 1`.  `Q = R_+`, `π(O \ 0) ⊆ int Q`,
and `I(H) < ∞`.  Every hypothesis of (V1) holds except the character condition: `|det ū| = ε ≠ 1`.  The
conclusion of (V1) fails, since `u` compresses `O`.  So the character condition, supplied by (T), cannot be
dropped.  Nothing else in the proof uses (T).

*Calibration of the measure.*  For `n = 1`, `φ_Q(y) = 1/y`, and `w(x) = exp(-λ(x))` with `λ = σ_1`.  Under `u`,
`w(u x) = exp(-ε σ_1(x))`, which is not invariant.  That is precisely the failure.

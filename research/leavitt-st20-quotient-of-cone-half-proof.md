Notation as in the target. `||X||_2 = d^(-1/2) ||X||_HS` on `M_d(C)` and `tr = Tr/d`. For
unitaries `u, v, w`:

```text
||uv - 1||_2 <= ||u - 1||_2 + ||v - 1||_2,     ||w u w* - 1||_2 = ||u - 1||_2.            (U)
```

For a word `μ = μ_1 ... μ_k` put `s_μ = s_(μ_1) ... s_(μ_k)` and `t_μ = (s_μ)^* = t_(μ_k) ... t_(μ_1)`.
Here `*` is the involution of `R` with `s_i^* = t_i`. For `|μ| = |ν|` we have `t_ν s_μ = δ_μν`, and
`sum_(|μ| = k) s_μ t_μ = 1` for every `k`.

**Literature used verbatim.**
- (L2) Simplicity. Leavitt, *The module type of a ring*, Trans. AMS 103 (1962): `L_K(1,n)` is a
  simple ring for every field `K` and every `n >= 2`.
- (L3) Property (T). Ershov–Jaikin-Zapirain, Invent. Math. 179 (2010), imported as
  `ershov-jaikin-kassabov-steinberg-groups-have-property-t`: `E_n(A)` has (T) for `n >= 3` and every
  finitely generated associative unital ring `A`.
- (L4) Malcev: every finitely generated subgroup of `GL_d(C)` is residually finite.
- (L5) Hyperlinearity. Pestov, Bull. Symb. Logic 14 (2008), and Radulescu. A countable group is
  hyperlinear iff it embeds in the unitary group of an ultraproduct `prod_ω M_(d_n)(C)`, iff it
  admits maps `σ_n : G -> U(d_n)` with `||σ_n(gh) - σ_n(g)σ_n(h)||_2 -> 0` and `tr σ_n(g) -> 0` for
  `g != 1`.

## Step 1. `R_+` is the free path algebra `F_2 Q`

**Spanning set.** Let `B = {s_μ} ∪ {s_μ q}` over all words `μ`, including the empty one. Then:

```text
s_μ s_i = s_(μ i),     s_μ q = s_μ q,     s_μ q s_1 = s_μ s_1 t_1 s_1 = s_(μ 1),
s_μ q s_2 = s_μ s_1 (t_1 s_2) = 0,     s_μ q q = s_μ q.
```

So `span B` is closed under right multiplication by the generators, and it contains `1`. Hence
`span B = R_+`.

**Basis.** `R` acts on the `F_2`-space with basis `Ω = {1,2}^N` of infinite words, by
`s_i ω = iω` and `t_i(jω) = δ_ij ω`. The Leavitt relations hold in this action.
- Suppose `sum c_μ s_μ + sum d_μ s_μ q = 0` is a finite sum.
- Apply it to an `ω` that begins with `2` and is not eventually periodic. The `q` terms vanish on
  such an `ω`.
  - The words `μω` are pairwise distinct: `μω = μ'ω` with `μ' = μν` and `ν` nonempty would force
    `νω = ω`, making `ω` periodic.
  - So every `c_μ = 0`.
- Apply the remaining sum to an `ω` that begins with `1` and is not eventually periodic. The same
  argument gives every `d_μ = 0`.

So `B` is a basis of `R_+`.

**The quiver.** Let `Q` have vertices `e, f` and arrows:

```text
α : e -> e,   β : e -> f,   γ : f -> e,   δ : f -> f.
```

Paths are composed left to right. Define `Φ : F_2 Q -> R_+` on these generators:

```text
e -> q,   f -> 1-q,   α -> q s_1 q,   β -> q s_1 (1-q),   γ -> (1-q) s_2 q,   δ -> (1-q) s_2 (1-q).
```

The defining relations of the path algebra hold for these images:
- `e + f = 1`, and the vertex idempotents are orthogonal.
- Each arrow is absorbed by its source vertex on the left and by its target vertex on the right.

So `Φ` is a homomorphism. It is onto, because `s_1 = q s_1 = Φ(α + β)` (from `q s_1 = s_1 t_1 s_1`)
and `s_2 = (1-q) s_2 = Φ(γ + δ)` (from `(1-q) s_2 = s_2 t_2 s_2`).

**Injectivity.**
- Let `a_1 ... a_n` be a nonzero path of length `n >= 1`.
  - Write `i_k = 1` if `a_k` is `α` or `β`, and `i_k = 2` if `a_k` is `γ` or `δ`.
  - The target idempotent of `a_k` is the left unit of `s_(i_(k+1))`. So
    `Φ(a_1 ... a_n) = s_(i_1 ... i_n) v`, where `v` is `q` or `1-q` according to the target of `a_n`.
- The paths of length `n` are thus in bijection with pairs `(μ, v)`, with `|μ| = n` and `v` in
  `{q, 1-q}`.
- Their images `s_μ q` and `s_μ - s_μ q`, together with `q` and `1-q` for the length-zero paths,
  are carried to `B` by an invertible triangular change of basis.
- So `Φ` maps a basis to a basis and is an isomorphism. This proves item 1.

## Step 2. `R` is generated by two elements

**Matrix iterate.** For `k = 4`, the map `Θ(A) = sum_(|μ| = |ν| = 4) s_μ A_μν t_ν` is a unital ring
isomorphism `M_16(R) -> R`, with inverse `r -> (t_μ r s_ν)_(μ,ν)`.
- It is multiplicative because `t_ν s_κ = δ_νκ` for words of equal length.
- It is unital because `sum_μ s_μ t_μ = 1`.

Index `{1,2}^4` by `1, ..., 16` in any fixed order.

**Two generators of `M_16(R)`.** Let `P = sum_i e_(i+1, i)` (indices mod 16), and let
`D = diag(y_1, ..., y_16)` with `(y_1, ..., y_10) = (1, 1, 0, s_1, 0, s_2, 0, t_1, 0, t_2)` and
`y_11 = ... = y_16 = 0`. Let `A` be the subalgebra generated by `P` and `D`. Then `P^(-1) = P^15`
lies in `A`, and:

```text
(P^m D P^(-m))_(ii) = y_(i-m),     D · P D P^(-1) = diag(y_i y_(i-1))_i = e_22.
```

The last equality holds because `(i, i-1) = (2, 1)` is the only pair of cyclically adjacent
positions that are both nonzero.

From `e_22` and `P`:
- `e_jj = P^(j-2) e_22 P^(2-j)` and `e_ij = P^(i-j) e_jj`, so `A` contains every matrix unit.
- `e_(i,p) D e_(p,j) = y_p e_ij`, so `A` contains `r e_ij` for `r` in `{s_1, s_2, t_1, t_2}`.

These generate `M_16(R)`. Hence `X = Θ(P)` and `Y = Θ(D)` generate `R`, which proves item 2.

## Step 3. The surjection `φ : R_+ ->> R`

**Corner decomposition.** Put `E = q = s_1 t_1` and `F = 1 - q = s_2 t_2`. The map
`Θ_2(A) = sum_(i,j <= 2) s_i A_ij t_j` is a unital ring isomorphism `M_2(R) -> R`, and:

```text
Θ_2(e_11) = E,   Θ_2(e_12) = s_1 t_2,   Θ_2(e_21) = s_2 t_1,   Θ_2(X e_11) = s_1 X t_1,   Θ_2(Y e_22) = s_2 Y t_2.
```

So `s_1 X t_1` lies in `ERE`, `s_1 t_2` in `ERF`, `s_2 t_1` in `FRE`, and `s_2 Y t_2` in `FRF`.

**Definition.** By the universal property of `F_2 Q` (Step 1), there is a unique unital homomorphism
`φ : R_+ -> R` with:

```text
e -> E,   f -> F,   α -> s_1 X t_1,   β -> s_1 t_2,   γ -> s_2 t_1,   δ -> s_2 Y t_2.
```

Then `φ(q) = q`, and `φ(s_1) = φ(α + β) = s_1 (X t_1 + t_2)`.

**Onto.**
- The image contains `Θ_2` of `e_11`, `e_12`, `e_21`, and hence `e_22 = e_21 e_12`.
- It also contains `Θ_2` of `X e_11` and `Y e_22`, and hence `Θ_2(r e_ij)` for every `r` in the
  algebra generated by `X` and `Y`. By Step 2 that algebra is all of `R`.
- So the image is `Θ_2(M_2(R)) = R`.

**Groups.**
- `φ` fixes `F_2 E + F_2 F` pointwise. So the entrywise map `φ_* : GL_20(R_+) -> GL_20(R)` restricts
  to the identity on `Delta_0`.
- `φ_*` maps `Delta_+ = E_20(R_+)` onto `E_20(R)`, since `φ_*(x_ij(a)) = x_ij(φ(a))`.
- `E_20(R) = Delta` (`leavitt-steinberg-map-iso-from-rank-three`, and the setting of
  `leavitt-cuntz-cone-halves-have-rf-amalgam-cover`).

**Mirror.** `*` fixes `q` and maps `R_+` onto `R_-`. So `φ_-(r) = φ(r^*)^*` is a unital
homomorphism `R_- ->> R` fixing `q`. It is a composite of two anti-homomorphisms and one
homomorphism.

**The kernel ideal is finitely generated.** `R_+` is generated by `x_1, x_2, x_3 = s_1, s_2, q`.
`R` has the finite presentation `F_2<y_1..y_4> / (r_1, ..., r_5)`, with the Leavitt relations in
`y = (s_1, s_2, t_1, t_2)`.
- Write `φ(x_i) = w_i(y)`, and choose `u_j` in `R_+` with `φ(u_j) = y_j`.
- Let `J` be the ideal generated by the elements `x_i - w_i(u)` and `r_l(u)`.
  - `J` lies in `I = ker φ`.
  - `y_j -> u_j + J` defines a homomorphism `R -> R_+/J`, because the relations `r_l(u)` lie in `J`.
  - This map is inverse to the map `R_+/J -> R` induced by `φ`. Both composites fix generators:
    `R_+/J` is generated by the `u_j`, since `x_i ≡ w_i(u)`.
- So `I = J` is generated by the finitely many elements `a_1, ..., a_m` listed above. This proves
  item 3.

## Step 4. `(QN)`: the kernel head bound with linear modulus

**The fibre-product ring.** Let `D = {(x, y) in R_+ x R_+ : φ(x) = φ(y)}`, with coordinate projections
`p_1, p_2 : D -> R_+`.
- `D = Δ(R_+) + (I x 0)`, since `(x, y) = (y, y) + (x - y, 0)`.
- `(r, r)(a_k, 0)(r', r') = (r a_k r', 0)`. So `D` is generated as a unital ring by
  `S_0 = {(s_1, s_1), (s_2, s_2), (q, q)} ∪ {(a_k, 0) : k <= m}`.
- By (L3), `E_20(D)` has property (T).
- `x_ij(d_1 d_2) = [x_il(d_1), x_lj(d_2)]` for distinct `i, j, l`. So `E_20(D)` is generated by the
  finite set `S = {x_ij(d) : i != j, d in S_0 ∪ {(1,1)}}`.
- Let `κ > 0` be a Kazhdan constant for `(E_20(D), S)`. It depends only on `φ`, not on any
  representation.

**Relative subgroup.**
- `p_2` has the section `Δ`. So `ker(p_2 : E_20(D) -> E_20(R_+))` is the normal closure in `E_20(D)`
  of the generators `x_ij((a_k, 0))`, and more generally of the `x_ij((a, 0))` with `a` in `I`.
- Hence `p_1(ker p_2)` is the normal closure in `E_20(R_+)` of `{x_ij(a) : a in I}`, which is
  `E_20(R_+, I)`.
- `E_20(R_+, I)` is normal in `Delta_+`, and it lies in `N`.

**Intertwiner.** Let `λ : Delta_+ -> U(V)` with `dim V = d`, and suppose
`max_(x in F) ||λ(x) - 1||_2 <= δ`.
- `E_20(D)` acts on `End(V)`, with the normalized Hilbert–Schmidt inner product, by
  `σ(g) T = λ(p_1 g) T λ(p_2 g)^(-1)`.
- For `ξ = 1_V` (norm 1):
  - The generators `x_ij((r, r))` fix `ξ` exactly.
  - `σ(x_ij((a_k, 0))) ξ = λ(x_ij(a_k))`, which is within `δ` of `ξ`.
- By property (T), the projection `T` of `ξ` onto the `σ`-invariant vectors satisfies
  `||T - 1_V||_2 <= δ/κ`.
- `σ`-invariance means `λ(p_1 g) T = T λ(p_2 g)` for every `g`.
- For `g` in `ker p_2` this reads `λ(p_1 g) T = T`. So `range(T)` is fixed by `E_20(R_+, I)`.

**Size of the fixed space.**
- On `ker T`, `T - 1_V` acts as `-1`. So `dim ker T <= ||T - 1_V||_HS^2 = d ||T - 1_V||_2^2`.
- Hence `W = V^(E_20(R_+, I))`, which contains `range(T)`, has `codim W <= (δ/κ)^2 d`.

**No finite quotients.** Let `ψ : Delta_+ -> G` be a homomorphism onto a finite group that kills
`E_20(R_+, I)`. Put `J_ψ = {r in R_+ : ψ(x_ij(r)) = 1 for all i != j}`.
- `J_ψ` is an additive subgroup: `x_ij(r + r') = x_ij(r) x_ij(r')`.
- It has finite index, as the intersection of the kernels of the additive maps `r -> ψ(x_ij(r))`
  into `G`.
- It is a two-sided ideal: `x_ij(rs) = [x_il(r), x_lj(s)]` and `x_ij(sr) = [x_il(s), x_lj(r)]`.
- It contains `I`.
- So `R_+/J_ψ` is a finite quotient ring of `R_+/I ≅ R`. By (L2), `R` is simple, and it is
  infinite. Hence `J_ψ = R_+`, and `ψ` kills every `x_ij(r)`, so `ψ` is trivial.

**Conclusion.**
- `W` is `Delta_+`-invariant, because `E_20(R_+, I)` is normal.
- `λ|_W` factors through `Delta_+ / E_20(R_+, I)`. Its image is a finitely generated linear group,
  so by (L4) it is residually finite. By the previous paragraph it is therefore trivial.
- So `W = V^(Delta_+)`. In particular `V^N` lies between `V^(Delta_+)` and `V^(E_20(R_+,I))`, and
  all three are equal.
- For every `g` in `Delta_+`, `λ(g) - 1` vanishes on `W` and has norm at most 2 on `W^⊥`. So
  `||λ(g) - 1||_2^2 <= 4 codim(W)/d <= 4 (δ/κ)^2`.

This proves item 4.

## Step 5. The single-prerequisite split

**Compression lemma.** Let `λ` be unitary on `C^(D')`, let `P : C^(D') -> C^d` be a coisometry with
`d <= D'` and `D'/d -> 1`, and suppose `||P λ P* - 1_d||_(2,d) -> 0`. Then `||λ - 1||_(2,D') -> 0`.
- Put `B = λ P*`, an isometry. Then `||(1 - P*P) B||_HS^2 = d - ||P B||_HS^2 = o(d)`, because
  `||P B||_HS >= √d - ||P B - 1_d||_HS`.
- So `||(λ - 1) P*||_HS^2 = ||P λ P* - 1_d||_HS^2 + ||(1 - P*P) λ P*||_HS^2 = o(d)`.
- On the complement of `range P*`, which has dimension `D' - d = o(d)`, the Hilbert–Schmidt norm of
  `λ - 1` is at most `2 √(D' - d)`. Divide by `√D'`.

**(PR) implies non-hyperlinear.** Suppose `Delta` is hyperlinear, with maps `σ_n` as in (L5), and
suppose `(PR)` holds.
- Take genuine `λ_n : Delta_+ -> U(D_n)` with `D_n/d_n -> 1` and
  `||σ_n(φ_* g) - P_n λ_n(g) P_n*||_2 -> 0` for every `g`.
- `σ_n(1) -> 1`, since `σ_n(1)` is a unitary asymptotically equal to its square.
- For `x` in `F`, `φ_* x = 1`. So `||P_n λ_n(x) P_n* - 1||_2 -> 0`, and by the compression lemma
  `||λ_n(x) - 1||_2 -> 0`.
- By Step 4, `||λ_n(g) - 1||_2 <= 2 max_F ||λ_n(x) - 1||_2 / κ -> 0` for every `g` in `Delta_+`.
- Hence `σ_n(φ_* g) -> 1` for every `g`, and so `σ_n(h) -> 1` for every `h` in `Delta`, because
  `φ_*` is onto (Step 3).
- This contradicts `tr σ_n(h) -> 0` for `h != 1`.

**Non-hyperlinear implies (PR).** Let `σ_n` be any asymptotic representation of `Delta`, and `ω` a
free ultrafilter.
- The ultraproduct gives a homomorphism `Delta -> U(prod_ω M_(d_n))`.
- Its kernel is normal, so by simplicity (`binary-leavitt-elementary-group-is-simple`) it is trivial
  or everything.
- If it is trivial, then `Delta` is hyperlinear by (L5).
- So if `Delta` is non-hyperlinear, then `σ_n(h) -> 1` along every ultrafilter, that is, for every
  `h`. Then `σ_n ∘ φ_*` is rounded by the trivial representation, with `D_n = d_n`.

This proves item 5.

**Item 6.** Flexible HS-stability of `Delta_+` means that every asymptotic representation of
`Delta_+` is flexibly roundable. `σ_n ∘ φ_*` is an asymptotic representation of `Delta_+`, because
`φ_*` is a homomorphism. So flexible HS-stability gives `(PR)`, and `Delta` is not hyperlinear by
item 5.
- The infinite simple group `Delta` witnesses `non-hyperlinear-group`.
- Non-hyperlinearity implies `(QC)` and `(HR)`, by item 1 of
  `leavitt-st20-nonhyperlinear-iff-cone-bound-and-half-rounding`.

## Checks

- Step 4 uses no property of `N` beyond `E_20(R_+, I) <= N`. The kernel `N` may be larger, with
  quotient a relative `K_1`-type group. That quotient is irrelevant, because the finite-quotient
  argument already gives `V^(E_20(R_+, I)) = V^(Delta_+)`.
- The modulus `2δ/κ` is linear, and the test set `F` is finite and explicit once `a_1, ..., a_m` are
  computed by the recipe of Step 3.
- Step 2 is a routine instance of the classical fact that `M_n(A)` is 2-generated for large `n`.
  It is spelled out here only to make `φ` explicit.

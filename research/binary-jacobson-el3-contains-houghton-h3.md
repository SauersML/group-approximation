**ESTABLISHED** (swarm-0917 w21, agent-verified, no referee). Parts (H1)-(H3) are proved
below from definitions, and `verify_houghton.py` checks them exactly: 14 checks, exit 0. Part
(H4) imports Brown's theorem that `H_3` is finitely presented, with the same citation as
`cofinite-abelian-subgroups-give-relative-pbh`.

**Setting.**
* `J = F_2<S,T | TS = 1>` and `Q = 1 - ST`.
* `V = F_2^(Omega)`, where `Omega = {1,2,3} x N` is three rays. `J` acts on each ray by the Fock
  action `S delta_n = delta_(n+1)`, `T delta_n = delta_(n-1)` and `T delta_0 = 0`. So `Q` is the
  projection onto `delta_0`.
* `M_3(J)` acts on `V` by column vectors.
* `E = EL_3(J)`, `pi : E -> SL_3(F_2[z,z^(-1)])` is the symbol map, and `L = ker pi = GL_fin(V)`.

**Claim.**
* **(H1)** `d_12 = x_12(S) x_21(T) x_12(S) x_21(1) x_12(1) x_21(1) = [[S,Q,0],[0,T,0],[0,0,1]]`
  lies in `E`, with inverse `[[T,0,0],[Q,S,0],[0,0,1]]`.
  * This is the Levi compressor `g = diag(u,1)` of `jacobson-el3-is-not-lef` read in
    characteristic two. It is also the balanced shift `a_12` of
    `binary-jacobson-active-cycle-generates-rank-three`.
  * On `Omega` it acts as Houghton's translation `g_12`: `(1,n) -> (1,n+1)`,
    `(2,n) -> (2,n-1)` for `n >= 1`, `(2,0) -> (1,0)`, and ray 3 is fixed.
* **(H2)** Let `P_23 = x_23(1) x_32(1) x_23(1)` and `d_13 = P_23 d_12 P_23`. Then
  `<d_12, d_13> <= E` maps isomorphically onto Houghton's group `H_3 <= Sym(Omega)`, the
  permutations that are eventually translations on each ray.
  * `[d_12, d_13]` is the transposition of `(2,0)` and `(3,0)`.
  * `H_3 ∩ L = FSym(Omega)`.
* **(H3)** Let `D <= SL_3(F_2[z,z^(-1)])` be the diagonal torus `{diag(z^i, z^j, z^k) : i+j+k = 0}`.
  Then `pi^(-1)(D) = L H_3`, an extension `1 -> L -> L H_3 -> Z^2 -> 1`.
  * This *linear Houghton group* `LH_3` is locally-finite-by-`Z^2`, so it is amenable.
  * It is generated by `d_12`, `d_13` and the head `x_13(Q)`, and it contains the head.
* **(H4)** `H_3` is finitely presented and not residually finite. So `H_3`, `LH_3`, `E`, and every
  `EL_n(J)` with `n >= 3` (via `H_n <= EL_n(J)`) are not LEF. The non-LEF witness lies in the
  amenable subgroup `LH_3`.

## Proof

**Faithfulness.** The Fock action of `J` is faithful.
* `S^a T^b` sends `delta_n` to `delta_(n-b+a)` if `n >= b`, and to `0` otherwise.
* Let `x = sum c_(a,b) S^a T^b != 0`, and let `b_0` be the least `b` with some `c_(a,b) != 0`.
  Then `x delta_(b_0) = sum_a c_(a,b_0) delta_a != 0`.

So `M_3(J)` acts faithfully on `V`. A subgroup of `E` that permutes the basis `Omega` is
isomorphic to its permutation image.

**(H1)** The identity is a direct 3x3 product over `J`. It uses only `TS = 1`, and all signs
vanish in characteristic two. The product with the stated inverse is `1` on both sides, because
`TS = 1`, `ST + Q = 1`, `TQ = 0` and `QS = 0`.

The action is read off column by column:
* `d_12(delta_n^(1)) = S delta_n^(1) = delta_(n+1)^(1)`;
* `d_12(delta_n^(2)) = Q delta_n` placed in ray 1, plus `T delta_n` in ray 2. For `n >= 1` this
  is `delta_(n-1)^(2)`, and for `n = 0` it is `delta_0^(1)`.

**(H2)** `P_23` is the permutation matrix of the swap of coordinates 2 and 3, so `d_13` is `g_13`.
Let `G` be the permutation group generated by `g_12` and `g_13`.
* **`G <= H_3`.** Both generators are bijections that are eventually translations on each ray.
* **`G` contains a transposition.** The commutator `[g_12, g_13]` is the transposition
  `((2,0) (3,0))`. This is computed exactly in `M_3(J)` and on the basis by the script.
* **`G ⊇ FSym(Omega)`.** Write `tau_(p,q)` for the transposition of `p` and `q`.
  * Conjugating `tau_((2,0),(3,0))` by `g_12^m` for `m ∈ Z` gives `tau_(p,(3,0))` for every `p` on
    rays 1 and 2, since `g_12` is transitive on the line formed by rays 1 and 2 and fixes `(3,0)`.
  * Fix `p` on ray 2, which `g_13` fixes. Conjugating `tau_(p,(3,0))` by `g_13^m` pairs `p` with
    every point of rays 1 and 3.
  * The transpositions obtained form a connected graph on `Omega`, so they generate `FSym(Omega)`.
* **`G ⊇ H_3`.** Every `h ∈ H_3` eventually translates the rays by `(t_1, t_2, t_3)` with
  `t_1 + t_2 + t_3 = 0`. Since `g_12` and `g_13` translate by `(1,-1,0)` and `(1,0,-1)`,
  `h g_12^(t_2) g_13^(t_3)` translates by `0` eventually, so it is finitary. Hence `h ∈ G`.

Hence `<d_12, d_13> ≅ H_3`.
* The symbols are `pi(d_12) = diag(z, z^(-1), 1)` and `pi(d_13) = diag(z, 1, z^(-1))`.
* So `pi` maps `H_3` onto `D ≅ Z^2`, with kernel `H_3 ∩ L`.
* That kernel is `FSym(Omega)`: an element of `H_3` in `L` has finitary matrix, so it is a
  finitary permutation.

**(H3)** Since `pi(H_3) = D`, we get `pi^(-1)(D) = L H_3`.
* `L = GL_fin(V)` is locally finite, so `L H_3` is locally-finite-by-`Z^2`. It is amenable.
* `L` is the normal closure of the elementary transvection `x_13(Q)`, which sends
  `delta_0^(3)` to `delta_0^(3) + delta_0^(1)`.
  * Conjugating by `FSym(Omega) <= H_3` gives every elementary transvection
    `1 + delta_p ⊗ delta_q^*`.
  * These generate `GL_fin(V)`, since over `F_2` every finitary invertible matrix is a product of
    elementary transvections.
  * So `L H_3 = <d_12, d_13, x_13(Q)>`.

**(H4)** Imported: `H_3` is finitely presented (K. S. Brown, *Finiteness properties of groups*,
JPAA 44 (1987); `H_n` is of type `F_(n-1)`), as cited in `cofinite-abelian-subgroups-give-relative-pbh`.
* **`H_3` is not residually finite.**
  * `Alt(Omega)` is an infinite simple normal subgroup.
  * A finite-index normal subgroup `N` meets it in a finite-index normal subgroup of
    `Alt(Omega)`, which must be all of `Alt(Omega)`.
  * So every finite quotient kills `Alt(Omega)`.
* **So `H_3` is not LEF**, because a finitely presented LEF group is residually finite.
* LEF passes to finitely generated subgroups. So `LH_3`, `E` and `EL_n(J)` for `n >= 3` are not
  LEF. For `EL_n(J)`, the translations `d_1j = P_2j d_12 P_2j` generate `H_n`, which is finitely
  presented for `n >= 3`.

This proof uses no property (T), no trace and no presentation of `E`. It is independent of the
contraction trap.

## Consequences

**(K) Precise obstruction: the non-LEF invariants are amenable-local.** `LH_3` is amenable, and
it shares with `E` every invariant below. So none of them can separate `E` from a group whose head
survives.
* **Non-LEF.** Both are non-LEF, by (H4).
* **Finite-quotient invisibility.** Every finite quotient of `LH_3` kills the head, because `L` is
  infinite and simple.
* **No level-factoring models.** `LH_3` has no injective rank model that factors through
  representations of `GL_m(F_2)` with positive transvection displacement. Such a model would make
  `LH_3` LEF, by `transvection-displacement-forces-exact-local-embedding`.
* **Yet the head survives.** `LH_3` has faithful, hence head-retaining, characteristic-two rank
  models: sofic approximations linearized. As an amenable group it is also MF, through
  quasidiagonality of amenable group C*-algebras (Tikuisis–White–Winter, recalled; this MF clause
  is not part of the ESTABLISHED statement (H1)-(H4)).

So an argument for head collapse in `E` fails for rank models and for MF models alike if its only
inputs are:
* non-LEF-ness;
* finite-quotient invisibility of the head;
* the exclusion of level-factoring models (`binary-jacobson-el3-rank-radical-is-the-finitary-kernel`,
  "Dies if E is not LEF");
* relations holding inside `pi^(-1)(D)`.

It would prove the same statement for `LH_3`, which is false. This makes explicit, for the maximal
diagonal instance, what `jacobson-amenable-symbol-subgroups-are-amenable` predicts. The new point is
that this amenable instance already carries the non-LEF certificate.

**(R) The rank threshold is Houghton's threshold.**
* `d_12` lies in the `2 x 2` block, so `H_2 = <FSym, g_12> <= EL_2(J)`.
* `H_2` is not finitely presented (Brown 1987). This is consistent with `binary-jacobson-el2-is-lef`.
* For `n >= 3`, `H_n <= EL_n(J)` is finitely presented. So the LEF threshold `n = 3` of `EL_n(J)`
  coincides with the finite-presentation threshold of the Houghton groups on its Fock rays.

**(P) An amalgam frame for the presentation question.**
* The constant permutation matrices `S_3 <= SL_3(F_2)` permute the three rays, so they normalize
  `H_3`. Also `H_3 ∩ SL_3(F_2) = 1`. A nontrivial constant matrix either does not permute the
  basis, or it is a nontrivial ray permutation, and no element of `H_3` permutes the rays.
* `<a_12, x_12(1), x_23(1), x_31(1)> = E` (`binary-jacobson-active-cycle-generates-rank-three`),
  with `a_12 = d_12`.
* So `E` is a quotient of the finitely presented amalgam `A = (H_3 x| S_3) *_(S_3) SL_3(F_2)`.
* Hence `E` is finitely presented iff `ker(A -> E)` is finitely normally generated.

This does not decide `binary-jacobson-el3-is-finitely-presented`. It replaces the non-finitely
presented cone amalgam `U` of the presentation artifact by a finitely presented amalgam of a
Houghton group and a finite group.

**ESTABLISHED (proposed; unreviewed).**  Derivation: [[nonneg-generated-kazhdan-groups-have-nonsalient-cones-proof]].
It is a class-killing obstruction for the nonsofic side of [[rank-three-finite-twisted-kazhdan-cone-is-sofic]].
It answers (N5) of [[galois-psd-monomial-subpair-has-no-infranormal-trace]] in the negative.

## Setting

`H ≤ GL_d(Z)`, `O = R_+^d`, `H_+ = H ∩ M_d(N)`, `K0 = cone(H · O)`, `K` its closure, `L = K ∩ -K`,
`π : V = R^d → V/L`, `Q = π(K)`, a pointed closed cone.  For a face `F` of `Q` write
`J(F) = { i : π e_i ∈ F }`.  Call `H` **character-free** if no finite-index subgroup of any quotient of `H`
has a nontrivial homomorphism to `R_(>0)^×`.  Property (T) implies this: (T) passes to quotients and to
finite-index subgroups, and Kazhdan groups have finite abelianisation.

## Theorem

**(W1) Face rigidity (no volume condition).**  Let `H` be character-free and generated by `H_+`, and let
`L ∩ O = 0`.  Then every element of `H_+` is a permutation matrix, so `H` is finite.

**(W2) Salience theorem.**  Let `H` be character-free and generated by `H_+`.  If `K0` is salient, then `H` is
finite.  Equivalently: **an infinite Kazhdan group of integer matrices generated by nonnegative matrices has
a line in `cone(H · R_+^d)`**.  In fact `K0` then contains a whole `H`-invariant coordinate subspace `R^M`
with `M ≠ ∅`.

**(W3) Consequence for the rank-three cone.**  Every origin-level monomial subpair `B_(H,k) = < U_k, H >` of
[[monomial-origin-level-subpairs-cannot-certify-rank-three-cone]] fails to be a Kun-Thom certificate for `T_3`:

- if `K0` contains a line, then `psi(C) = F` and the centraliser condition fails, by (M2);
- if `K0` is salient and `C` is infranormal, then `H_+` generates `H` by (N1); if also `B` is Kazhdan, then
  `H` is Kazhdan, so `H` is finite by (W2), and (M4) makes `C` normal.

No hypothesis on atoms, on the lattice basis, on rationality of `L`, or on the Vinberg volume is needed.  This
supersedes (V1)–(V4) of [[kazhdan-volume-rigidity-kills-interior-orthant-subpairs]] and the open question of
[[atomic-exponent-monoids-kill-monomial-kazhdan-subpairs]].

## Mechanism

1. `ḡ` for `g ∈ H_+` permutes the finite set `𝒞 = { F_S }` of minimal faces of `Q` containing `π(O_S)`,
   `S ⊆ [d]`, because `ḡ F_S = F_(supp g e_S)`.  So a finite-index normal `H_1` fixes each `F_S`.
2. An element `g ∈ H_1 ∩ H_+` is block triangular for the partition of `[d]` by carrier face
   (`i ∈ A_F` iff `π e_i ∈ relint F`), with nonnegative diagonal blocks `g_F ∈ GL(Z^(A_F))`.
3. On `O_(A_F)` put `w(y) = exp(-φ_F(π y)^(-1/n_F))`, with `φ_F` Vinberg's function of the face `F` in its
   span.  The character `|det ḡ|_(span F)|` of `H_1` is trivial, and `φ_F` decreases along `F`, so
   `w ∘ g_F ≥ w`.  The mass is finite because `π(O_(A_F) \ 0) ⊆ relint F`.  So `g_F` preserves `O_(A_F)` and is
   a permutation.  This is where the boundary obstruction of (V1) disappears: each index is measured only on
   its own open face.
4. A power of `g` is then unipotent and nonnegative.  If it is not `1`, a vector `x ≥ 0` with `N x = v ≠ 0`,
   `N^2 x = 0` gives `(u^(-n) x)/n → -v ∈ K`, so `v ∈ L ∩ O`.  Hence `g` has finite order, and a nonnegative
   integer matrix of finite order is a permutation.
5. (W2) runs (V3) of the volume node, applies (W1) to the quotient piece, and recurses into the piece on
   `R^J`, `O_J = L ∩ O`.  The recursion stops only at a piece `H_M` with `cone(H_M · O_M) = R^M`, which puts
   a line in `K0`.

## Calibration

- `u = [[3,4],[2,3]]` on `Z^2` (multiplication by `3 + 2√2`): nonnegative, infinite, `K0` salient.  (W1) fails
  only through step 3: the character `|det ū| = 3 + 2√2` is nontrivial.
- `[[1,1],[0,1]]`: nonnegative, `K0` salient, `L = R e_1` meets `O`.  (W2) fails only in the final nilpotent step,
  since `Z` is not character-free.
- `SL_3(Z)` on `Z^3`: generated by the nonnegative `e_ij(1)`, infinite, Kazhdan; `K0 = R^3`, as (W2) says.
- `Sym^2 SL_3(Z[√2])` in the basis `ω v v^T`: every `π e_i` spans an extreme ray of `Q = PSD`, so the face
  partition consists of rays (with rank-2 lattices `{E, √2 E}` on some rays).  Step 3 on a ray is the functional
  argument, and reproduces (N3): `H_+` is finite.  The same now holds in every basis.

## What is left

The monomial nonsofic side of [[rank-three-finite-twisted-kazhdan-cone-is-sofic]] is closed.  A nonsofic
certificate for `T_3` now needs `B ⊇ U_k` with `B ∩ EL_3(R)` strictly larger than the monomial group `Ũ`, where
(N1) is unproved, or a `B` not containing any level `U_k`.  The positive side (sofic approximations of `T_3`)
is untouched.

**ESTABLISHED (proposed; unreviewed).**  Derivation: [[kazhdan-volume-rigidity-kills-interior-orthant-subpairs-proof]].
It is an obstruction for the nonsofic side of [[rank-three-finite-twisted-kazhdan-cone-is-sofic]].  It answers
the question left by [[atomic-exponent-monoids-kill-monomial-kazhdan-subpairs]] ("does nonnegative generation of a
Kazhdan `H` force `P` to be atomic?") by going around it: on a large part of the residual case, nonnegative
generation of an infinite Kazhdan `H` is impossible outright, whatever `P` looks like.

## Setting

`H ≤ SL_d(Z)`, `O = R_+^d` the orthant, `K0 = cone(H · O)`, `K` its closure, `L = K ∩ -K`, `n = dim V/L`,
`π : V = R^d → V/L`, and `Q = K / L`.  `Q` is a closed convex cone in `V/L` that is pointed and has nonempty
interior, and `H` acts on `V/L` preserving `Q`.  Assume `K ≠ V` (true when `K0` is salient), so `n ≥ 1`.
Write `φ_Q(y) = ∫_(Q*) e^(-<ξ, y>) dξ` for Vinberg's characteristic function on `int Q`, and `Δ` for the
standard simplex `{x ∈ O : Σ x_i = 1}`.  Call

```text
I(H) = ∫_Δ φ_Q(π u)^(d/n) du  ∈ (0, ∞]
```

the **orthant volume** of `H`.  It is finite, for example, when `π(O \ 0) ⊆ int Q` (the orthant is *interior*).
`H_+ = H ∩ M_d(N)` is the semigroup of nonnegative elements.

## Theorem

**(V1) Volume rigidity.**  Suppose every homomorphism `H → R_(>0)^×` is trivial.  This holds when `H` has
property (T), since then `H^ab` is finite.  Suppose `L ∩ O = 0` and `I(H) < ∞`.  Then every `g ∈ H_+` maps
`O` onto `O`, so `g` is a permutation matrix.  In particular, if `H_+` generates `H`, then `H` is finite.

**(V2) Compact quotient action.**  If `L ∩ O = 0` and the image of `H` in `GL(V/L)` is relatively compact,
then some `H`-invariant functional is positive on `O \ 0`, and again every `g ∈ H_+` is a permutation matrix.
No character condition and no volume condition is needed here.

**(V3) Lineality meeting the orthant.**  `L ∩ O` is a coordinate face `O_J`.  If `H_+` generates `H`, then `H`
preserves `R^J`.  The two pieces, `H_J = H|R^J` on `Z^J` and `H'` on `Z^d / Z^J`, are again generated by
nonnegative matrices.  The quotient piece has `L' ∩ O' = 0`, so (V1) and (V2) apply to it.  The piece `H_J` has
its whole orthant `O_J` inside `L`.  If `H` is Kazhdan and both pieces are finite, then `H` is finite.

**(V4) Consequence for the rank-three cone.**  Let `B_(H,k)` be an origin-level monomial subpair of
[[monomial-origin-level-subpairs-cannot-certify-rank-three-cone]] with `K0` salient.  By (N1) of
[[galois-psd-monomial-subpair-has-no-infranormal-trace]], `C = B ∩ Gamma` is infranormal in `B` only if `H_+`
generates `H`.  If `B` is Kazhdan, so is its quotient `H`.  So by (V1)–(V3), `B_(H,k)` with infinite `H` is dead
unless one of the following holds:

- the piece `H_J` of (V3) is infinite, where `J ≠ ∅` and `O_J ⊆ L`;
- the quotient piece has three properties: it acts on `V'/L'` through a group that is not relatively compact,
  its orthant touches `∂Q'`, and it does so badly enough that `I(H') = ∞`.

**(V5) (T) is needed.**  `H = <u>`, with `u` multiplication by `3 + 2√2` on `Z[√2] = Z^2`, is nonnegatively
generated and infinite.  It has `L ∩ O = 0`, `n = 1`, and an interior orthant.  (V1) fails only through the
character `|det(u|V/L)| = 3 + 2√2`.  This is the abelian counterexample to atomicity, and the character is what
(T) removes.

## What is left

A monomial certificate now needs an infinite Kazhdan `H ≤ SL_d(Z)` with the following properties:

- `H` is generated by nonnegative matrices;
- `K0` is salient;
- `P` is non-atomic with a finite atom set;
- either the piece `H_J` inside `L` is infinite, or the quotient piece has a non-compact action on `V'/L'` and
  infinite orthant volume.

The volume condition forces some coordinate vector, or face of `O`, to project to `∂Q`.  For
`Q = PSD_m`, `φ_Q = c · det^(-(m+1)/2)`, so rank-deficient projections of the coordinate vectors are exactly what
is needed.  The Galois PSD geometry `Sym^2 SL_3(Z[√2])` survives (V1) only in a basis where some basis matrix
is singular at the first real place.  The next step is the boundary case: decide whether a nonnegative `g`
can map `O` strictly into itself when `π(O)` touches `∂Q`, by running (V1) on the face stabilisers of `Q`.

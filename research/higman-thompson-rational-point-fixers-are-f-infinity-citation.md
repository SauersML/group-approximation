Citation import, read 2026-09-18 from the arXiv LaTeX source.

J. Belk, J. Hyde and F. Matucci, *Finite Germ Extensions*, arXiv:2407.03149 (v1), Appendix A, "Stabilizers in
Higman–Thompson groups" (`sec:AppendixA`). This is the same source file as in
`germ-complex-and-bux-gonzalez-morse-inputs-citation`.

- **Rational points.** "Recall that a point in C_{d,r} is rational if it is eventually periodic, i.e. it has the form
  αβ̄ for some α∈X_r×X_d^* and β∈X_d^+."
- **(Stab)** `thm:Stabilizers`, verbatim: "Let S ⊂ C_{d,r} be a finite set of rational points. Then Fix_{V_{d,r}}(S)
  is an iterated ascending HNN extension of V_{d,n} for some n≥1, and in particular Fix_{V_{d,r}}(S) and
  Stab_{V_{d,r}}(S) have type F_∞."
- **(Germ)** Proof of `thm:Stabilizers`, with `G = Fix_{V_{d,r}}(S)`: "we can write s as αβ̄, where …, and β is not a
  power of any shorter word. Let t be an element of G that agrees with the prefix replacement αψ↦αβψ in a
  neighborhood of s, and note that the group of germs (G)_s is the infinite cyclic group generated by (t)_s."

**Note on the source.** In the displayed proof the alphabets appear as `α ∈ X_d × X_r^*` and `β ∈ X_r^+`, which swaps
the roles of `d` and `r` compared with the definition of rational points just before it. We read this as a typo and
use the definition.

**Why the germ statement is also true in general.** Near `s`, an element of `V_{d,r}` fixing `s` is a prefix
replacement `αβ^kψ ↦ γψ` with `γβ̄ = αβ̄`. So `γ` is a prefix of `αβ̄`. If `|γ| - |α|` were not divisible by `|β|`,
then `β̄` would equal a nontrivial rotation of itself, and `β` would be a proper power. So `γ = αβ^a` and the germ is
`(t)_s^{a-k}`.

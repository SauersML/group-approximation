**ESTABLISHED** through `leavitt-tensor-unit-word-problem-reduces-to-base-proof`.
Elementary; no import.

Let `L = L_(F_2)(1,2) = F_2<x_1,x_2,y_1,y_2 | y_i x_j = δ_ij, x_1 y_1 + x_2 y_2 = 1>`.
Let `B = F_2<b_1..b_m | R>` be a finitely generated unital `F_2`-algebra. Its
**zero test** takes a noncommutative polynomial in the `b`'s, written as a sum of
monomials of total size `n` (number of letters), and decides whether it is `0`
in `B`. Suppose the zero test runs in time `F_B(n)`, with `F_B` nondecreasing.

1. **Reduction.** Let `H` be a subgroup of `(B ⊗ L)^x` generated by finitely many
   units `h_1, ..., h_s`. Then `H` has a word-problem algorithm, for the
   generating set `{h_i}`, running in time at most
   `C * 2^(C l) * (1 + F_B(C * 2^(C l)))` on words of length `l`. Here `C`
   depends on `H` and fixed expressions for `h_i^(±1)` in the generators
   `b_k ⊗ 1`, `1 ⊗ x_i`, `1 ⊗ y_i`. The same holds with `L` replaced by
   `M_N(L)`, so it covers every finitely generated subgroup of `GL_N(B ⊗ L)`.
2. **Transfer of a class bound.** Let `𝓑` be a class of finitely generated unital
   `F_2`-algebras, and `F` recursive nondecreasing, such that every `B ∈ 𝓑` has a
   zero test in time `C_B * F(C_B n) + C_B` for some generating set. Put
   `T(l) = 2^(2l) * (1 + F(2^(2l)))`. Every finitely generated subgroup of
   `GL_N(B ⊗ L)`, `N >= 1`, `B ∈ 𝓑`, has a word-problem algorithm within
   `C * T(C l) + C l + C`. So by `complexity-bounded-host-classes-are-not-universal`
   some two-generated group with solvable word problem embeds in no
   `GL_N(B ⊗ L)` with `B ∈ 𝓑`, in particular in no `(B ⊗ L)^x`.

**Meaning.** The Leavitt factor adds at most one exponential to the word problem.
Any construction proving `decidable-groups-embed-in-cantor-crossed-leavitt-tensor-units`
must therefore carry the whole complexity of the input in the base `B`. Every
complexity kill on the group-algebra form
`decidable-group-algebras-have-fp-cantor-crossed-hosts` that runs through a
zero-test bound for `B` passes to the units form unchanged. The first instance is
`free-group-leavitt-tensor-units-are-not-universal`.

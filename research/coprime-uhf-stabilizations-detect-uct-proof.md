All permanence facts cited as P1--P4 are items 1--4 of
`uct-class-permanence-properties`.

**Step 1: the gluing algebra.**  Let

```text
Z = { f ∈ C([0,1], M_s ⊗ M_t) : f(0) ∈ M_s ⊗ 1,  f(1) ∈ 1 ⊗ M_t }.
```

Evaluation at the endpoints gives an exact sequence

```text
0 → C_0((0,1), M_s ⊗ M_t) → Z → M_s ⊕ M_t → 0.                       (D1)
```

**Step 2: K-theory of `Z`.**  Write `Q_r = {a/b : b divides r}` for a
supernatural `r`, so that `K_0(M_r) = Q_r` and `K_1(M_r) = 0`.  The six-term
sequence of (D1) reads

```text
0 → K_0(Z) → Q_s ⊕ Q_t --∂--> Q_{st} → K_1(Z) → 0,    ∂(x, y) = x − y,
```

using `K_1(C_0((0,1), B)) = K_0(B)` and `K_0` of a suspension of an AF algebra
being `0`.  Since `s` and `t` are coprime, `Q_s ∩ Q_t = Z`, so `ker ∂ = Z`,
generated by `(1, 1) = [1_Z]`.  Also `Q_s + Q_t = Q_{st}`: a denominator
`b | st` splits as `b = b_1 b_2` with `b_1 | s`, `b_2 | t` coprime, and Bézout
`u b_2 + v b_1 = 1` gives `1/b = u/b_1 + v/b_2`.  So `∂` is onto, and

```text
K_0(Z) = Z [1_Z],     K_1(Z) = 0.
```

**Step 3: `Z` is KK-equivalent to `C`.**  In (D1) the ideal is the suspension of
an AF algebra and the quotient is AF, so `Z` satisfies the UCT (P2, P4).  The
unital inclusion `ι : C → Z` induces an isomorphism on K-theory.  A KK-element
between UCT algebras that induces an isomorphism on K-theory is invertible
(Rosenberg--Schochet), so `[ι] ∈ KK(C, Z)` is a KK-equivalence.

**Step 4: tensoring with `A`.**  Because `A` is nuclear, tensoring (D1) with `A`
gives an exact sequence

```text
0 → S(A ⊗ M_s ⊗ M_t) → A ⊗ Z → (A ⊗ M_s) ⊕ (A ⊗ M_t) → 0,               (D2)
```

which is semisplit by Choi--Effros, the quotient being nuclear.  Suppose `A ⊗ M_s`
and `A ⊗ M_t` satisfy the UCT.  Then `(A ⊗ M_s) ⊗ M_t` and its suspension
satisfy the UCT (P4), and so does the quotient in (D2).  By P2, `A ⊗ Z`
satisfies the UCT.

**Step 5: back to `A`.**  `id_A ⊗ [ι] ∈ KK(A, A ⊗ Z)` is invertible with inverse
`id_A ⊗ [ι]^{-1}`, so `A` is KK-equivalent to `A ⊗ Z` and satisfies the UCT (P1).
The converse of (CU1) is P4, since `M_s` and `M_t` satisfy the UCT.

**Step 6: the filter.**

* *Upward closure.*  If `P ⊆ P'`, then
  `A ⊗ M_{P'^∞} ≅ (A ⊗ M_{P^∞}) ⊗ M_{(P' ∖ P)^∞}` (P4).
* *Finite intersections.*  For `P, P' ∈ 𝒫(A)` put `B = A ⊗ M_{(P ∩ P')^∞}`,
  which is separable and nuclear.  Then `B ⊗ M_{(P ∖ P')^∞} ≅ A ⊗ M_{P^∞}` and
  `B ⊗ M_{(P' ∖ P)^∞} ≅ A ⊗ M_{P'^∞}` both satisfy the UCT.  If `P ∖ P'` and
  `P' ∖ P` are both nonempty, they are coprime types and (CU1) for `B` gives
  `P ∩ P' ∈ 𝒫(A)`.  Otherwise `P ∩ P'` is `P` or `P'`.
* *The UCT criterion.*  `∅ ∈ 𝒫(A)` is the UCT for `A`.  Two disjoint members
  give it by (CU1) applied to `A` itself, and conversely `∅` is disjoint from
  every member.
* *Nonemptiness.*  If `P ∈ 𝒫(A)`, then `A ⊗ Q ≅ (A ⊗ M_{P^∞}) ⊗ Q` satisfies
  the UCT by P4.  Conversely, the UCT for `A ⊗ Q` puts the set of all primes
  into `𝒫(A)`.
* *At most one prime.*  Two primes `p ≠ q` with `{p}, {q} ∈ 𝒫(A)` are disjoint
  members, which forces the UCT for `A`.

Notation as in the target: `R = Z[1/2][t^±1]`, `M = Z[t^±1]`, `N`, `T`, `Σ`,
`H = N x| <T,Σ>`, `φ`, `C` and `Ĥ = H/C`.

**Step 1 (N is a group, nilpotent of class 2).**
- The product stays in `N`, since `ab' ∈ R·M ⊆ R`. It is the multiplication of
  the matrices `[[1,a,c],[0,1,b],[0,0,1]]`, so it is associative.
- The identity is `(0,0,0)` and `(a,b,c)^-1 = (-a,-b,-c+ab)`.
- `Z_0 = {(0,0,c) : c ∈ R}` is central.
- `[(a,b,c),(a',b',c')] = (0, 0, ab' - a'b) ∈ Z_0`. So `[N,N] ⊆ Z_0` and `N` is
  nilpotent of class at most 2.

**Step 2 (the automorphisms).**
- `T(x)T(y) = (t(a+a'), t^-1(b+b'), c+c'+(ta)(t^-1 b')) = T(xy)`, and
  `T(N) = N` because `t^±1 M = M` and `t^±1 R = R`.
- `Σ(x)Σ(y) = (2a+2a', b+b', 2c+2c'+2ab') = Σ(xy)`. `Σ` is bijective, with
  inverse `(a,b,c) -> (a/2, b, c/2)`, because `1/2 ∈ R`.
- `TΣ = ΣT`, and `T^i Σ^j` fixes `(1,0,0)` only if `t^i 2^j = 1` in `R`, that is,
  `i = j = 0`. So `<T,Σ> ≅ Z^2` and `H = N x| Z^2` is defined.

**Step 3 (four generators).** Put `A = (1,0,0)` and `B = (0,1,0)`.
- `Σ^j T^i A T^-i Σ^-j = (2^j t^i, 0, 0)`, and `(a,0,0)(a',0,0) = (a+a',0,0)`.
  So `<A,T,Σ>` contains every `(a,0,0)` with `a ∈ R`.
- `T^i B T^-i = (0, t^-i, 0)`, and the elements `(0,b,0)` add. So `<B,T>`
  contains every `(0,b,0)` with `b ∈ M`.
- `[(a,0,0),(0,b,0)] = (0,0,ab)`. Since `1 ∈ M`, this gives every `(0,0,c)` with
  `c ∈ R`.
- `(a,b,c) = (a,0,0)(0,b,0)(0,0,c-ab)`. So `H = <A,B,T,Σ>`, and `Ĥ` is
  generated by the images of these four elements.

**Step 4 (C is normal, and the corner becomes Q).**
- **Surjectivity of φ.** `φ` is `Z[1/2]`-linear with `φ(t^i) = 1/|i|!`. Its image
  contains the `Z`-span of `{1/n! : n >= 0}`, which is `Q`: for `p/q` with
  `q >= 1`, `p/q = p(q-1)!/q!`.
- **Normality.** `C = {(0,0,c) : c ∈ ker φ}` lies in the central `Z_0`.
  - `T` fixes `Z_0` pointwise.
  - `Σ(0,0,c) = (0,0,2c)`, and `φ(2c) = 2φ(c)`.
  - So `C` is invariant under `N`, `T` and `Σ`, hence normal in `H`.
- **The corner.** `Z_0 C / C ≅ R / ker φ ≅ Q` through `φ`, and `Σ` acts on it as
  `q -> 2q`.
- **Trivial intersection.** `Z_0 ⊆ N` while `Σ^j ∉ N C` for `j ≠ 0`, since
  `H/N ≅ Z^2` and `C ⊆ N`. So `(Z_0 C/C) ∩ <ΣC> = 1`.
- So the subgroup `<Z_0 C/C, ΣC>` of `Ĥ` is `(Z_0 C/C) x| <ΣC> ≅ Q x|_2 Z = D_2`.

**Step 5 (solvable word problem).**
- **Normal forms.** Every element of `Ĥ` is uniquely `(a, b, q) T^i Σ^j` with
  `a ∈ R`, `b ∈ M`, `q = φ(c) ∈ Q` and `i, j ∈ Z`. Uniqueness holds because
  `H = N x| Z^2`, and two triples `(a,b,c)` and `(a,b,c')` agree modulo `C` iff
  `φ(c) = φ(c')`.
- **Operations.** The product of normal forms is computable:
  - `(T^i Σ^j)(a,b,c) = (t^i 2^j a, t^-i b, 2^j c)`;
  - the corner coordinate composes as `q + q' + φ(ab')`;
  - `φ(ab')` is computable, because `ab'` is an explicit Laurent polynomial over
    `Z[1/2]`.
- **Deciding the identity.** Rewriting a word in the four generators to normal
  form decides whether it is trivial.

**Step 6 (derived length).**
- `H/N ≅ Z^2` is abelian, so `H' ⊆ N`.
- Then `H'' ⊆ [N,N] ⊆ Z_0`, and `H''' ⊆ [Z_0, Z_0] = 1`.
- The same bounds pass to the quotient `Ĥ`. So `Ĥ` is solvable of derived length
  at most 3, and is (class-2 nilpotent)-by-`Z^2`.

This proves items 1–4 of the target.

Notation is as in [[galois-psd-monomial-subpair-has-no-infranormal-trace]] and
[[monomial-origin-level-subpairs-cannot-certify-rank-three-cone]] (cited as (M0)–(M5)).  `S`, `P` are the
generating set and exponent semigroup of (M0), and `P_0 = P ∩ N^d`.

## (N1)

*Facts used.*  By (M0), `B = Ũ x| H`, `Ũ ⊆ 1 + M_3(F_q[P])`, and `e_ij(x^m) ∈ Ũ` for every `m ∈ P`, `i ≠ j`.
Since `K0` is salient, `0 ∉ P` by (M2).  `C = Ũ ∩ Gamma`, and `e_ij(x^m) ∈ C` for `m ∈ P_0`.
`P_0 ⊇ { m ∈ N^d : |m| ≥ k }`, because those `m` lie in `S`.

*Compressors are nonnegative.*  Let `t = u σ ∈ P_C` and `m ∈ P_0`.  Then

```text
t e_ij(x^m) t^-1 = u e_ij(x^(σm)) u^-1 = 1 + x^(σm) (u E_ij u^-1),
```

whose `(i, j)` entry is `x^(σm) u_ii (u^-1)_jj`.  Both `u` and `u^-1` lie in `1 + M_3(F_q[P])`, so
`u_ii (u^-1)_jj = 1 + a` with `a ∈ F_q[P]` (use `P + P ⊆ P`).  As `0 ∉ P`, `a` has no constant term, so the
monomial `x^(σm)` occurs in that entry with coefficient 1.  The element lies in `C ⊆ SL_3(R_+)`, so
`σm ∈ N^d`.  Taking `m = k e_l` gives `k · σ e_l ∈ N^d`, so every column of `σ` lies in `N^d`: `σ ∈ H_≥0`.

*Nonnegative elements are compressors.*  If `σ ∈ H_≥0` then `x^m ↦ x^(σm)` maps `R_+` into `R_+`, so
`σ Gamma σ^-1 ≤ Gamma`, and `σ Ũ σ^-1 = Ũ`.  So `σ C σ^-1 ≤ C`.  Trivially `C ⊆ P_C`.

*The equivalence.*  Let `π : B -> H` be the projection.  If `P_C` generates `B`, then `π(P_C)` generates `H`,
and `π(P_C) ⊆ H_≥0`, so `H_≥0` generates `H`.  Conversely, if `H_≥0` generates `H`, the group generated by
`P_C ⊇ C ∪ H_≥0` contains `U_k ⊆ C` and `H`, hence `B`.

## (N2)

`SL_3(O)` acts on `Sym_3(O)` by `X ↦ g X g^T`.  This is a faithful action of `SL_3(O)` (only `± I` act
trivially, and `det(-I) = -1`), by matrices of determinant 1 in `SL_12(Z)`.  `SL_3(O)` is an irreducible
lattice in `SL_3(R)^2`, so it is infinite and Kazhdan.

*Generators of `K0`.*  `K0` is spanned by the orbits `H · ω v v^T`, that is by the `ω w w^T` with `w = g v`.
`O` is Euclidean, so `SL_3(O)` is transitive on unimodular vectors of `O^3`; every `v ∈ V0` is unimodular.
So the generators are `ω w w^T`, `ω ∈ {1, √2}`, `w ∈ O^3` unimodular.  With `u = 1 + √2`, the vector
`u^n w` is unimodular, so `ω u^(2n) w w^T` is a generator for every `n ∈ Z`.

*`K0` is salient and `K ⊆ PSD × Sym^2 R^3`.*  In the embedding, a generator is
`(ω_+ w_+ w_+^T, ω_- w_- w_-^T)` with `ω_+ > 0` and `w_+ ≠ 0`.  So every nonzero element of `K0` has
`v_+` PSD and nonzero.  If `± v ∈ K0` then `± v_+` are both PSD, so `v_+ = 0` and `v = 0`.  The set
`{ v_+ PSD }` is closed, so it contains `K`.

*`K ⊇ PSD × Sym^2 R^3`.*  The embedding of `ω u^(2n) w w^T` is
`(ω_+ u_+^(2n) w_+ w_+^T, ω_- u_-^(2n) w_- w_-^T)` with `|u_-| = √2 - 1 < 1 < u_+`.  Dividing by `u_+^(2n)`
and letting `n -> +∞` gives `(ω_+ w_+ w_+^T, 0) ∈ K`.  Dividing by `|u_-|^(2n)` and letting `n -> -∞` gives
`(0, ω_- w_- w_-^T) ∈ K`, and `ω_- = ± 1, ± √2` takes both signs.  The unimodular vectors
`(1, a, b)`, `a, b ∈ O`, have directions `w_+` dense in `RP^2`, and likewise `w_-`.  So `K` contains
`PSD × 0` and the line `0 × R w_- w_-^T` for a dense set of `w_-`.  These lines span `0 × Sym^2 R^3`, so
`K ⊇ PSD × Sym^2 R^3`.  Hence `K = PSD × Sym^2 R^3`, with lineality space `V_- = 0 × Sym^2 R^3`.

*Interior.*  For a convex set with nonempty interior in `R^n`, the interior of its closure equals its
interior.  So `K0 ⊇ int K = PD × Sym^2 R^3`.

*The origin image.*  `K0` is salient, so `psi(C) = 1` by (M2).  `H` is infinite and `K` is not pointed, so
(M3) and (M4) do not apply.  This is the residual case (M5).

## (N3)

*The orthant criterion.*  For a real symmetric `Y`, let `c(Y) ∈ R^6` be its coordinates in the basis
`E_ii`, `P_ij`: `c_ij = Y_ij` for `i < j`, and `c_ii = Y_ii - Σ_(j ≠ i) Y_ij`.  Let
`DD = { Y : c(Y) ≥ 0 }`.  It is the cone of symmetric matrices with nonnegative entries that are diagonally
dominant, and `DD ⊆ PSD`.  An element `α = a + b√2 ∈ O` has `a, b ≥ 0` iff `α_+ ≥ |α_-|`, since
`α_+ - α_- = 2b√2` and `α_+ + α_- = 2a`.  The map `c` has rational coefficients, so `c(X)_± = c(X_±)`.
Hence `X ∈ Sym_3(O)` has nonnegative coordinates in the `Z^12` basis iff

```text
X_+ + X_- ∈ DD   and   X_+ - X_- ∈ DD .
```

*Columns of a nonnegative element.*  Let `Sym^2 g ∈ H_≥0` and `w = g e_i`.  The image `w w^T` of the basis
vector `E_ii` is nonnegative, so `w_+ w_+^T - w_- w_-^T ∈ DD ⊆ PSD`.  A difference `a a^T - b b^T` of rank-one
matrices is PSD only if `b = t a` with `|t| ≤ 1`: otherwise some `x ⊥ a` has `x · b ≠ 0` and
`x^T (a a^T - b b^T) x < 0`.  So `w_- = t w_+`.  The ratios of the entries of `w` then equal their Galois
conjugates, so they are rational, and `w = ε w_0` with `w_0 ∈ Z^3` primitive and `ε ∈ O`.  `w` is a column
of an invertible matrix over `O`, so it is unimodular, and `ε` is a unit, `ε = ±u^n`.  Now
`|t| = |ε_- / ε_+| = (√2 - 1)^(2n)`, and `|t| ≤ 1` means `n ≥ 0`.  Next
`(ε_+^2 + ε_-^2) w_0 w_0^T = w_+ w_+^T + w_- w_-^T ∈ DD`, so `w_0 w_0^T ∈ DD`.  A rank-one `w_0 w_0^T ∈ DD` with
`w_0 ≥ 0` (up to sign) has `w_0,i ≥ Σ_(j ≠ i) w_0,j` for every `i` in the support.  Two support entries
`i, j` force `w_0,i = w_0,j` and the third entry zero; three are impossible.  So `w_0 ∈ ± V0`.

*Determinant.*  `1 = det g = ε_1 ε_2 ε_3 det(W_0)` with `W_0 ∈ M_3(Z)` the matrix of the `w_0`.  So
`det W_0 = ±1` and `ε_1 ε_2 ε_3 = ±1`, which gives `n_1 + n_2 + n_3 = 0` with all `n_i ≥ 0`.  So every
`n_i = 0` and `g ∈ SL_3(Z)` has columns in `± V0`.  The same argument with the basis vector `P_ij` shows that
`g e_i + g e_j ∈ ± V0`.

*The finite set.*  So `H_≥0` lies in the image of the finite set of integer matrices of determinant 1 with
columns and pairwise column sums in `± V0` (entries in `{0, ±1}`), and is finite.  A finite submonoid of a
group is a subgroup.  The script enumerates that set: it has six elements, the three even permutation
matrices and the negatives of the three odd ones, and all six are nonnegative on `Z^12`.  `Sym^2` maps them to
the six coordinate permutations of `Sym_3`, so `H_≥0 ≅ S_3`.  Only finiteness is used below.  The script also
checks, on the radius-3 ball of 33438 elements, that no other nonnegative element occurs.

## (N4)

`H_≥0` generates a group of order 6, and `H` is infinite.  By (N1), `C` is not infranormal in `B_(H,k)`, for
every `k ≥ 1`.  So Kun-Thom Theorem A does not apply to `(B, C)`.  The Sym^2 PSD candidate over `Z` was
already dead by (M3); over `Z[√2]` it is dead by (N1) and (N3).

## (N5)

By (M5), a certificate `B_(H,k)` needs `H` infinite and Kazhdan with `K0` salient and `K` not pointed.  By
(N1) it also needs `H_≥0` to generate `H`.  For finite `H`: a nonnegative integer matrix of finite order has a
nonnegative inverse (a power of itself), so it is a permutation matrix.  Then `S ⊆ N^d`, so `Ũ ≤ Gamma` and
`C = Ũ` is normal, which recovers (M4) in this case.  For `H = < [[1,1],[0,1]] >` on `Z^2`, the orbit of the
orthant spans the open upper half-plane together with the ray `R_+ e_1`: salient, with closure the closed
upper half-plane.  So the geometry of (N5) occurs without property (T).

Artifact §5 (Lemma N and Theorem D (c)).

1. By `braided-v-has-continuum-many-normal-subgroups`, `V_br` has a strictly ascending chain of normal subgroups
   `N_1 < N_2 < …`. Its union `N_infinity` is not the normal closure of any finite set.
2. **Lemma N (B. H. Neumann).** Let `G` be generated by a finite set `X` and let `N ◁ G`. If `G/N` is finitely
   presented, then `N` is normally finitely generated.

   *Proof.*
   1. Let `eps : F(X) -> G` be the natural surjection. Let `nu : F(X) -> G/N` be its composite with the quotient
      map, and `K = ker nu`.
   2. Let `<Y | U>` be a finite presentation of `G/N`, with `mu : F(Y) -> G/N`. Choose lifts
      `alpha : F(Y) -> F(X)` with `nu alpha = mu`, and `beta : F(X) -> F(Y)` with `mu beta = nu`.
   3. Let `J` be the normal closure of the finite set `alpha(U) ∪ {x^{-1} alpha beta(x) : x ∈ X}`. Then
      `J ≤ K`, because `nu(alpha(u)) = mu(u) = 1` for `u ∈ U` and
      `nu(x^{-1} alpha beta(x)) = nu(x)^{-1} mu(beta(x)) = nu(x)^{-1} nu(x) = 1`, and `K` is normal.
   4. The map `theta : mu(w) -> alpha(w) J` is a well-defined homomorphism `G/N -> F(X)/J`: `ker mu` is the
      normal closure of `U` in `F(Y)`, and `alpha` maps it into the normal closure of `alpha(U)`, which lies in
      `J`. Let `nubar : F(X)/J -> G/N` be induced by `nu` (possible since `J ≤ K`). For `x ∈ X`,
      `theta(nubar(xJ)) = theta(mu(beta(x))) = alpha(beta(x)) J = xJ`, so `theta ∘ nubar = id`. Hence `nubar` is
      injective, that is, `K = J`.
   5. So `N = eps(K)` is the normal closure in `G` of the finite set `eps(alpha(U) ∪ {x^{-1} alpha beta(x)})`.
3. `V_br` is finitely generated; indeed it is finitely presented (Brin 2007, Dehornoy 2006; arXiv:1403.8132v2,
   Introduction). By Lemma N, `V_br / N_infinity` is not finitely presented.

So some quotient of `bV` is not finitely presented.

A counting argument gives more. `V_br` has only countably many normally finitely generated normal subgroups, but
`2^aleph_0` normal subgroups. So all but countably many quotients of `V_br` are not finitely presented.

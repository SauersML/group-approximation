This corpus keeps producing two-generator perfect groups as candidate nonsofic
quotients, and a normally-one-generated kernel is only one Tietze step away from
a one-relator presentation.  So: take `Q = F_2/K` perfect and nonsofic, discover
that `K = <<x>>_{F_2}` for a single word `x`, and read off `Q = <a, b | x>`, a
nonsofic one-relator group.

**Dead: the kernel is never the normal closure of one element**, by
[[perfect-two-generator-relation-module-not-cyclic]].  The five-term homology
sequence for `1 → K → F_2 → Q → 1` makes the coinvariants `K/[F_2,K]` surject
onto `Z²` when `Q` is perfect, while a cyclic `ZQ`-module has cyclic
coinvariants — and a cyclic abelian group does not surject onto `Z²`.  So `M =
K/[K,K]` is not cyclic and `K` is not normally generated by one element, whatever
`Q` is.

No property of `Q` beyond perfectness is used, and no search is required.  In
particular this applies to the candidate in
`notes/TORSION_FREE_NORMAL_GENERATION_HULL_QUOTIENT.md`, which in any case carries
a standing prohibition banner and is used as an input nowhere in this region.

## What survives the demolition

The kill is tied to `rank(F) = 2` **and** perfectness, and both are load-bearing.

- Over `F_n` the same argument gives `K/[F_n,K] ↠ Z^n`, so cyclicity fails for
  every `n >= 2` as well.  The escape is therefore not "use more generators and
  hope": it is "use more generators and then eliminate them by a construction
  that changes the presentation", which is a different and unformulated plan.
- Once `H_1(Q) ≠ 0` the argument says nothing.  A **nonperfect** nonsofic target
  is untouched by this route's kill, and nothing in the corpus rules one out.

What the route does establish for good is that one-normal-generation is a
homological question, not a presentation-search question — the same lesson
`simple-kl-via-abelianized-relation-module` records from the other direction on
the Kervaire--Laudenbach lane, where the analogous module turned out to be `Z`
and therefore excluded nothing.

## Why sufficient

Let `iota : S -> prod_omega M_(N_n)(k_n)` be the injective unital map.
Choose representatives, so that `iota(x) = [x_n]_omega`.

**Step 1: finitely many exact relations.**  Since `w R_0 w^(-1) <= R_0`, each
`w r_i w^(-1)` lies in `R_0`, so it equals a noncommutative polynomial
`P_i(r_1, ..., r_m)` with integer coefficients.  The finitely many identities

```text
w w' = w' w = 1,   z z' = z' z = 1,   w r_i w' = P_i(r),   z r_i = r_i z,
```

where `w' = w^(-1)` and `z' = z^(-1)`, hold in `S`.  So they hold in the
ultraproduct.  An element of an algebraic ultraproduct is `0` exactly when its
coordinates vanish on an `omega`-large set, and a finite intersection of
`omega`-large sets is `omega`-large.  So there is an `omega`-large set `U`
such that for `n in U` all these identities hold exactly in `M_(N_n)(k_n)`.

**Step 2: the coordinate dimension count.**  Fix `n in U` and let
`A_n <= M_(N_n)(k_n)` be the unital `k_n`-subalgebra generated by
`(r_1)_n, ..., (r_m)_n`.
- Conjugation `x -> w_n x w_n^(-1)` is a `k_n`-algebra automorphism of the
  matrix ring, since `k_n` is central.
- It maps each generator into `A_n`, by the polynomial identities.  Hence it
  maps `A_n` into `A_n`.
- It is an injective `k_n`-linear map of the finite-dimensional space `A_n`
  into itself, so it maps `A_n` onto `A_n`.
- `z_n` commutes with every generator, hence with `A_n`.  Therefore
  `w_n z_n w_n^(-1)` commutes with `w_n A_n w_n^(-1) = A_n`.

In particular `[w_n z_n w_n^(-1), (r_i)_n] = 0` for every `i` and every
`n in U`.

**Step 3: pull back.**  The element `[w z w^(-1), r_i]` of `S` has image
with coordinates vanishing on `U`, so its image is `0`.  Injectivity of `iota`
gives `[w z w^(-1), r_i] = 0` in `S`.
- The centralizer of `w z w^(-1)` is a subring of `S` containing every `r_i`,
  so it contains `R_0`.
- Each generator `w z w^(-1) p w z^(-1) w^(-1) - p` of `I_S` is `0`, so
  `I_S = 0`.

**Consequences.**
1. *Consequence 1.*  If `w` implements `psi` on `R_0 u {z}`, then
   `w z w^(-1) = psi(z)` and `w R_0 w^(-1) = psi(R_0) <= R_0`.  So `psi(z)`
   centralizes `R_0`, and the ideal `I` of (R5) is `0` in `R`.  The skew
   Laurent ring contains `R` and `t` with `t x t^(-1) = psi(x)`.
2. *Consequence 2.*  In the crossed product `LC(X,k) semidirect Lambda`, the
   canonical unit `u_S` implements `psi` on `LC(X,k) semidirect Gamma`.  The
   hypothesis of consequence 1 is then supplied by the cited
   matriciality theorems.

The group-level analogue in locally residually finite targets is
`locally-residually-finite-targets-kill-compression-defects`.  The present
proof also covers characteristic zero and infinite fields, where no finite
quotient is available, because it counts dimensions instead of elements.

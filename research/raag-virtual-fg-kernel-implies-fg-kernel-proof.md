A finitely generated group is of type `FP_1(Z)`. By
`raag-virtual-fp-n-kernel-forces-acyclic-flag-complex` with `n = 1`, `H̃_0(L; Z) = 0`, so `L`
is nonempty and connected.

For connected `L` the kernel `BB_L` of `χ: A_L → Z`, `χ(v) = 1`, is finitely generated.
Elementary proof: let `N` be the subgroup generated by the finite set
`{u v^{-1}, u^{-1} v : {u, v} an edge of L}`. By connectivity and telescoping along edge paths,
`x y^{-1} ∈ N` and `x^{-1} y ∈ N` for all vertices `x, y`. For an edge `{u, v}` and a vertex `w`,
`u` and `v` commute, so
`w (u v^{-1}) w^{-1} = (w v^{-1})(u w^{-1}) ∈ N` and `w^{-1} (u v^{-1}) w = (w^{-1} u)(v^{-1} w) ∈ N`,
and similarly for `u^{-1} v = v u^{-1}`. So `N` is normal. In `A_L / N` all generators have the same
image, so `A_L / N` is cyclic; `χ` vanishes on `N` and maps `A_L / N` onto `Z`, so `A_L / N ≅ Z`
through `χ`, and `N = ker χ = BB_L`.

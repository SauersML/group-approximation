## Statement

Let `d ≥ 2`, `X = {0, …, L}` with `L = d−1`, and `T_d = X^*`. Let `G ≤ Aut(T_d)` be generated
by the states of a finite bounded automaton (so `G` is self-similar, finite-state, bounded).
Let `σ: G → G` be an endomorphism with

```text
σ(g) = (ψ_0(g), …, ψ_{L−1}(g), g)      for all g in G     (trivial root permutation),
```

that is, `σ(G) ≤ St_G(1)` and the section of `σ(g)` at the last letter `L` is `g`. (Then `σ`
is injective, and each `ψ_z` is a homomorphism `G → G`.) Assume

- **(F) finite first sections:** each `ψ_z(G)` is finite; and
- **(E) eventually finitary:** there is `k_0` such that every element of `ψ_z(σ^k(G))` is
  finitary, for all `z < L` and all `k ≥ k_0`.

Then `G*_σ = ⟨G, t | t^{-1} g t = σ(g)⟩` embeds in the Röver–Nekrashevych group `V_d(S)` of a
self-similar group `S ≥ G` generated by a finite bounded automaton. Hence:
1. `G*_σ` embeds in a finitely presented simple group (BBMZ arXiv:2309.06224 Corollary
   `cor:RN_BH`), so it satisfies Boone–Higman;
2. `G*_σ` lies in the permutational class `B_A` (`V_d(S)` has an action of type (A), from the
   proof of BBMZ Proposition `prop:contr_to_simple`).

The stable letter goes to the inverse of an explicit element `s ∈ V_{d}` (in Thompson's `F`
when `d = 2`).

## Instances

| group `G` | `d` | endomorphism `σ` | node |
|---|---|---|---|
| first Grigorchuk group | 2 | Lysenok: `a↦aca, b↦d, c↦b, d↦c` | `grigorchuk-fp-amenable-group-satisfies-boone-higman` |
| Grigorchuk supergroup `G̃` | 2 | Bartholdi: `a↦ab̃a, b̃↦d̃, c̃↦b̃, d̃↦c̃` | `grigorchuk-supergroup-fp-amenable-hnn-satisfies-boone-higman` |
| Fabrykowski–Gupta group `Γ` | 3 | `a ↦ a^{-1}∘r∘a = (1, r, a)`, `r ↦ r` | `fabrykowski-gupta-ascending-hnn-satisfies-boone-higman` |

For the first two, Bartholdi's ascending L-presentations make `G*_σ` finitely presented,
amenable and not elementary amenable. The third is amenable and not elementary amenable;
its finite presentation is not checked.

## What the criterion excludes (checked)

- **Basilica, Grigorchuk–Żuk endomorphism** (`a ↦ b, b ↦ a²`, with `a` the root swap
  followed by sections `(1, b)` and `b = (1, a)`, so `a² = (b, b)`): `σ(a) = (1, a)` and
  `σ(b) = (b, b)`, of last-section form, but the first section `ψ` has `ψ(b) = b` of
  infinite order. The slot values `ψσ^k(b)` run through `b^{2^m}`, so `E_b` is not
  finite-state. (F) fails. `basilica-hnn-extension-is-fp-amenable-non-ea` is not covered.
- **Brunner–Sidki–Vieira group** (Bartholdi's `τ ↦ τ², λ ↦ τ²λ^{-1}τ²`): of last-section
  form with `ψ(τ) = τ`, `ψ(λ) = τ²`, infinite image. (F) fails.
- **Gupta–Sidki group:** Bartholdi's substitution `σ` "does not extend to an endomorphism"
  (arXiv math/0007062, after Thm `thm:GammaBB`). There is no endomorphism to use.

So (F) separates the torsion-type examples (Grigorchuk, Fabrykowski–Gupta), whose first
sections live in finite groups, from the dilation-type ones (Basilica, BSV), where the first
section is a nontrivial power map.

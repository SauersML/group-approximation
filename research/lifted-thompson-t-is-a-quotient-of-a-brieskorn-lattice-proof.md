## Imports

- (I1) Cannon–Floyd–Parry, *Introductory notes on Richard Thompson's groups*, §5. `T` is
  generated by `A`, `B` and `C`, where:
  - `A` maps `[0,1/2]`, `[1/2,3/4]`, `[3/4,1]` affinely onto `[0,1/4]`, `[1/4,1/2]`, `[1/2,1]`;
  - `B` fixes `[0,1/2]` pointwise and maps `[1/2,3/4]`, `[3/4,7/8]`, `[7/8,1]` affinely onto
    `[1/2,5/8]`, `[5/8,3/4]`, `[3/4,1]`;
  - `C` maps `[0,1/2]`, `[1/2,3/4]`, `[3/4,1]` affinely onto `[3/4,1]`, `[0,1/2]`, `[1/2,3/4]`.
- (I2) Poincaré's polygon theorem, for the hyperbolic triangle with angles `π/4, π/3, π/5`. The
  angles sum to less than `π`, since `1/4 + 1/3 + 1/5 = 47/60 < 1`.
  - Let `x_F` and `y_F` be the rotations by `2π/4` and `2π/3` about the first two vertices.
  - Then `Γ = ⟨x_F, y_F⟩ ≤ PSL_2(R)` is discrete and cocompact.
  - `x ↦ x_F`, `y ↦ y_F` is an isomorphism `Δ → Γ`.
- (I3) `G̃` is torsion-free, and `ker(G̃ → PSL_2(R)) = ⟨τ⟩`.
  - A lift `g̃` of an element `g` of order `m` in `PSL_2(R)` has `g̃^m ∈ ⟨τ⟩`.
  - `g̃^m = τ^{m·rot(g̃)}`, where `rot` is the translation number on `R`.
- (I4) Cherix–Cowling–Jolissaint–Julg–Valette, *Groups with the Haagerup property*, Thm 4.0.1.
  `G̃` is locally isomorphic to `SU(1,1)`, so it has the Haagerup property, and so does every
  closed subgroup of it.

## Step 1: part (A), exact computation

**The code.**
- `pl.py` implements degree-one PL lifts with rational breakpoints. Composition and inversion are
  exact, on breakpoints.
- `run.py` defines `α̃`, `β̃`, `A`, `B`, `C` and verifies, as exact identities of PL maps of `R`:
  - `α̃^4 = z`, `β̃^3 = z`, `(β̃α̃)^5 = z^3` and `(α̃β̃)^5 = z^3`;
  - that no smaller positive power of `α̃`, `β̃` or `β̃α̃` is a translation, so the orders in `T`
    are `4`, `3` and `5`.
- `gen.py` finds, by breadth-first search in the Cayley graph, `A ≡ α α β`, `B ≡ β α β` and
  `C ≡ β^{-1}` modulo `⟨z⟩`. By (I1), `α` and `β` generate `T`.

**Hand check.**
- `α̃^4 = z` is immediate.
- `β̃` maps `[0,1/2] → [1/2,3/4] → [3/4,1] → [1,3/2]` with slopes `1/2, 1, 2`. So on each piece
  `β̃^3` is affine of slope `1`, and `β̃^3(0) = 1`; hence `β̃^3 = z`.
- `C = β^{-1}`: `β^{-1}` maps `[0,1/2]` onto `[3/4,1]` with slope `1/2`, as `C` does, and
  similarly on the other two pieces.
- The orbit of `0` under `g = β̃α̃` is `0 → 5/8 → 5/4 → 7/4 → 5/2 → 3`. Each step is `α̃` (add
  `1/4`) followed by `β̃`. Reduced mod 1, the points `0, 5/8, 1/4, 3/4, 1/2` are distinct, so
  `g^5(0) = 3`. The exact computation shows `g^5` is a translation, hence `g^5 = z^3`.
- `A = ααβ` sends `0 ↦ β: 1/2 ↦ α^2: 1 ≡ 0`, and `A(0) = 0` ✓. The full identities are the exact
  checks in `gen.py`.

## Step 2: part (B)

**The map `q`.** By Step 1, `x ↦ α̃`, `y ↦ β̃` respects the relations of `Λ`:
- `α̃^4 = z = β̃^3`;
- `(β̃α̃)^5 = z^3 = α̃^{12}`.

So `q : Λ → T̄` is a homomorphism, with `q(c) = z`.

**Surjectivity.** `q` is onto. Its image contains `z = α̃^4` and lifts of the generators `α, β`
of `T`, and `ker(T̄ → T) = ⟨z⟩`.

**The kernel `N̂`.**
- `q(c^m) = z^m ≠ 1` for `m ≠ 0`, so `N̂ ∩ ⟨c⟩ = 1`.
- The projection `Λ → Λ/⟨c⟩ = Δ` maps `N̂` into `N`, because `q` covers `Δ → T`.
- It is injective on `N̂`, since `N̂ ∩ ⟨c⟩ = 1`.
- It is onto `N`. Given `n ∈ N`, lift it to `g ∈ Λ`. Then `q(g) ∈ ⟨z⟩`, say `q(g) = z^m`, and
  `g c^{-m} ∈ N̂` maps to `n`.

**`N` is non-trivial.** `T` is infinite and simple, so it is not residually finite. `Δ ≅ Γ` is
finitely generated and linear, so it is residually finite (Malcev). Hence `Δ → T` is not injective.

**`N` is non-elementary.**
- `Δ` has no non-trivial finite normal subgroup `K`. Otherwise `Fix(K) ⊂ H^2` would be a non-empty
  `Γ`-invariant totally geodesic subspace, and `Γ` is non-elementary, so `Fix(K) = H^2`, i.e.
  `K = 1`. So `N` is infinite.
- The limit set of `N` is non-empty, closed and `Γ`-invariant, hence all of `∂H^2`.
- So `N` is a non-elementary Fuchsian group, and it contains `F_2`, by ping-pong on loxodromics
  with disjoint fixed points.

## Step 3: part (C)

**Λ is perfect.**
- With `a = [x]` and `b = [y]`, `H_1(Λ)` is `Z^2` modulo the relations `4a − 3b` and
  `5(a+b) − 12a = −7a + 5b`.
- `det [[4, −3], [−7, 5]] = 20 − 21 = −1`, so `H_1(Λ) = 0`.

**Lifting the Fuchsian generators.**
- By (I2), `x_F`, `y_F` and `y_F x_F` are elliptic of orders `4, 3, 5`.
- Let `X̃`, `Ỹ` be lifts with translation numbers `j_1/4` and `j_2/3` in `(0,1)`.
- By (I3), `X̃^4 = τ^{j_1}`, `Ỹ^3 = τ^{j_2}` and `(ỸX̃)^5 = τ^{j_3}`, for integers `j_1, j_2, j_3`.

**Shifting by central powers.**
- Put `n := 12 j_3 − 15 j_1 − 20 j_2`.
- `n ≡ −15 j_1 ≡ j_1 (mod 4)` and `n ≡ −20 j_2 ≡ j_2 (mod 3)`, so `a := (n − j_1)/4` and
  `b := (n − j_2)/3` are integers.
- Set `X := X̃ τ^a` and `Y := Ỹ τ^b`, where `τ` is central.
- Then `X^4 = τ^{j_1 + 4a} = τ^n` and `Y^3 = τ^{j_2 + 3b} = τ^n`.
- Also `(YX)^5 = τ^{j_3 + 5a + 5b}`, and
  `12(j_3 + 5a + 5b) = 12 j_3 + 15(n − j_1) + 20(n − j_2) = 35n + n = 36n`.
  So `(YX)^5 = τ^{3n} = X^{12}`.
- Hence `x ↦ X`, `y ↦ Y` defines `ι : Λ → G̃` with `ι(c) = τ^n`.

**`n ≠ 0`.** If `n = 0`, then `X^4 = 1` with `X ≠ 1`, since `X` covers `x_F ≠ 1`. This contradicts
(I3), because `G̃` is torsion-free.

**`ι` is injective.**
- Composing with `G̃ → PSL_2(R)` gives `Λ → Λ/⟨c⟩ = Δ ≅ Γ`. So `ker ι ⊂ ⟨c⟩`.
- `ι(c^m) = τ^{nm} ≠ 1` for `m ≠ 0`. So `ι` is injective.

**The image is a cocompact lattice.** It lies in the preimage `Γ̃` of `Γ`, which is discrete and
cocompact. It meets `⟨τ⟩` in `⟨τ^n⟩` and maps onto `Γ`, so it has index `|n|` in `Γ̃`.

**The centre.** The image of `Z(Λ)` in `Γ` is central, and `Γ` is centreless because it is
non-elementary. So `Z(Λ) ⊂ ⟨c⟩`, and `c` is central, so `Z(Λ) = ⟨c⟩`.

**The quotient manifold.** `G̃ ≅ R^3` is contractible. `ι(Λ)` is torsion-free, discrete and
cocompact. So `Λ\G̃` is a closed orientable aspherical 3-manifold, and `H_1 = 0` because `Λ` is
perfect.

**Remark (recalled, not used).**
- Counterclockwise rotations give `j_1 = j_2 = 1`, and `j_3 ∈ {1, 4}`.
- Milnor's presentation `⟨γ_1, γ_2, γ_3 | γ_1^4 = γ_2^3 = γ_3^5 = γ_1γ_2γ_3⟩` of `Γ̃` has
  `H_1 = Z/13`. `Λ` is perfect, so `Λ ⊂ [Γ̃, Γ̃]`, and `13 | n`.
- That forces `j_3 = 4` and `n = 13`, so `Λ = [Γ̃, Γ̃] = π_1 Σ(3,4,5)` (Milnor 1975).

## Step 4: part (D)

**`(Λ, ⟨c⟩)` fails relative (T).**
- By (I4) and Step 3, `Λ` has the Haagerup property. It has a proper cnd function `ψ`, e.g. the
  pullback of one on `G̃`.
- `⟨c⟩` is infinite, so `ψ(c^m) → ∞`.

**The kill.** Let `(★)` be any argument whose premises are relations among `α̃`, `β̃`, `z` that hold
for `x, y, c` in `Λ`, and whose conclusion is that every cnd function is bounded on the centre.
- `(★)` applies verbatim to `Λ`, which contradicts the previous paragraph.
- This covers `α̃^4 = β̃^3 = z`, `(β̃α̃)^5 = z^3` and all their consequences. It also covers
  anything that uses only the translation numbers `1/4`, `1/3`, `3/5`: these are the numbers `j/m`
  read off from `x^4 = c`, `y^3 = c`, `(yx)^5 = c^3`.
- So a valid argument must use a relation of `T̄` that fails in `Λ`, i.e. a non-trivial element of
  `N̂`.

**Consequences stated in the target.**
- A cnd function on `T̄` is the same as a cnd function on `Λ` vanishing on `N̂`. Such a function is
  constant on `N̂`-cosets, by `|√ψ(gn) − √ψ(g)| ≤ √ψ(n)`.
- Twist costs can only increase along `Λ → T̄`, since every representation of `T̄` is one of `Λ`.

∎

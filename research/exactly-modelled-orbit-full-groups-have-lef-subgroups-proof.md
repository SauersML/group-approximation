**The finite data.** Fix `r` and `B = B_(2r)(Γ)`. By `c_(gh)(x) = c_g(hx)·c_h(x)`, the level sets of `c_g`, `g ∈ B`, lie in
a finite algebra `𝒜_0 ⊆ 𝒜`, generated by translates of the generators' level sets by the finite set `F` of cocycle
values on `B`. Take an exact model `(E, σ, β)` for `(F, 𝒜_0, ε)`.

**The model.** Put `ĝ(v) = σ(λ)v` for `v ∈ β{c_g = λ}`.

1. **Permutation.** `{c_g = λ}` partition `X`, and so do `λ{c_g = λ}`. `β` is Boolean and equivariant, so both
   `β{c_g = λ}` and `σ(λ)β{c_g = λ}` partition `E`.
2. **Exact multiplicativity.** For `v ∈ β({c_h = λ_2} ∩ λ_2^(-1){c_g = λ_1})`, `ĥv = σ(λ_2)v ∈ β{c_g = λ_1}`, so
   `ĝĥv = σ(λ_1λ_2)v`. On that set `c_(gh) = λ_1λ_2`, so `\widehat{gh}v = σ(λ_1λ_2)v`. These sets partition `X`, so
   `ĝĥ = \widehat{gh}` for `g, h ∈ B_r(Γ)`.
3. **Injectivity.** For `g ≠ 1` in `B`, essential freeness gives `μ{c_g ≠ e} = μ{gx ≠ x} > 0`. Outside `⋃_(λ∈F) Fix σ(λ)`,
   `ĝ` moves each point of `β{c_g ≠ e}`, and there are at least `(μ{c_g ≠ e} − ε − |F|ε)|E| > 0` of them for small `ε`. So
   `ĝ ≠ 1`, and by step 2, `ĝ ≠ ĥ` for distinct `g, h ∈ B_r(Γ)`.

So `g ↦ ĝ` is an injective partial homomorphism of `B_r(Γ)` into the finite group `Sym(E)`, for every `r`, and `Γ` is
LEF. ∎

**The instances.**
- **Profinite actions:** take `E = Λ/Λ_k` with the translation action and `β` the level-`k` cylinders; this is exact, and
  free off a vanishing set for large `k`.
- **Bernoulli shifts of LEF groups:**
  - with `ι : B_R(Λ) -> Q` an injective partial homomorphism into a finite group, put `E = A^Q × Q`,
    `λ·(c,q) = (c, qι(λ)^(-1))`, and `β{x|_W = p} = {(c,q) : c(qι(h)) = p(h), h ∈ W}`;
  - equivariance holds because `ι` is multiplicative on the ball;
  - the counts `|A|^(−|W|)` are exact because `h ↦ qι(h)` is injective on `W`;
  - freeness holds because `q ↦ qι(λ)^(-1)` has no fixed points for `λ ≠ e`.
- **Dual actions of `G_X`:** the finite linear models of the ring act exactly on `F_2^(3N)`. Sets defined by finitely
  many characters get counts `2^(−dim)`, exactly equivariant on balls.

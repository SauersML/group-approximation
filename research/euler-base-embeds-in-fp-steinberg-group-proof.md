**1.** `T_l` is a finitely presented unital ring (`euler-triangular-ring-is-fp-rf`, item 1), so
`St_N(T_l)` is finitely presented for `N >= 5` (`steinberg-groups-of-fp-rings-are-fp-in-rank-five`).

**2.** `ι : M -> T_l` is additive, and `x_12(a) x_12(b) = x_12(a+b)`, so the map is a homomorphism. Its
composite with `St_N(T_l) -> E_N(T_l)` is `n -> e_12(ι(n))`, whose `(1,2)` entry is `ι(n)`. So it is
injective.

**3.**
- *Finitely generated.* `E_N(T_l)` is generated by the `e_ij(g)` with `g` among the six ring generators
  and 1, because `N >= 3` and `[e_ij(a), e_jk(b)] = e_ik(ab)`.
- *Residually finite.* `T_l` is residually finite (item 2 of the ring node). For `1 != g in GL_N(T_l)`,
  some entry of `g - I` survives in a finite quotient ring, and `GL_N` of a finite ring is finite.
- *Contains `G_l`.* `G_l <= T_l^×` by item 4 of the ring node.
  `diag(a, a^(-1)) = e_12(a) e_21(-a^(-1)) e_12(a) · e_12(-1) e_21(1) e_12(-1)` for any unit `a` of a
  ring (Whitehead). So `g -> diag(g, g^(-1), 1, ..., 1)` is an injective homomorphism into `E_N(T_l)`. ∎

Put

```text
S=s_0,             T=t_0,             Q=1-ST=s_1t_1,
H=x_(c_2,c_1)(Q),
U=x_(c_1,c_0)(T),
V=x_(c_0,c_3)(S).                                      (QJM1)
```

The shortest mixed-orientation chain is

```text
C_1=[H,U]=x_(c_2,c_0)(QT),
W=[C_1,V]=x_(c_2,c_3)(QTS)=x_(c_2,c_3)(Q).             (QJM2)
```

Thus a raw negative letter and a raw positive letter return the same
finite-dimensional-invisible head coefficient on a noncentral qutrit
root. The last equality uses `TS=1` and cannot occur in either
one-letter triangular algebra.

With `E=(1-H)/2` define

```text
P=E(1+C_1)/2,
G=P(1+W)/2.                                             (QJM3)
```

Then `P,G` are projections and the two exact polar identities are

```text
(EUE)^2=P,
(PVP)^2=G.                                              (QJM4)
```

For every joint `C=<J,Z>` character atom `z`,

```text
tau(zE)=1/18,          tau(zP)=1/36,
tau(zG)=1/72.                                           (QJM5)
```

Consequently, for `R=e_0+e_1`,

```text
tau(ER)=1/9,           tau(PR)=1/18,
tau(GR)=1/36.                                           (QJM6)
```

The first mixed polar exactly fits the target `Ee_2` of trace `1/18`;
the second uses only half of that target. In particular the routed
operator

```text
e_2g_1GR
```

has polar source of trace at most `1/36` and range below `Ee_2`. The
first nonabsorbed coefficient relation therefore still produces no Hall
excess.

Let `K=GL_28(F_2)`. The generated group is exactly

```text
<K,H,U,V>=EL_28(J),
J=F_2<S,T | TS=1>.                                     (QJM7)
```

It is finitely presented and is not residually finite. More sharply, every
finite-dimensional unitary representation kills the normal subgroup
generated by the `Q`-roots, including `H,C_1,W`. Thus there is no finite
regular absorber which retains the canonical head carrier: `(QJM2)` is
the first routed packet to pass that gate.

This is an exact algebraic candidate, not a nonhyperlinearity theorem.
The established Jacobson results do not decide whether `EL_28(J)` is
hyperlinear, and `(QJM6)` supplies no trace contradiction. The next
relation must recombine complementary sign branches of `C_1` and `W`
so that their joint polar covers more than one complement capacity,
rather than selecting the single quarter `G`.

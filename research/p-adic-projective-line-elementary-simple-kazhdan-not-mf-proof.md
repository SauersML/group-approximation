Details are in `research/artifacts/un-boundary-families-2026-09-13-part1.md`, §6.

- **Cantor.** `P^1(Q_p)` is the one-point compactification of `Q_p`. It is compact, metrizable, totally disconnected
  and perfect.
- **Unipotents.** `d_p^k e_12(1) d_p^(-k) = e_12(p^(2k))`. Every `b ∈ Z[1/p]` is `n p^(2k)` with `n ∈ Z` and
  `k <= 0`, so `e_12(b) ∈ Γ_p`. The same holds for `e_21`.
- **Minimal.** `Z[1/p]` is dense in `Q_p`, so the closure of `Γ_p` contains `e_12(Q_p)` and `e_21(Q_p)`, which
  generate `SL_2(Q_p)`.
  - `PSL_2(Q_p)` is transitive on `P^1(Q_p)`.
  - For `x ∈ X` and open `U != ∅`, the set `{g : gx ∈ U}` is open and nonempty, so it meets `Γ_p`.
- **Topologically free.** An element fixing an open set pointwise fixes infinitely many points. A Möbius
  transformation fixing three points is trivial in `PGL_2`.
- **(H-gen).** `Γ_p` is finitely generated by definition. Take `𝒫 = {Z_p, pZ_p}`.
  - For a ball `a + p^m Z_p`, pick `b ∈ Z[1/p]` with `a - b ∈ p^m Z_p` and write `m = 2k + ε` with `ε ∈ {0,1}`.
  - Then `φ = e_12(b) d_p^k ∈ Γ_p` maps `p^ε Z_p` onto `a + p^m Z_p`.
  - Balls separate points of `P^1(Q_p)`, since balls never contain `∞`.
- **North–south.** `g = d_p` is `z ↦ p^2 z`, with `ξ^+ = 0` and `ξ^- = ∞`.
  - A compact `K ⊆ Q_p` is bounded, so `g^n K -> 0` uniformly.
  - A compact `K ∌ 0` is bounded away from `0`, so `g^(-n) K -> ∞` uniformly.

Now `north-south-minimal-cantor-action-is-paradoxical` gives (H-par), and
`paradoxical-cantor-actions-give-simple-kazhdan-not-mf` gives the statement.

Fix `D`.  There is a modulus `omega_D(t)->0` as `t->0` with the following
property.  Let `Q_1,...,Q_L` be reflections in a finite tracial matrix
algebra and suppose the von Neumann algebra `N` they generate has only
type-I central summands

```text
 N_z = M_(r_z) tensor I_(m_z),       r_z<=D.             (BTN1)
```

Put

```text
 beta=L^(-2)sum_(i,j)||[Q_i,Q_j]||_2^2.                  (BTN2)
```

Then there are pairwise commuting reflections `S_1,...,S_L` in `N` such
that

```text
 L^(-1)sum_i ||Q_i-S_i||_2^2 <= omega_D(beta).           (BTN3)
```

Now let the coordinates carry bounded-width parity checks with bounded
column occurrence and a uniform classical LTC soundness constant.  If the
average squared parity-word defect is `eta`, the `S_i` can be changed once
more, in the same matrix algebra, to commuting reflections `S_i'` whose
joint PVM is supported on the classical code and

```text
 L^(-1)sum_i ||Q_i-S_i'||_2^2
   <= Omega_D(beta)+O(eta),                              (BTN4)
```

where `Omega_D(t)->0` depends only on `D` and the fixed code parameters.

Thus a genuinely noncentral diffuse far sector of the balanced overlay
cannot have uniformly bounded irreducible type.  Any countermodel left by
projective erasure cleaning must put nonvanishing trace on irreducible
blocks whose dimensions tend to infinity.  This is a localization theorem,
not full basin capture: normalized-HS small commutators do not bound the
type of `N`, and the occurrence synchronization step must still produce one
shared tuple before `(BTN1)` is meaningful.

Notation as in the target. Inputs, used verbatim:
- **[U1]** from `mod-s2-real-untwisting-identifies-deligne-norm-parameters`: `f : M -> R` with
  `f(x) + f(y) - f(xy) = b(pi x, pi y)`; `f|_K` is a homomorphism; `r = f(t_s) = a/10`, `a in Z`, `3 ∤ a`;
  `sigma = f|_K / r : K -> Z` equals `1` on every separating twist. `b` is the normalized integral cocycle of the
  universal-cover extension, so `b(e, g) = b(g, e) = 0`.
- **[Mess]** from `genus-two-torelli-freely-generated-by-separating-twists`: `K` is generated by separating twists,
  and two separating curves give the same splitting iff they differ by an element of `K`.
- **[DR2]** from `deligne-covers-of-sp2g-z-have-finite-residual-2z`: for the preimage `Gamma~` of `Gamma` in the
  universal cover, `Res_fin(Gamma~)` contains `2Z` (the kernel generated by `z`).

Standard group cohomology used without citation: pushout of an extension along an invariant homomorphism
(Brown, *Cohomology of Groups*, IV.3); triviality of the conjugation action of `Gamma` on restricted classes in
`H^*(Gamma')` (Brown III.8.3); `H^2(G; Z/n) -> H^2(G; Q/Z)` has kernel the Bockstein image of `H^1(G; Q/Z)`.

## Step 0. The orbit homomorphisms chi_D

For a separating curve `c` write `split(c)` for its splitting. If `split(c) = split(c')` then `c' = k(c)` with
`k in K` [Mess], so `t_{c'} = k t_c k^{-1}` and every homomorphism `K -> Z` takes the same value on both. `K` is
free on one twist per splitting [Mess], so for each orbit `D` there is a unique homomorphism `chi_D` with
`chi_D(t_c) = 1_D(split(c))` for **every** separating curve `c`.

Invariance. For `x in M'`, `x t_c x^{-1} = t_{x(c)}` and `split(x(c)) = pi(x) split(c)`. Since `D` is
`Gamma'`-invariant, `chi_D(x t_c x^{-1}) = chi_D(t_c)`. Both sides are homomorphisms in `k in K` and `K` is
generated by separating twists, so `chi_D` is `M'`-conjugation invariant.

More generally, for `x in M` with `pi(x) = gamma`, the same computation gives
`chi_D(x k x^{-1}) = chi_{gamma^{-1} D}(k)` whenever `gamma` normalizes `Gamma'`.            (0.1)

Sum. `sum_D chi_D` and `sigma` are homomorphisms that agree (value `1`) on every separating twist, so
`sum_D chi_D = sigma`. The sum is finite: `m(Gamma') <= [Gamma : Gamma']`.

## Step 1. Cocycles, and the identity (NP0)

Fix a section `s : Gamma' -> M'` with `s(e) = e`, and set `u(g, h) = s(g) s(h) s(gh)^{-1} in K`. For an
`M'`-invariant homomorphism `chi : K -> A` (`A = Z` or `R`), the function `chi o u` is a 2-cocycle. Its class is the
class of the pushout extension `(A x M') / {(-chi(k), k)}` of `Gamma'` by `A`, and it does not depend on `s`
(Brown IV.3). So `v_D = [chi_D o u] in H^2(Gamma'; Z)`, and since `sum_D chi_D = sigma` exactly,

    sum_D v_D = [sigma o u]   in H^2(Gamma'; Z).                                     (1.1)

Compute `f o u`. For `k in K`, [U1] with `b(e, .) = 0` gives `f(k y) = f(k) + f(y)`. Apply this to
`u(g, h) s(gh) = s(g) s(h)` and use [U1] once more:

    f(u(g, h)) + f(s(gh)) = f(s(g) s(h)) = f(s(g)) + f(s(h)) - b(g, h).

With `F = f o s` this reads `f o u = dF - b` on `Gamma'`, where `dF(g, h) = F(g) + F(h) - F(gh)`. Since
`f|_K = r sigma`, we get `r [sigma o u] = -res b` in `H^2(Gamma'; R)`, that is `a [sigma o u] = -10 res b`.

The coefficient inclusion `Q -> R` splits as a map of Q-vector spaces (trivial modules), so
`H^2(Gamma'; Q) -> H^2(Gamma'; R)` is injective. Both sides are rational classes, so the identity holds in
`H^2(Gamma'; Q)`. With (1.1):

    sum_D v_D = -(10/a) res b   in H^2(Gamma'; Q).                                    (NP0)

## Step 2. Deligne on a finite-index subgroup

**Lemma 2.1.** Let `Gamma' <= Gamma` have finite index and `q in Q`. If `beta(q) in H^2_fin(Gamma'; Q/Z)`, then
`q in (1/2)Z`.

*Proof.* Write `q = j/n` in lowest terms with `n >= 1`, and suppose `n >= 3`. Let `Gamma~'` be the preimage of
`Gamma'` in `Gamma~`; it is the extension of `Gamma'` by `Z = <z>` with class `res b`.

(i) `Res_fin(Gamma~')` contains `2Z`. `Gamma~'` has finite index in `Gamma~`, so every finite-index subgroup `L`
of `Gamma~'` has finite index in `Gamma~` and contains `Res_fin(Gamma~)`. Hence
`Res_fin(Gamma~) <= Res_fin(Gamma~')`, and [DR2] gives `2Z <= Res_fin(Gamma~')`.

(ii) The class `beta(q)` is the image of `e_n = j (res b mod n) in H^2(Gamma'; Z/n)` under the injection
`Z/n -> Q/Z`, `1 -> 1/n`. By hypothesis `beta(q) = inf(c)` for a finite quotient `Gamma' -> F` and
`c in H^2(F; Q/Z)`. `c` has finite order, so it comes from `c' in H^2(F; Z/n')` for some multiple `n'` of `n`.
Let `e' in H^2(Gamma'; Z/n')` be the image of `e_n` under `Z/n -> Z/n'`, `1 -> n'/n`. Then `e'` and `inf(c')`
have the same image in `H^2(Gamma'; Q/Z)`. Their difference is a Bockstein of some `phi in Hom(Gamma', Q/Z)`.
`phi` has finite image, because `Gamma'` is finitely generated, so the difference is inflated from the finite
quotient `Gamma' / ker phi`. Passing to the common finite quotient `Gamma' / (N cap ker phi)`, where `N` is the
kernel of `Gamma' -> F`, `e'` is inflated from a finite group `F'`.

(iii) The extension `E'` of `Gamma'` by `Z/n'` with class `e'` is the pushout of `Gamma~'` along
`psi : Z -> Z/n'`, `1 -> j n'/n`. Since `e'` is inflated from `F'`, `E'` is the pullback of an extension `E_F'` of
`F'` by `Z/n'`, and the projection `E' -> E_F'` is injective on `Z/n'`. Composing, we get a homomorphism from
`Gamma~'` to the finite group `E_F'` whose restriction to `Z` is `psi`. Its kernel `L` has finite index and
`L cap Z = ker psi = nZ`, because `gcd(j, n) = 1`. By (i), `2Z <= nZ`, so `n | 2`, contradicting `n >= 3`. ∎

**Corollary 2.2 (NP1).** Apply (NP0) with `Gamma' = Gamma`: there is one orbit and `v_Gamma = -(10/a) b`
rationally. `iota` kills images of integral classes, so `beta(-10/a) = iota(v_Gamma) = 0`, which lies in `H^2_fin`.
Lemma 2.1 gives `10/a in (1/2)Z`, that is `a | 20`.

## Step 3. The Maslov coordinate and its conjugation symmetry

Let `Gamma'` be normal in `Gamma`, `m = m(Gamma')`, and put `S = beta(Q) + H^2_fin(Gamma'; Q/Z)`, a subgroup
(two finite quotients have a common finite quotient). Suppose, for contradiction, that `x_D = iota(v_D / m)` lies
in `S` for some orbit `D`.

**Coordinate.** For `x in S` choose `q` with `x - beta(q) in H^2_fin`. By Lemma 2.1, `q` is unique modulo
`(1/2)Z`, so `C(x) = q mod (1/2)Z` defines a homomorphism `C : S -> Q/(1/2)Z`, with `C(beta(q)) = q` and
`C = 0` on `H^2_fin`.

**Symmetry.** For `gamma in Gamma`, conjugation `c_gamma` preserves `Gamma'`. `c_gamma^*` fixes `res b` (Brown
III.8.3) and preserves `H^2_fin` (it carries the kernel `N` of a finite quotient to `gamma^{-1} N gamma`), so it
preserves `S`, and `C o c_gamma^* = C` on `S`. Choose `x in M` with `pi(x) = gamma` and set `s'(g) = x^{-1} s(gamma g gamma^{-1}) x`,
another section. Then `u(gamma g gamma^{-1}, gamma h gamma^{-1}) = x u'(g, h) x^{-1}`, where `u'` is the cocycle of `s'`. By (0.1),
`c_gamma^* v_D = [chi_D(x u' x^{-1})] = [chi_{gamma^{-1} D} o u'] = v_{gamma^{-1} D}`, using that the pushout class does not depend on
the section. Since `Gamma'` is normal, `Gamma` permutes the `Gamma'`-orbits transitively
(`gamma (Gamma' y) = Gamma' (gamma y)`). Hence every `x_{D'}` lies in `S`, and `C(x_{D'}) = C(x_D) =: gamma_0` for all
`D'`.

## Step 4. The contradiction, giving (NP2)

(a) `m x_D = iota(v_D)` is the image of an integral class, hence `0`. So `m gamma_0 = 0` in `Q/(1/2)Z`, that is
`gamma_0 = j/(2m) mod (1/2)Z` for some `j in Z`.

(b) Summing over the `m` orbits and using (NP0) divided by `m`: `sum_D x_D = beta(-10/(a m))`. Apply `C`:
`m gamma_0 = -10/(a m) mod (1/2)Z`.

Now (a) gives `m gamma_0 = j/2 in (1/2)Z`, so by (b) `10/(a m) in (1/2)Z`, that is `m | 20/a`. (By (NP1),
`20/a` is an integer.) This contradicts the hypothesis `m ∤ 20/a`. So no `x_D` lies in `S`. The order of `x_D`
divides `m` by (a). ∎

## Step 5. Orbit counts, giving (NP3)

For `Gamma'` normal, the `Gamma'`-orbits on `Gamma/Gamma_s` are the cosets `Gamma / (Gamma' Gamma_s)`. For
`Gamma' = Gamma(p)` this is `|Sp_4(F_p)| / |im Gamma_s|`. Reduction `SL_2(Z) -> SL_2(F_p)` is onto, and the
swap of the two planes maps outside `SL_2(F_p)^2`, so `|im Gamma_s| = 2 |SL_2(F_p)|^2 = 2 p^2 (p^2-1)^2`. With
`|Sp_4(F_p)| = p^4 (p^2 - 1)(p^4 - 1)`:

    m(Gamma(p)) = p^2 (p^4 - 1) / (2 (p^2 - 1)) = p^2 (p^2 + 1) / 2,   so m(Gamma(2)) = 10 and m(Gamma(3)) = 45.

Check: `F_3^4` has `|Sp_4(F_3)| / |Sp_2(F_3)|^2 = 51840/576 = 90` nondegenerate planes, which gives `45`
unordered splittings. If `Gamma'' <= Gamma'` then every `Gamma'`-orbit is a union of `Gamma''`-orbits, so
`m(Gamma'') >= m(Gamma')`. Hence every normal `Gamma' <= Gamma(3)` has `m >= 45 > 20 >= 20/|a|`, and (NP2) applies. ∎

## What this kills

Take a Torelli-abelian finite-image model on level `Gamma'`, with multiplier class
`(alpha/r) res b + sum_D h_D v_D`. Consider every argument for the gap (B) that reads a single Maslov coordinate
modulo profinite classes, extended linearly or Zhat-linearly to the span of the `v_D`, and concludes
`alpha/r in (1/2)Z + O(|h|)`. Each such argument needs `x_D in S` at the step where the coordinate is evaluated
on `h_D v_D`. That step fails at `h_D = 1/m`, on every normal level contained in `Gamma(3)`. The invariant is the
nonzero quotient `H^2(Gamma'; Q/Z) / S`, which contains the image of each `x_D`.

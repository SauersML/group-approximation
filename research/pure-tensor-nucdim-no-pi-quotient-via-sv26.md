Full proof: artifact Section 8 (Theorem D), steps (a)--(k).

By `nucdim-factor-transfers-m-comparison`, `Cu(C)` has `m`-comparison (pure
`A` has almost unperforated `Cu(A)`); by
`nucdim-factor-transfers-bounded-divisibility`, `C` has the bounded
divisibility with `M = 2(m+1)`.  Let `M_1 = 2M^3` and `L = 32(m+1)^3 = 2M_1`.
It suffices to verify the two-piece splitting of item 2 of
`sv26-bounded-divisibility-dimension-reduction`.  Work in the stabilization
`cC = C tensor K`.

Given `x' << x = [f]` and `eps` with `x' <= [(f-2eps)_+]`, item 1 of
`sv26-bounded-divisibility-dimension-reduction` gives `c in her(f)_+` with
`[(f-eps/2)_+] << 2M_1[c] << M_1[f]`; pick `delta` with
`[(f-eps)_+] <= 2M_1[(c-delta)_+]`.  Put `d0 = g_delta(c)`, `e = g_(delta/2)(c)`
and `d1 = (1-e)^(1/2) f (1-e)^(1/2)`, where `g_delta` is `0` on `[0, delta/2]`,
`1` on `[delta, infinity)` and linear between.  Then `d0 d1 = 0`, both lie in
`her(f)`, `y_0 = [d0]`, `y_1 = [d1]` satisfy `y_0 + y_1 <= [f]`, and
`[(f-eps)_+] <= 2M_1 y_0`.  From `[f] <= [e] + [d1]` and
`2M_1[e] <= M_1[(f-epsbar)_+]` for some `epsbar > 0`:

```text
2M_1 [f]  <=  M_1 [(f-epsbar)_+] + 2M_1 [d1] .
```

*Quotient step.*  Let `I` be the ideal of `cC` generated by `d1`.  Then
`I = J tensor K` for the ideal `J = {c : c tensor e_11 in I}` of `C` (proved in
the artifact), so `Cu(cC/I) = Cu(C/J)`.  In the quotient,
`z = M_1[pi f]` satisfies `2z <= M_1[(pi f - epsbar)_+] << z`, hence `z << z` and
`2z <= z`.  By hypothesis `z = 0`, so `f in I` and `[f] <= (n+1)[d1]` for some `n`
(artifact Lemma 1.11).

*Traces.*  For every lower semicontinuous 2-quasitrace `tau`, the displayed
inequality gives `d_tau(f) <= 2 d_tau(d1)` when `d_tau(f) < infinity`, and
`d_tau(d1) = infinity` otherwise.  So `d_tau(f) <= (1 - 1/3) d_tau(3[d1])` for all
`tau`, and Robert, arXiv:1002.2180 (Munster J. Math. 4 (2011)), Lemma 1, with
`m`-comparison gives `[f] <= 3(m+1)[d1] <= L y_1`.  Hence `x' << L y_0, L y_1`,
and item 2 of `sv26-bounded-divisibility-dimension-reduction` gives purity.

This follows Seth--Vilalta's proof of their Proposition 5.10 for `C(X, A)`
(arXiv:2602.14809v2), with evaluation at points replaced by the quotient map
of `C` itself.

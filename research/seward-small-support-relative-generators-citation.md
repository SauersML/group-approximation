B. Seward, *Krieger's finite generator theorem for actions of countable groups I*, arXiv:1405.3604. Read on
2026-09-13 from the PDF text extracted on MSI (`review-lit/entropy/1405.3604.txt`), Section 2. Verbatim:

- "A pre-partition of X is a countable collection of pairwise-disjoint subsets of X. We say that another
  pre-partition β extends α, written β ⊒ α, if there is an injection ι : α → β with A ⊆ ι(A) for every A ∈ α."
- "For a Borel pre-partition α, we define the reduced σ-algebra σ-alg^red_G(α) to be the collection of Borel
  sets R ⊆ X such that there is a conull X′ ⊆ X satisfying: for every r ∈ R∩X′ and x ∈ X′\R there is g ∈ G
  with g·r, g·x ∈ ∪α and with g·r and g·x lying in distinct classes of α."
- "Lemma 2.2. Let G y (X,µ) be a p.m.p. action, and let α be a pre-partition. If β is a pre-partition and
  β ⊒ α then σ-alg^red_G(β) ⊇ σ-alg^red_G(α). In particular, if β is a partition and β ⊒ α then
  σ-alg_G(β) ⊇ σ-alg^red_G(α)."
- "Theorem 2.3. Let G be a countably infinite group acting ergodically, but not necessarily freely, by
  measure-preserving bijections on a non-atomic standard probability space (X,µ). Let F be a G-invariant
  sub-σ-algebra of X. If 0 < r ≤ 1 and p̄ = (p_i) is any finite or countable probability vector with
  h^Rok_G(X,µ|F) < r·H(p̄), then there is a Borel pre-partition α = {A_i : 0 ≤ i < |p̄|} with µ(∪α) = r,
  µ(A_i) = r·p_i for every 0 ≤ i < |p̄|, and σ-alg^red_G(α) ∨ F = B(X)."

The text calls Theorem 2.3 "the statement of the main theorem of this paper in its strongest form" and
"new even in the case G = Z".

## 0. Lemmas

**Lemma A (fixed sets of conjugates).** Let `G` act on a set `A`. If `A^Gamma`
is `G`-invariant as a set, then `A^Gamma = A^N`.

*Proof.* `h · A^Gamma = A^(h Gamma h^-1)`. Invariance under `h` and `h^-1`
gives `h · A^Gamma = A^Gamma`, so every `a` in `A^Gamma` is fixed by every
conjugate of `Gamma`, hence by `N`. The reverse inclusion is trivial. ∎

Applied to `A = M` with `Ad sigma`: `sigma(G)` normalizes `C_sigma` if and only if
`C_sigma = sigma(N)' ∩ M`. In that case `sigma(t) C_sigma sigma(t)^* = C_sigma`,
because `N` is normal. Also `sigma(t) C_sigma sigma(t)^* = sigma(Lambda)' ∩ M`.
So (CCR) holds.

**Lemma B (L^2 fixed vectors).** Let `(P, tau)` be a tracial von Neumann
algebra and `V` a group of unitaries in `P`. Then the `Ad V`-fixed vectors of
`L^2(P)` form the 2-norm closure of `V' ∩ P`.

*Proof.* Elements of `L^2(P)` are closed densely defined operators affiliated
with `P`. Let `xi` be fixed and `xi = w |xi|` its polar decomposition. For `v`
in `V`, `v xi v^* = (v w v^*)(v |xi| v^*)` is again a polar decomposition, so
by uniqueness `v` commutes with `w` and with every spectral projection of
`|xi|`. Hence `xi_m = w |xi| 1_[0,m](|xi|)` lies in `V' ∩ P`, and
`xi_m -> xi` in `L^2`. The reverse inclusion is clear. ∎

**Lemma C (self-adjoint enemies).** `C_sigma` is a `*`-algebra. If `x` is an
enemy, then `Re x = (x + x^*)/2` or `Im x = (x - x^*)/(2i)` is an enemy.

*Proof.* `sigma(Gamma)` consists of unitaries, so its commutant is closed
under `*`. Also `Ad sigma(g)` commutes with `*`, so both parts lie in
`C_sigma`. If both parts were fixed by `Ad sigma(N)`, then so would be `x`. ∎

## 1. Gaussian actions and chaos

Let `K` be a separable real Hilbert space with an orthogonal
`G`-representation `pi`. The Gaussian action `G ↷ (Omega_K, mu_K)` is a p.m.p.
action on a standard probability space. It comes with a real linear isometry
`W : K -> L^2_R(Omega_K)` onto centered Gaussian variables, and
`g · W(v) = W(pi(g) v)`. The Wiener chaos decomposition is a `G`-equivariant
unitary isomorphism

```text
L^2(Omega_K)  ≅  ⊕_(k >= 0) Sym^k(K_C) ,                                   (1.1)
```

where the `k = 1` summand is `W(K)` complexified. The algebra `L^∞(Omega_K)` is
generated by the bounded Borel functions of the variables `W(v)`.

**Lemma D.** Suppose Theorem C's conclusion holds for `Omega_K`. If `v` in `K`
is `pi(Gamma)`-fixed, then `v` is `pi(N)`-fixed.

*Proof.* `W(v)` is `Gamma`-fixed, so `arctan W(v)` lies in
`L^∞(Omega_K)^Gamma`. By Lemma A applied to the action on `L^∞(Omega_K)`,
`L^∞(Omega_K)^Gamma = L^∞(Omega_K)^N`. So `arctan W(v)` is `N`-fixed. Since
`arctan` is injective, `W(v) = W(pi(n) v)` almost surely for each `n` in `N`.
`W` is isometric, so `pi(n) v = v`. ∎

**Lemma E (factors).** If `G ↷ X` satisfies Theorem C's conclusion and
`G ↷ Y` is a factor of it, then so does `G ↷ Y`.

*Proof.* `L^∞(Y)` is a `G`-invariant subalgebra of `L^∞(X)`, and
`L^∞(Y)^Gamma = L^∞(Y) ∩ L^∞(X)^Gamma`. Both sets are `G`-invariant. ∎

## 2. Parts (1) and (2)

Recall that an *enemy* is an element of `C_sigma` that is not fixed by
`Ad sigma(N)`. By Lemma A (with `A = M`), `sigma` has no enemy exactly when
`sigma(G)` normalizes `C_sigma`.

Let `x` be an enemy. By Lemma C take `x_0 = x_0^*` an enemy (if both parts of
`x` were `N`-fixed, so would be `x`). Let `K_0` be the closed real span of
`pi_sigma(G) x_0` in `L^2(M)_sa`. It is separable because `G` is countable.
`x_0` is `pi_sigma(Gamma)`-fixed, since `sigma(gamma) x_0 sigma(gamma)^* = x_0`
exactly, and it is not `pi_sigma(N)`-fixed. By Lemma D, Theorem C's conclusion
fails for `Omega_(K_0)`. By Theorem C (both groups Kazhdan, `Gamma`
infranormal) the action is not sofic, and by Lemma E it is not a factor of a
sofic action. This is (1).

(2) is the contrapositive. If every `Omega_(K_x)` is a factor of a sofic
action, then each satisfies Theorem C's conclusion (Theorem C and Lemma E). By
Lemma D every self-adjoint `x` in `C_sigma` is `sigma(N)`-fixed, and by Lemma C
every element is. So `sigma` has no enemy, and Lemma A gives (CCR). ∎

## 3. Part (3)

**Tensor powers.** For `j >= 1` the map
`[a_1,n] ⊗ ... ⊗ [a_j,n] -> [a_1,n ⊗ ... ⊗ a_j,n]` is well defined on bounded
representatives: changing one factor by `h_n` with `||h_n||_2 -> 0` changes the
product by at most `||h_n||_2 · prod ||a_i,n||` in 2-norm, because
`||a ⊗ b||_2 = ||a||_2 ||b||_2` for normalized traces. It is a `*`-homomorphism
and multiplies traces, so it is trace-preserving. It extends to a normal
embedding `M^(⊗̄ j) -> M_j` and to an isometry
`L^2(M)^(⊗ j) = L^2(M^(⊗̄ j)) -> L^2(M_j)`. This isometry intertwines
`(Ad sigma)^(⊗ j)` with `Ad sigma^(⊗ j)`. Composing, for all `j, k`,

```text
Sym^k( L^2(M_j) )  ⊆  L^2(M_j)^(⊗ k)  ⊆  L^2(M_(jk)) ,                    (3.1)
```

`G`-equivariantly, with `G` acting on the right through `Ad sigma^(⊗ jk)`.

**(b) implies (a).** Fix `j` and a separable `G`-invariant
`K ⊆ L^2(M_j)_sa`. Let `eta` be in `L^2(Omega_K)^Gamma`. By (1.1) its chaos
components `eta_k` are `Gamma`-fixed, and `eta_k` lies in
`Sym^k(K_C) ⊆ L^2(M_(jk))` by (3.1). By Lemma B, applied in `P = M_(jk)` with
`V = sigma^(⊗ jk)(Gamma)`, `eta_k` lies in the 2-norm closure of `C_(jk)`, the
`Gamma`-commutant of `sigma^(⊗ jk)`. By (b), `sigma^(⊗ jk)` has no enemy, so every
element of `C_(jk)` is fixed by `Ad sigma^(⊗ jk)(N)`, and so is its closure.
Hence each `eta_k` is `N`-fixed (the `k = 0` term is a constant). So
`L^2(Omega_K)^Gamma ⊆ L^2(Omega_K)^N`. The reverse inclusion is trivial, so
`L^∞(Omega_K)^Gamma = L^∞(Omega_K)^N`, which is `G`-invariant because `N` is
normal.

**(a) implies (b).** Fix `k` and suppose `sigma^(⊗ k)` has an enemy. Section 2,
run with `sigma^(⊗ k)` in place of `sigma` (it is trace-faithful), gives a
self-adjoint enemy `x_0` and a separable `K_0 ⊆ L^2(M_k)_sa`. By Lemma D,
Theorem C's conclusion fails for `Omega_(K_0)`. This contradicts (a) with
`j = k`. ∎

## 4. Part (4)

If `S` is closed under tensor powers, then (b) for all `sigma` in `S` is the
same as "no `sigma` in `S` has an enemy", because `sigma^(⊗ k)` is in `S`. By
Lemma A, this means every `sigma` in `S` normalizes `C_sigma`. Likewise (a) for
all `sigma` in `S` is the same as Theorem C's conclusion for every Gaussian
suspension of every `Ad sigma`, `sigma` in `S`. Part (3) gives the equivalence.

The two classes named in the claim are closed under tensor powers. For a sofic
representation lifted by `phi_n : G -> Sym(Y_n)`, the power `sigma^(⊗ k)` is lifted
by `phi_n^(× k)` on `Y_n^k`. It is asymptotically multiplicative in normalized
Hamming distance (a union bound over the `k` coordinates), and its fixed-point
fraction is `(|Fix phi_n(g)|/|Y_n|)^k -> 0` for `g != e`. For trace-faithful
unitary representations, `tr(a^(⊗ k)) = tr(a)^k`. ∎

## 5. Calibration and checks

- **Corollary D is the coset case.** Let `Delta` contain `Gamma` but not `N`, and
  let `K = l^2_R(G/Delta)` with the quasi-regular action. Its Gaussian action is
  `N(0,1)^(G/Delta)`: the coordinate variables `W(delta_c)` are independent
  standard Gaussians permuted by `G`. `delta_Delta` is `Gamma`-fixed and not
  `N`-fixed, so Lemma D and Theorem C show that this shift is not sofic. With
  `Delta = Gamma` this is Kun--Thom Corollary D for the Gaussian base. It is a
  consistency check, not a new result.
- **Nothing false is proved.** The Bernoulli shift `N(0,1)^G` is sofic
  (Elek--Lippner, Proposition 7.1, verified in the Kun--Thom artifact). Here
  `K = l^2_R(G)` has no nonzero `Gamma`-fixed vector because `Gamma` is
  infinite, so Lemma D is vacuous and there is no conflict.
- **Where Kazhdan enters.** Only through Theorem C, in parts (1) and (2). Parts
  (3) and (4) do not use soficity or property (T): they are an exact
  equivalence between two fixed-point statements. So the infinite-measure form
  of Theorem C (the Gaussian or Poisson suspension of the Loeb pair action
  of a sofic model) carries exactly the content of the normalization claim.
  Any proof of it would prove `kt-sofic-models-normalize-vn-commutants`.
- **Poisson form.** For an infinite-measure-preserving action, the Poisson
  suspension also has `L^2 = ⊕ Sym^k(L^2)` equivariantly, with first chaos
  isometric to `L^2`. Lemmas D and E and Section 3 use only this structure, so
  every statement holds verbatim with Poisson in place of Gaussian whenever
  `Ad sigma` is realized as a genuine Koopman representation. For sofic
  `sigma` the pair maps `psi_n` are only asymptotically multiplicative on a
  measure space of infinite total mass. That is why the claim uses the
  Gaussian suspension of the honest unitary representation `Ad sigma`.

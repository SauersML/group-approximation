Products of rows, columns and matrices are matrix products. For a word `α`, `|α|` is its length.

**Item 1.**
- (T2) with `b = 1` gives `s = s p` and `t = p t`.
- `φ(b) φ(b') = t b (s t) b' s = t b s φ(b') = t b b' s = φ(b b')`, using `s φ(b') = b' s` from (T2). So `φ` is multiplicative
  and additive, with `φ(1) = p`, and `φ(b) = p φ(b) p` since `φ(b) = φ(1) φ(b) φ(1)`.
- `e^2 = s p t = s t = e`. For `b in B`, `b e = s φ(b) t = e b`.
- `q s = s - s (t s) = s - s p = 0` and `t q = t - (t s) t = t - p t = 0`.
- **Normal form.** In a word in `B` and the `s_i, t_j`, replace `t_i s_j` by `p_ij in B`. Move each `b in B` to the
  right past `s_i` using `b s_i = Σ_j s_j φ(b)_(ji)`, and to the left past `t_i` using `t_i b = Σ_j φ(b)_(ij) t_j`.
  This terminates in a sum of elements `s_α b t_β`: each move strictly lowers the number of pairs `(t, s)`, `(b, s)`
  and `(t, b)` standing in that order (gq-referee-a, N1).
- **Gram matrices.** For `|α| = |β| = m`, the same moves turn `t_β s_α` into an element `P^(m)_(βα)` of `B`.
  If `|β| < |α|`, then `t_β s_α` is a sum of terms `b s_γ` with `γ` nonempty. If `|β| > |α|`, it is a sum of terms
  `t_γ b` with `γ` nonempty.
- **Recursion.** `P^(m+1)_((β,j),(α,i)) = t_j P^(m)_(βα) s_i = (φ(P^(m)_(βα)) p)_(ji) = φ(P^(m)_(βα))_(ji)`, where the
  word `(α, i)` means `s_α s_i` and `(β, j)` means `t_j t_β`.

**Item 2.**
- `t_β q = 0` for `β` nonempty, since its last factor is some `t_i` and `t_i q = 0`. Likewise `q s_γ = 0` for `γ`
  nonempty. `q` commutes with `B`. By the normal form,
  `R q R = span{s_α b t_β q s_γ b' t_δ} = span{s_α q b t_δ}`.
- **Fock idempotents.** Put `E_m = Σ_(|α| = m) s_α t_α`, so `E_0 = 1` and `E_1 = e`, and `G_m = Σ_(|α| = m) s_α q t_α`.
  - `E_m s_α = s_α` for `|α| = m`, by induction. `E_1 s_i = s_i` is `s p = s`. For the step, write
    `E_(m+1) = Σ_(|α| = m) s_α e t_α`. For `|α'| = m`, `E_(m+1) s_(α') s_j = Σ_α s_α e P^(m)_(α α') s_j`
    `= Σ_α s_α P^(m)_(α α') e s_j = (E_m s_(α')) s_j = s_(α') s_j`, using `e b = b e` and `e s_j = s_j`.
  - `q t_β s_α q = 0` if `|β| != |α|`, by the Gram bullet, `q b = b q`, `q s_γ = 0` and `t_γ q = 0`. If
    `|β| = |α| = m`, it is `P^(m)_(βα) q`.
  - So `G_j G_(j') = δ_(jj') G_j`, using `Σ_β s_β P^(m)_(βα) = E_m s_α = s_α`. Also `G_m s_α q = s_α q` for
    `|α| = m`, `G_j s_α q = 0` for `j != |α|`, and dually `q t_δ G_m = q t_δ` for `|δ| = m`. The
    dual uses `t_δ E_m = t_δ` for `|δ| = m`, proved like `E_m s_α = s_α` from `t s t = p t = t` (gq-referee-a, N2).
- **Truncation.** Suppose `1 in R q R`. Then `1` is a finite sum of elements `s_α q b t_δ` with `|α|, |δ| <= n`, for
  some `n`. Put `G = G_0 + ... + G_n`, an idempotent. Each summand satisfies `x = G x G`, so `1 = G y G` for some
  `y`, and `G = G · 1 = G (G y G) = 1`.
- For `|α| = n + 1` and `j <= n`, `G_j s_α = Σ_(|β| = j) s_β q t_β s_α = 0`: `t_β s_α` is a sum of `b s_γ` with `γ`
  nonempty, and `q b s_γ = b q s_γ = 0`. So `s_α = G s_α = 0`.
- Then `P^(n+1) = 0`. If `φ` is injective, the recursion gives `P^(n) = 0`, and so on down to `P^(1) = p = 0`. Then
  `s = s p = 0`, `t = p t = 0` and `q = 1`.

**Item 3.** If `q != 0` and `R` is simple, then `R q R = R`, and item 2 gives `p = 0`, a contradiction. So `q = 0`.
If `B` is simple, `ker φ` is a proper ideal because `φ(1) = p != 0`, so it is zero. A directed union of simple rings
along unital inclusions is simple, and this covers matricial `B`.

**Item 4.** Concatenate the rows and the columns. (T1) and (T2) for the concatenation are the hypotheses. The sum
`Σ_a s^(a) t^(a)` is the new `s t`.

**`R_L`.** The relations `t_i s_j = δ_ij`, `N s_1 = s_1 (N + 1)` and `N s_2 = 0` give `t_1 f s_1 = f(N+1)`,
`t_2 f s_2 = f(0)` and `t_i f s_j = 0` for `i != j`, first for `f = N` and then for resolvents. `(N + c)^(-1)` lies in `R_L` by transporting `A` along `s_1`
(`leavitt-resolvent-ring-is-fp-simple-of-char-zero`, Structure), and `(N + c)^(-1) s_1 = s_1 (N + c + 1)^(-1)`. The
`s_2` identity `(N + c)^(-1) s_2 = c^(-1) s_2` uses `Q ⊆ R_L` (gq-referee-a, N3). So `φ(f) = diag(f(N+1), f(0))`, and (T2) follows from `s_1 t_1 + s_2 t_2 = 1`.
`R_L` is generated by `B` and the `s_i, t_i`, since `N, A in B`.

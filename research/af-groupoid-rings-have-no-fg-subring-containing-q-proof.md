Lane proof (gq-deep-adelic-1), not independently reviewed. Notation as in the target.

1. **One subgroupoid.** Let `R ⊆ F_c(G, Q)` be generated by `r_1, ..., r_m`, with `r_i` vanishing off
   the compact set `K_i`. Since `G` is AF, `K_1 ∪ ... ∪ K_m` lies in a compact open subgroupoid
   `H ⊇ G^(0)`.
2. **H carries a subring.** Let `F_H` be the set of `f ∈ F_c(G, Q)` vanishing off `H`.
   - If `f, g ∈ F_H` and `(f * g)(γ) != 0`, then `γ = αβ` with `α, β ∈ H`, so `γ ∈ H`.
   - `χ_(G^(0)) ∈ F_H`.
   So `F_H` is a unital subring containing every `r_i`, and `R ⊆ F_H`.
3. **A finite representation.** Fix `x ∈ G^(0)` and let `H_x = {h ∈ H : s(h) = x}`. It is finite,
   being a closed discrete subset of the compact set `H`, and nonempty since `x ∈ H_x`. For `f ∈ F_H`
   and `ξ : H_x -> Q` put

       (π(f) ξ)(h) = Σ_(k ∈ H, r(k) = r(h)) f(k) ξ(k^(-1) h).

   - Here `k^(-1) h ∈ H` has source `x`, so the formula makes sense, and the sum is finite.
   - This is the left regular representation of `F_H` on the fibre `H_x`, so `π(f * g) = π(f) π(g)`.
   - For `f = χ_(G^(0))`, only `k = r(h)` contributes, so `π` is unital.
   So `π : F_H -> End_Q(Q^(H_x)) = M_(|H_x|)(Q)` is a unital ring homomorphism.
4. **Conclusion.** If `Q ⊆ R`, then `π|_R` is a unital homomorphism from a finitely generated ring
   containing `Q` into `M_(|H_x|)(Q)`. That is impossible by
   `fg-q-rings-have-no-matrix-representations`.

## Proof

1. **The action.** `G` acts by simplicial isometries on the CAT(−1) 2-complex `Y` with a
   triangle `T = [v_0, v_1, v_2]` as strict fundamental domain (`cckw-ghb2-kms-group-structure`,
   item 3). Stabilizers: trivial on `T`; `<b>` on `[v_0,v_1]`, `<c>` on `[v_1,v_2]`, `<a>` on
   `[v_0,v_2]`; `X_0, X_1, X_2` on `v_0, v_1, v_2`. An element fixing an edge fixes both of its
   endpoints (it lies in both vertex stabilizers), so no cell is mapped to itself with reversed
   orientation.
2. **Orbit complex.** `N` acts on `Y` with finite stabilizers. The orbit space `N\Y` is a finite
   2-dimensional CW complex whose `k`-cells are the `N`-orbits of `k`-simplices. `N` is normal,
   so the `N`-orbits inside the `G`-orbit `G·σ` are in bijection with `N\G/G_σ = Q/φ(G_σ)`:
   - triangles: `|Q|`;
   - edges: `|Q|/|φ(<a>)| + |Q|/|φ(<b>)| + |Q|/|φ(<c>)|`;
   - vertices: `|Q|/|φ(X_0)| + |Q|/|φ(X_1)| + |Q|/|φ(X_2)|`.
3. **Rational cohomology (standard fact, not re-read at source; Brown, *Cohomology of Groups*,
   VII.7).** For a group acting cellularly on a contractible complex with finite stabilizers and
   without orientation reversal, the equivariant spectral sequence with `Q` coefficients has
   `E_1^{p,q} = ⊕_{σ∈Σ_p} H^q(N_σ; Q) = 0` for `q > 0`. So `H^*(N;Q) ≅ H^*(N\Y;Q)`. `Y` is CAT(0),
   hence contractible, and 2-dimensional, so `b_k(N;Q) = 0` for `k >= 3`.
4. **Euler characteristic.** `b_0 − b_1 + b_2 = χ(N\Y)`, the alternating cell count of step 2.
5. **Property (T).** `G` is Kazhdan (item 1). A finite-index subgroup of a Kazhdan group is
   Kazhdan (standard), and Kazhdan groups have finite abelianization. So `b_1(N;Q) = 0` and
   `b_2(N;Q) = χ(N\Y) − 1`, which is the displayed formula.
6. **Instances.**
   - `Z/7`, `a,b,c ↦ 1`: every `φ(<x>)` and every `φ(X_i)` is all of `Z/7`, so
     `χ = 7 − 3 + 3 = 7` and `b_2 = 6`.
   - `(Z/7)^2`, `a ↦ e_1`, `b ↦ e_2`, `c ↦ e_1+e_2`: edge images have order 7 and each `φ(X_i)` is
     generated by two of `e_1, e_2, e_1+e_2`, hence is everything. `χ = 49 − 21 + 3 = 31`, `b_2 = 30`.
   - `(Z/7)^3`: edge images order 7, vertex images order 49. `χ = 343 − 147 + 21 = 217`,
     `b_2 = 216`.
   - Vertex-injective `φ`: `χ = |Q|(1 − 3/7 + 1/343 + 2/2401) = |Q|·1381/2401`, matching
     `ghb7-congruence-kernel-b2-euler-count-proof`.
   - Well-definedness: `G^ab = (Z/7)^3` with basis `a, b, c`
     (`ghb7-triangle-vertex-groups-split-abelianizations`), so all three maps exist. ∎

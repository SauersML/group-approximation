Notation is as in the claim. Write `P = M_n(R)`. For `x ∈ P` and `j ∈ Z`, `x_j` is the matrix of degree-`j`
components of the entries. So `x = Σ_j x_j`, a finite sum, and `(xy)_d = Σ_(a+b=d) x_a y_b`.

For `k ∈ Z`, let `F_k = {x ∈ P : x_j = 0 for all j < k}`. Then:
- `F_k F_l ⊆ F_(k+l)`, `F_(k+1) ⊆ F_k`, and `∩_k F_k = 0` (each `x` has only finitely many nonzero `x_j`);
- `M_n(R_(>=0)) = F_0`.

## Proof of Theorem A

Let `u, v = u^-1 ∈ F_0`, let `A ⊆ M_n(V)` be a subspace with `u A u^-1 ⊆ A`, and put `B = u A u^-1`. Then `B` is a
`k`-subspace and `B ⊆ A ⊆ M_n(V) ⊆ F_0`.

**Step 1 (degree-0 parts are inverse).** The degree-0 part of `uv = 1` is `Σ_(a+b=0) u_a v_b = u_0 v_0`, because
`u_a = v_b = 0` for negative indices. So `u_0 v_0 = 1`, and likewise `v_0 u_0 = 1`.

**Step 2 (leading terms).** Let `x ∈ F_j`. Then `u x v ∈ F_j` and `(u x v)_j = u_0 x_j v_0`: in
`Σ_(a+b+c=j) u_a x_b v_c` only `a = c = 0`, `b = j` survives, since `a, c >= 0` and `b >= j`.

**Step 3 (graded pieces agree).** For a subspace `X ⊆ F_0` put `gr_j(X) = {x_j : x ∈ X ∩ F_j}`. This is a subspace,
and for `X ⊆ M_n(V)` it lies in `M_n(V_j)`, which has dimension `n^2 dim V_j < ∞`.
- `B ⊆ A` gives `gr_j(B) ⊆ gr_j(A)`.
- Let `w ∈ gr_j(A)`, say `w = x_j` with `x ∈ A ∩ F_j`. Then `u x v ∈ B ∩ F_j`, and by Step 2 its degree-`j` part is
  `u_0 w v_0`. So `u_0 gr_j(A) v_0 ⊆ gr_j(B)`.
- By Step 1 the map `w ↦ u_0 w v_0` is injective. So `dim gr_j(A) <= dim gr_j(B) <= dim gr_j(A)`, both finite, and
  therefore `gr_j(B) = gr_j(A)`.

**Step 4 (degree-density).** *Claim:* for every `a ∈ A` and every `k >= 0` there is `b ∈ B` with `a - b ∈ A ∩ F_k`.

Induct on `k`. For `k = 0` take `b = 0`. Suppose `a - b ∈ A ∩ F_k`. By Step 3, `(a - b)_k ∈ gr_k(A) = gr_k(B)`, so
there is `b' ∈ B ∩ F_k` with `b'_k = (a - b)_k`. Then `a - (b + b') = (a - b) - b'` lies in `A` (since `B ⊆ A`) and in
`F_k`, and its degree-`k` part vanishes. So it lies in `A ∩ F_(k+1)`, and `b + b' ∈ B`.

*Alternative proof of Step 4, for the special case `u ∈ GL_n(V)` with `V` a graded subalgebra.* In that case
`I_k = M_n(V_(>=k))` is a two-sided ideal of `M_n(V)`. The quotient `M_n(V) / I_k` is a finite-dimensional algebra, and
conjugation by the image of `u` is bijective on it. So the images of `A` and `B` have equal dimension. One contains the
other, so they coincide, which is Step 4.

This is also the grading-level form of the profinite invisibility (C2) of the w18 node: a compression in a half is
invisible modulo every degree truncation.

**Step 5 (continuity of commutation).** Let `y ∈ P`, and choose `m >= 0` with `y_j = 0` for `|j| > m`. For `f ∈ F_k`
we have `y f, f y ∈ F_(k-m)`, so `[y, f] ∈ F_(k-m)`.

**Step 6 (conclusion).** `A ⊇ B` gives `A' ⊆ B'`. Conversely, let `y ∈ B'` and `a ∈ A`, and choose `m` for `y` as in
Step 5. For every `k`, Step 4 gives `b ∈ B` with `a - b ∈ F_k`. Then `[y, a] = [y, a - b] + [y, b] = [y, a - b]`,
which lies in `F_(k-m)`. So `[y, a] ∈ ∩_k F_(k-m) = 0`, and `y ∈ A'`. Hence `B' = A'`.

The case of `R_(<=0)` follows by applying the above to the regrading `R_j^op-grade := R_(-j)`. ∎

## Proof of Theorem B

**The cone is graded, with finite pieces.** Let `W = span_(F_2){s_μ, s_μ q : μ a word in {1,2}}`. The following
products lie in `W`:
- `s_μ s_ν = s_(μν)`;
- `q s_1 = s_1 t_1 s_1 = s_1`, `q s_2 = s_1 t_1 s_2 = 0`, and `q q = q`.

So `q s_ν` is `s_ν` if `ν` starts with 1, is `0` if `ν` starts with 2, and is `q` if `ν` is empty. Hence
`(s_μ q^ε)(s_ν q^δ)` lies in `W` for all `ε, δ ∈ {0,1}`. So `W` is a unital subalgebra containing `s_1, s_2, q`,
and it is spanned by products of these, so `W = R_+`.

Each spanning element is homogeneous: `deg s_μ = deg s_μ q = |μ|`, since `deg q = 0`. So `R_+` is a graded subspace
of `R_(>=0)`, and `(R_+)_j` is spanned by `2^(j+1)` elements. Finite-dimensionality is all Theorem A needs. The
dimension is exactly `2^(j+1)`, because `s_μ` and `s_(μ1) t_1` are distinct normal-form monomials, and the checker
confirms this for `j <= 4`.

**Compressors.** `Delta_+ = E_20(R_+)` is generated by the `x_ij(a)` with `a ∈ R_+`, and
`x_ij(a)^-1 = x_ij(-a) = x_ij(a)`. So every `u ∈ Delta_+` has `u, u^-1 ∈ M_20(R_+) ⊆ M_20(R_(>=0))`.

**Groups.** Let `L <= GL_20(R_+)` and `u ∈ GL_20(R)` with `u, u^-1 ∈ M_20(R_(>=0))` and `u L u^-1 <= L`. Put
`A = span_(F_2) L`. Then:
- `A ⊆ M_20(R_+)`;
- `u A u^-1 = span_(F_2)(u L u^-1) ⊆ A`;
- a matrix commutes with a set exactly when it commutes with its span.

By Theorem A with `V = R_+` and `n = 20`, we get `(F_2 u L u^-1)' = (F_2 L)'`. Intersecting with `GL_20(R)` gives
equality of the centralizers in `GL_20(R)`. By `leavitt-steinberg-map-iso-from-rank-three` (KH2), the Steinberg map
`Delta = St_20(R) -> GL_20(R)` is an isomorphism, so this is `C_Delta(u L u^-1) = C_Delta(L)`.

(KH2) is used exactly here. Without it, commuting matrices could have a nontrivial central `K_2` commutator in the
Steinberg group.

For `c ∈ C_Delta(L)`, the element `u c u^-1` lies in `C_Delta(u L u^-1) = C_Delta(L)`. So `[u c u^-1, l] = 1` for all
`l ∈ L`.

The mirror case: the anti-automorphism `*` exchanges `s_i` and `t_i`, fixes `q`, maps `R_+` onto `R_-` and negates
degree. Equivalently, apply Theorem A to the regrading `j -> -j`, with `V = R_-`.

For conjugates: if `L, u ⊆ g Delta_+ g^-1`, apply the above to `g^-1 L g` and `g^-1 u g`, and conjugate back. ∎

## Proof of Corollary C and of the class statement

(HEC) asks for `L <= Delta_+`, `u ∈ Delta_+` with `u L u^-1 <= L`, and `c ∈ C_Delta(L)`, `l ∈ L` with
`[u c u^-1, l] ≠ 1`. Theorem B gives `[u c u^-1, l] = 1` for every such choice, with or without property (T). So
(HEC) is false, and so is its mirror in `Delta_-`.

The class statement is conditional only on the Bass-Serre localization proved in the w18-ptl-pull node
`cone-half-compression-defects-force-head-bound` (item 1), which is not landed at the time of writing. That item
states: every compression pair `(L, u)` of `Gamma` with `L` infinite and Kazhdan lies in one vertex stabilizer
`g Delta_+- g^-1`.

Granting it, `p(L)` and `p(u)` lie in `p(g) Delta_+- p(g)^-1` for the projection `p : Gamma -> Delta`. By Theorem B
every defect `[p(u) c p(u)^-1, p(l)]`, with `c ∈ C_Delta(p(L))`, is trivial. So the transferred smallness of
`rho([u ĉ u^-1, l])` bounds only an element of `K = ker p`, and never the head, whatever lift `ĉ` of `c` is chosen.

Finite `L` needs no localization for the defect statement, since Theorem B covers every `L <= GL_20(R_+)`. ∎

## Scope notes

- **What Theorem A does not use.** It uses no property (T), no finite generation of `L`, no simplicity of `R`, no
  stable finiteness, and nothing about the order of `u`.
- **Where it stops.** It needs the compressor to have components of one sign of degree only, with inverse of the same
  sign. The mixed Kun-Thom unit `s_11 t_1 + s_12 t_21 + s_2 t_22` has components in degrees `1, 0, -1` and is not
  covered.
- **The finite-dimensionality hypothesis is used exactly once**, in Step 3. For `A ⊆ M_n(R_(>=0))` with
  infinite-dimensional graded pieces, Step 3 fails. The degree-0 part `R_0 ⊇ ∪_n M_(2^n)(F_2)` is where such
  compressions could live, and the corner kill (C4) of the w18 node handles only corners there.

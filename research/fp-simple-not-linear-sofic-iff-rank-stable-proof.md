Notation: `rk` is normalized rank, `Rk` unnormalized rank, and `hat` pads by zeros. Relators are evaluated on invertible
matrices, with inverse letters sent to inverse matrices.

**Lemma 0 (exact solutions are trivial).** Let `F` be any field and `B` in `GL_(n')(F)^d` with `P_j(B) = Id` for all `j`.
Then every `B_i = Id`.
- `x_i -> B_i` defines a homomorphism `rho : G -> GL_(n')(F)`, and `rho(G)` is residually finite by
  `finitely-generated-linear-groups-are-residually-finite`.
- If `ker rho = 1`, then `G` is residually finite. Take `g != 1` and a finite-index normal `N` with `g` not in `N`.
  Then `N != G`, so `N = 1` by simplicity, and `G` is finite. That is a contradiction.
- So `ker rho = G`.

**Lemma 1 (padding).** Let `A` be in `GL_n(F)` and `n' >= 1`. If `Rk(hat A - hat Id_(n')) < eps n`, then
`rk(A - Id_n) < 2 eps`.
- If `n' >= n`, then `A - Id_n` is the top-left `n x n` block of `hat A - hat Id_(n')`.
- If `n' < n`, then `Rk(hat A - hat Id_(n')) >= Rk(A) - Rk(Id_(n')) = n - n'`, so `n - n' < eps n`. The top-left
  `n x n` block of `hat A - hat Id_(n')` is `A - Id_n + diag(0, Id_(n-n'))`. So
  `Rk(A - Id_n) <= Rk(hat A - hat Id_(n')) + (n - n') < 2 eps n`.

**(b) => (a).** Suppose `Theta : G -> prod_omega GL_(n_k)(F) / d_omega` is injective.
- Pick invertible representatives `A^(k)` of the `Theta(x_i)`. Then `lim_omega rk(P_j(A^(k)) - Id) = 0` for every `j`.
- `G` is infinite and generated by the `x_i`, so some `x_(i0) != 1`, and `c = lim_omega rk(A_(i0)^(k) - Id) > 0`.
- Take `eps = c/4` and `delta` from stability. For `omega`-many `k`, all relator defects are below `delta` and
  `rk(A_(i0)^(k) - Id) > c/2`.
- Stability gives an exact `B` with `Rk(hat A_i - hat B_i) < eps n_k`. By Lemma 0, `B_i = Id_(n')`. By Lemma 1,
  `rk(A_(i0)^(k) - Id) < c/2`. That is a contradiction.

**(a) => (b).** Suppose `G` is not rank-stable over `F`. Fix the failing `eps`.
- For `delta_k = 1/k` there are `n_k` and `A^(k)` in `GL_(n_k)(F)^d` with all relator defects below `1/k` and no
  `eps`-approximating exact solution.
- If `k >= n_k`, every defect is below `1/n_k`, so every `P_j(A^(k)) = Id` and `A^(k)` approximates itself, which is
  impossible. So `n_k > k`.
- `B = Id_(n_k)` fails, so some `i` has `Rk(A_i^(k) - Id) >= eps n_k`. Fix one `i0` that occurs for infinitely many
  `k`, and pass to that subsequence.
- For a nonprincipal `omega`, `x_i -> [A_i^(k)]` defines a homomorphism of the free group into
  `U = prod_omega GL_(n_k)(F) / d_omega`. It kills every relator, since the defects tend to `0`, so it induces
  `Theta : G -> U`.
- `Theta(x_(i0)) != 1` because its displacement is at least `eps`. So `ker Theta` is a proper normal subgroup, hence
  trivial, and `G` is `F`-linear sofic.

**(b) <=> (c).** This is `fp-group-rank-stability-equals-group-algebra-rank-stability`.

**Item 2.** The same two arguments work with the field varying along the sequence.
- (b') => (a'): one `delta` serves every `F_(q_k)`.
- (a') => (b'): the failing sequence may use fields `F_(q_k)`, and gives an injective `Theta` into
  `prod_omega GL_(n_k)(F_(q_k)) / d_omega`. Lemmas 0 and 1 hold over every field.
- (a') <=> (c') is (i) <=> (iii) of `fp-simple-weak-soficity-is-finite-field-linear-soficity`.

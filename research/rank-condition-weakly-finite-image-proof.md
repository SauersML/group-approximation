Artifact Section 3.
1. **Lemma.** Let `I` be generated by the entries of idempotent matrices of class `0` in `K_0(A)`.
   - Suppose `YX = I_(n+1) + K` with `K` in `M_(n+1)(I)`, `X` of size `n x (n+1)` and `Y` of size
     `(n+1) x n`.
   - Write `K = U Ẽ V`, where `Ẽ` is a block-diagonal sum of class-zero idempotent matrices.
   - Then `X' = [[X],[ẼV]]` and `Y' = [Y, -UẼ]` satisfy `Y'X' = I_(n+1)`, with `X'` mapping into
     `A^n ⊕ ẼA^R`.
   - So `[A^(n+1)] <= [A^n] + [Ẽ] = [A^n]` in `K_0(A)`. After adding a free module this is a failure of
     the rank condition in `A`.
   - The same computation works for state-null idempotents, with `n + 1 <= n`.
2. **Zorn.** The ideals `J` with `A/J` satisfying the rank condition are closed under unions of chains: a
   failure uses finitely many entries. So a maximal `J` exists when `J = 0` qualifies.
3. **Maximality.** In `W = A/J` every class-zero idempotent matrix is `0`, by the lemma, and every
   state-null idempotent matrix is `0`, by the state form.
4. **Weak finiteness.** If `AB = I_n` in `M_n(W)`, then `I_n - BA` is idempotent of class `0`, so it is
   `0`.
5. **Converse.** A failure of the rank condition in `A` maps to one in every image, and weakly finite
   rings satisfy the rank condition.

**ESTABLISHED** (proposed; referee pending) through
`folner-tile-collapse-of-cycle-module-computes-chi-exactly-proof`, from
`rf-weak-bass-defect-is-degree-two-approximation-defect` (items 1 and 3) and
`amenable-cd-two-bass-defect-equals-euler-characteristic` (item 1, `χ = D(P)`, used only in
item 5). Recalled imports: Shapiro's lemma; B. Weiss, *Monotileable amenable groups* (2001):
a nested residual chain of an amenable group has fundamental domains forming a Følner
sequence. Obstruction for the brief's tiling step. Items 1 to 4 hold for every group in the
setting, amenable or not.

**Setting.** `K` is finitely generated by a finite set `S`, `|S| = n`, with `cd_Z K <= 2` and
`b_2(K) < ∞`, and `K` is infinite. `Cay = Cay(K, S)` has vertex set `K` and edges `g → gs`, and
`K` acts on the left. `P = ker(∂_1 : Z[K]^n → Z[K])`, `g e_s ↦ gs − g`, is the relation module.
It is the module of finitely supported integral 1-cycles of `Cay`, and it is projective because
`cd_Z K <= 2`. Write `χ = χ_Q(K)` and `r = rank_Q(Q ⊗ P) = χ + n − 1`. For a subgroup `N` of
finite index, `X = N\K` and `π : Cay → N\Cay`, the Schreier graph on `X`.

The complex is

> `C(N) = ( Q[X] ⊗_{Z[K]} P →∂ Q[X]^n → Q[X] )`,

which is `Q ⊗_{Z[N]}` of the resolution, so `H_k(C(N)) = H_k(N; Q)`. By target item 1,
`dim C_2 = r[K:N]`.

A *tile family* for `N` is a finite family `T_1, …, T_k` of finite subsets of `K` such that
`π` is injective on `T = ⊔ T_j`, the images being disjoint. For each tile write:

- `E(T_j) = {(t, s) : t, ts ∈ T_j}`, the induced edges;
- `c_j` for the number of components of `Cay|_{T_j}`;
- `β_j = n|T_j| − |E(T_j)|` for the number of edges leaving `T_j`.

Put `E(T) = ⊔_j E(T_j)`, and let `θ = 1 − |T|/[K:N]` be the uncovered fraction. A *transversal* is the case `k = 1`,
`θ = 0`. Put `ρ : P → Q[X] ⊗ P`, `z ↦ 1 ⊗ z`.

1. **Tiles are exactly acyclic.** Let `T_*` have
   - degree 2: `A = Σ_j ρ(Z_1(Cay|_{T_j}; Z))` (over `Q`);
   - degree 1: `π_* Q^{E(T)}`;
   - degree 0: `Q[π T]`.

   Then `T_*` is a subcomplex of `C(N)`, `∂ ∘ ρ` is injective on `⊕_j Z_1(Cay|_{T_j}; Q)`,
   `H_2(T_*) = H_1(T_*) = 0` and `H_0(T_*) = Q^{Σ c_j}`. No condition on the size, radius or
   relator depth of the tiles is needed.
2. **Exact collapse.** `H_2(N; Q) ≅ H_2(C(N)/T_*)` and
   `dim H_1(C(N)/T_*) = b_1(N) + Σ c_j − 1`. The quotient complex has dimensions
   - degree 2: `χ[K:N] + (n − 1)θ[K:N] + Σβ_j − Σc_j`;
   - degree 1: `nθ[K:N] + Σβ_j`;
   - degree 0: `θ[K:N]`.

   For a transversal these are `(χ[K:N] + β − c, β, 0)`.
3. **Consequences at each finite level.** For a transversal `T`:
   - `χ[K:N] − c <= b_2(N) <= χ[K:N] + β − c`;
   - `b_1(N) <= β − c + 1`;
   - `c <= β`.

   The coinvariants split as
   `Q[X] ⊗ P = H_2(N) ⊕ A ⊕ R` with `dim R = β − c + 1 − b_1(N) <= β`. In particular
   `H_2(N) ∩ A = 0`: no cycle supported in the tile, of any length, meets `H_2(N)`. The cokernel
   of `Z_1(Cay|_T; Q) → H_0(N; Q ⊗ P)` has dimension exactly `χ[K:N] + β − c`.
4. **The finite-level step is the target.** Let `(N_i)` be a residual chain and `δ > 0`.
   "`H_2(N_i)` lies, up to `δ[K:N_i]` dimensions, in the image of finitely many relators" means
   `H_2(N_i) ⊂ im(Q[X_i] ⊗ M) + W_i` with `M <= P` finitely generated and
   `dim W_i <= δ[K:N_i]`. Suppose `b_1(N_i)/[K:N_i] → 0`, which holds whenever `K` is
   amenable, by item 5.
   - If this holds for all large `i`, then `lim sup b_2(N_i)/[K:N_i] <= δ + λ(M)`, where
     `λ(M) = lim sup dim(H_2(N_i) ∩ im(Q[X_i] ⊗ M))/[K:N_i]`.
   - Conversely, `b_2(N_i) <= δ[K:N_i]` gives it with `M = 0`.
   - With `λ(M) = 0`, which holds for amenable `K` by
     `ultraproduct-limits-of-finite-covers-see-only-the-l2-rank`, the step for `δ` implies
     `χ <= δ`, and `χ < δ` implies the step for `δ`. So the step for every `δ > 0` is
     equivalent to `χ = 0`, which is the target.

   So "prove `rk coker Φ = 0` at finite level" has no content beyond the target. The finite
   level offers nothing weaker to prove.
5. **Følner tilings compute `χ` exactly and cannot bound it.** Let `K` be amenable and
   residually finite, and take Weiss's Følner transversals `T_i` for a nested residual chain, so
   `β(T_i)/[K:N_i] → 0`. Then, with no Lück approximation:
   - `b_2(N_i)/[K:N_i] → χ` and `b_1(N_i)/[K:N_i] → 0`;
   - `χ = lim dim coker(Z_1(Cay|_{T_i}; Q) → H_0(N_i; Q ⊗ P)) / [K:N_i]`.

   The same holds for any Følner tile families with `θ_i → 0`. Every conclusion drawn from the
   collapse has the form `b_2(N) = χ[K:N] + O(β + θ[K:N])`, with `χ` entering only through
   Swan's count `r = χ + n − 1` in degree 2. Hence **every Følner-tiling or quasi-tiling collapse
   of the covers is `χ`-blind**, at every scale. This includes cell-model collapses: a
   relator or 2-cell supported in a tile maps into `A`, so it meets `H_2(N)` in `0`. A proof
   of `χ = 0` along these lines must bound the Swan rank `r` of the `N`-coinvariants of `P` by
   `n − 1` from a non-tiling input, and that is `D(P) = 0`, the target.
6. **Calibrations.**
   - `Z²`, and `BS(1, m)` with `m ≠ 0`: `χ = 0` and `r = n − 1`. For the `L × L` box in
     `Z²/(LZ)²` the quotient complex has dimensions `(2L − 1, 2L, 0)` with `H_2 = Q` and
     `dim H_1 = 2`.
   - A torsion-free `Ã_2`-lattice `Γ` with property (T): `cd Γ = 2`, `b_1(N) = 0` for all `N`,
     so `χ(Γ) = 1 + b_2(Γ) >= 1`. Items 1 to 3 hold verbatim, but `β(T) >= h[Γ:N]` with `h > 0`
     for every transversal, so the collapse gives no asymptotics. Amenability enters only
     through `β = o([K:N])`, which fixes `b_2/[K:N]` at `χ` and not at `0`.

**Next step.** Bound `dim H_0(N_i; Q ⊗ P)` by `(n − 1)[K:N_i] + o([K:N_i])` from an input that
is not a tiling, for instance a Q[F_i]-module structure on the cross-tile remainder
`H_2(N_i) ⊕ R_i` that forces it to be induced from a proper subgroup. On the escape side, look
for an amenable, torsion-free, non-elementary-amenable group of cd 2 whose finite-index subgroups
all have `b_1 = 0`. By item 3 its Schreier graphs would carry `χ[K:N] − c` independent classes
of the cycle coinvariants invisible to every tile.

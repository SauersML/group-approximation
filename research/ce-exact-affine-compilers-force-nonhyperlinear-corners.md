independently reviewed. No novelty is claimed: the proof combines (CS1) of
`group-corner-exact-compilers-force-source-affine-safety` with Thom's
central-corner criterion.

**2026-09-20 strengthening.**
`ce-affine-decoder-positive-model-forces-safe-support` removes the need
to assume the entire host hyperlinear: any one CE corner model supplies
a hyperlinear image quotient preserving the central character, whose
canonical corner model has affine context support. Thus an affine-unsafe
source forces the target corner to have **no CE model**, not just a
nonhyperlinear ambient group. The theorem below remains valid, but a
nonhyperlinear host is not an escape compatible with positive CE
completeness.

## Setting

Notation as in `group-corner-exact-compilers-force-source-affine-safety`:
- a countable group `Gamma`, a central `J` of finite order `n`, and a
  faithful character `omega` of `<J>`;
- the central projection `p_omega` and the corner `p_omega C*(Gamma) p_omega`;
- contexts `A_t`, which are finite abelian subgroups, and answer projections
  `e_chi` (GC2).

A model `tau'` of the corner is **Connes-embeddable** if the von Neumann
algebra generated by the corner in the GNS representation of `tau'`, with its
vector trace, admits a trace-preserving unital embedding into `R^U`.

Let `B` be a finite Boolean constraint system with contexts `V_c` and allowed
sets `C_c subseteq F_2^(V_c)`. A **CE-exact compiler with affine decoding**
from `B` consists of, for each source context `c`:
- a target context `A_(t(c))`;
- an affine map `D_c : A_(t(c))^ -> F_2^(V_c)`.

It must satisfy:

(CE) for **every Connes-embeddable** model `tau'` of the corner, the source
observables `X_v = sum_chi (-1)^(D_c(chi)_v) e_chi` (GC5) agree across contexts
and form a perfect tracial model of `B` in the GNS representation of `tau'`.

Decoding is required on no other models.

## Statement (CS3)

Suppose such a compiler exists, `J` has order exactly `n`, and `Gamma` is
hyperlinear. Then `B` has a **Connes-embeddable** perfect tracial model whose
support in every context `c` is the affine set

```text
S_c = D_c(X_(A_(t(c)))(omega)) subseteq C_c.                          (CE1)
```

So `Aff_F2(S_c) = S_c subseteq C_c` for every `c`.

The same holds with shared randomness. Suppose each seed `r` of a finite
probability space carries affine maps `D_c^r`, and (CE) is only required of
the seed-averaged strategy. Every seed with positive mass then gives such a
model, because an average of values at most one equals one only if each
positive-mass term does.

## Consequences

1. **Nonhyperlinearity is forced.** Suppose `B` has no Connes-embeddable
   perfect model with affine-safe supports, while the compiler is CE-exact,
   decodes affinely, and has `J` of order `n`. Then `Gamma` is nonhyperlinear.
   - Example source: the active JNVWY compression outputs of
     `jnvwy-active-output-has-no-affine-safe-perfect-model`, which have no
     affine-safe perfect model of any kind.
   - At halting inputs these sources are perfectly Connes-embeddable
     satisfiable, so the compiler is not vacuous there.
2. **The recursion layer is not where the difficulty lies.**
   - Take a machine-indexed compiler with (PC1) of
     `perfect-completeness-constant-soundness-lcs-compiler` (halting gives
     `J != 1`).
   - Suppose its soundness decoder is an affine ultraproduct decoder of the
     form (GC5) that is exact on the limiting Connes-embeddable models.
   - Then at every halting input whose source is affine-unsafe, the output
     group is already nonhyperlinear.
   - So proving such soundness at **one** explicit halting input already
     proves `non-hyperlinear-group`. The proof-search fixed point of
     `re-oriented-lcs-compiler-gives-nonhyperlinear-group` adds nothing to
     the difficulty of this decoder class.
3. **The failing step of the proposed upgrade.** The proposed no-go said
   that every CE-sound compiler is already sound on all traces.
   - On a hyperlinear target, (CE) already implies the conclusion (GC6) of
     (CS2): the only trace (CS2) uses is the canonical corner trace, which is
     Connes-embeddable by Thom's criterion.
   - On a nonhyperlinear target the host's own canonical corner trace need
     not be Connes-embeddable. However, any positive CE model supplies a
     hyperlinear image quotient and hence a different canonical corner
     trace to which the decoder applies. The strengthening cited above
     closes this proposed escape for positive CE completeness.
   - No hyperlinearity theorem for the whole compiled halting group is
     needed to rule out this exact affine decoder class on affine-unsafe
     positive inputs.

## Scope

Not covered:
- non-affine decoders, where source involutions are not signed group
  elements of the corner (`non-ru-bcs-is-satisfiable-in-a-group-factor`);
- randomized non-affine readouts such as the Taller--Vidick uniform choice
  from a measured Fourier set, which pay the random-guessing floor of
  `perfect-correlated-masks-have-undamped-conditioned-spectrum`;
- constant-gap affine decoders, where near-perfect target models only give
  source value at least a constant `s < 1`. (CE) applied to the canonical
  trace of a hyperlinear target then gives a Connes-embeddable strategy of
  value at least `s` with affine context supports, and no firewall on main
  bounds the value of such strategies for MIP* sources.

The artifact records these regimes, with source pins for the linear robust
tests that avoid the random-guessing floor.

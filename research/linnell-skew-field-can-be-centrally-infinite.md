Let `Q = Z[1/2] x| Z = BS(1,2)` with `x = (1,0)`, `t = (0,1)`, so
`t x t^{-1} = x^2`.  Let `P = <x>`, `X = Q/P`, `A = (+)_X Z` with `Q`
permuting coordinates, and

    W = A x| Q,        c = delta_P.

**Claim.**  `W` is a three-generated torsion-free elementary amenable group
with **nontrivial** intrinsic compression--centralizer defect that
**satisfies** the Strong Atiyah Conjecture.  Consequently its Linnell
division closure `D = D_C(W)` is a division ring in which the division
subring generated by the three elements `x, t, c` is infinite-dimensional
over its center; in particular `D` is not weakly locally finite.

The defect element is `u = [t c t^{-1}, x] = delta_{tP} - delta_{xtP} != 0`,
nontrivial because `t^{-1} x t = (1/2, 0)` is not in `P`.  Here `t` compresses
`P` (`tPt^{-1} = <x^2>`) and `c` centralizes `P` (`P` fixes the coset `P`).

## What it refutes

Two statements, both of which a natural proof of
`strong-atiyah-torsion-free` from this repository's machinery would need:

* *"Every homomorphism into a division ring kills the compression defect."*
  False: `W -> D_C(W)^x` is faithful and `u != 1`.
* *"Every Linnell division ring is weakly locally finite."*  False, by the
  claim above.

This is not an unfilled technical step.  The intermediate statement is
contradicted by a group for which Strong Atiyah is a **theorem** -- it is
torsion-free elementary amenable, and that class is on Fisher--Ng's list of
known cases.

## It is this graph's own witness, rediscovered

`W` is not a new object here.  It is the family of
`infinite-cyclic-compression-lamp-mf` -- integer lamps over a compressed site
space, `Z^(X) x| H` with `H` countable residually finite and
`L_1 = t L t^{-1} < L` -- at `H = BS(1,2)`, `L = <x>`.  That node already used
it to refute a *different* bridge: the defect survives inside a faithful MF
group, so "the defect lies in the MF radical" is false.  The external audit
that produced the present claim did not know that, and arrived at the same
group from the division-ring side.

The two nodes index lamps differently -- `H/L_1` there, `Q/P` here -- and
nothing depends on the choice.  The agreement is worth recording: the same
witness kills the MF-radical bridge and the division-ring bridge, which
suggests it will kill the next bridge of this shape too, and that any future
attempt should be tested against it first.

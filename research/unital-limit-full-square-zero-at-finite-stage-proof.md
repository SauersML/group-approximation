Write `phi_(k,infinity):A_k->A` and `phi_(k,j):A_k->A_j` for the canonical
maps.  Recall `||phi_(k,infinity)(w)||=lim_j ||phi_(k,j)(w)||`.

### Finite unit identities

In a unital C-star algebra `B`, an element `y` is full if and only if

```text
1=sum_(i=1)^m a_i y b_i                                        (FU1)
```

for finitely many `a_i,b_i in B`.  If `y` is full, the algebraic ideal
generated by `y` is dense, so it contains some `c` with `||1-c||<1`.  Then `c`
is invertible and `1=c^(-1)c` lies in the algebraic ideal, which is (FU1).
The converse is immediate.  Unital `*`-homomorphisms preserve (FU1).

### 2 implies 1

Apply the unital map `phi_(j,infinity)` to (FU1) for `z`.  The image is
square-zero and still satisfies (FU1).

### 1 implies 2

Scale so that `||x||<=1`, keeping `x^2=0` and fullness.  Fix (FU1) for `x`
with `m` terms and put `M=max(1, ||a_i||, ||b_i||)`.  Choose `eta` in
`(0,1)` so small that

```text
m [ M^2 (3 eta) + 2 (M+1)^2 eta ] < 1.                          (FU2)
```

Let `delta` be the stability constant of
`square-zero-contractions-are-stable-relations` for `eta`, and put
`rho=min(eta, delta/6)`.  The order matters: `eta` is fixed first, then
`delta`, then `rho`.

By density of the union of the stage images, there are a stage `k` and
`y_0, a_i', b_i' in A_k` whose images in `A` are within `rho` of
`x, a_i, b_i`.  Writing `w'` for the image in `A`, in `A` we have

```text
||(y_0')^2|| <= ||y_0'-x|| ||y_0'|| + ||x|| ||y_0'-x|| < rho(1+rho) + rho < 3 rho.
```

Since stage norms decrease to limit norms, some `j>=k` satisfies

```text
||phi_(k,j)(y_0)|| < 1+rho,       ||phi_(k,j)(y_0)^2|| < 3 rho <= delta/2.
```

Put `y=phi_(k,j)(y_0)/max(1, ||phi_(k,j)(y_0)||)`.  Then `||y||<=1`,
`||y-phi_(k,j)(y_0)||<rho`, and `||y^2||<delta`.  The stability claim gives
`z in A_j` with

```text
z^2=0,        ||z-y||<eta,        so  ||phi_(j,infinity)(z)-x|| < eta+2 rho <= 3 eta.
```

Let `c=sum_i phi_(k,j)(a_i') z phi_(k,j)(b_i') in A_j`, and write `z'` for
the image of `z` in `A`.  Each term splits into three differences:

```text
||a_i x b_i - a_i' z' b_i'||
  <= ||a_i-a_i'|| ||x|| ||b_i|| + ||a_i'|| ||x-z'|| ||b_i|| + ||a_i'|| ||z'|| ||b_i-b_i'||
  <= rho M + (M+1)(3 eta) M + (M+1)(2) rho.
```

Summing over `i` and using `rho<=eta` and (FU2), `||1-phi_(j,infinity)(c)||<1`.
Stage norms decrease to this limit norm, so for some `j'>=j`,

```text
||1-phi_(j,j')(c)|| < 1.
```

Then `phi_(j,j')(c)` is invertible in `A_(j')`, so `phi_(j,j')(z)` satisfies
(FU1) in `A_(j')`: it is full there, and it is square-zero.  This is 2 with
stage `j'`.

Specialization. Every amenable automatic group is automatic, so
`automatic-groups-have-contractible-rips-complexes` provides a finite generating
set and a scale at which its Rips complex is contractible. That is the
existential reading of Zaremsky Problem 4.1 recorded in
`amenable-automatic-groups-have-contractible-rips-complexes`.

The prerequisite is strictly stronger: it drops amenability. This is a
reduction, not a restatement.

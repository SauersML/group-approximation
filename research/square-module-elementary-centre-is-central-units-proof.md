Notation: `E_ij` is a matrix unit, `e_ij(r) = 1 + r E_ij` for `i != j`,
`E_n(R)` is the group generated by these, and `E(R) = ∪ E_N(R) ≤ GL(R)`.
Fix `c in Z(R)^x`.

## Step 0. The module isomorphism in coordinates

An isomorphism `R_R -> R_R^d` is given by a column `a in R^(d×1)` and a row
`b in R^(1×d)` with

    b a = 1,     a b = I_d.

The map `θ : M_d(R) -> R`, `θ(X) = b X a`, is a ring isomorphism:
- it is multiplicative, since `θ(X)θ(Y) = bX(ab)Ya = bXYa`;
- it sends `I_d` to `ba = 1`;
- its inverse is `r ↦ a r b`, since `θ(arb) = (ba) r (ba) = r` and
  `a θ(X) b = (ab) X (ab) = X`.

Because `c` is central, `θ(c I_d) = c b a = c`.

## Step 1. `[c] = d[c]` in `K_1(R)`

In `GL_(d+1)(R)` put `P = [[0, b], [a, 0]]`, with blocks of sizes `1` and `d`.
Then `P^2 = diag(ba, ab) = I_(d+1)`. Using centrality of `c`,

    P diag(c, I_d) P = [[0, b], [ac, 0]] · [[0, b], [a, 0]]
                     = diag(ba, c·ab) = diag(1, c I_d).

So `diag(c, I_d)` and `diag(1, c I_d)` are conjugate in `GL_(d+1)(R)`. Since
`K_1(R) = GL(R)/E(R)` is abelian, the class of a matrix is invariant under
conjugation. Hence `[c] = [c I_d] = d[c]`, and therefore `[c^(d-1)] = 0`.

This uses two standard facts. First, block diagonal sums add in `K_1`, since
`diag(x, y)` and `diag(xy, 1)` agree modulo `E(R)` (Whitehead). Second, `E(R)`
is normal in `GL(R)`, and `GL(R)/E(R)` is abelian (Whitehead lemma).

Hence there is `N` with `diag(c^(d-1), 1, ..., 1) in E_N(R)`.

## Step 2. Full scalar matrices in large rank

Put `u = c^(d-1)`, which is central, and fix `M >= N`. Let `D_i in GL_M(R)`
be the diagonal matrix with `u` in position `i` and `1` elsewhere. The
inclusion `E_N ≤ E_M` gives `D_1 in E_M(R)`.

The signed transposition `w = e_1i(1) e_i1(-1) e_1i(1)` lies in `E_M(R)` and
is a monomial matrix with entries `±1`. Conjugation by `w` permutes the
diagonal entries, and the signs cancel, so `w D_1 w^(-1) = D_i`. Therefore
every `D_i` lies in `E_M(R)`, and

    u I_M = D_1 D_2 ... D_M  in  E_M(R).

## Step 3. Descent in rank through `θ`

For `m >= 2`, identify `M_(dm)(R) = M_m(M_d(R))` by `m × m` blocks of size
`d`. This gives the same group `GL_(dm)(R) = GL_m(M_d(R))`.

**Claim: `E_(dm)(R) ≤ E_m(M_d(R))`.** Take a generator `e_jk(r)` of
`E_(dm)(R)`.
- If `j` and `k` lie in different blocks `α != β`, then
  `e_jk(r) = e_αβ(r E_j'k')` for the matrix unit `E_j'k'` of `M_d(R)` at the
  in-block positions. This is a generator of `E_m(M_d(R))`.
- If `j != k` lie in the same block, choose an index `l` in another block
  (possible since `m >= 2`). Then

      e_jk(r) = [e_jl(r), e_lk(1)].

  This is the Steinberg commutator relation for distinct `j, l, k`. Both
  factors are of the first kind.

**The map `F`.** Applying `θ` entrywise gives a ring isomorphism
`F : M_m(M_d(R)) -> M_m(R)`. It sends `e_αβ(X)` to `e_αβ(θ(X))`, so
`F(E_m(M_d(R))) ≤ E_m(R)`. It also sends `u I_(dm) = diag(u I_d, ..., u I_d)`
to `diag(θ(u I_d), ...) = u I_m`.

**Conclusion.** If `u I_(dm) in E_(dm)(R)`, then `u I_m in E_m(R)`.

**Iterating.** Now fix `n >= 2`. Choose `k` with `M = n d^k >= N`, so that
`u I_M in E_M(R)` by Step 2. Apply the conclusion `k` times, with
`m = n d^(k-1), ..., n d, n`; every such `m` satisfies `m >= n >= 2`. This gives
`c^(d-1) I_n in E_n(R)`, which is item 1.

(Commutator convention: `[x, y] = x y x^(-1) y^(-1)`.)

## Step 4. The centre (item 2)

**The centraliser of `E_n(R)`, for any ring and `n >= 2`.** Let `X in M_n(R)`
commute with every `e_ij(r)`, so `X r E_ij = r E_ij X`.
- The left side is supported in column `j`, with `(k, j)` entry `X_ki r`.
- The right side is supported in row `i`, with `(i, l)` entry `r X_jl`.
- For `k != i` and `r = 1` this gives `X_ki = 0`. So `X` is diagonal.
- At position `(i, j)` it gives `X_ii r = r X_jj` for all `r`. With `r = 1`
  all diagonal entries equal a common `c`, and then `c r = r c` for all `r`,
  so `c in Z(R)`.

Hence

    Z(E_n(R)) = E_n(R) ∩ Z(R)^x I_n.

The inclusion `⊇` holds because scalar matrices with central entries are
central in `GL_n(R)`. By item 1 this group contains `(Z(R)^x)^(d-1) I_n`.

**The case `d = 2`.** Here every `c I_n` with `c in Z(R)^x` lies in `E_n(R)`,
so `Z(E_n(R)) = Z(R)^x I_n`. The map `c ↦ c I_n` is an isomorphism
`Z(R)^x -> Z(E_n(R))`.

## Step 5. Finite centre (item 3)

Let `R` be finitely presented and simple, `n >= 4`, and `PE_n(R)` finitely
presented. By [[projective-elementary-fp-kernel-criterion]] (1 ⇒ 2),
`Z(E_n(R))` is a finitely generated abelian group. Since `R` is simple,
`k = Z(R)` is a field.

By Step 4, `(k^x)^(d-1)` is isomorphic to a subgroup of `Z(E_n(R))`, so it is
finitely generated. The power map `x ↦ x^(d-1)` maps `k^x` onto `(k^x)^(d-1)`,
and its kernel consists of roots of `x^(d-1) = 1`, so it has at most `d - 1`
elements. Hence `k^x` is finitely generated. A field with finitely generated
multiplicative group is finite:
- **Characteristic `0`.** Then `Q^x ≤ k^x`, which contains the free abelian
  group on the primes. It is not finitely generated, and subgroups of
  finitely generated abelian groups are finitely generated.
- **Characteristic `p`, with an element `t` transcendental over `F_p`.** The
  monic irreducible polynomials in `t` are infinitely many, and they generate a
  free abelian subgroup of `F_p(t)^x ≤ k^x` of infinite rank.
- **Characteristic `p`, algebraic over `F_p`.** Then `k^x` is torsion. A
  finitely generated torsion abelian group is finite, so `k` is finite.

So `k = F_q`.

## Step 6. Simplicity of `E_n` (item 4)

If `E_n(R)` is simple, its centre is trivial. Indeed `E_n(R)` is nonabelian
for `R != 0` and `n >= 2`, since `[e_12(1), e_21(1)] != 1`; so the centre,
being a normal subgroup, is not the whole group. By item 1,
`c^(d-1) I_n = I_n` for every `c in Z(R)^x`.
- **`d = 2`.** Then `Z(R)^x = 1`.
- **`R` simple.** Then `Z(R)` is a field in which every nonzero element
  satisfies `x^(d-1) = 1`. It therefore has at most `d` elements, and `q - 1`
  divides `d - 1`. For `d = 2` this forces `F_2`.

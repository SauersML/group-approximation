**OPEN.** `D_2 = Q x|_2 Z = <Q, s | s q s^-1 = 2q>` embeds in a finitely
presented group with an action of type (A)
(`type-a-action-gives-boone-higman-for-subgroups`). Equivalently, by
`permutational-host-forms-agree-for-countable-inputs`, it embeds in a finitely
presented simple group lying in `B_A`.

## Why this test case

- **Necessary for the root's `B_A` form.** `D_2 <= Aff(Q) <= GL_2(Q)` as the matrices
  `[[2^k, q],[0, 1]]`, and `B_A` is closed under subgroups. So
  `gl-n-q-in-permutational-boone-higman-class` implies this claim.
- **It carries both obstructions.**
  - It contains the divisible `(Q,+)`, so any host must fail to be residually
    finite at every stage (root O1).
  - It contains `BS(1,2) = <1, s>`, whose cyclic subgroup `<1>` is exponentially
    distorted. So `VA` and all its subgroups are excluded as hosts (root O4), and
    so are the Higman--Thompson groups `V_{d,r}`
    (`almost-automorphism-conjugate-to-proper-power-is-equicontinuous`).
- **Its finitely generated subgroups are all `BS(1,2)`,** which lies in `B_A` by
  `char-zero-linear-groups-satisfy-permutational-boone-higman`, because
  `BS(1,2) = Aff(Z[1/2]) <= GL_2(Z[1/2])`. So only the single-host requirement is
  open.

## Attempts

1. **Hall-type finitely generated overgroup (2026-09-17, lane gq-deep-typeA-1).**
   `rational-bs12-hull-embeds-in-a-fg-solvable-group` puts `D_2` inside an explicit
   4-generator solvable group `Ĥ` with solvable word problem. This gives route
   `rational-bs12-hull-via-hall-overgroup`, whose one open hole is
   `rational-bs12-hall-overgroup-in-permutational-bh-class`, a question about a
   single finitely generated group.
2. **Twisted Brin--Thompson tower route: the reduction (same lane).**
   - **Actor.** Let `G ↷ S` be of type (A) with `BS(1,2) = <a, t> <= G`, where
     `t a t^-1 = a^2`. Add one point `*` fixed by all of `G`. The action on
     `S^+ = S ⊔ {*}` is again of type (A): `Stab(*) = G` is finitely presented,
     and the new two-element orbits `{*, s}` are finite in number. Then
     `Γ = S^+V_G` is finitely presented and simple
     (`twisted-brin-thompson-finite-presentation-criterion`).
   - **Skew products.** Write `C^(S^+) = C_* × C^S`. The maps
     `(y, z) -> (v(y), f(y)·z)`, with `v ∈ V` acting on `C_*` and `f : C_* -> G`
     locally constant, lie in `Γ`.
   - **Tower data.** Suppose:
     - (i) there are `ρ_m ∈ V` (`m` odd, directed by divisibility, cofinal) with
       `ρ_(mk)^k = ρ_m`, each `ρ_m` freely and cyclically permuting clopen levels
       `Y^m_0, …, Y^m_(m-1)`. Then the towers `x_m = (ρ_m, a^[y ∈ Y^m_(m-1)])`
       generate `D ≅ Z[1/odd]` containing `a`
       (`twisted-bt-point-fixing-actor-elements-are-divisible` is this device);
     - (ii) there is `ψ ∈ V` with `ψ ρ_m ψ^-1 = ρ_m^2` for all `m`;
     - (iii) there is a locally constant `β : C_* -> Z` with
       `2c_m∘ψ^-1 + β∘ρ_m^2 - β = c_m + c_m∘ρ_m` for all `m`, where `c_m` is the
       indicator of `Y^m_(m-1)`.
   - **Conclusion.** Then `t^ = (ψ, y -> a^(β(ψ y)) t)` satisfies `t^ x t^-1 = x^2`
     on `D` and `t^ a t^-1 = a^2`. So `<D, t^> ≅ D_2`. Injectivity holds because a
     normal subgroup of `D_2` meeting `Q` meets `Z[1/odd]`. This proves the claim.
   - **Dropping a tempting simplification.** A pure coordinate permutation
     cannot serve as `t^`. The factor action on `C_*` would force `ρ_x = ρ_x^2`.
3. **The tower route dies with vertical factor `V` (conditional; same lane).**
   Suppose infinite-order elements of `V` have a finite, nonempty set `A` of
   periodic points with nonzero return slope (the input
   `infinite-order-elements-of-v-have-hyperbolic-periodic-points`, still OPEN
   here, together with the standard finiteness from revealing pairs). Then (i)
   and (ii) are incompatible. Proof:
   - `ψ` has infinite order, because `x2` has infinite order on `R_odd = Z[1/odd]/Z`.
   - Each `ρ` in `R_odd = <ρ_m>` has odd order `n`, so `ψ^N` commutes with `ρ` for
     `N` the order of 2 modulo `n`.
   - Commuting with `ψ^N` and lying in `V`, `ρ` preserves the hyperbolic periodic
     points of `ψ^N`, which are exactly those of `ψ`: slopes are conjugation
     invariant in `V`.
   - So the divisible group `R_odd` acts on the finite set `A`. A divisible group
     has no nontrivial finite quotient, so it fixes `A` pointwise. That contradicts
     freeness.
   - Hence the vertical factor must be a group whose elements can have infinitely
     many hyperbolic periodic points, or aperiodic cores. That means a block of at
     least two fixed coordinates, acting through `2V`. Two examples: the baker map
     has periodic saddles of every period, and `three-v-contains-aperiodic-rationals`
     gives aperiodic elements.
4. **Spark, not pursued: a solenoid model for a 2V vertical factor.**
   - `Λ = R_odd x|_2 Z` acts naturally on the dyadic solenoid
     `Σ_2 = (Z[1/2])^`. Its torsion subgroup is `R_odd`, acted on freely by
     translation, and `x2` is a homeomorphism.
   - In digits, `Σ_2 ≈ C × Z_2`, and `x2` is the baker map, which lies in `2V`.
   - What is missing is a recoding that makes the torsion translations into
     finite-piece maps while keeping the baker finite-piece. This is the
     two-dimensional analogue of Belk--Hyde--Matucci's recoding of `Q/Z <= T`. Its
     one-dimensional shadow is the circle reformulation in
     `q-x2-z-in-t-check-has-a-doubling-semiconjugacy`, item 5.

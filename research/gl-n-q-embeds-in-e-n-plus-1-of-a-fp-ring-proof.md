Proof from `q-embeds-in-a-corner-of-a-fp-toeplitz-ring`. Lane proof, not independently
reviewed.

Let `φ: Q -> C = E R_T E` be the injective unital map onto the corner. Viewed as a map into
`R_T` it is a non-unital ring homomorphism with `φ(1) = E`.

1. **Embedding GL.** For `m >= 1`, define `Ψ: GL_m(Q) -> GL_m(R_T)` by
   `Ψ(g) = φ(g) + (1 - E)·I_m`, where `φ` acts entrywise. Every entry `x` of `φ(g)`
   satisfies `x(1 - E) = (1 - E)x = 0`. Hence
   - `Ψ(g)Ψ(h) = φ(gh) + (1 - E)I_m = Ψ(gh)` and `Ψ(1) = I_m`;
   - `Ψ` is an injective group homomorphism, because `φ` is injective.
2. **Elementary matrices go to elementary matrices.** `Ψ(e_ij(q)) = I + φ(q)e_ij = e_ij(φ(q))`.
   `Q` is a field, so `SL_m(Q) = E_m(Q)`, and therefore `Ψ(SL_m(Q)) <= E_m(R_T)`.
3. **GL_n inside SL_(n+1).** The map `g ↦ diag(g, det(g)^(-1))` embeds `GL_n(Q)` in
   `SL_(n+1)(Q)`. Compose with `Ψ` for `m = n + 1`.
4. **Finite generation.** Let `m = n + 1 >= 3` and let `H` be the subgroup generated by
   `e_ij(x)`, `x ∈ X = {1, S, T, N, A}`. For each pair `(i, j)`, the set
   `{r : e_ij(r) ∈ H}` is an additive subgroup, because `e_ij(a)e_ij(b) = e_ij(a+b)`.
   For distinct `i, j, k`, the commutator `[e_ij(a), e_jk(b)] = e_ik(ab)` shows:
   - if `a` lies in the `(i,j)` set and `b` in the `(j,k)` set, then `ab` lies in the
     `(i,k)` set;
   - by induction on word length in `X`, every product of generators lies in every
     `(i,j)` set, because `m >= 3` leaves a third index free.

   So each set is all of `R_T`, and `H = E_m(R_T)`.
5. **The concrete model.** `ρ∘Ψ` is injective, since `ρ(φ(q)) = q·ρ(E)` and `ρ(E) ≠ 0`.
   The image `ρ(E_m(R_T)) = E_m(ρ(R_T))` is generated by the images of the same finitely
   many elements.
6. **Word problem in the model.** Every element of `ρ(R_T)` is a finite sum `Σ S^a d T^b`
   with `d` diagonal. Its diagonal entries `d(k)` are eventually a rational function of
   `k`, and arbitrary at finitely many `k`:
   - `S d = (shifted d) S` and `T d = (shifted d) T`;
   - `TS = 1` and `ST = 1 - E_0`;
   - products and shifts of eventually rational sequences are eventually rational.

   Such an operator is zero if and only if, for each of the finitely many offsets
   `c = a - b`, the eventually rational entry function vanishes. That is decidable: check
   the rational part symbolically, and check the finitely many exceptional values.
   Matrix identities in `E_m(ρ(R_T))` reduce entrywise to this test. ∎

Conventions: `x^y = y^-1 x y` and `[x,y] = x^-1 y^-1 x y = x^-1 x^y`. The rank of an abelian group `U`
is `dim_Q (U ⊗ Q)`. For a solvable group, the Hirsch length (torsion-free rank) is the sum of the ranks
of the derived factors. It is additive along subnormal series with abelian factors and does not increase
on subgroups (Lennox--Robinson, *The theory of infinite soluble groups*, §1.3).

Let `Q = H4/R` with `Q != 1`, and write `a, b, c, d` for the images. By item 1 of
`nontrivial-higman-quotients-keep-all-four-bs-subgroups`, they have infinite order. Fix `m >= 1`, and put

```text
alpha = a^m,   gamma = c^m,   P = 2^m >= 2,   A_1 = <alpha, gamma>,   z = [gamma, alpha] = gamma^-1 gamma^alpha.
```

Assume `A_1` is metabelian, so `A_1'` is abelian. We derive a contradiction.

## Step 1 (relations)

From `a^-1 b a = b^2` we get `a^-j b a^j = b^(2^j)` by induction, so `b^alpha = b^P`, i.e. `b alpha = alpha b^P`.
Also `gamma^b = (c^b)^m = c^(2m) = gamma^2`. Let `phi` be conjugation by `g = b^P`. Then

```text
phi(gamma) = gamma^(2^P),
phi(gamma^alpha) = (alpha b^P)^-1 gamma (alpha b^P) = (b alpha)^-1 gamma (b alpha) = alpha^-1 gamma^2 alpha = (gamma^alpha)^2.
```

In the same way, `d^c = d^2` and `a^d = a^2` give `d^gamma = d^P` and `alpha^d = alpha^2`. So conjugation
`phi'` by `g' = d^P` satisfies `phi'(alpha) = alpha^(2^P)` and `phi'(alpha^gamma) = (alpha^gamma)^2`. This is
Step 1 with `(alpha, b, gamma)` replaced by `(gamma, d, alpha)`.

## Step 2 (the `b` side: `z` is torsion under conjugation by `gamma`)

Write `V = A_1' ⊗ Q` additively. `A_1` acts on `V` by conjugation through the abelian group `A_1/A_1'`.
Let `X` and `Y` be the commuting linear maps induced by `alpha` and `gamma`, and let `zbar` be the image of `z`.

**Claim.** `span_Q { Y^j zbar : j in Z }` is finite-dimensional.

*Proof.*
- Let `M = <gamma, gamma^alpha> = <gamma, z>`. Let `W` be the subgroup generated by the conjugates
  `z^(gamma^j)`, `j in Z`. Then `W <= A_1'`, so `W` is abelian.
- `W` is normalized by `gamma`, and by `z` since it is abelian. So `W` is normal in `M`, `M = <gamma> W`, and
  `M/W` is cyclic.
- `W` is a cyclic module over `R = Z[T^±1]`, with `T` acting as conjugation by `gamma` and generator `z`.
- By Step 1, `phi(M) <= M`. Since `phi` is the restriction of an inner automorphism of `Q`, it is injective,
  and `phi(W)` is abelian.
- Compute:

  ```text
  phi(z) = phi(gamma)^-1 phi(gamma^alpha) = gamma^(-2^P) (gamma z)^2 = gamma^(2 - 2^P) · z^gamma z = gamma^e w_0,
  ```

  with `e = 2 - 2^P != 0`, because `P >= 2`, and `w_0 = z^gamma z in W`.
- Let `D = phi(W) ∩ W`. Take `w in D`. It commutes with `phi(z) = gamma^e w_0`, since `phi(W)` is abelian,
  and with `w_0`, since `W` is abelian. Hence `w^(gamma^e) = w`. So `D <= F = { w in W : (T^e - 1) w = 0 }`.
- `R` is Noetherian, so `F` is a finitely generated `R`-module. It is killed by `T^e - 1`, so it is a
  finitely generated module over `R/(T^e - 1)`, which is free of rank `|e|` over `Z`. Hence `F` is a
  finitely generated abelian group, of finite rank `r_F`.
- The composite `phi(W) -> M -> M/W` has kernel `D`, so `phi(W)/D` embeds in a cyclic group and has rank
  at most 1.
- So `rank W = rank phi(W) <= 1 + rank D <= 1 + r_F < ∞`.
- Since `Q` is flat, `W ⊗ Q -> A_1' ⊗ Q = V` is injective. Its image is `span_Q { Y^j zbar }`, which therefore
  has dimension at most `1 + r_F`. ∎

Being finite-dimensional and `Y`-invariant, this span carries the minimal polynomial `p` of `Y`, which is
nonzero: `p(Y) zbar = 0`.

## Step 3 (the `d` side: `z` is torsion under conjugation by `alpha`)

Apply Step 2 to `(gamma, d, alpha)` in place of `(alpha, b, gamma)`, using `phi'` from Step 1. The group
`<alpha, alpha^gamma> = <alpha, [alpha, gamma]>` lies in the same metabelian group `A_1`, and
`[alpha, gamma] = z^-1`. The conclusion is that `span_Q { X^j zbar : j in Z }` is finite-dimensional. So
some nonzero polynomial `q` satisfies `q(X) zbar = 0`.

## Step 4 (`A_1` has finite Hirsch length)

`A_1` is generated by `alpha` and `gamma`, so `A_1'` is the normal closure of `[alpha, gamma] = z^-1`.
- Hence `V = Q[X^±1, Y^±1] · zbar`.
- `X` and `Y` commute, so `p(Y)` and `q(X)` annihilate all of `V`.
- `V` is therefore a quotient of `Q[X^±1]/(q(X)) ⊗_Q Q[Y^±1]/(p(Y))`, which has dimension at most
  `deg p · deg q`.

So `rank A_1' < ∞`, and `h(A_1) = rank (A_1/A_1') + rank A_1' <= 2 + deg p · deg q < ∞`.

## Step 5 (distinct eigenvalues contradict finite Hirsch length)

This is Item 1, solvable version, of `higman-nilpotent-edge-collapse-proof`, run on the powers `alpha`,
`gamma`. Let `h = h(A_1)` and `K = h`.
- **Scaling.** From `b alpha = alpha b^P`, induction gives `b alpha^k = alpha^k b^(P^k)`. Put
  `u_k = gamma^(alpha^k)` for `0 <= k <= K`. Then

  ```text
  u_k^(b^(P^k)) = (alpha^k b^(P^k))^-1 gamma (alpha^k b^(P^k)) = (b alpha^k)^-1 gamma (b alpha^k) = alpha^-k gamma^2 alpha^k = u_k^2.
  ```

  Iterating `P^(K-k)` times, conjugation by `g_K = b^(P^K)` sends `u_k` to `u_k^(n_k)` with
  `n_k = 2^(P^(K-k))`. These exponents are pairwise distinct.
- **Infinite order.** Each `u_k` is conjugate to `gamma = c^m`, so it has infinite order.
- **Invariant subgroup.** Let `M_K = <u_0, ..., u_K> <= A_1`. Conjugation by `g_K` restricts to an
  endomorphism `psi` of `M_K`, and `h(M_K) <= h`.
- **Eigenvectors.** `psi` preserves the derived series `M_K^(i)` and induces linear maps `L_i` on
  `V_i = M_K^(i)/M_K^(i+1) ⊗ Q`. For each `k`, let `i(k)` be the largest `i` such that some positive power
  `u_k^(r_k)` lies in `M_K^(i)`. It exists, because `u_k` has infinite order. The image `w_k` of
  `u_k^(r_k)` in `V_(i(k))` is nonzero by maximality, and `L_(i(k)) w_k = n_k w_k`.
- **Count.** For fixed `i`, the `w_k` with `i(k) = i` are eigenvectors with pairwise distinct eigenvalues, so
  they are linearly independent. Summing over `i` gives `K + 1 <= sum_i dim V_i = h(M_K) <= h = K`.

This is a contradiction, so `Q = 1`. That proves item 1 for `<a^m, c^m>`.

**The pair `<b^m, d^m>`.** The automorphism `theta : a -> b -> c -> d -> a` of `H4` permutes the relators.
If `<b^m, d^m>` is metabelian in `Q = H4/R`, then `<a^m, c^m>` is metabelian in `H4/theta^-1(R) ≅ Q`,
which is trivial by the above.

## Step 6 (item 2)

Let the image `A` of `<a,c>` have a normal metabelian subgroup `A_0` of finite index `m`. Then
`x^m in A_0` for every `x in A`. So `<a^m, c^m> <= A_0` is metabelian, and Step 5 gives `Q = 1`. The same
argument applies to `<b,d>`.

## Step 7 (item 3)

Suppose `Q != 1` acts on a tree without inversions and fixes no vertex. By item 2 of
`nilpotent-edge-images-collapse-higman-quotients`, some edge stabilizer `S` contains `<a,c>` or `<b,d>`.
- If `S` is virtually metabelian, so is that subgroup, and Step 6 gives `Q = 1`.
- If `S` is virtually solvable of finite Hirsch length, item 1 of
  `nilpotent-edge-images-collapse-higman-quotients` gives `Q = 1`.

Both contradict `Q != 1`. A nontrivial amalgam or HNN splitting gives a Bass--Serre tree action without
inversions and without a global fixed point, with edge stabilizers conjugate to the edge group. So such
a splitting over these edge groups is impossible.

## Calibration

- **The `b` side alone is consistent with infinite rank.**
  - Let `N = Ind_<b>^BS(1,2) Z[1/2]`, where `b` acts on `Z[1/2]` by multiplication by 2. Let
    `c in N` be the image of `1`, and let `G = N ⋊ <a,b>` with `<a,b> = BS(1,2)`.
  - The relations `b^a = b^2` and `c^b = c^2` hold. So `G` is a solvable quotient of
    `< a, b, c | b^a = b^2, c^b = c^2 >` in which `b` and `c` have infinite order.
  - The cosets `a^k <b>` are distinct, so the `c^(a^k)` are independent, and `<a,c> ≅ Z wr Z`.
  - The `Y`-span of `zbar` is one-dimensional, since `c` centralizes the base, in agreement with Step 2.
  - The `X`-span is infinite-dimensional. Step 3 fails there because `G` has no `d` with `d^c = d^2` and
    `a^d = a^2`.
- **Exponent 1.** For the analogue with commuting pairs, where `Z^4` is a nontrivial quotient,
  `2 - 2^P` becomes `1 - 1 = 0`. Step 2 then gives nothing, as it must.
- **Where `H4` is special.** Beyond the relations, the proof uses only the infinite order of `c` (Step 5).
  In the base-3 analogue, whose abelianization is `(Z/2)^4`, that input fails.

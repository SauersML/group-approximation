The model is proved in Section 5.1 of the artifact.  Its proof is repeated
in steps 1--4 of `stw83-circle-ideal-cuntz-quotient-two-bound-proof`, and it
uses only the gauge-invariant uniqueness theorem and matrix-unit
computations.  It gives

```text
0 -> C(T,K) -> C*(F_(n,k)) -> O_n -> 0,
```

with ideal `I_{v}=C(T,K)`.

**Imported theorem.**  S. Evington, arXiv:2012.03650v3, Theorem 1, checked
verbatim in the TeX source on 2026-09-16:

> Let `0->J->A->B->0` be a full extension where `J` is a separable stable
> C\*-algebra and `B` is a separable, nuclear, `O_infinity`-stable
> C\*-algebra.  Then `1 <= dim_nuc(A) <= dim_nuc(J)+1`.

**Verification of the hypotheses.**
1. *The ideal.*  `J=C(T) tensor K` is separable and stable.
2. *The quotient.*  `B=O_n` is separable and nuclear.  It is
   `O_infinity`-stable, by Kirchberg's absorption theorem for Kirchberg
   algebras; this is standard and was not re-fetched here.
3. *Essentiality.*  If `Phi` annihilates `C(T,K)`, then `Phi(t)K=0` for
   every `t`, so `Phi=0`.
4. *Unital Busby invariant.*  Since `A` is unital, the Busby invariant
   `tau:O_n->Q(J)` is unital and injective.
5. *Fullness.*  For `b!=0`, the ideal generated by `tau(b)` contains `tau`
   of the ideal generated by `b`.  That ideal is all of `O_n`, because `O_n`
   is simple, so the ideal contains `tau(1)=1`.  Hence the extension is
   full.  Evington's paper makes the same remark: when `B` is simple, unital
   extensions are full.

**Conclusion.**  Theorem 1 of Evington gives
`1<=dim_nuc(C*(F_(n,k)))<=dim_nuc(C(T) tensor K)+1`.  By Winter--Zacharias,
`dim_nuc(C(T) tensor K)=dim_nuc(C(T))=1`, so the bound is `2`.

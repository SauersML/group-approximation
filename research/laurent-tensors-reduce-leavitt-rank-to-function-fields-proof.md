Notation: `F` is a field, `A` an `F`-algebra, `R` a commutative `F`-domain with `K = Frac(R)` and
`trdeg_F K = s < ∞`. We identify `R` with `1 ⊗ R`, which is central in `A ⊗ R`. All tensor products are over `F`
unless marked otherwise.

## 0. Two facts about `A ⊗ R`

**(0.1) Nonzero elements of `R` are non-zero-divisors in `A ⊗ R`.**
- Fix an `F`-basis `(a_i)` of `A`. Then `A ⊗ R = ⊕_i a_i ⊗ R`.
- For `y = Σ a_i ⊗ r_i` and `0 ≠ r ∈ R`, we have `y r = Σ a_i ⊗ r_i r`.
- This is zero only if every `r_i r = 0`. Since `R` is a domain, that means every `r_i = 0`.

**(0.2) `A ⊗ R ⊆ A ⊗ K`, and `A ⊗ K` is the central localisation `(A ⊗ R)[(R∖0)^(-1)]`.**
- The inclusion holds because `A` is flat over the field `F`.
- Write an element of `A ⊗ K` as `Σ a_i ⊗ k_i` (finite sum). Let `f` be a common denominator of the `k_i`.
  Then the element equals `f^(-1) y` with `y ∈ A ⊗ R`.

## 1. Part (a)

Let `D ⊆ A ⊗ R` be a commutative domain with `trdeg_F Frac(D) >= s + m`.

1. **The commutative hull.** Let `C` be the subalgebra generated by `D` and `R`. It is unital, and it is
   commutative because `R` is central.
2. **A prime avoiding `D` and `R`.** Put `S = {1} ∪ {d r : 0 ≠ d ∈ D, 0 ≠ r ∈ R}`.
   - `S` is multiplicatively closed, because `C` is commutative and `D` and `R` are domains.
   - `0 ∉ S`, by (0.1): `d r = 0` with `r ≠ 0` forces `d = 0`.
   - So `S^(-1) C ≠ 0`, and a maximal ideal of `S^(-1) C` contracts to a prime `P` of `C` with
     `P ∩ S = ∅`. Hence `P ∩ D = 0` and `P ∩ R = 0`.
3. **Transcendence degree over `K`.** Let `L = Frac(C / P)`.
   - Both `D` and `R` inject into `C / P`. So `Frac(D) ↪ L` and `K ↪ L`.
   - Therefore `trdeg_F L >= s + m`.
   - Since `trdeg_F K = s` is finite, additivity gives `trdeg_K L >= m`.
4. **Choosing the elements.** `L` is generated as a field over `K` by the image of `C`. A generating set of a
   field extension contains a transcendence basis. So there are `c_1, …, c_m ∈ C` whose images
   `c̄_i ∈ C / P` are algebraically independent over `K`. The `c_i` commute, since `C` is commutative.
5. **Independence in `A ⊗ K`.** Suppose `Σ_α k_α c^α = 0` in `A ⊗ K`, with `k_α ∈ K`.
   - Choose `0 ≠ r ∈ R` with every `r k_α ∈ R`.
   - Then `z = Σ_α (r k_α) c^α` is an element of `C`. It is zero in `A ⊗ K`, so it is zero in `A ⊗ R` by (0.2).
   - Reduce modulo `P`: `Σ_α (r k_α) c̄^α = 0` in `L`, with coefficients in `R ⊆ K ⊆ L`.
   - By step 4 every `r k_α = 0`, so every `k_α = 0`.

   So the unital `K`-subalgebra `K[c_1, …, c_m] ⊆ A ⊗ K` is a polynomial ring. ∎(a)

## 2. Part (b)

Let `c_1, …, c_m ∈ A ⊗ K` commute and be algebraically independent over `K`.

1. **Clearing denominators.** By (0.2) there is one `0 ≠ f ∈ R` with every `c_i' = f c_i ∈ A ⊗ R`.
   - The `c_i'` commute.
   - They are still independent over `K`, because `X_i ↦ f X_i` is a `K`-automorphism of `K[X]`.
2. **The polynomial ring.** Define `ψ : R[X_1, …, X_m] → A ⊗ R` as the identity on `R` and `X_i ↦ c_i'`. It is a
   ring homomorphism because `R` is central and the `c_i'` commute.
   - If `ψ(Σ r_α X^α) = 0`, read the identity in `A ⊗ K`. Independence over `K` then forces every `r_α = 0`.
   - So `ψ` is injective.
3. **Counting variables.** If `F[x_1, …, x_s] ⊆ R`, then `F[x_1, …, x_s][X_1, …, X_m] ⊆ R[X]` is a polynomial ring
   in `s + m` variables inside `A ⊗ R`. This applies to `R = F[Z^s]`. ∎(b)

## 3. Matrix and corner reduction for Leavitt algebras

For every field `k`, the map `M_2(L_k(1,2)) → L_k(1,2)`, `(a_ij) ↦ Σ_(i,j) s_i a_ij t_j`, is a unital
isomorphism of `k`-algebras.
- It is multiplicative, because `t_j s_k = δ_jk`.
- It is unital, because `s_0 t_0 + s_1 t_1 = 1`.
- Its inverse is `a ↦ (t_i a s_j)`.

Hence `L_k ≅ M_(2^r)(L_k)` for every `r`.

Given `N`, choose `2^r >= N` and let `e = diag(1_N, 0)` in `B = M_(2^r)(L_k)`, so that `M_N(L_k) = e B e`.

Suppose `c_1, …, c_m ∈ e B e` commute and are independent over `k` in `e B e`. They remain independent in `B`:
- in `B`, `p(c) = p_(eBe)(c) + p(0)(1 − e)`;
- compressing by `e` recovers `p_(eBe)(c)`.

So **`Q_m` for `M_N(L_k)` implies `Q_m(k)`.** (This is the fact `M_N(L(1,2)) ≅ L(1,2)` of Abrams–Ánh–Pardo,
but only the corner argument is used.)

## 4. Parts (c) and (d)

**(c).**
- The fraction field of `F[Z^s]`, and of `F[x_1, …, x_s]`, is `F(x_1, …, x_s)`.
- A Laurent ring `F[Z^(s+2)]` is a domain of transcendence degree `s + 2`.
- Apply (a) with `A = L_F(1,2)`. This uses `L_F(1,2) ⊗_F K = L_K(1,2)`, since the Leavitt relations are defined
  over the prime field.
- For the equivalence, apply (a) and (b) with `R = F[x_1, …, x_s]`.

**(d), first bullet.** Let `F[c_1, …, c_m] ≅ F[X]` inside `L_F`.
- By flatness, `K ⊗_F F[c] ≅ K[X]` injects into `K ⊗_F L_F = L_K`.

**(d), second bullet.** Let `c_1, …, c_m ∈ L_K` commute and be independent over `K`.
1. **A finitely generated field.** The `c_i` have finitely many coefficients in `K` with respect to an
   `F_p`-basis of `L_(F_p)(1,2)`. Let `k_1` be the field they generate.
   - Then `c_i ∈ L_(k_1) ⊆ L_K`.
   - The `c_i` commute there, and they are independent over `k_1 ⊆ K`.
2. **A purely transcendental base.** Choose a transcendence basis `x_1, …, x_e` of `k_1 / F_p`, and put
   `k_0 = F_p(x_1, …, x_e)`. Then `[k_1 : k_0] = n < ∞`.
3. **Descending to `k_0`.** The regular representation `k_1 ↪ M_n(k_0)` induces a unital injective
   `k_0`-algebra map `L_(k_1) = L_(k_0) ⊗_(k_0) k_1 ↪ M_n(L_(k_0))`. The images of the `c_i` commute and are
   independent over `k_0`.
4. By Section 3, `Q_m(k_0)` holds.

**(d), third bullet.**
- If `Q_2(K)` holds for some field of characteristic 2, then `Q_2(F_2(x_1, …, x_e))` holds by the second bullet.
  Then (c) gives a polynomial ring in `e + 2` variables in `L_(F_2) ⊗ F_2[x_1, …, x_e]`.
- Conversely, such a polynomial ring gives `Q_2(F_2(x_1, …, x_s))` by (a). ∎(c,d)

## 5. Part (e)

Let `Y = lim_n Z^2 / Λ_n` be a factor of `Ω`, with `Λ_n` of finite index and decreasing. The cases of a point and
of a single finite orbit are the constant sequences.

1. **Pullback.** A factor map `π : Ω → Y` is surjective. So `f ↦ f ∘ π` is a unital equivariant injection
   `LC(Y) → LC(Ω)`.
   - It induces a unital injection `LC(Y) ⋊ Z^2 → LC(Ω) ⋊ Z^2 = ⊕_g LC(Ω) u_g`, since it acts coefficientwise.
   - Tensoring with `L_2` gives `H_Y ⊆ B_Ω ⊗ L_2`.
2. **Filtration.** Every clopen subset of the inverse limit is pulled back from some finite stage. So
   `LC(Y) ⋊ Z^2 = ⋃_n LC(Z^2 / Λ_n) ⋊ Z^2`.
3. **Imprimitivity.** Let `G = Z^2`, `Λ = Λ_n`, `N = [G : Λ]`, and choose a transversal `g_1, …, g_N`. Put
   `E_ij(λ) = δ_(g_i + Λ) u_(g_i − g_j + λ)`.
   - Then `E_ij(λ) E_kl(μ) = δ_jk E_il(λ + μ)`, because `δ_(g_i+Λ) δ_(g_i − g_j + g_k + Λ) ≠ 0` if and only if
     `k = j`.
   - Also `Σ_i E_ii(0) = 1`.
   - The `E_ij(λ)` are a relabelling of the basis `δ_c u_g`: given `c = g_i + Λ` and `g`, the index `j` and the
     element `λ` are determined by `g_i − g ∈ g_j + Λ`.
   - So `LC(G/Λ) ⋊ G ≅ M_N(F_2[Λ])`, and `Λ ≅ Z^2`.
4. **Applying (a).** A finitely generated subalgebra of `H_Y` lies in some `M_N(F_2[Λ]) ⊗ L_2 = M_N(L_2) ⊗ F_2[Λ]`.
   Apply (a) with `A = M_N(L_2)`, `R = F_2[Λ]`, `s = m = 2`. Then `M_N(L_K)` contains two commuting elements
   independent over `K = F_2(x, y)`. By Section 3, `Q_2(K)` holds.
5. **Mechanism (i).** `H_Y` contains the lattice units, and hence `F_2[Z^2] ⊗ L_2`.
   - Take a Laurent pair in a corner `e L_2 e`. Tensoring it with the lattice gives `F_2[Z^4]` in the corner
     `1 ⊗ e`.
   - The unital extension `φ + ε(·)(1 − 1 ⊗ e)` stays in `H_Y`. ∎(e)

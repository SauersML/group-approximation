Notation is that of the claim and of `infranormal-kernel-sources-die-in-sofic-mapping-tori`.
- `deg : G -> Z` is the quotient map, with `deg s = 1`.
- The intrinsic defect is the normal closure in `G` of the generators `[u c u^-1, l]`, over
  `u in Comp_G(L)`, `c in C_G(L)` and `l in L` (ICD1).
- Throughout, `D_G(L) = K`, and `K != 1`.

## Step 0: what is imported from the parent node

The parent node (its Steps 0--6) supplies these facts.
- **(B0) Bookkeeping.** For `h in G` of degree `d`: `h A_j h^-1 = A_(j+d)` and
  `h C_K(A_j) h^-1 = C_K(A_(j+d))`. Every `A_j` and every `C_K(A_j)` is normal in `K`.
- **(B1) Strict compressors.** Since `D_G(L) != 1`, a strict compressor exists. After replacing
  `s` by `s^-1`, every strict degree is positive. Non-strict compressors give trivial
  generators (IS1).
- **(B2) Monotonicity (P).** `A_(j+p) <= A_j` for all `j in Z` and `p in P`. Here `P` is the
  additive semigroup generated by the strict degrees, and `g = gcd P >= 2` (IS3, IS4).
- **(B3) Roots centralize shallow beads.** If `u` is strict of degree `m` and `c in C_G(L)`,
  then `x = u c u^-1` lies in `C_G(A_m)`, and `A_m < N`. This is the parent's Step 2, and it is
  the only place where soficity enters, through (IS0).
- **(B4) Centralizer bound (C).** Every nontrivial generator lies in `C_K(A_m)` for some
  `m in P`, and so `D_G(L) <= < C_K(A_j) : j in Z >`.

**Frobenius.** `P/g` is a numerical semigroup with gcd 1, so there is an `F` such that `ng in P`
for every `n >= F`. With (B2) this gives

```text
A_(j+ng) <= A_j      and      C_K(A_j) <= C_K(A_(j+ng))      for all j in Z, n >= F.     (F)
```

The second inclusion holds because a smaller subgroup has a larger centralizer.

**Finite products.** A product of finitely many normal subgroups of `K` is a normal subgroup.
So the subgroup generated by any family of normal subgroups of `K` is the directed union of
their finite products. `K` is Kazhdan, hence finitely generated. So if such a family generates
`K`, then finitely many of its members already multiply to `K`.

## Step 1: (NB1)

- *Generation by translates.* Each generator `[x,l] = (x l x^-1) l^-1` with `l in L` lies in
  `<<L>>^G`. So `K = D_G(L) <= <<L>>^G`. Also `<<L>>^G` is generated by the `G`-conjugates of
  `N = <<L>>^K`, which are the `A_j` by (B0). Hence `K = < A_j : j in Z >`.
- *One finite product.* By finite generation, `K = A_(i_1) A_(i_2) ... A_(i_r)` for some
  integers `i_1, ..., i_r`.
- *Lowering the indices.* For each residue `rho` mod `g`, put
  `T_rho = min { i_k : i_k = rho (mod g) } - Fg`, and `T_rho = rho` if no `i_k` lies in that
  class. Suppose `j_rho = rho (mod g)` and `j_rho <= T_rho`. Each `i_k` in the class of `rho`
  equals `j_rho + ng` with `n >= F`, so `A_(i_k) <= A_(j_rho)` by (F). A factor for a missing
  class only enlarges the product. So

  ```text
  K = A_(j_0) A_(j_1) ... A_(j_(g-1))     whenever j_rho = rho (mod g) and j_rho <= T_rho.
  ```

- *Raising the indices.* Conjugation by `s^(ng)` fixes `K` and sends `A_j` to `A_(j+ng)`, by
  (B0). So the display also holds whenever `j_rho <= T_rho + ng`, for every `n >= 0`. Every tuple
  with `j_rho = rho (mod g)` satisfies this for large `n`. This is (NB1).

Two special cases are used below.
- For `m in P` (so `m = 0 mod g`) and any `M`: `K = A_m B_M`.
- `A_m <= A_0 = N` by (B2). So `K = N B_M`.

## Step 2: (NB2)

- *Centralizers generate.* By (B4), `K = D_G(L) <= < C_K(A_j) : j in Z >`. Each `C_K(A_j)` is
  normal in `K`, so by finite generation `K = C_K(A_(i_1)) ... C_K(A_(i_r))`.
- *Raising the indices.* Now (F) says that centralizers grow as the index rises in a residue
  class. For each residue `rho`, put `S_rho = max { i_k : i_k = rho (mod g) } + Fg`, and
  `S_rho = rho` for a missing class. Then

  ```text
  K = C_K(A_(j_0)) C_K(A_(j_1)) ... C_K(A_(j_(g-1)))    whenever j_rho = rho (mod g), j_rho >= S_rho.
  ```

- *Lowering the indices.* Conjugation by `s^(-ng)` fixes `K` and sends `C_K(A_j)` to
  `C_K(A_(j-ng))`, by (B0). So the display holds for every tuple with `j_rho = rho (mod g)`.
- *Central core.* Take `j_rho = Jg + rho` and put `Z_J = A_(Jg) ∩ ... ∩ A_(Jg+g-1)`. Each factor
  `C_K(A_(Jg+rho))` centralizes `Z_J`, because `Z_J <= A_(Jg+rho)`. The factors multiply to `K`,
  so `K` centralizes `Z_J`, and `Z_J <= Z(K)`. This is (NB2).

## Step 3: (NB3)

Fix `M in Z`. Consider a defect generator `[u c u^-1, l]`.
- If `u` is not strict, the generator is trivial (B1).
- Otherwise `u` is strict of degree `m in P`. Put `x = u c u^-1`, so that `x in C_G(A_m)` by
  (B3).
- *Split.* By Step 1, `K = A_m B_M`, so `l = a e` with `a in A_m` and `e in B_M`. Here
  `a in A_m <= N` and `l in L <= N`, so `e = a^-1 l in N`. Hence `e in N ∩ B_M = E_M`.
- *Absorb.* `x` commutes with `a`, so

  ```text
  [x, l] = x a e x^-1 e^-1 a^-1 = a (x e x^-1 e^-1) a^-1 = a [x, e] a^-1.
  ```

- *Bound.* `a in K`, and `[x,e] = (x e x^-1) e^-1` lies in `<<E_M>>^G`. So every generator of
  `D_G(L)` lies in the normal subgroup `<<E_M>>^G` of `G`, and so does `D_G(L)`.

Therefore `K = D_G(L) <= <<E_M>>^G <= K`. Also `K = N B_M` by Step 1, so the second isomorphism
theorem gives `N/E_M = N/(N ∩ B_M) = N B_M / B_M = K/B_M`. This is (NB3).

## Step 4: (NB4)

Let `R` be the amenable radical of `K`, the union of all amenable normal subgroups of `K`.
- `R` is an amenable normal subgroup, because a product of two amenable normal subgroups is
  amenable (an extension of amenable groups) and a directed union of amenable groups is amenable.
- `R` is characteristic in `K`, and `K` is normal in `G`. So `R` is normal in `G`.
- `E_M = N ∩ B_M` is normal in `K`, since `N` and `B_M` are. So an amenable `E_M` lies in `R`.

Suppose `E_M <= R` for some `M`. By Step 3, `K = <<E_M>>^G <= R`, so `K` is amenable. An amenable
Kazhdan group is finite. Then `N` is finite, and a conjugate `A_m` of a finite group has the
same order, so `A_m < N` is impossible. This contradicts (B1). So `D_G(L) != K`.

The two cases:
- **Two beads.** If `g = 2`, then `B_0 = A_1` and `E_0 = A_0 ∩ A_1`. This is `Z_0` of Step 2, so
  it is central, hence abelian, hence amenable.
- **Commuting beads.** Suppose `[N, A_(Mg+rho)] <= Z(K)` for `1 <= rho <= g-1`.
  - For normal subgroups, `[X, YW] = [X, Y][X, W]`. So `[N, B_M] <= Z(K)`.
  - `E_M <= B_M` gives `[E_M, N] <= Z(K)`, and `E_M <= N` gives `[E_M, B_M] <= Z(K)`.
  - Since `K = N B_M` (Step 1), `[E_M, K] <= Z(K)`, that is `E_M <= Z_2(K)`.
  - `Z_2(K)` is nilpotent of class at most 2, hence amenable.
  - For normal subgroups `[N, A] <= N ∩ A`, so central pairwise intersections suffice.

## Step 5: the corollary

- The first two cases are (IS4) with the parent's Step 7, and (IS3).
- The third case is the two-bead case of Step 4.
- The fourth is Step 4 itself. A central `E_M` is abelian, and one with `[E_M, K] <= Z(K)` lies
  in `Z_2(K)`. Both are amenable and normal in `K`.

Nothing uses torsion-freeness, finite presentation or the absence of finite quotients. Soficity
enters only through (B3).

## Step 6: the calibration

Let `H` be an infinite Kazhdan group and `phi in Aut(H)`. Let `N_0` be normal in `H` with
`phi(N_0) < N_0`. Put `K = H x H x H`, `s(h_0,h_1,h_2) = (phi h_2, h_0, h_1)` and
`G = K semidirectProduct <s>`. Take any Kazhdan source `L`, infranormal in `K`, with
`<<L>>^K = N = N_0 x H x 1`, and assume `G` is sofic.

- *Translates.* `s^3 = phi x phi x phi`. Directly, `A_1 = 1 x N_0 x H`, `A_2 = H x 1 x N_0`
  and `A_(3k+rho) = phi^k (A_rho)` coordinatewise.
- *Strict degrees.* For `j = 1, 2 (mod 3)` the group `A_j` has a nontrivial coordinate where `N`
  has `1`, so `A_j` is not contained in `N`. A strict degree `m` has `A_m < N`, so `3 | m`. Hence
  `3 | g`. Assume from now on that some strict compressor has degree 3, for example `s^3` when
  `(phi x phi x phi)(L) <= L`. Then `g = 3`.
- *(NB1) and (NB2) hold.* `A_0 A_1 A_2 = H^3 = K`, and `A_0 ∩ A_1 ∩ A_2 = 1`, since the first
  coordinate is `N_0 ∩ 1 ∩ H`.
- *The central tests miss.* `N ∩ A_2 = N_0 x 1 x 1` and `[N, A_1] = 1 x [H, N_0] x 1`. The first
  is noncentral when `N_0` is noncentral in `H`, and the second when `N_0` is not in `Z_2(H)`.
  `E_M` below is non-amenable when `N_0` is.
- *(NB3) fails.* `B_M = A_(3M+1) A_(3M+2) = H x phi^M(N_0) x H`, so
  `E_M = N ∩ B_M = N_0 x phi^M(N_0) x 1`.
  - Put `H^+ = union_(k >= 0) phi^-k (N_0)`. Since `N_0 < phi^-1 (N_0)`, this is an increasing
    union.
    - `H^+` is normal in `H` and `phi`-invariant.
    - `H^+` contains `phi^k (N_0)` for every `k in Z`.
  - `(H^+)^3` is normal in `K` and `s`-invariant, so it is normal in `G`. It contains `E_M`, so
    it contains `<<E_M>>^G`.
  - `N_0 != H`, since `phi(H) = H`. So every `phi^-k (N_0)` is a proper normal subgroup of `H`.
    `H` is finitely generated, so the increasing union `H^+` is proper.
  - Hence `<<E_M>>^G <= (H^+)^3 < K`. By (NB3), `D_G(L) != K`.

So when `N_0` is non-amenable and not in `Z_2(H)`, (NB4) does not apply, but (NB3) still kills.
This does not come from the cruder bound `<<N>>^G`: that bound is
`< A_j : j in Z > = K`.

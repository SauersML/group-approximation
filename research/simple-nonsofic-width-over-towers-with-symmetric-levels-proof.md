Conventions as in `relator-width-over-towers-of-bounded-commutator-width-proof`. `C = 3(m! + m + 2)`.

## 1. Even permutations are commutators

- **One cycle.** Identify an `L`-cycle with `i -> i + 1` on `Z/L`. It equals `rho_1 rho_2` with
  `rho_1(i) = 1 - i`, `rho_2(i) = -i`, and also `rho_a rho_b` with `rho_a(i) = -i`, `rho_b(i) = -1 - i`. All four are
  involutions.
  - *`L` odd.* `rho_1` and `rho_2` each have `(L-1)/2` transpositions.
  - *`L` even.* `(rho_1, rho_2)` have `(L/2, L/2 - 1)` transpositions, and `(rho_a, rho_b)` have `(L/2 - 1, L/2)`.
- **Balancing.** An even permutation has an even number of even-length cycles. Use the first
  factorization on half of them and the second on the other half.
- **Assembly.** Taking products over the disjoint cycles gives `sigma = iota_1 iota_2`, with involutions
  `iota_1`, `iota_2` having the same number of transpositions. So `iota_2 = gamma iota_1 gamma^-1` for some
  `gamma in Sym(n)`, and `sigma = iota_1 gamma iota_1^-1 gamma^-1 = [iota_1, gamma]`.

## 2. Commutator width of admissible towers

Induct on depth; `W = H wr T`. By induction every element of `[H, H]` is a product of `c_H <= C`
commutators.

**Bounded levels.** `T` of degree `<= m`: Section 3 of `transitive-wreath-towers-bounded-commutator-width-proof`
gives `c_W <= m! + m - 1 + 2 ceil(c_H/3) <= C`.

**Symmetric levels.** `T = Sym(n)`, `n >= 2`. Let `x = (f; tau) in [W, W]`.
- *The top.* `tau in Alt(n)` is one commutator by Section 1, and `x = (f; 1)(1; tau)`.
- *The move.* Take `beta = (1 2 ... n)` and put `g_i = f_i` for `i != 1`, `g_1 = (f_n ... f_2)^-1`. The `beta`-cycle
  product `g_n ... g_2 g_1` is `1`, so `(g; 1)` is a commutator by the base lemma of
  `transitive-wreath-towers-bounded-commutator-width-proof`.
- *The defect.* `(f; 1) = (g; 1) (z at 1; 1)` with `z = f_n ... f_2 f_1 in [H, H]`.
- *Absorption.* Three-for-two absorption at the `beta`-adjacent coordinates `1, 2` writes `(z at 1; 1)` as
  `2 ceil(c_H/3)` commutators.
- *Total.* `c_W <= 2 + 2 ceil(c_H/3) <= 4 + 2C/3 <= C`, since `C >= 12`.

## 3. Relator width

Let `eps_0`, `N_0`, `k_1` be as in `simple-nonsofic-width-over-bounded-base-symmetric-wreath-proof`,
Section 0, and put `N_1 = max(m, N_0, ceil(12/eps_0) + 4)`. `Phi` is the free group on `X` of the variety
generated by `Sym(N_1)`. Put
```text
M = |Phi| + k_1 + N_1 + 2 ceil(2/eps_0) + 2 C N_1 .
```
We show by induction on depth that `a_x = A · P` with `A = prod_r r(a)^(n_(x,r))` and at most `M` pairs of
each relator in `P`, all conjugators having tops that fix the coordinates fixed by the root tuple.

**Small levels.** The root level is bounded, or it is symmetric with moved set of size `n' <= N_1`. Then
`<p>` lies in a copy of `Sym(N_1)`. The argument of Sections 1--5 of
`relator-width-over-towers-of-bounded-commutator-width-proof` applies verbatim with `Phi` for `Phi_m`, at
most `N_1` moving orbits, and commutator width `C` from Section 2. It uses at most
`|Phi| + (N_1 - 1) + 2 C N_1 <= M` pairs of each relator.

**Large symmetric levels.** `T = Sym(n)` and `n' = |Omega_0| > N_1`, where `Omega_0` is the moved set of `<p>`.
- **Top.** `top(A^-1 a_x) in Alt(Omega_0)`, since exponent sums fix the sign. A relator `r*` has
  `|supp r*(p)| >= eps_0 n'`. The balanced block `r*^(k_1) r*^(-k_1)`, with conjugators `(1; pi)`, `pi in Sym(Omega_0)`,
  covers `Alt(Omega_0)` (Rodgers, as in Section 2, Block B of the symmetric wreath proof). After reordering
  it is `k_1` pairs.
- **Base on `Omega_0`.** `Psi_0(f; q) = prod_(i in Omega_0) f_i mod [H, H]` is a homomorphism on the stabilizer of
  `Omega_0`, which contains every letter and every `a_x`. So the base error `e` on `Omega_0` has
  `Psi_0(e) = 0`.
  - *Dipoles.* A Hamiltonian path of `Omega_0` is realized in at most `2 ceil(2/eps_0)` rounds, placed by
    `Sym(Omega_0)`-conjugation (Block C of that proof). One pair per round.
  - *Defect.* The leftover `z in [H, H]` at one coordinate costs `C` nested commutators, `2C` pairs
    (Block D of that proof, with `cw` replaced by `C` from Section 2).
- **Fixed coordinates `Omega \ Omega_0`.**
  - *No effect there.* Every conjugator top lies in `Sym(Omega_0)` and fixes them. The pairs above have
    section `1` there.
  - *Recursion.* Left-multiplying conjugators by elements supported at such a coordinate `i` yields
    arbitrary pairs for the subtree tuple `a^(i)` without changing other coordinates. By induction `a^(i)_x`
    is realized with at most `M` pairs of each relator, inside the same pairs.
- **Count.** `k_1 + 2 ceil(2/eps_0) + 2C <= M` pairs of each relator.

So `w_W(a) <= sum_r |n_(x,r)| + 2|R| M` for every admissible tower. The bound depends on `G`, its
presentation and `m` only.

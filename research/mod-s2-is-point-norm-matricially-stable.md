**OPEN.** Let `M = Mod(S_2)`. For every sequence of maps `V_n : M -> U(d_n)` with `V_n(e) = I`
and `||V_n(m)V_n(m') - V_n(mm')||_op -> 0` for all fixed `m, m'`, there are unitary
representations `rho_n : M -> U(d_n)` with `||V_n(m) - rho_n(m)||_op -> 0` for every fixed `m`.

**Weaker form that suffices downstream.** For
`deligne-opnorm-sectors-empty-via-mod-s2-matricial-stability`, only the following is used. If
`V_n(t_s) -> omega I` for a separating twist `t_s` and a primitive cube root of unity `omega`, then there
are honest `rho_n : M -> U(d_n)` with `||V_n(t_s) - rho_n(t_s)||_op -> 0`.

## Evidence and calibration (not a proof)

- **The known cohomological obstruction is absent.** Dadarlat's almost-flat K-theory obstruction to
  matricial stability needs a nonzero class in even positive rational (co)homology.
  - `H_1(M;Z) = Z/10` and `H_2(M;Z) = Z/2`, both torsion
    (`genus-two-mapping-class-group-homology-and-symplectic-quotient`).
  - `H_k(M;Q) = 0` for `k >= 4`, by Harer's virtual cohomological dimension `4g - 5 = 3`. This is not
    pinned in the graph.

  So every even positive rational class vanishes. By contrast, `Sp_4(Z)` has `H^2(Sp_4(Z);R) != 0`,
  carried by the Maslov class, and it is matricially unstable through exactly those windings. Pulled
  back to `M` that class is a real coboundary (`mod-s2-real-untwisting-identifies-deligne-norm-parameters`, (U1)).
- **Necessary finiteness condition holds.** `M` is residually finite (Grossman), so its full
  C*-algebra is residually finite-dimensional. This is consistent with stability, and it is required
  for the combination "matricially stable and MF".
- **Why this is not automatic.** `M` contains `Z^2`, generated by two commuting twists, and
  `Z^2` is not matricially stable (Voiculescu's unitaries). Instability of a subgroup does not pass
  to the overgroup, but any proof must explain why Voiculescu pairs in `Z^2 < M` extend to exact
  representations of `M` only after a small perturbation. The class kill
  `deligne-flexible-subgroup-restrictions-carry-exact-sector-models` does not apply: this is a global
  statement about `M`, not an argument localized on a flexible subgroup of `Sp_4(Z)`.
- **How it can fail.** A single asymptotic homomorphism of `M` that stays far from representations
  refutes it. A natural test is a non-torsion even class on a finite-index subgroup of `M` that
  survives transfer to an almost-flat bundle over `M`. The graph has no such class.

  reach `M`; deferred.** The stable classes the graph knows

  over a finite subgroup, and the graph records none. The Birman--Hilden
  central extension `1 -> Z/2 -> M -> Mod(S_(0,6)) -> 1` moves the question to
  the spherical-braid quotient, which also contains `Z^2`, and that quotient
  is not known to be stable either. Where it dies: no permanence theorem covers
  a group containing `Z^2` with no splitting over finite groups. A direct attack
  must control Voiculescu-type pairs on commuting twists using the relations
  of `M` alone (lantern and chain relations), and that is not attempted here.
- **2026-09-18, swarm-0917-w10-w10-deligne-break (stability-approximation): winding obstructions are provably
  inert on `M`, including virtual ones.** See `mod-s2-quasirep-windings-vanish-on-fixed-window`, ESTABLISHED.
  - *Mechanism.* The determinant cochain `beta_pi` of any model with defect below `1` is an exact local cocycle, by
    Tr log applied to the defect identity. Since `H_2(M;R) = 0`, every 2-cycle `z` has a filling `u`, and so
    `<beta_pi, z> = <delta beta_pi, u> = 0` on a fixed, dimension-free window `W(z)`.
  - *Voiculescu pairs.* For commuting `a, b` (for example disjoint twists), every model with defect below `1` on
    `W_(a,b)` has `Tr log [pi(a),pi(b)] = 0`. This answers the winding half of the concern above about `Z^2 < M`.
  - *Virtual test dead.* `b_2(M[2]) = 26` (Birman--Hilden and Arnold; not pinned), so the node's suggested
    refutation test is well posed. But any quasi-representation of a finite-index `H` with a nonzero winding stays at
    distance at least `1/12` from every restriction of a `1/2`-model of `M` (W3). Inducing it to `M` cancels the total
    winding (W4).
  - *Where refutations must go.* Any refutation of this claim needs a torsion or non-cohomological invariant; winding
    or Chern arguments in degree two, the only positive even rational degree, cannot work. The positive direction
    stays open: the traceless part of the defects is untouched.

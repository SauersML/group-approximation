The standard facts used are the Pimsner--Voiculescu sequence, the six-term
exact sequence, continuity of K-theory under inductive limits, and the UCT
for the bootstrap class.  In particular, `C(X) rtimes Z` is in the bootstrap
class, and `KK(A,B) = Hom(K_*(A), K_*(B))` when `K_*(A)` is free.

**1.**  `Sigma_2 = lim_<- (T, z -> z^2)` is connected, so
`K^0(Sigma_2) = lim Z = Z`, generated by `[1]`, and
`K^1(Sigma_2) = lim (Z, x2) = Z[1/2]`.  The generator `alpha` acts as the
identity on `K^0` and as multiplication by `2^(+-1)` on `K^1`.
- On `K^0`, `1 - alpha_* = 0`, so both its kernel and its cokernel are `Z`.
- On `K^1 = Z[1/2]`, `1 - alpha_*` is multiplication by `-1` or by `1/2`.
  Both are invertible, so the kernel and the cokernel are `0`.

The PV sequence then gives the two extensions
- `0 -> coker_0 -> K_0(A) -> ker_1 -> 0`, which is `Z -> K_0(A) -> 0`;
- `0 -> coker_1 -> K_1(A) -> ker_0 -> 0`, which is `0 -> K_1(A) -> Z`.

The generator of `ker_0` is `[1]`, which lifts to `[u_t]`.  So
`K_0(A) = Z[1]` and `K_1(A) = Z[u_t]`.

**2.**  Take a unitary in `M_k(Q_omega)`.  It lifts to a sequence `(x_N)` in
`prod M_{kN}` with `||x_N* x_N - 1|| -> 0` along `omega`.  Polar parts give
unitaries `U_N`.  Write `U_N = exp(i H_N)` with `H_N` self-adjoint and
`||H_N|| <= pi`.  Then `t -> (exp(i t H_N))_N` is a norm-continuous path to
`1` in `U_k(Q_omega)`.  Hence `K_1(Q_omega) = 0`.

The extension `0 -> J_omega -> Q_omega -> R^omega -> 0` gives the exact
segment
`K_0(Q_omega) -> K_0(R^omega) -> K_1(J_omega) -> K_1(Q_omega) = 0`.
Since `R^omega` is a II_1 factor, `K_0(R^omega) = R` via the trace.  The
projections `1_{floor(rN)} + 0` in `M_N` map to `r` for every `r` in
`[0,1]`, so the first map is onto.  Hence `K_1(J_omega) = 0`.

**3.**  Let `E` be separable with `phi(A) + psi(A) subset E`, and set
`J_E = E cap J_omega`, a separable ideal of `E`.  Then
`(phi, psi) : A -> E -> M(J_E)` with `phi - psi` valued in `J_E` is a Cuntz
pair.  It defines `[phi, psi]` in `KK(A, J_E)`.  By the UCT and freeness of
`K_*(A)`, the class is determined by its action on `K_*(A)`.
- *On `[1]`.*  The image is `[phi(1)] - [psi(1)] = [1] - [1] = 0` in
  `K_0(J_E)`.
- *On `[u_t]`.*  The image is `[phi(u_t) psi(u_t)*]` in `K_1(J_E)`, a
  unitary in `1 + J_E`.

`J_omega` is the directed union of the `J_{E'}` over separable
`E' supset E`.  K-theory commutes with that inductive limit, and
`K_1(J_omega) = 0`.  So the class `[phi(u_t) psi(u_t)*]` dies in some
`K_1(J_{E_1})`.  Enlarging `E` to `E_1` changes the Cuntz pair only by
composing with the inclusion.  The class therefore maps to a homomorphism
`K_*(A) -> K_*(J_{E_1})` that vanishes on both generators, and so is `0` in
`KK(A, J_{E_1})`.

**4.**  For fixed `m != 0` and `N > |m|`, `tr_N(D_N^m) = 0`.  An
HS-asymptotic homomorphism satisfies
`f_N(a^(m/2^k)) ~ f_N(t)^(-k) D_N^m f_N(t)^k` in normalized HS norm.  So the
limit character `phi` vanishes on `a^q` for every `q != 0`.  By the corollary
in `bs1n-hs-stable-levit-vigdorovich`, `phi = delta_e`.

For the exact clock rep and for the census pairs, the `a`-matrix is exactly
`D_N`.  The census pairs are near-representations, so they are asymptotic
homomorphisms along any sequence where their defect tends to `0`.  Finally,
`tau_reg` is faithful on `C*_r(G) = C*(G)`, because `G` is amenable.  QED.

title: A degree-ten non-torsion algebraic unit has primitive divisors beyond an explicit bound
---

Let `u` be an algebraic unit that is not a root of unity, with
`[Q(u):Q]<=10`, contained in a number field `F`. For each integer

```text
n > B_* = 4000 * 40^12 = 67108864000000000000000,
```

there is a prime ideal `p` of `O_F` at which the reduction of `u` has
exact multiplicative order `n`.

This is a specialization of existing literature, not a new theorem claimed
by this project.

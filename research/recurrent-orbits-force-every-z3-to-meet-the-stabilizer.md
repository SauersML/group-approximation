**ESTABLISHED.** **Setting.** `G` is a group with a finite symmetric generating
multiset `S = (s_1, …, s_m)`, meaning that `G` is generated by the `s_i` and there is
an involution `σ` of `{1, …, m}` with `s_{σ(i)} = s_i^{-1}`. `G` acts on a set `X`, and
`x ∈ X`. The *Schreier network* `Sch(G·x, S)` has vertex set `G·x` and conductance
`c(y, y′) = #{i : s_i y = y′}` between `y ≠ y′`. This is symmetric, because
`s_i y = y′` iff `s_{σ(i)} y′ = y`. Its network random walk is the walk
`Y_{n+1} = s Y_n` with `s` uniform in `S`, with the loop steps `s y = y` deleted, which
only delay the walk. The orbit `G·x` is *recurrent for `S`* if this walk is recurrent.

**Statement.**
1. **(Independence and heredity.)** Let `K ≤ G` be generated by a finite symmetric
   multiset `T`. If `K·x` is transient for `T`, then `G·x` is transient for `S`. In
   particular, recurrence of `G·x` does not depend on `S`. And if `G·x` is recurrent,
   every finitely generated subgroup of `G` acts recurrently on the orbit of `x`.
2. **(Rank-three test.)** If `G·x` is recurrent and `A ≤ G` with `A ≅ Z^3`, then
   `A ∩ G_y ≠ 1` for every `y ∈ G·x`.

**Remark (not used).** The same argument shows that every finitely generated
`K ≤ G` whose Cayley graph is transient meets `G_y` nontrivially. Only `Z^3`, via
Pólya, is used downstream.

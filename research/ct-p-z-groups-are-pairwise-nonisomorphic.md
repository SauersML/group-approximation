## Statement

Kourovka 17.60 (S. Kohl): for a set `P` of odd primes, let `CT_P(Z)` be the group
generated by the class transpositions whose moduli have all prime factors in
`P' = P ∪ {2}`. These groups are simple (Kohl). Are they pairwise non-isomorphic?

**Answer: yes.** If `CT_P(Z) ≅ CT_Q(Z)` as abstract groups, then `P = Q`. This holds
for arbitrary (finite or infinite) sets `P, Q` of odd primes.

The proof extracts `P'` from the abstract group. At a point with nontrivial germ
group, the "prime axes" are recovered as minimal stable sets. Each axis is labeled by
the unique prime `ℓ` for which a minimal component of an induced compact rotation has
infinitely many continuous eigenvalues of `ℓ`-power order.

## Setup

- **Spaces and box maps.**
  - `X_P = ∏_{p ∈ P'} Z_p`, a Cantor set. `Z` embeds diagonally and densely.
  - A *box* is `B(r, m) = r + mX_P`, with `m` a positive `P'`-smooth integer and
    `0 ≤ r < m`. Boxes form a basis of clopen sets, and `B(r, m) ∩ Z = r(m)`.
  - The *canonical box map* `κ : B(r', m') → B(r, m)` is `κ(x) = r + (m/m')(x − r')`.
    On `Z` it sends `r' + tm'` to `r + tm`.
- **The groupoid.** `G_P` is the groupoid of germs of box maps. It is étale and
  effective (a box map fixing an open set pointwise is the identity). So it is
  essentially principal in Matui's sense, with Cantor unit space `X_P`. It is
  minimal, since box maps take any box onto any other.
- **`F_P := [[G_P]] ≅ CT_P(Z)`.** An element of `[[G_P]]` is a homeomorphism of `X_P`
  that is, on a finite partition into boxes, a canonical box map on each piece. A box
  map restricted to a sub-box is again canonical: `B(r'', m'') ⊆ B(r', m')` goes
  canonically onto `B(r + (m/m')(r'' − r'), mm''/m')`, and `m''/m'` is a `P'`-smooth
  integer.
  - Such an element preserves `Z`, and restricting to `Z` is injective because `Z` is
    dense.
  - The restriction is a piecewise-canonical permutation with `P_0'`-smooth moduli for
    a finite `P_0 ⊆ P`. By item 3 of the parent node it lies in
    `CT_{P_0}(Z) ⊆ CT_P(Z)`.
  - Conversely, class transpositions are elements of `[[G_P]]`.
  - So restriction to `Z` is an isomorphism `F_P → CT_P(Z)`. For finite `P`, `G_P` is
    the groupoid `G_Λ` of the parent node.

## Step 1: an isomorphism is spatial

By Matui's Proposition `tfg=F`, `F_P` is of class F: `G_P` is essentially principal,
étale and minimal, with Cantor unit space, and `F_P ⊇ D(F_P)`.

By Theorem `spatial`, an isomorphism `Φ : F_P → F_Q` has the form
`Φ(α) = φ α φ^{-1}` for a homeomorphism `φ : X_P → X_Q`.

## Step 2: germ groups

For `y ∈ X_P`, let `𝒢_y(P)` be the group of germs at `y` of elements `α ∈ F_P` with
`α(y) = y`. Conjugation by `φ` carries `𝒢_y(P)` isomorphically onto `𝒢_{φ(y)}(Q)`,
and it conjugates the germ actions near `y` and `φ(y)`.

Near `y`, an `α ∈ F_P` fixing `y` is one box map `κ` fixing `y`. In the local
coordinate `u = x − y`, `κ` is `u ↦ γu` with `γ = m/m'`. Conversely, every germ of a
box map fixing `y` is a germ of an element of `D(F_P) ⊆ F_P`, by Matui's lemma (orbits
are infinite).

Write `T_m(x) = (x − r)/m`, where `r ≡ x mod m` and `0 ≤ r < m`. Then

    𝒢_y(P) ≅ Γ_y := {m/m' : T_m(y) = T_{m'}(y)},

a subgroup of the group `Γ_P` of positive `P'`-smooth rationals, acting by
`u ↦ γu`.

- **Irrational points.** If `y ∉ Q`, then `T_m(y) = T_{m'}(y)` forces
  `y(m' − m) = m'r − mr'`, so `m = m'` and `Γ_y = 1`.
- **Rational points.** If `y = c/b ∈ X_P ∩ Q` (so `b` is prime to `P'`), then for each
  `p ∈ P'` some `p^t` with `t ≥ 1` lies in `Γ_y`.
  - `T_p(c/b) = c'/b` with `c' = (c − rb)/p ∈ Z` and `|c'| ≤ |c|/p + b`. So the
    `T_p`-orbit of `y` enters the finite set `{c/b : |c| ≤ 2b}` and is eventually
    periodic: `T_p^{n+t}(y) = T_p^n(y)`.
  - Since `T_{p^n} = T_p^n`, this gives `p^t = p^{n+t}/p^n ∈ Γ_y`.
- **Example.** `Γ_0 = Γ_P`, since `T_m(0) = 0` for all `m`.

So the points with nontrivial germ group are exactly the rationals in `X_P`, and `φ`
maps them to the rationals in `X_Q`.

## Step 3: prime axes are intrinsic

Fix a rational `y`. For a germ `g ∈ 𝒢_y(P)` with representative defined on a small box
`V ∋ y`, let `W_V(g) = {x ∈ V : g^n(x) ∈ V for all n ≥ 0, and g^n(x) → y}`. For
`g = (u ↦ γu)` and all sufficiently small `V`,

    W_V(γ) = y + {u ∈ V − y : u_p = 0 for every p with v_p(γ) ≤ 0}.

The reason is coordinatewise:
- where `v_p(γ) > 0` the coordinate contracts;
- where `v_p(γ) = 0` it is isometric and does not converge;
- where `v_p(γ) < 0` it leaves `V`.

Conjugation by `φ` carries `W_V(g)` onto `W_{φ(V)}(φgφ^{-1})`, so the germs at `y` of
these sets, with germ-inclusion, are invariants.

- **Atoms.** The minimal germs strictly larger than `{y}` are the axes
  `A_q = y + {u : u_p = 0 for all p ≠ q}`, one for each `q ∈ P'`. Each occurs, because
  `q^t ∈ Γ_y`, and every nontrivial `W(γ)` contains one.
- **Consequence.** `φ` induces a bijection from the axes at `y` to those at `φ(y)`. In
  particular `|P'| = |Q'|`, which recovers the earlier partial result.
- **Neutral subgroup.** Let `H_q = {g ∈ 𝒢_y : neither W(g) nor W(g^{-1}) contains A_q}`.
  Then `H_q = {γ ∈ Γ_y : v_q(γ) = 0}`, and it is intrinsic.
- **Shells.** Every `γ ∈ Γ_y` preserves `A_q`. Pick `g_1 ∈ Γ_y` with
  `c = v_q(g_1) > 0`. The quotient of `A_q ∩ V ∖ {y}` by `u ~ g_1 u` is intrinsic up to
  `H_q`-equivariant homeomorphism.
  - It is the union of `c` shells `y + q^j Z_q^×` (in the `q`-axis), one for each
    `j` in a range of length `c`.
  - `H_q` acts on each shell by multiplication through `ρ : H_q → Z_q^×`, `γ ↦ γ`.

## Step 4: each axis remembers its prime

Suppose `|P'| ≥ 2`. Pick `p ∈ P' ∖ {q}` and `t ≥ 1` with `p^t ∈ Γ_y`. Then
`p^t ∈ H_q`, and `ρ(p^t) = p^t` has infinite order in `Z_q^×`.

- **The closure is open.** `K := closure of ρ(H_q)` is an infinite closed subgroup of
  `Z_q^× ≅ (finite) × Z_q`, so `K ⊇ 1 + q^a Z_q` for some `a`. Indeed
  `K ∩ (1 + q^2 Z_q)` is an infinite closed subgroup of `1 + q^2 Z_q ≅ Z_q`, hence
  equal to `1 + q^a Z_q`.
- **The minimal components.** The minimal closed `H_q`-invariant subsets of the shell
  quotient are the cosets `xK`. Each is the rotation of `K` by the dense subgroup
  `ρ(H_q)`.
- **Eigenvalues.** For a minimal rotation of a compact abelian group by a dense
  subgroup, the continuous eigenfunctions are scalar multiples of characters. So the
  group of continuous eigenvalues is `E_q = {χ ∘ ρ : χ ∈ K^} ≅ K^`.
  - The standard proof: `|f|` is invariant, hence constant. Then
    `f(kz) = χ(k) f(z)` with `χ(k) = f(k)/f(1)` continuous and multiplicative.
  - A conjugacy that intertwines the actions through an isomorphism `H_q → H'` carries
    eigenvalue groups to eigenvalue groups. So `E_q` is an isomorphism invariant.
- **The primary parts.** `K^` is a torsion group. Restriction `K^ → (1 + q^a Z_q)^ ≅ Q_q/Z_q`
  is onto, so the `q`-primary part of `E_q` is infinite. For a prime `ℓ ≠ q`, an
  element of `ℓ`-power order restricts to `0` in the `q`-primary group `Q_q/Z_q`. So it
  lies in the finite kernel `(K/(1 + q^a Z_q))^`, and the `ℓ`-primary part is finite.

So `q` is the unique prime `ℓ` for which `E_q` has infinitely many elements of
`ℓ`-power order. This labels each axis intrinsically by its prime.

## Conclusion

Let `Φ : CT_P(Z) ≅ CT_Q(Z)`. By Step 1, `Φ` is spatial via some `φ`. Take `y = 0`. By
Step 2, `φ(0)` is a rational point of `X_Q`, and `φ` conjugates the germ groups. By
Step 3, `φ` maps the axes at `0` bijectively onto the axes at `φ(0)`. If `|P'| = 1`,
then `|Q'| = 1`, so `P = Q = ∅`. Otherwise, by Step 4, corresponding axes carry the
same prime. So `P' = Q'`, and `P = Q`, since `P` and `Q` consist of odd primes.

## Remarks

- For infinite `P`, the same proof applies verbatim. Only finitely many coordinates
  are constrained by any box.
- The invariant is local. The germ group at any rational point, with its axes and
  shell rotations, already determines `P`.

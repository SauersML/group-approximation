Notation as in the target. All rings are `F_2`-algebras, so `-1 = 1`. The commutator is
`[x, y] = x y x^-1 y^-1`. For unitaries `u, v, w` in `M_d(C)`, with normalized Hilbert--Schmidt
norm,

```text
||uv - 1||_2 <= ||u - 1||_2 + ||v - 1||_2,      ||w u w* - 1||_2 = ||u - 1||_2 = ||u^-1 - 1||_2.   (U)
```

## Step 0. The shadow homomorphism

Let `(phi_+, phi_-)` be a ring shadow over the finite ring `B`. The maps `St_20(phi_+-)` agree on
`Delta_0 = St_20(F_2 1 + F_2 q)`, because `phi_+` and `phi_-` agree there. So by the universal
property of the amalgam they define `Phi : Gamma -> St_20(B)`. Write

```text
S_j = phi_+(s_j),   T_i = phi_-(t_i),   Q = phi_+(q) = phi_-(q).
```

## Step 1. Six defect elements of K

For `i, j in {1, 2}` put

```text
g_ij = [x_12(t_i), x_23(s_j)] * x_13(delta_ij)^-1,
g_1  = [x_12(s_1), x_23(t_1)] * x_13(q)^-1,
g_2  = [x_12(s_2), x_23(t_2)] * x_13(1 + q)^-1.
```

- *These are words in Gamma.* Every letter lies in a half:
  - `x_12(t_i)` lies in `Delta_-`, and `x_23(s_j)` lies in `Delta_+`;
  - `x_13(0) = 1`, and `x_13(1)`, `x_13(q)` and `x_13(1 + q)` lie in `Delta_0`.
- *They lie in K.* In `Delta = St_20(R)` the relation `[x_12(a), x_23(b)] = x_13(ab)` holds, and the
  Leavitt relations are `t_i s_j = delta_ij`, `s_1 t_1 = q` and `s_2 t_2 = 1 + q`. So each of the six
  maps to 1.
- *Their shadow images are root elements.* The same Steinberg relation holds in `St_20(B)`. So
  `Phi(g_d) = x_13(d)` for the six defects

```text
d in  { T_i S_j + delta_ij (i, j = 1, 2),   S_1 T_1 + Q,   S_2 T_2 + 1 + Q }.          (D6)
```

Since `K` is the normal closure of `k_1, ..., k_r`, each `g_d` is a fixed product of `L_d`
conjugates of the `k_i^(+-1)`. This expression does not depend on `B` or `pi`. By `(U)`, for
`rho = pi o Phi`,

```text
||pi(x_13(d)) - 1||_2 = ||rho(g_d) - 1||_2 <= L_d * delta,   delta = max_i ||rho(k_i) - 1||_2.   (1)
```

## Step 2. The defects generate B

Let `D` be the two-sided ideal of `B` generated by the six elements `(D6)`. In `B/D` the images of
`S_j`, `T_i` and `Q` satisfy `T_i S_j = delta_ij`, `S_1 T_1 = Q` and `S_2 T_2 = 1 + Q`. Hence
`S_1 T_1 + S_2 T_2 = 1`, and `s_j -> S_j`, `t_i -> T_i` defines a unital ring map `R -> B/D`.

**Lemma 2.1.** *A finite ring `A` that receives a unital map from `R` is zero.*

*Proof.* Write `S_j, T_i` for the images.
- Since `T_1 S_1 = 1`, left multiplication by `S_1` is injective on the finite set `A`, hence
  bijective. So `S_1 y = 1` for some `y`, and `T_1 = T_1 S_1 y = y`. Thus `S_1 T_1 = 1`.
- Then `S_2 T_2 = 1 + S_1 T_1 = 0`.
- So `1 = (T_2 S_2)(T_2 S_2) = T_2 (S_2 T_2) S_2 = 0`. ∎

So `D = B`. Now write `B = prod_j B_j` with each `B_j` simple, and let `e_j` be the component of
`e` in `B_j`. Put `supp(e) = {j : e_j != 0}`. If all six defects had zero component in `B_j`, then
`D` would lie in the kernel of `B -> B_j`. Hence

```text
every block j lies in supp(d) for at least one defect d.                          (2)
```

## Step 3. The row group and its character measure

From here on `B` is semisimple. By Wedderburn, and because finite division rings are fields,
`B = prod_j M_(n_j)(F_(q_j))` with each `q_j` a power of 2. Put `V_j = F_(q_j)^(n_j)`.

**The row group.** Let `U = { x_1k(a_k) : 2 <= k <= 19 }` inside `St_20(B)`.
- It is abelian: `x_1k` and `x_1l` commute for `k != l`, since neither index is 1 as a column.
- The root maps are additive. So `U` is a quotient of `B^18`. It maps isomorphically onto its image
  in `E_20(B)`, so `U = B^18` as written, `a = (a_2, ..., a_19)`.

**Characters.** The characters of `(B^18, +)` are

```text
psi_c(a) = (-1)^(sum_j Tr_j tr( sum_k a_(k,j) c_(k,j) )),       c = (c_(k,j)),  c_(k,j) in M_(n_j)(F_(q_j)),
```

where `Tr_j = Tr_(F_(q_j)/F_2)`. The trace pairing is nondegenerate. For each `j`, stack the
`c_(k,j)` into one matrix `c_j` in `M_(18 n_j x n_j)(F_(q_j))`.

**Spectral measure.** Let `pi` act on `C^N`. Then `pi|U` splits into isotypic subspaces `H_c`. Put
`mu(c) = dim H_c / N`, a probability measure. Since `pi(x_13(e))` acts on `H_c` by
`psi_c(x_13(e)) in {+-1}`,

```text
m(e) := ||pi(x_13(e)) - 1||_2^2 / 4 = mu{ c : psi_c(x_13(e)) = -1 }.                 (3)
```

If `g` normalizes `U` with `g x g^-1 = alpha(x)`, then `pi(g) H_c = H_(c o alpha^-1)`. So `mu` is
invariant under the dual action. Two families of such `g` are used.

1. **Left action.** Take `g` in the copy of `St_18(B)` on the indices `2..19`.
   - The relation `[x_1k(a), x_kl(b)] = x_1l(ab)` shows that conjugation by `x_kl(b)` acts on `U` as
     the right multiplication `a -> a (1 + b e_kl)`.
   - Dually this is `c_j -> g_j c_j`, where `g_j` runs over the group generated by the block
     elementary matrices. That group is `SL_(18 n_j)(F_(q_j))`: transvections inside one diagonal
     block are commutators of transvections through another block.
2. **Right action.** For a unit `u = (u_j)` of `B`, take the Whitehead element
   `h = w_(1,20)(u) w_(1,20)(1)`, where `w_(1,20)(u) = x_(1,20)(u) x_(20,1)(u^-1) x_(1,20)(u)`.
   - The standard Steinberg-group identities (Milnor, *Introduction to algebraic K-theory*, §9) give
     `h x_1k(a) h^-1 = x_1k(u a)` for `2 <= k <= 19`.
   - Since `tr(u a c) = tr(a c u)`, dually this is `c_j -> c_j u_j`, with `u_j` running over
     `GL_(n_j)(F_(q_j))`.

**Orbit structure.** Put `K_j(c) = ker(c_j)`, a subspace of `V_j`, and `K(c) = (K_j(c))_j`.

- *Left orbits.* `SL_(18 n_j)` acts transitively on `{ c_j : ker c_j = K_j }`.
  - Such `c_j` are the maps `c~_j o p`, where `p : V_j -> V_j / K_j` is the quotient and `c~_j` is
    injective into `F^(18 n_j)`.
  - Two injective maps differ by an element of `GL_(18 n_j)`. That element can be chosen of
    determinant 1, because the image has dimension at most `n_j < 18 n_j`.
  - So, conditioned on `K(c) = K`, `mu` is uniform on `S_K = prod_j { c_j : ker c_j = K_j }`. The
    blocks are independent, and each `c~_j` is uniform among injective maps.
- *Right orbits.* `c_j -> c_j u_j` sends `ker c_j` to `u_j^-1 ker c_j`.
  - So the law `nu` of `K(c)` is invariant under `prod_j GL(V_j)`.
  - That group is transitive on each set `prod_j Gr(k_j, V_j)` of fixed dimension profile
    `k = (k_j)`. So, conditioned on `k`, `K` is uniform on that product of Grassmannians.

## Step 4. One character against one root element

For `e in B`, `psi_c(x_13(e)) = (-1)^(l_e(c))` with `l_e(c) = sum_j Tr_j tr(c_(3,j) e_j)`. Here
`c_(3,j) = c~_(3,j) o p`, where `c~_(3,j)` is the third `n_j`-row block of `c~_j`. Put

```text
I_K = { e in B : im(e_j) ⊆ K_j for every j },        N(e) = nu{ K : e not in I_K }.
```

**Lemma 4.1.** *Let `eta = 2^-17`. Conditioned on `K(c) = K`:*
- *if `e in I_K`, then `psi_c(x_13(e)) = 1` surely;*
- *if `e not in I_K`, then `P(psi_c(x_13(e)) = -1)` lies in `[1/2 - eta, 1/2 + eta]`.*

*Proof.*
- *Case `e in I_K`.* Then `c_(3,j) e_j = c~_(3,j) p e_j = 0` for every `j`, so `l_e(c) = 0`.
- *Case `e not in I_K`.* Fix `j0` with `im(e_j0) ⊄ K_j0`, and condition on all blocks `j != j0`.
  Then `l_e = lambda(c~_(3,j0)) + const`, where `lambda(Y) = Tr_j0 tr(Y e-bar)` and
  `e-bar = p o e_j0 : V_j0 -> V_j0/K_j0` is nonzero.
  - *`lambda` is a nonzero `F_2`-linear functional.* The trace pairing
    `Hom(V/K, V) x Hom(V, V/K) -> F_q` is nondegenerate, so `Y -> tr(Y e-bar)` is a nonzero
    `F_q`-linear functional. Composing with the surjective `Tr_j0` keeps it nonzero.
  - *Uniform comparison.* Let `d = dim V_j0/K_j0 <= n = n_j0` and `M = 18n`. Let `Y` be a uniform
    element of `Hom(F^d, F^M)`. Its third block is then uniform in the `F_2`-space
    `Hom(F^d, F^n)`, so `lambda` of it is uniform on `F_2`.
  - *Injectivity costs at most eta.* The event `E = {Y injective}` has
    `P(E^c) <= sum_(i<d) q^(i-M) <= q^(d-M) <= 2^(-17n) <= eta`.
  - `c~_j0` has the law of `Y` conditioned on `E`. For every event `A`,
    `|P(A | E) - P(A)| <= P(E^c)`. ∎

Averaging Lemma 4.1 over `K` with `(3)` gives

```text
(1/2 - eta) N(e)  <=  m(e)  <=  (1/2 + eta) N(e).                                   (4)
```

## Step 5. The Grassmannian comparison

Fix a dimension profile `k = (k_j)`, and let `F(k) = { j : k_j < n_j }`. Let `P_k` be the
conditional law of `K`, which by Step 3 is uniform on `prod_j Gr(k_j, V_j)`.

**Lemma 5.1.**
- *If `supp(e) ∩ F(k)` is empty, then `P_k(e not in I_K) = 0`.*
- *Otherwise `P_k(e not in I_K) >= 1/2`.*

*Proof.*
- *First case.* For `j` in `supp(e)`, `K_j = V_j`. For `j` outside `supp(e)`, `e_j = 0`.
- *Second case.* Take `j` in `supp(e) ∩ F(k)` and a nonzero `v in im(e_j)`. Then
  `P(v in K_j) = (q^(k_j) - 1)/(q^(n_j) - 1) < 1/q <= 1/2`. ∎

**The comparison.** Let `Q` be the shadow of the head.
- If `supp(Q) ∩ F(k)` is nonempty, pick `j` in it. By `(2)` some defect `d` has `j in supp(d)`, so
  `P_k(d not in I_K) >= 1/2` by Lemma 5.1.
- Hence, for every `k`,

  ```text
  P_k(Q not in I_K)  <=  1[ supp(Q) ∩ F(k) nonempty ]  <=  2 * sum_d P_k(d not in I_K).
  ```

- Averaging over `k` gives `N(Q) <= 2 * sum_d N(d)`.
- With `(4)`:

  ```text
  m(Q) <= (1/2 + eta) N(Q) <= (1 + 2 eta) sum_d N(d) <= (1 + 2 eta)/(1/2 - eta) * sum_d m(d) <= 3 sum_d m(d).
  ```

## Step 6. Conclusion

Here `Phi(z) = x_13(Q)`. By `(3)`, `(1)`, and because there are six defects,

```text
||rho(z) - 1||_2^2 = 4 m(Q) <= 12 sum_d m(d) = 3 sum_d ||rho(g_d) - 1||_2^2 <= 18 (max_d L_d)^2 delta^2.
```

So `(RS)` holds with `L = sqrt(18) * max_d L_d`. `L` depends only on the relators `k_i` and on the
six fixed expressions of the `g_d`, not on `B`, `pi` or the dimension. ∎

## Where the argument stops

- **Radical shadows.** Step 3 uses semisimplicity twice:
  - the characters are read through `ker c_j`, a subspace;
  - the right action of the units is transitive on subspaces of each dimension.

  Over `F_2[eps]/(eps^2)`, for example, the units fix the radical line, and `psi_c(x_13(eps x))` is
  not controlled by any kernel datum. Steps 0 to 2 hold for every finite `B`.
- **Non-ring gluings.** The route needs one ring `B` and one representation of `St_20(B)`. A genuine
  representation of `Gamma` whose halves factor through different finite quotients, glued by an
  intertwiner on `Delta_0` that no common ring induces, has no row group on which both halves act.
  Steps 1 and 2 have no analogue there.

Notation as in the target. The definitions of `full` and `alt` and the facts about `F` are item 4, and
items 1, 2, 3 and 5, of `nekrashevych-golden-mean-fragmentation-group-properties`.

**Step 1 (disjoint translates).** Let `x ∈ X` with `|Hx| ≥ n`. Choose `g_1 = 1, g_2, ..., g_n ∈ H` with the
points `g_i x` pairwise distinct. `X` is Hausdorff, so there are pairwise disjoint open sets `W_i ∋ g_i x`.
The set `⋂_i g_i^{-1}(W_i)` is an open neighbourhood of `x`, because each `g_i` is continuous. `X` has a
basis of clopen sets, so it contains a nonempty clopen `U ∋ x`. Then `g_i(U) ⊆ W_i`, so the sets `g_i(U)`
are pairwise disjoint.

**Step 2 (proof of (A)).** By the imported definition, `α -> h_α` is a monomorphism `Sym_n -> full(H,X)`,
and it maps `Alt_n` into `alt(H,X)`. If `sup_x |Hx| = ∞`, Step 1 applies for every `n`.

Every finite group `K` embeds in `Sym_{|K|}`, by Cayley. Then `Sym_m` embeds in `Alt_{m+2}` via
`σ -> σ·τ^{sign σ}`, where `τ` is the transposition of the two new points. So `alt(H,X)` contains every
finite group. For each odd prime `p`, the `p`-cycle in `Alt_p` has order `p`, so the exponent is unbounded.

**Step 3 (proof of (B)).** Let `H = <s_1, ..., s_k>` act faithfully, with every orbit of size at most `M`.
- For each orbit `O`, the action on `O` gives a homomorphism `ρ_O : F_k -> Sym(O)`, where `F_k` is free on
  the `s_i`.
- Up to a bijection `O ≅ {1, ..., |O|}`, `ρ_O` is one of the finitely many homomorphisms
  `F_k -> Sym_m` with `m ≤ M`.
- So `K = ⋂_O ker ρ_O` is an intersection of finitely many finite-index subgroups of `F_k`, and so it
  has finite index.
- Faithfulness means that the kernel of `F_k -> H` equals `K`.

So `H ≅ F_k / K` is finite.

**Step 4 (proof of (C)).** Suppose some `H`-orbit has `n ≥ N+2` points. Step 1 and Step 2 then give
`Alt_n ≤ alt(H,X) ≤ E`. `Alt_n` contains an `n`-cycle if `n` is odd and an `(n-1)`-cycle if `n` is even,
so it has an element of order at least `n-1 > N`. This contradicts exponent `N`. So every `H`-orbit has at
most `N+1` points.

The two bullets follow:
- By definition `alt(E,X) ≤ full(E,X)`. So if `E = full(E,X)`, then `E` has bounded orbits, and Step 3
  makes the finitely generated faithful `E` finite.
- If `alt(H,X) ≤ E` with `H` infinite, finitely generated and faithful, then `H` has bounded orbits, which
  contradicts Step 3.

**Step 5 (proof of (D)).** `F` is finitely generated and acts faithfully, since it is a group of
homeomorphisms. It is infinite, since it has intermediate growth (item 1). By Step 3, `sup_x |Fx| = ∞`. By
item 1, `F = full(F,X)`. So `alt(F,X) ≤ F`, and Step 2 gives `Alt_n ≤ F` for every `n`.

`Alt_n` is generated by its 3-cycles. A 3-cycle `h ∈ F` has odd order, and `F/[F,F]` is an elementary
abelian 2-group (item 2), so the image of `h` there is trivial and `h ∈ [F,F]`. Hence `Alt_n ≤ [F,F]`.

**Step 6 (proof of (E)).**
- Let `E = <e_1, ..., e_k> ≤ F`, with each `e_i` of length at most `C` in the generators of `F`. The
  `r`-ball of `E` then lies in the `Cr`-ball of `F`. So the growth function of `E` is at most that of `F`
  at `Cr`, and it is subexponential (item 1).
- Finitely generated groups of subexponential growth are amenable: some sequence of balls is Følner.
- The sentence about the literature is item 5.
- For a general fragmentation of a minimal dihedral action, amenability of all subgroups is item 3.

Nothing here decides whether an infinite amenable bounded-exponent group exists.

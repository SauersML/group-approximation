claimed).

## Statement

Let `P` be a finite set of odd primes, `P' = P ∪ {2}`, and `N_0 = {0, 1, 2, ...}`. By item 3 of
`ct-p-z-is-a-one-vertex-k-graph-full-group`, `CT_P(Z)` is the group of permutations `g` of `Z` for which
there are partitions of `Z` into residue classes `r_i(m_i)` and `s_i(n_i)` with `P'`-smooth moduli,
`0 <= r_i < m_i`, `0 <= s_i < n_i`, and `g(r_i + t m_i) = s_i + t n_i` for all `t ∈ Z`. Then:

1. `CT_P(Z)` preserves `N_0` and acts on it faithfully;
2. the action on `N_0` is highly transitive;
3. `Stab(0)` is generated by a copy of `CT_P(Z)` and `|P'|` elements `c_q` (`q ∈ P'`), so it is finitely
   generated, and so is every point stabilizer;
4. hence the action of `CT_P(Z)` on `N_0` is of type (A), in the sense of
   `type-a-action-gives-boone-higman-for-subgroups`.

**Consequences.**
- The twisted Brin–Thompson group `SV_{CT_P(Z)}` of this action is finitely presented and simple
  (`twisted-brin-thompson-finite-presentation-criterion`).
- `CT_P(Z)` admits a type (A) action, a positive instance of Zaremsky's Question 5.13(i) (arXiv:2405.18354,
  `quest:BHC_PBHC`), "Does every finitely presented simple group admit an action of type (A)?".
- It is a new row for the BFFHZ Question 3.4 census.

## Proof

1. **Invariance and faithfulness.** A piece `r + tm ↦ s + tn` with `0 <= r < m` and `0 <= s < n` sends
   `r + tm >= 0` (that is, `t >= 0`) to `s + tn >= 0`, and negative to negative. So `N_0` is invariant.
   If `g` is the identity on `N_0`, each affine piece is the identity at infinitely many points `t >= 0`, so it
   is the identity map, and `g = 1`.
2. **High transitivity.** Let `a_1, ..., a_k` and `b_1, ..., b_k` be two tuples of distinct elements of `N_0`,
   and pick `M = 2^e` larger than all of them.
   - Send the class `a_i(M)` to `b_i(M)` by `a_i + tM ↦ b_i + tM`.
   - The remaining `M - k` classes on each side are matched bijectively, again by canonical maps.
   - This is a permutation `g` of the form above, and `g(a_i) = b_i`.
3. **Point stabilizers.**
   - **Germ slope.** If `g(0) = 0`, the piece containing `0` is `0(m) ↦ 0(n)`, acting as `x ↦ λx` with
     `λ = n/m` in the group `Λ_P ⊂ Q_{>0}^×` generated by `P'`. Call `λ` the germ slope of `g` at `0`; it is
     multiplicative. For `m` even let `K_m = {g : g = id on 0(m)}`. An element of slope `1` is the identity on
     some class `0(m)`, which can be taken even.
   - **Contractions.** For `q ∈ P'` let `c_q` send `0(2)` to `0(2q)` by `x ↦ qx`, and send the complement `1(2)`
     onto the complement of `0(2q)`, which is `2q - 1` classes mod `2q`. For the second part, refine `1(2)` into
     `2q - 1` classes by repeatedly splitting a class `r(m)` into `r(2m)` and `(r+m)(2m)`, then match the pieces
     by canonical maps. So `c_q ∈ CT_P(Z)`, `c_q(0) = 0`, and `c_q` has slope `q`. For `m` even,
     `c_q(0(m)) = 0(qm)`, so `c_q K_m c_q^{-1} = K_{qm}`.
   - **`K_2 ≅ CT_P(Z)`.** Put `κ(n) = 1 + 2n`, a bijection `Z -> 1(2)`.
     - *(⊆)* A piece `r + tm ↦ s + tn` of `g` becomes the piece `(1 + 2r) + t(2m) ↦ (1 + 2s) + t(2n)` of
       `κ g κ^{-1}`. That is in canonical form, and adding the identity on `0(2)` gives an element of `K_2`.
     - *(⊇)* Let `h ∈ K_2`. Refine its partitions until every modulus is even, by the same splitting, so each
       class has one parity. `h` fixes `0(2)` pointwise, so it maps odd classes `a + tM` to odd classes
       `b + tN`. Then `κ^{-1} h κ` has pieces `(a-1)/2 + t(M/2) ↦ (b-1)/2 + t(N/2)`, so it lies in `CT_P(Z)`.
     - So `h ↦ κ^{-1} h κ` is an isomorphism `K_2 -> CT_P(Z)`, and `K_2` is finitely generated.
   - **Generation.** Let `g ∈ Stab(0)` have slope `∏ q^{a_q}`, and let `c = ∏ c_q^{a_q}`, taken in any order.
     Then `c^{-1} g` has slope `1`, so it lies in some `K_m` with `m` even. Enlarge `m` to
     `2 ∏ q^{e_q} ∈ 2N_{P'}`, which only enlarges `K_m`. Then `K_m = d K_2 d^{-1}` with `d = ∏ c_q^{e_q}`, by
     the contraction identity. So `g ∈ <K_2, c_q : q ∈ P'>`. Other point stabilizers are conjugates, by item 2.
4. **Type (A).**
   - `CT_P(Z)` is finitely presented (`ct-p-z-is-a-one-vertex-k-graph-full-group`, a lane proof resting on Li's
     theorem), and the action is faithful (item 1).
   - High transitivity leaves one orbit of two-element subsets.
   - Stabilizers are finitely generated (item 3).

**Calibration.** For `P = ∅`, `CT_∅(Z) ≅ V` (McDermott) acts on `N_0`, which is the tail class of `0^∞` in the
2-adic integers. Item 3 then recovers finite generation of `Stab_V(0^∞)`, compatibly with
`v-point-stabilizers-are-ascending-hnn-extensions-of-v`.

**Not claimed.**
- *Higher finiteness.* It is not shown that the finite-set stabilizers are `F_∞`, which would give type
  `[A_∞]`, and by FFWZ Theorem B, `F_∞` for `SV_{CT_P}`. The same ascending-union structure suggests it.
- *CT(Z) itself.* The case of all primes is not finitely generated, so it does not arise.

**OPEN.** Let `S_- = eps_- F_3[G_3]` with `G_3 = L_(F_3)(1,2)^x`. If `(K_0(S_-), [eps_-])` has a state
(equivalently, `S_-` satisfies the rank condition), then some proper two-sided ideal `I` of `S_-` has
`S_- / I` weakly finite.

**Why it matters.** It is step (U1a) of the state upgrade.
- **Necessary:** by `anti-central-rank-functions-give-weakly-finite-leavitt-images`, any Sylvester matrix
  rank function on `S_-` produces such an ideal. So (U1), and the whole upgrade, imply this claim.
- **Contrapositive:** if every nonzero quotient of `S_-` fails weak finiteness, then `S_-` has no rank
  function at all, whatever the state picture. The ternary corner would still survive only if the rank
  condition holds anyway.

## Attempts

- 2026-09-12 `w4-upg-state` (artifact Section 1):
  - **Trivial case.** If `S_-` is stably finite (the anti-central half of Kaplansky's direct finiteness
    for `G_3`), take `I = 0`.
  - **What else is needed.** Otherwise a proof must find a proper ideal with weakly finite quotient.
    The evaluation quotient `S_- -> L_(F_3)(1,2)` is not one: it fails the rank condition.
  - **Transfinite attempt.** Kill the ideal `I_1` generated by all idempotent matrices of state zero
    (defects `1 - BA` with `AB = 1`), then iterate. A state vanishes on `I_1`, and `1` is not in `I_1`
    because `[1] <= n[e] = 0` would follow. But I found no reason the state descends to `K_0(S_- / I_1)`,
    and new defects can appear in the quotient. So the iteration can stop at `0`.
  - **Literature.** P. Malcolmson's work on weakly finite images of rings (not read locally, unverified)
    is the place to look for a ring with the rank condition and no nonzero weakly finite image. Such a
    ring would kill (U1) as a general ring-theoretic statement, though not for `S_-`.

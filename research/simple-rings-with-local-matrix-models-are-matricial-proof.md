Artifact §1, Lemma S.
1. For `a, b ∈ R`, both lie in `W_n` for all large `n`. Cofinite sets belong to `ω`, so `Ψ` is
   additive, multiplicative and unital.
2. `Ψ(1) = [1] != 0`, because every `N_n >= 1`. So `ker Ψ` is a proper two-sided ideal.
3. `R` is simple, so `ker Ψ = 0`.

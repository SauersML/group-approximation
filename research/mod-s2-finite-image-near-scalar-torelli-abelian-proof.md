Input **[ST1]** from `deligne-torelli-character-counts-separating-twists`: separating twists form one
conjugacy class of `M`, and `K` is its normal closure, so `K` is generated by separating twists. All norms
are operator norms, and all matrices are in `U(d)`.

## Lemma 1 (commutator contraction)

For unitaries `g, h`, `||[g,h] - I|| <= 2 ||g - I|| ||h - I||`, where `[g,h] = g h g^-1 h^-1`.

*Proof.* `[g,h] - I = (gh - hg) g^-1 h^-1`, and
`gh - hg = (g - I)(h - I) - (h - I)(g - I)`.

## Lemma 2 (back-tracking)

If `A` commutes with `B A B^-1` and `||B - I|| < sqrt 2`, then `AB = BA`.

*Proof.* Let `V_i` be the eigenspaces of `A`, with distinct eigenvalues `a_i`. Then `B V_i` is the
`a_i`-eigenspace of `B A B^-1`. Commuting normal operators are simultaneously diagonalizable, so
`B V_i` is the direct sum of the spaces `B V_i ∩ V_j`. Suppose `j != i` and `u in B V_i ∩ V_j` is a unit
vector. Then `B^-1 u in V_i`, which is orthogonal to `u`, so `||B^-1 u - u||^2 = 2`. But
`||B^-1 - I|| = ||B^-1 (I - B)|| = ||B - I|| < sqrt 2`, a contradiction. Hence `B V_i = V_i` for every `i`,
so `B` commutes with `A`.

Note that `A` commutes with `[A,B]` iff it commutes with `B A^-1 B^-1`, iff it commutes with `B A B^-1`.

## Lemma 3 (Frobenius)

Let `H <= U(d)` be finite, and let `g, h in H` with `||g - I|| < 1/2` and `||h - I|| < sqrt 2`. Then `gh = hg`.

*Proof.*
1. Put `h_0 = h` and `h_(k+1) = [g, h_k]`, all in `H`. With `q = 2||g - I|| < 1`, Lemma 1 gives
   `||h_k - I|| <= q^k ||h - I||`. In particular `||h_k - I|| < sqrt 2` for all `k`.
2. `H` is finite, so `delta = min{ ||x - I|| : x in H, x != I } > 0`. Hence `h_N = I` for some `N`.
3. Descend. `g` commutes with `h_N = I`. If `g` commutes with `h_(k+1) = [g, h_k]`, then Lemma 2 with
   `A = g` and `B = h_k` shows that `g` commutes with `h_k`. By induction `g` commutes with `h_0 = h`.

## Proof of the claim

1. Let `H = <rho(M), lambda I>`. It is finite, since `rho(M)` is finite, `lambda` has finite order and `lambda I` is central.
2. For every separating twist `t_c`, [ST1] gives `t_c = m t_s m^-1`. So `g_c := lambda^-1 rho(t_c)` is conjugate in
   `U(d)` to `lambda^-1 rho(t_s)`, and `||g_c - I|| = ||rho(t_s) - lambda I|| < 1/2`.
3. By Lemma 3 (`1/2 < sqrt 2`), the elements `g_c` and `g_(c')` of `H` commute. Hence `rho(t_c)` and `rho(t_(c'))`
   commute for all separating curves `c`, `c'`.
4. By [ST1], `K` is generated by separating twists, so `rho(K)` is generated by pairwise commuting unitaries, hence is
   abelian, and `rho` kills `[K,K]`.

The consequences in the target are direct:
- For finite image, the Torelli character `chi` of Step 2 in `mod-s2-torelli-abelian-scalars-shifted-multipliers-proof`
  takes values in the finite group of eigenvalues, so it has finite order.
- `u(gamma) = rho(s(gamma))|_(W_chi)` has finite image.
- For `lambda = 1`, `rho(t_s)` acts on `W_chi` by the scalar `exp(2 pi i h_chi(s))` with `|h_chi(s)| < 1/2`,
  so the principal `Tr log rho(t_s)` equals `2 pi i sum_chi (dim W_chi) h_chi(s)`.

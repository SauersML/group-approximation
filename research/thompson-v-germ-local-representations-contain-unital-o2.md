**ESTABLISHED.** Notation: `X = {0,1}^N`, `V` acts on it by prefix replacements, and `[w]` is the cylinder of the
word `w`. For a clopen `B` put `V_B = {g in V : g fixes X \ B pointwise}`.

A *germ-local covariant representation* is a unitary representation `pi` of `V` on `H != 0` together with a unital
`*`-homomorphism `rho : C(X) -> B(H)` such that:
- **(cov)** `pi(g) rho(f) pi(g)* = rho(f o g^-1)`;
- **(loc)** `pi(g) rho(1_A) = rho(1_A)` whenever `g` fixes the clopen `A` pointwise.

Examples:
- the Koopman representation on `L^2(X, mu)` with Radon--Nikodym factors, for any quasi-invariant `mu`;
- the quasi-regular representation on `l^2(Y)` for any `V`-invariant `Y ⊂ X`, e.g. one orbit, with `rho` given by multiplication;
- every representation of `O_2` restricted to `V ⊂ U(O_2)`;
- direct sums and amplifications of these.

**Theorem.**
1. `rho(C(X)) ⊂ C*_pi(V) := C*(pi(V))`.
2. `C*_pi(V)` contains two isometries `v_0, v_1` with `v_0 v_0* + v_1 v_1* = 1`, hence a unital copy of `O_2`.
3. Every nonzero quotient of `C*_pi(V)` contains a unital copy of `O_2`, and so it is not finite.
4. **Kill.** Let `A` be any finite unital C*-algebra, e.g. `Q = prod M_n / (+) M_n`, `R^omega`, or any MF algebra. Then no
   homomorphism `psi : V -> U(A)` satisfies `||psi(h)|| <= ||pi(h)||` for all `h in C[V]`. Equivalently, no sequence of
   operator-norm approximate representations `sigma_n : V -> U(k_n)` with defect tending to `0` has
   `limsup_n ||sigma_n(h)|| <= ||pi(h)||` for every `h in C[V]`.
5. `lambda` and `pi` are weakly incomparable. `C*_r(V)` is simple (V is C*-simple) and has a faithful trace, so it is
   neither a quotient of `C*_pi(V)` (by 3) nor has `C*_pi(V)` as a quotient (a quotient of a simple algebra is itself or
   `0`, and `C*_pi(V)` is infinite).

**Proof.**

*Step 0 (no invariant measure).* Every nonempty clopen `B ⊊ X`, and also `B = X`, is a finite union of cylinders. So
there is a prefix-replacement homeomorphism `B -> X` that conjugates `V_B` onto `V`. Hence `V_B` is finitely generated,
with a finite symmetric generating set `S_B` of size `k`, and `V_B` has no invariant Borel probability measure on `B`.
The measure argument is transported to `X`: pick `g, g' in V` with `g[0] = [00]` and `g'[0] = [01]`. Then
`m([0]) = m([00]) + m([01]) = 2 m([0])`, so `m([0]) = 0`. Likewise `m([1]) = 0`, which contradicts `m(X) = 1`.

*Step 1 (spectral gap, then functional calculus).* Fix a proper nonempty clopen `A` and put `B = X \ A`, `P = rho(1_A)`,
`H_A = PH`, `H_B = (1-P)H`. For `s in V_B` we have `sB = B`, so by (cov) `pi(s)` commutes with `P`. By (loc),
`pi(s)P = P`.

Suppose unit vectors `xi_n in H_B` satisfy `||pi(s) xi_n - xi_n|| -> 0` for all `s in S_B`. The states
`nu_n(f) = <rho(f) xi_n, xi_n>` are probability measures on `B`. By (cov),
`|nu_n(f o s^-1) - nu_n(f)| <= 2 ||f|| ||pi(s)* xi_n - xi_n|| -> 0`. A weak-* limit point is then an `S_B`-invariant,
hence `V_B`-invariant, probability measure on `B`. That contradicts Step 0.

Now let `T = (k+1)^-1 (1 + sum_{s in S_B} pi(s))`. It is self-adjoint, `T = 1` on `H_A`, and `T` preserves `H_B`. On
`H_B`, the spectrum of `T` lies in `[-(k-1)/(k+1), 1]`. If `<T xi, xi> >= 1 - eps` for a unit `xi in H_B`, then
`||pi(s) xi - xi||^2 <= 2(k+1) eps` for each `s`. So by the previous paragraph `||T|_{H_B}|| <= 1 - eta` for some
`eta > 0`. Therefore `T^m -> P` in norm, and `rho(1_A) in C*_pi(V)`. Such indicators span a dense subalgebra of
`rho(C(X))` (use `1 = 1_[0] + 1_[1]`), which proves 1.

*Step 2 (Cuntz isometries).* Choose `g_i, h_i in V` (`i = 0, 1`) with `g_i[0] = [i0]` and `h_i[1] = [i1]`. Such maps
exist because `V` maps any proper nonempty clopen onto any other with complements to complements. Put
`v_i = pi(g_i) rho(1_[0]) + pi(h_i) rho(1_[1])`, which lies in `C*_pi(V)` by 1.

By (cov), `pi(g_i) rho(1_[0]) = rho(1_[i0]) pi(g_i)` and `pi(h_i) rho(1_[1]) = rho(1_[i1]) pi(h_i)`. Hence:
- the cross term in `v_i* v_i` is `pi(g_i)* rho(1_[i0]) rho(1_[i1]) pi(h_i) = 0`, so `v_i* v_i = rho(1_[0]) + rho(1_[1]) = 1`;
- the cross term in `v_i v_i*` is `pi(g_i) rho(1_[0]) rho(1_[1]) pi(h_i)* = 0`, so
  `v_i v_i* = rho(1_[i0]) + rho(1_[i1]) = rho(1_[i])`;
- `v_0 v_0* + v_1 v_1* = 1`.

`O_2` is simple, so `C*(v_0, v_1) ≅ O_2` unitally. This proves 2.

*Step 3.* Let `q` be a nonzero quotient map. Then `q(1) != 0`, and `q` is injective on the simple unital subalgebra
`C*(v_0, v_1)`. So `q(v_0)` is a non-unitary isometry, because `q(v_1 v_1*) != 0`.

*Step 4.* The condition `||psi(h)|| <= ||pi(h)||` says exactly that `pi(g) -> psi(g)` extends to a unital surjection
`q : C*_pi(V) -> C*_psi(V) ⊂ A`. Then `q(v_0)` is an isometry of the finite algebra `A`, so it is unitary. That
contradicts 3.

For the sequence form, pass to `Q`. There the `sigma_n` define a homomorphism `psi : V -> U(Q)`, and
`||psi(h)||_Q = limsup_n ||sigma_n(h)||`. Finiteness of `Q`: if `x^*x = 1` in `Q`, lift `x` to `(x_n)`. Then
`||x_n^* x_n - 1|| -> 0`, and `x_n x_n^*` has the same nonzero spectrum and the same size, so `||x_n x_n^* - 1|| -> 0`.

*Step 5* is as stated. ∎

**Remarks.**
- With (loc), one can check that `pi(g) rho(1_[u]) = v_w v_u*` whenever `g` acts on `[u]` by `uy -> wy`, so in fact
  `C*_pi(V) = C*(v_0, v_1) ≅ O_2`. All nonzero germ-local covariant representations of `V` are then weakly equivalent,
  with the kernel of the canonical map `C*(V) -> O_2`. This refinement is not needed above.
- Only Step 1 uses (loc). Step 2 uses only (cov).

**What the kill covers (symbolic-dynamics transplants for `thompson-v-has-full-mf-radical`).** Consider any MF model
of `V` built by truncating the Cantor dynamics, where the finite-dimensional norms are controlled from above by a
spatial representation. This covers Koopman, orbit `l^2`, Cuntz-algebra/Jones-type, and self-similar tree
representations. Every such model dies at Step 4: the image of `v_0` would be a proper isometry in `Q`.

Survivors are:
- models whose norm profile exceeds every germ-local representation on some `h in C[V]`;
- mixtures `pi (+) lambda` whose quotient discards the `O_2` summand;
- models built from representations that do not satisfy (cov), such as Pythagorean representations
  (`A*A + B*B = 1` without `AA* + BB* = 1`).

By BKKO trace convergence and `thompson-v-character-simplex`, the models that are nontrivial in 2-norm already satisfy
`lambda ≺ psi`. So a witness must weakly contain `lambda` and must escape domination by every representation of
`O_2`.

## Statement

Let `P` be an infinite group generated by a finite set `S`, `nu: P -> N` a bijection,
`lambda_g(nu(h)) = nu(gh)`, `s: n -> n+1`, and let `R = R_nu = <lambda(P), s>` be the
near permutation group of `shell-germ-group-has-index-two-fiber-product`, with near index
`eta: R -> Z`. Write `c_k = s^k lambda(P) s^-k` for the label-`k` conjugate and, for
`eps` in `{1, -1}` and `N >= 0`,

    W_N^eps = < c_(eps*j) : 0 <= j <= N >.

For `eps` in `{1, -1}` the following are equivalent.

1. **(Gate.)** There is a finitely generated `B <= ker(eta)` with
   `B <= s^eps B s^-eps` and `ker(eta) = union_(n >= 0) s^(eps*n) B s^(-eps*n)`.
2. **(Finite window.)** For some `N >= 0`,
   `s^-eps lambda(P) s^eps <= W_N^eps`,
   that is, `s^-eps lambda_g s^eps` lies in `W_N^eps` for each `g` in `S`.

When (2) holds, `B = W_N^eps` witnesses (1). Consequently, by
`shell-germ-fp-is-an-ascending-hnn-gate`, the shell germ group `Q` is finitely presented
exactly when `R_nu` is finitely presented and (2) holds for some `eps` and `N`.

Condition (2) is a finite list of near identities between explicit near permutations. So
a gate witness is certified by finitely many words, not by an infinite exhaustion.

## Relation to known obstructions

For one-ended `P`, the case `N = 0` of (2) says `s^-eps lambda(P) s^eps <= lambda(P)`,
which `one-ended-shell-inputs-admit-no-shift-normalizing-enumeration` excludes. Every
witness for a one-ended input therefore needs `N >= 1`.
`square-spiral-z2-enumeration-passes-the-finite-window-gate` gives such a witness for
`P = Z^2` with `N = 2`.

Notation as in the target claim.

**Step 1: an integral form containing `S`.** Let `s_1, ..., s_r` generate `S` and
write `s_i = sum_j lambda_{ij} b_j` (finite sums, `lambda_{ij} in K`). Let `A <= K`
be the subring generated by `A_1` and all `lambda_{ij}`; it is a finitely
generated commutative domain of characteristic 0. Put `B_A = sum_j A b_j`. The `b_j`
are `K`-linearly independent, so `B_A` is a free `A`-module with basis `(b_j)`, and
every element has well-defined coordinates in `A`. `B_A` is closed under
multiplication, because the structure constants lie in `A_1 <= A`. It contains `1`,
since the coordinates of `1` lie in `A_1`, and it contains every `s_i`. Hence
`S <= B_A`, and `M_m(S) <= M_m(B_A)`. The latter is a free `A`-module on the basis
`b_j E_{kl}`.

**Step 2: a nonzero element of `A` lies in `pA` for only finitely many primes.**
Let `0 != a in A`. The ring `A[1/a] (x) Q` is a nonzero finitely generated
`Q`-algebra: it is the localization of the domain `A` at the multiplicative set
generated by `a` and the nonzero integers, and it lies in `Frac(A)`. Take a
maximal ideal `m` of it. The residue field `F` is a finitely generated
`Q`-algebra that is a field. By Zariski's lemma (Atiyah–Macdonald, *Introduction to
Commutative Algebra*, Proposition 7.9: "Let `k` be a field, `B` a finitely
generated `k`-algebra. If `B` is a field then it is a finite algebraic extension of
`k`") it is a number field. Let `phi: A -> F` be the composite ring homomorphism.
Then `phi(a) != 0`, because `a` is a unit in `A[1/a]`.

Write `A = Z[g_1, ..., g_t]`. Each `phi(g_i)` has `n_i phi(g_i) in O_F` for some
integer `n_i >= 1` (clear the denominators of its minimal polynomial). So
`phi(A) <= O_F[1/n]` with `n = n_1 ... n_t`. Norms of elements of `O_F[1/n]` lie in
`Z[1/n]`. Put `d = [F:Q]` and `N = N_{F/Q}`.

Suppose `a = p c` with `c in A` and `p` a prime not dividing `n`. Then
`N(phi(a)) = p^d N(phi(c))`, where `N(phi(c)) in Z[1/n]`. So the fixed nonzero
rational number `N(phi(a))` has `p`-adic valuation at least `d >= 1`. Only
finitely many primes do. Hence `a in pA` for only finitely many `p`.

**Step 3: conclusion.**
- *Clause 1.* Let `0 != x in M_m(S)`, and pick a nonzero coordinate
  `a in A` of `x` in the basis `b_j E_{kl}` of `M_m(B_A)`. If `x = p y` with `y` in
  `M_m(S) <= M_m(B_A)`, then comparing coordinates gives `a in pA`. By Step 2 this
  holds for only finitely many `p`.
- *Clause 2.* A nonzero divisible subgroup contains a nonzero element divisible by
  every prime, which contradicts clause 1. If `f: Q -> M_m(S)` is a nonzero ring
  homomorphism, then `e = f(1)` is nonzero, because `f(q) = f(q) e`. Also
  `e = p f(1/p)` for every prime `p`, which again contradicts clause 1. A copy of `Q`
  in a corner `e M_m(S) e` is such a homomorphism.
- *Clause 3.* If `q -> 1 + N(q)` is an injective homomorphism `(Q,+) -> GL_m(S)`
  with `N` additive, then `N(Q)` is a divisible subgroup of `(M_m(S),+)`. It is
  nonzero because the map is injective, which contradicts clause 2. The elementary
  unipotents `e_ij(q) = 1 + q E_ij` are of this form. A ring homomorphism
  `M_n(Q) -> M_m(S)` restricts to a ring homomorphism `Q -> M_m(S)` on the scalar
  matrices, which is nonzero if the homomorphism is nonzero; clause 2 excludes it.
  ∎

**The examples in the claim.**
- **Leavitt and Cohn path algebras.** Products of normal-form monomials reduce, by
  relations with integer coefficients, to integer combinations of normal-form
  monomials. So the structure constants lie in `Z`.
- **Group algebras.** The basis `Gamma` has constants 0 and 1.
- **Weyl algebras.** In the basis `x^a d^b`, the constants are integers from the
  Leibniz rule.
- **Enveloping algebras.** For a Lie algebra with integral structure constants, the
  PBW basis has integral constants.
- **Finite-dimensional algebras.** There are only finitely many constants.

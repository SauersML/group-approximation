**Setting.** `R_L` is the ring of `leavitt-resolvent-ring-is-fp-simple-of-char-zero`. `B = Q[N][(N+c)^(-1) : c >= 1]`
is its diagonal ring, and `q_k = s_1^k s_2 t_2 t_1^k` for `k >= 0`.

**Statement.**
1. **`R_L` is a single-register completion with a spine and point indicators.** The functions `N -> Q` that
   agree with an element of `B` for all large `n` form the ring `B⁺ = B ⊕ J`, with `J = ⊕_(k>=0) Q δ_k`.
   - `f + Σ a_k δ_k -> f + Σ a_k q_k` embeds `B⁺` in `R_L`.
   - `R_L` is the universal ring on `B⁺`, the letters `s_1` (shift `N -> N + 1`) and `s_2` (reset `N -> 0`), and
     the Cuntz relations. `s_1` is a spine.
   - So `register-completion-pimsner-from-supercoherence` applies to `R_L`. That node's scope remark excluding
     `R_L` concerns the smaller base `B`, which has no idempotents.
2. **The transfer.** On `G_n = K_n(B⁺) = K_n(Q)·1 ⊕ ⊕_(c>=1) K_(n-1)(Q) e_c ⊕ ⊕_(k>=0) K_n(Q) δ_k`, where `e_c` is
   the residue at `N = -c`, the transfer is `[X] = σ_* + ev_(0,*)`. The map `1 - [X]` is injective, and its
   cokernel is `K_(n-1)(Q)` through the residue sum `Σ_c e_c-components`.
3. **The K-groups.** `K_n(R_L) ≅ K_(n-1)(Q)` for every `n in Z`, through `K_n(B⁺) -> K_n(R_L)` followed by the
   residue sum. In particular:
   - `K_0(R_L) = 0`;
   - `K_1(R_L) ≅ Z`, generated by `[N + 1]`. Every `[N + c]`, `c >= 1`, equals `[N + 1]`, and every rational scalar
     is `0` in `K_1`;
   - `K_2(R_L) ≅ Q^x`, with `{λ, N + 1} -> λ`. Every `{λ, N + c}` maps to `λ`, and the image of `K_2(Q)` is `0`;
   - `K_3(R_L) ≅ K_2(Q)`, and `K_n(R_L) = 0` for `n < 0`.
4. **`K_2(N, R_L)` hits everything.** For every `N >= 3`, `K_2(N, R_L) -> K_2(R_L)` is onto, since
   `{λ, N + 1}` is a Steinberg symbol of commuting units in `St_N(R_L)`.
5. **No finitely presented elementary group.** For every `N >= 3`, `E_N(R_L)` is not finitely presented. Neither
   is `E_N(R_L)/C` for any finite normal subgroup `C`. The Steinberg symbols `{λ, N+1}` of commuting units generate
   `K_2(R_L) ≅ Q^x`, which is not finitely generated (`infinitely-generated-symbols-block-fp-elementary-groups`).

## Consequences for `st-n-leavitt-resolvent-word-problem-reduces-to-k2`

- The shortcut "(i) and stable `K_2(R_L) = 0`" is closed: `K_2(R_L) = Q^x ≠ 0`.
- If (i), injective stability at `N`, holds, then `K_2(N, R_L) ≅ Q^x` by item 4. Condition (ii) then asks for a
  **computable** version of the isomorphism of item 3: from a word of `St_N(R_L)` that is trivial in `E_N(R_L)`,
  compute its value in `Q^x`.
- The isomorphism is explicit on generators, `{λ, N + c} -> λ`, but it is defined through the Pimsner sequence.
  Whether it is computable on arbitrary words is **OPEN**.
- A computable detector would be a ring-level "total residue along the resolvent orbit". By Weil reciprocity in
  `K_2(Q(N))`, this is the tame symbol at `N = ∞` of the base part. Constructing it on all of `R_L` is the remaining
  step.

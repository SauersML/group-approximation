**Conventions.**
- A chain is a stochastic matrix `Q` on a countable set `Y`, written with a trajectory `(Y_n)`.
- `T_x = inf{n ≥ 0 : Y_n = x}` and `T⁺ = inf{n ≥ 1 : Y_n = x}`. For finite `B ∋ x`, `τ_B = inf{n ≥ 0 : Y_n ∉ B}`.
- `⟨f,g⟩ = Σ_y f(y) g(y)` for finitely supported `f`. `Q*(y,z) = Q(z,y)`.
- `Q` is doubly stochastic if `Q*` is stochastic too. Every induced chain `P(y,z) = μ{g : g y = z}` is doubly
  stochastic, since `Σ_y μ{g : g y = z} = Σ_g μ(g) · #{y : g y = z} = 1`.
- For symmetric stochastic `Q`, `E_Q(f) = ½ Σ_(y,z) Q(y,z) (f(y) − f(z))²`. For finitely supported `f` all sums below
  are finite, and `E_Q(f) = ⟨f, (I − Q) f⟩` by expanding the square and using that rows and columns sum to `1`.

**Step 0 (standard facts on irreducible chains).**
- (a) `x` is recurrent iff `Σ_(n≥0) Q^n(x,x) = ∞`. The number of visits to `x` from `x` is geometric with
  parameter `P_x(T⁺ = ∞)`, and its mean is that sum.
- (b) Recurrence is a class property, so for irreducible `Q` it does not depend on `x`.
- (c) If `Q` is irreducible and `B` is finite, then `P_x(τ_B = ∞, T⁺ = ∞) = 0`. On this event some `y ∈ B` is
  visited infinitely often. If `Q` is transient this has probability `0`. If `Q` is recurrent, `T⁺ < ∞` almost
  surely.

**Step 1 (escape probabilities and the equilibrium potential).** Let `Q` be irreducible, `x ∈ Y`, and `B ∋ x` finite.
Put `h_B(y) = P_y(T_x < τ_B)`.
- `h_B(x) = 1`, `h_B = 0` off `B`, and `h_B(y) = (Q h_B)(y)` for `y ∈ B ∖ {x}`, by the Markov property at time `1`
  (both `T_x ≥ 1` and `τ_B ≥ 1` there).
- `(Q h_B)(x) = P_x(T⁺ < τ_B)`, again by the Markov property at time `1`, since `τ_B ≥ 1`.
- So `⟨h_B, (I − Q) h_B⟩ = h_B(x) (1 − (Q h_B)(x)) = 1 − P_x(T⁺ < τ_B) = P_x(τ_B < T⁺)`. The last equality uses
  Step 0(c), and that `τ_B = T⁺ < ∞` is impossible because `Y_(T⁺) = x ∈ B`.
- Let `B_1 ⊆ B_2 ⊆ ⋯` be finite, contain `x`, and exhaust `Y`. The events `A_n = {τ_(B_n) < T⁺}` decrease, and
  `∩_n A_n = {T⁺ = ∞}` up to a null set. If `T⁺ < ∞`, the finite path `Y_0, …, Y_(T⁺)` lies in `B_n` for large `n`,
  so `A_n` fails. If `T⁺ = ∞`, then `τ_(B_n) < ∞` almost surely by Step 0(c), so every `A_n` holds. Hence
  `P_x(τ_(B_n) < T⁺) ↓ P_x(T⁺ = ∞)`.

**Step 2 (Dirichlet principle for symmetric chains).** Let `Q` be symmetric and irreducible, and put
`cap_Q(x) = inf{E_Q(f) : f finitely supported, f(x) = 1}`. Then `cap_Q(x) = P_x(T⁺ = ∞)`.
- Fix `B` and `f` with `f(x) = 1` and `f = 0` off `B`, and set `g = f − h_B`. Then `g` vanishes at `x` and off `B`,
  while `(I − Q) h_B` vanishes on `B ∖ {x}`. By polarization, `E_Q(h_B, g) = ⟨g, (I − Q) h_B⟩ = 0`.
- So `E_Q(f) = E_Q(h_B) + E_Q(g) ≥ E_Q(h_B) = P_x(τ_B < T⁺)` by Step 1, with equality at `f = h_B`.
- Every finitely supported `f` is supported in some `B_n`, and the minimum over `B_n` decreases in `n`. So
  `cap_Q(x) = lim_n P_x(τ_(B_n) < T⁺) = P_x(T⁺ = ∞)` by Step 1.

**Step 3 (symmetrization cannot destroy recurrence).** Let `Q` be doubly stochastic and irreducible, and put
`Q_s = (Q + Q*)/2`. It is symmetric, stochastic, and irreducible because `Q_s ≥ Q/2`.
- For finitely supported `h`, `⟨h, Q* h⟩ = ⟨Q h, h⟩ = ⟨h, Q h⟩`, so `E_(Q_s)(h) = ⟨h, (I − Q_s) h⟩ = ⟨h, (I − Q) h⟩`.
- Apply this to the potential `h_B` of `Q` itself, which is admissible for `cap_(Q_s)(x)`. By Step 1,
  `cap_(Q_s)(x) ≤ E_(Q_s)(h_(B_n)) = P^Q_x(τ_(B_n) < T⁺) → P^Q_x(T⁺ = ∞)`.
- So if `Q` is recurrent, `cap_(Q_s)(x) = 0`, and `Q_s` is recurrent by Step 2.

**Step 4 (subordination to full support).** Let `P` be the chain induced by `μ`. Put
`μ′ = Σ_(k≥1) 2^(−k) μ^(*k)`, whose induced chain is `P′ = Σ_(k≥1) 2^(−k) P^k`.
- `supp μ′ = ∪_k supp μ^(*k)` is the semigroup generated by `supp μ`, which is `G`. So `μ′(g) > 0` for every `g ∈ G`.
- With `A(t) = Σ_(k≥1) 2^(−k) t^k = t/(2 − t)`, the formal series `Σ_(n≥0) A(t)^n = (2 − t)/(2(1 − t)) = 1 + ½ Σ_(k≥1) t^k`
  has nonnegative coefficients. Expanding each `P′^n = A(P)^n` and summing by Tonelli gives
  `Σ_(n≥0) P′^n(x,x) = 1 + ½ Σ_(k≥1) P^k(x,x)`.
- So `P′` is recurrent iff `P` is, by Step 0(a). `P′` is doubly stochastic and irreducible.

**Step 5 (comparison with a generating set of F).**
- Let `S = (s_1, …, s_m)` be a finite symmetric generating multiset of `F` (with involution `σ` as in
  `recurrent-orbits-force-every-z3-to-meet-the-stabilizer`), and `t_i = θ(s_i)`.
- Let `R(y,z) = (1/m) #{i : t_i y = z}` on `X`. It is symmetric (by `σ`) and stochastic.
- Let `ε = min_i μ′(t_i) > 0`. For `y ≠ z`,
  `P′(y,z) = μ′{g : g y = z} ≥ ε · #{distinct g ∈ {t_1, …, t_m} : g y = z} ≥ (ε/m) #{i : t_i y = z} = ε R(y,z)`.
  The same bound holds for `P′*`, since `R* = R`. So `P′_s ≥ ε R` off the diagonal.
- Since `E` is a sum over pairs `y ≠ z` of nonnegative terms, `E_(P′_s)(f) ≥ ε E_R(f)` for all finitely supported `f`.
- `R(y,z) = 0` unless `z ∈ θ(F)·y`. Let `Ω = θ(F)·x` and `R_Ω` the restriction of `R` to `Ω`. It is symmetric,
  stochastic and irreducible, and `E_R(f) ≥ E_(R_Ω)(f|_Ω)`.
- So `cap_(R_Ω)(x) ≤ ε^(−1) cap_(P′_s)(x)`.

**Step 6 (conclusion).** Suppose `P` is recurrent. Then:
- `P′` is recurrent (Step 4);
- `P′_s` is recurrent, so `cap_(P′_s)(x) = 0` (Steps 3 and 2);
- so `cap_(R_Ω)(x) = 0`, and `R_Ω` is recurrent (Steps 5 and 2).

`R_Ω` is the walk `Y_(n+1) = t Y_n` with `t` uniform in `(t_1, …, t_m)`. This is the network walk of `Sch(F·x, S)` for
`F` acting on `Ω ≅ F/H` through `θ`, with `H = θ^(−1)(Stab_G(x))`, loop steps included (they only delay it). So the
`F`-set `F/H` has a recurrent Schreier graph, and `H ⊇ F′` by `thompson-f-recurrent-f-sets-factor-through-the-abelianization`.
So `θ(F′)` fixes `x`. Recurrence of the irreducible `P` does not depend on the base point (Step 0(b)), so `θ(F′)`
fixes every point of `X`. ∎

**Corollary 1 (inverted orbits).** Let `h_1, h_2, …` be i.i.d. of law `μ` and `O_n = {h_1 ⋯ h_k x : 0 ≤ k ≤ n}`.
- `h_1 ⋯ h_(n+1) x` is new iff `h_(k+1) ⋯ h_(n+1) x ≠ x` for all `0 ≤ k ≤ n`.
- Put `g_j = h_(n+2−j)` for `1 ≤ j ≤ n+1`. Then `h_(k+1) ⋯ h_(n+1) = g_(n+1−k) ⋯ g_1`, and `Y_j = g_j ⋯ g_1 x` is the
  induced chain from `x`.
- So `E|O_(n+1)| − E|O_n| = P_x(T⁺ > n+1)`, and `(1/n) E|O_n| → P_x(T⁺ = ∞)` by Cesàro. This holds for every `μ`.
- If `θ(F′)` moves a point of `X`, the Theorem says `P` is transient, so the limit is positive.

**Corollary 2** is the Theorem with `X = G·y` and `θ` the inclusion of the copy of `F`.

This is an alternative route to `lef-groups-embed-in-simple-kazhdan-lef-groups-proof`. It is the text proposed for
Corollary 2 of the note: 45 source lines against 66 in rev3 at 9047d0d3c9 l.281–346.

1. **Overgroup.** `lef-groups-lie-in-derived-subgroups-of-infinite-lef-groups` gives an infinite f.g. LEF group
   `Δ ≤ ∏_ω Λ_n` with `Γ ≤ [Δ,Δ]`, where `Λ_n = Q_n^(Z/m_n) ⋊ Z/m_n` are finite.
2. **Host.** `L` is the group of maps `x ↦ δx + f` of `Z = F_2^Δ`, with `(δx)(h) = x(δ^(-1)h)` and `f` finitely
   supported. It is generated by `Δ` and `a: x ↦ x + 1_e`.
   - *Minimal:* orbits contain `x + ⊕_Δ F_2`, which is dense.
   - *Topologically free:* fixed points satisfy `x(h) = x(δ^(-1)h) + f(h)` for all `h`. If `δ = e` and `f ≠ 0`, this
     fails at `h ∈ supp f` for every `x`. If `δ ≠ e`, then in a cylinder over a finite `W` it fails at some point for
     `h ∉ W ∪ δW ∪ supp f`: such `h` exist as `Δ` is infinite, and `h ≠ δ^(-1)h` are free coordinates.
   - *Finite generation:* `R = LC(Z,F_2) ⋊ L` is generated by `u_s^(±1)` for the generators `s` of `L` and
     `e_(x(e)=1)`. Translates of the latter give the coordinate indicators, which generate `LC(Z,F_2)` together with 1.
3. **Exact covariant models.**
   - Choose representatives `κ_n(δ) ∈ Λ_n`, and put `Y_n = F_2^(Λ_n)` with `(qy)(q') = y(q^(-1)q')`.
   - Let `σ_n(δ,f) y = κ_n(δ) y + Σ_(h ∈ supp f) 1_(κ_n(h))` and `p_n(y) = y ∘ κ_n ∈ Z`.
   - Fix `ℓ = (δ,f)`, `ℓ' = (δ',f')` and a finite coordinate set `H`. For `ω`-almost all `n`, `κ_n` is multiplicative
     on the elements involved and injective on `H ∪ supp f ∪ δ supp f'`.
   - Multiplicativity: `σ_n(ℓ)σ_n(ℓ')y = κ_n(δδ')y + Σ_(h' ∈ supp f') 1_(κ_n(δh')) + Σ_(h ∈ supp f) 1_(κ_n(h))`, which
     equals `σ_n(ℓℓ')y` with `ℓℓ' = (δδ', f + δf')`. The F_2-cancellation on the overlap is exact, by injectivity.
   - Covariance: `p_n(σ_n(ℓ)y)(h) = y(κ_n(δ)^(-1)κ_n(h)) + #{h' ∈ supp f : κ_n(h') = κ_n(h)} = y(κ_n(δ^(-1)h)) + f(h)
     = (ℓ p_n(y))(h)` for `h ∈ H`, uniformly in `y`.
   - Put `D_n(f) = diag(f ∘ p_n)`, an exact ring homomorphism into the diagonal matrices, and let `U_n(ℓ)` be the
     permutation matrix of `σ_n(ℓ)` on `F_2^(Y_n)`.
   - Then `U_n(ℓ) D_n(f) U_n(ℓ)^(-1) = D_n(f ∘ p_n ∘ σ_n(ℓ)^(-1)) = D_n(f ∘ ℓ^(-1))` for `ω`-almost all `n`, and
     `U_n(ℓ)U_n(ℓ') = U_n(ℓℓ')`.
   - So `Σ f_ℓ u_ℓ ↦ (Σ D_n(f_ℓ) U_n(ℓ))_n` is a unital ring homomorphism `R → ∏_ω M_(|Y_n|)(F_2)`, with
     `(f u_k)(f' u_ℓ) = f (f' ∘ k^(-1)) u_(kℓ)`.
4. **Theorem 2.** `topologically-free-matricial-crossed-el-simple-kazhdan-lef` gives an infinite f.g. simple Kazhdan
   LEF group `G = EL_3(R)`.
5. **Embedding.** Over `F_2`:
   - `e_12(c) e_21(c^(-1)) e_12(c) · e_12(1) e_21(1) e_12(1) = diag(c, c^(-1), 1)`, since `1 + c c^(-1) = 0`;
   - `diag(a,a^(-1),1) diag(b,b^(-1),1) diag((ba)^(-1), ba, 1) = diag(aba^(-1)b^(-1), 1, 1)`.

   So the injective homomorphism `ℓ ↦ diag(u_ℓ,1,1)` maps `[L,L]` into `G`, and `Γ ≤ [Δ,Δ] ≤ [L,L]`.

Converse: subgroups of LEF groups are LEF.

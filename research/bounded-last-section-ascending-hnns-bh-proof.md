Lane proof (bh-free-20, 2026-09-18), elementary; not reviewed. Notation of the claim:
`X = {0,…,L}`, `C = X^N`, `σ(g) = (ψ_0(g), …, ψ_{L−1}(g), g)`. Maps act on the left; `f|_x`
is the section of `f` at the letter `x`.

## 1. Preliminaries

- `σ` is injective, since `g = σ(g)|_L`.
- Each `ψ_z` is a homomorphism, because sections at a fixed letter are multiplicative on the
  level-1 stabilizer.
- Each `ψ_z(G) ≤ G`, because `σ(g) ∈ G` and `G` is self-similar.

## 2. The hats and the stable letter

For `g ∈ G` define `ĝ ∈ Homeo(C)`:

```text
ĝ(L u)             = L g(u),
ĝ(x u)             = x u                        (1 ≤ x ≤ L−1),
ĝ(0^{k+1} y v)     = 0^{k+1} y  ψ_{y−1}(σ^k(g))(v)   (k ≥ 0, 1 ≤ y ≤ L),
ĝ(0^∞)             = 0^∞.
```

Define `s ∈ V_d` by the prefix replacement

```text
L u ↦ L L u,     0 y v ↦ L (y−1) v   (1 ≤ y ≤ L),     x u ↦ x u   (1 ≤ x ≤ L−1),     0 0 w ↦ 0 w.
```

- **`s` is a bijection.** The domain cones `LC, 0yC (1≤y≤L), xC (1≤x≤L−1), 00C` partition `C`.
  So do the image cones `LLC, L0C, …, L(L−1)C, xC, 0C`.
- **Binary case.** For `d = 2` this is the element of `F` used in
  `last-section-ascending-hnns-embed-in-rover-nekrashevych-groups`, and `ĝ` is the hat defined
  there.

**Homomorphism, faithful.** On each piece `ĝ` acts through a homomorphism of `g` (the identity,
the trivial map, or `ψ_{y−1}∘σ^k`). So `g ↦ ĝ` is a homomorphism. It is injective because
`ĝ` restricted to `LC` is the given action of `g`.

**Conjugation identity `s ĝ s^{-1} = \widehat{σ(g)}`.** We check it piece by piece on the
image partition of `s`. In each line below, the left side is computed as `s^{-1}`, then `ĝ`,
then `s`; the right side uses `σ(g)|_z = ψ_z(g)` and `σ(g)|_L = g`.
- `L L u`: `s^{-1}` gives `L u`, and `ĝ` gives `L g(u)`, so the result is `L L g(u)`. This
  equals `L σ(g)(L u)`.
- `L z v` with `z = y−1 < L`: `s^{-1}` gives `0 y v`, and `ĝ` gives `0 y ψ_z(g)(v)`, so the
  result is `L z ψ_z(g)(v)`. This equals `L σ(g)(z v)`.
- `x u` with `1 ≤ x ≤ L−1`: both sides fix it.
- `0^{k+1} y v`: `s^{-1}` gives `0^{k+2} y v`, and `ĝ` gives `0^{k+2} y ψ_{y−1}σ^{k+1}(g)(v)`,
  so the result is `0^{k+1} y ψ_{y−1}σ^{k+1}(g)(v)`. This is `\widehat{σ(g)}` there, since
  `ψ_{y−1}σ^k(σ(g)) = ψ_{y−1}σ^{k+1}(g)`.
- `0^∞`: both sides fix it.

## 3. Injectivity on the HNN extension

`θ(g) = ĝ`, `θ(t) = s^{-1}` respects `t^{-1} g t = σ(g)` by §2.

`B = ⋃_{k≥0} t^k G t^{-k}` is an increasing normal union, since `G = tσ(G)t^{-1} ≤ tGt^{-1}`
and `t^{-1}Gt = σ(G) ≤ G`. Every element of `G*_σ` is `t^m b` with `m ∈ Z`, `b ∈ B`, and
`θ|_B` is injective because it is injective on each conjugate of `G`.

Put `Z_j = s^{-j}(LC)`.
- **The chain is strictly increasing.** `s(LC) ⊆ LC` and `s(0yC) ⊆ LC`, so
  `Z_1 = LC ∪ ⋃_y 0yC ⊋ Z_0`, and by induction `Z_{j+1} ⊋ Z_j`.
- **`θ(B)` preserves late members.** `ĝ` preserves `LC`, so `s^{-j}ĝs^{j} = θ(t^j g t^{-j})`
  preserves `Z_j`. By §2, `s^{-j}ĝs^{j} = s^{-j'}\widehat{σ^{j'−j}(g)}s^{j'}`, which preserves
  `Z_{j'}` for every `j' ≥ j`. So each `θ(b)` preserves `Z_j` for all large `j`.
- **The kernel lies in `B`.** Suppose `θ(t^m b) = 1` with `m ≠ 0`. Then `s^{-m} = θ(b)^{-1}`
  maps `Z_j` to `Z_j` for large `j`. But `s^{-m}(Z_j) = Z_{j+m} ≠ Z_j`, a contradiction.
- **Conclusion.** `ker θ ⊆ B`, so `ker θ = 1`.

## 4. The host is generated by a finite bounded automaton

**Sections.**
- `ĝ|_L = g` and `ĝ|_x = 1` for `1 ≤ x ≤ L−1`.
- `ĝ|_0 = E_g`, where `E_g` acts on `0^k y C` by `ψ_{y−1}σ^k(g)` (`k ≥ 0`) and fixes `0^∞`.
- `E_g|_y = ψ_{y−1}(g) ∈ G` and `E_g|_0 = E_{σ(g)}`.
- `g ↦ E_g` is a homomorphism.

**Finitely many `E`'s.** Put `F_z = ψ_z(G)`, a finite group by (F). Let `Φ_n = (ψ_z∘σ^n)_{z<L}`,
an element of the finite set `∏_z Hom(G, F_z)` (`G` is finitely generated). The sequence is
deterministic: `Φ_{n+1} = Φ_n∘σ`. So it is eventually periodic, with some preperiod `Q` and
period `P`. The map `g ↦ E_{σ^n(g)}` is determined by `(Φ_{n+k})_{k≥0}`, so only finitely many
such maps occur as `n` varies. Each has finite image, because `E_{σ^n(g)}` is determined by the
finitely many values `Φ_m(g)`, `n ≤ m < n+Q+P`. So the set `𝓔 = {E_h : h ∈ σ^n(G), n ≥ 0}`
is finite and closed under sections into `𝓔 ∪ ⋃_z F_z`.

**The automaton.** Let `Y` be the union of:
- the state set `Y_0` of the finite bounded automaton generating `G`;
- all sections of the finitely many elements of `⋃_z F_z`, a finite set of elements of `G`,
  because each element of `G` is finite-state;
- the finite set `𝓔`;
- `ĝ` for `g ∈ Y_0`.

`Y` is finite and closed under sections:
- `ĝ|_L = g ∈ Y_0`;
- sections of elements of `𝓔` lie in `𝓔 ∪ ⋃_z F_z`, and sections of those `F_z`-elements are
  in `Y` by construction.

So `Y` is the state set of a finite automaton, and `S = ⟨Y⟩ ≥ G` is self-similar. Every
element of `G` is bounded, since products of bounded automorphisms are bounded. So only the
`E`'s and hats need checking.

**Bounded.** It suffices to bound the number of level-`n` vertices where a state has a
nontrivial section.
- `G`'s states are bounded by hypothesis.
- For `E_h`, the candidates at level `n` are `0^n` (one vertex) and the vertices
  `0^k y w` with `k + 1 + |w| = n`, whose section is `ψ_{y−1}σ^k(h)|_w`.
  - Let `D` be a common depth of the finitary elements in `⋃_z ψ_zσ^k(G)`, `k ≥ k_0`. This is
    well defined because these sets range over finitely many finite sets, by periodicity.
  - Vertices with `k ≥ k_0` contribute only when `|w| < D`, that is, only for `k ≥ n−D`. That
    gives at most `(D+1)·L·d^D` vertices.
  - Vertices with `k < k_0` contribute at most `k_0·L·B`, where `B` is a common bound for the
    finitely many bounded elements of `⋃_z F_z` (each an element of `G`).
- `ĝ` has sections `E_g, 1, …, 1, g`, so it is bounded too.

So `S` is generated by a finite bounded automaton. It is therefore contracting (Bondarenko–
Nekrashevych; Nekrashevych, *Self-similar groups*, Thm 3.9.12; cited, not re-read).

## 5. Conclusion

- **Embedding.** By §2–§3, `G*_σ ↪ ⟨s, Ŝ⟩ ≤ V_d(S)`, since `s ∈ V_d` and all hats lie in `S`.
- **Host.** `S` is finite-state and contracting, so `V_d(S)` is a full contracting RSG (BBMZ
  Example `ex:rn` and the remark after Definition `def:contracting`).
- **BH.** Corollary `cor:RN_BH`.
- **PBH.** The proof of Proposition `prop:contr_to_simple` gives `V_d(S)` finitely presented
  and highly transitive on the orbit of a rational point, with finitely generated
  stabilizers of finite subsets (`prop:fin_gen_stabs`). That is an action of type (A). ∎

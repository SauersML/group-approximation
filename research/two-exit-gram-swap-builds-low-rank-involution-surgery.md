**ESTABLISHED.**  Let `E` and `K` be finite-dimensional Hilbert spaces and
let

```text
F_1,F_2,H_1,H_2:E -> K.
```

Combine the forward and backward exits as

```text
F=[F_1 F_2],                 H=[H_1 H_2]:E (+) E -> K.
```

There is a selfadjoint unitary `J` on `K` such that

```text
J F_i=H_i                    (i=1,2)                  (GS1)
```

if and only if

```text
F^*F=H^*H,                  F^*H=H^*F.               (GS2)
```

The same criterion applies if an ambient extension is allowed while all
four supplied exit vectors are kept fixed: adding orthogonal dimensions
cannot repair a failure of `(GS2)`.

Moreover, relative to any pre-existing reflection `J_0` on `K`, a
reflection satisfying `(GS1)` can be chosen so that

```text
rank(J-J_0)<=8 dim(E),
||J-J_0||_F<=2 sqrt(8 dim(E)).                        (GS3)
```

It agrees literally with `J_0` on the orthogonal complement of a
`J_0`-invariant subspace of dimension at most `8 dim(E)`.

## Boundary cell consequence

Let `U_1,U_2` be unitaries on a Hilbert space `H`, let `V:E -> H` be an
isometry, and set `P=1-VV^*`.  Let `C=C^*` have spectrum in `(-1,1)`, put

```text
D=(1-C^2)^(1/2),             G=C(1+C)^(-1),           (GS4)
```

and assume

```text
V^*U_iV=G                    (i=1,2).                 (GS5)
```

Define the forward/backward exit maps

```text
F_i=P U_iV,                  H_i=P U_i^(-1)V.         (GS6)
```

Whenever `(GS2)` holds, choose its reflection `J` and define on `E (+) H`

```text
X~=[ C       D V^*                 ]
   [ V D    -V C V^* (+) J on PH  ].                 (GS7)
```

Then `X~` is a selfadjoint unitary.  If `U~_i=1_E (+) U_i` and `Y_i=X~U~_i`,
then

```text
Y_i^3=1
```

on the `Y_i`-cyclic subspace generated by the added boundary `E`.  Thus the
same finite-rank reflection completes both source/exit cubic cells.  If the
old reflection on `PH` is `J_0`, `(GS3)` leaves it unchanged off an
`O(dim E)` subspace.

## BS(1,4) specialization: one mixed moment is the seam

Now put

```text
U_1=S^2,                      U_2=RS,
RSR^(-1)=S^4,                RV=V,
M_n=V^*S^nV.                                           (GS8)
```

The covariance and `RV=V` imply `M_n=M_(4n)`.  The common top-cell identity
`(GS5)` is exactly

```text
M_1=M_2=G=G^*.                                       (GS9)
```

The four exits become

```text
F_1=PS^2V,     H_1=PS^(-2)V,
F_2=PS^4V,     H_2=PS^(-1)V.                         (GS10)
```

Under `(GS9)`, the norm-Gram identity `F^*F=H^*H` is automatic.  The first
diagonal block of `F^*H=H^*F` is automatic as well.  If the second cubic
cell is individually reflection-compatible, its diagonal block says
precisely that `M_(-5)` is selfadjoint.  After those two individual-cell
conditions, the **only remaining joint condition** is

```text
boxed: M_(-3)=M_6.                                   (GS11)
```

Indeed the two mixed blocks are

```text
F_1^*H_2=M_(-3)-G^2,
H_1^*F_2=M_6-G^2.                                    (GS12)
```

Thus simultaneous two-cubic source/exit completion is not missing an
unspecified matrix factorization.  Its continuous seam is the single mixed
compressed-moment identity `(GS11)` (plus its adjoint).

This theorem does not assert that the separately extracted residual polar
carriers satisfy `(GS11)`.  Each cubic controls its own diagonal exit pair;
`(GS11)` couples the two cubic rows and is invisible to separate polar
rounding.

**ESTABLISHED** by `virtually-open-commensurators-certify-a2-kernels-proof`.

**Setting.** `G ↷ S` is of type `[A_2]` (Fournier-Facio--Wu--Zaremsky,
arXiv:2603.24687v2, Definition 1.3), through `ρ : G -> Sym(S)`, with kernel `K`. Points
are encoded as in `a2-kernel-removal-forces-recursive-kernel` (a): a word `c` together
with the index `i` of an orbit representative `x_i`.

`Γ <= G` is a finitely generated subgroup, given by finitely many words, with
`Γ ∩ K = 1`. For a subgroup `H <= G` and a finite set `F ⊆ S`, write `H_F` for the
pointwise stabilizer `H ∩ Stab_G(F)`.

**Definitions.**
- *Virtually open.* A subgroup `U <= H` is virtually open in `H` if some finite `F ⊆ S`
  has `[H_F : U ∩ H_F] < ∞`. With `F` empty, this is finite index.
- *Virtually open commensurator.* `VOComm_G(Γ)` is the set of `g in G` such that
  `Γ ∩ gΓg^-1` is virtually open in `Γ` and in `gΓg^-1`.
- *Effectively oligomorphic (EO).* `Γ ↷ S` is EO if there is an algorithm that, given
  `n >= 0`, outputs finitely many `n`-tuples of encoded points that meet every
  `Γ`-orbit on `S^n`. For each tuple `T` it must also output:
  - a finite generating set of `Γ_T`, as words;
  - finitely many encoded points that meet every `Γ_T`-orbit on `S`.

  In particular `Γ` has finitely many orbits on every `S^n`, and pointwise stabilizers
  of finite sets are finitely generated.

**(a) Structure.**
- `VOComm_G(Γ)` is a subgroup of `G` containing `Γ`.
- For `k in K`: `Γ ∩ kΓk^-1 = Γ ∩ k^-1Γk = C_Γ(k)`. Hence `k in VOComm_G(Γ)` iff
  `C_Γ(k)` is virtually open in `Γ`.

**(b) Oligomorphic certificate theorem.** Suppose `Γ ↷ S` is EO and `C_Γ(k)` is
virtually open in `Γ` for every `k in K`. Then `K` is recursive, so `G/K` has solvable
word problem.

The hypothesis holds in particular when `G` is generated by `Γ` and finitely many
elements of `VOComm_G(Γ)`.

**(c) Finite-index version.** Suppose instead that `Γ` merely has finitely many orbits
on `S`, and `C_Γ(k)` has finite index in `Γ` for every `k in K`. Then `K` is recursive.

This holds in particular when `G` is generated by `Γ` and elements `g` with
`Γ ∩ gΓg^-1` of finite index in both `Γ` and `gΓg^-1`. Examples are elements
normalizing `Γ`, and the stable letter in `permutation-hnn-realization-of-type-a-actor-is-a2`
(b). No relator of `Γ` is checked, so `Γ` need not be finitely presented.

**(d) HNN realizations.** Take the setting of
`permutation-hnn-realization-of-type-a-actor-is-a2`:
- `Γ ↷ X` is of type (A);
- `L = Γ*_ψ` acts through `t -> π`;
- `πD_1π^-1 = D_2`.

If `Γ ↷ X` is EO, and `D_1` and `D_2` are both virtually open in `Γ`, then the kernel
of `L ↷ X` is recursive, and `<Γ, π> <= Sym(X)` has solvable word problem.

This covers any `D_1` that contains a finite-index subgroup of the pointwise stabilizer
of a finite tuple, with `D_2 = πD_1π^-1` of the same kind.

**(e) The EO class is nonempty.** For `n >= 3`, Houghton's group `H_n` acting on its
rays `X = {1..n} x N` is of type (A) and EO. In it:
- the pointwise stabilizer of a finite set `F` is conjugate in `Sym(X)` to `H_n`,
  by an eventual translation `X -> X \ F`;
- its orbits on `X` are the points of `F` and `X \ F`.

**Obstruction (contrapositive).** Suppose some type `[A_2]` action has a non-recursive
kernel. Then for every finitely generated, effectively oligomorphic subgroup `Γ` with
`Γ ∩ K = 1`:
- some kernel element `k` has `C_Γ(k)` not virtually open in `Γ`;
- `G` is not generated by `Γ` and virtually open commensurators.

So a permutation HNN witness for `type-a-hnn-realization-with-unsolvable-word-problem`
must have one of two forms:
- an actor that is not EO. It may have infinitely many orbits on some `X^n`, as in
  suggestion 1 of that node, or non-finitely-generated tuple stabilizers, or
  non-computable tuple data;
- an edge group that is nowhere virtually open, such as the cyclic `D = <t>` of its
  Attempt 4.

The invariant is virtual openness of `C_Γ(k)`. Every member of the killed class dies at
the certificate step: `k` commutes with the Schreier generators of a finite-index
subgroup of some `Γ_F`.

**Not claimed.**
- Nothing is claimed for actors that are not EO, such as the FFWZ Theorem C actors of
  `a2-kernel-removal-forces-recursive-kernel` (c).
- Nothing is claimed for edge groups that are not virtually open.
- Amalgam realizations `Γ_1 *_C Γ_2` are not treated. (b) would apply if such an
  amalgam were of type `[A_2]` with `Γ_2 <= VOComm(Γ_1)`, but that is not a node.
- Uniformity is not claimed: the decision procedure depends on the finite data.

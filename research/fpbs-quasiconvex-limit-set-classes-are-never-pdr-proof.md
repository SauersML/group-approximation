# Proof

Notation is as in the claim. `Gamma` is a countable group, `(Z, mu)` an ergodic imp `Gamma`-action on a standard
Borel space, and `Z^2 = Z x Z` carries the diagonal action and `mu x mu`. All maps are Borel. An a.e. equivariant map
is made strictly equivariant on a conull invariant Borel set (countable group). We discard such null sets without
comment.

## 0. Imported inputs

- **(BB-Hopf)** Bevilacqua--Bowen, arXiv:2510.05459, Definitions 37--39 and Theorem A.1.
  - `Discont_cofinite(X)` is the set of points whose ergodic component is an atomic orbit and whose stabilizer is finite.
  - `Dis(X) = Discont_cofinite(X)` and `Con(X)` is its complement. Both are invariant and defined modulo null sets.
  - **Theorem A.1:** the restriction of the action to `Con(X)` is infinitely conservative. That is, for every
    measurable `B` inside `Con(X)` with positive measure, `Ret(B,p) = {g : gp in B}` is infinite for a.e. `p` in `B`.
- **(BB-PDR)** Definition 40: `Z` is PDR if for a.e. `(x,y)` there is a chain `x = x_1, ..., x_n = y` with
  `(x_i, x_{i+1})` in `Con(Z^2)`.
  - `Con(Z^2)` is only a class modulo null sets. So we read the definition as a property of that class: the
    relation generated by `Con(Z^2) \ N` is conull for **every** `mu x mu`-null set `N`. Remark 1.3 explains why this
    is the only consistent reading, and why it is the one BB's proof uses. The companion node
    `fpbs-hyperbolic-bb-criterion-obstruction` uses the same reading.
- **(Conv)** Let `Gamma` be hyperbolic. Every sequence of distinct elements `g_n` has a subsequence and points
  `a, b` in `dGamma` with `g_n -> a` and `g_n^{-1} -> b` in `Gamma ∪ dGamma`. Along that subsequence,
  `g_n -> a` uniformly on compact subsets of `dGamma \ {b}` (the convergence property; Tukia, Freden, Bowditch).
  For a subgroup `K`, the limit set `Lambda_K` is the set of accumulation points of `K o` in `dGamma`. It is closed and
  `K`-invariant, and `Lambda_{gKg^{-1}} = g Lambda_K`. If `K` is finite then `Lambda_K` is empty, and a finite-index
  subgroup has the same limit set.
- **(Q1)** An intersection of two quasiconvex subgroups is quasiconvex (Short 1991). Conjugates and finite-index
  overgroups of quasiconvex subgroups are quasiconvex.
- **(Q2)** For quasiconvex `H, K`: `Lambda_H ∩ Lambda_K = Lambda_{H ∩ K}` (Gitik--Mitra--Rips--Sageev 1998,
  Lemma 2.6; Swenson).
- **(Q3)** A quasiconvex subgroup `H` of infinite index has finite height `h(H)` (Gitik--Mitra--Rips--Sageev 1998).
  So if `g_1 H, ..., g_n H` are distinct cosets and `∩ g_i H g_i^{-1}` is infinite, then `n <= h(H)`.
- **(Zimmer)** `fpbs-hyperbolic-bb-criterion-obstruction`, item 4. For an amenable ergodic imp action of a
  nonelementary hyperbolic group with `Con(Z)` conull, the Zimmer map is `x -> delta_{xi(x)}` for a measurable
  equivariant `xi : Z -> dGamma`. This is used only in Corollary 4.

## 1. Theorem 1 (coset obstruction)

**Setting.**
- `L` is a proper subgroup of `Gamma`, and `c : Z -> Gamma/L` is equivariant.
- `P_x = {(x,y) : c(x) != c(y)}`, and `Delta_c` is its complement.
- `R` is a set of representatives of the double cosets `L \ (Gamma \ L) / L`.
- For `beta` in `R`, put `H_beta = L ∩ beta L beta^{-1}`, the stabilizer in `Gamma` of the pair of cosets
  `(L, beta L)`, and `Q_beta = c^{-1}(L) x c^{-1}(beta L)`. Each `Q_beta` is `H_beta`-invariant.

**Hypothesis (S).** For each `beta` in `R`, up to a null set:
- the `H_beta`-orbit relation on `Q_beta` has a Borel transversal `T_beta`, meaning a Borel set meeting every
  `H_beta`-orbit in exactly one point;
- `Stab_{H_beta}(q)` is finite for every `q` in `Q_beta`.

**Step 1.1 (orbit bookkeeping).** Every `Gamma`-orbit in `P_x` meets `⊔_{beta in R} Q_beta` in exactly one
`H_beta`-orbit, and for exactly one `beta`.
- *Existence.* Take `(x,y)` with `c(x) = gamma L` and `c(y) = gamma' L != gamma L`. Then `gamma^{-1} gamma'` is not
  in `L`, so `gamma^{-1} gamma' = l beta l'` with `beta` in `R` and `l, l'` in `L`. The point
  `l^{-1} gamma^{-1} (x,y)` has cosets `(L, beta l' L) = (L, beta L)`, so it lies in `Q_beta`.
- *Uniqueness.* Suppose `g(x,y)` is in `Q_beta` and `g'(x,y)` is in `Q_{beta'}`. Put `u = g' g^{-1}`. Then `u L = L`,
  so `u` is in `L`. Also `u beta L = beta' L`, so `beta'` is in `L beta L`, hence `beta' = beta`. So `u` is in
  `L ∩ beta L beta^{-1} = H_beta`.

Therefore `T = ⊔_beta T_beta` is a Borel set meeting every `Gamma`-orbit in `P_x` in exactly one point. For `p` in
`T_beta`, `Stab_Gamma(p)` fixes the pair of cosets of `p`, so `Stab_Gamma(p) = Stab_{H_beta}(p)`, which is finite.

**Step 1.2 (cross-coset pairs are dissipative).** We show `mu x mu(Con(Z^2) ∩ P_x) = 0`.
- Suppose not. `Con(Z^2)` and `P_x` are invariant and `P_x = Gamma T`, so `B = Con(Z^2) ∩ T` has positive measure.
- By Theorem A.1, `Ret(B, p)` is infinite for a.e. `p` in `B`.
- But if `gp` is in `B` inside `T`, then `gp` and `p` are two points of `T` in the same orbit, so `gp = p`. Hence
  `Ret(B, p)` lies in `Stab_Gamma(p)`, which is finite. This is a contradiction.

(Equivalently, `P_x` lies in `Discont_cofinite(Z^2)`: the ergodic components of `mu x mu` on the smooth set `P_x` are
atomic orbits of points with finite stabilizers.)

**Step 1.3 (conclusion).**
- Put `N = Con(Z^2) ∩ P_x`, which is null. Then `Con(Z^2) \ N` lies in `Delta_c`. `Delta_c` is an equivalence
  relation on `Z`, so it contains the relation generated by `Con(Z^2) \ N`.
- `P_x` has positive measure. The fibres `c^{-1}(gamma L) = gamma c^{-1}(L)` all have the same measure, which is
  positive because they cover `Z`, and there are at least two of them because `L` is proper. So
  `mu x mu(P_x) >= mu(c^{-1}(L)) mu(c^{-1}(beta L)) > 0`.
- No pair in `P_x` is joined by a chain in `Con(Z^2) \ N`. So `Z` is not PDR. ∎

**Remark 1.3 (the reading of Definition 40, and the exact failing step of BB).**
1. *The weak reading makes PDR vacuous.* A "some representative of `Con`" reading would make every ergodic imp action
   PDR. Pick `x_0` in `Z` and add the invariant null set `Gamma({x_0} x Z ∪ Z x {x_0})` to `Con`. Then every pair
   `(x,y)` is joined by the chain `x, x_0, y`. PDR could then never fail. Theorem 8.1 would then give max-cost 1 to
   every exact group with an amenable ergodic imp action with infinite non-atomic components. That includes free
   groups (take an ergodic component of the Maharam extension of a boundary action), whose cost exceeds 1. The same
   device would also void `fpbs-hyperbolic-bb-criterion-obstruction`.
2. *BB's proof uses exactly the modulo-null content.* Claim 1 in the proof of Theorem 7.1 is an a.e. statement about
   `(x,y)` in `Cont(X^2)`. Claim 2 applies it to pairs of points of a Poisson configuration `Pi`. By the Mecke
   (Slivnyak) formula, for a fixed null set `N` in `Z^2`, a.s. no pair of distinct points of `Pi` lies in `N`.
3. *Failing step for our actions.* Take the null set `N = Con(Z^2) ∩ P_x` of Step 1.3. By item 2, a.s. no pair of
   distinct Poisson points lies in `N`. So a.s. every pair of Poisson points in different cosets lies outside
   `Con(Z^2)`, and a chain of Poisson points can join only points with the same coset.
   - Such a cross-coset pair has only finitely many joint returns to `fS x gS`, so the infinite-monkey argument of
     Claim 1 gives no a.s. percolation edge between `E(x)` and `E(y)`.
   - So BB's derivation of Claim 2 from Claim 1 and PDR cannot cross cosets. That is the step where the route breaks,
     before the cost bound (10)--(11).
   - We do not claim that `hat E(Pi) ∪ G` is disconnected for every percolation parameter. The theorem is that the
     PDR hypothesis fails.

**Remark 1.4 (the hypothesis is sharp).** Let `Gamma = Z^2` act on `Z = Z^2 / L` with counting measure, where
`L = 0 x Z` and `c` is the identity. Then `H_beta = L` is infinite, and every pair of points has infinite stabilizer.
So `Con(Z^2) = Z^2` and the action is PDR, as it must be, since `Z^2` is amenable with fixed price 1. The only
hypothesis of Theorem 1 that fails here is finiteness of stabilizers.

## 2. Theorem 2 (private limit points induce)

Let `Gamma` be hyperbolic, `L` a proper subgroup, and `xi : Z -> dGamma` equivariant with
`mu(xi^{-1}(Gamma Lambda*_L)) > 0`.

**Lemma 2.1 (private part).**
1. `Lambda*_L` is Borel and `L`-invariant.
2. For cosets `gamma L` and `gamma' L`, the sets `gamma Lambda*_L` and `gamma' Lambda*_L` are equal if the cosets
   are equal, and disjoint otherwise.
3. For `beta` not in `L`, `Lambda*_L` is disjoint from `beta Lambda_L`.

*Proof.*
1. `eta` in `Lambda_L` fails to be private exactly when `eta` lies in `gamma^{-1} Lambda_L` for some `gamma` not in
   `L`. So `Lambda*_L = Lambda_L \ ∪_{gamma not in L} gamma^{-1} Lambda_L`, a closed set minus a countable union of
   closed sets. For invariance, let `l` be in `L` and `eta` in `Lambda*_L`. Then `l eta` is in `Lambda_L`. If
   `gamma l eta` is in `Lambda_L`, then `gamma l` is in `L`, so `gamma` is in `L`.
2. Equality follows from invariance. Suppose `gamma eta_0 = gamma' eta_1` with `eta_0, eta_1` in `Lambda*_L`. Then
   `gamma'^{-1} gamma eta_0 = eta_1` is in `Lambda_L`, so `gamma'^{-1} gamma` is in `L`.
3. If `eta = beta eta'` with `eta'` in `Lambda_L`, then `beta^{-1} eta = eta'` is in `Lambda_L` while `beta^{-1}` is
   not in `L`. So `eta` is not private. ∎

**Step 2.2 (the induction map).**
- By Lemma 2.1(2), `Gamma Lambda*_L = ⊔_{gamma L} gamma Lambda*_L`, and `kappa(eta) =` the coset `gamma L` with
  `eta` in `gamma Lambda*_L` is a Borel equivariant map from `Gamma Lambda*_L` to `Gamma/L`.
- The set `xi^{-1}(Gamma Lambda*_L)` is invariant and has positive measure, so it is conull by ergodicity.
- Hence `c = kappa ∘ xi : Z -> Gamma/L` is defined a.e. and equivariant, `c^{-1}(L) = xi^{-1}(Lambda*_L)`, and
  `Z = Ind_L^Gamma c^{-1}(L)`.

**Lemma 2.3 (proper discontinuity off the limit set).** Let `K` be a subgroup of `Gamma` and
`Omega = dGamma \ Lambda_K`. For every compact `C` in `Omega`, the set `{k in K : kC ∩ C != ∅}` is finite. In
particular, point stabilizers in `K` of points of `Omega` are finite.

*Proof.* If `K` is finite there is nothing to prove. Otherwise, suppose infinitely many distinct `k_n` in `K` satisfy
`k_n C ∩ C != ∅`. By (Conv), pass to a subsequence with `k_n -> a` and `k_n^{-1} -> b`. Both points are
accumulation points of `K o`, so both lie in `Lambda_K`, and therefore outside `C`. Since `b` is not in `C`,
`k_n -> a` uniformly on `C`. Choose an open `U` containing `a` whose closure misses the closed set `C`, which is
possible because `a` is not in `C`. For large `n`, `k_n C` lies in `U`, so `k_n C ∩ C` is empty. This is a
contradiction. ∎

**Lemma 2.4 (Borel transversal).** Let a countable group `H` act properly discontinuously, in the sense of
Lemma 2.3, on an open subset `Omega` of `dGamma`. Let `Q` be a standard Borel `H`-space with a Borel equivariant map
`pi : Q -> Omega`. Then the `H`-orbit relation on `Q` has a Borel transversal, and stabilizers in `Q` are finite.

*Proof.*
- **Finite stabilizers.** `Stab_H(q)` lies in `Stab_H(pi(q))`, which is finite by the case `C = {pi(q)}`.
- **Finite orbit slices.** Fix a countable base `V_1, V_2, ...` of open sets of `Omega` whose closures are compact
  and contained in `Omega` (`Omega` is locally compact and second countable). For `q` in `Q`, let `k(q)` be the least
  `j` with `H pi(q) ∩ V_j != ∅`. Then `k` is Borel, since `H pi(q) ∩ V_j != ∅` is the countable union over `h` of
  `{h pi(q) in V_j}`, and `k` is `H`-invariant. Put `S(q) = {hq : h pi(q) in V_{k(q)}}`, a subset of the orbit `Hq`
  that depends only on the orbit and is nonempty.
- **`S(q)` is finite.** Fix `h_0` with `omega = h_0 pi(q)` in `C = closure(V_{k(q)})`. Every `h` with `h pi(q)` in
  `C` has `(h h_0^{-1}) omega` in `C`, so `h h_0^{-1}` lies in the finite set `{g : gC ∩ C != ∅}`.
- **The transversal.** Fix a Borel linear order `<` on `Q`, for instance by a Borel isomorphism with a subset of the
  reals. Let `T` be the set of `q` with `pi(q)` in `V_{k(q)}` and `q <= hq` for every `h` in `H` with `h pi(q)` in
  `V_{k(q)}`. This is a countable intersection of Borel conditions, so `T` is Borel. It meets each orbit in exactly
  one point, the `<`-least element of the finite set `S(q)`. ∎

**Proof of Theorem 2.** Apply Theorem 1 to the map `c` of Step 2.2. We check hypothesis (S) for `beta` not in `L`.
- Let `(x,y)` be in `Q_beta`. Then `c(x) = L`, so `xi(x)` is in `Lambda*_L`.
- By Lemma 2.1(3), `xi(x)` is not in `beta Lambda_L = Lambda_{beta L beta^{-1}}`.
- Since `H_beta` lies in both `L` and `beta L beta^{-1}`, we have `Lambda_{H_beta} ⊂ Lambda_L ∩ beta Lambda_L`. So
  `xi(x)` lies in `Omega_beta = dGamma \ Lambda_{H_beta}`.
- Put `pi(x,y) = xi(x)`. This is an `H_beta`-equivariant Borel map from `Q_beta` to `Omega_beta`, and `H_beta` acts
  properly discontinuously on `Omega_beta` by Lemma 2.3.
- Lemma 2.4 gives the transversal `T_beta` and finite stabilizers.

Theorem 1 then shows that `Z` is not PDR. ∎

No quasiconvexity, malnormality or non-atomicity was used. `L` may be any proper subgroup. The only input is the
convergence property.

## 3. Theorem 3 (quasiconvex descent)

Let `H` be quasiconvex of infinite index, with `mu(xi^{-1}(Gamma Lambda_H)) > 0`.
- For a finite set `C = {g_1 H, ..., g_n H}` of distinct cosets, put `K_C = ∩_i g_i H g_i^{-1}`. This depends only on
  the cosets, and satisfies `K_{gamma C} = gamma K_C gamma^{-1}`.
- Call `C` **charged** if `mu(xi^{-1}(Gamma Lambda_{K_C})) > 0`.

**Step 3.1 (a maximal charged collection).**
- `{H}` is charged, by hypothesis.
- If `C` is charged, then `Lambda_{K_C}` is nonempty, so `K_C` is infinite, and by (Q3) `|C| <= h(H)`.
- So we may fix a charged `C` of maximal size `n`, and put `K = K_C`. It is quasiconvex by (Q1).

**Step 3.2 (the overgroup).** Let `L = {gamma : gamma C = C}` be the setwise stabilizer of `C` under left
multiplication.
- `gamma g_i H = g_i H` exactly when `gamma` is in `g_i H g_i^{-1}`. So `K` is the kernel of the permutation
  representation `L -> Sym(C)`. Hence `K` is normal in `L` and `[L : K] <= n!`.
- `K` lies in `g_1 H g_1^{-1}`, which has infinite index. So `K` and `L` have infinite index, and `L` is proper.
- `Lambda_L = Lambda_K`, because `K` has finite index in `L`.

**Step 3.3 (maximality makes most of `Lambda_K` private).** Let `gamma` be outside `L`.
- `C ∪ gamma C` is a collection of more than `n` distinct cosets, with `K_{C ∪ gamma C} = K ∩ gamma K gamma^{-1}`.
- By maximality it is not charged: `mu(xi^{-1}(Gamma Lambda_{K ∩ gamma K gamma^{-1}})) = 0`.
- By (Q1) and (Q2), `Lambda_{K ∩ gamma K gamma^{-1}} = Lambda_K ∩ gamma Lambda_K`.

Put `S = Lambda_K \ ∪_{gamma not in L} (Lambda_K ∩ gamma Lambda_K)`.
- **`S` lies in `Lambda*_L`.** Let `eta` be in `S` and let `delta eta` be in `Lambda_L = Lambda_K` for some `delta`
  not in `L`. Then `eta` is in `Lambda_K ∩ delta^{-1} Lambda_K` with `delta^{-1}` not in `L`, which was removed.
- **`Gamma S` is charged.** `Gamma Lambda_K \ Gamma S` lies in the countable union
  `∪_{gamma not in L} Gamma(Lambda_K ∩ gamma Lambda_K)`, and each term has `xi`-preimage of measure zero. Since
  `Gamma Lambda_K` is charged, so is `Gamma S`.
- Hence `mu(xi^{-1}(Gamma Lambda*_L)) > 0`.

Theorem 2 applied to `L` shows that `Z` is not PDR. ∎

## 4. Corollary 4

Let `Gamma` be nonelementary hyperbolic and let `(Z, mu)` be a BB certificate: an amenable, ergodic, PDR imp action
with infinite non-atomic components.
- `Con(Z)` is conull, since the components are non-atomic.
- By (Zimmer), there is an equivariant `xi : Z -> dGamma`. Its boundary class is `nu = [xi_* mu']` for a probability
  measure `mu'` equivalent to `mu`.
- Let `H` be quasiconvex of infinite index. If `nu(Gamma Lambda_H) > 0`, Theorem 3 contradicts PDR. So
  `nu(Gamma Lambda_H) = 0`.

The listed cases follow.
- **Free-subgroup codes.** A ray, Schottky or paperfolding code in a quasiconvex free subgroup `F` of infinite index
  produces points of `iota(dF) = Lambda_F`, so a class carried by such codes and their translates is carried by
  `Gamma Lambda_F`. This covers the rotation, zero-entropy and positive-entropy codes of the earlier lanes. Ping-pong
  subgroups `<a^N, b^N>` for large `N` are quasiconvex and free of infinite index, so no malnormality statement (M')
  is needed.
- **Quasiconvex surface or quasi-Fuchsian subgroups.** They have infinite index in a nonelementary hyperbolic group
  that is not virtually a surface group. Surface groups themselves have cost above 1.
- **Atomic loxodromic classes.** Take `H = <h>`, so `Lambda_H = {h^+, h^-}`. ∎

## 5. Consistency checks

- **Theorem 2 with `L = Gamma`.** There is only one coset, and Theorem 1 needs `L` proper. Nothing is claimed.
- **Normal subgroups.** Take the fibre `N` of a fibred hyperbolic 3-manifold group. Then `Lambda_N = dGamma` is
  `Gamma`-invariant, so `Lambda*_N` is empty. Theorem 2 is vacuous and Theorem 3 does not apply, since `N` is not
  quasiconvex. This is correct: if two cosets have the same limit set, the boundary cannot tell them apart.
- **Induced actions directly.** Let `Y` be any imp `L`-action with `L` malnormal and quasiconvex, and let
  `Z = Ind_L^Gamma Y`. Then `H_beta` is trivial, so cross-coset pairs have trivial stabilizers, and they form a
  smooth part of `Z^2`. This agrees with Theorem 1 even with no boundary map.
- **Lebesgue and Patterson--Sullivan classes.** For a cocompact lattice in `Sp(n,1)` or `SO(n,1)`, and for
  quasiconvex `H` of infinite index, `Lambda_H` has Hausdorff dimension `delta_H`, which is less than `delta_Gamma`.
  So `Gamma Lambda_H` is null for the Patterson--Sullivan class (in the lattice case this is the Lebesgue class).
  Corollary 4 does not see these classes; the Dini claim kills them. The two obstructions are complementary.
- **Free groups and surface groups.** Their cost exceeds 1, so every candidate must die. The corollary removes
  candidates and proves nothing false.

## 6. What remains

A BB certificate for a cocompact `Sp(n,1)` lattice needs a non-atomic ergodic quasi-invariant class on `dGamma` with
three properties:
- it is singular to every Dini measure;
- no measure in the class is shadow-summable;
- it is null on `Gamma Lambda_H` for every quasiconvex `H` of infinite index.

The existence of such "quasiconvex-null small" classes is the named open statement of the claim.

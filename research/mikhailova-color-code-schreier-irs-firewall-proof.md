Write `F=F(X)`, `N=ker(q)`, `G=F x F`, and
`M={(u,v):q(u)=q(v)}`.  Let `S_U` act on its universal color space
`X_U`.

## The commuting-centralizer normal form

By [[mikhailova-left-right-soficity-is-one-color-code]], GKP soficity is
equivalent to a homomorphism `Phi:G->S_U` and `xi in X_U` satisfying

```text
d_U(Phi(g)xi,xi)=1_(g notin M).                         (MSP1)
```

Set

```text
a(w)=Phi(w,1),       b(w)=Phi(1,w).
```

The ranges of `a` and `b` commute.  Since `(n,1) in M` for
`n in N`, equation `(MSP1)` gives `(MSI1)`; since `(w,w) in M`,
it gives `(MSI2)`; and applying it to `(w,1)` gives `(MSI3)`.

Conversely, every `(u,v)` has the factorization

```text
(u,v)=(uv^(-1),1)(v,v).                                (MSP2)
```

The second factor fixes `xi` by `(MSI2)`.  Therefore

```text
d_U(a(u)b(v)xi,xi)=d_U(a(uv^(-1))xi,xi),
```

which is zero exactly when `uv^(-1) in N`, equivalently
`q(u)=q(v)`, and is one otherwise.  Thus `(MSI1)--(MSI3)` imply
`(MSP1)`.

This also exhibits the centralizer constraint explicitly:

```text
b(F) is contained in C_{S_U}(a(F)),
b(w)xi=a(w)^(-1)xi.                                    (MSP3)
```

It is the implementation of right translation on the code orbit, not just
a second unrelated sofic action.

## Faithful amplification does not change the code

The homomorphism `Phi` in `(MSP1)` need not initially be injective.
This can always be repaired without changing a single color coefficient.

The actor `G=F x F` is residually finite.  Choose homomorphisms to finite
groups

```text
rho_n:G->Q_n
```

so that every fixed `g != 1` has `rho_n(g) != 1` for all sufficiently
large `n`.  Let `Q_n` act on itself regularly.  Represent `Phi` on
finite sets `A_n` by permutations `phi_n(g)`, and represent `xi` by
colorings `c_n:A_n->N`.  On `A_n x Q_n` use

```text
phi'_n(g)(s,t)=(phi_n(g)s,rho_n(g)t),
c'_n(s,t)=c_n(s).                                      (MSP4)
```

The color agreement proportion in `(MSP4)` is exactly the old one,
because the color ignores the second coordinate.  For every nonidentity
`g`, however, the regular permutation by `rho_n(g)` has no fixed
point eventually.  Hence `[phi'_n(g)]_U` has Hamming distance one from
the identity.  The resulting `Phi':G->S_U` is injective and still
satisfies `(MSP1)`.

The same observation shows that the ordinary stabilizer of a uniformly
chosen point in these amplified models converges to `{1}`: every fixed
nonidentity element has zero fixed-point proportion eventually.  The
subgroup `M` survives only as the stabilizer of the external color point
`xi`.

## Finite presentation reduces all invariance tests to finitely many

Suppose `H=<X|R>`, so `N` is the normal closure of the finite set
`R`.  Because the ranges of `a` and `b` commute, the map

```text
D(w)=a(w)b(w)
```

is a homomorphism.  If `D(x)xi=xi` for every free generator `x in X`,
then `D(w)xi=xi` for every `w in F`.

Assume also `a(r)xi=xi` for `r in R`.  For `f in F`, diagonal
invariance gives `a(f)^(-1)xi=b(f)xi`.  Therefore

```text
a(frf^(-1))xi
 =a(f)a(r)a(f)^(-1)xi
 =a(f)a(r)b(f)xi
 =a(f)b(f)a(r)xi
 =xi.                                                   (MSP5)
```

The stabilizer of `xi` is a subgroup, so `(MSP5)` implies
`a(N)xi=xi`.  This proves the finite reduction `(MSI5)`.  Notice that
only separation remains an infinite family: every word outside `N` must
move the color point by the maximal distance one.

## Pointed Schreier convergence is exactly the residual-finiteness route

A finite pointed Schreier `G`-set is `G/L_i` for a finite-index
subgroup `L_i`.  Rooted local convergence

```text
(G/L_i,L_i)->(G/M,M)
```

is precisely Chabauty convergence `L_i->M`.

For a finite presentation, `M` is finitely generated.  Indeed it is
generated by

```text
{(x,x):x in X} union {(r,1):r in R};                    (MSP6)
```

the diagonal generators conjugate `(r,1)` to
`(frf^(-1),1)`, and `(MSP2)` handles every element of `M`.
If `L_i->M`, all generators in `(MSP6)` lie in `L_i` eventually,
so `M<=L_i` eventually, while every `g notin M` is eventually
excluded.  Thus `M` is separable.  Conversely, separability lets one
enumerate `G minus M`, intersect finitely many finite-index overgroups
of `M`, and obtain such a convergent sequence.  Hence pointed finite
Schreier approximation is equivalent to separability of `M`.

For completeness, separability of `M` is equivalent to residual
finiteness of `H`.  If `H` is residually finite, finite quotients of
`H` separate every point outside the diagonal in `H x H`, and their
pullbacks separate every point outside `M`.  Conversely, let a
finite-index subgroup `L<=F x F` contain `M` but exclude `(w,1)`.
Because `L` contains the diagonal, the set

```text
K={f in F:(f,1) in L}
```

is a finite-index normal subgroup of `F`, and
`(u,v) in L` exactly when `uv^(-1) in K`.  Since `M<=L`, one has
`N<=K`; since `(w,1) notin L`, one has `w notin K`.  Thus the
finite quotient `F/K` factors through `H` and separates `q(w)`
from the identity.

## Uniform roots see an IRS, not the color stabilizer

For every finite `G`-set, the law of the stabilizer of a uniformly
chosen point is conjugation invariant.  Every weak limit is therefore an
IRS.  A point mass `delta_M` is an IRS if and only if `M` is normal.

The surjection `q x q:G->H x H` sends `M` onto the diagonal
`Delta_H` and has kernel contained in `M`.  Consequently `M` is
normal exactly when `Delta_H` is normal.  The diagonal is normal in
`H x H` exactly when `H` is abelian: conjugating `(h,h)` by
`(a,1)` forces `aha^(-1)=h` for all `a,h`.  Hence for the intended
nonabelian host, `delta_M` cannot be a uniform-root limit at all.

At a finite level the analogous color equality set

```text
K_{n,s}={g:c_n(phi_n(g)^(-1)s)=c_n(s)}
```

need not be a subgroup.  For example, in the regular action of `C_3`,
color two adjacent points red and the third blue; at a red root the
corresponding equality set has two elements and is not a subgroup.  GKP's
normalized color agreements can converge to the zero/one subgroup pattern
of `M` without the finite models carrying stabilizer subgroups close to
`M`.

This proves the firewall: pointed Schreier limits demand separability,
uniform roots demand an IRS, and faithful actor amplification sees the
trivial ordinary stabilizer.  None is equivalent to the external-color
criterion `(MSI1)--(MSI3)`.

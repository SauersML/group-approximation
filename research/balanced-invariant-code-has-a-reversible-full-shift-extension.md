The invariant scalar code for the balanced triangular rule on
A_4 x Z admits a zero-preserving nonlinear reversible cellular
automaton on the entire enlarged scalar full shift. Its memory
subgroup H has order at most 192. On each finite H-block, use
the code involution on block patterns occurring in the code and
the identity on every other pattern. This is an equivariant
involution, so it glues across all left H-cosets.

This closes general nonlinear reversible extension. An injective
extension of the special form x+B Q_s with B linear remains
unproved. The known two-term extension is noninjective; one
explicit nonzero four-term operator vanishing on the code leaves
all its complement collisions unchanged. Other corrections are
not excluded.

Any full-shift cellular automaton supported in a finite subgroup
is surjunctive by finite block counting. Thus this construction
is not a Gottschalk counterexample. A subsequent group audit
proves the entire current source symmetry group elementary
amenable, excluding a counterexample even with memory generating
an infinite subgroup; see
`current-prefix-symmetry-group-is-elementary-amenable`.

**Theorem.** Let `G` be finitely generated with a finite symmetric generating set `S`. Let
`a: G ↷ (X, nu)` be a free ergodic p.m.p. action with nonsofic orbit relation. On
`X x [0,1]^E`, with the diagonal action, let `R^a_p` be the relation generated by moving the root along
edges open at level `p`: `(x, xi) ~ g^-1.(x, xi)` for `g` in the open cluster of `1` in `omega_p(xi)`.
Then:

1. `{ p : R^a_p is sofic }` is a down-set containing `[0, p_c)`. It also contains `p_c` if `Cay(G,S)` is
   nonamenable.
2. `R^a_p` is nonsofic for every `p > p_u`.

So `p_c <= p_sof(a,S) <= p_u`. The same holds with "hyperlinear" in place of "sofic", for actions with
non-Connes-embeddable orbit relation.

**Consequence.** If `R^a_p` is sofic for some `p > p_c`, then `p_c < p_u` on `Cay(G,S)`. This applies to
the residually finite Kazhdan groups of `kun-thom-free-nonsofic-action`. Their Bernoulli cluster relations
are sofic at every level, so `nonsofic-groups-have-cluster-soficity-threshold-in-pc-pu` gives nothing for
them.

**Proof** (part 2 artifact, Section 5).
- `R_a` embeds in the orbit relation of `a x Bernoulli` as a class-bijective factor. So that orbit relation
  is nonsofic.
- Above `p_u` the unique infinite cluster identifies `R^a_p` on the infinite cluster with that orbit
  relation restricted to a set of measure `theta(p)`.
- Restriction, amplification and subrelation permanence (part 1, Lemmas 1.1--1.5) finish the argument.

Use the new algebraic PCP as the constant-query outer verifier for the Boone
computation.  Install its low-degree/Hadamard auxiliary coordinates privately,
retain the shared proof-bit incidence, and compile each fixed local binary
predicate by the S3 radical packet.  The PCP soundness gap then supplies
positive rejected-check density, while the local packet theorem converts that
density into normalized-HS relator energy.

The attraction is that the new PCP avoids a composition tower, reducing the
number of consistency interfaces which must survive groupification.  The
remaining coordinate-atlas theorem is nevertheless substantial: ordinary PCP
Hamming soundness does not itself define sites or shared binary observables in
an arbitrary matrix microstate.

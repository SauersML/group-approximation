An element of `ker p_1` has the form `(1,b)`, while an element of `ker p_2`
has the form `(a,1)`.  Their intersection is therefore just `(1,1)`.  Hence
if the two kernels are equal, both are trivial.  This proves `1=>2`.

Assume both projections are injective.  Since `p_1:K->H_1` is also surjective
by definition, it is an isomorphism.  Define

```text
phi = p_2 o p_1^(-1): H_1 -> H_2.
```

The second projection is likewise an isomorphism onto `H_2`, so `phi` is an
isomorphism and every element of `K` is uniquely `(h,phi(h))`.  This is
`(PKB1)`, proving `2=>3`.  A graph of an isomorphism plainly has both
coordinate kernels trivial, giving `3=>1`.

If `K` is generated by `(a_s,b_s)`, `(PKB1)` forces `phi(a_s)=b_s`.
Conversely a homomorphism with those generator values contains every generator
pair in its graph, and hence contains `K`; surjectivity onto both generated
images gives equality when the homomorphism is an isomorphism.

For the finite-state procedure, breadth-first traversal of `H_1` records for
each reached left state the right product of the same generator word.  A
second, different right label on the same left state gives two words with the
same left evaluation and different right evaluation; their quotient is the
claimed kernel witness.  If no conflict occurs, the stored label is a
well-defined homomorphism because every Cayley edge respects multiplication.
The generators make it surjective onto `H_2`; injectivity, or the symmetric
traversal, completes the test.

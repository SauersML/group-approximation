ESTABLISHED.  Let `K=F_(2^n)`, `n>=3`, choose a field generator
`alpha`, and choose

```text
gamma notin {0,1,alpha,1+alpha},     delta=1+alpha+gamma.  (RPC1)
```

For every `x in K^*` add the four-coordinate view

```text
P_x={x,alpha x,gamma x,delta x}.                           (RPC2)
```

Its four points are distinct and sum to zero, so an affine simplex word has
even parity on `P_x`.  Ask for one PVM supported on the even-parity strings.
Every nonzero coordinate occurs in at most four such views, so this is one
four-local answer template and adds degree at most four.  The finitely many
cases `n<3` can use a fixed exceptional template.

Let `C_n` be the affine simplex code and identify its dual evaluation space
with

```text
W=F_2 direct-sum K,       w_x=(1,x).                       (RPC3)
```

If `L` is the span in `Lambda^2 W` of the local jointness directions from
the views `(RPC2)`, then

```text
L=Lambda^2 W.                                               (RPC4)
```

In fact the single pair `{x,alpha x}` inside each view already suffices.
More quantitatively, for every nonzero alternating form `beta` on `W`,

```text
Pr_(x in K^*)[beta(w_x,w_(alpha x))=1] >= 1/4.             (RPC5)
```

Thus the overlay has a uniform full-exterior-square gap, stronger than a
gap only on decomposable wedges.

Let `Gamma` be the exact homogeneous solution group generated by these
`N` coordinate reflections, with abelianization `(RPC3)`, after adjoining
the views `(RPC2)`.  Its maximal class-two quotient is abelian.  Equivalently,

```text
gamma_2(Gamma)=gamma_3(Gamma).                              (RPC6)
```

It follows inductively that every nilpotent quotient of `Gamma` is abelian;
there are no higher nilpotent layers left to audit.  Any remaining exact
contextual quotient must be genuinely nonnilpotent, with a commutator core
equal to its own commutator with the ambient group.

There is also a same-dimension linear rounding bound on the entire class-two
sector.  Suppose an exact class-two reflection table `{Q_x}` has abelianized
labels `(RPC3)`, and set

```text
eta=E_(x in K^*) ||[Q_x,Q_(alpha x)]||_2^2.                (RPC7)
```

Then there are commuting reflections `{Q'_x}` on the same tracial matrix
algebra such that

```text
E_x ||Q_x-Q'_x||_2^2 <= 4 eta.                             (RPC8)
```

If the original table obeys the exact homogeneous parity presentation of
`C_n`, the rounded table does too and hence is the coordinate marginal of one
global affine-codeword PVM.  This closes the exact and robust central
class-two obstruction.  It does not yet round arbitrary non-class-two local
PVMs: the remaining gate is exclusion or stability of the nonnilpotent
contextual core in `(RPC6)`.

## Exact-group boundary

For the canonical radial-only presentation, the assertion that the
abelianization is `(RPC3)` requires the cyclic gcd condition isolated in
`radial-only-group-needs-a-cyclic-gcd-audit`.  If the radial checks are only
being adjoined to an already specified simplex presentation, the identity of
that base presentation must be named: abelianization alone does not define
its nonnilpotent solution group.

Under the exact-simplex hypothesis there is now a stronger finite-quotient
result.  `radial-simplex-has-no-nonabelian-finite-solvable-quotient` proves
that every finite solvable quotient is abelian.  Hence a surviving finite
contextual quotient must contain a nonabelian finite simple composition
factor; the remaining problem is genuinely semisimple, not an unexamined
odd-primary affine extension.

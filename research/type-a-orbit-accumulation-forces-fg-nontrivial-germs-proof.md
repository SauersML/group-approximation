**Finite generation.** `G_x/N_x` is a quotient of `G_x`, which is finitely
generated by hypothesis 1.

**Pair orbits versus stabilizer orbits.** Map each `G_x`-orbit `G_x y` in
`Γx \ {x}` to the `Γ`-orbit of the two-element set `{x, y}`. This is well
defined. It is at most two-to-one. Suppose `γ{x,y} = {x,y'}` for some `γ ∈ Γ`.
- If `γx = x`, then `y' = γy ∈ G_x y`.
- Otherwise `γx = y'` and `γy = x`. If `γ_1` and `γ_2` both occur in this way,
  with `y'_i = γ_i x` and `γ_i y = x`, then `γ_2 γ_1^(-1)` fixes
  `x = γ_2 y = γ_2 γ_1^(-1) x`. It maps `y'_1` to `y'_2`. So the second kind
  contributes at most one `G_x`-orbit.

By hypothesis 2 there are finitely many `Γ`-orbits of two-element subsets. So
`G_x` has finitely many orbits on `Γx \ {x}`.

**Nontriviality.** Suppose `G_x = N_x`. Let `g_1, ..., g_k` generate `G_x`.
Each `g_i` is the identity on an open neighbourhood `U_i` of `x`, so every
element of `G_x` is the identity on `U = U_1 ∩ ... ∩ U_k`. As `X` is Hausdorff
and `x` is an accumulation point of `Γx`, the neighbourhood `U` contains
infinitely many points `y ≠ x` of `Γx`. Each is fixed by `G_x`, so each
`{y}` is a separate `G_x`-orbit in `Γx \ {x}`. That contradicts the previous
paragraph. Hence `G_x/N_x` is nontrivial.

**First consequence.** An element of `Stab_H(x)` that lies in `N_x` agrees near
`x` with the identity. Quasi-analyticity makes it the identity, so
`Stab_H(x) ∩ N_x = 1` and `Stab_H(x)` embeds in `G_x/N_x`. For
`H = PGL_m(Q)` on `RP^(m-1)`, two projective maps that agree on a nonempty open
set are equal, and `Stab_H(x)` is the parabolic stabilizer of the rational
point `x`.

**Calibration.** The germ at `0^ω` of an
element fixing it is a prefix replacement `0^a w ↦ 0^b w` near `0^ω`. That
gives the homomorphism `a - b` onto `Z`, and its kernel is `N_x`.

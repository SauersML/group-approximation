Let `J` be weakly purely infinite with `P_pi(J)=0`, let `I ideal J`, and
suppose that the nonzero quotient

```text
Q=J/I
```

is purely infinite.  Then `I` is nonzero, `I` and `J` are radical-free
weakly-but-not-plain purely infinite, and the extension

```text
0 -> I -> J -> Q -> 0
```

is essential.  Equivalently, its Busby map `tau:Q -> Q(I)` is injective.

The seam is hereditary-self-similar.  For every nonzero hereditary
subalgebra `C subset J`, the intersection `C intersect I` is nonzero and is
essential in `C`.  If the image of `C` in `Q` is nonzero, then

```text
0 -> C intersect I -> C -> image(C) -> 0
```

is another essential extension with radical-free weakly-but-not-plain terms
on the left and in the middle, and a purely infinite quotient.

Let `n` witness weak pure infiniteness.  Under the inclusion
`Cu(I) subset Cu(J)`, the order ideal `Cu(I)` is defect-essential: for every
nonzero `x in Cu(J)` there is a nonzero `z in Cu(I)` such that

```text
z <= infinity x,
z < 2z <= ... <= nz = infinity z.
```

On the other hand, pure infiniteness of the quotient says that for every
`x in Cu(J)` there is `w in Cu(I)` lying in the principal order ideal
generated by `x` such that

```text
2x <= x+w,                 w <= infinity x.
```

Thus the quotient has removed every duplication defect, while every nonzero
principal region upstairs still contains such a defect in the essential
kernel.  Iteration gives `infinity x=nx <= x+(n-1)w`; the exact unresolved
comparison is whether the kernel term can be absorbed while retaining the
first copy of `x`.

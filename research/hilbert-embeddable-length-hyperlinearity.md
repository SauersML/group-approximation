Call a conjugation-invariant length `ell` on a finite group `K` (real,
symmetric, `ell(k)=0` iff `k=1`) **Hilbert embeddable** when the kernel
`(a,b) |-> ell(a^(-1)b)` is conditionally negative definite.

1. **Character criterion.**  Expanding `ell` in irreducible characters,
   `ell = sum_i b_i chi_i`, the length is Hilbert embeddable if and only if

   ```text
   b_i <= 0   for every nontrivial irreducible chi_i.
   ```

2. **Realization.**  If `ell` is Hilbert embeddable then for every `t>0` and
   `epsilon>0` there is a unitary representation `rho` of `K` with
   `|tr rho(k) - exp(-t ell(k))| < epsilon` for all `k`; consequently the
   normalized-Hilbert--Schmidt distance satisfies
   `||rho(a)-rho(b)||_2^2 = 2(1-exp(-t ell(a^(-1)b))) + O(epsilon)`, which for
   `ell` bounded by `1` is comparable to `ell(a^(-1)b)` with constants
   depending only on `t`.
3. **Criterion.**  A countable group which is weakly sofic *with Hilbert
   embeddable witnessing lengths* is hyperlinear.  The normalization is the
   one already in the definition of weak soficity (recorded, with its
   numbering, in `glebsky-weak-soficity-is-metric-free`):
   lengths bounded by `1`, defect tending to zero, separation bounded below
   by a constant not depending on the defect.  All comparison constants in 2
   are then absolute — they come from concavity of `s |-> 2(1-e^(-s))` on
   `[0,1]` — so no uniformity is lost along the witness family.  What the
   normalization is doing is genuine and not bookkeeping: if the diameters
   were allowed to grow, rescaling to diameter `1` would drive the separation
   to zero.  The conclusion is hyperlinearity in the maximal-separation sense
   of `Sofic/Hyperlinear.HyperlinearModel`; the upgrade from constant to
   maximal separation is *not* free for unitary models
   (`HyperlinearAmplification.tensorPow_phase_collapse`), and it is available
   here only because the Schoenberg traces are approximately the real
   positive numbers `exp(-ell)`, which is exactly the scalar-freeness
   hypothesis of `exists_conjDouble_separation`.
4. **Calibration.**  Sufficiency has content on both sides:
   - the normalized Hamming length on `Sym(n)` is Hilbert embeddable, and 3
     then reproduces the formalized `sofic-implies-hyperlinear`;
   - the discrete length is Hilbert embeddable, reproducing
     "residually finite (or LEF) implies hyperlinear";
   - on any family with a uniform character ratio bound
     `|chi(x)|/chi(1)<=c<1` (Gluck, finite Lie type), *every* Hilbert
     embeddable invariant length is uniformly bi-Lipschitz to the discrete
     length, so witnesses through such groups collapse to LEF witnesses.
     This is where the asymptotic content lives, and it subsumes the
     recorded rank/Schoenberg no-go;
   - the `F_2`-rank length on `GL_2(F_2)` is **not** Hilbert embeddable —
     the sign character carries coefficient `1/6` — but this single-group
     computation has no asymptotic content on its own, since `rank^s` on the
     same group *is* Hilbert embeddable for every `s <= log_2(3/2)`.
     Conditional negativity is parametrization-sensitive in both directions
     (`d_H` is, `d_H^2` is not), so any candidate-witness question must name
     the function that carries the defect and separation bookkeeping.

5. **Normalized-character form, and why the normalization must stay.**  The
   cone of Hilbert embeddable invariant lengths is generated by the
   `psi_i(h)=d_i-Re chi_i(h)`, `i` nontrivial (cairn-bernoulli,
   `hilbert-embeddable-is-representation-realized`), equivalently by the
   normalized `1-Re chi_i/d_i`.  That gives the exact identity
   `psi_rho(h)=(1/2)||rho(h)-1||_F^2` for a representation `rho` with the
   matching multiplicities.  It does **not** replace item 2, because the
   conversion this criterion needs is to the *normalized* Hilbert--Schmidt
   metric, and

   ```text
   ||rho(a)-rho(b)||_(2,norm)^2 = 2 psi_rho(a^(-1)b) / dim(rho),
   ```

   whose scalar `1/dim(rho)` is not bounded below along a family — the
   Frobenius identity is exact but the separation it delivers can decay like
   `1/dim`.  What item 2 produces instead is a representation whose
   *normalized* trace realizes the length, which is dimension free.  So the
   right object to design is a **normalized character**
   `phi = sum_i lambda_i chi_i/d_i`, `lambda_i>=0`, `sum_i lambda_i = 1`,
   with

   ```text
   phi ~ 1 on the error set,     |phi| bounded away from 1 on the targets,
   ```

   after which `rho o sigma` *is* the microstate, since `rho` is a genuine
   homomorphism.  The two formulations correspond by `ell = 1 - Re phi`.

   **Three descriptions, one object.**  For a countable group the following
   coincide, and this is the canonical form the weak-soficity lanes compute
   against:

   - it is weakly sofic with Hilbert embeddable witnessing lengths (this
     claim);
   - it lies in cairn-bernoulli's class `C_FU` — approximable by *finite
     subgroups of unitary groups* in normalized Hilbert--Schmidt,
     equivalently its microstates factor as `Phi -> K -> U(m)` with the
     second arrow a homomorphism;
   - the normalized-multiplicity linear program of
     `hilbert-embeddable-length-lp-feasibility` is feasible along the family.

   The identification is `ell = 1 - Re phi` in one direction and item 2 in
   the other.  **The normalization caveat travels with it**: the LP must be
   run on the simplex `lambda_i >= 0`, `sum_i lambda_i = 1` in the normalized
   generators `1 - Re chi_i/d_i`, not on an unconstrained multiplicity vector
   in the `psi_i`.  The two span the same cone, so ratios of linear
   functionals are unaffected, but the *conversion* to microstates is not:
   an exact unnormalized realization `psi_rho = ell` yields normalized
   separation `2c/dim(rho)`, which decays along a family.
   In these coordinates the collapse in item 4 is one line: if no nontrivial
   normalized character comes near `1` anywhere, then `phi ~ 1` on the error
   set forces `lambda_triv ~ 1`, hence `phi ~ 1` everywhere, hence no
   separation.
6. **Calibration against Glebsky's own construction.**  The lengths his
   Lemma 3 manufactures are conjugation-invariant word metrics, so the
   criterion can be run against them directly, and it cuts both ways.
   - *The smallest nonabelian instance fails.*  On `H=S_3` with the
     transposition class as generating set the word metric is
     `(0,1,1,1,2,2)`, which **is** the `F_2`-rank length on
     `GL_2(F_2)=S_3` of item 4 — so the recorded non-embeddable example is
     not merely analogous to that family, it is a member of it.
   - *The lamp direction passes.*  On `(Z/2)^A` with the coordinate
     generators the word metric is the Hamming weight
     `sum_alpha (1-epsilon_alpha)/2`, a nonnegative combination of
     `1 - character`, hence Hilbert embeddable outright.

   So generic parameter choices fail while the lamp direction is free: for a
   lamp-and-acting-part witness the question is entirely about the acting
   part's contribution.

This is a **sufficient** condition only.  Hyperlinearity is not known to
return a weak-soficity witness — hyperlinear approximations live in `U(n)`,
not in finite groups — so a negative answer for Glebsky's construction would
not show the Kun--Thom wreath non-hyperlinear.  What the criterion does give
is one finite, mechanical route from the settled statement "the Kun--Thom
wreath is weakly sofic and not sofic" to Question 3.4: whether Glebsky's
witnesses admit a uniformly Hilbert embeddable reparametrization.

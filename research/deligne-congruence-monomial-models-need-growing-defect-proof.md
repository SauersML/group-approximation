The notation is that of the target. The external inputs are:
- **(Del)** Deligne (1978). For `h >= 2`, every finite-index subgroup of the preimage `Sp_(2h)(Z)~` of `Sp_(2h)(Z)` in the universal cover of `Sp_(2h)(R)` contains `2 pi_1 = <z^2>`.
- **(SA)** The reduction `Sp_(2h)(Z) -> Sp_(2h)(F_p)` is surjective.
- The order formula `|Sp_(2h)(F_p)| = p^(h^2) prod_(i=1..h) (p^(2i) - 1)`.

**Step 0: the block preimage is the Deligne cover of Sp_4(Z).**
- The block embedding `Sp_4(R) -> Sp_(2g)(R)` restricts on maximal compact subgroups to the standard block embedding `U(2) -> U(g)`.
- The determinant restricts to the determinant, so the induced map on `pi_1 = Z` is an isomorphism.
- Hence the preimage of `Sp_4(R)` in the universal cover of `Sp_(2g)(R)` is the universal cover of `Sp_4(R)`, with the same central generator `z`.
- So `H~`, the preimage of `H = Sp_4(Z)` in `Gamma~`, is `Sp_4(Z)~`, and (Del) applies to it.

Fix generators `T` of `H` and relators `R_H`. Write each `t` as a word `w_t` in `S`. Put `t~ = w_t(S~)` and define `k^H_rho` by `rho(t~) = z^(k^H_rho)` in `Gamma~`. Consider the abstract group `E = <T, z | z central, rho(T) z^(-k^H_rho)>`.
- `E` maps onto `H~`.
- Both `E -> H` and `H~ -> H` have kernel generated by `z`.
- `z` has infinite order in `H~`.

So `E ≅ H~`.

**Step 1: a detecting cycle on the presentation complex K_H (item 1, first half).**

Suppose `q` divides `kappa_H(Sigma) = sum c_rho k^H_rho` for every integral 2-cycle `Sigma = sum c_rho rho` on `K_H`. Fix `zeta` of order `q` and `theta` with `zeta = exp(2 pi i theta)`.

1. The cochain `c(rho) = theta k^H_rho` in `R/Z` vanishes on `Z_2(K_H) = H_2(K_H)`.
2. Since `R/Z` is divisible, `Ext(H_1(K_H), R/Z) = 0`, and `H^2(K_H; R/Z) -> Hom(H_2(K_H), R/Z)` is an isomorphism. So `c` is a coboundary. There is `a : T -> R/Z` such that, for each `rho`, the signed sum of `a` over the letters of `rho` equals `theta k^H_rho`.
3. The assignment `t~ -> exp(2 pi i a(t))`, `z -> zeta` kills every defining relator of `E`. It is therefore a character `chi` of `E = H~`.
4. The image of `chi` is a finitely generated abelian group, hence residually finite. Since `zeta^2 != 1` (as `q >= 3`), some finite quotient of the image does not kill `zeta^2`.
5. The kernel of `H~ -> (that finite quotient)` is a finite-index subgroup not containing `z^2`. This contradicts (Del).

So some integral 2-cycle `Sigma_0` on `K_H` has `q` not dividing `kappa_H(Sigma_0)`.

**Step 2: pushing Sigma_0 into Y_(Gamma/H) (item 1, second half).**

Let `X = Gamma/H`, with base vertex `o` stabilized by `H`.
- Each relator `rho` gives a word `rho(w_T)` in `S` that is trivial in `Gamma`.
- Choose a van Kampen diagram for it in the Cayley complex of `Gamma`. Its signed cell count gives `kappa = k^H_rho`, because in `Gamma~` a product of conjugates of `r~^(+-1)` equals `z` to the signed sum of the `k_r`.
- Project the diagram to `Y_X = H \ Cay`. This gives a 2-chain `C_rho` whose boundary is the 1-chain of the loop reading `rho(w_T)` at `o`.
- Each `w_t` is in `H`, so reading `w_t` from `o` returns to `o`. Hence `partial C_rho = sum_t (signed count of t in rho) ell_t`, where `ell_t` is the chain of that loop.
- Put `Sigma_H = sum c_rho C_rho`, with `c_rho` the coefficients of `Sigma_0`. Its boundary is `sum_t (sum_rho c_rho count_t(rho)) ell_t = 0`, because `Sigma_0` is a cycle on the one-vertex complex `K_H`.
- So `Sigma_H` is an integral 2-cycle with `kappa(Sigma_H) = kappa_H(Sigma_0)`, not divisible by `q`, and of mass `A` at most the sum of `|c_rho|` times the diagram areas.

**Step 3: transfer (item 2).**

Let `N` be normal of finite index, `Lambda = HN` and `D = [Lambda : N]`.
- The projection `Y_(Gamma/H) -> Y_(Gamma/Lambda)` is cellular. The image of `Sigma_H` is a cycle `Sigma_Lambda` of mass at most `A` with the same value.
- The map `Y_(Gamma/N) -> Y_(Gamma/Lambda)` is a `D`-sheeted covering of 2-complexes.
- Give every lift of a cell `(y, r)` the coefficient of `(y, r)`. This gives the preimage chain `pi^* Sigma_Lambda`.
- Boundary commutes with `pi^*` for coverings, so `pi^* Sigma_Lambda` is a cycle, of mass `D |Sigma_Lambda|_1 <= D A` and value `D kappa(Sigma_H)`.
- If `q` does not divide `D`, the value is not divisible by `q`. Then `theta` times the value is not an integer for `zeta` of order `q`, so the cycle is detecting.
- Item 1 of `deligne-bounded-rank-monomial-models-need-large-detecting-cycles` (`[Gamma:N] <= m |Sigma|_1` for any detecting cycle) gives `[Gamma : N] <= m D A`, which is `m >= [Gamma : HN] / A`.

**Step 4: congruence levels (item 3).**
- By (SA) for `h = 2`, the image of `H` in `Gamma/Gamma(p) = Sp_(2g)(F_p)` is the block `Sp_4(F_p)`. So `D = p^4 (p^2-1)(p^4-1)`.
- `q` does not divide `D` if and only if `p != q`, `p^2 != 1 mod q` and `p^4 != 1 mod q`, that is, iff `p != q` and the order of `p` mod `q` does not divide 4.
- For `q >= 7`, `(Z/q)^*` is cyclic of order `q - 1 >= 6`, so it has elements whose order does not divide 4. By Dirichlet there are infinitely many such primes `p`.
- For `q = 3, 5`, the factor `p^2 - 1` or `p^4 - 1` is divisible by `q` unless `p = q`, in which case `q | p^4`. So there are none.
- Finally, `[Gamma : H Gamma(p)] = |Sp_(2g)(F_p)| / |Sp_4(F_p)| = p^(g^2-4) prod_(i=3..g) (p^(2i)-1) >= 2^(-(g-2)) p^(2g^2+g-10)`.

This proves (BT) and `alpha(Gamma(p)) = A_0(Gamma(p)) / [Gamma : Gamma(p)] <= D A / [Gamma : Gamma(p)] = A / [Gamma : H Gamma(p)]`.

**Check (Limits, SL_2 block).** The preimage of `SL_2(Z)` in the universal cover of `SL_2(R)` is the braid group `B_3`, with abelianization `Z` and `z = (s_1 s_2)^6` (the kernel of `B_3 -> SL_2(Z)`) mapping to 12. Characters `s_i -> exp(2 pi i theta/12)` send `z -> zeta`, so Step 1 fails for that block, as expected: `SL_2(Z)~` is residually finite.

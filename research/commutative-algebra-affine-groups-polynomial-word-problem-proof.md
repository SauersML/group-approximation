Direct proof (2026-09-13, lane `solve-kms-self-similar-affine`).

## Setup

- Write `P_0 = F_q[x_1, ..., x_m]` and `R = P_0 / I`, with `I = (f_1, ..., f_t)`.
- `S` is finitely generated and `R` is noetherian, so `S ≅ R^N / L'` with `L'`
  finitely generated. Lift generators of `L'` to `l_1, ..., l_r in P_0^N` and let
  `L = P_0 l_1 + ... + P_0 l_r`. Then `S ≅ P_0^N / (L + I P_0^N)`. Write `≡` for
  congruence modulo `L + I P_0^N`.
- **Lifts.** For each `γ = (s, w)` in `B ∪ B^(-1)` choose `v_γ in P_0^N` lifting `s`,
  and `W_γ in M_N(P_0)` whose `i`-th column lifts `w(e_i)`. By `R`-linearity, `W_γ ξ`
  lifts `w(x)` whenever `ξ` lifts `x`. Let `d >= 1` bound the total degrees of all
  these entries.

## Step 1: words become polynomial data

- For a word `γ_1 ... γ_l`, define `(v, W)` by `(v, W) = (v_(γ_1), W_(γ_1))` for
  `l = 1` and `(v_γ, W_γ)·(v', W') = (v_γ + W_γ v', W_γ W')`.
- By induction, `ξ -> v + W ξ` lifts the map `x -> γ_1(...γ_l(x))`.
- All entries of `v` and `W` have degree `<= d*l`. A polynomial of degree `<= D` in
  `m` variables has at most `M_m(D) = binom(D+m, m) <= (D+1)^m` monomials.
- So `(v, W)` is computed with `O(l * N^3 * (dl+1)^(2m))` operations in `F_q`.

## Step 2: the identity criterion

The word is trivial in `Γ` iff

- (i) `v ≡ 0`, and
- (ii) `W e_i - e_i ≡ 0` for `i = 1, ..., N`.

- **(⇐)** For any lift `ξ`, `W ξ - ξ = Σ ξ_i (W e_i - e_i) ≡ 0`, so `v + W ξ ≡ ξ`.
- **(⇒)** Apply the element to `x = 0` to get (i). Then `w(e_i) = e_i` gives (ii).

## Step 3: module membership is ideal membership

- Let `P = F_q[x_1, ..., x_m, y_1, ..., y_N]`, graded by degree in the `y`'s, with
  `P_0` in degree 0.
- For `u in P_0^N` put `λ(u) = Σ u_i y_i`. So `λ` is an `F_q`-linear bijection from
  `P_0^N` onto the `y`-degree-one component `P_1`.
- Let `J` be generated by `f_1, ..., f_t`, `λ(l_1), ..., λ(l_r)` and all products
  `y_i y_(i')`.

**Claim.** `u ≡ 0` iff `λ(u) in J`.

- The generators are `y`-homogeneous, of degrees 0, 1 and 2, so `J` is a homogeneous
  ideal.
- `J_1` is spanned by the degree-one parts of products `h g`, with `h` homogeneous and
  `g` a generator:
  - `h f_k` with `h = Σ h_i y_i` gives `λ((h_i f_k)_i) in λ(I P_0^N)`;
  - `h λ(l_j)` with `h in P_0` gives `λ(h l_j) in λ(L)`;
  - multiples of `y_i y_(i')` have degree `>= 2`.
- So `J_1 = λ(L + I P_0^N)`, and the claim follows because `λ` is injective.

## Step 4: dividing within bounded degree

- Fix a graded monomial order on `P` and a Gröbner basis `G = {g_1, ..., g_c}` of `J`.
  This is finite data attached once to `(Γ, B)`.
- Divide `f = λ(u)` by `G` (trust surface below). Each iteration replaces the running
  dividend `p` by `p - (LT(p)/LT(g_i)) g_i` or moves `LT(p)` to the remainder.
- **Degree.** Every monomial of `(LT(p)/LT(g_i)) g_i` is `<= LM(p)`. Since the order is
  graded, it has total degree `<= deg LM(p)`. So if `f` has degree `<= D`, every `p`
  has degree `<= D`.
- **Termination.** `LM(p)` strictly decreases at each iteration. So there are at most
  `M_(m+N)(D)` iterations, each costing `O(c * M_(m+N)(D))` operations in `F_q`.
- **Correctness.** `f in J` iff the remainder is zero.

The tests (i) and (ii) are `N + 1` divisions with `D = d*l + 1`. So the total time is
`O(l N^3 (dl+1)^(2m) + (N+1) c (dl+2)^(2(m+N)))`, which is at most `C*l^C + C`. This
proves part 1.

## Step 5: one bound for the class

- For real `t >= 0` we have `t <= 2^t`. Applying this with `t = l/C` gives
  `l <= C 2^(l/C)`, so `l^C <= C^C 2^l`.
- Hence `C*l^C + C <= C'*2^(C'*l) + C'*l + C'` with `C' = C^(C+1) + C`, i.e. the word
  problem is in `F(2^n)`.
- The constant depends on `Γ` and `B`; the function `g(n) = 2^n` does not. This proves
  part 2. ∎

## Trust surface

The existence of Gröbner bases, the division algorithm (leading-monomial bound and
termination), and "f in J iff the remainder is zero" are standard. They are quoted
from Cox--Little--O'Shea, *Ideals, Varieties, and Algorithms*, Ch. 2 §§3 and 6, and
not re-read at source.

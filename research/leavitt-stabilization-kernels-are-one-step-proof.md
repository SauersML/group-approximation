**Item 1.**
- `j_N(St_N(R))` is generated by the `X_ij(a)` with `i, j <= N`. `D_(N+1)` fixes every `X_ij(a)` with `i, j < N + 1`, by its
  defining formulas. So does `j_(N+1)`. Hence `D_(N+1) ∘ j_N` and `j_(N+1) ∘ j_N` agree on generators of `St_N(R)`, and
  they are equal.
- **Induction.** Suppose `j_(N+k-2) ∘ ... ∘ j_N = D_(N+k-2) ∘ ... ∘ D_(N+1) ∘ j_N`. The image of `St_N(R)` under either side
  is generated by the `X_ij(a)` with `i, j <= N`. These are fixed by `j_(N+k-1)` and by `D_(N+k-1)`, since
  `N < N + k - 1` for `k >= 2`. So composing with `j_(N+k-1)` or with `D_(N+k-1)` gives the same map. That proves the
  statement for `k`.

**Item 2.**
- Every `D_m`, `m >= 3`, is injective (item 1 of `leavitt-refinement-identifies-unstable-k2-levels`). By item 1,
  `ker(j_(N+k-1) ∘ ... ∘ j_N) = ker(j_N)` for every `k`.
- `St(R) = colim_m St_m(R)`. So `x in St_N(R)` is `1` in `St(R)` if and only if it is `1` in some `St_(N+k)(R)`, which
  happens if and only if `x in ker(j_N)`.
- `j_N` lifts the injection `E_N(R) -> E_(N+1)(R)`, `A -> A ⊕ 1`. So `ker(j_N) ⊆ K_2(N, R)`, and `ker(j_N) = U_N`.

**Item 3.**
- **Where `D_N` sends last-coordinate generators.** `D_N(X_iN(b)) = X_iN(be) X_(i,N+1)(bf)`. With `b = a e*` this is
  `X_iN(a) X_(i,N+1)(0) = X_iN(a)`, using `e*e = 1` and `e*f = 0`. Likewise `D_N(X_Nj(e a)) = X_Nj(e* e a) X_(N+1,j)(f* e a) = X_Nj(a)`.
  So `D_N(Σ^(e)(y)) = j_N(y)` for each generator `y` of `St_N(R)`.
- **`Σ^(g)` is a homomorphism.** For an isometry `g`, `Σ^(g)` is induced by the non-unital ring endomorphism
  `A -> G A G*` of `M_N(R)`, with `G = diag(1, ..., 1, g)`. It preserves the Steinberg relations:
  - `[X_iN(a g*), X_Nj(g b)] = X_ij(a g* g b) = X_ij(ab)`;
  - `[X_ij(a), X_jN(b g*)] = X_iN(ab g*)`;
  - `[X_Ni(g a), X_ij(b)] = X_Nj(g ab)`;
  - relations not involving index `N` are fixed.
  So `j_N = D_N ∘ Σ^(e)` holds on all of `St_N(R)`.
- **Composition and units.** `Σ^(g) Σ^(h)` sends `X_iN(a)` to `X_iN(a h* g*) = X_iN(a (gh)*)` and `X_Nj(a)` to
  `X_Nj(g h a)`. For a unit `u`, `Σ^(u)` has inverse `Σ^(u^-1)`.
- **The other isometry.** `W = ef* + fe*` satisfies `W* = W`, `W² = 1` and `W e = f`. So
  `Σ^(f) = Σ^(W) Σ^(e)`, and `Σ^(W)` is an automorphism.
- `D_N` is injective, so `ker j_N = ker Σ^(e)`.

**Item 4.** This is items 2--3 for `R_L`, with `e = s_1` and `f = s_2`. Condition (i) is `U_N = 1`, and the `U_N`
are isomorphic across `N` (`leavitt-refinement-identifies-unstable-k2-levels`, item 2).

Notation as in the claim: `C = <a>`, `B = <a> x <s>`, `Q = Y *_C B`.

**1. Homology of `Q`.** Both edge maps `C -> Y` and `C -> B` are injective. So
the Mayer--Vietoris sequence of the amalgamated product applies (standard,
e.g. Brown, *Cohomology of Groups*, II.7; not re-read):

    H_2(C) -> H_2(Y) (+) H_2(B) -> H_2(Q) -> H_1(C) -> H_1(Y) (+) H_1(B)
           -> H_1(Q) -> H_0(C) -> H_0(Y) (+) H_0(B).

- `H_2(C) = 0` because `C` is cyclic, and `H_2(Y) = 0`. So `H_2(B) -> H_2(Q)`
  is injective.
- `H_1(C) -> H_1(B) = B` is injective, since `C` is a direct factor of `B`.
  So `H_2(Q) -> H_1(C)` is zero, and `H_2(B) -> H_2(Q)` is onto.
- `H_0(C) -> H_0(Y) (+) H_0(B)` is injective. So
  `H_1(Q) = (H_1(Y) (+) H_1(B))/H_1(C) = B/C = Z`, generated by `s`.
- **Künneth.** For `a` of infinite order, `H_2(B) = H_2(Z^2) = Z`. For `a` of
  order `n`, `H_2(Z/n x Z) = H_1(Z/n) (x) H_1(Z) = Z/n`: the other degree-two
  terms `H_2(Z/n)`, `H_2(Z)` and the Tor terms vanish. In both cases the
  generator is the torus class of `a` and `s`.

**2. Injective case.** `Y <= Q` contains the coefficients of `w`, and
`Y -> Y_w` is injective by assumption. By
`schur-kernel-localizes-to-coefficient-subgroup` with `B := Y`,

    K_2(Q, w) = iota_*( K_2(Y, w) ) <= iota_*( H_2(Y) ) = 0.

**3. Killed case.** Apply `kl-failure-yields-a-schur-kill` with `G = Y`. Its
`Q` is `Y *_(<a>) (<a> x Z)`, which is ours. Its proof shows that
`<a> x Z -> Q_w` kills `a`, so the map factors through `Z`, and `H_2(Z) = 0`.
So the entire image of `H_2(<a> x <s>)` dies in `H_2(Q_w)`. By step 1 that
image is `H_2(Q)`, which is nonzero because `H_1(<a>) != 0` for `a != 1`. So
`K_2(Q, w) = H_2(Q) != 0`.

**4. The equivalence.**
- If the conjecture holds, then `Y -> Y_w` is injective for every such datum,
  and step 2 gives the Schur statement.
- If the conjecture fails, `kl-counterexample-can-be-acyclic` supplies a datum
  `(Y, a, w)` with `a` dying in `Y_w`. By step 3 its Schur kernel is nonzero,
  so the Schur statement fails.

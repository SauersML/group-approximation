Notation as in `equicontinuous-bs-bases-force-conjugator-entropy`: `X` compact
metrizable, `f g f^-1 = g^k` with `k ≥ 2`, `g` equicontinuous, `Z = cl<g>`,
`Z_k = cl<g^k>`, `m = [Z : Z_k]`, and hypothesis (H). Give `Homeo(X)` the uniform
topology (sup-distance of maps and of inverses). It is a Hausdorff topological
group.

**Step 0: the groups.**
- `Z` is compact. This is item 2(b) of `higman-group-almost-automorphism-obstruction-proof`
  (Arzelà–Ascoli; the proof there does not use zero-dimensionality). `Z` is abelian,
  being the closure of a cyclic subgroup.
- `Z_k = {z^k : z ∈ Z}`: the right side is compact (continuous image of `Z`) and
  contains `<g^k>` densely. `Z/Z_k` is generated by the image of `g`, and that image
  has order dividing `k`. So `Z/Z_k` is cyclic of order `m`, `m | k`.
- Conjugation `c_f(y) = f y f^-1` is a topological automorphism of `Homeo(X)`. So
  `c_f(Z) = cl<f g f^-1> = Z_k`. Put `Z' = f^-1 Z f`. Then `f^-1 Z_k f = Z`, so
  `Z ⊆ Z'` with `[Z' : Z] = [Z : Z_k] = m`. `Z'` is abelian.
- Put `r = f^-1 g f ∈ Z'`. Then `r^k = f^-1 g^k f = g`, and `Z'/Z` is cyclic of order
  `m`, generated by `rZ` (it is the image of `Z/Z_k` under `c_(f^-1)`). So
  `Z' = ⊔_(0 ≤ i < m) r^i Z`.
- Stabilizers transport: for `w ∈ X`, `Stab_(Z')(w) = f^-1 Stab_Z(f w) f`, and
  `f^-1 (Z \ Z_k) f = Z' \ Z`. So (H) at the point `f w` says exactly that
  `Stab_(Z')(w) ⊆ Z`.

**Step 1: the orbit space.** `Z` is a compact group acting continuously on `X`,
because evaluation `Homeo(X) × X → X` is continuous for the uniform topology. So
`T = X/Z` is compact metrizable, and the quotient map `π : X → T` is continuous,
open and surjective. Fix a compatible metric `d_T` on `T`.

**Step 2: the induced map.** `f(Z x) = (f Z f^-1) f x = Z_k f x ⊆ Z f x`. So
`f̄(Z x) = Z f x` is well defined, and `f̄ ∘ π = π ∘ f`. Since `π` is a quotient
map, `f̄` is continuous, and it is surjective because `f` is.

**Step 3: fibres have exactly `m` points.** Let `y = Z x' ∈ T` and `w = f^-1 x'`.
Then
`f^-1(Z x') = (f^-1 Z f) f^-1 x' = Z' w = ⋃_(i<m) r^i Z w = ⋃_(i<m) Z r^i w`,
using that `r` commutes with `Z` (both lie in the abelian group `Z'`). So
`f̄^-1(y) = { Z r^i w : 0 ≤ i < m }`. If `Z r^i w = Z r^j w` with `0 ≤ i < j < m`,
then `z r^(j-i) w = w` for some `z ∈ Z`, so `z r^(j-i) ∈ Stab_(Z')(w)` lies in
`Z' \ Z`, contradicting Step 0. Hence `|f̄^-1(y)| = m` for every `y ∈ T`.

**Step 4: the fibres are orbits of a free finite action.** `r` commutes with `Z`, so
it maps `Z`-orbits to `Z`-orbits. It induces a homeomorphism `ρ` of `T`, with
`ρ ∘ π = π ∘ r`. Then `ρ^m = id`, since `r^m ∈ Z`. By Step 3 the points
`t, ρ t, …, ρ^(m-1) t` are distinct for every `t`, so `<ρ> ≅ Z/m` acts freely on `T`.
Also `f̄ ∘ ρ = f̄`, because `Z f r w = Z g f w = Z f w`. So each fibre of `f̄` is one
`<ρ>`-orbit. Put
`c = min { d_T(t, ρ^i t) : t ∈ T, 0 < i < m } > 0`,
a minimum of finitely many continuous positive functions on a compact space.

**Step 5: separated preimages.** If `f̄ t = f̄ t'` and `t ≠ t'`, then `t' = ρ^i t` with
`0 < i < m`, so `d_T(t, t') ≥ c`. By Step 3 and induction, `|f̄^-n(y)| = m^n` for
every `y ∈ T` and `n ≥ 1`. Let `t ≠ t'` in `f̄^-n(y)`, and let `j` be the largest
index in `[0, n-1]` with `f̄^j t ≠ f̄^j t'`. It exists because `f̄^0 t ≠ f̄^0 t'`, and
`f̄^(j+1) t = f̄^(j+1) t'` by maximality or because `j+1 = n`. So
`d_T(f̄^j t, f̄^j t') ≥ c`. Therefore `f̄^-n(y)` is `(n, c/2)`-separated for `f̄`, and
`s_n(f̄, c/2) ≥ m^n`. In the Bowen–Dinaburg form of entropy recalled in
`brin-thompson-proper-power-conjugates-have-zero-entropy`, this gives `h(f̄) ≥ log m`.

**Step 6: back to `f`.** `π` is a continuous surjection with `π ∘ f = f̄ ∘ π`, so `f̄`
is a topological factor of `f`, and `h(f) ≥ h(f̄) ≥ log m`. The monotonicity of
entropy under factors is textbook (Bowen; Walters, *An Introduction to Ergodic
Theory*, Ch. 7) and is not re-read at source here. ∎

## Consequences, proofs

- **Item 1 (odometer `s`).** `s = tau × id` on `C × C`, with `tau` the 2-adic odometer,
  is an isometry, so it is equicontinuous. `cl<s> = {(x,y) ↦ (x + a, y) : a ∈ Z_2}`
  acts freely, `cl<s^2>` is the subgroup with `a ∈ 2Z_2`, and `m = 2`. For a
  conjugate `s' = h s h^-1` the hypotheses transport: `s'` is equicontinuous
  because `h` and `h^-1` are uniformly continuous, `cl<s'> = h cl<s> h^-1`, stabilizers
  are conjugated by `h`, and the index is unchanged. So the theorem applies to `s'`. For a
  translation `x ↦ x + c` with `c ∈ Z_2^×` the closure is again all 2-adic
  translations, acting freely.
- **Item 2 (H4).** In `𝔅_n` every element has finite entropy (item 3 of
  `bg-in-isometric-brick-hosts-needs-unbounded-exponents`). By item 2 of
  `brin-thompson-proper-power-conjugates-have-zero-entropy`, which holds for all
  homeomorphisms of a compact metric space, `γ_i γ_(i+1) γ_i^-1 = γ_(i+1)^2` gives
  `h(γ_(i+1)) = h(γ_(i+1)^2) = 2 h(γ_(i+1))`, so `h(γ_(i+1)) = 0` for every `i`. If
  `γ_(i+1)` were equicontinuous with (H) and `m = 2`, the theorem with `f = γ_i`,
  `g = γ_(i+1)` would give `h(γ_i) ≥ log 2`, a contradiction. So `m = 1`, i.e.
  `cl<γ_(i+1)^2> = cl<γ_(i+1)>`.
- **Item 3 (BG).** `h(a) = h(a^2)` forces `h(a) = 0` when finite, and
  `b = t a t^-1` is conjugate to `a`, so `h(b) = 0`. The theorem with `f = b`,
  `g = a` gives the same conclusion for `a`.
- **Item 4.** If `Z` is isomorphic to the ring of `k`-adic integers (`k ≥ 2`) as a
  topological group, with `g` corresponding to `1`, then `cl<g^k>` corresponds to
  the ideal generated by `k`, of index `k`, so `m = k`.

**ESTABLISHED** (proof in [[poisoned-ck-envelopes-have-no-fng-maximal-kernel-proof]]).

**Theorem.** Let `S` be a finitely generated, computably presented, infinite simple group and let
`1 != s in S`. Then there is a finitely presented property-(T) group `Γ` such that:

1. `S <= Γ` and `Γ = <<s>>_Γ`, and `Γ` is an output of
   `chatterji-kassabov-normal-generator-embedding` for a legitimate input;
2. every nontrivial quotient of `Γ` has unsolvable word problem;
3. hence no maximal proper normal subgroup `M` of `Γ` is recursively enumerable, and in
   particular none is finitely normally generated. So no maximal quotient of `Γ` is recursively
   presented, let alone finitely presented.

This refutes [[ck-envelope-has-a-finitely-normally-generated-maximal-kernel]] as stated. That
statement quantifies over every finitely presented `Γ ⊇ S` with `Γ = <<s>>_Γ` supplied by
Chatterji--Kassabov, and it fails for every pair `(S, s)`.

The narrower reading "supplied by CK Theorem 3 *for the input `S` itself*" does not escape. CK
Theorem 3 is a pure existence statement: an embedding into some finitely presented property-(T)
group normally generated by `s`. Our `Γ` is such an embedding of `S`, so it is a valid output for
input `S`.

**The poison obstruction (general form).** Let `Γ` be any group with a simple subgroup `S` and
`Γ = <<s>>_Γ` for some `1 != s in S`. Suppose some finitely generated `P <= Γ` contains an element
`1 != t in S` that is *poisoned in `P`*: every homomorphism from `P` that does not kill `t` has an
image with unsolvable word problem. Then no simple quotient of `Γ` has solvable word problem. If
`Γ` is finitely presented, no maximal kernel of `Γ` is recursively enumerable.

**Transfer to the marked Steinberg cover.** Take the finitely presented marking `H` in
[[ck-steinberg-marked-cover]] to be the poisoned `Γ` above, with `g = s`. Then the marked cover
`St_4(U) ->> Γ' ->> EL_4(U)` inherits the conclusion: every nontrivial quotient of `Γ'` has
unsolvable word problem. The matrix structure of the cover does not help. Every proof of a
finitely normally generated maximal kernel must use a property of the **specific marking**, and
that property is strictly stronger than "finitely presented and containing `S`".

## The invariant and where every hypothesis-only proof dies

- **The invariant.** Call `t in Γ` *WP-poisoned* when some finitely generated `P ∋ t` has every
  `t`-surviving quotient undecidable.
- **Where it acts.** Proper normal subgroups miss the core
  (`proper-normal-subgroups-miss-the-normally-generating-core`), so every core element survives
  in every maximal quotient.
- **Where a hypothesis-only proof dies.** Such a proof uses only finite presentation,
  property (T), normal generation by a core element, perfectness, the absence of finite quotients,
  or a Steinberg/elementary cover over an arbitrary finitely presented marking. It dies at the
  final step `Γ/M` finitely presented. Every one of those hypotheses holds for the poisoned
  envelope, and `Γ/M` there is not even recursively presented.
- **What survives.** Any surviving proof must establish, for its chosen envelope, the *necessary
  prerequisite*: some simple quotient containing the core has solvable word problem (an r.e.
  maximal kernel). That prerequisite can fail on its own, and it fails for poisoned markings.

## What this does not do

- It does not refute Boone--Higman. If `S` embeds in a finitely presented simple `H0`, then `H0`
  itself is an envelope with `M = 1`.
- It does not decide the hole for the specific cover of `boone-higman-via-ck-maximal-kernel`,
  whose marking comes from Clapham's decidable envelope. There, the covering ring
  `U = Z[T]<p,q>/(p(1-g)q-1)` and the derived-subgroup host `T` are not known to be poison-free.
- Consequence for the finite bi-index programme (`ck-envelope-simple-core-has-finite-bi-index`,
  which is existential and not refuted): a poisoned envelope always has infinite core bi-index.
  - Finite bi-index would make `SV_Γ` a finitely presented simple group containing `Γ`. Then `Γ`
    would have solvable word problem, but `Γ` is a nontrivial quotient of itself.
  - The same holds for any normal-lattice finiteness principle, such as Max-n, that would force a
    finitely normally generated maximal kernel.
  - So "arrange the envelope" must mean choosing a poison-free input, not just any input.

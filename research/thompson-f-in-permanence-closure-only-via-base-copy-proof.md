Notation is as in the target. `F[a,b]` is the subgroup of elements fixing `[0,1] ∖ (a,b)` pointwise, as in the
reading notes of `thompson-f-rigid-interval-subgroups-facts`.

## Imports

**From `thompson-f-rigid-interval-subgroups-facts`, verbatim.**
- (F1) "Its commutator subgroup $F'$ is a simple group which coincides with the subgroup of all elements with
  support contained in the unit interval $(0,1$)."
- (F2) "If $a<b$ are dyadic rationals, then $F[a,b]$ is isomorphic to $F$."

**From `nontrivial-normal-subgroups-of-thompson-f-contain-a-copy-of-f`.** (N) If `1 ≠ N ◁ F_0 ≅ F`, then `N`
contains a subgroup isomorphic to `F`.

**Tree facts** (Serre, *Trees*, Chapter I, as used in `finitary-permanence-closures-collapse-proof`).
- (T1) A hyperbolic automorphism `h` has a unique axis `ℓ_h`, a bi-infinite line on which `h` translates by a nonzero
  amount. By uniqueness, `ℓ_(g h g^-1) = g ℓ_h`.
- (T2) The fixed-point set of a group acting without inversions is a subtree, possibly empty. For vertices `p, q`
  fixed by a group, the geodesic `[p, q]` is fixed pointwise.
- (T3) A finitely generated group all of whose elements are elliptic fixes a vertex.
- (T4) The fundamental group of a graph of groups acts without inversions on its Bass–Serre tree. Vertex
  stabilizers are the conjugates of vertex groups, and edge stabilizers are the conjugates of edge groups, which
  lie in vertex groups.

Throughout, `F_0 ≤ G` is a subgroup with an isomorphism `F → F_0`. We transport supports and the subgroups `F[a,b]`
to `F_0` through it. Put `c = [x_0, x_1]`, which is nontrivial. Indeed `F' ⊇ F[1/4,3/4] ≅ F` by (F1) and (F2), so
`F' ≠ 1` and `F` is nonabelian, and a group generated by two commuting elements is abelian.

## Step 1. Normal subgroups and products

**Lemma 1.1.** `C_F(F') = 1`.

*Proof.* Let `g ≠ 1`, moving `x ∈ (0,1)`. By continuity there is a dyadic interval `J = [p, q] ⊂ (0,1)` around `x`
with `g(J) ∩ J = ∅`. By (F2), `F[p,q] ≅ F` is nontrivial. Take `h ≠ 1` in it. Then `h ∈ F'` by (F1), since its support
lies in `J ⊂ (0,1)`. The conjugate `g h g^-1` is the identity on `J`, because its support lies in `g(J)`, while `h` is
not. So `g` does not commute with `h`. `∎`

**Lemma 1.2.** Every nontrivial normal subgroup `N` of `F` contains `F'`, and in particular contains `c`.

*Proof.* `N ∩ F'` is normal in the simple group `F'` (F1). If it is trivial, `[N, F'] ⊆ N ∩ F' = 1`, so
`N ⊆ C_F(F') = 1` by Lemma 1.1, which is impossible. So `N ∩ F' = F'`. Finally `c ∈ F'`. `∎`

**(O3) Products.** Let `F_0 ≤ ∏_i G_i` with every `G_i ∈ 𝓕`, and let `p_i` be the coordinate projections. If
every `ker p_i ∩ F_0` were nontrivial, each would contain `c` by Lemma 1.2, so `c ∈ ∩_i ker p_i = 1`, which is
impossible. So some `p_i` is injective on `F_0`, and `G_i` contains a copy of `F`. `∎`

## Step 2. The relative tree lemma (item 1)

Let `G` act on a tree `T` without inversions, and assume that **no edge stabilizer `G_e` contains a subgroup
isomorphic to `F`**. We show that `F_0` fixes a vertex.

**Lemma 2.1 (a commuting copy forces ellipticity).** Let `B ≤ G` with `B ≅ F`, and let `g ∈ G` commute with every
element of `B`. Then `g` is elliptic.

*Proof.* Suppose `g` is hyperbolic, with axis `ℓ = ℓ_g` (T1).
1. **`B` preserves the axis.** For `b ∈ B`, `b ℓ = ℓ_(b g b^-1) = ℓ_g = ℓ` by (T1).
2. **`B` translates it.** An automorphism of a simplicial line is a translation or a reflection. If `b` restricted
   to `ℓ` were a reflection, then `b g b^-1` would translate `ℓ` by the negative of the translation length of `g`. That
   translation length is nonzero, so `b g b^-1 ≠ g`, which is a contradiction. So restriction to `ℓ` gives a
   homomorphism `τ : B → Z`, the translation amount.
3. **The kernel is large.** `K = ker τ` fixes `ℓ` pointwise, so `K ≤ G_e` for any edge `e` of `ℓ`. Since `B/K` is
   abelian, `K ⊇ B'`. Now `B' ≠ 1`, because `B ≅ F` is nonabelian, and `B' ◁ B`, so `B'` contains a copy of `F` by (N).
   So `G_e` contains a copy of `F`, against the assumption. `∎`

**Lemma 2.2 (compactly supported copies fix vertices).** For `k ≥ 2` put `G_k = F_0[2^-k, 1 - 2^-k]`. Then
`G_k ≅ F`, and `G_k` fixes a vertex.

*Proof.* `G_k ≅ F` by (F2), so `G_k` is finitely generated. Put `B_k = F_0[0, 2^-k] ≅ F` (F2). An element of `G_k`
is the identity on `[0, 2^-k]` and an element of `B_k` is the identity on `[2^-k, 1]`. So they commute: on each of
the two intervals at most one of them acts. By Lemma 2.1 every element of `G_k` is elliptic, and by (T3) `G_k` fixes
a vertex. `∎`

**Lemma 2.3 (the union fixes a vertex).** `N = ∪_(k ≥ 2) G_k` is a normal subgroup of `F_0`, and it fixes a vertex.

*Proof.*
1. **Normality.** `G_k ⊆ G_(k+1)`, so `N` is a subgroup. It consists of the elements whose moved set has closure
   inside `(0,1)`. Conjugation by `f ∈ F_0` maps the moved set of `h` onto `f` of it, and `f` maps compact subsets of
   `(0,1)` to compact subsets of `(0,1)`. So `N ◁ F_0`.
2. **Nested fixed trees.** Let `S_k = Fix(G_k)`. This is a nonempty subtree by (T2) and Lemma 2.2, and
   `S_(k+1) ⊆ S_k`. Fix a vertex `v_0`, and let `p_k` be the vertex of `S_k` nearest to `v_0`. For every vertex `s` of
   `S_k`, the geodesic `[v_0, s]` passes through `p_k`. Since `p_m ∈ S_m ⊆ S_k` for `m ≥ k`, the vertex `p_k` lies on
   `[v_0, p_m]`, and `d_k = d(v_0, p_k)` is nondecreasing.
3. **Bounded case.** If `d_k` is bounded, it is eventually constant, say from `k_0` on. Then `p_k ∈ [v_0, p_m]` with
   `d_k = d_m` forces `p_k = p_m = p` for `m ≥ k ≥ k_0`. So `p ∈ S_m` for all `m ≥ k_0`, and `p` is fixed by every
   `G_k`, since `G_k ⊆ G_m` for `m ≥ k`. So `N` fixes `p`.
4. **Unbounded case.** Choose `k` and `m > k` with `d_m > d_k`. Then `G_k ⊆ G_m` fixes both `p_k` and `p_m`, hence
   the geodesic `[p_k, p_m]` pointwise (T2). That geodesic contains an edge `e`. So `G_k ≅ F` lies in `G_e`, against the
   assumption. `∎`

**Conclusion of item 1.** `Fix(N)` is a nonempty subtree (Lemma 2.3, T2). It is `F_0`-invariant, because `N ◁ F_0`.
If it contained an edge `e`, then `G_2 ≤ N ≤ G_e` with `G_2 ≅ F`, against the assumption. So `Fix(N)` is a single
vertex `v`, and `F_0` fixes `v`. `∎`

**(O5) Graphs of groups.** Let `X` be the fundamental group of a graph of groups with vertex groups `Y_v ∈ 𝓕` and
arbitrary edge groups, and suppose `F_0 ≤ X`. By (T4), `X` acts on its Bass–Serre tree without inversions.
- If `F_0` fixes a vertex, `F_0` lies in a conjugate of some `Y_v`, so `Y_v` contains a copy of `F`.
- Otherwise item 1 puts a copy of `F` in an edge stabilizer. That is a conjugate of an edge group, which embeds in a
  vertex group `Y_v`.

Both contradict `Y_v ∈ 𝓕`. `∎`

## Step 3. Local embeddings and the collapse (items 2–4)

**(O6) Local embeddability.** Suppose `G` is locally embeddable into `𝓕` and `F_0 ≤ G`. `F` is finitely presented
(`thompson-f-is-of-type-f-infinity`), say `F = ⟨x_0, x_1 | R_1, ..., R_r⟩`. Let `a_0, a_1 ∈ F_0` be the images of
`x_0, x_1`. Let `E ⊂ G` be the finite set of values in `G`, under `x_i ↦ a_i`, of all prefixes of the words `R_j`,
`c = x_0^-1 x_1^-1 x_0 x_1` and their inverses, together with `1` and `a_i^(±1)`.

Take `φ : E → H ∈ 𝓕`, injective on `E` and with `φ(gh) = φ(g) φ(h)` whenever `g, h, gh ∈ E`.
1. `φ(1) = φ(1)^2`, so `φ(1) = 1`; and `φ(a_i) φ(a_i^-1) = φ(1) = 1`.
2. Define the homomorphism `ψ` from the free group on `x_0, x_1` to `H` by `ψ(x_i) = φ(a_i)`. By induction on
   length, `ψ(w) = φ(value of w)` for every prefix `w` of a word listed above: if `w = w' s` with `s = x_i^(±1)`,
   then the values of `w'`, `s` and `w` lie in `E`, so `φ(w) = φ(w') φ(s) = ψ(w') ψ(s)`.
3. So `ψ(R_j) = φ(1) = 1`, and `ψ` factors through a homomorphism `ψ̄ : F → H`.
4. `ψ̄(c) = φ(value of c) ≠ φ(1) = 1`, by injectivity on `E`, since `c ≠ 1` in `F_0`.
5. So `ker ψ̄` does not contain `c`, and it is trivial by Lemma 1.2. So `H` contains a copy of `F`, against
   `H ∈ 𝓕`. `∎`

Limits in the space of marked groups and residually-`𝓕` groups are locally embeddable into `𝓕`: in the first case
large balls of `G` agree with balls of the approximants, and in the second a homomorphism injective on `E` is such a
`φ`.

**(O1), (O2), (O4), (O7).** These are Theorem T1 of `f-free-groups-are-closed-under-recurrent-extensions`, items 1,
3, 2 and 4, for the same class `𝓕`.

**Item 2.** Combine (O1)–(O7). `∎`

**Item 3.** If `F` embeds in a member of `𝓑 ⊆ 𝒫(𝓑)`, it embeds in a member of `𝒫(𝓑)`. Conversely, suppose `F`
embeds in no member of `𝓑`. Then `𝓑 ⊆ 𝓕`, and `𝓕` is closed under (O1)–(O7) by item 2, so `𝒫(𝓑) ⊆ 𝓕`. `∎`

**Item 4.** By item 3 and (O1), `F ∈ 𝒫(𝓑_0)` implies that `F` embeds in an amenable, LEA or LEF group `H`.
- If `H` is amenable, so is its subgroup `F`.
- Local embeddability passes to subgroups, by restricting the finite sets. If `H` is LEA, then `F` is LEA, hence
  amenable by `thompson-f-is-lea-only-if-amenable`.
- If `H` is LEF, then `F` is LEF. Since `F` is finitely presented (`thompson-f-is-of-type-f-infinity`), it is
  residually finite by `finitely-presented-lef-groups-are-residually-finite`, contradicting
  `thompson-f-is-not-residually-finite`.

Conversely, if `F` is amenable, then `F ∈ 𝓑_0 ⊆ 𝒫(𝓑_0)`.

For the last sentence: if some `G ∈ 𝒫(𝓑_0)` contains `F`, then `F ∈ 𝒫(𝓑_0)` by (O1), so `F` is amenable. `T` and
`V` contain `F`. `∎`

## (A) Graded units

1. **Inverses are homogeneous.** Let `u ∈ R_d` be a unit and `v = u^{-1} = Σ_g v_g`.
   - Comparing degrees in `uv = 1` gives `u v_g = 0` for `g != -d`.
   - Then `v_g = u^{-1}(u v_g) = 0`. So `v = v_{-d}`.
2. **Dependence.** Let `d_i` be the degree of `u_i`. The images of `d_1, …, d_{s+1}`
   in `Γ ⊗ Q` lie in a space of dimension `<= s`. So there is `0 != n ∈ Z^{s+1}`
   with `Σ n_i d_i` torsion. Multiply `n` by the order of that element, so
   `Σ n_i d_i = 0`.
3. **Degree-0 monomial.** By step 1, `w = ∏ u_i^{n_i}` is homogeneous of degree
   `Σ n_i d_i = 0`, so `w ∈ R_0`. The `u_i` commute, so `w = φ(t^n)`.
4. **Relation.** `w` is algebraic, so `p(w) = 0` for some `0 != p ∈ F[z]`.
   - `t^n` has infinite order in `Z^{s+1}`, so the powers `t^{kn}` are distinct
     group elements.
   - Hence `P = p(t^n) ∈ F[Z^{s+1}]` is nonzero, while `φ(P) = p(w) = 0`. ∎(A)

## (B) Local matrix algebras

1. **One stage.** `F[x_1, …, x_{s+1}]` is finitely generated, so it lies in some
   `R_λ ⊆ ∏_{j <= k} M_{n_j}(A_j)`.
2. **One factor.** Let `I_j` be the kernel of the `j`-th projection on `F[x]`.
   Then `I_1 ⋯ I_k ⊆ ∩ I_j = 0`. As `F[x]` is a domain, some `I_j = 0`. So
   `F[x] ⊆ M_n(A)` for one factor `(n, A)`.
3. **Integral hull.** Let `A' ⊆ A` be the `F`-subalgebra generated by the finitely
   many matrix entries of `x_1, …, x_{s+1}`. Then `x_i ∈ M_n(A')`.
   - Embed `A'` as scalar matrices. Let `S ⊆ M_n(A')` be the subalgebra generated
     by `A'` and the `x_i`. It is commutative, since scalars are central and the
     `x_i` commute.
   - `S` is a finitely generated `F`-algebra, so it is Noetherian.
   - By Cayley–Hamilton over the commutative ring `A'`, `χ_{x_i}(x_i) = 0` with `χ_{x_i}`
     monic over `A'`. So `S` is integral over `A'`.
   - `A' -> S` is injective. By Cohen–Seidenberg, `dim S = dim A' <= s`, by the
     local-dimension hypothesis.
4. **A minimal prime.** `S` has finitely many minimal primes `P_1, …, P_r`, and their
   intersection is the nilradical `N`.
   - `F[x] ∩ N = 0`, because a nilpotent of `S` lying in the reduced ring `F[x]` is
     nilpotent there, hence `0`.
   - So `∏_j (F[x] ∩ P_j) ⊆ F[x] ∩ N = 0`. The domain argument of step 2 gives
     `F[x] ∩ P = 0` for some `P = P_j`.
5. **Contradiction.** `F[x] -> S/P` is injective. `S/P` is a finitely generated
   `F`-domain, so `trdeg_F Frac(S/P) = dim S/P <= dim S <= s` (Noether
   normalisation). But `Frac(S/P) ⊇ F(x_1, …, x_{s+1})`, which has transcendence
   degree `s+1`. ∎(B)

`F[Z^{s+1}] ⊇ F[t_1, …, t_{s+1}]`, so (B) excludes `F[Z^{s+1}]` too.

## Host applications

- **Grading.** `L(E_d)` is `Z`-graded by `|μ| - |ν|` on `μν^*`.
  - Its core `L(E_d)_0` is the union over `m` of `span{μν^* : |μ| = |ν| <= m}`.
  - Each of these spaces is finite dimensional, since `E_d` is finite.
  - Each is closed under multiplication: `μν^*κλ^*` is `0`, `μκ'λ^*` when
    `κ = νκ'`, or `μ(λν')^*` when `ν = κν'`. In every case both lengths stay at most
    `m` and remain equal.
  - So `L(E_d)_0` is locally finite dimensional, hence algebraic.
- **The `Z^3`-grading of `H`.** `(B_Ω)_a = LC(Ω) δ_a` for `a ∈ Z^2`. The tensor
  grading is `H_{(a,b)} = (B_Ω)_a ⊗ L(E_d)_b`. So `H_0 = LC(Ω) ⊗ L(E_d)_0`.
  - A finitely generated subalgebra of `H_0` lies in `C ⊗ D` with `C`, `D` finite
    dimensional, so it is algebraic.
  - Apply (A) with `s = 3`. This gives Consequences 1 and 2.
- **Corners.** For a degree-0 idempotent `p`:
  - `pRp` is graded with core `p R_0 p ⊆ R_0`;
  - `M_k(R)` is graded with core `M_k(R_0)`, locally finite when `R_0` is.
  - Ara–Moreno–Pardo (`V(L(E)) ≅ M_E`) gives, for any idempotent `e ∈ L(E_d)`, a
    diagonal `p` of vertex projections in some `M_k(L(E_d))`, together with
    `x ∈ e M_{1×k} p` and `y ∈ p M_{k×1} e` satisfying `xy = e` and `yx = p`.
  - Then `a ↦ y a x` is a ring isomorphism `e L e -> p M_k(L) p`, with inverse
    `b ↦ x b y`.
  - Apply (A) with `s = 1`. This gives Consequence 3.
- **Odometer pieces.** A transitive `Z^r`-action on `Z^r/Λ` has
  `LC(Z^r/Λ) ⋊ Z^r ≅ M_N(F[Λ])`, `N = [Z^r:Λ]`: this is the standard
  induced-algebra identification.
  - `LC(X) ⋊ Z^r` is the directed union of these over the finite quotients.
  - Tensoring with a locally matricial `D` keeps it locally `M_{N'}(F[Z^r])`.
  - Apply (B) with `s = 3`. This gives Consequence 4.

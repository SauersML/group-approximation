Lane proof, not reviewed.

## Part 1 (host ⇒ uniform word problem)

Fix `H = ⟨Y⟩` finitely generated, with an algorithm `D` deciding its word problem.
Given `P = ⟨X | R⟩ ∈ 𝒞` and a word `w` over `X`, run two searches in parallel.

- **(i)** Enumerate the consequences of `R`. Halt with "`w = 1`" if `w` appears.
- **(ii)** Enumerate all assignments `φ : X -> Y^±*`. For each one, use `D` to check
  that `φ(r) = 1` in `H` for every `r ∈ R` (finitely many checks), and that
  `φ(w) ≠ 1` in `H`. Halt with "`w ≠ 1`" when both hold.

**Soundness.** If (ii) halts, `φ` induces a homomorphism `G_P -> H` with
`φ(w) ≠ 1`, so `w ≠ 1` in `G_P`. If (i) halts, `w = 1`.

**Termination.** If `w = 1`, then (i) halts. If `w ≠ 1`, write the given embedding
`ι : G_P -> H` by words. It is one of the assignments in (ii), and it passes both
checks. So exactly one search halts, with the correct answer.

The procedure uses `D` and `P` only. If `H` is finitely presented simple, `D` exists
by `simple-envelope-forces-solvable-word-problem` (uniformly in the presentation of
`H`), so the statement covers that case.

**Varying hosts, (c) ⇒ (a) of item 4.** Suppose an algorithm gives `(S_P, φ_P)` from
`P`, with `S_P` finitely presented simple. The same argument works with `H = S_P` and
`D` the uniform simple-group procedure: `u ≠ 1` in `S_P` iff `S_P/⟨⟨u⟩⟩` is trivial,
which is r.e. because `S_P ≠ 1`. So the word problem is uniform on `𝒞`. (This is also
immediate from `φ_P` directly.)

## Part 2 (c.e. and uniform ⇒ common finitely presented decidable host)

1. **Free product.** Enumerate `𝒞` as `P_1, P_2, …`; repetitions are harmless.
   Let `W = *_i G_{P_i}`, generated by the disjoint union of the generating sets.
2. **`W` is countable with solvable word problem.** Given a word, split it into
   maximal syllables from single factors. Delete a syllable that is trivial in its
   factor (decided by the uniform algorithm), merge the neighbours it separated, and
   repeat. By the normal form theorem for free products, the word is trivial iff
   this reaches the empty word. So the generating enumeration and the decider are
   computable.
3. **Two-generated overgroup.** By the Higman–Neumann–Neumann embedding for countable
   decidable groups (survey arXiv:2306.16356v3, Prop. 3.3, quoted in
   `countable-decidable-bh-from-boone-higman`), `W` embeds in a two-generated group
   `W*` with solvable word problem. The images of the generators of `W` are explicit
   words in the two generators, computable from the index.
4. **Finitely presented overgroup.** By `clapham-fp-embedding-preserves-word-problem`,
   `W*` embeds in a finitely presented `K` with solvable word problem, by a fixed
   embedding.
5. **Computable embeddings.** Composing the factor inclusion `G_{P_i} -> W` (from the
   enumeration index of `P`) with these fixed embeddings gives words for the
   generators of `P` in `K`, computable from `P`. Search the enumeration for `P`; it
   occurs because `P ∈ 𝒞`.

## Part 3 (Boone–Higman ⇒ common simple host)

Assume `boone-higman-conjecture`. By `countable-decidable-groups-embed-in-fp-simple-groups`
(equivalent to it via survey Cor. 3.5), the countable decidable group `W` embeds in
a finitely presented simple `S`, by a fixed embedding `W -> S` whose generator images
we hard-code. Composing with the computable inclusions `G_P -> W` gives computable
embeddings into one `S`. (Boone–Higman applied to `W*` does the same.)

## Items 4 and 5

- **Item 4.**
  - (a) ⇒ (b) and (a) ⇒ (c): part 3.
  - (b) ⇒ (a): part 1, with `H = S`.
  - (c) ⇒ (a): the varying-host paragraph of part 1.
  - Unconditional equivalence of (a) with a common finitely presented decidable host:
    parts 1 and 2.
- **Item 5.**
  - ⇒: item 4.
  - ⇐: a singleton class `{P}` with `G_P` decidable is c.e. with uniformly solvable
    word problem. Its common simple host embeds `G_P`. Finitely generated inputs reduce
    to finitely presented ones by Clapham.

## Corollaries

- **Boone–Rogers.** Part 1 turns a universal decidable host into a uniform word
  problem algorithm for all finitely presented groups with solvable word problem.
  Boone–Rogers (1966) show that no such algorithm exists.
- **Polynomial Dehn class.** Item 4 of `polynomial-dehn-fp-groups-have-nonuniform-word-problem`
  says `[x_e, y_e] = 1` in `H_e` iff `phi_e(0)` halts, with `P_e` computable from `e`.
  A common decidable host for all `H_e` would decide this by part 1, and so decide the
  halting problem. Every `H_e` lies in both stated complexity classes, by items 1 and 2
  of that node.
- **Hyperbolic and one-relator groups.** Apply part 2 (and, conditionally, part 3) to
  the c.e. set of hyperbolic presentations, with the uniform word problem given by
  finding `δ` and then running Dehn's algorithm, and to the set of one-relator
  presentations with Magnus's uniform algorithm. The textbook citations were not
  re-read at source.

Notation of the claim. `G = Gamma^`, `K = ker phi^`, `D_d` the Zassenhaus
filtration of `G`, `d0 < infinity` the first deviation degree. We use two
facts from the inertness claim:
- (Z1) `D_(d0)/D_(d0+1)` is central in `G/D_(d0+1)`, and `D_(d0)^p` lies
  in `D_(d0+1)`;
- (Z2) `K` lies in `D_(d0)`.

We also use its (P): `Pi` is well defined, lies in `Kd0`, is invariant
under `I_1`-conjugation, and vanishes on `phi(v)` for `v` in a vertex group.

## 1. Additivity (A)

Let `y, z` in `I_1` commute, with `y^p = z^p = 1`, and choose lifts
`yt, zt`.

1. `phi^([yt, zt]) = [y, z] = 1`, so `k = [yt, zt]` is in `K`, which lies
   in `D_(d0)` by (Z2).
2. Work in `Q = G/D_(d0+1)`. The image of `k` is central by (Z1). So the
   image `H` of `<yt, zt>` has `[H, H]` generated by the central element
   `k`, and `H` has class at most 2.
3. In a group of class 2 we have
   `(xy)^m = x^m y^m [y, x]^(m(m-1)/2)`. With `m = p` odd, the exponent
   `p(p-1)/2` is a multiple of `p`. By (Z1), `k^p` is in `D_(d0+1)`, so the
   commutator factor vanishes in `Q`.
4. Hence `(yt zt)^p = yt^p zt^p` modulo `D_(d0+1)`. Here `yt zt` lifts
   `yz`, and `(yz)^p = 1`. Both sides lie in `D_(d0)` by (Z2), so
   `Pi(yz) = Pi(y) + Pi(z)`.
5. Induction gives `Pi(y^k) = k Pi(y)`. On an abelian subgroup of exponent
   `p`, `Pi` is therefore a homomorphism.

## 2. Vertex root elements

`phi` maps `a, b, c` to `x12(1)`, `x23(1)`, `x31(t)`. The group commutator
`[x,y] = x^-1 y^-1 x y` gives
`[a,b] -> x13(1)`, `[b,c] -> x21(t)` and `[c,a] -> x32(t)`
(`root_conj.py`, part 1). These are central in the Heisenberg vertex groups
`U_ab`, `U_bc` and `U_ca`. So for every root `(i,j)` and every `lam` in
`F_p`, the element `x_ij(lam t^v0)` is `phi` of a vertex element, namely a
power of the corresponding generator or commutator. Here `v0 = 0` for
`i < j` and `v0 = 1` for `i > j`.

## 3. Torus rescaling

Let `u` be in `1 + tO`. Since `p` is odd, `u` has a square root `r` in
`1 + tO`, given by the binomial series. Put `d = diag(d_1, d_2, d_3)` with
`d_i = r`, `d_j = r^-1` and the third entry `1`. Then `det d = 1`,
`d = 1 mod t`, so `d` is in `I_1`, and `d_i/d_j = u`. For every `f`,
`Ad(d) x_ij(f) = d x_ij(f) d^-1 = x_ij((d_i/d_j) f) = x_ij(u f)`.

## 4. Proof of (V)

Let `x_ij(f)` be in `I_1`. Then `t^v0` divides `f`; write `f = t^v0 g`
with `g` in `O`. Every root element has order `p`, because
`x_ij(f)^p = x_ij(p f) = 1`.

- **Case `g(0) = lam != 0`.** Put `u = g/lam`, which is in `1 + tO`. By §3,
  `x_ij(f) = Ad(d) x_ij(lam t^v0)`. By §2 this is an `I_1`-conjugate of a
  vertex element, so `Pi(x_ij(f)) = 0` by (P).
- **Case `g(0) = 0`.** Then `1 + g` is in `1 + tO` and
  `x_ij(f) = x_ij(t^v0 (1+g)) . x_ij(-t^v0)`. The two factors lie in the
  abelian group `X_ij`. The first is a vertex conjugate by the first case,
  and the second is a vertex element. Both have `Pi = 0`, so `Pi(x_ij(f)) = 0`
  by (A).

For a product `y_1 ... y_r` of pairwise commuting root elements, each of
order `p`, apply (A) repeatedly; partial products commute with the
remaining factors. Each factor has `Pi = 0`, so the product does too.
Conjugates follow from (P). The listed pairs of root groups commute because
`E_ij E_kl = 0 = E_kl E_ij` for them. For example, `E21 E23 = 0` and
`E23 E21 = 0`.

## 5. Proof of (N)

1. **Content.** For `h` in `GL_3(O)`, the entries of `h(y-1)h^-1` generate
   the same ideal of `O` as those of `y-1`, since conjugation and its
   inverse are `O`-linear.
   - Every element of `phi(U_ab)` other than 1 has content `(1)`.
   - An element `x23(u) x31(tv) x21(tw)` of `phi(U_bc)` has content `(1)`
     if `u != 0`, and `(t)` otherwise.
   - The same holds in `phi(U_ca)`, with the constant coordinate on `x12`.
   - `x21(t^n) - 1 = t^n E21` has content `(t^n)`. For `n >= 2` it is not a
     conjugate of any vertex element or its powers.
2. **Leading term at content `(t)`.** If `y = 1 + tM` with `M` integral,
   then for `h` in `I_1` we have `h y h^-1 = 1 + t Ad(h)M`, and
   `Ad(h)M = Ad(h mod t)(M mod t) mod t`, with `h mod t` in `B^+(F_p)`.
   The content-`(t)` vertex elements have `M mod t = v E31 + w E21` or
   `v E31 + w E32`. Each is a rank-one matrix `x y^T` whose image vector `x`
   has a nonzero `e_2` or `e_3` coordinate, and unipotent upper triangular
   `h` keeps that property for `hx`. The matrices `E13`, `E12` and `E23`
   have image `e_1`, so they are not in the orbit. The orbits were also
   enumerated exhaustively for `p = 5, 7, 11` (`root_conj.py`, part 3).
   So `x13(t)`, `x12(t)` and `x23(t)` are not vertex conjugates. For the
   lower roots with exponent 1 and the upper roots with exponent 0 the
   first case of §4 already applies.

   Precisely, the property kept is this: if `x_2 = x_3 = 0` fails for `x`,
   it fails for `hx`, since `h` is upper unitriangular. Its lower two rows
   form an invertible upper triangular block acting on `(x_2, x_3)`.

## 6. Proof of (O)

Sections 1–4 use (Z1), (Z2), (P), the vertex images and the diagonal torus
of `I_1`, and nothing else. None of these depends on `V_n`. So for any
`V_n` with `V_n <= W_n`, including `V_n = 0`, the conclusion
`Pi = 0` on root-type elements holds. So it cannot imply `C_nA in V_n`,
`C_nB in V_n` or `K_n in V_n`.

The bridge of the inertness claim, (B), predicts
`Pi(x12(lam) x21(t^n) x12(-lam)) = lam C_nA mod V_n`. The left side is a
conjugate of a root element, so it is 0 by (V). So (Bridge_n) holds exactly
when `C_nA` lies in `V_n`, which agrees with (B). Neither statement gives
the other for free.

## 7. What is left for the Cartan half

A class in `W_n` that no torsion statement sees must come from a relator of
`I_1` that is not of the form "an order-`p` element has order `p`". The
torus relator `h(1+t^n)^p = h(1+t^(np))` of the `12` block is the natural
candidate. It is a word in root elements by the Bruhat identity
(`root_conj.py`, part 4). The class of its lift at `3np` is well defined only
after the root-element lifts are fixed modulo `D_(d0+1)`. §4 fixes them as
vertex conjugates, and the remaining freedom is exactly the centralizer
pairing `delta_v(c) = [ct, v] mod D_(d0+1)`, for `c` in `C_(I_1)(phi v)`.
For `c, c'` in the centralizer, `delta_v(cc') = delta_v(c) + delta_v(c')`,
because the top layer is central. Also `delta_v(c^p) = 0`. The next step
named in the claim is to compute these pairings.

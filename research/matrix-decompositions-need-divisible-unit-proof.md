1. **Idempotent classes.** An isomorphism `φ: M_N(A) → M_k(R_X)` sends the matrix units `E_ii` to orthogonal idempotents `f_i = φ(E_ii)` of `M_k(R_X)` with `Σ_i f_i = 1`. The `E_ij` give `f_i ~ f_j` (Murray–von Neumann equivalence: `E_ij E_ji = E_ii`, `E_ji E_ij = E_jj`). So in `K_0(M_k(R_X))` we have `[1] = N[f_1]`.
2. **Morita.** `K_0(M_k(R_X)) = K_0(R_X)`, and under this identification `[1_{M_k(R_X)}] = k[1_{R_X}]`.
3. **Transfer.** By `subshift-crossed-product-k0-is-coinvariant-group`, `K_0(R_X) ≅ K^0`, with `[1] ↦ [χ_X]`. So `k[χ_X] = N·c` with `c` the image of `[f_1]`.
4. **Measures.** A `T`-invariant Borel probability `μ` defines a homomorphism `C(X,Z) → R`, `f ↦ ∫f dμ`, that kills `(1−T_*)C(X,Z)` by invariance, so it factors through `K^0`, with `[χ_X] ↦ 1` and `[χ_U] ↦ μ(U)`. Applying it to `k[χ_X] = N·c` gives `k = N·μ(c)`, and `μ(c)` lies in the subgroup `μ(K^0)` generated by clopen measures (every `f ∈ C(X,Z)` is an integer combination of clopen indicators). ∎
5. **Divisibility (optional).** If `K^0` is torsion-free (Herman–Putnam–Skau for minimal `T`; an import, not used in step 6), put `d = gcd(N,k)`, `N = dN′`, `k = dk′`. Then `k′[χ_X] = N′c`, and with `ak′ + bN′ = 1` we get `[χ_X] = N′(ac + b[χ_X])`.
6. **Sturmian.** `X_α` is uniquely ergodic, and clopen sets have measures in `Z + αZ` (they are finite unions of cylinder sets, whose measures are lengths of arcs cut by the points `−jα mod 1`, as in the note's Sturmian coding; recalled, not re-read at source). With `k = 3`, `N = 3·2^n` step 4 gives `2^{−n} ∈ Z + αZ`, which forces `n = 0` because `α` is irrational.

**Checks.** Model test, dyadic odometer (`K^0 = Z[1/2]`): the divisibility holds for all `n`, consistent with `M_2(R) ≅ R`-type decompositions from constant towers. Model test, finite `X` of size `p` (not minimal-infinite, `R_X = M_p(F_q[t^{±1}])`): `K^0 ≅ Z` with `[χ_X] = p`, consistent.

Let `m >= 1` and `E(m) = <e_ij(m) : i != j> <= SL_3(Z)`.

1. `e_ij(mx) = e_ij(m)^x`, so `E(m)` is the subgroup generated by all level-`mZ`
   elementary matrices.
2. By `sl3-level-q-elementary-group-contains-e3-of-q-squared` with `q = mZ`,
   `E(m) >= E_3(Z, m^2 Z)`.
3. By `sl3z-relative-elementary-equals-principal-congruence`,
   `E_3(Z, m^2 Z) = Γ(m^2) = ker(SL_3(Z) -> SL_3(Z/m^2 Z))`.
4. `[SL_3(Z) : Γ(m^2)]` is the order of the image of reduction, at most
   `|SL_3(Z/m^2 Z)|`.

So `E(m)` contains `Γ(m^2)` and has index at most `|SL_3(Z/m^2 Z)|`. This is
Corollary D of the artifact. The route does not use Tits's note.

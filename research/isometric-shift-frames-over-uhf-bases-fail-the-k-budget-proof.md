**Item 1.** View `s` as a `1 × k` and `t` as a `k × 1` matrix over `R`.
- `s t = 1` and `t s = p`. Also `s p = s t s = s` and `p t = t s t = t`. So `1 in M_1(R)` and `p in M_k(R)` are
  equivalent idempotents, and `[1_R] = [p]_R` in `K_0(R)`.
- `[p]_R` is the image of `[p]_B` under `K_0(B) -> K_0(R)`, and `[1_R]` is the image of `[1_B]`.
- If `m [p]_B = n [1_B]`, then `m [1_R] = m [p]_R = n [1_R]`, so `(m - n)[1_R] = 0`.

**Matricial bases.** Let `B = ∪_i B_i` with `B_i ≅ M_(n_i)(Q)` and unital inclusions.
- `K_0` commutes with directed unions, and `K_0(M_(n_i)(Q)) = Z`, generated by a rank-one idempotent, with
  `[1] = n_i`. The unital inclusions multiply by `n_j / n_i`, which is injective. So `K_0(B)` is identified with
  a subgroup of `Q` by `[e] -> rank(e) / n_i` for `e` in some `M_k(B_i)`, with `[1_B] = 1`.
- **Cancellation.** If idempotents `e, f in M_k(B)` have `[e] = [f]`, pick `i` with `e, f in M_k(B_i) = M_(k n_i)(Q)`.
  Their classes agree there, since the maps are injective. So they have the same rank and are equivalent
  over `Q`: `e = x y` and `f = y x` with `x in e M_k(B_i) f` and `y in f M_k(B_i) e`.

**Item 2.** `[p] = r = n/m`, with `m, n >= 1`, gives `m [p] = n [1_B]`, and `r != 1` means `m != n`. By item 1,
`[1_R]` has finite order. Then `rational-k1-detection-forces-infinite-order-unit-class`, item 1, gives
`ker(Q^x -> K_1(R)) ⊇ (Q^x)^(2 s' t')` for some `s', t' >= 1`, which is not finitely generated.

**Item 3.**
- `r = 1` means `[p] = [e_11]` in `K_0(B)`, where `e_11 in M_k(B)` is the matrix unit. By cancellation, `p = x y`
  and `e_11 = y x` with `x in p M_k(B) e_11` and `y in e_11 M_k(B) p`.
- Put `u = (s x)_1` and `v = (y t)_1`, the only possibly nonzero entries of the row `s x = s x e_11` and the column
  `y t = e_11 y t`.
- `u v = (s x)(y t) = s p t = (s t)(s t) = 1`, and `v u = (y t s x)_(11) = (y p x)_(11) = (y x)_(11) = 1`. So `u`
  is a unit with inverse `v`.
- **Intertwining.** Since `s = s p = s x y` and `s t = 1`, `b u = (b s x)_1 = (s t b s x)_1 = (s x y t b s x)_1 = u · v b u`.
  So `u^-1 b u = v b u = (y (t b s) x)_(11)`, which lies in `B` when `t B s ⊆ M_k(B)`, the intertwining of the
  Cuntz--Pimsner shape. The graded conclusion does not use this.
- **Grading.** If `s_i in R_1`, `t_i in R_(-1)` and `B ⊆ R_0`, then the entries of `x` and `y` lie in `B ⊆ R_0`, so
  `u in R_1`. `Q ⊆ B` gives the unital map `Q -> R`. So `graded-rings-with-degree-one-units-fail-the-k-budget`
  applies to `R` and `u`.

**Item 4.** `K_0(B) ⊆ Q`, so `[p] = r` for some positive rational `r`. Since `p != 0` (`1 = s p t`), items 2 and 3
cover every value of `r`.

**Calibration.** For `L_Q(1,d)` with `s = (s_1, ..., s_d)` and `t = (t_1, ..., t_d)^T`, `t_i s_j = δ_ij`, so
`p = I_d` and `r = d`. For `U_n ⋊ Z`, take `s = u`, `t = u^-1`.

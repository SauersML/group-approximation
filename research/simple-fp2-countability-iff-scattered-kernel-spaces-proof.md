Notation as in the claim. `H` is generated by the finite set `X`. For
`h ∈ H`, `[h ∈ N]` denotes the clopen subset `{N : h ∈ N}` of `N(H)`.

## 1. `MP(H)` is `G_δ`

`N(H)` is closed in `{0,1}^H`, because containing `1` and closure under
products, inverses and conjugation are each intersections of clopen
conditions. `H` is countable, so `N(H)` is compact metrizable.

- **`N ≠ H`.** This is `∪_{x∈X} (N(H) ∖ [x ∈ N])`, which is open.
- **Perfect.** For `w ∈ H`, let `O_w` be the union of `N(H) ∖ [w ∈ N]` with
  the sets `[a_1 ∈ N] ∩ [b_1 ∈ N] ∩ ... ∩ [b_m ∈ N]`, taken over all words
  `w = [a_1,b_1]...[a_m,b_m]` in `H`. Each such set is a finite intersection of
  clopen sets, so `O_w` is open. `N` is perfect iff `N ∈ ∩_w O_w`.
- **Maximal.** `H/N` is simple iff `N ≠ H` and every `w ∉ N` satisfies
  `⟨⟨N ∪ {w}⟩⟩ = H`, that is, contains every `x ∈ X`. The condition
  `x ∈ ⟨⟨N ∪ {w}⟩⟩` holds iff some expression
  `x = ∏_j g_j u_j g_j^{-1}`, with each `u_j` either `w^{±1}` or designated,
  has all designated `u_j` in `N`. So it is a union of finite intersections of
  clopen sets, which is open. Since `X` is finite, `[w ∈ N] ∪ ∩_{x∈X} {x ∈ ⟨⟨N∪{w}⟩⟩}`
  is open. Intersecting over the countably many `w` gives a `G_δ` set.

So `MP(H)` is a countable intersection of open subsets of the compact metric
space `N(H)`.

A `G_δ` subset `G = ∩_n U_n` of a complete metric space `(Z, d)` is
completely metrizable. One complete metric on `G` is
`d'(y,z) = d(y,z) + Σ_n 2^{-n} min(1, |1/d(y, Z∖U_n) − 1/d(z, Z∖U_n)|)`.
A `d'`-Cauchy sequence is `d`-Cauchy, and its limit stays at positive distance
from each `Z∖U_n`, hence lies in `G`. `MP(H)` is also second countable, so it
is Polish.

## 2. Perfect-set lemma

**Lemma.** Let `Y` be a Polish space. Then `Y` is countable iff it is
scattered, and `Y` is uncountable iff it contains a homeomorphic copy of the
Cantor set `2^N`.

**Proof.** Let `Y_c` be the set of points of `Y` that have a countable open
neighbourhood.

- **`Y_c` is countable.** Fix a countable base `(B_n)`. Then `Y_c` is covered
  by the countably many countable `B_n`.
- **`P = Y ∖ Y_c` is closed, and every nonempty relatively open subset of `P`
  is uncountable.** If `U` is open and meets `P`, then `U` is uncountable and
  `U ∩ Y_c` is countable. In particular `P` has no isolated points.

The four implications:

- **Scattered ⇒ countable.** `P` is closed without isolated points, so
  scatteredness forces `P = ∅` and `Y = Y_c`.
- **Countable ⇒ scattered.** A nonempty closed `F ⊆ Y` is Polish and is the
  countable union of its closed singletons. By the Baire category theorem some
  singleton is open in `F`, so its point is isolated.
- **Cantor copy ⇒ uncountable.** Trivial.
- **Uncountable ⇒ Cantor copy.** If `Y` is uncountable then `P ≠ ∅`. Fix a
  complete metric `d`. Build open sets `U_s`, for finite binary strings `s`,
  with these properties:
  - each `U_s` meets `P`;
  - `diam U_s ≤ 2^{-|s|}`;
  - `cl U_{s0}` and `cl U_{s1}` are disjoint and contained in `U_s`.

  The construction is possible because `U_s ∩ P` contains two distinct points,
  and small balls around them do the job. For `α ∈ 2^N`, the nested nonempty
  closed sets `cl U_{α|n}` have diameters tending to `0`, so they meet in
  exactly one point `f(α)`. The map `f` is injective, since closures separate
  at the first differing digit. It is continuous, since
  `β|n = α|n` implies `d(f(α), f(β)) ≤ 2^{-n}`. A continuous injection from
  a compact space into a Hausdorff space is an embedding. `∎`

## 3. The equivalences (a)–(e)

- **(a) ⇔ (b).** By `simple-fp2-uncountability-via-perfect-simple-quotients`,
  (a) fails iff some finitely presented `H` has uncountably many perfect normal
  `N` with `H/N` simple. Simple groups are nontrivial, so these are exactly
  uncountably many points of `MP(H)`.
- **(b) ⇔ (c) ⇔ (d).** Apply the Lemma to the Polish space `MP(H)` (Section 1).
- **(e) ⇒ (b).** If `N ∈ MP(H)`, then `H/N` is a finitely presented group
  modulo a perfect normal subgroup, hence of type FP_2 by
  `fp2-iff-quotient-of-fp-group-by-perfect-normal-subgroup`, and `N` is
  maximal.
- **(a) ⇒ (e).** Suppose a finitely presented `H` has uncountably many maximal
  `N` with `H/N` of type FP_2. A surjection from `H` is determined by the
  images of `X`, so for a fixed countable group `Σ` only countably many `N`
  have `H/N ≅ Σ`. So the simple FP_2 groups `H/N` realize uncountably many
  isomorphism types, and (a) fails.

## 4. Kernel criterion

**(⇐).** Put `N' = ⟨⟨F⟩⟩`. By
`fp-quotient-iff-kernel-finitely-normally-generated`, `H/N'` is finitely
presented. From `N = N'[N,N]` we get `N/N' = [N/N', N/N']`, so `N/N'` is
perfect. Then `H/N ≅ (H/N')/(N/N')` is of type FP_2 by
`fp2-iff-quotient-of-fp-group-by-perfect-normal-subgroup`.

**(⇒).** Let `Q = H/N` be of type FP_2. The same claim gives
`Q ≅ H'/N'` with `H'` finitely presented by `⟨X' | R'⟩` and `N'` perfect.

1. For `x ∈ X`, choose `w_x ∈ H'` mapping to the image of `x` in `Q`. Let
   `R` be a finite set of relators of `H`, and put
   `W = H' / ⟨⟨ r(w_x) : r ∈ R ⟩⟩`. These relators lie in `N'`, and
   `x ↦ w_x` induces a homomorphism `H -> W`.
2. For `x' ∈ X'`, choose a word `v_{x'}` in `X` whose image in `Q` equals that
   of `x'`. Put `W' = W / ⟨⟨ x' v_{x'}(w)^{-1} : x' ∈ X' ⟩⟩`. These
   relators also lie in the kernel of the map to `Q`.
3. `W' = H'/L` with `L ⊆ N'` finitely normally generated, so `W'` is finitely
   presented, and the kernel of `W' -> Q` is `N'/L`, which is perfect.
4. `W'` is generated by the images of `X`, so `H -> W'` is onto with some
   kernel `S`, and the composite `H -> W' -> Q` is the original quotient map.
5. By `fp-quotient-iff-kernel-finitely-normally-generated`, `S = ⟨⟨F⟩⟩` for a
   finite `F`. Also `N/S ≅ N'/L` is perfect, so `N = S[N,N]`. `∎`

## 5. Biography

Assume (a) fails. By Section 3, some finitely presented `H` has `MP(H)`
uncountable.

Let `C ⊆ MP(H)` be the set of `N` such that at least one of the following
holds:

- `H/N` is finite;
- `N` is finitely normally generated;
- the set of words in `X` representing elements of `N` is r.e. or co-r.e.

`C` is countable. There are countably many finite groups, each receiving
finitely many homomorphisms from `H`. There are countably many finite subsets
of `H`, and countably many r.e. and co-r.e. sets of words.
`MP(H) ∖ C = ∩_{c∈C} (MP(H) ∖ {c})` is still `G_δ`, hence Polish, and
uncountable. By the Lemma it contains a Cantor set `K`, which is compact.

**(ii) and (iii).** For `N ∈ K`, `H/N` is simple, infinite and of type FP_2
(Section 3, (e) ⇒ (b)), and (iii) holds by the choice of `K`. The isomorphism
fibres on `K` are countable (Section 3) and `|K| = 2^aleph_0`. Fewer than
`2^aleph_0` types would cover `K` by fewer than `2^aleph_0` countable sets,
which is impossible.

**(i).** Take any `N ∈ K`. `H/N` is infinite simple, hence nonabelian and
perfect, so `H = [H,H]N`. `N` is perfect, so `N = [N,N] ⊆ [H,H]`. Hence
`H = [H,H]`.

**(iv).** Write `H = F/R` with `F` free on `X` and `R` normally generated by
finitely many relators. Then `H/N = F/S` with `S ⊇ R` and `S/R = N`. By Hopf's
formula, `H_2(F/T) ≅ (T ∩ [F,F])/[F,T]` naturally for `T ⊴ F`.

1. Perfectness of `S/R` gives `S = R[S,S] ⊆ R[F,S]`, so `S = R[F,S]`.
2. `[F,S] ⊆ [F,F]`, so the modular law gives
   `S ∩ [F,F] = (R ∩ [F,F])[F,S]`.
3. The natural map `(R∩[F,F])/[F,R] -> (S∩[F,F])/[F,S]` is therefore onto.
4. `H_2(H)` embeds in `R/[F,R]`, which is abelian and generated by the images
   of the finitely many relators, since conjugates agree modulo `[F,R]`. So
   `H_2(H)` is finitely generated.

This works for every `N ∈ MP(H)`.

**(v).** Induct on `k`. Let `I` be the image of `H` in
`P × H/N_k`, where `P = ∏_{i<k} H/N_i`. By induction `I` projects onto `P`,
and it projects onto `H/N_k`. `J = I ∩ (1 × H/N_k)` is normal in `H/N_k`, so
`J = 1` or `J = H/N_k`.

- If `J = H/N_k`, then `I` is everything.
- If `J = 1`, then `I` is the graph of a surjection `θ : P -> H/N_k`. `ker θ`
  is a maximal normal subgroup of a finite product of nonabelian simple groups,
  hence the product of all factors but one, say factor `j`.
  - So `θ` factors through an isomorphism `H/N_j -> H/N_k` compatible with the
    projections from `H`.
  - That forces `N_j = N_k`, a contradiction.

**(vi).** Fix `w`. `K_w = K ∩ [w ∈ N]` is closed in `K`, hence compact. For
each commutator expression `e` of `w`, the set `U_e = [a_1∈N] ∩ ... ∩ [b_m∈N]`
is open, and the `U_e` cover `K_w` because each member is perfect. A finite
subcover gives `E⁺(w)`.

Similarly, `K ∖ [w ∈ N]` is compact. For fixed `x ∈ X`, the open sets
attached to normal-generation expressions of `x` from `N ∪ {w}` cover it by
maximality (Section 1). A finite subcover gives `E⁻(w,x)`. `∎`

**Remark on isolation arguments.** The isolated points of `MP(H)` are
countable, because each is the only point of some basic open set. So proving
that every kernel is isolated would already prove (b), whereas a proof that
only isolates "generic" or "most" kernels leaves room for `K`.

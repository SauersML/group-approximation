## Kodama's generator

For `n ≥ 2`, the map `y` on `C_n = {0,…,n−1}^ω` is defined by (for `1 ≤ k ≤ n−2`)

- `y(00ζ) = 0 y(ζ)`, `y(0kζ) = kζ`, `y(0(n−1)ζ) = (n−1)0 y^(−1)(ζ)`,
- `y(kζ) = (n−1)kζ`, `y((n−1)ζ) = (n−1)(n−1) y(ζ)`.

`y_s` is `y` applied inside the cone `s` and the identity elsewhere. `G_0(n)` is generated by the
generators of `F(n)` together with `y_((n−1)0)`, and `G_0(2)` is Lodha–Moore's group `G_0`.

## Statement

Let `n ≥ 3`, and let `(ψ, g_0, …, g_(n−1))` be an analytic tree coding of `C_n` onto an interval
`J`, as in `analytic-codings-make-contracting-recursions-analytic`. There is no homeomorphism `Y`
of `J` with `ψ ∘ y_((n−1)0) = Y ∘ ψ` that is piecewise analytic. The same holds for `y` itself.

**Consequences.**
1. Take any complete prefix code `c : {0,…,n−1} → {0,1}^*`, recode `C_n` onto `C_2`, and then
   apply Lodha–Moore's coding `Φ` of `C_2` onto a subinterval of `RP^1`, whose cone maps lie in
   `PSL_2(Z)`. This never conjugates `G_0(n)` into Monod's `H(R)`, into the Lodha–Moore group `G`,
   or into any group of piecewise real-analytic homeomorphisms. The same goes for every n-ary
   Farey, Stern–Brocot or PL coding.
2. So a positive answer to Kodama's question needs an action of `G_0(n)` on the line in which the
   cone structure of `F(n)` is not coded analytically. Every action that comes from the natural
   action through an analytic coding is excluded.
3. The obstruction uses only two of the five rules for `y`: the contracting rule
   `y(00ζ) = 0y(ζ)` and one finitary rule `y(0kζ) = kζ`. So it excludes every generalization of
   `y` that has a contracting branch and a finitary branch arranged this way. This matches
   Kodama's own remark (arXiv:2204.08230v2, l.173–174) that a generalization lying inside `H`
   might have to use a different `y`.

**Calibration.** For `n = 2` there is no digit `k` and hence no finitary branch. Lodha–Moore's
coding then makes `y` the single projective map `t ↦ 2t` on `[0, ∞]`, consistent with the claim.

## Lesson for general BH

The n-adic Lodha–Moore groups fail to be analytic because germs propagate along a contracting
recursion. This is a close cousin of the germ rigidity at fixed points that excludes Higman's group
from the same hosts. A finitary branch then pins the
generator to one analytic map, and the recursion forces the cone map to be the identity. Reading an
algebraic or self-similar construction into piecewise-projective hosts therefore needs every
generator's finitary and recursive branches to continue each other analytically. Thompson-type
(prefix-replacement) hosts have no such constraint. This is a structural reason to build general
Boone–Higman envelopes on Cantor (prefix-replacement or germ) models rather than one-dimensional
analytic ones.

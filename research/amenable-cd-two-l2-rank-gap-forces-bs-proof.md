Notation as in the target. Modules are left modules, and `⊗ = ⊗_{Z[G]}`. "Items A.1–A.3" are the
items of `l2-small-projectives-with-rank-gap-are-finitely-generated`. "Items K.2, K.4" are items 2
and 4 of `amenable-fp-iff-affiliated-top-homology-vanishes`.

## Item 1

Let `ω ⊆ Z[G]` be the augmentation ideal. Since the `x_j` generate `G`, the elements `x_j − 1`
generate `ω` as a left ideal (Brown, *Cohomology of groups*, II.5). So
`0 → P → Z[G]^d → ω → 0` is exact. `P` is projective because `pd_{Z[G]} Z = cd G = 2` and
`Z[G]^d, Z[G]` are free (Schanuel).

Tensor with `U` to get the exact sequence `Tor_1(U, ω) → U ⊗ P → U^d`. From
`0 → ω → Z[G] → Z → 0`, `Tor_1(U, ω) ≅ Tor_2(U, Z) = H_2(G; U)`. By K.2 with `n = cd G = 2`,
`H_q(G; U) = 0` for `q ≠ 1`, so `H_2(G; U) = 0`. Hence `U ⊗ P → U^d` is injective and
`dim_U(U ⊗ P) <= d` by monotonicity. ∎

## Item 2

Suppose `P` is finitely generated. Choose a surjection `Z[G]^r → P`. Then
`Z[G]^r → Z[G]^d → Z[G] → Z → 0` is a partial resolution by finitely generated free modules, so
`G` is of type `FP_2`. K.4 ((b) ⇒ (a)) gives `G ≅ BS(1,m)`. So if `G ≇ BS(1,m)`, then `P` is
not finitely generated. By item 1 it is `L²`-small. Item A.1 gives the thin elements of `T(P)`.
Item A.3 gives `P = P_0 ⊕ P'` with `P' ≠ 0` having no nonzero finitely generated summand.

If `P ≅ ⊕_λ Q_λ` with each `Q_λ` finitely generated, apply A.3 to the finite sub-sums: each is a
finitely generated summand of `P`, so its dimension is at most `⌊dim_U(U ⊗ P)⌋ <= d`. Each nonzero
`Q_λ` has dimension at least 1, so only finitely many `Q_λ` are nonzero. Then `P` is finitely
generated, a contradiction. ∎

## Item 3

By item 1, `P` is `L²`-small. The hypothesis is that of item A.2, so `P` is finitely generated. As
in item 2, `G` is of type `FP_2`, and K.4 gives `G ≅ BS(1,m)`. `m ≠ 0`, since `BS(1,0) ≅ Z` has
`cd 1`. ∎

## Item 4

*Gap ⇒ Kropholler in cd ≤ 2.* By item 3, every finitely generated amenable group of cd 2 is
`BS(1,m)`, hence of type `FP_2`. K.4 records that this is Kropholler's question for groups of cd
at most 2.

*Kropholler in cd ≤ 2 ⇒ gap, with value 1.* Such `G` is then `BS(1,m)`, a torsion-free solvable,
hence elementary amenable, group. By `elementary-amenable-torsion-free-strong-atiyah`, von Neumann
ranks of matrices over `C[G]` are integers. Take `0 ≠ a ∈ Z[G]`. Then `U a` is a nonzero finitely
generated submodule of `U`. It is a summand by (J2) of A's proof, with positive dimension by (J1).
Its dimension is at most 1. It equals `1 − dim_NG ker(r_a)`, which is an integer. So
`dim_U(U a) = 1`. ∎

## Remark: Ore domains (for the "What it kills" list)

Let `R` be an Ore domain with division ring of fractions `D`, and `P` a projective left
`R`-module with `dim_D(D ⊗_R P) = n < ∞`. Then `P` is finitely generated.

*Proof.* `P` is torsion-free, being a submodule of a free module, so `P → D ⊗ P` is injective.
Every `f ∈ Hom_R(P, R)` extends uniquely to a `D`-linear map `D ⊗ P → D`, so `f` is determined by
its values on any `D`-basis. Pick a `D`-basis `1 ⊗ y_1, …, 1 ⊗ y_n` with `y_k ∈ P`, by clearing
denominators. Take a dual basis `(x_i, f_i)`. Then `f_i ≠ 0` only if `f_i(y_k) ≠ 0` for some `k`,
which happens for finitely many `i`. So `P` is generated by finitely many `x_i`. ∎

This is item A.2 with the rank function of `D` in place of `dim_U`, where the gap is 1. For
amenable `G` with `Z[G]` a domain, Tamari's theorem makes `Z[G]` Ore. So in dimension 2 this
recovers the finiteness step of Degrijse's Theorem B in module form.

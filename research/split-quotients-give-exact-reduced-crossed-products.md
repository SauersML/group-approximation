**ESTABLISHED** by `split-quotients-give-exact-reduced-crossed-products-proof`. Groups are
countable and discrete.

**(A) Coefficient splittings.** Let `0 -> I -> A -> A/I -> 0` be a short exact sequence of
`G`-algebras. Suppose the quotient map `q` has a `G`-equivariant completely positive
contractive `psi : A/I -> A` with `q ∘ psi = id`. Then
`0 -> I ⋊_r G -> A ⋊_r G -> (A/I) ⋊_r G -> 0` is exact. Ozawa's Lemma A.1 in the
Buss--Echterhoff--Willett erratum is the unital case `A/I = C`.

**(B) Co-amenable sections.** Let `M` be an amenable normal subgroup of `Γ`, with
`q : Γ -> Γ' = Γ/M`. Suppose some subgroup `S <= Γ` maps injectively onto a co-amenable
subgroup `S' = q(S)` of `Γ'`. Then `ker(C*_r Γ -> C*_r Γ')` is the closed ideal generated by
`{u_m - 1 : m ∈ M}`.

**(C) Module triples are exact** (setting of
`k-inexact-module-triple-refutes-trivial-coefficient-bc`, `X = V^`, `Z = W^perp`) whenever:
1. `V = W ⊕ V'` as `Z[G]`-modules;
2. `V/W` is finite;
3. `G` is co-amenable in `(V/W) ⋊ G`.

In each case the K-theory sequence is exact at the middle, so none of these triples can feed
the module route.

**(D) Survivors.** Let `p` be prime, `H <= G` infinite, `V = F_p[G]` and
`W = ker(F_p[G] -> F_p[G/H])`, so that `V/W = F_p[G/H]`. The quotient map
`F_p wr G -> F_p wr_(G/H) G` has kernel `W`.
1. `C(X) -> C(Z)` has **no** `G`-equivariant completely positive splitting. In particular
   there is no equivariant continuous map `X -> Prob(Z)` restricting to `zeta ↦ delta_zeta`.
2. If `H` is amenable and `G` is not, then `G` is **not** co-amenable in
   `F_p[G/H] ⋊ G`. Criterion (B) with other sections is not excluded.

So over a non-exact `G` with an infinite amenable subgroup `H` (for example a Gromov monster
and `H = <s>`), the permutational wreath quotient is a module triple that none of (A)--(C)
certifies exact.

**Novelty.** (A) and (B) are elementary and very likely known in this form. The applications
(C) and (D) to module quotients are recorded for the Baum--Connes route.

## 1. Where contraction enters

FH p. 32 say the verification that `(𝕊, ℙ)` is an `S_R`-structure uses the self-similarity and contraction of
Grigorchuk's group, and that `{1, b, c, d}` is a subgroup. They do not name the axiom. The lane's reading is right,
because every other axiom holds for formal reasons:
- **(P1)–(P5) and (S6).** These are formal for the maximal pattern function: images of domain partitions under
  S-maps are domain partitions (Lemma 3.7).
- **(S1)–(S4).** These need only that `H` is a subgroup.
- **(S5), generation.** This is the only axiom that sees sections. For every `f ∈ Ŝ` with domain `D ∈ 𝒟⁺`, it asks
  for a pattern `P ∈ ℙ(D)` with `f|_E ∈ 𝕊(E, f(E))` for every `E ∈ P`.
- **Thm 8.2** never uses sections.

## 2. The (S5) step: the proof as written is vacuous

**The setting (tree coordinates).**
- `S = {g_(ω1,ω2) = σ_(ε,ω2) g σ_(ω1,ε) : g ∈ G}`, with `G` self-similar.
- `𝕊(B_(ω1), B_(ω2)) = {h_(ω1,ω2) : h ∈ H}` for a subgroup `H ≤ G`.
- Call a node `w` **good for `g`** if the section `g|_w` lies in `H`. Since `g_(ε,ε)|_(B_w) = (g|_w)_(w, g(w))`,
  `g|_B_w` is a chosen map exactly when `w` is good.

**The defect.** Both items apply (S5) to `h ∈ H` "at the root" to get sections in `H` at the pattern depth.
- But `{B_ε} ∈ ℙ(B_ε)` by (P1), and `h_(ε,ε) ∈ 𝕊` already. So (S5) holds for `h` with the trivial pattern, and says
  nothing about the sections of `h`.
- So "every section is one of finitely many above depth `δ_h`" (item 1) and "at bounded depth `δ` all sections
  are `H`-words" (item 2) do not follow. The second is false in general: sections at depth exactly `δ` are only
  sections of `H`-elements at shallower depths.

**The correct argument.**
- **(S5) at every node.** Every restriction `g_(ε,ε)|_(B_v)` lies in `S` (Cor. 3.8), and so in `Ŝ`. So (S5) applies
  at every node `v`: below `v` there is a finite barrier of nodes good for `g`. Singleton pieces, in vertex
  versions, are finitely many and do not affect rays.
- **Good nodes on every ray.** Hence every ray contains infinitely many good nodes.
- **The first-return region.** Let `R_g` be the set of nodes `w ≠ ε` such that no node on the path from the root's
  child to `w` is good. If `R_g` were infinite, König's lemma would give a ray with no good node below the root, a
  contradiction. So **`R_g` is finite, for every `g ∈ G`**, whether `H` is finite or not.

**Item 1 (`H` finite).**
- Every section of `h ∈ H` is `h|_w` with `w ∈ R_h ∪ {ε}`, or a section of some `h' = h|_u ∈ H` at a later node.
- So the set of all sections of all elements of `H` is `⋃_(h ∈ H) {h|_w : w ∈ R_h ∪ {ε}}`, which is finite.
- Each `g ∈ G` has finitely many sections before its barrier, and sections of `H`-elements after it. So **every
  element of `G` is finite-state**, and item 1 holds.
- A byproduct: FH's certificate for Röver's group, with `H = {1, b, c, d}`, independently forces Grigorchuk's group
  to be finite-state, as it is.

**Item 2 (`H` finitely generated by `A`).**
- Put `Q = {a|_w : a ∈ A, w ∈ R_a ∪ {ε}}`, a finite set containing `A`. Let `c` bound the `A`-lengths of the
  barrier sections `a|_u ∈ H`.
- For `q = a|_w ∈ Q` and a letter `x`:
  - if `wx ∈ R_a`, then `q|_x ∈ Q`;
  - otherwise `a|_(wx) = (a|_u)|_r` for a barrier node `u ≤ wx`, with `|r| < |wx|`. Expand `a|_u` as an `A`-word of
    length `≤ c`, and recurse on each letter at depth `|r|`.
- Barrier nodes lie strictly below the root, so the depth drops at every step, and the recursion stops within
  `δ = max_a (depth of R_a) + 1` rounds.
- So **one-level sections of a `Q`-word of length `m` are `Q`-words of length `≤ L·m`**, with `L ≤ c^δ`. At depth
  `k` the length is `≤ L^k m`, which is geometric growth. Item 2 holds.

## 3. The orbit cap (item 3)

- **The seed has a finite address.** Seed full groups contain `FSym(O)`, so every orbit point is a singleton
  domain (`finitary-permutations-force-singleton-domains`, refereed PASS). In the vertex version of tree
  coordinates that means a finite address.
- **Each generator step.** Each generator of the seed group is a finite union of maps `g_(ω1,ω2)`. Applying one to a
  current address of length `ℓ = O(n)` means a prefix test, a bounded prefix swap, the finitely many pre-barrier
  states of `g`, and then a `Q`-word applied to the tail. That costs `2^(O(ℓ))` by item 2, or `O(ℓ)` by item 1.
- **Total.** Over `n` steps the cost is `2^(O(n))`, with constants depending on the certificate.
- **Reading the seed.** `y_*(w)` is read from letter cylinders. The node should state the hypothesis, as the
  finite-type node does, that these are finite unions of domains.

## 4. Scope: what "tree coordinates" must mean

The argument needs the **connecting maps** to be prefix swaps: `𝕊(B_(ω1), B_(ω2)) = {h_(ω1,ω2)}` with one `H` for
all pairs. The FH axioms allow more.
- **Twisted connectors.** With one domain type, (S3)–(S4) give `𝕊(B_(ω1), B_(ω2)) = κ_(ω2) 𝕊(B_ε, B_ε) κ_(ω1)^(-1)`,
  for arbitrary chosen `κ_ω = (k_ω)_(ε,ω) ∈ S`.
  - "Good" then means `g|_w ∈ k_(g(w)) H k_w^(-1)`, which involves infinitely many conjugates.
  - Twisted sections `k_(g(w))^(-1) g|_w k_w` do not compose along paths unless the `k_ω` are coherent.
  - The König argument still gives finite first-return regions, but not bounded word lengths.
- **So twisted connectors are the "no coherent coordinates" case,** which the node itself lists as open. The node's
  "tree coordinates" should say *prefix connectors*.
- **What the argument does extend to.** Finitely many cone types with one `H_t` per type and prefix connectors
  within each type.

## 5. What this means for the BH plan

This is a **genuine negative result**, of limited scope.
- **Closed.** The hard-seed form of gate 1 is closed for every Farley–Hughes certificate in tree coordinates with
  prefix connectors, whether or not it is closed under restriction.
- **Still open.**
  - (i) Certificates with twisted or incoherent connectors, and abstract, non-tree certificates.
  - (ii) Finiteness engines outside Farley–Hughes.
  - (iii) Hardness through the word problem of an `F_∞` structure group `H`, the Röver–Nekrashevych branch, which
    the node correctly leaves open.

## Lesson for general BH

- **(S5) at the root says nothing.** The generation axiom constrains a certificate only through restrictions. It is
  a compactness statement: every ray eventually re-enters the chosen structure. Compactness, via König, turns that
  into finite first-return regions, and so into finite-state or geometric section growth.
- **Where hardness could still enter.** For a Farley–Hughes engine it can only enter where the chosen coordinates
  are not coherent, or through the word problem of the structure group. It cannot enter through the axioms.

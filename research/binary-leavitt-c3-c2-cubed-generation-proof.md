## Proof

**The involution `v`.**  Using `t_1 s_0 = 0`, `t_1 s_1 = 1`, `t_0 s_0 = 1`,
`t_0 s_1 = 0`,

```text
v^2 = s_0(t_1 s_0)t_1 + s_0(t_1 s_1)t_0 + s_1(t_0 s_0)t_1 + s_1(t_0 s_1)t_0
    = s_0 t_0 + s_1 t_1 = 1,
v s_0 = s_0(t_1 s_0) + s_1(t_0 s_0) = s_1,
t_0 v = (t_0 s_0)t_1 + (t_0 s_1)t_0 = t_1,
```

which is `(LG2)`; hence `s_1` and `t_1` lie in the unital subring generated by
`s_0, t_0, v`, so those three generate `R`.

**The two subgroups.**  `x_12(a)x_12(b) = x_12(a+b)`, so `B` is elementary
abelian of order `2^(dim span{s_0,t_0,v})`.  The defining relations of `R` are
homogeneous for `deg s_i = 1`, `deg t_i = -1`, so the ideal they generate is
homogeneous and `R` is `Z`-graded; `s_0, t_0, v` lie in degrees `1, -1, 0`,
and each is nonzero because `t_0 s_0 = 1` and `v^2 = 1` in `R != 0`.  Hence
they are `F_2`-independent and `|B| = 8`.  The 3-cycle `c` lies in `EL_3(R)`:
in characteristic two the coordinate transposition on `i,j` is
`x_ij(1)x_ji(1)x_ij(1)`, and `c = (12)(23)`.

**Generation.**  For distinct `i,j,l` and any `a,b in R`,

```text
[x_ij(a), x_jl(b)] = x_il(ab),                                   (LG5)
```

by multiplying the four elementary matrices (`E_ij^2 = E_jl^2 = 0`,
`E_ij E_jl = E_il`, `E_jl E_ij = 0`); no commutativity of `R` is used.
Conjugation by `c` shifts root indices `1 -> 2 -> 3 -> 1`.  So

```text
d = [b_2, c b_1 c^(-1)] = [x_12(t_0), x_23(s_0)] = x_13(t_0 s_0) = x_13(1),
a = [d, c^2 d c^(-2)]   = [x_13(1), x_32(1)]     = x_12(1),
```

using `t_0 s_0 = 1`.  Cyclic conjugation of `a` and of `d` supplies all six
constant roots `x_ij(1)`.  It also supplies `x_12(r), x_23(r), x_31(r)` for
`r in {s_0, t_0, v}`, and commuting those with constant roots through `(LG5)`
supplies the remaining three positions.  Let `S` be the set of `r in R` with
all six `x_ij(r)` in `G = <A,B>`: it contains `1, s_0, t_0, v`, is closed
under addition (same-root multiplication) and under multiplication by
`(LG5)`, hence is the unital subring generated by `s_0,t_0,v`, which is `R`.
So `G` contains every elementary matrix, i.e. `G = EL_3(R)`, which is `H` by
the prerequisite.

The notation is that of the target.  The imports are the two quoted
statements there (Voiculescu's homotopy invariance with Brown's Example
3.16, and Voiculescu's Theorem 4.2).

## Step 1: `A'` is quasidiagonal and embeds unitally in a norm matrix corona

`u(0) = 1` and `w_j(0) = e^0 = 1`, so `A'` lies in

    A = { f ∈ C([0,1], O_2) : f(0) ∈ C·1 }.

`A` is the unitization of `{ f : f(0) = 0 } ≅ C_0((0,1]) ⊗ O_2`, the cone
over `O_2`.  The cone is QD by Example 3.16, and a unitization of a QD
algebra is QD.  A C\*-subalgebra of a QD algebra is QD, so `A'` is QD.

`A'` is separable.  Fix a dense sequence `(x_k)` and apply Theorem 4.2 to
`F_n = {x_1, ..., x_n}` with `ε = 1/n`.  This gives contractive completely
positive maps `phi_n : A' → M_{k_n}`, into matrix algebras containing the
finite-dimensional targets.  They are asymptotically multiplicative and
`‖phi_n(x)‖ → ‖x‖` for every `x`, because the lower bound improves while
`‖phi_n(x)‖ ≤ ‖x‖`.  So `x ↦ [phi_n(x)]` is an injective `*`-homomorphism
`A' → prod M_{k_n} / sum M_{k_n}`, and it stays injective in every
ultraproduct `prod_omega M_{k_n}`.

The image of `1` is a nonzero projection `p`.  Lift it to projections
`p_n` of rank `r_n`.  After discarding the indices with `r_n = 0`, the corner
`p Q p` is `prod M_{r_n} / sum M_{r_n}`, which is again a norm matrix corona.
The embedding into it is unital.  If one insists on `d_n → ∞`, compose with
`x ↦ x ⊗ 1_n`.  Call the resulting unital embedding `iota`.

`u` is central in `A` (it is scalar-valued) and `F_4` is free, so
`eps ↦ u`, `a_j ↦ w_j` defines a homomorphism `Theta_0: Z x F_4 → U(A')`.
Composing with `iota` gives `Theta`.

## Step 2: `A'` is a `C([0,1])`-algebra with fiber `C` at `0` and `O_2` elsewhere

The map `t ↦ e^{i pi t}` is a homeomorphism of `[0,1]` onto the upper
half-circle `S`.  So `C*(u) = { g(t)·1 : g ∈ C[0,1] }`, which is central in
`A'`, and `sp(u) = S`.  This gives item 4 of the target:
`‖u − 1‖ = |e^{i pi} − 1| = 2`, and `iota` is isometric.

For `t_0 ∈ [0,1]`, let `ev_{t_0}` be evaluation and
`J_{t_0} = ker(ev_{t_0}) ∩ A'`.  If `f ∈ J_{t_0}`, take `g_n ∈ C[0,1]` with
`0 ≤ g_n ≤ 1`, `g_n = 0` near `t_0` and `g_n = 1` off the `1/n`-ball.  Then
`g_n(u) f ∈ C_0([0,1] \ {t_0}) A'` and `‖f − g_n(u) f‖ → 0` by continuity of
`f` at `t_0`.  So

    J_{t_0} = closure( C_0([0,1] \ {t_0}) · A' ),                     (2a)

and the fiber of `A'` at `t_0` is `ev_{t_0}(A')`.

- At `t_0 = 0` every generator evaluates to a scalar, so `ev_0(A') = C`.
- At `t_0 > 0`, `ev_{t_0}(w_j) = e^{i t_0 h_j}`, and `sp(t_0 h_j) ⊂ [−1, 1]`.
  Let `L` be the continuous inverse of `s ↦ e^{is}` on the arc
  `{e^{is} : |s| ≤ 1}`, extended continuously to the circle.  Functional
  calculus gives `L(e^{i t_0 h_j}) = t_0 h_j`, so `h_j ∈ ev_{t_0}(A')`.
  Hence `ev_{t_0}(A') ⊇ C*(1, h_1, ..., h_4) = O_2`, and so
  `ev_{t_0}(A') = O_2`.

## Step 3: `A'` has exactly one tracial state, evaluation at `0`

`ev_0` is a character of `A'`, hence a tracial state.

Let `tau` be an extreme tracial state of `A'`.  Then the GNS closure
`M = pi_tau(A')''` is a finite factor.  The algebra `pi_tau(C*(u))` is central
in `M`, so it consists of scalars, and `g(u) ↦ g(t_0)` for some
`t_0 ∈ [0,1]`.  For `g ∈ C_0([0,1] \ {t_0})` and `b ∈ A'` this gives
`pi_tau(g(u) b) = g(t_0) pi_tau(b) = 0`.  By (2a), `pi_tau` and therefore
`tau` vanish on `J_{t_0}`.  So `tau` factors through a tracial state of the
fiber `ev_{t_0}(A')`.

Suppose `t_0 > 0`.  Then the fiber is `O_2`, which has no tracial state:
`s_1^* s_1 = s_2^* s_2 = 1` and `s_1 s_1^* + s_2 s_2^* = 1`, so a trace `T`
would satisfy `1 = T(1) = T(s_1 s_1^*) + T(s_2 s_2^*) = 2`.  Hence `t_0 = 0`,
and `tau = ev_0`.

The tracial state space is a weak\*-compact convex set.  By Krein–Milman it
is the closed convex hull of its extreme points, which here are just
`{ev_0}`.  So `ev_0` is the only tracial state.  This is item 2.

## Step 4: every corner trace of the relative commutant sees `Theta(eps) = 1`

Let `q ∈ B = Theta(H)' ∩ Q` be a nonzero projection.  Because `A'` is
generated by `Theta_0(H)`, `q` commutes with `iota(A')`.  Then
`a ↦ q iota(a) q = q iota(a)` is a unital `*`-homomorphism `A' → qQq`.

Let `sigma` be any tracial state of `qQq`.  Tracial states exist:
`qQq ≅ prod M_{rank q_n} / sum` along the indices with `q_n ≠ 0`, and the
limit trace along a free ultrafilter on those indices is one.  Then
`sigma(q iota(·) q)` is a tracial state of `A'`, so by Step 3 it equals
`ev_0`.  Since `q` commutes with `Theta(eps)`,

    ‖q Theta(eps) q − q‖_{2,sigma}^2
      = sigma( q |iota(u) − 1|^2 q )
      = |u(0) − 1|^2
      = 0.

This is item 3.  It holds for every tracial state of every corner, so it
holds under any convention for the corner's normalized trace in
`commutant-projection-extraction` and `corona-corner-detection-criterion`.

## Step 5: the conclusion, and its approximate form, fail

`Theta(eps) = iota(u)` and `‖iota(u) − 1‖ = 2`, so `Theta(eps) ≠ 1`.

For the approximate form, let `lambda ∈ C` and `q ∈ B` be nonzero with
`‖(Theta(eps) − lambda) q‖ < |lambda − 1|`.  Pick a tracial state `sigma`
of `qQq`.  Then

    |1 − lambda|^2 = sigma( q |iota(u) − lambda|^2 q )
                   ≤ ‖(Theta(eps) − lambda) q‖^2
                   < |lambda − 1|^2,

where the equality is Step 3 applied to `|u − lambda|^2`.  This is a
contradiction.  So even the weakest detecting corner, clause 3 of
`corona-corner-detection-criterion`, never exists here.

The ultraproduct version, needed for the reductions quoted in the target, is
the same argument with `A_omega` in place of `Q`, using that `iota` stays
injective there (Step 1).

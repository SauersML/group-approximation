**ESTABLISHED (literature import).** A. Bishop and E. Schesler, *A branch group with
unsolvable conjugacy problem*, arXiv:2509.12161v2. TeX `arxiv_v2.tex` (sha256 prefix
941f1e1a112d3ad6), read on MSI on 2026-09-18.

> **Theorem B** (l.203, `thm:main-embedding-intro`). For every finitely generated
> residually finite group $G$, there exists a finitely generated branch group $\Gamma$
> and a Frattini embedding $\iota \colon G \rightarrow \Gamma$. Moreover, if $G$ is
> recursively presented and $\EFRF^{+}$, then $\Gamma$ can be chosen to be recursively
> presented and $\EFRF^{+}$ as well.

> **Corollary** (l.218, `cor:boone-higman`). If the Boone--Higman conjecture is true for
> the class of branch groups with $\EFRF^{+}$, then it is true for every group with
> $\EFRF^{+}$.

**Definitions** (their Definition `def:eff-res-fin`, l.258, after Rauzy).
- `EFRF`: an algorithm that, given `w ≠ 1`, outputs a homomorphism to a finite group
  in which `w` survives.
- `EFRF^+`: in addition, the algorithm does not halt on `w = 1`.
- For recursively presented finitely generated groups, `EFRF^+` is equivalent to
  `EFRF` plus a solvable word problem.
  - (⇐) First decide `w ≠ 1`; if so, run the `EFRF` algorithm.
  - (⇒) Run the `EFRF^+` machine in parallel with the enumeration of relations.

**The host.**
- `Γ` acts on the spherically homogeneous tree with level alphabets
  `X_n = G/N_n ∪ {x_n, y_n, z_n, p_n, q_n}` (l.385–400), where `(N_n)` is a residual
  chain.
- `Γ` is generated by a copy of `G × Alt(6)` acting spinally along the `x_n`-ray,
  together with rooted alternating groups.
- Under `EFRF^+`, the chain, the alphabets and the actions are computable (§`sec:eff-res-fin`).

## Consequence for BBMZ Problem 5.3 (lane remark; elementary)

Every finitely presented residually finite group is recursively presented. By
McKinsey's algorithm it has solvable word problem, and it is `EFRF` (Rauzy, Fact 3,
recorded in `rf-higman-embedding-for-decidable-groups-fails`). So it is `EFRF^+`. The
following inputs are therefore all covered by the Corollary:
- closed-surface mapping class groups (finitely presented; residually finite by
  Grossman);
- `Out(F_n)` (finitely presented; residually finite by Grossman);
- finitely presented metabelian groups (residually finite by P. Hall);
- the whole of BBMZ 5.3(12).

These are BBMZ 5.3(2), (3), (7) and (12). Boone–Higman for all of them follows from
Boone–Higman for finitely generated, recursively presented, `EFRF^+` branch groups.

## Lesson for general BH

The residually finite sector of the open list collapses to one host problem:
spinal branch groups over a computable sequence of growing alphabets.
- **These groups are not self-similar.** The tree is not regular, and the sections vary
  with the level. So the Röver–Nekrashevych / BBMZ contracting-RSG hosts do not apply
  directly.
- **Regular-tree hosts may miss them.** Whether `Γ`, or the input `G`, admits any
  faithful action on a regular rooted tree is not addressed here. For finitely presented
  residually finite inputs that is the open claim
  `every-fp-rf-group-acts-on-a-regular-rooted-tree`. The branch route avoids that
  question by allowing growing alphabets.
- **What a host must do.** It must absorb *computable, level-dependent* tree data. A
  natural first target is the full group of the boundary groupoid of a computable
  spherically homogeneous tree generated by level shifts and spinal maps.
- **Comparison with the self-similar route.** Main's route
  `fp-rf-boone-higman-via-fp-self-similar-overgroups` needs regular trees and dies if
  `some-fp-rf-group-acts-on-no-regular-rooted-tree` holds. The branch route has no such
  failure point, because it allows growing alphabets. Its price is the loss of
  self-similarity.
- **An upper bound on the difficulty.** One host construction for this spinal class
  would settle closed MCG, `Out(F_n)`, fp metabelian and fp RF together.

Notation as in the claim. Write elements of `G` as `(v, g)` with `v in D^2`, `g in Lambda`,
and `(v,g)(w,h) = (v + g w, g h)`.

**1. The pair.**
- `Gamma` contains `SL_2(Z)`, which contains a free group of rank two, so it is non-amenable.
- Relative (T) of `(Z^2 x| F_2, Z^2)` for a finite-index free subgroup `F_2 <= SL_2(Z)` is
  classical. It is recorded verbatim from Navas, arXiv:1712.06462v2, p. 3, in
  `relatively-kazhdan-amenable-pairs-allow-sofic-defects-proof`, step 2. An affine isometric
  action of `Gamma` restricts to `Z^2 x| F_2`, which has a `Z^2`-fixed point. So
  `(Gamma, Z^2)` has relative (T).
- `t = (0, 2I)` is central in `Lambda`, so `t (w, g) t^-1 = (2w, g)`. Hence
  `t Gamma t^-1 = (2Z)^2 x| SL_2(Z) <= Gamma` and `t in P_Gamma`. Also `Gamma <= P_Gamma`.
- The group generated by `Gamma` and `t` contains `t^-k (w, I) t^k = (2^-k w, I)` for all `k`,
  hence all translations by `D^2`, as well as `SL_2(Z)` and `2I`. So it is `G`, and `Gamma`
  is infranormal. Translations by `D^2` need not lie in `P_Gamma`; that is not required.
- `t^-1 (e_1, I) t = (e_1/2, I)` is not in `Gamma`, so `Gamma` is not normal.

**2. Soficity of `H`.**
- `B = D^2 x| <2I>` is normal in `G`: `SL_2(Z)` preserves `D^2` and commutes with `2I`. Since
  `B cap SL_2(Z) = 1` and `B SL_2(Z) = G`, we get `G = B x| SL_2(Z)`. `B` is metabelian,
  hence amenable.
- `N = (direct_sum_X Z/2) x| B` is normal in `H` and amenable, being an extension of an
  abelian group by `B`. So `H = N x| SL_2(Z)`.
- `SL_2(Z) = Z/4 *_(Z/2) Z/6`. A split extension of `N` by an amalgam is the amalgam of the
  split extensions: both sides satisfy the same universal property for pairs of compatible
  homomorphisms. Hence

  ```text
  H = (N x| Z/4) *_(N x| Z/2) (N x| Z/6),
  ```

  with all three groups amenable, since each is a finite extension of `N`.
- Păunescu, arXiv:1002.0605v5, verbatim in the listed artifact:
  - Proposition 3.4: "Amenable groups are in 𝒮."
  - Theorem 3.9: "Class 𝒮 is closed under amalgamated product over amenable groups."
  Here 𝒮 is the class of groups all of whose p.m.p. actions are sofic.
- So `H` is in 𝒮. Take the action on a one-point space: `L(H)` embeds trace-preservingly in
  `prod_omega M_(n_k)` with `H` in the permutation matrices, and `H` is sofic.

**3. The defect.**
- `o = Gamma in X` is fixed by `Gamma`, so `z = e_o` commutes with `Gamma`.
- `t z t^-1 = e_(t o)`. For `gamma = (e_1, I) in Gamma`:
  `gamma t o = t o` iff `t^-1 gamma t in Gamma` iff `(e_1/2, I) in Gamma`, which fails.
- So `[t z t^-1, gamma] = e_(t o) + e_(gamma t o) != 0` in the lamp group.

Items 1–3 are proved. ∎

**Remark (not used above).** `H` is the ordinary binary coset wreath of `Gamma <= G`, sofic and
hence hyperlinear. The hyperlinearity of `G *_Gamma (Gamma x Z)` would follow from
`binary-free-and-ordinary-coset-wreaths-share-hyperlinearity` (1 iff 5). That node has its own
route with open requirements, so this route does not consume it.

marked carrier, let

```text

```

Put a complete gauge-doubled Fanizza occurrence at every site of the free
Thompson occurrence amalgam.  In each occurrence use the endpoint packet of
`s3-active-complement-is-three-equal-scale-affine-atoms`, so

```text
A=P_(+,+)+P_(+,-)+P_(-,+),       X=P_(-,-).            (MAR2)
```

The required return must send `X` to the fresh first-hit atom and send all
three atoms of `A` below the next survivor prefix, while making that survivor
the reducing carrier for the next occurrence.  The local nonlinear split is
now supplied by `two-bit-tag-routing-splits-s3-exit-and-survivor`: an affine
bridge transports the four endpoint atoms into a two-bit site tag, whose one
distinguished atom is the exit and whose other three atoms form the survivor.

By `packet-central-active-complement-reduces-shared-words`, the source
complement approximately reduces the current shared BCS words.  The remaining
obligation is `tagged-s3-survivor-installs-next-recurrent-carrier`: preserve
that semantic reduction after routing into the next independent occurrence
and prove the active/exit trace comparison used by the branching ledger.

The exit component `X` no longer belongs to this target:
`projected-hard-sign-bridge-selects-joint-exit` transports it directly to the
correct E5 first-hit layer using `b` as the hard word and `X` only as an
analytic right compression.

The earlier free-occurrence HNN attempt is invalid.  As proved in
`free-occurrence-hnn-return-does-not-preserve-first-hit-prefix`, independently
transporting `X` to a reservoir does not stop the same source mass from
reappearing in the fresh HNN chart.  The next active carrier must itself lie
below the survivor prefix; otherwise the first-hit reservoir does not certify
one-time charging.

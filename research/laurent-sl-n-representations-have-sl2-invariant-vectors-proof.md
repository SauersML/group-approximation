Notation: `A = F_q[t,t^{-1}]`, `p = char F_q`, `e_ij(r) = I + rE_ij`, `[g,h] = ghg^{-1}h^{-1}`, `d = dim ρ`.

1. **Root subgroups have finite image.** `U_ij = e_ij(A) ≅ (A,+)` is an elementary abelian `p`-group. So `ρ(U_ij)`
   consists of commuting unitaries `x` with `x^p = 1`. They are simultaneously diagonalizable with eigenvalues in the
   `p`-th roots of unity, so `|ρ(U_ij)| ≤ p^d`. Hence `I_ij = {r ∈ A : ρ(e_ij(r)) = 1}` is an additive subgroup of
   index at most `p^d`. It is nonzero, since `A` is infinite.
2. **A level ideal.** Let `i, j, k` be distinct, which needs `n ≥ 3`. For `r ∈ I_ik` and `s ∈ A`,
   `e_ij(rs) = [e_ik(r), e_kj(s)]`, and `ρ` kills this commutator. Since `I_ij` is additive, the ideal `(I_ik)`
   generated by `I_ik` lies in `I_ij`. Let `J` be the product of the ideals `(I_ik)` over all ordered pairs `i ≠ k`.
   It is nonzero because `A` is a domain. Given `i ≠ j`, choose `k ∉ {i,j}`: then `J ⊆ (I_ik) ⊆ I_ij`. So
   `ρ(e_ij(x)) = 1` for all `i ≠ j` and `x ∈ J`.
3. **Congruence.**
   - `A` is the ring of `S_∞`-integers of the global field `F_q(t)`, with `S_∞ = {t = 0, t = ∞}`. It is of arithmetic
     type and not totally imaginary, since Bass–Milnor–Serre call `A` totally imaginary only when `k` is a totally
     imaginary number field (import node).
   - By Corollary 4.3 a), `SL_n(A) = E_n(A)`. `ker ρ` is normal and contains `e_ij(J)`, so it contains
     `E_n(A,J)`, the normal subgroup of `E_n(A)` generated by these matrices.
   - By Corollary 4.3 b), `SL_n(A,J) = E_n(A,J)`. So `ker ρ ⊇ SL_n(A,J) = ker(SL_n(A) → SL_n(A/J))`.
   - `A/J` is a finite commutative ring, so `SL_n(A/J)` is generated by elementary matrices, and they lift to `A`.
     So `SL_n(A) → SL_n(A/J)` is onto, and `ρ = ρ' ∘ (reduction mod J)` for a representation `ρ'` of `SL_n(A/J)`.
     This proves item 1.
4. **Invariant vector.** `A` is a principal ideal domain, being a localization of `F_q[t]`. So `J = (m)`, and `A/J` is
   a finite commutative principal ideal ring. Let `n ≥ 4`. Restrict `ρ'` to the upper-left `SL_4(A/J)`. By
   `sl4-over-finite-chain-rings-has-sl2-invariant-vectors` it has a nonzero vector fixed by the upper-left
   `SL_2(A/J)`. The reduction map sends the upper-left `SL_2(A)` into that subgroup, so the vector is fixed by
   `ρ(SL_2(A))`. This proves item 2.
5. **Norms.**
   - Item 3 of `ring-model-permutation-vectors-block-strong-convergence` (Nagao) gives free generators `S, T` of a free
     subgroup of `SL_2(F_q[t]) ≤ SL_2(A)`.
   - `ρ(z)` has eigenvalue `4` on the fixed vector, and `‖ρ(z)‖ ≤ 4`, so `‖ρ(z)‖ = 4`.
   - `λ_{SL_n(A)}` restricted to `⟨S,T⟩` is a multiple of `λ_{F_2}`, so `‖λ_{SL_n(A)}(z)‖ = 2√3` (Kesten).
   - A strongly convergent sequence would have `‖ρ_i(z)‖ → 2√3`, which fails.
   - For `Γ ⊇ SL_4(A)`: finite-dimensional representations of `Γ` restrict to finite-dimensional representations of
     `SL_4(A)`, and `λ_Γ` restricts to a multiple of `λ_{SL_4(A)}`. So the same witness applies. This proves item 3.

**Model tests.**
- `n = 2`: step 2 needs a third index, and the argument stops there.
- `A = Z`: step 1 fails, because unipotent elements have infinite order. The published `SL_4(Z)` theorem needs
  superrigidity and the congruence subgroup property instead.
- `ρ` trivial: every vector is fixed, consistent with item 2.

**Credit.**
- Step 2 is the standard level-ideal computation.
- Item 1 is the congruence subgroup property for finite-dimensional unitary representations of this lattice.
- The invariant-vector argument is Magee–de la Salle's (arXiv:2312.03220v2, Proposition 2.1), transferred to finite
  principal ideal rings in the required node.

## Setting

`G_1 = ⟨s, δ, σ | s δ s^-1 = δ^2, δ σ δ^-1 = σ^2⟩ = A *_C B`, with `A = ⟨s, δ⟩ ≅ BS(1,2)`,
`B = ⟨δ, σ⟩ ≅ BS(1,2)` and `C = ⟨δ⟩`. It is the chain group of
`higman-chain-group-pbh-iff-chain-configuration`, in the convention of
`scale-periodic-bs-chain-germ-representations-are-not-faithful`.

Let `H = {ψ ∈ Homeo_+(R) : ψ(2x) = 2ψ(x)}`. It is a closed subgroup of `Homeo_+(R)` with the
compact-open topology, so it is a Polish group. For `ψ ∈ H` define homeomorphisms of `R`:

    σ(x) = x + 1,    δ(x) = 2x,    s_ψ = ψ ∘ s_0 ∘ ψ^-1,  where  s_0(x) = x|x|.

Then `s_ψ δ s_ψ^-1 = δ^2` (since `s_0(2x) = 4 s_0(x)` and `ψ` commutes with `δ`) and
`δ σ δ^-1 = σ^2`. So there is a homomorphism `θ_ψ : G_1 -> Homeo_+(R)`. Let
`θ_ψ^∞ : G_1 -> Germ_{+∞}` be its composition with the map to germs at `+∞`.

## Statement

1. **Generic faithfulness.** There is a comeagre set `F ⊆ H` such that, for every `ψ ∈ F` and
   every `1 ≠ u ∈ G_1`, the homeomorphism `θ_ψ(u)` is not the identity on any nonempty open
   interval. In particular `θ_ψ` and `θ_ψ^∞` are injective, and the germ group
   `Q_ψ = ⟨σ, δ, s_ψ⟩` at `+∞` is isomorphic to `G_1`.
2. **Not every ψ.** For `ψ = id`, `ρ = s_0^-1 δ s_0 = √2·x`, so `ρσρ^-1 = x + √2` commutes with
   `σ`. But `[ρσρ^-1, σ] ≠ 1` in `G_1`, by normal forms. So `id ∉ F`.
3. **Splitting criterion.** Let `N = ⟨⟨σ⟩⟩_{G_1}` and `N_B = ⟨⟨σ⟩⟩_B ≅ Z[1/2]`. Then
   `N = *_{a ∈ T} a N_B a^-1` for a transversal `T` of `A/C`. For every `ψ ∈ H`, `θ_ψ^∞` is
   injective iff the subgroups `θ_ψ^∞(a N_B a^-1)`, for `a ∈ T`, generate their free product.
   The same holds for every germ realization with:
   - `σ = x+1`;
   - `δ` a lift with `δ(x+1) = δ(x) + 2`, some iterate of which expands;
   - `s` arbitrary.

   This covers the non-affine dyadic lift `δ_f` of
   `non-affine-doubling-lifts-evade-the-sparse-defect-kill`, since `δ_f^2` has all slopes `≥ 2`.
4. **Where PL realizations sit.** Suppose moreover that `s`, read in `log_2` coordinates after
   linearizing `δ`, has an expanding iterate. Then the realization is conjugate at `+∞` to
   `θ_ψ^∞` for one explicit `ψ ∈ H`. It is faithful iff `ψ` lies in the comeagre set
   `F^∞ = {ψ : θ_ψ^∞ injective} ⊇ F`.

## What this changes

- **No dynamical kill exists.** The route realizes `σ` as the `V`-zoom `x+1` and `δ` as a
  doubling. Its candidate obstructions so far are:
  - sparse commuting defects;
  - abelian rank and centralizer tests (the w17 firewall F1–F3);
  - soluble zoom-root pairs.

  Every one of them is a property of the germ group as an abstract group. Item 1 gives
  topological realizations, with `σ = x+1` and `δ = 2x` exactly, whose germ group *is* `G_1`. So
  no obstruction that holds for all homeomorphism germs can kill the route. A kill must use
  arithmetic or PL rigidity of the actual host data, as the affine kill does.
- **P1 becomes a meagre-versus-comeagre question.** Conjugating by a Shub conjugacy puts an
  expanding PL realization `(δ, s)` into the form `θ_ψ^∞` for one explicit `ψ = ψ(δ, s) ∈ H`.
  The dyadic data `(δ, s)` are countable, so these `ψ` form a countable, meagre set `R ⊆ H`. P1
  (PL) asks whether `R ∩ F ≠ ∅`. Genericity alone cannot answer that.
  - The affine realizations lie outside `F`.
  - So does the smooth model `ψ = id`, by item 2.
  - Whether the non-affine lift `δ_f` lands in `F` is exactly P1 for it.
- **A single test replaces three.** Item 3 turns faithfulness into one ping-pong-type condition
  on the Prüfer-type root group `θ(N_B)`, which consists of lifts of circle maps, and its
  conjugates by `A/C ≅ Z × (Z[1/2]/Z)`. The firewall tests F1–F3 are consequences of it.

## Scope

- The theorem gives no finitely presented host. The maps `ψ ∈ F` are not locally in `V`, so
  P2 (the Belk–Hyde–Matucci check) does not apply to them.
- It does not decide P1 for any PL or `V`-realizable lift.
- It gives no new case of `G_1 ∈ B_A`.

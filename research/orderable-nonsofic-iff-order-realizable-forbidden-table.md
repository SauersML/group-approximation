**ESTABLISHED (proposed; unreviewed).**  Derivation: `orderable-nonsofic-iff-order-realizable-forbidden-table-proof`.

**Tables.**  A *table* `T = (F, m)` is a finite set `F` with a partial binary operation `m`.  An *`eps`-model* of `T`
is a map `sigma : F -> Sym(n)` with `d(sigma(x) sigma(y), sigma(m(x,y))) <= eps` whenever `m(x,y)` is defined, and
`d(sigma(x), sigma(y)) >= 1 - eps` for `x != y` (normalized Hamming distance).  `T` is *forbidden* at `eps` if it
has no `eps`-model in any `Sym(n)`.  `T` *embeds* in a group `H` if some injective `f : F -> H` has
`f(x) f(y) = f(m(x,y))` wherever `m` is defined.  The *table group* is `P_T = < F | x y = m(x,y) >`.

Let `P` be one of: left-orderable (LO), bi-orderable (BO), locally indicable (LI).  Write `P(G)` for the largest
quotient of `G` that has `P` (it exists, see the proof).

**Theorem.**
1. **(Reduction.)**  Some group with `P` is nonsofic iff some forbidden table embeds in some group with `P`.
2. **(Universal witness.)**  If a forbidden table `T` embeds in any group with `P`, it embeds in `P(P_T)`, and
   `P(P_T)` is a finitely generated, recursively presented, nonsofic group with `P`.  Moreover every group with `P`
   into which `T` embeds is nonsofic, and every such group generated by the image of `F` is a quotient of `P(P_T)`.
3. **(Arithmetical form.)**  "`T` embeds in a group with `P`" is `Pi^0_1` in `T`: its failure has a finite
   certificate, a finite unsatisfiable set of order clauses.  "`T` is forbidden at `eps`" is `Pi^0_1` in
   `(T, eps)`.  So each of the three existence sentences "some group with `P` is nonsofic" is a `Sigma^0_2`
   sentence `exists (T, eps) [Pi^0_1]`.
4. **(Simple witness, LO only.)**  Some left-orderable group is nonsofic iff some finitely generated *simple*
   left-orderable group is nonsofic.  This imports Darbinyan--Steenbock, *Embeddings into left-orderable simple
   groups*, J. London Math. Soc. 105 (2022), Theorem 1: every countable left-ordered group embeds in a finitely
   generated left-ordered simple group.

**What this changes for [[left-orderable-non-sofic-group]].**
- *The table and the group come apart.*  A witness needs only a forbidden *table* that is order-consistent.  The
  group from which the table's nonsoficity was proved is irrelevant: the largest orderable quotient of the table
  group is a witness as soon as the table survives in it.  The dead end "bi-orderable and locally indicable groups
  contain no Kazhdan subgroup, so every mechanism on the shelf is closed to them" was a statement about groups.  The
  correct finitary form is about tables: [[kazhdan-certified-tables-not-order-realizable]].
- *Both halves of a certificate are checkable in the same direction.*  Forbiddenness and order-consistency are both
  co-enumerable, so a candidate `(T, eps)` can be refuted by a finite object of either kind: an `eps`-model in some
  `Sym(n)`, or a finite contradictory set of order clauses.
- *If every orderable group is sofic,* that fact is a `Pi^0_2` sentence.

**What it does not claim.**
- It does not produce a finitely presented witness.  The Bludov--Glass right-orderable Higman embedding
  (Proc. LMS 99 (2009)) would upgrade (2) to a finitely presented left-orderable witness only under its own
  hypothesis on the order, which was not re-read here.  A left order with a recursively enumerable positive cone
  on a recursively presented group forces a decidable word problem, and `P(P_T)` need not have one.
- The unique-product cell is not covered: unique products is not visibly axiomatized by propositional clauses on
  a quotient.

**Calibration.**
- *Torsion.*  A table containing elements `1 != x` with `m(1,1) = 1` and `m(x, x) = 1` embeds in no LO group, and
  the clauses of the proof refute it in a few steps.  The relators give `n_1` and `n_(x x)`, so `p_(x^-2)`.  If
  `p_x`, then `p_(x^-2) and p_x -> p_(x^-1)`, so `n_x`; symmetrically if `p_(x^-1)`.  Then `n_(x^-1 1)`, against
  the distinctness clause for the pair `(x, 1)`.
- *A sofic orderable group.*  Every table of `Z^2` embeds in an LO group and has `eps`-models for all `eps`, so it
  is never a certificate.  The reduction produces no false witness.

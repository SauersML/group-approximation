Notation is as in the claim. `E` is countable, and it is generated by the
finitely many elementary matrices `x_ij(1)`, `x_ij(S)`, `x_ij(T)`.

## Step 0. Imported facts about L

From Step 2 of `leavitt-corner-trace-gate-jacobson-proof`, the route of
`leavitt-corner-trace-gate-collapses-to-jacobson-hyperlinearity`, valid for
every `n >= 2`:

- **(S1)** `L <= E`, and `L` is normal (it is the kernel of the symbol map).
- **(S2)** `L` is simple and perfect. It is the increasing union of the
  simple perfect groups `GL_m(F_2) = SL_m(F_2)`, `m >= 3`.
- **(S3)** `C_E(L) = 1`.

For `n = 5` these are also the content of (JHF2)--(JHF3) in
`binary-jacobson-head-retaining-homomorphisms-are-faithful`.

## Step 1. MF characters are closed under the operations used

Let `rho_k` and `rho'_k` be MF models with characters `tau` and `tau'`.

**(C0) Near-unitality and class functions.**
- From `rho_k(1)^2 ~ rho_k(1)` and unitarity, `||rho_k(1) - 1|| -> 0`.
- Hence `||rho_k(g^(-1)) - rho_k(g)^*|| -> 0`, and
  `tr rho_k(x g x^(-1)) - tr rho_k(g) -> 0`.
- So `tau` is a normalized class function. It is positive definite, as a
  limit of positive-definite functions up to `o(1)`.
- So `tau` is a character in the sense of `character-diracization-limit`
  (normalized, central, positive definite). Extremality is not used.

**(C1) Products.** `rho_k (x) rho'_k` is an MF model.
- The defect on `(g,h)` is at most the sum of the two defects, because
  `a (x) b - a' (x) b' = (a - a') (x) b + a' (x) (b - b')` and unitaries have
  norm 1.
- Its character is `tau tau'`. With `rho' = conj(rho)`, the character is
  `|tau|^2`.
- So `|tau|^(2j)` is MF for every `j`.

**(C2) Limits.** Enumerate `E = {g_1, g_2, ...}`. Let `tau^(m)` be MF
characters converging pointwise to `tau`.
- For each `m` choose `m'` with `|tau^(m')(g_i) - tau(g_i)| < 1/m` for `i <= m`.
- Then choose a coordinate `k_m` of a model for `tau^(m')` with defect
  `< 1/m` on all pairs from `{g_1..g_m}`, and with trace within `1/m` of
  `tau^(m')` on `g_1..g_m`.
- The diagonal sequence is an MF model with character `tau`.

**(C3) Trace versus 2-norm.** For a unitary `u`,
`||u - 1||_2^2 = 2 - 2 Re tr u`.

## Step 2. The dichotomy for one MF character

Let `tau` be an MF character and `K = K_tau`. By `character-diracization-limit`:
- `u_g = tau(g) 1` in the GNS representation exactly when `g in K`;
- `K` is normal;
- `lambda = tau|_K : K -> T` is a homomorphism;
- `|tau|^(2j) -> 1_K` pointwise.

By (C1) and (C2), `1_K` is an MF character. For `g in E` and `k in K`,
`u_g u_k u_g^(-1) u_k^(-1) = 1`, since `u_k` is a scalar. So `lambda` is
trivial on `[E,K]`.

**Case A: `K ∩ L = 1`.**
- Both `K` and `L` are normal, so `[K,L] <= K ∩ L = 1`.
- Then `K <= C_E(L) = 1` by (S3), so `1_K = delta_e^E`.
- Hence `delta_e^E` is MF. This is (Z2).

**Case B: `K ∩ L != 1`.**
- `K ∩ L` is normal in `L`, so by (S2) it equals `L`, and `L <= K`.
- By perfectness, `L = [L,L] <= [E,K]`, so `lambda|_L = 1`, that is, `u_l = 1`
  for `l in L`.
- Then `tau(gl) = <u_g u_l xi, xi> = tau(g)`, so `tau` is `L`-invariant and
  factors through `p`.

**Exclusivity of (Z1) and (Z2).**
- If (Z2) holds, `delta_e^E` is an MF character that is not trivial on `L`,
  since `delta_e(w) = 0`. So (Z1) fails.
- If (Z1) fails, some MF `tau` is not in Case B, so it is in Case A, and
  (Z2) holds.

This proves (ZO) and the "more precisely" clause.

## Step 3. Corollary 1

- **(1) <=> (2).** This is (ZO).
- **(2) => (3).** Let `rho_k` be any MF model.
  - Every subsequence has a further subsequence along which `tr rho_k(g)`
    converges for all `g`, by compactness of the unit disc and a diagonal
    argument.
  - The limit is an MF character, so by (2) it takes the value `1` at `w`.
  - By (C3), `||rho_k(w) - 1||_2 -> 0` along that sub-subsequence. Hence it
    tends to `0` along the whole sequence.
  - For the eigenspace form, note that `rho_k(w)^2 -> 1` in norm. So
    `rho_k(w)` is within `o(1)` in norm of an involution `v_k`, and
    `||v_k - 1||_2^2 = 4 rank(v_k=-1)/d_k`.
- **(3) => (4).** Immediate.
- **(4) => (2).** Suppose (Z1) fails. By (ZO), `delta_e^E` is MF, and its
  witnesses have `||rho_k(w) - 1||_2^2 -> 2`, contradicting (4).

So a single model with `limsup ||rho_k(w) - 1||_2 > 0` gives, along a
trace-convergent subsequence, an MF `tau` with `Re tau(w) < 1`. That `tau` is
not trivial on `L`, and Step 2 turns it into `delta_e^E`. This is the
upgrade statement.

## Step 4. Corollary 2

- By (JHF3), any corona homomorphism of `EL_5(J)` retaining `w` is
  injective. So "the head dies in every norm-corona model" (HC) is the same
  as "`E` has no injective corona homomorphism", i.e. `E` is not MF.
- A witness for `delta_e^E` has `||rho_k(g) - 1||_2^2 -> 2` for `g != 1`. So
  it is injective in the corona, and `not (H1)` implies that `E` is MF.
  Equivalently, (HC) implies (H1).
- The residual case `(H1) and not (HC)` is therefore "`E` is MF, and by
  Corollary 1 every MF model has `||rho_k(w) - 1||_2 -> 0`". In particular
  every faithful MF model does.

**Why the reblocking does not close this gap.** Take an injective corona
model with an HS-null head. Let `p_k` be the `(-1)`-eigenprojection of
(an involution near) `rho_k(w)`, so `rank p_k = o(d_k)`.
- The span of the ranges of `rho_k(g) p_k rho_k(g)^*`, over `g` in a ball
  `B_r`, is mapped by each generator into the span over `B_(r+1)`.
- `torsion-normal-generator-has-full-support-corona-core` closes this span
  after one step. There every generator is a finite product of conjugates of
  the mark and acts as the identity off the span.
- In `E` the generators `x_ij(S)` are not products of conjugates of `w`, since
  such products lie in `L`. The span need not stabilize.
- Closing the gap is equivalent to controlling this growth in operator norm.

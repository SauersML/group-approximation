**ESTABLISHED.**  With `J_Z = Z<S,T | TS = 1>`, `Q = 1 - ST`,
`F_Z = J_Z Q J_Z` and `D = Z[z,z^(-1)]`, define

```text
A_2 = J_Z / 2 F_Z = Z<S,T | TS = 1, 2Q = 0>.                      (OT1)
```

The two presentations agree because the two-sided ideal generated by `2Q`
is exactly `2F_Z`.  Then:

1. there is an exact ring sequence

```text
0 --> M_fin(N,F_2) --> A_2 --> D --> 0,                           (OT2)
```
   so `A_2` is countable of characteristic zero while its nonzero defect
   `Q` has additive order two, and `Q` is **nonfull** since `D != 0`;
2. reduction mod two and the integral symbol give an injective ring map
   with fibre-product image

```text
A_2 --> J_(F_2) x D,
A_2 = J_(F_2)  x_(F_2[z,z^(-1)])  D;                              (OT3)
```
3. for every `n >= 2` the elementary symbol sequence

```text
1 --> L_n --> EL_n(A_2) --> EL_n(D) --> 1,
L_n = GL_fin(N x {1,...,n}, F_2),                                 (OT4)
```
   is exact, `L_n` is infinite and simple, and `EL_n(D)` is residually
   finite.

`A_2` is the ring called `R_q` at `q = 2` in
`torsion-defect-universal-rank-transport-proof`.  That route needs only
the defect ideal and one normal locally finite subgroup at rank four;
`(OT2)`--`(OT4)` add the symbol quotient, the fibre-product description
and the identification of the **whole** kernel at every rank down to two.

**ESTABLISHED.** Let `G` be a torsion-free group and let `A` and `B` be
finite nonempty subsets of `G` such that no element of `AB` has a unique
expression `ab` with `a in A` and `b in B`. Suppose `1 in A` and put
`H = <A>`. For every homomorphism `phi: H -> L` into a left-ordered group:

1. the minimum of `phi` on `A` is attained at no fewer than three elements
   of `A`, and so is the maximum;
2. if `phi` is not constant on `A`, then `|A| >= 6`;
3. if `|A| <= 5`, then `phi` is trivial.

So when `|A| <= 5`, `H` has no nontrivial left-orderable quotient. Its
abelianization is finite, every homomorphism from `H` to `Z`, to a free
group, to a torsion-free nilpotent group or to `Homeo^+(R)` is trivial, and
`H` is not locally indicable. The same holds for `<B>` when `1 in B` and
`|B| <= 5`.

**Zero divisors.** Let `k` be a field and `alpha, beta` nonzero elements of
`k[G]` with `alpha beta = 0`. If `|supp alpha| <= 5`, then
`<a^-1 c : a, c in supp alpha>` has no nontrivial left-orderable quotient. If
`|supp beta| <= 5`, then `<b c^-1 : b, c in supp beta>` has none. For
instance, a zero divisor `r_1 g + r_2 gx + r_3 gy` forces `<x,y>` to have
finite abelianization and no nontrivial action on the line by
orientation-preserving homeomorphisms.

**Sieve on universal groups.** Let `X` be a set of quadruples in
`([m] x [n])^2` such that every pair `(i,j)` has a partner
`(k,l) != (i,j)` with `(i,j,k,l) in X`, and put

```text
G_X = < a_1, ..., a_m, b_1, ..., b_n | a_1 = b_1 = 1,  a_i b_j = a_k b_l for (i,j,k,l) in X >.
```

Suppose `m <= 5` and some homomorphism from `<a_1, ..., a_m> <= G_X` to a
left-ordered group is nontrivial. For instance, some `a_i` has nonzero image
in `G_X^ab tensor Q`. Then no homomorphism from `G_X` to a torsion-free
group is injective on both `{a_i}` and `{b_j}`. So `X` is not the pattern of
equal products of any zero divisor. The test must be applied to complete
patterns. Adding quadruples replaces `G_X` by a quotient, and orderable
quotients need not survive.

With `phi` the identity of a left-ordered `H`, item 1 is impossible. So the
statement contains the classical fact that left-orderable groups have unique
products.

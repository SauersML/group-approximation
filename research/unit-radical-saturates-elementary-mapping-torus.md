**ESTABLISHED.** Let `S` be a countable unital associative ring, `sigma in Aut(S)`, `n >= 3`, and

```text
G_n = E_n(S) semidirect_sigma Z,     t e_ij(a) t^(-1) = e_ij(sigma(a)).
```

Let `C <= S^x` be a unit subgroup with `sigma(C) = C` and `diag(c,1,...,1) in E_n(S)` for every
`c in C`. By Whitehead's lemma this holds for `C = [S^x, S^x]`, and for every `sigma`-invariant
subgroup of it. Put

```text
U_C = Rad_MF(C semidirect_sigma Z)   (it lies in C x {0}),
I_C = two-sided ideal of S generated by { c - 1 : (c,0) in U_C }.
```

Then:

1. **(Saturation)** `I_C` is `sigma`-invariant, and the relative elementary group satisfies
   `E_n(S, I_C) x {0} <= Rad_MF(G_n)`.
2. **(Exact radical)** If `I_C = S`, then `Rad_MF(G_n) = E_n(S) x {0}`.
3. **(sigma-simple case)** If `S` has no nonzero proper `sigma`-invariant two-sided ideal and `U_C != 1`,
   then `Rad_MF(G_n) = E_n(S) x {0}`.
4. **(Dynamical case)** Let `S = LC(Y,k) semidirect Gamma`, with `Y` compact totally disconnected,
   `k` a commutative unital ring, and `Gamma` acting by homeomorphisms. Suppose the elements `h` of the
   topological full group `[[Gamma curvearrowright Y]]` with `(u_h, 0) in U_C` have no common fixed point
   on `Y`. Then `I_C = S`, so `Rad_MF(G_n) = E_n(S) x {0}`.

More generally, **level-ideal lemma**: for every `N <= E_n(S)` that is normalised by `E_n(S)`, the sets
`{a : e_ij(a) in N}` for `i != j` all equal one two-sided ideal `J(N)`, and `E_n(S, J(N)) <= N`. If
`N` is also normal in `G_n`, then `J(N)` is `sigma`-invariant.

**Consequences.**
- **(C1) A refutation route for (EKL1).** Suppose `S` is finitely generated, nonzero and a LEF ring,
  and `I_C = S` for some admissible `C`. Then `K = E_3(S)` is:
  - nontrivial and finitely generated;
  - Kazhdan, by `ershov-jaikin-kassabov-steinberg-groups-have-property-t`;
  - LEF, because `GL_3` of a LEF ring is LEF.

  Also `Rad_MF(K semidirect_sigma Z) = K x {0}`. So `K` violates (EKL1) of
  `exact-kazhdan-radical-kernel-cannot-be-lef`.
- **(C2) Forced failures (class kills).**
  - *Finite quotient rings.* If a finitely generated `S` has any nonzero finite quotient ring, then
    `Rad_MF(G_n) != E_n(S) x {0}`, and hence `I_C != S`. This kills:
    - group rings `k[Gamma]` over finite fields or `Z`, by the augmentation;
    - every residually finite ring, which gives `Rad_MF(G_n) = 1` outright.
  - *Amenable unit groups.* If `C` is amenable, then `C semidirect Z` is amenable, hence MF by
    `amenable-implies-operator-mf`. So `U_C = 1` and `I_C = 0`. In particular, commutative unit subgroups
    give nothing. `C` must be a non-amenable LEF group whose `Z`-extension is not MF, as in
    `mf-not-closed-under-integer-extensions`.
  - *Ambient inner powers.* If `sigma^r` is conjugation by a unit of a LEF ring containing `S`, then
    `G_n` is LEF by (C) of `quotient-permuting-and-ambient-inner-mapping-tori-are-lef`, so `U_C = 1`.
- **(C3)** Step 0 of `simple-ring-centralizer-compression-gives-xmf-proof` is the level-ideal lemma over
  a simple ring. For a `N` that is normal in the whole mapping torus, it holds verbatim over a
  `sigma`-simple ring. Whether the remaining steps of that route survive the weakening is not claimed
  here.

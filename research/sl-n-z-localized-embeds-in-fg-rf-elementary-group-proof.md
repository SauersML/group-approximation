Notation as in the target. Write `R = R̄_l`.

**1. Θ is multiplicative and injective.** For `A, B in M_n(Z_(l))` the entries of
`θ(A)` lie in `eRe`, so `θ(A)(1-e) = 0 = (1-e)θ(B)` entrywise. Hence

    Θ(A)Θ(B) = θ(A)θ(B) + (1-e)^2 I = θ(AB) + (1-e) I = Θ(AB),

and `Θ(I) = e I + (1-e) I = I`. So `Θ` maps `GL_n(Z_(l))` into `GL_n(R)`
homomorphically. It is injective because `θ` is and `Θ(A) e = θ(A)`.

**SL_n(Z_(l)) = E_n(Z_(l)).** `Z_(l)` is local with maximal ideal `l Z_(l)`.
- Let `g in SL_n(Z_(l))`. Some entry of the first column is a unit, since otherwise
  `det g in l Z_(l)`.
- Elementary row operations move a unit into position `(1,1)` and make it 1. They
  then clear the first row and column.
- Induction on `n` reduces `g` to a diagonal matrix of determinant 1. By Whitehead's
  lemma (item 2 below, for `1 x 1` blocks) it lies in `E_n(Z_(l))`.

`Θ(e_ij(c)) = I + θ(c) E_ij = e_ij(θ(c))`, so `Θ(SL_n(Z_(l))) ⊆ E_n(R)`.

**2. Whitehead's lemma.** For any unital ring `S` and `a in GL_n(S)`,

    diag(a, a^-1) = [[1,a],[0,1]] [[1,0],[-a^-1,1]] [[1,a],[0,1]] [[0,-1],[1,0]]

in `2 x 2` blocks. Each factor lies in `E_(2n)(S)`: block unipotents are products of
elementary matrices, and `[[0,-1],[1,0]] = [[1,-1],[0,1]] [[1,0],[1,1]] [[1,-1],[0,1]]`
in blocks. Apply this with `a = Θ(g)`. The map `g -> diag(Θ(g), Θ(g)^(-1))` is an
injective homomorphism, since its first block is `Θ`.

**3. Finite generation.** Let `N >= 3` and let `Σ` be the five generators of `R`
together with `1`. By `e_ij(r) e_ij(s) = e_ij(r+s)`, and by
`[e_ij(r), e_jk(s)] = e_ik(rs)` for distinct `i, j, k`, the subgroup generated by
`{e_ij(σ) : σ in Σ}` contains `e_ij(r)` for every `r` in the ring generated by `Σ`,
which is `R`. So it is `E_N(R)`.

**4. Residual finiteness.** Let `1 != g in GL_N(R)`. Some entry of `g - I` is nonzero,
so it survives in some component `End(M_r)` of `R`. The ring map `R -> End(M_r)`
induces a group map `GL_N(R) -> GL_N(End(M_r))` to a finite group, under which `g`
survives. ∎

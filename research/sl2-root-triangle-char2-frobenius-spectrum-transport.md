**Setting.** Take the data of `kazhdan-hyperbolic-sl2-root-triangles` with `q = 2^f >= 8`, `k = F_q ⊂ F = F_{q^2}` and
`s ∈ F \ k`. Use the standard root parametrizations `p_i^e: (k,+) -> A_i`:
- `p_1^{12} = u` and `p_1^{13} = v`;
- `p_2^{12} = u` and `p_2^{23} = v`;
- `p_3^{13} = u` and `p_3^{23}(y) = v(sy)`.

Here `u(y) = [[1,y],[0,1]]` and `v(y) = [[1,0],[y,1]]`. The edge group `E_e` is embedded at vertex `i` as
`x ↦ p_i^e(α_i^e(x))`, and the relative twist of `e = (i,j)`, `i < j`, is `φ_e = α_j^e (α_i^e)^{-1} ∈ GL(k,+)`.

**Linearized support.** Put `ψ_e = φ_e^{-1}`. Every additive map `ψ: k -> k` is uniquely
`ψ(y) = Σ_{b ∈ Z/f} c_b y^{2^b}` with `c_b ∈ k`; write `supp(ψ) = { b : c_b ≠ 0 }`.
- `φ_e` is semilinear, `φ_e(x) = λ_e x^{2^{a_e}}`, iff `|supp(ψ_e)| = 1`. In that case `supp(ψ_e) = {-a_e}`.
- For semilinear twists, the **Frobenius holonomy** is `hol = a_12 + a_23 - a_13 ∈ Z/f`.

**Frobenius expansion.** Let `K` be a field of characteristic 2 containing `F`, and `ρ: Λ -> GL(M)` a
representation, `d = dim M`. For each root parametrization `p` there are unique commuting operators
`X_a^p ∈ End(M)`, `a ∈ Z/f`, with `(X_a^p)^2 = 0` and

```text
ρ(p(y)) = Π_{a ∈ Z/f} (1 + y^{2^a} X_a^p)      for all y ∈ k.
```

The **Frobenius spectrum** of `p` is `S(p) = { a : X_a^p ≠ 0 }`.

**ESTABLISHED (unreviewed).** Let `ρ` be nontrivial.
- **(0) Characteristic.** In characteristic `≠ 2`, every nontrivial representation of `Λ` has dimension
  `>= q - 1`.
- **(a) One spectrum per vertex.** `S(p_i^e)` does not depend on `e`. Call it `S_i`.
- **(b) Nonempty and bounded.** `1 <= |S_i| <= d(d-1)/2`.
- **(c) Edge transport.** For `e = (i,j)`, `S_j = S_i + supp(ψ_e)`, and `S_j = S_i + b` for every `b ∈ supp(ψ_e)`.
- **(d) Triangle.** Let `H ≤ Z/f` be generated by:
  - all differences `b - b'` with `b, b' ∈ supp(ψ_e)`, for `e = 12, 13, 23`;
  - `b_12 + b_23 - b_13` for one choice of `b_e ∈ supp(ψ_e)`.

  Then `S_1` is a union of `H`-cosets, so `|H|` divides `|S_1|` and `|H| <= d(d-1)/2`. For semilinear
  twists, `H = <hol>`.

**Corollaries.**
- **Dimension 2.** `|S_i| <= 1`, so `H = 0`: every twist is semilinear and `hol = 0`. This recovers
  `sl2-root-triangle-2dim-reps-force-semilinear-gluing` and adds the holonomy condition; see
  `sl2-root-triangle-2dim-iff-zero-frobenius-holonomy`.
- **`f` prime.** If some twist is non-semilinear, or all are semilinear with `hol ≠ 0`, then `H = Z/f`. So
  every nontrivial representation has `S_1 = S_2 = S_3 = Z/f` and `d(d-1)/2 >= f`.
- **`f = 3`.** Every nontrivial representation of such a member has `d >= 4`. Three linearly independent
  commuting nilpotent `3×3` matrices do not exist, since a commutative subspace of strictly upper
  triangular `3×3` matrices has dimension at most 2.

**What it does not say.** Stability under `H` constrains only the spectrum. A spectrum equal to all of
`Z/f` is stable under every shift. So the claim does not exclude representations whose vertex
restrictions look like the Steinberg module `V ⊗ V^{(1)} ⊗ ... ⊗ V^{(f-1)}` (dimension `q`), whose
spectrum is `Z/f`. Whether such representations exist for a nonzero-holonomy or non-semilinear member
is open.

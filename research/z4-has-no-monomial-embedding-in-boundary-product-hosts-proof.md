Notation as in the target. For a bisection `U` and `y ∈ s(U)`, write `U_y` for the germ of `U` at `y`, which is
the unique arrow of `U` with source `y`. Write `h·y = r((U_h)_y)`.

## Item 1: converse germ lemma

1. **Germs compose.** `φ(g)φ(h) = φ(gh)` and `1_U 1_V = 1_(UV)` for bisections. Since `1_U` determines `U`, we
   get `U_g U_h = U_(gh)` and `U_e = Y`. Hence `(U_(gh))_y = (U_g)_(h·y) (U_h)_y`.
2. **Fixed-germ sets.** Put `W_h = { y ∈ Y : (U_h)_y ∈ 𝒢^(0) }`, which equals `U_h ∩ 𝒢^(0)`. The groupoid is
   Hausdorff and ample, so `𝒢^(0)` is clopen in `𝒢`. Hence `W_h` is compact open in `Y`.
   - By step 1, `(U_g)_y = (U_(g'))_y` holds iff `y ∈ W_(g^(-1) g')`.
   - On `W_h` the bisection `U_h` is the identity, so `1_(W_h) φ(h) = 1_(W_h)`.
3. **Invariance.** `H` is abelian, so `U_g U_h U_g^(-1) = U_h`. At `g·y` this reads
   `(U_h)_(g·y) = (U_g)_y (U_h)_y (U_g)_y^(-1)`, which is a unit iff `(U_h)_y` is one. So `g·W_h = W_h`.
   Consequently `φ(g) 1_(W_h) φ(g)^(-1) = 1_(g·W_h) = 1_(W_h)`: each `1_(W_h)` commutes with `φ(H)`, and so
   does every element of the Boolean algebra generated by the sets `W_h`.
4. **Compactness.** Suppose no `y` has pairwise distinct germs. Then `Y = ∪_(h ≠ e) W_h` by step 2. By
   compactness, `Y = W_(h_1) ∪ … ∪ W_(h_q)` with every `h_i ≠ e`.
   - Put `V_j = W_(h_j) ∖ ∪_(i<j) W_(h_i)`. These are disjoint and `φ(H)`-central clopens with union `Y`.
   - Put `p = Π_i (1 + h_i) ∈ F_2[H]`. Since `H` is torsion-free abelian, `F_2[H]` is a domain (it is a
     directed union of Laurent polynomial rings), so `p ≠ 0`.
   - Then `1_(V_j) φ(p) = Π_(i ≠ j) (1_Y + φ(h_i)) · 1_(V_j)(1_Y + φ(h_j))`. The last factor is
     `1_(V_j) + 1_(V_j) = 0` by step 2, since we are in characteristic 2.
   - So `φ(p) = Σ_j 1_(V_j) φ(p) = 0`, which contradicts injectivity.
5. **Conclusion of item 1.** Some `y` has pairwise distinct germs. `c` is at most `m`-to-one on `𝒢_y`, so
   `h ↦ c((U_h)_y)` is at most `m`-to-one.

## Item 2: separator obstruction

1. **Reduction.** Let `H ⊇ Z^(r+2)`. Conjugating by `w` preserves injectivity, and restricting to
   `F_2[Z^(r+2)]` also preserves it. So assume `H = Z^(r+2) = Z^n` with basis `e_1, …, e_n`. Item 1 gives a
   point `y` such that `f(h) = c((U_h)_y)` is at most `m`-to-one.
2. **Lipschitz property.** By step 1 of item 1, `f(e_i^(±1) h) = c((U_(e_i^(±1)))_(h·y)) f(h)`. The set
   `S = ∪_i c(U_(e_i^(±1)))` is finite, because each `U` is compact, `c` is continuous and `Q` is discrete.
   - Let `L = max_(s ∈ S) |s|` in the standard word length of `Q`. Put `ψ(h) = f(h)^(-1)`.
   - Then `d(ψ(h'), ψ(h)) = |f(h') f(h)^(-1)| <= L` for grid neighbours `h ~ h'`, where `d` is the metric of
     the right Cayley graph of `Q`. That graph is `T × Z^r` with metric `d_T + |·|_1`, where `T` is the
     `2d`-regular tree.
   - So `ψ` is `L`-Lipschitz from the grid graph on `Z^n` to `T × Z^r`, and at most `m`-to-one.
3. **The slab.**
   - Setup. Let `B = {0, …, k-1}^n` with its induced grid graph, and `N = k^n`. Give each tree vertex `t`
     the weight `w(t) = |{ b ∈ B : π_T ψ(b) = t }|`. A finitely supported weight on a tree has a centroid
     `v`: every component of `T ∖ {v}` has weight at most `N/2`.
   - The separator. Put `Σ = { b ∈ B : d_T(π_T ψ(b), v) <= L }`.
   - Components avoid the centroid. Let `b ~ b'` be an edge of `B ∖ Σ`. Its tree images are at distance at
     most `L`. If the geodesic between them passed through `v`, both images would lie within `L` of `v`. So
     both lie in the same branch of `T ∖ {v}`. Hence each component of `B ∖ Σ` lies over a single branch,
     and every branch carries at most `N/2` points of `B ∖ Σ`.
   - Size of the separator. The `Z^r`-coordinates of `ψ(B)` lie in a box of side `2nLk + 1`. The
     tree-coordinates of `ψ(Σ)` lie in `B_T(v, L)`. Hence
     `|Σ| <= m · |B_T(L)| · (2nLk + 1)^r =: C k^r`
     for `k >= 1`, with `C` independent of `k`.
4. **Splitting.** Let `M = N − |Σ|`, and take `k` large enough that `|Σ| <= N/12`.
   - Group the branches into two unions `P, R` of points of `B ∖ Σ`, so that `P ∪ R = B ∖ Σ`.
   - Case 1: some branch has at least `M/3` points. Take it as `P`. Then `|P| >= M/3 >= 11N/36`, and
     `|R| >= M − N/2 >= 5N/12`.
   - Case 2: no branch has `M/3` points. Add branches greedily until the total reaches `M/3`. The total is
     then below `2M/3`.
   - Either way `|P|, |R| >= N/4`. No grid edge joins `P` to `R`, so every edge leaving `P` ends in `Σ`.
     Hence `|∂P| <= 2n|Σ|`.
5. **Cube isoperimetry by canonical paths.** For each ordered pair `(a, b) ∈ P × (B ∖ P)`, walk from `a` to
   `b` by fixing coordinates `1, 2, …, n` in turn, each monotonically. Each such path crosses `∂P`.
   - An edge in direction `i` at `x` is used only by pairs with `a_j = x_j` for `j > i` and `b_j = x_j` for
     `j < i`. That leaves at most `k^(i-1) · k^(n-i) · k^2 = k^(n+1)` pairs.
   - Hence `|P| |B ∖ P| <= k^(n+1) |∂P|`, so `|∂P| >= (N/4)^2 / k^(n+1) = k^(n-1)/16`.
6. **Contradiction.** Combining steps 3 to 5 gives `k^(n-1)/16 <= 2nC k^r`. With `n = r + 2` this is
   `k <= 32nC`, which fails for large `k`. ∎

## Item 3: sharpness

`Z^r × ⟨a⟩ ≅ Z^(r+1)` is a subgroup of `Q`. The canonical units `v_q` are the full bisections `{q} × X`,
and `F_2[Q] → LC(X) ⋊ Q` is injective because the crossed product is free as a left `LC(X)`-module on
`{v_q}`. ∎

## Remarks

- The abelian hypothesis enters only in step 3 of item 1. For non-abelian inputs the sets `W_h` are not
  invariant. The hypothesis in `crossed-product-growth-bounded-by-ball-patterns`, part 3, shows that
  disjoint-support pairs then give genuine kernels.
- Item 2 uses only that `Cay(Q)` embeds in `T × Z^r` with bounded fibres. It therefore applies verbatim to
  `Q = Z^r × Λ` for any virtually free `Λ`.

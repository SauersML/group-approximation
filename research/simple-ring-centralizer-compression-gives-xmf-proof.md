## Why sufficient

Notation.  `x_ij(a)` is the elementary matrix, `t` the generator of `Z` in
`E`, so `t g t^{-1} = sigma(g)`.  Commutators are `[g,h] = g h g^{-1} h^{-1}`.
Two standard Steinberg identities are used, valid over every unital ring:

```text
(St1) x_ij(a) x_ij(b) = x_ij(a+b);
(St2) [x_ij(a), x_jk(b)] = x_ik(ab)   for i,j,k distinct.
```

**Step 0 (saturation lemma).**  Let `N` be a normal subgroup of `EL_3(S)`
containing `x_12(r)` with `r != 0`.  Then `N = EL_3(S)`.

By (St2), `[x_12(r), x_23(b)] = x_13(rb)` lies in `N`, and then
`[x_21(a), x_13(rb)] = x_23(arb)` lies in `N`, for all `a,b in S`.  By (St1),
`x_23(s) in N` for every `s` in the two-sided ideal `SrS`, which is `S` by
simplicity.  Commutators with an element of `N` stay in `N`, so (St2) gives,
in order:

```text
x_13(s) = [x_12(s), x_23(1)]     (x_23(1) in N),
x_12(s) = [x_13(s), x_32(1)]     (x_13(s) in N),
x_32(s) = [x_31(s), x_12(1)]     (x_12(1) in N),
x_31(s) = [x_32(1), x_21(s)]     (x_32(1) in N),
x_21(s) = [x_23(1), x_31(s)]     (x_31(s) in N).
```

So all six root subgroups lie in `N`, hence `N = EL_3(S)`.

**Step 1 (the kernel).**  `S` is finitely generated, so `EL_3(S)` is
countable, and it is nontrivial because `S != 0`.  `EL_3(S)` is the elementary
Chevalley group of type `A_2` over the finitely generated ring `S`, so it has
property (T) by `ershov-jaikin-kassabov-steinberg-groups-have-property-t`
(type `A_n` allows noncommutative rings).  It is MF by (CC1).

*No finite quotients.*  Let `f : EL_3(S) -> F` with `F` finite.  The map
`s |-> f(x_12(s))` is a homomorphism from `(S,+)` to `F`, so its kernel `I`
has finite index in the infinite group `(S,+)`, hence contains some `r != 0`.
Then `ker f` is normal and contains `x_12(r)`, so `ker f = EL_3(S)` by Step 0.

`K = EL_3(S) x {0}` is normal in `E`, because `sigma` maps elementary
matrices to elementary matrices, and `E/K ~= Z`.

**Step 2 (the Kazhdan source and its contraction).**  Let `L <= EL_3(S)` be
the subgroup generated by `x_ij(a)` for `a in R`.  It is the image of
`EL_3(R)` under the map induced by `R -> S`.  `R` is finitely generated, so
`EL_3(R)` has property (T) by the same import, and so does its quotient `L`.
Take `Gamma = L` and `iota` the inclusion into `E`.  For a generator,
`t x_ij(a) t^{-1} = x_ij(sigma(a))` with `sigma(a) in R` by (CC2).  So
`t L t^{-1} <= L`, which is the `compresses` field of `KazhdanCompressionCore`.

**Step 3 (the scalar root).**  For any unit `u`, the element
`h_12(u) = x_12(u) x_21(-u^{-1}) x_12(u) x_12(-1) x_21(1) x_12(-1)` equals
`diag(u, u^{-1}, 1)`, and similarly `h_13(u) = diag(u, 1, u^{-1})`.  For units
`x,y`,

```text
h_12(x) h_13(y) h_12(x)^{-1} h_13(y)^{-1} = diag(xyx^{-1}y^{-1}, 1, 1).
```

So `diag(z,1,1) in EL_3(S)` for every `z in [S^x,S^x]`.  Conjugating by the
Weyl elements `x_ij(1) x_ji(-1) x_ij(1)`, which permute diagonal entries up to
sign, and sign changes cancel in conjugation of a diagonal matrix, gives
`diag(1,z,1)` and `diag(1,1,z)` in `EL_3(S)`.  Their product is `c = zI`, so
`c in EL_3(S)` by (CC3).  Since `zI x_ij(a) (zI)^{-1} = x_ij(z a z^{-1})`,
`c` commutes with `x_ij(a)` when `za = az`.  By (CC4) `c` commutes with every
generator of `L`, hence with `L`.  This is the `comm_c` field.

So `C = (Gamma = L, iota, t, c)` is a `KazhdanCompressionCore L E`
(`GroupApproximation/Sofic/KazhdanCompressionCore.lean`).

**Step 4 (the defect saturates K).**  The transported root is
`t c t^{-1} = sigma(z) I`, and for `a in R`

```text
[sigma(z) I, x_ij(a)] = x_ij(sigma(z) a sigma(z)^{-1}) x_ij(-a)
                      = x_ij(sigma(z) a sigma(z)^{-1} - a).
```

By (CC4) there is `b in sigma^{-1}(R)` with `zb != bz`.  Put
`a = sigma(b) in R`.  Applying `sigma` gives `sigma(z) a != a sigma(z)`, so
`r = sigma(z) a sigma(z)^{-1} - a != 0`.  Thus `x_12(r)` lies in the defect set
of `C`, and so in `C.defectNormal`, the normal closure in `E`.  The subgroup
`C.defectNormal cap K` is normal in `EL_3(S)` and contains `x_12(r)`, so it is
all of `K` by Step 0.  Hence `K <= C.defectNormal`.

**Step 5 (the radical).**  `E` is countable.  `K` is normal in `E`,
nontrivial, has property (T) (Step 1) and lies in `C.defectNormal` (Step 4).
The kernel-checked theorem `KazhdanCompressionCore.normalKazhdan_le_normMFResidual`
of `normal-kazhdan-defect-non-mf` gives `K <= Rad_MF(E)`.  Conversely
`E -> E/K ~= Z` is a homomorphism to a countable residually finite group,
which is MF by `central-quotients-of-residually-finite-groups-are-mf`
(trivial central quotient).  So `Rad_MF(E) <= K`, and `Rad_MF(E) = K`.

Together with Step 1, `Q = EL_3(S)` and `psi = sigma` satisfy every clause of
`(XMF)`.  As the `(XMF)` node requires, `sigma` has infinite order in `Out(Q)`
automatically.  Directly: (CC4) forces `sigma(R) != R`, since otherwise
`sigma^{-1}(R) = R` and `z` would commute with it.

**Squaring case.**  If `sigma(w) = w^2` and `R` is generated by `w^{+-2}`,
then `sigma(R)`, generated by `w^{+-4}`, lies in `R`.  `sigma^{-1}(R)` contains
`sigma^{-1}(w^2) = w`, so `[z,w^2] = 0 != [z,w]` is (CC4).

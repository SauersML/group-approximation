Lane proof, 2026-09-18 (bh-free-17). Notation as in the target.

1. **`R` is a finite module over a finitely generated subring.**
   - `Q ≅ Γ/R^n` is finitely generated, where `Γ = R^n ⋊ Q`. Let `g_1, …, g_k` generate `Q`, and let
     `R_0 ⊆ R` be the subring generated by the entries of all `g_i^{±1}`. Then `R_0` is finitely
     generated and `Q ≤ GL_n(R_0)`.
   - Let `(a_1, q_1), …, (a_r, q_r)` generate `Γ`. The `Z[Q]`-submodule `M ⊆ R^n` generated by
     `a_1, …, a_r` is `Q`-invariant. So `M ⋊ Q` is a subgroup containing every generator, and
     `M = R^n`.
   - `Z[Q]` acts on `R^n` through the `Z`-span of `Q`, which lies in `M_n(R_0)`. So
     `R^n ⊆ Σ_i M_n(R_0) a_i`. Taking first coordinates gives `R ⊆ Σ_{i,j} R_0 (a_i)_j ⊆ R`.
   - So `R` is a finitely generated `R_0`-module, hence a finitely generated ring.
2. **`R` is algebraic.** `R` is a domain of characteristic zero (a subring of `Z_p`) and is
   finitely generated. Rigidity is condition (SC) with `O = Z_p` and `π = p`. So
   `affine-self-similar-coordinate-rings-are-one-dimensional` makes `Frac(R) = K` a number field.
3. **`Q` is linear over `Q`.** `Q ≤ GL_n(K) ≤ GL_{n[K:Q]}(Q)`. ∎

**An independent check of step 2 via dimension theory.**
- **`pR` is maximal.** Rigidity gives `R ∩ pZ_p = pR`, so `R/pR ↪ F_p`. Hence `m = pR` is maximal
  and principal.
- **Upper bound.** Krull's principal ideal theorem gives `ht(m) ≤ 1`.
- **Lower bound.** `Z` is universally catenary (Matsumura, *Commutative Ring Theory*, Thm 17.9). So
  the dimension formula (Matsumura Thm 15.6) applies:
  `ht(m) = ht(pZ) + trdeg_Q Frac(R) − trdeg_{F_p} κ(m) = 1 + trdeg_Q Frac(R)`.
- **Conclusion.** The two bounds force `trdeg_Q Frac(R) = 0`.

**Examples.**
- `Z[√2, 1/(3+√2)] ⊂ Z_7`, with `√2 ≡ 3 (mod 7)`, is rigid and finitely generated. `7` splits as
  `(3+√2)(3−√2)`, and only `3 − √2` lies in `7Z_7`.
- `Z[s]` with `s ∈ Z_p` transcendental is not rigid. With `s ≡ c (mod p)`, the element `s − c`
  lies in `Z[s] ∩ pZ_p` but not in `pZ[s]`.

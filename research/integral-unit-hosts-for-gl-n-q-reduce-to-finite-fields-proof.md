Lane proof, not independently reviewed. Notation as in the target: `A` is unital
with a `Z`-basis `B`, and `A_K = A ⊗_Z K`. Only part 4 uses the cited K-theory.

**0. Integral structure.** Products of elements of `B` are `Z`-combinations of `B`.
So for every subring `D ⊆ K`, the `D`-span `A_D = A ⊗ D` of `B` is a subring of
`A_K`, and `A_D -> A_K` is injective because `A_D ≅ D^(B)`. For `L_Z(1,d)` a basis
is the set of irreducible words of the reduction system `t_i s_j -> δ_ij`,
`s_d t_d -> 1 - Σ_(i<d) s_i t_i`. Its two ambiguities resolve with integer
coefficients:
- `t_i s_d t_d`: both sides reduce to `δ_id t_d`;
- `s_d t_d s_j`: both sides reduce to `δ_dj s_d`.

So Bergman's diamond lemma applies over `Z`.

**1. Residually finite-field.** Let `S = <g_1, ..., g_r>`. Let `D ⊆ K` be the
subring generated by the `B`-coordinates of all matrix entries of the `g_i` and
the `g_i^(-1)`. Then `S ≤ GL_m(A_D)`. `D` is a finitely generated commutative
domain over `Z` or over `F_p`. So it is a Jacobson ring with Jacobson radical
equal to its nilradical, which is `0`. Every residue field `D/𝔪` at a maximal
ideal is finite (Nullstellensatz for finitely generated `Z`- and `F_p`-algebras).
The reduction `ρ_𝔪 : A_D -> A ⊗ D/𝔪` is a surjective ring homomorphism with
kernel `𝔪^(B)`. Hence `∩_𝔪 ker ρ_𝔪 = (∩_𝔪 𝔪)^(B) = 0`. Entrywise, the product of
the `ρ_𝔪` embeds `GL_m(A_D)`, and so `S`, in `∏_𝔪 GL_m(A ⊗ D/𝔪)`.

**2. Transfer of SL_n(Q) and PSL_n(Q).**
- **Setup.** In every case we have a subgroup `P ≤ S` and a surjection
  `π: P -> P_0 ≅ PSL_n(Q)` whose kernel `Z_P` is central in `P`.
  - Case (a): `P` is the given copy of `SL_n(Q)`, with `Z_P ≤ {±I}`, or the given
    copy of `PSL_n(Q)`, with `Z_P = 1`.
  - Case (b): lift generators, so that `S ≤ GL_m(A_K)` is finitely generated with
    image `S̄ ≤ GL_m(A_K)/K^x` containing `P_0`. Put `P = {s ∈ S : sK^x ∈ P_0}`.
    Every element of `P_0` has a representative in `S`, so `π` is onto, with
    kernel `Z_P = P ∩ K^x·1`, which consists of central scalars.
- **Perfectness.** `PSL_n(Q)` and `SL_n(Q)` are perfect, because `|Q| > 3`.
  `PSL_n(Q)` is also simple and has trivial centre. So `P' = [P,P]` maps onto
  `P_0`, and in case (a) `P' = P`.
- **Some reduction has central kernel.** Take `D` and `ρ_𝔪` from part 1 and put
  `N_𝔪 = ker(ρ_𝔪|P')`. The image `π(N_𝔪)` is normal in the simple group `P_0`,
  so it is `1` or `P_0`.
  - Suppose it were `P_0` for every `𝔪`. Then `P' = N_𝔪 (P' ∩ Z_P)`, so
    `P'/N_𝔪` is a quotient of the abelian group `P' ∩ Z_P`. Since `P'` is perfect,
    `P' = N_𝔪` for every `𝔪`. Then `P' = ∩_𝔪 N_𝔪 = 1`, which contradicts
    `π(P') = P_0 ≠ 1`.
  - So for some `𝔪` we have `N_𝔪 ≤ P' ∩ Z_P`.
- **The group over a finite field.** Put `F = D/𝔪` and `G_F = ρ_𝔪(P') ≅ P'/N_𝔪`.
  Then `G_F -> P_0` is onto with kernel `C_0 = ρ_𝔪(P' ∩ Z_P)`, which is central in
  `G_F`.
  - Case (a): `G_F ≅ P/N_𝔪` with `N_𝔪 ≤ Z_P ≤ {±I}`, so `G_F` is a copy of
    `SL_n(Q)` or of `PSL_n(Q)` in `GL_m(A ⊗ F)`.
  - Case (b): choose the basis `B` with `1 ∈ B`, which is possible because `Z·1`
    is a direct summand. A scalar `λ·1 ∈ A_D` then has `λ ∈ D`. So `ρ_𝔪` maps
    `Z_P` into `F^x·1`, which is central in `GL_m(A ⊗ F)`. Let
    `C = G_F ∩ F^x·1`; then `C_0 ≤ C`. The image of `C` in `P_0` is central,
    hence trivial, so `C = C_0` and `G_F·F^x/F^x ≅ G_F/C_0 ≅ PSL_n(Q)`.
- **Lifting (Q,+).** The upper unitriangular group `U ≅ (Q,+)` in one `2 x 2`
  block meets `{±I}` trivially, so it injects into `P_0`. Let `Ẽ ≤ G_F` be its
  preimage, a central extension of `(Q,+)` by `C_0`. In case (a), `G_F` already
  contains `U`. In case (b), `C_0 ≤ F^x` is finite.
  - The commutator map `Q x Q -> C_0` is bilinear and alternating, so it factors
    through `Λ²_Z Q = 0`: indeed `(a/q) ∧ (b/s) = ab·qs·(1/qs ∧ 1/qs) = 0`. So `Ẽ`
    is abelian.
  - `Ext^1_Z(Q, C_0) = 0`: multiplication by `|C_0|` acts invertibly through the
    first argument and as zero through the second.
  - So `Ẽ ≅ Q ⊕ C_0`, and `(Q,+) ≤ GL_m(A ⊗ F)`.

**3. (Q,+) and F[Q].**
- **From F[Q] to (Q,+).** If `F[Q] ⊆ R` unitally, the group elements are units,
  and distinct elements stay distinct.
- **From (Q,+) to F[Q].** Conversely, let `ι: Q -> R^x` be injective and put
  `x_k = ι(1/k!)`. An algebraic unit `x` over the finite field `F` generates a
  finite ring `F[x]`, so it has finite order. Hence every `x_k` is transcendental
  over `F`. Then `F[x_k^(±1)]` is a Laurent ring: `f(x_k) = x_k^(-N) g(x_k) = 0`
  with `g ∈ F[x]` forces `g = 0`. `F[Q]` is the increasing union of the
  `F[(1/k!)Z] ≅ F[x_k^(±1)]`, so the induced map `F[Q] -> R` is injective.
- **F[Q] inside M_(∞!)(F) ⊗ F[t^(±1)].** Write `t = [1]`. `F[t^(±1/k!)]` is free
  over `F[t^(±1)]` on `t^(j/k!)`, `0 <= j < k!`. Its regular representation is a
  unital embedding into `M_(k!)(F[t^(±1)])`. In the basis
  `t^(i/(k+1)!) t^(j/k!)` of level `k+1` (the exponents `((k+1)j + i)/(k+1)!`
  enumerate `0, ..., (k+1)! - 1` once), multiplication by an element of level `k`
  is block diagonal `diag(a, ..., a)`. So the embeddings are compatible with
  `a -> diag(a, ..., a)`, and their union embeds `F[Q]` in the limit
  `M_(∞!)(F) ⊗ F[t^(±1)]`.
- **The sufficient condition.** Let `U ⊆ R` be a unital copy of `M_(∞!)(F)` and
  `u` a unit of infinite order commuting with `U`. The induced map
  `M_(k!)(F[u^(±1)]) -> R` has kernel `M_(k!)(I)` for an ideal `I` of
  `F[u^(±1)]`. For `f ∈ I` we get `f(u) = Σ_i E_(i1) f(u) E_(1i) = 0`, so `f = 0`
  because `u` is transcendental. So the limit, and with it `F[Q]`, embeds in `R`.
- **Infinite rank.** If `F[Q] ⊆ R` with `u = t`, then `F[Q] ⊆ C_R(u)`. Localization
  is exact, so `F(u) ⊗_(F[u]) C_R(u)` contains
  `F(u) ⊗_(F[u]) F[Q] = F(t)[t^Q]`. That has infinite dimension over `F(t)`,
  because `F[Q]` is free over `F[t^(±1)]` on `{t^q : 0 <= q < 1}`. So `ρ(u) = ∞` in
  the notation of `leavitt-unit-centralizers-have-finite-rank`.

**4. Not a corner.**
- **Corners have finite K_1.** By `abc-leavitt-path-k-theory-exact-sequence` for
  the rose with `d` petals:
  `K_1(L_F(1,d)) ≅ coker(K_1(F) --(1-d)--> K_1(F)) ⊕ ker(K_0(F) --(1-d)--> K_0(F))
  = F^x/(F^x)^(d-1) ⊕ 0`, which is finite. `L_F(1,d)` is simple, so every corner
  `p M_m(L_F(1,d)) p` with `p ≠ 0` is a full corner. `K_1` is Morita invariant,
  so these corners have the same finite `K_1`.
- **K_1(F[Q]) is not finite.** `F[Q]` is commutative, so `det: K_1(F[Q]) ->
  F[Q]^x` is split onto. Its target contains the group elements, a copy of `Q`.
  So no corner is isomorphic to `F[Q]`.

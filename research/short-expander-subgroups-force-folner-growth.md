## Definitions

- `H` is a group with a finite symmetric generating set `S`, and `|·|_S` is word
  length. `F_(H,S)(n)` is the least size of a finite nonempty `Ω ⊂ H` with
  `|Ω \ xΩ| <= |Ω|/n` for all `x in S`, as in `folner-separators-of-boone-higman`.
- For a finite group `Γ` with a symmetric generating set `T`, the **Cheeger
  constant** is
  `h(Γ,T) = min { Σ_(y in T) |A \ yA| / |A| : A ⊂ Γ, 0 < |A| <= |Γ|/2 }`.
- For `δ > 0` the **short-expander profile** `X^δ_(H,S)(L)` is the largest `|Γ|`
  over finite subgroups `Γ ≤ H` that have a symmetric generating set `T` with
  `|T| <= L`, `|y|_S <= L` for all `y in T`, and `h(Γ,T) >= δ`. The trivial
  group (with `T` empty) always counts, so `X^δ_(H,S)(L) >= 1`.
- The **finite-subgroup profile** `FS_(H,S)(L)` is the largest order of a finite
  subgroup of `H` generated by elements of `S`-length at most `L`, or `∞` if
  these orders are unbounded. Clearly `X^δ_(H,S)(L) <= FS_(H,S)(L)`.

## Statement

1. **Coset-averaging lemma.** Let `H = <S>` be amenable, `Γ ≤ H` finite with a
   symmetric generating set `T`, `|y|_S <= L` for `y in T`, and
   `h(Γ,T) >= δ > 0`. Then `F_(H,S)(n) > |Γ|/2` for every `n >= 2|T|L/δ`.
2. **Profile form.** Consequently `F_(H,S)(⌈2L^2/δ⌉) > X^δ_(H,S)(L)/2` for all
   `L >= 1`.
3. **Monotonicity.** If `K = <R>` is a finitely generated subgroup of `H` and
   `c >= 1` bounds `|r|_S` for `r in R`, then `X^δ_(K,R)(L) <= X^δ_(H,S)(cL)`
   and `FS_(K,R)(L) <= FS_(H,S)(cL)`. So the `≼`-classes of both profiles are
   invariants of finitely generated groups that can only grow under embeddings.
4. **Transfer to E.** Let `U` be non-decreasing and recursive, and suppose
   `X^δ_(H,S) ⋠ U'` where `U'(L) = L · U(L^3)`. Then `F_H ⋠ U`.

## Reading

- Item 4 gives a sufficient condition for the open statement
  `fp-simple-amenable-subgroups-beat-every-recursive-folner-bound` (E): it is
  enough to find, for every recursive `U`, an amenable subgroup of a finitely
  presented simple group whose short-expander profile beats `U`. This is the
  prerequisite `fp-simple-amenable-subgroups-have-unbounded-expander-profile`,
  and the route `fp-simple-folner-growth-via-short-expanders` records the
  reduction.
- The condition is not necessary. The towers `Z wr ... wr Z` are torsion-free,
  so their profiles are identically `1`, yet their Følner functions pass every
  `exp_k`. The expander route is one mechanism among others, and it can fail
  while E holds.
- The profile is only as large as `FS`. So a host whose finitely generated
  subgroups all have `FS ≼ R` for one recursive `R` cannot carry this mechanism
  past `R`. `higman-thompson-finite-subgroup-profile-is-recursive` shows every
  Higman--Thompson group `V_d` is such a host.

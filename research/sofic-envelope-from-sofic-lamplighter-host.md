This is a reduction. It is steps 1, 2, 3 and 5 of `sofic-groups-simple-kazhdan-linear-sofic-envelope-proof`, with its
step 4 (linear soficity) replaced by the open claim `sofic-lamplighter-host-elementary-groups-are-sofic`. By
`column-model-kazhdan-cut-downs-certify-only-lef`, that claim cannot be proved through column models when `Γ` is not
LEF.

Let `Γ` be finitely generated and sofic.

1. **Overgroup.** `Δ = C(Γ)` is finitely generated, infinite and sofic, and `δ_0 : Γ → Δ` is an injective homomorphism
   with `δ_0(Γ) ≤ [Δ,Δ]` (`groups-embed-in-derived-subgroup-of-half-line-overgroup`, items 1, 3 and 4).
2. **Host.** `L = Z/2 ≀ Δ = (⊕_Δ Z/2) ⋊ Δ` acts on `Z = 2^Δ`, and `R = LC(Z,F_2) ⋊ L`. The following is Lemma 1 of
   `research/artifacts/sk-measured-subshift-lamplighter-rank-envelopes-2026-09-13.md` §2, restated.
   - *Minimal.* `⊕_Δ Z/2 ≤ L` acts by all finite modifications, so every orbit is dense.
   - *Topologically free.* Let `ℓ = λδ ≠ e` with `λ ∈ ⊕_Δ Z/2` and `δ ∈ Δ`, so `ℓx = λ + δx`.
     - If `δ = e`, then `λ ≠ 0` and `ℓ` has no fixed point.
     - If `δ ≠ e`, take a cylinder `[p]` on a finite window `W`. Since `Δ` is infinite, there is `h ∉ W ∪ δW ∪ supp λ`.
       Then `h ≠ δ^(−1)h` and both lie outside `W`, so some `x ∈ [p]` has `x(h) ≠ x(δ^(−1)h)`.
     - For this `x`, `(ℓx)(h) = λ(h) + x(δ^(−1)h) = x(δ^(−1)h) ≠ x(h)`. So `Fix(ℓ)` contains no cylinder, and has empty
       interior.
   - *Finitely generated.* `R` is generated by `u_s^(±1)` for `s` in a finite generating set of `Δ`, `u_a`, and
     `1_{x(e)=1}`. Conjugating the last by the `u_δ` gives every coordinate indicator, and these generate `LC(Z,F_2)`
     as a ring.
3. **Group.** Put `G = EL_3(R)`.
   - It is simple with trivial centre, by `binary-el-simple-iff-minimal-topologically-free` and step 2.
   - It has property (T), by `elementary-groups-over-fg-rings-have-property-t`, since `R` is finitely generated.
   - It is finitely generated, by the `e_ij(r)` with `r` among the ring generators and `1`. This follows from
     `e_ij(r)e_ij(s) = e_ij(r+s)` and `[e_ij(r), e_jk(s)] = e_ik(rs)` for distinct `i, j, k`.
   - It is infinite: `LC(Z,F_2)` is infinite because `Δ` is, and `r ↦ e_12(r)` is injective.
4. **Soficity.** `G` is sofic by `sofic-lamplighter-host-elementary-groups-are-sofic` at `Δ = C(Γ)`.
5. **Embedding.**
   - `Δ ≤ L` gives `[Δ,Δ] ≤ [L,L]`.
   - `ℓ ↦ diag(u_ℓ,1,1)` is an injective homomorphism `L → GL_3(R)` whose restriction to `[L,L]` lands in `EL_3(R)`
     (`perfect-groups-embed-in-crossed-product-elementary-groups`, items 1 and 3, with acting group `L` on the compact
     totally disconnected space `Z`).
   - Composing with `δ_0` embeds `Γ` in `G`.

So `Γ` is a subgroup of the infinite simple Kazhdan sofic group `G`. ∎

distinct_from:
  kl-implies-universal-schur-injectivity: that asks whether the conjecture forces Schur injectivity over every coefficient group, and is open; this proves that the conjecture forces Schur injectivity over torus amalgams of acyclic groups, and that nothing more is needed for the converse.
  acyclic-torus-amalgam-adjunctions-kill-no-schur-class: that is the open Schur statement; this is the established equivalence between it and the conjecture.
  kl-failure-yields-a-schur-kill: that turns a violation into a killed torus class over an arbitrary torus amalgam; this places the amalgam over an acyclic core, where the killed class is the whole multiplier, and adds the converse.

Let `Y` be a group with `H_n(Y; Z) = 0` for all `n >= 1`, let `1 != a in Y`,
put `Q = Y *_(<a>) (<a> x <s>)`, and let `w in Y * <t>` have
`deg_t(w) != 0`. Write `Q_w = (Q * <t>)/<<w>>` and
`K_2(Q, w) = ker(H_2(Q) -> H_2(Q_w))`.

1. `H_1(Q) = Z`, generated by `s`. `H_2(Q)` is isomorphic to
   `H_2(<a> x <s>)`, which is `Z` if `a` has infinite order and `Z/n` if `a`
   has order `n`. It is generated by the torus class of `a` and `s`.
2. If `Y -> Y_w` is injective, then `K_2(Q, w) = 0`.
3. If `a` dies in `Y_w`, then `K_2(Q, w) = H_2(Q) != 0`.
4. Consequently `kervaire-laudenbach-nonsingular-conjecture` holds if and only
   if `acyclic-torus-amalgam-adjunctions-kill-no-schur-class` holds.

**What this changes.** The Schur route into the root
(`kl-via-universal-schur-injectivity`) needs Schur injectivity for every
coefficient group. Whether the conjecture implies that is the open
`kl-implies-universal-schur-injectivity`. This theorem shows the route loses
nothing if the premise is narrowed to one family. There the whole multiplier
is a single cyclic torus class, and killing it is the same as killing the
coefficient `a`.

No novelty is claimed. The proof combines the repository's localization and
torus-kill nodes with the acyclic embedding.

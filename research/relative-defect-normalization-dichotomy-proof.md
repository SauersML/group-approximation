Notation as in `relative-defect-normalization-dichotomy`.

**`N_rel(sigma)` is a subgroup.** For `x, y` in it and `s = sigma(gamma)`:

- `[xy, s] = x [y, s] x^-1 . [x, s]`, which lies in `sigma(M)` because `x`
  normalizes `sigma(M)`;
- `[x^-1, s] = x^-1 [x, s]^-1 x`, which lies in `sigma(M)` for the same reason;
- permutations normalizing `sigma(M)` form a group.

**RNORM ==> RDD.**

1. Let `H` be countable sofic with `M` normal Kazhdan and a rigid pair
   `M <= Gamma <= G <= H`. Take an injective `sigma : H -> S_U` with
   `tr(sigma(h)) = 0` for `h != 1`; amplifying a sofic approximation gives one.
2. Let `z in H` with `[z, Gamma] <= M`. Since `M` is normal in `H`, `sigma(z)`
   normalizes `sigma(M)`, and `[sigma(z), sigma(gamma)] = sigma([z, gamma])`
   lies in `sigma(M)`. So `sigma(z) in N_rel(sigma|_G)`.
3. By `RNORM`, `sigma(g) sigma(z) sigma(g)^-1 in N_rel(sigma|_G)`, so
   `sigma([g z g^-1, gamma]) in sigma(M)`.
4. `sigma` is injective, so `sigma^-1(sigma(M)) = M` and
   `[g z g^-1, gamma] in M`.

**not RNORM ==> not RDD.**

1. Let `sigma : G -> S_U` be a homomorphism and `x in N_rel(sigma)`.
   Normalization fails exactly when some `g in G` has
   `sigma(g) x sigma(g)^-1 not in N_rel(sigma)`: if the inclusion held for
   every `g`, applying it to `g^-1` would give equality.
2. Put `H' = <sigma(G), x> <= S_U`, `M' = sigma(M)`, `Gamma' = sigma(Gamma)`
   and `G' = sigma(G)`.
   - `H'` is countable because Kazhdan groups are finitely generated. It is
     sofic as a countable subgroup of `S_U`.
   - `Gamma'`, `G'` and `M'` are Kazhdan as quotients of Kazhdan groups.
   - `Gamma'` is infranormal in `G'`: `sigma` maps the compression semigroup
     of `Gamma` into that of `Gamma'`, and its image generates `G'`.
   - `M'` is normal in `H'`: `sigma(G)` normalizes `sigma(M)` because `M` is
     normal in `G`, and `x` normalizes it by definition.
   - `M' <= Gamma'`, and `[x, Gamma'] <= M'`.
3. `sigma(g) x sigma(g)^-1` normalizes `sigma(M)`. So its failure to lie in
   `N_rel(sigma)` means `[sigma(g) x sigma(g)^-1, sigma(gamma)] not in M'` for
   some `gamma`. That is a nontrivial defect modulo `M'` in the sofic group
   `H'`, with `z' = x`, `g' = sigma(g)` and `gamma' = sigma(gamma)`. So `RDD`
   fails. ∎

Notation. `P, L` are the points and lines of a projective plane of order `q`, with
`n = q^2+q+1`. A *triangle presentation* (CMSZ) is a bijection `λ : P → L` and a set
`T ⊂ P^3` such that:
- (i) `T` is invariant under cyclic rotation;
- (ii) for all `x, y` there is `z` with `(x,y,z) ∈ T` iff `y ∈ λ(x)`, and then `z` is unique.

The group is `Γ_T = ⟨a_x, x ∈ P | a_x a_y a_z = 1, (x,y,z) ∈ T⟩`. We write `A_x = a_x^{-1}`.
Every script below is in `experiments/a2-left-orderability-2026-09-17/` and runs
single-threaded in seconds to minutes. The time for each run is printed in the `.out` files.

## Imported facts

- **(I1)** Cartwright–Mantero–Steger–Zappa, *Groups acting simply and transitively on the
  vertices of a building of type Ã2*, I and II, Geom. Dedicata 47 (1993) 143–166 and
  167–226.
  - For every triangle presentation, `Γ_T` acts simply transitively on the vertices of a
    thick locally finite Ã2 building `Δ_T`.
  - The 1-skeleton of `Δ_T` is the Cayley graph of `Γ_T` with respect to
    `{a_x^{±1}}`, and `Γ_T` acts by left multiplication.
  - Part II lists all presentations for `q = 2, 3` up to natural equivalence.
- **(I2)** Cartwright–Młotkowski–Steger, *Property (T) and Ã2 groups*, Ann. Inst.
  Fourier 44 (1994) 213–248: every such `Γ_T` has property (T).
  - Alternative: the Ballmann–Świątkowski / Żuk local spectral criterion. Links are
    incidence graphs of projective planes, whose nontrivial eigenvalue ratio is
    `√q/(q+1) < 1/2`, and `Γ_T` is a cocompact lattice.
- **(I3)** Only used for the "exotic" reading, not for the theorem. The counts come from
  Herron, arXiv:2502.09536:
  - `q = 2`: 8 classes (4 in `PGL(3,F_2((t)))`, 4 in `PGL(3,Q_2)`);
  - `q = 3`: 89 classes (16 in `PGL(3,F_3((t)))`, 8 in `PGL(3,Q_3)`, and 65 that embed in
    no `PGL(3,K)`).
  - Non-linearity of the exotic ones is Bader–Caprace–Lécureux, arXiv:1608.06265,
    Theorem `nonlinear`, quoted in `exotic-a2-lattices-satisfy-boone-higman`.

## Step 1. The type kernel is an infinite torsion-free Kazhdan group

**The type map.** Relators have exponent sum 3, so `τ : Γ_T → Z/3`, `a_x ↦ 1`, is a
homomorphism. Put `Γ_0 = ker τ`. It has index 3 (`τ(a_0) = 1`), so it is infinite and has
(T) by (I2).

**Distinct simplex vertices have distinct types.** By (I1), adjacent vertices `g, g a_x^{±1}`
satisfy `τ(g a_x^{±1}) = τ(g) ± 1 ≠ τ(g)`. So the (pairwise adjacent) vertices of any
simplex of `Δ_T` have pairwise distinct `τ`.

**Torsion-freeness.** Let `F ≤ Γ_0` be finite.
- `Δ_T` is a complete CAT(0) space, so `F` fixes a point `p` (Bruhat–Tits fixed point
  theorem).
- `F` preserves the unique simplex `σ` containing `p` in its relative interior, so it
  permutes the vertices of `σ`.
- `τ(hg) = τ(h) + τ(g) = τ(g)` for `h ∈ Γ_0`, and the vertices of `σ` have distinct types.
  So `F` fixes every vertex of `σ`.
- Vertex stabilizers are trivial (simple transitivity), so `F = 1`.

**Schreier generators.** With transversal `{1, a_0, a_0^{-1}}`, `Γ_0` is generated by
`a_x a_0^{-1}`, `a_0 a_x a_0` and `a_0^{-1} a_x`, over `x ∈ P`. Each has word length at
most 3.

## Step 2. A confluent rewriting system

`a2group.py` builds these rules for any `T`, with `p = p(y,z)` the unique point with
`y, z ∈ λ(p)`:

| Rule | Rewrite | Condition |
|---|---|---|
| R0 | `a_x A_x → 1`, `A_x a_x → 1` | none |
| R1 | `a_x a_y → A_z` | `(x,y,z) ∈ T` |
| R2 | `A_y A_x → a_z` | `(x,y,z) ∈ T` |
| R3 | `A_y a_z → a_{z'} A_{y'}` | `y ≠ z`, `(z',p,y) ∈ T`, `(p,z,y') ∈ T` |

**Validity.**
- R1 and R2 are the relators, rotated.
- For R3, `a_{z'} a_p a_y = 1` and `a_p a_z a_{y'} = 1` give
  `A_y = a_{z'} a_p` and `a_z = A_p A_{y'}`. So `A_y a_z = a_{z'} A_{y'}`.

**Generated congruence.** The rules generate every relator, since
`a_x a_y a_z → A_z a_z → 1`.

**Termination.** R0–R2 shorten words. R3 keeps the length and strictly decreases the
number of (negative, positive) letter pairs out of order.

**Local confluence.** `check_confluence()` resolves every overlap of two left-hand sides:
these are words of length 3, and all left-hand sides have length 2.

**Unique normal forms.** By Newman's lemma, every element has a unique normal form. A normal
form is a positive word followed by a negative word, and the empty word is the only normal
form of `1`.

**Check.** `validate_q3.py` confirms, for all 133 `q=3` presentations
(`validate_q3.out`, "ALL OK"):
- confluence (2210 critical pairs);
- the relators reduce to 1;
- sphere sizes `1, 26, 390, 4914`, the vertex counts of spheres in an Ã2 building with
  `q = 3` (`N(m,n) = 13·9^{m-1}·12·9^{n-1}` summed over `m+n = r`).

In addition, `gamma0_sat.py` asserts `check_confluence()` for every presentation, `q = 2`
included, before it builds the instance.

## Step 3. Every presentation is covered

- **One plane per order.** Projective planes of order 2 and 3 are unique (Desarguesian), so
  we may take `P = L =` the standard `PG(2,q)`.
- **Relabelling.** A collineation `g` sends `(λ, T)` to a triangle presentation
  `(gλg^{-1}, gT)` with `Γ_{gT} ≅ Γ_T` (relabel the generators).
- **Normalizing `λ(0)`.** `PGL(3,q)` is transitive on flags and on antiflags. So every
  `PGL(3,q)`-orbit contains a presentation with `λ(0) = L_flag` or `λ(0) = L_anti`, the
  two fixed lines through and missing point 0.
- **Encoding.** `enumerate_pg2.py` encodes conditions (i)–(ii) exactly:
  - `λ` is a bijection;
  - `arc(x,y) ⇔ y ∈ λ(x)`;
  - each arc lies in exactly one cyclic class `{(x,y,z)}`;
  - non-arcs lie in none.
- **Orbit loop.** The script repeatedly takes a model, records it, and blocks every
  `PGL(3,q)`-image obeying the breaking. Each blocking clause kills exactly that set of
  classes and its supersets. A superset of a valid `T` is not valid (uniqueness of `z`).
  So each new model is a new orbit.
  - It finds 11 orbits for `q = 2` (and prints COMPLETE, `enumerate_q2all.out`).
  - It finds 133 orbits for `q = 3` (`enumerate_q3.out`).
- **Completeness certificate.** `complete_pg2.py` rebuilds the same CNF, blocks all listed
  orbits, and proves UNSAT on each cube `λ(0) = L_0 ∈ {L_flag, L_anti}, λ(1) = L_1`.
  - These cubes cover every assignment allowed by the breaking clause. Cubes with
    `L_1 = L_0` are excluded by injectivity.
  - Outputs: `complete_q2.out`, `complete_q3.out` and `complete_q3.progress`, one UNSAT line
    per cube.
  - Negative control: deleting one `q = 2` orbit makes the certifier return a new model at
    once.
- **Calibration against CMSZ.** `classify_q3.py` merges orbits under reversal
  `T ↦ {(z,y,x)}` (`Γ_{T^rev} ≅ Γ_T` via `a_x ↦ a_x^{-1}`), after transporting the reversed
  plane structure back to the standard plane.
  - `q = 2`: 11 orbits → 8 classes (`classify_q2.out`).
  - `q = 3`: 133 orbits → 89 classes, 45 of them self-reversal (`classify_q3.out`).
  - These are exactly the CMSZ / Herron totals 8 and 89. This is a consistency check only;
    completeness rests on the certificate.

## Step 4. SAT certificates: no nontrivial action of `Γ_0` on `R`

**The preorder from an action.** Suppose `φ : Γ_0 → Homeo_+(R)` is nontrivial.
- Some Schreier generator `s` acts nontrivially. Pick `x_0` with `s x_0 ≠ x_0`.
- Put `P = {g : g x_0 > x_0}`, `H = {g : g x_0 = x_0}`, and `P^{-1} = {g : g x_0 < x_0}`.
  These three sets partition `Γ_0`, and `H = H^{-1}` contains `1` but not `s`.
- The following inclusions hold:
  - `PP ⊂ P`, since `g h x_0 > g x_0 > x_0`;
  - `HP ⊂ P` and `PH ⊂ P`;
  - `HH ⊂ H`.

**The instance.** `gamma0_sat.py pre R hmax` creates, for every nontrivial type-0 normal form
`w` of length at most `R`, variables `P_w`, `P_{w^{-1}}` and `H_w = H_{w^{-1}}`, with
"exactly one of the three". For every type-0 pair `g ∈ B(R)` and `h` with `|h| ≤ hmax` it
adds:
- if `gh` is a variable: `P_g ∧ P_h ⇒ P_{gh}`, `H_g ∧ P_h ⇒ P_{gh}`,
  `P_g ∧ H_h ⇒ P_{gh}` and `H_g ∧ H_h ⇒ H_{gh}`;
- if `gh = 1`: `¬(P_g ∧ P_h)`, `¬(H_g ∧ P_h)` and `¬(P_g ∧ H_h)`.

It also adds the clause "some type-0 `w` with `|w| ≤ 3` has `¬H_w`". This clause contains
every nontrivial Schreier generator, since rewriting never lengthens words.

**Soundness.** Setting each variable to the truth value of the corresponding membership
(`P_w` iff `φ(w) x_0 > x_0`, and so on) satisfies every clause.
- Products and inverses are computed by valid rules (Step 2).
- A nonempty normal form is `≠ 1` (Step 2). So `w` and `w^{-1}` genuinely lie in exactly one
  of `P`, `H`, `P^{-1}`, and the "`gh = 1`" branch is correct.
- Only a subset of all true constraints is imposed.

So **UNSAT ⇒ every homomorphism `Γ_0 → Homeo_+(R)` is trivial.**

**Results.**
- `gamma0_q3_pre.out`: all 133 `q = 3` orbits, `R = 3`, `hmax = 2`, 2262 type-0 elements,
  about 36800 products each. All `SAT=False`.
- `gamma0_q3_pre_glucose.out`: the same instances with Glucose 4 instead of CaDiCaL. All
  `SAT=False`.
- `gamma0_q2all_pre.out`: all 11 `q = 2` orbits, `R = 3`, `hmax = 3`. All `SAT=False`.
- Independent positive-cone encoding (`mode lo`, `P_{w^{-1}} = ¬P_w`, which detects only
  left orders):
  - `gamma0_q3_lo.out` and `gamma0_q3_lo_glucose.out`: all 133 are UNSAT already at
    `R = hmax = 2` (156 elements `a_x A_y`);
  - `gamma0_q2all_lo.out`: all 11 are UNSAT at `R = hmax = 3`.

## Step 5. Conclusion

By Steps 3 and 4, for every triangle presentation over `PG(2,2)` or `PG(2,3)`, every
homomorphism `Γ_0 → Homeo_+(R)` is trivial. `Γ_0` is an infinite torsion-free Kazhdan group
(Step 1). It is countable, so it is not left-orderable.

Any `ψ : Γ_T → Homeo_+(R)` kills `Γ_0`, so it factors through `Z/3`. `Homeo_+(R)` is
torsion-free, so `ψ` is trivial. ∎

Direct proof, using one textbook theorem.

**Import (generic freeness).** The Stacks Project, Lemma 10.118.1 (Tag 051R):
"Let `R -> S` be a ring map. Let `M` be an `S`-module. Assume `R` is Noetherian,
`R` is a domain, `R -> S` is of finite type, and `M` is a finite type `S`-module.
Then there exists a nonzero `f in R` such that `M_f` is a free `R_f`-module."
The wording is from the search-engine rendering of the Stacks page on 2026-09-17;
the page itself did not load. The same statement is Eisenbud, *Commutative Algebra
with a View Toward Algebraic Geometry*, Theorem 14.4, which was not re-read here.

**Setup.** Let `G` be generated by `s_1, ..., s_k`, and put `M = G'` (abelian) and
`Q = G/M` (finitely generated abelian). Conjugation makes `M` a module over the
commutative ring `B = Z[Q]`, a finitely generated `Z`-algebra. `M` is the normal
closure of the finitely many commutators `[s_i, s_j]`, because the quotient by that
normal closure is abelian. So `M` is the `B`-submodule generated by them, and it is a
finitely generated `B`-module.

**Reduction into M.**
- Let `x` have infinite order and let `y_q^q = x` for `q` in an infinite set `Π` of
  primes.
- Write `Q = Z^s ⊕ T` with `T` finite of exponent `ε`.
- The `Z^s`-coordinate of `x̄` is `q` times that of `ȳ_q` for every `q in Π`, so it
  is 0. Likewise each `ȳ_q` has `Z^s`-coordinate 0, since `q` times it is 0.
- So `x̄, ȳ_q in T`, and `z := x^ε` and `w_q := y_q^ε` lie in `M`.
- `w_q^q = (y_q^q)^ε = z`, and `z` has infinite order.

In additive notation, `z = q w_q in q M` for every `q in Π`.

**Generic freeness.** Apply the import to `Z -> B = Z[Q]` and `M`. It gives `0 != N` with
`M[1/N] = M ⊗ Z[1/N]` free over `Z[1/N]`. Let `z'` be the image of `z`.
- For `q in Π` with `q ∤ N` (infinitely many `q`), `z' in q F`, where `F = M[1/N]`.
- In a basis of `F`, every coordinate of `z'` is an element `a / N^t` of `Z[1/N]`
  divisible in `Z[1/N]` by infinitely many primes not dividing `N`. So the integer
  `a` has infinitely many prime divisors, and `a = 0`.
- Hence `z' = 0`, i.e. `N^t z = 0` for some `t`, contradicting the infinite order of
  `z`. ∎

Standard input (not re-read): the base group of an HNN extension embeds in it
(Higman–Neumann–Neumann).

1. The map `pi: G -> Z`, `t -> 1`, `H -> 0`, respects the relations, so it is a homomorphism.
2. Put `s_0 = t`, `s_1 = a t`, `a_0 = 1`, `a_1 = a`. From `t h = phi(h) t`, a positive word
   `w = s_{e_1} ... s_{e_n}` equals `g_w t^n` with
   `g_w = a_{e_1} phi(a_{e_2}) phi^2(a_{e_3}) ... phi^{n-1}(a_{e_n}) in H`.
3. Words of different lengths differ under `pi`. If `w, w'` have length `n` and `w = w'`, then
   `g_w = g_{w'}` in `G`, hence in `H` by the embedding.
4. Write `g_w = a_{e_1} phi(X)` and `g_{w'} = a_{e'_1} phi(X')` with `X, X' in H`. If
   `e_1 = 1` and `e'_1 = 0`, then `a = phi(X' X^{-1}) in phi(H)`, a contradiction; the reverse case
   gives `a^{-1} in phi(H)`, also a contradiction. So `e_1 = e'_1`, then `phi(X) = phi(X')`, and
   `X = X'` by injectivity. Induction on `n` gives `w` and `w'` equal as words.
5. So `s_0, s_1` generate a free semigroup. If `H` is generated by a finite set containing `a`,
   then `G` is generated by that set and `t`; the `2^n` distinct words of length `n` have word
   length at most `2n`, so the ball of radius `2n` has at least `2^n` elements.

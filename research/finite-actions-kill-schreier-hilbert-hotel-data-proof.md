Notation: `Gamma` is generated by a finite symmetric set `S`, `alpha in Aut(Gamma)`,
`A = alpha(Gamma_0) <= Gamma_0`.

## Step 1: periodicity lemma (a)

Let `F` be a finite set. Since `Gamma` is generated by `S`, a homomorphism
`rho : Gamma -> Sym(F)` is determined by `rho|_S`, so `Hom(Gamma, Sym(F))` is finite.

- The map `P(rho) = rho o alpha` sends `Hom(Gamma, Sym(F))` to itself, and `rho -> rho o alpha^(-1)`
  is its inverse. So `P` is a permutation of a finite set, and `P^k = id` for some `k >= 1`.
- Hence `rho o alpha^k = rho`, and `rho(alpha^k(Gamma_0)) = rho(Gamma_0)`.
- Applying `alpha^j` to `A <= Gamma_0` gives `alpha^(j+1)(Gamma_0) <= alpha^j(Gamma_0)` for all
  `j >= 0`. So `alpha^k(Gamma_0) <= A <= Gamma_0`.
- Taking images, `rho(Gamma_0) = rho(alpha^k(Gamma_0)) <= rho(A) <= rho(Gamma_0)`.

So `rho(A) = rho(Gamma_0)`, and in particular the `A`-orbits and the `Gamma_0`-orbits on `F`
coincide. No finite generation of `Gamma_0` is used here.

## Step 2: the ball copy

Let `X`, `x_0` and `H = Stab(x_0)` be as in (b), and let finite-index `H_n -> H` in the Chabauty
topology. Put `F_n = Gamma/H_n` with base point `f_n = H_n`, and write `|gamma|` for word length in `S`.

For `R >= 0` let `B_R` be the set of points `w x_0` with `|w| <= R`. Choose, for each `x in B_R`, one
element `gamma_x` of length `<= R` with `x = gamma_x x_0`. Put `iota_n(x) = gamma_x f_n`.

Fix `R`. Only finitely many elements have length `<= 2R + 1`, so for all large `n` and all such
`delta`, `delta in H_n` iff `delta in H`. For such `n`:

- *Injective.* If `x != x'` in `B_R`, then `gamma_(x')^(-1) gamma_x notin H`, so `notin H_n`, so
  `iota_n(x) != iota_n(x')`.
- *Equivariant.* If `x, s x in B_R` with `s in S`, then `gamma_(s x)^(-1) s gamma_x in H`, so it is
  in `H_n`, and `iota_n(s x) = s iota_n(x)`.
- *Well defined on words.* Let `x in B_R` and let `w = s_1 ... s_m` be a word such that all the partial
  products `s_j ... s_m x` lie in `B_R`. Iterating the previous item gives `iota_n(w x) = w iota_n(x)`.
  Also `iota_n(x_0) = f_n`, since `gamma_(x_0)` fixes `x_0`, so it lies in `H` and hence in `H_n`.

## Step 3: local transfer (b)

Let `Gamma_0` be generated by the finite set `T`, so `A` is generated by `alpha(T)`. Write each
`u in alpha(T) u alpha(T)^(-1)` as a word in `S` of length `<= L`. Let `y = g x_0` with
`g in Gamma_0`, and assume that `O = A y` is finite.

Choose `R` with `O u {x_0} subset B_R` and `|g| <= R`, put `R' = R + L`, and take `n` large for `R'`
as in Step 2 (so `iota_n` is defined, injective and equivariant on `B_(R')`).

- *The copy of `O` is closed.* Let `z in O` and `u in alpha(T)^(+-1)`. Then `u z in O subset B_R`,
  and every partial product of the chosen word for `u`, applied to `z`, lies in `B_(R')`. By Step 2,
  `iota_n(u z) = u iota_n(z)`. So `iota_n(O)` is invariant under `alpha(T)^(+-1)`, hence under `A`.
- *It is the orbit of the image of `y`.* The path of the word for `g` from `x_0` stays in `B_R`, so
  `iota_n(y) = g f_n`. Every point of `O` is reached from `y` by a word in `alpha(T)^(+-1)` whose
  steps stay in `O`, so `iota_n(O) = A (g f_n)`.
- *Collapse.* By Step 1 applied to the finite action on `F_n`, `A (g f_n) = Gamma_0 (g f_n)`, and this
  `Gamma_0`-orbit contains `g^(-1) g f_n = f_n`, since `g in Gamma_0`. So `f_n in iota_n(O)`.
- *Pull back.* `f_n = iota_n(x_0)` and `x_0 in B_R`. By injectivity of `iota_n` on `B_R`, `x_0 in O`.

So `x_0 = a y` for some `a in A`, that is, `y = a^(-1) x_0 in A x_0`, which proves (b).

## Step 4: (HH) is refuted (c)

Suppose (HH) data exist. Then `Gamma` is finitely generated, `Gamma_0` is finitely generated with
`A <= Gamma_0`, and `H` is a Chabauty limit of finite-index subgroups. Moreover `g in Gamma_0`,
`y = g x_0` has a finite `A`-orbit (because `A meet gHg^(-1)` has finite index in `A` and is the
stabilizer of `y` in `A`), and `g notin A H`, that is `y notin A x_0`. This contradicts Step 3.

The hypotheses `alpha(H) = H` and (IS) were never used. If `H` is only assumed profinitely closed,
enumerate `Gamma \ H = {gamma_1, gamma_2, ...}` (`Gamma` is countable), choose finite-index
`L_i >= H` with `gamma_i notin L_i`, and put `H_n = L_1 meet ... meet L_n`. These have finite index,
contain `H` and miss `gamma_1, ..., gamma_n`, so `H_n -> H`. So that variant dies too.

## Remark: relation to (N2)

Step 9 of `schreier-hilbert-hotel-ring-reduction-proof` shows that the extended action of
`Gamma x|_alpha Z` is not approximable. Step 1 above shows more: the `Gamma`-action alone cannot be
approximable once the Hilbert-hotel configuration is present, because every finite action of
`Gamma` carries its own hidden power `alpha^k` that acts on it like the identity.

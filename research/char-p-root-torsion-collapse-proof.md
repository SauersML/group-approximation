# Diagonalize the torsion roots, generate the ideal, apply the unit trick

**1. Root images are finite.**  In characteristic `p`,
`e_ij(f)^p = e_ij(pf) = I`, so `U_ij = e_ij(R)` is elementary abelian
`p`.  A commuting family of unitaries of order dividing `p` is
simultaneously diagonalizable with `p`-th-root-of-unity eigenvalues;
an abelian subgroup of `μ_p^n` (diagonalized) has order ≤ `p^n`.  So
`ρ(U_ij)` is finite and `A_ij := ker(ρ|_{U_ij})` is an additive
subgroup of finite index `≤ p^n` in `(R, +)`.

**2. The kernel contains a relative elementary subgroup for a
finite-codimension ideal.**  `A := ⋂_{i≠j} A_ij` has finite index.
For `a ∈ A`, `f ∈ R`, `i ≠ j`, pick `k ∉ {i,j}` (`r ≥ 3`):
`e_ij(af) = [e_ik(a), e_kj(f)]`, and a commutator of a kernel element
with anything lies in the (normal) kernel.  So `e_ij(J) ⊆ ker ρ` for
every `i ≠ j`, where `J = A·R` is the ideal generated by `A`.
Finiteness of `R/J`: `A` contains a finite-codimension
`𝔽_q`-subspace, so for all but finitely many monomials `μ` there is
`a_μ = μ + f_μ ∈ A` with `f_μ` in one fixed finite-dimensional space
`F`; then `μ ≡ −f_μ (mod J)`, so `R/J` is spanned by `F` plus
finitely many bad monomials — finite.  Hence
`E_r(J) := ⟨⟨ e_ij(J) ⟩⟩_{E} ⊆ ker ρ`.

**3. Structure of the quotient and the collapse.**  `Ē = E/E_r(J)`
surjects onto the finite group `EL_r(R/J)` with kernel
`K(R,J) = (E ∩ SL_r(R,J))/E_r(J)`, which is CENTRAL in `Ē` for
`r ≥ 3` — verified citation (2026-08-18 K-theory pass):
Hazrat–Vavilov–Zhang arXiv:1510.07143 Thm 11
(`[E(n,A), GL(n,A,I)] = E(n,A,I)`, `n ≥ 3`, module-finite `A`, no
stable range needed); centrality is claimed only in the
`E`-quotient, never in `GL/E_r(J)` (which would need stable-range
input) — and this proof conjugates only by elementary matrices, so
the `E`-ambient form suffices.  Moreover `K(R,J) ≅
coker(K₂(R) → K₂(R/J))` unconditionally (Weibel III Thm 5.7.1 with
`SK₁(R) = 0`, Suslin 1977 Cor 7.11), and this group is genuinely
NONZERO for the KT rings (see
`twisted-tower-central-character-criterion` — `(ℤ/2)²` at least via
the `𝔽_2[C_2×C_2]` quotient), so the modulo clause below is not
removable.  In
`EL_r(R/J)`: `R/J` is a finite ring, so `x̄_i` has finite
multiplicative order `m_i` and `x̄_i^{-1} = x̄_i^{m_i−1}` lies in the
image of the polynomial subring — hence the polynomial subring
surjects onto `R/J`, `π̄(Γ) = π̄(E)` (the
`compressor-coset-two-point-exact` computation, run for the quotient
`R/J` in place of `(ℤ/M)`-coefficients), and E-normality gives
`π̄(Λ) = π̄(t)π̄(Γ)π̄(t)^{-1} = π̄(Γ)`.  Lifting through the central
kernel: `ρ(E) = ρ(Γ)·Z = ρ(Λ)·Z` with `Z = ρ(K(R,J))` central in
`ρ(E)`.  ∎

**4. Where the modulo clause bites (recorded so nobody overclaims).**
For the (CCR)-style commutant conclusion one needs `x ∈ ρ(Λ)'` to
commute with `ρ(γ)`; the collapse gives `ρ(γ) = ρ(λ')·z` with
`z ∈ Z`, and `Z` central in `ρ(E)` does NOT make `z` commute with an
arbitrary `x ∈ ρ(Λ)'`.  So the clean consequence needs the central
piece to vanish or act trivially on the relevant commutant — i.e.
the relative `SK₁(R,J)` sub-item of the claim node.  If `SK₁(R,J)`
vanishes for all finite-codimension `J` arising this way, the
collapse is unconditional and every genuine-coordinate ultraproduct
of `G`-representations is a `ccr-for-coordinate-collapsing-models`
instance.

**5. Scope.**  Everything uses only: characteristic `p` (root
torsion), `r ≥ 3` (Steinberg commutators, Mennicke centrality), and
finite generation of `R` (ideal finiteness).  The `SL_d(ℤ)` part of
`G` never obstructs — the argument runs entirely inside `E` and its
`ρ`-image, and the compressor enters only through E-normality.  No
property (T), no trace condition, no ultraproduct.

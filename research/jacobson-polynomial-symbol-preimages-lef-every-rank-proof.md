Notation as in the target. The only imported text is the soficity convention quoted in
`elek-szabo-amalgams-over-amenable-subgroups-are-sofic` ("a not necessarily finitely generated group [is] sofic if all
of its finitely generated subgroups are sofic. Amenable and residually finite groups are sofic."). Everything else is
elementary linear algebra.

## Step 0. The module and the ideal

- **Faithfulness.** `J` has the basis `S^a T^b` (`a, b >= 0`) and acts faithfully on `F[N]`: for
  `x = sum c_ab S^a T^b != 0`, let `b_0` be minimal with some `c_(a,b_0) != 0`; then `x e_(b_0) = sum_a c_(a,b_0) e_a`
  is nonzero. So `M_m(J)` acts faithfully on `V = F[N]^m`, with basis `e_j ⊗ ε_i`.
- **Matrix units.** `Q e_0 = e_0` and `Q e_k = 0` for `k >= 1`, so `S^a Q T^b` is the matrix unit `e_ab` of
  `End F[N]`. Hence `JQJ` is the ideal of finitely supported (finite-rank, finitely many nonzero entries) operators.
  `J / JQJ = A` with `S -> z`, `T -> z^(-1)`.
- **Kernel.** `ker(π|E_m) = E_m ∩ (1 + M_m(JQJ))`. So every `l in L_m` has the form `1 + f` with `f` finitely
  supported on the basis `e_j ⊗ ε_i`.
- **Transvections lie in `L_m`.** Let `p = (a,i)` and `q = (b,j)` be distinct in `N x {1..m}`, and
  `t_pq = 1 + e_pq`. If `i != j`, then `t_pq = x_ij(S^a Q T^b)`. If `i = j`, pick `k != i` (here `m >= 2` is used) and
  `r = (0,k)`; then `t_pq = [t_pr, t_rq]` with both factors of the first kind. So `SL_fin(V) <= L_m`. For
  `F = F_2`, `GL_N(F_2) = SL_N(F_2)` is generated by transvections, so `L_m = GL_fin(V)`.

## Step 1. The splitting (point 1)

- **Onto.** `F[S] ≅ F[z]` is Euclidean, so `SL_m(F[z]) = E_m(F[z])`. The elements `x_ij(p(S))` lift `x_ij(p(z))`.
  So `π(EL_m(F[S])) = SL_m(F[z])`.
- **Injective.** A nonzero `p(S) = sum c_d S^d` has infinitely many nonzero matrix entries (the entry `(d + k, k)` is
  `c_d` for every `k`), so `F[S] ∩ JQJ = 0`, and `π` is injective on `M_m(F[S])`.
- For `h in H_+`, choose `g in EL_m(F[S])` with `π(g) = π(h)`. Then `h g^(-1) in L_m`. So `H_+ = L_m EL_m(F[S])`,
  with trivial intersection, and `L_m` is normal in `E_m`.

## Step 2. The tail filtration (point 2)

Put `V_(>=k) = span{e_j ⊗ ε_i : j >= k, 1 <= i <= m} = S^k V`. It has finite codimension `mk`, and
`∩_k V_(>=k) = 0`.

- **Polynomial part.** Every `g in GL_m(F[S])` commutes with the diagonal action of `S`, so
  `g V_(>=k) = g S^k V = S^k g V ⊆ V_(>=k)`. The same holds for `g^(-1)`, so `g V_(>=k) = V_(>=k)` for every `k`.
- **Finitary part.** Let `l = 1 + f in L_m`, and let `k(l)` exceed every first index `j` of a basis vector
  `e_j ⊗ ε_i` in the support of `f` (as source or target). Then `f` vanishes on `V_(>=k)` for `k >= k(l)`, so `l` is
  the identity on `V_(>=k)`. The same holds for `l^(-1) = 1 + f'`, which is also finitary, with its own bound.
- **Generators.** Let `Y = <y_1, ..., y_r>`, with `y_s = l_s g_s` by Step 1. Let `k_0` be the maximum of the bounds
  for `l_s` and `l_s^(-1)`. Then every `y_s^(±1)` maps `V_(>=k)` onto itself for `k >= k_0`, and so does `Y`.
- **Finite images.** `Y` acts on the finite set `V / V_(>=k)`, which has `|F|^(mk)` elements. This gives a
  homomorphism `r_k : Y -> GL(V / V_(>=k))` into a finite group.
- **Separation.** Let `1 != y in Y`. By faithfulness there is `v` with `w = (y - 1) v != 0`. The vector `w` is a finite
  combination of basis vectors. Take `k >= k_0` larger than every first index in its support. Then `w ∉ V_(>=k)`, so
  `r_k(y) != 1`.

So `Y` is residually finite.

## Step 3. LEF and soficity (point 3)

- **LEF.** Let `D ⊂ H_+` be finite and `Y = <D>`. By Step 2 there is a finite quotient `Y -> Y_bar` injective on the
  finite set `D ∪ D D`. Its restriction to `D` is injective and multiplicative wherever the product stays in `D`,
  which is the definition of LEF.
- **Sofic.** Every finitely generated subgroup of `H_+` is residually finite, hence sofic, and `H_+` is sofic by the
  quoted convention.
- **Head.** An element `1 != l in L_m` lies in some finitely generated `Y`, and Step 2 gives a finite quotient of `Y`
  that keeps it. For `m >= 3` this applies to `x_13(Q)`.

## Step 4. The other half (point 4)

- **The anti-involution.** On the free algebra `F<S,T>`, let `σ` be the anti-automorphism with `S <-> T`. Then
  `σ(TS - 1) = σ(S) σ(T) - 1 = TS - 1`, so `σ` descends to an anti-involution of `J`. It fixes `Q = 1 - ST`, because
  `σ(ST) = σ(T) σ(S) = ST`. So it preserves `JQJ`, and it induces on `A` the automorphism `z -> z^(-1)`.
- **The twist.** `θ(g) = (σ(g)^t)^(-1)`, with `σ` applied entrywise, is an automorphism of `GL_m(J)`. It satisfies
  `θ(x_ij(r)) = x_ji(-σ(r))`, so `θ(E_m) = E_m` and `θ(L_m) = L_m`.
- **Symbols.** `π θ = θ_A π`, where `θ_A(a) = (a(z^(-1))^t)^(-1)`. `θ_A` maps `SL_m(F[z])` onto `SL_m(F[z^(-1)])`.
  So `θ(H_+) = H_-`, and points 1--3 transfer. ∎

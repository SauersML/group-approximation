Indices are taken in `Z/4`.

## Item 1 (profinite four-cycle lemma)

**Setup.**
- Put `Z_i = cl<h_i>`. It is compact, totally disconnected, abelian and topologically generated by `h_i`, so it is a procyclic profinite group.
- For such a group `Z = cl<h>`, let `P(Z)` be the set of primes `p` for which `Z` has a continuous quotient `Z/p`.
- If `Z ≠ 1`, it has a proper open subgroup, hence a nontrivial finite cyclic continuous quotient. So `P(Z) ≠ ∅`.
- For `p ∈ P(Z)`, the set `Z^p = {z^p : z ∈ Z}` is the image of the continuous map `z ↦ z^p`, so it is compact. It contains the dense subgroup `<h^p>` of `cl<h^p>`, so `Z^p = cl<h^p>`.
- `Z/Z^p` is cyclic, generated by the image of `h`, and has order at most `p`. Since `p ∈ P(Z)` it has order exactly `p`, so `Z^p` is open of index `p`.

**Step 1: positive powers are dense.** Let `K` be a compact group and `x ∈ K`.
- Choose `n_1 < n_2 < …` with `x^(n_j)` convergent and `n_(j+1) − n_j ≥ 2`.
- Then `x^(n_(j+1) − n_j) = x^(−n_j) x^(n_(j+1)) → 1`.
- So `x^(n_(j+1) − n_j − 1) → x^-1`, and every exponent here is at least 1.
- Hence the closure of `{x^n : n ≥ 1}` contains `x^-1` and `1`, so it equals `cl<x>`.

**Step 2: normalization.**
- The relation `h_i h_(i+1) h_i^-1 = h_(i+1)^2` shows that conjugation by `h_i` maps `<h_(i+1)>` into itself, and hence maps `Z_(i+1)` into itself.
- Let `k ∈ Z_i`. By Step 1, `k = lim h_i^(n_j)` with `n_j ≥ 1`.
- For `z ∈ Z_(i+1)`, `k z k^-1 = lim h_i^(n_j) z h_i^(−n_j)`, and each term lies in the closed set `Z_(i+1)`. So `k Z_(i+1) k^-1 ⊆ Z_(i+1)`.
- The same holds for `k^-1 ∈ Z_i`. So `k Z_(i+1) k^-1 = Z_(i+1)` for every `k ∈ Z_i`, and in particular `h_i Z_(i+1) h_i^-1 = Z_(i+1)`.

**Step 3: conjugation is squaring, and `2 ∉ P(Z_(i+1))`.**
- The maps `z ↦ h_i z h_i^-1` and `z ↦ z^2` are both continuous homomorphisms `Z_(i+1) → Z_(i+1)`; the second is one because `Z_(i+1)` is abelian.
- They agree on the dense subgroup `<h_(i+1)>`, and `T` is Hausdorff, so they agree on `Z_(i+1)`.
- By Step 2 the first map is surjective. So squaring is surjective on `Z_(i+1)`.
- If `2 ∈ P(Z_(i+1))`, every square lies in the index-2 subgroup `Z_(i+1)^2`, which contradicts surjectivity.
- So `2 ∉ P(Z_i)` for every `i`.

**Step 4: the action on `Z/p`.** Let `p ∈ P(Z_(i+1))`. Put `U = Z_(i+1)^p` and `Q = Z_(i+1)/U ≅ Z/p`; `Q` is generated by the image of `h_(i+1)`.
- For `k ∈ Z_i`, conjugation `c_k` is an automorphism of `Z_(i+1)` by Step 2. So `c_k(U) = c_k(Z_(i+1))^p = U`, which gives a homomorphism `ψ : Z_i → Aut(Q) ≅ (Z/p)^×`.
- The kernel of `ψ` is `{k : k h_(i+1) k^-1 ∈ h_(i+1) U}`. That is the preimage of the open set `h_(i+1) U` under the continuous map `k ↦ k h_(i+1) k^-1`, so it is open.
- The relation gives `ψ(h_i) = (multiplication by 2)`. The image `ψ(Z_i)` is the closure of `ψ(<h_i>)` in the finite discrete group `Aut(Q)`, so it is the cyclic group `<2 mod p>`, of order `o = ord_p(2)`.
- By Step 3, `p` is odd, so `2 ≢ 1 mod p` and `o ≥ 2`. Also `o` divides `p − 1`.
- `Z_i / ker ψ ≅ Z/o`. So every prime `q` dividing `o` lies in `P(Z_i)`, and `q ≤ o ≤ p − 1`.

**Step 5: descent.**
- Let `P = ⋃_i P(Z_i)`. If some `h_i ≠ 1`, then `Z_i ≠ 1` and `P ≠ ∅`.
- Let `p = min P`, and say `p ∈ P(Z_(i+1))`. Step 4 gives a prime `q < p` in `P(Z_i)`, which contradicts minimality.
- So every `Z_i = 1`, that is, every `h_i = 1`. ∎

## Item 2 (equicontinuous actions)

Fix a compatible metric `ρ` on `X`. Give `Homeo(X)` the uniform topology, from the sup-distance of maps plus the sup-distance of their inverses. It is a Hausdorff topological group.

**(a) Compact subgroups of `Homeo(X)` are totally disconnected.**
- For a finite partition `𝒫` of `X` into clopen sets, let `S_𝒫 = {f : f(A) = A for all A ∈ 𝒫}`. This is a subgroup.
- Distinct atoms are at positive distance; let `δ` be the minimum. If `sup_x ρ(f x, x) < δ`, then `f` maps every point into its own atom. Since `f` is a bijection and the atoms partition `X`, `f(A) = A`. So `S_𝒫` is open.
- `X` is compact, zero-dimensional and metrizable. So for every `ε > 0` there is such a partition whose atoms have diameter `< ε`, and then `S_𝒫` lies in the `ε`-ball around `1`.
- Hence open subgroups form a neighbourhood basis of `1`. Every compact subgroup inherits such a basis, so it is totally disconnected.

**(b) `cl<g_i>` is compact.**
- `F_i = {g_i^m : m ∈ Z}` is equicontinuous and closed under inverses. By Arzelà--Ascoli its closure in `C(X, X)`, with the uniform topology, is compact.
- Suppose `g_i^(m_j) → k` uniformly. Pass to a subsequence with `g_i^(−m_j) → k'`.
- Uniform equicontinuity of `F_i` gives `k k' = lim g_i^(m_j) g_i^(−m_j) = 1`, and similarly `k' k = 1`.
- So `k ∈ Homeo(X)` and `g_i^(−m_j) → k^-1` uniformly. Hence `cl<g_i>` in `Homeo(X)` is compact.

**Conclusion.** By (a) and (b), item 1 applies with `T = Homeo(X)` and `h_i` the image of `g_i`. So each `g_i` acts as the identity, and the action is trivial. ∎

## Item 3 (almost-automorphism hosts)

- Let `φ : H4 → A_(d,r)` and put `h_i = φ(g_i)`.
- For each `i`, `f = h_i` and `g = h_(i+1)` satisfy `f g f^-1 = g^2`, that is `f g^k f^-1 = g^l` with `k = 1`, `l = 2`, `|k| ≠ |l|`.
- Item 1 of `almost-automorphism-conjugate-to-proper-power-is-equicontinuous` makes `<h_(i+1)>` equicontinuous on `X_(d,r)`, which is compact, zero-dimensional and metrizable.
- So `H4` acts on `X_(d,r)` through `φ` with every generator equicontinuous. Item 2 makes the action trivial.
- `A_(d,r)` acts faithfully on `X_(d,r)`, so `φ` is trivial. ∎

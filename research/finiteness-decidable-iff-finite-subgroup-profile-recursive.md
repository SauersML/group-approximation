## Definitions

Let `G` be a group with a finite symmetric generating set `S`, word length
`|·|_S` and balls `B(L) = {g : |g|_S <= L}`.

- `TO_(G,S)(L)` is the largest order of a torsion element in `B(L)`.
- `FS_(G,S)(L)` is the largest order of a finite subgroup generated by a subset
  of `B(L)`. There are finitely many subsets, so this is a finite number.
- For a finite group `Γ` and a symmetric generating set `T`, the Cheeger
  constant is
  `h(Γ,T) = min { Σ_(y in T) |A \ yA| / |A| : A ⊂ Γ, 0 < |A| <= |Γ|/2 }`.
- For rational `δ > 0`, `X^δ_(G,S)(L)` is the largest `|Γ|` over finite
  subgroups `Γ <= G` with a symmetric generating set `T ⊂ B(L)`, `|T| <= L`,
  `h(Γ,T) >= δ`. The trivial group counts, so the value is at least `1`.

These are the profiles `FS` and `X^δ` of the w10 lane node
`short-expander-subgroups-force-folner-growth` (not on this branch), with the
torsion-order profile `TO` added. Clearly `TO <= FS` and `X^δ <= FS`.

- The **order problem** asks, given a word, whether it has finite order.
- The **finiteness problem** asks, given a finite set of words, whether the
  subgroup they generate is finite.
- The **δ-expander problem** asks, given a finite symmetric set `T` of words,
  whether `<T>` is finite with `h(<T>,T) >= δ`.

A function `P` is *recursively bounded* if `P(L) <= R(L)` for all `L`, for some
recursive `R`. Since `C·R(CL)` is recursive whenever `R` is, this is the same as
`P ≼ R` for some recursive `R`.

## Statement

Let `G = <S>` have solvable word problem.

1. `TO_G` is computable ⇔ `TO_G` is recursively bounded ⇔ the order problem is
   decidable.
2. `FS_G` is computable ⇔ `FS_G` is recursively bounded ⇔ the finiteness
   problem is decidable.
3. For rational `δ > 0`: `X^δ_G` is computable ⇔ `X^δ_G` is recursively bounded
   ⇔ the δ-expander problem is decidable.
4. **Invariance.** Let `K = <R>` be a finitely generated subgroup of `G`, and
   let `c >= 1` bound `|r|_S` for `r in R`. Then `TO_(K,R)(L) <= TO_(G,S)(cL)`,
   `FS_(K,R)(L) <= FS_(G,S)(cL)` and `X^δ_(K,R)(L) <= X^δ_(G,S)(cL)`. In
   particular, whether each profile is recursively bounded depends neither on
   the generating set nor on passing to an overgroup, except that it can only
   get worse in an overgroup.

## Reading for the short-expander route to E

- **The finite-subgroup obstruction reaches exactly the decidable hosts.** Let a
  single finitely presented simple host `S` supply short-expander witnesses
  past every recursive bound. Then `FS_S` is not recursively bounded, since
  `X^δ <= FS` and item 4 applies. By item 2 this happens exactly when `S` has
  undecidable finiteness problem.
- **This sharpens the w10 necessary condition.** That condition, recorded on
  `fp-simple-amenable-subgroups-have-unbounded-expander-profile`, is not on this
  branch. The w10 kill of the Higman--Thompson groups (pumping) is one instance
  of a decidable finiteness problem.
- **An undecidable order problem suffices** for the necessary condition, by
  item 1 and `TO <= FS`. See
  `brin-thompson-torsion-orders-escape-every-recursive-bound` for `2V`.

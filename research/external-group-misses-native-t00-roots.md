**ESTABLISHED FULL CONSTANT-RETURN FENCE.**  Let

```text
G_X=<L_0, the eight external signed normalizer roots>
   =UT_(6,9,5,8,4,7,2)(F_2),                           (XTR1)
```

so `|G_X|=2^21=2097152` and `|G_X/L_0|=256`.  Retain the
minimal coefficient-conversion outputs

```text
x_(8,ell)(y_2),       ell in {2,4,5,6,7},
x_(ell,8)(y_1),       ell in {2,4,5,6,9}.              (XTR2)
```

No word in `G_X` conjugates any root in the first row to the native reverse
root `x_89(y_2)`, and no word in `G_X` conjugates any root in the second row
to `x_78(y_1)`:

```text
g x_(8,ell)(y_2) g^(-1) != x_89(y_2),
g x_(ell,8)(y_1) g^(-1) != x_78(y_1)                  (XTR3)
```

for every `g in G_X` and every displayed `ell`.

The exact rank-one conjugacy-orbit sizes, in the displayed endpoint orders,
are

```text
(256,64,32,8,128),       (8,32,64,256,128).            (XTR4)
```

None contains its native target transvection.  This is stronger than the
signed-`L_0` zero result: arbitrary use of all eight constant external
returns, at unbounded word length and with arbitrary `L_0` dressing, still
cannot restore the endpoint changed by the `t_00` multiplication.

Consequently there is no external-return word whose reservoir gauge can be
fed into the complementary positive-`L_0` fusion cancellation at this
stage.  That cancellation applies only after two returned occurrences have
landed on one positive `L_0` root; `(XTR3)` says the native reverse
Whitehead occurrence is never reached.  A live continuation must use a
nonconstant opposite-root/Whitehead return outside `G_X`.

No Property T, Kazhdan input, trace hypothesis, literature theorem, local
computation, or Lean compilation is used.

Numbering follows the claim. Put `a ↦ x_0`, `b ↦ x_1`, and let `π : F_2 → F` be the quotient map, so
`ker π = <<R_1, R_2>>`.

**Import (trust surface).** Every nontrivial normal subgroup of `F` contains `[F,F]`. It is pinned in
`thompson-f-is-lea-only-if-amenable-proof` (Burillo–Lodha–Reeves, arXiv:1509.04586, citing
Cannon–Floyd–Parry: every proper quotient of `F` is abelian), and used the same way in
`thompson-f-almost-kernels-force-linear-commutator-bounds-proof`.

**1. Item 1.**
- **A verbal representative.** Verbal subgroups map onto verbal subgroups under surjections, so
  `V(F) = π(V(F_2))`. `V(F)` is normal and nontrivial, so it contains `[F,F]`, which contains `π(c)`.
  Choose `w ∈ V(F_2)` with `π(w) = π(c)`.
- **Relator part.** Then `r := c w^-1 ∈ <<R_1, R_2>>`, so `r` is a product of some number `N_v` of
  conjugates of `R_1^±1`, `R_2^±1`, and `c = r w` in `F_2`.
- **Evaluation.** If `G = <A, B>` satisfies `v`, then `w(A,B) ∈ V(G) = 1`, so `c(A,B) = r(A,B)`. The
  metric is bi-invariant, so `t = d(c(A,B), 1) ≤ N_v · D`.

**2. Item 2.**
- **`F'' = F'`.** By `thompson-f-metabelian-pairs-obey-sharp-linear-commutator-bound` item 2,
  `c = u_2 P` with `u_2 ∈ F_2''` and `P ∈ <<R_1, R_2>>`. So `π(c) = π(u_2) ∈ π(F_2'') = F''`. `π(c) ≠ 1`,
  since `F` is nonabelian and generated by `x_0, x_1`. So `F''` is a nontrivial normal subgroup, and
  the import gives `F'' ⊇ F'`, hence `F'' = F'`.
- **Induction.** `F^(ℓ+1) = (F^(ℓ))' = (F')' = F'` for every `ℓ ≥ 1`.
- **Constants.** The law of derived length `ℓ` (the iterated commutator word in `2^ℓ` letters) has
  verbal subgroup `F^(ℓ) = F' ≠ 1`, so item 1 applies. `N_1 = 0` because abelian pairs commute.
  `N_2 ≤ 3`, with the sharper form, by claim `thompson-f-metabelian-pairs-obey-sharp-linear-commutator-bound`.

**3. Item 3.** `x_0^e(τ) = τ/2^e` for small `τ > 0`, so `x_0^e ≠ 1` and `V(F) = F^e ≠ 1` for the law
`x^e`. Apply item 1.

**4. Item 4.**
- **Kernel of the projection.** The projection `(p, i) ↦ p` intertwines `A, B` with `A_0, B_0`, so
  it induces a homomorphism `G = <A,B> → G_0 = <A_0, B_0>`. By induction on word length,
  `w(A,B)(p,i) = (w(A_0,B_0) p, κ_w(p) i)`, where `κ_w(p)` is a product of values of `c, d` and their
  inverses, so it lies in `K`. An element of the kernel therefore acts fibrewise by elements of `K`,
  and the kernel embeds in `K^(n_0)`, which has derived length `dl K`.
- **Derived length.** `G^(dl G_0)` lies in the kernel, so `dl G ≤ dl G_0 + dl K`.

**5. Item 5.**
- **Product form.** With `c ≡ P` and `d ≡ Q`, `A = T_1 × P` and `B = T_2 × Q` on
  `(Z/N × Z/N) × [k]`, where `T_1, T_2` are the commuting translations. So
  `w(A,B) = w(T_1,T_2) × w(P,Q)` for every word `w`.
- **Counts.** `R_1`, `R_2` and `c` have exponent sum zero in `a` and in `b`, so they evaluate to the
  identity on `Z/N × Z/N`. Each moved count is `N^2` times the count for `(P,Q)`, so `D` and `t` are
  unchanged.
- **Firewall.** A uniform bound `t ≤ C D` over these skew products is the bound for all pairs, which is
  item 2 of `thompson-f-sofic-iff-defect-to-separation-ratio-vanishes`. ∎

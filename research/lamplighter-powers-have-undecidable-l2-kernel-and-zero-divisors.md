**ESTABLISHED (literature import).**
- **Kernel-over-Z[G].** Given `M in M_k(Z[G])`, is `ker M = {0}` as an operator on `ℓ²(G)^k`?
  This problem is undecidable for `G = (Z/2 ≀ Z)^3`.
- **Zero-divisors-in-Z[G].** This problem is undecidable for `G = (Z/2 ≀ Z)^4`.
- For a finitely presented group containing `Z/2 ≀ Z`, deciding whether a given L²-Betti number of
  a finite CW complex with fundamental group its cube vanishes is undecidable.

**Step 0 (colimit).** `L_0` is the directed union of
`span{x_μ y_ν : |μ| = |ν| = m} ≅ M_(2^m)(k)`. The inclusion appends a letter,
`x_μ y_ν = Σ_j x_(μj) y_(νj)`, so it is the diagonal map `a ↦ a ⊗ 1_2`.
- Hence `C = colim_m C_m`, where `C_m = M_(N_m)(L)` and `N_m = 2^(m(d−1))`, along
  diagonal unital maps.
- Each `C_(m+1)` is free of finite rank as a left and as a right `C_m`-module.
  So `C` is flat over every `C_m` on both sides.

**Step 1 (semihereditary).**
- By `leavitt-tensor-global-dimension-bound` with `B = k` and `d = 1`,
  `l.gl.dim L = r.gl.dim L = 1`. So `L` is hereditary, and by Morita invariance
  so is each `C_m`.
- A finitely generated left ideal `I ⊆ C` is generated by finitely many elements
  lying in some `C_m`. Let `I_m` be the left ideal of `C_m` that they generate.
  It is projective.
- Flatness gives `C ⊗_(C_m) I_m ≅ C I_m = I`, so `I` is projective. The right
  side is symmetric.
- A finitely presented module `M = coker(C^a -> C^b)` has image a finitely
  generated submodule of `C^b`. Over a semihereditary ring such a submodule is
  projective, so `pd M <= 1`.

**Step 2 (regular supercoherent).**
- `L` is regular supercoherent, by Ara–Cortiñas Lemma 6.1
  (`ara-cortinas-leavitt-tensor-k-theory-vanishes`, part 1). Morita invariance
  gives the same for each `M_N(L)`.
- For fixed `p`, `C[t_1, ..., t_p] = colim_m M_(N_m)(L[t_1, ..., t_p])`, along
  free extensions.
- **Coherent.** A finitely generated left ideal is extended from some stage. It
  is finitely presented there, and flat base change keeps it finitely presented.
- **Regular.** A finitely presented module is extended from some stage. There it
  has a finite resolution by finitely generated projectives, and base change
  carries the resolution over.

**Step 3 (K-theory).** Nonconnective algebraic K-theory commutes with filtered
colimits of rings and is invariant under `R ↦ M_N(R)`. So

```text
K_n(C) = colim_m K_n(M_(N_m)(L)) = colim K_n(L).
```

By Ara–Cortiñas Proposition 6.2 with `R = k`, which is regular supercoherent,
`K_n(L) = 0` for every `n ∈ Z` (`ara-cortinas-leavitt-tensor-k-theory-vanishes`,
part 2). Hence `K_n(C) = 0` for every `n ∈ Z`.

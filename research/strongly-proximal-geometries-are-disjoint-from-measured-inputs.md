**ESTABLISHED (lane proof, elementary, unreviewed; no priority claimed for Part 1, which is
standard Glasner-type disjointness).** Conventions: `Λ` countable, compact metrizable
`Λ`-spaces, `P(X)` the Borel probability measures with the weak* topology. A minimal
`Λ`-space `G` is *strongly proximal* if the closure of `Λ·μ` contains a Dirac mass for every
`μ ∈ P(G)`.

## Part 1. Disjointness

**Lemma 1.** Let `G` be minimal and strongly proximal, and let `Y` be minimal with a
`Λ`-invariant `ν ∈ P(Y)`. Every closed invariant `J ⊆ G x Y` with `π_Y(J) = Y` equals
`G x Y`. In particular `G x Y` is minimal.

*Proof.*
1. The push-forward `P(J) -> P(Y)` along the continuous surjection `π_Y|_J` is onto (its
   image is weak*-closed and convex and contains every Dirac mass). Pick `λ ∈ P(J)` with
   `(π_Y)_*λ = ν`.
2. By strong proximality there is a net `g_i` with `g_i·(π_G)_*λ -> δ_{x_0}` for some `x_0`.
   Pass to a subnet with `g_i·λ -> λ'`. Then `λ' ∈ P(J)`, since `J` is closed and invariant.
3. The marginals are continuous: `(π_G)_*λ' = δ_{x_0}`, and `(π_Y)_*λ' = lim g_i·ν = ν`.
4. So `λ'` lives on `J ∩ ({x_0} x Y)`, and its `Y`-marginal is `ν`. Hence
   `supp ν ⊆ {y : (x_0,y) ∈ J}`. `supp ν` is closed, invariant and nonempty, so it is `Y`.
5. Invariance gives `{g x_0} x Y ⊆ J` for all `g`, and minimality of `G` gives `G x Y ⊆ J`. ∎

For the minimality statement, apply Lemma 1 to an orbit closure. Its `Y`-projection is closed,
invariant and nonempty, so it is all of `Y`.

## Part 2. A minimal strongly proximal paradoxical SFT

Let `W_3 = ⟨s_1,s_2,s_3 | s_1^2, s_2^2, s_3^2⟩`. Its Cayley graph is the 3-regular tree `T`,
with the edge `{g, g s_i}` labelled `i`. `W_3` acts on it by left multiplication, which
preserves labels, and on configurations by `(γ·x)(g) = x(γ^{-1} g)`. Put

    B = { x ∈ {1,2,3}^{W_3} : for all g and i, exactly one of  x(g) = i,  x(g s_i) = i  holds }.

**Proposition 2.**
- (a) `B` is a nearest-neighbour SFT, conjugate to the boundary action `W_3 ↷ ∂T`.
- (b) Hence `B` is minimal and strongly proximal, and it has no invariant probability measure.
- (c) Every point stabilizer is trivial or infinite cyclic, generated by a hyperbolic element.
- (d) For each `x ∈ B`, `φ_x(g) = g s_{x(g)}` is a 2-to-1 map with `g^{-1}φ_x(g) ∈ S`. So a
  local recoding (colour the two preimages by label order) embeds `B` as a sub-SFT of the
  Barbieri–Sablik–Salo paradoxical subshift of `W_3`.

*Proof.*
- **(a) Orientation.** `x ∈ B` orients every edge exactly once (`g -> g s_i` iff `x(g) = i`),
  with out-degree 1 at every vertex, hence in-degree 2.
- **(a) Geodesics.** Along a geodesic `w_0 … w_n`, no interior vertex has both of its path
  edges outgoing. So the edge orientations read `→^a ←^b`.
- **(a) The end.** From any vertex, the outgoing edges form a non-backtracking ray, since the
  edge just used points into the current vertex. By the `→^a ←^b` pattern, the rays from any
  two vertices merge. So all rays converge to one end `ξ_x`.
- **(a) Inverse.** Given an end `ξ`, set `x(g)` to be the label of the first edge from `g`
  toward `ξ`. Every edge has exactly one endpoint whose ray to `ξ` uses it, so `x ∈ B`.
  Both maps are continuous, and they are equivariant for left multiplication.
- **(b)** `W_3` is virtually free of rank 2, a non-elementary hyperbolic group. The action on
  its Gromov boundary is minimal and strongly (indeed extremely) proximal. This is standard
  and recalled, not re-proved here. A strongly proximal minimal space with more than one point
  has no invariant measure.
- **(c) No torsion in stabilizers.** `W_3` acts freely on vertices, so a nontrivial elliptic
  element inverts an edge `{g, gs}`. It cannot fix an end `ξ`: it would preserve the Busemann
  function `b_ξ` up to a constant `c`, and swapping `g` and `gs` forces `c = 0` and
  `b(g) = b(gs)`, while adjacent vertices have `|b(g) − b(gs)| = 1`.
- **(c) Conclusion.** `Stab(ξ)` is torsion-free and virtually cyclic, so it is trivial or `Z`.
- **(d)** The preimages of `g` are the two ends of its incoming edges. ∎

**Rays and walls.** The BSS path `γ_g` (Section `sec:paradox` of arXiv:2104.05141) follows
preimages of the colour opposite to `g`'s. So it runs away from `ξ_x`.
- A vertex is reached by some path if and only if the colours of its ancestors, read upward,
  eventually change.
- The unreached vertices lie on at most two bi-infinite lines, one all-G and one all-B.
  - The all-G set is closed under taking parents and G-children, so it is a single line if
    nonempty.
  - Such lines occur only for the countably many ends whose upward colour sequence is
    eventually constant.

## Part 3. Products

Let `Λ_0` be finitely generated and `Γ = Λ_0 x W_3 x W_3`. Put
`G = B ⊠ B = { x(λ,u,v) = (x_1(u), x_2(v)) : x_1, x_2 ∈ B }`.
- `G` is a nearest-neighbour `Γ`-SFT, conjugate to `∂T x ∂T` with `Λ_0` acting trivially.
- **Minimal:** orbits are products of dense orbits.
- **Strongly proximal:** first push the first marginal to a Dirac mass using the first `W_3`
  (the limit keeps a Dirac first marginal), then push the second marginal using the second.
  A measure with two Dirac marginals is a Dirac mass.
- **Grids:** `G` carries the BSS grids `γ_{(u,v)} = γ^1_u x γ^2_v`.
  - Every element of `Γ` is the origin of an anchored `N^2`-grid.
  - Unreached vertices lie in at most two walls `L x W_3` and two walls `W_3 x L'` in each
    `Λ_0`-plane, at the same position in every plane.
- `Γ` is finitely presented with solvable word problem when `Λ_0` is.
- BSS Theorem `thm:selfsimulation` applies to `(Λ_0 x W_3) x W_3` whenever `Λ_0` is finitely
  generated.

## Part 4. Consequences for minimal self-simulation (Q:minimal)

**Theorem 3 (injective codings, any countable group).** Let `Z` be a minimal `Λ`-SFT with
factor maps `τ : Z -> T` and `φ : Z -> Y`, such that `(τ,φ)` is injective and `T x Y` is
minimal. Then `Y` is a `Λ`-SFT.

*Proof.*
1. **Conjugacy.** The image of `(τ,φ)` is closed, invariant and nonempty, so it is `T x Y`.
   A continuous bijection of compacta is a homeomorphism, so `Z ≅ T x Y`.
2. **`T` is a subshift.** `T ≅ T x {y_0}` is closed in `Z`, so it is zero-dimensional. An
   expansive constant of `Z` is one for `T`: if `t ≠ t'` stay `c`-close, so do `(t,y_0)` and
   `(t',y_0)`. So `T` is conjugate to a subshift `T'`, via a clopen partition finer than `c`.
3. **Finite type transfers.** The product subshift `P = T' x Y`, over the alphabet `C x B`
   with the diagonal action, is conjugate to `Z`. Finite type is a conjugacy invariant over
   any countable group (Curtis–Hedlund–Lyndon, as in Step 4 of
   `injective-plane-lift-codings-force-finite-type-proof`). So `P` is of finite type, with
   some window `K`.
4. **Slice.** Let `y'` have every `K`-pattern in the language of `Y`, and fix `t ∈ T'`.
   - At each position `h`, pick `y'' ∈ Y` agreeing with `y'` on `hK`.
   - `(t,y'') ∈ P` shows that the `hK`-pattern of `(t,y')` is not forbidden.
   - So `(t,y') ∈ P`, which gives `y' ∈ Y`. ∎

**Corollary 4.**
- **(i) Return times never synchronize.** Take `Λ = Γ`, `G` as in Part 3 (or any minimal
  strongly proximal geometry), and `Y` minimal with an invariant measure. For every minimal
  SFT extension `Z` with factors `τ : Z -> G` and `φ : Z -> Y`, the pair map is onto
  `G x Y`, by Lemma 1.
  - So BSS obstacle (b), return times of input cylinders coordinating with return times of
    geometry patterns, cannot occur.
  - Any geometry pattern and any input pattern co-occur, syndetically, at every relative
    placement that the product allows.
- **(ii) The floating locus is forced.** If `Y` is not of finite type, then `(τ,φ)` is not
  injective, by Theorem 3. Some two points have the same geometry and the same input but
  different computation data. So BSS obstacle (a), uncontrolled content away from anchored
  grids, cannot be designed away. It is the whole problem.
- **(iii) Every countable transverse factor.** Let `Λ = Λ_0 x H` with `H` any countable
  group, `T` an `H`-system (`Λ_0` acting trivially) and `Y` a `Λ_0`-system (`H` acting
  trivially). Then `T x Y` is minimal, since orbits are products. So Theorem 3 applies, and
  `Y` is a `Λ_0`-SFT: a `Λ`-window `K ⊆ K_0 x K_1` gives the `Λ_0`-window `K_0`.
  - This proves in full generality Design Constraint 1 of
    `nonamenable-products-have-minimal-sft-extensions-of-free-inputs`, which was recorded
    there as a sketch for countable `H`.

**What stays open (sketch, not claimed).** Take `G` from Part 3, which is `Λ_0`-constant.
- **Coherence across planes.** The BSS coherence rule for `Λ_0`-generators,
  `σ(λ,u,v)(s) = σ(λs^{-1},u,v)(1)`, holds at *every* vertex of the configurations built in
  BSS's surjectivity proof. The grids of `g` and `gs^{-1}` are aligned there. So the rule
  can be imposed everywhere without losing surjectivity.
- **What this settles.** On the walls, the floating data is then coherent across planes. The
  "tuple coherence" half of the joint-diversification crux
  `plane-coupled-floating-tuples-are-jointly-diversifiable` is automatic for this geometry.
- **What is left:** only *validity and recurrence of wall data*. The unanchored grids must
  carry a hierarchical verification, as in Durand–Romashchenko fixed-point tilings, so that
  every wall window already occurs in an anchored grid.

## Lesson for general BH

Minimality of simulated SFTs has two enemies, and they need opposite cures.
- **Synchronization** between geometry and input is a joining phenomenon. It disappears
  entirely if the geometry is strongly proximal (boundary-like) and the input carries an
  invariant measure. The paradoxical geometry has no invariant measure anyway, so the natural
  choice is the *boundary* of a virtually free group: here a nearest-neighbour SFT
  (Part 2).
- **The floating locus** is forced by Theorem 3 over every countable group, and it is all
  that remains.
- **Route.** Replace the square `Λ_1 x Λ_1` by `Λ_1 x W_3 x W_3`: finitely presented, with
  solvable word problem, containing `K`, self-simulable by BSS.
- **Premise needed: (M2μ).** An effective minimal free input for this group that carries an
  invariant measure. A product of such inputs for the three factors works: product measures
  are invariant, and freeness is needed along `W_3` as well, since boundary stabilizers are
  cyclic.
- **What gate E1 then reduces to:** one statement, hierarchical control of wall data on a
  `Λ_1`-constant boundary geometry.

## Proof

`[R,R]` is normal in `F` (characteristic in the normal subgroup `R`), so
`(FA1)` is exact with kernel `R/[R,R]`.  Every subgroup of a free group is
free (Nielsen-Schreier: in the coset graph of `L <= F`, based reduced loops
are the elements of `L`; a spanning tree turns the non-tree edges into a free
basis, since recording them identifies loop reduction with free-word
reduction).  So `R` is free and `R/[R,R]` is free abelian, in particular
torsion-free.

Now suppose `f in F` has `f^n in [R,R]` for some `n > 0`; we show
`f in [R,R]`.  Since `[R,R] <= R`, the image of `f` in `G = F/R` satisfies
`f^n = 1`, so it has finite order `m | n`.

**Case `m = 1`.**  Then `f in R`, and `f^n in [R,R]` says the image of `f` in
the torsion-free group `R/[R,R]` is `n`-torsion, hence trivial:
`f in [R,R]`.

**Case `m > 1`.**  Put `L = <R, f> <= F`.  Then `L/R` is the cyclic group of
order `m` generated by the image of `f`, so there is a surjection
`L -> Z/mZ` sending `f` to `1`.  By Nielsen-Schreier `L` is free, so that map
lifts to a homomorphism `l : L -> Z`: choose for each free basis element of
`L` any integer representing its image in `Z/mZ`.  Then `l` reduces mod `m`
to the original map, so

```text
l(f) = 1  mod m,     hence  l(f) != 0   because m > 1.
```

But `Z` is abelian, so `l` kills `[R,R]`, and `f^n in [R,R]` gives
`0 = l(f^n) = n l(f)`, so `l(f) = 0`.  Contradiction; this case does not
occur.

Hence only `m = 1` happens and every torsion element of `E` is trivial.

Finally, the images of a free basis of `F` generate `E`, so `E` is `n`-generated
when `F` has rank `n`.

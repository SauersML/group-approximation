A tree `T` is a connected graph without cycles, with path metric `d` on vertices.
All actions are by automorphisms without inversions. `[x, y]` is the geodesic.

**T0 (no backtracking).** An edge path in which no edge is immediately
followed by its reverse is the geodesic between its endpoints. This is the
definition of a tree: a reduced edge path cannot close up or revisit a vertex.

**T1 (fixed sets are subtrees).** For `H <= Aut(T)`, `Fix(H)` is convex, because an
automorphism fixing `x` and `y` fixes the unique geodesic `[x, y]`. If a vertex
`p` is nearest to `q` in a nonempty subtree `F`, then `[p, q]` meets `F` only in `p`.

**T2 (axis).** Let `a` fix no vertex, and let `m = min_x d(x, ax) >= 1`, attained at
`x_0`.
- *No backtracking at `ax_0`.* Let `x_1` be the vertex after `x_0` on
  `[x_0, ax_0]`, and `y` the vertex before `ax_0`. Backtracking means `y = a x_1`.
  - If `m >= 2`, then `d(x_1, a x_1) = d(x_1, y) = m - 2`, contradicting minimality.
  - If `m = 1`, then `y = x_0`, `x_1 = a x_0` and `a x_1 = x_0`, so `a` inverts an
    edge, which is excluded.
- So by T0 the union `A = ∪_n a^n [x_0, a x_0]` is a bi-infinite geodesic line, and
  `a` translates it by `m`.
- *Min set.* Let `x` be a vertex at distance `r >= 1` from `A`, with nearest point
  `π(x)`. Then `aπ(x) != π(x)` is the nearest point of `ax`, and the path
  `[x, π(x)] ∪ [π(x), aπ(x)] ∪ [aπ(x), ax]` has no backtracking. So
  `d(x, ax) = 2r + m > m`. Hence `A = {x : d(x, ax) = m}`.

**T3 (disjoint fixed sets).** Let `a, b` each fix a vertex, with
`Fix(a) ∩ Fix(b) = ∅`. Then `ab` fixes no vertex.
- Let `[p, q]` be the bridge, with `p in Fix(a)`, `q in Fix(b)` and `d = d(p, q) >= 1`.
- Let `e` be the edge of `[p, q]` at `p`, and `f` the edge at `q`. By T1,
  `a e != e` and `b f != f`: otherwise the other endpoint would be fixed.
- Put `σ = [q, p] ∪ a[p, q]`. It runs from `q` to `a q = ab q`, has length `2d`,
  and has no backtracking at `p` because `a e != e`.
- The path `σ` is followed by `ab σ`, which starts at `ab q`. The last edge of `σ`
  is `a f`, and the first edge of `abσ` is `ab f`. These differ because `bf != f`.
- By T0, `d((ab)^n q, q) = 2dn`, which is unbounded. An automorphism that fixes a
  vertex `v` has bounded orbits: `d(g^n q, q) <= 2 d(q, v)`. So `ab` fixes no vertex.

**T4 (Helly).** Finitely many pairwise intersecting subtrees have a common vertex.
- For three subtrees `A, B, C`, pick `u in B∩C`, `v in A∩C` and `w in A∩B`. The
  median of `u, v, w`, the common vertex of `[u, v]`, `[v, w]` and `[w, u]`, lies
  in all three by convexity.
- Induct by replacing `A, B` by `A ∩ B`, which meets every other subtree by the
  three-set case.

**T5 (finite generation).** If `Γ` is generated by a finite set `Y` and every
`y` and every product `yz` (`y, z in Y`) fixes a vertex, then `Γ` fixes a vertex.
- By T3 the sets `Fix(y)` intersect pairwise.
- By T4 they have a common vertex, which `Γ` fixes.

**Proof of (E).** Let `L = gPg^-1`, which is perfect and commutes with `P`.
- Suppose `p in P` fixes no vertex. Let `A` be its axis.
- For `l in L`, `d(lx, p lx) = d(lx, l px) = d(x, px)`. So `L` preserves the min set of
  `p`, which is `A` by T2.
- Restriction gives a homomorphism `L -> Aut(A)`. The automorphism group of a
  bi-infinite line is `D_inf = Z ⋊ C_2`, whose second derived subgroup is trivial.
- The image is perfect and solvable, hence trivial. So `L` fixes `A` pointwise.
- In particular `gpg^-1 in L` fixes a vertex `v`, and then `p` fixes `g^-1 v`.
  This is a contradiction. `∎`

**Proof of (FA).** By (E), every element of `Q_ij` fixes a vertex. `Q_ij` is
finitely generated, so by T5 it fixes a vertex `v_ij`.
- By T1, `F_i = Fix(K_i)` is a subtree. It is nonempty, since `v_ii in F_i`.
- For `i != j`, `v_ij in F_i ∩ F_j`.
- By T4 there is a vertex in `F_1 ∩ F_2 ∩ F_3`. It is fixed by `<K_1, K_2, K_3> = Γ`. `∎`

**On inversions.** Serre's property FA concerns actions without inversions. An
action with inversions acts without inversions on the barycentric subdivision.
So a group satisfying the criterion fixes a vertex or the midpoint of an edge in
every tree action.

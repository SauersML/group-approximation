The full derivation is in artifact sections 1 to 4.

1. **Equivalences.**
   - Full ⟹ `1 ≼ P`, by proper infiniteness. That gives `E_P ≅ H_X ⊕ E'`, which is `≅ H_X` by Kasparov.
   - Stable `D_P` gives `E_P ≅ ℓ²(F)`. Compactness gives a unit section of some `F^N`, hence
     `H_X ↪ E_P` complementably.
   - (AO) builds orthonormal `η_k` with `sup |⟨ζ_j, η_k⟩| ≤ 2^{-k}` for `j ≤ k`. So `δ_k -> η_k` is an
     adjointable isometry `H_X -> E_P`.
2. **Property (S).**
   - A unital quotient `D_{P|F}` would make `P|F` a properly infinite bundle of finite rank r, so
     `2r ≤ r`, which is impossible.
   - For a bounded 2-quasitrace τ, the isometries `W_i = V_2^i V_1` give
     `n τ(x) = τ(Σ_{i<n} W_i x W_i^*) ≤ ‖τ‖‖x‖`, so τ = 0.
   - So Ortega--Perera--Rørdam arXiv:0903.2917v4 Proposition 4.5 (read in the PDF: "A has property (S)
     if and only if A has no non-zero bounded lower semi-continuous 2-quasitrace and no non-zero unital
     quotient") gives property (S).
3. **Stability.** OPR Proposition 4.8, read in the PDF: for separable A with `Cu(A)` weakly ω-comparable
   and `A ⊗ K` containing a full projection, a full hereditary `B ⊆ A ⊗ K` is stable iff it has
   property (S). Apply it with `A = C(X)` and `B = D_P`. Then use step 1.
4. **Detectors.** `π(iota_1(s_1)), π(iota_1(s_2))` make `P_E` properly infinite, and `π(J) ⊆ K(E)`
   because J is generated by a compact element.
   - If `P_E` is full, `K(E)` is stable and `K(E)~` is K1-injective.
   - `[π(u)] ∈ π_* K_1(J) = 0`, where `K_1(J) = 0` is computed in route
     `lxi-from-halving-and-toeplitz-defect-ideal`.

Notation as in the target claim. All maps are group homomorphisms.

**Step 0 (the core is `L_m`).** In `L_m` every element has the form `tau^-a p tau^b` with
`a, b >= 0`, `p in P`, because `tau^-a (g,v) tau^a = (g, m^-a v)` and
`V_m = union_a m^-a Z^n`. The relations `tau p tau^-1 = alpha(p)` hold, so
`<P, t | t p t^-1 = alpha(p)> -> L_m` is surjective. It is injective: an element of the HNN
group can be written `t^-a p t^b`, and it maps to `(g, m^-a v) tau^(b-a)`, which is trivial only if
`b = a` and `p = 1`. So `iota` and `s` induce `psi : L_m -> G`, with
`psi(tau) = s` and `psi(g, m^-a v) = s^-a iota(g,v) s^a`.

**Step 1 (the kernel is small inside `V_m`).** Let `K = ker psi` and `M = K ∩ V_m`. Since `K` is
normal, `M` is invariant under `Gamma` and under conjugation by `tau^{±1}`, that is
`m M = M`. Since `G` is torsion-free, `V_m / M ≅ psi(V_m)` is torsion-free: if `x in V_m` and
`N x in M` with `N != 0`, then `psi(x)^N = 1`, so `psi(x) = 1` and `x in M`. Let `W` be the
`Q`-span of `M` in `Q^n`. If `x in V_m ∩ W`, write `x = sum r_i y_i` with `y_i in M` and
`r_i in Q`. For a common denominator `N`, `N x in M`, so `x in M`. Hence `M = V_m ∩ W`. `W` is
`Gamma`-invariant, so `W = 0` or `W = Q^n` by hypothesis. In the second case `M = V_m`, and
`iota(Z^n) = psi(Z^n) = 1`, against (A). So `M = 0`.

**Step 2 (the kernel centralizes `V_m`).** For `k in K` and `x in V_m`, `[k, x] in K ∩ V_m = 0`.
Write `k = (g, u) tau^j`. Then `k x k^-1 = m^j g x`, where `g` acts linearly on `Q^n`. So
`m^j g = I`. Taking determinants gives `m^(nj) = 1`, so `j = 0` and `g = I`. Hence
`K <= V_m`, `K = M = 0`, and (A) is proved.

**Step 3 (part B).** If `iota(Z^n) = 1`, then `iota(v_0) = 1` and the commutator is trivial.
So (A) applies and `iota` is injective on `P <= L_m`. Let `K'` be the kernel of
`((g,v),k) -> iota(g,v) c^k` on `P x Z`. This is a homomorphism because `c` commutes with `iota(P)`.
Then `K' ∩ Z^n = 0`, so `K'` centralizes `Z^n` as in Step 2, and `K' <= Z^n x Z`. If
`(v, k) in K'`, conjugating by `g in Gamma` gives `(g v, k) in K'`, hence `(g v - v, 0) in K' ∩ Z^n = 0`.
A nonzero `Gamma`-fixed vector would span an invariant line, and `n >= 2` excludes that, so `v = 0`. If
`(0, k) in K'` with `k != 0`, then `c^k = 1`, so `c = 1` by torsion-freeness, and
`[s c s^-1, iota(v_0)] = 1`, a contradiction. So `K' = 1`.

**Step 4 (irreducibility of `Gamma(3)`).** `Gamma(3)` contains `I + 3 E_ij` for all `i != j`. Let
`0 != W <= Q^3` be invariant, pick `0 != x in W` and `j` with `x_j != 0`. Then
`(I + 3E_ij) x - x = 3 x_j e_i in W`, so `e_i in W` for both `i != j`. Applying the same argument
to `e_i` gives `e_j in W`. So `W = Q^3`.

**Step 5 (corollary).** In `R` the relations `t p t^-1 = alpha(p)` and `[c, P] = 1` hold,
`p_0 = e_1 in Z^3`, and `q(w) = [q(t) q(c) q(t)^-1, q(e_1)]`. So (B) applies with `G = Q`,
`s = q(t)`, `v_0 = e_1`, and Step 4 supplies the hypothesis. `<e_1, tau> = Z[1/m] e_1 x| <tau>`
is `BS(1,m)`.

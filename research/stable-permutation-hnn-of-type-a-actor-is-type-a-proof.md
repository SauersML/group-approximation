*(a).* Check the four clauses of type (A).

* **Finite presentation.** `Gamma` is finitely presented and `D_1` is
  finitely generated, so `L` is presented by the generators and relators of
  `Gamma`, one letter `t`, and one relator `t d_j t^-1 = psi(d_j)` for each
  generator `d_j` of `D_1`. These relators hold for `pi` in `Sym(X)`, so `rho` is
  a well-defined homomorphism.
* **Faithfulness.** This is the hypothesis that `rho` is injective.
* **Pair orbits.** Every `L`-orbit of two-element subsets of `X` is a union of
  `Gamma`-orbits, and there are finitely many of those.
* **Stabilizers.** Fix `x in X` and let `P = Stab_L(x)`. Let `T` be the
  Bass--Serre tree of `L`, with vertex set `L/Gamma` and edge set `L/D_2`. By
  Britton's lemma `Gamma ∩ tGammat^-1 = D_2`, so the edge stabilizers are the
  conjugates of `D_2`. `P` acts on `T` without inversions, so it is the
  fundamental group of a graph of groups on `P\T` whose vertex groups are
  stabilizers in `P` of vertices of `T` (Serre, *Trees*, §I.5.4).
  - The vertices of `P\T` are the double cosets `P\L/Gamma`. Inversion
    `g -> g^-1` matches them with `Gamma\L/P`, which is the set of
    `Gamma`-orbits on `L/P = L.x ⊆ X`. There are finitely many, because
    `Gamma` has finitely many orbits on `X`: finitely many orbits of
    two-element subsets force finitely many orbits of points.
  - The edges of `P\T` correspond the same way to `D_2`-orbits on `L.x`. Since
    `pi(D_1 y) = D_2 pi(y)`, the permutation `pi` carries `D_1`-orbits
    bijectively onto `D_2`-orbits, so there are finitely many.
  - The vertex group at `gGamma` is `P ∩ gGammag^-1 = g Stab_Gamma(g^-1 x) g^-1`,
    which is finitely generated.

  The fundamental group of a finite graph of groups is generated by its vertex
  groups and one letter for each edge outside a maximal tree. So `P` is finitely
  generated.

*(b).* By `type-a-action-gives-boone-higman-for-subgroups` (Zaremsky, Corollary
B), every subgroup of `L` embeds in a finitely presented simple group. For
`A <= Gamma` with `A ∩ D_i = C_i` and `psi(C_1) = C_2`, a Britton-reduced word of
`A*_phi` stays reduced in `L`: a pinch `t c t^-1` or `t^-1 c t` in `L` needs
`c in A ∩ D_1 = C_1` or `c in A ∩ D_2 = C_2`. So `<A, t> <= L` is `A*_phi`
(Lyndon--Schupp, *Combinatorial Group Theory*, Chapter IV, §2).

*(c).* Take `D_1 = D_2 = Gamma` and `psi = phi`. Then `L = Gamma ⋊_phi Z`, and
`D_1` has finitely many orbits because `Gamma` does.

* An element `gamma t^m` lies in the kernel of `rho` exactly when
  `pi^m = rho(gamma)^-1`. So `rho` is injective if and only if no nonzero power
  of `pi` lies in `rho(Gamma)`, and then (a) applies.
* Otherwise let `n >= 1` be least with `pi^n = rho(gamma_0)`. Faithfulness of
  `Gamma` gives `phi^n = c_(gamma_0)`, so `u = gamma_0^-1 t^n` centralizes `Gamma`.
  Also `<u> ∩ Gamma = 1`, because `u` has `t`-exponent `n`. So
  `<Gamma, u> = Gamma x Z`, of index `n` in `L`.
* If `Gamma` has an element of infinite order, `Gamma x Z <= Gamma x Gamma`.
  `Gamma x Gamma` acts on `X ⊔ X` of type (A) by
  `type-a-actions-closed-under-products-and-finite-wreaths` (a). So `L` is a
  finite-index overgroup of a member of the permutational class, and it lies in
  that class by `boone-higman-type-a-class-closed-under-finite-extensions`.

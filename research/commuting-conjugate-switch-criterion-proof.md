## Why sufficient

The full proof is Sections 1--3 of the artifact. It uses only von Dyck's
theorem, the universal property of semidirect products, and the closure
properties of amenability.

**Isomorphism.** Let `E` be the set of `K`-translates `{gC, guC}` with `uC != C`.
Since `E` is `K`-invariant, `K` acts on `A(Gamma)` by `beta_x -> beta_(kx)`.

- *Forward map.* `phi : k -> k`, `b -> beta_C`.
  - Relators of `K` hold.
  - `c in S_C` fixes the vertex `C`, so `[beta_C, c] = 1`.
  - `[b, u b u^-1] -> [beta_C, beta_(uC)]` is a relator or trivial.
- *Backward map.* `psi : beta_(kC) -> k b k^-1`, `k -> k`.
  - It is well defined, because `C` is generated by elements commuting with `b`
    in `Q`.
  - RAAG relators map to conjugates `g[b, u b u^-1]g^-1 = 1`.
  - Compatibility `k psi(beta_(gC)) k^-1 = psi(beta_(kgC))` makes it a
    homomorphism on the semidirect product.
- *Inverse.* Both composites are the identity on generators.

**Adjacency.** Suppose `{C, y} = {gC, guC}`. Either `g in C` and
`y subset CuC`, or `gu in C` and `y subset Cu^-1C`. Conversely every such coset
arises. So `N(C) = (CUC cup CU^-1C)/C \ {C}`. By vertex-transitivity, `Gamma` is
complete iff `K = D(C,U)`.

**Dichotomy.**

- If `Gamma` is complete, `A(Gamma) = Z^(X)`, so `Q` is abelian-by-`K` and is
  amenable iff `K` is.
- Otherwise take non-adjacent `x != y`. Killing every other vertex generator
  respects all relators, since each edge has an endpoint outside `{x,y}`. This
  gives `A(Gamma) -> F(beta_x, beta_y)`, sending `beta_x, beta_y` to a basis. So
  `<beta_x, beta_y> = F_2` and `Q` is not amenable.
- A non-amenable `K <= Q` also makes `Q` non-amenable.

**Finite presentation.** If `K = <S|R>` is finite, then
`<S, b | R, [b,c] (c in S_C), [b, u b u^-1] (u in U)>` is the displayed finite
presentation. `QED`

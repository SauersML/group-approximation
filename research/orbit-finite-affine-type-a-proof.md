Notation as in the claim: `Γ = S ⋊ W`, `(s,w)·x = s·w(x)`.

1. **It is an action.** `(1, id)·x = x`. For the composition,
   `((s,w)(s',w'))·x = (s·w(s'), ww')·x = s·w(s')·w(w'(x)) = s·w(s'·w'(x))
   = (s,w)·((s',w')·x)`, using that `w` is a homomorphism.
2. **Faithful.** If `(s,w)·x = x` for every `x`, then `x = 1` gives `s = w(1)^(-1)·1 = 1`,
   and then `w(x) = x` for every `x`, so `w = id`.
3. **Transitive, stabilizers.** `(x, id)·1 = x`. `(s,w)·1 = s·w(1) = s`, so
   `(s,w)` fixes `1` exactly when `s = 1`; hence `Stab_Γ(1) = {(1,w)} ≅ W`. By
   transitivity every point stabilizer is conjugate to it, explicitly
   `Stab_Γ(x) = (x,1)·Stab_Γ(1)·(x,1)^(-1)`. In particular all point stabilizers are
   finitely generated if and only if `W` is.
4. **Pair orbits.** Put `q(x,y) = x^(-1) y`.
   - *Invariance.* `q((s,w)·x, (s,w)·y) = (s·w(x))^(-1)·(s·w(y)) = w(x)^(-1)·w(y)
     = w(q(x,y))`, so the `W`-orbit of `q(x,y)` depends only on the `Γ`-orbit of
     `(x,y)`.
   - *Surjective onto `W`-orbits.* `q(1,t) = t`.
   - *Injective.* Suppose `q(x',y') = w(q(x,y))` for some `w ∈ W`. Put
     `g = (x'·w(x)^(-1), w)`. Then `g·x = x'·w(x)^(-1)·w(x) = x'` and
     `g·y = x'·w(x)^(-1)·w(y) = x'·w(q(x,y)) = x'·q(x',y') = y'`.
   So `Γ`-orbits on `S × S` correspond bijectively to `W`-orbits on `S`.
5. **Criterion.** The action is faithful (step 2). Condition (i) of type (A) is
   finite presentation of `Γ`; condition (ii) is finite generation of `W` (step 3);
   condition (iii) is finiteness of the `W`-orbits on `S` (step 4). For the
   two-element-subset form of (iii): an orbit of two-element subsets `{x,y}` is the
   image of the orbits of `(x,y)` and `(y,x)`, and the diagonal is a single orbit by
   transitivity, so finitely many ordered-pair orbits is equivalent to finitely
   many orbits of two-element subsets.
6. **Necessary conditions.**
   - (a) *Retract.* `r: Γ → W`, `(s,w) ↦ w`, is a homomorphism with section
     `i(w) = (1,w)`. If `Γ` is generated by a finite set `X` and finitely presented,
     let `N` be the normal closure of the finitely many elements `x·i(r(x))^(-1)`,
     `x ∈ X`. Then `N <= ker r`, every `x ∈ X` is congruent to `i(r(x))` modulo `N`,
     so `Γ/N` is generated by the image of `i(W)`, and `r` induces an isomorphism
     `Γ/N → W` with inverse induced by `i`. So `W` is a quotient of a finitely
     presented group by finitely many relators, hence finitely presented.
   - (b) A finitely presented group is countable, and `S <= Γ`.
   - (c) Automorphisms preserve element orders, so each `W`-orbit has one order;
     finitely many orbits give finitely many orders.
   - (d) A finite group of automorphisms has only finite orbits, so finitely many
     orbits on an infinite `S` forces `W` infinite.
7. **Payoff.** Under the three conditions the action is of type (A) by step 5, and
   `type-a-action-gives-boone-higman-for-subgroups` (Zaremsky, arXiv:2405.18354,
   Corollary B, quoted verbatim there) says every subgroup of `Γ` has solvable word
   problem and embeds in a finitely presented simple group. `W ≅ i(W) <= Γ`.

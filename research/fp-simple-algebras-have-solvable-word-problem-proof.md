Let `r_1, ..., r_k` generate `I`.

1. **Zero is semi-decidable.** `w = 0` in `A` iff `w in I` iff `w` equals a
   finite sum `sum c u r_j v` with `c in K` and monomials `u, v`. Enumerate all
   such sums and compare them with `w` in the free algebra. Equality of
   noncommutative polynomials over a computable field is decidable.
2. **Nonzero is semi-decidable.** Suppose `w != 0` in `A`. The two-sided ideal
   `J_w` of `A` generated by `w` is nonzero, so `J_w = A` by simplicity.
   - *Unital case.* `1 in J_w`: there are finitely many `u_k, v_k` with
     `1 - sum u_k w v_k in I`.
   - *Non-unital case.* Every generator lies in `J_w = K w + A w + w A + A w A`:
     for each `i` there is a finite expression `e_i` of this shape with
     `x_i - e_i in I`.

   Either certificate is a finite object, and checking it reduces to step 1, so
   the set of nonzero `w` is recursively enumerable.
3. **The two searches are exclusive.** If `w = 0` in `A`, then `J_w = 0 != A`,
   so no certificate from step 2 exists, since `A != 0`. If `w != 0`, step 1
   never succeeds.

Run both searches in parallel; exactly one halts, and its answer is correct.

**ESTABLISHED** by `table-group-holonomy-elimination-proof`.

Let `D = (A, S, M, nu, mu)` be a design and `E` a marked partition of `S x M`,
with table group `U_E` as in `strict-automata-live-on-canonical-table-groups`.

**The decoder difference graph `Gamma_E`.** Its vertex set is `S`. Each identified
pair `(s,m) ~_E (s',m')` gives an edge from `s'` to `s` labelled
`delta = x_m' x_m^(-1)`, so its relator reads `x_s = x_s' delta`.

**Theorem.**

    U_E  ≅  Hol_M(E) * F_(c-1),     Hol_M(E) = < M \ {1} | holonomies of the cycles of Gamma_E >.

Here `c` is the number of components. `Hol_M(E)` has `b_1(Gamma_E)` relators, and
each decoder letter `x_s` equals the holonomy `w_s` of a tree path from its root.
Eliminating the memory letters along the memory difference graph instead gives
`U_E ≅ Hol_S(E) * F_(c'-1)`, and `Hol_S(E)` is the subgroup generated by the decoder
letters.

**Only the component of `1_S` matters.** Restricting the decoder to that component
keeps a forward-sufficient design with the same encoder. Strictness of a
realization is unchanged.

**Consequence.** Iterating that restriction with minimization shows: if
Gottschalk's conjecture fails, some design with a minimal forward partition and a
connected difference graph is strict over

    U_E = Hol_M(E) = < M \ {1} | b_1(Gamma_E) cycle holonomies >.

This host is generated by the encoder memory alone. Every decoder address is a
path holonomy of memory differences, and every reverse hinge word becomes
`w_s'^(-1) x_m'^(-1) x_m w_s`.

Proof: sections 1 and 2 of the artifact.

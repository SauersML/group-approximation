**Import (Jordan--Dickson).** For a field `F` and `m >= 2`, `PSL_m(F)` is simple
except for `PSL_2(F_2)` and `PSL_2(F_3)`. Wording as in K. Igusa, Brandeis
Math 131b notes, §15, Theorem 15.7: "For n ≥2, PSL(n, F) is simple with the
exception of PSL(2, 2) and PSL(2, 3)." That wording was read from a search
excerpt, not the full notes; the theorem is classical (see also K. Conrad,
*Simplicity of PSL_n(F)*). We use it for `F = Q`.

**`SL_m(Q)` is perfect and generated by root elements.** Over a field, row
reduction writes every element of `SL_m` as a product of elementary matrices
`e_ij(q)`.
- For `m >= 3` and `k ∉ {i,j}`, `e_ij(q) = [e_ik(q), e_kj(1)]`.
- For `m = 2` put `h = diag(2, 1/2)`. Then `h e_12(b) h^-1 = e_12(4b)`, so
  `[h, e_12(q/3)] = e_12(q)`; likewise for `e_21`.

**(1).** If `a/b != 0` lies in `ker φ`, then `φ(1)^a = φ(b · a/b) = 1`, so
`φ(1)` has finite order. Conversely, `φ(1)^a = 1` with `a != 0` puts `a` in the
kernel.

**(2).** The centre of `U_n(Q)` is the corner root group `{e_1n(q)} ≅ (Q,+)`.
In a nilpotent group `G`, a normal subgroup `N != 1` meets the centre
nontrivially: take `k` maximal with `M = [N, G, ..., G] != 1` (`k` brackets).
Then `M <= N` and `[M,G] = 1`. So `ker φ = 1` iff `ker φ` meets the centre
trivially, and (1) applies to the centre.

**(3).** Let `N` be normal and `T = {t_b} ≅ Q`. Conjugating by `x ↦ ax`
sends `t_b` to `t_(ab)`, so `N ∩ T` is `1` or `T`.
- If `N ∩ T = 1`, then `[N, T] <= N ∩ T = 1`. The centralizer of `T` is `T`
  itself (`x ↦ ax + b` commutes with `t_1` iff `a = 1`). So `N <= T`, hence
  `N = 1`.
- So every `N != 1` contains `T`, and `Aff(Q)/T ≅ Q^x` is abelian.

Hence `φ(t_1) != 1` forces `ker φ = 1`, and `φ(t_1) = 1` makes the image
abelian.

**(4).** Let `N` be normal in `SL_m(Q)` and `Z` its centre.
- If `N` maps to `1` in the simple group `PSL_m(Q)`, then `N <= Z`.
- Otherwise `NZ = SL_m(Q)`, and perfectness gives
  `SL_m(Q) = [NZ, NZ] = [N, N] <= N`.

`Z = {λI : λ in Q, λ^m = 1}`, which is `{I}` for odd `m` and `{±I}` for even
`m`. If `φ(e_12(1)) != 1`, then `ker φ` is central, and it is trivial when
`m` is odd, or when `m` is even and `φ(-I) != 1`.

**(5).** Let `N` be normal in `GL_n(Q)`. Then `N ∩ SL_n(Q)` is normal in
`SL_n(Q)`, so it is central in `SL_n(Q)` or equal to it.
- If it equals `SL_n(Q)`, then `N` contains `SL_n(Q)`.
- In the central case, fix `g ∈ N`. For `s ∈ SL_n(Q)`, `[g,s]` lies in
  `N ∩ SL_n(Q)`, which consists of central scalars, so
  `[g, st] = [g,s] · s[g,t]s^-1 = [g,s][g,t]`.
- Thus `s ↦ [g,s]` is a homomorphism from the perfect group `SL_n(Q)` to an
  abelian group, hence trivial. So `g` commutes with every `e_ij(1)` and is
  scalar.

So `ker φ` is scalar unless it contains `e_12(1)`, which gives (5).

**Consequence.** For odd `m`, (4) turns "homomorphism with `φ(e_12(1)) != 1`"
into "embedding". "Embeds in a finitely presented simple group" and "lies in
`B_A`" are inherited by subgroups, so `gl-n-q-targets-are-cofinal-in-n`
(item 3, with the infinitely many odd `m`) gives the root and its permutational
form.

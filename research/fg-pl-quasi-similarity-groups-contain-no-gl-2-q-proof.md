Each listed group `H` contains a copy `D` of `(Q,+)` together with elements that
act on `D` by multiplication by every element of a set `R_H ⊆ Q^x`.
- **`Aff(Q)`:** `D` = the translations, `R_H = Q^x`.
- **`B_2(Q)`, `GL_n(Q)` (`n >= 2`):** `D = {e_12(q)}` (upper unipotent in the
  first two coordinates), `diag(a,1,...,1)` acts by `a`, so `R_H = Q^x`.
- **`SL_n(Q)`, `PSL_n(Q)`, `PGL_n(Q)`:**
  - `D` = the image of `{e_12(q)}`. It is still `≅ (Q,+)`, because it meets the
    centre trivially: a nontrivial unipotent is not scalar.
  - `diag(a, a^-1, 1, ..., 1)` acts by `a^2`, so `R_H ⊇ {a^2 : a in Q^x}`.
  - In `PGL_n(Q)`, `diag(a,1,...,1)` acts by `a`, so `R_H = Q^x`.

**Proof of 1.**
- Suppose `H <= Γ`. By `pl-quasi-similarity-groups-scale-rational-lines-by-ratio`,
  every `r in R_H` equals `c(t)` for some `t in Γ`, so `R_H ⊆ c(Γ) ∩ Q^x`.
- In each case `R_H` contains `p^2` for every prime `p`. The subgroup generated by
  `-1` and finitely many primes does not.
- If `Γ` is finitely generated, `c(Γ)` is a finitely generated abelian group, and
  so is its subgroup `c(Γ) ∩ Q^x`. Its elements then involve only the finitely many
  primes appearing in a finite generating set.

**Proof of 2.** If `Γ` preserves orientation then `c(Γ) ⊆ R_{>0}`, but
`R_H ∋ -1` for `Aff(Q)`, `B_2(Q)`, `GL_n(Q)` (`diag(-1,1,...,1)`) and `PGL_n(Q)`.
∎

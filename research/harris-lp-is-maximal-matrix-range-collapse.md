**ESTABLISHED (Passer--Paulsen, specialized to Harris).**  Let a unital
C-star algebra `A` be generated by unitaries `u_1,...,u_n`.  Form Harris's
self-adjoint matrices `D,G in M_(n+2)(A)` and put

```text
c=(n+3)/2,                 T=(D-cI,G),
S=span{I,D,G}=span{I,T_1,T_2}.                         (HMR1)
```

Let `W(T)` be the matrix range of `T`.  For each `k`, let
`W^(k-max)(W(T))` be the largest matrix convex set agreeing with `W(T)`
through level `k`, and define

```text
gamma_k(T)=inf{r>=1: W^(k-max)(W(T)) subset r W(T)},
gamma(T)=lim_(k->infinity) gamma_k(T).                  (HMR2)
```

Then the following are equivalent:

```text
S has LP;
gamma(T)=1;
W^(k-max)(W(T)) -> W(T) uniformly over every matrix level;
for every epsilon>0, W(T) has a multiplicative
  (1+-epsilon) approximation by one finite free spectrahedron. (HMR3)
```

The interior hypothesis needed for the scaling formulation is automatic
for Harris's concrete matrices.  Write `a=(n+1)/2`.  Vector states on the
first and last diagonal blocks give `(-a,0)` and `(a,0)`.  Harris includes
the scalar edge `1 <-> n+2`; the two equal-weight vectors with relative
signs `+` and `-` give `(0,1)` and `(0,-1)`.  The scalar numerical range of
the self-adjoint pair is convex, so it contains the diamond spanned by
these four points and has zero in its interior.

There is also a basis-free formulation.  For an operator system `R`, set

```text
d_k(S)=sup ||phi||_cb,                                  (HMR4)
```

where the supremum is over all operator systems `R` and all unital
`k`-positive maps `phi:S->R`.  Aubrun--Davidson--Muller-Hermes--Paulsen--
Rahaman prove for finite-dimensional `S` that

```text
S has LP iff lim_(k->infinity) d_k(S)=1.                (HMR5)
```

Thus the three-dimensional endpoint is not merely the original quantified
quotient-lifting definition.  It is enough to prove a dimension-free
collapse estimate for the maximal matrix hulls, or equivalently that every
unital `k`-positive map out of the explicitly written span has cb norm
`1+o_k(1)`.  Pointwise approximation at each fixed matrix level is not
enough: the Hausdorff convergence in `(HMR3)` is uniform over all output
levels.

Primary sources: B. Passer and V. Paulsen,
[*Matrix range characterizations of operator system properties*](https://arxiv.org/abs/1912.06279),
Theorem 3.3 and Corollary 3.4; G. Aubrun et al.,
[*Completely Bounded Norms of k-positive Maps*](https://arxiv.org/abs/2401.12352),
Theorem 6.1; S. Harris,
[*Ubiquity of counterexamples to the Smith--Ward problem*](https://arxiv.org/abs/2607.11001),
Theorem 2.4.

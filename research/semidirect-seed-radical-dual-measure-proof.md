Full proof: Section 2 of the artifact, using the standard facts F1--F7 of Section 0. Each of F3, F4, F6 and F7 is
proved there.

**Homomorphism.** In `N_nu`, `u_a e_m u_a^* = e_(a.m)`, so `sigma(m,a) = e_m u_a` is a homomorphism
`G -> U(N_nu)`, with `tau(sigma(m,a)) = delta_(a,1) int e_m d nu`.

**(B1).** Compose `sigma` with a trace-preserving embedding. Then

```text
||e_(m_0) - 1||_2^2 = int |chi(m_0) - 1|^2 d nu > 0.
```

Also `tau(u_a) = 0` for `a != 1`, so `A` is hyperlinear.

**(B2).** Let `theta : G -> U(Q)` have `theta(m_0) != 1`.

1. The commutative C`*`-algebra generated by `theta(M)` is `C(Sigma)` for a closed `Sigma <= M^`. The trace becomes
   a measure `nu` with `int e_m d nu = tau(theta(m))`. Conjugation invariance of `tau` and uniqueness of Fourier
   coefficients (Stone--Weierstrass) make `nu` `A`-invariant. Moreover
   `int |chi(m_0) - 1|^2 d nu = ||theta(m_0) - 1||_2^2 > 0`.
2. F7 gives `alpha' : A -> U(Q_alpha)` with `tau(alpha'(a)) = delta_(a,1)`. It is built from separating
   representations, a trivial summand, tensor powers and a diagonal choice.
3. The diagonal tensor product `rho_l(g) = theta_(n_l)(g) (x) alpha'_(j_l)(pi(g))`, `pi(m,a) = a`, defines
   `rho : G -> U(Q_rho)` with `tau(rho(m,a)) = delta_(a,1) tau(theta(m)) = tau(sigma(m,a))`.
4. Equal traces on the group give a trace-preserving isomorphism `W^*(sigma(G)) = W^*(rho(G)) <= Q_rho` (GNS plus
   Kaplansky density).
5. `W^*(sigma(G))` contains the characters `e_m`, which generate `L^infinity(M^, nu)` by Stone--Weierstrass and
   weak`*` density of `C(M^)`. It also contains every `u_a`, so it is `N_nu`, and `N_nu` is Connes embeddable.

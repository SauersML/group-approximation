**ESTABLISHED** (route `lamp-preserving-automorphisms-tensor-lamp-roots-proof`;
elementary; builds on the established Lemma+ of `automorphic-compression-orbit-rigidity-proof`).

**Setting.**

- `Gamma` is finitely generated, `alpha` is in `Aut(Gamma)`, and `H <= Gamma` is a Chabauty limit of
  finite-index subgroups. Put `X = Gamma/H`.
- `k` is a field, `B = M_d(k)^(tensor X)` is the restricted tensor product, and `R = B x| Gamma`.
- `Gamma_0 <= Gamma` is finitely generated with `A = alpha(Gamma_0) <= Gamma_0`. `P` is a finite subset
  of `X`, and `Y_0 = Gamma_0 P`.
- `R_0` is generated by `M_d(k)` at the sites of `P` and by `u_s^(+-1)`, for `s` in a finite
  generating set of `Gamma_0`. Equivalently, `R_0 = sum_(gamma in Gamma_0) B_(Y_0) u_gamma`.
- `psi` is a ring automorphism of `R` with `psi(k 1) = k 1` and `psi(B) = B`. Write `beta = psi|_B`.
  Also `psi(u_gamma) = u_(alpha(gamma))` for all `gamma`, and `psi(R_0) <= R_0`.
- `z` is a unit of `B` commuting with `R_0`.

`beta` is **not** assumed to permute sites. It only has to satisfy `beta(gamma . b) = alpha(gamma) . beta(b)`,
which is forced by `psi(u_gamma b u_gamma^(-1)) = u_(alpha(gamma)) beta(b) u_(alpha(gamma))^(-1)`.

**Theorem.** `psi(z)` commutes with `R_0`. So the ideal `I` of (R5) is `0`.

**Invariant.** The finite-orbit site algebra `B_(Y_f)`, where `Y_f` is the union of the finitely many
finite `Gamma_0`-orbits inside `Y_0`. Intrinsically, it is the set of elements of `B_(Y_0)` whose
`Gamma_0`-orbit is finite. It is finite-dimensional.

**Death step.** Profinite density (Lemma+) shows that `beta` carries elements with finite
`Gamma_0`-orbit to elements with finite `Gamma_0`-orbit. So `beta(B_(Y_f)) <= B_(Y_f)`. A dimension
count turns this into equality. The root's image then centralizes `B_(Y_f)`. Its support avoids the
infinite orbits, and it is fixed by `Gamma_0` through the same permutation group as `A`.

**Casualties** (all are exactly matricial and simple, so they pass (R1)):

- site permutations: this is the old Corollary;
- `alpha`-twisted equivariant quantum cellular automata on the lamps (automorphisms of `B` that carry
  each local algebra `M_F` into some `M_(F')` with `F'` finite), composed with any site bijection. They
  may move supports arbitrarily far and need not be finite-depth circuits;
- in particular, lamp-dependent recodings of any site-bijection twist, provided `B` is preserved.

**What survives.** A tensor-lamp witness for `matricial-compression-ring-exists` must break at least
one of the following:

1. `psi(u_gamma) = u_(alpha(gamma))`, for example by a nontrivial lamp cocycle,
   `psi(u_gamma) = w_gamma u_(alpha(gamma))` with `w_gamma` in `U(B)` and not a coboundary on `Gamma_0`;
2. `psi(B) = B`, so that `psi` mixes lamps with group unitaries;
3. `z` in `B`, so the root has nonzero `u_gamma`-coefficients with `gamma != 1`;
4. `R_0` containing full site algebras, so it is generated by partial lamp elements;
5. approximability of `X` (then (R1) must come from somewhere else).

Item 1 is the cheapest next test. The proof uses `psi(u_gamma) = u_(alpha(gamma))` only through the
intertwining `beta(gamma . b) = alpha(gamma) . beta(b)`, in Steps 3 and 6. A cocycle replaces this by
`Ad(w_gamma)`, after which finite-orbit elements need not map to finite-orbit elements.

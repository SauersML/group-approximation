## Why sufficient

Artifact Section 2, Proposition 2.

- **Commutation.** `u H u^(-1)` is generated by `x_kl(SaT)`. Because `TS = 1`, `Q SaT = 0` and
  `SaT Q = 0`. So `1 + Q E_ij` and `1 + SaT E_kl` commute. That gives item (1).
- **The cell.** Conjugating by `u^(-1)` gives `K_0 <= C(H)`, and `c in K_0` since `u c u^(-1) = x_12(Q)`.
- **The lamps.**
  - For `j >= 1`, `K_j = <x_ik(e_(j-1,j-1))> <= H`.
  - For `j <= 0`, `K_j <= C(u^j H u^(-j)) <= C(H)`, because `H <= u^j H u^(-j)`.
  - For `i < j`, conjugating by `u^(-i)` reduces commutation to `K_0 <= C(H)` against `K_(j-i) <= H`.
- **Constants.** Split `x_ik(1) = x_ik(e_(j-1,j-1)) x_ik(1 - e_(j-1,j-1))`. The second factor commutes
  with `K_j`. The identity for `u^(-1) x_23(1) u` is the cell identity `u x_23(1) u^(-1) = x_23(ST)`.
- **Finitary kernel.** The symbol map kills `Q`, so every `K_j` lies in its kernel
  (`binary-jacobson-mark-dichotomy-holds-from-rank-two`).

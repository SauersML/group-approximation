Notation of the target; `µ = κ^G` on `X = X_κ`, and `1 = 1_G`.

**Item 1.**
- *Factor maps.* For `ξ ∈ Ind_λ(X)`, `π_ξ` is Borel and equivariant:
  `π_ξ(h·x)(g) = ξ(g^-1 h x) = π_ξ(x)(h^-1 g) = (h·π_ξ(x))(g)`. Since `{x : ξ(g^-1 x) = ℓ} = g·ξ_ℓ`, for distinct
  `g_1, …, g_n` we get `µ{π_ξ(x)(g_i) = ℓ_i for all i} = µ(∩_i g_i·ξ_(ℓ_i)) = ∏_i λ(ℓ_i)`. So `π_ξ` pushes `µ` to `λ^G`.
- *Inverse.* For `φ ∈ Fac_G(X, X_λ)` let `ξ^φ` have atoms `φ^-1{y : y(1) = ℓ}`. By equivariance
  `g·ξ^φ_ℓ = φ^-1{y : y(g) = ℓ}`, so the translates are independent with law `λ`. Also
  `φ(x)(g) = (g^-1·φ(x))(1) = φ(g^-1 x)(1)`, so `π_(ξ^φ) = φ`; and `ξ^(π_ξ) = ξ`.
- *Isometry.* `µ(ξ ≠ ζ) = µ{π_ξ(x)(1) ≠ π_ζ(x)(1)} = d(π_ξ, π_ζ)`. `d` is a metric modulo null sets: if
  `d(φ, ψ) = 0`, then `φ(x)(g) = φ(g^-1 x)(1)` and `ψ(x)(g) = ψ(g^-1 x)(1)` agree off a null set, for each of the
  countably many `g`.
- *Generation.* `σ-alg_G(ξ)` is generated by the sets `g·ξ_ℓ = π_ξ^-1{y(g) = ℓ}`, so it is `π_ξ^-1 B(L^G)`. A factor
  map between standard probability spaces is an isomorphism modulo null sets iff the pulled-back σ-algebra is
  `B(X)` modulo null sets. So `ξ` generates iff `π_ξ` is an isomorphism.

**Item 2.**
- *`d` controls every set.* Let `A` be a cylinder depending on the coordinates in a finite `W ⊆ G`. The set
  `φ^-1 A` depends only on the values `φ(x)(w) = φ(w^-1 x)(1)` for `w ∈ W`. So
  `µ(φ_n^-1 A Δ φ^-1 A) <= Σ_(w ∈ W) µ{φ_n(w^-1 x)(1) ≠ φ(w^-1 x)(1)} = |W|·d(φ_n, φ)`.
  Finite unions of cylinders are dense in the measure algebra of `λ^G`. If `λ^G(A Δ A') < δ`, then
  `µ(φ^-1 A Δ φ^-1 A') < δ` for every measure-preserving `φ`. So `d(φ_n, φ) → 0` gives
  `µ(φ_n^-1 A Δ φ^-1 A) → 0` for every Borel `A`.
- *Every set controls `d`.* Put `A_ℓ = {y : y(1) = ℓ}`. If `φ_n(x)(1) ≠ φ(x)(1) = ℓ`, then
  `x ∈ φ_n^-1 A_ℓ Δ φ^-1 A_ℓ`, so `d(φ_n, φ) <= Σ_ℓ µ(φ_n^-1 A_ℓ Δ φ^-1 A_ℓ)`.
- *Invariance.* Let `θ: X → X'` be an isomorphism of actions. Conjugation `φ ↦ θ φ θ^-1` is a bijection
  `End_G(X) → End_G(X')` carrying `Aut` onto `Aut`. It is a homeomorphism for the intrinsic topologies, because
  `(θ φ θ^-1)^-1 A' = θ(φ^-1(θ^-1 A'))` and `θ` preserves measure. So DENSE is an isomorphism invariant.

**Item 3.**
- *Action by isometries.* `T` commutes with `G`, so `φ ∘ T^-1` is equivariant. `S·(T·φ) = φ ∘ T^-1 ∘ S^-1 = (ST)·φ`,
  and `d(φ ∘ T^-1, ψ ∘ T^-1) = d(φ, ψ)` because `T^-1` preserves `µ`.
- *One orbit.* Let `φ, ψ` be isomorphisms and put `T = ψ^-1 ∘ φ ∈ Aut_G(X_κ)`. Then
  `T·φ = φ ∘ φ^-1 ∘ ψ = ψ`. And `T·φ` is an isomorphism whenever `φ` is.
- *Lemma.* Let a group `H` act by isometries on a metric space `(Y, d)`. Write `y ≼ z` if `y ∈ cl(H·z)`.
  - It is symmetric: `d(hz, y) < ε` gives `d(z, h^-1 y) < ε`.
  - It is transitive: `d(hz, y) < ε` and `d(kw, z) < ε` give `d(hkw, y) <= d(hkw, hz) + d(hz, y) < 2ε`.

  So if `cl(H·z) = Y`, then each `y` has `z ≼ y`, hence `w ≼ y` for every `w ∈ Y`, and `cl(H·y) = Y`.

**Item 4.** Let `𝒢 ⊆ Fac_G(X_κ, X_λ)` be the set of isomorphisms. By item 1, (a) says `𝒢` is dense.
- (a) ⇒ (b): `Fac_G(X_κ, X_λ) ≠ ∅` and density give `𝒢 ≠ ∅`, so `X_κ ≅ X_λ`. `𝒢` is one orbit (item 3) and dense,
  so by the lemma every orbit is dense.
- (b) ⇒ (c) is immediate.
- (c) ⇒ (a): by the lemma every orbit is dense. In particular `𝒢` is dense, and it is non-empty since `X_κ ≅ X_λ`.
- (a) ⇔ (d). Both contain `X_κ ≅ X_λ`, (a) by the first step. Fix an isomorphism `θ: X_κ → X_λ`.
  - `φ ↦ φ ∘ θ` is a bijection `End_G(X_λ) → Fac_G(X_κ, X_λ)`, with inverse `ψ ↦ ψ ∘ θ^-1`.
  - It is isometric: `µ{φθ(x)(1) ≠ φ'θ(x)(1)} = λ^G{φ(y)(1) ≠ φ'(y)(1)}`.
  - It maps `Aut_G(X_λ)` onto `𝒢`.

  So `𝒢` is dense iff `Aut_G(X_λ)` is dense in `End_G(X_λ)`.
- *Last sentence.* `id ∈ Fac_G(X_λ, X_λ)`, so the theorem applies to `(λ, λ)`, where (d) reads DENSE(`X_λ`).

**Item 5.** Let `s = h^Rok_sup(G) > 0` and `H(λ) > 0`.
- Choose `0 < a < min(s, H(λ), log 2)`, a two-point base `(A, p)` with `H(p) = a`, and a finite base `(B, q)` with
  `H(q) = H(λ) − a`. On `n` points the Shannon entropy takes every value in `[0, log n]`, by continuity.
- Put `κ = p × q`, so `H(κ) = H(λ)` and `X_κ ≅ X_λ` by `bernoulli-shifts-with-equal-base-entropy-are-isomorphic`.
- Item 3 of `iid-generators-not-dense-at-positive-rokhlin-supremum` applies to `X_κ`, because `a < s`. It says the
  generating partitions are not dense in `Ind_λ(X_κ)`: (a) fails.
- `G` is nonamenable, so `Fac_G(X_κ, X_λ) ≠ ∅` by `nonamenable-bernoulli-shifts-are-weakly-isomorphic`, and the
  theorem applies. Since `X_κ ≅ X_λ`, (d) fails only through DENSE(`X_λ`).
- Concretely, the isometry `φ ↦ φ ∘ θ` of item 4 carries a ball of `Ind_λ(X_κ)` without generators to a `d`-ball of
  `End_G(X_λ)` without automorphisms.

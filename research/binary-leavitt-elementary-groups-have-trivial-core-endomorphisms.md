## Statement

Let `L = L_(F_2)(1,2)`, with generators `s_1, s_2, t_1, t_2`, relations `t_i s_j = δ_ij` and
`s_1 t_1 + s_2 t_2 = 1`. Fix `n >= 3` and put `P = EL_n(L)`, the group generated by the
elementary matrices `e_ij(r)`, `i != j`, `r in L`. Let

    m(x) = s_1 x t_1   (x in L),        F(g) = I + m(g - I)   (g in P),

where `m` is applied entrywise. Then:

1. `P` is finitely generated, simple and has property (T).
2. `F` is an injective group endomorphism of `P`.
3. `F` is not surjective: `e_12(1)` is not in `F(P)`.
4. `F` has trivial core: the intersection of the `F^j(P)`, `j >= 0`, is `{I}`.

So **the answer to "does some finitely generated simple Kazhdan group admit an injective,
non-surjective endomorphism with trivial core?" is yes.** The unit-group form is
`u -> s_1 u t_1 + s_2 t_2` on `L^x`, which is isomorphic to `P` whenever `n >= 4` is a power
of `2` (the ring isomorphism `L ≅ M_2(L)` iterated, together with `EL_n(L) = GL_n(L)` from the
simplicity node).

## What this changes

- **For `fw-window-zero-descending-sign-forces-trivial-core`.** Its item 3 excludes
  co-Hopfian FW inputs from descending window zero. `P` is an FW input (Kazhdan implies FW)
  in the reduced class of `boone-higman-iff-simple-kazhdan-decidable-inputs` (finitely
  generated, simple, Kazhdan; solvable word problem, see the note below), and it is not
  co-Hopfian. So the endomorphism condition alone does not close
  window zero for the reduced class. What remains open is whether a genuine action with
  infinite supports realizes the descending relation `s ρ_g s^-1 = ρ_(F(g))`.
- **A calibration for that question.** The natural twisted-equivariant maps for `F` do not
  have cofinite image. Left multiplication by `s_1` on a Chen module, and prepending `1` on a
  tail class of infinite words (for the monomial copy of `V` in `L^x`), both satisfy
  `σ(ρ_g x) = ρ_(F(g)) σ(x)`, but their complements are infinite. A shell witness needs a
  cofinite image, and a linear action cannot give one: a proper subspace has infinite
  complement. So a witness, if it exists, must be a non-linear action.

**Note on the word problem.** Solvability of the word problem of `P` is not used above. It
holds because `P ≅ L^x` is a finitely generated group of units of an algebra with a
computable normal form; this is textbook and is not pinned here.

## Scope

- Nothing here says a descending window-zero shell action of `P` exists.
- The same corner map on `EL_n(R_L)` over the Leavitt resolvent ring is not treated: the
  argument needs the core `∩ s_1^j R t_1^j` to vanish, which is proved here only for `L`.

Proof (swarm-0917-w19-w19-titz-break, 2026-09-19). The notation is that of the target claim.

**Step 0: the image group.** Put `Λ = Π(K) ≤ U(Q)`.
- `Λ` is a quotient of `K`, so it has property (T). It is countable, since `K` is finitely
  generated by (T).
- Every finite quotient of `Λ` is a finite quotient of `K`, so `Λ` has no nontrivial finite
  quotient.
- **Finite-dimensional representations of `Λ` are trivial.** Let `σ : Λ → U(d)` be one. Its image
  is a finitely generated linear group, so it is residually finite by Mal'cev. It is also a quotient
  of `K`, so it has no nontrivial finite quotient. A residually finite group with no nontrivial
  finite quotient is trivial.
- The inclusion `Λ ⊆ U(Q)` extends to a unital *-homomorphism `C*(Λ) → Q`, with image `B`.
- We must show `Λ = 1`.

**Step 1: case (QD).** Let `B ⊆ A ⊆ Q` with `A` quasidiagonal. Then `B` is quasidiagonal, because
quasidiagonality passes to C*-subalgebras. By Step 0, `Λ` satisfies the hypotheses of
`kazhdan-groups-without-fd-reps-avoid-qd-unitary-groups`: property (T), and no nontrivial
finite-dimensional unitary representation. Its homomorphism `Λ ⊆ U(Q)` generates the
quasidiagonal algebra `B`, so it is trivial. Hence `Λ = 1`.

The covariant form is the special case `Q = A`, `Π|_K = ι`. It uses neither `β` nor `w`.

**Step 2: case (NUC).** Let `Q = ∏_n M_{k_n} / ⊕_n M_{k_n}`, with quotient map
`q : ∏_n M_{k_n} → Q`. Let `B ⊆ D ⊆ Q` with `D` separable and nuclear.
- Put `D_1 = D + C·1_Q`. It is separable, unital and nuclear, since the unitization of a nuclear
  algebra is nuclear.
- The inclusion `j : D_1 → Q` is a ucp map. It is nuclear because `D_1` is nuclear.
- **Choi--Effros lifting theorem** (Brown--Ozawa, *C*-algebras and finite-dimensional
  approximations*, Theorem C.3): a nuclear ucp map from a separable unital C*-algebra into a
  quotient `C/J` of a unital C*-algebra has a ucp lift to `C`.
- So there is a ucp `Φ = (φ_n)_n : D_1 → ∏_n M_{k_n}` with `q ∘ Φ = j`. Each `φ_n` is ucp into
  `M_{k_n}`.
- **Asymptotic multiplicativity.** For `x, y ∈ D_1`, `q(Φ(xy) − Φ(x)Φ(y)) = xy − xy = 0`. So
  `‖φ_n(xy) − φ_n(x)φ_n(y)‖ → 0`.
- **No collapse.** The corona norm is `‖q((a_n))‖ = limsup_n ‖a_n‖`. So
  `limsup_n ‖φ_n(x)‖ = ‖x‖` for `x ∈ D_1`.
- Put `θ_n = φ_n ∘ π_B : C*(Λ) → M_{k_n}`, where `π_B : C*(Λ) → B ⊆ D_1` is the map of Step 0.
  The maps `θ_n` are ucp and asymptotically multiplicative.
- For `g ∈ Λ \ {1}`, `g − 1 ≠ 0` in `Q`, so
  `limsup_n ‖θ_n(u_g) − I‖ = limsup_n ‖φ_n(g − 1)‖ = ‖g − 1‖_Q > 0`.
- So `Λ` meets the hypotheses of `weak-qd-kazhdan-quotientless-group-is-trivial`: countable,
  Kazhdan, weakly quasidiagonal through `(θ_n)`, and with no nontrivial finite quotient. Hence
  `Λ = 1`.

**Step 3: the consequence for nontrivial MF models.** Let `Π : K → U(Q)`, with `Q` the corona, be
nontrivial. By Step 1 with `A = C*(Π(K))`, the algebra `C*(Π(K))` is not quasidiagonal. By
Step 2, it is not contained in any separable nuclear subalgebra of `Q`. It is MF, since it is a
C*-subalgebra of the corona.

**Step 4: the named constructions.**
- In item 1 of the claim (the Pimsner--Voiculescu and Brown routes), `ι(K) ⊆ U(A)` with `A` AF or
  quasidiagonal, so Step 1 applies to `ι`.
- In item 2 (nuclear hosts), the model lands in a separable nuclear subalgebra of the corona, so
  Step 2 applies.
- In item 3 (RFD and exact-product models), `∏_n M_{k_n}` is quasidiagonal and RFD algebras are
  quasidiagonal, so Step 1 applies.
- In each case the restriction to `K` is trivial, so the model cannot refute (XMF), (EKL1), (EK1)
  or (LK3). ∎

**Remark (what was not used).** Step 2 needs only the local liftability of the inclusion
`B → Q`. The same argument therefore works whenever that inclusion is locally liftable. For
example, it works when `C*(K)` has Kirchberg's LLP, since a ucp map from an LLP algebra into a
quotient lifts on every finite-dimensional operator system, and `∏_n M_{k_n}` is injective. In
that case every MF model of `K` is trivial, so `Rad_MF(K) = K`. That case is already subsumed by
`llp-non-rf-kazhdan-group-is-non-hyperlinear` and is not claimed here.

**Remark (a second route to case (NUC)).** A separable nuclear C*-subalgebra `D` of the corona is
MF. By Blackadar--Kirchberg, a separable nuclear MF algebra is NF, and NF algebras are
quasidiagonal. So case (NUC) also follows from case (QD) with `A = D`. The Choi--Effros argument
of Step 2 is self-contained and avoids the Blackadar--Kirchberg theorem, but the two cases are not
logically independent.

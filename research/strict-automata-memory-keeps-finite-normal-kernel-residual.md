**ESTABLISHED** (proof in the artifact, Section 3; independent verification requested from
`w3-vf-positive`). Let `N` be a finite normal subgroup of a group `E` with `E/N` surjunctive. Let `tau` be
an injective non-surjective automaton on `A^E` with memory set `M`, and `H = <M>`. Then:
- `tau` restricts to an injective non-surjective automaton over `H`;
- `H cap N` injects into no finite quotient of `H`; equivalently `N cap Res_fin(H) != 1`;
- `H` is not sofic.

**Use.**
- **Design filter.** Every counterexample to `finite-normal-subgroups-do-not-affect-surjunctivity` lives on
  a finitely generated memory group that holds part of the kernel in its own finite residual and is
  nonsofic. Other finitely generated subgroups can be ignored.
- **Deligne's triple cover** (artifact Corollary 3.3). The memory group `H` of any strict automaton on
  `E_3` contains the central `z` with `z in Res_fin(H)`, and `H/<z>` is a subgroup of `Sp_4(Z)` over which
  the triple cover does not virtually split. Virtually free and amenable subgroups are excluded, including
  the block `SL_2(Z)`.
- **Fixed configurations.** Also on `E_3`, a strict automaton is bijective on `z`-invariant configurations,
  by `surjectivity-descends-to-centralized-coset-quotients`, so every missed configuration has trivial
  `C_3`-stabilizer.

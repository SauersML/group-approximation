**INVALIDATED RAW-SIZE PROPOSAL.**  Use the ambient matrix dimension, the
absolute rank of a word kernel, or the anonymous multiplicity of a finite
packet type to decide which native occurrence is compared with the Hecke
map or how deeply the comparison is imposed.

`fixed-type-and-raw-rank-selectors-do-not-evade-hecke-firewall` invalidates
this route.  Spectator amplification multiplies every absolute rank and
packet multiplicity while preserving all normalized word traces, all
normalized Hilbert--Schmidt defects, and every represented word algebra.
Consequently ordinary group relations cannot authenticate a branch which
reads raw matrix size or anonymous multiplicity.  A kernel or spectral cut
defined from an actual mixed word remains possible only through a uniform
normalized coercivity theorem; proving the required vanishing-loss theorem
is already the no-microstate step, not a consequence of raw rank.

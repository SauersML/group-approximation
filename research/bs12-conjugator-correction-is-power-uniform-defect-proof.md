All norms are operator norms, and all unitaries are finite-dimensional.
`Delta` and `I(B)` are as in `(PU0)` of the target.

## Item 1

**(PU1a).**  Let `C` be in `I(B)`.  Then `C B^k C^* = (C B C^*)^k = B^(2k)` for
every `k` in `Z`.  Hence

```text
||A B^k A^* - B^(2k)|| = ||A B^k A^* - C B^k C^*||
                       <= ||(A-C) B^k A^*|| + ||C B^k (A-C)^*||
                       <= 2 ||A-C||.
```

Taking the supremum over `k` and the infimum over `C` gives
`Delta(A,B) <= 2 dist(A,I(B))`.  If `I(B)` is empty the distance is `+infinity`
and there is nothing to prove.

**(PU1b).**  Let `G` be the closure of `{B^k : k in Z}` in `U(N)`.  It is a
compact abelian group, and `dg` is its normalized Haar measure.  The function
`g -> ||A g A^* - g^2||` is continuous and bounded by `Delta` on the dense
subgroup of powers of `B`, so it is bounded by `Delta` on all of `G`.  Put

```text
X = int_G g^2 A g^(-1) dg.
```

1. *Intertwining.*  Translation invariance of `dg` under `g -> B g` gives
   `B^2 X B^(-1) = int_G (Bg)^2 A (Bg)^(-1) dg = X`.  So `B^2 X = X B`.
2. *Closeness.*  For `g` in `G`,
   `g^2 A g^(-1) - A = (g^2 - A g A^*) A g^(-1)`, and `A g^(-1)` is unitary.
   Hence

   ```text
   ||X - A|| <= int_G ||g^2 A g^(-1) - A|| dg = int_G ||g^2 - A g A^*|| dg <= Delta.
   ```

   So every singular value of `X` lies in `[1-Delta, 1+Delta]`.  Since
   `Delta < 1`, `X` is invertible.
3. *The modulus commutes with the base.*  Taking adjoints in `B^2 X = X B`
   gives `X^* B^(-2) = B^(-1) X^*`, that is `B X^* = X^* B^2`.  Therefore

   ```text
   X^* X B = X^* B^2 X = B X^* X,
   ```

   so `X^*X` commutes with `B`.  By continuous functional calculus, so do
   `|X| = (X^*X)^(1/2)` and `|X|^(-1)`.
4. *Polar part.*  `C = X |X|^(-1)` is unitary, and

   ```text
   C B = X B |X|^(-1) = B^2 X |X|^(-1) = B^2 C.
   ```

   So `C B C^* = B^2`, and `C` is in `I(B)`.
5. *Distance.*  `C - X = C (1 - |X|)`, so `||C - X|| = ||1 - |X||| <= Delta`,
   because the eigenvalues of `|X|` are the singular values of `X`.  Hence
   `||C - A|| <= ||C - X|| + ||X - A|| <= 2 Delta`.

No hypothesis on `spec B` entered.  When `B` has finite order `o`, `G` is the
cyclic group of powers of `B`, and `X = (1/o) sum_(k<o) B^(2k) A B^(-k)`.  This
is the formula used by the script.

## Item 2: `(PUC) <=> (CGC)`

**`(PUC) => (CGC)`.**  Given `epsilon`, put
`eta = min(kappa_PUC(epsilon/2)/2, epsilon/2)`.  Let `(C_i, Z_(i+1))` be exact
packets in `U(M)` with `||Z_j - C_j|| <= eta` for every `j` in `Z/4`.  Since
`C_i` is in `I(Z_(i+1))`, `(PU1a)` gives

```text
Delta(Z_i, Z_(i+1)) <= 2 dist(Z_i, I(Z_(i+1))) <= 2 ||Z_i - C_i|| <= 2 eta <= kappa_PUC(epsilon/2).
```

So `(PUC)`, applied to `U_i = Z_i`, gives `||Z_i - 1|| <= epsilon/2`.  Hence
`||C_i - 1|| <= epsilon/2 + eta <= epsilon`.

**`(CGC) => (PUC)`.**  Given `epsilon`, put
`kappa = min(eta_CGC(epsilon/2), epsilon/2, 1/2)/2`.  Then `kappa <= 1/4 < 1`.
Let `U_0,...,U_3` in `U(M)` satisfy `Delta(U_i, U_(i+1)) <= kappa`.  By
`(PU1b)` there are `C_i` in `I(U_(i+1))` with `||C_i - U_i|| <= 2 kappa`.  Put
`Z_(i+1) = U_(i+1)`.  Then `(C_i, Z_(i+1))` are exact packets, and the seams
satisfy

```text
||Z_(i+1) - C_(i+1)|| = ||U_(i+1) - C_(i+1)|| <= 2 kappa <= eta_CGC(epsilon/2).
```

So `(CGC)` gives `||C_i - 1|| <= epsilon/2`.  Hence
`||U_i - 1|| <= epsilon/2 + 2 kappa <= epsilon`.

## Item 3: `(HMF5) <=> (PUU) and (CGC)`

**(a)**  Let `delta = delta_HMF5(epsilon)`.  A tuple with defect at most
`delta` has `||U_i - 1|| <= epsilon`.  Take `k = 0` and `V_i = 1`.  Then
`Delta(1,1) = 0`.

**(b)**  Let `delta = delta_TPC(epsilon/4)`.  For each `i`, the pair
`(U_i, U_(i+1))` has `BS(1,2)` defect at most `delta`.  So `(TPC)` gives an
exact packet in `U(N + k_i)` within `epsilon/4` of the padded pair.  Put
`k = max k_i`, and pad each packet by an identity block to `U(N+k)`.  Padding
by `1` keeps packets exact and keeps the distances.  This gives exact packets
`(C_i, Z_(i+1))` in `U(N+k)` with

```text
||C_i - (U_i (+) 1_k)|| <= epsilon/4,   ||Z_(i+1) - (U_(i+1) (+) 1_k)|| <= epsilon/4.
```

Put `V_j = Z_j`, the base produced by seam `j-1`.  Then
`||V_j - (U_j (+) 1_k)|| <= epsilon/4`.  By `(PU1a)`, since `C_i` is in `I(Z_(i+1))`,

```text
Delta(V_i, V_(i+1)) <= 2 ||Z_i - C_i|| <= 2 (||Z_i - U_i (+) 1_k|| + ||U_i (+) 1_k - C_i||) <= epsilon.
```

**(c)**  Given `epsilon`, let `kappa = kappa_PUC(epsilon/2)` (this exists by
item 2), `epsilon_1 = min(kappa, epsilon/2)`, and `delta = delta_PUU(epsilon_1)`.
A tuple `U` with defect at most `delta` has some `V` with
`||V_i - (U_i (+) 1_k)|| <= epsilon_1` and `Delta(V_i, V_(i+1)) <= epsilon_1 <= kappa`.
By `(PUC)`, `||V_i - 1|| <= epsilon/2`.  So
`||U_i - 1|| <= ||(U_i (+) 1_k) - 1|| <= epsilon/2 + epsilon_1 <= epsilon`.

**(d)**  This is item 2 of `higman-seam-gate-needs-only-padded-bs-correction`.

Combining: (a) and (d) give `(HMF5) => (PUU) and (CGC)`, and (c) gives the
converse.  Item 2 replaces `(CGC)` by `(PUC)`.

## Item 4: the twisted fine clock

Let `o` be odd, `w = exp(2 pi i/o)`, and `h(x) = 2^(-1) x + 1` on `Z/o`.  This
is a bijection with inverse `h^(-1)(y) = 2y - 2`.  Put `B e_x = w^x e_x` and
`A e_x = e_(h(x))`.  Then

```text
A B^k A^* e_y = A B^k e_(2y-2) = w^(k(2y-2)) e_y,
so A B^k A^* = w^(-2k) B^(2k).
```

Hence `||A B^k A^* - B^(2k)|| = |1 - w^(-2k)| = 2 |sin(2 pi k/o)|`.

- At `k = 1` this is `2 sin(2 pi/o)`, which tends to `0`.
- Since `o` is odd, `2k` runs over all of `Z/o`.  So

  ```text
  Delta(A,B) = max_m |1 - w^m| = 2 sin(pi (o-1)/(2o)) = 2 cos(pi/(2o)).
  ```

For `o >= 3` this is at least `sqrt(3)`.  By `(PU1a)`,
`dist(A, I(B)) >= cos(pi/(2o)) >= sqrt(3)/2`.

When the base may move, the pair is exactly correctable.  `Z = w^(-2) B`
satisfies `A Z A^* = w^(-4) B^2 = Z^2` and `||Z - B|| = 2 sin(2 pi/o)`.

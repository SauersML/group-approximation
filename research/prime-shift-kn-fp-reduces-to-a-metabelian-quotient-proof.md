Lane proof. Notation as in the claim; `n >= 2`.

**Item 1.**
- `σ` is multiplicative on `Q` with `σ(0) = 0`, so `σ_n(t w) = σ(t) σ_n(w)`.
  Linear maps satisfy `g(t w) = t g(w)`.
- If `k(t w) = σ^a(t) k(w)` and `k'(t w) = σ^b(t) k'(w)` for all `t, w`, then
  `k'k(t w) = σ^(a+b)(t) k'k(w)`. So every element of `K_n` has such an exponent.
- Uniqueness: `t = 0` gives `k(0) = 0`, so `k(w) != 0` for `w != 0`. Then two
  exponents `a, b` give `σ^a = σ^b` on `Q`, and `σ^m(2) = p_m != 2` for `m != 0`.
- So `d` is well defined, and the composition rule makes it a homomorphism.
  `d(σ_n^m) = m`, so the sequence splits.
- `K_n = <GL_n(Q), σ_n>` (item 1 of the construction node). So `ker d` is the
  normal closure of `GL_n(Q)`, generated by the conjugates `σ_n^j GL_n(Q) σ_n^-j`.

**Item 2.**
- By item 1, each `k in K_n^0` commutes with every scalar `tI`, and
  `tI in GL_n(Q) ⊆ K_n^0`.
- Conversely, let `z` be central in `K_n^0`. Then `z` commutes with `GL_n(Q)`,
  whose only fixed point is `0`, so `z(0) = 0`.
- Let `H = Stab_(GL_n(Q))(e_1)`. It contains `x_1j(b)`, and `x_1j(b) w = w + b w_j e_1`.
  So `Fix(H) = Q e_1`, and `z(e_1) = c e_1` with `c != 0`.
- For `w = g e_1`: `z(w) = g z(e_1) = c w`. So `z = cI`.
- `σ_n (tI) σ_n^-1 = σ(t) I`, so the centre is normal in `K_n`.

**Item 3.**
- For `q = diag(q_1,...,q_n)`: `q x_ij(1) q^-1 = x_ij(q_i/q_j)`. So `N` contains
  every `x_ij(b)`, `b in Q`, hence `SL_n(Q)`. It also contains `diag(-1,1,...,1)`.
  So `N ⊇ ker(|det| : GL_n(Q) -> Q_>0)`.
- Hence `N ∩ GL_n(Q) = |det|^-1(I_n)`, and `I_n` is a subgroup.
- `σ_n diag(r,1,...,1) σ_n^-1 = diag(σ(r),1,...,1)` and `N` is normal, so
  `σ^(±1)(I_n) = I_n`.
- `d` kills `N`, which is generated by conjugates of `GL_n(Z) ⊆ ker d`. So `d`
  induces a split surjection `K_n/N -> Z`, and its kernel is `K_n^0/N`.
- Let `Ḡ` be the image of `GL_n(Q)`. Write `g in GL_n(Q)` as
  `g = diag(|det g|,1,...,1) · s` with `s in ker|det| ⊆ N`. Then `σ_n^(±1) g σ_n^(∓1)`
  lies in `diag(σ^(±1)|det g|,1,...,1) · N`. So `σ̄` normalizes `Ḡ`, acting as `σ`.
- So `K_n^0/N`, generated by the `σ̄^j Ḡ σ̄^-j`, equals
  `Ḡ ≅ GL_n(Q)/(N ∩ GL_n(Q)) ≅ Q_>0/I_n`, via `|det|`. The base is generated by
  `|det e| = 2`.

**Item 4.**
- `N` is the normal closure of a finite generating set of `GL_n(Z)`. So if `K_n`
  is finitely presented, so is `G = K_n/N = M ⋊ <t>`, where `M = Q_>0/I_n` is
  written additively. Let `χ : G -> Z` be the projection.
- **Bieri--Strebel.** A finitely presented group with an epimorphism
  `χ` onto `Z` is an HNN extension `<B, t | t C t^-1 = D>`, where:
  - `B ⊆ ker χ` is finitely generated;
  - `C, D ⊆ B` are finitely generated;
  - `χ(t) = 1`.

  The source is R. Bieri and R. Strebel, *Almost finitely presented soluble
  groups*, Comment. Math. Helv. 53 (1978); the theorem number is not pinned.
- **The HNN is ascending.** Suppose `C != B` and `D != B`.
  - By Bass--Serre theory, `B` and `tBt^-1` generate
    `B *_(D) tBt^-1` inside `ker χ`. Here `D = tCt^-1` is proper in both factors.
  - Take `b in B \ D` and `b' in tBt^-1 \ D`. By the normal form theorem
    `b b' != b' b`.
  - But `ker χ = M` is abelian. So `C = B` or `D = B`.
- **`M` is finitely generated on one side.**
  - Say `D = B`. Then `t^-1 B t = C ⊆ B`, the chain `t^i B t^-i` increases, and
    every element of `ker χ` has the form `t^i b t^-i`. So `ker χ = ∪_(i>=0) t^i B t^-i`.
  - `M` is abelian, so conjugation by `t` is the module action of `t`. Hence
    `M = Z[t]·B` is finitely generated over `Z[t]`.
  - `C = B` gives `Z[t^-1]` in the same way.
- **Translation to relations.** `M` is cyclic over `Z[t,t^-1]`, generated by
  `m_0`, the class of `2`.
  - If `M` is finitely generated over `Z[t]`, then `M = Σ_(j>=-K) Z t^j m_0` for
    some `K`. So `t^(-K-1) m_0` is a finite integer combination of `t^j m_0`,
    `j >= -K`.
  - Applying `t^(K+1)` gives `m_0 = Σ_(j>=1) a_j t^j m_0`. Multiplicatively,
    `2/r in I_n` for `r = Π_(j>=1) p_j^(a_j)`, that is,
    `e · diag(r,1,...,1)^-1 in N`.
  - Conversely, such an `r` gives `t^-1 m_0 in Z[t] m_0`. Induction then puts
    every `t^-k m_0` in `Z[t] m_0`.
  - `Z[t^-1]` is the mirror case, with `j <= -1`.
- **The contrapositive.** If every element of `I_n` is a square, then `2/r` is
  not in `I_n`, since its exponent at `p_0` is `1`. So `K_n` is not finitely
  presented.

**Item 5.**
- `GL_n(Z)` preserves the content: `g` and `g^-1` are integral, so `gw` and `w`
  have the same `Z`-span of coordinates.
- Let `w in D` and `λ = c(w)`. Then `w/λ` is a primitive integral vector.
  `GL_n(Z)` is transitive on primitive vectors, so `λ e_n = g w` for some
  `g in GL_n(Z)`, and `λ e_n in D`.
- Since `n >= 2`, `e(λ e_n) = λ e_n`. So
  `φ(F(w)) = φ(F(λ e_n)) = F(e λ e_n) = F(λ e_n) = F(w)`.

**Item 6.**
- `v_p(c(w)) = min_i v_p(w_i)` over the nonzero coordinates, and
  `v_(σ(p))(σ(x)) = v_p(x)`. Also `σ(Q_>0) = Q_>0`.
- So `c(g w) = c(w)` for `g in GL_n(Z)`, `c(2w) = 2 c(w)`, and
  `c(σ_n w) = σ(c(w))`.
- By the composition rule of item 1, every `k in K_n'` has a map
  `ψ_k : r -> a σ^m(r)` on `Q_>0` with `c(k w) = ψ_k(c(w))`. `ψ_k` is determined
  by `k`, because `c` maps onto `Q_>0`.
- So `ψ` is a homomorphism onto `Γ = Q_>0 ⋊_σ Z ≅ Z ≀ Z`, and it kills `GL_n(Z)`.
- `K_n'/<<GL_n(Z)>>` is generated by the images `a` of `2I` and `s` of `σ_n`.
  Since `s^j a s^-j` is the image of `p_j I`, and scalars commute, it is a
  quotient of `<a, s | [a, s^j a s^-j], j in Z> = Z ≀ Z`.
- The composite `Z ≀ Z -> K_n'/<<GL_n(Z)>> -> Γ` is the identity on generators.
  So the first map is injective, and both maps are isomorphisms.
- `Z ≀ Z` is not finitely presented (G. Baumslag, Math. Z. 75, 1961), and
  `GL_n(Z)` is finitely generated. So `K_n'` is not finitely presented.
- `c(e e_1) = 2 != 1 = c(e e_2)`, while `c(e_1) = c(e_2)`. Every element of
  `K_n'` maps vectors of equal content to vectors of equal content, so `e ∉ K_n'`.

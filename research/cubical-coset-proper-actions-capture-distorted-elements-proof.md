Notation is as in the target. All statements are elementary and self-contained.

**Step 0 (length).**
- `ghA Δ A ⊆ (ghA Δ gA) ∪ (gA Δ A)`, and `|ghA Δ gA| = |hA Δ A|`. So
  `ℓ(gh) ≤ ℓ(g) + ℓ(h)`.
- `g^{-1}A Δ A = g^{-1}(A Δ gA)`, so `ℓ(g^{-1}) = ℓ(g)`.
- Let `L` be generated by a finite symmetric set `S`, and let `K = max_{s ∈ S} ℓ(s)`. Then
  `ℓ(g) ≤ K |g|_L` for `g ∈ L`.

**Step 1 (bounded-or-linear).** Fix `f` and decompose `X` into `⟨f⟩`-orbits `O`. Put
`A_O = A ∩ O`. Then `f^N A Δ A` is the disjoint union of the sets `f^N A_O Δ A_O`.
- *Active orbits.* If `O` misses the finite set `fA Δ A`, then `f A_O = A_O`, so
  `f^N A_O = A_O` for all `N`. Only finitely many orbits meet `fA Δ A`; call them active.
- *Finite active orbit.* It contributes at most `|O|`.
- *Infinite active orbit.* Choose `x_0 ∈ O` and identify `O` with `Z` by `f^k x_0 ↔ k`. Then
  `A_O` becomes a set `S ⊆ Z` and `f^N A_O` becomes `S + N`.
  - `(S + 1) Δ S` corresponds to `fA_O Δ A_O ⊆ fA Δ A`, so it is finite. So `1_S(k−1) ≠ 1_S(k)`
    for only finitely many `k`. Hence `1_S` is constant, equal to `ε_+`, for `k ≫ 0`, and
    constant, equal to `ε_−`, for `k ≪ 0`.
  - Let `S_0` be `∅`, `Z`, `[0, ∞)` or `(−∞, 0)` according to `(ε_−, ε_+)`. Then `S Δ S_0` is
    finite, of size `c_O`, and `|(S+N) Δ S|` differs from `|(S_0 + N) Δ S_0|` by at most `2c_O`.
  - `|(S_0+N) Δ S_0|` is `0` if `ε_− = ε_+`, and `N` otherwise.
- Summing over the finitely many active orbits: `|ℓ(f^N) − mN| ≤ C` for `N ≥ 0`, where `m` is
  the number of infinite active orbits with `ε_− ≠ ε_+`, and `C` is the sum of `|O|` over the
  finite active orbits plus `2c_O` over the infinite ones. This proves item 1.

**Step 2 (capture).** Let `f` have infinite order and be distorted in `L`.
- By Step 0, `ℓ(f^N) ≤ K |f^N|_L = o(N)`. By Step 1, `m = 0`, so `ℓ(f^N) ≤ C` for all `N ≥ 0`.
- By properness modulo `H`, `{ℓ ≤ C} ⊆ g_1H ∪ ... ∪ g_rH`.
- Among the `r + 1` elements `f^0, f^1, ..., f^r`, two lie in one coset: `f^a H = f^b H` with
  `0 ≤ a < b ≤ r`. Then `f^{b−a} ∈ H`, so `d = b − a` works, with `1 ≤ d ≤ r`. This proves
  item 2.

**Step 3 (no cubical transversal).** Let `f` be an infinite-order element distorted in `L`.
- If some commensurating action were proper modulo `H`, Step 2 would give `f^d ∈ H` with
  `d ≥ 1`.
- `f^d` has infinite order, and it is distorted in `L`: `|f^{dN}|_L / N = d · |f^{dN}|_L / (dN) → 0`.
- This contradicts the hypothesis on `H`. This proves item 3. ∎

**Remarks.**
- Normality of `H` is not used, and neither is finiteness of the number of `G`-orbits on `X`.
- The hypothesis that `X` carries finitely many active `⟨f⟩`-orbits is automatic for a single
  commensurated set. It fails for *weighted* sums `Σ_j w_j |gA_j Δ A_j|` over infinitely many
  commensurating actions (a general cnd function), which is exactly why the transversal half
  of the split has to be non-cubical for an undistorted `H`.

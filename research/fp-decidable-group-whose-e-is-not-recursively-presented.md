## Statement

There is a finitely presented group `G` with solvable word problem such that `J_1(G) ⊴ G * ⟨x⟩`, the set of one-variable mixed identities, is co-r.e. but not r.e. Hence
`E(G) ≅ (G * Z)/J_1(G)` is not recursively presented, and it embeds in no finitely presented group. With a
recursively presented `H_0` in step 1 and Higman's theorem in place of Clapham's, `J_1(G)` becomes `Π_2`-complete,
the largest complexity possible for finitely presented `G`.

## Three lemmas

**Lemma 1 (amalgam detects cores).** Let `K` be a group, `A ≤ K`, and `G = K *_A (A × ⟨b⟩)`. For `c ∈ K`:

    [x^{-1} c x, b] ∈ J_1(G)   iff   c ∈ Core_K(A) = ⋂_{k∈K} k A k^{-1}.

- (⇐) `N = Core_K(A)` is normal in `K` and lies in `A`, which `b` centralizes. So `N ⊴ ⟨K, b⟩ = G`, and each `g^{-1}cg` lies in `N ⊆ C_G(b)`.
- (⇒) If `k^{-1}ck ∉ A` for some `k ∈ K`, then `(k^{-1}ck)·b·(k^{-1}ck)^{-1}·b^{-1}` alternates between `K ∖ A` and `(A×⟨b⟩) ∖ A`. By the normal form theorem it is nontrivial.

**Lemma 2 (cores in a Mihailova mapping torus).** Let `H = ⟨Y | R⟩` be a finite presentation, `F = F(Y)`,
`p: F → H`, and `ψ ∈ Aut(F)`. Put
- `M = {(u,v) ∈ F × F : p(u) = p(v)}`;
- `K = (F × F) ⋊ ⟨s⟩`, with `s(u,v)s^{-1} = (u, ψ(v))`.

Then `K` is finitely presented, `M` is generated by the finite set `{(y,y) : y ∈ Y} ∪ {(1,r) : r ∈ R}`, and for `W ∈ F`

    (1, W) ∈ Core_K(M)   iff   p(ψ^n(W)) = 1 for every n ∈ Z.

*Proof.*
- **Generation.** `(u,v) = (u,u)(1,u^{-1}v)` with `u^{-1}v ∈ ⟨⟨R⟩⟩`, and `(1, g r g^{-1}) = (g,g)(1,r)(g,g)^{-1}`.
- **Presentation.** Two free bases, commutation between them, and `s y s^{-1} = y`, `s y' s^{-1} = ψ(y')` on the two copies.
- **The core.** Every `k ∈ K` is `(g,h)s^n`, and `k(1,W)k^{-1} = (1, h ψ^n(W) h^{-1})`. This lies in `M` iff `p(ψ^n(W)) = 1`. ∎

**Lemma 3 (a cyclic Π_1 pattern).** There are a finitely generated group `H_0` with a recursive presentation and a
solvable word problem, elements `a, b, c ∈ H_0`, and a computable family `w_e(z) ∈ H_0 * ⟨z⟩`, such that

    w_e(a^n) = 1 in H_0 for all n ∈ Z   iff   the machine φ_e(e) never halts.

*Proof.*
- **Set-up.** Let `L = F(a,b)` and `b_j = a^j b a^{-j}`. These form a free basis of `⟨⟨b⟩⟩`.
- **The recursive set.** Let `T = {2^e(2n+1) : e ≥ 0, n ∈ Z, φ_e(e) does not halt within |n| steps}`. Each nonzero `j` is `2^e(2n+1)` for exactly one pair `(e,n)`.
- **The group.** Let `C = ⟨b_j : j ∈ T⟩` and `H_0 = L *_C (C × ⟨c⟩)`.
  - `H_0` is recursively presented: relators `[c, b_j]` for `j ∈ T`.
  - `u ∈ L` lies in `C` iff its `a`-exponent sum is 0 and its expression in the basis `(b_j)` uses only `j ∈ T`. This is decidable, so `H_0` has solvable word problem by normal forms.
- **Commutation.** `[c, b_j] = 1` iff `j ∈ T`. For `j ∉ T`, `b_j ∉ C`, and Lemma 1's alternating-word argument applies.
- **The words.** Put `w_e(z) = [c, z^{2^{e+1}} b_{2^e} z^{-2^{e+1}}]`. Then `w_e(a^n) = [c, b_{2^e(2n+1)}]`, which is `1` iff `φ_e(e)` has not halted within `|n|` steps. ∎

## Construction

1. **Embed.** By Clapham's theorem, `H_0 ≤ H` with `H` finitely presented with solvable word problem. Write
   `H = ⟨X | R⟩` and fix words `α, β, γ` in `X` for `a, b, c`.
2. **Add the parameter letter.** `Y = X ∪ {z}`, `R' = R ∪ {z}`, so `p(z) = 1`. Let `ψ ∈ Aut(F(Y))` fix `X` and send `z ↦ zα`. Then `ψ^n(z) = zα^n` for all `n ∈ Z`, so `p(ψ^n(z)) = a^n`.
3. **The words.** `W_e = w_e(z)` with `a, b, c` replaced by `α, β, γ`. Then `p(ψ^n(W_e)) = w_e(a^n)`, since `ψ^n` fixes `α, β, γ`.
4. **The group.** Build `K ⊇ M` as in Lemma 2 from `⟨Y | R'⟩` and `ψ`, and put `G = K *_M (M × ⟨b'⟩)`. `G` is finitely presented: `K` is, and `M` is finitely generated.
5. **The identities.** Put `Ω_e = [x^{-1}(1,W_e)x, b'] ∈ G * ⟨x⟩`. By Lemmas 1–3,

       Ω_e ∈ J_1(G)   iff   ∀n p(ψ^n W_e) = 1   iff   ∀n w_e(a^n) = 1   iff   φ_e(e) never halts.

## Proof of the statement

- **Not r.e.** `e ↦ Ω_e` is computable. If the words of `J_1(G)` were r.e., so would be `{e : φ_e(e) never halts}`, which is not.
- **Solvable word problem.**
  - `K` has solvable word problem: `(g,h)s^n` is trivial iff `n = 0` and `g, h` are freely trivial.
  - Membership in `M` is decidable: `(g,h)s^n ∈ M` iff `n = 0` and `p(g) = p(h)`, and `H` has solvable word problem.
  - So `G` has solvable word problem by the normal form theorem.
  - Hence `J_1(G)` is co-r.e. (item 2 of `e-of-finitely-presented-group-is-recursively-presented`), and not decidable.
- **E(G).** `E(G)` is not recursively presented (item 1 of that node). By Higman's embedding theorem it embeds in no finitely presented group.
- **Π_2 variant.** Replace `T` by the r.e. set `{2^e(2n+1) : φ_e(|n|) halts}`. Then `H_0` is recursively presented, and Higman's theorem embeds it in a finitely presented `H`. Lemma 2 needs no decidability, and `{e : Ω_e ∈ J_1(G)}` is the `Π_2`-complete set of total machines. `J_1(G)` is always `Π_2` for finitely presented `G`.

## Remarks

- **What changed relative to the finitely generated example.** A mixed identity quantifies over the whole group, so it does not pass to overgroups. That was the gap recorded as Attempt 2 of the question node. Here the only quantifier that matters ranges over the cyclic group `⟨a⟩`, which survives any embedding. The Mihailova mapping torus converts "for all `n`" into "for all `k ∈ K`" (Lemma 2), and the amalgam converts that into a one-variable mixed identity (Lemma 1).
- **The general principle (Lemma 1).** For finitely presented `K` and finitely generated `A ≤ K`, a non-r.e. normal core `Core_K(A)` gives a finitely presented `G` with non-r.e. `J_1(G)`.
- **Relation to `mixed-identities-encode-normal-closure-commutation`.** Here `[N_{(1,W_e)}, N_{b'}] = 1` iff `Ω_e ∈ J_1(G)`, so `G` is also a finitely presented decidable group with undecidable normal-closure commutation.

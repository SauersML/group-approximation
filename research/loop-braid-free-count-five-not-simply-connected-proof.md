Artifact §5.2 and §6.

1. **Setup.**
   - `P = PLB_n` acts on `Y = Y_n(F; v, w)` with strict fundamental domain
     `Q_Y = OM(K_5) * {(v,w), (w,v)}` and pointwise-fixing cabling stabilizers. This restricts the
     setup of the colimit claim, step 1, to a P-invariant full subcomplex.
   - `OM(K_5)` is connected, so its suspension `Q_Y` is simply connected.
   - Y is connected: `P` is generated by the stabilizers of vertices of `Q_Y`, since every `A_ij`
     fixes some pair among 5 free rings avoiding `{i, j}`.
2. **If Y were simply connected**, then P would be the colimit of the stabilizers over `Q_Y`.
   - This is K. S. Brown, *Presentations for groups acting on simply-connected complexes*,
     JPAA 32 (1984); in the strict-fundamental-domain form, Bridson–Haefliger II.12.20.
   - Then `H_1(colim) ≅ H_1(P) = Z^{n(n−1)}`, which is torsion-free.
3. **Computation.**
   - `H_1(colim_{Q_Y})` is `⊕_v H_1(P_v)` modulo the edge identifications. Abelianization commutes
     with colimits, and triangle groups factor through edges.
   - The edge-to-vertex maps are the abelianized Lemma 5.1 of the colimit claim:
     `A_pf ↦ A_pa + A_pb`, `A_fq ↦ A_aq + A_bq`, `A_pq ↦ A_pq`.
   - The script computes the corank of the integer relation matrix modulo 2, 3, 5, 7 and 1000003.
   - For `(n, |F|) = (7,0), (8,1), (9,2)` it finds rank `n(n−1)` modulo every prime except 3, where
     it finds `n(n−1) + 2`. So `H_1(colim)` has nonzero 3-torsion. This contradicts step 2, which
     proves (i) for the tested `(n, |F|)`.
   - **Sanity check.** The same code over `Q_F` returns exactly `n(n−1)`, torsion-free, at
     N = 7, 8, as the colimit claim predicts.
4. **All n ≥ 7.** The relation matrix depends only on N. The ring set enters only through the free
   rings and the passive forbidden rings, which contribute the same block for every n; this was
   checked for n = 7, 8, 9.
   - Honest gap: this uniformity is observed for n ≤ 9 and argued structurally; it is not proved
     for all n.
   - The fully proved content of (i) is therefore `n ∈ {7, 8, 9}`.
5. **(ii) from (i).** Put `X^0 = X_n(F ∪ {v, w})`, so `n − |F| = 7`.
   - Y is `X^0` with cones attached on the links `lk(b)` of the type-`{v, w}` vertices b.
   - These links are family members of free count 5 (artifact Lemma 2.1), hence connected (Lemma
     3.1).
   - Van Kampen then makes `π_1(X^0) → π_1(Y)` onto, so `π_1(X^0) ≠ 0`.

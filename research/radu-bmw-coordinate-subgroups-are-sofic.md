**ESTABLISHED** by `radu-bmw-coordinate-subgroups-sofic-proof`.

Let `Gamma_R = <a,b,c,x,y,z | involutions, axax, ayay, azbz, bxbx, bycy, cxcz>` be Radu's BMW lattice
(`radu-bmw-lattice-embeds-in-titz-witzel-kernel`), `A = <a,b,c>` and `V = <x,y,z>`. Put

```text
P_y  = <a, b, c, y>,        P_xz = <a, b, c, x, z>.
```

**Theorem.**
1. `P_y = A ⋊ <y>`, with `y` swapping `b` and `c`, and it is virtually free.
2. `P_xz` consists of the elements whose vertical normal-form part is a word in `x, z`. The
   even-`c` subgroup `A_ev` of `A` is normal in `P_xz`, and `P_xz / A_ev` embeds in `D_infinity`.
3. Both are proper and sofic.
4. For a set `V'` of vertical letters, `<A, V'>` is `A`, `P_y`, `P_xz` or `Gamma_R`. For any nonempty
   set `A'` of horizontal letters, `<V, A'> = Gamma_R`.

**Screen.** An automaton whose memory lies in a sofic subgroup is surjunctive, and composites of
surjunctive automata are surjunctive (`strict-composites-have-strict-factors`). So a strict factor of
any automaton on `Gamma_R` has memory contained in no conjugate of `A`, `V`, `P_y`, `P_xz` or a
dihedral `<h, v>`. In particular some memory element has `y` in its vertical normal-form part, and
some has `x` or `z`. There is no horizontal analogue.

Proof: Section 4 of the artifact.

Let `G` be a finitely generated group with solvable word problem. Then `G`
embeds in a finitely generated simple group `S` with solvable word problem in
which every action on a tree has a global fixed point.

By Serre's criterion (*Trees*, §I.6.1), a countable group has property FA
exactly when it is finitely generated, has no quotient `Z`, and is not a
nontrivial amalgam. So an infinite finitely generated simple group has FA
exactly when it is not a nontrivial amalgam. An HNN extension maps onto `Z`,
so it is already excluded.

## Why this matters

It is the single missing prerequisite for part (D) of
`finitary-permanence-closures-collapse-boone-higman-to-base`. If it holds,
then no reduction of `boone-higman-conjecture` can reach every decidable input
from a base class by closure under subgroups, extensions, products, directed
unions and graphs of groups in any mixture. The base class would already host
every decidable group.

If it fails, some decidable input has all its decidable simple envelopes split
as amalgams or HNN extensions. Such an input is the only place where mixing
tree steps with infinitary steps could do real work in a permanence reduction.

## Attempts

1. **Square the envelope (2026-09-17).** `S wr C_2` has FA
   (`fg-perfect-wreath-c2-has-property-fa`), but it is not simple. Its normal
   subgroup `S x S` is where an extension step deposits the probe. `S x S`
   has FA only if `S` does: act through the first coordinate. So the square
   does not help. *Dies* at the normal subgroup `S x S`.
2. **Property (T) hosts (2026-09-17).** `lef-wp-groups-have-decidable-simple-kazhdan-lef-hosts`
   settles the claim for LEF inputs. Its lamplighter host needs a LEF
   overgroup. Hull's small-cancellation construction in
   `countable-group-embeds-in-fg-simple-kazhdan-group` gives no word problem
   control. The maximal normal subgroup in its last step is chosen through a
   maximality argument, with no effectivity recorded. *Open* for non-LEF inputs.
3. **Helly generation in Thompson-like hosts (2026-09-17).** The tool: if a
   group is generated by finitely many FA subgroups whose pairwise joins have
   FA, then it has FA. The fixed-point sets are pairwise-intersecting subtrees,
   so they have a common vertex (Serre, *Trees*, §I.6.5).

   Thompson's group `V` is reported to have FA (K. Brown; D. Farley), and so
   are the Brin--Thompson groups `nV` (arXiv:1504.06680). These locators were
   seen through search and not read from source.

   For a host that twists an FA copy of `S wr C_2` into `V` on a cone, such as
   twisted Brin--Thompson or Röver--Nekrashevych type groups, the natural
   generators are subgroups supported on cones. Their pairwise joins are rigid
   stabilizers of unions of cones, and those are isomorphic to the whole host.
   So the pairwise-join hypothesis is the conclusion again. *Dies* at the
   pairwise-join step for cone-supported generators. Generators whose joins are
   genuinely smaller have not been found.
4. **Bounded products (2026-09-17).** Suppose `S = A_1 A_2 ... A_k` setwise,
   with each `A_i` having FA. Let `x_i` be a vertex fixed by `A_i` and `v` any
   vertex. For `g = a_1 ... a_k`, we have
   `d(g v, v) <= Σ_i d(a_i v, v) <= 2 Σ_i d(v, x_i)`. So orbits are bounded,
   and `S` has a fixed point (Serre, *Trees*, §I.6.5). This criterion needs a
   simple decidable host that is a bounded product of FA subgroups containing
   the input, and no candidate is known. *Open.*
5. **From finitely presented simple envelopes.** Boone--Higman would give a
   finitely presented simple envelope. Those can split (Burger--Mozes
   lattices), so the conjecture does not obviously imply this claim. *Open.*
6. **Import property NL for twisted Brin--Thompson groups (2026-09-17).**
   Fournier-Facio--Wu--Zaremsky (arXiv:2603.24687v2, Theorem 6.4) prove that
   every `SV_G` has property NL. With Serre's lemma, every finitely generated
   `SV_G` has FA (`twisted-brin-thompson-groups-have-property-fa`). The host
   `G.V_G` is finitely generated and simple, contains `G`, and has solvable
   word problem when `G` does (`self-twisted-bt-group-fp-embedding-iff-solvable-wp`).
   *Succeeds* (`decidable-simple-fa-host-via-self-twisted-brin-thompson`).
   Here is how the imported proof avoids Attempt 3's pairwise-join obstacle:
   - uniform perfectness bounds quasimorphisms, which excludes focal and
     oriented lineal actions;
   - relative simplicity excludes general-type actions.

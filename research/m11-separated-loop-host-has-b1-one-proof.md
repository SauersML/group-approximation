**Conventions.** Right actions: `(xw)^g = x^{π_g} w^{g|_x}` and `(gh)|_v = g|_v h|_{v^g}`.
`g@v` acts as `g` below `v` and trivially elsewhere. For finitary `π`,
`π^{−1}(g@x)π = g@(x^π)`. Since `α` is finitary, `(bα)|_x = b|_x`, so
`bα = (b, α, β, 1, …, 1)·α`.

**Step 1 (item 1).**

- `R_0` is fully self-replicating (`tits-hosts-for-transitive-local-actions` item 6). So
  `(bα)@5 ∈ R_0 ⊆ R'`.
- `c'` and `(bα)@5` fix level 1, and their sections differ only at `5`. So
  `c' · ((bα)@5)^{−1} = c'@4`. Script check (1) confirms this at depth 4.
- `M_11` is transitive, so conjugating by finitary elements gives `c'@x ∈ R'` for every
  `x`. Also `g@x ∈ R_0` for `g ∈ {α, β, b}`. So `R'@x ⊆ R'`.
- The states `c', bα, b, α, β` lie in `R'`, so `R'` is self-similar. Its root image is `M_11`,
  since `b` and `c'` have trivial root. Therefore `St_{R'}(1) = ∏_x R'@x`, and
  `R' = R'^X ⋊ M_11`.
- **Activity.** The nontrivial level-`n` sections of `c'` are:
  - `c'` at `4^n`;
  - `bα` at `4^{n−1}5`;
  - `b`, `α` or `β` at `4^k 5 1^j z`, with `z ∈ {1, 2, 3}`.

  There are `O(n)` of them. The other generators are bounded. So the activity is linear, and
  `R'` is amenable by Amir–Angel–Virág. ∎

**Step 2 (item 2).** `c'` fixes level 1, so `c'^m|_4 = c'^m` and `c'^m|_5 = (bα)^m`. By
Lemma 1 of `m11-odometer-free-linear-host-h1-is-z55-squared-proof`, `bα` has infinite
order. So `c'^m ≠ 1` for every `m ≠ 0`, and the elements `c'^m`, which equal their own
sections at `4`, lie in no finite nucleus. So `R'` is not contracting. ∎

**Step 3 (item 3).** The automaton has exactly two cycles: `b → b` on letter `1`, and
`c' → c'` on letter `4`. Every other path ends in a finitary state, and then in `1`.

- **Ray `1^∞`.** `Ω_1 = X*1^∞`, and (Ω) holds because all generators are finite-state and
  bounded along `1^∞`.
  - The stable sections are `c(b, 1^∞) = b` and `c(c', 4^k 5 1^∞) = b`, the latter through
    `bα → b`.
  - All others are trivial. So `C = {b^{±1}}`, and `H_{1^∞} = ⟨b⟩ ≅ C_55`, by item 2 of
    `m11-odometer-free-linear-host-h1-is-z55-squared`.
- **Ray `4^∞`.** `Ω_4 = X*4^∞`.
  - `b` has section `1` at `4`, and so do `α` and `β`.
  - Along `4^k 5 w`, the state `bα` gives `b|_{w_1}`. This is eventually trivial, because
    `w` ends in `4^∞` and `b` loops only on `1`.
  - So the only nontrivial stable sections are `c(c'^{±1}, 4^∞) = c'^{±1}`. So
    `C = {c'^{±1}}`, and `H_{4^∞} = ⟨c'⟩ ≅ Z` by Step 2.
- **Any other periodic ray** `ζ = (x_1 ⋯ x_p)^∞`, regrouped as in item 3 there. A state
  whose section along the period is itself lies on a cycle read along the period word. So
  it is `b` with period word `1^p`, or `c'` with period word `4^p`. For `ζ ≠ 1^∞, 4^∞` the
  eventual sections are therefore trivial, and `H_ζ = 1`.

All three kinds of loop group are finitely presented. ∎

**Step 4 (item 4).**

- **(FS) at `4^∞`.** By Step 3, a generator has a nontrivial stable section at `η ∈ Ω_4`
  only for `s = c'^{±1}` and `η = 4^∞`. So (FS) holds, with support `{4^∞}`.
- **The character.** By item 3 of
  `fp-self-similar-finitely-supported-loops-give-characters`, with `t = c'` and
  `y = 4`, the loop character `Φ : R' → H_{4^∞}^{ab} = Z` is onto, and `Φ(c') = 1`. Also
  `Φ(α) = Φ(β) = Φ(b) = 0`, since these generators have empty support. So `Φ` is the
  `c'`-exponent sum `e`.
- **The rest of `H_1`.** `H_1(R'; Z)` is generated by `[b]` and `[c']`, because `M_11` is
  perfect. `[b]` has order dividing `55`, because `b^{55} = 1`. The map `e` splits off
  `Z[c']`. So `H_1(R'; Z) = Z[c'] ⊕ ⟨[b]⟩`, and `b_1(R') = 1`.
- **Script.**
  - Check (3) verifies the cocycle `κ(w, η) = c'^{K}` on 1460 random pairs of a word and an
    end `η = t 4^∞`, at a deep prefix.
  - Check (4a) verifies `Σ_η κ = e` on 2000 random words.
  - Check (4b): the 10 freely reduced words of length at most 5 that are trivial at depth 3
    all have `c'`-exponent `0`. ∎

**Step 5 (item 5).** `R' ≅ R' ≀_X M_11`, and `M_11 ≤ Alt(11)` because `M_11` is simple.
Also `H_1(R'; Q) ≠ 0`. So item 4 of the loop-character theorem applies with `d = 11`:

- `R'` is not `FP_{10}` over `Q`;
- the Tits host is not `FP_{10}` over `Q`, by the Bieri induction given there.

For `FP_2`, item 3(d) of `fully-self-replicating-fp-infinity-groups-are-acyclic` needs
`b_1 ≤ 1`, which holds. The excess space `E_2` needs two degree-1 classes or an even-degree
class, and there is one odd class over `Q`. The ray-loop test passes by Step 3. ∎

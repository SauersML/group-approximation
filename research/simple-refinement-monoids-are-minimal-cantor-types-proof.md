`<=` is the algebraic order.  Parts 1--3 are those of
`wehrung-countable-refinement-monoids-group-measurable`.  Corollary 2.7 of
Ortega--Perera--Rordam (recorded in `opr-mixed-simple-refinement-monoid`): a
conical simple refinement monoid is atomless iff it is not `Z^+`.

**Riesz decomposition.**  In a refinement monoid, `x <= y_1 + ... + y_n` gives
`x = x_1 + ... + x_n` with `x_i <= y_i`.  To see this, write
`x + z = y_1 + (y_2 + ... + y_n)`, refine, and induct on `n`.

**Step 1: halving.**  `e` is not an atom, so `e = x + y` with `x, y != 0`.
Simplicity gives `x <= n y`, and Riesz gives `x = x_1 + ... + x_n` with
`x_i <= y`.  By conicality some `a = x_i` is nonzero.  Then `a <= x` and
`a <= y`, so `2a <= x + y = e`, and simplicity gives `e <= m a` for some `m`.

**Step 2: Wehrung.**
* Part 1 gives a countable unital Boolean ring `B` and a groupoid-induced
  V-measure `mu: B -> M` with `mu(1) = e`.
* By Step 1 and part 2, `mu` is group-induced.
* The range of `mu` is the lower set `{x : x <= e}`, by the V-condition.
  Every `x in M` satisfies `x <= m e`, so Riesz writes `x` as a sum of
  elements of the range.  Hence the range generates `M`.
* For each of the countably many pairs `(a, b)` in `B` with `mu(a) = mu(b)`,
  fix finitely many witnessing automorphisms in `Aut(B, mu)`.  Let `Gamma` be
  the countable group they generate.  The action of `Gamma` on `B` is
  `mu`-exhaustive.
* Part 3 then gives an isomorphism `Z^+<B>//Gamma -> M`, `[a] -> mu(a)`,
  which sends `[1]` to `e`.

**Step 3: Stone duality.**
* Let `X` be the space of ultrafilters of `B`.  It is compact,
  zero-dimensional and metrizable, since `B` is countable.
* `a -> X_a` is an isomorphism from `B` onto the clopen algebra of `X`, and
  `Gamma` acts by homeomorphisms with `gamma X_a = X_(gamma a)`.
* Every `f in C(X, Z^+)` is a finite sum of clopen indicators.  So `C(X, Z^+)`
  is the commutative monoid with generators `1_A` and relations
  `1_(empty) = 0`, `1_(A ⊔ A') = 1_A + 1_A'`.
* So the presentation of `Z^+<B>//Gamma` is the quotient of `C(X, Z^+)` by the
  congruence generated by `1_A ≈ 1_(gamma A)`.
* That congruence equals `~`:
  * `~` is additive.
  * `~` is transitive.  Given two chains of pieces, pass to a clopen partition
    on which every membership pattern is constant, and match pieces cell by
    cell.
  * `~` contains the generators.
  * Every `f ~ g` is a sum of generating pairs `1_(A_i) ≈ 1_(gamma_i A_i)`.
* Hence `S(X, Gamma) ≅ Z^+<B>//Gamma ≅ M`, with `[1_X] -> e`.  This is the
  presentation of the type semigroup of the transformation groupoid in
  Ara--Bonicke--Bosa--Li (arXiv:2001.00376, page 9, relations (1)--(3)).

**Step 4: the Cantor space.**
* Suppose `x in X` is isolated.  Then `{x} = X_b` for an atom `b` of `B`, and
  `mu(b) != 0` because `mu` is a measure.
* If `mu(b) = p + q` with `p, q != 0`, the V-condition splits
  `b = b_1 direct_sum b_2` with `mu(b_1) = p != 0` and `mu(b_2) = q != 0`.
  This is impossible for an atom.
* So `mu(b)` is an atom of `M`, contradicting Corollary 2.7.
* Hence `X` has no isolated points, and by Brouwer's theorem `X` is the Cantor
  space.

**Step 5: minimality.**
* Let `U` be a nonempty open `Gamma`-invariant set, and `C ⊆ U` a nonempty
  clopen set.
* `[1_C] = mu(c) != 0` is an order unit, so `1_X + h ~ n 1_C` for some `n` and
  some `h`.  That is, `1_X + h = sum_i 1_(A_i)` and
  `n 1_C = sum_i 1_(gamma_i A_i)`.
* Every `gamma_i A_i` lies in `C ⊆ U`.  So `A_i ⊆ gamma_i^(-1) U = U`, and the
  `A_i` cover `X`.
* Hence `U = X`.  Every nonempty invariant open set is `X`, and the action is
  minimal.

**Step 6: measures and states.**
* An invariant Borel probability measure `nu` gives `s([f]) = ∫ f d nu`.  This
  is well defined by invariance, additive, and `s(e) = s([1_X]) = 1`.
* Conversely, a state with `s(e) = 1` gives a finitely additive invariant
  `nu(A) = s([1_A])` on clopen sets with `nu(X) = 1`.
* A clopen set covered by countably many disjoint clopen sets is covered by
  finitely many (compactness), so `nu` is countably additive on the clopen
  algebra.  By Caratheodory it extends uniquely to an invariant Borel
  probability measure.
* The two constructions are inverse to each other.  Ara--Bonicke--Bosa--Li,
  Lemma 2.3, is the groupoid version.

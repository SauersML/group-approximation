Verbatim up to typesetting:

- **Definition 4.1** (label `def:houghton_like`, line 895): "Let $G\le\Sym(\N)$ be shift-similar. For $n\in \N$,
  let $H_n(G)$ be the group of bijections from $[n]\times\N$ to itself given as follows: ... Map $[n]\times\N$ to
  itself by sending $M_+$ to $M_-$ via some bijection $\sigma$, and for each $1\le k\le n$ sending $Q(k,M_+)$ to
  $Q(k,M_-)$ via $\beta_{k,M_-}\circ g_k \circ \beta_{k,M_+}^{-1}$ for some $g_k\in G$." Here `Q(k,M)` is
  `({k} x N) \ M`, and `beta_{k,M} : N -> Q(k,M)` is its increasing enumeration (Section 2, line 302 on).
- **Observation 5.1** (label `obs:G_embed`, line 1022): "For any shift-similar group $G\le\Sym(\N)$ and any
  $n\in\N$, the map $(g_1,\dots,g_n)\mapsto [\emptyset,(g_1,\dots,g_n),\emptyset]$ is an injective homomorphism
  $G^n\to H_n(G)$."
- **Proposition 5.3** (label `prop:H1_equal`, line 1042): "Let $G\le\Sym(\N)$ be a strongly shift-similar group.
  Then $H_1(G)=G$."
- **Proposition 5.5** (label `prop:HnG_shift_sim`, line 1060): "Let $G\le\Sym(\N)$ be shift-similar. Then for any
  $n\in\N$, the Houghton-like group $H_n(G)$ admits a strongly shift-similar representation. Moreover, for any
  $m,n\in\N$ we have $H_m(H_n(G))\cong H_{mn}(G)$." Its proof uses $\xi(k,i) = k+(i-1)n$. It states: "Since
  $H_n(G)$ contains $\Symfin([n]\times\N)$ and $\omega$ preserves size of support, $\omega^{-1}(H_n(G))$ contains
  $\Symfin(\N)$."
- **Proposition 5.10** (label `prop:gens`, line 1149): "Let $G\le \Sym(\N)$ be shift-similar and let $n\ge 2$.
  Then the Houghton-like group $H_n(G)$ is generated by the copies of $H_n$ and $G^n$ referenced above."
- **Corollary 5.11** (label `cor:fin_gen`, line 1161): "For $n\ge 2$, if $G$ is finitely generated then so is
  $H_n(G)$."
- **Definition 3.17** (label `def:strong`, line 668): "Call an infinite shift-similar group $G\le\Sym(\N)$
  \emph{strongly shift-similar} if $\shift_\infty$ is surjective."
- **Lemma 3.19** (label `lem:strong_shift1_surj`, line 680): "If $G\le\Sym(\N)$ is a strongly shift-similar group,
  then the function $\shift_j\colon G\to G$ is surjective for all $j\in\N$."
- **Question 5.13** (label `quest:inherit_fin_props`, line 1187): "If a shift-similar group $G$ is finitely presented
  and $n\ge 3$, then is $H_n(G)$ finitely presented? If $G$ is of type $\F_m$ and $n\ge m+1$, then is $H_n(G)$ of type
  $\F_m$? If $G$ is strongly shift-similar, then do these results hold for all $n$?"

**Conventions.** The source uses `N = {1, 2, ...}`. Nodes of this graph that use `N = {0, 1, ...}` transport by
`n -> n+1`. That bijection is order preserving, so shift-similarity and the maps `psi_j` transport with it.

**Source read 2026-09-13.** R. Meyer and G. Nadareishvili, *A universal
coefficient theorem for actions of finite groups on C\*-algebras*,
arXiv:2406.11787v2 (5 Dec 2025). Text was extracted on MSI with ghostscript
`txtwrite`. Their reference [1] is Y. Arano and Y. Kubota, *A categorical
perspective on the Atiyah–Segal completion theorem in KK-theory*, J. Noncommut.
Geom. 12 (2018), 779–821.

- **Definition, introduction.** The equivariant bootstrap class is "the
  subcategory of all objects that are KK^G-equivalent to a G-action on a
  separable C∗-algebra of Type I."
- **Theorem 2.1 ([1, Corollary 3.13.(1)]).** "Let G be a finite group. If
  A ∈ KK^G is such that Res^H_G(A) ≅ 0 for all cyclic subgroups H ⊆ G, then
  already A ≅ 0 in KK^G."
- **Theorem 3.1.** "Let G be a finite group. Then A ∈ KK^G belongs to the
  localising subcategory of KK^G that is generated by C(G/H)⊗A for cyclic
  subgroups H ⊆ G."
- **Corollary 3.2.** "An object A in KK^G belongs to the equivariant bootstrap
  class if and only if Res^H_G(A) belongs to the equivariant bootstrap class in
  KK^H for each cyclic subgroup H ⊆ G."
- **Corollary 3.3.** "The objects C(G/H) for cyclic subgroups H ⊆ G generate
  the equivariant bootstrap class in KK^G."
- **Introduction, item 4 and the open converse.** "Incidentally, the results of
  Arano and Kubota [1] also imply that a G-action belongs to the G-equivariant
  bootstrap class if and only if the restrictions of the action belong to the
  H-equivariant bootstrap class for all cyclic subgroups H ⊆ G. This implies
  that A and A⋊H for cyclic subgroups H ⊆ G are in the bootstrap class in KK.
  We do not know whether this necessary condition is sufficient as well."
- **Before Corollary 3.5.** "The following corollary relates certain conditions
  that are clearly necessary for A∈KK^G to belong to the equivariant bootstrap
  class. We do not know whether they are also sufficient."

No later version or follow-up settling the converse was found. The check was
bounded: a text search of 2406.11787v2 and of the square-free sequel
arXiv:2604.12529v2 (25 Jun 2026) for "do not know" and "sufficient". The sequel

reviewed).

## Statement

KMS notation (arXiv:1204.6506v5 §4.1, `gq/src/kms/KMS-322.tex`, lines 922–1075):
`G(M) = T ⋊ Q`, where `T = ⟨⟨x_u : u ∈ U⟩⟩` is abelian of exponent `p`, written
additively as an `F_p[Q]`-module. Let `I ⊂ F_p[Q]` be the augmentation ideal and suppose
the machine has `K ≥ 1` counters.
1. `T = I·T`, that is, `T/[T, Q] = 0`.
2. Every `Q`-invariant homomorphism from `T` to an abelian group is zero.
3. Let `Q` act self-similarly on any tree `T_X`, let `L` be an abelian group, and let
   `ι: T → L^{X^*}` be a `Q`-equivariant homomorphism with restriction-closed image.
   Then `ι = 0`. In particular `T` has no self-similar module structure, and
   `kms-configuration-modules-carry-self-similar-structures` is false for every machine.

## Proof

1. Additively, `[x, g] = x(g − 1)`. The module `T` is generated by the `x_u`.
   - If `u` contains some `A_i`, write `u = u'A_i`. Then G5a gives
     `x_u = [x_{u'}, A_i] = x_{u'}(A_i − 1) ∈ IT`.
   - Otherwise `u = q_j`. G5b with `i = 1` gives `x_{q_j}(a_1 − 1) = x_{q_j}a_1'`, so
     `x_{q_j} = x_{q_j}(a_1 − 1) − x_{q_j}(a_1' − 1) ∈ IT`.
2. An invariant homomorphism `λ` kills `x(g − 1)` for all `x` and `g`, hence kills `IT = T`.
3. `λ = ev_∅ ∘ ι` is `Q`-invariant, because `Q` fixes the root. So `λ = 0` by 2.
   Restriction-closure gives `ev_w ∘ ι = ev_∅ ∘ ι ∘ ρ_w` with `ρ_w(T) ⊆ T`, so every
   evaluation vanishes and `ι = 0`. ∎

## Remarks

- The same argument applies to the lamp ring `R_1 = F_p[a^{±1}, (a^{-1} − 1)^{-1}]` of each
  one-counter top factor `B_i`, since `a − 1` is a unit. Yet `B_i` is self-similar
  (affine action on `F_p[[X]]`). There `Q` does not act on positions only: it mixes lamp
  digits with positions, and the root functional is not invariant. So the obstruction is
  specific to the lamp-digit shape "`Q` on positions, `T` on lamps". It says nothing
  about other self-similar actions of `G(M)`.
- The affine shape is excluded separately for hard machines by
  `affine-self-similar-groups-are-function-field-linear`.

Let

```text
0 -> J -> A -> B -> 0
```

be a full extension such that `J` is a separable stable AF algebra and `B`
is a nonzero separable nuclear O-infinity-stable C-star algebra.  Then

```text
dim_nuc(A) = 1.
```

In particular, `A` automatically satisfies the hereditary commutative-shadow
hypothesis of Problem LXXXI and its nuclear dimension has the required value.
This class contains genuinely non-type-I algebras, including the
Toeplitz--Cuntz algebras `T_n`, `2 <= n < infinity`.

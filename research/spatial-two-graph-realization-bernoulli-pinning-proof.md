The full proof is Sections 0–3 of the artifact: Lemmas 1.1–1.3, Lemma 2.1, Theorem 3.1 and
Corollary 3.2. It is self-contained and uses only the definitions of `G_2^n`, of the path
space of a 2-graph and of Gelfand's spectral radius formula.

1. **Lemma 1.1.** Put `ν_p = μ_p∘h`. Then `ν_p(λA) = ∫_A exp D_p(ι(λy, d(λ), y)) dν_p`.
   - `ι(Z(λ, s(λ)))` is a compact bisection, because `h` is injective.
   - Cover it by basic bisections `[u,v]`. There `μ_p` has density `w_p(u)/w_p(v)`.
2. **Lemma 1.2 (Perron pinning).** If the Radon–Nikodym cocycle is
   `a d_1 + b d_2 + H∘r - H∘s`, then `e^{-H}ν` scales by `e^{aj}` along degree-`(j,0)`
   cylinders.
   - Summing over the partition gives `m_- e^{aj}‖M_1^j‖_Σ ≤ const ≤ m_+ e^{aj}‖M_1^j‖_Σ`.
   - So `e^a ρ(M_1) = 1`, and likewise for colour 2.
3. **Lemma 1.3.** `d_1` and `d_2` are independent in `H^1`: a coboundary is bounded along
   `σ^{(j,0)}`, and `d_1` is not.
4. **Theorem, Steps 1–3.** If every `[N^ε_i∘ι] = α^ε_i[d_1] + β^ε_i[d_2]`, then
   `Σ_i α^1_i log p_i + α^0_i log(1-p_i) = -log ρ(M_1)` for all `p ∈ (0,1)^n`.
   Differentiating in `p_i` gives `α^ε_i = 0`, and likewise `β^ε_i = 0`. So the offset
   cocycles `c_i∘ι` have continuous, hence bounded, transfer functions.
5. **Lemma 2.1 (bounded fibres).** Take a subgroupoid generated by finitely many compact
   bisections whose offsets have bounded transfers `F_i`.
   - Replace `F_i` by `⌊F_i⌋`. The difference is integer-valued, so the transfer identity
     survives.
   - Induction on word length shows every `g` with source `x` is
     `(P(rg) w, c(g), P(x) w)`, with canonical bricks `P(x)_i = x_i|_{L+F_i(x)}` of bounded
     length.
   - So source fibres have at most `2^{n(D+2M+1)}` elements.
6. **Theorem, Steps 4–5.** `ι(G_Λ)` is generated by the images of the edge bisections. The
   `ι(λy, (j,0), y)` have distinct ranges, so column sums of `M_1^j` are bounded and
   `ρ(M_1) ≤ 1`, a contradiction.
7. **Corollary 3.2.** Each `N^ε_i∘ι` is locally constant, so rigidity puts its class in the
   degree plane, which contradicts (i).

**Setup.**
* `J = F_2<S,T | TS = 1>`, `n >= 2`, `E = EL_n(J)` acting on `V_+ = F_2^(N x {1..n})` (finitely supported), as in
  `leavitt-corner-trace-gate-collapses-to-jacobson-hyperlinearity`.
* `X_+ = Hom(V_+, F_2) = (F_2^n)^N` with Haar measure `mu`. `E` acts by `g.xi = xi o g^(-1)`. `R_E` is its orbit
  relation, a countable p.m.p. relation.
* `A = F_2[x, x^(-1)]`, `K = F_2((x^(-1)))` (Laurent series in `x^(-1)`), with Haar measure `m` on `K^n`.
* `Γ_n = A^n x| EL_n(A)` acts on `K^n` by `(w, a).y = a y + w`.
* `D = x^(-1) F_2[[x^(-1)]]^n`, the open unit ball, with `m(D) = 1`. `R_Γ|_D` is the restriction of the orbit relation.

**Theorem.**
1. **(Identification.)** Using the residue pairing `<y, p> = coefficient of x^(-1) in y^T p`, the map `y -> <y, .>` is a
   measure-preserving isomorphism `(D, m) -> (X_+, mu)`. Off a countable invariant set it carries `R_Γ|_D` onto `R_E`.
2. **(The model is free and residually finite.)**
   * `Γ_n` acts on `(K^n, m)` essentially freely and preserves `m`.
   * `Γ_n <= SL_(n+1)(A)` is linear, hence residually finite whenever it is finitely generated.
   * It is finitely generated for `n >= 3`.
3. **(Sofic transfer.)** If `R_Γ|_D` is sofic, then `E` is sofic.
4. **(CE transfer.)** If the von Neumann algebra `L(R_Γ|_D)` is Connes-embeddable, then `E` is hyperlinear. In
   particular the Haar fixed-point character `phi_1` is then CE.

**Corollary (what a non-approximability proof for `EL_n(J)` must produce).**
* If `EL_n(J)` is not sofic, then the free affine action of the residually finite linear group `Γ_n` on the
  Laurent-series space `F_2((1/x))^n` has a restricted orbit relation that is **not sofic**.
* If `EL_n(J)` is not hyperlinear, which is the Toeplitz survivor class of `agent-leavitt-not-bcs-negative-root-corner`
  at `n = 20`, then that relation has a **non-CE** von Neumann algebra.

So every route to non-hyperlinearity of `EL_20(J)` has to pass through a non-CE orbit relation of an affine action of an
S-arithmetic group over `F_2[x, x^(-1)]`. Conversely, one sofic approximation of that action makes `EL_n(J)` sofic for
every `n`, including `EL_3(J)` (`binary-jacobson-el3-is-sofic`).

**Where the natural approximations stop (recorded, not part of the theorem).** `Γ_n` is generated by two halves:
* `Γ_+ = A^n x| EL_n(F_2[x])` is the increasing union of the groups `x^(-k) F_2[x]^n x| EL_n(F_2[x])`. Each of these
  translates by a cocompact lattice that `EL_n(F_2[x])` preserves. So it descends to an automorphism action on the
  compact group `K^n / x^(-k) F_2[x]^n`, which has dense periodic points. This is the truncation side, carrying the
  polynomial Toeplitz subgroup `EL_n(F_2[S])` and the tails.
* `Γ_- = A^n x| EL_n(F_2[x^(-1)])`. On `D` it restricts to the relation of `D_fin x| EL_n(F_2[x^(-1)])`, where
  `D_fin = D ∩ A^n`. That group preserves every ball `x^(-k) D`, so the relation is profinite. This is the corona
  side, carrying `EL_n(F_2[T])`.

Each half has its own finite approximation scheme, by invariant lattices on one side and invariant balls on the other.
They do not fit together:
* no ball `x^(-k) D` is invariant under `EL_n(F_2[x])`, since `x_12(x^j)` is unbounded;
* `EL_n(A)` has property (FA) for `n >= 3`, so the join is not an amalgam. This is the relation-level form of the mirror
barrier of `jacobson-toeplitz-extension-is-a-mirror-quotient-of-a-lef-group`. Whether `R_Γ|_D` is sofic is open.

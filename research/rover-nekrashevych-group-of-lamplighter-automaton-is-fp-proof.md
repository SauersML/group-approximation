Conventions are those of `rover-nekrashevych-fp-iff-finite-lift-presentation`: `g(xw) = g(x) g|_x(w)` and
`(gh)|_x = g|_{h(x)} h|_x`. Here `S = {a, b, a^{-1}, b^{-1}}` is closed under sections and inverses, `F = F(a, b)`,
and `Ĝ = F/K_∞`.

## 1. `Ĝ` has injective recursion

`K_∞ = ⟨⟨∅⟩⟩_lift` is section-closed, by (1b) of the Theorem A route with `R = ∅`. So by (1d), `ψ` descends to an
injective `ψ̂: Ĝ -> Ĝ ≀ Sym(X)`. In `Ĝ`, an element is trivial iff its root permutation is trivial and both of its
sections are trivial in `Ĝ`.

## 2. Recursion of the lamps

Put `c = b^{-1}a`.

- `c(x) = σ(x)`. Its sections are `c|_0 = (b|_1)^{-1} a|_0 = b^{-1}a = c` and `c|_1 = (b|_0)^{-1} a|_1 = a^{-1}b = c^{-1}`.
  So `c = σ(c, c^{-1})`.
- `c^2` has trivial root permutation and sections `c|_1 c|_0 = c^{-1}c` and `c|_0 c|_1 = c c^{-1}`, both freely
  trivial. So `c^2 in K_∞`, and in `Ĝ` we have `c = c^{-1} = σ(c, c)`.

Let `d_k = b^k c b^{-k}`. Each `d_k` is an involution in `Ĝ`. Since `a = bc`, induction gives
`a^k = d_1 d_2 ··· d_k b^k` for `k >= 1`, using `bc = d_1 b`. With `b^k = (a^k, b^k)`:

- `d_k|_0 = b^k|_1 · c|_0 · (a^k)^{-1} = b^k c b^{-k} (d_1···d_k)^{-1} = d_k d_k ··· d_1 = d_{k-1} ··· d_1 =: u_k`;
- `d_k|_1 = a^k · c|_1 · b^{-k} = d_1 ··· d_k d_k = d_1 ··· d_{k-1} =: v_k`.

So, in `Ĝ`, `d_k = σ(u_k, v_k)` with `u_1 = v_1 = 1`. This uses only `c^2 = 1`. In particular `d_0 = c = σ(d_0, d_0)`.

## 3. The lamps commute in `Ĝ`

Let `P(k)` be the statement that `[d_i, d_j] = 1` in `Ĝ` for all `i, j` with `|i - j| <= k`. `P(0)` is trivial.
Assume `P(k-1)` with `k >= 1`.

- `d_0 d_k` has trivial root permutation, and `(d_0 d_k)|_x = d_0|_{d_k(x)} d_k|_x = d_0 · d_k|_x`.
  So `d_0 d_k = (d_0 u_k, d_0 v_k)`.
- Hence `[d_0, d_k] = (d_0 d_k)^2 = ((d_0 u_k)^2, (d_0 v_k)^2)`.
- `d_0 u_k` and `d_0 v_k` are products of the involutions `d_0, d_1, ..., d_{k-1}`, which commute pairwise by
  `P(k-1)`. So their squares are `1`.
- By §1, `[d_0, d_k] = 1`. Conjugating by powers of `b`, `[d_i, d_{i+k}] = b^i [d_0, d_k] b^{-i} = 1`. So `P(k)`
  holds.

At the word level this says: `c^2` and every `[c, b^k c b^{-k}]` lie in `K_∞`. `lamp.py` confirms this directly for
`k <= 10` by the acyclicity test.

## 4. `N = K_∞`

- `Ĝ` is generated by `b` and `c`, since `a = bc`. By §2–§3 it is a quotient of
  `L = ⟨b, c | c^2, [c, b^k c b^{-k}] (k >= 1)⟩ ≅ Z/2 ≀ Z`.
- The composite `L -> Ĝ -> G` is surjective.
- `G ≅ Z/2 ≀ Z` (Grigorchuk–Żuk, *The lamplighter group as a group generated by a 2-state automaton, and its
  spectrum*, Geom. Dedicata 87 (2001)).
- `Z/2 ≀ Z` is finitely generated metabelian, hence residually finite (P. Hall), hence Hopfian. So the surjection
  `L -> G ≅ L` is an isomorphism.
- Both factors are therefore isomorphisms. In particular `F/K_∞ -> F/N` is injective, so `N = K_∞`.

As a sanity check, `lamp.py` confirms that the normal forms `b^m d_{j_1} ··· d_{j_r}` with `|m| <= 3`, distinct
`j_i in [-3, 3]` and `r <= 3`, other than the empty word, act nontrivially.

## 5. Conclusion

- *Finitely presented.* By Theorem A, consequence 2, with `R = ∅`, `V_2(G)` is presented by `V_2`, (C) and (S).
- *Not contracting.* `b^m = (a^m, b^m)`, so `b^m|_{1^n} = b^m` for all `n`. Since `b` has infinite order in
  `Z/2 ≀ Z`, a nucleus would have to contain every `b^m`.
- *Not finitely presented.* `Z/2 ≀ Z` is not finitely presented (G. Baumslag, 1961). ∎

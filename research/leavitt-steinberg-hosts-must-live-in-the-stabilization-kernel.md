Parts 2–3 are elementary and inline.

## Statement

Let `R` be a unital ring with **two-sided division** (for every `x ≠ 0` there are `a, b`
with `axb = 1`) that carries a unital binary Leavitt family
(`t_i s_j = δ_ij`, `s_0 t_0 + s_1 t_1 = 1`). Let `N >= 3`. Write `K = K_2(N,R)`,
`U_N = ker(K -> K_2(R))`, and `M ⊴ St_N(R)` with `S = St_N(R)/M` nonabelian simple.

1. **Root detection modulo the centre.** Every normal subgroup of `E_N(R)` not contained in
   `Z(E_N(R))` contains a nonzero root `x_ij(x)`, hence equals `E_N(R)`. So `PE_N(R)` is
   simple and `(R, N)` has the sandwich property SW_N. This holds whatever the central units
   of `R` are, in particular when `Q ⊆ R`.
2. **Dichotomy for Steinberg quotients.** Either `K <= M` and `S ≅ PE_N(R)`, or
   `St_N(R) = U_N · M`. In the second case `U_N` is non-abelian, `S ≅ U_N/(U_N ∩ M)`, and
   `M` maps **onto** `E_N(R)`.
3. **Hosts containing Q.** If moreover `Q ⊆ R` unitally, `PE_N(R)` is not finitely presented
   (`ibn-failure-makes-rational-scalars-elementary`, part 3). So every finitely presented
   simple quotient of `St_N(R)` lies in the second case: it is a quotient of the stabilization
   kernel `U_N`, although it still contains `(R,+)` through `x_12`
   (`steinberg-simple-quotients-of-q-rings-reduce-to-pe-n`, part 1).

`L_Q(1,2)` satisfies the hypotheses (two-sided division is the Lean theorem
`exists_mul_mul_eq_one` of `GroupApproximation/Leavitt/LeavittSimplicity.lean`, proved over
any field). For the Leavitt resolvent ring `R_L`, two-sided division is **not** known; if it
holds, parts 1–3 apply to `R_L`.

## What this says about the Steinberg route to `gl-n-q-embeds-in-fp-simple-group`

For a ring as above containing `Q`, a finitely presented simple host built as a quotient of
the finitely presented group `St_N(R)` must satisfy `U_N · M = St_N(R)`: the whole host is
generated by the image of elements of `St_N(R)` that are trivial both in `E_N(R)` and in the
stable Steinberg group. So the host is invisible to every linear representation of `R`, and
the unstable `K_2(N,R)` must be non-abelian (indeed non-central, which already fails if
`U_N = 0`). For `R_L` the levels are identified (`leavitt-refinement-identifies-unstable-k2-levels`),
so the question is one group: is `U_3(R_L)` non-abelian, and does it have a finitely
normally generated co-complement `M`? This is the opposite of what gate 1 of
`steinberg-resolvent-shell-envelope-is-finitely-presented` wants (`U_N = 0`).

## Proof

*Part 1.* Let `H ⊴ E_N(R)` with `H ⊄ Z(E_N(R))`; pick `g ∈ H \ Z(E_N(R))`.

- *Off-diagonal case:* some off-diagonal entry of `g^(-1)` is nonzero. Then
  `exists_elGen_mem_of_offDiag_inv` with the split annihilators of `exists_split_annihilator`
  gives a nonzero root in `H`. Neither lemma uses the central-unit hypothesis (see their
  statements in the Lean file).
- *Diagonal case:* `g^(-1)`, hence `g`, is diagonal with unit entries `d_u`. For `k ≠ l`,
  `g x_kl(a) g^(-1) = x_kl(d_k a d_l^(-1))`, so `[g, x_kl(a)] = x_kl(d_k a d_l^(-1) - a) ∈ H`.
  If all of these vanish, then `d_k a = a d_l` for all `a` and `k ≠ l`; `a = 1` gives
  `d_k = d_l =: d`, and then `da = ad` for all `a`, so `g = dI` with `d` central, which
  commutes with every elementary generator, contradicting `g ∉ Z(E_N(R))`. So some
  `x_kl(d_k a d_l^(-1) - a)` is a nonzero root in `H`.

A nonzero root `x_ij(x) ∈ H` puts `x` in the level ideal of `H` (a two-sided ideal, see
`sandwiched-e-n-has-only-projective-simple-quotients`, part 1); with `axb = 1` the level
contains `1`, so `H = E_N(R)`. Hence `PE_N(R)` is simple (it is nontrivial and nonabelian,
`E_N(R)` being perfect and noncentral). SW_N follows: for `R` simple the only levels are
`0` and `R`, and a normal subgroup with level `0` is central.

*Part 2.* `KM/M` is normal in the simple group `S`, so `K <= M` or `KM = St_N(R)`.
If `K <= M`, `S` is a nonabelian simple quotient of `E_N(R)`, the image of `Z(E_N(R))` is
central hence trivial, and `S` is a nontrivial quotient of the simple group `PE_N(R)`, so
`S ≅ PE_N(R)`.

Otherwise `KM = St_N(R)`. `U_N` is normal in `St_N(R)` (intersection of the kernel `K` with
the kernel of stabilization), so `U_N M = M` or `U_N M = St_N(R)`. Suppose `U_N <= M`. By
`steinberg-simple-quotients-of-q-rings-reduce-to-pe-n`, part 4, `[K, St_N(R)] <= U_N <= M`,
so the image of `K` in `S` is central, hence trivial, so `K <= M`, contradicting
`KM = St_N(R) ≠ M`. Hence `U_N M = St_N(R)` and `S = U_N M / M ≅ U_N/(U_N ∩ M)`, which is
non-abelian, so `U_N` is non-abelian. Applying `St_N(R) -> E_N(R)`, which kills `U_N`, to
`U_N M = St_N(R)` shows `M` maps onto `E_N(R)`.

*Part 3.* `R` has a unital Leavitt pair and contains `Q` unitally, so
`ibn-failure-makes-rational-scalars-elementary`, part 3, says `PE_N(R)` is not finitely
presented; so a finitely presented `S` is in the second case of part 2.

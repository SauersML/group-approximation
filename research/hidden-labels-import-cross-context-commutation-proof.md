Notation as in the target.  Write `e' = (c,c')` and `e'' = (c,c'')`.

**(H1) Edge labels.**  For an edge `e`, Goursat's lemma
(`exact-label-coset-refinements-are-affine-proof`, (G)) writes the blocks of
`c_1^e D_e` as `c_1^e x N_e x c_2^e theta_e(x N_e)`, with `N_e` normal in
`K_1^e`.

- Put `L_e = K_1^e / N_e`, and `ell_e(c_1^e x) = x N_e` on `c_1^e K_1^e`.
- **Block sums are shared.**  By (R3) of
  `coset-refinement-forces-rectangular-central-splitting-proof`, the block sum
  `[ell_e = lambda] := sum_(s : ell_e(s) = lambda) p_c^s` equals the matching
  block sum of the neighbour.  So it lies in `W*(p_(c_e))`.
- **Blocks fix shared variables.**  Every block lies in
  `(beta x beta')^(-1)(Acc)`, so `x_v o beta_c` is constant on blocks for
  each `v in c ∩ c_e`.  Hence `x_v(beta_c(s)) = psi_e^v(ell_e(s))` for a
  function `psi_e^v` on `L_e`.

**(H2) The label coset of `c`.**
- By (S2) of `exact-label-coset-refinements-are-affine-proof`, `p_c` is
  supported on a nonempty coset `S_c = s_c K^~`.  This step uses only (CS)
  and the PVM sums.
- Write `s_c = c_1^e x_0^e`.  For `k in K^~ <= K_1^e`, normality of `N_e`
  gives `ell_e(s_c k) = (x_0^e N_e)(k N_e)`.
- So `(ell_(e'), ell_(e''))` maps `S_c` onto a coset `(g', g'') T` of the
  subgroup `T = {(k N_(e'), k N_(e'')) : k in K^~} <= L_(e') x L_(e'')`.

**(H3) Goursat classes lie in three algebras.**  Apply Goursat to `T`.

- The coset `(g', g'') T` is a disjoint union of full rectangles
  `C'_j x C''_j`, `j in J`, with the `C'_j` disjoint and the `C''_j`
  disjoint.
- **Definition.**  Put `m_j = sum_(s in S_c, ell_(e')(s) in C'_j) p_c^s`.
- **Two expressions.**  For `s in S_c`, `ell_(e')(s) in C'_j` iff
  `ell_(e'')(s) in C''_j`.  Also `p_c^s = 0` off `S_c`.  Hence

  ```text
  m_j = sum_(lambda in C'_j) [ell_(e') = lambda] = sum_(lambda in C''_j) [ell_(e'') = lambda].
  ```

- **Consequence.**  By (H1),
  `m_j in W*(p_c) ∩ W*(p_(c')) ∩ W*(p_(c''))`.  These algebras are abelian
  and contain `P_c`, `P_(c')` and `P_(c'')` respectively.  So each `m_j`
  commutes with all three PVMs.  Also `sum_j m_j = 1`.

**(H4) Rectangles in the allowed set.**
- Put `U_j = psi_(e')^u(C'_j)` and `W_j = psi_(e'')^w(C''_j)`.
- Every pair `(lambda', lambda'') in C'_j x C''_j` is the label pair of some
  `s in S_c`.
- Then `beta_c(s) in Allowed_c` restricts to
  `(psi^u(lambda'), psi^w(lambda''))`.
- So `U_j x W_j` lies in the restriction of `Allowed_c` to `(u,w)`.  That
  restriction misses a pattern, so for each `j`, `|U_j| = 1` or `|W_j| = 1`.

**(H5) The split.**  Let `J_u = {j : |U_j| = 1}` and `m = sum_(j in J_u) m_j`.

- **On `m`.**
  - `X_u m_j = ± m_j` for `j in J_u`, since `X_u m_j` is the sum of
    `(-1)^(psi^u(lambda'))[ell_(e') = lambda']` over `C'_j`.
  - So `X_u m in W*(p_(c''))`, which commutes with `P_(c'')`.
  - `m` commutes with both `X_u in W*(p_c)` and `P_(c'')`, so
    `[X_u, P_(c'')^b] m = [X_u m, P_(c'')^b] = 0`.
- **On `1 - m`.**
  - For `j` not in `J_u` we have `|W_j| = 1`, so `X_w m_j = ± m_j`.
  - So `X_w (1 - m) in W*(p_(c'))`.
  - The same computation gives `[X_w, P_(c')^(b')] (1 - m) = 0`.

**(H6) Factor test.**  Let `N = W*(P_c, P_(c'), P_(c''))`, and let `C(n)`
denote the central support in `N'` of a projection `n in N'`, which lies in
`Z(N)`.
- `m in N' ∩ M`, and for `x in N`, `x m = 0` implies `x C(m) = 0` (as in (R6)).
- If `N` is a factor and `[X_u, P_(c'')] != 0`, then `C(m) = 0`, so `m = 0`.
- Symmetrically, `[X_w, P_(c')] != 0` forces `1 - m = 0`.  This is a
  contradiction.

**(H7) Synchronous sources.**
- For the NAND context `{x_(q,a), x_(q',a')}`, take `c' = q` and `c'' = q'`.
- `P_c` lies in `W*(P_q, P_(q'))`, so commuting with `P_q` and `P_(q')`
  implies commuting with `P_c`.
- `X_u = 2 P_q^a - 1`, so (HL) gives the stated commutation.
- In a factor pair algebra, a projection of `W*(P_q, P_(q'))` that commutes
  with both PVMs is central, hence `0` or `1`.

**(H8) Model test (`M_3`).**
- **Perfection.**
  - `X_y` swaps `e_00` and `e_01`, which have equal `u`-bit, so it commutes
    with `X_u`.
  - `X_z` swaps `e_00` and `e_10`, which have equal `w`-bit, so it commutes
    with `X_w`.
  - `(X_u, X_w)` has spectrum `{00, 01, 10}`, which is NAND.
- **Generation.**
  - The diagonal algebra is generated by `X_u` and `X_w`, which separate the
    three basis vectors.
  - Adding the two transpositions gives all of `M_3`.
- **Commutators.**
  - `X_z` moves `e_00` (`u`-bit 0) to `e_10` (`u`-bit 1), so
    `[X_u, X_z] != 0`.
  - `X_y` moves `e_00` (`w`-bit 0) to `e_01` (`w`-bit 1), so
    `[X_w, X_y] != 0`.

Weakening, not a restatement. If a.a.s. `h_1(Y,Sym) >= c > 0` in the mid-range,
then a.a.s. `h_1(Y,Sym) = ω(n^(-2-η))`, because `n^(-2-η) -> 0`. The converse
fails as a statement: the target allows `h_1 -> 0`.

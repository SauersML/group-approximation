**OPEN.** Let `P = A_0 * A_1` with `A_i` finite, `h_i = |A_i| - 1 >= 2`, and
`h_0 != h_1`. Let `nu` be the least-significant-first mixed-radix enumeration of
the artifact: a nonempty reduced word of first type `epsilon` with syllable
digits `d_1, d_2, ...` has value

    q = d_1 + R_1 (d_2 + R_2 (d_3 + ...)),   R = (h_eps, h_(1-eps), h_eps, ...),
    nu(word) = 2q - 1 + epsilon,             nu(1) = 0.

Claim: `R_nu` is finitely presented and `ker(eta)` is finitely generated. By
`finite-index-in-a-kernel-fg-near-host-passes-both-germ-gates` it would suffice
that `R_nu` has finite index in a finitely presented near group whose near-index
kernel is finitely generated. The natural candidate host is the two-radix odometer
group of the artifact, whose finiteness properties are themselves not established.

Perfect instance: `P = A_5 * A_6` (`h_0 = 59`, `h_1 = 359`), which is perfect,
finitely presented and has decidable word problem. Smallest instance:
`Z/3 * Z/4`.

**Established here** (lane proof, artifact §2–§4, not reviewed):
- `nu` is a computable bijection, and every `lambda_x` (x in a factor) is
  residue-affine mod `2h_i` with slopes `h_i`, `1`, `1/h_i`; so
  `arithmetic-near-shift-actions-have-mixed-relations` applies and
  `free-shift-shell-envelopes-are-not-finitely-presented` does not.
- In the completion `X = {0,1} x Z_(h_0 h_1)`, `s(0,y) = (1,y)` and
  `s(1,y) = (0,y+1)`: a change of radix. For `h_0 != h_1` it maps the depth-one
  type-0 cone `{0} x (c + h_0 Z^)` onto a set that is not a cone of the type-1
  digit tree. So `s` is not an automorphism of the digit (Bass–Serre) tree, and
  Step 1 of `arithmetic-a5-near-group-not-fp-proof` has no analogue. No other tree
  action with locally virtually abelian stabilizers is excluded.
- For `h_0 = h_1` this enumeration is exactly the dead A*A benchmark.

A positive answer would give the first non-virtually-cyclic enumeration passing
gates (G1) and (G2) of `mz-envelope-fp-forces-two-sided-fg-near-index-kernel`, and
the shell germ gate. Gate (G3), finite presentation of `A_1`, and finite
presentation of `E_nu` would remain.

## Status update (bh-shell-arith, 2026-09-18)

- **Host half discharged.** `two-radix-odometer-host-is-f-infinity-with-fg-charge-kernel`: the
  two-radix odometer host `H` is `F_infinity` (X. Li's higher-rank Zappa--Szep theorem), and its
  near-index kernel is finitely generated. `R_nu <= H`. So the claim now reduces to the single
  generation question `[H : R_nu] < infinity`.
- **Structure.** `unequal-radix-near-group-halves-are-tree-groups-that-are-not-fp`: `R_nu` is
  generated by two one-radix tree groups `G_0, G_1`. Each is not finitely presented, by the
  equal-radix argument. They are glued by disjoint-support relations, so `R_nu` is not their
  amalgam and not a group of Bass--Serre tree automorphisms. At `(0,-1/2)`, `R_nu` realizes the
  full rank-2 germ group of `H`.

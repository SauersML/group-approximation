**ESTABLISHED (proposed; unreviewed).**  Derivation: [[net-sandwich-level-subpairs-cannot-certify-rank-three-cone-proof]].
It is a class-killing obstruction for the nonsofic side of [[rank-three-finite-twisted-kazhdan-cone-is-sofic]],
extending (X3) of [[subring-level-subpairs-cannot-certify-rank-three-cone]] from subrings to nets.

## Setting

As in [[subring-level-subpairs-cannot-certify-rank-three-cone]]: `R_+ = F_q[x_1..x_d]`, `R` the Laurent ring,
`Gamma = SL_3(R_+)`, `G = EL_3(R) x| SL_d(Z)`, `psi = ev_0`, `U_k = < e_ij(x^m) : |m| ≥ k >`.  For `B ≤ G`:
`C = B ∩ Gamma`, `E_B = B ∩ EL_3(R)`, `H_B` the projection to `SL_d(Z)`, `K0 = cone(H_B · R_+^d)`, and
`Λ = span_(F_q) { g - 1 : g ∈ E_B }`.  Call `E_B` **pattern-sandwiched** if there are `F_q`-subspaces
`σ_ab ⊆ R` (`a, b ∈ {1,2,3}`) with

```text
e_ab(σ_ab) ⊆ E_B  (a ≠ b)      and      E_B ⊆ 1 + M(σ),   M(σ) = ⊕ σ_ab E_ab .
```

No closure axiom on `σ` is needed.  Every elementary net group `E(σ)` (with `σ` a net, diagonal included) and
every group between `E(σ)` and the net group `G(σ)` is pattern-sandwiched, and so is `EL_3(A)` for a subring.

## Theorem

Let `B ≤ G` contain `U_k` for some `k ≥ 1`.

**(Y1) Span theorem.**  If `-e_l ∈ K0` for some coordinate `l`, then `I ∈ Λ` and `E_ab ∈ Λ` for all `a ≠ b`,
so `Λ ⊇ M_3(F_q)`.

**(Y2) Span to group.**  If moreover `E_B` is pattern-sandwiched, then `e_ab(1) ∈ C` for all `a ≠ b`, and
`psi(C) = F`.

**(Y3) Consequence.**  No `B ⊇ U_k` with pattern-sandwiched `E_B` is a Kun-Thom certificate for `T_3`.
Suppose `B`, `C` Kazhdan and `C` infranormal.  By (X1) of the subring node, `H_B` is generated by nonnegative
matrices, and it is Kazhdan.  If `H_B` is finite, `C` is normal by (X2).  If `H_B` is infinite, (W2) of
[[nonneg-generated-kazhdan-groups-have-nonsalient-cones]] gives a coordinate subspace `R^M ⊆ K0`, `M ≠ ∅`, so
`-e_l ∈ K0` for `l ∈ M`, and (Y2) gives `psi(C) = F`: the centraliser condition fails.

**(Y4) Sharpness: a box level is not enough.**  Let `d = d_1 + 2`, `d_1 ≥ 3`, variables `x_1..x_(d_1), y_1, y_2`,
`q ≥ 5`, and `D = diag(1, 1, y_1 y_2^(-1))`.  Put
`B = D (EL_3(F_q[x^(±1)][y_1, y_2]) x| SL_(d_1)(Z)) D^-1`, with `SL_(d_1)(Z)` acting on the `x`'s.  Then:

- `B` is Kazhdan, `E_B = E(σ)` is an elementary net group, `H_B = SL_(d_1)(Z)`, and `K0 ⊇ R^(d_1)`;
- `B` contains the **box level** `< e_ab(x^m) : m ≥ (1,..,1) >` but no `U_k`;
- `psi(C)` lies in the Levi subgroup `S(GL_2 x GL_1)(F_q)`, whose centraliser in `F` is nontrivial.

So (Y2) fails for box levels, and the centraliser condition does hold there.  But `C` is not Kazhdan: modulo
`(y_1, y_2, x_2, .., x_(d_1))` it maps onto a finite-index subgroup of `GL_2(F_q[x_1])` containing
`SL_2(F_q[x_1])`.  This is the hypersurface-level failure of
[[divisor-level-subpairs-cannot-certify-rank-three-twisted-cone]].

## Mechanism

1. *(Y1).*  `Λ` is an `Ad(B)`-invariant algebra, since `(g-1)(h-1) = (gh-1) - (g-1) - (h-1)`.  From `U_k`,
   `x^m E_ab ∈ Λ` for `|m| ≥ k`, and `x^m I ∈ Λ` for `|m| ≥ 2k`.  `Ad(u σ)` sends `x^m I` to `x^(σm) I`.  A
   rational positive relation `-N e_l = Σ n_s h_s e_(i_s)`, `h_s ∈ H_B`, gives `x^(-2kN e_l) I ∈ Λ`, and
   multiplying by `x^(2kN e_l) E_ab ∈ Λ` gives `E_ab ∈ Λ`.
2. *(Y2).*  `Λ ⊆ M(σ)` because `M(σ)` is a linear space containing every `g - 1`.  So `1 ∈ σ_ab`, and
   `e_ab(1) ∈ E_B ∩ Gamma ⊆ C`.  The span-to-group gap of the subring node closes because the pattern records
   exactly which entries the group can reach, and the span cannot leave the pattern.
3. *(Y4).*  `D` is a monomial diagonal twist along the `y`-directions, which `SL_(d_1)(Z)` fixes, so `B` is
   the semidirect product of the net group with entries `y^(a_a - a_b) F_q[x^(±1)][y]` and `SL_(d_1)(Z)`.
   The entries in positions `(1,3), (2,3)` lie in `y_2 R_+`, those in `(3,1), (3,2)` in `y_1 R_+`.  The scalar
   step of (Y1) still runs, but every box-level entry carries `y_1 y_2`, and `x^(-2kN e_l)` has no `y`, so
   the last multiplication never reaches a constant.

## Calibration

- `B = G`: pattern `σ_ab = R`, `psi(C) = F`.  `B = EL_3(F_q[P]) x| H`: the subring node's (X3).
- The (Y4) group is the first net subpair with an infinite Kazhdan projection whose cone has a line and whose
  trace still has a nontrivial centraliser; it shows that the true level `U_k`, which contains
  `e_ab(x_l^n)` for each single variable, is what drives (Y1).

## What is left

A certificate with `B ⊇ U_k` now needs `E_B` **not** pattern-sandwiched: for some `a ≠ b`, `1` is an
`(a,b)`-entry of the span of `E_B - 1`, and in fact `E_ab ∈ Λ`, yet `e_ab(1) ∉ E_B`.  Every elementary part
generated by elementary matrices of a net, or squeezed between `E(σ)` and `G(σ)`, is excluded.  The remaining
elementary parts are non-net, for instance normal closures in `B` of `U_k` twisted by a non-monomial `u`.
The other open class is `B` with no level `U_k`, where by (Y4) the failure mode is a hypersurface level and
the edge must be shown Kazhdan in some new way.

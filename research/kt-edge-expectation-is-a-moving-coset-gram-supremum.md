**ESTABLISHED.**  Let `rho_n:G->U(d_n)` be finite-dimensional
representations, let `tau_n` be normalized trace, and put

```text
B_n=C*(rho_n(Gamma)),        chi_n(g)=tau_n(rho_n(g)).  (KCG1)
```

For finitely supported `c:Gamma->C`, define

```text
N_n(c)=sum_(gamma,delta)
       conjugate(c_gamma)c_delta chi_n(gamma^(-1)delta),

L_(n,g)(c)=sum_gamma conjugate(c_gamma)
                         chi_n(gamma^(-1)g).            (KCG2)
```

Then the trace-preserving expectation satisfies the exact formula

```text
||E_(B_n)(rho_n(g))||_2^2
 =sup_(c:N_n(c)>0) |L_(n,g)(c)|^2/N_n(c).              (KCG3)
```

Equivalently, for any finite spanning list
`rho_n(gamma_1),...,rho_n(gamma_k)` of `B_n`, if

```text
G_(ij)=chi_n(gamma_i^(-1)gamma_j),
v_i=chi_n(gamma_i^(-1)g),
```

then `(KCG3)` is `v^* G^dagger v`, with the Moore--Penrose inverse allowing
linear dependence in the chosen group-unitary list.

Thus canonical character convergence `chi_n->delta_e` kills the ratio in
`(KCG3)` for every **fixed** finitely supported `c` when `g notin Gamma`, but
does not imply that the supremum tends to zero.  For the Kun--Thom pair take
`h in cl_profinite(Gamma)\Gamma` and residual finite-quotient regular models.
For every `n` there is `gamma_n in Gamma` with
`rho_n(gamma_n)=rho_n(h)`.  The moving vector `c_n=delta_(gamma_n)` makes the
ratio in `(KCG3)` equal to one, even though `chi_n` converges pointwise to the
regular character of `G`.

The same distinction persists if fixed group-ring norms converge to reduced
norms: those tests quantify over one fixed coefficient vector before taking
`n->infinity`, whereas `(KCG3)` permits an `n`-dependent unit vector in the
whole edge algebra.  Consequently the relative-randomization route to the
reduced double needs a separate **uniform no-moving-Gram-leak** estimate.
Cross-block coupling can evade the blockwise profinite-separation argument
only for genuinely approximate vertex maps:
`kt-exact-kun-thom-edge-return-is-algebraically-absorbed` proves that every
exact finite-dimensional representation has supremum exactly one for the
chosen compressor return.  In either setting, vanishing is not supplied
merely by canonical vertex marginals.

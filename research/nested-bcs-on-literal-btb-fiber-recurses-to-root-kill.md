**ESTABLISHED REDUCTION / NO-GO FOR THE NAIVE NESTING.**  At the canonical
root, `Q_0`, the selected Reynolds atom, and the corrected BTB--E5 outer cut
are literal projections in one fixed finite packet algebra.  Thus the root
fiber `F` may be used as a reducing activation projection for a fresh shared
non-CE BCS tuple.  Fixed PVM correction and synchronization then give

```text
sum_b tau(F P'_b) >= beta' tau(F)-C sqrt(E),            (NBF1)
```

where `b` ranges over the nested forbidden assignments.  This localization
is valid and loses no dimension-dependent constant.

It does not yet give `(BAF3)`.  Every `F P'_b` is again a Reynolds/character
projection in a fixed finite packet.  Turning its trace into ordinary
relator energy requires a displacement word `z_b` with

```text
tau(F P'_b) <= C_b ||rho(z_b)-1||_2^2+O(sqrt(E)).       (NBF2)
```

By `agent-packet-root-finite-detectors-are-normal-quotient-selectors`, every
finite packet or finite projective detector can satisfy `(NBF2)` only when
the image of `F P'_b` is already zero in the packet quotient obtained by
setting `z_b=1`.  For a general Boolean forbidden atom this is precisely the
missing normal-quotient/affine selector: quotient-compatible character sets
are affine, while the nested BCS forbidden menu is arbitrary.

A formal controlled reflection `L_F=1-2F` in a coefficient ring does not
remove the gate.  To use it in arbitrary unitary microstates one must
authenticate that the `L_F=-1` spectral projection is the group-algebra
projection `F`.  A finite packet authentication is again a normal-quotient
selector by the theorem above.  Rank-five/Steinberg context absorption can
wordize multiplication tables, but it does not supply this missing
representation-uniform spectral identification; that is exactly why the BTB
root detector was needed in the first place.

There are only two exits.  If root killing algebraically kills the detector's
global protected sign, the canonical activated sector collapses along with
the root and no floor on the original `F` remains.  If an infinite mixed cell
kills `F P'_b` only in finite-dimensional approximate representations while
retaining it in the perfect tracial quotient, then that cell already supplies
the dimension-uniform finite-dimensional-only rigidity requested in `(BAF3)`.
Nesting has merely renamed the missing theorem.

Consequently `(NBF1)` is a useful exact localization, but iterating the same
non-CE verifier does not cascade to an ordinary-group floor.  A successful
one-fiber compiler must directly cross the normal-quotient selector gate (or
provide an equivalent payload-conditioned infinite-cell HS floor); no further
BCS nesting is needed once that is done.

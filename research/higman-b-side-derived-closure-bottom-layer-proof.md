Conventions: `x^y = y^-1 x y`, `[x,y] = x^-1 y^-1 x y`, and `X^(0) = X`, `X^(i+1) = [X^(i), X^(i)]`.
The requirement supplies `G_b = BS(a,b) *_<b> BS(b,c)`, with `<b>` infinite cyclic in both factors.
The script is a calibration of the corollary at `k = 3` in an explicit quotient; nothing depends on it.

## Step 1 (the kernel of `c -> 1` is a free product of dyadic lines)

- Let `H = <a, b | b^a = b^2>` and `K = <b, c | c^b = c^2> = Z[1/2] ⋊ <b>`, where `c = 1 in Z[1/2]` and
  `b^-1 u b = 2u`. Then `G_b = H *_<b> K`. The retraction `pi : G_b -> H`, `c -> 1`, is well defined,
  and `N = ker pi = ncl_(G_b)(c)`, with `G_b = N ⋊ H`.
- `N` acts on the Bass--Serre tree `T` of the splitting.
  - **Edge stabilizers.** They are conjugates of `<b>`, and `N ∩ <b>^g = 1`, since `pi` is injective
    on `<b>^g`.
  - **Vertex stabilizers.** They are conjugates of `N ∩ H = 1` and of `N ∩ K = Z[1/2]`.
  - **Quotient graph `N\T`.** Its vertices are `N\G_b/H` (one point) and `N\G_b/K = H/<b>`, and its edges
    are `N\G_b/<b> = H/<b>`. So it is a star, hence a tree.
- By Bass--Serre theory,

  ```text
  N = *_(x in H/<b>) L_x,   L_x = x Z[1/2] x^-1  (x a coset representative).
  ```

  Changing the representative from `x` to `x b^n` rescales the identification of `L_x` with `Z[1/2]`
  by `2^n`, so `L_x` depends only on the coset.
- **`H` permutes the factors.** For `h in H`, conjugation `u -> h u h^-1` maps `L_x` isomorphically onto
  `L_(hx)`, by a map that is multiplication by a power of 2 in the chosen coordinates.

## Step 2 (the free pair and its subgroup `P`)

- `a^j in <b>` only for `j = 0` (map `H -> Z`, `a -> 1`, `b -> 0`). So the cosets `a^j <b>` (`j in Z`)
  are distinct. Take `a^j` as their representatives and put `c_j = a^j c a^-j`, the element `1` of
  `L_(a^j)`.
- The factors `L_(a^j)` are distinct free factors of `N`, and each `c_j` has infinite order. So the
  `c_j` freely generate a free subgroup `P <= N`. (The factors form a free product, and a
  cyclic subgroup of each factor is free on its generator.)
- `a` normalizes `P` by `c_j -> c_(j+1)`, and `<a> ∩ N = 1`. So `F := <a, c> = P ⋊ <a>`. That is the
  group with free generators `c_j` and a shift, i.e. the free group on `a, c` (the requirement's
  statement that `<a,c>` is free is recovered). Also `P = F ∩ N = ncl_F(c)`, since `F ∩ N` is the
  kernel of `pi|_F : F -> <a>`, and that kernel is `ncl_F(c)`.
- `F/P ≅ Z` is abelian, so `F' <= P`, hence `F^(k) <= P^(k-1)` for `k >= 1`.

## Step 3 (retraction onto the lines indexed by powers of `a`)

- Let `P_Z = *_(j in Z) L_(a^j) <= N`, and let `rho : N -> P_Z` be the retraction of the free product
  that is the identity on each `L_(a^j)` and kills every other factor. Then `rho|_(P_Z) = id`, and in
  particular `rho|_P = id`.
- **(R) For each `h in H`, the map `sigma_h : P_Z -> P_Z`, `u -> rho(h u h^-1)`, is a group homomorphism.**
  It is the composite of conjugation by `h` (an automorphism of `N`) and the homomorphism `rho`.
  Explicitly, it sends `L_(a^j)` onto `L_(h a^j)` if `h a^j <b> = a^i <b>` for some `i`, and kills
  `L_(a^j)` otherwise.
- **Claim.** Let `M` be a normal subgroup of `F` with `M <= P^(k-1)` (for instance `M = F^(k)`). Then
  `rho(ncl_(G_b)(M)) <= P_Z^(k-1)`.
  - *Proof.* `ncl_(G_b)(M)` is generated by the conjugates `g w g^-1` with `w in M` and `g in G_b`. Write
    `g = n h` with `n in N` and `h in H` (Step 1). Since `M <= P <= N`, we have `h w h^-1 in N`, and

    ```text
    rho(g w g^-1) = rho(n) · sigma_h(w) · rho(n)^-1.
    ```

  - `w in P^(k-1) <= P_Z^(k-1)`. A homomorphism maps derived subgroups into derived subgroups, so
    `sigma_h(w) in P_Z^(k-1)`.
  - `P_Z^(k-1)` is normal in `P_Z`, so every generator maps into `P_Z^(k-1)`. So does the subgroup they
    generate. ∎
- **Consequence.** If `w in ncl_(G_b)(M) ∩ F`, then `w in N ∩ F = P`, and `w = rho(w) in P_Z^(k-1)`.
  Hence

  ```text
  ncl_(G_b)(M) ∩ F  <=  P ∩ P_Z^(k-1).
  ```

It remains to show that `P ∩ P_Z^(k-1) = P^(k-1)` (Step 4). The point is that `P_Z` contains roots
`c_j^(2^-n)` of the free generators of `P`, so this is not automatic.

## Step 4 (power lemma: `P ∩ P_Z^(j) = P^(j)`)

- **Reduction to free groups.** For `n >= 0`, let `P_n = < c_j^(2^-n) : j in Z > <= P_Z`, where
  `c_j^(2^-n)` denotes the element `2^-n` of `L_(a^j)`. Each `P_n` is free on these elements, as in
  Step 2. `P_0 = P`, and `P_Z` is the directed union of the `P_n`. Derived subgroups commute with
  directed unions: a finite product of commutators of elements of `P_Z` lies in some `P_n`. So
  `P_Z^(j) = ∪_n P_n^(j)`, and it suffices to prove `P ∩ P_n^(j) = P^(j)` for all `n` and `j`.
- **The power map.** Let `E` be the free group on `{e_k : k in Z}`. Fix `m = 2^n`, and let
  `iota : E -> E` be the homomorphism `e_k -> e_k^m`. Identifying `P_n` with `E` via
  `c_k^(2^-n) -> e_k`, the inclusion `P ⊆ P_n` becomes `iota`, an injective map. So we must show

  ```text
  iota^-1(E^(j)) = E^(j)   for all j >= 0.
  ```

  The inclusion `⊇` is clear, since `iota` maps `E^(j)` into `E^(j)`.
- **Induction on `j`.** The case `j = 0` is trivial. Assume `iota^-1(E^(j)) = E^(j)`, and put
  `R = E^(j)` and `G = E/R`.
  - Then `iota` induces an **injective** endomorphism `theta : G -> G`, `theta(e_k R) = e_k^m R`, and a ring
    endomorphism `theta : Z[G] -> Z[G]`. This ring map is injective too, since it maps the basis `G`
    injectively to the basis `G`.
  - Let `w in iota^-1(E^(j+1))`. Then `w in iota^-1(E^(j)) = R`, and `iota(w) in R' = E^(j+1)`.
  - **Magnus embedding.** Take the free left `Z[G]`-module `M = ⊕_k Z[G] t_k`. The map
    `e_k -> (t_k, e_k R)` induces an injective homomorphism `E/R' -> M ⋊ G`. An element `v in R`
    maps to `(Σ_k D_k(v) t_k, 1)`, where `D_k(v)` is the image in `Z[G]` of the Fox derivative
    `∂v/∂e_k`. So `v in R'` if and only if `D_k(v) = 0` for all `k`.
  - **Chain rule.** Since `iota` is a substitution, `∂iota(v)/∂e_k = Σ_l iota(∂v/∂e_l) ∂(e_l^m)/∂e_k`,
    and `∂(e_l^m)/∂e_k = δ_(lk)(1 + e_k + ... + e_k^(m-1))`. Reducing mod `R`:

    ```text
    D_k(iota(w)) = theta(D_k(w)) · Phi_k,    Phi_k = 1 + ē_k + ... + ē_k^(m-1)  in Z[G].
    ```

  - `iota(w) in R'` gives `theta(D_k(w)) Phi_k = 0` for every `k`.
    - `G` is the free solvable group of rank `|Z|` and derived length `j`, hence torsion-free and
      elementary amenable.
    - By Kropholler--Linnell--Moody (1988), `Z[G]` has no zero divisors.
    - `Phi_k ≠ 0`: for `j >= 1` the element `ē_k` has infinite order in `G`, so the `m` terms of `Phi_k`
      are distinct group elements. For `j = 0`, `G = 1` and `Phi_k = m`.
  - Hence `theta(D_k(w)) = 0`. Injectivity of `theta` gives `D_k(w) = 0` for every `k`, so `w in R'`.
    This proves `iota^-1(E^(j+1)) = E^(j+1)`. ∎
- **Combining.** By Step 3, `ncl_(G_b)(M) ∩ F <= P ∩ P_Z^(k-1) = P^(k-1)`. Also `P^(k-1) <= F^(k-1)`,
  since `P <= F`. This proves the statement for `M = F^(k)` and for every normal `M <= P^(k-1)` of `F`.

## Step 5 (corollary)

- Fix `k >= 2`, and let `U_k = ncl_(G_b)(F^(k))` and `Q_k = G_b / U_k`.
  - **Universality.** `Q_k` is the universal group generated by `a, b, c` with `b^a = b^2`, `c^b = c^2`
    and `<a,c>^(k) = 1`.
  - **Infinite order.** `U_k <= N`, and `N ∩ H = 1`, so `H` embeds in `Q_k`. So `a` and `b` have
    infinite order. `c` has infinite order because `F ∩ U_k <= P^(k-1)` and `<c> ∩ P' = 1` for `k >= 2`
    (the image of `c` in `P/P'` is a basis element), so `<c> ∩ U_k = 1`.
- **Free solvable top.** The image `A` of `F` in `Q_k` is `F/(F ∩ U_k)`, and its derived subgroup
  `A^(k-1)` is `F^(k-1)(F ∩ U_k)/(F ∩ U_k)`. So `A/A^(k-1) = F / F^(k-1)(F ∩ U_k) = F/F^(k-1)`, because
  `F ∩ U_k <= F^(k-1)`. This is free solvable of rank 2 and length `k-1`.
- **The `d` side.** Apply `theta^2 : a -> c, b -> d, c -> a, d -> b`, which maps the `b`-side relations to
  the `d`-side relations and `F = <a,c>` to itself, with `P -> P_d = ncl_F(a)`.
- **Bottom layer and the two-sided alternation.** The argument says nothing about
  `A^(k-1)/A^(k) = F^(k-1)/(F ∩ U_k)`. So a bound on the bottom layer is not excluded. For
  a normal `M <= P^(k-1) ∩ P_d^(k-1)` of `F`, Step 3 gives `ncl_b(M) ∩ F <= P^(k-1)` and
  `ncl_d(M) ∩ F <= P_d^(k-1)`. It gives no mixed bound. So the two-sided closure `ncl_(H4)(F^(k)) ∩ F`, in
  `H4 = G_b *_F G_d`, is not controlled by this argument.

## Calibration (script)

`free_metabelian_top.py` (on top of `one_sided_example.py` of
`higman-one-sided-span-counterexample-proof`) computes, at `k = 3`, in the explicit quotient of `Q_3`
built there, a functional on `A_m'/A_m''` with `Phi(z^(alpha^-i gamma^-j)) = S^(mi) t^(mj) Phi(z)` and
`Phi(z) = t^-m (S^-m - 1)(1 + ... + t^(m-1)) ≠ 0` (`t = 1.7`, `S = 2.3`, `m = 1, 2`,
`0 <= i, j <= 2`). This shows that `A_m'/A_m'' ⊗ Q` contains a free cyclic `Q[X^±, Y^±]`-module, as the
corollary predicts for `A = <a,c>`. Output: `free_metabelian_top-output.txt`.

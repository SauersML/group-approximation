**Item 1.**
- By (GE), `A = X D` with `X in E_n` and `D = diag(u_1, ..., u_n)`. Invertible diagonal matrices normalize `E_n`, since
  `D t_ij(a) D^-1 = t_ij(d_i a d_j^-1)`, so the diagonal factors can be moved to the right.
- For units `a, b`, `diag(a, b) = diag(ab, 1) · diag(b^-1, b)`, and `diag(b^-1, b) = W(b^-1) W(-1)` lies in `E_2`. Here
  `W(c) = t_12(c) t_21(-c^-1) t_12(c)`.
- Applying this at positions `(n-1, n)`, then `(n-2, n-1)`, and so on, collects `D` into `diag(u_1 ⋯ u_n, 1, ..., 1)`
  modulo `E_n`. So every class contains some `diag(u, 1, ..., 1) = diag(u) ⊕ I_(n-1)`.

**Item 2.**
- By item 1, stabilization `s_n : GL_n/E_n -> GL_(n+1)/E_(n+1)` is onto for every `n >= 1`.
- For `n >= 3`, item 3 of `leavitt-k1-stability-is-one-step` makes `s_n` injective, so it is a bijection.
- `K_1(R) = colim GL_n/E_n`, so `GL_n/E_n ≅ K_1(R)` for `n >= 3`.

**Item 3.**
- `K_1(R_L) ≅ Z`, generated by `[N + 1]` (`leavitt-resolvent-k-theory-is-shifted-rational-k-theory`). With (GE) and item 2,
  `GL_n(R_L)/E_n(R_L) ≅ Z` on `diag(N+1, 1, ..., 1)` for `n >= 3`.
- For `n >= 4`, `n - 1 >= 3`, so `s_(n-1)` is injective, and `H ⊕ 1 in E_n` gives `H in E_(n-1)`.

**The core-element case.**
- By item 1 of the simplicity criterion node, a nonzero core element `y = Σ s_μ Y_(μν) t_ν` has some nonzero coefficient
  `Y_(μν) = t_μ y s_ν in B⁺`.
- `B⁺` consists of functions `N -> Q`, and `q_k c = c(k) q_k`. So `t_2 t_1^k c s_1^k s_2 = c(k) t_2 t_1^k s_1^k s_2 = c(k)`.
  Choose `k` with `c(k) != 0`. Then `(c(k)^-1 t_2 t_1^k t_μ) y (s_ν s_1^k s_2) = 1`.

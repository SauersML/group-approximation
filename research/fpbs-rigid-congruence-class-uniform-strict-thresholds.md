**ESTABLISHED (2026-09-17, computer-assisted, unreviewed)** through
`fpbs-rigid-congruence-class-uniform-strict-thresholds-proof`.

**Statement.** Let `A` be an abelian group generated by `y, z, w`. Put
`Gamma = F_2 x A` and

```text
S(y,z,w) = {(a,0),(a,y),(a,z),(b,0),(b,y),(b,w),(1,y)}^{±1}.
```

Let `(z0,w0)` be one of the certified patterns `(3,4), (3,5), (4,5), (3,6), (4,6)`,
and put `N0 = 14 + 2 max(z0,w0)`. Suppose some homomorphism `chi : A -> Q`, with
`Q = Z` or `Q = Z/N` for some `N >= N0`, sends `(y,z,w)` to `(1,z0,w0)`. Then, for
Bernoulli bond percolation on `Cay(Gamma, S(y,z,w))`,

```text
p_c  <=  p1(z0,w0)  <  93/1000  <=  p_{2->2}  <=  p_u ,
```

with `p1 = 91/1000` for `(3,4), (3,5), (4,5)`, `p1 = 92/1000` for `(3,6)` and
`p1 = 925/10000` for `(4,6)`. So `p_c < p_u`.

**The class is infinite and rigid.** In `F_2 x Z`:
* take `y = 1`, `z = z0 + N t`, `w = w0 + N t'` for any integers `t, t'`, with
  `N >= N0`;
* more generally, take any `N >= N0` and `y` coprime to `N`, with `z ≡ z0 y` and
  `w ≡ w0 y (mod N)`. Multiplication by `y^(-1)` mod `N` is then the character.

Every such decoration is rigid in the sense of
`fpbs-tree-projected-rigid-decorations-strict-thresholds`. For `N >= 14`, a
3-subset of `Z/N` with diameter at most 6 has a unique cyclic gap larger than 6.
So its translation class is the ordered pair of its two small gaps, exactly as in
`Z`. The four sets `D_a, -D_a, D_b, -D_b` reduce to the gap pairs `(1,z0-1)`,
`(z0-1,1)`, `(1,w0-1)` and `(w0-1,1)`, which are pairwise distinct for
`3 <= z0 < w0`. Translation equivalence over `Z` would survive reduction mod `N`,
so the integer sets are pairwise inequivalent too. The class also contains:
* `S_rig = S(1,3,4)`, as calibration;
* the free-abelian cover `F_2 x Z^3` itself;
* all mixed fibres such as `F_2 x (Z x Z/M)`.

**Mechanism: a cover-quotient sandwich.** Every graph in the class sits in a tower
of Cayley-graph coverings

```text
Cay(F_2 x Z^3, S_tri)  ->  Cay(F_2 x A, S(y,z,w))  ->  Cay(F_2 x Q, S(1,z0,w0)) ,
```

where `S_tri` sends the three basis vectors to `y, z, w`. Each map is a group
homomorphism that is the identity on `F_2` and bijective on generators. A covering
can only push the two thresholds in one direction:
* `theta` increases when passing to the cover (lift of an exploration tree), so
  `p_c(member) <= p_c(quotient)`;
* the fibre sums `f(w) = sum_h tau_p((w,h))` also increase when passing to the
  cover (same coupling), and Young's inequality on `A` gives
  `||T_p||_{l^2(F_2 x A)} <= ||lambda_{F_2}(f)||`. So
  `p_{2->2}(member) >= p_{2->2}` of the Schur majorant on the cover.

Two certificates are therefore enough for the whole class:
1. **Uniform `l^2` side, on the cover.** A chord-weighted Busemann-Schur transfer
   inequality holds on `F_2 x Z^3` at `p = 93/1000` (memory 4, 32569 windows x 4
   letters, 417198 transitions, exact max ratio `0.999879...`), and at `p = 37/400`
   (memory 3, max ratio `0.99731`). Both are checked in exact integer arithmetic. The walk majorant charges `p(1-p)^c` per step, where `c` counts the
   edges from the new vertex back to the last few path vertices. A shortest open
   path has all such chords closed. This is strictly stronger than cycle avoidance.
2. **`p_c` side, on the quotient.** The 64-type star-stage Galton-Watson process (window `W = 6`,
   `K = 3`, `A = 4`, cutoff `10^-6`; restated in the proof) is run for the pattern `(z0,w0)`.
   The exact Collatz-Wielandt checks give `rho >= 1.016, 1.0085, 1.0064` at
   `91/1000` for `(3,4), (3,5), (4,5)`, `rho >= 1.0011` at `92/1000` for `(3,6)`, and
   `rho >= 1.0057` at `925/10000` for `(4,6)`. Every height and ladder edge a stage
   reveals lies in a height window of width `N0` or less, so for `N >= N0` the stage
   is the same function of the same number of distinct edges on `F_2 x Z/N` as on
   `F_2 x Z`, and the mean matrix is literally the same.

**Why the sandwich needs a partial cover (calibration and failure boundary).**
* *Fully generic cover.* The most general decoration of this shape is a quotient of
  `F_2 x Z^5`, with all five heights independent. There the chord-weighted Schur
  threshold is only `≈ 0.0898` (memory 3: `C = 1.0026` at `p = 0.090`; memory 4:
  `C = 1.0072` at `p = 0.0905`). The best star-stage GW threshold for the pattern
  `(3,4)` lies between `0.089` and `0.091` (`rho = 0.990` at `0.089`). So the
  generic sandwich does not close. Monte Carlo (`mcgen.c`) shows why the generic
  cover percolates so much earlier: `P(|C| >= 2 * 10^4) = 0.014` at `p = 0.078`,
  where `S_rig` has `0.000`.
* *Common cover `F_2 x Z^3`.* Here the same height `y` is shared by
  `(a,y), (b,y), (1,y)`. This keeps the short height-mixing loops
  `(a,0)(1,y)(a,y)^{-1}` as genuine relations, and it raises the certified threshold
  to `≈ 0.093`. That is above the quotient GW thresholds of all five patterns.
* *Patterns outside the list.* `(5,6)`, `(3,7)` and `(4,7)` fail the GW check at
  `0.0925` (`rho = 0.9963, 0.9922, 0.9910`). They are not covered.

**What it gives the root.** The recorded attempts of
`fpbs-tree-projected-rigid-decorations-strict-thresholds` asked for "a bound uniform
in the decoration sets". This is the first such bound for rank two. The Schur side
is uniform over **all** decorations of the shape `{0,y,z},{0,y,w}` with vertical `y`,
because it lives on the cover. Only the `p_c` side depends on residues, and there
only through finitely many patterns. The obstruction to extending it is quantitative
and localised: a pattern is covered as soon as its star-stage GW certificate
survives at some `p < 93/1000`.

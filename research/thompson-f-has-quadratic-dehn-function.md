**Established (literature import).** The Dehn function of Thompson's group F is
quadratic: `δ_F(n) ≃ n^2`. Guba works with the presentation
`⟨x_0, x_1 | x_2^(x_1) = x_3, x_3^(x_1) = x_4⟩`, where `x_(k+1) = x_1^(x_0^k)`
and `a^b = b^(-1) a b`; the class of the Dehn function is the same for every
finite presentation.

In the same paper, Corollary 1 says the isodiametric function of F is linear.

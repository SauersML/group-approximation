## Why sufficient

Soundness is the whole method.  A derivation is a finite sequence of
statements `x in R(H)` or `R(H) = H`, each one an instance of a rule applied
to earlier statements.  Every assignment that satisfies all the rule
instances satisfies every derived statement.  So if an assignment satisfies
a given rule set and the input (A), and is trivial on torsion-free groups,
then no derivation from that rule set proves `1 != x in R(T)` for a
torsion-free `T`.

**Rad_MF satisfies the rules.**

- (F) is `mf-radical-functoriality`.
- (S) is `mf-radical-saturation-along-any-homomorphism`.
- (X) is `full-mf-radical-groups-form-an-extension-colimit-class`.
- (I) is `corona-finite-index-radical-heredity`.
- (C) is the list of torsion-conclusion theorems, sound by definition.
- (D) holds because, when `N <= Rad_MF(H)`, every corona representation of
  `H` kills `N`.  So corona representations of `H` and of `H/N` are the same
  maps, and the preimage of `Rad_MF(H/N)` is `Rad_MF(H)`.

Both countermodels below are intersections `Rad_MF intersect P` with `P` a
normal-subgroup assignment.  For an intersection:

- (F), (D) and (I) hold if they hold for `P`;
- (X) holds if the class `{P(H) = H}` has the same closure properties;
- (S) holds if `P` satisfies (F) and `P(Q)` is normal.  Then `f(d)` lies in
  `P(Q)`, the normal closure `Q` of `f(d)` lies in `P(Q)`, and so `P(Q) = Q`.

**Unconditional form.**  The intersections satisfy input (A) exactly when
`Rad_MF` does.  The bare assignments `Phi` and `T` satisfy the same rule
lists, and they satisfy (A) *unconditionally*, because `St_20(L)` lies in
`Cl` (step (a)6).  So the obstruction does not assume endpoint 2.  The
intersections are recorded because they also respect the true inclusion
`R <= Rad_MF`.

## (a) The class `Cl` and `Phi`

`Cl` is the class of groups with no nontrivial finite quotient and no
nontrivial torsion-free quotient.

1. **Closure properties.**  `Cl` is closed under quotients, extensions,
   arbitrary free products, amalgams and directed colimits.  In each case a
   homomorphism to a finite or torsion-free group is trivial on every
   constituent, since each constituent's image is a finite or torsion-free
   quotient of it.  The constituents generate the group, or, for an
   extension, trivial on `A` means the map factors through `C`.
2. **`Phi(H)` is the largest `Cl`-subgroup.**  Let `Phi(H)` be the subgroup
   generated by all `Cl`-subgroups of `H`.  It is a quotient of their free
   product, so it lies in `Cl`.  It is characteristic, hence normal.  Then
   `Phi(H) = H` exactly when `H` is in `Cl`, which gives (X) by step 1.
3. **(F).**  The image of a `Cl`-subgroup is a quotient, so it lies in `Cl`.
4. **(I).**  Let `E <= H` have finite index and let `C <= H` be in `Cl`.
   Then `C intersect E` has finite index in `C`, and `C` has no finite
   quotient, so `C <= E`.  Hence `Phi(H) <= E`, and `Phi(E) = Phi(H)`.  With
   heredity this gives
   `Rad*(E) = E intersect Rad_MF(H) intersect Phi(H) = E intersect Rad*(H)`.
5. **(D).**  Let `N <= Phi(H)` be normal and let `P` be the preimage of
   `Phi(H/N)`.
   - `P/Phi(H)` is a quotient of `Phi(H/N)`, so it lies in `Cl`.
   - `P` is an extension of `Phi(H)` by a `Cl`-group, so it lies in `Cl`.
   - Hence `P <= Phi(H)`.  The reverse inclusion is (F).
   Intersect this with (D) for `Rad_MF`.
6. **(A).**  `G = St_20(L)` has no nontrivial finite quotient: the
   elementary group is simple and infinite (`binary-leavitt-elementary-group-is-simple`),
   and the kernel `K_2` of `G -> EL_20(L)` is central.  Let `M` be normal
   in `G`.
   - If `M K_2 = G`, then `G/M` is a quotient of `K_2`.  It is abelian and
     perfect, so trivial.
   - Otherwise `M <= K_2`.  Then `x_12(1)`, an involution in characteristic
     2, maps to a nontrivial element of order 2 in `EL_20(L)`, so its image
     in `G/M` is a nontrivial torsion element.

   So `G` is in `Cl`, and `Rad*(G) = G` by (A).  The same dichotomy applied
   to finite quotients gives no finite quotient.
7. **Torsion-free groups.**  If `H` is torsion-free, every `Cl`-subgroup is
   a torsion-free quotient of itself, so it is trivial.  Hence `Rad*(H) = 1`.

## (b) The torsion-free residual `T`

Let `T(H)` be the intersection of all normal `M` with `H/M` torsion-free.
`H/T(H)` embeds in the product of those quotients, so it is torsion-free.
It is the universal torsion-free quotient.

1. **(F).**  `H -> H/T(H)` composed with `f` is a torsion-free quotient of
   `G`, so it kills `T(G)`.
2. **(X).**  `T(H) = H` means `H` has no nontrivial torsion-free quotient.
   This class is closed under extensions, colimits, free products and
   amalgams by the argument of (a), step 1.
3. **(D).**  For `N <= T(H)`:
   - `H/T(H)` is a torsion-free quotient of `H/N`, so `T(H/N) <= T(H)/N`;
   - `(H/N)/T(H/N)` is a torsion-free quotient of `H`, so
     `T(H) <= preimage of T(H/N)`.
4. **(C).**  Every finite-order element dies in every torsion-free
   quotient, so every torsion-generated `K` lies in `T(H)`.  A (C)-instance
   gives `K <= Rad_MF(H)`, so `K <= Rad#(H)`.
5. **(A).**  From (a) step 6, `T(G) = G`.
6. **Torsion-free groups.**  For torsion-free `H`, `T(H) = 1`.
7. **(I) fails.**  Let `T_0` be any torsion-free non-MF group, for example
   the one supplied by `torsion-free-finitely-presented-non-mf`.  It is used
   only to exhibit the failure and enters no goal route.
   - Take `1 != a in Rad_MF(T_0)`, `H = (T_0 x T_0) x| <s>` with `s` the
     swap, and `E = T_0 x T_0`, which is torsion-free of index 2.
   - `(a, a^-1)` lies in `Rad_MF(E)` by (F) along the two coordinate
     inclusions.  By (F) along `E <= H` it lies in `Rad_MF(H)`.
   - It also equals `[(a,1), s]` up to orientation, so it dies in every
     torsion-free quotient of `H`, because `s` does.  Hence it lies in
     `Rad#(H) intersect E`.
   - But `Rad#(E) = 1`.

## (c) Small-kernel kill

1. The outer action `G -> Out(N)` has image a quotient of `G` inside a
   residually finite group.  A nontrivial image would give a nontrivial
   finite quotient of `G`, so the image is trivial.
2. Hence every element of `Et` acts on `N` by an inner automorphism of `N`,
   and `Et = N C` with `C = C_Et(N)`.
3. `C intersect N = Z(N)` is central in `C`, and `C/Z(N)` is isomorphic to
   `Et/N`, which is `G`.
4. By the universal coefficient theorem,
   `H^2(G; Z(N)) = Hom(H_2 G, Z(N)) + Ext(H_1 G, Z(N)) = 0`.  So `C` splits
   as `Z(N) x G`, and `G` embeds in `Et`.
5. For `St_20(L)`: it is perfect, and its `H_2` vanishes for `n >= 5`
   (`steinberg-group-homology-gives-k2-and-k3`: centrally closed).  The
   element `x_12(1)` is an involution.  `Out(Z^k) = GL_k(Z)` is linear, and
   `Out(F_n)` and surface mapping class groups are residually finite
   (Grossman).

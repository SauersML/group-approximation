Let `X` be an infinite minimal subshift, `R = LC(X,F_q) ⋊_T Z`, and `G = EL_3(R) = E(3,R)`. This route uses no towers,
no finite simple groups, and no stable rank.

1. **Condition (a).** By `minimal-subshift-algebra-is-simple-lef-ring`, item 2, `R` is simple with centre `F_q`. So its
   only proper two-sided ideal is `0`. For `I = 0`, Stepanov's condition (a) reads `[GL(3,R,0), E(3,R)] = E(3,R,0)`,
   and both sides are `{1}`.
2. **Condition (b)** for `I = 0` is item 2 of `amenable-crossed-products-meet-stepanov-condition-b`, with
   `Γ = Z`.
3. **Sandwich.** Stepanov's Theorem 4.4 (`stepanov-linear-dependence-standard-normal-structure`) now gives part
   (1.6)(3). Every subgroup `H ≤ GL(3,R)` normalized by `E(3,R)` satisfies `E(3,R,I) ≤ H ≤ C(3,R,I)` for a unique ideal
   `I`. The proof on p. 2152 ends with exactly this sandwich. Since `R` is simple, `I = 0` or `I = R`.
   - If `I = R`, then `H ⊇ E(3,R) = G`.
   - If `I = 0`, then `H ≤ C(3,R,0)`, the centre of `GL(3,R)`, which is `Z(R)^× I_3 = F_q^× I_3`.
4. **Conclusions.** A normal subgroup `N ⊴ G` is normalized by `E(3,R)`, so either `N = G` or `N ≤ F_q^× I_3`.
   - So `Z(G) ⊆ F_q^× I_3` and `G/Z(G)` is simple.
   - `G` is infinite because `e_12(LC(X,F_q)) ≤ G`. It is finitely generated by item 1 of the ring node and the
     commutator identity `[e_ik(r), e_kj(s)] = e_ij(rs)`.
   - If `G/N` is finite, `N` is not central, since `G` is infinite and `Z(G)` is finite. So `N = G`, and `G` has no
     nontrivial finite quotient.

Over `F_2` the centre is trivial, so `G` is simple. The same argument gives `EL_n(R)/Z` simple for every `n ≥ 3`, and
`LC(X,K) ⋊ Γ` for any amenable `Γ` and any field `K` whenever the crossed product is simple.

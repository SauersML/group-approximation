**Direct proof** (lane proof, elementary, not reviewed; no priority claimed). This is the
argument of `shell-germ-algebra-fp-singular-ball-proof`, run modulo `J`. Notation is as in that
route. That includes the fibre matrices `a_(yx) ∈ K[Q]`, the words `W_m(x) ∈ F`, and the finite
set `X_0` of columns whose relator paths visit `p`. From
`shell-germ-singular-ideal-is-generated-at-the-singular-point` we use `M`, `J_p` and
`e_n = 1_([0^n])`.

## Step 0: presentation

`A/J` is generated by the images of `s_0, s_1, t_0, t_1, u_g`, which generate `A`. If `A/J` is
finitely presented, then on these generators the kernel of `K<gens> -> A/J` is the ideal
generated by finitely many `r_1, ..., r_k`. Each `r_i` evaluates in `A` to an element of `J`.

## Step 1: three facts about the fibre model

**(a) Entries of singular elements are local singular.** Let `f ∈ J` and `x, y ∈ Ω`. The entry
`f_(yx)` is the restriction to `G_p^p` of `f' = 1_(C_y^(-1)) f 1_(C_x) ∈ J`, where `C_x` is the
bisection of `0^(|u|) z |-> u z` with germ `γ_x` at `p`.
- By item 1 of that node, `f'` lives on germs over a finite set.
- So for large `N`, `e_N f' e_N` is supported on `G_p^p`.
- Its restriction there is `f_(yx)`. By item 2 of that node, `f_(yx) ∈ J_p`.

**(b) No shift polynomial is local singular.** `τ` acts on `N` by `n |-> n + 1`. For
`0 ≠ x = Σ_j c_j τ^j`, the element `x · e_n = Σ_j c_j e_(n+j)` is nonzero for every `n`. So
`K[<τ>] ∩ J_p = 0`.

**(c) Local singular elements come from `J`.** Let `z = Σ_W c_W W ∈ K[F]` with
`π(z) ∈ J_p`. Put `m_z = Σ_W c_W m_W`, where `m_W` substitutes `τ -> s_0`, `τ^(-1) -> t_0` and
`g -> u_g`. Then `m_z e_n ∈ J` for all large `n`.
- `m_W = 1_(B_W)`, where the bisection `B_W` has germ `π(W)` at `p`.
- Words with the same germ give bisections that agree on some `[0^n]`. So for large `n`,
  `m_z e_n = Σ_q c_q 1_([e_q, [0^n]])` with `c_q = Σ_(π(W) = q) c_W`.
- This is the element `h_(π(z))` of the proof of item 2 of
  `shell-germ-singular-ideal-is-generated-at-the-singular-point`.
- For large `n` it is supported on `G_p^p`, since `π(z) ∈ J_p`. The unit `p` is not isolated,
  so the support has empty interior, and `m_z e_n ∈ J`.

## Step 2: a finite set of local relators

For a relator `r_i = Σ_m c_m m`, a column `x` and a row `y`, put
`ε_i(y,x) = Σ_(m : path from x defined, z_0 = y) c_m W_m(x) ∈ K[F]`. By (a),
`π(ε_i(y,x)) = (r_i)_(yx) ∈ J_p`.

**Far columns vanish formally.** Take `x ∉ X_0`. Every `W_m(x)` is freely equal to
`τ^(N_m(x))`, so `π(ε_i(y,x)) ∈ K[<τ>] ∩ J_p = 0` by (b). Since `τ` has infinite order, the
coefficients `c_m` with a fixed `N_m(x)` sum to `0`. So `ε_i(y,x) = 0` already in `K[F]`.

**Near columns.** Let `E_0` be the set of the `ε_i(y,x)` with `x ∈ X_0`. It is finite, since for
each `x` only finitely many rows occur. Put `Λ_0 = K[F]/(E_0)`, a two-sided ideal quotient. Since
`π(E_0) ⊆ J_p`, `π` induces a surjection `Λ_0 -> Λ = K[Q]/J_p`.

## Step 3: the model

Send each generator to its monomial column-finite `Ω × Ω` matrix, with entries `[τ^c]` or `[g]`
read in `Λ_0`. The `(y,x)` entry of the image of `r_i` is `[ε_i(y,x)]`:
- it is `0` in `Λ_0` for `x ∈ X_0`, by definition of `E_0`;
- it is `0` for `x ∉ X_0`, by step 2.

So this unital homomorphism `K<gens> -> M_Ω(Λ_0)` kills `(r_1, ..., r_k)`, and it induces a
unital homomorphism `ψ : A/J -> M_Ω(Λ_0)`.

## Step 4: `Λ_0 -> Λ` is injective

Let `z ∈ K[F]` with `π(z) ∈ J_p`.
- **In the model.** Every letter fixes the column `p`, with `(p,p)` entry the letter. So the
  `p`-column of `ψ(m_z)` is the single entry `[z]` at `(p,p)`. The `p`-column of
  `ψ(e_n) = ψ(s_0^n t_0^n)` is `1` at `(p,p)`.
- **In `A/J`.** By (c), `m_z e_n = 0` in `A/J` for large `n`.

Taking the `(p,p)` entry of `ψ(m_z e_n) = 0` gives `[z] = 0` in `Λ_0`. So `Λ = K[F]/(E_0)` is
finitely presented, which proves item 1.

**`Q` embeds in `Λ^×`.** Suppose `q - 1 ∈ J_p`. Then `q e_n = e_n` for large `n`, so
`σ_q(n) = n` on large shells. A representative therefore fixes every point `0^n 1 w` with `n`
large, and it fixes `p`. So it is the identity on a cylinder around `p`, and `q = 1`.

## Step 5: local rigidity (item 2)

Let `X = ⊔_(H ∈ 𝓛) Q/H` be the Schreier boundary. By
`shell-germ-singular-ideal-is-the-boundary-annihilator`, `J_p = Ann_(K[Q]) K[X]`, so every
`e ∈ E_0` acts as `0` on `K[X]`.

Let `ℓ` bound the lengths of the words in `E_0`, and let `Y` be an `F`-set whose rooted
`ℓ`-balls are each isomorphic, as labelled graphs, to some rooted `ℓ`-ball of `X`. Fix
`e = Σ c_W W ∈ E_0` and `y ∈ Y`, and choose `x'` with `B_ℓ(y) ≅ B_ℓ(x')`.
- Every `W·y` is reached by a path of length at most `ℓ` inside `B_ℓ(y)`.
- The isomorphism sends `W·y` to `W·x'`, and it preserves which of these coincide.
- So `e·y` and `e·x' = 0` have the same coefficient pattern, and `e·y = 0`.

So the ideal `(E_0)` kills `K[Y]`, and `K[Y]` is a `Λ_0 = Λ`-module. If `π(W) = 1`, then
`W - 1 ∈ ker(K[F] -> Λ) = (E_0)`, so `W` acts trivially on `Y`. `∎`

## Remark

With `A` in place of `A/J`, the relators have entries exactly `0` rather than in `J_p`, so the
matched words give group relators. That is `shell-germ-algebra-fp-singular-ball-proof`. The only
extra ingredient here is (b). Modulo `J`, far columns still carry no relations, because a
nonzero shift polynomial is never singular.

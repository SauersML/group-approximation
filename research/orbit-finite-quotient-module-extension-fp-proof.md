Notation as in the claim: `M = ⊕_i F_p[W/H_i]` with basis `e_(i, gH_i)`, `K <= M` a
finitely generated submodule, and `S = M/K`. Let `W = <Y | R>` with `Y, R` finite. Let
`T_i` be a finite generating set of `H_i`, written as words in `Y`, and `D_ij` a finite
set of double coset representatives of `H_i \ W / H_j`, also written as words. Let
`κ_1, ..., κ_m` generate `K` as a module, and write each as a finite sum
`κ_l = Σ c_(l,q) e_(i_q, g_q H_(i_q))` with words `g_q` and `c_(l,q) ∈ {0, ..., p-1}`.

**Presentation.** Let `Γ^` be the group with generators `Y ∪ {x_1, ..., x_k}` and
relators

1. `R`;
2. `x_i^p` for each `i`;
3. `[x_i, t]` for `t ∈ T_i`;
4. `[x_i, d x_j d^(-1)]` for `d ∈ D_ij`;
5. `Π_q (g_q x_(i_q) g_q^(-1))^(c_(l,q))` for each `l`, in any fixed order.

This is finite.

**Step 1: `W` is a retract.** Sending every `x_i` to `1` kills relators 2–5 and
preserves `R`, so `Γ^ -> W` retracts the evident map `W -> Γ^`. Hence `W <= Γ^` and
`Γ^ = N ⋊ W`, where the kernel `N` is the normal closure of the `x_i`.

**Step 2: conjugates are indexed by cosets.** For `g ∈ W` put `x_i^g = g x_i g^(-1)`.
Relators 3 give `h x_i h^(-1) = x_i` for every `h ∈ H_i`, so `x_i^g` depends only on
`g H_i`; write it `x_i^(gH_i)`. The subgroup these elements generate is normalized by `W`
and contains every `x_j`, so it is normal in `Γ^` and equals `N`.

**Step 3: `N` is abelian of exponent `p`.** Take `g, g' ∈ W` and write
`g^(-1) g' = h d h'` with `h ∈ H_i`, `d ∈ D_ij`, `h' ∈ H_j`. Then
`x_j^(g^(-1) g') = h x_j^d h^(-1)`, and

    g^(-1) [x_i^g, x_j^(g')] g = [x_i, h x_j^d h^(-1)] = h [h^(-1) x_i h, x_j^d] h^(-1) = h [x_i, x_j^d] h^(-1) = 1

by relators 3 and 4. So the generators of `N` commute, and relators 2 give them order
dividing `p`. Hence `N` is an `F_p`-vector space on which `W` acts linearly by
conjugation.

**Step 4: `N` is a quotient of `S`.** By Steps 2–3, `e_(i, gH_i) -> x_i^(gH_i)` extends
to a surjective `F_p W`-module map `M -> N`. Relators 5 say that each `κ_l` maps to `0`,
and the kernel is a submodule, so `K` maps to `0`.

**Step 5: comparison.** In `S ⋊ W` send `Y` to `W` and `x_i` to the image `v_i` of
`e_(i, H_i)`. Relators 1–5 hold there: `R` holds in `W`; `v_i` has order dividing `p`;
`H_i` fixes `e_(i, H_i)`; `S` is abelian; `κ_l = 0` in `S`. So there is a homomorphism
`Γ^ -> S ⋊ W` that is the identity on `W` and sends `x_i^(gH_i)` to `g·v_i`. The
composite `M -> N -> S` is the quotient map, so the kernel of `M -> N` lies in `K`; by
Step 4 it equals `K`, and `N -> S` is an isomorphism. A homomorphism of semidirect
products that is bijective on both factors is bijective, so `Γ^ ≅ S ⋊ W`, which is
therefore finitely presented.

**Consequence.** If `W` acts faithfully on `S`, an element fixing every point of `O`
fixes a spanning set, hence all of `S`; so `W` acts faithfully on `O`. Let
`P_i = Stab_W(v_i)`. Since `H_i` fixes `e_(i, H_i)`, `H_i <= P_i`, so `P_i` is the union
of the double cosets `H_i d H_i` (`d ∈ D_ii`) that meet it, and `P_i` is generated by
`T_i` and those finitely many `d`. Point stabilizers on `W·v_i ≅ W/P_i` are conjugates
of `P_i`. The `W`-orbit of `(g·v_i, g'·v_j)` corresponds to the double coset
`P_i g^(-1) g' P_j`, and `H_i x H_j -> P_i x P_j` is onto, so there are finitely many
orbits on `O × O`. With `W` finitely presented, BFFHZ's three conditions
(arXiv:2503.21882, quoted verbatim on `orbit-finite-affine-actions-are-type-a`) hold for
`W` acting on `O`.

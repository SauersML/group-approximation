Lane proof (`gq-steinberg-q`), elementary, not independently reviewed; referee requests sent.

## Setting

As in `harmonic-elimination-puts-q-in-odometer-crossed-products`:
- `Γ` is a finitely generated group with finite generating set `S`.
- `Γ = Γ_0 ⊋ Γ_1 ⊋ …` is a chain of finite-index normal subgroups with `∩ Γ_n = 1`.
- `K = lim Γ/Γ_n` is the odometer.
- `X` is a Γ-set with a Γ-map `π : X -> K`.
- `x_∞ ∈ K` is arbitrary, and `ℓ(y) = sup{n : y_n = (x_∞)_n}`.
- `f = f_K ∘ π` with `f_K(y) = 1/(1+ℓ(y))` and `f_K(x_∞) = 0`.

Let `R ⊆ F(X,Q) ⋊_alg Γ` be the unital ring generated by:
- the units `u_s^(±1)`, `s ∈ S`;
- finitely many functions `h_1, …, h_r : X -> Z` with finite range;
- `f`.

Here `F(X,Q)` is the ring of all functions. Compact `X` with continuous `π` and `h_i ∈ LC(X,Z)` is the
case of interest. Then `Q ⊆ R`, by the elimination node, whose identity is pointwise.

## Statement

1. **No finitely presented ring maps to R and contains Q.** For every finitely presented unital ring `P`
   with a unital ring homomorphism `P -> R`, only finitely many primes are invertible in `P`. In
   particular `R` is not finitely presented.
2. **E_N(R) is not finitely presented.** For every `N >= 3` the group `E_N(R)` is not finitely presented.
   If `Z(E_N(R))` is finite, `PE_N(R) = E_N(R)/Z(E_N(R))` is not finitely presented either.
3. **Instances.**
   - `R_T` of `sl3-toeplitz-harmonic-ring-is-simple-and-k1-rational`: `Γ = SL_3(Z)`, letter cylinders,
     any base point. `Z(E_N(R_T)) ⊆ {±I}`, so for every `N >= 3` none of `R_T`, `E_N(R_T)`,
     `PE_N(R_T)` is finitely presented.
   - The odometer ring `R_K = ⟨u_s^(±1), f⟩`, with `X = K`.

## Proof

**Truncation.** For `k >= 1` define `f_k : X -> Z[1/(k+1)!]` by:
- `f_k(x) = f(x)` if `ℓ(πx) < k` or `ℓ(πx) = ∞`;
- `f_k(x) = 1/(k+1)` if `k <= ℓ(πx) < ∞`.

Let `A_k = Z[1/(k+1)!]` and `T_k = F(X, A_k) ⋊_alg Γ`, a unital ring. For a prime `p > k+1`, reduction
`A_k -> F_p` gives a unital map `T_k -> F(X, F_p) ⋊ Γ`, which is nonzero when `X ≠ ∅` and sends `p` to `0`.
So `p` is not invertible in `T_k`.

**Lemma (finitely many identities survive truncation).** Let `P_1, …, P_q` be noncommutative integer
polynomials in the symbols `u_s^(±1)`, `h_i`, `f` that vanish in `F(X,Q) ⋊ Γ`. Then for all large `k` they
also vanish when `f` is replaced by `f_k`, with `u_s` and `h_i` unchanged.

*Proof of the lemma.*
- **Expansion.** Push the units to the right with `u_g φ = (φ∘g^(-1)) u_g`. Then
  `P_t = Σ_γ C_(t,γ)(h_i∘g, f∘g : g ∈ F) u_γ`, where `F ⊂ Γ` is a finite set determined by the formal
  polynomials and each `C_(t,γ)` is an integer polynomial. The same expansion holds for any function in
  place of `f`. The `u_γ` are a basis over `F(X,Q)`, so each `C_(t,γ)(h∘g, f∘g)` vanishes pointwise on `X`.
- **Choice of k.** Let `k_0` exceed `ℓ(g g'^(-1) x_∞)` for all `g ≠ g'` in `F`. This is finite, because
  `Γ` acts freely on `K`. Fix `x` and write `z = πx`.
  - *Case 1: `ℓ(gz) < k` for all `g ∈ F`, or some `g_0` has `ℓ(g_0 z) = ∞`.* Then `f_k∘g = f∘g` at `x` for
    all `g ∈ F`. When `ℓ(g_0 z) = ∞` and `g ≠ g_0`, this uses `ℓ(gz) = ℓ(g g_0^(-1) x_∞) < k_0`, from
    `(hy)_n = h y_n`. So the value at `x` is the true value `0`.
  - *Case 2: some `g_0 ∈ F` has `k <= ℓ(g_0 z) < ∞`, with `k >= k_0`.* Then `g_0` is unique. For every
    `g ≠ g_0`, `ℓ(gz) = c_g := ℓ(g g_0^(-1) x_∞) < k`. Let `σ(x) = (h_i(gx))_(i, g ∈ F)`, which ranges over a
    finite set `Σ`. At `x`, `C_(t,γ)` equals `Q_σ(t)` with `t = f(g_0 x)`, a polynomial in one variable
    determined by `(σ(x), (c_g))`.
- **Realized levels.** For `σ ∈ Σ` and `g_0 ∈ F` let `J(σ, g_0)` be the set of `j` with `k_0 <= j < ∞` such
  that some `x` has `ℓ(g_0 πx) = j` and `σ(x) = σ`.
  - If `J(σ, g_0)` is finite, take `k` above its maximum. Then no `x` in Case 2 has this `(σ, g_0)`.
  - If it is infinite, `Q_σ` vanishes at infinitely many distinct values `1/(j+1)`. So `Q_σ = 0`, and it
    vanishes at `1/(k+1)`, the value of `f_k(g_0 x)`.
- **Conclusion.** With `k` beyond `k_0` and all finite maxima (there are finitely many), every
  `C_(t,γ)(h∘g, f_k∘g)` vanishes at every `x`. ∎

**Part 1.** Let `P = ⟨y_1, …, y_m | Ψ⟩` be finite and `φ : P -> R` unital. Write `φ(y_j) = w_j(u, h, f)`.
Each `ψ ∈ Ψ` gives an identity `ψ(w(u,h,f)) = 0` in `R`. By the lemma, for large `k`,
`y_j -> w_j(u, h, f_k)` respects `Ψ`. This defines a unital map `φ_k : P -> T_k`. If `p` were invertible
in `P`, `φ_k(p^(-1))` would invert `p` in `T_k`, which is impossible for `p > k+1`. Take
`P = R` to see that `R` is not finitely presented.

**Part 2.** `E_N(R)`, `N >= 3`, is generated by `e_ij(g)` for `g ∈ {1, u_s^(±1), h_i, f}`, since
`e_ij(ab) = [e_ik(a), e_kj(b)]`. Suppose finitely many words `ω_1, …, ω_q` in these generators give a
presentation. Each relation `ω_t = I` is a matrix identity whose `N^2` entries are polynomial identities of
`R`. By the lemma, for large `k` the assignment `e_ij(g) -> e_ij(g_k)` respects them, where `g_k` replaces
`f` by `f_k`. This gives a homomorphism `Θ_k : E_N(R) -> GL_N(T_k)`.

Now take a prime `p > k+1`. Let `W_p` be a ring word in the generators with `W_p = 1/p` in `R`, and let
`ε_p` be the corresponding group word for `e_12(W_p)`, from `e_ij(a+b) = e_ij(a)e_ij(b)` and the
commutator formula. Then `ε_p^p = e_12(1)` in `E_N(R)`, while `Θ_k(ε_p) = e_12(W_p(u,h,f_k))`. So
`p · W_p(u,h,f_k) = 1` in `T_k`, a contradiction. A quotient of a group that is not finitely presented by a
finite central subgroup is not finitely presented, which gives the claim for `PE_N(R)`. ∎

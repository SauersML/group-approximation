## Imports

- **(HSZ) Hyde–Skipper–Zaremsky, arXiv:2605.20564v2 (29 May 2026), Theorem A, verbatim:**
  "Let G be a finitely generated subgroup of V, with S a finite symmetric generating set for G. Let X be the
  G-orbit of some κ₀∈ℭ, and let Γ be the action graph for G acting on X, that is, the Schreier graph with
  respect to the subgroup Stab_G(κ₀). Then Γ is quasi-isometric to a tree."
  Here ℭ = {0,1}^ℕ, and `V` acts (on the right) by homeomorphisms that are locally prefix replacements.
  Read from the arXiv HTML; the proof itself was not re-checked here.
- **(QT) A finitely generated group quasi-isometric to a tree is virtually free.** This is standard (Gromov).
  One route: such a group is finitely presented (a QI invariant), hence accessible (Dunwoody), and a
  one-ended vertex group of its terminal splitting would be a one-ended group quasi-isometrically embedded
  in a tree, which is impossible. Recalled, not read at source.

## Two elementary facts about V

Write `v ∈ V` as a bijection between two finite cone partitions, `w_i κ ↦ u_i κ` for `i = 1, …, m`.

**(F1) `Fix(v) = U_v ⊔ P_v`, with `U_v` clopen and `P_v` finite, and `int Fix(v) = U_v`.** A point `w_i κ` is
fixed iff `u_i κ = w_i κ`. There are three cases:
- If `u_i = w_i`, the whole cone is fixed.
- If `|u_i| = |w_i|` and `u_i ≠ w_i`, no point of the cone is fixed.
- If `|w_i| < |u_i|`, a fixed point forces `u_i = w_i s` and then `κ = sκ`, i.e. `κ = s^∞`. That is one point;
  the case `|u_i| < |w_i|` is symmetric.

So `U_v` is the union of the cones with `u_i = w_i`, and `P_v` has at most one point in each other cone. No
point of `P_v` is interior to `Fix(v)`: an open set around it meets its cone in infinitely many points, but
the cone contains only one fixed point. Every point of `P_v` is eventually periodic.

**(F2) Germs at a fixed point embed in `Z`.** Let `v(x) = x`. Near `x`, `v` acts as `wκ ↦ uκ` with `w` and `u`
both prefixes of `x`.
- If `|w| = |u|`, then `w = u`, and `v` is the identity on a neighborhood of `x`.
- Otherwise `x` is eventually periodic, as in (F1).

The map `germ ↦ |u| − |w|` does not change when both prefixes are extended by the same letter, and it adds
under composition. It is injective by the first case. So the germ group of `V` at `x` embeds in `Z`, and it
is trivial unless `x` is eventually periodic.

## Proof

Let `G ≤ V` be generated by a finite symmetric `S`.

**(1)** Suppose `Stab_G(x) = 1`. The action graph on `Gx` is then the Schreier graph for the trivial subgroup,
i.e. the Cayley graph `Cay(G,S)`. By (HSZ) it is quasi-isometric to a tree, so `G` is virtually free by (QT).

**(2)** Suppose `int Fix(g) = ∅` for every `g ≠ 1`. By (F1), each `Fix(g) = P_g` is finite, so
`E = ⋃_{g≠1} P_g` is countable. `C` is uncountable, so some `x ∉ E` exists. Then `Stab_G(x) = 1`, and (1)
applies.

**(3a)** Let `E = ⋃_{g≠1} (Fix(g) ∖ int Fix(g)) = ⋃_{g≠1} P_g`, which is countable. Take `y ∈ K ∖ E` and
suppose `gy = y` with `g ≠ 1`. Then `y ∈ Fix(g)` and `y ∉ int Fix(g)`, since `y ∉ O`. So `y ∈ P_g ⊆ E`,
which is a contradiction. Hence `Stab_G(y) = 1`, and `G` is virtually free by (1). So if `G` is not
virtually free, `K ⊆ E` is countable.

**(3b)** Take `x ∈ K`.
- The kernel of the germ map `Stab_G(x) → Germ_x(V)` consists of the elements that are the identity near `x`,
  i.e. those `g` with `x ∈ int Fix(g)`. Since `x ∉ O`, the only such element is `g = 1`.
- So by (F2), `Stab_G(x)` embeds in `Z`.
- It is not trivial, by (1), since `G` is not virtually free. So `Stab_G(x) ≅ Z`, the germ group at `x` is
  nontrivial, and `x` is eventually periodic.

**(3c)** This is (HSZ) at `κ₀ = x`. ∎

## Where a negative answer to Question 4.7 now stands (open)

Let `Γ` be a torsion-free one-ended hyperbolic group, e.g. `π_1(Σ_2)`, with `Γ ≤ V`. By the claim,
`K = C ∖ O` is a countable set of eventually periodic points with cyclic stabilizers `⟨c_x⟩`, and every
`Γ/⟨c_x⟩` is quasi-isometric to a tree.

**Lemma L (open; sketch only).** For `c ≠ 1` of infinite order, `Γ/⟨c⟩` is not quasi-isometric to a tree.
- Sketch: `⟨c⟩` is quasiconvex. If `⟨c⟩\Cay(Γ)` is hyperbolic with Gromov boundary `(∂Γ ∖ {c^±})/⟨c⟩`, this
  follows. The boundary `∂Γ` of a one-ended hyperbolic group is a connected, locally connected continuum
  without cut points (Bestvina–Mess, Bowditch, Swarup, recalled). So `∂Γ ∖ {c^±}` has open, nondegenerate
  components, and their images are nondegenerate connected subsets of the quotient. Quasi-trees, by
  contrast, have totally disconnected boundaries.
- Not verified: hyperbolicity of the quotient, and the boundary identification.
- For surface groups, `⟨c⟩\H²` is a hyperbolic annulus. Its funnels have circle boundary, so the lemma is
  very plausible there.

**With Lemma L, `K = ∅`.** Then, by compactness, `C = W_1 ⊔ … ⊔ W_n` with each clopen `W_i` fixed pointwise
by some `g_i ≠ 1`.
- By `cyclic-centralizer-subgroups-of-nv-have-meeting-supports`, two clopen sets `W`, `W'` with
  `W ∪ W' = C` never both have nontrivial pointwise fixers. Their moved sets would be disjoint.
- So no nontrivial element of `Γ` is supported inside any `W_i`.
- A contradiction still needs a compression: some `γ ∈ Γ` mapping a support into some `W_i`. For example,
  use the flow power of an element whose attractors lie in `W_i` and whose repellers avoid the support.
  Nothing on main supplies this yet.

**Test for any claimed embedding of a one-ended group in `V`.** It must be almost everywhere locally trivial,
in the sense of (3a). F, `Z²` and the other known one-ended subgroups of `V` are, which is consistent.

## Statement

Let `Γ` be a periodic PL quasi-similarity group
(`pl-quasi-similarity-groups-scale-rational-lines-by-ratio`), with similarity
ratio `c : Γ -> R^x`.

1. If `c(Γ) ∩ Q^x` lies in the subgroup generated by `-1` and finitely many
   primes, then `Γ` contains no subgroup isomorphic to any of
   `Aff(Q) = Q x| Q^x`, `B_2(Q)`, `SL_n(Q)`, `PSL_n(Q)`, `GL_n(Q)`, `PGL_n(Q)`
   (`n >= 2`). This holds in particular if `Γ` is finitely generated: then `c(Γ)`
   is a finitely generated subgroup of `R^x`, so `c(Γ) ∩ Q^x` is too.
2. If `Γ` preserves orientation, then `Γ` contains none of `Aff(Q)`, `B_2(Q)`,
   `GL_n(Q)`, `PGL_n(Q)` (`n >= 2`), whatever `c(Γ)` is.

So the natural "Belk--Hyde--Matucci plus dilations" hosts cannot contain
`GL_n(Q)` for any `n >= 2`: `T-bar`, `<T-bar, x -> 2x>` (finitely presented,
containing `(Q,+)` and `BS(1,2)`), their Stein-type analogues over `Z[1/m]` with
dilations by the primes dividing `m`, and `x -> -x` adjoined. Since the property
passes to subgroups, no finitely presented simple group containing `GL_n(Q)` can
embed in such a group either.

## What survives

- The lemma allows a rational line scaled by the ratios in `c(Γ)`.
  `Q x|_2 Z <= <T-bar, x -> 2x>` is not excluded (open).
- To contain `Aff(Q)`, a host must scale one rational line by every prime.
  In this family that forces infinitely many independent similarity ratios,
  which a finitely generated group cannot have.

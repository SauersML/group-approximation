Notation as in the target. `G = Cay(Gamma,S)`, `Delta = |S|+1`, `|B_r| <= Delta^r`.
Left multiplication acts by graph automorphisms. For a word `w = s_1...s_l`,
`P(v,w)` is the path `v, v s_1, ..., v s_1...s_l`, and `gamma P(v,w) = P(gamma v, w)`.
Fix words `w_g`, `w_t` over `S` that represent `g` and `t`, and put
`L = max(|w_g|,|w_t|)`.

## 0. Cosets, coordinates, sites

Each left coset `c = xH` gets the coordinates `x g^i t^j <-> (i,j) in Z^2`.
The coordinates depend on the choice of `x`, but only up to a translation of
`Z^2`. The elements of `Gamma` are called *sites* when viewed inside their
coset. Two sites `u, u'` of `c` are *n.n.* if `u' in {u g^{±1}, u t^{±1}}` and
*-adjacent if `u' = u g^a t^b` with `max(|a|,|b|) = 1`.

For `gamma in Gamma`, left multiplication sends `xH` to `(gamma x)H` and
`x g^i t^j` to `(gamma x) g^i t^j`. So it preserves the coordinates, n.n.
adjacency and *-adjacency. Since `t` is central, `t^s x g^i t^j = x g^i t^{j+s}`:
left multiplication by `t^s` maps every coset to itself and shifts the
coordinates by `(0,s)`.

Constants, all depending only on `(Gamma,S,g,t)`:

* `D = #{h in H : |h|_S <= 4L}`.
* `r_L = 1 + max{ ||(a,b)||_inf : g^a t^b in H, |g^a t^b|_S <= 4L+2 }`. This is
  finite because balls of `G` are finite.

**Star.** For a site `v`,
`star(v) = P(v,w_g) ∪ P(v,w_t) ∪ P(v g^{-1}, w_g) ∪ P(v t^{-1}, w_t)`, viewed as
a set of at most `4L` edges. Every endpoint of these edges lies within
distance `L` of `v`. So `star(v) ∩ star(v') = ∅` whenever `d(v,v') > 2L`.
Every n.n. neighbour `u'` of `u` is joined to `u` by a path inside `star(u)`.

## 1. The variables and the construction

All of the following variables are independent:

* `U_e` uniform on `[0,1]`, for each edge `e`;
* `B_e ~ Bernoulli(q)`, for each edge `e`;
* `lambda^k_{v,h}` and `lambda^k_{v,v}`, each `~ Bernoulli(p_k)` with
  `p_k = K / m_k^2`, for each `v in Gamma` and `k >= 1`.

The constants `q`, `K` and `m_k` are fixed in Section 2.

`Gamma` acts on the index sets (edges, and `Gamma x {h,v} x N`) with
stabilizers of size at most 2. So `(U,B,lambda)` is a Bernoulli shift over
actions with finite stabilizers, and it is mixing of all orders.

**Sticks.** Let `ell_k = 4 m_k` and `w_k = ceil(log_2 ell_k)`. The horizontal and
vertical level-`k` sticks based at `v` are

* `St^k_h(v) = { v g^i t^j : 0 <= i < ell_k, 0 <= j < w_k }` (an `ell_k x w_k` rectangle),
* `St^k_v(v) = { v g^i t^j : 0 <= i < w_k, 0 <= j < ell_k }` (a `w_k x ell_k` rectangle).

The stick `St^k_o(v)` is *present* if `lambda^k_{v,o} = 1`. A site `v` is *open*
if `zeta(v) := prod_{e in star(v)} B_e = 1`. So `zeta` is a function of `B`,
`P(zeta(v) = 0) <= rho := 1 - q^{4L}`, and `zeta(v)`, `zeta(v')` are independent
(jointly, for any family of sites at pairwise distance `> 2L`).

**Spine at level k.** `Y^{(k)}` is the set of edges that are

* in `star(u)` for some site `u` of some present level-`k` stick; or
* of the form `{u, us}` with `s in S` and both `u` and `us` in present level-`k`
  sticks.

`Y^{(k)}` is a function of `lambda^k` only. Put `Y_n = ∪_{k >= n} Y^{(k)}` and
`Y_∞ = ∅`.

**The family.** Let `n(t) = ceil(1/(t - p_c))` for `t > p_c`, and `n(t) = ∞` for `t <= p_c`. Define

    omega_t = xi_t ∪ ( Y_{n(t)} ∩ B ),   where B = {e : B_e = 1}.

**Properties (1), (2), (3).**

* If `t <= t'` then `n(t) >= n(t')`, so `Y_{n(t)} ⊆ Y_{n(t')}`. Also
  `xi_t ⊆ xi_{t'}`. This gives (1).
* (2) holds because `Y_∞ = ∅`.
* `omega_t` is an equivariant measurable function of `(U,B,lambda)`, which
  gives (3).

**Property (4), uniform finite energy.** For an edge `f`, whether `f` lies in
`omega_t` depends on `(U_f, B_f, lambda)`. So `omega_t` restricted to
`E \ {e}` is measurable with respect to `F_e = sigma(U_{-e}, B_{-e}, lambda)`,
which is independent of `(U_e, B_e)`. Also `Y_{n(t)}` is `lambda`-measurable,
so

    P(e in omega_t | F_e) = t + (1-t) q 1{e in Y_{n(t)}}  in  [t, t + (1-t) q].

Conditioning on the smaller sigma-field generated by `omega_t` on `E \ {e}`
averages this quantity, so the value stays in the same interval.

**Property (5), Harris–FKG.** `omega_t` is increasing in the variables
`(-U_e, B_e, lambda^k_{v,o})`: each `Y^{(k)}` is increasing in `lambda`. Harris's
inequality for increasing functions of countably many independent variables
gives (5), by approximation by functions of finitely many coordinates and
martingale convergence.

**Insertion tolerance, jointly with the marks.** Let `M = (B,lambda)` and
`Pi_e(omega, M) = (omega ∪ {e}, M)`. For every event `A`,

    P( (omega_t, M) in Pi_e A ) >= P( U_e <= t, (omega_t^{-e} ∪ {e}, M) in Pi_e A ) = t P( (omega_t^{-e} ∪ {e}, M) in Pi_e A ) >= t P( (omega_t, M) in A ).

Here `omega_t^{-e} = omega_t \ {e}`, and this set, together with `M`, is a
function of `(U_{-e}, M)`, which is independent of `U_e`. On `{U_e <= t}` we have
`omega_t = omega_t^{-e} ∪ {e}`. The last step uses
`(omega,M) in A => (omega ∪ {e}, M) in Pi_e A`.

## 2. Constants, crossings, density

Put `eps_* = 64^{-121}`, so `8 eps_*^{1/121} = 1/8`. Fix the constants in this order:

* `q in (0,1)` with `8 rho^{1/D} <= 1/4`, where `rho = 1 - q^{4L}`;
* `K` with `2 e^{-K/2} <= eps_*/2`;
* `m_k` for each `k`, satisfying all of
  - `m_k >= r_L`,
  - `1/m_k <= eps_*/2`,
  - `Delta^{2L} * 8 K w_k / m_k <= 2^{-k}`.

The last condition can be met because `w_k = O(log m_k)`.

**Lemma 2.1 (crossing).** Let `R` be an `ell x w` rectangle of sites in one
coset, with `w = ceil(log_2 ell)`. The probability that `R` has no LR crossing
(an n.n. path of open sites of `R` from its left column to its right column) is
at most `2/ell`. Symmetrically, a `w x ell` rectangle has no TB crossing with
probability at most `2/ell`.

*Proof.* By planar site duality in `Z^2`, if there is no LR crossing then there
is a self-avoiding *-path of closed sites of `R` from the bottom row to the top
row. Such a path has `k >= w` sites.

* The number of such paths with `k` sites is at most `ell 8^k`.
* Among `k` distinct sites `x h_1, ..., x h_k`, a greedy choice yields at least
  `k/D` sites pairwise at `G`-distance `> 4L`, because
  `d(x h, x h') = |h^{-1} h'|_S`. Their `zeta` values are independent.

So the probability of a given path is at most `rho^{k/D}`, and the total
probability is at most

    sum_{k >= w} ell 8^k rho^{k/D} <= ell sum_{k>=w} 4^{-k} <= 2 ell 4^{-w} <= 2/ell.

∎

**Lemma 2.2 (local emptiness).** For every finite `F ⊆ Gamma`, a.s. there is an
`n` such that no edge of `Y_n` has an endpoint in `F`. Consequently
`omega_t|_{F} = xi_t|_{F}` for all `t > p_c` close enough to `p_c`.

*Proof.*

* A site is covered by at most `2 ell_k w_k` stick positions, so
  `P(v lies in a present level-k stick) <= 2 ell_k w_k p_k = 8 K w_k / m_k`.
* If an edge of `Y^{(k)}` has endpoint `o`, then some site of a present
  level-`k` stick lies within distance `L` of `o`.

So `P(o is an endpoint of Y^{(k)}) <= Delta^{2L} 8 K w_k / m_k <= 2^{-k}`.
Borel–Cantelli and invariance give the first claim. The second follows
because `n(t) -> ∞` as `t ↓ p_c`. ∎

**Property (6), second half: theta -> 0.**

* Fix `R`. By Lemma 2.2 with `F = B_{R+1}`, the configurations
  `omega_t|_{B_{R+1}}` decrease a.s. to `xi_{p_c}|_{B_{R+1}}` as `t ↓ p_c`.
* The event `{o <-> ∂B_R}` depends only on edges with both endpoints in `B_R`.

Hence

    limsup_{t ↓ p_c} theta(t) <= lim_{t ↓ p_c} P(o <-> ∂B_R in omega_t) = P(o <-> ∂B_R in xi_{p_c}).

As `R -> ∞`, the right side tends to `P(|C(o)| = ∞ in xi_{p_c}) = 0`, by
`fpbs-critical-no-infinite-cluster` (`Gamma` is nonamenable). ∎

## 3. A unique giant inside each coset at each level

Fix a coset `c`, with coordinates, and a level `k`. Write `m = m_k`,
`ell = 4m` and `w = w_k`.

**The set Omega.** `Omega^k_c` is the set of open sites of `c` that lie in some
present level-`k` stick, with n.n. adjacency.

* **Realization.** If `u` is in `Omega^k_c`, then `star(u) ⊆ Y^{(k)} ∩ B`. Every
  n.n. neighbour of `u` is joined to `u` inside `star(u)`. So every connected
  subset of `Omega^k_c` lies in a single cluster of `Y^{(k)} ∩ B`, and hence of
  `omega_t` whenever `k >= n(t)`.
* **Monotonicity.** `Omega^k_c` is increasing in `(B, lambda^k)`.
* **Invariance.** For `h in H`, left multiplication by `x h x^{-1}` is a graph
  automorphism that maps `c = xH` to itself and sends `x h'` to
  `x h h' = x h' h`. So it shifts the coordinates of `c` by `h`, and it
  preserves the law of `(Omega^k_c, B, lambda)`. The subgroup `x H x^{-1}` is
  infinite and acts on the index sets of `(U,B,lambda)` with finite stabilizers,
  so every orbit is infinite and the Bernoulli shift is mixing under it. In
  particular every coordinate translation of `c`, and the `Z`-action by `t^s`,
  is mixing on the law of any equivariant function of `(B,lambda)`.

**Blocks.** For `z in Z^2`, `Q_z = [z_1 m, z_1 m + m) x [z_2 m, z_2 m + m)`.

* `good^h(z)`: some present horizontal stick with base coordinates `(a,b)`,
  where `a in [z_1 m - 2m, z_1 m - m)` and `b in [z_2 m, z_2 m + m - w]`, has an LR
  crossing.
* `good^v(z)`: some present vertical stick with base `(a,b)`, where
  `a in [z_1 m, z_1 m + m - w]` and `b in [z_2 m - 2m, z_2 m - m)`, has a TB crossing.
* `good(z) = good^h(z) ∧ good^v(z)`.

For a good block, let `sigma(z)` be the lexicographically first present
horizontal stick with admissible base that has an LR crossing, and fix one such
crossing by a deterministic rule. `tau(z)` and its TB crossing are defined
similarly for vertical sticks. These choices are functions of `(B,lambda)`. Let `K(z)` be the union of the two chosen crossings.

*Extents.*

* `sigma(z)` covers `i in [z_1 m - m, z_1 m + 2m)` (length `4m` from a base
  `< z_1 m - m`), with its `j`-range inside `[z_2 m, z_2 m + m)`.
* `tau(z)` covers `j in [z_2 m - m, z_2 m + 2m)`, with its `i`-range inside
  `[z_1 m, z_1 m + m)`.

**Lemma 3.1 (block probability).** `P(good(z) fails) <= 2 e^{-K/2} + 4/ell <= eps_*`.

*Proof.*

* There are at least `m * (m-w+1) >= m^2/2` admissible horizontal bases. Each is
  present independently with probability `K/m^2`, so none is present with
  probability at most `e^{-K/2}`.
* Conditional on `lambda`, the lexicographically first present admissible
  stick is fixed, and it has an LR crossing except with probability at most
  `2/ell` (Lemma 2.1), because `B` is independent of `lambda`. If it has one,
  `good^h(z)` holds.

The same bound holds for `good^v`. Finally `4/ell = 1/m <= eps_*/2`. ∎

**Lemma 3.2 (neighbours connect).** If `z` is good, then `K(z)` is connected. If
`z` and `z' = z ± e_1` or `z ± e_2` are both good, then `K(z) ∪ K(z')` is
connected.

*Proof.* The i-range of `tau(z)` lies inside the i-range of `sigma(z)`, and the
j-range of `sigma(z)` lies inside the j-range of `tau(z)`. So the two sticks meet
in a `w x w` square `R`.

* An LR crossing of the strip `sigma(z)` contains an LR crossing of `R`: take the
  last visit to the left column of `R` before the first visit to its right
  column.
* Likewise the TB crossing of `tau(z)` contains a TB crossing of `R`.
* In `Z^2`, an n.n. LR crossing and an n.n. TB crossing of a square share a site.

For `z' = z + e_1`: `tau(z')` has i-range inside
`[z_1 m + m, z_1 m + 2m) ⊆` i-range of `sigma(z)`, and it covers the j-range of
`sigma(z)`. So `sigma(z)` and `tau(z')` also meet in a `w x w` square. For
`z' = z + e_2`: `sigma(z')` has j-range inside `[z_2 m + m, z_2 m + 2m) ⊆` j-range of
`tau(z)`, and it covers the i-range of `tau(z)`. The same argument applies in
both cases. ∎

**Dependence.** `good(z)` and `K(z)` are measurable with respect to

* `lambda^k` at bases in `W_z = [z_1 m - 2m, z_1 m + 2m) x [z_2 m - 2m, z_2 m + 2m)`, and
* `B` on the stars of the sites of `W_z`.

Sticks based in `W_z` have all their sites in
`[z_1 m - 2m, z_1 m + 3m) x [z_2 m - 2m, z_2 m + 3m)`. Suppose
`||z - z'||_inf >= 6`. Then the coordinates of sites of sticks based in `W_z`
and in `W_{z'}` differ by at least `m >= r_L` in some coordinate. So those sites are
at `G`-distance `> 4L+2`, and their stars are disjoint. Hence the block states
of any family of blocks at pairwise `inf`-distance `>= 6` are independent.
Every `n` distinct blocks contain at least `n/121` of them at pairwise distance
`>= 6`.

**Peierls.** Any given *-path of `n` blocks is entirely bad with probability at
most `eps_*^{n/121} = 64^{-n}`. There are at most `8^n` such paths from a given
block.

**Lemma 3.3 (an infinite good cluster).** A.s. there is an infinite n.n.
cluster of good blocks.

*Proof.* If the origin block is bad or lies in a finite good cluster, then by
planar duality there is a *-circuit of bad blocks surrounding or containing the
origin. A circuit of length `n` passes through some block `(j,0)` with
`0 <= j <= n`. So

    P <= eps_* + sum_{n >= 1} (n+1) 8^n 64^{-n} <= eps_* + 2 sum_n n 8^{-n} = eps_* + 16/49 < 1.

The block field is invariant under translations of `m Z^2`, and it is
ergodic under them by the Invariance item above (it is an equivariant function
of `(B,lambda)` under `x H x^{-1}`). So the event of an infinite good cluster, which
has positive probability, has probability 1. ∎

**Lemma 3.4 (good circuits).** Let `A_N = [-2N, 2N]^2 \ (-N, N)^2` in block
coordinates. The probability that `A_N` contains no n.n. circuit of good blocks
surrounding the origin tends to 0 as `N -> ∞`.

*Proof.* If there is no such circuit, then a bad *-path crosses `A_N` from its
inner to its outer boundary. Its probability is at most
`8N * sum_{n >= N} 8^n 64^{-n} <= 16 N 8^{-N}`. ∎

**Lemma 3.5 (uniqueness in the coset).** A.s. `Omega^k_c` has exactly one
infinite component `J^k_c`. It contains every `K(z)` of the infinite good
cluster, and `P(u in J^k_c) = beta_k > 0` for every site `u`.

*Proof.* Let `Gamma_∞` be an infinite good block cluster. By Lemma 3.2 the set
`K_∞ = ∪_{z in Gamma_∞} K(z)` is connected and infinite, so it lies in an
infinite component `J` of `Omega^k_c`.

Let `C` be any infinite component and `u in C`. By Lemma 3.4 applied along
`N_j -> ∞` (Fatou), there are a.s. infinitely many `j` with a good circuit
`z^j_0, ..., z^j_r = z^j_0` in `A_{N_j}`. Choose `p(z) in K(z)` and join
`p(z^j_i)` to `p(z^j_{i+1})` inside `K(z^j_i) ∪ K(z^j_{i+1})`. This yields a
closed n.n. walk `W_j ⊆ Omega^k_c`.

*Winding.* Every point of the piece of `W_j` for step `i` lies within Euclidean
distance `8m` of the segment joining the centres of `Q_{z^j_i}` and
`Q_{z^j_{i+1}}`. So the straight-line homotopy from `W_j` to the block polygon
`P_j` avoids every point at distance `> 8m` from `P_j`. Choosing the good circuit self-avoiding, the polygon `P_j` is a
simple closed curve surrounding the origin at distance `>= (N_j - 1)m`, so it
has winding number `±1` around points of `(-(N_j - 9)m, (N_j - 9)m)^2`. The
walk `W_j` therefore has the same winding number around those points, and
winding number 0 around points far outside.

Take `j` large enough that `u` has winding number `±1`. The component `C` is
infinite and locally finite, so it contains an infinite n.n. ray from `u`
(Kőnig). Winding numbers are constant on connected subsets of the complement
of the curve, so the ray meets the curve `W_j`. Lattice curves intersect only
at lattice points, so the ray shares a site with `W_j`.

The block circuit also meets `Gamma_∞`, by planar Jordan separation in the
block lattice, since `Gamma_∞` is infinite and contains blocks inside the
circuit for `j` large. So `W_j` shares a block with `Gamma_∞` and is connected to
`K_∞`. Hence `C = J`.

Finally, `P(u in J^k_c)` does not depend on `u` by invariance. It is positive
because `J^k_c` is a.s. nonempty and there are countably many sites. ∎

## 4. Gluing the giants

**Lemma 4.1 (across levels).** For every coset `c` and every `k`, a.s.
`J^k_c ∩ J^{k+1}_c ≠ ∅`.

*Proof.* The events `{u in J^k_c} = {u in an infinite component of Omega^k_c}`
and `{u in J^{k+1}_c}` are increasing in `(B,lambda)`. By Harris,
`P(u in J^k_c ∩ J^{k+1}_c) >= beta_k beta_{k+1} > 0`.

Left multiplication by `t^s` maps `c` to itself, and the pair
`(J^k_c, J^{k+1}_c)` is equivariant. So the events `{t^s u in J^k_c ∩ J^{k+1}_c}`
are the images of this one under a measure-preserving mixing `Z`-action.
Birkhoff's theorem gives a.s. infinitely many such `s`. ∎

**Lemma 4.2 (across cosets).** Let `c = xH`, `s in S`, `c' = xsH ≠ c`, and `v = x`.
A.s. there is an `i in Z` such that `t^i v in J^k_c`, `t^i v s in J^k_{c'}` and
`B_{t^i v, t^i v s} = 1`. The edge `{t^i v, t^i v s}` then lies in `Y^{(k)} ∩ B`.

*Proof.* The event `E_0 = {v in J^k_c, vs in J^k_{c'}, B_{v,vs} = 1}` is an
intersection of three increasing events, each of positive probability. By
Harris, `P(E_0) >= beta_k^2 q > 0`.

Since `t` is central, `t^i v s = (vs) t^i` lies in `c'`, and left multiplication
by `t^i` maps the edge `{v,vs}` to `{t^i v, t^i v s}` and `J^k_{c}`, `J^k_{c'}` to
themselves. Birkhoff along the mixing `Z`-action by `t` gives a.s. some `i`
with `E_i` occurring.

Both endpoints lie in present level-`k` sticks. So the edge belongs to `Y^{(k)}`
by definition, and to `B` by `E_i`. ∎

**Corollary 4.3 (one spine cluster).** Fix `n`. A.s. all the sets `J^k_c` with
`k >= n` and `c in Gamma/H` lie in a single cluster of `Y_n ∩ B`, and this
cluster is infinite.

*Proof.*

* By the realization property (Section 3), each `J^k_c` is connected in
  `Y^{(k)} ∩ B`.
* The coset graph (cosets `c`, `cs` adjacent) is connected because `S` generates
  `Gamma`.
* There are countably many events in Lemmas 4.1 and 4.2, so a.s. all of them
  occur.

Lemma 4.2 connects `J^k_c` to `J^k_{c'}` for adjacent cosets, so all `J^n_c` lie
in one cluster. Lemma 4.1 connects `J^k_c` to `J^{k+1}_c`. ∎

## 5. Uniqueness of the infinite cluster (property 6, first half)

Fix `t > p_c` and `n = n(t) < ∞`. By Corollary 4.3, `omega_t ⊇ Y_n ∩ B` has an
infinite cluster `C_spine` that contains every `J^k_c` with `k >= n`.

**Number of infinite clusters.** `omega_t` is an invariant ergodic factor of
the iid field (Section 1) and is insertion tolerant. By Newman–Schulman, the
number `N` of infinite clusters is a.s. constant and lies in `{0,1,∞}`. Here
`N >= 1`.

**Suppose N = ∞.** Consider the marked configuration `(omega_t, M)` with
`M = (B,lambda)`. This is a jointly invariant, ergodic random network on the
unimodular graph `G`, and it is insertion tolerant jointly with its marks
(Section 1). By indistinguishability of infinite clusters for insertion
tolerant invariant percolation with marks (Lyons–Schramm 1999, Thm 3.3, in its
marked form, Aldous–Lyons 2007, Thm 6.15), for every invariant Borel property
`A` of (cluster, marked configuration), either a.s. all infinite clusters have
`A` or a.s. none do.

Take `A`: "the cluster contains `J^k_c` for some `k >= n` and some coset `c`".

* `J^k_c` is a Borel equivariant function of `M`, so `A` is an invariant Borel
  property.
* `C_spine` has `A`.
* Every other infinite cluster is disjoint from `C_spine`. Since all `J^k_c`
  with `k >= n` lie in `C_spine`, those clusters do not have `A`.

This contradicts indistinguishability. So `N = 1`.

*Calibration of the hypothesis.* Joint insertion tolerance is essential here.
A mark that singles out one cluster directly is not jointly insertion
tolerant, because adding an edge would merge clusters without updating the
mark. Here the marks `M` are fixed in advance and do not look at `U`, and
`Pi_e` changes only `omega`, so the hypothesis is satisfied by Section 1.

Together with Section 2, this proves property (6). ∎

## 6. What the construction says about proofs of p_c < p_u

**Recorded consequences.**

* For `t > p_c` near `p_c`, the family behaves like a Bernoulli family with no
  window. It is monotone, Bernoulli below `p_c`, FIID, uniformly finite energy
  and FKG, has no percolation in the limit `t ↓ p_c`, and has a unique infinite
  cluster for every `t > p_c`.
* The edge density satisfies
  `P(e in omega_t) <= t + P(e in Y_{n(t)}) <= t + 2^{1-n(t)} Delta^{2L} -> p_c`.
* `theta(t) >= theta_Bern(t)`, because `omega_t ⊇ xi_t`.

**Where soft arguments must break.** Take any argument deriving
`p_u > p_c` on `Cay(Gamma,S)` from the properties of the coupling
`(xi_t)_t` listed in the target. Applied to `omega_t`, it would give `N >= 2`
for some `t > p_c`, which is false. So a valid argument for `Gamma in Z` must
use a property of the product law at parameters above `p_c` that `omega_t`
lacks. Candidates are:

* **BK / Reimer.** Disjoint occurrence bounds fail in the presence of the
  positive correlations of the sticks.
* **Russo's formula and its exact form.** Pivotality with product
  derivative is exact only for product measures.
* **Upper-bound differential inequalities.** Aizenman–Barsky, Menshikov, and
  Hutchcroft's `||T_p||` inequality all bound the growth of `theta` and of
  two-point functions from above, via independence.

**Calibration.**

* **Z^2.** The same construction runs in `Z^2` (one coset, `H = Z^2`), where
  `p_c = p_u`. So it cannot prove anything false there.
* **F_2.** `F_2` is not in `Z` (it has no `Z^2` subgroup), and it has a window.
* **F_2 x Z.** It lies in `Z` and has a window for suitable `S`
  (`fpbs-simple-generating-set-with-gap-exists`). Bernoulli percolation there
  has infinitely many clusters on an interval above `p_c`, while `omega_t` has
  one. There is no contradiction, because `omega_t` is not Bernoulli: its
  marginal at `t` near `p_c` is below `p_u`, yet it has a unique infinite
  cluster.
* **Cost.** An FIID unique infinite cluster with small `theta` would force
  cost 1, and class `Z` has fixed price 1. This is consistent with
  `fpbs-sparse-spine-cost-bound`.

**ESTABLISHED ALGEBRAIC COVER WITH GAUGE-TYPING FENCE.**  For the `31`
positive detector classes whose internal `L_0` normal closures contain no
root, let `M_Y` be the literal paid `48`-word dual-Pauli/Whitehead menu and
use the five return legs

```text
F={X_1,X_2,X_3,L_2,L_4},
L_2=x_12(s_1),              L_4=x_14(s_1).             (FRC1)
```

After an allowed `L_0` conjugacy choice in each class, the exact faithful
Leavitt enumeration proves

```text
for every fenced class C there are g in C, u in M_Y, f in F
such that [[g,u],f] is a nonzero elementary root.       (FRC2)
```

The middle legs cover `28/31` classes.  The two endpoint legs cover the
three misses and leave eight different classes, all already covered by the
middle legs.  Thus the union misses none.  The classwise probe menu has at
most

```text
48*5=240                                                     (FRC3)
```

two-probe cells; including a literal source-preserving representative
choice from the fixed `8192`-element `L_0` table is still one fixed finite
ordinary-word menu.

This cover is moving-source typed only in the weak algebraic sense.  Among
the `48` first probes, exactly `1` and `Y_1` normalize
`(L_0,lambda_0)`, and both centralize `L_0`.  Hence no fenced class has a
nontrivial source-preserving extraction.  The other probes name `24`
explicit conjugate source types, and appending a return leg names another
finite conjugate source, but no relation identifies their multiplicity
charts with `Q`, with the prescribed positive `R_0<=Q`, or with its common
range `P`.  Mere knowledge of the conjugate projection is not a common
source occurrence or a gauge identity.

The mark return has a second exact limitation.  Although `L_2,L_4` repair
the endpoint count, neither gives `z` directly in this menu: the dual
ejection carries one of

```text
b_m=s_(0^m)t_1,
```

whereas `s_1b_m` need not equal `q=s_1t_1`.  For the three repaired classes,
an exact mark return is obtained only with the matching depth-three legs

```text
L_(2,3)=x_12(a_3),       L_(4,3)=x_14(a_3),
a_3=s_1t_000,            a_3b_3=q.                    (FRC4)
```

For every representative of all three classes, the complete same-`g`
scale profile is exactly `{3}`.  There is no same-detector adjacent pair at
scales `(1,2)` or `(2,3)`, even after all `48` first probes.  This is not an
enumeration accident: the literal prefix Whitehead is disjoint from actor
endpoints `2,4`, so

```text
J_m L_(r,m) J_m^(-1)=L_(r,m) != L_(r,m+1),
r in {2,4}.                                             (FRC5)
```

Thus the current braid transports the middle Pauli factor but not the new
endpoint coefficient.  The two exact mark cells needed for a shared
reservoir gauge never occur on the same detector/source occurrence.

The next viable extension is therefore the fresh endpoint-Whitehead
candidate `Jhat_(r,m)` characterized by

```text
Jhat_(r,m)L_(r,m)Jhat_(r,m)^(-1)=L_(r,m+1),
r in {2,4},                                             (FRC6)
```

together with the corresponding transport of the paired endpoint ejection.
It must also come with a source-preserving or multiplicity-typing occurrence
identifying that transport on the prescribed moving `R_0 -> P` channel.
Another finite conjugate-source name, another disjoint fixed root, or the
current `J_m` does not supply either requirement.  No Property T, Kazhdan
input, canonical trace, literature theorem, local computation, or Lean
compilation is used.

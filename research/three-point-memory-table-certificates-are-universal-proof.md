## 0. Definitions

**Tables.** `S` and `M` are finite label sets, each containing a label `1`. A *table* is a rook-independent partition
`T` of `S x M`: no class has two cells in one row or one column. Its *table group* is

```text
P(T) = < x_a (a in S u M), x_1 = 1 | x_s x_m = x_s' x_m'  for (s, m) ~ (s', m') in T >.
```

Here `x_s` and `x_m` are different letters even when the labels share a name. Both labels `1` go to `1`. The
*reverse products* of `T` are the elements `x_m x_s` of `P(T)` for `(m, s)` in `M x S`.

A table is *realizable* when there is a group `G` and injective maps `S -> G`, `M -> G` sending `1` to `1` such that
`(s, m) ~ (s', m')` iff `sm = s'm'` in `G`. We write `T = T_f(G)`. Then `phi: x_a -> a` is a homomorphism
`P(T) -> G`, because every relator holds in `G`.

**Certificates.** `C` is a class of groups closed under isomorphism. A *`C`-certificate* for `T` is a homomorphism
`psi: P(T) -> H` with `H` in `C` whose restriction to the set of reverse products is injective: distinct elements
`x_m x_s != x_m' x_s'` of `P(T)` have distinct images.

**Local embeddability.** A group `G` is *locally embeddable into `C`* when for every finite `F` in `G` there are `H` in
`C` and an injective map `f: F -> H` with `f(gh) = f(g) f(h)` whenever `g, h, gh` lie in `F`.

## 1. Resolution by certificates

**Proposition 1.** Suppose every group in `C` is surjunctive and `T` is realizable with a `C`-certificate. Then no
group `G` with `T = T_f(G)` carries a strict pair (`sigma tau = id`, `tau` not surjective) with decoder memory `S`
and encoder memory `M`, for any finite alphabet and any rules.

*Proof.* Let `G`, an alphabet `A`, and rules `mu: A^M -> A`, `nu: A^S -> A` give a strict pair with `T_f(G) = T`. By
`surjunctivity-is-axiomatized-by-rectangle-clauses`, the data `D = (S, M, A, mu, nu, T, T_r(G))` are strict, where
`T_r(G)` is the partition of `M x S` by `ms` in `G`. So `Dec(T)` holds and `Enc(T_r(G))` fails.

Let `T_r(P)` be the partition of `M x S` by `x_m x_s` in `P(T)`. Since `phi` is a homomorphism, `T_r(P)` is finer
than `T_r(G)`, so `Enc(T_r(P))` fails as well. Hence `D' = (S, M, A, mu, nu, T, T_r(P))` is strict data.

Now put `y_a = psi(x_a)` in `H`. Forward products `y_s y_m` coincide along `T`, because the relators of `P(T)` hold
under `psi`. Reverse products `y_m y_s` coincide exactly along `T_r(P)`: equal elements of `P(T)` stay equal, and
distinct ones stay distinct by injectivity. In particular they coincide along at most `T_r(P)`. By the Theorem of
`surjunctivity-is-axiomatized-by-rectangle-clauses`, `H` is not surjunctive. That is a contradiction. QED

## 2. The path lemma

Write `x^S_s` for the decoder letters and `x^M_m` for the encoder letters of `P(T)`.

Let `K` be an infinite group generated by `a` and `b`, with `1, a, b` distinct, and let `r >= 1` and `k >= 3`. Put
`S = {1, a, b, c_4, ..., c_k}` with further distinct elements `c_i` of `K`, `M = B_K(2r)` (the ball for the word
metric on `{a^+-1, b^+-1}`), and `T = T_f(K)`. `K` itself realizes `T`. For `e` in `{a, b}` put `x(e) = x^S_e` and
`x(e^-1) = (x^S_e)^-1`.

**Lemma 2 (paths).** Let `w = e_1 e_2 ... e_L` be a word over `{a^+-1, b^+-1}` whose suffix elements
`g_j = e_j e_(j+1) ... e_L` (`1 <= j <= L`) all lie in `M`. Then `x^M_(g_1) = x(e_1) x(e_2) ... x(e_L)` in `P(T)`.

*Proof.* Induction on `L`. For `L = 0` both sides are `1`. Suppose the claim holds for the suffix `m = g_2`, with
`m = 1` when `L = 1`. It suffices to show `x^M_(em) = x(e) x^M_m` when `m` and `em` lie in `M`.

- If `e = a`, the cells `(a, m)` and `(1, am)` both have product `am` in `K`. They lie in one class of `T`, so
  `x^S_a x^M_m = x^M_(am)`.
- If `e = a^-1`, the cells `(a, a^-1 m)` and `(1, m)` both have product `m`. So `x^S_a x^M_(a^-1 m) = x^M_m`, that
  is, `x^M_(a^-1 m) = (x^S_a)^-1 x^M_m`.

The generator `b` is handled in the same way. QED

**Corollary 3.** For `g, h` in `B_K(r)`, `x^M_(gh) = x^M_g x^M_h` in `P(T)`. For `g != g'` in `M`,
`x^M_g != x^M_g'` in `P(T)`.

*Proof.* Let `u` and `v` be geodesic words for `g` and `h`. Every suffix of `u`, `v` and `uv` has length at most `2r`,
so its element lies in `M`. Lemma 2 gives `x^M_g = u(x)`, `x^M_h = v(x)` and `x^M_(gh) = u(x) v(x)`. For the second
claim, `phi(x^M_g) = g != g' = phi(x^M_g')`. QED

**Corollary 4 (not needed for the Theorem).** Suppose the `c_i` lie in `B_K(2r)`, and `K` has a presentation on
`a, b` whose relators have length at most `2r`. Then `phi: P(T) -> K` is an isomorphism.

*Proof.* By Lemma 2 every encoder letter is a word in `x^S_a, x^S_b`. For `c` in `S` inside `M`, the cells `(c, 1)`
and `(1, c)` give `x^S_c = x^M_c`. So `P(T)` is generated by `x^S_a, x^S_b`.

Split each relator as `u v^-1` with `|u|, |v| <= r`. Every suffix of `u` and of `v` lies in `B_K(r)`, and Lemma 2
applies to both words ending at the same element `g`. So `u(x) = x^M_g = v(x)`. Hence `a -> x^S_a`, `b -> x^S_b`
defines a homomorphism `K -> P(T)`. It is onto, and `phi` composed with it is the identity of `K`. So it is an
isomorphism with inverse `phi`. QED

## 3. The theorem

**Theorem.** Let `k >= 3` and let `C` be closed under isomorphism. The following are equivalent.

- (a) Every realizable table with `|S| = k` has a `C`-certificate.
- (b) Every realizable table with `|M| = k` has a `C`-certificate.
- (c) Every group is locally embeddable into `C`.

*(c) implies (a) and (b).* Let `T` be any table (realizable or not) and `P = P(T)`. Take the finite set
`F = {1} u {x_a} u {x_s x_m} u {x_m x_s}` of `P`. By (c) there are `H` in `C` and an injective map `f: F -> H` that is
multiplicative on `F`. Since `1 = 1 * 1` lies in `F`, `f(1) = 1`.

Define `psi` on generators by `psi(x_a) = f(x_a)`. For a relator `x_s x_m = x_s' x_m'`, both sides are the same element
`p` of `F`, so `f(x_s) f(x_m) = f(p) = f(x_s') f(x_m')`. Hence `psi` is a homomorphism `P -> H`.

On reverse products, `psi(x_m x_s) = f(x_m) f(x_s) = f(x_m x_s)`, and `f` is injective on `F`. So `psi` is a
certificate. This proves (a) and (b) for tables of every shape.

*(a) implies (c).* Local embeddability into `C` depends only on finite subsets. A finite subset of a group `G`
lies in a finitely generated, hence countable, subgroup `G_0`. By Higman, Neumann and Neumann, the countable group
`G_0 * Z * Z` embeds into a 2-generated group `K = <a, b>`. `K` contains `Z * Z`, so it is infinite and not cyclic.
Hence `1, a, b` are distinct: otherwise `K` would be cyclic.

A subgroup of a group locally embeddable into `C` is locally embeddable into `C`: restrict the maps. So it suffices to
show `K` is locally embeddable into `C`. Let `F` be a finite subset of `K` and choose `r` with `F` in `B_K(r)`.
Build `T` as in Section 2, with `M = B_K(2r)` and the padding labels `c_i` distinct in `K`.

By (a), there is a certificate `psi: P(T) -> H`. Let `lambda: B_K(r) -> P(T)` be `lambda(g) = x^M_g`, and put
`f = psi lambda` on `F`.

- Multiplicative: if `g, h, gh` lie in `F`, Corollary 3 gives `lambda(gh) = lambda(g) lambda(h)`, so
  `f(gh) = f(g) f(h)`.
- Injective: `x^M_g = x^M_g x^S_1` is a reverse product, and the `x^M_g` for `g` in `M` are distinct by
  Corollary 3. So `psi` separates them.

Hence `K` is locally embeddable into `C`.

*(b) implies (c).* For a table `T` on `S x M`, let `T^t` be the partition of `M' x S'`, with `M' = M` as decoder
labels and `S' = S` as encoder labels, given by `(m, s) ~ (m', s')` iff `(s, m) ~ (s', m')`.

- If `T = T_f(G)` with labels `s`, `m`, then `T^t = T_f(G)` with decoder labels `m^-1` and encoder labels `s^-1`,
  because `m^-1 s^-1 = (sm)^-1`. So `T^t` is realizable iff `T` is.
- `y_a -> x_a^-1` defines an isomorphism `P(T^t) -> P(T)`: the relator `y_m y_s = y_m' y_s'` goes to
  `(x_s x_m)^-1 = (x_s' x_m')^-1`. The reverse product `y_s y_m` of `T^t` goes to `(x_m x_s)^-1`.
- Inversion is a bijection, so `psi` is a certificate for `T` iff `psi` composed with this isomorphism is one for
  `T^t`.

A table with `|S| = k` transposes to one with `|M| = k`. So (b) implies (a), which implies (c). QED

**Proposition 5 (k = 2).** Every realizable table with `|S| = 2` (or `|M| = 2`) has a finite certificate.

*Proof.* Let `S = {1, s}`. A class has at most two cells, in different rows and columns. So the relators are
`x_s x_m = x_m'` for `m != m'`, one for each two-cell class `{(s, m), (1, m')}`.

Consider the directed graph on `M` with an edge `m -> m'` for each relator. Every vertex has in-degree and out-degree
at most `1`, so the graph is a disjoint union of paths and cycles. Tietze moves eliminate `x_m'` along each edge. A
component with base vertex `m_0` contributes the generator `x_(m_0)`, or none if the component contains `1`. A cycle
of length `L` contributes the relator `x_s^L = 1`.

So `P(T)` is `Z / d` (with `d = 0` allowed) freely times a free group. Such a group is residually finite by
Gruenberg's theorem on free products. So one finite quotient separates the finitely many distinct reverse products,
by intersecting finitely many finite-index normal subgroups. The case `|M| = 2` follows by transposition. QED

## 4. Instances

**4.1 Surjunctive groups.** Let `C` be the surjunctive groups. By `surjunctivity-is-axiomatized-by-rectangle-clauses`,
a group locally embeddable into surjunctive groups is surjunctive, since universal sentences pass to local embeddings.
So (c) is Gottschalk's conjecture.

By Proposition 1, (a) implies the three-point decoder claim `three-point-decoder-memory-injective-ca-are-surjective`.
By the Theorem, (a) also implies Gottschalk's conjecture. If the conjecture holds, (a) holds with `psi` the identity
of `P(T)`. So

```text
Gottschalk  <=>  every realizable table with three decoder points has a surjunctive certificate
            ==>  three-point-decoder-memory-injective-ca-are-surjective.
```

Every rule-free argument for the three-point claim establishes the left-hand side, and so the conjecture.

**4.2 Sofic groups.** A group locally embeddable into sofic groups is sofic: partial embeddings compose with sofic
approximations of the targets (standard, Elek--Szabo). Sofic groups are surjunctive (`sofic-groups-are-surjunctive`).
So sofic certificates for all three-row tables exist iff every group is sofic.

**4.3 Finite, linear and residually finite groups: the explicit table.** Let `K = BS(2,3) = <a, t | t^-1 a^2 t = a^3>`,
`r = 2`, `S = {1, a, t}` and `M = B_K(4)`.

`ballcal.py` finds `|B_K(4)| = 147`, so `T` has shape `3 x 147` with `272` classes. It checks rook independence
and the edge relators of Lemma 2. It also checks that every suffix of `t^-1 a^2 t` and of `a^3` lies in `M`, so
Lemma 2 gives `(x^S_t)^-1 (x^S_a)^2 x^S_t = x^M_(a^3) = (x^S_a)^3` in `P(T)`.

Every letter of `P(T)` is a word in `x^S_a, x^S_t`: the encoder letters by Lemma 2, and `x^S_a = x^M_a`,
`x^S_t = x^M_t`. So `a -> x^S_a`, `t -> x^S_t` maps `K` onto `P(T)`, and `phi` inverts it. Hence `P(T) = BS(2,3)`.

Put `u = t^-1 a t`. The elements `au` and `ua` have length `4`, so they lie in `M`. They are distinct in `K` by
Britton's lemma, which `ballcal.py` checks. So `x^M_(au)` and `x^M_(ua)` are distinct reverse
products (with `s = 1`). Let `psi: P(T) -> H` be any homomorphism whose image `Q = psi(P(T))` is residually finite.

- In a finite quotient of `Q`, let `o` be the order of the image of `a`. Conjugate elements `a^2` and `a^3` have
  equal orders `o / gcd(o, 2) = o / gcd(o, 3)`, so `gcd(o, 6) = 1`.
- Then `a = a^(2j)` with `2j = 1 mod o`, so `u = t^-1 a^(2j) t = a^(3j)` commutes with `a`.
- So `au = ua` in every finite quotient of `Q`, hence in `Q`, and `psi` is not injective on reverse products.

Therefore `T` has no certificate in any class whose members have residually finite 2-generated subgroups. That
includes the finite groups, the linear groups (Malcev) and the residually finite groups. This is a certified gap
table for the finite-quotient method at three decoder points, independent of any census.

**4.4 Amenable groups.** Thompson's group `V` is finitely presented, simple and contains `F_2`. Suppose `V` were locally
embeddable into amenable groups. A partial embedding of a ball containing all relators of a finite presentation and a
nontrivial element defines a nontrivial homomorphism `V -> H`, with `H` amenable. It is injective, since `V` is
simple, so `V` would be amenable. By the Theorem, some realizable three-row table has no amenable certificate. The
witness is a ball table of any 2-generated group containing `V`.

## 5. Scope

- The Theorem concerns only the rule-free condition. A table with no `C`-certificate can still carry no strict pair,
  because of the rules `mu`, `nu`. Proposition 1 goes one way only.
- The Theorem says nothing about tables whose table group is restricted, for example by amenability of `<S^-1 S>`
  as in `amenable-decoder-memory-forces-surjectivity`. It shows only that the unrestricted family of three-row
  tables is universal.
- The threshold is sharp: two-row tables are always finitely certified (Proposition 5).

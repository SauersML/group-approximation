**OPEN.** Some group `G` has an action on a set `S` of type `[A_2]`, in the sense of
Fournier-Facio--Wu--Zaremsky (arXiv:2603.24687):
- `G` is finitely presented;
- point stabilizers are finitely generated;
- there are finitely many orbits on `S x S`.

Its kernel `K` is not recursive as a set of words in a finite generating set of `G`.
Equivalently, the action image `G/K` has unsolvable word problem.

This is the negation of `a2-action-kernels-are-recursive`, which becomes REFUTED once
this claim is ESTABLISHED.

**Consequences once established.**
- `a2-pair-with-non-removable-kernel-exists`, via
  `non-removable-a2-kernel-from-nonrecursive-kernel`.
- A negative answer to the first part of FFWZ Question 5.9.

**Constraints on a witness.**
- `K` is co-r.e. (`a2-kernel-removal-forces-recursive-kernel` (a)), so `K` is not r.e.
- The image `G/K` is not recursively presented. Every stabilizer image is finitely
  generated but not finitely presented
  (`a2-stabilizer-image-presentation-controls-kernel`).
- By `a2-kernel-recursion-ascends-normal-orbit-finite-chains` (5): no finitely
  generated normal subgroup with finitely many orbits meets `K` trivially. More
  generally, the bottom of any finitely generated orbit-finite normal chain up to `G`
  meets `K` in a non-r.e. set. Also, `K` does not consist of elements that centralize
  conjugates of finitely many finitely generated orbit-finite subgroups.

**Known sufficient inputs.**
- `type-a-hnn-realization-with-unsolvable-word-problem`, via
  `nonrecursive-a2-kernel-from-unsolvable-hnn-realization`.
- `fp-simple-group-with-nonrecursive-mixed-identities`, through the Theorem C actor
  (`a2-kernel-removal-forces-recursive-kernel` (c), and its `k`-variable version in
  `non-removable-a2-kernel-from-nonrecursive-mixed-identities`). No route from it to
  this claim is recorded here.

## Attempts

**Attempt 1 (2026-09-16): normalizer covers.** Take the actors
`Γ x|_θ F_m ↷ Ω` of `normalizer-extension-of-type-a-actor-is-a2-cover`, where the
image `ΓQ` can fail to be finitely presented
(`a2-action-with-non-finitely-presented-image`). This dies:
`Γ` is a finitely generated orbit-finite normal subgroup meeting the kernel
trivially, so the kernel is recursive
(`a2-kernel-recursion-ascends-normal-orbit-finite-chains` (4)).

**Attempt 2 (2026-09-16): the two-sided regular action.** Let `B = <b_1, ..., b_k |
r_1, ..., r_l>` be finitely presented. Let `F_k x F_k` act on the set `B` through
`B x B` by `(u, v).x = u x v^-1`. The action is transitive, and the stabilizer of `1`
is the fibre product `{(u, v) : u = v in B}`. That stabilizer is generated by the
diagonal pairs `(b_i, b_i)` together with the pairs `(1, r_j)`, so it is finitely
generated.

Moving the first coordinate to `1` shows that the orbits on `B x B` correspond to the
conjugacy classes of `B`. So the action is of type `[A_2]` exactly when `B` has
finitely many conjugacy classes.

The kernel is `{(u, v) : u = v in B, u in Z(B)}`. This is r.e.:
- `u = v` in `B` is r.e.;
- `u in Z(B)` iff `[u, b_i] = 1` in `B` for each `i`, which is r.e.

Since the kernel is also co-r.e., it is recursive. This dies for every `B`.

**Attempt 3 (2026-09-16): HNN realizations of type (A) actors.** These are the
natural source: the kernel is free and meets the actor trivially, and there is
typically no finitely generated orbit-finite normal subgroup, so Attempt 1's
obstruction does not apply. The reduction and the tame cases are recorded in
`type-a-hnn-realization-with-unsolvable-word-problem`. Finite-index edge groups die by
`permutation-hnn-realization-of-type-a-actor-is-a2` (b).

**Attempt (bh-free-41, 2026-09-18): Mihailova-type data.** Lane proof, elementary, not reviewed. It closes several natural shapes of witness; none is constructed.
1. **Stabilizers are recursive.** In any type `[A_2]` action of a finitely presented `G`, the finitely many double
   cosets `G_s g G_s` are r.e. sets of words that partition all words, so each is recursive; in particular `G_s`
   is. So a Mihailova subgroup, whose membership is undecidable, can never be a stabilizer. Mihailova-type
   undecidability has to sit in the core `K = core_G(G_s)`, with `G_s` itself decidable.
2. **Recursively presented images give r.e. kernels.** `K` is r.e. iff `G/K` is recursively presented. So every
   construction whose image is defined by an r.e. set of relations dies. For example, let `A` be any finitely
   presented group, `φ : A ↠ Q` with `Q` finitely presented, and let `A × A` act on `Q` by
   `(u,v)·x = φ(u) x φ(v)^{-1}`.
   - The kernel is `{(u,v) : φ(u) = φ(v) ∈ Z(Q)}`.
   - That set is r.e., since equality in `Q` is r.e. and centrality needs only the finitely many generators.
   - This extends Attempt 2 from `F_k` to every `A`.
   A witness's image must be a group of computable permutations whose relations are genuinely `Π_1`.
3. **The factor parts over `F × F` are recursive.** Let `G = F × F` with `F` free, act of type `[A_2]` with
   stabilizer `H`, and suppose `p_1(H)` and `p_2(H)` have finite index in `F`.
   - Put `H_1 = {u : (u,1) ∈ H}`. It is normal in `p_1(H)` and recursive by item 1.
   - Then `K ∩ (F × 1) = core_F(H_1) × 1`, which is a finite intersection of conjugates of `H_1`, hence
     recursive. The same holds for `1 × F`.
   - So in `F × F` a witness must hide its non-recursive part in the Goursat graph part of `K`, the
     identification `p_1(K)/K_1 ≅ p_2(K)/K_2`.

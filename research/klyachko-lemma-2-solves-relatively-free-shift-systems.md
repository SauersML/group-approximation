**Statement** (Klyachko, Comm. Algebra 21(7) (1993), Lemma 2, p. 2569--2570).
Let `H` be a group with two isomorphic subgroups `P` and `P^phi`, the
isomorphism written `p -> p^phi`. Let `a_i, b_i, c in H` (`i = 0, ..., k`)
satisfy

    gp(a_i, P)     = <a_i>_inf * P,
    gp(b_i, P^phi) = <b_i>_inf * P^phi,        i = 0, ..., k,

where `<x>_inf` means that `x` has infinite order and the natural map from the
free product is an isomorphism. Then the system of equations over `H`

    ( prod_(i=0)^k b_i t^(-1) a_i t ) c t = 1,
    { t^(-1) p t = p^phi  :  p in P }

is solvable over `H`: some group `H~ >= H` contains `t~` satisfying all of it.

**What is imported.** The proof is Klyachko's car-crash argument
(Proposition 1a on motions on tessellations of the 2-sphere, and Lemma 1a, the
van Kampen-type lemma). The only algebraic input is that a complete collision
at an interior source or sink vertex reads a relation in `gp(a_i, P)` or
`gp(b_i, P^phi)`, which the hypothesis makes trivial (p. 2571). There is no
hypothesis on `c`.

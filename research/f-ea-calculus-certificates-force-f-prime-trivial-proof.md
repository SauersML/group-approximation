Notation is as in the target. `ψ : F → Φ` is a fixed isomorphism onto a copy `Φ` of `F`, so `Φ′ = ψ(F′)`.
`F` is generated by `x_0, x_1`, so `F` and every copy of `F` are finitely generated. Facts (F1) and (F2)
are imported by `thompson-f-rigid-interval-subgroups-facts`, with support meaning the closure of the
moved set. The unused last clause of (F1) is not used here.

**Strategy.** Let `𝓠` be the class of pairs with property P. It is enough to show that `𝓠` contains
(B1) and (B2) and is closed under (O1)–(O6). Then `𝓟 ⊆ 𝓠`, because `𝓟` is the smallest such class.

## Three lemmas on F

**Lemma A (rigid copies inside F′).** For dyadic `0 < a < b < 1`:
- `F[a,b] ≤ F′`;
- `F[a,b] ≅ F`, with `F[a,b]′ = F(a,b)`;
- `F′ = ⋃_{a<b} F(a,b)`.

*Proof.*
- Elements of `F[a,b]` have support in `[a,b] ⊂ (0,1)`, so they lie in `F′` by (F1).
- The isomorphism and the commutant are (F2).
- Let `g ∈ F′`. By (F1) its support is a closed subset of `(0,1)`, so it lies in some `[c,d]` with
  `0 < c < d < 1`. Pick dyadic `a < c` and `b > d` in `(0,1)`. Then `g` fixes `[0,1] ∖ [a,b]` and is the
  identity near `a` and `b`, so `g ∈ F(a,b)`. The reverse inclusion is the first item. ∎

**Lemma B (normal subgroups).** Every nontrivial normal subgroup `N` of `F` contains `F′`.

*Proof.*
- First, the centralizer of `F′` in `F` is trivial. Let `1 ≠ g ∈ F`. Then `g` moves some `t ∈ (0,1)`, so
  there is an open interval `I ∋ t` in `(0,1)` with `g(I) ∩ I = ∅`. Pick dyadic `a < b` in `I`.
- `F(a,b) = F[a,b]′` is the commutant of a group isomorphic to the nonabelian group `F`, so it has an
  element `h ≠ 1`. By Lemma A, `h ∈ F′`, and `h` moves some `s ∈ I`.
- `ghg^{-1}` is supported in `g(I)`, so it fixes `s`. Hence `ghg^{-1} ≠ h`, and `g` does not centralize `F′`.
- Now suppose `N ∩ F′ = 1`. Then `[N, F′] ⊆ N ∩ F′ = 1`, since both are normal. So `N` centralizes `F′`
  and `N = 1`.
- Hence `N ∩ F′` is a nontrivial normal subgroup of `F′`. It equals `F′` because `F′` is simple (F1). ∎

**Lemma C (kernels on a copy).** For any homomorphism `φ` defined on `Φ`, either `φ|_Φ` is injective,
so that `φ(Φ)` is a copy of `F` with `φ(Φ)′ = φ(Φ′)`, or `Φ′ ⊆ ker φ`.

*Proof.* Apply Lemma B to `ψ^{-1}(ker φ ∩ Φ) ⊴ F`. ∎

## Bases

**(B1) Recurrent actions.** Let `(G, X)` be recurrent, let `Φ` be a copy of `F` in `G`, and let `p ∈ X`.
- Let `S = ψ({x_0^{±1}, x_1^{±1}})` and let `μ` be uniform on `S`. It is a symmetric, finitely supported
  probability measure on `G`.
- By recurrence of `(G, X)`, the walk induced by `μ` on `G·p` is recurrent. It stays in `Φ·p`, where it
  is the simple random walk on the Schreier graph `Γ(Φ, p, S)`.
- Transport by `ψ`: that graph is the Schreier graph of `F/H` for the generating set `{x_0^{±1}, x_1^{±1}}`,
  where `H = ψ^{-1}(Φ_p)`. It is recurrent.
- By `thompson-f-recurrent-f-sets-factor-through-the-abelianization`, `H ⊇ F′`. So `Φ′ ⊆ Φ_p`.
- `p` was arbitrary, so `Φ′` fixes `X` pointwise.

**(B2) Actions of groups in `𝓕`.** There is no copy of `F` in `G`, so property P holds vacuously.

## Operations

**(O1) Pullback.** Let `(G, X) ∈ 𝓠`, let `φ : K → G`, and let `Φ` be a copy of `F` in `K`. By Lemma C:
- either `φ(Φ)` is a copy of `F` in `G`, so `φ(Φ′) = φ(Φ)′` fixes `X`. Then `Φ′`, which acts through
  `φ`, fixes `X`;
- or `Φ′ ⊆ ker φ`, which acts trivially.

**(O2) Invariant subsets.** A point of `Z ⊆ X` is a point of `X`.

**(O3) Images.** Let `p : X → Y` be a surjective `G`-map. Every `y = p(x)` satisfies `g·y = p(g·x) = y` for
`g ∈ Φ′`.

**(O4) Local-to-global.** Let `Φ` be a copy of `F` in `G` and `x ∈ X`. `Φ` is finitely generated, so by
hypothesis `(Φ, Φ·x) ∈ 𝓠`. `Φ` is a copy of `F` in itself, so `Φ′` fixes `x`.

**(O5) Extension principle.** Let `q : X → Y` be a `G`-map with `(G, Y) ∈ 𝓠` and `(G_y, q^{-1}(y)) ∈ 𝓠`
for every `y ∈ Y`. Let `Φ` be a copy of `F` in `G`, let `x ∈ X`, let `y = q(x)`, and let `g ∈ Φ′`.
- Since `(G, Y) ∈ 𝓠`, `Φ′` fixes `Y` pointwise, so `Φ′ ≤ G_y`.
- By Lemma A, `ψ^{-1}(g) ∈ F(a,b)` for some dyadic `0 < a < b < 1`.
- By Lemma A, `F[a,b] ≤ F′`, so `Φ_{ab} := ψ(F[a,b]) ≤ Φ′ ≤ G_y`. Again by Lemma A, `Φ_{ab}` is a copy of
  `F` (via `ψ` composed with an isomorphism `F ≅ F[a,b]`), and `Φ_{ab}′ = ψ(F[a,b]′) = ψ(F(a,b)) ∋ g`.
- Since `(G_y, q^{-1}(y)) ∈ 𝓠`, `Φ_{ab}′` fixes `q^{-1}(y) ∋ x`. So `g·x = x`.

So `Φ′` fixes `X` pointwise. This step is where the stabilizer inputs are forced to contain copies of `F`:
the fibres see only `G_y ⊇ Φ′`, and `Φ′` is exhausted by commutants of copies of `F`.

**(O6) Functor extension.** Let `(G, X) ∈ 𝓠`, let `𝔉 : 𝐈 → 𝐆𝐫𝐩` with `𝔉(X) ∈ 𝓕`, let `Γ = 𝔉(X) ⋊ G`, and
let `Φ` be a copy of `F` in `Γ`. Let `π : Γ → G` be the projection.
1. *`π` is injective on `Φ`.* Otherwise, by Lemma C, `Φ′ ⊆ ker π = 𝔉(X)`. But `Φ′` contains the copy
   `ψ(F[1/4, 3/4])` of `F` (Lemma A), against `𝔉(X) ∈ 𝓕`.
2. *`Ψ′` acts trivially on `𝔉(X)`.* So `Ψ := π(Φ)` is a copy of `F` in `G` with `Ψ′ = π(Φ′)`, and
   `Ψ′` fixes `X` pointwise. `𝔉(X)` is the direct limit of `𝔉(S)` over finite `S ⊆ X`, and `g ∈ G` acts
   by `𝔉(g|_S) : 𝔉(S) → 𝔉(gS)`. For `g ∈ Ψ′`, `g|_S = id_S`, so `𝔉(g) = id_{𝔉(X)}`.
3. *The cocycle part.* By item 1, every element of `Φ′` is `(c_g, g)` for a unique `g ∈ Ψ′`. By item 2,
   `(c_g, g)(c_h, h) = (c_g·𝔉(g)(c_h), gh) = (c_g c_h, gh)`. So `c : Ψ′ → 𝔉(X)` is a homomorphism.
4. *`c` is trivial.* `Ψ′ ≅ F′` is simple (F1), so `ker c` is `Ψ′` or `1`. If it were `1`, then `c(Ψ′)`
   would be a copy of `F′` in `𝔉(X)`. That copy contains `c(π(ψ(F[1/4,3/4])))`, a copy of `F`, against
   `𝔉(X) ∈ 𝓕`. So `c ≡ 1`.
5. *Conclusion.* `Φ′ = {(1, g) : g ∈ Ψ′}` acts by `d ↦ 𝔉(g)(d) = d`.

This proves the Theorem. ∎

## Corollaries

**Corollary 1.** Let `θ : F → G` be injective and `(G, X) ∈ 𝓟`. Then `θ(F)` is a copy of `F`, so `θ(F′)`
fixes `X`, and `F ↷ X` factors through `F/F′`.
- The dyadic action `F ↷ D` does not factor, since the commutator `[x_0, x_1] ∈ F′` is nontrivial (`F` is
  nonabelian), and its moved set is open and nonempty, so it contains a dyadic point. Nor does any `F`-set on which `F′` moves a point.
- For a faithful `(G, X)`, `θ(F′) = 1` is impossible. ∎

**Corollary 2.** Let `(G, X) ∈ 𝓟` with `F ≤ G`, let `𝔉(X) ∈ 𝓕`, and let `c : G → 𝔉(X)` satisfy
`c_{gh} = c_g·𝔉(g)(c_h)`.
- `σ(g) = (c_g, g)` is a homomorphism `G → Γ = 𝔉(X) ⋊ G`, because `(c_g, g)(c_h, h) = (c_{gh}, gh)`. It
  is injective.
- So `Φ = σ(F)` is a copy of `F` in `Γ`, with `Φ′ = σ(F′)`.
- By the Theorem, `(G, X)` has property P. Steps 1–4 of (O6) apply verbatim to `Φ`: step 1 is automatic
  since `π∘σ = id`, and step 4 uses only `𝔉(X) ∈ 𝓕`. They give `c_g = 1` for all `g ∈ F′`.
- `ker c = {g : c_g = 1}` is a subgroup, by the cocycle identity. It contains `F′ ⊇ F[1/4, 3/4] ≅ F`.

So the hypothesis "`ker c` amenable" of JMBMdlS Corollary `prop:functor:amenable:intro` implies
amenability of `F`. The same holds for any subgroup of `G` containing `F` in place of `ker c`. ∎

## Scope of the kill

The target's list of JMBMdlS results shows that the extensively amenable part of `𝓟` contains every
certificate obtained from those results. Corollaries 1–2 then give the invariant (property P) and the
step where every member dies (the kernel).

The proof uses only:
- the recurrent-base theorem;
- (F1)–(F2);
- the group theory above.

It does not use extensive amenability itself. So the obstruction is combinatorial, and it applies to any
permanence calculus built from these operations.

**OPEN (lane ex3-uct-cartan-fence, 2026-09-13).**  Let `G` be a finite group,
`A` a separable nuclear C\*-algebra, `α : G ↷ A` an action, and `C ⊆ A` a Cartan
subalgebra with `α_g(C) = C` for all `g ∈ G`.  Is `(A, α)` in the equivariant
bootstrap class `B^G`, that is, `KK^G`-equivalent to an action on a separable
type I C\*-algebra (Meyer--Nadareishvili, arXiv:2406.11787v2, introduction)?

**Why it matters.**  For `G = Z/p` and `A = O_2`,
`zp-restriction-trivial-splits-cellular-plus-phantom` item 5 turns membership
into `θ = [α_ω] = 1` in `KK^G(E, E)`.  That is the Cartan fence of
`cartan-invariant-zp-actions-on-o2-have-trivial-action-element`: an equivariant
phantom fixes no Cartan subalgebra.

**Model tests.**
* Commutative `A = C`: an action on a type I algebra, in `B^G` by definition.
* Quasi-free `λ_z : Z/p ↷ O_2`, `z = (ζ^a, ζ^b)`, fixes the canonical masa
  `D_2` pointwise.  The equivariant Pimsner triangle gives
  `E ≃ cone(1 − t^a − t^b)` over `C` with trivial action, in `B^G`.  Consistent.
* Trivial action on `O_2` (fixes `D_2`): `τ(O_2) ≃ 0` since `O_2 ≃_KK 0`.  Consistent.

## Attempts

* **Equivariant Tu through partial descent (in progress).**  Renault's theorem
  with its functoriality gives `A ≅ C*_r(𝒢, Σ)` for a twisted, effective, étale,
  amenable groupoid, with `α` acting by twisted groupoid automorphisms, so
  `ℋ = G ⋉ 𝒢` is amenable.  This is the model Barlak--Li use for crossed products.
  Plan:
  1. strong Baum--Connes for the amenable groupoid `ℋ` puts the unit object
     `C_0(ℋ^(0))` in the localizing subcategory of `KK^ℋ` generated by
     algebras induced from proper subgroupoids, with commutative coefficients;
  2. partial descent along `𝒢 ◁ ℋ`, `KK^ℋ → KK^G`, is exact, commutes with
     countable sums, and sends `C_0(ℋ^(0))` to `(A, α)`;
  3. the images of the generators are crossed products of proper actions with
     finite isotropy, which are type I.

  Points where it can die, all unchecked:
  * the twist, which has to be carried `G`-equivariantly;
  * the exact generation statement for amenable groupoids, which has to be
    read verbatim (Tu, K-Theory 17 (1999); Bönicke--Proietti; Meyer--Nest);
  * the partial descent functor for `G ⋉ 𝒢`.

**Conventions.** `Q = H^n ⋊ P`, `P in {Sym(n), Alt(n)}`, `(f; p)(g; q) = (f · p(g); pq)` with
`p(g)_i = g_(p^-1 i)`. Write `a_x = (f_x; p_x)`. Let `Omega_0` be the moved set of `<p>`, `n' = |Omega_0|`,
`Omega_1` its complement, and `P_0` the elements of `P` supported on `Omega_0`. Every `a_x` lies in
`Q_0 × Q_1`, where `Q_0 = H^(Omega_0) ⋊ P_0` and `Q_1 = H^(Omega_1)`. Superscripts `0`, `1` denote
components. A *letter* is a conjugate `c r(a)^(+-1) c^-1` with `c in Q`, and a block is *balanced* if
each relator occurs equally often with each sign.

## 0. Constants

- `eps_0`: Lemma 1.2 of `simple-group-support-and-semisimple-rank-models-collapse-proof`. So some `r*` has
  `s := |supp r*(p)| >= eps_0 n'`.
- `N_0`, `k_1`: the thresholds of Sections 2--3 of `simple-group-relator-width-in-finite-simple-targets-proof`.
  For `n' >= N_0` and `k >= k_1`, the `P_0`-class `C` of `r*(p)` satisfies `C^k = Alt(Omega_0)` or a coset
  of it (Rodgers for `Sym`, Liebeck--Shalev item 1 for `Alt`).
- `N_1 = max(N_0, ceil(12/eps_0) + 4)`.
- `V_N`: the variety generated by all `H wr Sym(m)` with `|H| <= N` and `m <= N_1`. It is generated by
  finitely many finite groups, so its free group `Phi` on `X` is finite.

## 1. Small moved set, `n' <= N_1`

`<a> <= Q_0 × Q_1`, with `Q_0 ≅ H wr P_0 <= H wr Sym(N_1)` and `Q_1 = H^(Omega_1)` in `var(H)`. So
`<a>` lies in `V_N` and is a quotient of `Phi`. By (E1) the relator values normally generate `Phi`, and
by (E2) every element is a product of at most `|Phi|` conjugates. Width does not increase under quotient
maps, so `w_Q(a) <= |Phi|`.

## 2. Large moved set, `n' > N_1`: the five blocks

Fix `x`. The product is `a_x = A · B · C · D · E`, with the blocks below.

**Block A (exponents).** `G` is perfect, so choose integers `n_(x,r)` with `e_x = sum_r n_(x,r) e_r`,
and put `A = prod_r r(a)^(n_(x,r))`. Put `y = A^-1 a_x`.
- *Top parity.* `sgn` of the top is a homomorphism, and exponent sums agree. So `top(y^0) in Alt(Omega_0)`.
- *Base total.* `Psi_0(f; p) = sum_(i in Omega_0) f_i mod [H, H]` is a homomorphism `Q_0 -> H^ab`. So
  `Psi_0(y^0) = 0`.
- *Fixed part.* `y^1` is the image of the word `A^-1 x`, which has exponent sum `0`.

**Block B (top).** `B = (r*)^(k_1) (r*^-1)^(k_1)`, with conjugators `(1; pi_j)` and `pi_j in P_0`.
- *Covering.* `C^(k_1)` is one coset of `Alt(Omega_0)`, and `C^(-k_1) = (C^(k_1))^-1` is the same coset. So
  `C^(k_1) C^(-k_1) ⊇ Alt(Omega_0)`, and the tops can be chosen to multiply to `top(y^0)`.
- *Fixed part.* On `Q_1` the letters are `r*(a^1)^(+-1)`, unconjugated, so `B^1 = 1`.
- Put `e = B^-1 y^0`. Then `e in H^(Omega_0)` and `Psi_0(e) = 0`, because `B` is balanced.

**Dipole lemma.** Let `c = (g; sigma)` be any letter's value `c r*(a)^(+-1) c^-1` restricted to `Q_0`, and
`S ⊂ Omega_0` with `sigma(S) ∩ S = ∅`. For `h in H^(Omega_0)` supported on `S`,
```text
[(h; 1), (g; sigma)]  =  (d; 1),   d_i = h_i,  d_(sigma i) = g_(sigma i) h_i^-1 g_(sigma i)^-1  (i in S),  d = 1 elsewhere.
```
*Proof.* `(h;1)(g;sigma)(h^-1;1)(g;sigma)^-1 = (h g sigma(h^-1) g^-1; 1)`. At `j in S`, `sigma^-1 j` is not in
`S`. At `j = sigma(i)`, `h_j = 1`. The commutator is a letter times a letter of opposite sign. Its
`Q_1`-component is `[1, r*(a^1)^(+-1)] = 1`.

**Block C (moved base).**
- *Supply.* Each cycle `(c_1 ... c_L)`, `L >= 2`, of `r*(p)` gives sources `c_1, c_3, ...` with
  `floor(L/2)` disjoint edges `(c, r*(p) c)`. So there are at least `s/3` edges whose sources `S*` satisfy
  `r*(p)(S*) ∩ S* = ∅`.
- *Placement.* For a matching `M` on `Omega_0` with `|M| <= eps_0 n'/3 <= (n' - 2)/2`, choose `pi in P_0`
  carrying `|M|` of these edges onto the pairs of `M`. For `P_0 = Alt(Omega_0)`, fix parity by a
  transposition of two unused points. Then `sigma = pi r*(p) pi^-1` realizes `M` as edges `(i, sigma i)`, and
  one commutator as in the lemma (two letters) is a *round*.
- *The path.* Order `Omega_0 = {i_1, ..., i_(n')}`. The edges `{i_j, i_(j+1)}` form two matchings of size
  `<= n'/2`. A round carries `floor(eps_0 n'/3) >= eps_0 n'/4` edges, since `n' > 12/eps_0`. So each
  matching splits into at most `ceil(2/eps_0)` rounds, and there are `R <= 2 ceil(2/eps_0)` rounds.
- *Solving.* Let `D_1, ..., D_R` be the rounds, with unknown `h`-values `h_j` on edge `j`.
  - Coordinate `i_1` meets only edge `1`, and the dipole entry is a bijective function of `h_1`.
  - Coordinate `i_j`, `1 < j < n'`, sees the known entry of edge `j - 1` and a bijective function of `h_j`, in
    round order. So `h_j` is determined.
  - Coordinate `i_(n')` sees only edge `n' - 1`, already determined. So there is a unique `z in H` with
    `e = D_1 ... D_R · (z at i_(n'))`.
- *The defect.* Every dipole has `Psi_0 = 0`, since its entries are `h_i` and a conjugate of `h_i^-1`. So
  `z in [H, H]`.

**Block D (defect).** Write `z = prod_(t <= cw(H)) [k_t, l_t]`, with `cw(H) <= |H| <= N`.
- *The letters.* Choose a letter `c r*(a) c^-1` whose top moves `i := i_(n')`. By the lemma with `S = {i}`,
  `u = [(k at i; 1), c r*(a) c^-1] = (k at i, k' at sigma i; 1)`. Then `[u, (l at i; 1)] = ([k, l] at i; 1)`.
  It equals `u · (l u^-1 l^-1)`, which is four letters, balanced, with trivial `Q_1`-component.
- *The block.* `D` is the product of these, with `4 cw(H)` letters.

**Block E (fixed coordinates).**
- *Where the tuple lives.* `a^1` is a tuple in `H^(Omega_1)`, which lies in `V_N`. So `<a^1>` is a quotient
  of `Phi`.
- *The error.* The word `A^-1 x` has exponent sum `0`, so it lies in `[F, F]`, and its image lies in
  `[Phi, Phi]`.
- *Balanced pairs.* By (E1) the relator images normally generate `Phi`, so `[Phi, Phi]` is generated by the
  elements `[u, v r^(+-1) v^-1]`, `u, v in Phi`. Each is a balanced pair
  `(u v r v^-1 u^-1)(v r^-1 v^-1)`. So `y^1` is a product of at most `|Phi|` balanced pairs, with
  conjugators in `<a^1> <= Q_1`.
- *No interference.* Lift the conjugators as `(g; 1)` with `g` supported on `Omega_1`. On `Q_0` each pair
  is `r(a^0)^(+-1) r(a^0)^(-+1) = 1`.

## 3. Assembly

- `Q_0` and `Q_1` commute and every block is a product of letters in `Q`.
- On `Q_0`: `E^0 = 1` and `C^0 D^0 = e`, so `A^0 B^0 C^0 D^0 E^0 = A^0 B^0 e = A^0 y^0 = a^0_x`.
- On `Q_1`: `B^1 = C^1 = D^1 = 1`, so the product is `A^1 y^1 = a^1_x`.

So
```text
w_Q(a) <= max( |Phi| ,  max_x sum_r |n_(x,r)|  +  2 k_1  +  4 ceil(2/eps_0)  +  4N  +  2|Phi| ) ,
```
which depends only on `G`, its presentation and `N`.

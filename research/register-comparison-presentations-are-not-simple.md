## Scope: which presentations are covered
A **register presentation** `𝒫` consists of the following data.
- **(D1) Types and letters.** Finitely many *types* `ρ`, with orthogonal idempotents
  `p_ρ` summing to `1`, and finitely many *letters* `x`, with Leavitt-type partial
  isometries `s_x, t_x` from type `s(x)` to type `r(x)`.
- **(D2) Registers.** Finitely many commuting *registers* at each type, the variables
  `Y_ρ`.
- **(D3) Substitutions.** For each letter, a *substitution* `σ_x` sending each register of
  `s(x)` to an integer polynomial in the registers of `r(x)`.
- **(D4) Base generators.** These are:
  - the registers;
  - *indicators* `e_P`, with `e_P^2 = e_P` and `e_P P = 0`, and *reciprocals* `P'`, with
    `P P' = p_ρ − e_P`, for finitely many `P ∈ Z[Y_ρ]`;
  - *resolvents* `Q^(-1)` for finitely many `Q ∈ Z[Y_ρ]`.
- **(D5) Availability.** `t_x s_x = α_x`, a Boolean polynomial in the indicators at
  `r(x)`.
- **(D6) Relations.** The Cuntz--Krieger relation `p_ρ = Σ_(s(x)=ρ) s_x t_x`,
  `t_x s_y = 0` for `x ≠ y`, and covariance: base generators commute with every
  `s_y t_y`, and `t_x Y s_x = σ_x(Y) α_x`.
- **(D7) Extra relations.** Any finite set of elements of the **base closure** `ℬ`, the
  commutative subring generated by the base generators and all transports
  `t_w b s_w` along words, each set equal to `0`.

A **diagonal module** is a module on a basis of *states* in which:
- each state has a type and a *value* `v(s)`, an assignment of the registers in some
  field extension of `Q`;
- letters act by prefixing, and a prefix is legal exactly when `α_x = 1` at the rest;
- values transform by the `σ_x`;
- base generators act diagonally by evaluation.

The **concrete model** `M_Z` is a diagonal module whose values are integers. `R_conc` is
the image of the presented ring `R(𝒫)` in `End(M_Z)`.

## Hypotheses: a comparison with a translation chain
- **(C1) Translation chain.** There are a type `τ`, a register `Δ` at `τ`, and a letter
  `c : τ -> τ` with `σ_c(Δ) = Δ − 1` and `σ_c` fixing every other register at `τ`. Its
  availability satisfies `α_c(y) = 1` whenever `Δ(y) ∉ Z`, as for
  `α_c = p_τ − e_Δ`.
- **(C2) Comparison.** There are a second register `L` at `τ` and an infinite set `K` of
  integers such that, for every `k ∈ K`:
  - the `τ`-values of `M_Z` with `L = k` have finitely many `Δ`-coordinates `F_k`;
  - there are elements `λ_k` and `ε_i` (`i ∈ F_k`) of `ℬ` acting on every diagonal module
    as the indicators of `L = k` and of `Δ = i`.
- **(C3) Density.** At every type, the values of `M_Z` are Zariski dense in `Q^(Y_ρ)`.
- **(C4) Generic chains.** Let `δ` be transcendental over `Q`. For each `k ∈ K` there is a
  diagonal module `M_k` of `𝒫` *without* the extra relations (D7) such that:
  - it contains a `c`-chain of `τ`-states `s_n` (`n ∈ Z`) with `c s_n = s_(n+1)`,
    `Δ(s_n) = δ − n`, `L = k`, and the other `τ`-registers fixed integers;
  - every value of `M_k` has coordinates in `Z[δ]`, and every value free of `δ` is a
    value of `M_Z` of the same type;
  - for every nonzero polynomial `P`, only finitely many `k ∈ K` have a `δ`-dependent
    value `y` of `M_k` with `P(y) = 0`.

## Statement
Assume (C1)–(C4), with any finite set of extra relations (D7) that hold on `M_Z`, and any
finitely many resolvents `Q` nonzero on `M_Z`. Then, for all but finitely many `k ∈ K`:
1. `M_k` is a module of the full presentation `𝒫`;
2. `X_k = λ_k·(1 − Σ_(i∈F_k) ε_i) ∈ ℬ` acts as `1` on the chain states of `M_k` and as `0`
   on `M_Z`.

So `ker(R(𝒫) -> R_conc)` is a nonzero proper ideal, and `R(𝒫)` is not simple.

**Instance.** The capacity-chain presentation of `capacity-chain-resolvent-ring-has-rational-k0`,
with or without `a_u`, together with *any* finite set of extra relations from `ℬ` true
in its concrete model and any finitely many extra resolvents. Here `F_k = {0..k}`,
`λ_k = t_d t_st ε_(k−1) s_st s_d`, `ε_i = t_c^i e_Δ s_c^i`, and `M_k` is the module of
`capacity-chain-presentation-is-not-simple-proof` with `δ` transcendental. See the proof,
§4.

## Not covered (explicit loopholes)
- **Dilation-driven fibres: not covered by this theorem.** These are designs whose growing
  fibres are not traversed by a translation letter `σ_c(Δ) = Δ − 1`, for example fibres
  counted by dilations `N ↦ pN + r`; (C1) fails. The proof uses (C1) only through the
  `c`-chain of (C4). So the same argument applies to any design with a `δ`-generic chain
  meeting (C2)–(C4), and the dilation case is open, not shown to escape (referee b, W3).
- **Noncommutative relations.** Relations not in the base closure, for example
  `sl_2`-type commutator relations among letters, or relations between letters beyond
  (D6). Lane `gq-k2-q` shows the `sl_2` route hides the same comparison, between the
  running weight and the top weight, and admits Verma-type modules
  (`sl2-vacuum-hosts-admit-verma-type-modules`, f9915b838). That argument is separate from
  this theorem.
- **Non-register hosts.** Rings not given by a register presentation.
- **Sparse models.** Concrete models whose values are not Zariski dense, where (C3) fails.

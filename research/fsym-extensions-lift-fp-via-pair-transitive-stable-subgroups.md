**ESTABLISHED** (lane proof, elementary, proved below; not independently reviewed; no priority claimed).

**Statement.** Let `X` be infinite and `FSym(X) <= K <= Γ <= Sym(X)`. Assume:
- (a) `K` is finitely presented;
- (b) `Γ = <K, y_1, ..., y_m>`, and `Q = Γ/FSym(X)` is finitely presented;
- (c) for each `i` there is a finite set `C_i ⊂ Γ_(i-1) = <K, y_1, ..., y_(i-1)>` such that
  `y_i c y_i^-1 ∈ Γ_(i-1)` for every `c ∈ C_i`, and `<C_i>` has finitely many orbits on 2-element subsets of `X`.

Then `Γ` is finitely presented. The intermediate groups `Γ_(i-1)` need not be finitely presented, and their
quotients by `FSym(X)` need not be either.

Hypothesis (b) on `Q` is also necessary. `FSym(X)` is normally generated in `Γ` by one transposition, so a finite
presentation of `Γ` gives one of `Q`.

**Proof.** Fix a finite generating set `A` of `K`. For each transposition `u` of `X` fix a word `û` in `A`
representing it (possible since `u ∈ K`). Presentation `Γ̃`, with generators `A` and letters `ỹ_1, ..., ỹ_m`:
- (R1) a finite presentation of `K` on `A`;
- (R2) for each `i` and `c ∈ C_i`: words `w_c` for `c` and `w'_c` for `y_i c y_i^-1`, both in `A` and `ỹ_1..ỹ_(i-1)`,
  and the relation `ỹ_i w_c ỹ_i^-1 = w'_c`;
- (R3) for each `i` and one transposition `u` from each `<C_i>`-orbit of transpositions: `ỹ_i û ỹ_i^-1 = v̂`,
  where `v = y_i u y_i^-1`;
- (R4) a finite presentation of `Q` on the images of `A ∪ {y_i}`. For each of its relators `r`, the value of `r` in
  `Γ` is some `f_r ∈ FSym(X)`, and the relation is `r = f̂_r`.

All relations hold in `Γ`, and there are finitely many by (a), (b) and (c). Let `π : Γ̃ -> Γ` be the natural
surjection.

*Step 1.* By (R1), `A` generates a quotient `K̃` of `K`, and `π` maps it onto `K` by the identity on `A`. So
`π : K̃ -> K` is an isomorphism. Put `F̃ = π^-1(FSym(X)) ∩ K̃`, and write `ũ` for the element of `F̃` over a
transposition `u`. Every `k ∈ K̃` then satisfies `k ũ k^-1 = (π(k) u π(k)^-1)~`, since both sides lie in `K̃`
and have the same image.

*Step 2 (induction on `i`).* Say `g ∈ Γ̃` *acts correctly* if `g ũ g^-1 = (π(g) u π(g)^-1)~` for every
transposition `u`. Acting correctly is closed under products and inverses, because it says that conjugation by `g`
permutes `T̃ = {ũ}` as `π(g)` permutes the transpositions. Suppose `K̃` and `ỹ_1, ..., ỹ_(i-1)` act correctly.
Then so does every element of `Γ̃_(i-1) = <K̃, ỹ_1..ỹ_(i-1)>`, in particular every `c̃ = w_c` and `c̃' = w'_c`.

Let `U` be the set of transpositions `u` with `ỹ_i ũ ỹ_i^-1 = (y_i u y_i^-1)~`. For `u ∈ U` and `c ∈ C_i`, (R2)
gives

    ỹ_i (c̃ ũ c̃^-1) ỹ_i^-1 = c̃' (y_i u y_i^-1)~ c̃'^-1 = (y_i c y_i^-1 · y_i u y_i^-1 · y_i c^-1 y_i^-1)~ = (y_i (c u c^-1) y_i^-1)~,

and `c̃ ũ c̃^-1 = (c u c^-1)~`. So `c u c^-1 ∈ U`. Inverting (R2) gives the same for `c^-1`. So `U` is
`<C_i>`-invariant. By (R3) it meets every orbit, so `U` is everything and `ỹ_i` acts correctly.

*Step 3.* Every generator of `Γ̃` acts correctly and permutes `T̃`. Since `T̃` generates `F̃`, the subgroup `F̃` is
normal in `Γ̃`. In `Γ̃/F̃` the relations (R4) become the relators of the chosen presentation of `Q`. So the
assignment on generators defines a homomorphism `Q -> Γ̃/F̃`. It is inverse to the map `Γ̃/F̃ -> Q` induced by `π`,
since both are the identity on generators. So `ker(Γ̃ -> Q) = F̃`.

*Step 4.* `ker π ⊆ ker(Γ̃ -> Q) = F̃`, and `π` is injective on `F̃ ⊆ K̃` by Step 1. So `π` is an isomorphism. ∎

## Calibrations

- **Free-shift enumerations.** Take `Γ = H_n(E_nu(P))` with `P * <s>` embedded as `R_nu`, `K = H_n(E_2)`, and the
  letters `rho`. Then (c) fails for every letter; see
  `strand-map-bases-lift-only-bounded-displacement-letters`. That is consistent with
  `free-shift-houghton-like-envelopes-are-not-fp`, where the germ group is finitely presented and `Γ` is not.
- **Finitely presented strongly shift-similar `G`.** Take `K = G^n · FSym(X)`, finitely presented by
  `finitary-mixing-of-fp-highly-transitive-groups-is-fp`, and let the letters be the Houghton translations.
  `K` is normal in `H_n(G)` (step 2 of `fp-strongly-shift-similar-groups-have-fp-houghton-like-groups`), so
  `C_i` can be a finite generating set of `G^n`. It has finitely many orbits on pairs, since each `G_k` contains
  `FSym(ray k)`. This agrees with that node's conclusion.
- **`H_2`.** It has no finitely presented subgroup containing `FSym(Z)`, so the criterion does not apply. That
  is consistent with `H_2` not being finitely presented while `H_2/FSym = Z` is.

## Reading

- The lifting problem for `H_n(E_nu(P))`, `n >= 2`, now reduces to one question per letter. Its germ group is
  finitely presented iff `R_nu` is (`houghton-like-envelopes-have-fp-germs-iff-fp-near-shift-group`), and
  `K = H_n(E_2)` is finitely presented, being commensurable with `H_(2n)`. What remains is to find, for each
  `rho`-letter, a finitely generated subgroup that the letter conjugates back into the group already built and
  that is transitive enough on pairs.
- The rigid near relations that item 3 of `free-shift-houghton-like-envelopes-are-not-fp` requires are exactly
  what (R2) records. A letter `y` must carry elements `c` whose `y`-conjugates stay inside the known group.
- Over the Houghton base, with every `C_i` taken inside `K`, this forces every `rho`-letter to have bounded
  displacement, and hence forces `P` to be virtually cyclic
  (`strand-map-bases-lift-only-bounded-displacement-letters`). A non-virtually-abelian witness therefore needs
  either the iterated form of (c) or a finitely presented base whose elements have unbounded displacement on the
  `rho`-strands.

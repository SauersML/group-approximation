Write `P = PPSL_2(Z)` and `M = PSL_2(Z) ≤ P`. By `thompson-t-is-isomorphic-to-ppsl2z`,
`Φ : P → T` is an isomorphism with `Φ(M) = Λ`, so it suffices to prove the statements for
`M ≤ P`. For `g ∈ P` let `B(g)` be its breakpoint set in the sense of Definition 2.1 there: the
points `x ∈ RP^1` with no open neighbourhood on which `g` agrees with one element of `M`. By that
definition `B(g)` is finite and contained in `Q ∪ {∞}`.

**Step 1 (germs).** A nonidentity element of `M` has at most two fixed points on `RP^1`, since
`x = (ax+b)/(cx+d)` is a nonzero polynomial condition of degree at most 2 unless the matrix is
`±1`. So two elements of `M` that agree on an open interval are equal. Hence for `x ∉ B(g)` there
is a unique `germ_x(g) ∈ M` with `g = germ_x(g)` near `x`, and `x ↦ germ_x(g)` is locally
constant on `RP^1 \ B(g)`.

**Step 2 (`B(g) = ∅` iff `g ∈ M`).** If `B(g) = ∅`, the locally constant map `x ↦ germ_x(g)` on
the connected space `RP^1` is constant, equal to some `m`, and then `g = m`. The converse is
clear.

**Step 3 (`|B(g)| ≠ 1`).** If `B(g) = {x}`, then `RP^1 \ {x}` is homeomorphic to an open
interval, hence connected, so `g` agrees with one `m ∈ M` on it. By continuity `g = m` on all of
`RP^1`, so `x ∉ B(g)`, a contradiction. With Step 2: `g ∉ M` implies `|B(g)| ≥ 2`.

**Step 4 (equivariance).** For `m, m' ∈ M` and `x ∈ RP^1`: `x ∈ B(m g m')` iff `m'x ∈ B(g)`.
Indeed if `g = n ∈ M` near `m'x`, then `m g m' = m n m'` near `x`; conversely if
`m g m' = n'` near `x`, then `g = m^{-1} n' m'^{-1}` near `m'x`. So `B(m g m') = m'^{-1}(B(g))`.

**Step 5 (the intersection permutes the breakpoints).** Fix `g ∈ P \ M` and put
`K = M ∩ g^{-1}Mg`. Conjugation `k ↦ gkg^{-1}` is an isomorphism `K → M ∩ gMg^{-1}`, so it
suffices to bound `K`. For `k ∈ K` write `gkg^{-1} = h ∈ M`. Then `g = h^{-1} g k`, and Step 4
gives `B(g) = k^{-1}(B(g))`. So `K` acts on the finite set `B(g)`, which has at least two points
(Step 3), all in `Q ∪ {∞}`.

**Step 6 (the action is faithful).** Let `k ∈ M` fix two distinct points of `Q ∪ {∞}`, with
matrix `[[a, b], [c, d]]` and trace `t = a + d`.
- If `c = 0`, then `ad = 1`, so `a = d = ±1` and `k(x) = x ± b`, which fixes `∞`. A second fixed
  point in `Q` forces `b = 0`, so `k = 1`.
- If `c ≠ 0`, then `∞` is not fixed, so both fixed points are rational roots of
  `c x² + (d - a) x - b = 0`. Its discriminant is `(d - a)² + 4bc = t² - 4`. Two distinct rational
  roots need `t² - 4 = n²` with `n` a positive integer (an integer with a rational square root is
  a perfect square). Then `(t - n)(t + n) = 4`, where the two factors have the same parity, so both
  are `±2`, which gives `n = 0`. This is a contradiction.

So the kernel of `K → Sym(B(g))` is trivial, and `|M ∩ gMg^{-1}| = |K| ≤ |B(g)|!`. This is claim 1.
(It is also Haagerup--Olesen's Proposition 2.5, quoted in
`psl2z-in-thompson-t-has-amenable-centralizers-in-v-citation`, but the proof above is
self-contained.)

**Step 7 (hypotheses of the lemma).**
- `T` is countable.
- `Λ ≅ M` is nonamenable. `M ≅ Z/2 * Z/3` (Proposition 2.4 in `thompson-t-is-isomorphic-to-ppsl2z`),
  and the kernel of `Z/2 * Z/3 → Z/2 × Z/3` is free of rank 2 (standard). Equivalently, `M`
  contains the free group generated by `[[1,2],[0,1]]` and `[[1,0],[2,1]]` (Sanov).
- `Λ ≠ T`. Every finite-order element of a free product is conjugate into a factor (standard), so
  elements of `Λ` have order 1, 2 or 3. The rotation `r_(1/4) ∈ T`, used in
  `thompson-t-orbits-carry-no-invariant-means`, has order 4.
- By claim 1, `Λ ∩ gΛg^{-1}` is finite, hence amenable, for every `g ∈ T \ Λ`.

**Step 8 (conclusion).** `nonamenable-almost-malnormal-subgroups-are-not-co-amenable` with
`G = T` and `H = Λ` gives claims 2 and 3. The transport remark in the target holds because an
isomorphism `P → T` carries `M` to a subgroup satisfying the same hypotheses. ∎

**Calibration.** The proof uses the breakpoint set `B(g)` as the invariant. The class dies at
Step 5: every element of `Λ ∩ gΛg^{-1}` must permute the finite set `B(g)`. It would not work
for `F ≤ T` or any point stabilizer, since those intersect their conjugates in nonamenable groups.
They are excluded instead by `thompson-t-orbits-carry-no-invariant-means`.

Throughout, `N >= 3` and `R ⊇ Q` as in the statement. By
`q-algebra-elementary-quotients-contain-gl-n-q` (parts 1–2), `Q ⊆ Z(R)`, and
`Z(E_N(R)) = E_N(R) ∩ Z(R)^x I`.

**Perfection.** For distinct `i, l, j` (possible since `N >= 3`),
`e_ij(r) = [e_il(r), e_lj(1)]`. So `E = E_N(R)` is perfect.

**1.** Let `x_1, ..., x_k ∈ E` map to generators of `P`, and put `H = <x_1..x_k>`.
Then `E = H Z(E)`. Since `Z(E)` is central, `[E, E] = [H Z(E), H Z(E)] = [H, H] ⊆ H`.
So `E = [E, E] ⊆ H`, and `E` is finitely generated.

Let `S` be the subring generated by the entries of the `x_i` and of their inverses.
Then `E ⊆ GL_N(S)`. For every `r ∈ R`, `e_12(r) ∈ E` has `(1,2)` entry `r`, so
`r ∈ S`. Hence `R = S` is finitely generated.

**2.** By part 1, `E` is finitely generated. `Z(E)` is central, and `E/Z(E) = P` is
finitely presented. So by `fg-central-extension-of-fp-group-is-fp`, `Z(E)` is
finitely generated, as an abelian group.

`λ ↦ λI` embeds `Λ_N(R)` in `Z(E)`. The image is central because `λ ∈ Z(R)`, and
the map is injective because `Q -> R` is. A subgroup of a finitely generated
abelian group is finitely generated, so `Λ_N(R)` is. A finitely generated subgroup
of `Q^x = {±1} x ⊕_p p^Z` involves finitely many primes.

For the last sentence, let `P` be simple and let `M` be normal in `E` with `E/M`
simple.
- The image of `M` in `P` is normal, so it is trivial or `P`.
- If it were `P`, then `E = M Z(E)`, so `E = [E, E] = [M, M] ⊆ M`. That contradicts
  `E/M != 1`.
- So `M ⊆ Z(E)`, and `Z(E)/M` is normal in the simple group `E/M`.
- It is not all of `E/M`, since `E` is perfect and nontrivial, hence not equal to its
  centre. So `M = Z(E)` and `E/M = P`.

**3.** If `GL_N(R) = E_N(R)`, then `λI ∈ E_N(R)` for all `λ ∈ Q^x`, so
`Λ_N(R) = Q^x`. That group is not finitely generated, since there are infinitely
many primes. Apply the contrapositive of part 2.

**4.** `Q^x ⊆ Z(R)^x ⊆ Z(R^x)`, and `Q^x` is not finitely generated. So `Z(R^x)`,
an abelian group containing it, is not finitely generated.
- If `R^x` is finitely generated and `R^x/Z(R^x)` is finitely presented, then
  `fg-central-extension-of-fp-group-is-fp` makes `Z(R^x)` finitely generated.
  That is a contradiction.
- If `R^x` is perfect and `R^x/Z(R^x)` is finitely presented (so finitely
  generated), then the argument of part 1 makes `R^x` finitely generated. This
  reduces to the previous case.
- `R^x` is not simple: `Q^x` is a nontrivial central subgroup. It is proper unless
  `R^x = Q^x`, which is abelian but not simple.

**5.** Let `λ ∈ Λ_N(R)`. Then `λI_N ∈ E_N(R)`, so its class in `K_1(R)` is `0`. By
naturality of `K_1`, that class is the image of the class of `λI_N` in
`K_1(Q) = Q^x`, namely `det(λI_N) = λ^N`. So `λ^N` lies in the kernel `C` of
`Q^x -> K_1(R)`.

If `C` is finitely generated, it involves only a finite set `F` of primes. Then
`λ^N ∈ C` forces the prime support of `λ` into `F`. So
`Λ_N(R) ⊆ <-1, p : p ∈ F>`, which is finitely generated. ∎

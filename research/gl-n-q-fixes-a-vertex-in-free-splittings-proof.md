Direct proof. Let `H` act on the simplicial tree `T` without inversions, with
trivial edge stabilizers. If `T` has no edge there is nothing to prove, so
assume it has one.

**Step 1. Divisible elements are elliptic.** A hyperbolic element `g` of a
simplicial tree without inversions has integer translation length
`ℓ(g) >= 1`, and `ℓ(r^k) = k ℓ(r)` for hyperbolic `r`. If `g = r_k^k` for
infinitely many `k`, then either some `r_k` is elliptic, and then so is
`g = r_k^k`, or `ℓ(g) = k ℓ(r_k) >= k` for infinitely many `k`, which is
impossible. So an element with roots of infinitely many orders is elliptic.

**Step 2. A nontrivial elliptic element fixes exactly one vertex.** If
`u != 1` fixed two vertices, it would fix the geodesic between them and hence
an edge, whose stabilizer is trivial.

**Step 3. A nontrivial divisible locally cyclic subgroup `D` has a common fixed
vertex `x_D`.** Every element of `D` is divisible in `D`, hence elliptic by
Step 1. For `u, v ∈ D \ {1}`, the group `<u, v>` is cyclic, say `<w>` with
`w ∈ D \ {1}`. By Step 2, `w` fixes a unique vertex `x_w`. Then `u = w^a` and
`v = w^b` fix `x_w`, so by Step 2 again `Fix(u) = Fix(v) = {x_w}`.

**Step 4. Normalizers fix `x_D`.** If `h` normalizes `D`, then for
`u ∈ D \ {1}`, `h` maps `Fix(u) = {x_D}` to `Fix(h u h^-1) = {x_D}`. So
`h x_D = x_D`.

**The cases.**
- `(Q,+)` is divisible and locally cyclic: Step 3.
- `Aff(Q)`: the normal subgroup `Q` gives `x_Q`, fixed by all of `Aff(Q)` by
  Step 4.
- `U_3(Q)`: the centre is `≅ (Q,+)` and normal. Step 4 again.
- `GL_n(Q)` and `SL_n(Q)`, `n >= 2`. Each root subgroup
  `U_ij = {1 + q e_ij : q ∈ Q}` (`i != j`) is `≅ (Q,+)`, with a vertex
  `x_ij`.
  - The diagonal torus normalizes every `U_ij`, so by Step 4 it fixes every
    `x_ij`.
  - Take the nontrivial diagonal element `t_0 = diag(2, 1/2, 1, ..., 1)`, which
    lies in `SL_n(Q)`. If `x_ij != x_12`, then `t_0` fixes the geodesic between
    them, hence an edge, so `t_0 = 1`. That is a contradiction. So all `x_ij`
    equal one vertex `x`.
  - `SL_n(Q)` is generated by the `U_ij`, and `GL_n(Q)` by the `U_ij` and the
    torus, since `Q` is a field. So each fixes `x`.

**Consequences.** The Bass--Serre tree of `A * B`, or of any graph of groups
with trivial edge groups, has trivial edge stabilizers, and its vertex
stabilizers are the conjugates of the vertex groups. After a barycentric
subdivision there are no inversions. The subdivision leaves edge stabilizers
trivial and adds midpoint vertices whose stabilizers have order at most 2, and
none of the groups above embeds in a group of order 2. So the fixed vertex is
an original vertex and `H` lies in a conjugate of a vertex group.

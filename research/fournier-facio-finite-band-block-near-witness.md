Partition the singular charged basis into blocks of one fixed maximum size.
Let each actor permute the blocks while applying an arbitrary unitary matrix
inside each transported block.  Permit additional noncompact errors on a
charge-null reservoir, hoping that matrix traces inside fixed blocks hide
the fixed points of the underlying block near action.

This architecture is invalidated by
`fournier-facio-bounded-block-near-witness-impossible`.  Uniform recurrence
in `U(m)` exposes every positive-charge fixed-block sector in one of finitely
many nontrivial powers.  Torsion-freeness and essential freeness then force
the block near action itself to be free, which would make the nonsofic group
sofic.

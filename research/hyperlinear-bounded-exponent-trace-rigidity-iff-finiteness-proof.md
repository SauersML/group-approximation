**Conventions.** `||a||_2 = tr(a* a)^(1/2)` with `tr` normalized. The norm is
bi-invariant on `U(d)`, and `|tr a - tr b| <= ||a - b||_2`. Hyperlinearity is
used in the two forms of Pestov, *Hyperlinear and sofic groups: a brief
guide*, arXiv:0804.3968v8, §3, checked against the text:

- **Definition 3.2.** "A group G is hyperlinear if it is isomorphic to a
  subgroup of a metric ultraproduct of a suitable family of unitary groups
  of finite rank, with their normalized Hilbert-Schmidt distances."
- **Theorem 3.6 (Radulescu).** "A group G is hyperlinear if and only if for
  every finite F ⊆ G and each ε > 0 there exist a natural n and a mapping
  θ : F → U(n) ... so that (1) if g, h, gh ∈ F, then
  ||θ(g)θ(h) − θ(gh)||_2 < ε, (2) if e ∈ F then ||θ(e) − Id||_2 < ε, and
  (3) for all distinct x, y ∈ F, ||θ(x) − θ(y)||_2 ≥ 1/4."

## 1 implies 2

Let `u^(k)` be an approximate exponent-N model with limit trace `tau`. Fix a
nonprincipal ultrafilter `ω` on `N`. Let `G_ω` be the metric ultraproduct of
the groups `(U(d_k), ||.||_2)`: the product group modulo the sequences with
`lim_ω ||g_k - I||_2 = 0`, a normal subgroup because the distance is
bi-invariant. Put `U_i = [u_i^(k)]` and `H = <U_1, ..., U_m> <= G_ω`.

1. **Exponent.** For a word `w`, `w(U)^N = [w(u^(k))^N]`, whose distance to
   the identity is `lim_ω ||w(u^(k))^N - I||_2 = 0`. Every element of `H` is
   some `w(U)`, so `H` has exponent dividing `N`.
2. **Finite.** `H` is `m`-generated and hyperlinear by Definition 3.2. By
   statement 1, `H` is finite.
3. **The trace factors.** For `g = [g_k]` in `G_ω` put `s(g) = lim_ω tr g_k`.
   This is well defined because `|tr a - tr b| <= ||a - b||_2`. For every word
   `w`, `tau(w) = lim_k tr w(u^(k)) = lim_ω tr w(u^(k)) = s(w(U))`. With
   `p: F_m -> H`, `w ↦ w(U)`, this gives `tau = s o p`, and `H` is finite.

## 2 implies 1

Let `H` be hyperlinear, of exponent dividing `N`, and generated by
`h_1, ..., h_m`. Let `π: F_m -> H` send `x_i` to `h_i`, and let `B_k` be the
radius-`k` ball of `H` in the word metric of `{h_i^(±1)}`. Theorem 3.6 with
`F = B_k` and `ε = 1/k` gives `θ_k: B_k -> U(d_k)`. Put `u_i^(k) = θ_k(h_i)`.

1. **Word control.** For each letter `x = h_i^(±1)`, write `x(u)` for `u_i`
   or `u_i^*`. Then
   `||u_i^* - θ_k(h_i^(-1))||_2 = ||I - θ_k(h_i) θ_k(h_i^(-1))||_2 < 2/k`,
   by bi-invariance and conditions (1), (2). If `w = w' x` has length
   `L <= k`, conditions (1) and (2) with `π(w'), π(x), π(w) in B_k` give
   `||w(u^(k)) - θ_k(π(w))||_2 <= ||w'(u^(k)) - θ_k(π(w'))||_2 + 3/k`. By
   induction from the empty word, `||w(u^(k)) - θ_k(π(w))||_2 <= (3L+1)/k`.
2. **Approximate exponent law.** For a fixed `w` and `k >= N|w|`, step 1
   applied to `w^N` and `π(w^N) = π(w)^N = e` give
   `||w(u^(k))^N - I||_2 <= (3N|w| + 2)/k -> 0`.
3. **Limit trace.** The sequences `tr w(u^(k))` are bounded, and there are
   countably many words. A diagonal subsequence makes all of them converge.
   That is an approximate exponent-N model with some limit trace `tau`. By
   statement 2, `tau = s o p` for a finite quotient `p: F_m -> Q`.
4. **Kernels.** Suppose `p(w) = 1`. Then `tau(w) = tau(e) = 1`, so
   `||w(u^(k)) - I||_2^2 = 2 - 2 Re tr w(u^(k)) -> 0`. If `π(w) != e`, then for
   large `k` both `π(w)` and `e` lie in `B_k`, and step 1 with condition (2)
   gives `||θ_k(π(w)) - θ_k(e)||_2 -> 0`. That contradicts condition (3).
   Hence `ker p ⊆ ker π`, and `H` is a quotient of the finite group `p(F_m)`.

## Consequence

`B(m,N)` is `m`-generated of exponent dividing `N`. If it is infinite and
statement 1 holds, it cannot be hyperlinear.

∎

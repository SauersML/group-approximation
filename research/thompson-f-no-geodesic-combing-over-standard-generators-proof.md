Direct proof from one elementary lemma and one imported theorem. Notation as
in the target: `X` is finite with `x0 ∈ X ⊆ {x0, x1, ...}`, `S = X ∪ X^-1`, and
`|g|` and `d` are the word length and word metric over `S`. Write `B(n)` for the
ball of radius `n` about the identity.

## Imported theorem

M. Horak, M. Stein, J. Taback, *Convexity properties of Thompson's group F*,
arXiv:0801.1862v1 (January 2008), Theorem 4.4. The statement below was read
verbatim from the PDF on 2026-09-17:

> Theorem 4.4. Let X be any subset of the standard infinite generating set for F
> which includes x0. Then F is not almost convex with respect to X.

Their definition (Introduction, following Cannon, *Almost convex groups*, Geom.
Dedicata 22 (1987)) reads: `G` is `AC(k)` with respect to a finite generating set
`X` if there is `L(k)` such that for every `n`, any `x, y ∈ B(n)` with
`d(x, y) <= k` are joined by a path of length `<= L(k)` inside `B(n)`. Cannon
proved `AC(2) ⇒ AC(k)` for all `k`, and "almost convex" means `AC(2)`.

For `X = X_n = {x0, ..., xn}` the same conclusion is proved independently in
Horak–Stein–Taback, *Computing word length in alternate presentations of
Thompson's group F*, arXiv:0706.3218, Theorem 6.1. For `X = X_1` it is
Cleary–Taback, *Thompson's group F is not almost convex*, J. Algebra 270 (2003).
The imported proofs were not re-derived this session. The general `X` case of
Theorem 4.4 passes through their Theorem 3.1: a `C`-coarse isometry carries
non-minimal-almost-convexity to non-almost-convexity.

## Lemma (geodesic combing ⇒ AC(2))

Let `G` be generated by a finite symmetric set `S`. Suppose `σ_g` (for `g ∈ G`)
is a choice of geodesic words and `K >= 0` is such that
`d(σ_g(t), σ_h(t)) <= K` for all `t >= 0` whenever `d(g, h) <= 1`. Here
`σ_g(t)` is the endpoint of the prefix of length `min(t, |g|)`. Then `(G, S)` is
`AC(2)` with `L(2) = 4K`.

*Proof.* Take `x, y ∈ B(n)` with `d(x, y) <= 2`. Choose `u` with
`d(x, u) <= 1` and `d(u, y) <= 1`. The vertex `u` may lie outside `B(n)`; only
its combing path is used. By the triangle inequality, applied twice,
`d(σ_x(t), σ_y(t)) <= 2K` for every `t`.

Put `t0 = max(0, n − K)` and build a path in three pieces.

1. Walk backwards along `σ_x` from `x` to `σ_x(t0)`. If `|x| <= t0` this piece
   is empty, because `σ_x(t0) = x`. Otherwise it has `|x| − t0 <= n − t0 <= K`
   edges. `σ_x` is geodesic, so every vertex on it has length `<= |x| <= n`.
2. Join `p = σ_x(t0)` to `q = σ_y(t0)` by a geodesic of length `d(p, q) <= 2K`.
   Each of its vertices `v` is within `K` of `p` or of `q`, so
   `|v| <= max(|p|, |q|) + K <= t0 + K`. This uses `|σ_g(t)| <= t`. If `t0 > 0`
   then `t0 + K = n`. If `t0 = 0` then `n <= K` and `p = q = 1`, so this piece is
   empty. Either way piece 2 lies in `B(n)`.
3. Walk forwards along `σ_y` from `q` to `y`: at most `K` edges inside `B(n)`,
   as in piece 1.

The concatenation joins `x` to `y` inside `B(n)` and has length
`<= K + 2K + K = 4K`. ∎

## Proof of the target

**Part 1.** Suppose `Γ(F, S)` had a geodesic combing with the fellow traveller
property. By the Lemma, `F` would be almost convex with respect to `X`. This
contradicts the imported Theorem 4.4.

**Part 2.** Let `(W, M)` be an automatic structure over `S`. By the
characterisation of automatic structures (Epstein et al., Theorem 2.3.5, as used
in `zaremsky-2-02-thompson-f-automatic`), there is `K` such that any accepted words
`u, v ∈ W` whose endpoints satisfy `d(ū, v̄) <= 1` obey `d(u(t), v(t)) <= K` for
all `t`. Suppose `W` contained a geodesic representative of each `g ∈ F`. Pick
one, `σ_g ∈ W`, for each `g`. The words `σ_g` are accepted, so they satisfy the
hypothesis of the Lemma with this `K`, which contradicts Part 1.

Shortlex automatic structures, and more generally geodesic automatic structures,
consist of geodesics that represent every element. They are excluded. ∎

## Remarks

- Cleary–Taback make the remark for `X_1` after Theorem 4.2 of
  arXiv:math/0310466: "This also follows from the fact that F is not almost
  convex". The route above extends that remark to every finite standard subset.
- The Lemma does not extend to near-geodesic combings (`|σ_g| <= |g| + c`).
  Pieces 1 and 3 can then leave `B(n)` by up to `c/2`. Non-almost-convexity only
  constrains paths inside `B(n)`, so the case `c > 0` needs Hauze-type arguments.

Write `chi = sum a_ij omega_ij`, `c_A = sum_{i<j in A} a_ij`, and let `A = A(P_n)` be
the Orlik–Solomon algebra of the braid arrangement. Its top degree is `n - 1`. A real
character `chi` is a point of `R^i` iff `H^i(A ⊗ R, chi ∧) != 0`; the dimension is
the same over `C`. Fix `m >= 1`.

Small `n`. `P_1` is trivial and both sides are empty. `P_2 = Z`: every nonzero
character is in `Sigma^infinity`, and `(Λ(e), a e ∧)` is exact for `a != 0`.
So both sides are the whole sphere. From now on `n >= 3`.

Inclusion `⊆`. Let `q = min(m, n - 1)`. Then `R^i` is empty for `i >= n`, and
`R^0 = {0}` misses the sphere, so `R^{<=m} = R^1 ∪ ... ∪ R^q`. For `1 <= i <= q`,
`Sigma^m ⊆ Sigma^i`, and `Sigma^i` avoids the real points of `R^i` by
`arrangement-bnsr-invariants-avoid-real-resonance`.

Inclusion `⊇`. Let `[chi]` avoid the real points of `R^{<=m}`.

1. If `sum a_ij != 0`, then `[chi]` is in `Sigma^infinity(P_n)`
   (`pure-braid-top-bnsr-invariants-are-center-nonvanishing`).
2. Let `sum a_ij = 0`. The arrangement is central, and deconing along `H_12` gives
   `A = A' ⊗ Λ(e_12)`. Here `A'` is the subalgebra generated by the `e_ij - e_12`,
   isomorphic to the Orlik–Solomon algebra of the decone, with Poincaré polynomial
   `prod_{k=2}^{n-1} (1 + k t)` (Orlik–Terao; standard, not re-read). Then
   `chi = sum a_ij (e_ij - e_12) + (sum a_ij) e_12` lies in `A'`. So
   `H^i(A, chi) = H^i(A', chi) ⊕ H^{i-1}(A', chi)`. The complex `(A', chi ∧)` has
   Euler characteristic `prod_{k=2}^{n-1} (1 - k) = (-1)^{n-2} (n-2)! != 0`. Hence
   `chi` is in `R^{<=n-2}`. So `m <= n - 3`, and `n >= 4`.
3. If every `c_A` (`2 <= |A| <= n - 1`) is nonzero, then `[chi]` is in
   `Sigma^{n-3} ⊆ Sigma^m`
   (`pure-braid-nonzero-twist-characters-lie-in-sigma-n-minus-3`).
4. Otherwise some `c_A = 0`.
   - If `m = 1`: `chi` is not in `R^1`, so `[chi]` is in `Sigma^1(P_n)`. This uses
     `pure-braid-bns-invariant-is-circle-complement` (KMM circles are the real
     points of `R^1`, Cohen–Suciu).
   - If `2 <= m <= n - 3`, then `n >= 5`, and `[chi]` is in `Sigma^m(P_n)` by
     `pure-braid-nonresonant-zero-twist-characters-in-sigma`.

The cases are exhaustive, which proves the target. Degree `m` of the target on
`P_n` needs the last required claim only in degree `m` on `P_n`. For the
middle-range consequences of this route, see `pure-braid-middle-bnsr-from-resonance-sharpness`.

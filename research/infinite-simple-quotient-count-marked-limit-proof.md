Notation as in the target. `B(r)` is the set of words of length `<= r` in `F_m`.

## (M1)

**Orders are unbounded.** There are finitely many groups of order `<= M`, and at most
`M^m` homomorphisms from `F_m` to each. So only finitely many kernels have quotient of
order `<= M`. Since `X(Λ) = ∞`, take distinct kernels `ker φ_n ⊇ N_Λ` with `|S_n| -> ∞`.

**A limit exists.** `F_m` is countable. By a diagonal argument some subsequence has, for
each `w`, `w ∈ ker φ_n` for all large `n` or `w ∉ ker φ_n` for all large `n`. Let `N_∞` be
the set of eventually-in words.
- `N_∞` is a normal subgroup: for `w, v ∈ N_∞` and `g ∈ F_m`, the words `wv^{-1}` and
  `g w g^{-1}` lie in `ker φ_n` for all large `n`.
- `N_Λ ⊆ N_∞`, because `N_Λ ⊆ ker φ_n` for all `n`.

**G_∞ is infinite.** Otherwise `N_∞` has finite index, so it is generated by a finite set
`T` (Schreier). For large `n`, `T ⊆ ker φ_n`, so `N_∞ ⊆ ker φ_n` and
`|S_n| <= [F_m : N_∞]`. That contradicts `|S_n| -> ∞`.

**G_∞ is LEF.** Let `C ⊆ G_∞` be finite, and choose `r` with every element of `C`
represented by a word in `B(r)`. Take `n` with `ker φ_n ∩ B(3r) = N_∞ ∩ B(3r)`. Define
`ι(wN_∞) = φ_n(w)` for `w ∈ B(r)`.
- **Well defined and injective:** for `w, w' ∈ B(r)`, `w'^{-1}w ∈ N_∞` iff
  `w'^{-1}w ∈ ker φ_n`, since `|w'^{-1}w| <= 2r`.
- **Multiplicative:** if `wN_∞ · vN_∞ = uN_∞` with `u, v, w ∈ B(r)`, then `u^{-1}wv` has
  length `<= 3r` and lies in `N_∞`, hence in `ker φ_n`. So `ι(uN_∞) = ι(wN_∞)ι(vN_∞)`.

## (M2)

`R` is finite and `R ⊆ N`. For each `w ∈ R`, `w ∈ ker φ_n` for all large `n`, so
`R ⊆ ker φ_n` and `φ_n` factors through `Λ` for large `n`. Infinitely many of these kernels
are distinct because `|S_n|` is unbounded. So `X(Λ) = ∞`.

## (M3)

**Each S_n embeds in GL_(D^2).** Pass to a subsequence with `pdeg(S_n) <= D`; limits along
it are unchanged. Take `ψ_n: S_n -> PGL_(D_n)(F_n)` nontrivial, with `D_n <= D`.
1. `S_n` is simple, so `ψ_n` is injective.
2. `PGL_(D_n)(F_n)` acts on `M_(D_n)(F_n)` by conjugation. The kernel of `GL_(D_n)` on
   `M_(D_n)` is the center, the scalars, so `PGL_(D_n)(F_n) ↪ GL_(D_n^2)(F_n)`.
3. `g ↦ diag(g, I)` embeds `GL_(D_n^2)` in `GL_(D^2)`.

This gives injective `θ_n: S_n -> GL_(D^2)(F_n)`.

**Ultraproduct.** Let `U` be a non-principal ultrafilter on the index set and
`K = ∏ F_n / U`. `K` is a field: a class that is nonzero has coordinates nonzero on a set
in `U`, and inverting them there inverts the class.
- The map `∏ GL_(D^2)(F_n) -> GL_(D^2)(K)`, taking entries classwise, is a homomorphism,
  because matrix entries of products are polynomials.
- Its image is invertible: the determinant is nonzero `U`-almost everywhere.
- Its kernel is the set of sequences equal to `I` `U`-almost everywhere.

Put `Ψ(w) = [(θ_n φ_n(w))_n]`. Then `ker Ψ = {w : φ_n(w) = 1 for U-almost all n}`. For each
`w` the set `{n : w ∈ ker φ_n}` is cofinite or finite, and `U` contains every cofinite set
and no finite one. So `ker Ψ = N_∞`, and `G_∞ ≅ Ψ(F_m) <= GL_(D^2)(K)`. It is infinite by
(M1).

## (M4)

Fix `D`. If infinitely many simple quotients of `Λ` had `pdeg <= D`, apply (M1) to those
kernels and then (M3). The result is an infinite linear quotient, which contradicts the
hypothesis. So for each `D` only finitely many kernels have `pdeg <= D`, and any sequence
of distinct kernels has `pdeg(S_n) -> ∞`. Extract a convergent subsequence as in (M1).

## (M5)

**Forward.** Let `Λ` be non-elementary hyperbolic, and suppose no marking of `Λ` maps onto
an infinite marked limit of finite simple groups. By (M1), `X(Λ) < ∞`. So `Λ` has only
finitely many isomorphism types of finite simple quotients, and
`finite-simple-spectrum-gives-quotientless-hyperbolic-group` gives an infinite hyperbolic
group with no nontrivial finite quotient.

**Converse.** Let `Λ_0` be infinite hyperbolic with no nontrivial finite quotient.
- `Λ_0` is non-elementary. An infinite virtually cyclic group has a finite-index subgroup
  `Z`, is residually finite, and so has nontrivial finite quotients.
- Hyperbolic groups are finitely presented (standard). So (M2) applies to every marking:
  if `Λ_0` mapped onto a marked limit of finite simple groups of unbounded order, those
  groups would be finite quotients of `Λ_0`.
- Sequences of bounded order give no infinite limit. Only finitely many kernels have a
  quotient of order `<= M`. A convergent sequence taking finitely many values is eventually
  constant, since two values occurring infinitely often would differ at some word. So its
  limit is a kernel of finite index.

Let `R` be unital with a properly infinite unit and let `m >= 2`.  Choose
`S_1,...,S_m,T_1,...,T_m` with `T_iS_j = delta_(ij)1`, available from
binary words of a common length in the two copies.  With
`p = sum_i S_iT_i`,

```text
jmath(A) = 1 - p + sum_(i,j) S_i A_(ij) T_j
```

is an injective group homomorphism `GL_m(R) -> R^x`, and
`Psi(A) = diag(jmath(A),1)` restricts to an injective homomorphism

```text
Psi : EL_m(R) --> EL_2(R).
```

The normal closure of `Psi(EL_m(R))` in `EL_2(R)` is `EL_2(R)`; already the
single element `Psi(e_12(1))` normally generates it.

**Rank-descent principle.**  For any class `C` of groups: if every
homomorphism from `EL_m(R)` to a group in `C` is trivial for one `m >= 2`,
then the same holds for `EL_n(R)` for every `n >= 2`.

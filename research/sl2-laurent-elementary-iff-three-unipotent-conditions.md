Notation: `R = Z[t,t^{-1}]`, `G = SL_2(R)`, `E_2(R)` generated by the elementary
matrices, `U_2(R)` generated by all unipotent matrices `I + N` (`N` nilpotent). For
`v = (p,-q)^T ∈ R^2` put `J = [[0,-1],[1,0]]` and

`C(p,q) = I + v (Jv)^T = [[1+pq, p^2],[-q^2, 1-pq]]` (the Cohn matrix of `(p,q)`).

Call `(p,q)` *primitive* if `p, q` have no common non-unit divisor in `R`, and
*unimodular* if `pR + qR = R`. Consider:

- **(N)** `E_2(R)` is a normal subgroup of `G`.
- **(C)** `C(p,q) ∈ E_2(R)` for every primitive, non-unimodular pair `(p,q)`.
- **(U)** `SL_2(Z[t]) ⊂ U_2(R)`.

Then:

1. `G = E_2(R)` if and only if (N), (C) and (U) all hold.
2. (N) holds if and only if `C(p,q) ∈ E_2(R)` for every unimodular `(p,q)`, if and
   only if every `G`-conjugate of `E_12(1)` is elementary.
3. `U_2(R) = E_2(R)` if and only if (N) and (C) hold, if and only if `C(p,q) ∈ E_2(R)`
   for every primitive `(p,q)`.
4. (U) holds if and only if `G = U_2(R)`.
5. For `Y ∈ E_2(R)`, `C(Yv) = Y C(v) Y^{-1}`, so (C) needs one Cohn matrix per
   `E_2(R)`-orbit of primitive non-unimodular vectors. In particular `C(n,f)` depends,
   up to elementary conjugation, only on `f mod n`.

So the open problem `sl2-laurent-integers-equals-elementary-subgroup` splits into three
conditions of different kinds:

- (N) asks whether `E_2` of this two-dimensional ring is normal (for `E_n`, `n ≥ 3`,
  normality holds over every commutative ring by Suslin's theorem, which does not
  apply here);
- (C) is exactly where the classical non-elementary matrices live. Cohn's
  `[[1+2t,4],[-t^2,1-2t]] = C(2,t)` over `Z[t]` and `C(x,y)` over `k[x,y]` are Cohn
  matrices at primitive non-unimodular vectors;
- (U) is exactly where the Grunewald–Mennicke–Vaserstein free quotients
  (`gmv-sl2-zx-mod-unipotents-has-free-quotients`) would survive; it fails if
  `polynomial-unipotent-subgroup-fricke-compatible` holds.

Over `R` Cohn's `C(2,t)` moves from type (C) to type (N), because `t` is a unit.

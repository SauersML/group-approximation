**Step 1: `K[P]` has only trivial idempotents for a finite `p`-group `P`.**

We show the augmentation ideal `omega(P)` is nilpotent, by induction on `|P|`.
- If `P = 1`, then `omega = 0`.
- Otherwise `P` has a central element `z` of order `p`.
  - In characteristic `p`, `(z - 1)^p = z^p - 1 = 0`.
  - `z - 1` is central, so the ideal `I = (z - 1)K[P]` satisfies `I^p = 0`.
  - The kernel of `K[P] -> K[P/<z>]` is `omega(<z>)K[P] = I`, since
    `omega(<z>)` is generated by `z - 1` as an ideal of `K[<z>]`.
  - By induction `omega(P/<z>)^m = 0` for some `m`. So `omega(P)^m ⊆ I`, and
    `omega(P)^(mp) = 0`.

Let `e` be idempotent with augmentation `eps(e)`. Then `eps(e)^2 = eps(e)`, so
`eps(e)` is `0` or `1`.
- If `eps(e) = 0`, then `e` lies in `omega(P)`, and `e = e^(mp) = 0`.
- If `eps(e) = 1`, apply the same to `1 - e`.

**Step 2: residual separation of finite sets.** Let `S` be finite. For each of
the finitely many `g = s^(-1)s'` with `s != s'` in `S`, choose `N_g` normal
with `G/N_g` a finite `p`-group and `g` not in `N_g`. Let `N` be the
intersection of these `N_g`. Then:
- `N` is normal;
- `G/N` embeds in the product of the `G/N_g`, so it is a finite `p`-group;
- `S -> G/N` is injective.

**Step 3.** By Step 1, every finite `p`-group lies in `C_K`. By Step 2, `G` is
fully residually in `C_K`. `fully-residual-limits-preserve-trivial-idempotents`
then gives the claim.

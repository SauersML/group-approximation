**Setting.**
- `F` is a finite field and `J = J_F = F<S,T | TS = 1>`, acting faithfully on `F[N]` by `S e_k = e_(k+1)`, `T e_(k+1) = e_k`
  and `T e_0 = 0`. Put `Q = 1 - ST` and `A = F[z, z^(-1)]`.
- `m >= 2` and `E_m = EL_m(J)`. The symbol is `π : E_m -> SL_m(A)`, with `S -> z` and `T -> z^(-1)`.
- `L_m = ker π` consists of finitary invertible maps of `V = F[N x {1..m}] = F[N]^m`, and contains the group
  `SL_fin(V)` generated by the finitary transvections. For `F = F_2` it equals `GL_fin(V)`.

Put `H_+ = π^(-1) SL_m(F[z])` and `H_- = π^(-1) SL_m(F[z^(-1)])`.

**Theorem.**
1. `H_+ = L_m ⋊ EL_m(F[S])`, and `π` maps `EL_m(F[S])` isomorphically onto `SL_m(F[z])`.
2. For every finitely generated `Y <= H_+` there is a `k_0` such that `Y` preserves every subspace
   `V_(>=k) = span{e_j ⊗ ε_i : j >= k}` with `k >= k_0`. The induced maps `Y -> GL(V / V_(>=k))`, `k >= k_0`, into
   finite groups separate the points of `Y`. So every finitely generated subgroup of `H_+` is residually finite.
3. So `H_+` is LEF and sofic. Every element of `L_m`, in particular the head `x_13(Q)` for `m >= 3`, survives in
   finite quotients of every finitely generated subgroup of `H_+` that contains it.
4. The transpose-inverse twist `g -> (σ(g)^t)^(-1)` is an automorphism of `E_m` that exchanges `H_+` and `H_-`. Here
   `σ` is the anti-involution of `J` with `S <-> T`. So 1--3 hold for `H_-`.

**Consequence.** For every `n >= 3`, both factors of the decomposition (BC4)
`EL_(2n)(J) = <H_+, rho(H_bi(n))>` of `laurent-finitary-el-is-kazhdan-lef-inside-doubled-jacobson` are LEF. This answers
part (a) of bus need `c4fb8c8f` (w13-nh-last1).

**Contrast.** Every finite quotient of `H_+` kills `SL_fin(V)`, because that group is simple and infinite. So the
residual finiteness in point 2 is local only, and `H_+` is not residually finite. The theorem says nothing about the
mixed group `E_m`, which for `F = F_2` and `m >= 4` is not LEF (`cohn-elementary-group-is-not-lef`, as used in
`laurent-finitary-el-is-kazhdan-lef-inside-doubled-jacobson`).

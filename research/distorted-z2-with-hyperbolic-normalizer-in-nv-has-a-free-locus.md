**Setting.** `X = C^n`, `C = {0,1}^ω`. Let `H = ⟨x_1, x_2⟩ ≅ Z^2` be a subgroup of `nV`, and write
`x^v = x_1^{v_1} x_2^{v_2}`. Let `N ≤ nV` be a subgroup normalizing `H`, with twisting image
`Γ = {M_g : g ∈ N} ≤ GL_2(Z)`, where `g x^v g^{-1} = x^{M_g v}`. Put `E = HN`,
`Fix(h) = {z : hz = z}`, and `S(z) = {v ∈ Z^2 : x^v z = z}`.

**Theorem.**
- **(F1) Distortion.** If `Γ` contains a hyperbolic matrix, then every `x^v`, `v ≠ 0`, is
  drift-free.
- **(F2) Clopen fixed sets.** Let every `x^v` be drift-free, which is automatic under (F1). Then:
  - every periodic point of every `x^v` has zero offset;
  - `Fix(x^v)` is clopen for every `v`;
  - `z ↦ S(z)` is lower semicontinuous: each `z` has a neighbourhood `U` with `S(z') ⊇ S(z)` for all
    `z' ∈ U`.
- **(F3) Free locus.** Suppose `Γ` contains a hyperbolic matrix. Put
  `W = X \ ⋃_{v≠0} Fix(x^v)`, the set where `H` acts freely. Then `W` is **nonempty**, closed and
  `E`-invariant. More precisely, let `K` be the set of points whose `H`-orbit is infinite. Then `K`
  is nonempty, closed and `E`-invariant, and `W` is a nonempty closed subset of `K`. The map
  `z ↦ Q·S(z)` is locally constant on the open subset `K \ W` of `K`, with values rational lines.
- **(F4) Measures (Sol case).** Suppose `E` is amenable, for example `E` is a Sol lattice
  `Z^2 ⋊_A Z` with `A` hyperbolic. Then every `E`-invariant Borel probability measure gives zero
  mass to the set of points with rank-one stabilizer. It is carried by `W` together with the
  finite-orbit points, where the stabilizers are lattices with finite `Γ`-orbit. Some
  `E`-invariant probability measure is carried by `W`.

**Consequences.**
- **Gate.** A hyperbolic Sol lattice `Z^2 ⋊_A Z`, a Burger pair `Z^2 ⋊ Γ` with `Γ ≤ GL_2(Z)`
  non-amenable (so `Γ` contains a hyperbolic matrix), and the root subgroup
  `⟨e_13, e_23⟩ ⊲ Z^2 ⋊ SL_2(Z) ≤ SL_3(Z)` all satisfy the hypotheses of (F1)–(F3). So in any
  embedding of any of them into any `nV`, the base `Z^2` has clopen fixed sets and a nonempty closed
  invariant free locus `W`, on which every `x^v` is aperiodic and drift-free.
- **Class killed: locally non-free bases.** Call `H` *locally non-free* if
  `X = ⋃_{v≠0} Fix(x^v)`, i.e. every point is fixed by some nonzero element. No locally non-free
  `Z^2 ≤ nV` carries a hyperbolic twisting element of `nV`. So no locally non-free base extends to a
  Sol lattice, a Burger pair or a copy of `GL_3(Z)`, in any `nV`. The class includes:
  - every `Z^2 = ⟨x, y⟩` built from **disjoint supports**, `{xz ≠ z} ∩ {yz ≠ z} = ∅`, the standard
    way of making commuting pairs in Thompson-like groups;
  - more generally, every `Z^2` generated by elements `x, y` with `Fix(x) ∪ Fix(y) = X`, or with
    `⋃_{j} Fix(x^{v_j}) = X` for finitely many nonzero `v_j`: for example, bases assembled piecewise
    from rigid stabilizers of the pieces of a finite clopen cover.
  - **Invariant:** the stabilizer map `z ↦ S(z)`.
  - **Where every member dies:** at (F3). The line map `z ↦ Q·S(z)` is locally constant on the
    compact set `K`, so it has finite image, and this finite set of rational lines is invariant
    under the twisting matrices. A hyperbolic matrix has no power fixing a rational line.
- This answers the open step left by `brin-thompson-2v-is-not-a-t-menable`, Attempt
  2026-09-19, in part. That attempt proposed constructions "built from supports or germs rather than
  from a completion". Every such construction must still leave a nonempty closed set on which the
  base acts freely.

**Forced shape of a survivor**, combining this with the coordinate-shadow theorem. The base `Z^2` of
any Sol lattice, Burger pair or `GL_3(Z)` in `nV` must meet all of the following:
- it is coordinate-mixing: every `D_J` is empty or infinite
  (`coordinate-shadows-rigidify-abelian-normalizers-in-nv`);
- it is drift-free in every direction, and every periodic point has zero offset;
- it has clopen fixed sets and a nonempty closed invariant set `W` where it acts freely;
- in the Sol case, `W` carries an invariant probability measure and no invariant measure charges
  rank-one stabilizers.

**Calibration.**
- In `V` (`n = 1`), (F1) and the undistortion of cyclic subgroups of `V` already exclude every such
  normalizer.
- The block-split products of SMART odometers (`monomial-renormalization-compiler-gives-dilation-groups-in-nv`)
  are distorted in every direction, hence drift-free, so they satisfy (F2). They die at the shadow
  invariant (S6), not at (F3).
- Conversely, the shadow invariant says nothing when `n = 1` or when the base is coordinate-mixing,
  while (F3) makes no reference to coordinates. A coordinate-mixing, locally non-free base, for
  example one built from disjoint supports inside a single brick, passes the shadow test and dies
  at (F3).

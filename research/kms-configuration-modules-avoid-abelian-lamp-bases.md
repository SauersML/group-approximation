**ESTABLISHED** by `kms-lamp-base-obstruction-proof`, not independently
reviewed. No priority is claimed.

**Setting.** `MM_k` is a Minsky machine with `k >= 1` glasses and commands
numbered `0, ..., N`, and `G = G(MM_k)` is the group of Kharlampovich--Myasnikov--Sapir,
*Algorithmically complex residually finite groups*, Bull. Math. Sci. 7 (2017),
§4.1. It is generated by the configuration letters `x(u)`, the `A`-letters and
the `a`-letters `a_i, a'_i, ã_i, ã'_i`.

**Statement.** Let `B` be an abelian group, `Q` a group acting on a set
`Omega`, and `iota : G -> B^(Omega) x| Q` an injective homomorphism into the
restricted permutational wreath product. Then `iota(x(q_j))` does not lie in the
base `B^(Omega)`, for every command `j = 0, ..., N`.

**Meaning.** The hard module of `G` is the normal subgroup `T` generated by the
`x(u)`, elementary abelian of exponent `p` (KMS Lemma 4.5). No embedding into an
abelian-lamp wreath product puts `T` into the lamps. Whatever part of `T` meets
the base misses every `x(q_j)`. For the Boone--Higman problem of
`fp-rf-apapa-groups-satisfy-boone-higman`, this rules out the route "`M` into a
type (A) actor `Gamma`, `T` into finite abelian lamps", which would otherwise
follow from `bh-type-a-class-closed-under-permutational-lamp-wreaths`.

**Scope.** Only abelian lamp groups and only the base placement. Nonabelian
finite lamps, and embeddings in which the configuration letters act through the
top group or through germs, are not covered.

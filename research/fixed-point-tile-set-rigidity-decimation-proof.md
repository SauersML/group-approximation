Notation is as in the target: ℓ¹ norm `|·|`, balls `B_D`, `R(D) = N(2D+2) − 2`. "Commute" means that all projections at
the two sites commute.

**(B)** For `x, y ∈ Z^2` and `s ∈ Z^2`, `|⌊(x−s)/M⌋ − ⌊(y−s)/M⌋| <= |x − y|/M + 2`. Each coordinate contributes at most
`|x_i − y_i|/M + 1`.

## Step 0. Mismatched dominoes vanish

Let `E` be a local `D`-family with `D >= 1`, and let `(a, b)` be horizontally mismatched. Then
`E_a(z) E_b(z+e_1) = 0`.
- Insert `Σ_c E_c(w) = I` at every other site `w` of `B_D(z)`. All factors commute by (Q2), since the ball has
  diameter `2D`.
- Each resulting pattern on `B_D(z)` contains the mismatched domino, so it vanishes by (Q3_loc).

The vertical case is the same. Consequently, if the sites of a finite set `S` pairwise commute, the product over `S`
of any pattern containing a mismatched domino vanishes: reorder so that the domino's two factors are adjacent.

## Step 1. Phases are central

Put `P_z^p = Σ_(κ(a) = p) E_a(z)`. This is a partition of unity at each `z`.

- By (H1), `κ(b) ≠ κ(a) + e_1` forces `(a, b)` to be mismatched. So `P_z^p P_(z+e_1)^q = 0` unless `q = p + e_1`, by
  Step 0.
- Hence `P_z^p = P_z^p Σ_q P_(z+e_1)^q = P_z^p P_(z+e_1)^(p+e_1)`.
- Also `P_(z+e_1)^(p+e_1) = Σ_(p') P_z^(p') P_(z+e_1)^(p+e_1) = P_z^p P_(z+e_1)^(p+e_1)`.
- So `P_z^p = P_(z+e_1)^(p+e_1)`, and likewise for `e_2`.

Therefore `Q_t := P_z^((z−t) mod N)` does not depend on `z`.
- The `Q_t` are orthogonal idempotents with sum `I`.
- `Q_t` lies in the algebra generated by the `E(z)` at any single site `z`, so it commutes with every `E(w)`: choose
  `z = w`. So `Q_t` is central in `alg(E)`, and `W_t := Q_t W` is invariant under all `E`.

## Step 2. Block products form a local D-family

Assume the commutation in `H(D)`. Fix `t`, work on `W_t`, and put `β(Z) = NZ + t + [0,N)^2`.
- **Blocks commute internally.** Sites of `β(Z)` lie within distance `2N − 2 <= R(D)` of each other, so they commute,
  and `M_c(Z)` is an idempotent.
- **Orthogonality.** For `c ≠ c'`, (H2) gives `u` with `σ(c)_u ≠ σ(c')_u`. Then `M_c(Z) M_(c')(Z)` contains the factor
  `E_(σ(c)_u)(z) E_(σ(c')_u)(z) = 0`.
- **Partition of unity.** Expand `Π_u Σ_a E_a(NZ+t+u) = I` into block patterns `p`.
  - On `W_t` we have `Q_t = P_(NZ+t+u)^u`, so `E_a(NZ+t+u) = 0` unless `κ(a) = u`.
  - Patterns with a mismatched domino vanish by Step 0.
  - The remaining patterns are the `σ(c)`, by (H3). So `Σ_c M_c(Z) = I` on `W_t`.
- **Recovery.** For `z = NZ + t + u`:
  `E_a(z) = E_a(z) Σ_c M_c(Z) = Σ_c [σ(c)_u = a] M_c(Z)`.
  This uses that `E_a(z)` commutes with `M_c(Z)` and that `E_a(z) E_(σ(c)_u)(z) = δ E_a(z)`.
- **(Q2) at macro scale `D`.** If `|Z − Z'| <= 2D`, sites of `β(Z)` and `β(Z')` lie within `2DN + 2(N−1) = R(D)`. So
  `M(Z)` and `M(Z')` commute.
- **(Q3_loc) at macro scale `D`.** Let `q` be a pattern on `B_D(Z_0)` with a mismatched macro domino, say `c` at `Z` and
  `c'` at `Z + e_1`.
  - The `M`'s in the ball pairwise commute by the previous item. Reorder so that `M_c(Z) M_(c')(Z+e_1)` is a factor.
  - That factor is a product of `E`'s over `β(Z) ∪ β(Z+e_1)`, whose sites are within `3N − 2 <= R(D)` of each other.
    Its pattern `σ(c)σ(c')` contains a mismatched domino by (H4), so it vanishes by Step 0.
  - The vertical case is the same.

So `(M_c(Z))` on `W_t` is a local `D`-family for `τ`, and item 1 of the target is proved.

## Step 3. Iteration (item 2)

Assume `H(D)` with `D >= 2`, and let `E` be a local `D`-family.
- **Level 1.** Steps 1–2 give, on each `W_(t_1)`, a local `D`-family `M^(1)`.
  - `H(D)` quantifies over all local `D`-families, so `M^(1)` satisfies its commutation, and Steps 1–2 apply again.
  - Recovery shows `alg(M^(1)) = alg(E)|W_(t_1)`. So the level-2 phases are central in `alg(E)|W_(t_1)`.
- **Level `k`.** After `k` steps, `W = ⊕ W_(t_1…t_k)` is a decomposition into summands invariant under all `E`.
  - On each summand, `E_a(z)` lies in the span of the `M^(k)_c(Z_k(z))` at the single macro site
    `Z_k(z) = ⌊(z − s_k)/N^k⌋`, where `s_k = t_1 + N t_2 + … + N^(k−1) t_k`.
  - This uses the nested-floor identity `⌊(⌊x/N⌋ − t)/N⌋ = ⌊(x − Nt)/N^2⌋` on integers.
- **Conclusion.** Given `z, w`, choose `k` with `N^k >= |z − w|`. By (B), `|Z_k(z) − Z_k(w)| <= 3 <= 2D`.
  - So `M^(k)(Z_k(z))` and `M^(k)(Z_k(w))` commute by (Q2).
  - Hence `E(z)` and `E(w)` commute on every summand, and therefore on `W`.
- **Consequences.** A (Q3)-family in the sense of `sft-crossed-product-fp-iff-quantum-rigid` is a local family, since
  a pattern containing a mismatched domino does not occur in `Ω_τ`. So `Ω_τ` is `D`-quantum rigid, and finite
  presentation follows from that node (`D >= 1 = r`). ∎

## Step 4. Converse (item 3) and semi-decidability (item 4)

**Converse.** Suppose `Ω_τ` is `D'`-quantum rigid.
- By compactness (König), there is `D'' >= D'` such that a pattern on `B_(D')` that extends to a mismatch-free pattern on
  `B_(D'')` occurs in `Ω_τ`.
- Let `D >= D''` and let `E` be a local `D`-family, and let `p` be a pattern on `B_(D')` that does not occur in `Ω_τ`.
  - Insert partitions of unity on `B_D`; the sites commute by (Q2).
  - This writes the product of `p` as a sum over extensions to `B_D`. Each extension contains a mismatched domino
    inside `B_(D'')`, so it vanishes by (Q3_loc).
- So `E` is a `D'`-family in the (Q3) sense, and it commutes. Hence `H(D)` holds.

**Semi-decidability.** Let `U_D` be the free `k`-algebra on symbols `e_a(z)`, modulo the two-sided ideal `I_D`
generated by the (Q1), (Q2), (Q3_loc) relations. This is an explicit recursive list.
- Local `D`-families are exactly the `U_D`-modules, and `U_D` acting on itself is one of them.
- So `H(D)` holds iff `[e_a(z), e_b(w)] ∈ I_D` for all `|z − w| <= R(D)`.
- Translation of indices is an automorphism of `U_D` that preserves `I_D`, so only `z = 0` and `|v| <= R(D)` need to be
  checked.
- Ideal membership with an r.e. generating set is Σ⁰₁ (a finite linear combination of generators exhibits it).
- Items 2 and 3 then give: `Ω_τ` is rigid iff there exist `D >= 2` and finitely many such derivations. ∎

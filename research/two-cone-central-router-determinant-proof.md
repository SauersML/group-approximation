## Direct proof

From `xy=c^e` one has

```text
y = x^(-1)c^e.
```

Since `c` is central, the group is therefore generated by the commuting pair
`x,c`, so it is abelian.  In additive notation for the free abelian group on
`(x,c)`, the relation `x^m=c^a` is

```text
m x - a c = 0,
```

while `y^n=c^b` becomes

```text
n(e c-x)-b c = 0,
```

or, after multiplying by `-1`,

```text
n x + (b-ne)c = 0.
```

Thus `R(m,n;e,a,b)` is the cokernel of

```text
M = [ m   -a   ]
    [ n   b-ne ].
```

The first Smith divisor of a `2 x 2` integer matrix is the gcd of all its
entries.  It divides both `m` and `n`, hence is one because `gcd(m,n)=1`.
Also

```text
det(M) = m(b-ne)+an
       = -(mne-na-mb)
       = -D.
```

If `D != 0`, the matrix has rank two, its Smith form is
`diag(1,|D|)`, and the cokernel is `Z/|D|Z`.  If `D=0`, the matrix has rank
one: it is not the zero matrix because `m>=2`, and with first Smith divisor
one its Smith form is `diag(1,0)`, so the cokernel is infinite cyclic.

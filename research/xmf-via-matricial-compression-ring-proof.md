## Why sufficient

Take `(R, psi, R_0, z)` satisfying (R1)–(R5) of `matricial-compression-ring-exists`.

**The groups.**
- `Q = EL_4(R)`, the group generated by the elementary matrices `e_ij(r)`
  for `i != j` and `r in R`.
- `psi` acts entrywise on `GL_4(R)`, and `psi(e_ij(r)) = e_ij(psi r)`, so it
  restricts to an automorphism of `Q`.
- `G = Q semidirectProduct_psi Z`, with `t` a generator of `Z` and
  `t q t^(-1) = psi(q)`.  `G` is countable because `R` is finitely generated.

**Step 1: Q is Kazhdan, LEF, MF and nontrivial.**
- `Q` is Kazhdan by `elementary-groups-over-fg-rings-have-property-t`, since
  `R` is finitely generated and `n = 4 >= 3`.
- By (R1) and `exactly-matricial-rings-have-lef-general-linear-groups`, `GL_4(R)`
  is LEF, so its subgroup `Q` is LEF and hence MF.
- `R != 0`, so `e_12(1) != 1` and `Q` is nontrivial.

**Step 2: the compression core.**  Put `Gamma = EL_3(R_0)`, which is Kazhdan
by the same import because `R_0` is finitely generated.  Let
`iota : Gamma -> G` be the upper-left `3 x 3` block inclusion into `Q x {0}`.
1. *Compression.*  For each generator,
   `t iota(e_ij(r)) t^(-1) = iota(e_ij(psi r))`, and `psi r in R_0` by (R3).
   So `t iota(gamma) t^(-1) in iota(Gamma)` for every `gamma`.  This is the
   field `compresses` of `KazhdanCompressionCore`.
2. *The root.*  Put `c = diag(z, z, z, z^(-3))`.  By the Whitehead lemma,
   `diag(u, u^(-1))` lies in `E_2(R)` for every unit `u`, via
   `diag(u,u^(-1)) = e_12(u) e_21(-u^(-1)) e_12(u) e_12(-1) e_21(1) e_12(-1)`.
   Embed it in the coordinate pairs `(1,4)`, `(2,4)` and `(3,4)`.  The product
   is `c`, so `c in Q`.
3. *`c` centralizes the source.*  For `i, j <= 3` and `r in R_0`,
   `c e_ij(r) c^(-1) = e_ij(z r z^(-1)) = e_ij(r)` by (R4).  So `c`
   centralizes `iota(Gamma)`.  This is `comm_c`.

**Step 3: the defect normal subgroup contains Q.**  Put
`c' = t c t^(-1) = diag(psi z, psi z, psi z, psi z^(-3))`.  For `p in R_0`,

```text
[c', iota(e_12(p))] = c' e_12(p) c'^(-1) e_12(-p) = e_12( psi(z) p psi(z)^(-1) - p ).
```

Let `D` be the normal closure in `G` of all such commutators.  This is
`defectNormal`.  Put `A = { a in R : e_12(a) in D }`.
- `A` is an additive subgroup, since `e_12(a) e_12(b) = e_12(a+b)`, and it
  contains every `psi(z) p psi(z)^(-1) - p`.
- `D` is normal, so `[x, d] in D` for all `x in G` and `d in D`.  Use the
  commutator rule `[e_ij(x), e_jk(y)] = e_ik(xy)` for distinct `i, j, k`.
  For `a in A` and `r, s in R`:
  - `e_13(a) = [e_12(a), e_23(1)]` and `e_12(ar) = [e_13(a), e_32(r)]` lie in `D`;
  - `e_32(s a r) = [e_31(s), e_12(ar)]` lies in `D`;
  - `e_12(s a r) = [e_13(1), e_32(s a r)]` lies in `D`.
- Hence `A` is a two-sided ideal, so `A` contains the ideal `I` of (R5).
  By (R5), `A = R`.
- The same rules move `e_12(R)` to every `e_ij(R)`:
  - `e_1k(r) = [e_12(r), e_2k(1)]` for `k = 3, 4`;
  - `e_kj(r) = [e_k1(1), e_1j(r)]` for `k != 1, j`;
  - `e_k1(r) = [e_kj(r), e_j1(1)]` for `j != 1, k`.  So `D` contains every elementary matrix, and
  `Q x {0} <= D`.

**Step 4: the radical.**
- `Q x {0}` is a nontrivial normal Kazhdan subgroup of the countable group
  `G`, and it lies in `defectNormal`.  So `normal-kazhdan-defect-non-mf`
  (Lean: `GroupApproximation/Sofic/NormalKazhdanMFRadical.lean`) shows that
  every homomorphism from `G` into the unitary group of a norm matrix corona
  kills `Q`.  Thus `Q x {0} <= Rad_MF(G)`.
- Conversely, `G -> Z` composed with a faithful corona representation of `Z`
  (for instance, the diagonal unitaries `diag(e^(2 pi i k/n))`) has kernel
  `Q x {0}`.  So `Rad_MF(G) <= Q x {0}`.
- Hence `Rad_MF(G) = Q x {0}`.

**Step 5: no finite quotients.**  `Q` is finitely generated, by property (T).
By `mapping-torus-mf-radical-lies-in-finite-residual`,
`Q x {0} = Rad_MF(G) <= R_fin(Q) x {0}`.  So `R_fin(Q) = Q`: every finite
quotient of `Q` is trivial.

Steps 1, 4 and 5 give all clauses of `(XMF)` for `(Q, psi)`.

## Remarks

- Infinite outer order of `[psi]` is then automatic, by
  `finite-outer-order-mapping-torus-is-virtually-product`.  It is also visible
  directly: `psi(R_0)` is a proper subring of `R_0` (Attempt 2 of the ring node).
- For the flagship through the descent dichotomy (DX), one needs in addition a
  torsion-free sofic Kazhdan `K` with `K/Rad_MF(K) = EL_4(R)` and a lift of
  `psi`.  This does not conflict with `steinberg-images-die-in-torsion-free-groups`:
  that result forbids elementary *subgroups* of torsion-free groups, not
  elementary *quotients*.
- The recipe uses the ring only through (R1)–(R5), so it is insensitive to the
  choice `n = 4`.  Any `n >= 4` works with `c = diag(z, ..., z, z^(-(n-1)))`
  and `Gamma = EL_(n-1)(R_0)`.

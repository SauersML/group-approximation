**ESTABLISHED** by `large-window-table-group-presentation-proof`.

**Setting.**
- `G` is generated by a finite symmetric set `X` and has a finite presentation
  `<X | R>` whose relators have length at most `L`.
- `h` in `G` has finite order, and

      S = B_(r_s)(X),     M = <h> . B_(r_m)(X).

- `U` is the table group of the invariant-output window `(S, M, <h>)`. It has
  generators `x_a` for `a` in `S u M`, with `x_1 = 1`, and relators
  `x_s x_m = x_s' x_m'` whenever `sm = s'm'` in `G`, and `x_k x_m = x_(km)` for
  `k` in `<h>`, `m` in `M`.

**Theorem.** If `1 <= r_m <= r_s`, `|h|_X <= r_s` and `ceil(L/2) <= r_s`, then
`x_a -> a` is an isomorphism `U -> G`.

**Corollary (blind windows).** Suppose `G` has no nontrivial finite quotient
(for instance, `G` is infinite and simple) and `h != 1`. Take any window above
the threshold.
1. No homomorphism from `U` into a finite group sends `x_h` to a nontrivial
   element. So the character and permutation-image screen behind
   `small-leavitt-invariant-output-windows-have-finite-separations` cannot
   exclude the window, whatever its rules.
2. If `G` is simple, a realization of the window data with `x_h != 1` in a group
   `K` is an embedding `G -> K`. Corollary 3 of
   `strict-pairs-transfer-to-table-realizations` excludes pairs on such a window
   only through a surjunctive group containing `G`. Surjunctivity passes to
   subgroups, so such a `K` already makes `G` surjunctive.

**Scope.** The theorem applies to every finite generating set of Thompson's
group `V` (`thompson-v-finitely-presented-infinite-simple`), and to every other
finitely presented infinite simple group.
- A rule-free finite-image screen over such a group reaches only the finitely
  many radii below the threshold.
- Above the threshold, a candidate window is tested only at the level of its
  local rules.

The statement says nothing about which windows carry strict pairs.

Notation is as in the target. Cones are written `[w]`. `Q` is the set of proper nonempty clopen
subsets of `C`.

## Step 0. Cone partitions and constancy partitions

A cone partition is the set of leaf cones of a finite full binary tree `T`, which is a prefix-closed
set of words in which every internal node has both children. `I(T)` is the set of internal nodes, and
`T` has `|I(T)| + 1` leaves. Every word either is a node of `T` or has a leaf of `T` as a proper prefix.

For `f ∈ A`, the words `w` with `f` nonconstant on `[w]` are the internal nodes of a finite full
binary tree `T(f)`. This set is prefix-closed: if `f` is nonconstant on `[w0]` or on `[w1]`, it is
nonconstant on `[w]`. It is finite because `f` is locally constant.

`P(f)` denotes the leaf set of `T(f)`, the *constancy partition*. `P(f) = {C}` iff `f` is constant.

Two facts follow:
- If `f` is constant on the leaves of some full tree `T`, then `I(T(f)) ⊆ I(T)`, so `|P(f)| <= |I(T)| + 1`.
- `W ∈ P(f)` iff `f` is constant on `W` and either `W = C` or `f` is nonconstant on the parent of `W`.

## Step 1. Quasi-equivariance

**(L1)** Let `v ∈ V` be given by a tree pair with `k` leaves, `v(u_i s) = u'_i s`. Then
`|P(v·f) Δ vP(f)| <= 4k` for all `f`.

- Let `[w] ∈ P(f)` with `w = u_i s` and `s` nonempty.
  - `v[w] = [u'_i s]`, and `v·f` is constant there.
  - Its parent is `v[u_i s^-]`, where `s^-` is `s` without its last letter. `v·f` is nonconstant on
    that parent, because `f` is nonconstant on `[u_i s^-]`, the parent of `[w]`.
  - So `v[w] ∈ P(v·f)`.
- The remaining `w` are the internal nodes and the leaves of the domain tree, at most `2k` words.
  Hence `|vP(f) \ P(v·f)| <= 2k`.
- Apply the same bound to `v^(-1)` and `v·f`, then apply `v`. This gives `|P(v·f) \ vP(f)| <= 2k`.

**(L2)** Fix `a ∈ A`. Then `|P(f + a) Δ P(f)| <= 6|I(T(a))|` for all `f`.

- Let `[w] ∈ P(f)`, with neither `w` nor its parent in `I(T(a))`.
  - By Step 0, `a` is constant on `[w]` and on its parent.
  - So `f + a` is constant on `[w]` and nonconstant on the parent, and `[w] ∈ P(f + a)`.
- The excluded words number at most `3|I(T(a))|`: each internal node together with its two children.
- The reverse bound follows by symmetry, writing `f = (f + a) + (−a)` with `T(−a) = T(a)`.

## Step 2. V-submodules of A

**(L3)** Let `B ≤ A` be a `V`-invariant subgroup. Then either `B ⊆ Z·z` or `B ⊇ nA` for some `n >= 1`.

- Suppose `f ∈ B` is nonconstant. Choose disjoint cones `[u]`, `[u']`, not covering `C`, with `f = a` on
  `[u]`, `f = b` on `[u']`, and `δ = b − a ≠ 0`. Deep enough cones exist.
- Let `τ ∈ V` swap `[u]` and `[u']` by prefix replacement and fix the rest. Then
  `τ·f − f = δ(1_[u] − 1_[u'])`, which lies in `B`.
- `V` acts transitively on ordered triples of disjoint nonempty clopens covering `C`: refine each piece
  into the same number of cones as its target and map cone to cone. So `δ(1_U − 1_W) ∈ B` for all
  disjoint nonempty clopens `U, W` with `U ∪ W ≠ C`.
- `(1_[00] − 1_[10]) + (1_[01] − 1_[10]) − (1_[0] − 1_[10]) = −1_[10]`, and all three pairs are
  admissible. So `δ1_[10] ∈ B`.
- `V` is transitive on `Q`, so `δ1_U ∈ B` for every `U ∈ Q`. Then `δz = δ1_[0] + δ1_[1] ∈ B`, and
  `δA ⊆ B`.

**(L4)** `A` is generated by the elements `v·f − f`.
- This is Step 0 of `cantor-integer-maps-central-growth-criterion-proof`, repeated here.
- Modulo the subgroup these elements generate, all `1_U` with `U ∈ Q` are congruent.
- `1_[0] = 1_[00] + 1_[01]` then gives `1_[0] ≡ 0`, so `1_U ≡ 0` for every `U ∈ Q`, and `z ≡ 0`.

## Step 3. Item 1 (co-amenable subgroups onto V contain nA)

Let `p(H) = V` and `B = H ∩ A`.
- For `h ∈ H` with `p(h) = v` and `b ∈ B`, `hbh^(-1) = v·b` because `A` is abelian. So `B` is
  `V`-invariant.
- Suppose, for a contradiction, that `B ⊉ nA` for every `n`. By (L3), `B ⊆ Z·z`.

**Model of G/H.**
- `G = AH`: given `g`, pick `h ∈ H` with `p(h) = p(g)`, so `gh^(-1) ∈ A`.
- So `[f] ↦ fH` is a bijection `A/B → G/H`.
- `A` acts by translation.
- `v ∈ V` acts by `[f] ↦ [v·f + a_v]`, where `vH = a_vH` with `a_v ∈ A` fixed. This holds because
  `vf = (v·f)v`.

**The transfer.**
- Since `B ⊆ Z·z`, `P(f)` depends only on `[f]`. Put `D([f]) = P(f) \ {C} ⊆ Q`, a finite set.
- By (L1) and (L2), `|D(v[f]) Δ vD([f])| <= 4k_v + 6|I(T(a_v))|` for all `f`.
- `Q ≅ V/Stab_V([0])`, and `Stab_V([0])` contains `V_[0]` and `V_[1]` and is proper. So it lies in the
  family `𝓒` of `thompson-v-amenable-actions-are-free-off-fixed-points`. By item 5 of that claim,
  every point of a `V`-set with an invariant mean whose stabilizer is in `𝓒` is null. Hence `Q`
  carries no `V`-invariant mean.
- Theorem A of `thompson-v-finitary-structure-stabilizers-are-not-co-amenable`, applied to `V` acting
  on `G/H` with the restricted mean `m`, gives `N` with `m(E) > 0` for
  `E = {[f] : |P(f)| <= N + 1}`.

**Checkerboard translates.**
- Choose `d` with `2^d > 2N + 1`, and let `χ_d = Σ_(|w| = d−1) 1_[w0]`.
- `χ_d` is nonconstant on every `[w]` with `|w| < d`. So for every integer `j ≠ 0`,
  `|P(jχ_d)| = 2^d`.
- For `i = 1, ..., K` put `S_i = {[f] : [f + iχ_d] ∈ E}`, the translate of `E` by `−iχ_d`. Then
  `m(S_i) = m(E)`.
- Suppose `[f] ∈ S_i ∩ S_j` with `i ≠ j`.
  - `(i − j)χ_d = (f + iχ_d) − (f + jχ_d)` is constant on the leaves of the union of the trees
    `T(f + iχ_d)` and `T(f + jχ_d)`.
  - That union has at most `2N` internal nodes.
  - By Step 0, `2^d <= 2N + 1`, a contradiction.
- So the `S_i` are disjoint, `K·m(E) <= 1` for every `K`, and `m(E) = 0`. This contradicts the
  transfer.

Hence `B ⊇ nA` for some `n >= 1`.

## Step 4. Item 2

Let `z ∈ H`, and let the image of `z` in `H^ab` have infinite order. Let `K = p(H)`.

**K ≠ V.**
- Otherwise Step 3 gives `nA ⊆ B`.
- Let `ψ : H → H^ab`. By the first bullet of Step 3, `ψ(v·b) = ψ(b)` for `b ∈ B`.
- So `ψ(v·(nf) − nf) = 0` for all `f ∈ A`, since `nf ∈ B`.
- By (L4), `nz` is a sum of such elements. So `ψ(z)` has order dividing `n`, a contradiction.

**K is co-amenable.**
- `gH ↦ p(g)K` is a `G`-equivariant surjection `G/H → V/K`.
- Pushing the mean forward gives a `V`-invariant mean on `V/K`.
- `V/K` has no global fixed point, since `vK = K` for all `v` forces `K = V`.

This is item 1(a) of `thompson-v-amenable-actions-are-free-off-fixed-points`, i.e.
`thompson-v-has-a-fixed-point-free-amenable-action`.

**Special cases.**
- `V`, `Z·z × V` and twisted complements all map onto `V`.
- They meet `A` inside `Z·z`, so Step 3 excludes them.

## Why sufficient

Soundness is the method of `torsion-free-seeds-need-kernel-descent-or-trace-corner-proof`.
An assignment satisfying every rule instance and the input satisfies every
derived statement.  That route also shows the following for
`R = Rad_MF intersect P`, with `P` a normal-subgroup assignment:

- (F), (D) and (I) hold if they hold for `P`;
- (X) holds if the class `{P(H) = H}` has the same closure properties;
- (S) holds if `P` satisfies (F).

`Rad_MF` satisfies every rule, as recorded there.  Throughout, `V` is a
virtually torsion-free group.  Two elementary facts are used:

- **(v1)** A subgroup `U` of `V` is virtually torsion-free.  If `V_0 <= V` is
  torsion-free of finite index, then `U intersect V_0` is torsion-free of
  finite index in `U`.
- **(v2)** Finite products and finite wreath products `V^n x| Sym(n)` are
  virtually torsion-free, with `V_0^n` torsion-free of finite index.

`VT(H)` is an intersection of kernels, so it is normal.

## The rules for `VT`

1. **(F).**  Let `f : G -> H` and `psi : H -> V`.  Then `psi o f : G -> V`
   kills `VT(G)`, so `f(VT(G)) <= ker psi`.  Intersecting over `psi` gives
   `f(VT(G)) <= VT(H)`.
2. **(S).**  Let `d in VT(E)` with `f(d)` normally generating `Q`.  For
   `psi : Q -> V`, (F) gives `psi(f(d)) = 1`, so `psi` kills the normal
   closure `Q`.  Hence `VT(Q) = Q`.
3. **(X).**  `VT(H) = H` means every homomorphism from `H` to a virtually
   torsion-free group is trivial.
   - **Extensions.**  Let `1 -> A -> H -> C -> 1` with `VT(A) = A` and
     `VT(C) = C`, and let `psi : H -> V`.  `psi(A)` is virtually
     torsion-free by (v1), so `psi` restricted to `A` is trivial.  Then `psi`
     factors through `C`, so it is trivial.
   - **Directed colimits, free products and amalgams.**  The group is
     generated by the images of the constituents, and `psi` is trivial on
     each constituent by (v1).
   Combined with (X) for `Rad_MF`, the full class of `R` is closed.
4. **(D).**  Let `N <= VT(H)` be normal, with `pi : H -> H/N`.  Every
   `psi : H -> V` kills `N`, so it factors uniquely through `pi`.  So
   homomorphisms from `H` and from `H/N` to virtually torsion-free groups
   correspond, and `VT(H) = pi^-1(VT(H/N))`.  For `R` with `N <= R(H)`,
   intersect this with (D) for `Rad_MF`.
5. **(I).**  Let `E <= H` have finite index `n`.
   - **`VT(E) <= E intersect VT(H)`.**  This is (F) along the inclusion.
   - **`E intersect VT(H) <= VT(E)`.**  Fix `phi : E -> V` and induce it.
     Let `Y = (H x V)/~`, where `(he, v) ~ (h, phi(e) v)` for `e in E`.
     Write `[h, v]` for a class.
     - `H` acts on the left by `g[h, v] = [gh, v]`, and `V` acts on the right
       by `[h, v]w = [h, vw]`.  Both actions are well defined and they
       commute.
     - The right `V`-action is free.  If `[h, vw] = [h, v]`, then `h = he`
       forces `e = 1`, and then `w = 1`.
     - Its orbits are the sets `[h, V]`, indexed by `H/E`, so there are `n`
       of them.
     - The group of `V`-equivariant permutations of a free right `V`-set with
       `n` orbits is `V^n x| Sym(n)`.  Fix base points `y_i`.  An equivariant
       bijection is `y_i -> y_(pi(i)) a_i`, determined by `(a, pi)`.
     - This gives `Psi : H -> V^n x| Sym(n)`, and the target is virtually
       torsion-free by (v2).
     - `E` preserves the orbit `[1, V]`, and `e[1, v] = [e, v] = [1, phi(e) v]`.
       So `Psi(e) = 1` forces `phi(e) v = v` for all `v`, that is
       `phi(e) = 1`.
     - Hence `E intersect VT(H) <= E intersect ker Psi <= ker phi`.
       Intersecting over `phi` gives the claim.
   - **For `R`.**  With `corona-finite-index-radical-heredity`,
     `R(E) = (E intersect Rad_MF(H)) intersect (E intersect VT(H)) = E intersect R(H)`.

## The torsion rule, the input, and vanishing

6. **(C), and the first half of (c).**  Let `t in Rad_MF(H)` have finite
   order, and let `psi : H -> V`.
   - By `mf-radical-functoriality`, `psi(t) in Rad_MF(V)`.
   - By `virtually-torsion-free-mf-radical-is-torsion-free` (Part 2),
     `Rad_MF(V)` is torsion-free.
   - `psi(t)` has finite order, so `psi(t) = 1`.
   Hence `t in VT(H)`.  So every torsion-generated subgroup of `Rad_MF(H)`
   lies in `R(H)`.

   A (C)-instance has hypotheses that are either structural statements about
   `H` (a corner map, an absorber identity) or positive radical statements.
   The positive statements are `y in R(G)` or `R(G) = G`.  Since
   `R <= Rad_MF`, they transfer to `Rad_MF`.  So the instance gives
   `K <= Rad_MF(H)` with `K` torsion-generated, and hence `K <= R(H)`.
7. **(A).**  Let `G = St_20(L)`.  `G` has no nontrivial finite quotient, as
   shown in `torsion-free-seeds-need-kernel-descent-or-trace-corner-proof`,
   step (a)6, using `binary-leavitt-elementary-group-is-simple`.  Let
   `psi : G -> V` and `U = psi(G)`.
   - `U` is virtually torsion-free by (v1).  Let `C_0` be the normal core of
     a torsion-free finite-index subgroup of `U`.
   - `U/C_0` is a finite quotient of `G`, so it is trivial, and `U = C_0` is
     torsion-free.
   - `G` is generated by the `x_ij(r)`.  The Steinberg relation gives
     `x_ij(r)^2 = x_ij(2r) = x_ij(0) = 1`, since `L` is an `F_2`-algebra.
   - So `U` is generated by elements of order at most 2 in a torsion-free
     group, and `U = 1`.
   Hence `VT(G) = G` with no hypothesis.  `R(G) = G` holds exactly when
   `Rad_MF(G) = G`.
8. **(b) Vanishing.**  For `V` virtually torsion-free, `psi = id_V` gives
   `VT(V) = 1`, so `R(V) = 1`.
9. **Second half of (c).**  If `psi(x) != 1` for some `psi : H -> V`, then
   `x` is not in `VT(H)`, which contains `R(H)`.

## Consequences

1. **Soundness.**  Every statement derived from (F), (S), (X), (D), (I), (C)
   and (A) holds for `R`, by steps 1--7.  `R(T) = 1` for every virtually
   torsion-free `T`, by step 8.  So no such derivation gives
   `1 != x in Rad_MF(T)`.
   - This includes the swap wreath `(T_0 x T_0) x| Z/2` that breaks `Rad#`
     in the w12 route.  That group is virtually torsion-free, so `R` of it
     is `1`, which is consistent with (I).
   - The combined gate is therefore closed.
2. **A step outside the calculus certifies a non-MF virtually torsion-free
   group.**  Let a proof step be an instance whose hypotheses hold for `R`
   and whose conclusion `x in R(H)` fails for `R`, while it holds for
   `Rad_MF`, since the step is a theorem.
   - Then `x in Rad_MF(H)` but `x` is not in `VT(H)`.
   - So some `psi : H -> V` has `psi(x) != 1`.
   - By `mf-radical-functoriality`, `psi(x)` is a nontrivial element of
     `Rad_MF(V)`.  By `universal-mf-quotient`, `V` is not MF.
3. **The exits.**
   - Written as a rule, the descent `full-mf-radical-abelianized-cover-is-not-mf`
     reads: `R(G) = G != 1` implies `R(cover) != 1`.  With `G = St_20(L)`,
     the cover is torsion-free (`free-abelianized-cover-is-torsion-free`),
     so `R(cover) = 1`, and `R` violates the rule.
   - An analytic non-MF theorem for a torsion-free group is violated by
     step 8.
   - A no-CE corner on a finite subgroup is a (C)-instance, and `R`
     satisfies it by step 6.  So it is never an exit.

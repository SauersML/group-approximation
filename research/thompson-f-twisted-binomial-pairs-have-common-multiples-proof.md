Notation as in the target. `R = K[F]` has no zero divisors, because `F` is left-orderable
(derivation step 2 of `thompson-f-amenable-iff-group-ring-is-ore`). Group elements are units
of `R`. For a group `H` and a homomorphism `chi : H -> E^x` into the units of a field
`E ⊇ K`, the `E`-linear map `theta_chi : E[H] -> E[H]`, `h -> chi(h) h`, is a ring automorphism
with inverse `theta_(chi^-1)`, since `chi(h h') h h' = (chi(h) h)(chi(h') h')`.

**Item 3.** We prove more: if `A, B` are nonzero right ideals of a domain `R` with
`A + B = R`, then `A ∩ B ≠ 0`. The case `A = x R`, `B = y R` is item 3 for right ideals.
- Suppose `A ∩ B = 0`. Write `1 = e + f` with `e` in `A` and `f` in `B`.
- Pick `a ≠ 0` in `A`. Then `a = e a + f a`, with `e a` in `A` and `f a` in `B`, because both are
  right ideals. Also `a = a + 0`. Since `A ∩ B = 0`, the decomposition is unique, so `f a = 0`.
- In a domain this forces `f = 0`. Then `1 = e` lies in `A`, so `A = R`. Hence
  `B = A ∩ B = 0`, a contradiction.
- The left-ideal version is the same argument with `a = a e + a f`.
- Remark. This uses only that `R` has no zero divisors. An equivalent form: if the right ideals
  met trivially, `R = A ⊕ B` would split off a nontrivial idempotent.

**Restriction.** Let `H <= F` and `x, y` in `K[H]`. If `x R ∩ y R ≠ 0`, then
`x K[H] ∩ y K[H] ≠ 0`.
- Choose representatives `S` of the right cosets `H s`, so `R = ⊕_(s in S) K[H] s` as a left
  `K[H]`-module. This is Lemma A of `thompson-f-rescaled-x0-binomials-have-common-multiples-proof`.
- Write `x u = y v ≠ 0` with `u = sum_s u_s s` and `v = sum_s v_s s`, where `u_s, v_s` lie in
  `K[H]`. Comparing components gives `x u_s = y v_s` for every `s`, and some `x u_s ≠ 0`.

**Item 1, right multiples.** Fix `a, c ≠ 1` and `lambda, mu`. Put `x = 1 + lambda a` and
`y = 1 + mu c`, both nonzero. Let `H = <a, c>`.
- Let `Gamma` be the subgroup of `H × K^x` generated by `(a, -lambda)` and `(c, -mu)`. Its
  projection onto `H` is onto.
- *Case A: `Gamma ∩ ({1} × K^x) = {(1, 1)}`.* Then `Gamma` is the graph of a homomorphism
  `chi : H -> K^x` with `chi(a) = -lambda` and `chi(c) = -mu`.
  - Item 1 of `thompson-f-binomial-pairs-have-common-multiples` gives
    `(1 - a) R ∩ (1 - c) R ≠ 0`. By restriction, some nonzero `u, v` in `K[H]` have
    `(1 - a) u = (1 - c) v ≠ 0`.
  - Apply `theta_chi` on `K[H]`. Since `theta_chi(1 - a) = 1 + lambda a` and
    `theta_chi(1 - c) = 1 + mu c`, this gives `x theta_chi(u) = y theta_chi(v)`.
  - It is nonzero because `theta_chi` is injective. So `x R ∩ y R ≠ 0`.
- *Case B: some `(1, kappa)` in `Gamma` has `kappa ≠ 1`.*
  - Put `I = x R + y R`, a right ideal. Let `rho : Gamma -> R^x`, `(h, k) -> k h`, a group
    homomorphism. Then `rho(a, -lambda) - 1 = -x` and `rho(c, -mu) - 1 = -y` lie in `I`.
  - `Gamma_0 = {gamma : rho(gamma) - 1 ∈ I}` contains the generators and `1`. It is closed under
    products, since `rho(gamma delta) - 1 = (rho(gamma) - 1) rho(delta) + (rho(delta) - 1)`. It
    is closed under inverses, since `rho(gamma^-1) - 1 = -(rho(gamma) - 1) rho(gamma^-1)`. Both
    use that `I` is a right ideal. So `Gamma_0 = Gamma`.
  - Hence `kappa - 1 = rho(1, kappa) - 1` lies in `I`. It is a nonzero scalar, hence a unit, so
    `I = R`. Item 3 gives `x R ∩ y R ≠ 0`.

**Item 1, left multiples.** The `K`-linear map `*`, `h -> h^-1`, is an anti-automorphism of
`R`. It maps `z R` onto `R z*`.
- Apply the right statement to `a^-1, c^-1`, which are `≠ 1`, with the same `lambda, mu`. It
  gives `(1 + lambda a^-1) R ∩ (1 + mu c^-1) R ≠ 0`.
- Applying `*` gives `R (1 + lambda a) ∩ R (1 + mu c) ≠ 0`.

**Item 2.**
- *One term.* If `b = beta t`, then `b R = R`, and the intersection is `(1 + lambda g) R ≠ 0`.
- *Two terms.* Let `b = beta_1 t_1 + beta_2 t_2` with `t_1 ≠ t_2`, and put
  `c_i = t_i^-1 g t_i ≠ 1`. Item 1 gives a nonzero `v` in
  `(1 + lambda c_1) R ∩ (1 + lambda c_2) R`.
  - Since `t_i (1 + lambda c_i) = (1 + lambda g) t_i`, each `t_i v` lies in `(1 + lambda g) R`.
  - So `b v` lies there, and `b v ≠ 0` in a domain.
- *Equivalent form.* A two-term element is `alpha u + beta w = alpha (1 + (beta/alpha) w u^-1) u`
  with `w u^-1 ≠ 1`. Right unit factors do not change principal right ideals, and a one-term
  element is a unit.

**Item 4.**
- *Characters.* All of `F` fixes `0` and `1`, so the chain rule makes `e_0` and `e_1`
  homomorphisms `F -> Z`. Choose integers `p, q` with `p e_0(g) + q e_1(g) = d`. Then
  `chi(f) = gamma^(p e_0(f) + q e_1(f))` is a homomorphism `F -> L^x` with
  `chi(g) = gamma^d = -1/lambda`.
- *Twist.* `theta_chi` on `L[F]` sends `1 + lambda g` to `1 + lambda chi(g) g = 1 - g`. For
  nonzero `b` in `R`, `theta_chi(b) ≠ 0`. The hypothesis gives `y, v` in `L[F]` with
  `(1 - g) y = theta_chi(b) v ≠ 0`. Applying `theta_chi^-1` gives
  `(1 + lambda g) y' = b v' ≠ 0` with `y' = theta_chi^-1(y)` and `v' = theta_chi^-1(v)`.
- *Descent.* Fix a `K`-basis `(omega_j)` of `L`. Then `L[F] = ⊕_j omega_j R`, and the coordinate
  maps `pi_j : L[F] -> R` satisfy `pi_j(r s r') = r pi_j(s) r'` for `r, r'` in `R`, because the
  `omega_j` are central.
  - So `(1 + lambda g) pi_j(y') = b pi_j(v')` for every `j`.
  - Some `pi_j(v') ≠ 0`, because `v' ≠ 0`. Then `b pi_j(v') ≠ 0`, and it lies in
    `(1 + lambda g) R ∩ b R`.

**Trust surfaces.**
- Quoted: left-orderability of `F`, and hence that `K[F]` is a domain.
- Used: item 1 of `thompson-f-binomial-pairs-have-common-multiples`, only in Case A.
- Everything else is proved above.

**ESTABLISHED (proof in `sum-invariant-characters-of-contracting-groups-via-nucleus-proof`; unreviewed).**

Let `G <= Aut(X^*)` be self-similar with `X = {0, ..., d−1}`. Write `g(xw) = π_g(x) g|_x(w)`, so
`(gh)|_x = g|_{h(x)} h|_x`. A character `χ in Hom(G, Q)` is *sum-invariant* if `χ(g) = Σ_{x in X} χ(g|_x)` for
all `g`. By `rover-nekrashevych-characters-are-sum-invariant` these are exactly `Hom(V_d G, Q)`.

Suppose `G` is contracting, and let `N` be a finite set closed under sections with this property: every `g` has
`g|_v in N` for all `|v| >= L(g)`. For example, `N` can be the nucleus.

For `f in G` whose sections lie in `N` at every depth `>= L(f)`, and a function `I: N -> Q`, put

    χ_I(f) = Σ_{|v| = k} I(f|_v)        (k >= L(f)).

**Theorem.** A function `I: N -> Q` with `I(1) = 0` is the restriction of a sum-invariant character if and only if:

- **(i)** `I(n) = Σ_x I(n|_x)` for every `n in N`;
- **(ii)** `χ_I(n_1 n_2) = I(n_1) + I(n_2)` for all `n_1, n_2 in N`.

In that case the character is `χ_I`. Restriction to `N` is a linear isomorphism from the space of sum-invariant
characters onto the solution space of (i)–(ii).

**Effective version (contraction certificate).** Let `G` be generated by a finite automaton `S`. Let `N` be a finite
set of finite-state elements with these properties:

- `N` contains `1` and is closed under sections;
- `N` contains every state of `S` that lies on a cycle of the section graph;
- for all `n_1, n_2 in N`, every section of `n_1 n_2` lying on a cycle of the section graph of `n_1 n_2` is in `N`.

Then `G` is contracting, and `N` has the property above. Both the certificate and (i)–(ii) are finite exact
computations:

- equality of finite-state elements is decided by Moore minimization;
- `χ_I(n_1 n_2)` is evaluated by recursing through sections until they land in `N`.

So `dim Hom(V_d G, Q)` is computable for every contracting `G` given by a finite automaton.

**Implementation.** `experiments/contracting-polynomial-activity-2026-09-17/sumchar.py`, which uses the toolkit
`autgrp.py`, implements the certificate and the linear system over `Fraction`. Calibration:

| Binary odometer | 3 | 1 |
| Basilica | 7 | 1 |
| Grigorchuk group | 5 | 0 (generated by torsion) |

The binary odometer and the Grigorchuk group agree with `rover-nekrashevych-characters-are-sum-invariant`.

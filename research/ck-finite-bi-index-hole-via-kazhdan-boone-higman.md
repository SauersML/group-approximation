This route proves the free-core reading of the hole (see
`ck-finite-bi-index-hole-is-kazhdan-boone-higman`). Given `G`, a finitely
presented simple Kazhdan host `T` containing `G` is normally generated by
any nontrivial element of `G`. So `S = Gamma = T` satisfies every
conclusion of `chatterji-kassabov-normal-generator-embedding`, and
`|S \ Gamma / S| = 1`. The fixed-core reading is not proved by this route.

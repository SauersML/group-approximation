**Item 1 (MON2).** Write `H = <A, t | [t, C]>` and `H' = <A', t | [t, C']>`, both HNN
extensions with associated subgroups equal and identity isomorphism. The assignment
`a -> a`, `t -> t` respects the relators of `H` because `C subseteq C'`, so it defines a
homomorphism `phi : H -> H'`.

Let `h in H`, `h != 1`. Choose a Britton-reduced expression

```text
h = a_0 t^(e_1) a_1 t^(e_2) ... t^(e_k) a_k,     a_i in A,  e_i in Z - {0},
```

with no pinch: no `0 < i < k` with `a_i in C` (a letter of `C` between two `t`-powers
could be commuted past and the powers merged). Such an expression exists by Britton's
lemma in `H`.

- If `k = 0`, then `h = a_0 in A - {1}` and `phi(h) = a_0 != 1` in `A' subseteq H'`.
- If `k >= 1`, a pinch of the same word in `H'` would be an index `0 < i < k` with
  `a_i in C'`. Since `a_i in A`, this means `a_i in A cap C' = C`, which was excluded.
  So the image word is Britton-reduced in `H'` and contains `k >= 1` stable letters,
  hence `phi(h) != 1` by Britton's lemma in `H'`.

Thus `phi` is injective.

**Item 2 (MON3).** Take `A = A_(n,S)` embedded in `A' = A_(n',S')` by
`x -> diag(x, I_(n'-n))`, using `Z[1/S] subseteq Z[1/S']`, and `C' = C_(n')`. A block matrix
`diag(x, I)` has integer entries iff `x` does, and `det diag(x, I) = det x`. So
`A cap C' = {diag(x,I) : x in SL_n(Z)} = C_n`. Item 1 gives the embedding.

**Item 3.** A subgroup of a hyperlinear group is hyperlinear: restrict the trace-preserving
embedding of `L(G')` into `R^omega` to `L(G) subseteq L(G')`. A subgroup of a sofic group
is sofic: restrict the approximately multiplicative maps to the subgroup; the separation
condition only involves elements of the subgroup. Contrapositives give the upward transfer
of the negative properties.

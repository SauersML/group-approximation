`Gamma_0(2)/+-` is generated by `T=xy` and `w=xy^2xyx`.  In the vertex
conjugated by `diag(2,1)` these same two edge elements are `(x'y')^2` and
`x'y'x'y'^2x'`, respectively.  This gives `(SR1)`.

For the coordinate reformulation set `s=x'y'` and `e=x'`, so `y'=es`.
Then, using `e^2=1`,

```text
x'y'x'y'^2x'
 = e(es)e(es)^2e
 = s^2 e s e.
```

The four remaining equations are therefore

```text
s^2=T,        e^2=1,        (es)^3=1,        w=s^2ese.
```

Conversely these equations make `x'=e`, `y'=es` a modular pair and recover
both edge identifications.  No elimination of `e` is asserted: the false
one-cubic elimination in the earlier draft dropped a genuine mirror-word
constraint.

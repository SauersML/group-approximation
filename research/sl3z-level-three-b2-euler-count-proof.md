Write `Γ = Γ(3)` and `b_q = dim_Q H^q(Γ; Q)`.

## 1. Γ is a torsion-free congruence subgroup

`Γ` is a congruence subgroup by definition. It is torsion-free.
- Suppose `g ∈ Γ` has prime order `ℓ`. Write `g = I + 3^k A` with `k >= 1` and `A ∈ M_3(Z)`,
  `A ≢ 0 mod 3`.
- **Case `ℓ ≠ 3`.** Then `g^ℓ ≡ I + ℓ 3^k A (mod 3^(k+1))`. Since `3 ∤ ℓ`, this is `≢ I`.
- **Case `ℓ = 3`.** Expand
  `g^3 = I + 3^(k+1) A + 3^(2k+1) A^2 + 3^(3k) A^3`.
  - For `k >= 1` we have `2k+1 >= k+2` and `3k >= k+2`.
  - So `g^3 ≡ I + 3^(k+1) A (mod 3^(k+2))`, which is `≢ I`.
- Either way `g^ℓ ≠ I`, a contradiction.

## 2. Degree 0, degree 1, and degrees at least 4

- **Degree 0.** `b_0 = 1`.
- **Degree 1.** `SL_3(Z) = EL_3(Z)`, by Euclidean row reduction over `Z`.
  - By `elementary-groups-over-fg-rings-have-property-t` ("Consequences used in the graph"),
    every finite-index subgroup of `EL_3(Z)` has (T) and (FH), so `Γ` does.
  - A nonzero homomorphism `f : Γ -> R` would give a fixed-point-free isometric action
    `x ↦ x + f(γ)` on `R`, contradicting (FH).
  - Hence `H^1(Γ; Q) = Hom(Γ, Q) ⊆ Hom(Γ, R) = 0`, and `b_1 = 0`.
- **Degrees at least 4.** `b_q = 0` for `q >= 4`, by item 1 of
  `lee-szczarba-level-three-top-cohomology-is-steinberg` with `binom(3,2) = 3`.

## 3. Degree 3

`b_3 = 27`. This is the "case used in the graph" of
`lee-szczarba-level-three-top-cohomology-is-steinberg`, items 2--5 at `n = p = 3`:

```text
H^3(Γ; Q) ≅ (St_3(Q))_Γ ⊗ Q ≅ H~_1(T_3(Q)/Γ) ⊗ Q ≅ H~_1(T_3(F_3)) ⊗ Q ≅ Q^27.
```

The artifact recomputes the last step: `T_3(F_3)` is connected with 26 vertices and 52 edges,
so its `H_1` is `Z^(52-26+1) = Z^27`.

## 4. Degree 2

- **The Euler characteristic.** By §1, `harder-congruence-sln-z-euler-characteristic-vanishes`
  applies at `n = 3`, and gives `Σ_q (-1)^q b_q = 0` with every `b_q` finite.
- **Finiteness of `b_2`, independently.** `Γ` has finite index in the finitely presented
  group `SL_3(Z)`, so it is finitely presented. Hence `H_2(Γ; Z)` is finitely generated, and
  `b_2 = rank H_2(Γ; Z) < ∞`.
- **The count.** By §§2--3,

```text
0 = b_0 - b_1 + b_2 - b_3 = 1 - 0 + b_2 - 27,   so   b_2 = 26.
```

## 5. Integral forms

- **Rank.** `H_1(Γ; Z)` and `H_2(Γ; Z)` are finitely generated by §4. By universal
  coefficients, `H^2(Γ; Q) = Hom(H_2(Γ; Z), Q)`, so `H_2(Γ; Z)` has free rank 26.
- **Splitting.** Universal coefficients also give
  `H^2(Γ; Z) ≅ Hom(H_2(Γ; Z), Z) ⊕ Ext(H_1(Γ; Z), Z)`.
  - Here `Hom(H_2, Z) ≅ Z^26`, and the Ext term is finite.
- **Lattice.** The map `H^2(Γ; Z) -> H^2(Γ; R) = Hom(H_2(Γ; Z), R)` is the inclusion
  `Hom(H_2, Z) ⊂ Hom(H_2, R)` on the first summand and zero on the second. Its image is a full
  lattice.
- **Mod `n` classes.** The Bockstein sequence of `0 -> Z -> Z -> Z/n -> 0` gives an injection
  `H^2(Γ; Z)/n ↪ H^2(Γ; Z/n)`. The source contains `(Z/n)^26`.

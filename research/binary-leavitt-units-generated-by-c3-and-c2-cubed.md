**ESTABLISHED.**  Let `R = L_(F_2)(1,2)` with the usual generators
`s_0,s_1,t_0,t_1` (`t_i s_j = delta_(ij)`, `s_0t_0 + s_1t_1 = 1`), and let
`H = R^x`, identified with `EL_3(R)` by
`leavitt-gl-equals-el-and-perfect-unit-group`.  Put

```text
v = s_0 t_1 + s_1 t_0,
c = the coordinate 3-cycle (123) in EL_3(R),
b_1 = x_12(s_0),   b_2 = x_12(t_0),   b_3 = x_12(v).             (LG1)
```

Then

```text
v^2 = 1,      v s_0 = s_1,      t_0 v = t_1,                     (LG2)
```

so `s_0, t_0, v` generate `R` as a unital ring; `A = <c> = C_3`;
`B = <b_1,b_2,b_3> = C_2^3` has order exactly eight; and

```text
<A, B> = EL_3(R) = H.                                            (LG3)
```

In particular there is a surjection

```text
q : P = C_3 * C_2^3 -> H,                                        (LG4)
```

and `H` is generated by two finite abelian subgroups of orders `3` and `8`.

The independence that makes `|B| = 8` is grading, not computation: the
defining relations are homogeneous for `deg s_i = 1`, `deg t_i = -1`, so `R`
is `Z`-graded and `s_0, t_0, v` sit in the distinct degrees `1, -1, 0` and are
each nonzero (`t_0 s_0 = 1`, `v^2 = 1`).

This is a statement about generators only.  It asserts nothing about a finite
presentation of `H`, and the kernel of `(LG4)` is not claimed to be finitely
normally generated.

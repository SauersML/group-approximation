**ESTABLISHED** (proof route `locally-finite-hnn-regular-rank-model-proof`; artifact Sections 1–2).

Let `R = L_(F_2)(1,2)` and let `L <= R^x` be a countable locally finite subgroup. For a countable
set `U ⊆ R^x`, let `Lambda` be generated by `L` and letters `t_u` (`u` in `U`), subject to the
relations of `L` and `t_u k t_u^-1 = u k u^-1` for `k` in `L cap u^-1 L u`. Then:

1. **The model.** There is a homomorphism `sigma : Lambda -> M^x` into a rank ultraproduct over `F_2`
   with `rk(sigma(alpha)) = rank(lambda_Q(alpha))/|Q|` for every finite `Q <= L` and every `alpha` in
   `F_2[Q]`.
2. **Its properties.** `sigma` is nontrivial, it is fixed-point-free when `L` is infinite, and one can
   take `sigma(t_u) = sigma(u)` for `u` in `L`.
3. **Independent defects.** Let `A_1, ..., A_k` be pairwise disjoint proper cylinders whose unit root
   pairs `iota_(A_i)(x_12(1))`, `iota_(A_i)(x_23(1))` lie in `L`. Then:
   * `rk(N^A_12) = 1/2` and `rk(D_A) = 3/8`;
   * `rk(D_(A_1) ... D_(A_k)) = (3/8)^k`, so `theta = 1`.

**Consequence.** No argument for `leavitt-disjoint-cylinder-defects-strictly-submultiplicative` can use
only the following inputs:
* identities among elements of one locally finite subgroup;
* single conjugations `u g u^-1 = g'` by arbitrary units, including compressors, torus units and the
  `V`-conjugacies of disjoint cylinder configurations;
* rank calculus, nontriviality and fixed-point-freeness.

Such an argument must use something else:
* identities that multiply conjugating units;
* identities among elements generating a non-locally-finite group;
* a global input about all rank models of `R^x`: corner locality through the defect gap, globality
  through property (T), or compactness over models.

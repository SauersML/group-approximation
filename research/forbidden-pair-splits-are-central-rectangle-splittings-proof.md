Notation as in the target.  `M` acts on `H = L^2(M, tau)`, `N'` is the
commutant of `N` in `B(H)`, and `Z(N) = N ∩ N'`.  Write `e = P_q^a` and
`f = P_(q')^(a')`, so `fe = ef = 0`.

**(P0) Central supports.**
- For a projection `p` in a von Neumann algebra `R`, the projection onto
  `[R p H]` is the least central projection of `R` above `p`.  The space is
  invariant under `R` and under `R'`.  Call it `C_R(p)`.
- For `p in N`, `C(p) = C_N(p)` lies in `Z(N)`.
- For `m in N'`, `C_(N')(m)` lies in `Z(N') = Z(N)`.  If `x in N` and
  `xm = 0`, then `x u m = u x m = 0` for every `u in N'`, so
  `x C_(N')(m) = 0`.
- If `z in Z(N)` and `pz` is a projection of `Z(N)`, then
  `pz = C(pz) = C(p) z`.
- If `z in Z(N)` and `pz = 0`, then `C(p) <= 1 - z`, so `C(p) z = 0`.

**(P1) (CS) ⇔ (W).**
- `C(e)` projects onto `[N e H]`.  So `f C(e) = 0` iff `f x e = 0` for all
  `x in N`.
- By (P0), `f C(e) = 0` iff `C(f) C(e) = 0`.
- The span of words in `P_q, P_(q')` is weakly dense in `N`, and
  `x |-> f x e` is weakly continuous, so words suffice.  Using
  `sum_c P_q^c = 1`, words reduce to alternating ones.

**(P2) (CS) ⇒ (FS).**  Put `m = 1 - C(e)`.  It lies in `Z(N)`, so it commutes
with `P_q` and `P_(q')`.
- `e m = 0`, so `[e, P_(q')^b] m = e m P_(q')^b - P_(q')^b e m = 0`.
- `1 - m = C(e) <= 1 - C(f)`, so `f(1 - m) = 0`, and the same computation
  gives `[f, P_q^(b')] (1 - m) = 0`.

**(P3) (FS) ⇒ (CS).**  Let `m` be as in (FS).  Then `m in N' ∩ M`, since `N`
is generated by `P_q` and `P_(q')`.
- **Central pieces.**  Put `z = C_(N')(m)` and `z' = C_(N')(1-m)`, both in
  `Z(N)`.  By (P0), `[e, P_(q')^b] z = 0` for all `b`, and
  `[f, P_q^(b')] z' = 0` for all `b'`.
  - `ez` commutes with `P_q` (same PVM) and with `P_(q')`, so `ez in Z(N)`.
    Likewise `f z' in Z(N)`.
  - `z ∨ z' >= m ∨ (1-m) = 1`, so `1 - z <= z'`.
- **The overlap.**  Put `g = C(e) C(f) in Z(N)`.
- **On `gz`.**
  - `ez` is a central projection, so by (P0) `ez = C(e) z`.  Hence
    `e g z = g z`.
  - Then `f g z = f e g z = 0`, so `C(f) g z = 0` by (P0).
  - Since `g <= C(f)`, this gives `g z = 0`.
- **On `g(1-z)`.**
  - `f(1-z) = (f z')(1-z)` is a central projection, so `f(1-z) = C(f)(1-z)`
    and `f g (1-z) = g(1-z)`.
  - Then `e g (1-z) = e f g (1-z) = 0`, so `C(e) g (1-z) = 0`, and
    `g(1-z) = 0`.
- **Conclusion.**  `g = 0`.

**(P4) All forbidden pairs ⇔ (RCS).**  Write `U_q(p) = {c : p P_q^c != 0}`.
- **(RCS) ⇒ (CS).**  On a central piece `f_j`, one of `e f_j`, `f f_j` is `0`,
  since the used rectangle is accepted.  By (P0), `C(e) f_j = 0` or
  `C(f) f_j = 0`.  So `g f_j = 0` for all `j`, and `g = 0`.
- **(CS) ⇒ (RCS).**
  - For `U ⊆ A_q` and `U' ⊆ A_(q')`, put
    `f_(U,U') = prod_(c in U) C(P_q^c) prod_(c notin U) (1 - C(P_q^c))`
    times the same product over `U'` on `q'`.
  - These central projections sum to `1`.
  - If `c notin U`, then `f_(U,U') <= 1 - C(P_q^c)`, so
    `f_(U,U') P_q^c = 0`.  So `U_q(f_(U,U')) ⊆ U`, and likewise on `q'`.
  - If `f_(U,U') != 0` and `(c,d) in U x U'` were forbidden, then
    `f_(U,U') <= C(P_q^c) C(P_(q')^d) = 0`, a contradiction.  So
    `U x U' ⊆ Acc`.

**(P5) Corollary 1.**
- In the one-hot/NAND presentation, the NAND context of `(a,a')` has
  `c' = q` and `c'' = q'`.  Its joint PVM lies in `N`, so commuting with `P_q`
  and `P_(q')` is what the hidden-labels theorem asks of `m`.
- `X_u = 2e - 1` and `X_w = 2f - 1`, so (HL) there is (FS).
- By (P3) and (P4), the splits for all forbidden pairs are (RCS) on every
  pair.

**(P6) Corollary 2.**
- If `N` is abelian, then `[N e H] = eH`, so `C(e) = e` and (CS) reads
  `ef = 0`.
- With `V = 1` off `supp mu`, every forbidden pair lies on a pair with
  `mu > 0`, where Definition 3.15 gives commutation.

**(P7) Corollary 3.**
- **Variables are functions of contexts.**  Fix `v in c`.  Perfection and
  `sum_b P_v^b = 1` give `P_c^a = P_v^(a_v) P_c^a`, and taking adjoints
  `P_c^a = P_c^a P_v^(a_v)`.  Hence
  `P_v^b = P_v^b sum_a P_c^a = sum_(a_v = b) P_c^a`.  So `P_v in W*(P_c)`, and
  `N_(c,v) = W*(P_c)` is abelian.
- Pairs `(c,c')` and `(v,w)` carry no forbidden pairs.
- **Isomorphism.**  `A(B)` is generated by symmetries `x_v`, commuting within
  each context, with the spectral projections of disallowed assignments
  equal to `0`.
  - `x_v |-> P_v^0 - P_v^1` respects the relations.  Commutation holds by
    the first step, and for `a in Z_2^c`
    `prod_(v in c) P_v^(a_v) = sum_(a' in Allowed_c, a'|_c = a) P_c^(a')`,
    which is `P_c^a` or `0`.
  - The inverse sends `P_c^a |-> prod_(v in c) (1 + (-1)^(a_v) x_v)/2` and
    `P_v^b |-> (1 + (-1)^b x_v)/2`.  Row sums are `1`, because the
    disallowed spectral projections vanish, and forbidden products vanish.
  - The two maps are inverse on generators.
- **The gap source.**  A perfect trace of `G_cv(B)` is a trace on `A(B)`, and
  a perfect `R^U` model is an `R^U` model of `A(B)`.  (PQB4) says `A(B_I)` has
  a trace and every trace is non-CE.  By (P6), every perfect trace passes.

**(P8) Model tests.**
- **`M_3`.**  `N = M_3` is a factor, so `C(e) = C(f) = 1`.
- **`M_2 ⊕ C`.**
  - `e_11 f`, `e_22 f` and their complements vanish on the `C` summand, where
    only answer `3` is used.
  - `P_q^3` and `P_(q')^3` vanish on `M_2`.
  - So all four forbidden products are `0`.
  - `C(P_q^c) = 1 ⊕ 0` for `c = 1, 2` and `C(P_q^3) = 0 ⊕ 1`, and the same on
    `q'`.  So every forbidden product of central supports is `0`.

Notation is as in the target. `G = A_Γ`. `V = Liv_0 ⊔ Dead` is the vertex set.

**Conventions.**
- `N = N_χ` consists of the formal sums `Σ n_g g` such that for every `t` only finitely many
  `g` with `n_g ≠ 0` have `χ(g) < t`.
- `N_{≥s}` is the set of elements supported in `χ ≥ s`. We have
  `N_{≥s} N_{≥s'} ⊆ N_{≥s+s'}`, and `N_{>0} = N_{≥1}` because `χ` is integer valued.
- The complex is `N ⊗_{ZG} C_*(X̃)` for the presentation complex `X` of the Artin
  presentation.
  - `C_1 = N^V`, with rows `y`, and `d_1(y) = Σ_v y_v (v - 1)`.
  - `C_2 = N^E`. The basis vector of `e` goes to the Fox row `(∂r_e/∂v)_v`, read in `G`.
  - Everything is left `N`-linear.
- This is the convention called `V(χ)` below: "`H_0 = H_1 = 0` for this complex with
  `N_χ`".

**Step 0 (sign and side).**
- The first input (`novikov-sikorav-h1-criterion-for-artin-sigma1`) says that for every
  nonzero `χ`, `[χ] ∈ Σ^1` iff the Novikov homology in degrees `0, 1` vanishes, in the
  convention of the source.
- The anti-automorphism `g -> g^{-1}` of `ZG` carries `N_χ` to `N_{-χ}` and swaps left and
  right modules. So the source convention is `V(εχ)` for some fixed sign `ε`, for all `χ`
  at once.
- By the second input (`artin-sigma1-living-subgraph-bounds`), `Σ^1(A_Γ) = -Σ^1(A_Γ)`.
  Hence, for all `χ`: `[χ] ∈ Σ^1` iff `V(χ)` iff `V(-χ)`.
- The same input says that for discrete `χ` this is equivalent to `ker χ` being finitely
  generated.
- It also says that `[χ] ∈ Σ^1` forces `χ` to be dominant (part 2). So it suffices to prove
  Theorem part 1 for dominant `χ`, and to apply it to `±χ`.

**Step 1 (units and levels).**
- If `δ ∈ N_{≥1}`, then `1 + δ` is a unit with inverse `Σ (-δ)^n`.
- If `χ(g) > 0`, then `g - 1 = -(1 - g)` is a unit. If `χ(g) < 0`, then
  `g - 1 = g(1 - g^{-1})` is a unit. So `v - 1` is a unit for every living `v`, and
  `S_k(g) = (g^k - 1)(g - 1)^{-1}` is a unit whenever `χ(g) ≠ 0`.
- `N_{≥0} -> Z[H]`, "keep the level-0 part", is a ring homomorphism with kernel `N_{>0}`.
  Its values are finite sums, because only finitely many support elements lie below level 1.

**Step 2 (Fox rows).** Artifact check (1) verifies these in the free group ring, for
`2 <= l <= 14`, before reading them in `G`.
- For an edge `{u,v}` of label `2k`:
  - `∂r/∂u = (1 - v) S_k(uv)`;
  - `∂r/∂v = (u - 1) S_k(vu)`.
- For label `2k+1`: `∂r/∂u = Σ_{j<=k} (uv)^j - Σ_{j<k} (vu)^j v`.
- The fundamental formula `Σ_x (∂r/∂x)(x - 1) = r - 1 = 0` holds in `ZG` for every relator.
  So every Fox row lies in `ker d_1`.
- An odd label forces `χ(u) = χ(v)`. Hence an edge between a dead vertex and a living vertex
  has even label.

**Step 3 (`H_0`, and eliminating dead vertices).**
- `H_0 = N / Σ_v N(v - 1) = 0`, because some `v` is living and `v - 1` is a unit.
- For a dead `w`, let `e_w = {w, u(w)}` have label `2k_w` and put `u = u(w)`. The row
  `R_w := row(e_w)` has:
  - `w`-entry `α_w = (1 - u) S_{k_w}(wu)`, a unit by Step 1 (`χ(wu) = χ(u) ≠ 0`);
  - `u`-entry `β_w = (w - 1) S_{k_w}(uw)`;
  - zeros elsewhere.
  In particular `R_w` has zero entries at every other dead vertex.
- Let `Z' = {y ∈ ker d_1 : y_w = 0 for all dead w}`. Define
  `π(y) = y - Σ_w y_w α_w^{-1} R_w`. It is a left `N`-linear projection `ker d_1 -> Z'`
  whose kernel is `Σ_w N R_w`. The sum is direct, as the `w`-coordinates show.
- Since every `R_w` lies in `im d_2`, we get `H_1 ≅ Z' / π(im d_2)`. Here `π(im d_2)` is
  generated by the `π(row(e))` for `e` not of the form `e_w`.

**Step 4 (coordinates).** For `y ∈ Z'`, put `z_v = y_v (v - 1)` for `v ∈ Liv_0`.
- Each `v - 1` is a unit, and `d_1(y) = Σ_v z_v`.
- So `y -> z` is an isomorphism `Z' ≅ K(Liv_0) := {z ∈ N^{Liv_0} : Σ z_v = 0}`.

**Step 5 (the image of each Fox row, in `z`-coordinates).**
- *Edge `{u,v}` with both ends living.* `π` does nothing. The image is
  `g_e (e_u - e_v)` with `g_e = (∂r/∂u)(u - 1) = -(∂r/∂v)(v - 1)`, by the fundamental
  formula.
  - Label `2k`, not dead: `g_e = (1 - v) S_k(uv)(u - 1)` is a product of units, because
    `χ(uv) ≠ 0`. This includes `k = 1`, where `S_1 = 1`.
  - Odd label: `χ(u) = χ(v) = c ≠ 0`. The words of `∂r/∂u` have the pairwise distinct levels
    `0, c, 2c, ..., 2kc`, each with coefficient `±1`. Artifact check (2) verifies this for
    all `l <= 14`. The level-extreme term is `1` if `c > 0` and `(uv)^k` if `c < 0`.
    Either way `∂r/∂u` is that monomial times `1 + N_{>0}`, so it is a unit, and `g_e` is a
    unit.
  - Dead edge (label `2k >= 4`, `χ(u) = -χ(v)`): `g_e = (1 - v) S_k(uv)(u - 1)` generates
    the left ideal `N S_k(uv)(u - 1)`. The same ideal is generated by
    `-(u - 1) S_k(vu)(v - 1)`, that is, by `N S_k(vu)(v - 1)`. So we may name the ends so
    that `χ(p) > 0`, and use the generator `S_k(pq)(p - 1)`. This is **D**.
- *Edge `{w,x}`, `w` dead, `x` living, `e ≠ e_w`, label `2k'`.*
  - The row has `w`-entry `ρ_w = (1 - x) S_{k'}(wx)` and `x`-entry
    `ρ_x = (w - 1) S_{k'}(xw)`.
  - `π(row) = row - ρ_w α_w^{-1} R_w` is supported on `{x, u(w)}`. We have `x ≠ u(w)`
    because `Γ` is simplicial and `e ≠ e_w`.
  - Its `z`-image is `g(e_x - e_{u(w)})` with `g = z_x = ρ_x (x - 1)`. The coefficient
    sum is zero because `π(row) ∈ ker d_1`.
  - By the fundamental formula, `g = -ρ_w (w - 1) = -(1 - x) S_{k'}(wx)(w - 1)`.
    `(1 - x)` and `S_{k'}(wx)` are units (`χ(wx) = χ(x) ≠ 0`), so `N g = N(w - 1)`.
    This is **V**.
- *Edge `{w,x}` with both ends dead.*
  - `π(row) = row - (∂r/∂w) α_w^{-1} R_w - (∂r/∂x) α_x^{-1} R_x`.
  - Its `u(w)`-coordinate is `-(∂r/∂w) α_w^{-1} β_w`. By the fundamental formula for
    `r_{e_w}`, `β_w (u - 1) = -α_w (w - 1)`. So
    `z_{u(w)} = (∂r/∂w)(w - 1)`.
  - Likewise `z_{u(x)} = (∂r/∂x)(x - 1) = -(∂r/∂w)(w - 1)`. The image is therefore
    `(∂r/∂w)(w - 1)(e_{u(w)} - e_{u(x)})`. It is `0` if `u(w) = u(x)`. This is **W**.
  - All prefixes of `r_{wx}` have level `0`, so `∂r/∂w ∈ Z[H]`.

**Step 6 (contraction).**
- Let `B_1, ..., B_r` be the components of `Liv^χ`, the graph on `Liv_0` whose edges are the
  living non-dead edges.
- The map `Φ : K(Liv_0) -> K_r(N)`, `z -> (Σ_{v∈B_i} z_v)_i`, is onto.
- Its kernel is spanned by the `e_u - e_v` over the edges of `Liv^χ`. To see this, fix a
  spanning tree of each block. The vectors `e_u - e_v` along the tree edges, together with
  one lift of each `e_{B_i} - e_{B_r}`, form a basis of `K(Liv_0)`.
- By Step 5, these are exactly the images of the living non-dead edges up to unit factors.
- So `H_1 ≅ K_r(N) / Σ_ρ N g_ρ (e_{[a]} - e_{[b]})`, with `ρ` running over the D, V and W
  relations. That is `coker L_χ`, which proves part 1.
- Part 2 follows by Step 0: when `χ` is dominant, `V(χ)` holds iff `coker L_χ = 0`.

**Step 7 (level-0 sufficiency, part 3).**
- Every generator has the form `g_ρ = ε_ρ σ_ρ + δ_ρ` with `ε_ρ = ±1` and `δ_ρ ∈ N_{>0}`:
  - D: `S_k(pq)(p - 1) = -S_k(pq) + S_k(pq) p`, where `χ(pq) = 0` and `χ(p) > 0`;
  - V and W: `g_ρ = σ_ρ` exactly, with `δ_ρ = 0`.
- Use the basis `f_i = e_i - e_r` (`i < r`) of `K_r(R)`. The `f`-coordinates of a vector are
  its first `r - 1` entries.
- Suppose `L_0` is onto. The signs `ε_ρ` do not change its image. So there are
  `c^{(i)} ∈ Z[H]^{Rel}` with `Σ_ρ c^{(i)}_ρ ε_ρ σ_ρ (e_{a_ρ} - e_{b_ρ}) = f_i`.
- In `N`: `Σ_ρ c^{(i)}_ρ g_ρ (e_{a_ρ} - e_{b_ρ}) = f_i + Σ_j M_{ij} f_j`. Here
  `M_{ij} ∈ N_{>0}`, since `Z[H] ⊆ N_{≥0}` and `δ_ρ ∈ N_{>0}`.
- Every entry of `M^n` lies in `N_{≥n}`. So `Σ_n (-M)^n` converges entrywise in `N`, and
  `I + M` is invertible in `M_{r-1}(N)`.
- The image of `L_χ` contains the rows of `I + M`, hence the rows of
  `(I + M)^{-1}(I + M) = I`. So `L_χ` is onto, and by part 2, `[χ] ∈ Σ^1`.

**Step 8 (canonical image, part 4).**
- Let `w` be dead, with living neighbours `x` and `y`. Taking V first with `u(w)` and then
  with another choice shows that the V-span is `Σ_w Σ_{x,y} R (w - 1)(e_{[x]} - e_{[y]})`,
  over living neighbours of `w`. This holds for `R = N` and for `R = Z[H]`, whatever the
  choices are.
- Changing `u(w)` to `u'` changes a W generator by `(∂r/∂w)(w - 1)(e_{[u]} - e_{[u']})`,
  which lies in the V-span.
- For a change at the `x` end, use `(∂r/∂w)(w - 1) = -(∂r/∂x)(x - 1)`. This is the
  fundamental formula in `ZG`, applied to a relator in `w, x` only.
- D does not involve any choice.

**Step 9 (corollaries).**
- *Cut map.* For a set `S` of blocks, `K_r(N) -> N`, `n -> Σ_{i∈S} n_i`, is onto. It sends
  a relation to `±g_ρ` if exactly one end is in `S`, and to `0` otherwise. So `L_χ` onto
  implies `J_S = N`. For `r = 2` this map is an isomorphism, so the implication is an iff.
- *Level-0 identities.* Blocks `{a,b}`, `{c,e}`, `χ = (1,1,-1,-1)`, no dead vertices.
  - The identities displayed in the target are exactly `L_0`-surjectivity for `r = 2`.
    They are checked by hand in `artin-k4-odd-family-dead-characters-lie-in-sigma1-proof`
    (Step 3) and for the mixed `K` in the target.
  - For the mixed `K`: `S_2(bc) - S_2(be) = b(c - e)`, so `x ab^{-1} b(c - e) = x·ac - x^2`,
    and the sum is `S_3(x) - x - x·ac + x·ac - x^2 = 1`.
- *Ring witnesses.* Let `φ : Z[G] -> R ≠ 0` kill every `σ_ρ` crossing a cut `S`. Then the
  cut map `K_r(Z[H]) -> Z[H]`, composed with `φ`, kills the image of `L_0`. But it takes
  the value `φ(1) = 1 ≠ 0`. So `L_0` is not onto.
- *Augmentation.* `ε(σ_D) = k`, and `ε(σ_V) = ε(σ_W) = 0` because each has a factor
  `w - 1`. `L_0` onto implies `ε(L_0)` onto `K_r(Z)`.

**Step 10 (the computation, artifacts).**
- `dead_cut_laplacian_check.py` builds the full Fox complex and the reduced Laplacian.
  - The reduced Laplacian uses the unsimplified generators:
    - V as `(w - 1) S_{k'}(xw)(x - 1)`;
    - W as `(∂r/∂w) α_w^{-1} β_w (u(w) - 1)`.
  - Both are specialized at `g -> t^{χ(g)} λ(g) ρ(g)`, where `ρ` is a reflection
    representation of a Coxeter quotient `W(m')`, `m' | l`.
  - It compares `dim H_1` with `dim coker`. It skips instances where a specialization makes
    a unit singular.
  - Result: 400/400 agree, 0 disagreements. The negative controls, which drop D, V or W,
    change the answer in 56, 14 and 2 cases.
  - It also checks the Fox formulas symbolically for `l <= 14`, and the one-word-per-level
    property.
- `simplified_forms_check.py` repeats the comparison with the table generators
  (`w - 1`, `(∂r/∂w)(w - 1)`, `S_k(pq)(p - 1)` with `χ(p) > 0`). Result: 400/400 agree.

**Step 11 (combinatorial type, part 6).**
- Let `H'` be the subgroup generated by the supports of the `σ_ρ`:
  - the words `pq` for dead edges;
  - the dead vertices `w`;
  - the prefixes of the dead-dead relators, whose products with `w` also lie in `H'`.
- Write `Z[H] = ⊕_s s Z[H']` over left coset representatives `s` of `H'` in `H`, with
  `s_0 = 1`. This is a direct sum of right `Z[H']`-modules.
- For `λ = Σ_s s μ_s` and `σ ∈ Z[H']` we have `λσ = Σ_s s(μ_s σ)`.
- Suppose `Σ_ρ λ_ρ σ_ρ (e_a - e_b) = f_i` over `Z[H]`. Taking the `s_0`-components gives the
  same identity with coefficients `μ_{ρ,s_0} ∈ Z[H']`. So `L_0` is onto over `Z[H]` iff it
  is onto over `Z[H']`.
- Now fix the type `τ`: the signs `sign χ(v)` and the set of edges with `χ(u) + χ(v) = 0`.
  It determines:
  - the dead vertices, the dead edges and the blocks;
  - the orientation of every D edge;
  - every `σ_ρ ∈ Z[G]`;
  - `H'` as a subgroup of `G`.
- All of these are the same for every `χ` of type `τ`. So surjectivity of `L_0` over
  `Z[H']` is a property of `τ` alone.

**Step 12 (real characters, part 5).**
- *Additional import (I1)*, verbatim. A. Suciu, *Sigma-invariants and tropical varieties*,
  arXiv:2010.07499, abstract: "The Bieri-Neumann-Strebel-Renz invariants
  Σ^q(X,ℤ)⊂H^1(X,ℝ) of a connected, finite-type CW-complex X are the vanishing loci
  for Novikov-Sikorav homology in degrees up to q".
  - This is the import (I1) of `artin-k4-odd-family-dead-characters-lie-in-sigma1-proof`.
  - We use it with `q = 1`, for the presentation complex, or for a `K(G,1)` containing it
    as its 2-skeleton. The degree `<= 1` homology is the same for both.
- With (I1) in place of the first input, Step 0 goes through for every real `χ`.
  `Σ^1 = -Σ^1` holds for all characters by the second input.
- Steps 1–9 and 11 use only these facts:
  - `N_{>0} · N_{≥0} ⊆ N_{>0}`;
  - `N_{≥0}/N_{>0} = Z[H]`;
  - `1 + δ` is a unit for `δ ∈ N_{>0}`.
- For the unit fact and for the convergence in Step 7: a nonzero `δ ∈ N_{>0}` has a least
  support level `η > 0`, by the finiteness condition. Then `δ^n ∈ N_{≥nη}`, and the same
  holds for the finitely many entries of `M`. Everything else is exact algebra in `ZG`.
- Almeida–Kochloukova (Corollary 2.9, quoted in the conjecture node) independently reduces
  *non*-membership questions to discrete characters.

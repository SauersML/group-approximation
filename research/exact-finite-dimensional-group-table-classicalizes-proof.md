Let `Gamma <= U(d)` be the subgroup generated by the finitely many matrices
`U_x` occurring in the table.  It is a finitely generated linear group over
`C`, hence residually finite (Malcev's theorem).

For every ordered pair of distinct labels `x != y`, the element

```text
U_x^-1 U_y
```

is nonidentity.  There are only finitely many such elements.  Residual
finiteness supplies, for each one, a finite quotient in which it survives;
taking the product of these finitely many quotients gives one homomorphism

```text
q : Gamma -> Q
```

with `Q` finite and with `q(U_x) != q(U_y)` for every distinct pair of table
labels.

Take `X = Q` and let `lambda : Q -> Sym(Q)` be left translation.  Define
`sigma_x = lambda(q(U_x))`.  If `xy=z` is a listed multiplication constraint,
then

```text
sigma_x sigma_y
 = lambda(q(U_x U_y))
 = lambda(q(U_z))
 = sigma_z,
```

so the entire partial table is realized exactly.  If `x != y`, then
`q(U_x) != q(U_y)`, and two different left translations of a group disagree
at every point: equality at one `r in Q` would give
`q(U_x) r = q(U_y) r`, hence `q(U_x)=q(U_y)`.  Thus the normalized Hamming
distance between `sigma_x` and `sigma_y` is exactly `1`.

On the regular-character face the distinctness hypothesis is automatic:
`tau(U_x^* U_y)=0` for `x != y` rules out `U_x=U_y`.  Therefore every exact
finite-dimensional separated unitary table classicalizes with zero loss.

Finally, if a fixed dimension `d` admitted unitary models of the finite table
with defect tending to zero and regular-character separation tending to the
exact values, compactness of the finite product `U(d)^F` would give a
convergent subsequence whose limit is an exact separated unitary table.  The
argument above would then give an exact permutation model.  Hence a genuine
finite-table quantum/classical Hamming gap forces the required dimensions to
escape every finite bound.

Notation is as in [[monomial-origin-level-subpairs-cannot-certify-rank-three-cone]].  `σ ∈ SL_d(Z)` acts on `R`
by `x^m ↦ x^(σ m)`, and in `G` we have `σ e_ij(f) σ^-1 = e_ij(σ f)`.  Suslin gives `Gamma = SL_3(R_+) = EL_3(R_+)`.
All elements of `S` are nonzero, since `σ` is injective and `|m| ≥ k ≥ 1`.

## (M0)

`H` permutes `S`, so it normalises `Ũ_S = < e_ij(x^s) : s ∈ S >`, and `B_(H,k) = Ũ_S H`.  Since
`Ũ_S ≤ EL_3(R)` meets `SL_d(Z)` trivially, `B_(H,k) = Ũ_S x| H`.

*`Ũ_S = Ũ`.*  `⊆` is clear.  Let `E_ij = { m ∈ Z^d : e_ij(x^m) ∈ Ũ_S }`.  Then `S ⊆ E_ij`, and
`[e_ik(x^a), e_kj(x^b)] = e_ij(x^(a+b))` gives `E_ik + E_kj ⊆ E_ij` for distinct `i, j, k`.  By induction on
`n ≥ 2`, as in (D5) of [[divisor-level-subpairs-rank-three-twisted-cone-proof]], every sum of `n` elements of
`S` lies in every `E_ij`.  So `P ⊆ E_ij`.

*`Ũ ⊆ 1 + M_3(F_q[P])`.*  `F_q[P]` is closed under multiplication because `P + P ⊆ P`, so `1 + M_3(F_q[P])` is a
multiplicative monoid.  It contains every `e_ij(± x^m)`, `m ∈ P`, hence the group they generate.

*The trace.*  If `u σ ∈ Gamma` with `u ∈ Ũ` and `σ ∈ H`, then `σ ∈ EL_3(R) ∩ SL_d(Z) = 1`.  So `C = Ũ ∩ Gamma`.

## (M1)

Let `B ⊇ U_k` and `S_B = H_B · { m ∈ N^d : |m| ≥ k }`.  The two bullets above hold with `E_ij` defined from `B`
and `S_B` in place of `S`.  Let `K_B = cone(S_B) = cone(H_B · R_+^d)`, the cone spanned by the vectors `σ e_l`.

*A line forces a generator in the lineality space.*  If `w ≠ 0` and `± w ∈ K_B`, write `w = Σ a_g g` and
`-w = Σ b_g g` with `a_g, b_g ≥ 0` over finitely many generators `g = σ e_l`.  Then `Σ (a_g + b_g) g = 0`, and
some `a_g > 0`.  That `g` satisfies `-g = (a_g + b_g)^-1 Σ_(h ≠ g) (a_h + b_h) h ∈ K_B`.

*Zero is a long sum.*  Put `v = k g ∈ S_B`.  The set of nonnegative coefficient vectors `c` with
`-v = Σ c_s s`, over a fixed finite set of `s ∈ S_B`, is a nonempty polyhedron defined over `Q`.  So it has a
rational point, and `-N v ∈` the semigroup generated by `S_B` for some integer `N ≥ 1`.  Then `0 = N v + (-N v)`
is a sum of at least two elements of `S_B`, so `0 ∈ E_ij`.  Hence `e_ij(1) ∈ B ∩ Gamma = C` for all `i ≠ j`, and
`psi(C) ⊇ psi(EL_3(F_q)) = F`.

## (M2)

The first half is (M1) with `H_B ⊇ H`; note `K0 ⊆ K_B`, so a line in `K0` is a line in `K_B`.  Conversely let
`K0` be salient.  If `0 = s_1 + ... + s_n` with `s_i ∈ S` and `n ≥ 1`, then `s_1 ≠ 0` and
`-s_1 = s_2 + ... + s_n ∈ K0`, so `K0` contains the line through `s_1`.  Hence `0 ∉ P`.  For `g ∈ C`, (M0) gives
`g - 1 ∈ M_3(F_q[P])`, whose entries have no constant term.  So `ev_0(g) = 1` and `psi(C) = 1`.

## (M3)

*Irreducibles.*  Since `K` is pointed and closed, there is `λ` in the interior of the dual cone `K*`, and
`λ(m) ≥ c |m|` on `K` for some `c > 0`.  So `{ m ∈ P : λ(m) ≤ t }` is finite for every `t`.  Call `m ∈ P`
irreducible if `m ∉ P + P`, and let `X` be the set of irreducibles.  By induction on `λ`, every element of `P`
is a sum of irreducibles: a reducible `m = a + b` has `λ(a), λ(b) < λ(m)`, since `λ > 0` on `P ⊆ K \ 0`.  So
`X` generates `P`, and `X ⊆ S` because `S` generates `P`.  Each `σ ∈ H` maps `P` bijectively onto `P` and
`P + P` onto `P + P`, so `H` permutes `X`.

*`X` is infinite.*  If `X` were finite, the kernel `H'` of the permutation action would have finite index in
`H`.  `X` generates `P ∋ k e_l`, so `X` spans `R^d`, and `H'` fixes a spanning set, so `H' = 1`.  Then `H` is
finite, a contradiction.

*The abelian quotient.*  `J = F_q[P + P]` is an ideal of `F_q ⊕ F_q[P]` containing `F_q[P] · F_q[P]`.  On the
monoid `1 + M_3(F_q[P])`,

```text
φ(g) = (g - 1) mod M_3(J)  ∈  M_3(F_q[P] / J) = M_3(F_q[X])
```

is a homomorphism to an additive group, because `(1 + a)(1 + b) - 1 = a + b + ab` with `ab ∈ M_3(J)`.  It is
`H`-equivariant.  Its image on `Ũ` is spanned by the `φ(e_ij(x^m)) = x^m E_ij` with `m ∈ X` (the other generators
map to 0), and each of these lies in the image since `X ⊆ S`.  So `u σ ↦ (φ(u), σ)` is a surjection

```text
B = Ũ x| H  ->>  ( ⊕_(i ≠ j) F_q[X] E_ij ) x| H  ->>  F_q[X] x| H = F_q wr_X H ,
```

the last map keeping the `(1,2)` coefficient.  `H` acts on `F_q[X]` by permuting `X`.

*The wreath product is not Kazhdan.*  Let `W = F_q[X] x| H` act on `Ω = X × F_q` by
`(f, 1)·(x, a) = (x, a + f(x))` and `(0, σ)·(x, a) = (σ x, a)`.  These relations respect
`σ f σ^-1 = f ∘ σ^-1`, so they define an action.  Put `Y = X × {0}`.  `H` preserves `Y`, and `(f, 1) Y` differs
from `Y` exactly over `supp f`, so `|w Y Δ Y| < ∞` for every `w ∈ W`.  Hence `b(w) = 1_(wY) - 1_Y` is a 1-cocycle
for the permutation representation on `ℓ^2(Ω)`, with `||b(f, 1)||^2 = 2 |supp f|`.  Since `X` is infinite, `b` is
unbounded, so it is not a coboundary, and `W` does not have property (T) (Delorme-Guichardet).  This is the
permutational wreath product theorem of Cherix-Martin-Valette and Neuhauser, in the case needed.  Property (T)
passes to quotients, so `B` is not Kazhdan.

## (M4)

*A grading.*  `H` is finite, so `K0 = cone(∪_(σ ∈ H) σ R_+^d)` is finitely generated, hence closed, and salient,
hence pointed.  Its dual `K0*` is `H`-invariant (transpose action) and has nonempty interior.  Pick an integral
`λ_0` in that interior, and put `λ = Σ_(σ ∈ H) λ_0 ∘ σ`.  Then `λ` is integral, `H`-invariant and positive on
`K0 \ 0`, and `P_(<n) = { m ∈ P : λ(m) < n }` is finite.

*A filtration by finite-index normal subgroups.*  `I_n = F_q[P_(≥n)]` is an ideal of `F_q ⊕ F_q[P]`, because
`λ ≥ 0` on `P ∪ {0}`.  Let `Ũ_n = Ũ ∩ (1 + M_3(I_n))`, the kernel of the monoid map
`Ũ -> 1 + M_3(F_q[P] / I_n)`.  The target is finite because `P_(<n)` is finite, so `[Ũ : Ũ_n] < ∞`.  `Ũ_n` is
normal in `Ũ` and `H`-invariant because `λ` is, so it is normal in `B`, of finite index since `H` is finite.

*`C` is closed.*  Let `g ∈ ∩_n C Ũ_n`.  Then `g ∈ Ũ`.  For each `n` write `g = c_n w_n` with `c_n ∈ C` and
`w_n ∈ Ũ_n`.  Then `c_n - g = g (w_n^-1 - 1) ∈ M_3(I_n)`, because `g ∈ 1 + M_3(F_q[P])` and
`w_n^-1 - 1 ∈ M_3(I_n)`.  So `g` and `c_n` have the same monomials of `λ`-degree `< n`.  Choose `n` larger than
the `λ`-degree of every monomial of `g`.  Every monomial of `g` is then a monomial of `c_n ∈ M_3(R_+)`, so it
lies in `N^d`.  Hence `g ∈ SL_3(R_+) = Gamma`, and `g ∈ Ũ ∩ Gamma = C`.  So `C = ∩_n C Ũ_n`, and `C` is closed in
the profinite topology of `B`.

*Conclusion.*  If `C` is infranormal in `B`, its profinite closure is normal by
[[infranormal-subgroups-have-normal-profinite-closure]].  That closure is `C`.  So `C` is normal, and Theorem A
does not apply.

## (M5)

`B = Ũ x| H` maps onto `H`, so a Kazhdan `B` has a Kazhdan `H`.  If `K0` contains a line, (M2) gives
`psi(C) = F`, which is centreless.  If `K0` is salient and `H` is finite, (M4) applies.  If `K0` is salient, `H`
is infinite and `K` is pointed, (M3) applies.  What remains is `K0` salient, `H` infinite and `K` not pointed.

## The PSD example

The basis `E_ii`, `P_ij = (e_i + e_j)(e_i + e_j)^T` is a lattice basis of `Sym^2 Z^3`
(`E_ij + E_ji = P_ij - E_ii - E_jj`), and all its elements are PSD, so the orthant lies in the PSD cone.
`X ↦ g X g^T` preserves the PSD cone, which is closed and pointed, so `K ⊆ PSD` is pointed.
`Sym^2 SL_3(Z)` is infinite, and (M3) applies for every `k`.

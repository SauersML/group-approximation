## Statement

Call `g ∈ CT(Z)` **monomial** if `g(n) = λn` on each of its pieces. Here `λ ∈ Q_{>0}`, and positivity
is forced because `CT(Z)` is class-wise order preserving.
- A class transposition `τ_{r_1(m_1), r_2(m_2)}` is monomial iff `r_2 m_1 = r_1 m_2`. An example is
  `τ_{c(L), 2c(2L)}`, which is `n ↔ 2n` on `c(L)`.
- The monomial elements form a subgroup `Mon`. It contains the involutions `s_1`, `s_2` of every
  `F_M` and `A_M`, so it contains every step map of the counter-machine constructions on main.

**Theorem 1 (monomial torsion is decidable).** There is an algorithm that decides, given a
monomial `g` (as an rcwa table or a word in monomial class transpositions), whether `g` has finite
order. So every subgroup of `Mon` has solvable torsion problem. In particular:
- for a universal reversible 2-counter machine `U`, the group generated by the involutions `s_1`,
  `s_2` of `F_U`;
- the group generated by the instruction involutions of `U`.

This holds although 21.74(b), finite cycles, is undecidable already inside `Mon` (the `F_M`).
Moreover 21.74(c) and 21.73 are undecidable for elements built from `Mon` with a few non-monomial
pieces (`H_M`, `B_M`).

**Theorem 2 (one active prime).** Torsion is decidable for elements of `CT(Z)` whose moduli are all
powers of 2. This includes `CT_∅(Z)`.

**Corollary 3.**
- **Statement.** Let `H ≤ CT(Z)` be finitely generated with unsolvable torsion problem. Then some
  element of `H` is non-monomial and has a modulus that is not a power of 2.
- **Proof.** Given a word, compute its rcwa table. If it is monomial, use Theorem 1; if all its
  moduli are powers of 2, use Theorem 2. If every element of `H` fell into one of these two cases,
  torsion in `H` would be decidable. ∎

## Proofs

**Theorem 1.**
- **Setup.** Let `S` be the primes dividing the moduli of `g`, and `L` the lcm of its piece moduli,
  so `g(n) = λ_{[n]} n` with `[n] = n mod L` and `λ_{[n]}` an `S`-unit. The class of `0` is `0(m)`,
  so `g(0) = 0`.
- **Coordinates.** Write `n ≠ 0` as `n = σ ∏_{p∈S} p^{e_p} w`, with `σ = ±1` and `w ≥ 1` prime to `S`.
  Then `g` keeps `σ` and `w`, and adds `ε_{[n]} = (v_p(λ_{[n]}))_p` to the counter vector `e`.
- **`[n]` is finite data.** Put `k_p = v_p(L)`. The residue `n mod p^{k_p}` is `0` if `e_p ≥ k_p`.
  Otherwise it is `p^{e_p}` times `σ ∏_{q≠p} q^{e_q} w` mod `p^{k_p − e_p}`. So `[n]` is a function of:
  - `σ` and `w mod W`, where `W = ∏ p^{k_p}`;
  - `min(e_p, k_p)` for each `p`;
  - `e_q mod O`, where `O` is a common multiple of the orders of all `q ∈ S` modulo all `p^{k_p}`
    (`p ≠ q`).
- **A counter machine.** So `g` acts on `Conf = {±1} × (Z/W)^× × N^S` by
  `(σ, ω, e) ↦ (σ, ω, e + ε(σ, ω, e))`, where `ε` depends only on the finite data above.
  - Choose `O ≥ max k_p` and write `e_p = O c_p + r_p`, keeping `(σ, ω, r)` in the finite control.
  - Then each step reads zero tests on the `c_p` and changes each `c_p` by a bounded amount.
  - Splitting bounded changes into unit steps through intermediate states gives a deterministic
    `|S|`-counter machine `M_g`, computable from `g`.
- **Periodicity transfers.** Every point of `Conf` comes from an integer. If `g^N = 1`, then `M_g`
  has period at most `N·c`, where `c` bounds the number of micro-steps per step; conversely,
  uniform periodicity of `M_g` with bound `P` gives `g^{P!} = 1`. So `g` has finite order iff
  `M_g` is uniformly periodic, which is decidable by Kari–Ollinger Thm 4. ∎

**Theorem 2.**
- **Reduction to `V`.** With `S = {2}`, Theorem 1 of
  `ct-z-residue-partition-certificates-live-on-s-adic-coordinates` gives `ĝ = (g_2, β)`. Each piece
  of `g_2` is `x ↦ s + 2^{b−a}(x − r)` from `r + 2^aZ_2` onto `s + 2^bZ_2`: it replaces the `a` low
  digits of `r` by the `b` low digits of `s`. So `g_2` is an element of `V`, computable from `g`.
- **The equivalence.** If `g_2^N = 1`, then on each piece of `ĝ^N` the single rational affine map
  `x ↦ Ux + B` fixes an open ball of `Z_2`. So `U = 1`, `B = 0`, and `ĝ^N = 1`. The converse is
  projection.
- `V` has solvable torsion problem. ∎

## What this leaves

- **The route is dead.** A universal reversible counter machine gives elements of `Mon` whose
  cycle structure is undecidable (21.74(b),(c), 21.73). But finite order is uniform periodicity,
  and for counter dynamics that is decidable. This is the thin/thick dichotomy of
  `ct-z-torsion-problem-and-the-brin-thompson-transplant`, now a theorem on the thin side.
- **The two live routes both need additive pieces over two active primes.**
  1. `2V ↪ CT(Z)`. Lane bh-free-57 is testing "hidden 3-adic coordinates".
  2. *Rational-base Turing machines.*
     - Use the transfer pieces `x ↦ (ax − u)/b` of Theorem 2 of that node, with tape cells coded
       as blocks.
     - Unused block words, the junk, must reflect the head reversibly. Then a complete reversible
       Turing machine `T` gives `g_T` of finite order iff `T` is uniformly periodic, and Kari–Ollinger
       applies.
     - The missing piece is a junk-reflection gadget that keeps `g_T` complete and reversible and
       adds no non-periodic orbits.

## Lesson for general BH

**Uniform (torsion-type) questions die on multiplicative dynamics and need additive digit dynamics.**
- Monomial elements are counter machines, whose single-orbit questions are undecidable and whose
  uniform questions are decidable.
- A host can carry arbitrary computation in its individual orbits while every uniform property of
  those elements stays decidable. That is the pattern "undecidable conjugacy and cycles, decidable
  torsion".
- **For BH.** Embedding a group whose hardness is *uniform* (unsolvable torsion problem) needs host
  pieces that are additive over at least two independent active coordinates. Brin–Thompson hosts
  have these. The multiplicative (valuation) part of an arithmetic host provably does not.

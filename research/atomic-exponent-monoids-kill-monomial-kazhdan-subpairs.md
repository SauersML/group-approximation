**ESTABLISHED (proposed; unreviewed).**  Derivation: [[atomic-exponent-monoids-kill-monomial-kazhdan-subpairs-proof]].
It is an obstruction for the nonsofic side of [[rank-three-finite-twisted-kazhdan-cone-is-sofic]].

## Setting

As in [[monomial-origin-level-subpairs-cannot-certify-rank-three-cone]]: `H ≤ SL_d(Z)`,
`S = H · { m ∈ N^d : |m| ≥ k }`, `P` the additive semigroup generated by `S`, `K0 = cone(H · R_+^d)`,
`K` its closure, `L = K ∩ -K`, and `B = B_(H,k) = < U_k, H > = Ũ x| H`.  Assume `K0` is salient, so
`0 ∉ P` and `psi(C) = 1` by (M2); otherwise (M1)–(M2) already kill `B`.  An **atom** of `P` is an
`m ∈ P` with `m ∉ P + P`.  Write `X` for the set of atoms.  `P` is **atomic** if every element is a finite sum of atoms.

## Theorem

**(A1) Infinite atom set kills (T).**  `X ⊆ S`, `H` permutes `X`, and `B` maps onto `F_q wr_X H`.  So if `X`
is infinite, `B` is not Kazhdan.  Pointedness of `K` is not needed.

**(A2) Atomic and infinite gives infinitely many atoms.**  If `P` is atomic and `H` is infinite, then `X` is infinite, so `B` is not Kazhdan.

**(A3) An integral grading makes P atomic.**  If some `λ ∈ Hom(Z^d, Z)` is positive on `P`, then `P` is
atomic.  Such a `λ` exists whenever the lineality space `L` is a **rational** subspace and
`L ∩ R_+^d = 0`.  This covers pointed `K` (`L = 0`), which is (M3).

**(A4) Consequence.**  An origin-level monomial subpair `B_(H,k)` with infinite `H` can satisfy property (T)
only if `X` is finite and `P` is not atomic.  Then a finite-index subgroup of `H` fixes every atom, so the span of
`X` is an `H`-invariant subspace fixed pointwise by that subgroup.  It is proper, because `H` is infinite.  In particular:

- `L` is not rational, or `L` meets the orthant `R_+^d`;
- no integral functional is positive on `P`, so every rational `λ ∈ K*` vanishes at some point of `P`;
- some `m ∈ P` has infinitely many lattice points of `P` in `m - P`, so the order interval `[0, m]_P` is infinite.

The Galois-twisted candidate `Sym^2 SL_3(Z[√2])` of [[galois-psd-monomial-subpair-has-no-infranormal-trace]]
is expected to be of this kind: its lattice is dense at the real place, which suggests `P + P = P`.  This is not
proved here, and that candidate is killed anyway by nonnegative generation.

**(A5) The residual geometry exists with (T) over Z, so (A3) is needed.**  Let `H = SL_3(Z)` act diagonally on
`V = Z^3 ⊕ Sym^2 Z^3 ≅ Z^9`.  Use the basis `(0, E_ii)`, `(0, (e_i + e_j)(e_i + e_j)^T)`, `(e_i, E_11)`.
Every basis vector has a nonzero PSD second component.  So `K0` is salient, and `K = R^3 × PSD` is not pointed, with rational lineality `L = R^3 × 0`.  `H`
is infinite and Kazhdan.  So the cone condition (M5) together with property (T) of `H` does not rule this example out.  But `L` is rational and misses the
orthant, so (A3) applies and `B_(H,k)` is not Kazhdan.  This refutes the proposal to settle (N5) by
cone geometry and property (T) of `H` alone.  Any proof of (N5) has to use nonnegative generation, or
non-atomicity.

## What is left

Together with (N1) of [[galois-psd-monomial-subpair-has-no-infranormal-trace]], a monomial certificate needs
an infinite Kazhdan `H ≤ SL_d(Z)` with these properties:

- `H` is generated by nonnegative integer matrices;
- `K0` is salient;
- the exponent monoid `P` is not atomic and has a finite atom set.

Non-atomicity is the new condition.  It asks for a dense, Galois-type grading, as in `Z[√2]` at one real
place, or for a lineality space that meets the orthant.  The open question: does nonnegative generation of a
Kazhdan `H` force `P` to be atomic?  If it does, every origin-level monomial subpair is dead.

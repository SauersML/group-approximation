Notation from `non_mf_group_notes.tex`: sites `X = Σ/B`, blocks `Σ/K` with
`K = t^{-1} B t = (1/2)Z^3 ⋊ SL_3(Z)`, lamps `c_ξ = g c g^{-1}` for
`ξ = gB`, and `[c_ξ, c_η] = w` for distinct sites of one block
(`literal-lamp-kernel-clifford-block-amalgam`: the lamp kernel is the
central amalgam of the block Clifford groups over `⟨w⟩`).  Write
`χ(g) = τ(ρ(g))`.

**Step 0 (compression).**  `ρ(w)` is a central involution of `ρ(E)''`.  Put
`p = ½(1 − ρ(w))`.  If `p ≠ 0`, then `pWp` is again finite and injective
with faithful normal trace `τ(p · )/τ(p)`, and `ρ_p = ρ(·)p` is a
homomorphism into `U(pWp)` with `ρ_p(w) = −p`.  So it suffices to derive a
contradiction from `ρ(w) = −1`; assume this.

**Step 1 (the base block is an `M_16`).**  The eight lamps `c_ξ`, `ξ ∈ K/B`,
are involutions that pairwise anticommute in `W` (since `ρ(w) = −1`), so
they generate a quotient of the complex Clifford algebra `Cl_8 ≅ M_16`,
which is simple; hence a unital copy `ι : M_16 → W`.  `W ≅ M_16 ⊗ W_1` with
`W_1 = ι(M_16)' ∩ W`, and `τ = tr_16 ⊗ τ_1` because `M_16` has a unique
trace.  Each `k ∈ K` permutes the block's sites, so
`ρ(k) ι(c_ξ) ρ(k)^* = ι(c_{kξ})`, i.e. `Ad ρ(k)` restricts to the
permutation automorphism of `Cl_8`, which is `Ad V_k` for a unitary
`V_k ∈ M_16`; thus `ρ(k) = ι(V_k) w_k` with `w_k ∈ W_1` and
`χ(k) = tr_16(V_k) τ_1(w_k)`.

**Step 2 (traceless translations).**  For `v ∈ (1/2)Z^3 \ Z^3` the
translation `t_v ∈ K` acts on `K/B ≅ (Z/2)^3` by the fixed-point-free
involution `+v̄`, a product of four disjoint transpositions `π` of the eight
generators.  Then `|tr_16(V)|^2 = tr_256(Ad V)` where `Ad V` permutes the
256 Clifford monomials `c_S` up to sign.  `c_S` is fixed iff `S` is a union
of `j` of the four pairs `{a, π(a)}`, and then `Ad V(c_S) = (−1)^j c_S`
(each pair `c_a c_{πa} ↦ c_{πa} c_a = −c_a c_{πa}`).  So
`tr_256(Ad V) = Σ_j C(4,j)(−1)^j = 0`, hence `tr_16(V_{t_v}) = 0` and
`χ(t_v) = 0` for every non-integral half-translation.

**Step 3 (doubling).**  The doubling relation gives
`t t_v t^{-1} = t_{2v}` on all of
`Z[1/2]^3`.  Every `u ∈ Z[1/2]^3 \ {0}` is `2^n v` with
`v ∈ (1/2)Z^3 \ Z^3` and `n ∈ Z`, so `χ(t_u) = χ(t^n t_v t^{-n}) = χ(t_v) = 0`
by traciality.  In particular `χ(t_u) = 0` for all `u ∈ Z^3 \ {0}`.

**Step 4 (the abelian algebra).**  Let `𝒜 = ρ(Z^3)'' ⊆ W`, generated by the
level-zero translations.  By Step 3 the faithful normal trace `τ` restricts
on `𝒜` to the functional with Fourier coefficients `δ_{u,0}`, so
`𝒜 ≅ L^∞(T^3)` with `τ|_𝒜 = ∫ dHaar`.  For `m ∈ SL_3(Z)`, `Ad ρ(m)` maps
`𝒜` to itself and acts on `L^∞(T^3)` by the dual linear action `σ_m` of `m`
on `T^3`.

**Step 5 (null fixed sets).**  Let `E_𝒜 : W → 𝒜` be the trace-preserving
normal conditional expectation and `x = E_𝒜(ρ(m))` for `m ≠ 1`.  Bimodularity
gives `x f = E_𝒜(ρ(m) f) = E_𝒜(σ_m(f) ρ(m)) = σ_m(f) x` for all `f ∈ 𝒜`, so
`x (f − σ_m(f)) = 0`.  Taking `f` to range over indicator functions of a
countable base of `T^3` shows `x = 0` almost everywhere off
`Fix(m) = {y ∈ T^3 : m y = y} = ker(m − 1)`, a closed subgroup of positive
codimension since `m ≠ 1`, hence Haar-null.  So `x = 0`, and for every
`f ∈ 𝒜`, `τ(f ρ(m)) = τ(f E_𝒜(ρ(m))) = 0`.  With `f = ρ(t_u)`, `u ∈ Z^3`,
this gives `χ(t_u m) = 0` for all `m ≠ 1`; with Step 3 for `m = 1`,
`χ|_B = δ_e` on `B = Z^3 ⋊ SL_3(Z)`.

**Step 6 (contradiction).**  The trace-preserving \*-homomorphism
`(C[B], δ_e) → (ρ(B)'', τ)` is injective, and `ρ(B)''` is the completion, so
`ρ(B)'' ≅ L(B)`.  `B ⊇ SL_3(Z)` is not amenable, so `L(B)` is not injective
(Connes).  But `ρ(B)''` is a von Neumann subalgebra of the finite injective
`W`, and the trace-preserving conditional expectation onto it transports
injectivity.  Contradiction; so `p = 0` in Step 0 and `ρ(w) = 1`.

Property (T) of `B` is never used.  What is used: the block Clifford
structure with the mark at `−1`, a fixed-point-free block permutation by
elements conjugate under `t` into every level, and an abelian normal
subgroup of a nonamenable subgroup acting on its dual with null fixed sets.

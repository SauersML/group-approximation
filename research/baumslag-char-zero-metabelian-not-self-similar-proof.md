Notation as in the target: `B = R x| P`, with `R = Z[x^±1,(1+x)^-1]` and
`P = <s,t> = Z^2` acting by multiplication by the units `1+x` and `x`. Write
`pi : B -> P`. For `q = s^a t^b`, `u(q) = (1+x)^a x^b` is the corresponding unit.
The units `x` and `1+x` are multiplicatively independent in `Q(x)`, so
`u(q) = 1` only for `q = 1`.

## Step 0. Faithfulness forces a trivial joint core

Let `rho : B -> Aut(T_d)` be a homomorphism whose image `G` is state-closed.
Choose representatives `y_1, ..., y_k` of the `G`-orbits on the first level, and
let `f_i : Stab_G(y_i) -> G`, `g -> g|_(y_i)`. By state-closedness this lands in
`G`, and it is a homomorphism because `g` fixes `y_i`.

Let `N <| G` with `N <= Stab_G(y_i)` and `f_i(N) <= N` for all `i`.

- **Level 1.** `N` is normal and fixes each `y_i`, so it fixes every first-level
  vertex.
- **Sections are in N.** For `y = g y_i` and `n in N`,
  `n|_y = g|_(y_i) · (g^-1 n g)|_(y_i) · (g|_(y_i))^-1`.
  Since `g^-1 n g in N`, its section `f_i(g^-1 n g)` is in `N`. So `n|_y` lies in
  `N` up to conjugation in `G`, hence in `N`.
- **Induction.** Every element of `N` fixes level 1 and has all its level-1
  sections in `N`. By induction on the level, `N` acts trivially on `T_d`, so
  `N = 1`.

Suppose `rho` is faithful, and identify `B = G`. Then each
`H_i := Stab_G(y_i)` has finite index in `B`, and each `f_i : H_i -> B` is a
homomorphism. No nontrivial `K <| B` satisfies both `K <= H_i` and
`f_i(K) <= K` for all `i`. To reach a contradiction it therefore suffices to
exhibit a nonzero ideal `J <= R` with `J <= H_i` and `f_i(J) <= J` for all `i`.

## Step 1. Structure of `B`

1. **Abelian subgroups.** If `(w,q) in B` commutes with `0 != r in R`, then
   `(u(q) - 1) r = 0`, so `q = 1`. Hence an abelian subgroup containing a nonzero
   element of `R` lies in `R`.
2. **Normal subgroups.** If `K <| B` and `K ∩ R = 0`, then `[K,R] <= K ∩ R = 0`,
   so `K` centralizes `R` and `K <= R`, hence `K = 1`. The `P`-invariant
   subgroups of `R` are exactly its ideals, because `Z[P] -> R` is onto.
3. **Finite index.** Put `I_i = H_i ∩ R`, of finite index in `R`. Then
   `N_i R <= I_i`, where `N_i` is the exponent of `R / I_i`. Let
   `Lambda_i = pi(H_i)`, of finite index in `P`, and `S_i = Z[u(Lambda_i)] <= R`.
4. **Birational restriction.** `Frac S_i = Q(x)`. `S_i` contains `x^m` and
   `(1+x)^m` for some `m`. Over `F = Q(x^m,(1+x)^m)` the polynomials `X^m - x^m`
   and `(1+X)^m - (1+x)^m` have the single common root `X = x` in an algebraic
   closure: `X = zeta x` and `1 + zeta x = zeta'(1+x)` force `zeta' = 1`, then
   `zeta = 1`. So `X - x` is their gcd in `F[X]`, and `x in F`.
5. **Conductor.** `R` is integral over `S_i`, since `x^(±m)` and `(1+x)^(-m)`
   lie in `S_i`, and `R` is generated by `x^(±1)` and `(1+x)^(-1)`. So `R` is a
   finite `S_i`-module in `Frac S_i`, and some `0 != c_i in S_i` has `c_i R <= S_i`.

## Step 2. Classification of each `f = f_i`, with `H = H_i`, `I = I_i`

**Case (i): `f(I)` not contained in `R`.** `f(I)` is abelian. If it contained a
nonzero element of `R`, Step 1.1 would force `f(I) <= R`. So `f(I) ∩ R = 0`,
`pi` is injective on `f(I)`, and `I / ker(f|I)` embeds in `Z^2`. So
`K := ker(f|I)` is nonzero, because `I` has infinite rank. It is invariant under
conjugation by `H`.

**Case (ii): `f(I) <= R`.** For `h in H`, `pi f(h)` depends only on
`pi(h) in Lambda`, since `f(I) <= R`. This gives `beta : Lambda -> P` with
`alpha(u(q) r) = u(beta q) alpha(r)`, where `alpha = f|I : I -> R`. Let
`psi : Z[Lambda] -> R` be `q -> u(beta q)`, and `nu : Z[Lambda] -> S` be `q -> u(q)`.

- If `alpha = 0`, put `K = I`.
- **Kernel condition.** If `alpha != 0` and `z in ker nu`, then
  `psi(z) alpha(r) = alpha(nu(z) r) = 0` for all `r`. So `psi(z) = 0`, since `R`
  is a domain. So `psi` induces a ring map `psibar : S -> R`.
- If `psibar(s_0) = 0` for some `s_0 != 0`, then `alpha` kills `s_0 I`. Put
  `K = ker alpha`, which contains `s_0 I` and so is nonzero and `H`-invariant.
- **Case (a).** Otherwise `psibar` is injective and extends to a field map
  `tau : Q(x) = Frac S -> Q(x)`. Put `g = tau(x)`.
  - **Both `g` and `1+g` are units of `R`.** `tau(x^m) = u(beta(q))` is a
    monomial `x^a (1+x)^b`, so `g^m = x^a(1+x)^b`. Unique factorization in
    `Q[x]` gives `m | a, b` and `g = ± x^(a/m) (1+x)^(b/m)`. The same argument
    applied to `(1+x)^m` gives `1 + g = ± x^c (1+x)^d`.
  - **`g` is one of six maps.** Put `U = -g` and `V = 1 + g`, so `U + V = 1`
    with `U,V` units whose zeros and poles lie in `{0, -1, infinity}`.
    - `U` is not constant: the only constant units are `±1`, and `U = -1` gives
      `V = 2`, `U = 1` gives `V = 0`.
    - By Mason--Stothers, `deg U <= 3 - 2 = 1`.
    - A Möbius `U` with `U` and `1 - U` supported on those three points maps
      `{0,-1,infinity}` onto `{0,1,infinity}`.
    So `g` is one of `x, -1-x, 1/x, -x/(1+x), -(1+x)/x, -1/(1+x)`. Each has `g`
    and `1+g` units of `R`, so `sigma := tau` restricts to a ring automorphism of
    `R`, and `Aut(R)` is this group of order 6.
  - **Formula for `alpha`.** For `r in I` and a fixed `0 != r_0 in I`, write
    `r/r_0 = s_2/s_1` with `s_j in S`, using Step 1.4. Then
    `sigma(s_1) alpha(r) = alpha(s_1 r) = alpha(s_2 r_0) = sigma(s_2) alpha(r_0)`.
    So `alpha(r) = lambda sigma(r)` with `lambda = alpha(r_0)/sigma(r_0) in Q(x)`.
  - **`lambda in R`.** `J' := sigma(I)` has finite index in `R` and contains
    `N R`, so `N lambda in R`. Write `lambda = rho/N` with `rho in R`, so that
    `rho J' <= N R`. For a prime `p | N`: `J'` is not inside `pR`, because `pR` has
    infinite index. Take `j in J' \ pR`. Then `rho j in pR`, and `R/pR` is the
    domain `F_p[x^±1,(1+x)^-1]`, so `rho in pR`. Divide by `p` and induct.

So in case (a), `f(r) = lambda sigma(r)` on `I`, with `lambda in R` and
`sigma in Aut(R)`. In every other case `f` kills a nonzero `H`-invariant subgroup
`K <= I`.

## Step 3. A common ideal in the joint core

- **An ideal inside each `K_i`.** `K_i` is an `S_i`-submodule, since `H_i` acts
  through `Lambda_i`. For `0 != k_i in K_i`, `c_i k_i R <= k_i S_i <= K_i`
  (Step 1.5). So `K_i` contains the nonzero ideal `c_i k_i R`.
- **Define `J`.** Let
  `J_1 = (∩_i N_i R) ∩ (∩_(i non-(a)) c_i k_i R)`, and
  `J = ∩_(sigma in Aut R) sigma(J_1)`.
  Both are intersections of finitely many nonzero ideals of a domain, so they
  contain a nonzero product. So `J != 0`, `J` is an `Aut(R)`-stable ideal, and it
  is normal in `B`.
- **Check the conditions.** `J <= N_i R <= H_i` for all `i`. If `f_i` is in case
  (a), `f_i(J) = lambda_i sigma_i(J) = lambda_i J <= J`. Otherwise `J <= K_i`, so
  `f_i(J) = 0 <= J`.

By Step 0 the action has nontrivial kernel. This holds for every `d` and every
choice of orbits. ∎

## Uses

- **The group.** `B ≅ Z[x^±1,(1+x)^-1] x| Z^2` is Baumslag's presentation
  (Baumslag 1972). Its finite presentation is classical and is not needed here:
  the argument uses only the semidirect product structure.
- **Arithmetic inputs.** Unique factorization in `Q[x]`, Mason--Stothers for
  `C(x)`, and `F_p[x^±1,(1+x)^-1]` being a domain.
- **No literature import.** Step 0 is proved above rather than quoted from
  Dantas--Santos--Sidki, Proposition A.

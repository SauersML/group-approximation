Notation as in the claim. All spectra are taken in `C*_r(G)`. They agree with
the spectra of the same operators on `l^2(G)`, and with those in `C*_r(H)` for
any subgroup `H` containing the relevant supports, because unital C*-subalgebras
are inverse closed.

**Perturbation lemma.** For self-adjoint `x, y` in a unital C*-algebra,
`spec(x)` lies within distance `||x - y||` of `spec(y)`.
- If `dist(lambda, spec y) > ||x - y||`, then `y - lambda` is invertible, with
  `||(y - lambda)^-1|| = 1/dist(lambda, spec y) < 1/||x - y||`.
- Hence `x - lambda = (y - lambda)(1 + (y - lambda)^-1 (x - y))` is invertible
  by the Neumann series.

**(1) ⇒ (2).** Let `p` be a projection other than `0` and `1`.
- *Approximation.* `C[G]` is dense, so pick `b` in `C[G]` with
  `||b - p|| < 1/16`. The operator norm is at most the `l^1` norm, so replacing
  the finitely many coefficients of `b` by Gaussian rationals within total
  `l^1` error `1/16` gives `b'` in `Q(i)[G]` with `||b' - p|| < 1/8`.
- *Self-adjointness.* Put `a0 = (b' + b'*)/2`. It lies in `Q(i)[G]`, because
  the adjoint conjugates coefficients and inverts group elements, and
  `||a0 - p|| < 1/8`.
- *Integrality.* Choose an integer `N >= 1` clearing denominators. Then
  `a = N a0` lies in `Z[i][G]`, is self-adjoint, and `spec(a) = N spec(a0)`.
- *The two components.* By the lemma, `spec(a0)` lies in
  `[-1/8, 1/8] ∪ [7/8, 9/8]`.
  - If it lay in the first interval, then `||a0|| <= 1/8`, hence `||p|| < 1/4`.
    But `||p|| = 1` for a nonzero projection.
  - If it lay in the second, then `||1 - a0|| <= 1/8`, hence `||1 - p|| < 1/4`.
    But `1 - p` is a nonzero projection.
  So `spec(a0)` meets both intervals and is disconnected, and so is `spec(a)`.

**(2) ⇒ (1).** Write `spec(a) = K_1 ⊔ K_2` with `K_1` and `K_2` nonempty,
disjoint and closed. The function `f = chi_(K_1)` is continuous on `spec(a)`
and satisfies `f = f^2 = conj(f)`. So `p = f(a)` lies in `C*(1, a)`, inside
`C*_r(G)`, and is a projection. Continuous functional calculus is isometric,
`||f(a)|| = sup over spec(a) of |f|`. Therefore `p != 0` because `f = 1` on
`K_1`, and `1 - p != 0` because `f = 0` on `K_2`.

**`supp mu_a = spec(a)`.**
- *Inclusion.* `mu_a` is a Borel probability measure on `spec(a)`, so its
  support lies in `spec(a)`.
- *Reverse inclusion.* Let `lambda` be in `spec(a)` and `U` an open
  neighbourhood of it. Take a continuous `g: R -> [0,1]` with `g(lambda) = 1`
  and support in `U`. Then `g(a) >= 0`, and `g(a) != 0` because `g` does not
  vanish on `spec(a)`. Faithfulness of `tau` gives
  `mu_a(U) >= int g d mu_a = tau(g(a)) > 0`.
- *(2) ⟺ (3).* A compact subset of `R` is connected iff it is an interval, so
  the two conditions are the same.

**Trace of the gap projection.** `tau(chi_(K_1)(a)) = mu_a(K_1)`.
- `K_1` is open in `spec(a)` and nonempty, so it has positive measure.
- The same holds for `K_2`.
- So `0 < mu_a(K_1) < 1`.

**Finitely generated witness.** Let `H` be the subgroup generated by the support
of `a`. Then `C*_r(H)` is a unital C*-subalgebra of `C*_r(G)` containing `a`,
and spectra agree by inverse closedness. QED

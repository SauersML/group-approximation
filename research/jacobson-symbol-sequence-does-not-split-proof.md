Notation as in the target. Every vector space is over `F_2`. A linear map
`X : U -> U'` is *Fredholm* if `ker X` and `coker X` are finite-dimensional.
Then `ind X = dim ker X - dim coker X`.

## Step 0. Algebraic Fredholm facts

(F1) **Composition.** If `X`, `Y` are Fredholm and composable, then `YX` is Fredholm and `ind(YX) = ind X + ind Y`.
This is the exact sequence `0 -> ker X -> ker YX -> ker Y -> coker X -> coker YX -> coker Y -> 0`.

(F2) **Finite-rank perturbation.** If `X` is Fredholm and `F` has finite rank, then `X + F` is Fredholm and has the same index.
- Let `K = ker F`, which has finite codimension. Then `X|_K = (X+F)|_K`.
- Restriction to a subspace of codimension `r` lowers the index by exactly `r`, for both maps.

(F3) **Block diagonal.** If `U = U_1 (+) U_2` and `X = X_1 (+) X_2` with each `X_i` Fredholm on `U_i`, then `ind X = ind X_1 + ind X_2`.

(F4) **Shift.** On `V_+`, `S` is injective with cokernel `F_2 e_0`, so `ind S = -1`. Also `T` is onto with kernel `F_2 e_0`, so `ind T = +1`.
By (F1), `ind S^2 = -2` and `ind T^2 = +2`.

## Step 1. Every lift is its canonical Toeplitz matrix plus finite rank

- The kernel of `pi : J -> A` is the two-sided ideal generated by `Q = 1 - ST`.
  - On `V_+`, that ideal is the span of the matrix units `S^i Q T^j = e_i (x) e*_j`.
  - So it is exactly the ideal of finite-rank operators in `J`.
- Hence two elements of `M_n(J)` with the same symbol differ by a matrix of finite-rank operators, which is a finite-rank operator on `V`.
- In particular, every `g~ in E` with symbol `g` has `g~ = t(g) + (finite rank)`, where `t(g)` is any fixed element of `M_n(J)` with symbol `g`.

We use the following matrices in `M_n(J)`:
- `t(c) = c`: `c` is a constant matrix, and constants lie in `J`.
- `t(h) = diag(S, S, T^2, 1, ..., 1)`, whose symbol is `diag(z, z, z^(-2), 1, ..., 1) = h`.

## Step 2. Relative index along an idempotent

Let `e` be an idempotent operator on `V`, and let `X` be an operator with `eX - Xe` of finite rank.
Put

```text
Y(e, X) = e X e + (1 - e).
```

Say `(e, X)` is *admissible* if `Y(e,X)` is Fredholm, and then put `ind_e X = ind Y(e,X)`.

(R) **Invariance.** Suppose `e - e'` and `X - X'` have finite rank, and `(e, X)` is admissible.
Then `(e', X')` is admissible and `ind_(e') X' = ind_e X`.
- `Y(e', X') - Y(e, X)` is a sum of products, each with at least one finite-rank factor `(e' - e)` or `(X' - X)`, so it has finite rank.
- Apply (F2).

(B) **Exact reduction.** If `eX = Xe` exactly, then `Y(e,X) = X|_(eV) (+) 1_((1-e)V)` with respect to `V = eV (+) (1-e)V`.
So `ind_e X = ind(X|_(eV) : eV -> eV)` by (F3).

## Step 3. The constant side

- `c_0 = [[0,1],[1,1]]` satisfies `c_0^2 + c_0 + 1 = 0` over `F_2`. So `c_0` has order 3 and `c_0 + c_0^2 = 1_2`.
- Put `e_0 = c + c^2`. It is block diagonal with block `c_0 + c_0^2 = 1_2` in coordinates `1,2` and `1 + 1 = 0` in coordinates `3..n`.
- So `e_0` is the coordinate projection of `V = V_+^n` onto `V_+ (+) V_+ (+) 0 (+) ... (+) 0`.
- `t(h)` is block diagonal in the coordinates, so it commutes with `e_0` exactly. By (B) and (F3), (F4):

```text
ind_(e_0) t(h) = ind (S (+) S) = -2.
```

## Step 4. The lifted side

- Suppose `c~, h~ in E` have symbols `c, h`, with `c~^3 = 1` and `c~ h~ = h~ c~`.
- Put `e~ = c~ + c~^2`. Then `e~^2 = c~^2 + 2 c~^3 + c~^4 = c~^2 + c~ = e~`, since `2 = 0` and `c~^3 = 1`. So `e~` is an idempotent.
- `h~` commutes with `c~`, hence with `e~`. So `h~` maps `e~V` into itself.
- `h~^(-1)` also commutes with `e~`. So `h~|_(e~V)` is invertible, with index `0`.
- By (B), `ind_(e~) h~ = 0`.

## Step 5. Comparison

- By Step 1, `c~ = c + F_1` with `F_1` of finite rank. So `c~^2 = c^2 + (finite rank)`, and `e~ - e_0` has finite rank.
- By Step 1 again, `h~ - t(h)` has finite rank.
- `(e_0, t(h))` is admissible by Step 3. So (R) gives `ind_(e~) h~ = ind_(e_0) t(h)`, that is, `0 = -2`.

This contradiction proves (NS).

- A splitting `sigma` of the sequence over any subgroup containing `c` and `h` would give `c~ = sigma(c)` and `h~ = sigma(h)` with these properties. So there is none.
- For a conjugate `q A_0 q^(-1)`, conjugate a putative section by any lift of `q`.
- For `h^k` with `k ≠ 0`, the same computation gives `ind_(e_0) t(h)^k = -2k ≠ 0`.

## Step 6. General form (G)

Let `F <= GL_n(F_2)` have odd order, let `e in F_2[F]` be a central idempotent, and let `g in Q` centralize `F`.
- Given a homomorphism `s : F -> E` lifting `F`, and `g~` lifting `g` and centralizing `s(F)`, Steps 4 and 5 give `ind_(s(e)) g~ = 0 = ind_e t(g)`.
  - Here `s(e)` is an idempotent because `s` extends to the group algebra.
- `e F_2^n` is an `F`-submodule, and `g` preserves `M = e A^n = e F_2^n (x) A`, which is free of rank `r = dim e F_2^n`.
- Choose an `F_2`-basis of `e F_2^n`. Then `g|_M in GL_r(A)` has determinant `z^m` with `m = m_e(g)`, since `A^x = {z^m}`.
- Write `g|_M = diag(z^m, 1, ..., 1) * u` with `u in SL_r(A)`. Then `u in EL_r(A)`, since `A` is Euclidean.
- Elementary matrices `x_ij(a)` lift to invertible `x_ij(t(a))`. Symbol lifting is multiplicative modulo finite rank.
- So by (F1), (F2) and (F4), `ind t(g|_M) = ind t(z^m) = -m`.
- Now replace `t(g)` by `t'(g) = e t(g) e + (1-e) t(g) (1-e)`.
  - It has the same symbol, because `g` commutes with the constant `e`, so `t'(g) - t(g)` has finite rank.
  - It commutes with `e` exactly.
  - By (R) and (B), `ind_e t(g) = ind(t'(g)|_(eV))`, and `t'(g)|_(eV)` is a lift of `g|_M` on `V_+^r`. So `ind_e t(g) = -m`.
- Hence `m_e(g) = 0` whenever such lifts exist.
- For `r = 1` there is nothing to factor.

## Step 7. Sanity checks

- **Total index.** For `e = 1`, `m_1(g) = deg det g = 0` on `SL_n(A)`. This recovers (MQ1), and no obstruction arises.
- **One-sided halves.** On `SL_n(F_2[z])` every centralizing `g` has `det(g|_M)` a unit of `F_2[z]`, so `m = 0`. This is consistent with the analytic-Toeplitz splitting of `H_+`.
- **Bilateral ambient.** In `H_bi`, `t(z)` is the invertible bilateral shift, and every index is `0`. This is consistent with `H_bi` being a genuine semidirect product.
- **Congruence subgroups.** If `f` is a nonunit and `g ≡ 1 mod f` has finite order, then every eigenvalue `zeta` of `g` is a root of unity in the constant field, and `zeta - 1` is divisible by `f`. So `zeta = 1` and `g` is unipotent.
  - `F_2[F]` for a 2-group `F` has no nontrivial idempotents.
  - So (G) says nothing about virtual splitting.

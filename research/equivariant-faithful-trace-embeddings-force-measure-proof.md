The invariant state t∘ι is an invariant probability measure m.
Any nonempty open set contains the support of a nonzero positive
continuous function; injectivity and faithfulness give that function
strictly positive integral. Thus m has full support. Infinitely
many disjoint translates of a nonempty open set would have the same
positive measure, contradicting m(Y)=1. Normalize the trace to apply
the same argument to an invariant finite-trace corner.

This is a written deduction integrated from the supplied attempt, not
an independent referee report or a Lean proof.

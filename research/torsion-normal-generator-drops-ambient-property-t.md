Let `G` be finitely generated and normally generated by an element `a` of
finite order.  Suppose `L <= G` has property (T) and

```text
a in D_G(L),
```

the intrinsic compression defect.  Then every homomorphism from `G` to an MF
group is trivial.

**No property (T) is assumed for `G`.**  Property (T) is still required for
`L`, so this does not remove the Ershov--Jaikin-Zapirain input from the ring
theorem; it removes only the ambient Kazhdan hypothesis that the printed
upgrade uses.

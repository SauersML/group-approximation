Notation is as in the target.

## (1)

Fix finite generating sets of `Γ` and `D`, and representatives
`c_1 = 1, c_2, ..., c_m` of the double cosets `D \ Γ / D`.

**Double cosets are r.e.** The words representing elements of `D c_i D` are the
words `w` such that `w = u c_i v` in `Γ` for some words `u, v` in the generators of
`D`. Enumerate all triples `(u, v, w)` and test the equation with the word problem
algorithm of `Γ`. So each `D c_i D` is r.e., uniformly in `i`.

**Membership in a union of double cosets is decidable.** Let `I ⊆ {1, ..., m}`.
Given `w`, run the `m` enumerations in parallel. Exactly one of them eventually
lists `w`, since the double cosets partition `Γ`. Answer yes iff its index lies in
`I`. This halts on every input and is correct.

**Overgroups are unions of double cosets.** If `D <= H <= Γ` and `h in H`, then
`D h D ⊆ H`. So `H` is the union of the `D c_i D` with `c_i in H`. Taking
`I = {i : c_i in H}`, a finite set, gives a decision procedure for `H`.

For `H = D` this is `finite-bi-index-subgroups-have-decidable-membership`; the
argument above is the same one.

## (2)

`C_Γ(π) = {γ in Γ : γπ = πγ}` is a subgroup of `Γ`. Since `ψ = id`, every `d in D`
satisfies `π d π^-1 = d`, so `D <= C_Γ(π)`.

`Γ` has solvable word problem: it has a faithful type (A) action, so this is
`type-a-action-gives-boone-higman-for-subgroups`, as used in
`permutation-hnn-realization-of-type-a-actor-is-a2`. `D` is finitely generated by
hypothesis and has finite bi-index, so (1) applies with `H = C_Γ(π)`.

## (3)

For `d in D_1`, `π' d π'^-1 = δ^-1 ψ(d) δ = δ^-1 δ d δ^-1 δ = d` as permutations. Since
`δ in Γ`, the groups `<Γ, π>` and `<Γ, π'>` coincide.

`(D_1, D_1, id, π')` satisfies the hypotheses of
`permutation-hnn-realization-of-type-a-actor-is-a2`. So by its part (a), both kernels
are recursive iff this common image has solvable word problem. Part (2) applies to
`π'`.

For `C_Γ(π)`: an element `d in D_1` commutes with `π` iff `ψ(d) = d`, iff `d`
commutes with `δ`. That is all that is claimed.

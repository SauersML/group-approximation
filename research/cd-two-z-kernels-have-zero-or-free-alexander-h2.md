Recalled imports: projective modules over a PID are free (Kaplansky); Shapiro's lemma;
the Künneth short exact sequence over a PID; Hillman's bound `h(G) <= cd G` for elementary
amenable `G` and the Hillman–Linnell structure theorem (virtually solvable when torsion-free of
finite Hirsch length).
Items 1–3 need no amenability and no residual finiteness.

**Setting.** `H` is finitely generated by `n` elements, `cd_Z H <= 2`, `P` is the relation module
(`0 → P → Z[H]^n → Z[H] → Z → 0` is a projective resolution), `b_k = dim_Q H_k(H; Q)`,
`χ = χ_Q(H) = 1 − b_1 + b_2`. Let `φ : H ↠ Z = ⟨t⟩`, `L = ker φ`, `Λ = Q[t^{±1}]`,
`H_m = φ^{-1}(mZ)`. The deck action makes `A_k = H_k(L; Q)` a `Λ`-module. Put
`ρ_k = rank_Λ A_k = dim_{Q(t)} Q(t) ⊗_Λ A_k`.

1. **The Alexander complex is free.** `Λ ⊗_{Z[H]} P` is a free `Λ`-module of rank
   `r = n − b_1 + b_2` (possibly infinite). Hence `A_k = H_k(Λ ⊗ P → Λ^n → Λ)`, and
   - `A_0 = Λ/(t − 1) = Q` and `A_k = 0` for `k >= 3`;
   - `A_1` is a finitely generated `Λ`-module, `A_1 ≅ Λ^{ρ_1} ⊕ T_1` with `dim_Q T_1 < ∞`,
     and `ρ_1 <= n − 1`;
   - `A_2` is a **free** `Λ`-module, of rank `ρ_2 <= r`.
2. **Alexander formula.** If `b_2 < ∞`, then

   > `χ_Q(H) = ρ_2 − ρ_1`.

   If `b_2 = ∞`, then `ρ_2 = ∞`.
3. **Zero-or-free dichotomy and the cyclic tower.**
   - (a) `H_2(L; Q)` is either `0` or infinite-dimensional. It is `0` exactly when
     `b_2(L) < ∞`, and then `b_2(H) < ∞` and `χ_Q(H) = −ρ_1 <= 0`.
   - (b) Lück approximation holds along the cyclic tower, whose intersection is `L` rather than
     `1`: `b_k(H_m) = mρ_k + O(1)` for `k = 1, 2`, with `|O(1)| <= dim T_1 + 1`. In particular,
     `lim b_2(H_m)/m = ρ_2` and the `Q[Z/m]`-module `H_2(H_m; Q)` contains
     `A_2/(t^m − 1) ≅ Q[Z/m]^{ρ_2}`, a free module of codimension at most `dim T_1`.
   - (c) *Fibred construction kill.* If `H` is an ascending HNN extension, with stable letter
     `t`, of any group `B` with `b_2(B) < ∞` (finitely generated or not), or more generally if
     `L` is a directed union of subgroups whose `b_2` is bounded, then `χ_Q(H) <= 0`.
4. **Escape-side dichotomy for Kropholler's question in dimension 2.** Let `K` be a finitely
   generated amenable group of cd 2 with finite abelianization, `K ≠ 1`. Such a `K` exists iff
   Kropholler's question fails in dimension 2 (item 3(i) of the LI node). Then
   `χ_Q(K) = 1 + b_2(K) >= 1`, and exactly one of the following holds.
   - (I) **Virtually rationally perfect.** Every finite-index `N` has `b_1(N) = 0`. If
     `b_2(K) < ∞`, then `b_2(N) = χ[K:N] − 1`, and for normal `N`, with `F = K/N`,
     `H_2(N; Q) ⊕ Q ≅ Q[F]^{χ}` as `Q[F]`-modules. If `b_2(K) = ∞`, every `b_2(N) = ∞`.
   - (II) **Fibred.** Some finite-index `H` maps onto `Z`. Then, for **every** finite-index `H`
     and every `φ : H ↠ Z`, the kernel `L` is amenable, of cd 2, not finitely generated and not
     elementary amenable, and
     > `H_2(L; Q) ≅ Λ^{ρ_2}` is free with `ρ_2 = [K:H] χ_Q(K) + ρ_1 >= [K:H]`.

     In particular `b_2(L) = ∞`, and `L` contains finitely generated subgroups of arbitrarily
     large `b_2`. Each of those with `b_2 >= 2` is again a counterexample, because every
     elementary amenable group of cd `<= 2` has `b_2 <= 1`.
5. **A class where the question holds.** Let `G` be amenable with `cd_Z G <= 2`. Suppose every
   finitely generated subgroup `J ≠ 1` of `G` with finite abelianization has a finite-index
   subgroup with an epimorphism onto `Z` whose kernel has finite `b_2`. Then no such `J`
   exists, so `G` is locally indicable, hence solvable: `1`, `Z`, a noncyclic subgroup of `Q`, or
   `BS(1,m)` with `m ≠ 0`. Neither finite presentability nor finite generation of any kernel
   is assumed. Equivalently: a finitely generated counterexample with finite abelianization is
   never virtually (finite-`b_2`)-by-`Z`.
6. **What this says about the target's item 6 and the brief's step.**
   - For `Γ = Z` the L²-Swan statement of target item 6(a) holds automatically:
     `Λ ⊗ P` is free, so `D_Z(P_Z) = 0` and `χ^{(2)}(H; Z) = ρ_2 − ρ_1 = χ_Q(H)`.
   - The lifting inequality of item 6(b) for `Γ = Z` is exactly `ρ_2 <= ρ_1`: the fibre's `H_2`
     must have Alexander rank at most that of its `H_1`.
   - The module-structure input suggested for the cross-tile remainder does exist along a cyclic
     tower, and it points the other way. `H_2(H_m)` is, up to `O(1)`, a **free**
     `Q[Z/m]`-module of rank `ρ_2`, induced from the fibre. So induced structure does not make
     `H_2` small. For a fibred counterexample it carries the whole slope `χ + ρ_1`.

**Calibrations** (all satisfy item 2).

| `H` | `φ` | `L` | `A_1` | `A_2` | `ρ_2 − ρ_1` | `χ` |
|---|---|---|---|---|---|---|
| `Z²` | projection | `Z` | `Q` | `0` | `0` | `0` |
| `BS(1,m)` | `a ↦ 0, t ↦ 1` | `Z[1/m]` | `Λ/(t − m)` | `0` | `0` | `0` |

The last row shows that `A_2` can be a nonzero free module. It is the non-amenable shape that
type (II) would need.

**What this changes.** It kills every construction of a two-dimensional amenable counterexample
as a virtual extension of a group of finite `b_2` by `Z`. This includes ascending HNN extensions
over bases with finite `b_2`, whether or not the base is finitely generated, which extends the
finitely generated case of `amenable-cd-two-ascending-hnn-groups-are-baumslag-solitar`. A
counterexample is either virtually rationally perfect, or fibred with fibres whose `H_2` is
Alexander-free of rank `>= [K:H]`. In the fibred case, `χ = 0` is equivalent to the single
inequality `rk_Λ H_2(L) <= rk_Λ H_1(L)` for one virtual `Z`-kernel `L`. That is a statement about
one non-finitely-generated amenable group of cd 2 with a `Z`-action, and needs no residual chain.

Full written proof of Theorem A and Example B of the target. Notation is as in
`fpbs-finite-fibre-bb-classes-are-boundary-squares` and its proof.

## Standard facts

- **(E1)** In a hyperbolic group, the stabiliser of a point of `dGamma` is finite or virtually cyclic (there are no
  parabolic subgroups). An infinite virtually cyclic subgroup contains a loxodromic `k`, and every infinite subgroup
  of it contains a power of `k`.
- **(E2)** A loxodromic `k` fixes exactly two points `k^+ != k^-` of `dGamma`. Its powers fix the same two points.
- **(E3)** A measure-preserving action of a countable group on a countable set with counting measure is conservative
  on the union of orbits of points with infinite stabiliser, and dissipative on the rest. (A point with finite
  stabiliser and infinite orbit is a wandering singleton. A point with infinite stabiliser returns to itself
  infinitely often.)

## Proof of Theorem A

1. **The class lives on one orbit.** The set of atoms of `lambda_0` is invariant, because `C` is quasi-invariant.
   It is not null, so by ergodicity it is conull. Two atoms in different orbits would give two disjoint invariant
   sets of positive measure. So `lambda_0` is carried by one countable orbit `Gamma x_0`.
2. **Lambda is constant on the orbit.** Invariance gives `lambda({g x_0}) = lambda({x_0}) = c`, with `0 < c <
   infinity` because the fibres are finite and nonzero a.e. By minimality the orbit is dense, so every nonempty open
   `U` contains infinitely many orbit points, and `lambda(U) = infinity`. This proves item 1.
3. **Conservative atoms of the square.** `lambda x lambda` on `D` is `c^2` times counting measure on
   `(Gamma x_0)^2 \ Delta`. By (E3), its conservative part is the set of orbits of pairs `(x, y)`, `x != y`, whose
   stabiliser `Stab(x) cap Stab(y)` is infinite. By (E1) such a stabiliser contains a loxodromic `k` fixing `x` and
   `y`, so `{x, y} = {k^+, k^-}` by (E2). Conversely, a fixed pair of a loxodromic has stabiliser containing `<k>`.
   This proves item 2.
4. **An infinite dissipative part.** Fix `x = x_0`.
   - If `Stab(x_0)` is finite, then every pair `(x_0, y)` has finite stabiliser.
   - Otherwise, by (E1) and (E2), a pair `(x_0, y)` with infinite stabiliser has `y` equal to the partner fixed
     point `x_0'`. This `x_0'` is the same for every loxodromic in `Stab(x_0)`, because such loxodromics have a
     common power.
   The orbit `Gamma x_0` is infinite (it is dense in the perfect space `dGamma`). So infinitely many `y` give atoms
   `(x_0, y)` of mass `c^2` with finite stabiliser. These atoms are wandering, so the dissipative part of
   `(D, lambda x lambda)` has infinite measure. By Theorem 2.2 of the audited node, which holds verbatim here, since
   Step 3 of its proof does not use nonatomicity, `Con(W) = pi^{-1}(Con(D))`. So `W` is not conservative. This
   proves item 3. ∎

## Proof of Example B

- **The group.** `Gamma = <s> * <t> * <u>`, with `s, t` of order 2 and `u` of infinite order, is a free product of
  finite and cyclic groups, so it is virtually free and hyperbolic. It is nonelementary, since it is not virtually
  cyclic. The element `h = st` has infinite order, so it is loxodromic, and `s h s = ts = h^{-1}`. Hence
  `s h^+ = h^-`.
- **The action.** `Z = Gamma / <h>` with counting measure is transitive, so it is ergodic. It is infinite, since
  `<h>` has infinite index, and it is measure preserving. The map `xi(g<h>) = g h^+` is well defined and equivariant.
  The fibre over `h^+` is `Stab(h^+) / <h>`, which is finite, since `<h>` has finite index in the virtually cyclic
  `Stab(h^+)`. By equivariance all fibres are finite, and the class is atomic.
- **The square.** The pair `(h^+, h^-) = (h^+, s h^+)` lies in `(Gamma h^+)^2` and has stabiliser containing `<h>`.
  So its orbit is in the conservative part (E3), and by Theorem A.3 the dissipative part is infinite.
- **Not PDR.** For counting measure on `Z`, `Con(Z^2)` is the set of pairs of cosets `(a<h>, b<h>)` with
  `a<h>a^{-1} cap b<h>b^{-1}` infinite. Such pairs have `a h^± ` and `b h^±` fixed by a common loxodromic, so
  `{a h^+, a h^-} = {b h^+, b h^-}`. So the relation generated by `Con(Z^2)` keeps `a{h^+, h^-}` constant. The
  coset `u<h>` is not in the class of `<h>`, because `u{h^+, h^-} != {h^+, h^-}` (the element `u` is not in the
  virtually cyclic stabiliser of `{h^+, h^-}`, which is `<s, t>`). Hence `Z` is not PDR.
- **Cost.** `beta_1^(2)(A * B) = beta_1^(2)(A) + beta_1^(2)(B) + 1 - 1/|A| - 1/|B|` for infinite `A * B`.
  - For `D_inf = Z/2 * Z/2` this gives `beta_1^(2)(D_inf) = 0`.
  - Then `beta_1^(2)(D_inf * Z) = 0 + 0 + 1 - 0 - 0 = 1`.
  - So every free pmp action of `Gamma` has cost `>= 2`, by Gaboriau. ∎

## What this does not do

It does not bear on the nonatomic square problem (II_inf-square) or on the infinite-fibre case. Both remain OPEN.

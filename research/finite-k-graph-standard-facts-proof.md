**Lane proof** (bh-groupoid, 2026-09-18), not independently reviewed.

## Conventions

- **Kumjian–Pask side.** `Λ` is a finite `k`-graph with no sources, in Kumjian–Pask
  conventions.
  - `λ(m, n)` is a segment of `λ`, `Λ^∞` is the space of infinite paths `x: Ω_k -> Λ` with
    the cylinder topology, and `σ^p` is the shift.
  - `G_Λ = {(x, p−q, y) : σ^p x = σ^q y}`, with basic sets
    `Z(λ, μ) = {(λz, d(λ)−d(μ), μz) : z ∈ s(λ)Λ^∞}`. Here `s(λ) = s(μ)`, and `G_Λ` is taken
    with the topology generated by these sets.
- **Li side.** These are read at source: X. Li, *Left regular representations of Garside
  categories I*, arXiv:2110.04501, TeX on MSI. `𝔠` is `Λ` viewed as a left cancellative
  small category (the elements are the paths).
  - Constructible right ideals `𝒥`, characters `Ĵ`, and the subspace `Ω` of
    Definition `def:Omega`.
  - The action of `I_l` on `Ω`, and the transformation groupoid `I_l ⋉ Ω = I_l * Ω/~`, where
    `(s,χ) ~ (t,χ)` iff `se = te` for some `e ∈ 𝒥` with `χ(e) = 1`.
  - `Ω_∞ = Ω \ {χ_x : x ∈ 𝔠}` and `∂Ω = closure(Ω_max)` (subsection `ss:boundary`).
  - Lemma `lem:infpaths`: for finitely aligned `𝔠`, every `χ ∈ Ω_∞` is `χ_w` for an
    infinite path `w` in `𝔖`, and `cd^{-1}.χ_w = χ_{c x_n w_{>n}}` when `d x_n = c w_n`.
  - Lemma `lem:Omegamax`. Finite `k`-graphs are finitely aligned (TeX l.1771).

## Lemma A: elements of I_l and ideals

1. Let `c, d ∈ 𝔠` have the same range.
   - `c𝔠 ∩ d𝔠 = ⊔_{ε ∈ MCE(c,d)} ε𝔠`, a finite disjoint union ("disjoint mcms", Li
     l.1776).
   - So `d^{-1}c = ⊔_ε α_ε β_ε^{-1}` with `ε = cβ_ε = dα_ε`, on disjoint domains `β_ε𝔠`.
2. **Products.** Inductively, every element of `I_l` is a finite disjoint union of maps
   `cd^{-1}` on disjoint domains `d𝔠`. Every constructible ideal is a finite disjoint union
   of principal ideals `λ𝔠`.
3. **Germs.** For `χ ∈ Ω` with `χ(s^{-1}s) = 1`, there is one `i` with `χ(d_i𝔠) = 1`
   (`χ ∈ Ω` and the domains cover), and then `[s, χ] = [c_i d_i^{-1}, χ]` using
   `e = d_i𝔠`.

## Item 1: models agree

**(a) Paths give characters.** For `x ∈ Λ^∞`, put `χ_x(e) = 1` iff `x(0, n) ∈ e` for some
`n`.
- It lies in `Ω`, as Li's `χ_w` for any path `w` in `𝔖` exhausting `x`.
- `x ↦ χ_x` is injective, since `χ_x(λ𝔠) = 1` iff `λ = x(0, d(λ))`.
- It is continuous, since on each finite union of principal ideals it reads a finite prefix.

**(b) Ω_max = {χ_x}.**
1. **χ_x is maximal.** Let `e = ⊔λ_i𝔠` with `χ_x(e) = 0`, and take `N ≥ d(λ_i)` for all
   `i`. Then `f = x(0,N)𝔠` has `χ_x(f) = 1` and `ef = ∅`, since `λ_i𝔠 ∩ x(0,N)𝔠 ≠ ∅` would
   force `λ_i = x(0, d(λ_i))`. So Lemma `lem:Omegamax`(i) applies. Here `0 ∈ I_l`, because
   distinct edges of one degree at one vertex have disjoint ideals.
2. **Every maximal character is some χ_x.**
   - `χ_λ` is never maximal, since `χ_λ ≤ χ_x` for any `x` extending `λ`, strictly.
   - So by Lemma `lem:infpaths`(ii), a maximal `χ` is `χ_w` for an infinite path `w`.
   - The sets `{x ∈ Λ^∞ : x(0, d(w_m)) = w_m}` are nonempty (no sources), compact and
     decreasing. So some `x` extends every `w_m`, and `χ_x ≥ χ_w`.
   - If some coordinate `j` of `d(w_m)` stays bounded by `D`, then `χ_x(x(0,n)𝔠) = 1` while
     `χ_w(x(0,n)𝔠) = 0` for `n_j > D`. That contradicts maximality.
   - So all coordinates of `d(w_m)` tend to infinity, and `χ_w = χ_x`.

**(c) The boundary.** `Λ^∞` is compact and `Ω` is Hausdorff, so `x ↦ χ_x` is a
homeomorphism of `Λ^∞` onto `Ω_max`. Its image is closed, so `∂Ω = Ω_max ≅ Λ^∞`. It lies in
`Ω_∞` and is `I_l`-invariant, by `lem:infpaths`(iii). Li's `X(v; ∅) = ∂Ω(v𝔠)` corresponds
to the cylinder `Z(v)`.

**(d) The groupoid map.** Put `Φ([cd^{-1}, χ_{dz}]) = (cz, d(c) − d(d), dz)`. Lemma A(3)
and `lem:infpaths`(iii) give every arrow this form, with range `χ_{cz}`.
- **Well defined.** Suppose `cd^{-1}e = c'd'^{-1}e` with `e ⊇ x(0,N)𝔠`, where `x = dz`.
  Evaluating at `x(0,N')` for `N' ≥ N` gives equal elements of `𝔠`. So the lags agree, and
  `cz = c'z'`.
- **Injective.** Suppose the images agree. Then both maps agree on `x(0,N)𝔠` for `N` large,
  since they send `x(0,N)v` to the degree-`N+lag` prefix of the common range path followed
  by `v`. So the germs agree.
- **Surjective.** Given `(x, p−q, y)` with `σ^p x = σ^q y`, take `c = x(0,p)` and
  `d = y(0,q)`.
- **Homomorphism.** Lags add, and paths compose.
- **Homeomorphism.** `Φ` maps `[cd^{-1}, ∂Ω(d𝔠)]` onto `Z(c,d)`. These are bases of the two
  topologies: Lemma A(2) for Li's side, and the definition for Kumjian–Pask's.

So `I_l ⋉ ∂Ω ≅ G_Λ`, compatibly with the unit-space homeomorphism.

## Item 2: products

For a `k`-graph `Λ_1` and an `l`-graph `Λ_2`:
- `(Λ_1 × Λ_2)^∞ = Λ_1^∞ × Λ_2^∞`, with `σ^{(p_1,p_2)} = σ^{p_1} × σ^{p_2}`;
- `σ^p x = σ^q y` holds coordinatewise;
- `Z((λ_1,λ_2),(μ_1,μ_2)) = Z(λ_1,μ_1) × Z(λ_2,μ_2)`.

So `G_{Λ_1×Λ_2} ≅ G_{Λ_1} × G_{Λ_2}` as topological groupoids. Composed with item 1, this
is Li's observation in the proof of Corollary `cor:ProdGraphs`.

## Item 3: topology

- **Ample.** The sets `Z(λ,μ)` are compact open bisections, and there are countably many.
- **Hausdorff.** Arrows with different end paths are separated by cylinders. Arrows with the
  same end paths but different lags are separated by basic sets of different lags, which are
  disjoint.
- **Compact open sets.** A compact open subset of `Λ^∞` is a finite union of cylinders.
  These can be refined to one common degree, and cylinders of one degree are disjoint.
- **No isolated points.** Suppose each vertex has at least two edges of some colour. Every
  cylinder `Z(λ)` splits into two nonempty cylinders, so there are no isolated points and
  `Λ^∞` is a Cantor set.

## Item 4: effectiveness

- The isotropy at `x` is `{p − q : σ^p x = σ^q x}`. It is trivial iff `x` is aperiodic.
- **Density.** If `y ∈ s(λ)Λ^∞` is aperiodic, so is `λy`. Indeed, `σ^m(λy) = σ^n(λy)`
  gives `σ^{m+d(λ)}(λy) = σ^{n+d(λ)}(λy)`, which is `σ^m y = σ^n y`. So condition (A)
  gives aperiodic points in every cylinder.
- So `G_Λ` is topologically principal. For Hausdorff étale groupoids this implies essential
  principality: the interior of the isotropy is the unit space. ∎

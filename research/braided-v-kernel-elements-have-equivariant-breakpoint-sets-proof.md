- Fact 1.1: deleting strands is well defined, and cabling is injective.
- Lemma 1.2: every kernel element is a pure braid on a single tree.
- Lemma 2.1: the box set does not depend on the representative.
- Lemma 2.2: the box set is equivariant under conjugation by elements lying over T.

**ESTABLISHED.** Derivation: route `sos-certificates-cannot-see-an-infinite-central-subgroup-proof`.

**Setting.**
- `G` is a group and `z ∈ Z(G)` is central of infinite order.
- `R[G]` carries the involution `(Σ a_g g)* = Σ a_g g^{-1}`, and `Σ²R[G]` is the set of finite sums
  `Σ_i ξ_i* ξ_i`.
- `q : R[G] → R[G/⟨z⟩]` is the quotient map, with kernel `J`.
- `Δ_z = 2 − z − z^{-1} = (1 − z)*(1 − z)`. For a finite symmetric `S ⊆ G`, write
  `Δ_S = Σ_{s∈S} (1 − s)`.

**Statement.**
- **(a) Central descent.** If `Σ_i ξ_i* ξ_i ∈ J`, then each `ξ_i = (1 − z)η_i` for some
  `η_i ∈ R[G]`, and `Σ_i ξ_i*ξ_i = Δ_z Σ_i η_i*η_i`.
- **(b) Cancellation.** For `p = p* ∈ R[G]` and `m ≥ 1`: `Δ_z^m p ∈ Σ²R[G]` iff `p ∈ Σ²R[G]`.
- **(c) The two natural relative certificates collapse.** For every finite symmetric `S`, every
  `m ≥ 1` and every `λ > 0`:
  - `Δ_z^m (Δ_S − λ) ∉ Σ²R[G]`;
  - if `Δ_z^m (Δ_S² − λΔ_S) ∈ Σ²R[G]` and `S` generates `G`, then `G` has property (T).
- **(d) For `T̄`.** Let `G = T̄` (the lift of Thompson's `T` to `R`) or `G = C(C,Z) ⋊ V`, with
  `z(x) = x + 1`, respectively `z = 1_C`. Neither certificate in (c) exists, for any finite
  generating set, any `m` and any support radius. This holds because `G` surjects onto the
  infinite Haagerup group `T`, respectively `V`, and so lacks (T).
- **(e) Twisted certificates of fixed support degenerate.**
  - Let `θ ∈ R/Z` and `A_θ = C[G]/(z − e(θ))`.
  - Fix a finite `F ⊆ G/⟨z⟩`, a section `σ` of it, and a finite symmetric generating set `S`
    of `G`.
  - Let `Λ_F(θ)` be the supremum of those `λ` for which `Δ_S − λ = Σ_i ξ_i*ξ_i` holds in `A_θ`
    with each `ξ_i ∈ span σ(F)`.
  - Then `Λ_F(θ) → 0` as `θ → 0`.
  - Every such identity proves `Δ_S ≥ Λ_F(θ)` in every unitary representation with
    `π(z) = e(θ)`. So a proof of relative (T) of `(G, ⟨z⟩)` through twisted hermitian squares
    needs supports `F(θ)` that are unbounded as `θ → 0`. No finite family of fixed-radius
    semidefinite computations can give it.

**Named invariant.** The canonical trace of the quotient algebra `R[G/⟨z⟩]`
(respectively the augmentation at `θ = 0`) together with cancellation of the central
non-zero-divisor `Δ_z`. Here is where every member dies. The certificate maps to `0` in
`R[G/⟨z⟩]`, so the trace forces every square root `ξ_i` into `(1 − z)R[G]`. `Δ_z` then cancels,
and what is left is a certificate `p ∈ Σ²R[G]`, which is positive in *every* representation,
including those trivial on `z`. So it carries no relative information. For twisted certificates, the same augmentation applies
in the limit `θ → 0`, by compactness of bounded Gram matrices.

**Numerical trap (why this matters in practice).** The semidefinite programme in
`experiments/lifted-thompson-t-sos-2026-09-17/`, run for `T̄` with generators `x_0, x_1, c̃, z`
(and inverses) at radius 2, returns `λ* ≈ 0.0033`. The ℓ¹-residual of the PSD-projected Gram
matrix is `≈ 5·10^{-4}`, well below `λ*`. A naive reading would call this a relative-(T)
certificate. By (c) the exact optimum is `0` at every radius, so the value is solver error. The
certificate cannot be rounded to an exact one, because the residual would have to be absorbed by
a multiple of `Δ_z`, which (a) forbids.

**What survives.**
- Certificates for non-central normal subgroups are not affected. There `J` is generated by
  `{1 − n : n ∈ N}`, not by one central non-zero-divisor, and (a) gives no cancellation.
  An example is `Z² ⋊ SL_2(Z)`, where relative (T) holds.
- So algebraic proofs of the negative side of `brin-thompson-groups-nv-are-a-t-menable` should
  go through a non-central pair, as in the coordinate-mixing `Z² ⋊ F_2` route of
  `brin-thompson-2v-is-not-a-t-menable`. The alternative is an argument uniform in the support
  radius, for instance the dyadic twist gap `Gap_T` of
  `lifted-thompson-t-relative-t-forces-dyadic-twist-gap`, proved by representation theory rather
  than by a finite certificate.
- Positivity of `Δ_z (Δ_S − λ)` in `C*(G)` is **not** refuted. That is exactly relative (T) for
  the centre, and it is still OPEN. By the archimedean Positivstellensatz for group algebras
  (the form Ozawa uses for property (T); cited from memory and **not imported here**), such
  positivity amounts to `Δ_z(Δ_S − λ) + ε ∈ Σ²R[G]` for every `ε > 0`. By (a), those
  certificates are not in `J`, so they must have `ε`-dependent support.

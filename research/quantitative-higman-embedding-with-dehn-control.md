**Established by citation.**  Chornomaz--Wagner, arXiv:2304.07603v1,
`th-BORS-1-1-improved`, their refinement of Birget--Ol'shanskii--Rips--Sapir
Theorem 1.1 obtained by substituting the emulating machine of
`chornomaz-wagner-quasilinear-s-machine-emulation`:

> Let `G` be a finitely generated group with word problem solvable by a
> non-deterministic Turing machine with time function `<= T(n)` such that
> `T(n)^2` is superadditive.  Then, for any `eps>0`, `G` can be embedded into a
> finitely presented group `H_eps` with Dehn function bounded above by
> `n^2 T(n^2)^(2+eps)` in such a way that `G` has bounded distortion in
> `H_eps`.  Moreover, the Dehn function of `G` in `H_eps` is at most
> `T(n)^(2+eps)`.

The Dehn function of `G = <A>` in `H` with finite presentation `P` is

```text
delta_(G,H)(n) = max { Area_P(w) : w in (A u A^-1)^*, w =_G 1, |w|_A <= n }.
```

The corresponding BORS bounds are `n^2 T(n^2)^4` and `T(n)^4`.

**Quasi-optimality, and where it is not available.**  The source observes that
for a non-hyperbolic `G` with quasilinear word problem -- a finitely generated
infinite free Burnside group is their example -- the relative bound
`n^(2+eps)` is optimal modulo `eps`: `G` cannot be embedded with bounded
distortion into a hyperbolic group, so the isoperimetric gap of Gromov and
Ol'shanskii forces the Dehn function of `G` in any finitely presented host to
be at least quadratic under a quasi-isometric embedding.

**Scope gate, stated so this is not mistaken for a Higman replacement.**  The
hypothesis is a *decidable* word problem with a time bound.  Higman's theorem
and Chiodo's torsion-preserving refinement (`torsion-free-higman-embedding`)
require only a recursive presentation, and therefore cover groups this theorem
cannot touch.  Nothing in this repository's finitely-presented lane should be
rewritten to depend on this node.

## Setting

We work in the layered setting of `copy-constraints-make-simulation-skeleton-and-data-commute`:
`Λ = Λ_0 x Z^2`, an SFT `X ⊆ (H x B x C)^Λ` with window `D_X`, alignment (Al) and copying (Cp).
Write `X_HB` for the image of `X` under forgetting `C`. The *data shadow* is
`Y = { λ ↦ x_B(λ, 0) : x ∈ X } ⊆ B^(Λ_0)`, a `Λ_0`-subshift.

**Bounded determination (BD_R).** There is a map `F` from `(H x B)`-patterns on `B_R` to `C` such
that `x_C(q) = F(x_HB restricted to qB_R)` for every `x ∈ X` and every site `q`.

## Theorem

1. **Unique completion is bounded determination.** (BD_R) holds for some `R` if and only if the map
   `X → X_HB` that forgets `C` is injective.
2. **Rigidity transfers.** Assume (BD_R) and (R1) (the skeleton SFT `Ω_H` is `D_H`-quantum rigid),
   and let `D >= max(D_X, D_H, R)`. In every `D`-quantum family, each `E_a(q)` lies in the algebra
   generated by skeleton and data projections. So `X` is `D`-quantum rigid if and only if the data
   projections `B_b(λ)` pairwise commute in every `D`-quantum family. Under the uniform-reading
   hypothesis (R2) they always do.
3. **Such a simulation only simulates SFTs.** Under (BD_R) alone, `Y` is a finite union of
   `Λ_0`-SFTs defined by patterns on balls of radius `R + D_X`. If `Y` is minimal, it is an SFT.
4. **Corollary.** Let `X` be an aligned plane-constant simulation whose data shadow is a minimal
   subshift that is not of finite type, as (M1) requires for every useful input. Then (BD_R) fails
   for every `R`. Equivalently, there are `x ≠ x'` in `X` with the same skeleton and data layers,
   differing only in `C`.

## Proof

**1.**
- *Forward.* (BD_R) makes the map injective.
- *Converse.* If the map is injective, its inverse is continuous, because the spaces are compact. So
  `x ↦ x_C(1)` is a continuous function on `X_HB` with values in a finite set. It is therefore
  locally constant, and by compactness it depends on finitely many coordinates, say `B_R`.
  Equivariance gives the same `R` at every site.

**2.** Fix `q`. For each `(H x B)`-pattern `κ` on `qB_R`, let `Π_κ` be the product of the
corresponding layer projections. These sit in one ball, so they commute; and `Σ_κ Π_κ = I`.
- *No wrong value.* No `x ∈ X` shows `κ` together with `x_C(q) ≠ F(κ)`. Expanding into full letters
  on `qB_D` as in the copy lemma, (Q3) gives `C_c(q) Π_κ = 0` whenever `c ≠ F(κ)`.
- *The formula.* All factors commute by (Q2), so `C_c(q) = Σ_{κ : F(κ) = c} Π_κ`.
- *Conclusion.* `E_a(q) = H_{a_H}(q) B_{a_B}(q) C_{a_C}(q)` is then a polynomial in skeleton and data
  projections. Skeleton projections commute with each other by (R1), and with data projections at a
  common site (items 2–3 of the companion node). So everything commutes as soon as the data
  projections do. Item 4 of the companion node supplies this under (R2).
- *Caveat.* A reading radius beyond `R` is compatible with (BD_R) only if far data are determined by
  near data. So in useful simulations item 2 is applied through its "iff", not through (R2).

**3.** Let `B' ⊆ Z^2` and `B'' ⊆ Λ_0` be the balls of radius `R' = R + D_X`.
- *Legality is local.* Whether `x` is legal at `(λ, z)` depends only on `x_H` near `(λ, z)` and
  `x_B` near `(λ, z)`. By (Al) and (Cp), these depend only on `h = x_H(1, ·)` restricted to
  `z + B'`, and on `y = x_B(·, 0)` restricted to `λB''`. So legality is a predicate
  `Legal(u, w)` with `u ∈ L_{B'}(Ω_H)` and `w` a `B''`-pattern.
- *Build a configuration.* Conversely, given `h ∈ Ω_H` and `y ∈ B^(Λ_0)`, put `x_H(λ, z) = h(z)`,
  `x_B(λ, z) = y(λ)` and `x_C = F`. This `x` lies in `X` if and only if every window is legal.
- *The union.* So `y ∈ Y` if and only if `L_{B''}(y) ⊆ W(L_{B'}(h))` for some `h ∈ Ω_H`, where
  `W(U) = { w : Legal(u, w) for all u ∈ U }`. There are only finitely many sets
  `U = L_{B'}(h) ⊆ L_{B'}(Ω_H)`. Hence `Y = ∪_U SFT(W(U))`, a finite union of SFTs.
- *Minimal case.* If `Y` is minimal, each nonempty piece is a closed invariant subset of `Y`, so it
  equals `Y`. Hence `Y` is an SFT.

**4.** This follows from 3 and 1. ∎

## Reading for the master route

- (M1) exists to turn a non-SFT effective `Y` into an SFT one level up. By item 4 it must use
  computation that the skeleton and data do not determine. In Durand–Romashchenko fixed-point
  tilings this is the top-down, infinite-level data of macrotiles. The corollary proves it is forced;
  it is not an artifact of that construction.
- Together with the companion node: in every `D`-quantum family of a rigid-skeleton, uniform-reading
  simulation, all non-commutativity lives in `C`. It is carried by the forced ambiguity pairs
  `x ≠ x'` with equal `(H, B)`-layers.
- **Kill test.** Suppose some such `x` has two ambiguity modifications `x^1, x^2 ∈ X`. Each agrees
  with `x` off a set `S_i`, and `d(S_1, S_2) > 2D`. Then `x^1, x^2` form a wall certificate, the
  standard two-basis family on `k^2`, and `X` is not `D`-rigid.
- **Design requirement.** So a rigid simulation needs *unsplittable ambiguity*. At every large scale,
  no two far-apart pieces of an ambiguity may be switched independently. This is the simulation form
  of the golden–silver warning, and the open target is
  `plane-constant-simulation-computation-layers-are-quantum-rigid`.

## Lesson for general BH

The G2 crux cannot be dodged by clever simulation: a simulation that computes nothing beyond its
inputs is rigid for free, but it only simulates SFTs. Every useful simulation must carry information
not locally determined by its skeleton and data. That information is exactly where rigidity must be
proved. The conjectured rigidity of fixed-point tilings with locally unique parse (G2-fp on
`board/SYNTHESIS.md`) must therefore be proved for the undetermined infinite-level data, the limit
step of the level induction. The finite levels are the easy part.

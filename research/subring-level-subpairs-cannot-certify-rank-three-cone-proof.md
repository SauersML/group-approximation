Notation is as in [[subring-level-subpairs-cannot-certify-rank-three-cone]].  `Q_k = { m ∈ N^d : |m| ≥ k }`.
`SL_d(Z)` acts on `R` by `σ(x^m) = x^(σm)`, and on matrices entrywise; in `G`, `σ g σ^-1 = σ(g)`.  So for
`t = u σ ∈ G` and `X ∈ M_3(R)` put `Ad(t) X = u σ(X) u^-1`; then `t g t^-1 = Ad(t) g` and
`Ad(t)(g - 1) = t g t^-1 - 1`.  Throughout, `B ≤ G` contains `U_k`, `k ≥ 1`.  Since `U_k ≤ Gamma`, `U_k ≤ C`.

## 1. (X1): compressors are nonnegative

Let `t = u σ ∈ P_C`, `i ≠ j`, `m ∈ Q_k`.  Then `e_ij(x^m) ∈ C`, so

```text
t e_ij(x^m) t^-1 = u (1 + x^(σm) E_ij) u^-1 = 1 + x^(σm) X ,   X = u E_ij u^-1 ,
```

lies in `C ⊆ Gamma ⊆ M_3(R_+)`.  So `x^(σm) X ∈ M_3(R_+)`.  `X ≠ 0`, being conjugate to `E_ij`.  Pick an entry
`X_ab ≠ 0` and a monomial `x^s` occurring in it.  Multiplication by `x^(σm)` shifts supports, so
`x^(σm + s)` occurs in `x^(σm) X_ab ∈ R_+`, and `σm + s ∈ N^d`.

Fix `l ∈ [d]` and take `m = n e_l`, `n ≥ k`.  Then `n σ e_l + s ∈ N^d` for every `n ≥ k`.  If some coordinate
`(σ e_l)_c` were negative, `n (σ e_l)_c + s_c` would be negative for large `n`.  So `σ e_l ∈ N^d` for every
`l`, and `σ ∈ M_d(N)`.

If `C` is infranormal, `P_C` generates `B`, so its image generates `H_B`, and that image lies in
`H_B ∩ M_d(N)`.  ∎

*Remark.*  (N1) of [[galois-psd-monomial-subpair-has-no-infranormal-trace]] used a fixed `m` and needed the
coefficient of `x^(σm)` in the `(i, j)` entry to survive, which required `u ∈ 1 + M_3(F_q[P])` with `0 ∉ P`.
Here `u` is arbitrary.  A fixed monomial `x^s` of `X` is only translated by `x^(σm)`, and `m → ∞` along a
coordinate ray detects the sign of `σ e_l`.  Salience is not used.

## 2. (X2): finite projection

*Lemma 2.1.*  A nonnegative `σ ∈ GL_d(Z)` of finite order is a permutation matrix.  This is Lemma 4.2 of
[[nonneg-generated-kazhdan-groups-have-nonsalient-cones-proof]]: `σ^-1` is a power of `σ`, so it is nonnegative.
A nonnegative integer matrix with nonnegative integral inverse is a permutation matrix.

Let `H_B` be finite and `C` infranormal.  By (X1), `H_B` is generated by nonnegative elements.  They have finite
order, so by Lemma 2.1 they are permutation matrices, and `H_B` consists of permutation matrices.

*Lemma 2.2.*  Let `t = u σ ∈ P_C` with `σ` a permutation matrix.  Then `Ad(u)` maps `M_3(R_+)` onto itself.

*Proof.*  Let `X = u E_ij u^-1`, `i ≠ j`, and let `x^s` occur in an entry of `X`.  By §1,
`σm + s ∈ N^d` for every `m ∈ Q_k`.  Fix a coordinate `c`.  As `d ≥ 2` and `σ e_l = e_(π l)` for a permutation
`π`, there is an `l` with `π l ≠ c`.  For `m = k e_l`, `(σm)_c = 0`, so `s_c ≥ 0`.  Hence `s ∈ N^d`, and
`X ∈ M_3(R_+)`.

The `E_ij`, `i ≠ j`, generate `M_3(F_q)` as a ring, since `E_ii = E_ij E_ji`.  `Ad(u)` is a ring homomorphism, so
`Ad(u) M_3(F_q) ⊆ M_3(R_+)`.  It is `R`-linear, so `Ad(u) M_3(R_+) ⊆ M_3(R_+)`.  Write `T ∈ M_9(R_+)` for the
matrix of `Ad(u)|_(M_3(R_+))` in the basis `E_ab`.  The trace form `(X, Y) ↦ tr(XY)` has Gram matrix
`tr(E_ab E_cd) = δ_bc δ_ad` in that basis, a permutation matrix `J` with `det J = ± 1`.  `Ad(u)` preserves the
trace form, so `T^T J T = J` and `(det T)^2 = 1`.  So `T ∈ GL_9(R_+)`, and `Ad(u) M_3(R_+) = M_3(R_+)`. ∎

Now `Ad(u)` preserves `M_3(R_+)` and the determinant, so `u Gamma u^-1 = Gamma` with `Gamma = SL_3(R_+)`.  The
permutation `σ` maps `R_+` onto itself, so `σ Gamma σ^-1 = Gamma`.  So every `t ∈ P_C` normalises `Gamma`, and,
being in `B`, it normalises `B ∩ Gamma = C`.  The normaliser `N_B(C)` is a subgroup containing `P_C`.  If `P_C`
generates `B`, then `N_B(C) = B`, so `C` is normal in `B`. ∎

## 3. (X3): the subring class

Assume `E_B = EL_3(A)` for an `F_q`-subalgebra `A ⊆ R`.

*The span.*  Let `Λ` be the `F_q`-span of `{ g - 1 : g ∈ E_B }`.  From
`gh - 1 = (g - 1) + (h - 1) + (g - 1)(h - 1)`, `Λ` is closed under products, so it is an `F_q`-algebra.
Each generator `e_ij(a)`, `a ∈ A`, lies in `1 + M_3(A)`, and `1 + M_3(A)` is closed under products because `A` is
a ring.  The group `E_B` is generated by these elements as a monoid (`e_ij(a)^-1 = e_ij(-a)`), so
`E_B ⊆ 1 + M_3(A)` and `Λ ⊆ M_3(A)`.

*Invariance.*  `E_B = B ∩ EL_3(R)` is normal in `B`.  For `t = u σ ∈ B`, `Ad(t)` is `F_q`-linear and maps
`{ g - 1 : g ∈ E_B }` onto itself, so `Ad(t) Λ = Λ`.

*The scalars.*  Let `Z = { f ∈ R : f · 1 ∈ Λ }`.  It is an `F_q`-subspace, closed under products since `Λ`
is, and `Z ⊆ A` since `Λ ⊆ M_3(A)`.  For `t = u σ ∈ B` and `f ∈ Z`, `Ad(t)(f · 1) = u σ(f) u^-1 = σ(f) · 1`,
so `σ(f) ∈ Z`.  Hence `σ(Z) ⊆ Z` for every `σ ∈ H_B`.

*Monomials of high degree.*  For `m, m' ∈ Q_k`, the elements `x^m E_ab = e_ab(x^m) - 1` lie in `Λ`, and so do the
products `x^m E_12 · x^(m') E_21 = x^(m+m') E_11`, `x^m E_21 · x^(m') E_12 = x^(m+m') E_22` and
`x^m E_31 · x^(m') E_13 = x^(m+m') E_33`.  Their sum is `x^(m+m') · 1`.  Every `n ∈ Q_(2k)` splits as `m + m'`
with `m, m' ∈ Q_k`, so `x^n ∈ Z` for all `n ∈ Q_(2k)`.

*A line gives the unit.*  Suppose `v ≠ 0` and `± v ∈ K0 = cone(H_B · R_+^d)`.  Adding the two expressions
gives `0 = Σ_s c_s w_s` with `c_s > 0` and each `w_s = σ_s e_(i_s)`, `σ_s ∈ H_B`, a nonzero integer vector.  The
set of `c ∈ R_(≥0)^S` with `Σ c_s w_s = 0` is a rational polyhedral cone containing a point with all
coordinates positive, so it contains a rational point with all coordinates positive.  Clearing denominators,
`Σ n_s w_s = 0` with `n_s ∈ Z_(>0)`.  Now `x^(2k e_(i_s)) ∈ Z`, so `x^(2k w_s) = σ_s(x^(2k e_(i_s))) ∈ Z`, and

```text
1 = x^0 = Π_s ( x^(2k w_s) )^(n_s) ∈ Z ⊆ A .
```

So `e_ij(1) ∈ EL_3(A) = E_B ≤ B` for all `i ≠ j`.  These lie in `Gamma`, so `EL_3(F_q) = SL_3(F_q) ≤ C`, and
`psi(C) ⊇ psi(SL_3(F_q)) = PSL_3(F_q) = F`. ∎

## 4. (X4)

Let `B ⊇ U_k` have `E_B = EL_3(A)`.

- If `K0 = cone(H_B · R_+^d)` contains a line, then `psi(C) = F` by §3, and `C_F(F) = 1` since `F` is
  centreless.  The centraliser condition fails.
- If `K0` is salient, and `C` is infranormal and `B` Kazhdan, then `H_B`, a quotient of `B`, is Kazhdan, and it is
  generated by nonnegative matrices by §1.  Kazhdan groups are character-free in the sense of
  [[nonneg-generated-kazhdan-groups-have-nonsalient-cones]].  So (W2) there makes `H_B` finite, and §2 makes
  `C` normal in `B`.

In either case `B` is not a Kun-Thom certificate. ∎

*The monomial case.*  For `B_(H,k)`, (M0) of [[monomial-origin-level-subpairs-cannot-certify-rank-three-cone]]
gives `E_B = Ũ = EL_3(F_q[P])` and `H_B = H`.  So (X4) contains (W3) of the salience node.  §2 also re-proves
(M4) without the profinite-closure lemma.

## 5. Where it stops

§1 and §2 hold for every `B ⊇ U_k`.  §3 uses `E_B = EL_3(A)` at one point only: to pass from `1 ∈ Z`, a
statement about the linear span `Λ`, to the group elements `e_ij(1) ∈ E_B`.  For a general `B ⊇ U_k` with
infinite `H_B`, the argument of §3 still gives `1 ∈ Z`.  More: let `R^M ⊆ K0` be the coordinate subspace of
(W2) and `l ∈ M`.  The relation `-e_l ∈ K0`, run through §3, gives `x^(-2kN e_l) ∈ Z` for some `N ≥ 1`.  `Λ` is
a module over the algebra `Z`, and `x^(2kN e_l) E_ab ∈ Λ`, so `E_ab = x^(-2kN e_l) · x^(2kN e_l) E_ab ∈ Λ`.
So `Λ ⊇ M_3(F_q)`.  Whether a subgroup `E_B` with this span can still have
`psi(E_B ∩ Gamma)` with a nontrivial centraliser is the residual question.  (M1) of the monomial node answers it
when the line lies in the cone of `B ∩ SL_d(Z)` rather than of the projection `H_B`.

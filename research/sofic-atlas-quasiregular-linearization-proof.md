Choose a witnessing sequence for the sofic action, with finite root sets
`V_n`, good sets `S_n subset V_n` of relative size tending to one, finite
label sets `B_n`, approximately multiplicative maps

```text
phi_n:A->Sym(V_n),
```

and injective moving charts `pi_(n,s):E_n->B_n`, where the finite windows
`E_n` exhaust `A/C`.  Consider the Hilbert ultraproduct of

```text
H_n=l2(V_n x B_n, |V_n|^(-1) counting measure)
```

and precomposition in the `V_n` coordinate.  Approximate multiplication
does not define an action on every vector of this Hilbert ultraproduct
(vectors could concentrate on the exceptional roots).  We use it only on
the closed subspace generated by the uniformly bounded chart vectors below;
there every fixed finite multiplication error has norm tending to zero.

For fixed `x in A/C`, once `x in E_n`, define

```text
xi_(x,n)(s,b)=1_(b=pi_(n,s)(x))       (s in S_n),
```

and define it arbitrarily with the same norm off `S_n`.  Its ultraproduct
class `xi_x` is a unit vector.  Chart injectivity gives, for `x!=y`,

```text
<xi_x,xi_y>=0,
```

because the two one-hot labels differ on `S_n`, whose relative size tends
to one.  Chart covariance gives

```text
Pi(a)xi_x=xi_(ax)
```

(up to the harmless inverse convention in the definition), since the
identity holds whenever both chart roots are good, again a set of relative
size tending to one.  On finite linear combinations of the `xi_x`, both
this covariance error and the multiplicativity error tend to zero.
Consequently precomposition descends on their closed span to an exact
unitary representation `Pi`.  The map `delta_x |-> xi_x` extends to an
isometric `A`-intertwiner from `l2(A/C)` into that representation.  This
proves `(SQA1)`.

Set `v=xi_C`.  Since `cC=C`, `Pi(c)v=v` for every `c in C`.  If `h notin C`,
then `hC!=C`, so `(SQA1)` gives

```text
||Pi(h)v-v||^2=2.
```

Finally `b(a)=Pi(a)v-v` is, by definition, the coboundary `delta_0 v`; it
satisfies the cocycle identity and represents zero in first cohomology.
For any cellular cochain complex, `delta_1 delta_0=0`, so every
degree-one Garland/coboundary-expansion statement is fully compatible with
this packet.  This proves `(SQA2)`--`(SQA3)` and the stated firewall.

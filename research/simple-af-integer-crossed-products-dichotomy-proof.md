Notation: `G = K_0(D)`, a countable simple dimension group, noncyclic because
`D` is non-elementary.  `E: A -> D` is the canonical faithful conditional
expectation, `u` the implementing unitary, and `S = S(G, x_0)` the compact
state space for a fixed order unit `x_0 > 0`.  Standard facts used:

* (EHS) For a simple dimension group, `g > 0` iff `s(g) > 0` for all
  `s in S`, and for a noncyclic one the image of `G` in `Aff(S)` is dense
  (Effros--Handelman--Shen; Goodearl, *Partially ordered abelian groups with
  interpolation*).
* (GH) A preordered abelian monoid with order unit `v` has a state `f` with
  `f(v) = 1` iff `(n+1)v <= nv` fails for every `n` (Goodearl--Handelman 1976;
  see also Blackadar--Rordam, J. Algebra 1992).  The numbering was not verified.

**(P1) Simplicity and compression into `D`.**  `A` is simple (Kishimoto;
Olesen--Pedersen).  Let `a in A_+` be nonzero.  By Kishimoto's lemma (the
argument of Lemma 5.4 in Rordam 2005, *The real rank of certain simple
C\*-algebras*) there are `h in D_+` and `lambda > 0` with
`||hah - hE(a)h|| < lambda < ||hE(a)h||`.  The hereditary subalgebra of `D`
generated by `b = (hE(a)h - lambda)_+ != 0` contains a nonzero projection `p`,
since `D` is AF.  Rordam's Lemma 5.1 writes `b = s^* h a h s` and identifies
`her_A(b) = her(x^* x)`, isomorphic to `her(x x^*) subset her_A(a)` for
`x = a^(1/2) h s`.  This isomorphism is implemented by the partial isometry of
the polar decomposition of `x`, so it carries `p` to an equivalent projection.
So every nonzero hereditary subalgebra of `A` contains a projection equivalent
in `A` to a nonzero projection of `D`.

**(P2) The coinvariant monoid.**  Define `M_alpha` as in the claim.  The
relation `y ~ y'` (one-step moves) is reflexive, symmetric (use `-k_i`) and
additive.  It is transitive: given `y = sum c_i`, `sum alpha^(k_i) c_i = sum d_j`
and `y'' = sum alpha^(l_j) d_j`, refine
`sum_i alpha^(k_i) c_i = sum_j d_j` (Riesz refinement in `G^+`) as
`alpha^(k_i) c_i = sum_j f_ij` and `d_j = sum_i f_ij`.  Then
`y = sum_ij alpha^(-k_i) f_ij` and `y'' = sum_ij alpha^(l_j + k_i)(alpha^(-k_i) f_ij)`.
So `~` is the congruence generated by `y ~ alpha(y)`.  Since
`alpha(p) = u p u^*` is equivalent to `p`, the map `[p] |-> [p]` is a monoid
map `M_alpha -> V(A)`.  It sends nonzero elements to nonzero elements, and
infinite elements (`[x] = [x] + [e]`, `e != 0`) to infinite projections.
`M_alpha` is simple because `G` is.

**(P3) Coinvariant Tarski lemma.**  Suppose `Nx ~ Nx + e` with `x, e > 0`.
One-step form: `Nx = sum_(i<=m) c_i` and `Nx + e = sum_i alpha^(k_i) c_i`.
Refine `sum_i c_i = x + ... + x` (`N` terms) as `c_i = sum_(j<=N) c_ij` with
`sum_i c_ij = x` for each `j`.  Put `eta = min_S e^ > 0` and
`L = max_i sup_(s in S) s(alpha^(k_i) x_0) < infinity`.  Every positive
functional `s o alpha^k` is `lambda s'` with `s' in S` and `lambda <= L`.
Fix `epsilon > 0` with `m N^2 (L+1) epsilon < eta / 2`.  By (EHS) choose
`d_ij in G^+` such that `d_ij = 0` if `c_ij = 0`, and otherwise
`0 < N d_ij^ < c_ij^` and `c_ij^ - N d_ij^ < N epsilon` on `S`.  Then

* `y = sum_ij d_ij` satisfies `N y <= N x`, so `r = x - y >= 0` by
  unperforation;
* `x ~ x' := sum_ij alpha^(k_i)(d_ij) + r` by one move;
* for `s in S`,
  `N s(x' - x) = sum_ij [s(alpha^(k_i) N d_ij) - s(N d_ij)]`
  `= s(e) - sum_ij [s(alpha^(k_i)(c_ij - N d_ij)) - s(c_ij - N d_ij)]`.
  Here `sum_ij [s(alpha^(k_i) c_ij) - s(c_ij)] = s(Nx + e) - s(Nx) = s(e)`,
  and the error term has absolute value at most
  `m N (L + 1) N epsilon < eta / 2`.

Hence `s(x' - x) > 0` for all `s`, so `e' = x' - x > 0` by (EHS), and
`[x] = [x + e']` is infinite in `M_alpha`.

**(P4) Dichotomy in `M_alpha`.**  Let `x in G^+` be nonzero.  If `M_alpha` has
a state `f` with `f([x]) = 1`, then `f` pulls back to an additive
`alpha`-invariant map `G^+ -> R^+`, hence to a positive `alpha`-invariant
homomorphism `G -> R`.  Otherwise (GH) gives `n` and `t in G^+` with
`(n+1)x + t ~ nx`.  Then `nx ~ nx + (x + t)`, so `n[x]` is infinite, and (P3)
makes `[x]` infinite.

**(P5) Case 1.**  A nonzero positive `alpha`-invariant homomorphism
`G -> R` is the `K_0` map of a unique densely finite lower semicontinuous
trace `tau` on the AF algebra `D`.  Uniqueness forces `tau o alpha = tau`.
Then `tau o E` is a nonzero lower semicontinuous trace on `A`.  Its null ideal
is a proper closed ideal, hence zero, so it is faithful.  Its domain is a
nonzero ideal and contains the Pedersen ideal.  So `(tau o E) tensor Tr` is
finite and faithful on every projection of `A tensor K`, and `p ~ p' <= p`
forces `p = p'`.  Thus `A` is stably finite.  Conversely, an invariant trace
gives a state on `M_alpha` at every `[x]` with finite nonzero trace.

**(P6) Case 2.**  If `D` has no nonzero invariant densely finite trace, (P4)
and (P5) make every nonzero `[p] in G^+` infinite in `M_alpha`, so every
nonzero projection of `D tensor K` is infinite in `A tensor K` by (P2).  By
(P1) every nonzero hereditary subalgebra of `A` contains a projection
equivalent to such a `p`, which is infinite.  For simple `A` this is pure
infiniteness.  A purely infinite algebra is not stably finite, so the two
cases are exclusive.

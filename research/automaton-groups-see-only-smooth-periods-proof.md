Lane proof (bh-free-16, 2026-09-18). Notation as in the claim.

## Step 1. One finite-state automorphism

Let `h` be finite-state with state set `Σ_h ⊆ Σ`. Let `x` be eventually periodic, with preperiod `a` and period `p`,
and write `B` for the periodic block of length `p`.
- **The period map.** Reading `B` from a state `q` ends in a state `F(q)`, which defines `F : Σ_h → Σ_h`.
- **The state sequence.** Let `q_j` be the state of `h` at position `a + jp`. Then `q_(j+1) = F(q_j)`, so `(q_j)` is
  eventually periodic, with cycle length `c <= |Σ_h| <= s`.
- **The output.** The digits written at positions `a + jp, …, a + jp + p − 1` depend only on `(q_j, B)`. So `h(x)` is
  eventually periodic with period dividing `p·c`, where `c <= s`.

## Step 2. Words

- **Induction.** Every `g ∈ Γ` is a product `h_1 ⋯ h_k` of generators and inverses, each finite-state with states in
  `Σ`. Apply `h_k` first and use Step 1 repeatedly: `g(x)` has period dividing `p·c_1 ⋯ c_k` with every `c_i <= s`.
- **Smoothness.** `N = c_1 ⋯ c_k` is a product of integers `<= s`, hence `s`-smooth. This is item 1.

## Step 3. Periods and denominators

- **Periods give denominators.** If `y ∈ Z_m` has eventually periodic digits, with preperiod `a` and period `P`, then
  `y = A + m^a B/(1 − m^P)` with `A, B ∈ Z`. So `(m^P − 1) y ∈ Z`.
- **Denominators give orders.** If a prime `ℓ ∤ m` divides the reduced denominator of such a `y`, then
  `ℓ | m^P − 1`, i.e. `ord_ℓ(m) | P`.
- **Spans.** A `Z`-combination of points of periods `P_1, …, P_r` has denominator dividing `lcm_i (m^(P_i) − 1)`. So
  if `ℓ` divides its denominator, then `ℓ | m^(P_i) − 1` for some `i`.

## Step 4. Zsigmondy

**Zsigmondy's theorem.** For `a > 1` and `n >= 3`, `a^n − 1` has a prime divisor `ℓ` with `ord_ℓ(a) = n`, except
`(a, n) = (2, 6)`.

- **The primes.** Take `n` prime with `n > max(s, 2)`, and `ℓ` as above for `a = m`. Then `ℓ ∤ m`, so `ℓ ∉ S`.
  Distinct `n` give distinct `ℓ`.
- **The orbit of `0`.** `0` has period `p = 1`, so by Step 2 every point of `Γ·0` has an `s`-smooth period `P`.
- **Why `1/ℓ` is missed.** If `ℓ` divided the denominator of an element of `Z`-span`(Γ·0)`, then by Step 3
  `n = ord_ℓ(m)` would divide some `s`-smooth `P`. That is impossible, since `n` is a prime `> s`. So `1/ℓ` is not
  in the span.
- **Item 2(a).** `τ_(1/ℓ)(0) = 1/ℓ`, so `τ_(1/ℓ) ∉ Γ`. The smooth-order form is the same argument applied to any `ℓ`.
  Together with part 2 of `odometer-root-hosts-are-non-affine-and-non-contracting` (the `ℓ`-th roots of the odometer
  are exactly `τ_(1/ℓ)`), `Γ` contains no `ℓ`-th root of the odometer.
- **Item 2(b).** For `f = Σ n_g g ∈ M(Γ)` constant with value `c`, we have `c = f(0) = Σ n_g g(0)`, which lies in
  `Z`-span`(Γ·0)`. So `1/ℓ ∉ M(Γ)`. (`G_Γ` is generated by the adder, which has two states, and `id × Γ`, so it is
  itself an automaton group on `T_4`.)
- **Item 2(c).** In `V_m(Γ)`, a neighbourhood of any point is mapped by `α z ↦ β h(z)` with `h ∈ Γ`. The tail of `x`
  after the prefix `α` is eventually periodic with the same period `p`. Then `h` multiplies that period by an
  `s`-smooth factor, and prepending `β` does not change the eventual period. The same holds colourwise in `dV_Γ`.

## Step 5. Möbius pieces over a finitely generated ring

- **The piece group.** A piece of a product of generators on a small cylinder is the product of the corresponding
  pieces. So all pieces of elements of `H` lie in the group `Δ` generated by the pieces of the generators and their
  inverses.
- **Integrality.** The pieces of the generators are represented in `GL_2(R)`, so every element of `Δ` has a
  representative in `GL_2(R)`, with determinant in `R^×`.
- **Rigidity.** If `τ_(1/ℓ) ∈ H`, it agrees on an open set with some `δ ∈ Δ`. Möbius maps that agree on an open set
  are equal, so `δ = [[1, 1/ℓ], [0, 1]]` projectively. Write its representative as `λ[[1, 1/ℓ], [0, 1]] ∈ GL_2(R)`.
  Then `λ ∈ R`, `λ/ℓ ∈ R` and `λ² ∈ R^×`, so `λ ∈ R^×` and `1/ℓ ∈ R`.
- **Finitely many primes.** A finitely generated ring `R` of characteristic 0 contains `1/ℓ` for only finitely many
  primes `ℓ`. Indeed, by Noether normalization over `Z[1/N]` for suitable `N`, `R[1/N]` is integral over a polynomial
  ring over `Z[1/N]`. So `R/ℓR ≠ 0`, and `ℓ ∉ R^×`, for every `ℓ ∤ N`. This is the same generic-freeness step as in
  `fg-linear-groups-have-roots-at-finitely-many-primes`. ∎

## Remarks

- **Sharpness of the bound.** `s` can be replaced by the largest number of states of a single generator. The
  smooth factor `N` really does grow: `μ_3^k τ_1 μ_3^(-k) = τ_(1/3^k)` has period `2·3^(k−1)`.
- **Asynchronous transducers are not covered.** Finite asynchronous transducers can change periods additively,
  because output lengths vary. The rational group itself contains `PGL_2(Q)`
  (`pgl-2-q-embeds-in-the-rational-group`). So the finite-state hypothesis here means synchronous (tree
  automorphisms), and prefix replacements are allowed only as in item 2(c).

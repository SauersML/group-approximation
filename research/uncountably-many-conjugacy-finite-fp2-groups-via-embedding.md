By `uncountably-many-torsion-free-groups-of-type-fp` there are torsion-free groups
`H_i` of type FP, finitely generated, pairwise non-isomorphic, `i` in an
uncountable set. By `torsion-free-fp-groups-embed-in-fp2-conjugacy-finite-groups`
each `H_i` lies in a torsion-free, conjugacy-finite group `Γ_i` of type FP_2.

Counting: each `Γ_i` is countable, so it has countably many finite subsets and
hence countably many finitely generated subgroups. If the `Γ_i` realized only
countably many isomorphism types, the `H_i`, each isomorphic to a finitely
generated subgroup of one of them, would realize only countably many types. So
the `Γ_i` realize uncountably many types, as required.

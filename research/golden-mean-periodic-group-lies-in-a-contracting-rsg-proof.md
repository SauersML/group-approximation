## Notation

- **Blocks.** Call `2`, `11` and `12` blocks. A finite word is *complete* if it is a concatenation of blocks.
  Otherwise it is *dangling*, meaning it is `s_0 1` with `s_0` complete.
  - Greedy parsing from the left shows that every word is exactly one of these, with a unique factorization.
  - Every point of `X^ω` factors uniquely as an infinite concatenation of blocks.
- **The group `K`.** Let `K = {1, b, c, d}`, writing `b = b_0`, `c = c_0`, `d = d_0`.
  - For `κ ∈ K` let `σ_κ` be the transposition of the words `2` and `11` when `κ ∈ {b, c}`, and the identity on
    `{2, 11}` when `κ ∈ {1, d}`.
  - Let `1⁺ = 1`, `b⁺ = c`, `c⁺ = d`, `d⁺ = b`.
  - By l.1410–1413, every `κ ∈ K` satisfies the *block rule*:
    `κ(2y) = σ_κ(2)y`, `κ(11y) = σ_κ(11)y`, `κ(12y) = 12κ⁺(y)`.   (BR)
- **K-pieces and K-maps.**
  - A *K-piece* is a map `C_u → X^ω`, `uw ↦ vκ(w)`, with `κ ∈ K`.
  - A map `f` on a cone `C_u` is a *K-map* if `C_u` has a finite partition into cones `C_{u_j}` on each of which
    `f` is a K-piece `u_j w ↦ v_j κ_j(w)`.
  - Let `𝒢` be the set of homeomorphisms of `X^ω` that are K-maps.
- **The set `N_0`.** Let `N_0 = {1, b, c, d, b̂, ĉ, d̂}`, where `κ̂ = κ|_1`.

## Lemma 1: `K` is a Klein four group

This is l.1442. A direct check: output is produced block by block from the input, so for each point the recursion
(BR) determines the value of the map uniquely.
- The triples `(b², c², d²)` and `(1, 1, 1)` satisfy the same recursion, so every `κ ∈ K` is an involution.
- The triples `(bc, cd, db)` and `(d, b, c)` satisfy the same recursion, because `σ_b σ_c = 1 = σ_d` and
  `σ_c σ_d = σ_b`. So `bc = d`, `cd = b` and `db = c`.

In particular `κ^{-1} = κ` and `λκ ∈ K` for all `κ, λ ∈ K`.

## Lemma 2: `K` on cones

Let `κ ∈ K` and let `s` be a word.
- (a) If `s` is complete, then `κ(sy) = s'κ'(y)` for all `y`, with `s'` complete and `κ' ∈ K`. This follows from
  (BR) by induction on the number of blocks.
- (b) If `s` is dangling, then `s1` and `s2` are complete. So `κ` restricted to `C_s = C_{s1} ⊔ C_{s2}` consists of
  two K-pieces, by (a).

In both cases `κ|_{C_s}` is a K-map, and the image of each piece is a cone, because `κ'(X^ω) = X^ω`.

## Lemma 3: the local actions of `K` lie in `N_0`

Let `κ ∈ K` and let `α` be a word.
- **`α` complete.** By Lemma 2(a), `κ(C_α) = C_{s'}`, so `κ̄(α) = s'` and `κ|_α = κ' ∈ K`.
- **`α = s_0 1` with `s_0` complete.** Then `κ(s_0 1 y) = s'κ'(1y)`. So `κ̄(α) = s'·κ̄'(1)` and
  `κ|_α = κ'|_1 ∈ {1|_1, b̂, ĉ, d̂}`, and `1|_1 = 1`.

Explicitly:
- `b(C_1) = C_2 ⊔ C_{12}` and `d(C_1) = C_{11} ⊔ C_{12} = C_1`.
- `b̂(1u) = 2u` and `b̂(2u) = 12c(u)`.
- `ĉ(1u) = 2u` and `ĉ(2u) = 12d(u)`.
- `d̂(1u) = 1u` and `d̂(2u) = 2b(u)`.

## Lemma 4: every K-map on `X^ω` is rational, with nucleus in `N_0`

Let `f` have pieces `u_j w ↦ v_j κ_j(w)`, where the cones `C_{u_j}` partition `X^ω`.
- If `C_α ⊆ C_{u_j}`, write `α = u_j t`. Then `f(u_j t y) = v_j κ̄_j(t)·κ_j|_t(y)`. So `f̄(α) = v_j κ̄_j(t)`, and
  `f|_α = κ_j|_t ∈ N_0` by Lemma 3.
- Every other `α` is a proper prefix of some `u_j`, and there are finitely many of these.

Hence `f` has finitely many local actions, and `Nuc_f ⊆ N_0`.

## Lemma 5 (the phase lemma): `w ↦ λ(rκ(w))` is a K-map on `X^ω`

This holds for all `κ, λ ∈ K` and every word `r`.
- **`r` complete.** By Lemma 2(a), `λ(rx) = r'λ'(x)`, so the map is the single K-piece `w ↦ r'(λ'κ)(w)`, and
  `λ'κ ∈ K` by Lemma 1.
- **`r = r_0 1` with `r_0` complete.** Then `λ(r_0 1 x) = r_0' μ(1x)` with `μ ∈ K`. It remains to show that
  `M(w) = μ(1κ(w))` is a K-map. On the partition `{C_2, C_{11}, C_{12}}` of `X^ω`, using (BR):
  - `w = 2y` or `w = 11y`. Then `κ(w) ∈ {2y, 11y}`.
    - If `κ(w) = 11y`, then `1κ(w) = 11·1y`, so `M(w) = σ_μ(11)·1y`.
    - If `κ(w) = 2y`, then `1κ(w) = 12y`, so `M(w) = 12μ⁺(y)`.

    Either way this is one K-piece on `C_2` (resp. `C_{11}`).
  - `w = 12y`. Then `κ(w) = 12κ⁺(y)` and `1κ(w) = 11·2κ⁺(y)`, so `M(w) = σ_μ(11)·2κ⁺(y)`. This is one K-piece.

This finite look-ahead is the only place where the asynchrony of `b_i, c_i, d_i` enters. The dangling `1` shifts
the block phase by one letter, and the shift is absorbed after one block.

## Lemma 6: `𝒢` is a group

- **Inverses.** Let `f ∈ 𝒢` have pieces `u_j w ↦ v_j κ_j(w)`. Each `κ_j` maps onto `X^ω`, so `f(C_{u_j}) = C_{v_j}`,
  and these cones partition `X^ω`. Hence `f^{-1}(v_j w) = u_j κ_j(w)`, using `κ_j^{-1} = κ_j`, and `f^{-1} ∈ 𝒢`.
- **Products.** Let `f, g ∈ 𝒢` and let `g` have pieces `u'_i w ↦ v'_i λ_i(w)`. It suffices to show that `g∘P` is a
  K-map on `C_u` for every piece `P: uw ↦ vκ(w)` of `f`. Cones are nested or disjoint, so there are two cases.
  - **(a) `C_v ⊆ C_{u'_i}` for some `i`.** Write `v = u'_i r`. Then `gP(uw) = v'_i λ_i(rκ(w))`. By Lemma 5 this is
    `u·(K-map)` followed by the prefix `v'_i`, so it is a K-map on `C_u`.
  - **(b) Otherwise.** The `C_{u'_i}` that meet `C_v` lie inside it and partition it. Write `u'_i = v z_i`.
    - By Lemma 2, `κ|_{C_{z_i}}` has pieces `z_i e w ↦ y_e κ_e(w)`, for `e = ∅` or `e ∈ {1, 2}`.
    - Since `κ` and `κ_e` are involutions, `κ(y_e x) = z_i e κ_e(x)`, and `κ(C_{z_i}) = ⊔_e C_{y_e}`.
    - So `P^{-1}(C_{u'_i}) = ⊔_e C_{u y_e}`, and on `C_{u y_e}`:
      `gP(u y_e x) = g(v z_i e κ_e(x)) = v'_i λ_i(eκ_e(x))`.
    - This is a K-map in `x` by Lemma 5, with `r = e`.
    - The cones `C_{u y_e}`, over all `i` and `e`, partition `C_u`.

## Lemma 7: `V_2 ≤ 𝒢`, and every generator of `F` lies in `𝒢`

- **`V_2`.** Every element of `V_2` is a K-map with all labels `1`.
- **`b_0, c_0, d_0`.** These lie in `K`, each a single piece over `C_∅`.
- **`a_0`.** It has pieces `11 → 2`, `2 → 11` and `12 → 12`, all with label `1`, so `a_0 ∈ V_2`.
- **`x_1` and `x_2`, for `x ∈ {b, c, d}`.** `x_1` has the pieces `1w ↦ 1x_0(w)` and `2w ↦ 2w`, and `x_2` has the
  pieces `1w ↦ 1w` and `2w ↦ 2x_0(w)`.
- **`a_1` and `a_2`.** They conjugate `a_0` into `C_1`, resp. `C_2`, by prefixing, so they lie in `V_2`.

## Conclusion

By Lemmas 6 and 7, `H = <V_2, F> ≤ 𝒢`. By Lemma 4, `H ≤ R_2` and `Nuc_H ⊆ N_0`, so `Nuc_H` is finite. `X^ω` has
an irreducible core, so `H` is a contracting group containing `V_{Γ,E}`.

The "Consequence used downstream" of `contracting-rsgs-embed-in-fp-simple-groups` then applies, with `G_0 = H` and
`N = Nuc_H`:
- `G = {f ∈ R_2 : Nuc_f ⊆ N}` is a full contracting RSG containing `H ⊇ F`.
- `G` embeds in a finitely presented simple group `Q`, namely `SV_G`.

This gives items 1 and 2 of the target.

For item 3, by `th:F`, `[F,F]` is simple, has finite index in the finitely generated group `F`, and is periodic. So
`[F,F]` is finitely generated and periodic. `F` has intermediate growth, so `F` is infinite, and hence `[F,F]` is
infinite.
- An infinite simple group is not residually finite: a finite quotient separating a nontrivial element has a
  proper normal kernel, which must be trivial, so the group would be finite.
- So `[F,F] ≤ F ≤ G ≤ Q` is an infinite, finitely generated, periodic, non-residually-finite subgroup of the
  contracting RSG `G` and of the finitely presented simple group `Q`. ∎

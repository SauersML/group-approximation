Everything computational in the claim is recorded exactly (rational
arithmetic, no floating point) in the artifact
`experiments/atlas-transported-corner-overlap.json` produced by
`experiments/atlas_transported_corner_overlap.py`, the same artifact that
establishes `two-pauli-quarter-carriers-have-fixed-reflection-holonomy`.
With `R_0, R_1` the two carrier reflections of that claim, `K = (R_0 R_1)^2`
and `H = (1 - K)/2`, the artifact keys read:

```text
common_transported_pauli_carrier_reflection_product_fourth_is_identity: true
                                              -> (R_0 R_1)^4 = 1, i.e. K^2 = 1
derived_holonomy_carrier_is_projection: true  -> H^2 = H
derived_holonomy_carrier_trace: 1/8           -> tau(H) = 1/8, hence tau(K) = 3/4
derived_holonomy_carrier_commutes_with_both_reflections: [true, true]
derived_holonomy_carrier_reflections_anticommute: true
                                              -> H R_0 R_1 = - H R_1 R_0       (PDR3)
derived_holonomy_carrier_quarter_cut_overlaps: [1/16, 1/16]
                                              -> tau(H (1 + R_i)/2) = 1/16     (PDR4)
derived_holonomy_carrier_lies_under_raw_corner / _comb_corner: false, false
derived_holonomy_carrier_raw_corner_overlap / _comb_corner_overlap: 1/16, 1/16
                                              -> (PDR5)
```

This gives `(PDR1)`, `(PDR2)`, `(PDR3)`, `(PDR4)` and `(PDR5)` verbatim.  The
remaining assertions are elementary consequences:

- `K = [R_0, R_1] = R_0 R_1 R_0^(-1) R_1^(-1) = (R_0 R_1)^2` because the
  reflections are involutions, so `K` is literally a commutator and lies in
  the derived subgroup of the reflection group.
- `K` commutes with both reflections without any computation once `K^2 = 1`:
  `R_0 K R_0 = (R_1 R_0)^2 = K^(-1) = K`, and likewise for `R_1`; hence so
  does `H`.
- On `ran H` one has `K = -1`, i.e. `(R_0 R_1)^2 = -1`, so `R_0 R_1` has
  order four there with square the central sign; the group generated by
  two involutions whose product has order four is `D_8`, and a
  representation of `D_8` in which the central element `(R_0 R_1)^2` acts as
  `-1` is a multiple of its unique two-dimensional irreducible (spin)
  representation.  That is the "unique marked two-dimensional spin type of
  `D_8`" of the claim; `(PDR3)` is the statement `(R_0 R_1)^2 = -1` on
  `ran H` rewritten.
- Balance `(PDR4)` is then forced, not merely computed: in the
  two-dimensional spin representation each reflection has eigenvalues
  `+1, -1`, so `tau(H R_i) = 0` and `tau(H (1 + R_i)/2) = tau(H)/2 = 1/16`;
  the artifact confirms it.
- The carrier density `tau(H) = 1/8` and the transversality of the new
  selector pair are the recorded `(PDR2)` and `(PDR3)`; no tensor qubit is
  introduced because `H, R_0 H, R_1 H` live in the algebra generated by the
  original two carriers.
- `(PDR5)` is recorded directly and is the claim's own caveat: `H` has
  exactly half of its trace under either pre-existing corner and is
  contained in neither, so the reset is balanced but not semantically
  localized.

The claim asserts nothing beyond these identities and their reading; in
particular it does not assert the semantic/gauge return, which it names as
still load-bearing.

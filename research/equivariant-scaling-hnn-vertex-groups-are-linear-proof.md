Notation as in `equivariant-scaling-hnn-vertex-groups-are-linear`.

**phi is an injective endomorphism of finite-index image.** For
`m, m' in M`, `h, h' in H`, `(m h)(m' h') = (m + h·m') hh'`. Applying (SC) gives
`λ(m) + λ(h·m') = λ(m) + h·λ(m')` by equivariance, which is
`phi(m h) phi(m' h')`. Injectivity follows from injectivity of `λ`, and
`phi(A) = λM ⋊ H` has index `|M/λM|`.

**(1) Faithfulness.** In `K`, `t A t^-1 = phi(A) <= A`. The kernel of the action
on the Bass--Serre tree is `N_K = ∩_{g in K} g A g^-1`, the largest normal
subgroup of `K` inside `A`.
- *If `M_∞ := ∩_n λ^n M != 0`, the action is not faithful.* `λ` is injective, so
  `λ(M_∞) = ∩_n λ^(n+1) M = M_∞`. `M_∞` is an `H`-submodule of the abelian normal
  subgroup `M`, so it is normal in `A`, and `t M_∞ t^-1 = phi(M_∞) = M_∞`. Hence
  `M_∞` is normal in `K = <A, t>` and lies in `N_K`.
- *If `N_0 := ker(H -> Aut M) != 1`, the action is not faithful.* `N_0` is normal
  in `H` and centralizes `M`, so it is normal in `A`; and `phi` is the identity on
  `H`, so `t N_0 t^-1 = N_0`. Hence `N_0 <= N_K`.
- *Conversely, suppose `M_∞ = 0` and `N_0 = 1`.* `N_K <= ∩_n t^n A t^-n
  = ∩_n phi^n(A) = M_∞ ⋊ H = H`. A normal subgroup of `A` contained in `H`
  commutes with `M`, since `[N_K, M] <= N_K ∩ M = 1`. So `N_K <= N_0 = 1`.

**(2) Linearity.** Assume `M_∞ = 0` and `N_0 = 1`, and let `d = dim M/λM`.
1. *Finite quotients.* `λ^i M / λ^(i+1) M ≅ M/λM` by injectivity, so
   `dim M/λ^n M = nd < ∞`.
2. *Completion.* Put `M̂ = lim_n M/λ^n M`, a profinite `F_p[[x]]`-module with `x`
   acting as `λ`. Since `M_∞ = 0`, the map `M -> M̂` is injective. The transition
   maps are surjective between finite modules, so the inverse limit is exact and
   `M̂ / x M̂ ≅ M/λM` has dimension `d`.
3. *Structure.* `F_p[[x]]` is a complete local ring, so by Nakayama's lemma for
   compact modules `M̂` is generated by `d` elements. It is a principal ideal
   domain, so `M̂ ≅ F_p[[x]]^r ⊕ T_0` with `r <= d` and `T_0` the finite torsion
   submodule.
4. *`M` misses the torsion.* If `m in M ∩ T_0`, then `x^e m = λ^e(m) = 0` for some
   `e`. As `M -> M̂` is injective, `λ^e(m) = 0` in `M`, so `m = 0`. So
   `ι: M -> M̂/T_0 ≅ F_p[[x]]^r` is injective.
5. *The top acts linearly.* `H` preserves every `λ^n M`, so it acts on `M̂`
   continuously and `x`-equivariantly, preserving `T_0`. This gives
   `ρ: H -> GL_r(F_p[[x]])` with `ι` `H`-equivariant. `ρ` is injective: if
   `ρ(h) = 1`, then `h` fixes `ι(M)` pointwise, hence fixes `M`, so `h in N_0 = 1`.
6. *The embedding.* `m h ↦ (ι(m), ρ(h))` is a homomorphism
   `A -> F_p[[x]]^r ⋊ GL_r(F_p[[x]]) <= GL_(r+1)(F_p((x)))`, because `ι` is
   `H`-equivariant. It is injective, since `ι` and `ρ` are. `∎`

**Inputs.** Only textbook facts: exactness of inverse limits of finite modules,
Nakayama's lemma for compact modules over a complete local ring, and the structure
theorem over the PID `F_p[[x]]`. None is imported as a node.

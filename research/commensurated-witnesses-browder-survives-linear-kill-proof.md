Verification tier: proposed-established. Standard inputs:
- Serre's theorem on `cd` of torsion-free finite-index overgroups (Brown,
  *Cohomology of Groups*, VIII.3.1);
- Steps 2--4 of `type-f-weyl-groups-have-bounded-elementary-abelian-ranks-proof`
  (Browder's argument), rechecked below without finiteness hypotheses;
- Bass--Serre theory (Serre, *Trees*, I.4 and I.5); Karrass--Pietrowski--Solitar
  (a finitely generated fundamental group of a finite graph of finite groups is
  virtually free);
- finite rank of compact `p`-adic linear groups (Dixon--du Sautoy--Mann--Segal,
  *Analytic pro-p groups*, Thm 3.8 and Thm 5.2: in a uniform pro-`p` group of
  dimension `D` every closed subgroup is generated by `≤ D` elements, and the
  level-`p^2` congruence subgroup of `GL_d(Z_p)` is uniform of dimension `d^2`).

Notation: `π : F -> P = F/N`, `Σ ∩ F = N ⊴ F`.

## Step 1: Q-cores

Let `Q ≤ P` be finite, `H = π^{-1}(Q)`, so `H ∩ Σ = N` and `H/N ≅ Q`.
- **Only finitely many conjugates.** For `x ∈ N`, `xΣx^{-1} = Σ` since
  `N ≤ Σ`. So `hΣh^{-1}` depends only on `hN`. With coset representatives
  `h_q`, the set `{hΣh^{-1} : h ∈ H}` is `{h_qΣh_q^{-1} : q ∈ Q}`, finite.
- **Normality.** `H` permutes this set by conjugation, so it normalizes
  `Σ_Q = ∩_q h_qΣh_q^{-1}`. So `E_Q = Σ_Q H` is a subgroup and `Σ_Q ⊴ E_Q`.
- **`N ≤ Σ_Q`.** `h_q^{-1} N h_q = N ≤ Σ`.
- **The quotient.** `H ∩ h_qΣh_q^{-1} = h_q(H ∩ Σ)h_q^{-1} = N`, so
  `H ∩ Σ_Q = N` and `E_Q/Σ_Q ≅ H/(H ∩ Σ_Q) = H/N ≅ Q`.
- **`E_Q ∩ Σ = Σ_Q`.** If `sh ∈ Σ` with `s ∈ Σ_Q`, `h ∈ H`, then
  `h ∈ H ∩ Σ = N ≤ Σ_Q`.
- **Commensurated case.** Each `[Σ : Σ ∩ h_qΣh_q^{-1}]` is finite, so the
  finite intersection `Σ_Q` has finite index in `Σ`. A finite-index subgroup
  of a type `F_m` group is of type `F_m`.

This proves item 1. For a normalized witness, `Σ_Q = Σ`, recovering the
earlier setting.

## Step 2: the Σ-independent part of Browder's bound

Assume `Λ` torsion-free and `cd Σ = n < ∞`. Fix `Q`, a prime `p`, and an
elementary abelian `A ≤ Q` acting trivially on `H_i(Σ_Q; Z)` for all `i ≥ 1`.
Let `E ≤ E_Q` be the preimage of `A`, so `E/Σ_Q ≅ A`.
- `cd Σ_Q ≤ n` (subgroup), `E ≤ Λ` is torsion-free, and `[E : Σ_Q] < ∞`, so
  `cd E = cd Σ_Q ≤ n` by Serre's theorem.
- Steps 0, 2 and 3 of the cited proof apply verbatim: `C = Z ⊗_{ZΣ_Q} P_*`
  is a bounded complex of projective `ZA`-modules (possibly infinitely
  generated; Tate cohomology still vanishes on projectives), with
  `H_j(C) = H_j(Σ_Q)`. They give `|A|` dividing
  `∏_{i=1}^{n} exp Ĥ^{i+1}(A; H_i(Σ_Q))`.
- Step 4 needs no finite generation. For a trivial module `B` and `k ≥ 2`,
  the universal coefficient sequence splits:
  `H^k(A; B) ≅ Hom(H_k(A; Z), B) ⊕ Ext(H_{k-1}(A; Z), B)`. Both
  `H_k(A; Z)` and `H_{k-1}(A; Z)` are killed by `p` (Künneth), so both
  summands are killed by `p`, and `p^2` kills `H^k(A; B)`.
- Hence `rk A ≤ 2n`. This proves item 2. ∎

## Step 3: the amalgam family

Fix `p` and `r ≥ 2`. Let `M = ker(F_r -> (Z/p)^r)`, free of rank
`R = 1 + p^r(r-1)` (Schreier). A subgroup of index `m` in `F_2` is free of
rank `m + 1`, so choose `M' ≤ F_2` of index `p^r(r-1)` and an isomorphism
`M ≅ M'`. Put `Λ_r = F_r *_{M = M'} F_2`, `F = F_r`, `Σ = F_2`.
- **Type `F`, torsion-free.** The graph-of-spaces model (two wedges of circles
  joined by a mapping cylinder of a finite graph) is a finite aspherical
  2-complex.
- **Witness.** In an amalgam `F_r ∩ F_2 = M`, so `Σ ∩ F = M = N`, with
  `P = (Z/p)^r`.
- **Commensurated.** For `f ∈ F_r`, `Σ ∩ fΣf^{-1} ⊇ M` (as `M ⊴ F_r` and
  `M ≤ Σ`), and `[Σ : M] < ∞`.
- **The core.** In the Bass--Serre tree, for `f ∉ M` the vertices `Σ` and
  `fΣ` are at distance 2 through the vertex `F_r`, so
  `Σ ∩ fΣf^{-1} = M ∩ fMf^{-1} = M`. Hence `Σ_Q = M` for `Q = P`.
- **What Browder sees.** `H_1(M) ≅ Z ⊕ Z[Q]^{r-1}` (Gaschütz), a faithful
  `Q`-module, consistent with Step 2. The constant `c_p(M) ≥ rk_p GL_R(Z)`
  is at least `⌊R/(p-1)⌋`, using block-diagonal copies of the companion
  matrix of the `p`-th cyclotomic polynomial. So `r ≤ 2 + c_p(Σ_Q)` is true
  and carries no information.

So for the fixed type `F` group `Σ = F_2`, commensurated torsion-free type
`F` witnesses realize every `(Z/p)^r`. No function of `(Σ, p)` bounds `r`.
This proves item 3. ∎

## Step 4: the linear kill

Assume `N = F ∩ ρ^{-1}(K)` with `K` compact and open in a closed subgroup
`G_0 ⊇ ρ(F)` of `G = ∏_{j=1}^{s} GL_d(Q_{p_j})`. Let `Q ≤ P` be finite and
`H = π^{-1}(Q) = ∪_q h_q N`.

**`Q` is a quotient of a compact group.**
- `ρ(H) ⊆ ∪_q ρ(h_q) K` is relatively compact, so `L = cl ρ(H) ≤ G_0` is a
  compact subgroup.
- `L_0 = L ∩ K` is open in `L`. As `H ∩ ρ^{-1}(K) = H ∩ N = N`, we get
  `ρ(H) ∩ K = ρ(N)`, and density of `ρ(H)` in `L` with openness of `K` gives
  `L_0 = cl ρ(N)`. Since `ρ(N) ⊴ ρ(H)`, `L_0 ⊴ L`.
- `H -> L/L_0` is onto (dense image in a finite discrete group) with kernel
  `{h : ρ(h) ∈ K} = N`. So `Q ≅ L/L_0`.

**Ranks of such quotients.**
- Each projection of `L` to `GL_d(Q_{p_j})` is compact, so it stabilizes a
  lattice (the sum of the `L`-translates of `Z_{p_j}^d`). After conjugating,
  `L ≤ W = ∏_j GL_d(Z_{p_j})`.
- Let `A ≤ Q` be elementary abelian of rank `t` for a prime `ℓ`, `Ã ≤ L` its
  (closed) preimage, and `S` an `ℓ`-Sylow subgroup of `Ã`. Then `S` maps onto
  `A`, so `t ≤ d(S)`.
- Let `W_1 = ∏_j Γ_j`, with `Γ_j` the kernel of reduction mod `p_j^2`, a
  uniform pro-`p_j` group of dimension `d^2` (DDMS 5.2). `S ∩ W_1` is
  pro-`ℓ`, so its projections to the `Γ_j` with `p_j ≠ ℓ` are trivial.
  - If `ℓ ∉ {p_j}`, then `S ∩ W_1 = 1`.
  - Otherwise it is a closed subgroup of one uniform group of dimension
    `d^2`, so `d(S ∩ W_1) ≤ d^2` (DDMS 3.8).
- `S/(S ∩ W_1)` embeds in the finite group `W/W_1 = ∏_j GL_d(Z/p_j^2)`, so
  it has `d ≤ β = log_ℓ |∏_j GL_d(Z/p_j^2)|_ℓ`.
- So `t ≤ d(S ∩ W_1) + d(S/(S ∩ W_1)) ≤ d^2 + β` for `ℓ ∈ {p_j}`, and
  `t ≤ β` otherwise; `β = 0` for `ℓ` not dividing the finite order.

**Restriction of scalars.** For a finite extension `k/Q_p`,
`GL_d(k)` is a closed subgroup of `GL_{d[k:Q_p]}(Q_p)`, and a compact open
subgroup of `GL_d(k)` is compact and open in that closed subgroup. This
covers S-arithmetic congruence witnesses (`Σ = Λ ∩ GL_d(O_{S'})`,
`Λ ≤ GL_d(O_S)` with `S' ⊂ S`, cut out by `∏_{v ∈ S \ S'} GL_d(O_v)`) and
vertex stabilizers in Bruhat--Tits buildings. This proves item 4. ∎

**Calibration.** `SL_2(Z) ≤ SL_2(Z[1/p])` (after passing to torsion-free
finite-index subgroups) is a commensurated, non-separable example: by strong
approximation `SL_2(Z)` is dense in the profinite completion of
`SL_2(Z[1/p])`, which has the congruence subgroup property (Serre). So item 4
reaches witnesses that `separable-benign-witness-forces-rf-quotient` does not.

## Step 5: the tree kill

Let `F` act on a locally finite tree `T` (subdivide to remove inversions) with
`Stab_F(v) = N`.
- `N ⊴ F` fixes every `fv`, since `f^{-1}Nf = N` fixes `v`. The fixed set of
  `N` is a subtree, so `N` fixes the hull `Y` of `F·v` pointwise, and
  `P = F/N` acts on `Y`.
- **Finite stabilizers.** For a vertex `y ∈ Y`, `Stab_F(y) ⊇ N`, and
  `gN -> gv` injects `Stab_F(y)/N` into the sphere of radius `d(y, v)` about
  `y`, which is finite. So `Stab_P(y)` is finite.
- **Cocompact core.** `P` is finitely generated, say by the images of `S`.
  The subtree `Y' = P·(∪_{s ∈ S} [v, sv])` is connected, `P`-invariant and
  has finitely many edge orbits.
- By Bass--Serre theory `P` is the fundamental group of a finite graph of
  finite groups, hence finite or virtually free (Karrass--Pietrowski--
  Solitar). Virtually free groups have bounded finite-subgroup order.

For a graph-of-groups witness with `Σ` a vertex group and all edge inclusions
of finite index, the Bass--Serre tree is locally finite and `Σ = Stab_Λ(v)`.
This proves item 5. ∎

## Step 6: consequences and the completion picture

**Item 6.**
- `U` contains every finite group, and so does `V`.
- `Z/2 ≀ Z` contains `(Z/2)^r` for all `r`.
- Grigorchuk's group: see Corollary 3 of the cited proof.

Items 4 and 5 bound finite-subgroup ranks, so none of these groups is `F/N`
for such a witness. `Z/2 ≀ Z` is residually finite, so the separable kill
does not reach it.

**Completion picture (surviving shape).** Let the witness be commensurated
and `C = ⟨F, Σ⟩`, which commensurates `Σ`. Let `G` be the closure of the image
of `C` in `Sym(C/Σ)` (pointwise topology). Then:
- `K = Stab_G(Σ)` is compact open, since `Σ`-orbits on `C/Σ` are finite.
- Let `F̃`, `Ñ` be the images of `F` and `N`, and `F̂ = cl F̃`. Then
  `F̃ ∩ K = Ñ` because `Stab_F(Σ) = N`.
- `M = cl Ñ ≤ K` is normalized by `F̂`. The map `P = F̃/Ñ -> F̂/M` is
  injective, since `F̃ ∩ M ⊆ F̃ ∩ K = Ñ`.
- Its image is dense and meets the open subgroup `(F̂ ∩ K)/M` trivially.
  A dense subgroup meets every nonempty open set, so `(F̂ ∩ K)/M = 1`, i.e.
  `M = F̂ ∩ K`. Then `F̂/M` is discrete and `P ≅ F̂/M`.
- If `F̂` were isomorphic to a closed subgroup `G_0` of a product of groups
  `GL_d(Q_{p_j})`, then Step 4 would apply with `K = M` (compact open in
  `G_0`), since `F ∩ ρ^{-1}(M) = N`. So for `U` this is impossible.

**What is not claimed.**
- No bound is claimed for arbitrary commensurated witnesses. Step 3 shows the
  Browder route alone cannot give one.
- Non-linear completions, such as characteristic `p` groups or Neretin-type
  groups with non-tree geometry, remain open.
- The root is untouched.

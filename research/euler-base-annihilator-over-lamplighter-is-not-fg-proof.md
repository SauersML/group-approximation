Notation as in the target. As abelian groups, `Z[H] = ⊕_(m in Z) x^m Z[B]`, and `Z[B]` is the Laurent
polynomial ring in the independent variables `β_k`.

**1. Presentation over D.**
- `r` annihilates `M`: `x β x^(-1) f_j = (1 + l(j+1)) f_j = (β + l) f_j`.
- `β - 1` annihilates `f_0`.
- Conversely, in `D` the conjugates `x^(-k) r x^k = β_(k-1) - β_k - l` vanish. Telescoping gives
  `β_k - (1 - lk) = (β_0 - 1) - Σ_(j=1..k) (β_(j-1) - β_j - l)` for `k >= 1`, and similarly for `k < 0`.
  So in `D / D(β-1)` every lamp acts on the class of 1 by the scalar `1 - lk`. That class generates, and
  `x^m` moves it to the `m`-th slot.
- Hence `D/D(β-1) -> M`, `1 -> f_0`, is onto, and injective slot by slot. The identification of `D` with
  `A[x^(±1); σ]` is Step 1 of `resolvent-ring-has-path-normal-form-proof`.

**2. The annihilator is not finitely generated.**
- *Computing J.* For `z = Σ_m x^m b_m`, `z f_0 = Σ_m ε(b_m) f_(-m)`, since the lamps act on `f_0` by
  `ε`. So `z in J` iff every `b_m in ker ε`, and `J = ⊕_m x^m ker ε`.
- *Finitely generated left ideals are confined.* Suppose `J = Σ_(i=1..n) Z[H] g_i`, with
  `g_i = Σ_m x^m c_(i,m)`. For `a in Z` and `b in Z[B]`,
  `x^a b g_i = Σ_m x^(a+m) (x^(-m) b x^m) c_(i,m)`. So every slot component of every element of the left
  ideal lies in the ideal `I = Σ_(i,m) Z[B] c_(i,m)` of `Z[B]`. `I` is generated by finitely many
  elements, involving only lamps `β_k` with `|k| <= R` for some `R`.
- *The ring map.* Define `ε' : Z[B] -> Z_(l)[T, T^(-1)]` by:
  - `β_(R+1) -> T`;
  - `β_k -> 1 - lk` for `k != R+1`.

  `ε'` agrees with `ε` on the lamps with `|k| <= R`. So it kills every generator of `I`, which lies in
  `ker ε`, and hence kills `I`.
- *The contradiction.* `ε'(β_(R+1) - (1 - l(R+1))) = T - (1 - l(R+1)) != 0`. So
  `β_(R+1) - (1 - l(R+1))`, an element of `ker ε`, is not in `I`. Its slot-0 copy in `J` is not in the
  left ideal. So `J` is not finitely generated.
- *Consequences.* A cyclic module `Z[H]/L` is finitely presented only if `L` is finitely generated
  (Schanuel's lemma).
  - Taking `L` generated by `β - 1` and the `r x^k`, `k in F`: slot 0 of that left ideal lies in an ideal
    of `Z[B]` involving finitely many lamps. The same map `ε'` then shows it misses some
    `β_(R+1) - (1 - l(R+1))`. So these finitely many relations do not cut out `M`.

**3. Overgroups.**
- `Z[Q]` is a free right `Z[H]`-module on coset representatives `q_α`, with `q_0 = 1`. So
  `Z[Q] ⊗_(Z[H]) M = Z[Q] / Z[Q]J`, and `Z[Q]J = ⊕_α q_α J`.
- Suppose `Z[Q]J = Σ_(i=1..n) Z[Q] g_i`, with `g_i = Σ_α q_α j_(i,α)`. Write `z q_α = Σ_γ q_γ h_(γ,α)`,
  with `h_(γ,α) in Z[H]`, for `z in Z[Q]`.
- Then the `q_0`-component of `z g_i` is `Σ_α h_(0,α) j_(i,α)`, which lies in the finitely generated left
  ideal `Σ_(i,α) Z[H] j_(i,α) ⊆ J`.
- Projecting `Z[Q]J` to its `q_0`-component gives all of `J`. So `J` would be finitely generated,
  contradicting 2.
- By Schanuel again, the induced module is not finitely presented. Baumslag's group contains `<a, t>` as
  `Z≀Z` (lamp `a`, shift `t`), so it is an instance of `Q`. ∎

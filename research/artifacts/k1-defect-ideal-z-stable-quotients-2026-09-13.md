## 1. The quotient lemma for Z-stable quotients

**Lemma 1'.** Let Q be unital and Z-stable with `K_0(Q) = 0`. Then `U((SQ)~)` is path-connected.

*Proof.*
- `C = C(T) ⊗ Q` is unital and Z-stable. Evaluation at `1 ∈ T` gives a split extension
  `0 -> SQ -> C -> Q -> 0`, so `K_1(C) ≅ K_1(SQ) ⊕ K_1(Q) = K_0(Q) ⊕ K_1(Q)`.
- Let `f ∈ U(1 + SQ)`. Its class in `K_1(C)` is the image of `[f] ∈ K_1(SQ) ≅ K_0(Q) = 0`, so it is 0.
- By Jiang, arXiv:math/9707228v1, Theorem 2 (`z-stable-unital-algebras-are-k1-bijective`), `f ∈ U_0(C)`.
- Correcting a path by the constants `c(ev(w_s))^*`, exactly as in Part 1 Lemma 1, gives a path in
  `U(1 + SQ)`. Square.

No hypothesis on `K_1(Q)` is needed.

**Corollary 3'.** Let `0 -> I -> B -> Q -> 0` be exact with B unital and Q unital, Z-stable, properly
infinite, with `K_0(Q) = 0`. Then:
- (a) `U(I~) ∩ U_0(B) = U_0(I~)`;
- (b) `K_1(I) -> K_1(B)` is injective;
- (c) `I~` is K1-injective iff B is.

*Proof.*
- (a) Lemma 1' and Part 1 Proposition 2.
- (b) The boundary `K_0(Q) -> K_1(I)` has trivial domain.
- (c)(⟸) As in Part 1 Corollary 3(c), using (a) and (b).
- (c)(⟹) `k1-injectivity-extends-over-properly-infinite-quotients`: Q is properly infinite, and it is
  K1-injective by Jiang's Theorem 2. Square.

Examples of admissible quotients: O_2, `O_2 ⊗ D` for any unital D (Z-stable since `O_2 ⊗ Z ≅ O_2`, and
K-theory 0 by the Künneth formula for nuclear `O_2`), and every unital Kirchberg algebra with `K_0 = 0`.

## 2. The commutator ideal of the halving algebra

`U = O_2 *_C C(T)`, and `J_c = ker(U -> O_2 ⊗ C(T))`, the map sending `s_k -> s_k ⊗ 1` and `z -> 1 ⊗ z`.

**Proposition 4.** `J_c~` is K1-injective iff `U` is K1-injective, iff the halving homotopy
`o2-free-circle-halving-homotopy` holds. Moreover `K_1(J_c) ≅ K_1(U) ≅ Z`, generated by the class of z.

*Proof.*
- `O_2 ⊗ C(T)` is unital, Z-stable and properly infinite, with K-theory 0. So Corollary 3'(c) applies,
  and the six-term sequence gives `K_*(J_c) ≅ K_*(U)`.
- Germain's sequence gives `K_1(U) = K_1(O_2) ⊕ K_1(C(T)) = Z`.
- K1-injectivity of U is the halving homotopy by `trivial-unit-class-lxi-iff-universal-halving-homotopy`.
  Square.

## 3. The ideal lattice of `A_T = T_2 * T_2`

Two quotients of `A_T` qualify:
- `φ_c: A_T -> O_2 ⊗ C(T)`, with `ι_1(s_k) -> s_k ⊗ 1` and `ι_2(s_k) -> s_k ⊗ z`. It is surjective,
  since `1 ⊗ z = Σ_k φ_c(ι_2(s_k)) φ_c(ι_1(s_k))^*`.
- `φ_f: A_T -> O_2`, the composite of `φ_c` with `z -> 1`.

Put `I_c = ker φ_c` and `I_f = ker φ_f`. Recall `J = <ι_1(p_3)>`. Then `J ⊆ I_c ⊆ I_f`, since both maps
kill `ι_1(p_3)`.

**Theorem 5.** The following are equivalent:
- (i) STW Problem LXI;
- (ii) `U(I_c~)` is path-connected;
- (iii) `U(I_f~)` is path-connected.
They imply
- (iv) `U(J~)` is path-connected (Part 1, Theorem 5).
Together with the halving homotopy, (iv) implies (i).

*Proof.*
- `K_1(A_T) = 0` (Blanchard arXiv:0804.4624v13, Lemma 4.4, read in the PDF by this lane). Both
  quotients are admissible in Corollary 3', with trivial K-theory, so `K_1(I_c) ≅ K_1(I_f) ≅ 0`.
- Corollary 3'(c) makes (ii) and (iii) each equivalent to K1-injectivity of `A_T`.
- K1-injectivity of `A_T` is equivalent to LXI by Blanchard's Proposition 4.2, (i) <=> (v), read in the
  PDF. That proposition states: "The following assertions are equivalent. (i) `T_2 *_C T_2` is
  K_1-injective. [...] (v) Any unital properly infinite C\*-algebra A is K_1-injective." Square.

**The gap between (iv) and (ii).** `I_c/J ≅ ker(O_2 * T_2 -> O_2 ⊗ C(T))` gives an extension
`0 -> J -> I_c~ -> (I_c/J)~ -> 0`.
- Its quotient has a character, so it is not properly infinite. The extension lemma therefore does not
  apply, and neither does Corollary 3'.
- By Corollary 3'(c) with `B = O_2 * T_2`, `U((I_c/J)~)` is connected iff `O_2 * T_2` is K1-injective,
  iff halving holds. Here `K_*(O_2 * T_2) = 0`.
- If both `J~` and `(I_c/J)~` have connected unitary groups, then so does `I_c~`. Lift a null-homotopy
  of the image to `U_0(I_c~)` through exponentials, and use `K_1(J) = 0` for the remainder.
- This recovers route `lxi-from-halving-and-toeplitz-defect-ideal`.

## 4. What remains open for J, stated sharply

Under halving, and with `S = ι_1(s_2)`, `p = 1 - ι_1(s_1s_1^*)` and `B_J = J + ι_1(T_2)` (Part 1):
- For `u ∈ U(1+J)`, put `ψ(u) = S u S^* + ι_1(p_3) ∈ U(pB_Jp)`. Its class is `[u] = 0`, and `pB_Jp`
  is properly infinite with trivial unit class. So halving makes `ψ(u)` null in `pB_Jp`.
  Adding `ι_1(s_1s_1^*)` shows that `C_S(u) = SuS^* + (1 - SS^*)` is null in `B_J`, hence in `U(J~)` by
  Part 1 Proposition 2.
- So, under halving, `U(J~)` is connected iff `u ~_h C_S(u)` in `U(J~)` for every `u ∈ U(1+J)`.
- This is the unit axiom of Part 1 section 5 for one isometry whose defect `ι_1(s_1s_1^*) + ι_1(p_3)`
  is full and properly infinite, applied only to unitaries in `1 + J`.

## R1. The ring (Part 1 §1)

- **Generators.** `u^i χ_[a] u^(-i) = χ_[a]∘T^(-i) = χ_{x_(-i)=a}`. Products give every cylinder and
  `Z`-combinations give `LC(X,F_p)`. For `q = p^e`, `e > 1`, the ring generated by `u^(±1)` and the letters
  is `LC(X,F_p) ⋊ Z`, a proper subring. Adding one `λ` with `F_p[λ] = F_q` gives `R`. PASS.
- **(P) long cylinders have long return times.** `T^j C(v) ∩ C(v) ≠ ∅` puts two occurrences of `v` at
  distance `|j|`, so `v` has period `|j|`. Fix `j` along a subsequence, take a limit point of centred points:
  it is `j`-periodic, contradicting aperiodicity (a finite orbit is a proper closed invariant set). PASS.
- **Simplicity.** `χ_W P χ_W = Σ_j f_j χ_W χ_(T^j W) u^j = c χ_W`, and `χ_W χ_(T^jW) = 0` for `j ≠ 0`
  once `W` separates `x` from `T^j x`. The orbit of `W` is an open invariant set, hence all of `X`;
  compactness gives a finite cover. `1 - Π_t (1 - χ_(T^(i_t)W)) = 1` expands into terms that each contain
  a factor in `J`. PASS.
- **Centre.** `[c, χ_W] = 0` gives `f_j (χ_(T^jW) - χ_W) = 0`. For `f_j(x) ≠ 0`, choose `W ∋ x` with
  `T^(-j)x ∉ W`, so the bracket is `-1` at `x`: contradiction. `[c,u] = 0` makes `f_0` `T`-invariant, hence
  constant. PASS.
- **Tower subrings.** `E_ab(W) = χ_(T^aW) u^(a-b) = u^(a-b) χ_(T^bW)`, since `α^(a-b)(χ_(T^bW)) = χ_(T^aW)`.
  `E_ab(W) E_cd(W') = χ_(T^aW) χ_(T^(a-b+c)W') u^(a-b+c-d)`. For `b ≠ c` the levels `T^aU` and
  `T^(a+c-b)U` are disjoint because `0 < |c-b| ≤ 2m`. `Φ(F) = Σ_ab (F_ab∘T^(-a)) χ_(T^aU) u^(a-b)` is an
  isomorphism `M_(2m+1)(LC(U,F_q)) → B_m(U)`; injectivity follows from the normal form, since distinct
  levels have disjoint supports. PASS.
- **Absorption.** `(f u^i) E_ab(W) (f' u^j) = f χ_(T^(a+i)W) α^(i+a-b)(f') u^(i+a-b+j)`, as printed. Cut `W`
  so that the coefficient is constant on each `T^(a+i)W_k`; the result is `Σ_k c_k E_(a+i,b-j)(W_k)`, with
  indices at most `m+w`. PASS.

## R2. LEF by periodic return words (Part 1 §3.1–3.2)

- **Seams.** Seams of `y` sit at multiples of `N`. A window of length `ℓ` crosses two seams only if
  `ℓ ≥ N+2`; here `ℓ ≤ 2k+1 ≤ N`. A crossing window is `suffix_s(w_k) prefix_t(w_k)` with `s,t ≥ 1` and
  `s+t ≤ 2k+1`, so `t ≤ 2k`. Then `prefix_t(w_k) = prefix_t(v) = x_[p', p'+t)` and
  `suffix_s(w_k) = x_[p'-s, p')`: the window is `x_[p'-s, p'+t) ∈ L(X)`. PASS.
- **Every word occurs.** `|w_k| ≥ l(2k+1)` gives `L_(2k+1)(X) ⊆ L(w_k) ⊆ L_(2k+1)(y)`. With the seam
  argument, `L_(2k+1)(y) = L_(2k+1)(X)`. PASS.
- **`D_k` well defined.** If `f = Φ(x_[-ρ,ρ]) = Φ'(x_[-ρ',ρ'])` on `X` and `K = max(ρ,ρ') ≤ k`, then
  `y_[n-K,n+K] ∈ L(X)` is realised by some `x ∈ X`, so `Φ` and `Φ'` agree at position `n`. `D_k` is a ring
  homomorphism on functions of radius `≤ k`. PASS.
- **Multiplicativity.** `P^i D(g) P^(-i) δ_n = ĝ(n-i) δ_n`, and `α^i(g)(x) = Φ_g(x_[-ρ-i, ρ-i])`, so
  `D_k(α^i g) = diag(ĝ(n-i))`. Hence `ψ_k((fu^i)(gu^j)) = D(f) P^i D(g) P^j`. The precise condition is: all
  coefficient radii `ρ` and exponents `|i|` satisfy `ρ + |i| ≤ k` (N2). PASS.
- **Injectivity.** `D(f_j) P^j` is supported on positions `(n+j, n)`. For `|j|, |j'| ≤ J < N/2` these are
  disjoint. A nonzero `f_j` is nonzero on a word of `L(X)`, which occurs in `y^(k)` for all large `k`.
  So `ψ_k(r) ≠ 0` for all large `k`, not only for `ω`-many. PASS.
- **LEF of `G`.** Units of `Π_ω M_(3N_k)` are `Π_ω GL_(3N_k)`. Finitely many products and inequalities hold
  on an `ω`-set, which is nonempty. PASS.

## R3. Passing to `S = G/Z` (Part 1 §3.3)

`Z(G) = Λ I_3` (4.4 gives `⊆`; scalars in `G` are central). `Ψ(λ) = D_k(λ) = λ I` since constants have
radius 0. With `C = Λ I` a finite central subgroup of every `Q_k = GL_(3N_k)(F_q)`: `[a_k] ↦ [a_k C]`
has kernel `{[a_k] : a_k ∈ C ω-a.e.}`, and since `C` is finite each such element equals a constant `[λ I]`
on an `ω`-set. So `Π_ω(Q_k/C) ≅ (Π_ω Q_k)/[C]`. If `Ψ(g) = [λI] = Ψ(λ I_3)`, injectivity gives `g = λ I_3`,
so `λ ∈ Λ` and `g ∈ Z(G)`. So `S ↪ Π_ω(Q_k/C)` and `S` is LEF. LEF ⇒ sofic ⇒ hyperlinear. PASS.

## R5. Property (T): Ershov–Jaikin-Zapirain hypotheses

"Let $R$ be a finitely generated (associative) ring with $1$ and $n\geq 3$. Let $G=EL_n(R)$, that is, the
subgroup of $GL_n(R)$ generated by elementary matrices. Then $G$ has Kazhdan's property $(T)$."

- `R` is associative with 1.
- `R` is finitely generated as a ring by `u, u^(-1), χ_[a]` (`a ∈ A`) and, for `q` not prime, one `λ`.
- `G` is by definition generated by all `e_ij(r)`.
- `n = 3`.
- No commutativity, Noetherian or stable-range hypothesis occurs.

`S` is a quotient, so it has (T). PASS.

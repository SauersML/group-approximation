## 0. Setting and status

- **Automaton.** `G` is a group with `1, a, b` distinct, and `H = <a, b>`. Put `M = (1, a, b)`, `c = a^-1 b` and
  `tau(x)(g) = mu(x(g), x(ga), x(gb))` over `F_3`.
- **Rules.** `mu = lambda + t_p [y = p] + t_q [y = q]`.
  - `lambda` has coefficients `(1,1,-1)` or `(1,1,0)`.
  - The patches `p != q` share a symbol, and `t_p, t_q` lie in `{1, 2}`.
  - Script key: `(lambda, p, q, t_p, t_q)`, with `-1` written `2`.
- **Census** (seed artifact, Section 6). There are 855 raw rigid unbalanced rules.
  - 126 have a collapsing diagonal. They are settled by Corollary 5.2 there.
  - 30 are in class `II`.
  - The other 699 are the subject here:

    | `I_0` | 195 | 0 |
- **Reduction** (seed artifact, Theorem 4.1 proof). A collision over `H` extends to `G`. For amenable `H`,
  injectivity forces `mu` balanced, which it is not. So only nonamenable `H` matter.
- **Status.**

## 1. Moves and realization

- **Model group.** `K` is `F(a, b)`, or `<a, b | d^k>` with `d` in `{a, b, c}` and `k` in `{2, 3}` (normal forms in
  `level2.py`).
- **Moves.** A move is a finite support `S` in `K`, with before and after values on `S` and context values on the
  other sites of the touched windows `S M^-1`. It is valid if every touched window keeps its `mu` value.
- **Realization.** Let `H` be a marked quotient of `K`. A move realizes in `H` if coinciding sites carry equal
  data. Changed sites may coincide only when their changes agree.
- **Conflicts.** A pair of sites `u, w` with unequal data conflicts, and its relator is the cyclic word
  `u^-1 w` up to rotation and inversion (`canon` in `tp.py`; `A = a^-1`, `B = b^-1`). A move realizes in `H`
  when no relator of a conflicting pair holds in `H`.
- **Dropped relators.** Suppose `H` is nonamenable and `1, a, b` are distinct. A relator `r` cannot hold in `H` if
  `<a, b | r>` (with the model relator) is amenable, by the quotient rule. Nor can a breaker `A`, `B` or `Ab` hold,
  since these say `a = 1`, `b = 1` or `a = b`. Such relators are dropped.
- **Labels.** `a2` stands for the relator `AA`, that is `a^2 = 1`; `c3` stands for `AbAbAb`, that is `c^3 = 1`;
  and so on.
- **Patterns.** For a nonamenable `H`, let `T(H)` be the set of labels among `a2, a3, b2, b3, c2, c3` that hold.
  A pattern `P` is *forced amenable* (`amenable` in `census_moves.py`) in three cases:
  - it contains `d2` and `d3` for some `d`, a breaker;
  - it has a label for each of `a, b, c`, so `H` is a quotient of `<x, y | x^k, y^m, (xy)^n>` with `x = a^-1`,
    `y = b` and `k, m, n` in `{2, 3}`, which is finite or the Euclidean `(3,3,3)` group;
  - it has two labels of order 2, so `H` is generated by two involutions and is a quotient of `D_infinity`.

  `T(H)` is never forced amenable.

## 2. Level 1: two-site shapes over free memory

- **Shapes.** The shape `1a` has support `{1, a}`, 5 windows and 11 sites. The shapes `1b` and `ab` come from `1a`
  by the symmetries below (`shape_words` in `tp.py`). A rule's class is the number of shapes that have a valid move.
- **Relators.** By hand, every relator among the 55 pairs of `1a` falls in one class:

  | class | relators |
  |---|---|
  | breaker | `A`, `B`, `Ab` |
  | cyclic `H` | `AB`, `AAB`, `AAb`, `ABB`, `Abb`, `AAAb`, `Abbb`, `AAbAb` (`a = c^2`), `AbAbb` (`b = c^-2`) |
  | Klein bottle group | `AAbb` (`a^2 = b^2`), `ABAb`, `ABaB` |
  | `Z^2` | `ABab` |
  | kept | `AA`, `AAA`, `BB`, `BBB`, `AbAb`, `AbAbAb`, the labels `a2 ... c3` |
- **Other shapes.** Two automorphisms carry the table to `1b` and `ab`:
  - the mirror `a <-> b` maps windows to windows and `1a` to `1b`;
  - the involution `psi: a -> a^-1, b -> a^-1 b` satisfies `psi(g{1, a, b}) = psi(g) a^-1 {1, a, b}`, so
    `x -> psi(a^-1 x)` maps windows to windows and `ab` to `1b`.

  Both permute the breakers, preserve amenability and permute the labels. The mirror swaps `a` with `b`, and `psi`
  fixes `a2`, `a3` and swaps `b` with `c`. So every relator of `1b` and `ab` falls in the class of its preimage.
- **Why completeness matters.** `census_moves.py` keeps only the words in `TORS` and drops every other relator, so
  level-1 soundness rests on this table covering every pair. Every pair that meets a changed site counts as
  conflicting, which is the safe direction.
- **Conflict sets.** `census_moves.py` computes, for every valid move of every shape, the set of kept labels on
  conflicting pairs. It keeps the minimal ones.
- **Residuals.** If no level-1 move realizes, then `T(H)` meets every minimal set. A *residual* is a minimal pattern,
  not forced amenable, that meets every minimal set. So `T(H)` contains a residual.
- **Output.** `level1.txt` has one row per residual profile, with an example rule and its sets. For instance, all
  276 rules with `lambda = (1,1,0)` have only the shape `1a` and residuals `{a2}` or `{a2}, {a3}`.
- **Consistency with the seed.** `mu_3` lies in the `I_3` row with residual `{c2}`. That matches Theorem 4.1 of the
  seed artifact.

## 3. Level 2: swaps and cycles

**Swaps.** For `d` in `{a, b, c}`, work in `K = <a, b | d^2>`. The support is `{1, d}`, with 4 windows and 8 sites
(`universe2.txt`). By hand, the relators for `d = a`, taken modulo `a^2`, are:
- `a`, `b^-1`, `a b^-1`: breakers;
- `b^-2` and `(a b^-1)^2`: with `a^2` these make `H` a quotient of `D_infinity`, since `a` and `b` (or `a` and
  `a b^-1`) generate `H`;
- `a b^-2`: `a = b^2`, so `H` is cyclic;
- `a b^-1 a b`: with `a = a^-1` this says that `a` commutes with `b`, so `H` is a quotient of `Z/2 x Z`.

The table for `d = b` is the mirror image. For `d = c` it has the same words in the generators `c, a` (rename
`a -> c`, `b -> a`), with `b = ac`. One class changes:
- `c`, `a^-1`: breakers;
- `c a^-1`: `c = a`, so `b = a^2` and `H` is cyclic;
- `a^-2` and `(c a^-1)^2`: quotients of `D_infinity`;
- `c a^-2`: cyclic;
- `c a^-1 c a`: `c` commutes with `a`.

**Lemma 3.1.** Let `H` be nonamenable, with `1, a, b` distinct and `d^2 = 1`. Then every valid `d`-swap realizes in
`H`.

*Proof.* Every pair relator is a breaker or makes `H` amenable. ∎

**Cycles.** For `d^3 = 1`, the support is `{1, d, d^-1}` in `K = <a, b | d^3>`, with 6 windows and 12 sites. By
hand, the relators for `d = a`, taken modulo `a^3`, are:
- `a`, `b^-1`, `a b^-1`: breakers;
- `a b`, `a b^-2`, `a b^2`: `a` is a power of `b`, so `H` is cyclic;
- `a b^-1 a b`: `b^-1 a b = a^-1`, so `H` is a quotient of `Z/3 x| Z`;
- `a b^-1 a^-1 b^-1`: `a b a^-1 = b^-1`. Conjugating three times gives `b = b^-1`, and then `a` and `b` commute:
  `Z/6`;
- `a b^-1 a^-1 b`: `a` commutes with `b`, so `Z/3 x Z`;
- `b^-2` and `(a b^-1)^2`: the labels `b2` and `c2`, since `(a b^-1)^2` is conjugate to `c^-2`. They are kept
  because `Z/3 * Z/2` is nonamenable.

The table for `d = b` is the mirror image, with kept labels `a2` and `c2`. The table for `d = c` (`universe2.txt`,
model `c3`) is not the `a`-table renamed, but it has the same classes. By hand, modulo `c^3`, with `b = ac`:
- `c`, `a^-1`, `c a`: breakers (`c a = 1` says `b = 1`);
- `c a^-2`, `c a^-1`, `c a^2`: `c` is a power of `a`, so `H` is cyclic;
- `c a^-1 c a`: `a^-1 c a = c^-1`, so `H` is a quotient of `Z/3 x| Z`;
- `c a^-1 c^-1 a^-1`: `c a c^-1 = a^-1`. Conjugating three times gives `a = a^-1`, and then `a` and `c` commute:
  `Z/6`;
- `c a^-1 c^-1 a`: `c` commutes with `a`, so `Z/3 x Z`;
- `a^-2` and `(c a)^2`: the labels `a2` and `b2`, since `(c a)^2 = a^-1 b^2 a`. They are kept.

`level2b.py` asserts that every `e2` pair of a cycle joins two context sites.

**Lemma 3.2.** Let `H` be nonamenable, with `1, a, b` distinct and `d^3 = 1`. Then a valid `d`-cycle realizes in `H`
provided that every `e2` context pair with `e^2 = 1` in `H` carries equal values.

*Proof.* By the cycle tables, every pair relator other than the two kept labels is a breaker or makes `H` amenable,
so it does not hold in `H`. The kept labels are `e2` for the two letters `e` other than `d`, and their pairs join
two context sites. If `e^2 ≠ 1` in `H`, those sites stay distinct. If `e^2 = 1`, they carry equal values by
hypothesis. So coinciding sites always carry equal data. ∎

**Closure test** (`close` in `level2b.py`). For each residual `R`, and each pattern `P ⊇ R` that is not forced
amenable, find one of:
- some `d2` in `P` with a valid `d`-swap;
- some `d3` in `P` with a valid `d`-cycle whose `e2` pairs carry equal values for every `e2` in `P`.

The search for a move with given equalities is `feasible` in `level2b.py`.

**Theorem 3.3.** If a rule in `I_3` or `I_1` passes the closure test for all its residuals, then `tau` is not
injective over any `G`.

*Proof.* Take `H` nonamenable, and put `P = T(H)`.
- If a level-1 move realizes, we are done.
- Otherwise `P` contains a residual `R`, and `P` is not forced amenable.
  - If the test uses a swap for `d2` in `P`, it realizes by Lemma 3.1.
  - If it uses a cycle for `d3` in `P`, it realizes by Lemma 3.2. The labels outside `P` do not hold in `H`, and
    the pairs for labels in `P` carry equal values.

The collision over `H` extends to `G`. For amenable `H`, Section 0 applies. ∎

**Strict and relaxed swaps.**
- **Strict run** (`level2b_strict_swap.txt`, `python3 level2b.py --strict-swap`). It also forced equal values on
  the `e2` pairs of swaps. It left 174 rules open.
- **Relaxed run.** By Lemma 3.1 no `e2` can hold beside `d2`, so those equalities are unnecessary. The census below
  is the relaxed run, `level2b.txt`.

**Explicit moves.** `explicit_moves.py` runs the test on the example rule of every row of Section 4
(`explicit_moves.txt`).
- **Per pattern.** For every pattern `P`, it prints the closing step.
- **Per move.** For every move used, it prints the changes and all context values, then replays every touched
  window by direct evaluation.

A hand re-derivation of a row checks 4 windows per swap and 6 per cycle.

## 5. The 36 open `I_1` rules

- **Rules.** `lambda = (1,1,-1)`, shape `1a` only. The example is
  `mu = x_1 + x_a - x_b + [y = (0,1,0)] - [y = (0,2,1)]`, key `((1,1,2),(0,1,0),(0,2,1),1,2)`.
- **Level 1.** One minimal set, `{a2, a3, b2, c2}` (`level1.txt`, the 36-rule row). Every valid `1a` move has a
  conflict for each of the four labels.
- **Level 2.** The closure test fails only at `P = {a3}`. At `P = {a3}` no valid `a`-cycle exists, even with no
  equalities imposed. The other patterns containing `a3` close (`explicit_moves.txt`):
  - `{a3, b2}` by the `b`-swap and `{a3, c2}` by the `c`-swap;
  - `{a3, b3}` by the `b`-cycle and `{a3, c3}` by the `c`-cycle.
- **Where it stops.** The open placements are nonamenable `H` where `a^3 = 1` is the only label that holds. There,
  every `1a` move fails and no `a`-cycle exists. The next supports to try are three-site supports in
  `<a, b | a^3>`, searched with the dynamic program of `i0_dp.py` over the normal forms of `level2.py`.
- **Strict run.** It left 174 rules open. The failing patterns were `{a2}` in 114 rules, `{a3}` in 36, `{a3,b2}`
  in 6, `{a3,c2}` in 6, `{b2}` in 60 and `{c2}` in 60 (counts overlap). Relaxing the swaps closes all of them
  except the 36 at `{a3}`.

## 6. Class `I_0`

- **Rules.** There are 195 rules, all with `lambda = (1,1,-1)`.
  - By the seed census, each has no valid two-site move and one doubly blind coordinate pair `(i, j)`
    (`B[i] & B[j]` in `i0_close.py`).
  - The pairs are `1a` (39 rules), `1b` (78) and `ab` (78).
- **Path support** (`path` in `i0_path.py`). Let `k` be the third coordinate. The support is `s_0 = m_k`,
  `s_1 = m_i` and `s_2 = m_i m_j^-1 m_k` in `F(a, b)`, with 7 windows and 15 sites:
  - `1a`: `{b, 1, a^-1 b}`;
  - `1b`: `{a, 1, b^-1 a}`;
  - `ab`: `{1, a, a b^-1}`.
- **Conflict sets** (`min_conflicts` in `i0_dp.py`). A dynamic program over the 7 windows, with dominance pruning,
  returns the minimal sets of kept relators over all valid path moves.
- **Relators** (`i0_universe.txt` lists every relator with the site pairs it identifies). The breaker, cyclic,
  Klein, `Z^2` and label classes are those of Section 2. The script marks the others `BS` or `?`. By hand:

  | class | relators | reason |
  |---|---|---|
  | `BS(1, ±2)`: amenable, dropped | `AABAb`, `AABab`, `AAbaB`, `ABBab`, `ABaBB`, `ABabb`, `ABaBab`, `ABabAb`, `AAbAbb` | below |
  | free-by-cyclic: kept | `ABAbb`, `ABBAb`, `ABAbAb`, `ABaBAb`, `AABaB`, `AAbab`, `ABaBaB` | Lemma 6.1 |
  | torus knot: kept | `AAAbb` (`a^3 = b^2`), `AAbbb` (`a^2 = b^3`) | modulo the center, `Z/2 * Z/3` |

- **`BS` relators.** Each says that one generator conjugates another to its power `±2`, so `H` is a quotient of a
  metabelian group:
  - `AABAb`: `b^-1 a b = a^-2`; `AABab`: `b^-1 a b = a^2`; `AAbaB`: `b a b^-1 = a^2`;
  - `ABBab`: `a b a^-1 = b^2`; `ABaBB`: `a^-1 b a = b^-2`; `ABabb`: `a^-1 b a = b^2`;
  - with `b = a c`: `ABaBab` gives `a c a^-1 = c^2`, `ABabAb` gives `a^-1 c a = c^2`, and `AAbAbb` gives
    `a c a^-1 = c^-2`.

**Lemma 6.1.** For each free-by-cyclic word `w` of the table, `<a, b | w>` contains `F_2`.

*Proof sketch.*
- **Map to `Z`.** Let `(s_a, s_b)` be the exponent sums of `w`, and put `phi(a) = s_b`, `phi(b) = -s_a`. The
  `phi`-levels after each letter of the cyclic word are:

  | `w` | `(s_a, s_b)` | levels |
  |---|---|---|
  | `ABAbb` | `(-2, 1)` | `-1, -3, -4, -2, 0` |
  | `ABBAb` | `(-2, -1)` | `1, -1, -3, -2, 0` |
  | `ABAbAb` | `(-3, 1)` | `-1, -4, -5, -2, -3, 0` |
  | `ABaBAb` | `(-1, -1)` | `1, 0, -1, -2, -1, 0` |
  | `AABaB` | `(-1, -2)` | `2, 4, 3, 1, 0` |
  | `AAbab` | `(-1, 2)` | `-2, -4, -3, -1, 0` |
  | `ABaBaB` | `(1, -3)` | `3, 4, 1, 2, -1, 0` |

  In every row the maximum and the minimum are each attained once.
- **Kernel.** By Brown's criterion for two-generator one-relator groups, `phi` and `-phi` lie in `Sigma^1`, so
  `ker phi` is finitely generated. A finitely generated normal subgroup of a one-relator group with quotient `Z`
  is free. So `G = F_n x| Z`.
- **Rank.** The exponent sums are coprime, so `G` has abelianization `Z`.
  - `n = 1` is impossible, since `Z^2` and the Klein bottle group have other abelianizations.
  - If `n = 0`, then `G = Z`, so `w` is primitive in `F(a, b)` (Magnus). But in each `w` one generator occurs with
    both signs, which no cyclically reduced primitive word allows.

  So `n >= 2`. ∎

**Moves for every `I_0` rule** (`i0_close.txt`).

**Proposition 6.2.** Let `mu` be in `I_0`, and let `H` be nonamenable with `1, a, b` distinct. Suppose that one of
`a^2`, `b^2`, `c^2`, `b^3`, `c^3` is `1` in `H`, or that `a^3 = 1` and `mu` has a valid `a`-cycle. Then `tau` is
not injective over `G`.

*Proof.* If `d^2 = 1`, the `d`-swap realizes by Lemma 3.1. Otherwise no `e^2` holds, so the `d`-cycle for the label
`d3` realizes by Lemma 3.2. The collision extends to `G`. ∎

## Hypotheses and internal inputs

- **Setting, from `z-localized-embeds-in-fg-rf-soluble-group`.** Part 2 builds a ring map by sending `β_(R+1)`
  freely to `T`. That needs the lamps `β_k` to be independent, so that `Z[B]` is a Laurent ring in independent
  variables. They are.
  - Suppose `∏ β_k^(n_k)` fixes every `f_j`. Take `k_0` in the support, and a prime `q ≠ l` with
    `q > max |k - k_0|`.
  - Choose `j` with `q | 1 + l(j - k_0)`. Then `q` divides no other factor `1 + l(j - k)`, since it would have to
    divide `l(k - k_0)`.
  - Comparing `q`-adic valuations gives `n_(k_0) = 0`.
- **Item 1.**
  - *The identification with `A[x^(±1); σ]`.* In `Z[H]/(r)`, `x^k u x^(-k) = u + kl` with `u = β - 1`. The two-sided
    ideal `(r)` is `⊕_m x^m I_0`, where `I_0 ⊂ Z[B]` is generated by the `x`-conjugates `β_(k-1) - β_k - l`. So
    each slot is `Z[β_0^(±1), (β_0 - kl)^(-1)] = A`. This matches Step 1 of
    `resolvent-ring-has-path-normal-form-proof`.
  - *Injectivity "slot by slot".* It is correct, but it silently uses `ker ε = (β_k - (1 - lk) : k ∈ Z)`.
    - This holds: `Z[B]/(β_k - (1 - lk))` is the localization of `Z` at the multiplicative set generated by the
      `1 - lk`, and that localization is `Z_(l)`.
    - The reason is that every prime `q ≠ l` divides some `1 - lk`, and `l` divides none.
    - The same fact makes `M` cyclic over `Z[H]`.
    - Add this line to the route.
- **Item 2: correct.**
  - Conjugation by `x^m` preserves `Z[B]`, so the slot components of a finitely generated left ideal lie in an
    ideal involving finitely many lamps.
  - `ε'` is well defined, because every `1 - lk` is a unit of `Z_(l)`.
  - The claim "do not imply the others" follows. The left ideal generated by `β - 1` and all the `r x^k` is exactly
    `J`: telescoping gives every `β_k - (1 - lk)`, and these generate `ker ε`. So if some finite `F` fails to give
    `J`, some omitted `r x^k` is missing.
- **Item 3: correct.**
  - `Z[Q]` is free as a right `Z[H]`-module on left coset representatives, so `Z[Q]J = ⊕ q_α J`.
  - Projecting to the `q_0`-component maps any finitely generated left ideal of `Z[Q]` contained in `Z[Q]J` into
    a finitely generated left ideal inside `J`.

## The Baumslag instance (requested)

The claim is that `⟨a, t⟩ ≅ Z≀Z` in `G = ⟨a, s, t | [s,t], [a,a^t], a^s = a a^t⟩`. I verified it directly.

- **The conjugates `a^(t^i)` commute pairwise.** Induct on the index distance `k ≥ 1`, with base case the relation
  `[a,a^t] = 1`.
  - `s` commutes with `t`, so conjugating `[a, a^(t^k)] = 1` by `s` gives `[a a^t, a^(t^k) a^(t^(k+1))] = 1`.
  - Put `u, v, w, z = a, a^t, a^(t^k), a^(t^(k+1))`. By induction every pair except `(u, z)` commutes.
  - Cancel `v`, which commutes with the other three, and then use that `u` commutes with `w`. This gives
    `uz = zu`.
- **`⟨a, t⟩` is a quotient of `Z≀Z`.** This follows from the previous step.
- **`⟨a, t⟩` surjects onto `Z≀Z`.** The assignment `a ↦ 1`, `t ↦ x`, `s ↦ 1 + x` defines a map
  `G → Z[x^(±1), (1+x)^(-1)] ⋊ Z^2`, because the relations hold there.
  - This map sends `⟨a, t⟩` onto `Z[x^(±1)] ⋊ ⟨x⟩ ≅ Z≀Z`.
  - The composite `Z≀Z → ⟨a,t⟩ → Z≀Z` is the identity on generators.
- So **`⟨a, t⟩ ≅ Z≀Z`**. No source is needed.
- **"Finitely presented metabelian".** Finite presentation holds by definition. "Metabelian" is Baumslag's theorem
  that the map above is an isomorphism (G. Baumslag, Proc. AMS 35 (1972) 61–62), which I did not read at source.
  - Cite it, or drop the adjective.
  - Item 3 holds for every `Q ⊇ H`, so the logic uses neither.

## Wording fixes

- **W1 (BR remark: convention).** The relation `f^(xβx^(-1)) = f^β f^l` holds in `M ⋊ H` only if `f^g` means
  `g · f`, that is, `g f g^(-1)` in the usual semidirect product.
  - KMS fix `u^a = a^(-1) u a` (§4.1). In that convention `f^g = g^(-1) · f`.
  - The relation as written is then false. At `f = f_0` it would read `(1+l)^(-1) = 1 + l`.
  - The relation that holds is `f^(β_(-1)^(-1)) = f^(β^(-1)) f^l`.
  - So the KMS Lemma 4.1 shape, with monic `t - l` (two terms, since `l ≠ 0`) and `⟨F ∪ F'⟩` abelian because the
    lamps commute, is right. But the conjoint pair is `(β_(-1)^(-1), β^(-1))`, not `(β_(-1), β)`.
  - Alternatively, state the convention `f^g := g · f` explicitly.
  - The heuristic that follows ("carried along conjugation by the lamp group") is unaffected, because `B` is
    abelian.
- **W2 (title).** "The Euler base `Z_(l)[y^±1]` is not a finitely presented module over `Z[Q]` for any group
  `Q ⊇ Z≀Z`" is inaccurate, because `M` is not a `Z[Q]`-module. Statement 3 concerns the induced module
  `Z[Q] ⊗_(Z[H]) M`. Say "its induced module is not finitely presented over `Z[Q]`".

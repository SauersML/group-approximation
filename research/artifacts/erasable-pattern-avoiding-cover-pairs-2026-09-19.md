## 0. Conventions

- `(g.x)(h) = x(g^-1 h)`, so `(g^-1 x)(k) = x(gk)`. An automaton `F : A^G → A^G` with memory `M` (finite) and
  local rule `f : A^M → A` is `F(x)(g) = f((g^-1 x)|_M)`. So `F(x)(g)` depends only on `x|_{gM}`.
- `x ~ y`: `x`, `y` differ at finitely many sites; `Δ(x, y)` is the set of those sites.
- A pattern `p` on a finite `P ⊆ G` **occurs at `g` in `x`** if `x(gk) = p(k)` for all `k ∈ P`.
  `X_p = {x ∈ A^G : p occurs nowhere in x}` is a subshift of finite type.
- Strong post-surjectivity with constant `Φ` and lifts in `X`: as in
  `strict-pairs-give-dual-failures-on-bounded-defect-domains`: for every `x ∈ X` and `z ~ F(x)` there is `x' ∈ X`,
  `x' ~ x`, `F(x') = z`, `Δ(x, x') ⊆ Δ(F(x), z)Φ`.
- A **dual failure** at `G` is a post-surjective automaton `F : A^G → A^G` that is not pre-injective, i.e. a
  counterexample to `every-group-is-dual-surjunctive` at `G`.

Imported (verbatim, via `capobianco-kari-taati-dual-surjunctivity-toolkit`, Doucha–Gismatullin, citing CKT
Lemma 1): "A CA T: A^G → A^G is post-surjective if and only if it is strongly post-surjective".

## 1. Theorem

**Theorem D.** Let `G` be a group, `A` a finite alphabet, and `F : A^G → A^G` a post-surjective automaton that is
not pre-injective. Then there is a pattern `w'` on a finite set `L'`, not constant, such that:

1. `X = X_{w'}` is a proper SFT of `A^G` that contains every constant configuration;
2. `F|_X : X → A^G` is strongly post-surjective with lifts in `X`, with constant
   `Φ' = Φ ∪ Φ L'^-1 K`, where `Φ` is a constant for `F` on `A^G` and `K` is defined in §2.

So `(X, F|_X)` refutes CP at `G`. Equivalently: **CP(G) ⇒ dual surjunctivity of G**, group by group.

## 2. Step 1: a context-free erasable pair

Since `F` is not pre-injective there are `x_0 ≠ x_0'` with `x_0 ~ x_0'` and `F(x_0) = F(x_0')`. Put
`K = Δ(x_0, x_0') ≠ ∅` and `L = K M^-1 M ⊇ K`. Let `u = x_0|_L`, `u' = x_0'|_L`; they differ exactly on `K`.

**Lemma E.** Let `y ∈ A^G` and `g ∈ G` with `u` or `u'` occurring at `g` in `y`. Let `y*` be `y` with the values on
`gK` switched to the other pattern (`u` ↔ `u'`). Then `F(y*) = F(y)`.

*Proof.* By equivariance take `g = 1`, and by symmetry say `y|_L = u`. `y` and `y*` differ only on `K`, so
`F(y)(h) = F(y*)(h)` unless `hM ∩ K ≠ ∅`, i.e. `h ∈ K M^-1`. For such `h`, `hM ⊆ KM^-1M = L`, so
`F(y)(h) = f(y|_{hM}) = f(x_0|_{hM}) = F(x_0)(h) = F(x_0')(h) = f(x_0'|_{hM}) = f(y*|_{hM}) = F(y*)(h)`, using
`y|_L = x_0|_L` and `y*|_L = x_0'|_L`. ∎

## 3. Step 2: an unbordered context

For a finite `L' ⊇ L` and a context `c : L' \ L → A`, put `w = u ∪ c` and `w' = u' ∪ c` (patterns on `L'`).
Let `H(L') = K L'^-1 \ {1}`, the set of `h ≠ 1` with `hL' ∩ K ≠ ∅`.

Call `c` **unbordered** if for every `h ∈ H(L')` there is `k ∈ L' ∩ hL'` with `w(k) ≠ w'(h^-1 k)`. In words: no
configuration has `w` at `1` and `w'` at any `h ∈ H(L')`.

**Lemma U.** If `G` is infinite and `|A| ≥ 2`, there are a finite `L' ⊇ L` and an unbordered context `c` that is not
constant.

*Proof.* Fix `L'` and draw `c` uniformly. Fix `h ∈ H(L')` and let `C_h = {k ∈ L' ∩ hL' : k ∉ L, h^-1 k ∉ L}`.
If `c` is not good for `h`, then `c(k) = c(h^-1 k)` for every `k ∈ C_h`. Consider the graph on `L' \ L` with an
edge `{k, h^-1 k}` for each `k ∈ C_h`. Each vertex has at most one edge to `h^-1 k` and one from `hk`, and
`h^-1 k ≠ k` since `h ≠ 1`, so the components are paths and cycles of length at least `2`. A path with `e` edges
imposes `e` independent equalities; a cycle with `e ≥ 2` edges imposes `e - 1 ≥ e/2`. Hence

  `P(c fails at h) ≤ |A|^{-|C_h|/2} ≤ |A|^{-(|L' ∩ hL'| - 2|L|)/2}`,

since removing `k ∈ L` and `k ∈ hL` removes at most `2|L|` points. Also `P(c constant) ≤ |A|^{1 - |L' \ L|}`. So
it suffices to find `L'` with

  (∗) `Σ_{h ∈ H(L')} |A|^{-(|L' ∩ hL'| - 2|L|)/2} + |A|^{1 - |L' \ L|} < 1.`

*Case 1: `G` is not locally finite.* Then some finitely generated subgroup is infinite; enlarging it by `L`,
there is an infinite subgroup `Γ` generated by a finite symmetric `S` with `L ⊆ Γ`. Use the word length `|·|` of
`S` and the balls `B_n` of `Γ`. Let `r = max_{ℓ ∈ L} |ℓ|` and `L' = B_R` with `R ≥ r`. Every `h ∈ H(L')` lies in
`K B_R ⊆ Γ`, so `|h| ≤ R + r`. Write `h` as a geodesic word of length `ℓ ≤ R + r` and let `m` be its prefix of
length `⌈ℓ/2⌉`. Then `|m| ≤ ⌈ℓ/2⌉` and `|m^-1 h| ≤ ⌈ℓ/2⌉`, so with `ρ = R - ⌈(R + r)/2⌉` we get
`m B_ρ ⊆ B_R ∩ h B_R`, hence `|L' ∩ hL'| ≥ |B_ρ|`. Also `|H(L')| ≤ |B_{R+r}| ≤ |B_ρ|^2 |B_{2r+2}|` by
submultiplicativity, as `R + r ≤ 2ρ + 2r + 2`. So the left side of (∗) is at most

  `|B_ρ|^2 |B_{2r+2}| · 2^{-(|B_ρ| - 2|L|)/2} + 2^{1 - |B_R| + |L|}`,

which tends to `0` as `R → ∞`, because `|B_ρ| → ∞` (`Γ` is infinite).

*Case 2: `G` is locally finite and infinite.* Let `L' = Γ` be a finite subgroup containing `L`; such subgroups of
every size exist. Then `hL' = L'` for `h ∈ H(L') ⊆ Γ`, so `|L' ∩ hL'| = |Γ|` and `|H(L')| < |Γ|`. The left side
of (∗) is at most `|Γ| 2^{-(|Γ| - 2|L|)/2} + 2^{1 - |Γ| + |L|} → 0` as `|Γ| → ∞`. ∎

If `G` is finite, every post-surjective automaton is surjective, hence bijective, hence pre-injective, so
Theorem D is vacuous. So Lemma U covers every case that occurs. (`|A| = 1` is trivial.)

**No-creation property.** Let `c` be unbordered. If `y` has `w` at `g`, then `w'` occurs in `y` at no `h ≠ g` with
`hL' ∩ gK ≠ ∅`. (Translate by `g^-1`; then `g^-1 h ∈ H(L')`.) `w'` does not occur at `g` either, since
`w ≠ w'`.

## 4. Step 3: proof of Theorem D

Fix `L'` and a non-constant unbordered `c` from Lemma U, and put `X = X_{w'}`. `w'` is non-constant because
`c` is (it takes two values on `L' \ L`).

**Part 1.**
- `X` is an SFT with one forbidden pattern.
- It is proper: any configuration with `w'` at `1` lies outside it.
- A constant `a^G` restricts to the constant pattern on `L'`, which is not `w'`. So `a^G ∈ X` for every `a ∈ A`.

**Swap step.** Let `y ∈ A^G` and let `Occ(y)` be the set of `g` at which `w'` occurs in `y`. For `g ∈ Occ(y)`, let
`y*` be `y` with `y*|_{gK}` switched from `u'` to `u` (`w'` at `g` gives `u'` at `g`, since `L ⊆ L'`). Then:
1. `F(y*) = F(y)`, by Lemma E.
2. `y*` has `w` at `g`, because `w` and `w'` differ exactly on `K`.
3. `Occ(y*) ⊆ Occ(y) \ {g}`.
   - `y*` and `y` differ only on `gK`.
   - If `hL' ∩ gK = ∅`, then `w'` occurs at `h` in `y*` iff it occurs there in `y`.
   - If `hL' ∩ gK ≠ ∅`, the no-creation property applied to `y*` (which has `w` at `g`) says `w'` does not occur
     at `h` in `y*`. This includes `h = g`.

**Part 2.** Let `Φ` be a constant for `F` on `A^G`; it exists by the imported Doucha–Gismatullin statement. Let
`x ∈ X` and `z ~ F(x)`.
1. **Lift in `A^G`.** There is `x' ~ x` with `F(x') = z` and `Δ(x, x') ⊆ Δ(F(x), z)Φ`.
2. **Finitely many bad sites.** `x` has no occurrence of `w'`. So if `g ∈ Occ(x')`, then `gL'` meets `Δ(x, x')`,
   i.e. `g ∈ Δ(x, x')L'^-1`. So `Occ(x')` is finite, of size `n`.
3. **Swap them out.** Apply the swap step `n` times, each time at some remaining occurrence. This gives
   `x' = y_0, y_1, …, y_m` with `|Occ(y_{i+1})| < |Occ(y_i)|`, so `m ≤ n` and `Occ(y_m) = ∅`. Each swap site
   lies in `Occ(y_i) ⊆ Occ(x')`.
4. **Conclusion.** `x'' = y_m` lies in `X`, and `F(x'') = z` by swap property 1.
   - `Δ(x, x'') ⊆ Δ(x, x') ∪ Occ(x')K ⊆ Δ(x, x') ∪ Δ(x, x')L'^-1K`.
   - This is contained in `Δ(F(x), z)(Φ ∪ ΦL'^-1K) = Δ(F(x), z)Φ'`.
   - In particular `x'' ~ x`.

So `F|_X` is strongly post-surjective with lifts in `X` and constant `Φ'`. ∎

**Remark.** Part 2 uses only that `F` is strongly post-surjective on `A^G` and not pre-injective. Post-surjectivity
enters only through the Doucha–Gismatullin constant `Φ`.

## 5. Consequences

1. **CP ⇒ dual surjunctivity, group by group.** Suppose `constant-point-sft-domains-admit-no-post-surjective-covers`
   holds at `G`. Then every post-surjective automaton over `G` is pre-injective. So CP(all groups) ⇒
   `every-group-is-dual-surjunctive`.
   - This strengthens the known `CP ⇒ NPE` (part 2 of `alphabet-enlarging-covers-refute-dual-and-domain-duality`),
     since dual surjunctivity implies NPE by part 1 of the same claim.
   - With `CP ⇒ Gottschalk` (one line, recorded under `injective-automaton-images-are-sft-cover-pairs`), CP(G)
     implies both `Gottschalk(G)` and `DualSurj(G)`. So CP is a common strengthening of both conjectures.

2. **Where the pair lands in the split `CP ⟺ Gottschalk ∧ CP_col`.** Let `G` be surjunctive and let `F` be a dual
   failure at `G`.
   - By `pointed-pre-injective-cover-pairs-admit-sections` (Theorem P and Proposition C), the pair `(X, F|_X)` of
     Theorem D collides on the asymptotic class of every constant.
   - So it refutes `CP_col(G)`.
   - Hence `Gottschalk(G) ∧ ¬DualSurj(G) ⇒ ¬CP_col(G)`, i.e. `CP_col(G) ∧ Gottschalk(G) ⇒ DualSurj(G)`.

3. **Class obstruction for the converse `Gottschalk(G) ⇒ CP(G)`.** This is needs 36774ad3 (PRUNE) and 06d50d0e
   (coset lift), via `CP_col`.
   - Invariant: the pair of Theorem D. It exists whenever `G` has a dual failure.
   - Dying step: any argument deriving `CP(G)` from `Gottschalk(G)` applies to that pair. So it proves
     `surjunctive-groups-are-dual-surjunctive` at `G`, which is OPEN. Over all groups it proves the universal form.
   - So no proof of the converse is cheaper than "surjunctive ⇒ dual surjunctive". A proof of the converse must
     in particular turn a post-surjective, non-pre-injective full-shift automaton over a surjunctive group into a
     contradiction.
   - Conversely, a dual failure at a surjunctive group, if one exists, refutes the converse outright.

4. **Deficiency is not forced.** The Theorem D pair need not be deficient. Every constant of `A^G` lies in `X`,
   and `F` maps constants to constants, but `F` need not permute them. So this family is not covered by the
   deficiency class kill of `cover-pair-sections-force-fixed-point-surjectivity`, and it differs from the
   alphabet-enlarging family, which is always deficient.

5. **Spark (not pursued).** Is `X_{w'}` strongly irreducible for a suitable choice of `c`? If it is, then
   `(X, F|_X)` is a counterexample to `proper-sft-domains-admit-no-dual-failures` whenever `F|_X` is not
   pre-injective. Over a surjunctive `G` it is not, by item 2. That would give
   `PSD(G) ∧ Gottschalk(G) ⇒ DualSurj(G)`. This is not checked: a single forbidden pattern with small
   self-overlap is a natural candidate for strong irreducibility, but no gluing argument is given here.

### Item 1: hypotheses match (PASS)

- `steinberg-groups-of-fp-rings-are-fp-in-rank-five` needs `R = Z<g_1,...,g_d | ρ_1,...,ρ_l>`, a finitely presented
  unital ring, and `n ≥ 5`.
- `T_l` is such a ring with `d = 6`: its generators are `e, u, x, x', B, m`, and it has the listed relations, each
  written as `ρ = 0`.
- I checked the presentation proof (item 1 of `euler-triangular-ring-is-fp-rf-proof`). It is correct.
  - Every generator satisfies `g = eg`, so `(1-e)R' = Z(1-e)`.
  - `m g = m e g = 0`.
  - The Peirce decomposition is `R' = D' ⊕ D'm ⊕ Z(1-e)`.
  - Each piece maps isomorphically: `D' → D` has a one-sided inverse, and `D/Du → D'm → M` is the identity.
- So `St_N(T_l)` is finitely presented for `N ≥ 5`.

### Item 3

These parts are correct:
- **Finite generation.** Commutators give monomials, `e_ij(a+b) = e_ij(a) e_ij(b)` gives sums, and `N ≥ 3`.
- **Residual finiteness.** It is inherited from `GL_N(T_l)`, since `T_l` is residually finite and `GL_N` of a finite
  ring is finite.
- **The Whitehead identity.** I recomputed it for noncommutative units: `e_12(a)e_21(-a^(-1))e_12(a) =
  [[0,a],[-a^(-1),0]]`, and multiplying by `w_12(-1)` gives `diag(a, a^(-1))`.

**The mismatch.** The map `g ↦ diag(g, g^(-1), 1, ..., 1)` is not a homomorphism on `G_l`:
`diag(g,g^(-1)) diag(h,h^(-1)) = diag(gh, g^(-1)h^(-1))`, but `diag(gh,(gh)^(-1)) = diag(gh, h^(-1)g^(-1))`.
- `G_l` is nonabelian. The units `x + f` and `1 + u`, where `f = 1 - e`, do not commute.
- Indeed `x(1+u) = (1 + u + le)x`, and `le x ≠ 0` in `D`.
- So "contains `G_l` through `g ↦ diag(g, g^(-1), 1, ..., 1)`" is false as stated.

**The naive alternative also fails.** `g ↦ diag(g, 1, ..., 1)` does not land in `E_N(T_l)`.
- There is a ring map `D → F_l[X^(±1)]` given by `u ↦ 0`, `x ↦ X`, `x' ↦ X^(-1)`, `B ↦ 1`. The relation
  `xu = (u+l)x` becomes `0 = lX = 0`.
- The corner projection `T_l → D`, `[[d,n],[0,k]] ↦ d`, is a unital ring map.
- The composite sends `E_N(T_l)` into `SL_N`, but sends `diag(x+f, 1, ..., 1)` to determinant `X ≠ 1`.

**Repair.** The conclusion itself is true for every `N ≥ 3`. Let `a, b : G_l → Z` be the `x`- and `β`-exponent sums,
through `G_l → Z≀Z → Z^2`. Define

    ψ(g) = diag(g, (x+f)^(-a(g)), (1+u)^(-b(g)), 1, ..., 1).

- `ψ` is an injective homomorphism into `GL_N(T_l)`, because each diagonal slot is a homomorphism.
- `G_l` is generated by `x + f`, `1 + u` and `1 + m`. This is because `M = Z[H] f_0` is cyclic (report 86b226622):
  conjugating `[[1,n],[0,1]]` by `[[h,0],[0,1]]` gives `[[1,hn],[0,1]]`.
- The generators land in `E_3(T_l)`:
  - `ψ(x+f) = diag(x+f, (x+f)^(-1), 1)` and `ψ(1+u) = diag(1+u, 1, (1+u)^(-1))`, both by Whitehead;
  - `ψ(1+m) = diag(1+m, 1, 1)`, which equals `e_12(e) e_21(m) e_12(-e) e_21(-m)`. I checked this product directly,
    using `em = m` and `me = 0`.
- So `ψ(G_l) ≤ E_3(T_l) ≤ E_N(T_l)`.

Replace the formula with `ψ`. This item is off the critical path, which only uses `ι(M) ⊂ St_N(T_l)`.

## 2. Attempt 1 inputs: what I could read

### (T1) Triangular K-theory

- **Primary source, not reached.** Berrick–Keating, *The K-theory of triangular matrix rings*, Contemp. Math. 55
  (1986), Part I, 69–74. The AMS site returns 403.
- **Secondary source, read.** C. C. Xi, *Higher algebraic K-groups and D-split sequences*, arXiv:1107.5380v1,
  Lemma 4.1, p. 8, verbatim:

  > "[1] If R_i is a ring with identity for i = 1, 2, and if M is an R_1-R_2-bimodule, then, for the triangular
  > matrix ring S = (R_1 M; 0 R_2), there is an isomorphism of K-groups: K_n(S) ≃ K_n(R_1) ⊕ K_n(R_2) for all
  > integers n ∈ Z. Moreover, this isomorphism is induced from the canonical inclusion of R_1 ⊕ R_2 into S."

  - Reference [1] is Berrick–Keating as above.
  - The same page adds: "For n = 1, 2, this was already shown by Dennis and Geller in 1976."
- **Hypotheses.** There are none beyond unital rings and a bimodule; in particular no flatness or projectivity of `M`.
  `T_l = [[D, M],[0, Z]]` matches.
- **What it gives, and what it does not.** Stable `K_2(T_l) ≅ K_2(D) ⊕ K_2(Z)`. It says nothing about unstable
  `K_2(N, T_l)`.

### (T2) `K_2(D)`

- **The fibration is sourced in the repo.** `abc-twisted-laurent-k-theory-fibration` records ABC Theorem 3.6 and
  Lemma 7.2, which were read at source.
  - Hypotheses: `A` regular supercoherent, and `σ` a unital automorphism.
  - `A = Z[u][π_k^(-1)]` is regular Noetherian, so every `A[t_1..t_p]` is regular Noetherian, hence coherent.
  - `σ(u) = u + l` permutes the primes `π_k = u + 1 + kl`, so it is an automorphism of `A`.
  - This gives the exact sequence `K_2A →(1-σ) K_2A → K_2 D → K_1A →(1-σ) K_1A`, as (T2) states.
- **The localization step (Quillen, regular Noetherian) was not read.** The `K_1` part follows from it. Since
  `[Z[u]/π_k] = 0` in `K_0(Z[u])`, we get `K_1(A) = ±1 × ⊕_k Z π_k` and `SK_1(A) = 0`.
- The `σ`-invariants are `±1`, as the node says.

### (T3) Stability and centrality

- **Centrality, secondary source, read.** E. Voronetsky, *Centrality of K_2-functor revisited*, arXiv:2004.08551v2,
  p. 1, verbatim: "From surjective stability for K_2 (see [2]) it follows that K_2(n,A) is central if
  n ≥ sr(A)+2."
  - This gives centrality with no injective stability, once `sr(T_l)` is finite.
- **Stafford: hypothesis mismatch.** Stafford's bound `sr ≤ Kdim + 1` is a theorem about **right** Noetherian rings
  (*On the stable range of right Noetherian rings*, Bull. LMS 13 (1981); not read).
  - `T_l` is left Noetherian, but it is **not right** Noetherian: `M_Z = ⊕ Z_(l)` is not finitely generated.
  - Either of two fixes works; neither source was read.
    - Apply Stafford to `T_l^op`, and use Vaserstein's left–right symmetry of stable rank.
    - Or use `sr(R) = sr(R/J)` for `J` inside the Jacobson radical. Here the square-zero ideal `[[0,M],[0,0]]` gives
      `sr(T_l) = sr(D × Z) = max(sr D, 2)`, and `D` is Noetherian on both sides.
- **van der Kallen: out of range.** vdK Theorem 1 (LNM 551, p. 77, read at source, report 7a9be50ac) is for
  **commutative** rings. It does not give injective stability for `T_l`.
  - Its §6 announces "some non-commutative variations", which I did not read.
  - The finite-generation half of the claim needs injective stability of `K_2(N, T_l) → K_2(T_l)` for a
    noncommutative ring, and that still lacks a source.

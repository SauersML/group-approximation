# Commuting-conjugate coset switches and the finite-rank screen (2026-09-16)

Swarm attack on `amenability-of-finite-presentations-is-pi2-complete`.
Everything here is proved in full from standard facts, which are listed where
they are used. No novelty is claimed for the isomorphism in Section 1: it is the
`Z`-lamp version of the invariant graph-product model used in
`finite-orbital-checksum-no-go-proof` and `wreath-presentation-double-coset-obstruction`.
What is new here is how it is used: it turns amenability of a finite presentation
into a bi-index cover event (Section 3). Section 4 then screens out the
polycyclic and metabelian ambient groups.

## 0. Conventions

- `K` is a group, `C <= K` a subgroup generated by a set `S_C`, and `U subset K` a
  finite set.
- `X = K/C` is the set of left cosets, with base point `o = C`, and `K` acts on
  `X` by left multiplication.
- The **cover set** is

```text
D(C,U) = C  cup  C U C  cup  C U^-1 C  subset K.                        (D)
```

- `D(C,U)` is a union of left cosets of `C`, because it is right `C`-invariant.
- A `K`-set `Y` has **finite rank** if `K` has finitely many orbits on `Y x Y`.
- For `Y = K/C` the `K`-orbits on `Y x Y` are in bijection with the double
  cosets `C\K/C`: translate the first coordinate to `o`, and the residual
  stabilizer `C` acts on the second. So the rank of `K/C` is the bi-index
  `|C\K/C|`.

## 1. The presentation is a graph-product extension

Define

```text
Q(K,C,U) = < K, b | [b,c] (c in S_C),  [b, u b u^-1] (u in U) >.        (Q)
```

If `K = <S | R>` is finite, `S_C` is a finite set of words and `U` is a finite
set of words, then `(Q)` is the explicit finite presentation
`< S, b | R, [b,c], [b, u b u^-1] >`, and it is computed uniformly from the data.

The graph `Gamma = Gamma(K,C,U)` has vertex set `X` and edge set

```text
E = { {gC, g u C} : g in K, u in U, uC != C }.                          (E)
```

`E` is `K`-invariant. Write `A(Gamma)` for the right-angled Artin group with
vertex generators `beta_x` (`x in X`) and relators `[beta_x, beta_y]` for
`{x,y} in E`. Each `k in K` permutes the generators by `beta_x -> beta_(kx)`. This
permutation maps the relator set onto itself, so it defines an automorphism of
`A(Gamma)`. The result is an action of `K`, and we form `A(Gamma) x| K`.

**Theorem 1.** The assignments `k -> k` and `b -> beta_o` define an isomorphism
`Q(K,C,U) -> A(Gamma) x| K`.

*Proof.*

**Forward map.** Define `phi` on generators by `k -> (1,k)` and `b -> beta_o`. We
check the relators.

- The relators of `K` hold in the complement `K`.
- For `c in S_C`, conjugation by `c` sends `beta_o` to `beta_(cC) = beta_o`, so
  `[beta_o, c] = 1`.
- For `u in U`, conjugation by `u` sends `beta_o` to `beta_(uC)`, so
  `phi([b, u b u^-1]) = [beta_o, beta_(uC)]`. This is trivial: it is a defining
  relator when `{o, uC}` is an edge (take `g = 1`), and it is `[beta_o, beta_o]`
  when `uC = C`.

So `phi` is a homomorphism by von Dyck's theorem.

**Backward map on `A(Gamma)`.** Define `psi_A` by `beta_(kC) -> k b k^-1`.

- *Well defined on vertices.* If `kC = k'C` then `k' = kc` with `c in C`. The
  element `c` is a product of elements of `S_C` and their inverses, each of which
  commutes with `b` in `Q`. So `c b c^-1 = b` and `k' b k'^-1 = k b k^-1`.
- *Relators hold.* Every edge has the form `{gC, guC}`, and
  `[g b g^-1, g u b u^-1 g^-1] = g [b, u b u^-1] g^-1 = 1` in `Q`.

So `psi_A : A(Gamma) -> Q` is a homomorphism.

**Backward map on `K`.** Let `psi_K : K -> Q` be the evident map; the relators of
`K` hold in `Q`.

**Gluing.** The two maps are compatible with the action. On generators,

```text
psi_K(k) psi_A(beta_(gC)) psi_K(k)^-1 = (kg) b (kg)^-1 = psi_A(beta_(kgC)).
```

Both sides of `psi_K(k) psi_A(a) psi_K(k)^-1 = psi_A(k.a)` are homomorphisms in
`a`, so the identity holds for all `a`. By the universal property of the
semidirect product, `psi(a,k) = psi_A(a) psi_K(k)` is a homomorphism
`A(Gamma) x| K -> Q`.

**Inverse.** We check both composites on generating sets.

- `psi phi` fixes `k` and sends `b -> beta_o -> b`.
- `phi psi` fixes `k` and sends `beta_(kC) -> k b k^-1 -> k beta_o k^-1 = beta_(kC)`.

Hence `phi` and `psi` are inverse isomorphisms. `QED`

## 2. Adjacency is the cover set

**Lemma 2.**

(a) `K` acts on `Gamma` by graph automorphisms, transitively on vertices.

(b) The neighbours of `o` are exactly the vertices `x != o` with
`x subset CUC cup CU^-1 C`.

(c) `Gamma` is a complete graph iff `K = D(C,U)`.

*Proof.*

(a) `E` is `K`-invariant, and `K` is transitive on `X`.

(b) We find the neighbours of `o`.

- *Every such neighbour lies in the cover set.* Suppose `{o, y} = {gC, guC}`
  with `u notin C`.
  - If `gC = C`, then `g in C` and `y = guC subset CuC`.
  - If `guC = C`, then `g in C u^-1`, and `y = gC subset C u^-1 C`.
- *Every such coset is a neighbour.*
  - If `y = c u c' C = c u C` with `y != o`, then `u notin C`. With `g = c` we
    get `{gC, guC} = {o, y}`.
  - If `y = c u^-1 C != o`, then `u notin C`. With `g = c u^-1` we get
    `gC = y` and `guC = cC = o`.

(c) Suppose `Gamma` is complete. By (b), every coset other than `o` lies in
`CUC cup CU^-1 C`, so `K = D(C,U)`.

Conversely, suppose `K = D(C,U)`. Then every `y != o` is adjacent to `o`. Given
distinct vertices `x = kC` and `y`, the vertex `k^-1 y` is distinct from `o`, so
`{o, k^-1 y}` is an edge. By (a), `{x, y} = k.{o, k^-1 y}` is an edge. `QED`

## 3. The amenability dichotomy

Standard facts used:

- `(F1)` subgroups of amenable groups, and extensions of amenable groups by
  amenable groups, are amenable;
- `(F2)` abelian groups are amenable;
- `(F3)` `F_2` is not amenable;
- `(F4)` a surjection from a group generated by two elements onto `F_2`, sending
  the generators to a free basis, is an isomorphism, because the inverse map on
  the basis splits it.

**Lemma 3 (free pairs in RAAGs).** Let `x != y` be non-adjacent vertices. Then
`beta_x` and `beta_y` freely generate a free group of rank two.

*Proof.* Define `rho : A(Gamma) -> F(p,q)` by `beta_x -> p`, `beta_y -> q` and
`beta_z -> 1` for every other vertex `z`.

The map `rho` respects the relators. A relator `[beta_z, beta_w]` has
`{z,w} != {x,y}`, so at least one of `z, w` is outside `{x,y}`. Its image is
therefore a commutator with `1`, which is trivial.

Restricted to `<beta_x, beta_y>`, the map `rho` sends the two generators to a
free basis. Apply `(F4)`. `QED`

**Theorem 4.** `Q(K,C,U)` is amenable iff `K` is amenable and `K = D(C,U)`.

- When `K = D(C,U)`, we have `Q = Z^(X) x| K`, the permutational wreath product
  `Z wr_X K`.
- When `k notin D(C,U)`, the elements `b` and `k b k^-1` freely generate `F_2`.

*Proof.* Use Theorem 1.

- *`K` not amenable.* `K` is a subgroup of `Q`, so `Q` is not amenable by `(F1)`.
- *`K = D(C,U)`.* By Lemma 2 the graph `Gamma` is complete, so `A(Gamma)` is the
  free abelian group on `X`. `Q` is abelian-by-`K`, so it is amenable when `K` is,
  by `(F1)` and `(F2)`.
- *`k notin D(C,U)`.* Then `kC != o` and `kC` is not adjacent to `o`, by Lemma 2(b).
  Lemma 3 gives the free pair `beta_o = b` and `beta_(kC) = k b k^-1`, and `(F3)`
  and `(F1)` show `Q` is not amenable. `QED`

**Corollary 5 (switch form and upper bound).** Let `e -> (K_e, S_(C_e), U_e)` be a
computable map to finite presentations `K_e`, finite word sets `S_(C_e)` and
finite word sets `U_e`, with every `K_e` amenable. Then `e -> Q_e := Q(K_e, C_e, U_e)`
is a computable map to finite presentations, and

```text
Q_e amenable   iff   K_e = D(C_e, U_e).                                  (SW)
```

The right-hand side is uniformly `Pi^0_2`. It says: for every word `w` there
exist words `c, c'` in `S_(C_e)^(+-1)`, an element `u in U_e` with a sign
`epsilon in {0, +-1}`, and a finite derivation of `w = c u^epsilon c'` in `K_e`.

Therefore any computable family of this kind satisfying `e in TOT iff K_e = D_e`
is a many-one reduction `TOT <=_m AMENABLE_fp`. `QED`

Relation to the recorded screens:

- A positive instance of `(SW)` asserts infinitely many double-coset memberships,
  one for each coset. It is not a finite packet of equations as in
  `finitely-generated-centralizer-switches-are-sigma1`.
- `Q_e` is a quotient of the amalgam `K_e *_(C_e) (C_e x Z)`, and a proper
  quotient as soon as some `u in U_e` lies outside `C_e`. That amalgam
  is a finite graph of groups whose amenable locus is `C_e = K_e`, by
  `finite-graphs-of-amenable-groups-have-sigma1-locus`. The finitely many
  relators `[b, u b u^-1]` are the controller relations that destroy the free
  quotient the root asks for.
- Taking `K = Z`, `C = 1` and `U = J` recovers the shift-RAAG family `G_J` of
  `shift-raag-family-classifies-amenability`, where `U` is infinite. With `U`
  finite and `C = 1`, the cover set `D` is finite, which is why that family never
  becomes a finite presentation. A finite-presentation switch needs `C` of
  infinite index but finite bi-index.

## 4. The finite-rank screen

*Referee attribution (2026-09-16).* Theorem 6 below is a special case of
Y. de Cornulier, arXiv:math/0509090v2 (2006), Proposition 3.20 with Lemma 3.2.
That result says finitely generated nilpotent-by-(virtually polycyclic) groups
have Property (MF), hence Property (BF): finite bi-index implies finite index.
Cornulier's proof uses Roseblade's theorem (his Theorem 3.21). The proof here
is independent of that source and elementary. The open class-three question of
Section 5.1 is Cornulier's Proposition 3.23 / Question 3.24(1) with `n = 3`.

By Corollary 5, a switch family needs ambients `K_e` in which `C_e` has
**infinite** index but finite bi-index, at least on the total branch. If
`|K_e : C_e| < infinity`, then `K_e = D_e` is witnessed by a finite coset table,
as in Corollary 7 below. This section shows that polycyclic ambients and
metabelian ambients never have infinite-index subgroups of this kind.

**Lemma 6.1 (finite index).** Let `L <= K` have index `m`, and let `Y` be a
transitive `K`-set of finite rank. Then:

- `Y` is a union of at most `m` orbits of `L`;
- each `L`-orbit `Y_j` is a transitive `L`-set of finite rank.

*Proof.* Write `K = L g_1 cup ... cup L g_m`. Then `K.p = L.(g_1 p) cup ... cup L.(g_m p)`
for any point `p` of any `K`-set. Applying this to `Y` gives the first claim.
Applying it to `Y x Y` shows each `K`-orbit on `Y x Y` splits into at most `m`
orbits of `L`. The `L`-orbits on `Y_j x Y_j` are among those. `QED`

**Lemma 6.2 (quotients).** Let `N` be a normal subgroup of `K`, and let `Y` be a
transitive `K`-set of finite rank. Then the set `Y/N` of `N`-orbits is a
transitive `K/N`-set of finite rank.

*Proof.* `K` permutes the `N`-orbits and `N` acts trivially on them. The map
`Y x Y -> Y/N x Y/N` is a surjection that is equivariant for `K`, so it cannot
increase the number of orbits. `QED`

**Lemma 6.3 (orbit module).** Let `A` be an abelian normal subgroup of `K`, let
`Y` be a transitive `K`-set of finite rank, fix `y in Y`, and put
`A_y = A cap K_y`. Then:

(a) `S := A K_y` is the setwise stabilizer of the block `A.y`, and `|K : S| = |Y/A|`.

(b) `M := A/A_y` is a `Z[R]`-module, where `R := S/A`. The class of `s = a k` with
`k in K_y` acts by `m A_y -> (k m k^-1) A_y`.

(c) The number of `R`-orbits on `M` is at most the rank of `Y`.

*Proof.*

(a) Since `A` is normal, `g(A.y) = A.(gy)`, so the `A`-orbits are blocks permuted
transitively by `K`. We have `s(A.y) = A.y` iff `sy in A.y` iff `a^-1 s in K_y`
for some `a in A`, that is, iff `s in A K_y`.

(b) An element `k in K_y` normalizes `A` and satisfies `k A_y k^-1 = A cap K_(ky) = A_y`.
So conjugation by `K_y` acts on `M` by automorphisms. The subgroup
`A_y = A cap K_y` acts trivially because `A` is abelian. Hence the action factors
through `K_y/(A cap K_y) = K_y A/A = R`.

(c) The map `a A_y -> a.y` is a bijection `M -> A.y`. For `k in K_y` we have
`k.(a.y) = (k a k^-1).y`, so this bijection is equivariant for `R`. Two pairs
`(y, a.y)` and `(y, a'.y)` lie in one `K`-orbit iff `a'.y` is in `K_y.(a.y)`, iff
`a A_y` and `a' A_y` lie in one `R`-orbit. `QED`

**Lemma 6.4 (lattices).** Let `M` be a finitely generated abelian group of
torsion-free rank `s >= 1`, and let `Lambda` be any group of automorphisms of `M`.
Then `Lambda` has infinitely many orbits on `M`.

*Proof.* The torsion subgroup `T` is characteristic and `M/T = Z^s`.

For `v in M` with image `vbar != 0`, let `c(v)` be the largest integer `n >= 1`
with `vbar in n(M/T)`. Automorphisms preserve every subgroup `n(M/T)`, so `c` is
invariant.

Choose `w` whose image is a basis vector. Then `c(nw) = n` for each `n >= 1`, so
the elements `nw` lie in pairwise distinct orbits. `QED`

**Theorem 6 (finite rank forces finite).** Let `Y` be a transitive `K`-set of
finite rank. Then `Y` is finite if either:

- (i) `K` is virtually polycyclic; or
- (ii) `K` is finitely generated and has an abelian normal subgroup `A` with `K/A`
  virtually abelian. This covers every finitely generated metabelian group,
  including the finitely presented metabelian groups of Baumslag and
  Remeslennikov.

Equivalently, in these groups a subgroup of finite bi-index has finite index.

*Proof of (i).* A group is polycyclic if it has a subnormal series
`1 = L_0 <| L_1 <| ... <| L_n = L` with cyclic factors. Two elementary facts are
used.

- `(P1)` Quotients of polycyclic groups are polycyclic, via the image series.
- `(P2)` Subgroups of polycyclic groups are polycyclic, hence finitely
  generated. For `H <= L` the series `H cap L_i` has factors
  `(H cap L_i)/(H cap L_(i-1))`, and each embeds in the cyclic group
  `L_i/L_(i-1)`. Picking one generator per factor gives at most `n` generators.

By Lemma 6.1 it suffices to treat a polycyclic `L`. We show, by induction on the
derived length `d` of `L`, that every transitive `L`-set `Y` of finite rank is
finite.

*Base case.* If `d = 0`, then `L = 1` and `|Y| = 1`.

*Inductive step.* Suppose `d >= 1`.

1. The last nontrivial derived term `A = L^(d-1)` is an abelian normal subgroup.
   It is finitely generated by `(P2)`.
2. By Lemma 6.2, `Y/A` is a transitive `L/A`-set of finite rank. The quotient
   `L/A` is polycyclic by `(P1)` and has derived length `d - 1`. By induction,
   `Y/A` is finite.
3. By Lemma 6.3, `M = A/A_y` is a finitely generated abelian group with finitely
   many orbits under a group of automorphisms. By Lemma 6.4, `M` has torsion-free
   rank zero, so it is finite.
4. For `g in L`, the orbit `A.(gy)` is in bijection with `A/A_(gy)`, and
   `A_(gy) = g A_y g^-1` because `A` is normal. Conjugation by `g` gives a
   bijection `A/A_y -> A/A_(gy)`, so every `A`-orbit has `|M|` points. There are
   `|Y/A|` of them, so `Y` is finite. `QED`

*Proof of (ii).*

1. **Reduce to one orbit module.** `K/A` is finitely generated and virtually
   abelian, so it is virtually polycyclic. By Lemma 6.2 and part (i), `Y/A` is
   finite. Fix `y` and use Lemma 6.3. The subgroup `S` has finite index in `K`,
   so it is finitely generated. Hence `R = S/A <= K/A` is finitely generated and
   virtually abelian. Choose an abelian subgroup `R_0 <= R` of finite index; it is
   finitely generated. By Lemma 6.3(c) and the splitting argument of Lemma 6.1,
   `R_0` has finitely many orbits on `M`.
2. **Finitely many cyclic submodules.** For `m in M` and `r in R_0`, the element
   `r` is a unit of `Z[R_0]`, so `Z[R_0](rm) = Z[R_0]m`. Hence there are at most
   as many cyclic submodules as `R_0`-orbits.
3. **Finite length.** Every submodule is the union of the cyclic submodules it
   contains, so `M` has finitely many submodules. Strictly increasing chains of
   submodules therefore have bounded length. A chain of maximal length
   `0 = M_0 < ... < M_t = M` has simple factors.
4. **Factors inherit finitely many orbits.** Each `M_i` is `R_0`-invariant, so its
   `R_0`-orbits are among those of `M`. The quotient map
   `M_i -> M_i/M_(i-1)` is `R_0`-equivariant and onto. So each simple factor has
   finitely many `R_0`-orbits.
5. **Factors are fields with finitely generated unit group.** Let `V` be a simple
   `Z[R_0]`-module and pick `0 != v in V`.
   - Simplicity gives `Z[R_0]v = V`, so `V = Z[R_0]/I` with `I = Ann(v)`.
   - Submodules of `Z[R_0]/I` correspond to ideals containing `I`, so `I` is
     maximal and `F := Z[R_0]/I` is a field.
   - Under this identification `r in R_0` acts by multiplication by its image
     `rbar in F^x`. The images form a finitely generated subgroup `Gamma <= F^x`.
   - The `R_0`-orbits on `F` are `{0}` and the cosets `x Gamma`. Finitely many
     orbits means `|F^x : Gamma|` is finite, so `F^x` is finitely generated
     (generators of `Gamma` plus coset representatives).
6. **Lemma 6.5.** A field `F` whose multiplicative group is finitely generated is
   finite. Only two facts are used: subgroups of finitely generated abelian groups
   are finitely generated, and a free abelian group on an infinite basis is not
   finitely generated.
   - *Characteristic zero is impossible.* Then `Q subset F`. The primes are
     multiplicatively independent in `Q^x` by unique factorization, and there are
     infinitely many of them. So `F^x` contains a free abelian subgroup of
     infinite rank, which is a contradiction.
   - *Characteristic `p`, transcendental case is impossible.* Suppose `t in F` is
     transcendental over `F_p`. Then evaluation `F_p[t] -> F` is injective. There
     are infinitely many monic irreducible polynomials: if `f_1..f_k` were all of
     them, an irreducible factor of `f_1...f_k + 1` would be a new one. Their
     values at `t` are multiplicatively independent in `F^x`, by unique
     factorization in `F_p[t]`. This is again a contradiction.
   - *Algebraic case.* Every `x != 0` is algebraic over `F_p`. So `F_p[x]` is a
     finite-dimensional `F_p`-space, hence a finite set. Its powers `x^i` repeat,
     and since `x` is invertible, `x` has finite order. So `F^x` is a finitely
     generated abelian torsion group, which is finite. Hence `F` is finite.
7. **Conclusion.** Every composition factor of `M` is finite, so `M` is finite.
   As in step 4 of (i), every `A`-orbit has `|M|` points, and there are `|Y/A|`
   of them. `QED`

(An earlier draft of step 6 used Zariski's lemma. The argument above replaces it
and uses no commutative algebra beyond unique factorization.)

**Corollary 7 (Sigma^0_1 locus).** Let `e -> (K_e, S_(C_e), U_e)` be as in
Corollary 5. Suppose every `K_e` satisfying `K_e = D_e` falls under Theorem 6(i)
or 6(ii). Then `{e : K_e = D_e}` is `Sigma^0_1`. So such a family is never a
reduction from `TOT`.

*Proof.* A certificate for `e` consists of a finite set `Y`, a permutation
`rho(s)` for each generator `s` of `K_e`, and a point `y_0`, satisfying:

1. every relator of `K_e` acts trivially, so `rho` is an action of `K_e`;
2. the action is transitive;
3. `rho(c) y_0 = y_0` for `c in S_(C_e)`;
4. for each Schreier generator `sigma` of `Stab(y_0)`, read off a spanning tree of
   the Schreier graph, there is a word `c_sigma` in `S_(C_e)^(+-1)` and a finite
   derivation of `sigma = c_sigma` in `K_e`;
5. `Y` is the union of the `<rho(S_(C_e))>`-orbits of `y_0`, `rho(u) y_0` and
   `rho(u)^-1 y_0` over `u in U_e`.

*Soundness.* By Schreier's lemma, conditions 3 and 4 give `Stab(y_0) = C_e`. So
`Y = K_e/C_e` equivariantly, and condition 5 is exactly `K_e = D_e`.

*Completeness.* If `K_e = D_e`, then `C_e\K_e/C_e` has at most `1 + 2|U_e|`
elements, so `K_e/C_e` has finite rank. By Theorem 6 it is finite, and the coset
action is a certificate.

Certificates are finite objects that can be checked by enumeration, so the set is
`Sigma^0_1`. The set `TOT` is not `Sigma^0_1`. `QED`

## 5. What survives, and where the next screen would sit

1. **Solvable class three.** The KMS machine groups `G(M)` used for `RF_fp` lie
   in `A_p^2 A`. They have an elementary abelian normal `p`-subgroup `T`, and
   `G(M)/T` is finitely generated metabelian
   (`research/artifacts/rf-fp-pumped-minsky-part1-2026-09-12.md`, Lemma 4.5 as
   quoted there).
   - Theorem 6(ii) applies to `G(M)/T`, and Lemma 6.3 together with steps 2--3 of
     the proof of (ii) apply to `T`.
   - So an infinite finite-rank transitive action of `G(M)` exists only if some
     finitely generated metabelian `R` has an infinite simple `F_p[R]`-module
     with finitely many `R`-orbits. **This is open here.** Step 5 fails because
     `F_p[R]` is not commutative, so a simple module need not be a field, and
     the multiplicative-group count of Lemma 6.5 has nothing to act on.
   - **Refinement inside `A_p^2 A` (proved here).** Let `K` be finitely
     generated with a series `1 <= A <= N <= K` of normal subgroups, where `A`
     and `N/A` are elementary abelian `p`-groups and `K/N` is abelian. (If `A` is
     only normal in `N`, replace it by the characteristic subgroup
     `N^p[N,N] <= A`.) Let `Y` be an infinite transitive `K`-set of finite rank.
     1. `K/A` is finitely generated with abelian normal `N/A` and abelian
        quotient, so `Y/A` is finite by Lemma 6.2 and Theorem 6(ii). By step 4
        of the proof of (i), `|Y| = |Y/A| . |M|` with `M = A/A_y`, so `M` is
        infinite. By Lemma 6.3(a), `|K : S| = |Y/A|` for `S = A K_y`, so
        `R = S/A` is finitely generated. By Lemma 6.3(c), it has finitely many
        orbits on `M`.
     2. Steps 2--4 of the proof of (ii) work verbatim over the group ring
        `Z[R]`, since only the fact that `r in R` is a unit was used. So `M` has
        finite length, and some simple factor `V` is infinite with finitely many
        `R`-orbits. As `A` has exponent `p`, `V` is an `F_p[R]`-module.
     3. Put `B = R cap (N/A)`. It is an elementary abelian normal `p`-subgroup
        of `R`, and `R/B` embeds in `K/N`, so it is abelian.
     4. *`V^B = 0`.* For `b in B`, `r in R` and `v in V^B`,
        `b(rv) = r(r^-1 b r)v = rv`, so `V^B` is a submodule. If it is nonzero,
        it equals `V`. Then `V` is a simple module over the commutative ring
        `Z[R/B]` with finitely many orbits, and steps 5--6 make `V` finite,
        which is a contradiction.
     5. *Fixed-point count.* A finite `p`-group acting linearly on a finite
        nonzero `F_p`-space `W` fixes a nonzero vector. Its orbits have
        `p`-power sizes, so the number of fixed points is congruent to
        `|W| = 0 mod p`, and `0` is one of them.
     6. *Every nonzero vector has an infinite `B`-orbit.* Suppose `v != 0` has
        finite orbit `Bv`. Then the span `W` of `Bv` is finite, nonzero and
        `B`-invariant. `B` acts on it through a finite `p`-group, so step 5
        gives a nonzero fixed vector of `B`, contradicting step 4.
     7. *Stabilizer constraint.* By step 5, every finite `B_0 <= B` fixes a
        nonzero vector of `V`. By step 4, every stabilizer `B_v` with `v != 0`
        is proper. Since `B_(rv) = r B_v r^-1` and there are finitely many
        orbits, the `B_v` fall into finitely many `R`-conjugacy classes. `B` is
        infinite by step 6. It is countable, being a subgroup of the finitely
        generated group `R`, and elementary abelian, so it is an increasing
        union of finite subgroups. Each of these fixes a nonzero vector (apply
        step 5 to the span of a finite orbit), so it lies in some `B_v`.
        Pigeonhole gives one proper subgroup `H <= B` whose `R`-conjugates
        contain arbitrarily large finite subgroups of `B`.

     So a finite-rank infinite action of a KMS-type ambient needs a simple
     module with no `B`-fixed vector. The support-size invariant of the swarm
     notes does not apply here. The only simple `F_p[B]`-module is trivial:
     every element of the augmentation ideal lies in the group algebra of a
     finite subgroup and is nilpotent there, so it lies in every maximal ideal.
   - **The constraints are consistent: a local-field model (proved here).** Let
     `R = C_p wr Z`. Realize it as `B = F_p[t, t^-1]` (additive) `x| <t>`,
     with `t` acting by multiplication, acting on `k = F_p((t))` by
     `x -> t^j x + b`. Put `O = F_p[[t]]`, and let
     `V = C_c^infty(k, F_p)` be the locally constant, compactly supported
     functions, with `(r.f)(x) = f(r^-1 x)`. Then:
     1. *`V` is countable and infinite.* It is spanned by the indicators of the
        countably many balls `a + t^n O`.
     2. *`V^B = 0`.* A function in `V` is constant on the cosets of some
        `t^n O`. `B` is dense, so `B + t^n O = k`. A `B`-invariant such function
        is therefore constant on `k`, and compact support makes it `0`.
     3. *`V` is simple.* Let `0 != f` lie in a submodule `I`. For some `n`, `f`
        is a finite combination of indicators of cosets of `t^n O`. Identify
        these functions with `F_p[G_n]`, where `G_n = k/t^n O`. `B` maps onto
        `G_n` by density, and translation acts by multiplication, so `I`
        contains the ideal of `F_p[G_n]` generated by `f`.
        - Write `f = delta_(g_0) f_0` with `f_0 != 0` in `F_p[E]` for a finite
          subgroup `E <= G_n`.
        - By the count of step 5, the nonzero ideal `F_p[E] f_0` contains a
          nonzero `E`-fixed element. Such an element is a scalar multiple of
          `N_E = sum_(e in E) delta_e`. Translating by `-g_0`, `N_E` is in `I`.
        - Choose `m <= n` with `E <= E' = t^m O/t^n O`. Then
          `N_(E') = N_E . sum_(c in E'/E) delta_c` is in `I`, and
          `N_(E') = 1_(t^m O)`.
        - Scaling by powers of `t` gives every `1_(t^j O)`. Translating by `B`
          gives every ball, by density. These span `V`, so `I = V`.
     4. The stabilizer in `B` of `1_O` is `B cap O = F_p[t]`, a half-line
        subgroup. Its conjugates `t^-k F_p[t]` contain arbitrarily large finite
        subgroups, consistent with step 7 above.
     5. *Infinitely many orbits.* `R` acts by similarities of the `t`-adic
        metric, and `supp(r.f) = r(supp f)`. For a compact open `S`, the ratio
        of `diam S` to the largest radius `eps` such that `S` is a union of
        balls of radius `eps` is invariant. Take `f_k = 1_O + 1_(t^-k + O)` with
        `k >= 2`, and `S_k = supp f_k`.
        - `diam S_k = |t^-k| = p^k`.
        - `S_k` is a union of two balls of radius `1`.
        - It is not a union of balls of radius `p^j` with `j >= 1`: such a ball
          around `0` is `t^-j O`, which contains `t^-1`, and `t^-1` is not in
          `S_k`.

        So the ratio is `p^k`, and the `f_k` lie in pairwise distinct orbits.
        (For `p = 2` and `k = 1` the support is the single ball `t^-1 O`, which
        is why `k >= 2`.)

     So an infinite simple `F_p[C_p wr Z]`-module with no base-fixed vector
     exists, and the refinement above does not by itself exclude the KMS class.
     The obstruction in this model is metric: a similarity invariant of
     supports.

2. **Non-solvable ambients do exist.** Take a Houghton group `H_n` with `n >= 3`.
   - It is finitely presented and elementary amenable, since `FSym` is normal
     with free abelian quotient. These facts and the stabilizer isomorphism are
     stated in Cornulier, arXiv:math/0509090v2, Example 3.6, citing
     K. S. Brown (1987). Brown's paper was not fetched.
   - It contains `FSym(X)`, so its action on `X` is highly transitive and has
     rank two. A point stabilizer is isomorphic to `H_n`: shifting one ray
     conjugates it onto `H_n`.
   - So with `U = {g}` and `gx != x`, the group `Q(H_n, Stab(x), {g}) = Z wr_X H_n`
     is a finitely presented amenable positive instance with infinite `X`.
   - But `H_n` has solvable word problem and fixed rank, so it cannot carry a
     `Pi^0_2`-hard family by itself.
3. **Wreath lift of a machine group transfers no rank.** Let `K = M wr_X H` with
   `H` highly transitive of rank two with finitely generated stabilizers, and `M`
   finitely presented. Let `K` act on `Y = X x M/P` by
   `(m,h).(x, gP) = (hx, m_(hx) g P)`. This action is transitive.
   - The stabilizer of `(x_0, P)` is `<P_(x_0), M_(x_1), H_(x_0)>`, which is
     finitely generated when `P` is.
   - Its orbits on `Y` are one orbit `{y != x_0}`, plus `P\M/P` on the fibre over
     `x_0`. So the rank is `1 + |P\M/P|`.
   - The wreath lift therefore reduces the cover problem to the machine group's
     own rank. That rank is finite only for finite index when `M` is in the scope
     of Theorem 6.

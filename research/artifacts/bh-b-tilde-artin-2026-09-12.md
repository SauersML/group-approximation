# Boone–Higman for the Euclidean Artin groups of type B̃_n

Lane `bh-survey-open-cases`, 2026-09-12.

**Target.** Problem 5.3(13) of arXiv:2306.16356, for type B̃_n. The target was
chosen in `bh-survey-open-cases-status-2026-09-12.md` §4.

## 1. Result

**Theorem.** Let `n >= 3` and `A = A(B̃_n)`.
1. `A` embeds in `Aut(F_M)`, where `M = 2^n · n! · (3n·2^(n−1) + n + 2)`. For
   `n = 3` this gives `M = 1968`.
2. `A` embeds in a group with a type (A) action, and therefore in a finitely
   presented simple group.
3. `A` is residually finite.

**Why it matters.** Survey Remark 5.4 and BFFHZ (arXiv:2503.21882v2, after
Corollary B) both list type B̃_n as open.

**Ingredients:**
- the Li–Roushon fibration;
- Nguyễn's description of an affine Artin group as the fundamental group of an
  orbit space;
- Artin's representation;
- BFFHZ, as imported in `aut-free-groups-satisfy-permutational-boone-higman`.

Type D̃_n is not reached; see §6.

## 3. What Li–Roushon prove

Quoted from the source, with the LaTeX rendered as text.

1. **The model.** `M_{B̃_n} = {u ∈ C^n | u_i ± u_j ∉ Z for i ≠ j; u_k ∉ Z}`.
   - "W_{B̃_n} acts properly discontinuously on M_{B̃_n} and
     A_{B̃_n} ≃ π_1(M_{B̃_n}/W_{B̃_n})".
   - This gives the exact sequence `1 → π_1(M) → A → W → 1` (Ngu83, §5).
2. **Three changes of space.**
   - The map `z ↦ e^(2πiz)` induces a covering `M → N`, where
     `N = {v ∈ C^n | v_i ≠ v_j^(±1) for i ≠ j; v_k ≠ 0, 1}`.
   - The map `α ↦ (α+1)/(α−1)` induces a homeomorphism `N → P`, where
     `P = {w ∈ C^n | w_i ≠ ±w_j for i ≠ j; w_k ≠ ±1}`.
   - The map `(w, λ) ↦ (λ, λw_1, …, λw_n)` is a homeomorphism from `P × C^×` onto
     `Y_(n+1) = {y ∈ C^(n+1) | y_i ≠ ±y_j for i ≠ j; y_1 ≠ 0}`.
3. **Proposition `fibration`.** For `m >= 3`, let
   - `Y_m = {y ∈ C^m | y_i ≠ ±y_j for i ≠ j; y_1 ≠ 0}`,
   - `Z_m = {z ∈ (C^×)^(m−1) | z_i ≠ z_j}`, and
   - `f(y) = (y_1(y_1² − y_m²), …, y_1(y_(m−1)² − y_m²))`.

   Then `f : Y_m → Z_m` "is a locally trivial fibration, with non-compact
   connected fibers homeomorphic to a 2-manifold of genus (3m−6)2^(m−3)+1, with
   3·2^(m−2) points removed."

   Inside the proof, `Z_m` is aspherical (Fadell–Neuwirth) and
   `1 → π_1(f^−1(z)) → π_1(Y_m) → π_1(Z_m) → 1` is exact.
4. **How the Proposition is proved.**
   - Take the closure `C̄` of the graph of `f` in `P^m × Z_m`. Lemma `lemma B12`
     describes its boundary `B = B_1 ∪ B_2`.
   - The projection `C → Z` is a surjective submersion.
   - `C̄` is smooth and `C̄ → Z` is a proper submersion.
   - `B` is smooth and `B → Z` is a submersion.
   - Thom's first isotopy lemma applied to the strata `{C, B}` gives local
     triviality.
   - Connectedness of the fibre comes from monodromy of `y ↦ y_1`, and the
     genus from Riemann–Hurwitz for the same map.

## 4. Checks made on the imported input

1. **The arrangement has type B̃_n, not C̃_n.**
   - The region `u_1 > u_2 > … > u_n > 0`, `u_1 + u_2 < 1` meets no hyperplane:
     every `u_k` and every `u_i ± u_j` with `i < j` lies in `(0, 1)`. So it is a
     chamber.
   - Its walls are `u_1 + u_2 = 1`, `u_i = u_(i+1)` and `u_n = 0`, with normals
     `e_1 + e_2`, `e_i − e_(i+1)` and `e_n`.
   - `e_1 + e_2` is orthogonal to `e_1 − e_2` and makes `m = 3` with `e_2 − e_3`.
     `e_(n−1) − e_n` and `e_n` make `m = 4`.
   - So the diagram has a branch at one end and a double edge at the other, which
     is B̃_n. The C̃_n arrangement needs `u_k ∈ ½Z` instead (Allcock §4, as in
     `c-tilde-artin-groups-are-punctured-plane-braid-groups`).
2. **W acts freely on M.**
   - Suppose `w ∈ W` fixes `u = x + iy`. Then `w` fixes `x`, so `w` lies in the
     finite parabolic subgroup `W_x`, which is generated by reflections through
     `x`. The linear part of `w` fixes `y`.
   - By Steinberg's theorem, `Stab_(W_x)(y)` is generated by reflections fixing
     `y`. If `w ≠ 1`, one of those reflections has a hyperplane `α = k` with
     `α(x) = k` and `α(y) = 0`, which puts `u` on a complexified hyperplane. That
     is impossible for `u ∈ M`.
3. **The fibres lie inside Y_m.** Fix `z ∈ Z_m`. Every `y` with `y_1 ≠ 0` and
   `y_1(y_i² − y_m²) = z_i` for all `i` already lies in `Y_m`:
   - `y_i² − y_m² = z_i / y_1 ≠ 0`;
   - `y_i² − y_j² = (z_i − z_j) / y_1 ≠ 0`.

   So the fibre over `z` is exactly this affine curve.
4. **Riemann–Hurwitz arithmetic, re-done.**
   - `2g − 2 = −2^m + 3(m−1)2^(m−2) + 2^(m−2) = (3m−6)2^(m−2)`.
   - Punctures: `|B_1^z| + |B_2^z| = 2^(m−1) + 2^(m−2)`.
5. **An independent Euler characteristic check.**
   - For a large prime `q`,
     `#{y ∈ F_q^m | y_1 ≠ 0, y_i ≠ ±y_j} = (q−1)(q−3)⋯(q−(2m−3))(q−m)`. To see
     it, choose `y_1`, then the ±-classes of `y_2, …, y_m`; at most one of them
     is `{0}`.
   - So `Y_m` has Poincaré polynomial `(1+t)(1+3t)⋯(1+(2m−3)t)(1+mt)`, and
     `χ(Y_m / C^×) = (−2)^(m−2)(m−2)!(1−m)`.
   - `g(y) = y_1(y_1² − y_m²)` is homogeneous of degree 3 and does not vanish on
     `Y_m`. So `{g = 1} ∩ Y_m` is a 3-sheeted cover of `Y_m / C^×`.
   - `{g = 1} ∩ Y_m` is the preimage under `f` of
     `Z^1 = {z_1 = 1} ≅ Conf_(m−2)(C − {0,1})`, and `χ(Z^1) = (−1)^(m−2)(m−2)!`.
   - Hence `χ(fibre) = 3·χ(Y_m/C^×) / χ(Z^1) = −3(m−1)2^(m−2)`. This equals
     `2 − 2g − p` for the Li–Roushon values of `g` and `p`.
6. **Local triviality, read but not recomputed.**
   - `C̄ → Z` is a proper submersion, and `B` is a closed submanifold on which the
     projection is a proper submersion.
   - Relative Ehresmann then makes `(C̄, B) → Z` locally trivial, and so
     `C → Z` is.
   - The Jacobian rank computations in Lemmas `submersion` and `smooth` were read,
     not recomputed.

## 5. Derivation

Fix `n >= 3`, and write `A = A(B̃_n)`, `W = W(B̃_n)`, `M = M_{B̃_n}`.

**Step 1. Translations.**
- Each generating reflection of `W` has the form `u ↦ w_0(u) + v`, where `w_0` is
  a signed permutation and `v` lies in the lattice
  `D_n = {v ∈ Z^n | Σ v_i even}`:
  - `u_k = c` gives `u_k ↦ 2c − u_k`;
  - `u_i − u_j = c` gives `(u_i, u_j) ↦ (u_j + c, u_i − c)`;
  - `u_i + u_j = c` gives `(u_i, u_j) ↦ (c − u_j, c − u_i)`.
- `D_n` is invariant under signed permutations, so
  `W ⊆ W(B_n) ⋉ D_n ⊆ W(B_n) ⋉ Z^n`, and `W(B_n) ⋉ Z^n` preserves `M`.
- Let `T = W ∩ Z^n` be the translations in `W`.
  - Composing the reflections in `u_i ∓ u_j = 0` and `= 1` gives the translations
    `e_i ± e_j`, so `T = D_n` and `[Z^n : T] = 2`.
  - The linear-part map `W → W(B_n)` is onto, because the reflections through
    `0` lie in `W`. Its kernel is `T`, so `[W : T] = 2^n n!`.

**Step 2. Coverings.**
- `M` is connected: it is the complement of a locally finite union of complex
  hyperplanes.
- `W` acts freely and properly discontinuously (§4.2), and so does `Z^n`, by
  translations.
- So `A_T := π_1(M/T)` has index `2^n n!` in `π_1(M/W) = A`.
- It also has index `2` in `π_1(M/Z^n)`, and `M/Z^n = N` by the exponential map.

**Step 3. Into Y_(n+1).** `π_1(N) ≅ π_1(P) ≤ π_1(P) × Z = π_1(P × C^×) ≅ π_1(Y_(n+1))`.

**Step 4. A free normal subgroup.**
- Apply Proposition `fibration` with `m = n + 1`. The fibre `F` has genus
  `g = (3n−3)2^(n−2) + 1` and `p = 3·2^(n−1)` punctures.
- So `π_1(F)` is free of rank `r = 2g + p − 1 = 3n·2^(n−1) + 1`, with `r >= 37`.
- The sequence `1 → π_1(F) → π_1(Y_(n+1)) → π_1(Z_(n+1)) → 1` is exact.
- `Conf_(n+1)(C) ≅ C × Z_(n+1)` via `(x_0, …, x_n) ↦ (x_0; x_1 − x_0, …, x_n − x_0)`.
  Hence `π_1(Z_(n+1)) ≅ P_(n+1)`, the pure braid group.

**Step 5. The centreless-kernel embedding.**
- **Lemma.** If `K ⊴ G` and `Z(K) = 1`, then `g ↦ (c_g|_K, gK)` is injective from
  `G` into `Aut(K) × G/K`. Its kernel is `C_G(K) ∩ K = Z(K)`.
- A free group of rank `>= 2` is centreless. So
  `π_1(Y_(n+1)) ↪ Aut(F_r) × P_(n+1)`.

**Step 6. Into one Aut(F_m).**
- `P_(n+1) ≤ B_(n+1) ≤ Aut(F_(n+1))` by Artin's faithful representation.
- `Aut(F_a) × Aut(F_b) ≤ Aut(F_a * F_b) = Aut(F_(a+b))`, acting factorwise.
- Hence `A_T ≤ Aut(F_m)` with `m = r + n + 1 = 3n·2^(n−1) + n + 2`.

**Step 7. Inducing up.**
- A group with a subgroup of index `k` embeds in that subgroup wreathed with `S_k`
  (Krasner–Kaloujnine).
- `Aut(F_m) ≀ S_k ≤ Aut(F_(mk))` by permuting `k` free factors; the action is
  faithful.
- With `k = 2^n n!`, this gives `A ↪ Aut(F_M)`, `M = mk`.

**Step 8. The consequences.**
- **Type (A).** `Aut(F_M)` has a type (A) action
  (`aut-free-groups-satisfy-permutational-boone-higman`), and the property passes
  to subgroups.
- **Simple envelope.** By `type-a-action-gives-boone-higman-for-subgroups`
  (Zaremsky, arXiv:2405.18354, Corollary B), `A` embeds in a finitely presented
  simple group.
- **Residual finiteness.** `Aut(F_M)` is residually finite by Baumslag's theorem
  for automorphism groups of finitely generated residually finite groups, so `A`
  is too.

QED.

## 6. Scope and caveats

- **Range.** `n >= 3`, as in Li–Roushon. The diagram B̃_2 is C̃_2. That case is
  covered by `c-tilde-artin-groups-satisfy-permutational-boone-higman`, and
  survey Remark 5.4 credits it, as a Euclidean triangle Artin group, to
  Bux–Llosa Isenrich–Wu.
- **M is not optimized,** and the embedding in `Aut(F_M)` is not natural.
- **D̃_n stays open.**
  - The argument uses the hyperplanes `u_k ∈ Z`: they force `v_k ≠ 1`, which is
    what lets the Möbius map carry `N` onto a linear arrangement complement.
  - The D̃_n arrangement has only `u_i ± u_j ∈ Z`. Its toric image
    `{v ∈ (C^×)^n | v_i ≠ v_j^(±1)}` contains points with `v_k = 1`, where the
    Möbius step breaks.
  - No fibration with free fibres is known for it. Allcock's picture for D̃_n has
    two cone points, and Flechsig corrects Roushon's earlier pure orbifold braid
    sequence.
- **Other types.** F̃_4, Ẽ_6, Ẽ_7, Ẽ_8 are not addressed.
- **Imported, not reproved:**
  - Li–Roushon's Proposition. The Jacobian ranks were not recomputed; the fibre
    description, the genus arithmetic and the Euler characteristic were checked
    (§4).
  - Nguyễn's theorem.
  - BFFHZ Theorem A.
  - Zaremsky, Corollary B.
- **Residual finiteness** was not given its own novelty search.

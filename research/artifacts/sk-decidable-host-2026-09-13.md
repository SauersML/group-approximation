## 1. The half-line overgroup and its balls
Recalled from `groups-embed-in-derived-subgroup-of-half-line-overgroup` (PASS, sk-verify-7). Let `Γ` be generated by a
finite set `S`, `X = Γ × Z`, `σ(x,m) = (x,m+1)`, and `h_γ` left translation by `γ` on the levels `m ≥ 0`, identity
below. `C(Γ) = ⟨σ, h_s : s ∈ S⟩`.
- `C(Γ) = E ⋊ ⟨σ⟩`, where `E` is the group of sequences `f : Z → Γ`, trivial for `m ≪ 0` and constant for `m ≫ 0`,
  acting levelwise by left translation.
- `σ f σ^(-1) = φ(f)` with `φ(f)(m) = f(m-1)`, so `(fσ^k)(gσ^l) = (f·φ^k(g))σ^(k+l)`.
- `[σ, h_s] = δ_0(s^(-1))`, where `δ_0(γ)` translates level `0` only. So `Γ ≅ δ_0(Γ) ≤ [C(Γ), C(Γ)]`.

**Ball lemma.** Every element of the ball `B_r` of `C(Γ)` (word length in `σ^(±1)`, `h_s^(±1)`) is `fσ^k` with
`|k| ≤ r`, `f(m) = e` for `m < -r`, `f(m) = f(r)` for `m ≥ r`, and `f(m) ∈ B_r(Γ)` for all `m`.

*Proof.* Induct on the length. Appending `σ^(±1)` to `fσ^k` changes `k` by `±1`. Appending `h_s^(±1)` gives
`(f·φ^k(h_s^(±1)))σ^k`, which multiplies `f` by `s^(±1)` on the levels `m ≥ k`. The levels where `f` changes are among
the values of `k` reached, all in `[-r, r]`, and each `f(m)` is a product of at most `r` letters from `S^(±1)`. ∎

## 2. Theorem A: finite models of the balls of C(Γ)
Let `Γ` be LEF and fix `r ≥ 1`.

**Data.**
- `ψ : B_(2r)(Γ) → Q` is a finite model: `Q` is a finite group, `ψ` is injective, and `ψ(ab) = ψ(a)ψ(b)` whenever
  `a, b, ab ∈ B_(2r)(Γ)`. In particular `ψ(e) = e`.
- `M = 3r`, `I = {-M, …, M}`, and `H = Q^I`, a finite group.
- `A = {v ∈ H : v_(M-1) = v_M}` and `B = {v ∈ H : v_(-M) = e}`. The map `θ : A → B`, `θ(v)_(-M) = e`,
  `θ(v)_m = v_(m-1)` for `-M < m ≤ M`, is a group isomorphism, with inverse `w ↦ (w_(-M+1), …, w_M, w_M)`.
- **The bijection `t`.** Left multiplication by `A`, and by `B`, is free on `H`, with `|H|/|A| = |H|/|B|` orbits. Pick
  right transversals `H = ⊔_i A x_i = ⊔_i B y_i` and put `t(a x_i) = θ(a) y_i`. So `t` is a bijection of `H` with
  `t(ax) = θ(a) t(x)` for all `a ∈ A`, `x ∈ H`.
- `Ω = H × Z/(5r)`, with `λ(v)(x,i) = (vx, i)` for `v ∈ H` and `τ(x,i) = (t(x), i+1)`. Put `K = ⟨λ(H), τ⟩ ≤ Sym(Ω)`,
  a finite group.

**Conjugation.** For `a ∈ A`: `τ λ(a) τ^(-1)(x,i) = τ(a·t^(-1)(x), i-1) = (t(a·t^(-1)x), i) = (θ(a)x, i)`. So
`τ λ(a) τ^(-1) = λ(θ(a))`.

**The map.** For `g = fσ^k ∈ B_(2r)` put `Ψ(g) = λ(ιf) τ^k`, where `ιf = (ψ(f(m)))_(m ∈ I)`. By the ball lemma the
values `f(m)` lie in `B_(2r)(Γ)`, so `ιf` is defined.

**Claim 1 (shifts).** Let `f ∈ E` with `f(m) = e` for `m < -2r` and `f` constant from `2r` on, and let `|k| ≤ r`. Then
`τ^k λ(ιf) τ^(-k) = λ(ι φ^k f)`.
- For `k ≥ 0`: for `0 ≤ j < k`, `φ^j f` is constant from `2r + j ≤ 3r - 1 = M - 1` on, so `ιφ^j f ∈ A`, and
  `θ(ιφ^j f) = ιφ^(j+1) f`. The coordinate `-M` agrees since `φ^(j+1) f` is trivial below `-2r + j + 1 > -M`.
- For `k < 0`: `φ^(-j) f` is trivial below `-2r - j ≥ -3r + 1 > -M`, so `ιφ^(-j) f ∈ B`, and
  `θ^(-1)(ιφ^(-j) f) = ιφ^(-j-1) f`. The last coordinate agrees because `φ^(-j) f` is constant from `M - 1` on.
- Induct on `|k|`, using the conjugation formula. ∎

**Claim 2 (multiplicative on `B_r`).** For `g = fσ^k` and `g' = f'σ^(k')` in `B_r`, `Ψ(g)Ψ(g') = Ψ(gg')`.
- By Claim 1, `Ψ(g)Ψ(g') = λ(ιf) τ^k λ(ιf') τ^(k') = λ(ιf · ιφ^k f') τ^(k+k')`.
- Coordinatewise, `f(m)` and `(φ^k f')(m)` lie in `B_r(Γ)` and their product lies in `B_(2r)(Γ)`, so
  `ψ(f(m))ψ((φ^k f')(m)) = ψ(f(m)·(φ^k f')(m))`.
- `gg' = (f·φ^k f')σ^(k+k') ∈ B_(2r)`, so the right side is `Ψ(gg')`. ∎

**Claim 3 (injective on `B_r`).** If `Ψ(g) = Ψ(g')`, the second coordinate gives `k ≡ k' mod 5r`, so `k = k'`. Then
`λ(ιf) = λ(ιf')` gives `ψ(f(m)) = ψ(f'(m))` for `m ∈ I`, so `f = f'` on `I`. Outside `I` both are trivial below `-r` and
constant from `r` on, so `f = f'`. ∎

So the restriction of `Ψ` to `B_r` is an injective partial homomorphism into the finite group `K`, for every `r`. So
`C(Γ)` is LEF. Conversely, `Γ ≅ δ_0(Γ) ≤ C(Γ)`, so `C(Γ)` is LEF only if `Γ` is. ∎

**Remarks.**
- The models are not quotients. `τ` has finite order in `K`, and the relation `σ^N δ_0(b) σ^(-N) = δ_0(b)`, which would
  follow, has length at least `2N`, outside every ball used. This matches item 5 of the half-line node: `C(Γ)` is not
  residually finite for non-abelian `Γ`.
- **Why the naive truncation failed** (sk-perfect-overgroup §4). There the levels are wrapped into a cycle and `h_γ`
  acts on an arc, which creates a second boundary carrying suffix products. Here the level shift is realized by an
  arbitrary bijection `t` intertwining the partial shift `θ`, so no second boundary is visible to words of length
  `≤ r`. The §4 word `W = c_(0,a) c_(1,b) c_(0,a^(-1)) c_(1,a b^(-1) a^(-1))` maps to `λ(ι(value of W)) = e`.
- **Credit.** Realizing an isomorphism between subgroups of a finite group by conjugation with a permutation, through
  transversals, is the finite shadow of HNN extensions (Higman–Neumann–Neumann, 1949; recalled, not re-read). The
  half-line commutator is recalled from B. H. Neumann and H. Neumann (1959) in the reviewed node.

## 3. Theorem A′: the word problem of C(Γ)
`WP(C(Γ)) ≡_T WP(Γ)`.
- (`≥`) `δ_0(s) = [σ, h_s^(-1)]`, a computable word for each `s ∈ S`, so `WP(Γ) ≤_m WP(C(Γ))`.
- (`≤`) Given a word, compute the exponent sum `k` of `σ`, and for the `i`-th letter `h_(s_i)^(ε_i)` its prefix
  exponent `j_i`. Then `f(m) = ∏_(i : j_i ≤ m) s_i^(ε_i)` (product in the order of the word). `f` changes only at the
  levels `j_i`, is `e` below `min j_i`, and is constant from `max j_i` on. So the word is trivial iff `k = 0` and
  `f(j_i) = e` in `Γ` for every `i`, finitely many tests with `WP(Γ)`. ∎

## 4. Theorem B: decidable simple Kazhdan LEF hosts
**Statement.** Let `Γ` be finitely generated. Then `Γ` is LEF with solvable word problem iff `Γ` is a subgroup of an
infinite, finitely generated, simple group with property (T) that is LEF and has solvable word problem.

(`⇐`) Write a finite generating set of `Γ` as words in the generators of the host `G`. A word on `Γ`'s generators is
trivial iff its translation is trivial in `G`, so `WP(Γ)` is solvable. LEF passes to subgroups.

(`⇒`) Let `Δ = C(Γ)`. By Theorems A and A′ and §1, `Δ` is infinite, finitely generated and LEF, `WP(Δ)` is solvable,
and `Γ ≤ [Δ, Δ]`.
- **Host** (`lamplighter-bernoulli-crossed-products-simple-kazhdan-lef`, three PASS reviews).
  - `Δ` acts on `Ω = 2^Δ` by `(δx)(h) = x(δ^(-1)h)`, and `a` flips the coordinate at `e`.
  - `L = ⟨Δ, a⟩ ≅ Z/2 ≀ Δ`, `R = LC(Ω, F_2) ⋊ L`, and `G = EL_3(R)`.
  - `G` is infinite, finitely generated, simple, Kazhdan and LEF, and `ℓ ↦ diag(u_ℓ,1,1)` embeds
    `[L,L] ⊇ [Δ,Δ] ⊇ Γ` in `G`.
- **`Ω` as an `L`-subshift.** `F : Ω → F_2^L`, `F_x(ℓ) = (ℓ^(-1)x)(e)`.
  - `F` is continuous, and injective because `F_x(δ) = x(δ)` for `δ ∈ Δ`.
  - `F` intertwines the action with the left shift, `(ℓ'·F)(ℓ) = F(ℓ'^(-1)ℓ)`.
  - So `R ≅ LC(X, F_2) ⋊ L` for the `L`-subshift `X = F(Ω)`, and the indicator of `{x : x(e) = 1}` is the letter
    indicator `e_1`.
  - `crossed-product-el-word-problem-is-group-wp-plus-language` (PASS) gives `WP(G) ≡_T WP(L) ⊕ L(X)` for the
    generators `e_ij(u_s^(±1))`, `s ∈ S_Δ ∪ {a}`, and `e_ij(e_b)`.
- **`WP(L) ≤_T WP(Δ)`.** `L = F_2^(⊕Δ) ⋊ Δ`. A word reduces to a pair `(c, δ)`: `δ` is a word on `S_Δ`, and `c` is a
  finite list of lamp positions, each a word on `S_Δ`. It is trivial iff `δ = e` and, after identifying equal positions
  with `WP(Δ)`, every position occurs an even number of times.
- **`L(X) ≤_T WP(Δ)`.** An element `ℓ = (c, δ)` acts by `x ↦ δx + c`, so over `F_2` we have
  `ℓ^(-1)(y) = δ^(-1)(y + c)` and `(ℓ^(-1)x)(e) = x(δ) + c(δ)`.
  - A pattern `p ∈ F_2^W` on a finite set `W ⊆ L` occurs in `X` iff the constraints `x(δ_w) = p(w) + c_w(δ_w)`,
    `w ∈ W`, are consistent: whenever `δ_w = δ_(w')` the right sides agree.
  - Consistent constraints are realized, since `Ω` is the full shift.
  - Computing `δ_w`, the value `c_w(δ_w)` and the equalities `δ_w = δ_(w')` uses only `WP(Δ)`.

So `WP(G)` is solvable. ∎

## 5. Consequences
- **`erf-groups-have-decidable-simple-kazhdan-hosts` (OPEN on main).** Effectively residually finite groups are
  residually finite, hence LEF, so Theorem B applies to every f.g. ERF group with solvable word problem. The same holds
  for every f.g. residually finite group with solvable word problem, ERF or not. Route:
  `erf-groups-decidable-hosts-via-half-line-proof`.
- **`perfect-erf-groups-have-decidable-simple-kazhdan-hosts`, "Sharpness".** The sentence "Effective residual
  finiteness cannot be weakened to residual finiteness with solvable word problem" is true of that route's hypothesis,
  not of the conclusion. Theorem B hosts Rauzy's non-ERF examples. Rauzy's theorems concern residually finite, or
  finitely presented, overgroups; the hosts here are LEF and not residually finite.
- **Contrast with `recursive-lef-growth-hosts-miss-some-fp-rf-group`.** Each host here has solvable word problem, so
  its finite models are found by search, and that node says each such host misses some finitely presented residually
  finite group. There is one host per group, so no conflict.
- **The note (proposal artifact).** A second characterization in Corollary 2, and an overgroup paragraph without
  ultraproducts or Ore's theorem.

## 6. Model tests
- **LEF hypothesis of Theorem A.** `Γ = T`, Thompson's group (finitely presented, infinite, simple, so not LEF, since a
  finitely presented LEF group is residually finite). `C(T) ⊇ T` is not LEF, as it must be.
- **Word-problem hypothesis of Theorem B.** The note's `G_X` for a minimal subshift with non-recursive language is LEF
  with unsolvable word problem (note, Corollary 3). No decidable host contains it, as the easy direction requires.
- **Non-residually-finite input.** `G_X` for the Fibonacci subshift is LEF, not residually finite, and has solvable word
  problem (note §3). Theorem B hosts it, and it is already its own host.
- **Non-abelian finite input.** `Γ = S_3`: `C(S_3)` is not residually finite (half-line node item 5) and is LEF by
  Theorem A. The models `K` have `τ` of finite order, and the obstruction relation lies outside every ball used.
- **Trivial model of the construction.** If `t` is chosen without the intertwining property, for example `t = id`,
  Claim 1 fails already for `k = 1` and `f = h_s`: the image of `σ h_s σ^(-1)` is `λ(ι h_s)`, not `λ(ιφ h_s)`. The
  intertwining property is exactly what the ball relations use.

## 7. Credit and bounds
- **Boone–Higman–Thompson.** A f.g. group has solvable word problem iff it embeds in a simple subgroup of a finitely
  presented group (Boone and Higman, J. Austral. Math. Soc. 18 (1974), 41–53; recalled, not re-read). Thompson
  strengthened this to finitely generated simple groups with solvable word problem ("Embeddings into finitely
  generated simple groups which preserve the word problem", Word Problems II, Stud. Logic Found. Math. 95 (1980),
  401–441; title, volume and pages seen in two web search listings, the paper not opened). Theorem B is the analogue
  inside LEF groups, with property (T).

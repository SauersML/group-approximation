## 1. The colored subgroup (node 1)

**Definition checked.** FFWZ §2.3 (l.436–447) define `SV_G^abs` as generated by `SV` and the `G(n)`, "subject to
the set of relations that is closed under compositions and direct sums and contains" two relations:
- `x_(g.s) ∘ g = (g ⊕ g) ∘ x_s`;
- `(g_1 ⊕ ⋯ ⊕ g_n) ∘ p_σ = p_σ ∘ (g_(σ(1)) ⊕ ⋯ ⊕ g_(σ(n)))`.

These are BZ `lem:Relations`(7) and (6) verbatim, with the same composition convention. They hold in `S'V_G` for
`s ∈ S ⊆ S'`.

**Ψ is well defined.**
- The `S`-colored forests of `S'V` act as the `SV`-element on `C^S` and as the identity on `C^G`. Canonical maps
  of `S`-bricks `B_S × C^G` are exactly these. So `SV → S'V` is an injective groupoid map, and every relation of
  `SV` holds in `S'V`.
- Twists compose (`lem:Relations`(3)).
- So `Ψ` is well defined. ✓

**Ψ is injective.**
- Suppose `Ψ[F_−, σ, (g_i), F_+] = id`. Then `B_i = B'_(σ(i))`, and `τ_(g_i) = id` on `C^(S')`.
- So `g_i` fixes `S'` pointwise, and `g_i = 1` because `G` acts freely on the summand `G`.
- The remaining `SV`-element acts as the identity on `C^S`, so it is trivial. ✓

**Image and kernel.**
- The image is `f_2^(-1) t f_1` with `S`-colored forests. Moving a twist past an `S`-split changes the color to
  `γ^(-1)s ∈ S`, so the forests stay `S`-colored.
- For `k ∈ K`, the element `x_s^(-1)(k_1 ⊕ k_2) x_s` acts on `C^G` by `k_1` on one half and `k_2` on the other. So
  the kernel is "invisible on `C^S`", as item 3 says. ✓

## 2. The criterion (node 2)

**The transfer of BZ §§5–7.** For each result I rechecked where the split colors enter:
- **`prop:directed`.** It uses the normal form of node 1. ✓
- **`prop:JoinForests`.** It works because `S`-bricks of `C^(S')(m)` are `B_S × C^G`. So the partition lattice
  equals that of `C^S(m)`, and brick sets determine classes, since twisted permutations do not change preimage
  partitions. ✓
- **`prop:elem_core`, `prop:cible`.** Unchanged. ✓
- **`lem:vtx_stab`.** `Stab_Σ([h]) = h^(-1)𝒢(m)h`, where `𝒢(m)` is the group of twisted permutations of
  `C^(S')(m)`, `≅ G ≀ Σ_m` because `G ↷ S'` is faithful. It lies in `Σ` because twisted permutations use no
  splits. This is the step the quotient approach loses: acting through `SV_(G/K)`, a vertex stabilizer also
  contains elements such as `x_s^(-1)(k_1⊕k_2)x_s`, which are not in `W(1)`. ✓
- **`lem:stab_spectrum`, `prop:stabs`.** `lem:swap` keeps forests `S`-colored. So the grid stabilizers are
  commensurate with `∏ Stab_G(C_i)`, taken for `G ↷ S` and including `K`. That matches `[HA_n]`. ✓
- **`prop:E_hi_conn`.**
  - Unchanged, and valid for every `|S| >= 1`: the stars are indexed by `S`, which may be finite.
  - Referee a's N1 correction to `lem:VE_conn` is right. `VE_m^(i,j)` is the poset `(A ⊔ {⊤}) × (VE_(m−2) ⊔ {⊤})`
    minus its top. That realizes the join `|A| * |VE_(m−2)|`, with `A ≠ ∅` discrete, so it is
    `(ν(m)−1)`-connected, and the intersections are joins too. The faithful case is equally affected, and the
    lemma is true.

**Step 2 (FP_n).** This is a verbatim rerun of the faithful proof. The grid-sphere lemma is a statement about the
partition lattice, which is the same one. The orbit count uses `G ≀ Σ_r` acting on tuples of subsets of `S`. ✓

**Step 3 (finite presentation).**
- For `d >= 2`, `(v,w)` contains the root atom, so `∂I` is connected and `π_0` is unchanged. So `F_1 = Γ_sh` is
  connected.
- Van Kampen kills `im π_1(∂I)`.
- The cases:
  - non-grid: contractible;
  - grid with `e >= 3`: `S^(e−1)`, simply connected;
  - grid with `e = 2`: `S^1`.
- I checked the hexagon edge by edge: `v → x_r → (x_r; x_b on one half) → w → (x_b; x_r on one half) → x_b → v`.
  Each step is a single split, and it passes once through each of the two components.
- Rigidity holds: the vertices of each loop are distinct, and edges are oriented by rank.
- Under `[A_2]` (FFWZ Definition 1.3, l.83–88: `G` is `F_2`, `Stab(s)` is `F_1`, finitely many orbits on `S^2`):
  - vertex stabilizers `G ≀ Σ_r` are finitely presented;
  - short-edge stabilizers `≈ Stab_G(s) × G^(r−1)` are finitely generated;
  - vertex, edge and 2-cell orbits are finite.
- Brown 1984 then gives finite presentation. ✓

**Step 4.** `F_n = FP_n` + finitely presented. ✓

**The conjecture quotation** (FFWZ l.115–117) is accurate.

## 3. The interval Brown criterion (node 3)

- **FP_n half.** This is the faithful argument in the abstract. Hypotheses 1–4 are exactly what Steps 0–6 use.
  Rank separates the vertices of a chain, which gives pointwise fixing. ✓
- **Finite-presentation half.**
  - The poset is graded, so `(v,w) ≠ ∅` for `d >= 2`.
  - `ΣA ≃ ⋁ΣA_i ∨ ⋁^(k−1)S^1` for the `k` path components `A_i` of the finite `|(v,w)|`, so `π_1` is free of rank
    `k−1`.
  - It is generated by the loops `v → (A_1) → w → (A_j) → v`, whose legs are chains of covers inside `[v,w)` and
    `(v,w]`.
  - Finitely many loops per interval, rigid 2-cells, then Brown. ✓

## 4. Nits

- **N-a (node 3, finite presentation, hypothesis 4).** A cover has `(v,w) = ∅`, which some conventions call
  disconnected. The proof uses only intervals of length `>= 2`. Say "intervals of length `>= 2` whose open part is
  disconnected".
- **N-b (both criteria, Lesson paragraphs).** My faithful-case report left the wreath-product equivalence
  unchecked. FFWZ l.95–97 state it for every infinite `B` of type `F_n` ("B ≀_S G is of type F_n if and only if
  the action G ↷ S is of type [A_n]", citing dC06, BdCK15, FFKLZ25). So the `Z ≀_S G` sentence is exactly as FFWZ
  cite it. This is a citation, which I did not read at source.

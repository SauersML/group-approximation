# Relative commutants of Leavitt endomorphisms, and triangular units in Ara--Cortiñas Question 5.7

Lane `ex2-q34-commuting-units`, 2026-09-13. Complete proofs, unreviewed. The exact screens are in Section 4.

## 0. Notation

Let `K` be any field and `R = L_K(1,2)`, generated by `s_0, s_1, t_0, t_1` with `t_i s_j = δ_ij` and
`s_0 t_0 + s_1 t_1 = 1`. Put `V = K^2`, with basis `e_0, e_1`.
- **Grading.** `R = ⊕_(d ∈ Z) R_d`, with `deg s_i = 1` and `deg t_i = -1`.
- **Levels.** `R_d^(n) = span{ s_α t_β : |β| = n, |α| = n + d }` (for `n + d >= 0`). Sending `s_α t_β` to the
  matrix unit `|α><β|` identifies it with `Hom(V^⊗n, V^⊗(n+d))`.
- **Lifting.** `R_d^(n) ⊆ R_d^(n+1)`, since `s_α t_β = Σ_i s_(αi) t_(βi)`. In tensor form, `X` becomes
  `X ⊗ 1_V`, with the identity on the last letter. Every element of `R_d` lies at some level, and products
  are compositions after lifting to a common level.
- **Core.** `R_0^(k) = M_(2^k)(K)`, and `R_0 = ⋃_k R_0^(k)`. A unit of `R` lying in `R_0` has its inverse in the
  same `R_0^(k)`.
- **The shift.** `phi(x) = s_0 x t_0 + s_1 x t_1` is a unital endomorphism. On `X ∈ Hom(V^⊗n, V^⊗(n+d))` it
  gives `phi(X) = 1_V ⊗ X`, with the identity on the first letter.
- **Endomorphisms.** For a unit `u`, `rho_u(s_i) = u s_i` and `rho_u(t_i) = t_i u^(-1)`. Every unital
  endomorphism is some `rho_u` (see `no-unital-map-from-leavitt-tensor-square-to-leavitt-over-f2`, Attempts).
  The relative commutant is

```text
C_u = C_R(rho_u(R)) = { z : z u s_i = u s_i z, i = 0, 1 } = { z : z = u phi(z) u^(-1) } .
```

- **Triangular units.** `H_<= = { u ∈ R^x : u, u^(-1) ∈ R_(<=0) }`, and `H_>=` is defined the same way.

## 1. Core units

**Theorem 1.** Let `u` be a unit of `R` in `R_0^(k)`, with `k >= 1`. Then `C_u` is graded, and for `z ∈ C_u ∩ R_d`:
- (a) `|d| <= 2k - 2`;
- (b) `z ∈ R_d^(k-1)` if `d >= 0`, and `z` lies at output length `k - 1` (in `R_d^(k-1-d)`) if `d < 0`.

So `dim_K C_u <= Σ_(|d| <= 2k-2) 2^(2k-2+|d|)`.

*Proof.*

**Step 0: grading.** `u s_i ∈ R_1` is homogeneous. So the degree-`(d+1)` parts of `z u s_i` and `u s_i z` are
`z_d u s_i` and `u s_i z_d`, and every component `z_d` of `z ∈ C_u` lies in `C_u`.

**Step 1: levels (last-letter support).** Say `X ∈ Hom(V^⊗a, V^⊗b)`, with `a, b >= 1`, *splits off the last
letter* if `X = X' ⊗ 1_V`. Conjugating by operators that do not touch the last input letter or the last output
letter preserves this property in both directions. `1_V ⊗ Z` splits off the last letter iff `Z` does, because
`(W_1 ⊗ W_2) ∩ (W_1' ⊗ W_2') = (W_1 ∩ W_1') ⊗ (W_2 ∩ W_2')` for subspaces of a tensor product.
- Let `z ∈ C_u ∩ R_d` lie at level `n` (so `z = Z ∈ Hom(V^⊗n, V^⊗(n+d))`), with `n >= k` and `n + d >= k`.
- At level `n + 1` the fixed-point equation reads
  `Z ⊗ 1_V = (U ⊗ 1_(n+1+d-k)) (1_V ⊗ Z) (U^(-1) ⊗ 1_(n+1-k))`, where `U ∈ End(V^⊗k)` is `u`.
- Both exponents are at least `1`, so `U` and `U^(-1)` leave the last letters alone. The left side splits off
  the last letter, hence so does `1_V ⊗ Z`, hence so does `Z`, and `z` lies at level `n - 1`.
- Repeating gives `min(n, n + d) <= k - 1`. That is (b).

**Step 2: degrees (Schmidt rank).** Suppose `d >= 1` and `z != 0`. By Step 1, `z = Z ∈ Hom(V^⊗(k-1), V^⊗(k-1+d))`.
- Iterating `z = u phi(z) u^(-1)` gives `z = u_n phi^n(z) u_n^(-1)`, with `u_n = u phi(u) ... phi^(n-1)(u)`, a unit
  of `R_0^(n+k-1)`. Let `U_n` be its matrix and `N = n + k - 1`, and take `n >= d`. At input level `N`:

```text
Z ⊗ 1_(V^⊗n)  =  (U_n ⊗ 1_(V^⊗d)) (1_(V^⊗n) ⊗ Z) U_n^(-1)      in Hom(V^⊗N, V^⊗(N+d)).
```

- View an operator `V^⊗N -> V^⊗(N+d)` as a tensor, and cut it into `A` = {all input letters, output letters
  `1..N`} and `B` = {output letters `N+1..N+d`}. Multiplying by invertible operators on `A`-letters does not
  change the Schmidt rank across `A | B`.
- **Left side.** Output letters `N+1..N+d` of `Z ⊗ 1_n` are identity copies of input letters `N+1-d..N`
  (this uses `n >= d`). So the tensor is (a nonzero tensor on `A`) ⊗ `Σ_β e_β^(B) ⊗ e_β^*(A)`, of Schmidt rank `2^d`.
- **Right side.** Output letters `N+1..N+d` of `1_n ⊗ Z` are the last `d` output letters of `Z`, and every
  other letter of the `Z`-tensor lies in `A`. So the Schmidt rank is at most the dimension of the `A`-part of
  `Z`, the first `k - 1` output letters together with `k - 1` input letters: `4^(k-1)`.
- Hence `2^d <= 4^(k-1)`, so `d <= 2k - 2`.

**Step 3: negative degrees.** The anti-automorphism `τ(s_α t_β) = s_β t_α` maps `R_d` to `R_(-d)` and
`rho_u(R)` onto `rho_(τ(u)^(-1))(R)`: `τ(u s_i) = t_i τ(u)`, and `τ(t_i u^(-1)) = τ(u)^(-1) s_i`. So
`τ(C_u) = C_(τ(u)^(-1))`, and `τ(u)^(-1)` is a unit of `R_0^(k)`. Step 2 applied to it gives `-d <= 2k - 2` for
`d < 0`. ∎

## 2. Triangular units

**Theorem 2.** If `u ∈ H_<= ∪ H_>=`, then `C_u` is finite-dimensional. If `u ∈ H_<=` and `u_0` is its degree-zero
component, a unit of some `R_0^(k)`, then `dim C_u <= dim C_(u_0)`.

*Proof.* Let `u ∈ H_<=`.
- `x -> x_0` is a ring map `R_(<=0) -> R_0`, so `u_0` is a unit of `R_0`.
- Let `z ∈ C_u` be nonzero, with top degree `D` and top component `z_D`. Then `u s_i ∈ R_(<=1)`, with degree-1
  part `u_0 s_i`.
- The degree-`(D+1)` parts of `z u s_i` and `u s_i z` are `z_D u_0 s_i` and `u_0 s_i z_D`. So `z_D ∈ C_(u_0)`,
  and by Theorem 1, `|D| <= 2k - 2`.
- Filter `C_u` by `F_D = C_u ∩ R_(<=D)`. Taking top components embeds `F_D / F_(D-1)` into `C_(u_0) ∩ R_D`. So
  `dim C_u <= Σ_D dim(C_(u_0) ∩ R_D) = dim C_(u_0)`.
- For `u ∈ H_>=`, apply `τ`. It maps `H_>=` onto `H_<=` and `C_u` onto `C_(τ(u)^(-1))`. ∎

## 3. Consequence for Question 5.7

**Corollary 3.** Over any field `K`, let `f : L ⊗ L -> L` be a unital homomorphism, where `L = L_K(1,2)`.
Put `u = f(s_0 ⊗ 1) t_0 + f(s_1 ⊗ 1) t_1` and `v = f(1 ⊗ s_0) t_0 + f(1 ⊗ s_1) t_1`. Then no unit `w` puts
`w u phi(w)^(-1)` or `w v phi(w)^(-1)` in `H_<= ∪ H_>=`.

*Proof.*
- `f(- ⊗ 1) = rho_u`, and `f(1 ⊗ -)` is a unital homomorphism `L -> C_u`. Its image `B` satisfies
  `B ≅ B ⊕ B` as left `B`-modules, through the images of `s_i, t_i`. So `B` is not finite-dimensional, and
  neither is `C_u`.
- `Ad_w ∘ f` is again unital, with first unit `Σ_i w u s_i w^(-1) t_i = w u phi(w^(-1))`, since
  `s_i w^(-1) = phi(w^(-1)) s_i`. Apply Theorem 2.
- For `v`, compose `f` with the flip of `L ⊗ L`. ∎

So a unital map `L_2 ⊗ L_2 -> L_2`, if one exists, is built from units with components of both signs in every
twisted conjugate. Examples of units it cannot use:
- every unit of the core `R_0`, hence every localized endomorphism in Cuntz's sense;
- every unipotent `1 + n` with `n ∈ R_(<0)` nilpotent;
- all their products inside `H_<=`.

**Credit.** For C*-algebras, Cuntz proved that localized endomorphisms of `O_n` have finite-dimensional
relative commutants (J. Cuntz, *Automorphisms of certain simple C\*-algebras*, 1980). That source was not
re-read here. The algebraic support and Schmidt-rank argument above uses no traces or norms, so it works in
characteristic two. The triangular extension (Theorem 2) was not found in the two sources read this session
(Ara--Cortiñas arXiv:1108.0352v3; Bilich--Hazrat--Nam arXiv:2512.09241v2). The check is bounded.

## 5. Scope

Theorem 2 does not reach units with components of both signs. Examples are the north--south unit `c`, and every
unit that could come from a unital map. The general statement is the open claim
`leavitt-endomorphism-relative-commutants-are-finite`, which would answer Question 5.7 negatively over `F_2`.
- Neither proof step survives the shift. Step 1 needs the last letters to be untouched by `u`, and a unit with
  nonzero degrees moves the tail by different amounts in different terms.
- Step 0 needs `u s_i` to be homogeneous.

## Result

- **The coarse type graph** (subtree shapes, stabilized at depth 2, equitable). Types 0–3 with child counts:

      A = [[0,5,5,0], [0,2,0,1], [0,1,2,0], [0,0,1,0]]

  Type 0 is the root, and the core is {1,2,3}.
- **The homology.** `H_0 = Z^4 / ⟨e_t − Σ_w A[t][w] e_w⟩ ≅ Z`, generated by `x = [e_2] = [e_3]`. Also
  `[e_1] = −x`, and the whole space has class `[e_0] = 0`.
- **Defects.** For every generator (reflection) `k`, the 4 singular chains carry defect classes `+x, +x, −x, −x`,
  at every tested level (`n = 2, 3, 4`):
  - `kD = A'_1 ⊔ A'_2` with `d = [A'_1] + [A'_2] − [D]`;
  - the vectors are `(0,0,1,0) ↦ x` and `(0,1,−1,1) ↦ −x`.

  These are **nonzero and of infinite order**. Paired chains cancel, as `Σ_p d_k(p) = 0` requires.
- **Transfer to the true types.** The true (BBMZ morphism) types refine the shape types equitably. So there is a
  surjection `H_0(true) → H_0(coarse)` carrying true defects to these coarse ones. A defect of infinite order in
  the quotient has infinite order in `H_0(true)`.

**Conclusion.** The reflection germs of the pentagon RSG have defect of infinite order. The torsion criterion of
`torsion-defect-costs-nothing-in-bhm-germ-complexes` fails at the level of elements, not only of groups. This is
the open non-torsion case.

## Reading

- **The defect is an integer flux.** Each reflection moves `±x` of "clopen mass" across the two endpoints of its
  wall, with total 0. This is the shape of a Houghton flux (translation lengths on rays summing to 0), and of the
  index map of Reid's group.
- **Is it an obstruction?** In BHM's complex, a `Z`-valued total defect gives infinitely many orbits of
  portraits, and Brown's criterion with that filtration fails. For Houghton groups the analogous flux is where
  finiteness stops (`H_n` is `F_(n−1)` but not `F_n`, Brown).
  - So a non-torsion defect may be a genuine obstruction to `F_∞` for this RSG, which would be a negative answer
    to BBMZ Question 1.2.
  - Or it may be a failure of the complex only.
  - **Open.**
- **What can be computed** (corrected per referee bh-ref-q12; the earlier claim that `SingFix(M,M)` is an extension
  of `Fix_B(M)` by a finite-index subgroup of `Z^{|M|−1}` was wrong). An element fixing `M` has torsion defect at
  each point of `M`, so no free-part flux. By BHM Proposition 2.8, `Fix_B(M)` has finite index in `SingFix(M,M)`,
  which is therefore `F_∞`. Any obstruction must therefore be global: orbit
  non-finiteness, a Houghton-type Σ-invariant, not local.

## Lesson for general BH

- **Two different fluxes.** On hyperbolic hosts, a reflection's singular germs carry an integer flux across its
  wall, in `H_0` of the atom SFT, and no recoding that induces an isomorphism of `G_Σ` removes it (Bowen–Franks invariance; a coding with a
  different groupoid and base group is not covered). Surface-type hosts
  therefore sit in the Houghton-like regime of germ extensions, not in the Röver–Nekrashevych regime.
- **What decides Q1.2 for them.** Whether a flux with infinitely many possible carriers kills higher finiteness
  (as a fixed finite set of rays does for Houghton groups), or can be absorbed by a flux-aware germ complex.

## Script: defectclass.py

```python
"""Defect class of the reflection germs of the right-angled pentagon RSG (bh-finf-hyp, 2026-09-19).

For a generator k and a non-matching atom D on a singular chain, find the level m at which kD is exactly a union of
atoms A'_i, and form d = sum [A'_i] - [D] in H_0 = Z^types / <e_t - sum_w A[t][w] e_w>. Types: subtree-shape classes
(an equitable coarsening of BBMZ's types, as in atomtypes.py), so H_0(true) surjects onto H_0(coarse). Consequently a
NON-TORSION coarse defect is non-torsion for the true types; a zero or torsion coarse defect is inconclusive.
Reported: invariant factors of the relation lattice, and for each chain atom whether d is 0, torsion, or of infinite
order, plus the sum of the defects of each generator (must vanish).
"""
import time, json
from multiprocessing import Pool
from fractions import Fraction
from collections import defaultdict
from cmp_test import setup, lmul, ekey, ball, winit, wkeys

T0 = time.time()


def log(s):
    print(f"{time.time()-T0:7.1f}s {s}", flush=True)


def rank_q(rows):
    A = [[Fraction(x) for x in r] for r in rows]; rk = 0; ncol = len(A[0]) if A else 0
    for c in range(ncol):
        p = next((r for r in range(rk, len(A)) if A[r][c] != 0), None)
        if p is None:
            continue
        A[rk], A[p] = A[p], A[rk]
        for r in range(len(A)):
            if r != rk and A[r][c] != 0:
                f = A[r][c] / A[rk][c]; A[r] = [A[r][j] - f * A[rk][j] for j in range(ncol)]
        rk += 1
    return rk


def hnf(rows):
    """Integer row echelon basis of the row lattice (Euclid on columns)."""
    A = [list(r) for r in rows if any(r)]; out = []; ncol = len(rows[0])
    for c in range(ncol):
        while True:
            nz = [r for r in A if r[c] != 0]
            if len(nz) <= 1:
                break
            nz.sort(key=lambda r: abs(r[c])); piv = nz[0]
            for r in nz[1:]:
                q = r[c] // piv[c]
                for j in range(ncol):
                    r[j] -= q * piv[j]
            A = [r for r in A if any(r)]
        piv = next((r for r in A if r[c] != 0), None)
        if piv is not None:
            A.remove(piv); out.append((c, piv))
    return out


def in_lattice(basis, v):
    v = list(v)
    for c, piv in basis:
        if v[c] % piv[c] != 0:
            return False
        q = v[c] // piv[c]
        v = [v[j] - q * piv[j] for j in range(len(v))]
    return not any(v)


def main(R0=9, N=7, ncpu=2, D=2):
    nv = 5; edges = [(0, 1), (1, 2), (2, 3), (3, 4), (4, 0)]
    comm, pairs, pair_of = setup(nv, edges); npairs = len(pairs)
    words, keys, level, parent, letter = ball(R0 + 2, nv, comm, npairs, pair_of)
    cnt = [0] * (R0 + 3)
    for l in level:
        cnt[l] += 1
    size = [sum(cnt[:n + 1]) for n in range(N + 1)]; sizeN = size[N]
    children = [[] for _ in range(sizeN)]
    for i in range(1, sizeN):
        children[parent[i]].append(i)
    ops = []; stack = [(0, iter(children[0]))]
    while stack:
        node, it = stack[-1]; c = next(it, None)
        if c is None:
            stack.pop()
            if node != 0:
                ops.append(-1)
        else:
            ops.append(c); stack.append((c, iter(children[c])))
    shell = [i for i in range(len(words)) if R0 - 1 <= level[i] <= R0 + 2]
    chunks = [[words[i] for i in shell[j:j + 2000]] for j in range(0, len(shell), 2000)]
    with Pool(ncpu, initializer=winit, initargs=(comm, ops, letter[:sizeN], sizeN, N)) as pool:
        res = pool.map(wkeys, chunks)
    fk = {}; pos = 0
    for ch in res:
        for kb in ch:
            fk[shell[pos]] = kb; pos += 1
    log(f"fullkeys for {len(shell)} points")
    M = [i for i in shell if level[i] == R0]
    W1 = [i for i in shell if level[i] in (R0 - 1, R0 + 1)]
    atoms = [{} for _ in range(N + 1)]
    for n in range(N + 1):
        for i in M:
            atoms[n].setdefault(fk[i][:size[n]], []).append(i)
    kids = [defaultdict(set) for _ in range(N)]
    for n in range(N):
        for i in M:
            kids[n][fk[i][:size[n]]].add(fk[i][:size[n + 1]])
    intern = {}; shp = [dict() for _ in range(N + 1)]
    for n in range(N + 1):
        for a in atoms[n]:
            shp[0][(n, a)] = 0
    for d in range(1, N + 1):
        for n in range(0, N - d + 1):
            for a in atoms[n]:
                t = tuple(sorted(shp[d - 1][(n + 1, c)] for c in kids[n][a]))
                shp[d][(n, a)] = intern.setdefault((d, t), len(intern))
    dom = [(n, a) for n in range(0, N - D) for a in atoms[n]]
    types = sorted({shp[D][x] for x in dom}); tid = {t: j for j, t in enumerate(types)}; T = len(types)
    A = [[0] * T for _ in range(T)]
    for (n, a) in dom:
        t = tid[shp[D][(n, a)]]; row = [0] * T
        for c in kids[n][a]:
            row[tid[shp[D][(n + 1, c)]]] += 1
        A[t] = row
    rel = [[(1 if i == j else 0) - A[i][j] for j in range(T)] for i in range(T)]   # rows e_t - sum A[t][w] e_w
    basis = hnf(rel); rq = rank_q(rel)
    log(f"types={T} A={A} rank_Q(relations)={rq} (free rank of H_0 = {T - rq}) HNF pivots={[(c, p[c]) for c, p in basis]}")
    out = {'A': A, 'rank_Q': rq, 'free_rank_H0': T - rq, 'gens': {}}
    in_ball = set(shell)
    for k in range(nv):
        img = {i: keys.get(ekey(lmul(k, words[i], comm), npairs, pair_of)) for i in M + W1}
        byclass = {}
        for m in range(1, N + 1):
            for i in W1:
                byclass.setdefault((m, fk[i][:size[m]]), []).append(i)
        recs = []
        for n in range(2, N - D):
            for a, X in atoms[n].items():
                Y = [img[i] for i in X]
                if any(y not in in_ball for y in Y):
                    continue
                for m in range(max(1, n - 2), min(N - D + 1, n + 3)):
                    cls = {fk[y][:size[m]] for y in Y}
                    back = all(fk[img[w]][:size[n]] == a for c in cls for w in byclass.get((m, c), [])
                               if img[w] in in_ball)
                    if not back:
                        continue
                    if len(cls) == 1 and m == n:
                        break                                    # matching atom: no defect
                    tD = shp[D].get((n, a)); tI = [shp[D].get((m, c)) for c in cls]
                    if tD not in tid or any(t not in tid for t in tI):
                        recs.append((n, m, len(cls), 'untyped')); break
                    dv = [0] * T
                    dv[tid[tD]] -= 1
                    for t in tI:
                        dv[tid[t]] += 1
                    if not any(dv):
                        status = 'zero-vector'
                    elif in_lattice(basis, dv):
                        status = 'zero'
                    elif rank_q(rel + [dv]) == rq:
                        status = 'torsion'
                    else:
                        status = 'infinite-order'
                    recs.append((n, m, len(cls), dv, status)); break
        summ = defaultdict(int)
        for r in recs:
            summ[r[-1]] += 1
        out['gens'][k] = {'records': recs, 'summary': dict(summ)}
        log(f"generator {k}: summary {dict(summ)}; non-trivial records {[r for r in recs if r[-1] != 'zero-vector'][:8]}")
    json.dump(out, open('defectclass.json', 'w'), default=str, indent=1)
    log("ALL DONE")


if __name__ == '__main__':
    main()
```

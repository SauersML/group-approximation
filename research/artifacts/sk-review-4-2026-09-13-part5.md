## 1. The K_1 criterion (item 16)
- **Homomorphism.** `u: Δ → R^×` is an injective homomorphism because coefficients are unique, and `a ↦ diag(a,1,1)` is a
  homomorphism. So γ ↦ diag(u_γ,1,1) is injective into GL_3(R).
- **Stable E(R).** `K_1(R) = GL(R)/E(R)` is abelian, and `[diag(a,1,1)] = [a]`. So `diag(u_γ,1,1) ∈ E(R)` iff
  `[u_γ] = 0`, and the kernel is normal.
- **Commutators land in EL_3.** Multiplying out
  `diag(u_α,u_α^(-1),1)·diag(u_β,u_β^(-1),1)·diag((u_βu_α)^(-1),u_βu_α,1)` gives first coordinate
  `u_αu_βu_α^(-1)u_β^(-1) = u_[α,β]` and second coordinate `u_α^(-1)u_β^(-1)u_βu_α = 1`.
- **Whitehead.** `e_12(a)e_21(−a^(-1))e_12(a)·e_12(−1)e_21(1)e_12(−1) = diag(a,a^(-1))`.

Note: the title's "only obstruction" refers to the stable `E(R)`, and the body says so correctly. Membership in
`EL_3(R)` for elements outside `[Δ,Δ]` could be finer, and is not claimed.

## 2. Perfect amenable envelopes (item 18)
The route is:
- a free minimal subflow (GJS);
- `R` finitely generated by `e_([x_e=1])` and the units;
- Steinberg simplicity plus centre `F_2`, so `G = EL_3(R)` is simple;
- EJZ (T);
- Følner rank models plus the transfer theorem for linear soficity;
- `Γ = [Γ,Γ]`, so item 16(3) embeds `Γ` in `EL_3(R)`.

Each step checks, conditional on the imports' own status.

**Scope repair.** The claim allowed every f.g. perfect amenable `Γ`, finite ones included. For finite `Γ` there is no
infinite free minimal subflow, so `EL_3(LC(X,F_2)⋊Γ)` is finite, and the route's own model test excludes that case. The
conclusion is still true: `Γ ≤ Sym(d) ≤ GL_d(F_2)` embeds as a tower copy in any `G_X` (the note's l.205–215 argument).
`G_X` is LEF, hence `F_2`-linear sofic, since regular permutation models give rank defect 0 and `rk(P_g − I) ≥ N/2` for
`g ≠ 1`. The claim sentence now says "when `Γ` is infinite" and records the finite case.

## 3. Rank models versus vector actions (item 19)
- **Fixed points.** The fixed set of `g ∈ GL_N(F_q)` on `F_q^N` is `ker(g−1)`, of size `q^(N−rk(g−1))`, so the normalized
  Hamming distance to `1` is `1 − q^(−rk)`.
- **Defect.** For `g = Φ(st)^(-1)Φ(s)Φ(t)`, `rk(g−1) = rk(Φ(s)Φ(t) − Φ(st))`.
- **Consequence.** A sofic approximation needs Hamming defect `→ 0`. So the rank defect vanishes on each finite set for
  large `i`, the models are exact local embeddings into `GL_(N_i)(F_q)`, and the group is LEF.

PASS.

## 4. Word problems of crossed-product envelopes (items 20–23)

**Item 20, `WP(G) ≡_T WP(Δ) ⊕ L(X)`.**
- **Upper bound.** Normalize entries with the `WP(Δ)` oracle, which compares exponents and window positions. Then test
  each window function on the finitely many patterns of its window with the `L(X)` oracle.
- **First lower bound.** `e_12(u_δ)e_12(u_(δ'))^(-1) = e_12(u_δ − u_(δ')) = I` iff `δ = δ'`.
- **Second lower bound.** `e_([p]) = ∏ u_(w_i)e_(p(w_i))u_(w_i)^(-1)`, and a group word for `e_12(e_([p]))` comes from iterated
  commutators.
- **Repair.** The sentence "the same holds for `G/Z(G)`, since the centre is the finite group of central scalars" is
  false for general subshifts. Take the Heisenberg group `H` acting on a point, so `R = F_2[H]`. For a central `z = [x,y]`,
  `u_z I_3` is a product of three conjugates of `diag(u_z,1,1) ∈ EL_3`, and it is central of infinite order.
  - The conclusion is still true, for a different reason.
  - `w ∈ Z(G)` is decided by testing `[w,s] = 1` for the finitely many generators with `WP(G)`, so
    `WP(G/Z(G)) ≤_T WP(G)`.
  - `e_12(a)` is central only for `a = 0`, because it must commute with `e_21(1)`. So both lower-bound reductions pass to
    `G/Z(G)`.
  - The sentence is replaced by this argument.

**Item 21, computable chains.**
- `K_m = ∩{ker φ_i : i ≤ m, w_i ≠ e}` is normal of finite index and descending.
- `∩K_m = {e}`, because each `w ≠ e` is some `w_i` and `φ_i(w) ≠ 1`.
- Membership: evaluate in the `F_i`. Quotients: close the image of `S` in `∏F_i`.
- Converse: search for `m` with `w ∉ K_m`. With a recursive presentation, `w = e` is semi-decidable as well.

PASS.

**Item 22, the Toeplitz language.**
- **Values.** `x(γ)` is computed at the first level where `γ` leaves the hole.
- **Occurrence.** Choose `M` with the elements of `W` in distinct `Δ_M`-cosets; the test `w_iw_j^(-1) ∉ Δ_M` is equivalent
  by normality. For `δ ∈ Δ_M`, `γδwΔ_M = γwΔ_M`, so the determined positions are fixed. The single hole position runs over
  `C_M`, which contains both a `1`-coset and a `0`-coset of level `M+1`.

PASS. Wording notes:
- **(a)** First identify words of `W` that are equal in `Δ`, using `WP(Δ)`, and reject inconsistent `p`. Otherwise the
  search for `M` does not halt.
- **(b)** The Theorem T construction makes choices: the new hole, the `1`-coset, and the passage to a subsequence with
  large indices. "The construction computes its representative" needs every choice to be the least admissible one in a
  computable enumeration, which is available from the computable finite quotients.

**Item 23, decidable envelopes.** The composition checks:
- a computable chain (item 21);
- a Toeplitz subshift whose subsequence and choices are made computable, as in note (b);
- Corollary T (PASS twice), with trivial centre over `F_2`;
- the embedding of `[Δ,Δ]` (item 16, and Theorem E, PASS);
- `WP(G) ≡_T WP(Δ) ⊕ L(X_Δ)`, both decidable.

For the corollary: `SL_n(Z)`, `n ≥ 3`, is infinite, finitely presented, residually finite and perfect, so ERF with
solvable word problem. The converse holds because f.g. subgroups inherit solvable word problem and LEF.

## 6. Not uniformly simple (item 26)

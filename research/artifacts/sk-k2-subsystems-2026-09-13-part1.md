# sk-k2-subsystems (part 1): the congruence layer vanishes when limit sets are separated

Lane `sk-k2-subsystems`, 2026-09-13. Status: complete proofs, UNREVIEWED.
Notation follows `research/artifacts/sk-open-1-subsystem-normal-subgroups-2026-09-13-part1.md`.

## 0. Summary
- **What the open node asks.** `aperiodic-subshift-ring-unstable-k2-vanishes` asks for K_2(n,R_Y) = 0 for every aperiodic Y. The dictionary needs less: ker π_Y = E_Y if and only if K_2(n,R_X) → K_2(n,R_Y) is onto (Lemma A).
- **Theorem D.** ker π_Y = E_n(R_X,I_Y) for every n ≥ 2 whenever the α- and ω-limit sets of the points outside Y lie in Y ∪ Z, for some closed invariant Z disjoint from Y. The proof needs nothing about K_2(n,R_Y).
- **Corollary E.** Suppose the closure of the limit set L(X) is a finite union of infinite minimal subshifts. Then, for n ≥ 3:
  - the normal subgroups of EL_n(R_X) are exactly the kernels ker π_Y;
  - the kernel onto the limit set is locally finite.
- **Open.** The case where some limit set meets both Y and X∖Y. Example: X is the orbit closure of a recurrent point that is not uniformly recurrent, and Y is a minimal subset. There the question really is about the unstable K_2 layer.

## 1. Setting
- **Ring.** X ⊆ A^Z is a subshift and R = R_X = LC(X,F_2) ⋊_T Z, with u f u^{-1} = f∘T^{-1}.
- **Restriction.** For closed invariant Y, put I_Y = {Σ f_j u^j : supp f_j ∩ Y = ∅}. The restriction ρ_Y : R_X → R_Y is onto with kernel I_Y, and π_Y = EL_n(ρ_Y).
- **Relative groups.**
  - GL_n(R,I) = {g ∈ GL_n(R) : g ≡ I mod I}.
  - E_n(I) is the subgroup generated by the e_ij(r), r ∈ I.
  - E_n(R,I) is its normal closure in EL_n(R).
- **Limit sets.** α(x) and ω(x) are the α- and ω-limit sets of x, and L(X) = ⋃_x α(x) ∪ ω(x).

## 2. Lemma A (the congruence layer is a K_2 cokernel)
For any ring R, two-sided ideal I and n ≥ 3,
  (EL_n(R) ∩ GL_n(R,I)) / E_n(R,I) ≅ coker(K_2(n,R) → K_2(n,R/I)).

*Proof.*
- The quotient St_n(R)/⟨⟨x_ij(I)⟩⟩ satisfies the Steinberg relations over R/I and is presented by them. So it is St_n(R/I), and ⟨⟨x_ij(I)⟩⟩ maps onto E_n(R,I).
- Take g in the left-hand group and lift it to x ∈ St_n(R). Its image x̄ ∈ St_n(R/I) lies in K_2(n,R/I).
- Two lifts differ by K_2(n,R), so φ(g) = [x̄] is a well-defined homomorphism.
- φ(g) = 0 iff some lift lies in ⟨⟨x_ij(I)⟩⟩ · K_2(n,R), iff g ∈ E_n(R,I).
- φ is onto: y ∈ K_2(n,R/I) lifts to x ∈ St_n(R), and its image in EL_n(R) maps to 1 in EL_n(R/I). □

So the layer in `aperiodic-subshift-el-normal-subgroups-are-sandwiched` (b) is exactly this cokernel. At a given Y, the dictionary needs K_2(n,R_X) → K_2(n,R_Y) to be onto, not K_2(n,R_Y) = 0.

## 3. Lemma B (ultramatricial ideals over F_2 have elementary congruence kernels)
Let R be a ring, I a two-sided ideal and n ≥ 2. Suppose every finite subset of I lies in a subring B ⊆ I with a unit e_B (possibly e_B ≠ 1) and B ≅ ∏_i M_{k_i}(F_2). Then GL_n(R,I) = E_n(I), and GL_n(R,I) is locally finite.

*Proof.*
- **Elementary matrices fill GL over B.** For n ≥ 2, E_n(M_k(F_2)) = SL_{nk}(F_2) = GL_{nk}(F_2).
  - Block elementary matrices contain the transvections between coordinates in different blocks.
  - A transvection inside one block is [t_xy, t_yz], with y in another block.
  - Transvections generate SL_{nk}(F_2), which is GL over F_2. Taking products over i gives E_n(B) = GL_n(B).
- **Localize g.** Let g ∈ GL_n(R,I), x = g − I and y = g^{-1} − I. Choose B containing all entries of x and y. Since x + y + xy = 0, e_B I_n + x ∈ GL_n(B), with inverse e_B I_n + y.
- **Embed back.** ι : GL_n(B) → GL_n(R), z ↦ (1−e_B)I_n + z, is a homomorphism because z = e_B z e_B, and ι(e_B I_n + bE_ij) = e_ij(b).
- So g = ι(e_B I_n + x) ∈ ι(E_n(B)) ⊆ E_n(I).
- **Local finiteness.** Finitely many elements lie in ι(GL_n(B)) for one common B, which is a finite group. □

Remarks:
- **F_2 is used.** Over F_q with q > 2, GL_{nk}(F_q) ≠ SL_{nk}(F_q), and the proof gives only E_n(I) times diagonal units.
- **Prior use.** The Toeplitz extension proof on main (`toeplitz-subshift-kazhdan-group-has-pestov-mf-quotient-proof`, "Congruence kernel") uses this argument for one ideal; this is the general form.

## 4. Proposition C (biasymptotic complements give ultramatricial ideals)
Let X be a subshift and Y ⊆ X closed invariant with α(x) ∪ ω(x) ⊆ Y for every x ∈ X∖Y. Then I_Y satisfies the hypothesis of Lemma B.

*Proof.*

(i) **Localization.**
- Given r_1, …, r_m ∈ I_Y, let K be the union of the supports of their coefficients f_j, and K′ = ⋃ T^{-j}(supp f_j).
- V = K ∪ K′ is clopen and V ∩ Y = ∅, because X∖Y is invariant.
- e_V r_i e_V = r_i, so all r_i lie in the corner C_V = e_V R e_V.

(ii) **Bounded chains.** Fix J ≥ 1.
- Let V_m be the set of x ∈ V with times 0 = t_0 < … < t_{m−1}, T^{t_i}x ∈ V and t_{i+1} − t_i ≤ J. Each V_m is clopen, and V_m ⊇ V_{m+1}.
- If every V_m is nonempty, compactness gives x ∈ V with infinitely many forward visits to V. Then ω(x) ∩ V ≠ ∅, contradicting ω(x) ⊆ Y.
- So M = max{m : V_m ≠ ∅} is finite.

(iii) **Relation.**
- For x ∈ V and T^t x ∈ V, write x ~ T^t x if consecutive visits of x to V between times 0 and t have gaps ≤ J. This is an equivalence relation on V.
- By (ii), each class has at most M elements and time-diameter at most D = MJ.
- The set {x ∈ V : T^t x ∈ V, x ~ T^t x} is clopen for each |t| ≤ D, since it depends on a bounded window.

(iv) **Subring.**
- B_{V,J} is the set of Σ_{|j|≤D} f_j u^j with supp f_j ⊆ {x ∈ V : T^{-j}x ∈ V, T^{-j}x ~ x}.
- It contains e_V. It is closed under multiplication, since (fu^i)(gu^j) = f(g∘T^{-i})u^{i+j} and ~ is transitive; the diameter bound keeps exponents ≤ D.
- It contains every element of C_V with exponents ≤ J: between two visits at distance ≤ J, all intermediate gaps are ≤ J.

(v) **Structure.**
- For x ∈ V, let k(x) be the size of its class, p(x) its position in time order and, when p(x) = 1, s_q(x) the time of the q-th element. These functions are locally constant.
- For clopen W ⊆ {k = k_0, p = 1} on which the s_q are constant, put ε_pq(W) = e_{T^{s_p}W} u^{s_p − s_q}.
- Then ε_pq(W) ε_{q′r}(W′) = δ_{qq′} ε_pr(W ∩ W′), because the members of a class are distinct points, and these elements span B_{V,J}.
- So B_{V,J} ≅ ∏_{k_0} M_{k_0}(LC(W_{k_0},F_2)). Every finite subset lies in a subring ∏ M_{k_0}(F_2^{c}) with unit e_V, built from a finite clopen partition. □

Hypothesis check: a point of X∖Y is never periodic, since a periodic orbit is its own limit set.

## 5. Theorem D (restriction kernels)
Let X be a subshift, Y ⊆ X closed invariant and n ≥ 2. Suppose some closed invariant Z ⊆ X∖Y satisfies α(x) ∪ ω(x) ⊆ Y ∪ Z for all x ∈ X∖(Y ∪ Z). Then
  ker(π_Y : EL_n(R_X) → EL_n(R_Y)) = E_n(R_X, I_Y).
For n ≥ 3, K_2(n,R_X) → K_2(n,R_Y) is onto.

*Proof.*
- **Split.** Put Y′ = Y ∪ Z. Y and Z are disjoint closed sets, so each is clopen in Y′. So R_{Y′} = R_Y × R_Z and EL_n(R_{Y′}) = EL_n(R_Y) × EL_n(R_Z).
- **The Y′ kernel.** By Proposition C for Y′ and Lemma B, ker π_{Y′} ⊆ GL_n(R_X, I_{Y′}) = E_n(I_{Y′}) ⊆ E_n(I_Y).
- **Lift the Z part.**
  - Choose a clopen U ⊇ Z with U ∩ Y = ∅. Every coefficient on Z extends to X; multiplying by e_U makes it vanish on Y. So each r ∈ R_Z lifts to I_Y with restriction (0, r) to Y′.
  - So π_{Y′}(E_n(I_Y)) ⊇ 1 × EL_n(R_Z).
  - For g ∈ ker π_Y we have π_{Y′}(g) ∈ 1 × EL_n(R_Z). Pick h ∈ E_n(I_Y) with π_{Y′}(h) = π_{Y′}(g).
- **Conclude.** g h^{-1} ∈ ker π_{Y′} ⊆ E_n(I_Y), so g ∈ E_n(I_Y) ⊆ E_n(R_X, I_Y). The reverse inclusion is clear. Lemma A gives the K_2 clause. □

Nothing about the unstable K_2 of R_Y or R_Z is used. Y and Z may be minimal subshifts whose K_2(3,·) is unknown.

## 6. Corollary E (the exact dictionary for finite limit type)
Let X be a subshift such that cl L(X) = M_1 ∪ … ∪ M_s is a finite union of infinite minimal subshifts. Let n ≥ 3 and G = EL_n(R_X).
- (a) Y ↦ ker π_Y is an inclusion-reversing bijection from closed invariant subsets of X onto normal subgroups of G, and G/ker π_Y ≅ EL_n(R_Y).
- (b) K = ker π_{M_1∪…∪M_s} is locally finite, and G/K ≅ ∏_i EL_n(R_{M_i}). This is a finite product of infinite, finitely generated, simple Kazhdan LEF groups, by the note's theorem.

*Proof.*
- **Aperiodic.** X has no periodic points: a periodic orbit is its own α-limit set, so it would be a finite minimal subset of cl L(X). So the sandwich `aperiodic-subshift-el-normal-subgroups-are-sandwiched` applies: every N ⊴ G has a unique Y with E_n(R_X, I_Y) ≤ N ≤ ker π_Y.
- **Z.** Given Y, let Z be the union of the M_i not contained in Y.
  - Distinct minimal sets are disjoint, and each M_i lies in Y or misses it. So Z is closed, invariant and disjoint from Y.
  - For x ∉ Y ∪ Z, α(x) and ω(x) are closed invariant subsets of ⋃ M_i, so they are unions of some M_i and lie in Y ∪ Z.
- **Kernels.** Theorem D gives ker π_Y = E_n(R_X, I_Y), so N = ker π_Y.
- **Bijection.** ker π_Y determines I_Y = {r : e_12(r) ∈ ker π_Y}, hence Y (`aperiodic-subshift-ring-ideals-are-invariant-open-sets`). π_Y is onto because elementary generators lift.
- **(b).** Y = ⋃M_i satisfies Proposition C with Z = ∅. So K ⊆ GL_n(R_X, I_Y), which is locally finite (Lemma B). Also R_{⋃M_i} = ∏ R_{M_i}. □

Example: X = X_α ∪ O(x), where X_α is Sturmian and x agrees with one point of X_α far left and another far right. Its closed invariant sets are ∅, X_α and X. So EL_3(R_X) has exactly three normal subgroups 1 < K < G, with K locally finite and G/K ≅ G_{X_α}.

## 7. What stays open
- **Where Theorem D fails.** It does not apply when some x ∉ Y has a limit set that cannot be separated from Y by a closed invariant Z. Example: X is the orbit closure of a recurrent point x that is not uniformly recurrent, and Y ⊊ X is a minimal subset. Every closed invariant set containing x contains Y, and corners e_V R e_V with x ∈ V have unbounded J-chains.
- **Attempts:**
  - **van der Kallen.** Injective stability holds for n ≥ sr(R)+2, and the stable K_2(R_Y) = 0 (sk-open-4). So K_2(n,R_Y) = 0 for n ≥ sr(R_Y)+2. At n = 3 this needs sr(R_Y) = 1, and no stable-rank bound is known (sk-stable-rank-a/b).
  - **Stepanov condition (b)** (sk-stable-rank-b, 7ff75787cb). It gives the GL-level sandwich E(n,R,I) ≤ H ≤ C(n,R,I), not equality with ker π_Y. The gap is the cokernel of Lemma A.
  - **Stable range.** K_2(R_Y) = 0 and Lemma A for E = colim EL_n give ker(E(R_X) → E(R_Y)) = E(R_X, I_Y). So each g ∈ ker π_Y lies in E_m(R_X, I_Y) for some m ≥ n; the open question is whether m = n works.
  - **Towers (this lane).** The locally matricial mechanism needs bounded J-chains in compact clopen subsets of X∖Y, which is exactly the limit-set condition.

## 8. Model tests
- **X minimal:** cl L(X) = X, and Corollary E gives the normal subgroups {1, G}. ✓
- **X = M_1 ⊔ M_2:** four normal subgroups, and G = EL_n(R_{M_1}) × EL_n(R_{M_2}). ✓
- **A fixed point:** it violates the hypothesis. Indeed congruence subgroups of EL_n(F_2[t^{±1}]) give extra normal subgroups (sk-open-1 §Aperiodicity). ✓
- **Lemma B over F_3:** it fails by the determinant, so F_2 is used. ✓
- **Proposition C with a separate minimal Z ⊆ X∖Y:** here I_Y contains a copy of R_Z, which is not locally finite, and the hypothesis excludes this case. ✓

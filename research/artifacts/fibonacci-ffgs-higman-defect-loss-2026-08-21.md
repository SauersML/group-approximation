# Fibonacci FFGS source inside a quantitative Higman host

## Concrete source and wrapper

Take the Fibonacci subshift generated by `0 -> 01`, `1 -> 0`, and let
`H=[[T_F]]'`.  Its language is recursive.  Grigorchuk--Medynets,
*Presentations of topological full groups by generators and relations*,
arXiv:1508.04454, describe generators and defining relations for derived
topological full groups of minimal subshifts and prove that the word problem
is solvable exactly when the language is recursive.  Thus this is a concrete
finitely generated recursive presentation, not merely an abstract choice
from the uncountable FFGS family.

Mikaelian's explicit Higman algorithm can turn that enumerated presentation
into an explicit two-generator finitely presented overgroup.  More strongly,
after fixing any recursive time bound `T(n)` for the decidable word problem,
the Chornomaz--Wagner/BORS refinement recorded in
`quantitative-higman-embedding-with-dehn-control` gives a bounded-distortion
finitely presented host whose relative Dehn function is at most
`T(n)^(2+epsilon)`.

This is enough to test both proposed quantitative resources: distortion and
source-relator area.

## Exact defect transfer

For a finite host presentation `G=<A|R>`, an embedded source generating set
`B`, and a host tuple with relator defect `delta`, van Kampen telescoping gives

```text
max { ||u(U_B)-1||_2 : |u|_B<=k, u=_H 1 }
    <= Delta_(H,G)(k) delta.                              (1)
```

For every sequence `delta_n->0`, one can choose `k(n)->infinity` sufficiently
slowly that the right side tends to zero.  This is precisely enough to make
the restricted tuples approximate `H`, and no uniformity in `k` follows.

## The sharp partial-model escape

FFGS Theorems 5.4--5.5 say `H` is LEF and locally HS-stable.  Choose local
embeddings of its radius-`n` ball into a finite group `K_n`.  In the left
regular action of `K_n`, every nonidentity element is fixed-point-free.
Consequently, for every fixed `1!=h in H`, the resulting partial unitary
homomorphisms satisfy eventually

```text
||rho_n(h)-I||_2^2=2-2 Re tr(rho_n(h))=2.                (2)
```

These maps are already partial homomorphisms, so the local-stability
correction can have error zero while retaining the invisible mark maximally.
This is the concrete countermodel to any **restriction-only** rounding claim.
It is not claimed that these partial models extend to approximate
representations of the Higman host; preventing such extensions is exactly
what a successful use of the wrapper's stable-letter relations must prove.

## Why quasi-retractions do not repair the loss

A multiplicative word substitution from host generators back to source words
which validates every host relator and fixes the embedded source generators
induces a genuine retraction `G->H`.  No such map exists because a retract of
a finitely presented group is finitely presented, while this `H` is not.

A coarse Lipschitz or quasi-isometric retraction is compatible with the
known undistorted Higman embeddings, but it does not send products to
products.  It therefore cannot be evaluated on matrices to turn host
relator defect into a source correction.  The relevant analytic resource is
not metric undistortion; it is a joint extension theorem for partial source
models across the stable-letter relations.

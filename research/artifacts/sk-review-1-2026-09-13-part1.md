## 2. Level-ideal step of sk-proof-minimal-concrete (part 1, item 8): PASS
**Text.** "Finally, $I_N=\{r\in R:e_{ij}(r)\in N\text{ for all }i\ne j\}$ is a two-sided ideal by~\eqref{eq:elementary}, and it contains $e_W$. So it contains every $e_{T^nW}=u^ne_Wu^{-n}$. By minimality and compactness finitely many of these sets cover $X$, so $1=1-\prod_i(1-e_{T^{n_i}W})\in I_N$."

**Derivation.**
- Additivity comes from e_ij(r+s) = e_ij(r)e_ij(s). With k the third index, e_ij(sr) = [e_ik(s), e_kj(r)] and e_ij(rs) = [e_ik(r), e_kj(s)] lie in N, because one factor lies in N and N is normal.
- u^ne_Wu^{-n} = e_{T^nW}.
- ⋃_n T^nW is open, invariant and nonempty. Its complement is closed and invariant, so by minimality it is empty. Compactness gives a finite subcover.
- ∏_i(1-e_{T^{n_i}W}) is the indicator of the complement of the union, which is 0. So 1 = 1-∏_i(1-e_{T^{n_i}W}) is a sum of products, each containing some e_{T^{n_i}W} ∈ I_N.
- So I_N = R, and N contains every e_ij(r), so N = G.

**Uses.** Minimality, yes; simplicity of R, no.

**Optional note.** "is a two-sided ideal by (elementary)" is terse. Adding "since $N$ is normal" names the second input.

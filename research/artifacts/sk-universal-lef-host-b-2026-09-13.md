# sk-universal-lef-host-b: one simple Kazhdan LEF group for all recursively presented LEF groups (2026-09-13)

Lane `sk-universal-lef-host-b`, start (b) of ROSTER-F: build the host directly from finite models. Everything below is
unreviewed and queued with sk-verify-7. No `.tex` was edited.

## 0. Results
- **Lemma A** (`countable-lef-groups-embed-in-two-generator-lef-groups`): every countable LEF group is a subgroup of a
  2-generated LEF group, which is infinite if the group is.
- **Theorem B** (`countable-lef-groups-embed-in-simple-kazhdan-lef-groups`): a countable group is LEF iff it is a
  subgroup of an infinite f.g. simple Kazhdan LEF group. This is Lemma A composed with the reviewed
  `lef-groups-embed-in-simple-kazhdan-lef-groups`, which has two PASSes.
- **Theorem C** (`simple-kazhdan-lef-host-for-recursive-lef-groups`):
  - (a) one infinite f.g. simple Kazhdan LEF group contains every member of a given countable family of countable
    LEF groups;
  - (b) one such group contains every recursively presented f.g. LEF group.
- **Proposition D** (`no-countable-group-contains-all-fg-lef-groups`): no countable group contains every `G_X`, so
  none contains every f.g. LEF group.

Theorem C supersedes the residually finite hosts of sk-strong-1 and sk-strong-3 (Wilson route). It needs no import
beyond Ore's theorem, and it contains groups that are not residually finite: every `G_Y` with recursive language, and
derived topological full groups of minimal subshifts with recursive language.

## 1. Lemma A: countable LEF groups inside 2-generated LEF groups
**Statement.** Let `Γ` be a countable LEF group. There is an injective homomorphism `ι : Γ -> Δ` into a group `Δ`
generated by two elements, and `Δ` is LEF. If `Γ` is infinite, so is `Δ`.

**Proof.** Write `[x,y] = xyx^(-1)y^(-1)`, and enumerate `Γ = {γ_1, γ_2, …}` (with repetitions if finite).

*Step 1: models.* LEF gives finite groups `Q_k` and maps `φ_k : Γ -> Q_k`. Each is injective on
`F_k = {1,γ_1,…,γ_k}` and satisfies `φ_k(gh) = φ_k(g)φ_k(h)` for `g,h ∈ F_k`. In particular `φ_k(1) = φ_k(1)^2`, so
`φ_k(1) = 1`. For fixed `g,h ∈ Γ`, both `g,h ∈ F_k` for all large `k`. So:
- (M) `φ_k(gh) = φ_k(g)φ_k(h)` for all large `k`;
- (I) if `g ≠ 1`, then `φ_k(g) ≠ 1` for all large `k`.

*Step 2: even permutations and Ore.* Let `π_k(g) ∈ Sym(Q_k × {1,2})`, `(x,e) ↦ (φ_k(g)x, e)`. Every cycle of
`π_k(g)` occurs twice, once for each `e`, so `π_k(g)` is even. By Ore's Theorem 1 (`ore-even-permutations-are-commutators`), for each
`j ≤ k` choose `α_(j,k), β_(j,k) ∈ Sym(Q_k × {1,2})` with `π_k(γ_j) = [α_(j,k), β_(j,k)]`.

*Step 3: levels.* Put:
- `L_k = 4^(k+1)`, `X_k = Q_k × {1,2} × Z/L_k`;
- `p_j = 2^(2j−1)`, `q_j = 2^(2j) = 4^j`, `P_k = {2^1, 2^2, …, 2^(2k)}`.

Since `2^(2k) < L_k`, the `2k` numbers in `P_k` are distinct residues. Define `a_k, b_k ∈ Sym(X_k)`:
- `b_k(x,i) = (x,i+1)`;
- `a_k(x,i) = (τ_(k,i)(x), i)`, where `τ_(k,i) = α_(j,k)` if `i ≡ p_j`, `τ_(k,i) = β_(j,k)` if `i ≡ q_j` (`j ≤ k`),
  and `τ_(k,i) = id` otherwise.

*Step 4: conjugates shift levels.* `(b_k^(−n) a_k b_k^n)(x,i) = b_k^(−n)(τ_(k,i+n)(x), i+n) = (τ_(k,i+n)(x), i)`. All
these elements preserve levels, so products and commutators can be computed level by level.

*Step 5: isolation.* Fix `j ≤ k` and the word `w_j(a,b) = [b^(−p_j) a b^(p_j), b^(−q_j) a b^(q_j)]` of the free group on
`a,b`. On level `i`, `w_j(a_k,b_k)` acts by `[τ_(k,i+p_j), τ_(k,i+q_j)]`. This is the identity unless both residues
`i+p_j` and `i+q_j` lie in `P_k`. Suppose `i+p_j ≡ s'` and `i+q_j ≡ s` with `s,s' ∈ P_k`.
- Then `q_j − p_j ≡ s − s' (mod L_k)`. Both sides have absolute value less than `4^k = L_k/4`, so they are equal in `Z`.
- **Powers of 2 have distinct positive differences.** If `2^c − 2^d = 2^(c') − 2^(d')` with `c > d` and `c' > d'`,
  the 2-adic valuations give `d = d'`, and then `c = c'`.
- `q_j − p_j > 0`, so `s = q_j`, `s' = p_j`, and `i ≡ 0`.

At `i = 0`, `w_j(a_k,b_k)` acts by `[α_(j,k), β_(j,k)] = π_k(γ_j)`. So `w_j(a_k,b_k)` acts by `π_k(γ_j)` on level 0
and trivially on every other level.

*Step 6: the ultraproduct.* Fix a nonprincipal ultrafilter `ω` on `N`, and let `U = ∏_ω Sym(X_k)` be the algebraic
ultraproduct. For `g ∈ Γ`, let `ι_k(g) ∈ Sym(X_k)` act by `π_k(g)` on level 0 and trivially elsewhere, and put
`ι(g) = [ι_k(g)]_ω`.
- By (M), `ι_k(gh) = ι_k(g)ι_k(h)` for all large `k`, so `ι` is a homomorphism.
- By (I), `ι(g) ≠ 1` for `g ≠ 1`.
- Put `a = [a_k]_ω` and `b = [b_k]_ω`. For every `j`, Step 5 gives `w_j(a_k,b_k) = ι_k(γ_j)` for all `k ≥ j`, so
  `ι(γ_j) = w_j(a,b)`.
- So `ι(Γ) ≤ Δ := ⟨a, b⟩`.

*Step 7: `Δ` is LEF.* Take a finite set `A ⊆ U` of elements with representatives `(u(k))_k`. Only finitely many
conditions are involved:
- `u(k)v(k) = uv(k)` whenever `u, v, uv ∈ A`;
- `u(k) ≠ v(k)` for distinct `u,v ∈ A`.

Each condition holds on a set in `ω`, and a finite intersection of sets in `ω` is nonempty. At any `k` in it,
`u ↦ u(k)` is an injective partial homomorphism `A -> Sym(X_k)`. So every subgroup of `U` is LEF, `Δ` included.

*Step 8.* If `Γ` is infinite, then `Δ ⊇ ι(Γ)` is infinite. ∎

**Remarks.**
- The words `w_j` do not depend on `k`. That is what lets one pair `(a,b)` work in the ultraproduct.
- The construction is the classical commutator-isolation trick (P. Hall; B. H. and H. Neumann), carried out inside
  finite symmetric groups so that the LEF property survives.
- Non-LEF input is ruled out by Step 7 (`Δ` is LEF, so `Γ` is), as it must be.

## 2. Theorem B: countable LEF groups are exactly the subgroups of simple Kazhdan LEF groups
**Statement.** A countable group is LEF if and only if it embeds in an infinite, finitely generated, simple group
with property (T) that is LEF.

**Proof.**
- ⇐: a partial model of a finite subset of the host restricts to the subgroup.
- ⇒, making it infinite: let `Γ` be countable and LEF. `Γ × Z` is countable, infinite and LEF. Given partial models
  `φ : Γ -> Q` on a finite `A ⊆ Γ`, together with the products of its elements, and `Z -> Z/N` injective on a finite
  `B ⊆ Z`, with `N` large, the product map is injective and multiplicative on `A × B`.
- ⇒, two generators: Lemma A embeds `Γ × Z` in a 2-generated infinite LEF group `Δ`.
- ⇒, the host: `lef-groups-embed-in-simple-kazhdan-lef-groups`, reviewed PASS by sk-verify-3 part6 and by
  sk-lef-embedding-c's adversarial review, embeds `Δ` in an infinite f.g. simple Kazhdan LEF group. ∎

## 3. Theorem C: one host
**(a)** Let `𝒞` be a countable set of countable LEF groups.
- `D = ⊕_(C∈𝒞) C` is countable.
- `D` is LEF. A finite subset `A` of `D` lies in finitely many coordinates `C_1,…,C_m`. Products of partial models
  `C_i -> Q_i`, each injective and multiplicative on the projection of `A` together with its pairwise products, give a
  partial model of `A` in `Q_1 × … × Q_m`.
- Theorem B gives `D ≤ U`, and every `C ∈ 𝒞` is a subgroup of `D`.

**(b) Countability.** A recursively presented f.g. group has a presentation `⟨s_1,…,s_k | Rel⟩` with `Rel` recursively
enumerable. There are countably many such presentations, so (a) applies to representatives of the recursively
presented f.g. LEF groups.

**Examples inside the one host `U`:**
- every finitely presented residually finite group;
- every f.g. linear group over a field. These are residually finite (`finitely-generated-linear-groups-are-residually-finite`)
  and recursively presented, as recorded in `universal-simple-kazhdan-lef-groups-exist-proof`;
- every `G_Y`, `Y` an infinite minimal subshift with recursive language. `WP(G_Y) ≡_T L(Y)`
  (`subshift-elementary-group-word-problem-degree`), so the word problem is solvable and the group is recursively
  presented. This includes the Fibonacci subshift and Sturmian subshifts of computable slope. Which of these are
  pairwise non-isomorphic is not addressed;
- derived topological full groups `[[T]]'` of minimal subshifts with recursive language. They are f.g. (Matui 2006),
  LEF (Grigorchuk–Medynets 2014), and have decidable word problem (Grigorchuk–Medynets, J. Algebra 500 (2018),
  Thm 1.1(3)). These attributions are recalled; the route does not require them.

## 4. Proposition D: sharpness
- A countable group has countably many finite subsets, so countably many f.g. subgroups up to isomorphism.
- The groups `G_X` realize continuum many isomorphism types (`continuum-many-simple-kazhdan-lef-groups`, reviewed PASS
  as subsumed by the Turing-degree node).
- So no countable group contains every `G_X`, and none contains every f.g. LEF group. In Theorem C the countability of
  the family cannot be dropped, and "recursively presented" is one natural way to impose it.

# A counter engine for matricial divisibility, and where it stops (lane gq-en-ring, round 4)

Target from the coordinator: a finitely generated simple `R ⊇ Q` with the UHF K-budget shape.
- `R ≅ M_n(R_n)` for `n` divisible by every integer.
- `[1]` of infinite order.
- No unit with infinitely generated rational symbols.

The coordinator's idea: a number operator on a tape, plus partial isometries whose orbit sizes
run through all integers. Split with `gq-deep-adelic-1`: that lane takes crossed products by
perfect groups (their spark S1), and this lane takes counter-driven, Bratteli-type engines.

## 1. The engine `R_fac` (five generators, an operator ring over `Q`)

Let `T_n` be the rooted tree whose levels branch `n+2, n+3, n+4, ...`, with Cantor boundary
`∂T_n`. So `∂T_n = {0..n+1} × ∂T_(n+1)`. Put
- `V_n = LC(∂T_n, Q)` and `V = ⊕_(n>=0) V_n`, where sector `n` is the counter value.
- `c_0 : V_(n+1) -> V_n`, `(c_0 f)(i, x) = δ_(i,0) f(x)`. Its left inverse is
  `c_0^* : g ↦ g(0, ·)`.
- `ρ` on each `V_n`: rotate the first digit mod `n+2`. It is a unit of order `n+2` on sector
  `n`, so every integer `>= 2` occurs as an orbit size.
- `A` on each `V_n`: multiplication by `1/(n+2)`, the resolvent of the counter.

Let `R_fac` be the subring of `End_Q(V)` generated by `c_0, c_0^*, ρ^(±1), A`.

**What it does (verified here).**
- **Sector projections.** `P_0 = 1 - c_0^* c_0` projects onto `V_0`. More generally
  `P_n = c_0^(*n) P_0 c_0^n` projects onto `V_n`.
- **Matrix units.** The descendant maps
  `σ = ρ^(i_0) c_0 ρ^(i_1) c_0 ... ρ^(i_(k-1)) c_0`, with `0 <= i_j <= j+1`, number
  `(k+1)!`. They carry `V_k` isomorphically onto pieces of `V_0` that partition it. So
  `P_0 = Σ_σ σ P_k σ^*`, and `P_0 R_fac P_0 ≅ M_((k+1)!)(P_k R_fac P_k)` for every `k`.
- **Q in the corner.** `Σ_σ σ A σ^* = (1/(k+2)) P_0`. So `Q·P_0 ⊆ S := P_0 R_fac P_0`.
- **So `S` is the factorial UHF ring.** `S ⊇ colim_k M_((k+1)!)(Q)`. Every word acts on `V_0`
  at bounded depth, so `S` equals this colimit, which is `U_Q`: matricially divisible, with
  the UHF K-budget.

## 2. Why this is not a host

**Pruning lemma: full corners of finitely generated rings are finitely generated.** Let `R` be
generated by `g_1..g_r` with `1 = Σ_i x_i e y_i`. Insert this sum between the letters of
`e g_(j_1) ... g_(j_k) e`. Then `eRe` is generated by the finitely many elements `e g_j x_i e`,
`e y_i g_j x_l e`, `e y_i g_j e` and `e g_j e`.

`U_Q` is a strictly increasing union of the `M_(n!)(Q)`, so it is not finitely generated. Hence
`P_0` is not full in `R_fac`: the ideal `J = R_fac P_0 R_fac` is proper, and `R_fac` is not
simple.

More generally, in a finitely generated simple ring no nonzero corner is locally matricial. The
host's matricial divisibility must therefore come from matrix units that are **not** exhausted
by finite-depth pieces. The UHF behaviour has to live in a full corner that stays finitely
generated.

**The remaining candidate is `R_fac / J`**, the infinite-depth boundary of the engine. It
contains every `P_n` in `J`, but not `1`. Open questions about it:
- Is it simple?
- Does it contain `Q`? The corner trick gives `(1/m) P_0 ∈ J`. A global `1/m` would need a
  uniform descendant sum across all sectors, and the number of descendants depends on the
  sector.
- What is its `K_0`, and is `[1]` divisible?
- Does `ρ` or `c_0` become a unit of index type? `c_0^* c_0 ≡ 1` there, so `c_0` becomes an
  isometry, whose defect `1 - c_0 c_0^*` may be nonzero.

This lane has not decided any of them.

## 3. Landed this round

- `full-corners-must-kill-rational-k2-symbols` (ESTABLISHED; lane proof with textbook inputs).
  If `E_N(R)` is finitely presented, then every full corner `eRe` sends `K_2(Q)` to a finite

## 4. Next tests (for whoever continues)

1. Decide simplicity of `R_fac / J`, and whether any rational scalar other than `±1` survives
   there as a ring element.
2. Variants that keep a full corner.
   - Replace the counter-dependent branching `n+2` by branching that is periodic in the
     counter, so that the sector type repeats. With period `P` and `b` the product of the
     branchings over one period, `V_n ≅ V_(n+P)` and `V_n ≅ V_(n+P)^b`. So `(b-1)[P_n] = 0`: the
     corner class is torsion, a Leavitt-type relation, and it is dead by
     `rational-k1-detection-forces-infinite-order-unit-class`.
   - Or let the counter run over `Z` (a two-sided tape), so that no sector is initial. That
     reintroduces a translation of the counter, which is a Laurent-type unit and is dead by
     `laurent-rational-symbols-block-fp-elementary-groups`.

   These two variants show the tension: finite self-similar descriptions give torsion or
   index. A host needs a third mechanism.

# bh-shell-kazhdan: does rigidity finitize the shell near relations? (2026-09-18)

Lane bh-shell-kazhdan of the BH swarm. Everything below is a lane result, not reviewed.

**Target.** By `boone-higman-iff-simple-kazhdan-decidable-inputs`, Boone–Higman reduces to infinite finitely generated simple Kazhdan groups `P` with solvable word problem. The shell route (`perfect-decidable-inputs-have-fp-shell-envelopes`) needs an enumeration `nu` whose germ group `Q_nu` is finitely presented. By `shell-germ-group-has-index-two-fiber-product`, `shell-germ-fp-is-an-ascending-hnn-gate` and `shell-ascending-gate-is-a-finite-window-inclusion`, that means two things:
- `R_nu = <lambda(P), s>` is finitely presented;
- `c_(-eps) <= W_N^eps` for some `eps` and `N`.

**Question.** Does property (T) make finitely many near relations suffice, or does it block the gate?

## Result landed

`one-ended-near-regular-actions-have-a-realization-defect`, with its proof route.
- **The invariant.** Near-regular actions of a one-ended group carry an integer defect `delta`. For the shell conjugates, `delta(c_k) = -k`.
- **What it forbids.** A window witness can never be obtained by conjugating `c_(-eps)` into a single window copy, whatever the conjugator in `ker(eta)`.
- **Realizability for eps = 1.** The window group's near action on `N` is not realizable, although each generating copy is. So the canonical lifts generate a subgroup `G_hat <= Sym(N)` that meets the finitary permutations nontrivially.
- **Generalization.** This extends `one-ended-shell-inputs-admit-no-shift-normalizing-enumeration`, which is the conjugator `tau = 1`.
- **Calibration.** The `Z^2` square spiral, with `eps = 1` and `N = 2`, satisfies both constraints. Its diagonal ray shifts are the non-realizable mixing.

## What rigidity gives, and what it does not

1. **(T) implies one-ended.** That is the only way (T) enters the landed invariant. Every consequence above holds for all one-ended inputs, including `Z^2`, which has a window witness. So the invariant constrains the shape of witnesses but cannot exclude them.
2. **FA.** Suppose `R_nu` is finitely presented. By Bieri–Strebel it splits as an HNN extension over a finitely generated base in `ker(eta)`, and each Kazhdan copy `c_k` fixes a vertex of the Bass–Serre tree. Under the gate the splitting is ascending with base `W_N`. The copy `c_k` fixes `s^k v_0` at height `h(v_0) + k`, which matches `c_k = s^k c_0 s^-k`. There is no contradiction.
3. **FW and near actions.** Cornulier: groups with FW have finitely stably realizable near actions. That result is recalled, not read at source.
   - It applies to the copies `c_k`, which is consistent with item 2 of the landed node.
   - It does not apply to `W_N`, which is generated by finitely many Kazhdan subgroups but need not have FW; a free product of two Kazhdan groups acts on a tree without a fixed point.
   - Item 6 of the node shows that a witness with `eps = 1` makes `W_N` non-realizable on `N`. That is compatible with `W_N` being realizable after adding points, so there is no contradiction.
4. **Positive direction.** Finitely many near relations imply all the commutation relators `[lambda_g^(1), s^k lambda_h^(2) s^-k]` exactly when the window inclusion propagates them. No mechanism was found by which (T) or simplicity supplies the window inclusion or the finite presentation of `R_nu`. Rigidity constrains the copies `c_k` one at a time: fixed points, realizations, and the defect. The gate needs a relation among several copies, and item 5 of the node shows it must use non-realizable mixing, which rigidity does not produce.

## Verdict

- **Neither outcome.** No enumeration was constructed, and no obstruction specific to Kazhdan inputs was proved.
- **A negative calibration.** All the constraints found depend only on one-endedness, and the one-ended input `Z^2` does pass the window gate. So a Kazhdan obstruction would need an invariant of the window group `W_N` itself, one sensitive to (T) in a way that `Z^2` is not. The obvious ones fail:
  - property (T) or FW of `W_N`, which is not forced;
  - fixed points on trees, which are consistent with an ascending HNN extension;
  - realizability on `N`, which fails for every witness with `eps = 1`, amenable or not, so it cannot tell Kazhdan inputs apart.
- **What remains open.** The gate for simple Kazhdan inputs is still open. The next concrete test is to take a specific finitely presented Kazhdan input, such as `SL_3(Z)`, which is perfect and one-ended, and look for a window witness that mixes copies through non-realizable ray shifts, as the `Z^2` spiral does. It is unknown whether such mixing survives the non-amenability of Kazhdan inputs.

## Second pass (free mode): the ends of the orbits, not of the group

Landed `one-ended-schreier-orbits-force-index-zero` with its proof route. The question this answers is the window-zero (twisted normalization) gate for the GENUINE-action shell of bh-shell-universal, where the input may act by any action with infinite supports.

**The invariant.** For an orbit `A`, what matters is the number of ends of its Schreier graph, not the number of ends of `P`. One end makes the labelled germ of a near-equivariant partial bijection unique on the one infinite component, and on a free orbit that germ extends to a bijection of orbits, so the index contribution vanishes. Two ends give two germs, which is exactly how the `Z` zigzag achieves index one. Infinitely many ends give many germs, and nothing is claimed there.

**Consequences.**
- Free actions of any infinite finitely generated simple input are dead for window zero, for every automorphism twist, of any order. This settles the infinite-order-twist case left open by item 5 of `eventually-periodic-genuine-shell-actions-give-fp-envelopes` in the free case.
- The one-ended input `Z^2` escapes because the eventually periodic action's orbits are finite, not because `Z^2` is special. So the regular-shell window obstruction and this one are the same phenomenon at different levels.
- For infinite simple inputs: fixed points are finite in number, there are no finite orbits beyond them, and no orbit has two ends. The live shape is a non-free orbit, and the natural candidate is one whose Schreier graph has infinitely many ends.

**The gap I could not close.** For a one-ended NON-free orbit, the argument gives only that `sigma` maps it onto a cofinite subset of one orbit. Making the per-orbit deficit vanish needs the labelled germ to extend across the loops of the Schreier graph that leave the infinite component, and a stabilizer need not be generated by loops that stay inside it. A correct treatment probably needs a flux or coboundary count rather than a germ.

**What would finish the window-zero story for Boone–Higman's reduced inputs.** Property (T) should forbid an orbit whose Schreier graph has infinitely many ends: the Dunwoody structure tree of such a graph gives an action of `P` on a tree, and transitivity on the orbit should make it unbounded, while property FA gives a fixed point. That is stated as expected and unproved on the node. With it, and with the non-free deficit gap closed, window `N >= 1` would be forced for every reduced input, in the genuine-action generalization as well as for regular enumerations.

## Third pass: both gaps closed for FW inputs

Landed `fw-inputs-pass-window-zero-only-via-proper-self-embeddings` with its proof route.

**One device replaces the germ.** Take a near-equivariant partial bijection `f` between two `P`-sets. The graph of `f` is a commensurated subset of the product, and FW transfixes it. So off finite sets `f` is an equivariant bijection, and `ind f = |F_Y| - |F_X|` for finite invariant sets. For `(T)` inputs this comes from Delorme–Guichardet in two lines.

**Consequences, all for FW inputs.**
- Every infinite orbit has a one-ended Schreier graph, since a set with finite coboundary is commensurated. This closes gap (ii) without the Dunwoody structure tree.
- Windows of sign `+1` force every orbit to be finite, for every injective endomorphism twist. The shift makes the infinite part near downward closed, hence cofinite, and then the index is `|Fin(rho)| - |Fin(rho∘psi)| <= 0`.
- Windows of sign `−1` need `|Fin(rho∘psi^m)| = |Fin(rho)| + m`. So `psi` is a proper self-embedding of infinite index.
- For simple inputs, `psi^m(P)` fixes exactly `m` new points, one added per step. With finitely many orbits, each orbit minus those points is a single `psi^m(P)`-orbit, and the action on some orbit is highly transitive.

**The one surviving window-zero configuration for Boone–Higman's reduced inputs.** A simple Kazhdan group `P` with a highly transitive action on an orbit `O`, and a proper self-embedding `psi: P -> Stab(z_1)` of infinite index such that `(O \ {z_1}, psi(P))` looks like `(O, P)`. Highly transitive actions of Kazhdan groups exist, for example via Hull–Osin for acylindrically hyperbolic groups, so this is not excluded. It is the natural target for anyone attempting a positive genuine-action window-zero shell for a Kazhdan input.

**Status of the gaps.**
- Gap (ii) is closed for FW inputs.
- Gap (i) is irrelevant for FW inputs, and stays open for inputs without FW.

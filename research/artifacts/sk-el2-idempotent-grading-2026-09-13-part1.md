# sk-el2, part 1: EL_2 over rings with complementary full idempotents has property (T)

Lane sk-el2, 2026-09-13. Status: every proof below is written out and UNREVIEWED (queued with sk-verify-4).
Part 2 (`sk-el2-idempotent-grading-2026-09-13-part2.md`) applies this to subshift algebras and proves simplicity.

## 0. Sources, quoted verbatim

Ershov–Jaikin-Zapirain–Kassabov, *Property (T) for groups graded by root systems*, arXiv:1102.0031. The TeX source
`2014gradedT0310.tex` was fetched on MSI (`/scratch.global/sauer354/sk/sk-el2/src-1102.0031/`). Main already imports
it as `strongly-root-graded-groups-have-kazhdan-root-unions` and `elementary-linear-semidir-pair-relative-t`.

- **Grading** (definition opening §4 of the source): "A $\Phi$-grading of $G$ ... is a collection of subgroups
  $\{X_\alpha\}_{\alpha\in\Phi}$ of $G$, called root subgroups such that (i) $G$ is generated by $\cup X_{\alpha}$;
  (ii) For any $\alpha, \beta\in \Phi$, with $\alpha\not\in\R_{<0}\beta$, we have
  $[X_\alpha,X_\beta] \subseteq \la X_\gamma \mid \gamma = a \alpha + b \beta \in\Phi, \ a,b \geq 1 \ra$".
- **Strong:** "the grading $\{X_\alpha\}$ is strong at the pair $(\gamma,\Phi_f)$ if
  $X_\gamma \subseteq \la X_\beta \mid \beta \in \Phi_f\mbox{ and }\beta\not\in\R\gamma\ra$", and strong means strong
  at every pair. The A_2 example reads: "A sufficient condition for the grading to be strong is that
  $[X_\alpha,X_\beta] = X_{\alpha+\beta}$ for any pairs of roots $\alpha$ and $\beta$ such that $\alpha+\beta$ is
  also a root."
- **Theorem `thm:main2`:** "Let $\Phi$ be an irreducible classical root system of rank $\geq 2$, and let $G$ be a
  group which admits a strong $\Phi$-grading $\{X_{\alpha}\}$. Then $\cup X_{\alpha}$ is a Kazhdan subset of $G$."
- **Relative (T) input** (source l.1008–1011): "if $R$ is any finitely generated ring, then the pair
  $(\EL_2(R)\ltimes R^2, R^2)$ has relative property $(T)$. This has been proved by Burger for $R=\Z$, by Shalom
  for commutative $R$ and by Kassabov in general."
- **Rank one, firewall** (source footnote): "It is easy to see that $\EL_2(R)$ does not have $(T)$ whenever $R$
  (possibly noncommutative) surjects onto $\Z$ or $F[t]$, with $F$ a finite field. A more delicate argument shows
  that $\EL_2(R)$ does not have $(T)$ for any infinite commutative ring $R$ (with $1$)."
- **Combining** (Ershov–Jaikin-Zapirain arXiv:0809.4095, `EL_n0909.tex`): "It is clear from definitions that if a
  group $G$ has a subset $B$ such that $\kappa(G,B)>0$ and $(G,B)$ has relative property $(T)$, then $G$ has
  property $(T)$." Their definition: "The pair $(G,B)$ has relative property $(T)$ if for any $\epsilon>0$ there are
  a finite subset $S$ of $G$ and $\mu>0$ such that if $V$ is any unitary representation of $G$ and $v\in V$ is
  $(S,\mu)$-invariant, then $v$ is $(B,\eps)$-invariant."

## 1. Theorem A

**Theorem A.** Let R be a finitely generated associative unital ring, and e ∈ R an idempotent with ReR = R and
R(1−e)R = R. Then EL_2(R) has property (T).

Notation:
- e' = 1−e; M = M_2(R); G = EL_2(R) = ⟨e_12(r), e_21(r) : r ∈ R⟩ ⊆ GL_2(R).
- E_1 = eE_11, E_2 = eE_22, E_3 = e'I_2. These are orthogonal idempotents of M with E_1+E_2+E_3 = I_2.
- For A ≠ B in {1,2,3}, put Y_AB = I_2 + E_A M E_B.

**Fullness.** Each E_A is full in M, i.e. M E_A M = M.
- Write 1 = Σ_t a_t e b_t. Then E_ij = Σ_t (a_t E_i1)(eE_11)(b_t E_1j), and the same with E_22 in place of E_11.
- Write 1 = Σ_t c_t e' d_t. Then E_ij = Σ_t (c_t E_ii)(e'I_2)(d_t E_ij).

**Products.** For x ∈ E_A M E_B and y ∈ E_C M E_D, xy = 0 unless B = C. In particular x² = 0, so
(I+x)(I+x') = I+x+x' for x, x' ∈ E_A M E_B, and Y_AB is an abelian group isomorphic to (E_A M E_B, +).

**Lemma 1 (commutators).** Let x, y ∈ M with x² = y² = 0.
- If yx = 0, then [I+x, I+y] = I+xy.
- If xy = 0, then [I+x, I+y] = I−yx.

*Proof.* Here [g,h] = ghg⁻¹h⁻¹ and (I+x)⁻¹ = I−x. In the first case (I+x+y+xy)(I−x) = I+y+xy, and
(I+y+xy)(I−y) = I+xy. The second case is similar: (I+x+y)(I−x) = I+y−yx, and (I+y−yx)(I−y) = I−yx, using
y(xy) = 0. ∎

**Lemma 2 (the grading).** {Y_AB} is a strong A_2-grading of G. The roots of A_2 are ε_A − ε_B ↔ (A,B).

*(i) Each Y_AB ⊆ G.*
- Let x ∈ E_A M E_B. Each entry x_pq lies in f_A^p R f_B^q, where f_A^p is the idempotent of block A in coordinate p:
  e for (A,p) = (1,1) or (2,2), e' for A = 3, and 0 otherwise. Also x_pq E_pq ∈ E_A M E_B.
- By additivity I+x = Π_{p,q}(I + x_pq E_pq). For p ≠ q the factor is e_pq(x_pq) ∈ G.
- A diagonal factor I + zE_pp with z = f_A^p z f_B^p ≠ 0 needs A ≠ B present in coordinate p, so
  {f_A^p, f_B^p} = {e, e'} and f_A^p f_B^p = 0. Take p' ≠ p. Put x' = zE_pp' and y' = f_B^p E_p'p. Then x'² = y'² = 0
  and y'x' = f_B^p z E_p'p' = f_B^p f_A^p z E_p'p' = 0. So Lemma 1 gives I + zE_pp = [e_pp'(z), e_p'p(f_B^p)] ∈ G.

*(ii) G ⊆ ⟨Y⟩.* By additivity e_12(r) = e_12(ere)·e_12(ere')·e_12(e're)·e_12(e're').
- e_12(ere) ∈ E_1ME_2 = Y_12 − I, e_12(ere') ∈ Y_13, and e_12(e're) ∈ Y_32.
- For e_12(e're'), write 1 = Σ_t a_t e b_t. Then e're' = Σ_t αβ with α = e'ra_te and β = eb_te'. Put x' = αE_12 ∈ E_3ME_2
  and y' = βE_22 ∈ E_2ME_3. Then x'² = 0, y'² = β²E_22 = 0 (as e'e = 0), y'x' = βE_22·αE_12 = 0, and x'y' = αβE_12.
  So e_12(αβ) = [I+x', I+y'] ∈ ⟨Y_32, Y_23⟩.
- e_21(r) is symmetric. So G = ⟨Y⟩, which is axiom (i).

*(iii) Axiom (ii).* Take roots α = (A,B), β = (C,D) with (C,D) ≠ (B,A), and x ∈ E_AME_B, y ∈ E_CME_D.
- If B = C, then D ≠ A and yx = 0. So [I+x, I+y] = I+xy ∈ Y_AD, and (A,D) = α+β.
- If D = A, then B ≠ C and xy = 0. So [I+x, I+y] = I−yx ∈ Y_CB, and (C,B) = α+β.
- If (C,D) = (A,B), the group is abelian, and no aα+bβ with a,b ≥ 1 is a root.
- Otherwise B ≠ C and D ≠ A, so xy = yx = 0: the elements commute, and α+β is not a root.

*(iv) Strong.* Let α+β be a root.
- If α = (A,B) and β = (B,C), then ⟨Y_AB, Y_BC⟩ contains I+xy for all x ∈ E_AME_B and y ∈ E_BME_C (Lemma 1). It is
  closed under the additive group law of Y_AC. Since E_B is full, E_AME_C = E_AME_BME_C as additive groups, so
  Y_AC ⊆ ⟨Y_AB, Y_BC⟩.
- If α = (A,B) and β = (C,A), the same argument with I−yx and the fullness of E_A gives Y_CB ⊆ ⟨Y_AB, Y_CA⟩.
- For A_2 every Borel set is {α, β, α+β} with core {α+β} (main's import node), so the grading is strong. ∎

By `strongly-root-graded-groups-have-kazhdan-root-unions`(a), ∪Y_AB is a Kazhdan subset of G.

**Lemma 3 (corner rings).** If R is generated by a finite set F and e is a full idempotent, then eRe is a
finitely generated unital ring (with unit e).

*Proof.* Write 1 = Σ_{t≤m} a_t e b_t, and insert this sum between consecutive letters of a product x_1⋯x_k of
elements of F ∪ {1}:

`e x_1 ⋯ x_k e = Σ_{t_1..t_{k−1}} (e x_1 a_{t_1} e)(e b_{t_1} x_2 a_{t_2} e) ⋯ (e b_{t_{k−1}} x_k e)`.

So eRe is generated by the finite set {e x a_t e, e b_t x a_s e, e b_t x e, e x e : x ∈ F ∪ {1}}. ∎

**Lemma 4 (relative (T) of the root subgroups).** Each pair (G, Y_AB) has relative property (T).

*(a) Columns: Y_13 and Y_23.*
- *The rank-two corner.* Put S = eRe, a finitely generated unital ring by Lemma 3.
  - ρ: GL_2(S) → GL_2(R), A ↦ e'I_2 + A, is an injective homomorphism.
  - ρ(e_12(s)) = I + sE_12 and ρ(e_21(s)) = I + sE_21. So K := ⟨Y_12, Y_21⟩ = ρ(EL_2(S)).
- *The module.* Put N_3 = I + (E_1+E_2)ME_3. Its elements are I+x with x a 2×2 matrix whose entries lie in
  L := eRe', and every such matrix occurs.
  - For A ∈ EL_2(S): ρ(A)xρ(A)⁻¹ = Ax, since e'x = 0 and xA⁻¹ = 0.
  - So (A,v) ↦ ρ(A)(I+v) defines a homomorphism EL_2(S) ⋉ M_2(L) → G onto KN_3. Here EL_2(S) acts on M_2(L) = L²⊕L²
    (two columns) by left multiplication, which is the standard action on each column.
- *L is finitely generated.* With 1 = Σ_{t≤m} a_t e b_t we have ere' = Σ_t (e r a_t e)(e b_t e'), so L = Σ_t S ℓ_t
  with ℓ_t = e b_t e'.
  - π: S^m → L, (s_t) ↦ Σ s_t ℓ_t, is S-linear and onto.
  - So ψ: H := EL_2(S) ⋉ (S²)^{2m} → G, equal to id⋉π followed by the map above, is a homomorphism. It sends
    N := (S²)^{2m} onto N_3.
- *Relative (T) on H.* Write N = N_1⋯N_{2m} with N_i ≅ S², and H_i = EL_2(S) ⋉ N_i ≤ H.
  - By `elementary-linear-semidir-pair-relative-t`, for every ε > 0 there are a finite F_i ⊆ H_i and μ_i > 0 such
    that every (F_i, μ_i)-invariant vector of a unitary representation of H_i is (N_i, ε)-invariant.
  - Put F = ∪F_i and μ = min μ_i. An (F, μ)-invariant vector ξ is (N_i, ε)-invariant for every i. Then
    ||n_1⋯n_{2m}ξ − ξ|| ≤ Σ_i ||n_iξ − ξ|| ≤ 2mε. So (H, N) has relative (T).
- *Push forward.* Composing representations of G with ψ, (G, ψ(N)) = (G, N_3) has relative (T), with finite set ψ(F).
  So (G, Y_13) and (G, Y_23) have relative (T).

*(b) Rows: Y_31 and Y_32.*
- *Transposition.* T: M_2(R) → M_2(R^op) satisfies (AB)^T = B^T A^T. So Φ(g) = (g^T)⁻¹ is a group isomorphism
  GL_2(R) → GL_2(R^op), and Φ(e_ij(r)) = e_ji(−r). Hence Φ(EL_2(R)) = EL_2(R^op).
- *Root subgroups.* Φ(I+x) = I − x^T for x² = 0. The idempotents E_1 = eE_11, E_2 = eE_22 and E_3 = e'I are
  symmetric, so Φ(Y_3A) = Y^op_A3, the column root subgroups for R^op with the same e.
- *Conclusion.* R^op is finitely generated and e, e' are full in R^op. So (a) applied to R^op gives relative (T) for
  (G, Y_31) and (G, Y_32).

*(c) Y_12 and Y_21.*
- E_3 is full, so I_2 = Σ_{t≤m'} c_t E_3 d_t. For x ∈ E_1ME_2, x = xE_2 = Σ_t y_t z_t with y_t = x c_t E_3 ∈ E_1ME_3
  and z_t = E_3 d_t E_2 ∈ E_3ME_2.
- z_t y_t = 0, since E_2E_1 = 0. So Lemma 1 gives [I+y_t, I+z_t] = I + y_t z_t, and I+x = Π_t [I+y_t, I+z_t].
- Hence Y_12 ⊆ (Y_13 Y_32 Y_13 Y_32)^{m'}. A vector that is (Y_13 ∪ Y_32, ε)-invariant is (Y_12, 4m'ε)-invariant.
- By (a) and (b), (G, Y_12) has relative (T). Y_21 is handled the same way, through Y_23 and Y_31. ∎

**Proof of Theorem A.**
- By Lemma 2, B := ∪Y_AB is a Kazhdan subset: κ(G,B) = κ > 0.
- By Lemma 4 and a finite union, (G,B) has relative (T). So there are a finite F ⊆ G and μ > 0 such that every
  (F,μ)-invariant vector is (B, κ/2)-invariant.
- A representation with an (F,μ)-invariant unit vector therefore has a (B, κ/2)-invariant unit vector, hence a nonzero
  G-invariant vector. So F is a finite Kazhdan set, and G has (T), which is EJZ's "clear from definitions" step. ∎

## 2. Model tests for the hypothesis
- **Commutative R.** ReR = eR = R forces e = 1, so e' = 0 is not full and the hypothesis fails. This agrees with
  EJZK's footnote: EL_2(R) lacks (T) for every infinite commutative ring.
- **R surjecting onto Z or F[t].** In the domain quotient, e and e' map to {0,1}, and one of them is not full, so the
  hypothesis fails. EL_2(R) lacks (T) there, by the same footnote.
- **R = S × S' with S commutative.** Hypothesis false (the S-component of e is 0 or 1); EL_2(S) is a quotient
  without (T).
- **R = M_2(S), e = E_11.** The hypothesis holds, and EL_2(R) = EL_4(S) has (T) by EJZ. Consistent.
- **Leavitt L_2 over F_2, e = x_1y_1.** It holds, and L_2 ≅ M_2(L_2), so EL_2(L_2) = EL_4(L_2). Consistent.
- **R = LC(X,F_q)⋊Z, X infinite minimal, e = e_W with ∅ ≠ W ≠ X.** It holds (part 2 §1). There is no Morita
  reduction for Sturmian X, which is the new case.

## 3. What was open and what changed
The open node's Attempt 2 used a partition X = U_1⊔U_2⊔U_3 in both coordinates. There, relative (T) was unchecked
for root subgroups whose corner rings e_iRe_i are not isomorphic. Here the SAME idempotent e is used in both
coordinates, so blocks 1 and 2 are isomorphic (corner S = eRe) and give EL_2(S) directly. Block 3 is reached through
the opposite ring (row roots) and bounded products (roots between blocks 1 and 2).

**Novelty (bounded).** A grep of the EJZK source for idempotent, Morita, generalized matrix, EL_2 and St_2 finds
only the rank-one footnote and Steinberg-group material, and no rank-two statement with idempotents. No other
literature search was done. The Peirce-grading idea is standard in structure theory, so a statement of this kind may
be folklore.

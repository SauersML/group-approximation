## §1 The Toeplitz extension of the Pestov ring: PASS

**Sources read verbatim at main's tip.**
- `prop:torsion-defect-ring` (tex l.1084): "Let $R$ be a countable unital ring, let $s,t\in R$ satisfy $ts=1$, and
  suppose that $e=1-st$ has finite additive order. Then for every $n\ge4$, $\EL_n(R,ReR)\le\Rad_{\mathrm{MF}}(\EL_n(R))$,
  where $\EL_n(R,ReR)$ is the normal closure of the $e_{ij}(a)$ with $a\in ReR$."
- `thm:core-mf-radical` (tex l.1609), used in §3.
- The node `hilbert-hotel-radical-is-smallest-directly-finite-quotient` (un-verify PASS), item 2: `hh(R) ≤ I` whenever
  `R/I` is directly finite.

**Lemma 1 (normal form).**
- Relations checked on `g b_i`: `M_f s = s M_(α^(-1)f)`, `t M_b = M_(α^(-1)b) t` (both sides vanish on `b_0`),
  `t^m M_f s^m = M_(α^(-m)f)`.
- For `k ≥ j`, the product is `s^(i+k−j) M_(α^(−(k−j))(a) b) t^l`. For `j > k` it is `s^i M_(a α^(−(j−k))(b)) t^(j−k+l)`.
- `α^(−m)`, `m ≥ 0`, sends cylinders on nonnegative coordinates to cylinders on nonnegative coordinates, so `A_+` is
  stable and the span is closed.

**Lemma 2 (the defect ideal).**
- `t^j e = 0` for `j ≥ 1` and `e s^k = 0` for `k ≥ 1`, so `ReR = span{s^i M_a e t^l}`.
- Matrix units: `e t^j s^k M_b e = δ_jk M_b e`.
- Injectivity: `Σ s^i M_(a_ij) e t^j` sends `1·b_j` to `Σ_i α^i(a_ij) b_i`.
- Over `F_2`, finitely generated subalgebras of `A_+` are `F_2^r`, so `J ≅ M_∞(A_+)` is locally matricial with local
  units `p_N`.

**Lemma 3 (the quotient).**
- For `m ≥ max j`: `x(g b_m) = Σ_d F_d α^d(g) b_(m+d)` with `F_d = Σ_(i−j=d) α^i(a_ij)`. This is read off from `x(1·b_m)`,
  so `π` is well defined.
- Composition on the tail is `(F u^(d'))(F' u^d) = F α^(d')(F') u^(d+d')`, and `u f u^(-1) = α(f)` matches the Pestov
  convention.
- `π(s) = u`, `π(t) = u^(-1)`, `π(M_f) = f`, and translates of `A_+` generate `LC(Y,k)`.
- Kernel: `J ⊆ ker π` since `π(e) = 0`. Conversely, modulo `J`, `s^iM_at^j ≡ s^N M_(α^(−(N−i))(a)) t^(N−(i−j))` for
  `N ≥ i`. The terms of one `d` sum to `s^N M_(α^(−N)(F_d)) t^(N−d)`, which is `0` when `F_d = 0`.

**Proposition 4.** `J ⊆ d(R) = hh_1 ⊆ hh(R)`. `R/J ≅ LC(Y,F_2) ⋊ Z` is directly finite: minimal `Y` has no clopen `U`
with `TU ⊊ U`, since a nonempty clopen has positive measure for the invariant measure (`subshift-ring-lef-iff-word-edges-lie-on-cycles`).
So `hh(R) ⊆ J`.

**Theorem 5.**
- **(1)** EJZ for the finitely generated ring `R`, and finite generation by `elementary-group-fg-from-fg-coefficient-ring`.
- **(2) Lower bound, at the genuine pair.** `s, t ∈ R` with `ts = 1` exactly in `R`; `2e = 0` because `R` is an
  `F_2`-algebra; `R` is countable. The printed proposition gives `EL_n(R,ReR) ≤ Rad_MF(EL_n(R))` for `n ≥ 4`. The demoted
  `relative-torsion-defect-mf-radical-step` (OPEN) is not used, and the route does not require it.
- **(2) Congruence kernel.**
  - Let `g ∈ GL_n(R,J)` with `X = g − I` and `Y = g^(-1) − I`. The entries lie in `B = M_N(A_0) ≅ ∏_f M_N(F_2)` with
    unit `p = p_N`.
  - `X + Y + XY = 0` gives `(pI+X)(pI+Y) = pI`, so `h = pI + X ∈ GL_n(B)`.
  - `φ(h) = (I−pI) + h` is a homomorphism `GL_n(B) → GL_n(R)`, since `(I−pI)h = 0`, and `g = φ(h)`.
  - `GL_n(B) ≅ ∏ GL_(nN)(F_2) = ∏ SL_(nN)(F_2)` is generated by elementary transvections `e_(pr)(1)` in each factor.
    - Cross-block ones map to `e_ij(x)` with `x ∈ J`.
    - Same-block `e_((i,a),(i,b))` is `[e_((i,a),(k,c)), e_((k,c),(i,b))]` with `k ≠ i`, so its image is a commutator of
      two cross-block images.
  - Hence `GL_n(R,J) = EL_n(R,J)` and `ker(EL_n(R) → EL_n(R/J)) = EL_n(R,J)`. Locally finite, because finitely many
    elements live in one finite `φ(GL_n(B))`.
- **(2) Upper bound.** `EL_n(R/J)` is LEF: `R/J` is a LEF ring, and a LEF ring has LEF `GL_n` through finite ring
  windows. So it is MF (`lef-implies-operator-mf`), and `Rad_MF ⊆ ker`.
- **(2) Nontrivial and proper.** `e ≠ 0`, and `EL_n(R/J)` is infinite.
- **(3)** `R/J` is the Steinberg algebra of the free minimal transformation groupoid of the infinite minimal subshift.
  The reviewed simplicity theorem gives central-or-everything with centre in `F_2^×I = {I}`, so `EL_n(R/J)` is simple.
  It is finitely generated with (T), and LEF.

## §2 Chain-transitive core: PASS (standard)

- `ω(x)` and `α(x)` are nonempty by compactness and consist of chain recurrent points.
- The chain `x, …, T^(N−1)x, y_0, …, y_(k−1), T^(−M)x, …, T^(−1)x, x` has junction errors
  `d(T^N x, y_0) < δ` and `d(T y_(k−1), T^(−M)x) ≤ d(Ty_(k−1), r) + d(r, T^(−M)x) < ε`.
- If `k = 0`, the single junction `d(T^N x, T^(−M)x) < ε`.
- A minimal set is chain transitive through its dense orbits.
- Standard Conley theory.

## §3 Transient crossed products: PASS

- By `thm:core-mf-radical` (`n ≥ 4`, `k = F_2`), the maximal MF quotient of `EL_n(R_X)` is `EL_n(R_Y)`.
- `X ≠ Y` means `Y` is not chain transitive by §2's contrapositive, hence not minimal. `Y = CR(T)` is closed and
  invariant, so a nonempty closed invariant `Z ⊊ Y` exists.
- `I_Z` (all coefficients vanishing on `Z`) is a two-sided ideal: `Z` is invariant, so `u f u^(-1) = f∘T^(-1)` still
  vanishes on `Z`. It is nonzero, since `Y` is zero-dimensional and `Y \ Z` is open and nonempty. It is proper, since
  `Z ≠ ∅`.
- For `n ≥ 3`, `EL_n(R_Y, I_Z)` is normal. If `EL_n(R_Y,I_Z)·Z = EL_n(R_Y)`, the nontrivial perfect group
  `EL_n(R_Y/I_Z)` would be an image of the abelian `Z`.
- **Display note.** The route shows nontriviality via `[e_12(a), e_23(1)] = e_13(a)`. Noncentrality needs one more
  line: `[e_13(a), e_32(1)] = e_12(a) ≠ 1`.

# Field crossed products over virtually division-embeddable groups (2026-09-17)

Lane `swarm-0917-w4-gs-rokhlin-kazhdan` (pivot from `bernoulli-rokhlin-maximal-on-fg-simple-kazhdan-groups`
to its bounty-30 kill `some-field-crossed-product-fails-the-rank-condition`, need `f489b4fe`).

**Why this hole.** By `twisted-linear-profile-deficits-are-rank-condition-failures`, one field crossed product
`K*G` without the rank condition kills every profile-level proof of maximal Bernoulli Rokhlin entropy at `G`.
The open claim names `Q(x) ⋊ PSL_2(Z)` (Möbius) as its lead test case, because it evades all three survival
regimes of `field-crossed-product-rank-condition-survival-cases`. This artifact shows that the test case, and a
large class around it, has the rank condition, and that the class stops exactly at groups with Kazhdan-like
subgroups. It also shows that for faithful actions the rank condition is the same as stable finiteness.

Notation. `K` is a commutative field, `σ: G -> Aut(K)` a homomorphism, `α: G x G -> K^x` a 2-cocycle for `σ`,
and `R = K*G` the crossed product with `K`-basis `u_g` (`g ∈ G`), relations `u_g c = σ_g(c) u_g` and
`u_g u_h = α(g,h) u_{gh}`. Each `u_g` is a unit of `R`. For `H <= G`, `K*H` denotes the span of the `u_h`,
`h ∈ H`: a subring and itself a crossed product for the restricted `σ, α`.

Terminology. `R` is *stably finite* (= weakly finite) if `XY = I_n` implies `YX = I_n` for square matrices of
every size `n`. `R` has the *rank condition* if there are no `A` (`d x r`), `B` (`r x d`) with `AB = I_d`, `r < d`.

## 1. Elementary lemmas

**Lemma 1 (stably finite gives rank condition).** A nonzero stably finite ring has the rank condition.

*Proof.* If `AB = I_d` with `r < d`, put `A' = [A | 0]` and `B' = [B ; 0]`, both `d x d`. Then `A'B' = AB = I_d`,
so `B'A' = I_d`. But the last `d - r` rows of `B'` are zero, so the last row of `B'A'` is zero, a contradiction
since `1 ≠ 0`. ∎

**Lemma 2 (simplicity for faithful actions).** If `σ` is injective, `R = K*G` is a simple ring.

*Proof.* Let `I ≠ 0` be a two-sided ideal and `x = sum_{g∈S} a_g u_g ∈ I` nonzero with `|S|` minimal, all
`a_g ≠ 0`. Multiplying on the right by the unit `u_{g_0}^{-1}` for some `g_0 ∈ S` gives an element of `I` with the
same support size whose support contains `e`; rename it `x`, so `e ∈ S`. For `c ∈ K`,
`c x - x c = sum_{g∈S} a_g (c - σ_g(c)) u_g` (because `u_g c = σ_g(c) u_g`). It lies in `I`, and its coefficient at
`e` vanishes, so its support is a proper subset of `S`. By minimality it is `0`: `a_g(c - σ_g(c)) = 0` for all
`g ∈ S`, `c ∈ K`, so `σ_g = id`, so `g = e` by injectivity. Thus `x = a_e u_e` with `a_e ≠ 0`, which is a unit
(`u_e = α(e,e) · 1`). So `I = R`. ∎

**Corollary 3.** If `σ` is injective, `K*G` has the rank condition iff it is stably finite.

*Proof.* `rank-condition-rings-have-weakly-finite-images` (ESTABLISHED): `A` has the rank condition iff it has a
nonzero weakly finite homomorphic image. A simple ring's only nonzero image is itself. Conversely Lemma 1. ∎

**Lemma 4 (locality).** If `AB = I_d` over `K*G`, let `H` be the subgroup generated by the finitely many group
elements in the supports of the entries of `A` and `B`. Then `AB = I_d` holds over `K*H`. The same holds for
`XY = I_n, YX ≠ I_n`. So `K*G` has the rank condition (is stably finite) iff `K*H` does for every finitely
generated `H <= G`.

*Proof.* `K*H` is a subring of `K*G` containing all entries. ∎

## 2. Finite-index transfer

**Lemma 5.** Let `N <= G` have finite index `n`, and suppose `K*N` embeds unitally in a stably finite ring `S`.
Then `K*G` embeds unitally in `M_n(S)`, and `K*G` is stably finite.

*Proof.* Choose right coset representatives `t_1 = e, t_2, ..., t_n`, so `G = ⊔_i N t_i`. Every `g ∈ G` is
uniquely `g = h t_i` with `h ∈ N`, and `u_h u_{t_i} = α(h,t_i) u_g`, with `α(h,t_i)` a unit of `K`. Hence
`M = K*G` is a free left `K*N`-module with basis `u_{t_1}, ..., u_{t_n}`:
`sum_g c_g u_g = sum_i (sum_{h∈N} c_{h t_i} α(h,t_i)^{-1} u_h) u_{t_i}` uniquely.

For `r ∈ K*G`, right multiplication `ρ_r: m -> m r` is left `K*N`-linear. Write `u_{t_i} r = sum_j M_r(i,j) u_{t_j}`
with `M_r(i,j) ∈ K*N`. For `m = sum_i m_i u_{t_i}`, `m r = sum_j (sum_i m_i M_r(i,j)) u_{t_j}`: in coordinates,
`ρ_r` is the row vector `(m_i)` times the matrix `M_r`. So `ρ_{r r'} = ρ_{r'} ∘ ρ_r` corresponds to
`M_{r r'} = M_r M_{r'}`, and `M_1 = I_n`, `M_{r+r'} = M_r + M_{r'}`. So `r -> M_r` is a unital ring homomorphism
`K*G -> M_n(K*N)`. It is injective: `M_r = 0` gives `u_e r = 0` (row `i = 1`), and `u_e` is a unit.

Compose with `M_n(K*N) -> M_n(S)`, which is injective and unital. `M_m(M_n(S)) = M_{mn}(S)` is directly finite for
every `m` because `S` is stably finite. A unital subring of a directly finite ring is directly finite, so
`M_m(K*G)` is directly finite for every `m`. ∎

## 3. The theorem

**Theorem 6.** Let `K*G` be a crossed product over a commutative field with any `σ`, `α`. Suppose every finitely
generated subgroup `H <= G` has a finite-index subgroup `N` such that one of the following holds:

- (i) `N` is residually torsion-free nilpotent (for example free, a subgroup of a right-angled Artin group, or a
  torsion-free nilpotent group);
- (ii) `N` is locally indicable and amenable;
- (iii) `N` is free-by-cyclic;
- (iv) `N` is the fundamental group of a finite graph of groups whose vertex groups are locally indicable and each
  satisfy (i), (ii) or (iii), and whose edge groups are locally indicable.

Then `K*G` is stably finite, and it has the rank condition.

*Proof.* By Lemma 4 it suffices to treat `K*H` for finitely generated `H`. Fix `N` as in the hypothesis and
restrict `σ, α` to `N`. The field `K` is a division ring, so `fsp-graph-of-rings-and-linnell-extension-imports`
applies to the crossed product `K*N`:

- in cases (i)–(iii), item 2 (Jaikin-Zapirain, *The universality of Hughes-free division rings*, Selecta Math.
  27 (2021), Thm 1.1, quoted verbatim in `fsp-graph-of-rings-and-linnell-extension-citation`: "Let $G$ be a
  locally indicable amenable group, a residually (torsion-free nilpotent) group, or a free-by-cyclic group. Then
  $\mathcal D_{k * G}$ exists and it is universal.") gives a Hughes-free division ring `D_{K*N}`. By definition
  it is an injective epic `K*N`-division ring, so `K*N` embeds unitally in a division ring. Residually
  torsion-free nilpotent groups are locally indicable, as the definition of Hughes-free requires; so are
  free-by-cyclic groups, and case (ii) assumes it;
- in case (iv), each vertex ring `K*G_v` has a Hughes-free embedding by the previous bullet, and item 6 of the
  import gives an embedding of `K*N` in a division ring.

A division ring `D` is stably finite: `M_m(D)` is the endomorphism ring of the finite-dimensional
`D`-vector space `D^m`, and a one-sided inverse of an endomorphism of a finite-dimensional vector space is
two-sided. Lemma 5 with `S = D` gives stable finiteness of `K*H`, and Lemma 1 gives the rank condition. ∎

Examples for (i): free groups and RAAG subgroups are residually torsion-free nilpotent by the sentence quoted in
the citation route ("Since RAAGs are residually (torsion-free nilpotent) ... so are their subgroups").

## 4. Consequences for the witness hunt

**Corollary 7 (the lead test case has the rank condition).** Every crossed product `K*PSL_2(Z)` over a commutative
field, in particular `Q(x) ⋊ PSL_2(Z)` by Möbius substitutions, is stably finite and has the rank condition.
More generally so is `K*G` for every virtually free `G`, every `G` with a finite-index subgroup embedded in a RAAG,
and every `G` with a finite-index free-by-cyclic subgroup; and so are `F_p(x_g) ⋊ G` for such `G`.

*Proof.* Classical input (not a graph import): `PSL_2(Z) ≅ C_2 * C_3`, and the kernel `N` of the map
`C_2 * C_3 -> C_2 x C_3` is torsion-free of index 6 and free (it meets no conjugate of a vertex group, hence acts
freely on the Bass–Serre tree; Serre, *Trees*, Ch. I §3). Apply Theorem 6 (i). Finitely generated subgroups of the
other classes keep a finite-index subgroup in the same class (intersect with the finite-index subgroup), so
Theorem 6 applies. ∎

This refutes the expectation recorded under `some-field-crossed-product-fails-the-rank-condition` that the Möbius
case "evades all three survival regimes": it evades them, but not the ordering regime. The complex-measure
argument died there; the division-ring argument does not need a measure.

**Lemma 8 (the regime is blind on Kazhdan groups).** Let `H` be an infinite finitely generated group with
property (T). No finite-index subgroup of `H` is locally indicable, so Theorem 6 never applies to `H` or to any
group containing `H`.

*Proof.* A finite-index subgroup `N` of `H` is infinite, finitely generated and has property (T), so its
abelianization is finite (`atiyah-kazhdan-edge-blocks-routes-proof`: property (T) groups are non-indicable). A
locally indicable nontrivial finitely generated group surjects onto `Z`. ∎

So every witness for `some-field-crossed-product-fails-the-rank-condition` must contain a finitely generated
subgroup none of whose finite-index subgroups is residually torsion-free nilpotent, locally indicable amenable,
free-by-cyclic, or a graph of these. Kazhdan subgroups are the cleanest source of such subgroups, and the flagship
host of `bernoulli-rokhlin-maximal-on-fg-simple-kazhdan-groups` is one. The ordering-and-indicability toolbox
(Malcev–Neumann, Hughes-free, Linnell) and the Kazhdan frontier of the Rokhlin program meet at the same place.

**Where the next test case lives.** Candidates that evade all four regimes (three survival cases plus Theorem 6):
- `Q(x, y) ⋊ SL_3(Z)` by projective substitutions, or its torsion-free congruence subgroup `Γ(3)`. Property (T)
  kills Theorem 6 by Lemma 8. Survival (c) needs an invariant probability measure on transcendental complex points
  of `P^2`; none is known (unchecked here). Note `congruence-kazhdan-groups-satisfy-strong-atiyah` gives
  `C[Γ(3)]` a division ring, but only for the trivial action, which survival (c) already covers.
- The ternary Leavitt twisted algebra of `some-field-crossed-product-fails-rank-from-ternary-cohn-family`, whose
  group contains Thompson-like torsion and nonamenable subgroups.

**What does not transfer.** Lemma 5 needs finite index. Commensurators and infinite-index division-embeddable
subgroups give nothing, because `K*G` is then a free module of infinite rank over `K*N`.

`N` to Theorem 6, but it is not imported verbatim here, so the established statement does not use it.

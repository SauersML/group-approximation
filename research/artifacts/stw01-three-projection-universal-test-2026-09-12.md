# STW Problem I: three projections are a universal test (2026-09-12)

Lane `quasitrace`. Proof artifact for `stw01-three-projection-algebra-quasitraces-are-traces`
and the route `stw01-problem-i-via-three-projection-algebra`.

## Statement

Let `P_3 = C^2 *_C C^2 *_C C^2` be the universal unital C*-algebra generated by
three projections `r_1, r_2, r_3`, equivalently `C*(Z_2 * Z_2 * Z_2)`.

**Theorem.** The following are equivalent.

1. STW Problem I: every bounded 2-quasitrace on a unital C*-algebra is a trace.
2. Every bounded 2-quasitrace on `P_3` is a trace.

**Sharpness.** The two-projection algebra `P_2 = C*(Z_2 * Z_2) = C*(D_infinity)`
is nuclear, because `D_infinity` is amenable. So every bounded 2-quasitrace on
`P_2` or on any of its quotients is a trace (Haagerup). Three is the least number
of projections that can carry a counterexample.

**Relation to the `C*(F_2)` test.** At the level of groups neither test comes from
the other.
- `F_2` does not surject onto `Z_2 * Z_2 * Z_2`, whose abelianization `(Z/2)^3` is
  not 2-generated.
- `Z_2 * Z_2 * Z_2` does not surject onto `F_2`, because it is generated by
  involutions and `F_2` is torsion-free.

So this theorem is not an instance of the group-quotient step of the predecessor's
Theorem 3.1(3), and the proof below is separate. Whether `P_3` and `C*(F_2)` are
quotients of one another as C*-algebras is not decided here: a C*-quotient map need
not send group elements to group elements. Both algebras are universal tests for
Problem I.

## Inputs, with sources read on MSI

- **(I1)** Gow arXiv:2601.04431v2, Theorem A, (i) ⟺ (ii), due to Blackadar–Handelman.
  If (1) fails, some type `II_1` AW*-factor `M` is not a W*-factor.
- **(I2)** Gow Theorem 2.22 (after Fehlker, Theorem 1.27). A finite AW*-algebra
  has a unique centre-valued quasitrace. For the factor `M` it is scalar-valued:
  - additive on commuting normal elements;
  - homogeneous;
  - `0 <= tau(x*x) = tau(xx*)`;
  - faithful;
  - `tau(x + iy) = tau(x) + i tau(y)`;
  - monotone on `M_sa`;
  - norm-continuous;
  - equal to the dimension function on projections.
- **(I3)** Blackadar–Handelman, Corollary II.1.10, quoted by Gow §2.3. Every
  1-quasitrace on an AW*-algebra is a 2-quasitrace, hence an `n`-quasitrace. So
  there is a quasitrace `tau_4` on `M_4(M)` with `tau_4(z (x) e_11) = tau(z)`.
- **(I4)** Wright, J. London Math. Soc. (2) 12 (1975/76), quoted by Gow §1. A type
  `II_1` AW*-factor admitting a faithful state is a W*-factor.
- **(I5)** Every self-adjoint element of an AW*-algebra lies in a MASA `C(X)` with
  `X` Stonean, so totally disconnected. Positive elements with finite spectrum are
  therefore norm-dense in `M_+`.
- **(I6)** The unital full free product has the universal property. A bounded
  2-quasitrace restricts to a bounded 2-quasitrace on a unital C*-subalgebra, and
  pulls back to one along a unital surjective *-homomorphism: predecessor artifact
  `stw01-certificates-products-universal-tests-2026-09-11.md`, Theorem 3.1.

## Proof of (2) ⟹ (1)

Assume (1) fails. Take `M` and `tau` from (I1) and (I2). For `x, z in M_+` write

```text
D(x, z) = tau(x + z) - tau(x) - tau(z).
```

**Step 0: some defect is nonzero.** Suppose `D` vanished on `M_+`. Then `tau` would
be additive and homogeneous on `M_+`, hence linear on `M_sa` via `x = x_+ - x_-`,
and linear on `M` by (I2). So `tau` would be a faithful state, and `M` would be W*
by (I4). So `D(a, b) != 0` for some `a, b in M_+`.

**Step 1: continuity.** If `x, x' in M_+` and `||x - x'|| <= eps`, then
`x <= x' + eps 1`. Monotonicity and linearity on `C*(1, x')` give
`tau(x) <= tau(x') + eps`, and symmetrically. So
`|D(x, z) - D(x', z')| <= 2(||x - x'|| + ||z - z'||)`. By (I5) we may replace `b`
by a finite-spectrum `b' = sum_(j=1)^m beta_j q_j`, with `beta_j > 0` and pairwise
orthogonal projections `q_j`, keeping `D(a, b') != 0`.

**Step 2: telescope to a single projection.** Put `x_0 = a` and
`x_j = a + sum_(l <= j) beta_l q_l`. The `q_j` commute, so
`tau(b') = sum_j beta_j tau(q_j)`, and

```text
D(a, b') = sum_(j=1)^m [ tau(x_(j-1) + beta_j q_j) - tau(x_(j-1)) - beta_j tau(q_j) ].
```

So some `j` gives `D(x, beta q) != 0`, with `x = x_(j-1) in M_+`, `beta = beta_j > 0`
and `q = q_j` a projection.

**Step 3: finite spectrum, then shift.** By Step 1, replace `x` by a finite-spectrum
`y_0 = sum_(i=1)^k gamma_i e_i` with `D(y_0, beta q) != 0`. Here the `e_i` are
nonzero pairwise orthogonal projections summing to `1`, and `gamma_k` is the least
eigenvalue. Since `D(c 1, beta q) = 0`, we have `k >= 2`. Put

```text
y = y_0 - gamma_k 1 = sum_(i<k) delta_i e_i,     delta_i > 0.
```

Linearity on `C*(1, w)` gives `tau(w + c 1) = tau(w) + c`, so
`D(y, beta q) = D(y_0, beta q) != 0`.

**Step 4: dilate the spectral family into two projections.** Put
- `P = sum_(i<k) e_i`;
- `A = sum_(i<k) lambda_i e_i`, with `lambda_i = i/k` distinct in `(0, 1)`;
- `S = (A - A^2)^(1/2)`.

All three lie in the commutative algebra `C*(e_1, ..., e_(k-1))`, and `SP = S`. In
`M_2(M)` define

```text
p  = [[P, 0], [0, 0]],        p' = [[A, S], [S, P - A]],        q^ = [[q, 0], [0, 0]].
```

Then `p` and `q^` are projections, and

```text
p'^2 = [[A^2 + S^2, AS + S(P - A)], [SA + (P - A)S, S^2 + (P - A)^2]]
     = [[A, S], [S, P - A]] = p'.
```

Also `p p' p = [[A, 0], [0, 0]]`, whose spectrum is `{0} union {lambda_i : i < k}`.
Choose `g` continuous on `[0,1]`, with `g >= 0`, `g(0) = 0` and
`g(lambda_i) = delta_i`. Then `g(p p' p) = [[y, 0], [0, 0]]`. So `y (+) 0` and `q^`
lie in `B = C*(1, p, p', q^) <= M_2(M)`.

**Step 5: amplify and pull back.**
- *The quasitrace on `M_2(M)`.* Let `tau~` be the restriction of `tau_4` from (I3)
  to the upper-left block `M_2(M) (x) e_11` of `M_4(M) = M_2(M_2(M))`. Then `tau~`
  is a quasitrace on `M_2(M)` with `tau~(z (+) 0) = tau(z)`, and it is a
  2-quasitrace because `tau_4` extends it.
- *The defect survives.* With homogeneity on `C*(q^)`,

  ```text
  tau~((y + beta q) (+) 0) - tau~(y (+) 0) - beta tau~(q^) = D(y, beta q) != 0.
  ```

- *Restriction.* `tau~|_B` is a bounded 2-quasitrace (I6). It is bounded because
  `0 <= w <= ||w|| 1` forces `tau~(w) <= ||w|| tau~(1)`, by linearity on `C*(1, w)`.
- *Pullback.* The unital *-homomorphism `pi : P_3 -> B` with `r_1 -> p`,
  `r_2 -> p'` and `r_3 -> q^` is surjective, so `sigma = tau~ o pi` is a bounded
  2-quasitrace on `P_3` (I6). Its positive lifts are `g(r_1 r_2 r_1)`, since
  `g(0) = 0` and `pi` commutes with functional calculus, and `beta r_3`. So

  ```text
  sigma(g(r_1 r_2 r_1) + beta r_3) != sigma(g(r_1 r_2 r_1)) + beta sigma(r_3),
  ```

  and (2) fails.

**(1) ⟹ (2)** is trivial. ∎

## Extracted lemma

In a type `II_1` AW*-factor, the quasitrace `tau` is linear iff
`tau(y + q) = tau(y) + tau(q)` for every positive `y` with finite spectrum and
every projection `q`. This is Steps 0–3 together with homogeneity. So
non-additivity always shows up when a single projection is added to a positive
element with finite spectrum.

## 4. One central transvection detects a unitriangular group
**Lemma 3.** Let d ≥ 2, and let y_PQ (1 ≤ P < Q ≤ d) be elements of a group Q satisfying:
- y_PQ² = 1;
- [y_PQ, y_QS] = y_PS for P < Q < S;
- [y_PQ, y_RS] = 1 whenever Q ≠ R and P ≠ S.

Then x_PQ = I + E_PQ ↦ y_PQ extends to a homomorphism U_d(F_2) → Q. If y_1d ≠ 1 this homomorphism is injective, so
|Q| ≥ 2^{d(d−1)/2}.

*Proof.*
- Let Ũ be the group presented by these generators and relations. They hold in U_d(F_2), so U_d(F_2) is a quotient of Ũ.
- Give y_PQ height Q − P, and let Ũ_h = ⟨y_PQ : Q − P ≥ h⟩.
- For generators y, y', the commutator [y', y] is 1 or a generator whose height is the sum of the two heights.
  The case [y_PQ, y_RP] = [y_RP, y_PQ]^{-1} = y_RQ is covered because the generators are involutions.
- Since g y g^{-1} = [g, y] y, the subgroup Ũ_{h+1} is normal in Ũ, and two generators of height h commute modulo Ũ_{h+1}.
- So Ũ_h/Ũ_{h+1} is abelian, generated by the images of the d − h involutions of height h, and has order ≤ 2^{d−h}.
- Hence |Ũ| ≤ 2^{Σ_h (d−h)} = 2^{d(d−1)/2} = |U_d(F_2)|, so Ũ ≅ U_d(F_2).
- A nontrivial normal subgroup of the finite 2-group U_d(F_2) meets its centre {I, I + E_1d} nontrivially. So a nontrivial kernel forces y_1d = 1. ∎

## 5. Short towers force large models
**Lemma 4 (tower copy; note l.155-216).** Let W ⊆ X be a nonempty clopen set with W ∩ T^tW = ∅ for 0 < |t| ≤ 2m, and let d = 3(2m+1).
- Index {1,2,3} × {−m,…,m} by P = (p,a), ordered lexicographically, and put E_ab(W) = u^a e_W u^{-b} = e_{T^aW}u^{a−b}.
- The relation E_ab(W)E_cd(W) = δ_bc E_ad(W) (note l.161) makes E_PQ ↦ E_ab(W)E_pq an injective non-unital ring homomorphism ι: M_d(F_2) → M_3(R).
- Then g ↦ (1 − e)I_3 + ι(g), with e = Σ_a e_{T^aW}, embeds GL_d(F_2) in G_X.
- Its elementary transvections τ_PQ = I_3 + E_ab(W)E_pq are:
  - τ_PQ = e_pq(E_ab(W)) when p ≠ q;
  - τ_PQ = [e_pq'(E_ab(W)), e_q'p(E_bb(W))] with q' ≠ p when p = q and a ≠ b (note l.209-214).
- So the relations of Lemma 3 hold among the τ_PQ (P < Q) in G_X, and τ_1d ≠ 1.

**Theorem C.** In the setting of Lemma 4, let κ = max_{i≠j} |e_ij(e_W)|. Then L_X(r) ≥ 2^{d(d−1)/2} for every r ≥ 20κ + 480m.

*Proof.*
- By Lemma 1, |e_pq(E_ab(W))| ≤ κ + 24m. So every τ_PQ has length ≤ λ = 4(κ + 24m).
- Each relation of Lemma 3 is a word of length ≤ 5λ = 20κ + 480m ≤ r.
- By Lemma 0 the elements y_PQ = φ(τ_PQ) satisfy these relations in Q, and y_1d ≠ φ(1) = 1 by injectivity.
- Apply Lemma 3. ∎

For a full cylinder of length 2^h, Lemma 2 gives κ ≤ 25·4^h. For linearly recurrent X this recovers only exp(cr). Sturmian subshifts have much shorter towers.

## 6. Sturmian subshifts
**Theorem D.** Let X = X_α be the Sturmian subshift of irrational slope α ∈ (0,1), and let a = ⌊1/min(α, 1−α)⌋. For every
r ≥ 3440 + 1200a,
`2^{18((r − 3440)/2400)²} ≤ L_X(r) ≤ 2^{9(8r+4)²}`.
So L_{X_α} ≃ exp(r²) for every α, and the constants in the exponents do not depend on α.

*Proof.* The upper bound is Corollary A1. For the lower bound:

1. *Reduction.* Exchanging the letters 0 and 1 conjugates X_α to X_{1−α} and maps the generating set S to itself. So assume α < 1/2. Then a = q_1 = ⌊1/α⌋ ≥ 2.
2. *Coding* (Lothaire, *Algebraic Combinatorics on Words*, ch. 2).
   - X consists of the codings x^+_θ and x^−_θ, θ ∈ R/Z.
   - x^+_θ(n) = 1 iff θ + nα ∈ [1−α, 1) mod 1, and x^−_θ uses (1−α, 1].
   - T x^±_θ = x^±_{θ+α}.
3. *Best approximation.* Let p_n/q_n be the convergents of α and η_n = q_nα − p_n.
   - Claim: for 0 < t < q_{n+1} and every integer p, |tα − p| ≥ |η_n|, with equality only for (t,p) = (q_n, p_n).
   - Since p_{n+1}q_n − p_nq_{n+1} = ±1, write (t,p) = c(q_n,p_n) + c'(q_{n+1},p_{n+1}) with integers c, c', so tα − p = cη_n + c'η_{n+1}.
   - c = 0 would force t ∉ (0, q_{n+1}).
   - If c' = 0 then c ≥ 1, and |tα − p| = c|η_n|.
   - Otherwise c and c' have opposite signs (same signs would put t outside (0, q_{n+1})). Since η_n and η_{n+1} also have opposite signs, |tα − p| = |c||η_n| + |c'||η_{n+1}| > |η_n|.
   - So ‖tα‖ ≥ ‖q_nα‖ = |η_n| for 0 < t < q_{n+1}.
4. *The set W.* Let m ≥ a/2, and let n ≥ 1 be largest with q_n ≤ 2m, so that q_{n+1} > 2m.
   - Put ε = |η_n|. Then ε ≤ |η_1| = 1 − q_1α < α.
   - Choose s ∈ {q_n, −q_n} with sα ≡ −ε mod 1. Let j = 1 + s and W = {x ∈ X : x_0 = 1, x_j = 1}.
   - For + codings: θ ∈ [1−α,1) and θ + jα ≡ θ + α − ε ∈ [1−α,1). So θ ∈ [1−α,1) ∩ [1−2α+ε, 1−α+ε) = J := [1−α, 1−α+ε); the arcs do not wrap, since α < 1/2 and ε < α.
   - For − codings the same computation gives J^− = (1−α, 1−α+ε].
   - So W is a nonempty clopen set, and |j| ≤ q_n + 1 ≤ 2m + 1.
5. *No short returns.* Suppose x ∈ W ∩ T^tW with 0 < |t| ≤ 2m.
   - Replacing (x, t) by (T^{-t}x, −t), take t > 0.
   - Write x = x^±_θ. Then T^{-t}x = x^±_{θ−tα} ∈ W, so θ and θ − tα lie in the same half-open arc J or J^− of length ε.
   - So ‖tα‖ < ε, contradicting step 3, since 0 < t ≤ 2m < q_{n+1}.
6. *Costs.* e_W = e_1 · u^{-j} e_1 u^j. By [e_ik(r), e_kj(s)] = e_ij(rs) and Lemma 1,
   |e_ij(e_W)| ≤ 2·1 + 2(1 + 24|j|) ≤ 52 + 96m.
   Theorem C with κ ≤ 52 + 96m gives L_X(r) ≥ 2^{d(d−1)/2} ≥ 2^{18m²} whenever r ≥ 1040 + 2400m, where d = 6m+3.
7. *Choice of m.* For r ≥ 3440 + 1200a, take m = ⌊(r − 1040)/2400⌋. Then m ≥ a/2, r ≥ 1040 + 2400m, and m ≥ (r − 3440)/2400. ∎

## 7. Consequences
- **(D1) LEF growth does not separate Sturmian slopes.** For all irrational α and β, L_{X_α} ≃ L_{X_β} ≃ exp(r²). The recurrence function of X_α is linear only for bounded partial quotients (standard; not re-verified here).
  - This refutes the separation clause of `elementary-group-lef-growth-separates-subshifts`.
  - Whether G_{X_α} ≅ G_{X_β} forces a relation between α and β stays open. Other invariants would be needed; see `subshift-elementary-group-isomorphism-forces-orbit-equivalence`.
- **(D2) Complexity separates coarser classes.** Suppose X has positive entropy, or p_X(n) ≥ n^{4+ε} for infinitely many n. Then:
  - at r_i = 500n_i², Theorem B gives log L_X(r_i) ≥ c·r_i^{2+ε/2};
  - for linearly recurrent Y, N_Y(n) ≤ 2R_Y(n) = O(n), so L_Y ≼ exp(r²);
  - so G_X ≇ G_Y, because the LEF growth class is an isomorphism invariant.
  - In particular G_X ≇ G_{X_α} for every Sturmian X_α.
- **(D3) Bradford's Question 7.2** asks for the LEF growth of [[T]]' and its dependence on the dynamics. Theorem D answers the analogous question for G_X on the Sturmian family: the growth is exp(r²) and does not depend on the slope. This is a variant, not an answer to the printed question.
- **(D4) Other q and n (sketch, not reviewed).** The argument applies to S_X = EL_n(LC(X,F_q) ⋊ Z)/Z for n ≥ 3.
  - The tower copy of SL_{n(2m+1)}(F_q) meets the centre trivially, because it acts as the identity off the tower.
  - Lemma 3 over F_q, with generators y_PQ(λ), has the same height filtration with factors of order ≤ q^{d−h}.
  - A nontrivial normal subgroup of the p-group U_d(F_q) meets the centre {I + λE_1d}, and every element of that centre is a short tower transvection.
  - So L ≃ exp(r²) for Sturmian X, for all q and n ≥ 3, with constants depending on q and n.

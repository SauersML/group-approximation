# No homomorphic-image transfer can be torsion-free on every permitted input

2026-09-08.  Third ingestion into the torsion-free transfer region, after
`torsion-free-transfer-covers-and-obstructions-2026-09-08.md` (the canonical
cover and the central-kernel no-go) and
`torsion-free-cover-fd-radical-and-heisenberg-2026-09-08.md` (the cover's exact
finite-dimensional radical, and why computing it is not a transfer).

An external note again reported that it had **not** settled the transfer, and
supplied two negative results instead.  Both are real, both are new here, and
both are landed.  Neither touches `free-abelianized-cover-reflects-mf`, which
remains the isolated open implication.

## 1. The construction

Everything below takes as input a nontrivial finitely generated group `H` with

```text
Rad_MF(H) = H,
```

i.e. every homomorphism from `H` to a countable MF group is trivial -- the
archive's *full MF radical*.  The class of such groups is `Z_MF` of
`full-mf-radical-groups-form-an-extension-colimit-class`, and it is nonempty:
`defect-saturation-full-mf-radical` supplies a two-generated finitely presented
one.

Two of the note's preliminary steps are already established here and are cited
rather than re-derived.

- **`H` may be taken finitely presented.**  The note proves this by an
  amplification argument (tensor-power direct sums push a fixed generator
  displacement up to `sqrt 2` while multiplying relator error by a bounded
  factor, so a corona representation of some finite truncation survives).  The
  archive already has the conclusion in a stronger form:
  `full-mf-radical-has-fp-cover-same-generators` produces a finitely presented
  cover on the same generating set with the same property, and the same
  amplification is the content of
  `full-mf-radical-linear-relator-inequality`.
- **`H` is perfect.**  A nontrivial finitely generated abelianization has a
  nontrivial finite cyclic quotient, which is MF.  This is
  `full-mf-radical-forces-perfect-commutator-bound`.

Now set

```text
B = H * H.
```

`B` is finitely presented, perfect, and lies in `Z_MF` (free products, by
`full-mf-radical-groups-form-an-extension-colimit-class`).  Pick `h != 1` in
`H` and let `a` be the product of its two copies, one from each free factor;
`a^n` is a reduced alternating word of length `2n`, so `a` has infinite order.

For `m = 2, 3` put

```text
W_m = B^m x| C_m,        C_m = <t_m | t_m^m = 1>,
```

with `t_m` cyclically permuting the coordinates, and

```text
u_m = (a,1,...,1) t_m,        so   u_m^m = (a,a,...,a).
```

So `u_m` has infinite order.  Finally

```text
K = W_2 *_(<u_2> = <u_3>) W_3.
```

`K` is finitely presented: `B` is, hence so is each `W_m`, and an amalgam of
finitely presented groups over a finitely generated subgroup is finitely
presented.  Both factors embed, by the normal form for amalgamated free
products; the note gives an elementary substitute -- left multiplication of
`W_m` on `W_m x N` is faithful, `u_m` acts with countably many infinite cyclic
orbits, so both actions transport to `Z x N` with `u_2` and `u_3` acting as the
same shift, and the resulting `K -> Sym(Z x N)` restricts faithfully to each
factor.

## 2. What `K` is

**`K` has full MF radical.**  Let `phi : K -> M` with `M` MF.  Each coordinate
copy of `B` lies in `Z_MF` and its image is a countable subgroup of `M`, hence
MF, so `phi` kills it.  So `phi` factors through `C_m` on each side and
`phi(u_m) = phi(t_m)`.  The amalgamating relation then gives

```text
phi(t_2) = phi(u_2) = phi(u_3) = phi(t_3) =: g,
g^2 = g^3 = 1,     hence   g = 1.
```

So `phi` kills `t_2, t_3` and both bases, hence both factors, hence `K`.

**`t_m` normally generates `W_m`.**  Setting `t_m = 1` identifies all `m`
coordinate copies of `B`; distinct coordinates commute in `W_m`, so the common
image is abelian, and `B` is perfect, so it is trivial.  Hence
`W_m/<<t_m>> = 1`.

**Therefore `K = <<t_2, t_3>>`,** with `t_2, t_3` of order exactly `2` and `3`
(the factors embed).  In particular `K` is generated by torsion elements.

**Consequences.**  Every nontrivial quotient of `K` retains `t_2` or `t_3`,
hence contains an element of order exactly `2` or exactly `3`.  Every
homomorphism from `K` to a torsion-free group is trivial -- which is
`torsion-generated-mf-absorbers-die-in-torsion-free-targets` clause 1 applied
to `K`, so it is a citation, not a new argument -- and the universal
torsion-free quotient of `torsion-free-universal-quotient-recursively-presented`
satisfies

```text
K^tf = 1.
```

## 3. What it rules out, exactly

`K` is a **permitted input**: nontrivial, finitely presented, with full MF
radical.  And it has no nontrivial torsion-free quotient at all.  So there is
no procedure, valid on every input with full MF radical, that outputs a
nontrivial torsion-free group as a homomorphic image of its input.

This is the universal form of something the archive already had in scoped form.
`torsion-generated-mf-absorbers-die-in-torsion-free-targets` proves that the
binary-Leavitt absorbers currently in use are torsion-generated and so die in
every torsion-free quotient -- a fact about the witness in hand, which a better
witness could in principle repair.  The construction above shows the defect is
not repairable by choosing a better witness: whatever strong input one starts
from, the input class *contains* an object with trivial universal torsion-free
quotient, built from it.

**What it does not rule out.**  Covers.  A surjection `T ->> K` with `T`
torsion-free is not excluded and indeed exists trivially (free groups), which
is exactly why `free-abelianized-cover-reflects-mf` is the interesting
statement and why it is untouched here.  Nor does it bear on
`torsion-free-mf-radical-routing-saturation`, whose hypothesis `(TFR1)` takes
the torsion-free `Q` as *supplied data*; what the obstruction adds there is
that no general procedure can manufacture that `Q` as a quotient of the input.

And it does not contradict the archive's own torsion-free theorem:
`defect-saturation-full-mf-radical` builds a torsion-free full-MF-radical group
directly, using property (T), rather than transferring one out of an arbitrary
input.  The open target remains the property-(T)-free version.

## 4. The permanence axioms cannot imply the transfer

The note's second result is a genuine independence argument.  Fix `K` and put

```text
C_K = { L : every homomorphism K -> L is trivial }.
```

Then `C_K` contains every MF group (section 2) and every torsion-free group
(section 2), all finite and all residually finite groups, and is closed under
subgroups, arbitrary direct products, directed unions, arbitrary directed
colimits, and extensions.  Non-membership localizes to a finite presentation:
if `L = F/R` is finitely generated and some `f : K -> L` is nontrivial, lift
the images of `K`'s finitely many generators to words in `F`, collect the
finitely many evaluated relators of `K` into `R_0 subset R`, and the same tuple
defines a nontrivial map `K -> F/<<R_0>>`.  The colimit case uses finite
presentability of `K` in both halves: lift a finite generating set to one
stage, and the finitely many relations hold at some later stage.

Yet `C_K` contains **every** torsion-free group, so there is no torsion-free
group outside it, while `K` itself is a nontrivial finitely presented group
outside it.  Reading "MF" as "`C_K`" therefore satisfies each of the listed
permanence and localization properties and falsifies the transfer statement.
Hence no derivation of the transfer from those properties alone can be valid.

**Two honesty notes on this argument.**

- `C_K` satisfies *more* than MF does, not less: MF is not closed under
  extensions (`mf-extension-nonclosure`) and not closed under quotients
  (`mf-quotient-nonclosure`), whereas `C_K` is extension-closed.  That does not
  weaken the independence -- a model may satisfy extra properties -- and it is
  worth recording so a reader does not disqualify the counterclass for being
  too well behaved.  `C_K` is *not* quotient-closed either: free groups lie in
  it and `K` is one of their quotients.
- The conclusion is about derivations from that axiom list, not about MF.  Any
  affirmative transfer theorem must use something specific to norm matrix
  models.  This is a statement about proof ingredients, not an impossibility
  theorem.

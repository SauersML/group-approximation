# Stabilizer rounding for prime-dimensional qudits (2026-09-12)

Lane `ex-quantum-pcp`. Elementary proof, unreviewed, not Lean-verified, no
computation. This extends Theorem SR of
`research/artifacts/pauli-frustration-stabilizer-rounding-2026-09-12.md` from qubits
to qudits of prime dimension `d`, with a weaker constant. The root claim allows any
constant local dimension, and good qLDPC codes exist over every finite field
(Panteleev--Kalachev), so the qudit case is the one code-based designs meet.

## 1. Setting

`d` is prime and `omega = e^(2 pi i/d)`. The Weyl operators on `n` qudits are
`X^a Z^b` for `a,b in F_d^n`, up to phases in `<omega>` (and `-1` when `d=2`). Two
Weyl operators satisfy `gh = omega^m hg` for some `m`. A stabilizer group is an
abelian group of Weyl operators with phases containing no scalar other than `I`.
Its code projector is `Pi_S = |S|^(-1) sum_(g in S) g`. When `|S| = d^n` it is a
rank-one stabilizer state.

A *Weyl decomposition* of a Hermitian `K` is an explicit list
`K = sum_j c_j g_j` with `c_j` complex and `g_j` Weyl operators. Its weight is
`W = sum_j |c_j|`. Put `u_j = (c_j/|c_j|) g_j`, a unitary that commutes with every
`u_k` up to a power of `omega`. Then `K = sum_j |c_j| u_j` and
`<psi|K|psi> = sum_j |c_j| Re<psi|u_j|psi>`.

## 2. Theorem SR_d

**Theorem.** `max_(phi stabilizer) <phi|K|phi> >= lambda_max(K) - C_d (W - lambda_max(K))`,
with `C_d = 8/sin^2(pi/d) - 1`.

*Proof.* Let `psi` be a top eigenvector, `delta_j = 1 - Re<psi|u_j|psi> in [0,2]`, so
`sum_j |c_j| delta_j = W - lambda_max =: F`. Put `tau_d = sin^2(pi/d)/8`.

**(Q1) The good set commutes.** For a unitary `u`, `||u psi - psi||^2 = 2 delta_u`.
If `u_j u_k = omega^m u_k u_j` with `m != 0 mod d`, then

```text
|1 - omega^m| = ||u_j u_k psi - u_k u_j psi||
             <= ||u_j u_k psi - psi|| + ||psi - u_k u_j psi||
             <= 2 (sqrt(2 delta_j) + sqrt(2 delta_k)),
```

and `|1-omega^m| >= 2 sin(pi/d)`. If both `delta < tau_d`, the right side is below
`4 sqrt(2 tau_d) = 2 sin(pi/d)`, which is a contradiction. So `G = {j : delta_j < tau_d}` is a
commuting family of unitaries.

**(Q2) Pattern.** Measuring the commuting family `{u_k : k in G}` on `psi` gives a
distribution `mu` on outcome tuples `x` (eigenvalues, which are phases). Let `G*`
be the indices `j` with `u_j` in `C^* <u_k : k in G>`. Each such `u_j` has a determined
outcome `x_j`, and `E_mu x_j = <psi|u_j|psi>`. Choose `x` of positive probability with
`sum_(G*) |c_j| (1 - Re x_j) <= sum_(G*) |c_j| delta_j`.

**(Q3) Stabilizer states in `E_x`.** The joint eigenspace `E_x` is nonzero. So the
group `A_x` generated by `{x_k^(-1) u_k : k in G}` is abelian and contains no
nontrivial scalar. For prime `d` it extends to maximal stabilizer groups of order
`d^n`, whose states `S_x` lie in `E_x`. All of them have `<u_j> = x_j` for
`j in G*`. Let `nu` be uniform on the finite set `S_x`.

**(Q4) Undetermined terms average to zero.** Let `j not in G*`.
(a) If `u_j h = omega^m h u_j` for some `h in A_x` and `m != 0`, then for every
`phi in S_x`, `<phi|u_j|phi> = <phi|u_j h|phi> = omega^m <phi|h u_j|phi> = omega^m <phi|u_j|phi>`,
so `<phi|u_j|phi> = 0`.
(b) Otherwise `u_j` lies in the centralizer `C(A_x)` but not in `C^* A_x`.
The symplectic form on `C(A_x)/A_x` over `F_d` is nondegenerate, so some Weyl `R` in
`C(A_x)` has `R u_j = omega^m u_j R` with `m != 0`. `R` commutes with `A_x`, so it
permutes `S_x`, and `<R phi|u_j|R phi> = omega^(-m) <phi|u_j|phi>`. Invariance of
`nu` gives `E_nu <u_j> = omega^(-m) E_nu <u_j>`, so the average is `0`.

**(Q5) Accounting.**
`E_nu <phi|K|phi> = sum_(G*) |c_j| Re x_j >= sum_(G*) |c_j| (1 - delta_j)`. Hence
`lambda_max - E_nu<phi|K|phi> <= sum_(j not in G*) |c_j| max{0, 1 - delta_j}`. Outside
`G`, `delta_j >= tau_d`, and `max{0,1-delta} <= ((1-tau_d)/tau_d) delta`, so the loss is at
most `C_d F`. Some member of `S_x` attains the average. QED.

For `d=2` this gives `C_2 = 7`. The qubit proof uses `(A+B)^2 = 2I` for
anticommuting signed Paulis instead and gets `1+sqrt2`.

## 3. Code-constraint Hamiltonians

**Corollary.** Let `H = sum_a w_a (I - Pi_(S_a))` with `w_a >= 0` and stabilizer
groups `S_a` on prime-dimensional qudits. Some stabilizer state has
`<phi|H|phi> <= (8/sin^2(pi/d)) lambda_min(H)`.

*Proof.* `Pi_(S_a) = |S_a|^(-1) sum_(g in S_a) g` lists `|S_a|` distinct Weyl operators,
each with coefficient of modulus `|S_a|^(-1)`, so its weight is exactly one. Then
`K = sum_a w_a Pi_(S_a)` has weight `W = sum_a w_a`, `H = W I - K`,
`lambda_min(H) = W - lambda_max(K)`, and the theorem gives
`<phi|H|phi> <= F + C_d F = (8/sin^2(pi/d)) lambda_min(H)`. QED.

**NP.** For prime `d`, a stabilizer state has a polynomial-size tableau over `F_d`.
`<phi|Pi_S|phi> = |S|^(-1) sum_(g in S) <phi|g|phi>`. Here `<phi|g|phi>` is nonzero
only on the subgroup `T` of `S` proportional to members of `Stab(phi)`, and on `T` it
is a character. So the value is `|T|/|S|` if that character is trivial and `0`
otherwise, computable by `F_d` linear algebra. Deciding `lambda_min(H) <= a` versus
`>= b` is therefore in NP when `b > (8/sin^2(pi/d))a`. Arbitrary extra terms of weight
`V` are handled as for qubits: the NP bound holds when `V < b - (8/sin^2(pi/d))a`.

## 4. Scope

- Composite local dimensions are not treated. Qubit codes embedded in larger
  dimension are covered by the qubit theorem.
- Values: `8/sin^2(pi/3) = 10.67`, `8/sin^2(pi/5) = 23.2`. No sharpness is claimed
  for `d>2`.
- Bearing, if QMA is not in NP: a QMA-hard family on prime-`d` qudits whose terms all
  penalize leaving stabilizer code spaces has YES energy at least
  `b sin^2(pi/d)/8`. Reducers on the Dinur and global-walk routes cannot output
  such families.

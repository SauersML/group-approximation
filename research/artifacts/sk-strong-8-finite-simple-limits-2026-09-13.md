# sk-strong-8: LEF groups are the subgroups of simple Kazhdan limits of finite simple expanders

Lane sk-strong-8, 2026-09-13. Status: established with complete proofs below, UNREVIEWED (queued with sk-verify-7).

## 0. Statements

**Theorem A (the lamplighter host is a limit of finite simple expanders).**
- Setting: Δ is a finitely generated infinite LEF group with finite symmetric generating set S. As in `lamplighter-bernoulli-crossed-products-simple-kazhdan-lef`:
  - Δ acts on Z = 2^Δ by (δx)(h) = x(δ^{-1}h), and a flips the coordinate at e;
  - L = ⟨Δ, a⟩ ≅ Z/2 ≀ Δ, R = LC(Z,F_2) ⋊ L, and H = EL_3(R).
- Let F be the free F_2-algebra on letters t_s, t_s′ (s ∈ S), t_a, t_p. Let π: F → R send t_s ↦ u_s, t_s′ ↦ u_s^{-1}, t_a ↦ u_a and t_p ↦ p = 1_{[x(e)=1]}.
- Mark H by the matrices e_ij(π(t)), for i ≠ j and t a letter.

Then there are finite simple groups SL_{3N_n}(F_2), N_n → ∞, with markings e_ij(ρ_n(t)), such that:
1. (SL_{3N_n}(F_2), markings) → (H, marking) in the space of marked groups;
2. H and every approximant are marked quotients of Λ = EL_3(F), which has property (T), so the Cayley graphs of the approximants for these markings form a family of expanders.

Together with the reviewed node, H is also infinite, finitely generated, simple, Kazhdan and LEF.

**Theorem B (characterization).** For a finitely generated group Γ the following are equivalent.
- (i) Γ is LEF.
- (ii) Γ is a subgroup of an infinite, finitely generated, simple group with property (T) that is the limit, in the space of marked groups, of finite simple groups SL_N(F_2) whose Cayley graphs form expanders.

The trivial group Γ = 1 recovers the existence statement that answers Brown, Ozawa and Pestov.

## 1. The view models

**LEF models.** There are finite groups Q_n and radii r_n → ∞ with maps φ_n: B_{2r_n} → Q_n, φ_n(e) = e, injective and multiplicative on pairs from B_{r_n}.
- Replace Q_n by the subgroup ⟨φ_n(S)⟩. It contains φ_n(B_{r_n}), since φ_n(s_1⋯s_k) = φ_n(s_1)⋯φ_n(s_k).
- Extend φ_n to all of Δ by e outside B_{r_n}.
- So φ_n: Δ → Q_n, and for each r, when n is large, φ_n is injective on B_r and φ_n(gh) = φ_n(g)φ_n(h) for g,h ∈ B_r.

**The space.** Y_n = F_2^{Q_n}, the functions Q_n → F_2, and V_n = F_2[Y_n] with basis δ_y. So N_n = 2^{|Q_n|}, and N_n → ∞ because |Q_n| ≥ |φ_n(B_r)| = |B_r| → ∞.
- Q_n acts on Y_n by (q·y)(p) = y(q^{-1}p), and a_n acts by y ↦ y + 1_e.
- L_n is the group generated by these permutations; it is Z/2 ≀ Q_n.
- U_n(g) is the permutation matrix of g ∈ L_n.

This is the space of configurations seen from the base point. The models `E_n = 2^(Q_n) × Q_n` on main also record the base point. Their generated algebra commutes with the Q_n-translations of the base point, so they are not full matrix algebras.

**Partial group models.**
- Every ℓ ∈ L is uniquely c·δ, with δ ∈ Δ and c ∈ ⊕_Δ Z/2 a product of the flips a_h = h a h^{-1}. On Z it acts by (ℓx)(h) = x(δ^{-1}h) + c(h).
- Put ψ_n(c·δ) = (φ_n)_*c · φ_n(δ), where (φ_n)_*c = Σ_{h ∈ supp c} 1_{φ_n(h)}.
- For a fixed ball B ⊆ L and large n, ψ_n is injective on B and multiplicative on pairs from B. The product is (cδ)(c′δ′) = (c + δ·c′)δδ′, and pushforward commutes with shifts once φ_n is multiplicative on the supports involved.

**Diagonal models.**
- For y ∈ Y_n, x_y = y∘φ_n is a point of Z = 2^Δ, because every configuration is legal.
- Put D_n(f)δ_y = f(x_y)δ_y. So D_n is a unital ring homomorphism from LC(Z,F_2) to the diagonal matrices, exactly and for every n.
- For r = Σ_ℓ f_ℓ u_ℓ (unique finite sum) put Φ_n(r) = Σ_ℓ D_n(f_ℓ) U_n(ψ_n(ℓ)).

## 2. Lemmas

**Lemma 1 (partial homomorphism).** Fix r, r′ ∈ R. For all large n, Φ_n(r+r′) = Φ_n(r)+Φ_n(r′), Φ_n(rr′) = Φ_n(r)Φ_n(r′), and Φ_n(1) = I.

*Proof.*
- Additivity and Φ_n(1) = I are clear.
- For multiplicativity, use (f u_ℓ)(f′u_{ℓ′}) = f (f′∘ℓ^{-1}) u_{ℓℓ′}. It suffices, for large n, to have:
  - (a) D_n(ff′) = D_n(f)D_n(f′);
  - (b) ψ_n(ℓℓ′) = ψ_n(ℓ)ψ_n(ℓ′);
  - (c) U_n(ψ_nℓ) D_n(f′) U_n(ψ_nℓ)^{-1} = D_n(f′∘ℓ^{-1}).
- (a) holds exactly; (b) was shown above.
- (c) The left side sends δ_y to f′(x_{ψ_n(ℓ)^{-1}y}) δ_y, and the right side to f′(ℓ^{-1}x_y) δ_y. Now f′ depends only on coordinates in a finite set W′. So (c) follows from:

  (★) (ψ_n(ℓ)^{-1}·y)(φ_n(h)) = (ℓ^{-1}x_y)(h) for h in a fixed finite set and large n.

- Proof of (★) for the letters:
  - s ∈ S: (φ_n(s)^{-1}·y)(φ_n(h)) = y(φ_n(s)φ_n(h)) = y(φ_n(sh)) = x_y(sh) = (s^{-1}x_y)(h).
  - a: (y + 1_e)(φ_n(h)) = y(φ_n(h)) + [φ_n(h) = e] = x_y(h) + [h = e] = (a x_y)(h), since φ_n is injective on the set together with e.
  - Words in the letters follow by induction, using (b). ∎

**Lemma 2 (injectivity on fixed elements).** If r ≠ 0, then Φ_n(r) ≠ 0 for all large n.

*Proof.* Write r = Σ_{ℓ ∈ F} f_ℓ u_ℓ with F finite and f_{ℓ_0} ≠ 0.
1. Choose a cylinder [p_0] on which f_{ℓ_0}∘ℓ_0 = 1. This is possible because ℓ_0^{-1}{f_{ℓ_0} = 1} is a nonempty clopen set.
2. For each pair ℓ ≠ ℓ′ in F, with ℓ = cδ and ℓ′ = c′δ′, pick a witness coordinate:
   - if δ = δ′, then c ≠ c′, and ℓx and ℓ′x differ at every h ∈ supp(c + c′), for every x;
   - if δ ≠ δ′, pick h outside supp c ∪ supp c′ so that δ^{-1}h and δ′^{-1}h are distinct, avoid the window of p_0, and avoid the coordinates already used. This is possible because Δ is infinite. Prescribe x(δ^{-1}h) = 0 and x(δ′^{-1}h) = 1. Then (ℓx)(h) ≠ (ℓ′x)(h).
3. Let p extend p_0 by all these prescriptions, and let W_p be its window.
4. Take n so large that Lemma 1's conditions and (★) hold on a ball containing W_p, the witnesses, the supports and F. Choose y ∈ Y_n with x_y|_{W_p} = p; this is possible because φ_n is injective on W_p and all configurations are legal.
5. Then Φ_n(r)δ_y = Σ_{ℓ∈F} f_ℓ(x_{ψ_n(ℓ)y}) δ_{ψ_n(ℓ)y}.
   - By (★) applied to ℓ^{-1}, (ψ_n(ℓ)y)(φ_n(h)) = (ℓx_y)(h) at the finitely many coordinates involved. So the vectors ψ_n(ℓ)y are pairwise distinct, and f_ℓ(x_{ψ_n(ℓ)y}) = f_ℓ(ℓx_y).
   - The coefficient of δ_{ψ_n(ℓ_0)y} is f_{ℓ_0}(ℓ_0 x_y) = 1, since x_y ∈ [p] ⊆ [p_0].
   - So Φ_n(r) ≠ 0. ∎

(The ultraproduct route also gives Lemma 2 for ω-almost all n, because R is simple. The direct argument gives all large n, so convergence holds along the whole sequence.)

**Lemma 3 (onto).** Let ρ_n: F → M_{N_n}(F_2) be the ring homomorphism with ρ_n(t_s) = U_n(φ_n(s)), ρ_n(t_s′) = U_n(φ_n(s))^{-1}, ρ_n(t_a) = U_n(a_n) and ρ_n(t_p) = D_n(p). Then ρ_n is onto. Moreover, for any fixed w ∈ F, ρ_n(w) = Φ_n(π(w)) for all large n.

*Proof.*
- **Permutations.** Products of the ρ_n(t_s^{(′)}) are the matrices U_n(q) for every q ∈ Q_n = ⟨φ_n(S)⟩.
- **Diagonal units.** D_n(p)δ_y = y(e)δ_y, so U_n(q)D_n(p)U_n(q)^{-1}δ_y = (q^{-1}·y)(e)δ_y = y(q)δ_y. The operators y ↦ y(q), for q ∈ Q_n, separate the points of Y_n. So products of these diagonal matrices and of I minus them give every diagonal matrix unit E_{y,y}.
- **Translations.** U_n(q)U_n(a_n)U_n(q)^{-1} is translation by 1_q. Products give translation T_c by every c ∈ Y_n.
- **All units.** E_{y,y′} = T_{y+y′}E_{y′,y′}. So the image is all of M_{N_n}(F_2).
- **Agreement.** Φ_n agrees with ρ_n∘… on the letters: Φ_n(u_s) = U_n(φ_n(s)), Φ_n(u_s^{-1}) = U_n(φ_n(s^{-1})) = U_n(φ_n(s))^{-1} for large n, Φ_n(u_a) = U_n(a_n), and Φ_n(p) = D_n(p). Lemma 1, applied to the finitely many monomials of w, gives ρ_n(w) = Φ_n(π(w)) for large n. ∎

## 3. Proofs of the theorems

**Proof of Theorem A.**
1. **Approximants.** ρ_n is onto, so e_ij(ρ_n(t)) generate EL_3(M_{N_n}(F_2)) = SL_{3N_n}(F_2). Transvections generate SL, and those inside one block are commutators of transvections between blocks. So H and each SL_{3N_n}(F_2) are marked quotients of Λ = EL_3(F), with compatible markings.
2. **Convergence.** Let w be a word in the marking of Λ. The entries of w − I_3 are elements of F of degree at most |w|. Then:
   - w is trivial in H iff π(entries) = 0;
   - by Lemmas 2 and 3, for large n this holds iff ρ_n(entries) = 0, i.e. iff w is trivial in SL_{3N_n}(F_2).

   Each radius involves finitely many words, so the marked groups converge.
3. **Expansion.** Λ has property (T): `elementary-group-property-t-over-free-algebras`, or EJZ, since F is finitely generated. A Kazhdan pair (Σ, ε) with Σ the marking bounds the spectral gap of every Cayley graph of a finite quotient with respect to the image of Σ from below by a constant depending only on ε and |Σ| (Margulis). Since N_n → ∞, these graphs form an expander family (compare Kassabov 2007). ∎

**Proof of Theorem B.**
- **(i) ⇒ (ii).**
  - If Γ is finite, replace it by Γ × Z, which is LEF, infinite and finitely generated.
  - By `rf-groups-lie-in-derived-subgroups-of-rf-groups` (LEF part, Ore 1951), Γ ≤ [Δ,Δ] for some finitely generated infinite LEF group Δ.
  - Then [Δ,Δ] ≤ [L,L], and γ ↦ diag(u_γ,1,1) embeds [L,L] in H = EL_3(R) (item 4 of the lamplighter node; Whitehead's lemma).
  - Theorem A gives the marked limit and expansion properties of H.
- **(ii) ⇒ (i).**
  - A marked limit of finite groups is LEF: for each radius, the ball of H injects into an approximant preserving products that stay in the ball.
  - A finitely generated subgroup of a LEF group is LEF. ∎

## 4. Model tests

- **Δ = Z, Q_n = Z/n.** Here Y_n = 2^{Z/n} and the approximants are SL_{3·2^n}(F_2) for the lamplighter host EL_3(LC(2^Z,F_2)⋊(Z/2≀Z)). The algebra generated by the cyclic shift, the flip at 0 and the evaluation at 0 on F_2[2^{Z/n}] is M_{2^n}(F_2), as in Lemma 3.
- **Main's models E_n = 2^{Q_n}×Q_n.**
  - Right translation (c,q) ↦ (c∘R_g, qg) commutes with the letters, so the generated algebra lies in a proper commutant. This is why the view models are needed for finite simple approximants.
  - The view models are the quotient of E_n by that commuting action.
- **Non-LEF Δ.** There are no Q_n, so nothing is constructed.
- **The expected failure.** If Δ is finite, 2^Δ is finite, the action is not minimal and R is not simple. Lemma 2 then fails, as it should (Δ infinite is used in step 2).

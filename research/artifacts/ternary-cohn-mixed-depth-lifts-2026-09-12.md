# Mixed-depth lifts of the Leavitt pair in the ternary anti-central summand

Lane `w3-corner-cohn-a`, 2026-09-12. Supports the claims
`natural-leavitt-pair-lifts-have-partial-symmetry-defect` (Section 2) and, in a later section,
`no-equivariant-lattice-lift-of-cylinder-idempotents`. Target they bear on:
`ternary-anti-central-summand-has-cohn-family`.

## 0. Setup

`G = L_(F_3)(1,2)^x`, `z = -1`, `eps_- = 2(1 - [z])`, `S_- = eps_- F_3[G]`. By
`signed-thompson-algebra-is-odd-measure-crossed-product`, the subalgebra generated by the signed
Thompson group `E x| V` is

```text
B = C(M_-, F_3) x| V  ⊆  S_-,
```

where `X = {0,1}^N`, `M_-` is the space of finitely additive `F_2`-valued measures `mu` on the clopen
algebra of `X` with `mu(X) = 1`, and `V` acts by push-forward, `(g mu)(C) = mu(g^-1 C)`.

Conventions used throughout.
- `[g] f [g]^-1 = g.f` with `(g.f)(mu) = f(g^-1 mu)`. So `([g] f)([k] f') = [gk] (k^-1 . f) f'`.
- For a clopen `C`, `U_C = { mu : mu(C) = 1 }` and `P_C = 1_(U_C)`. This is the honest lift
  `2(1 - [1 + p_C])` of the cylinder idempotent `p_C`, and `g U_C = U_(gC)`.
- `U_C ⊔ U_(X \ C) = M_-`, because `mu(C) + mu(X \ C) = 1`.
- Evaluation `pi : S_- -> R` sends `[g] -> g` and `P_C -> p_C`. On `B` it is evaluation at Dirac
  measures followed by the germ quotient. A set containing no Dirac measure has indicator in `ker pi`.

## 1. The natural mixed-depth lift of `(s_0, t_0)`

Let `g_0, g_1 in V` extend `s_0` on the two first-letter cylinders:

```text
g_0(0x) = 00x,     g_1(1x) = 01x     for all x.
```

Any such units work; the prefix codes on the complements are free (this is the mixed-depth freedom).
Then `g_0(1) = 01 ∪ 1` and `g_1(0) = 00 ∪ 1` as clopens. In `R`, `s_0 = g_0 p_0 + g_1 p_1` and
`t_0 = g_0^-1 p_00 + g_1^-1 p_01`. Put

```text
sigma = [g_0] P_0 + [g_1] P_1,        tau = [g_0^-1] P_00 + [g_1^-1] P_01,
```

so `pi(sigma) = s_0` and `pi(tau) = t_0`. Define

```text
A = g_1^-1(00) ⊆ 0,     B' = g_0^-1(01) ⊆ 1,     h = g_0^-1 g_1,
W_1 = U_A ∩ U_1,        W_2 = U_0 ∩ U_(B'),       F = 1_(W_1) + 1_(W_2),
D = [h] 1_(W_1) + [h^-1] 1_(W_2).
```

## 2. The defect is a partial symmetry

**Lemma 2.1.** `tau sigma = 1 + D`, and:
1. `W_1 ∩ W_2 = ∅`, so `F` is an idempotent. Both `W_i` are nonempty and contain no Dirac measure,
   so `F, D in ker pi`.
2. `h W_1 = W_2`, `h^-1 W_1 ∩ W_1 = ∅` and `h W_2 ∩ W_2 = ∅`.
3. `D^2 = F` and `DF = FD = D`.
4. `e = 2(F + D)` and `e' = 2(F - D)` are orthogonal idempotents with `e + e' = F`, and `e' != 0`.
5. With `c = (1 - F) + 2e` (so `c^2 = (1 - F) + e`; `c` kills `e'` and is not invertible), the
   corrected lift `tau'' = c tau` satisfies `pi(tau'') = t_0` and

```text
tau'' sigma = 1 - e'.
```

*Proof.*
- *Products.* By the product rule, `tau sigma = sum_(a,b) [g_a^-1 g_b] (g_b^-1 . P_(C_a)) P_b` with
  `C_0 = 00`, `C_1 = 01`.
  - `a = b = 0`: `g_0^-1(00) = 0`, so the term is `P_0 P_0 = P_0`.
  - `a = b = 1`: `g_1^-1(01) = 1`, giving `P_1`. So the identity grade is `P_0 + P_1 = 1`.
  - `(a,b) = (0,1)`: `[h] 1_(U_A) P_1 = [h] 1_(W_1)`. `(a,b) = (1,0)`: `[h^-1] 1_(U_(B')) P_0 = [h^-1] 1_(W_2)`.
- *Item 1.* `W_1 ⊆ U_1`, `W_2 ⊆ U_0` and `U_0 ∩ U_1 = ∅`. A Dirac measure in `W_1` would lie in
  `A ⊆ 0` and in `1`. `W_1` is nonempty: `g_1^-1(1) = 0 \ A` is nonempty, and the atoms
  `(A, 0 \ A, 1)` carry the odd function `(1,1,1)`. Symmetrically for `W_2`.
- *Item 2.* `h(A) = g_0^-1(00) = 0` and `h(1) = g_0^-1(g_1(1)) = g_0^-1(01) = B'`, so `h W_1 = W_2`.
  Next `h^-1(1) = g_1^-1(g_0(1)) = g_1^-1(01 ∪ 1) = 1 ∪ (0 \ A)`. If `mu` lies in `h^-1 W_1 ∩ W_1`,
  then `mu(1) = 1` and `mu(1 ∪ (0\A)) = 1`, so `mu(0 \ A) = 0`. Since `mu(A) = 1`, `mu(0) = 1`, and
  `mu(X) = mu(0) + mu(1) = 0`, a contradiction. The same computation with
  `h(0) = g_0^-1(00 ∪ 1) = 0 ∪ (1 \ B')` gives `h W_2 ∩ W_2 = ∅`.
- *Item 3.* Using the product rule and item 2:
  `([h]1_(W_1))^2 = [h^2] 1_(h^-1 W_1 ∩ W_1) = 0`, `([h^-1]1_(W_2))^2 = [h^-2] 1_(h W_2 ∩ W_2) = 0`,
  `[h]1_(W_1) [h^-1]1_(W_2) = 1_(h W_1 ∩ W_2) = 1_(W_2)`, and
  `[h^-1]1_(W_2) [h]1_(W_1) = 1_(h^-1 W_2 ∩ W_1) = 1_(W_1)`. So `D^2 = F`. `DF = D` is immediate.
  `FD = D` follows from `1_(W_2)[h]1_(W_1) = [h]1_(h^-1W_2 ∩ W_1) = [h]1_(W_1)`, the symmetric term,
  and the two vanishing terms `1_(W_1)[h]1_(W_1) = 0`, `1_(W_2)[h^-1]1_(W_2) = 0`.
- *Item 4.* `(F ± D)^2 = F ± 2D + F = 2(F ± D)` and `4 = 1`, so `e, e'` are idempotents.
  `(F + D)(F - D) = F - D + D - F = 0`, and `e + e' = 4F = F`. The identity grade of `e'` is
  `2F != 0`.
- *Item 5.* `tau sigma = (1 - F) + (F + D) = (1 - F) + 2e`, since `2e = 4(F + D) = F + D`.
  Since `(1 - F)` and `e` are orthogonal idempotents, `c tau sigma = c^2 = (1 - F) + 4e = (1 - F) + e = 1 - e'`.
  `pi(c) = 1` because `F, D in ker pi`. QED

**Remark 2.2 (what the mixed-depth freedom buys).** The choice of `g_0, g_1` changes `A`, `B'`, `h`
and the sets `W_i`, never the type of the defect. For every choice, the lift of the binary pair is
left invertible exactly modulo one nonzero kernel idempotent: `tau'' sigma = 1 - e'`. So `sigma` is
left invertible in `S_-` iff `e' in S_- sigma`. Its Haar trace mod 3 is `Tr(e') = 2 lambda(F) = 2 * 1/2 = 1`
(each `W_i` has Haar measure `1/4`), so the mod-3 trace does not forbid removing it.

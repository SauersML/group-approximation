## Setting

`R = L_(F_2)(1,2)`, generated by `s_0, s_1, t_0, t_1` with `t_i s_j = delta_ij` and
`s_0 t_0 + s_1 t_1 = 1`. `G = R^x`, `A = F_2[G]`, and `pi : A -> R`, `pi([g]) = g`, is the
evaluation map. It is onto (`leavitt-unit-group-algebra-surjects-onto-leavitt`). Put
`K = ker(pi)`. A *pair* means `alpha, beta` in `A` with `beta alpha = 1`. It is *strict* when
`alpha beta != 1`.

## Input from the literature

**(P)** Every nonzero finitely generated projective right `R`-module is isomorphic to `R_R`.

This is Bergman's computation of the monoid of isomorphism classes of finitely generated
projectives, `V(L_K(1,n)) = <x | x = n x>`, which for `n = 2` is `{0, x}`: G. M. Bergman,
*Coproducts and some universal ring constructions*, Trans. AMS 200 (1974), Theorem 6.1; in
graph form P. Ara, M. A. Moreno, E. Pardo, *Nonstable K-theory for graph algebras*, Algebr.
Represent. Theory 10 (2007), Theorem 3.5, for the graph with one vertex and two loops.

(P) is used exactly once, in Lemma 1, to produce the elements `z, w` below.

## Lemma 1. Every left-invertible non-unit of R is a unit times s_0

Let `x, y` in `R` with `y x = 1` and `x y != 1`. Then `x = u s_0` for some `u` in `G`.

*Proof.* `e = x y` is an idempotent, `R = eR (+) (1-e)R`, and `xR = eR` because
`xR = xyxR ⊆ xyR ⊆ xR`. The summand `P = (1-e)R` is nonzero since `e != 1`, and finitely
generated projective, so (P) gives an isomorphism `psi : R_R -> P`. Put `z = psi(1)`, which lies
in `P`. The endomorphism `r -> psi^-1((1-e) r)` of `R_R` is left multiplication by
`w = psi^-1(1-e)`, so:
* `w p = psi^-1(p)` for `p` in `P`;
* `w z = psi^-1(psi(1)) = 1`;
* `z w r = psi(psi^-1((1-e) r)) = (1-e) r`, so `z w = 1 - e`.

Two vanishing products:
* `y z = y (1-e) z = (y - yxy) z = 0`, since `z = (1-e) z`;
* `w x = psi^-1((1-e) x) = psi^-1(x - xyx) = 0`.

Put `u = x t_0 + z t_1` and `v = s_0 y + s_1 w`. Then
* `v u = s_0 (y x) t_0 + s_0 (y z) t_1 + s_1 (w x) t_0 + s_1 (w z) t_1 = s_0 t_0 + s_1 t_1 = 1`,
* `u v = x (t_0 s_0) y + x (t_0 s_1) w + z (t_1 s_0) y + z (t_1 s_1) w = xy + zw = e + (1-e) = 1`,
* `u s_0 = x (t_0 s_0) + z (t_1 s_0) = x`.

So `u` is in `G` and `x = u s_0`. QED

## Lemma 2. Left inverses of s_0 are fixed by one involution

If `y s_0 = 1` in `R`, then `y = t_0 + r t_1` with `r = y s_1`, and `v_r = 1 + s_0 r t_1` is an
involution in `G` with `v_r s_0 = s_0` and `y v_r = t_0`.

*Proof.*
* `y = y (s_0 t_0 + s_1 t_1) = t_0 + (y s_1) t_1`.
* `(s_0 r t_1)^2 = s_0 r (t_1 s_0) r t_1 = 0`, so `v_r^2 = 1` in characteristic two.
* `v_r s_0 = s_0 + s_0 r (t_1 s_0) = s_0`.
* `y v_r = t_0 + t_0 s_0 r t_1 + r t_1 + r (t_1 s_0) r t_1 = t_0 + r t_1 + r t_1 = t_0`. QED

## Theorem. Every pair is a group translate of a kernel-local pair or of a lift of (s_0, t_0)

Let `beta alpha = 1` in `A` and `x = pi(alpha)`.

**(i) `x` in `G`.** Then `pi(beta) = x^-1`. Put `alpha_1 = [x^-1] alpha` and
`beta_1 = beta [x]`:
* `pi(alpha_1) = pi(beta_1) = 1`, so `alpha_1, beta_1` lie in `1 + K`;
* `beta_1 alpha_1 = beta [x][x^-1] alpha = 1`;
* `alpha_1 beta_1 = [x^-1] (alpha beta) [x]`, so `alpha_1 beta_1 = 1` exactly when `alpha beta = 1`.

**(ii) `x` not in `G`.** Since `pi(beta) x = 1`, `x` is a left-invertible non-unit. By Lemma 1,
`x = u s_0` with `u` in `G`.
* Put `alpha_2 = [u^-1] alpha` and `beta_2 = beta [u]`. Then `pi(alpha_2) = s_0` and
  `beta_2 alpha_2 = 1`, so `pi(beta_2) s_0 = 1`.
* Lemma 2 gives `r` with `pi(beta_2) = t_0 + r t_1`. Put `alpha_3 = [v_r] alpha_2` and
  `beta_3 = beta_2 [v_r]`. Then `pi(alpha_3) = s_0`, `pi(beta_3) = t_0`, and
  `beta_3 alpha_3 = beta_2 [v_r^2] alpha_2 = 1`.
* `alpha_3 beta_3 != 1` automatically: otherwise `s_0` would be a unit of `R`
  (`leavitt-direct-finiteness-failure-from-left-invertible-lift`), and it is not.

The translations are by trivial units of `A`, so `alpha_3 beta_3` is conjugate to
`alpha beta` and strictness is preserved in both directions. QED

**Corollary.** `A` is not directly finite exactly when one of the following holds.
* **(i')** There are `k, l` in `K` with `(1+l)(1+k) = 1 != (1+k)(1+l)`, that is
  `l + k + lk = 0` and `kl != lk`. The defect idempotent `1 - (1+k)(1+l)` lies in `K`.
* **(ii')** There are lifts `alpha` of `s_0` and `beta` of `t_0` with `beta alpha = 1`.
  Strictness is then automatic, and the defect idempotent evaluates to `s_1 t_1 != 0`.

*Proof.* A strict pair falls into (i) or (ii), which produce (i') or (ii'). Conversely (i') is a
strict pair, and (ii') is one by the automatic strictness in (ii). QED

## What this changes

1. `left-invertible-lift-of-s0-in-leavitt-group-algebra` asks for a pair whose right factor
   evaluates to `s_0`. Pinning the value costs nothing among *visible* defects, those with
   `pi(1 - alpha beta) != 0`: every visible strict pair is a translate by trivial units of a
   lift of `(s_0, t_0)`. The only strict pairs that are not such translates are the invisible
   ones, and those are translates of pairs over `1`.
2. The left factor's value can be pinned too: `beta` may be taken to lift exactly `t_0`, not
   merely some left inverse `t_0 + r t_1`.
3. Every Kaplansky counterexample in `F_2[R^x]` is therefore of exactly two kinds: a
   characteristic-two lift of the Leavitt isometry, or a one-sided quasi-inverse pair inside the
   evaluation kernel. The second kind is the new open claim
   `leavitt-kernel-unitization-not-directly-finite`.

## Kernel-local case: first observations

For `k, l` in `K` with `(1+l)(1+k) = 1`, write `alpha = 1+k` and `beta = 1+l`.
* `eps(k) = eps(l) = 0` for the augmentation `eps`, since `eps(alpha) eps(beta) = 1`.
* By `subgroup-supported-one-sided-inverse-rigidity`, the supports of `alpha` and of `beta` each
  generate a subgroup whose group algebra is not directly finite.
* By `lifted-trace-detects-finite-subgroup-projectives`, the defect idempotent
  `d = 1 - alpha beta` is not a finite sum of finite-subgroup projectives. It also has zero
  class in `K_0(A)`, since `A = alpha beta A (+) dA ≅ A (+) dA`.
* **Kernel corners feed this case.** If `q` in `K` is an idempotent and `qAq` is not directly
  finite, with `b a = q != a b` in `qAq`, then `alpha = (1-q) + a` and `beta = (1-q) + b` satisfy
  `beta alpha = 1 != alpha beta`, and `alpha - 1 = a - q` lies in `K` because `a, b, q` do. So
  any non-directly-finite kernel corner gives case (i'). The kernel does contain nonzero
  idempotents (`leavitt-corner-kernel-not-jacobson-radical`,
  `leavitt-recursive-kernel-idempotents`).
* Units of the form `1 + n` with `n` in `K` nilpotent are two-sided units and never strict, so
  a witness needs non-nilpotent kernel parts in both factors.

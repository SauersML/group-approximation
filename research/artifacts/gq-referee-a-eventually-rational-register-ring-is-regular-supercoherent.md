# Referee report (gq-referee-a, proof-gap lens): the eventually-rational register ring B⁺

**Reviewed:** `eventually-rational-register-ring-is-regular-supercoherent` (lane gq-ring-fp-simple, bcdfabf89),
read on origin/main.

**Verdict.**
- **Part 1** (von Neumann regular): PASS. One sentence is false and must be corrected (§1).
- **The exact sequence:** PASS, for `B⁺` as defined, that is, all eventually rational `Q`-valued functions (§2).
- **Part 2** (supercoherence) is OPEN. §3 gives a literature lead that may close it. The same lead suggests that one
  remark in the node is wrong.

## 1. Part 1
- **The inverse.** On the tail, `f = P/Q` with `Q` nonzero.
  - If `P ≢ 0`, it has finitely many zeros, so `g = Q/P` is eventually rational. The finitely many exceptional
    states are allowed.
  - If `P ≡ 0`, `f` is eventually 0, and so is `g`.
  - Pointwise, `fgf = f`.

  So `B⁺` is commutative von Neumann regular: reduced, of Krull dimension 0, with every finitely generated ideal
  generated by an idempotent. It is coherent, and every finitely presented module is projective.
- **Correction.** "Every module has projective dimension 0" is **false**. That would make `B⁺` semisimple, but `B⁺`
  has infinitely many orthogonal idempotents.
  - Von Neumann regularity gives weak dimension 0 (every module is flat), and projectivity only for finitely
    presented modules.
  - ABC's "regular coherent" needs only finite projective dimension of finitely presented modules, which holds.
  - So the conclusion stands, but the sentence must be replaced.

## 2. The sequence `0 → ⊕_ℕ Q → B⁺ → Q(t) → 0`
- **The map is well defined.** Two rational functions that agree at infinitely many integers are equal, so the
  eventual rational function of `f` is determined by `f`.
- **Surjective.** For `r ∈ Q(t)`, set `f(N) = r(N)` off the finitely many poles.
- **Kernel.** It is the eventually-zero functions.

All of this holds because `B⁺` is the **full** ring of eventually rational `Q`-valued functions. If a consumer means
instead the subring generated by the registers, indicators and the resolvents `(N+c)^{-1}` only, then neither
regularity nor surjectivity is available: the inverse `1/(N−5)` is not produced. Make sure the consuming node (the
single-register completion) uses the full ring.

## 3. A literature lead for Part 2, and a likely error in "The obstacle"
- **The remark.** The node says there are von Neumann regular `A` with `A[t]` not coherent, for example "an infinite
  product of fields". I believe this is false.
- **One variable.** McCarthy, *The ring of polynomials over a von Neumann regular ring*, Proc. AMS 39 (1973): `R[X]`
  is semihereditary **iff** `R` is von Neumann regular. Semihereditary rings are coherent. I am recalling this from
  memory, so check it at the source.
- **Several variables.** S. Glaz, *Commutative Coherent Rings*, LNM 1371, §7.3, contains, as I recall, the statement
  that polynomial rings in finitely many variables over a von Neumann regular ring are coherent regular rings.
  - If that is right, every commutative von Neumann regular ring is regular supercoherent in ABC's sense.
  - With Part 1, Part 2 would follow.
- **Next step.** Ask `gq-lit-arxiv` or `gq-referee-b` to fetch and quote Glaz's statement verbatim. Until then, strike
  the "infinite product of fields can fail" sentence, or mark it as unverified.

## 19.2 Theorem A: re-derived

1. **The corner.** `Q = φ_n(P) ≠ 0`. `M_n(J_Q)` is the ideal generated by `Q`, and `Q` is full there. The corner
   `QM_n(B)Q` is unital AF, so it has a tracial state `t`.
2. **The pulled-back trace.** `ρ` extends `t` densely finitely to `M_n(J_Q)`, and `ρ^∞` is an l.s.c. trace on `M_n(B)`
   with finiteness ideal `M_n(J_Q)` (§0: `J` is hereditary, and sublevel sets are closed). So `σ_n = ρ^∞∘φ_n` is an
   l.s.c. trace, `σ_n = Tr ⊗ σ` with `σ(a) = σ_n(a ⊗ e_11)`, and `σ(P) = t(1) = 1`.
3. **Finiteness.**
   - `σ(a) < ∞` forces `φ(a) ∈ J_Q`, so `φ(I_σ) ⊆ J_Q`.
   - `m_σ` is a dense ideal of `I_σ`, so it contains `Ped(I_σ)` and every projection. So `σ^` is defined on `K_0(I_σ)`,
     and `σ^ = ρ^∘(φ|)_*`.
4. **Annihilation.** For `x ∈ ι_σ^{-1}(G)`, `ι_{J_Q}((φ|)_*x) = φ_*(ι_σx) = 0`. `K_1(B/J_Q) = 0` makes `ι_{J_Q}` injective,
   so `σ^(x) = 0`. Since `ker ι_σ ⊆ ι_σ^{-1}(G)`, the pairing with `G ∩ im ι_σ` is well defined.

**Wording note.** Theorem A is stated for any `A` and any AF `B`. The corner-trace extension of §0 is stated for
separable ideals. For separable `A`, replace `B` by a separable AF subalgebra containing `φ(A)`; its quotients are
still AF. Every use downstream is separable, so this affects only the stated generality.

## 19.3 Proposition B: re-derived

1. **The kernel.** By six-term exactness, `H = ker(K_0(K) → K_0(E))`. So
   `ι_P^{-1}(H) = ker(K_0(I_P) → K_0(E)) = ∂_{I_P}K_1(E/I_P)`.
2. **Singularity.** If `[e] = 0` in `K_0(E)`, then `e ⊕ 1_m ~ 0 ⊕ 1_m ≤ e ⊕ 1_m` in `M_{k+m}(Ẽ)`, and finiteness forces
   `e = 0`.
3. **The corner.**
   - `C_P = PM_n(I_P)P` is unital, exact and stably finite.
   - `K_0(C_P) ≅ K_0(I_P)` as ordered groups (full corner, Brown; `E` is separable).
   - Lemma A gives `t` with `t^(G_P) = 0`. Its proof tensors with `Q`, keeps singularity through Moutzouris Proposition
     2.6, and uses the torsion-free positive cone, Lemma 2.12 with `H_1 = H_2`, and (2.5).
4. **The trace.** `σ_P = ρ^∞`, finite exactly on `I_P` (`ρ` is finite on `Ped(M_n(I_P))`), with `σ_P(P) = 1` and
   `σ_P^ = t^` vanishing on `ι_P^{-1}(H)`.

## 19.4 Corollary C and the reading (3) → (3′)

- **Hypothesis (3) as landed** (`bk-relative-lemma-b`): "up to scaling `τ` is the only l.s.c. trace on `A` annihilating
  `G`".
- **"Annihilating" already has this meaning.** Hypothesis (1) asks `τ̂` to annihilate
  `G_I = G ∩ im(K_0(I) → K_0(A))`. That pairing is well defined only if `τ̂` vanishes on `ker ι_I = ∂K_1(A/I)`, which is
  residual (i) in the same node. So "annihilating `G`" means vanishing on `ι_σ^{-1}(G)`: (3′)'s "annihilates `G` on its
  finiteness ideal".
- **The literal (3) cannot hold.** Any trace that is `+∞` on every nonzero positive element annihilates vacuously and is
  not a positive multiple of `τ`. So some exclusion is forced, and (3′) excludes exactly the traces finite and nonzero
  nowhere.
- **Direction.** Uniqueness over the smaller class of (3′) is a weaker hypothesis than uniqueness over all annihilating
  traces. So Corollary C applies to relative Lemma B under every consistent reading of (3). (3′) does not require `τ`
  itself to be in the class, and the proof never uses that.
- **The proof.**
  - For positive `x ∈ M_n(A)`, `x_ij x_ij^* ≤ ‖x_jj‖ x_ii`, so a diagonal inside `I` puts all entries in `I`. Hence
    some `P_ii ∉ I`.
  - By (2) and `m_τ ⊆ I`, `(Tr ⊗ τ)(P) = ∞`.
  - Theorem A (case i) or Proposition B (case ii, with `A = K ⊴ E` separable, exact, stably finite and `G = ∂K_1(E/K)`)
    gives an annihilating `σ` with `σ(P) = 1`. It is finite and nonzero at `P`, so it is not `cτ`.
- **Model tests re-checked.**
  - In `C(S²) ⊕ C`, the vacuous annihilators on `0 ⊕ C` make (3′) fail.
  - In the Toeplitz algebra, `Tr^([e_0]) = 1` breaks Proposition B's conclusion, as it must: `T` is not stably finite.

## 19.5 Step 5 of the route: pushout gluing

- **As written.** "Push the extension out along `φ` into the hereditary subalgebra generated by `φ(R)` (quasidiagonal),
  passing to a separable subextension containing the image of `E`. The new extension has quotient `E/R` and zero
  boundary, so it is quasidiagonal by Brown--Dadarlat Theorem 3.4."
- **The mechanism is right.**
  - `φ` is nondegenerate into `J = her(φ(R))`, since `φ(e_λ)` is an approximate unit there. So it extends to
    `M(R) → M(J)`, and the pushed-out extension exists with boundary `(φ|_J)_*∘∂`.
  - The pushout receives `E` injectively when `φ` is injective.
  - Theorem 3.4 applies because `J` is QD and `E/R` is nuclear, QD and UCT.
- **Wording note, with no statement change.**
  - *The boundary.* Zero boundary needs `φ_*(H) = 0` in `K_0(J)`, not only in `K_0(D)`. For a general quasidiagonal `D`,
    `K_0(her φ(R)) → K_0(D)` need not be injective.
  - *How Brown--Dadarlat get it.* In the converse half of Proposition 4.6 (and in Lemma C, part 5), `D` is first embedded
    in `Π M_{n_i} + K(H)`, which has real rank zero and stable rank one. Only then is `J` formed there, and Lemma 4.5 makes
    `K_0(J)` inject.
  - *The separable subextension* must contain the countably many partial isometries that witness the killing, or the
    boundary may not vanish in the smaller ideal.
  - *Fix.* Step 5 should cite Lemma C of `bk-radical-projection-trace-step-2026-09-13.md` directly. Lemma C has exactly
    step 4's hypotheses: an injective map into a QD algebra killing the boundary.
- **Other steps of that route.**
  - Step 1 uses `stw07-separating-qd-quotients-force-quasidiagonality`.
  - Step 2 is two-out-of-three for `0 → R/J → E/J → E/R → 0`.
  - Step 3 is Proposition B with `K = R`.

# Unfolding chords into fold seeds: a b-length weighted floor for the Gamma_mal stage pair

Agent swarm-0917-w9-w9-fp-break, 2026-09-18. Scripts are in
`experiments/fpbs-chord-unfolding-2026-09-17/`.

## 0. Summary

Pair: `L = F(a, b)`, `K = <a, c>` with `c = b a b^{-2}`. This is every stage
pair `H_n ≤ H_{n+1}` of `Gamma_mal`, with `b = b_{n+1}`.

1. **Theorem B (§2).** Let `L` act freely, p.m.p., and let `Φ` be a graphing
   inside `R_L` with `R_K ∨ Φ = R_L`. Split each piece of `Φ` by its label
   `h ∈ L` (well defined, since the action is free), so that `Φ = ⊔ h|_{D_h}`.
   Then
   ```text
   Σ_h |h|_{K,b} μ(D_h)  ≥  σ_b(X) .
   ```
   Here `|h|_{K,b}` is the least `r` with
   `h ∈ K b^{±1} K b^{±1} ⋯ b^{±1} K`, using `r` letters `b^{±1}`.
2. **Corollary (§3).** On every free action weakly contained in Bernoulli,
   `σ_b ≥ 1/80` by `fpbs-weakly-bernoulli-fold-seeds-have-density-floor`.
   Therefore:
   - Every generating graphing whose labels have `|h|_{K,b} ≤ r` has mass
     `≥ 1/(80 r)`. This holds uniformly in:
     - the number of double cosets used;
     - the `K`-letters in the labels;
     - the word length of the labels.
   - A generating graphing of mass `ε` puts length-weighted mass `≥ 1/160`
     on labels with `|h|_{K,b} > 1/(160 ε)`.
   - For `Gamma_mal`: a stagewise scheme
     `E_{H_n} ∨ Φ_n = E_{H_{n+1}}` with `b_{n+1}`-lengths `≤ r_n` has mass
     `≥ Σ_n 1/(80 r_n)`. Summable mass forces `Σ 1/r_n < ∞`.
3. **Exactness checked (§4).** Theorem B uses the hard half of the fold
   theorem (Theorem 1.2 of `fpbs-fold-bootstrap-seeding-2026-09-17.md`). I
   re-derived its folding rules from the local structure of the Stallings
   core, and record it as `fpbs-mal-fold-closure-exactness`.
4. **Where unfolding dies (§5).** The unfolding is lossy by exactly the
   factor `|h|_{K,b}`. A chord gives one identification of cosets, while its
   `r` seeds give `r` of them. Rank counting cannot recover this, because a
   chord and a seed both have matroid rank `≤ 1`. A uniform floor therefore
   needs sparsity for the circuits made by chords and triangles, whose number
   of types grows with `r`.
5. **iid computation (§6).** In truncated Cayley balls, iid graphings that
   move mass from `b` to labels of `b`-length 2 or 3 do *worse* per unit of
   mass than `b` alone. A mix of four `b`-length-2 labels that generates with
   `K` is far worse still. The label `b^2` looks long but has `b`-length 1,
   since `b^2 = c^{-1} b a ∈ K b K`, and it performs like `b`. So longer
   labels could help only if they were highly correlated, which is
   consistent with the floor.

## 1. Definitions

- `L = F(a, b)` acts freely and p.m.p. on `(X, μ)`. `K = <a, c>`,
  `c = b a b^{-2}`. `R_K ⊆ R_L` are the orbit relations.
- A **graphing** in `R_L` is a countable family of partial p.m.p.
  isomorphisms `φ_j : D_j → φ_j(D_j)` with graph in `R_L`. Its **mass** is
  `Σ_j μ(D_j)`. Since the action is free, each `D_j` splits by the label
  `h ∈ L` with `φ_j(x) = h x`. Splitting does not change the mass, so we
  always assume `Φ = ⊔_j h_j|_{D_j}` with one label per piece. Labels may
  repeat across pieces.
- `R_K ∨ Φ` is the equivalence relation generated by `R_K` and the graph of
  `Φ`.
- For `A ⊆ X`, `cl(A)` is the 2-of-3 closure on the triples
  `T_w = (w, a w, b w)`, and `σ_b(X) = inf { μ(A) : cl(A) conull }`. This is
  exactly the definition in `fpbs-weakly-bernoulli-fold-seeds-have-density-floor`.
- **Double-coset `b`-length.** For `h ∈ L`, `|h|_{K,b}` is the least `r ≥ 0`
  such that
  ```text
  h = k_r b^{ε_r} k_{r-1} b^{ε_{r-1}} ⋯ k_1 b^{ε_1} k_0 ,   k_i ∈ K, ε_i = ±1 .
  ```
  It is finite, because `L = <K, b>`. Equivalently, it is the graph distance
  from `K` to `K h` in the graph on `K \ L` that joins `K g` and `K g'` iff
  `g' g^{-1} ∈ K b^{±1} K`. (This is not the Schreier graph of `b`.) It is
  `0` iff `h ∈ K`. It is subadditive, and
  `|h^{-1}|_{K,b} = |h|_{K,b}`.
- `relC_{≤ r}(R_L; R_K)` is the infimum of the masses of graphings `Φ` with
  `R_K ∨ Φ = R_L` and all labels of `b`-length `≤ r`.

## 2. Theorem B and its proof

**Theorem B.** Let `L` act freely and p.m.p. on `(X, μ)`, and let
`Φ = ⊔_j h_j|_{D_j}` be a graphing with `R_K ∨ Φ = R_L`. Then

```text
Σ_j |h_j|_{K,b} μ(D_j)  ≥  σ_b(X) .
```

In particular `relC_{≤ r}(R_L; R_K) ≥ σ_b(X) / r` for every `r ≥ 1`, and
`relC_{≤ 1}(R_L; R_K) = σ_b(X)`.

*Proof.* If the left side is infinite there is nothing to prove, so assume it
is finite.

*Step 1 (unfold one piece).* Fix a piece `h|_D` with `r = |h|_{K,b}`, and fix
a shortest expression `h = k_r b^{ε_r} ⋯ k_1 b^{ε_1} k_0`. For
`i = 1, …, r` put

```text
q_i = k_{i-1} b^{ε_{i-1}} ⋯ k_1 b^{ε_1} k_0      (so q_1 = k_0),
g_i = q_i          if ε_i = +1,
g_i = b^{-1} q_i   if ε_i = −1 .
```

For `x ∈ D` the path

```text
x → q_1 x → b^{ε_1} q_1 x → k_1 b^{ε_1} q_1 x = q_2 x → ⋯ → b^{ε_r} q_r x → k_r b^{ε_r} q_r x = h x
```

alternates `K`-moves (pairs in `R_K`) with the `b`-steps
`(q_i x, b^{ε_i} q_i x)`.
- If `ε_i = +1`, the step is `(y, b y)` with `y = q_i x = g_i x`.
- If `ε_i = −1`, the step is `(b y', y')` with `y' = b^{-1} q_i x = g_i x`.

Either way it lies in the graph of `b|_{g_i D}`, up to orientation. Put
`A(h, D) = g_1 D ∪ ⋯ ∪ g_r D`. Then `(x, h x) ∈ R_K ∨ b|_{A(h,D)}` for all
`x ∈ D`, and `μ(A(h, D)) ≤ r μ(D)`, because each `g_i` preserves `μ`. If
`r = 0` then `h ∈ K`, the piece lies in `R_K`, and `A(h, D) = ∅`.

*Step 2 (union).* Put `A = ⋃_j A(h_j, D_j)`. Then
`μ(A) ≤ Σ_j |h_j|_{K,b} μ(D_j)`, and by Step 1 every edge of `Φ` lies in
`R' := R_K ∨ b|_A`. So `R_L = R_K ∨ Φ ⊆ R' ⊆ R_L`, that is, `R' = R_L`.

*Step 3 (exactness).* Since `R' = R_L`, every `w` satisfies `w R' b w`. So
the set `D` of Theorem 1.2 in `fpbs-fold-bootstrap-seeding-2026-09-17.md`
is all of `X`. That theorem, for free actions, gives `D = cl(A)`, so `cl(A)`
is conull. (It is applied in each orbit, and the orbits are countable, so
null sets cause no trouble.) Hence `μ(A) ≥ σ_b(X)`, which combined with
Step 2 is the claim.

*The particular cases.* If all labels have `b`-length `≤ r`, the left side is
at most `r · mass(Φ)`. For `r = 1`, the graphing `b|_A` with `cl(A)` conull
generates by Lemma 1.1 of the fold artifact, and has mass `μ(A)`. So
`relC_{≤ 1} ≤ σ_b`. ∎

**Remark (what is used).**
- Freeness is used twice: to label the pieces, and in Theorem 1.2.
- p.m.p. is used only for `μ(g D) = μ(D)`.
- Nothing about the action beyond `σ_b(X)` enters, so Theorem B is a pure
  transfer from one double coset to all double cosets, at the price of the
  weight `|h|_{K,b}`.

## 3. Corollaries

Below, `X` is a free p.m.p. action of `L` that is weakly contained in a
Bernoulli shift of `L`. By `fpbs-weakly-bernoulli-fold-seeds-have-density-floor`
(ESTABLISHED), `σ_b(X) ≥ 1/80`.

**Corollary 3.1 (bounded length).** Every graphing `Φ` with
`R_K ∨ Φ = R_L` and all labels of `b`-length `≤ r` has mass `≥ 1/(80 r)`.
Nothing else is bounded here: not the number of labels or double cosets,
not the `K`-letters, and not the word length of the labels.

**Corollary 3.2 (small mass needs long labels).** Let `Φ` generate
(`R_K ∨ Φ = R_L`) with mass `ε`, and let `T ≥ 0`. Then

```text
Σ_{ j : |h_j|_{K,b} > T }  |h_j|_{K,b} μ(D_j)  ≥  1/80 − T ε .
```

With `T = 1/(160 ε)`, labels of `b`-length `> 1/(160 ε)` carry weighted mass
`≥ 1/160`.

*Proof.* The labels with `|h_j| ≤ T` contribute at most `T ε` to the sum in
Theorem B. ∎

**Corollary 3.3 (Gamma_mal).** Let `β` be the Bernoulli shift of
`Gamma_mal = <a, b_1, b_2, … | b_n = b_{n+1} a b_{n+1}^{-2}>`, or any free
action of `Gamma_mal` weakly contained in it. Here `H_n = <a, b_n>`.
For each `n`, the pair `H_n ≤ H_{n+1}` is `K ≤ L` with `b = b_{n+1}`. The
restriction to `H_{n+1}` is free and weakly contained in a Bernoulli shift
of `H_{n+1}`, as stated in the w8 claim. Therefore:

- (a) *Single stage.* Every graphing `Φ` with
  `E_{H_1} ∨ Φ = E_{H_2}` (so its labels lie in `H_2`) satisfies
  `Σ |h|_{H_1, b_2} μ(D_h) ≥ 1/80`. So `relC(E_{H_2}; E_{H_1}) = 0` would
  need graphings whose average `b_2`-length tends to infinity, and
  Corollary 3.2 quantifies how fast.
- (b) *Stagewise schemes.* If `E_{H_n} ∨ Φ_n = E_{H_{n+1}}` for all `n`, and
  the labels of `Φ_n` have `b_{n+1}`-length `≤ r_n`, then
  `Σ_n mass(Φ_n) ≥ Σ_n 1/(80 r_n)`. A stagewise witness of `C(β) = 2` needs
  `Σ 1/r_n < ∞`. So all schemes with `r_n = O(n log n)` die, including
  bounded `r_n`.
- (c) *Relation to the target.* `fpbs-mal-bernoulli-single-stage-floor`
  asks for `relC(E_β; E_{H_1}) > 0`. If `relC(E_{H_2}; E_{H_1}) = 0`, then
  by shift stationarity every stage has relative cost `0`, and telescoping
  with masses `ε 2^{-n}` refutes the target. So the target implies the
  single-stage floor `relC(E_{H_2}; E_{H_1}) > 0`. Theorem B decides
  neither. It confines every counterexample to graphings with
  unbounded double-coset `b`-length (per stage), or to non-stagewise
  graphings with labels deep in `Gamma_mal` (§5).

## 4. Independent check of Theorem 1.2 (exactness)

Theorem B needs the hard half of the fold theorem, which so far lives only
inside an artifact. I re-derived it, and it is recorded as the claim
`fpbs-mal-fold-closure-exactness`. Notation is as in §1 of the fold
artifact: the right Cayley tree `T'`, left cosets `zK`, and the core `Γ_K`
with edges
`a : 0 → 0`, `b : 0 → v_1`, `a : v_1 → v_2`, `b : v_1 → v_2`.

**4.1 Vertex types.** The hull of `K` is the set of reduced words readable
from `0` in `Γ_K`.
- Words ending at `0` are exactly the elements of `K`.
- Words ending at `v_1` are exactly `K b`. The only edge into `v_1` is
  `b` from `0`, and paths returning from `v_2` end with `a^{-1}` or `b^{-1}`,
  e.g. `b a b^{-1} = c b`.
- Words ending at `v_2` are exactly `K b^2 = K b a`, because
  `b a = c b^2`.

So a vertex `y` of `T'` lies in `hull(zK) = z · hull(K)` with type `t` iff
`zK = c_t(y)`, where `c_0 = yK`, `c_1 = y b^{-1} K`, `c_2 = y b^{-2} K`.
These three cosets are distinct, because `b, b^2, b^{-1} ∉ K`. So `y` lies
in exactly three hulls, one of each type.

**4.2 Local stars.** Read off from `Γ_K`, with `→` meaning out-edges:

| type | out-`a` | out-`b` | in-`a` | in-`b` |
|---|---|---|---|---|
| 0 | to type 0 | to type 1 | from type 0 | none |
| 1 | to type 2 | to type 2 | none | from type 0 |
| 2 | none | none | from type 1 | from type 1 |

**4.3 Folding rules.** Two copies identified at `y` have their common
labelled edges identified. Reading common columns of the table:
- `(0,1)`: out-`a` gives `(0,2)` at `y a`; out-`b` gives `(1,2)` at `y b`.
  There is no common in-edge.
- `(0,2)`: in-`a` gives `(0,1)` at `y a^{-1}`. Nothing else is common.
- `(1,2)`: in-`b` gives `(0,1)` at `y b^{-1}`. Nothing else is common.

This matches the fold artifact exactly. So, writing `d(y)` for `(0,1)` at
`y`, the relation `(0,2)` at `y` is equivalent to `d(y a^{-1})`, and `(1,2)`
at `y` is equivalent to `d(y b^{-1})`. Since a partition of three copies is
determined by its pairs, consistency (transitivity) at `y` is exactly the
2-of-3 rule on `{ y, y a^{-1}, y b^{-1} }`. After `g ↦ z = g^{-1}`, this is
the triple `T_w = (w, a w, b w)`.

**4.4 Closing.** The closing argument in the fold artifact is standard.
1. Identify copies at each `y` by the partition that the 2-of-3 closure `S`
   of the seeds prescribes.
2. By 4.3 this identification is closed under every folding rule, and it is
   consistent at every `y`. So the quotient `W` is folded, i.e. it immerses
   into `T'`.
3. Every prescribed identification joins two copies whose cosets lie in one
   `R'`-class. This is Lemma 1.1 (`cl(A) ⊆ D`) together with the
   equivalences of 4.3. So `W` has the same components as `W_0`, namely the
   `R'`-classes.
4. A connected graph that immerses into a tree embeds. So two copies at the
   same `y` in one component of `W` are already identified.

Hence cosets at `y` in one `R'`-class are identified by `S`, i.e.
`D ⊆ cl(A)`. The reverse inclusion is Lemma 1.1.

**4.5 Numerics.** `experiments/fpbs-fold-bootstrap-2026-09-17/certify.py`
compares `D` with `cl(A)` for 30 random seed sets and finds them equal every
time (`certify_out.txt`).

## 5. Where unfolding dies, and what survives

**5.1 The loss is exactly `|h|_{K,b}`.** In one orbit, work with the
`R_K`-classes as vertices. A chord `h|_D` at `x` adds one edge between the
classes of `x` and `h x`, so it has rank `≤ 1` in the graphic matroid on
classes. Its unfolding adds `r` seed edges along a path of classes, which
have rank `r`. Only `μ(A)` is bounded below, and
`μ(A) ≤ Σ r_j μ(D_j)`, with equality when the translates `g_i D_j` are
disjoint. So Theorem B loses nothing if the unfolded seeds of different
chords are disjoint, and loses everything if they can be shared.

**5.2 Rank counting cannot close the gap.** A uniform bound
`mass(Φ) ≥ c` would follow from `μ(A) ≤ C · mass(Φ)` for *some* choice of
unfoldings. That requires the seed paths of different chords to overlap on
a `(1 − 1/C)`-fraction of their length, on average. Neither the matroid rank
(chord and seed both `≤ 1`) nor the fold closure sees this. It is a property
of the circuits formed by chords and fold triangles, and the number of
circuit types grows with `r`.

**5.3 Direct counting of chords dies at once.** In the random-permutation
models of the w8 proof, a seed is a point, so there are `C(N, αN)` seed sets.
A chord is a pair of points in one `L`-orbit. Already for `r = 1` the
`K`-orbits are giant, so the entropy of `εN` chords is about `εN log N`,
which beats every `e^{-cN}` probability bound (heuristic; not used
anywhere). Theorem B avoids this by
converting chords to points before counting. That is why the w8 constant
transfers with only the length weight.

**5.4 What survives.**
- (S1) Per stage, graphings whose average `b`-length is at least
  `1/(80 ε)` at mass `ε` (Corollary 3.2), with heavily shared unfoldings.
- (S2) Non-stagewise graphings of `E_β` over `H_1` whose labels lie deep in
  `Gamma_mal`. For a label `h ∈ H_M` and a graphing that generates `E_β` over
  `H_1`, Theorem B at the pair `(H_{M-1}, H_M)` would need
  `E_{H_{M-1}} ⊆ E_{H_1} ∨ Φ_{≤ M}`, which nothing provides.
- (S3) Actions not weakly contained in Bernoulli. There `σ_b` can be `0`,
  e.g. `β × Ẑ_χ` in `fpbs-mal-odometer-product-actions-have-cost-two`.

**5.5 Next decomposition (each part can fail on its own).**
- (P1) *Geodesic bundling.* For every generating `Φ` over `K` there are
  unfoldings with `μ(A) ≤ C · mass(Φ)`, with `C` absolute. With Theorem B's
  Steps 2–3 this gives `relC(R_L; R_K) ≥ 1/(80 C)` on the Bernoulli class,
  hence `fpbs-mal-bernoulli-single-stage-floor`. It fails if some
  factor-of-iid chord graphing has unfoldings that must be nearly disjoint.
- (P2) *Refutation side.* A factor-of-iid graphing of the Bernoulli shift of
  `L` with labels of `b`-length about `1/ε` and mass `ε`, whose unfolded
  seeds are shared so that `μ(A) = O(1)`. By Theorem B, any witness of
  `relC(E_{H_2}; E_{H_1}) = 0` has exactly this form.
- (P3) *Deep labels (S2).* Show that a graphing generating `E_β` over `H_1`
  can be pushed into stagewise form with at most a constant-factor loss in
  length-weighted mass. It fails if deep labels save more than a constant
  factor.

*Reading.*
- At equal mass, moving mass from `b` to labels of `b`-length 2 or 3 lowers
  `D_M`.
- The pure length-2 generating mix is far below `b` alone.
- `b^2` (`b`-length 1) tracks `b`.

This is what Theorem B predicts for uncorrelated chords, whose unfoldings
share few seeds. It does not test correlated (factor-of-iid) chords, which
is exactly the open case (P2).

*Caveats.* These are truncated balls. The boundary lowers `D_M`, which is
why the `b` column crosses well above the infinite-volume threshold `5/32`.
The inner sample has only 161 points and the outcomes are strongly
correlated, so single entries can be off by about `0.1`. Only the ordering
across schemes is meaningful.

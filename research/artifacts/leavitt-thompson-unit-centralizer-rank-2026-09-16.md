# Thompson units of the binary Leavitt algebra have finite centralizer rank

Swarm lane `leavitt-unit-centralizers-have-finite-rank`, 2026-09-16. The proof is self-contained: it uses
only the defining relations of `R = L_(F_2)(1,2)` and elementary symbolic dynamics on `{0,1}^ω`. No
literature result is used in any proof step.

## 0. Statements

Let `R = L_(F_2)(1,2)`, generated by `s_0, s_1, t_0, t_1` with `t_i s_j = δ_(ij)` and `s_0 t_0 + s_1 t_1 = 1`,
and let `Q = R^x`. For `u ∈ Q` of infinite order put `S = F_2[u] − {0}` and
`rho(u) = dim_(F_2(u)) S^(-1) C_R(u)`, the centralizer rank of claim `leavitt-unit-centralizers-have-finite-rank`.

An element `g` of Thompson's group `V` is given by complete prefix codes `{β_1, …, β_n}` and
`{α_1, …, α_n}` with `g(β_i z) = α_i z`. Its **Thompson unit** is `u_g = Σ_i s_(α_i) t_(β_i)`. Lemma 1.4 shows
that `u_g` depends only on `g`, and that `g -> u_g` is an injective group homomorphism `V -> Q`.

**Theorem A.** Let `g ∈ V` have infinite order and `w ∈ Q`. Then
`1 <= rho(w u_g w^(-1)) <= min(N(g), N(g^(-1))) < ∞`, where
`N(g) = |P_a(g)| · Σ_O d_O`. Here `P_a(g)` is the finite set of attracting periodic points of `g`, the sum
runs over the `g`-orbits `O ⊆ P_a(g)`, and `d_O >= 1` is the length gained by one period along `O`
(Section 2).

**Theorem B (V0 and V0+).** Let `g ∈ V` have infinite order. Then `g` has a periodic point `p`,
`g^k p = p`, whose local prefix replacement `u w -> v w` of `g^k` around `p` has `|u| != |v|`. The set of all
such points is finite and meets both signs of `|v| − |u|`.

Theorem B is claim `infinite-order-elements-of-v-have-hyperbolic-periodic-points`, together with the
finiteness statement (V0+) of `research/artifacts/zp-pl-interval-subgroup-obstructions-2026-09-13-part3.md`.
It is Corollary 2.8 below. Theorem A is Section 3. Section 4 lists consequences, Section 5 says where the
method stops, Section 6 reports computations, and Section 7 covers literature.

**Notation.**
- `X = {0,1}^ω` with the product topology, and `[w] = wX` is the cylinder of a finite word `w`.
- For `α = a_1 … a_n`, `s_α = s_(a_1) ⋯ s_(a_n)`. For `β = b_1 … b_m`, `t_β = t_(b_m) ⋯ t_(b_1)`, so that
  `t_β s_β = 1`.
- **Products.** `t_β s_γ = s_(γ')` if `γ = βγ'`, `t_β s_γ = t_(β')` if `β = γβ'`, and `t_β s_γ = 0`
  otherwise. Also `t_(β') t_γ = t_(γβ')`.
- So `R` is spanned by the monomials `s_α t_β`.
- **Padding.** `s_α t_β = s_α (s_0 t_0 + s_1 t_1) t_β = s_(α0) t_(β0) + s_(α1) t_(β1)`.

## 1. The groupoid model

**Lemma 1.1.** If `ρ, ρ'` are words with `ρ z = ρ' z` for all `z ∈ X`, then `ρ = ρ'`.

*Proof.* Say `|ρ| <= |ρ'|`. The prefix of length `|ρ|` of `ρ z = ρ' z` is `ρ`, so `ρ' = ρ θ` for a word `θ`. If `θ` were nonempty, then
`z = θ z` for all `z`, which fails when the first letter of `z` differs from that of `θ`. So `θ` is empty. ∎

**The groupoid.**
- `G = {(x, k, y) ∈ X × Z × X : σ^a x = σ^b y and k = a − b for some a, b >= 0}`, where `σ` is the shift.
- Multiplication is `(x, k, y)(y, l, z) = (x, k + l, z)`, and the inverse is `(x, k, y)^(-1) = (y, −k, x)`.
- For subsets `U, W ⊆ G`, `U W` is the set of all products `γ_1 γ_2` with `γ_1 ∈ U` and `γ_2 ∈ W`.
- `π_1(x, k, y) = x` and `π_2(x, k, y) = y`.
- A subset `U` is a **bisection** if `π_1` and `π_2` are both injective on `U`.
- `Z(α, β) = {(α z, |α| − |β|, β z) : z ∈ X}` is a bisection, since `z` is recovered from either endpoint.
- We give `X × Z × X` the product topology, with `Z` discrete. Each `Z(α, β)` is the continuous image of
  the compact space `X`, so it is compact and hence closed.

**Lemma 1.2 (product rule).** `Z(α, β) Z(γ, δ)` equals `Z(αγ', δ)` if `γ = βγ'`, equals `Z(α, δβ')` if
`β = γβ'`, and is empty if `β, γ` are incomparable.

*Proof.* A product `(αz, |α| − |β|, βz)(γw, |γ| − |δ|, δw)` needs `βz = γw`.
- If `γ = βγ'`, this means `z = γ' w`, and the product is `(αγ' w, |αγ'| − |δ|, δ w)` with `w` free.
- If `β = γβ'`, this means `w = β' z`, and the product is `(α z, |α| − |δβ'|, δβ' z)` with `z` free.
- If `β, γ` are incomparable, then `βz != γw` always. ∎

**The algebra `A`.**
- Let `A` be the `F_2`-span of the functions `1_(Z(α, β)) : G -> F_2`.
- Convolution is `(f * h)(γ) = Σ_(γ = γ_1 γ_2) f(γ_1) h(γ_2)`.
- For bisections `U, W`, a factorization `γ = γ_1 γ_2` with `γ_2 ∈ W` is determined by `π_2(γ)`, because
  `π_2(γ_2) = π_2(γ)`. So the sum defining `1_U * 1_W` has at most one nonzero term, and
  `1_U * 1_W = 1_(UW)`.
- Each element of `A` is a finite sum of such indicators, so all sums are finite and `*` is bilinear.
- By Lemma 1.2 a product of two sets `Z(α, β)` is again such a set or empty. So on indicators
  `(1_U * 1_V) * 1_W = 1_((UV)W) = 1_(U(VW)) = 1_U * (1_V * 1_W)`, and associativity follows by bilinearity.
- The unit is `1_(Z(∅, ∅))`, the indicator of the unit space `{(x, 0, x)}`.

**Lemma 1.3.** `φ(s_i) = 1_(Z(i, ∅))` and `φ(t_i) = 1_(Z(∅, i))` define a unital injective homomorphism
`φ : R -> A` with `φ(s_α t_β) = 1_(Z(α, β))`.

*Proof.*
- **Relations.** By Lemma 1.2, `φ(t_i) φ(s_j) = 1_(Z(∅, i) Z(j, ∅))`, which is `1_(Z(∅, ∅))` if `i = j` and
  `0` otherwise. Also `Z(0, 0) ⊔ Z(1, 1) = Z(∅, ∅)`, so `φ(s_0 t_0) + φ(s_1 t_1) = 1_(Z(∅, ∅))`. So `φ`
  extends to a unital homomorphism, and Lemma 1.2 gives `φ(s_α t_β) = 1_(Z(α, β))` by induction.
- **Injectivity.** Let `r ∈ R`.
  - Write `r` as a sum of monomials `s_α t_β`. Pad every term to a common `|β| = M`.
  - Cancel equal pairs mod 2, leaving `r = Σ_(i ∈ I) s_(α_i) t_(β_i)` with distinct pairs and `|β_i| = M`.
  - If `(α_i z, |α_i| − M, β_i z) = (α_j z', |α_j| − M, β_j z')`, then `|α_i| = |α_j|`, `β_i z = β_j z'` with
    `|β_i| = |β_j|` gives `β_i = β_j` and `z = z'`, and then `α_i = α_j`. So the `Z(α_i, β_i)` are pairwise
    disjoint.
  - Hence `φ(r) = 1_(W_r)` with `W_r = ⊔_(i ∈ I) Z(α_i, β_i)`. This is nonzero unless `I = ∅`, that is,
    unless `r = 0`. ∎

**Support.** For `r ∈ R`, `W_r = supp φ(r)`.
- It is a finite disjoint union of sets `Z(α, β)`, so it is compact and closed in `X × Z × X`.
- `|k|` is bounded on `W_r`.
- `π_1(W_r)` is a finite union of cylinders, so it is compact.
- `W_(r + r') = W_r Δ W_(r')`.

**Lemma 1.4 (Thompson units).** Let `g ∈ V` with codes as in Section 0, and put
`B_g = ⊔_i Z(α_i, β_i) = {(g y, c(y), y) : y ∈ X}`, with `c(y) = |α_i| − |β_i|` for `y ∈ [β_i]`.
1. `φ(u_g) = 1_(B_g)`.
2. `c` depends only on `g`, so `u_g` depends only on `g`.
3. `B_g B_h = B_(gh)`, with the cocycle identity `c_(gh)(z) = c_g(h z) + c_h(z)`, so `u_g u_h = u_(gh)`.
4. `g -> u_g` is injective, and `u_g` has infinite order iff `g` does.

With `c_n(x) = Σ_(0 <= i < n) c(g^i x)` we get `B_(g^n) = {(g^n y, c_n(y), y)}`, and the cocycle of `g^(-1)` is
`y -> −c(g^(-1) y)`.

*Proof.*
- **Item 1.** The sets `Z(α_i, β_i)` have the pairwise disjoint source sets `[β_i]`, so they are disjoint,
  which gives `φ(u_g) = 1_(B_g)`.
- **Item 2.** Suppose two codes for `g` give rules `(β, α)` and `(β', α')` around `y`, say with `β' = βθ`.
  Then `g(βθ z) = αθ z = α' z` for all `z`, so `α' = αθ` by Lemma 1.1, and the length differences agree. So
  `c` and `B_g` depend only on `g`. By injectivity of `φ` so does `u_g`.
- **Item 3.** `(g h z, c_g(h z), h z)(h z, c_h(z), z) = (g h z, c_g(h z) + c_h(z), z)`. Since `c_(gh)` is
  intrinsic, it equals this sum, and `u_g u_h = u_(gh)` follows by injectivity of `φ`.
- **Item 4.** `B_g` determines `g`, and `u_1 = 1`.
- The formula for `B_(g^n)` follows from item 3 by induction.
- `B_(g^(-1)) = B_g^(-1) = {(y, −c(y), g y)}` gives the cocycle of `g^(-1)`. ∎

**Lemma 1.5 (commuting).** Let `u = u_g` and `B = B_g`, and put
`T(x, k, y) = (g x, k + c(x) − c(y), g y)`. For `r ∈ R`, `u r = r u` iff `T(W_r) = W_r`. Moreover
- `T^n(x, k, y) = (g^n x, k + c_n(x) − c_n(y), g^n y)` for `n >= 0`, and
- `W_(u^m r) = B^m W_r = {(g^m x, c_m(x) + k, y) : (x, k, y) ∈ W_r}`.

*Proof.* First, `1_B * 1_W = 1_(BW)` and `1_W * 1_(B^(-1)) = 1_(W B^(-1))` for every finite disjoint union
`W` of sets `Z(α, β)`, although `W` need not be a bisection.
- For each `γ_2 ∈ G` there is exactly one `γ_1 ∈ B` with `π_2(γ_1) = π_1(γ_2)`, namely `(g π_1(γ_2), c(π_1(γ_2)), π_1(γ_2))`.
- So `λ(γ_2) = γ_1 γ_2` is a well-defined map `G -> G`. It is injective, because `γ_2 = γ_1^(-1) λ(γ_2)` and
  `γ_1` is recovered from `π_1(λ(γ_2)) = π_1(γ_1)`.
- Hence `1_B * 1_(Z_i) = 1_(λ(Z_i))` for each piece `Z_i` (Section 1, bisection case), and the sets
  `λ(Z_i)` are pairwise disjoint. Summing gives `1_B * 1_W = 1_(λ(W)) = 1_(BW)`.
- The right-hand case is symmetric.

So `φ(u r u^(-1)) = 1_(B W_r B^(-1))`, and
`B W_r B^(-1) = {(g x, c(x), x)(x, k, y)(y, −c(y), g y)} = T(W_r)`. Since `φ` is injective, `u r = r u` iff
`u r u^(-1) = r` iff `T(W_r) = W_r`. The formula for `T^n` is an induction using `c_(n+1)(x) = c_n(x) + c(g^n x)`,
and the last formula is Lemma 1.4. ∎

## 2. Dynamics of one element of V

Fix `g ∈ V` with codes `β_i -> α_i`, and let `L = max_i max(|α_i|, |β_i|)`. The same codes, swapped, describe
`g^(-1)`, with the same `L`. Then `|c| <= L`.

**Lemma 2.1 (rigid words).** Suppose some `β_i` is a prefix of the word `a`, which holds whenever `|a| >= L`.
That `i` is unique, and we put `g_*(a) = α_i a'` where `a = β_i a'`.

- **(a)** `g(a z) = g_*(a) z` for all `z`. Also `g_*(a s) = g_*(a) s` for every word `s`, and
  `|g_*(a)| − |a| = c(x)` for every `x ∈ [a]`.
- **(b)** `g_*` is injective.
- **(c)** `(g^(-1))_*(g_*(a)) = a`.
- **(d) Rigid iteration.** Let `a_0 = a` and `a_(n+1) = g_*(a_n)`. If `|a_0|, …, |a_(N−1)| >= L`, then
  `g^N(a z) = a_N z` for all `z`, and `|a_N| = |a| + c_N(x)` for all `x ∈ [a]`. In particular `c_N` is
  constant on each cylinder of length `L + N L`, so `c_N` is locally constant.
- **(e)** If `n >= 1` and `g^n(ρ z) = ρ' z` for all `z`, then `c_n(x) = |ρ'| − |ρ|` for all `x ∈ [ρ]`.

*Proof.*
- **Existence and uniqueness of `i`.** When `|a| >= L`, any infinite extension of `a` has a prefix in the
  complete code `{β_i}`, and that prefix is a prefix of `a` because its length is at most `L`. The code is
  prefix-free, so `i` is unique.
- **(a)** Immediate from `g(β_i a' z) = α_i a' z`.
- **(b)** If `g_*(a) = g_*(b)`, then `g(a z) = g(b z)`, so `a z = b z` for all `z`, and `a = b` by Lemma 1.1.
- **(c)** `g_*(a) = α_i a'` has the prefix `α_i`, and `g^(-1)` replaces it by `β_i`.
- **(d)** Induction on `N`, using (a): `g^(n+1)(a z) = g(a_n z) = a_(n+1) z`, and
  `|a_(n+1)| − |a_n| = c(g^n x)` because `g^n x ∈ [a_n]`. For `|a| >= L + N L` the hypothesis holds
  automatically, since each step changes the length by at most `L`.
- **(e)** Take `x ∈ [ρ]` and let `a = ρ s` be the prefix of `x` of length `|ρ| + L + n L`.
  - By (d), `g^n(a z) = a_n z` with `|a_n| = |a| + c_n(x)`.
  - Also `g^n(ρ s z) = ρ' s z`, so `a_n = ρ' s` by Lemma 1.1.
  - Hence `c_n(x) = |ρ'| + |s| − |ρ| − |s|`. ∎

**Lemma 2.2 (periodic points).** Let `g^p y = y` with `p >= 1`, and put `d = c_p(y)`. Let `a'` be the prefix of
`y` of length `L + p L`, and let `a'_p` be its `p`-th rigid iterate, so `g^p(a' z) = a'_p z` and
`|a'_p| = |a'| + d`. Both `a'` and `a'_p` are prefixes of `y = g^p y`, so they are comparable.

- **`d = 0`.** `a'_p = a'`, so `g^p = id` on `[a']`.
- **`d > 0`.** `a'_p = a' γ` with `|γ| = d`. With `a = a'`, `g^p(a z) = a γ z`. Writing `y = a z_0`,
  `y = g^p y = a γ z_0` gives `z_0 = γ z_0`, so `y = a γ^∞`.
- **`d < 0`.** `a' = a'_p δ` with `|δ| = −d`. With `a = a'_p`, `g^p(a δ z) = a z`, that is,
  `g^(-p)(a z) = a δ z`. As before, `y = a δ^∞`.

Moreover:
1. `c_(mp)(y) = m d`.
2. `c_p(g y) = c_p(y)`.
3. The sign of `d` does not depend on the period `p` chosen, nor on the point of the orbit.

*Proof of the extra statements.*
- **Item 1.** `c_(mp)(y) = Σ_(j<m) c_p(g^(jp) y) = m c_p(y)`.
- **Item 2.** Expand `c_(p+1)(y)` in two ways: `c(y) + c_p(g y) = c_p(y) + c(g^p y) = c_p(y) + c(y)`.
- **Item 3.** For two periods `p, p'`, `c_(pp')(y) = p' c_p(y) = p c_(p')(y)`. Together with item 2 this gives
  the claim. ∎

**Definitions.** `P_a` (resp. `P_r`, `P_0`) is the set of periodic points with `d > 0` (resp. `d < 0`,
`d = 0`).
- All three sets are `g`-invariant.
- By Lemma 1.4 the cocycle of `g^(-1)` is `−c(g^(-1) ·)`. So for `g^p y = y` the period cocycle of `g^(-1)`
  at `y` is `−c_p(y)`, and `P_r(g) = P_a(g^(-1))`.
- By Lemma 2.1(e), a local replacement `u w -> v w` of `g^k` around a periodic point `p` with `g^k p = p` has
  `|v| − |u| = c_k(p)`. So the hyperbolic periodic points of claim
  `infinite-order-elements-of-v-have-hyperbolic-periodic-points` are exactly `P_a ∪ P_r`.

**Classes.** For `x ∈ X` put `μ(x) = inf_(n >= 0) c_n(x)` and `M(x) = sup_(n >= 0) c_n(x)`, so
`μ <= 0 <= M`. Then
- `A0 = {μ > −∞, M < ∞}`,
- `A+ = {μ > −∞, M = ∞}`,
- `B = {μ = −∞}`.

These partition `X`. Using item 1 and `|c_r| <= r L`:
- `P_0 ⊆ A0`, because `c_(mp + r)(y) = c_r(y)`;
- `P_a ⊆ A+`, because `c_(mp + r)(y) = m d + c_r(y)`;
- `P_r ⊆ B`.

**Lemma 2.3 (A0).** Let `x ∈ A0`. There are `p >= 1` and a prefix `a` of `x` with `g^p = id` and `c_p = 0` on
`[a]`. Hence `[a] ⊆ P_0`, `A0 = P_0`, and `A0` is open.

*Proof.* Put `K = L − μ(x)` and `a = prefix_K(x)`.
- The rigid iterates satisfy `|a_n| = K + c_n(x) ∈ [L, K + M(x)]` for all `n`, so all of them are defined and
  they range over finitely many words.
- So `a_i = a_j` for some `i < j`. Applying Lemma 2.1(b) `i` times gives `a_0 = a_(j−i)`.
- With `p = j − i`, Lemma 2.1(d) gives `g^p(a z) = a z` and `c_p = |a_p| − |a| = 0` on `[a]`.
- So `[a] ⊆ P_0 ⊆ A0`, and `A0 = P_0` follows. ∎

**Lemma 2.4 (A+).** Let `x ∈ A+`. Then `c_n(x) -> ∞`. Moreover there are
- `j >= 0` and `p >= 1`,
- a word `v` with `|v| = L`, and
- a nonempty word `γ`

such that `g^p(v z) = v γ z` for all `z` and `g^j x ∈ [v]`. Consequently
`g^(j + mp) x -> q = v γ^∞ ∈ P_a` as `m -> ∞`, and `c_(j + mp)(x) = c_j(x) + m |γ|` for all `m >= 0`.

*Proof.* Write `c_n = c_n(x)`, and let `a = prefix_K(x)` with `K = L − μ(x)`, with rigid iterates `a_n`. As in
Lemma 2.3, `|a_n| = K + c_n >= L` for all `n`.

1. **`c_n -> ∞`.** Otherwise some `C` has `c_n <= C` for infinitely many `n`. Then two of the words `a_n` with
   `|a_n| <= K + C` coincide. As in Lemma 2.3, `g^p x = x` with `c_p(x) = 0`, so `c_n` is `p`-periodic and
   bounded, which contradicts `M(x) = ∞`.
2. **Ladder times.** Call `j` a ladder time if `c_n > c_j` for all `n > j`. For each `N`, the last time
   `j >= N` at which `min_(n >= N) c_n` is attained is a ladder time. The minimum exists and is attained
   finitely often by step 1. So there are infinitely many ladder times.
3. **Structure at a ladder time.** Let `j` be a ladder time and write `a_j = b_j s_j` with `|b_j| = L`. We show
   by induction that for `n >= j`, `a_n = e_n s_j` with `e_j = b_j`, `e_(n+1) = g_*(e_n)` and
   `|e_n| = L + c_n − c_j >= L`.
   - Since `|e_n| >= L`, Lemma 2.1(a) gives `a_(n+1) = g_*(e_n s_j) = g_*(e_n) s_j`.
   - Also `|g_*(e_n)| − |e_n| = c(g^n x)`, because `g^n x ∈ [a_n] ⊆ [e_n]`.
   - For `n + 1 > j`, `c_(n+1) > c_j`, so the new length is at least `L`.
   - By Lemma 2.1(d), `g^(n−j)(b_j z) = e_n z` for all `z`.
4. **Pigeonhole.** There are only `2^L` words of length `L`, so there are ladder times `j < j'` with
   `b_j = b_(j') =: v`.
   - `e_(j')` (built from `j`) and `b_(j')` are both prefixes of `a_(j')`.
   - `|e_(j')| = L + c_(j') − c_j > L = |b_(j')|`, so `e_(j') = v γ` with `|γ| = c_(j') − c_j >= 1`.
   - Hence `g^p(v z) = v γ z` with `p = j' − j`.
5. **Convergence.** `a_j = v s_j` is a prefix of `g^j x`, so `g^j x = v y'` for some `y'`.
   - By induction `g^(j + mp) x = v γ^m y'`, which tends to `q = v γ^∞`.
   - `g^p q = v γ γ^∞ = q`.
   - By Lemma 2.1(e), `c_p = |γ|` on `[v]`. So `c_p(q) = |γ| > 0` and `q ∈ P_a`.
   - Also `c_(j + mp)(x) = c_j(x) + Σ_(i<m) c_p(g^(j + ip) x) = c_j(x) + m |γ|`. ∎

**Lemma 2.5 (B).** Every `x ∈ B` lies in `P_r`. Hence `B = P_r`.

*Proof.* Write `c_n = c_n(x)`.

1. **New-minimum times.** Call `j` a new-minimum time if `c_j < c_i` for all `i < j`.
   - Since `μ(x) = −∞`, for every `N` the first `n` with `c_n < min_(i <= N) c_i` is a new-minimum time
     larger than `N`. So there are infinitely many.
   - For such `j` put `v_j = prefix_L(g^j x)`.
2. **Backward rigid words.** For a word `v` of length `L` let `V_0(v) = v` and
   `V_(i+1)(v) = (g^(-1))_*(V_i(v))`, defined as long as `|V_i(v)| >= L`.
   - *Claim.* If `j` is a new-minimum time and `v = v_j`, then for `0 <= i <= j`, `V_i(v)` is defined, is a
     prefix of `g^(j−i) x`, and has length `L + c_(j−i) − c_j`.
   - *Proof of the claim.* Induction on `i`; the case `i = 0` is the definition. Suppose `i < j`.
     - `|V_i(v)| >= L`, so `V_(i+1)(v)` is defined, and `g^(-1)(V_i(v) z) = V_(i+1)(v) z`. So
       `V_(i+1)(v)` is a prefix of `g^(j−i−1) x`.
     - By Lemma 2.1(a) for `g^(-1)` and Lemma 1.4, `|V_(i+1)(v)| − |V_i(v)| = −c(g^(j−i−1) x)`, which gives
       length `L + c_(j−i−1) − c_j`.
     - This is `>= L + 1`, since `j − i − 1 < j` and `j` is a new-minimum time.
   - *Consequence.* By Lemma 2.1(d) for `g^(-1)`, `g^(-j)(v z) = V_j(v) z`, and `V_j(v)` is a prefix of `x` of
     length `L − c_j`.
3. **One word, many times.** Pick `v` with `v = v_j` for infinitely many new-minimum times `j_1 < j_2 < …`, and
   put `j = j_1`.
   - The sequence `V_i(v)` depends only on `v`, so for `k >= 2` both `V_j(v)` and `V_(j_k)(v)` are prefixes of
     `x`.
   - Their lengths are `L − c_j < L − c_(j_k)`. So `V_(j_k)(v) = V_j(v) ε_k` with
     `|ε_k| = c_j − c_(j_k) >= k − 1`.
   - Then, for all `z`,
     `g^(−(j_k − j))(v z) = g^j(g^(-j_k)(v z)) = g^j(V_j(v) ε_k z) = v ε_k z`.
     The last equality is `g^(-j)(v w) = V_j(v) w` with `w = ε_k z`.
4. **Commensurable words.** Put `h = g^(-1)` and `p_k = j_k − j >= 1`, so `h^(p_k)(v z) = v ε_k z`.
   - Iterating, `h^(p_k p_2)(v z) = v ε_k^(p_2) z = v ε_2^(p_k) z`.
   - By Lemma 1.1, `ε_k^(p_2) = ε_2^(p_k)`, so `ε_k` is a prefix of `ε_2^∞`.
5. **The point.** `x ∈ [V_j(v) ε_k]` and `g^j(V_j(v) w) = v w` for all `w` (step 2), so `g^j x ∈ [v ε_k]`.
   - So `v ε_k` is a prefix of `g^j x` for every `k >= 2`. Since `|ε_k| -> ∞` and each `ε_k` is a prefix of
     `ε_2^∞`, `q' := g^j x = v ε_2^∞`.
   - `h^(p_2)(q') = v ε_2 ε_2^∞ = q'`. So `g^(p_2) q' = q'` and `g^(p_2)(v ε_2 z) = v z`.
   - By Lemma 2.1(e), `c_(p_2)(q') = |v| − |v ε_2| = −|ε_2| < 0`. So `q' ∈ P_r`.
   - `P_r` is `g`-invariant, so `x = g^(-j) q' ∈ P_r`. With `P_r ⊆ B`, this gives `B = P_r`. ∎

**Lemma 2.6 (finiteness).** `P_a` consists of at most `2^L` orbits, each finite, so `P_a` is finite. The same
holds for `P_r`.

*Proof.*
- **Every orbit contains a canonical point.** Let `y ∈ P_a`, so `y ∈ A+`. Lemma 2.4 gives `v, p, γ, j` with
  `g^(j + mp) y -> q_v = v γ^∞`. This sequence lies in the finite orbit `O(y)`. A convergent sequence in a
  finite subset of a Hausdorff space has its limit in that subset, so `q_v ∈ O(y)`.
- **`q_v` depends only on `v`.** If `g^(p_1)(v z) = v γ_1 z` and `g^(p_2)(v z) = v γ_2 z` with `γ_1, γ_2`
  nonempty, then `g^(p_1 p_2)(v z) = v γ_1^(p_2) z = v γ_2^(p_1) z`. So `γ_1^(p_2) = γ_2^(p_1)` by Lemma 1.1,
  and `v γ_1^∞ = v γ_2^∞`.
- So `O -> v` (choosing any `v` produced for a point of `O`) is injective from orbits in `P_a` to words of
  length `L`.
- For `P_r`, apply this to `g^(-1)`, using `P_r(g) = P_a(g^(-1))`. ∎

**Lemma 2.7 (punctured neighbourhoods of repellers).** Let `y ∈ P_r`, with `a, δ, p` as in Lemma 2.2, so
`y = a δ^∞` and `g^(-p)(a z) = a δ z`. Then every `x' ∈ [a] − {y}` has infinite orbit, and lies in `A+`.

*Proof.* Write `x' = a w`. Since `w != δ^∞`, there is a largest `k >= 0` with `w = δ^k y''`, and `y''` does not
begin with `δ`.
- `g^(kp) x' = a y''`, since `g^p(a δ z) = a z`.
- The points `g^(-np)(a y'') = a δ^n y''` for `n >= 0` are pairwise distinct: `a δ^n y'' = a δ^m y''` with
  `n < m` would give `y'' = δ^(m−n) y''`, which begins with `δ`.
- So the orbit of `x'` is infinite and `x'` is not periodic.
- Points of `A0 = P_0` and of `B = P_r` are periodic (Lemmas 2.3 and 2.5), so `x' ∈ A+`. ∎

**Corollary 2.8 (Theorem B).**
1. `g` has finite order iff `X = A0` iff `P_a ∪ P_r = ∅`.
2. If `g` has infinite order, then `P_a` and `P_r` are both nonempty and finite.

*Proof.*
- **Finite order implies `X = A0`.** If `g^m = 1`, then `B_(g^m)` is the unit space, so `c_m = 0`. Hence
  `c_(qm + r)(x) = c_r(x)`, and `n -> c_n(x)` is bounded for every `x`.
- **`X = A0` implies finite order.** By Lemma 2.3 and compactness, finitely many cylinders `[a_l]` with
  `g^(p_l) = id` on `[a_l]` cover `X`. So `g^(lcm p_l) = 1`.
- **`X = A0` implies `P_a ∪ P_r = ∅`.** Then `X = P_0`.
- **`P_a ∪ P_r = ∅` implies `X = A0`.**
  - If `P_r = ∅`, then `B = ∅` by Lemma 2.5.
  - If `P_a = ∅`, then `A+ = ∅`, since any point of `A+` produces a point of `P_a` by Lemma 2.4.
- **Item 2, `P_a != ∅`.** Let `g` have infinite order, so `A+ ∪ B != ∅`.
  - If `A+ != ∅`, Lemma 2.4 gives `P_a != ∅`.
  - If `B != ∅`, then `P_r != ∅` by Lemma 2.5, so Lemma 2.7 gives `A+ ⊇ [a] − {y} != ∅`, and again
    `P_a != ∅`.
- **Item 2, `P_r != ∅`.** Apply the above to `g^(-1)`, which also has infinite order, using
  `P_r(g) = P_a(g^(-1))`.
- **Finiteness.** Lemma 2.6. ∎

For comparison, `research/artifacts/infinite-order-v-elements-hyperbolic-points-2026-09-16.md` (lane
`zaremsky-2-15b`, not yet landed when this was written) is an independent direct proof of (V0) alone. This lane
checked it.
- Its Lemma 1 plays the role of Corollary 2.8(1).
- Its Lemma 2 is a records argument like Lemma 2.4, applied to a finite stretch of large positive drift.

The present Lemmas 2.5–2.7 add the classification `A0 = P_0`, `B = P_r`, and the finiteness (V0+). These are
what Section 3 needs.

## 3. The germ map and Theorem A

Fix `g ∈ V` of infinite order, `u = u_g`, `B = B_g`, and `C = C_R(u)`. By Corollary 2.8, `P_a = P_a(g)` is finite
and nonempty. For a `g`-orbit `O ⊆ P_a` put `d_O = c_(|O|)(p)` for `p ∈ O`. By Lemma 2.2 this does not depend
on `p`, and `d_O >= 1`.

**The target module.** Let `Φ = ⊕_((p, p') ∈ P_a × P_a) F_2[x^(±1)]`, where `x` is a formal variable. Define
`t : Φ -> Φ` by `(t f)_(p, p') = x^(c(g^(-1) p)) f_(g^(-1) p, p')`. Since `P_a` is `g`-invariant, `t` is a
well-defined invertible `F_2`-linear map, and `Φ` becomes an `F_2[t^(±1)]`-module.

**Lemma 3.1.** `Φ` is a free `F_2[t^(±1)]`-module of rank `N(g) = |P_a| · Σ_O d_O`.

*Proof.* On the `F_2`-basis `e(p, p', k) = x^k` in coordinate `(p, p')`, `t e(p, p', k) = e(g p, p', k + c(p))`.
So `t` permutes the basis, and `t^(|O|) e(p, p', k) = e(p, p', k + d_O)` for `p ∈ O`.
- **No finite orbits.** `d_O >= 1`, so every `t`-orbit on the basis is infinite. The group `⟨t⟩ ≅ Z` acts
  freely, and `Φ` is the permutation module on these orbits, hence free with one generator per orbit.
- **Counting orbits.** Fix `O` and `p'`, and fix `p ∈ O`.
  - Every `t`-orbit on `{e(p_1, p', k) : p_1 ∈ O, k ∈ Z}` meets `{e(p, p', k) : k ∈ Z}`.
  - It meets that set in exactly one `⟨t^(|O|)⟩`-orbit, that is, in one residue class of `k` mod `d_O`.
  - So there are `d_O` orbits.
- Summing over `O` and `p' ∈ P_a` gives `N(g)`. ∎

**The germ map.** For `r ∈ R` define
`κ(r)_(p, p') = Σ_(k ∈ Z) [(p, k, p') ∈ W_r] x^k`. The sum is finite because `|k|` is bounded on `W_r`, and `κ`
is `F_2`-linear because `W_(r + r') = W_r Δ W_(r')`.
- By Lemma 1.5, `(p, k, p') ∈ B W_r` iff `(g^(-1) p, k − c(g^(-1) p), p') ∈ W_r`.
- So `κ(u r) = t κ(r)`, and hence `κ(P(u) r) = P(t) κ(r)` for every Laurent polynomial `P`.
- Restricted to `C`, `κ` is a homomorphism of `F_2[u^(±1)]`-modules, with `u` acting on `Φ` as `t`.

**Lemma 3.2 (the kernel is torsion).** If `r ∈ C` and `κ(r) = 0`, then `u^m r = r` for some `m >= 1`.

*Proof.* Put `W = W_r`. Then `T(W) = W` by Lemma 1.5, and `κ(r) = 0` says exactly that
`W ∩ (P_a × Z × P_a) = ∅`. Let `K_W = max |k|` over `W`.

- **(i) Both endpoints of an arrow lie in the same class.** For `(x, k, y) ∈ W` and `n >= 0`,
  `T^n(x, k, y) = (g^n x, k + c_n(x) − c_n(y), g^n y) ∈ W`. So `|k + c_n(x) − c_n(y)| <= K_W`, and
  `c_n(x) − c_n(y)` is bounded in `n`. Hence `μ(x) = −∞` iff `μ(y) = −∞`, and `M(x) = ∞` iff `M(y) = ∞`.
- **(ii) No arrow has endpoints in `A+`.** Suppose `(x, k, y) ∈ W` with `x, y ∈ A+`.
  - Lemma 2.4 gives `(j, p, v, γ)` for `x`, with `g^(j + mp) x -> q ∈ P_a` and
    `c_(j + mp)(x) = c_j(x) + m|γ|`. It gives `(j', p', v', γ')` for `y`, with `g^(j' + mp') y -> q' ∈ P_a` and
    the analogous formula.
  - Put `J = max(j, j')` and `n_m = J + m p p'`.
  - **Positions.** `g^(n_m) x = g^(J − j)(g^(j + (m p') p) x)`. This tends to `g^(J − j) q ∈ P_a`, by continuity
    of `g^(J − j)`. Likewise `g^(n_m) y -> g^(J − j') q' ∈ P_a`.
  - **Cocycles.** `c_(n_m)(x) = c_j(x) + m p' |γ| + c_(J − j)(g^(j + m p' p) x)`. The function `c_(J − j)` is
    locally constant (Lemma 2.1(d)), so for `m >= m_0` the last term equals `c_(J − j)(q)`. So
    `c_(n_m)(x) = C_x + m p' |γ|` for `m >= m_0`. Likewise `c_(n_m)(y) = C_y + m p |γ'|`, after enlarging `m_0`.
  - **Middle coordinates.** The middle coordinate of `T^(n_m)(x, k, y)` is
    `k + C_x − C_y + m (p'|γ| − p|γ'|)`, which is bounded by (i). So `p'|γ| = p|γ'|`, and the middle
    coordinate is a constant `k*` for `m >= m_0`.
  - **Limit.** The points `(g^(n_m) x, k*, g^(n_m) y) ∈ W` converge in `X × Z × X` to
    `(g^(J − j) q, k*, g^(J − j') q')`. `W` is closed (Section 1), so this limit lies in
    `W ∩ (P_a × Z × P_a) = ∅`. This is a contradiction.
- **(iii) No arrow has endpoints in `B`.** Suppose `(x, k, y) ∈ W` with `x, y ∈ B = P_r`.
  - `W` is a finite union of sets `Z(α, β)`, so `(x, k, y) ∈ Z(α, β) ⊆ W` for some `α, β`. So `x = α z`,
    `y = β z` and `k = |α| − |β|`.
  - Lemma 2.7 gives prefixes `a` of `x` and `b` of `y` with `[a] − {x} ⊆ A+` and `[b] − {y} ⊆ A+`.
  - Choose `z' != z` agreeing with `z` on its first `|a| + |b|` letters. Then `α z' ∈ [a] − {x}` and
    `β z' ∈ [b] − {y}`.
  - So `(α z', k, β z') ∈ Z(α, β) ⊆ W` has both endpoints in `A+`, which contradicts (ii).
- **(iv) Conclusion.**
  - By (i)–(iii), every arrow of `W` has both endpoints in `A0`. So `π_1(W) ⊆ A0`.
  - `π_1(W)` is compact. By Lemma 2.3 it is covered by finitely many cylinders `[a_l]` with `g^(p_l) = id` and
    `c_(p_l) = 0` there.
  - Let `m = lcm p_l`. For `x ∈ π_1(W)`, `g^m x = x` and `c_m(x) = (m / p_l) c_(p_l)(x) = 0` (Lemma 2.2).
  - By Lemma 1.5, `W_(u^m r) = {(g^m x, c_m(x) + k, y)} = W`. So `u^m r = r`. ∎

**Proof of Theorem A.**
- **Invariance.** Conjugation by `w` is a ring automorphism of `R`. It carries `C_R(u)` onto
  `C_R(w u w^(-1))` and `F_2[u]` onto `F_2[w u w^(-1)]`, so `rho(w u w^(-1)) = rho(u)`.
- **Upper bound `N(g)`.**
  - `0 -> ker κ -> C -> κ(C) -> 0` is exact.
  - Localization at `S = F_2[u] − {0}` is exact, and `S^(-1) ker κ = 0` by Lemma 3.2.
  - So `S^(-1) C ≅ S^(-1) κ(C) ⊆ S^(-1) Φ`.
  - `Φ` is free over `F_2[t^(±1)]` of rank `N(g)` (Lemma 3.1), and `t` is already invertible. So
    `S^(-1) Φ ≅ F_2(t)^(N(g))`, and `rho(u) <= N(g)`.
- **Lower bound 1.**
  - `κ(1)_(p, p') = [p = p']`, which is nonzero.
  - `Φ` is a free module over the domain `F_2[t^(±1)]`, so `P(t) κ(1) != 0` for `P != 0`.
  - So `1` is not torsion, `S^(-1) F_2[u] ⊆ S^(-1) C` is nonzero, and `rho(u) >= 1`.
- **Upper bound `N(g^(-1))`.**
  - `C_R(u^(-1)) = C_R(u)`.
  - A nonzero polynomial in `u^(-1)` is a unit times a nonzero polynomial in `u`, and conversely. So the two
    localizations coincide and `rho(u^(-1)) = rho(u)`.
  - `u^(-1) = u_(g^(-1))`, so `rho(u) <= N(g^(-1)) = |P_r(g)| · Σ_(O ⊆ P_r(g)) |c_(|O|)(O)|`. ∎

**Examples.** The values of `rho` below are from established graph nodes; the bounds are computed here.

1. **`c`.** Here `c = s_00 t_0 + s_01 t_10 + s_1 t_11`, with `g: 0z -> 00z, 10z -> 01z, 11z -> 1z`.
   - `P_a = {0^∞}` with `d = 1`, so `N = 1`.
   - `rho(c) = 1` (`leavitt-north-south-thompson-unit-has-cyclic-centralizer`).
2. **`c^2`.** `P_a = {0^∞}` with `d = 2`, so `N = 2`.
   - `C_R(c^2) = F_2[c^(±1)]` (same claim, item 1), which is free of rank 2 over `F_2[c^(±2)]`.
   - So `rho = 2 = N`.
3. **`phi(c) = s_0 c t_0 + s_1 c t_1`.** `P_a = {00^∞, 10^∞}`, two fixed points with `d = 1`, so
   `N = 2 · 2 = 4`.
   - `rho(phi(c)) = 4 rho(c) = 4`, by the quadrupling step of route `no-diagonal-conjugacy-from-finite-centralizer-rank`,
     which is proved in that route's body.
4. **A two-cycle, where the bound is not sharp.** Let `g(0 z) = 1 c(z)` and `g(1 z) = 0 z`, so
   `u = s_1 c t_0 + s_0 t_1`.
   - **Dynamics.** `g^2(0 z) = 0 c(z)` and `g^2(1 z) = 1 c(z)`. `P_a = {00^∞, 10^∞}` is one orbit with
     `d_O = c(00^∞) + c(10^∞) = 1 + 0 = 1`, so `N(g) = 2`. Similarly `P_r = {01^∞, 1^∞}` is one orbit with
     `|d_O| = 1`, so `N(g^(-1)) = 2`.
   - **Matrix form.** Under `R ≅ M_2(R)`, `x -> (t_i x s_j)_(i, j)`, we get `u -> [[0, 1], [c, 0]]` and
     `u^2 -> diag(c, c)`.
   - **Centralizer.** `C_R(u) ⊆ C_R(u^2) = M_2(C_R(c)) = M_2(F_2[c^(±1)])`.
     - For `X = [[a, b], [e, f]]` with entries in `F_2[c^(±1)]`, `X U = U X` with `U = [[0, 1], [c, 0]]`
       forces `e = b c` and `f = a`.
     - So `X = a(c) I + b(c) U = a(u^2) + b(u^2) u`, and `C_R(u) = F_2[u^(±1)]`.
   - So `rho(u) = 1 < 2 = min(N(g), N(g^(-1)))`.

*Heuristic, not used anywhere.* Why the bound is not sharp: `κ` records all germs at pairs of attracting points. An element of `C` must also
behave coherently along the flow between attractors and repellers, and `κ` does not see that constraint.

## 4. Consequences

Let `U_V = {w u_g w^(-1) : w ∈ Q, g ∈ V}` be the set of conjugates of Thompson units.

**4.1 (algebraic dependence).** Let `u ∈ U_V` and let `a ∈ R` commute with `u`. Then some nonzero
`P ∈ F_2[x, y]` has `P(a, u) = 0`.

*Proof.* If `u` has finite order `m`, take `P = y^m − 1`. Otherwise `n = rho(u)` is finite by Theorem A. The
remaining steps are those of route `algebraic-dependence-from-finite-centralizer-rank`:
- The `n + 1` elements `1, a, …, a^n` of `S^(-1) C_R(u)` are linearly dependent over `F_2(u)`.
- Clearing denominators gives `q_i`, not all zero, and `s ∈ S` with `s(u) Σ_i q_i(u) a^i = 0`.
- `P(x, y) = s(y) Σ_i q_i(y) x^i` is nonzero, because `F_2[x, y]` is a domain. ∎

This is the case of claim `leavitt-commuting-units-are-algebraically-dependent` in which one of the two units
lies in `U_V`.

*Prior result (added by the referee, 2026-09-16).* When **both** commuting units lie in `U_V`, a polynomial
relation was already known: Brownlowe–Sørensen, arXiv:1603.03618, J. Algebra 456 (2016), Proposition 3.4, for
every commutative unital coefficient ring. Its proof uses revealing pairs and components of support. The statement
and its transfer to `F_2` are recorded verbatim in `research/artifacts/brownlowe-sorensen-transfer-to-f2-2026-09-13.md`,
read from the PDF on 2026-09-13; this referee did not re-read the PDF. Over `F_2`, 4.1 contains that proposition
and goes further, because the second element `a` is an arbitrary element of `R`.

**4.2 (Heisenberg centers and Baumslag–Solitar bases).**
- If `a, b ∈ Q` and `c = [a, b]` commutes with `a` and `b` and has infinite order, then `c ∉ U_V`.
- If `t x t^(-1) = x^k` in `Q` with `|k| >= 2` and `x` of infinite order, then `x ∉ U_V`.

*Proof.* Items (i) and (iii) of the established claim `leavitt-heisenberg-centers-have-infinite-centralizer-rank`
give `rho = ∞` in both cases. Theorem A gives `rho < ∞` on `U_V`. ∎

`a, b, t` are arbitrary linear units, so this is not a statement about subgroups of `V`. It extends the Consequence paragraph of
`leavitt-north-south-thompson-unit-has-cyclic-centralizer`, which covers conjugates of powers of `c` only, to
conjugates of every infinite-order element of `V`.

**4.3 (diagonal copies).** No `y ∈ U_V` of infinite order is conjugate to its diagonal copy
`phi(y) = s_0 y t_0 + s_1 y t_1`.

*Proof.* `rho(phi(y)) = 4 rho(y)` (route `no-diagonal-conjugacy-from-finite-centralizer-rank`, step 2, proved
there), `rho` is a conjugacy invariant, and `1 <= rho(y) < ∞` by Theorem A. ∎

This is the case `y ∈ U_V` of claim `leavitt-units-are-not-conjugate-to-diagonal-copies`.

**4.4 (remark, not re-verified).** The node of that claim records that in any unital homomorphism
`f : L ⊗ L -> L`, `y = f(1 ⊗ c)` is an infinite-order unit conjugate to its diagonal copy. If that reduction is
correct, 4.3 shows `f(1 ⊗ c) ∉ U_V`. This lane did not re-check the reduction.

## 5. Where the method stops

- **Linear units.** For a unit `u` that is not in `U_V`, `φ(u)` is not the indicator of a bisection. Then
  `W_(u r u^(-1))` is not the image of `W_r` under a map of `G`. There is no `T`, no point dynamics, and
  Lemma 1.5 fails. The germ map of Section 3 still makes sense at clean germs, as in
  `leavitt-annulus-north-south-units-have-cyclic-centralizers`. But Lemma 3.2 has no analogue: its steps (ii)–(iv)
  use closedness of `W` under limits of point orbits and `g^m = id`, `c_m = 0` on `π_1(W)`, which are statements
  about points.
- **Overlap.** Theorem A does not cover the linear annulus twists `c(1 + n)` of that claim, and that claim does
  not cover general Thompson units. So neither result contains the other.
- **Sharpness.** Theorem A is not sharp (Example 4). The exact value of `rho(u_g)` is not determined here.
- **The target stays open.** Claim `leavitt-unit-centralizers-have-finite-rank` remains open for units outside
  `U_V`.

## 7. Literature and novelty

## 2. The degree-two theorem

**Theorem.** Let `B` be locally indicable and let `w in B * <t>` have
`deg_t(w) != 0`. Then `H_2(B; Z) -> H_2((B * <t>)/<<w>>; Z)` is injective.

**Proof.**

1. *Conjugation.* Replacing `w` by a conjugate does not change `<<w>>`.
2. *Case: `w` is conjugate into a factor.* It cannot be conjugate into `B`,
   because `deg_t(w) != 0`. So `w ~ t^m` with `m != 0`, and
   `G = B * Z/m`. The map `t -> 1` gives a retraction `G -> B`, so the
   coefficient map is split injective on `H_2`.
3. *Case: `w` is not conjugate into a factor.* Every cyclically reduced conjugate
   has free-product length at least 2.
   - If `R` is cyclically reduced of length `l >= 2`, its first and last
     syllables lie in different factors. So `R^n` is cyclically reduced of
     length `n l`.
   - Among all pairs `(R, n)` with `R` cyclically reduced and `R^n` conjugate to
     `w`, pick one with `n` maximal. Such a maximum exists because `n l(R) = l'`,
     where `l'` is the length of a cyclically reduced conjugate of `w`.
   - Suppose `R = S^k` with `|k| >= 2`. Then `S` is not conjugate into a factor.
     Write `S = u S' u^-1` with `S'` cyclically reduced. Now `w` is conjugate to
     `S'^(|k| n)` (after replacing `S'` by `S'^-1` if needed), which contradicts
     maximality.
   - So `R` is not a proper power, and `G = (B * <t>)/<<R^n>>` meets the
     hypotheses of the pinned theorem with `Lambda = {B, <t>}`. Here `Z` is
     locally indicable.
4. *Apply the pin.* Take `k = 2` and `M = Q/Z` with trivial action. Projecting
   onto one factor keeps the map onto, so the restriction
   `H^2(G; Q/Z) -> H^2(B; Q/Z)` is an epimorphism.
5. *Universal coefficients.* `Q/Z` is divisible, so `Ext(H_1 X, Q/Z) = 0` and
   `H^2(X; Q/Z) = Hom(H_2(X), Q/Z)` naturally in `X`. Therefore every
   `gamma : H_2(B) -> Q/Z` factors as `gamma' o i_*`.
6. *Conclusion.* Let `x != 0` in `H_2(B)`. Since `Q/Z` is an injective
   cogenerator, some `gamma` has `gamma(x) != 0`. Then
   `gamma'(i_* x) != 0`, so `i_* x != 0`. ∎

## 3. Transfer to arbitrary groups

**Corollary.** Let `Q` be any group and `w in Q * <t>` nonsingular.

- **(a) Locally indicable packets.** Suppose the coefficient subgroup `B` of `w`
  is locally indicable. Then `K_2(Q, w) = 0`.
  - `howie-locally-indicable-nonsingular-equations-are-solvable` makes `B`
    inject into `B_w`.
  - `schur-kernel-localizes-to-coefficient-subgroup` then gives
    `K_2(Q, w) = iota_* K_2(B, w)`.
  - The theorem gives `K_2(B, w) = 0`.
- **(b) Locally indicable images.** For every homomorphism `phi : Q -> L` with
  `L` locally indicable, `K_2(Q, w) <= ker(phi_* : H_2 Q -> H_2 L)`.
  - `phi * id` induces `G_Q -> G_L := (L * <t>)/<<phi(w)>>`. The degree does
    not change, so `phi(w)` is nonsingular over `L`.
  - Naturality maps `K_2(Q, w)` into `K_2(L, phi(w))`, which is `0` by the
    theorem.
- **(c) Combined.** `K_2(Q, w)` lies in `iota_*` of the intersection, over all
  homomorphisms `phi : B -> L` to locally indicable groups, of `ker phi_*`.

- **(d) p-local form.** Suppose `B` has a finite normal subgroup `A` of order
  prime to `p`, `B/A` is locally indicable, and `B` injects into `B_w`. Then
  `K_2(Q, w)` consists of elements of order prime to `p`.
  - By (b), `K_2(B, w)` lies in the kernel of `H_2 B -> H_2(B/A)`.
  - The LHS spectral sequence with `Z_(p)` coefficients shows that this kernel
    is killed by tensoring with `Z_(p)`.
  - Without the injectivity hypothesis, the coefficient kernel lies in `A`, by
    `nonsingular-coefficient-kernel-in-locally-indicable-residual`, but it is
    not known to vanish.

No shape hypothesis is used anywhere. This is the degree-two analogue of
`nonsingular-coefficient-kernel-in-locally-indicable-residual`.

## 4. Consequences for the Deligne lane (the obstruction)

A witness `(w, B)` for the target needs `alpha(iota_* x) != 0` for some
`x in K_2(B, w)`, where `alpha = e mod 3`. By (c) the following all fail, at
every `t`-shape:

- **Locally indicable Maslov packets.** This includes any surface-group,
  free-by-cyclic, torsion-free one-relator, RAAG or 3-manifold subgroup of
  `Sp_4(Z)` that carries a Toledo/Maslov class that is nonzero mod 3.
  - Invariant: Howie's `H^2(-; Q/Z)` restriction epimorphism.
  - Step where each such attempt dies: every multiplier of `B` extends to
    `B_w`, so the Maslov multiplier restricted to `B` extends and nothing dies.
- **Classes visible in a locally indicable image of the packet.** Suppose a
  Maslov-detected class survives to `H_2` of some locally indicable image of
  `B`. Then it cannot be killed.

This goes beyond `amenable-t-shape-adjunctions-kill-no-schur-class`. That result
needed an amenable shape, but allowed any torsion-free packet.

Updated forced profile of a witness packet `B <= Sp_4(Z)`:

- `B` is not locally indicable.
- If `B` is torsion-free, then the shape of `w` is non-amenable.
- The killed class is invisible in `H_2` of every locally indicable image of
  `B`, and invisible to projective unitary classes.

## 5. Dead end recorded: finite-cover transfer to torsion-free coefficients

The idea: pull the equation back to a finite-index torsion-free `B' <= B`
through a permutation extension `A_w -> Sym(X)`, then apply Forester--Rourke or
Klyachko to the square system over `B'`. It dies at two steps.

- **At the prime 3.** Transfer detects `alpha` only when `3` does not divide
  `|X|`. But `3 | |X|` whenever `B` contains an element `g` of order 3 and the
  stabilizers are torsion-free: `<g>` then acts freely on each orbit
  `B' \ B`, since `B' x g = B' x` forces `x g x^-1 in B'`.
- **At the layered theorem.** The exponent matrix `M_w` of the square system
  over `Z[P]` is typically not unimodular. For example `2 - zeta_3` has norm 7.
  So Forester--Rourke's layered theorem is not available. A disconnected base
  overdetermines the system, since `rank H_2(L/K) >= c - 1`.

The degree-two Howie theorem avoids the finite cover, but only for locally
indicable packets.

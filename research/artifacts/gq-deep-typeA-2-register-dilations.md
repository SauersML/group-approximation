## 1. Summary

- **New node:** `gl-n-q-lies-in-prime-shift-permutation-group`.
  - A single permutation `σ` of `Q`, the multiplicative automorphism shifting the
    primes along a `Z`-indexing, makes every prime dilation conjugate to `x -> 2x`.
  - So `GL_n(Q)` lies in `K_n = <GL_n(Z), diag(2,1,...,1), σ_n>`, and `Aff(Q)` in
    `A_1 = <x+1, 2x, -x, σ>`.
  - Both are finitely generated and 2-transitive (`K_n` on `P^(n-1)(Q)`). So for
    each, type (A) reduces to finite presentation plus one finitely generated
    point stabilizer.
- **Spark 3 is closed in three forms** (§4), each with the exact step where it
  fails. In every form, either translations `+1/p` lose uniform rewrite depth, or
  the radices at a fixed position become unbounded, or the overflow element needs
  a `BS(1,p)` structure for every `p` at once, which puts `Aff^+(Q)` itself into
  the actor.
- **Consistency.** This matches gq-bt-kojima §4.2 and
  `rational-stepping-stones-in-nv-need-bs12-or-heisenberg`: register devices give
  additive locality, while dilations need multiplicative locality.

## 2. Prime-shift overgroups

Notation of the node. `σ(-1) = -1`, `σ(p_k) = p_(k+1)`, `σ(0) = 0`, and
`σ_n = σ` in every coordinate. Example indexing: `p_0 = 2`; for `k > 0`, `p_k` is
the `2k`-th prime; for `k < 0`, the `(1-2k)`-th prime. So `p_1 = 3`, `p_-1 = 5`,
`p_2 = 7`.

- `GL_n(Q) <= K_n = <GL_n(Q), σ_n>`, and `<diag(2,1,...,1), σ_n> ≅ Z ≀ Z`.
- `K_n` is the image of the HNN extension `Π_n` of `GL_n(Q)` along the monomial
  group `N_n(Q)`, with the prime-shift automorphism.
- `σ` is continuous for neither the real nor any `p`-adic topology. So the landed
  natural-action obstructions do not reach `K_n` or `A_1`:
  - piecewise projective and piecewise linear hosts;
  - adelic hosts (`piecewise-commutative-linear-hosts-miss-linear-gl-n-q`);
  - germ extensions.

**Finite presentation is not evident.**
- `Π_n` is generated by `GL_n(Z)`, `e` and `s`. Writing `e_k = s^k e s^-k`, its
  relations include `e_k x_12(1) e_k^-1 = x_12(1)^(p_k)` for every `k`.
- Conjugating by `s` does not derive these from finitely many of them, because
  `s` does not normalize `GL_n(Z)`.
- Example: `σ_2 x_12(1) σ_2^-1` sends `(0,1)`, `(1,1)`, `(2,1)` to `(1,1)`,
  `(3,1)`, `(21,1)`:
  - `σ_2^-1(2,1) = (5,1)` and `x_12(1)(5,1) = (6,1)`;
  - `σ(6) = σ(2) σ(3) = 3 · 7 = 21`;
  - a linear map with the first two values would send `(2,1)` to `(5,1)`, so this
    map is not linear.
- Nothing here proves that `K_n` or `A_1` is not finitely presented.

**Tests on `A_1`, the smallest case.**
- **T3, the point stabilizer, answered NO.** One might hope
  `Stab_(A_1)(0) = Q^x ⋊ <σ> ≅ {±1} × (Z ≀ Z)`, which is finitely generated.
  - It is strictly larger. Put `h = τ_-1 σ τ_1 σ^-1`, where `τ_c = x -> x+c`.
    Then `h(0) = σ(1) - 1 = 0`.
  - `h(1) = σ(2) - 1 = 2`.
  - `h(2) = σ(σ^-1(2) + 1) - 1 = σ(6) - 1 = 20`.
  - An element `x -> c σ^m(x)` with `h(1) = 2` has `c = 2`, and then
    `h(2) = 2 p_m = 20` would force `p_m = 10`. So `h` is not of that form.
  - Whether `Stab_(A_1)(0)` is finitely generated is open.
- **T1, open.** Does `A_1` contain a nontrivial finitary permutation? If so, it is
  normally generated inside `A_1`, and `A_1` has host shape H1 of the cone map.
- **T2, open.** The abelianization of `A_1` and of `K_2`.

## 3. The locality dichotomy, and two bounded rewrites

**3.1 Additive locality.** In a most-significant-digit-first mixed-radix register
with radices `(r_1, r_2, ...)`, `+1/m` is a rewrite of depth `k` whenever
`m | r_1...r_k`. The carries run toward the top, and overflow goes to an integer
part (Kojima–Sheng; `rationals-embed-in-brin-thompson-group-2v`).

**3.2 Multiplicative locality.**
- On `Z_q`, written least significant digit first, `×u` for a unit `u` is a
  synchronous transducer: each output digit needs the carry from the lower
  digits. It is not a bounded prefix rewrite.
- On a most-significant-digit-first register, `×u` for `u` coprime to the radices
  needs carries from arbitrarily deep digits (gq-bt-kojima §4.2).

**3.3 Radix swaps are bounded.**
- Let a prefix block have radices `(r_1, ..., r_k)` and `R = r_1...r_k`. Its
  digits encode `N` in `[0, R)`, and the register value is `x = N/R + T/R`, with
  `T` the value of the tail.
- For any reordering of `(r_1, ..., r_k)`, re-expressing `N` in the reordered
  radices is a bijection of the depth-`k` cones that preserves `x`.
- So radices can be reordered inside a finite prefix by a bounded,
  value-preserving rewrite between two register formats.

**3.4 Placeholder dilation.**
- Let the first radix equal to `p` sit at position `k`, and put
  `R = r_1...r_(k-1)`. Then `x = N/R + d_k/(pR) + T/(pR)`, so
  `p x = ⌊(pN + d_k)/R⌋ + ((pN + d_k) mod R)/R + T/R`.
- So `×p` is a rewrite of depth `k`:
  - the new prefix number is `(pN + d_k) mod R`;
  - the overflow `⌊(pN + d_k)/R⌋`, in `{0,...,p-1}`, goes to the integer part;
  - position `k` becomes a placeholder of radix 1, and the tail keeps its format.
- So `×p` is a bounded rewrite between formats, with no carries from below.

## 4. Three forms of Spark 3 and where each fails

**4.1 Slot formats with placeholders.**
- *Model.* Fix a sequence of slots with prime labels, every prime infinitely
  often. A format marks each slot active (radix = its label) or placeholder
  (radix 1). The states `(format, digits)` form a compact space, and `×p` is §3.4
  applied to the first active `p`-slot.
- *Failure.* Along the orbit `×p^j`, the first `j` active `p`-slots become
  placeholders. So on any invariant set of states:
  - the depth of the first active `p`-slot is unbounded, and this depth is the
    rewrite depth of both `×p` and `+1/p`, so neither has finitely many local
    pieces;
  - the invariant set is not closed, since limits have no active `p`-slot and
    `+1/p` is undefined there.
- Reactivating slots by `×(1/p)` does not help, because `×p^j` must be defined
  on the whole space.

**4.2 Shifted formats (deleting the radix instead).**
- Deleting the first `p` shifts every later position one step to the left. A
  format space invariant under such a deletion at bounded depth gives each
  position `i` beyond that depth a set of possible radices containing the set at
  position `i+1`.
- So the radix sets are eventually nonincreasing, and compactness, meaning
  finitely many radices at each position, allows only finitely many primes.
  That caps the denominators, so the register cannot carry `(Q,+)`.

**4.3 One register per prime, with a shared overflow `a`.**
- *What works.* Base-`p` registers `R_p` on separate coordinates, each with
  overflow into the same infinite-order element `a` of the actor, give `(Q,+)`.
  The `p`-towers commute, and their union is the pushout of the `Z[1/p]` over `Z`,
  which is `Q`.
- On `R_p`, `×p` is the base-`p` shift, with the dropped digit `d` sent as `a^d`.
  This is bounded.
- *Failure 1.* This needs actor elements `t_p` with `t_p a t_p^-1 = a^p`,
  commuting in `p`. Then `H = <a, t_p (p prime)>` is `Aff^+(Q)`:
  - The relations `t_p a t_p^-1 = a^p` and `[t_p, t_q] = 1` present
    `Aff^+(Q) = Q ⋊ ⊕_p Z`, via `a -> (x -> x+1)` and `t_p -> (x -> p x)`. Adding
    one stable letter at a time is an ascending HNN extension, and the normal
    closure of `a` is the directed union `Z[1/m!]`, which is `Q`. So `H` is a
    quotient of `Aff^+(Q)` in which `a` has infinite order.
  - Let `N` be a normal subgroup of `Aff^+(Q)`. If `N ∩ Q != 0`, then `N ∩ Q` is
    invariant under multiplication by every positive rational, so it is `Q`,
    and `a` dies. Otherwise `[N, Q] ⊆ N ∩ Q = 0`, so `N` centralizes `Q`. The
    centralizer of `Q` in `Aff^+(Q)` is `Q`, so `N = 1`.
  - Hence `H ≅ Aff^+(Q)`. The actor already contains the stepping stone, so the
    construction is circular.
- *Failure 2.* `×p` must also act on `R_q` for `q != p`. That is the coprime case
  of §3.2, which is unbounded.

## 5. What would have to change

A register-type Cantor model of `Q ⋊_p Z` needs one of the following:
- a mechanism that replenishes `p`-digits at bounded depth after `×p`, which
  §4.1 and §4.2 exclude for slot and shift formats;
- an exact carry-from-below action, which no bounded rewrite gives;
- `BS(1,p)` on the overflow for every `p` compatibly, which is circular by §4.3.

These are the open gates already recorded: `bs12-embeds-in-brin-thompson-2v`,
and an actor that already contains `Aff^+(Q)`.

The prime-shift groups of §2 avoid registers. They supply the dilations
multiplicatively, through a single non-linear permutation, and leave only
finite presentation and one stabilizer open. The cheapest next test is T1 or
T2 for `A_1`.

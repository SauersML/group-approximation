## Item 2 (prop:BE-finite): PASS
Printed: for every sufficiently large n, ξ_n ∈ {ρ_n, η_n} and k ≤ r_n = 2^{⌊n/2⌋}, Δ^{S_n}_{ξ_n}(k) ≤ Ck^α and N^{S_n}_{ξ_n}(k) ≤ exp(Ck^α), with C, α (0 < α < 1) from `thm:BE`. The node's item 2 says exactly this.

Re-derived:
- **Ball criterion** (`lem:stabilizer-ball-criterion`): with right actions, ωg = ωg′ ⇔ g′g⁻¹ ∈ St(ω). For |g|, |g′| ≤ r this lies in B_S(2r), so equal stabilizers inside B_S(2r) give a well-defined, injective, surjective, label-preserving map ωh ↦ ω′h.
- **Fixation transfer** (`lem:fixation-transfer`): suppose n ≥ ⌈log₂|g|⌉ + 2 and g fixes 1^n. With m = ⌈log₂|g|⌉ + 1 ≤ n − 1, the state g_{1^m} lies in the nucleus {1,a,b,c,d} (contracting property, BGŠ Cor. 2.5, imported) and fixes 1^{n−m} with n − m ≥ 1, so it is not a. Each of b = (a,c), c = (a,d), d = (1,b) applies a only on the 0-branch, so each fixes 1^∞, and g fixes ρ. The converse holds because fixing ρ fixes its prefixes.
- **Local convergence at ρ_n:** |g| ≤ 2r_n gives ⌈log₂|g|⌉ ≤ ⌊n/2⌋ + 1, since 2r_n is a power of 2. The condition n ≥ ⌊n/2⌋ + 3 holds for n ≥ 6, as printed.
- **Local convergence at η_n:** ρ_n and η_n are the two children of 1^{n−1}. An automorphism fixing one of them fixes their parent and does not swap the children, so it fixes the other. Hence St(ρ_n) = St(η_n), and the ball criterion gives Γ_n(η_n, r_n) ≅ Γ_n(ρ_n, r_n).
- **Transfer:** every point ξ_n s_i⋯s_ℓ of an inverted orbit of a word of length ℓ ≤ k ≤ r_n lies in Γ_n(ξ_n, r_n) and maps to ρ s_i⋯s_ℓ. So δ_{ξ_n}(w) = δ_ρ(w), and w ↦ 𝒪(w) is injective from orbits at ξ_n to orbits at ρ. Both bounds follow from `thm:BE`.
- **Import:** `thm:BE` is Bartholdi–Erschler, Invent. Math. 189 (2012), Prop. 4.4 and Lemma 4.9, quoted identically in both sources; the primary paper was not opened.

## Item 3 (lem:separation): PASS
Printed: d_{Γ_n}(ρ_n, η_n) ≥ 2^{n−3} for every n ≥ 4.

Re-derived:
- A geodesic of length d gives g with ρ_n g = η_n and |g| ≤ d. Conversely a geodesic word for g gives a path, so |g| = d.
- g fixes 1^{n−1} and its state there swaps 0 and 1.
- If m = ⌈log₂|g|⌉ + 1 ≤ n − 2, then g_{1^m} ∈ {1,b,c,d} fixes 1^∞, so g fixes 1^n, a contradiction. So ⌈log₂|g|⌉ ≥ n − 2, hence log₂|g| ≥ n − 3.
- Edge cases: d = 0 is impossible since ρ_n ≠ η_n; d = 1 gives m = 1 ≤ n − 2, a contradiction.

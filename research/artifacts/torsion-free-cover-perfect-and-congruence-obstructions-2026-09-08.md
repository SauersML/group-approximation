## The four things that were not in the graph

**1. The commutator subgroup of the cover is finitely generated and
perfect.**  The graph has the cover `E`; it does not have `T = E'`.  From a
finitely presented strong `G = F/R` on `r` generators and `s` relators:

* `q(T) = G` because `E = AT`, and `q(T') = G` because `G` is perfect;
  hence `T'A = E`, so `E/T'` is a quotient of the abelian `A` and
  `T = E' <= T'`.  So `T` is perfect.  This works for any abelian-kernel
  extension of a perfect group.
* Finite generation is the step the dossier flags as previously missing, and
  it checks out.  `[R,R] <= [F,F]` gives `E_ab = Z^r`; `G` perfect gives
  `E = AT`, so the abelianization restricted to `A` is onto, with kernel
  `A_0 = A cap T`.  Pick `a_i` in `A` over the basis `e_i`, write
  `eta(r_j-bar) = sum_i m_(ij) e_i`, and set

```text
b_j = r_j-bar - sum_i m_(ij) a_i,     c_(ki) = (q(x_k) - 1)a_i.
```
  Modulo their `ZG`-span `B`, every `r_j-bar` is an integer combination of the
  `a_i` and every generator of `G` fixes each `a_i`, so `A/B` is generated as
  an abelian group by the `a_i`; the composite `Z^r -> A/B -> Z^r` is the
  identity, so `A/B = Z^r` and `B = A_0`.  With `y_i = x_i-bar a_i^-1 in T`,
  whose images generate `G` and whose conjugation on `A` equals that of
  `x_i-bar` (they differ by an element of the abelian `A`), the subgroup
  generated by the `y_i`, `b_j`, `c_(ki)` contains `A_0` and surjects onto
  `T/A_0 = G`, hence is `T`.  So `d(T) <= r + s + r^2`.
* Every exact finite-dimensional unitary representation of `T` is trivial:
  the joint character spaces of `rho(A_0)` are permuted through `T/A_0 = G`,
  which is strong, so each is invariant; conjugation on each block's matrix
  algebra kills `A_0`, factors through `G`, and is trivial, so `rho(T)` is
  abelian; `T` perfect finishes.

**2. A perfect torsion-free MF group with no finite-dimensional
representations at all.**  This is the sharpened calibration.
`rational-heisenberg-fd-radical-is-commutator-and-mf` refutes
`Rad_fd(K) = [K,K] != 1 ==> K non-MF`; it does not refute the stronger
reading that matches item 1, where the group is also **perfect** so that the
collapse is total.  The dossier supplies that: let `M` be the
finitely-supported upper unitriangular matrices over `Q` indexed by the
**ordered set `Q`**.  Re-derived here:

* torsion-free, by the first nonzero superdiagonal inside a finite support:
  higher powers of `A` vanish there, so the entry of `(I+A)^n - I` is `n`
  times that of `A`;
* perfect, because `Q` is dense: for `i < j` pick `i < k < j` and
  `[x_(ik)(a), x_(kj)(1)] = x_(ij)(a)`, and these generate;
* every exact finite-dimensional unitary representation is trivial, since
  each `x_(ij)(a)` is central in a `UT_3(Q)` on `{i,k,j}` and the rational
  Heisenberg determinant argument (`chi(ab)^m = 1`, then `a = c/m`, `b = 1`)
  kills that centre;
* MF, by reducing entries modulo increasing primes on an exhaustion of the
  index set and using left regular representations of the finite
  unitriangular groups.

`M` is **not finitely generated** — every finite subset is supported on a
finite index set — so it does not decide the MF status of the finitely
generated `T` of item 1.  That is exactly the residual gap.

**3. Congruence groups over the integral group ring are always MF.**  For
any countable `G` and `d >= 1`,
`Gamma_d(G) = {U in GL_d(Z[G]) : U = I mod 3}` is torsion-free and locally
residually finite.  Re-derived: `S = M_d(Z[G])` is free abelian with
`intersection_n 3^n S = 0`; for `U = I + 3^s B` with `B` not in `3S` and
`s >= 1`, binomial expansion (valid despite noncommutativity, since powers of
the single `B` commute) gives `v(U^t - I) = s` for `3` not dividing `t` and

```text
U^3 - I = 3^(s+1)(B + 3^s B^2 + 3^(2s-1) B^3),
```
whose bracket is `B` modulo `3S` because `2s - 1 >= 1`; so
`v(U^(3^k t) - I) = s + k` is always finite and no positive power is `I`.
For a finitely generated subgroup, a word reduced modulo `3^n S` expands into
ordered monomials of length below `n` in the finitely many `D_l`, with
coefficients modulo `3^n`, so the image is finite; those reductions separate
points.  Local residual finiteness gives MF.

So no construction whose output lands inside such a congruence group can
produce a non-MF group, whatever the input `G`.  That closes off a whole
concrete family.

**4. Rationalizing an abelian kernel restores torsion.**  If
`1 -> A -> E -> G -> 1` has torsion-free abelian kernel and one pushes out
along `A -> A tensor Q`, then a lift `e` of an order-`m` element with
`e^m = a` acquires `e-tilde = (-a/m)e` of order exactly `m`, the two factors
commuting because `e` centralizes `a = e^m`.  So dividing the kernel is not
a way to keep a cover torsion-free over a base with torsion.

## The amplification caveat, recorded but not landed as a node

The dossier also analyses `A_M(U) = (+)_(k<=M) U^(tensor k)` against the
clock and shift.  Whenever that amplification preserves almost commutation
the winding obstruction survives, and almost commutation forces
`M_n / n -> 0` for this particular all-powers sum.  But the caveat is the
useful half and it is a scope note rather than a theorem: the pair
`U_n tensor conj(U_n)`, `V_n tensor conj(V_n)` **commutes exactly**, its
scalar phase being `omega_n conj(omega_n) = 1`.  So the clock-and-shift
obstruction cannot rule out every matrix-amplification approach.  Recorded
here so that nobody reads `commuting-repair-forces-half-dimension-rank` as
excluding amplification in general.

## Where this leaves the transfer

`(D)` is untouched and remains the isolated open implication.  Items 1 and 2
together sharpen the region's central warning: the cover's commutator
subgroup is finitely generated, torsion-free, perfect, and has no
finite-dimensional theory whatsoever, and a group with **all four** of those
properties can still be MF.  So exact finite-dimensional collapse cannot be
substituted for non-MF even at this strength, and the only thing separating
`T` from `M` is finite generation.

Nothing here justifies deleting the existing torsion-free construction, and
nothing here is a non-MF construction.  No Lean certification is asserted.

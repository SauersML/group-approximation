## 0. Verdict

* **The mechanism as written cannot work.** Every relation Plan 1 lists is a relation of the
  unitriangular group `U_4(R)`, which is nilpotent:
  - the isometry commutators on `(1,2)-(2,3)` and on `(2,3)-(3,4)`;
  - both readings of `x_14(abc)`;
  - the additive split `x_12(1) = x_12(e_0) x_12(e_1)`.

  Section 1 gives a homomorphism of `U_4(R)` into `M_(p^2)(F_p)` with `rk(N_23 N_12) = (p-1)^2/p^2`.
  No corner Cuntz--Toeplitz family exists in it. So checks (a)--(c) cannot be derived from those
  relations.
* **Plan 2 dies the same way.** Its restriction to `U_3(R)` has nonzero defect and zero centre
  pairing, so `heisenberg-centre-pairing-constrains-two-root-defect` cannot close from `U_3`
  relations alone.
* **The route is not invalidated.** The claim is not refuted. Its conclusion is contradictory in
  every rank ultraproduct, so the claim is equivalent to the defect identity for `R` (Section 2). The
  route is a valid restatement whose content is still the gate.
* **Any valid proof must use `sigma` outside `U_4(R)`.** One opposite unit root element together with
  `U_4(R)` already generates a copy of `R^x` (Section 3). The fourth index adds coordinates, not
  relations.
* **Side result (Section 5).** `N_23 N_12 = 0` forces every `N_ab^2 = 0` in every characteristic. So
  the route's odd-characteristic case needs no second identity.

## 1. A unipotent model with nonzero defect

**Setting.**
- `K` is a finite field of characteristic `p`.
- `R` is any unital `K`-algebra, `L_K(1,2)` included.
- `U_4(R) <= EL_4(R)` is the group of unitriangular `4 x 4` matrices, generated by `x_IJ(a)` for
  `I < J`.
- For a homomorphism `rho`, write `N_IJ = rho(x_IJ(1)) - 1`.

**Theorem 1.** There is a homomorphism `rho : U_4(R) -> GL_(p^2)(F_p)` with

```text
rk(N_23 N_12) = (p-1)^2 / p^2        (normalized rank),     N_13 = N_24 = N_14 = N_34 = 0 .
```

*Proof.* For unitriangular `g, h`,
`(gh)_(i,i+1) = g_(i,i+1) + h_(i,i+1)`. So `g |-> (g_12, g_23)` is a homomorphism
`U_4(R) -> (R,+)^2`. Choose an `F_p`-linear `phi : R -> F_p` with `phi(1) = 1`, let
`C_p^2 = <u> x <v>` act on `V = F_p[C_p^2]` by translation, and put
`rho(g) = u^phi(g_12) v^phi(g_23)`.

This is a homomorphism. It sends `x_13, x_24, x_14, x_34` to `1`, and
`N_12 = u - 1`, `N_23 = v - 1`. With `x = u - 1` and `y = v - 1`, `V = F_p[x,y]/(x^p, y^p)`, and
`N_23 N_12` is multiplication by `xy`. Its image has basis `x^i y^j` with `1 <= i, j <= p-1`, so
its rank is `(p-1)^2` out of `p^2`. QED

**Corollary 2 (the listed relations hold).** `rho` satisfies every relation among elements of
`U_4(R)`. For `R = L_K(1,2)` with `t_i s_j = delta_ij` and `e_i = s_i t_i` this includes:
- the isometry commutators `[x_12(t_i), x_23(s_j)] = x_13(delta_ij)` and
  `[x_23(t_i), x_34(s_j)] = x_24(delta_ij)`;
- both readings `x_14(abc) = [x_13(ab), x_34(c)] = [x_12(a), x_24(bc)]`;
- `x_12(1) = x_12(e_0) x_12(e_1)`;
- the Heisenberg pairing identities of `U_3(R) = <x_12, x_23, x_13>`.

In `rho` all the `x_14` data vanish. So any `e` built as a range projection of that data is `0`,
and check (c) `rk(e) = rk(D)` fails while `rk(D) > 0`.

**Corollary 3 (no corner family).** Let `M` be a unital ring whose corners are directly finite, such
as a rank ultraproduct or `M_(p^2)(F_p)`. If `e` is an idempotent and `S_0, S_1, T_0` lie in
`eMe` with `T_0 S_0 = e` and `T_0 S_1 = 0`, then `S_1 = 0`.

*Proof.* Direct finiteness of `eMe` gives `S_0 T_0 = e`, so `S_1 = e S_1 = S_0 T_0 S_1 = 0`. QED

So no nonzero corner of any rank ultraproduct carries `T_i S_j = delta_ij e`.

**Consequence 4.** No implication valid for every homomorphism from `U_4(R)` into a rank
ultraproduct leads from `N_23 N_12 != 0` to a corner Cuntz--Toeplitz family with `e != 0`, because
`rho` is a counterexample. A procedure that builds `S_j`, `T_i` and `e` from `sigma(U_4(R))` by ring
operations in `M` (products, sums, range projections, corners), and proves checks (a)--(c) using
only relations of `U_4(R)` and properties shared by all rank ultraproducts, would succeed on `rho`,
which Corollary 3 forbids.

**The regular sofic model.** `U_4(R)` is nilpotent, hence amenable and sofic. Its sofic
approximations give rank models in which, for `a != 0`:
- every root element acts almost freely, with `rk(n_IJ(a)) = 1 - 1/p` at every position;
- `N_13, N_14 != 0`;
- in characteristic two, `rk(N_23 N_12) = 3/8` (`sofic-subgroups-carry-rank-models-violating-two-root-identity`,
  which lists `UT_3(R)`).

So rank symmetry across positions, and nonvanishing centre data, do not rescue a `U_4`-only argument
either. Only operator use of elements outside `U_4(R)` escapes.

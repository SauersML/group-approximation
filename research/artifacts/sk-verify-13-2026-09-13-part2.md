## 1. Full-group units (part 1, Lemma 1)

**(i) Multiplicativity.**
- `u^n e_A u^m e_B = u^{n+m}(u^{-m}e_Au^m)e_B = u^{n+m} e_{T^{-m}A ∩ B}`.
- So `w_g w_h = Σ_{n,m} u^{n+m} e_{A_m(h) ∩ T^{-m}A_n(g)}`.
- For `x` in `A_m(h) ∩ T^{-m}A_n(g)`: `h(x) = T^m x ∈ A_n(g)`, so `gh(x) = T^{n+m}x`.
- For each `x` the pair `(m,n) = (n_h(x), n_g(hx))` is unique, so these sets are pairwise disjoint and, over `n+m = k`, their
  union is `{n_{gh} = k}`. The cocycle is unique because there are no periodic points.
- Over any field, disjoint indicators add to the indicator of the union. So `w_gw_h = w_{gh}`, `w_1 = 1`, and
  `w_g^{-1} = w_{g^{-1}}`.

**(ii)** `w_g e_V = Σ_n e_{T^n(A_n∩V)}u^n`, and `T^n(A_n∩V) = g(A_n ∩ V) = gV ∩ T^nA_n`, so `w_g e_V = e_{gV}w_g`.
This is not used by (A) or (B).

**(iii) Injectivity.** `w_g = Σ_n e_{T^nA_n}u^n`, whose `u^0` coefficient is `e_{A_0}`, so `w_g = 1` forces `A_0 = X`.

Wording (0 lines): part 1 §1 says the representation `Σ_j f_ju^j` is unique "because T has no periodic points". It is unique
by construction of the algebraic crossed product. No periodic points is what makes `n_g` unique.

## 2. Whitehead identities (Lemma 2), computed entrywise

**Characteristic 2.**
- `e_12(a)e_21(a^{-1}) = [[1+aa^{-1}, a],[a^{-1},1]] = [[0,a],[a^{-1},1]]`.
- Then times `e_12(a)`: `[[0,a],[a^{-1}, a^{-1}a+1]] = [[0,a],[a^{-1},0]] = w(a)`.
- `w(a)w(1) = [[a,0],[0,a^{-1}]]`.

**Any ring.** `e_12(a)e_21(−a^{-1})e_12(a) = [[0,a],[−a^{-1},0]]`, and `w(a)w(−1) = diag(a,a^{-1})` with
`w(−1) = [[0,−1],[1,0]]`.

**Commutator identity.** In `diag(a,a^{-1},1)diag(b,b^{-1},1)diag((ba)^{-1},ba,1)`:
- slot 1 is `ab(ba)^{-1} = aba^{-1}b^{-1}`;
- slot 2 is `a^{-1}b^{-1}ba = 1`.

**(A).** `[[T]]′` is generated by the commutators `[g,h]`, and `diag(w_{[g,h]},1,1) = diag([w_g,w_h],1,1) ∈ EL_3(R)`. The
homomorphism carries products of these to products. Injectivity comes from (iii). Over a general field `k`, Lemma 1 and the
signed identities are unchanged. ∎

## 3. Theorem B

**Index by flux.** On the orbit `n ↦ T^ny` (injective, since there are no periodic points), `g` acts by
`ĝ(n) = n + n_g(T^ny)`, and `(gh)^ = ĝ∘ĥ`.
- `ind(A,B) = |A∩F| − |B∩F|` for any finite `F` containing `AΔB` (and, for three sets, all their differences). So `ind`
  is additive and invariant under bijections.
- `I(gh) = ind(ĥ^{-1}ĝ^{-1}N, ĥ^{-1}N) + ind(ĥ^{-1}N, N) = I(g) + I(h)`.
- `T̂^{-1}N = {−1,0,1,…}`, so `I(T) = 1`. `I` kills torsion.
- `I` depends on `y` a priori. (B) uses one fixed `y` throughout, so this is harmless.

**Lemma 3 (tower permutations).**
- `E_abE_cd = e_{T^aW}e_{T^{a−b+c}W}u^{a−b+c−d}`. This is `E_ad` if `b = c`. If `b ≠ c` it is `0`, because `W ∩ T^jW = ∅` for
  `0 < |j| < h_0`.
- `eE_ab = E_ab = E_abe`, so `(1−e)` is orthogonal to every `E_ab`.
- Then `Φ(A) = (1−e)I_3 + Σ A_{(p,a),(q,b)}E_abE_pq` is unital and multiplicative on `M_{3h_0}(F_2)`.
- Transvections, for `p ≠ q`: `Φ(I + E_{(p,a),(q,b)}) = e_pq(E_ab)`.
- For `p = q`, `a ≠ b`, put `r = E_ab`, `s = E_bb`. Then `r^2 = 0`, `sr = 0`, `rs = r`, and inverses are the elements themselves in
  characteristic 2. Expanding:
  - `(I+rE_pq)(I+sE_qp)(I+rE_pq)(I+sE_qp) = I + sE_qp + rsE_pp + srE_qq + rsrE_pq` times `(I+sE_qp)`;
  - that is `I + E_abE_pp`, since `sr = rsr = 0` and `E_ppE_qp = 0`.
  - So `[e_pq(E_ab), e_qp(E_bb)] = I + E_abE_pp`, which confirms note l.205–215.
- `GL_{3h_0}(F_2) = SL_{3h_0}(F_2) = E_{3h_0}(F_2)`, so `Φ(GL_{3h_0}(F_2)) ⊆ G`.
- `w_g = (1−e) + Σ_aE_{π(a),a}`: the `u^0` term is `e_{A_0} = (1−e) + Σ_{π(a)=a}E_aa`. So
  `diag(w_g,1,1) = Φ(diag(P_π,I,I))`.

**Lemma 4 (generation).**
- `|A| − |B| = I(g_1) = 0`, and `ĝ_1(A) ⊆ [0,M)` and `ĝ_1(B) ⊆ [−M,0)` from the displacement bound.
- The tower over `T^{-M}V` has height `2M`.
- The levels `T^jV`, `|j| ≤ 2M`, are pairwise disjoint, so `V ∩ T^dV = ∅` for `0 < |d| ≤ 4M`. That is why `|n′| > 4M` and
  `|m| > 3M`, as the artifact says. So `σ̃` realizes `σ` on `[−M,M)`, fixes `[−3M,3M]∖[−M,M)`, and moves no orbit point across 0.
- `h = σ̃g_1` preserves `N`:
  - for `n ∈ B`, `σ` sends `ĝ_1(n)` into `ĝ_1(A) ⊆ [0,M)`;
  - for `n ≥ 0` with `ĝ_1(n) ≥ 0`, the image is neither in `ĝ_1(B)` (negative) nor in `ĝ_1(A)` (by injectivity), so it is
    fixed or moved without crossing 0.
  - The same holds for negatives, and bijectivity gives onto.
- The three level cases, with return times `r > 2M′`, keep `h(x)` in its tower:
  - `j ∈ [M′, r−M′)`: displacement;
  - `j ∈ [0,M′)`: `n_h(x) = c_j` and `j + c_j ∈ [0, 2M′)`;
  - `j ∈ [r−M′, r)`: `x ∈ T^{−i}Y`, `n_h(x) = c_{−i}`, and `j + c_{−i} ∈ [r−2M′, r)`.
- As `n_h` is constant on levels and `h` is bijective, `h` permutes the levels of each tower. So `g = T^kσ̃^{-1}h` is a product
  of `T^k` and Lemma-3 elements, which are closed under inverses.

**Assembly.**
- `φ` is a slotwise homomorphism (§0) and injective by (iii).
- `φ(T) = diag(u,u^{-1},1) ∈ G`, since `w_T = u` and `I(T) = 1`.
- A Lemma-3 element has finite order, so `I = 0` and `φ(g) = diag(w_g,1,1) ∈ G`.
- Generators land in `G`, so `φ([[T]]) ⊆ G`. ∎

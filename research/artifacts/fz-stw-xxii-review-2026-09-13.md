## 1. The printed problem

**Source:** Schafhauser–Tikuisis–White, *Nuclear C\*-algebras: 99 problems*, arXiv:2506.10902v2 (8 May 2026),
§7 "Intermezzo: the trace problem", Problem XXII "(cf. [64, Question 1.1])", p. 24. Reference [64] is CCEGSTW.

**Hypothesis:** a C\*-algebra A whose trace space T(A) is non-empty and compact. The question:

> "Are all traces on Ā^{T(A)} automatically ‖·‖_{2,T(A)}-continuous? Equivalently, is the canonical embedding
> T(A) ⊆ T(Ā^{T(A)}) an equality?"

On the same page STW record three positive results:
- the answer is yes when T(A) is a finite-dimensional simplex;
- Evington [155] proves it when Ā^{T(A)} has complemented partitions of unity (CPoU), which follow from
  property Γ;
- Farah–Vaccaro [159] prove it when T(A) is a Bauer simplex whose extremal boundary is at most 1-dimensional.

STW say the problem is open in general, and also open when A is nuclear.

## 2. The definitions it uses

**Source:** Carrión–Castillejos–Evington–Gabe–Schafhauser–Tikuisis–White, *Tracially complete C\*-algebras*,
arXiv:2310.20594v6 (7 Aug 2026).

- **Def 3.4 (p. 29):** a tracially complete C\*-algebra is a pair (M, X) with the following data.
  - X ⊆ T(M) is compact and convex.
  - (i) X is a faithful set of traces.
  - (ii) The unit ball of M is ‖·‖_{2,X}-complete.
  - The remark after the definition: "Implicitly we always imagine X to be non-empty."
- **Def 3.13 (p. 32):** "(M, X) is said to be factorial if X is a closed face of T(M)." Proposition 3.10 is a
  different result.
- **Prop 3.15 (p. 33):** every ‖·‖_{2,X}-continuous trace lies in the closed face of T(M) generated by X. If
  (M, X) is factorial, X is precisely the set of ‖·‖_{2,X}-continuous traces.
- **Def 3.19 (p. 34):** Ā^X is the bounded ‖·‖_{2,X}-Cauchy sequences modulo the ‖·‖_{2,X}-null sequences.
- **Prop 3.23 (p. 36):** for compact convex X ⊆ T(A), with X̃ the traces on Ā^X induced by X:
  - (i) the seminorm ‖·‖_{2,X̃} coincides with ‖·‖_{2,X} on Ā^X;
  - (ii) X → X̃ is an affine homeomorphism;
  - (iii) (Ā^X, X̃) is tracially complete;
  - (iv) (Ā^X, X̃) is factorial iff X is a face of T(A).
- **Q1.1:** the trace problem, posed for factorial tracially complete (M, X).

**Relation between the two:** printed XXII is the instance M = Ā^{T(A)}, X = T(A)~ of Q1.1. That pair is
factorial by Prop 3.23(iv), because T(A) is a face of itself. So factoriality is a consequence in printed XXII,
not a hypothesis.

Remarks:

- **R1. Cite the 14-fold statement for printed XXII.** The four-fold theorem refutes Q1.1 for one factorial
  pair. That M *is* Ā^{T(A)} lives in the type definitions and in the gauge identity, not in the four-fold
  statement text. `factorialNegativeSolutionToProblemXXII` carries the gauge identity, the injective
  non-surjective extension and the properties of T(A), so it says printed XXII. A Palomar Challenge has to
  define the uniform tracial completion (Def 3.19) and T(A) in the statement file. The factorial-pair Props
  alone would not suffice.
- **R2. The continuity notion.** `IsUniformTwoContinuousOn` is sequential continuity at 0 for ‖·‖_{2,X}. For a
  linear functional and a seminorm topology this is equivalent to continuity. Conjunct 4 does not involve the
  continuity notion at all.
- **R3. The `nonempty` field** matches the remark after Def 3.4.
- **R4. Base versus completion.** Separability, nuclearity and type I are proved for A. Factoriality and the
  failure of the trace problem are proved for (M, X). Type I is asserted at an arbitrary universe v. Printed
  XXII needs none of the regularity: it only adds the nuclear case STW list as open.

## 4. Re-derivation of the key steps

The audit's steps were re-derived independently. Each item below names the audit section.

- **§1, (A1): the obstruction sequence.** D_s = Γ(End(1 ⊕ L_s^{⊕s})) over CP^{s²}, with fibre rank s+1. The
  projections p_s (trivial line) and q_s (one tautological summand) are orthogonal. So h_s = p_s − q_s has
  ‖h_s‖ = 1 and h_s² = p_s + q_s. Every normalized fibre trace gives ‖h_s‖₂² = 2/(s+1), and T(D_s) consists of
  integrals of those, so ‖h_s‖₂ → 0.
- **§2, (A2): top Chern class.** Take a packet of ℓ elements a_j. The trivial line reduces every a_j at x iff
  the (L^{⊕s} ← 1) components of a_j(x) and a_j(x)\* vanish there. Those components form a section of
  L^{⊕2sℓ}. Its top Chern class is ±u^{2sℓ}, which is non-zero in H\*(CP^{s²}) when 2sℓ ≤ s², that is s ≥ 2ℓ.
  So the section vanishes somewhere. At that point the vector state of the trivial line is multiplicative on
  the packet and takes value 1 on h_s.
- **§3: the trace space.** Traces on the unitized c₀-sum of homogeneous blocks are the probability measures on
  K, the one-point compactification of ⊔_s CP^{s²}. So T(A) is Bauer, its boundary K is compact metrizable,
  and K has unbounded covering dimension.
- **§4, (A8): ℂ1 + J is the completion.** On D_s, ‖a‖ ≤ √(s+1)·‖a‖_{2,T(D_s)}. So at each fixed coordinate,
  ‖·‖_{2,T(A)}-Cauchy data controls the operator norm. Hence the bounded approximable sequences are exactly
  ℂ1 + J, where J is the two-null ideal.
- **§5, (A10)–(A13): the character.** For a finite packet F, let S_F be the set of states on ∏D_s that kill the
  c₀-sum, are multiplicative on F, and send h to 1. Each S_F is weak-star closed. It is non-empty, because
  weak-star limits of the late (A2) vector states lie in it. The sets have the finite intersection property,
  and compactness gives a character of the tail corona that detects h.
- **§6, (A14)–(A16): discontinuity.** Pull the character back to a tracial state σ on M. Let h^{(n)} be the
  tail truncations of (h_s). Then σ(h^{(n)}) = 1, because h^{(n)} − h lies in the c₀-sum. On the other hand,
  ‖h^{(n)}‖_{2,T(A)} ≤ √(2/(n+1)) → 0.
- **Why the answer is no.** Every canonical extension τ̃ satisfies |τ̃(x)| ≤ ‖x‖_{2,τ} ≤ ‖x‖_{2,T(A)}, by
  Cauchy–Schwarz. So σ is not a canonical extension, and T(A) ⊊ T(M).

**Consistency with the positive results:**

- **Farah–Vaccaro [159]:** needs a boundary of dimension ≤ 1. K has unbounded dimension.
- **Evington [155]:** by its contrapositive, Ā^{T(A)} here has no CPoU. There is no conflict, since A has a
  character (the one at infinity), so A is not Z-stable and has no property Γ.
- **The repository's finite-dimensional factor-bundle theorem:** positive over a fixed finite-dimensional base.
  The base here has unbounded dimension.

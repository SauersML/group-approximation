## Step 0 (press point 1)
- *Self-similarity.* `g(i + 2y) = ai + b + 2ay`. With `j` the last digit of `ai + b ∈ Z_2`, set `b' = (ai + b − j)/2`.
  - `ai + b − j ∈ Z[1/N] ∩ 2Z_2 = 2Z[1/N]` for odd `N`. So `b' ∈ Z[1/N]`, and the restriction `y ↦ ay + b'` lies in
    `G_N`. ✓
  - The two factorizations of `(p,w)` agree, because colour-2 edges are fixed with restriction `g`. ✓
- *Pseudo-freeness.* A strong fix of `p` makes `g` the identity on `C(p)`, which is infinite. An affine map equal to
  the identity on infinitely many points is the identity. Colour-2 words have restriction `g` itself. ✓

## Step 1 (press point 2)
- *The natural action.* Elements of `Q_2` have finitely many negative-position digits, so addition to a bi-infinite
  sequence, with upward carries, is well defined. `u` shifts the digits up by one, which is `×2`.
- *Translations by `Z[1/N]`.* For `c ∈ Z[1/N] ⊆ Z_2`, the translation touches only colour 1, and it equals `(+c) × id`,
  the global bisection `Z(∅, +c, ∅)`. ✓
- *Translations by `Z[1/2N]`.* `u^(−k)T_c u^k(x) = (2^k x + c)/2^k = x + c/2^k`. So the group generated is the image of
  `Z[1/2N] ⋊ ⟨2⟩`, which is faithful. ✓
- *Not finitely generated.* The translation parts of a finitely generated subgroup lie in `Σ_i Z[1/2]c_i ⊆ (1/M)Z[1/2]`.
  That misses `1/p^k` for a prime `p | N` and large `k`. ✓

## Step 2B (press point 3)
- *Fixed sets.* The colour-2 length comparison and the surjectivity of `g|_ν` give equal degrees. Then `g|_ν = 1`, so
  `g` strongly fixes `ν`, and `g = 1` and `λ = μ`. So the groupoid is effective. ✓
- *Hausdorff.*
  - For `g ≠ 1`, `ax + b` has at most one fixed point: `b/(1−a)` if `a ≠ 1`, which may not even lie in `Z_2`, and
    none if `a = 1`.
  - So for `λ = μ`, the fixed set is at most `μ·({x_0} × C)`. It may be nonempty, unlike the odometer case, but it is
    nowhere dense.
  - Same degree with `λ ≠ μ` gives disjoint cylinders.
  - A degree mismatch gives affine equations: in colour 1, `(2^j − 2^(j')a)x = …` with `2^j ≠ 2^(j')a` for `j ≠ j'`; in
    colour 2, a periodic `y`.
  - So unit-germ sets are `μX` or `∅`. ✓
- *Essentially principal.* The groupoid is effective, Hausdorff and second countable, so it is topologically
  principal, and Matui's standing assumption holds. Countably many nowhere-dense fixed sets also give this directly
  (N3).
- *Perfectness via `σ_μ(g) = σ_(μ0)(g)σ_(μ1)(g)`.* The split is by the first colour-2 letter, which `g` fixes with
  restriction `g`, so `c_g = 2c_g = 0`.
  - `g × id = σ_((ε,0))(g)σ_((ε,1))(g)` is killed the same way.
  - The normal form `f = h∏σ_(μ_i)(g_i)` with `h ∈ 2V` then gives `F_ab = 0`. This does not need `F = ⟨2V, g × id⟩`
    (N2). ✓
- *Simplicity.* Minimality comes from `2V`. Pure infiniteness comes from the same `U` and `V`. With these, Matui's
  theorem gives simplicity. ✓
- *`G_3`.* `tat^(−1)(x) = 3(x/3 + 1) = x + 3 = a^3`, so `G_3 = Z[1/3] ⋊ ⟨3⟩ ≅ BS(1,3)`. It embeds as `g ↦ g × id`, and
  `BS(1,2) = ⟨+1 × id, u⟩`. ✓

## Step 3, the limit (press point 4)
- *The rectangle.* The translation `T_q = (+1/q) × id` fixes colour 2, so on a rectangle where it agrees with a basic
  bisection, `w' = w`.
- *The colour-1 equation.* `b + 2^j x' + 1/q = b' + 2^(j')(αx' + β)` for all `x'`.
  - This gives `2^j = 2^(j')α`, with `α` a 2-adic unit, so `j = j'` and `α = 1`.
  - Then `β = (b − b' + 1/q)/2^j ∈ Z[1/N']`, so `1/q ∈ Z[1/2N']`, which is false for a prime `q ∤ 2N'`. ✓
- *The conclusion.* The natural `Q ⋊ ⟨2⟩` contains every `T_q`, so it lies in no such `2V_H`. ✓

## Nits
- **N1 (Step 3, the choice of `N'`).** "The product of the denominators of the generators" does not cover inverses.
  Include the numerators of the multipliers too, since `a^(−1)` has denominator equal to the numerator of `a`.
  - All of these are odd, because the multipliers are 2-adic units and the translations are 2-adic integers. So `N'`
    stays odd.
- **N2 (item 1).** "It is generated by `2V` and `{g × id}`" reads as a claim about `Z[1/2N] ⋊ ⟨2⟩`, which does not
  contain `2V`. Say "this copy is generated by `u ∈ 2V` and the `(+c) × id`, `c ∈ Z[1/N]`".
  - If the sentence means `2V_(G_N) = ⟨2V, g × id⟩`, it needs an argument: the odometer's `qs = σ_((1,∅))` trick is
    specific to `+1`. It is not needed for perfectness.
- **N3 (Step 2B).** Add the essential-principality line. The fixed set for `λ = μ`, `g ≠ 1` can be nonempty, so the
  odometer's "empty fixed set" wording does not transfer verbatim.

## Items 1 and 2
- **Item 1: the degree character.**
  - *Every element has an exponent.* The generators do: `d(g) = 0` for linear `g`, and `d(σ_n) = 1` because `σ` is
    multiplicative with `σ(0) = 0`.
  - Inverses inherit it (N1): substituting `t = σ^(−a)(s)` and `w = k^(−1)w'` gives
    `k^(−1)(s w') = σ^(−a)(s) k^(−1)(w')`.
  - Composition adds exponents.
  - *Uniqueness.* `k(0) = 0`, so `k(w) ≠ 0` for `w ≠ 0`. Then `σ^(a−b) = id` on `Q`, which forces `a = b` because
    `σ^m(2) = p_m`.
  - *The kernel.* `K_n = ⟨GL_n(Q), σ_n⟩` with `d(GL_n(Q)) = 0`, so `K_n/⟨⟨GL_n(Q)⟩⟩` is cyclic and maps onto `Z`. Hence
    `ker d = ⟨⟨GL_n(Q)⟩⟩ = ⟨σ_n^j GL_n(Q) σ_n^(−j)⟩`. ✓
- **Item 2: the centre.**
  - Scalars are central in `K_n^0` by the `d = 0` equivariance.
  - Conversely, a central `z` commutes with `GL_n(Q)`, so `z(0)` is `GL_n(Q)`-fixed and equals 0.
  - `Fix(Stab(e_1)) = Q e_1`: the fixed set of the `x_1j(b)` with `j ≥ 2` is the set of `w` with `w_j = 0`.
  - So `z(e_1) = c e_1`, and transitivity on `Q^n ∖ 0` gives `z = cI`.
  - `σ_n(tI)σ_n^(−1) = σ(t)I`. ✓

## Item 3: `K_n/N` (the author asked about this)
- *`N` contains the determinant kernel.* `q x_ij(1) q^(−1) = x_ij(q_i/q_j)` gives every `x_ij(b)`, hence `SL_n(Q)`.
  With `diag(−1,1,…)`, `N ⊇ ker|det|`.
  - So `N ∩ GL_n(Q)` is a union of `ker|det|`-cosets, equal to `|det|^(−1)(I_n)`, and `I_n` is a subgroup.
- *`σ`-invariance.* `σ_n diag(r,1,…)σ_n^(−1) = diag(σ(r),1,…)`, and `N` is normal. So `σ^(±1)(I_n) ⊆ I_n`.
- *`σ̄` normalizes `Ḡ`.*
  - `g = diag(|det g|,1,…)·s` with `s ∈ ker|det| ⊆ N`.
  - `σ_n^(±1) s σ_n^(∓1) ∈ N`, since `N` is normal. So `σ̄^(±1) Ḡ σ̄^(∓1) = Ḡ`, acting as `σ` through `|det|`.
- *The quotient.* `K_n^0/N`, generated by the conjugates of `Ḡ`, is `Ḡ ≅ Q_>0/I_n`. The degree splitting gives
  `K_n/N ≅ (Q_>0/I_n) ⋊_σ Z`.
  - The base is cyclic on `2 = |det e|`, since `Q_>0 = ⊕ p_k^Z = Z[t^±]·2`. ✓
- *The normal generators.* `N = ⟨⟨x_12(1), diag(−1,1,…)⟩⟩`: the `x_ij(±1)` and `diag(−1,1,…)` generate `GL_n(Z)`,
  and each `x_ij(1)` is conjugate to `x_12(1)` by a permutation matrix in `GL_n(Z)`. ✓

## Item 4: Bieri–Strebel and the translation (the author asked about this)
- *Finite presentation passes to the quotient.* `N` is the normal closure of finitely many elements. So `K_n`
  finitely presented implies `G = K_n/N` finitely presented, and `χ` is onto.
- *The HNN is ascending.* Suppose `C ≠ B` and `D ≠ B`.
  - In the Bass–Serre tree, the edge `[B, tB]` has stabilizer `B ∩ tBt^(−1) = D = tCt^(−1)`, which is proper on both
    sides.
  - Two adjacent vertex groups generate their amalgam over the edge group. So `b b'` with `b ∈ B ∖ D` and
    `b' ∈ tBt^(−1) ∖ D` does not commute with `b' b`: `[b, b']` is reduced of length 4.
  - The normal closure of `B` in the HNN is `ker χ`, since `χ(B) = 0` and `χ(t) = 1`, and `ker χ = M` is abelian.
    Contradiction. ✓
- *`M` is finitely generated on one side.* If `D = B`, then `t^(−1)Bt = C ⊆ B`.
  - The union `∪_(i≥0) t^i B t^(−i)` is increasing, normalized by `t^(±1)` and by `B`, and contains `B`. So it is
    `ker χ`, and `M = Z[t]·B`.
  - The convention matches: `t` acts through `σ̄(·)σ̄^(−1)`, which is the module action `t = σ`. ✓
- *The translation.* `M = Z[t]{b_1..b_s}` with each `b_i` a finite Laurent combination of the `t^j m_0`. So
  `M = Σ_(j≥−K) Z t^j m_0`, and `t^(K+1)` gives `m_0 = Σ_(j≥1) a_j t^j m_0`.
  - That is, `2/r ∈ I_n` with `r = Π_(j≥1) p_j^(a_j)`, `a_j ∈ Z`. Equivalently `diag(2/r,1,…) = e·diag(r,1,…)^(−1) ∈ N`.
  - The converse follows by induction on `k` for `t^(−k) m_0`. The `Z[t^(−1)]` case is the mirror image.
- *The contrapositive.* `2/r` has exponent 1 at `p_0 = 2`, because `r` avoids `p_0`. So it is not a square. ✓

## Item 6: `K_n'`
- *The content map.* `v_p(c(w)) = min v_p(w_i)` and `v_(σ(p))(σ(x)) = v_p(x)`. These give `c(σ_n^(±1)w) = σ^(±1)c(w)`,
  `c(2^(±1)w) = 2^(±1)c(w)` and `c(gw) = c(w)`.
  - The maps `r ↦ aσ^m(r)` are closed under composition: `aσ^m ∘ bσ^(m') = aσ^m(b)σ^(m+m')`.
  - Their parameters are recovered at `r = 1`, and then from `σ^m(2)`. `c` is onto, since `c(r e_1) = r`. So
    `ψ : K_n' ↠ Γ ≅ Z[t^±] ⋊ Z = Z≀Z`.
- *The quotient is `Z≀Z`.* `s^j a s^(−j) = p_j I`, and scalars commute. So `K_n'/⟨⟨GL_n(Z)⟩⟩` is a quotient of
  `⟨a, s | [a, s^j a s^(−j)]⟩ = Z≀Z`. The composite with `ψ` is the identity on generators, so it is an
  isomorphism. ✓
- *`K_n'` is not finitely presented.* This uses Baumslag's theorem that `Z≀Z` is not finitely presented, together with
  `GL_n(Z)` being finitely generated.
- *`e ∉ K_n'`.* `e_1` and `e_2` have content 1, while `ee_1` has content 2 and `ee_2` has content 1. ✓

## 0. Summary

`quadrangle-closed-patterns-do-not-force-domination` builds the rotation-pointer gadget. It satisfies
(L), (R) and (Q), fails (H), and reaches `Phi -> 0` by coupon-collector amplification: `R` gadgets each
decode the same site `o` by a linear combination of their own rows. Its §7.4 asks whether (L), (R),
(Q) and (H) force domination.

`coset-local-decoders-force-gated-domination` kills gadget-local amplification in **groups** by coset
projection in `F_q[G]`. This note proves the same kill on **abstract patterns**, using only (L), (R),
(Q) and (H). There is no group and no group ring of the host.

**Theorem A (pattern-level coset projection).** Let a finite pattern satisfy (L), (R), (Q) and (H), with
a split `E = U ⊔ V` of positions into pointer and value positions, and a value functional
`T : V -> F_q`. For every site `o`:
1. at most one gadget (maximal set of rows with a common pointer site set) has a local decoder of `o`;
2. that decoder is unique;
3. if it exists, `T` is supported in one component of the value graph `Γ`, and its pushforward `T_C` is a
   unit of the finite group algebra `F_q[Π]`, where `Π` is generated by the within-gadget pointer
   permutations.

**Corollary B (class kill).** Take rotation-type codes, `y_c = (j_c, Σ_{e∈V} T_e x(ce)[j_c])`, where `j_c`
depends only on the pointer inputs and is constant on gadgets. Suppose every recovery of a coordinate of
`x(o)` is gadget-local, and `o` is not a pointer site. Then at most one coordinate of `x(o)` is
recovered in expectation, and `Phi >= log q`. So the coupon-collector amplification of the rotation gadget
has **no (H)-respecting repair**.

- **Invariant:** unit-ness of the pushed-forward gadget decoder `s_ρ` in `F_q[Π]`.
- **Step where every member dies:** Step 5 of §4. Two gadgets decoding `o` induce the same weighted
  partition of the same reader positions, so both read `o` at a common position with different rows,
  which violates (R).

**Scope.** Mixed decoders, which combine rows with different pointer site sets, are not covered. This is
the same survivor as item 3 of Corollary 4 of the group theorem, now forced at pattern level.

## 1. Setting

The pattern, (L), (R), (Q), classes `R(c, c')` and (H) are as in §1 of
`research/artifacts/quadrangle-closed-pattern-firewall-2026-09-17.md`.
- The row set `F` is arbitrary, and the position set `E` is finite.
- (H) quantifies over composites of classes, including `R(c', c) = R(c, c')^{-1}`.

**Split and gadgets.** Fix a partition `E = U ⊔ V`, the pointer and value positions.
- Rows `c, c'` are **pointer-equivalent** when `cU = c'U` as sets of sites.
- A **gadget** is a pointer-equivalence class. Distinct gadgets are disjoint.
- For a gadget `ρ`, write `ρV = {ce : c ∈ ρ, e ∈ V}`.

**Local decoders.** Work in the free vector space `F_q[S]` on the sites. A **local decoder** of the
site `o` in gadget `ρ` is a `σ : ρ -> F_q`, finitely supported, with

    Σ_{c∈ρ} σ_c Σ_{e∈V} T_e [ce] = [o].                                              (D)

In the rotation gadget, `T ≡ 1` on `V`, `q = 2` and `σ = (1, 1, 1)` satisfies (D) for every gadget `ρ`.

We assume `U != ∅`. With `U = ∅` all rows form one gadget and "local" is no restriction.

## 2. Structure lemmas

Write `c ~ c'` for pointer-equivalence.

**Lemma 1 (split classes).** Let `c ~ c'`. Then `R(c, c') = graph(π_{c,c'}) ⊔ ν_{c,c'}`, where
`π_{c,c'} ∈ Sym(U)` and `ν_{c,c'} ⊆ V × V` is a partial injection. Moreover:
- `π_{c,c} = 1` and `π_{c,c''} = π_{c',c''} π_{c,c'}` whenever `c ~ c' ~ c''`;
- `π_{c,c'} = 1` iff `c = c'`.

*Proof.*
1. Let `u ∈ U`. Since `cu ∈ cU = c'U`, there is `u' ∈ U` with `cu = c'u'`, and `u'` is unique by (L). This
   defines `π_{c,c'} : U -> U`. It is injective by (L) for `c`, so it is a bijection of the finite set `U`.
2. No mixed pairs. Suppose `ce = c'u'` with `e ∈ V` and `u' ∈ U`. Then `ce ∈ c'U = cU`, so `ce = cu` for
   some `u ∈ U`. Since `u != e`, this contradicts (L). The case `e ∈ U`, `e' ∈ V` is symmetric.
3. The value part `ν_{c,c'} = R(c, c') ∩ (V × V)` is a partial injection by (L) for `c` and `c'`.
4. Composition. `cu = c'π_{c,c'}(u) = c''π_{c',c''}π_{c,c'}(u)`. Then `π_{c,c} = 1` by (L).
5. If `π_{c,c'} = 1`, pick `u ∈ U`. Then `cu = c'u`, so `c = c'` by (R). □

Let `Σ = {π_{c,c'} : c ~ c'}` and let `Π = <Σ> <= Sym(U)`, a **finite** group. Let `Γ` be the directed
labelled graph on `V` with an edge `e -> e'` of label `π_{c,c'}` for each `(e, e') ∈ ν_{c,c'}` with
`c ~ c'`.
- Edges come in reverse pairs: `(e', e) ∈ ν_{c',c}`, with label `π_{c',c} = π_{c,c'}^{-1}`.
- The **components** of `Γ` are its connected components.
- A walk `e_0 -> e_1 -> ... -> e_r` through edges of labels `λ_1, ..., λ_r` has label `λ_r ... λ_1`.

**Lemma 2 (global value potential; uses (H)).**
- Every closed walk in `Γ` has label 1.
- So for each component `C` with a fixed base point `b_C ∈ C`, there is a unique map `φ : C -> Π` with
  `φ(b_C) = 1` and `φ(e') = λ φ(e)` for every edge `e -> e'` of label `λ`.
- `φ` is injective on `C`.

*Proof.*
1. Take a walk with steps `(e_{i-1}, e_i) ∈ ν_{c_i,c_i'}`, and put
   `Z = R(c_r, c_r') ∘ ... ∘ R(c_1, c_1')`, a composite of classes.
   - `Z` is a partial injection with `e_0 ∈ dom Z` and `Z(e_0) = e_r`.
   - By Lemma 1 each factor maps `U` bijectively onto `U` by its pointer part. So `U ⊆ dom Z`, and `Z`
     restricted to `U` is the walk label `λ`.
2. Closed walk. `Z` fixes `e_0`. By (H), `Z` is the identity on `dom Z ⊇ U`, so `λ = 1`.
3. So `φ(e)`, the label of any walk from `b_C` to `e`, is well defined and satisfies the edge rule. The
   walk from `e` to `e'` has label `φ(e') φ(e)^{-1}`.
4. Injectivity. Suppose `φ(e) = φ(e')`. A walk from `e` to `e'` has label 1, so its composite `Z` fixes
   every point of `U != ∅`. By (H), `Z` is the identity on `dom Z ∋ e`, so `e' = Z(e) = e`. □

The potentials use one global graph for all gadgets. Walks may alternate between classes of different
gadgets. This is where (H) is used across gadgets.

**Lemma 3 (global value relations; uses (Q)).** Suppose `c ~ c'`, `d ~ d'` and
`π_{c,c'} = π_{d,d'} = g`. Then `ν_{c,c'} = ν_{d,d'}`. Write `D_g` for this common partial injection of `V`.

*Proof.*
- If `g = 1`, then `c = c'` and `d = d'` by Lemma 1, and both value parts are the diagonal of `V`.
- Otherwise `c != c'` and `d != d'`. Pick `u ∈ U`. The pair `(u, g(u))` lies in `R(c, c') ∩ R(d, d')`.
- By Lemma 1.1 of the firewall artifact, the two classes are equal, so their value parts agree. □

**Lemma 4 (site coordinate).** Fix a gadget `ρ`, a base row `c_ρ ∈ ρ`, and put `γ_c = π_{c_ρ,c}` for
`c ∈ ρ`. Then:
- `π_{c,c'} = γ_{c'} γ_c^{-1}`;
- `c -> γ_c` is injective on `ρ`, so `|ρ| <= |Π|`;
- for a site `s ∈ ρV`, pick `c ∈ ρ` and `e ∈ V` with `ce = s`. The component `C(s)` of `e` and the element
  `κ_ρ(s) = γ_c^{-1} φ(e) ∈ Π` do not depend on the choice.

*Proof.*
- The first two items are Lemma 1.
- If `ce = c'e'` with `c, c' ∈ ρ` and `e, e' ∈ V`, then `(e, e')` is an edge of label `γ_{c'} γ_c^{-1}`.
  So `C(e) = C(e')` and `γ_{c'}^{-1} φ(e') = γ_c^{-1} φ(e)`.
- Rows of `ρ` never read a site of `ρV` at a pointer position, by step 2 of Lemma 1. □

## 3. Pushforward: a local decoder is a unit of `F_q[Π]`

For `a ∈ F_q[Π]` write `a(g)` for the coefficient of `δ_g`. For a component `C` put
`T_C = Σ_{e ∈ C} T_e δ_{φ(e)}`. Since `φ` is injective, `T_C(φ(e)) = T_e` for `e ∈ C`, and `T_C(g) = 0`
for `g ∉ φ(C)`.

**Proposition 5.** Let `σ` be a local decoder of `o` in gadget `ρ`, and put
`s_ρ = Σ_{c∈ρ} σ_c δ_{γ_c^{-1}}`. Then:
1. `o ∈ ρV`;
2. `s_ρ T_{C(o)} = δ_{κ_ρ(o)}`, and `s_ρ T_C = 0` for every other component `C`;
3. `s_ρ` and `T_{C(o)}` are units of `F_q[Π]`, `s_ρ = δ_{κ_ρ(o)} T_{C(o)}^{-1}`, and `T` vanishes
   outside `C(o)`;
4. `σ` is the only local decoder of `o` in `ρ`.

*Proof.*
1. The left side of (D) is supported in `ρV`.
2. Define the linear map `P : F_q[ρV] -> ⊕_C F_q[Π]` by `[s] -> δ_{κ_ρ(s)}` in coordinate `C(s)`
   (Lemma 4).
   - For `c ∈ ρ` and `e ∈ V`, `P[ce] = δ_{γ_c^{-1}} δ_{φ(e)}` in coordinate `C(e)`.
   - So `P` of the left side of (D) is `(s_ρ T_C)_C`, and `P[o] = δ_{κ_ρ(o)}` in coordinate `C(o)`.
3. Put `b = T_{C(o)} δ_{κ_ρ(o)^{-1}}`, so that `s_ρ b = 1`.
   - `F_q[Π]` is finite-dimensional, so `x -> s_ρ x` is surjective, hence injective.
   - Since `s_ρ (b s_ρ - 1) = 0`, we get `b s_ρ = 1`.
   - So `s_ρ` is a unit, `T_{C(o)} = s_ρ^{-1} δ_{κ_ρ(o)}` is a unit, and `T_C = s_ρ^{-1} · 0 = 0` for
     `C != C(o)`.
4. Another local decoder `σ'` gives `s' T_{C(o)} = δ_{κ_ρ(o)}`, so `s' = s_ρ`.
   - The data `κ_ρ(o)`, `C(o)` and `T_{C(o)}` depend only on `o`, `T` and the fixed base choices.
   - `σ -> s_ρ` is injective because `c -> γ_c^{-1}` is injective (Lemma 4). □

In a group this is Lemma 1(a) of `coset-local-decoders-force-gated-domination`. The gadget is the
coset, and `Π` is the finite stabilizer. Here `Π` is built from the pattern alone, via (L) and (H).

## 4. Proof of Theorem A

Items 2 and 3 are Proposition 5. For item 1, suppose gadgets `ρ != ρ'` have local decoders `σ` and `σ'`
of `o`. Put `p = κ_ρ(o)` and `p' = κ_{ρ'}(o)`. Primed symbols (`γ'`, `s_{ρ'}`) refer to `ρ'` and its
base row.

**Step 0 (common component).** By Proposition 5.3 for both gadgets, `T` vanishes outside `C(o)` computed
in `ρ`, and outside `C(o)` computed in `ρ'`. Also `T != 0`, since `s_ρ T_{C(o)} != 0`. So the two
components share a point of `supp T` and are equal. Call it `C`, and put `τ = T_C`, a unit. Then
`s_ρ = δ_p τ^{-1}` and `s_{ρ'} = δ_{p'} τ^{-1}`.

**Step 1 (readers).** Define `w(x) = τ^{-1}(x) τ(x^{-1})` for `x ∈ Π`, and `X = {x : w(x) != 0}`. For
`x ∈ X`:
- `e_x = φ^{-1}(x^{-1}) ∈ C` exists, because `τ(x^{-1}) != 0`;
- `s_ρ(px) = τ^{-1}(x) != 0` and `supp s_ρ ⊆ {γ_c^{-1} : c ∈ ρ}`. So there is a unique `c_x ∈ ρ` with
  `γ_{c_x} = x^{-1} p^{-1}`, and `σ_{c_x} = τ^{-1}(x)`;
- likewise there is a unique `d_x ∈ ρ'` with `γ'_{d_x} = x^{-1} p'^{-1}` and `σ'_{d_x} = τ^{-1}(x)`.

The positions `e_x` and the weights `w(x)` depend only on `T` and `φ`, not on the gadget.

**Step 2 (all nonzero terms at the fiber of `o`).** Let `N_ρ` be the set of incidences `(c, e) ∈ ρ × C`
with `γ_c^{-1} φ(e) = p` and `σ_c T_e != 0`. Then `x -> (c_x, e_x)` is a bijection `X -> N_ρ`, with
`σ_{c_x} T_{e_x} = w(x)`.
- *Into.* `γ_{c_x}^{-1} φ(e_x) = p x x^{-1} = p`, and `σ_{c_x} T_{e_x} = τ^{-1}(x) τ(x^{-1}) = w(x) != 0`.
- *Onto.* Let `(c, e) ∈ N_ρ` and put `x = φ(e)^{-1}`. Then `γ_c^{-1} = px`, so
  `σ_c = s_ρ(px) = τ^{-1}(x)` and `T_e = τ(x^{-1})`. Hence `w(x) = σ_c T_e != 0`, `x ∈ X`, `e = e_x`
  and `c = c_x`.
- *Injective.* `x -> e_x` is injective.

By Lemma 4, every incidence `(c, e) ∈ ρ × V` of a site `s` with `C(s) = C` and `κ_ρ(s) = p` lies in
`ρ × C` and has `γ_c^{-1} φ(e) = p`. So for such `s`, the coefficient of `[s]` on the left of (D) is

    Σ_{x ∈ X : c_x e_x = s} w(x).                                                    (W)

The same holds for `ρ'`, with `d_x` and `p'`.

**Step 3 (the same partition; uses Lemma 3).** Define `x ≈_ρ x'` iff `c_x e_x = c_{x'} e_{x'}`. Let
`x != x'`.
- Then `c_x != c_{x'}`, and `π_{c_x,c_{x'}} = γ_{c_{x'}} γ_{c_x}^{-1} = x'^{-1} p^{-1} p x = x'^{-1} x`.
- By Lemma 1, `c_x e_x = c_{x'} e_{x'}` iff `(e_x, e_{x'}) ∈ ν_{c_x,c_{x'}} = D_{x'^{-1}x}`.
- For `ρ'`, `π'_{d_x,d_{x'}} = x'^{-1} p'^{-1} p' x = x'^{-1} x` as well. So `x ≈_{ρ'} x'` iff
  `(e_x, e_{x'}) ∈ D_{x'^{-1}x}`.
- By Lemma 3, `D_{x'^{-1}x}` is the same relation for both gadgets. So `≈_ρ = ≈_{ρ'}`; call it `≈`.

**Step 4 (the same weighted class).**
- Each `≈_ρ`-class `K` is the set of `x ∈ X` with `c_x e_x = s` for one site `s`, and that site has
  `C(s) = C` and `κ_ρ(s) = p`.
- By (D) and (W), `Σ_{x∈K} w(x)` is 1 if `s = o` and 0 otherwise.
- The class `X_ρ = {x ∈ X : c_x e_x = o}` has weight `1 != 0`. So it is nonempty, and it is the **only**
  class of `≈` with nonzero total weight.
- By the same argument for `ρ'`, `X_{ρ'} = {x ∈ X : d_x e_x = o}` is the only class of `≈` with nonzero
  total weight.
- The partition and the weights are the same, so `X_ρ = X_{ρ'}`.

**Step 5 (death at (R)).** Pick `x ∈ X_ρ = X_{ρ'}`. Then `c_x e_x = o = d_x e_x` with `c_x ∈ ρ` and
`d_x ∈ ρ'`. Distinct gadgets are disjoint, so `c_x != d_x`. This contradicts (R) in column `e_x`. □

**Remark (the readers are intrinsic).** Steps 1-4 show that the positions at which any local decoder of `o`
reads `o` with nonzero weight, `{e_x : x ∈ X_ρ}`, are determined by `T`, `φ` and `≈`. Two gadgets would
have to place different rows in these same columns.

## 5. Corollary B: gadget-local amplification is dead under (H)

**Model.**
- Inputs `x(s)` are iid uniform on `F_q^k` over the sites.
- Pointer and value sites are disjoint: `FU ∩ FV = ∅`, and `o ∈ FV`.
- Row `c` outputs `y_c = (j_c, Σ_{e∈V} T_e x(ce)[j_c])`, with `T : V -> F_q` fixed.
- `j_c ∈ {1..k}` is a function of the pointer inputs `x(cU)` that is constant on each gadget, for example
  a symmetric function of the pointer multiset, as in the rotation gadget.
- **Locality hypothesis.** Suppose that, given the pointer inputs `P = (x(s))_{s∈FU}`, the coordinate
  `x(o)[i]` is a function of `y_F`. Then some local decoder of `o`, in some gadget, is supported on rows
  with `j_c = i`.

The rotation gadget satisfies the model with `q = 2`, `T ≡ 1` and `σ = (1, 1, 1)`, and it violates (H).

**Corollary B.** If the pattern satisfies (L), (R), (Q) and (H), then `H(x(o) | y_F) >= (k - 1) log q`
and `Phi = (1/k)[H(y_c) + H(x(o) | y_F)] >= log q`.

*Proof.*
1. `P` is independent of the value inputs. Given `P`, the value part of `y_c` is a linear function of
   the slice `(x(s)[j_c])_{s ∈ FV}`. Distinct coordinates `i` use independent slices.
2. So `H(x(o) | y_F, P) = Σ_i (1 - r_i) log q`, where `r_i = 1` iff `x(o)[i]` is determined by the
   slice-`i` observations. For a uniform vector `z` and observations `Mz`, the coordinate `z_o` is either
   determined or uniform.
3. By locality and Theorem A.1, `r_i = 1` forces `i = j_{ρ(o)}`, where `ρ(o)` is the unique gadget with a
   local decoder of `o`. So `Σ_i r_i <= 1` pointwise, and
   `H(x(o) | y_F) >= H(x(o) | y_F, P) >= (k - 1) log q`.
4. If `T != 0`, the value part of `y_c` is uniform given `P`, because the sites `ce` are distinct by
   (L). So `H(y_c) >= log q`. If `T = 0`, there are no decoders and `H(x(o) | y_F) = k log q`.
   Either way `Phi >= log q`. □

The same union bound gives `E Σ_i r_i <= Σ_i P(j_{ρ_i(o)} = i)` when the functional depends on the
coordinate, `T = T^{(i)}`. This is the pattern analogue of Theorem 2 of the group note.

**Class killed.**
- Members: every (H)-respecting modification of the rotation-pointer gadget, and more generally every
  split gated linear code on an (L)(R)(Q)(H) pattern whose recoveries are gadget-local, for any gadget
  size, any `Π` and any functional `T`.
- **Invariant:** unit-ness of `s_ρ` in the finite algebra `F_q[Π]` (Proposition 5.3).
- **Step where every member dies:** Step 5 of §4. The second gadget must read `o` in the same columns
  `e_x` with different rows, which (R) forbids.

## 7. Where it stops

1. **Mixed decoders.** A decoder `σ` supported on rows with different pointer site sets is not covered.
   - Proposition 5 needs one gadget, so that `γ` lands in a single coset structure.
   - With mixed support, cross-gadget cancellations can occur. The pointer parts of different gadgets
     interact only through (Q) on common sites, and Lemma 1 no longer applies.
   - This is the survivor already isolated in Corollary 4.3 of
     `coset-local-decoders-gated-domination-2026-09-17.md`. The group and pattern pictures now agree on
     the survivor.
2. **Unsplit or nonlinear codes.**
   - Theorem A is about split positions and linear value functionals.
   - Pointer-dependent functionals `T = T(P)` are covered by applying Theorem A for each value of `P`.
     Nonlinear value maps are not covered.
3. **Refined question, narrowed.**
   - Question §7.4 of `quadrangle-closed-pattern-firewall-2026-09-17.md` asks whether (L)(R)(Q)(H)
     force domination for the window-transport amplification.
   - That question is still OPEN. For split gated linear codes it is now equivalent to a question about
     mixed-pointer decoders only.
   - Any amplification firewall that respects (H) must decode across gadgets.
4. **(H) versus realizability.**
   - (H) is decidable by a BFS on position pairs.
   - Realizability of a pattern in a group reduces to word-problem instances, which is Evans-type. For
     a general class of groups we use no decision procedure for it.
   - Theorem A uses only (H), never its row dual (H*). The artifact does not use or claim any relation
     between (H) and (H*).

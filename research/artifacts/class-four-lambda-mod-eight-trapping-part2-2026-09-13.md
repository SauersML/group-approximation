## 4. Quaternionic Grassmannians

For k, d >= 1 put n = k + 2d and G = G(k, d) = Gr_k(H^n) =
Sp(n)/(Sp(k) x Sp(2d)). Let zeta be the tautological quaternionic k-plane
bundle, viewed as a complex bundle of rank 2k with c_1(zeta) = 0, and put
q_1 = c_2(zeta). Then dim_R G = 4k·2d = 8kd.

**Lemma 4.1.** (i) G is closed and 3-connected, so it is simply connected
and spin. H^4(G; Z) ≅ Z is generated by q_1.
(ii) <c_{2k}(zeta)^{2d}, [G]> = ±1.

*Proof.* (i) The Schubert cells of Gr_k(H^n) have real dimensions 4|mu| for
partitions mu in the k x 2d box. So there are no cells in dimensions 1, 2
and 3, and exactly one 4-cell. Its dual class is ±q_1.

(ii) By Borel, H^*(Gr_k(H^n); Z) = Z[q_1, ..., q_k, q'_1, ..., q'_{2d}]/(q·q' = 1),
where q_i = ±c_{2i}(zeta) has degree 4i and q' is the analogous class of the
complement. H^*(Gr_k(C^n); Z) has the same presentation, with c_i of the
tautological bundle in degree 2i. So doubling degrees gives a ring
isomorphism that sends q_k to ±c_k(zeta_C) = ±sigma_{1^k}. On
Gr_k(C^{k+2d}), Pieri's rule gives sigma_{1^k}·sigma_mu = sigma_{mu+(1^k)}
for mu in the k x 2d box, since adding a vertical strip of length k to a
partition with at most k rows adds one box to every row. So
sigma_{1^k}^{2d} = sigma_{(2d)^k}, which is the class of a point. The
isomorphism carries top classes to top classes up to sign. □

**Lemma 4.2 (defect).** Put Q_G = d·zeta, of complex rank 2kd, and
W_G = Hom(Q_G, C^2) ≅ 2d·zeta*. Then rank_R W_G = 8kd = dim_R G, the virtual
bundle TG − W_{G,R} is spin, and

    lambda(TG) − lambda(W_{G,R}) = k·q_1   in H^4(G; Z).

In particular, if 8 divides k, then TG − W_{G,R} carries a Spin_8-structure.

*Proof.* The tangent space at V is Hom_H(V, V^⊥). So
TG (+) Hom_H(zeta, zeta) ≅ Hom_H(zeta, H^n). For quaternionic bundles A and B,
Hom_H(A, B) (x)_R C ≅ Hom_C(A, B). On fibres, both sides are the
representation C^{2a} (x) C^{2b} of Sp(a) x Sp(b), because C^{2a} is
self-dual. For a real bundle V, p_1(V) = −c_2(V (x) C). For complex bundles
A, B of ranks alpha, beta with c_1 = 0,
c_2(A* (x) B) = beta·c_2(A) + alpha·c_2(B). Therefore

    c_2(Hom_C(zeta, C^{2n})) = 2n·q_1,   c_2(End_C zeta) = 4k·q_1,
    p_1(TG) = −(2n − 4k)·q_1.

Also W_{G,R} (x) C ≅ 2d·zeta* (+) 2d·zeta, whose c_2 is 4d·q_1, so
p_1(W_{G,R}) = −4d·q_1. Both bundles are spin: G is 3-connected, and
w_2(W_{G,R}) = c_1(W_G) mod 2 = 0. H^4(G; Z) is torsion-free, so
lambda = p_1/2 for both. This gives lambda(TG) = −(n − 2k)·q_1 =
−(2d − k)·q_1 and lambda(W_{G,R}) = −2d·q_1. Their difference is k·q_1. □

*Checks.* For k = 1, G = HP^{2d} and lambda(TG) = −(2d − 1)·q_1. This is
p_1(HP^m) = 2(m − 1)·u with m = 2d and u = −q_1 (Borel–Hirzebruch). The same
computation for Toms's G = Gr_k(C^{k+2d}), with k even, gives the defect
(1 − k/2)·c_1^2 + k·c_2. For k = 2 that is 2·c_2. No even k makes it vanish
mod 8, because the two coefficients cannot both be divisible by 8.

## 5. The tower

Put M = T^3 x S^3 and k = 8. Start with X_1 = point, Q_1 = 0 and r_1 = 0.
For i >= 1 put

    Y_i = M x X_i,   E_i = C^2 (+) Q_i,   A_i = Gamma(End E_i),   N_i = 2 + r_i.

So A_1 = C(T^3 x S^3, M_2). Choose finite sets
F_i = {z_{i,1}, ..., z_{i,m_i}} ⊂ Y_i such that alpha_{j,i}(F_i) is 1/i-dense
in Y_j for all j <= i. Here alpha_{j,i}: Y_i -> Y_j is the coordinate
projection. Put V_{i,l} = E_i|_{z_{i,l}} ≅ C^{N_i}, d_i = m_i N_i and
G_i = G(8, d_i) with tautological bundle zeta_i. Then define

    X_{i+1} = X_i x G_i,
    Q_{i+1} = pr^* Q_i (+) (+)_l (V_{i,l} (x) pr^* zeta_i) ≅ pr^* Q_i (+) d_i·pr^* zeta_i,
    phi_i(a) = alpha_i^* a (+) (+)_l ( a(z_{i,l}) (x) 1_{zeta_i} ).

Then E_{i+1} = alpha_i^* E_i (+) (+)_l V_{i,l} (x) zeta_i, with the protected
C^2 inside the first summand. Each phi_i is a unital injective
*-homomorphism A_i -> A_{i+1}.

**Lemma 5.1.** For every i: dim_R X_i = 4 r_i; the virtual bundle
TX_i − W_{i,R}, where W_i = Hom(Q_i, C^2), carries a Spin_8-structure tau_i;
and <c_{r_i}(Q_i)^2, [X_i]> = ±1.

*Proof.* At i = 1 everything is trivial. Suppose the claims hold for i. Then
r_{i+1} = r_i + 16 d_i and dim_R X_{i+1} = 4r_i + 64 d_i = 4 r_{i+1}. Also
W_{i+1} = pr^* W_i (+) pr^* W_{G_i}, so

    TX_{i+1} − W_{i+1,R} = pr^*(TX_i − W_{i,R}) (+) pr^*(TG_i − W_{G_i,R}),

and tau_{i+1} is the sum of tau_i with the structure of Lemma 4.2. Finally
c_{r_{i+1}}(Q_{i+1}) = pr^* c_{r_i}(Q_i)·pr^* c_16(zeta_i)^{d_i}. Its square
integrates over X_i x G_i to the product of the two numbers, which is ±1 by
induction and Lemma 4.1(ii). □

**Unitaries.** In A_1, with coordinates (s_1, s_2, s_3, z) on T^3 x S^3, put
u_j = alpha o s_j for j = 1, 2, 3 and v = omega o z. Their nested commutator
is c_4 o pr_M. In A_i put w_i = (c_4 o pr_M) (+) 1_{Q_i}.

**Lemma 5.2.** phi_i(w_i) is homotopic to w_{i+1} in U(A_{i+1}), so
phi_{1,j}(w_1) is homotopic to w_j.

*Proof.* This is Toms Lemma 6.2, and CT3 Lemma 5.1. The coordinate summand
of phi_i(w_i) is w_{i+1}. Each evaluation summand is
w_i(z_{i,l}) (x) 1_{zeta_i}. It joins 1 through a path in the connected
group U(V_{i,l}). □

**Lemma 5.3.** w_i is not in U_0(A_i), for every i.

*Proof.* Apply Part 1, Proposition 2.1 with M = T^3 x S^3 (Lie framing),
X = X_i, Q = Q_i and tau = tau_i. It gives
nu^{M,8}(w_i) = ±[T^3 x S^3, c_4]_red and nu^{M,8}(1) = 0. The class is
nonzero by Part 1, Proposition 3.1. The invariant is constant on path
components. □

**Proposition 5.4.** A = lim (A_i, phi_i) is simple.

*Proof.* This is Toms Proposition 6.4, and CT3 Proposition 6.1. Only density
of the evaluation sets is used. A nonzero positive a in A_i is nonzero at some
point alpha_{i,j}(z) with z in F_j. Then phi_{i,j+1}(a) contains the block
phi_{i,j}(a)(z) (x) 1, which is nonzero in every fibre, so it is full. Toms
Lemma 6.3 applies. □

**Proof of the Theorem.** A is a unital injective limit of homogeneous
algebras over finite CW complexes. So it is separable, unital, nuclear, AH and
infinite-dimensional. It is simple by Proposition 5.4. It is stably finite
because a tracial state exists by compactness and is faithful by simplicity.
Let c be the image of w_1 = [u_3, [u_2, [u_1, v]]]. If c were in U_0(A), then
Toms Lemma 7.1 would give some j with phi_{1,j}(w_1) in U_0(A_j). By Lemma
5.2, w_j would be in U_0(A_j). That contradicts Lemma 5.3.

*Order two.* [cbar_4] = 6 nu' has order two in pi_6(S^3) ≅ Z/12. So c_4^2
is homotopic to 1, and c^2 is in U_0(A). *K_1 and M_2*: as in CT3 Section 7.
The element c is a commutator, so [c]_1 = 0. Elements diag(x, 1) commute
modulo U_0(M_2(A)), so diag(c, 1) is in U_0(M_2(A)). □

## 6. Remarks

- *Excess.* dim Y_i − 2 rank E_i = 6 + 4r_i − 2(2 + r_i) = 2 + 2r_i. That is
  unbounded, and at least two, as the excess bound requires
  (`block-component-group-class-at-most-excess-plus-two`).
- *Why the earlier string attempt failed.* It asked for a string X and for
  p_1(Q_R) = 0 separately, and the Wu formula killed rank two. The detector
  needs a structure only on the difference TX − W_R, and only mod 8. Wu
  gives no obstruction there. The quaternionic Grassmannians realize it.
- *Seeing all of pi_3^s.* By Part 1, the kernel of pi_3^s -> Omega^8_3 lies in
  {0, 8 nu, 16 nu}. With k = 24, Lemma 4.2 gives defect 24·q_1. The
  analogous Spin_24 detector then sees pi_3^s ≅ Z/24 whole.
- *Class five with rank-two protected blocks.* Consider seeds that factor
  through one sphere collapse onto S^3 = SU(2). At depth four their stable
  images are eta^a (2 nu)^b with a + b = 4 (CF4 attempts). All of these are
  zero in pi_*^s: eta^4 = 0, eta·nu = 0, and (2 nu)^4 = 16 nu^4 = 0 in
  pi_12^s = 0. Every trapped bordism class is the image of the stable
  preimage class under a unit map S -> MG. So no trapping detector sees
  depth four for such seeds. Class five needs larger protected blocks,
  non-spherical seeds, or an unstable detector.

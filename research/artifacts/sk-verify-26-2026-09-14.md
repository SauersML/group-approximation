## 2. Re-derived by hand

- **Metric facts.**
  - d is invariant under left and right multiplication and satisfies the triangle inequality.
  - d(a,b) = 1 − fpr(b⁻¹a).
  - A gap δ is equivalent to distinct elements of H_N being at distance ≥ δ.
- **(gap ⇒ LEF), steps 1–4.**
  - The defect x_N = σ_N(gh)⁻¹σ_N(g)σ_N(h) lies in H_N, since H_N is a group.
  - By left invariance fpr(x_N) = 1 − d(σ_N(g)σ_N(h), σ_N(gh)) → 1.
  - P is finite, so for large N the gap forces every defect to be trivial.
  - Injectivity: d(σ_N(g),σ_N(h)) ≥ d(σ_N(h⁻¹g),1) − d(σ_N(h)σ_N(h⁻¹g), σ_N(g)). The first term tends to 1 and the second to 0. h⁻¹g need not lie in F, which is fine because σ_N is defined on all of G.
  - This direction only uses d(σ_N(g),1) bounded away from 0.
- **(LEF ⇒ gap).**
  - φ_N(e) = 1 from the pair (e,e).
  - The regular action of Q_N has gap 1.
  - Relations hold exactly once g, h, gh ∈ F_N.
  - Injectivity gives φ_N(g) ≠ 1, which moves every point.
  - Countability is used for the exhaustion.
- **Gap (A).**
  - Fix(aα) is empty or the coset y₀A^α. If A^α = A, then α = 1 and a ≠ 1, so there is no fixed point. Otherwise the index is ≥ 2. So fpr ≤ 1/2.
  - The maps compose as the holomorph A ⋊ Aut(A) and act faithfully (aα(e) = a).
  - GL_m(F_q) ≤ Aut(F_q^m), so AGL_m(F_q) is covered.
- **Gap (P).**
  - Fixed lines are the lines of the eigenspaces E_λ. These are independent, Σ d_λ ≤ m, and d_λ ≤ m−1 for non-scalar X.
  - The count is an equality: fpr = Σ_λ (q^{d_λ} − 1)/(q^m − 1).
  - f(d) = q^d − 1 is convex with f(0) = 0, so it is superadditive.
  - The maximum over parts ≤ m−1 with total ≤ m: merge all parts except the smallest part t. Then g(t) = f(m−t) + f(t) is convex and maximal at t = 1, giving f(m−1) + f(1).
  - q = 2: only λ = 1 occurs.
  - q ≥ 3: q^{m−1}(q−2) ≥ q(q−2) ≥ 2q−3, since (q−1)(q−3) ≥ 0.
  - PGL_m(F_q) acts faithfully on P^{m−1} for m ≥ 2.
- **Corollary 1.**
  - ψ(s⁻¹) = φ(s⁻¹) follows from the pair (s, s⁻¹).
  - The prefix induction uses pairs (p_{k−1}, w_k) with p_{k−1}, w_k, p_k ∈ B(r).
  - Relators of length ≤ L ≤ r go to φ(e) = 1, so ψ factors through G and is injective on B(r).
- **Corollary 2.**
  - If every defect on B(L) is trivial, then σ_N(e) = 1 (pair (e,e)) and σ_N(s)σ_N(s⁻¹) = 1.
  - Prefix induction on words of length ≤ L then gives a homomorphism ψ_N : S → Sym(Ω_N). It is nontrivial for large N, so it is injective because S is simple, and S would be finite.
  - So for all large N some defect on B(L) is nontrivial, with fpr → 1 uniformly over the finitely many pairs. No gap family can contain it.
- **Corollaries 3–4.** These are specializations. On vectors, a linear x with rank(x − I) = r has fpr = q^{−r}, so the Hamming form of a rank defect is exactly 1 − q^{−r}.

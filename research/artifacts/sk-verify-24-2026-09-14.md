## 2. The comb criterion: PASS

Node `finite-dimensional-combs-generate-popa-algebras`, route `finite-dimensional-combs-generate-popa-algebras-proof` (`requires: []`).

**Definition at source.** Brown–Dykema, arXiv:math/0207005, e-print `pa.tex` l.219–226, read on MSI 2026-09-14: "By definition, a Popa algebra is a unital, simple C$^{*}$-algebra $A$ with the property that for every finite set $\mathfrak{F} \subset A$ and $\epsilon > 0$ there exists a finite dimensional subalgebra $0 \neq B \subset A$ (the inclusion not necessarily unital) with unit $e$ such that $\| [x,e] \| < \epsilon$ for all $x \in \mathfrak{F}$ and for each $x \in \mathfrak{F}$ there exists $b \in B$ such that $\| b - exe \| < \epsilon$." The node's statement matches this definition, and l.219 lies in the introduction, as the node says.

Re-derived:
- **Step 1.** For j ≥ i, e_j commutes with A_j ⊇ A_i.
  - So ρ_j(x)ρ_j(y) = e_jxe_jye_j = e_jxye_j, and ρ_j is a unital *-homomorphism A_i → e_jA_je_j. Its target is finite-dimensional by (C1).
  - (C2) makes ⊕_{j≥i} ρ_j injective, so A_i is RFD, hence QD.
  - A is QD, because the local characterization passes to closures of increasing unions through Arveson extension. It also follows from the Popa property itself.
- **Step 2.** One index i serves all of 𝔉, since the union is increasing.
  - e_i ≠ 0, since a full matrix algebra has a nonzero unit.
  - ‖[x,e_i]‖ = ‖[x−x′,e_i]‖ ≤ 2‖x−x′‖ < 2η/3.
  - ‖e_ixe_i − e_ix′e_i‖ ≤ ‖x−x′‖ < η/3, with e_ix′e_i ∈ B = e_iA_ie_i.
- **Step 3.**
  - If J ∩ A_i = 0 for all i, the quotient map is isometric on every A_i (injective *-homomorphisms are isometric), hence on A by density, so J = 0.
  - For 0 ≠ x ∈ J ∩ A_i, (C2) gives j with e_jxe_j ≠ 0.
  - K = J ∩ D, with D = e_jA_je_j, is a two-sided ideal of D containing e_jxe_j.
  - D is a full matrix algebra, simple as a ring, so K = D ∋ e_j.
  - Then (C3) gives 1 ∈ J.
- **Model tests, re-run.**
  - UHF M_{2^∞} with e_i = 1 ⊗ f: e_i commutes with M_{2^i} ⊗ 1, e_i(x⊗1)e_i = x ⊗ f ≠ 0, and every nonzero projection is full ✓.
  - C ⊕ C with e_i = (1,0): (C2) fails at (0,1), (C3) fails, and A is not simple ✓.

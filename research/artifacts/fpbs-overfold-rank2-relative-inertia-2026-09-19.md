## 1. The counterexample

Work in `F = F(a, b)`. Write `c = a b² a⁻¹` and `B = ⟨b, c⟩`.

**Theorem 1.** Define the following.
- `ρ : B → S3` by `b ↦ (1 2 3)` and `c ↦ (1 2)`.
- `X = ker ρ`.
- `J = ⟨X, a⟩`.

Then `rk B = 2` and `J = F`, so `J ∩ B = B`. Moreover
`rk((J ∩ B) : X) = 2` while `rk(J : X) = 1`. So (RI_B) fails.

*Proof.*
1. **`B` is free on `b, c`.** Its Stallings graph is the base vertex `v` with
   a `b`-loop, together with an `a`-edge from `v` to a vertex `w` that carries
   a `b`-cycle of length 2 through a third vertex. This graph is folded and
   has rank 2. So `ρ` is well defined, and it is onto because
   `(1 2 3)` and `(1 2)` generate `S3`.
2. **`b ∈ J`.** First, `b³ ∈ X ⊆ J`. Next, `c² = a b⁴ a⁻¹` lies in `X`, so
   `b⁴ = a⁻¹ c² a ∈ J`. Hence `b = b⁴ · (b³)⁻¹ ∈ J`.
3. **`J = F`.** From `a, b ∈ J`. In particular `B ≤ J`, so `J ∩ B = B`.
4. **`rk(J : X) = 1`.** It is at most 1 because `J = ⟨X, a⟩`. It is not 0,
   because `X ≠ F`.
5. **`rk(B : X) = 2`.** It is at most 2 since `B = ⟨b, c⟩`. Suppose
   `B = ⟨X, h⟩` for a single `h`. Since `X` is normal in `B`, `B / X = S3`
   would be generated by the image of `h`, so it would be cyclic. It is not.
   ∎

**Why homology is blind.**
- The cokernel of `H_1(X) → H_1(B)` is `B / (X [B, B]) = S3^{ab} = Z/2`.
- So for every prime `p`, the mod-`p` cokernel has dimension at most
  `1 = rk(J : X)`.
- The necessary condition tested by `ri_test.py` in w17 therefore passes
  here, although (RI_B) fails. The 170k-trial evidence cannot see failures
  whose obstruction is a non-abelian quotient.

**Where it uses non-malnormality.** Step 2 conjugates `c² ∈ B` by
`a ∉ B` back into `B`: `a⁻¹ ⟨c⟩ a ≤ B`. So `a⁻¹ B a ∩ B ≠ 1`, and `B` is
not malnormal. Malnormality of `L_j` forbids exactly this move.

**Machine check.** `python3 searchC.py selftest` (output `selftest.txt`)
rebuilds `X` as the kernel cover (rank 7, index 6) and checks `J = F` by
folding. It also finds a hom `J ∩ B = B → S3` that kills `X` and is onto,
by exhaustive backtracking.

## 2. Violations with `J ⊇ B` need an equal-rank overgroup

**Lemma 2.** Let `X ≤ B ≤ F`, all finitely generated, and let
`J = ⟨X, g⟩` with `J ⊇ B`. If `rk(B : X) ≥ 2`, then the following hold.
- `J = ⟨B, g⟩`.
- `rk J ≤ rk B`.
- `J ≠ B`.

For `rk B = 2` it follows that `rk J = 2` and `[J : B] = ∞`.

*Proof.*
1. **`J = ⟨B, g⟩`.** We have `X ≤ B ≤ J = ⟨X, g⟩ ≤ ⟨B, g⟩`.
2. **`J ≠ B`.** If `J = B`, then `g ∈ B` and `B = ⟨X, g⟩`. That gives
   `rk(B : X) ≤ 1`, a contradiction.
3. **`rk J ≤ rk B`.** By step 1, `rk J ≤ rk B + 1`. Suppose equality holds.
   A basis of `B` together with `g` is then a generating set of `J` of size
   `rk J`. Free groups of finite rank are Hopfian, so this set is a basis,
   and `J = B * ⟨g⟩`. The retraction `π : J → B` that kills `g` maps
   `J = ⟨X, g⟩` onto `π(X) = X`, and it maps `J` onto `B`. So `X = B`, a
   contradiction.
4. **The case `rk B = 2`.** `J` contains a free group of rank 2, so
   `rk J ≥ 2`, and step 3 gives `rk J = 2`. If `[J : B] = n` were finite
   with `n > 1`, Schreier's formula would give `rk B = n + 1 > 2`. By
   step 2, `n ≠ 1`, so the index is infinite. ∎

**Consequences.**
- In Theorem 1, the overgroup is `J = F ⊋ B` with `[F : B] = ∞`.
- For `B = L_j`, a violation with `J ⊇ L_j` needs a rank-2 overgroup
  `⟨L_j, g⟩`. `F` is one, since `⟨L_1, b⟩ = F`. It also needs `g` with
  `⟨X, g⟩ ⊇ L_j` while `L_j / X` is not cyclic.
- The hunts below look for exactly this, with `J = ⟨X, g⟩` for short `g`.

## 4. Consequences for (O)

1. **(RI_B) is not a rank-2 theorem.** The w17 next step, "prove (RI_B) for
   `rk B = 2`", is false as stated.
   - A proof of (RI_{L_j}), with constant 1, must use malnormality of `L_j`
     in `F` or the position of `X` inside `L_{j+1}`.
   - Inertia of rank-2 subgroups and strengthened Hanna Neumann hold for
     every rank-2 subgroup, so an argument built only on them dies at
     Theorem 1.
   - Rank-2 Nielsen or Whitehead reductions and mod-`p` homology also hold
     for every rank-2 subgroup, and die the same way.
2. **The two known obstructions have opposite missing inputs.** Rank-3
   malnormal pairs (w17) show that malnormality is not enough. Rank-2
   non-malnormal pairs (here) show that rank 2 is not enough. In all data,
   every combination with **rank 2 and malnormal** has 0 violations
   (356 random malnormal subgroups, `L_1`, `L_2`, and the needed case). The
   invariant that must drive a proof is the conjunction.
3. **Homological evidence is not evidence here.** The 170k-trial homological
   test cannot see any obstruction of the Theorem 1 type. Only the
   non-abelian hunts above test (RI) beyond abelian quotients.
4. **The weak route is intact.** Theorem 1 has ratio exactly 2, so it is
   compatible with `(RI_B, 2)`. Proposition 3 of w17 gives `deep ≥ law / C`
   from `(RI_B, C)`, and the weak form of (O) is enough for the floor route.
   An unbounded rank-2 family would be needed to threaten that. `searchD`
   found none.
5. **Proposed decomposition of (RI_{L_j}).** Each part can fail on its own.
   - (RI-top): the case `J ⊇ L_j`, which by Lemma 2 needs a rank-2
     overgroup `⟨L_j, g⟩` with `⟨X, g⟩ ⊇ L_j`.

     form of (O).

   A counterexample to (RI-mal) would refute every `φ`-free proof. A
   counterexample to (RI-C) would need an unbounded family, which none of
   the searches here produced.

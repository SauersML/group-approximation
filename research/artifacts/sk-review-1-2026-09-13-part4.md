## 1. `root-localization-commutator-is-never-scalar` + `-proof`: PASS

**Index rules.**
- Left multiplication by `fu^{i'}` gives `fu^{i'}E_{a0}(W) = f e_{T^{a+i'}W}u^{a+i'}`, a combination of `E_{a+i',0}(W')`.
- Right multiplication by `f'u^{j'}` gives `E_{a',0}(W)f'u^{j'} = e_{T^{a'}W}(f'∘T^{-a'})u^{a'+j'}`, a combination of `E_{a',-j'}(W'')`.
- So the entries of `X = g sE_ij g^{-1}` have first index `|a+i'| ≤ m` and second index `|j'| ≤ w`.

**Second indices of `k-I`.**
- `Y = -sE_ij` has second index 0.
- The only nonzero column of `Y` is `j`. So `(XY)_{pj} = -X_{pi}s`, a sum of `E_{a'b'}(·)E_{a0}(W) = δ_{b'a}E_{a'0}(·)`, again with second index 0.
- `k-I = X+Y+XY`, so every second index lies in `[-w,w]`, which is strictly inside `[-m,m]`.

**The extreme columns.**
- `E_ab(W')` corresponds to the matrix unit at `(a,b)` times `χ_{W'}`.
- So the columns `(p,±m)` of `κ(x)-I_d` vanish, and `κ(x)` fixes those `2n` basis vectors.
- A scalar `λI_d` fixes a basis vector only if `λ = 1`.

**Uses in the proof.**
- It covers the note's three roots, since `E_00(C)`, `E_10(T^{-1}C)` and `E_{-1,0}(TC)` all have second index 0.
- Case 2 of b965d63ba `thm:root` is vacuous ✓.

**Remark (for sk-simplicity-short-a's all-q route, step 5).** In the constant-tower route the roots are `ε_00` and `ε_{0,-1}`.
- Their second indices are `0` and `-1`.
- The entries of `k-I` then have second index in `[-m, w]`, so column `+m` is never touched.
- By the same argument `k` is never a nonidentity scalar in `H`, so step 5 of that route (the scalar case) is vacuous and can be deleted. This is optional; the route is correct as written.

## 2. `subshift-el-group-centre-detects-rational-eigenvalues` + `-proof`: PASS

**(a)** A central g commutes with every `e_ij(1)`, so `g = cI_n`. Commuting with every `e_ij(r)` then gives `c ∈ Z(R) = F_q`, using item 2 of the established `minimal-subshift-algebra-is-simple-lef-ring` ✓.

**(b) `E_X(q) = μ_e`.**
- A factor `φ: X → Z/d` gives the eigenfunction `f = ζ^φ` ✓.
- Conversely, suppose `f∘T = λf` with `ord(λ) = d`.
  - The class `f(x)μ_d ∈ F_q^×/μ_d` is invariant and locally constant, so it is constant.
  - So `f = aψ` with `ψ: X → μ_d` and `ψ∘T = λψ`.
  - `ψ` is onto, since its image is closed under multiplication by `λ`. It is a factor onto `Z/d`.
- The set of `d | q-1` admitting a factor is closed under divisors and under lcm.
  - The image of `X → Z/d_1 × Z/d_2` is minimal, hence one orbit of `+(1,1)`, of size `lcm(d_1,d_2)`.
  - So these `d` are the divisors of a largest `e`, and `E_X(q)` is the subgroup `μ_e` of the cyclic group `F_q^×` ✓.

**(c) Whitehead.**
- Direct multiplication gives `e_12(v)e_21(-v^{-1})e_12(v) = [[0,v],[-v^{-1},0]]`.
- Times `e_12(-1)e_21(1)e_12(-1) = [[0,-1],[1,0]]` this is `diag(v,v^{-1})`. Only `vv^{-1} = v^{-1}v = 1` is used, so it holds over noncommutative R ✓.
- `diag(a,a^{-1})diag(b,b^{-1})diag((ba)^{-1},ba) = diag(aba^{-1}b^{-1},1)` ✓.
- `diag(c^n,1,…,1)·∏_{i≥2}diag_{(1,i)}(c^{-1},c) = cI_n` ✓.

**(d)**
- `f(Tx) = λf(x)` and `uf^{-1}u^{-1} = f^{-1}∘T^{-1}`.
- So `fuf^{-1}u^{-1} = f/(f∘T^{-1}) = λ`, a commutator of units ✓.

**(e)**
- `x_{[i,i+N+2k)}` begins and ends with `v`, so `x` has period `N` on that interval, and `y = w^∞` agrees with `x` (shifted by `i`) on `[0,N+2k)`.
- Every window of length `2k+1` of `y` starts at some `t ∈ [0,N)`, so it equals `x_{[i+t,i+t+2k+1)}`. No condition on `N` is needed ✓.
- `ψ_y` preserves the fixed computation. Each `ψ_y(e_ij(r))` is block-unipotent, and `ψ_y(cI_n) = cI_{nN}`. So `c^{nN} = 1`, i.e. `ord(c^n) | N` ✓.
- Every word of X occurs in every point, and `φ(x) = -i mod d` is well defined for any occurrence `i` of `v` in `x`.
  - `φ` is continuous, by uniform recurrence.
  - An occurrence `i` in `x` is an occurrence `i-1` in `Tx`, so `φ(Tx) = φ(x)+1`.
  - Also `d | q-1`, so `c^n ∈ μ_d ⊆ E_X(q)` ✓.

**(f)** `c^n ∈ μ_e ⟺ c^{ne} = 1 ⟺ c ∈ μ_{gcd(ne,q-1)}` ✓.

**Examples.**
- Sturmian: `e = 1`, since the continuous eigenvalues `Zα+Z` contain no nontrivial rational one.
- Period doubling: the rational eigenvalues are dyadic, so `e = 2^{v_2(q-1)}`. For `q = 3, n = 3` the centre is `{±I_3}`.
- The order of the centre is an isomorphism invariant ✓.

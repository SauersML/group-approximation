# STW LXXVI: soft-comparison reflection audit (2026-08-30)

## New boundary

For every separable `A` with almost unperforated `Cu(A)`, the actual map

```text
Cu(A) -> Cu(A tensor_min Z)
```

reflects a comparison whenever its left-hand source class is functionally
soft.  Therefore it order-embeds the soft subsemigroup.  Applied to a pure
algebra, this is an unconditional obstruction theorem for Problem LXXVI:
any injectivity collapse must involve a nonsoft class.

This is not a new interval, circle, one-dimensional-field, inductive-limit,
or ideal/quotient positive class.  It is a pointwise order theorem for every
separable almost-unperforated Cuntz semigroup.  Nor does it duplicate the
compact theorem `stw99-lxxvi-stable-weak-cancellation-finite-compact-injectivity`:
that result uses cancellation and finiteness to protect projections, while
this result needs neither and protects soft classes.

## Proof-graph audit

The closest existing input,
`stw99-lxxvi-first-factor-map-has-identical-coarse-shadows`, proves that the
first-factor map preserves ideals and quasitraces but explicitly warns that
these shadows do not determine arbitrary Cuntz classes.  The new proof adds
exactly the missing comparison mechanism:

1. target comparison and the ideal-lattice isomorphism put `x` in the ideal
   generated by `y`;
2. for `x'<<x`, softness supplies `(k+1)x'<=kx`;
3. quasitrace invariance lifts every functional normalized at `y`, making
   its value on `x'` strictly smaller than its value on `y`; and
4. almost unperforation turns this strict functional inequality into
   `x'<=y`, after which a supremum gives `x<=y`.

The proof localizes functionals to `Ideal(y)`.  This matters: it avoids
silently identifying arbitrary globally infinite functionals with densely
finite quasitraces.  A functional normalized at `y` restricts to the
relevant generated ideal, where the standard functional/quasitrace
correspondence and the first-factor quasitrace homeomorphism apply.

## Literature and trust boundary

The primary-source screen in
`stw99-lxxvi-fourth-depth-audit-2026-08-30.md` still records LXXVI as open.
The semigroup inputs used here are standard: the functional
characterization of almost unperforation and the correspondence between
functionals on `Cu(A)` and lower semicontinuous 2-quasitraces.  The explicit
softness argument is the same elementary strict-comparison mechanism that
underlies soft-order embeddings, but no source or existing Cairn node found
in the audit applies it to the concrete first-factor map.

The result is deliberately one-sided.  It proves no surjectivity onto soft
elements of `Cu(A tensor Z)`, since that would require a source-side rank
realization and gluing theorem.  It also does not protect arbitrary
noncompact elements: functional softness is the load-bearing hypothesis.
This was the boundary of the one-sided argument. For pure algebras it is
now strengthened by `stw99-lxxvi-first-factor-soft-cu-isomorphism`:
canonical realification proves soft surjectivity as well. Unrestricted
LXXVI remains open on nonsoft classes, including globally noncompact
classes with compact quotient images.

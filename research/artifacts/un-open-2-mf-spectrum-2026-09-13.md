# The MF spectrum of a ring: two thresholds behind every rank-quantified UN theorem

Lane `un-open-2`, 2026-09-13. Plan: `research/artifacts/un-open-2-plan-2026-09-13.md` (e5bd460ebd).
Everything here is **unreviewed** except the two literature facts quoted in §5, which come from the

## 1. Definitions

`R` is a countable unital ring with `1 != 0`. For `N >= 2`, `EL_N(R) <= GL_N(R)` is generated by the
elementary matrices `e_ij(r) = I + r E_ij`, `i != j`, `r in R`. A countable group is **MF** in the sense of
the manuscript: it admits an injective homomorphism into the unitary group of a norm matrix corona.
Two facts about that notion are used, both from the manuscript: **MF passes to subgroups** (tex l.1080,
"that group is not MF, and MF passes to subgroups"), and `Rad_MF(G)` is the intersection of the kernels of
all homomorphisms from `G` to MF groups.

**Definition.** `EL_N(R)` is **MF-rigid** if every homomorphism from `EL_N(R)` to an MF group is trivial,
i.e. `Rad_MF(EL_N(R)) = EL_N(R)`.

**Definition (the MF spectrum).**

```text
mf(R)  = sup{ N >= 2 : EL_N(R) is MF }            in {1,2,...,inf}   (sup of the empty set = 1)
rig(R) = min{ N >= 2 : EL_N(R) is MF-rigid }      in {2,...,inf}     (min of the empty set = inf)
```

## 2. Theorem 1 (rank monotonicity)

**Theorem 1.** Let `R != 0` be a countable unital ring and `2 <= N <= M`.

- **(a)** If `EL_M(R)` is MF, then `EL_N(R)` is MF.
- **(b)** If `EL_N(R)` is MF-rigid, then `EL_M(R)` is MF-rigid.
- **(c)** `EL_N(R)` is never both MF and MF-rigid.

*Proof.* Write `i: EL_N(R) -> EL_M(R)` for the top-left corner map `A |-> diag(A, I_(M-N))`; it is an
injective homomorphism, sending `e_ij(r)` to `e_ij(r)`.

(a) `i` embeds `EL_N(R)` in `EL_M(R)`, and MF passes to subgroups.

(b) First, a normal generation statement. For `a != b` in `{1,...,M}` put
`w_ab = e_ab(1) e_ba(-1) e_ab(1) in EL_M(R)`. Then `w_ab` is the signed transposition: it acts on the
`(a,b)` coordinate plane by `(x_a, x_b) |-> (-x_b, x_a)` and as the identity on the other coordinates.
Conjugation by `w_ab` therefore carries `e_ij(r)` to `e_(i')(j')(±r)`, where `i', j'` are `i, j` with `a`
and `b` interchanged. Transpositions generate the symmetric group on `{1,...,M}`, so for any `i != j` there
is a product `P` of such `w_ab` with `P e_12(r) P^(-1) = e_ij(±r)`. As `r` runs over `R` so does `-r`, so
the set of `EL_M(R)`-conjugates of `{e_12(r) : r in R}` contains every `e_ij(r)` with `i != j`, and those
generate `EL_M(R)`. Since `N >= 2`, `e_12(r) in i(EL_N(R))`, so the normal closure of `i(EL_N(R))` in
`EL_M(R)` is `EL_M(R)`.

Now let `phi: EL_M(R) -> H` be a homomorphism with `H` MF. Then `phi . i` is a homomorphism from `EL_N(R)`
to an MF group, hence trivial by hypothesis, so `i(EL_N(R)) <= ker phi`. As `ker phi` is normal it contains
the normal closure of `i(EL_N(R))`, which is `EL_M(R)`. So `phi` is trivial.

(c) If `EL_N(R)` were both, the identity map `EL_N(R) -> EL_N(R)` would be a homomorphism into an MF group,
hence trivial, forcing `EL_N(R) = 1`. But `e_12(1) != I` because `1 != 0`. `[]`

**Corollary 1.1 (the spectrum).** `{N >= 2 : EL_N(R) MF}` is a down-set and `{N >= 2 : EL_N(R) MF-rigid}`
is an up-set in `N`, and `mf(R) < rig(R)`. So the integers `N >= 2` split into three consecutive regimes:

```text
2 <= N <= mf(R)          EL_N(R) is MF
mf(R) < N < rig(R)       EL_N(R) is not MF but has a nontrivial MF quotient   (the MIDDLE regime)
rig(R) <= N              EL_N(R) is MF-rigid
```

*Proof.* The two monotonicity statements give the down-set and the up-set; (c) gives `mf(R) < rig(R)`. In
the middle regime `EL_N(R)` is not MF-rigid, so some nontrivial homomorphism to an MF group exists, and its
image is a subgroup of an MF group, hence a nontrivial MF quotient. `[]`

**What this buys the program.** Every rank-quantified UN theorem becomes an upper bound on one integer:

- tex l.918 (`full-defect-ring-non-mf-at-rank-two`): `rig(R) = 2` under `ts = 1`, `R(1-st)R = R`;
- `stably-infinite-ring-elementary-groups-have-no-mf-quotient`: `2n[1] <= n[1]` gives `rig(R) <= 2n`;
- `non-ibn-ring-el-n-full-mf-radical-above-module-rank`: `R^m ~= R^(m+d)` gives `rig(R) <= max(m+1,3)`;
- the open low-rank band `3 <= N < 2p` of `un-middle` is exactly "compute `rig(R)` below the bound";
- Pestov 9.1: `LC(X,F_q) ⋊ Z` is LEF, so every `EL_N` is MF, i.e. `mf(R) = inf` and `rig(R) = inf`.

That last line is the point of the definition: the two calibrating rings are the two extreme spectra,
`(mf, rig) = (inf, inf)` for the Pestov ring and `(1, 2)` for `L_k(1,2)`.

## 3. Theorem 2 (how the thresholds move under matrix amplification)

**Lemma 2.1.** For `N >= 2` and `m >= 1`, `EL_N(M_m(R)) = EL_(Nm)(R)` under the standard identification
`M_N(M_m(R)) = M_(Nm)(R)`.

*Proof.* `(<=)` For `X in M_m(R)` the block elementary `e_ij(X)` is the commuting product of the
`e_((i,a),(j,b))(X_ab)` over `a, b in {1,...,m}`; the index pairs are distinct because `i != j`, so each
factor is an elementary matrix over `R`. `(>=)` Let `p != q` in `{1,...,Nm}`, lying in blocks `i` and `j`.
If `i != j`, then `e_pq(r)` is the block elementary `e_ij(X)` with `X` the matrix unit scaled by `r`. If
`i = j`, use `N >= 2` to pick a block `l != i` and an index `p'` in it; then
`e_pq(r) = [e_(p p')(r), e_(p' q)(1)]`, a commutator of two elementary matrices lying in distinct blocks,
each already shown to be in `EL_N(M_m(R))`. `[]`

**Theorem 2.** For every `m >= 1`,

```text
rig(M_m(R)) = max(2, ceil(rig(R)/m)),      mf(M_m(R)) = floor(mf(R)/m)  when that is >= 2, else 1,
```

with the conventions `ceil(inf) = inf` and `floor(inf) = inf`.

*Proof.* By Lemma 2.1, for `N >= 2`, `EL_N(M_m(R))` is MF-rigid iff `EL_(Nm)(R)` is, iff `Nm >= rig(R)` by
Corollary 1.1, iff `N >= ceil(rig(R)/m)`; intersect with `N >= 2`. The same argument with the down-set
gives the `mf` statement. `[]`

**Corollary 2.2.** `rig(R) < inf` iff `rig(M_m(R)) < inf`, and `mf(R) = inf` iff `mf(M_m(R)) = inf`. So the
two *dichotomy conditions* are stable under matrix amplification, while the *thresholds themselves* are not:
they rescale by `ceil(./m)` and `floor(./m)`.

This is the precise sense in which the finiteness of `rig` is a coarse, `K_0`-level datum and the value of
`rig` is a genuinely finer ring-level one. Compare `un-low-rank-band`: its target `EL_3(L_k(3,4))` is the
computation of a value, not of a dichotomy, which is why no monoid-theoretic argument can settle it.

## 4. Which invariant is being measured

For countable **simple** unital `R`, un-middle's `simple-ring-stably-finite-iff-unit-not-paradoxical`
(un-verify PASS) says `R` is stably finite iff `[R]` is not paradoxical in `V(R)` iff `V(R)` carries a state
that is finite and nonzero at `[R]`. Combined with the threshold theorem:

```text
V(R) has no nonzero state  <=>  R not stably finite  =>  rig(R) < inf
```

"`V(R)` has no nonzero state" is a property of the ordered monoid `V(-)` alone. For simple `R` a state
nonzero anywhere is nonzero at `[R]`, because every nonzero element of `V(R)` is full: `1 = sum a_i e b_i`
gives `[1] <= m[e]`, and `[e] <= j[1]` for `e` an idempotent over `M_j(R)`. Since `V` is a Morita invariant
of the ring, so is this condition. Hence:

**The sufficient condition for rigidity is Morita invariant, and it is exactly the emptiness of the state
space of `V(R)`.** This is the honest answer to "which invariant does Kazhdan rigidity measure": on the
rigid side it measures the state space of `V(-)`, i.e. `K_0`-level Tarski data, and nothing finer.

**The asymmetry, and why the open converses are hard.** The LEF side is *not* a function of `V(R)`:
un-calibration's refutation F3 exhibits stably finite rings with a faithful rank function whose elementary
groups are not LEF. So the rigid side of the program is monoid-theoretic and the LEF side is not. Every
open converse in un-architect's ladder sits on the non-monoid side.

## 5. Theorem 3: the middle regime is genuinely inhabited

Let `k = F_2` and let `J = k<s,t | ts = 1>` be the Toeplitz-Jacobson algebra, `e = 1 - st != 0`.

**Theorem 3.** `mf(J) <= 3` and `rig(J) = inf`. So for every `N >= 4`, `EL_N(J)` is neither MF nor
MF-rigid: the middle regime of `J` is infinite.

*Proof.* Two facts are quoted from the manuscript on main, both recorded in un-calibration's row 11.
Tex l.1122-1125: "The Toeplitz--Jacobson algebra `J = F_2<s,t | ts=1>` has `1-st != 0` of order two, while
`J/J(1-st)J = F_2[z,z^(-1)] != 0`, so `1-st` is not full ... Proposition `prop:torsion-defect-ring` shows
that `EL_n(J)` is not MF for `n >= 4`." Tex l.1143-1148: "the quotient `EL_n(F_2[z,z^(-1)])` is residually
finite, so MF, and `Rad_MF(EL_n(J)) = EL_n(J, JeJ) = union_N SL_N(F_2)` for `n >= 4`."

`EL_4(J)` is not MF, so `mf(J) <= 3` by Corollary 1.1. For `rig(J) = inf` it suffices that no `EL_N(J)`,
`N >= 2`, is MF-rigid. The ring surjection `J -> F_2[z,z^(-1)]` induces a surjection
`EL_N(J) -> EL_N(F_2[z,z^(-1)])`, which is nontrivial for every `N >= 2` because `F_2[z,z^(-1)] != 0`. Its
target is a finitely generated linear group over a finitely generated commutative ring, hence residually
finite by Malcev, hence MF; the manuscript states exactly this for `n >= 4`. So every `EL_N(J)` admits a
nontrivial homomorphism to an MF group. `[]`

**Reading.** The paradox/measure dichotomy is not a dichotomy for general rings: `J` is neither eventually
MF nor eventually rigid, and its failure is quantified by an infinite middle regime. `J` is not simple - the
ideal `JeJ` is proper, which is precisely the failure of the fullness hypothesis that un-calibration
isolated as F4. So:

**Reformulation.** un-architect's open converse `stably-finite-simple-rings-have-mf-elementary-groups`
(rung (M), left-to-right) says exactly: *for simple rings the middle regime is empty*, i.e.
`mf(R) = inf` or `rig(R) < inf`. Theorem 3 shows that simplicity cannot be dropped, and measures by how
much: the middle regime of `J` contains every `N >= 4`.

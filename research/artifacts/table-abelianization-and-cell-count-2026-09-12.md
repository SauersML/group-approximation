# The abelian layer of a canonical table group: a cell-count Betti bound and a window test

Lane `gk-n-defect`, 2026-09-12. Supports the Cairn claims
`table-hosts-have-a-cell-count-betti-lower-bound` and
`two-cell-window-differences-die-in-host-abelianization`.

This computes the abelianization of the canonical table host of a design and
reads two rule-independent filters off it. Both are mechanical: they examine the
forward partition and the memory addresses only, never a local rule, never a
reverse product. Everything here is elementary once the holonomy normal form of
`table-groups-are-memory-holonomy-groups` is granted.

## 0. Conventions and inputs

A design is `D = (A, S, M, nu, mu)` with `1 in S`, `1 in M`, encoder memory `M`
and decoder memory `S`, in the convention `tau(x)(g) = mu((x(gm))_(m in M))` and
`sigma(y)(g) = nu((y(gs))_(s in S))`. A forward-sufficient marked partition `E`
of `S x M` and its table group `U_E` are as in
`strict-automata-live-on-canonical-table-groups`. Write

```text
P = the set of classes of E,        |P| = |S.M| = the number of cells read,
```

so `|P|` is the number of distinct products `sm`, and `|S||M| - |P|` is the
number of independent coincidences.

Two inputs are used as stated, not reproved.

* **(H1)** `table-groups-are-memory-holonomy-groups`. The decoder difference
  graph `Gamma_E` has vertex set `S`, and each identified pair
  `(s,m) ~_E (s',m')` gives an edge `s' -> s` labelled `delta = x_(m') x_m^(-1)`.
  For a connected `Gamma_E`,

  ```text
  U_E = Hol_M(E) = < x_m : m in M \ {1} | holonomies of the cycles of Gamma_E >,
  ```

  with one relator per element of a basis of the cycle space, so
  `b_1(Gamma_E)` relators. In general `U_E = Hol_M(E) * F_(c-1)` for `c`
  components, and the restriction to the component of `1_S` keeps a
  forward-sufficient design with the same encoder and the same strictness.
* **(H2)** `strict-automaton-tables-present-an-invisible-window-difference`, the
  table form of `sofic-radical-localizes-garden-of-eden-windows`: for a strict
  realization over `U_E` with Garden-of-Eden window `Omega`, the set
  `Omega^(-1) Omega` contains a nontrivial element of the sofic radical
  `Rad(<M>)`.

Throughout, `e_m` is the standard basis vector of `Z^(M \ {1})` for `m != 1`, and
`e_1 := 0`. This is the abelianization convention forced by the identity address
being the empty word.

## 1. The abelianized holonomy lattice

Let `Gamma_E` be connected, with one edge per independent coincidence. Orient
each edge `e` as `s' -> s` coming from `(s,m) ~_E (s',m')`, and set

```text
v_e := e_(m') - e_m   in Z^(M \ {1}).
```

**Lemma 1.1.** Abelianizing the holonomy of a cycle `z = sum_e c_e e` of
`Gamma_E` gives `sum_e c_e v_e`. Consequently

```text
Hol_M(E)^(ab) = Z^(M \ {1}) / L,      L := { sum_e c_e v_e : c in Z_1(Gamma_E) },
```

the image of the integral cycle space `Z_1(Gamma_E)` under `e -> v_e`.

*Proof.* By (H1) the relators are exactly the cycle holonomies, a cycle
holonomy is the ordered product of the labels `delta_e^(±1)` along the cycle, and
`delta_e = x_(m') x_m^(-1)` abelianizes to `e_(m') - e_m = v_e`. The
abelianization of a group presented by `< X | R >` is `Z^X` modulo the subgroup
generated by the abelianized relators, and a generating set of `Z_1(Gamma_E)`
gives a generating set of the relator set. Orientation reversal negates both the
holonomy and `v_e`, so the assignment is well defined on `Z_1`. QED

Two remarks that matter below.

* `L` is generated by `b_1(Gamma_E)` vectors, one per cycle basis element.
* `L` is a subgroup, not merely a rational subspace: an element of
  `Z^(M \ {1})` dies in `Hol_M(E)^(ab)` exactly when it lies in `L`, not when it
  lies in `L (x) Q`. A nonzero torsion image survives in a finite cyclic
  quotient, which is sofic.

## 2. The cell-count Betti bound

**Theorem 2.1.** Let `E` be a partition of `S x M` with connected difference
graph and `|P|` classes. Then

```text
b_1(Hol_M(E)) >= |S.M| - (|S| - 1)(|M| - 1) - 1,
```

where `b_1` denotes the rank of the abelianization. In particular, if the host
has finite abelianization -- for instance if it is Kazhdan, perfect, or simple --
then

```text
|S.M| <= (|S| - 1)(|M| - 1) + 1,
```

equivalently the forward table carries at least `|S| + |M| - 2` independent
coincidences.

*Proof.* Taking one edge per independent coincidence, `Gamma_E` has
`|S||M| - |P|` edges on `|S|` vertices, so for a connected graph

```text
b_1(Gamma_E) = |S||M| - |P| - |S| + 1.
```

By Lemma 1.1 the lattice `L` is generated by `b_1(Gamma_E)` vectors inside
`Z^(M \ {1})`, a free abelian group of rank `|M| - 1`. Hence

```text
rank Hol_M(E)^(ab) >= (|M| - 1) - b_1(Gamma_E)
                    = (|M| - 1) - |S||M| + |P| + |S| - 1
                    = |P| - [(|S| - 1)(|M| - 1) + 1].
```

Since `|P| = |S.M|`, that is the displayed bound. A group with finite
abelianization has `b_1 = 0`, so the right side is at most `0`, which is the
second display. The coincidence count is
`|S||M| - |P| >= |S||M| - (|S|-1)(|M|-1) - 1 = |S| + |M| - 2`. QED

For `c` components, `b_1(Gamma_E) = |S||M| - |P| - |S| + c`, and
`U_E = Hol_M(E) * F_(c-1)` by (H1), so `b_1(U_E) = b_1(Hol_M(E)) + c - 1`. The
same count gives

```text
b_1(U_E)       >=  |S.M| - (|S| - 1)(|M| - 1) - 1,
b_1(Hol_M(E))  >=  |S.M| - (|S| - 1)(|M| - 1) - c.
```

So the display holds verbatim for the table group `U_E`, and the host `Hol_M(E)`
loses `c - 1`. An earlier version of this remark put `|S| - c` in place of
`|S| - 1`. That is wrong: it gives the false bound `3` in the discrete `2 x 2`
example below. The connected case is the only one needed, by the reduction in
(H1).

**Sanity checks.**

* `S = M = {1}`: `|S.M| = 1`, bound `1 <= 1`. The host is trivial, and its
  abelianization is finite. Consistent.
* `S = {1,a}`, `M = {1,b}`, discrete table, `|S.M| = 4`. The difference graph
  has two vertices and no edges, so `c = 2`, and the connected display does not
  literally apply (scope note from `gk-vf-nonlinear`). The table group is
  `U_E = Z * Z` with `b_1 = 2`, matching the verbatim bound `4 - 1 - 1 = 2`. The
  host `Hol_M(E) = <x_b> = Z` has `b_1 = 1`, matching `4 - 1 - 2 = 1`.
* `S = M = F` a finite group with its full multiplication table: `|S.M| = |F|`
  and `(|F|-1)^2 + 1 >= |F|` for `|F| >= 1`, so the test passes. Correct: the
  host is `F`, with finite abelianization. So the filter is not vacuously
  restrictive; it excludes only tables that are close to free.

**Reading.** The bound says that a host with no abelian quotient is paid for in
coincidences, at a rate of one coincidence per address. It is a counting
statement about the forward table alone, so it screens a design before any rule,
any reverse product, or any realization is examined.

## 3. The anchor charge

Call an edge `e` of `Gamma_E`, from `(s,m) ~_E (s',m')`, **anchored** if exactly
one of `m, m'` is the identity address, and **balanced** otherwise. Let
`psi : Z^(M \ {1}) -> Z` send every `e_m` to `1`, so `psi(v_e)` is `+1`, `-1` or
`0` according to the type of `e`, and define the **anchor charge** of a cycle to
be `psi` of its abelianized holonomy.

**Proposition 3.1.** If every cycle of `Gamma_E` has zero anchor charge -- in
particular if `Gamma_E` has no anchored edge at all -- then `psi` descends to a
surjection `Hol_M(E) -> Z` sending every memory letter to `1`. Consequently:

1. the host has infinite abelianization, so it is neither Kazhdan nor perfect
   nor simple, and Theorem 2.1's second display fails;
2. every subgroup of the host with finite abelianization, every Kazhdan subgroup
   included, lies in `ker psi` and therefore contains no memory letter and no
   product of memory letters of nonzero total degree.

*Proof.* By Lemma 1.1, `psi(L) = 0` is exactly the hypothesis, so `psi`
descends. It is onto because `M \ {1}` is nonempty in any nontrivial design. A
subgroup with finite abelianization has trivial image in `Z`. QED

**Corollary 3.2 (free factor).** If every identification of `E` is balanced, then

```text
Hol_M(E)  ~=  Z * Q,       Q = < d_m : m in M \ {1, m_0} | the same relators >,
```

where `m_0 in M \ {1}` is any fixed address, `t = x_(m_0)` and
`d_m = x_m x_(m_0)^(-1)`. Consequently every Kazhdan subgroup of the host is
conjugate into `Q`, and every two-cell window difference lies in `Q`.

*Proof.* The set `{t} u {d_m}` is a free basis of the free group on the memory
letters. A balanced edge label is `x_(m') x_m^(-1) = d_(m') d_m^(-1)` with
`d_(m_0) = 1`, a word in the `d`'s alone, and every relator is a product of edge
labels, so no relator involves `t`. Hence the presentation splits as a free
product with `<t> = Z`. A group with property (T) fixes a point of the Bass-Serre
tree of a free product, so it is conjugate into a factor, and an infinite
subgroup of `Z` is not Kazhdan. A window difference `x_(m_1) x_(m_2)^(-1)` equals
`d_(m_1) d_(m_2)^(-1) in Q`. QED

So an unanchored design carries a free `Z` factor that no realization can use:
the whole question descends to `Q`, one generator smaller. Anchoring is what
lets a table present anything else.

An anchored edge is a concrete statement about the addresses: an identification
`(s,1) ~_E (s',m')` says `s = s'm'` with `m' != 1`, that is, the cell sitting at
the decoder address `s` is also read by the output at `s'` through a nontrivial
memory address. So Proposition 3.1 reads: *a table whose cells are never shared
between an output's own base and another output's nontrivial address has a free
abelian direction, and cannot present a Kazhdan host.* The known nonsoficity
mechanism needs property (T), so any design aiming at it must anchor its table.

## 4. The window test

**Theorem 4.1.** Let a realization over the table host `H = Hol_M(E)` be
injective with a Garden of Eden on a two-cell window `Omega = {1, d}`. Then

```text
d in Rad_sof(H) subset [H, H],
```

and if `d = m_1 m_2^(-1)` with `m_1, m_2 in M`, then

```text
e_(m_1) - e_(m_2)  in  L.
```

*Proof.* `Omega^(-1) Omega = {1, d, d^(-1)}`, so by (H2) one of `d, d^(-1)` is a
nontrivial element of the sofic radical; the radical is a subgroup, so
`d in Rad_sof(H)`. The quotient `H -> H^(ab)` has abelian, hence amenable, hence
sofic image, and the sofic radical lies in the kernel of every homomorphism onto
a sofic group, so `d in [H,H]`. By Lemma 1.1 the image of `d = m_1 m_2^(-1)` in
`H^(ab) = Z^(M \ {1}) / L` is `e_(m_1) - e_(m_2) + L`. QED

**Corollary 4.2.** A fully balanced table (Proposition 3.1) admits no two-cell
Garden-of-Eden window whose difference is a single memory letter: for `d in M`,
`psi(e_d) = 1 != 0`, while Theorem 4.1 puts `d` in `ker psi`.

**Corollary 4.3 (the mechanical test).** Given a design and a forward partition,
compute a cycle basis of `Gamma_E`, form the `b_1 x (|M|-1)` integer matrix of
abelianized holonomies, and test membership of `e_(m_1) - e_(m_2)` in the lattice
it spans, by Smith normal form. A negative answer excludes the window outright,
whatever the rules and whatever the realization.

## 5. What this gives the defect-window problem, and what it does not

For `defect-window-automaton-over-leavitt-units` the window is `{1, d}` with
`d = [u c u^(-1), l]` a commutator of the nine-leaf configuration. Theorem 4.1
applies, and its abelian half is **vacuous there**: a commutator lies in `[H,H]`
by definition, so `e_(m_1) - e_(m_2) in L` is automatic once the table realizes
the commutator relation at all. The abelian layer therefore does not screen the
defect window, and the honest conclusion is that the binding constraints on that
design are the two that survive:

* Theorem 2.1: the table must carry at least `|S| + |M| - 2` independent
  coincidences if the host is to be Kazhdan or simple, which the known
  invisibility mechanism requires;
* Proposition 3.1: the table must be anchored, since a fully balanced table has
  a `Z` quotient and no Kazhdan host.

Both are necessary conditions on the forward partition, and neither is
sufficient. The step where the design still dies is unchanged and is recorded in
the node: no rule pair is known whose forward sufficiency forces a Kazhdan
presentation. Nothing here supplies one, and nothing here forbids one; Section 2
only prices it.

**Scope.** Theorem 2.1 and Proposition 3.1 are unconditional statements about
table groups. Theorem 4.1 is unconditional given (H2). The reading in Section 3,
that a design aiming at the compression mechanism must anchor its table, is
conditional on that mechanism being the one used, since no theorem here says
invisibility requires property (T).

**Calibration that keeps the filters honest.** A commutator window passes the
abelian test for free, as just recorded, and the residually finite core
`Z * Z^2` of the node's small-core attempt passes Theorem 2.1 and can be
anchored. So both filters are strictly weaker than the invisibility requirement,
and neither is a route to the claim.

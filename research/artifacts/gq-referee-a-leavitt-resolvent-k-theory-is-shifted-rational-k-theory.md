## The four points the author asked about
- **Injectivity of `B⁺ → R_L`.**
  - *A ring homomorphism.* `q_kq_l = δ_(kl)q_k`, since `t_2t_1^ks_1^ls_2` is `1` for `k = l`. For `l > k` it
    contains `t_2s_1 = 0`, and for `k > l` it contains `t_1s_2 = 0`.
  - `q_kf = s_1^ks_2(t_2f(N+k))t_1^k = f(k)q_k`, and likewise `fq_k = f(k)q_k`. So the products match those of
    `B⁺ ⊆ Fun(N,Q)`.
  - `B ∩ J = 0`, because a rational function with infinitely many zeros vanishes.
  - *Injectivity.* In the model on `Q^(X)`, `q_k` is the projection onto `{ξ : ξ has exactly k leading 1's}`, and `f`
    acts by `f(N)`. Every `n ≥ 0` occurs, as `1^n2^∞`, so the composite `B⁺ → End(Q^(X))` is injective.
  - This uses only the model, not its faithfulness. ✓
- **`U ≅ R_L`.**
  - *Covariance.* `q_ks_1 = s_1q_(k−1)`, `q_0s_1 = 0` and `q_ks_2 = δ_(k0)s_2`. So `gs_1 = s_1σ(g)` and `gs_2 = s_2g(0)`
    on all of `B⁺`. Together with the Cuntz relations, these define `U`.
  - *`U` is generated by the image of `R_L`.* The nine relations hold in `U`, so there is a map `R_L → U`.
    - In `U`, `δ_0 = δ_0(s_1t_1 + s_2t_2) = s_1σ(δ_0)t_1 + s_2t_2 = s_2t_2`, and `δ_k = s_1δ_(k−1)t_1 = q_k`.
    - The elements `(N+c)^(−1)` for `c ≥ 2`, and `Q`, are the images of the same elements of `R_L`, by uniqueness of
      inverses (N1).
  - *The inverse map.* The embedding gives `U → R_L`, since `U`'s relations hold in `R_L`. The composite
    `R_L → U → R_L` is the identity on generators. ✓
- **The block computation.**
  - *On `A`.* `[X] = σ_* + (ev_0)_*`, and both fix `Q`, so `[X] = 2`.
  - *On `E`.* `σ_*{x, N+c} = {x, N+c+1}`, so `e_c ↦ e_(c+1)` exactly, and `(ev_0)_*{x,N+c} = {x,c} ∈ A`.
  - *On `D`.* `σ(δ_k) = δ_(k−1)` with `σ(δ_0) = 0`, and `ev_0(δ_k) = δ_(k0)`. So `δ_k ↦ δ_(k−1) + δ_(k0)·1`, as stated.
  - *`1 − [X]`.* It is `−1` on `A`, `1 − t` modulo `A` on `E`, and unitriangular modulo `A` on `D`, with inverse
    `δ_k ↦ δ_0 + … + δ_k` on finite sums.
  - *Kernel and cokernel.* The kernel is 0. The image contains `A`, so the cokernel is `E/(1−t)E ≅ K_(n−1)(Q)` via the
    sum. ✓
- **The register-node hypotheses.**
  - *Base ring.* `B` is the localization of `Q[t]` at the shift-stable multiplicative set generated by the `t + c`,
    `c ≥ 1`, so `B⁺ = B⁺_T` with `T = B` and `J ⊆ B⁺`.
  - *Letters.* The letters are `N ↦ N+1`, with `g ↦ g∘(N+1)` preserving `B⁺`, and `N ↦ 0`, with `g ↦ g(0) ∈ Q`.
  - *Availability and spine.* Both letters have full availability, `t_is_i = 1`, and `s_1` is a spine for the one
    type.
  - *Flatness of the reset* (N2). Via `ev_0`, `B⁺` is a direct sum of copies of `δ_0B⁺ = Qδ_0`, which is a direct
    summand of `B⁺`, hence projective. This is exactly where the point indicators repair the scope gap for `R_L`.
  - `R_L` is a `Q`-algebra. ✓

## Other checks
- **`K_*(B)`.**
  - The pushforward from `K_*(Q[N]/(N+c))` vanishes, because `[Q[N]/(N+c)] = 0` in `G_0` and the pushforward is
    `K_*(Q)`-linear.
  - `ev_0` splits off `K_n(Q)`, and `x ↦ {x, N+c}` lifts the residue at `N = −c`.
  - `K_*(B⁺) = K_*(B) ⊕ K_*(J)`, by the split surjection `B⁺ → B` and excision for the locally unital `J`. ✓
- **Item 3.** With a zero kernel in every degree, `K_n(R_L) ≅ K_(n−1)(Q)`.
  - `K_0 = 0`, which matches the Leavitt relation `[1] = 2[1]`.
  - `K_1 = Z`, via `[N+c] = [N+1]`.
  - `K_2 = Q^×`, via `{λ, N+c} ↦ λ`, and the image of `K_2(Q)` in `A` is 0. This is consistent with
    `algebraic-closure-kills-rational-steinberg-symbols`.
  - Negative `K_n` vanish. ✓
- **Items 4–5.**
  - `λ` is central and `N+1` is a unit with inverse `A`, so `{λ, N+1}` is a Steinberg symbol of commuting units in
    `K_2(N,R_L)` for `N ≥ 3`, and these symbols generate `Q^×`. So `K_2(N,R_L) → K_2(R_L)` is onto.
  - The symbol lemma then gives item 5. ✓

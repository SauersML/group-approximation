## 1. The general theorem (Ozawa, PAMS 132 (2004), Theorem 2)

### 1.1 Source
- Crossref: 10.1090/S0002-9939-03-07127-2, PAMS 132(2) 487–490, online 2003-06-23.
- arXiv v2 numbering: `\newtheorem{thm}{Theorem}`, `\newtheorem{cor}[thm]{Corollary}`. So Theorem 1 is hyp, Theorem 2 is vna, Corollary 3 is corv, Theorem 4 is cst.
- Theorem 2, verbatim: "Let $\G$ and $\{\G_\alpha\}_{\alpha\in I}$ be as in Theorem \ref{hyp} and let $M$ be a separable $\mathrm{II}_1$-factor. Then, the set $\{ \alpha\in I : \mbox{the unitary group $\U(M)$ of $M$ contains a subgroup isomorphic to $\G_\alpha$}\}$ is at most countable."
- Its proof, verbatim:
  - "let $u_\alpha\colon\G\to\U(M)$ be a non-trivial homomorphism which factors through $\G_\alpha$";
  - "$\pi\colon\G\ni s\mapsto u_\alpha(s)Ju_\beta(s)J$";
  - "Since $\G_\alpha$ and $\G_\beta$ are simple and $\ker u_\alpha$ and $\ker u_\beta$ are distinct, we actually have $\Delta=\G$."
- Ozawa's definition of (T) (§1) uses a finite generating set E and a function f with f(ε) → 0. The route node uses a Kazhdan pair (E, κ) with f(ε) = ε/κ. The two are equivalent, and the node's version is quantitative.

### 1.2 Re-derivation (route node, step by step)
- **Step 0.** Write ξ = Pξ + ζ, with P the projection onto invariant vectors. (ran P)^⊥ is π-invariant and has no invariant vectors, so some s ∈ E has ‖π(s)ζ − ζ‖ ≥ κ‖ζ‖. Also π(s)ξ − ξ = π(s)ζ − ζ. So ‖ξ − Pξ‖ ≤ κ⁻¹ max_E ‖π(s)ξ − ξ‖. Correct.
- **Step 1.** u_i(s) ≠ 1 for some s, and ‖u_i(s)1̂ − 1̂‖ = ‖u_i(s) − 1‖_2 > 0 because the trace is faithful. If I_0 = ⋃_n {i : sup_s > 1/n} is uncountable, some term is uncountable. Correct.
- **Step 2.** L²(M)^E is a separable metric space. Take the uncountable family (u_i(s)1̂)_{s∈E}, i ∈ I_1. Either the map from indices is not injective, giving two indices at distance 0, or its image is uncountable and so not ε-discrete. Either way some i ≠ j are within ε. Correct.
- **Step 3.** u_i(s) ∈ M and Ju_j(s)J ∈ M′ commute, and s ↦ Ju_j(s)J is a homomorphism because J is an antiunitary involution. So π is a unitary representation.
  - π(s)1̂ = (u_i(s)u_j(s)*)^.
  - ‖(u_i(s)u_j(s)*)^ − 1̂‖ = ‖u_i(s) − u_j(s)‖_2 = ‖u_i(s)1̂ − u_j(s)1̂‖ < ε.
  - Step 0 gives an invariant η with ‖1̂ − η‖ < ε/κ. Correct.
- **Step 4.**
  - Δ = Stab_{u_i}(η) is a subgroup. It contains N_i, where u_i = 1.
  - For s ∈ N_j, π(s) = u_i(s), so u_i(s)η = η.
  - So Δ ⊇ N_iN_j, a normal subgroup. Since Λ/N_i is simple, N_i is a maximal normal subgroup; so is N_j.
  - If N_iN_j = N_i, then N_j ⊆ N_i, so N_i/N_j is normal in the simple group Λ/N_j. Since N_i ≠ Λ, this forces N_i = N_j, a contradiction.
  - So N_iN_j = Λ = Δ. Correct.
- **Step 5.** ‖u_i(s)1̂ − 1̂‖ ≤ ‖u_i(s)(1̂ − η)‖ + ‖η − 1̂‖ < 2ε/κ < δ for all s, which contradicts Step 1. Correct.
- **Consequence.** For a (non-unital) embedding ψ: L(Λ/N_j) → M, the map λ_g ↦ ψ(λ_g) + 1 − ψ(1) is a unitary representation. It is injective since ψ is injective on a factor. Correct.

### 1.3 Where each hypothesis enters, and model tests
- **(T) of Λ: Step 3 only.**
  - *Model:* Λ = F_∞ with the quotients [[T_X]]′ for minimal subshifts X. These are simple and f.g. (Matui), amenable (Juschenko–Monod), and pairwise nonisomorphic for non-flip-conjugate X (Bezuglyi–Medynets). So there are continuum many distinct kernels.
  - Every amenable ICC group has hyperfinite L(Γ), so all these quotients lie in U(R). The conclusion fails, and the proof breaks exactly at Step 3.
- **Distinct kernels: Step 4 only.**
  - *Model:* N_i = N for all i in an uncountable index set. The conclusion fails, and Step 4 gives only Δ ⊇ N.
- **Simplicity: Steps 1 and 4.** Step 1 needs nontriviality; Step 4 needs maximality. Without simplicity, Step 4 gives invariance only on N_iN_j, and the argument stops.
- **Faithfulness.** Only a homomorphism Λ → U(M) with kernel exactly N_i is needed, i.e. a faithful representation of Λ/N_i. Nothing is required of Λ itself. Since Λ/N_i is simple, any nontrivial homomorphism that factors through it has kernel N_i. This is Ozawa's formulation.
- **Factoriality of M is not used.** A separable finite von Neumann algebra with a faithful normal trace suffices, as in NPS Theorem 0.2.

## 2. The G_X instance

Each point was checked against the note (main l.98–126, l.158–186, l.360–406) and the route node:
- **Kazhdan group and surjection.** Λ = EL_3(F), F = F_2⟨τ_+, τ_-, τ_a : a ∈ A⟩.
  - π(τ_±) = u^{±1} and π(τ_a) = e_a, the note's own map (l.160–166). π is onto because R is generated by u^{±1} and the e_a (l.109–112).
  - So EL_3(π): EL_3(F) → EL_3(R) = G_X is onto, since its image contains every e_ij(s).
  - EL_3(F) has (T) by EJZ Theorem 1.1, as l.179–180 already say.
- **Simple quotient.** G_X is simple by Theorem 1. For q = 2 it is centreless (`subshift-f2-ring-indicator-ideals-and-centreless-el3`, PASS).
- **Cylinder element.** With ufu⁻¹ = f∘T⁻¹ we get u^{-t}fu^t = f∘T^t. So u^{-t}e_{v_t}u^t is the indicator of {x : x_t = v_t}, and ∏_t of these is e_{[v]}.
  - e_{[v]} ≠ 0 in LC(X,F_2) iff [v] ∩ X ≠ ∅, iff v ∈ L(X).
  - The note's word-problem proof uses the same element (l.380–384).
- **Nontrivial and noncentral when v ∈ L(X).**
  - e_12(r)e_21(1) = I + rE_12 + E_21 + rE_11, while e_21(1)e_12(r) = I + rE_12 + E_21 + rE_22.
  - Their (1,1) entries are 1 + r and 1, so e_12(r) is central only if r = 0.
  - This matters for S_X over F_q (quotient by the centre). For q = 2, nontriviality is enough.
- **Distinct kernels.** X ≠ Y gives L(X) ≠ L(Y), so some v lies in exactly one language. Its element lies in exactly one kernel.
- **Continuum.** The X_α (α irrational) are infinite minimal subsets of {0,1}^Z. L(X_α) computes α, since the frequency of ones in length-m words is within 1/m of α. So α ↦ X_α is injective (`continuum-many-infinite-minimal-binary-subshifts`, PASS).
- **Isomorphism classes.**
  - If θ: L(G_Y) → L(G_X) is a *-isomorphism, then θ∘λ_Y: G_Y → U(L(G_X)) is an injective homomorphism.
  - L(G_X) is a separable II_1 factor, since G_X is countable, infinite and simple, hence ICC.
  - By §1, each class contains countably many X. A continuum partitioned into countable classes has continuum many classes.
- **R^ω.** G_X is hyperlinear, so L(G_X) ⊂ R^ω (Ozawa survey Prop. 7.1; note l.253–255).
- **Trivial model.** For a finite, periodic X, G_X is an SL over a matrix ring over F_2[t^{±1}], which has congruence quotients and so is not simple. The hypothesis "infinite minimal" is used.

## 3. Credit and novelty

### 3.1 Ozawa's printed wish (verbatim, arXiv math/0210411v2, §1, paragraph after Corollary 3)
> "In connection with Connes' embedding problem \cite{connes}, it would be interesting to know whether all (or at least one of) $\G_\alpha$'s are embeddable into the unitary group $\U(R^\omega)$ of the ultrapower $R^\omega$ of hyperfinite $\mathrm{II}_1$-factors. Since each $\G_\alpha$ arises as a limit of hyperbolic groups, we observe that if all hyperbolic groups are embeddable into $\U(R^\omega)$, then so is $\G_\alpha$."

The Γ_α are Gromov–Olshanskii quotients. The G_X are not among them. So the note must NOT say it answers this wish. It may say that the argument applies to a hyperlinear family.

### 3.2 Nicoara–Popa–Sasyk (arXiv math/0401139, source `rrs051606.TEX`; Crossref JFA 242(1) 230–246, 2007, doi 10.1016/j.jfa.2006.05.015)
- **Abstract, verbatim excerpt:**
  - "We prove that given any separable $\text{\rm II}_1$ factor $M$, the set of $2$-cocycles $\mu_{|H}\in \text{\rm H}^2(H,\Bbb T)$ with the property that $L_\mu(G)$ is embeddable into $M$ is at most countable."
  - "… the one parameter family of II$_1$ factors $M_\alpha(\Gamma)=L_{\mu_{\alpha}}(\Bbb Z^2 \rtimes \Gamma)$, $\alpha \in \Bbb T$, are mutually non-isomorphic, modulo countable sets, and cannot all be embedded into the same separable II$_1$ factor."
- **R^ω-embeddable, l.203–212:** "The factors $M_\alpha(\Gamma)$ are easily seen to be ``approximately embeddable'' into the hyperfinite $\text{\rm II}_1$ factor $R$ … i.e., $M_\alpha(\Gamma) \subset R^\omega$."
- **Theorem 0.1:** "For each fixed $\Gamma\subset SL(2,\Bbb Z)$ non-amenable there exist at most countably many $\alpha \in \Bbb T$ such that $M_{\alpha}(\Gamma)$ is embeddable into $M$ $($not necessarily unitaly$)$. In particular, the factors $\{ M_{\alpha}(\Gamma)\} _{\alpha \in \Bbb T}$ are non stably isomorphic modulo countable sets."
- **Their comment after 0.1:** "the above theorem gives an alternative proof to Ozawa's result on the non-existence of universal separable $\text{\rm II}_1$ factors in [O1], without using Gromov's property $\text{\rm(T)}$ groups."
- **Theorem 3.2 ((T) groups):** "Let $\Lambda$ be a discrete property $\text{\rm(T)}$ group such that the von Neumann algebra $L(\Lambda)$ has diffuse center … the factors $M_t$, $t\in\Cal Z\setminus\Cal Z_0$, are mutually non-stably isomorphic modulo countable sets." These are factorial components of one algebra L(Λ), not group factors of simple groups, and no R^ω claim is made.

**What NPS already give.** R^ω-embeddable II_1 factors that are pairwise non-isomorphic modulo countable sets, and so no separable II_1 factor containing every R^ω-embeddable separable one. Their families are twisted group factors of w-rigid groups (relative (T)). They are not property (T) factors, since Z²⋊SL_2(Z) has the Haagerup property, and not group factors of simple groups.

**What the G_X add** (bounded check: Ozawa 2004 and NPS read at source; Peterson and CDI through sk-strong-7's quotes; no further search). Untwisted group factors of infinite simple Kazhdan groups inside R^ω, with countable classes. These are exactly Ozawa's setting, placed where his printed wish points. The argument is Ozawa's.

### 3.3 The exact claim the note may make
1. Only countably many X per separable II_1 factor, by "the proof of [Theorem 2]{OzawaUniversal}". Do not say "by Theorem 2", which is stated for the Γ_α.
2. The L(G_X), X ⊆ {0,1}^Z, fall into continuum many isomorphism classes, each countable, and they embed in R^ω.
3. It should not claim to answer Ozawa's wish, and it should not claim the phenomenon of "no separable universal R^ω-embeddable factor" (NPS).
4. There is no "first" claim. If a comparison is wanted, credit NPS Theorem 0.1 (F2).

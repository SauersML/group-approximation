## 6. The switch machine

**Lemma C.**  There is a computable map `e |-> M_e` to simple, deterministic,
clocked Minsky machines such that

```text
e in INF  ==>  M_e is universally halting,
e in FIN  ==>  M_e has a configuration with an infinite forward computation.
```

*Construction.*  `W_(e,s) = { x < s : phi_e(x) halts within s steps }`, so
`Phi(e,s,n) := [ |W_(e,s)| > n ]` is primitive recursive in `(e,s,n)` (Kleene
`T`-predicate).  `W_(e,s)` increases with `s`, so `Phi` is monotone in `s`,
and `e in INF` iff `forall n exists s Phi(e,s,n)`.

Fix a LOOP program `CHECK` (Meyer--Ritchie) that reads registers `E, S, N`,
initializes its own work registers, writes `Phi(E,S,N)` into register `Z`,
and restores `E, S, N`.  The program of `M_e` has registers `N, S, E, Z`, the
work registers of `CHECK`, and the clock `tau`:

```text
L0:  E := 0;  E := E + 1  (e times);  CHECK;
L1:  if Z > 0 then goto STOP (command 0)
     else  Z := 0;  S := S + 1;  goto L0.
```

Compile LOOP constructs into simple Minsky code.

- `X := 0` is a Sub loop.
- `X := X + 1` is one Add.
- A copy uses a temporary register and two draining loops.
- `LOOP X DO P END` copies `X` into a fresh counter `C` used nowhere else, then
  runs `while C > 0: C--; P`.

Finally clock the machine (part 1, Section 2).  All of this is uniform in `e`.

*Termination of constructs from arbitrary configurations.*  By induction on
program structure, every compiled construct, entered at any of its command
numbers with any register contents, reaches its exit.

- A draining loop decrements its register each round, and nothing inside the
  loop increments it.
- A `LOOP` body cannot touch its own counter `C`, so `while C > 0` runs at most
  `C` rounds, and each round terminates by induction.
- Sequencing preserves termination.

*INF.*  Start from any configuration.  The current construct finishes, and the
machine reaches `L1` or `L0`.

- From `L1` it either halts or goes to `L0`.
- From `L0` onwards each round runs `CHECK` from its entry.  So it computes
  `Phi(e,S,N)` correctly on the current `S, N`, which `CHECK` restores and
  only the increment changes.
- The rounds therefore test `Phi(e, S_0 + t, N_0)` for `t = 0, 1, 2, ...`.  On
  `INF` some `s` has `Phi(e,s,N_0) = 1`, and by monotonicity so does every
  larger `s`.  So some round sets `Z > 0` and the machine halts.

Since `e` is rewritten at every round, garbage in `E` is harmless.  Garbage in
`N` or `S` only changes which `n` is searched for.

*FIN.*  Let `|W_e| = k` and take the configuration at `L0` with `N = k` and
all other registers `0`.  Every round computes `Phi(e,s,k) = 0`, so the forward
computation is infinite.  QED

## 7. Assembly

**Theorem.**  `RF_fp` is `Pi^0_2`-complete and `NONRF_fp` is
`Sigma^0_2`-complete.

*Proof.*  The map `e |-> ` (finite presentation of `G(P(M_e))`) is computable:
Lemma C, then the pumping construction of part 1, Section 2, then the relations
G1--G8 of KMS Section 4.1.

- On `INF`, `M_e` is universally halting (Lemma C), so `G(P(M_e))` is
  residually finite (Lemma B).
- On `FIN`, `M_e` has a divergent configuration (Lemma C), so `G(P(M_e))` is
  not residually finite (Lemma A).

Hence `INF <=_m RF_fp` and `FIN <=_m NONRF_fp`.  `INF` is `Pi^0_2`-complete,
and membership (`RF_fp in Pi^0_2`) is the finite-presentation clause of
`residual-finiteness-of-enumerated-presentations-is-pi3-complete`.  QED

**Corollaries.**

1. *LEF.*  `LEF_fp` is `Pi^0_2`-complete, and `NONLEF_fp` is
   `Sigma^0_2`-complete.  The reduction is the same, because for finitely
   presented groups LEF iff residually finite (Vershik--Gordon, St. Petersburg
   Math. J. 9 (1998), Thm. 2.2).
2. *Inside amenable groups.*  Every output lies in `A_p^2 A` (KMS Theorem
   4.3(a)).  So residual finiteness is `Pi^0_2`-complete on finitely presented
   solvable groups of derived length at most three.  These are amenable, hence
   sofic, hyperlinear, weakly sofic and (Tikuisis--White--Winter)
   quasidiagonal, so MF.  The hardness of exact finite approximation is
   therefore independent of every metric approximation property.
3. *Semigroups.*  The same map into the finitely presented semigroups
   `S(P(M_e))` shows that residual finiteness of finitely presented semigroups
   is `Pi^0_2`-complete.
   - On `INF`, Section B3 separates finitely many nonzero `q`-elements.  Words
     without `q` are separated by exponent bounds, and a pair
     (`q`-word, non-`q`-word) is separated in the Rees quotient by the ideal
     generated by the `q`-letters.
   - On `FIN`, Lemma A Step 2 runs in any finite quotient semigroup, since some
     power of `a_pi` is idempotent.
   - Membership: an equality is r.e. and a separating finite quotient is r.e.
4. *McKinsey's algorithm.*  The set of finite presentations on which McKinsey's
   algorithm is a decision procedure for the word problem (the "no" part
   terminates on every non-identity) is exactly `RF_fp`, so it is
   `Pi^0_2`-complete.

## 9. Cautions for a verifier

1. **Nondeterministic machines.**  Theorem 4.3(b) is applied to the
   nondeterministic `P(M)`, whose pumps and drains share command numbers with
   `M`.  KMS apply Section 4 to their own nondeterministic `M_n` (proofs of
   Theorems 3.9, 4.19, 6.1).  The proofs of Lemmas 3.1 and 3.2 concern
   single-relation steps and do not use determinism.  Determinism of `M`
   (not of `P(M)`) is used only through Lemma 2.1, inside B1 and Lemma A
   Step 1.
2. **Shape of the automorphisms.**  B4 uses the shape of the letter
   automorphisms on the basis of `T_1`, read from pages 23--24.  On `W_0` each
   letter acts trivially or through `z_(i',u)` and `z_(i',uℓ)`, and the case
   depends only on the `A`-letter set.  The inverses have the same shape (the
   displayed formula for `a_j^(-1)`, and the analogous ones).
3. **The clock.**  Without the clock, Lemma A Step 1 fails: garbage branches
   with longer pasts can drain the pumped input.  B2's classification also
   needs the invariant `iota`.
4. **Split extension.**  The residual finiteness of a split extension of a
   finite group by a residually finite group is used in B4.  Only the split
   form is needed, and it holds (argument given there).
5. **Novelty.**  A bounded search on 2026-09-12 (two web queries, the ledger's
   2026-08-26 literature sweep including Bilanovic--Chubb--Roven, and KMS
   §1.1.7) found no prior statement of (T0).  KMS construct residually finite
   finitely presented groups from sym-universally halting machines, but do not
   discuss recognition complexity.  Darbinyan--Rauzy, arXiv:2508.11973, study
   residual finiteness growth and computability of word problems, not the
   index set `RF_fp`.  The check is bounded and not exhaustive.

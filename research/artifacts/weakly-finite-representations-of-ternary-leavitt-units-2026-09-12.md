## 0. Setting and summary

- `G = L_(F_3)(1,2)^x`, `z = -1`, `eps_- = 2(1 - [z])` and `S_- = eps_- F_3[G]`.
- A ring is **weakly finite** if `AB = I_n` implies `BA = I_n` for all `n` and all square matrices
  (so weakly finite means stably finite). Subrings, products and corners `eWe` of weakly finite rings are
  weakly finite.
- A **weakly finite representation** of a group `Γ` over a field `K` is a group homomorphism
  `rho : Γ -> W^x` into a weakly finite `K`-algebra `W`. Its linear extension is a ring map `K[Γ] -> W`.

Summary:
1. **The target is one ideal.** Every ring `A` has an explicit ideal `J_omega(A)`, built in countably many
   stages from defects `BA - I` of one-sided inverse pairs, whose quotient is the universal weakly finite
   image. The target says `1 ∈ J_omega(S_-)`, a finite certificate. Refuting Gottschalk needs only the first
   stage `J_1(S_-) != 0` (Section 1).
2. **Weak finiteness replaces ranks in the defect criterion.** A weakly finite representation of
   `L_K(1,2)^x` that kills the two-root defect `D` is trivial (Section 2).
3. **Group form.** The target holds iff `G` has no nontrivial homomorphism into the unit group of any weakly
   finite `F_3`-algebra, iff every such homomorphism kills `D` (Section 3).
4. **Where it stops.** Stage 1 needs an exact one-sided pair over `S_-` itself. The natural lifts are left
   zero divisors, and every landed firewall model lives in a weakly finite algebra (Section 4).

## 1. The weakly finite reflection ideal

**Theorem 1.** Let `A` be a unital ring. For an ideal `J` let `Phi(J)` be the ideal generated by `J` and the
entries of `BA - I_n`, over all `n >= 1` and all `A, B in M_n(A)` with `AB - I_n in M_n(J)`. Put `J_0 = 0`,
`J_(k+1) = Phi(J_k)` and `J_omega = ∪_k J_k`.
- (a) `A / J_omega` is weakly finite.
- (b) Every ring homomorphism from `A` to a weakly finite ring kills `J_omega`. So `J_omega` is the smallest
  ideal with weakly finite quotient.
- (c) `A` has a nonzero weakly finite image iff `1 ∉ J_omega`. If `1 ∈ J_omega`, then `1 ∈ J_k` for some
  finite `k`, witnessed by finitely many pairs at each of finitely many stages.
- (d) `J_1 = 0` iff `A` is weakly finite, and then `J_omega = 0`.

*Proof.*
- (a) If `AB ≡ I_n` modulo `J_omega`, the finitely many entries of `AB - I_n` lie in one `J_k`, so the
  entries of `BA - I_n` lie in `J_(k+1)`.
- (b) By induction on `k`. If `phi(J_k) = 0` and `AB - I_n in M_n(J_k)`, then `phi(A) phi(B) = I_n`, so
  `phi(B) phi(A) = I_n`, so `phi` kills the entries of `BA - I_n`. Hence `phi(J_(k+1)) = 0`.
- (c) By (a) and (b), a nonzero weakly finite image exists iff `A / J_omega != 0`. An element of `J_k` is a
  finite combination of generators, each an entry of a defect of a `J_(k-1)`-pair; recurse.
- (d) `J_1` is generated by the defects of exact pairs. If it is `0`, then `Phi(0) = 0` and every stage is
  `0`. QED

Literature: this is presumably classical (Cohn; P. Malcolmson, "On making rings weakly finite"). Neither
source was read locally. Nothing here depends on the literature.

**Corollary 1.2 (the anti-central summand).**
- **The target as one membership.** `ternary-anti-central-summand-has-no-weakly-finite-image` says exactly
  `1 ∈ J_omega(S_-)`. This uses neither states nor rank functions.
- **The counterexample needs only stage 1.** `J_1(S_-) != 0` means some square matrix over `S_-` has a
  one-sided inverse and is not invertible. `S_-` is a direct factor of `F_3[G]`, so `F_3[G]` is not stably
  finite. That gives a strict linear automaton over `F_3^r` and refutes Gottschalk on `G` (links 5 and 6 of
  `research/artifacts/upg-chain-audit-2026-09-12.md`).
- **Target implies stage 1.** `S_- != 0` (evaluation maps it onto `L_(F_3)(1,2)`), so `1 ∈ J_omega` forces
  `J_omega != 0`, hence `J_1 != 0` by (d). The target is the whole collapse `1 ∈ J_omega`; a refutation of
  Gottschalk needs only its first stage.
- **Search space.** A certificate is a finite tower. Stage 1 must be an exact one-sided pair over `S_-`.
  Later stages need `AB = I` only modulo the defects already killed.

## 2. Weak finiteness replaces ranks in the defect criterion

**Theorem 2.** Let `K` be a field of characteristic `p > 0`, `R = L_K(1,2)` and `Γ = R^x`, identified with
`EL_3(R)` through the three-leaf prefix code (`leavitt-gl-equals-el-and-perfect-unit-group`). Let
`rho : Γ -> W^x` be a weakly finite representation. Put `N_ab = rho(x_ab(1)) - 1` and `D_rho = N_23 N_12`.
If `D_rho = 0`, then `rho` is trivial.

*Proof.* Steps 1, 2, 3 and 5 are ring algebra already checked for arbitrary rings. Only step 4 is new.
1. **Squares.** `reversed-root-pair-identity-forces-root-squares-to-vanish` (no characteristic, only group
   relations and units) gives `N_ab^2 = 0` for every root.
2. **Matrix units.** [TRI] Theorem A (`el3-unit-root-matrix-units-iff-two-root-identities`, stated for any
   unital ring) with `M = W` gives orthogonal idempotents `p_i` and `u_ij in p_i W p_j` with
   `rho(x_ij(1)) = 1 + u_ij`, `u_ij u_jk = u_ik` and `u_ij u_ji = p_i`.
3. **Corner homomorphism.** [RR] Proposition 6 (`p = 2`), or the ring-algebra form of [RR] Proposition 8 and
   Corollary 9 (`p` odd), gives a unital ring homomorphism `C : R -> p_1 W p_1`. That the proofs use only
   ring algebra is recorded in `research/artifacts/sylvester-rank-function-two-root-gate-2026-09-12.md`
   Section 1, step 3, and passed by `w3-vf-linear` (Section 23).
4. **The corner is weakly finite, `R` is not.**
   - Corners of weakly finite rings are weakly finite: if `x, y in M_n(p_1 W p_1)` and `xy = p_1 I_n`, then
     `X = x + (1 - p_1) I_n` and `Y = y + (1 - p_1) I_n` satisfy `XY = I_n`, so `YX = I_n` and `yx = p_1 I_n`.
   - `C(t_0) C(s_0) = C(1) = p_1`, so `C(s_0) C(t_0) = p_1`, so `C(s_1 t_1) = p_1 - C(s_0 t_0) = 0`.
   - Then `p_1 = C(t_1 s_1 t_1 s_1) = C(t_1) C(s_1 t_1) C(s_1) = 0`.
5. **Triviality** ([TRI] Theorem D.2, ring algebra). `p_1 = 0` gives `u_1j = 0` and `u_i1 = 0`, so
   `u_ij = u_i1 u_1j = 0` and `rho(x_ij(1)) = 1` for all `i != j`. `ker rho` is normal and contains
   `x_ij(a) = [x_ik(a), x_kj(1)]` for every `a`, hence every root element, hence `EL_3(R) = Γ`. QED

**Remarks.**
- **Relation to the rank criterion.** `leavitt-rank-functions-killing-two-root-defect-are-augmentation` used
  the rank function only in step 4, to exclude a positive-rank corner by counting. Here weak finiteness
  excludes the corner in one line.
- **A larger class of targets.** Null quotients of Sylvester rank functions are weakly finite
  (`sylvester-rank-function-quotients-are-weakly-finite`), and so are subalgebras of faithful rank rings. So
  Theorem 2 covers every target the rank criterion covers, and also any weakly finite algebra with no rank
  function at all.
- **Contrapositive.** Every nontrivial weakly finite representation of `Γ` has `D_rho != 0`.

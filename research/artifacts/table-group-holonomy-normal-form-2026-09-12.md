# Table groups are holonomy groups of the memory

Lane `gk-three-factor` (combinatorial and logical positive routes), 2026-09-12.
Handwritten proofs; nothing was run. Supports
`table-groups-are-memory-holonomy-groups`,
`amenable-decoder-memory-forces-surjectivity`,
`amenable-groups-satisfy-the-garden-of-eden-theorem` and
`unicyclic-strict-designs-present-nonsofic-one-relator-groups`.

Conventions are those of `canonical-table-groups-for-automaton-designs-2026-09-12.md`:
- a design `D = (A, S, M, nu, mu)` has identity addresses `1_S`, `1_M`;
- `E` is a marked partition of `S x M` whose marked class is the class of `(1_S, 1_M)`;
- `U_E = < x_a (a in S ⊔ M non-identity) | x_s x_m = x_s' x_m' for (s,m) ~_E (s',m') >`,
  where `x_(1_S)` and `x_(1_M)` are the empty word;
- `𝓕_D`, `𝓡_D` are the forward- and reverse-sufficient up-sets.

Write `S' = S \ {1_S}`, `M' = M \ {1_M}`, and `F(X)` for the free group on letters `X`.

## 1. The holonomy normal form

**The decoder difference graph.** `Gamma_E` has vertex set `S`. For every pair
`(s,m) ~_E (s',m')` it has an edge from `s'` to `s` labelled

```text
delta = x_m' x_m^(-1)   in F(M').
```

The relator of that pair reads `x_s = x_s' delta`. Using only a spanning tree of
each class gives the same group, and then there are `|S||M| - #classes(E)` edges.
Traversing an edge backwards multiplies by `delta^(-1)`.

**The memory difference graph.** `Gamma'_E` has vertex set `M`, and the same pair
gives an edge from `m` to `m'` labelled `epsilon = x_s'^(-1) x_s` in `F(S')`. The
relator reads `x_m' = epsilon x_m`.

**Theorem H.** Let `Gamma_E` have `c` components, with `1_S` in the first.
- Choose roots `r_1 = 1_S, r_2, ..., r_c` and a spanning forest `T`.
- For `s` in component `j`, let `w_s` in `F(M')` be the product of labels along the
  `T`-path from `r_j` to `s`.
- Put

  ```text
  Hol_M(E) = < M' | w_s = w_s' delta  for every edge s' -> s (label delta) outside T >.
  ```

Then

```text
U_E  ≅  Hol_M(E) * F(y_2, ..., y_c),       x_m -> x_m,   x_s -> y_j w_s  (s in component j, y_1 = 1).
```

`Hol_M(E)` has `|M'|` generators and `b_1(Gamma_E) = #edges - |S| + c` relators,
one for each independent cycle, each the holonomy around that cycle.
Symmetrically, eliminating the memory letters along `Gamma'_E` gives
`U_E ≅ Hol_S(E) * F_(c'-1)`. Here `Hol_S(E)` is presented on `S'` by the
left-multiplication holonomies of the cycles of `Gamma'_E`, and it is the subgroup
of `U_E` generated by the decoder letters.

*Proof.* These are Tietze moves.
- Walk `T` outward from each root. A tree edge between a letter already expressed
  and a new one expresses the new letter as the old one times `delta^(±1)`. So
  `x_s = x_(r_j) w_s` by induction, and each tree relator is consumed by the
  elimination of one letter.
- An edge `s' -> s` outside `T` lies inside one component `j`. It becomes
  `x_(r_j) w_s = x_(r_j) w_s' delta`, and the root letter cancels on the left,
  leaving `w_s = w_s' delta` in `F(M')`. A loop (`s = s'`) gives `delta = 1`.
- For `j >= 2` the root letters `y_j = x_(r_j)` occur in no remaining relator, so
  they split off as a free factor. For `j = 1`, `x_(1_S) = 1`.
- The memory side is the same computation. The relator `x_m' = epsilon x_m` is
  left multiplication, so here the free root letters cancel on the right. QED

**Hinge words in holonomy coordinates.** For `s, s'` in the component of `1_S`,
the reverse hinge word `x_s'^(-1) x_m'^(-1) x_m x_s` of Proposition C in the
canonical-table artifact equals

```text
w_s'^(-1) x_m'^(-1) x_m w_s     in Hol_M(E).
```

Also `x_m x_s = x_m w_s`. So strictness over `U_E` concerns short words in one
group presented on the memory letters.

**Examples.**
- Memories `{1, a}` and `{1, b}` with coincidences `a = b` and `ab = 1`: `Gamma_E`
  has two edges from `1` to `a`, labelled `b` and `b^(-1)`. There is one cycle, and
  `Hol_M(E) = < b | b^2 >`. This recovers the `Z/2` of the rectangle-clauses
  artifact (section 6).
- A triangular partition has an elimination order, but `b_1(Gamma_E)` can be
  positive. The relators of `Hol_M(E)` are then themselves eliminable, which is
  where Theorem D of the canonical-table artifact acts. Theorem H counts
  relators; triangularity says whether they peel.

## 2. Only the component of the identity matters

**Proposition C.** Let `E` be in `𝓕_D`, and let `S_1` be the vertex set of the
component of `1_S` in `Gamma_E`.
1. There is a rule `nu_1 : A^(S_1) -> A` such that `D_1 = (A, S_1, M, nu_1, mu)`
   has `E_1 = E|_(S_1 x M)` in `𝓕_(D_1)`.
2. For every realization `rho` of `D` with forward table `>= E`, `tau_rho` is strict
   exactly when the realization `rho|_(S_1 ⊔ M)` of `D_1` is strict.

*Proof.*
- **The two blocks are independent.** An `E`-class containing `(s,m)` and
  `(s',m')` gives an edge between `s` and `s'`. So every class lies in
  `S_1 x M` or in `(S \ S_1) x M`, and the symbol variables of the two blocks are
  independent.
- **Defining `nu_1`.** Fix an assignment `y^0` on the classes of the second block,
  put `e^0_s = mu((y^0[(s,m)])_m)` for `s` not in `S_1`, and define
  `nu_1((e_s)_(s in S_1)) = nu((e_s)_(S_1), e^0)`.
- **Part 1.** For `y_1` on the first block, `y_1 ⊔ y^0` is an assignment on all of
  `E`'s classes. `E` is forward sufficient and the marked class lies in the first
  block, so `Phi_(E_1)(y_1) = y_1[e]`.
- **Part 2.** If `rho` has forward table `>= E`, its restriction has forward table
  `>= E_1`. By Lemma 2 of the canonical-table artifact, `sigma' = sigma_(rho, nu_1)`
  is a left inverse of the same `tau_rho`. Strictness of either design means that
  `tau_rho` is not surjective. QED

**Corollary C'.** Suppose some design has a strict realization. Then some design
`D*` with a minimal `E*` in `𝓕_(D*)` and connected `Gamma_(E*)` is strict over
`U_(E*)`, and

```text
U_(E*) = Hol_M(E*) = < M' | b_1(Gamma_(E*)) cycle holonomies >,       x_s = w_s.
```

The encoder memory generates the canonical host, and every decoder address is a
path holonomy of memory differences.

*Proof.* Start from a strict `(D, E)` over `U_E` (Theorem A of the canonical-table
artifact) and repeat two moves.
- **Restrict** to the component of `1_S` (Proposition C). The host of `D_1` is
  `U_(E_1) = Hol_M(E_1)`. It maps onto the memory subgroup of `U_E`, because
  `E_1` omits the other components' cycles. Its reverse table on `M x S_1` is
  therefore finer, and strictness survives (Lemmas 2 and 5 there).
- **Minimize** `E` inside `𝓕` (Theorem A there). The host only gets freer, so
  strictness survives.

Each nontrivial move lowers `|S| + #edges`, so the process stops at a connected
minimal pair. QED

## 3. The decoder's memory group must be nonamenable

**Theorem Am.** Let `tau` and `sigma` be cellular automata over a group `G` with
`sigma tau = id`, and let `sigma` have memory `S`. If `<S>` is amenable, then `tau`
is surjective.

*Proof.*
- **`sigma` is surjective.** It has a right inverse.
- **Restriction to `H = <S>`.** `sigma` acts independently on each left coset
  `gH` by a copy of the automaton `sigma_H` over `H` with the same rule. So
  `sigma_H` is surjective: a target on one coset extends to a target on `G`, and
  the restriction of its preimage works.
- **`sigma_H` is pre-injective.** `H` is amenable, so by the Garden of Eden
  theorem (`amenable-groups-satisfy-the-garden-of-eden-theorem`) the surjective
  `sigma_H` is pre-injective.
- **`sigma` is pre-injective over `G`.** Two distinct asymptotic configurations
  with equal images differ on some coset `gH`. Their restrictions to that coset
  are distinct, asymptotic and have equal images, which is impossible.
- **Conclusion.** A decoder with a section is pre-injective only if it is
  bijective (`split-decoders-have-generic-cantor-fibers`). So `sigma` is
  bijective, and `tau = sigma^(-1)` is surjective. QED

**Design-level filter.** Let `E` be in `𝓕_D`. Every realization with forward table
`>= E` receives a homomorphism from `U_E`. That homomorphism maps the decoder
subgroup `Hol_S(E)` onto the realization's decoder memory group, and quotients of
amenable groups are amenable. So:

> If `Hol_S(E)` is amenable, then no realization of `D` with forward table `>= E`
> is strict. The filter reads only the holonomies of the memory difference graph:
> no rule and no reverse product.

**Instances.**
- **Decoder memory `{1, a}`**, for any encoder memory and any rules: `<a>` is
  cyclic, so there is no strict pair. The rectangle-clauses artifact excludes the
  case where both memories have size two; this is the one-sided strengthening. It
  also explains why the Hilbert hotel design dies in section 5 of the
  canonical-table artifact.
- **Decoder memories generating** a virtually solvable or locally finite group,
  or any other amenable group, in some group realizing the forward table.
- **Consequence for search.** A strict pair needs a nonsofic encoder memory group,
  since `tau` is induced from `<M>` and sofic groups are surjunctive. It also
  needs a nonamenable decoder memory group on which `sigma` violates Myhill's
  converse. Sofic and nonamenable is allowed on the decoder side.

**Relation to the literature.** The Garden of Eden theorem for amenable groups is
Ceccherini-Silberstein, Machì and Scarabotti. The equivalence of pre-injectivity
and bijectivity for split decoders is landed in the repository. Capobianco, Kari
and Taati (arXiv:1507.02472) study the dual pair post-surjectivity and
pre-injectivity. No novelty is claimed beyond the one-sided local form: only the
decoder's memory group has to be amenable.

## 4. One independent cycle presents a one-relator group

**Corollary U.** Let `E` be in `𝓕_D` with `Gamma_E` connected and
`b_1(Gamma_E) <= 1`. Then `U_E` is free or a one-relator group on `M'`. If the
realization over `U_E` is strict, then `U_E` is a non-sofic one-relator group.

*Proof.* The first sentence is Theorem H. A strict realization makes `U_E`
non-surjunctive, and sofic groups are surjunctive
(`sofic-groups-are-surjunctive`). QED

With Corollary C', a counterexample to Gottschalk's conjecture has one of two
forms:
- a connected minimal design with at least two independent coincidence cycles, or
- a non-sofic one-relator group.

The latter answers Pestov's Question 4.10 (`one-relator-groups-sofic`) negatively.
By the landed one-relator region, such a group is torsion-free, locally indicable,
and its relator has primitivity rank two
(`nonsofic-one-relator-relator-has-primitivity-rank-two`). So a proper-power
holonomy, or any relator already proved to give a sofic group, cannot be the
unique cycle of a strict design.

## 5. Scope

- Nothing here decides Gottschalk's conjecture.
- Theorem H is a Tietze normal form.
- Proposition C and Corollary C' refine Theorem A of the canonical-table artifact.
- Theorem Am is the local Garden of Eden obstruction.
- Corollary U links the design search to the one-relator soficity region.
- The remaining finitary core is to find rules whose minimal forward sufficiency
  forces at least two independent cycles, in a nonsofic memory holonomy group with
  a nonamenable decoder subgroup, while every minimal reverse hinge keeps a
  nontrivial word. Or to prove that no rules do.

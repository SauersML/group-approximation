# Rokhlin deficit windows: difference-subgroup localization, read bounds, and self-copy collapse

Lane `w5-inf-c`, 2026-09-12. Target: `bernoulli-rokhlin-entropy-maximal-for-every-group` (INF).
Nothing here decides INF. Sections 1–2 prove two filters on deficit configurations that use no
finite models of the ambient group.

## 0. Conventions

`G` is a countable group, `|A| = q >= 2`, and `(k, E, F, psi)` is a configuration as in
`bernoulli-rokhlin-deficit-has-a-finitary-witness`: finite `E, F ⊂ G`, `x` iid uniform on `A^k`
over `G`, `y_f = psi((x(fe))_(e in E))`, and

    Phi(k,E,F,psi) = (1/k) [ H(psi(x|_E)) + H( x(1) | (y_f)_(f in F) ) ].

A deficit witness is a configuration with `Phi < log q`. `H = <E E^-1>` denotes the subgroup
generated by the differences `e e'^-1` of the window. `F_1 = F ∩ E^-1` is the set of codewords
that read the site `1`, since `f e = 1` iff `f = e^-1`.

## 1. The window's difference subgroup carries every deficit

**Theorem 1.1.** If `H = <E E^-1>` is finite, or is Rokhlin-maximal at `q`, then
`Phi(k,E,F,psi) >= log q`. In particular `H` is infinite and not Rokhlin-maximal (so nonsofic)
for every deficit witness, whatever `F` is.

*Proof.*
1. **Drop independent codewords.** Join `f ~ f'` in `F` when `fE ∩ f'E` is nonempty. Let `C` be
   the union of the components that meet `F_1`. If `f` is not in `C`, then `fE` misses `CE` and
   misses `1`. So `y_(F \ C)` is a function of `x` on sites disjoint from `CE ∪ {1}`, hence
   independent of `(x(1), y_C)`, and `H(x(1) | y_F) = H(x(1) | y_C)`. If `C` is empty,
   `Phi >= log q` at once, so assume it is not.
2. **One coset.** If `f e = f' e'` then `f^-1 f' = e e'^-1 ∈ H`, so each component lies in one
   left coset of `H`. Every element of `F_1` has the form `e^-1`, and `e^-1 = e_0^-1 (e_0 e^-1)`,
   so `C ⊂ e_0^-1 H` for any fixed `e_0 ∈ E`.
3. **Transport into `H`.** Put `sigma(s) = e_0 s e_0^-1`, `C'' = e_0 C ⊂ H` and
   `E' = E e_0^-1 ⊂ E E^-1 ⊂ H`. Then `sigma(f e) = (e_0 f)(e e_0^-1)` and `sigma(1) = 1`.
   Since `sigma` is a bijection of `G`, the configuration `(k, E', C'', psi')` with
   `psi'((z_(e e_0^-1))) = psi((z_e))` has exactly the same coincidences among its reads, and the
   same special site, as `(k, E, C, psi)`. Pushing `x` forward along `sigma` gives an iid field on
   the transported sites. So `(x(1), y_C)` and `(x'(1), y'_(C''))` have the same law, and the
   configuration lives entirely inside `H` with the same value of `Phi`.
4. **Infinite `H`.** If `H` is Rokhlin-maximal at `q`, every configuration over `H` has
   `Phi >= log q` by `bernoulli-rokhlin-deficit-has-a-finitary-witness`.
5. **Finite `H`.** Take `x` iid over `H` and all codewords `y_h`, `h ∈ H`, with window `E'`. Then
       |H| k log q = H(x_H) <= H(y_H) + H(x_H | y_H)
                  <= |H| H(psi) + sum_h H(x(h) | y_(h C'')).
   Left translation by `h` preserves reads, since `(h c) e' = h (c e')`, so every summand equals
   `H(x(1) | y_(C''))`. Dividing by `|H| k` gives `Phi >= log q`. QED.

**Corollary 1.2.** No configuration with `|E| <= 2` is a deficit witness, over any group. Here
`H` is cyclic: finite, or infinite cyclic and sofic, hence Rokhlin-maximal by item 4 of
`seward-per-group-rokhlin-entropy-of-bernoulli-shifts`.

**Corollary 1.3.** If `E` lies in a left or right coset of a Rokhlin-maximal subgroup `K`, then
`Phi >= log q`: `E E^-1` lies in a conjugate of `K`, and maximality passes to subgroups
(`bernoulli-rokhlin-maximality-passes-to-subgroups`).

**Relation to the landed localization.** `sofic-radical-localizes-bernoulli-deficit-witnesses`
places a sofic-invisible difference inside `K = <E ∪ F>`. Theorem 1.1 says the host question is
carried by `<E E^-1>` alone: the codeword set `F` can be anything, and after step 3 the witness is
a configuration of the difference subgroup. The smallest windows that can be witnesses have
`|E| = 3`, with `<e_1 e_2^-1, e_1 e_3^-1>` a two-generated non-maximal group.

## 2. Information about one site is bounded by the codewords that read it

**Theorem 2.1.** For every configuration, with `m = |F ∩ E^-1| <= |E|`,

    I( x(1) ; y_F ) <= min{ k log q , m H(psi(x|_E)) }.

So `Phi >= max{ H(psi)/k , log q - (m-1) H(psi)/k } >= log q / m` when `m >= 1`, and
`Phi >= log q` when `m = 0`.

*Proof.* `y_(F \ F_1)` is a function of sites other than `1`, so it is independent of `x(1)`.
By the chain rule,
    I(x(1); y_F) = I(x(1); y_(F_1) | y_(F \ F_1)) <= H(y_(F_1)) <= sum_(f in F_1) H(y_f) = m H(psi),
because each `fE` consists of `|E|` distinct sites carrying iid values. Also
`I(x(1); y_F) <= H(x(1)) = k log q`. Substituting in `Phi = (1/k)[H(psi) + k log q - I]` gives the
first bound; `H(x(1) | y_F) >= 0` gives `Phi >= H(psi)/k`; the maximum of the two is smallest at
`H(psi)/k = log q/m`. QED.

**Corollary 2.2.** A configuration with `Phi < log q / m` has `|E| >= |F ∩ E^-1| > m` and
`H(psi(x|_E)) < k log q / m`.

**Scope.** This is the Rokhlin analogue of
`transport-identity-gives-reciprocal-memory-entropy-bound`, which concerns decoder memory of
injective automata. It is Shannon subadditivity only. A uniform lower bound needs an argument
that averages over codewords, which is where every known model-free attempt stops.

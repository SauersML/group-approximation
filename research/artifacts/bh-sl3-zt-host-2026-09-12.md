# Boone–Higman for linear groups over polynomial rings

Lane `bh-sl3-zt-host`, 2026-09-12. Target: embed `SL_3(Z[t])` in a finitely
presented simple group. Not independently reviewed; the imports are listed in §5.

## Result

**Theorem.** Let `m >= 1`, `k >= 0`, `A = Z[1/m]`, `R = A[t_1,...,t_k]` and
`N >= 1`. Every subgroup of `GL_N(R)` embeds in a finitely presented simple group.
So every finitely generated subgroup of `GL_N(Q[t_1,...,t_k])` does, and in
particular `SL_3(Z[t])` does.

The host is `G = R^n x| E_n(R)` with `n = max(k+4, 2N)`.
1. `G` is self-similar (§1). It acts on `Z_p^n x Z_p^k` for a prime `p` not
   dividing `m`. The last `k` coordinates are parameters at which the polynomial
   entries are evaluated, and the states use the substitutions `t_j -> a_j + p t_j`.
2. `R^n x| E_n(R)` is finitely presented whenever `E_n(R)` is and `n >= 4` (§2).
3. `E_n(R)` is finitely presented for `n >= k+4` (§3).
4. Zaremsky's Theorem 1.1 and the Whitehead embedding `GL_N(R) -> E_{2N}(R)`
   finish the proof (§4).

## 0. Conventions

- `[a,b] = a b a^-1 b^-1`, so `[AB,C] = A[B,C]A^-1 [A,C]` and `[a,bc] = [a,b] · b[a,c]b^-1`.
- Vectors are columns. `G` consists of the maps `v -> gv + b`, with product
  `(g,b)(g',b') = (gg', gb' + b)`.
- `e_ij(r)` is the elementary matrix and `tau_v` the translation by `v`, with
  `g tau_v g^-1 = tau_(gv)` and `e_ij(r) e_l = e_l + r δ_jl e_i`.
- Steinberg relations: `e_ij(r) e_ij(s) = e_ij(r+s)`;
  `[e_ij(r), e_jl(s)] = e_il(rs)` for `i != l`; `[e_ij(r), e_kl(s)] = 1` for
  `j != k` and `i != l`.

## 1. Self-similarity

Since `p` does not divide `m`, `A ⊂ Z_p` and `A/pA = F_p`. Every element of `A`
is congruent mod `pA` to a unique digit in `{0,...,p-1}`. Let
`X = Z_p^n x Z_p^k`, and let `G`, or `R^n x| SL_n(R)`, act on `X` by

```text
(g,b) · (v,s) = (g(s) v + b(s), s).
```

**(a) It is an action.** `(g,b)·((g',b')·(v,s)) = (g(s)g'(s)v + g(s)b'(s) + b(s), s)`,
which is `(gg', gb'+b)·(v,s)`.

**(b) It acts on a tree.** Let `D = {0,...,p-1}^(n+k)`. Writing `x = x_0 + p x'`
with `x_0 in D` and iterating identifies `X` with the boundary of the rooted
`d`-regular tree, where `d = p^(n+k)`. Level-`j` vertices are the classes in
`X / p^j X`. A polynomial with coefficients in `A ⊂ Z_p` preserves congruence mod
`p^j`. So each element, and its inverse, permutes each level, and `G` maps to
`Aut(T_d)`.

**(c) It is faithful.** Suppose `(g,b)` acts trivially.
- At `v = 0` we get `b(s) = 0` for every `s in Z_p^k`, so `b = 0`, because `Z_p`
  is infinite.
- Then `g(s)v = v` for all `v` and `s`, so `g(s) = I` for every `s`, and `g = I`.

**(d) States.** Fix a first-level vertex `(e,a)` with `e in {0..p-1}^n` and
`a in {0..p-1}^k`.
- Let `σ_a : R -> R` be the ring endomorphism with `t_j -> a_j + p t_j`, fixing
  `A`. For every `f in R`, `σ_a(f) - f(a) in pR`, because
  `(a_j + p t_j)^c ≡ a_j^c mod pR`.
- Let `u = σ_a(g) e + σ_a(b) in R^n`, and let `c in {0..p-1}^n` be the digit of
  `g(a)e + b(a) in A^n`. Then `u - c ≡ g(a)e + b(a) - c ≡ 0 mod pR`, so
  `w = (u - c)/p in R^n`.
- For `x = (e + p v', a + p s')`,

```text
g(a+ps')(e+pv') + b(a+ps') = σ_a(g)(s') e + σ_a(b)(s') + p σ_a(g)(s') v'
                           = c + p ( σ_a(g)(s') v' + w(s') ).
```

So `(g,b)` sends the vertex `(e,a)` to `(c,a)`, and its state there is
`(σ_a(g), w)`, the map `(v',s') -> (σ_a(g)(s') v' + w(s'), s')`. Since `σ_a` is a
ring map, `σ_a(E_n(R)) ⊆ E_n(R)` and `det σ_a(g) = σ_a(det g)`. So every state
lies in `G`, and `G` is self-similar in the sense of Zaremsky's `def:ss`
(arXiv:2405.09722v2 source, l.159–161): its image lies in `S_d ≀_d G`. The same
holds for `R^n x| SL_n(R)`.

**How this escapes `affine-self-similar-coordinate-rings-are-one-dimensional`.**
That claim is about affine maps `x -> Mx + b` of the digit tree of `O^n`, with
`M` and `b` constant. There the state of a translation at the digit `0` is
`b/π`, which forces (SC). Here the maps are not affine on `Z_p^(n+k)`, because
the linear part depends on the parameter coordinate. The state of `tau_b` at
`(0,a)` is `tau_((σ_a(b) - c)/p)`, so no subring of `Z_p` has to be
section-closed. It does not matter that `σ_a` is not surjective.

## 2. Finite presentation of the affine extension

**Lemma.** Let `R` be a commutative ring generated as a ring by a finite set `T`.
Let `n >= 4`, and suppose `E_n(R)` is finitely presented. Then `R^n x| E_n(R)`
is finitely presented.

Let `S = T ∪ {1}`. For `n >= 3`, `E_n(R)` is generated by the `e_ij(ε)` with
`ε in S`:
- `[e_il(μ), e_lj(ε)] = e_ij(με)` reaches every monomial;
- additivity reaches every sum of monomials.

**Presentation `P`.** The generators are the `x_ij(ε)` for `i != j` and
`ε in S`, together with `τ_1, ..., τ_n`. The relations are:
- **(E)** finitely many relators presenting `E_n(R)` on the `x_ij(ε)`;
- **(C1)** `[x_ij(ε), τ_k] = 1` for `k != j`;
- **(C2)** `x_ij(1) τ_j x_ij(1)^-1 = τ_j τ_i`;
- **(C3)** `[τ_k, τ_l] = 1`.

These hold in `G` with `τ_i = tau_(e_i)`. Let `π : P -> G` be the natural map.
- By (E), `e_ij(ε) -> x_ij(ε)` extends to a homomorphism `φ : E_n(R) -> P`.
- Write `x_ij(r) = φ(e_ij(r))` for every `r in R`. All Steinberg relations hold
  among the `x_ij(r)`.

**A. `[x_ij(r), τ_k] = 1` for every `r in R` and `k != j`.**
- For monomials, induct on degree: `x_ij(με) = [x_il(μ), x_lj(ε)]` with
  `l ∉ {i,j,k}`, which needs `n >= 4`.
  - `x_il(μ)` commutes with `τ_k` by induction, since `k != l`.
  - `x_lj(ε)` commutes with `τ_k` by (C1).
- A general `r` is a signed sum of monomials, and `x_ij` is additive.

Put `y^k_i(r) = [x_ik(r), τ_k]` for `k != i`. In `G` this is `tau_(r e_i)`.

**B. `y^k_i(r)` commutes with every `τ_l`.**
- **Case `l != k`.** `τ_l` commutes with `x_ik(r)` by A and with `τ_k` by (C3).
- **Case `l = k`.** Let `g = x_ik(r)` and `Y = g τ_k g^-1`; we need `[τ_k, Y] = 1`.
  - Pick `l ∉ {i,k}` and `h = x_kl(1)`. By the first case, `[τ_l, Y] = 1`.
  - `h τ_k h^-1 = τ_k` by (C1), and `h τ_l h^-1 = τ_l τ_k` by (C2).
  - `h g h^-1 = x_il(-r) g`, and `x_il(-r)` commutes with `g` (Steinberg) and
    with `τ_k` (A). So `h Y h^-1 = Y`.
  - Conjugating `[τ_l, Y] = 1` by `h` gives `[τ_l τ_k, Y] = 1`, hence `[τ_k, Y] = 1`.

**F1. For distinct `i, k, k'`, `y^k_i(r) = y^(k')_i(-r)^-1`.**
- Conjugate `[x_ik(r), τ_k'] = 1` (A) by `u = x_kk'(1)`. We have
  `u x_ik(r) u^-1 = x_ik'(-r) x_ik(r)` and `u τ_k' u^-1 = τ_k' τ_k`.
- Expanding with the identities of §0, A and B:
  `1 = [x_ik'(-r) x_ik(r), τ_k' τ_k] = x_ik'(-r) y^k_i(r) x_ik'(-r)^-1 · y^(k')_i(-r)`.
- `x_ik'(-r)` commutes with `x_ik(r)` and with `τ_k`, hence with `y^k_i(r)`.
- Applying F1 twice through some `k' ∉ {i,k,k''}` (`n >= 4`) gives
  `y^k_i(r) = y^(k'')_i(r)`. Write `y_i(r)`.

**F2. `y_i(r+s) = y_i(s) y_i(r)` and `y_i(1) = τ_i`.**
- `[x_ik(r) x_ik(s), τ_k] = x_ik(r) y^k_i(s) x_ik(r)^-1 · y^k_i(r)`.
- Represent `y_i(s)` as `y^(k')_i(s)` with `k' ∉ {i,k}`. It commutes with
  `x_ik(r)` by the Steinberg relations and A.
- `y^k_i(1) = τ_k τ_i τ_k^-1 = τ_i` by (C2) and (C3).
- So `y_i : R -> P` is a homomorphism with abelian image.

**F3. `[y_i(r), y_j(s)] = 1` for `i != j`.**
- Take `y_i(r) = y^k_i(r)` with `k ∉ {i,j}`, and `y_j(s) = y^(k')_j(s)` with
  `k' ∉ {i,j,k}`.
- `y_j(s)` commutes with `τ_k` by B.
- `y_j(s)` commutes with `x_ik(r)`: `x_ik(r)` commutes with `x_jk'(s)` since
  `k != j` and `i != k'`, and with `τ_k'` by A.

**F4. For `g = x_ab(r')` with `r' in R`: `g y_i(r) g^-1 = y_i(r)` if `b != i`,
and `g y_i(r) g^-1 = y_i(r) y_a(r'r)` if `b = i`.**
- **Case `b != i`.** Take `k ∉ {i,a,b}`. Then `g` commutes with `x_ik(r)` and
  with `τ_k`.
- **Case `b = i`.** Take `k ∉ {i,a}`.
  - `g x_ik(r) g^-1 = x_ak(r'r) x_ik(r)` and `g τ_k g^-1 = τ_k`.
  - So `g y^k_i(r) g^-1 = x_ak(r'r) y_i(r) x_ak(r'r)^-1 · y^k_a(r'r)`.
  - `x_ak(r'r)` commutes with `y_i(r) = y^(k')_i(r)` for `k' ∉ {i,a,k}`.

**Conclusion.**
1. By F2 and F3, `z(v) = y_1(v_1) ··· y_n(v_n)` is a homomorphism `R^n -> P`. It
   satisfies `π z(v) = tau_v`, so `z` is injective, and `π` maps its image `N`
   isomorphically onto `R^n`.
2. `N` contains every `τ_i` (F2). It is normalized by every `τ_l` (B) and by
   every `x_ab(r')` (F4). So `N` is normal.
3. `P/N` is generated by the images of the `x_ij(ε)`, so `φ` induces a surjection
   `E_n(R) -> P/N`.
4. Composing it with `P/N -> G/R^n = E_n(R)` gives the identity. So `P/N -> G/R^n`
   is an isomorphism.
5. Therefore `π` is an isomorphism, and `G` is finitely presented. ∎

## 3. Finite presentation of `E_n` over polynomial `S`-integers

**Proposition.** Let `A = Z[1/m]`, `R = A[t_1,...,t_k]` and `n >= k+4`. Then
`E_n(R)` is finitely presented.

**Inputs.** Here `K_2(n,S) = ker(St_n(S) -> E_n(S))`.
1. **Krstić–McCool, Thm 3** (JPAA 141 (1999) 175–183), read through the quote in
   Ershov–Jaikin-Zapirain arXiv:0809.4095 §6.1. `St_n(S)` is finitely presented
   for every finitely presented associative ring `S` and every `n >= 4`. On main
   as `steinberg-finite-presentation-and-kazhdan-theorem`.
2. **Stability** (van der Kallen; Weibel, *K-book* III, Remark 5.5.2). For `S`
   commutative noetherian of Krull dimension `d`, `K_2(n,S) -> K_2(S)` is an
   isomorphism for `n >= d+3`. Here `dim R = k+1` and `dim A = 1`.
3. **Homotopy invariance** (Weibel III, Ex. 5.2.3). `K_2(S) -> K_2(S[t])` is an
   isomorphism for `S` regular noetherian. Iterate along
   `A ⊂ A[t_1] ⊂ ... ⊂ R`.
4. **`SL_n(A)` is finitely presented for `n >= 3`.** Borel–Serre 1976, the
   reference Zaremsky cites for `GL_n(Z[1/m])` (source l.336); classical for
   `m = 1`. `A` is Euclidean, with norm the absolute value of the part prime to
   `m`, so `SL_n(A) = E_n(A)`.

**Proof.**
1. The square with top `K_2(n,A) -> K_2(n,R)`, bottom `K_2(A) -> K_2(R)` and the
   stabilization maps as verticals commutes.
2. By input 3 the bottom map is onto. By input 2 the left map is onto and the
   right map is injective. So the top map is onto.
3. By inputs 1 and 4, `St_n(A)` and `E_n(A)` are finitely presented. So
   `K_2(n,A)` is the normal closure of finitely many `w_1, ..., w_q`.
4. The normal closure of their images in `St_n(R)` contains the image of
   `K_2(n,A)`, which is `K_2(n,R)`, and lies inside `K_2(n,R)`.
5. So `E_n(R) = St_n(R) / <<w_1,...,w_q>>`, with `St_n(R)` finitely presented by
   input 1. ∎

**Remarks.**
- For `m = 1`, `K_2(Z) = Z/2` (Weibel III, Ex. 5.2.2), so
  `K_2(n, Z[t_1..t_k]) = Z/2`.
- Suslin's `SL_n(Z[t]) = E_n(Z[t])` is not needed.
- **Consistency.**
  - Krstić–McCool show `SL_3(Z[t])` is not finitely presented.
  - Bux–Mohammadi–Wortman (arXiv:0801.1332, Thm 1) show `SL_n(Z[t])` is not
    `FP_(n-1)`, and write that "little is known" about its finiteness properties.
  - Neither contradicts finite presentation for `n >= 5`.
- Finite presentation of `E_5(Z[t])` is very likely known to experts. No novelty
  is claimed for §3.

## 4. Assembly

1. `g -> diag(g, g^-1)` is an injective homomorphism `GL_N(R) -> E_(2N)(R)`
   (Whitehead's lemma; Weibel III, Ex. 1.2.1, read 2026-09-12).
2. With `n = max(k+4, 2N)` we get `GL_N(R) <= E_n(R) <= G`.
3. `E_n(R)` is finitely presented by §3.
4. `G` is finitely presented by §2, since `R` is generated by `1/m, t_1, ..., t_k`.
5. `G` is self-similar on `T_(p^(n+k))` by §1.
6. By Zaremsky's `thrm:main` (arXiv:2405.09722v2 source, l.121–123; Bull. LMS 2025,
   doi:10.1112/blms.70022), `G` embeds in a finitely presented simple group, and
   so does every subgroup of `G`.
7. The generators of a finitely generated subgroup of `GL_N(Q[t_1..t_k])`, and
   their inverses, have entries in some `Z[1/m][t_1..t_k]`. ∎

**Restriction of scalars.** Suppose `S ⊇ R` is commutative and finitely generated
and projective as an `R`-module. Choose `Q` with `S^N ⊕ Q ≅ R^M`. Then
`g -> g ⊕ 1_Q` embeds `GL_N(S)` in `GL_M(R)`. For example this covers
`Z[1/m][x,y]/(y^2 - x^3 - x)`, which is free over `Z[1/m][x]`.

## 5. Relation to the graph

- **Root `char-zero-linear-groups-satisfy-boone-higman`.** Attempt 2 said affine
  self-similar hosts die for commutative coordinates. That covered the digit tree
  of `O^n`; parameter coordinates escape (remark in §1). The root stays open.
- **`el3-z-t-embeds-in-no-host-with-number-field-local-groups`.** The local group
  of the Röver–Nekrashevych host is `G`, which contains `E_3(Z[t])` and so is not
  linear over a number field. No conflict.
- **`char-zero-algebra-unit-hosts-exclude-unipotents`.** That excludes unit groups
  of algebras modulo central subgroups. Here the simple host is
  `[V_d(G), V_d(G)]`, which is not of that form.
- **Attempt 4, the property (T) exclusions.** These concern a-T-menable hosts,
  tree lattices and graph towers, and `V_d(G)` is none of them.

## 6. Still open

- **Laurent coordinates, starting with `SL_3(Z[t^(+-1)])`.** `σ_a(t^-1)` is not a
  Laurent polynomial. Closing `Z[t^(+-1)]` under all the substitutions adds the
  infinitely many denominators `a + pb + ... + p^j t`, so the section-closed ring
  is not finitely generated and the affine host is not finitely presented.
- **Denominators in `t`.** Finitely generated subgroups of `GL_n(Q(t))` whose
  entries need non-constant denominators, and coordinate rings that are not
  projective over any `Z[1/m][t_1..t_k]`.

# Braid groups and the Haagerup property, part 1: closure properties and the reduction to punctured-sphere mapping class groups

Lane z3-07-braid-haagerup, Zaremsky Problem 3.7 (`zaremsky-3-07-braid-groups-haagerup`), 2026-09-13.
Status: unreviewed. Everything here is standard or elementary; the point is to pin the exact equivalences.

## 0. Conventions

Groups are countable and discrete. A function `ψ: G → [0, ∞)` is conditionally negative definite (cnd) if
`ψ(1) = 0`, `ψ(g^{-1}) = ψ(g)`, and `Σ_{i,j} c_i c_j ψ(g_j^{-1} g_i) ≤ 0` whenever `Σ_i c_i = 0`. It is proper
if `{g : ψ(g) ≤ R}` is finite for every `R`. `G` has the Haagerup property (is a-T-menable) if it has a proper
cnd function. Equivalently, `G` has an affine isometric action on a real Hilbert space whose cocycle `b`
satisfies `‖b(g)‖ → ∞` as `g → ∞`, with `ψ(g) = ‖b(g)‖²`. Standard reference: Cherix, Cowling, Jolissaint,
Julg, Valette, *Groups with the Haagerup property: Gromov's a-T-menability*, Progress in Mathematics 197,
Birkhäuser (2001).

## 1. Closure properties used in this region (with proofs)

**(H1) Subgroups.** Restrict a proper cnd function.

**(H2) Finite direct products.** For `ψ_1` on `G_1` and `ψ_2` on `G_2`, `ψ(g, h) = ψ_1(g) + ψ_2(h)` is cnd (a sum
of pullbacks of cnd functions along homomorphisms) and proper (its sublevel sets lie in products of
sublevel sets).

**(H3) Finite-index overgroups.** Let `H ≤ G` with `[G : H] = m < ∞`, and let `H` act by affine isometries
`α` on a Hilbert space `K` with cocycle `b`, `‖b(h)‖ → ∞`. Choose left coset representatives `t_1, …, t_m`.
For `g ∈ G` and each `i`, write `g t_i = t_{σ_g(i)} h(g, i)` with `h(g, i) ∈ H`. On `V = K^m` put
`(g · v)_{σ_g(i)} = α(h(g, i)) v_i`. The identity `h(g g', i) = h(g, σ_{g'}(i)) h(g', i)` shows this is an
affine isometric action of `G` (the induced action). Its cocycle has squared norm
`‖B(g)‖² = Σ_i ‖b(h(g, i))‖²`. Since `h(g, i) = t_{σ_g(i)}^{-1} g t_i` and there are finitely many `t_j`,
the elements `h(g, i)` leave every finite subset of `H` when `g` leaves every finite subset of `G`, so
`‖B(g)‖ → ∞`.

**(H4) Quotients by finite normal subgroups.** Let `G` act properly by affine isometries on `K` and let `N`
be finite and normal. The fixed set `K^N` is a nonempty closed affine subspace (it contains the barycenter
of any `N`-orbit), and it is `G`-invariant because `N` is normal. `G/N` acts on `K^N`; for `v_0 ∈ K^N`
the displacement `‖g v_0 − v_0‖` tends to infinity with `g`, hence with `gN`.

**(H5) Free groups.** The word length with respect to a free basis is cnd (Haagerup, *An example of a
non nuclear C\*-algebra which has the metric approximation property*, Invent. Math. 50 (1979)) and proper.
So `Z` and `F_k` have the Haagerup property.

**(H6) Kazhdan subgroups.** If `H` has property (T), every cnd function on `H` is bounded (every affine
isometric action of `H` has a fixed point: Delorme–Guichardet). So a group with the Haagerup property
has no infinite subgroup with property (T).

## 2. Braid-group facts

- **(B1)** `B_n ≤ B_{n+1}` via `σ_i ↦ σ_i` is injective (adding a strand far to the right).
- **(B2)** `P_n = ker(B_n → S_n)` has index `n!`. Artin combing: deleting the last strand is a split
  surjection `P_n → P_{n−1}` whose kernel is the free group `F_{n−1}` of loops of the last strand around the
  others. `P_{n−1}` acts on `F_{n−1}` by pure braid automorphisms: each free generator is sent to a conjugate
  of itself. So `P_n ≅ F_{n−1} ⋊ P_{n−1}` (Artin 1947; Farb–Margalit, *A Primer on Mapping Class Groups*,
  Chapter 9).
- **(B3)** For `n ≥ 3`, `Z(B_n) = Z(P_n) = ⟨Δ²⟩`, where `Δ²` is the full twist (Chow 1948).
- **(B4)** Deleting strands defines homomorphisms `P_n → P_m`, and they send the full twist to the full
  twist: `Δ_n² ↦ Δ_m²`. In particular `Δ_2² = σ_1²` generates `P_2 ≅ Z`.
- **(B5)** `B_n ≅ Mod(D_n)`, the mapping class group of the disk with `n` marked points fixing the boundary.
  Capping the boundary with a once-punctured disk gives a surjection `P_n → PMod(S_{0,n+1})` whose kernel is
  generated by the boundary twist, which is `Δ²` (the capping homomorphism: Farb–Margalit, §3.6 and
  Chapter 9). So `P_n / Z(P_n) ≅ PMod(S_{0,n+1})` for `n ≥ 3`.
- **(B6)** `PMod(S_{0,m})` is the kernel of the action on the `m` punctures, of index `m!` in `Mod(S_{0,m})`.

## 3. Proposition A: `P_n ≅ Z × PMod(S_{0,n+1})` for `n ≥ 3`

Let `f: P_n → P_2 ≅ Z` delete strands `3, …, n`, and let `K = ker f`. By (B4), `f(Δ^{2m}) = σ_1^{2m}`, so
`f` is injective on `⟨Δ²⟩` and `K ∩ ⟨Δ²⟩ = 1`. For `g ∈ P_n` with `f(g) = σ_1^{2m}`, `g Δ^{−2m} ∈ K`, so
`K ⟨Δ²⟩ = P_n`. Both subgroups are normal (`Δ²` is central) and they intersect trivially, so
`P_n = K × ⟨Δ²⟩`. Then `K ≅ P_n / ⟨Δ²⟩ = P_n / Z(P_n) ≅ PMod(S_{0,n+1})` by (B3) and (B5). ∎

## 4. Theorem B: for `n ≥ 3`, `B_n` has the Haagerup property iff `Mod(S_{0,n+1})` does

- `B_n` ⟺ `P_n`: (H1) and (H3), since `[B_n : P_n] = n!`.
- `P_n` ⟺ `PMod(S_{0,n+1})`: Proposition A, with (H1) for one direction and (H2), (H5) for the other.
- `PMod(S_{0,n+1})` ⟺ `Mod(S_{0,n+1})`: (H1) and (H3), by (B6). ∎

**Corollaries.**

- `B_n` has the property iff `B_n / Z(B_n)` does: `P_n/Z(P_n)` has index `n!` in `B_n/Z(B_n)`, and
  `P_n ≅ Z × P_n/Z(P_n)`.
- By (B1) and (H1), failure for `B_n` implies failure for `B_{n+1}`. Equivalently, the property for
  `Mod(S_{0,m+1})` implies it for `Mod(S_{0,m})` (`m ≥ 4`).
- "Every braid group has the Haagerup property" ⟺ "`Mod(S_{0,m})` has it for all `m`" ⟺ "it holds for
  infinitely many `m`".

## 5. Proposition C: `B_1`, `B_2`, `B_3` have the Haagerup property

`B_1 = 1` and `B_2 ≅ Z`. For `B_3`, Artin combing gives `P_3 ≅ F_2 ⋊ P_2` with `P_2 = ⟨Δ_2²⟩`. The full twist
of the first two strands is the boundary twist of the twice-marked disk, and it acts on the fiber
`F_2 = π_1(C ∖ {2 points})` (basepoint at the position of the third strand, outside the disk) as conjugation
by the loop `w` around both points. Semidirect products by inner automorphisms split: with `t = Δ_2²`,
the element `t' = w^{-1} t` commutes with `F_2` and generates a complement, so `P_3 = F_2 × ⟨t'⟩ ≅ F_2 × Z`.
By (H5), (H2) and (H3) (`[B_3 : P_3] = 6`), `B_3` has the Haagerup property. ∎

(Equivalently, `P_3 ≅ Z × PMod(S_{0,4})` with `PMod(S_{0,4}) ≅ F_2`.)

## 6. `B_4` is the smallest undecided case

By Theorem B, `B_4` has the Haagerup property iff `PMod(S_{0,5})` does. The Birman exact sequence
`1 → π_1(S_{0,4}) → PMod(S_{0,5}) → PMod(S_{0,4}) → 1` has free quotient `PMod(S_{0,4}) ≅ F_2`, so it splits:
`PMod(S_{0,5}) ≅ F_3 ⋊ F_2`. Here `F_3` is the point-pushing subgroup, and a section `F_2 → PMod(S_{0,5})`
acts on it by conjugation, inducing the natural action of `PMod(S_{0,4})` on `π_1(S_{0,4})` up to inner
automorphisms. The monodromy contains pseudo-Anosov classes of `S_{0,4}`, so the fiber word length is
distorted exponentially. `S_{0,5}` has pairs of disjoint essential curves, whose Dehn twists span `Z^2`, so
the group is not hyperbolic. Dyer, Formanek and Grossman
(Arch. Math. 38 (1982)) relate `B_4 / Z(B_4)` to a subgroup of index 2 in `Aut(F_2)`; this is recorded as a
pointer only and was not re-verified here.

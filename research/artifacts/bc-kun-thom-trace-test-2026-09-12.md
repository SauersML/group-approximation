# Lück's trace test on the Kun--Thom actors: which projections can refute it

Lane `bc-kun-thom-trace-test`, 2026-09-12.

**Setting.**
- `q = p^f`, `r, d >= 3`, `R = F_q[x_1^(+-1), ..., x_d^(+-1)]`.
- `G = EL_r(R) semidirect SL_d(Z)`, with `SL_d(Z)` acting by monomial substitution.
- `P = P(q,r,d)` is the prime set of `kun-thom-actor-finite-subgroup-ring-has-finitely-many-primes`.
- `Lambda^G = Z[1/|H| : H <= G finite]`.
- `tau` is the canonical trace on `M_n(C*_r G)`, `tau(x) = sum_i x_ii(1)`.

**The trace test.** Lück (Invent. Math. 149 (2002); context, not imported): if the reduced
assembly map is surjective, then `tau(K_0(C*_r G))` lies in `Lambda^G`.

## 1. The target ring is exactly `Z[1/P]`

Every prime of `P` is the order of an element of `G`.
- **`p`:** the elementary matrix `e_12(1)` has order `p`.
- **`l` dividing `q^k - 1` with `1 <= k <= r`:** `SL_r(F_q) = E_r(F_q)` lies in `EL_r(R)`, and
  `|SL_r(F_q)| = q^(r(r-1)/2) prod_(j=2..r) (q^j - 1)`. For `k >= 2`, `q^k - 1` divides this
  order. For `k = 1`, `q - 1` divides `q^2 - 1`. Cauchy's theorem finishes.
- **Odd prime `l <= d + 1`:** the companion matrix of the cyclotomic polynomial `Phi_l` has size
  `l - 1 <= d`, determinant 1 and order `l`. Pad it with an identity block.
- **`l = 2`:** `diag(-1, -1, 1, ..., 1)`.

So `Lambda^G` contains `Z[1/P]`. With the landed containment, `Lambda^G = Z[1/P]`.

## 2. Algebraic idempotents pass the test

**Lemma A (finite-quotient trace).** Let `N` be a finite-index normal subgroup of `G` and `e` an
idempotent in `M_n(C[G])` with `supp(e) ∩ N ⊆ {1}`. Then `tau(e) ∈ (1/[G:N]) Z`.

*Proof.*
1. Let `F = G/N`, and let `ebar` be the image of `e` in `M_n(C[F])`. It is an idempotent.
2. `tau_F(ebar) = sum_(g in N) tr e_g = tr e_1 = tau(e)`.
3. `lambda_F(ebar)`, acting on `C^n ⊗ l^2(F)`, is an idempotent of integer rank `m`.
4. Its trace is `Tr lambda_F(ebar) = |F| tau_F(ebar)`, so `tau(e) = m/|F|`. QED

**Congruence quotients.** For a prime `p' != p`, let `I_(p')` be the ideal of `R` generated by
the `x^v - 1` with `v ∈ p' Z^d`.
- `I_(p')` is `SL_d(Z)`-invariant, and `R/I_(p') = F_q[(Z/p')^d]`.
- The principal congruence subgroup `Gamma(p')` acts trivially on `R/I_(p')`.
- Reduction gives a surjection `pi_(p') : G -> E_r(F_q[(Z/p')^d]) semidirect SL_d(Z/p')`, with
  kernel `N_(p')`.
- Since `p' != p`, the algebra splits: `F_q[(Z/p')^d] ≅ F_q × F_(q^k)^((p'^d - 1)/k)`, with
  `k = ord_(p')(q)` (Galois orbits of characters).

So

```text
[G : N_(p')] = |SL_r(F_q)| · |SL_r(F_(q^k))|^((p'^d - 1)/k) · |SL_d(F_(p'))|.
```

**Lemma C (avoidance).** For every finite `S ⊆ G \ {1}`, `S ∩ N_(p') = ∅` for all large primes `p'`.
- **`g = (A, sigma)` with `sigma != 1`:** then `sigma ≢ 1 (mod p')` once `p'` exceeds every entry of
  `sigma - 1`.
- **`sigma = 1`, `A != 1`:** some entry of `A - 1` is a nonzero Laurent polynomial whose exponent
  vectors lie in a box of width `W`. For `p' > W` distinct exponents stay distinct modulo `p'`, so
  the entry is nonzero in `R/I_(p')`.

**Lemma B (an index coprime to `l`).** For every prime `l` outside `P` and every `M`, there is a
prime `p' > M` with `l ∤ [G : N_(p')]`.

*Proof.* `l` outside `P` means three things: `l != p`; `o := ord_l(q) > r`; and `l > d + 1`, so
`l >= 5`. By Dirichlet, choose `p'` in a residue class meeting three conditions.
- **(i)** `p' ≡ g (mod l)`, with `g` a primitive root mod `l`. Then `ord_l(p') = l - 1 > d`, so `l`
  divides no `p'^j - 1` with `j <= d`, and `l != p'`.
- **(ii)** For every odd prime `s` dividing `o`: `p' ≢ 0, 1 (mod s)`. Then `s` does not divide
  `p' - 1`, so `s` does not divide `k`.
- **(iii)** If `o` is even: `p' ≡ 3 (mod 4)`, and `q` is a quadratic residue mod `p'`. Then
  `v_2(p' - 1) = 1` and `q^((p'-1)/2) ≡ 1`, so `k` is odd. The residue condition is automatic when
  `f` is even. For odd `f` it is a congruence condition:
  - `p = 2`: `p' ≡ 7 (mod 8)`;
  - odd `p`: `(p'/p) = (-1)^((p-1)/2)`, by reciprocity with `(p' - 1)/2` odd.

*Compatibility of the conditions.*
- The moduli are `l`, the odd primes `s` dividing `o`, 4 or 8, and `p`.
- `s` divides `l - 1`, so `s != l`.
- The only possible coincidence is `s = p` with `p` odd. Then one needs a residue mod `p` that is
  `≢ 0, 1` and has the required Legendre symbol:
  - for `p ≡ 1 (mod 4)` (so `p >= 5`), a quadratic residue other than 1;
  - for `p ≡ 3 (mod 4)`, any non-residue.
- Every chosen residue is prime to its modulus, so Dirichlet applies.

*Conclusion.*
1. By (ii) and (iii), `gcd(k, o) = 1`.
2. For `j <= r`, `l` divides `(q^k)^j - 1` iff `o` divides `kj`, iff `o` divides `j`. That is
   impossible because `o > r`. Likewise `l ∤ q^j - 1`.
3. With (i), `l` divides none of `|SL_r(F_q)|`, `|SL_r(F_(q^k))|`, `|SL_d(F_(p'))|`.
4. By Lemma C, `p'` can be taken larger than any `M`. QED

**Theorem.** Every idempotent `e ∈ M_n(C[G])` has `tau(e) ∈ Z[1/P] = Lambda^G`.

*Proof.*
1. Lemma A with any avoiding `N` already makes `tau(e)` rational. Write `tau(e) = a/b` in lowest
   terms.
2. Fix a prime `l` outside `P` and put `S = supp(e) \ {1}`.
3. Lemmas B and C give a prime `p'` with `S ∩ N_(p') = ∅` and `l ∤ [G : N_(p')]`.
4. Lemma A gives `b | [G : N_(p')]`, so `l ∤ b`. QED

**Corollary.** Let `a = a* ∈ M_n(C[G])` with `lambda(a)` of finite spectrum `{lambda_1, ..., lambda_m}`.
1. `prod (a - lambda_i) = 0` in `M_n(C*_r G)`. Since `lambda` is injective on `C[G]`, the same
   product vanishes in `M_n(C[G])`.
2. Each spectral projection is `L(a)` for a Lagrange polynomial `L`, hence an idempotent of
   `M_n(C[G])`.
3. By the Theorem, its trace lies in `Lambda^G`.

So finite-spectrum elements never refute the trace test on a Theorem E actor.
Combined with `integral-spectra-of-small-capacity-are-finite`: for `a ∈ M_n(Z[i][G])`, any gapped
witness needs spectrum of logarithmic capacity at least 1.

## 3. Markov operators on coset spaces over Kazhdan subgroups are not reduced

For `H <= G`, `lambda_(G/H)` weakly contained in `lambda_G` forces `H` amenable. This is standard
context.
1. Restricted to `H`, the vector `delta_(eH)` is `H`-invariant.
2. `lambda_G|_H` is a multiple of `lambda_H`.
3. So `1_H ≺ lambda_H`, i.e. `H` is amenable.

The Theorem E subgroup `Gamma = EL_r(F_q[x_1, ..., x_d])` and `SL_d(Z)` are infinite Kazhdan
groups, hence nonamenable. So the Markov operators of `G/Gamma` and `G/SL_d(Z)` generate
C*-algebras that are not quotients of `C*_r G`. Their spectral projections are not elements of
`M_n(C*_r G)`, and they carry no canonical trace for the test.

## 4. What a refuting projection must look like

- **Not algebraic.** It lies in `M_n(C*_r G)` but not in `lambda(M_n(C[G]))` (Section 2).
- **Natural form.** A gapped spectral projection `chi_((-inf,c))(lambda(a))` of a self-adjoint
  `a ∈ M_n(C[G])` with infinite spectrum, with `c` in a gap.
- **Its trace is a limit of rationals.**
  - By Lemma C, `tau_(G/N_(p'))(a^m) = tau(a^m)` once `p'` is large (depending on `m`).
  - So the congruence-quotient spectral measures converge weakly to `mu_a`.
  - The gap has `mu_a`-measure 0, so the quotient mass of the gap tends to 0, and

    ```text
    tau(chi(a)) = lim_(p') #{eigenvalues of pi_(p')(a) below c} / (n [G : N_(p')]).
    ```

  - For `l` outside `P`, Lemma B keeps the denominators coprime to `l` along a subsequence.
- **What a refutation needs.** The limit must leave `Z[1/P]`: it must be irrational, or have an
  `l`-adic defect that no single finite quotient shows.
- **No mechanism yet.** Nothing in the graph controls such limits for a gapped element. The finite
  quotients are not tempered: they contain the trivial representation and other non-tempered
  representations, whose eigenvalues may sit in the gap with vanishing weight.

# Sparse free-phase support classification

## Result

The zero pattern of a standard signed-Hecke free-phase packet has a complete
group-theoretic support invariant.  Its phase support is the free factor
whose rank is the number of vertices minus the number of connected
components of the off-diagonal coefficient graph.

This answers the immediate sparse-regauge question sharply.  Sparsity can
produce a proper nonamenable infinite associated subgroup, but not a new
kind of subgroup: it always produces primitive free-factor support.  A
single termwise HNN transport between two such packets is therefore covered
by the existing residual-finiteness theorem for free-factor phase graphs.

## Setup

Let `F_D=<h_1,...,h_D>` and let `(E_(ij))` be matrix units in a finite
signed packet corner.  For

```text
W=sum_i h_i E_(ii),
Y=sum_(i,j)y_(ij)E_(ij),
```

one has the exact expansion

```text
WYW^*=sum_(i,j)y_(ij) E_(ij) h_i h_j^(-1).              (1)
```

Let `G_Y` have vertex set `{1,...,D}` and an undirected edge `{i,j}` when
at least one of `y_(ij),y_(ji)` is nonzero.  Diagonal coefficients contribute
no phase word.  Define

```text
H_Y=<h_i h_j^(-1):{i,j} in E(G_Y)>.
```

Equation (1) immediately places the packet in the algebraic corner over
`K times H_Y`.

## Exact computation of `H_Y`

Write the connected components as `C_1,...,C_c`, and choose a root
`r_alpha` in each component.  Set

```text
a_i=h_i h_(r_alpha)^(-1)  (i in C_alpha, i!=r_alpha).
```

Starting from the free basis `(h_1,...,h_D)`, order each component with its
root first and perform the elementary Nielsen replacements

```text
h_i |-> h_i h_(r_alpha)^(-1).
```

The resulting family

```text
(h_(r_1),...,h_(r_c),(a_i)_(i not a chosen root))       (2)
```

is a free basis of `F_D`.

Every edge difference belongs to the subgroup generated by the `a_i`.  In
fact, for `i,j in C_alpha`,

```text
h_i h_j^(-1)=a_i a_j^(-1),
```

with the convention `a_(r_alpha)=1`.  Conversely, connectedness gives a path
`i=v_0,v_1,...,v_n=r_alpha`, and telescoping yields

```text
(h_(v_0)h_(v_1)^(-1))...(h_(v_(n-1))h_(v_n)^(-1))
  =h_i h_(r_alpha)^(-1)=a_i.                            (3)
```

Hence

```text
H_Y=<a_i:i is not a chosen root> isomorphic to F_(D-c). (4)
```

By (2), this subgroup is generated by a subset of a free basis, so it is a
free factor.  It is proper whenever `c>=2`, and nonamenable exactly when
`D-c>=2`.

## Consequence for a sparse first chord

Suppose two endpoint contexts use independent free-phase factors and sparse
packets `X_0,X_1`.  A termwise stable-letter transport that fixes the finite
packet identifies the corresponding groups `H_(X_0)` and `H_(X_1)`.  By
(4), each is a free factor in its ambient free-phase coordinate.  Adding old
commuting phase data only gives the auxiliary graph homomorphisms allowed in
`free-factor-phase-graph-hnn-is-residually-finite`.

Thus such a cell can have a proper nonamenable edge—for instance a graph on
four vertices with one three-vertex connected component and one isolated
vertex has support `F_2`—but the HNN extension is residually finite.  If a
completed no-CE atlas were obtained solely from these cells, its canonical
corner trace would be Connes embeddable, contradicting the source property.

The live sparse possibilities must change at least one premise of the
classification: use phase labels whose difference subgroup is embedded
nonprimitively, couple multiple transports so no single support graph
controls the edge, or leave Bass--Serre/HNN transport.

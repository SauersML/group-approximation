# Normal rank-two free subgroups of SL_3(Z), and what it does to the free-by-free candidates (2026-09-16)

Frontier swarm, root `zaremsky-3-04-sl3z-coherent`, hole worked
`sl3z-contains-cd2-euler-positive-fibered-subgroup`.

Supports the claims `sl3z-normal-subgroup-class-stabilizers-are-polycyclic`
(Lemma S), `sl3z-normal-f2-subgroups-have-virtually-cyclic-quotients`
(Proposition A), the refuted claim `sl3z-contains-f2-by-free-subgroup`, and
the Bieri-type criterion `sl3z-contains-cd2-group-with-fg-nonfree-normal-subgroup`.

## 0. Summary

- **Lemma S.** If `N ◁ G <= SL_3(Z)` and `x in N` has infinite order, the
  stabilizer in `G/N` of the `N`-conjugacy class of `x` is
  `C_G(x)/C_N(x)`, a polycyclic group.
- **Proposition A.** If `N ◁ G <= SL_3(Z)` and `N ≅ F_2`, then `G/N` is finite
  or virtually infinite cyclic, and `G` is finitely presented.
- **Consequences.** `SL_3(Z)` contains no `F_2 x| F_m` with `m >= 2`, so the
  free-by-free groups that Kropholler–Walsh prove incoherent never occur in
  `SL_3(Z)` with fibre rank two. For `F_n x| F_m <= SL_3(Z)` with `n >= 3`,
  the monodromy acts with cyclic stabilizers on conjugacy classes of elements
  and of rank-two subgroups of the fibre, which excludes every monodromy
  preserving the boundary classes of a surface with boundary. Hyperbolic
  free-by-free groups are untouched.
- **Criterion C3.** Suppose a finitely generated `G <= SL_3(Z)` has `cd G <= 2`
  and a normal subgroup that is finitely generated, not free, and of infinite
  index. Then `SL_3(Z)` is incoherent (Bieri).
  - Criterion C1 implies C3.
  - Long–Reid's Proposition 5.2 is an instance of C3, once its hypothesis
    "not free" is read as "not virtually free".

No novelty is claimed for the classical inputs. Lemma S and Proposition A
were not found in the sources checked (Section 8), but the check was not
exhaustive.

- **(I5)** Nielsen–Schreier: subgroups of free groups are free. A free group
  of rank at least 2 is not solvable, so a solvable free group is trivial or

- **(I6)** A group containing a finitely presented subgroup of finite index is

## 2. Lemma S: class stabilizers for a normal subgroup

**Setting.** Let `G` be any group and `N ◁ G`. For `x in N` write
`[x]_N = {n x n^-1 : n in N}`. For a subgroup `A <= N` write
`[A]_N = {n A n^-1 : n in N}`.

**Action.** `g . [x]_N := [g x g^-1]_N` is well defined: if `x' = n x n^-1`,
then `g x' g^-1 = (g n g^-1)(g x g^-1)(g n g^-1)^-1` with `g n g^-1 in N`. It is
an action of `G` in which `N` acts trivially, so it descends to `G/N`. The same
holds for classes of subgroups.

**Lemma S (general groups).**

1. `Stab_G([x]_N) = N . C_G(x)`, so
   `Stab_{G/N}([x]_N) = N C_G(x) / N ≅ C_G(x) / C_N(x)`.
2. `Stab_G([A]_N) = N . N_G(A)`, so
   `Stab_{G/N}([A]_N) ≅ N_G(A) / N_N(A)`.

*Proof.* (1) Elements of `N` and of `C_G(x)` stabilize `[x]_N`. Conversely, if
`g x g^-1 = n x n^-1` with `n in N`, then `n^-1 g in C_G(x)` and
`g in N C_G(x)`. Since `N` is normal, `N C_G(x)` is a subgroup, and the second
isomorphism theorem gives `N C_G(x)/N ≅ C_G(x)/(C_G(x) ∩ N) = C_G(x)/C_N(x)`.
(2) is identical with `N_G(A)` in place of `C_G(x)`, and
`N_G(A) ∩ N = N_N(A)`. ∎

**Lemma S (in SL_3(Z)).** If `G <= SL_3(Z)`, `N ◁ G` and `x in N` has infinite
order, then `Stab_{G/N}([x]_N)` is polycyclic.

*Proof.* `C_G(x) <= C_{SL_3(Z)}(x)` is polycyclic by (I1). Subgroups and
quotients of polycyclic groups are polycyclic, and (1) finishes. ∎

**Corollary S1 (finite orbit).** If `G <= SL_3(Z)`, `N ◁ G`, and some `x in N`
of infinite order has finite `G`-orbit of `N`-conjugacy classes, then `G/N` is
virtually polycyclic. The stabilizer has finite index.

**Corollary S2 (free quotients).** If moreover `G/N` is free, every
`Stab_{G/N}([x]_N)` with `x` of infinite order is trivial or infinite cyclic,
by (I5).

## 3. Lemma N: automorphisms of F_2 preserve the commutator class up to inversion

Let `F = F(a, b)` and `c = [a, b] = a b a^-1 b^-1`.

**Lemma N.** For every `α in Aut(F)`, `α(c)` is conjugate in `F` to `c` or to
`c^-1`.

*Proof.* Let `P` be the set of `α in Aut(F)` with `α(c) = u c^ε u^-1` for some
`u in F` and `ε in {1, -1}`.

- `P` is a subgroup. Suppose `α(c) = u c^ε u^-1` and `β(c) = v c^δ v^-1`. Then
  `αβ(c) = α(v) α(c)^δ α(v)^-1 = (α(v) u) c^{εδ} (α(v) u)^-1`. Applying
  `α^-1` to `α(c) = u c^ε u^-1` gives
  `c = α^-1(u) α^-1(c)^ε α^-1(u)^-1`, so `α^-1(c)^ε = w c w^-1` with
  `w = α^-1(u)^-1`, and `α^-1(c) = w c^ε w^-1`.
- The generators from (I3) lie in `P`:
  - `σ(c) = b a b^-1 a^-1 = c^-1`;
  - `ι(c) = a^-1 b a b^-1 = a^-1 (b a b^-1 a^-1) a = a^-1 c^-1 a`;
  - `τ(c) = (ab) b (ab)^-1 b^-1 = a b b b^-1 a^-1 b^-1 = c`.

So `P = Aut(F)`. ∎

This is the algebraic shadow of the fact that every automorphism of `F_2` is
induced by a homeomorphism of the once-punctured torus, which preserves the
puncture loop up to orientation.

## 4. Proposition A

**Proposition A.** Let `G <= SL_3(Z)` and let `N ◁ G` with `N ≅ F_2`. Then:

1. `C_G(N)` is finite, and the monodromy `G/N -> Out(N) ≅ GL_2(Z)` has finite
   kernel `C_G(N) N / N ≅ C_G(N)`.
2. `G/N` is finite or has an infinite cyclic subgroup of finite index.
3. Every element of infinite order in `G/N` has monodromy of infinite order
   in `Out(N)`.
4. `G` is finitely presented. Either `G` is virtually `F_2`, or `G` has a
   finite-index subgroup `N x|_φ Z` with `φ` of infinite order in `Out(F_2)`.

*Proof.* Fix a basis `a, b` of `N` and put `c = [a, b]`. It is a nontrivial
reduced word, so it has infinite order.

*Step 1: `C_G(N)` is finite.* `C_G(N)` commutes with the infinite group `N`. If
`C_G(N)` were infinite, `<N, C_G(N)>` would be polycyclic by (I2). It contains
`N ≅ F_2`, which is not solvable. So `C_G(N)` is finite.

*Step 2: the monodromy.* Conjugation defines `μ: G -> Aut(N)` with
`μ(N) = Inn(N)`, and hence `μbar: G/N -> Out(N)`. If `μ(g)` is conjugation by
`n in N`, then `n^-1 g in C_G(N)`. So
`ker μbar = C_G(N) N / N ≅ C_G(N)/(C_G(N) ∩ N) = C_G(N)/Z(N) = C_G(N)`,
because `Z(F_2) = 1`. Call this finite normal subgroup `K <= G/N`. This proves
(1), with `Out(N) ≅ GL_2(Z)` by (I3).

*Step 3: an index-two polycyclic subgroup.* For `g in G`, `μ(g)` is an
automorphism of `N`. By Lemma N, `g c g^-1 in [c]_N ∪ [c^-1]_N`. So the
`G`-orbit of `[c]_N` lies in the two-element set `{[c]_N, [c^-1]_N}`, and
`G^+ := Stab_G([c]_N)` has index at most 2 in `G`. By Lemma S,
`G^+/N ≅ C_G(c)/C_N(c)` is polycyclic.

*Step 4: the image in `Out(F_2)`.* Let `Q = μbar(G/N) <= GL_2(Z)` and
`Q^+ = μbar(G^+/N)`. Then `Q^+` has index at most 2 in `Q`, and it is
polycyclic as a quotient of a polycyclic group. By (I4) there is a free
`Φ <= GL_2(Z)` of finite index. `Q^+ ∩ Φ` has finite index in `Q`, and it is
both free (I5) and solvable, so it is trivial or infinite cyclic. Hence `Q` is
finite or virtually infinite cyclic.

*Step 5: lifting through the finite kernel.* `(G/N)/K ≅ Q` with `K` finite. If
`Q` is finite, `G/N` is finite. Otherwise let `P <= G/N` be the preimage of an
infinite cyclic subgroup of finite index in `Q`. Then `P` has finite index in
`G/N` and `P/K ≅ Z`. Choose `t in P` mapping to a generator. Then
`P = K <t>` and `<t> ∩ K = 1`. Conjugation by `t` restricts to an automorphism
of the finite group `K` of some finite order `e`. The cosets `k t^i <t^e>`
(`k in K`, `0 <= i < e`) cover `P`, so `<t^e> ≅ Z` has finite index in `P`, and
hence in `G/N`. This proves (2).

*Step 6: infinite-order monodromy.* Suppose `gN` has infinite order but
`μbar(gN)` has finite order `e`. Then `g^e N in K`, so `(g^e N)^{|K|} = 1` and
`gN` has finite order, a contradiction. This proves (3).

*Step 7: finite presentation.* If `G/N` is finite, `N ≅ F_2` has finite index
in `G`, and `G` is finitely presented by (I6). Otherwise take `t in G` such that
`<tN>` is infinite cyclic of finite index in `G/N`. Its preimage
`N <t> = N x| <t>` has finite index in `G` and the presentation
`<a, b, t | t a t^-1 = φ(a), t b t^-1 = φ(b)>`, where `φ = μ(t)|_N`. So `G` is
finitely presented by (I6). The class of `φ` has infinite order in `Out(F_2)`
by (3). ∎

**Remark (sharpness of the bookkeeping).** Proposition A does not claim that
any `F_2 x|_φ Z` with `φ` of infinite order embeds in `SL_3(Z)`. Finite-order
`φ` is excluded separately: a power of `t` then acts innerly, and `G` contains
`F_2 x Z`, which (I2) forbids. Long–Reid (Question 3) ask whether some
integral specialization `ρ_k` of their family of representations of the
figure-eight knot group `F_2 x|_φ Z` (`φ` Anosov) into `SL(3,Z)` is faithful.
That was open in their preprint, and its current status was not checked.
Proposition A is consistent with a positive answer. The group
`SL_2(Z) <= SL_3(Z)` is a trivial sanity check: its commutator subgroup is
free of rank 2 and of index 12, so the quotient is finite.

## 5. Corollaries

**Corollary A1 (no F_2-by-large).** No subgroup of `SL_3(Z)` is isomorphic to
an extension `1 -> F_2 -> E -> Q -> 1` with `Q` not virtually cyclic. The image
of the normal `F_2` is a normal subgroup isomorphic to `F_2`, so Proposition A
applies. In particular `SL_3(Z)` contains no `F_2 x| F_m` with `m >= 2`, no
`F_2 x| Z^2`, and no `F_2`-by-(surface group). This refutes
`sl3z-contains-f2-by-free-subgroup`.

**Corollary A2 (no incoherence witness with a normal F_2).** Every subgroup of
`SL_3(Z)` having a normal subgroup isomorphic to `F_2` is finitely presented
(Proposition A(4)).

**Corollary A3 (rank-two subgroup classes).** Let `N ◁ G <= SL_3(Z)` and
`A <= N` with `A ≅ F_2`. Then `Stab_{G/N}([A]_N) ≅ N_G(A)/N_N(A)` is virtually
cyclic.

*Proof.* `A ◁ N_G(A) <= SL_3(Z)`, so `N_G(A)/A` is virtually cyclic by
Proposition A. Also `N_N(A) = N_G(A) ∩ N` is normal in `N_G(A)` and contains
`A`, so `N_G(A)/N_N(A)` is a quotient of `N_G(A)/A` and virtually cyclic.
Lemma S(2) finishes. ∎

**Corollary A4 (surfaces with boundary).** Let `N ◁ G <= SL_3(Z)` with
`N ≅ π_1(S)`, where `S` is a compact surface with `b >= 1` boundary components
and `χ(S) < 0`. Suppose the conjugation action of `G` permutes the set of
`N`-conjugacy classes of the boundary loops and their inverses, as happens
when the monodromy is induced by homeomorphisms of `S`. Then `G/N` is
virtually polycyclic. If `G/N` is free, it is trivial or infinite cyclic.

*Proof.* A boundary loop `∂_1` is a nontrivial element of the free group
`π_1(S)`, so it has infinite order. Its orbit has at most `2b` classes.
Corollaries S1 and S2 finish. ∎

**Corollary A5 (free-by-free with fibre rank n >= 3).** Let
`G = F_n x| F_m <= SL_3(Z)`. Then `F_m`, acting through the monodromy on
`F_n`-conjugacy classes, has trivial or infinite cyclic stabilizers:

- on classes of elements of `F_n` other than 1 (by Lemma S and (I5));
- on classes of rank-two subgroups of `F_n` (by Corollary A3 and (I5)).

## 6. Effect on the hole `sl3z-contains-cd2-euler-positive-fibered-subgroup`

That hole asks for `G <= SL_3(Z)` of type FP with `cd G = 2`, `χ(G) != 0` and
an epimorphism onto `Z` with finitely generated kernel. Its Attempts section
(2026-09-13) lists free-by-free `F_n x| F_m` (`n, m >= 2`) as the candidate
family and records "no obstruction to existence is known".

- **Dead: `n = 2`.** Corollary A1. This is exactly the class covered by
  (I7), so the Kropholler–Walsh incoherence theorem for `F_2 x| F_m` cannot be
  imported into `SL_3(Z)`. The route `sl3z-incoherent-via-f2-by-free-subgroup`
  records this dead space.
- **Dead: geometric monodromy fixing a boundary class**, for any fibre rank,
  by Corollary A4. This covers surface-with-boundary-by-free groups whose
  monodromy lies in the mapping class group of the bounded surface.
- **Restricted: `n >= 3`.** By Corollary A5 the monodromy
  `F_m -> Out(F_n)` has cyclic stabilizers on conjugacy classes of elements
  and of rank-two subgroups.
  - Non-hyperbolic examples in which a non-cyclic subgroup of `F_m` fixes a
    class are excluded.
  - Hyperbolic `F_n x| F_m` survives untouched. There both kinds of
    stabilizer are already trivial.
    - Element classes. Suppose `1 != u in F_m` fixes `[x]_N` with `x != 1`. Pick a
      lift `g`, so `g x g^-1 = n x n^-1`. Then `n^-1 g` commutes with `x` and maps to
      `u`, so `<x, n^-1 g> ≅ Z^2`.
    - Rank-two subgroup classes. A nontrivial stabilizer gives
      `g in N_G(A) \ N`, and `<A, g> = A x| <g>`. By Lemma N some `a in A`
      makes `a^-1 g^2` commute with `c = [a_1, a_2]`, again giving `Z^2`.

    Neither is possible in a hyperbolic group.
- **Untouched: non-free fibres.** Lemma S still applies, but gives no
  contradiction when the quotient is small (for example cyclic).

Obstruction to test next, for hyperbolic survivors. `G` would be a hyperbolic
group of cohomological dimension 2 in `SL_3(Z)`, neither virtually free nor
virtually a surface group. By the Canary–Tsouvalas classification of
projective Anosov subgroups of `SL(3,R)`, recalled from reading before a
context reset and not re-verified, `G` could not be projective Anosov. So a
witness would be a non-Anosov hyperbolic subgroup.

## 7. Criterion C3 (Bieri) and how it subsumes C1

**Criterion C3.** There exist a finitely generated `G <= SL_3(Z)` with
`cd G <= 2` and `N ◁ G` that is finitely generated, of infinite index in `G`,
and not free. `G` is torsion-free, because its cohomological dimension is
finite.

**C3 implies incoherence** (route `sl3z-incoherent-via-bieri-normal-subgroup`).

- If `cd G <= 1`, `G` is free and so is `N`. So `cd G = 2`.
- By (I8), a finitely presented normal subgroup of `G` is free or of finite
  index. `N` is neither, so it is not finitely presented.
- `N` is finitely generated, so `SL_3(Z)` is incoherent.

This is the argument of Long–Reid, Proposition 5.2. Their hypotheses are:
`ρ_k(F)` has infinite index in `ρ_k(Γ)` and is not free, and `ρ_k(Γ)` has
virtual cohomological dimension 2. Their proof passes to a torsion-free
finite-index `Δ_k <= ρ_k(Γ)` and applies Bieri to `ρ_k(F) ∩ Δ_k`. That
intersection is torsion-free, so it is free exactly when `ρ_k(F)` is virtually
free (Stallings–Swan). The instance of C3 is therefore
`(Δ_k, ρ_k(F) ∩ Δ_k)`, under the hypothesis that `ρ_k(F)` is not virtually
free. That is how this reading adjusts their "not free".

**Hypothesis range of (I8).** The quote puts no finiteness condition on `G`.
Bieri's paper was not read. If the theorem needs `G` of type `FP_2` or `FP`,
then C3 must carry that hypothesis:

- C1 witnesses satisfy it, since they are of type FP.
- The Long–Reid instance would need `Δ_k` of type `FP_2`.

**C1 implies C3** (route `sl3z-euler-fibered-subgroup-gives-bieri-witness`).
Let `G` be as in `sl3z-contains-cd2-euler-positive-fibered-subgroup`: type FP,
`cd G = 2`, `χ(G) != 0`, with `φ: G -> Z` onto and `K = ker φ` finitely
generated.

- `G` is torsion-free, since its cohomological dimension is finite.
- `K` is normal of infinite index.
- Suppose `K` were free. Then `K ≅ F_r` with `r` finite, and `G ≅ F_r x| Z` is
  the fundamental group of the mapping torus `T` of a cellular map of a rose
  `R_r` realizing the monodromy. `T` is a finite aspherical 2-complex: it is a
  graph of spaces with aspherical vertex and edge spaces and injective edge
  maps.
- Each `p`-cell of `R_r` contributes one `p`-cell and one `(p+1)`-cell to `T`,
  so `χ(T) = 0`.
- For a group of type FP, `χ(G) = sum (-1)^k dim_Q H_k(G; Q)` can be computed
  from any finite `K(G,1)`. So `χ(G) = 0`, a contradiction. Hence `K` is not
  free, and `(G, K)` witnesses C3.

**Why C3 is a better target than C1.**

- C3 drops the Euler characteristic and the cyclic quotient. Any infinite
  quotient `G/N` is allowed.
- It covers the Long–Reid strategy, where `N` is the image of the fibre of the
  figure-eight knot group under `ρ_k` and `G/N` is cyclic. In that case `N` is
  a 2-generated quotient of `F_2`.
  - Long–Reid Theorem 4.1: `ρ_k(F)` has finite index in `SL(3,Z)` for
    `k = 0, 2, 3, 4, 5`. Those values are therefore not C3 instances.
  - A faithful `ρ_k` is not an instance either, because then `N ≅ F_2`.
  - So the strategy needs an unfaithful `ρ_k` with thin image of virtual
    cohomological dimension 2 and a fibre image that is not virtually free.
- It does not require `N` to be free-by-anything.

Proposition A says nothing about C3, because its fibre `N` is non-free by
definition. Lemma S applies to C3 witnesses, but gives a contradiction only
when `G/N` is large and some class has a finite orbit.

Necessary conditions on C3 witnesses, from the established region:

- `N` is Zariski dense and of infinite index in `SL_3(Z)`
  (`sl3z-incoherence-witnesses-are-zariski-dense-thin`).
- `N` is not virtually solvable: a finitely generated virtually solvable
  subgroup of `GL_3(Z)` is polycyclic-by-finite, hence finitely presented.
- The monodromy `G/N -> Out(N)` is injective. `C_G(N)` centralizes a
  Zariski-dense subgroup, so it is central in `SL_3`, hence trivial in
  `SL_3(Z)`; and `C_G(N) ∩ N = Z(N)` is trivial for the same reason. So
  `C_G(N) N/N = 1`.
- Every class stabilizer in `G/N` is polycyclic (Lemma S).

## 9. Trust boundary

  here), and the classical (I3)–(I6). The most "imported" step is
  `IA(F_2) = Inn(F_2)`, i.e. `Out(F_2) ≅ GL_2(Z)`, used only to know that
  `Out(F_2)` is virtually free.
- The dead route's implication rests on (I7), known only through the
  abstract. The range `n >= 2` is implicit there; `F_2 x| Z` is coherent
  (Feighn–Handel, recalled).
- C3's implication rests on (I8), known only through Long–Reid's quotation.

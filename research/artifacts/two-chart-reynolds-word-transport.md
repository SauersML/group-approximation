# Archived raw two-chart Reynolds transport program

This program asked nonisomorphic finite packet tables to return termwise under
one chart switch.  That raw requirement has been superseded: the active
`stabilized-two-chart-reynolds-word-transport` first stabilizes the packets
and extracts only the local finite-dimensional residue.  The original claim
is archived rather than marked false as an abstract existence statement.

Its useful warning remains: multiplication by the chart parameter is
additive on a root subgroup but is not a unital endomorphism of the full
elementary group, so a raw global return assertion cannot simply be imposed.

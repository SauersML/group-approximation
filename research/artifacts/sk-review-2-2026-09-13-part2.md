## 6. `ejz-elementary-groups-explicit-kazhdan-constant`
**Claim.** Let R be an associative ring with 1, generated by x_0 = 1, x_1, …, x_d, and let n ≥ 3. Put
Σ = {e_ij(x_m)}. Then κ(EL_n(R), Σ) ≥ 1/(8(12√(2d) + 2√(3n) + 36√2)).

**Independent check.** I read the TeX source on MSI, `/scratch.global/sauer354/fcah/src/EL_n0909.tex` (158552 bytes,
dated 9 Sep 2009):
- l.2364-2365: "Throughout the section we fix an integer $n\geq 3$ and a finitely generated associative ring $R$
  with $1$."
- l.2380-2385: "We fix a generating set $\{x_0,x_1,\ldots, x_d\}$ for $R$, where $x_0=1$. It is clear that the
  set \Sigma=\{e_{ij}(x_m)\, : \,i,j\in \{1,\ldots,n\}, i\neq j,\,\, 0\leq m\leq d\} generates $EL_n(R)$."
- l.2438-2441: "From Proposition~\ref{Kassabov2} and \eqref{CCC} it follows that κ(EL_n(R),Σ) ≥
  κ(EL_n(R),∪X_ij)/(12√(2d)+2√(3n)+36√2) > 0."
- l.2443-2447: "Since $\Sigma$ is finite, we conclude that $EL_n(R)$ has property $(T)$, and moreover
  \kappa(EL_n(R),\Sigma)\geq \frac{1}{8(12\sqrt {2d}+2\sqrt {3n}+36\sqrt 2)}."
- l.836-850, the definition. κ(G,S,V) is the infimum of the ε > 0 such that V contains a nonzero v with
  ‖sv − v‖ ≤ ε‖v‖ for all s ∈ S, and κ(G,S) is the infimum over V ∈ Rep_0(G). This is the same as the claim's
  "infimum of max_s ‖sv−v‖/‖v‖".

**Scope.** Correct. The bound depends only on n and d. If some x_m coincide in a quotient, the set shrinks and the
bound only improves, since it decreases in d. Arithmetic for n = 3, d = 4: 12√8 + 6 + 36√2 = 90.853…, so the
constant is 1/726.82… > 1/727. PASS.

The route honestly records that the journal equation numbering was not checked. Citing arXiv §6.1 is accurate.

## 7. `subshift-el3-models-explicit-kazhdan-constant`
**Claim.** With d = |A|+2 and Σ the note's generators (l.94-95), κ(G_X, Σ) ≥ c_d and κ(SL_{3N_k}(F_2), Σ_k) ≥ c_d,
where c_d = 1/(8(12√(2d)+6+36√2)). The model Cayley graphs have spectral gap at least c_d²/(12(d+1)). For the
Fibonacci subshift, κ > 1/727 and the gap is > 3·10^(−8).

**Checks.**
1. **The group.** R is generated as a ring by u, u^{−1} and the e_a (`minimal-subshift-algebra-is-simple-lef-ring`,
   item 1; F_2 needs no scalar). So Σ = {e_ij(x_m)} with x_0 = 1 is the EJZ set, and 2√(3·3) = 6. TRUE.
2. **The models.**
   - Take y_k of least period N_k. The least period of the note's y has the same set of (2k+1)-words.
   - N_k ≥ |L_{2k+1}(X)| ≥ 2k+2 (aperiodic complexity).
   - P^iD(e_a)P^{−i} = diag_m(1[y_{m−i} = a]). The product over i ∈ [0, N_k) with a_i = y_{n−i} is δ_{m≡n}, because
     distinct rotations are distinct. With P, every matrix unit E_{nm} = E_{nn}P^{n−m} is in the image. So 1, P,
     P^{−1} and the D(e_a) generate M_{N_k}(F_2), and EL_3(M_{N_k}(F_2)) = SL_{3N_k}(F_2).
   - The EJZ bound applies to this ring and these generators. TRUE, and it agrees with
     `finite-simple-groups-converge-to-simple-kazhdan-group-proof` steps 1-2.
3. **Spectral gap.**
   - Over F_2, e_ij(s)² = e_ij(2s) = I, so Σ_k is symmetric and M = |Σ_k|^{−1} Σ_s λ(s) is self-adjoint.
   - For v ⊥ constants with ‖v‖ = 1, ⟨(I−M)v,v⟩ = (2|Σ_k|)^{−1} Σ_s ‖sv−v‖² ≥ κ²/(2|Σ_k|).
   - ℓ²_0 has no invariant vectors, so max_s ‖sv−v‖ ≥ c_d.
   - |Σ_k| ≤ 6(d+1). So the eigenvalues of M off the constants are ≤ 1 − c_d²/(12(d+1)). TRUE. It is an upper bound
     only, and the claim says "at most".
4. **Numbers.** 727² = 528529, and 60·528529 = 31711740. 1/31711740 = 3.15…·10^(−8) > 3·10^(−8). TRUE.
5. **Convergence.** This is step 3 of `finite-simple-groups-converge-to-simple-kazhdan-group-proof`, reviewed PASS in
   `ex-review-groups-2026-09-12-part8.md` §8.6 and `ex-pestov91-second-review-2026-09-13.md` N5. At q = 2 the
   centre is trivial and PSL = SL.

PASS.

## 0. Scope and verdict

  `rank-condition-rings-carry-sylvester-rank-functions`.
- **Exact reformulation (Theorem 2.1, established).** A unital ring carries a Sylvester matrix rank
  function iff no identity matrix `I_(q+1)` lies below `I_q` in the preorder generated by minors and
  triangular moves. With minors alone the same statement is the rank condition (Theorem 2.2), which is
  equivalent to the existence of a `K_0` state (census Theorem A). So the whole content of (U1) is
  eliminating triangular moves, that is, Sylvester's law of nullity, from identity certificates.

  minor.
- **Calibrations where (U1) holds (Section 4, literature, not re-read locally):** regular rings, and
  rings with a unital map into a regular ring that has the rank condition.
- **For the plan (Section 5).** With the abstract form of the "No" branch, the plan is equivalent to:

## 1. Definitions and the implication table

Let `A` be a unital ring and `Mat(A)` the set of all rectangular matrices over `A`, zero-size ones
included.

- **Minor order.** `M <~ N` iff `M = X N Y` for rectangular `X`, `Y`. It is reflexive, transitive and
  compatible with block sums `(+)`.
- **Rank condition.** No epimorphism `A^q -> A^(q+1)` of right modules for any `q`; equivalently
  `I_(q+1)` is not `<~ I_q`.
- **`K_0` state.** An additive `f: K_0(A) -> R`, nonnegative on classes of finitely generated
  projectives, with `f([A]) = 1`.
- **Matrix state.** `d: Mat(A) -> R` with `d(M (+) N) = d(M) + d(N)`, `d(M) <= d(N)` whenever
  `M <~ N`, and `d(I_1) = 1`.
- **Sylvester matrix rank function (SMRF).** `rk: Mat(A) -> R_(>=0)` with `rk(0) = 0`, `rk(1) = 1`,
  `rk(MN) <= min(rk M, rk N)`, `rk(M (+) N) = rk M + rk N` and
  `rk [[M, C], [0, N]] >= rk M + rk N`. This is the definition used by
  `simple-group-rank-functions-are-augmentation-or-detecting`.
- **Sylvester module rank function.** `dim` on finitely presented modules, `dim A = 1`, additive on
  `(+)`, with `dim M_3 <= dim M_2 <= dim M_1 + dim M_3` for right exact `M_1 -> M_2 -> M_3 -> 0`.

| implication | status | reason |
|---|---|---|
| SMRF <=> module rank function | holds | Malcolmson's correspondence `dim coker(M) = n - rk(M)`; literature, not re-read; unused below |
| SMRF => matrix state | holds | `rk(XMY) <= rk M` from the product axiom |
| matrix state => `K_0` state | holds | restrict to idempotent matrices; isomorphic projectives come from `e = XY`, `e' = YX`, so `e <~ e' <~ e` |
| `K_0` state <=> rank condition | holds | census Theorem A(b),(c) and Remark: `-[A] in K_0^+` iff `A^N ~= A^(N+1) (+) Q`; items 3-5 of `twisted-leavitt-corner-fullness-equals-absence-of-k0-states` |
| rank condition => matrix state | holds | Theorem 2.2 |
| stably finite, `A != 0` => rank condition | holds | pad an epimorphism `A^q -> A^(q+1)` to a square one-sided pair |
| SMRF => a nonzero stably finite quotient | holds | the rank-zero matrices form `M(I)` for a two-sided ideal `I`, and `A/I` carries a faithful SMRF |
| rank condition => SMRF | **open** | this is (U1) for general rings; Theorem 2.1 reformulates it |

## 2. The triangular certificate criterion

**Theorem 2.1.** Let `<=_T` be the smallest relation on `Mat(A)` that
- contains `<~`,
- contains `A (+) B <=_T [[A, C], [0, B]]` for all `A`, `B`, `C` of compatible sizes,
- is transitive and compatible with `(+)`.

Then:
- **(a)** the SMRFs on `A` are exactly the matrix states that are monotone for `<=_T`;
- **(b)** `A` carries an SMRF iff there is no `q >= 0` with `I_(q+1) <=_T I_q`;
- **(c)** `I_(q+1) <=_T I_q` iff there is a finite chain `I_(q+1) = Y_0, Y_1, ..., Y_n = I_q` in
  which each step is either a minor step `Y_i <~ Y_(i+1)` or a triangular step
  `Y_i = A_i (+) B_i (+) Z_i -> Y_(i+1) = [[A_i, C_i], [0, B_i]] (+) Z_i`, up to permutation of rows
  and columns.

**Theorem 2.2.** `A` carries a matrix state iff there is no `q` with `I_(q+1) <~ I_q`, that is, iff
`A` has the rank condition.

**Proof.**
1. *Axioms as monotonicity.* An SMRF is `<~`-monotone, since `XMY` is a product, and monotone on
   triangular moves by the last axiom. Additivity carries monotonicity through `(+)`, and transitivity
   through chains. Conversely, let `d` be a `<=_T`-monotone matrix state. `MN <~ M` and `MN <~ N` give
   the product axiom. `0 (+) 0` and `0` dominate each other, so `d(0) = 2 d(0) = 0`, and `0 <~ M` gives
   `d >= 0`. `A (+) B <=_T T` gives the triangular axiom. This is (a).
2. *Monoid and group.* Let `~` be mutual `<=_T`-domination. It is compatible with `(+)`, and permutation
   matrices give `M (+) N ~ N (+) M`, so `W = Mat(A)/~` is a commutative monoid with the empty matrix as
   identity, preordered by `<=_T`. Let `G` be its Grothendieck group and
   `P = { [N] - [M] : M <=_T N }`. `P` is closed under addition because `<=_T` is compatible with `(+)`.
   Monotone matrix states are exactly the additive maps `G -> R` that are nonnegative on `P` and take
   the value 1 on `u = [I_1]`.
3. *Order unit.* `u` lies in `P` because `0 <=_T I_1`. For `x = [X] - [Y]` with `X` of size `p x c`,
   `X <~ I_c <~ I_c (+) Y`, so `c u - x = [I_c (+) Y] - [X]` lies in `P`.
4. *Goodearl–Handelman.* A state on `(G, P, u)` exists iff `-u` does not lie in `P`. This is the
   Hahn–Banach argument of census Theorem A(b), which uses only that `P` is closed under addition,
   `u` lies in `P`, and `u` is an order unit. The multiple `k` is irrelevant by the census Remark.
5. *Absorption.* `-u` lies in `P` iff `I_1 (+) X <=_T X` for some `X`. Indeed `[N] - [M] = -[I_1]` with
   `M <=_T N` means `N (+) I_1 (+) K ~ M (+) K` for some `K`. With `X = N (+) K` this reads
   `I_1 (+) X ~ M (+) K <=_T X`. Conversely `[X] - [I_1 (+) X] = -u`.
6. *Down to identities.* From `I_1 (+) X <=_T X`, induction gives `I_k (+) X <=_T X` for every `k`.
   If `X` has `q` columns, `X <~ I_q` and `I_(q+1) <~ I_(q+1) (+) X`, so
   `I_(q+1) <=_T I_(q+1) (+) X <=_T X <=_T I_q`. Conversely `X = I_q` works. This proves (b).
7. *Chains.* The relation "joined by a finite chain of minor and triangular steps" contains both
   generators and is transitive. Adding `(+) K` to a minor step gives a minor step, and adding it to a
   triangular step absorbs `K` into `Z`, so it is compatible with `(+)`. It is therefore `<=_T`, which
   is (c).
8. *Theorem 2.2.* Run steps 2–6 with `<~` in place of `<=_T`. `I_(q+1) <~ I_q` means `I_(q+1) = XY`
   with `X` of size `(q+1) x q`, an epimorphism `A^q -> A^(q+1)`. QED

**Remarks.**
- *Locality.* Certificates are finite, so both properties hold for `A` iff they hold for every finitely
  generated subring.
- *(U1) as flattening.* A ring with the rank condition carries an SMRF iff every triangular identity
  certificate over it flattens to a minor certificate: whenever `I_(q+1) <=_T I_q`, some
  `I_(q'+1) <~ I_(q')`.
- *The summand.* `eps_-` is a central idempotent and `F_3[G] = S_+ x S_-`. An SMRF on `S_-` pulls back
  along the projection to one on `F_3[G]` with `rk(eps_-) = 1`. Conversely one with `rk(eps_-) = c > 0`
  restricts to matrices over `S_-` and gives an SMRF there after dividing by `c`. So "every SMRF on
  `F_3[G]` kills `eps_-`" is the same as a finite certificate `I_(q+1) <=_T I_q` over `S_-`.

## 3. Split minors survive triangular moves

Nodes: `split-identity-minors-survive-triangular-moves` (claim), with route
`split-identity-minors-triangular-moves-proof`.

**Definition.** Write `I_n ⊑ Y` (a stable identity minor) if `I_(n+s) <~ Y (+) I_s` for some `s >= 0`.
Minor steps preserve `⊑`, and it adds over block sums.

**Proposition 3.1.** If `I_a ⊑ A` and `I_b ⊑ B`, then `I_(a+b) ⊑ T = [[A, C], [0, B]]` for every `C`.

*Proof.*
1. Choose `X_1 (A (+) I_s) W_1 = I_(a+s)` and `X_2 (B (+) I_t) W_2 = I_(b+t)`.
2. After permuting rows and columns, `T (+) I_(s+t) = [[A (+) I_s, C'], [0, B (+) I_t]]`, where `C'` is
   `C` bordered by zeros.
3. Multiplying on the left by `diag(X_1, X_2)` and on the right by `diag(W_1, W_2)` gives
   `[[I_(a+s), D], [0, I_(b+t)]]` with `D = X_1 C' W_2`.
4. Right multiplication by the invertible `[[I, -D], [0, I]]` gives `I_(a+b+s+t)`. QED

**Corollary 3.2 (split chains flatten).** Let `I_(q+1) = Y_0, ..., Y_n = I_q` be a chain as in Theorem
2.1(c). Suppose that at every triangular step `Y_i = A_i (+) B_i (+) Z_i`, the carried `I_(q+1) ⊑ Y_i`
splits: `I_a ⊑ A_i`, `I_b ⊑ B_i`, `I_c ⊑ Z_i` with `a + b + c = q + 1`. Then `I_(q+1) ⊑ I_q`, so
`I_(q+1+s) <~ I_(q+s)` for some `s`, and `A` fails the rank condition.

*Proof.* Induction along the chain. Minor steps preserve `⊑`. At a split triangular step, Proposition
3.1 gives `I_(a+b) ⊑ T_i`, and additivity gives `I_(q+1) ⊑ T_i (+) Z_i`. QED

**Remark 3.3 (idempotent steps are minor steps).**
- *Claim.* Suppose `A`, `B` and `T = [[A, C], [0, B]]` are idempotent matrices. Then `T` is conjugate to
  `A (+) B`, so the step is a minor step.
- *Why.* `T^2 = T` gives `C = AC + CB`. Multiplying by `A` on the left and `B` on the right gives
  `ACB = 2 ACB`, so `ACB = 0`. With `x = AC - CB`,
  `[[1, x], [0, 1]] T [[1, -x], [0, 1]] = [[A, C - Ax + xB], [0, B]]`, and the corner is
  `C - AC - CB + 2 ACB = 0`.
- *Consequence.* Only non-idempotent triangular steps can separate Sylvester rank functions from `K_0`
  states.

**Remark 3.4 (splitting is not automatic).**
- *Example.* Over `M_2(K)`, `K` a field, `I_1 ⊑ e_11 (+) e_22`, but neither `e_11` nor `e_22` carries
  `I_1`: over `K`, `I_(1+s) <~ e_11 (+) I_s` would give `2 + 2s <= 1 + 2s`.
- *Consequence.* Corollary 3.2 does not prove (U1) for regular rings. Fractional certificates
  (`I_k ⊑ M^((+)n)`) are the typical non-split case. Proposition 3.1 still applies to split fractional
  minors, since `T^((+)n)` is triangular with blocks `A^((+)n)` and `B^((+)n)`.

**What a calibration ring must contain.** A ring with the rank condition and no Sylvester rank function
has a chain `I_(q+1) <=_T I_q` with at least one triangular step that is
- (i) not idempotent, as in Remark 3.3, and
- (ii) at a carried identity minor that mixes the two diagonal blocks, so it does not split.

## 4. Calibrations where (U1) holds

This section rests on literature not re-read locally, and no node depends on it.
- **Regular rings.** On a von Neumann regular ring, pseudo-rank functions correspond to states on
  `(K_0, [1])` (Goodearl, *Von Neumann Regular Rings*, Chapters 16–18), and they extend to matrices as
  Sylvester rank functions. With census Theorem A, the rank condition gives one.
- **Rings mapping into regular rings.** Suppose `A` has a unital map into a regular ring `U` with the
  rank condition. Then `A` carries a Sylvester rank function: pull back one from `U`. The strategist's
  order-embedding lemma is one source of such a `U`: if `K_0(A) -> K_0(U)` reflects `-[1] >= 0`, the rank
  condition passes from `A` to `U`.
- **Leavitt path algebras of finite graphs.** They embed in regular algebras with the same V-monoid
  (Ara–Brustenga), so (U1) holds for them.
- **Why nothing here covers `S_-`.** `S_-` is not regular. A unital map from `S_-` into a regular ring
  with the rank condition would give a Sylvester rank function with `rk(eps_-) = 1`. That already refutes
  the ternary corner, by part 1 of `anti-central-state-obstruction-equals-stable-finiteness`. So
  producing such a `U` is the "Yes" side of the gate (w4-rankfn, w4-trace-state), not an independent step.

## 5. For the plan, and where it stops

- **Translation.** w3-gate-char3 Section 7 (PASS) shows that an abstract rank function `N` on `S_-` with
  `N(eps_-) = 1` is already an anti-central model, so the abstract "No" branch is what the plan needs. By
  Theorem 2.1 and the Remark on the summand:
  - *abstract "No"* is some `I_(q+1) <=_T I_q` over `S_-`, a finite triangular certificate;
  - *the corner is full, a counterexample* is some `I_(q'+1) <~ I_(q')` over `S_-`, a finite minor
    certificate. By census Theorem E this is the same as a two-pair Cohn family.
- **So the plan is exactly flattening:** every triangular identity certificate over `S_-` flattens to a
  minor certificate. It is recorded as the open claim `anti-central-triangular-certificates-flatten-to-minors`.
  The general version is `rank-condition-rings-carry-sylvester-rank-functions`.
- **Locality.** Both certificates use finitely many elements, so they live over `eps_- F_3[H]` for a
  finitely generated `H` containing `z`.
- **What flattening needs.**
  - *Handled by Section 3:* split chains and idempotent steps flatten on their own.
  - *Still needed:* a proof must handle non-idempotent triangular moves at mixed minors over `S_-`.
  - *Not examined:* the halving homomorphism `M_2(S_-) -> S_-` shrinks minor certificates to size one
    (census Theorem E), but whether it controls triangular ones was not checked.
- **What the kill test did not find.** No ring with the rank condition and no Sylvester rank function,

- **Literature to check** (none available locally): Malcolmson; Schofield, *Representations of Rings over

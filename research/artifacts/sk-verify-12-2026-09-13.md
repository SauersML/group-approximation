## 1. No distortion (sk-sl3z-bandwidth)

### 1.1 Theorem D, re-derived
Let R = LC(X,F_q)⋊_T Z, where X is compact and zero-dimensional and T is a homeomorphism.
- **Module.** V = ⊕_{x∈X}⊕_{t∈Z} F_q^m, with f·δ_{x,t} = f(T^t x)δ_{x,t} and u·δ_{x,t} = δ_{x,t+1}.
  - It is a representation: u f u^{-1} δ_{x,t} = f(T^{t−1}x)δ_{x,t} = (f∘T^{-1})(T^t x)δ_{x,t}.
  - Products follow the rule (fu^i)(f′u^j) = f(f′∘T^{-i})u^{i+j}, which is the ring's own multiplication.
- **Faithful.** For A = Σ_j A_j u^j ∈ M_m(R), Aδ_{x,0}⊗ξ = Σ_j A_j(T^j x)ξ δ_{x,j}, and the slots j are distinct. So A = 0 on V gives A_j∘T^j = 0, hence A_j = 0.
- **Propagation.** p(A) = max{|j| : A_j ≠ 0}. From the product rule, p(AB) ≤ p(A)+p(B). S is symmetric with p(s) ≤ w on S, so p(z^n) ≤ w|z^n|_S.
- **Uniform Krylov bound.** Take a slot vector v = δ_{x,t}⊗ξ. Its orbit z^n v, n < N, lies in the slots {x}×[t−wℓ(N), t+wℓ(N)], where ℓ(N) = max_{n<N}|z^n|_S. That space has dimension m(2wℓ(N)+1), and the bound does not depend on v.
- **Fekete.** τ = inf_n |z^n|_S/n, and it is the limit. For ε > 0 pick n_0 with |z^{n_0}|_S < (τ+ε)n_0. Then |z^n|_S ≤ (τ+ε)n + max_{r<n_0}|z^r|_S, so C exists.
  - If 2wm(τ+ε) < 1, then m(2wℓ(N)+1) < N for N ≥ N_0, with N_0 independent of v.
  - So some nonzero polynomial p_v of degree < N_0 has p_v(z)v = 0.
- **One polynomial.** P = lcm of the finitely many monic polynomials over F_q of degree < N_0. P(z) kills every slot vector, and slot vectors span V, so P(z) = 0 in M_m(R) by faithfulness.
- **Finite order.** P(z) = 0 makes F_q[z] a finite ring. z is invertible in M_m(R), so z is not a zero divisor in F_q[z]. A non-zero-divisor of a finite ring is a unit, so z has finite order. The artifact's t^a-removal step does the same.
- **Bound.** An infinite-order z has τ ≥ 1/(2wm). ✓
- **Degenerate case w = 0.** Then Γ ≤ GL_m(LC(X,F_q)), a directed union of finite groups, so Γ is finite, and the bound 1/(2wm) is vacuous (see F1).
- **Consequence C1.** The generators e_ij(u^{±1}) and e_ij(e_a) have w = 1 and m = 3, so every infinite-order element of G_X has stable length ≥ 1/6. ✓

### 1.2 Heisenberg group, SL_n(Z), BS(1,2)
- **The Heisenberg group.** In H = ⟨a,b | [a,c],[b,c]⟩ with c = [a,b] central, the commutator is bilinear, so [a^n,b^n] = c^{n²}.
  - With a = e_12(1) and b = e_23(1), c = e_13(1), which has infinite order.
  - For n² ≤ N < (n+1)², c^N = [a^n,b^n]c^{N−n²} with N−n² ≤ 2n, so |c^N| ≤ 4n + 8n = 12n ≤ 12√N and τ(c) = 0.
  - An embedding H ≤ GL_m(R) would give an infinite-order element of stable length 0, which contradicts Theorem D; when w = 0 the image is finite. ✓
- **SL_n(Z), n ≥ 3.** It contains H as upper unitriangular matrices. ✓
- **BS(1,2).** Since ta t^{-1} = a², t^k a t^{-k} = a^{2^k} has length 2k+1. a has infinite order, so τ(a) = 0. ✓
- **The refutation.** H is finitely generated and residually finite, hence LEF, and it lies in no G_X ≤ GL_3(LC(X,F_2)⋊Z). So `every-lef-group-embeds-in-a-z-subshift-elementary-group` is false. ✓

### 1.3 Model tests I ran
- **GL_1 of the commutative ring LC(X,F_q)** (w = 0): locally finite, consistent.
- **u ∈ GL_1(R):** τ(u) = 1 ≥ 1/2, consistent.
- **SL_3(F_2[u^{±1}]) ≤ G_X.**
  - Unipotents have order 2.
  - An infinite-order element has an eigenvalue transcendental over F_2, hence a valuation v with |λ|_v ≠ 1. So its norms grow exponentially and it is undistorted.
  - This is the classical valuation argument for finitely generated linear groups in positive characteristic (recalled, not read at source), and it is the commutative special case of Theorem D. Consistent.
- **The lamplighter hosts of `cor:lef`** contain H. Their propagation is measured in Z/2≀Δ, which has exponential growth, so no Krylov bound applies. Consistent.
- **Aut(A^Z)** has a distortion element in a finitely generated subgroup (Callard–Salo, below). Those operators are not F_q-linear slot operators, so there is no conflict.

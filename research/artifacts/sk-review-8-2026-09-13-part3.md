## 1. Theorem 2 (item 5): proposal §1 and route

- **Small sets.** Each `ℓ ≠ e` has a closed nowhere dense fixed set. So a point moved by all of `B_{2w} ∖ {e}` has a
  clopen neighborhood `V` with `V ∩ ℓV = ∅` on which the finitely many `f∘ℓ` are constant. Small sets are dense.
- **Criterion.** `g` commutes with `e_ij(r)` iff `g_pi r = 0` (`p ≠ i`), `r g_jq = 0` (`q ≠ j`), and `g_ii r = r g_jj`.
- **Scalar step.**
  - `c e_V = Σ c_ℓ e_{ℓV}u_ℓ`. A small `V ⊆ ℓ^{−1}U` detects `c_ℓ ≠ 0`, so commuting with every root forces `g` diagonal.
  - The `u_ℓ`-coefficients, `ℓ ≠ e`, of `g_ii e_V = e_V g_jj` sit on the disjoint sets `ℓV` and `V`, so they vanish.
  - So `g = cI`, `c ∈ LC`, and the constant coefficient of `cc^{−1} = 1` gives `c = 1` over `F_2`.
- **Tower group.**
  - `ε_abε_{a′b′} = e_{a(V ∩ b^{−1}a′V)}u_{…}` with `b^{−1}a′ ∈ B_{2w}`, so these are matrix units.
  - `f u_a e_V f′u_b = f e_{aV}(f′∘a^{−1})u_{ab} ∈ {0, ε_{a,b^{−1}}}`. This needs `b^{−1} ∈ B_w`, true for a symmetric
    generating set.
  - `k − I = (ghg^{−1} − h)h` and `k^{−1} − I = h(ghg^{−1} − h)`, because `h² = I`.
  - `H ≅ GL_d(F_2) = PSL_d(F_2)` is simple, so `H ⊆ N`.
- **Level ideal.** `e_{pq}(sr) = [e_pl(s), e_lq(r)]`. Finitely many `ℓV` cover `Z`, so `1 = 1 − ∏(1 − e_{ℓ_iV}) ∈ J`.
- **LEF.** `GL_n` of the ultraproduct is the ultraproduct of the `GL_{nN_k}(F_2)`. The kernel misses `e_12(1)`, so it
  is trivial. Subgroups of an algebraic ultraproduct of finite groups are LEF.
- **Instances.**
  - `Z` on an infinite minimal subshift: free, with the periodic-word models.
  - The lamplighter host: minimal and topologically free (three PASSes), with the affine models `F_2^{Q_n} × Q_n`.
  - The Toeplitz envelopes, through `residually-finite-actions-give-matricial-crossed-products` (un-verify-measure PASS).
- **Non-instance `∂F_d`.** `s_i^*s_j = δ_ij` and `Σ s_is_i^* = 1` force `d · rank(s_1s_1^*) = 1` with
  `rank(s_is_i^*) ≥ rank(1)`, so `d = 1`.
- **PASS.** The route's step 4 import `binary-el-simple-iff-minimal-topologically-free` carries two PASS lines, and
  §1 proves simplicity by itself anyway.

## 3. Rank-3 LEF converse (item 6)

- **Corner.**
  - `Φ(z)_{ij} = ε_1i z ε_j1` is multiplicative because `Σ_k ε_k1ε_1k = e`.
  - `ΦΨ = id` because `ε_1iε_k1 = δ_ikε_11`, and `ΨΦ(z) = eze = z`.
  - So `eRe ≅ M_2(S)`.
- **Rank doubling.**
  - `g ↦ (1−e)I_N + g` sends `eI + rE_ij` to `I + rE_ij`.
  - `EL_N(M_2(S)) = EL_{2N}(S)` for `N ≥ 2`: cross-block transvections are elementary, and in-block ones are commutators
    through a second block.
  - So `EL_{4}(S) ≤ EL_{2N}(S) ≤ EL_N(R)`, and `lef-elementary-groups-force-lef-rings` (two PASSes) makes `S` LEF.
- **Matrix rings.**
  - Partial sums `Σ_{k≤t}A_ikB_kj` in `E` let an entrywise LEF map preserve the products that stay in `F`.
- **Fullness.**
  - `1 = Σx_iε_11y_i`, `u = (ε_11y_i)_i`, `v = (x_iε_11)_i` and `vu = 1`.
  - `ψ(r) = urv` is a unital isomorphism `R → fM_m(S)f`, with inverse `z ↦ vzu`.
  - A LEF map `Φ′` of a finite set containing `f` and the `ψ(r)` lands in the finite unital corner `Φ′(f)Q′Φ′(f)`.
  - PASS.
- **The iff.**
  - (1)⇒(2): `Rε_11R = R` by simplicity.
  - (2)⇒(3): `simple-lef-rings-are-exactly-matricial` (two PASSes).
  - (3)⇒(4): units of the ultraproduct.
  - PASS.
- **N4 (model test, both nodes).** "`M_2(F_2 × F_2)` … unital maps onto one matrix factor are not injective, so
  simplicity is used only in (2) ⇒ (3)" does not show what it says.
  - `M_2(F_2 × F_2) ↪ M_4(F_2)` diagonally is a unital embedding, so (3) holds for it.
  - Simplicity is also used in (1) ⇒ (2), for fullness.
  - A correct test is `M_2(Z/4)`. It has full matrix units, is finite (so (1), (2) and (4) hold), and has no unital map
    into matrices over fields, since `4 = 0` there forces `2 = 0`.
  - The same remark applies to the `F_2 × F_2` test on `simple-lef-rings-are-exactly-matricial`.
- **N5 (Steinberg scope).**
  - The claim needs `R` countable and unital, so the Steinberg bullet needs a compact, second countable unit space.
  - The bisection argument is correct: an arrow with `r(g) ≠ s(g)` exists because an infinite minimal unit space is not
    a single orbit of trivial arrows. A small `σ ∋ g` has `σσ = ∅` and `1_σ1_{σ^{−1}} = 1_{r(σ)}`.

## 4. Word-problem hosts (item 7)

- **Theorem A.**

  - `uniform-wp-bound-excludes-bh-universal-targets` applied to `{U}` gives the conclusion.
- **Theorem B.**

  - `ψ(v) = φ(v̄)` by induction on `|v| ≤ n`, and relators of length `≤ m ≤ n` die. So `ψ̄` separates the whole ball, and

## 5. No distortion (item 8)

- **Module.**
  - `ufu^{−1}δ_{x,t} = f(T^{t−1}x)δ_{x,t} = (f∘T^{−1})δ_{x,t}`, so `V` is an `R`-module.
  - `Aδ_{x,0}ξ = Σ_jA_j(T^jx)ξ δ_{x,j}` puts different `j` in distinct slots, so the action is faithful.
  - `p(AB) ≤ p(A) + p(B)`.
- **Theorem D.**
  - `dim K_N(v) ≤ m(2wℓ(N)+1)`, and Fekete gives `ℓ(N) ≤ (τ+ε)N + C`. If `2wm(τ+ε) < 1`, a uniform `N_0` exists.
  - `P = lcm` of the monic polynomials of degree `< N_0` kills every slot vector, so `P(z) = 0`.
  - `P = t^aQ` with `Q(0) ≠ 0`. Then `z` is a unit of the finite ring `F_q[t]/(Q)`, so it has finite order.
  - PASS.
- **C1.** `[[T]] ↪ GL_1(R)` through `g ↦ Σ_n u^ne_{\{n_g=n\}}`. It is multiplicative, since
  `u^ne_Au^ke_B = u^{n+k}e_{T^{−k}A∩B}` and `x ∈ U^h_k ∩ T^{−k}U^g_n` lies in `U^{gh}_{n+k}`.
- **C2–C4.**
  - `[a^n,b^n] = c^{n²}` and `|c^N| ≤ 4n + 8n ≤ 12√N`.
  - In `BS(1,2)`, `a^{2^k} = t^kat^{−k}`.
  - Distortion passes to f.g. overgroups.
  - `H` is f.g. residually finite, hence LEF. PASS.
- **N6 (display).** The bound `1/(2wm)` assumes `w ≥ 1`. For `w = 0`, `Γ` lies in `GL_m` of a finite subalgebra of
  `LC(X,F_q)`, so it is finite and the statement is vacuous.

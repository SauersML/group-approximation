## 1. `clopen-crossed-product-subrings-have-local-annihilation`

**Proof. Correct.**
- **Step 1.** Pick `y ∉ Φx`, a finite set, which is possible because `X` is infinite. Then `γ^{-1}y ≠ x` for
  `γ ∈ Φ`. Compact Hausdorff totally disconnected implies zero-dimensional, so there is a clopen `V ∋ x` avoiding
  `Φ^{-1}y`. The clopen `W ∋ y` then lies in the complement of `V ∪ ΦV`, using `1 ∈ Φ`.
- **Step 2.** `ts = χ_Wχ_V r = 0`. Also `χ_W g_{f,γ} u_γ χ_V = g_{f,γ} χ_{W∩γV} u_γ = 0`, by
  `u_γχ_V = χ_{γV}u_γ` and commutativity of the coefficient ring.
- **Step 3.** A finite clopen partition refining the `V(x)`, with the same witnesses. `R = Σ_i χ_{V_i}R`.

**Hypothesis match with the Lean definition.** `GroupApproximation/Pestov91/SimpleModCentre.lean`, l. 43, verbatim:

```
def LocalAnnihilation (R : Type*) [Ring R] : Prop :=
  ∀ F : Finset R, NonUnitalSubring.closure
    {s : R | ∃ t : R, t ≠ 0 ∧ t * s = 0 ∧ ∀ f ∈ F, t * f * s = 0} = ⊤
```

- The node proves that `R` is the **additive span** of `S_F` (the set in braces). That is stronger than the
  non-unital closure being `⊤`. **It matches.**
- The model test for finite `X` is correct.

## 2. `sl3-toeplitz-harmonic-pe-groups-are-simple`

**Lean criterion.** `GroupApproximation.Pestov91.isSimpleGroup_elementaryGroup_quotient_center`, l. 327, verbatim

`(hcard : 3 ≤ Fintype.card ι) [IsSimpleRing R] (hloc : LocalAnnihilation R) : IsSimpleGroup (↥(elementaryGroup ι R) ⧸ Subgroup.center ↥(elementaryGroup ι R))`

- The module is imported by the root `GroupApproximation.lean` (l. 4898).
- The companion theorem `normal_le_center_or_eq_top` gives part 1 verbatim: every normal subgroup is central or
  `⊤`.

**Match for `R_T`.**
- `ι = Fin N` with `N >= 3`.
- **`IsSimpleRing R_T`.** Mathlib's two-sided-ideal simplicity is exactly the ring-theoretic "simple". This is
  part 2 of the ring node, which has a single referee pass (see above).
- **`LocalAnnihilation R_T`.** It follows from §1, because `R_T` is a unital subring of the algebraic crossed product
  over the infinite minimal Toeplitz subshift `X`, with `Γ = SL_3(Z)` acting by homeomorphisms. The Toeplitz subshift
  is infinite because the action on the odometer is free. `R_T` contains `LC(X, Z)`, hence every clopen indicator
  (ring node part 1). The coefficient ring is a `Γ`-invariant commutative ring of `Q`-valued functions containing
  the indicators, which is all §1 needs.
- **`elementaryGroup ι R`** is the subgroup generated by the `e_ij(r)`, that is `E_N(R_T)`. **It matches.**

**Infinite.** `a ↦ [e_12(a)]` is injective modulo the centre, because `[e_12(a−b), e_23(1)] = e_13(a−b)`. And `R_T`
is infinite.

**Centre clause.**

**Finite presentation equivalence. Correct.**
- `E_N(R_T)` is finitely generated through `[e_il(a), e_lj(b)] = e_ij(ab)`.
- A finitely presented group stays finitely presented after quotienting by a finite central subgroup: add at most

- Conversely, a finitely generated central extension of a finitely presented group is finitely presented
  (`fg-central-extension-of-fp-group-is-fp`).

# Unit-type vertex rounding: (T)-exact compressor transport and the depth profile

Lane `nh-unit-type-rounding`, 2026-09-12. Target: `theorem-e-vertex-rounds-to-unit-type-representations`.
Outcome: not settled. Three established lemmas cut the non-unit mass that can survive (H1) down to
three explicit regimes.

## Setting

- `R_+ = F_q[x_1..x_d]`, `L = F_q[x^(±1)]`, `r, d >= 3`.
- `Γ = EL_r(R_+) < G = EL_r(L) ⋊ SL_d(Z)`.
- `A ∈ SL_d(Z)` a compressor with all entries `>= 1`, e.g. `A_ij = min(i,j)`. `φ_A` is the
  monomial substitution `x^a -> x^(Aa)`, an injective ring endomorphism of `R_+`, with
  `A γ A^(-1) = φ_A(γ)` for `γ ∈ Γ`.
- `F_Γ` is a finite generating set, and `κ > 0` the Kazhdan constant of `(Γ, F_Γ)`. Γ has property
  (T) by Ershov–Jaikin-Zapirain (EL_r of a f.g. ring, `r >= 3`).
- `σ : G -> U(prod_U M_n)` is trace-preserving. (H1): genuine `π_n : Γ -> U(n')`, `n'/n -> 1`, with
  `max_(s ∈ F_Γ) ||σ_n(s) - π_n(s)||_2 -> 0` along `U`.
- By `unit-type-vertex-rounding-forces-compressor-commutant-rigidity` item 1, `π_n` factors
  through `St_r(B_n)` with `B_n = R_+/I_n = A_u × A_nu`.
- `μ_n` is the normalized spectral measure of `f -> π_n(e_12(f))` on `R_+^` (characters of `(R_+,+)`
  killing `I_n`).
- `z = x_1 ⋯ x_d`.

## §1 Lemma A: the compressor transport exactifies

Put `ρ_n = π_n ∘ Ad A`, a genuine representation of `Γ`, and
`δ_n = max_(s ∈ F_Γ) ||ρ_n(s) U_n - U_n π_n(s)||_2`, where `U_n` is a unitary representative of
`σ_n(A)`, padded by the identity.

1. **Defect.** `δ_n -> 0` along `U`. `σ` is a homomorphism into the ultraproduct, and `A s A^(-1)` is a fixed word in `F_Γ`, on
   which `π_n ≈ σ_n` with error at most (length)·(generator error).
2. **Averaging.** Both `π_n` and `ρ_n` factor through finite quotients of `Γ`. So the projection `E`
   onto invariants of `Φ(γ)X = ρ_n(γ) X π_n(γ)^*` is an average of contractions, and `||E X|| <= ||X||`.
3. **Kazhdan.** Kazhdan's inequality gives `||U_n - T||_2 <= δ_n/κ` for `T = E(U_n)`, and `T` intertwines
   `π_n` with `ρ_n`.
4. **Support.** `||1 - T^*T||_2 <= 2δ_n/κ`. The support `Q` of `T^*T` is `π_n(Γ)`-invariant and satisfies
   `τ(1 - Q) = ||(1 - T^*T)(1 - Q)||_2^2 <= 4δ_n^2/κ^2`. The polar part `W` of `T` is a partial isometry
   with `W^*W = Q`, `WW^* = Q'`, and `W π_n(γ) = ρ_n(γ) W`.
5. **Spectral measures.** `ρ_n(e_12(f)) = π_n(e_12(φ_A f))`, so the spectral measure of `ρ_n|e_12` is
   `D_A* μ_n`, with `D_A χ = χ ∘ φ_A`. On `Q` and `Q'` the two restrictions are unitarily
   equivalent. Hence for every Borel `E`:

   ```text
   | μ_n(E) - μ_n(D_A^(-1) E) |  <=  τ(1 - Q)  <=  4 δ_n^2 / κ^2  =:  η_n.
   ```

This is a total-variation statement at each finite stage, uniform over all test sets. Torus invariance
only gives weak* invariance of the ultralimit.

## §2 Lemma B: non-unit projection versus root spectral mass

`P_n` is the projection onto `Fix(St_r(A_nu))`, i.e. onto the constituents trivial on `St_r(A_nu)`.

- **Generation.** `St_r(B_n) = St_r(A_u) × St_r(A_nu)`, and `St_r(A_nu)` is generated by the root subgroups
  `x_ij(A_nu)`. So `Fix(St_r(A_nu)) = ∩_(i≠j) Fix(e_ij(A_nu))`.
- **Weyl symmetry.** The Weyl words `w_ij(1) ∈ Γ` conjugate `e_12(A_nu)` onto each `e_ij(A_nu)`, up to sign, so all
  these fixed spaces have the same dimension.
- **Fixed fraction.** `dim Fix(e_12(A_nu))/n' = μ_n({χ : χ|A_nu = 1})`.
- **Conclusion.** Codimensions add, so

  ```text
  τ(1 - P_n)  <=  r(r-1) · μ_n({χ : χ|A_nu ≠ 1}).
  ```

## §3 Lemma C: pure non-unit mass is log-scale Følner

Define `depth(χ) = min{k >= 0 : χ is trivial on z^k R_+}`, with value `∞` if there is none.

1. **Finite depth means pure non-unit.** For `χ` killing `I_n`, `z^k B_n = A_u × z^k A_nu`, and `z` is nilpotent on `A_nu`. So
   `depth(χ) < ∞` iff `χ|A_u = 1`. Mixed characters and unit-type characters have depth `∞`.
2. **Contraction.** `φ_A(z) = x^(A·1)` and `(A·1)_i = Σ_j A_ij >= d`, so `φ_A(z^k R_+) ⊆ z^(dk) R_+`. Hence
   `depth(D_A χ) <= ⌈depth(χ)/d⌉`.
3. **Per-scale bound.** Put `F_j = μ_n(depth <= d^j)`. By item 2, `D_A^(-1){depth <= d^j} ⊇ {depth <= d^(j+1)}`, so Lemma A gives
   `F_(j+1) <= F_j + η_n`. Each d-adic depth block `(d^j, d^(j+1)]` carries `μ_n`-mass at most `η_n`.
4. **Depth bound.** `B_n` embeds in `∏_(ij) π_n(e_ij(R_+))`, a product of elementary abelian p-subgroups of `U(n')`.
   So `dim_(F_p) A_nu <= r(r-1) n'`, and finite depths are at most `r(r-1)n'`. Hence

   ```text
   μ_n(1 < depth < ∞)  <=  η_n · (1 + log_d(r(r-1) n')).
   ```

## §4 What survives

By Lemma B, unit-type rounding (`τ(1 - P_n) -> 0`) needs `μ_n(χ|A_nu ≠ 1) -> 0`. That mass splits as:

- **(i) depth > 1, pure non-unit.** It is at most `η_n log n'`, so it vanishes whenever `δ_n^2 log n -> 0` along `U`. It can
  survive only when spread over `>= 1/η_n` d-adic depth scales. This is exactly the Følner escape
  along the amenable cyclic compressor direction predicted in `hs-scale-pinning`.
- **(ii) depth <= 1, pure non-unit.** Characters of `R_+/(z)`, the coordinate hyperplanes. `D_A` does not contract
  them. Torus invariance kills their ultralimit mass: `μ_U(E_k)` is constant in `k ∈ Z` for
  `E_k = {χ trivial on z^(2k+1) R_+}`, so no nontrivial limit mass sits at any fixed depth. But that
  is weak* information only.
- **(iii) mixed** (`χ|A_u ≠ 1` and `χ|A_nu ≠ 1`). Depth `∞`, so Lemma C says nothing.

## Not done

- No model with surviving non-unit mass was built, and no proof covers (ii) or (iii).
- A refutation would need `σ` far from genuine on the actor, with either `δ_n^2 log n` not tending to 0 and non-unit
  mass spread across scales, or shallow or mixed non-unit constituents. Weak* torus invariance of the
  limit forbids fixed-depth concentration.
- Nothing here is reviewed.

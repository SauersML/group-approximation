## 1. Theorem 5

**Theorem 5.**  Let `E` be separable, nuclear and stably finite, `R = R_qd(E)`,
and suppose `E/J` satisfies the UCT for every ideal `J ⊆ R` of `E`.  Suppose `R`
has an increasing approximate unit of projections `(e_k)`.  Put
`D_k = e_k R e_k` and `H = ∂(K_1(E/R)) ⊆ K_0(R)`.  Suppose there are bounded
traces `τ_k` on `D_k` with the following properties:
- they are not all zero;
- they are compatible: `τ_(k+1)|_(D_k) = τ_k`;
- they vanish on `H`: `τ_k^(h) = 0` whenever `h ∈ H` is represented over `D_k`.

Then `R = 0`, i.e. `E` is quasidiagonal.

Every `h ∈ K_0(R)` is `[p] - [r]` with `p, r ∈ M_N(D_k)` for large `k`.  So the
compatible family defines `τ^ : K_0(R) -> R`, and the last condition says
`τ^(H) = 0`.

*Proof.*
Step 1 (the ideal).  Let `N_k = {d ∈ D_k : τ_k(d*d) = 0}`, so that
`N_k = N_(k+1) ∩ D_k`.  Let `J` be the closure of the union of the ideals `J_k`
of `R` generated by `N_k`.
- For a hereditary `C ⊆ R` and an ideal `N` of `C`, the ideal generated by `N`
  meets `C` in `N`.  This follows by Cohen factorisation `n = n_1 n_2 n_3`,
  since `C R C ⊆ C`.
- Apply this in `D_l` and pass to the closed union: `J ∩ D_k = N_k`.
- Some `τ_k(e_k) > 0`, so `e_k ∉ J` and `J ⊊ R`.

Step 2 (quotient corners).  `q(e_k)` is an approximate unit of projections for
`R/J`, and `q(e_k)(R/J)q(e_k) ≅ D_k/N_k` carries the faithful trace `τ̄_k`.  For
`h ∈ H` represented over `D_k`, `τ̄_k^(q_*h) = τ_k^(h) = 0`.  Let `I_k` be the
ideal of `R` generated by `e_k`.  `D_k/N_k` is a full corner of the ideal
`(I_k + J)/J` of `E/J`.  That ideal satisfies the UCT by two-out-of-three,
because `E/J` and `E/(I_k + J)` do by hypothesis.

Step 3 (local killing).  Let `G_0 ⊆ q_*(H)` be finitely generated, with
generators `q_*(h_i)` and `h_i = [p_i] - [r_i]`, `p_i, r_i ∈ M_N(D_(k_0))`.  For
`k ≥ k_0` with `τ_k != 0`, let `L_k ⊆ K_0(D_k/N_k)` be generated by
`[q(p_i)] - [q(r_i)]`.
1. The normalised `τ̄_k` vanishes on `L_k`.  Lemma B gives a unital injective
   `φ_k : D_k/N_k -> B_k` into a simple AF algebra with `(φ_k)_*(L_k) = 0`.
2. `L_k` is finitely generated, so these classes vanish at some finite stage
   `F_j` of `B_k`.  A conditional expectation `B_k -> F_j`, the block sum
   `F_j ⊆ M_m`, and a unitisation coordinate give ucp maps
   `(D_k/N_k)~ -> M_(m+1)`.  On any given finite set they are as close to
   multiplicative and isometric as desired, and their value on `L_k` is `0`.
3. `R/J` is locally approximated by the corners `D_k/N_k`, because `q(e_k)` is
   an approximate unit.  Arveson extension to `(R/J)~`, with the estimates in
   the proof of Moutzouris Proposition 3.5, gives asymptotically multiplicative,
   asymptotically isometric ucp maps `(R/J)~ -> M_(m(n))` with value `0` on
   `G_0`.  Only the killing of these specific `L_k` is used, not the full
   K_0-embedding property of the corners.
4. So there is a faithful \*-homomorphism
   `(R/J)~ -> Π M_(m(n)) / ⊕ M_(m(n))` killing `G_0`.
5. The diagonal argument of Moutzouris Proposition 3.3, over an increasing
   exhaustion of `q_*(H)` by finitely generated subgroups, kills all of
   `q_*(H)`.  Proposition 3.2, whose proof builds the extension from the UCT for
   `⊕ C(T)` and uses no singularity, turns this into a quasidiagonal embedding
   of `(R/J)~`, hence of `R/J`, killing `q_*(H)`.

Step 4.  By naturality, the boundary of `0 -> R/J -> E/J -> E/R -> 0` has image
`q_*(H)`.  Lemma C makes `E/J` quasidiagonal, so `R ⊆ J`, a contradiction.  QED

**Corollary 6 (real rank zero).**  Keep the hypotheses of Theorem 5 on `E`, and
suppose `R` has real rank zero (for instance `E` has real rank zero).  If `E` is
not quasidiagonal, every positive group homomorphism `f : K_0(R) -> R` with
`f(H) = 0` is zero.

*Proof.*  Let `f != 0` be positive with `f(H) = 0`.  `D_k` is unital, exact and
of real rank zero.
1. `f_k = f ∘ (K_0(D_k) -> K_0(R))` is positive and `[e_k]` is an order unit.
   If `f_k([e_k]) > 0`, the normalised `f_k` is a state.  It is induced by a
   tracial state (Moutzouris (2.5), exactness), and that tracial state is
   unique by real rank zero.  Let `τ_k` be the corresponding multiple.
   If `f_k([e_k]) = 0`, then `f_k = 0`; put `τ_k = 0`.
2. `τ_(k+1)|_(D_k)` induces `f_k`, so uniqueness gives compatibility.
3. `f != 0` gives some `τ_k != 0`.

Theorem 5 now makes `E` quasidiagonal, a contradiction.  QED

## 2. Model tests

- **Trivial model failing the hypothesis.**  The Toeplitz algebra has `R = K`
  with approximate unit `e_k` and `Tr` compatible.  But `Tr^(H) = Z != 0`
  because `T` is not stably finite, so no compatible family vanishes on `H`.
  Consistent.
- **Real object satisfying it.**  Let `R = ⊕_n K` inside an extension
  `0 -> R -> E -> C(T) -> 0` with index
  `e_1 - e_2 ∈ K_0(R) = ⊕ Z` (`E` stably finite).  The traces `Tr` on the
  first two summands, with weights `(1, 1)`, form a compatible family
  vanishing on `H`.  Theorem 5 predicts that `R_qd(E) = 0`, and indeed `E` is
  quasidiagonal: `R` is AF, which has the K_0-embedding property.
- **Where Theorem 5 is blind.**  Let `R` be AF with `K_0(R) = ⊕_n Z e_n`,
  ordered lexicographically along the chain: `v > 0` iff its last nonzero
  coordinate is `> 0`.  Then `m e_n ≤ e_(n+1)` for all `m`, so any positive
  `f` has `f(e_n) ≤ f(e_(n+1))/m` for all `m`.  Hence `f = 0`: `R` has no
  nonzero densely finite trace at all.  Such `R` has the K_0-embedding property
  (AF), so it yields no counterexample, but the trace step cannot see it.

## 3. Consequences and the next hinge

A counterexample with UCT quotients has a radical `R` such that:
1. `Prim(R)` has a nonempty compact open subset carrying a traced compact ideal
   (`stw07-qd-radical-criterion-compact-open`);
2. no projection generates `R` (Theorem 1);
3. if `R` has an approximate unit of projections, no nonzero compatible corner
   trace vanishes on the boundary `H`.  In real rank zero this means
   `(K_0(R) ⊗ Q)/(H ⊗ Q)` has no nonzero positive functional (Theorem 5,
   Corollary 6).

For real rank zero, item 3 forces a non-archimedean ordered `K_0` along every
exhaustion, as in the lexicographic chain.  The missing tool is a **relative
Lemma B**.  Given an ideal `I_u` generated by one projection, and a trace finite
and faithful on `I_u/J` but infinite on `R/I_u`, it should kill `q_*(H)` in `R/J`.
The trace data sit only on the archimedean class of `u`, while the whole
boundary must die.  Equivalently, one needs a transfinite filtration of `R` by
archimedean classes, with one Lemma-C gluing step per class.  None of the tools
read here does this.

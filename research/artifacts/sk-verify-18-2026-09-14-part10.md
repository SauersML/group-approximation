## Lemma Z
- Take z = Σ f_j u^j central. From zu = uz: Σ f_j u^{j+1} = Σ (f_j∘T⁻¹)u^{j+1}, so each f_j is T-invariant, hence a constant c_j by minimality.
- From zf = fz: c_j(f∘T⁻ʲ − f) = 0 for all clopen f. If c_j = 1, then T^j = id, contradicting aperiodicity for j ≠ 0.
- So Z(R) = F_2.

## Lemma C (the centralizer computation)
- g commutes with e_12(r) iff g_{p1}r = 0 (p ≠ 1), r g_{2q} = 0 (q ≠ 2) and g_{11}r = r g_{22}. This comes from (g·rE_12)_{pq} = g_{p1}rδ_{q2} and (rE_12·g)_{pq} = δ_{p1}r g_{2q}.
- With r = 1: g_21 = g_31 = g_23 = 0 and g_11 = g_22. Commuting with e_23(1) likewise gives g_12 = g_32 = g_31 = 0 and g_22 = g_33. So g = cI + g_13E_13.
- For s ∈ S the remaining conditions reduce to cs = sc. So c commutes with the unital ring generated by S, which is R, and c ∈ Z(R).
- **c is a unit:** from gh = hg = I, the (2,2) entries give c h_22 = h_22 c = 1.
- So c = 1 and g = e_13(g_13). Conversely E_13E_12 = E_12E_13 = E_13E_23 = E_23E_13 = 0.

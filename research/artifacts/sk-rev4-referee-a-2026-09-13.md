### §1, simplicity (l.154–212)
- **Small sets:** B_{2w}∖{e} is finite and each fixed set is closed with empty interior, so the points moved by all of them form a dense open set. A clopen neighbourhood V of such a point with V ∩ ξV = ∅, on which the finitely many f∘ξ are constant, is small. So every nonempty clopen set contains one.
- **The commuting criterion:** (g rE_ij)_{pq} = g_pi r δ_qj and (rE_ij g)_{pq} = δ_pi r g_jq give exactly g_pi r = 0 (p ≠ i), r g_jq = 0 (q ≠ j), g_ii r = r g_jj.
- **g diagonal:** cV-computations: c e_V = Σ c_ξ e_{ξV} u_ξ and e_V c = Σ e_V c_ξ u_ξ. A small V ⊆ ξ^{-1}U, resp. V ⊆ U, witnesses c_ξ ≠ 0. So g is diagonal.
- **g scalar:** in g_ii e_V = e_V g_jj, the ξ ≠ e coefficients live on ξV and V, which are disjoint for ξ ∈ B_w∖{e}. The constant coefficients agree on a dense union of small sets, hence everywhere, so g = cI_3. The u_e-coefficient of cc^{-1} = 1 is c·(c^{-1})_e = 1, so c = 1.
- **Matrix units:** ε_ab ε_a′b′ = e_{aV} e_{ab^{-1}a′V} u_{ab^{-1}a′b′^{-1}} = e_{a(V∩b^{-1}a′V)} u_…, and b^{-1}a′ ∈ B_{2w} gives δ_{ba′} ε_ab′. As V ≠ ∅ these are nonzero matrix units, so A_V ≅ M_{|B_w|}(F_2) and GL_3(A_V) ≅ GL_d(F_2), d = 3|B_w|.
- **H_V ⊆ G:** it is generated by the e_pq(ε_ab), p ≠ q. The within-block transvections are [I+E_{(p,a),(q,c)}, I+E_{(q,c),(p,b)}].
- **Product formula:** f u_a e_V f′u_b = f e_{aV}(f′∘a^{-1}) u_{ab}. Here f is constant on aV because f∘a is constant on V, and f′∘a^{-1} is constant on aV because f′ is constant on V. So the product lies in {0, ε_{a,b^{-1}}}, with b^{-1} ∈ B_w as the generating set is symmetric.

### §3, isolation step (l.329–355) — item (i)
- **Well-definedness:** f_jk(x,i) = (μ_k(γ_j)^i x, i) is well defined as μ^{m_k} = 1.
- **The commutator,** composing maps right to left: (x,i) → t^{-1} (x,i−1) → f^{-1} (μ^{-(i−1)}x, i−1) → t (μ^{-(i−1)}x, i) → f (μ^i μ^{-(i−1)}x, i) = (μx, i). At i = 0 this uses μ^{m} = 1. So [f_jk,t_k] multiplies the first coordinate by μ_k(γ_j).
- **Conjugation:** b^{-n}ab^n acts on level i as a acts on level i+n. All maps are level-preserving, so commutators are computed levelwise.
- **Isolation:** on level i, w_j(a_k,b_k) is [a_{i+2^{2j−1}}, a_{i+4^j}], nontrivial only if both indices lie in P = {2^c : 1 ≤ c ≤ 2k} mod M = 4^{k+1}.
  - Then p′ − p ≡ 4^j − 2^{2j−1} = 2^{2j−1} (mod M).
  - As |p′ − p| < 4^k = M/4, this is an equality.
  - 2^a(2^{b−a} − 1) = 2^{2j−1} forces p = 2^{2j−1}, p′ = 4^j, i = 0.
  - So w_j acts by [f_jk, t_k] on level 0 and trivially elsewhere.
- **The ultraproduct map:** γ ↦ (left multiplication on level 0) is multiplicative ω-a.e. because μ_k preserves products on {1, γ_1, …, γ_k} for large k. It is injective, and sends γ_j ↦ w_j(a,b), so Γ ≤ [Δ,Δ].
- **Δ:** f.g. (a, b); LEF (finitely many relations and inequalities hold in a coordinate); infinite (Γ is infinite, and also b has infinite order).

### §3, host (l.357–394)

- **Topological freeness:** fixed points satisfy x(h) = x(δ^{-1}h) + f(h).

### SL_3(Z) obstruction (l.432–442)
- **Faithfulness:** the action Σ f_ju^j δ_{x,t} = Σ f_j(T^{t+j}x) δ_{x,t+j} is faithful, and uf u^{-1} = f∘T^{-1} matches.
- **Krylov bound:** g^nv is supported in {x}×[t − w|g^n|, t + w|g^n|], so dim span{g^nv : n < N} ≤ m(2w·max_{n<N}|g^n| + 1) = o(N).
- **Finite order:** each such v has a minimal polynomial of degree < N. There are finitely many polynomials of degree < N over F_2, so their product P satisfies P(g) = 0 by faithfulness. F_2[g] is finite, so g has finite order (U1).
- **Heisenberg:** [a,b]^{n²} = [a^n,b^n], so |c^N| = O(√N). Word lengths in SL_3(Z) and in the subgroup's generators agree up to constants, and w ≥ 1 costs nothing.

### §4, word problems and factors (l.444–494)
- **The reduction:** multiplication in LC(A^Z,F_2)⋊Z; the tables vanish on L(X). The cylinder word ∏u^{-t}e_{v_t}u^t = e_{[v]} is zero iff v ∉ L(X).
- **The Sturmian proof:**
  - α computes L(X_α): the points jα mod 1 are pairwise distinct irrationals, and θ rational in an arc never makes θ + (t+1)α an integer.
  - L(X_α) computes α: the count of ones in a word of length m is within 1 of mα.
  - [0; 1+χ_S(0), …]: each digit is one strict comparison with a rational, never an equality since α is irrational.
- **P1:** EL_3(F) is the same Kazhdan group for all X over a fixed alphabet; distinct languages give distinct kernels by the cylinder word; separable factor counting as re-derived by sk-verify-10. One alphabet {0,1} makes the continuum count meaningful.

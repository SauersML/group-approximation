"Quasitrace" means bounded 2-quasitrace in the sense of Blackadar–Handelman
(positive on `A_+`, `tau(x*x)=tau(xx*)`, linear on commutative C\*-subalgebras,
complex linear in the real and imaginary parts, and extending to `M_2(A)`).
For a unital C\*-algebra `A` put, following Milhøj–Rørdam Remark 4.7,

```text
mu(A) = least n with M_n(A) properly infinite            (infinity if none),
nu(A) = least n with x_1,...,x_n in A such that
        sum_j x_j* x_j = 1  and  || sum_j x_j x_j* || <= 1/2   (infinity if none).
```

A **certificate of size N and defect delta** is a family `x_1,...,x_N` with
`sum x_j* x_j = 1` and `||sum x_j x_j*|| <= delta`.  By Theorem 3.1 of
Milhøj–Rørdam, `nu(A)<infinity` iff `A` has no tracial state, and certificates
of every positive defect then exist.  By their Theorem 2.3, `mu(A)<infinity` iff
`A` admits no normalized 2-quasitrace.

## 1. Certificate calculus

**Lemma 1.1 (defect floor).**  A certificate of size `N` has defect at least
`1/N`; in particular `nu(A) >= 2`.

*Proof.*  `1 = ||sum x_j* x_j|| <= sum ||x_j* x_j||`, so some
`||x_j x_j*|| = ||x_j* x_j|| >= 1/N`, and `x_j x_j* <= sum_i x_i x_i*`.

**Lemma 1.2 (products).**  If `(x_j)_{j<=N}` has defect `delta` and
`(y_l)_{l<=N'}` has defect `delta'`, then `z_{jl} = x_j y_l` is a certificate
of size `NN'` and defect `delta delta'`.

*Proof.*

```text
sum_{j,l} z_{jl}* z_{jl} = sum_l y_l* (sum_j x_j* x_j) y_l = sum_l y_l* y_l = 1,
sum_{j,l} z_{jl} z_{jl}* = sum_j x_j (sum_l y_l y_l*) x_j* <= delta' sum_j x_j x_j*.
```

Hence a defect-`1/2` certificate of size `nu(A)` yields defect `2^-t`
certificates of size `nu(A)^t`.

**Lemma 1.3 (dominating corners).**  Let `x_1..x_N` in unital `A` have
`sum x_j* x_j = 1` and `||sum x_j x_j*|| <= delta`.  Let `e in M_k(A)` be a
projection with `1_A <~ e` (Murray–von Neumann).  Then the unital corner
`B = e M_k(A) e` contains a certificate of size `N(k+1)` and defect
`(k+1) delta`.  Consequently

```text
nu(e M_k(A) e) <= (k+1) * nu(A)^(1+ceil(log_2(k+1))).
```

*Proof.*  Choose a column `W in M_{k,1}(A)` with `W*W = 1_A` and
`p := WW* <= e`.  Put `X_j = W x_j W*`.  Then `X_j = p X_j p in B`,

```text
sum_j X_j* X_j = W (sum_j x_j* x_j) W* = p,      || sum_j X_j X_j* || <= delta.
```

Put `f = e - p`, a projection in `B`.  Let `f_i in M_{1,k}(A)` be the rows of
`f` and `T_i = W f_i in M_k(A)`, `i=1..k`.  Then `T_i = p T_i = T_i f`, so
`T_i in pBf`, and

```text
sum_i T_i* T_i = sum_i f_i* W*W f_i = f* f = f,     T_i T_i* = W f_i f_i* W* <= p.
```

Put `Y_{j,i} = X_j T_i in B`.  Then

```text
sum_{j,i} Y_{j,i}* Y_{j,i} = sum_i T_i* (sum_j X_j* X_j) T_i = sum_i T_i* p T_i = f,
sum_{j,i} Y_{j,i} Y_{j,i}* = sum_j X_j (sum_i T_i T_i*) X_j* <= k sum_j X_j X_j*.
```

The family `{X_j} union {Y_{j,i}}` has size `N(k+1)`, total
`sum z*z = p + f = e`, and `||sum z z*|| <= (k+1) delta`.  For the displayed
bound apply this to a defect-`2^-t` certificate from Lemma 1.2 with
`(k+1)2^-t <= 1/2`.

**Lemma 1.4 (monotonicity).**  A unital *-homomorphism `A -> B` with `B != 0`
gives `nu(B) <= nu(A)` and `mu(B) <= mu(A)`.  A unital C\*-subalgebra `C` of
`A` that contains a certificate of size `N` has `nu(C) <= N` and
`mu(C) >= mu(A)`.  (Proper infiniteness is two isometries with orthogonal
ranges; homomorphisms push them forward, and a subalgebra has fewer.)

## 2. Universal certificate algebras

For `N >= 2` let `U_N` be the universal unital C\*-algebra generated by
`x_1,...,x_N` subject to

```text
sum_j x_j* x_j = 1,           || sum_j x_j x_j* || <= 1/2.
```

The relations force `||x_j|| <= 1`, so `U_N` exists.  It is nonzero: in
`O_infinity` the elements `s_j / sqrt(N)` satisfy the relations with defect
`1/N`.  Padding by zero gives surjections `U_(N+1) -> U_N`.  `U_N` is traceless:
a tracial state would give `1 = tau(sum x_j* x_j) = tau(sum x_j x_j*) <= 1/2`.

**Theorem 2.1.**  The following are equivalent.

1. Every bounded 2-quasitrace on every C\*-algebra is a trace (Problem I).
2. For every `N >= 2`, `U_N` is stably properly infinite.
3. There is a function `f` with `mu(A) <= f(nu(A))` for every unital traceless
   C\*-algebra `A`.

*Proof.*  `(1 => 2)`.  If `U_N` were not stably properly infinite it would carry
a normalized 2-quasitrace (Milhøj–Rørdam Theorem 2.3).  By (1) this is a trace,
contradicting tracelessness.

`(2 => 3)`.  Put `f(N) = mu(U_N)`.  A certificate of size `N` in `A` is a
unital homomorphism `U_N -> A`, so `mu(A) <= mu(U_N)` by Lemma 1.4.

`(3 => 1)`.  Suppose (1) fails.  By `stw01-traceless-separable-simple-reduction`
there is a unital traceless `B` with a faithful normalized nonadditive
2-quasitrace.  By Theorem 3.1 of Milhøj–Rørdam, `nu(B) < infinity`; by their
Theorem 2.3, `mu(B) = infinity`.  No `f` can bound `mu(B)`.

Milhøj–Rørdam, Remark 4.7, state the (3)-form as the criterion for when an
ultraproduct counterexample can exist.  Form (2) concerns one explicit
finitely presented algebra for each `N`.  By their Lemma 3.4 (proper
infiniteness is witnessed by two elements `a_1,a_2` with
`||a_j* a_i - delta_ij 1|| < 1/2`), statement (2) for a given `N` asserts that
finitely many noncommutative *-polynomial matrices in the generators satisfy
strict universal norm inequalities.

## 3. The full free group algebra is a universal test

**Theorem 3.1.**  The following are equivalent.

1. Problem I.
2. Every bounded 2-quasitrace on `C*(F_2)` is a trace.
3. For some countable group `Gamma` admitting a surjection onto `F_2`, every
   bounded 2-quasitrace on `C*(Gamma)` is a trace.
4. The same holds for every countable group.

*Proof.*  `(1 => 4 => 3)` is trivial, and `(3 => 2)` holds because
`C*(Gamma) -> C*(F_2)` is surjective and a quasitrace on a quotient pulls back
to a quasitrace.

`(2 => 1)`.  Let `sigma` be a bounded 2-quasitrace on `A` with
`sigma(a+b) != sigma(a)+sigma(b)` for self-adjoint `a,b`.  Quasitraces are real
homogeneous on self-adjoint elements, so we may scale `a,b` to norm `< 1`.
Then `u = exp(ia)` and `v = exp(ib)` have spectra in the arc `{e^(it): |t|<1}`,
where `log` is continuous, so `a,b in B := C*(u,v)`.  Restricting the
`M_2(A)`-extension to `M_2(B)` shows that `sigma|_B` is a bounded 2-quasitrace.
Let `pi: C*(F_2) -> B` send the canonical unitaries to `u,v`.  It is surjective,
so choose self-adjoint lifts `a', b'`.  Then `sigma o pi` is a bounded
2-quasitrace on `C*(F_2)` and
`sigma(pi(a'+b')) - sigma(pi(a')) - sigma(pi(b')) != 0`.

Contrast: `C*_r(F_2)` is exact, so Haagerup's theorem already gives (2) for the
reduced algebra.  The universal test sits exactly on the full side, where
`C*(F_2)` is residually finite-dimensional and carries a faithful trace.

## 4. One-sided additivity is the whole problem

**Proposition 4.1.**  Let `sigma` be a bounded 2-quasitrace on a unital `A`.
The following are equivalent: (a) `sigma` is a trace; (b) `sigma` is
subadditive on `A_+`; (c) `sigma` is superadditive on `A_+`.  Moreover, if
some 2-extension `sigma~` on `M_2(A)` satisfies a one-sided Jensen inequality
for the two-point unitary averages `y -> (y + DyD)/2`, where `D = diag(1,-1)`,
in either direction, then `sigma` is a trace.

*Proof.*  `(b => c)`.  For `0 <= a <= alpha` and `0 <= b <= beta`, the elements
`alpha 1 - a` and `beta 1 - b` are positive, and linearity on the commutative
algebras `C*(1, a+b)`, `C*(1,a)` and `C*(1,b)` gives

```text
alpha+beta - sigma(a+b) = sigma((alpha 1 - a) + (beta 1 - b))
                       <= (alpha - sigma(a)) + (beta - sigma(b)).
```

Hence `sigma(a+b) >= sigma(a)+sigma(b)`.  `(c => b)` is symmetric.  Together
these give additivity on `A_+`.  Shifting self-adjoint elements by scalars
gives linearity on `A_sa`, and with `sigma(x*x) = sigma(xx*)` `sigma` is a
trace.

Jensen.  For `a,b >= 0` put `c = [[a^(1/2), b^(1/2)],[0,0]]`.  Then
`cc* = (a+b) (+) 0`, and `c*c` has pinching
`(c*c + D c*c D)/2 = a (+) b`.  Since `sigma~(c*c) = sigma~(cc*) = sigma(a+b)`
and `sigma~(a (+) b) = sigma(a)+sigma(b)` (commuting orthogonal summands and
unitary invariance), a downward Jensen inequality gives superadditivity and an
upward one gives subadditivity.

Consequence: a route to Problem I through a one-sided inequality for
quasitraces is a restatement of the problem, not a reduction.  This includes
Dixmier averaging, which gives `sigma = tau` on a simple unital algebra with a
unique trace once one-sided additivity is available, but supplies no such
inequality itself.

## 5. Products of matrix algebras

**Lemma 5.1 (balancing).**  If `c in R^n`, `sum c_j = 0` and `|c_j| <= M`,
there are a permutation `rho` and `w in R^n` with `||w||_infinity <= M` and
`rho(c) = w - s(w)`, where `s` is the cyclic shift.

*Proof.*  Order the entries greedily: while the running sum is `<= 0` take a
remaining nonnegative entry, otherwise a remaining negative entry.  Because the
total is zero, the required kind always remains, and every partial sum stays in
`[-M, M]`.  Let `w_j` be the partial sums (`w_n = 0`) and `(sw)_j = w_(j-1)`
with `w_0 = w_n`.

**Proposition 5.2.**  For any family of matrix algebras `M_(n_i)`, `i in I`,
every bounded 2-quasitrace on `W = prod_i M_(n_i)`, and on every quotient of
`W`, is a trace.

*Proof.*  Let `sigma` be a bounded 2-quasitrace on `W` and `D` the diagonal
subalgebra.  `sigma|_D` is linear, and unitary invariance on self-adjoint
elements makes it invariant under conjugation by the unitaries of `W` that
permute each block.  For `d in D_sa` let `E(d)` be the element that replaces
each block by its normalized trace times the identity.  By Lemma 5.1, applied
blockwise with one simultaneous permutation per block,
`d - E(d) = w - v w v*` with `w in D`, `||w|| <= 2||d||` and `v` a block
permutation unitary.  Hence `sigma(d) = sigma(E(d))`.  Every `x in W_+` is
`u d u*` with `u` a unitary of `W` and `d in D_+`, and `E(d) = T(x)`, where
`T(x) = (tr_(n_i)(x_i) 1)_i` is the center-valued trace.  So
`sigma(x) = sigma(T(x))`.  `T` is linear and `sigma` is linear on the abelian
center, so `sigma` is additive on `W_+`, hence a trace (Proposition 4.1).
Quasitraces on a quotient pull back to `W`, so quotients inherit the property.

## 6. Products of algebras with uniformly bounded nuclear dimension

**Theorem 6.1.**  Let `(A_k)_(k in K)` be unital C\*-algebras with
`dim_nuc A_k <= d` for all `k`.  Every bounded 2-quasitrace on
`prod_k A_k`, and on every quotient of it (in particular every ultraproduct
`prod_V A_k`), is a trace.

This is Brown–Winter's argument with one change: the finite-dimensional
algebras through which the approximations factor are replaced by products of
matrix algebras, whose quasitraces are traces by Proposition 5.2.

*Proof.*  Let `B = prod_k A_k` and `tau` a bounded 2-quasitrace on `B`.  By
Blackadar–Handelman (Brown–Winter, Lemma 3) it suffices to find a trace
`rho >= tau` on `B_+`.

*Uniform almost order zero approximations.*  Winter–Zacharias Proposition 3.2,
separable part, is quantitative.  For `0 < eps < (d+2)^-4` and a finite set `F`
of positive normalized elements of any C\*-algebra with `dim_nuc <= d`, there is
a piecewise contractive `d`-decomposable c.p. approximation `(F, psi, phi)`,
`phi = sum_(i=0..d) phi^(i)` with `phi^(i)` c.p.c. order zero, such that

```text
|| phi psi (b) - b || < eps^(1/16)          (b in F),
|| psi(c) psi(c') || < eps^(1/16)           (c, c' in F with ||c c'|| < eps).
```

The proof there takes any approximation within `eps` and deletes matrix blocks,
with estimates depending only on `eps` and `d`.  For nonseparable `A_k`, pass to
a separable subalgebra of nuclear dimension `<= d` containing the coordinates
(Winter–Zacharias Proposition 2.6), and extend `psi` to `A_k` by Arveson's
theorem.

*Assembling.*  Index `lambda = (S, eps)` by finite sets `S` of positive
normalized elements of `B` with chosen representatives `s = (s_k)`.  For each
`k` take an approximation `(F_(lambda,k), psi_(lambda,k), phi_(lambda,k))` of
`A_k` for `{s_k : s in S}` as above.  Put
`G^(i)_lambda = prod_k F^(i)_(lambda,k)`.  Coordinatewise maps give c.p.c.
`psi_lambda: B -> (+)_i G^(i)_lambda` and c.p.c. order zero
`phi^(i)_lambda: G^(i)_lambda -> B`.  For `s in S`,
`||s - phi_lambda psi_lambda(s)|| <= eps^(1/16)`.

*Domination.*  `t_(lambda,i) := tau o phi^(i)_lambda` is a bounded
2-quasitrace on `G^(i)_lambda` (order zero pullback, Winter–Zacharias Cor. 3.4
= Brown–Winter Lemma 2), hence a trace by Proposition 5.2.  For `s in S_+`, use
`s <= phi psi(s) + eps^(1/16) 1` and 2-subadditivity iterated over the `d+1`
summands (Blackadar–Handelman II.2.5, as in Brown–Winter):

```text
tau(s) <= 2^d sum_(i=0..d) t_(lambda,i)(psi^(i)_lambda(s)) + eps^(1/16) tau(1).
```

*Limit.*  Let `Uc` be an ultrafilter on the directed set of indices containing
all tails, and `Gc^(i) = prod_lambda G^(i)_lambda / c_Uc`.  The
`t_(lambda,i)` are uniformly bounded by `||tau||`, so `t_i = lim_Uc t_(lambda,i)`
is a bounded trace on `Gc^(i)`.  Let `psib_i: B -> Gc^(i)` be induced by the
`psi^(i)_lambda`.  It is order zero: if `c,c' in B_+` are normalized with
`cc' = 0`, then for indices with `c,c' in S` the estimate
`||psi(c)psi(c')|| < eps^(1/16)` holds in every coordinate `k` (because
`c_k c'_k = 0`), and `eps -> 0` along `Uc`.  So `t_i o psib_i` is a trace
(order zero pullback), and

```text
rho := 2^d sum_i t_i o psib_i
```

is a trace on `B` with `tau <= rho` on `B_+`.  Hence `tau` is a trace.  A
quasitrace on a quotient pulls back to `B`.

*Nonexact examples.*  Theorem 6.1 applies to products and ultraproducts of
algebras with nuclear dimension at most one, e.g. the unital simple separable
nuclear Z-stable algebras.  Such ultraproducts contain residually
finite-dimensional algebras like `C*(F_2)` and are not exact.
Antoine–Perera–Robert–Thiel, Corollary B, treat an ultrapower of a single
algebra under Cuntz-semigroup comparability conditions.  Theorem 6.1 instead
assumes only a uniform nuclear-dimension bound, allows different factors, and
covers full products.  No statement of Theorem 6.1 was found in the sources
read; the literature search was not exhaustive.

**Corollary 6.2 (Kaplansky function over bounded nuclear dimension).**  For
every `d` and `N` there is `f_d(N) < infinity` with `mu(A) <= f_d(N)` for every
unital C\*-algebra `A` with `dim_nuc A <= d` and `nu(A) <= N`.

*Proof.*  Otherwise choose `A_k` with `dim_nuc <= d`, `nu(A_k) <= N` and
`mu(A_k) > k`, and let `B = prod_omega A_k`.  The coordinatewise certificates
give a certificate in `B`, so `B` is traceless.  For each `m`,
`M_m(B) = prod_omega M_m(A_k)` is properly infinite only if `M_m(A_k)` is for
`omega`-many `k` (Milhøj–Rørdam Lemma 4.5), which fails for `k >= m`.  So `B`
is not stably properly infinite and carries a normalized 2-quasitrace
(Theorem 2.3).  By Theorem 6.1 it is a trace, a contradiction.

So any sequence as in Milhøj–Rørdam Remark 4.7 (bounded `nu`, unbounded `mu`)
must have unbounded nuclear dimension.

## 7. The Milhøj–Rørdam ultraproduct candidate

Milhøj–Rørdam Theorem 4.4 gives unital `P_n`, Morita equivalent to Rørdam's
simple nuclear `P` (finite, `M_2(P)` properly infinite), with `M_k(P_n)` finite
for `k <= n` and properly infinite for `k > n`.  Theorem 4.6 shows that each
`P_n` is traceless while `prod_omega P_n` admits a quasitrace.  Whether it
admits a trace is open.  If it does not, Problem I fails.  By Proposition 5.5
it admits a trace iff the `P_n` eventually admit `(N,eps)`-almost traces for
every `N` and `eps`.

What the results above say about it:

- Nuclear dimension is a Morita invariant (Winter–Zacharias Corollary 2.8), so
  all `P_n` share `dim_nuc P`.  Corollary 6.2 cannot decide the family:
  `P` is simple, not stably finite, and has a nonzero finite projection, hence
  is not purely infinite, hence not Z-stable, hence (Winter's theorem) has
  infinite nuclear dimension.  The chain of imports in this sentence is
  standard but was not re-read from source here.
- Lemma 1.3 bounds certificates of corners that dominate the unit.  The corners
  in Theorem 4.4 are small (`e` dominated by `1/n` of the unit), where
  certificates may degrade.  No lower bound on `nu(P_n)` is available.
- The finiteness in Rørdam's construction is topological: Euler classes over
  `(S^2)^N`, Rørdam Proposition 3.2.  It carries no linear functional.  Nothing
  in the construction produces almost traces, and nothing produces uniformly
  small certificates on small corners of `D x_alpha Z`.  Both answers remain
  plausible.

## 8. Attacks recorded and where they die

- *Counting with 2-subadditivity.*  Let `sigma` be a normalized quasitrace on
  an algebra with a certificate of size `N` and defect `delta`.  Iterated
  2-subadditivity along a balanced tree gives
  `1 = sigma(sum x_j* x_j) <= C_N S` with `C_N <= 2N` and
  `S = sum sigma(x_j* x_j) = sum sigma(x_j x_j*)`.  Monotonicity gives
  `delta >= sigma(sum x_j x_j*) >= S/N >= 1/(N C_N)`.  A contradiction needs
  `1/(N C_N) > delta`.  Lemma 1.1 gives `delta >= 1/N`, so it needs `C_N < 1`,
  which never holds.  Estimates that only bound sums of quasitraces by
  constants cannot work.
- *Haagerup–Thorbjørnsen descent.*  Milhøj–Rørdam Section 3 descends proper
  infiniteness from `A (x) C*_r(F_infinity)` to `M_k(A)` using exactness of `A`
  and matricial approximation of free semicirculars.  They note the key norm
  estimate `(*)` fails for suitable certificates in `C*(F_infinity)`.  In
  Theorem 2.1(2) the algebra `U_N` is non-exact, so this descent is unavailable
  there.
- *Dixmier averaging.*  It requires a one-sided inequality, which by
  Proposition 4.1 is the problem itself.
- *Corner transfer.*  Lemma 1.3 gives upper bounds on certificate size only.

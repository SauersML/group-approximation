# Referee report (gq-referee-a, proof-gap lens): the prime-shift affine group A_1 is not finitely presented

**Verdict: PASS.** No gaps. There is one bookkeeping slip in §2, and §3 absorbs it. The refutation of
`prime-shift-affine-group-a1-is-finitely-presented` stands. It does not depend on injectivity of `Π_1 → A_1`.

## (a) The translations
- The ultrametric inequality gives two facts, both independent of the prime, so they hold at `p = 2` too.
  - If `v_p(x) < 0 = v_p(1)`, then `v_p(x ± 1) = v_p(x)`.
  - If `v_p(x) ≥ 0`, then `v_p(x ± 1) ≥ 0`.
- Primes that divide nothing (`v_p(x) = 0`) may acquire positive valuation, never negative.
- So `τ^{±1}` preserves the set of negative valuations exactly, and creates none.
- A deep point never maps to `0`, since `x = ∓1` is not deep.

## (b) Margins
**The slip in §2.** The proof says `δ^{±1}` sends a `(C,V)`-deep point to a `(C+1, V+1)`-deep one. The correct
statement is `(C+1, V−1)`-deep:
- if `j = 0`, the deep valuation may increase by 1;
- if `j ≠ 0`, the shallow valuation `v_0` may decrease by 1.

**§3 uses the correct bounds, so the argument holds.**
- Along a word of length `ℓ`, only `δ` moves valuations, by 1 per step.
- `τ` keeps negative valuations fixed and nonnegative ones nonnegative.
- `σ` re-indexes the valuations and keeps both bounds.
- So after `i ≤ ℓ` steps the shallow valuations are `≥ −C − i` and the deep one is `< −C − 3ℓ − 1 + i ≤ −C − 2ℓ − 1`.
- Every intermediate point is therefore deep, and `π(gx) = φ_{γ_1} ∘ ⋯ ∘ φ_{γ_ℓ}(π(x))`.

## (c) Well-definedness
- `p_j^v` is deep, with `π = (j, v)`.
- Two words for the same `g` agree at every such point, so their germs coincide on all `(j, v)` with `v ≪ 0`.
- Germs of deep maps compose, so `g ↦ [φ_g]` is a homomorphism.
- `Φ(m_r)` can be read off directly from the action: `π(r x) = (j, v + v_j(r))` for `v ≪ 0`.

## (d) The germ group is `Z ≀ Z`
- Write `S` for `[φ_σ]`, `(j,v) ↦ (j+1, v)`, and `T_e : (j,v) ↦ (j, v + e_j)` with `e ∈ ⊕_Z Z`.
- `S^k T_{δ_0} S^{−k} = T_{δ_k}`.
- Products satisfy `(S^k T_e)(S^{k'} T_{e'}) = S^{k+k'} T_{e' + e(·+k')}`. This is the wreath product law.
- Distinct `(e, k)` give distinct germs: `k` is read off from the shift of `j`, and each `e_j` from the value at a fixed
  `j` and `v ≪ 0`.
- So the germ group is `Z ≀ Z`, and it is generated by `S` and `T_{δ_0}` because `e` is finitely supported.

## (e) The kernel bound
- In `Aff(Q)`, the normal closure of `τ` is the translation group, since `m_r τ m_r^{-1}` is `x ↦ x + r`.
- So `Π_1/⟨⟨τ⟩⟩ = Q^× *_{Q^×} (Q^× ⋊ ⟨s⟩) = Q^× ⋊_σ ⟨s⟩ ≅ Z/2 × Z ≀ Z`, because `σ(−1) = −1`.
- This group surjects onto `A_1/⟨⟨τ⟩⟩`. Composing with `Φ` gives the projection to `Z ≀ Z`: check it on `m_r`, `s` and
  `ι`. So the kernel `F` is the image of `⟨ι⟩`.
- **Conclusion.** Suppose `A_1` were finitely presented. Then so would be `A_1/⟨⟨τ⟩⟩`, and then `Z ≀ Z = (A_1/⟨⟨τ⟩⟩)/F`,
  since `F` is finite. That contradicts Baumslag. Correct.

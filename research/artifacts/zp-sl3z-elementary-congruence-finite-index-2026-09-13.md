# The level-m elementary subgroup of SL_3(Z) contains Γ(m²)

Lane z3-04-sl3z-coherent, 2026-09-13. Unreviewed.

Statement needed by `sl3z-congruence-elementary-generators-have-finite-index`: for every
m ≥ 1, the subgroup E(m) ≤ SL_3(Z) generated by the six matrices e_ij(m) has finite index.
We prove E(m) ⊇ Γ(m²) = ker(SL_3(Z) → SL_3(Z/m²Z)). The only literature input is
Bass–Milnor–Serre, Corollary 4.3(b), read from the Numdam scan (§5). Tits's note
"Systèmes générateurs de groupes de congruence" (C. R. Acad. Sci. Paris 1976) is recalled
as the general source of this kind of statement; it was not read, and the argument below
does not use it.

## 1. Notation and relations

A is a commutative ring, n = 3, and the indices are {1, 2, 3}. For i ≠ j and s ∈ A put
e_ij(s) = I + s E_ij, and write [x, y] = x y x⁻¹ y⁻¹.

- (R1) e_ij(s) e_ij(t) = e_ij(s + t).
- (R2) [e_ij(s), e_jk(t)] = e_ik(st) for distinct i, j, k.
- (R3) e_ij(s) and e_kl(t) commute when j ≠ k and i ≠ l; this includes two matrices in
  the same row or in the same column.

*Check of (R2).* (I + sE_ij)(I + tE_jk) = I + sE_ij + tE_jk + st E_ik. Multiplying on the
right by I − sE_ij gives I + tE_jk + st E_ik, since E_jk E_ij = 0 and E_ik E_ij = 0.
Multiplying by I − tE_jk then gives I + st E_ik. (R1) and (R3) are immediate.

Conjugation formulas, from x y x⁻¹ = [x, y] y. For distinct i, j, k:
- (C1) e_ki(s) e_ij(t) e_ki(−s) = e_kj(st) e_ij(t);
- (C2) e_jk(s) e_ij(t) e_jk(−s) = e_ik(−ts) e_ij(t), because [e_jk(s), e_ij(t)] = e_ik(ts)⁻¹.

For an ideal J put z_ij(t, c) = e_ji(c) e_ij(t) e_ji(−c), with t ∈ J and c ∈ A. Define:
- F(J) = ⟨e_ij(t) : t ∈ J, i ≠ j⟩;
- H(J) = ⟨z_ij(t, c) : t ∈ J, c ∈ A, i ≠ j⟩;
- E_3(A, J) = the normal subgroup of E_3(A) = ⟨e_ij(A)⟩ generated by F(J).

Then F(J) ⊆ H(J) ⊆ E_3(A, J), and z_ij(t, c)⁻¹ = z_ij(−t, c).

**(Obs).** Let t ∈ J and x = e_kl(c) with c ∈ A. If (k, l) = (j, i), then x e_ij(t) x⁻¹ is
z_ij(t, c). If (k, l) ≠ (j, i), it is a product of at most two elementary matrices with
entries in J, by (R3), (C1) or (C2). Either way it lies in H(J).

## 2. Lemma A: generation by opposite-root conjugates (n = 3)

**Lemma A.** H(J) = E_3(A, J).

*Proof.* It suffices to show x z x⁻¹ ∈ H(J) for x = e_hk(b), b ∈ A, and z = z_ij(t, c).
Inverses of both kinds of generator are of the same kind, so this makes H(J) normal in
E_3(A). Since H(J) contains F(J), it then contains E_3(A, J). Let l be the third index.
The six ordered pairs (h, k) fall into four cases.

**Case 1: (h, k) ∈ {(j, i), (j, l), (l, i)}.** Here x commutes with e_ji(c), so
x z x⁻¹ = e_ji(c) (x e_ij(t) x⁻¹) e_ji(−c).
- For (j, i) this is z_ij(t, b + c).
- For (j, l), (C2) gives x e_ij(t) x⁻¹ = e_il(−tb) e_ij(t).
- For (l, i), (C1) gives x e_ij(t) x⁻¹ = e_lj(bt) e_ij(t).
In the last two subcases each factor has its entry in J, and conjugating each factor by
e_ji(c) lands in H(J) by (Obs).

**Case 2: (h, k) = (i, l).** Here x commutes with e_ij(t) (same row). Also
[e_ji(c), e_il(b)] = e_jl(cb) by (R2), so x e_ji(c) x⁻¹ = e_jl(−cb) e_ji(c). Hence
x z x⁻¹ = e_jl(−cb) z e_jl(cb), which lies in H(J) by Case 1 with (h, k) = (j, l).

**Case 3: (h, k) = (l, j).** Here x commutes with e_ij(t) (same column). Also
[e_lj(b), e_ji(c)] = e_li(bc), so x z x⁻¹ = e_li(bc) z e_li(−bc), which lies in H(J) by
Case 1 with (h, k) = (l, i).

**Case 4: (h, k) = (i, j).**

*Step 1: z as a commutator.* By (R2), e_ij(t) = [e_il(t), e_lj(1)]. Conjugating by e_ji(c)
and using (C1) and (C2):
- e_ji(c) e_il(t) e_ji(−c) = e_jl(ct) e_il(t);
- e_ji(c) e_lj(1) e_ji(−c) = e_li(−c) e_lj(1).
So z = [X_0, Y_0] with X_0 = e_jl(ct) e_il(t) and Y_0 = e_li(−c) e_lj(1).

*Step 2: conjugate by x = e_ij(b).*
- [e_ij(b), e_jl(ct)] = e_il(bct), and e_il(t) commutes with x. So
  X := x X_0 x⁻¹ = e_jl(ct) e_il(t(1 + bc)), a product of column-l elementary matrices with
  entries in J.
- [e_ij(b), e_li(−c)] = e_lj(cb), and e_lj(1) commutes with x. So
  Y := x Y_0 x⁻¹ = e_li(−c) e_lj(1 + cb), a product of row-l elementary matrices.
- So x z x⁻¹ = [X, Y] = X · (Y X⁻¹ Y⁻¹), and X ∈ F(J) ⊆ H(J).

*Step 3: Y X⁻¹ Y⁻¹ ∈ H(J).* Write Y = e_li(r_i) e_lj(r_j) and X⁻¹ = e_il(s_i) e_jl(s_j)
with s_i, s_j ∈ J. It suffices to show that Y e_il(s) Y⁻¹ and Y e_jl(s) Y⁻¹ lie in H(J)
for s ∈ J.

- *First factor.* [e_il(s), e_lj(r_j)] = e_ij(s r_j), so
  e_lj(r_j) e_il(s) e_lj(−r_j) = e_ij(−s r_j) e_il(s). Conjugating by e_li(r_i):
  - e_ij(−s r_j) becomes e_lj(−r_i s r_j) e_ij(−s r_j), by (C1);
  - e_il(s) becomes z_il(s, r_i).
  Both lie in H(J).
- *Second factor.* e_lj(r_j) e_jl(s) e_lj(−r_j) = z_jl(s, r_j). Now conjugate by e_li(r_i).
  For the generator z_jl, the "(i, j)" of the lemma is (j, l), with third index i, and
  (h, k) = (l, i) is the "(j, l)" position of Case 1 for that generator. Case 1 has
  already been proved, so the result lies in H(J).

So x z x⁻¹ ∈ H(J). The case analysis uses only (Obs) and Case 1, so it is not circular. ∎

## 3. Lemma B: a commutator identity

**Lemma B.** For an ideal q, a, b ∈ q, c ∈ A and i ≠ j, the element z_ij(ab, c) lies in
F(q). Consequently z_ij(t, c) ∈ F(q) for every t ∈ q².

*Proof.* Let l be the third index. By (R2), e_ij(ab) = [e_il(a), e_lj(b)]. Conjugating by
e_ji(c) and applying (C1) and (C2):

  z_ij(ab, c) = [e_jl(ca) e_il(a), e_li(−bc) e_lj(b)].

Every entry ca, a, −bc, b lies in q, so both commutator entries lie in F(q). The map
t ↦ z_ij(t, c) is a homomorphism from (A, +), by (R1) and conjugation. Every element of q²
is a finite sum of products ab. ∎

## 4. Theorem C

**Theorem C.** For every commutative ring A and ideal q, F(q) ⊇ E_3(A, q²).

*Proof.* Lemma B gives H(q²) ⊆ F(q), and Lemma A gives H(q²) = E_3(A, q²). ∎

## 5. The case A = Z

Source: H. Bass, J. Milnor, J.-P. Serre, *Solution of the congruence subgroup problem for
SL_n (n ≥ 3) and Sp_2n (n ≥ 2)*, Publ. Math. IHÉS 33 (1967), 59–137. Read 2026-09-13 from
the Numdam scan (numdam.org/item/10.1007/BF02684586.pdf), pages 71, 94 and 95.

- §4, p. 94: "Let A be a commutative ring and let q be an ideal of A. E_n(A) denotes the
  subgroup of SL_n(A) generated by all "elementary" matrices, I + te_ij (t∈A, i≠j), and
  E_n(A, q) denotes the *normal* subgroup of E_n(A) generated by those with t∈q. This is a
  subgroup of SL_n(A, q) = ker(SL_n(A) → SL_n(A/q))." Theorem 4.1 b): "Write
  C_q(n) = SL_n(A, q)/E_n(A, q)".
- p. 95: "*Corollary 4.3.* — Suppose that A is of arithmetic type and that n≥3. a) SL_n(A)
  is equal to E_n(A) and it is a finitely generated group, equal to its own commutator
  subgroup. b) If A is not totally imaginary then C_q={1} for all q."
- §3, p. 71: "A denotes a Dedekind ring of arithmetic type defined by a finite set, S_∞, of
  primes in a global field k. [...] We shall call A totally imaginary if S_∞ consists of
  complex primes. This means that k is a totally imaginary number field, and that A is its
  ring of algebraic integers."

A = Z is the ring of integers of Q, with S_∞ the real prime. It is of arithmetic type (the
standing case of the Introduction, p. 59) and not totally imaginary. The formal definition
of "arithmetic type" in the Appendix was not re-read. BMS's E_n(A, q) is exactly E_3(A, J)
of §1.

**Corollary D.** For every m ≥ 1, E(m) = ⟨e_ij(m) : i ≠ j⟩ ≤ SL_3(Z) contains
Γ(m²) = ker(SL_3(Z) → SL_3(Z/m²Z)). So [SL_3(Z) : E(m)] ≤ |SL_3(Z/m²Z)| < ∞.

*Proof.*
- e_ij(mx) = e_ij(m)^x, so E(m) = F(mZ).
- Theorem C gives E(m) ⊇ E_3(Z, m²Z).
- BMS Corollary 4.3(b) gives E_3(Z, m²Z) = SL_3(Z, m²Z) = Γ(m²).
- The index of Γ(m²) is the order of the image of reduction mod m², which is at most
  |SL_3(Z/m²Z)|. ∎

## 6. Credit and scope

Lemma A is the n = 3 case of the generation lemma for relative elementary groups, commonly
attributed to Vaserstein–Suslin (1976) and to Tits (1976). Theorem C is the SL_3 case of a
statement attributed to Tits (1976). Both are recalled here and were not read. The proofs
above were written out independently and use only (R1)–(R3). Corollary D uses the
congruence subgroup theorem for SL_3(Z) (Bass–Milnor–Serre; Mennicke) in the verified form
above.

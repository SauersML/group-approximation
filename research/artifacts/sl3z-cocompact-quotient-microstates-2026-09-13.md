# SL_3(Z) on SL_3(R)/Λ: unique ergodicity, and soficity as a topological question (2026-09-13)

Lane `ex-sl3z-cocompact-quotient`. Notation: `G = SL_3(R)`, `Γ = SL_3(Z)`, `Λ <= G` a cocompact lattice,
`X = G/Λ` (compact), `μ` the `G`-invariant probability measure. `u_ij(t) = I + tE_ij`.

## 1. Import: Benoist--Quint, Corollaire 1.2

Source: Y. Benoist, J.-F. Quint, *Mesures stationnaires et fermés invariants des espaces homogènes*,
Ann. of Math. 174 (2011). Read from the preprint PDF `prepubli/09stationnaire.pdf` on Benoist's homepage
(`imo.universite-paris-saclay.fr/~yves.benoist`), pages 1--2, verbatim:

> **Corollaire 1.2.** Soient G un groupe de Lie réel quasi-simple connexe, Λ un réseau de G, X = G/Λ et
> Γ un sous-semi-groupe Zariski dense de G. Alors,
> a) Toute probabilité Γ-invariante sans atome ν sur X est la probabilité de Haar.
> b) Tout fermé Γ-invariant infini F de X est égal à X.
> c) Tout suite de Γ-orbites finies distinctes X_n dans X s'équirépartit vers la probabilité de Haar.

With their conventions (p. 1--2): *"Un groupe de Lie réel G est dit quasi-simple si son algèbre de Lie
est simple"*; *"Elle est dite sans atome si, pour tout x dans X, on a ν({x}) = 0"*; for non-linear `G`,
Zariski dense means `Ad(Γ)` is Zariski dense in `Ad(G)`.

Part c) also gives the Hecke equidistribution used in `sl3z-lattice-space-action-is-sofic`, which that
proof derives separately from Howe--Moore.

## 2. Unique ergodicity and minimality

**Proposition 2.1.** Every `Γ`-orbit in `X` is infinite. The action `Γ ↷ X` is minimal, and `μ` is its only
invariant Borel probability measure.

*Proof.* (a) *Zariski density.* A polynomial on `M_3(R)` that vanishes on `Γ` vanishes on `u_ij(n)` for
all `n ∈ Z`. Along the line `t ↦ u_ij(t)` it is a polynomial in `t` with infinitely many zeros, so it
vanishes on `u_ij(R)`. So the Zariski closure of `Γ` contains all the `u_ij(R)`, and these generate `G`.
`G` is connected and `sl_3(R)` is simple, so Corollaire 1.2 applies.

(b) *No finite orbits.* Suppose `Γ·gΛ` is finite. Then `Γ_0 = {γ : γgΛ = gΛ}` has finite index in `Γ`, so
it contains `u = u_12(n)` for some `n >= 1`, and `w = g^(−1)ug ∈ Λ ∖ {1}`. Put `a_t = diag(e^(−t), e^t, 1)`
and `h_t = a_t g`. Then `h_t w h_t^(−1) = a_t u a_t^(−1) = u_12(n e^(−2t)) → 1`. Since `Λ` is cocompact there
is a compact `F ⊆ G` with `G = FΛ`; write `h_t = f_t λ_t`. Then
`λ_t w λ_t^(−1) = f_t^(−1)(h_t w h_t^(−1)) f_t → 1`, uniformly since `F` is compact. These are elements of
`Λ ∖ {1}`, and `Λ` is discrete. Contradiction.

(c) *Unique ergodicity.* Let `ν` be a `Γ`-invariant Borel probability measure. If `ν({x}) > 0`, all points
of `Γx` carry the same mass, so `Γx` is finite, contradicting (b). So `ν` has no atoms, and `ν = μ` by
Corollaire 1.2(a).

(d) *Minimality.* For `x ∈ X`, the closure of `Γx` is closed, `Γ`-invariant and infinite by (b). By
Corollaire 1.2(b) it is `X`. ∎

The same proof works for any Zariski-dense subgroup of `G` that contains a nontrivial unipotent element,
and any cocompact `Λ`. Freeness is not needed.

## 3. Soficity of a uniquely ergodic action is existence of topological microstates

**Setting.** `Γ` is a countable sofic group acting by homeomorphisms on a compact metric space `(X,d)`,
and `μ` is a `Γ`-invariant Borel probability measure.

**Definition 3.1.** Let `F ⊆ Γ` be finite with `1 ∈ F`, and let `ε > 0`. An *`(F,ε)`-microstate* is a finite
set `V` with maps `σ : F → Sym(V)` and `y : V → X` such that

```text
(M1)  |{v : σ(s)σ(t)v != σ(st)v}| <= ε|V|         whenever s, t, st ∈ F,
(M2)  |{v : d(y(σ(s)v), s·y(v)) >= ε}| <= ε|V|     for every s ∈ F.
```

Neither freeness of `σ` nor any condition on the distribution of `y` is required.

**Theorem 3.2.** (i) If `Γ ↷ (X,μ)` is sofic (Păunescu Definition 1.4), then `(F,ε)`-microstates exist
for all `F, ε`. (ii) If `μ` is the unique `Γ`-invariant probability measure and microstates exist for all
`F, ε`, then `Γ ↷ (X,μ)` is sofic.

So for a uniquely ergodic action, soficity depends only on the topological system `Γ ↷ X`.

The tool is Lemma LC of `research/artifacts/nonsofic-action-mixing-transfer-2026-09-12.md`, Section 2:
the action is sofic iff it has models of every level `m` and error `ε`, for fixed generating partitions
`P_m` and exhausting finite sets `F_m`. The trace of a word `w` in the crossed product is
`τ(w) = μ(B_w)` if its group part `h_w` is `1`, and `0` otherwise. Here `B_w` is the intersection of the
translates of partition sets read off from `w`, as in Step 3 of `finite-equidistributed-orbits-give-sofic-action-proof`.

**Partitions with small mesh.** For each `m`, cover `X` by finitely many open balls of radius `1/m` whose
boundaries are `μ`-null. All but countably many radii qualify. Let `P_m` be the partition generated by
all balls chosen at stages `<= m`. Every atom of `P_m` lies in some stage-`m` ball, so `mesh(P_m) <= 2/m`.
The atoms and their translates are `μ`-continuity sets, and `P_m` increases and generates. We use these
`P_m` in Lemma LC, with symmetric `F_m ∋ 1`.

*Proof of (i).* Fix `F` and `ε`. Choose `m >= 3` with `F ⊆ F_m`, and `m` large enough that
`ω_s(2/m) + 2/m < ε` for `s ∈ F`, where `ω_s` is a modulus of uniform continuity of `s` on `X`. Take a
model `(Y, σ, (Y_p))` of level `m` and error `ε' = ε/(|P_m|^2 + 1)`. Pick `x_p ∈ p` for each nonempty
atom `p` (if `p` is empty then `μ(p)=0`, so `|Y_p| <= ε'|Y|`; send those points anywhere). Put
`y(v) = x_p` for `v ∈ Y_p`.

(M1): the word `u_s u_t u_(st)^*` has trace `1`, so its model trace, the fixed-point fraction of
`σ(s)σ(t)σ(st)^(−1)`, exceeds `1 − ε'`.

(M2): for atoms `p, q` the word `1_q u_s 1_p u_s^*` equals `1_(q ∩ sp)`, with trace `μ(q ∩ sp)`. Its model
trace is the fraction of `v` with `v ∈ Y_p` and `σ(s)v ∈ Y_q`. If `d(s x_p, x_q) >= ε`, then
`sp ∩ q = ∅`, because otherwise `d(s x_p, x_q) <= diam(sp) + diam(q) <= ω_s(2/m) + 2/m < ε`. So such
pairs have `μ(q ∩ sp) = 0` and model fraction `< ε'`. Summing over at most `|P_m|^2` pairs gives (M2). ∎

*Proof of (ii).* Let `(V_k, σ_k, y_k)` be `(F'_k, ε_k)`-microstates, with `F'_k` increasing and
exhausting `Γ`, and `ε_k → 0`. Let `τ_k : Γ → Sym(W_k)` be a sofic approximation of `Γ`.

*Step A: equidistribution.* Put `ν_k = (y_k)_*(uniform on V_k)`. Let `f ∈ C(X)` and `s ∈ Γ`, and take `k`
with `s ∈ F'_k`. Since `σ_k(s)` is a bijection, `Σ_v f(y_k(σ_k(s)v)) = Σ_v f(y_k(v))`. So by (M2),

```text
| ∫ f∘s dν_k − ∫ f dν_k | <= ω_f(ε_k) + 2||f||_∞ ε_k → 0 .
```

Every weak-* limit point of `(ν_k)` is therefore `Γ`-invariant, hence equal to `μ`. `Prob(X)` is
compact, so `ν_k → μ`.

*Step B: iterated (M2).* Let `g_1, ..., g_n ∈ F_m` with `n <= m`. For `v ∈ V_k`, put `v_n = σ_k(g_n)v` and
`v_j = σ_k(g_j)v_(j+1)`. By (M1) and (M2), used at most `2m` times, for all `v` outside a set of density
`<= 2m ε_k` (once `F'_k ⊇ F_m^m`), two things hold. First, `v_1 = σ_k(g_1···g_n)v`. Second,
`d(y_k(v_j), g_j···g_n·y_k(v)) <= η_k` for every `j`, where `η_k → 0` depends only on `ε_k`, `m` and the
moduli of continuity of the elements of `F_m^m`. For instance
`d(y(σ(g)v'), g g'·y(v)) <= ε + ω_g(ε)` when `v' = σ(g')v` is good.

*Step C: word traces.* On `Y_k = V_k × W_k` let `g ∈ F_m` act by `σ_k(g) × τ_k(g)`, with partition
`(y_k^(−1)(p)) × W_k` for `p ∈ P_m`. A word `w ∈ 𝒲_m` is a tensor product: a `V_k`-word `w_V` (the
permutations `σ_k` and the partition projections) times the group word `S_w(τ_k)`. So

```text
tr_(Y_k)(w) = tr_(V_k)(w_V) · tr_(W_k)(S_w(τ_k)) .
```

If `h_w != 1`, then `|tr S_w(τ_k)| → 0` because `τ_k` is a sofic approximation, and `|tr w_V| <= 1`. The
limit is `0 = τ(w)`.

If `h_w = 1`, then `tr S_w(τ_k) → 1`, and `tr_(V_k)(w_V)` is the fraction of `v` whose path returns to `v`
and visits the prescribed atoms. By Step B, outside density `2mε_k` the path returns, and its marks lie
within `η_k` of the translates of `y_k(v)` that define `B_w`. So the fraction differs from `ν_k(B_w)` by
at most `2mε_k + ν_k(N_(η_k))`, where `N_η` is the closed `η`-neighbourhood of the finite union of
boundaries of the translated atoms occurring in `w`. For fixed `η`, `limsup_k ν_k(N_η) <= μ(N_η)` by Step A
and Portmanteau for closed sets. As `η → 0`, `μ(N_η) → μ(∂) = 0`. Also `ν_k(B_w) → μ(B_w)`, because
`μ(∂B_w) = 0`. So `tr_(Y_k)(w) → τ(w)`.

`𝒲_m` is finite, so models of level `m` and every error exist, and Lemma LC gives soficity. ∎

**Remarks.** (1) Part (ii) fails without uniqueness: a microstate may concentrate on another invariant
measure. (2) Part (i) holds for every invariant `μ`. (3) Step A is the only place uniqueness is used.
(4) Theorem P (`finite-equidistributed-orbits-give-sofic-action`) is the case where `σ_k` is an honest
action on a finite invariant set and `y_k` is inclusion. There equidistribution is a hypothesis, and here
it is automatic.

## 4. Consequence for the cocompact quotient

By Proposition 2.1 and Theorem 3.2, `SL_3(Z) ↷ SL_3(R)/Λ` is sofic iff for every finite `F ⊆ Γ` and every
`ε > 0` there are a finite set `V`, an `ε`-almost multiplicative `σ : F → Sym(V)`, and a map
`y : V → SL_3(R)/Λ` with `y(σ(s)v)` within `ε` of `s·y(v)` for all but `ε|V|` points. The measure does not
enter: any such family automatically equidistributes to Haar measure. So the nonsofic direction
of `sl3z-on-cocompact-lattice-quotient-is-not-sofic` is equivalent to a topological rigidity statement:
for some `(F, ε)`, no finite almost-action of `SL_3(Z)` maps almost equivariantly into `SL_3(R)/Λ`.

## 1. Setup and the ball lemma
- **Elements of C(Γ).**
  - σf σ^{-1} = φ(f) with φ(f)(m) = f(m−1). This checks directly on (x,m).
  - Every element of C(Γ) is fσ^k with f ∈ E, uniquely: E preserves levels and σ shifts them.
  - (fσ^k)(gσ^l) = (f·φ^k g)σ^{k+l}.
- **Commutators.** [σ,h_s] = φ(h_s)h_s^{-1} = δ_0(s^{-1}), and [σ,h_s^{-1}] = δ_0(s). So δ_0(Γ) ≤ [C(Γ),C(Γ)].
- **Ball lemma.** Appending h_s^{±1} to fσ^k multiplies f on the right by s^{±1} at levels m ≥ k. The value k at that moment is the σ-exponent of a proper prefix, so |k| ≤ r−1.
  - So f is trivial below −r, constant from r−1 on (the lemma states "from r", which is weaker), and f(m) is a product of at most r letters.
- **N1 (wording only).** "Constant from r" can be sharpened to "from r−1". Nothing uses the sharper form.

## 2. Theorem A (C(Γ) is LEF when Γ is)
- **θ.** θ: A → B is a coordinatewise shift, so a homomorphism. It is a bijection with inverse w ↦ (w_{−M+1},…,w_M,w_M). The inverse lands in A because its last two coordinates agree, and θ(v)_{−M} = e = w_{−M} for w ∈ B. So |A| = |B|.
- **t.** Take right transversals H = ⊔Ax_i = ⊔By_i; the number of cosets is equal. Put t(ax_i) = θ(a)y_i. Then t is well defined and bijective (each coset maps onto a coset), and t(a′·ax_i) = θ(a′a)y_i = θ(a′)t(ax_i).
- **Conjugation.** τλ(a)τ^{-1}(x,i) = (t(a·t^{-1}x), i) = (θ(a)x, i).
- **Claim 1.**
  - For k ≥ 0 and j < k ≤ r: φ^j f is constant from 2r+j ≤ M−1 on, so ιφ^jf ∈ A. θ(ιφ^jf) and ιφ^{j+1}f agree on −M < m ≤ M. At m = −M, f(−M−j−1) = e because −M−j−1 < −2r, and ψ(e) = e from ψ(e) = ψ(e)².
  - For k < 0: φ^{−j}f is trivial below −2r−j ≥ −3r+1 > −M, so ιφ^{−j}f ∈ B. θ^{-1} repeats the last coordinate, and f(M+j) = f(M+j+1) because M+j ≥ 2r.
  - Induction on |k|.
- **Claim 2.** For g = fσ^k and g′ = f′σ^{k′} in B_r:
  - Ψ(g)Ψ(g′) = λ(ιf·ιφ^kf′)τ^{k+k′} by Claim 1.
  - Coordinatewise f(m), (φ^kf′)(m) ∈ B_r(Γ) with product in B_{2r}(Γ), so ψ is multiplicative there.
  - gg′ = (f·φ^kf′)σ^{k+k′} ∈ B_{2r}, and Ψ(gg′) is the same element.
- **Claim 3.** Evaluate Ψ(g) on (x,i).
  - The second coordinate gives k ≡ k′ mod 5r, and |k−k′| ≤ 2r < 5r, so k = k′.
  - Then ιf = ιf′, and ψ is injective on B_{2r}(Γ).
  - Outside I both f and f′ are trivial below −r > −M and constant from r < M.
- **Conclusion.** For every r, Ψ restricted to B_r is an injective partial homomorphism into the finite group ⟨λ(H),τ⟩, so C(Γ) is LEF. Conversely δ_0(Γ) ≤ C(Γ).
- **Model tests.**
  - t = id (no intertwining) fails Claim 1 at k = 1, as the artifact says.
  - Γ Thompson's T (infinite, f.p., simple, not LEF) gives C(T) not LEF, consistent.
  - For non-abelian Γ, C(Γ) is not residually finite, but LEF. The models have τ of finite order, and σ^Nδ_0(b)σ^{-N} = δ_0(b) has length ≥ 2N, outside the balls used. There is no contradiction.

## 3. Theorem A′ (WP(C(Γ)) ≡_T WP(Γ))
- **Lower bound.** γ ↦ δ_0(γ) is an injective homomorphism, and δ_0(s) = [σ,h_s^{-1}] is an explicit word. That gives a many-one reduction.
- **Upper bound.** A word equals (∏_i φ^{j_i}(h_{s_i}^{ε_i}))σ^k, with j_i the σ-exponent before letter i. So f(m) = ∏_{i: j_i ≤ m} s_i^{ε_i}, in word order.
  - f changes only at the values j_i, and is trivial below min j_i and constant from max j_i on.
  - Triviality is k = 0 together with f(j_i) = e for each i: finitely many WP(Γ) queries.

## 4. Theorem B (LEF + WP iff subgroup of a simple Kazhdan LEF host with WP)
- **(⇐)** Translate the generators of Γ into words in the host; LEF passes to subgroups.
- **(⇒) The overgroup.** Δ = C(Γ) is infinite (σ has infinite order), generated by |S|+1 elements, LEF (Theorem A) with WP(Δ) ≡_T WP(Γ) (A′), and Γ ≅ δ_0(Γ) ≤ [Δ,Δ].
- **The host.** `lamplighter-bernoulli-crossed-products-simple-kazhdan-lef` has three PASS reviews (sk-verify-3, sk-lef-embedding-c, sk-verify-4). It gives G = EL_3(LC(2^Δ,F_2)⋊L), L = Z/2≀Δ, infinite, f.g., simple, Kazhdan and LEF, with [L,L] ↪ G through diag(u_ℓ,1,1).
- **Ω as an L-subshift.** F_x(ℓ) = (ℓ^{-1}x)(e).
  - F_x(δ) = x(δ), so F is injective.
  - (ℓ′·F_x)(ℓ) = F_x(ℓ′^{-1}ℓ) = (ℓ^{-1}ℓ′x)(e) = F_{ℓ′x}(ℓ), so F is equivariant.
  - So R ≅ LC(X,F_2)⋊L for the L-subshift X = F(Ω), and {x(e) = 1} is the letter cylinder.
- **The WP formula.** `crossed-product-el-word-problem-is-group-wp-plus-language` (PASS, sk-verify-4) applies to any f.g. acting group, here L with generators S_Δ ∪ {a}, and any subshift over a finite alphabet. It gives WP(G) ≡_T WP(L) ⊕ L(X) for the generators e_ij(u_s^{±1}), e_ij(e_b). These generate G, since u_δ e_1 u_δ^{-1} is the cylinder {x(δ) = 1}.
- **WP(L) ≤_T WP(Δ).** A word reduces to (c,δ): δ is a word on S_Δ, and c is a list of lamp positions, each a word. The word is trivial iff δ = e and, after identifying positions with WP(Δ), every multiplicity is even.
- **L(X) ≤_T WP(Δ).**
  - With ℓ = (c,δ) acting by x ↦ δx+c over F_2, ℓ^{-1}y = δ^{-1}(y+c), so (ℓ^{-1}x)(e) = x(δ)+c(δ).
  - A pattern p on W ⊆ L occurs iff the constraints x(δ_w) = p(w)+c_w(δ_w) are consistent. Ω = 2^Δ is the full shift, so consistent constraints are realized.
  - Each δ_w, each parity c_w(δ_w), and each equality δ_w = δ_{w′} is computed with WP(Δ).
- **Conclusion.** WP(G) ≤_T WP(Δ) ≡_T WP(Γ).
- **Consistency with `no-decidable-group-contains-every-fp-rf-group`.** That result excludes one decidable host for all f.p. RF groups; here there is one host per group.
- **Model tests.**
  - The note's G_X with non-recursive L(X) is LEF with unsolvable WP, and no decidable host contains it, as (⇐) requires.
  - G_X Fibonacci is LEF, not RF, with solvable WP, and is hosted.

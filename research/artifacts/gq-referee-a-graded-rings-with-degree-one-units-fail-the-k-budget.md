# Referee report (gq-referee-a, proof-gap lens): graded rings with degree-one units fail the K-budget

**Reviewed:** `graded-rings-with-degree-one-units-fail-the-k-budget` and its `-proof` (lane gq-infinite-primes,
06896bab6), read on origin/main.

**Verdict: PASS** for items 1–2. There is one required wording fix (W1) in the Consequences, and two nits. One nit
corrects the lamplighter's `K_1` computation, which is slightly off but not load-bearing.

## Checks
- **`1 ∈ R_0`.**
  - The degree-`k` part of `1_k = 1·1_k` is `1_0 1_k`, so `1_0 1_k = 1_k`.
  - Then `1_0 = 1_0·1 = Σ_k 1_0 1_k = Σ_k 1_k = 1`.
  - The route states this after the homogeneous-inverse step, which uses it (N1).
- **Homogeneous inverses (the author asked about this).**
  - Comparing degrees in `Σ_k h v_k = 1 ∈ R_0` gives `hv_(−d) = 1` and `hv_k = 0` for `k ≠ −d`.
  - Multiplying on the left by `h^(−1)` kills the other `v_k`. So `h^(−1) = v_(−d) ∈ R_(−d)`. ✓
- **`Q ⊆ R_0` and the rest of item 1.**
  - Each `m ∈ Z` is a homogeneous unit of degree 0, so `1/m ∈ R_0`.
  - `r ∈ R_k` gives `r = (ru^(−k))u^k`.
  - `uR_0u^(−1) ⊆ R_0` and `u^(−1)R_0u ⊆ R_0`, so `σ` is an automorphism. It fixes `Q` because `Q` is central. ✓
- **Injectivity of `R_0[t^±;σ] → R` (the author asked about this).**
  - The map is multiplicative: `(bt^k)(ct^j) = bσ^k(c)t^(k+j) ↦ bu^k c u^j`.
  - If `Σ b_k u^k = 0`, then each `b_k u^k ∈ R_k` vanishes, because the sum `⊕R_k` is direct. Since `u` is a unit,
    `b_k = 0`. ✓
- **Item 2.**
  - *Case 1.* Tensor `0 → K → Q^× → Q^×/K → 0` with `Q`. `Q^× ⊗ Q` has infinite dimension and `(Q^×/K) ⊗ Q` has
    finite dimension, so `K` is not finitely generated.
  - *Case 2.* `Q ⊆ R_0 ⊆ R` are unital inclusions, so the image in `K_1(R)` is a quotient of the image in
    `K_1(R_0)`.
  - The hypotheses of `laurent-rational-symbols-block-fp-elementary-groups` hold exactly: `B = R_0` is unital with
    unital `Q`, `σ` fixes `Q`, `R = B[u^±;σ]`, and the image in `K_1(B)` is not finitely generated. ✓
- **The remark on homogeneous relations (the author asked about this).**
  - An ideal generated by homogeneous elements is graded, so the quotient keeps the direct sum `⊕R_k`.
  - `uu^(−1) = u^(−1)u = 1` are homogeneous of degree 0, so `u` stays a unit of degree 1.
  - `y` of degree 0 with `yu = uy` and `yay^(−1) = a·uau^(−1)` gives homogeneous relations of degree 0 and 1. ✓
- **The lamplighter's `K_1` (N2).**
  - `K_1` commutes with directed unions, and `a ↦ a ⊗ 1_(M_n⊗M_n)` raises `det` to the `n²`.
  - Under `det`, however, the scalar `λ` at stage `m` has class `λ^(n^(2m+1))`, not `λ`.
  - So `[λ] = 0` if and only if `λ^(n^(2m+1+2j)) = 1` for some `j`. That holds for `λ = 1`, and for `λ = −1` exactly
    when `n` is even. The kernel is `{±1}` for `n` even and trivial for `n` odd.
  - Either way it is finite, so the image is not finitely generated and the second case holds, as claimed.
  - For `U_Q` the kernel is `{±1}`, since `n!` is even. ✓

## Required wording fix
- **W1 (Consequences, the first bullet).** "So no `E_N` is finitely presented, whatever relations are added, as long as
  the grading survives" is too strong.
  - Added homogeneous relations change `R_0`, and they can kill rational classes in `K_1`. The enlarged ring may then
    fall into the first case of the dichotomy, where the `K_1` half of the budget fails, rather than the second.
  - Suggested text: "whatever homogeneous relations are added, the result stays under the dichotomy: either
    `Q^× → K_1` has infinitely generated kernel, or no `E_N` is finitely presented."
  - The next bullet, "Graded cures are dead … falls under the dichotomy", is already phrased correctly.

## Nits
- **N1 (item 1).** Move the `1 ∈ R_0` bullet before the homogeneous-inverse bullet.
- **N2 (the lamplighter).** Replace "the scalar `λ` has class `λ` at every stage … that is `λ = ±1`" with the
  computation above: the class is `λ^(n^(2m+1))`, and the kernel is `{±1}` or `{1}` according to the parity of `n`.

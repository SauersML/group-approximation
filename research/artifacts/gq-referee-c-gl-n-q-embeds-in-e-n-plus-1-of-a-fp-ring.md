Here `R_T = Z<S,T,N,A | TS = 1, NS = S(N+1), N(1-ST) = 0, A(N+1) = 1>`, with `E = 1 - ST`. Only the one-sided
resolvent `A(N+1) = 1` is available, and it is the only one used.

## 1. The corner embedding Q → E R_T E

- **E is idempotent.** `E^2 = 1 - 2ST + S(TS)T = E`. ✓
- **Shift and vacuum.**
  - `(N+c)S = S(N+c+1)`, so `(N+1)S^(m-1) = S^(m-1)(N+m)`.
  - `NE = 0`, so `(N+m)E = mE`. ✓
- **Inverses of integers.** Put `r_m = E T^(m-1) A S^(m-1) E`. Then
  `r_m·m = E T^(m-1) A S^(m-1)(N+m)E = E T^(m-1) A(N+1) S^(m-1) E = E T^(m-1) S^(m-1) E = E`.
  Since `m` is central, `mE` is invertible in the corner `C = ERE` (unit `E`), with inverse `r_m`. So `Z -> C`
  extends to `Q -> C`. ✓
- **E ≠ 0, from the model on `Q^(N)`.** Set `S f_k = f_(k+1)`, `T f_k = f_(k-1)`, `T f_0 = 0`, `N f_k = k f_k`,
  `A f_k = f_k/(k+1)`. All four relations hold: `ST` fixes every `f_k` with `k >= 1` and kills `f_0`, so `E` is
  the projection onto `f_0`, and `N f_0 = 0`. So `ρ(E) ≠ 0`, and the map from `Q` is injective. ✓
- **Consistency.** On `f_0` the chain `S^(m-1)`, `A`, `T^(m-1)` gives `f_0/m`, so `ρ(r_m) = (1/m)ρ(E)`. ✓

## 2. The Limits remark

- The two-sided ideal generated by `ρ(E)` is the finitary matrix ring `J = M_∞(Q)`:
  - `S^a ρ(qE) T^b` is `q` times the matrix unit `f_b ↦ f_a`;
  - each `x E y` has finitely many nonzero entries, because the operators move basis vectors by bounded shifts.
- `J` is simple and has zero left annihilator. If `MJ = 0`, then `M f_a = M e_(a0) f_0 = 0` for every `a`.
- Hence every nonzero ideal of `ρ(R_T)` contains `J`, and so contains `ρ(E)`.
- `J` is proper, since `1` is not finitary. So `R_T` is not simple, and every simple quotient of the model kills
  the copy of `Q`. ✓

## 3. GL_n(Q) ≤ E_(n+1)(R_T)

- **The embedding Ψ.** `Ψ(g) = φ(g) + (1-E)I_m`. The entries of `φ(g)` lie in `ERE`, so they are killed by `1-E`
  on both sides. Hence `Ψ(g)Ψ(h) = φ(gh) + (1-E)I_m = Ψ(gh)` and `Ψ(1) = I_m`. `Ψ` is injective because `φ` is. ✓
- **Elementary to elementary.** `Ψ(e_ij(q)) = I + φ(q)e_ij = e_ij(φ(q))`. Since `SL_m(Q) = E_m(Q)`, this gives
  `Ψ(SL_m(Q)) ≤ E_m(R_T)`. Composing with `g ↦ diag(g, det g^(-1))` for `m = n+1` embeds `GL_n(Q)`. ✓
- **Finite generation.** For `m >= 3`, the sets `{r : e_ij(r) ∈ H}` are additive subgroups containing `±1`. They
  are closed under products `ab` through `[e_ij(a), e_jk(b)] = e_ik(ab)`, using a free third index. So they
  contain every monomial in `S, T, N, A`, and hence all of `R_T`. ✓
- **The model.** `ρΨ(g) = g·ρ(E) + (1-ρ(E))I` is injective, and `ρ(E_m(R_T)) = E_m(ρ(R_T))`. ✓
- **Word problem in the model.** Every element of `ρ(R_T)` rewrites as a finite sum `Σ S^a d T^b` with `d`
  diagonal:
  - `TS = 1` and `ST = 1 - E_0`;
  - `dS = S d(·+1)` and `Td = d(·+1)T`;
  - `Sd = d̂S` and `dT = Td̃`, with an arbitrary value at the index that is killed.
- The diagonal entries lie in the ring of sequences that are eventually rational in `k`, with finitely many
  exceptional values. That ring is generated by constants, `k`, `1/(k+1)` and `δ_(k0)`, and is closed under
  shifts.
- The `(k+c, k)` entry of `Σ S^a d_ab T^b` is `Σ_(a-b=c) d_ab(k-b)[k >= b]`, which is again eventually rational.
  Deciding whether it is zero means checking the rational part symbolically plus the finitely many exceptional
  `k`. All of this is computable from the word. So `E_(n+1)(ρ(R_T))` has solvable word problem. ✓

## 4. Calibration and consistency

- **O1.** `E_(n+1)(R_T)` contains `(Q,+)`, so it is not residually finite. That is consistent.
- **Why Q embeds in a finitely presented ring here.** The integral-form obstruction
  (`integral-form-algebras-have-no-fg-subring-containing-q`) does not apply: `A` is a resolvent that no integral
  combinatorial form carries.
- **The simple version.** `R_L` (`gq-referee-c-leavitt-resolvent-ring-is-fp-simple-of-char-zero.md`) is the
  simple version of this ring. It glues the vacuum to a Leavitt isometry and removes the ideal `J`. This agrees
  with the Limits remark: here the vacuum projection `E` is what generates `J`.
- **Status update for the "Relevance" paragraph.** `St_(n+1)(R_T)` is finitely presented for `n+1 >= 5`. That
  follows from my direct proof (5d6390c47) and the quotient step. So the remaining question for that paragraph is
  `K_2` control alone, as the node says.

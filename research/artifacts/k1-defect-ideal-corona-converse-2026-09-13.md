# Properly infinite projections with nonzero fibres over C(X), and commutative detectors of J

Lane `ex2-k1-defect-ideal`, 2026-09-13, part 3. The proofs are complete and unreviewed.

**Setting.**
- X is compact metrizable, `B = C(X) ⊗ K`, and `M = M(B)`.
- For a projection `P ∈ M`, put `E_P = P H_X`, a countably generated Hilbert C(X)-module, and
  `D_P = PBP ≅ K(E_P)`.
- "Nonzero fibres" means `(E_P)_x ≠ 0` for every x. Equivalently, `D_P` is full in B.

## 1. Five forms of fullness

**Proposition 1.** Let P be properly infinite with nonzero fibres. The following are equivalent:
- (a) P is full in M;
- (b) `1 ≼ P`;
- (c) `P ~ 1`, that is, `E_P ≅ H_X`;
- (d) `D_P` is stable;
- (e) (AO) for all `ζ_1, …, ζ_m ∈ E_P` and `ε > 0` there is a unit section `η ∈ E_P` with
  `sup_x |⟨ζ_i, η⟩(x)| < ε` for every i.

*Proof.*
- (a)⟹(b): fullness gives `1 ≼ P ⊗ 1_n` for some n, and proper infiniteness gives `P ⊗ 1_n ≼ P`.
- (b)⟹(c): `H_X` is a complemented submodule of `E_P`, so `E_P ≅ H_X ⊕ E'`, and this is `≅ H_X` by
  Kasparov stabilization.
- (c)⟹(d): `D_P ≅ B`.
- (d)⟹(c):
  - Stability gives matrix units in `M(D_P)` with `Σ e_ii = 1` strictly, so `E_P ≅ ℓ²(F)` with
    `F = e_11 E_P`.
  - F has nonzero fibres. By compactness some `F^N` has a nowhere-vanishing, hence unit, section.
  - So `H_X = ℓ²(C(X)) ↪ ℓ²(F^N) ≅ E_P` complementably, and Kasparov applies.
- (c)⟹(e): use basis vectors of `H_X` far out.
- (e)⟹(b):
  - Fix a dense sequence `(ζ_j)` in `E_P`. Inductively choose unit sections `η_k`, orthogonal to
    `η_1, …, η_{k-1}`, with `sup_x |⟨ζ_j, η_k⟩| ≤ 2^{-k}` for `j ≤ k`. To do this, apply (e) to
    `{ζ_j}_{j≤k} ∪ {η_i}_{i<k}` with small ε, then Gram--Schmidt and normalize; the correction is O(kε).
  - Then `Σ_k |⟨ζ_j, η_k⟩|²` converges uniformly for each j, and by Bessel and density for every ζ.
  - So `V: H_X -> E_P`, `δ_k -> η_k`, has the adjoint `V^*ζ = (⟨η_k, ζ⟩)_k`. V is an isometry with
    `VV^* ≤ P`. Square.

## 2. Property (S) is automatic

**Lemma 2.** If P is properly infinite with nonzero fibres, then `D_P` has no nonzero unital quotient
and no nonzero bounded 2-quasitrace. So `D_P` has property (S) (Ortega--Perera--Rørdam,
arXiv:0903.2917v4, Proposition 4.5, read in the PDF).

*Proof.*
- **Quotients.** Ideals of `D_P` correspond to open sets `U ⊆ X`, by Brown's theorem. The quotient over
  `F = X \ U` is `D_{P|F}`, and `P|F` is still properly infinite with nonzero fibres.
  - A unital `D_{P|F}` would make `P|F` a compact projection, that is, a vector bundle of finite rank r.
  - `P ⊕ P ≼ P` then forces `2r ≤ r`, so r = 0, contradicting nonzero fibres.
- **Quasitraces.** Isometries `V_1, V_2 ∈ PMP` with orthogonal ranges give isometries
  `W_i = V_2^i V_1` with pairwise orthogonal ranges.
  - For `x ∈ D_P^+`, `τ(W_i x W_i^*) = τ(x^{1/2} W_i^*W_i x^{1/2}) = τ(x)`, and these elements are
    pairwise orthogonal.
  - So `n τ(x) = τ(Σ_{i<n} W_i x W_i^*) ≤ ‖τ‖ ‖x‖` for every n, and τ = 0. Square.

## 3. A sufficient condition

**Theorem 3.** If `Cu(C(X))` has the weak ω-comparison property (OPR Definition 2.18), then every
properly infinite projection in `M(C(X) ⊗ K)` with nonzero fibres is full.

*Proof.* OPR Proposition 4.8, read in the PDF: "Let A be a separable C\*-algebra such that Cu(A)
satisfies the weak ω-comparison property and such that A ⊗ K contains a full projection. Let B be a
full hereditary sub-C\*-algebra of A ⊗ K. Then the following conditions are equivalent: (i) B is stable
(ii) B has no non-zero unital quotient and no non-zero bounded 2-quasitrace. (iii) B has property (S)."
- Take `A = C(X)`. `A ⊗ K` contains the full projection `1 ⊗ e_11`.
- Take B to be `D_P`, which is full because the fibres are nonzero.
- Lemma 2 gives (ii), so `D_P` is stable, and Proposition 1 gives fullness. Square.

**Where a counterexample must live.**
- OPR Proposition 2.21: a complete ordered semigroup with weak ω-comparison and a full compact element
  has the Corona Factorization Property. `Cu(C(X))` contains the full compact element `[1]`.
- By OPR's main theorem (abstract and section 5, not re-read), a σ-unital algebra has the CFP iff its
  Cuntz semigroup does.
- OPR p. 1 records, after Kucerovsky--Ng and Rørdam, that `C(∏_n S²)` does not have the CFP.
- So `Cu(C(∏ S²))` fails weak ω-comparison, and `X = ∏ S²` is an admissible base for a counterexample.
  Finite-dimensional X is excluded, also by Robert and Dixmier--Douady.

## 4. Commutative detectors of the defect ideal

**Proposition 4.** Let `π: A_T -> L(E)` be a unital representation on a countably generated Hilbert
C(X)-module. Assume:
- `π(e) ∈ K(E)`, where `e = ι_1(p_3)` as in Part 1;
- E is the closed span of `π(J)E`;
- every fibre of E is nonzero.

Then `P_E` is properly infinite with nonzero fibres, and `π(J) ⊆ K(E)`. If `P_E` is full, every unitary of
`J~` maps to a null unitary of `K(E)~`.

*Proof.*
- `π(ι_1(s_1))` and `π(ι_1(s_2))` are isometries with orthogonal ranges in `L(E) ≅ P_E M P_E`.
- `π(J)` is generated by the compact `π(e)`, so it lies in `K(E)`.
- If `P_E` is full, `K(E) ≅ B` is stable, so `K(E)~` is K1-injective. Moreover
  `[π(u)] = π_*[u] ∈ π_*K_1(J) = 0`. Square.

So a non-null unitary of `J~` can be detected over a commutative base with compact defect only through a
counterexample to `properly-infinite-nonzero-fibre-projection-is-full`, over a base failing weak
ω-comparison. By Part 1, Theorem 5(d), such a detection would refute LXI.

## 5. What an obstruction to (e) must look like

- **Selection stalls.** Proper infiniteness gives orthonormal sections `η_j = V_2^j V_1 ξ` with
  `Σ_j |⟨ζ, η_j⟩(x)|² ≤ ‖ζ(x)‖²` pointwise. So at each x some `η_j` is almost orthogonal to ζ, but
  patching the indices by a partition of unity loses a factor √(multiplicity). That factor is unbounded
  over infinite-dimensional X.
- **Partial positive lemma.**
  - Suppose an isometry `W ∈ L(E)` and a unit section ξ satisfy `sup_x ‖W^*ξ(x)‖ < 1`.
  - Then `T = (1 - θ_ξ) W` has `T^*T = 1 - θ_{W^*ξ}` invertible, and polar decomposition embeds E
    complementably into `ξ^⊥`.
  - In particular `ξ^⊥` has unit sections.
- **Chern classes cannot protect a counterexample.**
  - Suppose `E = ⊕_k M_k` with finite-rank pieces and `N_n = ⊕_{k≤n} M_k` trivial of rank r.
  - Proper infiniteness puts `θ^J` inside some `N_m`, by perturbing an approximate frame, for every J.
  - Once `J > r`, this forces `c_{top}(W) = 0` for the window `W = ⊕_{n<k≤m} M_k`, since
    `c(N_m) = c(W)`.
  - Tails without sections would need obstructions invisible to Chern classes, such as torsion
    secondary obstructions.

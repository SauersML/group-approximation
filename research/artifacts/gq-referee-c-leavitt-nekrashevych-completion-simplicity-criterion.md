## 1. The embedding theorem (input)

- **Direction (⇒).** `ψ(b) = 0` forces `b = Σ s_i ψ(b)_ij t_j = 0`. ✓
- **Direction (⇐).** Take `C = lim(M_(d^n)(B), Ψ_n)`, where `Ψ_n` appends a letter at the end and applies `ψ`.
  Regrouping by the first letter commutes with `Ψ` (checked blockwise). So there is an isomorphism
  `Φ : C ≅ M_d(C)` with `Φ|_B = ψ`.
- **Module.** On `V = ⊕_N C`, the swindle gives `θ : V ≅ V^(d)_Φ`, using `C ≅ (C^(d)_Φ)^d`.
- **Representation.** Put `s_j = θ^(-1) ι_j` and `t_i = π_i θ`, and let `B` act by left multiplication. Then the
  Leavitt relations hold, and covariance holds because `θ(bv) = ψ(b) θ(v)`.
- **Injectivity.** `B -> C` is injective since `ψ` is, and `L_b(1,0,…) = (b,0,…)`. So `B -> O_ψ` is injective. ✓

## 2. The criterion

**Part 1 (normal form).**
- `b s_j = Σ_i s_i ψ(b)_ij` and `t_i b = Σ_j ψ(b)_ij t_j`.
- Padding raises both word lengths by one.
- `t_μ' y s_ν' = Y_μ'ν'` for words of equal length. The coefficients lie in `B ⊆ O_ψ` by §1. ✓

**Part 2 (graded ideals).**
- (a) A graded `J` is generated by `J_0`, via `y = Σ s_α t_α y`. `J_0` is spanned by `s_μ c t_ν` with
  `c ∈ J ∩ B`.
- (b) `J ∩ B` is ψ-saturated, using `t_i b s_j = ψ(b)_ij`.
- (c) A ψ-saturated `I` gives `O_ψ/⟨I⟩ ≅ O_ψ̄`. The map `ψ̄` is injective by saturation, so §1 gives
  `⟨I⟩ ∩ B = I`. ✓

**Part 3 (simplicity), main direction.**
- Take `x ∈ J \ {0}` of minimal support and normalize so that `min supp = 0`:
  - apply `t_α` when `m > 0`, choosing `t_α x_m ≠ 0`;
  - apply `s_1^(-m)` when `m < 0`, which is injective on components.
- Put `J_S = {y ∈ J : supp y ⊆ S}`.
  - *Injectivity.* `y ↦ y_0` is injective on `J_S`, by minimality.
  - *Ideal of the core.* `I_0 = {y_0}` is an ideal of `C`, closed under `t_i · s_j` and `s_i · t_j`.
  - *Saturation.* `I_0 ∩ B` is ψ-saturated and nonzero, taking an entry `t_μ y_0 s_ν`.
- By ψ-minimality some `y ∈ J_S` has `y_0 = 1`.
- For `c ∈ C`, `cy − yc ∈ J_S` has zero degree-0 part, so `cy = yc`. Componentwise, each `y_k` centralizes `C`.
- Aperiodicity gives `y = 1 ∈ J`. ✓

**Part 3, converse.** Immediate from part 2. ✓

**Part 4 (Leavitt calibration).**
- Commuting with the matrix units `s_a t_b` at level `N` forces the shape `Σ w_ω s_(νω) t_ν`.
- At level `N+1`, the coefficient at `(νωi, νi)` must have the shape `(b'ω', b')`. That needs `ωi = iω'`, which
  fails for `i ≠ ω_1` when `d >= 2`. ✓

## 3. R_k meets the hypotheses (§3 of its proof)

**ψ-minimality.**
- `ψ = diag(σ_x)`, so saturated ideals are `σ_x`-stable.
- For `0 ≠ b = F/s ∈ I`, apply `σ_v ∘ σ`. By the product-set lemma, choose `σ` with `F(σ*τ_0) ≠ 0`. The result is
  `F(τ)/s(τ) ∈ F_k \ {0} ⊆ B^x`.
- The product-set lemma holds: a nonzero polynomial over the domain `Q[t]` does not vanish on a product of
  infinite sets, and `Z`, `{t_1^j}`, `Z` and `Z_(>=0)` are infinite and reachable. ✓

**Aperiodicity.**
- The same two-level argument, with `B`-coefficients, gives `ψ_u(w_ω) = 0` unless `u` is a prefix of `ω^∞`.
- Choose `u = xvy` versus `xvy'`, with `y ≠ y'`. After `v` every register is a constant, so `σ_y` and `σ_y'` fix
  it. So `w_ω(ψ_x*τ_0) = 0` for every `x`, and the lemma gives `w_ω = 0`.
- Negative degrees use the anti-automorphism `s ↔ t`, which is valid because `ψ` is diagonal and `B` is
  commutative. ✓

So `R_k ≅ O_ψ` is simple by the criterion. This agrees with the existing PASSes of `gq-referee-a` and
`gq-referee-b`.

## 4. Calibration

- **ψ-minimality is needed.** For `B = K × K` and `ψ(b) = b·I_d`, the ideals `K × 0` and `0 × K` are ψ-saturated.
  Correspondingly `O_ψ ≅ L_d × L_d` is not simple, as the converse in part 3 predicts.
- **Aperiodicity is needed.** For `d = 1` (`L_1 = K[s, s^(-1)]`) the degree-1 element `s` centralizes the core,
  and `K[s, s^(-1)]` is not simple. Part 4 uses `d >= 2` exactly there.

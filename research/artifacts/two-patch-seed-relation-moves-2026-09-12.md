# The two-patch ternary seed is never injective

Lane `w5-two-patch`, 2026-09-12.

**Target.** The seed of `two-patch-ternary-rules-reduce-to-linear-strictness`, named in Section 3 of
`distinct-symbol-patch-collision-2026-09-12.md` as the smallest open instance:

`mu_2(y_1, y_a, y_b) = y_1 - y_a + y_b + [y = (0,1,2)] + [y = (1,2,0)]` over `F_3`.

**Result.**
- **Theorem 2.** Over every group and every placement of three distinct memory elements, `tau_(mu_2)`
  is not injective. When the memory group is nonamenable it is not even pre-injective, with a collision
  supported on one or two sites.
- **Why the seed was open.** It is not rigid: `{0, 1}` is a blind pair of all three coordinates. So
  `small-memory-balance-census-2026-09-12.md` Proposition 5.1 already excludes it on Sidon placements.
  What was missing is the relation cases, and Sections 1 and 2 settle them for this rule.

## 0. Setup

- **Group and placement.** `G` a group, `m_1, m_2, m_3` distinct. Right-translating the output by
  `m_1^-1` preserves injectivity, so assume the placement is `(1, a, b)` with `1, a, b` distinct.
  Put `H = <a, b>`.
- **Automaton.** `tau(x)(g) = mu_2(x(g), x(ga), x(gb))`.
- **The rule.** `lambda = y_1 - y_a + y_b` plus one unit at each of the patches `p = (0,1,2)` and
  `q = (1,2,0)`. Here `lambda(p) = 1` and `lambda(q) = 2`, so `mu_2(p) = 2` and `mu_2(q) = 0`.
  The value counts are `10, 8, 9` for `0, 1, 2`, so `mu_2` is unbalanced.
- **Windows.** The window at `g` is `gM = {g, ga, gb}`. A change at the site `s` affects exactly the
  windows at `s`, `s a^-1` and `s b^-1`, where `s` sits at addresses `1`, `a` and `b`.
- **Useful values.**

| pattern | `lambda` | patch | `mu_2` |
|---|---|---|---|
| `(0,1,2)` | 1 | yes | 2 |
| `(1,1,2)` | 2 | no | 2 |
| `(0,0,2)` | 2 | no | 2 |
| `(1,2,0)` | 2 | yes | 0 |
| `(1,2,1)` | 0 | no | 0 |

So `{0, 1}` is blind at coordinate `1` in context `(1,2)`, at coordinate `a` in context `(0,2)`, and at
coordinate `b` in context `(1,2)`.

## 1. The single flip

**Lemma 1.** Suppose none of the relations `a^2 = 1`, `b^2 = 1`, `ab = 1`, `b = a^2`, `a = b^2` holds.
Then `tau` is not pre-injective.

*Proof.* Fix `h`. Let `x` take these values, and anything elsewhere:

| site | `h` | `ha` | `hb` | `ha^-1` | `ha^-1 b` | `hb^-1` | `hb^-1 a` |
|---|---|---|---|---|---|---|---|
| `x` | 0 | 1 | 2 | 0 | 2 | 1 | 2 |

Put `x' = x + delta_h`. Only the windows at `h`, `ha^-1` and `hb^-1` read `h`.

| window | sites | `x` | `x'` | `mu_2` before, after |
|---|---|---|---|---|
| `h` | `h, ha, hb` | `(0,1,2)` | `(1,1,2)` | 2, 2 |
| `ha^-1` | `ha^-1, h, ha^-1 b` | `(0,0,2)` | `(0,1,2)` | 2, 2 |
| `hb^-1` | `hb^-1, hb^-1 a, h` | `(1,2,0)` | `(1,2,1)` | 0, 0 |

So `tau(x) = tau(x')` with `x != x'`, provided the table assigns each site one value.

**Coincidences.** With `h = 1` the seven sites are `1` and the six quotients `m^-1 m'` (`m != m'`), so
they are distinct exactly when `M` is Sidon. Among the 21 pairs, 12 coincide only if two of `1, a, b`
coincide. The other nine:

| pair | relation | values | |
|---|---|---|---|
| `a`, `a^-1` | `a^2 = 1` | 1, 0 | conflict |
| `a`, `a^-1 b` | `b = a^2` | 1, 2 | conflict |
| `a`, `b^-1` | `ab = 1` | 1, 1 | agree |
| `b`, `a^-1` | `ab = 1` | 2, 0 | conflict |
| `b`, `b^-1` | `b^2 = 1` | 2, 1 | conflict |
| `b`, `b^-1 a` | `a = b^2` | 2, 2 | agree |
| `a^-1`, `b^-1 a` | `b = a^2` | 0, 2 | conflict |
| `a^-1 b`, `b^-1` | `a = b^2` | 2, 1 | conflict |
| `a^-1 b`, `b^-1 a` | `(a^-1 b)^2 = 1` | 2, 2 | agree |

Each relation that agrees at one pair conflicts at another, except `(a^-1 b)^2 = 1`. So the table is
consistent unless one of the five listed relations holds. QED

**Note.** `(a^-1 b)^2 = 1` is covered by Lemma 1, and it holds in nonamenable groups such as `Z * Z/2`.

## 2. The involution moves

### Move A: `a^2 = 1`

**Lemma 2.** Suppose `a^2 = 1`, and `H` is not abelian, not cyclic and not generated by two involutions.
Then `tau` is not pre-injective.

*Proof.* Fix `h`. Put `x(h) = x(ha) = 0`, `x(hb^-1) = x(hab^-1) = 1` and `x(hb^-1 a) = x(hab^-1 a) = 2`.
Leave `x(hb)` and `x(hab)` free, and set `x' = x + delta_h + delta_(ha)`.
- **Touched windows.** The windows reading `h` are at `h`, `ha^-1 = ha` and `hb^-1`. Those reading `ha`
  are at `ha`, `h` and `hab^-1`. Since `b` is not in `{1, a}`, the windows at `hb^-1` and `hab^-1` each
  read one changed site.

| window | sites | `x` | `x'` | `mu_2` before, after |
|---|---|---|---|---|
| `h` | `h, ha, hb` | `(0,0,s)` | `(1,1,s)` | `s`, `s` |
| `ha` | `ha, h, hab` | `(0,0,t)` | `(1,1,t)` | `t`, `t` |
| `hb^-1` | `hb^-1, hb^-1 a, h` | `(1,2,0)` | `(1,2,1)` | 0, 0 |
| `hab^-1` | `hab^-1, hab^-1 a, ha` | `(1,2,0)` | `(1,2,1)` | 0, 0 |

Neither `(0,0,s)` nor `(1,1,s)` is a patch, and `lambda(0,0,s) = lambda(1,1,s) = s`.

**Coincidences** (`h = 1`). The sites are `1, a, b, ab, b^-1, b^-1 a, ab^-1, ab^-1 a`. Since `a^2 = 1`
and `b` is not in `{1, a}`, both `1` and `a` differ from the other six. The remaining pairs either force
`a = 1` or `b = 1`, or:
- **Fixed-value conflicts.** `b^-1 = ab^-1 a` (1 against 2) and `b^-1 a = ab^-1` (2 against 1). Each
  says `ab = ba`.
- **Forced values at `hb`.** 1 by `b^2 = 1`; 2 by `b = b^-1 a` and 1 by `b = ab^-1`, both equivalent to
  `b^2 = a`; 2 by `(ba)^2 = 1`.
- **Forced values at `hab`.** 1 by `a = b^-2`; 2 by `bab = a`; 1 by `b^2 = 1`; 2 by `b^2 = a`.

**Where it can fail.** A conflict needs `ab = ba`, or `b^2 = a`, or two forcings with different values.
The possible pairs are `{b^2 = 1, (ba)^2 = 1}`, `{bab = a, b^2 = 1}` and `{a = b^-2, b^2 = a}`. Each one,
with `a^2 = 1`, makes `H` abelian, cyclic, or generated by two involutions. QED

### Move B: `b^2 = 1`

**Lemma 3.** Suppose `b^2 = 1`, and `H` is not abelian and not virtually cyclic. Then `tau` is not
pre-injective.

*Proof.* Fix `h`. Put `x(h) = 0`, `x(hb) = 1`, `x(ha^-1) = 0`, `x(ha^-1 b) = 2`, `x(hba^-1) = 0` and
`x(hba^-1 b) = 2`. Choose `x(ha)` and `x(hba)` in `{0, 1}`, and set `x' = x + delta_h - delta_(hb)`.
- **Touched windows.** The windows reading `h` are at `h`, `ha^-1` and `hb^-1 = hb`. Those reading `hb`
  are at `hb`, `hba^-1` and `h`.

| window | sites | `x` | `x'` | `mu_2` before, after |
|---|---|---|---|---|
| `h` | `h, ha, hb` | `(0,s,1)` | `(1,s,0)` | `1-s`, `1-s` |
| `hb` | `hb, hba, h` | `(1,t,0)` | `(0,t,1)` | `1-t`, `1-t` |
| `ha^-1` | `ha^-1, h, ha^-1 b` | `(0,0,2)` | `(0,1,2)` | 2, 2 |
| `hba^-1` | `hba^-1, hb, hba^-1 b` | `(0,1,2)` | `(0,0,2)` | 2, 2 |

`(1,s,0)` and `(1,t,0)` are patches only at `s, t = 2`, which is excluded.

**Coincidences** (`h = 1`). The sites are `1, b, a, ba, a^-1, a^-1 b, ba^-1, ba^-1 b`. Here `1` and `b`
differ from the other six. The remaining pairs force `a = 1` or `b = 1`, or:
- **Fixed-value conflicts.** `a^-1 = ba^-1 b` and `a^-1 b = ba^-1`, each equivalent to `ab = ba`.
- **Forced values at `ha`.** 0 by `a^2 = 1`; 2 (excluded) by `b = a^2`; 0 by `b = a^2`; 2 (excluded)
  by `bab = a^-1`.
- **Forced values at `hba`.** 0 by `b = a^-2`; 2 (excluded) by `aba = b`; 0 by `a^2 = 1`; 2 (excluded)
  by `b = a^2`.

**Where it can fail.** A conflict needs one of `ab = ba`, `b = a^2`, `bab = a^-1` or `aba = b`. With
`b^2 = 1` these make `H` abelian, cyclic, virtually cyclic (`b` inverts `a`), or generated by the two
involutions `b` and `ab`. QED

## 3. The theorem

**Theorem 2.** For every group `G` and distinct `1, a, b` in `G`, `tau_(mu_2)` is not injective. If
`H = <a, b>` is nonamenable, it is not pre-injective.

*Proof.*
- **`H` amenable.** Suppose `tau` is injective over `G`. Configurations on `G` split into independent
  configurations on the left cosets of `H`, because `M` lies in `H`. So the automaton over `H` is
  injective, hence pre-injective, hence surjective by `amenable-groups-satisfy-the-garden-of-eden-theorem`.
  It is then bijective, so it preserves the uniform product measure by
  `bijective-ca-preserve-uniform-bernoulli-measure`. The output at `1` is `mu_2` evaluated on three
  independent uniform symbols, so `mu_2` would be balanced. That contradicts the counts `10, 8, 9`.
- **`H` nonamenable.** Then `a^2 = b^2 = 1` fails (`H` would be dihedral). The relations `ab = 1`,
  `b = a^2` and `a = b^2` fail too, since each makes `H` cyclic.
  - If neither `a^2 = 1` nor `b^2 = 1`, apply Lemma 1.
  - If `a^2 = 1`, apply Lemma 2. Its exceptions are amenable.
  - If `b^2 = 1`, apply Lemma 3. Its exceptions are amenable.

QED

**Consequence for the two-patch claim.** The seed gives no counterexample over any group, unit case
included. In particular it needs no linear strict automaton.

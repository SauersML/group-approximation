# Exact MF residual of the literal group `E`

Date: 2026-08-19.

Write

```text
B = iota(mathcal B),
d = t c t^-1,
u = [d, v_1],
D = <<u>>^E.
```

Then

```text
Res_MF(E) = D = N_conj,
E / D  ~=  Sigma *_B (B x C_2),
```

and `E/D` is MF.  Consequently the collapse defect in the sign-free quotient
computes its MF residual exactly.

This is a paper-level computation.  The inclusion `u in Res_MF(E)` and all of
the generic radical/collapse reduction machinery are already formalized; the
new ingredient here is the explicit quotient identification plus a published
MF-amalgam theorem.

## 1. The compression defect is normally generated by `u`

The defining relations give

```text
[d, t B t^-1] = 1.
```

For the affine base,

```text
B = Z^3 semidirect L,
t B t^-1 = (2 Z^3) semidirect L,
L = <x,y,z>.
```

Hence `d` commutes with the whole linear part `L` and with every even
translation.  Therefore `[d,b]` depends only on the translation part of `b`
modulo `2`.

The reduction of `L` modulo `2` is transitive on the seven nonzero vectors of
`(F_2)^3`; this is the same explicit seven-word calculation used in the
literal block geometry.  If the parity class of a translation `v` is zero,
then `[d,v]=1`.  Otherwise choose `ell in L` carrying `e_1` to the parity
class of `v`.  Then

```text
v = v_even * ell v_1 ell^-1
```

for an even translation `v_even`.  Since `v_even` and `ell` commute with `d`,

```text
[d,v] = ell [d,v_1] ell^-1 = ell u ell^-1.
```

Thus every generator `[d,b]` of the one-sided compression defect is either
trivial or a conjugate of `u`.  Conversely `u` is one of those generators.
Hence

```text
N_conj = << [d,b] : b in B >>^E = <<u>>^E = D.
```

## 2. Identify the quotient by `D`

In `E/D`, the image of `d` commutes with `B` and is an involution.  Use `d`
as the lamp generator rather than `c`; then `c = t^-1 d t`.  The old relation
`[c,B]=1`, conjugated by `t`, becomes

```text
[d, t B t^-1] = 1,
```

which is redundant because `t B t^-1 <= B` and `[d,B]=1` has now been
imposed.  The central-mark relations are also redundant: `w=u^2` is already
trivial in the quotient.

What remains is precisely

```text
<E/D> = < B, t, d |
          t b t^-1 = alpha(b),
          d^2 = 1,
          [d,B] = 1 >.
```

Let

```text
Sigma = < B,t | t b t^-1 = alpha(b) >.
```

The displayed presentation is the amalgamated free product

```text
E/D ~= Sigma *_B (B x C_2).
```

The conjugate description using `c` instead of `d` is
`Sigma *_{t^-1 B t} ((t^-1 B t) x C_2)`; the two are the same statement with
conjugate amalgamating subgroup.

## 3. The quotient is MF

The manuscript's matrix model realizes `Sigma` as the subgroup of
`GL_4(Q)` generated by the affine base and the dilation matrix.  It is
finitely generated linear in characteristic zero, hence residually finite by
Mal'cev.  Therefore

```text
G_0 = Sigma x C_2
```

is residually finite and in particular MF.

Shulman, arXiv:2603.13564v2, Theorem 10, is a C-star-algebra theorem,
not a blanket permanence theorem for weak group-MF.  The group-level input we
use is the established Cairn claim `symmetric-double-weak-mf`: for a
**residually finite** group `G_0`, its profinite regular corona embedding
carries the regular trace, so the generated MF C-star algebra remembers the
amalgamated subgroup; Shulman's C-star double theorem then yields a faithful
group embedding of the symmetric double.  Apply that verified argument to

```text
G_0 *_B G_0,
```

where `B` means `B x {1}` in each copy of `G_0`.

There is a natural homomorphism

```text
Sigma *_B (B x C_2)  -->  G_0 *_B G_0
```

which sends `Sigma` into the first vertex group as `Sigma x {1}` and
`B x C_2` into the second vertex group.  It is injective by the normal-form
theorem for amalgamated free products: a reduced word in the source still
alternates between elements outside `B` in the two target vertex groups, so
it cannot become trivial.  Since subgroups of MF groups are MF,

```text
E/D ~= Sigma *_B (B x C_2)
```

is MF.

## 4. Exact residual

`unsquared-defect-mf-invisible` is established: every norm-matrix-corona
homomorphism kills `u`.  Kernels are normal, so

```text
D = <<u>> <= Res_MF(E).
```

On the other hand `E/D` is MF.  Compose the quotient map `E -> E/D` with a
faithful norm-corona representation of `E/D`; its kernel is exactly `D`.
Because `Res_MF(E)` lies in the kernel of every corona representation,

```text
Res_MF(E) <= D.
```

Therefore

```text
Res_MF(E) = D = N_conj = <<u>>.
```

## 5. The sign-free collapse computes the residual exactly

Let `q : E -> E/<w>`.  Since `w=u^2`, `<w> <= D`.  The general pullback theorem
for the MF residual therefore gives

```text
Res_MF(E/<w>) = D/<w>.
```

In the proof of the sign-free theorem the image of `d` is an involutive orbit
witness.  Its base commutators normally generate `D/<w>`, so

```text
D/<w> <= D_coll.
```

Conversely the collapse theorem puts the full collapse defect in the MF
residual:

```text
D_coll <= Res_MF(E/<w>) = D/<w>.
```

Hence

```text
D_coll = Res_MF(E/<w>) = D/<w>,
Res_MF(E) = q^-1(D_coll).
```

Thus the collapse criterion computes the residual exactly for the principal
literal example, not merely a nontrivial subgroup of it.

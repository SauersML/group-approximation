## The node (checked)

- **Item 1.**
  - *Baire.* `Z*` is a countable intersection of dense open sets `w^(-1)(U_s)`, so it is dense.
  - *Composition.* Pieces compose along the orbit of a point of `Z*`.
  - *Möbius rigidity.* Agreement on an open set forces equality.
  - *Inverses.* The inverses have pieces `m^(-1)` on `h_i(U_(h_i))`.
- **Item 2.**
  - *The pole argument.* The states `s|_(0^k) = ρ_(r_k)^(-1) m_1 (w ↦ p^k w)` have poles `P/p^k`. These are pairwise
    distinct, because `P ∉ Z_p` forces `P ≠ 0`, and `P ≠ ∞`. That contradicts finiteness of the state set.
  - *Rationality.* It comes from eventually periodic digit tails of `b'`, and of `a + b'` at vertex 1.
  - *The piece formula.* `m(z) = a z + (h(v) − a v + p^n b')`, which lies in `Aff(Z[1/N])`.
  - *Finite generation.* `Aff(Z[1/N])` is finitely generated, via `z ↦ z + 1/r = d_r^(-1) t_1 d_r`.
- **Item 3.** Take `Δ = PGL_2(Z[1/N])`.
  - For `d_q`: `λ ∈ Z[1/N]`, and `v_q(λ^2 q)` is odd, so `det` is not a unit.
  - For `t_(1/q)`: `λ` is a unit, but the entry `λ/q` is not integral at `q`.
  - Both hold whether or not `Λ` is self-similar.

## Reading: overclaim check

- **Bullet 1 ("must be nowhere locally Möbius on some nonempty open set").** Correct as the contrapositive of item 3,
  for `Λ = ⟨Γ_0, finite-state h_i⟩`. If `U_h` is not dense, then `h` is nowhere locally Möbius on the nonempty open
  set `Z_p \ cl(U_h)`.
- **Bullet 2 ("wild finite-state maps are not examined").** Stated honestly.
  - The digit-substitution example is right: a single-state map that is Möbius on one cylinder would be affine on
    `Z_p`, hence affine mod `p`.
  - "Non-affine permutation of `F_p`" is sufficient but not necessary. For `p = 3`, digitwise `x ↦ x+1` is affine
    mod 3 but not 3-adically affine: `D(0) = −1/2`, `D(1) = 1/2`, `D(2) = −3/2`.
  - Non-affine permutations exist only for `p ≥ 5`, since `S_3 = AGL_1(F_3)`. Harmless.
- **W1, bullet 3 (under-justified).** "Then item 1 says the pieces of the generators generate a subgroup of
  `PGL_2(Q_p)` that is not finitely generated."
  - Item 1 gives only that `Δ = ⟨pieces⟩` contains every `d_q`. Non-finite-generation needs one more lemma:

    **Lemma.** A finitely generated `Δ ≤ PGL_2(Q_p)` contains `d_q` for only finitely many primes `q`.

    *Proof.*
    - Let `K` be the field generated by the entries of representatives of the generators. Then `det` induces
      `Δ → K^x/K^(x2)`.
    - Its image is a finitely generated 2-torsion abelian group, hence finite.
    - `d_q ∈ PGL_2(K)` has representatives `λ diag(q,1)` with `λ ∈ K`, so it maps to the class `[q]`.
    - Suppose `[q] = [q']` for distinct primes. Then `√(qq')` lies in the algebraic closure `k` of `Q` in `K`, which
      is a number field because `K` is finitely generated. So a fixed `q` shares its class with only finitely many
      `q'`, since `k` has finitely many quadratic subfields.
    - Finitely many classes, each holding finitely many primes, give finitely many primes. ∎
  - Add this lemma, or cite it. The closing phrase "involving infinitely many primes" should be dropped or made
    precise. Non-finite-generation of `⟨pieces⟩` alone does not force the pieces' entries to involve infinitely many
    primes.

## Attempt 2 of `euler-lamplighter-has-a-faithful-finite-state-action`: correct and correctly scoped

- **Images at each level.** A finite quotient of `Z_(l)` is `Z/l^k`. So the image of `Z_(l) f_0` at each level is a
  cyclic `l`-group, and it equals the image of `⟨f_0⟩`.
- **`l ≤ d`.** This follows from faithfulness, since level-group orders have only prime factors `≤ d`.
- **The closure.** The images are surjective with unbounded orders, so the closure is `≅ Z_l`.
- **Roots.** `f_0/q` has image a power of `f_0` at each level. For `q > d` the `q`-th power map is bijective on every
  level group, so roots are unique in `Aut(T_d)`.
- **The odometer.** Translations by `r ∈ Z_(l) ⊂ Q` are finite-state, since rational digit expansions are eventually
  periodic. So the necessary condition excludes nothing, as the text says.
- **The last bullet.** "The new obstruction nodes do not apply to `G_l`" is correct. Their hypotheses concern
  `Γ_0 ≤ PGL_2(Q)` acting on `Z_p`, and dilations. The status stays OPEN.

# sk-open-1: normal subgroups of EL_n over aperiodic subshift crossed products (part 1)

Lane `sk-open-1`, 2026-09-13. Status: complete proofs, UNREVIEWED. The notation is the note's (`$SK/manuscript-disk-1646.tex`).

## Setting
- A finite alphabet A. A subshift X ⊆ A^Z without periodic points.
- R = R_X = LC(X,F_2) ⋊_T Z, with (Tx)_n = x_{n+1} and u f u^{-1} = f∘T^{-1}, so u e_V u^{-1} = e_{TV}.
- n ≥ 3 and G = EL_n(R).
- For a closed invariant Y ⊆ X (Y = ∅ allowed), put U = X∖Y and I_Y = {Σ f_j u^j : supp f_j ⊆ U}.
- ρ_Y : R_X → R_Y restricts the coefficient functions to Y.
  - ρ_Y is a surjective ring homomorphism: Y is invariant, and every locally constant function on Y extends to X.
  - ker ρ_Y = I_Y.
- π_Y : G → EL_n(R_Y) is ρ_Y entrywise. (R_∅ = 0 and EL_n(0) = 1.)
- E_Y = E_n(R, I_Y) is the normal closure in G of {e_ij(r) : r ∈ I_Y, i ≠ j}.

## Tower facts (reproduced from the note, l.154-221)
Let U be clopen with the levels T^aU pairwise disjoint for |a| ≤ M.
- For |a|, |b| ≤ m and clopen W ⊆ U, put E_ab(W) = e_{T^aW} u^{a−b}. Then E_ab(W) E_cd(W') = δ_bc E_ad(W∩W').
  So their span is B_m(U) ≅ M_{2m+1}(LC(U,F_2)), with unit e = e_{⋃_{|a|≤m} T^aU}.
- Absorption: if r, r' involve only exponents |j| ≤ w and m + w ≤ M, then r B_m(U) r' ⊆ B_{m+w}(U).
- Some translate U of C has e_C, e_C u, e_C u^{-1} ∈ B_1(U): take U = C, T^{-1}C and TC respectively.
- Suppose the entries of g, g^{-1} use exponents |j| ≤ w, h = e_ij(s) with s ∈ B_1(U), and C ∩ T^jC = ∅ for 0 < |j| ≤ 2w+3.
  - Then k = [g,h] satisfies k − I, k^{-1} − I ∈ M_n(B_{w+1}(U)).
  - So k = (1−e)I + eke, where eke is a locally constant κ : U → GL_d(F_2) with d = n(2w+3).
- For clopen W ⊆ U, the copy H_W ≅ GL_d(F_2) acting on the tower over W, and as the identity elsewhere, lies in G.
  - It is generated by e_pq(E_ab(W)) for p ≠ q, together with [e_pq(E_ab(W)), e_qp(E_bb(W))] = I + E_ab(W)E_pp for a ≠ b.
  - If κ|_W = κ_0, conjugation by k on H_W is conjugation by κ_0.
  - GL_d(F_2) is simple and centreless for d ≥ 3. So κ_0 ≠ I and k ∈ N force H_W ≤ N.

## Lemma 1 (ideals are subsystems)
Every two-sided ideal J of R equals I_Y for exactly one closed invariant Y, namely Y = X ∖ ⋃{V clopen : e_V ∈ J}.

*Proof.* Let U = ⋃{V clopen : e_V ∈ J}. It is open, and it is invariant because u e_V u^{-1} = e_{TV}. Put Y = X∖U.

I_Y ⊆ J:
- Let supp f ⊆ U. By compactness, finitely many V_i with e_{V_i} ∈ J cover supp f.
- So f = e_{supp f}(1 − ∏_i(1 − e_{V_i})) ∈ J, and f u^j ∈ J.

J ⊆ I_Y:
- Let r = Σ f_j u^j ∈ J and fix an exponent i. Then r u^{-i} ∈ J has 0-coefficient f_i.
- Suppose f_i(x) = 1. Since x is not periodic, there is a clopen V ∋ x with f_i = 1 on V and V ∩ T^j V = ∅ for the finitely many nonzero exponents j of r u^{-i}.
- For j ≠ 0, e_V (f u^j) e_V = f e_V e_{T^j V} u^j = 0. So e_V r u^{-i} e_V = e_V, which lies in J, so x ∈ U.
- So supp f_i ⊆ U for every i, and r ∈ I_Y.

Uniqueness: e_V ∈ I_Y iff V ∩ Y = ∅, and clopen sets separate points. □

## Lemma 2 (trivial centre)
For every nonempty closed invariant Y ⊆ X, the centre of EL_n(R_Y) is trivial.

*Proof.*
- Take a central element of R_Y. Commuting with all e_V kills its coefficients of nonzero exponent: a point y and T^{-j}y ≠ y are separated by a clopen set. This uses only that Y has no periodic points.
- Commuting with u makes the 0-coefficient invariant.
- A central element of EL_n(R_Y) commutes with every e_ij(1), so it is cI with c central in R_Y and invertible. So c is an F_2-valued function with an inverse, and c = 1. □

## Theorem 3 (sandwich)
For every normal subgroup N ⊴ G there is exactly one closed invariant Y ⊆ X with
  E_Y ≤ N ≤ ker π_Y.
It is determined by I_Y = I_N := {r ∈ R : e_12(r) ∈ N}.

*Proof.*

Step 0. I_N is a two-sided ideal, by the note l.223-226: permutation matrices w_ij = e_ij(1)e_ji(1)e_ij(1) ∈ G carry positions, and (1) gives sums and one-sided products. Lemma 1 gives a unique Y with I_N = I_Y.

Step 1. N contains e_12(I_Y). Conjugating by permutation matrices, it contains every e_ij(I_Y), so E_Y ≤ N.

Step 2. Suppose g ∈ N and π_Y(g) ≠ 1, so Y ≠ ∅.
- Let w bound the absolute exponents of the entries of g and g^{-1}.
- Choose a finite clopen partition 𝒫 refining the letter partition, with C ∩ T^jC = ∅ for C ∈ 𝒫 and 0 < |j| ≤ 2w+3.

(2a) Some h = e_ij(s), with s ∈ {e_C, e_C u, e_C u^{-1} : C ∈ 𝒫}, has π_Y([g,h]) ≠ 1.
- Otherwise π_Y(g) commutes with every e_ij(ρ_Y(s)).
- By (1), the set {s̄ ∈ R_Y : π_Y(g) commutes with all e_ij(s̄)} is a subring. It contains ρ_Y(1), ρ_Y(u^{±1}) and ρ_Y(e_a), which generate R_Y.
- So π_Y(g) is central, hence trivial by Lemma 2. That is a contradiction.

(2b) Put k = [g,h] ∈ N.
- The note's absorption (l.189-201) gives: with m = w+1 and U_C the translate of C for which s ∈ B_1(U_C), both k − I and k^{-1} − I lie in M_n(B_m(U_C)).
- The corner of k is a locally constant κ : U_C → GL_d(F_2), with d = n(2m+1).
- ρ_Y maps B_m(U_C) onto B_m(U_C ∩ Y) by E_ab(W) ↦ E_ab(W ∩ Y). So π_Y(k) ≠ 1 gives y ∈ U_C ∩ Y with κ(y) ≠ I.
- Choose a clopen W ∋ y with κ|_W = κ_0.
- The note's l.205-221 argument uses only d ≥ 3 and κ_0 ≠ I. It gives H_W ≤ N, so e_12(e_W) ∈ N.
- Then e_W ∈ I_N = I_Y, so W ∩ Y = ∅. That contradicts y ∈ W. So N ≤ ker π_Y.

Uniqueness. Suppose E_{Y'} ≤ N ≤ ker π_{Y'}.
- Then I_{Y'} ⊆ I_N.
- If e_12(r) ∈ ker π_{Y'} then ρ_{Y'}(r) = 0, so I_N ⊆ I_{Y'}.
- So I_{Y'} = I_N, and Y' = Y by Lemma 1. □

## Corollary 4
Let X be an infinite subshift. Then EL_n(LC(X,F_2) ⋊ Z) is simple iff X is minimal.

*Proof.*
- If X is minimal and infinite, it has no periodic points and its only closed invariant sets are ∅ and X. By Theorem 3, N = G or N ≤ ker π_X = 1.
- If X is not minimal, choose a closed invariant Y with ∅ ≠ Y ≠ X. Then ker π_Y ∋ e_12(e_V) ≠ 1 for a clopen V ≠ ∅ disjoint from Y, and ker π_Y ≠ G because π_Y(e_12(1)) ≠ 1. This direction needs no aperiodicity. □

## Proposition 5 (the congruence layer)
G/E_Y is a quotient of St_n(R_Y), and ker π_Y / E_Y is the image of K_2(n, R_Y) = ker(St_n(R_Y) → EL_n(R_Y)).

So if K_2(n, R_Y) = 0 for every closed invariant Y:
- the normal subgroups of G are exactly the kernels ker π_Y;
- Y ↦ ker π_Y is an inclusion-reversing bijection from closed invariant subsets of X onto normal subgroups of G;
- G / ker π_Y ≅ EL_n(R_Y).

*Proof.*
- St_n(R)/⟨⟨x_ij(I_Y)⟩⟩ ≅ St_n(R_Y), since the generators and the Steinberg relations lift.
- St_n(R) → G is onto, so it maps ⟨⟨x_ij(I_Y)⟩⟩ onto E_Y.
- So St_n(R_Y) → G/E_Y → EL_n(R_Y) is the canonical surjection. The kernel of the second arrow, ker π_Y/E_Y, is the image of K_2(n, R_Y).
- The bijection then follows from Theorem 3, since each ker π_Y determines Y through I_N. □

## Aperiodicity is needed
- Let X = Y ⊔ {p} with p a fixed point (for instance the orbit closure of a point asymptotic to p, plus p isolated).
- Then R ⊇ an ideal quotient F_2[t^{±1}] at p.
- EL_n(F_2[t^{±1}]) has a congruence subgroup for each ideal (t−1)^k. So there are infinitely many normal subgroups with the same Y, and Lemma 1 fails.

## Open (part 2)
K_2(3, R_Y) for these rings. The stable group K_2(R_Y) should vanish by the Ara–Brustenga–Cortiñas twisted-Laurent sequence: K_1 = K_2 = 0 for the Boolean ring LC(Y,F_2). The unstable n = 3 case needs more.

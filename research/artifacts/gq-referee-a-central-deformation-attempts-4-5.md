## Attempt 4: the homotopy invariance argument

  dimension is at most `gl.dim A + 1 = 3`. So `D` is left regular noetherian, and Quillen gives
  `K_2(D) ≅ K_2(D[t])` with `t` central. ✓
- *The deformation `φ`.* `b ↦ tπ_0^(−1)` gives `p ↦ t`.
  - `bu = ub` holds because `A` is commutative and `t` is central.
  - `xpx^(−1) = p` becomes `xtx^(−1) = t`.
  - So `φ : B → D[t]` is well defined. `ev_1∘φ` is the quotient `B → B/(p−1) ≅ D`, with `b ↦ π_0^(−1)`, as in
    item 2. `ev_0∘φ` factors through `B_0 = Z[u][x^±;σ] ⊆ D`. ✓
- *The homotopy.* `ev_0` and `ev_1` are both left inverses of `D → D[t]`, whose `K_2` map is an isomorphism. So
  `K_2(ev_0) = K_2(ev_1)`, and `K_2(B) → K_2(D)` factors through `K_2(Z[u][x^±;σ])`. ✓
- *Finiteness.* `Z[u]` is regular, `K_2(Z[u]) = K_2(Z) = Z/2`, and `K_1(Z[u]) = {±1}`. `σ` acts trivially on both,
  so ABC gives an extension of `Z/2` by `Z/2`, of order at most 4. ✓

## Attempt 5: the lemma
- *`J` is finitely generated.* It is generated by the finitely many entries of the `ḡ_s − 1`.
- *`J ⊆ I_rf`.* Let `J'` be a two-sided ideal of finite index. The image of `St_N(T)` in `GL_N(T/J')` is a finite
  quotient, so each `g_s ∈ St_N(T)_rf` maps to `I`. That is, the entries of `ḡ_s − 1` lie in `J'` (N1). ✓
- *`I_rf ⊆ J`.*
  - For `a ∈ I_rf`, every finite quotient `ρ` has `I_ρ ⊇ I_rf` (`steinberg-rf-forces-ring-rf`), so
    `x_12(a) ∈ St_N(T)_rf = ⟨⟨g_s⟩⟩`.
  - `GL_N(T,J) = ker(GL_N(T) → GL_N(T/J))` is normal and contains the `ḡ_s`, so `e_12(a) ∈ GL_N(T,J)`, which gives
    `a ∈ J`. ✓
- *For `T_p`.*
  - `I_rf(T_p)` maps to `I_rf(T_l) = 0`, so it lies in `ker(T_p → T_l) = [[(p−1)B, 0],[0,0]]`.
  - It maps into `I_rf(B) × I_rf(Z) = I_rf(B) × 0` under `T_p → B × Z`. ✓

## Nits
- **N1 (the lemma, `J ⊆ I_rf`).** "Each `g_s` dies in every `St_N(T/J')`" should read "in the finite group
  `E_N(T/J') ⊆ GL_N(T/J')`". Membership in `St_N(T)_rf` only guarantees death in finite quotients, and `St_N(T/J')`
  need not be finite for `N = 3, 4`. The entry argument uses only the image in `GL_N(T/J')`.
- **N2 (for `T_p`).** The bound is an equality: `I_rf(T_p) = [[I_rf(B), 0],[0, 0]]`.
  - `D` is residually finite (`euler-triangular-ring-is-fp-rf`), so `I_rf(B) ⊆ ker(B → D) = (p−1)B`, and the
    intersection with `(p−1)B` is redundant.
  - Conversely, for a finite-index `J'` of `T_p`, `J' ∩ eT_pe` has finite index in `B`, so `[[I_rf(B),0],[0,0]] ⊆ J'`.
  - `[[I_rf(B),0],[0,0]]` is a two-sided ideal, because `(p−1)` kills `M`: `p` is central and `(p−1)m_0 = 0`.
  - So the route needs exactly "`I_rf(B)` finitely generated as a two-sided ideal of `B`".

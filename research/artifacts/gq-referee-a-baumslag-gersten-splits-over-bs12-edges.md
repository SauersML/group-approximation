## (1) `BG ≅ K*_ψ` (the author asked about this)
- `K = B_0 *_(⟨a_1⟩) B_1` is an amalgam of two `BS(1,2)`'s over an infinite cyclic group. In `B_0`, `a_1` is the stable
  letter; in `B_1` it is the base.
- `ψ : a_0 ↦ a_1, a_1 ↦ a_2` carries the relator of `B_0` to that of `B_1`, so it is an isomorphism.
- In `K*_ψ`, eliminate `a_1 = ta_0t^(−1)` and `a_2 = t²a_0t^(−2)`.
  - The first relator becomes `(tat^(−1))a(ta^(−1)t^(−1)) = a²`, which is `bab^(−1) = a²`.
  - The second relator is its `t`-conjugate.
  - So `K*_ψ ≅ BG`.
- Normal forms in `K` give `a_2 ∈ B_1 ∖ ⟨a_1⟩`, so `a_2 ∉ B_0`, and symmetrically `a_0 ∉ B_1`. So the extension is
  non-ascending. ✓

## (2) The conditional criterion (the author asked about this)
- **The hypotheses of the stable-permutation node.** `D_i = B_i` are finitely generated, and `ψ` is an isomorphism.
  (R3) gives `πdπ^(−1) = ψ(d)` on generators, hence on all of `B_0`.
- **Part (a).** It uses (R2), that `D_1 = B_0` is orbit-finite, and (R4), that `ρ` is injective.
- **Part (b).** Take `A = K`. Then `A ∩ D_i = B_i`, because `B_i ≤ K`, and `ψ(B_0) = B_1`. So

## (3) `S' ≅ W`, and type (A) on `S'` (the author asked about this)
- **`W`.**
  - Composing right to left, `a_1a_0a_1^(−1)(r) = 2(r/2 + 1) = r + 2`.
  - `W` is stable under `+1`, `×2` and `×½`, since `(1/3 + d)/2 = −1/3 + (½ + d/2)`.
  - `Z[1/2]` is generated by the conjugates `a_1^k a_0 a_1^(−k)`, which are translations by `2^k`. So `B_0` is
    transitive on `W`.
  - `Stab(1/3)` consists of the maps `r ↦ 2^k r + c` with `3 | 2^|k| − 1`, that is, `k` even. So it is generated by
    `r ↦ 4r − 1 = a_0^(−1)a_1²`.
  - The action is faithful, since an affine map fixing infinitely many points is the identity. ✓
- **`π`.**
  - Both `a_0` and `a_1` act freely on `W`, the latter because `0 ∉ W`.
  - Each has countably many orbits, all infinite, so `π` exists.
  - `a_2a_1a_2^(−1) = π(a_1a_0a_1^(−1))π^(−1) = πa_0²π^(−1) = a_1²`. ✓
- **The identification `r : S' → W`.**
  - `E ≅ Z`, with eventually-0 sequences giving the integers `≥ 0` and eventually-1 sequences the negative ones.
  - The fractional part `Σ y_k 2^(−(k+1))` of a `y` in the tail class of `(01)^∞` has the form `q/(3·2^j)`, which is
    `1/3` or `2/3` modulo `Z[1/2]`. Its binary expansion is unique, and every such fraction arises.
  - `s ↦ +1`.
  - `u(x, y_0y) = (y_0x, y) ↦ y_0 + 2x + 0.y_1y_2… = 2r`. ✓
- **The orbit is `E × Y'`.**
  - `2V` realizes any pair of prefixes, and `τ^(−1)` joins the tails `0^∞` and `1^∞`.
  - Germs at `p'` are prefix replacements. An odometer power `a^n` with `n < 0` borrows into the tail `0^∞`, so it
    cannot fix `p'`.
  - So the germ map `g ↦ (a' − a, (|w'| − |w|)/2)` is a well-defined homomorphism to `Z²`, with the parity condition.
    Its kernel is `⋃ Γ_(n)`.
  - `e(B_j) = B_(j+1)`, so `eΓ_(j)e^(−1) = Γ_(j+1)`. With `g_1, g_2` realizing germs that generate the image,
    `Stab(p')` is finitely generated.
  - There are at most three orbits on pairs, by high transitivity within each first-coordinate tail type.
  - The action is faithful, by density. ✓

## (4) `a_2 ∉ 2V_τ` (the author asked about this)
- Suppose `h ∈ 2V_τ` restricts to `a_2` on `S'`. Then `huh^(−1) = u²` on the dense set `S'`, hence everywhere.
- `u` is conjugate to the two-sided full 2-shift, via `(x, y) ↦ …x_1x_0.y_0y_1…`, so `h(u) = log 2`. But
  `h(u²) = 2 log 2`.
- This holds for every admissible `π`. ✓

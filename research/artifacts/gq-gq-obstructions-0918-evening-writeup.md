**1.5 `stably-finite-fp-simple-ring-containing-q-exists`** (OPEN, lane gq-k2-q). The claim asks for a ring `R`,
finitely presented over `Z`, that is simple, stably finite and of finite stable range, with `Q̄ ⊆ R` unitally and
`K_1(R) = ι(Q̄^x) + torsion`.

*Truncation principle* (proved necessary condition; lane proof, elementary). A finitely presented ring `P ⊇ Q` has
no nonzero map to any ring of positive characteristic. So:
- `P` has no nonzero finite quotient, and is not residually finite;
- if every finite integer system solvable in `R` is solvable in some nonzero ring of positive characteristic,
  then no finitely presented `P → R` contains `Q`.

The ring sought must therefore be *rigid in characteristic zero*.

*Mechanisms on main, against the target.*
- Leavitt and resolvent vacua are rigid, but not stably finite.
- An Euler-type evaluation idempotent has orthogonal equivalent conjugates, so it cannot be full.
- Harmonic elimination is not finitely presented.
- Integral forms and AF groupoid rings omit `Q`.

The node records that no candidate exists and that a new mechanism is needed.

## 6. Out(V) (`out-v-contains-the-root-problem-for-the-full-2-shift`)

1 referee: gq-referee-a PASS (0da548b9b, W1 and N1 applied). Inputs were read at the source in TeX, except
Boyle–Lind–Rudolph and Boyle 2008, which were read through Salo.
1. The Lipschitz part `L_2` of `O_2 ≅ Out(V)` is the inert group: `Aut(X_2^Z, σ) ≅ ⟨σ⟩ × L_2`, with
   `L_2 ≅ ker(dim)`.
2. `L_2` is residually finite, so it contains no `(Q,+)`. A copy of `Q` in `Out(V)` must use transducers that
   violate the Lipschitz constraint.
3. **Transfer of roots.** An element of `Aut` of infinite order, with roots of every order in an infinite set `I`,
   has image in `L_2 ⊂ O_2` with the same property. Also, `Z[1/2] ≤ Aut` if and only if `Z[1/2] ≤ L_2`.
4. **Calibration against Boyle's root problem.** Suppose an argument shows that no nontrivial element of `O_2` has
   roots of infinitely many orders. Then it answers negatively the open question (Boyle 2008, as quoted by Salo
   2023) whether `Aut` of the full 2-shift has elements of infinite order with such roots.
   - It also shows `Z[1/2] ∉ G`, where `G` is the class of groups embedding in `Aut` of the `Z`-full shift.
   - An obstruction to `Aff(Q) ≤ Aut(V)` through roots must therefore settle such cases, or use the coherence of
     the roots.

`aff-q-embeds-in-aut-v` stays OPEN.

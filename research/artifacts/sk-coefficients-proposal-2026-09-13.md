## 1. Results

1. **The note's proof works for every finite field and every n ≥ 3.** Every normal subgroup of G is central or G, `Z(G)` is a finite group of scalars, and `G/Z(G)` is an infinite finitely generated simple Kazhdan LEF group.
   - For n = 3 this is already on main (`subshift-elementary-group-is-simple-modulo-centre`; b965d63ba Theorem 1).
   - New here: the exact list of steps of the SHORT note that change (§2).
2. **The scalar case of root detection never occurs** (`root-localization-commutator-is-never-scalar`, §3). b965d63ba l.648–662 (Case 2, 15 lines) and write-up part 2 §6.2(d) can be deleted. Over F_q the note needs one sentence where the long version spends fifteen lines.
3. **Exact centre** (`subshift-el-group-centre-detects-rational-eigenvalues`, §4):
   `Z(EL_n(R_q)) = μ_{gcd(ne, q−1)}(F_q)·I_n`, where e is the largest divisor of q−1 such that (X,T) factors onto the rotation of Z/e.
   - Sturmian X: `Z(G) = Z(SL_n(F_q))`.
   - Period-doubling X, q = 3, n = 3: `−I_3 ∈ EL_3(R_3)` although `det(−I_3) = −1` in F_3.
4. **The coefficient range is exactly the finite fields** (§5). Infinite fields lose finite generation and (T). `M_k(F_q)` reduces to `EL_{nk}` over F_q. A non-simple finite ring gives a non-simple group.
5. **Verdict (§6).** Keep F_2 and EL_3 in the theorem. Add the 10-source-line remark "Other finite fields", which records the one non-routine point. The centre formula stays in Cairn.

**Finite simple group step over F_q.**
- `N_W = N ∩ H_W` is normal in `H_W ≅ SL_d(F_q)` and contains every `[κ_0, ε]`.
- Suppose `N_W` is central. Then `ε ↦ [κ_0, ε]` is a homomorphism into `Z(SL_d)`, since `[κ_0, εδ] = [κ_0,ε]·ε[κ_0,δ]ε^{-1}`. It is trivial because `SL_d(F_q)` is perfect for d ≥ 3. Then κ_0 centralizes `SL_d` and is scalar, which contradicts §3.
- So `N_W` is noncentral. `PSL_d(F_q)` is simple, so `N_W Z(H_W) = H_W`, and perfectness gives `N_W = H_W`.

**LEF of `G/Z` for finite central Z.**
- Let `F ⊇ Z` be finite and `φ` an injective partial homomorphism on a finite set containing `F·F`.
- For `f ∈ F` and `z ∈ Z`: `φ(z)φ(f) = φ(zf) = φ(fz) = φ(f)φ(z)`. So `φ(Z)` is central in `Q = ⟨φ(F)⟩`, and `φ|_Z` is an injective homomorphism.
- `ψ(fZ) = φ(f)φ(Z)` is a partial homomorphism `F/Z → Q/φ(Z)`.
- It is injective: `φ(f) = φ(f')φ(z) = φ(f'z)` forces `f = f'z`.

## 3. κ is never a nonidentity scalar (new; removes Case 2 of b965d63ba)

**Lemma.** Let:
- `g ∈ GL_n(R_q)`, with every entry of g and `g^{-1}` involving only powers `u^j`, `|j| ≤ w`;
- `U` clopen with `U ∩ T^jU = ∅` for `0 < |j| ≤ 2w+2`;
- `s = λ E_{a0}(W)` with `|a| ≤ 1`, `W ⊆ U` clopen, `λ ∈ F_q` (this covers `λχ_C = λE_00(C)`, `χ_C u = E_10(T^{-1}C)`, `χ_C u^{-1} = E_{-1,0}(TC)`);
- `h = e_ij(s)`, `k = [g,h]`, `m = w+1`.

Then:
- (i) every entry of `k − I` is an F_q-combination of elements `E_ab(W')` with `|a| ≤ m`, `|b| ≤ w`, `W' ⊆ U` clopen;
- (ii) under `M_n(B_m(U)) ≅ LC(U, M_d(F_q))`, the function κ of `k` fixes the 2n basis vectors at the levels `b = ±m`;
- (iii) `κ(x)` is scalar only if `κ(x) = I`.

**Proof.**
- Left multiplication by `f u^i` turns `E_ab(W)` into `E_{a+i,b}(W')`. Right multiplication by `f'u^j` turns it into `E_{a,b−j}(W'')` (note l.171–173).
- Put `X = ghg^{-1} − I` and `Y = h^{-1} − I = −sE_ij`, so that `k − I = X + Y + XY`.
- The entries of X are `g_{pi} s (g^{-1})_{jq}`. Their second index is `0 − j'` with `|j'| ≤ w`, and their first index is `a + i'` with `|a + i'| ≤ w+1`.
- The entries of Y have second index 0.
- In XY each entry is a sum of products `E_{a'b'}(·)·E_{a0}(·) = δ_{b'a} E_{a'0}(·)`, with second index 0.
- So all second indices of `k − I` lie in `[−w, w]`, which proves (i). Level disjointness for `|a| ≤ m` is the hypothesis on U.
- `E_ab(W')` corresponds to the matrix unit at `(a,b)` times `χ_{W'}`. So the columns of `κ(x) − I` at `b = ±m` vanish, which proves (ii).
- `λI_d` with `λ ≠ 1` has no column equal to a basis vector, which proves (iii). ∎

**Consequence.**
- In b965d63ba, Theorem `thm:root` (l.575–664): `κ ≢ I` already gives a non-scalar value, so Case 1 covers everything and Case 2 (l.648–662) is vacuous. The same holds for write-up part 2 §6.2(d).
- In the F_q form of the note, the lemma is the single extra sentence of §6. Over F_2 it is not needed, since `GL_d(F_2)` is centreless.

## 4. The exact centre (new, bounded check: nothing on main computes Λ)

Main's version has `Λ = {λ ∈ F_q^× : λI_3 ∈ G}` (b965d63ba l.557, write-up part 2 l.87) and leaves it at that. Here Λ is computed.

**Theorem.** Let X be an infinite minimal subshift, q a prime power, `n ≥ 3`, and `G = EL_n(LC(X,F_q) ⋊_T Z)`. Put
`E_X(q) = {λ ∈ F_q^× : f∘T = λ f for some continuous f: X → F_q^×}`.
Then `E_X(q) = μ_e(F_q)`, where `e` is the largest divisor of `q−1` such that `(X,T)` factors onto `(Z/e, +1)`, and
`Z(G) = {cI_n : c^n ∈ E_X(q)} = μ_{gcd(ne, q−1)}(F_q)·I_n`.

**Proof.**
(a) `Z(G) ⊆ F_q^× I_n` (note l.114–116, with `Z(R_q) = F_q`).

(b) `E_X(q) = μ_e`.
- If `φ: X → Z/d` is a factor map with `d | q−1`, and `ζ ∈ F_q^×` has order d, then `f = ζ^φ` satisfies `f∘T = ζf`.
- Conversely, suppose `f∘T = λf` with `ord(λ) = d`. Then `x ↦ f(x)μ_d` is T-invariant, hence constant by minimality. So `f = aψ` with `ψ: X → μ_d` and `ψ∘T = λψ`, which is a factor map onto Z/d (onto by minimality).
- The set of such d is closed under lcm: combine the two factor maps into `X → Z/d_1 × Z/d_2`; its image is the orbit of a point, of size `lcm(d_1,d_2)`. So `E_X(q)` is the cyclic group `μ_e`.

(c) Whitehead.
- `diag(v, v^{-1}) ∈ E_2(R)` for every unit v. So `diag([a,b], 1) = diag(a,a^{-1})·diag(b,b^{-1})·diag((ba)^{-1}, ba) ∈ E_2(R)`.
- Multiplying by `diag(c^{-1}, c)` in positions `(1, i)` for `i = 2..n` shows that `cI_n ∈ G` iff `diag(c^n, 1, …, 1) ∈ G`.

(d) `c^n ∈ E_X(q) ⇒ cI_n ∈ G`.
- Take λ ∈ E_X(q) with `f∘T = λf`, so `f(x) = λf(T^{-1}x)`.
- `u f^{-1} u^{-1} = f^{-1}∘T^{-1}`. So `f u f^{-1} u^{-1} = f/(f∘T^{-1}) = λ`, a commutator of units.
- By (c), `diag(λ,1,…,1) ∈ G`. Apply this with `λ = c^n` and use (c) again.

(e) `cI_n ∈ G ⇒ c^n ∈ E_X(q)`.
- Write `cI_n` as a product of elementary matrices, and let k_0 exceed the radii of all local functions in the ring computation that evaluates it, shifts included.
- Let v be a word of X of length `2k ≥ 2k_0`. Let N be the difference of two occurrences of v in a point x, and w the segment between them.
- Every window of length 2k+1 of `y = w^∞` is a word of X (note l.126–128; the seam argument needs no length condition). So `ψ_y(Σ f_j u^j) = Σ D_y(f_j) P^j` into `M_N(F_q)` preserves the computation (note l.137–141). Injectivity is not needed here.
- `ψ_y(c) = cI_N`, and each `ψ_y(e_ij(r))` is unipotent of determinant 1. So `c^{nN} = 1`, and `d := ord(c^n)` divides N (`ord(c) | nN ⟺ ord(c^n) | N`).
- So d divides every occurrence difference of v. `φ(x) = −i mod d`, for any occurrence i of v in x, is well defined, continuous (v occurs within bounded distance of 0 by uniform recurrence), and satisfies `φ∘T = φ+1`.
- So `(X,T)` factors onto `Z/d`, with `d | q−1` because `c^n ∈ F_q^×`. Then `c^n ∈ μ_d ⊆ E_X(q)`.

(f) `F_q^×` is cyclic, so `c^n ∈ μ_e ⟺ c^{ne} = 1 ⟺ c ∈ μ_{gcd(ne,q−1)}`. ∎

**Examples.**
- **q = 2:** trivial centre (the note).
- **Sturmian X, e.g. Fibonacci.** The continuous eigenvalues are those of the rotation factor, `e^{2πikα}`, with no nontrivial roots of unity. So `e = 1` and `Z(G) = μ_{gcd(n,q−1)} I = Z(SL_n(F_q))`.
- **Period-doubling subshift (0↦01, 1↦00).** It factors onto every `Z/2^j` (dyadic odometer), so `e = 2^{v_2(q−1)}`.
  - For q = 3, n = 3: `Z(G) = {±I_3}`, with `−1 = f u f^{-1} u^{-1}` for `f = (−1)^{φ}`, φ the position parity.
  - So `−I_3 ∈ EL_3(LC(X,F_3) ⋊ Z)` for this X, but not for Sturmian X.
- **Isomorphism invariant.** The order of the centre of `EL_n(R_q)` is `gcd(ne, q−1)`, so the abstract group `EL_n(R_q)` depends on the rational spectrum of X. It is a coarse invariant; see sk-rigidity-* for finer ones.

## 5. Other coefficient rings

- **Infinite field k.**
  - Consider finitely many elements of `R_k = LC(X,k) ⋊ Z`. Every element of the subring they generate has coefficient functions with values in the subring `k_0 ⊆ k` generated by the values of their coefficients.
  - If `R_k` were finitely generated, then `k = k_0` would be a finitely generated ring, hence finite (a field finitely generated as a ring is finite). So `R_k` is not finitely generated.
  - Every element of `R_k` occurs as an entry `e_12(r)` of G, so `EL_n(R_k)` is not finitely generated either. A countable discrete group with (T) is finitely generated, so `EL_n(R_k)` has no (T).
  - Simplicity modulo the centre survives: `H_W ≅ SL_d(k)`, `PSL_d(k)` is simple for d ≥ 3, and §3 applies (main: `steinberg-elementary-groups-are-simple-mod-centre`, any field). There is nothing new for the note.
- **Finite simple rings `M_k(F_q)`.**
  - `LC(X, M_k(F_q)) ⋊ Z ≅ M_k(R_q)`, and `EL_n(M_k(S)) = EL_{nk}(S)` for n ≥ 2.
  - Within-block transvections come from `[e_pq(rE_ac), e_qp(E_cb)] = I + rE_ab E_pp` for `a ≠ b`. Transvections across blocks are `e_pq(rE_ab)`.
  - So these rings give nothing new.
- **Finite non-simple rings (`Z/p²`, `F_q[ε]/ε²`, `F_q × F_q`).** A proper ideal J of the coefficient ring gives the proper ideal `LC(X,J) ⋊ Z`. The congruence kernel of `EL_n(R_F) → EL_n(R_{F/J})` is a proper noncentral normal subgroup (it contains `e_12(LC(X,J))`). So `EL_n/Z` is not simple.
- **Conclusion.** Among coefficient rings for which EJZ gives (T) (finite, so that R is finitely generated) and simplicity holds, the method gives exactly `M_k(F_q)`, which reduces to F_q.

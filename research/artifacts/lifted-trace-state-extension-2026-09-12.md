# The lifted trace and states on the ternary anti-central summand

Lane `w4-trace-state`, 2026-09-12. Supports:
- `anti-central-state-exists-iff-lifted-trace-relatively-positive` (Sections 1–2), with route
  `anti-central-state-lifted-trace-extension-proof`;
- the open claim `anti-central-lifted-trace-is-relatively-positive` (Section 3).

Directive: decide whether the lifted trace on the finite-subgroup algebras of `G = L_(F_3)(1,2)^x` extends to a state
on `(K_0(S_-), [eps_-])`. If it does, the swap corner is refuted.

Outcome: not decided, but the question is now exact.
- The lifted trace is already an additive invariant on all of `K_0(S_-)`, with values in `Z_3`. It obeys every law a
  state is known to obey (Section 1).
- So there is no equality relation among finite-subgroup projectives with different lifted traces. Remark 3.3 of
  `hadamard-spectral-conjugacy-and-forced-states-2026-09-12.md` asked for one; none can exist.
- A state extending the lifted trace exists iff the lifted trace is nonnegative on the positive classes lying in the
  span of finite-subgroup projectives. Some state exists iff this holds for the signed Thompson group (Section 2).
- So the swap corner is full iff one explicit kind of stable isomorphism exists, one that lowers the lifted trace
  across a complement. Positivity itself is open (Section 3).

## 0. Notation

- `R = L_(F_3)(1,2)`, `G = R^x`, `z = -1`, `eps_- = 2(1 - [z])`, `S_- = eps_- F_3[G]`, `u = [eps_-]`.
- `w = s0 t1 + s1 t0`, `e_- = 2 eps_- (1 + [w])`, `delta(g) = s0 g t0 + s1 g t1`, `psi(x) = e_- delta_*(x)`, and
  `F_*` the halving endomorphism of `K_0(S_-)` (census §7.2; `halving-invariant-k0-states-2026-09-12.md` §1).
- `H = E x| V`, the signed Thompson group, and `alpha(g) = (g^*)^(-1)` (forced-states artifact §3).
- `K_0(S_-)` is a direct summand of `K_0(F_3[G]) = K_0(S_+) (+) K_0(S_-)`, with cone `K_0^+ = K_0^+(S_-)`. By census §2,
  `u` is an order unit.
- For a finite subgroup `K <= G` with `z in K` and an idempotent matrix `p` over `eps_- F_3[K]`, `[p]` is the class of
  `p F_3[G]^n` in `K_0(S_-)`, and `trl(p) = 2 dim_(F_3)(p F_3[K]^n) / |K|`.
- `H_fin(L)`, for a subgroup `L <= G` containing `z`, is the subgroup of `K_0(S_-)` generated by all such `[p]` with
  `K <= L`. Conjugate idempotents have equal classes, so it only depends on `L` up to conjugacy. It contains `u`.
- `t_3 : K_0(F_3[G]) -> Z_3` is the additive lifted trace of `lifted-trace-detects-finite-subgroup-projectives`: the
  diagonal identity-coefficient trace `T` of an idempotent lift over `c_0(G, Z_3)`. Put `s_3 = 2 t_3` on `K_0(S_-)`.

## 1. The lifted trace obeys every known state law

**Proposition 1.1.** `s_3 : K_0(S_-) -> Z_3` is additive, and:
1. `s_3(u) = 1`;
2. `s_3([p]) = trl(p)` for every finite subgroup `K <= G` containing `z` and every idempotent matrix `p` over
   `eps_- F_3[K]`. In particular `s_3([1_U]) = lambda(U)` for clopens `U` of `M_-`, and `s_3(c_1) = s_3(c_2) = 1/2` on
   the two blocks of the semidihedral group `<w, d, h>`;
3. `s_3 o F_* = s_3 / 2`;
4. `s_3 o alpha_* = s_3`.

*Proof.*
- *Parts 1–2.* (LFT1) gives `t_3([p]) = dim(p F_3[K]^n)/|K|`, so `s_3 = trl` on these classes. For `u`, take `K = <z>`
  and `p = eps_-`: `trl = 2 . 1/2 = 1`.
  - *Clopens.* For a complete prefix code `c_1, ..., c_n`, `E_c = <tau_(c_i)>` has order `2^n` and contains `z`, and
    `eps_- F_3[E_c]` is the algebra of functions on its `2^(n-1)` odd characters. A clopen `U` at that level is the
    indicator of `m` of them, so `trl(1_U) = 2m/2^n = m 2^(1-n) = lambda(U)`.
  - *Semidihedral blocks.* `eps_- F_3[<w,d,h>]` has dimension 8 and splits as `M_2(F_3) x M_2(F_3)`, so each block unit
    has `trl = 2 . 4/16 = 1/2`.
- *Part 3.* Census §7.2 defines `F` through `Phi = M_2(psi)`, followed by `M_2(T) ~= S_-` and the Morita
  identification `V(M_2(S_-)) = V(S_-)`.
  - For an idempotent matrix `p` over `S_-`, the Morita image of `[p]` is the class of `p (x) e_11`.
  - Its image under `Phi` is `psi(p) (x) e_11`.
  - The identification `M_2(T) ~= S_-` carries `T (x) e_11` onto a corner conjugate to `T`, so the result is algebraically
    equivalent to `psi(p)`.
  - So `F_*([p]) = [psi(p)]`, with entries in `T = e_- S_- e_-`. This matches `F(u) = [Phi(e_11) S_-] = [e_-]`.
  - *Lift.* Lift `p` to an idempotent `P` over `eps~_- c_0(G, Z_3)`, where `eps~_- = (1 - z)/2`. `delta` is an
    injective homomorphism with `delta(z) = z`, so `delta_*` is an isometric ring endomorphism of `c_0(G, Z_3)`. It
    preserves identity coefficients, and `delta_*(P)` lifts `delta_*(p)`.
  - *Commuting idempotent.* `e~_- = (1 - z)(1 + w)/4` is an idempotent of `Z_3[<z, w>]` lifting `e_-`. `w` commutes
    with every `delta(g)`: `w delta(g) = s0 g t1 + s1 g t0 = delta(g) w`. So `e~_- delta_*(P)` is an idempotent lifting
    `psi(p)`.
  - *Identity coefficient.* For `a = delta_*(P_ii)`, `(e~_- a)_1 = (a_1 - a_z + a_w - a_(zw))/4`.
    - `a_w = a_(zw) = 0`, because `M(w)` and `M(zw)` are off-diagonal and `M(delta(g)) = diag(g, g)`, where `M` is the
      matrix isomorphism `R -> M_2(R)`.
    - `a_z = (P_ii)_z = -(P_ii)_1`, because `eps~_- P = P` forces `b_(zg) = -b_g` for the entries `b`.
    - So `(e~_- a)_1 = (P_ii)_1 / 2`. Summing over `i` gives `t_3([psi(p)]) = t_3([p])/2`, and `s_3` is additive.
- *Part 4.* `alpha` is an automorphism of `G` with `alpha(z) = z`. It extends to `c_0(G, Z_3)` preserving identity
  coefficients and `eps~_-`. QED

**Corollary 1.2 (no equality relation).** If `sum_i n_i [p_i] = 0` in `K_0(S_-)` for finite-subgroup idempotent
matrices `p_i`, then `sum_i n_i trl(p_i) = 0`.

*Proof.* The left side is `s_3(0) = 0` in `Z_3`, the right side is a rational number, and `Q -> Q_3` is injective. QED

So `trl` is a well-defined homomorphism `H_fin(G) -> Q`. Every obstruction and every design has to work with
inequalities `[P] = [Q] + [X]`, in which `X` is an arbitrary projective.

**Corollary 1.3 (the witness class).** If `c e_- b = eps_-` in `S_-`, the idempotent `h = e_- - (e_- b)(c e_-)` has
`s_3([h]) = -1/2`.

*Proof.* Census Theorem A(a): `f = (e_- b)(c e_-) <= e_-` and `f ~ eps_-`, so `[e_-] = [eps_-] + [h]`. And
`s_3(e_-) = trl(e_-) = 2 . 1/4 = 1/2` over `<z, w>`. QED

## 2. When the lifted trace extends to a state

**Lemma 2.1 (relative states extend).** Let `A` be an abelian group with a cone `P` (closed under addition,
containing 0) and an order unit `u`: for every `x` some `n` has `nu - x` and `x + nu` in `P`. Let `L <= A` be a subgroup
containing `u`, and `f : L -> R` additive with `f(u) = 1` and `f >= 0` on `L ∩ P`. Then `f` extends to a state on
`(A, P, u)`.

*Proof.*
- *Zorn.* Order the pairs `(M, g)`, with `L <= M <= A` and `g` an additive extension of `f` that is `>= 0` on `M ∩ P`,
  by extension. Chains have unions, so a maximal pair exists. Suppose some `x` lies outside `M`.
- *Bounds.* Put `alpha = sup{ g(m)/k : m in M, k >= 1, kx - m in P }` and
  `beta = inf{ g(m')/k' : m' in M, k' >= 1, m' - k'x in P }`. Both sets are nonempty, witnessed by `m = -nu` and
  `m' = nu`. If `kx - m` and `m' - k'x` lie in `P`, then `k'(kx - m) + k(m' - k'x) = km' - k'm` lies in `M ∩ P`. So
  `g(m)/k <= g(m')/k'`, and `alpha <= beta`. Choose `gamma` in `[alpha, beta]`.
- *Extension.* Put `g'(m + jx) = g(m) + j gamma`.
  - *Well defined.* It suffices that `jx = m_0 in M` with `j > 0` forces `g(m_0) = j gamma`. Both `jx - m_0 = 0` and
    `m_0 - jx = 0` lie in `P`, so `beta <= g(m_0)/j <= alpha`.
  - *Positive.* Let `m + jx` lie in `P`. If `j = 0`, then `g(m) >= 0`. If `j > 0`, then `jx - (-m)` lies in `P`, so
    `g(-m)/j <= alpha <= gamma`. If `j < 0`, then `m - |j| x` lies in `P`, so `gamma <= beta <= g(m)/|j|`. In each
    case `g(m) + j gamma >= 0`.
- *Contradiction.* `(M + Zx, g')` extends `(M, g)`. So `M = A`, and `g` is a state. QED

**Theorem 2.2.**
1. `trl` extends to a homomorphism `H_fin(G) -> Q`, namely the restriction of `s_3`.
2. For every subgroup `L` with `u in L <= H_fin(G)`, `trl|_L` extends to a state on `(K_0(S_-), u)` iff `trl >= 0` on
   `L ∩ K_0^+`.
3. `(K_0(S_-), u)` admits a state iff `trl >= 0` on `H_fin(H) ∩ K_0^+`.
4. `ternary-anti-invariant-swap-corner-is-full` holds iff there are finite direct sums `P` and `Q` of projectives
   induced from finite subgroups of `H` (each containing `z`), a finitely generated projective `X` and `r >= 0` with

   ```text
   P (+) S_-^r ~= Q (+) X (+) S_-^r      and      trl(P) < trl(Q).
   ```

   A witness supplies `P = e_- S_-`, `Q = eps_- S_-` and `X = h S_-` (Corollary 1.3).

*Proof.*
- *Part 1.* Corollary 1.2.
- *Part 2.* A state extending `trl|_L` is nonnegative on `K_0^+`. Conversely apply Lemma 2.1 with `A = K_0(S_-)`,
  `P = K_0^+` and `f = trl|_L`, which is well defined by part 1 and has `f(u) = 1`.
- *Part 3.* Every state equals `trl` on the generators of `H_fin(H)`, by part 2 of
  `anti-central-k0-states-equal-lifted-trace-on-signed-thompson` with `Gamma = G`, hence on `H_fin(H)`. So it gives
  `trl >= 0` on `H_fin(H) ∩ K_0^+`. Conversely, part 2 with `L = H_fin(H)` gives a state.
- *Part 4.* By `twisted-leavitt-corner-fullness-equals-absence-of-k0-states`, the corner is full iff no state exists.
  By part 3 that happens iff some `x in H_fin(H) ∩ K_0^+` has `trl(x) < 0`. Write `x = [P] - [Q]` with `P` and `Q`
  collecting the positive and negative coefficients. Then `x in K_0^+` means `[P] = [Q] + [X]` for a projective `X`,
  which is the stable isomorphism displayed. QED

**Remark 2.3 (extending the whole lifted trace).** With `L = H_fin(G)`, part 2 says the lifted trace on all finite
subgroups of `G` extends to a state iff it is nonnegative on `H_fin(G) ∩ K_0^+`. Such a state can be averaged along
`F_*` and `alpha_*` (the halving and transpose artifacts) without leaving the set of states that equal `trl` on
`H_fin(G)`. The reason: `psi` sends an idempotent over `K` to one over the finite group `delta(K) <w>`, `alpha`
permutes finite subgroups, and Proposition 1.1 gives `trl o F_* = trl/2` and `trl o alpha_* = trl` there.

**Remark 2.4 (what a design must do).** A corner witness is a stable isomorphism `e_- S_- ~= eps_- S_- (+) X` in which
the complement `X` carries lifted trace `-1/2`. Part 4 says every failure of positivity has this shape, up to replacing
`e_-` and `eps_-` by sums of finite-subgroup projectives of `H`. The complement is where elements outside finite
subgroups enter.

## 3. Where positivity stands

**Remark 3.1 (finite-support lifts).** Let `D` be an idempotent matrix of size `n` over `Z_3[G]` with finite support,
reducing to an idempotent matrix `d` over `F_3[G]`. If `T(D)` is rational, it lies in `[0, n]`.

*Proof.* `D` is an idempotent lift over `c_0(G, Z_3)`, so `t_3([d]) = T(D)`. The entries of `D` generate a finitely
generated subfield `L` of `Q_3`, and some embedding `sigma : L -> C` fixes `Q`. `sigma(D)` is an idempotent matrix over
`C[G]`, so `T(sigma D)` is real and lies in `[0, n]` by Kaplansky's positivity theorem. If `T(D)` is rational, then
`T(D) = sigma(T(D)) = T(sigma D)`. QED

So the complement `X` in Theorem 2.2(4) has no finite-support idempotent lift, since its lifted trace is a negative
rational, and neither has `h` in Corollary 1.3. This is the positive-class counterpart of Theorem 8.1 of
`ternary-anti-central-kernel-normal-forms-2026-09-12.md`, which excludes finite-support lifts of defects.

**Remark 3.2 (power formula).** Let `d` be an idempotent matrix over `F_3[G]` and `x` any lift of it over
`c_0(G, Z_3)`. Then `T(x^(3^k)) = t_3([d])` modulo `3^(k+1)`.

*Proof.*
- *Expansion.* Write `x = D + 3y` with `D` an idempotent lift, and expand `x^N`, `N = 3^k`, into words in `D` and `3y`.
- *Orbits.* `T` is cyclic, so words in one rotation orbit have equal trace. A word with primitive period `3^j` has an
  orbit of `3^j` words.
- *Valuation.* If such a word has `b >= 1` letters `3y`, it is a power `v^(3^(k-j))`, so `b >= 3^(k-j)`. Its orbit
  contributes an element of `3^(j+b) Z_3`, and `j + b >= j + 3^(k-j) >= k + 1`.
- *Leading word.* The word `D^N` gives `T(D)`. QED

So `s_3` modulo `3^(k+1)` counts closed words of length `3^k` with multiplicities. That is arithmetic data: it detects
that a class is nonzero and carries no order.

**Remark 3.3 (the signed Thompson crossed product).** On `B = eps_- F_3[H] = C(M_-, F_3) x| V`, lift an idempotent
matrix `q` over the completion of `eps~_- Z_3[H]`. Fourier inversion identifies `eps~_- c_0(E, Z_3)` with
`C(M_-, Z_3)`, and the identity coefficient of `f` there is `(1/2) integral f d lambda`. So

```text
s_3([q]) = sum_i integral_(M_-) Ex(q~_ii) d lambda,
```

where `Ex` keeps the coefficient of `1` in `V`. On `K_0(B)` the lifted trace is Haar measure composed with the diagonal
expectation. It is a `Z_3`-valued trace with no order. Over `C` the same functional is the positive trace of the reduced
crossed product. That positivity is exactly what fails to transfer to characteristic three.

**Where it stops.**
- The existence of a state is now one positivity statement about one invariant, equivalent to the failure of the swap
  corner (`anti-central-lifted-trace-is-relatively-positive`).
- No mechanism is known that gives real positivity to traces of infinite-support `Z_3` idempotent lifts.
- The natural sources of positivity are the open gates: rank functions on `S_-`, or rank models of `G` moving `z`.
- No stable isomorphism that lowers the lifted trace is known either.

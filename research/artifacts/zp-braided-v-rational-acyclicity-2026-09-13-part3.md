# bV is rationally acyclic: part 3, configuration modules and assembly

Lane z2-09-bv-acyclic, 2026-09-13. Parts 1 and 2 hold Steps A and B.
Refereed 2026-09-16 by an agent panel. C1, C2, C4 and C6 were checked, and
Step D was corrected to use the filtration of part 1, A5–A6. Human expert
review is still recommended.

**Notation.**

- `C = {0,1}^N` is the Cantor set, with Thompson's group `V` acting.
- `C(X, Q)` is the space of locally constant `Q`-valued functions on a compact
  totally disconnected space `X`, and `C_c` means compact support.
- For `j ≥ 1`, `V` acts on `C^j` diagonally.
- `Conf_m(C)` is the space of ordered `m`-tuples of pairwise distinct points.
- A `V`-module `M` is **V-acyclic** if `H_p(V; M) = 0` for every `p ≥ 0`,
  including `p = 0`.

## Step C: from products of Cantor sets to configuration modules

**Lemma C1 (restriction).** Let `A ⊆ X` be closed. Restriction
`C(X, Q) → C(A, Q)` is surjective with kernel `C_c(X \ A, Q)`.

*Proof.* A function `f ∈ C(A, Q)` has finitely many values, and its level sets
are clopen in `A`. Each is `A ∩ W` for some clopen `W ⊆ X`. Disjointify the `W`'s,
extend `f` by its value on each `W` and by `0` elsewhere.

For the kernel: if `g` vanishes on `A`, then `{g ≠ 0}` is clopen in `X` and
disjoint from `A`, so `g` lies in `C_c(X \ A)`. Conversely, a compact open subset
of the open set `X \ A` is clopen in `X`, so extending by zero is locally
constant. ∎

**Lemma C2 (closed union).** For closed `A, B ⊆ X` the sequence
`0 → C(A∪B) → C(A) ⊕ C(B) → C(A∩B) → 0` is exact. The maps are
`f ↦ (f|_A, f|_B)` and `(g, h) ↦ g|_{A∩B} − h|_{A∩B}`.

*Proof.* The first map is injective. Functions agreeing on `A∩B` paste, by the
pasting lemma for a finite closed cover, into a continuous function to the
discrete group `Q`. The last map is surjective by C1. When `A` and `B` are
`V`-invariant all maps are `V`-equivariant. ∎

**Lemma C3 (Step B, part 2).** For every `j ≥ 1`, `C(C^j, Q)` is V-acyclic.

**Lemma C4 (fat diagonal).** For `m ≥ 2` let `D ⊆ C^m` be the union of the
diagonals `Δ_{ab} = {x_a = x_b}`. Then `C(D, Q)` is V-acyclic.

*Proof.* For a set `E` of pairs, `Δ_E = ∩_{e ∈ E} Δ_e` is `V`-equivariantly
homeomorphic to `C^j`: project to one coordinate per class of the equivalence
relation generated by `E`, so `j ≥ 1`. Prove by induction on `k` that the union
`Y` of any `k` sets `Δ_{E_1}, ..., Δ_{E_k}` has V-acyclic `C(Y, Q)`.

- `k = 1` is C3.
- For `k > 1`, write `Y = Y' ∪ Δ_{E_k}`. Then
  `Y' ∩ Δ_{E_k} = ∪_{i<k} Δ_{E_i ∪ E_k}` is a union of `k − 1` such sets.
- In the long exact homology sequence of C2, `H_p(V; C(Y))` sits between
  `H_{p+1}(V; C(Y' ∩ Δ_{E_k}))` and `H_p(V; C(Y')) ⊕ H_p(V; C(Δ_{E_k}))`,
  which vanish by induction and by C3. ∎

**Lemma C5.** For `m ≥ 1`, `C_c(Conf_m(C), Q)` is V-acyclic.

*Proof.* `Conf_m(C) = C^m \ D`, with `D = ∅` if `m = 1`. C1 gives
`0 → C_c(Conf_m(C)) → C(C^m) → C(D) → 0`. The middle term is V-acyclic by C3
and the right term by C4. Apply the long exact sequence. ∎

**Lemma C6.** For a finite-dimensional `Q[Σ_m]`-module `W`, the module
`C_c(Conf_m(C), Q) ⊗_{Q[Σ_m]} W` is V-acyclic.

*Proof.* It is `(C_c(Conf_m(C), Q) ⊗_Q W)_{Σ_m}`. The idempotent
`(1/m!) Σ_σ σ` commutes with `V`, since the two actions commute, so this is a
`V`-direct summand of `C_c(Conf_m(C), Q)^{⊕ dim W}`. Apply C5. ∎

## Step D: assembly

Let `K = ker(bV → V)`. Step A (part 1, A5) gives, for every `q ≥ 1`, a
finite filtration of `H_q(K; Q)` by `V`-submodules with graded pieces
`C_c(Conf_m(C), Q) ⊗_{Q[Σ_m]} W_{m,q}` for `q + 1 ≤ m ≤ 2q`, with `W_{m,q}`
finite-dimensional. (An earlier version claimed a direct-sum decomposition;
the 2026-09-16 referee panel showed that cabling does not preserve it, see
part 1, A3.) By C6 each graded piece is V-acyclic. By part 1, A6, so is each
`H_q(K; Q)` with `q ≥ 1`.

In the Lyndon–Hochschild–Serre spectral sequence
`E²_{p,q} = H_p(V; H_q(K; Q)) ⇒ H_{p+q}(bV; Q)`:

- every row `q ≥ 1` vanishes;
- row `q = 0` is `H_p(V; Q)`, which vanishes for `p ≥ 1` because `V` is
  integrally acyclic (Szymik–Wahl), so rationally acyclic by universal
  coefficients.

Hence `H_n(bV; Q) = 0` for all `n ≥ 1`. ∎

## What is missing for integral acyclicity

- Step A is integral. The Orlik–Solomon description of `H^*(Conf_n(C); Z)` is
  torsion-free, and part 1, A2–A6, is written over `Z`.
- C1, C2, C4 and C5 are integral once C3 is.
- C6 is integral by a different argument. The lexicographic order on
  `{0,1}^N` gives a clopen fundamental domain for the free `Σ_m`-action, so
  `C_c(Conf_m(C), Z)` is a free `Z[Σ_m]`-module. Tensoring it with a free
  resolution of `W` gives a resolution by sums of V-acyclic modules.
- Only C3 uses rational coefficients in an essential way (part 2). So integral
  acyclicity of `bV` follows from the single statement:
  **`C(C^j, Z)` is V-acyclic for every `j ≥ 1`** (open claim
  `cantor-power-function-modules-are-v-acyclic`).

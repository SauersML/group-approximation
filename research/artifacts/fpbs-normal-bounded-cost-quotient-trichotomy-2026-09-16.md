## 1. Conventions and elementary facts

All groups are countable. An action is always an essentially free p.m.p.
action on a standard probability space, ergodic or not. A group has *fixed
price one* when every such action has cost one. This property is invariant
under group isomorphism.

**Standing hypothesis (H).** `N` is an infinite group, and there is
`K < infinity` such that every free p.m.p. action of `N` has cost at most `K`.

For `N ◁ Gamma`:
- Write `pi : Gamma -> Q = Gamma/N`.
- Write `c_gamma` for the automorphism `u -> gamma u gamma^-1` of `N`.

**F1 (outer action).**
- **Definition.** `rho(pi(gamma)) = [c_gamma]` in `Out(N)` defines a
  homomorphism `rho : Q -> Out(N)`.
- **Proof.** `c_(gamma a) = c_gamma c_a`, and `c_a` is inner for `a in N`.
- **The outer kernel.** Write `Q_0 = ker rho`.
- **Restriction.** Let `A <= Q` and `Lambda = pi^-1(A)`. The outer action of
  `Lambda/N = A` on `N` is the restriction of `rho` to `A`, since conjugation
  by `lambda in Lambda` is the same automorphism of `N`. So its kernel is
  `A ∩ Q_0`.

**F2 (wq-normality).** The definition is that of
`fpbs-wq-normal-hull-is-almost-malnormal`. `H <= L` is wq-normal in `L` when
every proper subgroup `K` with `H <= K < L` admits some `g in L \ K` with
`g K g^-1 ∩ K` infinite.
1. **Overgroups of an infinite normal subgroup.** If `N ◁ Gamma` is infinite
   and `N <= Lambda <= Gamma`, then `Lambda` is wq-normal in `Gamma`.
   - Take any proper `K` with `Lambda <= K < Gamma` and any `g in Gamma \ K`.
   - Then `g K g^-1 ∩ K ⊇ g N g^-1 ∩ N = N`, which is infinite.
2. **Normal subgroups.** An infinite normal subgroup `H ◁ L` is wq-normal in
   `L`. The argument is the same, with `H` in place of `N`.

**F3 (amenability).** These are textbook closure properties.
- Abelian groups and locally finite groups are amenable. A countable locally
  finite group is an increasing union of finite subgroups.
- Subgroups of amenable groups are amenable.
- If `1 -> M -> E -> B -> 1` is exact with `M` and `B` amenable, then `E` is
  amenable.

**F4 (imported, established).** `fpbs-wq-normal-price-one-subgroup-forces-price-one`:
- If `H` is an infinite wq-normal subgroup of `Gamma` and `H` has fixed price
  one, then `Gamma` has fixed price one.
- As its stated consequence, every countable group with an infinite amenable
  wq-normal subgroup has fixed price one.

## 2. Lemma L: an infinite amenable subgroup of the outer kernel

**Lemma L.** Let `N` be an infinite normal subgroup of a countable group
`Gamma`. Suppose `Q_0 = ker(rho)` contains an infinite amenable subgroup `A`.
Then `Gamma` has fixed price one. No cost hypothesis is placed on `N`.

**Proof.** Let `Lambda = pi^-1(A)` and `C = C_Gamma(N) ∩ Lambda`.

1. **`pi(C) = A`.**
   - Let `gamma in Lambda`. Then `pi(gamma) in A <= Q_0`, so `c_gamma` is
     inner: there is `a in N` with `gamma u gamma^-1 = a u a^-1` for all
     `u in N`.
   - So `a^-1 gamma` centralizes `N`. It lies in `Lambda`, since `a in N <= Lambda`.
   - Also `pi(a^-1 gamma) = pi(gamma)`. So every element of `A` is the image
     of an element of `C`.
   - Conversely `pi(C) <= pi(Lambda) = A`.
2. **`C` is infinite and amenable.**
   - The kernel of `pi` restricted to `C` is `C ∩ N = C_Gamma(N) ∩ N = Z(N)`,
     which is abelian.
   - So `C` is an extension of `Z(N)` by `pi(C) = A`.
   - By F3 it is amenable. It is infinite because `A` is.
3. **`C ◁ Lambda`.**
   - For `lambda in Lambda`, `lambda C_Gamma(N) lambda^-1 = C_Gamma(lambda N lambda^-1) = C_Gamma(N)`,
     because `N ◁ Gamma`.
   - Also `lambda Lambda lambda^-1 = Lambda`.
4. **`Lambda` has fixed price one.** By F2.2, `C` is an infinite amenable
   wq-normal subgroup of `Lambda`. The consequence in F4 applies.
5. **`Gamma` has fixed price one.**
   - `Lambda ⊇ N` is infinite, and by F2.1 it is wq-normal in `Gamma`.
   - It has fixed price one by step 4. F4 gives the conclusion.

**Special cases.**
- **Semidirect products with finite-order outer class.** Let `phi in Aut(N)`
  have finite order `k >= 1` in `Out(N)`, with `N` infinite. Then
  `N semidirect_phi Z` has fixed price one.
  - `Q = Z` is generated by the image of `t`, and `rho(t^j) = [phi]^j`.
  - So `Q_0 = kZ`, which is infinite cyclic.
- **Infinite outer kernel with locally finite quotient.** If `Q` is locally
  finite and `Q_0` is infinite, then `Gamma` has fixed price one.

## 3. Proposition R: the quotient trichotomy

**Proposition R.** Assume the three open claims:
- **(Z')** `fpbs-bounded-cost-outer-cyclic-extension-price-one`. If `N`
  satisfies (H) and `phi in Aut(N)` has infinite order in `Out(N)`, then
  `N semidirect_phi Z` has fixed price one.
- **(LF')** `fpbs-bounded-cost-locally-finite-outer-price-one`. If
  `N ◁ Gamma` satisfies (H), `Q` is infinite locally finite and `Q_0` is
  finite, then `Gamma` has fixed price one.
- **(T')** `fpbs-bounded-cost-fg-torsion-quotient-price-one`. If `N ◁ Gamma`
  satisfies (H), `Q` is infinite, finitely generated and torsion, and `Q_0`
  contains no infinite amenable subgroup, then `Gamma` has fixed price one.

Then `fpbs-normal-subgroup-bounded-cost-fixed-price-one` holds.

**Proof.** Let `N ◁ Gamma` satisfy (H), with `Q` infinite.

**Case 0.** Suppose `Q_0` contains an infinite amenable subgroup. Then Lemma L
concludes. From now on assume it contains none.

**Trichotomy.** The infinite group `Q` satisfies exactly one of the following.
- (a) `Q` has an element of infinite order.
- (b) `Q` is torsion, and every finitely generated subgroup of `Q` is finite.
  That is, `Q` is locally finite.
- (c) `Q` is torsion and has an infinite finitely generated subgroup.

**Case (a).** Let `q in Q` have infinite order.
1. **`<q> ∩ Q_0 = 1`.** Otherwise `q^k in Q_0` for some `k != 0`. Then
   `<q^k>`, which is isomorphic to `Z`, would be an infinite amenable subgroup
   of `Q_0`.
2. **`Lambda = pi^-1(<q>)` is a semidirect product.**
   - Pick `gamma in pi^-1(q)` and put `phi = c_gamma` restricted to `N`, an
     element of `Aut(N)`.
   - Define `N semidirect_phi Z -> Lambda` by `(u, k) -> u gamma^k`. The
     product is `(u,k)(u',k') = (u phi^k(u'), k+k')`.
   - It is a homomorphism, because
     `u gamma^k u' gamma^k' = u (gamma^k u' gamma^-k) gamma^(k+k') = u phi^k(u') gamma^(k+k')`.
   - It is onto. If `pi(lambda) = q^k`, then `lambda gamma^-k in N`.
   - It is injective. If `u gamma^k = 1`, then `q^k = pi(gamma^k) = 1`, so
     `k = 0` and `u = 1`.
3. **`phi` has infinite order in `Out(N)`.** `[phi]^k = rho(q^k)`, which is
   nontrivial for `k != 0` by step 1.
4. **Conclusion.** `N` satisfies (H), so (Z') gives `Lambda` fixed price one.
   `Lambda ⊇ N` is infinite and wq-normal in `Gamma` by F2.1, so F4 gives
   `Gamma` fixed price one.

**Case (b).**
- `Q_0 <= Q` is locally finite, hence amenable by F3.
- It contains no infinite amenable subgroup, so it is finite.
- `N ◁ Gamma` satisfies (H), and (LF') concludes.

**Case (c).** Let `A <= Q` be infinite, finitely generated and torsion, and
put `Lambda = pi^-1(A)`.
- `N ◁ Lambda` satisfies (H), and `Lambda/N ≅ A`.
- By F1 the outer kernel of `Lambda/N` is `A ∩ Q_0`, which has no infinite
  amenable subgroup.
- (T') gives `Lambda` fixed price one. F2.1 and F4 give `Gamma` fixed price
  one. ∎

**Converse.** Each of (Z'), (LF') and (T') is a special case of the target.
- In (Z') the quotient of `N semidirect_phi Z` by `N` is `Z`, which is
  infinite.
- In (LF') and (T') the hypotheses contain those of the target.

So the target is equivalent to the conjunction of the three claims. This is
recorded as a single route. The trivial converse implications are not added
as routes.

## 4. The 3-manifold route needs only (Z')

**Claim.** (Z'), Lemma L and `fpbs-fibered-3-manifold-cost-inputs` imply
`fpbs-hyperbolic-3-manifold-groups-fixed-price-one`.

**Proof.** Let `M` be a closed hyperbolic 3-manifold, and `Gamma = pi_1(M)`.
1. **Fibered cover.** By item 1 of the inputs, a finite cover `M'` fibers over
   the circle with closed fiber `S` of genus `g >= 2`.
   - `Gamma' = pi_1(M')` has finite index in `Gamma`.
   - `Gamma' ≅ N semidirect_phi Z`, where `N = pi_1(S)` is the normal fiber
     subgroup and `phi` is the monodromy.
2. **(H) holds.** `N` is infinite. By item 2 it has fixed price `2g-1`, so (H)
   holds with `K = 2g-1`.
3. **`Gamma'` has fixed price one.**
   - If `[phi]` has infinite order in `Out(N)`, (Z') applies.
   - If `[phi]` has finite order, the first special case of Lemma L applies.
4. **Transfer.**
   - Let `Gamma` act freely p.m.p. on `X`. The restriction to `Gamma'` is free
     and p.m.p., so it has cost one.
   - By item 3 of the inputs (commensurated transfer, finite index), the cost
     of the `Gamma` action is at most that of its `Gamma'` restriction, which
     is `1`.
   - The orbits are infinite, so the cost is at least one. ∎

This premise set is strictly weaker than that of
`fpbs-hyperbolic-3-manifold-fixed-price-via-normal-subgroup`, which needs the
full target.

## 5. The Burnside route needs only (T')

**Claim.** Assume (T'), `fpbs-burnside-normal-closure-split`,
`fpbs-burnside-common-upper-cost` and `fpbs-burnside-embedding-input`. Then
`fpbs-burnside-upper-cost-one` follows.

**Proof.** Fix odd `n` in the common range of the premises, and `m >= 3`. Let
`G = B(m,n)` with free generators `x_1, ..., x_m`, and let `N` be the normal
closure of `x_1`.
1. **The split.** By the split claim:
   - `N` is infinite;
   - `G = N semidirect H` with `H ≅ B(m-1,n)`;
   - `G/N ≅ B(m-1,n)`, which is infinite.

   Moreover `B(m-1,n)` is generated by `m-1` elements and has exponent `n`, so
   `Q = G/N` is infinite, finitely generated and torsion.
2. **(H) holds.** By the common-upper-cost claim, every free p.m.p. action of
   the infinite subgroup `N` has cost at most `c_n <= 2 - 2/n`. So (H) holds
   with `K = 2`.
3. **The outer kernel is finite.**
   - Step 1 of Lemma L, applied with `A = Q_0`, gives `Q_0 <= pi(C_G(N))`.
   - Elements of `C_G(N)` act trivially on `N`, so `pi(C_G(N)) <= Q_0`. Hence
     `Q_0 = pi(C_G(N))`.
   - `x_1` is a nontrivial element of `N`, so `C_G(N) <= C_G(x_1)`.
   - By the embedding input, `C_G(x_1)` is cyclic. In a group of exponent `n`
     a cyclic subgroup has order dividing `n`.
   - So `Q_0` is finite and contains no infinite subgroup at all.
4. **`G` has fixed price one.** (T') applies, so `C^*(G) = 1`.
5. **Conclusion.** The common-upper-cost claim identifies `c_n` with
   `C^*(B(m,n))`. So `c_n = 1`, which is `fpbs-burnside-upper-cost-one` in
   that range, exactly as in step 4 of
   `fpbs-burnside-upper-cost-one-via-normal-closure`. ∎

## 6. Remarks

1. **(LF') is vacuous for many `N`.**
   - Suppose every locally finite subgroup of `Out(N)` is finite. Then
     `rho(Q)` is finite for locally finite `Q`, so `Q_0` has finite index in
     `Q`. An infinite `Q` then has infinite `Q_0`.
   - This holds when `Out(N)` is virtually torsion-free. Let `T` be a
     torsion-free normal subgroup of finite index. A torsion subgroup `P`
     meets `T` trivially, so it embeds in `Out(N)/T`.
   - Standard examples, **not re-verified in this session**: `Out(F_n)` and
     the extended mapping class group of a closed surface.
   - For these `N`, the target restricted to locally finite quotients holds
     by Lemma L alone.
2. **Two more assumptions cost nothing.** In the target one may assume that
   `N` does not have fixed price one, and that `Gamma` has no infinite
   amenable wq-normal subgroup. Otherwise F4 already concludes.
   - For example, both `Z(N)` and the amenable radical of `N` may be assumed
     finite, since they are characteristic in `N` and hence normal in `Gamma`.
3. **Where the reduction stops.** (Z') contains every fibered hyperbolic
   3-manifold group (Section 4), and (T') contains the free Burnside groups
   (Section 5). Neither is resolved here.

## 1. Products with a factor in the LEF permanence closure (w3-products, `df56c017aa`)

Verdict: **PASS**, with one wording point on Corollary 2 whose missing argument is supplied in 1.4.

### 1.1 `finitary-split-structures-pass-to-direct-products` (Lemma 1). PASS.

The axioms checked are those of Theorem 0 in `finitary-split-extension-surjunctivity-2026-09-11.md`: (D),
(D') with transitivity `iota_(V,S) = iota_(U,S) iota_(V,U)`, (A1), (A2) for all `g` and `U ⊆ S`, (A3).
Put `S_i = S ∩ X_i`.

- **(D), (D').** `p^1_(S_1) x p^2_(S_2)` is onto a product of residually finite groups, and `N_∅ = 1 x 1`.
  The product embeddings are injective and transitive coordinatewise.
- **(A1).** For `n_j = (a_j, b_j) != 1`, detect the nontrivial `a_j` by `S_1` and the nontrivial `b_j` by
  `S_2` (take the empty set when there are none). Each `p_S(n_j)` keeps a nontrivial coordinate.
- **(A2).** `L(a,b) = L_1(a) ⊔ L_2(b)`. Since `(g_1,g_2)` acts on `X_i` through `g_i`,
  `gL = g_1 L_1(a) ⊔ g_2 L_2(b)` and `S∖U = (S_1∖U_1) ⊔ (S_2∖U_2)`. So `gL` misses `S∖U` iff each
  coordinate misses its part, and both (A2) identities hold at once.
- **(A3).** `(k_1,k_2)` fixes `S` pointwise iff `k_i` fixes `S_i` pointwise, so invariance is coordinatewise.
- **Special case.** `N = 1`, `X = ∅` is a finitary structure on any `G`: only `S = ∅` exists and (A1) is
  vacuous. The product with `N ⋊ B` is `N ⋊ (G x B)` with `G` acting trivially on the sites, and Theorem 0
  gives `G x (N ⋊ B)` surjunctive iff `G x B` is.

### 1.2 Theorem B′ (a)–(d). PASS.

- **(a), (b).** The LEF product theorem, and heredity through `G x K' ≤ G x K`.
- **(c).** Let `F ⊆ G x K` be finite and `F_K` its projection. A partial-table embedding `psi` of a finite

### 1.3 Theorem B′ (e), the graph-fold step. PASS.

Let the graph of groups have vertex groups `Q_v`, edge groups `Q_e`, edge maps `alpha_e`, `omega_e`, and
maximal tree `T`. Let `E` be the fundamental group of the graph with vertex groups `G x Q_v`, edge groups
`G x Q_e`, and edge maps `id x alpha_e`, `id x omega_e` (injective).

- **All copies of `G` coincide.** For `e` in `T` the relation identifies `(g, alpha_e c)` with
  `(g, omega_e c)`. With `c = 1` the copies `G x 1` of adjacent vertices agree, and `T` is connected. Call
  the common subgroup `G_0`.
- **Centrality.** For `e` outside `T`, `t_e (g,1) t_e^-1 = (g,1)`, and `G_0` is central in each vertex
  group. `E` is generated by vertex groups and stable letters, so `G_0` is central.
- **Quotient.** Adding `(g,1) = 1` in every vertex group turns the presentation of `E` into that of `Q`.
- **Retraction.** `(g,c) -> g` on vertex groups and `t_e -> 1` respects the vertex, edge and tree
  relations. So `r: E -> G` is a homomorphism, it is the identity on `G_0`, and `G_0 ≅ G`.
- **Splitting.** `e -> (r(e), e G_0)` is a homomorphism. Its kernel is `G_0 ∩ ker r = 1`. It is onto,
  because `x g_0` with `r(g_0) = r(x)^-1 g` has image `(g, x G_0)`. Under it the vertex group `G x Q_v`
  maps to `G x Q_v` identically.
- **Fold.** `id x f` is injective on each `G x Q_v` iff `f` is injective on `Q_v`. `G x K` is surjunctive,
  so `graph-folds-over-surjunctive-groups-are-surjunctive` makes `E ≅ G x Q` surjunctive.

### 1.4 Corollaries and instances. PASS, one wording point.

- **Corollary 1.** Induction over the construction of `Cl(LEF)`. Each operation keeps membership in

- **Corollary 2, surjunctivity.** `P(1)` is the class of surjunctive groups. For `K_1, K_2` in `Cl(LEF)`,
  `K_1` is surjunctive and `K_2` lies in `P(K_1)`, so `K_1 x K_2` is surjunctive. This is what the proof

- **Corollary 2, membership (the wording point).** The claim also says `Cl(LEF)` "is closed under finite

  membership statement is true, by the same induction over `K_2` with `K_1` in `Cl(LEF)` fixed:

- **Kun–Thom instances.** The wreath `W` (instance I1) and the double `D` (instance I2) are finitary over

  - finitary kernels are residually finite by (A1), so (d) is an extension inside `D_Sigma`;
  - (e) has vertex groups embedded in members.
  So the product question is open only when both factors lie outside `Cl(LEF)`, as the node says.

## 2. A strict automaton skews a single-site law (w3-inf-a, `d79393a27b`)

Verdict: **PASS** for `strict-automata-give-injective-ca-with-skewed-site-marginals`, Theorem 2 and

### 2.1 Step 1, greedy placement. PASS.

`S` avoids `p`, so `|S| <= q^|Omega| - 1`, and every atom has positive mass (preimages of cylinders are
nonempty open sets). The classes `C_a` have `N = q^(|Omega|-1)` elements. With atoms listed by
nonincreasing mass:

- `|S| < N`: everything sits in `C_(a_1)`;
- `N <= |S| <= (q-1)N`: `C_(a_q)` is empty;
- `|S| > (q-1)N`: `C_(a_q)` holds `|S| - (q-1)N <= N - 1` atoms, each of index above `N`, so of mass at most
  `nu(s_N)`. Hence `lambda(a_q) <= (N-1) nu(s_N) < N nu(s_N) <= lambda(a_1)`, strictly because
  `nu(s_N) > 0`.

In all three cases `lambda` is not uniform, and `c = log q - H(lambda) > 0`.

### 2.2 Step 2, anchors. PASS.

`D = Omega Omega^-1` is finite, symmetric and contains `e`. For anchors `g != h` with `g^-1 h = d` in `D`,
`d != e`, so `z(h) = z(gd) = 0` contradicts `z(h) = 1`. If `g omega = h omega'` then `g^-1 h` lies in `D`.
So blocks of distinct anchors are disjoint. When `|Omega| = 1` the blocks are singletons, and nothing
changes.

### 2.3 Steps 3 and 4, the automaton and its left inverse. PASS.

- **Well defined.** A site lies in at most one anchored block, so `h` and `omega = h^-1 g` are unique. The
  block pattern of `y_j = tau(x_j)` on `h Omega` is the pattern of `tau(h^-1 . x_j)` on `Omega`, so it
  lies in `S` and `beta` applies.
- **Finite memory.** `kappa` reads `x_0` on `g Omega^-1 D` and `x_j` on `g Omega^-1 Omega M`, and the
  definition is translation invariant.
- **Left inverse.**
  1. Track 0 gives `x_0` and its anchors.
  2. The pattern of `z_j` on a block is `beta` of the pattern of `y_j`, so `beta^-1` recovers `y_j` there,
     with `beta^-1` extended arbitrarily off `beta(S)`. Off the blocks `z_j = y_j`.
  3. `sigma` gives `x_j`.
  Each step reads a finite window and is equivariant, so `kappa` has an automaton left inverse.

### 2.4 Step 5, the entropy bound. PASS.

- **Anchor probability.** `I = 1` fixes `|D|` distinct sites of `x_0`, so `P(I = 1) = q^(-|D|) = rho`.
- **Chain rule.** `H(kappa(x)(e)) <= H(x_0(e)) + H(I) + H(y'(e) | I)`, with `H(I) <= log 2`.
- **Given `I = 0`.** The bound `k log q` holds whatever recoding happens at `e`.
- **Given `I = 1`.** The event depends on `x_0` only, so `x_1, ..., x_k` stay i.i.d. uniform. `e` is the
  `omega_0`-point of the block of `omega_0^-1`, and each `y'_j(e)` is a function of `x_j` alone. By shift
  invariance each has law `lambda`, independently, so the conditional entropy is `k H(lambda)`.
- **Total.** `log q + log 2 + (1 - rho) k log q + rho k H(lambda) = (k+1) log q + log 2 - rho k c`.

## 1. The k-graph model (17.61 node, "The k-graph" and "Properties")

- **Unique factorization.** Λ = {(m,r) : m P'-smooth, 0 ≤ r < m} with (m,r)(m',r') = (mm', r + mr') and
  d(m,r) = (v_p(m))_{p∈P'}. If m = m_a m_b, then r ≡ r_1 mod m_a forces r_1 = r mod m_a and
  r_2 = (r − r_1)/m_a < m_b. So Λ is a one-vertex k-graph (k = |P'|), finite, with |Λ^{e_p}| = p. **PASS.**
- **Boundary.** An infinite path x: Ω_k → Λ is the compatible system x(0,n) = (∏p^{n_p}, r_n), so
  Λ^∞ ≅ lim Z/m = Ẑ_{P'}. The cylinder λΛ^∞ with λ = (m,r) is r + mẐ = B(r,m). The bisection Z(λ,μ) acts by
  r_μ + m_μ z ↦ r_λ + m_λ z, the canonical box map, which is the class-transposition rule on Z. **PASS.**
- **Effective.** Let W be an open subset of Z(λ,μ) lying in the isotropy. Then the affine map κ_{λμ} is the
  identity on s(W), so m_λ = m_μ (hence d(λ) = d(μ)) and r_λ = r_μ, i.e. λ = μ. So the interior of the
  isotropy is the unit space. Hausdorff: two canonical maps agreeing on an open set are equal. **PASS.**
- **Minimal:** clear.
- **Purely infinite minimal, in Matui's Prop. `pim`(2) form** (read at source, line 1245): given U = ⊔B_i and
  a box B ⊆ V, split B into disjoint sub-boxes C_i and take ⊔κ_i. This is also Li's definition (2209.08087,
  §2), which gives comparison. **PASS.**

## 2. CT_P(Z) ≤ F and CT_P(Z) ⊴ F (proof steps 1–2)

- **Class transpositions lie in F.** τ = κ ⊔ κ^{-1} ⊔ id on U ⊔ V ⊔ rest, with U, V disjoint boxes. **PASS.**
- **Normality.**
  - For g ∈ F, gτg^{-1} is the involution that swaps g(U) and g(V) via g κ g^{-1}.
  - A product of compact open bisections is a finite union of basic ones, so g(U) = ⊔C_j with gκg^{-1}
    canonical on each box C_j, onto a box D_j ⊆ g(V).
  - The D_j are disjoint and disjoint from g(U). So gτg^{-1} = ∏_j τ_{C_j,D_j}, and each factor is a class
    transposition with P'-smooth moduli.

  **PASS.**

## 4. Item 3 and the 17.59 node

- **Item 3.** An element of F is a homeomorphism given by a compact open bisection with full source and range,
  i.e. a finite disjoint union of basic bisections. So it is piecewise canonical from one box partition onto
  another. Boxes meet Z in residue classes, and Z is dense, so restriction to Z is faithful. That is exactly
  item 3. **PASS.**
- **17.59 (⊆).** τ sends r1 + tm1 to r2 + tm2 with the same t, and t ≥ 0 iff the point is ≥ 0. **PASS.**
- **17.59 (⊇)**, re-derived:
  1. **Positive slopes.** A negative slope sends a positive tail to negatives.
  2. **Images are classes.** The image of r_i(m) is a progression with integer difference
     n_i = a_i m / c_i > 0 (a difference of integers), i.e. a class s_i(n_i). These partition Z.
  3. **Zero shift.** From g(r_i) = s_i + c n_i: t = 0 forces c ≥ 0, and t = −1 (a negative point) forces
     c ≤ 0.
  4. **Conclusion.** With P = odd primes dividing m∏n_i, g has the item-3 form, so g ∈ CT_P(Z) ⊆ CT(Z).

  **PASS.**
- **For 17.57, CT(Z) = [[G]] on Ẑ = ∏_{all p} Z_p.**
  - A canonical map with P'-smooth moduli lifts to Ẑ by the same formula, and agrees with its action on Z.
  - So [[G]] = ⋃_P CT_P(Z) as permutation groups of the dense orbit Z.
  - By 17.59 this is CT(Z).

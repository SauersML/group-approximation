# Laurent adjugate certificates and amenable coefficient supports

Date: 2026-09-08. Exact finite-tensor obstructions; no computation is used.
No actor in this artifact passes the complete exterior-square source
test, and no group-ring inverse or headline solution is claimed.

Use the complete source, target, and operator `Phi_g` from
[the two-sector artifact](kaplansky-full-two-sector-relative-transporter-obstruction-2026-09-08.md).
The first argument below gives a literal Laurent-polynomial kernel.
The second gives an independent quantitative dimension obstruction
and covers noncommutative amenable coefficient groups as well.

## 1. Laurent coefficients on an infinite regular module

Let the binary tail space be `B=F_2[z,z^-1]`, and let

```
a,b ∈ GL_2(F_2[z,z^-1]),       g=diag(a,b).
```

The chart `K=GL_2(F_4)` acts constantly on the four binary root
coordinates, as before. These matrices act on `B^4` by multiplication
in the Laurent coefficients, giving an actual representation of the
matrix subgroup generated by `K,g`.

After scalar extension, all character blocks `A,B,C,D` are scalar
multiplications by Laurent polynomials over `F_4`. Use two independent
variables to identify the tensor space:

```
B_4 tensor_(F_4) B_4 = R=F_4[z,z^-1,w,w^-1],
z^i tensor z^j <-> z^i w^j.
```

Let `tau` exchange `z,w`, and let `sigma` conjugate only the field
coefficients. These are distinct involutions.

For a finite Laurent polynomial `f=sum f_ij z^i w^j`, the coefficient
of `z^i wedge z^j`, `i<j`, in `alt(f)` is `f_ij+f_ji`. Every diagonal
coefficient is annihilated. Consequently, in characteristic two,

```
alt(f)=0  iff  tau(f)=f.                              (1)
```

This includes arbitrary diagonal terms; it does not incorrectly
replace the kernel of `alt` by the image of `1+tau`, which would omit
those diagonal terms.

Define the polynomial matrix

```
M=[[p,q],[r,s]],
p=C(z)A(w),             q=D^sigma(z)B^sigma(w),
r=D(z)B(w),             s=C^sigma(z)A^sigma(w).
```

The complete exterior operator satisfies

```
Phi_g(X,Y)=0
  iff both entries of M (X,Y)^T are tau-invariant.     (2)
```

## 2. Explicit finite certificate in every determinant case

Put `delta=ps+qr=det M`. All products here are in the commutative
integral domain `R`.

If `delta!=0`, take

```
(X,Y)^T=tau(delta) (s,r)^T
       =tau(delta) adj(M) (1,0)^T.                    (3)
```

The column `(s,r)^T` is nonzero, since otherwise `delta=0`, and
`tau(delta)!=0`. The domain property therefore makes (3) nonzero.
Direct multiplication gives

```
M (X,Y)^T=(delta tau(delta),0)^T.
```

Both coordinates are fixed by `tau`; the first is fixed because
the coefficient ring is commutative. Equations (1)–(2) show that
(3) is an exact nonzero kernel of the full operator.

If `delta=0` and `(r,s)!=(0,0)`, take `(X,Y)=(s,r)`; then
`M(X,Y)^T=(0,0)^T`. If the second row is zero but the first row is
nonzero, take `(X,Y)=(q,p)`. If `M=0`, take `(X,Y)=(1,0)`.
These alternatives exhaust all matrices and each supplies a
nonzero finite Laurent tensor kernel.

Under the injective complete-source identification, the tensor pair
gives the nonzero exterior vector `k_+(X)+k_-(Y)`, fixed by `f_0` and
killed by `P_0[g]f_0`. Here `k_+(X)` denotes the linear extension of
`k_+(xi,eta)` from simple tensors, and similarly for `k_-`.

Thus **every** Laurent block-diagonal transporter in Section 1 has
an explicit source kernel. Injectivity of its individual character
blocks, or of the relative blocks from the earlier criterion, cannot
make this Laurent family pass the complete test.

The same proof works over Laurent polynomials in any finite number
of commuting variables: take two copies of that variable set and
exchange them with `tau`. It remains a finite algebraic certificate.
No quotient specialization, infinite series, or finite-dimensional
invariant tail module is used.

## 3. A quantitative finite-support obstruction

Return to arbitrary binary-linear `a,b` on a tail space, with the
eight character operators

```
A,B,C,D,A^sigma,B^sigma,C^sigma,D^sigma.
```

Let `U` be any nonzero finite-dimensional `F_4` tail subspace, of
dimension `m`. Let `W` be a finite-dimensional tail space containing
the images of `U` under all eight operators, and put `n=dim W`.

The complete source over `U` has dimension `2m^2`. Every term of its
image under `Phi_g` lies in

```
(Lambda^2 W)_+ direct-sum (Lambda^2 W)_-,
```

whose dimension is `2 binom(n,2)=n(n-1)`. Hence the restricted kernel
has dimension at least

```
2m^2-n(n-1).                                          (4)
```

Whenever this quantity is positive, it supplies an actual nonzero
finite tensor source kernel. Neither `U` nor `W` has to be invariant
under either chart, the transporter, or the subgroup they generate.
This is a map between two different finite-dimensional spaces,
not an assumed finite-dimensional representation of that subgroup.

Conversely, passing the complete exterior-square source test requires
`n(n-1)>=2m^2` for every such nonzero input space and its output span.
The strict dimension inequality alone proves a kernel; the reversed
inequality alone does not prove injectivity.

## 4. Every amenable coefficient-group family fails

Let `Lambda` be a group and take the tail space `B=F_2[Lambda]` with
the left regular action. Suppose

```
a,b∈GL_2(F_2[Lambda]).
```

This statement concerns the actual matrix group over this coefficient
ring and its regular module. An unrelated representation of `Lambda`
whose group-algebra map has additional relations is not silently
substituted for the regular module.

Choose a finite set `S⊂Lambda` containing the identity and all group
supports of the eight character blocks. For any nonempty finite
`F⊂Lambda`, put

```
U=span_(F_4) F,       W=span_(F_4)(SF).
```

Then `m=|F|`, `n=|SF|`, and all required coefficient images lie in
`W`. A finite set satisfying

```
|SF|(|SF|-1)<2|F|^2                                  (5)
```

therefore proves a source kernel. In particular the simpler bound
`|SF|/|F|<sqrt(2)` suffices.

If `Lambda` is amenable, its Følner property supplies such a finite
set for every fixed `S`: choose `epsilon` with
`0<epsilon<sqrt(2)-1` and require
`|SF|<(1+epsilon)|F|`. The characterization used here is recorded
as Proposition 2.1 in Kropholler–Lorensen,
[*Group-graded rings satisfying the strong rank condition*](https://arxiv.org/pdf/1901.10001).
Only this finite-set property is needed for the conclusion.

Consequently every block-diagonal transporter over the regular
group-algebra module of an amenable coefficient group fails the
complete exterior test. This includes infinite groups and does not
require a finite-dimensional invariant submodule. It also does not
assert that the matrix subgroup `〈K,g〉` itself is amenable.

In either the Laurent or amenable-coefficient setting, a hypothetical
identity `L P_0[g]f_0=f_0` contradicts the resulting source kernel
in this actual subgroup representation. Conditional expectation
onto the subgroup algebra deals with `L` allowed in a larger ambient
group algebra. None of the arguments constructs a split for more
general coefficient operators or decides all fully mixed
block-diagonal transporters.

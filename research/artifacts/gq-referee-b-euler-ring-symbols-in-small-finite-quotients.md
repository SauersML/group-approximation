## Dennis–Stein inputs (read at source)

- **(S1)–(S4), p. 249, §9(a).** "If R is a commutative ring and n ≥ 3, these symbols satisfy the identities listed
  below. (S1) {uv,w} = {u,w} {v,w}, {u,vw} = {u,v} {u,w} (S2) {u,v} = {v,u}^(-1) (S3) {u,−u} = 1 (S4) {u,1−u} = 1".
  - The symbols are elements of `St(n,R)` lying in `K_2(n,R)`, so the identities hold **unstably**, for every
    `n ≥ 3`. This answers the lane's question.
  - The page adds that all elements involved must be units. Every use checks this: `t` and `1 − t`, `1 − t e^a`,
    and `1 − t'y`.
- **(St), p. 252, §10.**
  - §10(a)(i): "The Steinberg symbols generate K_2(n,R) for n ≥ 3 if R is a commutative semi-local ring [90, Theorem
    2.7]."
  - §10(b): "If J is an ideal contained in the Jacobson radical of the commutative ring R, then K_2(n,J) is generated
    by the elements ⟨a,q⟩, a ∈ R, q ∈ J, for all n ≥ 3 [90, Theorem 2.1]. Note that if R is additively generated by
    its units, then [...] K_2(n,J) is actually generated by Steinberg symbols of the form {u,1+q}, u ∈ R*, q ∈ J, a
    result proved earlier by Stein [89]."
  - In that section, `K_2(n,J)` is defined as `ker(K_2(n,R) → K_2(n,R/J))`.
  - **W1.** The route's (St) says "`J` ... additively generated by units". The source requires **`R`** to be
    additively generated by its units, with `J` in the radical.
  - Both uses meet the correct hypothesis. `O_K` and `C_r` are local, and a local ring is additively generated by
    units: for `a ∈ 𝔪`, `a = (a − 1) + 1`. Fix the wording.
- **(DS12), p. 254.** "Let A be a discrete valuation ring with finite residue field of characteristic p [...] Then
  K_2(A/P^m) is a cyclic p-group of order p^t where t = [m/e − 1/(p−1)]_[0,r] with p^r denoting the order of the
  p-component of the roots of unity in the completion of A in the P-adic topology [27, Theorem 4.3]."
  - **Application to `O_K`, `K = Q_l(ζ_l)`.**
    - `e = l − 1`, and `r = 1`, since `Q_l(ζ_{l^2})` has degree `l(l−1) > l − 1`.
    - `m = n ≥ l + 1` gives `(n−1)/(l−1) > 1`, so `t = 1` and the group is `Z/l`.
  - **Match.**
- **`K_2(N, Z/l^r) = 0`, l odd, N ≥ 3, pp. 255–256.** The citation is correct as given.
  - p. 255: "(ii) K_2(W_m(F_q)) = 1 if p is odd or if m = 1". This is the stable group.
  - p. 256, §14: the stability maps "are known to be isomorphisms [...] (iii) R is a discrete valuation ring or a

- **`K_2(N, O_K/𝔭^n) = K_2(O_K/𝔭^n)`.** This follows from the same p. 256 (iii).

## Steps checked

- **Part 1, `l` odd.**
  - The Fermat-quotient reduction gives `χ(s) = z^(−L(s))`.
  - From (S4), `E ≡ −(tL(t) + (1−t)L(1−t))/(1−t) ≡ P(t)/(1−t)`, using `binom(l,k)/l ≡ (−1)^(k−1)/k`.
  - `P(0) = P(1) = 0` and `deg P = l − 1`, so an admissible `t_0` exists. For `l = 3`, `P(2) = 1`.
  - `π_q ↦ (1+y)(1+ql)`.
  - For `l = 2`, `3 + y = −(1+y)`.
  - `A → C` is well defined, because each `1 + kl + y` is a unit.
- **Part 2.**
  - Surjectivity uses local rings, generation by symbols, and lifting of units.
  - The kernel is generated by `{v, 1+w}` with `w ∈ 𝔭^n`, which (Lv) kills.
  - In the trace, `Tr(ζ^(−1)) = −1`, and `v_l(l^(k−1)/k) ≥ 1` for `k ≥ 2`, `l ≥ 3`.
- **Part 3.**
  - `φ_(i+1) = φ_i ∘ σ` makes `ρ_m` a ring map.
  - Each diagonal factor has value `ζ^(−(i+q)) ζ^i = ζ^(−q)`. The cross term dies because `2(l−1) > l`.
  - `v_𝔭(ml) = (l−1)(1 + v_l(m)) ≥ l + 1` forces `l | m`.
- **Part 4, `r ≤ l − 1`.**
  - *The image ring.* The binomial-basis argument gives `C_r = Z[u]/(l,u)^r`, using that `k!` is a unit for
    `k ≤ r − 1`. The residues `j mod l^(r−1)` all occur, since `N` is a multiple of `l^(r−1)`.
  - *Bilinear form.* Truncated `exp` and `log` are valid. `β` is alternating because `{x,x} = {x,−1}` has odd `l`-power
    order.
  - *Coefficient extraction.* The Vandermonde step is legitimate, since `β` takes values in an `l`-power torsion group
    (`β(a, l^r b) = 0`) and the determinant is prime to `l`.
  - *Degree 1.* `μ(t)/l ≡ P(t)/(1−t)`, from `λ(s)/l ≡ −L(s)`.
  - *Higher degrees.* The top coefficient of `k! w_k` is `−(k−1)!`, and it has at most `k − 1 ≤ l − 3` roots among
    `l − 2` admissible `t'`.
  - *Polarization.* It needs `k + 2 ≤ l`, and `(k+1)β(u,u^k) = 0` with `k + 1 ≤ l − 1`. Hence `β = 0` on the spanning
    set `l^i u^j`.
- **Hypothesis match.** `F_(2,l)` is the case `r = 2`, `N = l` of the folding quotients `F_(r,N)` of
  `euler-triangular-ring-is-fp-rf`, item 2. There `u` acts by `lj`, `x` shifts, `N` is a multiple of `l^(r−1)`, and
  `C = Z/l^2[y]/(y^2, ly) = Z[u]/(l,u)^2`.
- **Scope.** "What is not claimed" is accurate: it covers `r ≥ l`, `K_2(ρ_m(D))`, and the open residual question.

## Banded matrix groups
- **(a)** Over a finite field every bounded function Z → M_m(F_q) is allowed, so band-w operators are exactly the finite sums Σ_{|j|≤w}D_ju^j, with uDu⁻¹ = D(·−1). Units are the banded operators with banded inverses. Since F_q is discrete, ℓ^∞(Z,F_q) = C(βZ,F_q) = LC(βZ,F_q).
- **(b) Coding.** Put y_s = (D^{(i,±)}_j(s)) over the finite alphabet M_m(F_q)^N. Y is the orbit closure of y, and the c^{(i,±)}_j read the components of z_0.
  - π_y(f)(s) = f(σ^s y) is a ring homomorphism: π_y(f∘σ⁻¹)(s) = π_y(f)(s−1) = (uπ_y(f)u⁻¹)(s).
  - π_y(ĝ^±_i) = g_i^{±1}.
  - **Faithfulness:** π_y(Σ f_ju^j) = 0 forces every f_j to vanish on the dense orbit, hence f_j = 0.
  - So the lifted products ĝ^+ĝ^- and ĝ^-ĝ^+ are I, and π_y|_{Γ̂} is an isomorphism onto Γ.
- **(c)** Any point with dense orbit gives a faithful representation. Regrouping (t,i) ↦ mt+i preserves bandedness in both directions.
- **Consequences.** For minimal X every orbit is dense, so G_X ≤ GL^band(Z;F_2). C*_r(Λ) ⊆ C*_r(Γ), and exactness passes to C*-subalgebras, which gives the equivalence as stated.

## Kakutani invariance
- **(a)** Block transvections are products of entry transvections. An in-block transvection e_{(p,a),(p,b)}(s) = [e_{(p,a),(p′,a)}(s), e_{(p′,a),(p,b)}(1)] with p′ ≠ p, which uses n ≥ 2.
- **(b) The tower.**
  - T′ is minimal, and coding by level and symbol gives an infinite subshift.
  - With e = e_{X×{0}}: u′^deu′⁻ᵈ = e_{X×{d}}, eu′^de = 0 for 0 < |d| < k, and u′^k e = e u′^k. So ε_ij = u′ⁱeu′⁻ʲ is a full system of matrix units, and R_{X^{(k)}} ≅ M_k(eRe).
  - T′^k restricted to level 0 is T, so eRe ≅ R_X, injectively because distinct powers are independent.
- **(c) The corner.**
  - Put V = ⊔_n V_n by first return time n, and w = Σ_n uⁿe_{V_n}.
  - ww* = Σ e_{TⁿV_n} = e_V, because T_V is a bijection of V.
  - w*w = e_V: the cross terms e_{V_n}u^{n′−n}e_{V_{n′}} with n ≠ n′ vanish, since a point of V_n equal to T^{n′−n} of a point of V_{n′} would be an intermediate, non-returning orbit point, which is not in V.
  - wfw⁻¹ = f∘T_V⁻¹ on V, so there is a ring homomorphism R_{X_V} → eR_Xe.
  - **Injective:** the orbit representation at a point of V has a dense T_V-orbit.
  - **Onto:** e f uᵈ e is supported where T^d x = T_V^{j(x)}x, with j locally constant.
- **(c) The embeddings.**
  - y ↦ (1−e)I_n + y maps GL_n(eRe) into GL_n(R) and elementary matrices to elementary matrices.
  - With W_i ⊆ T^{t_i}V a clopen partition, c_i = e u^{−t_i} e_{W_i} and d_j = e_{W_j}u^{t_j}e satisfy dc = Σ e_{W_j} = 1.
  - So φ(r) = crd is an injective ring homomorphism onto f·M_k(eRe)·f with f = cd, and f M f = φ(dMc).
  - Hence EL_n(R_X) ≤ EL_n(M_k(R_{X_V})) = EL_{nk}(R_{X_V}).
- **(d)**
  - diag(y,1) gives EL_n ≤ EL_{n+1}, so the exact ranks form an initial segment.
  - Kakutani equivalence X_V ≅ Y_W gives EL_n(R_X) ≤ EL_{nk}(R_{Y_W}) ≤ EL_{nk}(R_Y), and symmetrically.
  - EL_n(R_X) ≤ EL_{3n}(R_X) ≅ G_{X^{(n)}}, and X^{(n)} is an infinite minimal subshift.
- **Model tests re-checked:** k = 1 and V = X are trivial. A finite orbit gives M_p(F_2[t^{±1}]), which is exact. For Sturmian X the question is constant along the Gauss orbit.

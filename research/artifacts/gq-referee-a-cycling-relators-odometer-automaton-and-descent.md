## 1. `relator-complexity-descent-gives-free-splitting`
- The induction is well-founded induction on `c` over reduced relators.

  - Each section is smaller, so it lies in `K_∞` by induction, and one lift step puts `w` in `K_∞`.

## 2. `polynomial-automata-reduce-to-cycling-relators`
- **Subexponential activity implies (P1).** Two same-component letters at `s` give two first-return walks. I
  refereed that step as PASS (70ac9f576). ✓
- **Shape of the components.** Within a strongly connected component, each state has at most one out-edge, counted
  with multiplicity, since two letters with the same successor already violate (P1). A strongly connected digraph
  with out-degree at most 1 is a point or a simple cycle. So `ν` permutes the cycle states. ✓
- **The complexity, and the equality claim (the author asked about this).**
  - Each letter's section is `1` or one letter, of weight at most its own. Weight is equal iff the section is in the
    same component (N4), which is iff the letter is a cycle state receiving its cycle letter.
  - So the unreduced `w|_x` is obtained from `w` by lowering or deleting entries, and free reduction only deletes.
  - In the multiset order, `c(red(w|_x)) ≤ c(w)`, with equality iff nothing is lowered, deleted or cancelled. That is
    exactly "special at `x`". ✓
  - The multiset order is well-founded (Dershowitz–Manna), because the weights come from a finite linear order.
- **The induction, with the secondary descent (the author asked about this).**
  - If `w` is special at no letter, one lift step suffices.
  - If `w` is special at the unique `x = ℓ(s_n)`: the other sections are smaller, and `w|_x = ν(w)` is a reduced
    relator of the same complexity.
  - If `w` is not cycling, take the least `j` with `ν^j(w)` special nowhere. It exists and is `< r`, because
    `ν^r(w) = w`.
  - Each `ν^i(w)` with `i < j` is special, so each `ν^(i+1)(w)` is reduced, a relator, and of equal complexity.
  - `ν^j(w) ∈ M` by one lift step. Descending, `ν^i(w)` has its special section in `M` and its other sections
    smaller, so `ν^i(w) ∈ M`, down to `i = 0`. ✓
- **The examples.**
  - *Grigorchuk.* `ν = (b c d)` along `1`, and the cycling words are the words in `b, c, d`. The relators among them
    are the kernel of `F(b,c,d) → V_4`, normally generated by `b², c², d², bcd`. This agrees with Röver's finite
    presentation. ✓
  - *The spine automaton.* `ν = id` on the `ŝ_γ`, with `ℓ = 2`, so the relators among the `ŝ_γ` are the Grigorchuk
    relators. This agrees with `V_3` not being finitely presented. ✓

## 3. `linear-activity-odometer-automaton-has-fp-nekrashevych-group` (the author asked about this)
- **The letter table.** I checked it from `a(0w) = 1w`, `a(1w) = 0a(w)`, `b(0w) = 0a(w)` and `b(1w) = 1b(w)`. For
  example, `a^(−1)(0w) = 1a^(−1)(w)` and `b^(−1)(0w) = 0a^(−1)(w)`. All eight entries are correct. ✓
- **The complexity `(β, α)`.**
  - `b^(±1)` gives `a^(±1)` at 0 and `b^(±1)` at 1. `a^(±1)` gives `1` or itself.
  - So `β` does not increase, and it stays equal only if every `b^(±1)` receives 1.
  - Then the `a`-letters of `w|_x` come only from `a`-letters of `w`. So `α` does not increase, and it stays equal
    only if every `a` receives 1 and every `a^(−1)` receives 0, with no cancellation. ✓
- **The classification of special words.**
  - An `a` receiving 1 outputs 0. Its left neighbour would have to be `a^(−1)`, which is not reduced. So an `a` is
    leftmost.
  - An `a^(−1)` must receive 0, and only an `a` outputs 0. So an `a^(−1)` is rightmost, with `x = 0`.
  - The middle letters `b^(±1)` receive 1 and output 1.
  - So `w ∈ {b^e, ab^e, b^ea^(−1), ab^ea^(−1)}`. ✓
- **None of these is a nontrivial relator.**
  - `b^e = (a^e, b^e)`, and `a` has infinite order.
  - `b` fixes `1^ω`, while `a(1^ω) = 0^ω`.
  - `ab^ea^(−1) = 1` forces `b^e = 1`. ✓
- **Activity and contraction.**
  - The sections at level `n` are `b|_(1^n) = b` and `b|_(1^k01^(n−k−1)) = a`, so the activity is exactly linear.
  - `b^e|_1 = b^e` for infinitely many distinct elements, so the automaton is not contracting.
  - `a` moves `1`, the loop letter of `b`, so compression does not apply. ✓
- **Consistency.** This is (P1) with the loops `a` at 1, `a^(−1)` at 0 and `b^(±1)` at 1. Its special words are
  exactly the cycling words that the cycling node lists. ✓

# A finite-module obstruction to every single macro-prefix transporter

Status: scoped obstruction proved below. No Kaplansky counterexample or surjunctivity theorem is claimed.

## 1. Exact scope and statement

Use the finite chart `K=GL_2(F_4)` and reduced projectors `f_0,P_0` from Sections 7–8 of [the half-corner artifact](kaplansky-half-corner-feedback-and-projective-defects-2026-09-08.md). Work in the same embedded matrix group over `L_2(F_4)` used in its Sections 11–15. The constant chart acts on coordinates one and two and fixes the remaining coordinates.

Here a **macro-prefix permutation** means an `F_4`-linear permutation of the boundary basis, specified by a finite binary prefix-replacement table on those matrix coordinates. This is the copy of Thompson's `V` associated with the chosen `F_4` coordinates. It does not include arbitrary bit-level prefix permutations in the original `F_2` realization that mix the two binary coordinates encoding an `F_4` scalar.

**Theorem.** For every macro-prefix permutation `g`, the element

```
Z=P_0[g]f_0
```

has no `L` in the ambient group algebra satisfying `LZ=f_0`.

The proof uses a finite-dimensional module for the subgroup generated by two finite charts. It does not assume that the subgroup generated by `K,g` is finite, amenable, or has a finite boundary orbit.

## 2. The two matchings and a finite orbit

Let `Ω` be the disjoint union of the binary Cantor boundaries of the matrix coordinates, and let `F_4^(Ω)` denote the free vector space on this set. We allow all infinite binary tails here, including the eventually periodic tails supplied by the dynamics argument. Prefix replacement acts by basis permutations, and the constant chart acts linearly on each pair `(1ξ,2ξ)`.

Let `r` swap coordinates one and two, fixing the other coordinates, and put

```
q=g⁻¹rg,        t=rq.
```

Both `r,q` are involutions, and `rtr=t⁻¹`. There is a finite orbit `O` of `〈r,q〉` containing a point moved by `r`.

If `t` has finite order, the group generated by the two involutions is finite dihedral, and any point moved by `r` supplies such an orbit. If `t` has infinite order, the revealing-pair dynamics of `V` supplies an attracting or repelling periodic point `p` of `t`. The needed standard facts are in [Bleak et al., *Centralizers in the R. Thompson group V_n*, Section 4.1 and Lemmas 4.2–4.4](https://ems.press/content/serial-article-files/29667): a revealing pair exists, an infinite-order element has a nontrivial attracting or repelling component, and its component supplies a periodic point with a strictly contracting or expanding local return map.

Conjugation by `r` reverses `t`, so `r` sends an attracting periodic point to a repelling periodic point, and conversely. Consequently `rp≠p`. The set

```
O=〈t〉p ∪ r〈t〉p
```

is finite and invariant under `r` and `q=rt`, and it contains an `r`-pair. This uses periodic dynamics of `t=r g⁻¹ r g`, not an assumed finite orbit of `〈r,g〉`.

## 3. The exact finite-dimensional representation

Put

```
H=〈K,g⁻¹Kg〉,       Q=[g⁻¹]P_0[g].
```

The span `W_O=F_4^O` is invariant under `H`. Indeed `K` only mixes the two basis vectors in each `r`-pair, while `g⁻¹Kg` only mixes the two basis vectors in each `q`-pair. Points fixed by the respective involution are fixed by the corresponding chart. Thus restriction gives an actual representation

```
H → GL(W_O),
```

with finite image. Its exterior powers are also actual representations of `H`.

Let `a,b` be the numbers of two-point and one-point orbits of `r` in `O`, and let `a′,b′` be the corresponding numbers for `q`. Then

```
W_O restricted to K          ≅ V^a ⊕ 1^b,
W_O restricted to g⁻¹Kg      ≅ V^(a′) ⊕ 1^(b′),
2a+b=2a′+b′=|O|,            a≥1.
```

Here `V` is the natural two-dimensional `F_4` module, and the second line uses the natural identification of the conjugate chart with `K`.

The projector calculations in Section 12 of the half-corner artifact give the following ranks:

| Module of the corresponding chart | `f_0` | `P_0` |
| --- | ---: | ---: |
| `1` | 0 | 0 |
| `V` | 0 | 1 |
| `det(V)` | 1 | 0 |
| `V⊗V` | 2 | 1 |

All nontrivial summands appearing here have nontrivial central `C_3` character, so the removed center-trivial Steinberg block contributes nothing. Decomposing the exterior square of a direct sum therefore yields

```
rank_(Λ²W_O)(f_0)=a+2 binom(a,2)=a²,
rank_(Λ²W_O)(Q)=binom(a′,2)+a′b′.
```

## 4. Every finite orbit type gives a rank obstruction

Draw the `r`-pairs and `q`-pairs as two colors of edges. A connected finite orbit is an alternating cycle or an alternating path; fixed points are missing edges at endpoints. A two-vertex cycle may have the two differently colored edges joining the same vertices. An isolated point is excluded by `a≥1`.

The complete list is:

| Orbit type | `(a,b)` | `(a′,b′)` | `rank(f_0)` on `Λ²` | `rank(Q)` on `Λ²` |
| --- | --- | --- | ---: | ---: |
| Cycle | `(a,0)` | `(a,0)` | `a²` | `a(a−1)/2` |
| Odd path | `(a,1)` | `(a,1)` | `a²` | `a(a+1)/2` |
| Even path with two `q`-fixed endpoints | `(a,0)` | `(a−1,2)` | `a²` | `(a−1)(a+2)/2` |
| Even path with two `r`-fixed endpoints | `(a,2)` | `(a+1,0)` | `a²` | `a(a+1)/2` |

The source rank is strictly larger in every case except the odd path with `a=1`, which has three vertices, and the last even path with `a=1`, which has four vertices. In those two cases use the top exterior power of `W_O`. Its character on `K` is `det`, so `f_0` acts as one. Its character on the conjugate chart is respectively `det` or `det²`; `P_0` acts as zero on either one-dimensional character. Thus the top exterior power has ranks `(1,0)`.

In every case there is a finite-dimensional representation `ρ` of `H` such that

```
rank ρ(f_0) > rank ρ(Q).
```

## 5. Passing from the finite module to the unrestricted group-ring claim

Suppose `L P_0[g]f_0=f_0`. Since `P_0[g]=[g]Q`, this is precisely

```
(L[g]) Q f_0=f_0.
```

Both `Q,f_0` belong to the group algebra of `H`. Conditional expectation of `L[g]` onto that subgroup algebra preserves this identity, giving

```
Y Q f_0=f_0,        Y∈F_2[H].
```

Apply the representation from Section 4. The left side has rank at most `rank ρ(Q)`, while the right side has the strictly larger rank `rank ρ(f_0)`. This contradiction proves the theorem. No extension of the finite-dimensional representation to the entire ambient group is required.

## 6. A control that defeats the simpler orbit and exterior-square arguments

On three root coordinates consider the prefix table

```
1→20,       2→31,       30→1,       310→21,       311→30,
```

with all tails unchanged. It has order six: its refined cylinder partition is the cycle

```
1 → 20 → 310 → 21 → 311 → 30 → 1.
```

Using `k,J` from Section 13 of the half-corner artifact gives

```
P_0[g]f_0 k(ξ,η)
  =J(s_0ξ,s_0η)+e_2(s_0η)∧e_3(s_1ξ).
```

The external-coordinate tensor component is injective on `ξ⊗η`. Thus this transporter is injective on the entire exterior-square source sector, despite the theorem above. Its concrete kernel appears in degree three: for

```
w=e_1ξ∧e_2ξ∧e_3(s_0²ξ),
```

one has `f_0w=w≠0`, while its image under `g` is a determinant pair with tail `s_0ξ`, wedged with the external vector `e_3(s_1ξ)`. Therefore `P_0[g]w=0`.

Moreover `〈r,g〉` has no finite orbit on this three-coordinate boundary and is not amenable. Let `X` be cylinder `1`. The six sets `g^kX` partition that boundary, while

```
(rg)X=10,       (rg³)X=11,
```

partition `X`. An invariant mean would simultaneously give `μ(X)=1/6` and `μ(X)=2μ(X)`. A finite boundary orbit would supply such a mean by normalized counting. This explains why replacing `〈r,g⁻¹rg〉` by `〈r,g〉` in the proof would be an invalid step.

The theorem excludes a single macro-prefix transporter. It does not exclude sums of transporters, general linear Leavitt units, or arbitrary bit-level prefix permutations relative to the original `F_2` chart.

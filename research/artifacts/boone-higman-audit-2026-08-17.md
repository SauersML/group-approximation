## B. The near-solution, and the proofs the graph cites

### B.1 The easy direction (Kuznetsov)

*Claim.*  A finitely generated subgroup of a finitely presented simple group
has solvable word problem.

*Proof.*  Let `H = <X | R>` with `X, R` finite, `H` simple.  If `H = 1` the
statement is trivial, so assume `H != 1`.  Given `w in F(X)`, run two
enumerations in parallel.

*A.*  Enumerate finite products of conjugates of elements of `R^{±1}`; halt
if `w` appears.  This halts iff `w = 1` in `H`.

*B.*  Enumerate consequences of `R ∪ {w}`; halt once a proof of `x = 1` has
been found for **every** `x in X`, which is a terminating condition because
`X` is finite.  If `w != 1` in `H` then `<<w>>` is a nontrivial normal
subgroup of a simple group, hence all of `H`, hence `<X | R, w>` is trivial
and every generator is a consequence; so B halts.

Exactly one halts, so the word problem of `H` is decidable.  For a finitely
generated `G = <g_1,…,g_k> <= H`, substitute fixed words `u_i` representing
the images of `g_i` and appeal to injectivity.  ∎

Simplicity is what supplies the semi-decision procedure for *non*triviality;
finite presentation is what makes consequences enumerable.  Both halves are
used, which is why the conjecture's easy direction is a theorem and the hard
direction is not.

### B.2 Every proper normal subgroup misses a normally generating simple core

*Claim.*  Let `S` be a nontrivial simple group, `S <= Γ`, and suppose some
`1 != s in S` satisfies `Γ = <<s>>_Γ`.  Then `N <| Γ` and `N != Γ` imply
`N ∩ S = 1`.

*Proof.*  `N ∩ S <| S`, so by simplicity it is `1` or `S`.  If it is `S` then
`s in N`, so `Γ = <<s>>_Γ <= N`, contradicting properness.  ∎

*Corollary.*  For every proper `N <| Γ` the quotient map restricts to an
embedding `S ↪ Γ/N`.

*Corollary (existence of a maximal proper normal subgroup).*  If `Γ != 1` is
finitely generated, Zorn applies to the poset of proper normal subgroups:
the union `U` of a chain is normal, and if `U = Γ` then each of the finitely
many generators lies in some member of the chain, so by linearity one member
contains them all and equals `Γ`, contradicting properness.  Hence a maximal
proper normal `M` exists and `Γ/M` is simple.

Combining: **every** maximal proper normal quotient of `Γ` is simple and
contains `S`.  This is the source's Breakthrough 1, and it is correct.  Its
force is that it removes the usual difficulty entirely — one does not have to
choose the quotient carefully, because no proper quotient can damage the
core.

### B.3 All core elements normally generate; perfectness; infinite quotients

*Claim.*  Under B.2's hypotheses, every `1 != t in S` satisfies
`Γ = <<t>>_Γ`.

*Proof.*  `S = <<t>>_S` by simplicity, so `s in <<t>>_Γ`, so
`Γ = <<s>>_Γ <= <<t>>_Γ`.  ∎

*Claim.*  If moreover `S` is infinite then `Γ` is perfect and every proper
quotient of `Γ` is infinite.

*Proof.*  An infinite simple group is nonabelian, hence perfect, so
`s in [S,S] <= [Γ,Γ]`; `[Γ,Γ]` is normal and contains a normal generator, so
`[Γ,Γ] = Γ`.  For the second part, B.2's corollary embeds the infinite `S`
into every proper quotient.  ∎

*Claim (the core can be taken infinite at no cost).*  Replace the input `G`
by `G × Z` before applying Theorem 3.8.  It is still finitely generated with
solvable word problem, it still contains `G`, and the resulting simple
envelope contains an infinite cyclic subgroup, hence is infinite.

These are the source's Breakthroughs 2 and 3.  They sharpen the normal
lattice of `Γ` considerably and do **not** bear on finite normal generation
of a maximal kernel, which is the point at issue; the graph records them as
established facts about the envelope, not as progress on the obstruction.

### B.4 The finite-presentation equivalence

*Claim.*  For `Γ` finitely presented and `N <| Γ`: `Γ/N` is finitely
presented **iff** `N` is finitely normally generated in `Γ`.

*Proof.*  (⇐) With `Γ = <X | R>` finite and `N = <<n_1,…,n_k>>_Γ`, choosing
words `u_i` for the `n_i` gives the finite presentation
`Γ/N = <X | R, u_1,…,u_k>`.  (⇒) This is the Tietze theorem for kernels of
epimorphisms between finitely presented groups, and it is **already
formalized in this repository**, as
`GroupApproximation/Algebra/FinitePresentationKernel.lean`:

```
theorem ker_isFinitelyNormallyGenerated {E : Type u} [Group E] {W : Type v}
    [hE : Group.IsFinitelyPresented E] [Group.IsFinitelyPresented W]
    (f : E →* W) (hf : Function.Surjective f) :
    f.ker.IsFinitelyNormallyGenerated
```

∎

This is the source's Breakthrough 4 and it is the reason the whole attempt
lands on a single crisp hypothesis rather than a vague one.

**Why the tempting shortcut is false.**  "A quotient of a finitely presented
group is finitely presented" is not a theorem: for any finitely generated
group `Q` that is not finitely presented, a surjection `F_k ↠ Q` from a
finitely generated free group has finitely presented source and
non-finitely-presented target.  Zorn's lemma supplies a maximal `M` and
supplies nothing else; in particular it supplies no finite normal generating
set.  The graph records the shortcut as a dead route killed by B.4 itself.

### B.5 Coset action of the core, and the bi-index

Write the **bi-index** of `H <= Γ` for `|H \ Γ / H|`.  (This repository's
term; see §A.3.)

*Claim.*  Under B.2's hypotheses with `S != Γ`, the left multiplication
action `Γ ↷ Γ/S` is faithful.

*Proof.*  Its kernel is `Core_Γ(S) = ∩_γ γSγ^{-1}`, which is normal, is
contained in `S`, and is proper because `S != Γ`.  B.2 gives
`Core_Γ(S) = Core_Γ(S) ∩ S = 1`.  ∎

*Claim.*  For the transitive action `Γ ↷ Γ/S`, orbits on ordered pairs
correspond bijectively to double cosets `S \ Γ / S`.

*Proof.*  Every ordered pair moves to one of the form `(S, gS)`; and
`(S, gS)`, `(S, hS)` are in the same orbit iff some element of the point
stabilizer `S` carries `gS` to `hS`, i.e. iff `h in SgS`.  ∎

*Consequence.*  If the envelope can be arranged with `|S \ Γ / S| < ∞`, then
`Γ ↷ Γ/S` is faithful, has finitely generated point stabilizer `S`, has
finitely many pair-orbits, and `Γ` is finitely presented — precisely
Zaremsky's three conditions (§A.1), equivalently FFWZ type `[A_2]`.  The
twisted Brin--Thompson group `SV_Γ` is then finitely presented and simple and
contains `Γ`, hence `S`, hence `G`.  This is the source's Breakthrough 5.
Whether the arrangement is possible is open; the known construction gives no
double-coset control whatsoever.

## C. The universal-sandwich improvement — the attempt's strongest output

*Claim (Proposition 11.3 of the source).*  Let `R` be a unital associative
ring, `r in R`, and suppose there is an injective unital `φ: R ↪ B` and
`P, Q in B` with `P φ(r) Q = 1_B`.  Put

    U = R<p,q>/(prq - 1),

the universal unital ring adjoining two noncommuting elements to `R` subject
to that one relation.  Then `R → U` is injective, `UrU = U`, and if `R` is
finitely presented as a unital associative ring then so is `U`.

*Proof.*  The universal property gives a unital `Φ: U → B` extending `φ` with
`Φ(p) = P`, `Φ(q) = Q`; the relation is respected because
`Φ(prq) = Pφ(r)Q = 1`.  Writing `i: R → U` for the canonical map,
`Φ ∘ i = φ` is injective, so `i` is injective.  `prq = 1` says `1 in UrU`.
For the last part, from
`R = Z<x_1,…,x_m>/(f_1,…,f_k)` and a word `r̂` representing `r`,

    U = Z<x_1,…,x_m,p,q>/(f_1,…,f_k, p r̂ q - 1).

∎

**Why this is a real improvement and not a restatement.**  CK's Remark 5
says their concrete `L` — a subring of `End(W)` — need not be finitely
presented.  That is a statement about a *particular* ring, and it does not
transfer to the universal ring with the same defining relation.  §A.1
established that CK's own `L` is generated by `φ(R), P, Q`, so `Φ: U ↠ L`
and the composite `R → U ↠ L ⊆ End(W)` is the original injection.  The
surjection `U ↠ L` certifies that no additional relation has been imposed
that could collapse the embedded copy of `R`; whatever extra relations `L`
satisfies inside `End(W)`, `U` does not need them.

**What it buys.**  Take `R = Z[G̃]` for the finitely presented group `G̃` that
CK's chain produces, and `r = 1 - g`.  `R` is finitely presented as a unital
ring (group generators and formal inverses, the inverse relations, the
finitely many group relators) and has torsion-free additive group, so CK's
Lemma 4 applies and supplies the sandwich.  Then `U` is a **finitely
presented** ring containing `R` with `1 - g` full, and Krstić--McCool applies
directly to `EL_4(U)`.  The Steinberg relations plus fullness put every
elementary generator into `<<g>>`, exactly as in CK.  So one may take

    Γ = EL_4(U)

directly: finitely presented, property (T), containing `G`, normally
generated by `g` — **without** the auxiliary Shalom finitely presented cover.
One uncontrolled kernel leaves the construction.

**What it does not buy, with an explicit counterexample.**  A one-sided
sandwich does not force simplicity.  Take `R = k` a field and `r = 1`, so
`T = k<p,q | pq = 1>`.  Represent `T` on the space with basis
`e_0, e_1, e_2, …` by `q(e_n) = e_{n+1}`, `p(e_0) = 0`, `p(e_{n+1}) = e_n`.
Then `pq = 1` but `qp != 1`, so `e = 1 - qp != 0`.  The ideal `J = TeT` is
proper: the map `T ↠ k[t,t^{-1}]`, `q ↦ t`, `p ↦ t^{-1}`, kills `e`, and the
scalar copy of `k` survives in that quotient, so `J ∩ k = 0`.

A "Toeplitz defect" ideal disjoint from the coefficient core is therefore
compatible with the designated element being full.  This is the ring-level
mirror of §B.2 — fullness on the core says nothing about ideals that avoid
the core — and it kills, outright, the inference that the universal sandwich
delivers a simple ring.  Adding the reverse relation `qrp = 1` is not a
repair: forcing a noncommutative element such as `1 - g` to be genuinely
invertible can collapse the embedded group ring, and injectivity of such a
universal localization is a separate theorem, not a formality.

## D. The ring lane, and where it actually dies

### D.1 Fullness propagates across the core

In `Z[S]` the set `K = {s : 1 - s in I}`, for `I` the two-sided ideal
generated by `1 - t`, is a normal subgroup of `S` containing `t`, because of
the three identities

    1 - ab = (1 - a) + a(1 - b),
    1 - a^{-1} = -a^{-1}(1 - a),
    1 - h a h^{-1} = h (1 - a) h^{-1}.

So if `t` normally generates `S`, then `I` contains `1 - s` for all `s`,
i.e. `I` is the augmentation ideal.  For `S` simple this holds for every
`1 != t in S`.  Hence once an extension makes one `1 - t` full, every
`1 - s` with `1 != s in S` is full.  (Source's Breakthrough 7.)  This is the
exact ring analogue of §B.3 and, like §B.3, it constrains only the core.

### D.2 The CK endomorphism model is already simple, and that is the problem

For `W` of infinite dimension `κ`, the ideal `I_{<κ}` of operators of rank
`< κ` is proper, and every nonzero class in `End_F(W)/I_{<κ}` has a
representative of rank `κ`, to which the sandwich argument of §A.1 applies
verbatim.  So that quotient is simple, and the amplified coefficient algebra
survives in it because every nonzero algebra element acts with rank `κ`.
The CK device therefore does reach a simple ring containing the coefficients
— it just reaches an enormous one, with no finite generation and no finite
presentation.  (Source's Breakthrough 9.)  Replacing "huge simple quotient"
by "finitely presented simple quotient" is the ring-level restatement of the
same bottleneck, not an escape from it: taking a maximal ideal again yields
a simple quotient whose finite presentation is equivalent to finite
generation of that ideal as a two-sided ideal.

### D.3 What this repository's Leavitt formalization is, and is not

The repository already contains an excellent *target*: a finitely presented,
strongly simple ring with well-understood elementary groups.  Confirmed
present in the working tree this session:
`GroupApproximation/Leavitt/UniversalLeavittOver.lean`,
`FinitePresentation.lean`, `LeavittSimplicity.lean`, `ElementaryGroup.lean`,
`ElementaryPerfect.lean`, `ElementaryNoFiniteQuotients.lean`, and the
self-similar `ShiftEndomorphism.lean`, `RankFourCompressors.lean`,
`UniversalRankFour.lean`.

Two distinct temptations, both closed:

1. **`L_K(1,2)` as a universal host.**  Refuted in general by
   Bilich--Hazrat--Nam (§A.1): the first Weyl algebra does not embed, because
   the Heisenberg equation is unrealizable in any Steinberg algebra.  A
   Leavitt route must therefore be tailored to the particular group rings
   arising here; a blanket countable-algebra embedding theorem is false.
2. **The shift/compressor as a fullness compressor.**  The compressor
   finitely controls a family *already generated by a fixed self-similar
   rule*, `x, σ(x), σ²(x), …`.  An arbitrary recursive enumeration `r_0, r_1,
   …` of nonzero elements does not satisfy `r_{i+1} = σ(r_i)` for a
   pre-existing endomorphism `σ`, and declaring such identities encodes the
   enumeration algorithm into the algebra rather than compressing it.  Worse,
   adjoining sandwiches to make `r_i` full changes the ambient ring and
   creates new nonzero elements outside the original enumeration, which
   simplicity then also demands be made full.  (Source's Breakthrough 11.)

   This is a statement about what the existing machinery covers, **not** a
   theorem that no such compression exists.  The graph records it as a
   deferred attempt and states the missing theorem positively, as
   `finite-fullness-simulation-theorem-for-rings`: compile an effective
   sequence of fullness requirements into one finitely presented extension
   while proving the original coefficient ring stays embedded.  Nothing here
   proves it and nothing here refutes it.

### D.4 Clapham removes the effectivity excuse

Clapham's theorem embeds a finitely generated group with solvable word
problem into a *finitely presented* group with solvable word problem.  So
after passing to the simple core `S` one may embed `S` in a finitely
presented `H` with decidable word problem, take `R = Z[H]`, and obtain a
coefficient ring that is finitely presented as a unital ring **and** has
decidable equality (collect the finite support and compare in `H`).  `S`
being nonabelian simple, hence perfect, sits inside `[H,H]`.  The serious
obstruction in the ring lane is therefore not "we cannot recognize a nonzero
coefficient"; it is that new nonzero elements appear after each round of
adjunction.  (Source's §11.9.)

## E. The side result of §17, stated so it depends on nothing unread

*Theorem.*  Every infinite finitely generated group `G` admits a finite
symmetric monoid generating set `X` and a set `L ⊆ X*` containing exactly one
word representing each element of `G`, such that the left action of `G` on
`L` extends continuously to `L ∪ ∂L` and the induced action on `∂L` is
faithful.  The language `L` is **not** claimed regular, automatic, or
effective.

*Proof.*  Since `X` is symmetric and `G` is infinite, pick distinct `a, b in
X` and set `U_0 = a a^{-1}`, `U_1 = b b^{-1}`: two words of equal positive
length with distinct first letters, both representing `1`.  Substitution
`0 ↦ U_0`, `1 ↦ U_1` is then an injective block code `C: {0,1}* → X*` with a
topological embedding `C_∞: {0,1}^N → X^ω`.

Let `Y = {0,1}^G` carry the Bernoulli shift, which is faithful (for `g != 1`
take `y` with `y(1) != y(g)`; then `(g·y)(g) = y(1) != y(g)`).  Fix `y_0` with
dense orbit — enumerate the finite cylinder conditions `(F_i, p_i)` and
recursively choose `h_i` so the translated supports `h_i F_i` are pairwise
disjoint, which is possible because at each stage only finitely many choices
are forbidden and `G` is infinite; define `y_0` to realize `p_i` on `h_i F_i`.
Fix an enumeration `G = {e_0, e_1, …}`, let `θ(y) = (y(e_0), y(e_1), …)` and
`ι = C_∞ ∘ θ`.

For `g in G` write `ρ(g) = |g|_X` and `y_g = g · y_0`, choose any word `r_g`
representing `g`, and set

    ℓ_g = C( θ(y_g) restricted to its first ρ(g) digits ) · r_g .

The prefix represents `1`, so `ℓ_g` represents `g`; distinct group elements
get distinct words because a word has one value.  So `L = {ℓ_g}` is a set of
normal forms.

`∂L = ι(Y)`.  (⊆) A convergent sequence `ℓ_{g_n} → z` with distinct `g_n` has
`ρ(g_n) → ∞`, because `ρ` has finite sublevel sets; so for each `k` the first
`2k` letters of `ℓ_{g_n}` are eventually the first `k` code blocks, and
convergence stabilizes them, making `z` an in-phase infinite concatenation of
`U_0, U_1`.  (⊇) Given `y` and `k`, the cylinder `V_k` of configurations
agreeing with `y` on `e_0,…,e_{k-1}` is nonempty open; splitting it into
disjoint nonempty subcylinders and applying density repeatedly shows
`{g : g·y_0 in V_k}` is infinite, so some `g_k` in it has `ρ(g_k) ≥ k`, and
then `ℓ_{g_k}` agrees with `ι(y)` on its first `k` blocks.

Extend the action by `g · ι(y) = ι(g·y)`.  If `ℓ_{h_n} → ι(y)` then
`ρ(h_n) → ∞` and `h_n·y_0 → y`; left multiplication is a bijection of `G` so
`ρ(g h_n) → ∞`, and continuity of the Bernoulli action gives
`g h_n · y_0 → g·y`, whence `ℓ_{g h_n} → ι(g·y)`.  The space is metrizable and
points of `L` are isolated, so sequential continuity suffices; applying the
same to `g^{-1}` makes these homeomorphisms.  The boundary action is
conjugate via `ι` to the Bernoulli shift, hence faithful.  ∎

**Audit note.**  The argument is elementary and checks out as written, with
one wording repair: the source's density step ("unless the stabilizer of
`y_0` is infinite, in which case…") is garbled, and the clean reason
`{g : g·y_0 in V_k}` is infinite is subcylinder-splitting plus density, as
above.  The conclusion is unaffected.

Whether this answers the question the source says it answers cannot be
determined here (§A.4), and **nothing in the Boone--Higman lanes depends on
it**.  It is recorded because it is a correct theorem that came out of the
attempt.

## F. Attacks the source ran and closed, recorded so they are not re-run

* **Zorn on the finitely-normally-generated proper normals.**  Chains have no
  upper bound in that class: a union of finitely normally generated normal
  subgroups need not be finitely normally generated.  Finite generation of
  `Γ` gives properness of the union, not stabilization of the chain.  What
  would rescue it is a Max-n condition, and none was found.
* **Property (T) as a source of Max-n.**  No implication found.  The 2026
  "just finite presentations" phenomena concern deleting relators from a
  *chosen* finite presentation and say nothing about an arbitrary maximal
  normal subgroup.
* **Relative simplicity of the envelope.**  §B.2 says all proper normals miss
  `S`; it does **not** give a largest one.  Two proper normals `N_1, N_2`
  with `N_1 N_2 = Γ` are not excluded by anything proved here, so the
  envelope is not known to be relatively simple.
* **Compressing the infinite Boone--Higman HNN tower** into finitely many
  relators by a shift `t_i = z^{-i} t z^i`.  The hard part is not encoding
  the recursive list — Higman's theorem does that — but keeping *every*
  nontrivial element of the **final** group a normal generator, including the
  new machine and stable letters.  Forcing that with extra relations
  endangers the base embedding.  Finite compression preserving simplicity is
  the conjecture restated.
* **Schupp's two-generator simple envelope.**  Two-generator does not imply
  computably presented, so Higman does not apply to it; Thompson's Theorem
  3.8 restores computable presentability but then Higman destroys simplicity.
  The route rotates between the conjecture's two halves.  (This repository
  already carries the Schupp statement as
  `countable-group-embeds-in-two-generator-simple-group`.)
* **Diagonalization for a counterexample.**  Cardinality separates nothing
  (both sides are countable); Higman forbids diagonalizing against all
  finitely presented targets, so simplicity must be used essentially; and
  finite presentations defining *simple* groups are not available as an
  effective list with the semantic guarantees a priority construction needs.
  No hereditary separating property was found beyond solvable word problem,
  which the candidate has by hypothesis.  Finally, non-uniformity is not a
  disproof: the conjecture is existential, so incomputability of
  `presentation ↦ simple envelope` is consistent with it.
* **An effective maximal kernel** (weaker than finite normal generation).
  If a maximal `M` could be chosen recursively enumerable as a normal
  subgroup, `Γ/M` would be a finitely generated computably presented simple
  group with decidable word problem — still not finitely presented, but a
  useful intermediate.  The obvious effective-Zorn construction needs to
  decide `<<M, x>> ∩ S = 1`, and the clean criterion of §B.2 (`N` proper iff
  `N ∩ S = 1`) is not effective in the required direction.  Unsolved, and
  strictly easier than the conjecture, so worth recording as a subproblem.

# Rokhlin maximality ascends along co-amenable subgroups, and the Rokhlin entropy question for Thompson's V

Lane `rokhlin-entropy-v-l-times`, 2026-09-12. Handwritten proofs, no computation.

**Result.**
- Theorem A proves that maximal Rokhlin entropy of uniform Bernoulli shifts passes from an infinite co-amenable subgroup to the whole group. With the landed down-passing result, maximality is invariant along co-amenable inclusions.
- Section 3 wires the positive-entropy question for Thompson's V into Cairn.
- Section 4 audits which lower-bound mechanisms change when the Kazhdan host `U = L_(F_2)(1,2)^x` is replaced by V.

Nothing here proves positive Rokhlin entropy for any nonsofic group. `thompson-v-has-positive-rokhlin-entropy-action` stays open.

## 0. Imported statements

Labels (I1)-(I3) refer to the source quotes in Section 5.

- **(I1) Sub-additivity** (Seward, arXiv:1501.03367v4, Corollary 2.5, in the specialization checked in `research/artifacts/review-rokhlin-self-copy-dichotomy-2026-09-12.md`). For an ergodic p.m.p. action on `Z` and an invariant sub-sigma-algebra `Σ`, write `Y` for the factor it defines. Then
  - `h^Rok(Z) <= h^Rok(Y) + h^Rok(Z | Σ)`, and
  - `h^Rok(Z | Σ) <= H(β | Σ)` for every countable partition `β` with `σ-alg(β) ∨ Σ = B(Z)`.
- **(I2) Weak containment** (Seward, arXiv:1602.06680v2, Theorem 1.2). Let `G ↷ (X, μ)` be free p.m.p., let `F` be a G-invariant sub-sigma-algebra, and let `G ↷ (Y, ν)` be weakly contained in all free p.m.p. actions of G. Then `h_G(X, μ | F) = h_G(X × Y, μ × ν | F ∨ B(Y))`.
- **(I3) Abért–Weiss** (arXiv:1103.1063v2, Theorem 1, quoted on main in `nontrivial-bernoulli-weak-equivalence-proof`). Every free p.m.p. action of a countably infinite group weakly contains every Bernoulli action, whatever its base.

Relative Rokhlin entropy is `h_G(X | F) = inf { H(α | F) : σ-alg_G(α) ∨ F = B(X) }`. For trivial `F` and ergodic `X` this is `h^Rok_G(X)`.

`G` is **Rokhlin-maximal at q** when `h^Rok_G((A^k)^G, uniform) = k log q` for every `k >= 1`, where `|A| = q`. This is the definition of `bernoulli-rokhlin-maximality-passes-to-subgroups`.

Co-amenability is used in its Følner form: G acts on the right cosets `Ω = H\G` by `(Hg)s = Hgs`, and for every finite `S ⊆ G` and `δ > 0` there is a finite nonempty `Ω' ⊆ Ω` with `|Ω's \ Ω'| <= δ|Ω'|` for all `s ∈ S`. Classically this is equivalent to a G-invariant mean on `G/H`. That equivalence is not used.

## 1. Theorem A

**Theorem A.** Let G be a countable group, let `H <= G` be an infinite subgroup that is co-amenable in the Følner sense, and let `q >= 2`. If H is Rokhlin-maximal at q, then so is G.

*Proof.* Replacing `A` by `A^k`, it suffices to show `h^Rok_G(A^G) >= log q`. The reverse inequality comes from the time-zero partition. Put `X = A^G` with uniform product measure and shift `(g.x)(h) = x(g^-1 h)`. For `g ∈ G`, let `Q_g` be the partition of X according to `x(g)`, so `g.Q_1 = Q_g`.

Let P be a countable partition with `H(P) < ∞` and `σ-alg_G(P) = B(X)`. Fix `ε > 0`.

**Step 1: a window.** The sigma-algebras generated by `∨_(s ∈ S) sP` increase to `B(X)` as S runs through finite subsets of G. By martingale convergence there is a finite S with `H(Q_1 | ∨_(s ∈ S) sP) < ε`. By invariance,

    H(Q_g | ∨_(s ∈ S) gsP) < ε   for every g ∈ G.                          (1.1)

**Step 2: a Følner set of cosets.** Take `Ω' ⊆ Ω` finite nonempty with `|Ω's \ Ω'| <= (ε/|S|)|Ω'|` for all `s ∈ S`, and put `Ω'' = {ω ∈ Ω' : ωs ∈ Ω' for all s ∈ S}`. Right multiplication by s is a bijection of Ω, so

    |Ω' \ Ω''| <= Σ_(s ∈ S) |Ω's \ Ω'| <= ε|Ω'|.                            (1.2)

For each `ω ∈ Ω`, fix a representative `r(ω) ∈ G` with `ω = H r(ω)`.

**Step 3: the H-system.** Restrict the action to H. For `Θ ⊆ Ω`, let `F_Θ` be the sigma-algebra of the coordinates in `∪_(ω ∈ Θ) ω ⊆ G`.
- `x -> (x(h r(ω)))_(h ∈ H, ω ∈ Θ)` identifies `(X, F_Θ)` with `(A^Θ)^H`.
- `(k.x)(h r(ω)) = x(k^-1 h r(ω))`, so H acts on `F_Θ` as the uniform Bernoulli shift with base `A^Θ`.
- Coordinates on disjoint sets of cosets are independent, and the cosets partition G. So as H-systems, `X = B × C` with `B = F_(Ω'')` and `C = F_(Ω \ Ω'')`.

**Step 4: two partitions.** Put `P' = ∨_(ω ∈ Ω') r(ω)P`, so `H(P') <= |Ω'| H(P)`, and let `Σ = σ-alg_H(P')`. Put `Q'' = ∨_(ω ∈ Ω'') Q_(r(ω))`. Since `k.Q_(r(ω)) = Q_(k r(ω))`, we have `σ-alg_H(Q'') = F_(Ω'')`.

For `ω ∈ Ω''` and `s ∈ S`, the coset `ωs` lies in `Ω'`, and `r(ω)s` and `r(ωs)` lie in the same right coset. So `r(ω)s = k r(ωs)` for some `k ∈ H`, and `r(ω)sP = k.(r(ωs)P)`. The partition `r(ωs)P` is coarser than `P'`, so `r(ω)sP` is Σ-measurable. By (1.1), since conditioning on more can only lower entropy,

    H(Q'' | Σ) <= Σ_(ω ∈ Ω'') H(Q_(r(ω)) | ∨_(s ∈ S) r(ω)sP) < |Ω''| ε.       (1.3)

**Step 5: an upper bound on a factor.** Let Z be the H-factor of X with sigma-algebra `F_(Ω'') ∨ Σ`, and Y its factor with sigma-algebra Σ. The restriction of a Bernoulli shift to the infinite subgroup H is mixing, so Z and Y are ergodic.
- P' is Σ-measurable and generates Σ under H, so `h^Rok_H(Y) <= H(P')`.
- Q'' is Z-measurable and `σ-alg_H(Q'') ∨ Σ = B(Z)`.

So (I1) and (1.3) give

    h^Rok_H(Z) <= H(P') + H(Q'' | Σ) < |Ω'| H(P) + |Ω''| ε.                 (1.4)

**Step 6: a lower bound on the same factor.** Let β be a countable Z-measurable partition with `σ-alg_H(β) = B(Z)`. Then `σ-alg_H(β) ∨ C ⊇ F_(Ω'') ∨ F_(Ω \ Ω'') = B(X)`. By the definition of relative Rokhlin entropy, `h_H(X | C) <= H(β | C) <= H(β)`. Taking the infimum over β,

    h_H(X | C) <= h^Rok_H(Z).                                                (1.5)

- If `Ω'' = Ω`, then C is trivial and `h_H(X | C) = h^Rok_H(B)`.
- Otherwise C is a Bernoulli action of H. By (I3) it is weakly contained in every free p.m.p. action of H.
  - B is free, because it is a nontrivial Bernoulli shift over an infinite group (step 1 of `nontrivial-bernoulli-weak-equivalence-proof`).
  - (I2), applied with `X := B`, `F` trivial and `Y := C`, gives `h^Rok_H(B) = h_H(B | trivial) = h_H(B × C | C) = h_H(X | C)`.

Since H is Rokhlin-maximal at q and `Ω''` is nonempty for `ε < 1`, `h^Rok_H(B) = |Ω''| log q`.

**Step 7.** From (1.4), (1.5) and (1.2),

    |Ω''| log q < |Ω'| H(P) + |Ω''| ε,   so   H(P) > (1 - ε)(log q - ε).

As ε was arbitrary, `H(P) >= log q`. Partitions of infinite entropy do not affect the infimum, so `h^Rok_G(A^G) >= log q`. QED.

**Corollary B (invariance).** Let `H <= G` be infinite and co-amenable. Then H is Rokhlin-maximal at q if and only if G is.

*Proof.* "Only if" is Theorem A. "If" is item 1 of `bernoulli-rokhlin-maximality-passes-to-subgroups`. QED.

**Corollary C.** If H is infinite, co-amenable in G, and Rokhlin-maximal at every `q >= 2`, then G satisfies Gottschalk's surjunctivity conjecture and Kaplansky's direct finiteness conjecture.

*Proof.* Theorem A gives `h^Rok_G(k^G, u^G) = log k` for every k. Apply item 5 of `seward-per-group-rokhlin-entropy-of-bernoulli-shifts`, which is Seward's Corollary 4.1. QED.

**Remarks.**
1. **Finite index.** If `[G:H] < ∞`, take `Ω' = Ω`. Then `Ω'' = Ω`, C is trivial, and (I2) and (I3) are not needed. This recovers item 2 of `bernoulli-rokhlin-maximality-passes-to-subgroups` by a different argument.
2. **Where each input is consumed.**
   - Co-amenability pays for the windows. This is exactly the ratio `|T'|/|T|` of Section 1.2 of `research/artifacts/rokhlin-lower-bounds-without-finite-models-2026-09-12.md`, now proved sufficient.
   - (I2) and (I3) remove the independent complement C. A partition that generates the H-factor Z can use C only through the relative entropy, and weak containment makes that invisible.
3. **No new instance yet.**
   - Every group currently known to be Rokhlin-maximal is sofic: every known lower bound goes through sofic entropy (Seward II, introduction, recorded on main).
   - A co-amenable sofic subgroup already makes G sofic. That is the theorem of Brude–Sasyk recorded in `research/artifacts/multi-mover-hnn-dossier-2026-08-15.md`, not re-read here; Remark 4 gives a direct proof.
   - So Theorem A gives a new maximal group only once some nonsofic group is shown to be maximal. It is a permanence statement for the maximal class that uses no finite models.
4. **Co-amenable soficity induction.** Let `σ_n : H -> Sym(d_n)` be a sofic approximation, and choose Følner sets `Ω'` for a finite `W ⊆ G`. For `ω, ωg ∈ Ω'`, set `c(ω, g) = r(ω) g r(ωg)^-1 ∈ H`, and put `τ(g)(ω, i) = (ωg, σ_n(c(ω, g)^-1) i)` on `Ω' × [d_n]`, completed to a bijection off the boundary. (Use `g^-1` to turn the right action into a left one.)
   - The cocycle identity `c(ω, gg') = c(ω, g) c(ωg, g')` makes τ approximately multiplicative. The error is the boundary fraction plus the defects of `σ_n` on the finitely many values of c.
   - For `g ≠ 1`, a fixed point needs `ωg = ω`, and then `c(ω, g) ≠ 1`, which `σ_n` makes almost fixed-point free.

   This is the standard induction, included only so that Remark 3 does not rest on an unread import.

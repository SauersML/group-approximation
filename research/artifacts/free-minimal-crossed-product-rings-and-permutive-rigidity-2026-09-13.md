# Free minimal crossed-product rings: rank models, linear soficity, and permutive rigidity

Lane `ex-fp-kazhdan-ring`, 2026-09-13. Unreviewed. Part 2; part 1 is
`research/artifacts/sft-crossed-product-presentation-rigidity-2026-09-13.md` (Theorem 1 there:
finite presentation is quantum rigidity).

Setting.
- `k` is a finite field.
- `X` is a Cantor space with a free minimal action `σ` of `Z^d`; `(σ^g x)` is written `g.x`.
- `R = LC(X, k) ⋊ Z^d`, with `u^g f u^(-g) = f o σ^g`.
- For a subshift `X ⊆ A^(Z^d)`, `R` is generated by `u_i^(±1)` and the letter cylinders, plus a
  primitive element of `k` when a ring presentation is wanted.

## 1. Simplicity and centre

**Proposition 1.** `R` is simple and `Z(R) = k`. For `m >= 2`,
`Z(EL_m(R)) = EL_m(R) ∩ k^x 1_m`.

*Proof.*
1. **A nonzero element gives an idempotent.** Let `J != 0` be an ideal and
   `0 != P = sum_(g ∈ F) f_g u^g ∈ J`. After multiplying by some `u^(-g)`, assume `f_0 != 0`. Pick
   `x` with `f_0(x) = c != 0`. By freeness `g.x != x` for `0 != g ∈ F`, so there is a clopen
   `W ∋ x` with `f_0 = c` on `W` and `W ∩ σ^(-g) W = ∅` for `0 != g ∈ F`. Since
   `u^g chi_W = chi_(σ^(-g) W) u^g`, we get `chi_W P chi_W = c chi_W`, so `chi_W ∈ J`.
2. **Simplicity.** By minimality and compactness `X = ∪_(j ∈ K) σ^(-j) W` with `K` finite. Each
   `chi_(σ^(-j) W) = u^j chi_W u^(-j)` is in `J`, and inclusion–exclusion puts `1` in `J`.
3. **Centre of `R`.** If `c = sum f_g u^g` is central, commuting with `chi_W` gives
   `f_g (chi_W - chi_(σ^(-g) W)) = 0` for all clopen `W`. By freeness `f_g = 0` for `g != 0`.
   Commuting with `u^g` makes `f_0` invariant, and minimality makes it constant.
4. **Centre of `EL_m(R)`.** Commuting with every `e_ij(1)` forces `g = c 1_m` with `c ∈ R`, and
   commuting with every `e_12(r)` puts `c` in `Z(R) = k`. QED

Credit: this is the minimal effective case of Brown–Clark–Farthing–Sims; the proof is direct.

## 2. Følner rank models

For a finite `F ⊆ Z^d` and `x ∈ X`, let `rho_x` be the representation of `R` on finitely
supported functions `Z^d -> k`, given by `(u^g xi)(h) = xi(h + g)` and `(f xi)(h) = f(h.x) xi(h)`.
It is covariant. Put `psi_F(r) = Pi_F rho_x(r) Pi_F` on `k^F`, where `Pi_F` restricts to `F`.

**Proposition 2.** Let `F_n = [0, n)^d`. Then `psi_n = psi_(F_n)` is a sequence of unital,
`k`-linear, rank-approximate homomorphisms. It induces an injective unital homomorphism

```text
Psi : R -> M = prod_omega M_(n^d)(k) / {normalized-rank-null}.
```

So `R` carries a faithful Sylvester matrix rank function, and no `M_d(R)` has a halvable idempotent.

*Proof.*
1. **Unital.** `psi_n(1) = 1`.
2. **Almost multiplicative.** If `b` has propagation `<= w`, then `rho(b) Pi_F` is supported on
   `F + B_w`. So
   `psi(ab) - psi(a) psi(b) = Pi_F rho(a) (1 - Pi_F) rho(b) Pi_F`
   has rank `<= |(F + B_w) \ F| = o(n^d)`.
3. **Faithful.** Let `0 != r ∈ R`. Step 1 of Proposition 1 gives `s, t ∈ R` and a nonempty clopen
   `W` with `s r t = chi_W`. So `rk psi_n(chi_W) <= rk psi_n(r) + o(n^d)`. Now
   `rk psi_n(chi_W) = #{h ∈ F_n : h.x ∈ W}`, and with `K` as in Proposition 1 every
   `h + K` meets the visit set. So the count is at least `n^d/|K| - o(n^d)`. Hence
   `lim_omega rk psi_n(r)/n^d >= 1/|K| > 0`.
4. **Rank function.** The rank of `M` restricts to a faithful rank function on every `M_d(R)`,
   which kills halvable idempotents (`halvable-corner-makes-elementary-groups-nonsofic`). QED

## 3. Linear soficity of the projective elementary group

Say a group is *`k`-linear sofic* if it embeds in a rank ultraproduct
`prod_omega GL_(N_i)(k) / {normalized-rank-null}`. This is Arzhantseva–Păunescu's notion; the
equivalence with their finite-level definition (amplifying the separation constant) is recalled,
not re-read.

**Proposition 3.** Let `R` be a simple unital `k`-algebra with centre `k` and a unital rank model
`Psi : R -> M`. Put `G = EL_m(R)`, `m >= 2`, and `Z = G ∩ k^x 1_m`. Then `G` and `S = G/Z` are
`k`-linear sofic.

*Proof.*
1. **`G`.** `Psi` is injective, since `R` is simple. It induces
   `GL_m(R) -> M_m(M)^x = prod_omega GL_(m N_i)(k) / null`.
2. **The adjoint.** `Ad(A) = A ⊗ (A^(-1))^T` is an exact homomorphism
   `GL_N(k) -> GL_(N^2)(k)`. Since `rk(A^(-1) - B^(-1)) = rk(A - B)`, it satisfies
   `rk(Ad A - Ad B) <= 2N rk(A - B)`, so it passes to rank ultraproducts. Scalars lie in its kernel,
   so it descends to `S`.
3. **Commutant bound.** `rk(Ad A - 1) = N^2 - dim C(A)`, where `C(A)` is the commutant. Over the
   algebraic closure, with Jordan partitions `(p_i^λ)`,
   `dim C(A) = sum_λ sum_(i,j) min(p_i^λ, p_j^λ) <= sum_λ d_λ k_λ <= N max_λ dim ker(A - λ)`.
   So `rk(Ad A - 1)/N^2 >= min_λ rk(A - λ)/N`.
4. **Separation.** Let `g ∈ G \ Z` and `A_i` be representatives of `Psi(g)`.
   - For `λ ∈ k`, `g - λ 1_m != 0` in `M_m(R)`, so `lim_omega rk(A_i - λ)/(m N_i) > 0` by
     faithfulness.
   - For `λ ∉ k`, the Galois conjugates of `λ` have kernels of equal dimension, so
     `dim ker(A_i - λ) <= m N_i / 2`.

   Hence `lim_omega rk(Ad A_i - 1)/(m N_i)^2 > 0`, and `Ad o Psi` embeds `S`. QED

**For Section 2 rings.** `S = EL_m(R)/Z` is infinite and `k`-linear sofic, and `EL_m(R)` is
Kazhdan for `m >= 3`. This gives nothing new for LEF rings. For a finitely presented ring it would
give a finitely presented infinite simple group with a rank-metric approximation, provided `S` is
finitely presented and simple.

Simplicity of `S` for `d >= 2` should follow by transcribing the root detection of
`research/artifacts/simple-kazhdan-lef-subshift-elementary-group-2026-09-12.md` Section 4, with
boxes `B_m ⊆ Z^d` in place of intervals and a clopen `U` with `σ^g U ∩ U = ∅` for `0 < |g| <= L`.
That transcription is not written here and is left open.

## 4. Permutive triangles give quantum rigidity

Let `Ω ⊆ A^(Z^2)` be an SFT, `T = {0, e_1, e_2}`, and `L_T` the occurring `T`-patterns. Call `Ω`
*triangle-permutive* if each of the three projections `L_T -> A^2`, forgetting one point, is
injective. This means any two of `x(z)`, `x(z + e_1)`, `x(z + e_2)` determine the third.

**Proposition 4.** A triangle-permutive SFT is `D`-quantum rigid for every `D >= 1`. So its
crossed product is finitely presented (part 1, Theorem 1, with `D = max(1, r)`).

*Proof.* Fix a family `E` with (Q1)–(Q3). Write `𝒜(S)` for the algebra generated by the
`E_a(z)`, `z ∈ S`.
1. **Determinism is an operator identity.** Operators on `z + B_1` commute, by (Q2) with
   `2D >= 2`. Products over non-occurring `T`-patterns vanish: expand them over `B_1` and apply (Q3).
   For `(b, c)` occurring with completion `φ(b, c)`,
   `sum_a E_b(z) E_c(z+e_1) E_a(z+e_2) = E_b(z) E_c(z+e_1)`, and only `a = φ(b, c)` survives. So
   `E_a(z + e_2) = sum_(φ(b,c) = a) E_b(z) E_c(z + e_1)`.
   Likewise `E(z) ∈ 𝒜(z+e_1, z+e_2)` and `E(z+e_1) ∈ 𝒜(z, z+e_2)`.
2. **Rows.** `[𝒜(w), 𝒜(w + j e_1)] = 0` for all `w` and `j`, by induction on `j`. The cases
   `j <= 1` are (Q1) and (Q2). For `j = k >= 2`:
   - `𝒜(z) ⊆ 𝒜(z+e_2, z+e_1)`, and `𝒜(z + k e_1) ⊆ 𝒜(z + (k-1)e_1, z + (k-1)e_1 + e_2)`.
   - `E(z+e_1)` against `E(z+(k-1)e_1)`: distance `k-2`.
   - `E(z+e_1)` against `E(z+(k-1)e_1+e_2)`: the latter lies in `𝒜(z+(k-1)e_1, z+k e_1)`, at
     distances `k-2` and `k-1` from `z + e_1`.
   - `E(z+e_2)` against `E(z+(k-1)e_1)`: the former lies in `𝒜(z, z+e_1)`, at distances `k-1`
     and `k-2`.
   - `E(z+e_2)` against `E(z+(k-1)e_1+e_2)`: distance `k-1` in the row above.

   All four pairs commute by induction.
3. **All pairs.** Iterating step 1, `𝒜(z + (j, m)) ⊆ 𝒜(z + (j,0), ..., z + (j+m, 0))` for `m >= 0`,
   which commutes with `𝒜(z)` by step 2. For `m < 0`, exchange the two points. QED

Part 1, Proposition 5 (Ledrappier) is the instance `φ(b, c) = b + c` over `F_p`.

**Proposition 5 (periodicity from rows or columns).** Let `Ω` be triangle-permutive. If some
point of `Ω` has a horizontally periodic row, or a vertically periodic column, then `Ω` has a
doubly periodic point.

*Proof.*
1. **Rows.** `x(z + e_2) = φ(x(z), x(z+e_1))` is a sliding block code. If row `0` is
   `N`-periodic, every row `n >= 0` is `N`-periodic. There are finitely many such rows, so rows
   `n_0` and `n_1 > n_0` coincide.
2. **The periodic point.** Let `y` repeat rows `n_0, ..., n_1 - 1` vertically. Every `B_r`-pattern
   of `y` occurs in the upper part of `x`, so `y ∈ Ω`, and `y` is doubly periodic.
3. **Columns.** `x(z + e_1)` is determined by `x(z)` and `x(z + e_2)`, so the same argument runs
   to the right. QED

So a free triangle-permutive SFT has row and column subshifts without periodic points. In
particular both are non-sofic.

## 5. The open existence question and what it would give

**Question.** Is some free minimal `Z^2`-SFT quantum rigid, or is Labbé's shift?
- Rigidity is a conjugacy invariant: by part 1 it is equivalent to finite presentation of `R_Ω`,
  which depends only on the topological system. So any recoding may be used, including a
  triangle-permutive one.
- An affirmative answer gives, by Propositions 1–3, a finitely presented infinite-dimensional
  simple algebra over a finite field with a faithful rank function. Its `EL_m` modulo centre is
  infinite, Kazhdan for `m >= 3`, and `k`-linear sofic. It is also finitely presented and simple
  once gate (b) and the transcription of Section 3 hold.
- **Evidence against the permutive mechanism for Labbé's shift (heuristic, unchecked).**
  - `Ω_U` is almost one-to-one a coding of a toral `Z^2`-rotation (Labbé, Jeandel–Rao line; not
    re-read).
  - A column determines the rotation point only through arbitrarily fine precision. So no
    bounded-radius rule computes the next column.
  - Kari–Papasoglu 4-way determinism is determinism of tiles by edge colours. Columns are then
    determined only with a seed at infinity, which is not triangle permutivity.
- **Necessary conditions recorded.**
  - Zero entropy: positive entropy kills finite presentation.
  - Non-sofic rows and columns in any triangle-permutive recoding (Proposition 5).

## 1. Step 1 (coding) — correct
- **Left endpoints.** Let `u` be an admissible word of length `n`. Every shift of `u0^∞` is strictly below `d*_β(1)`: a factor of `u` that equals a prefix of `d*_β(1)` is followed by `0^∞`, while `d*_β(1)` is not eventually `0`. So by Parry `u0^∞` is the greedy expansion of `a_u`, and `len(a_u) <= n`.
  - Conversely, if `len(z) <= n` then `z = a_u` with `u` its first `n` digits.
  - So the level-`n` left endpoints are exactly the points of length `<= n`. This is the fact step 3 rests on.
- **Interiors.** The level-`n` intervals partition `[0,1)`, and each one's right endpoint is the next one's left endpoint. So the interior of `I_w` contains no point of length `<= |w|`.
- **The value map.** `π(uω) = a_u + β^{-|u|}π(ω)` by linearity. So a canonical similarity `[u] → [u']` with `t(u) = t(u')` is the affine map stated, with slope `β^{|u|−|u'|}`, breakpoint `a_u` and offset in `Z[β]`. Hence `V_{Γ,E} ≤ V_β`, with `E` the cone of the initial state.
  - This uses the standard right-resolving automaton of a simple Parry number, which is irreducible. Paths from `v_0` correspond bijectively to admissible sequences, so `E = C_{v_0}` is clopen.
- **Tanner's realization.** It applies because elements of `V_β` preserve `Z[β] ∩ [0,1) = Fin(β)`, by (F) and the unit hypothesis.
- **W1 (wording).** `X_β` contains `d*_β(1)`, of value `1`. So `π` identifies `X_β` with `[0,1]`, Cantorized at the interior points of `Fin(β)`, not with `[0,1)`.

## 2. Step 2 (length lemma) — correct
- **The fractional part.** `F = Σ_{i>n} z_i β^{n−i}` is the value of the shifted greedy expansion. So `F ∈ [0,1)`, `F ∈ Z[β]` since `F = y − I`, and `len(F) = len(z) − n` when `len(z) > n`.
  - The case `n <= 0` also works: then `I = 0` and `F = y`.
- **The bounds.** `|σ(I)| <= D/(1−ρ_σ)` and `|σ(F)| <= C + D/(1−ρ_σ)`. `|F| < 1` at the real place.
  - The Minkowski image of `Z[β] ≅ Z^d` is a lattice, so `F` ranges over a finite set, and `L(C)` is the maximum length over it.
- **The "Also" bound.** `|σ(b)| <= D ρ_σ^{−L}/(1−ρ_σ)` is the geometric-sum estimate.

## 3. Step 3 (uniform slope defect) — correct (the attacked step)
Put `m = |w| − k − L_β`, and suppose `b` has `len(b) <= m` and lies in `int J`. Increasing affine maps preserve interiors, so `p = β^{−k}(b−c) ∈ int I_w ∩ Z[β]`. The unit hypothesis is used here. So `len(p) > |w|`.
- **Coarse case, `len(b) < L_0(c)`.** There are finitely many such `b` over the finitely many pieces of `f`. Their preimages have finite length, so they are interior to no `I_w` with `|w|` above that length. This is absorbed into `N(f)`.
- **Fine case, `len(b) >= L_0(c)`.** Take `L = len(b)`.
  - Then `|σ(c)| <= ρ_σ^{−L}`, so `|σ(p)| <= C_β ρ_σ^{−(k+L)}`.
  - Step 2 with `n = k + L` gives `len(p) <= k + L + L_β`. So `len(b) = L > m`, a contradiction.
- **Conclusion.** No level-`m` left endpoint lies in `int J`. The level-`m` intervals are half-open and partition `[0,1)`, so `J` lies in the one containing its left endpoint.

On uniformity:
- `L_β = L(C_β)` depends only on `β`. All the dependence on `c` and on the pieces of `f` sits in `N(f)`, which the nucleus allows.
- This is bounded carry for addition in a Pisot unit base with (F), made quantitative.
- bh-free-03 §6 feared the defect is unbounded "for the group generated by all translations". That would matter only for a bound uniform over all `c` at fixed depth. The nucleus needs a bound uniform over `f` only at depths `>= N(f)`, and that is what is proved.
- The upper bound `|ō| <= |w| − k + log_β(ℓ_max/ℓ_min)` follows from comparing lengths. So `e ∈ [−L_β, log_β(ℓ_max/ℓ_min)]`.

## 4. Step 4 (offsets) — correct
- **The local action.** Evaluating at `ω = 0^∞`, a follower of every state, gives `d = π(f|_w(0^∞)) ∈ Z[β] ∩ [0, ℓ_max)`.
- **The conjugate bound.** `|σ(d)| <= ρ^{|ō|+k}|σ(a_w)| + ρ^{|ō|}|σ(a_ō)| + ρ^{|ō|}|σ(c)|`.
  - The first term is `<= Dρ^e/(1−ρ)`, since `len(a_w) <= |w|`, and `ρ^e <= ρ^{−L_β}`.
  - The second term is `<= D/(1−ρ)`.
  - The third term is `<= 1` once `|ō| >= L_0(c)`. This holds for `|w|` large, since `|ō| >= |w| − k − L_β`.
- So `d` lies in a finite set independent of `f`, by the same lattice argument.

## 5. Step 5 (finite nucleus, BBMZ input) — correct

- **Finite nucleus.** Deep local actions of every `f` lie in one finite set `𝒩`, and the shallow cones are finitely many. So every `f` is rational and `Nuc_{V_β} ⊆ 𝒩`.
- **Check against `contracting-rsgs-embed-in-fp-simple-groups`.** Its hypotheses are met: an irreducible SFT, `V_β ≤ R_{Γ,E}` containing `V_{Γ,E}`, and a finite nucleus.
  - So `V_β ≤ G_{Nuc}`, a full contracting RSG, which is finitely presented and embeds in a finitely presented simple group.
  - The local-action convention (the longest common prefix, i.e. the smallest cone `ō(w)`) matches the rational-map convention.
- **Step 6** (other lengths) is correct: conjugate by `x ↦ β^{−m}x`, then extend by the identity.

- **The rank bound.** "Rank up to `[K:Q]`" is automatic: a finitely generated subgroup of `K ≅ Q^d` has rank at most `d`.

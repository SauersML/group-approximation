# Small search for BS(1,2) witnesses in Brin's 2V (2026-09-13)

Target: `bs12-embeds-in-brin-thompson-2v`, which asks for `g, f ∈ 2V` with
`f g f^-1 = g^2` and `g` of infinite order. This is a finite search, not a
proof, and it changes no node status.

## Model

- **Elements.** An element of `2V` is a table of brick pairs
  `((d_1, d_2), (r_1, r_2))` over `{0,1}`, acting by
  `g(d_1 w_1, d_2 w_2) = (r_1 w_1, r_2 w_2)`. Domain and range bricks each
  partition the square.
- **Operations.** Composition refines range bricks against domain bricks.
  Inversion swaps the pairs.
- **Identity.** A table is the identity exactly when `d = r` for every pair,
  since prefix replacement fixes `d w` for all `w` only if `d = r`.
- **Self-test** (`selftest`, run on MSI before the search, output `selftest OK`):
  - Kojima--Sheng-type root: the element `h_1(0x, y) = (1x, y)`,
    `h_1(1x, y) = (0x, f y)`, with `f ∈ V` acting on the second coordinate,
    satisfies `h_1^2 = id × f`;
  - that `f` has infinite order;
  - two elements with disjoint supports commute.

## Job 705410

- **Script.** `bs12-2v-search-2026-09-13/bs12search.py`, md5
  `ba4e6c9038d897cd744e38c08bf383b8`. Every shard log prints this md5.
- **Elements tested.** Every table whose domain and range are partitions of the
  square into `n ≤ 5` bricks, each side of length `≤ 3`, with every bijection
  between them. There are 1, 2, 8, 39, 196 partitions for `n = 1, …, 5`, giving
  4,646,571 non-identity tables in all. Tables are not reduced, so distinct
  elements are counted with multiplicity.
- **Conjugators.** The baker maps `b(0x, y) = (x, 0y)`, `b(1x, y) = (x, 1y)` and
  `b'(0x, y) = (x, 1y)`, `b'(1x, y) = (x, 0y)`, together with their inverses.
- **Test.** `f g f^-1 = g^2` exactly, and `g^k ≠ id` for `k ≤ 48`.
- **Run.** Slurm array 705410, 32 shards on agsmall. All 32 shards printed
  `DONE` and `ALLDONE`, with no errors.
- **Result.** 0 witnesses among the 4,646,571 tables. The raw shard logs, with
  the sbatch file, are in `bs12-2v-search-2026-09-13/job705410-logs.txt`.

## Reading

- No witness with small tables exists for these conjugators.
- This does not decide `bs12-embeds-in-brin-thompson-2v`.
  `bs-kl-images-in-brin-thompson-groups-have-open-periodic-sets` shows why
  small tables are a weak test: a witness needs a nonempty closed invariant set
  without periodic points, and exponent sums of order `(log N)^2`. Both are
  global features that tables with 5 bricks of depth 3 are unlikely to show.

# Dead-edge rings: a coefficient-ring obstruction for Σ¹ of Artin groups

Lane z1-06-bns-artin, 2026-09-13. Zaremsky Problem 1.6; node
`artin-sigma1-dead-edge-ring-obstruction`. UNREVIEWED.

Notation: `Γ` a finite simplicial graph with labels `l(e) >= 2`, `A = A_Γ` with the
standard presentation (one relator per edge). For `k >= 1` and a ring element `x`
put `S_k(x) = 1 + x + ... + x^{k-1}`. `χ : A -> Z` a surjective character.
Rings are associative with 1; `R^×` is the unit group.

## 1. The twisted Laurent coefficients

Let `R` be a ring and `ρ : A -> R^×` a homomorphism. Set `S = R((t))` (Laurent series,
finitely many negative powers) and `S' = R((t^{-1}))`. The map
`g ↦ t^{χ(g)} ρ(g)` extends to ring homomorphisms `Z[A] -> S` and `Z[A] -> S'`
(`t` is central). Make `S`, `S'` right `Z[A]`-modules through them and write
`H_1(A; S) = Tor_1^{Z[A]}(S, Z)`. It can be computed from the cellular chain complex of
the universal cover of any presentation complex,
`C_2 -> C_1 -> C_0 -> Z -> 0`, which is exact at `C_1` and `C_0`.
With a right module `M`: `∂_1(w ⊗ σ_x) = w (x̄ - 1)` and
`∂_2(w ⊗ σ_r) = Σ_x w (∂r/∂x)‾ ⊗ σ_x` (Fox derivatives, bar = image in `S`).

**Units.** An element of `R((t))` whose lowest-degree coefficient is a unit of `R`
is a unit. So `t^a ρ(g) - 1` is a unit of `S` and of `S'` whenever `a != 0`.

## 2. Lemma A (finitely generated kernels kill the twisted homology)

*If `N = ker χ` is finitely generated, then `H_1(A; S) = 0` and `H_1(A; S') = 0`
for every ring `R` and every homomorphism `ρ : A -> R^×`.*

Proof. Pick `n_1, ..., n_r` generating `N` and `τ` with `χ(τ) = 1`, so `A` is
generated by `n_1, ..., n_r, τ`. Since `N` is normal there are words `w_i` in the `n_j`
with `τ n_i τ^{-1} = w_i` in `A`. Take any presentation on these generators whose
relators include `ρ_i = τ n_i τ^{-1} w_i^{-1}` (`i = 1..r`); `Tor_1` does not depend on
the choice. Work over `S'`.

- `ker ∂_1`: `Σ_i w_i (ρ(n_i) - 1) + w_τ (t ρ(τ) - 1) = 0`, and `t ρ(τ) - 1` is a unit.
  So the projection `w ↦ (w_1, ..., w_r)` is a bijection `ker ∂_1 -> S'^r`.
- The row of `ρ_i` in the `n`-coordinates is `t ρ(τ) e_i - J_i`, where
  `J_{ij} ∈ R` is the image of `∂w_i/∂n_j` (degree 0 because `χ(n_j) = 0`). We used
  `∂ρ_i/∂n_j = τ δ_{ij} - τ n_i τ^{-1} w_i^{-1} ∂w_i/∂n_j = τ δ_{ij} - ∂w_i/∂n_j` in `Z[A]`.
- `T = t ρ(τ) I - J = t ρ(τ) (I - t^{-1} ρ(τ)^{-1} J)` is invertible in `M_r(S')`: the
  second factor has inverse `Σ_{n >= 0} t^{-n} (ρ(τ)^{-1} J)^n`.

So the rows `ρ_1, ..., ρ_r` alone already project onto `S'^r`. Since `im ∂_2 ⊆ ker ∂_1`
and the projection is injective on `ker ∂_1`, we get `im ∂_2 = ker ∂_1` and
`H_1(A; S') = 0`. For `S` repeat with `τ^{-1}` (`χ = -1`) and relators
`τ^{-1} n_i τ = w_i'`; now `t^{-1} ρ(τ)^{-1} I - J'` is invertible in `M_r(R((t)))`. ∎

## 3. Fox derivatives of an Artin relator

Edge `e = {u, v}` with `l(e) = 2k`, relator `r = (uv)^k (vu)^{-k}`. Write `X_x = t^{χ(x)} ρ(x)`,
`P = X_u X_v`, `Q = X_v X_u`. Using `(vu)^j v = v (uv)^j` and `(uv)^j u = u (vu)^j`:

`(∂r/∂u)‾ = (1 - X_v) S_k(P)`, `(∂r/∂v)‾ = (X_u - 1) S_k(Q)`, and `S_k(P) X_u = X_u S_k(Q)`.

For every relator, Fox's fundamental formula gives `Σ_x (∂r/∂x)‾ (X_x - 1) = r̄ - 1 = 0`.

## 4. Theorem C (dead-edge rings)

*Let `χ : A_Γ -> Z` be nonzero. Suppose `V(Γ) = V_1 ⊔ V_2`, each `V_i` contains a
vertex with `χ(v) != 0`, and every edge between `V_1` and `V_2` is dead
(`l(e) = 2k_e >= 4`, `χ(u) + χ(v) = 0`). If there is a nonzero ring `R` and a
homomorphism `ρ : A_Γ -> R^×` with `S_{k_e}(ρ(u) ρ(v)) = 0` for every edge
`e = {u, v}`, `u ∈ V_1`, `v ∈ V_2`, then `ker χ` is not finitely generated and
`[χ] ∉ Σ^1(A_Γ)`.*

Proof. Rescale `χ` to be onto `Z`. Define the left `S`-linear map
`Φ : C_1 ⊗ S = S^{V(Γ)} -> S`, `Φ(w) = Σ_{x ∈ V_1} w_x (X_x - 1)`.

- `Φ` kills `im ∂_2`. The block of an edge with both ends in `V_1` gives
  `w Σ_x (∂r/∂x)‾ (X_x - 1) = 0`; with both ends in `V_2` it gives 0. For a cross edge
  (`u ∈ V_1`) it gives `w (1 - X_v) S_k(P) (X_u - 1)`. Here `χ(u) + χ(v) = 0`, so
  `P = ρ(u)ρ(v)` and `S_k(P) = 0` by hypothesis.
- `Φ` is onto on `ker ∂_1`. Pick live `u ∈ V_1`, `v ∈ V_2`; `X_u - 1` and `X_v - 1` are
  units, so `w = (X_u - 1)^{-1} δ_u - (X_v - 1)^{-1} δ_v` lies in `ker ∂_1` and `Φ(w) = 1`.

Hence `H_1(A_Γ; S) ↠ S != 0`. By Lemma A, `ker χ` is not finitely generated. For
Artin groups `Σ^1 = -Σ^1`, so `[χ] ∈ Σ^1` would force `ker χ` to be finitely generated
(Bieri–Renz, as quoted in `artin-sigma1-living-subgraph-bounds`). ∎

Remarks. (i) Taking `R = C`, `ρ = μ ∘ φ` for a finite abelian `φ` recovers the
hypothesis of Escartín-Ferrer's Theorem 4.4 (arXiv:2501.08692v3); partitions finer
than the components of `Liv^χ` are allowed. (ii) The same proof shows:
`H_1(A_Γ; S) != 0` whenever some nonzero left `S`-module `M` and `λ ∈ M ∖ 0`
satisfy `S_{k_e}(ρ(u_e v_e)) (X_{u_e} - 1) λ = 0` for every cross edge. Use
`Φ(w) = Σ_{x ∈ V_1} w_x (X_x - 1) λ`.

## 5. Example: the triangle A(3, 4, 6)

`Γ` is the triangle on `a, b, c` with `l(ab) = 4`, `l(ac) = 6`, `l(bc) = 3`, and
`χ = (1, -1, -1)`. Both `ab` and `ac` are dead; `Liv^χ = {a} ⊔ {b–c}`. Over `F = Q(ω)`,
`ω^2 + ω + 1 = 0`, put `y = diag(ω, ω^2)` and `M = [[1, 1], [ω/2, -ω]]`
(`det M = -3ω/2`). Define `ρ(a) = M^{-1}`, `ρ(b) = -M`, `ρ(c) = M y`. Then:

- `ρ(ab) = -I = ρ(ba)`, so `(ab)^2 = (ba)^2` holds and `S_2(ρ(ab)) = 0`;
- `ρ(ac) = y`, `ρ(ca) = M y M^{-1}`, `y^3 = I`, so `(ac)^3 = (ca)^3` holds and
  `S_3(ρ(ac)) = I + y + y^2 = 0`;
- `bcb = cbc` is equivalent to `M^2 y M = -M y M^2 y`, i.e. `M y M = -y M^2 y`. Entrywise,
  both sides are `[[ω + 1/2, ω - 1], [(ω^2 - ω)/2, ω^2/2 + ω]]`, using `ω^2 = -1 - ω`.

Theorem C with `R = M_2(F)`, `V_1 = {a}`, `V_2 = {b, c}` gives `[χ] ∉ Σ^1(A(3,4,6))`.
This agrees with Almeida–Kochloukova (circuit rank 1). The proof is new and uses a
non-abelian representation.

## 6. Limits of the method

**F1 (commutative coefficients miss A(3,4,6)).** In the example the only admissible
partition is `{a} | {b, c}`, because `bc` is odd and not dead. `b` and `c` are
conjugate, so for commutative `R` we have `ρ(b) = ρ(c)` and `z = ρ(ab) = ρ(ac)`. Then
`1 = (1 + z + z^2) - z(1 + z) = 0`, so `R = 0`. So no finite abelian twist
(Escartín-Ferrer Theorem 4.4) applies, and non-commutative coefficients are needed.

**F2 (a graph where every ring fails).** `K`: the complete graph on `u1, u2, v1, v2`
with `l(u1u2) = l(v1v2) = 2`, `l(u1v1) = l(u2v1) = l(u2v2) = 4`, `l(u1v2) = 6`, and
`χ = (1, 1, -1, -1)`. `Liv_0^χ = K` is connected; `Liv^χ = {u1–u2} ⊔ {v1–v2}`. The
label-2 edges are alive, so the only admissible partition is
`{u1, u2} | {v1, v2}`. In any ring with the four dead-edge sums zero:
`u1v1 = -1 = u2v1` gives `u1 = u2`; then `u1 v2 = u2 v2 = -1` and
`S_3(u1 v2) = 1 - 1 + 1 = 1 = 0`. So `R = 0`: Theorem C never applies to `K`.
`K` has circuit rank 3, halves 2 and 3 across the cut, is not balanced and not
coherent. It is outside families 1–4 and 6–11 of
`artin-sigma1-conjecture-known-families` (family 5 not checked). Either
`[χ] ∈ Σ^1(A_K)`, which would refute the Σ¹-conjecture, or a module witness as in
Remark (ii) is needed.

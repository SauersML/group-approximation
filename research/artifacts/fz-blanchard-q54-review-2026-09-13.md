**Question 5.4** (same wording in both). It first notes that T(E_DD) is locally purely infinite
([BK04b, Definition 1.3]), since all its simple quotients are isomorphic to O_∞ ([BK04b,
Proposition 5.1]). It then asks: "But is T(E_DD) properly infinite?" This is a yes/no question
about one algebra, so a proof that T(E_DD) is properly infinite answers it fully.

### Definitions the question depends on

Pages are those of 1507.02535v1. In 1312.7722v7 the same text is in the proof of Prop. 4.2
(pp. 5-6), Definition 5.1 (p. 6), Prop. 5.2 (p. 7) and Remark 5.3 a) (p. 8); v7 has no a').

- **Properly infinite** (Remark 2.2 b), p. 2): A contains two isometries with mutually orthogonal
  range projections, i.e. A unitally contains T_2.
- **T(E)** (Definition 5.1, p. 7): X is compact Hausdorff and E is a full Hilbert C(X)-module,
  "i.e. without any zero fibre". F(E) = ⊕_{m∈N} E^{⊗_{C(X)} m} with E^{⊗0} = C(X), and T(E) is
  the unital subalgebra of L(F(E)) generated by the creation operators ℓ(ζ), ζ ∈ E. By (5.2),
  ℓ(ζ)(f·1̂) = f·ζ = ζ·f and ℓ(ζ)(ζ_1⊗…⊗ζ_k) = ζ⊗ζ_1⊗…⊗ζ_k.
- **E_DD** (proof of Prop. 4.3, p. 6). Part (a)⇏(b) introduces it as the non-trivial Hilbert
  C(B_∞)-module with fibres ℓ²(N) of [DD63, §17] and [BK04a, Prop. 3.6], where
  B_∞ = {x ∈ ℓ²(N) : Σ_p|x_p|² ≤ 1} with d(x,y) = Σ_p 2^{-p-2}|x_p − y_p|. Part (b)⇏(c) makes
  it explicit: η(x) = x ⊕ √(1−‖x‖²), F̈ = [C(B_∞, ℓ²(N)⊕0) + C(B_∞)·η], θ_{η,η}ζ = η⟨η,ζ⟩ and
  E_DD = (1−θ_{η,η})·F̈, "the Hilbert C(B_∞)-submodule built in [DD63]".
- **H̃** ((4.6), p. 6): with Y = B_∞×(B_3)^∞,
  H̃ = C(Y) ⊕ E_DD⊗C((B_3)^∞) ⊕ C(B_∞)⊗[f̃·ℓ²(N, C((B_3)^∞)²)].
  Remark 5.3 a') (p. 8) asks whether T(H̃) is properly infinite.
- **Blanchard's own route** (Prop. 5.2 3), p. 8) needs a section ξ with ‖ξ_x‖ = 1 for all x,
  then uses [Blan13, Lemma 6.1]. Remark 5.3 a) notes that every section of E_DD vanishes
  somewhere, so this route cannot apply to E_DD.

The artifact's section 1 matches this setup. Its quote of Question 5.4 omits the two [BK04b]
citations (cosmetic).

## 2. Step-by-step check

Conventions: fibres E_x are Hilbert spaces with ⟨ξ_x,ζ_x⟩ = ⟨ξ,ζ⟩(x); inner products are linear in
the second variable (Remark 2.2 c): θ_{ξ1,ξ2}ζ = ξ1·⟨ξ2,ζ⟩); C(X) acts centrally, so
⟨a⊗b, c⊗d⟩ = ⟨a,c⟩⟨b,d⟩ in E⊗_{C(X)}E.

**E_DD as the node uses it.** Checked. For f ∈ C(B_∞, ℓ²⊕0), ⟨η,f⟩(x) = ⟨x, f(x)⟩ is
d-continuous, since f is norm continuous and x ↦ x is bounded and weakly continuous. As
⟨η,η⟩ = 1, P = 1 − θ_{η,η} is a projection and E_DD = PF̈. The constant sections e_k⊕0 lie in F̈
and are orthonormal.

**Lemma 1** (orthonormal θ_1, θ_2 ∈ E^{⊗k} give two isometries in T(E)). Checked.
- For θ = Σ_i z^i_1⊗…⊗z^i_k put l_k(θ) = Σ_i ℓ(z^i_1)…ℓ(z^i_k). It is a finite sum of products of
  generators, so it lies in T(E), and by (5.2) it acts by ω ↦ θ⊗ω (θ·f in degree 0).
- Different degrees are orthogonal, and ⟨θ⊗ω, θ'⊗ω'⟩ = ⟨ω, ⟨θ,θ'⟩·ω'⟩, so
  l_k(θ)*l_k(θ') is multiplication by ⟨θ,θ'⟩. If ⟨θ_i,θ_j⟩ = δ_ij, then s_i = l_k(θ_i) satisfy
  s_i*s_j = δ_ij·1, and Remark 2.2 b) applies.
- Wording nit: the node calls the isometries "the creation operators l(θ_1), l(θ_2)". They are
  l_2(θ_i), sums of products of two creation operators; the artifact says this correctly.

**Proposition 2.** Checked. Setup: E = PF with 1−P = Σ_{j≤n} θ_{η_j,η_j} for orthonormal η_j, and
orthonormal sections e_1..e_{2N} of F, N = 3n+1.
- ζ_k = Pe_k gives ⟨ζ_k,ζ_l⟩ = δ_kl − M_kl with M_kl = Σ_j⟨e_k,η_j⟩⟨η_j,e_l⟩ = (BB*)_kl. B*B is
  the Gram matrix of the projections of the η_j(x) onto span{e_k(x)}, so 0 ≤ M ≤ 1, tr M ≤ n.
- For I = {1..N} and V = Σ_{k∈I} ζ_k⊗ζ_k: ⟨V,V⟩ = Σ_{k,l∈I}⟨ζ_k,ζ_l⟩² (a plain square, not |·|²)
  = N − 2Σ_{k∈I}M_kk + tr(M_I·conj(M_I)). Since conj(M_I) = M_Iᵀ ≥ 0, the trace is ≥ 0, so
  ⟨V,V⟩ ≥ N − 2n = n+1. The same holds for W = Σ_{l∈J} ζ_l⊗ζ_l, J = {N+1..2N}.
- ⟨V,W⟩ = Σ_{k∈I,l∈J} M_kl², so |⟨V,W⟩| ≤ Σ_{k,l}|M_kl|² = tr M² ≤ tr M ≤ n.
- Gram–Schmidt: θ_1 = V·v^{-1/2} with v = ⟨V,V⟩. W' = W − V·v^{-1}⟨V,W⟩ is orthogonal to V, and
  w = ⟨W',W'⟩ = ⟨W,W⟩ − |⟨V,W⟩|²/v ≥ (n+1) − n²/(n+1) = (2n+1)/(n+1) > 0; θ_2 = W'·w^{-1/2}.
  Each θ_i is a finite sum of ζ⊗(ζ'·g) with ζ, ζ' ∈ E, g ∈ C(X), so Lemma 1 applies.

**Sharpness check** (n = 1, F = F̈, E = E_DD). At x = (e_1 + i e_2)/√2, ‖x‖ = 1 and η(x) = x⊕0.
P(x) projects onto η(x)^⊥, so Pe_1 = u and Pe_2 = i·u with u = (e_1 − i e_2)/2, and
Pe_1⊗Pe_1 + Pe_2⊗Pe_2 = u⊗u + i²·u⊗u = 0. With blocks of size 2, V(x) = 0. With N = 4,
V(x) = e_3⊗e_3 + e_4⊗e_4 and ⟨V,V⟩(x) = 2 = N − 2n. So the cancellation is real and the bound
N − 2n is attained. The crude Gram–Schmidt bound is positive exactly when N − 2n > n, i.e. N ≥ 3n+1.

**Theorem 3.** Checked.
- (a) F = F̈, n = 1, η_1 = η, e_k = e_k⊕0 for k ≤ 8. PF̈ = E_DD by Blanchard's printed definition,
  and E_DD is full (fibres ℓ²(N)). Proposition 2 and Lemma 1 make T(E_DD) properly infinite.
- (b) E' = E_DD⊗C((B_3)^∞) = (1−θ_{η⊗1,η⊗1})(F̈⊗C((B_3)^∞)) has constant sections e_k⊗1, so
  Proposition 2 over Y gives orthonormal θ_1, θ_2 ∈ E'⊗E'. This is an orthogonal summand of H̃⊗H̃
  with the restricted inner product, its elementary tensors have entries in H̃, and H̃ is full
  (it contains C(Y)). So Lemma 1 applies to T(H̃).

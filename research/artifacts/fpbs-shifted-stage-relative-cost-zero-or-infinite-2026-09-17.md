# Shifted stages: relative cost is 0 or infinity at every stage

Worker swarm-0917-w5-pull-fp-2 (inverter), September 17, 2026.
Target: `fpbs-fixed-price-non-amenably-generated-from-fg`, test group
`Gamma_mal`.

## 0. Setting and notation

- `Gamma` is a countable group, `H_0 <= H_1 <= ...` are subgroups with
  `U_n H_n = Gamma`.
- A **stage shift** is an automorphism `theta` of `Gamma` with
  `theta(H_n) = H_{n+1}` for every `n`.
- `a` is a free p.m.p. action of `Gamma` on `(X, mu)`. Write `E = E_a` and
  `R_n = E_{a|H_n}`.
- `a` is **theta-invariant** if some `T in Aut(X, mu)` satisfies
  `T a(g) T^{-1} = a(theta(g))` for all `g`.
- For p.m.p. relations `S <= R`,
  `relC(R; S) = inf { C(Phi) : Phi a graphing with S v Phi = R }`,
  where `S v Phi` is the relation generated by `S` and `Phi`.
  Two facts follow directly from the definition:
  - taking a union of graphings gives `C(R) <= C(S) + relC(R; S)`;
  - a measure-preserving isomorphism of pairs `(R, S) -> (R', S')` preserves
    `relC`.

## 1. Theorem S (stationarity)

Let `theta` be a stage shift and let `a` be a theta-invariant free action.

1. `relC(E; R_n) = relC(E; R_0)` and `C(R_n) = C(R_0)` for every `n`.
2. If `C(a) < infinity`, then `relC(E; R_n) -> 0`. This part needs no shift.
3. Hence, if `C(R_0) < infinity`:
   - **either** `C(a) < infinity` and `relC(E; R_n) = 0` for every `n`;
   - **or** `C(a) = infinity` and `relC(E; R_n) = infinity` for every `n`.
4. For every automorphism `theta` of `Gamma`, the Bernoulli shift
   `beta: Gamma -> Aut([0,1]^Gamma, Leb^Gamma)` is free and theta-invariant.

### Proof

**Item 1.** From `T a(g) T^{-1} = a(theta g)`:
- `T(x, a(g)x) = (Tx, a(theta g) Tx)`, so `T(R_n) = E_{a|theta(H_n)} = R_{n+1}`;
- `T(E) = E_{a|theta(Gamma)} = E`.

So `T` is an isomorphism of pairs `(E, R_n) -> (E, R_{n+1})`. It preserves
`relC` and `C`. Induct on `n`.

**Item 2.** Let `Phi = (phi_j)` be a graphing of `E` with `C(Phi) < infinity`.
- Since `a` is free, each `x` in the domain of `phi_j` has a unique
  `g in Gamma` with `phi_j(x) = a(g)x`. So the domain splits into Borel
  pieces `D_{j,g}`, and `sum_{j,g} mu(D_{j,g}) = C(Phi)`.
- Let `Phi'_n` be the pieces with `g` outside `H_n`. The pieces with `g` in
  `H_n` lie in the full groupoid of `R_n`. So `R_n v Phi'_n` contains every
  piece and equals `E`.
- Hence `relC(E; R_n) <= C(Phi'_n)`. Each `g` lies in `H_n` for all large `n`.
  By dominated convergence, `C(Phi'_n) -> 0`.

**Item 3.** By item 1, `relC(E; R_n)` is a constant `c`.
- If `c < infinity`, then `C(a) <= C(R_0) + c < infinity`. Item 2 gives
  `c = lim relC(E; R_n) = 0`.
- If `C(a) < infinity`, then item 2 again gives `c = 0`.
- Otherwise `C(a) = infinity` and `c = infinity`.

**Item 4.**
- **Invariance.** Put `(Tx)_gamma = x_{theta^{-1}(gamma)}`. This permutes
  coordinates, so it preserves `Leb^Gamma`. Then
  `(T beta(g) x)_gamma = x_{g^{-1} theta^{-1}(gamma)}` and
  `(beta(theta g) T x)_gamma = (Tx)_{theta(g)^{-1} gamma} = x_{g^{-1} theta^{-1}(gamma)}`.
- **Freeness.** Take `g != 1`. The orbits of left multiplication by `g` on
  `Gamma` all have size at least 2, and there are infinitely many of them. A
  fixed point of `beta(g)` is constant on each orbit. With a non-atomic base
  this is a null event. There are countably many `g`, so `beta` is free. QED

## 2. Corollary M (the Bernoulli shift of Gamma_mal)

`Gamma_mal = <a, b_1, b_2, ... | b_k = b_{k+1} a b_{k+1}^{-2}>` with
`H_m = <a, b_m>`, free on `{a, b_m}`, and `H_m <= H_{m+1}`.

**Stage shift.** `theta(a) = a`, `theta(b_k) = b_{k+1}` respects the relations.
- It is an endomorphism.
- It maps the basis `{a, b_k}` of `H_k` to the basis `{a, b_{k+1}}` of
  `H_{k+1}`. So `theta(H_k) = H_{k+1}` and `theta` is injective on every stage,
  hence on `Gamma_mal`.
- It is surjective: `a` is in the image, `b_k = theta(b_{k-1})` for
  `k >= 2`, and `b_1 = b_2 a b_2^{-2} = theta(b_1 a b_1^{-2})`.

Equivalently, `theta` is conjugation by `t^{-1}` in the ascending HNN extension
`M = F_2 *_phi`.

**Stage costs.** `beta|H_n` is a free action of `F_2`. Gaboriau's lecture
notes, Corollary 2.25, verbatim: "The following groups are strongly treeable
and have fixed price: C∗(Fn) = C∗(Fn) = n for the free group of rank n." So
`C(R_n) = 2` for all `n`.

**Conclusion.** For the Bernoulli shift `beta` of `Gamma_mal`, and for every
theta-invariant free action, for instance the restriction of any free action
of `M`:

```text
C(beta) = 2          iff   relC(E_beta ; E_{beta|H_1}) = 0
C(beta) = infinity   iff   relC(E_beta ; E_{beta|H_1}) > 0
                     iff   relC(E_beta ; E_{beta|H_n}) = infinity for all n.
```

The value `2`, rather than just "finite", comes from
`fpbs-locally-free-free-action-costs-are-c-star-or-infinite` with `c* = 2`.

## 3. What this changes

- **One-stage inverter test.** Shape (B) at the Bernoulli shift of
  `Gamma_mal` needs no uniform-in-`n` floor. Any positive lower bound for the
  single relative cost `relC(E_beta; E_{beta|H_1})` gives `C(beta) = infinity`.
  With the cost-2 stages `R_n`, that answers:
  - Gaboriau's Q 2.66 positively: "Is there an example of an increasing
    sequence of p.m.p. equivalence relations Rn such that:
    C(∪n↗Rn) > lim inf C(Rn)?";
  - the second part of Q 2.65 (`C - 1 = infinity > beta_1^(2) = 1`);
  - it refutes `fpbs-locally-free-free-actions-have-finite-cost`.

  This is recorded as OPEN `fpbs-mal-bernoulli-single-stage-floor`.
- **No intermediate regime.** For theta-invariant actions there is no
  "slowly decaying" relative cost. A route that proves only
  `0 < relC(E; R_n) <= eps_n` with `eps_n -> 0` proves `C = 2`, and hence
  `relC = 0` exactly. A route that proves `relC(E; R_n) >= delta_n > 0` for one
  `n` proves `C = infinity`.
  - The packing floor `delta_mal` of
    `fpbs-malnormal-coset-cycles-linear-perimeter` is a floor for packing
    certificates only. If it extended to all graphings at one stage, it would
    already give shape (B) for `beta`.
  - Conversely, `fpbs-mal-long-generator-packing-growth` would give
    `relC(E_beta; E_{beta|H_1}) = 0` exactly.
- **Labels must be unbounded.** A graphing `Phi` with `R_1 v Phi = E` must use
  labels outside every fixed `H_N`. Otherwise `R_1 v Phi <= R_N != E`. So a
  proof of `C(beta) = 2` must pay for arbitrarily long generators with
  arbitrarily small mass. This is the regime of the long-generator claim.

## 4. Not claimed

- Nothing about whether `relC(E_beta; E_{beta|H_1})` is `0` or positive.
- Nothing about free actions of `Gamma_mal` that are not theta-invariant.
  Cost monotonicity under weak containment is not imported for groups that are
  not finitely generated, so the Bernoulli value does not bound other actions.
- Nothing about `C*(Gamma_mal) < infinity`, that is, whether some free action
  has finite cost. By Theorem S, the Bernoulli shift has finite cost iff item 3
  lands in its first case.

# Full groups and elementary groups, part 2: Thompson's V_d inside Leavitt units

## 0. Summary

`k` is a countable field and `d >= 2`. `R = L_k(1,d)` has generators `s_i, t_i` with `t_i s_j = δ_ij` and
`Σ s_i t_i = 1`, and `H = R^×`. For a word `w`, `e_w = s_w t_w`. The Cuntz groupoid `𝒢_d` of the full shift on
`d` letters has `A_k(𝒢_d) ≅ R` (`leavitt-path-algebras-are-steinberg-algebras`), with `1_(Z(w)) ↦ e_w`. Its
topological full group is the Higman–Thompson group `V_d := V_(d,1)`, which sits in `H` through the bisection units
(`full-group-units-embed-in-steinberg-algebras`). `κ : H -> K_1(R)` is the canonical map.

**Theorem 2.**
1. Every homomorphism from `H` to an MF group restricts on `V_d` to a map with image of order at most 2, trivial on
   `D(V_d)`. More precisely, `κ(V_d) = ⟨[−1]⟩ ⊆ K_1(R)`, and `[−1]^2 = 1`.
2. If `d` is even, or if `−1 ∈ (k^×)^(d−1)`, then `V_d ⊆ Rad_MF(H)`: every homomorphism from `H` to an MF group kills
   `V_d`.
3. If `d` is odd and `−1 ∉ (k^×)^(d−1)`, then `[−1] ≠ 1`, `V_d ∩ Rad_MF(H) = D(V_d)`, and `κ|_(V_d)` is the parity
   character `V_d -> Z/2`. This item uses ABC Cor 7.7; see §3.
4. `⟨[H,H], V_d⟩ = κ^(-1)⟨[−1]⟩`. So `[H,H]` and `V_d` generate `H` iff `K_1(R) = ⟨[−1]⟩`.

Special cases:
- **Thompson's V** (`d = 2`): V lies in the MF radical of every binary Leavitt unit group, over every countable field.
- **Visible parity:** `k = Q` or `F_3` with `d = 3`, where the parity of `V_3` is the only MF shadow.
- **Invisible parity:** `k = F_5`, `d = 3` (`−1 = 2^2`), and every `k` of characteristic 2.

**What it does NOT say (firewall).** Nothing about whether `V_d` itself is MF, sofic or hyperlinear. A subgroup of a
group with a large MF radical can be MF: `k^× ⊆ H` is abelian, hence MF. What does follow is that if `V_d` is MF, then
none of its MF approximations extends to `H`, beyond the parity character.

## 2. Proofs

**Lemma 2.1 (scalars).** `[λ]^(d−1) = 1` in `K_1(R)` for every `λ ∈ k^×`.

*Proof.*
- The isomorphism `φ : R_R -> R_R^d`, `x ↦ (t_1x, …, t_dx)`, carries left multiplication by `u ∈ H` to the matrix
  `(t_i u s_j)`. For the central scalar `λ` this is `λ I_d`.
- By (K), `[λ] = [λ I_d]`. Each `diag(1,…,λ,…,1)` is conjugate by a permutation matrix to `diag(λ,1,…,1)`, whose class
  is `[λ]`. So `[λ I_d] = [λ]^d`.
- Hence `[λ]^(d−1) = 1`. ∎

So `[−1]^(d−1) = 1` and `[−1]^2 = 1`. For `d` even `d−1` is odd, so `[−1] = 1`. If `−1 = μ^(d−1)`, then
`[−1] = [μ]^(d−1) = 1`.

**Lemma 2.2 (transpositions).** Let `α ∈ V_d` be a transposition with clopen `A`, and write `A` as a disjoint union of
`m` cylinders. Then `κ(α) = [−1]^m`.

*Proof.*
- **Block form.** Let `U` be the compact open bisection of germs of `α` on `A`, so `s(U) = A` and `r(U) = α(A)`. As
  `α^2 = 1`, the unit is `1_α = 1_U + 1_(U^(-1)) + 1_W`, with `W = X \ (A ∪ α(A))`.
  - Decompose `R_R = 1_A R ⊕ 1_(α(A)) R ⊕ 1_W R` by orthogonal idempotents.
  - Left multiplication by `1_α` sends `1_A R -> 1_(α(A)) R` by `1_U·`, and back by `1_(U^(-1))·`, which is the inverse
    isomorphism `ψ`. It is the identity on `1_W R`, and the cross terms vanish.
  - So it is the block matrix `[[0, ψ^(-1), 0], [ψ, 0, 0], [0, 0, 1]]`.
- **Reduction to a sign.** From `[[0,a],[−a^(-1),0]] = [[1,a],[0,1]] [[1,0],[−a^(-1),1]] [[1,a],[0,1]]` and
  `[[0,a],[a^(-1),0]] = [[0,a],[−a^(-1),0]] · diag(−1,1)`, the class is that of `−1` on `1_A R` plus the identity,
  i.e. `[1 − 2·1_A]`.
- **Cylinders.**
  - Write `1_A = Σ_(i=1)^m e_(w_i)` with orthogonal `e_(w_i)`, so `1 − 2·1_A = ∏_i (1 − 2e_(w_i))`.
  - `1 − 2e_w` is `−1` on `e_w R` and the identity on `(1 − e_w)R`. Moreover `e_w R ≅ R` via `x ↦ t_w x`, with inverse
    `y ↦ s_w y`.
  - By (K), `[1 − 2e_w] = [−1_R ⊕ id] = [−1]`.
  - Hence `κ(α) = [−1]^m`. ∎

*Well-definedness check.* Replacing a cylinder by its `d` children changes `m` by `d−1`, and `[−1]^(d−1) = 1`
(Lemma 2.1).

**Proof of Theorem 2.**
1. By (M), `V_d = [[𝒢_d]]` is generated by transpositions, so by Lemma 2.2, `κ(V_d) ⊆ ⟨[−1]⟩`. The swap
   `s_2t_1 + s_1t_2 + Σ_(i>=3) s_it_i` is the transposition exchanging `Z(1)` and `Z(2)`, with `m = 1`, so
   `[−1] ∈ κ(V_d)`.
   - By (Q), every homomorphism `H -> M` into an MF group factors through `κ`, so it maps `V_d` onto a quotient of
     `⟨[−1]⟩`, of order `<= 2`. It kills `D(V_d)`, since `K_1` is abelian.
2. By Lemma 2.1, `[−1] = 1` in those cases, so `κ(V_d) = 1`. As `ker κ = Rad_MF(H)` by (Q), `V_d ⊆ Rad_MF(H)`.
3. Assume `[−1] ≠ 1` (§3). Then `κ|_(V_d)` is onto `Z/2`, its kernel is `V_d ∩ ker κ = V_d ∩ Rad_MF(H)`, and it has
   index 2. By (M), `V_d/D(V_d) ≅ Z_(d−1) ⊗ Z_2 = Z/2` for `d` odd, so that kernel is `D(V_d)`.
4. `ker κ = [H,H]` by (Q), so `⟨[H,H], V_d⟩ = κ^(-1)(κ(V_d)) = κ^(-1)⟨[−1]⟩`. ∎

**Model test.** `d = 2`, `k = F_2`: `H` is perfect (`leavitt-gl-equals-el-and-perfect-unit-group`), so everything lies
in `[H,H]`, which is consistent with item 2.

## 3. The arithmetic criterion for [−1] ≠ 1 (item 3)

Ara–Brustenga–Cortiñas, Corollary 7.7 (read from the text on MSI), for a PID `k` and a row-finite quiver `E`:

`K_1(L_k(E)) = coker(1 − N^t : K_1(k)^(E^0 \ Sink(E)) -> K_1(k)^(E^0)) ⊕ ker(1 − N^t : Z^(E^0 \ Sink(E)) -> Z^(E^0))`.

For one vertex with `d` loops, `N = (d)`, so `K_1(L_k(1,d)) ≅ k^×/(k^×)^(d−1)`.

**Caveat, recorded as the only unreviewed external input.** The printed text does not name the map `K_1(k) -> K_1(L_k(E))`.
I use the canonical one induced by the vertex inclusion `k -> L_k(1,d)`, as in ABC's construction (§§6–7, recalled,
not re-read in the garbled text). Under that identification `[λ] ↦ λ (mod (k^×)^(d−1))`, so `[−1] ≠ 1` iff
`−1 ∉ (k^×)^(d−1)`.
- The direction `−1 ∈ (k^×)^(d−1) ⇒ [−1] = 1` is Lemma 2.1 and needs no import.

## 4. Consequence for the dictionary (question (c))

Take a minimal effective ample `𝒢` with `A_k(𝒢)` purely infinite simple (Larki,
`purely-infinite-steinberg-algebras-characterized`). By (Q), the image of `[[𝒢]]` in any MF quotient of `A_k(𝒢)^×`
factors through `[[𝒢]] -> K_1(A_k(𝒢))`, which kills `D([[𝒢]])`. The same block computation as Lemma 2.2 sends a
transposition on `A` to `[1 − 2·1_A]`.

So on the paradox side the MF shadow of the full group inside the units is at most `[[𝒢]]^ab`, and is visible only
through `K_1`. On the measure side (part 1), the full group and the elementary groups are LEF together. That asymmetry is
the dictionary: the ring's units see the full group combinatorially when a model exists, and only through `K_1` when
the ring is purely infinite.

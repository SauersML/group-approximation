# Dyadic correlated-dessin cycle gate — 2026-08-22

For a modular dessin `(a,b)`, with `a^2=b^3=1`, set `u=ab`.  Eliminating
`b` from the Iwahori edge involution gives

```text
e=u a u^2 a,
alpha(u)=u^(-1)e=a u^2 a.
```

Hence a Nielsen match between two modular-extendible edge actions forces
their parabolics to be mutual squares up to conjugacy.  Each is therefore
conjugate to its fourth power.  A maximal 2-adic valuation argument on cycle
lengths shows that this is possible only when every parabolic cycle is odd.

This identifies the exact conditioned locus left after the generic random
edge model was excluded: correlated random dessins must be sampled with
odd face cycles.  The statistic is robust for uniformly bounded face
degrees, but not for macroscopic cycles, because a few Hamming edits can
merge or split long cycles.  Thus the next construction should use
odd-face one-face/few-face dessins or another deliberately odd parabolic
ensemble; an ordinary random permutation face law is not the right model.

# Weakly finite hosts for Leavitt unit groups: construction-side census

Lane `w6-wf-construct`, 2026-09-12. This is the construction side of the weak-finiteness form of both
counterexample routes.

**Hosts.** A **host** is a nonzero ring `W` with `p·1 = 0` and a homomorphism `ρ : G -> W^x` such that:
- for `G = L_(F_2)(1,2)^x` and `p = 2`, `ρ` is nontrivial;
- for `G = G_3 = L_(F_3)(1,2)^x`, `z = -1` and `p = 3`, `ρ(z) = -1`.

**Why a host matters.** A weakly finite host refutes
`binary-complement-corner-has-no-weakly-finite-image` (through
`binary-corner-weakly-finite-images-are-unit-representations`) or
`ternary-leavitt-units-have-no-weakly-finite-representation`. A host kills both corner routes but does not decide
Gottschalk: a counterexample needs only `J_1(F_p[G]) ≠ 0`
(`weakly-finite-reflection-ideal-detects-weakly-finite-images`).

**Weak finiteness.** `W` is **n-weakly finite** when `AB = I_k` implies `BA = I_k` for every `k <= n`. It is
weakly finite when this holds for every `n`.

**Notation.** `L_(F_p)(1,2)` is generated by `s_0, s_1, t_0, t_1` with `t_i s_j = δ_ij` and
`s_0 t_0 + s_1 t_1 = 1`. For a word `w = i_1…i_r`, put `s_w = s_(i_1)…s_(i_r)` and `t_w = t_(i_r)…t_(i_1)`.

## 0. Result

No construction was found.
- **Theorem A** (`leavitt-unit-hosts-need-nilpotents-of-unbounded-index`). Every host, weakly finite or not,
  contains nilpotents of unbounded index. This rules out division rings, `M_n(D)`, semisimple Artinian and
  semiprime Goldie rings, reduced rings and finite-dimensional algebras.
- **Corollary A.2** (same node). A Sylvester rank function on `F_2[G]` other than the augmentation rank, or one on
  `F_3[G_3]` with `rk(1 + [z]) = 0`, takes infinitely many values and lies in no `(1/N)Z`. It invalidates
  `nonaugmentation-rank-function-from-a-discrete-rank-model`.
- **Theorem B** (`leavitt-unit-hosts-exclude-matrices-over-commutative-rings`). There is no host inside
  `GL_n(C)` with `C` commutative, whatever its nilpotents. Remark B.2 extends this to PI rings, conditional on
  imported theorems.
- **Proposition D** (`weakly-finite-leavitt-hosts-reduce-to-bounded-matrix-size`). A weakly finite host
  exists iff an `n`-weakly finite host exists for every `n`. An algebraic ultraproduct is a host only if its
  factors already carry injective unit images of `V`.
- **Section 5.** Traces, crossed products, Ore localizations and presented algebras either reduce to existing
  nodes or die at the point stated there.
- **Section 6.** The resulting portrait of any host.

## 1. Theorem A: hosts need nilpotents of unbounded index

**Theorem A.** Let `W` be a nonzero ring with `p·1 = 0` whose nilpotent elements all satisfy `x^N = 0` for one
fixed `N`.
1. For `p = 2`, every homomorphism `L_(F_2)(1,2)^x -> W^x` is trivial.
2. For `p = 3`, no homomorphism `G_3 -> W^x` has `ρ(z) = -1`.

**Ternary input.** Part 2 uses that every normal subgroup `M` of `G_3` lies in `{±1}` or equals `G_3`. The
sources are `G_3/{±1}` simple (`odd-leavitt-unit-groups-mod-scalars-are-fp-simple`, conditional on its imports)
and `G_3` perfect (`leavitt-gl-equals-el-and-perfect-unit-group`). If `M ⊄ {±1}`, simplicity gives
`M{±1} = G_3`, so `G_3 = [G_3, G_3] = [M, M] ⊆ M`.

**Proof.**
- **p-power elements.** For `n >= 2` the words `0, 10, 110, …, 1^(n-2)0, 1^(n-1)` form a complete prefix code
  `w_1, …, w_n`. For `π ∈ S_n`, `u_π = Σ_i s_(w_(π(i))) t_(w_i)` satisfies `u_π u_σ = u_(πσ)` and `u_1 = 1`,
  because `t_w s_(w') = δ_(w,w')` on a prefix code and `Σ_i s_(w_i) t_(w_i) = 1`. It is injective, since
  `u_π s_(w_i) = s_(w_(π(i)))`. So `S_n ≤ V ≤ G` for every `n`, and a `p^k`-cycle gives an element of order
  exactly `p^k`.
- **Unipotence.** The elements `1` and `ρ(x)` commute and `p·1 = 0`, so `(ρ(x) - 1)^(p^j) = ρ(x)^(p^j) - 1` for
  every `j`. If `x^(p^k) = 1`, then `ρ(x) - 1` is nilpotent, so `(ρ(x) - 1)^N = 0`. For `p^j >= N` this gives
  `ρ(x)^(p^j) = 1`.
- **Kernel.** Take `x` of order `p^(j+1)`. Then `y = x^(p^j)` has order `p` and `ρ(y) = 1`.
  - `p = 2`: `G` is simple (`binary-leavitt-unit-group-is-simple`), so `ρ` is trivial.
  - `p = 3`: `y ∉ {±1}` because it has order 3. So `ker ρ = G_3` and `ρ(z) = 1`, which differs from `-1` in a
    nonzero ring of characteristic 3. ∎

**Sharper form.** Let `ρ` be nontrivial into any ring with `p·1 = 0`, or for `p = 3` have `ρ(z) = -1`.
- Then no element of order `p` lies in `ker ρ`, by the Kernel step.
- So for a `p^k`-cycle `x`, `(ρ(x) - 1)^(p^(k-1)) = ρ(x^(p^(k-1))) - 1 ≠ 0`, while `(ρ(x) - 1)^(p^k) = 0`.

**Corollary A.1 (dead hosts).** None of the following is a host.
- **Division rings** (`N = 1`).
- **`M_n(D)` over a division ring `D`.** A nilpotent endomorphism of `D^n` satisfies `x^n = 0`. The same holds
  for subrings of `∏_i M_(n_i)(D_i)` with all `n_i <= n`.
- **Semiprime right Goldie rings, prime ones included.** Their classical quotient ring is semisimple Artinian
  (Goldie's theorem, at statement level), so they sit in a finite product of such matrix rings.
- **Reduced rings** (`N = 1`).
- **Finite-dimensional algebras.** Left multiplication is faithful, so `x^(dim W) = 0`.
- **Algebraic ultraproducts `∏_U M_(n_i)(D_i)` with bounded `n_i`.** Such a ring is `M_n(∏_U D_i)`.

## 2. Theorem B: matrices over commutative rings

**Theorem B.** Let `C` be a nonzero commutative ring and `n >= 1`.
1. Every homomorphism `L_(F_2)(1,2)^x -> GL_n(C)` is trivial.
2. If `3·1 = 0` in `C`, no homomorphism `G_3 -> GL_n(C)` sends `z` to `-1`.

**Proof.**
- **Finite generation.** Both groups are generated by `V` and one transvection
  (`leavitt-prime-field-units-generated-by-v-and-one-transvection`). `V` is finitely generated
  (`thompson-v-finitely-presented-infinite-simple`).
- **Malcev over commutative rings** (imported at statement level; `finitely-generated-linear-groups-are-residually-finite`
  is the field case).
  - A finitely generated `Γ ≤ GL_n(C)` lies in `GL_n(C_0)`, where `C_0` is the finitely generated subring
    generated by the entries of the generators and their inverses.
  - `C_0` is residually finite. For `a ≠ 0`, take a maximal ideal `m ⊇ ann(a)`. Krull's intersection theorem in
    `(C_0)_m` gives `a ∉ m^k` for some `k`, and `C_0/m^k` is finite.
  - Reducing modulo `m^k` then separates any `γ ≠ 1` from `1`.
- **Binary case.** `ρ(G)` is `1` or `≅ G`. An infinite simple group is not residually finite, so `ρ` is trivial.
- **Ternary case.** By the input of Section 1, the quotients of `G_3` are `G_3`, `G_3/{±1}` and `1`. The two
  nontrivial ones are infinite and have no proper finite-index normal subgroup. So `ρ` is trivial and
  `ρ(z) = 1 ≠ -1`. ∎

**Scope.**
- Theorem B covers `M_n(C)` for non-reduced `C` of any nilpotence, which Theorem A does not reach. It also covers
  `∏_i M_n(C_i) = M_n(∏_i C_i)` at fixed `n`.
- Growing `n` is not covered.

**Remark B.2 (PI rings; conditional; no node).**
- **Semiprime PI rings** embed in matrices of bounded size over commutative rings (Posner–Rowen–Amitsur,
  statement level), so Theorem B applies.
- **General PI host `W`.**
  - Let `S` be the subalgebra generated by the `ρ(s^(±1))` for finitely many generators `s`.
  - `J(S)` is nilpotent (Braun–Kemer–Razmyslov, statement level).
  - Modulo `J(S)` the image is trivial, by Theorem B. In the ternary case `2 ∉ J(S)`, because `2 = -1` is a unit.
  - So `ρ(G) ⊆ 1 + J(S)`, which is a nilpotent group. Since `G` is perfect, `ρ` is trivial.

## 3. Corollary A.2: rank functions are not discrete

Let `rk` be a Sylvester matrix rank function on `F_p[G]`. Put `𝔫 = {a : rk(a) = 0}` and `W = F_p[G]/𝔫`.

**Why 𝔫 is an ideal.** It is two-sided because `rk(ab) <= min(rk a, rk b)` and `rk(a + b) <= rk a + rk b`.

**Binary.** If `rk ≠ rk_ε`, then `ρ : G -> W^x` is nontrivial.
- Suppose `ρ` is trivial. Then the augmentation ideal lies in `𝔫`.
- A matrix whose entries lie in `𝔫` has rank 0, so `rk(X) = rk(ε(X))`.
- The only Sylvester matrix rank function on `F_2` is the normalized rank. So `rk = rk_ε`, a contradiction.

**Ternary.** If `rk(1 + [z]) = 0`, then `ρ(z) = -1` in `W`, and `W ≠ 0` because `rk(1) = 1`.

**Sharper form in rank terms.** Let `x` be a `p^k`-cycle and `a = [x] - 1`. The sharper form of Theorem A gives
`a^(p^k) = 0` and `rk(a^(p^(k-1))) > 0`.

**Frobenius inequality.** `rk(XY) + rk(YZ) <= rk(Y) + rk(XYZ)`.
- By invertible elementary operations, `diag(Y, XYZ)` becomes `[[Y, YZ], [-XY, 0]]`.
- After a column swap, the triangular axiom bounds its rank below by `rk(YZ) + rk(XY)`.

**Consecutive differences.** Put `d_j = rk(a^j) - rk(a^(j+1))`.
- Frobenius with `X = Z = a` and `Y = a^j` gives `d_j >= d_(j+1)`.
- Let `m` be the least index with `rk(a^m) = 0`. Then `p^(k-1) < m <= p^k`.
- `d_(m-1) > 0`, so all of `d_0, …, d_(m-1)` are positive, and they sum to `rk(1) = 1`.
- So the values `1 = rk(a^0) > rk(a) > … > rk(a^(m-1)) > 0` are distinct, and some `d_j <= 1/m < p^(1-k)`.

**Corollary A.2.** A Sylvester matrix rank function on `F_2[L_(F_2)(1,2)^x]` other than `rk_ε`, or one on
`F_3[G_3]` with `rk(1 + [z]) = 0`:
- takes infinitely many values on single elements;
- has values contained in no `(1/N)Z`.

**Consequence.** Such a rank function is not the normalized rank pulled back from any homomorphism into
`M_n(D)`. So no rank function with values in some `(1/N)Z` witnesses
`binary-leavitt-units-carry-nonaugmentation-rank-function`. Its quotient `W` contains nilpotents of unbounded
index, as Theorem A requires.

## 4. Proposition D: ultraproducts

**Proposition D.**
1. **Upward.** If for every `n` there is an `n`-weakly finite host `(W_n, ρ_n)`, a weakly finite host exists.
2. **Downward.** Let `A_j` be rings with `p·1 = 0` and `U` an ultrafilter. If `W = ∏_U A_j` (algebraic
   ultraproduct) is a host, then for `U`-almost every `j` there is an injective homomorphism `V -> A_j^x`. For
   `p = 2` there is moreover a nontrivial homomorphism `G -> A_j^x`.

**Proof of 1.**
- Take a nonprincipal ultrafilter `U` on `N` and `W = ∏_U W_n`.
- For each `k`, "`AB = I_k` implies `BA = I_k`" is a first-order sentence in `2k^2` variables. It holds in `W_n`
  for `n >= k`, so it holds in `W` by Łoś. The identity `p·1 = 0` passes to `W` the same way.
- `ρ = (ρ_n)_U` is a homomorphism into `W^x`.
- **Binary:** each `ρ_n` is injective (simplicity), so `ρ(g) ≠ 1` for `g ≠ 1`.
- **Ternary:** `ρ(z) = (-1)_U = -1`. ∎

**Contrapositive.** If no weakly finite host exists, there is one `n_0` such that every host has
`AB = I_k ≠ BA` for some `k <= n_0`.

**Proof of 2.**
- **`ρ|V` is injective.** In the binary case `ρ` is injective. In the ternary case, `ρ(V) = 1` would put the
  infinite group `V` inside `ker ρ`, so `ker ρ = G_3` and `ρ(z) = 1`. Since `V` is simple, `ρ|V` is injective.
- **Passing to factors.** `V = ⟨S | R⟩` is finitely presented. Pick representatives `a_j(s)` and `b_j(s)` of
  `ρ(s)` and `ρ(s)^(-1)`. The following finitely many conditions each hold on a `U`-large set, hence together
  on one:
  - `a_j(s) b_j(s) = 1 = b_j(s) a_j(s)`;
  - `r(a_j) = 1` for every `r ∈ R`;
  - `a_j(s_0) ≠ 1` for one `s_0` with `ρ(s_0) ≠ 1`.
- On that set, `s ↦ a_j(s)` is a nontrivial homomorphism `V -> A_j^x`, injective because `V` is simple.
- For `p = 2`, run the same argument with the finite presentation of `G` (`leavitt-unit-group-finitely-presented`). ∎

**Consequences.**
- Algebraic ultraproducts of finite rings are not hosts. This includes the level algebras `M_(2^j)(F_2)`, since
  `V` is infinite simple.
- Realizing the compressors exactly inside larger algebras `A_j` only helps if the `A_j` already host `V`
  faithfully (and, for `p = 2`, host `G`).
- If `∏_U A_j` is weakly finite, then for each `k`, `U`-almost every `A_j` is `k`-weakly finite. In the binary
  case the factors then supply `k`-weakly finite hosts for every `k`, which is Part 1 read backwards.
- Only metric ultraproducts escape. Those are rank functions, constrained by Corollary A.2.

## 5. The other sources

**5.1 Traces in characteristic p.** Let `τ : W -> M` be additive with `τ(ab) = τ(ba)`, extended to `M_n(W)` by
summing the diagonal.
- **Torsion-free values vanish.** `p·τ(w) = τ(p·w) = 0`, so `τ = 0` when `M` is torsion-free (`R`, `Z_p`, `Q_p`).
- **No trace is faithful on idempotents of `M_p(W)`.** `τ(I_p) = p·τ(1) = 0` while `I_p ≠ 0`. A trace certifies
  at most `(p-1)`-weak finiteness.
- **What does certify.** A homomorphism `φ : K_0(W) -> M` with `φ([e]) ≠ 0` for every nonzero idempotent `e`
  over `W`.
  - If `AB = I_n`, then `BA` is equivalent to `AB` via `x = B`, `y = A`.
  - So `[I_n - BA] = 0`, and faithfulness forces `BA = I_n`.
  - Necessarily `φ([1])` has infinite order.
- **Positive real `φ` are `K_0` states.** Their existence on the corners is already in
  `binary-cyclic-corner-full-iff-complement-corner-has-no-state` and
  `anti-central-state-exists-iff-lifted-trace-relatively-positive`.
- **The `Z_p`-valued candidate** is the lifted trace `t_p` of `lifted-trace-detects-finite-subgroup-projectives`.
  - Faithful `t_p` on idempotents over `F_p[G]` would make `F_p[G]` a weakly finite host.
  - For `p = 3` this goes through the central direct factor `ε_- F_3[G_3]` with `ε_- = [z] - 1`.
  - That node records faithfulness on ambient projectives as not known. This is Kaplansky direct finiteness for
    `F_p[G]` in trace form, not a new source.

**5.2 Crossed products with invariant measures.** Over `F_p` a measure cannot enter through a trace (5.1). It
enters through normalized ranks along Følner or sofic approximations, which produce Sylvester rank functions.
- **Binary:** that is `binary-leavitt-units-carry-nonaugmentation-rank-function`.
- **Ternary:** that is `ternary-leavitt-units-have-a-nontrivial-char-three-rank-model`.
- Either way the rank function is constrained by Corollary A.2.

**5.3 Ore and skew localizations.** Let `B ⊆ W` contain `ρ(G)`, and let `S ⊆ B` be a right Ore set of regular
elements.
- **Certify, not create.** `B` embeds in `BS^(-1)`. A weakly finite `BS^(-1)` makes `B` a weakly finite host
  already, so localization can only certify.
- **Goldie case.** When `BS^(-1)` is semisimple Artinian, Theorem A applies.
- **No Ore domains.** Torsion gives nonzero nilpotents in `B`: `(1 + ρ(g))^2 = 0` for `g` of order 2 in
  characteristic 2, and `(ρ(g) - 1)^3 = 0` for `g` of order 3 in characteristic 3. They are nonzero because no
  element of order `p` lies in `ker ρ` (sharper form of Theorem A).

**5.4 Presented algebras and normal forms.** A presented `F_p`-algebra `P` receiving `F_p[G]` is weakly finite
iff `J_1(P) = 0` in `weakly-finite-reflection-ideal-detects-weakly-finite-images`.
- A normal form (Gröbner, diamond lemma) must therefore decide `BA = I` for every `AB = I` over `P`, in all
  matrix sizes.
- By Proposition D, if no host exists, every candidate fails at a size bounded uniformly over all candidates.
- No candidate presentation was found.

## 6. What a host must look like

Any host `(W, ρ)`:
- **contains a faithful copy of `V`,** hence of every finite group (proof of Proposition D.2);
- **when weakly finite, has `D_ρ = N_23 N_12 ≠ 0`,** where `N_ab = ρ(x_ab(1)) - 1` in the three-leaf frame
  (`weakly-finite-leavitt-representations-killing-defect-are-trivial`);
- **contains `ρ(x) - 1` of nilpotence index greater than `p^(k-1)`** for every `p^k`-cycle `x ∈ V` (Theorem A);
- **is none of these:** semiprime Goldie, reduced, finite-dimensional, inside `M_n` over a commutative ring
  (Theorem B), or PI (Remark B.2, conditional);
- **if it is a rank ultraproduct,** carries a rank function with values in no `(1/N)Z` (Corollary A.2).

## Item 1: the ray-germ computation (the author asked about this)
- **The semidirect product.**
  - Strong shift-similarity gives `s̄^(−1)Germs(G)s̄ = Germs(G)`.
  - `η` vanishes on `Germs(G)`, whose elements are classes of genuine permutations, and `η(s̄) = 1`.
  - So `Ĝ = Germs(G) ⋊ ⟨s̄⟩`. ✓
- **The ray germs.** The increasing enumeration of a ray minus `m_k` points is near `s̄^(m_k)`. So
  `x_k = s̄^(b_k) ḡ_k s̄^(−a_k)`, with `η(x_k) = b_k − a_k`.
  - `Σa_k = |M_+| = |M_−| = Σb_k`, so the tuple lies in `Q_n(Ĝ)`.
  - The germ map is a homomorphism, since each element preserves each ray up to finite sets.
  - Its kernel is exactly `FSym([n] × N)`. ✓
- **Onto.**
  - `a_k = max(0, −c_k)` and `b_k = max(0, c_k)` give `b_k − a_k = c_k`, and `Σc_k = 0` forces `Σa_k = Σb_k`.
  - The representative of `s̄^(−a_k)ḡ_ks̄^(a_k)` lies in `Germs(G)` by Step 1.
  - So the germs are `s̄^(b_k−a_k)ḡ_k = x_k`. ✓

## Item 2: the general gate (the author asked about this)
- **(⇐) for `n ≥ 3`.**
  - `ψ = Σ η∘pr_k` is onto `Z`, so it is discrete. It is nonzero on each of the `n ≥ 3` finitely presented factors,
    since `η(s̄) = 1`.
  - So (I2) with `m = 2` gives `[±ψ] ∈ Σ^2`, and Renz's criterion gives that `ker ψ` is finitely presented. ✓
- **(⇒) for `n ≥ 2`.**
  - `i(x) = (x, s̄^(−η(x)), 1, …)` is a homomorphism into `Q_n`, because powers of `s̄` commute.
  - It is a section of `pr_1`, so `Ĝ` is a retract of `Q_n`, and (I3) applies. ✓

## Item 3: `Ĝ = R_ν ≀ C_2`, via the Schreier generators of Step 4 (the author asked about this)
- **The two coordinate shifts.** Composing right to left:
  - `s̄ω̄` sends `2k ↦ 2k+1 ↦ 2k+2` and fixes the odds, so it is `(σ, 1)`;
  - `ω̄s̄` sends `2k+1 ↦ 2k+2 ↦ 2k+3` and fixes the evens, so it is `(1, σ)`. ✓
- **Parity.** Parity is a homomorphism: all generators preserve or swap the parts up to finite sets, `ω̄` and `s̄` are
  odd, and `F^-` is even.
- **The Schreier generators for `{1, ω̄}`.**
  - For `F^-`: `F^-` and `ω̄F^-ω̄`.
  - For `ω̄`: `1` and `ω̄^2 = 1`.
  - For `s̄`: `s̄ω̄ = (σ,1)` and `ω̄s̄ = (1,σ)`.
  - All of these lie in `R × R`. Conversely `R × R` is generated by `(λ_g,1)`, `(1,λ_g)`, `(σ,1)` and `(1,σ)`, all in
    `Ĝ^0`. So `Ĝ^0 = R × R`, and `Ĝ = R ≀ C_2`. ✓
- **The index-`2^n` subgroup.**
  - The near index is additive over the two parts. The parity map `Q_n → C_2^n` is onto, since `η(ω̄) = 0`.
  - Its kernel is `ker(Σ_(j ≤ 2n) η∘pr_j)` on `R^(2n)`.
  - With `2n ≥ 4 ≥ 3` factors, Step 3's argument applies with `R` in place of `Ĝ`, because `η(σ) = 1`.
  - The converse uses the retraction onto `R`. So "germs finitely presented ⟺ `R_ν` finitely presented" for every
    `n ≥ 2`. ✓

## Item 4, and the `n = 1` sanity check (the author asked about this)
- *Item 4.* `FSym([n] × N)` is the normal closure of one transposition, so finite presentation of `H_n(G)` passes to
  its germ group.
- *No conflict with `n = 1`.* There `Q_1(Ĝ) = Germs(E_ν(P))` contains `F^- = ker(η + η)` on `R × R` with index 2.
  - That is two factors only, so Step 3 does not apply, and the finite-presentation condition is the two-sided gate
    of `mz-envelope-fp-forces-two-sided-fg-near-index-kernel`, unchanged.
  - Item 5's claim that `E_ν(P)` is not finitely presented while the `n ≥ 2` germ groups are is consistent with this:
    `R_ν` finitely presented does not give the two-sided gate. ✓

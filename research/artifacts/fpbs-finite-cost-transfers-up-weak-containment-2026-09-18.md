# Cost is monotone under weak containment for every countable group

Swarm-0917, wave 8, agent `swarm-0917-w8-w8-fp-follow`, September 18, 2026.
Family: quantifier-shift (tail-mass stagewise transfer).

## 0. Summary

**Theorem A.** Let `Γ` be a countable group, `H ≤ Γ` any subgroup, and
`a ∈ FR(Γ, X, μ)`, `b ∈ FR(Γ, Y, ν)` free p.m.p. actions on standard
non-atomic spaces with `a ≼ b`. Then

```text
relC( E_b ; E_{b|H} )  ≤  relC( E_a ; E_{a|H} ).
```

With `H = {e}` this reads `C(b) ≤ C(a)`.

For finitely generated `Γ` this is Kechris's monotonicity (Burton–Kechris
Theorem 7.1). For arbitrary `Γ`, Tucker-Drob proved it under the extra
hypothesis `C(b) < ∞` (Burton–Kechris Theorem 7.3, citing [T-D, Cor 6.22]).
Burton–Kechris ask, as Problem 7.4, "Does Theorem 7.1 hold for arbitrary
groups?". Theorem A says yes. The missing case was `C(a) < ∞ = C(b)`. It is
handled by transferring from `a` to `b` only the *tail* of a finite-cost
graphing, stage by stage along an exhaustion of `Γ`. The tail masses are
summable.

A brief literature search (September 18, 2026) found no later solution of
Problem 7.4. The argument is short and elementary, so a referee should check
it closely.

**Corollaries** (§4).
- For every countably infinite group, every Bernoulli shift has maximal cost
  among free actions. So `Γ` has fixed price iff `C(s_Γ) = C(Γ)`.
- `fpbs-finite-cost-groups-free-actions-have-finite-cost` is equivalent to:
  `C(Γ) < ∞` implies `C(s_Γ) < ∞`.
- For a locally free `Γ` with `c* < ∞`, fixed price is equivalent to
  `C(s_Γ) < ∞`.
- For `Gamma_mal`, fixed price is equivalent to
  `relC(E_β; E_{β|H_1}) = 0` for its Bernoulli shift `β`. So
  `fpbs-mal-bernoulli-single-stage-floor` holds iff `Gamma_mal` is a
  counterexample to `fpbs-fixed-price-universal`.

## 1. Conventions

- A *labelled piece* of `a` is a pair `(A, γ)` with `A ⊆ X` Borel and
  `γ ∈ Γ`. It stands for the partial map `φ = γ^a|_A`, of cost `μ(A)`.
- Every partial isomorphism in `[[E_a]]` is a countable disjoint union of
  labelled pieces with the same total measure: split its domain by which
  `γ` moves each point. So costs and relative costs can be computed with
  labelled graphings, i.e. countable families `Φ = (A_i, γ_i)_{i ∈ I}`, with
  `cost(Φ) = Σ μ(A_i)`.
- For subrelations `S ⊆ R`, `S ∨ Φ` is the equivalence relation generated by
  `S` and the graphs of the pieces. The relative cost is
  `relC(R; S) = inf { cost(Φ) : S ∨ Φ = R }`, and `C(R) = relC(R; id)`.
- `E_{a|H}` is the orbit relation of the restricted action. If `H` is
  generated by `G ⊆ Γ`, then `E_{a|H}` is generated by the maps `g^a`,
  `g ∈ G`.

## 2. Two lemmas

**Lemma 1 (pattern transfer).** Let `a ∈ A(Γ, X, μ)` and `b ∈ A(Γ, Y, ν)` with
`a ≼ b`, both spaces standard non-atomic. Fix Borel `A_1, …, A_N ⊆ X`, a finite
`F ⊆ Γ`, finitely many Boolean combinations `P_1, …, P_M` of the sets
`(g^a)^{-1} A_i` (`g ∈ F`, `i ≤ N`), and `η > 0`. Then there is a measure
isomorphism `S : Y → X` such that, with `B_i = S^{-1} A_i`:

- `ν(B_i) = μ(A_i)` for every `i`;
- `|ν(P_j^b) − μ(P_j^a)| < η` for every `j`. Here `P_j^b` is the same Boolean
  combination with `(g^b)^{-1} B_i` in place of `(g^a)^{-1} A_i`.

*Proof.* Fix a measure isomorphism `S_0 : Y → X` and write
`b_0 = S_0 b S_0^{-1} ∈ A(Γ, X, μ)`, which is conjugate to `b`. By Burton–Kechris
Theorem 2.3 (item 1 of the imported node
`burton-kechris-cost-usc-and-maximum-action`), `a` lies in the weak closure of
`{ c ∈ A(Γ, X, μ) : c ≅ b }`. So there are `c_m = R_m b_0 R_m^{-1}` with
`R_m ∈ Aut(X, μ)` and `c_m → a` weakly.

Weak convergence means `μ(g^{c_m} A Δ g^a A) → 0` for every Borel `A` and every
`g`. Apply it to `g^{-1}`: `μ((g^{c_m})^{-1} A_i Δ (g^a)^{-1} A_i) → 0` for all
`g ∈ F` and `i ≤ N`. Symmetric difference is subadditive over finite unions,
intersections and complements. So `μ(P_j^{c_m} Δ P_j^a) → 0` for every `j`.

Fix `m` large and put `S = R_m S_0`, so that `c_m = S b S^{-1}`. Then
`(g^{c_m})^{-1} A = S (g^b)^{-1} S^{-1} A`. Hence `P_j^{c_m} = S(P_j^b)` with
`B_i = S^{-1} A_i`, and `ν(P_j^b) = μ(P_j^{c_m})`. Finally, `S` preserves measure,
so `ν(B_i) = μ(A_i)`. ∎

**Words.** Fix a subgroup `K ≤ Γ` and a labelled family `Φ = (A_i, γ_i)_{i ∈ I}`
of `a`. A *word* is a finite sequence `w = ℓ_1 ⋯ ℓ_r` of letters. Each letter is
one of:

- `h` with `h ∈ K`, meaning the full map `h^a`;
- `i^{+}`, meaning the piece `γ_i^a|_{A_i}`;
- `i^{-}`, meaning its inverse `(γ_i^{-1})^a|_{γ_i^a A_i}`.

Give the letters group labels `λ(h) = h`, `λ(i^+) = γ_i` and `λ(i^-) = γ_i^{-1}`.
The *value* of `w`, read right to left, is `v(w) = λ(ℓ_r) ⋯ λ(ℓ_1)`. The prefix
values are `g_0 = e` and `g_q = λ(ℓ_q) ⋯ λ(ℓ_1)`.

The composite partial map `w^a` is defined at `x` iff each successive piece
applies. For a letter `i^+` at position `q`, that means `g_{q-1}^a x ∈ A_i`. For
`i^-` it means `g_{q-1}^a x ∈ γ_i^a A_i`, i.e. `(γ_i^{-1} g_{q-1})^a x ∈ A_i`.
So the domain `D^a(w)` is a finite intersection of sets `(g^a)^{-1} A_i`. The
elements `g` involved form a finite set `F(w)`, and the pieces a finite set
`I(w)`. On `D^a(w)`, `w^a = v(w)^a`.

The same word read in `b`, with a family `(B_i, γ_i)`, has domain `D^b(w)`
given by the same formula, and acts there as `v(w)^b`. No freeness is needed
for this.

**Lemma 2 (finitely many words).** Let `a` be free and suppose
`E_{a|K} ∨ Φ ⊇ E_{a|⟨K, s⟩}` for some `s ∈ Γ`. Let `W_s` be the set of words
with `v(w) = s`. Then `⋃_{w ∈ W_s} D^a(w)` is conull. Hence for every `δ > 0`
there is a finite `W ⊆ W_s` with `μ(⋃_{w ∈ W} D^a(w)) > 1 − δ`.

*Proof.* `E_{a|K}` is the union of the graphs of `h^a`, `h ∈ K`. So `E_{a|K} ∨ Φ`
is the set of pairs `(x, w^a x)` with `w` any word and `x ∈ D^a(w)`. Such a
pair is a path of `E_{a|K}`-steps and piece-steps, and a run of consecutive
`K`-steps collapses to a single letter. For a.e. `x`, `(x, s^a x)` lies in this
relation. So `s^a x = w^a x = v(w)^a x` for some word `w` with `x ∈ D^a(w)`.
Freeness of `a` gives `v(w) = s` off a null set. There are countably many
words, so the union over `W_s` is conull, and continuity of measure gives the
finite `W`. ∎

## 3. Proof of Theorem A

Let `c = relC(E_a; E_{a|H})`. If `c = ∞` there is nothing to prove, so assume
`c < ∞` and fix `ε > 0`. Choose a labelled family `Φ = (A_i, γ_i)_{i ∈ I}`
(see §1) with `E_{a|H} ∨ Φ = E_a` and `cost(Φ) < c + ε`.

**Exhaustion and tails.** Enumerate `Γ = {γ'_1, γ'_2, …}` and put
`H_n = ⟨H, γ'_1, …, γ'_n⟩`, with `H_0 = H`. Define
`t_n = Σ { μ(A_i) : γ_i ∉ H_n }`. Every `γ_i` lies in `H_n` for all large
`n`, and `Σ_i μ(A_i) < ∞`. So `t_n ↓ 0` by dominated convergence.

Choose `n_0 = 0 < n_1 < n_2 < ⋯` with `t_{n_k} < ε 2^{-k}` for `k ≥ 1`. Let
`Φ^{(k)} = (A_i, γ_i)_{γ_i ∉ H_{n_k}}`, so `cost(Φ^{(k)}) = t_{n_k}`, and let
`t_{n_0} = cost(Φ) < c + ε`.

**Key fact.** `E_{a|H_{n_k}} ∨ Φ^{(k)} = E_a`. Each piece with `γ_i ∈ H_{n_k}` has
its graph inside `E_{a|H_{n_k}}`, and `E_{a|H} ⊆ E_{a|H_{n_k}}`. So
`E_{a|H_{n_k}} ∨ Φ^{(k)} ⊇ E_{a|H} ∨ Φ = E_a`.

**Stage `k`.** Let `S_k = {γ'_{n_k + 1}, …, γ'_{n_{k+1}}}`, a finite set with
`H_{n_{k+1}} = ⟨H_{n_k}, S_k⟩`. Put `δ_k = ε 2^{-k} / (2|S_k|)`. For each
`s ∈ S_k`, apply Lemma 2 with `K = H_{n_k}` and the family `Φ^{(k)}`. This
gives a finite set of words `W_s` of value `s` with
`μ(U^a_s) > 1 − δ_k`, where `U^a_s = ⋃_{w ∈ W_s} D^a(w)`.

Let:

- `I_k` be the finite set of piece indices used by the words in `⋃_{s ∈ S_k} W_s`;
- `F_k` be the finite set of all `F(w)`;
- the patterns be the sets `U^a_s` for `s ∈ S_k`.

Apply Lemma 1 with `η = δ_k`. It gives `S_k^*: Y → X` and pieces
`B^{(k)}_i = (S_k^*)^{-1} A_i` for `i ∈ I_k`, with `ν(B^{(k)}_i) = μ(A_i)` and
`ν(U^b_s) > 1 − 2δ_k`. Here `U^b_s = ⋃_{w ∈ W_s} D^b(w)`, computed with the
pieces `(B^{(k)}_i, γ_i)`. Define

```text
Ψ_k = { (B^{(k)}_i, γ_i) : i ∈ I_k }  ∪  { (Y ∖ U^b_s, s) : s ∈ S_k }.
```

Since each `γ_i ∉ H_{n_k}` for `i ∈ I_k`,

```text
cost(Ψ_k) ≤ t_{n_k} + |S_k| · 2δ_k = t_{n_k} + ε 2^{-k}.
```

**Stage claim.** `E_{b|H_{n_k}} ∨ Ψ_k ⊇ E_{b|H_{n_{k+1}}}`. Fix `s ∈ S_k` and
`y ∈ Y`.

- If `y ∈ D^b(w)` for some `w ∈ W_s`, then `s^b y = w^b y`. This is a path of
  `h^b`-steps (`h ∈ H_{n_k}`) and `Ψ_k`-piece steps.
- Otherwise the fix-up piece `(Y ∖ U^b_s, s)` sends `y` to `s^b y`.

So the graph of `s^b` lies in `E_{b|H_{n_k}} ∨ Ψ_k`. By §1 applied to the
generating set `H_{n_k} ∪ S_k` of `H_{n_{k+1}}`, the claim follows.

**Induction.** Put `R_k = E_{b|H} ∨ (Ψ_0 ∪ ⋯ ∪ Ψ_{k-1})`, with `R_0 = E_{b|H}`.
Then `R_k ⊇ E_{b|H_{n_k}}` for every `k`:

- `k = 0`: `H_{n_0} = H`.
- Step: `R_{k+1} ⊇ R_k ∨ Ψ_k ⊇ E_{b|H_{n_k}} ∨ Ψ_k ⊇ E_{b|H_{n_{k+1}}}`.

Since `⋃_k H_{n_k} = Γ`, we get `E_b = ⋃_k E_{b|H_{n_k}} ⊆ E_{b|H} ∨ ⋃_k Ψ_k ⊆ E_b`.

**Cost.**

```text
Σ_k cost(Ψ_k) ≤ (c + ε) + Σ_{k≥1} ε 2^{-k} + Σ_{k≥0} ε 2^{-k} ≤ c + 4ε.
```

So `relC(E_b; E_{b|H}) ≤ c + 4ε`, and `ε` was arbitrary. ∎

**Remarks.**

- Freeness of `b` was not used. Only `a` needs to be free, for Lemma 2.
- Every stage uses its own conjugator `S_k^*`. The copies of `Φ` in `b` at
  different stages are unrelated to one another. They interact only through
  the relations `E_{b|H_{n_k}}`, which do not depend on any copy. This is why
  no single simultaneous transfer of the infinite family `Φ` is needed. Such a
  transfer is what fails in general, and it is where Kechris's finitely
  generated argument uses finite generation.
- Stage 0 pays the full cost `≈ c`. Every later stage pays only the tail
  `t_{n_k}` plus a fix-up. The whole point is that the tail can be made
  summable, because the enumeration of `Γ` eventually absorbs every label.

## 4. Corollaries

Throughout, `Γ` is countably infinite and `s_Γ` is a Bernoulli shift `κ^Γ`
with `κ` not a point mass. Such a shift is free and non-atomic.

**Corollary 1 (Bernoulli is maximal, every countable group).**
- `C(a) ≤ C(s_Γ)` for every free `a`.
- Cost is constant on weak-equivalence classes of free actions.
- `Γ` has fixed price iff `C(s_Γ) = C(Γ)`.
- If `a` is free and `a ≼ s_Γ` (for instance a free factor of `s_Γ`), then
  `C(a) = C(s_Γ)`.

*Proof.* By Abért–Weiss Theorem 1 (node
`abert-weiss-free-actions-weakly-contain-bernoulli`), `s_Γ ≼ a`. Theorem A
with `(a, b) := (s_Γ, a)` gives `C(a) ≤ C(s_Γ)`. Apply Theorem A in both
directions to get constancy on weak-equivalence classes. `C(Γ)` is the
infimum over free actions and `C(s_Γ)` is the maximum, so fixed price means
they are equal. For the last item, `a ≼ s_Γ ≼ a`. ∎

The universal goal `fpbs-fixed-price-universal` is therefore equivalent to
`C(a) ≥ C(s_Γ)` for all free `a` and all `Γ`. That is the single inequality
already recorded there for finitely generated `Γ`, now with no passage from
finitely generated to countable groups needed.

**Corollary 2 (the finite-cost node).**
`fpbs-finite-cost-groups-free-actions-have-finite-cost` is equivalent to:

```text
for every countably infinite Γ,   C(Γ) < ∞  ⇒  C(s_Γ) < ∞.
```

*Proof.* One direction is the special case `a = s_Γ`. For the other, use
Corollary 1: every free `a` has `C(a) ≤ C(s_Γ)`. ∎

**Corollary 3 (locally free groups).** Let `Γ` be countably infinite and
locally free. Then:

- every free action has finite cost iff `C(s_Γ) < ∞`, and then every free
  action has cost `c*(Γ)`, so `Γ` has fixed price;
- if `C(Γ) < ∞`, then `Γ` has fixed price iff `C(s_Γ) < ∞`.

*Proof.*
- "Only if" in the first item is the case `a = s_Γ`. For "if", Corollary 1
  gives `C(a) ≤ C(s_Γ) < ∞` for all free `a`.
- By `fpbs-locally-free-free-action-costs-are-c-star-or-infinite`, every
  free action has cost in `{c*, ∞}`. So if all costs are finite, all equal
  `c*`.
- For the second item: if `C(Γ) < ∞` and `Γ` has fixed price, then all costs
  equal the finite value `C(Γ)`, including `C(s_Γ)`. The converse is the
  first item.

So, for these groups, `fpbs-locally-free-free-actions-have-finite-cost` is
exactly the statement `C(s_Γ) < ∞`. ∎

**Corollary 4 (`Gamma_mal`).** Let `β` be the Bernoulli shift of
`Gamma_mal = ⋃_m ⟨a, b_m⟩` and `H_1 = ⟨a, b_1⟩`. Then the following are
equivalent:

1. `Gamma_mal` has fixed price;
2. `C(β) < ∞`;
3. `C(β) = 2`;
4. `relC(E_β; E_{β|H_1}) = 0`;
5. some free action `a ≼ β` has finite cost;
6. `fpbs-mal-bernoulli-single-stage-floor` fails.

In particular, `fpbs-mal-bernoulli-single-stage-floor` holds iff `Gamma_mal`
is a counterexample to `fpbs-fixed-price-universal`.

*Proof.*
- 2 ⇔ 3 ⇔ 4 ⇔ 6 is `fpbs-shifted-stage-relative-cost-zero-or-infinite`,
  whose Gamma_mal paragraph states "`C(beta) = 2` iff
  `relC(E_beta; E_{beta|H_1}) = 0`. Otherwise `C(beta) = infinity`". Item 6 is
  the negation of that floor claim by its statement.
- 2 ⇔ 5 is Corollary 1, last item.
- 1 ⇒ 2: `fpbs-mal-odometer-product-actions-have-cost-two` gives a free
  action of cost 2, so under fixed price `C(β) = 2`.
- 3 ⇒ 1 is new, and it is the step that needs Theorem A. By Corollary 1,
  every free action `a` has `C(a) ≤ C(β) = 2`. By
  `fpbs-locally-free-free-action-costs-are-c-star-or-infinite`, `C(a) ∈ {2, ∞}`
  (`c*(Gamma_mal) = 2` by the odometer node, item 3). So `C(a) = 2`. ∎

Before Theorem A, the floor claim was known to make `Gamma_mal` a
counterexample. Its failure did not give fixed price, because some other free
action might have infinite cost. Now the whole fixed-price question for
`Gamma_mal` is the single Bernoulli statement.

Item 5 is a *relaxation that can fail independently*. To refute the floor it
suffices to find **any** free action weakly contained in `β` of finite cost:
a free factor of `β`, a factor of iid, or a weak limit of conjugates of `β`.
It need not be `θ`-invariant or mixing. By contrast, actions with a
nontrivial compact factor on which `Γ` acts through an abelian quotient, such
as the odometer products, are not weakly contained in `β`. Their Koopman
representation contains a finite-dimensional subrepresentation, and a
finite-dimensional representation weakly contained in the regular
representation forces amenability, which fails since `F_2 ≤ Gamma_mal`. So
item 5 rules out exactly the mechanism that gives cost 2 for the odometer
products. This agrees with the `σ_b` separation recorded in the floor claim.

**Corollary 5 (relative form).** For every subgroup `H ≤ Γ` and every free
`a`, `relC(E_a; E_{a|H}) ≤ relC(E_{s_Γ}; E_{s_Γ|H})`. Relative cost questions
over a fixed subgroup, such as `fpbs-relative-fixed-price-free-pairs`, reduce
in the upper direction to the Bernoulli shift of the ambient group.

*Proof.* Theorem A with `(a, b) := (s_Γ, a)` and the given `H`. ∎

## 5. Caveats and what this does not do

- **Imported inputs.** Theorem A uses only Burton–Kechris Theorem 2.3 (Kechris
  Prop 10.1), verbatim in `burton-kechris-cost-usc-and-maximum-action`:
  "Let a ∈ A(Γ, X, µ), b ∈ A(Γ, Y, ν) with (X, µ), (Y, ν) non-atomic. Then
  a ≼ b ⇐⇒ a ∈ {c ∈ A(Γ, X, µ) : c ≅ b}‾". The corollaries also use
  Abért–Weiss Theorem 1 and the three graph nodes cited in their proofs.
- **Novelty.** Burton–Kechris (arXiv:1611.07921v5), §7, state Theorem 7.1 for
  finitely generated `Γ`, and Theorem 7.3 ([T-D, Corollary 6.22]):
  "For any group Γ and actions a, b ∈ FR(Γ, X, µ), a ≼ b & Cµ(b) < ∞ =⇒
  Cµ(a) ≥ Cµ(b)". Problem 7.4 reads: "Does Theorem 7.1 hold for arbitrary
  groups?". Theorem A answers it in the affirmative. The note
  `fpbs-fixed-price-universal` also records (rechecked September 2026) that
  Tucker-Drob's result needs finite cost of the weakly containing action. No
  later solution was found, but the literature check was brief. The
  argument is elementary, so it should be verified independently before it
  is cited outside the graph.
- **What it does not give.** It gives no lower bound on the cost of any
  action. The universal goal is exactly the reverse inequality
  `C(a) ≥ C(s_Γ)`, which is untouched. The finite-cost node stays OPEN, and is
  reduced to Bernoulli shifts.
- **Why the obvious route missed it.** The obstruction recorded in the
  finite-cost node's Attempts is "nothing in `a` controls where `b` can place"
  infinitely many labels. That obstruction is real for a *single* transfer of
  the whole graphing. It disappears when each stage is transferred with its
  own conjugator relative to a subgroup relation already built in `b`.

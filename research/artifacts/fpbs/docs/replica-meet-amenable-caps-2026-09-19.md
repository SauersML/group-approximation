# Amenable coset subgraphs cap the replica meet thresholds (w14-bs-follow, 2026-09-19)

Follow-through on `fpbs-replica-meet-threshold-sandwich` and the hole
`fpbs-replica-meet-threshold-gap-universal` ([cap_fin]). Notation as in
`replica-meet-threshold-2026-09-18.md`: `G = Cay(Gamma,S)`, `k` independent
Bernoulli(`p`) bond configurations `omega_1, ..., omega_k`, clusters `K^i(x)`,
meet `M_k(x) = K^1(x) ∩ ... ∩ K^k(x)`, and

```text
p_cap^(k) = sup{ p : |M_k(o)| < infinity  P_p^(k)-a.s. } .
```

Since `M_k(x)` is increasing in each `omega_i`, the monotone coupling shows that
`{p : |M_k(o)| < infinity a.s.}` is an interval starting at `0`. By
transitivity of `G` the law of `|M_k(x)|` does not depend on `x`.

**Results.**

- **A (cap lemma).**
  - **(i)** For every infinite amenable subgroup `H <= Gamma` and every `k`,
    `p_cap^(k)(G) <= p_c(H;G)`. Here `p_c(H;G)` is Hutchcroft–Pan's relative
    threshold for a cluster meeting `H` in infinitely many vertices.
  - **(ii)** Suppose `H` is infinite and generated by `S_H = S ∩ H`, and let
    `Y = Cay(H,S_H) ⊆ G`. Then `p_cap^(k)(G) <= p_u(Y)`, and
    `p_c(H;G) <= p_c(Y)`.
- **B (the question [cap_inf] is false).** On `G = Cay(Z^3 * Z_2, {±e_1, ±e_2, ±e_3, t})`,
  a nonamenable Cayley graph with `p_u(G) = 1`, the meet thresholds are given
  exactly by a Galton–Watson criterion, and
  `lim_k p_cap^(k)(G) = p_c^bond(Z^3) <= 1/2 < 1 = p_u(G)`.
- **C (a hidden prerequisite of [cap_fin]).** Suppose [cap_fin] holds on `G`.
  - For every infinite amenable `H <= Gamma`, the relative gap
    `p_c(G) < p_c(H;G)` holds. Equivalently, by
    `fpbs-relative-gap-along-any-subgroup-separates`, `E_p|K_o ∩ H| < infinity`
    for some `p > p_c(G)`.
  - For every infinite `H` generated by `S ∩ H`, `p_c(G) < p_u(Cay(H,S∩H))`.

  So, group by group over all `S`, [cap_fin] implies the OPEN hole
  `fpbs-amenable-wq-normal-relative-subcriticality`. The same holds for
  everything above [cap_fin] in the chain (`p_c < p_(2->2)`, `p_c < p_2`, [Q],
  [Q_fin]).

Imports (all verbatim in the citation nodes):

- `fpbs-cluster-count-trichotomy` (Newman–Schulman; simultaneous uniqueness);
- `fpbs-hp-relative-burton-keane` (Hutchcroft–Pan, Theorem 1.7). It is applied
  with the amenable group `H` as its own subgroup, which gives Burton–Keane:
  at most one infinite cluster on an amenable Cayley graph. Lyons–Peres
  Theorem 7.6 states the same.
- `fpbs-hutchcroft-l2-gap-criterion`:
  - item 1 (sharpness: `chi(p) < infinity` iff `p < p_c`);
  - item 2 with `q = 1`
    (`chi(p) >= (1-p)/(||A||_(1->1)(p_c - p))`).
- `fpbs-kesten-square-lattice-pc-one-half` (new citation node, Lyons–Peres,
  Section 5.1), used only for the explicit gap `1/2`.

The argument in Section 2.2 does not use BLPS.

## 0. Invariant-set lemma

**Lemma 0.** Let `H` be a countably infinite group and `W` a random subset of
`H` whose law is invariant under left multiplication by `H`. Then
`P(h in W, |W| < infinity) = 0` for every `h in H`.

*Proof.* Fix `n >= 1`. By invariance, `c_n := P(h in W, |W| = n)` does not
depend on `h`. Summing over `h`:
`sum_h P(h in W, |W| = n) = E[ |W| 1{|W| = n} ] = n P(|W| = n) <= n`.
The left side is `c_n` times the infinite cardinality of `H`, so `c_n = 0`.
Sum over `n`. QED.

## 1. Lemma A (cap lemma)

### 1.1 Part (i): amenable subgroups, relative threshold

`Gamma` acts on `G` by left multiplication, and an infinite `H <= Gamma`
preserves both the set `H` and the Bernoulli measure.

- An element `h` fixes the edge `{g, gs}` only if `h = e`, or `h = g s g^(-1)`
  with `s^2 = e`. So every edge stabiliser has at most 2 elements.
- Hence, for edges `e_1, e_2`, the set `{h : h e_1 = e_2}` has at most 2
  elements.
- So for finite edge sets `F_1, F_2`, `h F_1 ∩ F_2 = ∅` for all but finitely
  many `h in H`.

The product measure is therefore `H`-mixing, and hence `H`-ergodic.

**Proof of (i).** Let `H` be infinite and amenable, and let `p > p_c(H;G)`.

1. *Existence.* The event `E = {some cluster meets H infinitely}` is
   `H`-invariant, so `P_p(E) in {0,1}`. It is increasing in `p`, and it has
   probability `1` at some `p' < p` by the definition of `p_c(H;G)` as an
   infimum. So `P_p(E) = 1`.
2. *Uniqueness.* By `fpbs-hp-relative-burton-keane` there is a.s. at most one
   `H`-infinite cluster. Call it `U_i` for replica `omega_i`. It is an
   `H`-equivariant function of `omega_i`.
3. *The root sees it.* `U_i ∩ H` is infinite a.s., so `P(h in U_i) > 0` for
   some `h in H`. By `H`-invariance this probability does not depend on `h`,
   so `P(o in U_i) =: theta_H > 0`.
4. *Invariant intersection.* Put `W = U_1 ∩ ... ∩ U_k ∩ H`. Its law is
   `H`-invariant, and `P(o in W) = theta_H^k > 0` by independence. On
   `{o in W}` each `U_i = K^i(o)`, so `W ⊆ M_k(o)`. By Lemma 0, `W` is a.s.
   infinite on `{o in W}`.

Hence `P_p^(k)(|M_k(o)| = infinity) >= theta_H^k > 0` and `p_cap^(k)(G) <= p`.
Since `p > p_c(H;G)` was arbitrary, `p_cap^(k)(G) <= p_c(H;G)`. QED.

`H` need not be generated by `S ∩ H`, normal or wq-normal. For
`H = <g> ≅ Z`, part (i) caps every meet threshold by the relative threshold
of a cyclic subgroup.

### 1.2 Part (ii): coset subgraphs

Setup. `H <= Gamma` is infinite and generated by `S_H = S ∩ H`. For `g in Gamma`
the coset `gH` spans a copy `gY` of `Y = Cay(H,S_H)` inside `G`: its edges are
`{gh, ghs}` with `h in H`, `s in S_H`. The restriction of `omega_i` to the
edges of `Y` is Bernoulli(`p`) on `Y`. Also `H` acts on `Y` by left
multiplication, and this action preserves the law of that restriction.

**Proof of (ii).** Let `p` be such that Bernoulli(`p`) on `Y` has a.s. exactly one
infinite cluster. Call this cluster `U_i`; it is a measurable function of
`omega_i|_Y`, and the function is `H`-equivariant. `Y` is transitive and an
infinite cluster exists a.s., so
`theta_Y(p) = P(o in U_i) > 0`. (If it were `0` for one vertex, it would be `0`
for all, and there would be no infinite cluster.)

Put `W = U_1 ∩ ... ∩ U_k ⊆ H`. The `omega_i` are independent and each map is
equivariant, so the law of `W` is `H`-invariant. Also
`P(o in W) = theta_Y(p)^k > 0`.

On `{o in W}`, each `U_i` is an `omega_i`-connected set that contains `o`, so
`U_i ⊆ K^i(o)`, and therefore `W ⊆ M_k(o)`. Lemma 0 shows that `W` is a.s.
infinite on `{o in W}`. Hence

```text
P_p^(k)( |M_k(o)| = infinity ) >= P(o in W) = theta_Y(p)^k > 0 .
```

So `p` is not in the interval `{q : |M_k(o)| < infinity a.s.}`, and
`p_cap^(k)(G) <= p`.

- **The cap.** By `fpbs-cluster-count-trichotomy` item 2, applied to `Y`,
  uniqueness holds for every `p > p_u(Y)`. So `p_cap^(k)(G) <= p_u(Y)`.
- **The comparison.** Let `p > p_c(Y)`. The infinite cluster of `Y` lies in a
  `G`-cluster that meets `H` infinitely. So `p_c(H;G) <= p_c(Y)`. QED.

Both bounds hold for every `k` uniformly. So

```text
sup_k p_cap^(k)(G) <= c(G,S) := inf { p_c(H;G) : H <= Gamma infinite amenable }
                             <= inf { p_c(Cay(H,S∩H)) : H infinite amenable, generated by S ∩ H },
```

with `inf ∅ = 1`. For amenable `Y` this recovers the uniqueness cap of the
sandwich (item 3) inside every amenable coset.

## 2. The example `G = Cay(Z^3 * Z_2, S)`, `S = {±e_1, ±e_2, ±e_3, t}`

### 2.1 Structure

Call the edges `{g, g e_j}` *cube edges* and the edges `{g, g t}` *t-edges*.
Every vertex lies on exactly one t-edge. Take the Bass–Serre tree of
`Z^3 * Z_2`, which has vertices `Gamma/Z^3 ∪ Gamma/Z_2` and edges `Gamma`.
Each vertex `gZ_2 = {g, gt}` has degree 2. Suppressing these vertices gives a
simple tree `Q`:

- the vertices of `Q` are the cosets `gZ^3`;
- the edges of `Q` are the t-edges, joining `gZ^3` to `gtZ^3`, which is
  different since `t ∉ Z^3`.

Consequences:

- **(S1)** Every t-edge is a bridge of `G`.
- **(S2)** A self-avoiding path of `G` that leaves a coset never returns to
  it. Hence, for any configuration, the cluster of `x` meets `xZ^3` exactly in
  the cube-edge cluster of `x` inside `xZ^3`.
- **(S3)** Distinct vertices of one coset have their t-edges going to distinct
  cosets.

### 2.2 Nonamenability and `p_u(G) = 1`

**Nonamenability.** Let `K` be finite and nonempty. It meets `c >= 1` cosets.
The t-edges with both ends in `K` form a subforest of `Q` on those `c`
cosets, so there are at most `c - 1` of them. Each such edge uses 2 vertices
of `K`, and each vertex has one t-edge, so at least `|K| - 2(c-1)` t-edges
leave `K`. In each coset, the nonempty finite set `A_j = K ∩ g_j Z^3` has at
least 2 boundary cube edges: the edges leaving the points of `A_j` with the
largest and with the smallest `e_1`-coordinate, in directions `+e_1` and
`-e_1`. Hence `|∂_E K| >= |K| - 2(c-1) + 2c > |K|`, and `G` is nonamenable.

**`p_u(G) = 1`.** Fix `p < 1`. Let `e = {o,t}`. Removing `e` splits `G` into
two components, `G_o ∋ o` and `G_t ∋ t` (by S1). The automorphism
`x ↦ t x` swaps them and fixes `e`. Let

- `A = {o ↔ ∞ inside G_o}`,
- `B = {t ↔ ∞ inside G_t}`.

By the symmetry, `P(A) = P(B)`. An infinite self-avoiding open path from `o`
either stays in `G_o`, or crosses `e` once and then stays in `G_t`. So
`theta_G(p) <= P(A) + P(B) = 2P(A)`.

- If `theta_G(p) = 0`, there is no infinite cluster.
- If `theta_G(p) > 0`, then `A`, `B` and `{e closed}` depend on disjoint edge
  sets, so `P(A ∩ B ∩ {e closed}) = P(A)^2 (1-p) > 0`. On this event the
  infinite clusters of `o` and `t` are different, because `e` is a bridge.

In both cases uniqueness fails with positive probability at every `p < 1`.
So `p_u(G) = 1`. (No import is used.)

### 2.3 Exact criterion for `p < p_c(Z^3)`

For a vertex `v` and replicas `omega_1..omega_k`, write:

- `C^i(v)` for the cube-edge `omega_i`-cluster of `v` inside `vZ^3`;
- `L(v) = C^1(v) ∩ ... ∩ C^k(v)` for the *local meet*.

By translation invariance, `|L(v)|` has the law of `|L(o)|`, and

```text
E|L(o)| = sum_{x in Z^3} tau_p(0,x)^k =: Z_k(p),   tau_p(0,x) = P_p^{Z^3}(0 <-> x).
```

Let `x` lie in a coset `c'`. Let `f_1 = {a_1,b_1}, ..., f_m = {a_m,b_m}` be the
t-edges of the `Q`-geodesic from `oZ^3` to `c'`, where `a_j` is on the side of
`o`, and put `b_0 = o`. By S2, `x in K^i(o)` iff

- `a_{j+1} in C^i(b_j)` for `0 <= j < m`,
- each `f_j` is `omega_i`-open, and
- `x in C^i(b_m)`.

So `x in M_k(o)` iff `a_{j+1} in L(b_j)`, every `f_j` is open in all `k`
replicas, and `x in L(b_m)`. Thus `M_k(o)` is a disjoint union of *blocks*
`L(b)`, organised as a rooted tree:

- The root block is `L(o)`. Its children are the blocks `L(at)`, one for each
  `a in L(o)` whose t-edge is open in all `k` replicas.
- A non-root block `L(b)` was entered through the t-edge of `b`. Its children
  are the blocks `L(at)` for the `a in L(b) \ {b}` whose t-edge is open in all
  replicas.

Different blocks use disjoint cube-edge sets (different cosets) and different
t-edges (S3). Hence the block tree is a delayed Galton–Watson tree:

- root offspring `~ Bin(|L(o)|, p^k)`;
- later offspring `xi ~ Bin(|L(o)| - 1, p^k)`, i.i.d.;
- `E xi = m_k(p) := p^k (Z_k(p) - 1)`.

Now let `p < p_c(Z^3)`. By sharpness (`fpbs-hutchcroft-l2-gap-criterion`
item 1, on the transitive graph `Z^3`),
`chi(p) = E|C(0)| = sum_x tau_p(0,x) < infinity`, so
`Z_k(p) <= chi(p) < infinity` and every block is a.s. finite. Hence
`|M_k(o)| = infinity` iff the block tree is infinite. For `0 < p < 1`:

- `P(xi = 0) >= P(|L(o)| = 1) > 0`, so `xi` is not a.s. `1`;
- the root has a child with positive probability.

By the Galton–Watson extinction criterion:

```text
(p < p_c(Z^3))   P_p^(k)(|M_k(o)| = infinity) > 0   <=>   p^k (Z_k(p) - 1) > 1 .
```

For `k = 1` this is the familiar free-product criterion `p(chi(p)-1) > 1`.

### 2.4 The limit

- **Upper bound.** Take `H = Z^3 = <e_1,e_2,e_3>`, which is amenable and
  generated by `S ∩ H`. Lemma A(i) and (ii) give
  `p_cap^(k)(G) <= p_c(Z^3;G) <= p_c(Z^3)` for every `k`.
- **Lower bound.** Fix `p < p_c(Z^3)`. Then `m_k(p) <= p^k (chi(p) - 1) → 0` as
  `k → ∞`. So there is `k_0` such that `m_k(p) <= 1` for `k >= k_0`, and by 2.3
  `|M_k(o)| < infinity` a.s. at `p`, so `p_cap^(k)(G) >= p`.
- **Monotonicity.** `p_cap^(k)` is nondecreasing in `k`, since
  `M_{k+1} ⊆ M_k`.

Therefore

```text
lim_k p_cap^(k)(G) = sup_k p_cap^(k)(G) = p_c(Z^3) <= p_c(Z^2) = 1/2 < 1 = p_u(G),
```

using `Z^2 ⊆ Z^3` and Kesten (`fpbs-kesten-square-lattice-pc-one-half`). This
refutes [cap_inf] (`sup_k p_cap^(k) = p_u`) on a nonamenable Cayley graph.
Only `p_c(Z^3) < 1` is needed for the refutation, and a Peierls argument
already gives that. Kesten's theorem gives the explicit gap `1/2`.

### 2.5 [cap_fin] holds on this `G`, with the coset gap forced

- **`p_c(G) < p_c(Z^3)`.** Take `fpbs-hutchcroft-l2-gap-criterion` item 2 with
  `q = 1` on `Z^3`, where `||A||_(1->1) = 6`:
  `chi(p) >= (1-p)/(6(p_c(Z^3) - p))`. This tends to infinity as
  `p ↑ p_c(Z^3)`. So some `p_1 < p_c(Z^3)` has `m_1(p_1) = p_1(chi(p_1)-1) > 1`.
  By 2.3 with `k = 1`, `theta_G(p_1) > 0`, so `p_c(G) <= p_1 < p_c(Z^3)`.
- **[cap_fin].** Take `p in (p_c(G), p_c(Z^3))`. By 2.4 there is `k` with
  `|M_k(o)| < infinity` a.s. at `p`.
- **Where the threshold sits.** For every `k`,
  `p_cap^(k)(G) in (p_c(G), p_c(Z^3)]`, and the gap `p_cap^(k) - p_c(G)` is
  bounded by the coset gap `p_c(Z^3) - p_c(G)`. This is RG (Section 3) for
  `H = Z^3`. Here `p_c(Z^3;G) = p_c(Z^3)` by 2.4, since the cap and the limit
  agree.

So `Z^3 * Z_2` calibrates [cap_fin] (true) and [cap_inf] (false) on the same
graph.

## 3. Corollary C and the class killed

**Corollary C.** Suppose [cap_fin] holds on `G = Cay(Gamma,S)`: there are
`p > p_c(G)` and `k` with `|M_k(o)| < infinity` a.s. Then `p <= p_cap^(k)(G)`,
and Lemma A gives:

```text
p_c(G) < p_cap^(k)(G) <= p_c(H;G)            for every infinite amenable H <= Gamma,
p_c(G) < p_cap^(k)(G) <= p_u(Cay(H, S ∩ H))  for every infinite H generated by S ∩ H.
```

By `fpbs-relative-gap-along-any-subgroup-separates` (1 ⇔ 2), the first line
is equivalent to `E_q|K_o ∩ H| < infinity` for some `q > p_c(G)`. By the chain
in `replica-meet-threshold-2026-09-18.md`, Section 2, the same conclusions
follow from any of `p_c < p_(2->2)`, `p_c < p_2`, [Q] or [Q_fin]. QED.

**RG (relative gap along every amenable subgroup).** On every nonamenable
Cayley graph `G = Cay(Gamma,S)`, `p_c(G) < p_c(H;G)` for every infinite
amenable `H <= Gamma`.

- *Place in the graph.*
  - RG is necessary for [cap_fin] (Corollary C).
  - Restricted to amenable wq-normal `H`, RG is the OPEN hole
    `fpbs-amenable-wq-normal-relative-subcriticality`, which is equivalent to
    BS for that class.
  - For any `Gamma` with an infinite amenable subgroup (for example any
    element of infinite order), RG implies BS on `Gamma`, by
    `fpbs-relative-gap-along-any-subgroup-separates`.
  - So on such groups
    `[cap_fin] => RG => p_c < p_u`, and [cap_fin] is at least as hard as the
    relative-gap lane *along every cyclic subgroup at once*.
- *No known counterexample.* An amenable subgroup of a nonamenable group is
  never co-amenable. So `fpbs-co-amenable-subgroup-relative-threshold-is-pc`,
  the only in-graph source of `p_c(H;G) = p_c(G)`, does not apply.
- *The coset form.* For `H` generated by `S ∩ H`,
  `p_c(H;G) <= p_c(Cay(H,S∩H))`. So RG implies the strict enhancement
  `p_c(G) < p_c(Cay(H, S∩H))` over amenable coset subgraphs, which is weaker
  than RG and still necessary.
- Recorded as the OPEN node `fpbs-relative-gap-along-every-amenable-subgroup-universal`.

**Why RG is not free.**

1. *Aizenman–Grimmett enhancement does not apply.* Their strict inequality
   needs an essential enhancement that can be localised by a finite
   modification.
   - On `Z^3 * Z_2` every edge outside the cube cosets is a bridge (S1). So
     "adding the t-edges" to the coset copy of `Z^3` is not a local
     enhancement of `Z^3`, and the differential-inequality comparison does
     not apply.
   - On free products the gap comes instead from the Galton–Watson mean
     `p(chi_A(p)-1)`, which blows up as `p ↑ p_c(A)` by the l1 Aizenman–Barsky
     bound, a critical-point input.
   - Beyond free products (amalgams over infinite subgroups, HNN extensions,
     lattices), cosets are not joined by bridges and this mechanism is not
     available.
2. *Where BS-type tools stop.* Nonamenable tools (mass transport,
   `p_c <= 1/(1+h)`, BLPS) bound `p_c(G)` from above by isoperimetry. RG needs
   a comparison with the relative threshold of an amenable subgroup. That
   threshold is not an isoperimetric quantity of `G`.

**Class killed (named invariant: the amenable-subgroup cap).** Let

```text
c(G,S) := inf { p_c(H;G) : H <= Gamma infinite amenable }     (inf ∅ = 1).
```

Lemma A gives `sup_k p_cap^(k)(G) <= c(G,S)`.

- **(K1)** Any route to [cap_fin], [Q_fin], [Q] or `p_c < p_2` through a
  replica characterisation of nonuniqueness (`sup_k p_cap^(k) = p_u`, or
  `p_cap^(k) → p_u`) is dead. On `Z^3 * Z_2`,
  `sup_k p_cap^(k) = p_c(Z^3) <= 1/2 < 1 = p_u`.
- **(K2)** Any argument that bounds `p_cap^(k)` from below by a quantity that
  can exceed `c(G,S)` on some nonamenable Cayley graph is dead. This includes
  quantities controlled only by global isoperimetry or the spectral radius.
  Free products `A * Z_2` stay uniformly nonamenable
  (`fpbs-l2-threshold-not-lsc-at-trees`) while `c <= p_c(A)`.
- **(K3)** What survives must place `p_c(G)` *strictly below* `c(G,S)`. This is
  RG, a subgroup-comparison statement, not a statement about the meet.

**Remark (parallel with the l2 lane).** `fpbs-l2-threshold-not-lsc-at-trees`
shows `p_(2->2)(A * Z_2) <= p_c(A)`. Lemma A is the meet-threshold analogue,
for every nonamenable Cayley graph and every amenable subgroup, in the
relative form.

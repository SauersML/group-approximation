# Single-letter Morse matchings die on Bernoulli: the dual-hypergraph peeling does not exist

## 0. Why this matters

The only method in the graph that reaches the Morse ceiling on a nonamenable, non-treeable-looking class is the
dual-forest matching of `fpbs-one-relator-twice-used-letter-fixed-price`: every cell of `<S | w>` is matched to one
of the edges of a single letter `s`, the position varying from cell to cell. Its recorded death as a general
method was "if every letter is used `k >= 3` times, well-foundedness needs a Borel peeling of the incidence
hypergraph, which nothing here supplies". The fixed-position obstruction
(`fpbs-fixed-position-morse-matchings-die-on-bernoulli`) kills only the matchings whose position is constant, and
lists "matchings whose position varies from cell to cell (dual-forest type)" as a survivor.

This note closes that question negatively on Bernoulli. **No** single-letter matching, with any Borel choice of
position, reaches the ceiling once the transport group `Lambda_s` of the letter is nonamenable. The deficit is
bounded below by an explicit Kesten constant. The obstruction is a property of the method, not of the group: it
applies to presentations of groups that do have fixed price (Section 5).

## 1. Setting

- `Gamma` is generated by a finite set `S`; `w = s_1^{e_1} ... s_l^{e_l}` is a word with `w = 1` in `Gamma`.
- `Gamma` acts freely, preserving the probability measure `mu` on `X`.
- One cell type: the cells are `(y, w)`, `y in X`, with boundary path as in the collapse-criterion artifact.
- `s in S` with `s^2 != 1`, occurring `k >= 2` times in `w` (counting `s` and `s^{-1}`), at indices
  `i_1 < ... < i_k`.
- Write `p_i = s_1^{e_1} ... s_i^{e_i}`. The path of cell `(y, w)` crosses at step `i` the `s_i`-edge
  `(h_i . y, s_i)` with

  ```text
  h_i = p_i^{-1}       if e_i = +1,        h_i = p_{i-1}^{-1}   if e_i = -1.
  ```

  (Step `i` joins `x_(i-1) = p_(i-1)^{-1}.y` and `x_i = p_i^{-1}.y`; the edge `(x, s)` joins `x` and `s.x`.)
- Identify the `s`-edge `(x, s)` with the point `x`. Because `s^2 != 1` and the action is free, distinct points give
  distinct edges.
- `Q = { h_a h_b^{-1} : a != b among the s-occurrences } \ {1}`, a finite symmetric set, and
  `Lambda_s = <Q>`. Replacing `w` by a cyclic rotation multiplies every `h_a` on the right by one common element,
  so `Q` and `Lambda_s` depend only on the cyclic word.

**Single-letter matching.** A Morse matching `M` for `{w}` (conditions (M1)-(M3)) all of whose removed edges are
`s`-edges. So `M` sends each cell of a Borel set `D ⊆ X` to one of its `k` `s`-edges, the choice of position being
an arbitrary Borel function of the cell. Its mass is `mu(M) = mu(D) <= 1`, and the removed set `E_M ⊆ X` has
`mu(E_M) = mu(M)` (Theorem A(b) of the collapse criterion). The number

```text
delta = 1 - mu(M)
```

is both the density of unmatched cells and the density `mu(X \ E_M)` of kept `s`-edges.

**Why the ceiling is 1.** For a torsion-free one-relator group `<S | w>` with `|S| >= 2`, the Dicks-Linnell value
(used through `one-relator-group-cost-equals-first-l2-betti-plus-one`) gives
`z(Phi_S) = |S| - 1 - beta_1 = 1`. So a single-letter matching at `{w}` reaches the Morse ceiling iff
`delta -> 0`. This is exactly what the dual-forest construction achieves when `k = 2`.

**Standing hypothesis (H).** `h_a != h_b` in `Gamma` for `a != b`, i.e. the `k` `s`-edges of each cell are
distinct (so each is traversed once and (M1) allows any of them). For `w` cyclically reduced and relator of a
one-relator group this is Weinbaum's theorem (no proper nonempty subword of `w` is trivial), since
`h_a h_b^{-1}` is a subword `s_{i+1} ... s_j` (up to shifting an endpoint by one) of length strictly between
`0` and `l`. Nothing below uses more than (H).

## 2. Heights and three counting lemmas (any free p.m.p. action)

**Incidences.** The point `x` is the `a`-th `s`-edge of exactly one cell, namely `y = h_a^{-1} x`. So the
incidence set `{(y, a)}` carries measure `k`, and for any Borel `A ⊆ X`

```text
mu{ (y, a) : h_a y in A } = k mu(A).                                    (2.1)
```

**Heights.** All edges of other letters are kept. Put `ht(x) = 0` for kept `s`-edges `x notin E_M`, and for
`x = M(y)` in `E_M` put `ht(x) = 1 + max ht(children of x)`; the children are the removed `s`-edges of `y`
other than `x`. By (M3) and König's lemma (at most `k - 1` children) `ht` is finite a.e., Borel, and satisfies

- *(top property)* in a matched cell `y`, `ht(M(y)) > ht(h_b y)` for every other occurrence `b`.

Let `A_j = {ht <= j}`, `n_j = mu(A_j)`. Then `A_0 = X \ E_M`, `n_0 = delta`, `n_j` is nondecreasing and
`n_j -> 1`.

**Lemma 1 (few straddling incidences).** Call a cell *inside* `A_j` if all its `k` `s`-edges lie in `A_j`, and
let `beta_j` be the measure of incidences `(y, a)` with `h_a y in A_j` and `y` not inside `A_j`. Then
`beta_j <= k delta`.

*Proof.* If `x in A_j \ A_0` then `x = M(y)`, and by the top property every other `s`-edge of `y` has height
`< ht(x) <= j`; so `y` is inside `A_j`. As `M` is injective and measure-preserving,
`mu(cells inside A_j) >= mu(A_j \ A_0) = n_j - delta`. These cells carry `k (n_j - delta)` incidences into `A_j`;
by (2.1) the total is `k n_j`. Hence `beta_j <= k delta`. ∎

**Lemma 2 (sublevels are almost `Q`-invariant).** For every `q in Q` and every `j`,
`mu(A_j Δ q A_j) <= 2 k delta`.

*Proof.* Let `q = h_a h_b^{-1}`. If `x in A_j` and `q x notin A_j`, the cell `y = h_b^{-1} x` has its `b`-th edge
`x` in `A_j` and its `a`-th edge `h_a y = q x` outside, so `(y, b)` is a straddling incidence. Thus
`mu(A_j \ q^{-1} A_j) <= beta_j <= k delta`. Since `q` preserves `mu`, `mu(A_j Δ q^{-1} A_j) =
2 mu(A_j \ q^{-1} A_j)`, and `Q` is symmetric. ∎

**Lemma 3 (a thick level forces unmatched mass).** For every `J >= 0`,

```text
(k - 1) mu{ ht = J } <= k ( (1 - n_J) + delta ).                        (2.2)
```

*Proof.* Each `x` with `ht(x) = J` has at least `k - 1` incidences `(y', a)`, `h_a y' = x`, with `x != M(y')`
(all `k` if `x` is kept, all but the matching one if `x` is removed). For such `y'`, either `y'` is unmatched
(measure `delta`), or `M(y')` is another edge of `y'`, so by the top property `ht(M(y')) > J`, i.e.
`M(y') in E_M \ A_J`, a set of measure `1 - n_J`; as `M` is a measure-preserving bijection `D -> E_M`, those
cells have measure `1 - n_J`. Each cell carries at most `k` incidences. ∎

## 3. The spectral input (Bernoulli and its factors)

Let `rho = rho(Lambda_s, Q) = || (1/|Q|) sum_{q in Q} lambda(q) ||` be the Kesten spectral radius; `rho < 1` iff
`Lambda_s` is nonamenable (Kesten).

**Lemma 4.** Let `Gamma ↷ (X, mu)` be the Bernoulli shift `[0,1]^Gamma` or any factor of it. For every real
`f in L^2_0(X)`,

```text
sum_{q in Q} || f - q f ||^2 >= 2 |Q| (1 - rho) || f ||^2.              (3.1)
```

*Proof.* Fix a real orthonormal basis `1 = e_0, e_1, ...` of `L^2[0,1]`. The product vectors indexed by
finitely supported `phi : Gamma -> N`, `phi != 0`, form a real orthonormal basis of `L^2_0` that `Gamma`
permutes. The stabilizer of `phi` stabilizes the finite nonempty set `supp phi`, so it is finite. Hence
`L^2_0 = ⊕ l^2(Gamma / K_i)` with `K_i` finite, and restricted to `Lambda_s` each summand is
`⊕ l^2(Lambda_s / (Lambda_s ∩ g K_i g^{-1}))`, again with finite, hence amenable, stabilizers. The decomposition
respects the real structure, so (KAG2) of `kesten-amenable-stabilizer-uniform-gap` with `(A, S) = (Lambda_s, Q)`
applies to each real component; sum. For a factor, `L^2_0(Y)` is a closed invariant subspace of `L^2_0(X)`. ∎

(Only (3.1) is used below, so the theorem holds for every free p.m.p. action whose Koopman representation of
`Lambda_s` on `L^2_0` satisfies it, e.g. is weakly contained in `lambda_{Lambda_s}`.)

## 4. The theorem

**Theorem.** Under Section 1 and (H), on the Bernoulli shift of `Gamma` or any free factor of it, every
single-letter Morse matching `M` for `{w}` satisfies

```text
1 - mu(M)  >=  (k - 1)(1 - rho) / (6 k^2).
```

In particular, if `Lambda_s` is nonamenable, no sequence of single-letter matchings at the letter `s` reaches the
Morse ceiling, whatever the Borel choice of positions.

*Proof.* Apply (3.1) to `f = 1_{A_j} - n_j`, with `||f||^2 = n_j (1 - n_j)` and
`||f - q f||^2 = mu(A_j Δ q A_j) <= 2 k delta` (Lemma 2):

```text
n_j (1 - n_j) <= theta_0 := k delta / (1 - rho)        for every j.     (4.1)
```

*Case `theta_0 >= 1/4`.* Then `delta >= (1 - rho)/(4k) >= (k - 1)(1 - rho)/(6 k^2)`.

*Case `theta_0 < 1/4`.* Put `theta = 2 theta_0 < 1/2`. The smaller root of `t(1 - t) = theta_0` is
`2 theta_0 / (1 + sqrt(1 - 4 theta_0)) <= theta`, so (4.1) puts every `n_j` in `[0, theta] ∪ [1 - theta, 1]`.
Since `1 - rho <= 1`, `n_0 = delta <= theta < 1 - theta`; since `n_j -> 1`, there is a least `J >= 1` with
`n_J >= 1 - theta`, and `n_{J-1} <= theta`. So `mu{ht = J} = n_J - n_{J-1} >= 1 - 2 theta`, and (2.2) gives

```text
(k - 1)(1 - 2 theta) <= k (theta + delta).
```

With `k delta = theta (1 - rho)/2 <= theta/2` this yields `k - 1 <= (3k - 3/2) theta <= 3k theta`, i.e.
`theta >= (k - 1)/(3k)`, i.e. `delta = theta (1 - rho)/(2k) >= (k - 1)(1 - rho)/(6 k^2)`. ∎

**Where it dies.** At (M3): well-foundedness is what makes the height filtration `A_0 ⊆ A_1 ⊆ ...` exhaust `X`,
and the top property is what makes every sublevel `2k delta`-almost `Lambda_s`-invariant. A spectral gap forbids
almost invariant sets of intermediate measure, so the filtration must cross from near `0` to near `1` in one
level, and one level cannot be that thick (Lemma 3). The invariant is `1 - rho(Lambda_s, Q)`.

## 5. Calibrations and examples

Computed by `experiments/single-letter-morse-2026-09-17/lambda_s.py` (exit 0). Nonamenability is certified by a
Freiheitssatz witness: two noncommuting reduced words in a conjugate of `Lambda_s`, both avoiding one letter of
`w`, generate a free group of rank 2 in `<S | w>`.

- **`k = 1`.** No children, heights `<= 1`, `delta = 0` is attained: consistent (the theorem needs `k >= 2`).
- **`k = 2`.** `Q = {q, q^{-1}}`, `Lambda_s` cyclic, `rho = 1`: no obstruction, consistent with the dual-forest
  theorem for twice-used letters.
- **Amenable `Gamma`** (`abAB`, `BS(1,2) = taTAA`): `rho = 1`, no obstruction, consistent with fixed price 1.
- **Poulin-Wróbel coset actions** have no spectral gap on `L^2_0`; (3.1) fails there and nothing is claimed.
- **`w = abacad`**, which presents `F(a, c, d)`: `Lambda_a ⊇ <AB, AC>` is free, so single-letter matchings at `a`
  (`k = 3`) have `delta >= (1 - rho)/27`, while the letter `b` (`k = 1`) reaches the ceiling. The obstruction is
  per letter.
- **`w = abaBabcdcDcd`** (every letter used three times, torsion-free). All four `Lambda_s` are nonamenable
  (witnesses `<AB, Ab>`, `<A, BAb>`, `<CD, Cd>`, `<C, DCd>`). So **no** single-letter matching for this relator
  reaches the ceiling on Bernoulli. Yet `Gamma = F(a,b) *_Z F(c,d)` (amalgamated along `abaBab = (cdcDcd)^{-1}`)
  has fixed price `3 = 1 + beta_1` by Gaboriau's amalgam-over-amenable theorem. So the method dies on a group
  where the conclusion holds.
- **`w = sbscsdbdcdbc`**: `Lambda_s` and `Lambda_d` are nonamenable; for `b` and `c` no depth-2 witness was found,
  so those letters are not claimed to be obstructed.

## 6. The class killed, and the survivors

**Killed.** Every Morse matching for a one-word list `{w}` whose removed edges all carry one letter `s`, with
arbitrary Borel variable positions, on Bernoulli (or any free factor, or any action satisfying (3.1)), whenever
`Lambda_s` is nonamenable: deficit `>= (k - 1)(1 - rho)/(6 k^2)`. This answers the recorded question "`k >= 3`
needs a Borel peeling of the incidence hypergraph" negatively. The peeling does not exist on Bernoulli, and no
choice of positions helps. It contains the fixed-position obstruction
(`fpbs-fixed-position-morse-matchings-die-on-bernoulli`) at `m = 1` as the special case of a constant position.

**Not killed.**

1. *Multi-letter matchings.* Kept edges of the other letters would make up most of `A_0`, and Lemma 1's count
   `n_0 = delta` fails.
2. *Several cell types* (`m >= 2` relators, or `m` copies with transversal modulation). Then `n_0 >= 1 - 1/m` can
   be large and (4.1) is no constraint.
3. *Longer word lists* `P_L` as in the target, where the extra relators supply the extra cells.

The target `fpbs-morse-deficit-vanishes-for-full-presentations` concerns `lim_L`, so it is untouched. What is
closed is the one-relator single-letter route to it.

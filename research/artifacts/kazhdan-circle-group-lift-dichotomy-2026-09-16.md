## 0. Setup: the covering group

Write `S^1 = R/Z` and `π : R → S^1` for the projection, and let `T(x) = x + 1`. Put

`Homeo_Z(R) = { F ∈ Homeo(R) : F ∘ T = T ∘ F }`.

**LEMMA 0.**

1. `Homeo_Z(R) ⊂ Homeo_+(R)`.
2. There is a surjective homomorphism `p : Homeo_Z(R) → Homeo_+(S^1)` with
   `π ∘ F = p(F) ∘ π`.
3. `ker p = ⟨T⟩ ≅ Z`, and `⟨T⟩` is central in `Homeo_Z(R)`.

*Proof.*

1. A homeomorphism of `R` is strictly monotone. Since `F(x+1) = F(x) + 1 > F(x)`, the
   map `F` is increasing.
2. Since `F` commutes with every integer translation, `p(F)[x] := [F(x)]` is well
   defined. It is continuous because `π` is a quotient map. It is bijective, with
   inverse `p(F^{-1})`, and hence it is a homeomorphism of the compact Hausdorff space
   `S^1`. It preserves orientation because `F` is increasing. Since
   `π ∘ FG = p(F) ∘ π ∘ G = p(F)p(G) ∘ π` and `π` is onto, `p(FG) = p(F)p(G)`.

   *Surjectivity.* Let `f ∈ Homeo_+(S^1)`. The map `f ∘ π : R → S^1` lifts through the
   covering `π`, since `R` is simply connected, to a continuous `F : R → R` with
   `π ∘ F = f ∘ π`. The function `F(x+1) - F(x)` is continuous and integer valued, so it
   is a constant `d`. Let `F'` be a lift of `f^{-1}` in the same way, with constant
   `d'`. Then `F ∘ F'` and `F' ∘ F` are lifts of the identity, so each is a translation
   by an integer. In particular `F` is a bijection, hence a homeomorphism of `R`, and it
   is increasing because `f` preserves orientation. Now `d = F(x+1) - F(x)` is the
   number of full turns that `f ∘ π` makes on `[x, x+1]`. An increasing homeomorphism
   lifting a circle homeomorphism has `d = ±1`: if `|d| ≥ 2`, then `F(x)` and
   `F(x) + 1` both lie in `F([x, x+1))` over one circle point, so `f` is not injective.
   Since `F` is increasing, `d > 0`, so `d = 1` and `F ∈ Homeo_Z(R)`.
3. If `p(F) = id`, then `F(x) - x` is continuous and integer valued, hence constant, so
   `F = T^n`. Conversely `p(T^n) = id`. Finally, `T` commutes with every element of
   `Homeo_Z(R)` by definition. ∎

For a subgroup `G ⊂ Homeo_+(S^1)`, write `Ĝ := p^{-1}(G)`. By Lemma 0 this gives a
central extension

`1 → ⟨T⟩ → Ĝ → G → 1`, with `⟨T⟩ ≅ Z`.

If `G` is generated by `g_1, …, g_k`, then `Ĝ` is generated by `T` and any lifts of the
`g_i`. So `Ĝ` is finitely generated whenever `G` is.

## 1. Left orders from actions on the line

**LEMMA 1.** Every subgroup of `Homeo_+(R)` is left-orderable.

*Proof.* Enumerate the rationals as `q_1, q_2, …`. Two distinct homeomorphisms differ
at some rational, since they are continuous and `Q` is dense. So for distinct `F, H`
there is a least index `n(F,H)` with `F(q_n) ≠ H(q_n)`. Declare `F ≺ H` when
`F(q_n) < H(q_n)` at `n = n(F,H)`.

- Exactly one of `F ≺ H`, `F = H`, `H ≺ F` holds.
- *Transitivity.* Let `F ≺ H ≺ L`, `a = n(F,H)` and `b = n(H,L)`.
  - If `a < b`, then `F` and `L` agree at `q_1, …, q_{a-1}`, and
    `F(q_a) < H(q_a) = L(q_a)`.
  - If `b < a`, then they agree before `b`, and `F(q_b) = H(q_b) < L(q_b)`.
  - If `a = b`, then `F(q_a) < H(q_a) < L(q_a)`.

  In each case `F ≺ L`.
- *Left invariance.* Let `M ∈ Homeo_+(R)`. Since `M` is injective,
  `n(MF, MH) = n(F, H)`. Since `M` is increasing, `MF(q_n) < MH(q_n)` if and only if
  `F(q_n) < H(q_n)`.

So `≺` is a left-invariant total order. ∎

**LEMMA 2 (dynamical realization).** A countable left-orderable group `H` embeds in
`Homeo_+(R)`.

The proof conjugates the left action into `Aut(Q,<)` and then extends to `R` by
Dedekind cuts. This avoids gap bookkeeping. It uses three facts, each proved here.

**(2a) Cantor's theorem.** Any two countable, nonempty, dense linear orders without
endpoints `A` and `B` are order-isomorphic.

*Proof (back and forth).* Enumerate `A = {a_0, a_1, …}` and `B = {b_0, b_1, …}`.

- *Extension step.* Let `f` be a finite order-preserving bijection from a finite
  `D ⊂ A` onto `f(D) ⊂ B`, and let `a ∈ A \ D`. The position of `a` relative to `D` is
  one of: below all of `D`, above all of `D`, or strictly between two consecutive
  elements `d < d'` of `D`. The corresponding set `J ⊂ B` is `(-∞, f(min D))`,
  `(f(max D), ∞)` or `(f(d), f(d'))`; it is all of `B` if `D` is empty. The set `J`
  is nonempty because `B` has no endpoints and is dense. It misses `f(D)`, so setting
  `f(a) := b` for any `b ∈ J` gives a larger finite order-preserving bijection. The
  same holds with the roles of `A` and `B` exchanged.
- *Iteration.* Start with `f_0 = ∅`. For `n ≥ 0`, extend `f_{2n}` so that `a_n` is in
  its domain (if not already), giving `f_{2n+1}`. Then extend `f_{2n+1}` so that `b_n`
  is in its range, giving `f_{2n+2}`.
- *Conclusion.* The union `f = ∪ f_n` is defined on all of `A`, onto `B`, and order
  preserving. ∎

**(2b) Extension of order automorphisms of `Q`.** Every order automorphism `f` of
`(Q,<)` extends to an increasing homeomorphism `f̄` of `R`, and `(fg)‾ = f̄ ḡ`.

*Proof.* A *cut* is a nonempty proper subset `C ⊊ Q` that is downward closed and has
no largest element. The maps `x ↦ C_x := {q ∈ Q : q < x}` and `C ↦ sup C` are mutually
inverse bijections between `R` and the set of cuts.

- *Cuts go to cuts.* The set `f(C)` is nonempty and proper because `f` is bijective.
  It has no largest element because `f` preserves order. It is downward closed: if
  `r < f(c)` with `c ∈ C`, then `r = f(q)` with `q < c`, so `q ∈ C`.
- *Definition.* Put `f̄(x) := sup f(C_x)`. Equivalently, `f(C_x) = C_{f̄(x)}`. For
  `q ∈ Q`, `f(C_q) = C_{f(q)}`, so `f̄(q) = f(q)`.
- *Composition.* `(fg)(C_x) = f(C_{ḡ(x)}) = C_{f̄ ḡ(x)}`, so `(fg)‾ = f̄ ḡ`. With
  `id‾ = id`, this makes `f̄` a bijection with inverse `(f^{-1})‾`.
- *Monotonicity.* If `x < y`, then `C_x ⊊ C_y`, so `f(C_x) ⊊ f(C_y)`. For cuts
  `C ⊊ C'`, pick `q ∈ C' \ C`. Then `q ≥ sup C`, since `C` is downward closed with no
  maximum, and `sup C' > q`, since `C'` has no maximum. So `f̄(x) < f̄(y)`.

A strictly increasing bijection of `R` has no jumps, so it is continuous, and so is its
inverse. Thus `f̄ ∈ Homeo_+(R)`. ∎

**(2c) Proof of Lemma 2.** Fix a left-invariant order `<` on `H`. Give `Ω := H × Q`
the lexicographic order: `(h,q) < (h',q')` iff `h < h'`, or `h = h'` and `q < q'`.

- *`Ω` is a countable dense linear order without endpoints.*
  - It is countable and nonempty.
  - It has no endpoints, since `(h,q-1) < (h,q) < (h,q+1)`.
  - It is dense. Given `(h,q) < (h',q')`: if `h = h'`, the point
    `(h, (q+q')/2)` lies between them; if `h < h'`, the point `(h, q+1)` does.
- *The action.* `H` acts on `Ω` by `g·(h,q) := (gh, q)`. This preserves the order,
  because left invariance gives `gh < gh'` iff `h < h'`, and `gh = gh'` iff `h = h'`.
- *Transport to `R`.* By (2a) there is an order isomorphism `ψ : Ω → Q`. Each
  `ψ_g := ψ ∘ (g·) ∘ ψ^{-1}` is an order automorphism of `Q`, and `g ↦ ψ_g` is a
  homomorphism. By (2b), `ρ(g) := (ψ_g)‾` defines a homomorphism
  `ρ : H → Homeo_+(R)`.
- *Faithfulness.* If `g ≠ 1`, then `g·(1,0) = (g,0) ≠ (1,0)`, so
  `ρ(g)(ψ(1,0)) = ψ(g,0) ≠ ψ(1,0)`.

∎

This is the standard dynamical realization up to the choice of construction; compare
Ghys, *Groups acting on the circle*, Enseign. Math. 47 (2001), §6. That reference was
not re-read here, and the proof above does not depend on it.

## 2. The lift dichotomy

**THEOREM 3 (lift dichotomy).** Let `G ⊂ Homeo_+(S^1)` be a subgroup with property
(T), and `Ĝ = p^{-1}(G) ⊂ Homeo_Z(R)`. Exactly one of the following holds.

- **(A)** There is a subgroup `K̂ ⊂ Ĝ` on which `p` is injective and whose image
  `K = p(K̂)` is a normal subgroup of finite index in `G`. Then `K ≅ K̂` is isomorphic
  to a subgroup of `Homeo_+(R)`.
- **(B)** `Ĝ` has property (T).

*Proof.* `G` is finitely generated (BdlHV Theorem 1.3.1), and so is `Ĝ` (§0).

*Case 1: some homomorphism `φ : Ĝ → R` has `φ(T) ≠ 0`.* Rescale so that `φ(T) = 1`
and put `K̂ = ker φ`.

- *Injectivity.* If `x ∈ K̂` and `p(x) = 1`, then `x = T^n` by Lemma 0(3), and
  `0 = φ(x) = n`, so `x = 1`.
- *Normality.* `K̂` is normal in `Ĝ` and `p : Ĝ → G` is onto, so `K = p(K̂)` is normal
  in `G`.
- *Finite index.* Since `p^{-1}(K) = K̂⟨T⟩`, we get `G/K ≅ Ĝ/K̂⟨T⟩`. The map `φ`
  induces an isomorphism `Ĝ/K̂ ≅ φ(Ĝ) ⊂ R`, carrying `K̂⟨T⟩/K̂` onto
  `φ(⟨T⟩) = Z`. Hence `G/K ≅ φ(Ĝ)/Z` is abelian. By BdlHV Corollary 1.3.6 every
  abelian quotient of `G` is finite, so `[G : K] < ∞`.

So (A) holds.

*Case 2: every homomorphism `Ĝ → R` vanishes on `T`.* Then every such homomorphism
factors through `Ĝ/⟨T⟩ ≅ G`, and so it is zero by BdlHV Corollary 1.3.5. Thus
`Hom(Ĝ, R) = 0`. The abelianization `Ĝ^{ab}` is a finitely generated abelian group
`Z^r ⊕ (finite)`, and `Hom(Ĝ, R) = Hom(Ĝ^{ab}, R) ≅ R^r`, so `r = 0` and `Ĝ^{ab}` is
finite. The subgroup `⟨T⟩` is central and `Ĝ/⟨T⟩ ≅ G` is Kazhdan, so `Ĝ` is Kazhdan by
BdlHV Theorem 1.7.11 (`bdhv-central-extension-property-t`). So (B) holds.

*Exclusivity.* Suppose (A) holds.

- `K̂ ∩ ⟨T⟩ = 1` because `p` is injective on `K̂`, and `T` is central.
- So `K̂⟨T⟩ ≅ K̂ × Z`.
- `K̂⟨T⟩ = p^{-1}(K)` has finite index in `Ĝ`, because `[Ĝ : p^{-1}(K)] = [G : K]`.

The group `K̂ × Z` maps onto `Z`, so it is not Kazhdan (BdlHV Corollary 1.3.5). By BdlHV
Theorem 1.7.1, `Ĝ` is not Kazhdan either, so (B) fails. ∎

**Remark (Euler class; not used).** Choose a set-theoretic section `s : G → Ĝ` and write
`s(g)s(h) = T^{c(g,h)} s(gh)`. Then `c` is an integral 2-cocycle representing the class
of the extension, which is the Euler class of the action up to the usual sign
convention. A homomorphism `φ` with `φ(T) = 1` has the form
`φ(T^n s(g)) = n + ψ(g)` with `c(g,h) = ψ(g) + ψ(h) - ψ(gh)`. So Case 1 is exactly the
vanishing of the real Euler class `e_R(G) ∈ H^2(G;R)`, and (B) is `e_R ≠ 0`. The proof
above never uses cohomology.

**Remark (the model for (B)).** BdlHV Example 1.7.13(iii) shows that the preimage of
`Sp_{2n}(Z)` in the universal cover of `Sp_{2n}(R)`, for `n ≥ 2`, is Kazhdan with
infinite centre. This is the same mechanism, but it is not an action on the line.

## 3. Navas's Questions 2 and 3 are equivalent

The two questions are quoted from Navas, arXiv:1712.06462v2, p. 3:

- **Q2:** "Does there exist an infinite, finitely-generated Kazhdan group of circle
  homeomorphisms ?"
- **Q3:** "Does there exist a nontrivial (hence infinite) Kazhdan group of
  orientation-preserving homeomorphisms of the interval ?"

In the graph they are `infinite-kazhdan-group-of-circle-homeomorphisms` and
`infinite-left-orderable-kazhdan-group`.

**COROLLARY 4 (Q2 ⟹ Q3).** If some infinite finitely generated Kazhdan group `G` is a
subgroup of `Homeo(S^1)`, then some infinite left-orderable group has property (T).

*Proof.* Let `G_+ = G ∩ Homeo_+(S^1)`. It is the kernel of the orientation character, so
`[G : G_+] ≤ 2`. Hence `G_+` is infinite and Kazhdan (BdlHV Theorem 1.7.1). Apply
Theorem 3 to `G_+`.

- In case (A), `K` has finite index in `G_+`, so it is infinite and Kazhdan. It is
  isomorphic to a subgroup of `Homeo_+(R)`, hence left-orderable by Lemma 1.
- In case (B), `Ĝ_+` is Kazhdan, is a subgroup of `Homeo_+(R)` by Lemma 0(1), and so is
  left-orderable by Lemma 1. It is infinite, since `T` has infinite order.

∎

**COROLLARY 5 (Q3 ⟹ Q2).** If some infinite left-orderable group `H` has property (T),
then some infinite finitely generated Kazhdan group is a group of circle homeomorphisms.

*Proof.* `H` is finitely generated (BdlHV Theorem 1.3.1), hence countable. Lemma 2 gives
an injective homomorphism `H → Homeo_+(R)`. Fix an increasing homeomorphism
`u : R → (0,1)` and identify `(0,1)` with `S^1 \ {[0]}` via `π`. For
`F ∈ Homeo_+(R)`, let `F^♮` be `u F u^{-1}` on `S^1 \ {[0]}` and fix `[0]`. Then `F^♮`
is continuous at `[0]`, because `u F u^{-1}` is an increasing bijection of `(0,1)` and
so tends to `0` at `0+` and to `1` at `1-`. It is a homeomorphism of `S^1`, and
`F ↦ F^♮` is an injective homomorphism. So `H` embeds in `Homeo_+(S^1) ⊂ Homeo(S^1)`.
∎

Together the two corollaries give **Q2 ⟺ Q3**.

## 4. What the dichotomy says about a witness

A positive answer to either question comes with one of two shapes. Either:

- **(A)** a Kazhdan group whose action on the line commutes with `T` and has zero real
  Euler class; or
- **(B)** a Kazhdan group with an infinite cyclic central subgroup acting by the
  translation `T`. When the circle action is minimal, one expects it to be of
  minimal-model type (ii) in the trichotomy recorded in
  `infinite-left-orderable-kazhdan-group`. That is heuristic and not proved here.

So an attack that rules out Kazhdan subgroups of `Homeo_+(R)` of type (iii) only does
not settle Q3. It must also handle the central shape (B), and conversely.

**Referee caveat (2026-09-16).** These shapes are not a normal form, and they do not
restrict witnesses. Every Q3 witness `H ⊂ Homeo_+(R)` already has shape (A) through
its one-point compactification (Corollary 5): the global fixed point `[0]` lifts to
the integers, and the lifts that fix `Z` form a periodic copy of `H` in `Homeo_Z(R)`.
The dichotomy therefore gives no WLOG reduction, such as to witnesses with finite
centre. It shows only that central lifts of circle witnesses are witnesses too.

## 6. Evidence only: circle actions a Kazhdan witness cannot have

These facts shape the Attempts of `infinite-kazhdan-group-of-circle-homeomorphisms`.
None enters a route.

1. **Projective actions.** A homomorphism from a Kazhdan group `G` into
   `PSL(2,R) ≅ SO_0(2,1) ⊂ O(2,1)` has relatively compact image (BdlHV Theorem
   2.12.7). The closure of the image is a compact subgroup, which lies in a conjugate of
   `PSO(2)` and is abelian. So the image is an abelian quotient of `G`, and it is
   finite.

   A homomorphism into the universal cover of `PSL(2,R)` then has image `Λ` with
   `Λ/(Λ ∩ centre)` finite, since it projects into a finite group. So `Λ` is a Kazhdan
   group with a finite-index central subgroup `Z_Λ` of the form `Z^r` or finite. If
   `r ≥ 1`, then `Z_Λ` has finite index and maps onto `Z`, contradicting BdlHV Theorem
   1.7.1 with Corollary 1.3.5. So `Λ` is finite.

   Hence no infinite Kazhdan group acts faithfully through projective or lifted
   projective actions.
2. **Invariant probability measures.** If a Kazhdan `G ⊂ Homeo_+(S^1)` preserves a
   probability measure, then some finite-index subgroup fixes a point. This follows
   from steps 3-5 of `amenable-infinite-simple-circle-groups-fix-a-point-proof`, with
   "abelian quotients of `G` are finite" replacing simplicity: the maximal-mass atoms
   are permuted through a finite quotient, or the rotation homomorphism `c` has finite
   image. The fixed-point-free complement is a line. So this case produces a Q3 witness
   of type (A) directly. It is not an obstruction, and it gives no new witness.

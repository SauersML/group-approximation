## Checks
- **Item 1: the retract.**
  - The Steinberg relations use only `+` and `·`, so non-unital ring maps induce homomorphisms.
  - `π` is a unital ring map, and `ι` is multiplicative. `π∘ι = id_D`, so `St(π)∘St(ι) = id`, and `St(ι)` is
    injective. ✓
- **Item 1: `K_2` maps to `K_2`.**
  - `A ↦ ι(A) + (1−e)I_N` is a homomorphism `GL_N(D) → GL_N(T_l)`, as for `Θ` in
    `sl-n-z-localized-embeds-in-fg-rf-elementary-group`.
  - It sends `e_ij(d)` to `eI + (1−e)I + ι(d)E_ij = e_ij(ι(d))`. So the square
    `St_N(D) → St_N(T_l) → E_N(T_l)` versus `St_N(D) → E_N(D) → E_N(T_l)` commutes on generators, and
    `K_2(N,D) → K_2(N,T_l)`. ✓
- **Item 2: the same detection.** Both directions check: the first by restricting along `St(ι)`, the second by
  pulling back along `St(π)`.
  - So `St(ι)^(−1)(St_N(T_l)_rf) = St_N(D)_rf`, which is the stated intersection. ✓
- **Item 3: `f(G_rf) ⊆ H_rf` for any homomorphism.** The preimage of a finite-index normal subgroup is finite-index
  normal.
  - So both `St(π)` and `St(ι)` descend.
  - `Λ_D → Λ_T` is injective by item 2, and `Λ_D → Λ_T → Λ_D` is the identity. ✓
- **Item 3: retracts of finitely presented groups are finitely presented.**
  - Let `K = ⟨⟨g^(−1)s(r(g)) : g ∈ S⟩⟩ ⊆ ker r`. Then `G/K` is generated by the image of `s`.
  - `H → G/K → H` is `r∘s = id`, so `h ↦ s(h)K` is bijective and `K = ker r`. ✓
- **Item 3: the conclusion.**
  - `St_N(T_l)_rf` finitely normally generated makes `Λ_T` finitely presented, hence `Λ_D` finitely presented.
  - The kernel of a surjection from the finitely presented `St_N(D)` onto the finitely presented `Λ_D` is finitely
    normally generated.
  - The inputs are finite presentation of `D` (`U ≅ D` by Step 1 of the normal-form proof) and the rank-five node
    for `N ≥ 5`. ✓

## N1: item 4, the step behind "they lie in `St_N(D)`"
The `T_l`-symbol of two commuting units of `D` is formed from the units `U = ι(u) + (1−e)` and `V = ι(v) + (1−e)` of
`T_l`. It is not literally `St(ι)` of the `D`-symbol, because `St(ι)(w_12(u))` uses the non-units `ι(u^(±1))`. They
agree for the following reason.
- The diagonal matrices form a unital subring `D × Z ⊆ T_l`, via `j`, and `ι = j∘(d ↦ (d,0))`.
- For `N ≥ 3`, `St_N(D × Z) = St_N(D) × St_N(Z)`.
  - `x_12((a,0))` commutes with `x_21((0,b)) = [x_23((0,b)), x_31((0,1))]`, because it commutes with both factors:
    - `[x_12(a,0), x_23(0,b)] = x_13(0)`;
    - `[x_12(a,0), x_31(0,1)] = x_32(0)`.
  - The other index patterns are Steinberg relations.
- So `{U, V}_(T_l) = St(j)({u,v}_D, {1,1}_Z) = St(j)({u,v}_D, 1) = St(ι)({u,v}_D)`.

# STW Problem I: the modular group is a universal test (2026-09-12)

Lane `quasitrace-three-projections`. Proof artifact for the claim
`stw01-modular-group-algebra-quasitraces-are-traces` and the routes
`stw01-problem-i-via-modular-group-algebra` and
`stw01-modular-test-from-three-projection-quotient`.

## Statement

Let `Q = C^3 *_C C^2` be the universal unital C*-algebra generated by a partition
of unity into three projections `e_1, e_2, e_3` (pairwise orthogonal, summing to
`1`) and one projection `p`. Since `C*(Z_3) = C^3`, `C*(Z_2) = C^2` and the full
group C*-algebra of a free product is the unital full free product,

```text
Q = C*(Z_3 * Z_2) = C*(PSL_2(Z)).
```

**Theorem.** The following are equivalent.

1. STW Problem I: every bounded 2-quasitrace on a unital C*-algebra is a trace.
2. Every bounded 2-quasitrace on `C*(PSL_2(Z))` is a trace.
3. For one (equivalently every) countable group `Gamma` that surjects onto
   `PSL_2(Z)`, every bounded 2-quasitrace on `C*(Gamma)` is a trace. Examples:
   `SL_2(Z)`, the braid group `B_3` (the trefoil knot group), `F_2`.

**Sharpness.** A two-block partition gives `C^2 * C^2 = C*(D_infinity)`, which is
nuclear because `D_infinity` is amenable, so Haagerup's theorem makes all its
quasitraces (and those of its quotients) traces. Among unital free products
`C^m * C^n` with `m >= n >= 2`, the pair `(3, 2)` is the least that can carry a
counterexample, and the theorem shows it carries every counterexample.

**Relation to the three-projection test.** There are unital surjections

```text
P_3 = C^2 * C^2 * C^2  ->  C^4 * C^2  ->  C^3 * C^2 = Q.
```

The first abelianizes the pair `r_1, r_2` (the abelianization of `C*(r_1, r_2)` is
`C^4`, spanned by the four products `r_1 r_2`, `r_1(1-r_2)`, `(1-r_1) r_2`,
`(1-r_1)(1-r_2)`) and keeps `r_3`. The second merges two of the four minimal
projections. So linearity on `P_3` implies linearity on `Q` directly, and the
theorem gives the converse through Problem I. `Q` is the smaller host.

**Group remarks.**
- `PSL_2(Z)` is generated by torsion, so it does not surject onto `F_2`. This test is
  therefore not an instance of the free-group quotient step
  (`stw01-full-free-group-algebra-quasitraces-are-traces`).
- `PSL_2(Z)` contains a free subgroup of rank 2 and finite index (the image of the
  principal congruence subgroup of level 2). The full algebra of a subgroup embeds in
  the full algebra of the group, and `C*(F_2)` is not exact (Wassermann), so `Q` is
  not exact and Haagerup's theorem gives nothing on `Q`. The reduced algebra
  `C*_r(PSL_2(Z))` is exact, since virtually free groups are exact, so any
  counterexample quasitrace must live on the full side.

## Proof of (2) ⟹ (1)

Assume (1) fails.

**Steps 0-3 (unchanged from the three-projection artifact).** They produce a type
`II_1` AW*-factor `M` with its canonical quasitrace `tau`, a projection `q in M`,
`beta > 0`, and a positive finite-spectrum element

```text
y = sum_(i=1)^k gamma_i e_i,     gamma_1 > ... > gamma_k >= 0,
```

with `e_i` nonzero pairwise orthogonal projections summing to `1`, such that

```text
D(y, beta q) = tau(y + beta q) - tau(y) - beta tau(q) != 0.
```

**Step 4' (three-block dilation).** Choose distinct `lambda_1, ..., lambda_k` in
`(0, 1)` and put `a = sum_i lambda_i e_i in M`. Then `a` is invertible and

```text
a - a^2 = sum_i lambda_i (1 - lambda_i) e_i >= m 1,     m = min_i lambda_i (1 - lambda_i) > 0.
```

Put `b = m q`. Then `0 <= b <= m 1 <= a - a^2`. Put `s_2 = b^(1/2)` and
`s_3 = (a - a^2 - b)^(1/2)`, both in `M_+`. In `M_3(M)` let `c` be the column
`(a, s_2, s_3)^T` and

```text
r = c a^(-1) c*.
```

- `c* c = a^2 + s_2^2 + s_3^2 = a^2 + b + (a - a^2 - b) = a`.
- Hence `r* = r` and `r^2 = c a^(-1) (c* c) a^(-1) c* = c a^(-1) c* = r`, so `r` is a
  projection.
- Its entries are `r_ij = c_i a^(-1) c_j`, so `r_11 = a`, `r_12 = a a^(-1) s_2 = s_2`
  and `r_21 = s_2 a^(-1) a = s_2`.

Let `f_1, f_2, f_3` be the diagonal matrix units of `M_3(M)`, a partition of unity.
Then

```text
f_1 r f_1 = a (+) 0 (+) 0,        f_1 r f_2 r f_1 = (r_12 r_21) (+) 0 (+) 0 = b (+) 0 (+) 0.
```

The spectrum of `a (+) 0 (+) 0` is `{0} union {lambda_i}`. Choose `g` continuous on
`[0, 1]` with `g(0) = 0` and `g(lambda_i) = gamma_i`. Then

```text
g(f_1 r f_1) = y (+) 0 (+) 0,          m^(-1) f_1 r f_2 r f_1 = q (+) 0 (+) 0.
```

So both elements lie in `B = C*(1, f_1, f_2, f_3, r) <= M_3(M)`.

**Step 5' (amplify, restrict, pull back).**
- *The defect survives the amplification.* With `tau_3` from (I3) and homogeneity on
  `C*(q (+) 0 (+) 0)`:

  ```text
  tau_3((y + beta q) (+) 0 (+) 0) - tau_3(y (+) 0 (+) 0) - beta tau_3(q (+) 0 (+) 0) = D(y, beta q) != 0.
  ```

- *Restriction.* `tau_3|_B` is a bounded 2-quasitrace (I6). It is bounded because
  `0 <= w <= ||w|| 1` gives `tau_3(w) <= ||w|| tau_3(1)` by linearity on `C*(1, w)`.
- *Pullback.* The universal property of the unital full free product gives a unital
  *-homomorphism `pi : C^3 * C^2 -> B` with `e_j -> f_j` and `p -> r`. It is
  surjective, so `sigma = tau_3|_B o pi` is a bounded 2-quasitrace on `Q` (I6), using
  `M_2(pi)` for the extension.
- *The defect in `Q`.* Put `x = g(e_1 p e_1)` and `z = (beta / m) e_1 p e_2 p e_1`,
  both positive. A unital *-homomorphism commutes with continuous functional
  calculus, so `pi(x) = y (+) 0 (+) 0` and `pi(z) = beta q (+) 0 (+) 0`. Therefore

  ```text
  sigma(x + z) != sigma(x) + sigma(z),
  ```

  and (2) fails.

**(1) ⟹ (2)** is trivial.

**(2) ⟺ (3).** (2) ⟹ (3) goes through (1). Conversely, a surjection `Gamma -> PSL_2(Z)`
induces a unital surjection `C*(Gamma) -> Q`. A non-linear bounded 2-quasitrace on `Q`
pulls back to a non-linear one on `C*(Gamma)` (I6), because the surjection maps
positive elements onto positive elements. Examples:
- `SL_2(Z) -> PSL_2(Z)`, modulo the center;
- `B_3 = <x, y | x^2 = y^3>`, modulo the central element `x^2`, gives `Z_2 * Z_3`;
- `F_2 -> Z_2 * Z_3`, sending the free generators to the two torsion generators.

∎

## Where a witness must live

A counterexample on `Q` can be taken of the form `sigma(x + z) != sigma(x) + sigma(z)`,
with

```text
x in C*(e_1 p e_1),      z in C*(e_1 p e_2 p e_1),
```

two positive elements of the corner `e_1 Q e_1`. They satisfy the corner identity

```text
e_1 p e_1 - (e_1 p e_1)^2 = e_1 p e_2 p e_1 + e_1 p e_3 p e_1.
```

So the whole problem is the interaction of one projection with a three-block
partition, read inside one corner.

## Attempts recorded, not claimed

- **Projection counting (Blackadar–Handelman dimension functions on projections).**
  Heuristically dead.
  - By Cuntz's exact sequence for unital full free products (primary not read here),
    `K_0(Q) = (Z^3 (+) Z^2) / Z[1] = Z^4`, generated by `[1], [e_1], [e_2], [p]`.
  - A 2-quasitrace is Murray–von Neumann invariant and additive on orthogonal
    projections, so it induces a homomorphism on `K_0(Q)`. Its values on projections
    of `M_n(Q)` are then fixed by `sigma(1), sigma(e_1), sigma(e_2), sigma(p)`.
  - The trace `sum_ch w_ch ch` over the six characters, with product weights, has
    the same four values.
  - So no counterexample is visible on projections. Witnesses need continuous
    functional calculus such as `g(e_1 p e_1)`.
- **Exact quotients.** Quasitraces factoring through `C*_r(PSL_2(Z))`, through
  `C*(D_infinity)`, or through finite-dimensional quotients are traces.
  - A counterexample needs a non-exact quotient that carries a faithful non-linear
    quasitrace.
  - Exactness of the corner algebra `e_1 Q e_1` is not decided here.

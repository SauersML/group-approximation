# STW Problem I: the modular test pair is the universal order pair (2026-09-12)

Lane `quasitrace-single-pair`. Proof artifact for the claims
`stw01-modular-test-pair-algebra-is-universal-order-pair` and
`stw01-universal-order-pair-quasitrace-additivity`, and for the route
`stw01-modular-single-pair-via-universal-order-pair`.

**Outcome.** Additivity on the single pair is not decided here. This artifact proves
that the test pair carries no structure beyond one order relation:
- the unital C*-algebra it generates is the universal unital C*-algebra of a pair
  `0 <= h_0 <= 1`, `0 <= k_0 <= h_0 - h_0^2` (Theorem A);
- so Kaplansky's problem is equivalent to additivity on that universal pair (Theorem B).

Section 4 records the attempts on the additivity itself.

Notation as in `research/artifacts/stw01-modular-single-pair-test-2026-09-12.md`.
`Q = C^3 * C^2 = C*(PSL_2(Z))` is the universal unital C*-algebra of a partition of
unity `e_1, e_2, e_3` and one projection `p`, and

```text
h = e_1 p e_1,     k = e_1 p e_2 p e_1,     k_3 = e_1 p e_3 p e_1,     h - h^2 = k + k_3.
```

Let `U` be the universal unital C*-algebra of two elements `h_0, k_0` subject to

```text
0 <= h_0 <= 1,        0 <= k_0 <= h_0 - h_0^2.                               (OP)
```

The relations bound the norms (`||h_0|| <= 1`, `||k_0|| <= 1/4`), so `U` exists. Every pair
satisfying (OP) in a unital C*-algebra `B` gives a unital *-homomorphism `U -> B`.

## 1. Theorem A: `C*(1, h, k) ~= U`

**Theorem A.** The unital *-homomorphism `phi : U -> Q` with `h_0 -> h`, `k_0 -> k` is
injective. So the unital C*-subalgebra of `C*(PSL_2(Z))` generated by the test pair is the
universal unital C*-algebra of one order pair.

**Proof.**

*The pair satisfies (OP).*
- `h = e_1 p e_1` is a positive contraction.
- `k = (e_2 p e_1)^*(e_2 p e_1) >= 0`.
- `k <= k + k_3 = h - h^2`.

So `phi` exists, and its image is `C*(1, h, k)`.

*Every Hilbert-space order pair dilates into a corner of a representation of `Q`.* Let
`a, b in B(H)` satisfy (OP).

1. **Douglas factorization.** Put `S = (1 - a)^(1/2) a^(1/2) >= 0`, so `S^* S = a - a^2 >= b`.
   Douglas' lemma gives `C in B(H)` with `||C|| <= 1` and `b^(1/2) = C S`. Put
   `d = (1 - a)^(1/2) C^* C (1 - a)^(1/2)`. Then `0 <= d <= 1 - a` and
   `b = S C^* C S = a^(1/2) d a^(1/2)`.
2. **A three-block projection.** In `M_(3,1)(B(H))` put
   `c = (a^(1/2), d^(1/2), (1 - a - d)^(1/2))^T`. The entries are self-adjoint, so
   `c^* c = a + d + (1 - a - d) = 1`, and `r = c c^*` is a projection in `M_3(B(H))`.
3. **The entries.** `r_11 = a`, `r_12 = a^(1/2) d^(1/2)` and `r_21 = d^(1/2) a^(1/2)`, so
   `r_12 r_21 = b`. With the diagonal matrix units `f_1, f_2, f_3`,

   ```text
   f_1 r f_1 = a (+) 0 (+) 0,          f_1 r f_2 r f_1 = b (+) 0 (+) 0.
   ```
4. **The representation.** The universal property of `Q` gives a unital *-homomorphism
   `rho : Q -> M_3(B(H))` with `e_j -> f_j` and `p -> r`. So `rho(h) = a (+) 0 (+) 0` and
   `rho(k) = b (+) 0 (+) 0`.

*Norms.* Let `P` be a *-polynomial in two noncommuting variables. `rho(h)`, `rho(k)` and
`rho(1) = 1 (+) 1 (+) 1` are block diagonal, so

```text
rho(P(h, k)) = P(a, b) (+) P(0, 0) 1 (+) P(0, 0) 1,
```

and `||P(a, b)|| <= ||rho(P(h, k))|| <= ||P(h, k)||_Q`. The norm of `U` is the supremum of
`||P(a, b)||` over unital Hilbert-space representations of (OP). Hence

```text
||P(h_0, k_0)||_U <= ||P(h, k)||_Q = ||phi(P(h_0, k_0))|| <= ||P(h_0, k_0)||_U.
```

So `phi` is isometric on a dense *-subalgebra, hence isometric and injective. ∎

**Remarks.**
- Douglas' lemma is used in `B(H)`. That suffices, because the universal norm is a
  supremum over Hilbert-space representations. No invertibility of `a` is needed. The
  Step 4' dilation of the single-pair artifact needs an invertible `a`.
- `U` also surjects onto `Q`. Take `a = sum_i lambda_i e_i` with distinct `lambda_i in (0, 1)`,
  `m = min_i lambda_i (1 - lambda_i)`, and `b = m p <= m 1 <= a - a^2`. The universal property
  gives `U -> Q` with image `C*(1, a, p) = Q`. So `U` embeds in `Q`, surjects onto `Q`,
  and is not exact.

## 2. Theorem B: Problem I is additivity on the universal order pair

**Theorem B.** The following are equivalent.

1. STW Problem I: every bounded 2-quasitrace on every unital C*-algebra is a trace.
2. Every bounded 2-quasitrace `sigma` on `U` satisfies
   `sigma(h_0 + k_0) = sigma(h_0) + sigma(k_0)`.
3. Every bounded 2-quasitrace `sigma` on `Q` satisfies `sigma(h + k) = sigma(h) + sigma(k)`.

**Proof.**
- **(1) ⟹ (2).** Linearity on the unital algebra `U`.
- **(2) ⟹ (3).** Let `sigma` be a bounded 2-quasitrace on `Q`. Then `sigma o phi` is a
  bounded 2-quasitrace on `U`. Composing with a *-homomorphism preserves homogeneity,
  additivity on commuting positive elements, `x^* x ~ x x^*`, the 2-amplification and
  boundedness. Its defect on `(h_0, k_0)` equals the defect of `sigma` on `(h, k)`. Only
  the existence of `phi` is used, not Theorem A.
- **(3) ⟹ (1).** The reviewed single-pair theorem, route
  `stw01-problem-i-via-modular-single-pair`. ∎

So additivity on the universal order pair is a group-free form of Kaplansky's problem:
two positive contractions tied by the single relation `k_0 <= h_0 - h_0^2`. Clause 2 is
formally stronger than clause 3, since a quasitrace on `U ~= C*(1, h, k)` need not extend
to `Q`. The two are equivalent only through the whole reduction.

## 3. A sandwich bound on the defect

**Lemma C.** For every bounded 2-quasitrace `sigma` on `U`,

```text
|sigma(h_0 + k_0) - sigma(h_0) - sigma(k_0)| <= sigma(h_0 - h_0^2).
```

**Proof.** Put `c = h_0 - h_0^2`. It commutes with `h_0`, and `0 <= k_0 <= c`. Bounded
2-quasitraces are monotone on positive elements. This is the standard axiom used in the
continuity trust boundary of
`research/artifacts/stw01-quasitrace-status-and-local-permanence-audit-2026-08-30.md`.
They are also additive on commuting pairs. So

```text
sigma(h_0) <= sigma(h_0 + k_0) <= sigma(h_0 + c) = sigma(h_0) + sigma(c),
sigma(h_0) <= sigma(h_0) + sigma(k_0) <= sigma(h_0) + sigma(c).
```

Both quantities lie in `[sigma(h_0), sigma(h_0) + sigma(c)]`. ∎

**Why this gives no contradiction.** In Step A of the single-pair proof,
`a = (1/2) 1 + eps y` in a `II_1` AW*-factor with quasitrace `tau`, and the produced defect
is `eps D(y, beta q)`. The commuting room is `tau(a - a^2) = tau(1)/4 - eps^2 tau(y^2)`. It is
positive for every admissible `eps`, because `eps gamma_1 < 1/2` with `gamma_1` the largest
eigenvalue of `y`. So Lemma C only confines the defect. It is consistent with every
counterexample the reduction can produce.

## 4. Attempts on the additivity itself (none settles it)

- **Cuntz semigroup.** Bounded 2-quasitraces correspond to lower semicontinuous
  dimension functions `d` with `sigma(x) = int_0^infinity d((x - t)_+) dt`
  (Blackadar–Handelman).
  - The inequality `h_0 + k_0 <~ h_0 (+) k_0` gives only the support-level bound
    `d((h_0 + k_0 - t)_+) <= d(h_0) + d(k_0)`.
  - Deciding additivity this way needs the Cuntz classes of all cut-downs
    `(h_0 + k_0 - t)_+` in terms of those of `h_0` and `k_0`. This lane could not compute
    them in the non-exact algebra `U`, and no comparison theorem for `U` is known here.
- **Free products of traces (Avitzour–Dykema).** `sigma` is a trace on each two-projection
  algebra `C*(e_j, p)` and on `C^3`. A quasitrace is not linear on words, however, so
  these restrictions do not determine it, and no free-product formula applies.
  - The natural two-block algebra holding `k ~ e_2 g e_2` (with `g = p e_1 p`) is
    `C*(1, e_2, g)`, a quotient of `C^2 * C([0,1])`.
  - `C^2 * C([0,1])` surjects onto `Q`, so it is not exact. Whether its quotient
    `C*(1, e_2, g)` is exact is not decided here, so this gives no traciality.
- **Ideal extension.** Let `J` be the closed ideal of `U` generated by `k_0`. Then
  `U/J ~= C([0,1])`, and `stw01-extensions-preserve-qt-linearity` reduces linearity on `U`
  to linearity on `J`. But `J` is not exact:
  - The surjection `U -> Q` of Section 1 sends `k_0 -> m p`, so it maps `J` onto the ideal
    `<p>` of `Q`.
  - `Q/<p> ~= C^3` is nuclear, so the extension is locally split. An exact `<p>` would make
    `Q` exact.
  - So `<p>` is not exact, and neither is its preimage `J`. Haagerup's theorem does not
    reach `J`.
- **Pinching form.** Put `z = (p e_1, e_2 p e_1)^T`. Then `h + k = z^* z`, so
  `sigma(h + k) = sigma_2(X)` for `X = z z^* = c g c^*`, where `c = (1, e_2)^T`. Also
  `sigma(h) + sigma(k) = sigma_2(E_2(X))`, where `E_2` is the diagonal pinching. So the test
  is pinching invariance of `sigma_2` on one explicit positive matrix. This is the generic
  reformulation of linearity for any pair and adds no leverage.
- **Commuting sandwich (Lemma C).** It confines the defect to `sigma(h_0 - h_0^2)`, and every
  counterexample from the reduction has positive room (Section 3).

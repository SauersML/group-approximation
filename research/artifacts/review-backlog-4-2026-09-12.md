## 2. `positive-rokhlin-entropy-makes-leavitt-units-surjunctive` (5a2a793cd): PASS

Read: the claim, its route, Section 2 of
`rokhlin-entropy-self-copy-dichotomy-2026-09-12.md`, and the three required
nodes.

- **Lemma 2.1, corners.** Recomputed from `t_i s_j = δ_ij` and
  `s_0 t_0 + s_1 t_1 = 1`:
  - `ι_0(a)ι_0(a') = s_0 a a' t_0 + s_1 t_1`, since both cross terms carry
    `t_0 s_1` or `t_1 s_0`;
  - `ι_0(1) = 1` and `t_0 ι_0(a) s_0 = a`;
  - `ι_0(a)ι_1(b) = s_0 a t_0 + s_1 b t_1 = ι_1(b)ι_0(a)`;
  - equal images give `a = 1` under `t_0(·)s_0` and `b = 1` under `t_1(·)s_1`.

  So `U × U ≤ U`. Checked.
- **Lemma 2.2, matrix units.** With `t_u = t_{u_n}···t_{u_1}`, the relation
  `t_v s_w = δ_{v,w}` holds by induction, and `Σ_{|u|=n} s_u t_u = 1` by
  induction. This gives a unital map `M_{2^n}(F_2) → L`, injective by
  simplicity. So `GL_{2^n}(F_2) ≤ U`. Checked.
- **Corollary hypotheses.** `U` is countably infinite and contains `U × U`,
  plus finite subgroups of unbounded order. Put `G` = the first factor. If
  `h_sup(U) < ∞` then `h_sup(G) < ∞`, and the `T_n` sit inside the second
  factor, commuting with `G` and meeting it trivially. So the theorem gives
  `h_sup = 0`: the dichotomy {0, ∞} holds.
- **Equivalences.**
  - POS ⇒ `h_sup > 0`, by the Seward Cor. 7.7 import.
  - Then `h_sup = ∞` (INF), and INF ⇒ RBS by Seward Thms 6.6/7.6.
  - RBS ⇒ POS through the Bernoulli 2-shift, which is free and ergodic with
    entropy `log 2`.
  - Surjunctivity and direct finiteness come from Seward Cor. 4.1.
- **"Every field `K`" check.** It is consistent with the classical facts:
  - Kaplansky settles characteristic 0.
  - In characteristic p, a counterexample `ab = 1 ≠ ba` needs only finitely
    many coefficients, in a finitely generated `F_p`-subalgebra `R`. `R` is a
    domain and a Jacobson ring, so a maximal ideal misses one nonzero
    coefficient of `ba − 1`. `R/m` is finite, which gives a finite-field
    counterexample.

  So the import's scope is not an overreach.
- **Trust surfaces.** Seward arXiv:1501.03367v4, Cor. 4.1, Thms 6.6, 6.7, 7.3,
  7.6 and Cor. 7.7, as the import nodes quote them. This pass did not re-read
  them.
- **Other reviews.** The dichotomy theorem already has
  `review-rokhlin-self-copy-dichotomy-2026-09-12.md`. gk-verify-pos §13
  re-derived the corner and matrix-unit computations.
- **Scope.** The claim is conditional on
  `leavitt-unit-group-has-positive-rokhlin-entropy-action`, which is open, and
  says so.

## 3. `surjunctivity-is-axiomatized-by-rectangle-clauses` (fb5e07c43): PASS

Read: the claim, its route (`requires: []`), and Sections 0–2 of
`gottschalk-rectangle-clauses-and-recognition-2026-09-12.md`.

- **Lemma 1.2 (evaluation).** Recomputed. `στ(x)(g)` reads `x` at
  `g λ(s) λ(m)`. As `x` varies, `p(s,m) := x(gλ(s)λ(m))` runs over every
  function that is constant on realized forward classes. The classes inject
  into `K`, and `p(1,1) = x(g)` because both labels `1` go to `1`. So
  `στ = id` iff Dec at the realized forward table. The reverse composite is
  symmetric. Checked.
- **Lemma 1.3 (left inverse).** `A^K` is compact and `τ` is an injective,
  continuous, equivariant map, so `τ^{-1}` on the closed image is continuous
  and equivariant. Its value at `1` reads a finite window. Extending the local
  rule arbitrarily gives `σ` with `στ = id`. This is the standard
  Curtis–Hedlund argument on a subshift, and it needs no finite generation.
  Checked.
- **Theorem 1.**
  - ⇒: take an injective, non-surjective `τ`, enlarge its memory to contain
    `1`, and take `σ` from Lemma 1.3. Dec holds. If Enc held, `τσ = id` and `τ`
    would be surjective. Checked.
  - ⇐: `στ = id` gives injectivity. A surjective `τ` with a left inverse is
    bijective, which forces `τσ = id` and so contradicts not-Enc. Checked.
- **Lemma 1.1 (monotonicity).** A function constant on the classes of a coarser
  relation is constant on the finer classes. So Dec passes to coarser forward
  tables and not-Enc to finer reverse tables. The directions are right.
  Checked.
- **Lemma 2.1 and Theorem 2.** An empty disjunction is false, so a failing
  instance has every reverse coincidence inside `T_r`, i.e. `T_r(λ) ⊆ T_r`. Its
  premises give `T_f(λ) ⊇ T_f`. With Corollary 1.4 this yields both directions.
  Checked.
- **Consequences.**
  - **(a) subgroups.** Universal sentences pass to subgroups.
  - **(b) local embeddings.** A partial embedding that is injective on the
    finite set of labels and pairwise products preserves the premise equations
    and the conclusion inequalities (`φ(1) = 1` follows from multiplicativity
    at `1·1`). Ultraproducts follow by Łoś.
  - **(c) directed colimits with arbitrary structure maps.** Each premise
    equation holds at some stage. A conclusion equation holding at any stage
    would hold in the colimit, so every conclusion equation fails at every
    stage.
  - **(d) products.** The non-Horn remark is correct.
  - **(e) existentially closed groups.** `not ρ_D` is an existential sentence
    with no parameters, so it transfers from `L` to `H * L` and down to an
    existentially closed `H`. Every group embeds in an existentially closed one.
  - **(f) presentations and complexity.** Every labelling satisfying the
    premises factors through `P(D)`, and equalities can only be created along
    homomorphisms. So `ρ_D` is universally valid iff some conclusion equation
    holds in `P(D)`. Strictness is decidable and the equations are `Σ⁰₁`, so
    the conjecture is `Π⁰₂`.

  All checked.
- **Test.** For `K = Z`, a residually finite and hence surjunctive group, the
  theorem requires every strict `D` to fail to realize. Z is abelian, so the
  realized forward and reverse tables coincide under `(s,m) ↔ (m,s)`, and
  `Dec ∧ ¬Enc` must then fail on that single table. It does: an injective CA
  over Z is surjective. This is consistent, but it is a sanity check, not an
  independent proof.
- **Trust surfaces.** None external. The route is self-contained.
  gk-verify-pos §15 re-derived both directions and the existentially closed
  transfer.
- **Novelty.** The rectangle two-table form and the universal axiomatization
  are presented without a priority claim. Heredity under subgroups and
  ultraproducts is classical (Gromov; Weiss).

## 4. `thompson-f-moment-data-cannot-certify-nonamenability`: PASS

Read: the claim and `thompson-f-moment-barrier-proof` (`requires: []`).

- **Step 1.** `supp μ = σ(P)`:
  - the trace is faithful, so every open set meeting `σ(P)` has positive
    measure;
  - a finite spectrum would make each Lagrange projection `E_i` a polynomial
    in `P`, so `E_i ∈ C[F]` with `E_i(1 − E_i) = 0`;
  - `F` is bi-orderable, so it has unique products and `C[F]` has no zero
    divisors. Contradiction.

  Checked. The scope note is also right: the argument only needs "`C[G]` has
  no idempotent other than 0 and 1", since `E_i` is already such an idempotent.
- **Step 2.** The pushforward under `t = x²` is at most 2-to-1, so the support
  stays infinite. The moments are `M_j`. Checked.
- **Step 3.** `W_N` is the convex hull of the moment curve on `[0,1]`, with
  nonempty interior. A boundary point `m` gives a nonzero polynomial `r ≥ 0` on
  `[0,1]` with `∫ r dμ_2 = 0`, so `μ_2` sits on finitely many zeros. That
  contradicts Step 2. Checked.
- **Step 4.** Put `m_ε = (m − εu)/(1 − ε)`, which stays interior for small `ε`,
  and `ν_2 = (1 − ε)ν' + εδ_1`. This reproduces `m` exactly, with `1` in the
  support. Symmetrizing gives `ν` on `[−1,1]` with the same even moments, zero
  odd moments, and `±1` in the support. Checked.
- **Step 5.** Deductions from the moment data alone hold for `ν`, and `‖P‖ =
  sup|supp μ|`. Kesten's criterion then gives the conclusion. Checked.
- **Positive-direction paragraph.** Slightly imprecise wording. "If
  supp μ_2 ≤ x_k this forces μ_2 onto the k−1 zeros of q" should say: if
  `sup supp μ_2 < x_k`, then `(x − x_k)q² ≤ 0` integrates to 0, so `μ_2` sits
  on `Z(q)`, which has `k − 1` points. That contradicts Hankel positivity of
  size `k`. If instead `x_k ∈ supp μ_2`, the bound `sup supp ≥ x_k` holds
  directly. The conclusion `sup supp μ_2 ≥ x_k > θ` is correct either way.
  This is a GAP in wording only; no graph change is needed.
- **Trust surfaces.** Bi-orderability of F and Kesten's criterion, both
  classical.

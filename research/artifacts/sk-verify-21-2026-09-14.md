## 1. `piecewise-dyadic-level-models-give-non-uniform-growth`: PASS

Conventions: `R = LC(X,F_2) ⋊_T Z`, `(fu^i)(f′u^j) = f(f′∘T^(−i))u^(i+j)`. So `u^j e_U = e_(T^jU) u^j` and `e_U u^(−j) = u^(−j) e_(T^jU)`.

**(a) Matrix units.** Fix a scale `k` and write `A_n = A^(i)_n`.
- `s′_i s_i = Σ_(m,n) e_(A_m ∩ T^(n−m)A_n) u^(n−m)`. For `m ≠ n`, `A_m ∩ T^(n−m)A_n = T^(−m)(T^mA_m ∩ T^nA_n) = ∅`. The diagonal terms sum to `e_(W_1)`.
- `s_i s′_i = Σ_(m,n) u^n e_(A_n)e_(A_m) u^(−m) = Σ_n e_(T^nA_n) = e_(W_i)`, since the `A_n` partition `W_1`.
- `s′_j = Σ_n u^(−n) e_(T^nA^(j)_n) = s′_j e_(W_j)` and `s_i = Σ_n e_(T^nA_n) u^n = e_(W_i) s_i`. So `s′_j s_i = 0` for `i ≠ j`.
- `s_i e_(W_1) = s_i` gives `ε_ij ε_kl = s_i(s′_j s_k)s′_l = δ_jk ε_il`, and `Σ_i ε_ii = 1`. With `ε_11 = e_(W_1)`, `x ↦ (ε_1i x ε_j1)_(i,j)` is a ring isomorphism `R → M_(2^k)(e_(W_1)Re_(W_1))`.

**(b) Corner.** Write `W = W_1`, `r` for the first return time, `B_j = {r = j}` and `T_W = T^r`.
- `e_W(fu^j)e_W = f 1_(W∩T^jW) u^j`.
- `v = Σ_j u^j e_(B_j)` and `v′ = Σ_j e_(B_j)u^(−j)`. The cross terms of `vv′` contain `e_(B_j)e_(B_l) = 0`. Those of `v′v` are supported on `B_j ∩ T^(l−j)B_l = T^(−j)(T^jB_j ∩ T^lB_l) = ∅`, because `T_W` is injective. So `vv′ = v′v = e_W`.

- Injective: if `Σ_m g_m v^m = 0`, uniqueness of Laurent coefficients in `R` gives `Σ_m g_m1_(D_(m,j)) = 0` for each `j`. Disjointness in `m` kills each term, and summing over `j` gives `g_m = 0`.

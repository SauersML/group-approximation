# Clifford covers: finite pullbacks, invisible adjacency, saturated graphs

Lane `w4-clifford-nonlinear`, 2026-09-12. Host: the Kun--Thom Clifford cover `E_S` of
`research/artifacts/clifford-cover-surjunctivity-test-host-2026-09-12.md` (lane w3-free-neg).

Nothing here decides whether the complete-graph cover is surjunctive. This artifact proves four things:

- **Theorem A:** exactly which graphs let the center survive in a finite quotient.
- **Lemma 2.2:** infranormal subgroups have normal profinite closures.
- **Theorem B:** a strict pair on any Clifford cover must read a profinitely invisible adjacency.
- **Theorem C:** Clifford covers over profinitely saturated graphs are surjunctive. This includes covers
  whose center lies in the finite residual.

## 0. Setting and coordinates

- `G` is a group and `X` is a left `G`-set with finitely many orbits.
- `S` is a `G`-invariant graph on `X`: a set of unordered pairs of distinct points. Its adjacency form is
  `b_S(x,y) = 1` exactly when `{x,y}` is in `S`.
- `q in F_2` is a constant.
- `V = directSum_X F_2`, with basis `e_x`.
- `Vtilde_S` is the group generated by `c_x` (`x in X`) and a central `eps`, with relations

  ```text
  eps^2 = 1,   c_x^2 = eps^q,   c_x c_y = eps^(b_S(x,y)) c_y c_x.
  ```

- `G` acts by `g(c_x) = c_(gx)` and `E_S = Vtilde_S semidirect G`.
- `E_S / <eps> = W = (Z/2) wr_X G`.

**Existence and normal form.** Fix a total order on `X`. The bilinear cocycle

```text
beta(u,v) = sum_(y < x) u_x v_y b_S(x,y) + q sum_x u_x v_x
```

defines a central extension of `V` by `F_2` in which the lift of `e_x` squares to `eps^q` and lifts of
`e_x, e_y` have commutator `eps^(b_S(x,y))`. On a finite site set `T` the presented group has at most
`2^(|T|+1)` elements (normal form `eps^s c_(x_1) ... c_(x_k)`, `x_1 < ... < x_k`), so the presentation
defines exactly this extension, and `eps != 1`. The relations are `G`-invariant, so `G` acts by
automorphisms.

**Coordinates.** Write `(u, s, g)` for `eps^s c_(x_1) ... c_(x_k) g`, where `supp u = {x_1 < ... < x_k}`.
Then

```text
(u,s,g) (v,t,h) = ( u + g v,  s + t + beta(u, g v) + gamma(v, g),  g h ),
```

where `gamma(v,g)` is the sign of reordering `c_(g y_1) ... c_(g y_l)` into increasing order. It counts the
pairs `y_i < y_j` of `supp v` with `g y_i > g y_j`, weighted by `b_S(g y_i, g y_j)`.

**Relevant pairs.** For elements `a = (u_a, s_a, g_a)` and `m = (u_m, s_m, g_m)`, let `R(a,m)` be the set of
unordered pairs of distinct sites inside `supp u_a  union  g_a supp u_m`. The coordinates of `a m` depend
on `S` only through `b_S` restricted to `R(a,m)`.

**Consequence 0.1 (coordinate transport).** Let `S'` be another `G`-invariant graph on `X`, with the same
`q`. Send `(u,s,g)` in `E_S` to `(u,s,g)` in `E_(S')`. This map is multiplicative on the pair `(a,m)`
whenever `b_S = b_(S')` on `R(a,m)`. It is injective and sends `1` to `1`.

**Profinite quotients of the site set.** For a finite-index normal subgroup `K` of `G`, put
`pi_K : X -> K\X`. `G` acts on `K\X` because `K` is normal, and `K\X` is finite: an orbit `G/Gamma` maps
onto `G/(K Gamma)`. Two sites are **profinitely inseparable** if `K x = K y` for every `K`. For
`X = G/Gamma` this happens for `a Gamma` and `b Gamma` exactly when `a^(-1) b` lies in

```text
Gammabar = intersection_K K Gamma,
```

the profinite closure of `Gamma`.

## 1. Theorem A: when the center survives a finite quotient

**Definition.** `S` is a **finite pullback** if for some `K` there is a `G`-invariant graph `Sbar` on
`K\X` such that `{x,y}` is in `S` exactly when `K x != K y` and `{K x, K y}` is in `Sbar`. In particular no
edge of `S` joins two sites of one `K`-fibre.

**Theorem A** (`clifford-cover-center-separable-iff-graph-is-finite-pullback`). `eps` survives in some finite
quotient of `E_S` if and only if `S` is a finite pullback.

*Proof of "if".* Let `Z = K\X`, with the graph `Sbar`. Let `Vtilde_Sbar(Z)` be the Clifford group of
Section 0 over the finite set `Z`. It is finite, and its `eps` is nontrivial. `G/K` acts on it by permuting
the `c_z`. Define

```text
f : E_S -> Vtilde_Sbar(Z) semidirect G/K,    c_x -> c_(K x),   eps -> eps,   g -> gK.
```

The defining relations of `E_S` are preserved:

- `c_x^2 = eps^q` maps to `c_(Kx)^2 = eps^q`.
- For `Kx != Ky`, `[c_x, c_y] = eps^(b_S(x,y))` maps to `eps^(b_Sbar(Kx,Ky))`, the same value by the
  pullback property.
- For `Kx = Ky` with `x != y`, the image commutator is `1`, and `b_S(x,y) = 0` because the fibre carries
  no edge.
- `g c_x g^(-1) = c_(gx)` maps to `c_(gKx) = c_(K gx)`, since `pi_K` is `G`-equivariant.
- The relations of `G` hold in `G/K`.

`E_S` is presented by the relations of `Vtilde_S`, those of `G`, and the conjugation relations, so `f` is a
homomorphism with `f(eps) = eps != 1`. QED

*Proof of "only if".* Let `f : E_S -> Q` be a homomorphism to a finite group with `f(eps) != 1`. Put
`Z = { f(c_x) : x in X }`, a finite subset of `Q`. `G` acts on `Q` by conjugation through `f`, and
`f(g) f(c_x) f(g)^(-1) = f(c_(gx))`, so `Z` is a `G`-set and `rho : x -> f(c_x)` is equivariant.

- For `x != y`, `[f(c_x), f(c_y)] = f(eps)^(b_S(x,y))`, and `f(eps) != 1`. So `b_S(x,y) = 1` exactly when
  `f(c_x)` and `f(c_y)` do not commute.
- Let `Sbar` be the non-commuting graph on `Z`. It is `G`-invariant.
- If `rho(x) = rho(y)` and `x != y`, the images commute, so `b_S(x,y) = 0`.

Let `K` be the kernel of the permutation action of `G` on the finite set `Z`. It is normal of finite index,
and for `k in K`, `rho(kx) = k . rho(x) = rho(x)`, so `rho` factors as `X -> K\X -> Z`. Pull `Sbar` back to
a graph on `K\X`. Two sites `x != y` are adjacent in `S` exactly when `rho(x) != rho(y)` and the images are
adjacent, so `S` is the pullback of that graph. Sites in one `K`-fibre have equal images, so no edge joins
them. QED

**Corollary A.1** (via `separated-finite-normal-subgroups-preserve-surjunctivity` and
`rf-lamp-wreaths-over-surjunctive-bases-are-surjunctive`). If `G` is surjunctive and `S` is a finite
pullback, then `E_S` is surjunctive.

**Corollary A.2 (the residue).** Let `X = G/Gamma` with `Gamma` of infinite index, and let `S` have at
least one edge.

- For the double-coset set `D(S) = { g : {o, g o} in S }`, with `o = Gamma`, `S` is a finite pullback exactly
  when `D(S)` is bi-invariant under some finite-index `L >= Gamma` and meets `L` in the empty set.
- **Finite degree.** If every site has finitely many neighbours, `S` is not a finite pullback. An edge
  `g in D(S)` gives `L g L in D(S)`, which contains the infinitely many distinct cosets `g l Gamma`,
  `l in L/Gamma`.
- **Complete graph.** `D(S) = G \ Gamma` meets every finite-index `L >= Gamma`. This recovers
  `complete-graph-clifford-cover-center-dies-in-finite-quotients`.

So the separated finite-normal theorem reaches no finite-degree cover and not the complete-graph cover.

*Proof of the first bullet.* A finite `G`-set through which `X = G/Gamma` factors is `G/L` with `L >= Gamma`
the stabilizer of the image of `o`. Adjacency `{a Gamma, b Gamma}` depends only on `a^(-1) b`, and descends
to `G/L` exactly when `D(S)` is `L`-bi-invariant. Fibres are independent exactly when `D(S)` misses `L`.

## 2. Inseparable sites and infranormal subgroups

**Lemma 2.1.** Sites in different `G`-orbits are separable. For `X = G/Gamma`, `K a Gamma = K b Gamma`
exactly when `a^(-1) b in K Gamma`. So `a Gamma`, `b Gamma` are profinitely inseparable exactly when
`a^(-1) b in Gammabar`.

*Proof.* `K\X` maps onto the orbit set of `X`. For one orbit, `b Gamma in K a Gamma = a K Gamma`, since `K`
is normal. QED

**Lemma 2.2** (`infranormal-subgroups-have-normal-profinite-closure`). Let `Gamma <= G`, and suppose
`P_Gamma = { t in G : t Gamma t^(-1) <= Gamma }` generates `G`. Then `K Gamma` is normal in `G` for every
finite-index normal `K`, and `Gammabar` is normal.

*Proof.* Let `t in P_Gamma` and `f : G -> G/K`. Then `f(t Gamma t^(-1)) <= f(Gamma)`. Both are finite and
conjugate, so they have the same order and are equal. Hence `K t Gamma t^(-1) = K Gamma`, and since
`t K t^(-1) = K`, `t (K Gamma) t^(-1) = K Gamma`. The normalizer of `K Gamma` is a subgroup containing
`P_Gamma`, so it is `G`. An intersection of normal subgroups is normal. QED

**Remark 2.3 (where the Kun--Thom phase sits).**
- Under Lemma 2.2 the profinitely inseparable pairs of `G/Gamma` are the pairs inside one fibre of
  `G/Gamma -> G/Gammabar`.
- For `t in P_Gamma`, `t^(-1) Gamma t <= t^(-1) Gammabar t = Gammabar`. So the edge `{o, h o}` with
  `h = t^(-1) gamma t` outside `Gamma`, which carries the marked word of `kun-thom-clifford-radical-phase`
  and makes `E_S` nonsofic, joins two inseparable sites.
- A non-normal infranormal `Gamma` is not profinitely closed, since `Gammabar` is normal.
- **Theorem E pair.** `Gamma = EL_r(F_q[x_1..x_d])` lies in `N = EL_r(F_q[x_1^(+-1)..x_d^(+-1)])`, which is
  normal in `G = N semidirect SL_d(Z)` with residually finite quotient `SL_d(Z)`. So `N` is closed and
  `Gammabar <= N`, and `G/Gammabar` is infinite.

## 3. Theorem B: strict pairs read invisible adjacency

Throughout, `G` is surjunctive. `(tau, sigma)` is a strict pair over `E_S`:
- `tau` has memory `M` and `sigma` has memory `S_sigma`, both containing `1`;
- `sigma tau = id`;
- `p` is a Garden of Eden pattern on a finite `Omega`.

Put `F = {1} union M union S_sigma union Omega union S_sigma M union Omega M`, as in
`strict-pairs-transfer-to-table-realizations`. Let

```text
R = union of R(a,m)  over  (a,m) in (S_sigma union Omega) x M,
```

the finite set of site pairs read by the products the transfer theorem needs.

**Definition.** A read edge `{x,y}` in `S` is **K-clean** if:
- `K x != K y`, and
- no read non-edge `{x',y'}` in `R` with `K x' != K y'` has `{K x', K y'}` in the `G`-orbit of `{K x, K y}`.

**Cleanliness passes to smaller K.** Let `K' <= K`. If `K' x = K' y` then `K x = K y`. If
`{K' x', K' y'} = g {K' x, K' y}`, applying `K'\X -> K\X` gives `{K x', K y'} = g {K x, K y}`. So a
K-clean edge is K'-clean.

**Theorem B (orbital form).** Some read edge is K-clean for no `K`.

*Proof.* Suppose each read edge `E` is `K_E`-clean. Put `K = intersection_E K_E`, which is of finite index
and normal. Every read edge is K-clean.
- **The graph on the quotient.** On `K\X` let `Sbar` be the union of the `G`-orbits of `{K x, K y}` over
  read edges. These are pairs of distinct points, so `Sbar` is a `G`-invariant graph.
- **The pullback.** Let `S'` be its pullback to `X`, with no edges inside `K`-fibres. `S'` is a finite
  pullback.
- **Agreement on `R`.** Read edges lie in `S'`. A read non-edge either has both ends in one fibre, or its
  image is outside `Sbar` by cleanliness. So `b_(S') = b_S` on `R`.
- **Transfer.** By Theorem A, Corollary A.1, `E_(S')` is surjunctive. By Consequence 0.1 the identity on
  coordinates `F -> E_(S')` satisfies `phi(sm) = phi(s) phi(m)` and `phi(wm) = phi(w) phi(m)`, and it is
  injective. The transfer theorem makes `E_(S')` carry a strict pair. Contradiction. QED

**Coset form.** Let `X = G/Gamma`, and give a read pair `{a Gamma, b Gamma}` the orbital `g = a^(-1) b`,
defined up to `Gamma g Gamma` and inversion. By Lemma 2.1:
- `K x = K y` exactly when `g in K Gamma`;
- the image orbits coincide exactly when `g' in K Gamma g^(+-1) Gamma`, using `K Gamma g K Gamma = K Gamma g Gamma`.

As `K` shrinks, each failure condition shrinks. With finitely many conditions, some single condition fails
for every `K`. So some read edge `g` satisfies one of:

```text
g in Gammabar,     or     g' in cl(Gamma g Gamma)  union  cl(Gamma g^(-1) Gamma)  for a read non-edge g',
```

where `cl(A) = intersection_K K A` is the profinite closure.

**Complete graph.** There are no non-edges between distinct sites, so some read pair is profinitely
inseparable. Under Lemma 2.2 it lies in one fibre of `G/Gamma -> G/Gammabar`.

**Theorem B' (holonomy form, complete graph).** Let `P` be the finite graph on the read sites with a move
`y -> g_a y` for every `a in S_sigma union Omega`, `m in M` and `y in supp u_m`. Moves are reversible, with
label `g_a^(-1)`. In a component with base site `x_0`, let `Hol` be the group of products of labels around
closed paths at `x_0`; it lies in `Stab(x_0)`. Every site of the component is `w x_0` for a path product `w`.

Then some component contains distinct sites `w x_0 != w' x_0` with `w^(-1) w' in cl(Hol)`.

*Proof.* Suppose not.
- **The target set.** Let `X'` be the disjoint union over components `i` of `G / cl(Hol_i)`.
- **The map.** Send `w x_0^(i)` to `w cl(Hol_i)`.
  - *Well defined:* two paths to one site differ by a closed-path product, which lies in `Hol_i`.
  - *Equivariant for every move.*
  - *Injective:* within a component by assumption, and across components because they land in different orbits.
- **The order.** Order `X'` so that the map preserves the order of the read sites.
- **Products agree.** In the complete graph all distinct sites are adjacent. So `beta` and `gamma` of
  Section 0 depend only on order and equalities among the sites of each product, and these are preserved.
  The identity on the sign and `G` coordinates, with `lambda` on the lamps, satisfies the product identities
  of the transfer theorem.
- **Contradiction.** In `X'` every point stabilizer `g cl(Hol_i) g^(-1)` is profinitely closed. So the
  complete graph on `X'` is profinitely saturated (Section 4), and `E(X')` is surjunctive by Theorem C.
  Transfer gives a strict pair on it. QED

B' implies the complete-graph case of B: `cl(Hol) <= cl(Stab x_0)`, and `w^(-1) w' not in Stab(x_0)`.

**Theorem B'' (table-group form, complete graph, any group `G`).** Let `U` be the group generated by
symbols `[g_a]` for the `G`-parts of the elements of `F`, with relators `[g_a][g_m] = [g_(am)]` for the
products the transfer theorem needs. Path words `w` and the holonomy groups `Hol_i^U` of the move graph `P`
live in `U`, and `U -> G` sends `Hol_i^U` into `Stab(x_0^(i))`. If `(tau, sigma)` is strict over the
complete-graph cover of any `G`-set `X`, then one of the following holds:

1. two elements of `Omega` with equal lamp and sign coordinates have `G`-parts whose difference lies in
   `Res_fin(U)`;
2. some component contains distinct read sites `w x_0 != w' x_0` with `w^(-1) w'` in the profinite closure
   of `Hol_i^U` in `U`.

*Proof.* Suppose neither holds. Finitely many conditions are involved, and each is avoided by some
finite-index normal subgroup of `U`. Their intersection `K_U` avoids all of them. Put `psi : U -> U/K_U`.
- **Target.** `X'' = disjoint union of (U/K_U) / psi(Hol_i^U)` is a finite `U/K_U`-set.
- **Sites.** `lambda(w x_0^(i)) = psi(w) psi(Hol_i^U)` is well defined, injective by the failure of (2),
  equivariant for the moves, and order-embeddable.
- **Elements.** `phi(u, s, g_a) = (lambda u, s, psi[g_a])` lands in the finite group
  `Vtilde(X'') semidirect U/K_U`.
- **Checks.** The needed products are exact, since the `U`-relators hold and the signs depend only on
  order and equalities. `phi` separates the distinguished pairs of `Omega` by the failure of (1).
- **Contradiction.** A finite group is surjunctive, so the transfer theorem gives the contradiction. QED

No surjunctivity of `G` is used, so this filter applies to complete-graph Clifford covers of every group.
It is checkable on designs, through finite quotients of the forward table group.
- **Residually finite `G`.** Condition (1) never holds there. Distinct `G`-parts have a nontrivial
  difference in `G`, some finite quotient of `G` separates them, and composing with `U -> G` gives a finite
  quotient of `U`. So over the Kun--Thom pair, (2) is the condition to test.
- **The phase configuration.** It meets (2) through the ascending relation `t Gamma t^(-1) <= Gamma`,
  imposed on generators.

**Reading for the Kun--Thom pair.** Take `x_0 = o`, so `Hol <= Gamma`. A witness must force, through its
products, a subgroup `Hol` of a stabilizer whose profinite closure contains the difference of two read
sites. The radical-phase configuration is one such table:
- moves by generators of `Gamma` at `o`;
- a path `o -> t o -> gamma t o -> t^(-1) gamma t o = h o`.

Its holonomy is `Gamma`, with closure `Gammabar`, which contains `h`.

## 4. Theorem C: saturated graphs

**Definition.** `S` is **profinitely saturated** if for every edge `{x,y}`:
1. some `K` has `K x != K y`;
2. for each non-edge `{x',y'}` of distinct sites, some `K` has `{K x', K y'}` outside `G {K x, K y}`.

**Theorem C** (`profinitely-saturated-clifford-covers-are-surjunctive`). If `G` is surjunctive and `S` is
profinitely saturated, then `E_S` is surjunctive.

*Proof.* Let `F` be a finite subset of `E_S`. Let `R_F` be the union of `R(a,b)` over all `a, b in F`.
- **One quotient.** By saturation each edge in `R_F` is K-clean for some `K`, relative to the finitely
  many non-edges in `R_F`. Cleanliness passes to smaller `K`, so one `K` works for all of them.
- **A separated cover.** Build `S'` as in Theorem B. It agrees with `S` on `R_F`, so the identity on
  coordinates embeds `F` as a partial multiplication table into `E_(S')`. That group is surjunctive by
  Corollary A.1.
- **Conclusion.** By Corollary 1 of `strict-pairs-transfer-to-table-realizations`, a group whose finite
  subsets all embed into surjunctive groups is surjunctive. QED

**Instances.**
1. **Finite pullbacks.** Adjacency descends to `K\X` and fibres are independent.
2. **Complete graphs over closed stabilizers.** If every point stabilizer of `X` is profinitely closed,
   distinct sites are separable (Lemma 2.1), and there are no non-edges between distinct sites. For
   `X = G/Gamma` with `Gamma` closed of infinite index, the center of `E_S` lies in its finite residual
   (Corollary A.2), yet `E_S` is surjunctive.
3. **The cross graph.** For `X = G/Gamma`, let `S_cross` join `a Gamma` and `b Gamma` exactly when
   `a^(-1) b` is not in `Gammabar`. `D(S_cross) = G \ Gammabar` is `Gamma`-bi-invariant and symmetric.
   - **Condition 1:** holds by Lemma 2.1.
   - **Condition 2:** a non-edge `g'` lies in `Gammabar`, so it lies in `K Gamma` for every `K`. Its image
     orbit is the diagonal one, which equals the orbit of the edge `g` only when `g in K Gamma`. Some `K`
     excludes that.
   - **Finite pullback exactly when `Gammabar` has finite index.** A pullback needs `K Gamma <= Gammabar`
     for some `K`. Conversely a finite-index `Gammabar` equals some `K Gamma`: the chain of finite-index
     subgroups `K Gamma >= Gammabar` stabilizes.
4. **The Kun--Thom Theorem E pair.** `G/Gammabar` is infinite (Remark 2.3). So `E_(S_cross)` has its center
   in the finite residual, and the separated theorem does not apply. By Theorem C, `E_(S_cross)` is
   surjunctive. Its quotient `E_(S_cross) / <eps>` is the surjunctive wreath `W`. This settles one instance
   of the residue of `finite-normal-subgroups-do-not-affect-surjunctivity`, in the predicted direction.

**Remark 4.1 (finite degree over infranormal pairs).** Let `Gamma` be infranormal and not normal. Then
`|Gammabar : Gamma| = ∞`, and no finite-degree graph with an edge is profinitely saturated.

*Proof.*
- **Infinite index.** Some `t in P_Gamma` has `t Gamma t^(-1) != Gamma`; otherwise the generating set
  `P_Gamma` would normalize `Gamma`. Then `Gamma < t^(-1) Gamma t < t^(-2) Gamma t^2 < ...` strictly, and
  every term lies in `Gammabar` by Lemma 2.2. An infinite strictly increasing chain between `Gamma` and
  `Gammabar` forces infinite index.
- **Non-saturation.** Let `g` be an edge orbital. If `g in Gammabar`, condition 1 fails. Otherwise the
  profinite closure of `Gamma g Gamma` contains `Gammabar g Gammabar = g Gammabar`, because multiplication
  is continuous in the profinite topology. It therefore contains the infinitely many distinct sites
  `g gammabar o`, `gammabar in Gammabar/Gamma`. Saturation would make all of them neighbours of `o`, which
  contradicts finite degree. QED

**What stays open.**
- **Non-saturated graphs.** The complete-graph cover over the Kun--Thom pair is not saturated: its edges
  inside `Gammabar`-fibres are inseparable. Every graph carrying the radical-phase edge fails too, and by
  Remark 4.1 so does every finite-degree graph.
- **Soficity of `E_(S_cross)`.** Not decided here. If it were sofic, Theorem C would add nothing new there.

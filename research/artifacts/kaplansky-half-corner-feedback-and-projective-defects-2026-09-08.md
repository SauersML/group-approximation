# Half-corner feedback and an explicit projective comparison

Status: exact algebraic reduction, with a failed primitive control and a bounded finite-group certificate. No Kaplansky counterexample or surjunctivity result is claimed. The finite calculation was run on MSI by the parent agent; the script and certificate were independently read here.

## 1. Source and notation

Work in `S=F_2[Q]`, where `Q=L_2(F_2)^×`, and let `ev:S→L_2(F_2)` be evaluation. Brackets around a unit denote its group-ring basis element. All differences below equal sums in characteristic two.

Set `x=s_00 t_01`, `y=s_01 t_00`, `r=[1+x]`, `s=[1+y]`, `g=rs`, and `e=g+g²`. The subgroup generated by `r,s` is `S_3`; `e` is its central natural-block idempotent. Put `q=1-e`. Write `U=[u]`, where the prefix permutation `u` sends `0→00`, `10→01`, and `11→1`.

The forward and inverse blocks needed below are

```
a = e U e,       c = q U e,
α = e U⁻¹ e,     β = e U⁻¹ q.
```

Thus `αa+βc=e`. Under evaluation, `ev(e)=p=s_0t_0`, `ev(c)=ev(β)=0`, and, writing `a_0=ev(a)` and `b_0=ev(α)`,

```
b_0 a_0=p,       a_0 b_0=p_00<p.
```

In particular the nonzero projection `p_01=p+p_00` satisfies `p_01 a_0=0`.

## 2. The exact square-zero mechanism

Let `e=f+h` be any orthogonal idempotent split. Choose an upper block `M∈eSq` and a lower block `K∈qSe`, and put

```
W=(1+K)(1+M)U,
a_M=a+Mc,
β_M=β+αM,
c_K=c+K a_M,
B=α+β_M K.
```

These formulas follow directly from `M²=K²=0`. Since `W⁻¹W=1`,

```
B a_M + β_M c_K=e.
```

The two conditions

```
h β_M=0,             c_K f=0                         (H)
```

force `R=β_M c_K=fRh`, and hence `R²=0`. Consequently

```
C=(e+R)B,            C a_M=e.
```

No evaluation-kernel condition on `M` or `K` is needed: `ev(c)=0` already gives `ev(a_M)=a_0` for every `M`, while the lower shear leaves `a_M` unchanged. Therefore `a_M C≠e`, because evaluating a hypothetical equality and multiplying by `p_01` on the left would give `p_01=0`. Padding `a_M,C` by `q` would give a strict one-sided inverse in `S`.

The equations in (H) are sequentially linear,

```
h α M=h β,           K a_M f=c f,
```

but jointly nonlinear because the coefficient `a_M f` in the second equation depends on `M`. This is not a support-size or complexity improvement by itself.

The first equation is equivalent to the existence of `X∈eSh` with `hαX=h`. In one direction take `X=(a+Mc)h`; in the other take `M=Xhβ`.

## 3. Every primitive split in the original S_3 block fails

One tempting split is

```
d=e(1+r),       d′=e(1+s),
f=dd′,          h=d′d.
```

The exact natural block `eF_2[S_3]` is `M_2(F_2)`. Thus `d²=d′²=0`, `f+h=e`, and `fh=hf=0`; evaluation gives `f=p_00`, `h=p_01`.

Nevertheless its first half-equation has no solution anywhere in `S`. The same obstruction applies to every primitive idempotent `h` in this original natural block.

Indeed, a solution gives `hαX=h`, hence

```
h′ e Y=h′,          h′=U h U⁻¹,    Y=XU⁻¹.
```

The coefficients `h′,e` lie in the finite matrix group on the four leaves `(000,001,010,011)`. Conditional expectation of group rings onto this finite subgroup would give a solution there. Test that identity on the six-dimensional exterior square of its natural four-dimensional module.

Write the natural basis as `v_1,...,v_4`, and abbreviate `A=12`, `B=14`, `C=23`, `D=34` for wedge basis vectors. The parent order-three matrix is `G⊗I_2`, with `G=[[0,1],[1,1]]`. Its action on the cross subspace is

```
gA=D,    gB=C+D,    gC=B+D,    gD=A+B+C+D.
```

It fixes `13` and `24`. Therefore

```
im(e)=span{A+B+C, A+D}.
```

The child `S_3` acts on `span(v_1,v_2)` and fixes `v_3,v_4`. Every element of its natural block kills `A=12` and `D=34` on the exterior square. A primitive child idempotent `h′` has rank two, one rank-one action on each of `span(13,23)` and `span(14,24)`. Yet `h′e` has image contained in the one-dimensional span of `h′(B+C)`. Thus `h′eY=h′` is impossible.

This is an exact representation obstruction, including arbitrary full-group coefficients in `Y`. Rotating the primitive split among the six rank-one idempotents does not evade it.

## 4. A split whose first equation is guaranteed

Put

```
T=αa=e(U⁻¹eU)e.
```

This element belongs to a finite subgroup algebra. Choose its stable-image idempotent `h` and Drazin inverse `v`, so that

```
h²=h,    Tv=vT=h,    v=hvh,
T f is nilpotent,    f=e+h.
```

These elements can be obtained by polynomial Chinese remaindering from the corner minimal polynomial `m_T(X)=X^m r(X)`, with `r(0)=1`: use `h≡0 mod X^m`, `h≡1 mod r`, and `v≡0 mod X^m`, `Xv≡1 mod r`. All polynomial constants use corner identity `e`.

For this source, the exact finite-group certificate gives

```
m_T(X)=X⁴+X²=X²(X+1)²,
T⁴=T²,       h=T²,       v=T³,       f=e+T².
```

Thus `(Tf)²=0` and `Tf≠0`. The source is fully explicit; no unspecified stable exponent remains. The literal matrix supports and coefficient checks are in [the finite certificate](kaplansky-finite-drazin-seed-2026-09-08.json), reproduced by [the finite-group script](../../experiments/kaplansky_finite_drazin_seed.py).

Since `ev(T)=p`, evaluation gives `ev(h)=ev(v)=p` and `ev(f)=0`. Define

```
X=av,        M_0=avβ,        P=e+avα.
```

Then

```
hαX=h,       P²=P,       hαP=0,
β+αM_0=fβ,  Paf=af,      ev(P)=p_01.
```

Every solution of the first half-equation is

```
M=M_0+P Y q,             Y∈S.
```

For proof, `P=e-Xhα` projects onto the kernel of `hα`: if `hαZ=0`, then `PZ=Z`. This is a complete homogeneous parameterization, not an assumption about available kernel directions.

The subgroup generated by the original finite `S_3` and `u` is locally finite by cyclic: nonnegative `u`-conjugates of the local `S_3` lie in equal-depth finite matrix groups, and any finite collection of integer conjugates shifts to nonnegative indices. Thus freezing the finite/amenable particular solution `M_0` cannot make the second equation globally solvable: conditional expectation would bring `K` back into that amenable group algebra, contradicting its direct finiteness. Any successful homogeneous term must change the relevant projective comparison through essential full-group relations.

## 5. The homogeneous term has an exact projective job

Because `Tf` is nilpotent, define the finite geometric inverse on the `f` corner and put

```
w=f+Tf=e+T+T²+T³,      j=wβ.
```

Then `w(e+T)f=f`, `j∈fSq`, and

```
j c f=f.
```

For an arbitrary element `Z∈PSf`, choose the upper shear

```
M=M_0+P(af+Z)j.
```

It satisfies the first half-equation and has the exact controlled column

```
a_M f=Z.
```

Indeed `M_0cf=av(e+T)f=0`, `Paf=af`, `PZ=Z`, and `jcf=f`.

The second half-equation is now `KZ=cf`. It is equivalent to a split embedding of the explicit projective module `fS` into `PS`:

```
LZ=f,       Z∈PSf,       L∈fSP.
```

If `KZ=cf`, take `L=jKP`; if `LZ=f`, take `K=cfL`. The latter automatically lies in `qSe`.

Such an embedding would already be strict: `ev(f)=0`, `ev(P)=p_01≠0`, so `ZL=P` is impossible. The scalar witness follows from the explicitly derived shear construction in Section 2. The comparison also produces the nonzero defect idempotent `P+ZL` directly.

Thus the reduction does not solve the comparison. Its gain is to identify the exact finite source and target projectors and to show that arbitrary mixed upper coefficients can install any proposed comparison map between them. A successful design must address this map, rather than merely insert actors into the support.

## 6. Trace control and practical finite algebra

The idempotents `f` and `P` each have finite subgroup support. The idempotent `avα` is equivalent to `h`, via `av` and `hα`; consequently the lifted 2-adic trace satisfies

```
τ(P)=τ(e)−τ(h)=τ(f).
```

Both `P` and `f` are nonzero. In particular `P` is nonzero by evaluation, so its finite-group lifted trace is a positive rational number, and equality forces `f≠0`.

Any successful split embedding creates the nonzero idempotent `D=P+ZL` with `τ(D)=0`. This is why finite-group routing alone cannot finish the construction: a nonzero idempotent supported in a finite subgroup has positive rational lifted trace. The fact that the square-zero feedback lies in the off-diagonal subspace `fSh` does not force the final reverse defect into a finite subgroup algebra. A finite idempotent corner contains words from the whole group.

There is a small exact control for constructing `h,v`. Conjugating by `u` puts

```
uTu⁻¹=E_child E_parent E_child
```

on leaves `(000,001,010,011)`, where the underlying order-three matrices are

```
child=diag(G,I_2),       parent=G⊗I_2.
```

Both commute with `J=diag(G,G)`, which equips the four-dimensional binary space with an `F_4` structure. Their subgroup therefore lies in `GL_2(F_4)`, of order 180. The exact calculation confirms that its order is 180 and obtains the displayed minimal polynomial by finite-group Krylov elimination, followed by polynomial CRT. No atlas support ball is involved.

Put `S_0=aα=eUeU⁻¹e`. Then `P=e+S_0⁴`. Both `P` and `f_+=UfU⁻¹` lie in the same finite group `K=〈g,ugu⁻¹〉`. In the four-leaf matrices they are

```
f_+=E_child+(E_child E_parent E_child)²,
P=E_parent+(E_parent E_child E_parent)⁴.
```

The exact certificate gives:

| Element | Support size | Rank in the regular 180-dimensional module |
| --- | ---: | ---: |
| `E_child` | 2 | 120 |
| `T` after conjugation | 8 | — |
| `h` after conjugation | 28 | 80 |
| `v` after conjugation | 76 | — |
| `f_+` | 30 | 40 |
| `P` | 70 | 40 |

Consequently `τ(f)=τ(f_+)=τ(P)=40/180=2/9`. On the natural four-dimensional representation, `f_+` acts as zero and `P` acts as `diag(0,0,1,1)`. They are thus not isomorphic projectives over this finite group algebra despite their equal regular ranks. The exact comparison in Section 5 can equivalently use `f_+` after conjugating its source by `U`.

Prediction: the primitive split is conclusively impossible; the stable-image split solves the first half exactly. Keeping all comparison coefficients in the amenable source subgroup remains impossible. The unresolved mechanism is an explicit split embedding `fS→PS` using essential full-group relations, despite equal positive lifted trace and unequal evaluated support. Neither full actor support nor a root square-zero factor establishes such an embedding.

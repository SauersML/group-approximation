## A9. Seed 8 (F_2). VERIFIED as a length-saving choice; no change recommended
F_2 is not forced by the truth. It saves real text:
- (i) Z(G) = {1}. Over F_q, SL_n(F_q) ≤ G gives central scalars μ_n(F_q)·I, so the theorem must pass to G/Z.
- (ii) GL_d(F_2) = SL_d(F_2) = PSL_d(F_2). Over F_q, H_W is SL_d(F_q), and the argument needs perfectness modulo the centre.
- (iii) κ_0 ≠ I is enough. Over F_q, κ may take only scalar values. Then g' = λI with λ ∈ LC(X)^×, and an extra commutator [g', e_12(r)] = e_12(λrλ^{-1} − r) is needed for a suitable r. One must also check that g' is not central: if ghg^{-1} = c·h, then (ch − I)² = 0 forces c = 1.
- (iv) No signs: e_ij(−r) = e_ij(r), so permutation matrices are unsigned.

Verdict: keep F_2 and add nothing. The note's questions need one group per X. If the user wants F_q, sk-coefficients owns that text (+2 to 3 lines).

## A12. NEW: a uniform encoding of Turing degrees
The case split at l.257-260 exists because interleaving a computable set with 1's can produce a rational. For S = ∅ it gives 0.010101…₂ = 1/3.

Before (l.257-260):
```
Every Turing degree has an irrational representative: use $\sqrt2-1$
for the computable degree, and interleave the characteristic sequence
of a noncomputable set with $1$'s in a binary expansion for any other
degree.
```
After:
```
Every Turing degree has an irrational representative: for
$S\subseteq\{1,2,\dots\}$ the continued fraction
$[0;1+\chi_S(1),1+\chi_S(2),\dots]$ is irrational and Turing equivalent to $S$.
```
Check:
- An infinite continued fraction is irrational, and α ∈ (0,1).
- The partial quotients of an irrational α are computable from α, since the floor function is computable away from integers, and α is computable from its partial quotients. So α ≡_T S.

Side fact, not needed in the note: bounded partial quotients make the Sturmian subshift linearly recurrent (known; attribute to Durand only after checking the source).
Length: −1. Reader: one rule for every degree, with no special case.

- F9, Sturmian subshifts as the family realizing every degree. Natural, because the language is Turing equivalent to the slope. Alternatives belong to sk-word-problem.

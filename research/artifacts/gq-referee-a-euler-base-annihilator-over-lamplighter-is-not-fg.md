**Verdict: PASS** for items 1–3. There is one required wording fix (W1). It concerns the *Reading* paragraph, not the

## The check the author asked for: `ε'` kills `I`
- **The generators lie in `ker ε`.** Each `g_i` lies in `J`, and `J = ⊕_m x^m ker ε` is a direct-sum decomposition
  inside `Z[H] = ⊕_m x^m Z[B]`. So every slot component `c_(i,m)` of `g_i` lies in `ker ε`.
- **The generators involve finitely many lamps.** There are `n` generators, each with finitely many nonzero slots.
  Each `c_(i,m)` is a Laurent polynomial in finitely many `β_k`, so one `R` bounds them all.
- **The multipliers do not matter.** In `x^a b g_i = Σ_m x^(a+m) σ^(-m)(b) c_(i,m)`, the shift `σ^(-m)` acts only on
  the multiplier `b`. The generator `c_(i,m)` is untouched. So `I` is the ideal of the commutative ring `Z[B]`
  generated by the finitely many `c_(i,m)`. Taking `a = 0`, `b = 1` puts each `c_(i,m)` in `I`.
- **`ε'` is a ring map.** `B` is free abelian on the `β_k`: this is the independence argument of
  `z-localized-embeds-in-fg-rf-soluble-group`, via distinct linear factors `1 + l(j−k)` in `j`. So `Z[B]` is the
  Laurent ring on independent variables. `ε'` sends each variable to a unit: `T` in `Z_(l)[T^±]`, and `1 − lk`,
  which is prime to `l` and hence a unit of `Z_(l)`.
- **`ε'` kills `I`.** On Laurent polynomials in `β_k` with `|k| ≤ R`, `ε'` equals `ε` followed by `Z_(l) ⊂ Z_(l)[T^±]`.
  So `ε'(c_(i,m)) = ε(c_(i,m)) = 0`, and `ε'(I) = 0`.
- **The witness.** `ε'(β_(R+1) − (1 − l(R+1))) = T − (1 − l(R+1)) ≠ 0`, and the witness lies in `ker ε`. Its slot-0
  copy lies in `J` but not in `Σ Z[H] g_i`. ✓

## Other checks
- **Item 1: conjugates.** `x^(-k) r x^k = x^(-(k-1)) β x^(k-1) − β_k − l = β_(k−1) − β_k − l`.
  - Telescoping: `Σ_(j=1..k)(β_(j−1) − β_j − l) = β_0 − β_k − kl`. So
    `(β_0 − 1) − (β_0 − β_k − kl) = β_k − (1 − lk)`. ✓
  - `r` kills `M`: `β_(−1) f_j = (1 + l(j+1)) f_j = (β + l) f_j`, so the two-sided ideal `(r)` acts as 0. ✓
- **Item 1: the two-sided ideal is a left ideal of the shifts.** `r ∈ Z[B]` commutes with `Z[B]`, so
  `r x^k b = σ^k(b) r x^k`. Hence `(r) = Σ_k Z[H] r x^k`, and `J = Z[H](β−1) + Σ_(k∈Z) Z[H] r x^k`. This is what
  makes "do not imply the others" in item 2 exact: all shifts cut out `M`; no finite set of shifts does.
- **Item 2: computing `J`.** `b f_0 = ε(b) f_0` for Laurent `b`, because `M` is a `Z_(l)`-module and `β_k^(−1)` acts on
  `f_0` by `(1−lk)^(−1)`. So `z f_0 = Σ ε(b_m) f_(−m)` and `J = ⊕ x^m ker ε`. ✓
- **Item 2: Schanuel.** A cyclic `Z[H]/L` is finitely presented only if `L` is finitely generated. `M = Z[H]/J` as a
  module, since `M = Z[H] f_0` (see N3). The finite-shift ideal `L` is finitely generated and lies in `J`. Since `J` is
  not finitely generated, `L ≠ J`. ✓
- **Item 3.** `Q = ⊔ q_α H` gives `Z[Q] = ⊕ q_α Z[H]` as right modules. So `Z[Q] ⊗ M = Z[Q]/Z[Q]J`, and
  `Z[Q]J = ⊕ q_α J`.
  - The `q_0`-component of `Σ z_i g_i` lies in `J' = Σ_(i,α) Z[H] j_(i,α) ⊆ J`.
  - `q_0 = 1` puts `J` itself inside `Z[Q]J`, so `J ⊆ J'`, and `J` would be finitely generated. ✓
  - `M → Z[Q] ⊗ M` is injective (the `q_0` summand), so `G_l` embeds in the induced semidirect product.
- **The Baumslag instance, checked without citation.** Take `G = <a, s, t | [s,t], [a, a^t], a^s = a a^t>`, with
  `u^g = g^(−1)ug`.
  - *Pairwise commuting.* Suppose `a` commutes with `a^(t^j)` for `1 ≤ j ≤ n`. Conjugate `[a, a^(t^n)] = 1` by `s`,
    using `(a^(t^j))^s = a^(t^j) a^(t^(j+1))`; this gives `[a a^t, a^(t^n) a^(t^(n+1))] = 1`.
    - `a^t` commutes with `a`, `a^(t^n)` and `a^(t^(n+1))` (distances 1, n−1 and n). Cancel it.
    - Then `a` commutes with `a^(t^n)`, so cancel that too. This leaves `[a, a^(t^(n+1))] = 1`.
    - So all `a^(t^i)` commute pairwise.
  - *`⟨a,t⟩ ≅ Z≀Z`.* `G → Z[x^±, (1+x)^(−1)] ⋊ Z^2`, with `a ↦ 1`, `t ↦ ·x` and `s ↦ ·(1+x)`, respects the three
    relators. On `⟨a,t⟩` it maps onto `Z[x^±] ⋊ Z = Z≀Z`. Together with the commuting step, the canonical map
    `Z≀Z → ⟨a,t⟩` composes to the identity, so it is an isomorphism.
  - *Metabelian.* Put `A = ⟨a^(t^j)⟩`. Then `A^s ⊆ A`, so `A ⊆ A^(s^(−1)) ⊆ A^(s^(−2)) ⊆ …`. The union is abelian,
    normal and contains `a`, and the quotient is `Z^2`.

  So the example needs no citation, which agrees with "no unread citation".

## Required wording fix
- **W1 (Reading, "What is not excluded").** "A finitely presented host must use a base `N` that is a proper quotient
  of the induced module" is not proved, and it is false as a statement about all hosts.
  - A host need not be an extension with abelian base. A finitely presented simple host, the root's target, has no
    base at all.
  - For a split host `N ⋊ Q` with abelian `N ⊇ M`, only the `Z[Q]`-span of `M` in `N` is a quotient of the induced
    module. `N` itself may be larger. So the dichotomy is: that span is a proper quotient, *or* `N` properly contains
    it.
  - Suggested text: "Item 3 excludes the split host `(Z[Q] ⊗ M) ⋊ Q`. In a split host `N ⋊ Q` with abelian base, the
    `Z[Q]`-span of `M` is a quotient of the induced module, and `N` must be finitely presented (R1). So either the span
    is a proper quotient, or `N` is strictly larger than the span. Non-split and non-metabelian hosts are not
    addressed."

## Optional strengthening
- **R1.** *For every group `Q ⊇ H`, `(Z[Q] ⊗_(Z[H]) M) ⋊ Q` is not finitely presented.* This makes "no top repairs this
  in the freest way" a theorem. Item 3 alone speaks of the module, not the group.
  - *Proof.* Suppose `G = N ⋊ Q` is finitely presented with `N` abelian. Then `Q` is a retract of `G`, so it is
    finitely presented.
  - Crowell's sequence `0 → N → Z[Q] ⊗_(Z[G]) I_G → I_Q → 0` is exact: tensor `0 → I_G → Z[G] → Z → 0` with `Z[Q]`,
    and use `Tor_1^G(Z[Q], Z) = H_1(N) = N`.
  - The splitting `s` gives the `Z[Q]`-linear section `q − 1 ↦ 1 ⊗ (s(q) − 1)`. So `N` is a direct summand of
    `Z[Q] ⊗ I_G`.
  - `Z[Q] ⊗ I_G` is finitely presented through the Fox Jacobian of a finite presentation of `G`. `I_Q` is finitely
    generated. So `N` is finitely presented. Apply item 3.

## Nits
- **N1 (item 1, slot injectivity).** "Every lamp acts on the class of 1 by the scalar `1 − lk`" does not directly give
  `b[1] = ε(b)[1]` for Laurent `b`, since `β_k^(−1)[1]` is not an integer multiple of `[1]`. Add one line: write
  `b = w^(−1)p`, with `w` a monomial and `p` a polynomial. Then `p[1] = ε(p)[1]`, and `ε(b) = 0` gives `ε(p) = 0`, so
  `b[1] = 0`. Alternatively, `ker ε` is the ideal generated by the `β_k − (1 − lk)`, the kernel of evaluation on a
  Laurent ring.
- **N2 (item 1, "Step 1").** Step 1 of `resolvent-ring-has-path-normal-form-proof` identifies the ring presented by
  `u, x, x', B` with `A[x^±; σ]`. It does not treat `Z[H]/(r)`. The direct argument is short:
  - `Z[H] = Z[B][x^±; σ]`, and `(r) = ⊕_m x^m I_r` with `I_r = (β_(k−1) − β_k − l)_k`, a `σ`-stable ideal.
  - `Z[B]/I_r ≅ A` by `β_k ↦ u + 1 − lk`. This inverts every `u + 1 + kl`, with `σ(u) = u + l`, matching that
    node's `A`.
  - Say "as in Step 1", or give these two lines.
- **N3 (item 1, onto).** "That class generates … hence onto" needs `Z[H] f_0 = M`, that is, `ε(Z[B]) = Z_(l)`. This is
  §2 of `z-localized-embeds-in-fg-rf-soluble-group-proof`, which uses the fact that every integer `≡ 1 (mod l)` is a
  `1 − lk`. Cite it there.

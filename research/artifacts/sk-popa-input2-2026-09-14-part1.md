## 1. Setup
- `M` a II_1 factor with separable predual and trace `τ`. `(y'_k)_{k≥1}` a sequence of unitaries in which every member of a generating sequence of `M` recurs infinitely often.
- Integers `r_i ≥ 3` (`i ≥ 0`) with `Σ_i 1/r_i < ∞`, e.g. `r_i = 2^{i+3}`.
- A unital copy of the hyperfinite factor `R ≅ (⊗_{i≥0}(M_{r_i}, tr))''` inside `M` (every II_1 factor contains one). `N_i ⊆ R` is the `i`-th tensor factor, and `p_i ∈ N_i` a rank-one diagonal projection, so `τ(p_i) = 1/r_i`. Put `M_{D_i} := ⊗_{i'<i}N_{i'} ≅ M_{D_i}(C)`, `D_i = ∏_{i'<i}r_{i'}`.
- For `k ≥ 1`, `m ≥ k`: `R_{k,m} := ∏_{k≤i'<m}(1−p_{i'})·p_m` ("the first tooth at or after `k` is `m`") and `g_k := ∏_{i'≥k}(1−p_{i'})` (strong limit). These are orthogonal projections in `R` with `g_k + Σ_{m≥k}R_{k,m} = 1`, and `τ(1−g_k) ≤ Σ_{i'≥k}1/r_{i'} → 0`.

## 2. The algebra
- **Approximants.** `z_k := u_k + Σ_{m≥k} c_k^{(m)}`, where `u_k` is a unitary of `g_kMg_k` and each `c_k^{(m)}` is a unitary of `R_{k,m}(⊗_{i'≤m}N_{i'})R_{k,m}`. So `z_k` is a unitary in `M`. The blocks are chosen in §4.
- **Stages.** `A_i := C*(N_0, …, N_{i−1}, z_1, …, z_i)` for `i ≥ 1`, and `A := closure ⋃_iA_i`.
- **Teeth.** `e_i := p_i ∈ N_i ⊆ A_{i+1}`.

**Lemma 1 (commutation).** `z_k` commutes with `p_j` for every `j ≥ k`.
*Proof.* `p_jg_k = 0`, so `p_ju_k = 0 = u_kp_j`. If `m > j`, then `R_{k,m} ≤ 1−p_j`, so `p_jc_k^{(m)} = 0 = c_k^{(m)}p_j`. If `m = j`, then `R_{k,m} ≤ p_j`, so `p_jc_k^{(m)} = c_k^{(m)} = c_k^{(m)}p_j`. If `m < j`, then `c_k^{(m)} ∈ ⊗_{i'≤m}N_{i'}` commutes with `p_j ∈ N_j`. ∎

**Lemma 2 (C1).** `e_j` commutes with `A_j`, and `e_jA_je_j = (⊗_{i'<j}N_{i'})p_j ≅ M_{D_j}(C)`.
*Proof.*
- `p_j` commutes with `N_{i'}` (`i' ≠ j`) and, by Lemma 1, with `z_k` for `k ≤ j`.
- For `k ≤ j`: `z_kp_j = Σ_{m=k}^{j}c_k^{(m)}p_j`, since `u_kp_j = 0` and the terms with `m > j` vanish.
  - For `m < j`, `c_k^{(m)}p_j` lies in `(⊗_{i'≤m}N_{i'})p_j ⊆ (⊗_{i'<j}N_{i'})p_j`, because `p_j` is minimal in `N_j`.
  - For `m = j`, `c_k^{(j)} = p_jc_k^{(j)}p_j ∈ p_j(⊗_{i'≤j}N_{i'})p_j = (⊗_{i'<j}N_{i'})p_j`.
- The generators `N_{i'}` (`i' < j`) compress to `N_{i'}p_j`. So `e_jA_je_j ⊆ (⊗_{i'<j}N_{i'})p_j`, and equality holds because `N_0, …, N_{j−1} ⊆ A_j`. ∎

**Lemma 3 (C3).** Each `e_i` is full in `A`: with matrix units `f_{l1}` of `N_i` and `f_{11} = p_i`, `Σ_l f_{l1}p_if_{l1}^* = 1`, and `f_{l1} ∈ A_{i+1}`. ∎

**Lemma 4 (weak density).** Choose `u_k` as the unitary part of the polar decomposition of `x_k = g_ky'_kg_k` in the finite factor `g_kMg_k`.
- **Bound on `u_k`.** `‖g_k − x_k^*x_k‖_1 = ‖(1−g_k)y'_kg_k‖_2² ≤ τ(1−g_k)`. Since `0 ≤ |x_k| ≤ g_k`, `‖u_k − x_k‖_2 = ‖g_k − |x_k|‖_2 ≤ τ(g_k − |x_k|²)^{1/2} ≤ τ(1−g_k)^{1/2}`.
- **Bound on `z_k`.** `z_k − y'_k = (u_k − x_k) − (1−g_k)y'_kg_k + (z_k − y'_k)(1−g_k)`, so `‖z_k − y'_k‖_2 ≤ 4τ(1−g_k)^{1/2} → 0`.
- **Conclusion.** Each generator of `M` is a strong limit of elements of `A` of norm 1, so `A'' = M`. ∎

## 3. The universal algebra W_i and separation (C2)
For `1 ≤ k ≤ i` put `b_k := ∏_{k≤i'<i}(1−p_{i'}) ∈ M_{D_i}` (`b_i = 1`).
- **Splitting `z_k` in `A_i`.** By Lemma 1, `z_k` commutes with `b_k`. Write `z_k = f_k + v_k` with `f_k := z_k(1−b_k) = Σ_{k≤m<i}c_k^{(m)} ∈ M_{D_i}` and `v_k := z_kb_k = u_k + Σ_{m≥i}c_k^{(m)}`, a unitary on the corner `b_k`. So `A_i = C*(M_{D_i}, v_1, …, v_i)`.
- **Definition.** `W_i` is the universal unital C*-algebra generated by a unital copy of `M_{D_i}(C)` and elements `v_1, …, v_i` with `v_k^*v_k = v_kv_k^* = b_k`. Let `q: W_i → A_i` be the canonical surjection.

**Lemma 5.** `W_i` is separable and RFD.
*Proof.*
- `W_i` is the iterated full amalgamated free product `W^{(0)} = M_{D_i}` and `W^{(k)} = W^{(k−1)} *_{C*(1,b_k)} (C(T) ⊕ C)`. Here `(1,0) ↦ b_k` and `v_k = (id_T, 0)`; when `b_k = 1` the amalgam is `C` and the factor is `C(T)`.
- **Inductive step.** Suppose `W^{(k−1)}` has a separating sequence `σ_n` of finite-dimensional representations. Replacing `σ_n` by `σ_n^{⊕n}` makes `P_n := σ_n(b_k)` have rank `≥ n`.
  - `q_1 = (σ_n)_n` embeds `W^{(k−1)}` unitally in `∏_nM_{d_n}`.
  - `q_2(f,λ) = (f(U_n) + λ(1−P_n))_n` embeds `C(T) ⊕ C` unitally, with `U_n` unitaries on `P_n` whose spectra contain the first `n` points of a dense sequence of `T`.
  - Both send `b_k` to `(P_n)_n`.
- By `li-shen-amalgamated-rfd-criterion`, `W^{(k)}` is RFD. For `b_k = 1`, use `exel-loring-free-products-of-rfd-algebras-are-rfd`. ∎

**Finite-dimensional representations.** Every finite-dimensional representation `ρ` of `W_i` restricts to `M_{D_i}` as `1_{D_i} ⊗ 1_t` (`M_{D_i}` is simple and unital). So `ρ ≅` (`M_{D_i} ⊗ 1` on `C^{D_i} ⊗ C^t`, `v_k ↦ V_k`), with `V_k` a unitary on `b_kC^{D_i} ⊗ C^t`. For each `i`, fix a separating sequence `(ρ^{(i)}_n)_n` with multiplicities `t^{(i)}_n`.

## 4. Choosing the blocks (input 2, scheduled)
- **Scheduling.** Since `∏_{i≤i'<m}(r_{i'}−1) → ∞` as `m → ∞`, there is a map `m ↦ π(m) = (i,n)` from `{1,2,…}` onto `{(i,n) : i,n ≥ 1}` with `i ≤ m` and `∏_{i≤i'<m}(r_{i'}−1) ≥ t^{(i)}_n`. Note that `W_i` does not depend on the blocks, so the families `ρ^{(i)}_n` are fixed in advance.
- **Block definition.** At step `m`, with `π(m) = (i,n)`, write `E_m := ⊗_{i≤i'<m}(1−p_{i'})C^{r_{i'}}` of dimension `∏(r_{i'}−1) ≥ t := t^{(i)}_n`, and fix an isometry `C^t ↪ E_m`.
  - For `k ≤ i`, `R_{k,m} = b_k ⊗ ∏_{i≤i'<m}(1−p_{i'}) ⊗ p_m`. In `⊗_{i'≤m}N_{i'}` its range is `b_kC^{D_i} ⊗ E_m ⊗ p_mC^{r_m}`, and `p_mC^{r_m}` is one-dimensional.
  - Put `c_k^{(m)} := (V_k ⊕ 1) ⊗ 1` on `b_kC^{D_i} ⊗ (C^t ⊕ (E_m ⊖ C^t))`, where `V_k = ρ^{(i)}_n(v_k)`.
  - For `i < k ≤ m`, put `c_k^{(m)} := R_{k,m}`.
- **Unitarity.** Each `c_k^{(m)}` is a unitary of `R_{k,m}(⊗_{i'≤m}N_{i'})R_{k,m}`, as §2 requires.

**Lemma 6 (C2).** For `x ∈ A_i` with `x ≠ 0`, some `j ≥ i` has `e_jxe_j ≠ 0`. Moreover `q` is injective, so `A_i ≅ W_i`.
*Proof.*
- **The projection `Q`.** Fix `n` and the step `m` with `π(m) = (i,n)`; then `m ≥ i`. Put `Q := ∏_{i≤i'<m}(1−p_{i'})·p_m ≤ e_m`.
  - `Q` commutes with `A_i` by Lemma 1 and the tensor structure.
  - `v_kQ = c_k^{(m)}Q` for `k ≤ i`: on `b_kQ` there is no tooth in `[k,m)` and a tooth at `m`, so `b_kQ ≤ R_{k,m}`.
- **A copy of `ρ^{(i)}_n`.** Write `M = (⊗_{i'≤m}N_{i'}) ⊗ P_m`, with `P_m` the relative commutant. `QA_iQ` acts on `QC^{D_{m+1}} ⊗ L²(P_m)` as `(C^{D_i} ⊗ E_m) ⊗ L²(P_m)`, with `M_{D_i} ⊗ 1` and `v_k ↦ (V_k ⊕ 1) ⊗ 1`. The subspace `C^{D_i} ⊗ C^t ⊗ ξ` is invariant and carries `ρ^{(i)}_n`. So `‖ρ^{(i)}_n(w)‖ ≤ ‖q(w)e_m‖` for every `w ∈ W_i`.
- **Norms.** For `w ∈ W_i`: `‖w‖ = sup_n‖ρ^{(i)}_n(w)‖ ≤ sup_{m≥i}‖q(w)e_m‖ ≤ ‖q(w)‖ ≤ ‖w‖`. So `q` is isometric, and for `x = q(w) ≠ 0` some `m ≥ i` has `e_mxe_m = xe_m ≠ 0`. ∎

## 5. Theorem
**Theorem P.** Every II_1 factor `M` with separable predual contains a weakly dense unital C*-subalgebra `A = closure ⋃A_i` with a comb `(e_i)`. So `A` is a Popa algebra (Brown–Dykema): unital, simple, quasidiagonal, with local quantization.
*Proof.* Lemmas 2, 3 and 6 give (C1), (C3) and (C2), and Lemma 4 gives weak density. Then apply `finite-dimensional-combs-generate-popa-algebras`. ∎

**Corollary.** The Popa clause of Brown 2001 Question 3 ("Can a free group factor or a II$_1$ factor with property T contain a weakly dense, QD C$^*$-subalgebra? How about a Popa algebra?") has a positive answer for every separable II_1 factor. This includes `L(SL_3(Z))`, `L(G_X)`, and the free group factors, which Brown–Dykema did for `L(F_s)`, `1 < s < ∞`.

## 6. Where each hypothesis enters, and model tests
- **`Σ1/r_i < ∞`:** only in Lemma 4 (`τ(1−g_k) → 0`). With `Σ1/r_i = ∞`, `g_k = 0` and the approximants are pure blocks in `R`, so `A'' ⊆ R`.
- **`r_i ≥ 2`:** fullness (Lemma 3). `r_i ≥ 3` is only for comfort, so that `E_m` grows.
- **II_1 factor:** the unital copy of `R`, the finite polar decomposition in `g_kMg_k`, and `M = (⊗_{i'≤m}N) ⊗ P_m`.
- **Separable predual:** a countable generating sequence.
- **Model test `M = R`:** the construction gives a Popa algebra, consistent with the UHF example in the comb node.
- **Firewall G** (sk-popa-lgx §2, Gamma from matrix units on corners of trace → 1): not triggered. The teeth have `τ(e_j) = 1/r_j → 0`, and no matrix-unit system commutes with `A_i` on a large corner (`z_k` is free on `g_k`).
- **Kazhdan constraints.**
  - `kazhdan-generators-admit-no-norm-popa-corners`: consistent, since `‖z_k − y'_k‖` is not small in norm (the blocks differ).
  - `orthogonal-popa-corners-for-kazhdan-approximants-small-trace`: consistent. The teeth `e_j` are not orthogonal, and `τ(e_j) = 1/r_j ≤ C·Σ_{i'≥k}1/r_{i'}`, the square of the 2-norm defect up to constants.
- **Separation needs the blocks.** If all `c_k^{(m)}` were identities, `x = z_1 − 1` would vanish on every tooth while being nonzero on `g_1`. This is why §4 schedules norming families.

# Is E_m(R_L) finitely presented? (lane gq-steinberg-q, 2026-09-17)

**Short answer: undecided.** What is proved, what is conditional, and why the question matters.

`R_L` is the Leavitt resolvent ring of `leavitt-resolvent-ring-is-fp-and-contains-q`. `St_m(R_L)` is finitely
presented for `m >= 4` (Krstić–McCool) and contains every `GL_n(Q)` (for `m >= 10`,
`leavitt-pair-centralizers-embed-e-n-in-st-3n-plus-1`, under review).

## 1. Proved

- **(P1)** `E_m(R_L)` is finitely presented iff `K_2(m,R_L) = ker(St_m(R_L) -> E_m(R_L))` is finitely normally
  generated in `St_m(R_L)`, for `m >= 4`. This is the standard fact about quotients of finitely presented groups.
- **(P2)** `Q^x · I_m ⊆ Z(E_m(R_L))` for `m >= 3` (`leavitt-centralizer-units-are-elementary-in-rank-three`).
  This central subgroup is not finitely generated.
- **(P3), the scalar obstruction.** `E_m(R_L)` and `E_m(R_L)/(Q^x I_m)` are not both finitely presented.
- **(P4)** The Tate symbols do *not* obstruct. For every `N >= 3`, the index-shifted image of `K_2(N,Q)` in
  `K_2(6N+1, R_L)` is trivial (`leavitt-pairs-embed-sl-n-q-in-steinberg-groups`).
  - The same swindle kills every symbol `{u, q}` with `u` in the centralizer of a Leavitt pair.
  - So an obstruction to finite presentation must come from units that do not commute with the pair.

The coordinator's reading ("the scalar obstruction suggests no") needs one correction. The scalar obstruction
(P3) does not decide `E_m(R_L)`. It says that at most one of `E_m(R_L)` and its central quotient is finitely
presented. For the simple-host target G, it is the central quotient that one wants finitely presented. If G's
Leavitt-resolvent route (`gl-n-q-bh-via-leavitt-resolvent-units`) is right that the relevant simple quotient
is finitely presented, then (P3) forces the corresponding non-quotiented group to be *not* finitely
presented.

## 2. Conditional non-finite-presentation of E_m(R_L)

- **(C1)** If `E_m(R_L)` is finitely presented, then `H_2(E_m(R_L); Z)` is finitely generated.
- **(C2)** The stabilization `H_2(E_m(R_L)) -> H_2(E(R_L)) = K_2(R_L)` hits every symbol `{v, q}` with
  `v ∈ R_L^x` and `q ∈ Q^x`:
  - `diag(v, v^(-1), 1, …)` and `diag(q, 1, q^(-1), …)` are commuting elements of `E_m(R_L)`;
  - the torus class they span maps to `{v,q}^(±1)` (Milnor, *Introduction to algebraic K-theory*, §§8–9: the
    element `⟨a,b⟩` for commuting `a, b ∈ E(R)`; the noncommutative case with `q` central is not re-derived
    here).
- **(C3)** Hence: **if the subgroup `{N+1, Q^x} ⊆ K_2(R_L)` is not finitely generated, then `E_m(R_L)` is not
  finitely presented for any `m >= 3`.** Here `N+1` is the resolvent unit. It does not commute with `s_1`,
  since `N s_1 = s_1 (N+1)`.

## 3. Heuristic K-theory of R_L (not a proof)

`R_L = O_ψ` is the Leavitt–Nekrashevych ring over `B = Q[N][(N+c)^(-1) : c >= 1]`, a regular PID, with
`ψ(f) = diag(f(N+1), f(0))`, so `ψ_* = σ_* + ev_0*`.

A Pimsner–Voiculescu type sequence `K_i(B) --1-ψ_*--> K_i(B) -> K_i(R_L) -> K_(i-1)(B)` is **not** imported for
this ring. Assuming it:
- **K_0.** `K_0(B) = Z`, and `1 - ψ_* = -1`. So `K_0(R_L) = 0`, consistent with `R_L ≅ R_L^2`.
- **K_1.** `K_1(B) = Q^x ⊕ ⊕_(c>=1) Z[N+c]`, and
  `(1-ψ_*)[N+c] = [N+c] - [N+c+1] - [c]` and `(1-ψ_*)[q] = -[q]`.
  - The cokernel is `Z`, generated by `[N+1]`. The kernel is `0`.
  - So `K_1(R_L) ≅ Z`, generated by the resolvent unit.
- **K_2.** `K_2(B) = K_2(Q) ⊕ ⊕_c {N+c, Q^x}`, from the localization sequence and tame symbols.
  - `1 - ψ_*` kills the `K_2(Q)` summand and identifies all `{N+c, q}`.
  - So `K_2(R_L) ≅ Q^x`, via `q -> {N+1, q}`. This is not finitely generated.

If this heuristic is right, (C3) applies and **`E_m(R_L)` is not finitely presented for every `m >= 3`**. Then
`St_m(R_L)` is the finitely presented group that remembers `SL_m(Q)`, and `E_m(R_L)` is too large a quotient.

The heuristic also predicts `K_1(R_L) ≅ Z`, so `GL_m(R_L) ≠ E_m(R_L)`. The class of `N+1` survives. Note that
`R_L^x` is the unit group used by the G route, via `GL_m(R_L) ≅ R_L^x`.

## 4. What would settle it

- **Import the sequence.** Find or prove a Pimsner–Voiculescu / Cuntz–Pimsner sequence for Leavitt–Nekrashevych
  rings `O_ψ` over regular coefficient rings. That would make §3 a theorem.
- **Detect the symbols directly.** Construct a map `K_2(R_L) -> Q^x` detecting `{N+1, q}`, for example a
  "residue along the resolvent" map.
- **Or refute.** Show `{N+1, q} = 1` by a swindle adapted to units that shift under `s_1`.

**Architecture.** A *level-factoring model* is `σ = lim_ω π_k ∘ τ_k`, where:

It is *natural* if `m_k = 3N_k` and `τ_k` follows the natural assignment on levels `< N_k`.

Every rank model factors this way with `π_k` the identity, so all content lies in the hypotheses.

## 1. Transvection displacement forces exact local embeddings

**Lemma 1 (projective displacement).** Let `F` have characteristic `p`, `H` be finite, and `P` be a
projective `F[H]`-module of dimension `n`. Let `g ∈ H` have nontrivial `p`-part `g_p`. Then
`rk(g − 1 on P) >= n(1 − 1/|g_p|) >= n/2`.

*Proof.*
1. `Fix(g) ⊆ Fix(g_p)`, because `g_p` is a power of `g`.
2. `P` restricted to `⟨g_p⟩` is projective over a local group algebra, hence free, so
   `dim Fix(g_p) = n/|g_p|`.

QED

**Lemma 2 (amplification).** For any representation `π` of a group `H` and `z, u ∈ H`,
`rk(π([z,u]) − 1) <= 2 rk(π(z) − 1)`.

*Proof.* `AB − 1 = (A−1)B + (B−1)` gives subadditivity. Also `[z,u] = z · u z^(−1) u^(−1)`, and
`u z^(−1) u^(−1) − 1 = u z^(−1)(1 − z)u^(−1)` has the rank of `z − 1`. QED

**Lemma 3 (two commutators reach a transvection).** Let `m >= 4` and `1 != z ∈ GL_m(F_2)`. There
are transvections `u, u''` such that `[z,u]` or `[[z,u],u'']` is a transvection. So in every
representation `π`, `rk(π(z) − 1) >= rk(π(t) − 1)/4` for every transvection `t`.

*Proof.*
1. Pick `v` with `zv != v`, and `φ != 0` vanishing on `v, zv, z^(−1)v`, which `m >= 4` allows.
   `u = 1 + v⊗φ` is a transvection.
2. Put `ψ = φ∘z^(−1)`, `A = zv⊗ψ` and `B = v⊗φ`, so that `z u z^(−1) = 1 + A`.
   * `ψ(v) = 0` and `φ(zv) = 0` give `A² = B² = AB = BA = 0`.
   * So `[z,u] = (1+A)(1+B) = 1 + N` with `N = A + B` and `N² = 0`.
   * `zv, v` are independent and `φ != 0`, so `N != 0`, and `rk N ∈ {1, 2}`.
3. If `rk N = 1`, `[z,u]` is a transvection. Otherwise write `N = a⊗α + b⊗β`, with `a, b` independent
   and `α, β` independent.
   * Pick `w` with `α(w) = 1`, so `Nw != 0`. Pick `χ != 0` vanishing on `a, b, w`. Put `u'' = 1 + w⊗χ`.
   * `χ∘N = 0`, so `y = 1 + N` has `y u'' y^(−1) = 1 + yw⊗χ`.
   * `χ(w) = χ(yw) = 0`, so `[y,u''] = 1 + Nw⊗χ`, a transvection.
4. Apply Lemma 2 once or twice. All transvections are conjugate in `GL_m(F_2)`.

QED

**Theorem 4.** Let `σ = lim_ω π_k ∘ τ_k : G -> M^x` be an injective level-factoring model with
`m_k >= 4`. Suppose the transvection displacement `d_k := rk(π_k(t) − 1)/n_k` has
`lim_ω d_k > 0`. Then for every finite `F ⊆ G`, ω-almost every `τ_k` is an injective partial
homomorphism on `F`. So `G` is LEF.

*Proof.*
1. Enlarge `F` to contain `1`, `F^(−1)` and `F^(−1)F`. For `g, h ∈ F` put
   `z_k = τ_k(gh)^(−1) τ_k(g) τ_k(h)`.
2. `rk(σ_k(g)σ_k(h) − σ_k(gh)) = rk(π_k(z_k) − 1)`, which is `o(n_k)` along ω.
3. If `z_k != 1` on an ω-large set, Lemma 3 gives `rk(π_k(z_k) − 1) >= d_k n_k/4` there, a
   contradiction. So `τ_k` is multiplicative on `F` for ω-almost all `k`.
4. If `g != 1`, then `σ(g) != 1`, so `τ_k(g) != 1` for ω-almost all `k`. With multiplicativity on
   `F^(−1)F`, `τ_k(g) = τ_k(h)` forces `g = h`.

QED

**Corollary 5.**
* **(a) Natural assignment.** If `τ_k(g_0)` is a transvection for a fixed `g_0 != 1`, then
  `d_k -> rk(σ(g_0) − 1) > 0`. The natural assignment does this with `g_0 = x_13(e)`.
* **(b) Projective share.** If `π_k` has a projective summand of normalized dimension `>= α`, then
  `d_k >= α/2`, by Lemma 1 applied to the involution `t`.
* **(c) `R^x`.** `G` is finitely presented and infinite simple, so it is not residually finite, and
  not LEF. Hence no nontrivial characteristic-two rank model of `G` is level-factoring with
  `lim_ω d_k > 0`. That excludes:
  * every natural level-factoring model, whatever `π_k` is and whatever `τ_k` does on non-finitary
    elements and near level boundaries;
  * every level-factoring model with projective share bounded below (Steinberg modules,
    projective indecomposables, free modules), with no assumption on `τ_k`.
* **(d) Uniform displacement in the limit.** Lemmas 2 and 3 also hold in `M`. So in any nontrivial
  model, every nontrivial element of `F_K` has displacement `>= c_0/4`, where `c_0` is the
  transvection displacement.
* **(e) Survivors.** `d_k -> 0` along ω. Then a product of `s` transvections is displaced by
  `<= s d_k`, so each `τ_k(g)` with `g != 1` needs unboundedly many transvections. The identity
  representation has `d_k = 1/n_k`, so this is the general setting.

**Remark 6 (odd characteristic).** Over `F_q`, pick `v` with `zv ∉ F_q v`. Then Lemma 3 holds for
non-central `z`, and Theorem 4 confines relator errors to the centre. For
`G_3 = L_(F_3)(1,2)^x`, central errors survive.

**Remark 7 (arbitrary finite groups).** For projective `π_k` over any finite `H_k`, Lemma 1 alone
forces relator errors of order prime to `p`. More is false in general: in `S_3` over `F_2`, every
commutator of an element of order 3 has odd order, and `C_3` acts trivially on the projective
`F_2[S_3/C_3]`.

## 2. Exact finitary block structure forces the truncated shifts

Fix `N >= 2`. The system `Σ_N` consists of these Steinberg relations, for all `a, b < N`:
* **(Σ1)** `[X, x_23(e_ab)] = x_13(t0 e_ab)`.
* **(Σ2)** `[x_12(e_ab), Y] = x_13(e_ab s0)`.
* **(Σ3)** `[X, Y] = Z`.
* **(Σ4)** `X` commutes with `x_12(e_ab)`, `x_13(e_ab)` and `x_32(e_ab)`. `Y` commutes with
  `x_13(e_ab)` and `x_21(e_ab)`. `Z` commutes with `x_12(e_ab)` and `x_13(e_ab)`.
* **(Σ5)** `[x_21(e_ab), Z] = x_23(e_ab)`.

**Proposition 7.** Under the natural assignment, (Σ1), (Σ2), (Σ4) and (Σ5) have exactly one
solution in `GL(W_N)`: `X^ = 1 + T_N E_12`, `Y^ = 1 + S_N E_23` and `Z^ = 1 + E_13`. Here
`T_N δ_j = δ_(j−1)` with `T_N δ_0 = 0`, and `S_N δ_j = δ_(j+1)` with `S_N δ_(N−1) = 0`. For this
solution `Z^^(−1)[X^, Y^] = u_13(N−1, N−1)`, so `Σ_N` has no solution.

*Proof.*
1. **Rank-one conjugation.** `g(1 + v⊗φ)g^(−1) = 1 + gv ⊗ φ∘g^(−1)`, and over `F_2` the factors of a
   transvection are determined.
2. **Commutators as conjugation.** For commuting involutions `u, w`, both `[q,u] = w` and `[u,q] = w`
   give `q u q^(−1) = wu`. The finitary pairs used below all commute.
3. **`X^`.**
   * Commuting with `u_12` and `u_13` fixes `V^(1)` and preserves the component-2 and component-3
     coordinates.
   * Commuting with `u_32` fixes `V^(3)`.
   * (Σ1) gives `X^ δ_a^(2) = δ_a^(2) + δ_(a−1)^(1)` for `a >= 1`, and `X^ δ_0^(2) = δ_0^(2)`.
   * So `X^ = 1 + T_N E_12`.
4. **`Y^`.**
   * Commuting with `u_13` and `u_21` fixes `V^(1)` and `V^(2)`, and preserves the component-1 and
     component-3 coordinates.
   * (Σ2) gives `δ_b^(2)*∘Y^^(−1) = δ_b^(2)* + δ_(b−1)^(3)*` for `b >= 1`, with `δ_0^(2)*` fixed.
   * So `(Y^^(−1)w)_2 = w_2 + S_N w_3`, and `Y^ = Y^^(−1) = 1 + S_N E_23`.
5. **`Z^`.**
   * Commuting with `u_12` and `u_13` fixes `V^(1)` and preserves the component-2 and component-3
     coordinates.
   * (Σ5) gives `δ_b^(1)*∘Z^^(−1) = δ_b^(1)* + δ_b^(3)*`, so `Z^ = 1 + E_13`.
6. **(Σ3).**
   * With `A = T_N E_12` and `B = S_N E_23`: `A² = B² = BA = 0`, so `[X^,Y^] = 1 + AB = 1 + T_N S_N E_13`.
   * `T_N S_N = 1 − P_(N−1)`, so `Z^^(−1)[X^,Y^] = 1 + P_(N−1)E_13 = u_13(N−1,N−1)`.

QED

**Corollary 8.** Take a natural level-factoring model, with any representations `π_k`, such that
`τ_k` satisfies (Σ1), (Σ2), (Σ4) and (Σ5) for all `a, b < N_k`.
* The Toeplitz commutator defect is `rk(π_k(u_13(N_k−1,N_k−1)) − 1)/n_k`.
* Swapping indices `0` and `N_k − 1` conjugates this error to `u_13(0,0) = τ_k(x_13(e))`.
* So the defect tends to `c_0 = rk(σ(x_13(e)) − 1)`, which is positive unless `σ` is trivial.

This is the explicit forced error. Theorem 4 shows that moving it elsewhere does not help.

**Reading.**
* Exact block structure is algebra-likeness at the group level.
* It forces the truncated shifts, whose products miss the identity by the projection `1 − T_N S_N`.
* That is the group-level shadow of (C3) and of Theorem A of the Toeplitz-assembly artifact.

## 3. What survives

* Natural level-factoring models, and level-factoring models with positive projective share, are
  excluded entirely (Corollary 5(c)).
* A surviving construction has transvection displacement `d_k -> 0` at the level it factors
  through. No fixed nontrivial element may go to a bounded product of level transvections. That
  rules out Fock, natural and circulant truncations of `F_K`, and Steinberg or projective-piece
  models.
* In the limit, `F_K` must still act with uniform displacement `>= c_0/4` (Corollary 5(d)).
* Filters reported by sibling lanes, 2026-09-12 (their own nodes are authoritative):
  * `w3-gate-bridge-b`: the defect piece `im(N'_23 N'_12)` carries a full nontrivial model of `R^x`.
  * `w3-gate-v`: no model represents the cylinder idempotents covariantly under `V`.
  * `w3-gate-char3`: the char-3 gate for `G_3` is a single question, and anti-central models force
    uniform weights on the signed-cylinder diagonal.

## 4. Normal form at moving levels

Claim `rank-models-are-exact-representations-at-moving-finite-levels`.

**Lemma 9 (finite subgroups are rank stable).** Let `H` be finite and `s : H -> GL_n(F)` a map with
`rk(s(g)s(h) − s(gh)) <= εn` for all `g, h ∈ H`. Then there is a representation `ρ` of `H` with
`rk(ρ(h) − s(h)) <= (|H|+1)|H|² εn` for all `h`.

*Proof.*
1. `V_0 := ∩_(g,h) ker(s(g)s(h) − s(gh))` has codimension `<= |H|² εn`.
2. `U := V_0 ∩ ∩_h s(h)^(−1)V_0` has codimension `<= (|H|+1)|H|² εn`.
3. **Invariance.** For `v ∈ U` and `k, h ∈ H`: `s(k)v ∈ V_0`, and `s(h)s(k)v = s(hk)v ∈ V_0`. So
   `s(k)v ∈ U`, and `s(k)` restricts to a bijection of `U`.
4. **Exactness.** `s(g)s(h) = s(gh)` on `U`. In particular `s(1)` is an invertible idempotent on `U`,
   hence the identity.
5. Put `ρ(h) = s(h)|_U ⊕ id_C` for a complement `C`. It is a representation agreeing with `s` on `U`.

QED

**Proposition 10 (moving levels).** Let `σ = lim_ω σ_k` be a rank model of a group `G`, and
`H_1 <= H_2 <= ...` finite subgroups. There are `N_k -> ∞` along ω and representations `ρ_k` of
`H_(N_k)` with `max_(h ∈ H_(N_k)) rk(σ_k(h) − ρ_k(h))/n_k -> 0` along ω.

*Proof.*
1. For fixed `N`, `ε_(k,N) := max_(g,h ∈ H_N) rk(σ_k(g)σ_k(h) − σ_k(gh))/n_k -> 0` along ω.
2. Put `C_N = (|H_N|+1)|H_N|²` and `K_N = {k : C_N ε_(k,N) <= 1/N} ∈ ω`.
3. Take `N_k = max{N <= k : k ∈ K_1 ∩ ... ∩ K_N}`. Then `{k : N_k >= N_0}` contains
   `K_1 ∩ ... ∩ K_(N_0) ∩ [N_0, ∞) ∈ ω`.
4. Apply Lemma 9 at level `N_k`, with error `<= 1/N_k`.

QED

**Corollary 11 (normal form for `G = R^x`).** Let `σ` be a nontrivial characteristic-two model, and
`H_N ≅ GL(W_N)` the finitary level subgroups.
* **(a)** The `ρ_k` of Proposition 10 have transvection displacement `-> c_0 > 0`. So every
  nontrivial element of `H_(N_k)` has `ρ_k`-displacement `>= c_0/4 − o(1)`, by Lemma 3.
* **(b)** Some generator `g` of `G` has `lim_ω dist_rk(σ_k(g), ρ_k(H_(N_k))) > 0`.
  * Otherwise pick `τ_k` on the generators with `σ_k(g) ≈ ρ_k(τ_k(g))`, and extend `τ_k` along
    fixed words.
  * The model `σ'_k = ρ_k ∘ τ_k` has the same limit, factors through `H_(N_k)`, and has transvection
    displacement `-> c_0`.
  * Theorem 4 then makes `G` LEF, which is impossible.
* **(c) The compressor is locally inner, with corrections at every level.**
  * For fixed `M`, put `γ_M = 1 + T_(M+1)E_12 ∈ GL(W_(M+1))`.
  * `D = (1 + T E_12)γ_M^(−1) = 1 + (T − T_(M+1))E_12` maps component-2 indices `>= M+1` to
    component-1 indices `>= M`, so it commutes with `H_M`. Hence `x_12(t0) h x_12(t0)^(−1) = γ_M h γ_M^(−1)`
    for `h ∈ H_M`.
  * So `c^X_(k,M) := ρ_k(γ_M)^(−1) σ_k(x_12(t0))` almost commutes with `ρ_k(H_M)`, and likewise
    `c^Y`, `c^Z` for `x_23(s0)` and `x_13(1)`, using `1 + S_(M+1)E_23` and `1 + E_13`.
  * If all three corrections were `o(1)`, Proposition 7 at level `M + 1` would make the Toeplitz
    commutator fail by `ρ_k(u_13(M,M))`, of displacement `c_0`.
  * So at every level `M`, some correction is not negligible.

**Reading.**
* A nontrivial model is an exact, uniformly displacing representation on the moving finitary level.
* The compressor images are locally inner on each fixed level, through the truncated shifts.
* Globally they stay away from the level group, with corrections that cannot all vanish at any
  level.
* Constructing a model means building those corrections coherently in `M`.

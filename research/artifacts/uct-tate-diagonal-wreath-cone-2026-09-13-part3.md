## 9. Theorem D: the Tate norm `T := q^*1_T ⊗ ⊗̂_G(−) : KK^Γ → KK^W`

Let `Γ` be countable discrete, `p` prime, `G = Z/p = Ω` (regular), and `W = Γ ≀ G`.

1. **Functor.** `T` is a functor, with `T([φ]) = 1 ⊗ [φ^(⊗p)]`.
2. **Additive.** `T(A ⊕ B) ≅ T(A) ⊕ T(B)`, compatibly with the canonical inclusions and projections.
   Hence `T(x + y) = T(x) + T(y)` on morphisms.
3. **Exact.** For a `Γ`-\*-homomorphism `φ : A → B` there is an exact triangle
   `T(C_φ) → T(A) → T(B)` in `KK^W`, whose second arrow is `T(φ)`.
4. **Gamma.** If `Γ` has a γ-element, then
   `T(A) ≅ T(γA) ⊕ T((1 − γ)A) = γ_W T(A) ⊕ (1 − γ_W)T(A)`.
5. **Induction.** `T(Ind_K^Γ B) ≅ Ind_(K≀G)^W(Res_(K≀G) q^*1_T ⊗ B^(⊗p))` for every subgroup `K ≤ Γ`.

*Proof.*
1. NP Thm. 5.10, followed by the functor `q^*1_T ⊗ −`.
2. **Direct sums.**
   - `(A ⊕ B)^(⊗p) = ⊕_(u ∈ {A,B}^G) (tensor word u)` as `W`-algebras.
   - The constant words give `A^(⊗p)` and `B^(⊗p)`.
   - Non-constant words form free `G`-orbits, since `p` is prime. Each orbit sum is
     `Ind_(Γ^p)^W` of one word.
   - `Ind_(Γ^p)^W(X) ⊗ q^*1_T ≅ Ind_(Γ^p)^W(X ⊗ Res q^*1_T) ≃ 0`, because `Res^W_(Γ^p) q^*1_T` is
     the inflation of `Res^G_1 1_T ≃ 0`.
   - `i_A^(⊗p)` and `p_A^(⊗p)` are the inclusion of and projection onto the constant word `A`.
   - So `T` preserves biproduct diagrams, and a functor between additive categories preserving
     biproducts is additive.
3. **Triangles.**
   - Let `(I_j)` be the Izumi filtration of `M_φ^(⊗p)` for `0 → C_φ → M_φ → B → 0`.
   - By NP Prop. 5.18, each step `0 → I_(j+1) → I_j → I_j/I_(j+1) → 0` is `W`-equivariantly c.p.-split,
     so it is an exact triangle in `KK^W`.
   - For `0 < j < p`, `I_j/I_(j+1) ≅ ⊕_(|S| = j) C_φ^(⊗S) ⊗ B^(⊗Ω∖S)`, and `G` acts freely on those
     `S`. These layers are induced from `Γ^p` and die after `⊗ q^*1_T`.
   - Hence `q^*1_T ⊗ I_p = T(C_φ)` is isomorphic to `q^*1_T ⊗ I_1`. Also `I_0/I_1 = B^(⊗p)`, and
     `I_0 = M_φ^(⊗p) ≅ A^(⊗p)` by functoriality applied to the homotopy equivalence `A → M_φ`.
   - The quotient map composes to `φ^(⊗p)`.
4. **The γ-decomposition.**
   - `A ≅ γA ⊕ (1 − γ)A` with `γA ∈ <CI_Γ>` and `(1 − γ)A ∈ CC_Γ` (Meyer–Nest Thm. 8.3).
   - By 2, `T(A) ≅ T(γA) ⊕ T((1 − γ)A)`.
   - `T(γA) ∈ <CI_W>`, by NP Lemma 5.19 and because `<CI>` is a tensor ideal.
   - `T((1 − γ)A)` is weakly contractible:
     - over `F = 1`, `Res 1_T ≃ 0`;
     - over `F` conjugate to `<σ>`, `Res_F ⊗̂_G(N) = N^(⊗p)`, which is `≃ 0` in `KK^G` by NP Lemma 5.15
       and functoriality, since `Res^Γ_1 N ≃ 0` for torsion-free `Γ`;
     - for `Γ` with torsion, apply the same argument to each finite `L ≤ Γ`.
   - The decomposition of Meyer–Nest Thm. 8.3 is unique, and NP Thm. 5.16 says the idempotent is `γ_W`.
5. `(Ind_K^Γ B)^(⊗p) ≅ Ind_(K≀G)^W(B^(⊗p))`, as in the proof of NP Lemma 5.19, and `Ind` commutes with
   `⊗ q^*1_T`. ∎

**This supersedes (f3) of part 2.** The norm sum formula is unnecessary after `⊗1_T`: `T` is additive.
In particular `T(1 − γ_Γ) = 1 − T(γ_Γ)`, and the Tate diagonal question lives entirely on
`T((1 − γ)C)`.

## 10. The functor `Ψ`, and a fence at K-amenability

Define `Ψ(A) := W ⋉_r (cone(ε) ⊗ T(A))`, an additive exact functor `KK^Γ → KK`. Then
`Ψ(C) = W ⋉_r Y`, so (P1) says `Ψ(C) ≃ 0`.

**Proposition E.** Let `Γ` be torsion-free.
- (a) `Ψ` vanishes on the localizing subcategory `𝒜_Γ := <Ind_K^Γ B : K ≤ Γ amenable>`, which contains
  `<CI_Γ>`.
- (b) If `Γ` is infinite with property (T), then `C ∉ 𝒜_Γ`, so `(1 − γ)C` survives in `KK^Γ/𝒜_Γ`.

So no argument that places `C` in a subcategory generated by amenably induced objects can prove (P1).

*Proof.*
- (a) By 9.5, `Ψ(Ind_K^Γ B) ≅ (K≀G) ⋉_r (Res_(K≀G) Y ⊗ B^(⊗p))`, up to Morita equivalence.
  `Res_(K≀G) Y` is weakly contractible (part 1, Thm. A.1), and `K ≀ G` is amenable, so it vanishes by
  Meyer–Nest Thm. 8.5. `Ψ` is exact and commutes with countable direct sums, so its kernel is
  localizing.
- (b) Let `λ_A : Γ ⋉_max A → Γ ⋉_r A`. The class of `A` for which `λ_A` is a KK-equivalence is
  localizing, since both descents are triangulated and commute with direct sums. It contains
  `Ind_K^Γ B` for amenable `K`, because the Morita equivalence reduces to `K ⋉_max B = K ⋉_r B`.
  If `C ∈ 𝒜_Γ`, then `λ_C : C*_max Γ → C*_r Γ` is a KK-equivalence. But the Kazhdan projection
  `p ∈ C*_max Γ` has `[triv]_*[p] = 1`, while `λ(p) = 0` for infinite `Γ`. Contradiction. ∎

**Reading.** (P1) is the statement that the Tate-norm crossed-product functor `Ψ` kills the image of
the unit in the "non-K-amenable quotient" `KK^Γ/𝒜_Γ`. Every functor known to vanish on `𝒜_Γ` and
detect the unit there is a max-versus-reduced comparison, and `Ψ` is built from reduced crossed products
only. A negative answer would need a reduced-side analogue of the Kazhdan-projection pairing on
`T((1 − γ)C)`. A positive answer would need an argument on `KK^Γ/𝒜_Γ` that is not generation.

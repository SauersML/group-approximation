# Problem LXXII: essential purely infinite quotient seam audit (2026-08-30)

## Theorem

Consider a quotient seam inside the radical-free core:

```text
0 -> I -> J -> Q -> 0,
```

where `J` is weakly purely infinite, `P_pi(J)=0`, and `0 != Q` is purely
infinite.  Then the extension is essential and its Busby map is injective.
Moreover, `I` remains essential after intersection with every nonzero
hereditary subalgebra of `J`.  In Cuntz-semigroup language, `Cu(I)` meets
every nonzero principal order ideal and carries a non-idempotent weak-pure
class there.

This is an unconditional reduction.  It does not assert that such an
essential extension exists and does not prove that `J` is purely infinite.

## Busby-kernel audit

For an arbitrary extension the annihilator

```text
I_perp={a in J : aI=Ia=0}
```

maps isomorphically onto the kernel of the Busby map.  The point requiring
care is that an element whose Busby image is zero need not itself annihilate
`I`; it differs by an element of `I` from one that does.  This proves

```text
I_perp isomorphic to ker(tau).
```

Because `ker(tau)` is an ideal of the purely infinite quotient, it is purely
infinite.  A nonzero kernel would therefore lift to the forbidden purely
infinite ideal `I_perp` of `J`.  Hence `I_perp=0` and `tau` is injective.

In particular, split direct-sum pieces and every other nonessential Busby
model are ruled out.  Any genuine counterexample seam must embed its purely
infinite quotient faithfully into the corona of a radical-free weakly purely
infinite ideal.

## Hereditary self-similarity

If `I` is essential in `J` and `0 != C subset J` is hereditary, then
`C intersect I` is nonzero and essential in `C`: for `0 != c in C_+`, the
corner `cIc` cannot vanish.  Quotienting gives

```text
C/(C intersect I) isomorphic to q(C),
```

and `q(C)` is hereditary in `Q`.  Whenever it is nonzero, it is purely
infinite.  The Morita-hereditary radical theorem says that the kernel and
middle algebra are again radical-free WPI non-PI.  Thus every quotient-visible
corner reproduces the same essential bad-by-good extension seam.

## Cuntz comparison boundary

Essentiality gives a nonzero element of `Cu(I)` in the principal order ideal
of every `0 != x in Cu(J)`.  Applying hereditary radical-freeness inside that
intersection produces `z` with

```text
z <= infinity x,
z < 2z <= ... <= nz = infinity z.
```

So the kernel is not only order-essential; comparison defects occur inside it
at every nonzero scale.

Since `Cu(Q)=Cu(J)/Cu(I)` and `Q` is purely infinite, `bar(2x)=bar(x)`.  Apply
the quotient-order formula inside the ideal generated by `x`.  This gives

```text
2x <= x+w,                 w in Cu(I),  w <= infinity x.
```

The correction can therefore be kept in the same principal region, and
iteration gives

```text
infinity x=nx <= x+(n-1)w.
```

The formula still does not permit cancellation of `w`.  Weak pure
infiniteness only says that a fixed finite multiple of `w` saturates, not that
`w` is absorbed by `x`.  Treating the formula as `2x<=x` or subtracting the
kernel term would be invalid.  The quotient description used here is the
exactness theorem of Ciuperca--Robert--Santiago, *Cuntz semigroups of ideals
and quotients and a generalized Kasparov Stabilization Theorem*, arXiv
`0710.5800`.

## Exact remaining obstruction

A counterexample seam must therefore satisfy all of the following at once:

1. `I` and `J` are radical-free WPI non-PI;
2. `Q` is PI and injects through the Busby map into `Q(I)`;
3. `I` is essential in every nonzero hereditary corner of `J`;
4. every principal Cuntz region contains a kernel-supported class with
   strict first duplication but finite saturation;
5. quotient idempotence only lifts as `2x<=x+w`, with `w` in the essential
   defect ideal and in the principal ideal of `x`.

Thus neither a nonessential extension nor a defect-free corner can support a
counterexample.  The remaining issue is precisely kernel-term absorption in
an essential Busby extension.

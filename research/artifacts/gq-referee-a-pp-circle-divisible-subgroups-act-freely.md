## 1. `pp-circle-divisible-subgroups-act-freely`

- **Step 0 (U), (F).** Correct. (P): a nontrivial element of `PSL_2(R)` fixes at most two points
  of `RP^1`. (L): on a lift `I~` of length at most 1, `λ(x) - x = (a-1)x + b` is either constant
  (an integer translation, which fixes all of `I` mod 1, or no fixed point) or strictly monotone, so
  it takes finitely many integer values. With finitely many breakpoints, `Fix(g)` has finitely
  many components, so `g` has finitely many gaps.
- **Step 1, gap endpoints.** Correct. `D` is abelian, so it permutes the gaps of `g`. The image of
  `D` in `Sym(m)` is finite and divisible, hence trivial. An orientation-preserving map that sends
  an open arc onto itself fixes its endpoints, including when the arc is `S^1` minus one point.
- **Step 1, germ homomorphism, including case (L).** Correct.
  - *Existence of `ρ(d)`.* A right neighbourhood `[a, a+ε)` lies in the closure of one component of
    `S^1 \ B_d`. In case (L) the definition asks only that *a* lift be `Λ`-piecewise. Lifts differ
    by integer translations, which lie in `Λ` by assumption, so the lift fixing `a~` is
    `Λ`-piecewise too. Worth one sentence in the proof.
  - *Uniqueness* is by (U).
  - *Multiplicativity.* `d'` fixes `a` and preserves orientation, so for small `ε` it maps
    `[a, a+ε)` into `[a, a+ε_d)`. There `dd' = ρ(d)ρ(d')`, once `ε ≤ ε_{d'}` as well (implicit
    in the proof). In case (L), the lift of `dd'` fixing `a~` is the composite of the lifts fixing
    `a~`.
  - So `ρ : D -> Stab_Λ(a~)` is a homomorphism. Its image is divisible abelian and is killed by (D).
    Then `g` is the identity on `(a, a+ε) ⊂ J`, contradicting that `J` is a gap. Item 1 holds.
- **Step 2.** Correct and standard.
  - `τ_μ` does not depend on `x` and is additive on lifts of a `μ`-preserving group. It equals the
    translation number, since `μ~([x, x+L))` lies between `⌊L⌋` and `⌈L⌉`.
  - Rotation number 0 is equivalent to having a fixed point.
  - Item 2 (the kernel is trivial by item 1), item 3 (conjugacy invariance plus injectivity) and
    item 5 follow.
- **Step 3.** Correct. The rotation number is intrinsic, so the `A`-invariant measure computes the
  same `rot` on `D ⊆ [A, A]`.
- **(D) for finitely generated hosts.** Correct.
  - Pieces of a product on the refined partition `B_h ∪ h^{-1}(B_g)` are products of pieces, so
    `Λ_0` is a group generated by finitely many pieces (with `x -> x+1` added in case (L)).
  - `Λ_0` is linear, through the adjoint representation `PSL_2(R) -> GL_3(R)` or through
    `Aff(R) <= GL_2(R)`, so it is residually finite by Mal'cev.
  - A residually finite group has no nontrivial divisible subgroup.

## 2. `pp-circle-and-lift-hosts-miss-gl-n-q`

- **Step 1, injectivity of `τ` on `D ≤ Γ~` (the point I was asked to push).** Correct.
  - `π(D)` is divisible abelian and preserves some `μ`. Every lift of a `μ`-preserving map preserves
    the periodic lift `μ~`, so `τ = τ_μ` is a homomorphism on `D`.
  - If `τ(d) = 0`, then `rot(π(d)) = 0`, so `π(d)` has a fixed point. Item 1 applied to
    `π(D) ≤ Γ` then gives `π(d) = 1`. So `d = (x -> x+k)` with `k = τ(d) = 0`, that is `d = 1`.
- **Normalizers and amenable subgroups in `Γ~`.** Correct. Translation number is invariant under
  conjugation by orientation-preserving homeomorphisms of `R` that commute with `x -> x+1`.
- **Step 2, the witnesses.** All correct.
  - `diag(2, 1/2, 1, …)` conjugates `I + qE_12` to `I + 4qE_12`. This works for `n = 2`, and in
    `PGL_n` / `PSL_n`, where `D` meets the scalars trivially.
  - `x -> 2x` doubles the translations in `Aff(Q)` and `B_2(Q)`.
  - For `r ≠ 1`, the action on `Q x|_r Z` is nontrivial.
  - In `U_n(Q)`, `n ≥ 3`: `[I+E_12, I+qE_23] = I + qE_13`, so `D ≤ [U, U]` inside a nilpotent,
    hence amenable, group.
  - Any group containing one of these contains the same `D`.
- **Hosts, part (c).** Each listed host is finitely generated with finitely many breakpoints per
  element, or has its pieces in one finitely generated linear `Λ`, so (D) holds. Compactifying the
  line or interval adds at most one breakpoint. `T-bar ⊆` translation numbers in `Q`, so its
  divisible abelian subgroups are `0` or `Q`, given Ghys--Sergiescu.

## 3. Scope (stated correctly in both nodes)

- Only finitely many breakpoints per element and pieces in a (D) group are covered. That includes
  every finitely generated, and so every finitely presented, candidate host of this type.
- Not covered: infinitely many breakpoints (Brin's `A`), higher-dimensional piecewise-projective
  groups, and Cantor-set hosts. Such groups remain possible building blocks inside Cantor hosts.

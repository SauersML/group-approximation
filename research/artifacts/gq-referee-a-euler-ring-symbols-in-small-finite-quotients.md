## Part 1, `F_(2,l)`
- *(a) and (b).* `y² = ly = 0` gives `(1+y)^a = 1 + ay` and `(1+y)^l = 1`.
  - `{1+y, −1}` has order dividing both 2 and `l`, so it is trivial.
  - (S3) then gives `{1+y, 1+y} = 1`, and the other symbols follow by bimultiplicativity. ✓
- *(c) The Fermat quotient step (the author asked about this).*
  - Write `s = ω(1+bl)`. Then `s^(l−1) = (1+bl)^(l−1) ≡ 1 − bl (mod l²)`, so `L(s) = −b`.
  - `χ` has exponent `l`, so it kills `ω`, and `χ(s) = χ(1+l)^b = z^(−L(s))`. ✓
- *(d) The relation.*
  - The factorization is `1 − t(1+y) = (1−t)(1 − t'y)`.
  - Expanding (S4) gives `χ(t)^(t') χ(1−t) = 1`, using `{t,1−t} = 1`, `{1+y, 1−t'y} = 1` and `1 − t'y = (1+y)^(−t')`
    with (S2). ✓
  - `sL(s) = (s^l − s)/l` exactly for an integer lift, and `t^l` mod `l²` depends only on `t` mod `l`.
  - Expanding `(1−t)^l` with `l` odd and `binom(l,k)/l ≡ (−1)^(k−1)/k` gives
    `(t^l + (1−t)^l − 1)/l ≡ Σ_(k<l) (−1)^(k−1)(−1)^k t^k/k = −P(t)`. So `E ≡ P(t)/(1−t)`. ✓
- *The root count (the author asked about this).*
  - `P` has degree `l − 1`, with leading coefficient `1/(l−1) = −1`.
  - `P(0) = 0`, and `P(1) = Σ 1/k ≡ Σ k = l(l−1)/2 ≡ 0`.
  - So `P` has at most `l − 3` roots on the `l − 2` points of `F_l ∖ {0,1}`.
  - For `l = 3`, `P(t) = t + 2t²` and `P(2) = 1`. ✓
- *(e) and `l = 2`.* `(1+y)(1+ql) = 1 + y + ql` because `ly = 0`. For `l = 2`, `3 + y = −(1+y)` because `2y = 0`. ✓

## Parts 2 and 3, the cyclotomic point
- *The map.* `π_k ↦ ζ + kl ≡ ζ (mod 𝔭^(l−1))`, a unit.
  - The kernel of `K_2(N,O_K) → K_2(N,O_K/𝔭^n)` is generated by `{v, 1+w}` with `w ∈ 𝔭^n`. These are killed by `h`,
    because `U^(n) ⊆ K^(×l)` for `n > l`.
  - (DS12), with `e = l − 1` and `r = 1`, gives order `l^t` with `t = [(n−1)/(l−1)]` clamped to 1. So `t = 1` for
    `n ≥ l + 1`. ✓
- *The Hilbert symbol value `ζ^(−q)` (the author asked about this).*
  - `h(ζ,ζ) = h(ζ,−1)^(−1) = 1`.
  - In Artin–Hasse, the `k = 1` term is `q·Tr(ζ^(−1)) = −q`.
  - For `k ≥ 2` the terms vanish mod `l`: `v_l(l^(k−1)/k) = k − 1 − v_l(k) ≥ 1` when `l ≥ 3`, and `Tr(ζ^(−k)) ∈ Z`.
  - The computation holds for any integer in place of `q`, which Part 3 uses. ✓
- *The orbit product `ζ^(−qm)` (the author asked about this).*
  - `φ_(i+m) = φ_i` because `ml ∈ 𝔭^n`, and `x a x^(−1)` acts on `e_i` by `φ_(i+1)(a) = φ_i(σa)`. So `ρ_m` is a ring map.
  - For each `i`:
    - `h(ζ, 1+(i+q)lζ^(−1)) = ζ^(−(i+q))`;
    - `h(1+ilζ^(−1), ζ) = ζ^i`, by antisymmetry;
    - the cross term vanishes by the level bound, since `2(l−1) > l`.
  - So each `i` contributes `ζ^(−q)`, and the total is `ζ^(−qm)`. Morita's sum map gives the identification. ✓
- *"`ml ∈ 𝔭^n` with `n ≥ l+1` forces `l | m`" (the author asked about this).*
  - `v_𝔭(ml) = (l−1)(1 + v_l(m))`, and `(l+1)/(l−1) > 1`. So `v_l(m) ≥ 1`. ✓
  - The `0`-th diagonal entry is a ring map `ρ_m(A) → O_K/𝔭^n` that recovers `φ_0`. So the commutative image still
    sees `c_q`. ✓

## Part 4, `C_r = Z[u]/(l,u)^r` (checked hardest, as asked)
- *The image of `A` is the image of `Z[u]`.* In a finite ring, an element invertible in an overring is invertible in
  the subring: `a^i = a^j` gives `a^(j−i) = 1` (N3).
- *The Stirling/Mahler identification.*
  - `t^i = Σ_k k! S(i,k) binom(t,k)`, so `d_k = k! Σ_(i≥k) S(i,k) c_i l^i`.
  - Vanishing at every integer forces `d_k = Δ^k f(0) ≡ 0 (mod l^r)`. This depends only on `j mod l^(r−1)`, so "all
    `j ∈ Z/N`" suffices.
  - For `k ≤ r − 1 ≤ l − 1`, `k!` is a unit. Descending induction from `k = r − 1`, where terms with `i ≥ r` vanish,
    gives `l^(r−i) | c_i` for `i < r`, hence `g ∈ (l,u)^r`. ✓
- *Coordinates.*
  - The truncated `exp` and `log` are inverse group isomorphisms. The cross terms `a^i b^j` with `i + j ≥ r` vanish,
    and only factorials `< l` occur.
  - `C_r^× = μ_(l−1) × (1+𝔪)`, since `Z/l^r ⊆ C_r` contains the Teichmüller roots.
  - `β` is alternating, because `{e^a,−1}` has order dividing both 2 and a power of `l`.
  - Symbols involving `μ_(l−1)` vanish: two roots of unity give a symbol in `K_2(N, Z/l^r) = 0`, and mixed ones have
    coprime orders. ✓
- *The relation `R(t,a)`.*
  - `1 − te^a = (1−t)e^(w(a))`, and `w_k` is `l`-integral: only `1/m` and `1/k!` with `m, k < r` occur.
  - `β(λ(t), λ(1−t))` vanishes, either by `K_2(Z/l^r) = 0` or directly by (S4) for `t`. ✓
- *The homogeneous-part separation (the author asked about this).*
  - `R(t, ca) = Σ_(d=1)^r c^d Q_d`. `a^k = 0` for `k ≥ r`, so the degree is at most `r`.
  - The Vandermonde determinant on `c = 1..r` is `Π c · Π (c' − c)`, a unit mod `l` because `r ≤ l − 1`.
  - Inverting it is legitimate because `K_2(N, C_r)` is a `Z/l^r`-module: it is generated by values of `β`, and
    `β(a,b)^(l^r) = β(l^r a, b) = 1` (N4). So every `Q_d = 0`. ✓
- *Degree 1.* The degree-1 part is `β(a, t'λ(t) + λ(1−t)) = β(a, μ(t))`.
  - `(l−1)λ(s) = log(s^(l−1)) ≡ s^(l−1) − 1 (mod l²)` gives `λ(s)/l ≡ −L(s)`, so `μ(t)/l ≡ P(t)/(1−t)`.
  - With `P(t) ≠ 0`, `μ(t) = l·v` for an integer unit `v`, so `β(a, l) = 0`. ✓
- *`w_k(t)` a unit (the author asked about this).*
  - The formula is `k! w_k = −Σ_(m=1)^k (m−1)! S(k,m) t'^m`. Its top coefficient is `−(k−1)!`, a unit, and it has no
    constant term.
  - `t ↦ t' = t/(1−t)` is a bijection from `F_l ∖ {0,1}` onto `F_l ∖ {0,−1}`, a set of `l − 2` points.
  - At most `k − 1 ≤ l − 3` of these are roots. ✓
- *The polarization (the author asked about this).*
  - The coefficient of `s` in `β(a+sb, (a+sb)^k)` is `β(b,a^k) + kβ(a, a^(k−1)b)`. Vandermonde on `k+2` points needs
    `k + 2 ≤ l`, which holds for `k ≤ r − 1`. For `k ≥ r` both sides vanish, because `a^(k−1)b ∈ 𝔪^k = 0`.
  - `(k+1)β(u,u^k) = 0` with `k+1 ≤ r ≤ l−1` is correct, but redundant (N2): the degree step already gives
    `β(a, a^k) = 0` for every `a ∈ 𝔪`, including `a = u`.
  - `β(u^j, u^k) = −kβ(u, u^(j+k−1)) = 0`. The `l^i u^j` span `𝔪`, and `β(lZ, ·) = 0`. So `β = 0`. ✓

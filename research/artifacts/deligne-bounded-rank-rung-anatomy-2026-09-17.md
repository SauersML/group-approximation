# Bounded-rank rung for Deligne covers: corona form, localization, anatomy, dead mechanisms

Lane sw-021 (scale-shifter), 2026-09-17. Node: `deligne-cover-bounded-rank-sector-tuples-have-bounded-dimension`.
Notation is that of the node. The rank inequalities used throughout are:

- `rank(XY - I) <= rank(X - I) + rank(Y - I)`;
- `rank(W X W^(-1) - I) = rank(X - I)`;
- `rank(X^(-1) - I) = rank(X - I)`.

## E2. Corona form

**Claim.** The rung fails iff some `d_i -> infinity` admits a homomorphism `phi : Gamma_n -> G_B` with
`phi(z) = [(zeta I)]`.

**Proof.**
- *Failure gives phi.* Suppose the rung fails for some `k`, witnessed by tuples `rho_i` of dimension
  `d_i -> infinity`. Define `phi(s) = [(rho_i(s))]`. For each relator `r` in `R`, `(rho_i(r))` lies in
  `B` because the rank is at most `k`. So `phi` descends to `Gamma_n`, and `phi(z) = [(zeta I)]`.
- *phi gives failure.* Lift each `phi(s)` to `(rho_i(s))` and put `rho_i(z) = zeta I`. The class
  `[(zeta I)]` agrees with `phi(z)` modulo `B`, so this is a valid lift of the generator `z`.
- Each relator `r` gives a sequence in `B`, so `sup_i rank(rho_i(r) - I) = k_r < infinity`. There are
  finitely many relators, so `k = max k_r` works uniformly.
- **Nontriviality.** `rank(zeta I - I) = d_i` is unbounded, so `[(zeta I)] != 1`.

**Remark (why D6 dies).** Put `A_B = prod M_(d_i) / I_B`, where `I_B` is the ideal of bounded-rank
sequences.
- `A_B` is stably finite. If `XY = 1` in `M_m(A_B)`, lift `X, Y` to sequences. Then
  `rank(I - Y_i X_i) = rank(I - X_i Y_i)` is bounded, because `v -> Y v` maps `ker(I - XY)`
  injectively into `ker(I - YX)` and symmetrically. So `YX = 1`.
- A non-stably-finite `C_zeta[Sp_(2g)(Z)]` does not contradict this. The induced map need not be
  injective, and `YX - 1` may map to `0`. **The exact failing step is injectivity**, and nothing in
  the setting supplies it.

## E3. Localization (LOC) and A1

**Lemma.** Let `g in Gamma_n` have noncentral image in `Sp_(2g)(Z)`. Then `z^2` is in the normal
closure `<<g>>` of `g` in `Gamma_n`.

**Proof.**
- By the Margulis normal subgroup theorem (`g >= 2`, real rank `g >= 2`), a normal subgroup of
  `Sp_(2g)(Z)` is either central (contained in `{+-I}`) or of finite index. The image of `<<g>>`
  contains a noncentral element, so it has finite index.
- `Gamma_n / <<g>>` is an extension of that finite quotient by the image of `<z>`, which is finite.
  So `<<g>>` has finite index in `Gamma_n`. Its normal core is itself, since it is normal.
- By `deligne-covers-of-sp2g-z-have-finite-residual-2z`, `z^2` lies in every finite-index normal
  subgroup. QED.

**Word identity.** Write `g` as a word in `S cup {z}`. There is an identity in the free group `F`:

```text
z^2 = prod_(i=1..N) w_i g^(e_i) w_i^(-1) * prod_(j=1..A) u_j r_j^(f_j) u_j^(-1),   e_i, f_j in {+-1}, r_j in R.
```

Fix one such identity with `N_g = N` and `A_g = A`. It depends only on the presentation and on `g`.

**(LOC) proof.**
- Apply `rho` to the identity. The product rank inequality gives
  `rank(rho(z)^2 - I) <= N rank(rho(g) - I) + A k`.
- Since `rho(z) = zeta I` and `zeta^2 != 1`, the left side equals `d`. So
  `d <= A k + N rank(rho(g) - I)`.
- This is (LOC) with room to spare. The stated form `(1 + A_g) k` also covers the variant where
  `rho(z) - zeta I` is only of rank `<= k`. Then `rho(z)^2 - zeta^2 = (rho(z) - zeta)(rho(z) + zeta)`
  has rank `<= k`, so `rank(rho(z)^2 - I) >= d - k`.
- **A1** is (LOC) rearranged.
- **Converse of the reduction.** If the rung holds, `rank(rho(g) - I) <= d <= C(k)`.

**Calibration.**
- *Heisenberg `H`.* `z = [a,b] = a (b a^(-1) b^(-1))`, so `N_a = 2`, `A_a = 0`, and (LOC) reads
  `d <= k + 2 rank(A - I)`. The shift `A` has `rank(A - I) = d - 1`, so this is consistent with
  rank-one tuples in every dimension. (LOC) carries no strength by itself.
- *`Sp_(2g)(Z) x Z/n`.* Here `<<g>>` avoids `Z/n`, so the Lemma fails at its last step. This is the
  only place Deligne enters.

## A2. Spectral gap off O(k) dimensions

**Certificate.** `Gamma_n` has (T) (`deligne-universal-cover-lattice-is-non-rf-kazhdan`, finite
quotient). By Ozawa's theorem (J. Inst. Math. Jussieu 2016) there are `eps > 0` and `xi_i in R[Gamma_n]`
such that, for `Delta = sum_(s in S cup {z}) (2 - s - s^(-1))`, `Delta^2 - eps Delta = sum xi_i^* xi_i`
holds in `R[Gamma_n]`.

**Lifting.** Lift everything to `R[F]`. The difference lies in the kernel of `R[F] -> R[Gamma_n]`,
which is the two-sided ideal generated by `r - 1` for `r` in `R`. So

```text
Delta^2 - eps Delta = sum xi_i^* xi_i + E,   E = sum_(j <= J) a_j (r_j - 1) b_j,   E = E^*.
```

(Symmetrize if necessary: replace `E` by `(E + E^*)/2`, which doubles `J`.)

**Proof.**
- Extend `rho` to `R[F]` with `rho(s^(-1)) = rho(s)^*`. Then `rho(E)` is self-adjoint of rank
  `<= kJ`, and `rho(Delta)^2 - eps rho(Delta) = P + rho(E)` with `P >= 0`.
- By Weyl's inequalities, `rho(Delta)^2 - eps rho(Delta)` has at most `kJ` negative eigenvalues.
  These are exactly the eigenvalues of `rho(Delta)` in `(0, eps)`.
- `ker rho(Delta)` is the common fixed space of `rho(S cup {z})`. On it `rho(z) = I`, but
  `rho(z) = zeta I` with `zeta != 1`, so `ker = 0`. In the rank-`<= k` variant, `dim ker <= k`.
- Total: at most `k(J + 1)` eigenvalues in `[0, eps)`. QED.

**Scope.** Exact representations of `Sp_(2g)(Z/m)` without invariant vectors satisfy (A2) with
`k = 0`. So (A2) alone bounds nothing; it only removes near-invariant constructions.

## D. Dead mechanisms, exact failing steps

- **D1. Determinant and trace.**
  - *Determinant.* A certificate `prod [rho(a_j), rho(b_j)] = zeta^e (I + K)` with `rank K <= k'` is
    consistent for every `d`, because `det(I + K)` can be any nonzero number. The step
    "take determinants to force `zeta^(ed) = 1`" (the Heisenberg exact case) dies as soon as one rank
    error is allowed. The Heisenberg shift tuple realizes exactly this.
  - *Trace.* The canonical trace kills commutators, so trace certificates see only `tr(K)`, which
    is unconstrained.
- **D2. Almost-invariant joint spectra.**
  - *Setup.* In `SL_3(Z) <= Sp_(2g)(Z)`, `b = e_23(1)`, `c = e_13(1)` commute. `A in SL_2(Z)`
    hyperbolic acts on `<b,c> = Z^2`. For exact finite-dimensional representations the joint
    spectrum of `(b,c)` is a finite `A^T`-invariant set, hence torsion.
  - *Why the rank version dies.* On the good subspace the joint spectral measure is only invariant
    up to `O(k)` atoms. The set `{(A^T)^j x : 0 <= j < d}` for a non-periodic `x` is invariant up to
    2 atoms and is not torsion. The failing step is "almost-invariant finite atomic measure implies
    torsion atoms".
  - *Relative (T).* It controls almost-invariant *vectors*, not atom counts, and D7 blocks passing
    to vectors.
- **D3. Torus and pi_2 certificates.**
  - *Claim.* Let `a, b in Sp_(2g)(R)` commute. Their lifts to the universal cover commute, so they
    commute in `Gamma_n`.
  - *Proof.* The class of `1 -> Z -> G~ -> G -> 1` (discrete topology) is represented by a bounded
    cocycle (the Guichardet–Wigner / Dupont bound for Hermitian groups; equivalently the rotation
    quasimorphism). Pull it back along `Z^2 -> G`; its value on `[T^2]` is `c = [a~, b~]`. For every
    real cycle `sigma` representing `[T^2]`, `|c| <= ||e||_infinity ||sigma||_1`. The simplicial
    volume of `T^2` is 0, so `c = 0`.
  - *pi_2.* Spherical identities have zero pairing.
  - *Consequence.* Every detecting certificate for `z`, including the detecting cycles of
    `deligne-bounded-rank-monomial-models-need-large-detecting-cycles`, contains genus `>= 2` pieces.
    Methods built from commuting pairs, Steinberg torus symbols, or Heisenberg subgroups whose
    center lifts isomorphically die at the pairing step.
- **D4. Exel partial representations.**
  - *Setup.* On `V_L = intersect_(|w| <= L, r) rho(w)^(-1) ker(rho(r) - I)`, of codimension
    `<= k |R| |S|^L`, the tuple defines a partial action that is exact on `L`-balls.
  - *Why it dies.* Globalizing it to a unitary sector representation requires the domain projections
    `rho(w) P rho(w)^*` to commute (Exel's theorem is for partial representations whose range
    projections commute). A general unitary tuple has no such commutation.
  - *Alternative.* Completing the operator-valued positive-definite function
    `w -> P_(V_L) rho(w) P_(V_L)` to a genuine sector representation is the truncation equivalence of
    `deligne-sector-truncations-have-bounded-dimension`, so it is circular.
- **D5. Bounded quasi-unipotence.**
  - A quantitative Deligne argument through eigenvalue orders needs `rho(x_alpha(1))^M - I` of
    bounded rank for a fixed `M`.
  - Exact representations of `Sp_(2g)(Z/m)` show that `M` must grow with `m`. Rank errors do not
    preserve eigenvalue orders anyway: `k` eigenvalues can move arbitrarily.
  - The failing step is "fixed `M`". Letting `M = M(d)` makes the cost `(N, A)` in (LOC) for
    `g = x_alpha(1)^M` depend on `d`, which is precisely the uncomputed Deligne cost.
- **D6.** See the remark in E2.
- **D7. (LB1) for tuples.**
  - *The unitary proof.* The Kazhdan boundary inequality places `P_W` in `pi (x) pi-bar` and uses
    that this representation has no invariant vectors.
  - *Why the rank version dies.* For a tuple, `rho (x) rho-bar` on `M_d` fixes `I` exactly. Its
    relator defects `rho(r) (x) rho(r)-bar - I` have rank up to `2kd`. So neither the "no invariant
    vector" input nor the rank control survives. The failing step is the invariant-vector exclusion.

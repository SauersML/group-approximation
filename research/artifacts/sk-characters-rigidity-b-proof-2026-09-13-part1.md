# Character rigidity of G_X, part 1: tower unit groups and constant characters

Lane sk-characters-rigidity-b, 2026-09-13. A written proof, UNREVIEWED. Part 2 has the dichotomy, the Bessel
step, the theorem, corollaries and firewalls.

**Notation.** `H_C` is the height of a tower `C`. `h[C]` is the component of a group element `h` in the factor of
that tower.

## 0. Statement

- `X` is an infinite minimal Cantor system with homeomorphism `T`, e.g. an infinite minimal subshift. So `T` has
  no periodic points, and `X` has no isolated points.
- `R = LC(X,F_2) ⋊_T Z` with `u f u^{-1} = f∘T^{-1}`, so `u e_U = e_{TU} u`. Every element of `R` is uniquely
  `Σ_j f_j u^j`.
- `G = EL_3(R)` is generated by `e_ij(r) = I_3 + rE_ij`, `i ≠ j`.
- A *character* is a positive definite class function `χ` with `χ(e) = 1`. Its GNS data is `(π, H, ξ)`, with
  `M = π(G)''` and `τ(x) = ⟨xξ,ξ⟩`.
  - `τ` is a normal tracial state on `M`.
  - It is faithful: `τ(x*x) = 0` gives `‖xπ(g)ξ‖² = τ(π(g)*x*xπ(g)) = τ(x*x) = 0` for every `g`, and `ξ` is cyclic.

**Theorem R.** Every character of `G` equals `a·1 + (1−a)δ_e` for some `a ∈ [0,1]`. In particular every extreme
character is `1` or `δ_e`.

Finite generation, property (T) and the simplicity of `G` are never used. The same proof works for `EL_n`,
`n ≥ 3`, with `3` replaced by `n`.

**Import (I1): Larsen–Tiep, Theorem A.** From *Uniform character bounds for finite classical groups*,
arXiv:2403.09046v1 (14 Mar 2024), p. 2, read from the PDF on 2026-09-13:

> "Theorem A. There exists an absolute constant c > 0 such that for all finite quasisimple groups G of Lie type,
> irreducible characters χ of G, and elements g ∈ G, we have
> (1.1)  |χ(g)| ≤ χ(1)^{1−c·log|g^G|/log|G|}."

## 1. Tower algebras and the locally finite groups L_y

**Towers.** Let `B` be a nonempty clopen set and `𝒬` a clopen partition of `X`.
- The return time `r_B(x) = min{j ≥ 1 : T^j x ∈ B}` is finite and bounded on `B`, by minimality and compactness.
- Partition `B` into clopen *bases* `C` so that on each `C` the return time `H_C` is constant, and so is the
  itinerary `(atom of 𝒬 containing T^a x)_{0≤a<H_C}`.
- The *levels* `T^aC` (`0 ≤ a < H_C`) partition `X`. Call this Kakutani–Rokhlin partition `𝒫`.
- A point `x` in level `a` of tower `C` has `Tx ∈ B` iff `a = H_C − 1`. So the top levels are exactly `T^{-1}B`,
  and the base levels are `B`.

**Matrix units.** Put `E^C_{ab} := e_{T^aC} u^{a−b}` for `0 ≤ a,b < H_C`. Then
`E^C_{ab}E^{C'}_{a'b'} = e_{T^aC} e_{T^{a−b+a'}C'} u^{a−b+a'−b'} = T^a`-translate of `e_C e_{T^{a'−b}C'}`, times a
power of `u`.
- If `C = C'` and `a' = b`, this is `E^C_{ab'}`.
- Otherwise `C ∩ T^jC' = ∅` for `j = a'−b ∈ (−H_C, H_{C'})`:
  - for `j ≥ 0`, `T^jC'` and `C` are distinct levels;
  - for `j < 0`, apply `T^{-j}`.

So `E^C_{ab}E^{C'}_{a'b'} = δ_{CC'}δ_{ba'}E^C_{ab'}` and `Σ_{C,a}E^C_{aa} = 1`. Hence
`A(𝒫) := span_{F_2}{E^C_{ab}} ≅ ⊕_C M_{H_C}(F_2)` is a unital subalgebra of `R`.

**Nesting.** Fix `y ∈ X`, clopen sets `B_1 ⊇ B_2 ⊇ …` with `⋂ B_n = {y}`, and clopen partitions `𝒬_1 ≤ 𝒬_2 ≤ …`
such that every clopen set is a union of atoms of some `𝒬_n`. Build `𝒫_n` with base `B_n`, refining the bases so
that every level of `𝒫_n` lies in an atom of `𝒬_n` and in a level of `𝒫_{n−1}`. Call `(𝒫_n)` a *nested system at y*.
- For `x ∈ B_n ⊆ B_{n−1}`, the return segment `x, …, T^{H_{C'}−1}x` to `B_n` ends just before a point of `B_{n−1}`.
  So it is a concatenation of full return segments to `B_{n−1}`.
- The itinerary through levels of `𝒫_{n−1}` is constant on each base `C'`. So every tower `C'` of `𝒫_n` is a
  concatenation of full towers of `𝒫_{n−1}`.
- A *passage* `(C', c)` of `C'` through `C` means `T^{c+a}C' ⊆ T^aC` for `0 ≤ a < H_C`. The set `T^aC` is the
  disjoint union of the sets `T^{c+a}C'` over all passages through `C`. So
  `E^C_{ab} = Σ_{passages (C',c) through C} E^{C'}_{c+a,c+b}`.
- Hence `A(𝒫_{n−1}) ⊆ A(𝒫_n)` is unital and block diagonal, with multiplicities given by the passages. The same
  holds for `A(𝒫_m) ⊆ A(𝒫_n)` with `m ≤ n`, since the towers of `𝒫_n` are also concatenations of full towers of
  `𝒫_m`.

Put `R_y := ⋃_n A(𝒫_n)`, `L_n := GL_3(A(𝒫_n)) ≅ ∏_C GL_{3H_C}(F_2)`, and `L_y := ⋃_n L_n`. So `L_y` is locally
finite.

**Lemma 1.**
- (i) `L_n ⊆ G`.
- (ii) `min_{C} H_C → ∞` as `n → ∞`, over the towers of `𝒫_n`.
- (iii) Let `m ≤ n` and `C_0` a base of `𝒫_m`. Choose `L` with `X = ⋃_{0≤i<L} T^{-i}C_0`. Then every tower `C'` of
  `𝒫_n` has at least `⌊H_{C'}/L⌋` passages through `C_0`.

*Proof.*
- (i) Index the coordinates of the factor `GL_{3H_C}(F_2)` by `(p,a)`, `1 ≤ p ≤ 3`, `0 ≤ a < H_C`. Transvections
  generate `GL_{3H_C}(F_2) = SL_{3H_C}(F_2)`.
  - The transvection between `(p,a)` and `(q,b)` with `p ≠ q` is `e_pq(E^C_{ab}) ∈ G`, as an element of `GL_3(R)`
    acting trivially on the other towers.
  - For `p = q` and `a ≠ b`, pick `p' ≠ p`. Then `t_{(p,a),(p,b)} = [t_{(p,a),(p',a)}, t_{(p',a),(p,b)}]` in the factor,
    by `[t_{xy},t_{yz}] = t_{xz}` for distinct coordinates.

  `L_n` is the product of these factors.
- (ii) Given `J`, the points `T^j y`, `0 < |j| < J`, differ from `y`. So some neighborhood `O` of `y` satisfies
  `O ∩ T^jO = ∅` for `0 < j < J`. By compactness `B_n ⊆ O` for large `n`, and then every return time is at least `J`.
- (iii) Such `L` exists by minimality and compactness: forward orbits are dense and `C_0` is open.
  - A tower `C'` of `𝒫_n` is traversed by an orbit segment of length `H_{C'}` that decomposes into full towers of
    `𝒫_m`.
  - Each visit `T^cx ∈ C_0 ⊆ B_m` starts a full passage through `C_0`, and there are at least `⌊H_{C'}/L⌋` visits. ∎

**Support.** For `x ∈ GL_N(F_2)`, `supp(x)` is the codimension of its largest eigenspace over `F̄_2`.

**Lemma 1′.** Let `h ∈ L_m ∖ {1}`, let `C_0` be a base of `𝒫_m` with `h[C_0] ≠ 1`, and `L` as in Lemma 1(iii). For
`n ≥ m` and every tower `C'` of `𝒫_n`, the component `h[C']` satisfies `supp(h[C']) ≥ ⌊H_{C'}/L⌋`.

*Proof.*
- By nesting, `h[C']` is block diagonal, with the block `h[C]` on the coordinates `{(p,c+a)}` of each passage
  `(C',c)` through `C`.
- For `λ ∈ F̄_2`, `h[C_0] − λ` is nonzero: `h[C_0] ≠ 1` has entries in `F_2`, and `F_2^× = {1}`. So its rank is at
  least 1.
- So `dim ker(h[C'] − λ) ≤ 3H_{C'} − #{passages through C_0}`, and Lemma 1(iii) finishes. ∎

## 2. Two points generate G

**Lemma 2.** Let `y ≠ y'`, and let `(𝒫_n)` and `(𝒫'_m)` be nested systems at `y` and `y'`. Then
`G = ⟨L_y, L_{y'}⟩`.

*Proof.*
- **Reduction.** By `e_ij(r+s) = e_ij(r)e_ij(s)` and `[e_ik(r),e_kj(s)] = e_ij(rs)`, the set of `r` with `e_ij(r)`
  in `⟨L_y,L_{y'}⟩` for all `i ≠ j` is a subring. `R` is generated by the `e_D` (`D` clopen, including `D = X`) and
  `u^{±1}`, so it suffices to treat these.
- **Idempotents.** For large `n`, a clopen `D` is a union of levels of `𝒫_n`. So `e_D ∈ A(𝒫_n)` and
  `e_ij(e_D) ∈ L_n`.
- **The unit u.** Choose `n` with `y' ∉ B_n`. Then choose `m` with `B'_m ∩ B_n = ∅` and `B_n`, `T^{-1}B_n` unions of
  levels of `𝒫'_m`.
  - Write `u = s + t` with `s = ue_{X∖T^{-1}B_n}` and `t = ue_{T^{-1}B_n}`.
  - `X ∖ T^{-1}B_n` is the union of the non-top levels of `𝒫_n`. So `s = Σ_{C, a<H_C−1} e_{T^{a+1}C}u =
    Σ E^C_{a+1,a} ∈ A(𝒫_n)`.
  - A level `D ⊆ T^{-1}B_n` of `𝒫'_m` is not a top level of `𝒫'_m`, because `T^{-1}B_n ∩ T^{-1}B'_m = ∅`. So
    `ue_D = E'^{C'}_{a+1,a}` and `t ∈ A(𝒫'_m)`.
  - Then `e_ij(u) = e_ij(s)e_ij(t)`, with `e_ij(s) ∈ L_n` (it is invertible, with inverse `e_ij(−s)`) and
    `e_ij(t) ∈ L'_m`.
- **The inverse.** `u^{-1} = u^{-1}e_{X∖B_n} + u^{-1}e_{B_n}`. The first summand is `Σ E^C_{a−1,a}` over non-base
  levels. A level `D ⊆ B_n` of `𝒫'_m` avoids `B'_m`, so it is a non-base level, and the second summand lies in
  `A(𝒫'_m)`. ∎

## 3. Characters are constant on L_y ∖ {1}

**Lemma 3 (bound).** Fix `α > 0` and let `c` be the constant of (I1). For `N ≥ max(3, 2/√α)`, every nontrivial
`χ ∈ Irr(GL_N(F_2))` and every `x` with `supp(x) ≥ αN` satisfy `|χ(x)|/χ(1) ≤ δ_α(N) := ⌊N²/4⌋^{−cα/2}`. In
particular `δ_α(N) → 0` as `N → ∞`.

*Proof.*
- `G_N = GL_N(F_2) = SL_N(F_2)` is simple for `N ≥ 3`, hence quasisimple of Lie type, and (I1) applies.
- **Class size.**
  - For one eigenvalue with Jordan partition `μ`, the commutant has dimension `Σ_k (μ'_k)² ≤ μ'_1·Σ_k μ'_k`, that is
    (eigenspace dimension)·(algebraic multiplicity).
  - Summing over eigenvalues, `dim_{F̄_2} C_{M_N}(x) ≤ (N − supp x)·N`. The commutant is the solution space of
    linear equations over `F_2`, so `|C_{G_N}(x)| ≤ 2^{N(N−supp x)}`.
  - `|G_N| = 2^{N²}∏_{j=1}^N(1−2^{−j}) ≥ 2^{N²}/4`. So `log_2|x^{G_N}| ≥ N·supp(x) − 2`, and `log_2|G_N| ≤ N²`.
  - With `supp(x) ≥ αN`, `log|x^G|/log|G| ≥ α − 2/N² ≥ α/2`, since `N² ≥ 4/α`.
- **Degree.**
  - A nontrivial irreducible representation of the simple group `G_N` is faithful.
  - `G_N` contains the elementary abelian unipotent radical `{[[I,A],[0,I]]}` of order `2^{⌊N²/4⌋}`.
  - The kernels of the linear constituents on it intersect trivially, so they span its dual of rank `⌊N²/4⌋`. So
    `χ(1) ≥ ⌊N²/4⌋`.
- **Combine.** `|χ(x)|/χ(1) ≤ χ(1)^{−c·α/2} ≤ ⌊N²/4⌋^{−cα/2}`. ∎

**Lemma 4 (constancy).** Let `χ` be a character of `G`, `y ∈ X`, and `(𝒫_n)` any nested system at `y`. There is
`c_χ ∈ [0,1]` with `χ(h) = c_χ` for every `h ∈ L_y ∖ {1}`. Moreover `c_χ = χ(e_12(e_P))` for every nonempty clopen
`P`, so `c_χ` depends neither on `y` nor on the nested system.

*Proof.*
- **Trivial weights.** `χ|_{L_n}` is a normalized positive definite class function on the finite group `L_n`, so
  `χ|_{L_n} = Σ_ρ c^{(n)}_ρ χ_ρ/ρ(1)` with `c^{(n)}_ρ ≥ 0` summing to 1. The trivial weight is
  `c^{(n)}_triv = |L_n|^{-1}Σ_{x∈L_n}χ(x) = τ(p_{L_n})`, where `p_{L_n} = |L_n|^{-1}Σ_{x∈L_n}π(x)` is the projection onto
  the `L_n`-fixed vectors.
- **Monotone limit.** The `p_{L_n}` decrease, so `c^{(n)}_triv ↓ c_χ := τ(p_{L_y})`.
- **Nontrivial weights are small.** Fix `h ∈ L_m ∖ {1}`, `C_0` with `h[C_0] ≠ 1`, and `L` from Lemma 1(iii). Let
  `n ≥ m` and `ρ = ⊗_{C'}ρ_{C'} ∈ Irr(L_n)` be nontrivial, with a nontrivial factor `ρ_{C'}`. Then
  `|χ_ρ(h)|/ρ(1) ≤ |χ_{ρ_{C'}}(h[C'])|/ρ_{C'}(1)`.
- **Apply Lemma 3.** Take `N = 3H_{C'}` and `α = 1/(4L)`. Once `H_{C'} ≥ 4L`, Lemma 1′ gives
  `supp(h[C']) ≥ H_{C'}/L − 1 ≥ N/(4L)`. So the ratio is at most `δ_α(3·min_C H_C)`, which tends to 0 by Lemma 1(ii).
- **Conclude.** `|χ(h) − c^{(n)}_triv| ≤ δ_α(3·min_C H_C) → 0`, so `χ(h) = c_χ`.
- For clopen `P ≠ ∅`, `e_12(e_P)` lies in `L_y ∖ {1}`, for every nested system. ∎

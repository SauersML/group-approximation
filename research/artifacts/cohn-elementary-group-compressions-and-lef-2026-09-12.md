# Cohn-pair compressions and the LEF question for EL_3(C_2)

Lane `w5-cohn-lef`, 2026-09-12. `C_2 = F_2<s_0, s_1, t_0, t_1 | t_i s_j = delta_ij>` is the binary Cohn
algebra, `J = F_2<S, T | TS = 1>` the Jacobson algebra, `R = L_(F_2)(1,2)`, and `G = EL_3(C_2)`.
The question: is `G` characteristic-two linear sofic? By
`cohn-coefficient-el3-rank-models-satisfy-two-root-identity`,
`two-root-identity-in-all-models-iff-no-nontrivial-model` and
`cohn-elementary-group-rank-radical-is-trivial-or-everything`, the open two-root identity for
`EL_3(C_2)` holds iff `G` has no injective characteristic-two rank model.

## 0. Summary

1. **Theorem 1.3 (compression).** In any ring with a Cohn pair, `g -> iota(g) + q` is an injective
   homomorphism `GL_(2n)(S) -> GL_n(S)`. For `n >= 2` it maps `EL_(2n)(S)` into `EL_n(S)`.
2. **Section 2 (consequences for C_2).**
   - `EL_m(C_2)` embeds in `EL_n(C_2)` for all `m, n >= 2`.
   - `EL_m(J) <= EL_3(C_2)` for every `m`.
   - The injective-model question is the same for every `EL_n(C_2)`, `n >= 2`.
   - With the landed rank-four lift, `V <= EL_3(C_2)`. So the V gate implies the two-root identity for
     `EL_3(C_2)`, and not only for `EL_4(C_2)`.
3. **Theorem 3.1 (task 1, negative).** `EL_n(J)` is not LEF for `n >= 4`, so `G` is not LEF. The LEF
   route to a "yes" is dead.
4. **Section 4 (where it stops).** Soficity and linear soficity of `G` are undecided. `G` sits between
   `V` and `R^x`. Task 3, transvection displacement, and task 4, comparison with `EL_5(J)`.

## 1. The compression embedding

**Setting.** `S` is a unital ring, and `s_0, s_1, t_0, t_1 in S` satisfy `t_i s_j = delta_ij`.
Put `q = 1 - s_0 t_0 - s_1 t_1`.

**Lemma 1.1.** `t_j q = 0`, `q s_i = 0` and `q^2 = q`.

*Proof.*
- `t_j q = t_j - sum_i (t_j s_i) t_i = t_j - t_j = 0`.
- `q s_i = s_i - sum_k s_k (t_k s_i) = s_i - s_i = 0`.
- `q^2 = q - sum_i s_i (t_i q) = q`. QED

Define `iota : M_2(S) -> S` by `iota(x) = sum_(a,b in {0,1}) s_a x_ab t_b`.

**Lemma 1.2.** `iota` is additive and multiplicative. It is injective, `iota(1_2) = 1 - q`, and
`iota(x) q = q iota(x) = 0`.

*Proof.*
- **Multiplicative:** `iota(x) iota(y) = sum s_a x_ab (t_b s_c) y_cd t_d = sum s_a (xy)_ad t_d = iota(xy)`.
- **Injective:** `t_c iota(x) s_d = x_cd`.
- **Absorbs q:** follows from Lemma 1.1. QED

Index `M_(2n)(S) = M_n(M_2(S))` by pairs `(i, a)` with `1 <= i <= n` and `a in {0,1}`. Let `iota_n`
apply `iota` blockwise.

**Theorem 1.3.** `psi_n(g) = iota_n(g) + q 1_n` defines an injective group homomorphism
`psi_n : GL_(2n)(S) -> GL_n(S)`. For `i != j`,

```text
psi_n( x_((i,a),(j,b))(c) ) = x_ij( s_a c t_b ),                                     (CP1)
```

and for `n >= 2`, `psi_n(EL_(2n)(S)) <= EL_n(S)`.

*Proof.*
1. **Homomorphism.** `iota_n` is multiplicative and `iota_n(g) (q 1_n) = (q 1_n) iota_n(g) = 0`
   entrywise. So `psi_n(g) psi_n(h) = iota_n(gh) + q 1_n = psi_n(gh)`, and `psi_n(1) = (1-q) 1_n + q 1_n = 1`.
2. **Injective:** `iota` is injective.
3. **(CP1).** The diagonal blocks of the generator are `1_2`, and `iota(1_2) + q = 1`. Its `(i,j)`
   block is `c e_ab`, and `iota(c e_ab) = s_a c t_b`.
4. **Generation.** Let `n >= 2`. A same-block generator `x_((i,a),(i,b))(c)` with `a != b` equals
   the commutator `[x_((i,a),(j,0))(c), x_((j,0),(i,b))(1)]` for any `j != i`, because the three
   indices are distinct. So `EL_(2n)(S)` is generated by cross-block generators, and by (CP1) their
   images are elementary. QED

**Remark 1.4.** For `n = 1` the image of `EL_2(S)` lies in `S^x`, and nothing is elementary. The
rank condition `n >= 2` is needed only in step 4.

**Remark 1.5 (symbols).** A unital ring map `pi : S -> S'` carries the Cohn pair to a Cohn pair, and
`pi o psi_n = psi'_n o pi`.
- **The quotient case:** for `S = C_2 -> S' = R` we have `pi(q) = 0`, so `psi'_n` is the Leavitt
  isomorphism `GL_(2n)(R) ~ GL_n(R)`. It is injective.
- **Consequence:** with `K_m = ker(EL_m(C_2) -> EL_m(R)) = GL_fin(W x m, F_2)`, `psi_n` maps `K_(2n)`
  into `K_n`, and maps elements outside `K_(2n)` to elements outside `K_n`.
- **Transvections:** `psi_n` sends a finitary matrix unit `e_(w,v)` in block `(i,a),(j,b)` to the
  matrix unit `e_(aw, bv)` in block `(i,j)`. So finitary transvections go to finitary transvections.

## 2. Consequences for the binary Cohn algebra

**Corollary 2.1.** For all `m, n >= 2`, `EL_m(C_2)` embeds in `EL_n(C_2)`.

*Proof.* `EL_m(C_2) <= EL_(2^k n)(C_2)` through the upper-left block for large `k`. Then compose
`psi_n o psi_(2n) o ... o psi_(2^(k-1) n)`. QED

**Corollary 2.2.** `EL_m(J) <= EL_3(C_2)` for every `m`.

*Proof.* `J -> C_2`, `S -> s_0`, `T -> t_0`, is a unital embedding (Lemma 2.1 of
`research/artifacts/cohn-elementary-group-rank-radical-2026-09-12.md`), so `M_m(J) <= M_m(C_2)`.
Now apply Corollary 2.1. QED

**Corollary 2.3.** For every `n >= 2`, `EL_n(C_2)` has an injective characteristic-two rank model
iff `EL_3(C_2)` does.

*Proof.* Restricting an injective model along an injective homomorphism gives an injective model.
Use Corollary 2.1 in both directions. QED

With the landed dichotomies (nontrivial iff injective, for `n = 3, 4`), the target claim and the
rank-four ordering in `thompson-v-lifts-into-rank-four-cohn-elementary-group` concern one and the
same question.

**Corollary 2.4 (V in rank three).** Let `phi : V -> GL_2(C_2)` be the lift of
`thompson-v-lifts-into-rank-four-cohn-elementary-group`, with `phi(V) (+) 1_2 <= EL_4(C_2)`. Then
`V' = psi_3(phi(V) (+) 1_4) <= EL_3(C_2)`, where `EL_4 <= EL_6` through the upper-left block. Also
`V' ~ V`, and `V'` meets `K = K_3` only in `1`.

*Proof.*
1. **Embedding:** `psi_3` is injective (Theorem 1.3).
2. **Trivial intersection:** `pi o phi = diag(g, 1)` is injective on `V`. By Remark 1.5,
   `pi o psi_3 = psi'_3 o pi` is injective on the image, so no nontrivial element of `V'` lies in
   `K`. QED

**Corollary 2.5 (V gate implies the Cohn identity).** Suppose every characteristic-two rank model
of `V` is trivial (`thompson-v-has-no-nontrivial-f2-rank-model`). Then every characteristic-two rank
model of `G = EL_3(C_2)` is trivial. So `N_23 N_12 = 0` holds in all of them.

*Proof.*
1. Let `sigma` be a model of `G`. Its kernel is a normal subgroup of `G`, so it is `1`, `K` or `G`
   (`cohn-elementary-group-rank-radical-is-trivial-or-everything`).
2. `sigma` restricted to `V'` is a model of `V`, hence trivial. So `V' <= ker sigma`.
3. `V'` is nontrivial and meets `K` trivially (Corollary 2.4), so `ker sigma` is neither `1` nor `K`.
   Hence `ker sigma = G`. QED

So the ordering landed by w4-cohn-el3 sharpens to:

```text
V gate  =>  Cohn EL_3 identity  =>  binary gate for R^x,        (CP2)
```

and, on the linear-sofic side,

```text
R^x F_2-linear sofic  =>  EL_3(C_2) F_2-linear sofic  =>  V F_2-linear sofic.        (CP3)
```

(CP3) comes from `V' <= G <= R^x`, since a linear sofic approximation restricts to subgroups.

## 3. G is not LEF

**Theorem 3.1.** For `n >= 4`, `EL_n(J)` is not LEF. Hence no `EL_m(C_2)` with `m >= 2` is LEF; in
particular `G` is not.

*Proof.* Put `Q = 1 - ST` and `e_ab = S^a Q T^b`, the finitary matrix units of `J`, with
`e_ab e_cd = delta_bc e_ad`.
1. **Finite images kill `x_13(Q)`.** Let `Gamma` be a group containing elements `x_ij(r)`
   (`i != j <= 3`, `r in J`) that satisfy `x_ij(r) x_ij(r') = x_ij(r + r')` and
   `[x_ij(r), x_jk(r')] = x_ik(r r')` for distinct `i, j, k`. Let `f : Gamma -> F` be a homomorphism
   to a finite group.
   - By pigeonhole, `f(x_13(e_a0)) = f(x_13(e_a'0))` for some `a != a'`, so `f(x_13(r)) = 1` with
     `r = e_a0 + e_a'0`.
   - `f(x_12(r)) = f([x_13(r), x_32(1)]) = 1`.
   - `f(x_32(e_0a r)) = f([x_31(e_0a), x_12(r)]) = 1`, and `e_0a r = e_00 = Q`.
   - `f(x_12(Q)) = f([x_13(1), x_32(Q)]) = 1`, and `f(x_13(Q)) = f([x_12(Q), x_23(1)]) = 1`.
2. **Finite presentation.** `J` is finitely presented, so `St_4(J)` is finitely presented
   (`steinberg-finite-presentation-and-kazhdan-theorem`, imported at statement level). Fix a finite
   presentation with generating set `X` of Steinberg generators (over `F_2` each is an involution),
   finitely many relators, and a word `w` in `X` representing `x_13(Q)`.
3. **LEF would give a finite image keeping `x_13(Q)`.** Suppose `EL_4(J)` is LEF, and let
   `pi : St_4(J) -> EL_4(J)`.
   - **The ball:** let `B` be the finite set of `pi`-images of all prefixes of the relators and of `w`,
     together with `1` and `pi(X)`.
   - **The partial embedding:** LEF gives a finite group `F` and an injective `beta : B -> F` with
     `beta(b b') = beta(b) beta(b')` whenever `b, b', b b' in B`.
   - **The homomorphism:** along each relator the prefix products are respected, so `x -> beta(pi(x))`
     defines a homomorphism `f : St_4(J) -> F`.
   - **The contradiction:** `f(w) = beta(x_13(Q)) != beta(1) = 1` by injectivity, since
     `x_13(Q) != 1`. This contradicts step 1 applied to `Gamma = St_4(J)`.
4. **Subgroups.** LEF passes to subgroups. `EL_4(J) <= EL_n(J)` for `n >= 4`, and
   `EL_4(J) <= EL_m(C_2)` for every `m >= 2` by Corollaries 2.1 and 2.2. QED

**Remark 3.2.** `G` is not residually finite for a simpler reason: `K` is infinite and simple, so
every finite image of `G` kills it. Non-LEF is stronger, and needs the finitely presented cover.

**Remark 3.3 (what dies).**
- **Task 1:** local embeddability cannot prove `G` sofic, hence cannot refute the Cohn identity.
- **Any construction built from exact partial homomorphisms on growing balls of `G`:** that is LEF
  again.
- **Level-factoring models:** in the sense of `transvection-displacement-forces-exact-local-embedding`,
  models of this kind with positive transvection displacement would give exact local embeddings, so
  they cannot be faithful on `G`. That node is stated for `R^x`; this transfer is a remark, not
  checked in detail.

## 4. Where it stops

**4.1 Soficity and linear soficity of G: undecided.**
- **Linear soficity:** by (CP3), `G` linear sofic sits between `R^x` (above) and `V` (below).
  - The target, "no injective model of `G`", is implied by the V gate and implies the binary gate.
  - A proof that `G` is not linear sofic would already show `R^x` is not.
- **Soficity:** a sofic approximation of `G` restricts to `V'`, so soficity of `G` would make `V`
  sofic, which is open.
- **Jacobson route:** `binary-jacobson-el3-rank-radical-is-the-finitary-kernel` gives the target
  (landed route). By Corollary 2.2, its rank-4 and rank-5 forms would too.

**4.2 Transvection displacement (task 3).**
- **Checked, and a proof:** all finitary transvections are conjugate in `K`, and rank is conjugation
  invariant. So `d(sigma) = rk(sigma(t) - 1)` is one number, and `d > 0` for every nontrivial model,
  because nontrivial models are injective. This part of Section 5 of the w4-cohn-el3 artifact is a
  proof, not a heuristic.
- **The heuristic** (polynomially bounded dimension forces bounded degree) **is not needed, and
  displacement alone rules out nothing.**
  - **Middle exterior powers:** `t = 1 + e_21` acts on `Lambda^j(F_2^m)` as `1 + N`, where `N` has
    rank `C(m-2, j-1)` (the `j`-subsets containing 1 and not 2). So the normalized displacement is
    `C(m-2, j-1)/C(m, j)`, which tends to `1/4` at `j ~ m/2`.
  - **Consequence:** level representations with displacement bounded below exist at every level.

**4.3 Comparison with EL_5(J) (task 4).**
- **Shared:**
  - no completeness relation;
  - an infinite simple locally finite finitary kernel;
  - neither is residually finite, and neither is LEF.
- **The relation that differs:** `C_2` has two orthogonal isometries, and `J` has one.
  - **For `C_2`:** the Cohn pair gives the compression `psi`, so `EL_3(C_2)` contains every
    `EL_m(C_2)`, every `EL_m(J)` and `V`.
  - **For `J`:** a single isometry gives no compression.
- **V does not embed in any `EL_n(J)`.**
  - **Setup:** `V` is infinite, simple and finitely generated, and has elements of infinite order.
  - **Two cases:** `V` meets the finitary kernel `GL_fin(N x n, F_2)` in `1` or in `V`. The second is
    impossible, because the kernel is locally finite. The first embeds `V` in the finitely generated
    linear group `EL_n(F_2[z, z^(-1)])`, which is residually finite (Mal'cev). An infinite simple
    group is not.
- **Consequence:** the V gate reaches `G` and not `EL_n(J)`. The Jacobson route and the V route
  into the Cohn identity are independent inputs.

**4.4 Not done.** No injective model of `G` is constructed, and no obstruction beyond (CP2) is
proved. The question stays open.

## 0. Conventions

- Rings are unital and associative; ring homomorphisms are unital. `EL_n(R)` is generated by `e_ij(r) = I + r E_ij`, `i != j`.
- **Algebraic ultraproduct.** For rings `R_i` and a nonprincipal ultrafilter `ω` on a countable index set, `∏_ω R_i` is the
  product modulo sequences vanishing on an ω-large set. An identity holds in `∏_ω R_i` iff it holds coordinatewise on an
  ω-large set.
- **Matricial.** `R` is *matricial over fields `(F_i)`* if it embeds unitally in `∏_ω M_(N_i)(F_i)`. It is *matricial over `k`*
  if every `F_i = k`. A **LEF ring** is one that is matricial over finite fields, which may vary with `i`.
- **Sylvester matrix rank function** (Malcolmson's axioms). A function `rk` on all rectangular matrices over `R` with values in
  `[0, ∞)` such that:
  - (S1) `rk(0) = 0` and `rk(1) = 1`;
  - (S2) `rk(AB) <= min(rk A, rk B)`;
  - (S3) `rk(A ⊕ B) = rk A + rk B`;
  - (S4) `rk [[A, C], [0, B]] >= rk A + rk B`.

  It is **faithful** if `rk(x) > 0` for every `x != 0` in `R`.
- **Rank-metric matricial.** `R` embeds unitally in a metric ultraproduct `∏_ω M_(N_i)(F_i) / Ker(ρ_ω)`, where `ρ_ω` is the
  ω-limit of normalized rank. This is "linear sofic" in Greenfeld's sense, quoted in `stably-finite-algebras-need-not-be-linear-sofic`.
- **Groups.**
  - *LEF.* For every finite `F ⊆ G` there are a finite group `Q` and an injective `σ: F → Q` with `σ(gh) = σ(g)σ(h)` whenever
    `g, h, gh ∈ F`.
  - *MF.* Quoted verbatim from `non_mf_groups_exist.tex` l.87–95 (tip 1b40532869): "A countable group $G$ is
    \emph{MF}~\cite{CDE} if there are positive integers $d_n$ and maps $V_n\colon G\to\U(d_n)$, with $V_n(1)=1$, such that
    \[ \opnorm{V_n(gh)-V_n(g)V_n(h)}\longrightarrow0 \qquad(g,h\in G), \] and
    \[ \limsup_n\opnorm{V_n(g)-1}>0 \qquad(g\in G\setminus\{1\}). \]"
  - *Linear sofic over `F_q`.* `G` embeds in the units of a rank-metric ultraproduct of matrix rings over `F_q`, with
    `ρ_ω(g − h) > 0` for `g != h`.
- **`V(R)` at `[1]`.**
  - *Paradoxical:* `R^2` is isomorphic to a direct summand of `R`, i.e. `2[1] <= [1]`. Equivalently there are
    `C ∈ M_(1×2)(R)` and `D ∈ M_(2×1)(R)` with `DC = I_2`.
  - *Infinite:* `R ≅ R ⊕ P` with `P != 0`.
  - *Finite:* not infinite.

## 1. General lemmas

**L1 (matricial ⇒ stably finite, with a rank function).** If `R` is matricial over any fields `(F_i)`, then `R` is stably finite,
and `rk_ω(A) = lim_ω rank(A_i) / N_i` is a Sylvester matrix rank function on `R`.

*Proof.* `M_m(∏_ω M_(N_i)(F_i)) = ∏_ω M_(m N_i)(F_i)`. If `AB = I_m` there, then `A_i B_i = I` on an ω-large set, hence
`B_i A_i = I` there by finite-dimensional linear algebra, so `BA = I`. Subrings of stably finite rings are stably finite. Each
normalized rank `rank(·)/N_i` satisfies (S1)–(S4), and ω-limits preserve these (in)equalities. ∎

The metric version, that every rank ultraproduct is stably finite, is quoted from Greenfeld in
`stably-finite-algebras-need-not-be-linear-sofic`.

**L2 (the rank-zero ideal; faithful ⇒ stably finite).** For a Sylvester matrix rank function, `N = {x ∈ R : rk(x) = 0}` is a
proper two-sided ideal. If `N = 0`, which is automatic when `R` is simple, then `R` is stably finite.

*Proof.*
- **`N` is a proper ideal.** By (S2), `rk(rx), rk(xr) <= rk(x)`. Since `x + y = (1 1) · diag(x, y) · (1 1)^T`, (S2) and (S3) give
  `rk(x + y) <= rk x + rk y`. So `N` is an ideal, and (S1) makes it proper.
- **Complementary idempotents.** For an idempotent `e ∈ M_m(R)`, the matrix `M = [[e, 1 − e], [1 − e, e]]` satisfies `M² = I`
  and `M · diag(I, 0) · M = diag(e, I − e)`. Multiplication by an invertible matrix preserves `rk` by (S2) applied both ways, so
  (S3) gives `rk(e) + rk(I − e) = rk(I_m) = m`.
- **Stable finiteness.** If `AB = I_m` in `M_m(R)`, put `e = BA`, an idempotent. Then `m = rk(A e B) <= rk(e) <= m`, so
  `rk(I − BA) = 0`. Every entry `x` of `I − BA` is `ε_i^T (I − BA) ε_j`, so `rk(x) = 0` and `x ∈ N = 0`. So `BA = I`. ∎

**L3 (paradox ⇒ no rank function).** If `DC = I_2` with `C ∈ M_(1×2)(R)` and `D ∈ M_(2×1)(R)`, then `R` has no Sylvester matrix
rank function.

*Proof.* `2 = rk(I_2) = rk(DC) <= rk(C) = rk(I_1 · C) <= rk(I_1) = 1`. ∎

**L4 (LEF ring ⇒ LEF group ⇒ MF and sofic).** Let `R` be matricial over finite fields `(F_i)`.
1. `GL_n(R)`, and hence `EL_n(R)`, embeds in `∏_ω GL_(n N_i)(F_i)`.
2. Every countable subgroup of `GL_n(R)` is LEF.
3. A LEF group is MF and sofic.

*Proof.*
- **(1)** A unit maps to a unit in an ω-large set of coordinates, and injectivity is inherited.
- **(2)** For a finite `F ⊆ G`, the coordinates that are injective on `F` and multiplicative on `F × F` form an ω-large set.
  Any one of them is a LEF datum into the finite group `GL_(n N_i)(F_i)`.
- **(3), MF.** Take finite sets `F_n ↑ G` with LEF data `σ_n: F_n → Q_n`, and put `V_n = λ_(Q_n) ∘ σ_n` on `F_n` and
  `V_n = 1` elsewhere. For fixed `g, h`, `V_n(gh) = V_n(g) V_n(h)` once `g, h, gh ∈ F_n`. For `g != 1`, `λ(σ_n(g))` is a
  permutation matrix moving some basis vector, so `||V_n(g) − 1|| >= √2`.
- **(3), sofic.** The Pestov artifact §3 records "LEF implies sofic (Elek--Szabó, via left regular ...".
∎

**L5 (group rings).** For a countable group `Γ`, a prime power `q` and `n >= 2`, the following are equivalent:
(i) `F_q[Γ]` is a LEF ring; (ii) `Γ` is LEF; (iii) `EL_n(F_q[Γ])` is LEF.

*Proof.*
- **(ii) ⇒ (i).** Take LEF data `σ_i: F_i → Q_i` with `F_i ↑ Γ`, and put `ρ_i(Σ a_g g) = Σ_(g ∈ F_i) a_g λ_(Q_i)(σ_i(g))`.
  - Each `ρ_i` is additive.
  - If `supp x`, `supp y` and `supp x · supp y` lie in `F_i`, then `ρ_i(xy) = ρ_i(x) ρ_i(y)`.
  - The regular representation matrices `λ(q)`, `q ∈ Q_i`, are linearly independent, since `λ(q) δ_e = δ_q`. So
    `ρ_i(x) != 0` once `0 != x` has support in `F_i`.

  So `ρ = [ρ_i]` is a unital injective ring homomorphism into `∏_ω M_(|Q_i|)(F_q)`.
- **(i) ⇒ (ii).** `Γ ⊆ F_q[Γ]^×`, which embeds in `∏_ω GL_(N_i)(F_i)`. So `Γ` is LEF by L4.
- **(i) ⇒ (iii).** L4.
- **(iii) ⇒ (ii).** Put `w(u) = e_12(u) e_21(−u^(−1)) e_12(u) = [[0, u], [−u^(−1), 0]]`. Then
  `w(u) w(−1) = diag(u, u^(−1))`, so `g ↦ diag(g, g^(−1), 1, ..., 1)` embeds `Γ` in `EL_n(F_q[Γ])`, and LEF passes to
  subgroups. ∎

**L6 (Følner rank functions on crossed products): on main, not re-proved.** `free-minimal-crossed-products-are-simple-with-rank-models`
covers simplicity and rank-metric models for free minimal actions. The complement used in part 2: for any countable amenable `Γ`
acting on a Cantor set `X`, `R = LC(X, F_q) ⋊ Γ` acts on `F_q^(Γ)` by `π(f) δ_h = f(hx) δ_h`, `π(u_g) δ_h = δ_(gh)`. Truncation to
Følner sets `B_n` is multiplicative up to rank `O(|∂B_n|) = o(|B_n|)`. This gives a unital homomorphism into a rank-metric
ultraproduct over `F_q`, not necessarily injective, and hence a Sylvester rank function. With free minimal action, `R` is simple
(Steinberg, imported as `steinberg-algebra-simple-iff-minimal-effective`). Then L2 makes the rank function faithful, the model
injective, and `R` stably finite. Then
`g != h` in `EL_n(R)` gives a nonzero entry `x` of `g − h` with `rk(g − h) >= rk(x) > 0`, so `EL_n(R)` is linear sofic over `F_q`.

**L8 (the non-MF paper's ring criteria, quoted).**
- Cor l.1016: "If $R$ is a countable simple unital ring that is not directly finite, then every homomorphism from $\EL_n(R)$ to an
  MF group is trivial for every $n\ge2$. The same conclusion holds for $R=L_k(1,m)$, for every countable field $k$ and every
  $m\ge2$."
- Prop l.1072 (torsion complementary idempotents): "Let $R$ be a countable unital ring, let $s,t\in R$ satisfy $ts=1$, and suppose
  that $e=1-st$ has finite additive order. Then for every $n\ge4$, [$\EL_n(R,ReR)\le\Rad_{\mathrm{MF}}(\EL_n(R))$] ... In
  particular $\EL_n(R)$ is not MF when $e\ne0$, and if $R$ has positive characteristic, then $\EL_4(R)$ MF implies that $R$ is
  directly finite."
- On main from `un-paradox`: `stably-infinite-ring-elementary-groups-have-no-mf-quotient`. If `2n[1] <= n[1]` in `V(R)`, then
  every homomorphism from `EL_N(R)` (`N >= 2n`) to an MF group is trivial.

**Consequence for U3 (remark).** In positive characteristic, "EL_4(R) MF ⇒ R directly finite" is already in the paper for EVERY
countable ring (L8, Prop l.1072), with no simplicity hypothesis. The open implications start at stable finiteness.

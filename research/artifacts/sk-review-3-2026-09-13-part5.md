## 1. Theorem A

**Step 1 (Kakutani–Rokhlin columns).**
- A clopen b with T^jb ∩ b = ∅ for 0 < j < J exists because T has no periodic points.
- Minimality gives finite return times and ⋃_(n≥0) T^n b = X. Compactness leaves finitely many clopen C_j, and the levels partition X.
- Refining by the B-word makes each level inside B or disjoint from B.
- The sets b, …, T^(J−1)b are disjoint with equal measure, so μ(b) ≤ 1/J.

**Step 2 (pieces).**
- E has fewer than K levels of each column, so μ(E) ≤ Kμ(b) ≤ K/J.
- μ(piece_i) = Σ_c m_c μ(C_c) is independent of i, and the K pieces are disjoint, so ‖piece_i‖ ≤ 1/K.

**Step 3 (a copy of GL_(3K)(F_2)).**
- w_(a″,a′)w_(a′,a) = e_(T^(a″)C) u^(a″−a′) e_(T^(a′)C) u^(a′−a) = w_(a″,a). Products across distinct levels vanish.
- v_ij = v_(i1)v_(1j) = Σ w_(φ^(i)(a), φ^(j)(a)), and v_ij v_kl = δ_jk v_il because J^(j) ∩ J^(k) = ∅. So v_ii = e_(piece_i) and the unit is e_(B′).
- The pieces are nonempty (Step 7), so the span is M_K(F_2).
- Transvections:
  - p ≠ q gives e_pq(v_ij).
  - p = q with a = v_ij, b = v_jj gives ab = a, ba = 0, aba = 0, so [e_pr(a), e_rp(b)] = I + v_ij E_pp.
- So ι(GL_(3K)(F_2)) ≤ G, and ι is an injective homomorphism.

**Step 4 (restriction of scalars).**
- ρ: M_(3K′)(F_(2^k)) → M_(3K)(F_2) is unital and uses the same basis of F_(2^k) over F_2 in every row block.
- ιρ(∏_β(I + E_((1,β),(2,β)))) = I + e_(B′)E_12 = e_12(e_(B′)), and ιρ(t) = e_12(e_P) with ‖P‖ ≤ k/K = 1/K′.
- t is a non-central transvection of SL_(3K′)(F_(2^k)).

**Step 5 (Lemma 1.4).** ψ = χ∘ι∘ρ is positive definite with ψ(e) = 1, and ψ(x^(−1)tx) = χ(e_12(e_P)) because χ is a class function. The lemma with q = 2^k, n = 3K′ gives |1 − χ(e_12(e_(B′)))| < 9(2ε + 16/2^k)^(1/2).

**Step 6 (remainder).**
- (I2) is the GNS inequality |⟨(π(g) − π(h))ξ,ξ⟩|² ≤ ‖π(g)ξ − π(h)ξ‖² = 2 − 2Re ψ(g^(−1)h).
- g^(−1)h = e_12(e_(B′))e_12(e_B) = e_12(e_(B′) + e_B) = e_12(e_E) in characteristic 2.
- So |χ(e_12(e_B)) − χ(e_12(e_(B′)))|² ≤ 2|1 − χ(e_12(e_E))|.

**Step 7 (parameters).**
- 16/2^k < ε, K′ > 1/η and J > K/η give ‖P‖ < η and ‖E‖ < η.
- J > 2K/β_B gives μ(B′) ≥ β_B/2 for every μ. Here β_B = min_μ μ(B) > 0: the minimum is attained on the weak*-compact set M(X,T), and every invariant measure of a minimal system is full.
- The total bound is 9(3ε)^(1/2) + (2ε)^(1/2) → 0.

**Step 8 (simplicity).**
- ‖π(g_0)π(k)ξ − π(k)ξ‖² = 2 − 2Re χ(k^(−1)g_0k) = 0 on a cyclic dense set, so π(g_0) = 1.
- ker π is normal and contains the non-central g_0, so by simplicity π is trivial and χ ≡ 1.

PASS.

## 2. Corollaries

## 4. For the note

The theorem is short, true and striking: the Kazhdan simple group of X has no character continuous in measure, while the amenable simple group [[T]]′ of the same X has one for every invariant measure (Dudko–Medynets).

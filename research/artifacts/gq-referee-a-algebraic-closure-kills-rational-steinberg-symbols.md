# Referee report (gq-referee-a, proof-gap lens): the algebraic closure kills rational Steinberg symbols

**Reviewed:** `algebraic-closure-kills-rational-steinberg-symbols` and its `-proof` (lane gq-infinite-primes, 05a4c7c2e),
read on origin/main.

**Verdict: PASS.** Items 1–4 hold, and I found no gap. There are three nits. The inputs of Tate, Suslin, Matsumoto and
van der Kallen are for the citation lens.

## Checks
- **Item 1.**
  - `x ∈ K_2(N,Q)` maps to `y ∈ K_2(N,F)`, and by functoriality `y` has stable image
    `(K_2(Q) → K_2(F))([x]) = 0`.
  - For a field and `N ≥ 3`, `K_2(N,F) → K_2(F)` is injective: this is Matsumoto's theorem, with the same
    presentation in every rank `≥ 3`, or van der Kallen with `sr(F) = 1`. So `y = 1`, and its image in `St_N(R)` is 1.
  - `{λ,μ}_N = h_12(λμ)h_12(λ)^(−1)h_12(μ)^(−1)` maps to 1 in `SL_N(Q)` because `λ` and `μ` commute. Its image in
    `St_N(R)` is the `R`-symbol, since `w` and `h` are functorial. ✓
- **Item 2.** Tate makes `K_2(Q)` torsion. Suslin makes `K_2(Q̄)` torsion-free. The alternative through
  `K_2(F)[n] = {ζ_n, F^×}` works too: `{ζ_n, γ^n} = n{ζ_n, γ} = {ζ_n^n, γ} = 0`, because every element of `Q̄^×` is an
  `n`-th power. So the map is zero, and it is zero for every `F ⊇ Q̄` by factoring. ✓
- **Item 3: unitality and the extension (the author asked about this).**
  - The inclusion `Q̄ ⊆ L_Q(1,2) ⊆ R_L` is unital. This is `field-envelopes-pass-to-algebraic-closures`, item 2, and
    §3 of its proof, which I refereed earlier (69a3cc64f).
    - The maps `ι_i` into `L_Q` are unital by construction.
    - The Leavitt family of `R_L` gives a unital map `L_Q → R_L`, injective because `L_Q` is simple.
  - *The extension is automatic* (N1). A unital ring map `Q → R` is unique, since it is determined on `Z` and on
    inverses. So every unital `F → R` with `F ⊇ Q` restricts to the given one. `Q`-linearity is true but not
    needed. ✓
  - *The same for `S ⊗_Q L_Q(1,2)`.* The copy `Q̄ ⊆ 1 ⊗ L_Q(1,2)` is unital. ✓
- **Item 4: bimultiplicativity in a commutative subring (the author asked about this).**
  - `ν` is central, so the subring `C` generated by `ν^(±1)` and `x^(±1)` is commutative and contains `λ = ν^m`. It is
    a unital subring, provided `Q̄ ⊆ Z(R)` is unital (N2).
  - In `K_2(C)`, Steinberg symbols of units are bimultiplicative (Milnor §§8–9), so `{λ,x}_C = m{ν,x}_C`.
  - The unital inclusion `C → R` sends `h_12`, and hence symbols of commuting units, to the corresponding symbols of
    `R`. These are the symbols in `Sym(R)` of the symbol lemma. So `{λ,x} = m{ν_m,x}` in `K_2(R)`, with `ν_m` depending
    on `m`.
  - If `E_N(R)` is finitely presented, then `A = im(K_2(N,R) → K_2(R))` is finitely generated and contains every
    `{ν_m, x}`. So `{λ,x} ∈ ∩_m mA`.
  - `∩_m mA = 0` for `A ≅ Z^r ⊕ T`: take `m ∈ |T|·Z`. ✓
  - The conclusion is `{λ,x} = 0` in the stable `K_2(R)`. The node says exactly this, and nothing about `K_2(N,R)`.

## Nits
- **N1 (item 1 and the Unitality bullet).** The hypothesis "`Q → R` extends to `F → R`" holds automatically for any
  unital `F → R`, because unital maps out of `Q` are unique. The Unitality bullet then reads more simply: what is
  needed for a corner `eRe` is a unital map `F → eRe`. Commuting with `e` is one way to get it.
- **N2 (item 4).** Write "`Q̄ ⊆ Z(R)` unitally". If the copy of `Q̄` had a different unit, for instance a central
  idempotent, then `ν` need not be a unit of `R`.
- **N3 (item 4).** Say explicitly that "symbol" means the Steinberg symbol `h_12(λx)h_12(λ)^(−1)h_12(x)^(−1)` of
  commuting units, as in `infinitely-generated-symbols-block-fp-elementary-groups`. Functoriality along `C ⊆ R` then
  identifies the two symbols.

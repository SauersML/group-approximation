Setting: `Lambda = SL_3(Z) <= Gamma = SL_3(Z[1/3])`,
`W_3 = (direct_sum_{Gamma/Lambda} C_2) rtimes Gamma`, `S` a fixed finite

## Theorem R (centralizer rounding for Kazhdan actions)

Let `Lambda` be any finitely generated group with property (T), with
Kazhdan pair `(S, kappa)`.  Let `Lambda acts V` be ANY action on a
finite set, `tau : Lambda -> Sym(V)`, and let `P in Sym(V)` satisfy

```text
|{v in V : P tau(s) v != tau(s) P v}| <= eps |V|   for all s in S.
```

Then there is an EXACTLY `Lambda`-equivariant permutation `c in
C_{Sym(V)}(tau(Lambda))`-extended (an equivariant bijection of `V`,
i.e. an element of the centralizer group generated by per-orbit right
translations and swaps of isomorphic orbits) with

```text
|{v : P v != c v}| <= C eps |V| / kappa^2,
```

`C` an absolute constant, provided `eps < kappa^2 / C'`.

*Proof.*  Consider `G = graph(P) = {(v, Pv)} subset V x V` and the
diagonal action of `Lambda` on `V x V`.  Then

```text
|| 1_G circ (s, s)^{-1} - 1_G ||^2 = 2 |{v : P tau(s) v != tau(s) P v}| <= 2 eps |V|.
```

The `Lambda`-invariant functions on `V x V` are exactly the span of the
orbital indicators `1_O` (`O` a diagonal orbit).  By property (T)
applied to `ell^2(V x V) ominus invariants` (a representation with no
invariant vectors), almost-invariance gives

```text
|| 1_G - sum_O a_O 1_O ||^2 <= (C_0 eps / kappa^2) |V|,   a_O = |G cap O| / |O|,
```

and a direct computation shows the left side equals
`sum_O |O| a_O (1 - a_O)`.  Write the orbital out-degree `d_O` (each
row of `O` has `d_O` entries; `|O| = d_O^{(i)} |V_i|` on the component
`V_i` housing its rows).  Since `P` is a permutation, each row of `G`
has exactly one entry, so for each `Lambda`-orbit `V_i` of `V`:

```text
sum_{O with rows in V_i} a_O d_O = 1     (exactly).
```

Let `O+` be the orbitals with `a_O >= 1/2`.  From
`sum |O| a_O(1-a_O) <= (C_0 eps/kappa^2)|V|`, splitting by
`a(1-a) >= (1-a)/2` on `O+` and `>= a/2` off it,

```text
sum_{O+ rows in V_i} d_O in [1 - delta_i, 1 + delta_i],
sum_i |V_i| delta_i <= 4 C_0 eps |V| / kappa^2.
```

For each `i` with `delta_i < 1` the left side is a nonnegative integer
combination of integers `d_O >= 1`, hence EXACTLY one orbital `O_i^*`
with rows in `V_i`, `d_{O_i^*} = 1`, `a_{O_i^*} >= 1 - delta_i`.  A
degree-one orbital with rows in `V_i` and columns in `V_j` is the graph
of a `Lambda`-equivariant map `V_i -> V_j`; on a transitive `Lambda`-set
`V_i ~ Lambda/H`, equivariant maps to a transitive set are bijections
of the form induced by right translation (`qH -> q c H`, `c` in the
relevant normalizer/transporter), so `O_i^*` is the graph of an
equivariant bijection `V_i -> V_{j(i)}`; near-injectivity of `P` forces
`i -> j(i)` to be (correctable to) a permutation of components matching
isomorphic ones (components with `delta_i >= 1` carry total mass
`<= 4C_0 eps|V|/kappa^2` and can be matched arbitrarily among
themselves at that cost, using equal sizes forced by mass counting).
The union of the `O_i^*` is the graph of an equivariant permutation `c`
agreeing with `P` off a set of measure `<= C eps/kappa^2`.  QED.

Remarks.  (i) Only property (T) of `Lambda` is used, through the
uniform Kazhdan constant; no transitivity, congruence structure, or
infranormality.  (ii) The mechanism (project to invariant functions,
then round by integrality) is the standard (T)-rounding of the
P-stability literature (Becker–Lubotzky–Thom style) run on the orbital
decomposition of `V x V`; Kun–Thom's Theorem 4.1 proves an ultraproduct
centralizer-normalization for infranormal pairs — different statement,
same family.  We claim the packaging, not the technique.

## Theorem C (permutation co-density of the arithmetic pair)

Every finite action `tau` of `Gamma = SL_3(Z[1/3])` satisfies
`tau(Lambda)-generated = tau(Gamma)-generated`: the two images generate
the same subgroup of `Sym(V)`; in particular every `tau(Gamma)`-orbit
is a `tau(Lambda)`-orbit and the centralizers coincide.

*Proof.*  A finite action is a disjoint union of transitive actions
`Gamma/H` with `H` of finite index.  By the Margulis normal subgroup
property and the congruence subgroup property for `SL_3(Z[1/S])`
(Bass–Milnor–Serre; Serre), `H` contains a principal congruence
subgroup `Gamma(m)`, necessarily with `gcd(m, 3) = 1` (3 is invertible
in `Z[1/3]`), so the action factors through
`Q = SL_3(Z/m) = Gamma / Gamma(m)`.  Strong approximation for
`SL_3(Z)` gives `Lambda ->> SL_3(Z/m)` — and jointly for finitely many
levels, `Lambda` surjects onto the product image of `Gamma` (the
closure of `SL_3(Z)` in `prod_{q != 3} SL_3(Z_q)` is everything).  So
`tau(Lambda) = tau(Gamma)` as subgroups of `Sym(V)`.  QED.

## Theorem P (the reduction)

If `Gamma = SL_3(Z[1/3])` is flexibly P-stable, then `W_3` is not
sofic.

*Proof.*  Suppose `W_3` sofic with sofic approximation
`sigma_n : W_3 -> Sym(V_n)` (asymptotically multiplicative and free in
normalized Hamming).  Restrict to `Gamma` and correct by flexible
P-stability: genuine actions `tau_n` of `Gamma` on `V_n' supseteq V_n`,
`|V_n' \ V_n| / |V_n| -> 0`, with `d_H(tau_n(gamma),
sigma_n(gamma)) -> 0` for each `gamma` (extend `sigma_n` by the
identity on the padding).  Set `P_n = sigma_n(k_0)` (the base lamp),
extended by the identity.  Since `[k_0, Lambda] = 1` in `W_3`,
`P_n` almost-commutes with `tau_n(lambda)` for each `lambda`, in
particular for the finite Kazhdan set `S`.  Theorem R rounds `P_n` to
an exactly `tau_n(Lambda)`-equivariant permutation `c_n` with
`d_H(P_n, c_n) -> 0`.  By Theorem C, `c_n` is `tau_n(Gamma)`-
equivariant: `tau_n(h) c_n tau_n(h)^{-1} = c_n` for
`h = diag(3, 1, 1/3)`.  Then

```text
sigma_n(k_0 . h k_0 h^{-1})  ~  P_n . tau_n(h) P_n tau_n(h)^{-1}
                             ~  c_n . tau_n(h) c_n tau_n(h)^{-1}  =  c_n^2 ,
```

up to Hamming `o(1)`.  Now `sigma_n(k_0)^2 ~ id` (as `k_0^2 = e`), so
`c_n^2` is an equivariant permutation Hamming-near the identity; an
equivariant permutation acts freely on each orbit unless trivial there
(a right translation `qH -> qcH` fixes a point iff it is trivial on
that orbit), so `c_n^2 = id` off vanishing mass, hence
`fix(sigma_n(k_0 . h k_0 h^{-1})) / |V_n'| -> 1`.  But
`k_0 . h k_0 h^{-1}` is a NONTRIVIAL element of `W_3` (the lamps at the
two distinct cosets `Lambda` and `h Lambda` multiply to a nontrivial
lamp configuration), so soficity demands that fixed-point density tend
to `0`.  Contradiction.  Also `c_n` is not near the identity
(`fix(sigma_n(k_0)) -> 0` since `k_0 != e`), so the contradiction is
not vacuous.  QED.

## Position

- This is the WREATH permutation-twin of the graph's HNN theorem
  (`hnn-over-codense-kazhdan-subgroup-not-hyperlinear` /
  `hnn-over-sl2-z-not-sofic-if-sl2-z-inverse-p-p-stable`): flexible
  HS-stability there, flexible P-stability here; the (T;FD)
  conjugation-gap step there, Theorem R here; co-density there,
  Theorem C here.  Bowen–Burton (arXiv:1906.02172) is the literature
  home of "flexible stability of a higher-rank lattice implies
  nonsofic groups exist"; the group produced here is the SUMMIT wreath
  itself, which feeds `separation-from-nonsofic-hyperlinear-wreath`.
- Strict P-stability of `Gamma` is FALSE (Becker–Lubotzky,
  arXiv:1809.00632: infinite RF groups with (tau) are never P-stable),
  so the flexible hypothesis is the only viable one, and it is open —
  the permutation sibling of the Dogon–Vigdorovich HS question.
- Two-sided reading: if instead `Gamma` is NOT flexibly P-stable, its
  sofic approximations witness non-correctable almost-actions — a
  different, also unproven, world; the reduction converts either
  resolution of the P-stability question into major information about
  `W_3`.

## 1. The Macbeath-type lemma
- **Setup.** Every edge orbit has a representative `[v_{i(ε)}, a_ε v_{j(ε)}]`. `H` is generated by the vertex
  stabilizers and the `a_ε`.
- **Closure.** The set `W = H·{v_i}` is closed under taking neighbours.
  - Case 1: `g ∈ G_{v_i} ⊆ H`.
  - Case 2: `g a_ε ∈ G_{v_i}`, so `g ∈ H a_ε^{-1} = H`.
  - Unoriented edges and inversions are covered by these two cases.
- **Conclusion.** `X` is connected, so `W` is every vertex, and `g v_1 = h v_1` forces `g ∈ H`. Correct.
- **Item 2.** Finitely many elements of these groups fix `o_q` for almost all `q`, but `e_12(1/q)` does not fix `o_q`.
  Correct.

## 2. The orbit structure (the correction to critic-2)
- **Vertices of `X`.** They correspond to lattices modulo `Q^×`. The local scalings `p^{n_p}` are nonzero at only
  finitely many `p` and assemble to one element of `Q^×`.
- **Stabilizers.** They are `Q^×·GL(L)`, and for `det g = 1` they are `SL(L)`, because `λ^2 = ±1` forces `λ = ±1`.
- **`PGL_2(Q)`.** It is vertex-transitive with one edge orbit per prime. `SL_2(Z) → SL_2(F_p)` is onto, so the
  stabilizer is transitive on `P^1(F_p)`.
- **`SL_2(Q)`.** The invariant `δ(L) = det B` in `Q^×/{±1}(Q^×)^2` is well defined.
  - Conversely, if `det B' = ελ^2 det B`, then `g = λ^{-1} B' diag(ε,1) B^{-1}` has determinant 1 and satisfies
    `gL = λ^{-1}L'`.
  - So the vertex orbits correspond to the squarefree positive integers, and the action is not cocompact. The
    correction to `gq-gq-critic-2.md`, item 1, is right.

## 3. Automorphisms of `∏'_p T_p`
- **Squares detect directions (the author's point).**
  - Two edges at `v` with different directions lie in the 4-cycle `v, a, w, b`.
  - Take two edges with the same direction `p`, and let `w ≠ v` be adjacent to both `a` and `b`. If `w` moved
    coordinate `r ≠ p`, it would differ from `b` in coordinates `p` and `r`. So `w` differs from `v` only in `p`, and
    `v_p, a_p, w_p, b_p` would be a 4-cycle in the tree `T_p`. That is impossible.
  - So "no common 4-cycle" is a graph-theoretic equivalence relation, and its classes at `v` have sizes `p+1`. These
    sizes are pairwise distinct, so every automorphism preserves directions.
- **The fibre-coordinate step (the author's point).**
  - The `p`-edge components are the `p`-fibres, and they are permuted by any automorphism. So `φ(y)_r = φ(x)_r`
    whenever `x` and `y` differ only in some coordinate `p ≠ r`.
  - Two vertices with the same `r`-coordinate differ in finitely many other coordinates, so `φ(x)_r` depends only on
    `x_r`.
  - `φ_r` preserves `r`-edges and is inverted by `(φ^{-1})_r`. Also `φ(o)` is a vertex of `X`, so `φ_r(o_r) = o_r` for
    almost all `r`.
- **Finitely generated subgroups.** They lie in `A_S × K_S`, where `K_S` is the full product of profinite stabilizers.
- **The normal-subgroup argument for `SL_2(Q)` (the author's point).** Let `N` be the kernel of a homomorphism to a
  residually finite group.
  - If `N` were central, the image would contain the divisible unipotent `Q`, which is impossible in a residually
    finite group.
  - A noncentral `N` maps onto the simple `PSL_2(Q)`, so `N{±I} = SL_2(Q)`, and perfectness gives
    `SL_2(Q) = [N, N] ⊆ N`.
  - `PSL_2(Q)` is infinite and simple, so it is not residually finite.
  - For `GL_2(Q)` and `PGL_2(Q)`, the commutator subgroups are `SL_2(Q)` and `PSL_2(Q)`.
- **Item 4.**
  - Every `g` fixing `o_q` for all `q ∉ S` satisfies `g Z_q^2 = q^{n_q} Z_q^2`, where `n_q ≠ 0` for only finitely many
    `q`.
  - Rescaling puts `g` in `GL_2(Z[1/S])`. With `det g = 1`, `λ` is a unit, so `g ∈ SL_2(Z[1/S])`.
  - Correct.

## 1. Route `local-annihilation-el-simplicity-explicit-extraction` (sk-general-master): PASS

Setting: R is simple, n ≥ 3, and S_F = {s : ∃ t ≠ 0, ts = 0, tfs = 0 ∀ f ∈ F} generates R.

**Step 1.**
- C_g is a non-unital subring and C_g ≠ R.
- If S_F ⊆ C_g, the ring generated by S_F would lie in C_g. So some s ∈ S_F gives ρ = [g, e_ij(s)] ≠ 1 ✓.

**Step 2.**
- ρ = (I + g·sE_ij·g^{-1})e_ij(-s), so ρ - I = -sE_ij + (g·sE_ij·g^{-1})e_ij(-s).
- Left multiplication by t kills both terms, since t g_pi s = 0 and ts = 0 ✓.

**Step 3.**
- Y = ρ^{-1} - I ≠ 0. R is prime, so Y_qm R t ≠ 0.
- Row m of ctE_ml·ρ equals c·(t·row l of ρ) = ct e_l^T, because tρ = tI. So e_ml(ct)ρ = ρ + ctE_ml.
- v = ρ^{-1}e_ml(ct)ρe_ml(-ct) = (I + ρ^{-1}ctE_ml)(I - ctE_ml) = I + Y·ctE_ml, because E_mlE_ml = 0.
- v ∈ N, since it is ρ^{-1} times a conjugate of ρ. It is supported in column l, and v_ql = Y_qm ct = z ≠ 0 ✓.

**Step 4.**
- v^{-1}e_k = e_k for k ≠ l.
- Since (v^{-1})_lk = 0 = v_lk for k ≠ l, the (l,l) entries of v^{-1}v = I and vv^{-1} = I give (v^{-1})_ll v_ll = 1 = v_ll (v^{-1})_ll. So (v^{-1})_ll is a unit ✓.

**Step 5.** Take b ∉ {l,q} and B = e_bq(1).
- Bv - vB = E_bqωe_l^T - ωe_l^T E_bq = ω_q E_bl = zE_bl, since e_l^T E_bq = 0 ✓.
- [B,v] = (vB + zE_bl)B^{-1}v^{-1} = I + zE_bl v^{-1}, because E_bl B^{-1} = E_bl ✓.
- Row l of v^{-1} is (v^{-1})_ll e_l^T, so [B,v] = e_bl(z(v^{-1})_ll) ∈ N, and z(v^{-1})_ll ≠ 0 ✓.

**Step 6.**
- Signed permutation matrices conjugate e_bl(r_0) to e_pq(±r_0), and e_pq(-r_0) = e_pq(r_0)^{-1}. So r_0 ∈ J.
- J is a two-sided ideal and R is simple, so J = R ✓.

**Comparison.**

## 2. Route `subshift-elementary-group-simple-via-local-annihilation`: PASS

**Local annihilation, additive form.**
- Choose y ∉ {T^jx : |j| ≤ w} and a clopen W ∋ y avoiding that finite set.
- Continuity gives a clopen V ∋ x with W ∩ T^jV = ∅ for all |j| ≤ w, including j = 0.
- With s = e_V r and t = e_W: ts = e_{W∩V}r = 0, and t·f_ju^j·e_V r = f_j e_{W ∩ T^jV}u^j r = 0 ✓.
- A partition refining the V's gives Σ_V e_V r = r, so the elements e_V r span R ✓.

**Consequences.**
- Normal subgroups are central or everything, by the established criterion. Its explicit extraction is §1.
- Z(G) ⊆ F_q^×I_3.
- G is finitely generated, G/Z(G) is infinite, and G has no finite quotient: a central kernel K would make G/Z(G), a quotient of G/K ≅ Q, finite ✓.

## 5. `crossed-product-gl-n-has-infinite-cyclic-index-quotient` + `-proof`: PASS

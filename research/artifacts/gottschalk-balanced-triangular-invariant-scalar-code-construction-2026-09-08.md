# An infinite balanced triangular rule has an invariant scalar code

Date: 2026-09-08. For the balanced two-track triangular rule on
A_4 x Z with A=I+R_h, t=(123), and h=(12)(34), there is an
explicit continuous injective Q-intertwiner into a scalar binary
shift-invariant code over a countable group Lambda. The induced
map on that code is a reversible scalar cellular automaton.
The source has nonzero off-axis component (I-E)AE.

Thus nonlinear invariant codes really can accommodate this
infinite balanced control. The remaining issue is extending its
code involution to an injective or reversible cellular automaton
on the entire scalar full shift. A subsequent
[controlled enlargement](gottschalk-controlled-symmetry-linear-code-extension-and-complement-collision-2026-09-08.md)
does produce an exact two-term extension x+B Q_s over an enlarged
group, but an explicit complement collision proves it noninjective.
It does not establish linear-span membership over the original
Lambda. An arbitrary local extension need not be injective.

The finite-source exclusion and the prefix homeomorphisms used
below are proved in
[the finite-code and infinite-prefix artifact](gottschalk-balanced-invariant-code-finite-exclusion-and-infinite-prefix-control-2026-09-08.md).
The present construction preserves that finite exclusion and
the full-conjugacy obstruction: its source is infinite and its
target is a proper invariant code. No computation or resolution
of Gottschalk's conjecture is claimed.

## The component system and its symmetry group

Let G_0=A_4, t=(123), h=(12)(34), and A=I+R_h. On the finite
component alphabet

    D=(F_2^{G_0})^2

define q by applying Q_t(x)=x R_t x separately to both tracks,
and define

    f_A(x,y)=(x+A Q_t(y),y).

Write u=(1,1). The map q fixes u and q^-1(u)={u}. Since A1=0,
f_A fixes u; since f_A is an involution, f_A^-1(u)={u} as well.
Consequently both operations preserve the classes U={u} and
Z=D minus {u}. They need not commute with each other.

The two-track system on G_0 x Z is a product of these identical
components. Enumerate the Z-indexed components by N and write
the resulting compact source as X=D^N. Denote its componentwise
operations by Q and F_A.

For each k>=0, let H_k fix the first k components and apply on
the remaining tail the prefix homeomorphism

    UU  -> UU,       UZU -> UZ,
    UZZ -> ZZ,       Z   -> ZU.

It copies the values of the Z symbols in order and then copies
the remaining suffix. The source and target prefix lists are
complete disjoint partitions, and the reverse substitutions
give the inverse. The pieces are clopen. Since Q and F_A
preserve U/Z masks and fix u, every H_k commutes with both.

Let Lambda be the subgroup of Homeo(X) generated by:

- all permutations of finitely many component indices;
- all tail maps H_k;
- the diagonal left action of G_0 on every component and track.

This is a countable group. Every generator commutes with Q and
F_A. For the diagonal G_0 action this follows from the group
equivariance of Q_t and A; for the other generators it follows
from their copying identical components and inserting or deleting
u. The diagonal action also preserves the U/Z classes.

Let s in Lambda be diagonal left translation by t. It has order
three. Here left translation acts as

    (s z)_i^x(g)=z_i^x(t^-1 g),

and similarly on the y track. This is a source symmetry. The
target quadratic operation will instead use right translation
by s on the coordinate group Lambda; the two roles are kept
separate below.

The source lies outside the axis-preserving case. With
e=1+t+t^2 in F_2[A_4],

    (1-e)(1+h)e=(t+t^2)h(1+t+t^2) != 0.

The six terms are distinct because h^-1 t h=(214) is outside
<t>, as checked in the preceding artifact. Thus (I-E)AE != 0
for E=I+R_t+R_t^2.

## A two-component Boolean observable

For z in X, write its component i as z_i=(x_i,y_i). Define
the continuous Boolean observable phi by

    phi(z)=x_0(1)  if z_1=u;
           y_1(1)  if z_1!=u and z_0=u;
           1       if z_1!=u and z_0!=u.

Its definition uses only two finite components. The selected
case is unchanged under Q or s, because both preserve whether
each component equals u. Within either coordinate-reading case,
the defining identity of Q_t gives

    phi(Qz)=phi(z) phi(s^-1 z).                    (1)

In the last case both sides are 1. This also verifies (1) when
one of the read components equals u.

Define the orbit map into a scalar full shift by

    L(z)(lambda)=phi(lambda^-1 z),       lambda in Lambda.

It is continuous, and is equivariant for the constructed Lambda
action on X and the usual left shift on F_2^Lambda. Since every
lambda commutes with Q, equation (1) gives

    L(Qz)(lambda)
      =phi(Q lambda^-1 z)
      =phi(lambda^-1 z) phi(s^-1 lambda^-1 z)
      =L(z)(lambda) L(z)(lambda s).

Consequently

    L Q=Q_s L,       Q_s(w)(lambda)=w(lambda)w(lambda s).   (2)

In particular, the target uses a right-s quadratic shift, even
though s was defined through a left action on the source.

## The observable orbit separates every pair

Let z,w in X be distinct. Choose a component where some x or
y bit differs, and move that component to index 0 by a finite
permutation. The next operations will leave component 0 fixed.

We first produce another component equal to u in both inputs.
Consider the infinitely many pairs of U/Z classes at indices
other than 0.

- If a pair is UU, it already supplies the common component u.
- If a pair is ZZ, move it to index 1 and apply H_1. Its first
  tail symbol is Z in both inputs, so H_1 inserts u at index 2
  in both.
- Otherwise every pair is ZU or UZ. One type occurs at least
  twice. Move two such pairs to indices 1 and 2 and apply H_1.
  One input has tail prefix ZZ and is sent to a prefix ZU;
  the other has prefix UU, which stays UU. Again index 2 is u
  in both inputs.

All transformations are the same for z and w and belong to
Lambda. None changes their distinguished component at index 0.
We have therefore retained a differing bit and obtained a common
component u that can be used as a control.

To read a differing x bit, place the distinguished component
at index 0 and the common u at index 1. Then phi reads its x
track. To read a differing y bit, reverse these positions.
If the distinguished component is non-u, the second case of
phi reads its y track. If it is u in one input, both components
there are u, and phi=1, which is also the required y bit of u.
Finally use a diagonal G_0 translation to read the chosen group
coordinate. This preserves u and all case choices.

Thus some Lambda translate of phi distinguishes z from w.
The orbit map L is injective. Compactness of X makes it a
homeomorphism onto a closed image C, and equivariance makes
C shift-invariant.

## Reversible dynamics on the code and the exact remaining gap

Define

    F_C=L F_A L^-1:C -> C.

Because F_A commutes with Lambda, this is a continuous
Lambda-equivariant involution. Hence it is a reversible scalar
cellular automaton on the subshift C. More explicitly, continuity
and compactness make its identity-coordinate output depend on
finitely many input coordinates of C; equivariance supplies the
same local rule at every coordinate.

The code is proper. For any three components, two have the same
U/Z class. The observable phi evaluated on that pair equals 1,
whether both are U or both are Z. Let p_12 and p_02 be the
component swaps (1,2) and (0,2). Every encoded configuration
therefore satisfies

    L(z)(1) or L(z)(p_12) or L(z)(p_02) = 1.

Thus the scalar all-zero configuration is outside C, whereas
the all-one source is encoded as scalar 1.

A local rule for F_C can be extended to all binary patterns,
giving a scalar cellular automaton on F_2^Lambda. It can be
chosen zero-preserving: enlarge its memory to contain the three
displayed coordinates, whose all-zero pattern never occurs on
C, and assign output 0 to that pattern. This observation supplies
no injectivity, surjectivity, or reversibility of the extension.
Nor does it make its feedback linear in Q_s.

The achieved conclusion is a continuous Q-preserving encoding
into a proper invariant scalar code with reversible dynamics
on that code. The unresolved step is an injective or reversible
full-shift extension. The subsequent controlled enlargement gives
one exact linear-feedback extension and an explicit collision for
it; other coefficients or extensions remain open. The code alone
is not a Gottschalk counterexample and does not establish an
outside-axis injective scalar feedback rule.

There is an exact obstruction to any order-preserving extension,
including a coordinate permutation or pure right shift. Every encoded coordinate satisfies
L(Qz)(lambda)<=L(z)(lambda), by (2). But phi F_A does not satisfy
this inequality with Q. Put u in component 1, and in component 0
take x=1 and a weight-two y with Q_t(y)=delta_1. Then Q_t^2(y)=0
and (A delta_1)(1)=1, so

    phi(F_A z)=0,       phi(F_A Qz)=1.

A monotone extension T would take Q_s Lz<=Lz to
T(Q_s Lz)<=T(Lz), contradicting the displayed values at the
identity coordinate. In particular, a coordinate permutation
cannot extend F_C. Also no Q-centralizing source symmetry
h can satisfy phi h^-1=phi F_A. This excludes the proposed shift
extension but leaves nonlinear reversible full-shift extension open.

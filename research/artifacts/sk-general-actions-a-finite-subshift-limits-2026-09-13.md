## 0. Results and relation to Cairn

**Conventions.**
- `Γ` is finitely generated, with a finite symmetric generating set `S`, word length `|γ|` and balls `B_j`. `A` is finite.
- `Γ` acts on `A^Γ` by `(γx)(h) = x(hγ)`. For `Γ = Z` this is the note's `(Tx)_n = x_(n+1)`.
- For finite `F ⊆ Γ` and invariant `Y ⊆ A^Γ`, put `L_F(Y) = {y|_F : y ∈ Y}`.
- A subshift `X` **has finite models** if for every finite `F` there is a finite invariant `Y ⊆ A^Γ` (a finite subshift) with `L_F(Y) = L_F(X)`. Equivalently, `X` is a limit of finite subshifts in the Hausdorff topology.
- `R = LC(X,F_2) ⋊ Γ = {Σ f_γ u_γ}` with `u_γ f u_γ^(-1) = f∘γ^(-1)`, so `u_γ e_V u_γ^(-1) = e_(γV)`.

**Results.**
- **Theorem G.** Let `X ⊆ A^Γ` be infinite, minimal and free, with finite models, and `n ≥ 3`. Then `G = EL_n(R)` is an infinite, finitely generated, simple group with property (T) that is LEF.
- **Proposition N.** If `Γ` acts freely on a nonempty subshift with finite models, then `Γ` is residually finite.
- **Proposition E.** Every finitely generated infinite residually finite `Γ` has a point `x ∈ {0,1,2}^Γ` whose orbit closure is free, minimal, and has finite models.
- So the note's theorem extends over `Γ` exactly when `Γ` is residually finite. Examples: `SL_3(Z)`, surface groups, `F_r`, `Z^d`.

## 1. Proof of Theorem G

**Step 1 (generation, (T), infinite).** `R` is generated by `u_t^(±1)` (`t ∈ S`) and the letter indicators `e_a = e_({x : x(e)=a})`. Indeed:
- `u_γ e_a u_γ^(-1)` is the indicator of `{z : z(γ^(-1)) = a}`, so products give every cylinder;
- `LC(X,F_2)` is spanned by cylinder indicators.

The identities `e_ij(r+s) = e_ij(r)e_ij(s)` and `[e_ik(r), e_kj(s)] = e_ij(rs)` (distinct indices) show that `e_ij(s)`, for `s ∈ {1, u_t, e_a}`, generate `G`. EJZ (Invent. Math. 179 (2010), Thm 1.1) gives (T). `G` is infinite because `e_12(LC(X,F_2))` is.

**Step 2 (simple ring, centres).** Let `J ≠ 0` be an ideal.
- Multiplying on the right by some `u_γ^(-1)` gives `r = Σ f_γ u_γ ∈ J` with `f_e ≠ 0`.
- Pick `x` with `f_e(x) = 1`. By continuity and freeness there is a clopen `U ∋ x` with `f_e = 1` on `U` and `U ∩ γU = ∅` for the finitely many `γ ≠ e` in the support of `r`.
- Then `e_U f_γ u_γ e_U = f_γ e_U e_(γU) u_γ = 0` for `γ ≠ e`, so `e_U r e_U = e_U ∈ J`.
- By minimality finitely many `γ_i U` cover `X`, so `1 = 1 − Π(1 − e_(γ_i U)) ∈ J`.

If `r` is central:
- `[e_V, r] = Σ f_γ (e_V − e_(γV)) u_γ = 0`. For `γ ≠ e` and `x` with `f_γ(x) ≠ 0`, pick `V ∋ x` with `γ^(-1)x ∉ V` (freeness). Then `(e_V − e_(γV))(x) = 1`, a contradiction. So `f_γ = 0`.
- `[u_t, f_e] = 0` makes `f_e` invariant, so it is constant by minimality. So `Z(R) = F_2`.
- A central `g ∈ G` commutes with every `e_ij(1)`, so `g = cI`. Commuting with every `e_ij(r)` gives `c ∈ Z(R)^× = {1}`.

**Step 3 (finite models, LEF).** Let `Y` be a finite subshift and `F` finite with `L_F(Y) = L_F(X)`.
- On `V_Y = F_2^Y` put `P_γ δ_z = δ_(γz)`, and `D_Y(f) δ_z = f(z) δ_z` for `f` depending only on `x|_F` (evaluate its table at `z|_F`).
- Then `P_γ D_Y(f) P_γ^(-1) = D_Y(f∘γ^(-1))` when both windows lie in `F` (`f∘γ^(-1)` has window `Fγ^(-1)`), and `D_Y(f)D_Y(f') = D_Y(ff')`.
- So `Σ f_γ u_γ ↦ Σ D_Y(f_γ) P_γ` preserves any finite list of sums and products, provided `F` contains all windows involved, shifted ones included.
- A nonzero `f` stays nonzero, since every `F`-pattern of `X` occurs in `Y`.

Distinctness:
- **Compactness fact.** If `g ≠ e`, the clopen sets `{x : x(h) ≠ x(hg)}`, `h ∈ Γ`, cover `X` (freeness). So a finite `F_g` has: every `x ∈ X` satisfies `x(h) ≠ x(hg)` for some `h ∈ F_g`.
- If `F ⊇ F_g ∪ F_g g`, then `g` fixes no point of `Y`.
- Take `F ⊇ F_g ∪ F_g g` for all `g ≠ e` in `E^(-1)E`, where `E` is the set of exponents involved. Then for each `z ∈ Y` the points `γz`, `γ ∈ E`, are distinct.
- If `f_(γ_0) ≠ 0`, pick `z' ∈ Y` with `f_(γ_0)(z') ≠ 0` and `z = γ_0^(-1) z'`. The coefficient of `δ_(z')` in `(Σ D_Y(f_γ)P_γ) δ_z` is `f_(γ_0)(z') ≠ 0`. So nonzero differences stay nonzero.
- For a finite subset of `G`, include all entries, the entries of the inverses, their differences, and the intermediate sums and products. This gives an injective partial homomorphism into `GL_(n|Y|)(F_2)`. So `G` is LEF.

**Step 4 (towers).** Let `U` be clopen and `B ⊆ Γ` finite, with the sets `γU`, `γ ∈ B`, pairwise disjoint. For `γ, δ ∈ B` and clopen `W ⊆ U` put `E_(γδ)(W) = e_(γW) u_(γδ^(-1))`.
- `E_(γδ)(W) E_(γ'δ')(W') = e_(γW) e_(γδ^(-1)γ'W') u_(γδ^(-1)γ'δ'^(-1))`. This equals `E_(γδ')(W ∩ W')` if `δ = γ'`, and `0` otherwise, since `γW ∩ γδ^(-1)γ'W' ⊆ γδ^(-1)(δU ∩ γ'U) = ∅`.
- So the span `B_B(U) ≅ M_B(LC(U,F_2))`, with unit `e_(BU)`.
- **Absorption.** `f u_σ E_(γδ)(W) = E_(σγ,δ)(W_1)` and `E_(γδ)(W) f' u_τ = E_(γ,τ^(-1)δ)(W_2)`, with clopen `W_1, W_2 ⊆ W`. So if `r, r'` are supported in `S_1, S_2`, then `r B_B(U) r' ⊆ B_(B')(U)` whenever `B' ⊇ B ∪ S_1 B ∪ S_2^(-1) B` and the sets `γU`, `γ ∈ B'`, are disjoint.

**Step 5 (extraction).** Let `1 ≠ N ⊴ G` and `1 ≠ g ∈ N`. Let `w` bound the word length of every group element in the support of an entry of `g` or `g^(-1)`.
- By freeness and compactness there is a clopen partition `𝒫` refining the letter partition with `C ∩ γC = ∅` for all `C ∈ 𝒫` and `γ ∈ B_(2w+2) \ {e}`. Each point has such a neighbourhood; refine a finite subcover.
- Some `h = e_ij(s)` with `s ∈ {e_C, e_C u_t : C ∈ 𝒫, t ∈ S}` fails to commute with `g`. Otherwise the coefficients `s` for which `g` commutes with all `e_ij(s)` form a subring (Step 1 identities). It contains `1 = Σ e_C`, `u_t = Σ e_C u_t` and `e_a = Σ_(C ⊆ [a]) e_C`, so `g ∈ Z(G) = 1`.
- Here `e_C = E_(ee)(C)` and `e_C u_t = E_(e,t^(-1))(C)`, so `s ∈ B_(B_1)(C)` with `U = C`; no translate is needed.
- `k = [g,h] ∈ N \ {1}`, and `k − I = (g sE_ij g^(-1) − sE_ij) h^(-1)`, `k^(-1) − I = h(g(−sE_ij)g^(-1) + sE_ij)`.
- By absorption with `B' = B_(w+1)`, both lie in `M_n(B_(B_(w+1))(C))`. The sets `γC`, `γ ∈ B_(w+1)`, are disjoint because `γC ∩ δC = γ(C ∩ γ^(-1)δC)` with `γ^(-1)δ ∈ B_(2w+2)`.
- With `e = e_(B_(w+1)C)` we have `k = (1−e)I + eke`. The corner is invertible in `M_n(B_(B_(w+1))(C)) ≅ LC(C, M_d(F_2))`, `d = n|B_(w+1)| ≥ 3`, so it is a locally constant `κ : C → GL_d(F_2)`, `κ ≢ I`.
- Take nonempty clopen `W ⊆ C` with `κ|_W = κ_0 ≠ I`. Index the coordinates by `(p, γ)`.
  - The transvections of `H_W ≅ GL_d(F_2)` are `e_pq(E_(γδ)(W))` for `p ≠ q`.
  - For `γ ≠ δ`: `[e_pq(E_(γδ)(W)), e_qp(E_(δδ)(W))] = I + E_(γδ)(W)E_pp`, from `E_(γδ)E_(δδ) = E_(γδ)` and `E_(δδ)E_(γδ) = 0`.
  - So `H_W ⊆ G`.
- `GL_d(F_2) = PSL_d(F_2)` is simple for `d ≥ 3`. Conjugation by `k` on `H_W` is conjugation by `κ_0`, which is not central. So `N ∩ H_W ≠ 1`, `H_W ⊆ N`, and `e_12(e_W) = e_12(E_(ee)(W)) ∈ N`.
- The level set `I_N = {r : e_12(r) ∈ N}` is a two-sided ideal: permutation matrices lie in `G` over `F_2`, and `[e_13(a), e_32(r)] = e_12(ar)` (similarly on the right). It contains `e_W ≠ 0`. `R` is simple, so `I_N = R` and `N = G`. ∎

## 2. Proposition N (residual finiteness is necessary)

Let `Γ` act freely on a nonempty subshift `X ⊆ A^Γ` with finite models, and let `γ ≠ e`.
- By the compactness fact of Step 3, some finite `F ∋ e` has: every `x ∈ X` satisfies `x(h) ≠ x(hγ)` for some `h ∈ F`.
- Let `Y` be a finite subshift with `L_(F ∪ Fγ)(Y) = L_(F ∪ Fγ)(X)`. Every `y ∈ Y` agrees on `F ∪ Fγ` with some `x ∈ X`, so `(γy)(h) = y(hγ) ≠ y(h)` for some `h`. So `γ` acts nontrivially on the finite set `Y`.
- The action `Γ → Sym(Y)` is a homomorphism not killing `γ`. So `Γ` is residually finite. ∎

**Model test.** Freeness is needed. The constant configurations form a finite subshift with finite models over every group, the non-RF ones included.

## 3. Proposition E (a nested-hole Toeplitz subshift)

Let `Γ` be finitely generated, infinite and residually finite. Choose normal subgroups `Γ = K_0 > K_1 > ⋯` of finite index with `∩ K_m = {e}` and `[K_m : K_(m+1)] ≥ 3`: pass to a subsequence of any separating chain. For `γ ≠ e` let `ℓ(γ)` be the unique `m` with `γ ∈ K_m \ K_(m+1)`.

Define `x ∈ {0,1,2}^Γ`:
- `x(e) = 1`;
- on `K_m \ K_(m+1)`, `x` is constant on each `K_(m+1)`-coset, takes the value `1` on exactly one of these cosets and `2` on exactly one other, and `0` on the rest.

So `x(hk) = x(h)` whenever `h ∉ K_n` and `k ∈ K_n`, because `ℓ(h) < n` and `K_n ⊆ K_(ℓ(h)+1)`. Let `X` be the orbit closure of `x`. Every `F`-pattern of a point of `X` is the pattern `h ↦ x(hσ)` of `x` at some `σ`.

**(a) Finite models.** Let `F` be finite and choose `n` with `FF^(-1) ∩ K_n = {e}`.
- For `σ ∈ Γ`, at most one `h_0 ∈ F` has `h_0σ ∈ K_n`: if `hσ, h'σ ∈ K_n`, then `hh'^(-1) ∈ K_n`.
- For `k ∈ K_n` the patterns of `x` at `σ` and at `σk` agree off `h_0`. As `k` varies, `h_0σk` runs over all of `K_n`, so `x(h_0σk)` takes every value in `x(K_n)`.
- For `b ∈ x(K_n)` let `y_b` equal `x` off `K_n` and `b` on `K_n`. It is fixed by `K_n`, so its orbit is finite.
- The pattern of `y_b` at `σ` is the pattern of `x` at `σk`, for any `k` with `x(h_0σk) = b`. Conversely, the pattern of `x` at `σ` is that of `y_b` at `σ` with `b = x(h_0σ)`.
- So `Y = ∪_b Γy_b` is a finite subshift with `L_F(Y) = L_F(X)`.

**(b) Minimal.** With `F`, `σ`, `n`, `h_0` as in (a), the pattern of `x` at `σ` recurs at `σk` whenever `x(h_0σk) = x(h_0σ)`, `k ∈ K_n`. This holds:
- for all `k ∈ K_n` if there is no `h_0`;
- for `k ∈ K_(m+1)` if `ℓ(h_0σ) = m ≥ n`;
- for `k` in the `1`-coset of level `n` if `h_0σ = e`.

In each case the return set contains a coset of a finite-index normal subgroup, which is syndetic. So `x` is almost periodic and `X` is minimal.

**(c) Free at every point.** Let `γ ≠ e`, choose `n` with `γ ∉ K_n`, and a finite transversal `T` with `Γ = T K_n`. Let `σ ∈ Γ`.
- `g = σ^(-1)γσ ∉ K_n`, so `m = ℓ(g) < n`.
- Let `κ_1K_(m+1)` and `κ_2K_(m+1)` be the level-`m` cosets valued `1` and `2`. At most one of them lies in `g^(-1)K_(m+1)`, so pick `κ` among `κ_1, κ_2` with `κg ∉ K_(m+1)`.
- For `ρ ∈ κK_(m+1)`: `ρg ∈ κgK_(m+1)`, which is another `K_(m+1)`-coset inside `K_m \ K_(m+1)`. The value of `κ` is unique among level-`m` cosets, so `x(ρ) ≠ x(ρg)`.
- `κK_(m+1)σ^(-1)` is a union of `K_n`-cosets, so it meets `T`. Take `h ∈ T` with `ρ = hσ ∈ κK_(m+1)`. Then `ρg = hγσ`, so `x(hσ) ≠ x(hγσ)`.
- So for every `σ` some `h ∈ T` has `(σx)(h) ≠ (σx)(hγ) = (γσx)(h)`. `T` is finite, so passing to limits, every `z ∈ X` has `z(h) ≠ z(hγ)` for some `h ∈ T`, i.e. `γz ≠ z`.

`X` is infinite because `Γ` is infinite and acts freely. ∎

## 4. The cases Z and Z^d
- **`Γ = Z`.** Every infinite minimal subshift is free (it has no periodic points) and has finite models: the note's return-word lemma (disk l.123-129) gives `y = w^∞` with the same `(2k+1)`-words, and its orbit is a finite subshift. So Theorem G contains the note's theorem.
- **`Γ = Z^d`, products.** For infinite minimal `X_i ⊆ A_i^Z`, the product `X_1 × ⋯ × X_d ⊆ (A_1 × ⋯ × A_d)^(Z^d)` with coordinatewise shifts is free and minimal: an orbit is a product of dense orbits. Products of periodic models realize exactly its box patterns.
- **`Γ = Z^d`, SFTs.** Aperiodic SFTs have no finite models. A finite subshift with the patterns of the SFT window would be a finite orbit inside the SFT (`z2-containing-groups-have-non-rf-measure-actions`). So beyond `Z` the hypothesis cannot be dropped.

## 5. Firewalls
- **Topological freeness is not enough for this proof.** The partition in Step 5 needs every point moved by each `γ ∈ B_(2w+2) \ {e}`. For topologically free actions, use `steinberg-elementary-groups-are-simple-mod-centre`.
- **Finite models force an invariant measure.** Averaging over models gives one (`un-rf-beyond-free-2026-09-13-part1.md` Lemma 3). So a free minimal `F_2`-subshift without invariant measure (`f2-groups-have-paradoxical-free-minimal-subshifts`) fails the hypothesis. That is consistent with its groups having no MF quotient.
- **Embedding Γ.**
  - `γ ↦ diag(u_γ, u_γ^(-1), 1)` is NOT a homomorphism for nonabelian `Γ`: the product is `diag(u_(γδ), u_(δγ)^(-1), 1)`.
  - Any diagonal homomorphism into `E_3(R)` must have classes summing to `0` in `K_1(R)`. For `Γ = Z`, `K_1(R) ≅ Z` with `[u]` a generator (algebraic Pimsner–Voiculescu, `K_1(LC(X,F_2)) = 0`).
  - For any ring, `diag(a,a^(-1),1) diag(b,b^(-1),1) diag((ab)^(-1),ab,1) = diag(1, a^(-1)b^(-1)ab, 1)`, so `c ↦ diag(1,c,1)` embeds `[GL_1(R), GL_1(R)]` in `E_3(R)`, and `[Γ,Γ]` embeds in `G`.
  - Units supported on a clopen tower with constant coefficients land in the groups `H_W`.
  - Told `sk-universal-embedding-a`.

## 6. Model tests
- A constant configuration has finite models but is not free or infinite, and `EL_3(F_2[Γ])` is not simple in general. Correctly excluded.
- The Fibonacci subshift over `Z` satisfies every hypothesis.
- Labbé's minimal aperiodic `Z^2` SFT is free and minimal but has no finite models. Correctly excluded.
- Thompson's group `T` is not residually finite, so by Proposition N it has no free subshift with finite models. Consistent.
- `SL_3(Z)` via Proposition E gives an infinite, finitely generated, simple Kazhdan LEF group over its three-letter Toeplitz subshift.

## 1. `fp-quotient-iff-kernel-finitely-normally-generated` (621a94a7e): PASS

Route `fp-quotient-kernel-equivalence-proof`, `requires: []`.

- **(<=).** Adjoining words `u_i` for the normal generators to a finite
  presentation `<X | R>` gives `<X | R, u_1..u_k>`. This presents
  `Gamma / <<n_i>> = Gamma/N`. Correct.
- **(=>).** This is B. H. Neumann's lemma. If `Gamma/N` is finitely presented
  and `X` is finite, then `ker(F(X) -> Gamma/N)` is finitely normally generated.
  This kernel is generated by `<<R>>` together with the lifts of `N`. So finitely many
  elements of `N` normally generate `N` modulo `<<R>>`, and hence normally
  generate `N` in `Gamma`. Every hypothesis is used: `X` finite, `R` finite,
  and the target finitely presented. The route cites the Lean theorem
  `ker_isFinitelyNormallyGenerated` for this half. I checked the argument by
  hand; the Lean build was not re-run.
- **Test.** `F_2 ->> Z wr Z` has finitely presented source, non-finitely
  presented target, and a kernel that is not finitely normally generated. This
  is consistent with the claim.
- **Body remarks.** "Zorn gives a maximal normal subgroup" holds for finitely
  generated groups: a union of a chain of proper normal subgroups is proper,
  because a finite generating set would lie in one member. The paragraph on
  `proper-normal-subgroups-miss-the-normally-generating-core` describes another
  node and is not reviewed here.

## 2. `free-cocompact-lattices-proportional-l2-betti` (d4f8cd7a8): PASS

Route `free-cocompact-lattices-l2-proportionality-proof`, `requires: []`; full
text in `atiyah-lattice-transfer-2026-09-12.md`.

- **Topology.** `X` is connected and locally finite. So `H = Aut(X)` is t.d.l.c.
  in the permutation topology, and its setwise simplex stabilizers `H_sigma` are
  compact open. Freeness on simplices gives `D ∩ H_sigma = 1`, so `D` is
  discrete. Cocompactness gives `D\H = ⋃ D\D x H_v` over finitely many double
  cosets, so it is compact, and `D` is a uniform lattice. "`H` contains a
  lattice, so `H` is unimodular" is the standard fact (Raghunathan, Remark
  1.9). The right-invariant Haar measure is therefore also left-invariant, and
  the quotient measure on `D\H` is defined.
- **Step 1.** Setwise freeness means no element of `D` fixes a simplex while
  permuting its vertices. So oriented representatives give
  `C^k ≅ ℓ²(D)^(n_k)` equivariantly. The formula
  `dim_(N(D)) V = Σ_(σ ∈ D\X_k) <P_V δ_σ, δ_σ>` is the trace on
  `N(D) ⊗ M_(n_k)`. Correct.
- **Step 2.** Automorphisms act by signed permutations commuting with the
  simplicial coboundary. This includes elements that fix a simplex setwise with
  an odd vertex permutation, which act by `-1` on it. So `H` commutes with
  `Δ_k` and `P_k`, and `ε² = 1` makes `p(σ)` constant on `H`-orbits. Correct.
- **Step 3.** `D x H_σ -> D·xσ` is a bijection `D\H/H_σ -> D\O`. The projection
  `xH_σ -> D\H` is injective exactly when `D ∩ x H_σ x^-1 = Stab_D(xσ) = 1`. So
  each piece has quotient measure `μ(xH_σ) = μ(H_σ)`, and
  `|D\O| μ(H_σ) = μ(D\H)`. Correct; finiteness of `H\X_k` follows from
  cocompactness of `D`.
- **Step 4.** The orbit sum is independent of `D`, and the vertex case of Step 3
  gives `|D\X_0| = μ(D\H) Σ_O 1/μ(H_(v_O))`. So the ratio is
  `|Γ\X_0| / |G\X_0|`. Correct.
- **Transfer.** `r ∈ Q_(>0)`, so irrationality transfers, and an integer
  `b(Γ)` forces `b(G) ∈ (1/r)Z`. Both bullets are correct.
- **Test.** `X = ` the Cayley tree of `F_2`, with `Γ = F_2` and `G ` an index-2
  subgroup. Then `r = 1/2` at the vertex count, `b_1(F_2) = 1`, and
  `b_1(G) = 2 = b_1(F_2)/r`. Consistent (`G ≅ F_3`).
- **Credit.** No novelty is claimed. The statement is the classical
  proportionality principle, and the node credits Gaboriau and Petersen without
  importing them.

## 3. `kazhdan-kernel-blocks-invariant-under-sofic-invisible-quotient` (eb31e2a42): PASS, one step under-argued

Route `kazhdan-kernel-block-invariance-proof`, which requires only
`kun-expander-decomposition-formalized` (Lean-proved in the development, not
re-built here). Full text: `hyperbolic-leavitt-cover-relative-defect-2026-09-12.md`
Section 7.

- **Inputs.** `σ_n|N` is a sofic approximation of `N`, and `N` is Kazhdan,
  hence finitely generated, and infinite. So Kun's decomposition applies on the
  prescribed `S`. Normality of `N` is what makes `g^-1 s g` a bounded word in
  `S`.
- **Steps 1–2.** Each defect point is counted in one block, so the Markov
  counts over blocks sum to `o(X)`. `B'` is exactly `S`-invariant in the edited
  graph, so `∂(A ∩ B') ⊂ ∂A ∩ B'`. Correct.
- **Step 3.** Expansion of `A = σ(g)B` for `gSg^-1` holds exactly for the
  transported edited graph. The actual `σ(gsg^-1)` differs from it off `o(X)`
  points, and the errors sum to `o(X)` over pairs `(B, B')`. The inequality
  `Σ_(B') min(|A∩B'|, |A \ B'|) <= δ|A|` then yields one `B'` with
  `|A \ B'| <= δ|A|`: if every intersection were at most `|A|/2`, the sum would
  be `|A|`.
- **Under-argued.** The assertion `||B'| − |B|| <= ε|B|` does not follow from
  `A ⊂≈ B'` alone, because `B'` could be larger than `A`. The fix is to apply
  Step 3 to `g^-1` and `B'`. That puts `σ(g^-1)B'` almost inside one block, and
  that block must be `B` since `σ(g^-1)σ(g)B ≈ B`. So `β_g` is almost bijective
  and almost size-preserving on most blocks. The same point is needed for
  `β_(gh) = β_g β_h`: the bad blocks of `g`, of total size `o(X)`, pull back
  under `β_h` to total size `o(X)`. With this filled in, Steps 4–5 are correct.
- **Step 4.** The map `τ` is well defined off `o(X)` points because
  `β_(gn) = β_g`. Order-preserving block maps compose, so `τ` is a homomorphism
  `Q -> S_U`.
- **Step 5.** A point of `B` is fixed only if `β_g(B) = B`. Correct.
- **Instance.** A nontrivial homomorphism from a simple group is injective. A
  countable group embedding in `S_U` is sofic (Elek–Szabó amplification). So a
  simple nonsofic `Q` satisfies the hypothesis. Correct.
- **Not verified.** The fixed-algebra form relies on Kun–Thom Lemma 2.3, which
  was not re-read here. It is a restatement and is not used by the main claim.

**Point indicators.** I recomputed the following in `R_L`, using `t_1 f = f(N+1) t_1` and `t_2 f = f(0) t_2`, which
follow from `f = f(s_1 t_1 + s_2 t_2)`:
- `q_k q_l = δ_kl q_k`;
- `q_k f = f(k) q_k = f q_k` for `f ∈ B`;
- `q_k s_1 = s_1 q_(k-1)` and `q_0 s_1 = 0`;
- `q_k s_2 = δ_(k0) s_2`.

So `f + Σ a_k δ_k ↦ f + Σ a_k q_k` is a ring map `B⁺ -> R_L`, and it intertwines `σ` and `ev_0`.

It is injective by the model on `Q^(X)`. There `q_k` is the projection onto `{N = k}`, and `N` takes every value
`k >= 0` on `ξ = 1^k 2^∞`. Only the fact that the model is a representation is used (W1).

**`B⁺ = B⁺_T`.**
- `T = B` is a localization of `Q[t]` at a multiplicative set of polynomials, as the eventually-rational node requires.
- It is closed under `r(t) ↦ r(t + 1)`, since `t + c + 1 ∈ S`.
- Its poles lie at negative integers. So every `r ∈ B` is defined on all of `ℕ`, and `ev_0` makes sense.
- `B ∩ J = 0`, since a rational function with infinitely many zeros is `0`.

**Flatness.**
- **The shift.** `σ(J) = J`, and after localizing at a tail prime the module is `T`, with `T_𝔮` acting through the
  injective map `r ↦ r(t + 1)`. That module is torsion-free over a DVR or a field, hence flat.
- **The reset.** `ev_0` factors through the summand `δ_0 B⁺ ≅ Q`, which is projective (N2, now in the route).
- **Over `B`.** The reset makes `Q = B/NB`, which is torsion, so it is not flat. That is exactly the scope exclusion
  in the register node. It disappears over `B⁺`, as the node says.

**Stages and the transfer.**
- `M_(2^n)(B⁺) -> R_L`, `e_(μν) b ↦ s_μ b t_ν`, is a homomorphism, because `t_ν s_μ' = δ_(νμ')` for words of equal length.
- It is injective: compress with `t_μ0` on the left and `s_ν0` on the right, then use `B⁺ ↪ R_L`.
- The padding is `b = s_1 σ(b) t_1 + s_2 b(0) t_2`, that is, `diag(σ, ι ∘ ev_0)`. By additivity this gives
  `[X] = σ_* + (ι ev_0)_*`, as the route says.

**Grading and AGGP.** Put `deg s_i = 1`, `deg t_i = −1` and `deg N = deg A = 0`. All nine relations are then
homogeneous. `t_+ = s_1` and `t_- = t_1` satisfy `t_- t_+ = 1`.

**Universality.** I checked both composites on generators, including N1. Note that the register proof only needs the
grading, `B⁺ ↪ R`, and the relations `g s_x = s_x σ_x(g)`. All of these are verified directly above.

**Cross-check: the answer does not depend on the enlargement.** The stages `M_(2^n)(B)` over the small base also
exhaust `R_0`, because `q_k` already lies in stage `k + 1` with coefficient `1 ∈ B`. So the telescope over `B`
computes the same `K(R_0)`. On `K_n(B) = A ⊕ E`, the map `1 − [X]` is `−1` on `A` and `(1 − t)` plus an `A`-part on
`E`. So it has kernel `0` and cokernel `E/(1−t)E ≅ K_(n-1)(Q)`, the same as over `B⁺`.

The enlargement is therefore needed only for the NK-vanishing step (§3 of the register proof), which is where the scope
exclusion was. A second check: dropping `E` (no resolvent) leaves `coker(−1) = 0`. That is `K_*(L_Q(1,2)) = 0`, as
in Ara–Brustenga–Cortiñas.

## 2. The linear algebra

I checked block triangularity, the kernel and the cokernel. Both the unitriangular inverse on `D` and the telescoping
identity `ker(Σ) = (1 − t)E` are correct.

The residue-sum map is canonical: it is `Σ_c ∂_c ∘ (B⁺ -> B⁺/J = B)_*`. So it does not depend on the choice of lifts.
It kills `A`, `D` and `(1−t)E`, so it factors through `K_n(R_L)`.

Degree checks:
- `n = 0`: `E = 0` and the cokernel is `0`. This agrees with `[1] = 2[1]`.
- The unit map `K_*(Q) -> K_*(R_L)` is multiplication by `[1_(R_L)] = 0`. This agrees with "scalars and `K_2(Q)` die".
- `n < 0`: `G_(n-1) = 0`, see §3(f).

## 3. External inputs, pinned

All from C. Weibel, *The K-book*, read at source in the author's chapter PDFs.

**(a) Quillen localization for `Q[N]` at `S`.** Weibel V, Application 6.1, p. 38:

> "Let S be a central multiplicatively closed set in a noetherian ring R. ... By the Localization Theorem 5.1,
> there is a homotopy fibration KM_S(R) → G(R) → G(S^(-1)R). We observed in 4.4 that M_S(R) is the colimit over all
> s ∈ S of the M(R/sR), and that K_*M_S(R) ≅ lim G_*(R/sR)."

and, for (6.1.1): "This is a sequence of K_*(R)-modules".

So the node's "colimit over finite sets of primes" is built into Application 6.1. By devissage (V, Corollary 4.2 and
Application 4.3, p. 34), `K_*M_S(Q[N]) = ⊕_(c>=1) K_*(Q)`, and every residue field is `Q`. The Dedekind form is (6.6),
p. 41.

The closest statement to the node's is V, Corollary 6.7.1, p. 43:

> "If k is a field, the localization sequence (6.6) for k[t] ⊂ k(t) breaks up into split short exact sequences
> 0 → K_n(k) → K_n(k(t)) → ⊕_p K_(n−1)(k[t]/p) → 0."

Its proof does the same for an intermediate localization of `k[t]`, "split by (t = 0)^*". That is the node's argument
exactly, with `ev_0`.

**(b) Vanishing of the pushforwards.** V, Example 6.1.3, p. 39:

> "the maps i_* are zero in (6.1.1) ... the vanishing of i_* follows from the projection formula (3.5.3):
> i_*(i^*y) = i_*(1·i^*y) = i_*(1)·y together with the observation in 6.1.2 that i_*([R/sR]) = i_*∂(s) = 0."

This is stated for `R = Z[s, 1/f(s)]`, and the argument is word for word the node's for `Q[N]`. Every element of
`K_*(Q[N]/(N+c)) = K_*(Q)` is of the form `i^* y`. The projection formula is also stated in IV, Example 6.6.5, p. 57.

Independently, the `ev_0` splitting makes `K_n(Q[N]) -> K_n(B)` injective. So either argument suffices.

**(c) `K_*(Q[N]) = K_*(Q)`.** V, Theorem 6.3, p. 40: "If R is a regular noetherian ring, then the base change
K(R) → K(R[s]) is a homotopy equivalence, so K_n(R) ≅ K_n(R[s]) for all n."

**(d) Lifts and residues.**
- V, Corollary 6.3.1, p. 40: the splitting "is multiplication by s ∈ K_1(Z[s, s^(-1)])", with "∂{s, x} = {∂s, x} = x".
  Applied at `s = N + c` over `Q`, the lift is `x ↦ {N + c, x}` in Weibel's order. The node's `{x, N + c}` differs by
  the sign already recorded in N3.
- Degree 1, V, Example 6.1.2, p. 38: "∂(s) = [R/sR]" when `R` is a domain. So `[N + c] ↦ e_c`.
- Degree 2, the paragraph after (6.6.1), p. 41: "∂ is the tame symbol ... ∂{π, u} = [ū]".

**(e) Product equals Steinberg symbol.** IV, Example 1.10.1, p. 8:

> "If r_1, ..., r_n are units of a commutative ring R, the product of the r_i ∈ K_1(R) is an element {r_1,...,r_n}
> of K_n(R). These elements are called Steinberg symbols, since the products {r_1, r_2} ∈ K_2(R) agree with the
> Steinberg symbols of III.5.10."

The product is natural (IV, Theorem 1.10, Loday). This identifies the node's `λ e_c`, a product in `K_2(B)` with `B`
commutative, with the Steinberg symbol `{λ, N + c}` in `K_2(R_L)` that items 4 and 5 use.

**(f) Excision for `J = ⊕_ℕ Q`, pinned two ways.**
- **As cited.** IV, Absolute Excision 1.11.2, p. 9: "Suslin proved in [Su95] ... that I satisfies absolute excision
  for all K_n if and only if I is H-unital."
  - `J` is H-unital. It is the filtered union of the unital rings `Q^m`. For a unital `I`, `Z ⊕ I ≅ Z × I`, so `Z` is
    projective and `Tor_(i>=1) = 0`. `Tor` commutes with filtered colimits.
- **Simpler, with no excision (suggested).** `B⁺` is the filtered union of the subrings
  `R_m = {Σ_(k<m) a_k δ_k + (1 − e_m) f}`, with `e_m = 1_([0,m))`. Each `R_m` is isomorphic to `Q^m × B`, because
  `f ↦ (1 − e_m) f` is injective on `B`.
  - IV, Elementary Properties 6.4, pp. 55–56: "K_n(R_1 × R_2) ≅ K_n(R_1) ⊕ K_n(R_2)", and "if a ring R is the
    filtered union of subrings R_i we have K_n(R) ≅ lim K_n(R_i)".
  - Take coordinates in which `K_n(B)` enters through the unital inclusion `B ⊆ B⁺`, that is, `f ↦ (f(0..m−1), f)`.
    Then the transitions are the inclusions `K_n(Q)^m ⊆ K_n(Q)^(m+1)`.
  - So `K_n(B⁺) = K_n(B) ⊕ ⊕_k K_n(Q) δ_k`, which is the node's decomposition, with `D` entering through the corners
    `Q δ_k`.
  - The same argument handles negative degrees. By III, Definition 4.1, p. 29, "if R is regular noetherian then
    K_n(R) = 0 for all n < 0". This applies to `Q^m × B`, and `K_(−n)` is built from `K_0` by cokernels, so it also
    commutes with filtered unions. Hence `G_n = 0` for `n < 0`, as §2 uses.

## 4. Items 4 and 5

Item 1 of `infinitely-generated-symbols-block-fp-elementary-groups` (refereed PASS) already puts every Steinberg symbol
of commuting units in the image of `K_2(N, R_L)`. With (e), this gives item 4's surjectivity. The explicit `h`-form in
item 4's proof is therefore not needed. In any case it is computed in `St_N(B)`, with `B` commutative, and then mapped
into `St_N(R_L)`, so no noncommutative identification arises.

The claim says `N >= 3` and the proof says `N >= 2`. These are consistent. Item 5 is `Sym(R_L) = K_2(R_L) ≅ Q^x`,
which is not finitely generated. ✓

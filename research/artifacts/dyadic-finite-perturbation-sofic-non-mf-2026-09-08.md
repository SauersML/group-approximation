# A concrete sofic non-MF group of finite perturbations

2026-09-08.  Ingestion record for a forwarded dossier
("compression-and-locally-finite-centralizers"), which completes the
concrete-example alternative of an earlier question.  Every step was
re-derived here before any node was written.

## The object

`D = Z[1/2]`, and

```text
X = { v + 2^k Z^3 : v in D^3, k in Z }
```
the countable set of dyadic affine lattice cosets.  `H = D^3 x| (SL_3(Z) x Z)`
acts by `(b,A,m)(v + 2^k Z^3) = b + 2^m A v + 2^(k+m) Z^3`.  `G` is defined
intrinsically as the group of all permutations of `X` agreeing outside a
finite set with one of these affine maps, and equals `Sym_fin(X) x| H`.

Claimed and verified: `G` is finitely generated, sofic, not MF, has no
nontrivial finite normal subgroup, and for `Gamma = Z^3 x| SL_3(Z)`,

```text
D_G(Gamma) = Rad_MF(G) = Alt_fin(X),   G/Alt_fin(X) = C_2 x H.
```

## What was re-derived here

* `H` acts faithfully on `X` modulo finite support: if `m != 0` the
  lattice scale of every point changes; if `m = 0` and the affine map is
  not the identity, choose `v` with `w = (A-I)v + b != 0`, and for all
  large `k`, `w` is outside `2^k Z^3`, so infinitely many cosets move.
  Hence `Sym_fin(X) cap H = 1` and the generated group is the displayed
  semidirect product.
* Transitivity: `t_v a^k` carries `Z^3` to `v + 2^k Z^3`.
* Finite generation: `H` is generated by the `e_ij(1)`, the three
  `t_(e_i)` and the dilation `a` (conjugates `a^-j t_(e_i) a^j` give all
  dyadic translations); adjoining the finitely many transpositions
  `(x_0, s x_0)` for `s` in a finite generating set gives the edge
  transpositions of a connected Schreier graph, which generate
  `Sym_fin(X)`.
* The three-point witness: every element of `Gamma = Z^3 x| SL_3(Z)`
  fixes `x_0 = Z^3`, `x_1 = 2^-1 Z^3`, `x_2 = 2^-2 Z^3`, so
  `C = Sym{x_0,x_1,x_2} = S_3` centralizes `Gamma`.  With `u = a^3`
  (dilation by 8) and `ell = t_(e_1)`,
  `u Gamma u^-1 = 8Z^3 x| SL_3(Z) <= Gamma` and the supports
  `Y = {8Z^3, 4Z^3, 2Z^3}` and `Z = {e_1+8Z^3, e_1+4Z^3, e_1+2Z^3}` are
  disjoint: different scales cannot coincide, and at scales 2, 4, 8 the
  vector `e_1` is outside the lattice.
* `[S_3,S_3] = A_3`: the commutator of two distinct transpositions on
  three letters is a 3-cycle, and the sign map puts the derived subgroup
  inside `A_3`.
* Every 3-cycle of `Sym_fin(X)` is conjugate into `C` by a finitely
  supported permutation, and 3-cycles generate `Alt_fin(X)` (pair the
  transpositions; `(ab)(cd) = (acb)(acd)`).
* Local residual finiteness of `R = Sym_fin(X) x| N`,
  `N = D^3 x| SL_3(Z)`: every `N_j = 2^-j Z^3 x| SL_3(Z)` has finite
  orbits on `X` (for `v + 2^k Z^3` pick `s >= max(j,-k,0)` with
  `v in 2^-s Z^3`; the orbit lies in the finite `2^-s Z^3 / 2^k Z^3`),
  finitely many elements of `R` live in one `Sym(O) x| N_j` with `O` a
  finite union of `N_j`-orbits, and that group is residually finite.
  Note the distinction the dossier draws: `Sym_fin(X) x| N_j` itself is
  **not** claimed residually finite, because finitary permutations mix
  orbits.
* The explicit sofic models for `R x|_alpha Z` on `I x Q`,
  `I = Z/MZ`, with `sigma_((r,m))(j,q) = (t, theta(alpha^-t(r)) q)`,
  `t = j + m mod M`: multiplication is exact except within `O(1/M)` of
  the endpoints, nonzero shifts are fixed-point free, and zero shifts
  with `r != 1` act by nonidentity left multiplication in every fibre.
* `H -> GL_4(D)` is injective (determinants force `m = n`, then
  `A = B`, then the translations agree), and reduction mod an odd prime
  separates, so `H` is residually finite.
* Conjugation preserves cycle type hence parity, so the `H`-action on
  `Sym_fin(X)/Alt_fin(X) = C_2` is trivial and
  `G/Alt_fin(X) = C_2 x H`.
* `D_J(L) = 1` for residually finite `J`: in a finite image, a subgroup
  and a compressed conjugate have equal cardinality, so containment
  forces equality.  Applied to `G ->> C_2 x H` this gives
  `D_G(Gamma) <= Alt_fin(X)`; the reverse uses `z_c = [u c u^-1, ell]`
  and `[d, z_c] = [d, u c u^-1]` for `d in uCu^-1`, by disjointness.
* No nontrivial finite normal subgroup: a finite normal subgroup of `H`
  meets the torsion-free `D^3` trivially, and commuting with
  translations forces the linear part to be `I`; a finite normal
  subgroup of `G` therefore lies in `Sym_fin(X)`, and its finite total
  support would be `H`-invariant, contradicting transitivity on the
  infinite `X`.

## Not asserted

The unrestricted upgrade `locally-finite-defect-subgroup-dies-in-every-corona`
is not proved; this example is a confirming instance of it, obtaining the
criterion's commuting-conjugate relation from disjointness of supports,
which normality plus membership in the defect does not supply.  No Lean
certification is claimed for anything in this region.  No priority or
literature-novelty claim is made; the dossier itself records that the
finitary-permutation example was suggested to it in its own prompt.

# Outcome

The node `projective-trace-square-transfer-for-sl3-pair` has five direct
Cairn consumers, but only one independent root-goal obstruction.  The direct
HNN route already reaches `non-hyperlinear-group`; the other four consumers
package the same universal input into reusable relative-commutant, free-
amalgamation, double-fold, and filtered-actuator interfaces.

The narrowest trace profile actually used is the canonical character of

```text
D=SL_3(Z[1/2]) *_(SL_3(Z)) SL_3(Z[1/2]).
```

For its nontrivial fold word `w`, the assertion that every canonical
microstate sequence has `|tr(w)|->1` is equivalent to non-hyperlinearity of
`D`: hyperlinearity supplies a canonical sequence with `tr(w)->0`, while in
the non-hyperlinear case the universal sequence statement is vacuous.  Thus
the regular-double and positive-density-sector terminals are useful
certificate forms, not weaker existence theorems.

# Narrowest nonvacuous sufficient gate

The current correction chain closes as soon as one vertex of every
canonical double microstate is near an exact finite-dimensional
representation.  Existing established nodes then correct the second vertex
and fold the mark.  The residual is exactly the simultaneous-two-outlier
sector.

This gate is conditional on a real dynamical fork.  Soficity of the type-zero
building action `A on A/C` produces canonical double permutation microstates
with both vertices uniformly uncorrectable and makes the double sofic.
Conversely the correctable-vertex theorem forces that action nonsofic and
proves the double non-hyperlinear.

The action is not decided by the current literature recorded in Cairn.
Locally compact soficity of `SL_3(Q_2)` gives unlabelled local `G`-spaces,
but the fixed dense arithmetic left labels do not descend through compact-
open quotienting without coherent deck-cocycle gauges.  Kun--Thom's proved
nonsofic action is a different coordinate action.

# Audit conclusion

Exact finite-dimensional co-density, property `(T)`, and canonical trace do
not promote formally to the approximate theorem.  The exact free-double
calibration already refutes such a general promotion.  Hence no existing
recent result implies or refutes the projective-transfer node for the SL3
pair.

For research prioritization, count the node as a broad reusable theorem but
only one root-bearing lane.  The smallest honest positive gate is the
correctable-vertex theorem; the smallest exact semantic formulation is
non-relative-embeddability of the arithmetic inclusion, which is already
equivalent to non-hyperlinearity of the fixed double.

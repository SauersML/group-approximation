# Ideals with quotient O_2, and why LXI forces connectivity of U(J~)

Lane `ex2-k1-defect-ideal`, 2026-09-13. All proofs below are complete. They have not been reviewed
externally and do not decide STW Problem LXI.

Notation. For a closed ideal I of a unital algebra B, `I~ = I + C1 ⊆ B`. `SQ = C_0((0,1), Q)` and
`(SQ)~ = {f ∈ C([0,1], Q) : f(0) = f(1) ∈ C1}`. A based loop in `U(Q)` is exactly a unitary of
`1 + SQ`, and a based null-homotopy is a path from it to 1 in `U(1 + SQ)`.

## 1. Loops in U(O_2)

**Lemma 1.** `U((SO_2)~)` is path-connected, so every based loop in `U(O_2)` is null-homotopic
through based loops.

*Proof.* Put `C = C(T, O_2) = C(T) ⊗ O_2` and `ev: C -> O_2`, evaluation at `1 ∈ T`. Its kernel is
`SO_2` (identify `T \ {1}` with `(0,1)`), and constant functions `c(v)` split ev.
- C is unital and Z-stable, because `O_2 ⊗ Z ≅ O_2`. `K_1(C) = K_1(O_2) ⊕ K_0(O_2) = 0`.
- By Jiang, arXiv:math/9707228v1, Theorem 2 (read in the PDF: "Let A be a unital Z-stable
  C\*-algebra. Then the natural map μ : U(A)/U_0(A) -> K_1(A) is an isomorphism"; on main as
  `z-stable-unital-algebras-are-k1-bijective`), `U(C) = U_0(C)`.
- Let `f ∈ U((SO_2)~)` and normalize so that `f(1) = 1`. Choose a path `w_s` in `U(C)` with `w_0 = f`
  and `w_1 = 1`. Then `w'_s = w_s c(ev(w_s))^*` has `ev(w'_s) = 1`, so it is a path in `U(1 + SO_2)`
  from f to 1. Square.

Jiang's Theorem 3 gives the same with `i = 1`: `π_1(U(O_2)) ≅ K_0(O_2) = 0`.
Trust surface: Z-stability of O_2 (Kirchberg's absorption `A ⊗ O_2 ≅ O_2` for unital separable simple
nuclear A, or strong self-absorption of O_2 plus Winter's theorem).

## 2. The lifting lemma

**Proposition 2.** Let B be unital, I a closed ideal, `q: B -> Q = B/I`, and assume `U((SQ)~)` is
path-connected. Then `U(I~) ∩ U_0(B) = U_0(I~)`.

*Proof.* The inclusion ⊇ is clear. Let `u ∈ U(I~) ∩ U_0(B)`, normalized so that `q(u) = 1`. Choose a
path `w: [0,1] -> U(B)` with `w_0 = 1` and `w_1 = u`. Then `γ = q∘w` is a based loop in `U(Q)`.
1. By hypothesis `γ ∈ U_0((SQ)~)`, so `γ = exp(ih_1)⋯exp(ih_m)` with `h_k = h_k^*` in `(SQ)~`. This
   holds because the identity component of a unitary group is the set of finite products of exponentials.
2. The map `(SB)~ -> (SQ)~` induced by q is a surjective \*-homomorphism, because
   `C_0((0,1)) ⊗ −` preserves surjections. So each `h_k` lifts to a self-adjoint `k_k ∈ (SB)~`.
3. `ω = exp(ik_1)⋯exp(ik_m)` is a unitary of `(SB)~` with `q(ω_t) = γ_t`. Its endpoint values are one
   scalar μ with `μ1 = q(ω_0) = γ_0 = 1`. So ω is a based loop in `U(B)`.
4. `w'_t = ω_t^* w_t` runs from 1 to u, and `q(w'_t) = γ_t^* γ_t = 1`. So `w'` is a path in
   `U(B) ∩ (1 + I) ⊆ U(I~)`, and `u ∈ U_0(I~)`. Square.

No fibration theory or Bartle--Graves section is needed.

**Corollary 3.** Let `0 -> I -> B -> O_2 -> 0` be exact with B unital. Then:
- (a) `U(I~) ∩ U_0(B) = U_0(I~)`;
- (b) `K_*(I) -> K_*(B)` is an isomorphism;
- (c) `I~` is K1-injective iff B is K1-injective;
- (d) if `K_1(B) = 0`, then `U(I~)` is connected iff B is K1-injective.

*Proof.*
- (a) Lemma 1 and Proposition 2.
- (b) Six-term exact sequence, since `K_*(O_2) = 0`.
- (c) (⟸) Let `u ∈ U(I~)` with `[u] = 0` in `K_1(I)`. Then `[u] = 0` in `K_1(B)`, so `u ∈ U_0(B)`,
  and `u ∈ U_0(I~)` by (a). (⟹) `k1-injectivity-extends-over-properly-infinite-quotients`: O_2 is
  properly infinite and K1-injective (Cuntz 1981).
- (d) Every `[u]` lies in `K_1(I) ≅ K_1(B) = 0`. Square.

**Comparison.** `o2-multiplier-extension-k1-injective-iff-unitization` proves (c) when `B = I + O_2`
with O_2 unital in `M(I)`. Corollary 3 needs only the quotient. That matters: a unital O_2 in `M(I)`
makes every unital quotient of I have `[1] = 0`, and the ideals below have unital quotients with
`[1] ≠ 0`.

## 3. The Toeplitz defect ideal

`A_T = T_2 *_C T_2` (full unital free product), with inclusions `ι_1, ι_2` and
`e = ι_1(1 - s_1s_1^* - s_2s_2^*)`. J is the closed ideal generated by e, and `B_J = J + ι_1(T_2)`.

**Lemma 4.** `B_J` is a unital, properly infinite C\*-subalgebra of `A_T`, and `B_J/J ≅ O_2`.

*Proof.*
- `B_J` is the preimage of the C\*-algebra `q_J(ι_1(T_2))` under `q_J: A_T -> A_T/J`, so it is closed.
  It contains the isometries `ι_1(s_1), ι_1(s_2)` with orthogonal ranges, so it is properly infinite.
- `B_J/J ≅ T_2 / ι_1^{-1}(J)`. The ideal `ι_1^{-1}(J)` contains `p_3`, hence the compact ideal K. It
  does not contain 1: the quotient map `A_T -> O_2 * T_2` on the first factor kills e and not 1.
- Every nonzero ideal of `T_2` contains K, which is essential and simple, and `T_2/K ≅ O_2` is simple.
  So `ι_1^{-1}(J) = K` and `B_J/J ≅ O_2`. Square.

**Theorem 5.**
- (a) `J~` is K1-injective iff `B_J` is K1-injective.
- (b) `K_*(B_J) ≅ K_*(J) = (Z, 0)`, so `U(J~)` is connected iff `B_J` is K1-injective.
- (c) STW Problem LXI implies that `U(J~)` is connected.
- (d) LXI holds iff the halving homotopy `o2-free-circle-halving-homotopy` holds and `U(J~)` is
  connected. Any unitary of `J~` outside `U_0(J~)` refutes LXI.

*Proof.*
- (a) and (b): Corollary 3 with Lemma 4. `K_*(J) = (Z,0)` is computed in route
  `lxi-from-halving-and-toeplitz-defect-ideal` from `K_*(A_T) = (Z,0)` (Blanchard arXiv:0804.4624v13,
  Lemma 4.4) and `K_*(O_2 * T_2) = 0` (Germain).
- (c) `B_J` is unital and properly infinite.
- (d) (⟸) is route `lxi-from-halving-and-toeplitz-defect-ideal`. (⟹) LXI gives the halving homotopy
  (`o2-free-circle-halving-homotopy-from-lxi`), and (c) gives connectivity. Square.

Before this, a non-null unitary in `J~` was known only to block that route. By (c) it now refutes LXI,
so `J~` is a two-sided test object.

**Remark 6 (no unital O_2 in M(J)).**
- The unital map `A_T -> O_3` with `ι_1(s_1) -> r_1`, `ι_1(s_2) -> r_2`, `ι_2(s_1) -> r_3`,
  `ι_2(s_2) -> r_2` is surjective, and it sends e to `r_3r_3^* ≠ 0`. Since O_3 is simple, J maps onto O_3.
- A surjection `π: J -> O_3` extends to a unital map `M(J) -> M(O_3) = O_3` by `π̄(m)π(x) = π(mx)`,
  which is well defined because `ker π` is invariant under `M(J)`.
- A unital O_2 in `M(J)` would force `[1] = 2[1]` in `K_0(O_3) = Z/2`, where `[1] ≠ 0`.
- So the multiplier criterion cannot reach J, while Corollary 3 does. The same quotient shows that J
  is not stable.

**Correction to the defect-ideal Attempts.** "Send `ι_2` anywhere" does not always give a unital
quotient of J. With `ι_2 = ι_1` composed into `T_2 ⊆ O_∞`, the image of `A_T` is `T_2` and J maps onto K.
A suitable `ι_2`, such as the O_3 map above, does give one.

## 4. A one-ideal form of LXI

Let `φ: A_T -> O_2` send both copies of `s_k` to `s_k`, the fold of the two Cuntz quotients, and put
`I_f = ker φ`. Then `J ⊆ I_f`.

**Theorem 7.** STW Problem LXI holds iff `U(I_f~)` is connected.

*Proof.*
- By Corollary 3(b),(d), `K_1(I_f) ≅ K_1(A_T) = 0`, and `U(I_f~)` is connected iff `A_T` is K1-injective.
- `A_T` K1-injective implies LXI: Blanchard arXiv:0804.4624v13, Proposition 4.2, (i) => (v).
- LXI implies `A_T` K1-injective, because `A_T` is unital and properly infinite. Square.

So LXI is the connectivity of the unitary group of one unitized ideal, with no K-theoretic condition
left. The same holds for `ker(O_2 * O_2 -> O_2)` and the halving homotopy
(`o2-free-circle-halving-homotopy`, Attempts). There the multiplier criterion already applied.

## 5. Where this leaves the defect ideal

- `U(J~)` connected is now sandwiched: it follows from LXI, and together with halving it gives LXI.
- Because `B_J ⊆ A_T`, `B_J` has `[1] = ` generator of `K_0 = Z`. So the halving theorem does not
  apply to `B_J` directly. The corner `p B_J p` with `p = 1 - ι_1(s_1s_1^*)` has `[p] = 0`, so under
  halving it is K1-injective.
- Passing back from `pB_Jp` to `B_J ≅ ι_1(s_2)B_Jι_1(s_2)^* ⊆ pB_Jp` is again the unit axiom: whether
  `u ~_h SuS^* + (1 - SS^*)` for the isometry `S = ι_1(s_2)`. By Proposition 2 this is the same
  inside `U(J~)`, for `u ∈ 1 + J`.
- So under halving, `U(J~)` is connected iff every `u ∈ U(1+J)` is homotopic in `U(1+J)` to
  `1 + ι_1(s_2) x ι_1(s_2)^*`, where `u = 1 + x`.

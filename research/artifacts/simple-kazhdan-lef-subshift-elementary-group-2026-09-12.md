## 0. Statement

Fix a prime power `q` and an infinite minimal subshift `X ⊆ A^Z` over a finite alphabet `A`
(for example the Fibonacci subshift). `T` is the shift `(Tx)_n = x_(n+1)`. Put

```text
Acal = LC(X, F_q)   (locally constant F_q-valued functions),     alpha(f) = f o T^(-1),
R    = Acal ⋊_T Z  (algebraic crossed product): elements  sum_j f_j u^j,  u f = alpha(f) u.
```

So `u chi_Y u^(-1) = chi_(TY)` for clopen `Y`. Let `G = EL_3(R)`, the subgroup of `GL_3(R)`
generated by the elementary matrices `e_ij(r) = I + r E_ij`, `i != j`, and `Z = Z(G)`.

**Theorem A.**
- (A1) `G` has property (T).
- (A2) `R` embeds as a unital ring in an algebraic ultraproduct `prod_omega M_(N_k)(F_q)`, so `G`
  and `S = G/Z` are LEF, hence sofic and hyperlinear.
- (A3) Every normal subgroup of `G` is either contained in `Z` or equal to `G`, and
  `Z ⊆ F_q^x I_3`. So `S` is an infinite, finitely generated, simple group with property (T).

**Corollary B.** Pestov's Open Question 9.1 (after Ozawa) has a positive answer in both forms:
`S` is an infinite simple Kazhdan group which is LEF, hence sofic, hence hyperlinear.

**Corollary C.** `G` is an infinite LEF, hence operator-MF, Kazhdan group with no nontrivial
finite quotient.

## 1. The ring

**1.1 Dynamics.** An infinite minimal subshift has no periodic point, since a finite orbit is
closed. `L(X)` is its language. Two standard facts:
- **(U) Uniform recurrence.** For every `m` there is `l(m)` such that every word of `L(X)` of
  length `l(m)` contains every word of `L_m(X)`.
- **(P) Long cylinders have long return times.** For every `L` there is `k_L` such that every
  centred cylinder `C(v) = {x : x_[-k,k] = v}` with `k >= k_L` satisfies
  `T^j C(v) ∩ C(v) = ∅` for `0 < |j| <= L`.
  Proof: otherwise words of unbounded length in `L(X)` have a period `j <= L`. Fix such a `j`
  along a subsequence and take a limit of points of `X` in which these words are centred. That
  gives `y ∈ X` with `T^j y = y`, a contradiction.

Every clopen set is a finite disjoint union of centred cylinders of any sufficiently large
radius.

**1.2 Normal form and generators.** Every `r ∈ R` is uniquely `sum_j f_j u^j` with finitely many
`f_j != 0`, and `(f u^i)(g u^j) = f alpha^i(g) u^(i+j)`. The ring is generated by `u`, `u^(-1)`
and `chi_[a]` (`a ∈ A`, `[a] = {x_0 = a}`): `u^i chi_[a] u^(-i) = chi_{x_(-i)=a}`, products give
all cylinders, and `F_q`-linear combinations give `Acal`. When `q` is not prime, a primitive element of `F_q`
must be added to the generators (review note, 0efeac410). Say `r` has *propagation* `<= w` if `f_j = 0` for `|j| > w`.

**1.3 `R` is simple.** Let `J != 0` be an ideal. Choose `0 != P = sum_(j ∈ F) f_j u^j ∈ J`.
Multiplying by a power of `u`, we may assume `f_0 != 0`. Pick `x` with `f_0(x) = c != 0`. Since
`T^j x != x`, there is a clopen `W ∋ x` with `f_0 = c` on `W` and `T^j W ∩ W = ∅` for
`0 != j ∈ F`. Then

```text
chi_W P chi_W = sum_j f_j chi_W chi_(T^j W) u^j = c chi_W,
```

so `chi_W ∈ J`. By minimality `X = T^(i_1) W ∪ ... ∪ T^(i_s) W`, and each `chi_(T^i W) =
u^i chi_W u^(-i)` lies in `J`. Inclusion-exclusion is a ring expression, so `1 ∈ J`.

**1.4 Centre.** If `c = sum f_j u^j` is central, then `c chi_W = chi_W c` gives
`f_j (chi_(T^j W) - chi_W) = 0` for all clopen `W`, so `f_j = 0` for `j != 0` by freeness.
`c u = u c` gives `f_0 o T = f_0`, so `f_0` is constant by minimality. Thus `Z(R) = F_q`.

**1.5 Tower subrings.** Let `U` be clopen with `T^j U ∩ U = ∅` for `0 < |j| <= 2m`. For clopen
`W ⊆ U` and `a, b ∈ [-m, m]` put

```text
E_ab(W) = chi_(T^a W) u^(a-b) = u^(a-b) chi_(T^b W).
```

Since the levels `T^a U` are pairwise disjoint, `E_ab(W) E_cd(W') = δ_bc E_ad(W ∩ W')`. So the
span `B_m(U)` of these elements is a subring isomorphic to `M_(2m+1)(LC(U, F_q))`, with unit
`chi_V`, where `V = V_m(U) = ⊔_(|a|<=m) T^a U`.

**1.6 Absorption lemma.** Suppose `T^j U ∩ U = ∅` for `0 < |j| <= 2(m+w)`. If `r, r'` have
propagation `<= w` and `b ∈ B_m(U)`, then `r b r' ∈ B_(m+w)(U)`.
Proof. By linearity take `r = f u^i`, `b = E_ab(W)`, `r' = f' u^j`. Then

```text
r b r' = f chi_(T^(a+i) W) alpha^(i+a-b)(f') u^(i+a-b+j).
```

Write `F = f alpha^(i+a-b)(f')` and split `W` into clopen pieces `W_k` such that `F` is constant,
equal to `c_k`, on `T^(a+i) W_k`. Then `r b r' = sum_k c_k E_(a+i, b-j)(W_k)`, and
`|a+i|, |b-j| <= m+w`.

## 2. Property (T) (A1)

Ershov--Jaikin-Zapirain, *Property (T) for noncommutative universal lattices*, Invent. Math. 179
(2010), arXiv:0809.4095v2, **Theorem 1.1**, read from the PDF on 2026-09-12: "Let R be a finitely
generated (associative) ring with 1 and n >= 3. Let G = EL_n(R), that is, the subgroup of GL_n(R)
generated by elementary matrices. Then G has Kazhdan's property (T)."

`R` is finitely generated with 1 (1.2), so `G` has (T). Quotients of Kazhdan groups are Kazhdan,
so `S` has (T).

## 3. Local embeddability into finite groups (A2)

**3.1 Periodic models.** For `k >= 1` use (U) to pick a point `x ∈ X`, a word `v ∈ L_(2k)(X)` and
two occurrences of `v` in `x`, at positions `p < p'`, with `N := p' - p >= max(2k+1, l(2k+1))`.
Put `w_k = x_[p, p')` and let `y = y^(k)` be the `N`-periodic sequence with `y_[0,N) = w_k`.
- **No new windows.** A window of `y` of length `<= 2k+1` meets at most one seam. A window
  across a seam is `suffix_s(w_k) prefix_t(w_k)` with `t <= 2k`. Because `v` is a prefix of `w_k`
  and `x_[p, p'+2k) = w_k v`, this equals `x_[p'-s, p'+t) ∈ L(X)`.
- **All windows.** `w_k` has length `>= l(2k+1)`, so it contains every word of `L_(2k+1)(X)`.

Hence `L_(2k+1)(y^(k)) = L_(2k+1)(X)`.

Let `P_k ∈ M_N(F_q)` be the cyclic shift `δ_n -> δ_(n+1)` on `F_q^(Z/N)`. If `f ∈ Acal` depends
only on `x_[-rho, rho]`, say `f(x) = Phi(x_[-rho,rho])` with `2 rho + 1 <= 2k + 1`, put
`D_k(f) = diag(Phi(y_[n-rho, n+rho]))_(n ∈ Z/N)`. This is well defined, because every window of
`y` lies in `L(X)` and `Phi` matters only on `L(X)`. Set `psi_k(sum f_j u^j) = sum D_k(f_j) P_k^j`
whenever all radii and `|j|` are small compared with `k`.

**3.2 The embedding.** Define `Psi(r) = [psi_k(r)]_omega ∈ prod_omega M_(N_k)(F_q)` (arbitrary at
the finitely many small `k`).
- `Psi` is additive and `Psi(1) = 1`.
- It is multiplicative. `P^i D_k(g) P^(-i) = diag(ghat(n-i))`, and this is the model of
  `alpha^i(g)`, since `alpha^i(g)(x) = g(T^(-i) x)` reads `x_[-rho-i, rho-i]`. So
  `psi_k((f u^i)(g u^j)) = psi_k(f u^i) psi_k(g u^j)` for large `k`.
- It is injective. If `r = sum f_j u^j != 0`, some `f_j` is nonzero on a word of `L(X)`. That word
  occurs in `y^(k)`, so `D_k(f_j) != 0`. Once `N_k > 2 max|j|`, the terms `D_k(f_j) P_k^j` have
  disjoint supports, so `psi_k(r) != 0` for all large `k`.

**3.3 `G` and `S` are LEF.** `Psi` induces `GL_3(R) -> prod_omega GL_(3 N_k)(F_q)`, which is
injective. A finitely generated subgroup of an algebraic ultraproduct of finite groups is LEF:
the finitely many products and inequalities in a finite window hold in omega-many coordinates.

For `S`, let `Λ = {λ ∈ F_q^x : λ I_3 ∈ G}`, so that `Z = Λ I_3` (by 4.4). The finite central
subgroup `Λ I` of each `GL_(3N_k)(F_q)` gives `prod_omega GL/Λ I ≅ prod_omega (GL_(3N_k)(F_q)/Λ I)`.
If `Psi(g) ∈ [Λ I]`, then `Psi(g) = Psi(λ I_3)`, so `g = λ I_3 ∈ Z`. Therefore `S` embeds in an
ultraproduct of finite groups and is LEF. LEF implies sofic (Elek--Szabó, via left regular
permutation representations), and sofic implies hyperlinear.

## 4. Normal subgroups (A3)

**4.1 Level ideal.** For `N ⊴ G`, `I(N) = {a : e_12(a) ∈ N}` is a two-sided ideal:
- it is additive;
- `[e_12(a), e_23(b)] = e_13(ab)`, `[e_31(b), e_12(a)] = e_32(ba)`, and conjugation by signed
  permutation matrices, which lie in `G`, moves `e_ij(a)` to `e_(σi σj)(±a)`.

If `I(N) = R`, every `e_ij(r) ∈ N`, so `N = G`. By 1.3, `I(N) != 0` forces `N = G`.

**4.2 Root detection.** Let `g ∈ N ⊴ G` with `g ∉ Z(G)`. We produce `0 != r` with some
`e_ij(r) ∈ N`.

(a) *A localized noncommuting root.* Let `w` bound the propagation of all entries of `g` and
`g^(-1)`, put `L = 2w + 3`, and let `Σ_L` be the set of elements `λ chi_C`, `λ chi_C u`, `λ chi_C u^(-1)` (`λ ∈ F_q`),
where `C` runs over the centred cylinders of radius `>= k_L`. The set
`C_g = {s : g commutes with e_ij(s) for all i != j}` is a subring:
- it is closed under `+` and `-`;
- `e_ij(st) = [e_ik(s), e_kj(t)]`.

`Σ_L` generates `R` (1.2 and 1.1). So if `Σ_L ⊆ C_g`, then `g` commutes with all of `G`, and `g`
is central. Hence some `h = e_ij(s)` with `s ∈ Σ_L` does not commute with `g`. Each such `s` lies
in `B_1(U)`, with `U = C`, `T^(-1) C` or `T C`: `chi_C = E_00(C)`,
`chi_C u = E_10(T^(-1) C)`, `chi_C u^(-1) = E_(-1,0)(T C)`. Every translate of `C` has return
times `> L`.

(b) *Localization.* Put `k = [g, h] = (g h g^(-1)) h^(-1) ∈ N`, so `k != 1`. Set `m' = 1 + w`.
- `g h g^(-1) = I + g (s E_ij) g^(-1)`, and its entries `g_pi s (g^(-1))_jq` lie in
  `B_(m')(U)` by 1.6, since `2m' = 2w + 2 <= L`.
- `h^(-1) = I - s E_ij`.

Since `B_(m')(U)` is a subring, `k - I ∈ M_3(B_(m')(U))`, and likewise `k^(-1) - I`. With
`e = chi_V`, `V = V_(m')(U)`,

```text
k = (1-e) I_3 + k_V,     M_3(B_(m')(U)) ≅ LC(U, M_d(F_q)),   d = 3(2m'+1) >= 9,
```

so `k` is a locally constant `κ : U -> GL_d(F_q)` with `κ ≢ I`.

(c) *Case 1: `κ(x_0)` is not scalar for some `x_0`.* Choose a clopen `W ∋ x_0` with `κ = κ_0` on
`W`. The unital ring map `M_d(F_q) -> M_3(B_(m')(W))`, `e_((p,a),(p',b)) -> E_ab(W) E_pp'`, gives
an injective homomorphism `ι_W : SL_d(F_q) -> GL_3(R)`, extended by `1` off `V_(m')(W)`. Its
image lies in `G`. Take a transvection `t = I + c e_((p,a),(p',b))`.
- If `p != p'`, then `ι_W(t) = e_pp'(c E_ab(W))`.
- If `p = p'`, then `a != b`. Put `x = c E_ab(W)` and `y = E_bb(W)`, so that `xy = x`, `yx = 0`
  and `x^2 = 0`. For `p'' != p`, expanding gives `[e_pp''(x), e_p''p(y)] = I + x E_pp = ι_W(t)`.

The group `N_W = ι_W^(-1)(N)` is normal in `SL_d(F_q)` and contains `[κ_0, ε]` for every
`ε ∈ SL_d(F_q)`, because `[k, ι_W(ε)] = ι_W([κ_0, ε])`. If `N_W` were central, then
`ε -> [κ_0, ε]` would be a homomorphism from the perfect group `SL_d(F_q)` to an abelian group,
hence trivial, and `κ_0` would centralize `SL_d(F_q)`, i.e. be scalar. So `N_W` is noncentral.
For `d >= 3` a noncentral normal subgroup of `SL_d(F_q)` is everything (`PSL_d` is simple and
`SL_d` is perfect). In particular `e_12(chi_W) = ι_W(I + e_((1,0),(2,0))) ∈ N`, with
`chi_W != 0`.

(d) *Case 2: `κ = λ I_d` with `λ ∈ LC(U, F_q^x)`, `λ ≢ 1`.* Then `k = c I_3` with
`c = 1 - e + (sum over pieces of λ chi_(V_(m')(piece))) ∈ Acal^x`. Choose a clopen `W ⊆ U` with
`λ = λ_0 != 1` on `W`, and put `r = chi_(T^(m'+1) W) u = u chi_(T^(m') W) != 0`. Since
`L >= 2m'+1`, `T^(m'+1) W` is disjoint from `V`, so `c r c^(-1) = λ_0^(-1) r`, and

```text
[k, e_12(r)] = e_12(c r c^(-1)) e_12(-r) = e_12((λ_0^(-1) - 1) r) ∈ N,   (λ_0^(-1)-1) r != 0.
```

**4.3 Simplicity.** By 4.2 and 4.1, `N ⊄ Z(G)` implies `N = G`.

**4.4 Centre.** If `g` commutes with `e_ij(1)` for all `i != j`, then `g = cI_3`; commuting with
`e_12(r)` for all `r` then gives `c ∈ Z(R)^x = F_q^x`. So `Z ⊆ F_q^x I_3` is finite and
`S = G/Z` is simple. `S` is infinite because `e_12(Acal) ⊆ G`.

**4.5 No finite quotients.** A finite-index `N ⊴ G` is not contained in the finite group `Z`, so
`N = G` (Corollary C). The same follows from 4.1 alone, since a finite-index level ideal is
nonzero.

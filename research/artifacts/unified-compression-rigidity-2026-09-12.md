# One compression-rigidity theorem across metrics (2026-09-12)

Lane `ex-free-unified-theory`. Part 1: the finitary theorem, the three faces of
property (T), the readoff table, and the Hilbert--Schmidt crux.

## 0. Summary

- **Theorem 1.** In each metric approximation class (sofic, hyperlinear,
  `k`-linear sofic, weak MF), normalization of Kazhdan centralizers at one rigid
  presentation is equivalent to a uniform inequality about approximate
  representations in each finite dimension, `UCS_C`. No ultrafilter survives in
  the statement.
- **Consequence.** The rigid defect criterion `DD(C)` of
  `research/artifacts/rigid-compression-defect-ladder-2026-09-11.md` is `UCS_C`
  for every rigid presentation of every infranormal Kazhdan pair.
- **Readoff (Section 3).** Every known proof of a row spends property (T) in up
  to three ways: rounding (R), localization (L) and lift (K). Each metric
  supplies some of them. The table says which, and which famous problem each
  open row decides.
- **Crux (Section 4).** `UCS_HS` at the Kun--Thom pair
  `Gamma < G = <Gamma, A, B>` (`d = 3`) is a dimension-uniform matrix inequality.
  - If it holds, the Kun--Thom wreath is not hyperlinear.
  - If it fails, some hyperlinear group is nonsofic.

## 1. Setting

**Model families.** A class `C` is given by groups `G_n` with bi-invariant
metrics `d_n`:

| class | `G_n` | `d_n(x, y)` |
| --- | --- | --- |
| sofic | `Sym(n)` | fraction of points where `x != y` |
| hyperlinear | `U(n)` | `||x - y||_2`, normalized trace |
| `k`-linear sofic | `GL_n(k)` | `rank(x - y)/n` |
| weak MF | `U(n)` | `||x - y||` (operator norm) |

`U_C` is the metric ultraproduct `prod_U G_(n_k) / {d = 0}`. Property (U) of the
ladder artifact (Section 1) holds for these four classes: a countable group is in
`C` iff it embeds in some `U_C`.

**Rigid presentations.** Let `Gamma <= G` be groups, `F` a finite symmetric
generating set of `Gamma`, and `T` a finite set with `t Gamma t^-1 <= Gamma` for
`t in T` and `G = <F cup T>`. Call `(F, T)` a rigid presentation when `Gamma` and
`G` have property (T). Write `B_R` for the ball of radius `R` in `G` for the word
metric of `F cup T`.

**Approximate models.** An `(eps, R)`-model in `G_n` is a map `u : B_R -> G_n`
with `u_1 = 1` and `d_n(u_g u_h, u_(gh)) <= eps` whenever `g, h, gh in B_R`.

**The finitary statement.** Write `c(x, y) = d_n(xy, yx)`.

```text
UCS_C(F,T):  for every eta > 0 there are eps > 0 and R such that for every n,
             every (eps,R)-model u in G_n, and every z in G_n with
                 c(z, u_s) <= eps                for all s in F,
             one has
                 c(u_t z u_t^-1, u_s) <= eta     for all s in F, t in T.
```

`NORM_C(F,T)`: for every metric ultraproduct `U_C` and every homomorphism
`sigma : G -> U_C`, the group `sigma(G)` normalizes `C_(U_C)(sigma(Gamma))`.

## 2. Theorem 1

**THEOREM 1.** For each of the four classes and every rigid presentation `(F, T)`,

```text
UCS_C(F,T)   <=>   NORM_C(F,T).
```

Hence `DD(C)` holds iff `UCS_C(F,T)` holds for every rigid presentation of every
infranormal Kazhdan pair. (With ladder Theorem 1: `DD(C) <=> NORM(C)`, and `NORM(C)`
is `NORM_C(F,T)` over all presentations.)

**Lemma 2.1 (reduction to the compressor generators).** For `sigma : G -> U` into
any group, put `C = C_U(sigma(Gamma))`. Then `sigma(G)` normalizes `C` iff
`sigma(t) C sigma(t)^-1 <= C` for every `t in T`.

*Proof.* `sigma(gamma) z sigma(gamma)^-1 = z` for `gamma in Gamma` and `z in C`. For `t in T`,
`sigma(t) C sigma(t)^-1 = C_U(sigma(t Gamma t^-1)) >= C`, because
`t Gamma t^-1 <= Gamma`. If also `<=` holds, it is an equality, so `sigma(t)^-1`
normalizes `C` as well. `G` is generated by `F cup T`. The converse is trivial. ∎

*Proof of Theorem 1.*

(`<=`) Suppose `UCS_C(F,T)` fails for some `eta > 0`. For `k = 1, 2, ...` choose
`n_k`, a `(1/k, k)`-model `u^(k)` and `z_k` with `c(z_k, u^(k)_s) <= 1/k` for
`s in F`, but `c(u^(k)_t z_k (u^(k)_t)^-1, u^(k)_s) > eta` for some `s_k in F`,
`t_k in T`. Fix a free ultrafilter `U` on `N`.
1. `F` and `T` are finite, so `s_k = s` and `t_k = t` for `U`-almost every `k`.
2. For `g in G` put `sigma(g) = [(u^(k)_g)_k]`, defined for `k >= |g|`. The defect
   bound `1/k` makes `sigma : G -> U_C` a homomorphism.
3. `z = [(z_k)]` commutes with `sigma(F)`, hence with `sigma(Gamma)`.
4. Inverses in `U_C` are computed coordinatewise, so `[((u^(k)_t)^-1)_k] = sigma(t)^-1`
   and `d(sigma(t) z sigma(t)^-1 sigma(s), sigma(s) sigma(t) z sigma(t)^-1) >= eta`.
5. So `sigma(t) z sigma(t)^-1` is not in `C_(U_C)(sigma(Gamma))`, and `NORM_C` fails.

(`=>`) Suppose `sigma : G -> U_C = prod_U G_(n_k)` does not normalize
`C = C_(U_C)(sigma(Gamma))`. By Lemma 2.1 there are `t in T` and `z in C` with
`w = sigma(t) z sigma(t)^-1` outside `C`. Since `F` generates `Gamma`,
`eta := max_(s in F) d(w sigma(s), sigma(s) w) > 0`. Assume `UCS_C(F,T)` and take
`eps, R` for `eta/2`.
1. Choose representatives `u^(k)_g` of `sigma(g)` for `g in B_R`, with `u_1 = 1`,
   and `z_k` of `z`.
2. `sigma` is a homomorphism and `B_R` is finite, so for `U`-almost every `k` the
   map `u^(k)` is an `(eps, R)`-model and `c(z_k, u^(k)_s) <= eps` for `s in F`.
3. `UCS_C` gives `c(u^(k)_t z_k (u^(k)_t)^-1, u^(k)_s) <= eta/2` for those `k`.
4. Passing to the limit, `max_s d(w sigma(s), sigma(s) w) <= eta/2 < eta`.
   Contradiction. ∎

**Remarks.**
- The statement involves no trace condition and no separation condition on the
  models. `NORM_C(F,T)` depends only on the pair `Gamma <= G`, so `UCS_C(F,T)` does
  not depend on the choice of rigid presentation of the pair.
- **Complexity.** If `G` has solvable word problem, then for rational `eta, eps` and
  integers `R, n` the inner statement for `C = hyperlinear` is a first-order
  sentence over the reals (unitaries, Hilbert--Schmidt norms), hence decidable by
  Tarski--Seidenberg. So `UCS_HS(F,T)` is a `Pi^0_3` sentence
  (`forall eta exists eps, R forall n`).

**Two-metric row.** Let models be operator-norm models in `U(n)`, `z` range over
contractions of `M_n`, and measure `c` in the normalized 2-norm. Call this
`UCS_(op->2)(F,T)`. The proof above transfers verbatim to the norm matrix ultraproduct
with the 2-norm commutant. `kazhdan-asymptotic-commutant-transport` states the
ultraproduct form with only `Gamma` Kazhdan. So `UCS_(op->2)` holds for every
presentation in which `Gamma` has property (T), with no hypothesis on `G`.

## 3. Three faces of property (T)

Every established row spends property (T) in some of the following ways.

- **(R) Rounding: internal coordinates for the vertex.** Property (T) of `Gamma` turns
  approximate commutants into finite-stage objects that carry a size.
  - *Operator norm:* the adjoint action on `L^2(M_n)` is an operator-norm almost
    representation, so its Kazhdan projection exists at each finite stage, with an
    exact integer rank (ladder Section 10, norm matrix corona row).
  - *Hamming:* Kun's decomposition into expanding components (Kun--Thom Lemma 2.3).
  - *Hilbert--Schmidt:* the gap exists only in the ultraproduct. Coordinates must be
    supplied, by (H1) of `hs-stable-vertex-rounding-for-every-model`, or in weaker form
    by Alekseev--Thom Open Problem 6.2(a). The latter gives coordinates only: the
    tracial co-Hopfian step recorded in `notes/NOTEPAD.md` ("rank-spiky compensation")
    is a separate input.
  - *Rank over a field:* no rounding (`kazhdan-rank-rounding-fails-over-every-field`).
    Unitary structure is what is missing, not characteristic zero.
- **(L) Localization: internal atoms for the compressor group.** Needed exactly when
  the size is a distribution over internal scales rather than one exact integer.
  Property (T) of `G` confines the scale observables to `G`-atoms.
  - *Operator norm:* not needed. One exact rank per compressor admits no drift.
  - *Hamming:* Kun's decomposition for `sigma` itself (Kun--Thom Proposition 3.1 takes
    both decompositions as hypotheses).
  - *Hilbert--Schmidt:* a liftable masa of `sigma(G)' cap M`
    (`hs-block-gap-iff-liftable-masa-of-actor-commutant`).
  - *Necessity:* the literal group `E` is sofic, so it lies in every normalized class,
    and it carries a nontrivial compression defect of a Kazhdan subgroup with one
    compressor (ladder Theorem 4). Without (L), compressors can shift mass to larger
    internal scales while conserving the trace.
- **(K) Lift: from the trace to the model metric.** Needed only when the model metric
  does not see the trace.
  - *Operator norm:* capture happens in the 2-norm shadow. A normal Kazhdan subgroup
    inside the defect lifts it to the MF radical (`normal-kazhdan-defect-non-mf`).
  - *Necessity:* `H_K = G *_Gamma (Gamma x K)` is weak MF with a nontrivial defect
    (`weak-mf-groups-can-carry-rigid-defects`), so `UCS_op` fails at the Theorem E pair.

| model metric | capture | (R) | (L) | (K) | `UCS` | decides |
| --- | --- | --- | --- | --- | --- | --- |
| exact f.d. / LEF | exact | free | not needed | -- | holds, no (T) | -- |
| operator norm | 2-norm shadow | Kazhdan projection, exact rank | not needed | -- | holds, (T) of `Gamma` | defect in `R_(infinity->2)` |
| operator norm | operator norm | same | not needed | normal Kazhdan `K <= D` | fails (`H_K`) | non-MF groups (established) |
| Hamming | Hamming | Kun for `Gamma` | Kun for `G` | -- | holds (Kun--Thom 4.1) | nonsofic groups (established) |
| Hilbert--Schmidt | HS | OPEN | OPEN | -- | OPEN, win--win | non-hyperlinear group / Pestov 3.4 |
| rank over `C` | rank | fails | -- | -- | OPEN, win--win | non-linear-sofic over `C` / AP Question 8.5 |
| rank over `F_2` | rank | fails | -- | -- | OPEN, win--win | non-`F_2`-linear-sofic / char. 2 form of 8.5 |
| weakly sofic | bi-invariant | none | none | -- | fails (`W`) | -- |

The Hamming row is the only normalized row where one theorem (Kun's decomposition)
supplies both (R) and (L). The open rows lack both, and for different reasons: the
Hilbert--Schmidt row has the gap but no finite-stage coordinates, and the rank rows
have finite-stage dimension counting but no gap.

## 4. The Hilbert--Schmidt crux

**Setting.** The Kun--Thom Theorem E pair with `d = 3`, `r >= 3`, `q` a prime power:

```text
Gamma = EL_r(F_q[x_1,x_2,x_3]),     G = EL_r(F_q[x_1^(+-1),x_2^(+-1),x_3^(+-1)]) x| SL_3(Z),
B = I + E_12,   A = C B,   T = {A, B},   G = <Gamma, A, B>
```

(`kt-two-positive-compressors-generate-full-obstruction`), and `F` a finite symmetric
generating set of `Gamma`. Both groups are Kazhdan, `Gamma` is infranormal and not
normal.

**Claim `hs-uniform-compression-stability-at-the-theorem-e-pair` (OPEN).**
`UCS_HS(F, {A, B})`: for every `eta > 0` there are `eps > 0` and `R` such that for all
`n`, all `(eps, R)`-models `u : B_R -> U(n)` in normalized Hilbert--Schmidt norm and all
unitaries `z in U(n)` with `||[z, u_s]||_2 <= eps` for `s in F`,

```text
||[u_t z u_t^*, u_s]||_2 <= eta      for all s in F, t in {A, B}.
```

**Both outcomes are landmarks.**
- *Holds.* By Theorem 1, every homomorphism `G -> U(prod_U M_n)` normalizes the
  centralizer of the image of `Gamma`. A hyperlinear embedding `rho` of the wreath
  `W = (direct_sum_(G/Gamma) Z/2) x| G` restricts to such a homomorphism, and ladder
  Theorem 1 (first half) makes `rho` kill `[t e_Gamma t^-1, gamma]`. That commutator is
  nontrivial (`kun-thom-wreath-carries-rigid-defect`), so `W` is not hyperlinear. This
  gives `non-hyperlinear-group`.
- *Fails.* By Theorem 1 there are `sigma : G -> U(prod_U M_n)` and a unitary
  `z in C(sigma(Gamma))` with `w = sigma(t) z sigma(t)^*` outside `C(sigma(Gamma))`.
  Then `H = <sigma(G), z>` is hyperlinear, `sigma(Gamma) <= sigma(G)` is a rigid pair in
  `H` (quotients of Kazhdan groups are Kazhdan, images of compressors are compressors),
  and `[w, sigma(s)] != 1` for some `s in F` is a nontrivial rigid defect. This is
  `hyperlinear-group-carries-nontrivial-rigid-defect`, hence a hyperlinear nonsofic
  group and a negative answer to Pestov's Question 3.4.

**Where each input would come from.** (R) and (L) of Section 3 in the Hilbert--Schmidt
row close it for one model: `hs-rounding-and-actor-gap-force-ccr` under (H1) and (H2').
A counterexample sequence must avoid genuine coordinates
(`ccr-holds-for-all-genuine-fd-coordinate-models`), must live on the diffuse part of the
commutant (`trace-preserving-endomorphism-fixes-discrete-type-i-summand`), and under (H1)
with transported defect `delta` it needs `log n` of order at least `1/delta`
(`ccr-under-vertex-rounding-from-few-aspect-scales`: `eps_n <= 18 (N_n delta_n)^(1/3)`,
and the number of occupied dyadic aspect windows is at most `2 log_2 n + 2`).

## 5. Model tests of the proposition `UCS_C(F,T)`

- **A trivial presentation satisfies it.** If every `t in T` normalizes `Gamma`, then
  `u_t^* u_s u_t` is within `O(eps)` of a word of bounded length in `F`, so
  `UCS_C` holds with `eta = O(eps)` in every class.
- **It is not vacuous.** At the Theorem E pair it fails in the weak MF class (Section 3,
  (K) necessity) and holds in the sofic class (Kun--Thom 4.1). The same inequality with
  the two metrics of the table therefore separates classes at one presentation.
- **Genuine representations.** Restricted to models that are genuine representations
  of `G`, `UCS_HS` holds at every rigid presentation. The proof of Theorem 1 runs
  verbatim inside the class of ultraproducts of genuine representations, where
  `ccr-holds-for-all-genuine-fd-coordinate-models` gives normalization.

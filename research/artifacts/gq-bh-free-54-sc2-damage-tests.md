# Bounded damage (SC₂) at the nodes of the least-damage tree-domination recursion

This artifact supports Attempt 5 of `edge-split-descendant-dissections-are-tree-dominated`.
It answers bh-major-mcg-2's request after `5a5a8bd32`. Lane bh-free-54, 2026-09-19.

**How it was run.** Directly on the MSI node, per the coordinator, because SLURM
submission was blocked:
- two processes, one per rank, under `taskset -c 30,31 nice -n 19 timeout 900`;
- rank 3 took 126 s and rank 4 took 332 s;
- output is under `/projects/standard/hsiehph/sauer354/bh-free-54/`.

Nothing was run locally. `tdlib.py` is the first part of `td.py`, and `gen.py` is the
rank-generic library; both are printed in
`research/artifacts/gq-bh-free-54-tree-domination-tests.md`.

## What is measured

At every node `C` (at least 2 fragments) of the R2 recursion, and for every first split
`s` of `C`:
- `dmg(s)` is the largest number of cells that the cut-lemma resolution `resolve`
  produces from one straddler of `s`: 1 if nothing straddles, 2 if `s` is single-cut;
- `ni(s)` is the number of fragments that lie in a child of `s` without descending from
  it.

Logged per node:
- histograms of `min_s dmg(s)`;
- the same minimum over the splits with `ni(s) = 0`;
- `dmg` at the split that R2 actually chooses.

SC holds at a node if and only if `min_s dmg(s) ≤ 2`, and SC₂ if and only if it is `≤ 3`.
Nodes where every first split has `dmg ≥ 4` are saved (the first three per rank).

**Why the greedy count decides SC₂.** bh-major-mcg-2 (`165c42817`) shows that the
straddlers of minimal damage 3 are exactly the value classes `±perm(1,1,−1)` and
`±perm(2,−1,0)`, and that `resolve` attains the minimum on them. So `resolve ≥ 4` implies
minimal damage `≥ 4`.

## Calibrations

- **Rank 2.** 2500 nodes, all with `min dmg = 1` (no straddlers), as expected.
- **The three logged no-SC nodes of `5a5a8bd32`.**
  - Each gives `min dmg = 3`. Two medians have damage 3; the third has damage 8, 10 and 8.
  - `ni = 0` everywhere.
  - This matches bh-major-mcg-2's independent re-check.

**SC₂ is false.** No first split has damage `≤ 3` at 6 rank-3 nodes and at 10 rank-4
nodes. The saved nodes list `dmg` and `ni` per split:
- rank 3, three medians: `(4, 4, 9)`, `(20, 4, 9)` and `(4, 4, 18)`;
- rank 4, six first splits: `(5, 5, 11, 7, 7, 8)`, `(35, 6, 4, 5, 5, 4)` and
  `(5, 7, 4, 18, 11, 5)`.

**The split R2 chooses.** It has damage `≤ 3` at all but 24 of the 18018 rank-3 nodes. In
rank 4 it has damage up to 17: the histogram is 4 (278 nodes), 5 (45), 6 (38), 7 (6),
8, 11 and 17 (one each).

**The rank-4 caps are not runaways of R2.** At the moment of the cap, the three logged
runs had:

| run | recursion depth | leaves | cuts | synchronizations |
|---|---|---|---|---|
| 1 | 1 | 1 | 0 | 1 |
| 2 | 0 | 0 | 0 | 2 |
| 3 | 10 | 31 | 13 | 2 |

So the cap was hit inside a synchronization subroutine (the braid-cut game, depth cap
120) or inside a cut, not in the recursion. In rank 4, unlike every rank-3 run so far, R2
did need synchronization.

## `sc2.py`

```python
#!/usr/bin/env python3
"""Bounded-damage test SC_2 for the least-damage tree-domination recursion (request of bh-major-mcg-2, 5a5a8bd32).
At every node C (>= 2 fragments) of the R2 recursion, for every first split s of C:
  dmg(s) = max over straddlers f of s of len(resolve(f, ell_s))   (1 if s has no straddler; 2 = single-cut)
  ni(s)  = number of fragments inside a child of s that do not descend from it
Logged per node: histogram of min_s dmg(s) (SC <=> 1 or 2; SC_2 <=> <= 3), of min over s with ni(s) = 0, and of
dmg at the split R2 actually chooses.  Nodes with min_s dmg(s) > 3 are kept as examples.  R2 runs that hit a cap
are logged with their counters and input.
Calibration: rank 2 (no straddlers, all nodes 1); the three logged no-SC nodes (nosc.json) must give min dmg 3.
Usage: sc2.py RANK TL   (instances generated as in sclog.py, seed 4242, one rank per process)."""
import sys, json, time, random
sys.setrecursionlimit(100000)
import tdlib as T
from gen import cell, sub, isdesc, inv, resolve, sync_tree, is_tree, delta, rand_tree, Cap

RANK = int(sys.argv[1])
TL = float(sys.argv[2])
T0 = time.time()
rnd = random.Random(4242)
T.G.rnd.seed(4242)
H = {"nodes": 0, "min_dmg": {}, "min_dmg_ni0": {}, "chosen_dmg": {}, "over3": 0, "over3_examples": []}
orig_choose = T.choose


def bump(d, k):
    k = str(k)
    d[k] = d.get(k, 0) + 1


def split_data(C, frags):
    n = len(C)
    A = inv(C)
    out = {}
    for i in range(n):
        for j in range(i + 1, n):
            c1, c2 = T.children(C, i, j)
            ell = tuple(A[i][k] - A[j][k] for k in range(n))
            strad = [f for f in frags if not sub(f, c1) and not sub(f, c2)]
            dmg = max([len(resolve(f, ell)) for f in strad], default=1)
            ni = sum(1 for f in frags if (sub(f, c1) and not isdesc(f, c1)) or (sub(f, c2) and not isdesc(f, c2)))
            out[(i, j)] = (dmg, ni)
    return out


def logged_choose(C, frags, rule):
    H["nodes"] += 1
    sd = split_data(C, frags)
    m = min(d for d, _ in sd.values())
    bump(H["min_dmg"], m)
    m0 = min([d for d, ni in sd.values() if ni == 0], default="none")
    bump(H["min_dmg_ni0"], m0)
    s = orig_choose(C, frags, rule)
    bump(H["chosen_dmg"], sd[tuple(s)][0])
    if m > 3:
        H["over3"] += 1
        if len(H["over3_examples"]) < 3:
            H["over3_examples"].append({"C": C, "frags": sorted(frags), "dmg": {str(k): v for k, v in sd.items()}})
    return s


def instances(n, k):
    C = delta(n)
    U0 = rand_tree(C, k)
    i, j = sorted(rnd.sample(range(n), 2))
    c1, c2 = T.children(C, i, j)
    A = inv(C)
    ell = tuple(A[i][q] - A[j][q] for q in range(n))
    U1 = [x for p in U0 for x in resolve(p, ell)]
    U = []
    for p in U1:
        S = c1 if sub(p, c1) else c2
        U += [p] if isdesc(p, S) else sync_tree(p, S)
    return [(ch, [p for p in U if sub(p, ch)]) for ch in (c1, c2)]


def snap():
    return {k: (dict(v) if isinstance(v, dict) else v) for k, v in H.items() if k != "over3_examples"}


# calibration on the three logged no-SC nodes (rank 3): split data at the node itself, no recursion
if RANK == 3:
    cal = []
    for ex in json.load(open("nosc.json"))["no_sc_examples"]:
        C = cell([tuple(v) for v in ex["C"]])
        F = [cell([tuple(v) for v in f]) for f in ex["frags"]]
        sd = split_data(C, F)
        cal.append({"pieces": len(F), "dmg_by_split": {str(k): v[0] for k, v in sd.items()},
                    "ni_by_split": {str(k): v[1] for k, v in sd.items()}, "min_dmg": min(d for d, _ in sd.values())})
    print(json.dumps({"calibration_no_sc_nodes": cal}), flush=True)

T.choose = logged_choose
ks = {2: (4, 8, 16), 3: (6, 10, 14, 20, 28, 36), 4: (4, 6, 8, 10, 12, 14)}[RANK]
if RANK == 2:
    for k in ks:
        for _ in range(100):
            D = rand_tree(delta(2), k)
            T.run(delta(2), D, "R2")
    print(json.dumps({"rank": 2, "hist": snap()}), flush=True)
    sys.exit(0)
stat = {"instances": 0, "non_tree": 0, "caps": []}
for k in ks:
    for _ in range(700):
        if time.time() - T0 > TL:
            break
        try:
            inst = instances(RANK, k)
        except (Cap, RuntimeError, RecursionError):
            continue
        for ch, D in inst:
            stat["instances"] += 1
            if is_tree(ch, D):
                continue
            stat["non_tree"] += 1
            s, st, Tr = T.run(ch, D, "R2")
            stat[s] = stat.get(s, 0) + 1
            if s == "cap" and len(stat["caps"]) < 3:
                stat["caps"].append({"k": k, "pieces": len(D), "counters": st, "C": ch, "D": sorted(D)})
    print(json.dumps({"rank": RANK, "after_k": k, "hist": snap(), "secs": round(time.time() - T0, 1)}), flush=True)
print(json.dumps({"rank": RANK, "stat": stat, "hist": snap(), "over3_examples": H["over3_examples"],
                  "secs": round(time.time() - T0, 1)}), flush=True)
```

## 0. Setting and result

- `R = L_(F_2)(1,2)` with `t_i s_j = δ_ij` and `s_0 t_0 + s_1 t_1 = 1`. For a word `μ = μ_1 ... μ_k` put
  `S[μ] = s_(μ_1) ... s_(μ_k)` and `T[μ] = t_(μ_k) ... t_(μ_1)`. So `S[v]T[w]` is the prefix replacement `wy -> vy`, and
  `T[w]S[w] = 1`. This is the convention `s_μ t_ν` of `research/artifacts/depth-monotone-leavitt-firewall-2026-09-12.md`,
  Section 0.
- `e_A = S[A]T[A]`, and `iota_A(r) = S[A] r T[A] + 1 - e_A`. Since `T[A]S[A] = 1`, `iota_A` is an injective unital
  ring homomorphism `R -> R`. Moreover `iota_(A1) = iota_A ∘ iota_1`.
- Code `(0, 10, 11)`, `D_8 = <x_12(1), x_23(1)>`, `iota_A(x_12(1)) = 1 + S[A0]T[A10]`, `iota_A(x_23(1)) = 1 + S[A10]T[A11]`.
- `b_A = S[A0]T[A0] + S[A100]T[A10] + S[A11]T[A110] + S[A101]T[A111] + 1 - e_A` and
  `Gamma_b(A) = <iota_A(D_8), iota_(A1)(D_8), b_A>`, as in `right-child-exchange-group-has-infinite-dihedral-root-closure`.
- **Weights and grading** (firewall artifact, Section 0). For `a, c > 0` put `ω(μ) = a·#_0(μ) + c·#_1(μ)` and
  `R^ω_≤ = span{ S[μ]T[ν] : ω(μ) <= ω(ν) }`. With `deg s_0 = (1,0)`, `deg s_1 = (0,1)`, `deg t_i = -deg s_i`, the
  relations are homogeneous, `R = ⊕_(d in Z^2) R_d`, `deg S[μ]T[ν] = c(μ) - c(ν)` with `c(μ) = (#_0 μ, #_1 μ)`, and
  `R^ω_≤ = ⊕_(ω·d <= 0) R_d`. Here `ω·(d_0, d_1) = a d_0 + c d_1`. So `R^ω_≤` is a unital subalgebra, and
  `R_d R_d' ⊆ R_(d+d')` gives `(⊕_(ω·d <= p) R_d)(⊕_(ω·d <= q) R_d) ⊆ ⊕_(ω·d <= p+q) R_d`.

**Theorem 4.** For every cylinder `A`, `Gamma_b(A)` is sofic.
* Its normal subgroup `N_b`, generated by the `b`-conjugates of the four frame generators `iota_A(x_12(1))`,
  `iota_A(x_23(1))`, `iota_(A1)(x_12(1))` and `iota_(A1)(x_23(1))`, is locally residually finite.
* `Gamma_b(A)/N_b` is cyclic.
* Hence `<x, y, u, beta>` (Section 2) is sofic, and so is `Gamma_b(A) × iota_B(D_8)` for every cylinder `B` disjoint from `[A]`.
* By `sofic-subgroups-carry-independent-cylinder-defects`, the latter carries a fixed-point-free rank model with
  `rk(D_A D_B) = rk(D_A) rk(D_B) = (3/8)^2`, that is, `theta = 1`.

The proof uses only four established results: `depth-monotone-leavitt-subalgebras-are-stably-finite` (finitely generated
unit subgroups of `R^ω_≤` over a finite field are residually finite, and the unit group is sofic),
`sofic-kernel-amenable-quotient-permanence`, `sofic-subgroups-carry-independent-cylinder-defects`, and
`elek-szabo-sofic-permanence` (subgroups and direct limits of sofic groups are sofic).

## 1. Reduction to the root and the kernel N_b

`iota_A` is an injective group homomorphism on units, and `iota_A(b_root) = b_A`, `iota_A(iota_1(r)) = iota_(A1)(r)`. So
`Gamma_b(A) = iota_A(Gamma_b(root)) ≅ Gamma_b(root)`, and from now on `A` is the root. Write
- `x = 1 + S[0]T[10]`, `y = 1 + S[10]T[11]`, `x1 = 1 + S[10]T[110]`, `y1 = 1 + S[110]T[111]`;
- `b = S[0]T[0] + S[100]T[10] + S[11]T[110] + S[101]T[111]`, `Σ = {x, y, x1, y1}`.

Every element of `Σ` is an involution, since `(S[v]T[w])^2 = 0` for incomparable `v, w`.

**Lemma 1.** Let `N_b = < b^j s b^-j : j in Z, s in Σ >` and `Lambda_n = < b^-j s b^j : s in Σ, 0 <= j <= n >`.
1. `N_b` is normal in `Gamma_b` and `Gamma_b / N_b` is cyclic, generated by the image of `b`.
2. Every finite subset of `N_b` lies in `b^J Lambda_(2J) b^-J ≅ Lambda_(2J)` for some `J`.

*Proof.*
1. Conjugation by `b^(±1)` permutes the generators of `N_b`. Each `s in Σ` lies in `N_b` (take `j = 0`), so conjugation by
   `s` preserves `N_b`. Hence `N_b` is normalized by all generators of `Gamma_b`. Modulo `N_b` every `s` is trivial, so
   the quotient is generated by the image of `b`.
2. A finite subset involves finitely many generators `b^k s b^-k`, all with `|k| <= J` for some `J`. Now
   `b^J (b^-j s b^j) b^-J = b^(J-j) s b^-(J-j)`, and `J - j` runs over `[-J, J]` as `j` runs over `[0, 2J]`. QED

## 2. The frame (0,1) and the conjugates

For `r in R`, write `r = Σ_(i,j) s_i r_ij t_j` with `r_ij = t_i r s_j`. The relations make `r -> (r_ij)` a unital ring
isomorphism `R -> M_2(R)`, because `(rr')_ij = t_i r (s_0 t_0 + s_1 t_1) r' s_j`. In this frame:
- `iota_1(r) = [[1, 0], [0, r]]`;
- `beta := S[00]T[0] + S[01]T[11] + S[1]T[10] = [[s_0, s_1 t_1], [0, t_0]]`;
- `beta^-1 = S[0]T[00] + S[11]T[01] + S[10]T[1] = [[t_0, 0], [s_1 t_1, s_0]]`. The product in both orders is the
  identity matrix, using `t_1 s_0 = t_0 s_1 = 0` and `s_0 t_0 + s_1 t_1 = 1`;
- `b = iota_1(beta)`, since `S[1] beta T[1] = S[100]T[10] + S[101]T[111] + S[11]T[110]` and `1 - e_1 = S[0]T[0]`;
- `u := 1 + S[0]T[1]`. Then `y = iota_1(u)`, `x1 = iota_1(x)` and `y1 = iota_1(y)`.

So `b^-j iota_1(g) b^j = iota_1(phi^j(g))` with `phi(g) = beta^-1 g beta`. Also `<y, x1, y1, b> = iota_1(<u, x, y, beta>)`,
so `<x, y, u, beta>` is isomorphic to a subgroup of `Gamma_b`.

**Lemma 2 (conjugates).** Suppose `g = [[1, m], [0, d]]`. Then `phi(g) = [[1, t_0 m t_0], [0, s_0 d t_0 + s_1 t_1 + s_1 t_1 m t_0]]`.
Consequently, for all `j >= 0`, `phi^j(g) = [[1, m_j], [0, d_j]]` with:

| `g` | `m_j` | `d_j` |
|---|---|---|
| `u` (`m = 1`, `d = 1`) | `t_0^(2j)` | `1 + Σ_(i<j) S[0^(j-1-i) 1] T[0^(j+i) 1]` |
| `x` (`m = t_0`, `d = 1`) | `t_0^(2j+1)` | `1 + Σ_(i<j) S[0^(j-1-i) 1] T[0^(j+1+i) 1]` |
| `y` (`m = 0`, `d = 1 + S[0]T[1]`) | `0` | `1 + S[0^(j+1)] T[0^j 1]` |

In addition, `b^-j x b^j = [[1, t_0 beta^j], [0, 1]] = 1 + s_0 t_0 beta^j t_1`.

*Proof.*
- **The step.** `[[t_0, 0], [s_1t_1, s_0]] [[1, m], [0, d]] = [[t_0, t_0 m], [s_1t_1, s_1t_1 m + s_0 d]]`.
  Multiplying on the right by `[[s_0, s_1t_1], [0, t_0]]`:
  - entry `(0,0)` is `t_0 s_0 = 1`;
  - entry `(0,1)` is `t_0 s_1 t_1 + t_0 m t_0 = t_0 m t_0`;
  - entry `(1,0)` is `s_1 t_1 s_0 = 0`;
  - entry `(1,1)` is `s_1 t_1 + s_1 t_1 m t_0 + s_0 d t_0`.
- **Initial values.** `u = s_0t_0 + s_0 t_1 + s_1 t_1`, `x = s_0 t_0 + s_0 t_0 t_1 + s_1 t_1`, and
  `y = s_0 t_0 + s_1 (1 + s_0 t_1) t_1`. These give the `j = 0` rows.
- **Induction.** The `m` column follows from `m_(j+1) = t_0 m_j t_0`.
  - Use `s_0 S[μ] = S[0μ]` and `T[ν] t_0 = T[0ν]`. Then `s_0 d_j t_0` equals `s_0 t_0` plus the old sum with every index
    word prefixed by `0`.
  - For `u`, the term `S[0^(j-1-i)1]T[0^(j+i)1]` becomes `S[0^((j+1)-1-i)1]T[0^((j+1)+i)1]`, the `i`-th term at level
    `j+1`. The remaining summands `s_1 t_1 + s_1 t_1 t_0^(2j+1)` are `s_1 t_1` and `S[1]T[0^(2j+1)1]`, the new term
    `i = j`, because `T[0^(2j+1)1] = t_1 t_0^(2j+1)`. Together with `s_0 t_0 + s_1 t_1 = 1` this gives `d_(j+1)`.
  - For `x` the same computation gives the new term `S[1]T[0^(2j+2)1]`.
  - For `y`, `m = 0` and `s_0 (1 + S[0^(j+1)]T[0^j1]) t_0 + s_1 t_1 = 1 + S[0^(j+2)]T[0^(j+1)1]`.
- **The last formula.** `x = [[1, t_0], [0, 1]]` and `b^(±j) = [[1, 0], [0, beta^(±j)]]`, so
  `b^-j x b^j = [[1, t_0 beta^j], [0, 1]] = s_0 t_0 + s_0 t_0 beta^j t_1 + s_1 t_1`. QED

**Explicit form.** `phi^j(g) = 1 + s_0 m_j t_1 + s_1 (d_j - 1) t_1`, and `iota_1` prefixes every index word by `1`. So:
- `b^-j y b^j = 1 + S[10]T[110^(2j)] + Σ_(i<j) S[110^(j-1-i)1] T[110^(j+i)1]`;
- `b^-j x1 b^j = 1 + S[10]T[110^(2j+1)] + Σ_(i<j) S[110^(j-1-i)1] T[110^(j+1+i)1]`;
- `b^-j y1 b^j = 1 + S[110^(j+1)] T[110^j 1]`.

These were checked exactly, as operators, for `j <= 8` (Section 6).

## 3. Weights

**Lemma 3.** Let `n >= 1` and `ω = (a, c) = (1, n)`. Then `b^-j s b^j in R^ω_≤` for every `s in Σ` and `0 <= j <= n`.
Hence `Lambda_n <= (R^ω_≤)^x`.

*Proof.* `iota_1` preserves degree, since `deg S[1] = -deg T[1]` and `deg S[0]T[0] = 0`. The monomials of the explicit
forms of Section 2 have the following degrees, and `ω·d = d_0 + n d_1`:

| monomial | degree `d` | `ω·d` |
|---|---|---|
| `S[10]T[110^(2j)]` | `(1-2j, -1)` | `1 - 2j - n <= 0` |
| `S[110^(j-1-i)1]T[110^(j+i)1]` | `(-1-2i, 0)` | `< 0` |
| `S[10]T[110^(2j+1)]` | `(-2j, -1)` | `< 0` |
| `S[110^(j-1-i)1]T[110^(j+1+i)1]` | `(-2-2i, 0)` | `< 0` |
| `S[110^(j+1)]T[110^j1]` | `(1, -1)` | `1 - n <= 0` |

This covers `y`, `x1` and `y1`, for all `j >= 0` (no bound on `j` is needed).

For `x`, consider `b^-j x b^j = 1 + s_0 t_0 beta^j t_1`.
- The three monomials of `beta` have degrees `(1,0)`, `(1,-1)` and `(-1,0)`, with `ω·d = 1`, `1 - n` and `-1`. So
  `beta in ⊕_(ω·d <= 1) R_d` and `beta^j in ⊕_(ω·d <= j) R_d`.
- `deg(s_0 t_0) = 0` and `deg t_1 = (0,-1)`, with `ω·d = -n`.
- So `s_0 t_0 beta^j t_1 in ⊕_(ω·d <= j - n) R_d ⊆ R^ω_≤` for `j <= n`.

Every generator of `Lambda_n` is an involution in `R^ω_≤`, so its inverse lies in `R^ω_≤`, and the group it generates
consists of units of `R^ω_≤`. QED

**Remark 3.1 (sharpness; b escapes).**
1. For `ω = (1, n-1)`, `n >= 2`, `b^-n x b^n` is not in `R^ω_≤`.
   - On points, `beta^n(0z) = 0^(n+1) z`. So `s_0 t_0 beta^n t_1 e_10 = S[0^(n+1)]T[10]`, where
     `e_10 = S[10]T[10]` has degree `0`.
   - Projections to homogeneous components commute with right multiplication by `e_10`. So the component of
     `b^-n x b^n` in degree `(n, -1)` is nonzero, and `ω·(n,-1) = 1 > 0`.
   - For a fixed weight, the conjugates `b^-j x b^j` therefore leave `R^ω_≤` for large `j`. No single weighted unit group
     contains `N_b`, and the weight has to drift with `n`.
2. `b` itself has the single-monomial components `S[100]T[10]` in degree `(1,0)` and `S[11]T[110]` in degree `(-1,0)`.
   So `b` lies in no `R^ω_≤` and no `R^ω_≥`. The firewall of `depth-monotone-leavitt-subalgebras-are-stably-finite`
   does not see `Gamma_b` directly; it sees only the finitely generated pieces of the kernel, one weight at a time.
3. Both statements are confirmed on canonical forms by `check_weights.py` for `n <= 5`. The canonical form certifies
   non-membership: it is a sum of monomials on distinct leaves of a prefix code, so right multiplication by a leaf
   idempotent isolates each leaf.

## 4. Soficity

**Lemma 4.1 (weight drift).** Let `K` be a finite field and `G = <S, b> <= L_K(1,2)^x` with `S` finite and `S = S^-1`. Suppose that for
every `n` there is a positive weight `ω_n` such that `b^-j S b^j ⊆ R^(ω_n)_≤` for all `0 <= j <= n`, or all
`⊆ R^(ω_n)_≥`. Then `N = <b^j S b^-j : j in Z>` is normal with cyclic quotient and locally residually finite, and `G` is
sofic.

*Proof.*
- Lemma 1 works verbatim with `Σ` replaced by `S`.
- `Lambda_n = <b^-j S b^j : 0 <= j <= n>` is generated by a finite symmetric subset of `R^(ω_n)_≤` (or `≥`), so it is a
  finitely generated subgroup of `(R^(ω_n)_≤)^x` (or `≥`). By `depth-monotone-leavitt-subalgebras-are-stably-finite` it
  is residually finite, and that claim also makes the whole weighted unit group sofic, so `Lambda_n` is sofic as a
  subgroup (`elek-szabo-sofic-permanence`).
- `N = ∪_J b^J Lambda_(2J) b^-J` is an ascending union of sofic subgroups, so `N` is sofic (`elek-szabo-sofic-permanence`,
  direct limits). Equivalently: soficity is defined through finite subsets, and every finite subset of `N` lies in one
  of these conjugates.
- `G/N` is cyclic, hence amenable, and `sofic-kernel-amenable-quotient-permanence` gives soficity of `G`. QED

*Proof of Theorem 4.*
1. By Lemmas 1 and 3, Lemma 4.1 applies to `Gamma_b(root)` with `S = Σ` (involutions, so symmetric) and
   `ω_n = (1, max(n,1))`. So `Gamma_b(root)` is sofic, hence so is `Gamma_b(A) ≅ Gamma_b(root)` (Section 1).
2. Subgroups of sofic groups are sofic (`elek-szabo-sofic-permanence`). So `<x, y, u, beta> ≅ <y, x1, y1, b>` is
   sofic (Section 2).
3. **The product with a disjoint frame.**
   - Let `B` be disjoint from `[A]`. Then `e_A e_B = e_B e_A = 0`. Elements `1 - e_A + p` with `p in e_A R e_A` and
     `1 - e_B + q` with `q in e_B R e_B` multiply in either order to `1 - e_A - e_B + p + q`, so they commute. The two
     subgroups meet trivially: compressing by `e_B` sends the first kind to `e_B` and the second to `q`.
   - So `H_B := <Gamma_b(A), iota_B(D_8)> = Gamma_b(A) × iota_B(D_8)`. Its normal subgroup `Gamma_b(A)` is sofic with
     finite quotient, so `H_B` is sofic by `sofic-kernel-amenable-quotient-permanence`.
4. **The model.** Take `A` nonempty and proper and `B` nonempty and proper. Then `H_B` contains `iota_A(D_8)` and
   `iota_B(D_8)`, and `b_A` has infinite order (`leavitt-right-child-frames-generate-infinite-order-units`; also
   Remark 3.1.1, since `b^-n x b^n` are pairwise distinct). `sofic-subgroups-carry-independent-cylinder-defects` gives a
   characteristic-two rank model of `H_B` that is free on finite subgroups and fixed-point-free, with
   `rk(D_A D_B) = (3/8)^2 = rk(D_A) rk(D_B)`. QED

## 5. Consequences for the lane and what stays open

- **The Gamma_b candidate for a relation-only deficit is dead.**
  - The attempt entry "Right-child exchange group (w7-gamma-b)" on `leavitt-disjoint-cylinder-defects-strictly-submultiplicative`
    ends with: is `<x, y, u, beta>` amenable, or does it contain a free subgroup?
  - By Theorem S of the dihedral-closure artifact, what matters is only soficity of `Gamma_b`, and Theorem 4 proves it.
  - The artifact sentence "if `Gamma'` contains a free subgroup, `Gamma_b` stays a live candidate" is superseded: a free
    subgroup no longer makes it a candidate.
  - No `theta < 1` inequality follows from relations that hold in `Gamma_b(A) × iota_B(D_8)`, together with rank
    calculus, nontriviality and fixed-point-freeness.
- **Where a certificate must live.** Combined with `sofic-subgroups-carry-independent-cylinder-defects`, a relation-only
  proof of the hole must use a nonsofic subgroup containing `iota_A(D_8)` and `iota_B(D_8)`. Candidates that neither the
  firewalls on the hole's attempt list nor Lemma 4.1 cover:
  - `EL_3(J)` (`binary-jacobson-el3-is-sofic`, open);
  - `R^x` itself.
- **Scope of Lemma 4.1.** It needs a single element `b` such that, over each finite window of exponents, the
  `b`-conjugates of a symmetric generating set lie in one weighted subalgebra. Groups whose soficity would need several
  conjugating elements, or conjugates escaping every weighted subalgebra, are not covered.
- **Open, not needed here.**
  - Amenability of `<x, y, u, beta>`, and free subgroups in it. The lane note

## 6. Computations

Scripts in `experiments/right-child-root-group-2026-09-16/`. `leavitt_ops.py` implements exact arithmetic of `L_(F_2)(1,2)`
in canonical form (a complete prefix code of leaves `ν` with finite sets `F_ν`, representing `Σ_ν Σ_(μ in F_ν) S[μ]T[ν]`).
All runs are single-threaded, under `timeout 600`, with `python3 -B`.

- **`support_closure.py`.**
  - Asserts that `x, y, x1, y1` are involutions and that `b, b^-1` are inverse.
  - Asserts the explicit forms of Section 2 for `j <= 4`, and that `b^-j x b^j` fixes `[0]` pointwise.
    Output: `generator formulas verified for j <= 4`.
- **Cross-check of local finiteness on points, not used in the proof.** For `Lambda_n`, `n = 1..4`, and 24 test points
  `z` each, the script computes the smallest set of explicit prefixes containing `z` and closed under the generators.
  - Test points consist of random short runs, then a run of `0`s of length at least `2n` after a `1`, then junk.
  - All closures are finite, with maximal sizes 62, 111, 150 and 122.
  - Controls with only short runs (`1^62`, `11(10 01)^30`) are consumed down to prefix length 2, as expected: the
    generators read at most `2n` levels of runs.
- **`check_weights.py`** (imports `support_closure.py`).
  - For `n = 0..5` and weight `(1, max(n,1))`, every canonical monomial of all `4(n+1)` generators of `Lambda_n`
    satisfies `ω(μ) <= ω(ν)`, with minimal slack 0.
  - For `n = 2..5` and weight `(1, n-1)`, `b^-n x b^n` has a violating monomial (Remark 3.1).
  - `b` contains `S[100]T[10]` and `S[11]T[110]`.
- **`extended_check.py`.**
  - Re-verifies the closed forms of Lemma 2 for `j <= 8`.
  - For `b^-j x b^j` with `j <= 8`, it finds the least integer `c` such that every canonical monomial satisfies
    `ω(μ) <= ω(ν)` for `ω = (1, c)`. Output: `c = 1, 1, 2, 3, 4, 5, 6, 7, 8` for `j = 0, ..., 8`. So `c = max(j, 1)`,
    exactly as Lemma 3 and Remark 3.1 predict.
  - The sizes (numbers of canonical monomials) are `2j + 4`.

# Boone–Higman swarm 7, lane `bh-simple-products-embed`: does S x T embed in a finitely presented simple group?

2026-09-12. Question: for finitely presented simple `S` and `T`, does `S x T` embed in a finitely presented simple group? This is equivalent to closure of the Boone–Higman class under finite direct products (`boone-higman-closed-under-finite-direct-products`).

**Outcome: not settled; one more reduction.**
- **Unconditional.** `S x T` sharply embeds in a finitely presented relatively simple group, an abstract twisted Brin–Thompson group. Its simple quotient contains `S x T`, but it is finitely presented only when both action images are.
- **New conditional route.** The second part of FFWZ Question 5.9 turns that relatively simple group into a finitely presented simple envelope of `S x T`. It is independent of the first-part route already in the graph.
- **Computability obstruction for the second part.** A positive answer forces the simple quotient of every finitely presented relatively simple group to have solvable word problem.
- **The three candidates in the lane directive** each reduce to a known gap (Section 4).

After this lane the closure follows from any one of four open inputs:
1. the Boone–Higman conjecture;
2. FFWZ Question 5.9, first part;
3. FFWZ Question 5.9, second part (new here);
4. BFFHZ Question 3.4.

## 1. Unconditional: S x T sharply embeds in a finitely presented relatively simple group

Let `S` and `T` be finitely presented simple.
1. **Relative actors.** By Theorem 5.1, `S` sharply embeds in `(A_1, K_1)` and `T` in `(A_2, K_2)`, for type [A_2] actions `A_i ↷ X_i` with kernels `K_i`.
2. **Product actor.** `A = A_1 x A_2` acts on `X = X_1 ⊔ X_2` with type [A_2] and kernel `K = K_1 x K_2`, and `S x T` sharply embeds in `(A, K)`. This is `relative-pbh-closed-under-finite-direct-products`.
3. **Twisted Brin–Thompson group.** Let `λ: A → SV_A` be the map of Lemma 5.2, so `λ(A) ∩ SK_A = λ(K)`. `SV_A` is finitely presented (Theorem 4.1(ii)), and `(SV_A, SK_A)` is relatively simple (Theorem 3.6).
4. **Sharpness.** Put `P = λ(S x T)`. Then `P ∩ SK_A = P ∩ λ(A) ∩ SK_A = λ((S x T) ∩ K) = 1`.

So `S x T` sharply embeds in the finitely presented relatively simple group `SV_A`, and it embeds in the simple group `SV_A/SK_A = SV_{A/K}`. By Corollary 4.2 that quotient is finitely presented iff `A/K = (A_1/K_1) x (A_2/K_2)` is, that is, iff both factor images are. That is the gate of Attempt 2 of the closure claim.

The graph records steps 3–4 for an arbitrary type [A_2] action as `abstract-btb-pairs-fp-and-relatively-simple` (literature import).

## 2. The second part of Question 5.9 closes the gap

This is route `bh-product-closure-via-relatively-simple-kernel-removal`. It continues the steps of Section 1.

5. **Removal.** The second part of Question 5.9 (`fp-relatively-simple-pairs-embed-with-fng-kernels`) gives two things:
   - a finitely presented relatively simple `(G′, N′)` with `N′` finitely normally generated;
   - an injective `ι: SV_A → G′` with `ι(SV_A) ∩ N′ = ι(SK_A)`.
6. **Sharpness survives.** `ι(P) ∩ N′ = ι(P) ∩ ι(SV_A) ∩ N′ = ι(P ∩ SK_A) = 1`.
7. **Envelope.** `G′/N′` is finitely presented, by adding finitely many relators. It is simple by Definition 1.2, and it contains `S x T` by step 6.

**Reading of "sharply embed" for pairs.** It is read as "embeds" in Definition 1.6. FFWZ use the phrase this way for pairs in Lemma 5.2, whose proof checks exactly `λ(G) ∩ SK_G ⊆ λ(K)`. Any stronger reading implies this one.

**Relation to the first-part route** `bh-product-closure-via-a2-kernel-removal`.
- The first part removes the kernel of an action. It then quotients to a faithful type (A) actor and uses Zaremsky's Corollary B.
- The second part removes the largest normal subgroup of a relatively simple group and quotients straight to a simple group.
- Neither is known to imply the other (Section 3, Attempt 2).

## 3. The second part: attempts

1. **Computability.** Let `(G, N)` be finitely presented and relatively simple, with `G = <X | R>`.
   - **`N` is co-r.e.** For `g ∈ G`, `g ∉ N` iff `<<g>> = G`: a proper normal closure lies in `N`, and the normal closure of an element of `N` stays in `N`. Also, `<<g>> = G` iff every `x ∈ X` is a consequence of `R ∪ {g}`, which is r.e.
   - **`N` is recursive iff `G/N` has solvable word problem**, because `w = 1` in `G/N` iff `w ∈ N`. By Kuznetsov's argument, `N` r.e. already suffices.
   - **Necessary condition.** Suppose `(G,N)` embeds in `(G′,N′)` as in the second part. Then `G′/N′` is finitely presented simple, so it has solvable word problem, and `N = ι⁻¹(N′)` is recursive.
   - **Where counterexamples live.** A finitely presented relatively simple group whose simple quotient has unsolvable word problem refutes the second part. Every counterexample has a simple quotient that is not finitely presented, since otherwise `(G,N)` itself works.
   - **FFWZ's unsolvable example is not one.** In lines 1251–1254 the action is on one point, so the kernel is all of `G` and the image is trivial. By Corollary 4.2 the simple quotient is finitely presented, and the pair is its own witness.
   - **Twisted Brin–Thompson pairs.** For a type [A_2] action `H ↷ S` with kernel `K`, membership in `K` reduces to membership in `SK_H` through `λ` of Lemma 5.2. So a type [A_2] action with non-recursive kernel refutes both parts of Question 5.9 at once. For the Theorem C actor, an infinite finitely presented simple group with non-recursive one-variable mixed identities would give one, since those identities many-one reduce to the kernel (`a2-kernel-removal-forces-recursive-kernel` (c)).
   - *Deferred*: no such group is known here.
2. **No formal link with the first part.**
   - **From the first part to the second.** A kernel-removing embedding `(G,K) → (G′,K′)` of type [A_2] pairs comes with no map between the sets acted on. So it gives no evident embedding of pairs `(SV_G, SK_G) → (SV_{G′}, SK_{G′})`. If it did, Corollary 4.2 would make `SK_{G′}` finitely normally generated, which is the second part for twisted pairs.
   - **From the second part to the first.** The output of the second part carries no action. Turning even a twisted Brin–Thompson pair into an action pair is FFWZ Question 5.7.
   - *Stops*: neither part is known to give the other.
3. **Removal does not multiply over factors.** For proper pairs, `(G_1 x G_2, N_1 x N_2)` is not relatively simple: `G_1 x N_2` is a proper normal subgroup outside `N_1 x N_2`. Removability for the first part does pass to products (`relative-pbh-closed-under-finite-direct-products`, item 3). The second part for two factors gives no relatively simple pair for the product. So the route applies it once, to `SV_A` of the product actor. *Consequence only.*

## 4. Candidates in the lane directive (closure claim, Attempts 7–11)

7. **Coordinatewise abstract twisted Brin–Thompson groups.**
   - `SV_{A_1} x SV_{A_2}` is finitely presented, and `S x T` meets `SK_{A_1} x SK_{A_2}` trivially.
   - That pair is not relatively simple (Section 3, Attempt 3).
   - The relatively simple group built from both actors is `SV_A` of Section 1.
   - *Stops* at the gate of Attempt 2.
8. **"Every finitely presented simple group satisfies PBH."** By BFFHZ Theorem C (i)⇔(iv), this statement is exactly BFFHZ Question 3.4, so it is Attempt 1.
   - **Intrinsic sufficient condition.** A finitely presented simple `S` admits a faithful type [A_2] action iff it has a proper finitely generated subgroup `H` with finitely many double cosets `H\S/H`. Then `SV_S` is finitely presented and simple and contains `S` (Theorems 3.6 and 4.1(ii), Lemma 5.2), so `S` satisfies PBH.
   - **Proof.** Given such an action, pick a point `x` with a non-trivial orbit and put `H = Stab_S(x)`. It is proper and finitely generated, and the double cosets `H\S/H` match the orbits on pairs in `Sx`, which are among the finitely many pair orbits. Conversely, use the coset action on `S/H`. Point stabilizers are conjugates of `H`, pair orbits match double cosets, and the kernel is a proper normal subgroup, hence trivial.
   - *Stops*: no general source of such `H`.
9. **Wreath and automorphism overgroups.**
   - `S ≀ Z/2` contains `S x S`, and `Aut(S x T)` contains `S x T`, in each case as a normal subgroup. So neither is simple, and a simple envelope of either is the same problem.
   - For `S ≀_X B` with `B` simple acting non-trivially on `X`, Lemma 3.1 makes the base `⊕_X S` the largest normal subgroup. The simple quotient is `B`, and no product of copies of `S` embeds sharply.
   - *Dies.*
10. **Joint embedding and squares.** The closure holds iff both of the following hold.
   - **(JE)** Any two finitely presented simple groups embed in one finitely presented simple group.
   - **(SQ)** `U x U` embeds in a finitely presented simple group for every finitely presented simple `U`.
   - **Proof.** The closure gives both. Conversely, `S, T ≤ U` by (JE), and `S x T ≤ U x U`.
   - *Stops*: neither is available in general. BFFHZ Corollary F gives free products, hence (JE), only for PBH factors, and (SQ) holds inside PBH (closure claim, Attempt 5).
11. **The Theorem C actor of `S x T` itself.** Rerun the proof of Theorem 5.1 with `Γ = S x T`.
   - `Γ` is finitely presented with trivial center, so `Aut_Γ(Γ * F_n)` is finitely presented (BFFHZ Proposition 1.1). Point stabilizers are finitely generated because `Γ` is finitely generated (BFFHZ Proposition 2.6).
   - The Γ-translations act freely, and that argument (lines 1225–1231) uses no simplicity.
   - Finitely many pair orbits came from high transitivity, which FFWZ derive from simplicity (BFFHZ Proposition 2.3). This was not rechecked for `S x T`.
   - **Never faithful.** Take the mixed identity `w(y) = [[y,(s,1)],(1,t)]` of Attempt 4. The automorphism fixing `Γ` and every other generator and sending `x_1 ↦ x_1 w(x_2)` is non-trivial, since `w(x_2) ≠ 1` in `Γ * F_n`. It acts trivially on `Hom_Γ(Γ * F_n, Γ)`, since `w(φ(x_2)) = 1` for every `φ`.
   - *Dies*: at best one more relative actor, behind the gate of Attempt 2.

## 1. Which relation breaks the models (question (a))

**Answer.** In every case, the first relation known to break *every* extension to `V` is [CG] Theorem 1.1 on a
**finite group mixing two primes**, `B ⋊ G`.
- `G` is the finite `p`-group carrying the model.
- `B ≅ (Z/q)^N` is generated by clopen `q`-cycles on the canonical partition of `G`, with `q != p`.
- In characteristic 3, `q = 5` as in [FR] §3.1. In characteristic 2, `q = 3`.

No word involving `x_0` or `x_1` is needed, and neither is a lamplighter piece `B ⋊ <x>` or the group
`<x_0, x_1, s>`.

**The relations used** (premises (P1)–(P3) of [FW]):
- **(R1) Orders:** `c^q = 1` and `g^p = 1`.
- **(R2) Disjoint commutation:** `[c_v, c_w] = 1` for disjoint supports.
- **(R3) Conjugation data:** `g c_v g^(-1) = c_(g v)` for `g in G`.
- **(R4) (T):** one constant `a_q` for all clopen `q`-cycle groups. It uses tree refinement `c_v = c_(v0) c_(v1)` and
  single-element `V`-conjugacy of clopen `q`-cycles through arbitrary conjugators ([TS] Lemma 1.1).

(Phi) only names the constant. The contradictions below use only that `G` has *one* trivial-plus-regular weight `α`.

### 1.1 The tree model `rk_2` in characteristic 3 (`2 <= m < p` means `m = 2`)

**Claim 1.1.** No rank function on `F_3[V]` restricts to `rk_2` on `<tau_1>`, where `tau_1` is a clopen 3-cycle.

*Proof.*
- `rk_2` gives `rk((1 - [tau_1])^j) = max(2 - j, 0)/2`, so the profile is `(1/2, 0)` for `j = 1, 2` ([PC] Lemma 2.2).
- Theorem 1.1 on `G = <tau_1>` gives `(1 - α)(3 - j)/3` for a single `α`.
- At `j = 2`, `(1 - α)/3 = 0` forces `α = 1`.
- Then `j = 1` gives `0 != 1/2`. ∎

**Smallest configuration.** A single finite group `B ⋊ <tau_1>`, with `q = 5` fixed.
- **Construction.** `B ≅ (Z/5)^(k|P|)`, built as in [PC] §1 Step 0: `k` clopen 5-cycles per piece of the canonical
  partition.
- **Error.** [PC] §1 gives the error `3n(|G| + 1)(1 - α) 5^(-k)`.
  - With `n = 1` and `|G| = 3`, step `j = 2` needs `12 · 5^(-k) < 1/3`, so `k = 3` suffices.
  - At `j = 1` the error carries the factor `1 - α = 0`.
  - [CG] §1 has error `2n|G|/q` and needs `q -> infinity`, so it gives no single finite configuration (`w3-vf-linear`
    §34.1).
- **Where each part comes from.** [PC] Step 2 (free orbits of characters of `B` give matrix units) produces the
  regular part, and Step 4 (trivial character) together with (T) weights it.

**Compare [PC] §2 premise audit.** That audit breaks only the *induced* extension to `W = E_3 ⋊ <s> ≅ Z/3 wr Z/3`, a
3-group, through (R3) and the conjugacy `tau_1 ~ s`. I have not decided whether 3-group data plus single-element
`V`-conjugacy break *every* extension of `rk_2`. `p-cycle-tree-invariance-cannot-force-order-char-law` rules out
endomorphism invariance alone.

### 1.2 The tree model `rk_3` in characteristic 3

- Single elements have the regular profile `(2/3, 1/3)`, so `α = 0`.
- The joint fixed rank of `E_r` is `1/3` for every `r` ([PC] Lemma 2.2).
- Theorem 1.1 on `G = E_2 = <tau_1, tau_2>` with `α = 0` gives joint fixed rank `3^(-2) = 1/9 != 1/3`.

**Smallest configuration.** `B ⋊ E_2`, finite through [PC] §1 at `q = 5`.

### 1.3 The counter-model of `w7-v-cycle-c2` in characteristic 2

The model is `rho(t_i) = 1 + lambda_i e_12` ([CG] §3).
- Singles: `rk(1 + [t]) = 1/2`, which is regular for `Z/2`, so `α = 0`.
- Theorem 1.1 on `E_2` with `α = 0` gives joint fixed rank `1/4`, but the model gives `1/2`.

**Smallest configuration.** `B ⋊ E_2`, with `B` a 3-group: a finite group mixing 2 and 3. This matches [CG]'s own
audit, where the first premise broken is Step 2 for `G = E_k`.

### 1.4 Firewall consistency

Every configuration in 1.1–1.3 is finite, hence sofic. Two kinds of rank function satisfy Theorem 1.1:
- `rk_aug`, with `α = 1`;
- on each sofic `K <= V`, the ultraproduct permutation ranks, with `α = 0` on finite subgroups ([FW] Thm 1.2).

Their mixtures `t rk_sofic + (1 - t) rk_aug` satisfy every confined premise on `K` with `α = 1 - t`. So these relations:
- separate the `p`-tree models from {augmentation, sofic};
- cannot force `α in {0, 1}`, let alone `α = 1`.

Breaking the models decides nothing about the gate, which is what [FW] Cor 4.1 predicts.

## 2. The gate at `<x_0, x_1, s>` (question (b))

### 2.1 Generation: `<x_0, x_1, s> = V` is false for the natural choices

Let `F = <x_0, x_1>` be the standard generators, acting on `X = {0,1}^N` by prefix replacement.

**Claim 2.1.** Each of the following gives a proper subgroup of `V`.
1. **`s` fixes `0^∞` or `1^∞`.** For example `s: 00w -> 01w -> 10w -> 00w` with `[11]` fixed. Every element of `F` fixes
   both `0^∞` and `1^∞`, so `<x_0, x_1, s> <= Stab_V(1^∞)` (or `Stab_V(0^∞)`). This is proper, since `V` moves both
   points.
2. **`s = C`, the order-3 generator of [CFP].** `C` is `0w -> 11w`, `10w -> 0w`, `11w -> 10w`, i.e. `x/2 + 3/4`,
   `2x - 1`, `x - 1/4` on `[0,1/2]`, `[1/2,3/4]`, `[3/4,1]`.
   - **`C` is not a clopen 3-cycle.** Its three cylinders cover `X`, so it has no fixed points. Since
     `Fix(h g h^(-1)) = h Fix(g)`, it is not `V`-conjugate to a clopen 3-cycle.
   - **It is a product of two.** `C = c' c''` with `c' = (00 -> 110 -> 100)` and `c'' = (01 -> 111 -> 101)`, two
     disjoint clopen 3-cycles, each leaving a nonempty complement.
   - **Generation.** `<x_0, x_1, C> = <A, B, C> = T` ([CFP] §5). This is proper: item 1's `s` sends
     `(00, 01, 10, 11)` to `(01, 10, 00, 11)`, which is not a rotation, so `s` is not in `T`.
   - **`T` contains no clopen 3-cycle** (`w3-vf-linear` §34.2).
     - A nontrivial finite-order orientation-preserving circle homeomorphism has no fixed point.
     - A clopen 3-cycle fixes a nonempty clopen set.
     - So `c'` and `c''` lie outside `T`. In `F_3[T]`, Theorem 1.1 enters only through `<C>` and the other finite
       subgroups of `T`.
     - On `<C>` it gives `rk((1 - [C])^j) = (1 - phi_V)(3 - j)/3`.

**Criterion for the remaining `s`.** Take `s` not in `T` moving both `0^∞` and `1^∞`, for example
`00w -> 11w -> 01w -> 00w` with `[10]` fixed. Then `<x_0, x_1, s> = V` iff it contains every clopen 3-cycle with
nonempty complement, because those form one `V`-conjugacy class ([TS] Lemma 1.1), whose normal closure is `V` by
simplicity. I did not decide whether `F`-conjugates of `s^(±1)` generate that class. The obstacle is that `F` preserves
the gap pattern of an ordered triple of cylinders.

**Effect on the gate.** None. Theorem 1.1 and `phi_V` are global, so an identity in `F_3[H]` for any
`H = <x_0, x_1, s>` combines with Theorem 1.1 on finite subgroups of `H`, with `α = phi_V`. The live choices are
`H = T` (with `s = C`) and `H = <x_0, x_1, s>` with `s` not in `T`. Neither is known to be sofic.

### 2.2 What an identity forcing `phi_V in {0, 1}` must look like

By convexity with `rk_aug` ([CG] §4.4), the gate is equivalent to `phi_V in {0,1}` for every `rk`. By [FR] Cor 1.3(3),
any `rk` with `phi_V < 1` is detecting, so it refutes the gate. `phi_V = 0` is only the normalized form.

**Premises available on `F_3[H]`:**
- Theorem 1.1 on every finite `G <= H`;
- identities in `F_3[H]`;
- the 3-sensitive identity `(1 - [s])^3 = 0`;
- single-element `V`-conjugacy.

**Excluded configurations.** An identity whose group lies inside any of these cannot decide the gate (§1.4 and [FW]):
- locally finite groups (finite groups included);
- `B ⋊ <x>` with `B` locally finite (amenable, [FR] §3.2);
- lamp groups `<x, L> ≅ L wr Z` ([FW] Prop 2.1);
- free products of finite groups (residually finite);
- `F`, if `F` is amenable;
- identities over subrings of `C`, which `rk_vN` satisfies ([FW] Cor 3.2).

**The non-sofic-known configuration an identity must use.** `T` or `<x_0, x_1, s>`, using `(1 - [s])^3 = 0`
essentially (in `T`, `(1 - [C])^3 = 0`). The same holds for any subgroup of `V` containing `F` together with a clopen
3-cycle, when `F` is non-amenable.

**Result: no identity found.**
- **Inert.** Single polynomials in one wandering `[x]` ([FR] Thm 2.3) and matrices over locally finite subgroups
  satisfy the mixtures of §1.4.
- **Open.** I found no matrix identity over `F_3[H]` that mixes `x_0`, `x_1` with `s` and avoids every configuration
  on the excluded list.

### 2.3 A characteristic-three `phi_V = 0` model not from soficity: none known

**Would refute the gate:**
- **Soficity of `V`.** Sofic ranks have `phi_V = 0` ([FW] Thm 1.2 applied to `K = V`), but they come from soficity.
- **`F_3`-linear soficity of `V`** (`linear-sofic-group-algebra-is-stably-finite` gives the weakly finite side).
  - Normalized rank distance bounded below gives `rk(1 - [g]) > 0`, so `phi_V < 1`. That already refutes the gate.
  - Reaching `phi_V = 0` then uses `v-rank-functions-split-as-augmentation-plus-reduced` (OPEN).

**Cannot be the source:**
- **Covariant models from the Cantor action.** They are blocked in characteristic 2
  (`thompson-v-cantor-system-has-no-covariant-rank-model`). The covariance theorem holds abstractly but is vacuous on
  `F_3[V]` (gate node, w5-v-infinite-order entry).
- **The `p`-tree models and `w7-v-cycle-c2`'s model.** They break on finite mixed-prime groups (§1).

**Status.** I constructed no source that is non-matricial or not from soficity. The gate stays OPEN.

## 3. What a `phi_V = 0` characteristic-three model would do (question (c))

Let `rk` be a Sylvester rank function on `F_3[V]` with `phi_V = 0`, or more generally `phi_V < 1`.

**Claim 3.1 (what it gives on V).**
1. **The gate falls.** `rk` refutes `thompson-v-ternary-rank-functions-are-augmentation` and establishes
   `thompson-v-carries-ternary-nonaugmentation-rank-function`.
2. **A faithful weakly finite image of V.** Put `I = {a : rk(a) = 0}` and `W_V = F_3[V]/I`.
   - **Weakly finite.** If `XY = I_n` over `W_V`, then `YX` is idempotent of rank `n`, so `rk(I_n - YX) = 0`. So
     every entry of `I_n - YX` lies in `I`.
   - **Injective on V.** `{g : rk(1 - [g]) = 0}` is a normal subgroup of `V`. It misses any clopen 3-cycle `s`, since
     `rk(1 - [s]) = 2(1 - phi_V)/3 > 0` ([CG] Cor 1.2). By simplicity it is trivial.
3. **Pullback to the signed group.** By `signed-thompson-z-moving-rank-functions-match-v-rank-functions`, `rk` gives a
   rank function on `F_3[E ⋊ V]` that moves `z`.
   - Its null quotient is weakly finite with `[z] != 1`.
   - So `eps_- F_3[E ⋊ V]` has a nonzero weakly finite quotient.
   - Contrapositive: any proof of `ternary-anti-central-summand-has-no-weakly-finite-image` confined to `E ⋊ V` proves
     the gate claim itself. That is sharper than the node's "would show V is not sofic".

**Claim 3.2 (what it does not give).** On its own, `rk` does **not** touch
`ternary-anti-central-summand-has-no-weakly-finite-image`.
- [VX] Prop 5.2 needs a unital ring map `rho: F_3[G_3] -> W` into a weakly finite `F_3`-algebra, injective on `V`.
  `rk` lives only on `F_3[V]`.
- Producing `rho` is the open target `v-detecting-rank-functions-extend-to-ternary-leavitt-units`.
- There is no Hamming-model extension, since `G_3` and `PG_3` are nonsofic ([VX] §1.2).
- There is no averaging, since `G_3` has (T) and `[G_3 : V]` is infinite ([VX] §1.3).
- [VX] Cor 5.1: under a detecting `rk`, that target fails iff link 1 holds.

**Claim 3.3 (if it extends).** Suppose some unital weakly finite `rho` on `F_3[G_3]` exists that is injective on `V`,
rank-induced or not. Prop 5.2 gives exactly two cases.
- **`rho([z]) != 1`.**
  - The image `rho(S_-)` is a nonzero weakly finite quotient of `S_-`.
  - It lies in the corner `rho(eps_-) W rho(eps_-)`, which is weakly finite (`XY = e` gives
    `(X + 1 - e)(Y + 1 - e) = 1`). The corner itself is not a quotient.
  - This refutes `ternary-anti-central-summand-has-no-weakly-finite-image`, and with it the corner route to the
    counterexample.
  - Gottschalk itself is not refuted, since a J_1 != 0 certificate survives (RULES.md CORRECTION and the
    w3-strategist-gate note).
- **`rho([z]) = 1`.** `rho` factors through `F_3[PG_3]` and is injective on `PG_3`. The summand node is untouched.

**Contrapositive.** The summand node plus Prop 5.2 imply that every weakly finite unital image of `F_3[G_3]` injective
on `V` kills `z`.
- **Obstructions confined to `E ⋊ V`.** They are not excluded, but by Claim 3.1(3) such an obstruction would prove the
  gate claim, and with it non-soficity of `V`.
- **So** a weakly finite obstruction that does not also decide the gate has to use letters of `G_3` outside `E ⋊ V`.
- This matches [VX] §5.2: at least two letters outside `L`, and nonsofic subgroups.

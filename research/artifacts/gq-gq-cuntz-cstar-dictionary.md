# Cuntz / C*-algebra transplant for GL_n(Q): dictionary and where it breaks

Lane `gq-cuntz-cstar`, 2026-09-17. Target: root `gl-n-q-embeds-in-fp-simple-group`.

## 1. Dictionary

| C*-algebra world | algebraic shadow | group-theoretic meaning |
|---|---|---|
| `O_2 = C*(S_0, S_1)` | Leavitt algebra `L_k(1,2)` | Thompson's `V` = monomial units `Σ s_α t_β` |
| `O_2 ⊗ M_n ≅ O_2` | `M_n(L) ≅ L` (prefix codes) | `V_(2,n) ≅ V`; `GL_n(k) ⊂ L^x` by corner matrices |
| diagonal masa `C(X) ⊂ O_2` | Leavitt diagonal = locally constant `X -> k` | cylinder projections, germs |
| continuous but not locally constant `f ∈ C(X)` | harmonic function `η = 1/(1 + #leading 1s)` | **supplies divisibility**: `t_0 t_1^k η s_1^k s_0 = 1/(k+1)` |
| pure infiniteness (Cuntz: `∀a≠0 ∃x,y: xay = 1`) | two-sided division | root detection, so `EL_n` is simple modulo scalars |
| `K_*(O_2) = 0` (Cuntz) | `K_*(L_k(1,2)) = 0` for fields `k` (ABC Thm 7.6, `1 - N^t = -1`) | `K_1 = 0`: `GL = EL`, perfect; `K_2 = 0`: Tate's `K_2(Q)` dies |
| de la Harpe–Skandalis simplicity of `U(A)/T` | `L_k(1,2)^x / k^x` simple (repo, Lean) | countable simple `Λ ⊇ GL_∞(Q)`, not f.g. |
| Kirchberg: exact `A ↪ O_2` | **fails** for f.g. subrings: coefficient descent (`infinite-field-leavitt-units-are-not-finitely-generated`) | why a non-Leavitt generator is needed |

## 2. The easiest translated case (landed)

- `harmonic-cuntz-ring-is-purely-infinite-simple`. The ring `C_h` is generated by
  the Cuntz operators on `Q^X` together with `m_η` and `m_ζ`, where `ζ = 1/(1+η)`.
  - It contains `Q`, has two-sided division and has centre `Q`.
  - It is the algebraic shadow of a dense subring of `O_2`: `η` lies in the
    diagonal `C(X)` because it is continuous.
- `harmonic-cuntz-el3-is-fg-simple-over-all-gl-n-q`:
  - `Λ_h = EL_3(C_h)/Q^x` is finitely generated and simple, with solvable word
    problem;
  - it contains every `GL_n(Q)`, and the countable simple group `Λ` of
    `leavitt-unit-groups-over-every-field-are-simple-mod-scalars`.
- `finitely-presented-harmonic-cuntz-ring-contains-q`: an explicit finitely
  presented *-ring `R_Q` with six generators, containing `Q`, with `R_Q ≅ M_n(R_Q)`,
  mapping onto `C_h` and into `O_2`.

The mechanism is a C*-phenomenon. Completing `L_Q(1,2)` inside `O_2` adds
continuous diagonal functions, and one of them, `η`, carries every denominator. The
ring stays finitely generated.
- **O1 respected.** The rings are simple and the groups are simple, hence not
  residually finite.
- **O2 respected.** `SL_3(Z) ⊂ Λ ⊂ Λ_h`, and neither `V` nor `VA` is used.

## 3. Where the transplant breaks

The C*-side has no finite presentation. Analytic completeness is exactly what brings
`Q` in. Finite presentation lives only in the algebraic shadow, and there it is
**the whole remaining content** of the root along this route
(`harmonic-cuntz-simple-group-is-finitely-presented`).

1. **Ring level.** Is `R_Q -> C_h` injective? If so, `C_h` is a finitely presented
   ring. Unknown. `C_h` is simple, so the kernel is a maximal ideal of `R_Q`.
2. **Central scalars.** `Q^x · I ⊂ EL_3(C_h)`: the inclusion `L_Q(1,2) ⊂ C_h` and
   `GL_3 = EL_3` over `L_Q(1,2)` put every scalar in. `Q^x` is not finitely
   generated. For a finitely presented `G` and central `Z`, `G/Z` is finitely
   presented only if `Z` is finitely generated (B. H. Neumann). So **`EL_3(C_h)` and
   `Λ_h` are never both finitely presented**. The right target is `Λ_h`.
3. **K_2.** Steinberg covers are natural finite-presentation candidates.
   - Stable: `K_2(Q) -> K_2(C_h)` factors through `K_2(L_Q(1,2)) = 0` (ABC). So
     Tate's non-finitely-generated `K_2(Q) = Z/2 ⊕ ⊕_p F_p^x` imposes no relation,
     and the stable `St(C_h)` contains `SL(Q) = ⋃ SL_N(Q)`.
   - Unstable: whether `K_2(Q)` also dies in `St_3` is not known here. This is the
     kind of relation a finite presentation of `Λ_h` must produce from finitely many.
4. **Steinberg finite presentation.** Is `St_3` (or a Thompson-type Steinberg
   group) of a finitely presented ring with a Leavitt family finitely presented?
   There are finitely many generators `x_ij(s)`. The question is whether finitely
   many Steinberg relations imply the rest. Not settled here. Shared with
   `gq-en-ring`, `gq-k2-q` and `gq-malcev-ring`.

## 4. Calibration

- **O1.** Not residually finite (simple).
- **Distortion.** `Λ_h ⊇ GL_2(Z[1/2])`, with exponentially distorted unipotents. So
  `Λ_h ∉ VA` (O4), consistent with it being a new kind of host.
- **FW.** `SL_3(Z)` sits inside through `L_Q(1,2)`. No fixed-point property is
  assumed.
- **What Q has that Z[1/m] lacks.** `η` realizes all denominators at once. Without
  it, every finitely generated piece lives over some `Z[1/m]`.

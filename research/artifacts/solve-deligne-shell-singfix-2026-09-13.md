## 2. The SingFix groups at `P = Gamma~`

These all come from general nodes on main; none of them is new here.
- **Orbit condition.** Theorem 2.1 at `n = 2` has its orbit condition, since V is
  highly transitive on `Omega = V*p`.
- **The groups to present.** The clauses are `A_1 = S({p},{p})`,
  `A_12 = S({p},{p,q})` and `A_2 = S({p,q},{p,q})`. The groups `S(emptyset,M')` are
  finitely presented stabilizers in V.
- **The extension.** `1 -> K -> A_1 -> Q -> 1`, where `K` is simple, not finitely
  generated, and normally generated by any nonidentity element
  (`shell-fp-stabilizer-forces-fp-germ-group`).
- **The germ group.** `Q` contains `F_nu = R_nu x_Z R_nu` with index two, where
  `R_nu = <lambda(Gamma~), s>` is a group of near permutations
  (`shell-germ-group-has-index-two-fiber-product`).
- **The gate.** If `A_1` is finitely presented, then `R_nu` is finitely presented
  and is an ascending HNN extension over a finitely generated base `B <= ker(eta)`
  (`shell-germ-fp-is-an-ascending-hnn-gate`).

**A remark on the gate, proved here and not landed as a node.**
- `ker(eta)` is generated by the shifted copies `s^c lambda(Gamma~) s^-c` for `c` in
  `Z`. So the finitely generated `B` lies in `K_C = <s^c lambda(Gamma~) s^-c : |c| <= C>`
  for some `C`.
- Take `epsilon = +1`, so `s^-1 B s <= B` and `ker(eta)` is the union of the groups
  `s^n B s^-n`. For each `g`, some `s^-n lambda_g s^n` lies in `B`, and then so does
  `s^-m lambda_g s^m` for every `m >= n`.
- So every generator must have all its far-shifted copies, in one direction, inside
  a group generated by finitely many shifted copies. The case `epsilon = -1` is
  symmetric.

**What `Gamma~` contributes.** `Q`, `R_nu` and the gate see the input only through its
regular action near infinity. No use of property (T), the infinite center or the
failure of residual finiteness was found in any of them.

## 4. Contracting rational similarity hosts

- **The implication.** Every hyperbolic group embeds in a contracting rational
  similarity group (`hyperbolic-groups-embed-in-contracting-rsgs`). A theorem that
  Kazhdan subgroups of such groups are residually finite would therefore make every
  hyperbolic group with property (T) residually finite, an open case of Gromov's
  question.
- **Consequence.** The Rover--Nekrashevych exclusion of `Gamma~` cannot be carried
  over to contracting rational similarity hosts without a result of that strength.

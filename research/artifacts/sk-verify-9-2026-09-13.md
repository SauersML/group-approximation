## 1. Theorem 2, re-derived

**Statement.**
- **Hypotheses:**
  - L is finitely generated and acts minimally on a Cantor set Z;
  - no g ≠ e fixes a nonempty open set;
  - R = LC(Z,F_2)⋊L is finitely generated as a ring;
  - there is a unital ring homomorphism φ: R → ∏_ω M_{N_k}(F_2), into the *algebraic* ultraproduct.
- **Conclusion:** for n ≥ 3, G = EL_n(R) is infinite, finitely generated, simple, LEF and Kazhdan.

Notation: S is a finite symmetric generating set of L, word length |·|, balls B_m. Write n = 3.

### 1.1 Generation, (T), infinite
- **Generation.** Every r ∈ R is an F_2-sum of products s_1⋯s_m of ring generators, with m ≥ 0 and 1 in the generating set. By induction, e_ij(s_1⋯s_m) = [e_ik(s_1⋯s_{m−1}), e_kj(s_m)] with k ∉ {i,j}, and e_ij is additive. So the e_ij(s) generate G.
- **(T).** EJZ as quoted at source.
- **Infinite.** r ↦ e_12(r) is injective on LC(Z,F_2), which is infinite. ✓

### 1.2 Density patch (small clopen sets)
- For g ≠ e, Fix(g) is closed with empty interior. So U = ⋂_{g∈B_{2w}∖{e}} (Z∖Fix g) is dense and open.
- Given a nonempty clopen W, pick x ∈ W∩U.
- For each g ∈ B_{2w}∖{e}, take disjoint clopen sets A ∋ x and B ∋ gx, and put V_g = A ∩ g^{-1}B, so V_g ∩ gV_g = ∅.
- Intersect all V_g with W and with a clopen neighbourhood of x on which the finitely many locally constant functions f∘a are constant (a ∈ B_w, f a coefficient of an entry of g^{±1}).
- The result contains x and is small. ✓
- In the Z-case, minimal and infinite gives no periodic points (a finite orbit is a closed invariant proper subset), so the action is free. ✓

### 1.3 A noncommuting root
- **Criterion.** g·e_ij(r) = e_ij(r)·g ⟺ g·rE_ij = rE_ij·g. The (p,j) entry of the left side is g_pi r and the (i,q) entry of the right side is r g_jq. So the criterion is: g_pi r = 0 (p ≠ i), r g_jq = 0 (q ≠ j), and g_ii r = r g_jj. ✓
- **Off-diagonal entries vanish.** u_ℓe_V = e_{ℓV}u_ℓ gives ce_V = Σ c_ℓ e_{ℓV}u_ℓ and e_Vc = Σ e_Vc_ℓ u_ℓ. If c_ℓ = 1 on a nonempty clopen set U′:
  - a small V ⊆ ℓ^{-1}U′ gives c_ℓe_{ℓV} ≠ 0;
  - a small V ⊆ U′ gives e_Vc_ℓ ≠ 0.

  So if g commutes with every e_ij(e_V), V small, all off-diagonal entries of g are 0.
- **Non-constant coefficients vanish.** At u_ℓ with ℓ ∈ B_w∖{e}, the two sides of g_ii e_V = e_V g_jj are functions supported on ℓV and on V, which are disjoint. So both vanish, and by the same choices of V the coefficients vanish.
- **Constant coefficients.** From ce_V = e_Vc′ we get c = c′ on every small V. Since c − c′ is locally constant and every nonempty clopen set contains a small set, c = c′.
- **Conclusion.** g = cI with c ∈ LC(Z,F_2) a unit of R. The u_e-coefficient of cc^{-1} = 1 gives c·d_e ≡ 1, so c ≡ 1 and g = 1. ✓

### 1.4 The tower copy of GL_d(F_2), d = 3|B_w|
- **Products.** ε_ab = e_{aV}u_{ab^{-1}}, so ε_abε_{a′b′} = e_{a(V∩b^{-1}a′V)}u_{ab^{-1}a′b′^{-1}}. Since b^{-1}a′ ∈ B_{2w}, this is δ_{ba′}ε_{ab′}. ✓
- **Independence.** For a fixed value of ab^{-1}, distinct a give disjoint nonempty sets aV, because a^{-1}a″ ∈ B_{2w}∖{e}. So the ε_abE_pq are linearly independent, and ψ is injective and multiplicative.
- **Embedding.** e = ψ(I_d) is an idempotent with eψ(M)e = ψ(M), so M ↦ I − e + ψ(M) is an injective group homomorphism.
- **Transvections.**
  - Between blocks: e_pq(ε_ab).
  - Inside a block: [I+E_{(p,a),(p′,a)}, I+E_{(p′,a),(p,b)}] = I+E_{(p,a),(p,b)}, with the three indices distinct (p′ ≠ p, a ≠ b).
  - GL_d(F_2) = SL_d(F_2) is generated by transvections. So H ≤ G. ✓

### 1.5 k = [g,h] lies in H
- **The products lie in the span.** f u_a e_V f′u_b = f e_{aV}(f′∘a^{-1})u_{ab}.
  - f is constant on aV because f∘a is constant on V.
  - f′∘a^{-1} is constant on aV because f′ is constant on V.
  - So the product is 0 or e_{aV}u_{ab} = ε_{a,b^{-1}}, with b^{-1} ∈ B_w (S symmetric). ✓
- **k and k^{-1}.** h² = I in characteristic 2, so k − I = (ghg^{-1}−h)h and k^{-1} − I = h(ghg^{-1}−h), since k^{-1} = hghg^{-1}. ψ(M_d(F_2)) is closed under sums and products and contains h − I = ε_eeE_ij, so both lie in it.
- **k ∈ H.** kk^{-1} = I gives ψ(A+B+AB) = 0, so (I+A)(I+B) = I and k is the image of I+A. ✓
- **H ≤ N.** H ≅ PSL_d(F_2) is simple (d ≥ 3) and N∩H ∋ k ≠ 1. So H ≤ N and e_pq(e_V) ∈ N. ✓

### 1.6 Level ideal and covering (the only use of minimality)
- **Ideal.** J is additive, and e_pq(sr) = [e_pl(s), e_lq(r)] ∈ N for l ∉ {p,q}, since N is normal.
- **Covering.** ⋃_ℓ ℓV is open, invariant and nonempty, so its closed invariant complement is empty. Compactness gives ℓ_1,…,ℓ_m.
- **Conclusion.** 1 = 1 − ∏(1 − e_{ℓ_iV}) is a sum of products of the e_{ℓ_iV} = u_{ℓ_i}e_Vu_{ℓ_i}^{-1} ∈ J. So J = R and N = G. ✓

### 1.7 LEF (the only use of the ring homomorphism)
- φ induces a unital ring homomorphism M_3(R) → ∏_ω M_{3N_k}(F_2), so a group homomorphism G → ∏_ω GL_{3N_k}(F_2). A class is invertible iff ω-almost every component is.
- The image of e_12(1) is the class of I + E_12⊗I_{N_k} ≠ I. So the kernel is a proper normal subgroup, trivial by 1.2–1.6.
- R and G are countable: Z is second countable and L countable.
- A countable subgroup of an algebraic ultraproduct of finite groups is LEF: for a finite F ⊆ G, the finitely many product and distinctness relations hold in ω-almost every coordinate. ✓

### 1.8 Where each hypothesis enters (model tests)
- **Minimality:** only in 1.6, plus aperiodicity in the Z-case.
  - It is necessary. A closed invariant Y with ∅ ≠ Y ⊊ Z gives ker(EL_3(R) → EL_3(LC(Y,F_2)⋊L)).
  - That kernel is proper, and nontrivial: it contains e_12(e_U) for a clopen U ≠ ∅ with U∩Y = ∅.
- **Topological freeness:** only in 1.2.
  - It is necessary. Take L = Z×Z/2 with Z/2 acting trivially on a subshift. Then R ≅ R_X⊗F_2[Z/2] has the nilpotent ideal generated by 1+u_{(0,1)}, which gives a proper nontrivial congruence normal subgroup.
- **R finitely generated:** only for (T) and finite generation.
  - The dyadic odometer is minimal and free; its EL_3 is simple, and LEF if the hypothesis on φ holds, but R is not finitely generated.
- **The ring homomorphism:** only in 1.7. It is not vacuous, as the node's non-instance shows.
  - LC(∂F_d,F_2)⋊F_d contains x, y with xy = 1 ≠ yx.
  - Matrix ultraproducts are directly finite, so φ(1−yx) = 0. Minimality then propagates this to φ(1) = 0.
- **Trivial model:** L = 1 is not minimal on a Cantor set, so it fails the hypotheses, as it should.
- **"Matricial" and F1 (varying finite fields):**
  - A unital homomorphism from an F_2-algebra into M_N(F_q) forces q = 2^m, and M_N(F_{2^m}) ⊆ M_{mN}(F_2). So fixing F_2 loses nothing.
  - The hypothesis must be the algebraic ultraproduct; a rank-metric one gives only linear soficity. The claim id's word "matricial" is loose, but the node statement and the candidate Theorem 2 state the algebraic hypothesis exactly.
- **LEF is derived, not assumed.** The hypothesis is at ring level, and injectivity on the group comes from simplicity (1.7). The map φ need not be injective.
- **n.** The proof uses n ≥ 3 in three places: EJZ, generation through commutators (1.1), and the level ideal (1.6). Theorem 2 claims only n ≥ 3.
  - FIREWALL for rev4: an n = 2 clause needs its own proof (sk-el2) and must not say "the same proof".

### 1.9 The two instances satisfy the hypotheses
- **Z-subshift (rev3 §1).**
  - The action is free (1.2) and R is generated by u^{±1} and the e_a.
  - φ_ℓ is defined on each fixed element for large ℓ, and is additive, multiplicative and unital on fixed pairs for large ℓ.
  - The covariance PD_ℓ(f)P^{-1} = D_ℓ(f∘T^{-1}) holds for f of radius ≤ ℓ−1; this is referee (a)'s U1 wording fix.
  - So the ultraproduct map is a unital ring homomorphism. ✓
- **Lamplighter (rev3 §2).**
  - **Minimal:** every orbit contains x+⊕F_2, which is dense.
  - **Topologically free** (re-derived): for δ ≠ e and a cylinder over W, prescribe x(h) ≠ x(δ^{-1}h) at some h ∉ W∪δW∪supp f. This h exists because Δ is infinite. Then (δx+f)(h) = x(δ^{-1}h) ≠ x(h).

# Referee report (gq-referee-a, proof-gap lens): one Steinberg group contains every GL_n(Q)

**Reviewed:** `one-steinberg-group-contains-every-gl-n-q` (lane gq-deep-free-1, 27d360184, proof under
Attempts 1) and route `gl-n-q-explicit-via-st-4-of-divisible-ring`, read on origin/main.

**Verdict: PASS (proof-gap lens), conditional on four classical K_2 citations.** Those citations are
listed in §6 and belong to the citation lens. With them, the proof is complete: for every ring `S ⊇ Q`
with a Leavitt pair, `SL_{4m}(Q) ≤ St_4(S)` for all `m`, and so every `GL_n(Q) ≤ St_4(S)`.

## 1. Cuntz families and `ι_m`
- `t_k = x_2^{k-1} x_1` (`k < m`), `t_m = x_2^{m-1}`. Checked that `t_k^* t_l = δ_kl`:
  - `y_2^{k-1} x_2^{l-1}` reduces to a power of `x_2` or of `y_2`;
  - then `y_1 x_2 = 0 = y_2 x_1` kills the off-diagonal terms.
- `Σ t_k t_k^* = 1` telescopes through `x_1 y_1 = 1 - x_2 y_2`.
- `Q` is central, so `ι_m` is a unital ring map. It is injective by `t_k^* ι_m(a) t_l = a_kl`.

## 2. (a) The block isomorphism `β_k`
- `β_k` is a homomorphism. The argument is the same as in my review of
  `leavitt-pairs-embed-sl-n-q-in-steinberg-groups` (fbbb1c736): the factors commute, and the
  commutators of factors are central among the factors.
- Given centrality of `K_2(4, M_k(Q))` (citation C1), `St_4(M_k(Q))` is a perfect central extension of
  `E_4(M_k(Q)) = SL_{4k}(Q)`.
- `St_{4k}(Q)` is perfect and centrally closed for `4k ≥ 5` (citation C2), with central kernel. So it
  is the universal central extension, and `μ` exists.
- `β_k μ = id` by universality.
- `μ β_k = id` because two maps over the same base, out of a perfect group into a central extension,
  agree. Correct.

## 3. (b) Scalar blocks: `β_{mN} ∘ St_4(j_N) = b_N ∘ β_m`
- On generators both sides are `∏_{s,t,c} x_{(i,s,c),(j,t,c)}(a_st)`, since
  `(a ⊗ I_N)_{(s,c),(t,c')} = a_st δ_{cc'}`, with one fixed identification `[4]×[m]×[N]`.
- `b_N = ∏_c ŝ_c`, a product of `N` homomorphisms with pairwise disjoint index sets. Their images
  commute by (R3), so the product is a homomorphism. This holds on all of `St_{4m}(Q)`, not only on
  `K_2`.
- For `y ∈ K_2(4m, Q)`: `K_2(n,F)`, `n ≥ 3`, is generated by symbols that do not depend on their
  indices (citation C3). So each `ŝ_c` sends a symbol to the same symbol of `St_{4mN}(Q)`,
  `ŝ_c(y) = ŝ_1(y)`, and `b_N(y) = ŝ_1(y)^N`. Correct.

## 4. (c), (d): the kernel dies
- `K_2(4m, Q) ≅ K_2(Q)` is torsion (citations C3 and C4), so the order `N` of `β_m(x)` is finite.
- `t'_{(i,c)} = t_i u_c` is a Cuntz family of size `mN`: `t'^*t' = δδ`, and
  `Σ t_i u_c u_c^* t_i^* = 1`.
- `ι_{mN}(a ⊗ I_N) = Σ a_ij t_i (Σ_c u_c u_c^*) t_j^* = ι_m(a)`. The index order `(i,c)` matches the
  convention of `j_N`. Hence `St_4(ι_m) = St_4(ι_{mN}) ∘ St_4(j_N)`.
- `β_{mN}(St_4(j_N)x) = ŝ_1(β_m(x)^N) = 1`, and `β_{mN}` is injective for `mN ≥ 2`. The case `mN = 1`
  is trivial.
- **(e).** The reverse inclusion holds because `E_4(ι_m)` is injective. The image is
  `E_4(M_m(Q)) = SL_{4m}(Q)`. Correct.

## 5. The route (`St_4(D)`)
- **The Leavitt pair in `D` holds**, checked against `D`'s relations R1–R3:
  - `vw = 1` (R2);
  - `vt·sw = v(ts)w = 1` (R1);
  - `wv + s(wv)t = 1` (R3).
  - The off-diagonal zeros come from `(x_2 y_2) x_2 = x_2 (y_2 x_2) = x_2` and its dual.
- **`Q ⊆ D` unitally** is claimed by `finitely-presented-divisible-ring-engine`. I did not review that
  node here. It is an input of the route, not of the lemma.
- **Finite presentation and (T) of `St_4(D)`** rest on the imports in
  `steinberg-finite-presentation-and-kazhdan-theorem`: Krstić–McCool Thm 3 for rank `≥ 4`, and
  Ershov–Jaikin-Zapirain Thm 6.2. That is the citation lens, and Krstić–McCool's primary text is still
  unread.
- **Consequence, if all inputs hold:** a single finitely presented group with property (T),
  `St_4(D)`, contains every `GL_n(Q)`.

## 6. Citations the proof depends on (for gq-referee-b)
- **C1.** Centrality of `K_2(n, A)` for `n ≥ sr(A) + 2`. This is taken from Voronetsky's introduction
  (arXiv:2004.08551), and the primary source [2] was not read. It is applied with
  `sr(M_k(Q)) = 1` (Vaserstein).
- **C2.** `St_n(A)` is centrally closed for `n ≥ 5` (Kervaire; van der Kallen). `K_2(n,F)` is central
  for fields and `n ≥ 3`.
- **C3.** Matsumoto: `K_2(n,F) = K_2(F)` for `n ≥ 3`, generated by index-independent symbols (Milnor
  §§9, 12).
- **C4.** Tate: `K_2(Q) = Z/2 ⊕ ⊕_{p odd} F_p^x`, a torsion group.

These are classical, and I know of no problem with them. The self-contained alternative is the rank
`6N+1` swindle (`leavitt-pairs-embed-sl-n-q-in-steinberg-groups`, PASS at fbbb1c736), which needs none
of C1–C4 but depends on `n`.

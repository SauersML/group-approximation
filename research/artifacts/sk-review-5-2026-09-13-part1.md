## 1. `crossed-product-el-kazhdan-iff-finite-field-and-subshift`: PASS
Setting: zero-dimensional `(X,T)`, a field `k`, `R = LC(X,k) ⋊ Z`, `n ≥ 3`. The claimed equivalences: (1) `R` is f.g.; (2) `EL_n(R)` is f.g.; (3) `EL_n(R)` has (T); (4) `k` is finite and `X` is a subshift.
- **(4 ⇒ 1).** Coordinate indicators are `u^{-t} e_a u^t`; products and sums give all cylinder functions, and the finitely many constants give `k`-multiples.
- **(1 ⇒ 3).** Ershov–Jaikin-Zapirain Theorem 1.1, for `n ≥ 3` and f.g. unital associative `R`.
- **(3 ⇒ 2).** A discrete group with (T) is compactly generated, so finitely generated (Bekka–de la Harpe–Valette, Theorem 1.3.1; recalled, not re-read).
- **(2 ⇒ 1).** Let `R_0` be generated by the entries of `S ∪ S^{-1}` for a finite generating set `S`. Then every element of `EL_n(R)` has entries in `R_0`, and `e_12(r)` has entry `r`, so `R_0 = R`.
- **(1 ⇒ 4), the field.** Let `k_0` be the subring generated by the finitely many values of the coefficient functions of the generators. The sums whose coefficients are `k_0`-valued form a subring, because `(g u^i)(h u^j) = g (h∘T^{-i}) u^{i+j}`. It contains the generators, so it is `R`, and the constants lie in it. So `k = k_0` is a field that is finitely generated as a ring, hence finite.
- **(1 ⇒ 4), the system.** Let `𝒫` be the partition by the level sets of those coefficients, and `ℬ` the Boolean algebra generated by the translates `T^jP`. The `ℬ`-measurable sums form a subring containing the generators, so every clopen set is a finite Boolean combination of translates. So the itinerary map `X → 𝒫^Z` is continuous, equivariant and injective, hence a conjugacy onto a subshift.
- **Model tests.** The dyadic odometer fails (4) and has a non-f.g. ring, consistent with the reviewed odometer node. `k = Q` fails.

## 2. `crossed-product-gl-n-has-infinite-cyclic-index-quotient`: PASS+repair
Re-derived:
- **Orbit representation.** `π(f)δ_m = f(T^m x)δ_m`, `π(u)δ_m = δ_{m+1}`. It is a homomorphism because `π(u)π(f)π(u)^{-1} = π(f∘T^{-1})`.
- **Compression.** `Pπ(gh)P − Pπ(g)Pπ(h)P = Pπ(g)(1−P)π(h)P`. If `h` has exponents bounded by `w`, the range of `(1−P)π(h)P` lies in the `nw`-dimensional span of `δ_m ⊗ k^n` with `−w ≤ m < 0`.
- **Fredholm.** With `A = Pπ(g)P` and `B = Pπ(g^{-1})P`, both `AB − 1` and `BA − 1` have finite rank. So `ker A` is finite-dimensional and `range A` has finite codimension. The algebraic index is additive and invariant under finite-rank perturbation, so `ind` is a homomorphism.
- **Values.** `Pπ(e_ij(r))P = 1 + (Pπ(r)P)E_ij` has inverse `1 − (Pπ(r)P)E_ij`, so index 0. `Pπ(diag(u,1,…,1))P` is the unilateral shift on the first summand, so index −1. So `GL_n(R) ↠ Z`, `GL_n(R)` has no (T), and for `n ≥ 2`, `EL_n(R) ⊆ ker(ind) ⊊ GL_n(R)`.

**Repair (scope).** The claim said "If `X` is minimal, then `Z(GL_n(R)) = k^× I_n` lies in `ker(ind)`", and the route justified `Z(R) = k` by minimality.
- For a finite orbit of size `p`, which is minimal, `u^p` is central in `R ≅ M_p(k[t^{±1}])`, and `ind(u^p I_n) = −np ≠ 0`. So the sentence is false there.
- The note's argument for `Z(R) = k` uses that `T` has no periodic points.
- Applied repair: "If `X` is infinite and minimal", in the claim and in the route bullet, with the finite-orbit counterexample recorded.
- No other conclusion of the node depends on this sentence.

## 3. `cyclic-factor-subshift-el-2-is-simple-kazhdan-lef`: PASS
Setting: `X` infinite minimal, `X = U ⊔ TU ⊔ … ⊔ T^{m−1}U`, `T^mU = U`, `m ≥ 2`, `Y = (U, T^m|_U)`.
- **The induced system.** A closed `T^m`-invariant `∅ ≠ Z_0 ⊆ U` generates the closed invariant set `⋃_{i<m} T^i Z_0`, which is `X`. Since the levels are disjoint, `Z_0 = U`. `U` is infinite. `T^m|_U` is expansive, so `Y` is conjugate to a subshift.
- **Matrix units.** Put `e_ij = u^i e_U u^{-j}` for `0 ≤ i,j < m`. Then `e_ij e_kl = u^i e_U u^{j'} e_U u^{-l}` with `j' = k − j`, and `e_U u^{j'} e_U = e_U e_{T^{j'}U} u^{j'}`. This is `e_U` when `j' = 0`. For `0 < |j'| < m` it is 0, because the levels are disjoint. So `e_ij e_kl = δ_jk e_il` and `Σ e_ii = Σ e_{T^iU} = 1`. Hence `R_X ≅ M_m(e_U R_X e_U)`.
- **The corner.** `e_U f u^j e_U ≠ 0` only if `U ∩ T^jU ≠ ∅`, i.e. `m | j`. So the corner is `LC(U,F_q) ⋊_{T^m} Z = R_Y`.
- **`EL_2(M_m(S)) = EL_{2m}(S)`.**
  - `⊆`: `e_12(x)` is a product of commuting transvections between the two blocks.
  - `⊇`: a transvection `t_{(1,a),(1,b)}`, with `a ≠ b` in the same block, equals `[t_{(1,a),(2,c)}, t_{(2,c),(1,b)}]`. Both factors lie in `EL_2(M_m(S))`. The same holds in block 2.
  - This is item 3 of `tower-subshift-elementary-group-is-el-3k-of-base`, PASS for items 1–3 in sk-review-3 part2 §5.
- **Conclusions.** `R_Y` is f.g., so EJZ gives (T) for `EL_{2m}(R_Y)`, since `2m ≥ 4 ≥ 3`. Simplicity modulo centre follows from the Steinberg criterion for the minimal effective groupoid of `Y`. For `q = 2`, LEF follows from the LEF ring `R_Y`.
- **Examples.** Period doubling and Toeplitz subshifts have `Z/2` factors. Sturmian subshifts have only irrational eigenvalues besides 1, so they have no finite cyclic factor.

## 4. `subshift-elementary-group-simple-iff-infinite-minimal`: PASS
- **If.** The Steinberg criterion (reviewed), for every field and `n ≥ 3`.
- **Only if, not minimal.** Restriction `ρ: R_X → R_Y` to a closed invariant `∅ ≠ Y ⊊ X` is a ring homomorphism, since restriction commutes with `∘T^{-i}` on invariant sets. It is surjective, since clopens of `Y` are traces of clopens of `X`. Its kernel contains `e_U` for a clopen `U ≠ ∅` avoiding `Y`.
- **Only if, finite orbit.** `σ: R_X → End_k(k^X)` is a homomorphism with `u^p − 1` in its kernel.
- **From the ideal to a normal subgroup.** `EL_n(φ)` is onto. Its kernel `K` contains `e_12(r)`, which does not commute with `e_21(1)`: the `(1,1)` entries are `1 + r` and `1`. If `K Z(G) = G`, then `EL_n(S) = φ(Z(G))` would be abelian, which it is not. So `G/Z(G)` has a proper nontrivial normal subgroup.

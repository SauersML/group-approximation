## 0. The claim and its consequence

Let `K` be a field and `H <= GL_n(K)` finitely generated. Then `H` embeds in a finitely
presented simple group.

Consequence: via Cohen–Wales (every Artin group of finite type is linear over a
characteristic-0 field of transcendence degree 2), every spherical-type Artin group
satisfies Boone–Higman. That includes the exceptional types E_6, E_7, E_8, F_4, H_3 and
H_4. The node is `spherical-artin-groups-satisfy-boone-higman`.

BFFHZ (arXiv:2503.21882v2, introduction) says: "For spherical and Euclidean Artin groups,
the Boone–Higman conjecture remains open for the exceptional type spherical Artin
groups." The same paper says only that BH "is known for many finitely generated linear
groups". This is part of survey Problem 5.3(13).

## 1. The key import, read at source

Zaremsky, arXiv:2405.09722v2 (BLMS 2025), from the arXiv HTML:
- **Definition 2.1.** A subgroup `G <= Aut(T_d)`, `d >= 2`, is self-similar if its image
  in `S_d wr_d Aut(T_d)` lies in `S_d wr_d G`.
- **Theorem 1.1.** "Every finitely presented self-similar group embeds in a finitely
  presented simple group." There are no further hypotheses: no contraction, no
  transitivity, no condition on the ring.
- **Citation 2.3 (Scott)**, used in the proof: V_d(G) is finitely presented whenever G is.
- **Example 4.7** needs a finite-index principal ideal. The repo does not use Example 4.7.
  It verifies self-similarity directly, which is all Theorem 1.1 needs.

## 2. Characteristic zero

**Step 1. Coordinates** (`char-zero-polynomial-embedding-via-noether-normalization`).
Each step checks:
- Restriction of scalars from the finitely generated field `K_0` to `Q(t)`. It is a
  unital ring embedding applied entrywise, so it is a group embedding.
- `A = Z[t][1/f]` is a localization of `Z[t]`, hence regular. This choice sidesteps the
  "A need not be Cohen–Macaulay" trap, since it never uses the original coordinate ring.
- The Nagata substitution `s_i = t_i - u^(D^i)` in `A = Z[t,u]/(uf-1)`. The weights
  `w(a) = 1 + Σ a_i D^i` are distinct because the exponents are `< D`. The leading
  coefficient is `c = c_(a*) ∈ Z`. So `u` is integral over `Z[1/c][s]`.
- Injectivity follows from transcendence degree.
- Miracle flatness: regular over regular, with the dimension equality from going down
  and the zero-dimensional fibers. So `A'` is finite flat, hence projective.
- Quillen, Theorem 4 over the PID `Z[1/c]`, gives freeness. The fallback without Quillen
  (a projective complement) also works.

Result: `H ≤ GL_M(Z[1/m][s_1..s_k])`.

**Step 2. Elementary group.** For `R = Z[1/m][t_1..t_k]` and `n = max(k+4, 2N)`:
- `g -> diag(g, (g^T)^-1, I)` is an injective homomorphism into `SL_n(R)`. (This is the
  corrected form. The Whitehead map is not a homomorphism, and that error was caught in
  the 09-12 review.)
- `SL_n(R) = E_n(R)`: `sr(R) <= dim R + 1 = k+2`, so Vaserstein applies for
  `n >= k+3`. `K_1(R) = K_1(Z[1/m]) = Z[1/m]^×` (fundamental theorem, `Z[1/m]` regular,
  Euclidean), so `SK_1 = 0`. PASS.

**Step 3. `E_n(R)` finitely presented** (`elementary-groups-over-polynomial-s-integers-are-fp-proof`).
- The square argument checks: `K_2(n,Z[1/m])` surjects onto `K_2(Z[1/m])` (`n >= 3`).
  `K_2(Z[1/m]) ≅ K_2(R)` by homotopy invariance (Weibel V.6.3).
  `K_2(n,R) -> K_2(R)` is injective by van der Kallen (Thm 1 p. 77, pinned at source by
  gq-referee-b: max-spectrum dimension `k+1`, `n >= k+4`). Hence
  `K_2(n,Z[1/m]) -> K_2(n,R)` is onto.
- So `K_2(n,R)` is normally generated by the images of finitely many normal generators of
  `K_2(n,Z[1/m])`. Those exist because `St_n(Z[1/m])` and `SL_n(Z[1/m])` are finitely
  presented (Behr / Borel–Serre).
- `St_n(R)` is finitely presented because `n >= 5`: the refereed
  `steinberg-groups-of-fp-rings-are-fp-in-rank-five`. No Krstić–McCool is needed.
- So `E_n(R)` is finitely presented. PASS.

**Step 4. Affine extension finitely presented** (`affine-extension-of-fp-elementary-group-is-fp-proof`).
I re-derived A, B, F1–F4 and the five-lemma conclusion. Each auxiliary index choice
needs `n >= 4`, which holds. The map `R^n -> P` is a homomorphism by F2 and F3, and
normality comes from B and F4. PASS.

**Step 5. Self-similarity** (`polynomial-parameter-affine-groups-are-self-similar`).
Checked independently:
- The action `(g,b)·(v,s) = (g(s)v + b(s), s)` on `Z_p^n × Z_p^k` with `p ∤ m` is:
  - an action, since evaluation is a ring homomorphism;
  - level-preserving, since the entries are polynomials over `Z[1/m] ⊂ Z_p`;
  - bijective on each level, since `det = 1`;
  - faithful, since a polynomial vanishing on `Z_p^k` is 0.
- The state at the first-level vertex `(e,α)` is `(σ_α(g), Q/p)`, where
  `σ_α(t_j) = α_j + p t_j` and `Q = σ_α(g)e + σ_α(b) - c`:
  - `Q ≡ g(α)e + b(α) - c ≡ 0 (mod pR)`, because `R/pR = F_p[t]` and
    `σ_α(P) ≡ P(α) (mod p)`;
  - `σ_α` is a ring endomorphism, so `σ_α(E_n(R)) ⊆ E_n(R)`.
- So every state lies in the group, which is Definition 2.1. PASS.

**Step 6.** Theorem 1.1 applies, and subgroups inherit the embedding. PASS.

## 3. Characteristic p

**Step 1. Coordinates** (`char-p-polynomial-embedding-via-noether-normalization`). The
same argument works over `F_p`. The leading coefficient is a unit, so `m = 1` and
`R = F_p[s_1..s_k]`. Quillen–Suslin applies over a field. `k = 0` means `H` is finite:
put it in `GL_M(F_p) ≤ GL_M(F_p[s_1])`. PASS.

**Step 2. Elementary group, `n >= max(k+4, 2M)`.**
- The transpose-inverse embedding checks.
- `SK_1(F_p[s]) = 0` (Weibel V.6.3, `K_1(F_p) = F_p^×`).
- So `SL_n = E_n`. PASS.

**Step 3. `E_n(R)` finitely presented** (`elementary-groups-over-polynomial-f-p-rings-are-fp-proof`).
- `K_2(R) = K_2(F_p) = 0` (homotopy invariance, and Weibel III.6.1.1).
- `K_2(n,R) -> K_2(R)` is injective for `n >= k+3` (van der Kallen, `d = k`).
- So `E_n(R) = St_n(R)`, finitely presented for `n >= 5` by the rank-five node. PASS.

**Step 4. Affine extension.** The same lemma applies, with `R` generated by
`s_1..s_k`. PASS.

**Step 5. Self-similarity** (`positive-char-polynomial-affine-groups-are-self-similar`).
Checked independently:
- The action is on `F_p[[u]]^n × F_p[[u]]^(k-1)`, with `s_1 -> u` and
  `s_i -> a_i` (parameters). It is:
  - level-preserving, bijective and an action;
  - faithful, because `F_p[s_1] -> F_p[[u]]` is injective and a polynomial over the
    infinite domain `F_p[[u]]` vanishing on `F_p[[u]]^(k-1)` is 0.
- The tree is `p^(n+k-1)`-regular.
- The state at `(e,α)` is `(σ_α(g), Q/s_1)`, where `σ_α(s_i) = α_i + s_1 s_i`:
  - `Q|_(s_1=0) = g(0,α)e + b(0,α) - c = 0`, so `s_1 | Q` in `R^n`;
  - `σ_α` preserves `E_n(R)`.
- This is exactly Definition 2.1. It also avoids the obstruction
  `affine-self-similar-coordinate-rings-are-one-dimensional`, because the linear part
  varies with the parameter. PASS.

**Step 6.** Theorem 1.1 applies. PASS.

## 4. Traps checked, none triggered

- **Coefficient ring.** The group lies in `GL_n(A)` for a finitely generated domain,
  not over a field. Both proofs handle this by restricting scalars to a purely
  transcendental field first.
- **Finite presentation of the host.** Checked through Steps 2–4, in rank at least 5.
- **Simplicity.** Theorem 1.1 gives a simple group, not merely a group with simple
  commutator subgroup.
- **Type (A).** Not used for plain BH. The permutational form is a separate node.
- **Transcendental coefficients in characteristic 0** (`Z[t]`, `Q(t)` with
  denominators). Handled by the parameter coordinates and the Nagata normalization.
  Worked example: `SL_3(Z[t^±1]) ≤ SL_6(Z[s])`.
- **Property (T).** `SL_3(Z[t])` has (T). That is harmless here: the host is not
  a-T-menable, and Zaremsky's `GL_n(Z)` case already contains (T) groups.

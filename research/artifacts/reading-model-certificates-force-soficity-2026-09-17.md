# Reading-model entropy certificates are exactly soficity (a-gs-pull-3, swarm-0917, 2026-09-17)

Lane: obstruction-miner, family finite-models, on `bernoulli-rokhlin-maximal-on-fg-simple-kazhdan-groups`.

**Question.** Every known proof that a configuration has `Phi >= log q` counts on finite models. The recorded
dead ends say "it needs soficity". That leaves a gate open: maybe a *weaker* finite structure is enough. Examples
are models whose reading maps are not bijections, models that are correct only inside the configuration's own
pattern, with no consistency between the pictures at different sites, models with a large boundary, and in-group
windows. Such structures might exist over a nonsofic host such as the Leavitt unit group.

**Answer.** No. We isolate the one inequality all these arguments use (Section 2, the double count). Its only
quality parameter is the code-to-site ratio `mu` of the model. For any configuration whose pattern contains a ball
`B_r x B_r`, `mu -> 1` already rebuilds an `(r, delta)`-sofic approximation of the ball (Section 3). The converse
holds too (Section 4). So on a nonsofic host every certificate of this class loses a fixed fraction of `H(psi)`
(Section 5).

## 1. Setup

Let `K` be a group generated by a finite symmetric set `S`, with `1` in `S`, and let `B_r` be the ball of radius
`r`. A *configuration* `c = (k, E, F, psi)` is as in `bernoulli-rokhlin-deficit-has-a-finitary-witness`:
- `E` and `F` are finite subsets of `K`;
- `psi : (A^k)^E -> Omega` is a function to a finite set;
- `|A| = q`.

With `x` iid uniform on `A^k` over `K`, put `Y_f = psi((x(fe))_{e in E})` and `Y = Y_1`, and

    k Phi(c) = H(Y) + H( x(1) | (Y_f)_{f in F} ).

The pattern of `c` is `P = FE ∪ {1}`, with its incidences `(f,e) -> fe`.

**Definition (reading model).** A reading model of `(E,F)` consists of:
- finite sets `M` (sites) and `N` (codes);
- maps `tau_e : N -> M` for `e in E`, and `sigma_f : M -> N` for `f in F`.

No map has to be injective, surjective or compatible with any group relation.

A site `v` is *good* if there is an injective map `c_v : P -> M` with `c_v(1) = v` and
`c_v(fe) = tau_e(sigma_f(v))` for all `f` in `F` and `e` in `E`. Well-definedness of `c_v` says that the
coincidences of `P` hold at `v`, and injectivity says that no other coincidences hold. Let:
- `M_g` be the set of good sites, assumed nonempty;
- `N'` be the set of codes `sigma_f(v)` with `v` good and `f` in `F`;
- the ratio `mu = |N'| / |M_g|`.

Bad sites, unused codes and anything outside the charts are unconstrained.

Examples:
- A sofic approximation gives such a model.
- A finite set `W` in `K` gives one: take `M = K`, `M_g = W` and codes at the points `WF`, so `mu = |WF|/|W|`.
- So do partial actions, local models and non-bijective designs.

## 2. The certificate (Lemma A)

**Lemma A.** For every configuration `c` and every reading model of its pattern,

    k Phi(c) >= k log q - (mu - 1) H(Y).

*Proof.* Let `x` be iid uniform on `A^k` over `M`, and for a code `n` put `Z_n = psi((x_{tau_e(n)})_{e in E})`.

1. **Code laws.** If `n = sigma_f(v)` with `v` good, then `tau_e(n) = c_v(fe)`. These points are distinct for
   distinct `e`, since `c_v` is injective. So `Z_n` has the law of `Y`, and `H(Z_n) = H(Y)` for every `n` in `N'`.
2. **Site laws.** For good `v`, the tuple `(x_v, (Z_{sigma_f(v)})_{f in F})` equals
   `(x_{c_v(1)}, (psi((x_{c_v(fe)})_e))_f)`. Since `c_v` is injective on `P` and `x` is iid, its law is that of
   `(x(1), (Y_f)_f)` over `K`. So `H(x_v | Z_{N'}) <= H(x(1) | Y_F)`.
3. **Count.** By the chain rule and subadditivity,

       |M_g| k log q = H(x_{M_g}) <= H(Z_{N'}) + H(x_{M_g} | Z_{N'})
                     <= |N'| H(Y) + |M_g| H(x(1) | Y_F).

   Divide by `|M_g|`, and use `H(x(1)|Y_F) = k Phi - H(Y)`. ∎

So a family of models with `mu -> 1` certifies `Phi(c) >= log q`. This is the Gromov--Weiss count of
`sofic-radical-localizes-bernoulli-deficit-witnesses` with every structural hypothesis removed. Only `mu` is left.

Three remarks:
- The proof uses only that the sites in `M_g` are good. So Lemma A holds with `M_g` replaced by any nonempty set
  `V` of good sites and `N'` by the codes `sigma_f(v)`, `v` in `V`. In particular a model of a larger pattern
  `(E', F') ⊇ (E, F)` restricts, with the same `V` and `mu` at most as large, to a model of `(E, F)`, since charts
  on `F'E' ∪ {1}` restrict to injective charts on `FE ∪ {1}`. This is used in `2 => 3` of the Theorem.
- If some `fe = 1`, the codes `sigma_f(v)` over good `v` are distinct, because `tau_e(sigma_f(v)) = v`. Hence
  `mu >= 1`, and the lemma is never stronger than the truth.
- If no `fe = 1`, then `H(x(1)|Y_F) = k log q` and `Phi >= log q` holds trivially.

## 3. Tight models rebuild sofic approximations (Lemma B)

**Lemma B.** Let `(E,F)` be a pattern with `B_r ⊆ E ∩ F` (`r >= 1`), and take any reading model with ratio
`mu`. Put `b = |B_r|`. Then there are permutations `pi_s` of `M_g` (`s` in `S`) and a set `V_1 ⊆ M_g` with

    |M_g \ V_1| <= (1 + b) b^2 (mu - 1) |M_g|

such that, for every `v` in `V_1`:
- there is an injective map `c_v : B_r -> M_g`;
- for every word `s_1 ... s_l` in `S` with `l <= r`, `pi_{s_l} ∘ ... ∘ pi_{s_1}(v) = c_v(s_1 ... s_l)`.

In particular, two words of length `<= r` send `v` to the same point exactly when they are equal in `K`. After
`pi'_s := pi_{s^-1}`, which turns the right action into a left one, this is an `(r, (1+b) b^2 (mu-1))`-sofic
approximation of `K`.

*Proof.* Let `N'_0` be the codes `sigma_f(v)` with `v` good and `f` in `B_r`. For a code `n`, let
`u(n) = #{(v,f) : v good, f in B_r, sigma_f(v) = n}`.

1. **At most one user per slot.** If `v` is good, `f` is in `B_r` and `sigma_f(v) = n`, then `f^-1` is in
   `B_r ⊆ E`. So `tau_{f^-1}(n) = c_v(f f^-1) = v`. Given `(n, f)`, the site `v` is therefore determined, and
   `u(n) <= b`. Taking `f = 1` shows `|N'_0| >= |M_g|`, hence `mu >= 1`.
2. **Few non-full codes.** Call `n` *full* if `u(n) = b`. Then

       sum_{n in N'_0} (b - u(n)) = b |N'_0| - b |M_g| <= b (mu - 1) |M_g|,

   so fewer than `b (mu-1) |M_g|` codes are not full. Let `V_0` be the good sites `v` with `sigma_f(v)` full for
   every `f` in `B_r`. Each non-full code has at most one user per `f`, so

       |M_g \ V_0| <= b^2 (mu - 1) |M_g|.

3. **Consistency.** Let `v` be good, `f, f'` in `B_r`, and `n = sigma_f(v)` full.
   - By fullness some good `w` has `sigma_{f'}(w) = n`, and by step 1, `w = tau_{f'^-1}(n) = c_v(f f'^-1)`.
   - For `e` in `E`: `c_w(f' e) = tau_e(n) = c_v(f e)`.
   - With `f' = 1`: **for `v` in `V_0` and `g` in `B_r`, `w = c_v(g)` is good and `c_w(e) = c_v(g e)` for all `e`
     in `E`.**
4. **Injectivity.** For `g` in `B_r`, the map `v -> c_v(g)` is injective on `V_0`, because by step 3
   `c_{c_v(g)}(g^-1) = c_v(1) = v`. In particular `rho_s(v) := tau_s(sigma_1(v)) = c_v(s)` is injective on `V_0`,
   and it extends to a permutation `pi_s` of `M_g`.
5. **Deep points.** Let `V_1` be the set of `v` in `V_0` with `c_v(g)` in `V_0` for all `g` in `B_r`. By the
   injectivity in step 4, `|V_0 \ V_1| <= b |M_g \ V_0|`, which gives the stated bound.
6. **Words.** For `v` in `V_1`, induct on `j <= l <= r`, with `g_j = s_1 ... s_j`.
   - Suppose `pi_{s_j} ... pi_{s_1}(v) = c_v(g_j) =: p`. Then `p` is in `V_0` because `g_j` is in `B_r`.
   - So `pi_{s_{j+1}}(p) = c_p(s_{j+1})`, which by step 3 (`g = g_j`, `e = s_{j+1}`) equals `c_v(g_{j+1})`.
   - Finally, `c_v` is injective on `P ⊇ B_r`. ∎

## 4. Converse

Suppose `K` has a `(2r, delta)`-sofic approximation, written as a right action `rho` on `M`. For `g` in `B_r`, fix
a word for `g` and let `rho_g` be its evaluation. Build the model as follows:
- `N = M`;
- `sigma_f = rho_f` for `f` in `B_r`;
- `tau_e = rho_e` for `e` in `B_r`.

Every point with a correct injective `2r`-chart is good, so `|M_g| >= (1-delta)|M|` and `|N'| <= |M|`. Hence
`mu <= 1/(1-delta)`.

**Theorem.** For a finitely generated group `K` the following are equivalent:
1. `K` is sofic;
2. for every `r`, the infimum of `mu` over reading models of `(B_r, B_r)` is `1`;
3. Lemma A certifies `Phi(c) >= log q` for every configuration `c` of `K`.

*Proof.*
- `1 => 2` is Section 4.
- `2 => 1` is Lemma B.
- `2 => 3`: extend `c` to `(k, E ∪ B_r, F ∪ B_r, psi ∘ restriction)` with `r` large. This leaves `H(Y)` unchanged
  and does not increase `H(x(1)|Y_F)`.
- `3 => 2`: the certificate for any configuration with `H(Y) > 0` and pattern `(B_r, B_r)` needs models with
  `mu -> 1`. ∎

## 5. The obstruction

Let `K` be nonsofic, for example the finitely generated `EL_D(R) <= L_(F_2)(1,2)^x` of `openai-leavitt-unit-nonsofic`,
a subgroup of every host of `bernoulli-rokhlin-maximal-on-fg-simple-kazhdan-groups` that contains `U`. Then some
radius `r_0` and some `delta_* > 0` admit no `(r_0, delta_*)`-sofic approximation. By Lemma B, every reading model
of every pattern with `B_{r_0} ⊆ E ∩ F` has

    mu >= 1 + eta_0,   eta_0 = delta_* / ((1 + b) b^2),   b = |B_{r_0}|.

So the best a reading-model certificate gives for such a configuration is

    Phi(c) >= log q - eta_0 H(Y)/k.

Maximality on `K` needs `Phi(c) >= log q` for all these configurations: they are exactly the extensions of all
configurations supported in `B_{r_0}`, and extension can only lower `Phi`. So the class certifies nothing on them
beyond a loss of the fixed fraction `eta_0` of `H(Y)`.

**Where every member dies.** The death is at step 1 of Lemma B:
- tightness of the double count, `|N'| ~ |M_g|`, together with the unit incidences `f f^-1 = 1`, forces every code
  to be read back to a unique site in each of its `b` slots;
- fullness turns the purely local charts into consistent charts (step 3);
- consistency turns the reading maps into near-permutations (step 4).

A weaker finite structure has no room to be non-sofic and still tight.

**What the class contains.**
- Gromov--Weiss and microstate counting on sofic models.
- In-group Følner windows, where `mu = |WF|/|W|` and `inf mu = 1` iff `K` is amenable.
- Partial actions, pattern-local models without global consistency, non-bijective reading maps, and models with an
  arbitrary boundary: bad sites are free in Lemma A.
- Weighted models with rational weights, by replication.

**What it does not contain.**
- Linear or rank models (dimension counts over a field).
- Tracial and Hilbert--Schmidt microstate counts, where an entropy is replaced by a log-determinant or a volume.
- Limit functionals that are not a single double count. Splitting-monotone cluster functionals are killed
  separately on one-ended groups, in the live lemma `cluster-entropy-functionals-vanish-on-one-ended-bernoulli`
  of lane a-gs-pull-7.
- Arguments that bound `Phi(c)` through a configuration that does not extend `c`.

**The gate.** A finite-model lower bound on a nonsofic host must use models in which the ambient information is not
Shannon entropy of iid labels, for instance vector-space dimension (linear soficity), Hilbert--Schmidt volume
(hyperlinearity), or a non-product measure on the labels. For the product measure, Lemma A is an exact accounting,
and Lemma B shows it has no slack.

# Rank functions on Thompson's V: the torsion constant is the fixed rank, and wandering elements act freely

Lane `w5-v-infinite-order`, 2026-09-12. Supports `v-rank-torsion-constant-equals-global-fixed-rank` and
`v-rank-models-act-freely-by-wandering-elements`. These bear on two gates:
- the characteristic-two V rank gate `thompson-v-has-no-nontrivial-f2-rank-model`;
- the characteristic-three abstract gate `thompson-v-ternary-rank-functions-are-augmentation`.

Everything is proved for ABSTRACT Sylvester matrix rank functions over any field. Each step that needs a
matricial model or a regular ring is marked **[matricial]**. Nothing here decides either gate.

## 0. Setting

- `X = {0,1}^N`, cylinders `[w]`, `V` acting by prefix replacement. For a clopen `O`, `V_O` is the rigid
  stabilizer (identity outside `O`).
- `F` is any field, `R = F[V]`, and `rk` a Sylvester matrix rank function on `R` with `rk(1) = 1`. A matricial
  model `sigma : V -> M^x` into a rank ultraproduct gives one, `rk(A) = rk(sigma(A))`, so every result below
  applies to models.
- `p` is an odd prime different from `char F`. So characteristic two is covered with `p = 3` and
  characteristic three with `p = 5`.
- *Clopen `p`-cycles* and *clopen-cycle subgroups* are as in
  `research/artifacts/thompson-v-rank-models-torsion-spectra-2026-09-12.md` (cited [TS]). For such `P`,
  `e_P = |P|^(-1) sum_(g in P) [g]` is an idempotent of `R`.
- **Scalar extension.** For a finite extension `F'` of `F`, `rk'(A) = rk(res A)/[F' : F]` is a Sylvester rank
  function on `F'[V]` extending `rk`. Here `res` writes a matrix over `F'[V]` as a matrix over `F[V]` through
  a basis of `F'`.

**Sylvester consequences used** (lists `Y` of elements of a ring, `col(Y)` the column they form):
- (S1) `rk(u A v) = rk(A)` for units `u`, `v`.
- (S2) `rk(A + B) <= rk(A) + rk(B)`.
- (S3) Orthogonal idempotents: `rk(e + e') = rk(e) + rk(e')`. Proof: `e + e'` is `(1 1) diag(e, e') (1 1)^T`,
  and `diag(e, e')` is `(e e')^T (e + e') (e e')`.
- (S4) **Column submodularity.** If `Y_0 <= Y_1 cap Y_2`, then
  `rk col(Y_1 cup Y_2) + rk col(Y_0) <= rk col(Y_1) + rk col(Y_2)`.
  *Proof.* Write `col(Y_1) = (c_0; x)` and `col(Y_2) = (c_0; y)`. Starting from `diag(col Y_1, col Y_2)`, add the
  second block column to the first, reorder rows, and subtract row `(c_0 | 0)` from `(c_0 | c_0)`. The result is
  `[[A, B], [0, c_0]]` with `A = col(Y_1 cup Y_2)`. The axiom `rk [[A, B], [0, D]] >= rk A + rk D` gives the bound.
- (S5) If every element of `Y'` lies in the left ideal generated by `Y`, then `rk col(Y cup Y') = rk col(Y)`.
- (S6) If `1` lies in the left ideal generated by `y_1, ..., y_m`, then `rk(y_1) + ... + rk(y_m) >= 1`.

**Fixed rank.** `phi(Y) = 1 - rk col(Y)`. For a subgroup `H` with a finite generating set `S`, set
`phi_H = phi(1 - [s] : s in S)`. By (S5) and `1 - [gh] = (1 - [g]) + [g](1 - [h])` it does not depend on `S`.
- For a finite `P` with `|P|` invertible, the left ideal generated by the `1 - [s]` is `R(1 - e_P)`, so
  `phi_P = rk(e_P)`.
- **[matricial]** For a model, `phi_H` is the rank of the fixed right ideal of `sigma(H)`.

**Torsion law** (`v-rank-models-are-trivial-plus-free-on-odd-cycle-trees`; valid for abstract `rk`, see
Section 3.1): there is one `a = a_p(rk)` with `rk(e_P) = a + (1 - a)/|P|` for every clopen-cycle subgroup `P`.

## 1. The torsion constant is the fixed rank

**Lemma 1.1 (group theory).** Let `U = X \ [00]` and `W = X \ [11]`. Then `V = <V_U, V_W>`, and each of `V_U`,
`V_W` is generated by finitely many clopen `p`-cycles supported in `U` (respectively `W`).

*Proof.*
- **Clopen transpositions generate `V`.** A clopen transposition exchanges two disjoint nonempty clopens by a
  prefix bijection. The set of them is conjugation invariant, so they generate a normal subgroup, which is `V`
  by simplicity.
- **Fragmenting.** Split `t : A <-> B` into commuting transpositions `t_i : A_i <-> t(A_i)`, where each piece
  lies in one of `[00], [01], [10], [11]`. If both pieces of `t_i` avoid `[00]`, then `t_i` is in `V_U`; if both
  avoid `[11]`, it is in `V_W`.
- **The remaining case,** `A_i <= [00]` and `C = t(A_i) <= [11]`:
  - pick a clopen `D <= [01]` and prefix bijections `psi : A_i -> D` and `phi = t psi^(-1) : D -> C`;
  - `r : A_i <-> D` has support in `[0]`, so `r` is in `V_W`; `r' : D <-> C` has support in `[01] cup [11]`, so
    `r'` is in `V_U`;
  - `r r' r = t_i`: on `A_i` it is `phi psi = t`, on `C` it is `psi^(-1) phi^(-1) = t`, and elsewhere the identity.
- **Generation of `V_U` and `V_W`.** Both are isomorphic to `V`, so they are simple and finitely generated. Their
  clopen `p`-cycles form a nonempty conjugation-invariant set, so finitely many of them generate. Each is a
  clopen `p`-cycle of `V`. QED

**Theorem 1.2.** For every Sylvester rank function `rk` on `F[V]` and every odd prime `p != char F`,
`a_p(rk) = phi_V(rk)`.

*Proof.*
- **Upper bound.** For a clopen-cycle subgroup `P`, the rows `1 - [s]`, `s` in `P`, lie in the left ideal of
  the generators of `V`. By (S5), and because adding rows cannot lower rank, `phi_V <= phi_P = a + (1 - a)/|P|`.
  Tree groups of unbounded order give `phi_V <= a`.
- **Lower bound, setup.** Take `S_U`, `S_W` from Lemma 1.1, with `m = |S_U|` and `m' = |S_W|`.
  - Choose `k` clopen `p`-cycles with pairwise disjoint supports inside `[00]`, not covering it, generating
    `T_k`. For example, cycle `p` cylinders `[0 0 1^(i-1) 0 c_j]`.
  - Choose `T'_k` inside `[11]` the same way.
  - Disjoint `p`-cycles leaving a nonempty complement generate clopen-cycle subgroups, so `T_k`, `T'_k`,
    `T_k x T'_k` and `<s> x T_k` (for `s` in `S_U`) all are.
  - Put `Y_0 = {1 - e_(T_k)}`, `Y'_0 = {1 - e_(T'_k)}`, and `Y_U = {1 - [s] : s in S_U}`, and define `Y_W`
    likewise.
- **Step 1.** `phi(Y_0 cup {1 - [s]}) = rk(e_(<s> x T_k))`, because both lists generate the augmentation ideal of
  `<s> x T_k`. This is `rk(e_(T_k)) - (1 - a) p^(-k)(1 - 1/p)`. Iterating (S4) over `s` in `S_U` gives
  `phi(Y_0 cup Y_U) >= a - m p^(-k)`.
- **Step 2.** Similarly, `phi(Y'_0 cup Y_W) >= a - m' p^(-k)`, and `phi(Y_0 cup Y'_0) = rk(e_(T_k x T'_k)) = a + (1 - a) p^(-2k)`.
- **Step 3.** (S4) with intersection `Y_0` gives `phi(Y_0 cup Y'_0 cup Y_U) >= a - (m + 1) p^(-k)`, and likewise
  for `Y_W`. (S4) with intersection `Y_0 cup Y'_0` gives `phi(Y_0 cup Y'_0 cup Y_U cup Y_W) >= a - (m + m' + 3) p^(-k)`.
- **Conclusion.** The rows `Y_U cup Y_W` generate the left augmentation ideal of `V`, and `Y_0`, `Y'_0` lie in
  it. By (S5) the last quantity equals `phi_V`. Letting `k -> inf` gives `phi_V >= a`. QED

**Corollary 1.3.**
1. `a_p(rk)` is independent of `p`.
2. **Fixed ranks do not localize.** For every nonempty clopen `O != X`, `phi_(V_O) = phi_V`, because `V_O`
   contains tree groups of unbounded order.
3. **Dichotomy.** `rk` is the augmentation rank iff `phi_V = 1` iff `a_p = 1`. Otherwise `rk` is detecting, by
   `simple-group-rank-functions-are-augmentation-or-detecting`. So the characteristic-three gate
   `thompson-v-ternary-rank-functions-are-augmentation` says `a_5(rk) = 1` for every `rk` on `F_3[V]`, and the
   binary gate says the same with `p = 3` for matricial models over `F_2`.
4. **Reduced rank functions.** If `phi_V = 0`, every clopen-cycle subgroup is regular
   (`rk(e_chi) = 1/|P|`), and every clopen `p`-cycle has `rk([g] - 1) = (p - 1)/p`.
5. **[matricial]** **Reduced quotient.** For a model with fixed idempotent `f`, `sigma(g) f = f` makes `sigma` block
   upper triangular, and `(1 - f) sigma (1 - f)` is a nontrivial model with `phi_V = 0` when `sigma` is
   nontrivial.
   - Idempotent block-triangular elements have rank `rk(f) + rk(e'_P)`, and perfection of `V` rules out a
     trivial compression.
   - This uses an idempotent generating the fixed ideal, which an abstract rank function does not provide.
     No abstract version is known.

## 2. Elements with a wandering clopen act freely

**Lemma 2.1 (dynamics).** Let `x` in `V` have a periodic point `y` of period `r` at which `x^r` has nonzero slope
([TS] Section 3). Then some nonempty clopen `W` has pairwise disjoint translates `x^j W`, for `j` in `Z`.

*Proof.*
- **Period one, negative slope.** Near `y`, `x` acts as `u z -> u' z` with `|u'| > |u|`. Both are prefixes of `y`,
  so `x[u] = [u'] <= [u]`, strictly. Put `W = [u] \ [u']`.
  - For `j >= 0`, `x^j W` are annuli of the decreasing cylinders `x^j[u]`.
  - For `j >= 1`, `x^(-j) W = x^(-j)[u] \ x^(-j+1)[u]` are annuli of an increasing chain, all outside `[u]`.
- **Positive slope:** use `x^(-1)`.
- **Period `r`.** Shrink `u` until `x^i[u]` (`0 <= i < r`) are pairwise disjoint, and apply the first case to
  `x^r`. For `k = m r + i` with `0 < i < r`:
  - if `m >= 0`, `x^k W <= x^i [u]`, which misses `[u]`;
  - if `m < 0`, `W cap x^k W = x^k(x^(-k) W cap W)` reduces to the previous case. QED

*Example.* `x_0` has slopes `+1`, `-1` at `0^inf`, `1^inf` ([TS] Example 3.2). Standard revealing-pair theory would
give such a point for every infinite-order element. That is not verified here, and no node depends on it.

**Setup 2.2.** Fix `x`, `W` as in Lemma 2.1, and a clopen `p`-cycle `g` supported in `W`. Put `g_j = x^j g x^(-j)`
and `B = <g_j : j in Z>`, an elementary abelian group on independent generators.
- For finite `J`, `B_J = <g_j : j in J>` is a clopen-cycle subgroup, since the supports are disjoint and leave a
  nonempty complement.
- Extend scalars to `F'` containing the `p`-th roots of unity, and let `R' = F'[V]`.
- Let `C = Hom(B, mu_p)`, which is `mu_p^Z`, a Cantor set, with Haar measure `mu`, trivial character `1`, and shift
  `(T chi)(b) = chi(x^(-1) b x)`.
- Send the cylinder `{chi : chi restricted to B_J = psi}` to the isotypic idempotent `e_psi` of `F'[B_J]`. Isotypic
  idempotents of `B_J` are sums of those of `B_(J')` for `J <= J'`, so this gives a Boolean homomorphism `S -> e_S`
  from clopens of `C` into commuting idempotents of `R'`, with `e_C = 1`.
- **Rank.** `rk(e_S) = a [1 in S] + (1 - a) mu(S)`. The torsion law gives it on cylinders, and (S3) on disjoint
  unions.
- **Covariance.** `[x] e_S [x]^(-1) = e_(T S)` in `R'`, by reindexing `b -> x b x^(-1)` in the averaging sum.

**Theorem 2.3.** In Setup 2.2, for every Sylvester rank function `rk` on `F[V]` and every nonzero `q` in `F[t]`,

```text
rk q([x]) >= 1 - a_p(rk) = 1 - phi_V(rk).
```

*Proof.*
- **Reduction.** `[x]` is a unit, so by (S1) we may take `q(0) != 0`. Write `q = c_0 + ... + c_d t^d`.
- **Towers.** Let `S` be the cylinder `chi(g_0) = ... = chi(g_(l-1)) = omega` for some `omega != 1`, so
  `mu(S) = p^(-l)` and `1` is not in `S`.
  - For `h <= R`, let `S_h` be the set of points of `S` with first return time `h`, and `L_(h,i) = T^i S_h` for
    `0 <= i < h`. These are pairwise disjoint clopens.
  - Let `Z_R` be the rest of `C`. It contains `1`. Since `T` is ergodic Bernoulli, a.e. point visits `S` at
    arbitrarily negative and positive times, so `mu(Z_R) -> 0` as `R -> inf`.
  - Let `Bot` be the union of levels with `i < d`, so `mu(Bot) <= d p^(-l)`.
- **Recursion.** By covariance, for `d <= i < h`,
  `e_(L_(h,i)) q([x]) = sum_(k=0..d) c_k [x]^k e_(L_(h,i-k))`, so
  `c_0 e_(L_(h,i)) = e_(L_(h,i)) q([x]) - sum_(k>=1) c_k [x]^k e_(L_(h,i-k))`.
- **Left ideal.** By induction on `i`, every `e_(L_(h,i))` lies in the left ideal `R' q([x]) + R' e_Bot`: the base
  levels `i < d` lie in `R' e_Bot`. Also `e_(Z_R)` lies in `R' e_(Z_R)`. Summing,
  `1 = sum_(h,i) e_(L_(h,i)) + e_(Z_R)` lies in `R' q([x]) + R' e_Bot + R' e_(Z_R)`.
- **Rank count.** By (S6), `rk q([x]) >= 1 - d p^(-l) - a - (1 - a) mu(Z_R)`. Let `R -> inf`, then `l -> inf`.
  Theorem 1.2 identifies `a` with `phi_V`. QED

**Corollary 2.4.** `rk([x^j] - 1) >= 1 - phi_V` for all `j != 0`. For a reduced rank function (`phi_V = 0`),
every nonzero polynomial in `[x]` has rank `1`. **[matricial]** In a model this says `r.ann q(sigma(x))` has
rank at most `rk Fix(sigma(V))`.

**Remark 2.5.** A reduced rank function restricted to `F[<x>]` has the data of the regular representation of `Z`.
Restricted to `<x, g>`, which is `B` extended by `<x>` and so abelian-by-cyclic, it carries a covariant copy of the
Bernoulli shift `(C, mu, T)` with rank equal to Haar measure. A Følner permutation model of this amenable group
does exactly this, so `<x, g>` alone forces no contradiction.

## 3. Audit and calibration

### 3.1 Which V gate tools hold for abstract Sylvester rank functions

- **Torsion law** ([TS] Theorem 1.3, `v-rank-models-are-trivial-plus-free-on-odd-cycle-trees`): holds abstractly.
  - **What it uses:** conjugacy of clopen `p`-cycles (group theory); isotypic idempotents in `F'[P]`, with the
    scalar extension done by restriction of scalars (Section 0) instead of the field independence of matrix rank;
    additivity on orthogonal idempotents (S3); unit invariance (S1); Fourier inversion, which is real linear
    algebra on the vector of ranks; and positivity.
  - **Audit scope:** I read [TS] Lemma 1.1, the tree-group definitions, the node statement and the route summary
    of Theorem 1.3. Verifier: please confirm that no eigenvalue rounding enters the full proof.
- **Uniform displacement** (`thompson-v-rank-models-displace-every-element-uniformly`): holds abstractly. Its
  route states `rk([g,h] - 1) <= 2 rk(g - 1)` for any unital ring with a rank function, and everything else there
  (the two-commutator construction, conjugacy of clopen 3-cycles) is group theory.
- **No covariant model** (`thompson-v-cantor-system-has-no-covariant-rank-model`): the theorem holds abstractly
  for a rank function on any ring containing `F[V]` together with covariant cylinder idempotents. The proof is
  additivity on orthogonal idempotents plus conjugation invariance. On `F[V]` alone it is vacuous, because there
  are no cylinder idempotents. Its finite form (defect at least `1/4`) and the truncation bound (ratio at least
  `1/32`, which rounds units to invertibles at corank cost) are **[matricial]**.
- **Symmetric-group stage theorem** (`thompson-v-rank-models-through-displacing-sym-reps-are-trivial`):
  **[matricial]**, since it uses exact representations at finite stages.
- **Slopes** ([TS] Section 3): group theory.
- **This artifact:** Theorems 1.2 and 2.3 are abstract. Corollary 1.3(5), the reduced compression, is
  **[matricial]**.

### 3.2 Calibration: amenable configurations are inert

**Proposition 3.1 (Følner rank functions).** Let `H <= V` be finitely generated and amenable, and `F` any field.
Følner sets give a sofic approximation of `H`, and normalized ranks in the permutation modules give a Sylvester
rank function `rk_H` on `F[H]` with these properties:
- every finite subgroup acts regularly, so `a_p = 0`;
- every element of infinite order is free, `rk_H q([h]) = 1` for `q != 0`, because on most points its cycles are
  longer than `deg q` times any bound;
- all relations of `H` hold.

So `rk_H` satisfies the torsion law, uniform displacement, and the reduced conclusions of Theorems 1.2 and 2.3 on
`H`.

**Proposition 3.2 (import at statement level, not re-read).** For amenable groups, any two sofic approximations
are close after conjugation (Elek–Szabó, *Sofic representations of amenable groups*, as cited in
`research/artifacts/peelable-extreme-one-relator-sofic-2026-09-11.md`).
- **Rank data are intrinsic.** Small Hamming perturbations change ranks by small amounts, and conjugation changes
  nothing. So the data `rk_H` induces on `F[K]`, for any subgroup `K <= H`, depend only on the marked group `K`.
- **Conjugacy invariance.** Tuples in `H` that are conjugate by an element of `V` generate isomorphic marked
  groups, so they get equal rank data.

**Consequence.** Consider an argument that uses only a finite configuration generating an amenable subgroup
`H <= V`: rank identities in `F[H]`, `V`-conjugacy invariance among tuples in `H`, and the torsion law.
`rk_H` satisfies all of that and is detecting, so no such argument proves either gate. The configurations in
this lane's brief fall as follows.
- **Inert.**
  - Lamps along a wandering orbit, `<x, g>`, which is abelian-by-cyclic.
  - Exact partial conjugacies `x y x^(-1) = y^2`, which are quotients of `BS(1,2)`.
  - Locally finite torsion, and ascending HNN extensions of locally finite groups ([TS] Sections 2 and 4).
- **Not covered.**
  - Two clopen `p`-cycles generating an infinite subgroup are inert only when that subgroup is amenable (for
    example lamplighter-type or virtually abelian pairs). Pairs generating a non-amenable subgroup, such as a free
    product, are not covered.
  - Higman–Thompson relations among baker maps generate subgroups like Thompson's `F`, whose amenability is open.
    An argument using only `F`-configurations would prove `F` not sofic.

### 3.3 Answer to the question in the brief

Does `a_p < 1`, combined with depth change, force a contradiction? Not through any mechanism in scope.
- **Nontriviality:** `a_p < 1` is exactly nontriviality, and it equals `phi_V < 1` (Theorem 1.2).
- **Sofic behaviour:** in the reduced part, torsion is regular and every element with a wandering clopen acts
  freely (Theorem 2.3), which is how a sofic approximation behaves.
- **Inertness:** every depth-changing configuration in scope generates an amenable subgroup, so Proposition 3.2
  makes it inert.
- **What a proof needs:** relations in a non-amenable subgroup. Any proof of either gate shows `V` is not sofic.

## 4. Where it stops

- **Abstract reduced quotient.** No abstract construction sends a rank function with `0 < phi_V < 1` to one with
  `phi_V = 0`.
- **Joint data.** Theorem 2.3 controls single polynomials in `[x]`. Whether a reduced rank function restricted to
  `F[<x, g>]` equals the Følner rank there, on mixed elements of `F[B extended by <x>]`, is open.
- **Non-amenable configurations.** No argument is known for depth-changing `p`-cycle pairs that generate free
  products, or for the Higman–Thompson relations.
- **Infinite-order elements without a nonzero-slope periodic point.** There are none if revealing-pair theory
  applies. That is not verified.

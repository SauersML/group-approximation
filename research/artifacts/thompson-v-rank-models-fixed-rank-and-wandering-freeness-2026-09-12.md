# Rank models of Thompson's V: the torsion constant is the fixed rank, and wandering elements act freely

Lane `w5-v-infinite-order`, 2026-09-12. Supports `v-rank-torsion-constant-equals-global-fixed-rank` and
`v-rank-models-act-freely-by-wandering-elements`, for the V rank gate
`thompson-v-has-no-nontrivial-f2-rank-model`. Nothing here decides the gate.

## 0. Setting

- `X = {0,1}^N`, cylinders `[w]`, and `V` acting by prefix replacement. For a clopen `O`, the rigid
  stabilizer `V_O` is the set of elements of `V` that are the identity outside `O`.
- `F` is a field and `M` a rank ultraproduct of matrix algebras over `F`, with rank `rk`. A *rank model*
  is a group homomorphism `sigma : V -> M^x`.
- `p` is an odd prime different from `char F`, so characteristic two is included.
- *Clopen `p`-cycles* and *clopen-cycle subgroups* are as in
  `research/artifacts/thompson-v-rank-models-torsion-spectra-2026-09-12.md` (cited [TS]). For such `P`,
  `e_P = |P|^(-1) sum_(g in P) sigma(g)` is an idempotent of `M`.
- **Imported, [TS] Theorem 1.3** (`v-rank-models-are-trivial-plus-free-on-odd-cycle-trees`): there is one
  `a = a_p(sigma)` with `rk(e_P) = a + (1 - a)/|P|` for every clopen-cycle subgroup `P`.

**Ring facts used.** `M` is a von Neumann regular ring and `rk` is a faithful rank function on it.
- Principal right ideals form a lattice, and `rk(I + J) + rk(I cap J) = rk(I) + rk(J)`. At each finite
  stage this is the dimension formula, and it passes to the ultralimit.
- Consequence: if `I_1, ..., I_m <= I_0`, then `rk(I_1 cap ... cap I_m) >= rk(I_0) - sum_j (rk(I_0) - rk(I_j))`.
- For `y` in `M`, `r.ann(y) = (1 - y^+ y) M` has rank `1 - rk(y)`. Since `rk` is faithful, principal right
  ideals `I <= J` with `rk(I) = rk(J)` are equal.

For a subset `S` of `V`, write `Fix(S) = cap_(s in S) r.ann(sigma(s) - 1)`. For a clopen-cycle subgroup `P`,
`Fix(P) = e_P M`. Write `f` for an idempotent with `f M = Fix(V)`, the fixed ideal of a finite generating
set.

## 1. The torsion constant is the global fixed rank

**Lemma 1.1 (two rigid stabilizers generate V).** Let `U = X \ [00]` and `W = X \ [11]`. Then
`V = <V_U, V_W>`. Each of `V_U`, `V_W` is isomorphic to `V`, and is generated by finitely many clopen
`p`-cycles supported in `U` (respectively `W`).

*Proof.*
- **Transpositions generate V.** A *clopen transposition* exchanges two disjoint nonempty clopens by a
  prefix bijection and fixes everything else. Conjugates of clopen transpositions are clopen
  transpositions, so they generate a nontrivial normal subgroup, which is `V` because `V` is simple.
- **Fragmenting.** Let `t` exchange `A` and `B`. Cut `A` into cylinders `A_i` so small that `A_i` and `t(A_i)`
  each lie in one of `[00], [01], [10], [11]`. Then `t` is the product of the commuting transpositions `t_i`
  exchanging `A_i` and `t(A_i)`.
- **Each piece.** If `A_i` and `t(A_i)` both avoid `[00]`, then `t_i` lies in `V_U`. If both avoid `[11]`, it
  lies in `V_W`. Otherwise, say `A_i <= [00]` and `C = t(A_i) <= [11]`.
  - Pick a nonempty clopen `D <= [01]`, a prefix bijection `psi : A_i -> D`, and put `phi = t psi^(-1) : D -> C`.
  - Let `r` exchange `A_i` and `D` by `psi`; its support lies in `[0]`, which avoids `[11]`, so `r` is in `V_W`.
  - Let `r'` exchange `D` and `C` by `phi`; its support lies in `[01] cup [11]`, which avoids `[00]`, so
    `r'` is in `V_U`.
  - Then `r r' r = t_i`. On `A_i` the composite is `phi psi = t`. On `C` it is `psi^(-1) phi^(-1) = t^(-1) = t`.
    On `D` and elsewhere it is the identity.
- **Rigid stabilizers.** `U` and `W` are nonempty proper clopens, prefix-homeomorphic to `X`, so `V_U` and `V_W`
  are isomorphic to `V`. Each is simple and finitely generated. Its clopen `p`-cycles with nonempty
  complement inside `U` (or `W`) form a nonempty conjugation-invariant set, so they generate it, and finitely
  many suffice. Such an element is a clopen `p`-cycle of `V`, because it also fixes `[00]` (or `[11]`). QED

**Theorem 1.2.** For every rank model `sigma` of `V` and every odd prime `p != char F`,

```text
a_p(sigma) = rk(f),   the rank of the fixed ideal Fix(V).
```

*Proof.*
- **Upper bound.** For every clopen-cycle subgroup `P`, `Fix(V) <= Fix(P) = e_P M`, so
  `rk(f) <= a + (1 - a)/|P|`. The dyadic tree groups of [TS] have unbounded order, so `rk(f) <= a`.
- **Setup for the lower bound.** Take `S_U`, `S_W` from Lemma 1.1, with `m = |S_U|` and `m' = |S_W|`.
  - For `k >= 1`, choose clopen `p`-cycles `g_1, ..., g_k` with pairwise disjoint supports inside `[00]`
    whose supports do not cover `[00]`. For example `g_i` cycles the cylinders `[0 0 1^(i-1) 0 c_j]` for
    `p` words `c_j` of one length that do not cover.
  - Put `T_k = <g_1, ..., g_k>`, and choose `T'_k` the same way inside `[11]`.
  - Every nonidentity element of a subgroup generated by clopen `p`-cycles with pairwise disjoint supports,
    leaving a nonempty complement, is a clopen `p`-cycle: take the union of pieces. So `T_k`, `T'_k`,
    `T_k x T'_k`, and `<s> x T_k` for `s` in `S_U` are clopen-cycle subgroups. The last is valid because the
    support of `s` lies in `U`, which is disjoint from `[00]`.
- **Step 1.** For `s` in `S_U`, `Fix(<s> x T_k) = Fix(s) cap e_(T_k) M`, and
  `rk(e_(T_k)) - rk(e_(<s> x T_k)) = (1 - a) p^(-k) (1 - 1/p)`. The iterated modular bound gives
  `A_k = Fix(S_U) cap e_(T_k) M` with `rk(A_k) >= a + (1 - a)p^(-k) - m (1 - a) p^(-k) >= a - m p^(-k)`.
- **Step 2.** In the same way `B_k = Fix(S_W) cap e_(T'_k) M` has `rk(B_k) >= a - m' p^(-k)`.
- **Step 3.** `C_k = e_(T_k) M cap e_(T'_k) M = e_(T_k x T'_k) M` has rank `a + (1 - a) p^(-2k)`.
  - `A_k` and `C_k` lie in `e_(T_k) M`, so `rk(A_k cap C_k) >= rk(A_k) + rk(C_k) - rk(e_(T_k)) >= a - (m + 1) p^(-k)`.
  - Likewise `rk(B_k cap C_k) >= a - (m' + 1) p^(-k)`.
  - Both lie in `C_k`, so `rk(A_k cap B_k cap C_k) >= a - (m + m' + 3) p^(-k)`.
- **Conclusion.** `A_k cap B_k cap C_k <= Fix(S_U cup S_W) = Fix(V)`, because `S_U cup S_W` generates `V`.
  So `rk(f) >= a - (m + m' + 3) p^(-k)` for every `k`, and `rk(f) >= a`. QED

**Corollary 1.3.**
1. `a_p(sigma)` does not depend on `p`.
2. **Fixed spaces do not localize.** For every nonempty clopen `O != X`, `Fix(V_O) = Fix(V)`. `V_O` contains
   dyadic tree groups of unbounded order, so `rk Fix(V_O) <= a = rk(f)`. Also `Fix(V) <= Fix(V_O)`, and
   faithfulness gives equality.
3. **Reduced quotient.** Let `sigma` be nontrivial. Since `sigma(g) f = f`, every `sigma(g)` is block upper
   triangular for `1 = f + (1 - f)`, and `sigma'(g) = (1 - f) sigma(g) (1 - f)` is a rank model of `V` in the
   corner `(1 - f) M (1 - f)`, again a rank ultraproduct.
   - For each clopen-cycle `P`, `sigma(e_P) = f + X + e'_P` with `X` in `f M (1 - f)`. Idempotency forces
     `X e'_P = 0`, so `rk(e_P) = rk(f) + rk(e'_P)`. By Theorem 1.2, `rk(e'_P) = (1 - a)/|P|`, and the
     normalized rank in the corner is `1/|P|`. So `a_p(sigma') = 0`, and by Theorem 1.2 `sigma'` has no
     nonzero fixed vectors.
   - `sigma'` is nontrivial. Otherwise every `sigma(g)` would lie in the abelian group `1 + f M (1 - f)`,
     and perfection of `V` would make `sigma` trivial.
4. **In a reduced model** (`Fix(V) = 0`), every clopen-cycle subgroup acts regularly (each isotypic
   rank `1/|P|`), every clopen `p`-cycle has `rk(sigma(g) - 1) = (p - 1)/p`, and no rigid stabilizer of a
   nonempty clopen fixes a nonzero vector.

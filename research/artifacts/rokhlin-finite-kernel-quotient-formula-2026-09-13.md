## 0. Setting and imports

- `W` is a countably infinite group, `N ◁ W` is finite with `n = |N|`, `Q = W/N` and `π : W -> Q`. When `Q` is
  finitely generated, `r` is the size of a generating set `{s_1, ..., s_r}` of `Q`, and `ŝ_j ∈ W` are fixed lifts.
- Actions are p.m.p. on standard probability spaces. For a `W`-action `(X, μ)`, `Σ_N` is the sigma-algebra of
  `N`-invariant Borel sets. `W` acts on `Σ_N` through `Q`, and `X/N` denotes this `Q`-factor.
- Rokhlin entropy, relative Rokhlin entropy and outer Rokhlin entropy are as in `seward-rokhlin-entropy-subadditivity`.
  For aperiodic actions `h^Rok_G(X) = inf { H(α) : σ-alg_G(α) = B(X) }` (Alpeev–Seward, arXiv:1705.09707,
  Corollary 1.4).
- `INF(G)` means `h_sup(G) = ∞`, where `h_sup(G)` is the supremum of `h^Rok_G(X)` over free ergodic actions with
  `h^Rok_G(X) < ∞`.

**Imports used.**
- **(I1) Sub-additivity** (`seward-rokhlin-entropy-subadditivity`). For ergodic `X` and an invariant sub-sigma-algebra
  `F`: `h^Rok_G(X) <= h^Rok_(G,μ)(F) + h^Rok_G(X | F)`.
- **(I2) Stabilizer growth** (`alpeev-seward-stabilizer-growth-kills-outer-entropy`, Theorem 1.11(i)). For an aperiodic
  action and a factor `f : X -> Y` with `|Stab(f(x)) : Stab(x)| >= k` a.e., `h^Rok_(G,μ)(Y) <= (1/k) h^Rok_G(Y)`.
- **(I3) Seward's per-group formula** (`seward-per-group-rokhlin-entropy-of-bernoulli-shifts`, Theorem 1.10).
  `h^Rok_G(L^G) = min{H(L), h_sup(G)}`. So `G` is Rokhlin-maximal at every `q` exactly when `INF(G)` holds.
- **(I4) Permanence** (`bernoulli-rokhlin-maximality-passes-to-subgroups`,
  `bernoulli-rokhlin-deficit-has-a-finitary-witness`). Maximality passes to subgroups and is closed under directed
  unions.

## 1. The torsor structure

**Lemma 1.1 (the quotient action is free).** If `W ↷ X` is free and ergodic, then `Q ↷ X/N` is free and ergodic,
and `Stab_W(Nx) = N` for a.e. `x`.

*Proof.* If `π(w)` fixes `Nx`, then `wx = mx` for some `m ∈ N`, so `m^-1 w ∈ Stab_W(x) = 1` and `w ∈ N`.
Ergodicity passes to factors. QED

**Lemma 1.2 (transversal and alignment cocycle).** Let `W ↷ X` be free. Fix a Borel linear order on `X` and let `M`
be the set of points that are least in their `N`-orbit. For `x ∈ X` let `p(x)` be the point of `M ∩ Nx`, and let
`τ(x) ∈ N` be defined by `x = τ(x) p(x)`. For `w ∈ W` put `a(x, w) = τ(w p(x))`. Then:

1. `p(mx) = p(x)` and `τ(mx) = m τ(x)` for `m ∈ N`; the push-forward `p_*μ` is `μ_M = n μ|_M`;
2. `w p(x) = a(x, w) p(wx)`, and `a(x, w)` depends only on `Nx`;
3. `a(x, m) = m` for `m ∈ N`;
4. `a(x, w_1 w_2) = (w_1 a(x, w_2) w_1^-1) a(w_2 x, w_1)`.

*Proof.* (1) `mx = m τ(x) p(x)` with `p(x) ∈ M ∩ N(mx)`. For Borel `A ⊆ M`, `p^-1(A) = NA` is a disjoint union
of `n` translates of `A`, so it has measure `n μ(A)`.
(2) `w p(x) = (w τ(x)^-1 w^-1) wx ∈ N wx`, so `p(w p(x)) = p(wx)` and `w p(x) = τ(w p(x)) p(wx)`. The right side
of the definition depends on `x` only through `p(x)`.
(3) `m p(x) ∈ mM`.
(4) `w_1 w_2 p(x) = w_1 a(x, w_2) p(w_2 x) = (w_1 a(x, w_2) w_1^-1) w_1 p(w_2 x)
= (w_1 a(x, w_2) w_1^-1) a(w_2 x, w_1) p(w_1 w_2 x)`. QED

**Lemma 1.3 (the torsor carries no relative entropy).** If `W ↷ X` is free and ergodic, then
`h^Rok_W(X | Σ_N) = 0`.

*Proof.* Fix `δ > 0` and a set `D ∈ Σ_N` with `0 < μ(D) < δ`. Put `α_D = {X \ D} ∪ {D ∩ mM : m ∈ N}`.
- **Entropy.** `D` is `Σ_N`-measurable, so `H(α_D | Σ_N) <= μ(D) log n < δ log n`.
- **Generation.** Enumerate `W = {w_0, w_1, ...}` and let `i(x)` be the least `i` with `w_i x ∈ D`. Each
  `w_i^-1 D` is `N`-invariant because `N` is normal, so `i` is `Σ_N`-measurable, and it is finite a.e. by ergodicity.
  - The atom of `α_D` containing `w_i x` gives `τ(w_i x)` on `{i(x) = i}`.
  - The map `x -> p(w_i x)` is `N`-invariant, since `w_i m x = (w_i m w_i^-1) w_i x`, so it is `Σ_N`-measurable.
  - Hence `x = w_i^-1 τ(w_i x) p(w_i x)` is measurable for `σ-alg_W(α_D) ∨ Σ_N`.

So `h^Rok_W(X | Σ_N) < δ log n` for every `δ`. QED

## 2. The quotient formula

**Theorem QF.** Let `W ↷ (X, μ)` be a free ergodic p.m.p. action. Then

    n h^Rok_W(X) <= h^Rok_Q(X/N).                                                    (2.1)

If `Q` is generated by `r` elements, then also

    h^Rok_Q(X/N) <= n h^Rok_W(X) + r log n.                                          (2.2)

*Proof of (2.1).* `X` is aperiodic. Let `f : X -> X/N` be the factor map. By Lemma 1.1, `Stab_W(x) = 1` and
`Stab_W(f(x)) = N` a.e., so the index is `n`, and (I2) gives `h^Rok_(W,μ)(Σ_N) <= (1/n) h^Rok_W(X/N)`.
- `W` acts on `X/N` through `Q`. For a partition `β` of `X/N`, `σ-alg_W(β) = σ-alg_Q(β)`. The `W`- and
  `Q`-actions on `X/N` are aperiodic, so `h^Rok_W(X/N) = h^Rok_Q(X/N)`.
- (I1) and Lemma 1.3 give `h^Rok_W(X) <= h^Rok_(W,μ)(Σ_N) + 0 <= (1/n) h^Rok_Q(X/N)`. QED

*Proof of (2.2).* We may assume `h^Rok_W(X) < ∞`. Let `α` be a countable partition of `X` with `H(α) < ∞` and
`σ-alg_W(α) = B(X)`. With the notation of Lemma 1.2, define `N`-invariant functions on `X`, that is, partitions of
`X/N`:
- `β(x) = (α(m p(x)))_(m ∈ N)`, with values in `α^N`;
- `ã_j(x) = a(x, ŝ_j) ∈ N` for `j = 1, ..., r`;
- `β' = β ∨ ã_1 ∨ ... ∨ ã_r`.

**Step 1: entropy.** Put `α_N = ∨_(m ∈ N) m^-1 α`, so `α_N(x) = (α(mx))_m` and `β = α_N ∘ p`. By Lemma 1.2(1)
the law of `β` is the law of `α_N` under `μ_M`.
- For `m ∈ N`, the law of `α_N` under `μ_(mM) = m_* μ_M` is that under `μ_M`, relabelled by the bijection of
  `α^N` induced by `m' -> m' m`. So it has the same entropy.
- `μ` is the average of the `n` measures `μ_(mM)`. By concavity of entropy,
  `H_(μ_M)(α_N) <= H_μ(α_N) <= n H(α)`.

Hence `H(β') <= H(β) + Σ_j H(ã_j) <= n H(α) + r log n`.

**Step 2: every alignment is expressible.** By Lemma 1.2(3,4), by induction on word length, and by the identity
`a(z, ŝ^-1) = ŝ^-1 a(ŝ^-1 z, ŝ)^-1 ŝ` (the case `w_1 = ŝ^-1`, `w_2 = ŝ` of (4)), each `a(·, w)` is a Borel
function of finitely many `W`-translates of the `ã_j`. Every `w ∈ W` is an element of `N` times a word in the
`ŝ_j^(±1)`. So every `a(·, w)` is `σ-alg_W(β')`-measurable.

**Step 3: the α-name of the transversal point is expressible.** For `w ∈ W`, Lemma 1.2(2) gives
`α(w p(x)) = α(a(x, w) p(wx))`, which is the `a(x, w)`-coordinate of `β(wx)`. So the map
`x -> (α(w p(x)))_(w ∈ W)` is `σ-alg_W(β')`-measurable.

**Step 4: generation.** Let `E ∈ Σ_N`. Then `1_E = 1_(E ∩ M) ∘ p`. Since `σ-alg_W(α) = B(X)`, there is a set `B'`
determined by the `α`-name with `μ(B' Δ (E ∩ M)) = 0`. By Lemma 1.2(1), `p_*μ` is absolutely continuous with respect
to `μ`, so `1_E = 1_(B') ∘ p` a.e., and this is a function of the `α`-name of `p(x)`. By Step 3 it is
`σ-alg_W(β')`-measurable. Since `β'` is `Σ_N`-measurable, `σ-alg_Q(β') = σ-alg_W(β') = Σ_N` mod null sets.

So `h^Rok_Q(X/N) <= H(β') <= n H(α) + r log n`. Taking the infimum over `α` gives (2.2). QED

**Remarks.**
1. **Sanity check.** `W = Z × Z/2`, `N = Z/2`, `X = {0,1}^W`. Over `Q = Z`, `X` is the Bernoulli shift with base
   `{0,1}^2`, and `X/N` is a two-to-one factor with Kolmogorov–Sinai entropy `log 4`. Here `n h^Rok_W(X) = log 4`,
   consistent with (2.1) and (2.2).
2. **Model test of the freeness hypothesis.** Let `Q ↷ Y` be free and let `W` act on `Y` through `Q`. This action is
   not free, and `h^Rok_W(Y) = h^Rok_Q(Y)`. The formula would predict `h^Rok_W = (1/n) h^Rok_Q`, so it fails, as it
   should: freeness is what makes `X -> X/N` an `N`-torsor.
3. **What it says about Alpeev–Seward.** For free `X`, (I2)(i) with `k = n` is sharp on `N`-quotients up to the
   additive error `(r log n)/n`, because `h^Rok_(W,μ)(Σ_N) = h^Rok_W(X) >= (h^Rok_Q(X/N) - r log n)/n`.
4. **Contrast with finite-index subgroups.** For `Γ <= G` of finite index the subgroup formula
   `h_Γ(X) = |G : Γ| h_G(X)` is open over nonamenable groups (Seward, arXiv:1602.06680v2, introduction, before
   Theorem 1.6). For finite kernels, the corresponding formula holds up to a bounded additive error.
5. **The error term.** Step 1 pays `log n` for each generator, to record how the fibres over neighbouring points are
   aligned. If all alignments `ã_j` could be made trivial, the lifts `ŝ_j` would satisfy every relator of `Q` in
   `W`, and the extension would split. This construction never removes the term, and the proofs below only need it
   bounded.

## 3. Descent of maximality

**Theorem D.** Let `N ◁ W` be finite with `W` infinite. If `W` is Rokhlin-maximal at every `q`, then so is `Q = W/N`.

*Proof.* **Finitely generated `Q`.** By (I3), `INF(W)` holds. Fix `C > 0` and a free ergodic `W`-action `X` with
`C < h^Rok_W(X) < ∞`.
- By Lemma 1.1, `X/N` is a free ergodic `Q`-action.
- By Theorem QF, `n C < h^Rok_Q(X/N) <= n h^Rok_W(X) + r log n < ∞`.

So `h_sup(Q) = ∞`, and (I3) gives maximality at every `q`.

**General `Q`.** If `Q` is locally finite, it is amenable, hence sofic and maximal. Otherwise fix an infinite finitely
generated `Q_0 <= Q`. Then `Q` is the directed union of the finitely generated subgroups `Q_i` containing `Q_0`.
- Each `W_i = π^-1(Q_i)` is infinite, finitely generated and contains `N`, so it is maximal by (I4).
- By the first case each `Q_i = W_i/N` is maximal.
- So `Q` is maximal by (I4). QED

**Remarks.**
1. **Scope.** Quotients by infinite normal subgroups are not covered. Every finitely generated group is a quotient
   of a free group, which is sofic and hence maximal. So descent along all quotients is exactly the open root
   `bernoulli-rokhlin-entropy-maximal-for-every-group`.
2. **Consequence.** A group with a non-maximal quotient by a finite normal subgroup is not maximal. For example, the
   open claim `leavitt-units-have-zero-rokhlin-entropy-supremum`, if established, makes every finite extension of
   `L_(F_2)(1,2)^x` non-maximal.
3. **Novelty.** Not found in the sources read (Section 4 of the companion artifact). The check was bounded to six
   papers of Seward and Alpeev–Seward, and no web search was available.

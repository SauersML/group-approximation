# Referee report (gq-referee-a, proof-gap lens): finite-state Möbius pieces see finitely many primes

**Reviewed:** `finite-state-mobius-pieces-see-finitely-many-primes` and its `-proof` (lane gq-ring-fp-simple,
dee7ac8ab), read on origin/main.

**Verdict: PASS** for items 1–3. There is one required addition (R1) to the third bullet of the Reading. That bullet
is true, but it does not follow from item 1 alone: the pieces there need not be rational. R1 supplies the missing
lemma. There are also two nits.

## Checks
- **Rigidity.** A Möbius map on `P^1(Q_p)` is determined by three points, and nonempty open subsets of `Z_p` are
  infinite. So pieces are unique. ✓
- **Item 1: the Baire composition (the author asked about this).**
  - The inverses: if `h_i = m` on an open `V ∋ z`, then `h_i^(−1) = m^(−1)` on the open set `h_i(V)`. So
    `U_(h_i^(−1)) ⊇ h_i(U_(h_i))` is dense open, and its pieces lie in `Δ`.
  - `Z*` is a countable intersection of dense open sets in the compact metric space `Z_p`, so it is dense.
  - At `z ∈ Z*`, each tail `s_(j+1)⋯s_n(z)` lies in `U_(s_j)`. Composition works because continuity lets the
    neighbourhood shrink, and `fg = fm' = mm'` there.
  - An `m` agreeing with `γ` on `V` meets `Z*` in `V`, and rigidity gives `m = δ ∈ Δ`. ✓
- **Item 2: the pole argument (the author asked about this).**
  - *Pieces live on cylinders.* Every piece lives on a cylinder, since cylinders form a basis, and
    `h(ρ_v w) = ρ_(h(v))(h|_v w)`. So the state is `s = m_1 = ρ_(h(v))^(−1) m ρ_v` on all of `Z_p`.
  - *The pole.* Conjugating by affine maps preserves `c ≠ 0`.
    - `P ∉ Z_p` because `m_1(Z_p) ⊆ Z_p`, so `P ≠ 0`. Also `P ≠ ∞`.
  - *The zoomed states.* `s|_(0^k) = ρ_(r_k)^(−1) ∘ m_1 ∘ (w ↦ p^k w)`, with `r_k = s(0^k)`.
    - Its pole is `P/p^k`, and the affine factor on the left does not move the pole.
    - The `P/p^k` are pairwise distinct. So by rigidity the states are pairwise distinct, which contradicts finiteness
      of the state set. ✓
- **Item 2: rational coefficients (the author asked about this).**
  - *The constant term.* For the affine state `s = aw + b'`, the image of `0^k` is the truncation `[b']_k`. So
    `s|_(0^k) = aw + (b' − [b']_k)/p^k`.
    - Finitely many states means finitely many shifted tails of the expansion of `b'`. So the expansion is eventually
      periodic, and `b' ∈ Q`.
  - *The slope.* `s|_1 = aw + (a + b' − [a+b']_1)/p` is again an affine state. The same argument makes `a + b'`
    rational, hence `a ∈ Q`, and `a ∈ Z_p^×` since `s` is an isometry.
  - *One `N`.* The finitely many pairs `(a, b')` give one `N`. The piece on the cylinder of `v` is
    `az + (h(v) − av + p^n b') ∈ Aff(Z[1/N])`. ✓
- **Item 3 (the author asked about this).**
  - `Γ_0 ⊆ PGL_2(Z[1/N_0])`: clear denominators in the generators and invert their determinants.
  - Item 1 applies with `Δ = PGL_2(Z[1/N])`. It contains `Aff(Z[1/N_i])` as `[[a,b],[0,1]]`.
  - *`d_q` for `q ∤ N`.* If the class of `d_q` is represented by `g ∈ GL_2(Z[1/N])`, then `g = λd_q` with
    `λ = g_22 ∈ Z[1/N]`. So `v_q(λ) ≥ 0` and `v_q(det g) = 2v_q(λ) + 1` is odd, hence not a unit.
  - *`t_(1/q)` for `q ∤ N`.* `det = λ²` forces `v_q(λ) = 0`, and then `v_q(λ/q) = −1`.
  - So `Λ` contains neither `Γ_p` nor the translations by `Z_(p)`. ✓
- **Reading, first bullet.** It is correct: if every generator were locally Möbius on a dense open set, item 3 would
  apply. So some generator's `U_h` has non-dense closure, and its complement has nonempty interior.

## R1: a required addition to the third bullet of the Reading
The bullet says that for `Λ ⊇ Γ_p` generated by elements that are locally Möbius on dense open sets, "item 1 says the
pieces of the generators generate a subgroup of `PGL_2(Q_p)` that is not finitely generated".
- Item 1 gives `d_q ∈ Δ` for every prime `q ≠ p`.
- Item 3 excluded this only for `Δ ⊆ PGL_2(Z[1/N])`, but here the pieces need not be rational. What is needed is the
  following lemma.

**Lemma.** A finitely generated `Δ ≤ PGL_2(Q_p)` contains `d_q` for only finitely many primes `q`.
- *The ring.* Let `S ⊂ Q_p` be the ring generated by the entries of representatives of the generators and the
  inverses of their determinants. Then every element of `Δ` is represented in `GL_2(S)`.
- *The primes.* `λd_q ∈ GL_2(S)` gives `λ, λq ∈ S` and `λ²q ∈ S^×`. So `λ` divides a unit, and `q ∈ S^×`.
- *Reduction to a number field.* `S ⊗ Q ≠ 0` is a finitely generated `Q`-algebra. By the Nullstellensatz it maps onto
  a number field `K`, and `S` maps into `O_K[1/M]` for some `M`, by clearing the finitely many denominators of the
  images of generators.
  - `q^(−1) ∈ O_K[1/M]` gives `M^k = qx` with `x ∈ O_K`. Taking norms, `q | M`.
- So only the primes dividing `M` can be units of `S`.

With the lemma, "not finitely generated" follows. So does "some generator has infinitely many pieces": otherwise `Δ`
would be finitely generated. Replace "involving infinitely many primes" by "whose entries generate a ring in which
infinitely many primes are invertible".

## Nits
- **N1 (item 2).** Say explicitly that states of states are states, which is how `s|_1` and `s|_(0^k)` count against
  the finite state set.
- **N2 (item 3).** `d_q` acts on `Z_p` only for `q ≠ p`. State the bound as "only for primes `q | N` (with `q ≠ p`)".

## 1. Where the arithmetic benchmark stands

The bijective-base enumeration of A_5*A_5 is dead on main:
`arithmetic-a5-near-group-is-not-finitely-presented` (R_nu acts on the 60-regular
digit tree by automorphisms, stabilizers locally virtually abelian, Z^infinity
inside, abelian rank bound) and `a5-arithmetic-shell-envelope-is-not-finitely-presented`
(via `shell-envelope-fp-forces-fp-germ-group`). The kill uses one structural fact:
**every generator, including the shift s, is an automorphism of one digit tree**,
because both factors use the same radix h and s is "swap roots, add one with
odometer carry".

The general gates for any enumeration are (G1) two-sided window, (G2) R_nu
finitely presented with ker eta finitely generated
(`mz-envelope-fp-forces-two-sided-fg-near-index-kernel`), and the one-sided shell
gate. Nothing non-virtually-cyclic is known to pass (G1)+(G2).

## 2. The least-significant-first mixed-radix enumeration of A_0*A_1

Index the nonidentity elements of A_i by 1..h_i, h_i = |A_i| - 1. A nonempty
reduced word has first type eps and digits d_1 (type eps), d_2 (type 1-eps), ...
Use the radix sequence R^eps = (h_eps, h_(1-eps), h_eps, ...) and bijective
mixed-radix value q = d_1 + R_1(d_2 + R_2(d_3 + ...)), d_j in 1..R_j. For each eps
this is a bijection from type-eps words onto q >= 1. Put nu = 2q - 1 + eps and
nu(1) = 0: a computable bijection P -> N.

Generators (x = x_c in A_0, c in 1..h_0; A_1 symmetric):
- on type-1 words (n = 2q): prepend, q' = c + h_0 q, so n' = h_0 n + (2c - 1);
- on type-0 words (n = 2q - 1), first digit d = q mod h_0 in 1..h_0:
  - if x x_d = x_(d') != 1: n' = n + 2(d' - d);
  - if x x_d = 1: tail value t = (q - d)/h_0 of type 1, n' = 2t = (n + 1 - 2d)/h_0.

So lambda_x is residue-affine mod 2h_0 with slopes h_0, 1, 1/h_0. The mixed
relation [lambda_x s^(2h_0) lambda_x^-1, s^(A)] = 1 of
`arithmetic-near-shift-actions-have-mixed-relations` applies (A = lcm of image
steps), so P*<s> -> R_nu is not injective.

## 3. The shift is a radix conversion

s(n) = n + 1 sends (type 0, q) to (type 1, q) and (type 1, q) to (type 0, q+1).
In words it re-expands the same integer q in the other radix sequence. In the
completion X = {0,1} x Z^, with Z^ = Z_(h_0 h_1) (both filtrations
M^eps_k = prod_(i<k) R^eps_i Z^ are cofinal), s(0,y) = (1,y), s(1,y) = (0,y+1),
and lambda_x acts by the affine branches above. Type-eps cones of depth k are
{eps} x (a + M^eps_k Z^).

**Lemma.** If h_0, h_1 >= 2 and h_0 != h_1, s is not a cone map: the depth-one
type-0 cone C = {0} x (c + h_0 Z^) has image {1} x (c + h_0 Z^), which is not a
type-1 cone. Proof: a type-1 cone of depth k is a coset of M^1_k Z^, with
M^1_0 = 1, M^1_1 = h_1, and M^1_k a multiple of h_1 h_0 for k >= 2. Cosets of aZ^ and bZ^
(a, b products of primes dividing h_0 h_1) coincide only if a = b. Here h_0 != h_1
and 1 < h_0 < h_1 h_0. ∎

So s is not an automorphism of the digit tree, equivalently of the Bass–Serre tree
of A_0*A_1 on which lambda(P) acts. Step 1 of `arithmetic-a5-near-group-not-fp-proof`
has no analogue. This escapes that proof only. It does not exclude another tree
action with locally virtually abelian vertex stabilizers.

## 4. The natural host

All generators are piecewise y -> alpha y + b on finitely many cosets, with alpha in
the monoid generated by h_0^(±1), h_1^(±1) and b in Z. They lie in a two-radix
analogue H of the odometer group V_(h,r)(<a>): prefix tables in two interleaved
radices with integer odometer carries. For h_0 = h_1 this is the host B of the A5
model. For h_0 != h_1 it is Stein–Thompson-like, since it has both h_0- and
h_1-splittings. Its finite presentation, and finite generation of its charge
kernel, are NOT established here. BHM Theorem 2.12 covers one radix only.

## 6. Update: the host is F_infinity; the halves are dead tree groups (bh-shell-arith, later on 2026-09-18)

**Question 1 of §5 is answered: yes.** See `two-radix-odometer-host-is-f-infinity-with-fg-charge-kernel`.
- The host `H` (coprime `h_0, h_1`) is the topological full group of the self-similar action of
  `R_2 x Z` on two copies of the one-vertex 2-graph `Lam(h_0,h_1)`. Its degree-`(i,j)` paths are
  residues mod `h_0^i h_1^j`, and the factorization rule is division with remainder.
- X. Li, arXiv:2110.04505v2, Example `ex:ZS` (III) then gives `F_infinity`, with `D*(w,w) = Z`.
- The near-index kernel is `<W, a_(c_1) a_(c_2)^-1>`, by a table-and-counting argument in which
  cone counts are invariant mod `gcd(h_0-1, h_1-1)`.
- So §4's caveat is superseded.

**Question 2 (finite index) is still OPEN.** Structure found (see
`unequal-radix-near-group-halves-are-tree-groups-that-are-not-fp`):
- `R_nu = <G_0, G_1>`, with `G_eps = <lambda(A_eps), s>` a one-radix tree group. Each `G_eps` is
  not finitely presented, by the equal-radix argument: edge-transitive, locally virtually abelian
  stabilizers, and `Z^infinity` via the pushing element `lambda_(z') s^(±1)`.
- `G_0 ∩ G_1` is virtually abelian. `R_nu` is not their amalgam, because disjoint-support
  localized odometer pairs commute.
- `R_nu` has unbounded local slope ratios, so it is not a group of automorphisms of the
  Bass--Serre tree.
- Calibration: at `(0,-1/2)` for `A_5 * A_6`, `R_nu` realizes the full germ group `<59, 359>` of `H`.

**Reading.** The equal-radix kill happens because one tree carries all the generators. With two
radices the tree structures interfere, and every invariant I tried is consistent with finite
index: bounded distortion, amalgam normal forms, and germs at fixed points.

## 1. `leavitt-stabilization-kernels-are-one-step`
- **Item 1.**
  - `j_N(St_N)` is generated by the `X_ij(a)` with `i, j ≤ N`, and both `D_(N+1)` and `j_(N+1)` fix these.
  - The induction is correct: the image of `St_N` under the `(k−1)`-fold composite is generated by the `X_ij(a)` with
    `i, j ≤ N < N+k−1`, and `j_(N+k−1)` and `D_(N+k−1)` agree there. ✓
- **Item 2.**
  - All `D_m` are injective, so the `k`-fold kernel is `ker j_N`.
  - A directed colimit of groups kills `x` iff some stage does.
  - `j_N` covers the injection `A ↦ A ⊕ 1`, so `ker j_N ⊆ K_2(N,R)`. Hence `U_N = K_2(N) ∩ ker(St_N → St) = ker j_N`. ✓
- **Item 3, the twist identity (the author asked about this).**
  - `D_N(X_iN(ae*)) = X_iN(ae*e) X_(i,N+1)(ae*f) = X_iN(a)`.
  - `D_N(X_Nj(ea)) = X_Nj(e*ea) X_(N+1,j)(f*ea) = X_Nj(a)`.
  - So `D_N Σ^(e) = j_N` on the last-row and last-column generators, and trivially on the others. ✓
- **`Σ^(g)` is a homomorphism.**
  - Each generator goes to a generator with the same index pair, so additivity and every commutation relation are
    preserved automatically.
  - The three commutator relations through index `N` are the ones listed. Only `[X_iN(ag*), X_Nk(gb)] = X_ik(ag*gb)`
    uses `g*g = 1`. ✓
  - As a check, on `E_N`, `Σ^(g)` covers the unital endomorphism `A ↦ GAG* + (1 − GG*)`. This is multiplicative because
    `G*(1−GG*) = 0 = (1−GG*)G`, and it is injective because `G*(·)G` recovers `A`. So the kernel question is purely
    one of `K_2`, as stated.
- **The unitary `W = ef* + fe*`.**
  - `W² = ee* + ff* = 1` and `We = f`.
  - `(We)* = e*W = f*`, so `Σ^(f) = Σ^(W)Σ^(e)`, with `Σ^(W)` an automorphism. So `ker Σ^(e) = ker Σ^(f)`. ✓
- **Item 4.** `U_N` is level-independent by item 2 of the refinement node. So "(i) at one `N`" is "`Σ^(s_1)` is
  injective at one `N`". ✓
- **The reading.** The untwist `X_iN(a) ↦ X_iN(ae)`, `X_Nj(a) ↦ X_Nj(e*a)` sends `X_ik(ab)` to `X_ik(aee*b)`, so it is
  indeed not a homomorphism.

## 2. `leavitt-surjective-k2-stability-implies-injective`
- **The unit `u` (the author asked about this).** Every product below is expanded by hand.
  - Write `v = fe*f* + eff*f*`. Then `v*v = f(ee* + ff*)f* = ff*` and `vv* = ff* + eff*e*`.
  - For `A = eee*`: `A*A = ee*` and `AA* = e²e*²`. All four cross terms contain a factor `e*f` or `f*e`, so they vanish.
  - So `u*u = ee* + ff* = 1`. Also `uu* = e²e*² + eff*e* + ff* = ee* + ff* = 1`, using `ee* = e(ee*+ff*)e*`.
  - `uee* = eee*`, because `v e = fe*(f*e) + eff*(f*e) = 0`. ✓
- **Item 1.**
  - For `a = aee*`: `au* = a(ee*u*) = a(ee*e*) = ae*`.
  - For `b = ee*b`: `ub = (uee*)b = eb`.
  - So `Σ^(u) = Σ^(e)` on the generators of `H_(ee*)`, hence on `H_(ee*)`. `Σ^(u)` is an automorphism with inverse
    `Σ^(u*)`, so `U_N ∩ H_(ee*) = 1`. ✓
- **The `f`-corner.**
  - `Wee*W* = (fe*)(ef* + fe*) = ff*`, and `R ee* W* = R ff*` because `W` is a unit. So `Σ^(W)(H_(ee*)) = H_(ff*)`.
  - The twist `τ` of coordinate `N` of `St_(N+1)` by `W` is an automorphism, by the same relation check. It satisfies
    `τ j_N = j_N Σ^(W)` on generators. So `U_N` is `Σ^(W)`-invariant, and `U_N ∩ H_(ff*) = 1`. ✓
  - The symmetric unit `u' = fff* + ef*e* + fee*e*` would give this directly from `ker Σ^(f) = U_N`.
- **Item 2.**
  - `D_N(K_2(N)) = K_2(N+1)`, because `D_N` is bijective and `α_N` is injective.
  - So surjectivity of `j_N = D_NΣ^(e)`, together with injectivity of `D_N`, gives `Σ^(e)(K_2(N)) = K_2(N)`.
  - `im Σ^(e) ⊆ H_(ee*)`, because `ae* = ae*(ee*)` and `eb = (ee*)eb`. So `U_N ⊆ K_2(N) ⊆ H_(ee*)`, and item 1 gives
    `U_N = 1`. ✓
- **Item 3.**
  - `S` is written with `h_12` only. Since `N ≥ 3`, every `Σ^(g)` and `D_N` fixes `S` pointwise, and `S ⊆ H_p` for
    every `p`.
  - `K_2(N) = U_N · S`, via `s = {ι[x], N+1}_N` and multiplicativity of `ι`.
  - `Σ^(e)(K_2(N)) = S`.
  - For `x ∈ K_2(N) ∩ H_(ee*)`: `x = Σ^(u*)(Σ^(e)x) ∈ Σ^(u*)(S) = S`.
  - The equivalences hold as written:
    - `K_2(N) ⊆ H_(ee*)` forces `U_N ⊆ S`, and `U_N ∩ S = 1` because `ι{λ, N+1} = λ`;
    - `U_N = 1` gives `j_N(K_2(N)) = D_N(S) = D_N(K_2(N)) = K_2(N+1)`. ✓
- **Item 4** is item 1 read contrapositively. Item 3 is not needed for it.
- **The reading.** "Infinite stable range" is correct for any `R ≅ R²`. With `sr(R) ≤ n`, Bass cancellation applied to
  `R^n ⊕ R ≅ R ≅ 0 ⊕ R` would force `R^n ≅ 0`.

## Nits
- **N1 (surjective node, item 1).** `a u* = a(uee*)*` applies `*` as an anti-involution of `R`. The setting only names
  the elements `e*` and `f*` of an arbitrary ring. Replace it with the direct line `ee*u* = ee*e*`, which follows from
  `e*e = 1` and `e*f = 0`. Likewise compute `Wee*W* = ff*` directly. Nothing else changes.
- **N2 (surjective node, item 3).** In `{λ, N+1}_N`, `N+1` is the ring element, with `N` the number operator of `R_L`,
  while the subscript `N` is the matrix size. Say so once. The collision is inherited from the computable-class node.
- **N3 (one-step node, item 3).** `Σ^(g)` is defined only for isometries. So "`Σ^(u)` is an automorphism for a unit
  `u`" should say "for a unitary `u` (`u*u = uu* = 1`)", with `(gh)* := h*g*` in the composition law. A unit that is
  not an isometry does not define `Σ^(u)` by these formulas.

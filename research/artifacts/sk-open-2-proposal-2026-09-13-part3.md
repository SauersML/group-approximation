## Setup
- The relation u f u^{-1} = f∘T^{-1} gives u e_V u^{-1} = e_V∘T^{-1} = e_{TV}, and u^{-t} e_a u^t = e_{\{x_t = a\}}. Products of these are cylinder indicators, and every locally constant F_2-valued function is a finite sum of cylinder indicators. So R is generated by u^{±1} and the e_a.
- (1) The identities e_ij(r+s) = e_ij(r)e_ij(s) and [e_ik(r), e_kj(s)] = e_ij(rs) hold for distinct i,j,k, with [g,h] = ghg^{-1}h^{-1}.
  - So {r : e_ij(r) ∈ ⟨gens⟩ for all i ≠ j} is a subring containing u^{±1}, the e_a, and 1 = Σ_a e_a. Hence it is R, and G is generated by the e_ij(s).
- (T): EJZ Theorem 1.1 covers EL_n(R) for R finitely generated associative, n ≥ 3. sk-citations owns the verbatim check.
- Infinite: e_12(LC(X,F_2)) ⊆ G is infinite because X is infinite.

## Finite models
- F1, choosing p.
  - Minimality means x is uniformly recurrent, so the word x_{[-ℓ,ℓ]} occurs in x at arbitrarily large positions p.
  - Every word of L(X) occurs in x_{[0,M)} for some M, since X has finitely many words of each length and the orbit of x is dense.
  - Take such a p > max(M, 2ℓ).
- F2. D(f) = diag(f(T^n x))_{0≤n<p} evaluates at p fixed points. So D(f+f') = D(f)+D(f') and D(ff') = D(f)D(f') for ALL f, f' ∈ LC. The map π_ℓ is F_2-linear on R.
- F3, covariance. With the indices of F_2^{Z/p} represented by 0 ≤ n < p:
  - (P^i D(f) P^{-i})_{nn} = f(T^{(n-i) mod p} x) and D(f∘T^{-i})_{nn} = f(T^{n-i} x).
  - These agree unless n−i ∉ [0,p). If n−i < 0, compare T^m x with T^{m+p} x for m = n−i ∈ [−|i|, 0). If n−i ≥ p, compare T^{m} x with T^{m+p} x for m = n−i−p ∈ [0, |i|).
  - In both cases |m| ≤ |i| ≤ ℓ−ρ. For |t| ≤ ρ we have |m+t| ≤ ℓ, so x_{m+t} = x_{p+m+t}, since x_{[p−ℓ,p+ℓ]} = x_{[−ℓ,ℓ]}. So T^m x and T^{m+p} x agree on [−ρ,ρ], and f takes the same value at both.
- F4, multiplicativity on a fixed pair.
  - For r = Σ f_i u^i and r' = Σ f'_j u^j: rr' = Σ_{i,j} f_i (f'_j∘T^{-i}) u^{i+j}.
  - So π_ℓ(rr') = Σ_{i,j} D(f_i) D(f'_j∘T^{-i}) P^{i+j}, using F2 and linearity, grouped by the integer i+j.
  - π_ℓ(r)π_ℓ(r') = Σ D(f_i) P^i D(f'_j) P^j. The two agree once ρ(f'_j) + |i| ≤ ℓ for all i, j, which is true for all large ℓ.
- F5, nonvanishing.
  - If r ≠ 0, some f_j is 1 at a point z ∈ X. Let ρ be a window of f_j. For ℓ ≥ ρ the word z_{[−ρ,ρ]} occurs inside x_{[0,p)} at some center n, so f_j(T^n x) = 1 and D(f_j) ≠ 0.
  - For p > 2ℓ ≥ 2 max|j|, the matrices P^j have pairwise disjoint supports, so π_ℓ(r) ≠ 0.
- F6, the partial homomorphism. Take F ⊆ G finite, closed under inverses, with I_3 ∈ F.
  - For g, h ∈ F with gh ∈ F: π(g)π(h)_{ij} = Σ_l π_ℓ(g_il)π_ℓ(h_lj) = π_ℓ(Σ_l g_il h_lj), by F4 on the finitely many pairs and by linearity.
  - Injectivity: π(g) = π(h) forces π_ℓ(g_ij − h_ij) = 0, so g = h by F5 on the finitely many differences.
  - Invertibility: π(g)π(g^{-1}) = π(I_3) = I_{3p}, since π_ℓ(1) = D(1) = I_p.
  - So F maps injectively into GL_{3p}(F_2), preserving the products that stay in F.
- F7. LEF implies sofic (regular permutation action of the finite group) and hyperlinear (permutation matrices) [Pestov]. The current note says the same at l.150-152.
- Comparison: the note's periodic word y = w^∞ (l.123-129) is replaced by orbit points T^n x. The return condition is the seam, and D is multiplicative for all functions, so no window bookkeeping is needed for D. This is the Grigorchuk–Medynets mechanism, unchanged.

## Simplicity
- S1, the partition.
  - Each point has a clopen neighborhood U with U ∩ T^jU = ∅ for 0 < |j| ≤ 2w, because T has no periodic points (X infinite and minimal).
  - Finitely many such U cover X. The atoms of the Boolean algebra they generate, refined by the level sets of the finitely many locally constant functions f∘T^i (f a coefficient of an entry of g^{±1}, |i| ≤ w), form 𝒫.
  - Atoms inherit the disjointness property.
- S2, the noncommuting h. Suppose g commutes with every e_ij(e_V), V ∈ 𝒫, i ≠ j.
  - By (1), e_ij(1) = Π_V e_ij(e_V), so g commutes with every I_3 + E_ij, and g = cI_3.
  - c is an entry of g, so c = Σ_{|j|≤w} f_j u^j.
  - Coefficients of u^j in c e_V = e_V c: Σ f_j e_{T^jV} u^j = Σ e_V f_j u^j, so f_j e_{T^jV} = f_j e_V.
  - Multiplying by e_V: f_j e_V = f_j e_{T^jV ∩ V} = 0 for 0 < |j| ≤ w (⊆ 2w). Summing over V gives f_j = 0, so c = f_0 ∈ LC.
  - Write c^{-1} = Σ h_j u^j. The constant coefficient of c c^{-1} = 1 is f_0 h_0 = 1, so f_0 is a unit of LC(X,F_2), i.e. f_0 ≡ 1. So g = I_3, a contradiction.
- S3, matrix units. For |a|,|b|,|c|,|d| ≤ w:
  - E_ab E_cd = e_{T^aV} u^{a−b} e_{T^cV} u^{c−d} = e_{T^aV ∩ T^{a−b+c}V} u^{a−b+c−d}.
  - T^aV ∩ T^{a−b+c}V = T^a(V ∩ T^{c−b}V), which is empty for 0 < |c−b| ≤ 2w and equals T^aV for b = c.
  - So A = span{E_ab} ≅ M_{2w+1}(F_2), with unit e = Σ_a E_aa.
- S4, absorption with constant coefficients.
  - f u^i e_V f' u^{i'} = f e_{T^iV} u^i f' u^{i'} = f e_{T^iV} (f'∘T^{−i}) u^{i+i'}.
  - On T^iV, f takes the value of f∘T^i on V (constant), and f'∘T^{−i} takes the value of f' on V (constant, i = 0).
  - So the product is c·e_{T^iV}u^{i+i'} = c·E_{i,−i'} with c ∈ F_2 and |i|, |i'| ≤ w.
  - The (k,l) entry of g e_V E_ij g^{-1} is g_{ki} e_V (g^{-1})_{jl}, a finite sum of such products, so it lies in A.
- S5, k ∈ H.
  - h = I_3 + e_V E_ij = h^{-1}, since (e_V E_ij)^2 = 0.
  - k = g h g^{-1} h = (I_3 + X) h with X = g e_V E_ij g^{-1}, and k^{-1} = h g h g^{-1} = h(I_3 + X).
  - So k − I_3 and k^{-1} − I_3 lie in M_3(A). With x = eI_3 + (k − I_3) and x' = eI_3 + (k^{-1} − I_3), both in M_3(A):
    - k = (1−e)I_3 + x, since (1−e)a = a(1−e) = 0 for a ∈ A;
    - k k^{-1} = I_3 gives x x' = eI_3.
  - So k ∈ H = (1−e)I_3 + GL_3(A) ≅ GL_3(M_{2w+1}(F_2)) = GL_d(F_2), d = 3(2w+1).
- S6, H ⊆ G.
  - For μ ≠ ν, the elementary transvection t_{(μ,a),(ν,b)} of H is I_3 + E_ab E_μν = e_μν(E_ab) ∈ G.
  - For a ≠ b and any ν ≠ μ, c: [t_{(μ,a),(ν,c)}, t_{(ν,c),(μ,b)}] = t_{(μ,a),(μ,b)}, the standard identity [I+E_xz, I+E_zy] = I+E_xy for distinct x, y, z.
  - The transvections generate SL_d(F_2) = GL_d(F_2).
- S7.
  - GL_d(F_2) = SL_d(F_2) = PSL_d(F_2) is simple for d ≥ 3 (Jordan–Dickson), and d = 3(2w+1) ≥ 3.
  - N ∩ H is normal in H and contains k ≠ 1, so H ⊆ N. In particular e_ij(e_V) = t_{(i,0),(j,0)} ∈ N.
- S8, the level ideal. For r ∈ I_N, s ∈ R and distinct i, j, k:
  - e_ij(sr) = [e_ik(s), e_kj(r)] ∈ N and e_ij(rs) = [e_ik(r), e_kj(s)] ∈ N, since N is normal and e_kj(r), e_ik(r) ∈ N.
  - Additivity comes from (1). So I_N is a two-sided ideal containing e_{T^nV} = u^n e_V u^{−n}.
  - By minimality ∪_n T^nV = X, so by compactness finitely many T^{n_i}V cover X, and 1 − Π_i(1 − e_{T^{n_i}V}) = 1 lies in I_N.
  - So every e_ij(r) ∈ N, and N = G.

## Model tests (each hypothesis must bind)
- X finite (a periodic orbit): T has periodic points, so S1 fails, and G is finite, as the theorem requires.
- X infinite but not minimal, without periodic points (e.g. the disjoint union of two Sturmian subshifts of different slopes): S1 still holds, but S8 (covering) fails. The ideal I generated by the indicator of one component is proper and nonzero, so EL_3(R,I) is a proper nontrivial normal subgroup.
- F_q with q > 2: S2 fails (f_0 can be a nonconstant unit), and scalar matrices cI_3, c ∈ F_q^× with c^3 = 1, are central. This matches the need for /Z in the F_q version on main.
- w = 0: A = F_2 e_V, H = GL_3(F_2), no same-block transvections, and the disjointness condition is vacuous. The argument still runs.
- Fibonacci subshift: infinite, minimal, alphabet {0,1}. Every step applies.

**Question.** Does the Higson--Lafforgue--Skandalis ghost class on the expander-marking subshift lift along the
restriction `I_1 ⋊_r G -> C_0(Ŷ \ {0}) ⋊_r G`?

**Answer, as a reduction.** Assume K_0 of the max-to-reduced map is injective at the tree boundary (hypothesis (H-K),
the hypothesis of HLS Lemma 1(2)).
- A class over the full shift whose tree-boundary restriction vanishes, but whose ranks at the marked expanders do not
  vanish eventually, is a witness against surjectivity of `T_r`.
- It also forces failure of the forest-shift comparison. So if Baum--Connes surjectivity holds at the forest coefficient
  `C_0(T \ {0})`, the HLS class never lifts.
- The expanders drop out of the obstruction: what remains is a question about configurations whose support induces a
  forest.

## 0. HLS, read verbatim

## 1. The HLS projection as a Bernoulli coefficient

**Hypotheses (M).**
- `G` is torsion-free, generated by a finite symmetric set `S`.
- `(X_n)` are finite connected `D`-regular graphs with `D >= 3`, lowest nonzero Laplacian eigenvalue at least `ε > 0`,
  girth tending to infinity, and strictly increasing sizes.
- `A_n ⊆ G` are images of `X_n` under maps that are isometric for the word metric, with `d(A_n, A_m) -> ∞`.
- Osajda arXiv:1406.5015 §1.3 gives isometric embeddings (`osajda-monster-hosts-for-bc-module-route`, item (2)).
  Torsion-freeness is assumed, not checked.
- Isometry makes the subgraph of `Cay(G, S)` induced on `A_n` equal to `X_n`.

Let `X = Λ^G` with `Λ = {0, ..., n}`, and `x_n = 1_(A_n)` (symbol `1`). Put `Ŷ = closure(∪_n G·x_n)` and
`∂Y = Ŷ \ ∪_n G·x_n`.

**Lemma 1.1 (shape of Ŷ).**
1. Each `x_n` is isolated in `Ŷ` and has trivial stabilizer. So `U = ∪_n G·x_n` is open in `Ŷ` and `C_0(U) ≅ c_0(N × G)`
   equivariantly.
2. `∂Y \ {0}` consists of limits `g_i·x_(n_i)` with `n_i -> ∞`. Their supports induce `D`-regular trees.
3. `f ↦ (g ↦ f(g^(-1)·x_n))_n` embeds `C_0(Ŷ \ {0})` equivariantly into HLS's `A = ℓ^∞(N; c_0(G))`, containing
   `c_0(N × G)`.

*Proof.*
1. Take `y ∈ Ŷ` agreeing with `x_n` on the 1-neighbourhood of `A_n`.
   - If `y = g·x_m`, then `A_n` is a union of components of the connected induced graph `gA_m ≅ X_m`. So `gA_m = A_n`,
     hence `m = n`, and `g = e` because a torsion-free group fixes no finite nonempty set.
   - A boundary point would contain the cycles of `X_n`, which contradicts item 2.
2. A pointed limit with bounded `n_i` is a translate of some `x_m`. A limit with `n_i -> ∞` sees, on each ball, one ball
   of some `X_(n_i)`, of radius below half the girth, hence a tree.
3. Translates of a finite configuration tend to `0`. Injectivity holds because `U` is dense in `Ŷ`. QED.

**Lemma 1.2 (the ghost projection).** At a configuration `x`, define on `l^2(G)`

`(D_x ξ)(h) = [x_h ≠ 0] Σ_(s ∈ S) [x_(hs) ≠ 0] (ξ(h) - ξ(hs)) + [x_h = 0] ξ(h)`.

This is a self-adjoint configuration-local element of `C(Ŷ) ⋊_alg G`. Put `γ = min(ε, 1, D - 2√(D-1)) > 0`.
1. `spec D_x ⊆ {0} ∪ [γ, ∞)` for every `x ∈ Ŷ`.
2. `p = χ_({0})(D)` lies in `C_0(Ŷ \ {0}) ⋊_r G`.
3. `r_(x_n)[p] = 1` for every `n`.
4. `q_∂(p) = 0`, where `q_∂ : C_0(Ŷ \ {0}) ⋊_r G -> C_0(∂Y \ {0}) ⋊_r G`.

This is HLS §7's `p` for injective `ϕ_n`.

*Proof.*
1. On the support, `D_x` is the Laplacian of the induced graph; on the complement it is the identity.
   - At translates of `x_n` that graph is `X_n`, with spectrum `{0} ∪ [ε, 2D]`.
   - At boundary trees it is the `D`-regular tree Laplacian, with spectrum in `[D - 2√(D-1), D + 2√(D-1)]`.
   - The spectrum of `D` in the algebra is the closure of the union over the faithful family `π_x`, `x ∈ Ŷ`.
2. Take `φ` continuous with `φ(0) = 1` and `φ = 0` on `[γ, ∞)`, so `p = φ(D)`.
   - Evaluation at the fixed point `0` sends `D` to `1`, hence `p` to `0`.
   - Its kernel is `C_0(Ŷ \ {0}) ⋊_r G`, since the unit splits `0 -> C_0(Ŷ \ {0}) -> C(Ŷ) -> C -> 0` equivariantly.
3. `π_(x_n)(p)` projects onto the constants on `A_n`.
4. At every boundary tree `D_y` is injective with a gap, so `π_y(p) = 0`. Boundary points form a faithful family for the
   quotient. QED.

HLS's weak embeddings may have unbounded fibres, and fibre weights are not finite-alphabet configurations. So (M) uses
isometric embeddings.

## 2. Theorem G

**Definitions.**
- The **forest shift** `T = {x ∈ X : the subgraph of Cay(G, S) induced on supp x is a forest}`. It is closed, since
  containing a cycle is witnessed by finitely many sites. It is invariant and closed under restriction.
- `∂Y ⊆ T`, and `x_n ∉ T`.
- `S_T` is the set of forest patterns, and `T_r^T : ⊕_([s] ∈ G\S_T) Z -> K_0(C_0(T \ {0}) ⋊_r G)`, `[s] ↦ [1_(C_s ∩ T)]`.
- For finitely supported `m` on patterns, set `L_m(B) = Σ_(t <= B) m_([t])` and
  `b_m = Σ_s m_s [1_(C_s ∩ ∂Y)] ∈ K_0(C_0(∂Y \ {0}) ⋊_r G)`.

**(H-K)** `K_0(C_0(∂Y \ {0}) ⋊_max G) -> K_0(C_0(∂Y \ {0}) ⋊_r G)` is injective.

**Lemma 2.1 (the forest comparison is Baum--Connes at the forest coefficient).** `T_r^T` is injective, and it is
surjective iff `μ_(G, C_0(T \ {0}))` is surjective in degree 0.

*Proof.*
- **Injectivity.** Use ranks at finite forests (RF R3).
- **K-theory basis.** `K_0(C_0(T \ {0})) = C_c(T \ {0}, Z)` has the forest cylinder indicators as a basis, and `K_1 = 0`.
  - They span, because compact open sets are Boolean combinations of `{x|_F = a}`.
  - They are independent: evaluate at finite forests, use the Möbius triangularity of RF R5, and note that finite
    forests are dense.
- **A weak K-equivalence.** Compose the element `T ∈ KK^G(c_0(S), I_1)` of CC item 2 (sending `δ_s ↦ 1_(C_s)`, CC item 4)
  with restriction to `T`, and restrict it to the summand `c_0(S_T)`. Since `G` is torsion-free, only the trivial
  subgroup is tested, so this is a weak K-equivalence.
- **Going-down.** Bönicke--Dell'Aiera Theorem 4.6 (`bernoulli-shift-weak-k-equivalence-and-going-down`) gives
  `K^top(G; C_0(T \ {0})) ≅ ⊕_([s] ∈ G\S_T) Z`.
- **Naturality.** Assembly identifies `μ_(G, C_0(T \ {0}))` with `T_r^T`, as in CC item 3. QED.

**Lemma 2.2 (block ranks are forest counts).** Let `m(y)` be the restriction of `n(y)` to forest patterns.
- For every finite forest `B`, `r_B(y) = L_(m(y))(B)`.
- For `n` with `girth X_n > |B(e, d_0(y))|`, `r_(x_n)(y) = L_(m(y))(A_n)`.

*Proof.* By LOC Corollary 2, `n(y)` lives on patterns of diameter below `d_0(y)`. Such a sub-pattern of `x_n` has fewer
vertices than the girth, so it induces a forest. For a forest `B`, every sub-pattern is a forest. QED.

**Key step (★).** Assume (H-K). If `m` is finitely supported and `b_m = 0`, then `L_m(A_n) = 0` for all large `n`.
- `w_max = Σ m_s [1_(C_s ∩ Ŷ)] ∈ K_0(C_0(Ŷ \ {0}) ⋊_max G)` maps to `w` in the reduced algebra. Also
  `λ_∂ (q_∂^max (w_max)) = q_∂^r (w) = b_m = 0`.
- By (H-K), `q_∂^max (w_max) = 0`.
- The maximal sequence `0 -> c_0(N×G) ⋊_max G -> C_0(Ŷ \ {0}) ⋊_max G -> C_0(∂Y \ {0}) ⋊_max G -> 0` is exact, and K_0 is
  half-exact. So `w_max` comes from `K_0(c_0(N, K(l^2 G))) = ⊕_n Z`.
- `r_(x_n)` is the `n`-th coordinate there, so `r_(x_n)(w) = 0` for large `n`.
- By RF R2, `r_(x_n)(w) = L_m(A_n)`. Non-forest patterns contribute nothing to `b_m`, nor to `L_m(A_n)` once `n` is large.
  QED.

**Theorem G.** Assume (M) and (H-K). Let `y ∈ K_0(I_1 ⋊_r G)` satisfy `y|_(∂Y) = 0`, with `r_(x_n)(y) ≠ 0` for infinitely
many `n`. Then:
- **(a)** `y ∉ im T_r`. So `T_r` fails to be surjective, and for `Λ = Z/p` reduced assembly for `F_p wr_G G` fails to be
  surjective (`bc-counterexample-via-bernoulli-cylinder-defect`).
- **(b)** `y - T_r(n(y))` is a nonzero rank-invisible class (shape (b)).
- **(c)** `y|_T ∉ im T_r^T`. So `μ_(G, C_0(T \ {0}))` fails to be surjective.

*Proof.*
- **(c)** Suppose `y|_T = T_r^T(m')`.
  - Ranks at finite forests and Lemma 2.2 give `m' = m(y)`.
  - Then `0 = y|_(∂Y) = b_(m(y))`, and (★) gives `L_(m(y))(A_n) = 0` for large `n`.
  - Lemma 2.2 then gives `r_(x_n)(y) = 0` for large `n`, a contradiction.
- **(a)** `T_r(m)|_T = T_r^T(m|_(S_T))`, since non-forest cylinders miss `T`. Now apply (c).
- **(b)** `n(y)` is finitely supported (LOC), so `y - T_r(n(y))` has all ranks `0`. It is nonzero by (a). QED.

**Corollary G′ (the HLS class).** Assume (M) and (H-K).
1. `[p]` is not a combination of cylinder classes on `Ŷ`. If it were, then `b_m = q_∂[p] = 0`, and (★) would give
   `1 = r_(x_n)[p] = L_m(A_n) = 0`.
2. A lift `y` of `[p]` satisfies (a)--(c). In particular it is a Baum--Connes counterexample for `F_p wr G`.
3. **No lift.** If `μ_(G, C_0(T \ {0}))` is surjective, `[p]` has no lift, and its boundary class in `K_1` of the kernel of
   the restriction is nonzero.

## 3. The doors

- **Ghost route.** Given (H-K), the expander route to a Bernoulli witness has become a forest-shift problem. A class
  carrying ghost ranks on the `x_n` restricts to a forest class outside `im T_r^T`. After its cylinder expansion is
  subtracted it is rank-invisible, and its restriction to the tree boundary is `-b_(m(y)) ≠ 0`. No configuration in `T`
  contains an expander.
- **Haar trace (independent).** `Cay(G, S)` has a cycle, so a Bernoulli configuration almost surely contains an induced
  cycle, and `μ(T) = μ(Ŷ) = 0`.
  - The trace is blind to this route.
  - A projection over `C*_r(F_p wr G)` with trace outside `Z[1/p]` stays a separate door (CC item 7).
- **K_1 (independent).** The lifting obstruction `∂[p]` lives in `K_1` of the kernel of the restriction. Nothing forces a
  class in `K_1(I_1 ⋊_r G)`.

## 4. Open inputs

- **(H-K)** (`expander-tree-boundary-k0-max-reduced-injective`).
  - Expected route: the boundary supports are isometrically embedded trees, so the transformation groupoid
    `(∂Y \ {0}) ⋊ G` should be a-T-menable, hence K-amenable (Tu).
  - Not proved: it needs a continuous proper conditionally negative definite function across all boundary points.
- **(F)** `μ_(G, C_0(T \ {0}))` surjective (`forest-shift-bernoulli-comparison-is-surjective`).

  - What is left are rank-invisible forest classes and `K_1`.
  - With (H-K), (F) decides the question: the HLS class never lifts.

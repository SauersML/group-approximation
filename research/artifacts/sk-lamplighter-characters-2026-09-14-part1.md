# Character rigidity of the lamplighter hosts (sk-lamplighter-characters, 2026-09-14), part 1

A written proof, UNREVIEWED. It adapts the reviewed Z-case proof (`research/artifacts/sk-characters-rigidity-b-proof-2026-09-13-part{1,2}.md`, passed by sk-characters-rigidity-a and sk-verify-8). The tower unit groups `L_y` are replaced by UHF unit groups, which need no free Z-action, no recurrence and no amenability.

## 0. Setting and statement
- `Δ` is an infinite countable group. `Ω = F_2^Δ` with `(δx)(h) = x(δ^{-1}h)`. `K = ⊕_Δ F_2` is the finitely supported configurations. `Λ = K ⋊ Δ = F_2 ≀ Δ` acts on Ω by `ξ = (δ,f): x ↦ δx + f`.
- `R = LC(Ω,F_2) ⋊ Λ`, with `u_ξ e_U u_ξ^{-1} = e_{ξU}`, and every element uniquely `Σ_ξ f_ξ u_ξ`. `G = EL_n(R)`, `n ≥ 3`; we write `n = 3`.
- `μ` is the Bernoulli (uniform product) measure on Ω. It is Λ-invariant: translations by `f` and coordinate shifts both preserve it.
- A *character* is a normalized positive definite class function, with GNS `(π, H, ξ)`, `M = π(G)''` and faithful normal trace `τ`.

**Theorem L.** Every character of `G` is `c·1 + (1−c)δ_e` with `c ∈ [0,1]`.

It uses neither finite generation nor amenability of `Δ`, nor property (T). The only import is Larsen–Tiep Theorem A (arXiv:2403.09046v1), as in the Z-case Lemma 3.

## 1. The UHF subalgebra and its unit group

**Stages.** For finite `W ⊆ Δ` let `A_W = span_{F_2}{E^W_{v,v'} := e_{[v]} u_{v−v'} : v,v' ∈ F_2^W}`. Here `[v] = {x : x|_W = v}`, and `u_{κ}` is the lamp translation by `κ ∈ F_2^W ⊆ K`.
- Since `u_κ e_{[w]} = e_{[w+κ]} u_κ`, we get `E^W_{v,v'}E^W_{w,w'} = δ_{v',w}E^W_{v,w'}` and `Σ_v E^W_{v,v} = 1`. So `A_W ≅ M_{2^{|W|}}(F_2)`, unital.
- For `W ⊆ W'`, `E^W_{v,v'} = Σ_{t ∈ F_2^{W'∖W}} E^{W'}_{(v,t),(v',t)}`. The inclusion is `x ↦ x ⊗ I_{2^{|W'∖W|}}`.
- Put `R_K = ⋃_W A_W`. It contains `LC(Ω,F_2)` and every `u_κ`, `κ ∈ K`, and it equals `LC(Ω,F_2) ⋊ K`.

**Lemma L1 (unit groups).** Let `W_1 ⊆ W_2 ⊆ …` exhaust `Δ`, put `L_m = GL_3(A_{W_m}) ≅ GL_{N_m}(F_2)` with `N_m = 3·2^{|W_m|}`, and let `L = ⋃ L_m`.
- (i) `L ⊆ G`.
- (ii) For `h ∈ L_m ∖ {1}` and `n ≥ m`, `supp_{L_n}(h) ≥ N_n/N_m`.

The same holds for `wLw^{-1} = GL_3(w R_K w^{-1})` for any unit `w ∈ R`, and for `dLd^{-1}` for any `d ∈ GL_3(R)` normalizing `G`.

*Proof.*
- (i) `GL_{N}(F_2) = SL_N(F_2)` is generated by transvections. A transvection between the coordinates `(p,v)` and `(q,v')`:
  - with `p ≠ q` is `e_pq(E_{v,v'}) ∈ G`;
  - with `p = q` is a commutator through `p' ≠ p`.
- (ii) In `L_n`, `h` becomes `h ⊗ I_s` with `s = N_n/N_m`. Eigenspaces multiply by `s`, so `supp(h⊗I_s) = s·supp(h) ≥ s`.
- For `wLw^{-1}` the stages `GL_3(wA_Ww^{-1})` are generated by the transvections `e_pq(wE_{v,v'}w^{-1})` and their commutators, so they lie in `G`, and (ii) is intrinsic to the finite groups.
- For `dLd^{-1}`: `d` normalizes `G`, and conjugation is an isomorphism of the stages. ∎

**Lemma L2 (constancy on single-block limits).** Let `Q = ⋃_m Q_m ⊆ G` with `Q_m ≅ GL_{N_m}(F_2)`, `N_m → ∞`, such that every `h ∈ Q_m ∖ {1}` satisfies `supp_{Q_n}(h) ≥ α_h N_n` for all `n ≥ m`, with `α_h > 0`. Then for every character `χ` of `G` there is `c_Q` with `χ(h) = c_Q` for all `h ∈ Q ∖ {1}`, and `c_Q = τ(p_Q) = lim τ(p_{Q_m})`.

*Proof* (the Z-case Lemma 4, with one simple factor per stage).
- `χ|_{Q_n} = Σ_ρ c^{(n)}_ρ χ_ρ/ρ(1)` with trivial weight `c^{(n)}_triv = τ(p_{Q_n})`, which decreases to `τ(p_Q)`.
- For `h ∈ Q_m ∖ {1}`, `n ≥ m` and nontrivial `ρ ∈ Irr(GL_{N_n}(F_2))`, the Z-case Lemma 3 (Larsen–Tiep plus class size plus degree) gives `|χ_ρ(h)|/ρ(1) ≤ ⌊N_n²/4⌋^{−cα_h/2}` once `N_n ≥ max(3, 2/√α_h)`.
- So `|χ(h) − c^{(n)}_triv| → 0`, and `χ(h) = τ(p_Q)`. ∎

By L1(ii), L2 applies to `L`, to `dLd^{-1}`, and to `wLw^{-1}` (with `α_h = 1/N_m`).

## 2. Generation and the central projection

**Lemma L3.** Let `S_Δ` generate `Δ` and `d_δ = diag(u_δ,1,1)`. Then `d_δ` normalizes `G`, and
`G = ⟨ L, d_δ^{±1} L d_δ^{∓1} : δ ∈ S_Δ ⟩`.

*Proof.*
- **Normalizing.** Conjugation by `d = d_δ` sends:
  - `e_12(r) ↦ e_12(u_δ r)`, `e_13(r) ↦ e_13(u_δ r)`;
  - `e_21(r) ↦ e_21(r u_δ^{-1})`, `e_31(r) ↦ e_31(r u_δ^{-1})`;
  - and fixes `e_23(r)`, `e_32(r)`.
- **Generation.** Let `Q` be the subgroup on the right. The set of `r` with `e_ij(r) ∈ Q` for all `i ≠ j` is a subring, by `e_ij(r+s) = e_ij(r)e_ij(s)` and `[e_il(r),e_lj(s)] = e_ij(rs)`. It contains `R_K`, since `e_ij(R_K) ⊆ L`.
  - `d e_12(1)d^{-1} = e_12(u_δ)` and `d e_13(1) d^{-1} = e_13(u_δ)`; `d^{-1}e_21(1)d = e_21(u_δ)` and `d^{-1}e_31(1)d = e_31(u_δ)`. With `d^{±1}` exchanged, we get `u_δ^{-1}` in the same positions.
  - `e_23(u_δ^{±1}) = [e_21(u_δ^{±1}), e_13(1)]` and `e_32(u_δ^{±1}) = [e_31(u_δ^{±1}), e_12(1)]`.
  - Since `u_{(δ,f)} = u_f u_δ`, `R` is generated as a ring by `R_K` and the `u_δ^{±1}`, `δ ∈ S_Δ`. So `Q ⊇ EL_3(R) = G`. ∎

**Lemma L4 (central trivial part).** Let `χ` be a character, `c = c_L`, and `A' = e_23(LC(Ω,F_2))`. Then `p_{A'}` is central, `τ(p_{A'}) = c`, and `χ = c + (1−c)χ_2`, where `χ_2 = τ((1−p_{A'})π(·))/(1−c)` (for `c < 1`) is a character vanishing on `L ∖ 1` and on every `dLd^{-1} ∖ 1`.

*Proof.*
- `A' = ⋃ A'_m` with finite `A'_m = e_23(span{e_{[v]} : v ∈ F_2^{W_m}}) ⊆ L_m`, and `|A'_m| → ∞`.
- By L2, `χ = c_L` on `A' ∖ 1`, so `τ(p_{A'}) = lim (1+(|A'_m|−1)c_L)/|A'_m| = c_L`.
- `d_δ` fixes `A'` elementwise, so `A' ⊆ d L d^{-1}` too, and the same computation gives `c_{dLd^{-1}} = τ(p_{A'}) = c_L`.
- `p_L ≤ p_{A'}` with equal traces, and `τ` is faithful, so `p_L = p_{A'}`. Likewise `p_{dLd^{-1}} = p_{A'}`.
- So `π(x)p_{A'} = p_{A'}` for `x` in each generating subgroup of Lemma L3, hence for all `x ∈ G`. Adjoints give `p_{A'}π(x) = p_{A'}`, so `p_{A'}` is central.
- The decomposition is the Z-case §6 verbatim. `χ_2 = 0` on `L∖1` and on `dLd^{-1}∖1`, because `χ = c` there. ∎

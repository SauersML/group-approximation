**Conventions (Lodha l.127 and l.236--415).** Actions are on the right; `gh` means first
`g`, then `h`.
- `2^N` is the space of infinite binary sequences; `2^{<N}` the finite words; `|u|` the
  length; `[u] = {uξ}` the cone of `u`. Words `σ, τ` are *independent* when neither is a
  prefix of the other, i.e. `[σ] ∩ [τ] = ∅`. Sequences are ordered lexicographically.
- A *tree* is a finite set `L ⊆ 2^{<N}` such that every `ξ ∈ 2^N` has exactly one prefix
  in `L` (Lodha l.244--249). Equivalently, `{[s] : s ∈ L}` is a partition of `2^N` into
  finitely many cones. List it as `s_1 < ... < s_n`.
- `x`, `y` are Lodha's primitive maps (l.347--362):
  `x: 00η ↦ 0η, 01η ↦ 10η, 1η ↦ 11η`, and
  `y: 00η ↦ 0(η·y), 01η ↦ 10(η·y^{-1}), 1η ↦ 11(η·y)`.
  Solving, `y^{-1}: 0η ↦ 00(η·y^{-1}), 10η ↦ 01(η·y), 11η ↦ 1(η·y^{-1})`.
- For `u ∈ 2^{<N}`, `x_u` and `y_u` act as `x`, `y` on the tail after `u`, and trivially
  off `[u]` (l.364--385). The map `λ_u(g): uξ ↦ u(ξ·g)`, identity off `[u]`, is an injective
  homomorphism `Homeo(2^N) → Homeo(2^N)` with `λ_u(x_v) = x_{uv}`, `λ_u(y_v) = y_{uv}`.
- `p_0` swaps the first digit; for `n ≥ 1`, `p_n` sends `1^k0η ↦ 1^{k+1}0η` (`k < n`),
  `1^n0η ↦ 1^{n+1}η`, `1^{n+1}η ↦ 0η` (l.275--289).
- For independent `σ, τ`, put `w_{σ,τ} = y_σ y_τ^{-1}` (Lodha l.625). The factors have
  disjoint supports, so they commute, and `w_{σ,τ}^{-1} = w_{τ,σ}`.
- `S_C = ⟨x, x_1, p_0, w_{10,110}⟩ ≤ Homeo(2^N)`.

## 1. Rational sequences and `Φ`

A sequence is *rational* when it is tail equivalent to `0^∞` or `1^∞` (Lodha l.241). Write
`Rat` for the set of rational sequences. Every `ξ ∈ Rat` is `wc^∞` with `c ∈ {0,1}`.

**On `Rat`, `Φ` is a finite computation.** Put `M_1(t) = 1 + t` and `M_0(t) = t/(1+t)` on
`[0,∞]`, with `M_1(∞) = ∞` and `M_0(∞) = 1`. Lodha's recursion (l.327--344) is
`φ(dξ) = M_d(φ(ξ))`, `Φ(1ξ) = φ(ξ)`, `Φ(0ξ) = −φ(~ξ)`, where `~` swaps the digits and
`−∞ = ∞`. The only fixed point of `M_0` in `[0,∞]` is `0`, and the only fixed point of
`M_1` is `∞`. So `φ(0^∞) = 0`, `φ(1^∞) = ∞`, and
`φ(d_1 ⋯ d_k c^∞) = M_{d_1}(⋯ M_{d_k}(φ(c^∞)))`. This value does not depend on how `ξ` is
written, because `M_c(φ(c^∞)) = φ(c^∞)`. It is what the experiment computes.

**Lemma 1.1.**
1. `Φ(Rat) = QP^1`.
2. For `ξ ∈ Rat`, `Φ(ξ) = ∞` if and only if `ξ ∈ {0^∞, 1^∞}`.
3. `Rat ∖ {0^∞, 1^∞}` is the union over `s ∈ 2^{<N}` of the pairs `p_s = {s01^∞, s10^∞}`,
   and `Φ` is constant on each `p_s`.

*Proof.*
1. `M_0` and `M_1` have integer matrices `[[1,0],[1,1]]` and `[[1,1],[0,1]]`, so
   `φ(Rat) ⊆ Q_{≥0} ∪ {∞}` and `Φ(Rat) ⊆ QP^1`. Conversely, let `q = p/r` with `p ≥ 0`,
   `r ≥ 1` coprime; induct on `p + r`. If `p = 0`, `q = φ(0^∞)`. If `p ≥ r`, then
   `q − 1 = (p−r)/r` has smaller `p + r`, so `q − 1 = φ(ξ)` and `q = φ(1ξ)`. If
   `0 < p < r`, then `t = p/(r−p)` has smaller `p + r` and `M_0(t) = q`, so `q = φ(0ξ)`
   with `t = φ(ξ)`. Also `∞ = φ(1^∞)`. So `φ(Rat) = Q_{≥0} ∪ {∞}`. Since `Φ(1ξ) = φ(ξ)`,
   `Φ(0ξ) = −φ(~ξ)` and `~` preserves `Rat`, `Φ(Rat) = QP^1`.
2. `M_0` never takes the value `∞` on `[0,∞]`, and `M_1(t) = ∞` only for `t = ∞`. So
   `φ(ξ) = ∞` iff every digit of `ξ` is `1`, i.e. `ξ = 1^∞`. Similarly `M_1(t) ≥ 1` and
   `M_0(t) = 0` only for `t = 0`, so `φ(ξ) = 0` iff `ξ = 0^∞`. Hence `Φ(1ξ) = ∞` iff
   `ξ = 1^∞`, and `Φ(0ξ) = −φ(~ξ) = ∞` iff `~ξ = 1^∞`, i.e. `ξ = 0^∞`.
3. Write `ξ ∈ Rat ∖ {0^∞,1^∞}` as `w c^∞` with `w` not ending in `c`. Then `w` is
   nonempty, so `ξ = s d c^∞` with `d ≠ c`, i.e. `ξ ∈ p_s`. For constancy:
   `φ(01^∞) = M_0(∞) = 1 = M_1(0) = φ(10^∞)`, hence `φ(s01^∞) = φ(s10^∞)` for every `s`.
   If `s = 1s'`, `Φ(p_s) = φ(p_{s'})`, one value. If `s = 0s'`, `Φ` is `−φ` of
   `{~s'10^∞, ~s'01^∞} = p_{~s'}`, one value. If `s` is empty,
   `Φ(01^∞) = −φ(0^∞) = 0 = φ(0^∞) = Φ(10^∞)`. ∎

**Lemma 1.2 (`Rat` is invariant).** `x_u`, `p_n` and `y_u^{±1}` map `Rat` onto `Rat`.

*Proof.* Prefix replacements change only a finite prefix. For `y^{±1}`, the defining rules
consume one or two input digits and emit a finite word, then continue with `y` or `y^{-1}`.
Applied to `wc^∞`, after finitely many steps the unread input is `c^∞`. Both `y` and
`y^{-1}` fix `0^∞` and `1^∞`: the rules give `0^∞·y = 0(0^∞·y)`, `1^∞·y = 11(1^∞·y)`,
`0^∞·y^{-1} = 00(0^∞·y^{-1})` and `1^∞·y^{-1} = 1(1^∞·y^{-1})`. So the output is a finite
word followed by `c^∞`. The same holds for `y_u^{±1} = λ_u(y^{±1})`, and all these maps
are bijections of `2^N` with inverses of the same kind. ∎

**Corollary 1.3.** `y_u^{±1}` fixes `0^∞` and `1^∞` for every `u`: either `u` is not a
prefix of `c^∞`, or `u = c^k` and `c^∞·y_u^{±1} = c^k(c^∞·y^{±1}) = c^∞`.

**Lemma 1.4 (the circle action through `S_C`).** There is a surjective homomorphism
`ι: S_C → S` with `Φ(ξ·g) = Φ(ξ)·ι(g)` for all `g ∈ S_C` and `ξ ∈ Rat`. In particular `S`
preserves `QP^1`.

*Proof.* Match the generators `x, x_1, p_0, w_{10,110}` with `a, b, l, s`. By (L3), for each
generator `g` with partner `c`, `Φ(ξ·g) = Φ(ξ)·c` on `Rat`. Putting `ξ = ζ·g^{-1}` gives
`Φ(ζ·g^{-1}) = Φ(ζ)·c^{-1}`, using Lemma 1.2. By induction on word length, a word
`g_1 ⋯ g_k` in the generators and inverses, with partner `c_1 ⋯ c_k`, satisfies
`Φ(ξ·g_1⋯g_k) = Φ(ξ)·c_1⋯c_k` on `Rat`. If two words define the same `g ∈ S_C`, their
partners agree on `Φ(Rat) = QP^1` (Lemma 1.1), which is dense in `S^1`, so they are the
same homeomorphism. Hence `ι(g) = c_1 ⋯ c_k` is well defined. It is a homomorphism, and
its image is `⟨a, b, l, s⟩ = S` by (L2). No injectivity of `ι` is used. ∎

## 2. The groups `F_C` and `T_C`

**Cyclic diagrams.** A *cyclic diagram* is a triple `(L, R, k)` of trees `L = (s_1<⋯<s_n)`,
`R = (t_1<⋯<t_n)` of the same size and `0 ≤ k < n`. It defines the homeomorphism
`s_i ξ ↦ t_{i+k} ξ` of `2^N`, indices mod `n`. The *depth* of the diagram is
`max_i |s_i|`. The map *acts on* a word `v` when `v` has a prefix `s_i ∈ L`; then
`v = s_i v'`, `v·g := t_{i+k} v'`, and `g` maps `[v]` onto `[v·g]` by prefix replacement.
Let `T_C` be the set of maps given by cyclic diagrams, and `F_C ⊆ T_C` the set of maps given
by diagrams with `k = 0` (Lodha's tree diagrams, l.253--263).

**Facts about trees.**
- **(D1)** If `L` has depth `d`, every word `v` with `|v| ≥ d` has a prefix in `L`: take any
  `ξ ∈ [v]`; its prefix in `L` has length `≤ d ≤ |v|`, so it is a prefix of `v`.
- **(D2)** If `v` is a proper prefix of some leaf of `L`, then `v0` and `v1` are each
  prefixes of leaves. A sequence in `[v1]` has a prefix `u ∈ L`. If `|u| ≤ |v|`, then `u` is
  a prefix of `v` and of the leaf extending `v`, so a sequence in `[leaf]` has two prefixes in
  `L`, which is impossible. So `u` extends `v1`. The same for `v0`.
- **(D3)** For disjoint cones `[σ] < [τ]`, each of the three sets
  `A = {ξ < [σ]}`, `B = {[σ] < ξ < [τ]}`, `C = {ξ > [τ]}` is a finite disjoint union of
  cones. Indeed `A = ⋃_{σ_i = 1} [σ_1⋯σ_{i−1}0]`, `C = ⋃_{τ_i = 0} [τ_1⋯τ_{i−1}1]`, and `B`
  is the intersection of two such unions, and two cones meet in a cone or not at all. So
  `{σ, τ}` together with cone decompositions of `A`, `B`, `C` is a tree.
- **(D4)** *Subdivision.* Replacing a matched pair `s_i ↦ t_{i+k}` by `s_i0 ↦ t_{i+k}0` and
  `s_i1 ↦ t_{i+k}1` gives a cyclic diagram for the same map. Any cone `[s]` of a tree meeting
  a nonempty finite union `U` of cones can be refined within `[s]` to a set of cones that
  contains a partition of `[s] ∩ U`, by repeated subdivision.

**Lemma 2.1.** `T_C` is a group, `F_C = Stab_{T_C}(0^∞)`, and no element of `T_C` maps `0^∞`
to `1^∞`.

*Proof.* Say that a bijection `β: L → R` between trees is *cyclic* when it is `s_i ↦ t_{i+k}`
for some `k`. Call `s_{i+1}` (indices mod `n`) the *successor* of `s_i`. Then `β` is cyclic
iff it sends the successor of each leaf to the successor of its image: one direction is
clear, and conversely, if `β(s_1) = t_{1+k}`, induction on `i` gives `β(s_i) = t_{i+k}`.
Composites and inverses of successor-preserving bijections are successor-preserving.
Subdivision (D4) preserves the property. Let `β(s) = t` with `n ≥ 2`, and subdivide this
pair. In the new left tree the successor of `s0` is `s1`, the successor of `s1` is the old
successor of `s`, and the successor of the old predecessor of `s` is `s0`. All other
successors are unchanged. The same holds on the right with `t`. Since `β(succ(s)) = succ(t)`
and `β(pred(s)) = pred(t)`, the new bijection preserves successors. For `n = 1` the
subdivided diagram matches `s0 ↦ t0` and `s1 ↦ t1`, which is cyclic.

Every tree is reached from `{∅}` by repeated subdivision. Induct on the number of leaves.
Let `vc` be a longest leaf of a tree `L ≠ {∅}`. By (D2) the word `vc̄` is a prefix of a
leaf, and by maximality of `|vc|` that leaf is `vc̄`. Replacing `vc, vc̄` by `v` gives a
tree with one leaf fewer. Applying this inside a cone `[r]` shows that any tree whose leaves
in `[r]` are `r` followed by the leaves of some tree is reached from `r` by subdivision.

Given `g = (L, R, β)` and `h = (L', R', β')`, let `M` be the common refinement of `R` and
`L'`: the longer word of each comparable pair `(r, l')`, `r ∈ R`, `l' ∈ L'`. It is a tree.
Every `ξ` has a unique prefix `r ∈ R` and a unique prefix `l' ∈ L'`, these are comparable,
and the longer one is its unique prefix in `M`. The leaves of `M` in `[r]` are either `r`
itself or the leaves of `L'` extending `r`. So `M` is reached from `R` by subdivision, and
likewise from `L'`. Subdividing both diagrams writes `g = (L̂, M, β̂)` and
`h = (M, R̂', β̂')`. Then `gh = (L̂, R̂', β̂'∘β̂)`, whose bijection is a composite of cyclic
bijections and is therefore cyclic. The inverse of `(L, R, β)` is `(R, L, β^{-1})`. So `T_C`
is a group.

For `g = (L, R, k)`, the sequence `0^∞` lies in `[s_1]`, since `s_1 = 0^a`. So
`0^∞·g = t_{1+k}0^∞`. This is never `1^∞`. It equals `0^∞` iff `t_{1+k}` consists of zeros,
iff `t_{1+k} = t_1`, iff `k = 0`. So every diagram for `g` has `k = 0` if `g` fixes `0^∞`,
and every diagram has `k ≠ 0` otherwise. Hence `F_C = Stab_{T_C}(0^∞)`, a subgroup. ∎

**Lemma 2.2.** `F_C = ⟨x, x_1⟩` and `T_C = ⟨x, x_1, p_0⟩`. In particular both are subgroups
of `S_C`.

*Proof.* **Conjugation of `x`'s.** If `g ∈ T_C` acts on `σ`, then `g^{-1} x_σ g = x_{σ·g}`.
The proof is that of Lemma 3.1 below, with `x` in place of `y`. Now `x` acts on `1^k` for
`k ≥ 1`, with `1^k·x = 1^{k+1}`. So `x^{-1} x_{1^k} x = x_{1^{k+1}}`, and
`x_{1^k} ∈ ⟨x, x_1⟩` for every `k ≥ 0`.

**Rotation.** Let `V_n = {0, 10, …, 1^{n−2}0, 1^{n−1}}`, the right vine. Let `L` be a tree
with `n` leaves and `L ≠ V_n`. Put `m = 1 + max{j : 1^j` is a proper prefix of a leaf`}`,
and `m = 0` if `L = {∅}`. By (D2), `1^m` and the words `1^k0` (`k < m`) are prefixes of
leaves. If none of the `1^k0` were a proper prefix of a leaf, all these words would be leaves.
They form the tree `V_{m+1}`, and a tree containing a tree equals it, so `L = V_{m+1} = V_n`.
So some `u = 1^k`, `k < m`, has `u0` a proper prefix of a leaf. By (D2), every leaf extends
`u00`, `u01` or `u1`, or lies outside `[u]`. So `x_u` acts on every leaf, and `L·x_u` is a
tree listed in the same order. As maps, `(L, V_n, 0) = x_u · (L·x_u, V_n, 0)`. The total
number `Z(L)` of zeros in the leaves strictly drops, since `u00η ↦ u0η` and at least one leaf
extends `u00`, while `u01η ↦ u10η` and `u1η ↦ u11η` keep their zeros. So after finitely
many steps `(L, V_n, 0)` is a product of elements `x_{1^k}`.

**Assembly.** `(L, R, 0) = (L, V_n, 0)(R, V_n, 0)^{-1}`, so `F_C ⊆ ⟨x_{1^k}⟩ = ⟨x, x_1⟩`.
The reverse inclusion holds because `x, x_1 ∈ F_C` and `F_C` is a group. For `T_C`:
`p_{n−2}` is exactly `(V_n, V_n, 1)` for `n ≥ 2` (l.275--289). The formula of l.275--289 for `n ≥ 1` also describes `p_0` when `n = 0` (the first case is
then empty). With it, the relation `p_n = x_{1^n} p_{n+1}` (2.3), `n ≥ 0`, is checked leaf by
leaf, applying `x_{1^n}` first:
- `1^j0η ↦ 1^j0η ↦ 1^{j+1}0η` for `j < n`, as for `p_n`;
- `1^n00η ↦ 1^n0η ↦ 1^{n+1}0η`, and `p_n` sends `1^n0(0η)` to `1^{n+1}0η`;
- `1^n01η ↦ 1^{n+1}0η ↦ 1^{n+2}η`, and `p_n` sends `1^n0(1η)` to `1^{n+2}η`;
- `1^{n+1}η ↦ 1^{n+2}η ↦ 0η`, as for `p_n`.

So `p_{n+1} = x_{1^n}^{-1} p_n ∈ ⟨x, x_1, p_0⟩`. Finally
`(L, R, k) = (L, V_n, 0)·p_{n−2}^k·(V_n, R, 0)`, since `s_iξ ↦ v_iξ ↦ v_{i+k}ξ ↦ t_{i+k}ξ`. ∎

**Lemma 2.3.** `x_u ∈ F_C` for every `u ∈ 2^{<N}`. More generally, for a word `σ` put
`K_σ = {σ_1⋯σ_{i−1}σ̄_i : 1 ≤ i ≤ |σ|}`, where `σ̄_i` is the other digit. Then `{σ} ∪ K_σ`
is a tree. Its leaf `σ_1⋯σ_{i−1}σ̄_i` lies before `σ` when `σ_i = 1` and after `σ` when
`σ_i = 0`.

*Proof.* A sequence not in `[σ]` first differs from `σ` at a unique position `i`, so it lies
in exactly one cone `[σ_1⋯σ_{i−1}σ̄_i]`. It is smaller than every element of `[σ]` exactly
when `σ̄_i = 0`, i.e. `σ_i = 1`. For `σ = u`, the map `x_u` is given by the diagram
`{u00, u01, u1} ∪ K_u → {u0, u10, u11} ∪ K_u` with `k = 0`. Listing both trees in order puts
the three words at the same positions, since the leaves of `K_u` before and after `[u]` are
the same in both. ∎

## 3. Conjugation and amplification

For `m ≥ 0` let `N_m = ⟨w_{σ,τ} : σ, τ independent, |σ| ≥ m, |τ| ≥ m⟩`, and `N = N_0`.
By Corollary 1.3, `N ≤ Stab(0^∞) ∩ Stab(1^∞)`.

**Lemma 3.1 (conjugation).** Let `g ∈ T_C` act on `σ`. Then `g^{-1} y_σ g = y_{σ·g}`. If `g`
has a diagram of depth `d`, then `g^{-1} N_{m+d} g ⊆ N_m` for every `m ≥ 0`.

*Proof.* `g` maps `[σ]` onto `[σ·g]` by `σ η ↦ (σ·g) η`. Let `ξ = (σ·g)η`. Then
`ξ·g^{-1} = ση`, then `y_σ` gives `σ(η·y)`, then `g` gives `(σ·g)(η·y) = ξ·y_{σ·g}`. If
`ξ ∉ [σ·g]`, then `ξ·g^{-1} ∉ [σ]` is fixed by `y_σ`, and `g` returns it to `ξ`.

For the second part let `σ, τ` be independent with `|σ|, |τ| ≥ m + d`. By (D1), `g` acts on
both. Write `σ = s_iσ'`; then `σ·g = t_{i+k}σ'` has length `≥ |σ'| ≥ |σ| − d ≥ m`, and
likewise for `τ`. The cones `[σ·g] = [σ]·g` and `[τ·g] = [τ]·g` are disjoint, so `σ·g`,
`τ·g` are independent. So `g^{-1} w_{σ,τ} g = w_{σ·g, τ·g} ∈ N_m`. ∎

**Lemma 3.2 (amplification).** For every `u ∈ 2^{<N}`,
`y_u = x_u · y_{u0} y_{u10}^{-1} y_{u11}` and `y_u^{-1} = x_u^{-1} · y_{u00}^{-1} y_{u01} y_{u1}^{-1}`. (3.2)

*Proof.* Applying `λ_u`, it suffices to take `u = ∅`. For `y = x y_0 y_10^{-1} y_11`, apply
the right side to the three cones:
- `00η ↦ 0η ↦ 0(η·y)`, then fixed by `y_10^{-1}` and `y_11`;
- `01η ↦ 10η`, fixed by `y_0`, `↦ 10(η·y^{-1})` by `y_10^{-1}`, fixed by `y_11`;
- `1η ↦ 11η`, fixed by `y_0` and `y_10^{-1}`, `↦ 11(η·y)`.

These are the three rules defining `y`. Inverting, `y^{-1} = y_11^{-1} y_10 y_0^{-1} x^{-1}`.
The map `x^{-1}` acts on `11, 10, 0` with images `1, 01, 00`. By Lemma 3.1 with
`g = x^{-1}`, `x y_v^{±1} x^{-1} = y_{v·x^{-1}}^{±1}`, so
`y^{-1} = x^{-1}·(x y_11^{-1} y_10 y_0^{-1} x^{-1}) = x^{-1} y_1^{-1} y_01 y_00^{-1}`. The
last three factors have disjoint supports and commute. ∎

## 4. Balanced `y`-products

A *balanced product* is `P = y_{u_1}^{ε_1} ⋯ y_{u_k}^{ε_k}` with `u_1, …, u_k` pairwise
independent, `ε_i ∈ {±1}` and `Σ ε_i = 0`. The factors have disjoint supports, so they
commute.

**Lemma 4.1.** Every balanced product lies in `F_C·N_m`, for every `m ≥ 0`. In particular
`w_{σ,τ} ∈ F_C·N_m` for all independent `σ, τ` and all `m`.

*Proof.* Fix `m`. Put `D(P) = Σ_i 4^{max(0, m − |u_i|)}`, a positive integer; induct on it.

If every `|u_i| ≥ m`, there are as many `+1` as `−1` exponents. Pair them:
`P = ∏_j y_{u_{i_j}} y_{u_{i'_j}}^{-1} = ∏_j w_{u_{i_j}, u_{i'_j}} ∈ N_m`.

Otherwise pick a factor `y_u^ε` with `|u| < m`, and write `P = y_u^ε Q`, where `Q` is the
product of the other factors. By (3.2), `y_u^ε = x_u^ε A`, where `A` is
`y_{u0} y_{u10}^{-1} y_{u11}` if `ε = 1` and `y_{u00}^{-1} y_{u01} y_{u1}^{-1}` if `ε = −1`.
So `P = x_u^ε · P'` with `P' = AQ`. The three new words extend `u`, are pairwise
independent, and are independent of the other `u_i`. The exponent sum of `A` is `ε`. So `P'`
is balanced. In `D`, the term `4^{m−|u|}` is replaced by at most
`4^{m−|u|−1} + 2·4^{max(0, m−|u|−2)} ≤ 3·4^{m−|u|−1} < 4^{m−|u|}`. So `D(P') < D(P)`, and by
induction `P' = fW` with `f ∈ F_C`, `W ∈ N_m`. Then `P = (x_u^ε f) W ∈ F_C·N_m`, since
`x_u ∈ F_C` (Lemma 2.3). ∎

## 5. `S_C = N·T_C`

**Lemma 5.1.** `N ⊆ F_C·N_m` for every `m ≥ 0`.

*Proof.* Every element of `N` is a product `w_1 ⋯ w_r` of generators `w_{σ,τ}`, since
`w_{σ,τ}^{-1} = w_{τ,σ}`. Induct on `r`, proving the statement for all `m` at once. For
`r = 0` it is trivial. Let `W = V w` with `V` of length `r − 1` and `w = w_{σ,τ}`. By
Lemma 4.1, `w = f'W''` with `f' ∈ F_C` and `W'' ∈ N_m`. Let `d` be the depth of a diagram
of `f'`. By induction, `V = fV'` with `f ∈ F_C` and `V' ∈ N_{m+d}`. Then
`W = f V' f' W'' = (f f')·(f'^{-1} V' f')·W''`, and `f'^{-1} V' f' ∈ N_m` by Lemma 3.1. So
`W ∈ F_C·N_m`. ∎

**Lemma 5.2.** `N·T_C = T_C·N` and `N·F_C = F_C·N`. Both are subgroups.

*Proof.* Let `W ∈ N` and `g ∈ T_C`, with a diagram of depth `d`. By Lemma 5.1,
`W = fW'` with `f ∈ F_C`, `W' ∈ N_d`. So `Wg = (fg)·(g^{-1}W'g)`, and `g^{-1}W'g ∈ N` by
Lemma 3.1. Hence `N·T_C ⊆ T_C·N`, and `N·F_C ⊆ F_C·N` when `g ∈ F_C`. Taking inverses gives
the reverse inclusions. If `H, K` are subgroups with `HK = KH`, then `HK` is a subgroup. ∎

**Proposition 5.3.** If every `w_{σ,τ}` lies in `S_C` (Proposition 6.1), then
`S_C = N·T_C = T_C·N`.

*Proof.* `T_C·N` is a subgroup (Lemma 5.2). It contains `x, x_1, p_0 ∈ T_C` and
`w_{10,110} ∈ N`, so it contains `S_C`. Conversely `T_C = ⟨x, x_1, p_0⟩ ⊆ S_C` by Lemma 2.2,
and `N ⊆ S_C` by Proposition 6.1. ∎

## 6. All `w_{σ,τ}` lie in `S_C`

**Gap pattern.** Let `σ, τ` be independent. Going around the circle `2^N/(0^∞ ∼ 1^∞)` in
increasing order from `[σ]`, the complement of `[σ] ∪ [τ]` splits into the part `G_1` met
before `[τ]` and the part `G_2` met after `[τ]`. For `[σ] < [τ]`, in the notation of (D3),
`G_1 = B` and `G_2 = C ∪ A`; for `[τ] < [σ]`, `G_1 = C' ∪ A'` and `G_2 = B'`, with the
regions of the pair `(τ, σ)`. The *pattern* of `(σ,τ)` records which of `G_1, G_2` are
empty.

**Lemma 6.0.** If `(σ,τ)` and `(σ',τ')` have the same pattern, some `g ∈ T_C` acts on `σ` and
`τ` with `σ·g = σ'` and `τ·g = τ'`. Then `g^{-1} w_{σ,τ} g = w_{σ',τ'}`.

*Proof.* By (D3), each of `G_1, G_2, G_1', G_2'` is a finite disjoint union of cones, so
`{σ,τ}` and `{σ',τ'}` extend to trees `L`, `L'`. By (D4), subdivide leaves inside the
nonempty regions until `G_1` and `G_1'` contain the same number of leaves, and likewise
`G_2` and `G_2'`. Now `|L| = |L'|`. List `L` cyclically starting at `σ`: `σ`, the leaves
of `G_1`, `τ`, the leaves of `G_2`. List `L'` the same way from `σ'`. Matching the two
lists position by position is a cyclic bijection, since the lexicographic order of a tree is
the cyclic order read from its first leaf. It sends `σ ↦ σ'` and `τ ↦ τ'`. The conjugation
formula is Lemma 3.1. ∎

**Proposition 6.1.** `w_{σ,τ} ∈ S_C` for all independent `σ, τ`.

*Proof.* `T_C ⊆ S_C` (Lemma 2.2), so by Lemma 6.0 it suffices to treat one pair per
pattern.
- **`G_1 = ∅`, `G_2 ≠ ∅`:** `(10, 110)`. Nothing lies between `[10]` and `[110]`, while
  `[111] ∪ [0]` lies after. `w_{10,110}` is a generator.
- **`G_1 ≠ ∅`, `G_2 = ∅`:** `(110, 10)`, and `w_{110,10} = w_{10,110}^{-1}`.
- **`G_1 ≠ ∅`, `G_2 ≠ ∅`:** `(10, 1101)`, with `G_1 = [1100]` and `G_2 = [111] ∪ [0]`.
  Lodha's identity (l.646), `w_{10,110} = x_110^{-1} w_{10,1101} w_{11001,11000}`, (6.2),
  follows from (3.2) at `u = 110`: after cancelling `y_10`, it reads
  `y_110^{-1} = x_110^{-1} y_1101^{-1} y_11001 y_11000^{-1}`. Rearranged,
  `w_{10,1101} = x_110 · w_{10,110} · w_{11000,11001}`. The pair `(11000, 11001)` has
  `G_1 = ∅ ≠ G_2`, so its `w` lies in `S_C` by the first case; `x_110 ∈ F_C ⊆ S_C`.
- **`G_1 = G_2 = ∅`:** only `(0, 1)` and `(1, 0)`, and `w_{1,0} = w_{0,1}^{-1}`. By (3.2) at
  `u = 0` with `ε = 1`, and at `u = 1` with `ε = −1`, and since `x_1` commutes with
  everything supported in `[0]`,
  `w_{0,1} = y_0 y_1^{-1} = x_0 x_1^{-1} · w_{00,010} w_{011,100} w_{101,11}`. (6.1)
  Each of the pairs `(00,010)`, `(011,100)`, `(101,11)` has nothing between its cones and
  something after, so each `w` lies in `S_C` by the first case. ∎

This follows Lodha's Lemma at l.631--650. Its proof recalls from Lemma `Taction` (l.301--312)
that the partial action of `T` on independent pairs has three orbits (l.637--639). Neither
that lemma nor the orbit count is used here. The pair `(0,1)`, whose cones cover `2^N`, is
treated on its own.

## 7. The stabilizer and its ten generators

**Proposition 7.1.** `Stab_S(∞) = ι(Stab_{S_C}(0^∞))`, and
`Stab_{S_C}(0^∞) = N·F_C = ⟨F_C, N⟩`.

*Proof.* Every element of `S` is `ι(g)` for some `g ∈ S_C`, and
`∞·ι(g) = Φ(0^∞)·ι(g) = Φ(0^∞·g)` (Lemma 1.4). By Lemma 1.1 (2), `ι(g)` fixes `∞` iff
`0^∞·g ∈ {0^∞, 1^∞}`. By Proposition 5.3 write `g = Wf` with `W ∈ N`, `f ∈ T_C`. Since `W`
fixes `0^∞`, `0^∞·g = 0^∞·f`. By Lemma 2.1 this is never `1^∞`, and it is `0^∞` iff
`f ∈ F_C`. So `ι(g) ∈ Stab_S(∞)` iff `g ∈ N·F_C`, and `Stab_{S_C}(0^∞) = N·F_C`, which is the
subgroup `⟨F_C, N⟩` by Lemma 5.2. ∎

**Order pattern.** For independent `σ, τ` with `[σ] < [τ]`, the *order pattern* records
which of the regions `A`, `B`, `C` of (D3) are empty. There are eight patterns.

**Lemma 7.2.** If `[σ] < [τ]`, `[σ'] < [τ']` and the order patterns agree, some `f ∈ F_C`
acts on `σ, τ` with `σ·f = σ'` and `τ·f = τ'`. Then `f^{-1} w_{σ,τ} f = w_{σ',τ'}`.

*Proof.* As for Lemma 6.0. Extend both pairs to trees by (D3). Subdivide inside the nonempty
regions until `A, A'` hold equally many leaves, and likewise `B, B'` and `C, C'`. Then the
order-preserving matching `L → L'` sends `σ ↦ σ'` and `τ ↦ τ'`, and gives an element of
`F_C`. ∎

**Theorem 7.3.** `Stab_{S_C}(0^∞)` is generated by the ten elements
`x`, `x_1`, `w_{0,1}`, `w_{0,10}`, `w_{01,1}`, `w_{00,11}`, `w_{01,11}`, `w_{00,10}`,
`w_{01,10}`, `w_{01,110}`. Hence `Stab_S(∞)` is generated by their ten images under `ι`.

*Proof.* By Proposition 7.1 and Lemma 2.2, the stabilizer is generated by `x`, `x_1` and all
`w_{σ,τ}`. Since `w_{σ,τ} = w_{τ,σ}^{-1}`, it suffices to take `[σ] < [τ]`. The eight listed
pairs realize the eight order patterns, recorded as (`A`; `B`; `C`):
- `(0,1)`: ∅; ∅; ∅.
- `(0,10)`: ∅; ∅; `[11]`.
- `(01,1)`: `[00]`; ∅; ∅.
- `(00,11)`: ∅; `[01] ∪ [10]`; ∅.
- `(01,11)`: `[00]`; `[10]`; ∅.
- `(00,10)`: ∅; `[01]`; `[11]`.
- `(01,10)`: `[00]`; ∅; `[11]`.
- `(01,110)`: `[00]`; `[10]`; `[111]`.

By Lemma 7.2, every `w_{σ,τ}` with `[σ] < [τ]` is `f w_rep f^{-1}` for a listed `w_rep`
and some `f ∈ F_C = ⟨x, x_1⟩`. The listed `w`'s lie in `S_C` by Proposition 6.1 and fix
`0^∞` by Corollary 1.3. The last sentence follows from Proposition 7.1. ∎

## 8. 2-transitivity and faithfulness

**Lemma 8.1.** For all `s, u ∈ 2^{<N}` there is `f ∈ F_C` with `(s01^∞)·f = u01^∞`.

*Proof.* By Lemma 2.3, `L = {s01} ∪ K_{s01}` is a tree. Its leaf `s00` (position
`i = |s| + 2`, where `σ_i = 1`) lies before `s01`, and its leaf `s1` (position `i = |s| + 1`,
where `σ_i = 0`) lies after `s01`. So `L` has `a ≥ 1` leaves before `s01` and `c ≥ 1` after
it. Likewise `L' = {u01} ∪ K_{u01}` has `a' ≥ 1` leaves before `u01` and `c' ≥ 1` after it.
Call `s01` the distinguished leaf of `L` and `u01` that of `L'`. Replacing any other leaf `v`
by `v0, v1` gives a tree with one more leaf, on the same side of the distinguished leaf as
`v`. Doing this in `L` or `L'`, whichever has fewer leaves before its distinguished leaf,
equalizes `a` and `a'`; do the same after it. The order-preserving matching of the two trees
is a diagram `(L, L', 0)`, hence an element `f ∈ F_C`. It matches `s01` with `u01`, so
`(s01η)·f = u01η` for every `η`. Take `η = 1^∞`. ∎

**Theorem 8.2.** `S` acts faithfully and 2-transitively on `QP^1`.

*Proof.* `S` preserves `QP^1` by Lemma 1.4.

*Step 1: `Stab_S(∞)` is transitive on `Q`.* Let `q, q' ∈ Q`. By Lemma 1.1 (1) and (2),
`q = Φ(ξ)` for some `ξ ∈ Rat ∖ {0^∞, 1^∞}`. By Lemma 1.1 (3), `ξ ∈ p_s` for some `s`, and
`Φ` is constant on `p_s`, so `q = Φ(s01^∞)`. Likewise `q' = Φ(u01^∞)` for some `u`. Take `f`
from Lemma 8.1 and put `h = ι(f)`. By Lemma 1.4, `q·h = Φ(s01^∞·f) = Φ(u01^∞) = q'`. Also
`f` fixes `0^∞` (Lemma 2.1) and `Φ(0^∞) = ∞` (Lemma 1.1 (2)), so
`∞·h = Φ(0^∞·f) = Φ(0^∞) = ∞`.

*Step 2: `S` is transitive on `QP^1`.* By construction `ι(p_0) = l`, and `∞·l = 0` because
`l(t) = −1/t`. For `q ∈ Q`, Step 1 gives `h ∈ Stab_S(∞)` with `0·h = q`, so `∞·(lh) = q`.

*Step 3: 2-transitivity.* Let `(p, q)` and `(p', q')` be ordered pairs of distinct points of
`QP^1`. By Step 2 choose `g, g' ∈ S` with `p·g = ∞` and `p'·g' = ∞`. Then `q·g` and
`q'·g'` are not `∞`, so they lie in `Q`. Step 1 gives `h ∈ Stab_S(∞)` with
`(q·g)·h = q'·g'`. Put `k = g h g'^{-1}`. Then `p·k = ∞·(h g'^{-1}) = ∞·g'^{-1} = p'` and
`q·k = (q'·g')·g'^{-1} = q'`.

*Step 4: faithfulness.* `S` is by definition a group of homeomorphisms of `S^1` (Lodha
l.108--118). An element fixing `QP^1` pointwise fixes a dense subset of `S^1`, so it is the
identity. ∎

## 9. Conclusion

**Corollary 9.1.** The action of `S` on `QP^1` is of type (A).

*Proof.* The action is faithful and 2-transitive (Theorem 8.2), and `|QP^1| ≥ 2`. `S` is
finitely presented (L1), and `Stab_S(∞)` is finitely generated (Theorem 7.3). Apply
`two-transitive-action-reduces-type-a-to-two-clauses`. ∎

**Corollary 9.2.**
1. Every subgroup of `S` satisfies permutational Boone--Higman, has solvable word problem,
   and embeds in a finitely presented simple group.
2. `S` embeds in a finitely presented simple group that is MIF, and in one that is highly
   transitive. So BFFHZ Question 3.4 has a positive answer for `S`.

*Proof.*
1. Membership in the permutational class holds by definition, since every subgroup of `S`
   embeds in `S`, which carries a type (A) action. The rest is
   `type-a-action-gives-boone-higman-for-subgroups` (Zaremsky, Corollary B).
2. `S` is finitely generated (L2) and has solvable word problem (part 1). So Theorem C of
   BFFHZ, (i) ⟹ (iv) and (i) ⟹ (iii), as imported in
   `fp-simple-highly-transitive-groups-satisfy-pbh`, gives both overgroups. ∎

**What is not used.**
- Injectivity of `ι`, so no identification `S_C ≅ S`, and no presentation of `S` beyond the
  bare statement (L1).
- Lodha's standard forms, his Lemma `Taction` (l.301--312, with the orbit count recalled at
  l.637--639), and his treatment of `S_∞`
  (l.827--838). His l.827 already names `S_∞ = Stab_S(∞)` as a subgroup, but a search of
  the source for "generated" and for `S_{\infty}` finds no finite generating set for it.

**Remarks, not proved here.**
- Lodha l.1444 states that `S` is generated by `G_0'` and `T`, which presupposes
  `G_0' ≤ S` for the commutator subgroup `G_0'` of the Lodha--Moore group. If so, every
  subgroup of `G_0'` satisfies permutational Boone--Higman. That containment was not
  re-derived here.
- The method (a Cantor model with a transducer letter `y`, balanced `y`-products, and
  conjugation by a Thompson-like group of tree diagrams) should apply to other groups built
  from `T` and finitely many `w_{σ,τ}`. Nothing beyond `S` is claimed.

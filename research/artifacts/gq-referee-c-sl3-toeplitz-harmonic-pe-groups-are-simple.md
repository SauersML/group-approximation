## 1. Local annihilation (re-derived)

**Setting.** `X` is an infinite compact Hausdorff totally disconnected space, and `C(X,k)` is a commutative
function ring containing every `χ_V`. The action satisfies `u_γ g u_γ^(-1) = g ∘ γ^(-1)`, so
`u_γ χ_V = χ_(γV) u_γ`. `R` is a unital subring containing every `χ_V`.

**Step 1 (choice of V and W).** Let `Φ ∋ 1` be the finite support set of `F`, and fix `x`.
- `X` is infinite, so some `y ∉ Φx`.
- Then no `γ^(-1)y` (`γ ∈ Φ`) equals `x`. Finitely many clopen separations give a clopen `V ∋ x` that avoids all
  of them. Hence `y ∉ γV` for every `γ ∈ Φ`.
- Put `W = X \ (V ∪ ⋃_Φ γV)`. It is clopen, contains `y`, and so is nonempty. ✓

**Step 2 (annihilation).** Take `t = χ_W ≠ 0` and `s = χ_V r`.
- `ts = χ_(W∩V) r = 0`.
- Each term of `t f s` is `g_(f,γ) χ_(W∩γV) u_γ r = 0`. ✓

**Step 3 (partition).** Compactness gives finitely many `V(x_i)`; refine them to a clopen partition `V_i`.
- `V_i ∪ ΦV_i ⊆ V(x_i) ∪ ΦV(x_i)`, so `W(x_i)` still works for `V_i`.
- Since `Σ χ_(V_i) = 1`, we get `R = Σ χ_(V_i) R ⊆ additive span of S_F`. ✓

**Match with Lean.** `GroupApproximation/Pestov91/SimpleModCentre.lean:43` defines
`LocalAnnihilation R := ∀ F : Finset R, NonUnitalSubring.closure {s | ∃ t ≠ 0, t*s = 0 ∧ ∀ f ∈ F, t*f*s = 0} = ⊤`.
- The additive span lies inside the non-unital subring closure, so the node's conclusion implies the Lean
  predicate. ✓
- The Lean theorem `isSimpleGroup_elementaryGroup_quotient_center` has hypotheses
  `(hcard : 3 ≤ Fintype.card ι) [IsSimpleRing R] (hloc : LocalAnnihilation R)` (lines 327–328). These are exactly
  `N >= 3`, a simple ring (two-sided ideals only `0` and `R`, as in part 2 of the ring node), and the lemma above.
  ✓

**Calibration.**
- If `X` is finite and the action transitive, then `C(X,k) ⋊ Γ` is a matrix ring. Take `F` to be all matrix
  units. Then primeness forces `S_F = {0}`, and local annihilation fails, as it must
  (`division-rings-satisfy-stepanov-b-not-local-annihilation`). The proof uses infinitude of `X` exactly in
  Step 1.
- There is no conflict with simplicity of `R`: primeness gives `tRs ≠ 0`, while local annihilation only kills
  `t f s` for `f` in a finite set.
- The coefficient ring may contain continuous functions that are not locally constant, such as the harmonic
  coefficient of `R_T`. The proof never uses local constancy of the coefficients, only commutativity and the
  clopen indicators.

## 2. PE_N(R_T) simple, and the centre

- **Hypotheses of the lemma.** `R_T ⊆ C(X,Q) ⋊_alg SL_3(Z)` with `X` an infinite minimal subshift. It contains
  `LC(X,Z)`, hence every `χ_V` (ring part 1), and it is simple (ring part 2). So §1 applies, and the Lean
  criterion gives: every normal subgroup of `E_N(R_T)`, `N >= 3`, is central or everything. ✓
- **Infinite.** `e_12(a) e_12(b)^(-1) = e_12(a-b)` is central only if `[e_12(a-b), e_23(1)] = e_13(a-b) = 1`, that
  is `a = b`. `R_T ⊇ Q` is infinite. ✓
- **Centre.** Re-derived: a matrix commuting with every `e_ij(1)` is scalar `dI`. Commuting with every `e_ij(r)`
  forces `d ∈ Z(R)`. So `Z(E_N(R)) = E_N(R) ∩ Z(R)^x I`, as in `q-algebra-elementary-quotients-contain-gl-n-q`
  part 2. With `Z(R_T) = Q` (ring part 2) and `Λ_N(R_T) ⊆ {±1}` (ring part 3), the centre is `⊆ {±I}`. ✓ This
  inference is correct. Both inputs sit in the ring node, which I have not reviewed.
- **Finite presentation iff.** `E_N(R_T)` is finitely generated, from finitely many ring generators and 1, using
  `[e_il(a), e_lj(b)] = e_ij(ab)`. The centre `C` is finite.
  - `E` finitely presented ⇒ `E/C` finitely presented: add at most one relator.
  - `E/C` finitely presented ⇒ `E` finitely presented, by `fg-central-extension-of-fp-group-is-fp`. That is
    standard: `C` is finitely generated because it is normally generated by the finitely many relators of `E/C`,
    whose conjugates coincide modulo the kernel; then P. Hall's extension lemma applies. ✓
- **Embedding.** For `N >= n+2`, `g ↦ [diag(g, det g^(-1), I)]` is injective into `PE_N`. The trailing `1`
  prevents any nontrivial image from being `±I`. ✓

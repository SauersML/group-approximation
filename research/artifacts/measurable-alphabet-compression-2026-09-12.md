# Measurable alphabet compression over the Leavitt units, and two measurable obstructions

Lane `gk-n-ae-decoder`, 2026-09-12. Supports the Cairn claims
`measurable-alphabet-compression-over-leavitt-units`,
`measurable-certificate-routing-preserves-bernoulli-measure` and
`bernoulli-factors-to-infinite-stabilizer-coset-shifts-trivial`, and the route
`leavitt-zero-supremum-via-measurable-compression`.

## Summary

The measurable negative target `leavitt-units-have-zero-rokhlin-entropy-supremum` asks for a
Rokhlin entropy deficit of a uniform Bernoulli shift over `U = L_(F_2)(1,2)^x`. A decoder that is
correct only almost everywhere suffices. Section 1 makes that object precise.

* **Compression.** An almost-everywhere injective Borel code `A^U -> B^U` with `|B| < |A|` gives a
  deficit, hence zero Rokhlin entropy supremum. With Seward's generator theorem the converse holds
  after amplifying the alphabet; that direction is only a remark here.
* **Theorem A.** Over every countable group, a code that keeps a routing certificate and fills each
  output data site from one input data site is, almost everywhere, a measure-preserving bijection.
  Routing, even Borel and of unbounded displacement, never compresses.
* **Theorem B.** Over every countable group, a Borel equivariant map from a Bernoulli shift into a
  coset shift with infinite stabilizers is almost everywhere constant. The Hilbert-hotel coset
  compressions cannot be pulled onto the free shift, even measurably.

Section 4 records what a compression still needs.

## 0. Setting

`G` is a countable group, with left shift `(h.x)(g) = x(h^-1 g)` on `A^G` and `(h.y)(p) = y(h^-1 p)`
on `B^X` for a left `G`-set `X`. `mu_A` is the uniform product measure. A map is *equivariant* when
it commutes with the shifts, and *almost everywhere injective* when it is injective on a Borel set of
full measure. Rokhlin entropy `h^Rok_G` of a free p.m.p. action is the infimum of `H(beta)` over
countable Borel partitions `beta` whose translates generate the Borel sigma-algebra modulo null sets.

## 1. A measurable compression gives zero Rokhlin entropy supremum

**Proposition 1.** Let `G` be countably infinite, `A, B` finite with `|B| < |A|`, and
`tau: A^G -> B^G` Borel, equivariant and injective on a conull Borel set `X_0`. Then
`h^Rok_G(A^G, mu_A) <= log |B| < log |A|`.

*Proof.* Put `beta = { {x : tau(x)(1) = b} : b in B }`, a Borel partition with `|B|` pieces, so
`H(beta) <= log |B|`. For `g in G`, `tau(x)(g) = tau(g^-1.x)(1)` is read off the `g`-translate of
`beta`, so the sigma-algebra generated by the translates of `beta` contains every coordinate of
`tau`. The restriction of `tau` to `X_0` is an injective Borel map between standard Borel spaces, so
by Lusin–Souslin it is a Borel isomorphism onto its image. The Borel sigma-algebra of `X_0` is
therefore generated by `tau`, and `beta` is generating modulo null sets. QED

**Corollary 2.** If such a `tau` exists for `G = U`, every free ergodic p.m.p. action of `U` has
Rokhlin entropy `0`.

*Proof.* By `seward-per-group-rokhlin-entropy-of-bernoulli-shifts` item 1,
`h^Rok_U(A^U) = min{ log |A|, h_sup(U) }`. Proposition 1 gives a value below `log |A|`, so
`h_sup(U) < log |A| < infinity`. Part 1 of `positive-rokhlin-entropy-makes-leavitt-units-surjunctive`
makes `h_sup(U)` equal to `0` or `infinity`, so `h_sup(U) = 0`. A free ergodic action of finite
Rokhlin entropy is then of entropy `0`. A free ergodic action of infinite Rokhlin entropy would be
POS(`U`), which part 2 of the same claim makes equivalent to INF(`U`), that is `h_sup(U) = infinity`:
a contradiction. QED

**Remark (converse; not imported).** Seward's Krieger generator theorem (arXiv:1405.3604) states that
a free ergodic action with Rokhlin entropy below `log k` has a generating partition with `k` pieces.
Subadditivity gives `h^Rok_U((A^m)^U) <= m h^Rok_U(A^U)`. So a deficit at `A` would give, for large
`m`, a generating partition of `(A^m)^U` into `|A|^m - 1` pieces, and its name map is an almost
everywhere injective equivariant code `(A^m)^U -> B^U` with `|B| = |A|^m - 1`. The compression claim
would then be equivalent to the zero supremum target. That statement has not been read from the
source in this repository, so no route is landed for this direction.

**Relation to the decoder.** The decoder of `tau` is its Borel inverse on the image, defined almost
everywhere. This is the "decoder correct almost everywhere" form of the target, weaker than a strict
automaton: no continuity, no locality, and no pattern avoided on every point.

## 2. Theorem A: measurable certificate routing preserves the Bernoulli measure

Let `C, D` be finite alphabets with `|D| >= 2`, and `mu = mu_C x mu_D` on `(C x D)^G`. Let
`rho: C^G x G -> G` and `pi: C^G x G -> Sym(D)` be Borel with

    rho_(h.c)(hg) = h rho_c(g),        pi_(h.c)(hg) = pi_c(g),

and define

    tau(c, d) = (c, y),        y(g) = pi_c(g)( d(rho_c(g)) ).

No locality, continuity or bounded displacement is assumed.

**Theorem A.** If `tau` is injective on a conull set, then for `mu_C`-almost every `c` the map
`rho_c` is a bijection of `G`, and `tau_* mu = mu`.

*Proof.*

1. **Mass transport.** Write `N(c) = #{ g : rho_c(g) = 1 }`. With `h = g^-1`, equivariance reads
   `rho_(g^-1.c)(1) = g^-1 rho_c(g)`, so `rho_c(g) = 1` exactly when `rho_(g^-1.c)(1) = g^-1`. By
   invariance of `mu_C` under the shift,

       E N = sum_g mu_C{ rho_(g^-1.c)(1) = g^-1 } = sum_g mu_C{ rho_c(1) = g^-1 } = 1.

2. **Every site is read.** Let `X_0` be the conull set of injectivity. By Fubini, for almost every
   `c` the section `X_0^c` is `mu_D`-conull. Fix such a `c`, and suppose some `h` is not in the image
   of `rho_c`. Let `F` apply a fixed-point-free permutation of `D` at coordinate `h`. `F` is a
   measure-preserving Borel bijection of `D^G`, so `X_0^c ∩ F^-1(X_0^c)` is conull. For `d` there,
   `d != F(d)` and `tau(c, d) = tau(c, F(d))`, because coordinate `h` is never read. This contradicts
   injectivity on `X_0`. So for almost every `c` every site has in-degree at least `1`.
3. **In-degree one.** `N >= 1` almost surely and `E N = 1`, so `N = 1` almost surely. Equivariance
   gives `#rho_c^-1(h) = N(h^-1.c)`, and countability of `G` makes every in-degree `1` for almost
   every `c`. Such `rho_c` is surjective with singleton fibres, hence bijective.
4. **Measure.** For such `c`, `d -> y` is a permutation of coordinates followed by coordinatewise
   permutations of `D`. It preserves `mu_D`, and Fubini gives `tau_* mu = mu`. QED

**Consequences.**

* A routing code never distorts the measure and never lowers Rokhlin entropy. It is, almost
  everywhere, a measure-preserving bijection of the shift.
* This is the almost-everywhere, non-local strengthening of `certificate-controlled-routing-is-surjunctive`,
  whose proof uses locality, bounded displacement and finite visibility of defects. Here the routing
  may be any Borel function of the whole certificate.
* The proof consumes only the transport identity `E N = 1`, which holds because the index set is a
  countable group acting on itself. On the end-fixing tree of
  `end-fixing-tree-symmetries-carry-strict-automata` the symmetry group is not unimodular, the
  identity fails, and the routing code "copy the parent" is strict. So unimodularity is exactly what
  this class uses.
* A compression must combine several input data symbols into one output symbol (synergy) or discard
  certificate information that the decoder reconstructs. Neither is a routing code.

## 3. Theorem B: Bernoulli factors to infinite-stabilizer coset shifts are trivial

**Theorem B.** Let `G` be countable, `K <= G` infinite, `A, B` finite, and `mu` the uniform product
measure on `A^G`. Every Borel map `F: A^G -> B^(G/K)` with `F(h.x) = h.F(x)` is almost everywhere
constant.

*Proof.* Put `o = K` and `f(x) = F(x)(o)`. For `k in K`,
`f(k.x) = (k.F(x))(o) = F(x)(k^-1 o) = F(x)(o) = f(x)`, so `f` is `K`-invariant.

The shift restricted to `K` is mixing. If `S, S'` are cylinder sets on finite coordinate sets `P, Q`,
then `k.S` is a cylinder on `kP`, which misses `Q` for every `k` outside the finite set `Q P^-1`;
there `mu(k.S ∩ S') = mu(S) mu(S')`. Approximating Borel sets by cylinders gives
`mu(k.S ∩ S') -> mu(S) mu(S')` as `k -> infinity` in the infinite group `K`. Mixing implies
ergodicity, so `f` is almost everywhere a constant `b`.

For `g in G`, `F(x)(g o) = F(g^-1.x)(o) = f(g^-1.x)`, which is `b` for almost every `x` because
`g^-1` preserves `mu`. There are countably many cosets, so `F(x)` is the constant configuration `b`
for almost every `x`. QED

**Consequence.** `compressed-coset-shifts-carry-strict-equivariant-embeddings` strictly embeds a coset
shift over `U/H` into itself by pulling back along `psi(gH) = g u^-1 H`, where `u H u^-1 < H` and `H`
is infinite. By Theorem B the free Bernoulli shift over `U` has no nonconstant Borel factor into such
a coset shift, so no measurable compression of the free shift passes through it. This is the measurable
twin of `full-shift-maps-to-infinite-stabilizer-coset-shifts-are-constant`. Coset shifts with finite
stabilizers stay admissible; they are the invariant-output codomains.

## 4. What a measurable compression still needs

A code `tau: A^U -> B^U` with `|B| < |A|`, Borel, equivariant, injective almost everywhere, must:

1. **not be a routing code** (Theorem A). Some output symbol has to depend jointly on several input
   symbols, or the certificate has to be discarded and reconstructed;
2. **not pass through an infinite-stabilizer coset shift** (Theorem B);
3. **be nonlinear** for `k = 1` and prime `q`, since a nonzero linear functional of uniform iid
   symbols is uniform (Attempts of the target);
4. **use nonsoficity in every good finite approximation.** A finite approximation of `tau` that
   decodes `x(1)` with small conditional entropy is a deficit configuration, and
   `sofic-radical-localizes-bernoulli-deficit-witnesses` makes its points generate a nonsofic
   subgroup of `U`.

**Where the synergy would have to come from.** The compressor `u Gamma u^-1 < Gamma` of the nine-leaf
configuration has no finite-model counterpart. On the free shift every coordinate carries an
independent symbol, Theorem A forbids storing it by moving it, and Theorem B forbids storing it on
cosets of `Gamma`. The open mechanism is a joint code: one output symbol recording a nonlinear function
of symbols spread along `g, gu, gu^2, ...`, which is decodable only because `Gamma` has no invariant
observables. No construction is known.

## 5. Homomorphic codes cannot compress

**Proposition 5.** Let `G` be countable, `A, B` finite groups with `|B| < |A|`, and
`tau: A^G -> B^G` an equivariant map that is a group homomorphism for the pointwise product. Then
`tau` is not injective on any set of full uniform measure. The same holds for `tau` composed with a
translation of `B^G`, and in particular for every `F`-linear or affine equivariant code
`(F^m)^G -> (F^n)^G` with `m > n` over a finite field `F`.

*Proof.* A constant configuration `c_a` is fixed by every shift, so `tau(c_a)` is shift-fixed, hence
constant. So `tau` restricts to a homomorphism `A -> B` on constants. Since `|B| < |A|` it has a
nontrivial kernel element `a`. For every `x`, `tau(x c_a) = tau(x) tau(c_a) = tau(x)`, and `x c_a != x`.
Right multiplication by `c_a` is a measure-preserving bijection of `A^G`. If `tau` were injective on
a conull set `S`, then `S ∩ S c_a^-1` would be conull, and each `x` in it would give a pair
`x != x c_a` in `S` with equal images. A translation `y -> y b` of the target changes nothing. QED

So synergy by linear combination is dead over every group: any compression is genuinely nonlinear
(non-homomorphic).

## 6. Continuous codes, pre-injectivity, and ascent along subgroups

**Continuous codes are pre-injective.** Let `tau` be continuous with finite memory `M`. Suppose
`x != x'` differ exactly on a finite set `W` with `tau(x) = tau(x')`. Whether that equality holds
depends only on `x` restricted to `W M^-1 M`. So swapping the pattern `x|_W` for `x'|_W` inside the
positive-measure cylinder of configurations agreeing with `x` on `W M^-1 M` is a measure-preserving
bijection onto a disjoint cylinder that preserves `tau`. On a conull set of injectivity this is
impossible. So a continuous code that is injective almost everywhere is pre-injective.

**Calibration (literature remark, not imported).** Pre-injectivity alone is not the target.
Bartholdi and Kielak (J. Eur. Math. Soc., 2019) show that every nonamenable group carries a
pre-injective automaton that is not surjective. That includes sofic groups, where no measurable
compression exists by maximality. So the measurable target sits strictly between pre-injectivity and
injectivity: injectivity on a conull set.

**Ascent.** Let `K <= G` and let `tau_K: A^K -> B^K` be a compression over `K`. For `x` in `A^G` and a
left coset `gK`, put `x_g(k) = x(gk)` and `y(gk) = tau_K(x_g)(k)`. Changing the representative to `gk'`
replaces `x_g` by the left shift `k'^-1.x_g`, and equivariance of `tau_K` makes `y` well defined. `y` is
`G`-equivariant, and by Fubini over the countably many cosets it is injective almost everywhere. So
compressions ascend along subgroups. This matches `bernoulli-rokhlin-maximality-passes-to-subgroups`.
A compression over Thompson's `V` would transfer to `U` and, by the localization theorem, prove `V`
nonsofic.

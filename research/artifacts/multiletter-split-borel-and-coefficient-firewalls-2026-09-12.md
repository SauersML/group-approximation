## 2. Cylinder swaps

**Lemma 2.1 (swaps).** For incomparable words `A`, `B`, put `tau_AB = S[A]T[B] + S[B]T[A] + 1 - e_A - e_B`.
Then `tau_AB` is an involution in `V`, and `tau_AB iota_A(g) tau_AB = iota_B(g)` for every `g in R^x`. It changes
depth when `|A| != |B|`.

*Proof.* We have `T[B]S[A] = 0 = T[A]S[B]` and `T[A]S[A] = 1`. So `tau_AB S[A] = S[B]`, `T[A] tau_AB = T[B]`, and
`tau_AB e_A tau_AB = e_B`. Conjugating `S[A] g T[A] + 1 - e_A` therefore gives `S[B] g T[B] + 1 - e_B`. The same
computation gives `tau_AB^2 = 1`. QED

**Lemma 2.2 (wreath product).** Let `1 != G <= R^x`, and let `A_1, ..., A_k` be pairwise incomparable. The group
`Gamma_k(G)` generated by the `iota_(A_i)(G)` and the swaps `tau_(A_i A_j)` is `G wr S_k`.

*Proof.*
* The `iota_(A_i)(G)` have disjoint supports, so they commute and together give `G^k` faithfully.
* The swaps permute the cylinders `[A_i]` by prefix replacement and fix the complement, so they multiply as
  permutations. By Lemma 2.1 they permute the `iota_(A_i)(G)`. This gives a surjection `G wr S_k -> Gamma_k(G)`.
* Its kernel `K` meets `G^k` trivially, so `[K, G^k] <= K cap G^k = 1`.
* An element `(g_i) pi` with `pi(i) = j != i` conjugates `iota_(A_i)(a)`, for `a != 1`, into
  `iota_(A_j)(G) != iota_(A_i)(G)`. So it does not centralize `G^k`, which gives `K <= G^k` and so `K = 1`. QED

**Proposition 2.3 (tensor wreath model).** Let `G` contain `D_8`. Let `rho` be a characteristic-two matricial rank
model of `G`, with defect `delta_rho = rk((rho(x_23(1)) - 1)(rho(x_12(1)) - 1))` and fixed rank `f_rho`. Then
`Gamma_k(G)` has a rank model `sigma` with the following properties.
* `sigma(iota_(A_i)(g))` is `rho(g)` in tensor slot `i` and `1` in the other slots. `sigma(tau_(A_i A_j))` is the
  flip of slots `i` and `j`.
* `rk(D_(A_(i_1)) ... D_(A_(i_m))) = delta_rho^m` for distinct `i_1, ..., i_m`.
* The fixed rank is at most `f_rho`, so `sigma` is fixed-point-free when `rho` is.

*Proof.* Work at stages `rho_n : G -> GL_(d_n)(K_n)` with normalized rank. Put
`sigma_n((g_i) pi) = (rho_n(g_1) (x) ... (x) rho_n(g_k)) P_pi`, where `P_pi` permutes the tensor slots.
* `X (x) Y - X' (x) Y' = (X - X') (x) Y + X' (x) (Y - Y')` and `rk(X (x) Y) = rk(X) rk(Y)`. So
  `rk(X (x) Y - X' (x) Y') <= rk(X - X') + rk(Y - Y')`.
* `P_pi` moves slot `i` to slot `pi(i)` exactly. So on each pair of elements, the multiplicativity defect of
  `sigma_n` is at most the sum of the `k` slotwise defects of `rho_n`, and `sigma_n` is an asymptotic homomorphism.
* `sigma_n(D_(A_i))` is `D_rho` in slot `i`. A product over distinct slots is a tensor product, so its normalized
  rank is `delta_rho^m`.
* For finite `S <= G`, the fixed space of `sigma_n(iota_(A_1)(S))` is `ker(col_S) (x) (K_n^(d_n))^((x)(k-1))`. Its
  normalized rank is `f_rho(S)`, and it contains the fixed space of `sigma_n(Gamma_k(G))`. QED

**Corollary 2.4 (firewall).** Suppose a derivation uses only relations holding in `Gamma_2(G)`, rank calculus and
fixed-point-freeness, and yields `rk(D_A D_B) <= theta rk(D_A) rk(D_B)` with `theta < 1`. Applied to Proposition
2.3, it gives `delta_rho^2 <= theta delta_rho^2`. So every fixed-point-free model `rho` of `G` has `delta_rho = 0`.
* For sofic `G`, Theorem S says this fails, and Proposition 2.3 adds nothing there, since `G wr S_k` is sofic. For
  finite `G`, `Gamma_k(G)` is finite and `finite-subgroup-data-cannot-force-defect-submultiplicativity` applies.
* For `G = R^x`, the defect gap `leavitt-rank-model-defect-gap-on-fixed-point-free-quotients` turns
  `delta_rho = 0` into triviality of `rho`. So the derivation would prove the gate outright.

**What it adds.** The Attempts entry "Independent tensor factors realize `theta = 1`" asks for a proof that
`V`-conjugate cylinder subgroups cannot act as independent factors. Proposition 2.3 shows that the conjugating
swap letters themselves, at any depths and for any `G`, do not break independence.

**Scope.**
* **Not covered.** Letters that do not carry each `[A_i]` onto a cylinder by one prefix replacement, such as `x_0`
  on `[1]`, which sends `[10]` and `[11]` to `[01]` and `[1]`. Global inputs.
* **Characteristic three.** Send `z = -1` to `-1`. When `[A] cup [B]` is proper, `z` is not in `Gamma_2(G)`, so this
  gives an anti-central model. When `[A] cup [B] = X`, `z = iota_A(z) iota_B(z)` goes to `(-1) (x) (-1) = +1`, so the
  model is not anti-central.

## 3. The lexicographic Borel group

Order `X` lexicographically, and write `U < W` when every point of `U` is below every point of `W`. Cylinders are
intervals, and two incomparable cylinders are disjoint, so one lies left of the other.

**Definition.** `T_<` is the `F_2`-span of the monomials `S[v]T[w]` with `[v] < [w]`, and `U_< = 1 + T_<`. Such a
monomial moves its domain strictly left.

**Lemma 3.1.** `T_<` is a subalgebra.

*Proof.* Let `[v] < [w]` and `[v'] < [w']`, with nonzero product `S[v]T[w] S[v']T[w']`.
* **Case `v' = wu`.** The product is `S[vu]T[w']`. `w'` is incomparable with `wu`, so it is not a prefix of `w`.
  Either `[w'] ⊆ [w]`, or `[w']` and `[w]` are disjoint, and then `[wu] < [w']` puts `[w']` right of `[w]`. Both
  cases give `[vu] ⊆ [v] < [w']`.
* **Case `w = v'u`.** The product is `S[v]T[w'u]`. `v` is incomparable with `v'u`, so it is not a prefix of `v'`.
  Either `[v] ⊆ [v']`, or `[v]` and `[v']` are disjoint, and then `[v] < [v'u]` puts `[v]` left of `[v']`. Both cases
  give `[v] < [w'] ⊇ [w'u]`. QED

**Lemma 3.2 (local nilpotence).** Every finite set `M` of monomials in `T_<` generates a finite-dimensional
nilpotent algebra.

*Proof.* The nonzero words in `M` form a prefix-closed set.
* Suppose that set is infinite. König's lemma gives `m_1, m_2, ...` in `M` with every `P_k = m_1 ... m_k` nonzero.
* As partial maps `P_k = P_(k-1) o m_k`. So the ranges of the `P_k` are decreasing nonempty cylinders, and some
  `eta` lies in all of them.
* By injectivity, the points `eta_0 = eta` and `eta_j = m_j^(-1)(eta_(j-1))` are defined for all `j`. Since each
  `m_j` moves points left, `eta_(j-1) < eta_j`.
* A lexicographically increasing sequence converges: each length-`n` prefix is nondecreasing in a finite ordered
  set, so it is eventually constant. Let `eta_inf` be the limit, and `L` the length of the longest word in `M`.
* For large `j`, `eta_(j-1)` and `eta_j` share their first `L` letters with `eta_inf`. Write `m_j = S[v]T[w]`. Then
  `v` is a prefix of `eta_(j-1)` and `w` is a prefix of `eta_j`, so both are prefixes of `eta_inf` and are
  comparable. This contradicts `[v] < [w]`.

So only finitely many words are nonzero, and all words longer than the longest one vanish. QED

**Corollary 3.3.** `U_<` is a locally finite 2-subgroup of `R^x`.

*Proof.* `(1 + a)(1 + b) = 1 + (a + b + ab)`, and `(1 + a)^(-1) = sum_(i >= 0) a^i` is a finite sum. So finitely
many elements of `U_<` lie in `1 + N`, where `N` is the algebra that Lemma 3.2 attaches to the monomials in their
supports. `N` is finite and nilpotent, so `1 + N` is a finite 2-group. QED

**Lemma 3.4.** Thompson's `F`, the elements of `V` preserving lexicographic order, normalizes `T_<` and `U_<`.

*Proof.* Write `g = sum_i S[p_i]T[q_i]`. Every nonzero term of `g S[v]T[w] g^(-1)` is a monomial whose partial map
restricts `g o (wy -> vy) o g^(-1)`. So its domain lies in `g[w]` and its range lies in `g[v]`. Since `g` preserves
order, `g[v] < g[w]`. QED

**Theorem 3.5.** Let `P <= F`.
* `<U_<, P> = U_< ⋊ P`.
* If `P` is amenable, then `U_< ⋊ P` is amenable, so sofic.
* If also `P != 1`, Theorem S gives a fixed-point-free model with `rk(D_(A_1) ... D_(A_k)) = (3/8)^k` for any
  disjoint nonempty proper `A_i`.
* `U_< ⋊ F` is amenable if and only if `F` is.

*Proof.* `P` normalizes `U_<` by Lemma 3.4. `P cap U_<` is torsion and `F` is torsion-free, so the product is
semidirect. Locally finite by amenable is amenable, and amenable groups are sofic. `iota_A(D_8) <= U_<` for every
`A` (Example 3.6), and `P != 1` has elements of infinite order. For the last item, `U_<` is amenable and `F` is a
quotient. QED

**Example 3.6 (what `U_< ⋊ P` contains).**
1. **Positive roots with any coefficient, at every cylinder.** Write `(p_1, p_2, p_3) = (0, 10, 11)`. For `a < b`
   and `c in R`, `iota_A(x_ab(c)) = 1 + S[A p_a] c T[A p_b]`. A monomial `S[u]T[u']` of `c` contributes
   `S[A p_a u]T[A p_b u']`, and `[A p_a u] ⊆ [A p_a] < [A p_b] ⊇ [A p_b u']`. So `iota_A(UT_3(R)) <= U_<` for every
   `A`. This includes `iota_A(D_8)` and the order-128 Toeplitz group generated by `x_12(t_0)`, `x_23(s_0)`,
   `x_12(1)` and `x_23(1)`.
2. **`Gamma_x = <iota_0(D_8), iota_1(D_8), x_0> <= U_< ⋊ <x_0>`**, where
   `x_0 = S[00]T[0] + S[01]T[10] + S[1]T[11]` preserves order. It is locally finite by cyclic, so amenable. This holds
   although `x_0` changes depth, contracts in every nontrivial frame (Corollary 4.4), and lies in no depth-monotone
   subalgebra `R^ω_≤` or `R^ω_≥` of `depth-monotone-leavitt-subalgebras-are-stably-finite`. For the last point:
   * If `x_0 in R^ω_≤`, then `y = x_0 e_0 = S[00]T[0]` and `z = S[0]T[00]` lie in `R^ω_≤`, with `zy = e_0` and
     `yz = e_00`. So `X = z + 1 - e_0` and `Y = y + 1 - e_0` give `XY = 1 != YX`, contradicting stable finiteness.
   * If `x_0 in R^ω_≥`, the same argument works with `x_0 e_11 = S[1]T[11]` and `S[11]T[1]` in the corner `e_1`.
3. Abelian groups of order-preserving letters, such as copies of `x_0` on disjoint cylinders, give `P = Z^r`.

**Corollary 3.7 (firewall).** Relations holding in `U_< ⋊ P`, with `P <= F` amenable, force no `theta < 1`. A
relation-only deficit from relations holding in `U_< ⋊ F` would prove that group nonsofic, so `F` nonamenable
(`thompson-f-is-not-amenable`, open).

**Characteristic three.** Lemmas 3.1–3.4 use only the monomial calculus, so they hold in `L_(F_3)(1,2)`. There
`U_<` is a locally finite 3-group. `-1` is central, and it lies outside `U_< ⋊ P`, because the torsion of that group
lies in `U_<` and `1` is not in the locally nilpotent `T_<`. So `<-1> x (U_< ⋊ P)` is amenable, which makes it sofic
data for `anti-central-sofic-data-cannot-force-defect-submultiplicativity`.

## 4. One-chart coefficients

**Fact 4.1 (on main).** If a unital subalgebra `S <= R` is residually finite-dimensional, then for every frame `Q`
the group `Phi_Q(GL_#Q(S))` is residually finite: `GL_#Q(S) -> prod_I GL_#Q(S/I)` over the ideals of finite
codimension is injective, into a product of finite groups. `pure-leavitt-chart-linear-groups-are-residually-finite`
gives this for the free algebras `F_2<s_0,s_1>` and `F_2<t_0,t_1>`, and `leavitt-rfd-entry-packets-satisfy-kl`
states the frame form for other residually finite-dimensional entry algebras.

**Corollary 4.2 (application to the deficit).** Let `A_1, ..., A_k` be disjoint nonempty proper cylinders, and `Q` a
frame containing `A_i 0`, `A_i 10` and `A_i 11` for every `i`. Put `S = F_2<s_0,s_1>` and
`H_Q = Phi_Q(GL_#Q(S))`. Then `H_Q` contains:
* `iota_(A_i)(GL_3(F_2))`, so the frames `iota_(A_i)(D_8)`, the opposite roots and the Weyl elements;
* `iota_(A_i)(x_ab(c))` for all `a != b` and `c in S`, since it equals `Phi_Q(1 + c E_(A_i p_a, A_i p_b))`;
* elements of infinite order, e.g. `x^A_12(s_0) x^A_21(1)`
  (`leavitt-right-child-frames-generate-infinite-order-units`, item 3).

So Theorem S applies to every subgroup of `H_Q` containing the frames and an element of infinite order, and
relations holding in `H_Q` force no `theta < 1`. The same holds with `F_2<t_0,t_1>`. With coefficients from both
charts the picture changes: `x_12(t_0)`, `x_23(s_0)` and the constant Weyl group generate `EL_3(J)`
(`toeplitz-pair-and-weyl-elements-generate-jacobson-el3`). Its soficity is the OPEN claim
`binary-jacobson-el3-is-sofic` (lane `w7-el3j-sofic`).

**Lemma 4.3 (contracting letters).** Let `S <= R` be a unital subalgebra, `u in Phi_Q(GL_#Q(S))`, and `q, q' in Q`
with `u e_q u^(-1) < e_(q')` strictly (`ef = fe = e != f`). Then:
* `M_Q(S)` has elements `X`, `Y` with `XY = 1 != YX`;
* `M_Q(S)` contains a copy of the Jacobson algebra `J = F_2<a, b | ba = 1>`;
* `S` is not residually finite-dimensional.

*Proof.*
1. `e_q` corresponds to the matrix unit `E = E_qq in M_Q(F_2) <= M_Q(S)`. Let `pi in M_Q(F_2)` exchange `q` and
   `q'`, and put `W = pi u`. Then `E' = W E W^(-1) < E`.
2. Put `x = E W^(-1) E'` and `y = E' W E`. Then `xy = E W^(-1) E' W E = E` and `yx = E' W E W^(-1) E' = E'`.
3. So `X = x + 1 - E` and `Y = y + 1 - E` satisfy `XY = 1` and `YX = 1 - (E - E') != 1`.
4. `b -> X` and `a -> Y` define a map `J -> M_Q(S)` sending `1 - ab` to `E - E' != 0`. Every nonzero ideal of `J`
   contains `1 - ab`. Indeed, write `j = sum c_(ii') a^i b^(i')` and choose a diagonal `i - i' = d` on which `j` has
   a nonzero coefficient. Let `k` be the smallest `i` on it, and `l = k - d`. Since `(1 - ab) a = 0 = b (1 - ab)`,
   the element `(1 - ab) b^k j a^l (1 - ab)` is `c_(k, l) (1 - ab)`. So the map is injective.
5. Finite-dimensional algebras are directly finite, and so are their products. If `S` were residually
   finite-dimensional, `M_Q(S)` would embed in `prod M_#Q(S/I)`, which is directly finite. QED

**Corollary 4.4.** `x_0` contracts in every frame `Q != {empty}`. `Q` contains a unique word `0^k` with `k >= 1`, and
`x_0 e_(0^k) x_0^(-1) = e_(0^(k+1)) < e_(0^k)`. So in no nontrivial frame does a configuration containing `x_0` have
residually finite-dimensional coefficients, and Fact 4.1 misses `Gamma_x`. Theorem 3.5 catches it. So Lemma 4.3
limits the coefficient method, not soficity. The trivial frame, where `S` is generated by the configuration itself,
is not settled here.

## 6. Where it stops

**Lemma 6.1.** Let `b = iota_A(w_23) iota_(A1)(w_12)`, which sends `A10 -> A100`, `A110 -> A11` and `A111 -> A101`
(`leavitt-right-child-frames-generate-infinite-order-units`, item 2). Consider total orders on `X` in which, for each
of the frames at `A` and `A1`, all positive roots move points strictly in one common direction. In any such order both
frames move the same way, and no such order is preserved by `b`.

*Proof.*
* **Same direction.** If the frame at `A` moves down, then `[A10] < [A11] ⊇ [A110]`, so `S[A10]T[A110]` moves down.
  It is a root of the frame at `A1`, so that whole frame moves down. The upward case is symmetric.
* **Not preserved.** Downward roots `S[A10]T[A110]` and `S[A110]T[A111]` need `[A10] < [A110] < [A111]`, so
  `[A10] < [A11]`. If `b` preserves the order, then `b[A10] < b[A110] < b[A111]`, that is `[A100] < [A11] < [A101]`.

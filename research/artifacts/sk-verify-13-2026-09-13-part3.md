## 1. The overgroup

**Ultraproduct copy.** The φ_n are injective on `B_n`, multiplicative when `g, h, gh ∈ B_n`, and extended arbitrarily.
- `e·e = e ∈ B_n` gives `φ_n(e) = φ_n(e)^2`, so `φ_n(e) = e`.
- For fixed `γ, δ`, the elements `γ, δ, γδ` lie in `B_n` for all large `n`, and a cofinite set lies in the nonprincipal `ω`.
  So `ι(γ) = (φ_n(γ))_n` is a homomorphism into the algebraic ultraproduct.
- It is injective: for `γ ≠ e`, `φ_n(γ) ≠ φ_n(e) = e` for large `n`.
- Constant functions give an injective homomorphism `∏_ω Q_n → ∏_ω Λ_n`.

**Well-definedness.** `f_q(i) = q^i` on `Z/m_n`: the order of `q` divides `|Q_n|`, which divides `m_n = n|Q_n|`. At the
wrap-around, `f_q(m_n − 1) = q^{-1}`, consistent with `f_q(−1)`.

**Commutator.**
- In `Λ_n = Q_n^{Z/m_n} ⋊ Z/m_n` with `(tft^{-1})(i) = f(i−1)`: `[f_q,t] = f_q·(t f_q^{-1} t^{-1})`.
- The second factor is the base element `i ↦ f_q(i−1)^{-1} = q^{−(i−1)}`.
- Powers of `q` commute, so `[f_q,t](i) = q^i q^{−i+1} = q`. So `[f_q,t] = c_q`.
- In the ultraproduct, commutators are computed coordinatewise, so `[f_s,t] = (c_{φ_n(s)})_n` is the copy of `ι(s)`.

**Γ ≤ [Δ,Δ].** The copy of Γ is generated by the `[f_s,t] ∈ [Δ,Δ]`. So each `s` is a single commutator, and `Δ` has
`|S|+1` generators.

**Infinite.** `t^k = (0, k mod m_n) ≠ e` once `m_n > |k|`, and `m_n ≥ n`.

**LEF.** For finite `F ⊆ Δ` and fixed representatives, the finitely many conditions (distinctness, and products lying in
`F`) each hold ω-a.e., so their intersection is nonempty. Variant A does not use LEF of `Δ`: its models are built from
`∏_ω Λ_n` directly.

**Model tests** (the lane's own, re-checked).
- `Γ = 1` gives `Δ = ⟨t⟩ ≅ Z`.
- `Γ = Z` shows the step is not vacuous.
- Bounded `m_n` could make `Δ` finite.

**Credit.** That constants are commutators in `Q ≀ Z/m` when `|Q|` divides `m` is an elementary wreath-product identity.
No citation is needed, and dropping Ore removes a citation without adding one.

## 2. The note-level route

**Host.**
- `(δ,f)∘(δ′,f′) : x ↦ δ(δ′x + f′) + f`, so `ℓℓ′ = (δδ′, f + δf′)` with `supp δf′ = δ supp f′`. The pair `(δ,f)` is
  determined by the map, since `f = ℓ(0)` and `Δ` acts faithfully.
- `δaδ^{-1} : x ↦ x + 1_δ`, so `Δ` and `a` generate `L`. `L` is f.g. because `Δ` is.
- `Z = F_2^Δ` is a Cantor set, since `Δ` is countably infinite.
- **Minimal:** `x + ⊕_Δ F_2` is dense.

**Topologically free.** Fixed points satisfy `x(h) = x(δ^{-1}h) + f(h)` for all `h`.
- `δ = e`, `f ≠ 0`: this fails at `h ∈ supp f`, for every `x`.
- `δ ≠ e`: take `h ∉ W ∪ δW ∪ supp f`, which exists as `Δ` is infinite. Then `h ∉ W`, `δ^{-1}h ∉ W` and `h ≠ δ^{-1}h`, and
  `f(h) = 0`. So some `x` in the cylinder has `x(h) ≠ x(δ^{-1}h)`.
- Every nonempty basic open set contains a non-fixed point.

**Ring generation.** `u_δ e_{x(e)=1} u_δ^{-1} = e_{x(δ)=1}`. Coordinate indicators and `1` generate `LC(Z,F_2)`.

**Models.** `Y_n = F_2^{Λ_n}` with `(qy)(q′) = y(q^{-1}q′)` is an action, and `q1_p = 1_{qp}`.

**Multiplicativity.**
- `σ_n(ℓ)σ_n(ℓ′)y = κ_n(δ)κ_n(δ′)y + Σ_{h′∈supp f′}1_{κ_n(δ)κ_n(h′)} + Σ_{h∈supp f}1_{κ_n(h)}`.
- For ω-a.a. `n`: `κ_n(δ)κ_n(δ′) = κ_n(δδ′)` and `κ_n(δ)κ_n(h′) = κ_n(δh′)`.
- `κ_n` is injective on `supp f ∪ δ supp f′`, so the F_2-sum of indicators over this multiset is the indicator sum over
  `supp f Δ δ supp f′ = supp(f + δf′)`.
- So `σ_n(ℓ)σ_n(ℓ′) = σ_n(ℓℓ′)`, uniformly in `y`. Also `σ_n(e) = id` ω-a.e., so `σ_n(ℓ)^{-1} = σ_n(ℓ^{-1})`.

**Covariance.**
- `p_n(σ_n(ℓ)y)(h) = y(κ_n(δ)^{-1}κ_n(h)) + #{h′ ∈ supp f : κ_n(h′) = κ_n(h)}`.
- ω-a.e. this equals `y(κ_n(δ^{-1}h)) + f(h) = (ℓ·p_n(y))(h)` for `h` in a fixed finite `H`, uniformly in `y`.

**Conjugation.**
- `U_n(ℓ)D_n(f)U_n(ℓ)^{-1}` is the diagonal of `f∘p_n∘σ_n(ℓ)^{-1} = f∘p_n∘σ_n(ℓ^{-1})`.
- By covariance for `ℓ^{-1}` on the coordinates of `f`, this is `(f∘ℓ^{-1})∘p_n`.
- Then `Φ(fu_k)Φ(f′u_ℓ) = D(f)[U(k)D(f′)U(k)^{-1}]U(k)U(ℓ) = D(f(f′∘k^{-1}))U(kℓ) = Φ((fu_k)(f′u_ℓ))`.
- With exact additivity and `Φ(1) = I`, `Φ` is a unital ring homomorphism `R → ∏_ω M_{|Y_n|}(F_2)`.

**Theorem 2.** Every hypothesis is checked above: `L` f.g.; the action minimal and topologically free on a Cantor set; `R`
f.g.; a unital homomorphism into a matrix ultraproduct. So `EL_3(R)` is infinite, f.g., simple, Kazhdan and LEF.

**Embedding.**
- In characteristic 2, `e_12(c)e_21(c^{-1})e_12(c) = [[0,c],[c^{-1},0]]` and `e_12(1)e_21(1)e_12(1) = [[0,1],[1,0]]`. Their
  product is `diag(c,c^{-1})`.
- `diag(a,a^{-1},1)diag(b,b^{-1},1)diag((ba)^{-1},ba,1) = diag(aba^{-1}b^{-1},1,1)`; the second slot is `a^{-1}b^{-1}ba = 1`.
- `ℓ ↦ diag(u_ℓ,1,1)` is an injective homomorphism (slot 1 only), and `[u_k,u_ℓ] = u_{[k,ℓ]}`. So `[L,L] → G`, and
  `Γ ≤ [Δ,Δ] ≤ [L,L]`.

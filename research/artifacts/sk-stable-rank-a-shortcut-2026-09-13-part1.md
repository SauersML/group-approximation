# sk-stable-rank-a, part 1: can a normal-structure theorem replace the tower proof?

Lane sk-stable-rank-a (SK swarm, 2026-09-13). Question: is the Bass stable rank of `R = LC(X,k) ⋊_T Z`
small enough, or is `R` an exchange ring, so that a classical sandwich theorem gives simplicity of
`EL_3(R)/Z` and the note's tower argument (disk l.154-227) shrinks to a citation?

## 1. The theorems, quoted

**(V) Vaserstein, LNM 854 (1981), Theorem 4.** It is already imported verbatim on main in
`vaserstein-local-stable-range-normal-subgroups`: "Suppose that n ≥ 3 and for every maximal ideal D of the
center C of A there exists a multiplicative set S ⊂ C − D such that sr(S^{-1}A) ≤ n − 1. Then (2) holds."
Statement (2) there: a subgroup `H` of `GL_n A` is normalized by `E_n A` if and only if, for a unique ideal `B`,
the image of `H` in `GL_n(A/B)` is central and `H ⊃ [E_n A, E_n B]`.

**(P) Preusser, arXiv:1912.11386v1 (23 Dec 2019), "On general linear groups over exchange rings", Theorem 3.**
Text extracted with ghostscript on MSI from the arXiv PDF
(`/scratch.global/sauer354/sk/sk-stable-rank-a/a1912.11386.pdf`), lines 47-52 of the extraction:
"Theorem 3. Suppose that R is an exchange ring and n ≥ 3. Let H be a subgroup of GL_n(R). Then H is normalised
by E_n(R) iff there is an ideal I ⊴ R such that E_n(R,I) ⊆ H ⊆ C_n(R,I). Moreover, the ideal I is uniquely
determined."
Lines 136-138 define "C_n(R,I) := φ^{-1}(Center(GL_n(R/I)))", "called the full congruence subgroup of level I",
where φ is induced by `R → R/I`. The journal version was not checked. There is no stable-range hypothesis.

**(B) Bass's range.** This is the survey report, not the primary: arXiv:1510.07143 ("The commutators of classical groups"),
pdftotext extraction lines 94-95: "In his paper, Bass already proved that for a ring A and two sided ideals I, J, and
n ≥ max(sr(A)+1, 3), [E(n,A,I), GL(n,A,J)] = [E(n,A,I), E(n,A,J)]". The survey's §3.4 (extraction line 329) defines sr
with Bass's convention: "sr(A) = n if every unimodular row of length n + 1 is stable". The numdam scan of Bass 1964
has no text layer and was not read.

**Consequence for simple rings** (claim `standard-normal-structure-makes-simple-ring-el-simple`, proof in the
route). Let `R` be a simple ring whose centre is a field `k`, and let `n ≥ 3`. If `R` is an exchange ring or
`sr(R) ≤ n − 1`, then every subgroup of `EL_n(R)` normalized by `EL_n(R)` is central or all of `EL_n(R)`, so
`EL_n(R)/Z(EL_n(R))` is simple.

So for the note, the shortcut exists exactly when `R_X = LC(X,F_2) ⋊ Z` satisfies `sr(R_X) ≤ 2` or is an exchange ring.

## 2. What is known about `R = LC(X,k) ⋊_T Z` for minimal Cantor `(X,T)`

Neither fact is in the literature I found. The bounded searches were:
- web queries on the stable rank or exchange property of algebraic crossed products, Steinberg algebras and skew group rings over Cantor sets;
- the main-graph grep for `stable rank`, `exchange ring` and `Preusser`.

The main node `steinberg-elementary-groups-are-simple-mod-centre` says the same: "nor Vaserstein's stable-range
criteria are known to hold for these algebras". The C*-analogues are theorems but do not transfer:
- `C(X) ⋊ Z` has topological stable rank one (Putnam 1990) and real rank zero, so it is an exchange C*-algebra (AGOP 1998);
- both proofs use norm approximation (compare Archey–Phillips, arXiv:1505.00725).
- `R` is not von Neumann regular.

### 2.1 Calibration: the odometer has stable rank at most two (easy)
Let `X = Z_2` with `T(x) = x+1`, write `e_i = 1_{i + 2^n Z_2}`, `N = 2^n`, and `R_n = span{e_i u^j}`.
- `t = u^N` is central in `R_n`, since `u^N e_i u^{-N} = e_{i+N} = e_i`.
- `E_{il} = e_i u^{i−l}` (0 ≤ i,l < N) are matrix units: `E_{il}E_{l'm} = δ_{ll'} E_{im}`.
- `u = Σ_{i<N−1} E_{i+1,i} + E_{0,N−1} t`.

So `R_n ≅ M_N(k[t^{±1}])`, and `R_odo = ⋃_n R_n`. Unimodular rows and their witnesses lie in some `R_n`, so
`sr(R_odo) ≤ sup_n sr(M_N(k[t^{±1}])) ≤ 2`. The last bound is Vaserstein's matrix formula
`sr(M_N(A)) = ⌈(sr(A)−1)/N⌉+1` with `sr(k[t^{±1}]) ≤ 2` (recalled, not re-verified here).
The odometer is not expansive and its algebra is not finitely generated, so this is a calibration only.

**Why it does not extend to subshifts.** For an expansive `X` and a finite clopen partition `P` refining the letter
partition, the subring generated by `u` and the `P`-measurable functions is all of `R`. The finite-type subrings
`M_N(k[t^{±1}])` that exhaust the odometer algebra come from `T`-invariant partitions, which a subshift lacks.

### 2.2 A Laurent obstruction that the towers remove (verified)
Take `k = F_2` and `a = u + u^2`, so `1 − a = p := 1 + u + u^2`.
- In `F_2[u^{±1}]` the element `a` is not suitable in Nicholson's sense. The only idempotents are 0 and 1, and neither `a` nor `p` is a unit.
- In `R` it is suitable. Choose a clopen `Y` whose return times are all ≥ 3, with Kakutani–Rokhlin towers `T^i Y_h`, 0 ≤ i < h.
  - Put `Φ = Σ_h Σ_{0≤i<h} u^{−i} e_{T^i Y_h}` ∈ `R`. It sends each level of a tower to its base: `Φδ_z = δ_{b(z)}` in the orbit representation.
  - Then `Φ p Φ = Φ`, since `Φ p δ_b = Φ(δ_b + δ_{b+1} + δ_{b+2}) = 3δ_b = δ_b`, using heights ≥ 3.
  - So `pΦ` is idempotent, and `e := 1 + pΦ` is idempotent with `1 − e = pΦ ∈ pR`.
  - Moreover `e = 1 + Φ + u(1+u)Φ = (1+u)(ρ_0 + uΦ)`, where `ρ_0 = Σ_h Σ_{i<h} Σ_{0≤j<i} u^{j−i} e_{T^i Y_h}` satisfies `(1+u)ρ_0 δ_z = δ_z + δ_{b(z)}`.
  - Since `aR = (1+u)R`, `e ∈ aR`.

So `R` repairs the failure of the exchange property for the Laurent polynomial `u + u^2`, using an idempotent that
lives in the locally matricial subalgebra `A_Y`.

### 2.3 Nonzero one-sided ideals contain idempotents (verified, necessary for exchange since J(R) = 0)
Let `0 ≠ c = Σ_j f_j u^j` and choose `j_0` with `f_{j_0} ≠ 0`. Take a nonempty clopen `W` on which
`f_{j_0}∘T^{j_0}` is a constant `γ ∈ k^×`, and with `W ∩ T^{i}W = ∅` for the finitely many `i = j − j_0 ≠ 0` that occur.
Put `r = γ^{-1} e_W u^{−j_0}`. Since `u^{−j_0} f = (f∘T^{j_0}) u^{−j_0}`,
`e_W u^{−j_0} c e_W = Σ_j e_W (f_j∘T^{j_0}) e_{T^{j−j_0}W} u^{j−j_0} = γ e_W`, so `r c r = r`.
Then `d = rc ∈ Rc` satisfies `d^2 = (rcr)c = d`, and `d ≠ 0` because `r = rcr ≠ 0`. So `d` is a nonzero idempotent in `Rc`.
This is the note's local-annihilation step, and it holds in every simple Steinberg algebra.

## 3. Status of the two ring facts (open; attempts in the nodes)
- `minimal-cantor-crossed-product-has-stable-rank-at-most-two`: OPEN.
- `minimal-cantor-crossed-product-is-an-exchange-ring`: OPEN.

For separative exchange rings, AGOP (1998) gives sr ∈ {1, 2, ∞} (recalled). If `R` is an exchange ring and `V(R)` is
cancellative (expected from `K_0(R) =` coinvariants, `subshift-crossed-product-k0-is-coinvariant-group`), the
second fact would likely imply the first. Preusser does not need it, though.

Dead or circular routes:
- **Morita bootstrapping.** Exchange is Morita invariant, and the stable rank of `R ≅ End_S(S^h ⊕ Q)` with
  `S = e_Y R e_Y` would drop to ≤ 2 through the matrix formula once ANY uniform finite bound on sr over all minimal
  Cantor crossed products is known. But `S` is again such a crossed product (the induced system), and no a priori bound is known.
  Corners do not bound the stable rank: `Z[x]` is a corner of `M_2(Z[x])`.
- **Stafford's Krull-dimension bound.** It needs Noetherian rings. `R` is not Noetherian: the left ideals `R e_{U_n}` form strictly increasing chains when `U_n` increase to a non-clopen open set.
- **Direct limits.** They work for the odometer (2.1), and fail for subshifts because the generators already give `R`.
- **The large subalgebra `A_Y`.** It is locally matricial, hence unit-regular, exchange and of stable rank 1. Every `a ∈ R` of degree `≤ w` is `a_Y + δ` with `a_Y ∈ A_Y`, where `δ` is supported in a band of width `2w` around the cuts and lies in `A_{Y'}` for a shifted cut `Y'`. No exact algebraic argument that assembles the two locally matricial pieces was found.

## 4. Consequence for the note (preliminary verdict)
- The citation route would replace l.154-227 (~73 lines) by about six lines. It needs `sr(R_X) ≤ 2` or "R_X is an exchange ring".
- Neither is citable, and every proof attempt so far builds the same Kakutani–Rokhlin towers the note uses.
- A hybrid route applies Preusser or Bass to the locally matricial ring `F_2(1−e) ⊕ B_m(U)` in which the commutator `k` of the note lives. It is a heavier restatement of l.202-221, where the case needed is a finite product of groups `GL_d(F_2)`. It is not shorter.

Verdict so far: **keep the self-contained tower proof.** The proposal artifact records the conditional six-line text
for the day a short proof or citation of either ring fact exists.

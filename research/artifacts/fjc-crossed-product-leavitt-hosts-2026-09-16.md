## 1. Conventions

- Rings are unital. `k` is a field, `L = L_k(1,2)` is generated by
  `x_1, x_2, y_1, y_2` with `y_i x_j = δ_ij` and `x_1 y_1 + x_2 y_2 = 1`.
- **Regular coherent** (Bartels–Lück): every finitely presented module has a
  finite resolution by finitely generated projective modules. This implies
  coherence: for a finitely generated ideal `I`, `A/I` is finitely presented,
  hence of type `FP_infinity`, so `I` is finitely presented. For coherent rings
  it is equivalent to "every finitely presented module has finite projective
  dimension" (Ara–Brustenga–Cortiñas): take a resolution by finitely generated
  free modules and truncate at a syzygy, which is projective and finitely
  generated.
- **Crossed products** (Bartels–Reich, as imported in
  `crossed-product-rings-inherit-fjc-with-additive-coefficients`). `α : P -> Aut(R)`
  with `α_e = id`, and `τ : P × P -> R^x` with

  ```text
  (C1)  τ_(g,h) τ_(gh,k) = α_g(τ_(h,k)) τ_(g,hk),
  (C2)  τ_(g,h) α_(gh)(r) = α_g(α_h(r)) τ_(g,h).
  ```

  `A = R_(α,τ)P = ⊕_(g∈P) R g` with `(r g)(s h) = r α_g(s) τ_(g,h) gh`. For a
  subgroup `H`, `R_(α|,τ|)H = ⊕_(h∈H) R h ⊆ A`.
- **Skew Laurent rings.** `S_φ[s, s^−1]` for an automorphism `φ` of `S` means
  `⊕_n S s^n` with `s a = φ(a) s`. The opposite convention `a s = s φ(a)` is the
  same ring for `φ^−1`, so a statement for all automorphisms covers both.

## 2. Crossed products over the trivial and infinite cyclic subgroups

**Lemma 2.1 (the unit and the trivial subgroup).** Put `c = τ_(e,e)`.

1. `c` is central in `R`.
2. `τ_(e,k) = c` for every `k`, and `τ_(g,e) = α_g(c)` for every `g`.
3. `1_A = c^−1 e`.
4. `ι : R -> A`, `r |-> r c^−1 e`, is an injective unital ring homomorphism with
   image `A_e := R e = R_(α|,τ|){e}`.

*Proof.*
1. (C2) with `g = h = e` and `α_e = id` gives `c r = r c`.
2. (C1) with `g = h = e` gives `c τ_(e,k) = τ_(e,k) τ_(e,k)`; cancel the unit
   `τ_(e,k)`. (C1) with `h = k = e` gives `τ_(g,e) τ_(g,e) = α_g(c) τ_(g,e)`;
   cancel `τ_(g,e)`.
3. `(c^−1 e)(s h) = c^−1 s τ_(e,h) h = c^−1 s c h = s h`, by 1 and 2. And
   `(s h)(c^−1 e) = s α_h(c)^−1 τ_(h,e) h = s α_h(c)^−1 α_h(c) h = s h`.
4. `ι(r) ι(s) = r c^−1 s c^−1 τ_(e,e) e = r s c^−1 e = ι(rs)`, using centrality
   of `c`, and `ι(1) = 1_A` by 3. It is injective because `A` is a free left
   `R`-module on `P`. Its image is `R e`, since `c` is a unit. ∎

**Lemma 2.2 (infinite cyclic subgroups give skew Laurent rings).** Let `g ∈ P`
have infinite order, `H = <g>`, `A_H = R_(α|,τ|)H = ⊕_(n∈Z) R g^n`, and
`t = 1·g ∈ A_H`. Then:

1. `t` is a unit of `A_H`, and `t^n ∈ R^x g^n` for every `n ∈ Z`;
2. `φ = Ad(t)` restricts to a ring automorphism of `A_e`;
3. `Ψ : (A_e)_φ[s, s^−1] -> A_H`, `Σ a_n s^n |-> Σ a_n t^n`, is a ring
   isomorphism.

*Proof.* `A_H` is `Z`-graded by `(A_H)_n = R g^n`, because
`(r g^n)(s g^m) ∈ R g^(n+m)`. Its degree-zero part is `A_e`.

- **Homogeneous elements with unit coefficients.** If `r, s ∈ R^x`, then
  `(r g^n)(s g^m) = r α_(g^n)(s) τ_(g^n,g^m) g^(n+m)` has a unit coefficient.
- **`t` is a unit.**
  - `t (1 g^−1) = τ_(g,g^−1) e = ι(τ_(g,g^−1) c)`. This is a unit of `A_e`,
    because `ι` is a unital homomorphism. Call it `v`.
  - Likewise `(1 g^−1) t = ι(τ_(g^−1,g) c)` is a unit of `A_e`.
  - So `t` has a right and a left inverse, hence is a unit, and
    `t^−1 = (1 g^−1) v^−1`.
  - Write `v^−1 = ι(w) = w c^−1 e` with `w ∈ R^x`. Then
    `t^−1 = α_(g^−1)(w c^−1) τ_(g^−1,e) g^−1`, with a unit coefficient.
- **Powers.** By the first bullet and induction, `t^n ∈ R^x g^n` for every
  `n ∈ Z`. This is part 1.
- **Degree components.** Write `t^n = u_n g^n` with `u_n ∈ R^x`. For `r ∈ R`,
  `ι(r) t^n = r c^−1 u_n τ_(e,g^n) g^n = r u_n g^n`, using `τ_(e,g^n) = c` and
  centrality of `c`. As `r` runs over `R`, so does `r u_n`. Hence
  `(A_H)_n = A_e t^n`.
- **Part 2.** `t A_e t^−1` and `t^−1 A_e t` lie in degree zero, which is `A_e`.
- **Part 3.**
  - `Ψ` is a ring homomorphism, because `t a = φ(a) t` in `A_H`.
  - It is onto by the degree components.
  - It is injective: `a_n t^n ∈ (A_H)_n`, so `Σ a_n t^n = 0` forces every
    `a_n t^n = 0`, and `t^n` is a unit. ∎

**Remark 2.3.** Lemma 2.2 uses only that `g` has infinite order. For a finite
subgroup `H`, `R_(α|,τ|)H` is a crossed product by a finite group and is not a
Laurent ring. Theorem A does not say anything about it, which is why it assumes
`P` torsion-free. For example, over a field of characteristic `2` the group ring
`k[Z/2] ≅ k[ε]/(ε^2)` is not regular.

## 3. Theorem A

**Theorem A.** Let `P` be a torsion-free group that satisfies the `K`-theoretic
Farrell–Jones conjecture with additive categories as coefficients, with respect
to `VCyc`. Let `R` be a ring such that:

- `K_n(R) = 0` for every `n ∈ Z`;
- `R[Z^m]` is regular coherent for every `m >= 0`.

Then `K_n(R_(α,τ)P) = 0` for every `n ∈ Z` and every crossed product
`R_(α,τ)P`.

*Proof.* Put `A = R_(α,τ)P`, and let `𝒜 = A_(α,τ)` be the additive `P`-category
of the import.

1. **Assembly.** By `crossed-product-rings-inherit-fjc-with-additive-coefficients`,
   part 2, `H_n^P(E_VCyc P; K_𝒜) -> K_n(A)` is bijective for every `n`.
2. **The family.** `P` is torsion-free, so every virtually cyclic subgroup is
   trivial or infinite cyclic. An infinite virtually cyclic group has a finite
   normal subgroup with quotient `Z` or `D_∞`. Torsion-freeness kills the finite
   subgroup and rules out `D_∞`. This is standard and was not re-derived.
3. **Orbit values.** By part 1 of the import,
   `H_n^P(P/H; K_𝒜) ≅ K_n(R_(α|,τ|)H)`.
   - `H = 1`: `R_(α|,τ|){e} = A_e ≅ R` by Lemma 2.1, so these groups vanish.
   - `H = <g> ≅ Z`: by Lemma 2.2, `R_(α|,τ|)H ≅ (A_e)_φ[s, s^−1]` with
     `A_e ≅ R`. Then `A_e[Z^m] ≅ R[Z^m]` is regular coherent for every `m`, and
     `K(A_e) ≃ 0`. By `regular-coherent-laurent-coefficients-kill-twisted-nil-terms`,
     `K_n(R_(α|,τ|)H) = 0` for every `n`.
4. **Vanishing on `E_VCyc P`.** Choose a model of `E_VCyc P` that is a `P`-CW
   complex `Y` with all isotropy groups in `VCyc`. Write `Y_j` for its skeleta.
   `H_*^P(−; K_𝒜)` is a `P`-homology theory in the sense of Davis–Lück, so:
   - `Y_j` is a pushout of `Y_(j−1) <- ∐_i P/H_i × S^(j−1) -> ∐_i P/H_i × D^j`,
     with every `H_i ∈ VCyc`;
   - excision and the disjoint union axiom give
     `H_*^P(Y_j, Y_(j−1)) ≅ ⊕_i H_(*−j)^P(P/H_i)`, which is `0` by Step 3;
   - by induction on `j` and the long exact sequence of the pair,
     `H_*^P(Y_j) = 0` for every `j`;
   - `H_*^P(Y) = colim_j H_*^P(Y_j) = 0`.
   These are standard properties of homology theories given by `Or(P)`-spectra.
   They were not re-read here, as in Step 4 of
   `leavitt-tensor-powers-k-vanishing-via-farrell-jones-proof`.
5. **Conclusion.** `K_n(A) ≅ H_n^P(E_VCyc P; K_𝒜) = 0` for every `n`. ∎

**Instances of the hypothesis on `P`.**
- **Verified at theorem level in the graph.** Torsion-free virtually poly-`Z`
  groups, for example `Z^d`, by
  `virtually-poly-z-groups-satisfy-fjc-with-additive-coefficients`
  (Bartels–Farrell–Lück, arXiv:1101.0469).
- **Abstract level only.** Wegner, *The Farrell–Jones Conjecture for virtually
  solvable groups*, arXiv:1308.2432 (J. Topol., DOI 10.1112/jtopol/jtv026). The
  abstract reads: "We prove the K- and L-theoretic Farrell-Jones Conjecture (with
  coefficients in additive categories) for virtually solvable groups." It was
  fetched 2026-09-16. The theorem statement inside the paper was not read,
  because the e-print download failed through the proxy. It covers `Z wr Z`.
- **Not used.** Bartels–Lück–Reich arXiv:math/0701434 (hyperbolic groups) states
  "(twisted) coefficients in any associative ring with unit" in its abstract.
  It was not checked whether "twisted" there covers the skew group rings of
  Theorem B, or how its orbit values compare with Step 3, so it is not used.

## 4. The coefficient ring `LC(X, L)`

Let `X` be a nonempty compact Hausdorff space. For a `k`-algebra `D`, `LC(X, D)`
is the ring of locally constant functions `X -> D`, with pointwise operations.

- A locally constant function on compact `X` has finite image and clopen fibres.
  So `LC(X, D) = ⋃_𝒫 D^𝒫`, where `𝒫` runs over finite clopen partitions of `X`,
  directed by refinement, and `D^𝒫 ≅ ∏_(U∈𝒫) D` is the subring of functions
  constant on each block.
- If `𝒬` refines `𝒫`, let `U(V) ∈ 𝒫` be the block containing `V ∈ 𝒬`.

**Lemma 4.1 (identification).** `μ : LC(X, k) ⊗_k D -> LC(X, D)`,
`f ⊗ d |-> (x |-> f(x) d)`, is a ring isomorphism. It is natural in `D`, and
intertwines `f |-> f ∘ h^−1` with `F |-> F ∘ h^−1` for every homeomorphism `h`
of `X`.

*Proof.* `μ` is a ring homomorphism because `k` is central. On `k^𝒫 ⊗ D` it is
the isomorphism `(∏_U k) ⊗ D ≅ ∏_U D`, since finite products are finite direct
sums. Tensor products commute with directed unions, so `μ` is the directed
union of these isomorphisms. The last two properties are clear. ∎

**Lemma 4.2.** `K_n(LC(X, L)) = 0` for every `n ∈ Z`.

*Proof.*
- `K_n(L^𝒫) = ⊕_(U∈𝒫) K_n(L) = 0`, by Ara–Cortiñas Proposition 6.2 ("the
  algebraic K-theories of L_2 and of L_2 ⊗ R are both trivial"), imported in
  `ara-cortinas-leavitt-tensor-k-theory-vanishes`.
- Non-connective `K`-theory commutes with directed colimits of rings. This is
  the same standard fact used in route `leavitt-crossed-product-coefficient-ring-proof`.
- Hence `K_n(LC(X, L)) = colim_𝒫 K_n(L^𝒫) = 0`. ∎

**Lemma 4.3.** For every `m >= 0`, `LC(X, L)[Z^m]` is regular coherent, for left
and for right modules.

*Proof.* Put `A_m = L[t_1, ..., t_m]` and `Λ_m = L[Z^m]`.

1. **Polynomial rings.** `A_m` is regular coherent, by Ara–Cortiñas Lemma 6.1
   ("L(E) is regular supercoherent", that is, every polynomial ring over it is
   regular coherent), with the conventions of Section 1.
   - **Sides.** `x_i |-> y_i`, `y_i |-> x_i` defines a `k`-linear
     anti-automorphism `*` of `L`: `(y_i x_j)^* = y_j x_i = δ_ij` and
     `(x_1 y_1 + x_2 y_2)^* = x_1 y_1 + x_2 y_2`.
   - Extend `*` to `A_m`, `Λ_m` and `LC(X, Λ_m)` by fixing the `t_j` and acting
     pointwise. It interchanges left and right modules and preserves finite
     presentation and finite projective resolutions.
   - So each ring below is regular coherent on the left iff it is on the right.
2. **Central localization.** `Λ_m = S^−1 A_m`, where `S` is the set of monomials
   in the central variables `t_j`.
   - `S^−1 A_m ⊗_(A_m) M ≅ k[Z^m] ⊗_(k[t]) M`, so `S^−1 A_m` is flat over `A_m`.
   - Every element of `S^−1 A_m` has the form `s^−1 a`. So a finite presentation
     matrix over `Λ_m` is `s^−1 D'` with `D'` over `A_m`, and its cokernel is
     `Λ_m ⊗_(A_m) coker(D')`.
   - Base change of a finite resolution of `coker(D')` by finitely generated
     projective modules gives one for the original module.
   - So `Λ_m` is regular coherent.
3. **Finite products.** A module `M` over `∏_(j≤N) Λ_m` is `⊕_j e_j M`. It is
   finitely presented iff every `e_j M` is. Resolutions of the pieces add up to
   a resolution of `M`, of length at most the maximum length. So `Λ_m^𝒫` is
   regular coherent.
4. **The colimit.**
   `LC(X, L)[Z^m] = LC(X, L) ⊗_k k[Z^m] ≅ LC(X, Λ_m) = ⋃_𝒫 Λ_m^𝒫`, by Lemma 4.1.
5. **Flat transition maps.** Let `D` be a ring and let `𝒬` refine `𝒫`.
   - As a left or right `D^𝒫`-module, `D^𝒬 = ⊕_(V∈𝒬) D e_V`.
   - `D^𝒫` acts on `D e_V` through its `U(V)`-coordinate, so
     `D e_V ≅ D^𝒫 e_(U(V))`.
   - So `D^𝒬` is a finitely generated projective `D^𝒫`-module on each side.
   - The union `⋃_𝒬 D^𝒬` is a directed colimit of flat `D^𝒫`-modules, hence flat
     over `D^𝒫` on each side.
6. **Descent.** Let `M` be a finitely presented module over
   `Λ_∞ = ⋃_𝒫 Λ_m^𝒫`.
   - Its presentation matrix has entries in some `Λ_m^𝒫`, so
     `M ≅ Λ_∞ ⊗_(Λ_m^𝒫) M_𝒫` with `M_𝒫` finitely presented over `Λ_m^𝒫`.
   - `M_𝒫` has a finite resolution by finitely generated projective modules,
     by Step 3.
   - Base change along the flat extension of Step 5 gives such a resolution of
     `M`. ∎

This is the argument of Step 2 of `leavitt-crossed-product-coefficient-ring-proof`
(flat directed unions) and Step 3.2 of
`leavitt-tensor-powers-k-vanishing-via-farrell-jones-proof` (central
localization), applied to the Boolean dilation `LC(X, −)`.

## 5. Theorem B

**Theorem B.** Let `k` be a field and `L = L_k(1,2)`. Let `P` be a torsion-free
group satisfying the `K`-theoretic Farrell–Jones conjecture with additive
categories as coefficients, with respect to `VCyc`. Let `P` act by
homeomorphisms on a nonempty compact Hausdorff space `X`. Put
`B = LC(X, k) ⋊ P = LC(X, k)_(α,1)P` with `α_g(f) = f ∘ g^−1`.

1. `K_n(B ⊗_k L) = 0` for every `n ∈ Z`. In particular `K_1` and `K_2` vanish.
2. If `P` has a finitely generated subgroup `S` that is not of type
   `FP_infinity` over `k`, then `B` is not left coherent.

*Proof of 1.*
- **The tensor product is a crossed product.** As a vector space,
  `B ⊗ L = ⊕_g (LC(X, k) ⊗ L) g`, with `(f g) ⊗ a` written `(f ⊗ a) g`.
  - In `B ⊗ L`, `((f g) ⊗ a)((f' h) ⊗ a') = (f α_g(f') gh) ⊗ a a'`.
  - So `B ⊗ L = (LC(X, k) ⊗ L)_(α⊗id, 1)P`.
- **Transport.** By Lemma 4.1 this is isomorphic to `LC(X, L)_(α',1)P` with
  `α'_g(F) = F ∘ g^−1`.
  - `α'` is a homomorphism `P -> Aut(LC(X, L))` with `α'_e = id`.
  - `τ ≡ 1` satisfies (C1) and (C2).
  - So this is a crossed product in the sense of Section 1.
- **Apply Theorem A.** `R = LC(X, L)` has `K(R) ≃ 0` by Lemma 4.2, and every
  `R[Z^m]` is regular coherent by Lemma 4.3. Theorem A gives
  `K_n(B ⊗ L) = 0` for every `n`. ∎

*Proof of 2.*
- **`B` is free over `k[P]`.** `LC(X, k) ⊗_k k[P] -> B`, `f ⊗ g |-> f g`, is
  bijective and right `k[P]`-linear, since `(f g)(1 h) = f gh`. So `B` is a free
  right `k[P]`-module on any `k`-basis `{f_j}` of `LC(X, k)`. Such a basis can
  contain `1`, since `X` is nonempty.
- **`B` is free over `k[S]`.** `k[P] = ⊕_c c k[S]` over a set of left coset
  representatives `c` containing `e`. So `B` is a free right `k[S]`-module with
  basis `{f_j c}`, which contains `1`.
- **Summand.** `B` is flat over `k[S]`, and `k[S] = 1·k[S]` is a direct summand
  of `B` as a right `k[S]`-module. It is a unital subalgebra.
- **Contradiction.** If `B` were left coherent,
  `coherent-flat-group-algebra-hosts-force-fp-infinity`(1) would make every
  finitely generated subgroup of `S`, including `S`, of type `FP_infinity` over
  `k`. ∎

**Example 5.1 (Wegner at abstract level, not wired).** `P = Z wr Z` is
torsion-free. It is not of type `FP_2` over any field, by the consequence
recorded in `coherent-flat-group-algebra-hosts-force-fp-infinity`. It is solvable,
so it satisfies the hypothesis by Wegner arXiv:1308.2432 (abstract). For every
compact `P`-space `X`, `B = LC(X, k) ⋊ (Z wr Z)` is not left coherent, and still
`K(B ⊗ L) ≃ 0`.
- With `X` a point, `B = k[Z wr Z]` and `B ⊗ L = L[Z wr Z]`.
- `Z wr Z` is finitely generated metabelian, hence residually finite (P. Hall).
  So it acts freely and minimally on a profinite completion along a chain of
  finite-index normal subgroups with trivial intersection. That gives candidate
  hosts `LC(X, k) ⋊ (Z wr Z)` with `X` a Cantor set. Their simplicity and
  finite presentation are not checked here.

**Remark 5.2 (the free minimal `Z^2`-SFT hosts).** With `P = Z^2` the hypothesis
is the verified import `virtually-poly-z-groups-satisfy-fjc-with-additive-coefficients`.
So for every `Z^2`-space `X`, `K(LC(X, k) ⋊ Z^2 ⊗ L) ≃ 0`.

In the setting of `free-minimal-z2-sft-is-quantum-rigid` and
`fp-simple-rank-model-algebra-via-rigid-free-minimal-sft`, a free minimal
`Z^2`-SFT `Ω` that is `D`-quantum rigid over `k = F_2` would give, by
`sft-crossed-product-fp-iff-quantum-rigid` (unreviewed) and
`free-minimal-crossed-products-are-simple-with-rank-models` (unreviewed), an fp
central simple `R = LC(Ω, F_2) ⋊ Z^2` with
`K_1(R ⊗ L) = K_2(R ⊗ L) = 0`, and hence by `leavitt-tensor-hosts-acyclic-steinberg-and-fp`
and `central-simple-leavitt-tensor-unit-groups-are-simple` an fp simple group
`(R ⊗ L)^x`.

The `Contrast` line of `rigid-sft-elementary-group-mod-centre-is-fp` names
`K_2`-regularity of `B ⊗ L` as the Leavitt gate. For these hosts it is now
automatic. Not wired: no current target consumes that single group.

**Sanity checks.**
- `P = Z`, `X` an infinite minimal subshift, `k = F_2`.
  `minimal-cantor-crossed-product-k-theory-formula` gives `K_1(B) = Z`. Theorem B
  says `K_1(B ⊗ L) = 0`.
  - This is consistent: the image of `K_*(B)` in `K_*(B ⊗ L)` is zero for every
    `B`. In degree `1` this is `leavitt-tensor-kills-k1-of-coefficient-matrices`;
    Section 8 gives the same corner swindle in every degree.
- Trivial action on a point, `P = Z^2`. `B ⊗ L = L[Z^2]`. Apply the untwisted
  case of `regular-coherent-laurent-coefficients-kill-twisted-nil-terms` twice,
  with Lemma 4.3 for `X` a point. Starting from `K(L) ≃ 0`, it gives
  `K(L[Z^2]) ≃ 0`, as Theorem B predicts.
- The theorem does not contradict `coherent-flat-group-algebra-hosts-force-fp-infinity`.
  That claim constrains coherent hosts, and Theorem B.2 says the hosts here are
  not coherent.

## 6. Necessary shape of a Cantor crossed product host

Let `X` be a nonempty compact totally disconnected Hausdorff `P`-space, and
`B = LC(X, k) ⋊ P`.

**Lemma 6.1 (finite generation).** If `B` is finitely generated as a
`k`-algebra, then `P` is finitely generated and `X` is conjugate to a
`P`-subshift, a closed invariant subset of `𝒜^P` for a finite alphabet `𝒜`.

*Proof.* Let `b_1, ..., b_r` generate `B`. Write `b_i = Σ_(g∈F_i) f_(i,g) g` with
finite supports `F_i`, and put `F = ⋃ F_i` and `Φ = {f_(i,g)}`.
- **`P` is finitely generated.** Every product of generators is supported in
  the monoid generated by `F`. Since `B ∋ g` for all `g`, that monoid is `P`.
- **Products of homogeneous pieces.**
  `(f_1 g_1)(f_2 g_2)⋯(f_j g_j) = f_1 α_(g_1)(f_2)⋯α_(g_1⋯g_(j−1))(f_j) g_1⋯g_j`.
  So the degree-`e` part `B_e = LC(X, k)` is contained in the subalgebra
  generated by the translates `α_P(Φ)`.
- **Separation.** Let `𝒫` be the finite clopen partition generated by the fibres
  of the functions in `Φ`. The translates of `𝒫` generate the Boolean algebra of
  clopen sets, so they separate points.
- **The subshift.** `x |-> (h |-> the block of 𝒫 containing h^−1 x)` is an
  injective continuous equivariant map `X -> 𝒫^P`. It is a conjugacy onto its
  image because `X` is compact. ∎

**Lemma 6.2 (simplicity forces an infinite minimal system).** Let `P` be
infinite. If `B` is simple, the action is minimal and `X` is infinite.

*Proof.*
- **Minimality.** Let `Y ⊊ X` be nonempty, closed and invariant.
  - Restriction `LC(X, k) -> LC(Y, k)` is equivariant and onto: clopen subsets
    of `Y` are traces of clopen subsets of `X`, since `X` is compact and totally
    disconnected. It induces a surjection `B -> LC(Y, k) ⋊ P`.
  - The kernel is proper, because `Y ≠ ∅`.
  - The kernel is nonzero: the open set `X \ Y` contains a nonempty clopen set
    `U`, and `1_U` lies in the kernel.
  - So `B` is not simple.
- **Infinite.** If `X` is finite, put `ρ(f) δ_x = f(x) δ_x` and
  `ρ(g) δ_x = δ_(gx)` on `k^X`.
  - Covariance holds: `ρ(g) ρ(f) ρ(g)^−1 = ρ(α_g(f))`.
  - So `ρ` is a unital homomorphism `B -> End_k(k^X)`, with finite-dimensional
    image.
  - `B` is infinite-dimensional because `P` is infinite, so `ker ρ` is a
    nonzero proper ideal. ∎

**Lemma 6.3 (centre).** If the action is minimal and topologically free (every
`g ≠ e` has a fixed-point set with empty interior), then `Z(B) = k`.

*Proof.* Let `z = Σ_g f_g g` be central.
- **Off-diagonal terms.** For `h ∈ LC(X, k)`, `h z = z h` gives
  `f_g (h − α_g(h)) = 0` for every `g`.
  - Suppose `g ≠ e` and `f_g ≠ 0`. Then `f_g` is nonzero on a nonempty clopen
    set `U` on which it is constant.
  - Topological freeness gives `x ∈ U` with `g^−1 x ≠ x`. Choose a clopen `h`
    with `h(x) ≠ h(g^−1 x)`. Evaluating at `x` contradicts the identity above.
  - So `z = f_e ∈ LC(X, k)`.
- **Diagonal term.** Commuting with every `g` gives `α_g(f_e) = f_e`. An invariant
  locally constant function on a minimal system is constant: each fibre is
  clopen and invariant. ∎

For free minimal actions of `Z^d` over finite fields, simplicity is
`free-minimal-crossed-products-are-simple-with-rank-models`. For general `P`,
simplicity of `LC(X, k) ⋊ P` for minimal topologically free actions is the
Steinberg-algebra simplicity criterion for effective minimal Hausdorff ample
groupoids. That criterion was not re-read here and is not used by any node.

## 7. The reduction, and where the attacks on existence die

**Route `fp-central-simple-hosts-via-cantor-crossed-products`.** Let `G` be
finitely generated with solvable word problem.
- `decidable-group-algebras-have-fp-cantor-crossed-hosts` gives `P`, `X` and
  `B = LC(X, F_2) ⋊ P`. `B` is finitely presented, simple, with centre `F_2`,
  and contains `F_2[G]` unitally. `P` is torsion-free and satisfies the
  Farrell–Jones hypothesis.
- Theorem B.1 with `k = F_2` gives `K_1(B ⊗ L) = K_2(B ⊗ L) = 0`.

That is the statement of `decidable-group-algebras-have-fp-central-simple-hosts`.

**The open claim is at least as hard as Boone–Higman.** Through
`boone-higman-via-central-simple-leavitt-tensor-host` it implies
`boone-higman-conjecture`, granted that chain (conditional on Khanh
arXiv:2609.08428v1; see "Downstream trust" in Section 9). A proof must produce hosts of unbounded word-problem
complexity (`complexity-bounded-host-classes-are-not-universal`): no single
`(P, X)` works.

**Attacks.**

1. **`P = Z`. Dies.**
   - A simple `B` forces an infinite minimal system (Lemma 6.2).
   - A finitely presented `B` is finitely generated, so `X` is a minimal
     subshift (Lemma 6.1).
   - `minimal-subshift-crossed-product-is-not-finitely-presented` then says `B`
     is not finitely presented.
   - The same holds for every `P` whose finitely generated crossed products of
     infinite minimal subshifts are never finitely presented. For `Z` that is
     the LEF argument.
2. **`P = Z^2`. Gated on an open claim.**
   - `fp-subshift-crossed-products-are-sfts` (unreviewed) makes `X` an SFT, and
     `sft-crossed-product-fp-iff-quantum-rigid` (unreviewed) makes finite
     presentation equivalent to quantum rigidity.
   - Simplicity forces minimality (Lemma 6.2). For abelian `P`, a minimal action
     with a non-freely-acting `g` has `g` acting trivially, and then `g` is a
     non-scalar central element. So the action must be free.
   - Free minimal gives central simple, by `free-minimal-crossed-products-are-simple-with-rank-models`.
   - Existence of one free minimal `Z^2`-SFT that is quantum rigid over `F_2`
     is the `F_2` form of the open `free-minimal-z2-sft-is-quantum-rigid`, which
     asks for rigidity over some field.
   - Even granted, each `Ω` is one host. The Følner rank model of
     `free-minimal-crossed-products-are-simple-with-rank-models`(2) is an
     injective unital `B -> ∏_ω M_(n^d)(F_2)/{rank-null}`. Restricting it to
     units embeds `G <= B^x` in a rank ultraproduct of general linear groups over
     `F_2`, so `G` would be `F_2`-linear sofic (compare
     `rank-modelled-simple-rings-give-linear-sofic-projective-el`). So the `Z^d` case of the open claim would make every finitely
     generated group with solvable word problem `F_2`-linear sofic. That is not
     known to be false, but it ties this case to an open approximation problem.
3. **Amenable `P` in general. Heuristic only.**
   - For free minimal actions one expects Følner rank models from invariant
     measures, as for `Z^d`. This is not proved in the graph for other amenable
     groups.
   - It would give the same linear-soficity consequence as attack 2.
4. **`P = F_d`, `X = ∂F_d`. One host, so it dies for universality.**
   - `boundary-crossed-product-is-a-leavitt-path-algebra` gives
     `B_∂ ≅ L_(F_2)(E_d)`. That is finitely presented, simple (reviewed), and has
     centre `F_2` by Lemma 6.3: the action is minimal, and topologically free
     since each `g ≠ e` fixes two points.
   - `B_∂` contains `F_2[F_d]`.
   - `B_∂` is regular supercoherent by Ara–Cortiñas Lemma 6.1, so
     `K(B_∂ ⊗ L) ≃ 0` already by Proposition 6.2. Theorem B is not needed there,
     and `F_d` is not covered by the imported Farrell–Jones instances anyway.
   - It is one finitely presented algebra, so
     `complexity-bounded-host-classes-are-not-universal` rules out universality.
   - Varying the `F_d`-subshift `X` is the natural family. No finite-presentation
     criterion for `LC(X, k) ⋊ F_d` exists in the graph. The local-presentation
     proof of `fp-subshift-crossed-products-are-sfts` was written for `Z^2` and
     was not checked to extend.
5. **Hosts from Boone–Higman embeddings of hyperbolic groups. Out of scope.**
   Belk–Bleak–Matucci–Zaremsky, arXiv:2309.06224, use groups acting on Cantor
   sets through germs. The natural algebras are Steinberg algebras of ample
   groupoids that are not transformation groupoids of torsion-free groups.
   Theorem A says nothing about them, and no Farrell–Jones theorem for groupoid
   coefficient rings was found.
6. **Where the torsion-freeness lives.** It is a hypothesis on the acting group
   `P`, not on `G`. `F_2[G]` need not sit inside `F_2[P]`. For example, a clopen
   `U` with `gU ∩ U = ∅` gives the order-two unit
   `(1 − 1_U − 1_(gU)) + 1_(gU) g + 1_U g^−1`. So torsion in `G` is no
   obstruction.

## 8. The corner swindle in every degree

This section is used only by the first sanity check of Section 5. No node
depends on it, and no novelty is claimed. The degree-one case is
`leavitt-tensor-kills-k1-of-coefficient-matrices`.

**Conventions.** For rings `R`, `S`, an `S`-`R`-bimodule `Q` that is finitely
generated projective as a left `S`-module induces an additive functor
`Q ⊗_R − : P(R) -> P(S)` on finitely generated projective modules, and hence a
map `K(Q) : K(R) -> K(S)` of non-connective `K`-theory spectra. Two standard
properties are used and were not re-derived:
- isomorphic bimodules induce naturally isomorphic functors, hence homotopic
  maps;
- `K(Q ⊕ Q') = K(Q) + K(Q')` on every `K_n`, `n ∈ Z`.

A unital homomorphism `θ : R -> S` induces `K(θ) = K(S_θ)`, where `S_θ` is `S`
with right `R`-action through `θ`.

**Proposition 8.1.** Let `k` be a field, `B` a unital `k`-algebra, `R = B ⊗_k L`
and `ι : B -> R`, `b |-> b ⊗ 1`. Then `K_n(ι) : K_n(B) -> K_n(R)` is zero for
every `n ∈ Z`.

*Proof.* Write `x_i`, `y_i` for `1 ⊗ x_i`, `1 ⊗ y_i`, and put `p_i = x_i y_i`.
The `p_i` are orthogonal idempotents with `p_1 + p_2 = 1`, and
`p_i x_j = δ_ij x_i`.

1. **The endomorphism.** `φ(r) = x_1 r y_1 + x_2 r y_2` is a unital ring
   endomorphism of `R`:
   `φ(r) φ(s) = Σ_(i,j) x_i r (y_i x_j) s y_j = Σ_i x_i r s y_i = φ(rs)`, and
   `φ(1) = p_1 + p_2 = 1`.
2. **It fixes the coefficients.** `b ⊗ 1` commutes with `x_i` and `y_i`, so
   `φ(b ⊗ 1) = (b ⊗ 1)(p_1 + p_2) = b ⊗ 1`. Hence `φ ∘ ι = ι`.
3. **The bimodule splits.** As a left `R`-module, `R_φ = R p_1 ⊕ R p_2`. For
   `a ∈ R` and `r ∈ R`, `(a p_i) φ(r) = a p_i x_i r y_i = a x_i r y_i`, which lies
   in `R p_i` since `y_i = y_i p_i`. So each `R p_i` is a sub-bimodule, on which
   `r` acts on the right by multiplication by `ψ_i(r) = x_i r y_i`. Write
   `Q_i = (R p_i)_(ψ_i)`. Then `R_φ = Q_1 ⊕ Q_2` as bimodules, and
   `K(φ) = K(Q_1) + K(Q_2)` on homotopy groups.
4. **Each summand is the identity bimodule.** Define `β_i : R -> Q_i` by
   `β_i(a) = a y_i`.
   - It lands in `R p_i`, because `y_i p_i = y_i`.
   - It is left `R`-linear.
   - It is right linear: `β_i(a) · r = a y_i x_i r y_i = a r y_i = β_i(a r)`.
   - It is bijective, with inverse `c |-> c x_i`: `a y_i x_i = a`, and for
     `c ∈ R p_i`, `c x_i y_i = c p_i = c`.

   So `Q_i ≅ R` as bimodules, and `K(Q_i) = id`.
5. **Conclusion.** `K_n(φ) = 2·id` on `K_n(R)`. By step 2,
   `K_n(ι) = K_n(φ) K_n(ι) = 2 K_n(ι)`, so `K_n(ι) = 0`. ∎

For `B = LC(X, F_2) ⋊ Z` over an infinite minimal subshift, this says
`K_1(B) = Z` maps to zero in `K_1(B ⊗ L)`, as Theorem B requires.

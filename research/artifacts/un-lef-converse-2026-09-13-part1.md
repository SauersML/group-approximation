# The LEF rung of the unification: LEF elementary groups force LEF (hence matricial) rings

Lane `un-lef-converse`, 2026-09-13. Status: complete written proof, **unreviewed**. It rests on one import,
`steinberg-finite-presentation-and-kazhdan-theorem` (St_n over a finitely presented unital ring is finitely
presented for n >= 4), used at statement level.

## 0. Statements

Conventions. Rings are unital and associative. `EL_N(R)` is generated by `e_ij(r)`, `i != j`. A group `G`
is *LEF* if every finite `B ⊆ G` has an injective `psi : B -> Q`, `Q` finite, with `psi(gh) = psi(g)psi(h)`
whenever `g, h, gh ∈ B`. A ring is *LEF* in the sense of `lef-simple-rings-are-not-finitely-presented`.

**Theorem 1 (`lef-elementary-groups-force-lef-rings`).** Let `R` be a ring and `N >= 4`. If `EL_N(R)` is LEF,
then `R` is a LEF ring. No simplicity is needed.

**Theorem 2 (`simple-lef-rings-are-exactly-matricial`).** A simple LEF ring `R` has an injective unital ring
homomorphism `R -> prod_omega M_(d_n)(F_(q_n))` over finite fields, for every non-principal ultrafilter `omega`.

**Corollary 3 (closes rung (L) for simple rings).** For a countable simple ring `R` the following are
equivalent:
(a) `EL_N(R)` is LEF for some `N >= 4`;
(b) `R` is a LEF ring;
(c) `R` embeds unitally in a matrix ultraproduct over finite fields;
(d) `GL_M(R)` and `EL_M(R)` are LEF for every `M >= 1`.
(a)⇒(b) is Theorem 1; (b)⇒(c) is Theorem 2; (c)⇒(d) is `exactly-matricial-rings-have-lef-general-linear-groups`;
(d)⇒(a) is trivial. So `lef-el-groups-force-exactly-matricial-simple-ring` holds, with one rank >= 4
suffices in place of every rank, and finite fields in the conclusion. Rank 3 alone is not covered.

## 1. Proof of Theorem 1

Fix a finite window `W ⊆ R` with `0, 1 ∈ W`, closed under negation. Let `x_1, ..., x_m` enumerate `W`,
`A = Z<x_1, ..., x_m>` the free unital ring, and `pi : A -> R` the unital homomorphism with `x_k |-> x_k`.
Let `theta : St_N(A) -> EL_N(R)` be `x_ij(a) |-> e_ij(pi(a))`.

**Step 1: a finite presentation.** `A` is finitely presented, so for `N >= 4` `St_N(A)` is finitely presented
(import). The finite set `S = {x_ij(1)^(±1), x_ij(x_k)^(±1)}` generates `St_N(A)`: monomials come from
commutators, since `[x_ij(a), x_jk(b)] = x_ik(ab)` for distinct `i, j, k`; sums come from products. By
Tietze moves there is a finite presentation `<S | Rel>`.

**Step 2: lifts and word lengths.** For `r ∈ W` put `l(r) = x_r ∈ A` (the generator itself). Let
`L = {0, 1, l(r), l(r) + l(s), l(r) l(s) : r, s ∈ W}` and `D = L - L`, both finite. Every `x_13(c)`, `c ∈ D`, is
a word in `S`; fix one, `u_c`. Let `B ⊆ EL_N(R)` be the finite set of theta-images of all prefixes of all
relators in `Rel`, of all `u_c`, and of `S`, together with `1` and `e_13(0) = 1`.

**Step 3: a homomorphism to a finite group.** LEF gives an injective partial homomorphism `psi : B -> Q`
into a finite group. `psi(1) = 1`, since `psi(1·1) = psi(1)^2`. For `s ∈ S` put `rho(s) = psi(theta(s))`.
By induction along prefixes, every word `v` whose prefixes have theta-images in `B` satisfies
`rho(v) = psi(theta(v))`. In particular each relator `w` gives `rho(w) = psi(theta(w)) = psi(1) = 1`, so `rho`
extends to a homomorphism `rho : St_N(A) -> Q`. Also `rho(x_13(c)) = psi(e_13(pi(c)))` for every `c ∈ D`.

**Step 4: the level ideal.** For `i != j` let `K_ij = {a ∈ A : rho(x_ij(a)) = 1}`, an additive subgroup,
since `a |-> rho(x_ij(a))` is a homomorphism from `(A, +)`. The relations `[x_ij(a), x_jk(1)] = x_ik(a)` and
`[x_ij(1), x_jk(a)] = x_ik(a)` give `K_ij ⊆ K_ik` and `K_jk ⊆ K_ik`. On indices 1, 2, 3 this yields the cycle
`K_12 ⊆ K_13 ⊆ K_23 ⊆ K_21 ⊆ K_31 ⊆ K_32 ⊆ K_12`, and the same chains through a third index identify every
`K_ij` with one subgroup `K`. From `[x_12(a), x_23(b)] = x_13(ab)`: if `a ∈ K` or `b ∈ K` then `ab ∈ K`. So `K` is
a two-sided ideal, and `A/K ≅ rho(x_13(A)) ≤ Q` as additive groups. So `A/K` is a finite unital ring.

**Step 5: the ring window.** For `c ∈ D`: `c ∈ K` ⟺ `rho(x_13(c)) = 1` ⟺ `psi(e_13(pi(c))) = psi(1)` ⟺
`e_13(pi(c)) = 1` (injectivity of `psi` on `B`) ⟺ `pi(c) = 0`. Define `phi : W -> A/K`, `phi(r) = [l(r)]`. Then:
- `phi` is injective on `W`: `r != s` gives `pi(l(r) - l(s)) != 0`, so `l(r) - l(s) ∉ K`;
- `phi(1) = [1]`, `phi(0) = 0`, and `phi(-r) = -phi(r)`, because `l(-r) + l(r) ∈ D` maps to `0`;
- `r + s ∈ W` gives `phi(r + s) = [l(r) + l(s)] = phi(r) + phi(s)`, since `l(r + s) - (l(r) + l(s)) ∈ D` maps to `0`;
- `rs ∈ W` gives `phi(rs) = [l(r) l(s)] = phi(r) phi(s)` likewise.
So every finite window of `R` embeds exactly in a finite ring, and `R` is LEF. ∎

## 2. Proof of Theorem 2

Let `W_1 ⊆ W_2 ⊆ ...` exhaust `R`, with LEF maps `phi_n : W_n -> Q_n` into finite rings. `Q_n != 0`, since
`phi_n` is injective and `0 != 1` in `R`. By Artin–Wedderburn and Wedderburn's little theorem,
`Q_n / J(Q_n)` is a nonzero finite product of rings `M_d(F_q)`. Let `p_n : Q_n -> M_(d_n)(F_(q_n))` be the
unital projection onto one factor, and `psi_n = p_n ∘ phi_n`: unital, additive and multiplicative on `W_n`.
Define `Psi(r) = [psi_n(r)]_omega`, defined once `r ∈ W_n`. `Psi` is a unital ring homomorphism, and
`Psi(1) = 1 != 0` because `d_n >= 1`. So `ker Psi` is a proper two-sided ideal, hence `0` by simplicity. ∎
(This is `simple-rings-with-local-matrix-models-are-matricial` with varying finite fields and finite-ring
input; the projection step is what lets a finite ring stand in for a matrix algebra.)

## 3. Model tests

- `L_k(1,2)`, `k` finite: a LEF ring is directly finite, since finite rings are, but `t_0 s_0 = 1 != s_0 t_0`.
  Theorem 1 then gives that no `EL_N(L_k(1,2))`, `N >= 4`, is LEF. This agrees with the non-MF paper
  (no MF quotient) and with `cohn-elementary-group-is-not-lef`, whose Step 2 is the same finite-presentation
  mechanism at one ring.
- The Pestov ring `LC(X, F_q) ⋊ Z`: LEF (`minimal-subshift-algebra-is-simple-lef-ring`) and matricial. Consistent.
- `A_1(Q)`: exactly matricial and LEF (`weyl-algebra-is-exactly-matricial`). Consistent; Theorem 1 needs no
  finite generation, because `A` is built from each window.
- `F_q[Gamma]` with `Gamma` amenable and not LEF: `EL_n` is not LEF (`group-ring-lef-iff-group-lef-iff-elementary-group-lef`),
  and the ring is not LEF. Consistent.
- `R = k × k`: not simple. Theorem 1 holds (it needs no simplicity); Theorem 2 correctly needs simplicity
  for injectivity of one coordinate projection.

## 4. Consequences for the program

- **Rung (L) closes for simple rings** (Corollary 3), modulo the import. The ladder's remaining converses are
  (Σ⇒) `linear-sofic-el-groups-force-rank-model` and (M⇐) `stably-finite-simple-rings-have-mf-elementary-groups`.
- **Finitely presented infinite simple rings never have LEF `EL_N`, `N >= 4`:** Theorem 1 plus
  `lef-simple-rings-are-not-finitely-presented`. So if the Labbé crossed product is finitely presented,
  every `EL_N` over it (`N >= 4`) is non-LEF, with no model search needed.
- **Why the finite presentation matters.** Exact partial models of a finite window cannot be closed inside
  the finite group: when `R` has a unit of infinite order, no finite `V ∋ 1` is closed under products, so root
  images never form graded subgroups with `[X_12, X_23] ⊆ X_13` (the Attempts of the open claim record this).
  The finitely presented cover `St_N(A)` sidesteps it: finitely many relators hold on a ball, and then every
  Steinberg relation holds in the finite image, and the level ideal exists.

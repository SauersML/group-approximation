## 10.2 Realization by minimal Cantor actions: PASS

- **Halving.** M ≠ Z^+ is atomless (OPR Corollary 2.7), so e = x + y with x, y ≠ 0.
  - Simplicity gives x ≤ ny. Riesz decomposition gives a nonzero a with a ≤ x and a ≤ y, so 2a ≤ e.
  - Simplicity again gives e ≤ ma. So Proposition 4.7.10(1) makes μ group-induced.
- **Range and exhaustiveness.** The V-condition makes the range {x ≤ e}, and Riesz decomposition makes it generate M.
  Countably many witness automorphisms give a countable μ-exhaustive Γ. Theorem 4.7.14(2) gives
  Z^+⟨B⟩//Γ ≅ M with [1] ↦ e.
- **Stone duality.** C(X, Z^+) is presented by clopen indicators. The congruence generated by 1_A ≈ 1_{γA} is ~, which is
  additive, transitive (refine to a common partition) and contains the generators.
- **Cantor space.** An isolated point gives an atom of B whose measure is an atom of M, which is impossible.
- **Minimality.** [1_C] is an order unit, so 1_X + h ~ n1_C, and the source pieces lie in U and cover X.
- **Measures and states.** Invariance gives well-definedness, compactness gives countable additivity, and Carathéodory
  gives the extension.
- **Measure-free case.** A countable part M′ of the OPR monoid, closed under refinement matrices and simplicity
  witnesses, keeps u finite and 2u properly infinite (4u + w = 2u). A state would give 4 + s(w) = 2.

## 10.3 Topologically free realization by generic witnesses: PASS

- **Witness space.** Group-induced μ decomposes every equal-measure pair. C_k = {g : g(c_k) = d_k} is clopen and
  nonempty in the Polish group Aut(B, μ), so P = ∏ C_k is Polish, and every g ∈ P generates a μ-exhaustive group.
- **Reduction.** U(w, b) = {g : w(g) not the identity on B|b} is open. A clopen set is fixed pointwise iff every clopen
  subset is invariant. So ∩ U(w, b) gives freeness on the g_k and topological freeness, and Baire reduces this to
  density.
- **Lemma R.** Choose U_0 ∋ x inside the atom and missing Φ ∖ {x}, and nonempty clopen W ⊆ X_p ∖ (U_0 ∪ Φ) (no isolated
  points).
  - Simplicity with Riesz and the V-condition gives pieces U_i with μ(U_i) ≤ μ(W), and V ⊆ W with μ(V) = μ(U).
  - Groupoid-induced μ gives h: B|U → B|V. τ = h ⊕ h^{-1} ⊕ id preserves the atoms, fixes Φ ∖ {x}, and sends x out of Φ.
- **Setup.** σ_k maps atoms of A onto themselves, so it fixes A elementwise. Hence g′_k = g_k σ_k agrees with g_k on F
  and keeps g′_k(c_k) = d_k.
- **Steering, sign +1.** x_{j−1} ∉ S_k.
  - It is not an earlier source point, by distinctness.
  - If it were an earlier inverse target x_i, then i = j − 1 and w would contain x_k x_k^{-1}.
  - τ fixes S_k, so earlier values of σ_k survive, and Φ ∋ σ_k^{-1}g_k^{-1}{x_0..x_{j−1}} makes x_j new.
- **Steering, sign −1.** q = σ_k^{-1}g_k^{-1}(x_{j−1}) ∉ S_k.
  - If q = x_{i−1} with letter k, then x_i = x_{j−1}, so i = j − 1 and w would contain x_k^{-1}x_k.
  - If q = x_i with letter k^{-1}, then x_{i−1} = x_{j−1}, so i = j, a contradiction.
  - τ is an involution, so (σ_kτ)(τq) = σ_k(q) = z, and x_j = τq ∉ Φ.
- **Conclusion.** w(g′)(x_0) = x_m ≠ x_0 with x_0 ∈ X_b, so some clopen c ≤ b moves.
- Every step is re-derived. The statement correctly drops BP's 2-divisibility, since halving comes from atomlessness.

## 10.4 Fidelity to Rainone's question: PASS

- **Hypotheses of Theorem 4.22 for C(X), X Cantor.**
  - C(X) is unital, separable and exact.
  - Projections are total (real rank zero).
  - It has cancellation, and K_0^+ = C(X, Z^+) has Riesz refinement.
  - The action is minimal, and for commutative coefficients properly outer means topologically free.
  - The weak-unperforation hypothesis is the one the question asks to fail, so the question is about the other
    hypotheses.
- **The semigroup.** Rainone's S(C(X), Γ, α) = K_0^+/~_α, whose pieces are sums of clopen indicators, is the clopen type
  semigroup. "Not almost unperforated" is shown for that semigroup itself.
- **Failure of almost unperforation.**
  - No state and Tarski (Rainone Theorem 4.11) give (k+1)θ ≤ kθ.
  - Iterating gives (k+1)(2θ) ≤ kθ. Almost unperforation would then give 2θ ≤ θ, impossible for finite θ.
  - So the weaker condition of his last sentence fails as well.
- **The BP route.** Corollary 6.12 is verbatim. ABBL Corollary B (comparison ⟺ almost unperforated, minimal actions)
  gives the first failure. Proposition 2.11 with all invariant measures trivial gives a non-properly-infinite element,
  hence a finite clopen class: in a simple conical monoid an infinite element is properly infinite. ABBL was not re-read.

# Residual finiteness of finite presentations is Pi-zero-two complete: part 1

Lane `ex-complexity-sofic`, 2026-09-12.  Unreviewed.  Part 1: the machine
groups, pumping, and the profinite invisibility of a divergent computation.
Part 2 proves residual finiteness on halting machines.  Part 3 builds the
switch and does the bookkeeping.

## 0. Theorem

```text
RF_fp    is Pi^0_2-complete,   NONRF_fp  is Sigma^0_2-complete,
LEF_fp   is Pi^0_2-complete,   NONLEF_fp is Sigma^0_2-complete.        (T0)
```

The hardness reduction `INF <=_m RF_fp` lands in finitely presented groups in
the variety `A_p^2 A`, so they are solvable of derived length at most three.
Hence residual finiteness is already `Pi^0_2`-complete among finitely
presented solvable groups, all of which are amenable, sofic, hyperlinear and
MF.  Membership in `Pi^0_2` is the finite-presentation clause of
`residual-finiteness-of-enumerated-presentations-is-pi3-complete`.  The LEF
lines follow because a finitely presented group is LEF iff it is residually
finite (Vershik--Gordon), and `LEF_fp` is `Pi^0_2` by
`lef-recognition-has-a-pi2-upper-bound`.

## 1. Imported: Kharlampovich--Myasnikov--Sapir machine groups

Source: O. Kharlampovich, A. Myasnikov, M. Sapir, *Algorithmically complex
residually finite groups*, arXiv:1204.6506v5 (22 Mar 2013); Bull. Math. Sci. 7
(2017) 309--352.  All numbers refer to v5 and were read from the PDF on
2026-09-12 (pages 9--28).

**Minsky machines (Section 2.3).**  A `K`-glass machine has commands numbered
`0..N`.  A configuration is `(i; e_1..e_K)`.  The three command forms are

```text
i -> Add(n_1..n_l); j                 put a coin in each listed glass,
i; e_n1 > 0,..,e_nl > 0 -> Sub(..); j take a coin from each listed glass,
i; e_n1 = 0,..,e_nl = 0 -> j          if the listed glasses are empty,
```

and `0` is the stop command.  Several commands may share a number
(nondeterministic machines, Remark 2.5).  `Sym(M)` adds all inverse commands.
Configurations are *equivalent* when a computation of `Sym(M)` joins them, and
a configuration is *accepted* when it is equivalent to one with command `0`.

**Lemma 2.1.**  If `M` is deterministic, two configurations are equivalent iff
two computations of `M` lead from them to a common configuration.  The proof
only uses that the domains of distinct commands are disjoint, so it applies
verbatim to the partial configurations used in part 2, Section B1.

**The semigroup `S(M)` (Section 3.1).**  Generators `q_0..q_N`, `a_1..a_K`,
`A_1..A_K`.  Relations: commutativity `(2)` (`a_i a_j = a_j a_i`,
`A_i A_j = A_j A_i`, `a_i A_j = A_j a_i` for `i != j`); the stop relation
`(3)` `q_0 = 0`; the 0-relations `xy = 0` for two-letter words that are not
subwords of configuration words modulo `(2)`; and the Minsky relations `(4)`:

```text
i -> Add(n_1..n_m); j                  q_i = q_j a_n1 ... a_nm
i; e_n > 0 -> Sub(n_1..n_m); j         q_i a_n1 ... a_nm = q_j
i; e_n = 0 -> j                        q_i A_n1 ... A_nm = q_j A_n1 ... A_nm
```

The configuration word is `w(i; e) = q_i a_1^(e_1) ... a_K^(e_K) A_1 ... A_K`.
Lemma 3.4: every nonzero element is represented by a subword of a
configuration word.

**The group `G(M)` (Section 4.1).**  Fix a prime `p`.  Generators
`L_0 = {x_u : u in U}` (with `U = {q_j w : w divides A_0 A_1...A_K}`),
`L_1 = {A_0..A_K}`, `L_2 = {a_i, a_i', ã_i, ã_i'}`; relations G1--G8.  For
`f` in the normal subgroup `T` generated by `L_0`, write

```text
f * a_i = f^(-1) f^(a_i) (f^(a_i^(-1)))^(-1) f^((a_i')^(-1)),   f * A_i = [f, A_i],
```

and `f * t^(n)` for `n`-fold iteration.  G8 imposes, for each command, the
table `(7)`: `x_(q_i A_0) = x_(q_j A_0) * a_n1 * ... * a_nm` for Add, the
mirror for Sub, and `x_(q_i A_0) * A_n1 * ... = x_(q_j A_0) * A_n1 * ...` for
zero tests.  The group is finitely presented, computably in `M`.

**Theorem 4.3.**  (a) `G(M)` belongs to `A_p^2 A cap ZN_(K+1) A`.  (b) The
equality

```text
x_(q_i A_0) * a_1^(m_1) * ... * a_K^(m_K) * A_1^(al_1) * ... * A_K^(al_K)
  = x_(q_j A_0) * a_1^(n_1) * ... * a_K^(n_K) * A_1^(be_1) * ... * A_K^(be_K)
```

(`al_i, be_i in {0,1}`) holds in `G(M)` iff
`q_i a^m A^al = q_j a^n A^be` holds in `S(M)`.  (c) The analogous words built
on `x_(q_i)` (no `A_0`) are equal iff all exponents agree.

**Lemma 4.5.**  `T` is abelian of exponent `p`.  Lemma 4.4: `<L_1 cup L_2>` is
metabelian.  So `G(M)/T` is a finitely generated metabelian group.

**The model `Ḡ` (pages 22--24) and Lemma 4.14.**  `Š` is `S(M)` without the
Minsky relations.  `W` = nonzero elements of `Š` containing a `q`-letter;
`W_0` = nonzero elements of `S(M)` containing a `q`-letter, with `A_0`
inserted next to it.  `T_1` is the elementary abelian `p`-group with basis
`z_(i,u)`, `i in {1,2,3}^K`, `u in W cup W_0`, with `z_(i,0) = 1`.  Each letter
of `L_1 cup L_2` acts on `T_1` by an explicit automorphism (formula `(13)` and
the displays after it), and `Ḡ = T_1 x| <those automorphisms>`.  Lemmas
4.10--4.11: `x_u |-> z_(1,u)`, letters to letters, is a surjection
`G(M) -> Ḡ`.  Lemma 4.14: `T` is the direct product of the cyclic groups
generated by the preimages `x_(i,w)`; equivalently the surjection is injective
on `T`, with `T ~= T_1`.

What we use of formula `(13)`, read off the displays on pages 23--24: on a
basis vector `z_(i,u)` with `u in W_0` (so `u` contains `A_0`), each letter
acts either trivially or by a product of basis vectors `z_(i',u)` and
`z_(i',uℓ)`, where `ℓ` is the letter appended on the right (`a_j` when `u`
does not contain `A_j`; `A_j` when `u` does not contain `A_j`; `ã_j`
acts trivially because `u` contains `A_0`).  The inverse automorphisms have
the same shape.  Which case applies depends only on the set of `A`-letters in
`u`.  On `u in W`, the letters act the same way, except that `ã_j` inserts
`a_j` before `A_j` (well defined in `Š`, which has no Minsky relations) and
`A_0` sends `z_(i,u)` to `z_(i,u) z_(i,uA_0)` with `uA_0 in W_0`.

Theorem 4.17 (not needed here, but it is the model for Part 2): if `M` is
sym-universally halting then `G(M)` is residually finite.

## 2. Clocked machines and their pumped versions

**Clocked.**  A deterministic machine `M` with glasses `1..K` is *clocked* by
glass `tau = K` if (C1) no command subtracts from or tests `tau`, (C2) every
Add command adds a coin to `tau`, and (C3) every Sub or zero-test command goes
to a command number whose only command is `Add(tau)`.  Every
machine can be clocked without changing its halting behaviour: insert the
auxiliary `Add(tau)` commands.  In any computation of length `L` at least
`floor(L/2)` commands add a coin to `tau`.

**Pumped.**  For clocked `M`, the machine `P(M)` has glasses `1..K`,
`pi = K+1`, `rho = K+2`, and commands

```text
every Add command i -> Add(Q); j of M   replaced by   i -> Add(Q, pi); j,
every Sub or zero-test command of M     kept as it is,
for each i in 1..N:   i -> Add(pi, rho); i                       (pump)
for each i in 1..N:   i; e_pi = 0, e_rho = 0 -> 0                (drain)
```

All commands have the three basic forms, so Section 4.1 applies to `P(M)`
as written.  The only difference from KMS's `M_n` (proof of Theorem 3.9) is
that `pi` counts clock ticks and no command tests `rho`.

**Invariant.**  For a word or configuration put
`iota = e_pi - e_rho - e_tau` (letter counts).  Every command preserves
`iota`: an Add of `M` adds to both `tau` and `pi`, pumps add to `pi` and
`rho`, and the other commands touch none of the three.  Commutativity
relations preserve letter counts.                                     (INV)

## 3. Lemma A (divergence is profinitely invisible)

**Lemma A.**  Let `M` be clocked and deterministic, and let `c` be a
configuration of `M` whose forward computation is infinite.  Put
`c' = (c; e_pi = 1 + e_tau(c), e_rho = 0)`, so that `iota(c') = 1`.  Then
`w(c') != w(0; 0..0)` in `G(P(M))`, but every homomorphism from `G(P(M))` to a
finite group identifies them.  In particular `G(P(M))` is not residually
finite.

*Correction (2026-09-12, after review by `ex-verify-groups`).*  An earlier
version took `c' = (c; 1, 0)` and asserted `iota(c') = 1`.  In fact
`iota((c; 1, 0)) = 1 - e_tau(c)`, and the statement is then false.  If the
first step of a divergent computation from `c_0` (with `e_tau(c_0) = 0`) is
an Add into `c`, then running that Add backward from `(c; 1, 0)` reaches
`(c_0; 0, 0)`, the drain applies, and the word is `0`.  The pumped glass must
start one above the clock reading.  The completeness reduction is unaffected:
the divergent configuration of Lemma C has `e_tau = 0`, where the two inputs
coincide.

*Step 1: `c'` is not accepted by `P(M)`.*  Take a computation of
`Sym(P(M))` from `c'` and stop it just before the first command with number
`0` appears.  Such a command can only arise from a drain, or from a command of
`M` into `0`.

- A drain needs `e_pi = e_rho = 0`, so `iota = -e_tau <= 0` there.  By (INV),
  `iota = iota(c') = 1` along the whole computation.
- Suppose instead the command comes from `M`.  Forgetting `pi`, `rho`, pumps
  and drains projects the computation to a computation of `Sym(M)` from `c`.
  Its end would be equivalent to `c` and have command `0`.  By Lemma 2.1 there
  would be forward computations of `M` from `c` and from some configuration at
  command `0` reaching a common configuration.  Stop has no commands, so that
  common configuration is at command `0` and lies on the forward orbit of `c`.
  That contradicts divergence.

So `w(c') != 0` in `S(P(M))`.  Since `w(0; 0..0) = 0` there, Theorem 4.3(b)
gives `w(c') != w(0; 0..0)` in `G(P(M))`.

*Step 2: finite quotients.*  Let `phi : G(P(M)) -> Q` with `Q` finite and
`V = phi(T)`.  For `g in G`, conjugation by `g` preserves `T`, and
`f |-> f * a_pi` is a product of conjugates of `f`.  So there is an
endomorphism `P̄` of the finite group `V` with `phi(f * a_pi) = P̄(phi(f))`,
and likewise for every other `*`-letter.  `End(V)` is a finite semigroup, so
some power `P̄^D` (`D >= 1`) is idempotent.  Then `P̄^m = P̄^(m + tD)` for all
`m >= D` and `t >= 0`.

Along the forward computation of `M` from `c`, `e_tau` grows by exactly one at
each Add step and tends to infinity.  In `P(M)` the lifted computation from
`c'` keeps `e_rho = 0` and `e_pi = 1 + e_tau`, which therefore takes every
value `>= 1 + e_tau(c)`.  Choose a configuration `d` on it with
`e_pi(d) = tD` for some `t >= 1`, at command `i != 0`.  In `S(P(M))`, hence by
Theorem 4.3(b) in `G(P(M))`,

```text
w(c') = w(d) = w(d with pi = tD + D, rho = D)          (D pumps at i).
```

The word `w(d')` with `d' = (i; e(d), tD + D, D)` equals the image of
`x_(q_i A_0)` under a fixed composition of endomorphisms, in which
`*a_pi` appears as the block `(*a_pi)^(tD + D)`.  Under `phi` that block
becomes `P̄^(tD+D) = P̄^D`, so

```text
phi(w(d')) = phi(w(i; e(d), D, D)).
```

Unpumping `D` times reaches `(i; e(d), 0, 0)`, the drain at `i` sends it to
command `0`, and a configuration at command `0` has word `0` in `S(P(M))`.
By Theorem 4.3(b) its group word equals `w(0; 0..0)`.  Chaining the equalities
gives `phi(w(c')) = phi(w(0; 0..0))`.  QED

**Remark.**  Step 1 is where the clock is essential.  Without it a garbage
configuration with a longer past can merge into the orbit of `c`.  Backing
along that branch then empties `pi` while `rho = 0`, and the drain applies, so
`c'` becomes genuinely accepted.  KMS's depth argument (Theorem 3.9) assumes
non-acceptance without addressing this.

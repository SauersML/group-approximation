**Claim.** If every group of type `F_n` (`n >= 2`) embeds in a group of type
`F_{n+1}`, then every finitely presented group embeds in a group of type
`F_∞`. The converse implication is trivial, so the claim says the two parts of
Zaremsky Problem 1.1 (root `zaremsky-1-01-type-fn-groups-embed-in-type-fn-plus-1`)
have the same answer. If it holds, the mixed answer route
`zaremsky-1-01-by-mixed` can never fire.

**Equivalent single-group form.** Let `U` be a universal finitely presented
group. The claim is equivalent to:

*if `U` has hosts `U <= K_3 <= K_4 <= ...` with `K_m` of type `F_m`, then `U`
has a host of type `F_∞`.*

Proof of the equivalence:

- The first part of Problem 1.1 gives such a chain by induction. `U` is of
  type `F_2` with a host `K_3` of type `F_3`; `K_3` has a host `K_4` of type
  `F_4`; and so on.
- Conversely, a chain for `U` gives the first part. A group `G` of type `F_n`
  is finitely presented, so `G <= U <= K_{n+1}`.
- Separate hosts `K'_m` of `U`, one of type `F_m` for each `m`, already give a
  chain. `K'_m` is finitely presented, so `K'_m <= U <= K'_{m+1}`.

An `F_∞` host of `U` is a host for every finitely presented group.

## Attempts

- **Directed union: dead.** `∪ K_m` is not finitely generated when the chain
  does not stabilize.
- **Constant cloning systems: dead.** Take the pure cloning system
  (Witzel--Zaremsky) with `G_n = K_n` and every cloning map `κ_k^n` equal to
  the inclusion. The commutation axioms hold trivially. But
  `(T, g, T') ↦ ((T, T'), [g])` is an isomorphism `F(G_*) ≅ F × colim K_n`,
  since with trivial `ρ` and constant `κ` the label never interacts with the
  trees. So the group is not finitely generated. Finite generation needs
  `G_{n+1}` to be generated by the images of the different cloning maps
  `κ_k^n`, which is exactly where finiteness could be raised.
- **One mapping torus for all levels (open).** By the power refinement on
  `universal-fp-group-embeds-in-rp-fp-infinity-group`, it suffices to find one
  injective endomorphism `ψ` of `U` such that, for every `m`, some power
  `ψ^{k(m)}` factors as `U → K → U` through a group `K` of type `FP_m`, with
  both maps injective. Then `U *_ψ` is of type `F_m` for every `m`. Each `K_m`
  gives such maps `U → K_m → U` separately; one `ψ` whose powers realize all
  levels at once is not known. Necessary condition: the Alexander modules
  `colim_ψ H_k(U; Z)` must be finitely generated over `Z[t^{±1}]` for every
  `k`.
- **Stein--Farley limit (idea, not verified).** Suppose a cloning system has
  level groups `G_n` of type `F_{g(n)}` with `g(n) → ∞`. Then Brown's
  criterion could run on the superlevel subcomplex `X_{>= n_0}` of the
  Stein--Farley complex:
  - ascending links there are full simplices, so `X_{>= n_0} ≃ X` is
    contractible;
  - for a fixed `m`, choose `n_0` with `g(n) >= m` for all `n >= n_0`;
  - the truncated descending links have connectivity roughly
    `min(ν(n), n - n_0 - 2) → ∞`.

  That would give type `F_∞`. Three things are missing: finiteness of cell
  stabilizers (subgroups of `G_n`), finite generation (non-constant cloning
  maps), and a cloning system that realizes a host chain for `U`. The last is
  where the idea stops.
- **Retract cap.** Any construction in which some `K_m`, or `U`, is a retract
  of a vertex group over good edge groups reduces to form (4) of
  `universal-fp-group-embeds-in-rp-fp-infinity-group`
  (`fp-n-splittings-over-fp-n-edges-have-fp-n-vertex-groups`).

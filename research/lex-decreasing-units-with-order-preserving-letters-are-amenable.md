**OPEN** (proved on paper, artifact Section 3; held OPEN until `w4-vf-gate` re-derives it).

**Setting.** `R = L_(F_2)(1,2)`. The monomial `S[v]T[w]` is the prefix replacement `wy -> vy` on `X = {0,1}^N`.
Order `X` lexicographically, and write `U < W` when every point of `U` is below every point of `W`.

**Statement.** Let `T_<` be the span of the monomials `S[v]T[w]` with `[v] < [w]`, and `U_< = 1 + T_<`.
1. `T_<` is a subalgebra, and every finite set of its monomials generates a finite nilpotent algebra. So `U_<` is a
   locally finite 2-subgroup of `R^x`.
2. Thompson's `F`, the order-preserving elements of `V`, normalizes `U_<`, and `<U_<, P> = U_< ⋊ P` for every
   `P <= F`.
3. `U_<` contains `iota_A(UT_3(R))` for every cylinder `A`, so `iota_A(D_8)` and the order-128 Toeplitz group.
4. If `P <= F` is amenable and nontrivial, `U_< ⋊ P` is amenable. By
   `sofic-subgroups-carry-independent-cylinder-defects` it has a fixed-point-free rank model with
   `rk(D_(A_1) ... D_(A_k)) = (3/8)^k` for disjoint nonempty proper cylinders `A_i`.

**Consequences.**
* `<iota_0(D_8), iota_1(D_8), x_0>`, with `x_0 = S[00]T[0] + S[01]T[10] + S[1]T[11]`, lies in `U_< ⋊ <x_0>`. So
  relations holding in it force no `theta < 1`, although `x_0` changes depth and lies in no depth-monotone subalgebra.
* `U_< ⋊ F` is amenable if and only if `F` is. A relation-only proof of
  `leavitt-disjoint-cylinder-defects-strictly-submultiplicative` from relations holding in `U_< ⋊ F` would prove
  `thompson-f-is-not-amenable`.
* Over `F_3` the same lemmas hold, `U_<` is a locally finite 3-group, and `-1` lies outside `U_< ⋊ P`. So
  `<-1> x (U_< ⋊ P)` is sofic data for `anti-central-sofic-data-cannot-force-defect-submultiplicativity`.

**Scope.** Let `b = iota_A(w_23) iota_(A1)(w_12)` be the right-child product. No total order preserved by `b` makes the
positive roots of each frame monotone in one common direction (artifact Lemma 6.1, hypothesis as corrected in
`research/artifacts/gk-vf-gate-verification-2026-09-12.md`, Section 35.4). So `<iota_A(D_8), iota_(A1)(D_8), b>` is not covered.

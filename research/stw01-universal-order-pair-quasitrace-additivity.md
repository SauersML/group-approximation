Let `U` be the universal unital C*-algebra of two elements `h_0, k_0` with

```text
0 <= h_0 <= 1,        0 <= k_0 <= h_0 - h_0^2.
```

Then every bounded 2-quasitrace `sigma` on `U` satisfies

```text
sigma(h_0 + k_0) = sigma(h_0) + sigma(k_0).
```

**Equivalent to STW Problem I** (Theorem B of
`research/artifacts/stw01-universal-order-pair-test-2026-09-12.md`). The chain is:
- Linearity implies this claim.
- This claim implies `stw01-modular-single-pair-quasitrace-additivity`, by pullback along
  `U -> Q` (`stw01-modular-single-pair-via-universal-order-pair`).
- That claim implies Problem I (`stw01-problem-i-via-modular-single-pair`).

The graph records only the forward routes, so that no dependency cycle is created.

**Why it is recorded separately.** It mentions no group: two positive contractions tied
by one order relation. By `stw01-modular-test-pair-algebra-is-universal-order-pair`,
`U ~= C*(1, h, k)` inside `C*(PSL_2(Z))`, so this is the modular test with the ambient
algebra removed. `U` is not exact, since it surjects onto `Q`.

## Attempts

- **Commuting sandwich.** `h_0 - h_0^2` commutes with `h_0` and dominates `k_0`. Monotonicity
  and commuting additivity give
  `|sigma(h_0 + k_0) - sigma(h_0) - sigma(k_0)| <= sigma(h_0 - h_0^2)`. This gives no contradiction:
  every counterexample produced by the modular reduction has positive room
  `tau(a - a^2) = tau(1)/4 - eps^2 tau(y^2)`. Artifact, Section 3.
- **Ideal extension.** For the ideal `J` generated by `k_0`, `U/J ~= C([0,1])`. So
  `stw01-extensions-preserve-qt-linearity` reduces linearity on `U` to linearity on `J`.
  Dead for Haagerup: `J` maps onto the ideal `<p>` of `Q`, and `Q/<p> ~= C^3` is nuclear. So
  `<p>` is not exact (otherwise `Q` would be), and neither is `J`.
- **Cuntz semigroup.** The inequality `h_0 + k_0 <~ h_0 (+) k_0` bounds only supports. Deciding
  additivity needs the Cuntz classes of all cut-downs `(h_0 + k_0 - t)_+`, which were not
  computed in the non-exact algebra `U`.
- **Free products and pinching.** A quasitrace is not determined by its traces on the
  two-projection subalgebras `C*(e_j, p)`, and no free-product formula applies. The test
  rewrites as pinching invariance of `sigma_2` on one positive `2 x 2` matrix, which is the
  generic form of linearity. Artifact, Section 4.

Source: E. Ortega, F. Perera, M. Rordam, *The Corona Factorization Property
and refinement monoids*, arXiv:0904.0541v1 (published 2011).  Read from the
arXiv PDF on 2026-09-12.

Verbatim, Corollary 5.16: "A separable simple C\*-algebra of real rank zero
with the Corona Factorization Property is either stably finite or purely
infinite."  The sentence before it: "The corollary below was proved in an
unpublished paper by S. Zhang. (One can drop the separability assumption by
passing to a suitable separable sub-C\*-algebra.)"

Supporting statements used in the node body, read in the same PDF:

* Theorem 5.8(ii): "Suppose that A is of real rank zero. Then A has the
  Corona Factorization Property (for C\*-algebras) if and only if V(A) has the
  Corona Factorization Property (for monoids)", under the standing hypothesis
  that `A tensor K` has a countable approximate unit consisting of projections.
* Theorem 5.14: in a conical refinement monoid, if `mu` is properly infinite,
  then `u` is properly infinite if (i) `M` has the strong CFP, or (ii) `M` has
  the CFP and `u` is an order unit.
* Corollary 5.9: a sigma-unital real-rank-zero `A` whose `V(A)` is almost
  unperforated, or has `n`-comparison for some `n`, has the CFP.

Same paper, page 20: "It is an open problem if all C\*-algebras of real rank
zero have the CFP."  Page 2: "It remains unknown if there is an example of a
simple C\*-algebra of real rank zero which contains both finite and infinite
projections."

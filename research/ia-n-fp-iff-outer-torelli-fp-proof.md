Fix `n >= 2`, and let `ρ: Aut(F_n) -> GL_n(Z)` be the action on `F_n^{ab} = Z^n`.

**Step 1: the extension.** An inner automorphism acts trivially on the
abelianization, so `Inn(F_n) <= IA_n = ker ρ`. Hence `ρ` factors through
`Out(F_n) = Aut(F_n)/Inn(F_n)`, and the kernel of the induced map
`Out(F_n) -> GL_n(Z)` is `IA_n/Inn(F_n) = T_n`. The free group `F_n` has trivial
center for `n >= 2`, so `F_n -> Inn(F_n)`, `x -> (conjugation by x)`, is an
isomorphism. This gives the short exact sequence

`1 -> F_n -> IA_n -> T_n -> 1`.

**Step 2: a quotient by a finitely generated normal subgroup.** Let `G` be finitely
presented and `N` a normal subgroup generated as a subgroup by finitely many
elements `n_1, ..., n_k`. If `G = <X | R>` with `X` and `R` finite and `w_i` is a
word in `X` representing `n_i`, then `G/N = <X | R ∪ {w_1, ..., w_k}>`. Here `N` is
the normal closure of `{n_i}`, because `N` is normal and generated by the `n_i`.
Apply this with `G = IA_n` and `N = Inn(F_n)`, generated by `n` inner automorphisms:
if `IA_n` is finitely presented, then so is `T_n`.

**Step 3: an extension of finitely presented groups (P. Hall).** Let
`1 -> N -> G -> Q -> 1` be exact, with `N = <A | S>` and `Q = <B | U>` finite
presentations, and choose lifts `b~` in `G` of the generators `b` in `B`. The
following hold in `G`:

- (i) each `s` in `S` holds in the letters `A`;
- (ii) for each `u` in `U`, `u(b~) = v_u(A)` for some word `v_u`, since `u(b~)`
  lies in `N`;
- (iii) for each `a` in `A`, `b` in `B` and `ε = ±1`,
  `b~^ε a b~^{-ε} = x_{a,b,ε}(A)` for some word `x_{a,b,ε}`, since `N` is normal.

Let `H` be the group given by generators `A ∪ B~` and the finitely many relations
(i)–(iii). The obvious map `π: H -> G` is surjective, since `A` generates `N` and
the `b~` map onto generators of `Q`. Let `N'` be the subgroup of `H` generated by
`A`. By (iii), `N'` is normal. Since (ii) says each `u(b~)` lies in `N'`, the
assignment `b -> b~ N'` defines a homomorphism `Q -> H/N'`, which is surjective and
inverse to the map induced by `π`; so `H/N' ≅ Q`. By (i), `a -> a` defines a
homomorphism `N -> N'`, which is surjective; composed with `π` it is the identity
of `N`, so it is an isomorphism and `π` restricted to `N'` is injective. Now take
`h` in `ker π`. Its image in `Q` is trivial, so `h` lies in `N'`, and injectivity of
`π` on `N'` gives `h = 1`. So `G ≅ H` is finitely presented. Apply this with
`N = Inn(F_n) ≅ F_n = <x_1, ..., x_n | >` and `Q = T_n`: if `T_n` is finitely
presented, then so is `IA_n`.

Steps 2 and 3 together prove the equivalence. Nothing here depends on `n` beyond
`n >= 2`, which is used only for `Inn(F_n) ≅ F_n` and plays no role in finite
presentability, since `Inn(F_n)` is finitely generated in any case.

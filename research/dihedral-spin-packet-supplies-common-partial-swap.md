title: One dihedral spin packet supplies the common partial-swap source for every Gram row

In the marked two-dimensional type of `D_8`, one literal involution has an
off-diagonal block that is a partial isometry supported exactly on the
central-sign sector.  Commuting each row involution with that same group
letter controls every Gram intertwining row, and mark mass gives a uniform
source-mass floor.

This solves common partial-swap alignment.  Constructing the required hybrid
row involutions coherently remains a separate finite-packet problem.

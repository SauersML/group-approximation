Notation as in the target. Two facts are used throughout:
- a Möbius map is determined by its values on any infinite subset of `Z_p`;
- a tree automorphism fixing 0 is an isometry, so it maps every shell `S_j` onto
  itself.

**Step 1: pieces off 0.** `Z_p \ p^JZ_p` is compact and misses 0. By condition 2
it is covered by finitely many open sets on which `g_i` agrees with elements of
`PGL_2(Q)`. Together with the `M^{(i)}_j`, these are the **pieces** of `g_i`;
the pieces of `g_i^{-1}` are their inverses.

**Step 2: the germ at 0 of a word.** Let `W = w_n ⋯ w_1` be a word in
`Γ_0 ∪ {g_i^{±1}}` with `W(0) = 0`. Put `x_0 = 0` and `x_k = w_k(x_{k-1})`. Let
`k_1 < ... < k_s` be the indices with `x_{k-1} = 0` and `w_k = g_{i_k}^{e_k}`.

- Every other letter agrees near `x_{k-1}` with an element of `PGL_2(Q)`: the
  letter itself if it lies in `Γ_0`, and a piece of `g_i^{±1}` at
  `x_{k-1} ≠ 0` otherwise (Step 1).
- Between consecutive singular visits the path goes from 0 to 0. So the
  composite of those letters agrees, near 0, with some `m_t ∈ PGL_2(Q)` with
  `m_t(0) = 0`.
- Near 0 this composite is a tree automorphism fixing 0, so it preserves the
  shells. Hence `m_t` maps `S_j` onto `S_j` for all large `j`.

For all `j` beyond some `J_W`, every factor is then defined on `S_j` and maps it
onto `S_j`. So `W` agrees on `S_j` with
`F_W(M_j) := m_s · (M^{(i_s)}_j)^{e_s} · m_{s-1} ⋯ m_1 · (M^{(i_1)}_j)^{e_1} · m_0`,
where `M_j = (M^{(1)}_j, ..., M^{(r)}_j)`.

**Step 3: the recursion.**
- By hypothesis `g_i|_0 = W_i` for words `W_i`. Since `g_i|_0` fixes 0, so does
  `W_i`. For `w ∈ S_j` we have `pw ∈ S_{j+1}`, so
  `g_i|_0 = ρ^{-1} g_i ρ` agrees on `S_j` with `ρ^{-1} M^{(i)}_{j+1} ρ`.
- By Step 2, `W_i` agrees on `S_j` with `F_{W_i}(M_j)` for large `j`. Both are
  Möbius maps that agree on the infinite set `S_j`, so
  `M^{(i)}_{j+1} = ρ F_{W_i}(M_j) ρ^{-1}` for all `j >= J'`.
- Let `H_0 <= PGL_2(Q)` be generated by `ρ`, the tuple `M_{J'}`, and the finitely
  many coefficients `m_t` of the words `W_1, ..., W_r`. By induction on `j`,
  `M^{(i)}_j ∈ H_0` for all `j >= J'`.
- The finitely many pieces of Step 1, and the `M^{(i)}_j` with `J <= j < J'`,
  are finitely many further elements. So all pieces of all `g_i` lie in one
  finitely generated `H_1 <= PGL_2(Q)`. Put `H = ⟨H_1, Γ_0⟩`.
- `H` is finitely generated, so it lies in `PGL_2(Z[1/N])` for some `N`.

**Step 4: pieces of arbitrary elements.** Let `h ∈ Λ` be written as a word.
- Its **singular points** are the points `x` at which some letter `g_i^{±1}` is
  applied at 0 along the path of `x`. There are finitely many, one for each
  such letter.
- Off the singular points, `h` agrees near each point with a composite of
  pieces, hence with an element of `H`.
- Now let `ℓ ∈ PGL_2(Q)` agree with `h` on a nonempty open `U`. Removing the
  finitely many singular points leaves an open set on which `h` agrees locally
  with some `η ∈ H`. Then `ℓ = η` there, so `ℓ = η ∈ H <= PGL_2(Z[1/N])`.

**Consequences.**
- `d_q = [diag(q,1)] ∈ PGL_2(Z[1/N])` forces `q | N`.
- `Γ_p` contains `d_q` for every prime `q ≠ p`, so `Γ_p ⊄ Λ`.
- A self-similar `Λ` has `g_i|_0 ∈ Λ`, so the statement applies to it with no
  finiteness hypothesis on `Λ`.

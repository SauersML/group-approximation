**ESTABLISHED** (lane proof, elementary, not reviewed; no priority claimed).

- **What it sharpens.** `amir-lazarovich-lattice-torsion-is-square-diagonals` reduced AL's torsion
  question to one involution per edge of `O_d`. Here all those involutions are conjugate, and one of
  them lying in `Λ` forces `Λ = Λ'^+`.
- **Consequence.** AL's open question "does Λ have torsion" becomes "is the explicit index-4 subgroup
  `Λ'^+` simple". The answer is yes exactly when `Λ` has torsion.

## Setting

AL = Amir–Lazarovich, arXiv:2605.09493. Artifact §A records the data below, with line numbers.

- **The lattice.** `Λ'` is the lattice of AL's proof of Theorem A: the group of Prop. "the lattice
  Lambda",
  `⟨Z ∪ V | z², D², [D,D'] ({D,D'} ∈ E(O_d)), z·D·δ_D(z)·ζ_z(D) (z ∈ Z, D ∈ V)⟩`.
  - `V = V(O_d)` and `ℓ = 2d−1`.
  - The interlacing pair is AL's, built from an involutive BMW group `Γ` with alternating local
    actions and an n-scaffolding satisfying (E1)–(E4).
- **The pair.**
  - `Z = 𝒳 ⊔ 𝒴`, with `ζ_{x_i} = ξ_i` and `ζ_{y_j} = υ_j`.
  - `δ_{A_i} = α_i` is supported in `𝒳`, `δ_B = (x_1 y_1)(x_2 x_3)`, and
    `δ_{C_i} = (y_i y_{i+1})(y_{i+2} y_{i+3})`.
  - `δ_D = id` for the other D; call these D **generic**. They exist, since
    `|𝒜' ∪ 𝒞| = n+1+k < |V|`.
  - Call `y_j` **legal at D** if `δ_D(y_j) = y_j`.
- **The subgroups.**
  - `χ: Λ' → (Z/2)²` sends `z ↦ (1,0)` and `D ↦ (0,1)`.
  - `Λ'^+ = ker χ` has index 4. It is the colour-preserving subgroup `Λ'_col` of the required node,
    and it is AL's `Λ'^+`, which has index 4 and lies in `Λ'_col`.
  - `Λ` is the finite residual of `Λ'`, and `q: Λ' → Q := Λ'/Λ`. Since `Λ'^+` has finite index,
    `Λ ⊆ Λ'^+`.

## Statement

1. **Conjugacy.** All vertex generators `D ∈ V` are conjugate in `Λ'`, and so are all square
   diagonals `DD'` with `{D,D'} ∈ E(O_d)`. In both cases the conjugators lie in
   `W_𝒴 = ⟨y_1, …, y_k⟩`. In particular `Λ'` is generated by the `c+1` involutions `Z ∪ {D_0}`, for
   any single `D_0`.
2. **Collapse.** If `Λ` contains one square diagonal, then `Λ = Λ'^+` and `Q ≅ (Z/2)²`. This part
   needs neither simplicity nor finite index of `Λ`.
3. **Dichotomy.** Under the hypotheses of AL's Theorem A the following are equivalent:
   - (a) `Λ` has a nontrivial element of finite order;
   - (b) `DD' ∈ Λ` for some edge `{D,D'}`;
   - (c) `DD' ∈ Λ` for every edge;
   - (d) `Λ = Λ'^+`;
   - (e) `[Λ' : Λ] = 4`;
   - (f) `Λ'^+` is simple;
   - (g) `q(D)` is central in `Q`, for one (equivalently every) D.

   So `Λ` is torsion-free iff `Λ'^+` has a proper finite-index subgroup, iff `Λ'` has a finite
   quotient of order `> 4`. In that case `Λ` is a finitely presented simple group of cohomological
   dimension 3, which answers Kourovka 21.46 and AL's Question.
4. **A finite test.** Let `r ≠ 1` lie in the finite residual `Γ^(∞)` of the embedded BMW group. Then
   `Λ = ⟨⟨r⟩⟩_{Λ'}`. So `Λ` has torsion iff the finitely presented, a priori finite, group
   `Λ'/⟨⟨r⟩⟩` has order 4. Equivalently, `D_0 D_0' = 1` there for one fixed edge `{D_0, D_0'}`.

## Proof

### Three facts about the y-generators

- **(Y1)** If `y_j` is legal at D, then `y_j D y_j = υ_j(D)`.
  - This is the relator `z·D·δ_D(z)·ζ_z(D)` with `z = y_j = δ_D(z)`, using that all generators are
    involutions.
- **(Y2)** If `y_j` is not legal at D, then `υ_j` fixes D and fixes every neighbour of D in `O_d`.
  - Only `D = B` (and only `j = 1`) and `D = C_i` (and only `i <= j <= i+3`) have `δ_D` moving a y.
  - In those cases `supp υ_j ⊆ D`, by (E3) for B and by (E4) for `C_i`.
  - So `υ_j` preserves the set D, and fixes pointwise every neighbour of D, which is a `(d−1)`-set
    disjoint from D.
- **(Y3)** `⟨υ_1, …, υ_k⟩ = Alt_ℓ`, by (E3). It is transitive on V and on `E(O_d)`: the
  `Sym_ℓ`-stabilizer of an edge contains `Sym(D)`, so it contains odd permutations.

### Item 1

- **Vertices.** Let `𝒱 ⊆ V` be the set of D that are `W_𝒴`-conjugate to `D_0`. Take `D ∈ 𝒱` and any j.
  - If `y_j` is legal at D, then `υ_j(D) = y_j D y_j ∈ 𝒱` by (Y1).
  - Otherwise `υ_j(D) = D` by (Y2).
  - So `𝒱` is invariant under every `υ_j`, hence under `Alt_ℓ`, and `𝒱 = V` by (Y3).
- **Edges.** Let `ℰ_0` be the set of edges `{D,D'}` with `DD'` `W_𝒴`-conjugate to `D_0 D_0'`. Take
  `{D,D'} ∈ ℰ_0` and any j.
  - If `y_j` is legal at both, then `y_j DD' y_j = υ_j(D) υ_j(D')` by (Y1), and `υ_j` maps edges to
    edges.
  - If `y_j` is not legal at D, then by (Y2) `υ_j` fixes D and its neighbour D', so it fixes the
    edge. The same holds with D and D' exchanged.
  - So `ℰ_0` is `Alt_ℓ`-invariant, and `ℰ_0 = E(O_d)` by (Y3).
- **Generation.** Every `D = w D_0 w^{-1}` with `w ∈ W_𝒴`.

### Item 2

- **All `q(D)` are equal.** Suppose `D_0 D_0' ∈ Λ`. By item 1 and normality, `DD' ∈ Λ` for every edge,
  so `q(D) = q(D')` along every edge. `O_d` is connected, so `q(D) = d̄` for all D.
- **`d̄` is central.** For a generic D the relator is `z·D·z·ζ_z(D)`, which gives `(q(z) d̄)² = 1`. So
  `q(z)` commutes with `d̄` for every z.
- **All `q(z)` are equal.** For any D the relator now gives `q(z) q(δ_D(z)) = 1`, so
  `q(δ_D(z)) = q(z)`. The group `⟨δ_D : D ∈ V⟩ = Alt(Z)` (AL Claim "the local actions of Λ") is
  transitive on Z. So `q(z) = z̄` for all z.
- **Conclusion.** `Q = ⟨d̄, z̄⟩` is abelian of order at most 4. It maps onto
  `Λ'/Λ'^+ ≅ (Z/2)²` because `Λ ⊆ Λ'^+`. So `Q ≅ (Z/2)²` and `Λ = Λ'^+`.

### Item 3

- **(a) ⟹ (b).** This is item 1 of the required node: every nontrivial finite-order element of
  `Λ'_col = Λ'^+ ⊇ Λ` is conjugate to some `DD'`, and `Λ` is normal.
- **The cycle.**
  - (b) ⟹ (c): item 1.
  - (c) ⟹ (d): item 2.
  - (d) ⟹ (a): `DD' ∈ Λ'^+` has order 2.
  - (d) ⟺ (e): `Λ ⊆ Λ'^+`, and `Λ'^+` has index 4.
- **(d) ⟺ (f).** `Λ` is simple (AL Theorem A), so (d) ⟹ (f). Conversely `Λ ⊴ Λ'^+` and `Λ ≠ 1`,
  since `Λ'` is not residually finite. So (f) ⟹ (d).
- **(g).** If `q(D_0)` is central, then every `q(D)` is conjugate to `q(D_0)` by item 1, hence equal
  to it. The last three steps of item 2 then give (d). Conversely (d) makes Q abelian.
- **Dimension.** A torsion-free uniform lattice in `T_c × X_{O_d}` has cd 3 (AL, Discussion). `Λ` is
  finitely presented because it has finite index in `Λ'`.

### Item 4

- **`⟨⟨r⟩⟩ = Λ`.** `Λ'` is just-infinite (Bader–Shalom, as in AL's proof). So `⟨⟨r⟩⟩` has finite
  index, and it therefore contains `Λ`. Conversely every finite-index subgroup of `Λ'` meets `Γ` in a
  finite-index subgroup, so `r ∈ Γ^(∞) ⊆ Λ`.
- **The test.** Apply item 3 to `Q = Λ'/⟨⟨r⟩⟩`, and items 1–2 for the single-edge form.
- **Precedent.** This is Radu's device for computing `[Γ : Γ^(∞)]` for BMW groups (artifact §C).

## Scope

- **Decided later, elsewhere.**
  - `amir-lazarovich-simple-lattices-have-torsion` (bh-free-extensions) proves the torsion
    alternative `Λ = Λ'^+` for AL's explicit scaffolding (d ≥ 9) and for seeds with a collapsed pair
    `a_j a_k ∈ FR(Γ)`.
  - `amir-lazarovich-plus-subgroup-is-perfect` shows that `Λ'^+` is perfect for every seed. So the
    torsion-free alternative always needs a nonabelian finite simple quotient of `Λ'^+`.
  - This node by itself decides nothing for an explicit `Λ'`.
  - Radu's (6,6)-groups have index exactly 4 in 158 of 160 cases (artifact §C). That is weak
    evidence for the torsion alternative, and it concerns BMW groups, not AL lattices.
  - A positive answer to 21.46 along this route needs a proper finite-index subgroup of `Λ'^+`.
  - The torsion alternative needs a proof that `Λ'^+` is simple. Item 4 is one way to get it.
- **Hypotheses used.** The scaffolding enters only through (Y2), that is (E3) and (E4). So the
  theorem holds for every n-scaffolding in AL's sense.
  - AL's printed explicit scaffolding violates (E4) for `d <= 8`, although Theorem A survives
    (artifact §B). Taking `d >= 9` gives (E4).
  - The same argument works for any interlacing pair on `O_d` that has a set `Y ⊆ Z` with three
    properties:
    - `⟨ζ_y : y ∈ Y⟩` is transitive on `V` and on `E(O_d)`;
    - `δ_D(y) ≠ y` forces `ζ_y` to fix D and all its neighbours;
    - `⟨δ_D⟩` is transitive on Z, and some `δ_D` is trivial.

## Lesson for general BH

- **The mechanism.** A group acting simply transitively on the vertices of a product has "legal
  moves": the relator `yDy = υ(D)`, where the state y is untwisted at D. They conjugate generators of
  the same type into each other, and the twisted moves fix what they touch. So a large, transitive
  group of legal moves makes every generator of one type conjugate.
- **Consequence for simple hosts.** Once one "diagonal" dies in a finite quotient, the whole
  quotient collapses to the colouring. So the finite residual of an NST lattice is either the
  explicit colour-preserving subgroup or it is cut out by a nonabelian quotient.
- **Tool.** One relator `r ∈ Γ^(∞)` from an embedded non-residually-finite seed computes the finite
  residual as `⟨⟨r⟩⟩` (Radu's device). This gives explicit presentations of NST-simple hosts, which
  matters wherever BH hosts must be written down, for instance for formal verification.

Notation as in the target claim. Lane-proved, not independently reviewed.

## Imports (standard; numbering to be checked by the referee)

- **(T) for S-arithmetic SL_3.** For `m >= 1`, `Λ_m = SL_3(Z[1/m])` is an
  irreducible lattice in `SL_3(R) × ∏_{p | m} SL_3(Q_p)` (Borel--Harish-Chandra).
  Each factor has property (T) (Kazhdan; Bekka--de la Harpe--Valette, *Kazhdan's
  Property (T)*, §1.4), finite products of (T) groups have (T), and lattices
  inherit (T) (ibid., Theorem 1.7.1). So every finite-index subgroup of `Λ_m`
  is an infinite Kazhdan group.
- **Normal subgroup theorem.** Margulis (S-arithmetic form; the `S`-rank of
  `SL_3` is at least 2): a normal subgroup of a finite-index subgroup `L` of
  `Λ_m` is either central or of finite index in `L`.

## Step 0. The centre is trivial

Let `L <= Λ_m` have finite index. `L ∩ SL_3(Z)` has finite index in `SL_3(Z)`,
so it is Zariski-dense in `SL_3` (Borel density). A central element of `L`
therefore commutes with a Zariski-dense subgroup, so it is a scalar matrix
`λI` with `λ^3 = 1` and `λ in Q`, which means `λ = 1`. So every normal subgroup
of `L` is trivial or of finite index in `L`.

## Step 1. One injective germ coordinate for each m

`GL_n(Q) >= SL_3(Q) >= Λ_m` for `n >= 3`, by the upper-left block embedding.
Fix `m`, and apply part 1 of `almost-v-fw-subgroups-act-through-finitely-many-germs`
to `Γ = Λ_m <= E <= H`, which has FW by the imports. This gives a finite-index
`Γ_0 <= Λ_m`, a finite set `F` fixed pointwise by `Γ_0`, `h in H`, and the germ
map `φ : Γ_0 -> ∏_{y in F} (E)_y` with `ker φ <= h V h^-1`.

- **φ is injective.** `ker φ` is normal in `Γ_0`, so by Step 0 it is trivial or
  of finite index. If it had finite index it would be an infinite Kazhdan group.
  Then `h^-1 (ker φ) h` would be an infinite FW subgroup of `V`, which is
  impossible by part 2 of `fw-subgroups-of-eventually-similar-groups-virtually-embed`.
- **Some coordinate is injective.** For `y in F` let `φ_y` be the coordinate
  map. Each `ker φ_y` is normal in `Γ_0`, so trivial or of finite index. If all
  were of finite index, `ker φ = ⋂_y ker φ_y` would have finite index, and then
  the infinite group `Γ_0` would be finite. So `φ_y` is injective for some
  `y = y_m in F`.
- **y_m is singular for E.** If every element of `Γ_0` were V-local at `y_m`,
  `φ_{y_m}` would take values in the germ group `(V)_{y_m}`. That group is
  infinite cyclic or trivial. A Kazhdan group has finite abelianization, so the
  image would be finite, contradicting injectivity. So `y_m in sing(E)`.

Put `L_m = Γ_0`. It has finite index in `Λ_m` and embeds in `(E)_{y_m}`.

## Step 2. One point for all m

Let `p_1, ..., p_r` represent the finitely many `E`-orbits in `sing(E)`. If
`y = e p_i`, conjugation by the germ of `e` at `p_i` is an isomorphism
`(E)_{p_i} -> (E)_y`. So for each `m` some `i(m)` has `L_m` embedding in
`(E)_{p_{i(m)}}`.

Some index `i` equals `i(k!)` for infinitely many `k`. Given `m`, choose such
`k >= m`, so that `m | k!` and `Λ_m <= Λ_{k!}`. Then `L_{k!} ∩ Λ_m` has finite
index in `Λ_m` and embeds in `(E)_{p_i}`. Take `p = p_i`.

## Step 3. Finitely generated E

If `E` is generated by a finite set `S`, then
`sing(s_1 ... s_k) ⊆ ⋃_j (s_{j+1} ... s_k)^-1 sing(s_j)`, and
`sing(s^-1) = s(sing s)`. So `sing(E)` lies in the union of the `E`-orbits of
the finite set `⋃_{s in S} sing(s)`. ∎

## Consequences, as stated in the claim

An infinite Kazhdan subgroup rules out amenability and a-T-menability of
`(E)_p` (a-T-menable groups have only finite Kazhdan subgroups), hence rules
out `(E)_p <= nV` by `brin-thompson-groups-nv-are-a-t-menable`. For `n = 2`
the claim's scope paragraph shows the method is empty.

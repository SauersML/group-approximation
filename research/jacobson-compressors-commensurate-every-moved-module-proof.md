Notation as in the target. `F` is any field until Step 7. `R = F[x,x^-1]` and `V = F[x]^N`. For a Laurent
matrix `A` (of any size) put `T_A f = P_+(A f)` on polynomial vectors. The corner theorem is used only in Step 6, to
compare the two situations. Steps 1 and 5 repeat the elementary parts of its proof in the generality needed here.

## Step 0. Elements of `M(J)` are Toeplitz operators plus finite rank

Write `e_i = x^i`. On `F[x]`, `S = T_x` exactly. Also `T f = P_+(x^-1 f) = T_(x^-1) f`, since `P_+` removes only
`x^-1 f_0`. `J` is spanned by the words `S^i T^j`.
- `S^i T^j` and `T_(x^(i-j))` agree on `x^k` for `k >= j`. On the finitely many `x^k` with `k < j`, the first is `0`.
- So `S^i T^j - T_(x^(i-j))` has finite rank.

By linearity, every `a` in `J` satisfies `a = T_(rho(a)) + (finite rank)`. The same holds for rectangular matrices
over `J` acting between the modules `F[x]^k`, entrywise. Finite-rank operators form the ideal `I`, and `rho` is
reduction modulo `I`.

Two perturbation facts, for linear maps `A, B` with `B` of finite rank:
- `im(A + B) ~ im(A)`, because `im(A+B) <= im A + im B` and `im A <= im(A+B) + im B`;
- `ker(A + B) ~ ker(A)`, because `ker A cap ker B = ker(A+B) cap ker B` has finite codimension in both.

## Step 1. Images of Toeplitz operators (Lemma A)

**Lemma A.** Let `A` be an `N x k` matrix over `R`, and `X = A R^k <= R^N`. Then `im(T_A : F[x]^k -> F[x]^N) ~ W(X)`.

*Proof.*
- **Lower bound.** Pick `d` with `x^d A` polynomial. For `h` in `F[x]^k`, `T_A(x^d h) = x^d A h`, because it is
  already polynomial. So `im T_A` contains `X_0 = x^d A F[x]^k`, an `F[x]`-submodule of `W(X)`.
- **`X_0` has finite codimension in `W(X)`.** `W(X)` is a finitely generated `F[x]`-module, as a submodule of
  `F[x]^N`. Inverting `x` gives `R X_0 = X = R W(X)`. So `W(X)/X_0` is finitely generated and killed by a power of
  `x` elementwise, hence torsion, hence finite-dimensional.
- **Upper bound.** Let `b_1..b_r` be the columns of `A`. As an `F`-space, `X` is spanned by the vectors `x^j b_i`
  with `j` in `Z`. Choose `D` so that every entry of every `b_i` has all exponents in `[-D, D]`. Then:
  - for `j < -D`, `P_+(x^j b_i) = 0`;
  - for `j > D`, `x^j b_i` is polynomial, so `P_+(x^j b_i) = x^j b_i` lies in `W(X)`.

  Since `P_+` is linear, `im T_A <= P_+(X) <= W(X) + Phi`, with
  `Phi = span{P_+(x^j b_i) : |j| <= D}` finite-dimensional.

Together, `im T_A cap W(X) >= X_0` has finite codimension in `W(X)`, and `im T_A / (im T_A cap W(X))` embeds in
`(W(X) + Phi)/W(X)`. QED.

## Step 2. Kernels of Toeplitz operators (Lemma B)

**Lemma B.** Let `A` be a `k x N` matrix over `R`, and `Y = ker(A : R^N -> R^k)`. Then `ker(T_A) ~ W(Y)`.

*Proof.*
- If `f` lies in `W(Y)`, then `A f = 0`, so `T_A f = 0`. Hence `W(Y) <= ker T_A`.
- Choose `D` with `x^D A` polynomial. If `f` lies in `x^D F[x]^N` and `T_A f = 0`, then `A f` is polynomial, so
  `A f = P_+(A f) = 0` and `f` lies in `W(Y)`.
- So `ker T_A cap x^D F[x]^N <= W(Y)`, and `x^D F[x]^N` has codimension `ND` in `F[x]^N`. QED.

## Step 3. The Toeplitz shadow (Theorem part 1)

Let `Gamma` be generated by `s_1..s_k`, and put `A_i = s_i - 1` in `M_N(J)`.

**Moved module.**
- For `gamma, delta` in `Gamma`, `(gamma delta - 1) v = (gamma - 1)(delta v) + (delta - 1) v`, and
  `(gamma^-1 - 1) v = -(gamma - 1)(gamma^-1 v)`.
- So `Mov(Gamma) = im(A_1) + ... + im(A_k)`. This is the image of the `N x kN` block row `A = [A_1, ..., A_k]`
  acting from `V^k` to `V`.
- The same identities in `GL_N(R)` give `M(Gamma) = rho(A) R^(kN)`.
- By Step 0, `A = T_(rho(A)) + (finite rank)`. By Lemma A, `Mov(Gamma) ~ W(M(Gamma))`.

**Fixed module.**
- `Fix(Gamma)` is the kernel of the `kN x N` block column `C = [A_1; ...; A_k]` acting on `V`.
- `K(Gamma)` is the kernel of `rho(C)` on `R^N`, since fixing the generators means fixing the group.
- By Step 0 and Lemma B, `Fix(Gamma) ~ W(K(Gamma))`.

Only finite generation of `Gamma` is used.

## Step 4. Symbol rigidity (Theorem part 2)

**Lemma C.** Let `R` be a noetherian domain of Krull dimension one, for instance `F[x,x^-1]`. Let `X <= R^N` be a
submodule and `h` in `GL_N(R)` with `h X <= X`. Then `h X = X`.

*Proof.*
- Let `k` be the fraction field and `U = k X`. Since `h U <= U` and `h` is injective with equal finite dimensions,
  `h U = U`.
- The saturation `X^s = U cap R^N` therefore satisfies `h X^s = h U cap h R^N = U cap R^N = X^s`.
- `X^s / X` is finitely generated and torsion. In Krull dimension one it has finite length `l`.
- `h` restricts to a bijection `X^s -> X^s` carrying `X` onto `h X`. So `X^s / h X` also has length `l`.
- Additivity of length along `h X <= X <= X^s` gives `length(X / h X) = 0`. QED.

**Application.** Let `g Gamma g^-1 <= Gamma` and `h = rho(g)`.
- The symbol moved module of `g Gamma g^-1` is `h M(Gamma)`, since `(h gamma h^-1 - 1) R^N = h (gamma - 1) R^N`.
  Moved modules grow with the subgroup, so `h M(Gamma) <= M(Gamma)`.
- Lemma C gives `h M(Gamma) = M(Gamma)`.
- In the same way `K(g Gamma g^-1) = h K(Gamma) >= K(Gamma)`. Apply Lemma C to `h^-1` and `K(Gamma)` to get
  equality.

Neither step assumes `h rho(Gamma) h^-1 = rho(Gamma)`.

## Step 5. Commensuration and the index homomorphisms (Theorem parts 3 and 4)

Let `g` compress `Gamma`.

**Moved module.**
- `(g gamma g^-1 - 1) V = g (gamma - 1) V`, so `g Mov(Gamma) = Mov(g Gamma g^-1)`. That is at most `Mov(Gamma)`,
  because `g Gamma g^-1 <= Gamma`.
- `g Gamma g^-1` is finitely generated. By Steps 3 and 4,
  `Mov(g Gamma g^-1) ~ W(h M(Gamma)) = W(M(Gamma)) ~ Mov(Gamma)`.
- So `g Mov(Gamma)` has finite codimension `c(g)` in `Mov(Gamma)`.

**Fixed module.** Likewise `g Fix(Gamma) = Fix(g Gamma g^-1) >= Fix(Gamma)`, and `W(h K) = W(K)` gives finite
codimension `c'(g)`.

**The hull.**
- Commensurability is an equivalence relation on subspaces.
- For linear automorphisms `a, b` commensurating a subspace `Z`, the product `ab` commensurates `Z`, because
  `ab Z ~ a Z ~ Z`. The inverse `a^-1` commensurates `Z`, because applying `a^-1` to `a Z ~ Z` gives `Z ~ a^-1 Z`.
- So the compressors and their inverses generate a group `D_H` that commensurates `Mov(Gamma)` and `Fix(Gamma)`.

**Additivity.** Use the relative dimension
`[A : B] = dim A/(A cap B) - dim B/(A cap B)`. It is additive on pairwise commensurable triples and invariant under
linear automorphisms. So
`ind(ab) = [Mov : ab Mov] = [Mov : a Mov] + [a Mov : ab Mov] = ind(a) + ind(b)`, and the same computation works for
`ind'`. On a compressor, `ind(g) = c(g) >= 0` and `ind'(g) = c'(g) >= 0`.

## Step 6. The corollary, and why corners are special

**Corollary.**
- Let `G` be Kazhdan and `Gamma` infranormal in `G`. Then `D_G = G`.
- `G` has finite abelianization, so `ind` and `ind'` vanish on `G`.
- So `c(g) = c'(g) = 0` for every compressor `g`: `g Mov = Mov` and `g Fix = Fix`.

Only the absence of nonzero homomorphisms `D_G -> Z` was used.

**Comparison with the corner theorem.**
- For a corner, `Mov = V_1` and `Fix = V_2` are complementary. The conclusion then makes `g` block diagonal, and
  normality of `Gamma_1` in `GL_m(J)` gives `g Gamma g^-1 = Gamma` (Step 3 of
  `jacobson-corner-compressor-hulls-carry-fredholm-index-proof`).
- For a general `Gamma`, `Mov` and `Fix` need not be complementary, and `Gamma` need not be normal in their joint
  stabilizer. So a zero index does not by itself give normality. That is exactly what the decomposition in the target
  records.

In particular, the corner theorem's survivor, "non-corners whose moved module is not commensurated", is empty. By
Step 5, every finitely generated `Gamma` has its moved module commensurated by all of its compressors.

## Step 7. The decomposition of what survives

Let `g` compress `Gamma` strictly, with `g Mov = Mov` and `g Fix = Fix`. Put `h = rho(g)`, `Gammabar = rho(Gamma)`,
and `L = Gamma cap GL_N(J, I)`.

**The dichotomy.** Suppose `h Gammabar h^-1 = Gammabar`, which is the negation of (S).
- For `gamma` in `Gamma`, choose `gamma'` in `g Gamma g^-1` with the same symbol. Then `gamma'^-1 gamma` lies in
  `Gamma cap ker rho = L`.
- So `Gamma = (g Gamma g^-1) L`. Also `(g Gamma g^-1) cap L = g L g^-1`, since `g` preserves `ker rho`.
- Hence the coset map `L / g L g^-1 -> Gamma / g Gamma g^-1` is a bijection, and
  `[Gamma : g Gamma g^-1] = [L : g L g^-1]`.
- Strictness forces `g L g^-1 < L` strictly. That is (F).
- Conversely, if (S) holds then `h` does not normalize `Gammabar`, so (F) fails. The two cases exclude each other.

If `F` is finite, `GL_N(J, I)` is the union of the finite groups `1 + M_n(F)` on finite coordinate blocks, so `L` is
locally finite.

**The lattice remark in (S).** Assume `F` is finite, and put `Y = SL_N(F((x))) x SL_N(F((x^-1)))`.
- `R` is the ring of `{0, infinity}`-integers of `F(x)`, so it embeds diagonally as a discrete cocompact subring of
  `F((x)) x F((x^-1))`.
- `SL_N(R)` is a lattice in `Y`. This is Harder's theorem on `S`-arithmetic groups over global function fields: for
  split `SL_N`, the `S`-arithmetic subgroup is a lattice in the product over `S` of the local groups.
- Conjugation by `h` in `GL_N(R)` is a topological automorphism of `Y`. Its modulus is a continuous homomorphism
  `GL_N(F((x))) x GL_N(F((x^-1))) -> R_(>0)`. It is trivial on `Y`, because `Y` is unimodular and the automorphism is
  then inner. It is trivial on scalars. The quotient of `GL_N` by `SL_N` times scalars is a quotient of
  `K^x / (K^x)^N`, which is `N`-torsion. So the modulus is trivial, and `h` preserves Haar measure on `Y`.
- Let `Gamma_0 = Gammabar cap SL_N(R)`. Conjugation preserves the determinant, so `h Gamma_0 h^-1 <= Gamma_0`.
- If `Gamma_0` had finite index in `SL_N(R)`, it and `h Gamma_0 h^-1` would be lattices in `Y` of equal covolume.
  One contains the other, so they are equal.
- The determinant embeds `Gammabar / Gamma_0` in `R^x = F^x x <x>`. When `Gamma` is Kazhdan it has finite
  abelianization, so this quotient is finite.
- Conjugation by `h` induces an injective map on the finite coset set `Gammabar / Gamma_0`, sending
  `gamma Gamma_0` to `h gamma h^-1 Gamma_0`. It is well defined and injective because `h Gamma_0 h^-1 = Gamma_0`.
  So it is bijective, and `h Gammabar h^-1 = Gammabar`.

**Conclusion.** Let `F` be finite and `Gamma` Kazhdan. If `Gammabar cap SL_N(R)` has finite index in `SL_N(R)`, then
every compressor normalizes `Gammabar`, so (S) is impossible. Only (F) remains, and it concerns the locally finite
group `L`.

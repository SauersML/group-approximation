Notation is that of the claim. "§" refers to
`research/artifacts/simple-kazhdan-lef-subshift-elementary-group-2026-09-12.md`, whose
arguments are written over `F_q`. `Acal_0 = LC(X,Z)`.

## 1. Generators and property (T)

`R_0 = ⊕_j Acal_0 u^j`, with `(f u^i)(g u^j) = f α^i(g) u^(i+j)` (§1.2). `Acal_0` is the
`Z`-span of the indicators of cylinders. `u^i χ_[a] u^-i = χ_{x_(-i) = a}`, and products of
these give every cylinder indicator. So `R_0` is generated as a ring by `u`, `u^-1` and the
`χ_[a]`, finitely many elements. No extra scalar is needed, since `Z` is generated by `1`.

Ershov--Jaikin-Zapirain, Theorem 1.1 (quoted in §2), applies to finitely generated rings with
`1` and `n ≥ 3`. So `Q_0 = EL_3(R_0)` has (T). This is item 1.

## 2. Periodic models over Z

Take the periodic points `y^(k)` of §3.1. Their construction is purely combinatorial and
gives `L_(2k+1)(y^(k)) = L_(2k+1)(X)`, with period `N_k -> ∞`.
- For `f ∈ Acal_0` with `f(x) = Φ(x_[-ρ,ρ])`, put `D_k(f) = diag(Φ(y_[n-ρ, n+ρ]))`, indexed
  by `n ∈ Z/N_k`. It lies in `M_(N_k)(Z)`.
- Let `P_k ∈ M_(N_k)(Z)` be the cyclic shift.
- Put `ψ_k(Σ f_j u^j) = Σ D_k(f_j) P_k^j`, and `Ψ = [ψ_k]_ω`.

The checks of §3.1 ("precise range") and §3.2 use only the following:
- the window identities of `y^(k)`;
- the relation `P^i D_k(g) P^-i = D_k(α^i g)`;
- disjointness of the supports of `D_k(f_j) P_k^j` once `N_k > 2 max |j|`;
- `D_k(f) != 0` whenever `f` is nonzero on some word that occurs in `y^(k)`.

None of these uses the coefficient field. So `Ψ` is an injective unital ring homomorphism
into `prod_ω M_(N_k)(Z)`. Reducing mod `p` gives the map of §3.2 for `F_p`.

`Ψ` induces an injective homomorphism `GL_3(R_0) -> prod_ω GL_(3N_k)(Z)`. Each
`GL_(3N)(Z)` is residually finite, hence LEF. A finite window of a finitely generated
subgroup of `GL_3(R_0)` is an injective partial homomorphism into `GL_(3N_k)(Z)` for
`ω`-many `k`, and then into a finite group. So every finitely generated subgroup is LEF. This
is item 2.

## 3. Ideals of R_0 (item 4)

*Reduction mod p.* `Acal_0` is free abelian. Every `F_p`-valued locally constant function
lifts to one with values in `{0, ..., p-1}`, and the kernel of reduction is `p Acal_0`. So
`Acal_0 / p Acal_0 = LC(X,F_p)`. Since `R_0 = ⊕_j Acal_0 u^j` with the same multiplication
rule, `R_0 / p R_0 = LC(X,F_p) ⋊ Z`. This ring is simple by §1.3 with `q = p`, and it is
infinite.

*Nonzero ideals.* Let `0 != J ⊴ R_0` be two-sided. Run §1.3 over `Z`. For `0 != P ∈ J` with
`f_0(x) = c != 0`, it gives `χ_W P χ_W = c χ_W ∈ J`, with `c ∈ Z \ {0}`. Covering `X` by
translates of `W` and using inclusion-exclusion, multiplied through by `c`, gives
`c · 1 ∈ J`. Put `d = |c|`. Then `d R_0 ⊆ J`.

## 4. No finite quotients (item 3)

Let `N ⊴ Q_0` have finite index. The map `e_12 : (R_0, +) -> Q_0` is a homomorphism, so
`I = I(N) = e_12^-1(N)` is an additive subgroup of index at most `[Q_0 : N]`.

`I` is a two-sided ideal by the argument of §4.1. That argument uses only two facts:
- the commutator identities;
- that signed permutation matrices lie in `EL_3(Z) = SL_3(Z) ≤ Q_0`.

Suppose `I != R_0`. Then `R_0 / I` is a nonzero finite ring. Since it has finitely many
ideals, it has a maximal two-sided ideal. Its preimage `m_0` gives a finite simple ring
`R_0 / m_0`.

A simple ring has characteristic `0` or a prime: if `ab · 1 = 0` with `a · 1 != 0`, the
central element `a · 1` generates the unit ideal, so it is invertible, and `b · 1 = 0`.
Being finite, `R_0 / m_0` has prime characteristic `p`. So `p R_0 ⊆ m_0 ⊊ R_0`.

By §3, `m_0 / p R_0` is a proper ideal of the simple ring `R_0 / p R_0`, so `m_0 = p R_0`.
Then `R_0 / p R_0` is finite, contradicting §3.

Hence `I = R_0` and `e_12(R_0) ⊆ N`. Conjugating by signed permutation matrices gives
`e_ij(R_0) ⊆ N` for all `i != j`, so `N = Q_0`.

## 5. Residual structure (item 5)

- **Surjection.** `R_0 -> R_0 / p R_0` induces `Q_0 -> EL_3(LC(X,F_p) ⋊ Z)`. It is onto,
  because elementary generators lift.
- **Embedding.** An element of the free abelian group `R_0` that is divisible by every prime
  is `0`. So `R_0 -> prod_p R_0 / p R_0` is injective, and so is
  `GL_3(R_0) -> prod_p GL_3(R_0 / p R_0)`.
- **Not simple.** The kernel of `Q_0 -> EL_3(R_0 / 2 R_0)` contains `e_12(2) != 1`. It is
  proper, since it does not contain `e_12(1)`.

## 6. Roots and torsion (item 6)

`e_ij(r)^m = e_ij(m r)`, and `m r != 0` for `r != 0` and `m != 0`, because `R_0` is additively
torsion-free. `diag(-1,-1,1)` has order 2 and lies in `SL_3(Z) = EL_3(Z)`, and
`EL_3(Z) ≤ EL_3(R_0)` via `Z ⊂ R_0`.

## Why sufficient

Notation as in the target. For `p ∈ R_0` write `d_p = ψ(z) p ψ(z)^(-1) − p`. So `I` is the ideal generated by the
`d_p`.

**Lemma 0 (quotients).** Let `J ⊴ R` with `ψ(J) = J`, and write bars for images in `R̄ = R/J`. If `ψ̄(R̄_0) = R̄_0`,
then `I ⊆ J`.
- *Proof.* `z` commutes with `R_0`, so `ψ(z)` commutes with `ψ(R_0)`, and hence `ψ̄(z̄)` commutes with
  `ψ̄(R̄_0) = R̄_0`.
- So `d̄_p = 0` for every `p ∈ R_0`, that is, every `d_p ∈ J`.

**Step A (finite quotients).** Let `R/J` be finite, of order `m`.
1. *Finitely many ideals of index `m`.* Fix generators `g_1, …, g_s` of `R`. An ideal `J'` with `|R/J'| = m` is the
   kernel of the quotient map `R → R/J'`. Choose an isomorphism of `R/J'` with one of the finitely many ring
   structures on `{1, …, m}`. The map is then determined by the images of the `g_i`. So there are finitely many
   such kernels.
2. *`ψ` permutes them.* `ψ` induces `R/J' ≅ R/ψ(J')`. So `ψ` permutes the finite set of ideals of index `m`, and the
   orbit `{ψ^k(J)}` is finite.
3. *The stable ideal.* `J_ψ = ∩_k ψ^k(J)` is a finite intersection. `R/J_ψ` embeds in `∏_k R/ψ^k(J)`, so it is
   finite. `ψ(J_ψ) = J_ψ`, so `ψ` induces an automorphism `ψ̄` of the finite ring `R̄ = R/J_ψ`.
4. *Equality by counting.* `ψ̄(R̄_0) ⊆ R̄_0`, and `ψ̄` is injective on the finite set `R̄_0`. So `ψ̄(R̄_0) = R̄_0`.
5. *Conclusion.* Lemma 0 gives `I ⊆ J_ψ`.

**Step B (PI quotients).** Let `T = R/J ≠ 0` satisfy a polynomial identity.
1. *A simple quotient.* `T` is unital, so it has a maximal ideal `M`. `A = T/M` is simple, hence primitive, and PI.
2. *Kaplansky.* A primitive PI ring is a central simple algebra, finite-dimensional over its centre `F`, which is a
   field.
3. *Artin–Tate.* `A` is a finitely generated ring and a finitely generated module over the central subring `F`.
   The Artin–Tate lemma (Atiyah–Macdonald Prop. 7.8) says that `F` is then a finitely generated `Z`-algebra.
   - The proof there is written for commutative `C`. It uses only that `B = F` is central, when it expands products
     of algebra generators in a module basis.
4. *Nullstellensatz.* A field finitely generated as a ring is finite. So `F` is finite, and `A` is finite and
   nonzero.
5. *Conclusion.* `R → T → A` is a finite nonzero quotient of `R`, with kernel `J' ⊇ J`. By Step A, `I ⊆ J'_ψ`.
   Since `J'_ψ ⊆ J' ≠ R`, we get `I ≠ R`.

**Step C (consequences of `I = R`).**
- *Finite quotients.* By Step A, a nonzero finite quotient `R/J` gives `I ⊆ J_ψ ⊆ J ≠ R`.
- *PI quotients.* Excluded directly by Step B.
- *Finite-dimensional representations.* A nonzero homomorphism `ρ : R → M_n(K)` has image `ρ(R) ≅ R/ker ρ`. The image
  is nonzero, because it contains `ρ(1) = 1`. It satisfies the standard identity `s_(2n)`, by Amitsur–Levitzki. So
  it is excluded by Step B.
- *Matrix sizes under (R1).* Suppose `U = {j : N_j ≤ N}` is `ω`-large. Every `M_(N_j)(k_j)` with `j ∈ U` embeds in
  `M_N(k_j)`, so it satisfies the multilinear identity `s_(2N)`. A multilinear identity holding coordinatewise on an
  `ω`-large set holds in the algebraic ultraproduct. The ring `R` embeds there, so `R` is PI, which contradicts
  Step B with `J = 0`.

**Step D (dimension drop).** Write `ψ(r_i) = P_i(r_1, …, r_m)`, with `P_i` noncommutative integer polynomials. This
is possible by (R3). Fix `K ≥ 1`.
1. *Finitely many identities.* Applying `ψ^k` gives `ψ^(k+1)(r_i) = P_i(ψ^k(r_1), …, ψ^k(r_m))`. Applying `ψ^k` to
   `[z, r_i] = 0` gives `[ψ^k(z), ψ^k(r_i)] = 0`. For `0 ≤ k ≤ K` these are finitely many identities in `R`. An
   element of the algebraic ultraproduct is zero exactly when its coordinates vanish on an `ω`-large set, so all of
   them hold exactly in coordinate `j` for `ω`-almost every `j`.
2. *Inclusion.* At such `j`, each generator `ψ^(k+1)(r_i)_j` of `A_j^(k+1)` is a polynomial in the generators of
   `A_j^(k)`. So `A_j^(k+1) ⊆ A_j^(k)`.
3. *Strictness.* Suppose `A_j^(k+1) = A_j^(k)` on an `ω`-large set `U`, for some `k ≤ K − 1`.
   - At `j ∈ U`, `ψ^(k+1)(z)_j` commutes with the generators of `A_j^(k+1)` (identity of step 1 at `k+1`). So it
     commutes with `A_j^(k)`, and in particular with every `ψ^k(r_i)_j`.
   - So `[ψ^(k+1)(z), ψ^k(r_i)]` has coordinates vanishing on `U`. Its image in the ultraproduct is `0`, and since
     `ι` is injective it is `0` in `R`.
   - Apply `ψ^(−k)`: `ψ(z)` commutes with every `r_i`, hence with `R_0`. So `I = 0`, which contradicts `I = R ≠ 0`.
4. *Conclusion.* Since `ω` is an ultrafilter, for each `k < K` the inclusion is strict on an `ω`-large set.
   Intersecting finitely many such sets gives the strict chain `A_j^(0) ⊋ … ⊋ A_j^(K)` for `ω`-almost every `j`.
   Each `A_j^(k)` is unital, so it has dimension at least `1`, and therefore `dim A_j^(0) ≥ K + 1`.

## Remarks

- Steps A–C never use (R1), nor finite generation of `R_0`. Step D uses (R1) and the finite generation of `R_0`.
- (R2)–(R5) pass to every quotient `R/J` with `ψ(J) = J`: the image of `I` is the ideal generated by the images of
  the `d_p`. So a ψ-stable maximal ideal would move any witness to a simple infinite ring, which is the setting of
  `simple-ring-with-centralizer-compressing-automorphism`, with the root in `R/M`. What does not pass to quotients
  is (R1), and `z ∈ [S^×, S^×]`.
- Citations used as black boxes, standard and not re-derived here: Kaplansky's theorem on primitive PI rings,
  Amitsur–Levitzki, the Artin–Tate lemma, and the fact that a field finitely generated as a ring is finite.

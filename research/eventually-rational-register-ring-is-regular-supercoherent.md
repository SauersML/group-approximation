**ESTABLISHED** through the proof below (lane proof; re-review requested). The first
version covered only the full-tail ring; referees a (288dbe786) and b (27950613e) passed
its part 1 with one correction, now made: over a von Neumann regular ring every module is
*flat*, and only finitely presented modules are projective. Part 2 is also a citation:
"any coherent ring ... of weak global dimension at most 1 (i.e., semihereditary), is
stably coherent" (arXiv:2509.05109, Proposition 4.36, quoted by referee b; the classical
source, Glaz, *Commutative Coherent Rings*, LNM 1371, Ch. 7, was not read). The direct
proof below does not rely on it. The earlier remark that von Neumann regular rings can fail
stable coherence was wrong and has been deleted: Soublin's example, `∏ Q[[x,y]]`, is not
von Neumann regular.

## The ring
Fix a type and write states as `n ∈ ℕ`. Let `T ⊆ Q(t)` be a localization of `Q[t]` at a
multiplicative set of polynomials. `T` is a PID, and it is closed under the tail
substitutions of the letters (`r(t) ↦ r(t + a)`, `r(pt + r')`). Put
`B⁺_T = { f : ℕ -> Q  |  f(n) = r(n) for all large n, for some r ∈ T }`. It sits in an
exact sequence `0 -> J -> B⁺_T -> T -> 0`, where `J = ⊕_ℕ Q` is the ideal of finitely
supported functions.

The coefficient ring `B⁺` of a single-register completion, the `σ`-closure of registers,
indicators, reciprocals and resolvents, is a finite product of such rings, one per type.
- **The generated ring is not the full ring.** Its tails lie in the localization `T`
  generated by the relevant denominators and their transports, not in all of `Q(t)`. For
  example, `1/(N−5)` is missing unless `N − 5` is inverted, which is referee a's
  correction to the first version of this node.
- **The full-tail case.** For `T = Q(t)` the ring is von Neumann regular. Given `f`, the
  function `g = 1/f` off the zero set and `0` on it lies in the ring, and `fgf = f`.
  Von Neumann regular rings have flat dimension `0`; only their finitely presented
  modules are projective, which corrects the first version.

## Statement
1. `B⁺_T` is **semihereditary**: every finitely generated ideal is projective. Hence it is
   coherent, with weak global dimension `<= 1`.
2. `B⁺_T[x_1..x_p]` is **coherent** for every `p`, so `B⁺_T` is stably coherent.
3. `B⁺_T` is **regular supercoherent** in the sense of ABC §7: each `B⁺_T[x_1..x_p]` is
   coherent, and its finitely presented modules have projective dimension `<= p + 1`.
4. **Flatness of substitutions.** Let `σ : B⁺_T -> B⁺_(T')` be induced by
   `N ↦ N + a`, `N ↦ pN + r` or `N ↦ c`, or restricted to an availability corner. Then
   `B⁺_(T')`, a `B⁺_T`-module through `σ`, is flat.

## Proofs
**Part 1.** Let `I = (f_1..f_r)`.
- **Choosing a cut.** Choose `M` such that `f_i(n) = r_i(n)` with `r_i ∈ T` for all
  `n >= M`. If every `r_i = 0`, then `I ⊆ Q^M` is a finite product of ideals of `Q`,
  hence projective.
- **The tail.** Otherwise let `d = gcd(r_i)` in `T`, with `d = Σ a_i r_i` and
  `r_i = b_i d`. Pick `M' >= M` beyond all poles of `a_i, b_i, d` and all zeros of `d`,
  and let `e = 1_([0,M'))`.
- **Splitting.** Then `I = eI ⊕ (1−e)I`. The first summand is an ideal of `Q^(M')`, hence
  projective. The second is `d·(1−e)B⁺_T`: it contains `(1−e)d = Σ(1−e)a_i f_i`, and each
  `(1−e)f_i = (1−e)b_i d`. Multiplication by `d` is injective on `(1−e)B⁺_T`, since `d`
  has no zeros there, so the second summand is free of rank `1`.

So `I` is projective. Semihereditary rings are coherent of weak dimension `<= 1`. ∎

**Part 2.** Let `A = B⁺_T` and `g_1..g_s ∈ A[x]`, with `x = (x_1..x_p)`. We show that the
syzygy module `Syz_A(g) ⊆ A[x]^s` is finitely generated.
- **The generic syzygies.** Let `g_i^∞ ∈ T[x]` be the tails. Let `h'` be the product of
  the denominators of their coefficients, `D = Q[t]_(h') ⊆ T` and `R = D[x]`. `R` is
  Noetherian, so `S = Syz_R(g^∞)` is generated by some `w_1..w_q ∈ R^s`. Since `T` and `K`
  are localizations of `D`, the `w_l` also generate `Syz_(T[x])(g^∞) = S ⊗_D T`.
- **Generic freeness.** This is the result for a Noetherian domain and a finitely
  generated algebra (e.g. Eisenbud, *Commutative Algebra*, Thm 14.4). Applied to the
  finitely generated `R`-modules `R/I` and `I`, where `I = (g^∞)`, it gives `a ∈ D \ 0`
  with `(R/I)_a` and `I_a` free over `D_a`.
- **Specializing.** For all `n` beyond the roots of `h'a` and beyond the places where
  `g_i(n) = g_i^∞(n)`, tensor `0 -> S_a -> R_a^s -> I_a -> 0` and `0 -> I_a -> R_a` with
  `D_a/(t−n) = Q`. Both stay exact, because `I_a` and `(R/I)_a` are flat over `D_a`. So
  `Syz_(Q[x])(g(n))` is generated by the `w_l(n)`. Fix `M` beyond all these finitely many
  exceptions.
- **Generators.** Put `W_l ∈ A[x]^s` with `W_l(n) = w_l(n)` for `n >= M` and `0` below.
  For each `n < M`, choose generators `v_(n,k)` of the Noetherian module
  `Syz_(Q[x])(g(n))`, and put `V_(n,k) = δ_n v_(n,k)`. All of these are syzygies.
- **They generate.** Let `η ∈ Syz_A(g)` have tail `η^∞ ∈ T[x]^s`. Then `η^∞` is a
  syzygy of `g^∞` over `T[x]`, so `η^∞ = Σ c_l w_l` with `c_l ∈ T[x]`. With `C_l ∈ A[x]`
  having tails `c_l` (and `0` at small `n`), the difference `η − Σ C_l W_l` vanishes at
  all large `n`. At each of the finitely many remaining `n` it is a syzygy of `g(n)`, so it
  equals `Σ δ_n d_l W_l` when `n >= M`, and `Σ δ_n e_k V_(n,k)` when `n < M`. ∎

**Part 3.** For an `A[x]`-module `N`, the exact sequence
`0 -> A[x] ⊗_A N -> A[x] ⊗_A N -> N -> 0` gives `fd_(A[x]) N <= fd_A N + 1`, so
`fd <= 1 + p` over `A[x_1..x_p]` by Part 1. Over a coherent ring, a finitely presented
module of flat dimension `m` has a resolution by finitely generated free modules whose
`m`-th syzygy is finitely presented and flat, hence projective. So `pd <= p + 1`. ∎

**Part 4.** Flatness is local, so check at every prime `𝔭` of the source `B⁺_T`.
- **Point primes.** `𝔭_n = {f(n) = 0}`: `B⁺_T` localized at `𝔭_n` is `Q`, since `δ_n` is
  inverted, so every module is flat there.
- **Tail primes.** `𝔭 ⊇ J`: every `1 − 1_([0,m))` is inverted, and the localization is
  `T_𝔮`, a DVR or `Q(t)`.
  - For `N ↦ N + a` or `N ↦ pN + r`, `σ` carries `1 − 1_([0,m))` to an eventual indicator.
    So the localized module is the tail ring `T'` with `T_𝔮` acting through the injective
    substitution `r ↦ r(t + a)` or `r ↦ r(pt + r')`. It is torsion-free, since `T'` is a
    domain, and torsion-free modules over a DVR are flat.
  - For a reset `N ↦ c`, `σ(1 − 1_([0,m))) = 0` for `m > c`, so the localized module is
    `0`.
- **Corners.** Availability corners are direct summands, and direct summands of flat
  modules are flat. ∎

Artifact Sections 2 and 3.

1. **Reduction to the host.** In each configuration `E`, `F` and `FE ∪ {1}` lie in the host subgroup `H`:
   - `(Z/2)^2` or `Z/7`, which are finite;
   - `D_inf`, the group generated by `r0` and `r1`.

   Every translation `t` with `S` and `tS` nonempty subsets of the window is `t = p q^-1` for window sites `p`, `q`, so it lies in `H`. So (P), (I), (D) and (T) are the same in any `G ⊇ H` as in `H`. The group classes are:
   - `Z2k(2)`, coordinatewise addition mod 2;
   - `Dinf`, pairs `(s, u)` meaning `x -> s x + u`, with composition `(s1 s2, s1 u2 + u1)`;
   - `Cyc(7)`.

   All three are in `experiments/promislow-shannon-windows-2026-09-17/torsion2_scan.py` and `experiments/shannon-window-certificates-2026-09-17/random_scan.py`.
2. **The fakes.** `verify_generic.py` works in five steps:
   1. Take a dual-simplex vertex of the LP.
   2. Rationalise it.
   3. Rebuild `h` on all `2^n` subsets of the ground set, without variable merging.
   4. Check in exact `Fraction` arithmetic:
      - `h(empty) = 0`, the `n` top monotonicity inequalities and every elemental submodular inequality;
      - `h(x_g) = 1` and `h(x_X) = |X|`;
      - `h(y_g x_(gE)) = h(x_(gE))`;
      - `h(S) = h(tS)` for every `t = p q^-1` and every subset `S` with `tS` in the ground set.
   5. Print `Phi`.

   Logged output (`verify_log.txt`):
   - `(Z/2)^2`: 679 elemental and 316 translation checks, `Phi = 7/9`; for the second configuration, `Phi = 11/12`.
   - `D_inf`: 67596 elemental and 6242 translation checks, `Phi = 7/8`.
   - `Z/7`: 28171 elemental and 5113 translation checks, `Phi = 5/6`; a second configuration gives `1264/1469`.

   Every line says `ALL EXACT`.
3. **LP duality.** Elemental inequalities generate all Shannon inequalities. Any Shannon-type derivation of `Phi >= 1` from the premises is a nonnegative combination of premise inequalities and equalities, and evaluating it at `h` would give `Phi(h) >= 1`, a contradiction.
4. **Corollary.** The claim node gives the dihedral case analysis. It uses only that two involutions `s != s'` generate a dihedral group of order `2 · ord(ss')`, and that for even `n >= 4` this group contains the central involution `(ss')^(n/2)`, which commutes with `s` and differs from it.

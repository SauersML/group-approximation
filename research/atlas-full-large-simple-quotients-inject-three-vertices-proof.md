Let `phi` map the universal group onto a nonabelian simple group.

First, `L=A5` is simple, so `phi|_L` is injective or trivial.  If it is
trivial, then `r,u,t,s`, and hence `b=st`, vanish.  The whole image is then
generated by `z,c` with

```text
z^3=c^2=(cz)^2=1,
```

so it is a quotient of `S3`, impossible for a nonabelian simple image.  Thus
`L` injects.

Write `F'=S3(r,u) x S3(z,c)`.  Its first factor already lies in the injected
`L`.  If a kernel element had a nontrivial first coordinate, commuting it with
the first factor would produce a nontrivial element of the kernel inside that
factor; equivalently the first coordinate would have to be central in `S3`.
Thus the kernel lies in the second factor.  A nontrivial kernel there contains
its normal `A3`, hence
kills `z`; the only possibilities are kernel `A3` or all of that `S3`.  But
the forward-fan relation then gives

```text
1=(z b)^3=b^3=b,
```

contradicting injection of `L`, where `b` is a nontrivial involution.  Hence
`F'` injects.

Finally consider `J=S4`.  Its proper nontrivial normal subgroups are `V4` and
`A4`.  The marked collision involution `c` is a double transposition in `V4`,
so a kernel containing `V4` contradicts injection of `F'`.  A kernel containing
`A4` meets the marked `K=S3(t,s)<L` in its order-three subgroup, contradicting
injection of `L`.  Thus `J` injects as well.

It follows that the simple target order is divisible by

```text
lcm(60,36,24)=360.
```

The same argument does not automatically inject `C144`: its normal binary
translation module has proper invariant submodules that can avoid the marked
involution `b`.  That remaining kernel classification must be handled
separately.

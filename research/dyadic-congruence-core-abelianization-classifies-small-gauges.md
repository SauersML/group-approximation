Put

```text
N=4^K-1,       K>=2,       G_N=PSL_2(Z/N),
u(z)=[[1,z],[0,1]],         h(a)=diag(a,a^(-1)),
Bbar_N=<u(1),h(2)><G_N.                                  (DCG1)
```

Then

```text
Bbar_N ~= C_N semidirect C_(2K),                         (DCG2)
```

where the second factor acts on `C_N` by multiplication by `4`, and

```text
Bbar_N^ab ~= C_3 x C_(2K).                              (DCG3)
```

In particular every scalar character is determined by

```text
theta(u(1)) in mu_3,       theta(h(2)) in mu_(2K).       (DCG4)
```

For a sequence `K->infinity`, a sequence of characters converges pointwise
to the trivial character only if its `C_3` coordinate is eventually trivial.
All asymptotically small nontrivial character gauges therefore lie in the
single cyclic `h(2)` direction used by
`cyclic-core-character-forces-linear-rms-section-area`.

## Proof

The upper unipotents form a cyclic group of order `N`, generated by `u(1)`.
Conjugation gives

```text
h(2)u(z)h(2)^(-1)=u(4z).                               (DCG5)
```

The order of `2` modulo `N=2^(2K)-1` is exactly `2K`: if
`0<m<2K` and `2^m=1 mod N`, then the positive integer `2^m-1` is smaller
than `N`, which is impossible.  Nor can `2^m=-1 mod N` for `0<m<2K`,
because `0<2^m+1<N` for `K>=2`.  Hence the projective order of `h(2)` is
also exactly `2K`.  A diagonal matrix cannot be a nontrivial upper
unipotent, so the two subgroups have trivial intersection.  This proves
`(DCG2)`.

In the abelianization, `(DCG5)` becomes

```text
u(1)=u(4),
```

so the unipotent coordinate is quotiented by multiplication by `3`.  Since
`3|4^K-1`, its surviving order is exactly `gcd(N,3)=3`.  There is no further
relation coupling this coordinate to the cyclic diagonal factor in the
semidirect presentation, proving `(DCG3)--(DCG4)`.

Finally `mu_3` is a fixed finite set whose two nontrivial points stay a
fixed distance from `1`.  Thus pointwise convergence to the trivial
character forces that coordinate eventually to equal `1`; only the
`C_(2K)` coordinate can carry phases tending nontrivially to `1`.

## Scope

This calculation explains the complete **scalar** gauge defect on the
congruence quotient.  The universal one-power endpoint differs from that
quotient by a fixed bounded kernel, and bounded-order scalar characters
cannot create a new nontrivial phase converging to `1`.  The calculation
does not classify matrix-valued deformations or the slow packet-commutant
modes already recorded in
`bs14-periodic-koopman-modes-refute-skeleton-regularity`; a successful
relative inequality must still minimize over the full nearby exact-core
variety, not merely over scalar twists.

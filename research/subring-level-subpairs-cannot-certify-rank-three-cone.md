**ESTABLISHED (proposed; unreviewed).**  Derivation: [[subring-level-subpairs-cannot-certify-rank-three-cone-proof]].
It is a class-killing obstruction for the nonsofic side of [[rank-three-finite-twisted-kazhdan-cone-is-sofic]].

## Setting

`R_+ = F_q[x_1..x_d]`, `R = F_q[x_1^(±1)..x_d^(±1)]`, `d ≥ 2`, `Gamma = SL_3(R_+) = EL_3(R_+)` (Suslin),
`G = EL_3(R) x| SL_d(Z)`, `psi = ev_0 : Gamma -> F = PSL_3(F_q)`.  `U_k = < e_ij(x^m) : i ≠ j, m ∈ N^d, |m| ≥ k >`
for `k ≥ 1`.  For `B ≤ G` write

```text
C = B ∩ Gamma,   E_B = B ∩ EL_3(R),   H_B = image of B in SL_d(Z),   P_C = { t ∈ B : t C t^-1 ≤ C } .
```

So `B / E_B ≅ H_B`.  `H_B` is the **projection**, not `B ∩ SL_d(Z)`: an element of `B` over `σ ∈ H_B` has the
form `u σ` with `u ∈ EL_3(R)`, and `u` need not be `1`.  A Kun-Thom certificate for `T_3` is a `B` with
`C_F(psi(C)) ≠ 1`, `B` and `C` Kazhdan, and `C` infranormal (`P_C` generates `B`) and not normal in `B`, as in
[[monomial-origin-level-subpairs-cannot-certify-rank-three-cone]].

## Theorem

Let `B ≤ G` contain `U_k` for some `k ≥ 1`.

**(X1) Compressors are nonnegative, for every such `B`.**  If `u σ ∈ P_C` with `u ∈ EL_3(R)`, then
`σ ∈ M_d(N)`.  Hence, if `C` is infranormal in `B`, the nonnegative elements of `H_B` generate `H_B`.  No
salience, monomial or basis hypothesis is needed.  This is (N1) of
[[galois-psd-monomial-subpair-has-no-infranormal-trace]] for all `B ⊇ U_k`.

**(X2) A finite projection makes an infranormal trace normal.**  If `H_B` is finite and `C` is infranormal,
then every compressor normalises `Gamma`, and `C` is normal in `B`.  This is (M4) for all `B ⊇ U_k`.

**(X3) The subring class.**  Suppose `E_B = EL_3(A) = < e_ij(a) : i ≠ j, a ∈ A >` for some `F_q`-subalgebra
`A ⊆ R`, unital or not.  If `cone(H_B · R_+^d)` contains a line, then `1 ∈ A`, `EL_3(F_q) ≤ C` and
`psi(C) = F`.

**(X4) Consequence.**  No `B` as in (X3) is a Kun-Thom certificate for `T_3`.

- If `cone(H_B · R_+^d)` contains a line, the centraliser condition fails, by (X3).
- Otherwise, let `C` be infranormal and `B` be Kazhdan.  Then `H_B` is Kazhdan and, by (X1), generated by
  nonnegative matrices.  Its cone is salient, so `H_B` is finite by (W2) of
  [[nonneg-generated-kazhdan-groups-have-nonsalient-cones]], and `C` is normal by (X2).

The class contains every monomial subpair `B_(H,k)` (there `A = F_q[P]`, by (M0)), every `B` with
`E_B = EL_3(F_q[P])` for a monomial subring, and every `B` with `E_B = EL_3(A)` for an arbitrary subring
`A ⊇ 𝔪^k` (the ideal of `R_+` spanned by monomials of degree `≥ k`), with `B` allowed to contain elements `u σ`
with `u ∉ E_B`.

## Mechanism

1. *(X1).*  For `t = u σ` and `m ∈ N^d` with `|m| ≥ k`,
   `t e_ij(x^m) t^-1 = 1 + x^(σm) · u E_ij u^-1`.  If `t` compresses `C`, this lies in `Gamma` for every such
   `m`.  Fix one monomial `x^s` of one nonzero entry of `u E_ij u^-1`.  Then `σ(n e_l) + s ∈ N^d` for all
   `n ≥ k`, which forces the column `σ e_l` into `N^d`.  The leading-monomial bookkeeping of (N1) is not needed:
   the degree `n` of the level element does the work.
2. *(X2).*  A finite `H_B` generated by nonnegative matrices consists of permutation matrices.  For a
   permutation `σ` and each coordinate `c` there is an `l` with `(σ e_l)_c = 0`, and `m = k e_l` then shows that
   every entry of `u E_ij u^-1` is a polynomial.  So `Ad(u)` maps `M_3(R_+)` into itself, and it preserves the
   trace form, whose discriminant is a unit.  So `Ad(u)` maps `M_3(R_+)` onto itself, and `t Gamma t^-1 = Gamma`.
3. *(X3).*  The `F_q`-span `Λ` of `{ g - 1 : g ∈ E_B }` is an algebra, and it is preserved by `Ad(t)` for
   `t ∈ B`.  Its scalars `Z = { f : f · 1 ∈ Λ }` form a subalgebra of `A`.  `Ad(u σ)` fixes a scalar `f`
   up to `σ`, since `u` commutes with scalars, so `Z` is `H_B`-invariant.  `Z` contains every monomial of degree
   `≥ 2k`, as `x^m E_12 · x^(m') E_21 = x^(m+m') E_11`.  A line in `cone(H_B · R_+^d)` is a positive integer
   relation `Σ n_s σ_s e_(i_s) = 0`, so `1 = Π σ_s(x^(2k e_(i_s)))^(n_s) ∈ Z ⊆ A`.

## Calibration

- `B = G`: `E_B = EL_3(R)`, `H_B = SL_d(Z)`, and `psi(C) = F`, as the target records.
- `B = Gamma x| S_d` (coordinate permutations): `H_B` finite, `C = Gamma` normal, as (X2) says.
- `B = EL_3(R)` alone: `P_C` is the normaliser of `Gamma`, by step 2 with `σ = 1`; so `Gamma` is not
  infranormal in `EL_3(R)`.  Compression really does need the monomial automorphisms.
- `B_(H,k)`: (X1) with `u ∈ Ũ` recovers (N1), and (X4) recovers (W3) of the salience node.

## What is left

The nonsofic side now needs a `B` outside the class, of one of two kinds.

- `B ⊇ U_k` with `H_B` infinite and `E_B` **not** generated by elementary matrices over a subring.  By (X1),
  (X2) and (W2), a certificate of this kind has an infinite, nonnegatively generated Kazhdan `H_B` preserving a
  coordinate subspace `R^M ⊆ cone(H_B · R_+^d)`.  The proof of (X3) still gives `1 ∈ Z` and `E_ij ∈ Λ` there,
  so the span of `E_B - 1` contains `M_3(F_q)`.  A certificate needs `E_B` to have that span while
  `psi(E_B ∩ Gamma)` still has a nontrivial centraliser.  The obstacle is that (X3) passes from the linear span
  back to group elements only for elementary-generated `E_B`.
- `B` containing no level `U_k` at all.  Then (X1) is unavailable, and so is the salience argument.

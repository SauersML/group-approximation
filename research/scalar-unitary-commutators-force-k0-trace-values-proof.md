For a piecewise `C^1` path `ξ : [0,1] → GL_m(A)` put
`Δ(ξ) = (1/2πi) ∫_0^1 τ_*( ξ'(s) ξ(s)^(-1) ) ds`.

**(a) Products.** `(ξη)'(ξη)^(-1) = ξ'ξ^(-1) + ξ(η'η^(-1))ξ^(-1)`, and `τ_*` is tracial, so
`Δ(ξη) = Δ(ξ) + Δ(η)` for pointwise products.

**(b) Constant conjugation.** `Δ(w ξ w^(-1)) = Δ(ξ)` for a constant `w ∈ GL_m(A)`.

**(c) Inverses.** `(ξ^(-1))' = -ξ^(-1) ξ' ξ^(-1)`, so `Δ(ξ^(-1)) = -Δ(ξ)`.

**(d) Homotopy invariance.** Let `H(s,t)` be a `C^2` homotopy of paths that keeps the endpoints
fixed, or keeps every `H(·,t)` a loop. Differentiating under the integral and using the trace
property,

```text
∂_t τ_*(∂_s H H^(-1)) - ∂_s τ_*(∂_t H H^(-1))
    = τ_*( ∂_t H H^(-1) ∂_s H H^(-1) - ∂_s H H^(-1) ∂_t H H^(-1) )  =  0,
```

so `d/dt Δ(H(·,t)) = (1/2πi) [τ_*(∂_t H H^(-1))]_(s=0)^(s=1) = 0`. Continuous paths and homotopies
in the open set `GL_m(A)` are approximated by smooth ones. So `Δ` depends only on the homotopy
class. It is also unchanged under `ξ ↦ ξ ⊕ 1`.

**(e) Loops.** For a loop `ξ` at `1`, `Δ(ξ) ∈ τ_*(K_0(A))`.
- *Bott periodicity.* For unital `A`, the map `K_0(A) → π_1(GL_∞(A))` sending `[p]` to the loop
  `f_p(s) = exp(2πis) p + (1 - p)` is an isomorphism (standard; source not re-read).
- *Values on generators.* `f_p' f_p^(-1) = 2πi p`, so `Δ(f_p) = τ_*(p)`.
- *Homomorphism.* In a topological group, pointwise product of loops represents the product in
  `π_1`. So by (a) and (d), `Δ` is a homomorphism `π_1(GL_∞(A)) → R`.
- *Conclusion.* Its image is generated by the values `τ_*(p)`, so it equals `τ_*(K_0(A))`.

**(f) The rotation path.** Let `R_s = [[cos s, -sin s], [sin s, cos s]] ⊗ 1_n` for
`s ∈ [0, π/2]`. Conjugation by `R_(π/2)` swaps the diagonal blocks, so

```text
ξ(s) = (V ⊕ 1) R_s (V^(-1) ⊕ 1) R_s^(-1)
```

runs from `1` to `V ⊕ V^(-1)`. With `w = U ⊕ 1`, the path `η = ξ · (w ξ^(-1) w^(-1))` runs from `1` to

```text
(V ⊕ V^(-1)) (U ⊕ 1) (V^(-1) ⊕ V) (U^(-1) ⊕ 1)  =  (V U V^(-1) U^(-1)) ⊕ 1  =  exp(2πiθ) 1_n ⊕ 1_n .
```

By (a), (b) and (c), `Δ(η) = Δ(ξ) - Δ(ξ) = 0`.

**(g) The scalar path.** `σ(s) = exp(2πiθs) 1_n ⊕ 1_n` has `σ'σ^(-1) = 2πiθ (1_n ⊕ 0)`, so
`Δ(σ) = nθ`.

**(h) Conclusion.** After reparametrizing `η` over `[0,1]`, the pointwise product `η σ^(-1)` is a loop
at `1`. By (a), (c) and (e), `Δ(η) - Δ(σ) = -nθ ∈ τ_*(K_0(A))`. So `nθ ∈ τ_*(K_0(A))`.

**Consequences.**
- *Kadison--Kaplansky.* For torsion-free `G` with `nθ ∉ Z`, `τ_*(K_0(C*_r G)) ⊄ Z`. Item 1 of
  `fractional-matrix-trace-gives-projection-in-g-star-z` gives a nontrivial projection over `G * Z`.
  If `C*_r(G)` is selfless, `selfless-projection-traces-equal-k0-trace-image` gives one over `G`.
- *Group elements.* `λ(h)λ(g)λ(h)^(-1)λ(g)^(-1) = λ([h,g])`. Distinct group elements are linearly
  independent in `C*_r(G)`, so this is a scalar only if `[h,g] = e`, and then `θ ∈ Z`.
- *Obstruction.* If assembly is surjective for torsion-free `G`, then `τ_*(K_0(C*_r G)) ⊆ Z` by
  `assembly-image-traces-are-integral-for-torsion-free-groups`. A unital `*`-homomorphism
  `A_θ → M_n(C*_r G)` supplies such `U, V`, so it forces `nθ ∈ Z`, and `θ` is rational.

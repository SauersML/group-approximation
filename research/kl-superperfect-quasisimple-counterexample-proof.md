The only external input is Hopf's formula `H_2(G; Z) = (R cap [F,F])/[F,R]`
for `G = F/R` with `F` free, as used in `nonsingular-schur-surjection-proof`.

**Step 0: the simple counterexample.** By
`kl-counterexample-can-be-two-generator-simple`, a failure gives a
two-generator nonabelian simple `S`, a nonsingular `w in S * <t>` of exponent
sum `m != 0`, and `1 != a in S` dying in `X = (S * <t>)/<<w>>`. The kernel of
`S -> X` is normal and nontrivial, so it is all of `S`: all of `S` dies.

Write `S = F/R` with `F` free of rank two. Put `S^ = [F,F]/[F,R]`,
`A = (R cap [F,F])/[F,R]`, and let `p : S^ -> S` be induced by `F -> S`.

**(U1) `p` is onto.** `S` is perfect, so `F = [F,F] R`, and `[F,F]` maps onto `S`.

**(U2) `ker p = A` is central.** Elements of `R` are central modulo `[F,R]`.
By Hopf, `A = H_2(S)`.

**(U3) `S^` is perfect.** Take `x, y in F`. Write `x = x'r` and `y = y's` with
`x', y' in [F,F]` and `r, s in R`. Since `r` and `s` are central modulo
`[F,R]`, `[x,y] = [x',y']` modulo `[F,R]`. The elements `[x,y]` generate
`[F,F]`, so `S^` is generated by images of elements of `[[F,F],[F,F]]`.

**(U4) Universality.** Let `1 -> B -> E -q-> S -> 1` be central. Then there is
exactly one homomorphism `phi : S^ -> E` with `q phi = p`.

* *Existence.* Lift the free generators to get `f : F -> E` over `S`. Then
  `f(R) <= B` is central, so `f([F,R]) = 1`, and `f` induces
  `F/[F,R] -> E`. Restrict it to `S^`.
* *Uniqueness.* If `phi` and `psi` both lie over `p`, put
  `c(x) = phi(x)^-1 psi(x) in B`. Because `c(x)` is central,
  `c(xy) = phi(y)^-1 c(x) psi(y) = c(x) c(y)`. So `c` is a homomorphism from
  a perfect group to an abelian group, hence trivial.

**(U5) Every central extension of `S^` splits.** Let `1 -> C -> E -pi-> S^ -> 1`
be central, and put `E_1 = [E,E]`.

* `pi(E_1) = [S^,S^] = S^` by (U3).
* Let `D = E_1 cap pi^-1(A)`. For `d in D` and `x in E`,
  `pi[x,d] = [pi x, pi d] = 1`, so `[x,d] in C`.
* Since `C` is central, `[xy,d] = [y,d][x,d]`, so `x -> [x,d]` is a
  homomorphism `E -> C`. It kills `E_1`, so `D` is central in `E_1`.
* Hence `p pi|_(E_1) : E_1 -> S` is a central extension of `S`. By (U4) there
  is `phi : S^ -> E_1` with `p pi phi = p`.
* Uniqueness in (U4), applied with `E = S^`, gives `pi phi = id`. So `phi`
  splits `pi`.

**(U6) `H_2(S^) = 0`.** Take any presentation `S^ = F_1/R_1`, and put
`M = F_1/[F_1,R_1]` and `Z_1 = R_1/[F_1,R_1]`, which is central in `M`.

* By (U5) there is a section `sigma` of `M -> S^`, and `M = sigma(S^) Z_1`.
* So `[M,M] = [sigma S^, sigma S^] = sigma(S^)`, by (U3).
* `sigma(S^)` meets `Z_1` trivially, because `M -> S^` is injective on
  `sigma(S^)` and kills `Z_1`.
* So `([F_1,F_1] cap R_1)/[F_1,R_1] = [M,M] cap Z_1 = 1`, which is `H_2(S^)`
  by Hopf.

With (U3), `S^` is superperfect.

**(U7) Quasisimple, two-generator.**

* *Center.* `Z(S^)` maps into `Z(S) = 1`, so `Z(S^) <= A`. And `A` is central,
  so `Z(S^) = A` and `S^/Z(S^) = S`.
* *Generation.* Let `g_1, g_2` be the images of the free generators in `M_0 = F/[F,R]`.
  Since `F = [F,F]R`, write `g_i = s_i c_i` with `s_i in S^` and `c_i` central.
  Then `[M_0,M_0]` is the normal closure of the `[g_i,g_j] = [s_i,s_j]` in
  `<s_1,s_2> Z(M_0)`, which lies in `<s_1,s_2>`. And `[M_0,M_0] = S^` by (U3).
  So `S^ = <s_1,s_2>`.

**(U8) Total collapse.** Lift the coefficients of `w` along `p` to get
`w^ in S^ * <t>` with exponent sum `m`, and put
`X^ = (S^ * <t>)/<<w^>>`, which maps onto `X`.

* The image `S'` of `S^` in `X^` maps to the image of `S` in `X`, which is
  trivial by Step 0. So `S'` is the image of `A`, which is abelian.
* `S'` is also perfect, as an image of `S^`. So `S' = 1`.

**(U9) Quotients.** Let `N` be normal in `S^`.

* `NA/A` is normal in the simple group `S`, so either `N <= A` or `NA = S^`.
* In the second case `S^/N` is an image of `A`, so abelian, and perfect. So
  `N = S^`.
* A nontrivial quotient `S^/N` with `N <= A` is a perfect central extension
  of `S`. Step (U8) applies verbatim, so it is a total-collapse
  counterexample.
* By `kervaire-laudenbach-holds-for-hyperlinear` and
  `kervaire-laudenbach-holds-for-mf` it is neither hyperlinear nor MF. Finite
  groups are hyperlinear.

**Schur kernel.** `K_2(S^, w^)` is a subgroup of `H_2(S^) = 0`.

**(U10) Finite presentation.** Suppose `S = <x_1, x_2 | r_1, ..., r_n>`.

* **`A` is finitely generated.** `R/[F,R]` is generated by the images of
  `r_1, ..., r_n`, since conjugates agree modulo `[F,R]`. So it is
  finitely generated abelian, and so is its subgroup `A`.
* **A finite presentation `P`.** Choose lifts `s^_1, s^_2` of the `x_i` in
  `S^`, and finitely many generators `a_1, ..., a_k` of `A` together with a
  finite presentation of `A` on them. Write `r_j(s^) = c_j` with `c_j` a word
  in the `a_i`. Let `P` have generators `s^_i, a_i` and relators: the
  relators of `A`, all `[a_i, s^_l]`, and all `r_j(s^) c_j^-1`.
* **`P` is an extension.** `P` maps onto `S^`. The normal closure `A_P` of
  the `a_i` in `P` is central and is a quotient of `A`, and `P/A_P = S`.
* **`P = S^`.** `A_P -> A` is onto and restricts to a quotient map
  `A -> A_P -> A` that is the identity on generators, so it is an
  isomorphism. By the five lemma for `1 -> A_P -> P -> S -> 1` against
  `1 -> A -> S^ -> S -> 1`, the map `P -> S^` is an isomorphism.

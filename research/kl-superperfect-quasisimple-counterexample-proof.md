The only external input is Hopf's formula `H_2(G; Z) = (R cap [F,F])/[F,R]`
for `G = F/R` with `F` free, as used in `nonsingular-schur-surjection-proof`.
Commutators are `[x,y] = x y x^-1 y^-1`.

**Step 0.** The kernel of `S -> X = (S * <t>)/<<w>>` is normal and nontrivial.
`S` is simple, so all of `S` dies in `X`.

Let `p : S^ -> S` be induced by `F -> S`.

**(U1) `p` is onto.** `S` is perfect, so `F = [F,F] R`, and `[F,F]` maps onto
`S`.

**(U2) `ker p = A` is central.** Elements of `R` are central modulo `[F,R]`.
By Hopf, `A = H_2(S)`.

**(U3) `S^` is perfect.**
* Take `x, y in F` and write `x = x'r`, `y = y's` with `x', y' in [F,F]` and
  `r, s in R`.
* Since `r` and `s` are central modulo `[F,R]`, `[x,y] = [x',y']` modulo
  `[F,R]`.
* The `[x,y]` generate `[F,F]`, so `S^` is generated by commutators of its own
  elements.

**(U4) Universality.** For every central extension `1 -> B -> E -q-> S -> 1`
there is exactly one `phi : S^ -> E` with `q phi = p`.
* **Existence.** Lift the free generators to `f : F -> E` over `S`.
  `f(R) <= B` is central, so `f([F,R]) = 1`. Restrict the induced map on
  `F/[F,R]` to `S^`.
* **Uniqueness.** If `phi` and `psi` both lie over `p`, put
  `c(x) = phi(x)^-1 psi(x) in B`. Since `c(x)` is central,
  `c(xy) = phi(y)^-1 c(x) psi(y) = c(x) c(y)`. So `c` is a homomorphism from a
  perfect group to an abelian group, hence trivial.

**(U5) Every central extension of `S^` splits.** Let `1 -> C -> E -pi-> S^ -> 1`
be central, and put `E_1 = [E,E]`, so `pi(E_1) = S^` by (U3).
* Let `D = E_1 cap pi^-1(A)`. For `d in D` and `x in E`, `pi[x,d] = 1`, so
  `[x,d] in C`.
* `[xy,d] = x[y,d]x^-1 [x,d] = [y,d][x,d]`, so `x -> [x,d]` is a homomorphism
  `E -> C`. It kills `E_1`, so `D` is central in `E_1`.
* So `p pi|_(E_1)` is a central extension of `S`, and (U4) gives
  `phi : S^ -> E_1` with `p pi phi = p`.
* Uniqueness in (U4), applied to `S^ -> S` itself, gives `pi phi = id`.

**(U6) `H_2(S^) = 0`.** Take a presentation `S^ = F_1/R_1`, and put
`M = F_1/[F_1,R_1]` and `Z_1 = R_1/[F_1,R_1]`, which is central.
* (U5) gives a section `sigma`, so `M = sigma(S^) Z_1`.
* Hence `[M,M] = sigma([S^,S^]) = sigma(S^)`, which meets `Z_1` trivially.
* By Hopf, `H_2(S^) = [M,M] cap Z_1 = 1`.

**(U7) Quasisimple and two-generated.**
* **Center.** `Z(S^)` maps into `Z(S) = 1`, so `Z(S^) <= A`, and `A` is
  central. So `Z(S^) = A` and `S^/Z(S^) = S`.
* **Proper normal subgroups.** For `N` normal in `S^`, `NA/A` is normal in
  `S`. If `NA = S^`, then `S^/N` is an image of `A`: abelian and perfect, so
  `N = S^`. Otherwise `N <= A`.
* **Generation.** Let `g_1, g_2` be the images of the free generators in
  `M_0 = F/[F,R]`, and write `g_i = s_i c_i` with `s_i in S^` and `c_i` central.
  Then `[M_0,M_0]` is the normal closure of `[g_1,g_2] = [s_1,s_2]`, and
  conjugation by `g_i` equals conjugation by `s_i`. So
  `S^ = [M_0,M_0] <= <s_1, s_2>`.

**(U8) Centralized collapse.** Let `w^` lift `w`, put
`X_c = (S^ * <t>)/<<w^, [A, t]>>`, and let `A_c` be the image of `A`.
* `A_c` commutes with `S^` and with `t`, so it is central in `X_c`.
* Killing `A` in `S^ * <t>` gives `S * <t>`, so `X_c/A_c = X`.
* The image of `S^` in `X_c` maps to the image of `S` in `X`, which is trivial
  by Step 0. So it lies in `A_c`: it is abelian, and perfect as an image of
  `S^`. Hence it is trivial.

**(U9) Plain adjunction.** The kernel of `S^ -> (S^ * <t>)/<<w^>>` is normal in
`S^`, so by (U7) it lies in `A` or is all of `S^`. Only the centralized
argument of (U8) forces collapse: without `[A,t]`, the image of `A` need not
be central, and the image of `S^` is only known to lie in its normal closure.
`K_2(S^, w^) <= H_2(S^) = 0` by (U6).

**(U10) Finite presentation.** Suppose `S = <x_1, x_2 | r_1, ..., r_n>`.
* **`A` is finitely generated.** `R/[F,R]` is generated by the images of the
  `r_j`, since conjugates agree modulo `[F,R]`. So `A` is a subgroup of a
  finitely generated abelian group, hence finitely generated and finitely
  presented.
* **The presentation `P`.** Choose lifts `s^_i` of `x_i`, generators
  `a_1, ..., a_k` of `A` with a finite presentation, and words `c_j` in the
  `a_i` with `r_j(s^) = c_j`. Let `P` have generators `s^_i, a_i` and relators:
  the relators of `A`, all `[a_i, s^_l]`, and all `r_j(s^) c_j^-1`.
* **`P -> S^` is onto** by (U7).
* **`P` is an extension of `S`.** The normal closure `A_P` of the `a_i` is
  central and generated by the `a_i`, and `P/A_P = S`.
* **`A_P = A`.** The composite `A -> A_P -> A` is the identity on generators,
  so `A_P = A`. The five lemma then gives `P = S^`.

Put `q=s_1t_1=q^2` and `z=x_13(q)` in
`St_20(L_(F_2)(1,2))`.  For `10<=k<=18`, define

```text
C_k=x_(1,k)(q),                 D_k=x_(k,3)(q).        (NHR1)
```

These eighteen involutions and `z` generate the nine-pair extraspecial
packet

```text
[C_k,D_l]=z^(delta_(k,l)),
[C_k,C_l]=[D_k,D_l]=[z,C_k]=[z,D_k]=1.                (NHR2)
```

Let `P=(1-rho(z))/2` in an arbitrary finite-dimensional unitary
representation.  On `PH`, put

```text
e_epsilon=P product_(k=10)^18 (1+epsilon_k rho(C_k))/2,
epsilon in {+1,-1}^9.                                 (NHR3)
```

Then the `e_epsilon` are orthogonal, sum to `P`, and

```text
tau(e_epsilon)=2^(-9)tau(P)                           (NHR4)
```

for **every** normalized trace profile.  More strongly, the algebra
generated by the restrictions of the `C_k,D_k` to `PH` is

```text
M_(2^9)(C) tensor 1_M.                                (NHR5)
```

Thus the ten-bit abelian packet
`<z,C_10,...,C_18>~=(C_2)^10` really does have canonical marked
multiplicities on every surviving norm-corona active core.  No regular
trace hypothesis is needed.

This does **not** close the arbitrary-profile native cross-Gram claim.  All
root words in the current center-chain and adjacent-prefix-Whitehead
packets use only the indices

```text
{2,4,5,6,7,8,9}.                                      (NHR6)
```

They commute pointwise with every generator in `(NHR1)`.  Consequently, on
the active core decomposition in `(NHR5)`, every current center-chain Hecke
operator, literal native Whitehead, and polar support has the form

```text
1_(2^9) tensor T.                                     (NHR7)
```

The equal atom multiplicities therefore only tensor-amplify the old
selector reservoir.  Every relative selector cross-Gram and every mixed
Pauli commutator has exactly the same normalized value as its reservoir
counterpart.  In particular, a zero-overlap or incorrectly typed reservoir
model remains zero-overlap or incorrectly typed after adjoining all nine
pairs.  Stone--von Neumann uniqueness removes multiplicity variation for
the auxiliary packet, but it does not remove the arbitrary multiplicity
representation on its commutant.

There is a coefficient-packed version using no spare root indices.  Choose
nine distinct binary words `alpha` of one common length and put

```text
X_alpha=x_12(s_1t_alpha),
Y_beta =x_23(s_beta t_1).                              (NHR8)
```

Prefix cancellation gives

```text
[X_alpha,Y_beta]=z^(delta_(alpha,beta)),               (NHR9)
```

so the same direct flip argument proves uniformity for
`<z,X_alpha>`.  The literal adjacent Whiteheads on the indices `7,8,9`
centralize this whole packet, again making it a spectator.  A chained
terminal return arm has the exact incidence

```text
[x_(k,2)(b),Y_beta]=x_(k,3)(b s_beta t_1),             (NHR10)
```

If the displayed coefficient is nonzero, the new root is outside the
extraspecial packet, so the arm does not normalize it.  If all nine prefixes
are chosen so that every displayed coefficient vanishes (for example, take
them long enough and all beginning in `0`), then the arms centralize the
whole packet and it is once again the tensor spectator of `(NHR7)`.  Thus
this placement has an exact dichotomy: it either loses the dual flips on the
Hecke carrier or decouples from that carrier completely.  In the first case
global uniformity cannot be promoted to conditional uniformity; in the
second it cannot constrain the selector reservoir.

Accordingly the proposed many-pair regularization is a rigorous positive
finite-packet fact and a rigorous placement fence.  It can be useful only
after a new occurrence word couples the unequal native selector row to the
packet.  The existing words either commute with the whole packet, leaving
the selector reservoir arbitrary, or move the dual half outside the packet
and lose the conditional character balance.  No Property `(T)`, Kazhdan input,
canonical trace, stability theorem, or literature result is used.

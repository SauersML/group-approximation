**Inputs** (read at source by gq-infinite-primes; see the artifact).
- BCMNO: `Out(G_(n,r)) ≅ O_(n,r)`, `O_(2,1) = O_2`. The map `N(V) → O_2` sends `t` to the
  core of its minimal transducer, which has no states of incomplete response. The product
  in `O_2` is the core of the minimized product. The kernel is `V`.
- Olukoya, arXiv:2004.00516: an element of infinite order in `O_n` has logarithmic,
  polynomial or exponential core growth (growth of `|core(A^m)|` in `m`), and exponential
  examples exist for every `n ≥ 2`. All three classes are unbounded.
- Rubin's theorem `Aut(V) ≅ N(V)` is standard and is used only to identify `Out(V)` with `N(V)/V`.

**Item 1.** `tVt^{-1} = V`, so `⟨V,t⟩ = V⟨t⟩` with `V` normal, and `Γ_t/V ≅ ⟨t⟩V/V`, which
is the cyclic subgroup of `N(V)/V = Out(V)` generated by `t`. If it is infinite then
`⟨t⟩ ∩ V = 1` and `Γ_t = V ⋊ ⟨t⟩`. An extension of a finitely presented group (`V`) by a
finitely presented group (cyclic) is finitely presented.

**Item 2.** `t` is rational and `V ≤ R_{Γ,C}`, so `Γ_t ≤ R_{Γ,C}`. For nonempty `α, β`
the complements of `C_α` and `C_β` are nonempty clopens, so `V` contains an element that is
the canonical similarity `αω ↦ βω` on `C_α`. BBMZ Proposition `RSGsAndV` (item 1 of
`contracting-rsgs-embed-in-fp-simple-groups`) says any subgroup of `R` containing `V` is an RSG.

**Nuclei of elements of `Γ_t`.** Every element is `v t^m` with `v ∈ V`. For `α` longer than
the prefixes of a cone decomposition of `v`, the local action of `v` at the relevant image
path is the identity, so `(v t^m)|_α = t^m|_α`. Hence `N_{v t^m} = N_{t^m}`, and
`N_{Γ_t} = ∪_m N_{t^m}` over the `m` that occur.

*Identification* `N_{t^m} = core(t^m)` (hand check of the two normalizations, not compared
line by line). The local actions of `t^m` at long paths are the maps induced by the states
reached after synchronization, which are exactly the core states. A core state has no
incomplete response, so its image lies in no proper cone and its induced map is the local
action with trivial image prefix. Distinct states of a minimal transducer induce distinct
maps. Every core state is reached at infinitely many paths.

**Item 3.** If `t` has order `m < ∞` in `Out(V)`, then `t^m ∈ V`, the elements of `Γ_t` are
`v t^i` with `0 ≤ i < m`, and `N_{Γ_t} = ∪_{i<m} N_{t^i}` is finite. The full shift has an
irreducible core, so `Γ_t` is contracting. If `t` has infinite order, `|N_{t^m}| = |core(t^m)|`
is unbounded in `m` by Olukoya, so `N_{Γ_t}` is infinite and `Γ_t` is not contracting.

**Lemma.** If `t^n` agrees with an element of `V` on some cone `C_β`, then `n = 0`. Proof:
at every path extending `β` far enough, the local action of `t^n` is the identity, so the
identity is a core state of `t^n`. The core is strongly connected, and the identity state
only reaches itself, so the core is the one-state identity. Hence `t^n` is trivial in `O_2`,
`t^n ∈ V`, and `n = 0` since `t` has infinite order. ∎

**Item 4.** `t(C_0)` is a proper nonempty clopen, so is its complement, and `V` is transitive
on proper nonempty clopens. Choose `v ∈ V` with `v(C_1) = C − t(C_0)`, and let `h` be `t` on
`C_0` and `v` on `C_1`. It is a homeomorphism that locally agrees with `Γ_t`, so
`h ∈ [[Γ_t]]`. Suppose `h = w t^n` with `w ∈ V`. On `C_1`, `t^n = w^{-1} v`, so `n = 0` by the
lemma. Then `h = w ∈ V`, and `t = w` on `C_0`, so the lemma (with exponent 1) gives `1 = 0`.
So `h ∉ Γ_t`.

**Item 5.** `Γ_t` is finitely presented and contains `V`, so by
`fp-cantor-groups-containing-v-type-a-iff-clopen-stabilizer-fg` it suffices that one clopen
stabilizer is finitely generated. Let `U` be a proper nonempty clopen. Then
`Stab_V(U) ≅ V_U × V_{C−U} ≅ V × V`. Its image in `Γ_t/V` is all of it: for each `n` there is
`v ∈ V` with `v t^n(U) = U`, because `t^n(U)` and `U` are both proper nonempty clopens. So
`Stab_{Γ_t}(U)` is an extension of `V × V` by a cyclic group, hence finitely generated.

**Item 6.** Olukoya's exponential examples have infinite order in `O_2 ≅ Out(V)`; lift one to `N(V)`.

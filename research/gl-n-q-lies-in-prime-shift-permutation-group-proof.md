Notation as in the target. For `y in Q` and `u in Q^x`, multiplicativity gives
`σ(u y) = σ(u) σ(y)`: for `y != 0` this is the homomorphism property, and for
`y = 0` both sides are `0`. Also `σ(-y) = σ(-1) σ(y) = -σ(y)`.

**Item 2.** Let `t = diag(t_1,...,t_n)` with `t_i in Q^x`. For `x in Q^n`, the
`i`-th coordinate of `σ_n t σ_n^-1 (x)` is `σ(t_i σ^-1(x_i)) = σ(t_i) x_i`. So
`σ_n t σ_n^-1 = diag(σ(t_1),...,σ(t_n))`. With `t = e` this is
`diag(p_1,1,...,1)`, and induction in both directions gives
`σ_n^k e σ_n^-k = diag(p_k,1,...,1)` for all `k in Z`. A signed permutation
matrix permutes coordinates and changes signs, and `σ` commutes with `y -> -y`,
so it commutes with `σ_n`.

For `<e, σ_n> ≅ Z ≀ Z`:
- The conjugates `diag(p_k,1,...,1)`, `k in Z`, commute. They are independent,
  since the `p_k` are distinct primes, so they span `D = ⊕_k Z`, and `σ_n` acts
  on `D` by the shift.
- For `m != 0`, `σ_n^m` fixes the vector `(1,...,1)`, since `σ(1) = 1`. It is not
  the identity, since it sends `2 e_1` to `p_m e_1`. The only element of `D`
  fixing `(1,...,1)` is the identity, so `σ_n^m` is not in `D`.
- Hence `<e, σ_n> = D ⋊ <σ_n>` with the shift action, which is `Z ≀ Z`.

**Item 1.** By item 2, `K_n` contains `GL_n(Z)` and `diag(p,1,...,1)` for every
prime `p`. By item 1 of `gl-n-q-generated-by-gl-n-z-and-prime-dilations` these
generate `GL_n(Q)`, so `GL_n(Q) <= K_n`. For `n = 1`, `GL_1(Z) = {±1}` together
with the prime dilations generates `Q^x` by unique factorization. Then
`K_n = <GL_n(Q), σ_n>`, since `GL_n(Z)`, `e`, `σ_n` all lie in the right-hand
side and it lies in `K_n`.

**Item 3.** For `λ in Q` and `v in Q^n`, `σ_n(λ v) = σ(λ) σ_n(v)`, coordinate by
coordinate. Since `σ` is a bijection of `Q`, `σ_n` maps the line `Q v` onto the
line `Q σ_n(v)`, and `σ_n^-1` maps lines to lines in the same way. Linear maps
permute lines, so `K_n` acts on `P^(n-1)(Q)`. The kernel of
`GL_n(Q) -> Sym(P^(n-1)(Q))` is the scalars, so `PGL_n(Q) <= PK_n`. For `n >= 2`,
`PGL_n(Q)` is 2-transitive on `P^(n-1)(Q)`: two distinct lines `Q u`, `Q v`
span a plane, and any basis extending `(u, v)` can be moved to any other by
`GL_n(Q)`.

**Item 4.** `σ ∘ (x -> 2x) ∘ σ^-1` is `x -> σ(2 σ^-1(x)) = p_1 x`, and in the
same way `σ^k (x -> 2x) σ^-k` is `x -> p_k x`. Together with `x -> -x` these
generate the dilations by `Q^x`. Conjugating `x -> x+1` by the dilation
`x -> m x` gives `x -> x + 1/m`, so all rational translations lie in `A_1`, and
`Aff(Q) = Q ⋊ Q^x <= A_1`. `Aff(Q)` is sharply 2-transitive on `Q`, so `A_1`
is 2-transitive.

**Item 5.** Both actions are faithful by construction, since `PK_n` and `A_1`
are subgroups of symmetric groups. Being 2-transitive, each has exactly one
orbit of two-element subsets. Being transitive, all point stabilizers are
conjugate. So the conditions of type (A) not yet verified are exactly finite
presentation of the group and finite generation of one point stabilizer. The
consequence for `B_A` is `type-a-action-gives-boone-higman-for-subgroups`
together with the embeddings `GL_(n-1)(Q) <= PGL_n(Q)` of
`gl-n-q-targets-are-cofinal-in-n`.

**Universal form.** `α(t w) = σ_n t σ_n^-1 w` for `t` diagonal and `w` a signed
permutation matrix defines an automorphism of `N_n(Q)`, by item 2. So the
HNN extension `Π_n` exists, and in `K_n` the relation `σ_n m σ_n^-1 = α(m)`
holds. So `GL_n(Q) -> K_n` and `s -> σ_n` define a homomorphism
`Π_n -> K_n`, which is onto by item 1. `Π_n` is generated by `GL_n(Z)`, `e` and
`s`, since `s^k e s^-k = diag(p_k,1,...,1)` holds in `Π_n`.

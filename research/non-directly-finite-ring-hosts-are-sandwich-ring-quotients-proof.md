Notation as in the claim. `E_ij` is a matrix unit and `e_ij(r) = 1 + rE_ij`.

## Step 1. The corner embedding

Let `y_i x_j = δ_ij` for `1 <= i, j <= 4`, and put `e = x_1 y_1 + ... + x_4 y_4`.

**`e` is an idempotent.** `e^2 = Σ_(i,j) x_i (y_i x_j) y_j = Σ_i x_i y_i = e`.

**The corner map.** Define `φ : M_4(R) -> eRe` by `φ(X) = Σ_(i,j) x_i X_ij y_j`.
- It is multiplicative: `φ(X)φ(Y) = Σ x_i X_ij (y_j x_k) Y_kl y_l = φ(XY)`.
- It is additive, and `φ(I_4) = e`.
- It is injective, since `y_a φ(X) x_b = X_ab`.
- It is onto `eRe`: for `s in eRe`, take `X_ab = y_a s x_b`. Then
  `φ(X) = e s e = s`.

So `φ` is a ring isomorphism `M_4(R) ≅ eRe`.

**Units.** Define `ρ(u) = φ(u) + (1 - e)` for `u in GL_4(R)`. Because
`φ(u)(1-e) = (1-e)φ(u) = 0`,

    ρ(u)ρ(v) = φ(uv) + (1-e) = ρ(uv),   ρ(1) = 1.

So `ρ : GL_4(R) -> R^x` is a group homomorphism. It is injective, since
`y_a ρ(u) x_b = u_ab`.

## Step 2. The marking and the relation

Assume `PE_4(R)` is finitely presented. By
[[projective-elementary-fp-kernel-criterion]] (1 ⇒ 2, with `R` finitely
presented and `n = 4`), `T := E_4(R)` is finitely presented.
- For distinct `i, j, k`, `[e_ij(s), e_jk(1)] = e_ik(s)`, so `T` is perfect.
- Put `H := T <= [T,T]` and `g := e_12(1) != 1`.

`U = Z[T]<p,q>/(p(1-g)q - 1)` is finitely presented. Add inverse generators and
the finitely many relators of `T` to present `Z[T]`, then two generators and one
relation.

By the universal property of the group ring, `ρ|_T` extends to a unital ring map
`Z[T] -> R`. We have `ρ(g) = e + x_1 y_2 + (1-e) = 1 + x_1 y_2`, so `1 - g`
maps to `-x_1 y_2`.

**The relation.** Send `p |-> -y_1` and `q |-> x_2`. Then

    (-y_1)(-x_1 y_2)(x_2) = (y_1 x_1)(y_2 x_2) = 1.

So this defines a unital ring map `θ : U -> R`, which is injective on `T`.

## Step 3. Surjectivity onto `R`

For `i != j` and `r in R`, the image of `θ` contains `ρ(e_ij(r)) - 1 = x_i r y_j`.
In particular it contains `x_1 r y_2`, and therefore

    θ(p) (x_1 r y_2) θ(q) = -y_1 x_1 r y_2 x_2 = -r.

So `θ(U) = R`. (In the square-module case, [[square-module-ring-hosts-are-sandwich-ring-quotients]]
maps onto `M_4(R)` instead. Here the corner makes `R` itself the quotient, so no
isomorphism `M_4(R) ≅ R` is needed.)

## Step 4. The kernel is finitely generated

This uses the ring form of Tietze's lemma. Let
`A = Z<z_1, ..., z_a>/(u_1, ..., u_b)`, let `θ : A ->> B` be surjective, and let
`B = Z<w_1, ..., w_c>/(v_1, ..., v_d)`.

Choose noncommutative polynomials `f_j` and `h_i` with `w_j = f_j(θ(z))` and
`θ(z_i) = h_i(w)`. The following Tietze moves present `B` on the generators `z`:
- add the generators `w_j` and the relations `w_j = f_j(z)` and `z_i = h_i(w)`;
- eliminate the `w_j`;
- add the relators `u_i`, which hold in `B`.

The result is the finite relator set

    u_1, ..., u_b,    z_i - h_i(f(z)),    v_l(f(z)).

The ideal `J` of `Z<z>` that they generate contains `(u)`, and `Z<z>/J ≅ B`
compatibly with `θ`. So `ker θ = J/(u)` is generated by the images of
`z_i - h_i(f(z))` and `v_l(f(z))`.

Apply this with `A = U` and `B = R`, both finitely presented. So `I := ker θ` is a
finitely generated two-sided ideal, and `U/I ≅ R`. Hence `PE_4(U/I) ≅ PE_4(R)`,
and `I != U` because `R != 0`. This proves item 1.

## Step 5. Simple rings that are not directly finite

Let `R` be simple, with `ab = 1 != ba`, and put `f = ba`.
- `f` is an idempotent, and `fR ≅ R_R` via `r |-> br`, with inverse `s |-> as`.
- So `R_R = fR ⊕ (1-f)R ≅ R ⊕ P`, where `P = (1-f)R != 0`.

**`R` is a summand of a power of `P`.** Since `R(1-f)R` is a nonzero two-sided
ideal, it is all of `R`. Write `1 = Σ_(j=1..m) a_j (1-f) b_j`. The maps

    P^m -> R, (p_j) |-> Σ a_j p_j,      R -> P^m, r |-> ((1-f) b_j r)_j

compose to the identity on `R`. So `P^m ≅ R ⊕ Q` for some `Q`.

**Powers of `R`.** Iterating `R ≅ R ⊕ P` gives `R ≅ R ⊕ P^n` for every `n`.
With `n = km`, this gives `R ≅ R ⊕ (R ⊕ Q)^k = R^(k+1) ⊕ Q^k`, so `R^k` is a
summand of `R`.

**The elements `x_i`, `y_i`.** Let `ι : R^k -> R` and `π : R -> R^k` be
right-module maps with `πι = 1`. Put `x_i = ι(e_i)`, and let `y_i` be the `i`-th
coordinate of `π(1)`. Right-linearity gives `π(r) = (y_1 r, ..., y_k r)`, so
`y_i x_j = δ_ij`.

The last sentence of item 2 is [[projective-elementary-simplicity-forces-simple-ring]].

## Step 6. The hole

Let `S <= R^x` be perfect. By [[perfect-unit-subgroups-embed-in-elementary-groups]],
`s |-> diag(s,1,1,1)` embeds `S` in `E_4(R) = H`. The data `H`, `T`, `g` and `I`
from Steps 2–4 are exactly the data the hole asks for. This proves item 3.

## Step 7. Directly finite witnesses

Let `R` be directly finite, and suppose `p(1-g)q = 1`.
- **`q` is a unit.** From `(p(1-g))q = 1`, direct finiteness gives
  `q (p(1-g)) = 1`. So `q` has a two-sided inverse.
- **`p` is a unit.** `p(1-g) = q^(-1)` is a unit. Then `p ((1-g)q) = 1` gives
  `((1-g)q) p = 1`, so `p` is a unit.
- **`1-g` is a unit.** `1 - g = p^(-1) q^(-1)`.

This proves item 4.

## Step 8. The dichotomy

**"If".** (NDF) gives the hole by item 3, and a (DF) witness is a witness.

**"Only if".** Let `R = U/I` be a witness. Then `R` is finitely presented, since
`U` is finitely presented and `I` is finitely generated. `S -> R^x` is injective
and `PE_4(R)` is finitely presented and simple. If `R` is not directly finite,
then `R` with the image of `S` is an (NDF) host. Otherwise the witness is directly
finite, and item 4 applies. This proves item 5.

**2026-09-18, referee: the injectivity of `S -> R^x` is asserted here without proof.** It is
not automatic. `S <= H <= T` maps to `(U/I)^x`, and its kernel, normal in the simple group `S`,
is `1` or `S`; the relation `p(1-g)q = 1` only forces the image of `g` to differ from `1`, so
if `g ∉ S` nothing exhibited stops the whole core from collapsing to `1`, and then the witness
ring is not an (NDF) host and this half of item 5 fails. The graph's lemma for it,
`ck-envelope-level-ideal-screen`, is stated with `1 != g in S` and its part (3) needs `g` in
the two-sided ideal of `Z[S]` generated by the `1-s`, whereas
`ck-sandwich-ring-has-fp-projective-simple-quotient` only posits `1 != g in H` with `H`
possibly larger than `S`. So the step needs the added prerequisite
`sandwich-witness-quotients-embed-the-perfect-core`. Items 1-4 and Steps 1-7 are unaffected,
as is the "if" half above.

**Secondary, repairable.** Item 2 of the claim drops the "nontrivial" hypothesis of
`projective-elementary-simplicity-forces-simple-ring`. Nontriviality does follow here, since
`E_4(R)` is perfect and `e_12(1) != 1`, so this is a wording slip rather than a gap.

## Remark: directly finite hosts shift the rank (not part of the claim)

Let `R` be simple and finitely presented, with `PE_4(R)` finitely presented.

**A marked element with `1-g` a unit.** Choose `g in E_4(R)` as follows.
- If `2 in R^x`, take `g = -I_4`.
- In characteristic 2, take `g = c ⊕ c` with `c = [[0,1],[1,1]]`. Then
  `c^2 = c + 1`, so `(1+c)c = 1`, and `c in E_2(Z/2)` has order 3.

**The quotient.** Put `p |-> (1-g)^(-1)` and `q |-> 1`. This maps `U` onto
`M_4(R)`, because the image of `Z[T]` already contains every `rE_ij`. The kernel
is finitely generated by Step 4, and `PE_4(U/I) = PE_4(M_4(R)) = PE_16(R)`.

So a directly finite host realises the hole once `PE_16(R)` is finitely presented
and simple. Matching rank four with rank sixteen is not addressed here.

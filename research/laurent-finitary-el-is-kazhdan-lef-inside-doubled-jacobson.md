**ESTABLISHED** (proof route `laurent-finitary-el-kazhdan-lef-doubled-jacobson-proof`).

**Notation.**
* `F = F_2`, `A = F[z, z^(-1)]`, and `W = F[Z]` with basis `e_k`, `k in Z`.
* `J = F<S,T | TS=1>` acting on `F[N]` by `S e_k = e_(k+1)`, `T e_0 = 0`, `T e_(k+1) = e_k`, and `Q = 1 - ST`.
* `pi : EL_m(J) -> SL_m(A)` is the symbol, with `S -> z`, `T -> z^(-1)`. Its kernel is the finitary group `L_m`.
* `R_bi = F<z, z^(-1), e_00> ⊂ End(W)` is the ring of Laurent-plus-finitary operators, with `e_ij = z^i e_00 z^(-j)`.
* The head of `EL_m(J)` is `x_13(Q)`, or any Weyl conjugate `x_pq(Q)`.

**Statement.** Let `n >= 3`.

1. **(BC1) The ring.** `R_bi` is generated by three elements. `I = span{e_ij}` is an ideal, and `R_bi = A ⊕ I` as
   a vector space with `R_bi / I = A`, the same quotient as `J / JQJ`. Every finite right `R_bi`-module `M` has
   `M e_00 = 0`.
2. **(BC2) The group.** `H_bi(n) := EL_n(R_bi) = GL_fin(Z x {1..n}, F) ⋊ EL_n(A)`, the untwisted bilateral group of
   `untwisted-bilateral-symbol-enrichment-is-lef`. So `H_bi(n)` has the following properties:
   * it is finitely generated and Kazhdan;
   * it is LEF;
   * every finite-dimensional unitary representation, and so every finite quotient, kills `GL_fin`;
   * it is not residually finite and not finitely presented.
3. **(BC3) Ray gluing.** Identify `W` with `F[N] ⊕ F[N]` by `e_k -> (e_k, 0)` for `k >= 0` and
   `e_(-1-k) -> (0, e_k)`. This gives an injective ring map `rho : R_bi -> M_2(J)` with
   ```text
   rho(z) = u = [[S, Q], [0, T]],   rho(z^(-1)) = u^(-1) = [[T, 0], [Q, S]],   rho(e_00) = diag(Q, 0),
   pi(rho(a)) = diag(a(z), a(z^(-1))).
   ```
   Take `n x n` matrices over `rho` and group the `2n` coordinates of `J^(2n)` in pairs.
   * This embeds `H_bi(n)` in `EL_(2n)(J)`, with image `pi^(-1)(Gamma^tw)`, where
     `Gamma^tw = {(a_ij) : a_ij-block = diag(a_ij(z), a_ij(z^(-1))), (a_ij) in SL_n(A)} ≅ SL_n(A)`.
   * The image contains the whole finitary kernel `L_(2n)`.
   * It contains the head `x_(1+,3+)(Q) = rho(x_13(e_00))`.
   * It contains the compressor pair `diag(u, u^(-1), 1, ..., 1) = rho(diag(z, z^(-1), 1, ..., 1))`.
   * The Toeplitz extension `1 -> L_(2n) -> pi^(-1)(Gamma^tw) -> Gamma^tw -> 1` splits.
4. **(BC4) Decomposition.** `EL_(2n)(J) = < H_+ , rho(H_bi(n)) >` with `H_+ = pi^(-1) SL_(2n)(F[z])`. The
   intersection is `L_(2n) ⋊ SL_n(F)`, which is locally finite.
5. **(BC5) Class kill.** Consider any argument that derives, for a subgroup `G <= EL_m(J)` containing the head,
   "the head has trace `-> 1` (or dies) in every sofic, hyperlinear or LEF approximation of `G`" from any conjunction
   of the following:
   * (T) or relative (T) for the pair;
   * a locally matricial simple normal subgroup with finite-module or finite-dimensional-exact head kill;
   * kernel `GL_fin` with quotient an `SL(A)`-lattice;
   * exact degree control by a torus or compressor pair;
   * finitary root identities.

   Such an argument is false, because `G = rho(H_bi(n))` satisfies all of these and is LEF with the head nontrivial
   in its finite models. So a head-death argument for `EL_m(J)` must use relations of `EL_m(J)` that do not hold in
   `pi^(-1)(Gamma^tw)`, that is, the mixing with `H_+` in (BC4).

**Where the killed class dies.** It dies at the interchange of `lim_k` and `sup_H`. Finite-dimensional exact head
kill holds in every fixed dimension `d` through the Jordan bound: the image of `SL_N(F)` has an abelian normal
subgroup of index at most `J(d)`. That bound is not uniform as `d -> infinity`. The LEF models of `H_bi(n)` realize
the failure: they carry the head faithfully, and it has trace `0` in their regular representations.

**What separates `EL_m(J)` from `rho(H_bi)`.** Only invariants that `H_bi` lacks can obstruct.
* **The Toeplitz cocycle, or Fredholm index.** `rho(H_bi)` contains `u ⊕ u^(-1)` but not `u ⊕ 1`. The block
  `S` of `u` has index `-1`, and the top-block symbol determinant of `u ⊕ 1` is `z`. `R_bi` is stably finite; `J`
  contains the index `-1` isometry `S`.
* **Finite presentability.** `EL_4(J)` is finitely presented (`jacobson-el4-is-finitely-presented-steinberg-group`).
  No `H_bi(n)` with `n >= 3` is. So a relator-based obstruction (such as the Steinberg-cover argument behind
  `cohn-elementary-group-is-not-lef`) is not blocked by this calibration.
* **The amalgam relations of (BC4).** These are relations of `EL_(2n)(J)` among `H_+`, which contains
  `u ⊕ 1`, and `rho(H_bi)`, holding over the locally finite intersection `L_(2n) ⋊ SL_n(F)`.

**Why it matters.** `EL_(2n)(J)` is not LEF for `2n >= 4` (`cohn-elementary-group-is-not-lef`). The head, the
whole finitary kernel, a Kazhdan lattice and the compressor pair all sit in one finitely generated Kazhdan LEF
subgroup. The failure of LEF, and any failure of soficity, is therefore carried by the (BC4) mixing between the two
symbol subgroups `SL_(2n)(F[z])` and `Gamma^tw`, not by any single one of them. This is a new pair of independently
falsifiable targets:
* the one-sided half `H_+` in rank `2n` (LEF in rank three by `jacobson-one-sided-symbol-preimages-are-lef`);
* the kernel of `H_+ *_(L ⋊ SL_n(F)) rho(H_bi(n)) -> EL_(2n)(J)`.

**Remark: uniform head bound, not part of the established statement.** The uniform Heisenberg head bound proved on
the landing branch (node `jacobson-heisenberg-root-group-uniformly-kills-the-head`, not in this base) uses only the
exact case and the finitary root identities. Its Steps 1-5 read verbatim over `R_bi`, with the exact case supplied
by (BC1). If that node lands, `H(R_bi)` also satisfies the uniform local bound, and the class kill in (BC5) extends
to arguments that assume uniform local control on the Heisenberg group.

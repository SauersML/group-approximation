**ESTABLISHED** by `v-rank-torsion-constant-global-fixed-rank-proof` (Section 1 of the artifact).
Independent re-derivation requested from `w3-vf-linear`.

**Setting.**
- `F` is any field and `rk` a Sylvester matrix rank function on `F[V]`. Matricial rank models are special cases.
- `p` is an odd prime different from `char F`: `p = 3` in characteristic two, `p = 5` in characteristic three.
- `a_p(rk)` is the torsion constant of `v-rank-models-are-trivial-plus-free-on-odd-cycle-trees`.
- `phi_V = 1 - rk col(1 - [s] : s in S)` for a finite generating set `S`. It does not depend on `S`.

**Theorem.** `a_p(rk) = phi_V(rk)`.

**Corollaries.**
1. `a_p(rk)` is the same for every odd prime `p != char F`.
2. **No localization.** For every nonempty clopen `O != X`, `phi_(V_O) = phi_V`.
3. **Dichotomy.** `rk` is the augmentation rank iff `a_p(rk) = 1`. So
   `thompson-v-ternary-rank-functions-are-augmentation` is equivalent to `a_5(rk) = 1` for every `rk` on `F_3[V]`.
4. **Reduced case.** If `phi_V = 0`, every clopen-cycle subgroup is regular, and every clopen `p`-cycle has
   `rk([g] - 1) = (p - 1)/p`.
5. **[matricial]** Every nontrivial matricial model compresses to a nontrivial model with `phi_V = 0`. The
   compression uses the idempotent of the fixed ideal. No abstract version is known.

**Proof idea.**
- **Upper bound:** tree groups of unbounded order.
- **Lower bound:** `V` is generated by the rigid stabilizers of `X \ [00]` and `X \ [11]`, each by finitely many
  clopen `p`-cycles.
- **Tails:** long tails of disjoint `p`-cycles in `[00]` and in `[11]` have fixed rank close to `a`.
- **Assembly:** column submodularity, `rk col(Y_1 cup Y_2) + rk col(Y_0) <= rk col(Y_1) + rk col(Y_2)`, which follows
  from the Sylvester axioms, shows the generators and the other tail almost preserve that fixed rank.

## Attempts

- **What it does not give.** A reduced rank function looks, on torsion, like a sofic approximation of `V`: regular
  on every clopen-cycle subgroup, with fixed ranks that never localize. So this cannot force triviality alone.
  What it removes is the constant: both gates become "every rank function has `phi_V = 1`".

## Why sufficient

Write `G_n = EL_n(J)`, `N_n = SL_fin(Z)`, `T_n = G_n/N_n`, and
`T_oo = lim T_n` along the injective stabilization maps of the
prerequisite; `E(S)`, `St(S)` are the stable elementary and Steinberg
groups.

**Step 1, a Steinberg presentation of `T_oo`.**  Let `lambda : S -> J`
be the additive section with `lambda(z^j) = s^j` for `j >= 0` and
`lambda(z^-j) = t^j` for `j > 0`.  Send the Steinberg generator
`X_(ij)(a)` to the class of `x_(ij)(lambda(a))`.  Additivity and the
commutation of unrelated roots hold exactly in `G_n`.  For distinct
`i, j, k`, `[x_(ij)(lambda a), x_(jk)(lambda b)] = x_(ik)(lambda(a)
lambda(b))`, and `lambda(a) lambda(b) - lambda(ab)` lies in `I` because
both terms have symbol `ab`; so the two sides of the Steinberg relation
differ by a relative root, which is trivial in `T_n`.  Hence
`St_n(S) -> T_n` is a homomorphism for `n >= 3`, onto because every
`x_(ij)(r)` is `x_(ij)(lambda(r-bar))` times a relative root; passing to
the limit, `St(S) ->> T_oo`.

**Step 2, the kernel.**  The composite `St(S) -> T_oo -> E(S)` is the
standard map, with kernel `K_2(S)`.  Classical inputs (Weibel, K-book,
checked 2026-09-09): `K_2(Z) = C_2` generated by `c = {-1,-1}`
(III.5.2.2, Milnor); for the regular ring `Z`,
`K_2(S) = K_2(Z) (+) K_1(Z)` with the second summand embedded by
multiplication by the unit `z` (V.6.3, V.6.3.1), so
`K_2(S) = <c_0> (+) <tau>`, `c_0 = {-1,-1}`, `tau = {z,-1}`, both of
order two.  The constant symbol `c_0` is a word in `X_(ij)(+-1)`, and
`lambda(+-1) = +-1`, so its image in `T_oo` is the class of the same word
in `E(Z) <= E(J)`, where it is the identity; thus `c_0` dies in `T_oo`.
By (SK4) the kernel of `T_oo -> E(S)` is `C_2`, so the kernel of
`St(S) ->> T_oo` has index two in `K_2(S)` and contains `c_0`; hence

```text
T_oo = St(S) / <c_0>,       class of eta = image of tau.               (1)
```

**Step 3, the finite detector.**  Let `B = Z/4`.  `K_2(B) = C_2` on
`c-bar = {-1,-1}` (Weibel III Ex. 5.13), and since `sr(B) = 1`,
`K_2(r, B) = K_2(B)` for `r >= 3` (Weibel III.5.5.2); so `St_r(B)` is a
finite group, an extension of the finite `E_r(B)` by `C_2`, and it
embeds in `St(B)`.  Put

```text
F_r = ( St_r(B) x St_r(B) ) / <(c-bar_r, c-bar_r)>,     r >= 3,        (2)
```

finite, with `F_r -> F_oo` injective.  The two ring maps `S -> B`,
`z -> 1` and `z -> -1`, induce `beta : St(S) -> St(B) x St(B)`, and by
naturality of symbols `beta(c_0) = (c-bar, c-bar)` while
`beta(tau) = ({1,-1}, {-1,-1}) = (1, c-bar)`.  So

```text
T_oo -> E(S) x F_oo,     [w] -> ( p(w), [beta(w)] )                     (3)
```

is well defined by (1) and injective: an element killed by `p` lies in
`K_2(S)/<c_0> = {1, [tau]}`, and `[beta(tau)] = [(1, c-bar)] != 1` in
`F_oo` because `(1, c-bar)` is not in `<(c-bar, c-bar)>`.

**Step 4, unstable restriction.**  For `n >= 3`, represent an element of
`T_n` by a word in `St_n(S)` (Step 1); both evaluations keep its indices
in `{1,..,n}`, so (3) restricts to an injective homomorphism
`T_n -> EL_n(S) x F_n`.  For `n = 2` use `T_2 <= T_3`.  `EL_n(S)` is
residually finite (reduce a nonzero Laurent entry modulo a prime and
then modulo an irreducible polynomial that is neither `z` nor a divisor
of it), and `F_n` is finite, so `T_n` is residually finite.  The class
of `eta` maps to `(1, [(1, c-bar_n)])`, nontrivial, so a finite quotient
sees the sign.

**Step 5, the finite residual.**  `SL_fin(Z)` has no nontrivial finite
quotient: for a homomorphism to a finite group and distinct internal
indices `a, b`, pigeonhole among the infinitely many other indices two
`r != s` with equal images of `T_(ar)(1)` and `T_(as)(1)`; then
`[T_(ar)(1) T_(as)(1)^-1, T_(rb)(1)] = T_(ab)(1)` (a direct computation
with `(E_(ar) - E_(as)) E_(rb) = E_(ab)` and all other products zero)
is killed, and these transvections generate.  So every finite quotient
of `G_n` kills `N_n`, while `T_n` is residually finite; hence
`Res_fin(G_n) = N_n`.  Countable residually finite groups are MF (regular
representations of separating finite quotients), so
`Rad_MF(G_n) <= N_n`.

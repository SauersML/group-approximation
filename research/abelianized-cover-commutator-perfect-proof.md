## Setup

The first prerequisite replaces the strong input by a nontrivial finitely
presented `G` with the same property and the same generators, giving `(TP1)`.
The second makes `E` torsion-free, hence `T = E'` torsion-free, which is
item 1.  `G` is perfect: a nontrivial finitely generated abelian group has a
nontrivial finite cyclic quotient, and finite groups are MF.

Write `q : E -> G`, so `ker q = A` is abelian and `A` is a left `ZG`-module
under conjugation.  Every element of `R` is a product of conjugates of the
`r_j^(+-1)`, so the classes `r_j-bar` generate `A` as a `ZG`-module.

## Perfectness

`G` perfect gives `q(T) = G` and `q(T') = G`, hence `T'A = E`.  So `E/T'` is
an image of the abelian `A` and is abelian, whence `T = E' <= T'`.  The
reverse inclusion is automatic, so `T = T'`.  This used only that the kernel
is abelian and the quotient perfect.

## Finite generation

Since `[R,R] <= [F,F]`, the abelianization of `E` is `F_ab = Z^r`.  Because
`E = AT` and `T = E'` dies in the abelianization, the restriction

```text
eta : A -->> Z^r,      ker eta = A cap T = A_0,                    (1)
```
is onto, and `G` acts trivially on the target.  Choose `a_i in A` with
`eta(a_i) = e_i`, write `eta(r_j-bar) = sum_i m_(ij)e_i`, put `g_k = q(x_k)`,
and set

```text
b_j = r_j-bar - sum_i m_(ij)a_i,      c_(ki) = (g_k - 1)a_i,       (2)
```
both in `A_0`.  Let `B` be their `ZG`-span.  In `A/B` each `r_j-bar` is an
integer combination of the `a_i` and each `g_k` fixes each `a_i`; since the
`r_j-bar` generate `A` as a module, the `a_i` generate `A/B` as an abelian
group.  So `e_i |-> a_i` gives a surjection `Z^r -> A/B` whose composite with
the map `A/B -> Z^r` induced by `eta` is the identity.  Hence it is an
isomorphism and `B = A_0`.

Now put `y_i = x_i-bar a_i^-1`.  Each lies in `T`, since `eta` kills it, and
`q(y_i) = g_i`, so their images generate `G`.  Conjugation by `y_i` on `A`
equals conjugation by `x_i-bar`, because the two differ by an element of the
abelian `A`.  Therefore the subgroup generated by the `y_i`, the `b_j` and
the `c_(ki)` contains every `G`-conjugate of the elements `(2)`, hence
contains their module span `A_0`, and it surjects onto `T/A_0 = G`.  So it is
all of `T`, giving `(TP2)`.

`T` is nontrivial because it surjects onto the nontrivial `G`.

## No finite-dimensional representations

Let `rho : T -> U(d)`.  The commuting unitaries `rho(A_0)` have a joint
character decomposition into finitely many spaces: split off eigenspaces of
any nonscalar member and repeat, the dimension bounding the number of splits;
no finite generation of `A_0` is needed.  `A_0` is normal in `T` and acts on
each space by a scalar, so it acts trivially on the index set, and the
permutation action factors through `T/A_0 = G`.  Symmetric groups are finite,
hence MF, so that action is trivial and each space is `T`-invariant.

On such a space `H`, conjugation `X |-> rho(t)|_H X rho(t)|_H^*` on
`End(H)` with its Hilbert--Schmidt inner product is a finite-dimensional
unitary representation of `T` killing `A_0`, so it factors through `G`.  Its
image is a countable subgroup of a unitary group, hence MF by constant matrix
sequences, so the strong property of `G` makes it trivial.  Then
`rho(t)|_H` commutes with every matrix and is scalar — commute first with the
diagonal matrix units, then with the off-diagonal ones.

So `rho(T)` is abelian, and `T = T'` forces `rho(T) = 1`.

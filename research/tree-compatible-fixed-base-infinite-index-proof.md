**Item 1.** The odometer `a` is an automorphism of the rooted `h`-ary tree: it maps each
level-`k` cylinder onto a level-`k` cylinder, by `x -> x + 1 mod h^k`. A local odometer on
`[z]` is that automorphism on the subtree below `z` and the identity elsewhere, so it is an
automorphism. On `n = rq + i`, `s` permutes the roots cyclically and applies `a` on one of
them. Each of these fixes the central vertex, or the central edge for `r = 2`, so each
extends to an automorphism of `T`.

**Item 2.** `R_nu` is generated by the `lambda_g`, `g in S`, and `s`, all of which lie in
the subgroup `Aut_B(T)` by hypothesis and item 1. So `R_nu <= Aut_B(T)`. Suppose
`[B : R_nu] < infinity`. Then `R_nu` contains a normal subgroup `K` of finite index in `B`.
The commutator subgroup `V' = V_(h,r)'` is simple and infinite (Higman), and `K ∩ V'` is a
normal subgroup of finite index in `V'`, so `K ∩ V' = V'` and `V' <= Aut_B(T)`. This is
false:
- Let `g in V_(h,r)` be the local copy, on a proper cylinder `[z]` with `|z| >= 1`, of an
  element of `V_(h,1)` that changes the length of some prefix. For `h = 2`, take the local
  copy of Thompson's `x_0 = [0 -> 00, 10 -> 01, 11 -> 1]`.
- `V_(h,r)/V'` has order at most 2, so `g^2 in V'`. `g^2` is the identity on the nonempty
  open set outside `[z]`, and it changes prefix lengths inside `[z]`.
- An automorphism of `T` that fixes every end in an open set fixes a vertex `u` inside the
  corresponding subtree, together with all branches at `u` except possibly one. At a vertex
  of degree `h + 1 >= 3` it then also fixes the remaining neighbour, and so it fixes the
  path from `u` to the vertex `z`. At `z` it is a rooted automorphism of the subtree below
  `z`, so it preserves prefix lengths there.
- `g^2` violates this, so `g^2 in V'` is not in `Aut_B(T)`.
This contradiction gives `[B : R_nu] = infinity`.

**Item 3.**
- *Normal form.* Every element of `C_2 * C_3` has a unique normal form, with `e_0, e_1` in
  `{0, 1}` and `eps_i` in `{+1, -1}`; for `k = 0` the element is `v^(e_0)`.
- *The encoding.* Codes with `k >= 1` fill the tails `t` in `[2^(k+1), 2^(k+2))`; `k = 0`
  gives `t = 0`. Missing tails `t = 1, 2, 3` are the missing points `n = 2, ..., 7`.
- *`lambda_v`.* Left multiplication by `v` toggles `e_0` in every case, so `lambda_v` is
  `n -> n XOR 1`.
- *`lambda_w`, three cases.*
  - `e_0 = 1`: `w` prepends `eps = +1`, so `1t -> 01t`.
  - `e_0 = 0`, `eps_1 = +1`: `w` changes `eps_1` to `-1`, so `01t -> 00t`.
  - `e_0 = 0`, `eps_1 = -1`: `w` deletes `w^-1` and exposes a leading `v`, so `00t -> 1t`.
  These hold except at the finitely many elements with `k <= 1` at the boundary of each case.
- *Re-indexing.* A bijection `N \ {2..7} -> N` equal to `s^-6` near infinity is `s^-6`
  composed with a finitary permutation, so `lambda'_g = s^-6 lambda_g s^6` near infinity and
  `R_nu' = s^-6 <lambda(P), s> s^6`. `s` lies in `Aut_B(T_3)`, and both `lambda_v` and
  `lambda_w` are `T_3` automorphisms:
  - `lambda_v` flips the central edge between `[0]` and `[1]`.
  - `lambda_w` permutes cyclically the three branches `[1], [01], [00]` at the vertex `[0]`,
    whose neighbours are `[00]`, `[01]` and `[1]`.
  Item 2 applies.

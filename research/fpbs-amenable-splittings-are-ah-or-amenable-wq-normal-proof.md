**Complete proof.**

**Case 1: `C` is weakly malnormal in `Gamma`.**
- In case (a), `fpbs-minasyan-osin-weakly-malnormal-splittings` item 1 makes
  `Gamma` virtually cyclic or acylindrically hyperbolic. Virtually cyclic
  groups are amenable, so `Gamma` is acylindrically hyperbolic.
- In case (b), first check that the extension is not ascending. Suppose
  `C = A`, and let `t` be the stable letter, with `t A t^(-1) = D <= A`.
  - `A = C` is amenable.
  - `N = ∪_(n >= 0) t^(-n) A t^n` is an increasing union of copies of `A`, so
    `N` is amenable.
  - `N` is normal. Conjugation by `t^(±1)` shifts the terms. For `a in A`,
    `t^n a t^(-n) in A`, so `a` normalizes each term.
  - `Gamma/N` is generated by the image of `t`, so it is cyclic.
  - So `Gamma` is amenable, a contradiction.

  The case `D = A` is symmetric: replace `t` by `t^(-1)`, and note `D ≅ C` is
  amenable. So `C != A != D`, and item 2 of the import makes `Gamma`
  acylindrically hyperbolic.

**Case 2: `C` is not weakly malnormal.** By definition, `|C^g ∩ C|` is infinite
for every `g in Gamma`. This is `s`-normality in the sense of Peterson--Thom,
arXiv:0708.4327, Section `notionsofnormality` (ii). With `g = 1`, `C` is
infinite.
- Every `g` has `g C g^(-1) ∩ C` infinite, so the one-step chain
  `C ⊂ Gamma` shows that `C` is `q`-normal, hence `wq`-normal.
- Equivalently, with the intermediate-subgroup criterion: for `C <= K < Gamma`
  and any `g notin K`, `g K g^(-1) ∩ K ⊇ g C g^(-1) ∩ C`, which is infinite.
- `C` is amenable by hypothesis.

**Consequences.** Hypothesis 2 of the residual claim excludes 1. Hypothesis 3
excludes 2. A finite subgroup is amenable. For the second consequence, 2 is
excluded by the class definition, so 1 holds.

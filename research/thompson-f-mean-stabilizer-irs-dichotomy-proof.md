Notation as in the claim.
- `d_g(ω) = |⟨g⟩ω| ∈ {1, 2, ..., ∞}` is the size of the `⟨g⟩`-orbit of `ω`.
- `supp(g) = {u ∈ (0,1) : g(u) ≠ u}` is the support of `g` in the interval.
- Two facts are used throughout:
  - `F` is torsion-free. An increasing homeomorphism `f` of `[0,1]` with `f(u) > u` at some `u` has
    `f^n(u) > u` for all `n ≥ 1`.
  - Every `g ∈ F'` is the identity near `0` and near `1`. The germ map
    `f ↦ (log_2 f'(0+), log_2 f'(1-))` is a homomorphism to an abelian group, so it kills `F'`. So
    `supp(g) ⊆ [a,b]` for some `0 < a < b < 1`.
- The input is item 3 of `thompson-f-following-models-separate-iff-mean-charges-commutator`:
  `m(Fix(g)) = 1 - t` for every `g ∈ F' \ {e}`.

**1. Short finite orbits are null.** Let `q ∈ F' \ {e}` and `k ≥ 1`.
- If `1 < d_q(ω) ≤ k`, then `q^(k!)` fixes `ω` and `q` does not.
- `q^(k!) ∈ F' \ {e}` by torsion-freeness, so `m(Fix(q^(k!))) = 1 - t = m(Fix(q))`.
- `Fix(q) ⊆ Fix(q^(k!))`, so `m({1 < d_q ≤ k}) ≤ m(Fix(q^(k!)) \ Fix(q)) = 0`.

**2. Disjointly supported pairs fix the same set.** Let `q, r ∈ F' \ {e}` with disjoint supports.
- `q^a r^b ∈ F' \ {e}` whenever `(a,b) ≠ (0,0)`: the factors have disjoint supports, and nontrivial powers
  are nontrivial.
- For `M ≥ 1` put `avg(ω) = M^-2 Σ_(0 ≤ a,b < M) 1[q^a r^b ω = ω]`. Every term with `(a,b) ≠ 0` has mean
  `1 - t`, and the `(0,0)` term is 1. So `m(avg) ≥ 1 - t`.
- **Pointwise bound.** Fix `b` and let `A_b = {a ∈ Z : q^a r^b ω = ω}`.
  - If `a, a' ∈ A_b`, then `q^(a-a')` fixes `q^(a') r^b ω = ω`. So `A_b` is empty or a coset of
    `d_q(ω)Z` (a single point if `d_q = ∞`).
  - Hence `|A_b ∩ [0,M)| ≤ M/d_q(ω) + 1`, and `avg(ω) ≤ 1/d_q(ω) + 1/M`. The same holds with `r`.
- **Case split.** For `k ≥ 1`:
  `min(1/d_q, 1/d_r) ≤ 1_(Fix(q) ∩ Fix(r)) + 1[1 < d_q ≤ k] + 1[1 < d_r ≤ k] + 1/k`.
  - If `ω` is fixed by both, the first term is 1.
  - Otherwise, say `d_q(ω) ≥ 2`. Either `d_q ≤ k`, and the second term is 1, or `1/d_q < 1/k`.
- **Integrate.** By step 1, `1 - t ≤ m(Fix(q) ∩ Fix(r)) + 1/k + 1/M` for all `k, M`. So
  `m(Fix(q) ∩ Fix(r)) ≥ 1 - t = m(Fix(q)) = m(Fix(r))`, and therefore `m(Fix(q) Δ Fix(r)) = 0`.

**3. Item 1.** Let `q ∈ F' \ {e}`.
- `supp(q) ∪ supp(c) ⊆ [a,b]` with `a > 0`.
- `x_0^n` maps `[1/4,3/4]` into `(0, 2^-n]`, and `supp(c) ⊆ (1/4,3/4)`. So
  `r = x_0^n c x_0^-n ∈ F' \ {e}` has `supp(r) = x_0^n(supp c) ⊆ (0, 2^-n)`, which is disjoint from
  `[a,b]` once `2^-n ≤ a`.
- Step 2 twice gives `Fix(q) ≈ Fix(r) ≈ Fix(c)` modulo null sets, i.e. `m(Moved(q) Δ X) = 0`.

**4. Item 2.** `gX = Moved(gcg^-1)`, and `gcg^-1 ∈ F' \ {e}`. Apply item 1.

**5. The stabilizer measures.**
- **The algebra.** `Sub(F) ⊆ {0,1}^F` is closed, hence compact, metrizable and totally disconnected.
  Its clopen algebra is generated by `U_g = {H : g ∈ H}`.
- **The measures.** For clopen `E` and `Y ∈ {X, Ω \ X}`, put `μ_Y(E) = m(1_Y(ω)·1_E(Stab(ω)))`. The
  function `ω ↦ 1_E(Stab(ω))` is a finite Boolean combination of indicators of sets `Fix(g)`.
  - `μ_Y` is finitely additive on the clopen algebra.
  - A clopen set that is a countable disjoint union of clopen sets is a finite union, by compactness. So
    `μ_Y` is countably additive on the algebra and extends uniquely to a Borel measure. The same
    argument gives `μ_Ω = μ_X + μ_(Ω \ X)`.
- **Conjugation invariance.** `Stab(gω) = g Stab(ω) g^-1`. For `f ∈ ℓ∞(Ω)`, invariance of `m` gives
  `m(f(g^-1·)) = m(f)`, and item 2 gives `m(|1_X(g^-1·) - 1_X|) = 0`. So `μ_Y(gEg^-1) = μ_Y(E)` on the
  algebra, hence on all Borel sets.

**6. The separating part is trivial.**
1. **No elements of F'.** For `q ∈ F' \ {e}`, `μ_X(U_q) = m(X ∩ Fix(q)) = 0` by item 1. `F'` is countable,
   so `μ_X` is carried by `S = {H : H ∩ F' = {e}}`.
2. **S is countable.**
   - Each `H ∈ S` maps injectively to `F/F'`, a finitely generated abelian group, since `F` is
     finitely generated. So `H` is finitely generated.
   - `F` has countably many finite subsets, so `S` is countable.
   - A conjugation-invariant finite measure on a countable invariant set is a sum of atoms, and atoms
     in one conjugacy class have equal mass. So every atom of `μ_X` has finitely many conjugates.
3. **Lemma.** If `H ∈ S` has finitely many conjugates, then `H = {e}`.
   - **Finite conjugacy class of an element.** Let `h ∈ H \ {e}` and let `H_1, ..., H_s` be the
     conjugates of `H`. Each `H_j ∩ F' = {e}`, because `F'` is normal. Every `ghg^-1` lies in some
     `H_j` and in the coset `hF'`. Two elements of `H_j` in the same coset differ by an element of
     `H_j ∩ F'`, so `{ghg^-1 : g ∈ F}` has at most `s` elements. Hence `C_F(h)` has finite index.
   - **The centralizer has infinite index.** Take a component `(α,β)` of `supp(h)`. Replacing `h` by
     `h^-1`, which has the same centralizer, we may assume `h(u) > u` there. Pick `u_0 ∈ (α,β)` and put `J_i = [h^(3i)(u_0), h^(3i+1)(u_0)]` for `i ≥ 0`.
     - The intervals `J_i` and `h(J_j)` have pairwise disjoint interiors.
     - Choose `q_i ∈ F' \ {e}` supported in a dyadic subinterval of `int(J_i)`. These exist: conjugate
       the standard copy of `F` into that subinterval and take a nontrivial commutator.
     - For `T ≠ T'` in `{0, ..., N-1}`, the element `p = q_T^-1 q_(T')` is a nontrivial product of
       `q_i^±1` with disjoint supports. `hph^-1` has support `h(supp p)`, disjoint from `supp(p)`, so
       `hph^-1 ≠ p` and `p ∉ C_F(h)`. So the `2^N` elements `q_T` lie in distinct cosets of `C_F(h)`,
       for every `N`.
   - This contradicts finite index. So `H = {e}`.
4. **Conclusion.** `μ_X = t·δ_{e}`. In particular `m(X ∩ Fix(g)) = μ_X(U_g) = 0` for `g ≠ e`, which is
   item 3.

**7. The complement.**
- For `q ∈ F'`, `μ_(Ω \ X)(U_q) = m(Ω \ X) - m((Ω \ X) ∩ Moved(q)) = 1 - t`, using item 1 (or trivially
  for `q = e`).
- By countable additivity, `μ_(Ω \ X)`-almost every `H` contains `F'`.
- If `t < 1`, put `μ_0 = μ_(Ω \ X)/(1-t)`. Then `μ_Ω = t·δ_{e} + (1-t)μ_0`. `{e}` does not contain `F'`,
  so `μ_Ω({e}) = t`. This is item 4.

**8. Corollaries.**
- **Witness form (⇐).** A mean-free amenable action has `m(Moved(c)) = 1`. Item 2 of the companion claim
  gives separating labelled models, and the companion shows they witness soficity.
- **Witness form (⇒).** Item 1 of the companion gives an invariant mean with `t ≥ ε > 0`. Put
  `m_X(f) = m(f·1_X)/t`.
  - `m_X` is invariant: `m(f(g^-1·)1_X) = m(f·1_X(g·)) = m(f·1_(g^-1X)) = m(f·1_X)`, using invariance of
    `m` and then item 2.
  - `m_X(Fix(g)) = 0` for `g ≠ e` by item 3.
- **Single orbits.** A labelled model on `S ⊆ F/H` with error `δ` has `|x_i S Δ S| ≤ 2δ|S|`. If the
  Schreier graph has Cheeger constant `h > 0`, then `δ ≥ h/4` for every nonempty finite `S`.

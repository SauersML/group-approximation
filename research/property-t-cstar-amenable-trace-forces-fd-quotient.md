Let `A` be a unital C-star algebra with Bekka's property (T).  Then `A`
admits an amenable tracial state if and only if `A` has a nonzero
finite-dimensional quotient.

This is Brown, *Kazhdan's Property T and C-star-algebras*, Corollary 5.6.
The direction used here is that an amenable trace supplies normalized
Hilbert--Schmidt ucp approximations; property (T) repairs them to
finite-dimensional star-homomorphisms, one of which is nonzero.  Property (T)
passes to quotients.  For a discrete property-(T) group `G`, its full group
C-star algebra has property (T), so the statement applies to every quotient
of `C^*(G)`.

Let `J` be the Jacobson algebra generated by `S,T` with `TS=1`,
and put `Q=1-ST`.  The elements

```text
E_(ij)=S^i Q T^j,                       i,j>=0,          (BJC1)
```

are matrix units.  In particular,

```text
QJQ=field times Q.                                      (BJC2)
```

Let `A` be any occurrence algebra commuting with the raw letters.
Then

```text
Q(J tensor A)Q=Q tensor A.                              (BJC3)
```

Consequently, if the literal Lin coefficient

```text
B=e_b c_y^* e_r c_x e_a
```

is placed anywhere in a bounded `S/T` path which starts and ends in
the `Q` corner, the collected return contains no raw letter:

```text
Q w(S,T;B_1,...,B_m) Q=Q tensor B_w                  (BJC4)
```

for an ordinary coefficient `B_w` in the algebra generated by the
`B_i`.  For the shortest round trip, `QTSQ=Q`, so `B_w=B`.
A path with unequal forward and backward raw degree vanishes at one of
the two `Q` cuts.

Every fixed return visits only finitely many matrix units.  If its
maximum height is `L`, its active raw part lies in

```text
M_(L+1)(A).                                              (BJC5)
```

Thus the raw package is a finite matrix amplification of the occurrence
algebra.  It neither removes the Lin multiplicity nor converts the
three-corner zero compression into an ordinary group relator.

In every tensor-product tracial model,

```text
||Q tensor B||_2^2=tau(Q)||B||_2^2,                     (BJC6)
```

and the nonzero singular values and polar source of `B` are merely
copied into the `Q` block.  The cross-Gram loss is the only invariant
which survives, and it survives unchanged up to the head trace; no new
non-Morita invariant is created by the raw return.

Therefore a bounded positive/negative return can advance the compiler
only if at least one raw letter acts nontrivially on the middle
occurrence algebra.  A relation of the form
`S a=alpha(a)S` must carry a genuinely non-inner occurrence action,
and the resulting return holonomy must meet the full-`C` target.
Commuting raw letters and rectangular intertwiners whose cokernel reduces
the Lin tuple are both covered by `(BJC3)`.  No such outer return is
proved here; the nonhyperlinear-group root remains open.

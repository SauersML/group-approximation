**Established by citation.** Xuanlong Fu and Huaxin Lin, *Tracial oscillation
zero and stable rank one*, [arXiv:2112.14007v4](https://arxiv.org/abs/2112.14007),
dated 2024-01-21, published in Canad. J. Math. 77 (2025), 563–630. The
journal reference was confirmed on the arXiv abstract page on 2026-09-16. The
HTML full text of v4 was read on 2026-09-16.

**Theorem 1.1, verbatim:** "Let A be a separable simple C*-algebra which admits
at least one densely defined non-trivial 2-quasitrace and has strict
comparison. Then the following are equivalent: (1) A has tracial approximate
oscillation zero; (2) Γ is surjective (see 2.13) and A has stable rank one;
(3) A has stable rank one; (4) Γ is surjective and A has almost stable rank
one; (5) A has property (TM)." The same page says: "Note that Theorem 1.1 is
stated without assuming that A is nuclear or exact."

**Definitions, verbatim or as printed:**

- **Definition 2.7.** "Denote by QT~(A) the set of densely defined 2-quasitraces
  on A⊗K", with a finite value required on `Ped(A⊗K)`.
- **Definition 2.11.** "A simple C*-algebra A is said to have (Blackadar's)
  strict comparison, if, for any a,b∈(A⊗K)_+, one has a≲b, provided
  d_τ(a)<d_τ(b) for all τ∈QT~(A)\{0}."
- **2.8.** "Every unital C*-algebra is compact." For compact `A`: "Denote by
  QT(A) the set of 2-quasitraces τ with ‖τ|_A‖=1."
- **Definition 2.16.** `‖x‖_{2,T} = sup{τ(x*x)^{1/2} : τ ∈ T}` for compact `T`.
- **Definition 8.1.** "Let A be a C*-algebra and S⊂QT~(A)\{0} be a non-empty
  compact subset. C*-algebra A is said to have property (TM) relative to S, if
  for any a∈Ped(A⊗K)_+, any ε>0, any n∈N, there is a c.p.c. order zero map
  φ:M_n→Her(a) such that ‖a−φ(1_n)a‖_{2,S}<ε. A σ-unital simple C*-algebra A
  with QT~(A)\{0}≠∅ is said to have property (TM), if for some
  e∈Ped(A)^1_+\{0}, Her(e) has property (TM) relative to closure QT(A)^w."

The target is the theorem with these definitions written out.

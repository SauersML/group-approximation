**ESTABLISHED** by `thompson-f-abelian-cofactors-fixing-an-interval-proof` (not yet refereed).

Let `F ≤ PL_o([0,1])` be Thompson's group in its standard realization. Let `H, K ≤ F` with
`F = HK` and `K` abelian. Write `X = F/H`, `Fix(K)` for the set of points of `[0,1]` fixed by every
element of `K`, and `C_F(K)` for the centralizer.

1. **Dichotomy.** Either `H` contains a subgroup isomorphic to `F`, or all of the following hold:
   - `K ∩ H = 1`, and `K` acts simply transitively on `X`, so `k ↦ kH` identifies `X` with `K`;
   - `F` acts faithfully on `X`, so `core_F(H) = 1`;
   - there is a homomorphism `ψ : C_F(K) → K` with `c·(kH) = k ψ(c) H`, so `C_F(K)` acts on
     `X ≅ K` by translations, `ψ|_K = id`, and `C_F(K) = (C_F(K) ∩ H) ⋊ K` with
     `C_F(K) ∩ H = ker ψ ⊇ [C_F(K), C_F(K)]`.
2. **Fixed-interval case.** If `Fix(K)` has nonempty interior, then `H` contains a subgroup
   isomorphic to `F`. More precisely, either the first alternative of item 1 holds, or
   `H ⊇ F(a,b)` for all dyadic `a < b` with `[a,b] ⊆ int Fix(K)`.

**Why it matters.**
- The survivor recorded in `liouville-action-criteria-cannot-decide-thompson-f-amenability` asks for
  a factorization `F = HK` with `H` amenable and `K` abelian. Such a factorization would make `F/K`
  a LAT `F`-set with abelian stabilizers, which is the input to Juschenko–Zheng's Question 5.
- Item 2 kills that route whenever `K` fixes an open interval, for example whenever `K` is generated by
  finitely many elements whose supports miss a common interval, such as `K = ⟨x_1⟩`.
  - *Invariant:* containment of a copy of `F` in the cofactor `H`.
  - *Dying step:* proving `H` amenable. That already requires amenability of a subgroup isomorphic
    to `F`, so the route is circular.
- What survives is exactly the dense-support case, where the union of the supports of `K` is dense in
  `[0,1]`, as for `K = ⟨x_0⟩`. That case is the OPEN general claim
  `thompson-f-abelian-factorizations-put-f-into-the-cofactor`. Item 1 is the structure a
  counterexample must have.

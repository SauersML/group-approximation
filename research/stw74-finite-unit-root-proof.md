Put `u=[1_A]`.  The required input from the LXXIV hypothesis is that `u` is
properly infinite, so

```text
m u = u                 for every m>=1.
```

First observe that `u` is the largest element of `Cu(A)`.  Indeed, if `b` is
a positive element of `A tensor K`, then each cutdown `(b-epsilon)_+` is
Cuntz below the unit of some finite matrix algebra over `A`, and hence below
`m u=u` for some `m`.  Taking the supremum over `epsilon` gives `[b]<=u`.

Now let `0!=x` in `Cu(A)`.  Simplicity says that the order ideal generated by
`x` is all of `Cu(A)`, and therefore

```text
u <= sup_n n x.
```

The projection class `u` is compact.  Hence `u<=n x` for some finite `n`.
On the other hand, `x<=u`, so

```text
n x <= n u = u.
```

The two inequalities give `n x=u`.

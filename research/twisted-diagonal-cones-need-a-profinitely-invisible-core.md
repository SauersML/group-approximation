**ESTABLISHED (proposed; unreviewed).**  Derivation: [[twisted-diagonal-cones-need-a-profinitely-invisible-core-proof]].
It answers the step left open by [[kazhdan-double-cones-add-one-sigma1-bit]] ("What survives", item 1), on
the way to [[sofic-recognition-finite-presentations-is-pi2-complete]].

## Setting

`Gamma ≤ G` is a **Kun-Thom pair**: `G` and `Gamma` have property (T), and `Gamma` is infranormal and not
normal in `G`.  For a group `H` and a homomorphism `psi : Gamma -> H`, the **twisted-diagonal cone** is

```text
X(H, psi) = (H x Gamma) *_(Gamma_psi) G ,    Gamma_psi = { (psi(g), g) : g in Gamma } ,
```

where `Gamma_psi` is identified with `Gamma ≤ G` by `(psi(g), g) <-> g`.  Call a finite-index normal
subgroup `G_1 ⊴ G` a **level**, and put `Gamma_1 = Gamma ∩ G_1`.

## Theorem

**(V1) Levels restrict Kun-Thom pairs.**  For every level `G_1`, the pair `Gamma_1 ≤ G_1` is again a Kun-Thom
pair.  Indeed `G_1` is generated by `P_Gamma ∩ G_1`, every element of which compresses `Gamma_1`, and
`Gamma_1` is not normal in `G_1`.  So `G_1 *_(Gamma_1) G_1` is nonsofic, by Kun-Thom Theorem A (v3).

**(V2) Virtual double embedding.**  If `C_H(psi(Gamma_1)) ≠ 1` for some level `G_1`, then `X(H, psi)`
contains `G_1 *_(Gamma_1) G_1`, and so it is **nonsofic**.

**(V3) The invisible core.**  Suppose `psi(Gamma)` is finite, which is automatic when `H` is amenable,
because a Kazhdan group has only finite amenable quotients.  Then the subgroups `psi(Gamma_1)` form a
downward-directed family of subgroups of a finite group.  So they stabilise at a normal subgroup

```text
F_inf(psi) = intersection over levels G_1 of psi(Gamma ∩ G_1)   ⊴   psi(Gamma) ,
```

the **invisible core** of `psi`.  It is attained at some level.  So:

- `X(H, psi)` is nonsofic unless `C_H(F_inf(psi)) = 1`.  In particular it is nonsofic when
  - `F_inf(psi) = 1`, that is, `psi` is **G-visible**: its kernel contains `Gamma ∩ G_1` for some level;
  - `F_inf(psi)` has a nontrivial centre (for example, when it is abelian, or a p-group, and nontrivial).
- The condition "`C_H(psi(Gamma)) = Phi_e`" of the twisted-cone plan is the wrong invariant.  The one that
  decides is `C_H(F_inf(psi))`, and that contains `C_H(psi(Gamma))`.
- **Necessary condition for any sofic branch.**  Put `F = psi(Gamma)`.  The subgroup `F x Gamma ≤ H x Gamma`
  contains `Gamma_psi`, so the **finite twisted cone** `X(F, psi)` is a subgroup of `X(H, psi)`.  Hence
  `X(H, psi)` sofic forces `X(F, psi)` sofic, whatever `H ⊇ F` is.

**(V4) Such cones are never residually finite.**  If `F_inf(psi)` is nonabelian, the subgroup
`[F_inf, F_inf] x 1 ≤ H x 1` lies in the finite residual of `X(H, psi)`.  So a soficity certificate for the
positive branch can never come from residual finiteness, LEF, or any finite-quotient argument.

**(V5) The loophole is nonempty for the Theorem E pair.**  For `Gamma = EL_r(F_q[x_1..x_d])` in
`G = EL_r(F_q[x^(±1)]) x| SL_d(Z)` (`r, d ≥ 3`), evaluation at the origin
`ev_0 : Gamma -> EL_r(F_q) = SL_r(F_q)` has invisible core all of `SL_r(F_q)`.  For every level `G_1` there is
an `n ≥ 1` with `e_ij(a(x_1^n - 1)) ∈ Gamma ∩ G_1` for all `a ∈ F_q`, and `ev_0` of it is `e_ij(-a)`.
These generate `SL_r(F_q)`.  Composing with the
projection to `PSL_r(F_q)`, which is simple and centreless, gives a twist whose core `F` has trivial
centraliser in `F` itself.

## Consequence for the route

The Kazhdan-cone programme reaches a sofic INF branch only through twists whose images of every level have
centraliser trivial on INF.  With `H` amenable, as for the machine group `G_e` of
[[machine-center-vanishes-exactly-on-inf]], the invisible core must be a **nonabelian finite group with trivial
centraliser in `H`**, and must be invisible to every finite quotient of `G`.  In particular:

- every twist through a congruence quotient that `G` sees is dead;
- the central `Phi_e` of the machine group always lies in `C_H(F_inf)`, so the FIN branch still fires by (V2).

What is left is exactly [[finite-twisted-kazhdan-cone-is-sofic]]: is the finite twisted cone
`(F x Gamma) *_(Gamma_(ev_0)) G`, with `F = PSL_r(F_q)`, sofic?  If it is nonsofic, then by (V3) **every**
twisted-diagonal cone over this pair that factors through `ev_0` is nonsofic, whatever `H` is.

Let `G <= Sym(N)` be shift-similar in the sense of Mallery--Zaremsky, arXiv:2202.00822, and let `H_n(G)` be
their Houghton-like group (Definition 4.1): the bijections of `[n] x N` that send a finite set `M_+` to a finite
set `M_-` of the same size by some bijection, and send each quasi-ray `Q(k, M_+)` to `Q(k, M_-)` by
`beta_{k,M_-} ∘ g_k ∘ beta_{k,M_+}^{-1}` with `g_k in G`. Then:

1. `G^n` embeds in `H_n(G)`, by `(g_1, ..., g_n) -> [∅, (g_1, ..., g_n), ∅]` (Observation 5.1). In particular
   `G <= H_n(G)`.
2. `H_n(G)` admits a strongly shift-similar representation, that is, an isomorphism onto a strongly
   shift-similar subgroup of `Sym(N)` (Proposition 5.5). Its proof uses that `H_n(G)` contains
   `FSym([n] x N)`.
3. If `G` is strongly shift-similar then `H_1(G) = G` (Proposition 5.3). For `n >= 2`, `H_n(G)` is generated by the Houghton group `H_n` and `G^n` (Proposition 5.10). So if `G` is
   finitely generated then so is `H_n(G)` (Corollary 5.11).
4. If `G` is strongly shift-similar then every `psi_j : G -> G` is surjective (Lemma 3.19). So the source's
   notion of strongly shift-similar (Definition 3.17: the germ shifting map `psi_infinity` is surjective)
   implies the one quoted in `fp-strongly-shift-similar-admits-type-a-action` (each `psi_j` surjective).

**Consequence used in this graph.** By item 2 and `fp-strongly-shift-similar-admits-type-a-action`, if
`H_n(G)` is finitely presented, then it has a type (A) action. By item 1 and
`type-a-action-gives-boone-higman-for-subgroups`, `G` (and every subgroup of `G`) then embeds in a finitely
presented simple group. So for Boone--Higman purposes, finite presentation of `H_n(G)` for one `n` can replace
finite presentation of `G`.

**Open in the source.** Question 5.13 asks whether `G` finitely presented and `n >= 3` imply `H_n(G)` finitely
presented. Section 5.3 of the source says higher finiteness properties of `H_n(G)` are "surprisingly
difficult". Brown's theorem that `H_n` has type `F_{n-1}` is recalled there, not proved.

**ESTABLISHED** (lane proof, not reviewed). No priority is claimed.

The one external input is Adamczewski–Bell, *A problem around Mahler functions*,
arXiv:1303.2019, Theorem `thm: main`. It was read at source (TeX in the swarm
scratchpad, `gq/src/kourovka/adamczewski-bell-1303.2019.tex`):

> Let `K` be a field of characteristic zero and let `k` and `l` be two
> multiplicatively independent positive integers. Then a power series
> `F(z) ∈ K[[z]]` is both `k`- and `l`-Mahler if and only if it is a rational
> function.

Here `F` is `k`-Mahler if `1, F(z), F(z^k), F(z^{k^2}), …` are linearly dependent
over `K(z)` (their eq. `eq: mahler`). Everything else below is proved in full. This
route is independent of Bell's theorem (`bell-generalized-cobham-theorem`, Sém.
Lothar. Combin. 54A (2006), B54Ap), which
`ct-z-normalizers-are-2-and-3-regular` item 3 uses instead.

## Statement

Kourovka 17.57 (S. Kohl) asks whether `Out(CT(Z)) = ⟨σ⟩ ≅ C_2`, where
`σ(n) = −n − 1`. **Yes.**

## Proof

Let `φ ∈ N`, the normalizer of `F = CT(Z)` in `Homeo(Ẑ)`, with `φ(N_0) = N_0`; this
is possible after composing with `σ` (item 2 of the reduction node). By item 4 of
`out-ct-z-is-c2-iff-normalizers-are-somewhere-affine`, it suffices to show that `φ`
is affine on some box. Put `f := Φ = φ|_{N_0}`.

1. **Regular, bounded growth, integer bijection.** By
   `ct-z-normalizers-are-2-and-3-regular`, `f : N_0 → N_0` is a bijection that is
   2-regular and 3-regular over `Q`, with `|f(n)| ≤ C n^D`.
2. **Regular implies Mahler.** Let `b ∈ {2, 3}` and let `V` be the `Q`-span of the
   `b`-kernel of `f`, with basis `v_1, …, v_d`.
   - `V` is stable under `Λ_r : v ↦ (n ↦ v(bn + r))` for `0 ≤ r < b`, since `Λ_r`
     maps kernel elements to kernel elements.
   - So the generating vector `V(z) = (Σ_n v_i(n) z^n)_i` satisfies
     `V(z) = A(z) V(z^b)`, with `A` a polynomial matrix (`A = Σ_r z^r M_r`, where
     `M_r` is the matrix of `Λ_r`).
   - `F(z) = Σ_n f(n) z^n = λ · V(z)`, so for `0 ≤ i ≤ d`,
     `F(z^{b^i}) = λ · A(z^{b^i}) ⋯ A(z^{b^{d−1}}) V(z^{b^d})`.
   - These `d + 1` series lie in the `Q(z)`-span of the `d` components of
     `V(z^{b^d})`, so they are linearly dependent over `Q(z)`. Hence `F` is
     `b`-Mahler.
3. **Rational.** 2 and 3 are multiplicatively independent. By Adamczewski–Bell,
   `F ∈ Q(z)`, so `f` satisfies a linear recurrence with constant rational
   coefficients for `n ≥ n_1`.
4. **Integrality.**
   - Let `f'(n) = f(n + n_1)`, with minimal recurrence polynomial `χ ∈ Q[x]` of
     degree `d'`.
   - The shifts `S^j f'` (`S f'(n) = f'(n+1)`) span a `Z`-module `M` of integer
     sequences satisfying the same recurrence.
   - Evaluation at `0, …, d' − 1` is injective on solutions, so `M ↪ Z^{d'}`. Hence
     `M` is free of finite rank, and `S|_M` is an integer matrix.
   - `χ` is the minimal polynomial of `S` on `M ⊗ Q` (cyclic, generated by `f'`), so
     `χ` divides the monic integer characteristic polynomial of `S|_M`.
   - Hence every root of `χ` is an algebraic integer, and the roots are closed under
     Galois conjugation.
5. **Unit circle.**
   - For `n ≥ m`, uniquely, `f'(n) = Σ_α P_α(n) α^n`, over the nonzero roots `α` of
     `χ`, with `P_α ≠ 0`.
   - `Σ_n n^k α^n z^n` has a pole of order `k + 1` at `1/α`. Poles at distinct points
     do not cancel, so the rational function `Σ f'(n) z^n` has a pole at each `1/α`.
   - `|f'(n)| ≤ C' n^D` makes it analytic in `|z| < 1`, so every `|α| ≤ 1`, and by
     step 4 so is every conjugate.
6. **Roots of unity (Kronecker).**
   - For such `α` of degree `s`, the polynomials `∏_σ (x − σ(α)^k)`, `k ≥ 1`, are
     monic in `Z[x]` of degree `s`, with `j`-th coefficient bounded by `binom(s, j)`.
   - There are finitely many of them, so `{α^k}` is finite, and `α` is a root of
     unity.
   - With `N` the lcm of their orders, on each class `n ≡ i (mod N)`, `n ≥ n_0`, the
     function `f` agrees with a polynomial `p_i`.
   - `p_i` has rational coefficients, by Lagrange interpolation at integer points.
7. **An affine class.**
   - No `p_i` is constant, by injectivity.
   - If every `deg p_i ≥ 2`, then each `p_i` has positive leading coefficient (since
     `f ≥ 0` and `f` is unbounded), so `#{n : f(n) ≤ Y} = O(√Y)`. But bijectivity
     onto `N_0` gives `Y + 1`.
   - So some class `i mod N` has `f(i + Nt) = c_0 + c_1 t` for `t ≥ t_0`, with
     `c_1 ∈ Z_{>0}` and `c_0 ∈ Z` (since the values are integers).
8. **Affine on a box.**
   - `{i + Nt : t ≥ t_0}` is dense in `B(i, N)`, because `{t ≥ t_0}` is dense in `Ẑ`.
   - `φ` and `i + Nt ↦ c_0 + c_1 t` are continuous on `B(i, N)` and agree on this
     dense set, so `φ(i + Nt) = c_0 + c_1 t` for all `t ∈ Ẑ`.
   - This is condition (b) of the reduction node. Hence `N = F ⊔ σF`, and
     `Out(CT(Z)) = ⟨σ⟩ ≅ C_2`. ∎

## Remarks

- **What the proof does not use.** It does not use the germ-group rigidity (item 3 of
  the reduction node). Only conjugates of the dilations `z ↦ 2z + e` and
  `z ↦ 3z + e` are used, together with the three facts about `φ`: `φ(Z) = Z`,
  `φ(N_0) = N_0` and continuity.
- **Why the multiplicative independence is essential.** For `V = CT_∅(Z)`, only
  base-2 dilations exist, and `Out(V) ≅ O_2` is infinite. The analogous statement for
  a finite set `P` (`Out(CT_P(Z))` with `|P| ≥ 1`) should follow by the same argument
  with bases `2` and `p ∈ P`.
  - This is only a sketch. Checking items 2–4 of the reduction node for `CT_P` means
    rerunning Step 2 of `ct-p-z-groups-are-pairwise-nonisomorphic` with
    `X_P ∩ Q ⊋ Z`, so it is not claimed here.

## Setting

Let `R = L_(F_2)(1,2)` with generators `s_0, s_1, t_0, t_1` (`t_i s_j = δ_ij`,
`s_0 t_0 + s_1 t_1 = 1`), acting on `M = C(C, F_2)` by `(s_i f)(a w) = δ_(a,i) f(w)` and
`(t_i f)(w) = f(i w)`. For a word `w` write `s_w`, `t_w` for the prefix products, so
`(s_w f)(w y) = f(y)`, `s_w f = 0` off `[w]`, and `(t_w f)(y) = f(w y)`. The units
`Σ s_(a_i) t_(b_i)` over bijections of complete prefix codes are a copy of Thompson's `V`
in `U = R^×`, acting on `M` by `f ↦ f ∘ φ^(-1)` for the prefix replacement `φ`.

Say `H <= V` is **clopen-rigid** if

- **(H1)** `H` is transitive on proper nonempty clopen subsets of `C`, and
- **(H2)** the only clopen sets invariant under `Stab_H([0])` are `∅`, `[0]`, `[1]`, `C`.

`V` itself is clopen-rigid.

A **diagonal cone subgroup** of `V` is a subgroup of the following form, or its conjugate by
an element of `V`. Take a complete prefix code `α_1, ..., α_k, β_1, ..., β_m` (`k >= 1`,
`m >= 0`), put `R_β = [β_1] ∪ ... ∪ [β_m]`, fix a complete prefix code `γ_1, ..., γ_m`, and
put `S_β = Σ_l s_(β_l) t_(γ_l)`, `T_β = Σ_l s_(γ_l) t_(β_l)`. For clopen-rigid `H, K <= V`
let

`D = { Σ_i s_(α_i) h t_(α_i) + S_β k T_β : h ∈ H, k ∈ K }`

(with `k` omitted when `m = 0`). Each element acts by `h` on the tails of every `[α_i]`
simultaneously and by a copy of `k` on `R_β`.

## Statement

1. **Commutant.** Every additive map `T : M → M` commuting with all of `D` has the form
   `Σ_(i,j) λ_(ij) s_(α_i) t_(α_j) + μ Σ_l s_(β_l) t_(β_l)` with `λ ∈ M_k(F_2)`,
   `μ ∈ F_2` (`μ = 0` term absent when `m = 0`). If `T` is invertible, `λ ∈ GL_k(F_2)`,
   `μ = 1`, and `T` is the action of a unit of `R`.
2. **Covered groups.** Let `W = <V, x_1, ..., x_r> <= Aut(M)` where each `x_j` commutes
   with some subgroup `C_j <= V` containing a diagonal cone subgroup. Then `W` is contained
   in the image of `U`, and `W` is isomorphic to a finitely generated subgroup of `U`.
3. **Not universal.** Some two-generated group with solvable word problem embeds in no such
   `W`. So `decidable-groups-embed-in-covered-cantor-module-actors` cannot be proved with
   covering subgroups of this kind; a universal construction needs covering subgroups
   containing no diagonal cone subgroup.

The Leavitt instance on main is the case `α = (00, 01)`, `β = (1)`, `H = K = V`, where the
commutant is `M_2(F_2) ⊕ F_2` and `x = 1 + s_(00) t_(01)` is the transvection.

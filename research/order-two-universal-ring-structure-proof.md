## Proof

**Presentations.**  Imposing `2Q = 0` on `J_Z` means quotienting by the
two-sided ideal generated by `2Q`.  Since `Q_(ij) = S^i Q T^j` and these
span `F_Z`, that ideal is `2F_Z`, giving `(OT1)`.

**`(OT2)`.**  By the first prerequisite, `F_Z = M_fin(N,Z)` and
`J_Z / F_Z = D`.  So `F_Z / 2F_Z = M_fin(N,F_2)` is an ideal of
`A_2 = J_Z/2F_Z` with quotient `D`.  The defect `Q` is nonzero in `A_2`
(its class in `F_Z/2F_Z` is the matrix unit `E_00(1)`) and `2Q = 0`.
`A_2` has characteristic zero because `D` does and the composite
`Z -> A_2 -> D` is injective.  `Q` is nonfull because `D` is a nonzero
quotient killing it.

**`(OT3)`.**  An element `a in J_Z` killed by both coordinates lies in
`2J_Z cap F_Z`.  Write `a = 2b`.  Then `0 = sigma(a) = 2 sigma(b)` and
`D` is torsion-free, so `sigma(b) = 0` and `b in F_Z`, giving
`a in 2F_Z`.  Conversely `2F_Z` is killed by both.  So the kernel is
exactly `2F_Z` and the map on `A_2` is injective.

For the image, take a compatible pair in the fibre product: a class in
`J_(F_2)` and an element of `D` agreeing in `F_2[z,z^(-1)]`.  Lift the
first coordinate to `a in J_Z`.  The difference between `sigma(a)` and
the prescribed second coordinate lies in `2D`.  Elements of `2J_Z` have
arbitrary symbols in `2D` and are zero mod two, so adding a suitable one
corrects the symbol without changing the first coordinate.  Hence the map
is onto the fibre product, which is `(OT3)`.

**`(OT4)`.**  Surjectivity of `EL_n(A_2) -> EL_n(D)` holds by lifting
coefficients of elementary generators.  For the kernel, use `(OT3)`: an
element with trivial integral symbol has integral coordinate `I_n`, so
its binary coordinate has trivial symbol in `J_(F_2)` and therefore, by
the first prerequisite, differs from `I_n` by a finite-support matrix
over `F_2`.  This places the kernel inside `L_n`.  Conversely the second
prerequisite realizes every finitary transvection over `F_2` inside
`EL_n(A_2)` already at `n = 2`, using coefficients `Q_(ab)` which are
two-torsion and have zero symbol, and those transvections generate
`L_n`.  So the kernel is exactly `L_n`.

Simplicity and infiniteness of `L_n` are item 1 of the fourth
prerequisite: `L_n` there and here are the same group, the finitary
invertible group of `N x {1,...,n}` over `F_2`, and the statement is
about that group alone, not about the ambient ring.  Residual finiteness
of `EL_n(D)` is the integral half of the third prerequisite.

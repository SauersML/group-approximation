Notation of the target. All cochains are cellular on `Y_X`. `delta : C^1 -> C^2` is the coboundary, and
`<Sigma, v>` is evaluation.

## Step 1 (L1): defect in terms of cochains

The relator unitaries are diagonal, since the `P_s` satisfy every `r` exactly. The entry at `x` is
`e((delta a)(x, r))`. So

```text
eps(rho) = max_(x,r) |e((delta a)(x, r) - theta k_r) - 1|.
```

For `|t| <= 1/2` we have `4|t| <= |e(t) - 1| = 2|sin(pi t)| <= 2 pi |t|`. The map `t -> |e(t) - 1|` is increasing
in `dist(t, Z)`. Hence `eps(rho) = |e(M) - 1|` with `M = max dist(delta a - theta k, Z)`, and `4M <= eps`.

Rephasing `a` by integers changes nothing, and `a` ranges over the compact torus `(R/Z)^E`. So the infimum
`mu_theta` is attained, and it equals

```text
mu_theta(X) = min over alpha in C^1(R), m in C^2(Z) of || theta k - m - delta alpha ||_inf.     (1)
```

Take `alpha = -a` lifted to `R`, and let `m` be the nearest integers.

## Step 2 (L1): passing to cohomology

Since `Y_X` has no 3-cells, every 2-cochain is a cocycle, so `H^2(Y_X; R) = C^2(R) / delta C^1(R)`. For fixed
`m`, the inner minimum in (1) is the quotient norm `||[theta k - m]||_cell`.

Put `theta = 1/q`. Then `[k/q - m] = (1/q)[k - q m]`, and `[k - q m]` runs over the integral classes
`f in kappa + q H^2(Y_X; Z)`, because every integral class is `[m]` for some `m`. The images `f_R` form a coset of
a full lattice in `H^2(Y_X; R)`, which is finite-dimensional, and `||.||_cell` is a norm on it. So the minimum is
attained. This proves the first display of (L1).

## Step 3 (L1): the dual formula

By Hahn-Banach, or finite LP duality, the `l^inf`-distance from `v` to the subspace `W = delta C^1(R)` is
`sup { <Sigma, v> : Sigma in W^perp, |Sigma|_1 <= 1 }`. Here `W^perp = ker(boundary_2) = Z_2(Y_X; R)`.

The set `{Sigma in Z_2(R) : |Sigma|_1 <= 1}` is a polytope cut out by rational linear conditions. So its vertices
are rational, and the supremum is a maximum over rescaled integral cycles. This gives the second display.

For the flat-connection reading, set `beta = 3 alpha`. Then `delta beta = k + 3m + 3e` with `||e||_inf <= mu`.
Conversely, from such a `beta` take `alpha = beta / 3`. The general `q` is the same.

## Step 4 (L2): transfer along covers

The `Gamma`-map `pi` induces a cellular covering `Y_(X') -> Y_X` of constant degree `N`. The fibres are equal
because `X` is transitive. Define the transfer

```text
(tr c)(sigma) = (1/N) sum over lifts sigma' of sigma of c(sigma').
```

`tr` commutes with `delta`. Along the loop reading `r` at `x`, the prefix word `w_j` gives a bijection
`x' -> w_j x'` from the fibre over `x` to the fibre over `w_j x`. So the lifts of the `j`-th edge of the loop
correspond exactly to the lifts `x'` of the base point of the loop.

Also `tr pi^* = id` and `||tr c||_inf <= ||c||_inf`. Therefore

```text
||c|| = ||tr pi^* c|| <= ||pi^* c|| <= ||c||,
```

where the last inequality holds because `pi^*` of a representative is a representative with the same sup.

## Step 5 (L3): the lattice `kappa(Z_2)`

Choose a spanning tree `T` of the 1-skeleton of `Y_X` and a base point `x_0`. Let:
- `F_T` be the free group on the non-tree edges, which is `pi_1` of the 1-skeleton;
- `l_c` be the lasso of the 2-cell `c = (x, r)`.

Reading edge labels gives a map `F_T -> Gamma~` with image in `Lambda~`, and `l_c -> u r u^(-1) = z^(k_r)`.

Let `G' = < F_T, z | z central, l_c = z^(k_c) >`. The natural map `G' -> Lambda~` is onto:
- its image maps onto `Lambda = pi_1(Y_X)`;
- the image contains `z`.

It is also injective. The kernel of `G' -> Lambda` is generated by the image of the central element `z`, so it is
cyclic. Its image is the infinite cyclic kernel of `Lambda~ -> Lambda`, so this cyclic kernel is infinite cyclic
and maps injectively.

Abelianizing gives

```text
H_1(Lambda~) = ( Z_1(graph; Z) (+) Z z ) / < (boundary c, -k_c) : c a 2-cell >.
```

Hence `j z = 0` iff `(0, j) = sum n_c (boundary c, -k_c)`. That holds iff `Sigma = sum n_c c` is a 2-cycle with
`j = -kappa(Sigma)`. So `kappa(Z_2(Y_X; Z)) = D Z` with `D` the order of `z`, where `D = 0` means infinite order.

## Step 6 (L3): `D` lies in `{1, 2}`

For `n >= 3`, `Lambda_n = Lambda~ / <z^n>` has finite index in `Gamma_n`. Hence `Res_fin(Lambda_n) = Res_fin(Gamma_n)`,
which is `<z^2>` by (DR2) of `deligne-covers-of-sp2g-z-have-finite-residual-2z`.

In `H_1(Lambda_n) = H_1(Lambda~) / <n z>`, the element `z` has order `gcd(D, n)`, with `gcd(0, n) = n`. This group
is a finitely generated abelian group, hence residually finite, so some finite quotient of `Lambda_n` gives `z`
order exactly `gcd(D, n)`. That quotient kills `z^2`, so `gcd(D, n) | 2`.
- With `n = 3`: `D != 0` and `3 not | D`.
- If `D >= 3`, then `n = D` gives `D | 2`, which is false.

So `D` lies in `{1, 2}`. At `X = pt` a cycle with `kappa(Sigma) = D != 0` shows `kappa_R != 0`, so `c_K > 0`.

## Step 7 (K1): spherical kill

Choose lifts `g~` in `Gamma~` of the vertices `g` of `Y~ = Cayley complex`. Define the integer 1-cochain
`A(g, s)` on `Y~` by `g~ s = (gs)~ z^(A(g,s))`, which uses that `z` is central. Reading the loop of `r` at `g`
gives `g~ r = g~ z^((delta A)(g, r))`. In `Gamma~`, `r = z^(k_r)`, and `z` has infinite order. So
`delta A = p^* k` on `Y~`.

For `sigma` in `Z_2(Y~)`, this gives `kappa(p_* sigma) = <sigma, delta A> = <boundary sigma, A> = 0`. So `kappa`
vanishes on `S_X`.

As an abelian group, `pi_2(Y) = Z_2(Y~)` is spanned by the `gamma sigma_i`, and `S_X` is spanned by the
`p_*(gamma sigma_i)`, each of mass at most `M_0`. Let `f = kappa + 3 g`. Then `f|S_X = 3 g|S_X`, which lies in
`3Z`. If this is nonzero, it is nonzero on some generator, with value of size at least 3 and mass at most `M_0`.
Step 3 gives `||f_R|| >= 3 / M_0`.

## Step 8 (K2): Kahler-proportional kill

Suppose `f_R = t kappa_R`, and let `Sigma` be an integral cycle with `kappa(Sigma) = D` (Step 5). Then `t D` is
the integer `f(Sigma)`, and `f(Sigma) = D + 3 g(Sigma)`, so `t D ≡ D` mod 3. Since `3 not | D`, `t D != 0`, and
therefore `|t| >= 1 / D >= 1/2`.

On `Y_X`, `kappa = pi^* kappa_Y` for `pi : X -> pt`. By Step 4,
`||f_R|| = |t| ||kappa_R||_Y >= ||kappa_R||_Y / 2 = 3 c_K`.

## Step 9 (K3): block reduction

The relator matrices are block-diagonal with blocks `W_(x,r)` in `U(b)`. Write the eigenvalues of
`W e(-k_r / 3)` as `e(phi_j)` with `|phi_j| <= 1/2`. Then `|phi_j| <= eps / 4`.

Now take `a(x, s) = (1 / 2 pi i) log det` of the `(x, s)` block. This is a monomial `(b/3)`-model whose phase
defect is

```text
dist(sum_j phi_j, Z) <= b eps / 4.
```

For `3 not | b`, `b/3 ≡ +-1/3` mod 1, and `mu_theta = mu_(-theta)` (negate `alpha` and `m`) depends only on
`theta` mod 1. So `mu_(1/3)(X) <= b eps / 4`.

## Step 10: the Corollary

Let `f` attain (L1), so `||f_R|| = 3 mu <= 3 eps / 4`. There are three cases:
- `f` is not zero on `S_X`: then (K1) gives `mu >= 1 / M_0`;
- `f_R` is a real multiple of `kappa_R`: then (K2) gives `mu >= c_K`;
- otherwise `f` is excluded by the hypothesis.

Finally, Step 1 gives `eps >= 4 mu`. Hopf's theorem `H_2(Y_X) / h(pi_2) = H_2(pi_1(Y_X))`, applied with
`h = p_*`, identifies the residual classes.

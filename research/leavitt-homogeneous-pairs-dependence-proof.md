Throughout, `k` is a field, `Σ = {0, …, n-1}` with `n >= 2`, and
`L = L_k(1,n)`. The algebra `L` is generated by `s_c, s_c^*` (`c ∈ Σ`) with
`s_c^* s_e = δ_(c,e)` and `Σ_c s_c s_c^* = 1`. For a word
`α = c_1 … c_m`, write `s_α = s_(c_1) ⋯ s_(c_m)`.

## Step 0. Elementary facts about `L`

The facts below are standard and are proved inline.

- **(F1) Spanning and grading.** `L` is spanned by the elements `s_α s_β^*`. The
  reason is that `s_c^* s_e` reduces to `δ_(c,e)`. The defining relations are
  homogeneous for `deg s_c = 1` and `deg s_c^* = -1`, so `L = ⊕_(d ∈ Z) L_d`, and
  `L_d` is spanned by the `s_α s_β^*` with `|α| - |β| = d`.
- **(F2) Refinement.** `s_α s_β^* = Σ_c s_(αc) s_(βc)^*`. So every element of `L_d`
  with `d >= 0` can be written, for any large enough `r`, as
  `Σ_(|β| = r, |α| = r + d) λ_(α,β) s_α s_β^*`.
- **(F3) Independence at fixed `|β|`.**
  - *Representation.* Let `Ω = Σ^N` be the set of infinite words, and let `L` act
    on `k[Ω]` by `s_c δ_ω = δ_(cω)` and `s_c^* δ_(eω) = δ_(c,e) δ_ω`. These
    operators satisfy the relations.
  - *Evaluation.* Fix `r`, and let `ω` not be eventually periodic. If
    `z = Σ_(|β| = r) λ_(α,β) s_α s_β^*`, then `z δ_(βω) = Σ_α λ_(α,β) δ_(αω)`.
  - *Distinct words.* The words `αω` are pairwise distinct. For `|α| = |α'|` this
    is clear. For `|α| < |α'|`, the equation `αω = α'ω` forces `ω = γω` for a
    nonempty word `γ`, so `ω` is periodic.
  - *Conclusion.* If `z = 0`, then every `λ_(α,β) = 0`. So the `s_α s_β^*` with
    `|β| = r` are linearly independent.
- **(F4) `L_0` is algebraic.** For each `r`, the span `M_r` of the `s_α s_β^*` with
  `|α| = |β| = r` is closed under products, since
  `s_α s_β^* s_γ s_δ^* = δ_(β,γ) s_α s_δ^*` for words of equal length. By (F2)
  every element of `L_0` lies in some `M_r`, which is finite-dimensional. Hence
  every element of `L_0` is algebraic over `k`.
- **(F5) Involution.** `s_c ↦ s_c^*` extends to an anti-automorphism `*` of `L`
  with `deg z^* = -deg z`. It preserves commutation and polynomial relations
  between commuting elements.

## Step 1. Reduction to equal positive degree

Let `x, y` be homogeneous and commute, of degrees `a` and `b`. If `x = 0` or
`y = 0`, then `f = X` or `f = Y` works.

- **`a = 0` (or `b = 0`).** By (F4), `m(x) = 0` for some nonzero `m ∈ k[X]`.
- **`a > 0 > b`.** The element `x^(-b) y^a` has degree `0`, so by (F4) there is a
  nonzero `m` with `m(x^(-b) y^a) = 0`. The monomials `X^(-bj) Y^(aj)` are
  distinct, so `f = m(X^(-b) Y^a)` is nonzero. The case `a < 0 < b` is symmetric.
- **`a, b > 0`.** The elements `x^b` and `y^a` commute and both have degree
  `d = ab`. If `g(x^b, y^a) = 0` with `g ≠ 0`, then `f = g(X^b, Y^a)` is nonzero,
  because `X ↦ X^b`, `Y ↦ Y^a` is injective on `k[X, Y]`.
- **`a, b < 0`.** Apply `*` from (F5) and use the previous case.

So it suffices to treat `deg x = deg y = d >= 1`.

## Step 2. Window matrices

Let `deg x = deg y = d >= 1`. By (F2), choose one `r` for both, and write

`x = Σ_(|u| = r, |w| = r, |c| = d) (A_c)_(w,u) s_(wc) s_u^*`,

`y = Σ_(|u| = r, |w| = r, |c| = d) (B_c)_(w,u) s_(wc) s_u^*`.

Here `c` runs over the alphabet `Σ^d`, and each `A_c, B_c` lies in `End_k(V)`,
where `V = k^(Σ^r)` has dimension `N = n^r`.

**Products.** Multiplying and reading off the first `r` letters gives, for words
`c_1, …, c_m ∈ Σ^d` and `M_i ∈ {A, B}`:

`z_1 ⋯ z_m = Σ (M_1(c_1) ⋯ M_m(c_m))_(w,u) s_(w c_1 ⋯ c_m) s_u^*`.

Here `z_i = x` if `M_i = A` and `z_i = y` if `M_i = B`.

**Commutation.** By (F3), applied with `|β| = r`, the relation `xy = yx` is
equivalent to `A_c B_e = B_c A_e` for all `c, e ∈ Σ^d`. Call this `(C)`.

**Evaluation map.** For a homogeneous `f = Σ_i φ_i X^i Y^(m-i)` and a word
`c_1 ⋯ c_m`, put

`Ψ(f)(c_1 ⋯ c_m) = Σ_i φ_i P_i(c_1 ⋯ c_m)`,

where `P_i` is the product with `i` factors `A` and `m - i` factors `B`, in any
order of types, with the letters kept in place. `(C)` swaps the types at two
adjacent positions while keeping the letters, so `P_i` does not depend on the order.

**Multiplicativity.** `Ψ(gh)(w_1 w_2) = Ψ(g)(w_1) Ψ(h)(w_2)` whenever
`|w_1| = deg g` and `|w_2| = deg h`. This holds for monomials by concatenation,
and then for all `g, h` by bilinearity.

If `Ψ(f) = 0` on all words of length `deg f`, then every coefficient of `f(x, y)`
in the display above vanishes, so `f(x, y) = 0` in `L`.

So Theorem H follows from Step 3, applied to `V` with the operators `A_c, B_c`.

## Step 3. Segre modules have low-degree relations

**Setting.** A *Segre module* is a finite-dimensional `k`-space `V` with operators
`A_c, B_c ∈ End V`, indexed by a finite alphabet `Λ`, that satisfy
`A_c B_e = B_c A_e` for all `c, e ∈ Λ`. The map `Ψ_V` is defined as in Step 2.

**Lemma S.** Every Segre module `V` has a nonzero homogeneous `f` with
`deg f <= dim V` and `Ψ_V(f) = 0` on all words of length `deg f`.

*Proof.* We use induction on `dim V`. If `V = 0`, take `f = 1`. Otherwise let
`K = ∩_c ker A_c` and `I = Σ_c Im A_c`.

**(i) `K` and `I` are submodules.**
- `A_c K = 0 ⊆ K`, and `A_c I ⊆ I`.
- For `v ∈ K`, `A_c B_e v = B_c A_e v = 0`, so `B_e v ∈ K`.
- For `u ∈ V`, `B_e A_c u = A_e B_c u ∈ I`, so `B_e I ⊆ I`.

**(ii) Case `K = V`.** Then all `A_c = 0`. Take `f = X`, of degree `1 <= dim V`.

**(iii) Case of a proper nonzero submodule `W`.** This covers `K` with
`0 ≠ K ≠ V`, and `I` with `0 ≠ I ≠ V`. The case `I = 0` forces `K = V`.
- Restriction to `W` and passage to `V/W` give Segre modules of smaller dimension.
- By induction, choose `f_W` for `W` and `f_Q` for `V/W`.
- `Ψ_V(f_Q)(w)` maps `V` into `W` for every word `w`, and `Ψ_V(f_W)(w')` vanishes
  on `W`.
- By multiplicativity, `Ψ_V(f_W f_Q)(w' w) = Ψ_V(f_W)(w') Ψ_V(f_Q)(w) = 0`.
- `f = f_W f_Q` is nonzero, because `k[X, Y]` is a domain, and
  `deg f <= dim W + dim V/W = dim V`.

**(iv) Case `K = 0` and `I = V`.** Let `Â : V -> V^Λ`, `v ↦ (A_c v)_c`, which is
injective. Let `A^row : V^Λ -> V`, `(v_e)_e ↦ Σ_e A_e v_e`, which is surjective.
Define `B̂` and `B^row` in the same way.
- *Block identity.* The `(c, e)` block of `Â B^row` is `A_c B_e`, and that of
  `B̂ A^row` is `B_c A_e`. So `(C)` says `Â B^row = B̂ A^row`.
- *Right factor.* Choose `R` with `A^row R = 1_V`, and put `G = B^row R`. Then
  `B̂ = B̂ A^row R = Â B^row R = Â G`, that is, `B_c = A_c G` for all `c`.
- *Left factor.* Now `Â B^row = B̂ A^row = Â G A^row`. Since `Â` is injective,
  `B^row = G A^row`, that is, `B_e = G A_e` for all `e`.
- *Consequence.* `B_c = A_c G = G A_c`. So `G` commutes with every `A_c`, and
  `P_i(c_1 ⋯ c_m) = A_(c_1) ⋯ A_(c_m) G^(m-i)`.
- *The relation.* Let `μ(t) = Σ_(j <= e) μ_j t^j` be the minimal polynomial of `G`,
  with `1 <= e <= dim V`. Put `f = Σ_j μ_j X^(e-j) Y^j`, which is nonzero. Then
  `Ψ_V(f)(w) = A_w μ(G) = 0` for every word `w` of length `e`. ∎

`G` is defined over `k` because `R` can be chosen over `k`. No extension of
scalars is needed.

**Theorem H (sharp form).** Apply Lemma S to `V = k^(Σ^r)` from Step 2. It gives
a homogeneous `f` of degree `<= n^r` with `f(x, y) = 0`. Together with Step 1,
this proves Theorem H.

## Step 4. Corollaries

1. **No homogeneous polynomial ring.** This is Theorem H. For an automorphism
   `θ`, apply Theorem H to `θ^(-1)(x)` and `θ^(-1)(y)`.
2. **Leading forms.**
   - *Setup.* For `0 ≠ z ∈ L`, let `top(z)` be its component of highest degree. For
     a commutative subalgebra `A ⊆ L`, let `T_d` be the set of `top(a)` with
     `deg a = d`, together with `0`.
   - *Subspaces.* Each `T_d` is a subspace. If `deg a = deg b = d`, then
     `top(a) + top(b)` is either `top(a + b)` or `0`.
   - *Products.* `top(a) top(b)` is the degree-`(deg a + deg b)` component of `ab`.
     So it is `top(ab)` or `0`, and it equals `top(b) top(a)` because `ab = ba`.
   - *Conclusion.* `gr(A) = ⊕_d T_d` is a graded commutative subalgebra.
   - *Krull dimension.* Let `B` be a finitely generated subalgebra of `gr(A)`.
     Then `B` is generated by finitely many homogeneous `h_i`, and by Theorem H
     any two of them satisfy a nonzero relation. The same relation holds in `B/P`
     for each minimal prime `P`. A transcendence basis of `Frac(B/P)` can be
     chosen among the images of the `h_i`, so it has at most one element. Hence
     `dim B <= 1`.
3. **Graded case of Q5.7.**
   - *Independence in `L ⊗ L`.* `k[a] ⊗ k[b] ≅ k[X, Y]` embeds in `L ⊗ L`, since
     tensor products of injective maps over a field are injective. So `a ⊗ 1` and
     `1 ⊗ b` are commuting and algebraically independent.
   - *Conclusion.* An injective `φ` preserves both properties. By Theorem H,
     `φ(a ⊗ 1)` and `φ(1 ⊗ b)` cannot both be homogeneous.

Let `Y = X union {1}`, let `t` be the finite set of matrices `e_ij(y)` with
`i != j` and `y in Y`, and let `H = <t>`.  Every generator of `H` is an
elementary matrix, so `H <= EL_n(A)`; the content is the reverse inclusion.

Put

```text
C = { a in A : e_ij(a) in H for all i != j }.
```

* `0 in C`, since `e_ij(0) = 1`.
* `1 in C` by construction of `t`.
* `C` is closed under addition: within a single root subgroup
  `e_ij(a)e_ij(b) = e_ij(a+b)`, and `e_ij(-a) = e_ij(a)^{-1}`, so `C` is an
  additive subgroup.
* `C` is closed under multiplication: given `a, b in C` and `i != j`, use
  `n >= 3` to choose `k` distinct from both.  Then `e_ik(a)` and `e_kj(b)`
  lie in `H`, and the Steinberg commutator relation
  `[e_ik(a), e_kj(b)] = e_ij(ab)` exhibits `e_ij(ab)` as a product of four
  elements of `H`.  Since `i != j` was arbitrary, `ab in C`.

So `C` is a subring of `A` containing `Y`, hence containing the subring
generated by `X`, which is `A`.  Therefore `e_ij(a) in H` for every `a in A`
and every `i != j`.  Those matrices generate `EL_n(A)` by definition, so
`EL_n(A) <= H` and `(EFG1)` holds.

No root permutation, no Gaussian elimination and no rigidity input is used;
the only structural hypothesis is `n >= 3`, which is what makes a third index
available for `(EFG3)`.  At `n = 2` the argument fails and the statement is
not claimed.

The same argument with `k`-algebra generators plus every scalar of a finite
coefficient field `k` in the generating set gives the finite-field form; both
are the machine-checked `elementaryGroup_finitelyGenerated` and
`elementaryGroup_finitelyGenerated_finiteField`.

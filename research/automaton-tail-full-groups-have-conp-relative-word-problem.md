## Setting

Let `X_1, …, X_n` be finite alphabets with `|X_i| >= 2`, and `Ω = ∏_i X_i^N`. For
each `i` let `H_i <= Aut(X_i^*)` be generated by a finite symmetric set `S_i` that
is **closed under sections** (`s|_x ∈ S_i ∪ {1}` for `s ∈ S_i`, `x ∈ X_i`). So `H_i`
is an automaton group with state set `S_i`, and every finitely generated
finite-state (rational) self-similar group has such an `S_i`.

`FV(H_1, …, H_n)` is the set of homeomorphisms `f` of `Ω` that have a **table**: a
partition of `Ω` into finitely many rectangles `∏_i [u_{j,i}]`, with words
`u'_{j,i} ∈ X_i^*` and `h_{j,i} ∈ H_i`, such that

```text
f( (u_{j,i} x_i)_i ) = ( u'_{j,i} h_{j,i}(x_i) )_i        for all x_i ∈ X_i^N.     (T)
```

It is a group. It contains:
- **Brin–Thompson** `nV`, with all `H_i` trivial;
- the **Rover–Nekrashevych group** `V_d(G)` of an automaton group `G`, with `n = 1`;
- the **product 2-graph hosts** `2V_τ` of `odometer-2v-is-fp-simple-and-contains-bs12`
  (`H_1 = <τ>`, `H_2 = 1`) and `2V_H` of `affine-2v-hosts-reach-z-1-2n-by-doubling-but-not-q`
  (`H_1 = H`, `H_2 = 1`), whose defining piecewise forms are exactly (T).

## Statement

Let `Γ <= FV(H_1, …, H_n)` be finitely generated.

1. **Relative coNP.** The word problem of `Γ`, over any finite generating set, is in
   `coNP` relative to an oracle for the word problems `WP(H_i, S_i)`. Explicitly, a
   nondeterministic polynomial-time machine with that oracle accepts exactly the
   nontrivial words.
2. **Absolute bounds.**
   - If every `WP(H_i, S_i)` is in `P`, then `WP(Γ) ∈ coNP`.
   - In all cases `WP(Γ) ∈ PSPACE`, because automaton groups have word problem in
     `PSPACE` (proved in the route).
3. **The new hosts are coNP-complete.** `2V_τ` and every `2V_{G_N}` (`N` odd) have
   coNP-complete word problem. The upper bound is item 2, since `Z` and
   `G_N = Z[1/N] ⋊ <p : p | N>` are automaton groups (route) with polynomial-time
   word problem. The lower bound: both contain Brin's `2V`, whose word problem is
   coNP-complete (Birget, arXiv:1902.03852, quoted in
   `fp-simple-groups-with-arbitrarily-complex-word-problem`).
4. **Zaremsky's hosts.** For a rational self-similar `G`, the groups `V_d(G)` and
   `[V_d(G), V_d(G)]` have word problem in `coNP^{WP(G)}`. In particular Zaremsky's
   finitely presented simple groups with at least exponential Dehn function
   (`fp-simple-group-with-at-least-exponential-dehn-function`, built on a rational
   representation of `BS(1,n)`) have word problem in `coNP`. The same holds for every
   host from Zaremsky's corollary `cor:simple_and_qr` with a linear coefficient group.

## Consequences for the complexity root

- **Hardness must come from the coefficient groups.** Each `H_i` embeds in the
  corresponding host, so `WP(H_i) <= WP(Γ)` up to length-linear substitution, and
  item 1 bounds the host by `coNP^{WP(H_i)}`. So a host of this shape is beyond
  coNP only if some `H_i` has word problem outside `P`. Neither the Brin–Thompson
  rearrangements nor a free colour nor Rover–Nekrashevych completion adds hardness
  beyond `coNP`.
- **Ceiling.** Every such host over automaton groups has word problem in `PSPACE`.
  So `fp-simple-groups-with-arbitrarily-complex-word-problem` cannot be reached
  inside `FV` over finite-state coefficient groups. It needs infinite-state
  coefficient groups, as the necessary condition "infinitely many states" of
  `fp-self-similar-groups-with-arbitrarily-hard-word-problem` already says. This
  sharpens the exponential wall `rational-homeomorphism-subgroups-have-exponential-wp`
  for this subclass.
- **What would beat Birget's coNP.** A *finitely presented* automaton group `G` whose
  word problem is `NP`-hard or `PSPACE`-hard. By Zaremsky's Theorem 1.1
  (`fp-self-similar-groups-embed-in-fp-simple-groups`), `G` lies in a finitely
  presented simple group whose word problem is at least as hard. Wächter--Weiß
  construct an automaton group with PSPACE-complete word problem (STACS 2020; cited,
  not read here). It is not known to be finitely presented, and finite presentation
  is the whole gap.

Notation as in the target.

**Step 0 (units of D(Z)).** By Step 4 of
`promislow-definite-line-shadow-parseval-proof`, `D(Z)^x = {+-t^m, +-t^m u}`.
Call `+-t^m` *rotations* and `+-t^m u` *reflections*. Rotations commute with
each other. Conjugation by a reflection inverts `t^m`. Every reflection squares
to `-1`, which is central. A unital ring homomorphism `phi: Z[P] -> D(Z)` is the
linear extension of a group homomorphism `P -> D(Z)^x`, and conversely.

**Step 1 (the endomorphisms).** `D(Z)` is generated by `t^(+-1)` and `u`,
subject to `t t^-1 = 1`, `u^2 = -1` and `u t = t^-1 u`. For
`T = eps_1 t^(m_1)` and `U = eps_2 t^(k_2) u`:
- `U^2 = -1`;
- `U T U^-1 = eps_1 t^(k_2) u t^(m_1) u^-1 t^(-k_2) = eps_1 t^(-m_1) = T^-1`.

So `t -> T`, `u -> U` extends to a ring endomorphism `e`. When `m_1 = 0` it is
not injective.

**Step 2 (the four families).** Let `alpha = phi(a)` and `beta = phi(b)`, and
check `r_1 = b^-1 a^2 b a^2` and `r_2 = a^-1 b^2 a b^2`.

- **Both rotations,** `alpha = eps t^m`, `beta = eps' t^k`. They commute, so
  `r_1 -> t^(4m)` and `r_2 -> t^(4k)`. Hence `m = k = 0` and
  `alpha, beta in {+-1}`: a sign character.
- **`alpha = eps t^m` a rotation, `beta = eps' t^k u` a reflection.**
  - `r_1 -> beta^-1 t^(2m) beta t^(2m) = t^(-2m) t^(2m) = 1`.
  - `r_2 -> alpha^-1 (-1) alpha (-1) = 1`.
  - Every such pair defines a homomorphism, and it equals `e o A` with
    `e(t) = eps t^m` and `e(u) = eps' t^k u`, since `A(a) = t` and `A(b) = u`.
- **`alpha` a reflection, `beta` a rotation.** Symmetrically, this is `e o B`,
  with `B(a) = u` and `B(b) = t`.
- **Both reflections,** `alpha = eps t^m u`, `beta = eps' t^k u`.
  - `alpha^2 = beta^2 = -1` is central, so both relators go to `(-1)(-1) = 1`.
  - Since `C(a) = u` and `C(b) = -t^-1 u`, `e o C` sends `a -> e(u)` and
    `b -> -e(t)^-1 e(u)`.
  - Take `e(u) = eps t^m u` and `e(t) = -eps eps' t^(m - k)`. Then
    `-e(t)^-1 e(u) = eps eps' t^(k - m) eps t^m u = eps' t^k u = beta`.
  - So the pair is `e o C`.

This is item 1.

**Step 3 (item 2).**
- **`=>`.** Let `v = epsilon + w` with `w in I_A cap I_B cap I_C`.
  - For `phi = e o S`: `S(w) = 0`, so `phi(v) = e(epsilon) = epsilon`.
  - For a sign character: `phi` lands in `Z`, and `phi(v)` is a unit of `Z`,
    so `+-1`.
- **`<=`.** The three shadows send `v` to signs `epsilon_A, epsilon_B,
  epsilon_C`, so `v - epsilon_S in I_S`.
  - Then `epsilon_C - epsilon_A` lies in `I_A + I_C`, inside the ideal `K`
    generated by `x+1, y+1, z+1`.
  - Item 3 of the Parseval route shows `2` is not in `K`; that step does not use
    `v = 1 mod 2`. So `epsilon_C = epsilon_A`.
  - In the same way `epsilon_B = epsilon_C`.
  - So `v - epsilon` lies in all three kernels.

**Step 4 (item 3).** This is item 4 of
`promislow-nonzero-twisted-classes-have-no-definite-shadows`. It is a separate
claim, not required here.

**Checks.** `class_shadow_check.py` enumerates all pairs `(alpha, beta)` of
monomial units with `|m| <= 3` (784 pairs). It finds:
- 4 sign characters;
- 196 solutions in each of the other three families;
- every solution in those families matched by an endomorphism of the matching
  shadow, found by search.

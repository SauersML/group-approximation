```text
U=401004080301c030
```

and both marked `GL4(2)` charts to `GL8(2)` exactly as in
`atlas-multiplicity-two-packet-collision-hub-escape`.  Direct evaluation of
the literal six stored relators gives

```text
row       value                     order   rank(value-I)

s_30      8740291008040201            2           2

```

Stacking the five residual maps in the displayed order gives cumulative
binary ranks

```text
2,4,6,6,7.                                             (M2S2)
```

Hence their common fixed space in the natural eight-dimensional module is
only one-dimensional.  This is a frame-specific collective charging fact,
not a uniform regular-multiplicity boundary inequality.

Thus the interior row remains exact, but every one of the five saturated
boundary rows fails, and each failure is a nonidentity involution.  Passing
to the regular representation of the finite group generated by the chart
and `U` makes both chart restrictions exact multiples of `Reg(A8)`.  Every
failed row then has normalized Hilbert--Schmidt defect `sqrt(2)`.

Consequently the known common-`U`, exact-regular packet-and-collision escape
does not refute a six-row typed localization inequality.  More sharply, no
proper subset obtained by merely deleting some of the other saturated rows
makes this particular frame a survivor: each individual boundary row already
rejects it.  A new countermodel must solve actual saturated word equations,
not only the H6/H18 context tables.

The replay is dependency-free exact GF(2) arithmetic.  It parses the committed
six-relator JSON, tensors every `4 by 4` binary chart matrix with `I_2`,
conjugates factor two by the stored frame, and checks the displayed values,
orders, and ranks.

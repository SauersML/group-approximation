Written proof. For a subgroup `S <= G` and a fixed free p.m.p. action of `G` on
`(X,mu)`, write `R_S` for the orbit relation of `S`, and `C(R_S)` for its cost.

**Lemma (commensurated step).** Let `K <= G`, and let `g_1, g_2, ...` be
countably many elements with `K ∩ g_j^(-1) K g_j` infinite for every `j`. Then
`C(R_<K, g_1, g_2, ...>) <= C(R_K)`.

*Proof.* Fix `epsilon > 0`, and put `L_j = K ∩ g_j^(-1) K g_j`.
* `L_j` is infinite and acts freely, so `R_(L_j)` is aperiodic. The marker lemma
  (Kechris--Miller, *Topics in orbit equivalence*, Lemma 6.7) gives a Borel
  complete section `B_j` for `R_(L_j)` with `mu(B_j) < epsilon 2^(-j)`.
* Take a graphing `Phi` of `R_K` with cost below `C(R_K) + epsilon`, and add the
  partial maps `g_j|_(B_j)`.
* For `x in X`, choose `l in L_j` with `l x in B_j`. Then
  `g_j x = (g_j l^(-1) g_j^(-1)) g_j (l x)`. Here `l in K`, `g_j (l x)` is an edge
  of `g_j|_(B_j)`, and `g_j l^(-1) g_j^(-1) in K` because `l in g_j^(-1) K g_j`.
* So `x` and `g_j x` are joined in the relation generated by
  `Phi ∪ {g_j|_(B_j)}`, which is therefore all of `R_<K, g_1, g_2, ...>`.

The cost of this graphing is below `C(R_K) + 2 epsilon`. QED

**Chain.** Use the Steinberg relation: `e_ij(a)` and `e_kl(b)` commute whenever
`j != k` and `i != l`. If `g` commutes with an infinite subgroup `M <= K`, then
`M <= K ∩ g^(-1) K g`, so the lemma applies.
* `K_0 = E_12(R)`, isomorphic to `(R,+)`, so infinite and abelian.
* `K_1` adds every `E_ij(R)` with `j != 1` and `i != 2`, which commute with
  `K_0`. It also adds `H`, which normalizes `K_0` because
  `h e_12(a) h^(-1) = e_12(h.a)`.
* `K_2` adds `E_i1(R)` for `i >= 3`, which commutes with `E_i2(R) <= K_1`, and
  `E_2j(R)` for `j >= 3`, which commutes with `E_1j(R) <= K_1`.
* `K_3` adds `E_21(R)`, which commutes with `E_23(R) <= K_2`.

Every step adds countably many elements, because `R` and `H` are countable.
`K_3` contains every elementary root subgroup and `H`, so `K_3 = G`. Three
applications of the lemma give `C(R_G) <= C(R_(K_0))`.

`K_0` is infinite amenable and acts freely, so `R_(K_0)` is aperiodic and
hyperfinite (Ornstein--Weiss) and has cost one (Levitt). Every aperiodic
relation has cost at least one. Hence `C(R_G) = 1` for every essentially free
p.m.p. action of `G`.

formal verification.

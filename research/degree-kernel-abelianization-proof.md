**Structure of `N_m`.**  `G * <t>` is the fundamental group of a graph of
groups with one vertex, vertex group `G`, and one loop with trivial edge
group.  The index-`m` subgroup `N_m` corresponds to the `m`-fold cyclic
cover: `m` vertices carrying `t^i G t^{-i}` for `0 <= i < m` — these are the
cosets `1, t, ..., t^{m-1}`, and `G <= N_m` — and `m` edges forming a single
cycle.  A cycle on `m` vertices has first Betti number `1`, so

    N_m  =  ( *_{i=0}^{m-1} t^i G t^{-i} )  *  F_1 ,

and the free generator, read off a spanning tree of the cycle, is `t^m`.
(Equivalently: Reidemeister--Schreier with transversal `1, t, ..., t^{m-1}`;
the Schreier generators from `G` give the `m` conjugates, those from `t` are
trivial except at the closing transition, which gives `t^m`.)

**Abelianization.**  `N_m^ab = (+)_{i<m} G^ab (+) Z`.  If `G` is perfect the
first summands vanish, leaving `Z` generated by `[t^m]`.  The homomorphism
`N_m -> Z`, `x |-> deg_t(x)/m`, sends `t^i g t^{-i} |-> 0` and `t^m |-> 1`,
so it induces this isomorphism.

**Action and generators.**  Conjugation preserves `deg_t`, so the residual
`C_m`-action on `N_m^ab = Z` is trivial.  Any `w in N_m` with `deg_t(w) = m`
maps to `1`, hence generates.

**The necessary condition.**  If `N_m = <<w>>_{G*<t>}` then `N_m` is
generated by the `G * <t>`-conjugates of `w`; in `N_m^ab` conjugation by
`N_m` is trivial, so the classes of those conjugates span the
`Z[C_m]`-submodule generated by `[w]`.  Hence `[w]` generates `N_m^ab` over
`Z[C_m]` — which the computation above shows is automatic.

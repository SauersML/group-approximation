Write `p = s_0 t_0`, so `1 - p = s_1 t_1`. Let `C = {a ∈ R_Q : ap = pa}`, a unital
subring.

**Compressions are ring maps on C.** Put `φ(a) = t_1 a s_1` and `ψ(a) = t_0 a s_0`.
- For `a, b ∈ C`,
  `φ(ab) = t_1 a (s_0 t_0 + s_1 t_1) b s_1 = t_1 a s_0 t_0 b s_1 + φ(a)φ(b)`.
- The first term vanishes: `a s_0 = a p s_0 = p a s_0`, and `t_1 p = (t_1 s_0) t_0 = 0`.
- Also `φ(1) = 1`. So `φ: C -> R_Q` is a unital ring map, and so is `ψ` by the same
  computation with `0` and `1` swapped.

`φ(C)` need not lie in `C`. Only `φ` and `ψ` on `C` are used.

**h, g ∈ C.**
- `h ∈ C` by (D).
- `g` commutes with `h` by (I): `g + gh = 1 = g + hg`.
- An inverse of an element of `C` lies in `C`: `x^(-1) p = x^(-1) p x x^(-1) = p x^(-1)`.
- `g = (1+h)^(-1)`, so `g ∈ C`. (D) also records this directly.

**Claim: for every k >= 1, 1 + kh is a unit, with inverse in C.** By induction.
- **Base.** `k = 1` is (I).
- **Step.** If `u = (1 + kh)^(-1) ∈ C`, then `φ(u)` inverts `φ(1 + kh) = 1 + k·hg` by
  (E1).
- Since `g` and `h` commute and `hg(1+h) = h`,
  `(1 + khg)(1 + h) = 1 + h + kh = 1 + (k+1)h`.
- So `1 + (k+1)h` is a product of two units. It lies in `C`, so its inverse does.

**Part 1.** By (E0), `ψ(1 + kh) = 1 + kψ(h) = 1 + k`. So `ψ((1 + kh)^(-1))` inverts
the integer `1 + k` for every `k >= 1`, and `-1` is a unit. Hence every nonzero
integer is invertible, and `a/b ↦ a b^(-1)` is a unital ring map `Q -> R_Q`. Its
kernel is an ideal of a field, so it is `0` once `R_Q ≠ 0`, which follows from part 3.
Integers are central, so their inverses are central.

**Part 2.** (L) makes `(s_0 s_1): R_Q^2 -> R_Q` an isomorphism of right modules, with
inverse `(t_0, t_1)^T`. Hence `R_Q^n ≅ R_Q` for all `n >= 1`, and
`M_n(R_Q) ≅ End(R_Q^n) ≅ R_Q`. Explicitly the isomorphism is
`M ↦ Σ s_(c_i) M_ij t_(c_j)` for a complete prefix code `(c_i)` of size `n`.

**Part 3.** The relations hold in `C_h`, checked pointwise on `Q^X`:
- (L) is the Leavitt family;
- (D) holds because multiplication operators commute with `s_0 t_0 = m_(1_[0])`;
- (I) holds because `ζ(1 + η) = 1`;
- (E0) holds because `η(0z) = 1`;
- (E1) holds because `η(1z) = 1/(2 + k(z)) = η(z)ζ(z)`, including `z = 1^∞`.

The map is onto because `C_h` is generated by the six images. `C_h ≠ 0`.

**Part 4.**
- **Involution.** The involution of the free *-ring maps each relator to a relator
  or to one in the ideal. The image of (E1) is `t_1 h s_1 = gh`, and `gh = hg`
  follows from (I). So the involution descends.
- **The O_2 relations.** On `L^2(X)` with the Bernoulli measure,
  `(S_i u)(w) = √2 [w_1 = i] u(σw)` are the Cuntz isometries, and
  `S_i^* M_f S_i = M_(f(i·))`. So the same pointwise checks hold. `η, ζ` are
  continuous, so `M_η, M_ζ` lie in the diagonal `C(X) ⊂ O_2`.
- **Density.** The image contains `S_0, S_1`, which generate `O_2`.

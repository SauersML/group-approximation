**ESTABLISHED NATIVE-CELL COUNTERMODEL.**  Use distinct Steinberg indices
`0,1,5,6`.  For `q_i=s_it_i` and active idempotent `A`, name the actual root
occurrences

```text
C_i=x_15(q_i),                 J=x_15(A),
S=x_56(s_0),                   R=x_16(s_0),
T=x_01(t_0),                   Z=x_06(A),
L=x_61(t_0).                                             (NOA1)
```

The Leavitt coefficient rows give the literal fold-compose-return table

```text
C_0C_1=J,
[C_0,S]=R,        [C_1,S]=1,        [J,S]=R,
[T,R]=Z,          [T,S]=1.                              (NOA2)
```

Now put the **intermediate arm itself** into its opposite root and form the
prescribed partial Whitehead

```text
P=RLR.                                                   (NOA3)
```

Since `t_0s_0=A`, direct two-by-two block multiplication gives

```text
RLR=LRL,            P^2=1,
PRP^(-1)=L,         PLP^(-1)=R.                         (NOA4)
```

Finally use fixed spare-index Weyl words `U,Q,V` which send the ordered root
positions

```text
(5,6) -> (1,6),       (6,1) -> (0,1),
(1,5) -> (0,6),                                      (NOA5)
```

respectively.  Thus occurrence authentication asks for

```text
USU^(-1)=R,            QLQ^(-1)=T,       VJV^(-1)=Z.    (NOA6)
```

One may choose the first two index permutations involutory and the last of
order four, so also retain `U^2=Q^2=V^4=1`.  Equations `(NOA1)--(NOA6)` are
the smallest native arm-inside-opposite-root refinement of the two-step
cell: no coefficient arm is represented only by an abstract label actor.

This entire table still has an exact finite marked model.  In `S_6` put

```text
S=Z=(3 4)(5 6),             C_0=(1 2)(4 5),
C_1=R=(3 6)(4 5),           J=(1 2)(3 6),
T=(1 2)(5 6),               L=(2 3)(4 5),
U=(4 6),                    Q=(1 3)(4 6),
V=(1 3 6 5)(2 4),           P=RLR.                     (NOA7)
```

All rows are exact and `Z!=1`.  Therefore even a literal opposite-root
partial Whitehead containing the propagated `s_0` arm, with its `t_0` arm
and final `A` output tied to their actual other root occurrences, does not
imply `(BAC1)`.  The finite escape overlaps several Klein-four and `S_3`
subpackets in one permutation group; it is neither the four-bit affine
model nor a finite coefficient-ring representation.

The next native relation must make an opposite-root word read **both binary
branches simultaneously on one shared payload corner**, rather than
authenticating one branch all the way through the fold.  This claim is a
scoped exact model of the displayed native cell, not a model of the full
signed Leavitt presentation.

No Property `(T)`, Kazhdan input, stability theorem, trace hypothesis, or
literature result is used.

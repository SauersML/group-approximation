Let

```text
B=I+E_12,                 A=C B,
S=<A,B>=SL_3(Z).
```

Restrict the Kun--Thom action on `Y=G/Gamma x {0,1}` to `S`.  Then

```text
Sigma_S=Sym_fin(Y) rtimes S
```

is LEF, hence sofic and hyperlinear.  Equivalently,

```text
R rtimes_(alpha|S) S
```

is Connes embeddable.  By
`finitary-extension-ce-iff-action-lifts-to-normalizer`, there is a
trace-correct homomorphism

```text
u:S->N_(R^omega)(R),          Ad(u_s)|R=alpha_s.         (SPL1)
```

Thus the pullback of

```text
1 -> U(R' cap R^omega) -> N_(R^omega)(R) -> Aut(R) -> 1
```

splits on the full two-compressor subgroup.  In the `q=2` specialization
the restricted action is outer, so the trace clause is automatic.

Consequently no cocycle involving only `A,B` and their actor relations can
obstruct the full lift.  The first possible obstruction necessarily uses a
mixed transported `Gamma`-stabilizer relation.  This is the normalizer-factor
counterpart of the established binary-lamp firewall, now with the entire
finitary symmetric base rather than one abelian lamp orbit.

**OPEN (RG).** Let `G = Cay(Gamma,S)` for a finitely generated nonamenable
group `Gamma`. For every infinite amenable subgroup `H <= Gamma`,

```text
p_c(G) < p_c(H;G),
```

where `p_c(H;G)` is Hutchcroft–Pan's relative threshold for a cluster meeting
`H` in infinitely many vertices. Equivalently, by
`fpbs-relative-gap-along-any-subgroup-separates`, for each such `H` there is
`p > p_c(G)` with `E_p|K_o ∩ H| < infinity`.

**Place in the graph.**

- **Necessary for [cap_fin], and for the chain above it.** By
  `fpbs-meet-threshold-capped-by-amenable-relative-threshold` item 3, the
  following all imply RG: `fpbs-replica-meet-threshold-gap-universal` ([cap_fin]),
  [Q_fin], [Q], `p_c < p_2` and `p_c < p_(2->2)`.
- **Sufficient for BS on groups with an infinite amenable subgroup.** This is
  `fpbs-relative-gap-along-any-subgroup-separates`.
- **Contains a known hole.** Restricted to amenable wq-normal `H`, RG is
  `fpbs-amenable-wq-normal-relative-subcriticality`.
- **Coset form.** For `H` generated by `S ∩ H`, RG gives the strict
  enhancement `p_c(G) < p_c(Cay(H,S∩H))`, since `p_c(H;G) <= p_c(Cay(H,S∩H))`.

**Known cases.** RG holds on `Z^3 * Z/2` for `H = Z^3`:
`p_c(G) < p_c(Z^3) = p_c(Z^3;G)`, by
`fpbs-meet-thresholds-tend-to-pc-z3-below-pu-on-z3-free-z2` item 5. The
mechanism is special to free products (bridges between cosets). It is
Section 3 of the artifact.

**No known counterexample.** An amenable subgroup of a nonamenable group is
never co-amenable. So `fpbs-co-amenable-subgroup-relative-threshold-is-pc`
does not produce `p_c(H;G) = p_c(G)`.

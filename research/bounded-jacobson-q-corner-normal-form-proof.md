## 1. The defect ideal is the finitary matrix algebra

Work over an arbitrary field `k) and write

```text
J=k<S,T | TS=1>,                         Q=1-ST.          (BJC7)
```

Direct calculation gives

```text
Q^2=Q,                       QS=0,              TQ=0.    (BJC8)
```

For `i,j>=0), put `E_(ij)=S^iQT^j).  If `j=k), then

```text
E_(ij)E_(kl)=S^iQ(T^jS^j)QT^l=E_(il).
```

If `j<k), reduction by `TS=1` leaves a positive power of `S)
immediately to the right of `Q), so `(BJC8)` makes the product zero.
If `j>k), it leaves a positive power of `T` immediately to the left
of the second `Q), and the product is again zero.  Therefore

```text
E_(ij)E_(kl)=delta_(jk)E_(il).                          (BJC9)
```

The ideal `JQJ` is the algebra of finitary matrices with these matrix
units.

Every word in `S,T` reduces to one monomial `S^iT^j).  Hence

```text
Q S^iT^j Q =
  Q       if i=j=0,
  0       otherwise.                                   (BJC10)
```

Indeed, `i>0` is killed by `QS=0), and after `i=0), any
`j>0` is killed by `TQ=0).  By linearity,

```text
QJQ=kQ.                                                 (BJC11)
```

## 2. Commuting occurrence coefficients factor out of every return

Let `A` be any unital algebra and form the algebraic tensor product
`J tensor A).  Put `q=Q tensor 1).  Equation `(BJC11)` gives

```text
q(J tensor A)q=q tensor A.                              (BJC12)
```

More explicitly, consider a monomial return

```text
q a_0 X_1 a_1 X_2 ... X_n a_n q,                       (BJC13)
```

where each `X_i` is `S` or `T) and each `a_i` lies in
`A).  Since the tensor factors commute, move the `a_i) through the
raw letters without changing their mutual order.  The result is

```text
(Q X_1...X_n Q) tensor (a_0a_1...a_n).                  (BJC14)
```

Equation `(BJC10)` makes the first factor either `Q` or zero.
Finite linear combinations prove the unique normal form

```text
q w q=q tensor b_w,                         b_w in A.    (BJC15)
```

In particular,

```text
q(T tensor 1)(1 tensor B)(S tensor 1)q=q tensor B,       (BJC16)
```

because `TS=1).  The positive and negative raw letters have returned,
but they have done nothing to the occurrence coefficient.  The opposite
safe orientations vanish because `QS=TQ=0).

Take `A` to contain the literal full-`C` Lin coefficient

```text
B=e_b c_y^*e_r c_xe_a.                                  (BJC17)
```

Then every commuting bounded defect-to-defect raw return is either zero
or another coefficient in the algebra generated by such `B)'s.  The
outer atoms still give the same full-`C` covariance; the raw letters
supply no additional occurrence authentication.

## 3. A fixed path is only a finite matrix amplification

A path which enters the defect ideal at `Q), takes at most `L) raw
steps away from its initial height, and later returns uses only

```text
E_(ij),                         0<=i,j<=L.               (BJC18)
```

By `(BJC9)`, their span is `M_(L+1)(k)).  After inserting arbitrary
coefficients from `A), the entire active path algebra is contained in

```text
M_(L+1)(A).                                              (BJC19)
```

This is true for every fixed word, even though the full defect ideal is
an increasing union of matrix algebras.  A bounded word never sees the
infinite union uniformly.  If `A` has a finite-dimensional model, so
does `(BJC19)`; for arbitrary `A), equation `(BJC19)` is precisely
a Morita amplification and retains all of its multiplicity.

## 4. The cross-Gram invariant is transported, not compiled

Let the representation carry a product trace and assume `q) is an
orthogonal projection.  For every `B` in the tracial occurrence
algebra,

```text
(q tensor B)^*(q tensor B)=q tensor B^*B.                (BJC20)
```

Functional calculus gives

```text
|q tensor B|=q tensor |B|,
supp|q tensor B|=q tensor supp|B|.                       (BJC21)
```

Consequently

```text
||q tensor B||_2^2=tau(q)||B||_2^2,                     (BJC22)
```

and every positive singular lower bound for `B` is unchanged on the
tensor support.  For the qutrit head `tau(q)=1/18).  Thus the Lin loss
from the three-corner theorem remains visible, but only as the same
cross-Gram inside a smaller matrix corner.  The raw return creates no
second invariant with which to contradict it.

This also proves that a commuting raw unitary multiplier is removable:
left or right multiplication changes neither `B^*B` nor its nonzero
singular values.  The matrix-unit package records a path label, not a
new source-target rank constraint.

## 5. The exact non-Morita escape condition

The tensor normal form fails only if a raw letter acts on the occurrence
algebra.  A typical covariance would be

```text
S a=alpha(a)S.                                           (BJC23)
```

If `alpha=Ad(u)` is inner, set `S'=u^*S`.  Then

```text
S'a=aS',                                                 (BJC24)
```

so the construction returns to the tensor case after a gauge change.
Finite-packet and common-intertwiner actions are of this removable type
on each isotypic block.

A genuinely new invariant therefore requires all three features:

1. `alpha` is outer on the named Lin cross-context algebra, not merely
   a multiplicity conjugation;
2. a bounded raw loop has nontrivial holonomy on `B), rather than
   reducing to `B` or zero; and
3. the holonomy output has the required full-`C` left atom and a
   representation-independent singular floor.

The off-diagonal complement-gauge theorem shows why ordinary rectangular
covariance does not provide feature 1: its cokernel representation is a
free direct summand.  The three-corner theorem supplies the coefficient
and feature 3 before the raw loop, but not an outer action.  Therefore
the remaining search is exactly a bounded outer Jacobson return on
`c_y^*e_rc_x`.  No such return, and hence no nonhyperlinearity proof,
is claimed here.

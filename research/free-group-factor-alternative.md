Exactly one holds:

1. `L(F_r) = L(F_s)` for all `1 < r <= s <= infinity`, and the fundamental group
   of every `L(F_r)` is `R_+`;
2. `L(F_r)` and `L(F_s)` are non-isomorphic for all `1 < r < s <= infinity`, and
   the fundamental group of `L(F_r)` is `{1}` for `1 < r < infinity`.

Literature import (Dykema; Rădulescu), statement quoted verbatim from the TeX of
I. Goldbring and J. Pi, *On the first-order free group factor alternative*
(arXiv:2305.08168), which cites it as "[Rad1995random, Corollary 4.7]":

- l.172: "$L(\F_r) \cong L(\F_s)$ for all $1 < r \leq s \leq \infty$, and the fundamental group of $L(\F_r)$ is $\bR_+$ for all $1 < r \leq \infty$."
- l.173: "$L(\F_r) \not \cong L(\F_s)$ for all $1 < r < s \leq \infty$, and the fundamental group of $L(\F_r)$ is $\{1\}$ for all $1 < r < \infty$."

Trust surface: second-hand. Rădulescu, Invent. Math. 115 (1994) 347–389, was not
read; the statement is consumed as quoted by Goldbring–Pi.

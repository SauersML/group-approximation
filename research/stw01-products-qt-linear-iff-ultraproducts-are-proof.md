Put `A = prod_i A_i` and let `theta: l^infinity(I) -> Z(A)` be
`theta(f) = (f_i 1_(A_i))_i`, a unital central star homomorphism.  Identify
`l^infinity(I) = C(beta I)`.  The Gelfand transform of `f` at `omega in beta I` is
`lim_omega f_i`, so

```text
C_0(beta I \ {omega}) = c_omega = {f : lim_omega f_i = 0}.
```

**Principal points.**  For `omega = i`, `c_i = {f : f_i = 0}`.  The closed ideal
generated by `theta(c_i)` is `{a : a_i = 0}`, because such an `a` equals
`theta(1 - delta_i) a`.  So the fiber is `A_i`.

**Free ultrafilters.**  Let `N_omega = {a : lim_omega ||a_i|| = 0}`, a closed
two-sided ideal with `A/N_omega = prod_omega A_i`.

- `J_omega subset N_omega`: for `f in c_omega` and `b in A`,
  `||f_i b_i|| <= |f_i| ||b||`, which tends to `0` along `omega`.  So
  `theta(c_omega) A subset N_omega`, and `N_omega` is a closed ideal.
- `N_omega subset J_omega`: for `a in N_omega`, put `f_i = ||a_i||^(1/2)` and
  `b_i = a_i / ||a_i||^(1/2)`, with `b_i = 0` if `a_i = 0`.  Then
  `||b_i|| <= ||a||^(1/2)`, so `b in A`, `f in c_omega` and `a = theta(f) b`.

So the fiber at `omega` is `prod_omega A_i`.

Apply `stw01-central-cx-fibers-preserve-qt-linearity` to `theta`.  Its fibers are
exactly the `A_i` and the `prod_omega A_i`, which proves the equivalence.

**Sequence algebra.**  For `A_infinity = l^infinity(N, A) / c_0(N, A)`, use
`theta: l^infinity / c_0 = C(beta N \ N) -> Z(A_infinity)`.  The same factorization
identifies the fiber at a free `omega` with `A_omega`, since `c_0(N, A)` is
contained in `N_omega`.  Apply the fiber theorem again.  QED.

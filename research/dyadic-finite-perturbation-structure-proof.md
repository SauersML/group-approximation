## Proof

**Multiplication in `H`** is `(b,A,m)(c,B,n) = (b + 2^m A c, AB, m+n)`, and
the displayed formula is an action on `X`: an integral unimodular `A`
carries `2^-s Z^3` to itself, so the coset is well defined.

**Transitivity.**  With `t_v` the translation by `v` and `a` the dilation
by `2`, the element `t_v a^k` sends `Z^3` to `v + 2^k Z^3`.

**Faithfulness modulo finite support.**  Let `(b,A,m) != 1`.  If `m != 0`,
every point of `X` has its lattice scale changed, so infinitely many
points move.  If `m = 0` and the affine map is not the identity, pick
`v in D^3` with `w = (A - I)v + b != 0`.  For all sufficiently large `k`,
`w` is not in `2^k Z^3`, so the cosets `v + 2^k Z^3` all move.  Either way
the element moves infinitely many points and so is not finitely
supported.  Hence `Sym_fin(X) cap H = 1`.

`Sym_fin(X)` is normalized by any permutation, in particular by `H`, so
the group they generate is `Sym_fin(X) x| H`.  Conversely, if a
permutation `g` agrees with `h in H` off a finite set then `gh^-1` has
finite support, which is `(DP2)`.

**Finite generation.**  `H` is generated by the six `e_ij(1)`, the three
translations `t_(e_i)` and `a`: the conjugates `a^-j t_(e_i) a^j` give all
dyadic translations, and the `e_ij(1)` generate `SL_3(Z)` by Euclidean
row reduction.  Let `S` be a finite symmetric generating set of `H` and
`x_0 = Z^3`.  Adjoin the finitely many transpositions `(x_0, s x_0)` for
`s in S` with `s x_0 != x_0`.  Their `H`-conjugates are exactly the edge
transpositions of the graph with edge set `{ h x_0, h s x_0 }`, which is
connected because the prefixes of a word `s_1...s_m` applied to `x_0`
trace a path.  Edge transpositions of a connected graph generate every
finitely supported permutation: the transposition of the endpoints of a
finite simple path is obtained by conjugating its last edge transposition
by the preceding ones, and every finitely supported permutation is a
product of transpositions.

**Residual finiteness of `H`.**  The map

```text
(b,A,m) |--> [[2^m A, b],[0,1]] in GL_4(D)
```
is injective: `2^m A = 2^n B` forces `2^(3m) = 2^(3n)` by determinants,
hence `m = n` and `A = B`, and then `b = c`.  Reduction of `D` modulo an
odd prime is defined because `2` is invertible there; given a nonidentity
element, choose an odd prime not dividing the numerator of a nonzero
entry of the difference from `I`.  The resulting finite matrix quotient
separates it.

**`(DP3)`.**  Conjugation by a permutation preserves cycle lengths, hence
the parity of a finitely supported permutation, so `H` acts trivially on
`Sym_fin(X)/Alt_fin(X) = C_2`.  The quotient is therefore the direct
product, and it is residually finite because both factors are.

**No nontrivial finite normal subgroup.**  First in `H`: let `F` be a
finite normal subgroup.  `D^3` is torsion-free, so `F cap D^3 = 1`.  If
`f in F` has linear part `M = 2^m A`, then `[f, t_v]` is the translation
by `(M - I)v`, which lies in `F cap D^3 = 1` for every `v in D^3`; hence
`M = I`, so `f` is a translation and `f = 1`.  Now let `F` be a finite
normal subgroup of `G`.  Its image in `H` is a finite normal subgroup, so
`F <= Sym_fin(X)`.  The union of the supports of the finitely many
elements of `F` is a finite subset of `X`, and normality under `H` makes
it `H`-invariant.  Transitivity of `H` on the infinite set `X` forces it
to be empty, so `F = 1`.

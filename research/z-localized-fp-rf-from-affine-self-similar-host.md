A self-similar group acts faithfully on a regular rooted tree, so it is residually
finite: the level stabilizers have finite index and trivial intersection. The group
`Aff_1(Z_(l)) ⊆ Aff_n(Z_(l))` contains the translations `x -> x + c`, `c in Z_(l)`, a
copy of `Z_(l)`. So the finitely presented self-similar overgroup given by the input
is a witness. ∎

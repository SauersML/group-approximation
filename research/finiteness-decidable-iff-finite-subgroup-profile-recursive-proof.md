Lane proof, elementary, no imports. Throughout `G = <S>` has solvable word
problem, so from the words of length `<= L` one computes a list of the distinct
elements of `B(L)`, and, given finitely many words, one decides which of them
represent equal elements.

**Bounded search (BS).** Let `W` be a finite set of words and `N` a number.
Enumerate `<W>` by breadth-first search in its Cayley graph with respect to
`W ∪ W^-1`, deduplicating with the word problem. Stop when either a sphere adds
no new element, or more than `N` distinct elements have been found. The search
always stops:

- if `<W>` is finite, the balls stabilise;
- if `<W>` is infinite, every ball is strictly larger than the previous one, so
  the count passes `N`.

On the first outcome `<W>` is finite and its elements are listed; on the second,
`|<W>| > N`, whether or not `<W>` is finite.

**Item 1.**
- *Computable implies recursively bounded*: trivial.
- *Recursively bounded implies order problem decidable.* Let `TO <= R` with `R`
  recursive, and let `w` have length `L`. If `w` has finite order, its order is
  at most `TO(L) <= R(L)`. So `w` has finite order iff `w^k = 1` for some
  `1 <= k <= R(L)`, which is finitely many word-problem queries.
- *Order problem decidable implies computable.* List the elements of `B(L)`.
  Decide which have finite order. For each that does, find its order by testing
  `w^k = 1` for `k = 1, 2, ...`, which terminates. Output the maximum.

**Item 2.**
- *Recursively bounded implies finiteness problem decidable.* Let `FS <= R`, and
  let `W` be a finite set of words with maximal length `L`. Then `W ⊂ B(L)`, so
  if `<W>` is finite, `|<W>| <= FS(L) <= R(L)`. Run BS with `N = R(L)`. If it
  closes, `<W>` is finite; if it passes `R(L)` elements, `<W>` is infinite.
- *Finiteness problem decidable implies computable.* Enumerate the finitely many
  subsets of `B(L)`. For each, decide finiteness; for the finite ones, compute
  the order by BS with no cap, which closes. Output the maximum.

**Item 3.** Fix rational `δ > 0`.
- *Exact Cheeger test.* For a listed finite group `Γ` and `T ⊂ Γ`, the word
  problem gives the multiplication table. `h(Γ,T)` is a minimum of finitely many
  rationals, so `h(Γ,T) >= δ` is decided exactly.
- *Recursively bounded implies δ-expander problem decidable.* Let `X^δ <= R`,
  and let `T` be a finite symmetric set of words. Deduplicate `T` into elements,
  and put `L = max(1, |T|, max_(t in T) |t|)`, so `T ⊂ B(L)` and `|T| <= L`.
  - If `<T>` is finite with `h >= δ`, then `|<T>| <= X^δ(L) <= R(L)`.
  - Run BS with `N = R(L)`. If it passes `R(L)`, answer no: either `<T>` is
    infinite, or it is finite but too large to be a δ-expander on `T`.
  - If it closes, apply the exact Cheeger test.
- *δ-expander problem decidable implies computable.* Enumerate the symmetric
  subsets `T ⊂ B(L)` with `|T| <= L`. Decide each; for the yes instances compute
  `|<T>|` by BS. Output the maximum together with `1`.

**Item 4.** Every word of length `<= L` in `R` becomes, after substituting a
word of length `<= c` in `S` for each letter, a word of length `<= cL` in `S`.
So `B_R(L) ⊂ B_S(cL)`, and:

- a torsion element of `B_R(L)` is a torsion element of `B_S(cL)`, with the
  same order;
- a finite subgroup generated by a subset of `B_R(L)` is generated by the same
  subset of `B_S(cL)`;
- a pair `(Γ, T)` with `T ⊂ B_R(L)`, `|T| <= L <= cL` and `h(Γ,T) >= δ` is
  admissible for `X^δ_(G,S)(cL)`, since `h(Γ,T)` depends only on `Γ` and `T`.

If `P_(G,S) <= U` with `U` recursive, then `P_(K,R)(L) <= U(cL)`, which is
recursive. Taking `K = G` with two generating sets gives independence of the
generating set. ∎

If a discrete group `G` has the property that `C*_r(G)` fails strict
comparison with respect to its canonical trace, then there exist an integer
`n>=1`, matrices

```text
z,w in M_n(C[G]),
```

and a positive rational number `r` such that, on putting

```text
x=z* z,        y=w* w,
X=(x-3r)_+,    Y=(y-r)_+,
```

one has

```text
d_(tau_G)(X) < d_(tau_G)(Y),          X not <=_Cu Y.  (1)
```

In particular, if `H<=G` is generated by the finite union of the supports of
the entries of `z` and `w`, then `H` is finitely generated and the same
elements satisfy (1) in `M_n(C*_r(H))`.  Thus `C*_r(H)` fails canonical
strict comparison.

Thus every negative answer to STW Problem XC has a finite-support algebraic
input and one rational cutoff witnessing a local comparison defect.  The
support subgroup need not itself be C*-simple, so the statement still does
not reduce XC to the finitely generated C*-simple case.

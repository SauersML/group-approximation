## Notation

- `Γ = E_n(S)`, `n >= 3`, and `π : Γ -> Q_I = Γ/E_n(S,I)` is the quotient map.
- `a_1, ..., a_m` generate `I` as a two-sided ideal, and `c_1, ..., c_r` generate `S` as a ring.
- On operators between finite-dimensional spaces, `||X||_2 = d^(-1/2) ||X||_HS`, with `d` the
  dimension of the model space `W` below, fixed within each step.
- We use `||AB||_2 <= ||A||_op ||B||_2`, `||B A||_2 <= ||B||_2 ||A||_op` and `||A*||_2 = ||A||_2`.
- `o(1)` means a quantity that tends to 0 as `k -> ∞` for a fixed group element.

**Imports used verbatim.**
- (T) `ershov-jaikin-kassabov-steinberg-groups-have-property-t`: `E_n(A)` has property (T) for
  every finitely generated unital ring `A` and `n >= 3` (Ershov--Jaikin-Zapirain, type `A_(n-1)`).
- (K) The Kazhdan projection inequality. Let `(G, F)` be a Kazhdan pair with constant `κ`, `τ` a
  unitary representation, `ξ` a unit vector with `max_(s in F) ||τ(s)ξ - ξ|| <= δ`, and `E` the
  orthogonal projection onto the `τ(G)`-invariant vectors. Then `||ξ - Eξ|| <= δ/κ`.
  - Proof: `η = ξ - Eξ` lies in the invariant complement, so some `s in F` has
    `||τ(s)η - η|| >= κ||η||`.
  - Since `τ(s)Eξ = Eξ`, we have `τ(s)η - η = τ(s)ξ - ξ`, which has norm at most `δ`.

## Step 0. The fibre-product ring and its Kazhdan set

Let `D = {(x, y) in S x S : x - y in I}`, with coordinate projections `p_1, p_2 : D -> S` and
diagonal `Δ : S -> D`, `s -> (s, s)`. All three are unital ring homomorphisms. The swap
`θ(x, y) = (y, x)` is a ring automorphism of `D`.

1. **`D` is finitely generated.**
   - `(x, y) = (y, y) + (x - y, 0)`, so `D = Δ(S) + (I x 0)`.
   - Every element of `I` is a sum `sum u a_l v`, and `(u a_l v, 0) = (u,u)(a_l,0)(v,v)`.
   - So `D` is generated as a unital ring by `G_D = {(c_i, c_i)} ∪ {(a_l, 0)}`.
2. **A finite generating set.** `E_n(D)` is generated by the finite set
   `F_D = {x_ij(g) : i != j, g in G_D ∪ {(1,1)}}`.
   - `x_ij(d + d') = x_ij(d) x_ij(d')`.
   - `x_ij(d d') = [x_ik(d), x_kj(d')]` for `k` distinct from `i, j`; this uses `n >= 3`.
   - Every element of `D` is a sum of products of elements of `G_D`, including the empty product `1`.
3. **Property (T).** By (T), `E_n(D)` has property (T). Let `κ > 0` be a Kazhdan constant for
   `(E_n(D), F_D)`. It depends only on `(S, I, n)` and the chosen generators.

Maps on groups are entrywise: `p_1, p_2 : E_n(D) -> Γ` and `Δ : Γ -> E_n(D)`, with
`p_1 Δ = p_2 Δ = id`. Also `θ` acts on `E_n(D)`.

## Step 1. Pull back and stabilize

Let `σ_k : Q_I -> U(W_k)`, `dim W_k = d_k`, be an asymptotic representation.

- Then `σ_k ∘ π` is an asymptotic representation of `Γ`.
- Standard consequences, for fixed `x`:
  - `||σ_k(1) - 1||_2 = ||σ_k(1)^2 - σ_k(1)||_2 = o(1)`, since `σ_k(1)` is unitary;
  - `||σ_k(x^(-1)) - σ_k(x)*||_2 = o(1)`.
- Stability of `Γ` gives genuine `λ_k : Γ -> U(V_k)`, where `V_k ⊇ W_k` has dimension
  `D_k >= d_k`, such that `||σ_k(π g) - P λ_k(g) P*||_2 = o(1)` for every `g`.
  - Here `P* : W_k -> V_k` is the inclusion and `p = P*P` is the projection onto `W_k`.

Drop the index `k` below.

**Lemma 1.1 (the corner almost commutes).** Let `u = σ(π g)` and `v = λ(g)`, with
`||u - PvP*||_2 <= ε <= 1`. Then:

```text
||v p v* - p||_2 <= 6 ε^(1/2),        ||v p - p v p||_2 <= 2 ε^(1/2)     (normalized by d).
```

Proof.
- Write `A = PvP*` and `C = (1-p) v P*`.
- `||A||_HS^2 + ||C||_HS^2 = ||v P*||_HS^2 = d`.
- `||A||_2 >= ||u||_2 - ε = 1 - ε`, so `||C||_2^2 <= 1 - (1-ε)^2 <= 2ε`. Since
  `vp - pvp = C P`, this gives the second bound.
- For the first, `v p v* = (vp)(vp)*`, and
  `||(vp)(vp)* - (pvp)(pvp)*||_2 <= 2||vp - pvp||_2`, since all operator norms are at most 1.
- Also `(pvp)(pvp)* = P* A A* P`, and `||AA* - 1_W||_2 <= ||A - u||_2 + ||A* - u*||_2 <= 2ε`,
  using `uu* = 1` and `||A||_op <= 1`.
- Summing, `||v p v* - p||_2 <= 2 (2ε)^(1/2) + 2ε <= 6 ε^(1/2)` for `ε <= 1`. Only `o(1)`
  matters below.

## Step 2. The corner projection is almost invariant under the fibre-product group

Let `H = End(V)` with inner product `<X, Y> = Tr(Y* X)/d`. Then `||p|| = 1`. Define

```text
τ(g) X = λ(p_1 g) X λ(p_2 g)*,        g in E_n(D).
```

This is a unitary representation of `E_n(D)` on `H`. Put
`δ = max_(s in F_D) ||τ(s)p - p||`.

**Claim: `δ = o(1)`.** The generators in `F_D` are of two kinds.

- **Diagonal generators** `s = x_ij((c, c))`, with `c` one of the `c_i` or `1`.
  - Here `p_1 s = p_2 s = h := x_ij(c)`, so `τ(s)p = λ(h) p λ(h)*`.
  - By Lemma 1.1 with `ε = ||σ(π h) - Pλ(h)P*||_2 = o(1)`, this is within `6 ε^(1/2) = o(1)` of `p`.
- **Ideal generators** `s = x_ij((a_l, 0))`.
  - Here `p_1 s = h := x_ij(a_l)` and `p_2 s = 1`, so `τ(s)p = λ(h)p`.
  - Since `a_l` lies in `I`, `h` lies in `E_n(S,I) = ker π`. So
    `||Pλ(h)P* - 1_W||_2 <= ||Pλ(h)P* - σ(1)||_2 + ||σ(1) - 1||_2 = o(1)`.
  - With `v = λ(h)`: `||vp - p||_2 <= ||vp - pvp||_2 + ||P v P* - 1_W||_2`. The first term is
    `o(1)` by Lemma 1.1, applied with `u = σ(π h) = σ(1)`.
  - So `||τ(s)p - p|| = o(1)`.

`F_D` is finite and fixed, so `δ = o(1)`.

## Step 3. The Kazhdan projection is a self-adjoint intertwiner

Let `E` be the orthogonal projection of `H` onto the `τ(E_n(D))`-invariant vectors, and put
`T = E p`. By (K), `||T - p|| <= δ/κ`.

**Intertwining.** Invariance reads `λ(p_1 g) T = T λ(p_2 g)` for all `g` in `E_n(D)`.
1. For `g = Δ(h)` with `h` in `Γ`, this gives `λ(h) T = T λ(h)`. So `T` lies in the commutant of
   `λ(Γ)`.
2. For `g = x_ij((a, 0))` with `a` in `I`, it gives `λ(x_ij(a)) T = T`. Here `(a, 0)` lies in `D`
   because `a - 0` lies in `I`.
3. Combining 1 and 2, for `h` in `Γ`:
   `λ(h x_ij(a) h^(-1)) T = λ(h) λ(x_ij(a)) T λ(h)^(-1) = λ(h) T λ(h)^(-1) = T`.
   So every element of the normal closure `E_n(S,I)` fixes `range(T)` pointwise.

**Self-adjointness.** Let `J X = X*`. This is a conjugate-linear isometric involution of `H`, and
`J τ(g) J = τ(θ g)`:

```text
(λ(p_1 g) X* λ(p_2 g)*)* = λ(p_2 g) X λ(p_1 g)* = λ(p_1 θg) X λ(p_2 θg)*.
```

- `θ` is an automorphism of `E_n(D)`. So `J` maps the invariant subspace `H_0` onto the vectors
  invariant under `τ ∘ θ`, which is `H_0` again.
- `J` is an isometric involution with `<JX, JY> = conj<X, Y>`, so it also preserves `H_0^⊥`.
  Hence `J E = E J`.
- `p = p*` gives `T* = J E p = E J p = E p = T`.

## Step 4. Spectral rounding to a subrepresentation of Q_I

Let `q = 1_((1/2, ∞))(T)`, a spectral projection of the self-adjoint operator `T` on `V`.

1. **`q` is a subrepresentation.** `q` commutes with `λ(Γ)`, because `T` does.
2. **It factors through `Q_I`.** `q = T f(T)` with `f(t) = 1_(t > 1/2)/t`, so
   `range(q) ⊆ range(T)`. By Step 3, `E_n(S,I)` fixes `range(q)` pointwise.
   - So `ρ = λ|_(range q)` is a genuine representation of `Q_I` on `U = range(q)`.
   - Put `r = dim U`.
3. **Closest projection.** For every projection `e` on `V`:

   ```text
   Tr((T - e)^2) = Tr(T^2) + Tr(e (1 - 2T) e).
   ```

   - `Tr(e A e)` for self-adjoint `A = 1 - 2T` is at least the sum of the negative eigenvalues of
     `A`, by the min-max principle.
   - Equality holds at `e = 1_(A < 0) = q`. So `||T - q|| <= ||T - p||`.
   - Hence:

   ```text
   ε := ||q - p|| <= 2 ||T - p|| <= 2δ/κ = o(1).
   ```

## Step 5. Absorb the defect in a trivial summand

Let `X = q P* : W -> U`. Then:

```text
||X - P*||_2 = ||(1 - q) P*||_2 = ||(p - q) p||_2 <= ε,        X* X = P q P*.
```

**The isometry.**
- Take the polar decomposition `X = v |X|`, with `v` isometric on `W_1 = (ker X)^⊥`.
- Put `W_2 = ker X` and `m = dim W_2`.
- Every unit vector `w` in `W_2` has `||(1-q)w|| = 1`, so `m <= Tr(P(1-q)P*) = d ||(1-q)P*||_2^2`.
  Hence `m <= d ε^2`.
- Let `ρ' = ρ ⊕ 1_m` on `U' = U ⊕ C^m`, a genuine representation of `Q_I`.
- Let `j = v ⊕ w_0 : W -> U'`, where `w_0` is a unitary from `W_2` onto `C^m`.
- `j` is an isometry: `v` and `w_0` are isometric on the orthogonal summands `W_1` and `W_2`, and
  their ranges `U` and `C^m` are orthogonal.
- Hence `dim U' = r + m >= d`.

**`j` is close to `X`.**
- On `W_1` we have `j - X = v(1 - |X|)`. On `W_2` we have `X = 0` and `|X| = 0`.
- So `||j - X||_2 = ||1_W - |X| ||_2`.
- For `0 <= t <= 1`, `1 - t <= 1 - t^2`. So
  `||1_W - |X| ||_2 <= ||1_W - X*X||_2 = ||P(1-q)P*||_2 <= ε`.

**The corner is close to the model.** For `g` in `Γ` and `x = π g`:

```text
||σ(x) - j* ρ'(x) j||_2 <= ||σ(x) - P λ(g) P*||_2 + ||P λ(g) P* - P λ(g) q P*||_2 + ||X* ρ'(x) X - j* ρ'(x) j||_2.
```

- Here `X* ρ'(x) X = P q λ(g) q P* = P λ(g) q P*`, because `q` commutes with `λ(g)`.
- The first term is `o(1)` by Step 1.
- The second term is at most `||(1-q)P*||_2 <= ε`.
- The third is at most `||(X - j)* ρ' X||_2 + ||j* ρ' (X - j)||_2 <= 2ε`.

So the total is at most `o(1) + 3ε = o(1)`.

Choose an orthonormal basis of `U'` that begins with `j` applied to the fixed basis of `W`.
Conjugating `ρ'` by it gives `λ'_k : Q_I -> U(D'_k)`, with:
- `D'_k = r + m >= d_k`;
- `||σ_k(x) - P λ'_k(x) P*||_2 -> 0` for every `x` in `Q_I`.

This is flexible HS stability of `Q_I`. `Q_I` is finitely generated, as a quotient of `Γ`.

**Dimension control.** `D'_k = r + m <= D_k + d_k ε_k^2`. So `D'_k/d_k <= D_k/d_k + o(1)`, and the
ratio-one variant is preserved. ∎

## Remarks

- **What is used about `S` and `I`.** The proof uses only:
  - that `D = S x_(S/I) S` is finitely generated, so that property (T) applies to `E_n(D)`;
  - that `θ` swaps the two projections.

  Finite generation of `I` as a two-sided ideal gives the first. For an ideal that is not finitely
  generated, `D` is not finitely generated, and the argument only descends to the quotients by
  `E_n(S, I')` for finitely generated `I' ⊆ I`.
- **Which kernel.** The descent reaches `Q_I = E_n(S)/E_n(S,I)`, not `E_n(S/I)`. The kernel of
  `Q_I -> E_n(S/I)` is `(E_n(S) ∩ GL_n(S,I))/E_n(S,I)`, which is `K_2`-type. It is killed separately
  in `universal-lattice-flexible-stability-forces-nonhyperlinear-group` when `S/I` is simple.
- **Relation to the Kazhdan-kernel descent.** If `E_n(S,I)` itself had (T), then
  `flexible-hs-stability-passes-to-kazhdan-kernel-quotients` would apply directly. Here the double
  `E_n(D)` supplies the relative rigidity instead. The intertwiner `λ(p_1 g) T = T λ(p_2 g)` is the
  wave-22 device from the Leavitt cone-half reduction, used there for representations that are
  almost trivial on the whole space.

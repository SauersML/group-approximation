**OPEN.**  Totally computably from a machine index `e`, produce a finitely
generated recursively presented base group, fixed rational mark `p_e`, and a
computably enumerable family of finite extension gadgets `(E_(e,i))` such
that:

1. on HALT, one exact (possibly properly infinite) representation extends
   **all** gadgets simultaneously and keeps `p_e!=0`;
2. on NONHALT, for every canonical matrix-ultraproduct base type retaining
   `p_e`, at least one `E_(e,i)` has no compatible matrix-ultraproduct
   extension.

The gadget selected in clause 2 may depend arbitrarily on the actual
approximation type—its relative commutant, multiplicity gauges, spectral
placement, or other existential data.  It need not depend on dimension and
no finite algorithm must identify it from a coordinate tuple.

By `bespoke-extension-nemesis-library-defeats-diagonal-schedules`, clause 2
collapses the mark on every canonical microstate sequence.  Clause 1 gives
reverse-Kleene completeness, so this compiler would yield a finitely
presented nonhyperlinear group after effective Higman embedding.

## Attempts

- Rational finite tuples may be used to discover candidate neighborhoods,
  but their challenges must enter the pre-enumerated library rather than be
  appended only after that tuple triggers a halt.
- Scalar moment fingerprints are useless because every canonical
  approximation has the same limiting group-word law.  A viable nemesis must
  test extension data, such as incompatible return equations in the actual
  multiplicity/commutant reservoir.
- Common HALT completeness is load-bearing.  Independently tailored gadgets
  that require mutually incompatible infinite completions cannot all be put
  in one final group.
- Robust nonextendability is load-bearing.  A challenge that excludes one
  exact rational code but not an open extension-type neighborhood permits a
  diagonal sequence to move among codes.

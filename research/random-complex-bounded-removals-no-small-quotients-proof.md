## Direct proof

Notation follows `random-complex-no-quotients-below-exp-pn-proof`, which follows
R. Meshulam, arXiv:1308.3769v1. Fix a finite group `G`.
- `C^1` is the set of `G`-valued 1-cochains on `K_n`, with `φ(w,v) = φ(v,w)^(-1)`.
- `C^0` acts by gauge transformations, `(β.φ)(v,w) = β(v) φ(v,w) β(w)^(-1)`.
- `||[φ]||` is the minimum support size in the orbit of `φ`.
- `V(φ)` is the set of triangles `{u,v,w}` with `φ(u,v)φ(v,w)φ(w,u) != 1`. This
  condition does not depend on the order of the vertices and is gauge invariant.
  Put `||d_1 φ|| = |V(φ)|`.

**0. Homomorphisms as cochains** (Meshulam, Claim 2.1 and Corollary 2.2).

Let `X` be a 2-complex with 1-skeleton `K_n`, and fix a vertex `u`.
- **Presentation.** `π_1(X,u)` is generated by the loops `γ_(vw) = (u,v,w,u)`
  over edges `vw` with `u ∉ {v,w}`. The relators are `γ_(vw) = 1` for each
  triangle `{u,v,w} ∈ X(2)`, and `γ_(vw) γ_(wx) γ_(xv) = 1` for each triangle
  `{v,w,x} ∈ X(2)` avoiding `u`. This is the edge-path presentation relative to
  the star of `u` as spanning tree.
- **Cochains.** A homomorphism `ψ: π_1(X,u) -> G` gives `φ` with `φ(u,v) = 1` and
  `φ(v,w) = ψ(γ_(vw))`. The relators say exactly `V(φ) ∩ X(2) = ∅`, and `ψ` is
  nontrivial iff `φ != 1`.
- **Classes.** A cochain with `φ(u,·) = 1` lies in the orbit of `1` only if the
  gauge `β` is constant, which gives `φ = 1`. So `ψ` is nontrivial iff
  `[φ] != [1]`.

Hence `X` admits a nontrivial homomorphism to `G` iff some class `[φ] != [1]`
satisfies `V(φ) ∩ X(2) = ∅`.

**1. Expansion of the simplex** (Meshulam, Proposition 3.1): `||d_1 φ|| >= (n/3) ||[φ]||`.

For a vertex `u`, let `φ_u = β` with `β(u) = 1` and `β(v) = φ(u,v)`. The gauged
cochain `ψ = φ_u . φ` satisfies `ψ(u,v) = 1` and `ψ(v,w) = φ(u,v)φ(v,w)φ(w,u)`.
- **Per vertex.** The support of `ψ` is the set of edges `vw` with
  `{u,v,w} ∈ V(φ)`. So `||[φ]||` is at most the number of violated triangles at `u`.
- **Sum.** Summing over `u` counts each violated triangle three times, so
  `3||d_1 φ|| >= n ||[φ]||`.

**2. Reduction.** Suppose, for some `T ⊂ Y(2)` with `|T| <= t`, the group
`π_1(Y \ T)` has a nontrivial finite quotient `Q` with `|Q| <= N`.
- **Simple quotient.** Pick a maximal normal subgroup of `Q`. Its quotient is a
  simple group `G` with `1 < |G| <= N`, and `π_1(Y \ T) -> G` is nontrivial.
- **Almost cocycle.** By step 0 there is `[φ] != [1]` with
  `V(φ) ∩ (Y(2) \ T) = ∅`, i.e. `|V(φ) ∩ Y(2)| <= t`. Call such a class a
  `t`-almost cocycle of `Y`.

This event does not mention `T`. So the union over all `T` is already inside it.

**3. Binomial tail.** Fix a class of weight `k = ||[φ]|| >= 1`, and let
`M = |V(φ)| >= nk/3`. Then `|V(φ) ∩ Y(2)| ~ Bin(M, p)`.
- **Assumptions.** Assume `n` is large, so `pn/3 >= max(t, 1)`. Then
  `Mp >= pnk/3 >= max(t,1)`.
- **Termwise.** For `j <= t`, `C(M,j) p^j (1-p)^(M-j) <= (Mp)^j e^(-p(M-j)) <= e^t (Mp)^t e^(-Mp)`.
- **Monotonicity.** `x -> x^t e^(-x)` is nonincreasing on `[t, ∞)`.

So

```text
Pr[ |V(φ) ∩ Y(2)| <= t ] <= (t+1) e^t (pnk/3)^t e^(-pnk/3).
```

**4. Sum over classes.** There are at most `C(C(n,2),k) |G|^k <= (n^2|G|/2)^k`
classes of weight `k`, and `k^t <= t! e^k`. With
`r_G = (e n^2 |G| / 2) e^(-pn/3)`,

```text
Pr[ some t-almost cocycle for G ] <= (t+1)! e^t (pn/3)^t sum_{k>=1} r_G^k
                                  <= 2 (t+1)! e^t (pn/3)^t r_G     when r_G <= 1/2.
```

**5. Union over simple groups.** There are at most two non-isomorphic finite
simple groups of each order. This is the count used by Meshulam, p. 6, and by
`random-complex-no-quotients-below-exp-pn-proof`, from Kimmerle--Lyons--Sandling--Teague,
Proc. London Math. Soc. (3) 60 (1990).

Take `N = exp(pn/8)`.
- **Small ratio.** For `|G| <= N`,
  `r_G <= (e/2) n^2 e^(-5pn/24) <= (e/2) n^(2-6.25) <= 1/2`, because `pn >= 30 log n`.
- **Union.** Summing over at most `2N` groups,

  ```text
  Pr[ some T, some nontrivial finite quotient of π_1(Y \ T) of order <= N ]
      <= 2N . 2 (t+1)! e^t (pn/3)^t . (e/2) n^2 N e^(-pn/3)
       = 2e (t+1)! e^t (pn/3)^t n^2 e^(-pn/12).
  ```

- **Limit.** `pn >= 30 log n` gives `n^2 e^(-pn/15) <= 1`, so the right side is
  at most `2e (t+1)! e^t (pn/3)^t e^(-pn/60)`. That tends to `0` because
  `pn -> ∞`.

The same display proves the growing-`t` remark on the claim node. ∎

**Established by citation.**  P. Ara, K. R. Goodearl, K. C. O'Meara and
R. Raphael, *K_1 of separative exchange rings and C\*-algebras with real rank
zero*, Pacific J. Math. 195 (2000), arXiv:math/9906141.  Read from the arXiv
TeX source on 2026-09-16.  Section 3 opens: "We consider only unital, complex
C\*-algebras in this section".

Part 1, verbatim: "Theorem 3.1. If A is a separative, unital C\*-algebra with
real rank zero, then the natural map U(A)/U(A)° -> K_1(A) is an isomorphism."
The proof combines K_1-injectivity from Lin ("Lin proved K_1-injectivity for
C\*-algebras with real rank zero in [Lin, Lemma 2.2]") with AGOR Theorem 2.8
(surjectivity of `GL_1(A) -> K_1^alg(A)` for separative exchange rings) and
AGOP Theorem 7.2 (real rank zero C\*-algebras are exchange rings).  Lin's
paper was not independently read here; STW cite the same result as Lin,
Pacific J. Math., Lemma 2.1.  The import is AGOR's theorem as published.

Part 2, verbatim: "Hence, A is separative if and only if p⊕p ∼ p⊕q ∼ q⊕q
⟹ p ∼ q for projections p,q ∈ M_∞(A).  An equivalent condition (analogous to
Lemma 1.3) is that p⊕r ∼ q⊕r ⟹ p ∼ q whenever r ≲ n.p and r ≲ n.q for some
n.  Separativity in A is thus equivalent to the requirement that all matrix
algebras M_n(A) satisfy the weak cancellation introduced by Brown and
Pedersen [Bro, p. 116; BPtwo, p. 114]."  The same passage then states the
Problem "Is every C\*-algebra with real rank zero separative?", which STW cite
as AGOR Question 3.2.

Definition of weak cancellation: Schafhauser--Tikuisis--White,
arXiv:2506.10902 (TeX source read 2026-09-16), discussion before Problem LX:
"A has weak cancellation if for all projections p,q ∈ A which generate the same
closed ideal I, one has [p]_0=[q]_0 in K_0(I) ⟹ p∼q", and "A is separative if
and only if A has stable weak cancellation, i.e. A⊗K has weak cancellation
([BrownPedersen:JFA14, Paragraph 2.3], [AGOR:PJM, Section 3])".  The
Brown--Pedersen sources were not independently read here.

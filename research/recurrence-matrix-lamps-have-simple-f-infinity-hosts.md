Let `q≥2`, `r≥1`, and let finitely many profiles be
`P_i(n)=q^(a_i(n))U_i(n)`, where `a_i:ℤ→ℤ` and
`U_i:ℤ→UT_r(ℤ)` have eventually rational constant-coefficient
recurrent scalar and entrywise tails at both ends. Let `𝒫` be
generated pointwise by all translates of these profiles, all constant
`UT_r(ℤ)` matrices, and `qI`. Then

`(ℤ[1/q]^r)^(ℤ)⋊(𝒫⋊ℤ)`

embeds in a simple `F_∞` group generated by two finite-order elements.
The profile action on each vector lamp is the displayed matrix, and
the shift translates positions. Arbitrary finite exceptions are allowed.

## Attempts

Sections 8–9 build finite-type weighted profile groups, the affine
vector arithmetic base, and the two-end shell action. The entire
`UT_r(ℤ)×⟨qI⟩` depth-zero isotropy is included; using only scalar
isotropy would not satisfy the compact-core theorem. Comparing a
primitive vector with its `pℤ_p^r` translates detects every affine
lamp/profile action. Weighted closure, arithmetic data and compact-core
finiteness remain substantive open gates. The conditional host route
uses the stated classical BHM/SZ/BZ theorems and proves no Lean result.

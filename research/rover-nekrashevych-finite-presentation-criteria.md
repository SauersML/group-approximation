**ESTABLISHED by citation.** Let `H <= Aut(T_d)` be self-similar.

1. **(FP1, Scott.)** If `H` is finitely presented, then `V_d(H)` is finitely presented.
2. **(FP2, Nekrashevych.)** If `H` is contracting, then `V_d(H)` is finitely presented.
   - `H` need not be finitely presented: the nucleus generates a contracting self-similar group with the same Rover--Nekrashevych group.
3. **(S)** `[V_d(H),V_d(H)]` is simple for every self-similar `H`.
4. **(Ab)** For even `d`, `V_d(H)^ab` is `H^ab` modulo `g = g_1 + ... + g_d` for each wreath recursion `g = sigma(g_1,...,g_d)`. For odd `d` one adds a `Z/2Z` summand and the term `sgn(sigma)`.
5. **(FP3)** Finite presentation of `V_d(H)` does not by itself give finite presentation of `[V_d(H),V_d(H)]`. If `V_d(H)^ab` is finite, the commutator subgroup has finite index, so it is finitely presented whenever `V_d(H)` is.
6. **(R, regrouping.)** Let `H` be finitely generated by `a_1,...,a_n`.
   - The recursion `g -> sigma^m(g_1,...,g_d, ..., g_1,...,g_d)`, with `m` blocks, is a faithful self-similar action of `H` on `T_(md)` with the same sections.
   - Let `A` be the integer matrix whose `i`-th column is the image of `(a_i)_1 + ... + (a_i)_d`.
   - For even `m` with `1/m` not an eigenvalue of `A`, `V_(md)(H)^ab` is finite.
   - Zaremsky combines this with FP1, S and a wreath-product embedding. Every finitely presented self-similar `H` then embeds in the finitely presented simple group `[V_(md)(H),V_(md)(H)]`.

## Answer to "which H give a finitely presented V_d(H)"

- **Known sufficient conditions.** The imported ones are FP1 (`H` finitely presented) and FP2 (`H` contracting).
- **Higher finiteness.** Zaremsky also states that his proof embeds every self-similar group of type `F_n` in a simple group of type `F_n`.
- **No characterization.** No necessary-and-sufficient condition is imported, and none is claimed. The sources contain no germ-level criterion.
- **The commutator host.** A finitely presented simple commutator host needs, beyond FP1 or FP2, a representation with finite abelianization. That is what (R) supplies.

Finite presentation is not what stops the Rover--Nekrashevych route to the full conjecture. Property (T) does:
`deligne-lattice-embeds-in-no-rover-nekrashevych-group`.

## Attempts

- 2026-09-18 (w7-101): a characterization for finite-state `H` is now proved in
  `rover-nekrashevych-fp-iff-finite-lift-presentation`. `V_d(H)` is finitely presented iff the relator kernel is a
  finitely generated lift ideal; FP1 and FP2 are special cases.
  - First example beyond FP1 and FP2: `rover-nekrashevych-group-of-lamplighter-automaton-is-fp`, where
    `V_2(Z/2 ≀ Z)` is finitely presented.
- 2026-09-18 (w8-101): the question "first finite-state `H` with `V_d(H)` not finitely presented" is prior art.
  Skipper--Witzel--Zaremsky (arXiv:1712.05361, Thm 7.1 / Ex. 7.2) already give such examples. Two new nodes build on
  the w7-101 criterion:
  - `persistent-automata-rn-group-fp-iff-group-fp`: for persistent (or theta-twisted persistent) automata every
    normal subgroup is a lift ideal, so `V_d(H)` is finitely presented iff `H` is. This is a short new proof of the
    `F_2` case of SWZ Thm 5.8. It also shows that finite presentability depends on the action and not only on the
    group. `Z/2 ≀ Z` has two actions on `T_4` with the same relator kernel `N`. One (the squared lamplighter) has
    `N = K_∞`, so `V_4` is finitely presented. The other (a persistent extension) has `K_∞ = 1`, so `V_4` is not.
  - `rn-groups-of-affine-lamplighters-f-q-wr-z-are-fp`: `V_q(F_q ≀ Z)` is finitely presented for every
    prime power `q` and every `a` in `F_q^×`. The proof shows `N = K_∞` directly, with no Hopficity argument.
    The group `G^+ = AGL_1(F_q[t^{±1}])` is `F_1` but not `FP_2` (Bux), yet `V_q(G^+)` is finitely presented. Its
    kernel is a finitely generated lift ideal different from `K_∞`. So SWZ Thm 5.8 cannot drop persistence.
  - Not landed, sketched only:
    - `V_q(G^+)` should be `PAff_R(O)` with `R = F_q[t, 1/t, 1/(t-a)]`, since `O ∩ R = O_S`.
    - Translations by `F_q[t]` are generated by constant translations through sections. So
      `V_q(AGL_1(F_q[t])) = V_q(AGL_1(F_q))`, which is finitely presented by FP1.
    - For `|S| = 2`, the 3-transitivity of `PGL_2(F_q)` makes the degree-one configurations uniform.
  - Open, and the next step: is `V_2(Z/2 ≀ Z)` of type `F_∞`, or at least `F_3`? A route is a Stein--Farley complex
    whose vertices are decorated with points of the Bruhat--Tits trees at `0` and `∞` of `F_2(t)`, with a

Notation: `τ_x(z) = z + x`. For `x ∈ Z_(p)`, `τ_x ∈ Γ_p` (the Iwahori matrix
`[[1,x],[0,1]]`), and `τ_x` has infinite order when `x ≠ 0`. For every prime
`q ≠ p`, `τ_{1/q}^q = τ_1`.

**(a)**
- The finite-state automorphisms of `T_p` form a subgroup. The sections satisfy
  `(gh)|_v = g|_{h(v)} h|_v` and `(g^{-1})|_v = (g|_{g^{-1}(v)})^{-1}`, so the
  sets of sections of `gh` and `g^{-1}` are finite whenever those of `g` and `h`
  are.
- So a group generated by finite-state automorphisms consists of finite-state
  automorphisms.
- `Γ_p` contains `u ↦ u/(1+pu)`, which is not finite-state (item 4 of
  `pgl2-q-in-rover-nekrashevych-group-of-rational-iwahori`).

**(b)** `x ↦ τ_x` embeds `Z_(p) = Z[1/P]`, with `P` the set of primes `≠ p`,
in `Λ`. `P` is infinite, so item 2 of
`fg-metabelian-groups-have-roots-at-finitely-many-primes` applies.

**(c)** `τ_1 ∈ Λ` has infinite order and `q`-th roots in `Λ` for every prime
`q ≠ p`. This contradicts `fg-linear-groups-have-roots-at-finitely-many-primes`.

**(d1)**
- A continuous additive endomorphism `A` of `Z_p` satisfies `A(n) = nA(1)` for
  `n ∈ Z`, so by density `A(z) = A(1)z`.
- So `Λ` would be a group of maps `z ↦ az + b` with `a ∈ Z_p^×` and `b ∈ Z_p`.
  It embeds in `GL_2(Q_p)` through `[[a,b],[0,1]]`, and the embedding is
  injective because the action is faithful. So `Λ` is linear, and (c) applies.

**(d2), commutativity lemma.** Let `R`, `π` be as stated, and let
`R̂ = lim R/π^kR`.

1. *Layers.* The map `R/πR -> π^jR/π^{j+1}R`, `r ↦ π^j r`, is onto. It is
   injective: `π^j r = π^{j+1} s` gives `r = πs` after cancelling `π^j` on the
   left. So every layer has `p` elements.
2. *Digits.* `R/πR` is a ring with `p` elements, so it is `F_p`, the image of
   `Z`. Inductively, every `r ∈ R` satisfies
   `r ≡ c_0 + πc_1 + ... + π^{k-1}c_{k-1} (mod π^kR)` with integers `c_j`:
   write `r = c_0 + πr_1` and recurse on `r_1`. So `R/π^kR` is the image of the
   commutative ring `Z[π]`, and `R̂` is commutative.
3. *DVR.* Let `0 ≠ r ∈ R̂` with `r ∈ π^kR̂ \ π^{k+1}R̂`. Then `r = π^k s` with
   `s ≢ 0 (mod π)`.
   - Here `s ≡ c (mod π)` for some integer `c` prime to `p`.
   - `p ∈ πR̂`, since `R/πR = F_p`. `R̂` is `π`-adically complete, so every
     `1 + πt` is a unit (geometric series), and `c` is a unit (`cc' = 1 + pn`).
     Hence `s` is a unit.
   - `π` is not a zero-divisor in `R̂`, because the layers are nonzero.
   - So `R̂` is a domain in which every nonzero element is a unit times a power
     of `π`: a complete DVR with residue field `F_p`. Let `K = Frac(R̂)`.
4. *Linearity.* The elements of `R` act through their images in `R̂`, and the
   boundary of the `π`-adic tree is `R̂`.
   - Affine maps `x ↦ ax + b` of `R̂` lie in `Aff(R̂) <= GL_2(K)`, which acts
     faithfully on `R̂`.
   - Möbius maps lie in `PGL_2(K)`. A Möbius map fixing the infinite set `R̂`
     pointwise is trivial, so `PGL_2(K)` acts faithfully on `R̂`, and
     `PGL_2(K) <= GL_3(K)` through the adjoint action.
   - Under the identification of trees, `Λ` is isomorphic to a finitely
     generated subgroup of `GL_2(K)` or `GL_3(K)`. Then (c) applies.

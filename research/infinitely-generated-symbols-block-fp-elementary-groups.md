## Statement

Let `R` be a unital ring and `N >= 3`. Let `Sym(R) ⊆ K_2(R)` be the subgroup generated by the
Steinberg symbols `{a, b}` of pairs of commuting units `a, b ∈ R^x`.

1. If `E_N(R)` is finitely presented, then the image of
   `K_2(N, R) = ker(St_N(R) -> E_N(R))` in `K_2(R)` is finitely generated, and it contains
   `Sym(R)`.
2. Hence, if `Sym(R)` is not finitely generated, then:
   - `E_N(R)` is not finitely presented for any `N >= 3`;
   - neither is `E_N(R)/C` for any finite normal subgroup `C`.
   In particular `PE_N(R)` is not finitely presented whenever `Z(E_N(R))` is finite.

## Uses

- **Rational symbols.** If `Q ⊆ R`, then `Sym(R)` contains the image of `K_2(Q)`, since `K_2(Q)`
  is generated by symbols (Matsumoto). It also contains every `{λ, x}` with `λ ∈ Q^x` and
  `x ∈ R^x`.
  - So a ring host with an infinitely generated image of `K_2(Q) -> K_2(R)` fails. This covers
    finitely generated rings built over `L_Q(E)` with `[1]` of infinite order
    (`rational-leavitt-path-k1-k2-scalar-dichotomy`), unless the added generators kill that image.
  - The same applies to rings in which some unit `x` pairs with infinitely many scalars, as in
    `laurent-rational-symbols-block-fp-elementary-groups`.
- **No centrality at rank N.** No hypothesis on `K_2(N, R)` being central in `St_N(R)` is
  needed. Only centrality of stable `K_2(R)` in `St(R)` is used.

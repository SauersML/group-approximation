Notation as in the target. `[g, h] = g h g^(-1) h^(-1)`. `||.||_2` is the normalized trace norm. It is invariant
under left and right multiplication by unitaries. Hence for unitaries `U_1, ..., U_n` and group elements with
`w = w_0 r_1 w_1 r_2 ... r_n w_n`,

```text
|| rho(w) - rho(w_0 w_1 ... w_n) ||_2  <=  sum_l || rho(r_l) - 1 ||_2 .                          (0)
```

This is the only analytic input. Everything else is exact word algebra.

  4 C_1 delta`. If `{i,j} ∩ {k,l}` is empty, the bound is `C_1 delta`." Since `[h, g] = [g, h]^(-1)`, the order of the
  two factors does not matter.
- `positive-characteristic-steinberg-unitary-images-are-finite`, items 1–2: "`I := {a in A : rho(x_12(a)) = 1}` is a

  holds ... for every group generated by root elements over `A` that is a quotient of `St_n(A)`." We apply it with

- `leavitt-cuntz-cone-halves-have-rf-amalgam-cover`: `Delta_+-` is the subgroup of `Delta` generated by the

- `leavitt-st20-nonhyperlinear-iff-cone-bound-and-half-rounding`, item 4 (Mirror): the automorphism

## Step 1. Notation for one reduction

Fix distinct indices `i, a, b, c, k`, `u in R_-`, `v in R_+`, `t = t_j`, `s = s_j'`, `eps = t s = delta_jj'`.
Put

```text
A = x_ia(u)   (Delta_-)        B = x_ab(t)   (Delta_-)        C = x_bc(s)   (Delta_+)
D = x_ck(v)   (Delta_+)        E = x_ac(eps) (Delta_0)
N = [C, D] = x_bk(s v)          F = [E, D] = x_ak(eps v)         (exact in Delta_+)
[A, B] = x_ib(u t)                                               (exact in Delta_-)
X = [[A, B], N] = P^b(u t, s v)       P = [A, F] = P^a(u, eps v) = P^a(eps u, v)
```

In characteristic 2 every root element is an involution, and these are exact relations of the halves. `P^a(u, 0)`
is `[A, 1] = 1`. The relators that occur are

```text
r1 = [A, N] = [x_ia(u), x_bk(s v)]        index pairs (i,a), (b,k) disjoint:   ||rho(r1) - 1|| <= C_1 delta
r2 = [B, D] = [x_ab(t), x_ck(v)]          index pairs (a,b), (c,k) disjoint:   ||rho(r2) - 1|| <= C_1 delta
r3 = [B, C] E^(-1)                         a generator-level Leavitt defect:    ||rho(r3) - 1|| <= c_0 delta
e1 = [E, C],  e2 = [C, F]                  exact in Delta_+ (far roots):        rho(e1) = rho(e2) = 1
```

The bound on `r3` holds because `r3` lies in `K`: in `Delta`, `[x_ab(t_j), x_bc(s_j')] = x_ac(t_j s_j')`. So `r3` is a
product of at most `c_0` conjugates of the `k_i^(+-1)`, and each conjugate moves `rho` by at most `delta`.
The index triples used below are `(a,b,c) in {(4,5,6), (5,4,6)}`, and `j, j'` range over `{1,2}`. So `c_0` is a
maximum over eight fixed elements of `K`, and it does not depend on `u, v, rho`.

## Step 2. Exact identities (free-product word algebra)

The identities below hold in the free product of copies of `Z/2` on the letters `A, B, C, D, E`, using no relations
at all. They are checked mechanically by
`experiments/leavitt-reduction-cost-2026-09-17/verify_leavitt_reduction.py`, checks I1–I6.

```text
(I1)  X = A [BAB, N] A r1
(I2)  [BAB, N] = B [A, BNB] B
(I3)  BNB = r3 E C r2 D r3 E C r2 D
(I4)  E C D E C D = e1 e2 F N
(I5)  [A, F N] = P F r1 F^(-1)
```

Combining (I1) and (I2) gives `X = (AB) [A, BNB] (AB)^(-1) r1`.

*Hand check of (I3).* `BNB = (BCB)(BDB)(BCB)(BDB)`, since `N = CDCD` and `B = B^(-1)`. Then
`BCB = [B, C] C = r3 E C` and `BDB = [B, D] D = r2 D`.

*Hand check of (I4).* `ECDECD = [E, C] CEDECD = e1 CEDECD`. Also
`FN = (EDED)(CDCD) = [F, C] C F DCD = e2^(-1) C EDED DCD = e2^(-1) CEDECD`. So `ECDECD = e1 e2 FN`.

## Step 3. Proof of (LR)

Let `W = BNB`, and let `W' = ECDECD` be `W` with the four relators `r2, r3, r2, r3` deleted. By (0),
`||rho(W) - rho(W')|| <= 2||rho(r2) - 1|| + 2||rho(r3) - 1||`.

By (I4) and `rho(e1) = rho(e2) = 1`, `rho(W') = rho(FN)`. Also `[A, W] = A W A W^(-1)` contains `W` twice, so

```text
|| rho([A, W]) - rho([A, FN]) ||  <=  4||rho(r2) - 1|| + 4||rho(r3) - 1|| .
```

By (I5), `||rho([A, FN]) - rho(P)|| <= ||rho(r1) - 1||`. Finally `X = (AB)[A, W](AB)^(-1) r1` costs one more
`||rho(r1) - 1||`. Altogether, with `g = AB`,

```text
|| rho(X) - rho(g) rho(P) rho(g)^(-1) ||  <=  2 C_1 delta + 4 C_1 delta + 4 c_0 delta  =  c_L delta .
```

This is `(LR)`. For `eps = 0` we have `E = F = P = 1`. The same computation, with `e1, e2` trivial words, gives
`||rho(X) - 1|| <= c_L delta`.

**Sanity check in a genuine ring.** In `EL_7(F_2[x,y]/(x,y)^3)`, all relators are trivial, and the script verifies in
50 random trials that `X = g P g^(-1)` exactly, with `X = x_ik(u t s v)`. This checks only that the letter bookkeeping
matches the Steinberg relations; the proof is the free-product identity.

## Step 4. The chain

Fix `i = 1`, `k = 3`, auxiliary index `c = 6`, and let the middle index alternate between `4` and `5`. Write `P(u, v)`
for `P^m(u, v)` when the middle `m in {4, 5}` is clear. Distinct middles differ only by the `(LR)` bookkeeping, and
every `(LR)` step changes the middle. Write `~` for "equal after a unitary conjugation, up to `||.||_2`-error", and
note that errors add under composition, by unitary invariance.

**Start (exact).** `z = x_13(q) = [x_14(q), x_43(1)] = P^4(q, 1)`. This is a Steinberg relation with entries in
`R_0`, so it is exact in `Delta_0`.

**Backward (L steps).** Let `omega = (w_1, ..., w_L)`. Apply `(LR)` in reverse with `t = t_(w_l)`,
`s = s_(w_l)`, `eps = 1`, for `l = 1, ..., L`, starting from `(u, v) = (q, 1)`. The arguments stay in `R_-` and `R_+`,
because `q, t_i in R_-` and `s_i in R_+`. After `L` steps,

```text
rho(z)  ~  rho(P(q s_omega^*, s_omega)),     error <= L c_L delta.
```

**Swap (exact).** Take `L = L*(J_+)` and distinct `omega != omega'` of length `L` with `s_omega - s_omega' in J_+`.
Then `rho(x_m3(s_omega)) = rho(x_m3(s_omega')) rho(x_m3(s_omega - s_omega')) = rho(x_m3(s_omega'))`, by the imported
fact about `J_+`. Hence

```text
rho(P(q s_omega^*, s_omega)) = rho(P(q s_omega^*, s_omega')).
```

**Forward (at most L steps).** Now `P(q s_omega^*, s_omega') = P(u t_(w_L), s_(w'_L) v')` with
`u = q t_(w_1) ... t_(w_(L-1))` and `v' = s_(w'_(L-1)) ... s_(w'_1)`. Apply `(LR)` forward with `t = t_(w_L)` and
`s = s_(w'_L)`.
- If `w_L = w'_L`, then `eps = 1`, and we get `P(u, v')`, one letter shorter on each side. Repeat.
- At the largest index `l` with `w_l != w'_l`, which exists because `omega != omega'`, we have `eps = 0`, and `(LR)`
  gives `~ 1`.

**Total.** At most `L + L` applications of `(LR)`:

```text
|| rho(z) - 1 ||_2  <=  2 L*(J_+) c_L delta .
```

**Pigeonhole.** There are `2^L` words of length `L`, and `|R_+/J_+| = 2^(D_+)`. So `L = D_+ + 1` forces a collision
of two distinct words, and `L*(J_+) <= D_+ + 1`. Finally `D_+ <= d` by `|R_+/J_+| <= 2^d`. This proves `(HB)`.

## Step 5. Mirror

Let `theta(g) = (g^*)^(-1)`, with `*` the involution of `R` that fixes `F_2`, sends `s_i` to `t_i`, and is
antimultiplicative. On roots, `theta(x_ij(a)) = x_ji(a^*)` in characteristic 2. It sends `R_+` onto `R_-` (note
`q^* = q`) and fixes `Delta_0`. So it lifts to an automorphism `theta~` of `Gamma` that exchanges the factors and
preserves `K`.
- Each `theta~(k_i)` is a product of at most `c_theta` conjugates of the `k_l^(+-1)`. So `rho o theta~` has defect at
  most `c_theta delta`.
- Its `J_+` is `(J_-(rho))^*`, which has the same collision depth as `J_-(rho)` under `omega -> omega`. Indeed,
  `(s_omega)^* = s_omega^*`, and the chain for `rho o theta~` uses the images of Cuntz words.
- `theta~^(-1)(z) = x_31(q)` is conjugate to `z` in `Delta_0` by a permutation matrix.

Step 4 applied to `rho o theta~` gives `||rho(z) - 1|| <= 2 L*(J_-) c_L c_theta delta`, where `L*(J_-)` is the least
length at which two distinct words `s_omega^*` collide modulo `J_-`.

## Step 6. Consequences recorded in the target

- `(QC)` holds in each fixed dimension `d`, with the explicit rate `delta(eps, d) = eps / (2(d + 1) c_L)`.
- A `(QC)` counterexample needs `L*(J_+) >= eps / (2 c_L delta)`, and likewise `L*(J_-)`, up to `c_theta`.
- **Class kill.** Bounded collision depth, and in particular bounded shadow dimension, forces the head bound. This
  does not depend on the dimension, the multiplicity, or the twist.
- **Precise obstruction to going further.** The chain is linear in `L*` because each `(LR)` step reduces one Cuntz
  letter and pays for a generator-level Leavitt defect `r3`.
  - Eliminating the accumulation is exactly the statement that the long defects
    `[x_ab(s_omega^*), x_bc(s_omega')] x_ac(delta_(omega omega'))^(-1)` are uniformly small. With that input, Steps 3–4
    run verbatim with `t = s_omega^*` and `s = s_omega` or `s_omega'`, since `E` is still `x_ac(0 or 1)` in `Delta_0`.
    The chain then has 2 steps.
  - This is recorded as the open node `leavitt-cone-long-leavitt-defects-are-uniformly-small`.

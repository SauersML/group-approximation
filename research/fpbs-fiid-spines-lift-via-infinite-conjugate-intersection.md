**ESTABLISHED (agent-verified, not refereed).** Proof in
`fpbs-fiid-spines-lift-via-infinite-conjugate-intersection-proof`, which
requires only `fpbs-central-z2-groups-have-fiid-sparse-spines` (for the base
case `Z^m`, `m >= 2`).

**Convention.** A finitely generated group `Gamma` *has FIID sparse spines*
if for every finite symmetric generating set `S` and every `eps > 0` there is
a factor-of-iid random subgraph `L` of `Cay(Gamma,S)` that is a.s. connected
and infinite, with `P(o ∈ V(L)) <= eps`. FIID means a `Gamma`-equivariant
measurable function of an iid uniform field on `V ⊔ E`.

**Theorem 1 (lifting).** Let `Gamma` be finitely generated and `H <= Gamma`
a finitely generated subgroup with FIID sparse spines. Put
`Σ_H = {g ∈ Gamma : |H ∩ gHg^-1| = ∞}`. If `Σ_H` generates `Gamma`, then
`Gamma` has FIID sparse spines.

**Corollary 2 (chains).** Let `H_0 <= H_1 <= ... <= H_k = Gamma` be finitely
generated, with `H_0` in class `Z` of
`fpbs-central-z2-groups-have-fiid-sparse-spines` (for example `H_0 ≅ Z^m`,
`m >= 2`), and let each `H_{i+1}` be generated by `Σ_{H_i} ∩ H_{i+1}`.
Then `Gamma` has FIID sparse spines.

**Corollary 3 (members).** The following groups have FIID sparse spines.
- (a) `Gamma_1 x Gamma_2` for finitely generated `Gamma_1`, `Gamma_2` that
  each have an element of infinite order. In particular `F_2 x F_2`, and
  products of nonelementary hyperbolic groups.
- (b) `SL_n(Z)` for `n >= 3`, a Kazhdan group with finite centre.
- (c) Every finitely generated `Gamma` with a finitely generated infinite
  normal subgroup `H` that has FIID sparse spines. Here `Σ_H = Gamma`.

**Consequences.**
- *The root is false on a large class.* `fpbs-no-fiid-sparse-spines-on-nonamenable-groups`
  fails on every nonamenable member above, so the route
  `fpbs-benjamini-schramm-via-no-fiid-sparse-spines` cannot reach the
  flagship.
- *Obstruction (Corollary E of `fpbs-fiid-soft-collapse-iff-fiid-sparse-spines`).*
  On every Cayley graph of every nonamenable member, no argument for
  `p_c < p_u` can succeed if its only inputs are:
  - Bernoulli facts at `p <= p_c`;
  - (S1)--(S4);
  - properties shared by factors of Bernoulli shifts (tempered Koopman
    representation, strong ergodicity, cost of FIID free extensions).

  This covers `F_2 x F_2` (the open product case
  `fpbs-product-no-amenable-wq-normal`) and `SL_n(Z)`.
  - *Invariant:* FIID sparse spines.
  - *Step where every member dies:* the continuation from `p_c` to
    `p_c + eps`. The FIID collapse family of part (iii) of that node has
    `p_u = p_c` and satisfies every listed input.
- *Consistency.* Every member has fixed price one, as Corollary D requires.
  For products and `SL_n(Z)`, `n >= 3`, this was already known (Gaboriau).
  So by Corollary D no group of cost greater than one satisfies Theorem 1's
  hypothesis. In `F_2`, for instance, `Σ_{<a>} = <a>`.

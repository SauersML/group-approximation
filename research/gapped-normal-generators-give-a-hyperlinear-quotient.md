**Statement.** Let `G` be generated by a finite set `S`, and let
`a_1, ..., a_m in G` normally generate `G`. Fix for every `s in S` an
expression

```text
s = product_(j=1)^(ell_s) h_(s,j) a_(i(s,j))^(eps_(s,j)) h_(s,j)^(-1),
                                              eps_(s,j) in {+1,-1},
```

and put `L = m + sum_(s in S) ell_s`. Let `rho : G -> U(Q_d)` be a
nontrivial norm-matrix-corona homomorphism, and let `delta > 0` satisfy,
for every `i`,

```text
sp(rho(a_i)) intersect { lambda : 0 < |lambda - 1| < delta } = empty.   (GNG0)
```

1. **Reblocking.** There are an infinite coordinate set `J`, an index `i*`,
   positive integers `k_n`, and an operator-norm asymptotic representation
   `sigma_n : G -> U(k_n)` (`n in J`) such that, after coordinate unitary
   conjugacy, `sigma_n directSum 1` represents the restriction of `rho` to
   `J`, and

   ```text
   ||sigma_n(a_(i*)) - 1||_(2,tr_(k_n))^2 >= delta^2/(4L) - o(1)   (n in J).  (GNG1)
   ```

2. **Hyperlinear quotient.** For every free ultrafilter on `J`, the image of
   `G` in the tracial matrix ultraproduct defined by `sigma` is a nontrivial
   hyperlinear quotient of `G` in which `a_(i*)` survives. In particular
   `a_(i*)` does not lie in the operator-to-HS shadow residual
   `R_(infinity->2)(G)`.
3. **Finite-order normal generators.** If every `a_i` has finite order, then
   `(GNG0)` holds for every corona map with
   `delta = min_i eta_(ord(a_i))`, where `eta_k = |1 - e^(2 pi i/k)|`. Hence,
   for a finitely generated group normally generated by finitely many
   elements of finite order,

   ```text
   R_(infinity->2)(G) = G   iff   Rad_MF(G) = G,
   ```

   and every nontrivial weak-MF such group has a nontrivial hyperlinear
   quotient.
4. **Critical groups.** Let `R` be finitely generated, nontrivial and weak-MF,
   with no nontrivial hyperlinear quotient (a critical residual in the sense
   of `mf-nonhyperlinear-residual-with-amenable-quotient-is-critical`). Then
   for every finite normal generating set `a_1, ..., a_m` of `R` and every
   nontrivial corona homomorphism `rho` of `R`, the point `1` is an
   accumulation point of `sp(rho(a_i))` for some `i`. In particular `R` is
   not normally generated by finitely many elements of finite order.

**Scope.** The case `m = 1` with `a_1` of finite order is
`torsion-normal-generator-has-full-support-corona-core`, and the proof is the
same span-of-active-ranges argument. Finite order enters only as a supply of
spectral projections at `1`, and `(GNG0)` is exactly what that supply needs.
The spectral hypothesis concerns one given corona map; it is not a
group-theoretic hypothesis unless the generators have finite order. No
novelty is claimed.

**What stays open.** The torsion-free branch: normal generators whose images
have spectrum accumulating at `1` in every corona map. The exact gap is
recorded in `research/artifacts/solve-mf-hyperlinear-quotient-2026-09-13.md`.

Notation as in the target. `n >= 3` throughout. For a set `Y`, `GL_fin(Y)` is the group of invertible `F`-linear maps
of `F[Y]` that differ from the identity in finitely many matrix entries.

## Step 0. Two linear-algebra facts

**(F1) Transvections.** Let `|Y| >= 3`. Then `GL_fin(Y)` is the directed union of the groups `GL(Y_0) = SL(Y_0, F)`
over finite `Y_0 ⊂ Y`. It is generated by the transvections `t_pq = 1 + E_pq` with `p != q`. For distinct
`p, r, q`, the commutator `[t_pr, t_rq] = t_pq`. Each `SL_N(F)` with `N >= 3` is simple, so the directed union
`GL_fin(Y)` is simple when `Y` is infinite.

**(F2) Jordan.** A finite subgroup of `U(d)` has an abelian normal subgroup of index at most `J(d)`. Take `N` with
`|SL_N(F)| > J(d)` and `N >= 3`. The image of the simple group `SL_N(F)` in `U(d)` is then trivial, because a
nonabelian simple image has no nontrivial abelian normal subgroup.

## Step 1. The ring (BC1)

Put `e_ij = z^i e_00 z^(-j)`. On `W`, `e_ij e_k = delta_jk e_i`, so the `e_ij` are the matrix units of `End(W)`.
They satisfy

```text
e_ij e_kl = delta_jk e_il,   z e_ij = e_(i+1, j),   e_ij z = e_(i, j-1).
```

Hence `I = span{e_ij}` is a two-sided ideal of the subring generated by `z, z^(-1), e_00`, and
`R_bi = A + I`.

A nonzero Laurent operator `sum c_d z^d` has infinitely many nonzero matrix entries, so `A ∩ I = 0` and
`R_bi / I = A`. The same holds for `J`: `JQJ = span{S^i Q T^j}` is the span of the matrix units of `End(F[N])`,
and `J / JQJ = A` with `S -> z`, `T -> z^(-1)`.

**Finite right modules.** Let `M` be a finite right `R_bi`-module, and suppose `m e_00 != 0` for some `m`. Then
`m e_00 = (m e_0i) e_i0`, so `m e_0i != 0`, and `m e_0i = (m e_0i) e_ii`. So `M e_ii != 0` for every `i`.

Put `P_N = sum_(|i| <= N) e_ii`. Then `M P_N` is a nonzero unital module over `P_N R_bi P_N`, which contains the
matrix units `e_ij`, `|i|, |j| <= N`. So `M P_N` is a nonzero unital `M_(2N+1)(F)`-module and has dimension at
least `2N + 1`. For large `N` this contradicts finiteness of `M`.

## Step 2. The group (BC2)

Let `X = Z x {1..n}`, so that `R_bi^n = F[X]`. Then `M_n(R_bi) = M_n(A) + M_n(I)`, and `M_n(I)` is the set of
finitary matrices on `X`.

**Inclusion `⊆`.** Write `r = a + f` with `a in A` and `f in I`. Then `x_ij(r) = x_ij(a) x_ij(f)`, and
`x_ij(f)` is unipotent and finitary, so it lies in `GL_fin(X)`. Laurent matrices have finite propagation, so
`EL_n(A)` normalizes `GL_fin(X)`. Hence `EL_n(R_bi) <= GL_fin(X) EL_n(A)`.

The product is semidirect. A nonidentity element of `EL_n(A)` differs from `1` in infinitely many entries, so
`EL_n(A) ∩ GL_fin(X) = 1`.

**Inclusion `⊇`.** It suffices to show `t_pq in EL_n(R_bi)` for `p = (a, i)` and `q = (b, j)`, by (F1).
* If `i != j`, then `t_pq = x_ij(e_ab)`.
* If `i = j`, pick `k != i` and `r = (0, k)`. Then `t_pq = [x_ik(e_a0), x_ki(e_0b)]`.

So `EL_n(R_bi) = GL_fin(X) ⋊ EL_n(A)`. This is literally the group `L ⋊ Q` of
`untwisted-bilateral-symbol-enrichment-is-lef`, with the same action by conjugation on `F[X] = A^n`.

**Consequences.**
* **(T).** `R_bi` is finitely generated (Step 1) and `n >= 3`, so `EL_n(R_bi)` has (T) by
  `elementary-groups-over-fg-rings-have-property-t`. It is finitely generated by the `x_ij(z^(±1))` and `x_ij(e_00)`.
* **LEF.** By `untwisted-bilateral-symbol-enrichment-is-lef`.
* **Representations.** Let `phi` be a finite-dimensional unitary representation of dimension `d`. By (F2),
  `phi` kills `SL(Y_0)` for every large finite window `Y_0`. The normal subgroup `ker phi ∩ GL_fin(X)` of the simple
  group `GL_fin(X)` is nontrivial, so it is everything. A finite quotient composed with its regular representation is
  such a `phi`, so every finite quotient kills `GL_fin(X)`.
* **Not residually finite.** This follows from the representation fact, since `GL_fin(X) != 1`.
* **Not finitely presented.** A finitely presented LEF group is residually finite (Gordon–Vershik). The group is
  LEF and not residually finite.

## Step 3. Ray gluing (BC3)

Let `phi : W -> F[N]^2` be the basis bijection `e_k -> (e_k, 0)` for `k >= 0` and `e_(-1-k) -> (0, e_k)`. Put
`rho(a) = phi a phi^(-1)`. This is an injective ring map `End(W) -> End(F[N]^2) = M_2(End F[N])`.

**`J` acts faithfully on `F[N]`.** `J` has the basis `S^a T^b`, with `a, b >= 0`, because `TS = 1`. For a nonzero
`x = sum c_ab S^a T^b`, let `b_0` be minimal with some `c_(a, b_0) != 0`. Then
`x e_(b_0) = sum_a c_(a, b_0) e_a != 0`, because `T^b e_(b_0) = 0` for `b > b_0`.

**Generators.** On basis vectors:
* `z` sends `(e_k, 0) -> (e_(k+1), 0)`, `(0, e_0) -> (e_0, 0)`, and `(0, e_(k+1)) -> (0, e_k)`. So
  `rho(z) = [[S, Q], [0, T]] = u`.
* Symmetrically, `rho(z^(-1)) = [[T, 0], [Q, S]]`.
* `rho(e_00) = diag(Q, 0)`.

These matrices lie in `M_2(J)`, so `rho(R_bi) ⊂ M_2(J)`. The inverse relation `u u^(-1) = u^(-1) u = 1` is the set of
`J`-identities `ST + Q = 1`, `QS = 0`, `TQ = 0` and `TS = 1`.

**Ideal and symbol.**
* `rho` maps the matrix units of `W` to the matrix units of `F[N]^2`, so `rho(I) = M_2(JQJ)`.
* Reducing entries mod `JQJ` gives `pi(rho(z)) = diag(z, z^(-1))` and `pi(rho(e_00)) = 0`. By multiplicativity,
  `pi(rho(a)) = diag(a(z), a(z^(-1)))`.

The experiment checks all of this numerically on a window of `Z`, including 200 random products.

**Matrices.** `M_n(rho) : M_n(R_bi) -> M_(2n)(J)` is an injective ring map. For `i != j` it sends
`x_ij(r)` to `1 + E_ij ⊗ rho(r)`. That is the product of the four commuting elementary matrices
`x_((i,s),(j,t))(rho(r)_st)`, `s, t in {+, -}`. So `M_n(rho)` embeds `H_bi(n)` in `EL_(2n)(J)`.

**The image is `pi^(-1)(Gamma^tw)`.**
* `ker(pi|EL_(2n)(J))` consists of invertible elements of `1 + M_(2n)(JQJ)`. These are the finitary invertible
  maps of `F[N x {1..2n}]`, so the kernel is `GL_fin(N x {1..2n}) = L_(2n)`. The reverse inclusion
  `L_(2n) <= EL_(2n)(J)` follows from (F1) exactly as in Step 2.
* Because `phi` is a basis bijection, `M_n(rho)` maps `GL_fin(X)` onto `L_(2n)`.
* `pi M_n(rho)` maps `EL_n(A)` isomorphically onto `Gamma^tw`.
* Let `h in pi^(-1)(Gamma^tw)`. Choose `g in EL_n(A)` with the same symbol as `h`. Then
  `h rho(g)^(-1) in L_(2n) <= rho(H_bi(n))`.

`rho(EL_n(A))` is a complement to `L_(2n)`, so the extension splits over `Gamma^tw ≅ EL_n(A) = SL_n(A)`, a
Kazhdan group. The head is `rho(x_13(e_00)) = 1 + E_13 ⊗ diag(Q, 0) = x_((1,+),(3,+))(Q)`. Since
`diag(z, z^(-1), 1, ..., 1) in EL_n(A)` (Whitehead), `diag(u, u^(-1), 1, ..., 1)` is in the image.

## Step 4. Decomposition (BC4)

`pi : EL_(2n)(J) -> SL_(2n)(A)` is onto, since `x_pq(S)` and `x_pq(T)` lift `x_pq(z^(±1))` and
`SL_(2n)(A) = E_(2n)(A)` (`A` is Euclidean). Both `H_+` and `rho(H_bi(n))` contain `ker pi = L_(2n)`. So it suffices
to show that `SL_(2n)(F[z])` and `Gamma^tw` generate `E_(2n)(A)`, that is, to produce every `x_pq(z^(-k))`, `k >= 1`.

* **Same sign, different blocks.** Let `i != j`. `Gamma^tw` contains
  `x_((i,+),(j,+))(z^(-k)) x_((i,-),(j,-))(z^k)`. The second factor is polynomial, which gives
  `x_((i,+),(j,+))(z^(-k))`. Symmetrically, `x_((i,-),(j,-))(z^(-k))` comes from
  `x_((i,+),(j,+))(z^k) x_((i,-),(j,-))(z^(-k))`.
* **Any `p != q`.** Say `p = (i, s)`. Since `n >= 3`, pick `j` different from `i` and from the block of `q`, and put
  `r = (j, s)`. Then `x_pq(z^(-k)) = [x_pr(z^(-k)), x_rq(1)]`, with `x_rq(1)` polynomial.

**Intersection.** `H_+ ∩ rho(H_bi(n)) = pi^(-1)(SL_(2n)(F[z]) ∩ Gamma^tw)`. If `a(z)` and `a(z^(-1))` both lie in
`F[z]`, then `a` is constant. So the symbol intersection is `rho(SL_n(F))`, which is finite, and the intersection is
`L_(2n) ⋊ SL_n(F)`, locally finite by finite.

## Step 5. Class kill (BC5)

`G = rho(H_bi(n))` has every listed property:
* **(T)**, by Step 2, and so relative (T) for every pair `(G, N)`.
* **The simple ideal.** `L_(2n)` is locally matricial and simple (F1). Finite right modules kill `e_00` (Step 1),
  and finite-dimensional unitary representations kill `L_(2n)` (Step 2).
* **Kernel and quotient.** The kernel is `GL_fin`, and the quotient is `Gamma^tw ≅ SL_n(A)`.
* **Exact degree control.** For `t = diag(z, z^(-1), 1, ..., 1)`, `t x_13(r) t^(-1) = x_13(z r)`. Under `rho`,
  conjugation by the compressor pair sends the head `x_((1,+),(3,+))(Q)` exactly to `rho(x_13(e_10))`.
* **Root identities.** Every finitary root element `x_pq(f)`, `f in JQJ`, lies in `L_(2n) <= G`, so every finitary
  root identity of `EL_(2n)(J)` holds in `G`.

`G` is LEF by Step 2. Take a finite ball `B` of `G` containing the head `h`, and a finite group `K` with a partial
injective homomorphism on `B`. The image of `h` is not `1`, so its normalized trace in the left regular
representation of `K` is `0`. Hence "the head has trace tending to `1` in every sofic, hyperlinear or LEF
approximation" fails for `G`.

Any argument proving that conclusion from the listed properties alone would prove it for `G`. So it is invalid. The
fixed-dimension kill in Step 2 depends on `d` through `J(d)`. The finite models of `G` have `d -> infinity`, and
this is the interchange of `lim_k` and `sup_H` recorded in the target.

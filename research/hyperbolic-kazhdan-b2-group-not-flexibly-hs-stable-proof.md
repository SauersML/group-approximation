Fix `g >= 2`. Write `Γ = Γ_g = Z^(2g) ⋊ Sp_(2g)(Z)`,
`ω(x,y) = Σ_i (x_i y_(g+i) - x_(g+i) y_i)`, and let `Γ~` be the integral Heisenberg cover,
`(v,s,A)(w,t,B) = (v+Aw, s+t+ω(v,Aw), AB)`, with central element `z = (0,1,1)` and
`Γ~/⟨z⟩ = Γ` (`rf-kazhdan-group-not-flexibly-hs-stable`, item 2).

Standard facts used without registration (Bekka--de la Harpe--Valette, Ch. 1; Bridson--Haefliger
III.Γ; P. Hall's extension lemma):

- (T) passes to quotients and to finite-index subgroups, and is closed under extensions.
- A finitely generated Kazhdan group has finite abelianization, and `Z` is not Kazhdan.
- Word-hyperbolic groups are finitely presented.
- An extension of a finitely presented group by a finitely presented group is finitely
  presented.

One literature input is not a registered node:

- `Sp_(2g)(Z)` is finitely presented. It is an arithmetic group, and arithmetic groups are
  finitely presented: Raghunathan (1968), or Borel--Serre, *Corners and arithmetic groups*
  (1973). So `Γ`, an extension of `Sp_(2g)(Z)` by `Z^(2g)`, is finitely presented.

## 1. The cover

By `torsion-free-hyperbolic-kazhdan-partner-exists`, fix `H` finitely presented,
torsion-free, non-elementary, word-hyperbolic and Kazhdan. `Γ` is finitely presented (above).
By `belegradek-osin-rips-construction`, there is an exact sequence
`1 -> N -> G -> Γ -> 1` in which:

- `G` is word-hyperbolic;
- `N` is a quotient of `H`;
- `G` is torsion-free, because `H` is.

Consequences:

- **(T).** `N` is Kazhdan as a quotient of `H`. `Γ` is Kazhdan
  (`rf-kazhdan-group-not-flexibly-hs-stable`, item 1). So `G` is Kazhdan, since (T) is closed
  under extensions.
- **Finite presentation.** `G` is hyperbolic, hence finitely presented.
- **Non-elementary.** `G` surjects onto the infinite group `Γ`, so `G` is infinite. A
  virtually cyclic infinite group has a finite-index subgroup `Z`, which is not Kazhdan. So `G`
  is not elementary.

This proves items 1 and 2 of the claim.

## 2. Instability (item 4)

`G` is finitely generated, and `N` is a normal subgroup with property (T). Suppose `G` were
flexibly HS-stable. Then `flexible-hs-stability-passes-to-kazhdan-kernel-quotients` would
make `G/N ≅ Γ` flexibly HS-stable. This contradicts `rf-kazhdan-group-not-flexibly-hs-stable`,
item 2. So `G` is not flexibly HS-stable.

**An explicit non-roundable asymptotic representation of `G`.** Let `q : G -> Γ` be the
quotient map and `α_k` the models of `rf-kazhdan-group-not-flexibly-hs-stable`, item 2. Put
`β_k = α_k ∘ q`. The proof of `flexible-hs-stability-passes-to-kazhdan-kernel-quotients`
shows that a rounding of `β_k` yields a rounding of `α_k`: the kernel `N` acts trivially
through `β_k`, and a Kazhdan pair for `N` pushes the stable corner onto the `N`-fixed
subspace. So `β_k` does not round.

## 3. Second Betti number (item 3)

**(a) `b_2(Γ;Q) >= 1`.** The five-term exact sequence of the central extension
`1 -> ⟨z⟩ -> Γ~ -> Γ -> 1` with integral coefficients reads

```text
H_2(Γ;Z) -> Z -> H_1(Γ~;Z) -> H_1(Γ;Z) -> 0.
```

Here `Z = H_1(⟨z⟩;Z)`, and `Γ` acts trivially because `z` is central. We claim `H_1(Γ~;Z)` is
finite.

- Put `x_w = (w,0,1)` and `y_A = (0,0,A)`. Then `x_v x_w = (v+w, ω(v,w), 1)`, so
  `[x_v, x_w] = z^(2ω(v,w))`. Choosing `ω(v,w) = 1` gives `z^2 ∈ [Γ~,Γ~]`.
- `y_A x_w y_A^(-1) = x_(Aw)` and `x_w x_u = z^(ω(w,u)) x_(w+u)`. So in `Γ~^ab/⟨[z]⟩` the map
  `w -> [x_w]` is a homomorphism that is constant on `Sp_(2g)(Z)`-orbits.
- The transvection `T_u(x) = x + ω(u,x)u` lies in `Sp_(2g)(Z)`, and `x_(T_u x) ≡ x_x` gives
  `[x_(ω(u,x)u)] = 0`. Taking `x` with `ω(u,x) = 1` kills `[x_u]` for every `u`.
- So the `x_w` contribute at most the image of `⟨[z]⟩`, which has order `<= 2`.
- The `y_A` contribute the image of `Sp_(2g)(Z)^ab`, which is finite because `Sp_(2g)(Z)` is
  Kazhdan for `g >= 2` (quotient of `Γ`).
- Since `Γ~` is generated by the `x_w`, the `y_A` and `z`, `Γ~^ab` is finite.

This is `rf-kazhdan-group-not-flexibly-hs-stable-proof`, §3, repeated so that this route does
not rely on the interior of that proof.

The map `Z -> H_1(Γ~;Z)` therefore has finite image, so its kernel is nonzero. By exactness,
`H_2(Γ;Z) -> Z` is nonzero, so `H_2(Γ;Z)` contains an element of infinite order. Hence
`H_2(Γ;Q) = H_2(Γ;Z) ⊗ Q ≠ 0`, and `b_2(Γ;Q) >= 1`.

**(b) `b_2(G;Q) >= b_2(Γ;Q)`.** The Lyndon--Hochschild--Serre five-term sequence of
`1 -> N -> G -> Γ -> 1` with rational coefficients reads

```text
H_2(G;Q) -> H_2(Γ;Q) -> H_1(N;Q)_Γ -> H_1(G;Q) -> H_1(Γ;Q) -> 0.
```

`N` is a quotient of the finitely generated group `H`, so it is finitely generated. It is
Kazhdan, so `N^ab` is finite and `H_1(N;Q) = 0`. So `H_2(G;Q) -> H_2(Γ;Q)` is onto. ∎

## 4. The pulled-back central extension (item "Moreover")

Let `G~ = G ×_Γ Γ~ = {(x, y) : q(x) = p(y)}`, where `p : Γ~ -> Γ` is the quotient map.

- **Central `Z`.** `(1, z^s)` is central in `G~`, and `G~/⟨(1,z)⟩ ≅ G`.
- **(T).** The projection `G~ -> Γ~` is onto, with kernel `{(n,1) : n ∈ N} ≅ N`. `Γ~` is a
  central extension of the Kazhdan group `Γ` with finite abelianization (§3a), so it is Kazhdan
  by `bdhv-central-extension-property-t`. `N` is Kazhdan. So `G~` is Kazhdan by closure under
  extensions.
- **Finite abelianization.** `N^ab -> G~^ab -> Γ~^ab -> 0` is exact, and both outer groups are
  finite.
- **Centre survives.** For `k >= 3`, compose `G~ -> Γ~ -> Q~_k = Γ~ mod k`
  (`rf-kazhdan-group-not-flexibly-hs-stable`, item 2). The image of `(1,z)` is `z mod k`, which
  has order exactly `k`.

This section is not used for items 1--4. It records that the instability of `G` is exactly
the Ioana--Spaas--Wiersma central gate, realized on a hyperbolic group.
`bdhv-central-extension-property-t` enters only here.

## 5. Calibration and scope

- **Calibration.** The mechanism reproduces a known statement: it must, and does, refuse to
  stabilize `Γ_g` itself, since it starts from that.
- **Not a known-false output.** It does not predict instability of every hyperbolic Kazhdan
  group. Free groups are flexibly stable and are not Kazhdan. Finite groups are stable and
  are elementary. So the output is consistent with the known cases.
- **What fails where.** In `classwide-hyperbolic-kazhdan-hs-stability-proof`, step 4 assumes
  the Belegradek--Osin cover `G` of a finitely presented Kazhdan `Q` is flexibly stable. For
  `Q = Γ_g` that premise is false, by §2.

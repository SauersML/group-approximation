Write `S = S_N`, `K = K_2(N, R_L)`, `E = E_N(R_L)`, and `A = A_N`.

**Inputs.**
- **(K)** `K ≅ Q^x` is central in `S` (`leavitt-resolvent-k2-stability-holds`, items 2 and 3).
- **(P)** `S` and `E` are perfect, since `X_ij(c) = [X_ik(c), X_kj(1)]` for a third index `k`.
- **(D)** Every normal subgroup of `E` not contained in `Z_E` equals `E`. This is part 1 of
  `leavitt-steinberg-hosts-must-live-in-the-stabilization-kernel`. Its hypotheses are two-sided division, which
  `leavitt-resolvent-ring-has-two-sided-division` proves for `R_L`, and the Leavitt pair `s_i, t_i`.

**Item 1.**
- *`A` is central.* Let `a ∈ A`. For `x ∈ S`, `φ([a, x]) = [φ(a), φ(x)] = 1`, so `[a, x] ∈ K`.
  - Since `K` is central, `[a, xy] = [a, x] · x[a, y]x^(-1) = [a, x][a, y]`.
  - So `x -> [a, x]` is a homomorphism from the perfect group `S` to the abelian group `K`. It is trivial, and `a`
    is central.
  - Conversely `φ` is onto, so it maps `Z(S)` into `Z_E`. Hence `A = Z(S)`.
- *Normal subgroups.* Let `M ⊴ S`. Then `φ(M) ⊴ E`.
  - If `φ(M) ⊄ Z_E`, then `φ(M) = E` by (D), so `S = MK`. Then `S/M` is a quotient of the abelian group `K`, and
    `S = M` by (P).
  - Otherwise `φ(M) ⊆ Z_E`, so `M ⊆ A`.
- *Simple quotients.* A normal subgroup of `S/A` pulls back to some `M ⊇ A`, which is `A` or `S`. So
  `S/A ≅ E/Z_E = PE_N(R_L)` is simple, and it is nonabelian because `E` is perfect and nontrivial.
  - If `S/M` is simple, then `M ≠ S`, so `M ⊆ A`. The image of `A` is a central normal subgroup of the nonabelian
    simple group `S/M`, so it is trivial, and `M = A`.
  - The same argument in `E`, with (D) in place of the first bullet, shows that `Z_E` is the only normal subgroup
    of `E` with simple quotient.

**Item 2.** `φ` restricts to a surjection `A -> Z_E` with kernel `K`. For `λ ∈ Q^x`, `λ I_N ∈ E`
(`ibn-failure-makes-rational-scalars-elementary`, part 3, case `d = 2`), and `λ` is central in `R_L`. So
`Z_E ⊇ Q^x I_N`. `K ≅ Q^x` is not finitely generated, so neither is `A`.

**Item 3.**
- **`H_2(S) = 0`.** van der Kallen, *Injective stability for K_2*, Lecture Notes in Math. 551 (1976), §8.1, p. 147,
  read at source (scan in the lane source cache, `gq/src/k2/vdk.pdf`). In paraphrase:
  - if `K_2(n,R) -> K_2(R)` is injective, then `K_2(n,R)` is central in `St(n,R)`, and for `n >= 3` there is a
    surjection `H_2(E(n,R)) -> K_2(n,R)`;
  - it is an isomorphism exactly when `H_2(St(n,R)) = 0`, and of that condition he writes: "This condition is
    satisfied if n ≥ 5." No hypothesis on `R` is imposed there.
  - For `N = 3, 4`, the refinement isomorphisms `St_3(R_L) ≅ St_4(R_L) ≅ St_5(R_L)`
    (`leavitt-refinement-identifies-unstable-k2-levels`, item 1) give `H_2(S_N) = H_2(S_5) = 0`.
- **Universal central extensions** (Milnor, §5, recalled). If `G` is perfect, a central extension `X -> G` with `X`
  perfect and `H_2(X) = 0` is universal, and its kernel is `H_2(G; Z)`.
  - `S -> E` has kernel `K`, which is central by (K). So `H_2(E; Z) ≅ K ≅ Q^x`. This is also van der Kallen's statement,
    since `U_N = 1`.
  - `S -> PE_N(R_L)` has kernel `A`, which is central by item 1. So `H_2(PE_N(R_L); Z) ≅ A`.
- A finitely presented group has finitely generated `H_2`, so `PE_N(R_L)` is not finitely presented.

**Item 4.**
- By `leavitt-pair-centralizers-embed-e-n-in-st-3n-plus-1`, part 2, with `S = R_L` and the central subring `Q`,
  there is an injective homomorphism `ι : SL_m(Q) -> St_10(R_L)` for every `m = 3k`. Choose `m >= n + 2`.
- Embed `GL_n(Q)` in `SL_m(Q)` by `g -> diag(g, det(g)^(-1), I_(m-n-1))`. The last diagonal entry is `1`, so no
  element other than `1` maps to a scalar matrix. So the image meets `Z(SL_m(Q))` trivially.
- If `ι(h) ∈ Z(S_10)`, then `ι(h)` commutes with `ι(SL_m(Q))`. Since `ι` is injective, `h ∈ Z(SL_m(Q))`. So the image
  of `GL_n(Q)` meets `Z(S_10)` trivially, and `S_10 -> S_10 / Z(S_10) = PE_10(R_L)` is injective on it.
- `PE_10(R_L)` has solvable word problem (`leavitt-resolvent-ring-has-two-sided-division`, item 3). `St_10(R_L)` is
  finitely presented and Kazhdan (`steinberg-finite-presentation-and-kazhdan-theorem`).
- **The finitely generated centre remark.** If `Γ` is finitely presented and `Z(Γ)` is generated by `z_1, ..., z_k`,
  then `Γ / Z(Γ)` is presented by the relators of `Γ` together with `z_1, ..., z_k`.

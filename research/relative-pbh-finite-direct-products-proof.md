Notation as in the target. Write S = S_1 ⊔ S_2 and let (g_1, g_2) act on s ∈ S_i
by g_i·s.

**1. Type [A_2].**
- **Finite presentation.** G_1 x G_2 is finitely presented, since each G_i is.
- **Point stabilizers.** For s ∈ S_1, Stab_G(s) = Stab_(G_1)(s) x G_2. It is
  finitely generated because Stab_(G_1)(s) is, and G_2 is finitely presented. The
  case s ∈ S_2 is symmetric.
- **Orbits on S x S.** Split S x S into four blocks.
  - On S_1 x S_1, G_2 acts trivially, so the G-orbits there are the G_1-orbits.
    There are finitely many.
  - S_2 x S_2 is the same with the roles exchanged.
  - The orbit of (s_1, s_2) ∈ S_1 x S_2 is (G_1 s_1) x (G_2 s_2). Each S_i has
    finitely many G_i-orbits, since finitely many orbits on S_i x S_i give
    finitely many on its diagonal. So this block has finitely many orbits.
  - S_2 x S_1 is the same.
- **Kernel.** (g_1, g_2) fixes every point of S exactly when g_1 fixes S_1 and
  g_2 fixes S_2. Here we use that both S_i are nonempty. So the kernel is
  K_1 x K_2, and G/K = (G_1/K_1) x (G_2/K_2) acts on S_1 ⊔ S_2 by the induced
  actions.

**2. Sharp embedding.** Let ι_i: Γ_i → G_i be injective with ι_i(Γ_i) ∩ K_i = {1}.
Then ι = ι_1 x ι_2 is injective and
ι(Γ_1 x Γ_2) ∩ (K_1 x K_2) = (ι_1(Γ_1) ∩ K_1) x (ι_2(Γ_2) ∩ K_2) = {1}.

**3. Removability.** Let j_i: G_i → G_i′ be injective with
j_i(G_i) ∩ K_i′ = j_i(K_i), and let K_i′ be the normal closure in G_i′ of a finite
set F_i.
- **The product actor.** By part 1 applied to the actions of G_i′ on S_i′,
  G_1′ x G_2′ acts on S_1′ ⊔ S_2′ with type [A_2] and kernel K_1′ x K_2′.
- **The embedding.** With j = j_1 x j_2,
  j(G_1 x G_2) ∩ (K_1′ x K_2′) = (j_1(G_1) ∩ K_1′) x (j_2(G_2) ∩ K_2′) = j(K_1 x K_2).
- **Finite normal generation.** The normal closure of F_1 x {1} in G_1′ x G_2′ is
  K_1′ x {1}, and similarly for F_2. So K_1′ x K_2′ is normally generated by the
  finite set (F_1 x {1}) ∪ ({1} x F_2).

Induction on the number of factors gives every finite product.

## Setting

- `p` is a prime, `R = F_p[t,t^-1]`, and `M = R^2` (column vectors).
- `M^ = Hom(M, F_p)` is identified with `(F_p^2)^Z` via
  `<(a,b),(α,β)> = Σ_k a_k α_k + b_k β_k`, where `a = Σ a_k t^k`.
  It is a compact abelian group under the product topology.
- `σ` is the shift `(σα)_k = α_(k+1)`. Multiplication by `t` on `M` is adjoint to `σ`.
- `GL_2(R)` acts on `M^` on the left by `γ·χ = χ∘γ^-1`, i.e. by `(γ^-1)^T(σ)`. On generators:

| element | action on `(α, β)` |
|---|---|
| `e_12(r)` | `(α, β − r(σ)α)` |
| `e_21(r)` | `(α − r(σ)β, β)` |
| `h = diag(t, t^-1)` | `(σ^-1 α, σ β)` |
| `w = [[0,1],[-1,0]]` | `(β, −α)` |

- An **affine map** of `M^` is `ξ ↦ γ·ξ + v` with `γ ∈ GL_2(R)` and `v ∈ M^`.
- A continuous `φ : C^n → M^` is **affinely spanning** if no nonzero `m ∈ M` makes
  `x ↦ φ(x)(m)` constant. Every surjective `φ` is affinely spanning.

## Theorem R (criterion)

Suppose there are:
- `n ≥ 1`;
- a continuous affinely spanning `φ : C^n → M^`;
- elements `g_1, ..., g_k ∈ nV` and affine maps `a_i(ξ) = γ_i·ξ + v_i` with `φ∘g_i = a_i∘φ`;
- such that `⟨γ_1, ..., γ_k⟩ ⊇ EL_2(R)`.

Then `nV` does not have the Haagerup property. More precisely, `nV` contains a subgroup
`G = M' ⋊ Λ`, where:
- `M' ≤ C(C^n, F_p)` is an infinite elementary abelian `p`-group;
- `(G, M')` has relative property (T).

The same holds with `R` any finitely generated infinite commutative unital `F_p`-algebra, `M = R^2`,
and `M^ = Hom(M, F_p)` with the pointwise topology.

**Generators.** `EL_2(R)` is generated by `e_12(1)`, `e_12(t)`, `e_21(1)`, `e_21(t)` and `h`. So for
`R = F_p[t,t^-1]` it suffices to lift five explicit linear cellular automata of `(F_p^2)^Z`, all
five with the same `φ`.

## Proposition B (the torus generator lifts in 2V)

Let `B(au, y) = (u, ay)` be the baker map on `C^2`, for `a ∈ {0,1}`. Then `B ∈ 2V`. Take `k` with
`2^k ≥ p^2` and a surjection `τ : {0,1}^k → F_p^2`. Then there is an explicit continuous
**surjective** `φ : C^2 → M^` with `φ∘B^k = h·φ`. For `p = 2` and `k = 2` this `φ` is a homeomorphism.

So in dimension 2 the torus generator is free. The whole problem is to lift the four shears, or
`e_12(1)`, `e_12(t)` and `w`, for **the same** `φ`. That lifting problem is the open claim
`brin-thompson-2v-lifts-el2-laurent-linear-ca-generators`.

## What this changes

- It is a new decomposition of `brin-thompson-2v-is-not-a-t-menable`: imported relative (T), plus a
  purely dynamical lifting problem about finitely many cellular automata. There is no analytic step
  left.
- For `n = 1` the conclusion is false, because `V` is Haagerup (Farley). So **no** such `φ` and
  lifts exist in `V`, for any `p`. This is a non-trivial statement about finitary maps of `C`.
- `injective-char-p-lamp-realizations-miss-fixed-points` shows the lift cannot be a conjugacy onto
  `M^` when `p ≥ 3`. It also forces the linear, injective version to miss `0`.
- `lamp-realized-burger-modules-have-positive-characteristic` shows positive characteristic is
  forced: over `Z`, `Z[1/2]` or `Z[t^±]` no lamp realization exists at all.

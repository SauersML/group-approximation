**Step 1: a countable mixed monoid.**
* `opr-mixed-simple-refinement-monoid` (OPR Proposition 5.17) gives a simple
  conical refinement monoid `M` and a nonzero `u in M` that is finite while
  `2u` is properly infinite.  So there is `w` with `2u + 2u + w = 2u`.
* Let `M_0` be the submonoid generated by `u` and `w`.  Given a countable
  submonoid `M_k`, add:
  * a refinement matrix for every equation `a_0 + a_1 = b_0 + b_1` in `M_k`;
  * for all `x != 0` and `y` in `M_k`, an integer `n` and an element `z` with
    `y + z = n x`.
* Let `M_(k+1)` be the submonoid generated, and `M' = union_k M_k`.
* `M'` is a countable submonoid of `M`.  It is conical, has refinement, and is
  simple.
* `u` is finite in `M'`: if `u + eta = u` with `eta in M'`, then `eta = 0` in
  `M`.
* `2u` is properly infinite in `M'`, because `w in M'`.
* `M'` is not `Z^+`, which has no infinite element, and `M' != {0}`.

**Step 2: realization.**  Apply `simple-refinement-monoids-are-minimal-cantor-types`
to `(M', u)`.  This gives a countable group `Gamma` and a minimal action on the
Cantor space `X` with `(S(X, Gamma), [1_X]) ≅ (M', u)`.

**Step 3: no invariant probability measure.**  An invariant measure would give
a state `s` with `s(u) = 1`.  Applying it to `2u + 2u + w = 2u` gives
`4 + s(w) = 2`, which is impossible.

**Step 4: the finite clopen class.**  `[1_X] = u` is finite in `S(X, Gamma)`,
so `A = X` works.  Geometrically:
* every injection `X -> X` that is piecewise a translation, with finitely many
  clopen pieces, is onto;
* two disjoint copies of `X` contain, in the same piecewise sense, four
  disjoint copies of `X`.

**Additional features.**
* `S(X, Gamma)` has no nontrivial state and is not purely infinite.
* It is not separative: with `r = 2u + w`, the elements `x = u` and
  `y = u + r` satisfy `2x = x + y = 2y` but `x != y`, as in
  `stw29-separative-projection-monoid-dichotomy-proof`, part 1.

**Limits.**  The action is not known to be topologically free (see the limits
recorded in `simple-refinement-monoids-are-minimal-cantor-types`).  So it does
not feed Rainone's Theorems 4.16 and 4.21, and it does not give a simple
crossed product.  The topologically free question is
`topologically-free-minimal-cantor-action-with-finite-clopen-type`.

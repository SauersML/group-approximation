Write `p = u v^∞` with `|v| = r` the least eventual period of `p`, and `p_n` for the `n`-th
letter. Let `w_n = p_1 … p_n`.

## 1. `(B)_p ≅ Z`

Let `b ∈ B` fix `p`. Near `p` it is a prefix replacement `αη ↦ βη` with `α < p`, `β < b(p) = p`
and `Fol(α) = Fol(β)`. Since `b(p) = p`, the suffix of `p` after `α` equals the suffix after
`β`. Two suffixes of an eventually periodic word at positions `≥ |u|` are equal if and only if
the positions are congruent mod `r`, so `|β| − |α| ∈ rZ` once `|α|, |β| ≥ |u|`, which we may
assume after lengthening `α`.

Define `σ(b) = |β| − |α| ∈ rZ`. This depends only on the germ of `b` at `p`: if two prefix
replacements agree near `p`, their composition with one inverse fixes a neighbourhood of `p`
pointwise, and such a map has `|α| = |β|`. It is a homomorphism, because composing prefix
replacements adds the length differences.

`σ` is injective on germs. Suppose `σ(b) = 0` but `b` is not the identity near `p`; then
`α = β` (prefixes of `p` of equal length), so `b` is the identity on `[α] ∋ p`, a
contradiction. Suppose instead `σ(b) = d ≠ 0`, say `d > 0`, and `b` is the identity on some
cylinder `[γ] ∋ p` with `|γ| ≥ |α|`. Then `b([γ]) = [γ']` where `γ'` is the prefix of `p` of
length `|γ| + d`, so `[γ] = [γ']`. Iterating, `[γ] = [γ'']` for prefixes `γ''` of `p` of
arbitrarily large length, hence `[γ] = {p}`, contradicting that `∂L` has no isolated points.

So `(B)_p` embeds in `rZ ≅ Z` via `σ`. It is nontrivial: the set of `m > 0` such that the shift
`u v^k η ↦ u v^{k + m/r} η` is a legal prefix replacement is nonempty, because the letter
sequence and the `∂L` automaton state along `p` are both eventually periodic, so for any common
period `m` of the two and any large `k` we have equal suffixes and `Fol(w_k) = Fol(w_{k+m})`.
Hence `(B)_p` is a nontrivial subgroup of `Z`, so infinite cyclic, generated by the shift with
the least such `m`. ∎

## 2. The germ rate

Let `h` be rational with `h(p) = p`. The transducer state after reading `w_n` takes finitely
many values, and the letter sequence `(p_n)` is eventually periodic, so the sequence of pairs
(state, position mod `r`) is eventually periodic, say with period `ℓ` from index `n_0`. Over one
such period the transducer reads the same letters from the same state, so it emits the same word;
let `s = |out_h(w_{n+ℓ})| − |out_h(w_n)|` for `n ≥ n_0`, a constant. Then
`|out_h(w_n)| = (s/ℓ)n + O(1)`, so `ρ(h) = lim |out_h(w_n)|/n = s/ℓ ∈ Q_{>0}` exists. It is
positive: `h` is a homeomorphism fixing `p`, so the clopen sets `h([w_n])` form a
neighbourhood basis of `p`, which forces `|out_h(w_n)| → ∞`, hence `s ≥ 1`.

*Depends only on the germ.* If `h, h'` agree on a neighbourhood of `p`, they agree on some
`[w_N]`, so `out_h(w_n)` and `out_{h'}(w_n)` differ by a bounded amount for `n ≥ N`, and the
limits agree.

*Homomorphism.* Let `h, h'` fix `p`. Reading `w_n`, the map `h h'` emits
`out_h(out_{h'}(w_n))`, because `out_{h'}(w_n)` is a prefix of `h'(p) = p`. Hence
`|out_{hh'}(w_n)| = |out_h(w_{m(n)})|` with `m(n) = |out_{h'}(w_n)| ~ ρ(h')n → ∞`, so
`|out_{hh'}(w_n)|/n → ρ(h)ρ(h')`. So `ρ` is multiplicative, and `ρ(id) = 1` gives
`ρ(h^{-1}) = ρ(h)^{-1}`.

*Prefix replacements have rate 1.* If `h` agrees near `p` with a prefix replacement
`α ↦ β` then `h(w_n η) = β·p_{|α|+1..n}·η`, so `out_h(w_n)` is a prefix of a word of length
`n + (|β| − |α|)`, and it grows to infinity; hence `|out_h(w_n)| = n + O(1)` and `ρ(h) = 1`. Hence `(B)_p ≤ ker ρ_p`. ∎

## 3. The test

Suppose (E4) holds at `p`. In the finite-index branch, `(B)_p ≤ ker ρ_p` has finite index in
`(Γ)_p`, so `ρ_p((Γ)_p)` is a finite subgroup of `Q_{>0}`, hence trivial, hence finitely
generated. In the normal branch, `ρ_p` kills `(B)_p`, so it factors as
`(Γ)_p → (Γ)_p/(B)_p → Q_{>0}`. The quotient is finitely presented, hence finitely generated,
so its image in the abelian group `Q_{>0}` is finitely generated. Since `Q_{>0}` is free abelian
on the primes, a finitely generated subgroup involves only finitely many primes. ∎

## 4. The sufficient condition

If `(Γ)_p` is finitely generated abelian then `(B)_p` is normal and `(Γ)_p/(B)_p` is finitely
generated abelian, hence finitely presented and of type `F_∞`, which is the normal branch of
(E4). If `(B)_p` has finite index in `(Γ)_p` that is the finite-index branch. ∎

## 5. Item 5

If `ρ_p` is nontrivial, its image is an infinite subgroup of `Q_{>0}` and `(B)_p ≤ ker ρ_p`, so
`|(Γ)_p : (B)_p|` is infinite. ∎

The upper unitriangular integer matrices of `SL_3(Z) <= GL_3(Z)` form
`H_3(Z)`: `a = E_12`, `b = E_23`, and `[a,b] = E_13` is central. A copy of
`GL_3(Z)` in `mV` would contain `H_3(Z)`. So `n = 3` witnesses the claim.

Notation is as in the claim. `F = k⟨s_1, ..., s_n⟩` is the subalgebra generated by the `s_i`. By the involution
`s_i <-> t_i` (an anti-automorphism, which preserves centralizers), (2) follows from (1). So let `T ∈ L` with
`T s_w = s_w T`, and write `|w| = l`, `w = u^m`, `|u| = p`.

1. **F is free, and L has a depth normal form.**
   - The words `s_v` are linearly independent. Let `L` act on `k[X]`, `X = {1..n}^N`, by
     `s_i δ_z = δ_(iz)` and `t_i δ_(iz) = δ_z`, `t_i δ_(jz) = 0` for `j != i`.
   - On `δ_z` with `z` aperiodic, distinct words `v` give distinct `δ_(vz)`. Indeed `vz = v'z` with
     `|v| != |v'|` would make `z` eventually periodic.
   - So `F` is the free algebra. The spanning set `s_α t_β`, padded with `1 = Σ_i s_i t_i` on the right of `t_β`,
     shows that every `T ∈ L` equals `Σ_(|μ|=N) R_μ t_μ` with `R_μ ∈ F` for all large `N`. Since
     `t_ν s_μ = δ_(νμ)` for `|ν| = |μ|`, we get `T s_μ = R_μ ∈ F`.
2. **Reduction to F.** Choose `N = Ml` large and put `R = T s_(w^M) = R_(w^M) ∈ F`.
   - `T` commutes with `s_w^M = s_(w^M)`, so `R = s_(w^M) T`.
   - Hence `s_w R = s_w T s_(w^M) = T s_w s_(w^M) = R s_w`, so `R` lies in the centralizer of `w` in `F`.
3. **Centralizer of a word in F is k[u].** Let `R = Σ c_x x ≠ 0` commute with `w`, and let `ℓ` be its top word
   length and `S` its top support.
   - For `x ∈ S`, the coefficient of the word `xw` in `Rw` is `c_x ≠ 0`. So `xw` occurs in `wR`, which means
     `xw = wφ(x)` with `φ(x) ∈ S`.
   - `φ` is injective on the finite set `S`, so it permutes `S`. Iterating, `x w^j = w^j φ^j(x)` for all `j`.
     Take `jl >= ℓ + 2l`.
   - Then `x w^j = w^j y` with `|y| = ℓ`, so `x` is the length-`ℓ` prefix of `w^j`. Write `x = w^a w'` with `w'`
     a proper prefix of `w`, `w = w'w''`, and `al <= ℓ`, so that `j >= a + 2`.
   - Strip the common prefix `w^a w'` from `w^a w' (w'w'')^j = (w'w'')^j y`. The left side continues with
     `w'w''` and the right side with `w''w'`, so `w'w'' = w''w'`.
   - By Lyndon–Schützenberger, `w'` and `w''` are powers of a common word, hence of the primitive root `u` of
     `w`. So `x = u^(ℓ/p)` is a power of `u`, `S = {u^(ℓ/p)}`, and `φ` fixes it.
   - `R - c u^(ℓ/p)` still commutes with `w` and has smaller top length. By induction `R ∈ k[u]`, so
     `R = r(s_u)`.
4. **Strip the tail.**
   - Since `s_w^M T = T s_w^M`, we get `T = t_(w^M) s_(w^M) T = t_(w^M) R = t_u^K r(s_u)` with `K = mM`.
   - Expanding with `t_u s_u = 1` gives `T = q(t_u) + P(s_u)`, where `q = Σ_(j=1)^J d_j x^j` has no constant
     term.
   - `P(s_u)` commutes with `s_w`, so `q(t_u)` commutes with `s_w = s_u^m`.
   - Suppose `d_J != 0`. Pick a word `v` with `|v| = p` and `v != u`, and apply both sides to
     `δ_z`, `z = u^(J-1) v z'`. Then `t_u^j δ_z = δ_(u^(J-1-j) v z')` for `j <= J-1`, and `t_u^J δ_z = 0`.
     So `s_u^m q(t_u) δ_z` and `q(t_u) s_u^m δ_z` agree in every term except `j = J`, where the second has
     `d_J δ_(u^(m-1) v z') ≠ 0` and the first has nothing.
   - So `q = 0` and `T = P(s_u) ∈ k[s_u]`. Conversely `k[s_u] ⊆ C_L(s_w)`, and `k[s_u]` is a polynomial ring
     because the `s_(u^j)` are linearly independent (step 1). ∎

**Remark.** Step 3 is the monomial case of Bergman's centralizer theorem (Trans. AMS 137 (1969) 327–344). The
direct word argument above is included so that the route does not depend on the citation.

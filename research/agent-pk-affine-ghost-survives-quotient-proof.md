An element `d in D` belongs to `K_D` exactly when all characters in `R`
take one common value on `d`; that value is `chi(d)`.  Fix `r_0 in R`.
Therefore

```text
K_D={d:(r r_0^(-1))(d)=1 for every r in R}.           (AAP1)
```

The annihilator of `K_D` is the subgroup generated by the differences
`r r_0^(-1)`, so the characters extending `chi|K_D=r_0|K_D` form

```text
r_0 <r r_0^(-1):r in R>=Aff(R).                       (AAP2)
```

This proves `(AAG2)`.

In the graph quotient, the image of the context algebra is the finite
twisted group algebra obtained by imposing

```text
d=chi(d)I,       d in K_D.                             (AAP3)
```

Since `D` is abelian and `chi` is a genuine character on `K_D`, this algebra
is canonically the direct sum of one-dimensional character atoms over all
extensions of `chi|K_D`.  By `(AAP2)` those extensions are exactly
`Aff(R)`.  The canonical twisted-regular trace is the normalized regular
trace of this finite quotient algebra, hence gives each minimal atom weight
`1/|Aff(R)|`.  This proves `(AAG3)` and the forbidden-ghost conclusion.

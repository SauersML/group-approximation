Standard inputs, all textbook:
- the C\*-identity, in the form `‖x‖^2 = ‖x^2‖` for self-adjoint `x`;
- character orthogonality for a finite abelian group:
  `Σ_{χ ∈ Ĝ} χ(g) = |G|` if `g = e` and `0` otherwise, and each `χ(g)` has
  modulus `1`;
- Zorn's lemma;
- the Pauli relations in `M_2`, with `X = [[0,1],[1,0]]`,
  `Y = [[0,−i],[i,0]]` and `Z = [[1,0],[0,−1]]`:
  - `X^2 = Y^2 = Z^2 = 1`;
  - `XY = iZ = −YX`, `YZ = iX = −ZY`, `ZX = iY = −XZ`;
  - `{1, X, Y, Z}` is a basis of `M_2`.

Notation: `α_g` is the action, and `C*(S)` is the C\*-subalgebra generated by
a subset `S`.

## Preliminaries

- **(P1) Invariant means setwise fixed.** If `α_g(C) ⊆ C` for all `g`, then
  `C = α_g(α_{g^{-1}}(C)) ⊆ α_g(C)`, so `α_g(C) = C`.
- **(P2) Commuting self-adjoint sets generate invariant abelian algebras.**
  Let `S ⊆ A` be closed under `*`, with pairwise commuting elements, and
  suppose `α_g(S) ⊆ C*(S)` for all `g`.
  - The \*-algebra generated by `S` is the linear span of finite products of
    elements of `S`, because `S = S*`. It is commutative, and so is its norm
    closure `C*(S)`, since multiplication is continuous.
  - For each `g`, `α_g^{-1}(C*(S))` is a C\*-subalgebra containing `S`, hence
    containing `C*(S)`. So `C*(S)` is invariant.
- **(P3) Spectral components.** For `χ ∈ Ĝ` and `x ∈ A`, put
  `E_χ(x) = |G|^{-1} Σ_{g ∈ G} \overline{χ(g)} α_g(x)`.
  - *Eigen-equation.* For `h ∈ G`, substitute `g' = hg` and use
    `\overline{χ(h^{-1} g')} = χ(h) \overline{χ(g')}`. This gives
    `α_h(E_χ(x)) = |G|^{-1} Σ_{g'} \overline{χ(h^{-1}g')} α_{g'}(x) = χ(h) E_χ(x)`.
  - *Decomposition.* By orthogonality,
    `Σ_{χ} E_χ(x) = |G|^{-1} Σ_g (Σ_χ \overline{χ(g)}) α_g(x) = α_e(x) = x`.
  - *Invariant subspaces.* If `V ⊆ A` is a linear subspace with
    `α_g(V) ⊆ V` for all `g`, then `E_χ(V) ⊆ V`.

## Item 1

Let `D` be maximal among the invariant abelian C\*-subalgebras, and
`B = D' ∩ A = {x ∈ A : xd = dx for all d ∈ D}`.

**(a) `B` is an invariant C\*-subalgebra and `D ⊆ Z(B)`.**
- `B` is a norm-closed subalgebra.
- `B` is closed under `*`: if `x` commutes with `D`, then `x*` commutes with
  `D* = D`.
- `B` is invariant: for `x ∈ B`, `d ∈ D` and `g ∈ G`, we have
  `α_{g^{-1}}(d) ∈ D` by (P1). Hence
  `α_g(x) d = α_g(x α_{g^{-1}}(d)) = α_g(α_{g^{-1}}(d) x) = d α_g(x)`.
- `D ⊆ B`, because `D` is abelian. Every element of `B` commutes with `D`, so
  `D ⊆ Z(B)`.

**(b) `B^G ⊆ D`.**
- *Self-adjoint case.* Let `y = y* ∈ B` with `α_g(y) = y` for all `g`. The
  set `S = D ∪ {y}` is closed under `*`. Its elements commute pairwise, since
  `D` is abelian and `y ∈ B`. Also `α_g(S) ⊆ S` by (P1). By (P2), `C*(S)` is
  an invariant abelian C\*-subalgebra containing `D`, so `C*(S) = D` by
  maximality, and `y ∈ D`.
- *General case.* Let `x ∈ B^G`. Since `α_g(x*) = α_g(x)* = x*`, both
  `Re x = (x + x*)/2` and `Im x = (x − x*)/(2i)` are self-adjoint elements of
  `B^G`. They lie in `D`, and so does `x = Re x + i Im x`.

**(c) Spectral elements of `B` are normal.** Let `χ ∈ Ĝ`, and let `b ∈ B`
satisfy `α_g(b) = χ(g) b` for all `g`. Put `c = b*b` and `d = bb*`.
- *They are fixed and central.* Both lie in `B`. Since `|χ(g)| = 1`,
  `α_g(c) = \overline{χ(g)} χ(g) b*b = c`, and likewise `α_g(d) = d`. By (b)
  and (a), `c, d ∈ B^G ⊆ D ⊆ Z(B)`. As `b, b* ∈ B`, both `c` and `d` commute
  with `b` and with `b*`.
- *Squares.* `c^2 = b*(bb*)b = b* d b = d b*b = dc`, using `b* d = d b*`.
  Similarly `d^2 = b(b*b)b* = b c b* = c bb* = cd`, using `bc = cb`.
- *Conclusion.* `c` and `d` commute, since both lie in `D`. So
  `(c − d)^2 = c^2 − cd − dc + d^2 = dc − cd − dc + cd = 0`.
  `c − d` is self-adjoint, so `‖c − d‖^2 = ‖(c − d)^2‖ = 0`. Therefore
  `b*b = bb*`.

**(d) Spectral elements of `B` lie in `D`.** With `b` as in (c), put
`S = D ∪ {b, b*}`.
- `S` is closed under `*`.
- Its elements commute pairwise: `D` is abelian; `b` and `b*` commute with
  `D` because they lie in `B`; and `b` commutes with `b*` by (c).
- `α_g(D) = D` by (P1). Also `α_g(b) = χ(g) b` and
  `α_g(b*) = \overline{χ(g)} b*` both lie in `C*(S)`.

By (P2), `C*(S)` is an invariant abelian C\*-subalgebra containing `D`. By
maximality `C*(S) = D`, so `b ∈ D`.

*Remark.* This is the only place where a non-self-adjoint eigenvector is
adjoined. Suppose every character of `G` is real-valued, that is, `G` is an
elementary abelian `2`-group such as `Z_2`. Then `Re b` and `Im b` are
themselves spectral elements, and step (c) can be bypassed. That is the route
of item 5 of `no-masa-of-o2-is-normalized-by-fixed-point-unitaries-proof`. For
`G = Z_3` the eigenvalues `e^{±2πi/3}` are not real, and (c) is what makes (d)
possible.

**(e) `B = D`.** Let `x ∈ B`. By (a) and (P3), each `E_χ(x)` lies in `B` and
satisfies `α_h(E_χ(x)) = χ(h) E_χ(x)`. By (d), `E_χ(x) ∈ D`, so
`x = Σ_χ E_χ(x) ∈ D`. Hence `D' ∩ A = B = D`.

**(f) `D` is a masa.** If `C ⊇ D` is abelian, then `C ⊆ D' ∩ A = D`. If `A` is
unital, then `1 ∈ D' ∩ A = D`. ∎

## Item 2

Let `C_0` be an invariant abelian C\*-subalgebra, and let `𝓕` be the family of
invariant abelian C\*-subalgebras containing `C_0`, ordered by inclusion.

- **Zorn.** `𝓕` is nonempty, since it contains `C_0`. Let `(C_i)` be a chain
  in `𝓕`, and let `C` be the norm closure of `∪_i C_i`.
  - The union of a chain of \*-subalgebras is a \*-subalgebra, so `C` is a
    C\*-subalgebra.
  - `C` is abelian, because any two elements of the union lie in a common
    `C_i` and commutation passes to norm limits.
  - `C` is invariant, because each `α_g` maps the union into itself and is
    continuous.
  - `C` contains `C_0`.

  So `C ∈ 𝓕` is an upper bound, and Zorn's lemma gives a maximal element `D`
  of `𝓕`.
- **`D` is a masa.** If `C` is any invariant abelian C\*-subalgebra with
  `D ⊆ C`, then `C_0 ⊆ C`, so `C ∈ 𝓕` and `C = D`. Thus `D` is maximal among
  all invariant abelian C\*-subalgebras, and item 1 makes it a masa.
- **Existence.** Take `C_0 = {0}`.
- **Masas of the fixed-point algebra.** Let `D_0` be a masa of `A^G`. It is
  abelian and invariant, being pointwise fixed. Let `D ⊇ D_0` be an invariant
  masa of `A`. Then `D ∩ A^G` is an abelian C\*-subalgebra of `A^G`
  containing `D_0`, so it equals `D_0` by maximality of `D_0` in `A^G`. ∎

## Item 3

Put `N = X + Y + Z` and `U = (1 − iN)/2`.

**(a) `U` is a unitary of order six.**
- *Unitary.* The Pauli matrices anticommute pairwise, so the cross terms in
  `N^2` cancel and `N^2 = X^2 + Y^2 + Z^2 = 3`. Since `N = N*`,
  `U*U = UU* = (1 + iN)(1 − iN)/4 = (1 + N^2)/4 = 1`.
- *Cube.* `N^2 = 3` and `N ∉ C1`, so `N` has eigenvalues `±√3`. Then `U` has
  eigenvalues `(1 ∓ i√3)/2 = e^{∓iπ/3}`, whose cubes are `−1`. So `U^3 = −1`,
  and `(Ad U)^3 = id`.

**(b) `Ad U` permutes the Pauli matrices cyclically.**
- *`UX = YU`.* From `NX = X^2 + YX + ZX = 1 − iZ + iY` we get
  `UX = (X − iNX)/2 = (X + Y − Z − i)/2`. From
  `YN = YX + Y^2 + YZ = −iZ + 1 + iX` we get
  `YU = (Y − iYN)/2 = (X + Y − Z − i)/2`. So `UXU* = Y`.
- *The other two.* The cyclic relabelling `(X, Y, Z) ↦ (Y, Z, X)` preserves
  every Pauli relation listed above. It fixes `N`, hence `U`. So the same
  computation gives `UYU* = Z` and `UZU* = X`.
- *Order.* In particular `Ad U ≠ id`, so `Ad U` has order `3`.

**(c) The group.** Let `V = {id, Ad X, Ad Y, Ad Z}`.
- `V` is an abelian subgroup of `Aut(M_2)` isomorphic to `Z_2 × Z_2`.
  - `(Ad X)^2 = Ad(X^2) = id`, and similarly for `Y` and `Z`.
  - `Ad X ∘ Ad Z = Ad(XZ) = Ad(−iY) = Ad Y`, and cyclically.
  - The four maps are distinct. `Ad X` fixes `X` and negates `Y` and `Z`,
    `Ad Y` fixes only `Y` among the three, and `Ad Z` fixes only `Z`.
- *Normality.* By (b), `Ad U ∘ Ad X ∘ (Ad U)^{-1} = Ad(UXU*) = Ad Y`, and
  cyclically. So `Ad U` normalizes `V`, and `G = V · ⟨Ad U⟩` is a subgroup.
- *Order 12.* `V ∩ ⟨Ad U⟩ = {id}`, since elements of `V` have order at most
  `2` and `Ad U` has order `3`. So `|G| = 4 · 3 = 12`.
- *Identification.* `G ≅ V ⋊ Z_3`, with `Z_3` acting by the `3`-cycle
  `Ad X ↦ Ad Y ↦ Ad Z ↦ Ad X` on the non-identity elements of `V`. This is
  `A_4`. Explicitly, send `Ad X ↦ (12)(34)`, `Ad Y ↦ (14)(23)`,
  `Ad Z ↦ (13)(24)` and `Ad U ↦ (123)`. The first three give an isomorphism
  of `V` onto the Klein subgroup `V_4 ⊆ A_4`, and conjugation by `(123)`
  permutes `(12)(34) ↦ (14)(23) ↦ (13)(24) ↦ (12)(34)`, matching (b). Both
  `G` and `A_4 = V_4 ⋊ ⟨(123)⟩` are internal semidirect products with
  matching conjugation actions, so `v (Ad U)^k ↦ φ(v) (123)^k` is an
  isomorphism. Only the list of generators is used below, not this
  identification.

**(d) Abelian C\*-subalgebras of `M_2`.** An abelian C\*-subalgebra `C ⊆ M_2`
is finite-dimensional, so it is spanned by its minimal projections
`p_1, …, p_k`. These are pairwise orthogonal and nonzero, and their ranks add
up to at most `2`. So `C` is one of:
- `{0}`;
- `C1`;
- `Cp` with `p` of rank one;
- `span{p, 1 − p}` with `p` of rank one.

A rank-one projection has trace `1`. Expanding in the basis `{1, X, Y, Z}`
and using self-adjointness, it has the form `p = (1 + aX + bY + cZ)/2` with
`a, b, c ∈ R`. From `p^2 = p` we get `a^2 + b^2 + c^2 = 1`. Then:
- `XpX = (1 + aX − bY − cZ)/2`,
- `YpY = (1 − aX + bY − cZ)/2`,
- `ZpZ = (1 − aX − bY + cZ)/2`,
- `1 − p = (1 − aX − bY − cZ)/2`.

**(e) No `Cp` is invariant.** Suppose `Cp` is invariant. Then `α_g(p)` is a
nonzero projection in `Cp`, so it equals `p`. `XpX = p` gives `b = c = 0`, and
`ZpZ = p` gives `a = b = 0`. This contradicts `a^2 + b^2 + c^2 = 1`.

**(f) No `span{p, 1 − p}` is invariant.** Suppose `C = span{p, 1 − p}` is
invariant. Each `α_g(p)` is a rank-one projection in `C`, so
`α_g(p) ∈ {p, 1 − p}`. Comparing coefficients:
- `XpX ∈ {p, 1 − p}` iff `b = c = 0` or `a = 0`;
- `YpY ∈ {p, 1 − p}` iff `a = c = 0` or `b = 0`;
- `ZpZ ∈ {p, 1 − p}` iff `a = b = 0` or `c = 0`.

So at most one of `a, b, c` is nonzero:
- if `a ≠ 0`, the `X`-condition forces `b = c = 0`;
- if `a = 0` and `b ≠ 0`, the `Y`-condition forces `c = 0`.

Hence `(a, b, c)` is `±` a standard basis vector, and `C` is one of
`span{1, X}`, `span{1, Y}` and `span{1, Z}`. By (b), `Ad U` maps these to
`span{1, Y}`, `span{1, Z}` and `span{1, X}`, respectively. None of them is
invariant, a contradiction.

**(g) Conclusion.**
- *No invariant masa.* The invariant abelian C\*-subalgebras are `{0}` and
  `C1`. `C1` is not a masa, since `C1 ⊊ span{1, Z}` and the latter is abelian.
- *The abelian subgroups do have invariant masas.* `span{1, Z}` is invariant
  under `V`, because `Ad X` and `Ad Y` negate `Z` and `Ad Z` fixes it. The
  algebra `span{1, N}` is fixed pointwise by `Ad U`, because `U` is a
  polynomial in `N`.
- *Both are masas.* By (d), every abelian C\*-subalgebra of `M_2` has
  dimension at most `2`, and these two have dimension `2`.

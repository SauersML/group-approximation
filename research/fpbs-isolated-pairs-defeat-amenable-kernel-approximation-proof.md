## Step 0. Two facts about marked groups

**(M1) Nearby groups are quotients of a finitely presented group.** Let
`R = <<r_1,...,r_m>>` be the normal closure in `F_k` of finitely many words,
of lengths at most `n_0`, and let `R_j -> R`. For `j` large,
`R_j ∩ B_(n_0) = R ∩ B_(n_0)`, which contains every `r_i`. Since `R_j` is
normal, `R_j ⊇ R`. So `F_k/R_j` is a quotient of `F_k/R`, compatibly with the
markings.

**(M2) Finitely generated subgroups follow along.** Let `R_j -> R`, and let
`u_1,...,u_m in F_k`, with `L = max |u_i|`. Consider a word `w` of length at
most `n` in `m` letters. Then `w(u_1,...,u_m)` has length at most `nL`. So
`w(u) in R_j` iff `w(u) in R`, once `R_j ∩ B_(nL) = R ∩ B_(nL)`.

Put `H = <u_i R> <= F_k/R` and `H_j = <u_i R_j> <= F_k/R_j`, each marked by
the images of the `u_i`. Then `H_j -> H` as marked groups.

## Step 1. Item 1: the transfer lemma on AA pairs

Take an AA pair `(Gamma, N)` with approximants `R_j ⊆ M`, where `M/R_j` is
amenable and `R_j -> R`. Put `H_j = F_k/R_j`, marked by the images of the
generators, and `A_j = M/R_j`.

The proof route of `fpbs-l2-gap-transfers-to-kesten-normal-gap` uses the
tower only through (T1)–(T4) of its Step 2. Each of these holds here, as
follows.

- **(T1).** `x R_j in A_j` iff `x in M` iff `x R in N`, for every
  `x in F_k` and every `j`.
- **(T2).** For each `R`, once `R_j ∩ B_(2R+2) = R ∩ B_(2R+2)`, a word of
  length at most `2R + 2` is trivial in `H_j` iff it is trivial in `Gamma`.
  That is exactly the ball isomorphism used there.
- **(T3).** `H_j/A_j = F_k/M = Q` as marked groups. So (F3) of that route
  gives `rho(G_j) <= rho_Q` once the generator images agree, which is (T2)
  with `R = 1`.
- **(T4).** Replace it by the following. If `w = e` in `Gamma`, then `w = e`
  in `H_j` for all large `j`, by (T2) with `2R + 2 >= |w|`. Corollary B uses
  (T4) only for all large `j`, so this suffices.

Steps 3–5 of that route then go through word for word, with Step 2's `j_0(R)`
read as the index from (T2) above. So the transfer lemma, Corollary A and
Corollary B hold for AA pairs.

A residually amenable `N` with tower `N_j` gives an AA pair: take `R_j` to be
the preimage of `N_j`. Then `M/R_j = N/N_j` is amenable, and `R_j -> R` by
(T2) of the original route. ∎

## Step 2. Item 2: the kernel obstruction

Let `(R_j, M_j) -> (R, M)`, with `N_j = M_j/R_j` in `C`. Let `H <= N` be
generated by `u_1 R, ..., u_m R`, with `u_i in M`, and let `L = max |u_i|`.

For `j` large, `M_j ∩ B_L = M ∩ B_L`, so every `u_i` lies in `M_j`. Then
`H_j = <u_i R_j>` is a subgroup of `N_j`, so `H_j` lies in `C` because `C` is
closed under subgroups. By (M2), `H_j -> H` as `m`-marked groups. This proves
the first sentence. (A different finite marking of `H` is a set of words in
the `u_i R`, so it is covered by the same argument with other `u_i`.)

Now let `H` be finitely presented, infinite and simple. Write `H = F_m/K` and
`H_j = F_m/K_j`, where `K = {w : w(u) in R}` and `K_j = {w : w(u) in R_j}`.
Then `K_j -> K` by (M2).

- `K` is the normal closure of finitely many words, because `H` is finitely
  presented. By (M1), `K_j ⊇ K` for `j` large. So `H_j` is a quotient of `H`.
- `H` is nontrivial, so some generator letter `x_i` of `F_m` lies outside
  `K`. Since `K_j ∩ B_1 = K ∩ B_1` for large `j`, `x_i` lies outside `K_j`,
  and `H_j` is nontrivial.
- `H` is simple. The kernel `K_j/K` of `H -> H_j` is a proper normal subgroup,
  so it is trivial, and `H_j ≅ H`.

So `H` lies in `C`.

Take `C` to be the class of amenable groups, which is closed under subgroups.
If `N` contains a finitely presented, infinite, simple, nonamenable subgroup
`H`, then `(Gamma, N)` is not a limit of pairs with amenable kernels. An AA
pair is such a limit, with `M_j = M` constant and `N_j = M/R_j`. So
`(Gamma, N)` is not AA. ∎

## Step 3. Item 3: `V x V`

**(3a) `V` has trivial center.** `V` is infinite and simple. It is not abelian,
since an abelian simple group is cyclic of prime order. The center is normal
and proper, so it is trivial.

**(3b) The normal subgroups of `Gamma = V x V`.** Let `K ◁ Gamma` contain
`(a,b)` with `a != e`. By (3a) there is `c in V` with `[a,c] != e`. Then

```text
[(a,b),(c,e)] = (a c a^(-1) c^(-1), b e b^(-1) e) = ([a,c], e)  lies in K.
```

So `K ∩ (V x 1)` is a nontrivial normal subgroup of `V x 1 ≅ V`, and it is
all of `V x 1`. In the same way, if `K` contains some `(a,b)` with `b != e`,
then `K ⊇ 1 x V`.

Hence a nontrivial `K` is `V x 1`, `1 x V` or `Gamma`, according to which
coordinates of its elements can be nontrivial. These four subgroups are
normal. The infinite normal subgroups with nonamenable quotient are exactly
`V x 1` and `1 x V`, once (3c) shows that `V` is nonamenable: `Gamma/Gamma` is
trivial, and each witness has quotient `V`. So `Gamma` lies in (alpha) of
`fpbs-bs-via-percolation-kesten-split`, with exactly these two witnesses.

**(3c) `V` is nonamenable.** Use the definition of `V` in Cannon–Floyd–Parry
(Enseign. Math. 42, 1996, §6), the source cited by
`thompson-v-fp-simple-citation`. There an element of `V` is a pair of finite
binary tree diagrams with the same number of leaves, together with a
bijection of the leaves. Reading the leaves as complete prefix codes makes
`V` the group of homeomorphisms of the Cantor set `C = {0,1}^N` that cut `C`
into finitely
many cylinders `[p_1], ..., [p_r]` (`{p_i}` a complete prefix code) and map
them onto the cylinders of another complete prefix code of the same size by
`p_i w -> q_i w`. Three elements are:

```text
g   :  00w -> 0w,    01w -> 10w,   1w  -> 11w
tau :  00w -> 01w,   01w -> 00w,   1w  -> 1w
sig :  0w  -> 1w,    1w  -> 0w
```

Suppose `V` were amenable, with a left-invariant mean `m` on `l^inf(V)`. Fix
`x in C`, and for `A ⊆ C` put `nu(A) = m(gamma -> 1_A(gamma x))`. Then:
- `nu` is finitely additive, with `nu(C) = 1`;
- `nu(hA) = nu(A)` for every `h in V`, since
  `1_(hA)(gamma x) = 1_A(h^(-1) gamma x)`.

Now `g[00] = [0]` gives `nu[00] = nu[0] = nu[00] + nu[01]`, so `nu[01] = 0`.
Next `tau[01] = [00]` gives `nu[00] = 0`, so `nu[0] = 0`. Finally
`sig[0] = [1]` gives `nu[1] = 0`, and `nu(C) = 0`, a contradiction.

**(3d) `g` has infinite order.** `g[0^(n+1) w] = [0^n w]`, so
`g^n [0^(n+1)] = [0]`. For `n >= 1` the cylinder `[0^(n+1)]` is a proper
subset of `[0]`, so `g^n != e`.

**(3e) Every marking is isolated.** `Gamma` is finitely presented, as a
product of two finitely presented groups: take the union of the two
presentations and the commutators of the two generating sets. Fix a marking,
`Gamma = F_k/R`. Fix `v in V` with `v != e`, and words `w_x, w_y` in `F_k`
representing `x = (v,e)` and `y = (e,v)`. Let `L >= max(|w_x|, |w_y|)` also
bound the lengths of the finitely many relators whose normal closure is `R`.

Let `R'` be normal in `F_k` with `R' ∩ B_L = R ∩ B_L`. The relators lie in
`R'`, so `R' ⊇ R` and `K = R'/R` is normal in `Gamma`. The words `w_x, w_y`
lie outside `R`, hence outside `R'`, so `x, y` lie outside `K`. By (3b) every
nontrivial normal subgroup of `Gamma` contains `x` or `y`. So `K = 1` and
`R' = R`. The open set `{R' : R' ∩ B_L = R ∩ B_L}` is `{R}`.

**(3f) The witness pairs are isolated.** Let `M/R = V x 1`. Let `(R', M')`
satisfy `R' ∩ B_L = R ∩ B_L` and `M' ∩ B_L = M ∩ B_L`. By (3e), `R' = R`, so
`M'/R` is normal in `Gamma` and is one of the four subgroups of (3b). Now
`w_x in M` and `w_y ∉ M`. So `x in M'/R` and `y ∉ M'/R`. The only one of the
four subgroups with this property is `V x 1`, so `M' = M`.

So the pair is isolated, and every sequence of pairs converging to it is
eventually equal to it. The same holds for `1 x V`, with `x` and `y`
exchanged.

**(3g) Neither witness is AA.** If `R_j ⊆ M`, `M/R_j` is amenable and
`R_j -> R`, then `R_j = R` for large `j` by (3e). So `V ≅ M/R` would be
amenable, contradicting (3c). Item 2 gives the same conclusion, with
`H = V x 1`. ∎

## Step 4. Item 4: what dies

Give the space of `k`-marked pairs the topology of Step 0. It is compact and
metrizable, with basic open sets
`U_n(R,M) = {(R',M') : R' ∩ B_n = R ∩ B_n, M' ∩ B_n = M ∩ B_n}`. By (3f),
`U_L(R,M) = {(R,M)}` for `P_0 = (V x V, V x 1)`.

**Proposition.** Let `P` be any set of `k`-marked pairs.
1. If `P_0` lies in the closure of `P`, then `P_0` lies in `P`.
2. If `P` is dense in a subspace containing `P_0`, then `P_0` lies in `P`.
3. Every sequence in the space converging to `P_0` is eventually equal to
   `P_0`.

The same holds for the marked group `(V x V, S)` in the space of marked
groups, by (3e).

*Proof.* `{P_0}` is open. So a set whose closure contains `P_0` meets `{P_0}`,
and a dense set meets it too. Part 3 is the statement that the open set
`{P_0}` contains the tail of every sequence converging to `P_0`. ∎

**How each listed method is an instance.**
- *Local convergence, lower semicontinuity, Easo–Hutchcroft locality.* Each
  passes a property from `(Gamma_j, N_j)` to a limit `(Gamma, N)`. At `P_0`
  the sequence is eventually `P_0` (part 3). So the input needed is the
  property at `P_0` itself.
- *Compactness of `X_(k,eta)`.* An argument by contradiction extracts a
  convergent subsequence of counterexamples, or covers `X_(k,eta)` by
  neighbourhoods on which a bound holds. At `P_0` the neighbourhood is
  `{P_0}`, and any sequence of counterexamples converging to it is eventually
  `P_0`. So it proves nothing at `P_0` beyond what is proved there directly.
- *Baire category.* A statement proved on a dense or comeagre set of pairs or
  groups holds at `P_0` only because the dense set contains `P_0` (part 2).
  Proving density there already includes proving the statement at `P_0`.
- *Finite models.* `V x V` is infinite and isolated, so it is not a limit of
  finite marked groups. Any transplant from finite approximants has no
  approximants to transplant from.
- *Følner compression on amenable kernels.* This is the transfer lemma, whose
  approximants are pairs with amenable kernels. By item 2, or by (3g), no
  such sequence converges to `P_0`.

**The step where the transfer route dies.** Step 2 of
`fpbs-l2-gap-transfers-to-kesten-normal-gap-proof` needs a tower
`N_j ◁ Gamma` inside `N = V x 1`, with `N/N_j` amenable and `∩ N_j = e`. Its
(T2) then gives `R_j -> R` for the preimages `R_j`. By (3e), `R_j = R` for
large `j`, so `N_j = 1` and `N ≅ V` would be amenable. This contradicts (3c).
So no tower exists, the hypothesis of Corollary A and Corollary B is false at
`P_0`, and their conclusions are silent there.

The same applies to `fpbs-uniform-kesten-law-from-uniform-l2` and
`fpbs-uniform-kesten-law-residually-amenable-pairs`, whose hypothesis is
residual amenability of the kernel. By item 1 and (3g), extending them from
residually amenable pairs to AA pairs does not reach `P_0`. By the
Proposition, no closure of any class that omits `P_0` reaches it. ∎

## Step 5. Item 5: the amenable-subgroup variant

**Compression certificates.** A compression certificate for `chi^H` at `q`,
on a `k`-marked group `(Gamma, S)` with a subgroup `H`, is the input of the
transfer mechanism with the kernel replaced by an arbitrary subgroup. It
consists of:
- marked groups `Gamma_j -> Gamma`, with amenable subgroups `A_j <= Gamma_j`;
- convergence `A_j -> H`: for each `n`, eventually a word of length at most
  `n` lies in `A_j` iff it lies in `H`;
- a bound `||T^(Gamma_j)_q|| <= M` for infinitely many `j`.

Lemma 1 of the transfer route, together with window agreement, then gives
`chi^H_q <= M`.

**At an isolated marked group, such as `V x V`.** By (3e), `Gamma_j = Gamma`
with the same marking for large `j`. So `A_j` is an amenable subgroup of
`Gamma` that agrees with `H` on the ball `B_n`, for `n` as large as we like.

- *If `H` is finitely generated and nonamenable*, take `n` at least the
  lengths of words for its generators. Those generators then lie in `A_j`,
  so `H <= A_j` and `H` is amenable, a contradiction. No certificate exists.
- *If `H` is amenable*, the certificate needs `||T^Gamma_q|| <= M < infinity`.
  To be useful for `fpbs-bs-iff-finite-relative-susceptibility` it must hold
  at some `q > p_c(Gamma)`. Then `p_(2->2)(Gamma) >= q > p_c(Gamma)`, and
  item 4 of `fpbs-hutchcroft-l2-gap-criterion` already gives
  `p_c(Gamma) < p_u(Gamma)` with no subgroup at all.

**The wq-normal subgroup of `V x V`.** Let `g in V` have infinite order, as in
(3d). By `fpbs-product-amenable-subgroup-wq-normal`, with the factors in
either order, `<g> x 1` and `1 x <g>` are infinite amenable wq-normal
subgroups of `V x V`. So `fpbs-bs-iff-finite-relative-susceptibility` applies:
on every Cayley graph of `V x V`, `p_c < p_u` iff `chi^(<g> x 1)_p < infinity`
for some `p > p_c`.

By the previous paragraph, the only compression certificate of this condition
is the global l2 gap `p_c < p_(2->2)` on the same Cayley graph. That gap
already implies the conclusion. So Følner compression gives no route to
`p_c < p_u` on `V x V` that is independent of the global l2 gap. ∎

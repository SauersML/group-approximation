# Proof

Write `[x,y] = xyx^(-1)y^(-1)`. For pairwise distinct `i,j,k` and `a,b ∈ R`, a direct computation with matrix units
gives `[e_ij(a), e_jk(b)] = e_ik(ab)`.

**1. Untwisting.** Coordinatewise factor maps `([0,1],Leb) → (Y,ν)` give a `G`-factor map
`π : Z̃ := ([0,1],Leb)^K → (Y,ν)^K`. By essential freeness of `G' ↷ X`, `c(g,z)` := the unique `g' ∈ G'` with
`θ(g·z) = g'·θ(z)` is a measurable cocycle, and `c̃(g,z̃) := c(g,π(z̃))` is a cocycle for the generalized Bernoulli
action `σ̃` on `Z̃`.

* `σ̃` is a generalized Bernoulli action, hence s-malleable.
* `[G:Γ] = ∞`, because `Γ <= EL_r(R)` and `G/EL_r(R) ≅ SL_d(Z)` is infinite. So every `G`-orbit in `K` is infinite,
  and `σ̃` is weakly mixing by Popa's criterion (`popa-oe-superrigidity`).
* `G` has property (T) (Theorem E), so it is an infinite rigid subgroup of itself, w-normal in itself.

Theorem 0.1 (`popa-bernoulli-cocycle-superrigidity`) gives a measurable `φ : Z̃ → G'` and a morphism `ρ : G → G'` with
`c̃(g,z̃) = φ(g·z̃) ρ(g) φ(z̃)^(-1)`. With the opposite convention, replace `φ` by `φ^(-1)`. Then
`ψ(z̃) := φ(z̃)^(-1)·θ(π(z̃))` satisfies `ψ(g·z̃) = ρ(g)·ψ(z̃)` for all `g` and a.e. `z̃`.

**2. The kernel has a finite orbit.** Let `N = ker ρ`, and suppose every `N`-orbit in `K` is infinite. By Popa's
criterion applied to `N` acting on `K`, `σ̃|N` is weakly mixing, hence ergodic. `ψ` is `N`-invariant, so it is
essentially constant, say `x_0`. Then `θ(π(z̃)) = φ(z̃)·x_0 ∈ G'·x_0` for a.e. `z̃`, and since `π_* Leb^K` is the
product measure, the countable set `G'·x_0` has full `μ_A`-measure.

That is impossible. `σ_Y` is essentially free and `G` is infinite, so a.e. `G`-orbit is infinite, and `θ` maps it
injectively into one `G'`-orbit. So `G'` is infinite. An atom of `μ` would then have an infinite free `G'`-orbit of
equal masses, so `μ` has no atoms. Hence some `N`-orbit in `K` is finite.

**3. Root levels are ideals.** For `i ≠ j` put `I_ij := {f ∈ R : e_ij(f) ∈ N}`, an additive subgroup. Let `a ∈ I_ij`
and `b ∈ R`, and choose `k ∉ {i,j}` (possible since `r >= 3`). `N` is normal, so `[e_ij(a), e_jk(1)] = e_ik(a) ∈ N`,
and then `[e_ik(a), e_kj(b)] = e_ij(ab) ∈ N`. So `aR ⊆ I_ij`.

**4. A nonzero root level has only infinite orbits.** Let `a ∈ I_ij` be nonzero, so `e_ij(aR) <= N`.

* *Summand `G`.* `N` acts freely there and is infinite, so its orbits are infinite.
* *Summand `G/Γ`.* Take a coset `gΓ` and write `g = es` with `e ∈ EL_r(R)` and `s ∈ SL_d(Z)`. Conjugation by `s` is a
  monomial substitution, so `sΓs^(-1) = EL_r(R_C)`. Here `C = s'(Z_(>=0)^d)` for some `s' ∈ GL_d(Z)` determined by
  `s`, and `R_C` is the span of the monomials `x^w` with `w ∈ C`.
  * Every entry of a matrix in `gΓg^(-1) = e·EL_r(R_C)·e^(-1)` lies in the `R_C`-submodule `M_e <= R` generated by
    the finitely many products `e_(il)(e^(-1))_(l'j)`. So `e_ij(aR) ∩ gΓg^(-1) <= e_ij(aR ∩ M_e)`, and the
    `e_ij(aR)`-orbit of `gΓ` has at least `[aR : aR ∩ M_e]` points.
  * Put `ℓ(w) := (1,...,1)·s'^(-1)w`, which is `>= 0` on `C`, and `v := s'(1,...,1)`, so `ℓ(v) = d`. Every monomial
    occurring in an element of `M_e` has its exponent in a finite union of translates `w_t + C`. So `ℓ >= B` on all
    of them, where `B := min_t ℓ(w_t)`.
  * Let `m := min{ℓ(w) : x^w ∈ supp a}`. Take integers `n > n'`. Every monomial of `a x^(-n'v)` has
    `ℓ >= m − n'd`, while `a x^(-nv)` has a monomial with `ℓ = m − nd < m − n'd`, which survives in
    `a x^(-nv) − a x^(-n'v)`. If `m − nd < B`, this difference is not in `M_e`. So the elements `a x^(-nv)` with
    `n > (m − B)/d` lie in pairwise distinct cosets of `aR ∩ M_e`, and the orbit of `gΓ` is infinite.

`N`-orbits contain `e_ij(aR)`-orbits, so every `N`-orbit in `K` is infinite. This contradicts Step 2. So `I_ij = 0`,
and `ρ` is injective on `U_ij`.

**5. `SL_d(Z)`.** Let `s ∈ N ∩ SL_d(Z)` with `s ≠ 1`. `SL_d(Z)` acts faithfully on the exponent lattice `Z^d`
through the substitution, so some monomial `f = x^w` has `s(f) ≠ f`. Now
`[s, e_12(f)] = s·(e_12(f) s^(-1) e_12(f)^(-1))` is a product of two elements of `N`, and it equals
`s e_12(f) s^(-1) e_12(−f) = e_12(s(f) − f)`. So `0 ≠ s(f) − f ∈ I_12`, which contradicts Step 4. So `ρ` is
injective on `SL_d(Z)`. This proves the main statement.

**6. Consequence 2, `char k ≠ p`.** Suppose `G' <= GL_n(k)`. Every element of `ρ(U_12)` has order dividing `p`, and
`x^p − 1` is separable over `k`. So each element is diagonalizable over an algebraic closure `k̄`. They commute, so
they are simultaneously diagonalizable, with `p`-th roots of unity on the diagonal. There are at most `p^n` such
diagonal matrices, but `ρ(U_12) ≅ (R,+)` is infinite.

**7. Consequence 2, `char k = p`.** Suppose `G' <= GL_n(k)`. Embed `SL_3(Z) <= SL_d(Z)` as a block. Write
`u_ij(m) ∈ SL_d(Z)` for integer elementary matrices, to keep them apart from the matrices `e_ij(f) ∈ EL_r(R)`. Put
`a := ρ(u_12(1))`, `b := ρ(u_23(1))` and `T := ρ(u_13(1))`. `u_13(1)` has infinite order, so by Step 5 `T` has
infinite order. The identity `u_13(m²) = [u_12(m), u_23(m)]` gives `T^(m²) = a^m b^m a^(-m) b^(-m)` for every
`m >= 1`.

* *(7a) An eigenvalue that is not a root of unity.* Suppose every eigenvalue of `T` is a root of unity. They lie in a
  finite field `F_(p^f)`, so `S := T^(p^f − 1)` has characteristic polynomial `(x−1)^n`, and `(S−1)^n = 0`. For
  `p^u >= n`, `S^(p^u) = 1 + (S−1)^(p^u) = 1` in characteristic `p`, so `T` has finite order, a contradiction. So
  some eigenvalue `λ ∈ k̄` of `T` is not a root of unity.
* *(7b) An absolute value with `|λ| > 1`.* Nonzero elements of `k̄` algebraic over `F_p` are roots of unity, so `λ` is
  transcendental over `F_p`. Let `L := F_p(λ, entries of a^(±1), b^(±1)) <= k̄`, a finitely generated field. On
  `F_p(λ)` put `|g/h| := e^(deg g − deg h)`, a non-archimedean absolute value with `|λ| = e > 1`. It extends to `L`:
  first by the Gauss norm to a purely transcendental extension over a transcendence basis of `L` over `F_p(λ)`, then
  to the finite extension `L`. It then extends further to an algebraic closure `F` of the completion of `L`. These
  extension facts are standard and not re-read here.
* *(7c) Growth.* On `F^n` put `‖w‖ := max_i |w_i|`, and on matrices `‖M‖ := max_(i,j) |M_ij|`. The ultrametric
  inequality gives `‖Mw‖ <= ‖M‖·‖w‖` and `‖MM'‖ <= ‖M‖·‖M'‖`. Take an eigenvector `w ≠ 0` of `T` with eigenvalue `λ`.
  Then `T^(m²)w = λ^(m²)w`, so

  ```text
  |λ|^(m²) <= ‖T^(m²)‖ <= C^(4m),    C := max(1, ‖a‖, ‖a^(-1)‖, ‖b‖, ‖b^(-1)‖).
  ```

  So `m² <= 4m·log C` for every `m >= 1`, which fails for large `m`. So `G'` is not linear over `k`.

**8. Consequence 3.** In a virtually torsion-free group, a torsion subgroup meets a torsion-free finite-index subgroup
trivially, so it injects into the finite quotient. `ρ(U_12)` is an infinite torsion group. ∎

**Calibration.** With `G' = G` and `θ` the identity, `ρ` is the identity: it is injective everywhere, and `G` is not
linear. Step 7 is where the Heisenberg group is used. In characteristic `p` the integer unipotents `u_ij(1)` of
`SL_3(Z)` would have to act with finite order, and Step 5 forbids that.

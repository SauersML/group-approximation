**ESTABLISHED** through `amenable-cd-two-l2-rank-gap-forces-bs-proof`, from
`l2-small-projectives-with-rank-gap-are-finitely-generated`,
`amenable-fp-iff-affiliated-top-homology-vanishes` (items 2 and 4) and
`elementary-amenable-torsion-free-strong-atiyah`.

Let `G` be a finitely generated amenable group with `cd G = 2`, generated by `x_1, …, x_d`. Let
`P = ker(Z[G]^d → Z[G], e_j ↦ x_j − 1)`, a projective module. `U = U(G)`, and the `L²`-rank of
`a ∈ Z[G]` is `dim_U(U a) = 1 − dim_NG ker(r_a : ℓ²G → ℓ²G)`.

1. **`P` is `L²`-small.** `U ⊗ P` embeds in `U^d`, so `dim_U(U ⊗ P) <= d`.
2. **Thin trace ideal.** If `G ≇ BS(1,m)`, then `P` is not finitely generated. For every `ε > 0`
   there is `0 ≠ a ∈ T(P)` with `dim_U(U a) < ε`. Moreover `P = P_0 ⊕ P'` with `P_0` finitely
   generated and `P' ≠ 0` having no nonzero finitely generated direct summand. In particular `P`
   is not a direct sum of finitely generated projectives.
3. **Rank gap.** If there is `c > 0` with `dim_U(U a) >= c` for all nonzero `a ∈ T(P)` (for
   instance for all nonzero `a ∈ Z[G]`), then `G ≅ BS(1,m)` for some `m ≠ 0`.
4. **Equivalence.** Kropholler's question for groups of cd at most 2 is equivalent to
   `amenable-cd-two-groups-have-an-l2-rank-gap`: every finitely generated amenable group of cd 2
   has `inf { dim_U(U a) : 0 ≠ a ∈ Z[G] } > 0`. The value of the infimum is then 1.

**Why this is a strict weakening.** The known equivalent forms of dimension-2 Kropholler ask
for exact values. `Z[G]` a domain means every nonzero element has `L²`-rank exactly 1 (for
amenable `G`). The Fox-rank form asks for exact attainment of rank `d − 1`, and its attempt died
at integrality of ranks of matrices. Item 3 asks only for a **gap**: `L²`-ranks of single elements
bounded away from 0. The gap need not be 1, and only elements of `T(P)` matter. No integrality is
needed, and nothing about matrices. For amenable `G`, `L²`-ranks are Følner limits of normalized
ranks of finite integer matrices (Elek's approximation theorem for amenable groups; recalled, not
used in the proofs). So the gap is a uniform lower bound on finite rank densities.

**What it kills.**

- *Bass's route ("big projectives are free").* For `L²`-small `P`, "free" and "finitely
  generated" coincide: a free module of infinite rank has infinite `U`-dimension. So any
  big-projective freeness theorem proves (F) of `amenable-free-top-syzygy-forces-type-fp` only
  by showing that `P` is finitely generated. Bass's hypothesis that the ring is noetherian modulo
  its radical cannot be used either. `Z[G]` is not left noetherian for a counterexample, since
  `P ⊆ Z[G]^d` is not finitely generated. By item 2, what any such argument must actually exclude
  is `L²`-thin elements in `T(P)`.
- *Kaplansky-type decomposition.* Arguments that decompose projectives into finitely generated
  pieces cannot apply to a counterexample, by item 2. This covers local, semiperfect and Ore-domain
  arguments. Over an Ore domain, every projective of finite rank is finitely generated.
- *Counterexample groups with bounded denominators.* A counterexample cannot have its `L²`-ranks
  of single elements in `(1/N)Z` for a fixed `N`. The same holds for any set of values bounded away
  from 0. This is needed even though `G` is torsion-free and the strong Atiyah conjecture would
  force `N = 1`.

**Shape of a counterexample.** It has a sequence `a_n ∈ T(P) ⊆ Z[G]` of nonzero elements with
`dim_NG ker(r_{a_n}) → 1`. Each `a_n` lies in the image of a dual-basis functional of `P`.

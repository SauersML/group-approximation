**Status:** unreviewed, computer-assisted. Sections 1–6 are the argument. Every finite fact it
uses is replayed by `verify_core.py` (Section 7). The only computational input to the induction
is one fixed-point check on a finite labelled graph.

Notation: words in `x, y` use capitals for inverses (`X = x⁻¹`). The same holds for the fibre
letters `p, q, r, s`. Composition of endomorphisms is written as substitution.

## 1. G is free-by-cyclic

`w = yxYXXyyxYXYxYYxyXy` has exponent sum 0 in both `x` and `y`. So `ε: G → Z`, `y ↦ 1`,
`x ↦ 0`, is well defined. Put `x_j = y^j x y^{-j}`. Reidemeister–Schreier with transversal
`{y^j}` gives `ker ε = ⟨x_j (j ∈ Z) | r_k (k ∈ Z)⟩`. Here `r_k` is `r_0` with every index shifted
by `k`, and

`r_0 = x_1 x_0^{-2} x_2 x_1^{-1} x_0 x_{-2} x_{-1}^{-1}`.

In `r_0` the top index 2 and the bottom index −2 each occur exactly once. Then `r_k` solves for
`x_{k+2}` in terms of `x_{k-2}, …, x_{k+1}`, and also for `x_{k-2}` in terms of
`x_{k-1}, …, x_{k+2}`. Eliminating every `x_j` with `j ∉ {−2,−1,0,1}` by this infinite Tietze
chain shows that `F := ker ε` is free on `p = x_{-2}`, `q = x_{-1}`, `r = x_0`, `s = x_1`
(Magnus). Conjugation by `y` is the automorphism

`φ: p ↦ q, q ↦ r, r ↦ s, s ↦ x_2 = r r S q P R s`,
`φ⁻¹: q ↦ p, r ↦ q, s ↦ r, p ↦ x_{-3} = Q r S q q R p`,

so `G = F ⋊_φ ⟨y⟩`. `fbc.py` checks that `φ φ⁻¹ = id` and that `w` rewrites to the empty word
(function `tofib`). For a word `u` with `ε(u) = 0`, `tofib(u) ∈ F` is its fibre normal form.

## 2. The fibre of π_1(C) is free

Put `P := π_1(C) = ⟨a,b,c,d,e | u_0, u_1⟩`, with

`u_0 = d e⁻¹ b c b⁻¹ a⁻¹ d⁻² e d` and `u_1 = b c b⁻¹ a⁻² b d⁻¹ c b⁻¹ d`.

The map `ι: P → G` sends `a = XyxYx`, `b = Xyyyx`, `c = XYxyx`, `d = y` and `e = xyX`. The
exponents of `y` are `sh(a) = 0`, `sh(b) = 3`, `sh(c) = 0`, `sh(d) = 1` and `sh(e) = 1`. The
relators have `sh`-sum 0, so `λ = ε ∘ ι: P → Z` is defined on `P` itself and `λ(d) = 1`.

**Reidemeister–Schreier.** Take the transversal `{d^l}` for `K := ker λ`. For `g ∈ {a,b,c,e}` and
`j ∈ Z`, put

`g_j := d^j (g d^{-sh(g)}) d^{-j}`.

Then `K = ⟨a_j, b_j, c_j, e_j | R_0^{(k)}, R_1^{(k)} (k ∈ Z)⟩`, where `R^{(k)}` shifts every index
of `R` by `k`, and

`R_0 = e_0⁻¹ b_0 c_3 b_0⁻¹ a_0⁻¹ e_{-2}`,
`R_1 = b_0 c_3 b_0⁻¹ a_0⁻² b_0 c_2 b_{-1}⁻¹`.

`verify_core.py` step 1 derives both words from `u_0, u_1` (function `rs`). Also
`P = K ⋊ ⟨d⟩`, and `d g_j d⁻¹ = g_{j+1}`.

**Lemma 2.1.** `K` is free on `𝓑 := {a_j, b_j : j ∈ Z} ∪ {c_3, e_3, e_4}`.

*Proof.* `R_1^{(k)}` reads

`c_{k+3} = b_k⁻¹ b_{k-1} c_{k+2}⁻¹ b_k⁻¹ a_k² b_k`.   (2.1)

So it expresses `c_{k+3}` through `c_{k+2}`, and `c_{k+2}` through `c_{k+3}`, with coefficients in
the `a, b`. `R_0^{(k)}` reads

`e_k = b_k c_{k+3} b_k⁻¹ a_k⁻¹ e_{k-2}`,   (2.2)

which expresses `e_k` through `e_{k-2}` and conversely. Use (2.1) upward from `c_3` to eliminate
`c_4, c_5, …`, and downward to eliminate `c_2, c_1, …`. Each relation `R_1^{(k)}` is then used
exactly once. Next use (2.2) along the two parity chains through `e_3` and `e_4` to eliminate
every other `e_j`. Each `R_0^{(k)}` is again used exactly once. Every eliminated generator
becomes a finite word in `𝓑`, and no relation is left. ∎

**Lemma 2.2.** `ι` is injective if and only if `Φ := ι|_K: K → F` is injective.

*Proof.* `ι` maps `K ⋊ ⟨d⟩` to `F ⋊ ⟨y⟩` with `d ↦ y`, and `λ = ε ∘ ι`. Take `g = k d^n` in the
kernel. Then `n = λ(g) = ε(ι g) = 0`, so `g = k ∈ ker Φ`. ∎

Since `d g_j d⁻¹ = g_{j+1}` and `ι(d) = y`,

`Φ(g_j) = φ^j(Φ(g_0))`, with `Φ(a_0) = A := tofib(XyxYx)`, `Φ(b_0) = B := tofib(XyyyxYYY)`,
`Φ(c_0) = C := tofib(XYxyx)` and `Φ(e_0) = E := tofib(xyXY)`,   (2.3)

and `Φ ∘ (conjugation by d) = φ ∘ Φ`. `verify_core.py` step 2 checks directly that `Φ` kills
`R_0^{(k)}` and `R_1^{(k)}`.

## 3. Windows and the reduction to ranks

For `M ≥ 0` put

`T_M := ⟨c_3, e_3, e_4, a_0, …, a_M, b_{-1}, …, b_M⟩ ≤ K`   and   `V_M := Φ(T_M) ≤ F`.

`T_M` is generated by `2M + 6` elements of the basis `𝓑`, so `T_M ≅ F_{2M+6}`. By (2.3),

`V_M = ⟨φ³C, φ³E, φ⁴E, φ^j A (0 ≤ j ≤ M), φ^j B (−1 ≤ j ≤ M)⟩`

(`cert.Vgens`).

**Lemma 3.1 (shift).** For `M ≥ 4`,

`d T_M d⁻¹ = T'_{M+1} := ⟨c_3, e_3, e_4, a_1, …, a_{M+1}, b_0, …, b_{M+1}⟩`.

Hence `T_{M+1} = d T_M d⁻¹ ∗ ⟨a_0, b_{-1}⟩`, a free product since all the generators lie in `𝓑`.

*Proof.* `d T_M d⁻¹ = ⟨c_4, e_4, e_5, a_{1..M+1}, b_{0..M+1}⟩`. By (2.1) with `k = 1`,
`c_4 ∈ ⟨c_3, a_1, b_1, b_0⟩` and `c_3 ∈ ⟨c_4, a_1, b_1, b_0⟩`. Both groups lie in both windows,
since `M + 1 ≥ 1`. Now use (2.1) with `k = 2, …, 5`. This puts `c_8` in `⟨c_4, a_{1..5}, b_{0..5}⟩`
and in `⟨c_3, a_{1..5}, b_{0..5}⟩`. Then (2.2) with `k = 5` gives
`e_5 = b_5 c_8 b_5⁻¹ a_5⁻¹ e_3`, so `e_5 ∈ T'_{M+1}` and `e_3 ∈ d T_M d⁻¹`. Both use
`M + 1 ≥ 5`. ∎

**Corollary 3.2.** For `M ≥ 4`, `V_{M+1} = ⟨φ(V_M), A, φ⁻¹B⟩`.

*Proof.* Apply `Φ` to Lemma 3.1 and use `Φ(d t d⁻¹) = φ Φ(t)`, `Φ(a_0) = A` and
`Φ(b_{-1}) = φ⁻¹ B`. `verify_core.py` step 4 re-checks the identity by Stallings membership for
`M = 4, …, 7`, as a sanity test only. ∎

**Lemma 3.3 (reduction).** If `rank V_M = 2M + 6` for all `M ≥ 0`, then `Φ` is injective, and so
`ι` is injective.

*Proof.*
- `Φ|_{T_M}: T_M → V_M` is a surjection between free groups of the same finite rank. Free groups
  of finite rank are Hopfian, so it is an isomorphism.
- By Lemma 3.1, `d^k T_M d^{-k} ⊆ T_{M+k}` for `M ≥ 4`. The window
  `d^{-k} T_{M+k} d^{k}` contains `a_{-k..M}`, `b_{-1-k..M}` and `c_3, e_3, e_4`.
- So every element `g ∈ K` lies in `d^{-k} T_N d^{k}` for some `k ≥ 0` and `N ≥ 4`. If
  `Φ(g) = 1`, then `Φ(d^k g d^{-k}) = φ^k Φ(g) = 1` with `d^k g d^{-k} ∈ T_N`, so `g = 1`.
- Lemma 2.2 finishes the proof. ∎

The rest of the proof shows `rank V_M = 2M + 6`. For `M < 8` this is a direct Stallings fold
(`verify_core.py` step 5, last line). For `M ≥ 8` it is an induction whose step is Corollary 3.2.
The difficulty is that each step applies `φ` to the whole window, so the words grow exponentially.
The next three sections make the induction finite.

## 4. A train track for the monodromy

Let `θ ∈ Aut(F)` be `s ↦ q s r`, fixing `p, q, r`. Its inverse is `s ↦ Q s R`. Then

`ψ := θ φ θ⁻¹:  p ↦ q,  q ↦ r,  r ↦ q s r,  s ↦ S P R`

(`tt2.py` asserts this). `θ` is the product of two Nielsen moves, and `tt_search.py` found it by
searching conjugates of `φ` of Nielsen depth at most 2. Since `θ φ = ψ θ`, applying `θ` turns
Corollary 3.2 into

`θV_{M+1} = ⟨ψ(θV_M), θA, θφ⁻¹B⟩`  for `M ≥ 4`.   (4.1)

**Directions and gates.** The directions are the eight letters `p,q,r,s,P,Q,R,S`. Let `Dψ` send
each direction `x` to the first letter of `ψ(x)`, where `ψ(X) = ψ(x)⁻¹`:

`p→q, q→r, r→q, s→S, P→Q, Q→R, R→R, S→r`.

Two directions `x ≠ y` are in the same gate when `(Dψ)^k x = (Dψ)^k y` for some `k ≥ 0`. The
gates are `{p,r,s}`, `{P,Q,R}` and `{q,S}` (`verify_core.py` step 3). A turn `{x,y}` is legal
when `x` and `y` lie in different gates.

**Lemma 4.1.**
1. If `{x,y}` is legal, then so is `{Dψ x, Dψ y}`. In particular `Dψ x ≠ Dψ y`.
2. Every turn inside an edge image is legal. The turn between consecutive letters `ℓ_i ℓ_{i+1}` of
   `ψ(z)` is `{ℓ_i⁻¹, ℓ_{i+1}}`, and here the only such turns are `{Q,s}` and `{S,r}` (in `qsr`)
   and `{s,P}` and `{p,R}` (in `SPR`).

*Proof.* (1) holds by the definition of gates. (2) is read off the list. `cert.py` asserts (2)
on import. ∎

So `ψ` is a train-track representative on the rose. Only Lemma 4.1 is used below.

## 5. The local folding lemma

All graphs are finite, connected and labelled. An edge labelled `z` from `v` to `t` gives `v` the
direction `z` and `t` the direction `Z`. A graph is **folded** when the directions at each vertex
are pairwise distinct. For a folded based graph `(X, o)`, `π_1(X, o) → F` is injective (Stallings).
So the subgroup `im(X)` it represents has rank `rank X = 1 − χ(X)`.

Let `d_X` be the distance from `o`, and fix `R ≥ 1`.
- `X` is **R-legal** if, at every vertex `v` with `d_X(v) > R`, every pair of directions is legal.
- The **ball datum** `Δ_R(X)` records the following:
  - the vertices with `d_X ≤ R`;
  - all edges between them (the inside edges);
  - at each such vertex, the labels of the edges that go to vertices at distance `R + 1` (the
    exits).

  It is encoded by breadth-first search from `o` with the labels in sorted order (`cert.datum`).
  Because `X` is folded, this code is a complete invariant of the labelled ball with exits.

**The step map.** For a datum `Δ`:
1. Build `Z` from the inside edges of `Δ`. Replace each edge `z: v → t` by a path from `v` to `t`
   that reads `ψ(z)`. Wedge on the loops `θA` and `θφ⁻¹B` at `o`.
2. Fold `Z` to `Z'`, and write `f` for the quotient map on vertices.
3. For each vertex `w` of `Z'`, let `Ex(w)` be the list of `Dψ(z)` over the exits `(v, z)` of
   `Δ` with `f(v) = w`.

`step(Δ)` accepts when three conditions hold:
- (i) at every `w`, the directions of `Z'` at `w` together with `Ex(w)` are pairwise distinct;
- (ii) `d' := min{d_{Z'}(w) : Ex(w) ≠ ∅}` satisfies `d' ≥ R`;
- (iii) every `w` with `d_{Z'}(w) > R` is legal once its directions `Ex(w)` are included.

It then outputs the datum of `Z'` with the exits `Ex`, and the number
`drop = rank Z − rank Z'`. This is `cert.step`.

**Lemma 5.1 (step).** Let `(X, o)` be folded and R-legal with `Δ_R(X) = Δ`, and suppose `step(Δ)`
accepts. Let `Y` be `ψ_*X` (each edge `z` subdivided to read `ψ(z)`) with the loops `θA` and
`θφ⁻¹B` wedged on at `o`, and let `Y'` be a folding of `Y`. Then:
1. `Y'` is folded, and `Y'` is R-legal;
2. `Δ_R(Y')` is the output datum of `step(Δ)`;
3. `im(Y') = ⟨ψ(im X), θA, θφ⁻¹B⟩`;
4. `rank Y' = rank X + 2 − drop`.

*Proof.* Split `Y = Z ∪ W`.
- `Z` is `ψ_*` of the inside edges plus the two loops, which is exactly the `Z` of the step.
- `W` is `ψ_*` of all the other edges of `X`.
- `Z ∩ W = J`, the set of ball vertices that carry an exit.

The vertices of `W` outside `J` come in two kinds:
- images of vertices `u` of `X` with `d_X(u) > R`. The directions there are the `Dψ` of the
  directions of `u`. They are pairwise legal by R-legality and Lemma 4.1(1);
- subdivision vertices. Their one turn is legal by Lemma 4.1(2).

Also, no edge of `W` joins two vertices of `J`. Every edge of `W` has an endpoint that is the image
of a vertex at distance `≥ R + 1`, or is a subdivision vertex.

Fold `Z` inside `Y` first, to `Z'`. Folds inside a subgraph are folds of `Y`. In `Z' ∪ W`, a pair
of equal directions can only occur at a vertex `f(v)` with `v ∈ J`, since vertices of `W` outside
`J` carry only their own, distinct, directions. At `f(v)` the directions are those of `Z'` plus
`Ex(f(v))`, which are distinct by (i). So `Y' = Z' ∪_f W` is folded. Folding does not change the
represented subgroup, which gives item 3.

Distances. Every path from `o` that enters `W ∖ J` passes through some `f(v)` with `v ∈ J`, and
then crosses at least one more edge. So it has length `≥ d' + 1 ≥ R + 1` by (ii). Hence:
- `d_{Y'} = d_{Z'}` on vertices of `Z'` with `d_{Z'} ≤ R`;
- every other vertex has `d_{Y'} > R`;
- the radius-R ball of `Y'` is the radius-R ball of `Z'`;
- its exits are the `Z'`-exits together with the `W`-edges at the `f(v)`, whose first letters are
  the `Dψ(z)`.

This gives item 2. For R-legality, a vertex with `d_{Y'} > R` is either a vertex of `W ∖ J`, which
is legal as shown above, or a vertex of `Z'` with `d_{Z'} > R`, which is legal by (iii).

Ranks. `χ(Y) = χ(Z) + χ(W) − |J|` and `χ(Y') = χ(Z') + χ(W) − |J|`. The second holds because `W`
is glued along the same `|J|` vertices even where `f` identifies some of their images. Both
graphs are connected, so `rank Y − rank Y' = rank Z − rank Z' = drop`. Finally
`rank Y = rank ψ_*X + 2 = rank X + 2`. ∎

## 6. The certificate and the induction

Take `R = 12` and `M_0 = 8`. Let `X_8` be the folding of the wedge of the loops
`θ(Vgens(8))` (22 words). `verify_core.py` step 5 checks the following:
- `rank X_8 = 22`;
- `X_8` is 12-legal;
- `Δ := Δ_{12}(X_8)` has 106 vertices;
- `step(Δ)` accepts with `d' = 12` and `drop = 0`;
- `step(Δ)` outputs `Δ` itself.

**Proposition 6.1.** `rank V_M = 2M + 6` for every `M ≥ 0`.

*Proof.* For `M < 8`, fold the generators of `V_M` directly (`verify_core.py`, last check). For
`M ≥ 8`, define `X_{M+1}` as the `Y'` of Lemma 5.1 applied to `X_M`. By induction on `M`:
- `X_M` is folded, 12-legal and has datum `Δ`. The step only reads `Δ`, and `step(Δ) = Δ` is
  accepted, so Lemma 5.1 applies again.
- `im X_M = θV_M`, by Lemma 5.1(3) and (4.1).
- `rank X_M = 2M + 6`, by Lemma 5.1(4) with `drop = 0`.

`θ` is an automorphism, so `rank V_M = rank θV_M = 2M + 6`. ∎

**Theorem.** `ι: π_1(C) → G` is injective, so `C` is a two-cell core.

*Proof.* Proposition 6.1 and Lemma 3.3. ∎

The certificate is robust. With `R = 16` the datum has 140 vertices, and it is again a fixed point
with `drop = 0` and `d' = 20`. It is the actual `Δ_{16}` of the directly folded graphs for
`M = 8, …, 11`. For `M ≥ 5`, the step output of `Δ_R(X_M)` equals `Δ_R` of the directly folded
`M + 1` graph. For `M ≤ 4` it does not, as expected, since Lemma 3.1 needs `M ≥ 4`.

## 7. Computation and reproduction

Everything is in `experiments/c2-free-by-cyclic-2026-09-18/`. The code is pure Python 3 with no
dependencies, and it runs single-threaded in about one second:

```sh
cd experiments/c2-free-by-cyclic-2026-09-18 && python3 verify_core.py 12
```

Its steps map to the proof as follows:
1. `rs` rewrites `u_0` and `u_1` into `R_0` and `R_1` (Section 2).
2. `Φ` kills the shifted relations.
3. `ψ`, the gates, and Lemma 4.1(2).
4. A sanity check of Corollary 3.2.
5. The base graph `X_8`, the acceptance and fixed point of `step`, and the direct ranks for
   `M < 8` (Section 6).

The output is recorded in `RESULTS.md`. `python3 cert.py R M` prints the per-`M` diagnostics
quoted at the end of Section 6.

Only these modules enter the proof:
- `fbc.py`: word arithmetic, `φ` and `tofib`;
- `fold2.py`: Stallings folding with union-find;
- `tt2.py`: `θ` and `ψ`;
- `cert.py`: gates, the datum and the step;
- `verify_core.py`.

`tt_search.py`, the train-track search, and `run5.py`, the direct window folds used to find the
windows, are the discovery scripts.

What a checker has to trust:
- the folding routine, meaning that `SG` returns a folded graph and computes `stats` correctly;
- the datum encoding, meaning that the BFS code with sorted labels records every inside edge and
  every exit.

Both are short. The mathematical content is in Lemmas 3.1, 4.1 and 5.1.

## 8. Remarks

- **Why the train track is needed.** In the original basis, `φ` has bounded cancellation, but
  controlling the radius-`R` ball of the next window needs about the radius-`7R` ball of the
  current one, so a ball induction diverges. `ψ` removes the loss. Beyond radius `R` every
  vertex is legal, so the new material glued there never folds (Lemma 5.1).
- **Why the positive direction.** The windows grow by `φ`, so a train track for `φ` is what is
  needed. None was found for `φ⁻¹` among conjugates of Nielsen depth at most 2, so the one-sided
  windows `a_{0..M}, b_{-1..M}` are chosen to grow upward.
- **Scope.** The method uses three features of this case:
  - `G` is free-by-cyclic, since both extreme levels of `w` occur once;
  - the fibre of `π_1(C)` has a free basis made of a finite part and finitely many
    `d`-orbits, with a shift lemma;
  - the monodromy has a rose train track after a small change of basis.

  None of these involves the rank of `C`. So the method applies to other two-cell configurations
  over free-by-cyclic one-relator groups, where the finite-cover route
  (`degree-one-two-cell-cores-with-ab-nonzero-exist`) is limited to rank `≤ 3`.

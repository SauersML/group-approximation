**Notation.**
- `N = {0, 1, 2, ...}` is identified with the eventually-zero points of `{0,1}^N`, least significant digit first.
  Then the 2-adic odometer `a : z -> z+1` restricts to the shift `s : n -> n+1`.
- `NSym(N)` is the group of near permutations modulo finitary ones, with near index `eta`, `eta(s̄) = 1`.
- `B = V_(2,1)(<a>)` is the odometer Röver–Nekrashevych group with its faithful near action on `N`
  (`odometer-prefix-groups-have-fg-index-kernels`). Its near index is `chi = eta|_B`, and `K = ker chi`.
- `rho : V -> Sym(N)` is the genuine binary action of Thompson's group `V`
  (`thompson-v-binary-shell-action-passes-both-germ-gates`).

**Statement.**
1. **Germ criterion.** Let `FSym(N) <= G <= Sym(N)` and `Γ = G/FSym(N) <= NSym(N)`. Then `G` is shift-similar
   iff `s̄^-1 Γ s̄ ⊆ Γ`, and strongly shift-similar iff `s̄^-1 Γ s̄ = Γ`. The germ shifting map `psi_infinity`
   is conjugation by `s̄^-1`. Every infinite shift-similar group contains `FSym(N)` (Mallery–Zaremsky Theorem
   `thrm:contain_symfin`). So strongly shift-similar groups are exactly the full preimages of index-zero germ
   groups normalized by `s̄`.
2. **The odometer group.** Let `G_od` be the full preimage of `K` in `Sym(N)`.
   - (a) `G_od` is strongly shift-similar, and its germ shift is conjugation by the odometer.
   - (b) `G_od = < rho(V), t~, (0 1) >` is finitely generated. Here `t~` lifts the balanced cone exchange `t` of
     `odometer-prefix-groups-have-fg-index-kernels`.
   - (c) `G_od` contains `FSym(N) ⋊ rho(V)`, so it is not amenable. It also contains `E_2`.
3. **K is the commutator subgroup.** `B^ab ≅ Z` through `chi`, so `K = [B,B]`.
4. **Houghton-like germ gates.** In the notation of `houghton-like-envelopes-have-fp-germs-iff-fp-near-shift-group`,
   `Ĝ_od = K ⋊ <s̄> = B`. So `H_n(G_od)/FSym([n] x N) ≅ Q_n(B)`, which is finitely presented for every `n >= 3`.
   For `n = 1` the germ group is `K`. So if `G_od` is finitely presented, then `K` is finitely presented.

**What this does not give.**
- No finite presentation of `G_od` or of any `H_n(G_od)` is claimed. That is
  `odometer-houghton-like-groups-are-finitely-presented`, OPEN.
- `G_od` is not an envelope `E_nu(P)`: `V` acts genuinely on `N`, not regularly.
- Its building blocks `V` and `B` already embed in finitely presented simple groups (the scope note of
  `thompson-v-binary-shell-action-passes-both-germ-gates`). So it is a structural test case, not a new
  Boone–Higman input.

**Reading for the route.**
- For every `n >= 3` the germ gate of `H_n(G_od)` passes unconditionally.
- The near relations are those of the finitely presented group `B`, and `s̄` lies in `B`. This is the most rigid
  situation possible: the refutation's hypothesis `P * <s> -> R` injective fails as badly as it can.
- The generators from `V` displace points linearly, not boundedly: a prefix replacement `u -> v` acts as
  `u + 2^|u| t -> v + 2^|v| t`. So `fp-bounded-displacement-e2-envelopes-are-eventually-periodic` does not apply
  either.
- Hence `H_3(G_od)` is the first test case of the Houghton-like lifting that is non-generic and not virtually
  abelian. If it is finitely presented, it is a non-amenable finitely presented shift-similar group; no such
  group is recorded on main or in the source. That would answer Mallery–Zaremsky Question `quest:examples_fin_props` ("beyond `E_n` and `H_n`") with non-amenable
  examples.

**Lesson for general BH.**
- Strong shift-similarity is a pure germ condition. By item 1, `G -> Ĝ = <Germs(G), s̄>` is a bijection
  between infinite strongly shift-similar groups and subgroups `B <= NSym(N)` containing the near shift `s̄`.
  The inverse is `B -> ` the finitary preimage of `ker(eta|_B)`. Surjectivity holds because `ker(eta|_B)` is
  normal in `B` and `B = ker(eta|_B) ⋊ <s̄>`.
- So a shift-similar host for `P` is nothing more than a near action on `N` of some group containing `P` and an
  element of near index 1. The Houghton-like germ gate for `n >= 3` is finite presentation of that group.
- Every finite-presentation question about such hosts is therefore a question of lifting through `FSym`.
- Self-similar groups hand over the index-one element for free: on eventually-zero 2-adic expansions, the near
  shift is the odometer. That moves the whole shift-similar route onto groups of Röver–Nekrashevych type, where
  finite presentation of the germ group is routine (Belk–Hyde–Matucci).

## Setting

- `τ` is a Wang tile set and `Ω_τ ⊆ τ^(Z^2)` its set of tilings. The forbidden patterns are the mismatched dominoes.
- A **self-simulation with zoom `N >= 2`** is a map `σ : τ → τ^([0,N)^2)` with:
  - **(H1) local coordinates.** There is `κ : τ → (Z/N)^2` such that matching edge colours force `κ(b) = κ(a) + e_1` for
    a right neighbour `b` of `a` and `κ(b) = κ(a) + e_2` for a top neighbour. Also `κ(σ(c)_u) = u`.
  - **(H2)** `σ` is injective.
  - **(H3) exact macrotiles.** Every pattern `p` on `[0,N)^2` with `κ(p(u)) = u` for all `u` and no mismatched domino
    equals `σ(c)` for some `c ∈ τ`.
  - **(H4) faithful macro edges.** If `c, c'` do not match horizontally, then `σ(c)` placed to the left of `σ(c')`
    contains a mismatched domino. The same holds vertically.
- The intended examples are the fixed-point tile sets of Durand–Romashchenko–Shen (J. Comput. Syst. Sci. 78, 2012).
  There H1–H4 state that the `τ`-macrotiles (correctly tiled `N × N` squares with aligned coordinates) form a copy of `τ`,
  and that matching is both preserved and reflected. Cited, not re-read. H2–H4 give `σ(Ω_τ) ⊆ Ω_τ`.
- **Local `D`-family.** Idempotents `E_a(z) ∈ End_k(W)`, for `a ∈ τ` and `z ∈ Z^2`, satisfying (Q1) and (Q2) of
  `sft-crossed-product-fp-iff-quantum-rigid` (ℓ¹ metric, commutation up to distance `2D`), together with:
  - **(Q3_loc)** for every `z`, the product over `h ∈ B_D` of `E_(π(h))(z+h)` vanishes for every pattern `π` on `B_D` that
    contains a mismatched domino.
- **`H(D)`.** Every local `D`-family satisfies `[E_a(z), E_b(w)] = 0` whenever `|z − w|_1 <= R(D) := N(2D+2) − 2`.

## Statement

1. **Decimation.** Let `E` be a local `D`-family satisfying the commutation in `H(D)`.
   - The **phase projections** `Q_t` (`t ∈ (Z/N)^2`), where `Q_t` is the sum of `E_a(z)` over `a` with `κ(a) ≡ z − t`,
     do not depend on `z`. They are central orthogonal idempotents with `Σ_t Q_t = I`.
   - On each `Q_t W`, the block products `M_c(Z) = Π_(u ∈ [0,N)^2) E_(σ(c)_u)(NZ + t + u)` form a local `D`-family for
     the same tile set `τ`.
   - `E` is recovered from `M` by substitution: `E_a(NZ+t+u) = Σ_(c : σ(c)_u = a) M_c(Z)` on `Q_t W`.
2. **Range collapse.** If `H(D)` holds for some `D >= 2`, every local `D`-family commutes. Hence `Ω_τ` is `D`-quantum
   rigid, and `LC(Ω_τ, k) ⋊ Z^2` is finitely presented over `k`.
3. **Converse.** If `Ω_τ` is quantum rigid, `H(D)` holds for all large `D`. So `Ω_τ` is quantum rigid iff `H(D)` holds for
   some `D >= 2`.
4. **Semi-decidability.**
   - `H(D)` is a finite conjunction, over `a, b ∈ τ` and `|v|_1 <= R(D)`, of statements
     "`e_a(0)e_b(v) − e_b(v)e_a(0)` lies in the two-sided ideal generated by the (Q1), (Q2), (Q3_loc) relations".
     Each of these is Σ⁰₁.
   - So among the triples `(τ, σ, κ)` satisfying H1–H4 (a decidable condition), those whose SFT is quantum rigid form
     a recursively enumerable set. The witness is a finite derivation of bounded-range commutation.
   - For a general `Z^2`-SFT the definition, read literally, is Σ⁰₃: there exists `D`, for all `v`, there exists a
     derivation, and the relation (Q3) refers to the co-r.e. language of `Ω`.

## Scope

- Only constant-zoom self-simulations with local coordinates. Variable-zoom hierarchies (zoom `N_k` at level `k`, as
  in the quasiperiodic and minimal DRS variants) need `H(D)` for each level's tile set, uniformly in `k`. The proof
  goes through verbatim under that uniform hypothesis.
- No tile set is shown here to satisfy `H(D)`.
- Fault slabs block the determinism route to `H(D)` along every fault normal, so a certificate must use the hierarchy
  or a genuinely noncommutative argument.

## Lesson for general BH

Take E2 in its `Z^2` form, for a programmable fixed point.
- **The decimation step.** A self-simulating tile set turns every local family into a local family for the same tile
  set at the same scale. Commutation up to one bounded range then climbs the hierarchy for free.
- **Both directions are one-scale.** Rigidity is verified by a finite derivation of commutation within a window of
  about `(2D+2) × (2D+2)` macrotiles. It is refuted by one non-commuting `D_0`-family
  (`self-similar-sfts-are-quantum-rigid-iff-rigid-at-one-scale`) or one thin wall
  (`self-similar-sft-thin-walls-refute-quantum-rigidity`).
- **What is left to design.** A programmable fixed point reduces E2 over `Z^2` to one macrotile whose neighbourhood
  algebra carries a bounded-range commutation certificate. That is the "one finite scale" form of the gate: an r.e.
  search target instead of an infinite noncommutative statement.
- **Non-amenable groups.** For the non-amenable carriers of Track A, the same argument should apply to the `Z^2`
  hierarchical layer of any Barbieri–Sablik–Salo simulation. This was not checked.

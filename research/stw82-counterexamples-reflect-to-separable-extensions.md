There is no genuinely nonseparable-only counterexample to the maximum formula
for nuclear dimension.  More precisely, fix an extension

```text
0 -> I -> E -q-> D -> 0
```

and a finite set `Omega` in `E`.  If
`dim_nuc(I), dim_nuc(D) <= n < infinity`, then there are separable C*-subalgebras
`I_0 <= I`, `E_0 <= E`, and `D_0 <= D` such that

```text
Omega is contained in E_0,
I_0 = E_0 intersect I,
q(E_0) = D_0,
dim_nuc(I_0), dim_nuc(D_0) <= n.
```

Consequently the arbitrary-extension statement is equivalent to its
restriction to separable extensions.

## Separable hull lemma

If `A` has nuclear dimension at most `n` and `B <= A` is separable, then `B`
is contained in a separable C*-subalgebra `C <= A` with nuclear dimension at
most `n`.

To prove this, start with `C_0=B`.  At stage `r`, choose a countable dense set
in `C_r`.  For the first `r` elements and tolerance `1/r`, use
`dim_nuc(A) <= n` to choose

```text
A -psi_r-> F_r -phi_r-> A,
F_r = direct_sum_{j=0}^n F_r^(j),
```

where both maps are c.p.c., each restriction
`phi_r|F_r^(j)` is order zero, and `phi_r psi_r` has the required accuracy.
Let `C_(r+1)` contain `C_r` and `phi_r(F_r)`.  The closure of the union is
separable.  The displayed approximations, restricted to this closure, prove
that it has nuclear dimension at most `n`: any finite set is first moved into
one stage and then handled at a later stage.  Equivalently, one may extend the
first c.p.c. maps from a stage to the closure by the matrix-valued Arveson
extension theorem.  This proof uses no separability of `A`.

## Construction of the exact subextension

Set `E^(0)=C*(Omega)`.  Inductively suppose `E^(r)` is separable.  Choose a
countable dense subset `X_r` of `E^(r)`.  For every `x in X_r` and positive
integer `k`, choose `i(x,k) in I` satisfying

```text
||x-i(x,k)|| <= ||q(x)|| + 1/k.                 (1)
```

This is possible because `||q(x)||=dist(x,I)`.  Inside `I`, apply the
separable hull lemma to the C*-algebra generated by the preceding ideal hull,
`E^(r) intersect I`, and all `i(x,k)`.  Call the resulting separable algebra
`I^(r+1)`; arrange the ideal hulls to be increasing.  Thus
`dim_nuc(I^(r+1)) <= n`.

Likewise, inside `D` apply the hull lemma to a separable algebra containing
`q(E^(r))` and the preceding quotient hull.  Call the result `D^(r+1)`, with
`dim_nuc(D^(r+1)) <= n`.  Lift a countable dense subset of `D^(r+1)` to `E`
and let `E^(r+1)` be generated by those lifts together with `E^(r)` and
`I^(r+1)`.  Then

```text
q(E^(r+1)) = D^(r+1),
```

because the range of a *-homomorphism between C*-algebras is closed.

Put

```text
E_0 = closure(union_r E^(r)),
I_0 = closure(union_r I^(r)),
D_0 = closure(union_r D^(r)).
```

The standard finite-set proof of nuclear-dimension permanence under
inductive limits gives
`dim_nuc(I_0), dim_nuc(D_0) <= n`, and continuity gives `q(E_0)=D_0`.
Certainly `I_0 <= E_0 intersect I`.  For the reverse inclusion, take
`x in E_0 intersect I` and `delta>0`.  Some element `y` of one of the chosen
dense sets `X_r` satisfies `||x-y||<delta`.  Since `q(x)=0`,
`||q(y)||<delta`; choosing `k` with `1/k<delta` in (1) gives an element of
`I_0` within `3 delta` of `x`.  Hence `x in I_0`.  This proves exactness.

## Reflection of a failure

If the maximum formula fails, its endpoint maximum is finite: if either
endpoint has infinite nuclear dimension, monotonicity already forces
`dim_nuc(E)=infinity`.  Write the finite maximum as `n`.  The assertion
`dim_nuc(E)>n` is witnessed by one finite set `Omega` and one positive
tolerance for which no `n`-coloured approximation exists.  Apply the
construction above to that `Omega`.  If `dim_nuc(E_0)<=n`, an approximation
inside `E_0` would also be an approximation inside `E`, contradicting the
choice of `Omega`.  Thus the separable exact subextension has endpoint
dimensions at most `n` and middle nuclear dimension greater than `n`.

This reduction also explains why exotic nonmetrizable commutative
compactifications cannot by themselves settle the problem: any successful
example would necessarily contain a separable commutative subextension that
already violates the formula, contrary to the classical separable
commutative maximum theorem.

Notation as in the target. `Γ ≤ W(Z)`, finitely generated by `S`, with `r = r(S)`.

**Step 0 (interval indicators).** Let `f ∈ W(Z)` have displacement at most `ρ`, and let
`J ⊂ Z` be a finite interval.
- If `x ∈ J` and `f(x) ∉ J`, then `f(x)` lies within `ρ` of an end of `J`, beyond that end.
  So `|f(J) ∖ J| ≤ 2ρ`.
- Since `|f(J)| = |J|`, this gives `‖f·1_J − 1_J‖² = |f(J) Δ J| ≤ 4ρ`.

**Step 1 (linear relative-Kazhdan inequality).** Let `H ⊴ Γ` with `(Γ, H)` relative (T). For a
unitary representation `(π, V)` let `P` be the projection onto `V^H`.
- *Normality.* If `v ∈ V^H`, `g ∈ Γ` and `h ∈ H`, then `π(h)π(g)v = π(g)π(g^{-1}hg)v = π(g)v`.
  So `V^H` and its orthogonal complement `(1−P)V` are `Γ`-invariant, `P` commutes with `π(Γ)`, and
  `‖π(g)(1−P)ξ − (1−P)ξ‖ = ‖(1−P)(π(g)ξ − ξ)‖ ≤ ‖π(g)ξ − ξ‖`.
- *Kazhdan pair.* There are a finite `Q ⊂ Γ` and `ε > 0` such that no `Γ`-representation without
  nonzero `H`-invariant vectors has a `(Q, ε)`-invariant unit vector. Suppose not. `Γ` is countable,
  so take finite `Q_1 ⊂ Q_2 ⊂ …` exhausting `Γ`, and representations `ρ_k` without `H`-invariant
  vectors having `(Q_k, 1/k)`-invariant unit vectors. Then `⊕_k ρ_k` has almost invariant
  vectors. It has no nonzero `H`-invariant vector, because each component of such a vector would be
  `H`-invariant. This contradicts relative (T).
- Let `w ∈ (1−P)V` be nonzero. The subrepresentation `(1−P)V` has no nonzero `H`-invariant vector.
  So `w/‖w‖` is not `(Q, ε)`-invariant, that is, `max_{q∈Q} ‖π(q)w − w‖ > ε‖w‖`.
- Now apply this to `w = (1−P)ξ` for an arbitrary `ξ ∈ V`. This gives, for every `ξ ∈ V`,
  `‖(1−P)ξ‖ ≤ ε^{-1} max_{q∈Q} ‖π(q)ξ − ξ‖`.   (★)

**Step 2 (item 1).** Take `π` the permutation representation on `ℓ²(Z)`, and put `ρ = r(Q)`.
- An `H`-invariant vector is square-summable and constant on `H`-orbits, so it vanishes on the
  infinite ones. Hence, for a finite interval `J`,
  `P 1_J = Σ_{b finite} (|b∩J|/|b|) 1_b`, and
  `‖(1−P)1_J‖² = Σ_{b infinite} |b∩J| + Σ_{b finite} |b∩J|·|b∖J|/|b|`.
- By (★) and Step 0, `‖(1−P)1_J‖² ≤ 4ρ/ε² =: K` for every finite interval `J`.
- *No infinite orbits.* An infinite `H`-orbit meets `[−N, N]` in more than `K` points once `N` is
  large, which is impossible.
- *Bounded crossing.* Fix a cut `c`, and any finitely many `H`-orbits `b_1, …, b_m` crossing it.
  Take `J = [a, c − 1/2]` with `a` below `min ∪_i b_i`. Then `b_i ∩ J = (b_i)_<` and
  `b_i ∖ J = (b_i)_>`, so `Σ_i |(b_i)_<|·|(b_i)_>|/|b_i| ≤ K`. The `b_i` were arbitrary, so the
  sum over all orbits crossing `c` is at most `K`.
- *Consequences.* For positive integers `u` and `v`, `uv/(u+v) ≥ 1/2` and
  `uv/(u+v) ≥ min(u,v)/2`. So at most `2K` orbits cross `c`, and each has smaller side at most
  `2K`. ∎(1)

**Step 3 (item 2).** Let `O ⊂ Z` be a finite `Γ`-orbit with `n ≥ 2` points `o_1 < … < o_n`.
Put `m = ⌊n/2⌋`, `L = {o_1, …, o_m}` and `w = 1_L − (m/n) 1_O`. Then `w ∈ ℓ²_0(O)`.
- `‖w‖² = m(n−m)/n ≥ (n² − 1)/(4n) ≥ n/8`.
- For `s ∈ S`, `s·w − w = s·1_L − 1_L`, since `1_O` is `s`-invariant.
- If `x ∈ L` and `s x ∉ L`, then `s x ∈ O ∩ (o_m, o_m + r]`, a set of at most `r` points. So
  `|sL ∖ L| ≤ r`, and `‖s·w − w‖² = 2|sL ∖ L| ≤ 2r`.
- By (τ) on the finite `Γ`-set `O`: `κ² n/8 ≤ κ²‖w‖² ≤ max_s ‖s·w − w‖² ≤ 2r`. So
  `n ≤ 16r/κ²`. ∎(2)

**Step 4 (item 3).** Put `C = ⌊16r/κ²⌋`.
- A finitely generated group has finitely many subgroups of index at most `C`. Let `Γ_0` be their
  intersection. It is normal and of finite index.
- If `x` lies in a finite orbit, then by Step 3 `[Γ : Γ_x] ≤ C`, so `Γ_0 ≤ Γ_x`. Hence `Γ_0` fixes
  the union `Z_fin` of the finite orbits pointwise.
- `Γ_0` is infinite, being of finite index in the infinite group `Γ`. It acts faithfully on `Z`,
  since `Γ ≤ W(Z)`. So it acts faithfully and nontrivially on `Z_∞ = Z ∖ Z_fin`, and `Z_∞ ≠ ∅`.
- Let `x ∈ Z_∞`. Then `Γx` is infinite, so `[Γ : Γ_x] = ∞`. Put `F_N = Γx ∩ [−N, N]`. Since
  `Γx` is an infinite subset of `Z`, `|F_N| → ∞`.
- `F_N = 1_{[−N,N]}` restricted to the `Γ`-invariant set `Γx`. By Step 0,
  `|s F_N Δ F_N| ≤ 4r` for `s ∈ S`. So `(F_N)` is a Følner sequence for the `Γ`-set
  `Γx ≅ Γ/Γ_x`. Any weak-* limit of the uniform means on `F_N` is a `Γ`-invariant mean on
  `Γ/Γ_x`. So `Γ_x` is co-amenable.
- If `Γ_x` were amenable, then `Γ` would be amenable: an amenable co-amenable subgroup gives an
  invariant mean on `Γ`, obtained by integrating the invariant means of the cosets against the
  invariant mean on `Γ/Γ_x`. So for non-amenable `Γ`, `Γ_x` is non-amenable.
- `[[X]]` embeds in `W(Z)` through a dense `σ`-orbit, as in the corollary of
  `wobbling-normal-relative-t-subgroups-are-locally-finite`. So the class kill transfers. ∎(3)

**Step 5 (item 4; conditional on (τ) for `Λ`, not claimed established).** Let `A = R²`, and
`Γ_p = Λ ⋉ A`. By `elementary-linear-semidir-pair-relative-t`, `(Γ_p, A)` has relative (T).
- *`Γ_p` has (τ).* Let `F` be a finite `Γ_p`-set and `P` the projection onto `ℓ²(F)^A`. Then
  `ℓ²_0(F) = W_1 ⊕ W_2` with `W_1 = Pℓ²_0(F)` and `W_2 = (1−P)ℓ²(F)`, both `Γ_p`-invariant.
  - `W_1` is `ℓ²_0(F/A)`, and `F/A` is a finite `Λ`-set, since `A` fixes every `A`-orbit as a set.
    So assumed (τ) for `Λ` gives a gap `κ_1` on `W_1`, for the images of a generating set.
  - (★) gives the gap `ε` on `W_2` for `Q`.
  - For `w = w_1 + w_2` and the finite set `S' = S ∪ Q`:
    `max_{s∈S'} ‖s·w − w‖² ≥ |S'|^{-1} Σ_{s∈S'} (‖s·w_1 − w_1‖² + ‖s·w_2 − w_2‖²) ≥ |S'|^{-1} min(κ_1², ε²) ‖w‖²`.
    Here `s·w_i − w_i ∈ W_i`, so the cross terms vanish.
- *The reduction.* Suppose `Γ_p ≤ W(Z)`. `Γ_p` is non-amenable, since it maps onto `Λ ⊇ F_2`.
  Item 3 gives `x` with `G_x := (Γ_p)_x` of infinite index, co-amenable and non-amenable. Let
  `Λ_x` be the image of `G_x` in `Λ`.
  - `Λ/Λ_x ≅ Γ_p/(G_x A)` as `Γ_p`-sets, and this is a quotient of the amenable `Γ_p`-set
    `Γ_p/G_x`. So `Λ_x` is co-amenable in `Λ`, and it is non-amenable because `Λ` is.
  - `A_x = G_x ∩ A` has index `|Ax| < ∞` in `A`, by item 1. Then
    `[Γ_p : G_x] = [Γ_p : G_x A]·[A : A_x]`. Since the left side is infinite and `[A : A_x]` is
    finite, `[Λ : Λ_x] = ∞`.
  - For `g = (λ, a) ∈ G_x`: `g A_x g^{-1} = A_{gx} = A_x`, and conjugation by `g` acts on the
    abelian group `A` through `λ`. So `λ(A_x) = A_x`. That is, `Λ_x` stabilises the
    finite-codimension subspace `V = A_x`. ∎(4, conditional)

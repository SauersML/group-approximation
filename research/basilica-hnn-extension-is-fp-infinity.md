**OPEN.** Let `B~ = ⟨a, t | t^(−2) a t^2 = a^2, [a, a^b] = 1, b = t a t^(−1)⟩` be the ascending HNN
extension of the Basilica group `B` along `σ : b ↦ a, a ↦ b^2`
(`basilica-hnn-extension-is-fp-amenable-non-ea`). Then `B~` is of type `FP_∞` over `Z`. Since
`B~` is finitely presented, this is equivalent to type `F_∞`. Together with the import and
`basilica-group-is-torsion-free-and-contains-every-z-n`, it would establish
`there-is-torsion-free-f-infinity-amenable-non-ea-group` through
`torsion-free-f-infinity-amenable-non-ea-via-basilica-hnn`.

## Attempts

- **Low-degree homology (computed; no obstruction).**
  - `σ_*` on `H_1(B) = Z^2`, in the basis `a, b`, has matrix `M = [[0, 1], [2, 0]]`: `a ↦ 2b` and
    `b ↦ a`. So `det(1 − M) = −1`, and `1 − σ_*` is invertible on `H_1(B)`.
  - The Mayer–Vietoris sequence of the ascending HNN extension,
    `H_k(B) --(1 − σ_*)--> H_k(B) → H_k(B~) → H_(k−1)(B) --(1 − σ_*)--> H_(k−1)(B)`,
    gives `H_1(B~) = Z`, generated by `t`, and `H_2(B~) = coker(1 − σ_* on H_2(B))`.
  - `B~` is finitely presented, so `H_2(B~)` is finitely generated. Hence `coker(1 − σ_*)` on the
    Schur multiplier of `B` is finitely generated. `H_2(B)` itself is not computed here.
- **Alexander-module test (necessary condition; stuck at degree 3).**
  - Let `N = ker(χ : B~ → Z)`, where `χ(t) = 1` and `χ(a) = 0`. Then `N = ⋃_(n ≥ 0) t^n B t^(−n)`.
    This is the directed colimit of `B` under `σ`, so `H_k(N; F) = colim_(σ_*) H_k(B; F)` for any
    field `F`.
  - By Shapiro's lemma, `H_k(N; F) ≅ H_k(B~; F[t^(±1)])`. If `B~` is of type `FP_n`, then
    `H_k(N; F)` is finitely generated over the Noetherian ring `F[t^(±1)]` for every `k ≤ n`.
  - Degree 1: `M^2 = 2·1`, so `N^ab = Z[1/2]^2`, and `N` is not finitely generated. Over `F_2`,
    `M` is nilpotent, so `H_1(N; F_2) = 0`. Over `Q`, `H_1(N; Q) = Q^2`. Both are consistent.
  - Degree 2 is automatic, since `B~` is `FP_2`.
  - Degree 3 needs `colim_(σ_*) H_3(B; F)` to be finitely generated over `F[t^(±1)]`. No
    computation of `H_3(B)` is known to this lane, so the test is not evaluated. Even if
    `H_3(B; F)` is infinite-dimensional, the test only asks for finite generation of the colimit.
- **Brown's criterion on the Bass–Serre tree (dead in homotopical form; homological form needs
  more than is known).** The action is cocompact, with one orbit of vertices and one of edges. The
  vertex and edge stabilizers are conjugates of `B`.
  - Homotopical form, for `F_n`: it needs vertex stabilizers of type `F_2` to reach degree 2. `B`
    is not finitely presented: any finitely presented cover of `B` has non-abelian free subgroups
    (Erschler, as recorded in `fp-covers-of-grigorchuk-groups-are-large`), and `B` is amenable. So
    this form fails already in degree 2, where `B~` is nevertheless finitely presented.
  - Homological form, for `FP_n`: vertex stabilizers of type `FP_n` and edge stabilizers of type
    `FP_(n−1)` give `FP_n`. So "`B` is of type `FP_∞` over `Z`" is a sufficient condition for this
    hole. This lane has not decided whether `B` is even of type `FP_2`. It is not, for instance, if
    the Schur multiplier `H_2(B)` is infinitely generated, which this lane expects but has not
    verified.
- **Changing the base (reduces to an equally hard problem).**
  - Suppose `B~` is an ascending HNN extension `B'*_τ` with a base `B' ≤ N` of type `FP_n` and a
    stable letter `s` with `χ(s) = ±1`. Then `B~` is of type `FP_n`. This is the Mayer–Vietoris
    argument for graphs of groups whose vertex and edge groups are `FP_n`.
  - Such a base must contain a copy of `B`. `N` is the directed union of the conjugates
    `s^m B' s^(−m)`, and `B` is finitely generated, so `B ≤ s^m B' s^(−m)` for some `m`.
  - So `B'` is torsion-free, amenable (it lies in the amenable group `B~`) and not elementary
    amenable (it contains `B ∉ SG`). If `B'` is of type `F_∞`, it answers
    `there-is-torsion-free-f-infinity-amenable-non-ea-group` directly.
  - The converse, that `FP_n` with `χ ∈ Σ^n` forces such a base, is the Bieri–Renz criterion. It
    is recalled here, not re-read, and nothing depends on it.
- **Kropholler fence (strategy constraint).**
  - `B~` is torsion-free with `cd B~ = ∞`, since it contains `Z^n` for every `n`. By Kropholler's
    theorem for torsion-free `H𝔉`-groups of type `FP_∞`, cited in
    `there-is-torsion-free-f-infinity-amenable-non-ea-group` via Januszkiewicz–Kropholler–Leary,
    arXiv:0908.3669v1, p. 1, an `FP_∞` `B~` lies outside `H𝔉`.
  - `B~` acts on its Bass–Serre tree with stabilizers conjugate to `B`, so `B ∈ H𝔉` would put
    `B~` in `H𝔉`. **Hence `FP_∞` for `B~` forces `B ∉ H𝔉`.**
  - Membership of `B` in `H𝔉` is open to this lane. Gandini's non-membership criterion (Groups
    Geom. Dyn. 6 (2012), DOI 10.4171/GGD/169, Theorem 4.7 and Corollary 4.10; used there for the
    first Grigorchuk group in Theorem 4.11) needs jump rational cohomology of finite height. `B`
    does not have it, because it contains `Z^n` of cohomological dimension `n` for every `n`.
- **Euler characteristic and `L^2` (no obstruction).** The presentation complex has Euler
  characteristic `1 − 2 + 2 = 1`. `B~` is infinite amenable, so its first `L^2`-Betti number is
  `0`. So the second `L^2`-Betti number of the universal cover of the presentation complex is `1`,
  and that complex is not aspherical. This is consistent with `cd B~ = ∞`. It says nothing about
  `FP_3`.
- **Sanity constraint.** Thompson's `F` is torsion-free, of type `F_∞`, of infinite cd, outside
  `H𝔉`, and an ascending HNN extension of a copy of itself along an infinite-index endomorphism.
  An argument against `FP_∞` for `B~` that uses only properties shared by `F` would contradict
  Brown–Geoghegan. If it also used amenability, it would prove `F` non-amenable. A disproof must
  use features `F` lacks, such as the base `B` not being finitely presented, or `B ∉ SG`.
- **No positive tool is known.** Nothing in this lane's reading proves `FP_3` for any finitely
  presented ascending HNN extension of a weakly branch group.

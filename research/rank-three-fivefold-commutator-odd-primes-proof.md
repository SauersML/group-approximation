Write s_j = Sigma^∞ cbar_j, so s_{j+1} = s_2 o (1 ∧ iota o s_j), where
iota: SU(3) -> U(3) is the inclusion.

**Splittings.** Fix an odd prime p. By Serre, SU(3) is p-regular:
SU(3)_(p) ≃ S^3 x S^5. Hence U(3)_(p) ≃ S^1 x S^3 x S^5, and the natural
splitting Sigma(X x Y) ≃ Sigma X ∨ Sigma Y ∨ Sigma(X ∧ Y) gives, p-locally,

    Sigma^∞ U(3) ≃ ∨_{d in D} S^d,   D = {1, 3, 4, 5, 6, 8, 9},
    Sigma^∞ SU(3) ≃ ∨_{b in B} S^b,  B = {3, 5, 8},

with iota the inclusion of the summands in B. Smash products of summands give
the summands of Sigma^∞ U(3)^{∧j}.

**Components.** Let y(d, e; b) in pi^s_{d+e−b} be the component of s_2 on
S^d ∧ S^e -> S^b. A map out of a finite wedge of spheres is determined by
its components, and composition of stems is their product up to sign. So
the component of s_5 on S^{d_4} ∧ ... ∧ S^{d_0} -> S^{b_5} is

    sum over b_2, b_3, b_4 in B of  ± x_4·x_3·x_2·y,
    x_i = y(d_i, b_i; b_{i+1}),   y = y(d_1, d_0; b_2).

**Stems.** The 3-primary stable stems used: pi_3 = Z/3{alpha_1},
pi_7 = Z/3{alpha_2}, pi_10 = Z/3{beta_1}, pi_11 = Z/9{alpha'_3},
pi_13 = Z/3{alpha_1 beta_1}, pi_15 = Z/3{alpha_4}. The 3-parts of pi_n vanish
for the other n <= 15 and for n = 17, 18, 21. For p >= 5 the only nonzero
p-primary stem n <= 14 is n = 2p − 3 = |alpha_1|, for p = 5 and p = 7.

**Letters.** A bracket letter x = y(d, b; b') has stem d + (b − b') with
d in D. Listing all (d, b, b') at p = 3 with a nonzero stem:
- b = b': stem d, nonzero only for d = 3 (alpha_1).
- 5 -> 3: d = 1, 5, 8, 9 give alpha_1, alpha_2, beta_1, alpha'_3.
- 8 -> 5: d = 4, 8 give alpha_2, alpha'_3.
- 8 -> 3: d = 5, 6, 8 give beta_1, alpha'_3, alpha_1 beta_1.
- Rises 3 -> 5, 5 -> 8, 3 -> 8: only alpha_1 or alpha_2.
So x has stem at most 14, it lies in J = {alpha_1, alpha_2, alpha'_3} or in
{beta_1, alpha_1 beta_1}, and a letter of the second kind is a strict drop
ending at b' = 3. The base letter y has stem at most 15.

**Products at p = 3.** (i) Every product of two elements of J is 0. Squares
of odd-degree classes vanish. alpha_1 alpha'_3 and alpha_2 alpha'_3 lie in
stems 14 and 18, which have no 3-part. For alpha_1 alpha_2 in stem 10:
Ext^{1,t}_A at p = 3 is spanned by a_0 and the h_i, in stems 0, 3, 11,
35, ..., so alpha_2 has Adams filtration at least 2 and alpha_1 alpha_2 has
filtration at least 3. The 3-part of pi_10 is generated by beta_1, detected
by b_0 in filtration 2, so every nonzero element has filtration exactly 2.
Hence alpha_1 alpha_2 = 0. (ii) alpha_2 beta_1 and alpha'_3 beta_1 lie in
stems 17 and 21, with no 3-part. (iii) alpha_1·alpha_1 beta_1 = 0 by (i).
(iv) alpha_1 beta_1^3 = 0 (Toda's relation alpha_1 beta_1^p = 0).

**Case count at p = 3.** Among x_2, x_3, x_4:
- At most one letter outside J. Two letters lie in J, and by graded
  commutativity the product contains their product, which is 0 by (i).
- Two letters outside J. Each is a strict drop ending at 3. A letter
  starting at 3 is flat or a rise, so the two drops are x_2 and x_4, and x_3
  must rise from 3 for x_4 to drop again. Rises lie in J. By (ii)
  and (iii) the product vanishes unless the rise is alpha_1 and both drops
  are beta_1. Then the component is ± alpha_1 beta_1^2·y. For y in
  J ∪ {alpha_4, alpha_1 beta_1} it contains alpha_1·y = 0: alpha_1 alpha_4
  lies in stem 18, and the rest is (i). For y = beta_1 it is
  alpha_1 beta_1^3 = 0 by (iv).
- Three letters outside J would need three drops to 3 with rises between,
  which is impossible with three letters.
So every component of s_5 vanishes 3-locally, and s_5 localized at 3 is null.

**p >= 5.** Every letter x has stem at most 14, so each x_i is a multiple of
alpha_1 or 0. Since alpha_1^2 = 0, x_4·x_3 = 0 and s_5 localized at p is
null. For the fourfold map, x_3·x_2 = 0 in the same way. This proves (a).

**(b)** s_2 induces 0 on reduced rational homology, because H_*(U(3); Q) is a
graded commutative Hopf algebra. Rationally a map of finite spectra is
determined by homology, so s_5 is rationally null. It is therefore a torsion
element of the finitely generated group [Sigma^∞ G^{∧5}, Sigma^∞ SU(3)], and
by (a) its order is a power of 2. Then 2^k·(E ∧ s_5) ≃ 0 for every E, and the
detection step of rank-two-trapping-depth-four-stable-null-proof turns this
into the statement on trapped classes.

**(c)** The commutator c(g, h) = g h g^{-1} h^{-1} is unchanged when g or h is
multiplied by a scalar. So c = c' o (pi x pi) with pi: U(3) -> PU(3) and
c': PU(3) x PU(3) -> SU(3). Inductively cbar_5 = C_5 o pi^{∧5} with
C_5 o s^{∧5} = cbar_5^{SU(3)}, where s = pi|SU(3). The map s is a 3-fold
covering of connected groups, so it is a 2-local equivalence. Write
pi(diag(z, 1, 1)·g) = l(z)·s(g), with l: S^1 -> PU(3). After localization at
2 the target is simply connected, so l is null and pi ≃ s o pr. Hence
cbar_5 ≃ cbar_5^{SU(3)} o pr^{∧5} 2-locally, and the same holds after
Sigma^∞.

*The splitting of SU(3).* SU(3) = S^3 ∪ e^5 ∪ e^8 with
H^*(SU(3); F_2) = Λ(x_3, x_5) and Sq^2 x_3 = x_5, so the 5-cell is attached
by eta. SU(3) is a closed parallelizable 8-manifold, so Atiyah duality gives
D(Sigma^∞ SU(3)_+) ≃ Sigma^{-8} Sigma^∞ SU(3)_+. The bottom cell of
Sigma^∞ SU(3)_+ splits off through the collapse SU(3)_+ -> S^0. Its dual
splits off the top cell. Hence Sigma^∞ SU(3) ≃ (S^3 ∪_eta e^5) ∨ S^8. □

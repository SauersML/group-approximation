Notation is as in the target. All complexes are CW complexes. Tilde denotes the universal cover.

## Lemma 0 (π_1-injective subcomplexes)

Let `Z` be an aspherical complex of dimension at most 2. Let `L ⊂ Z` be a connected subcomplex with
`π_1 L -> π_1 Z` injective. Then `L` is aspherical.

*Proof.* Since `π_1 L` injects, `L̃` embeds as a subcomplex of the cover `Z_L` of `Z` with group
`π_1 L`. The complex `Z_L` is aspherical and 2-dimensional, so `H_2(Z_L) = 0`. There are no
3-cells, so `H_2` of a subcomplex is its group of 2-cycles, which injects. Hence
`π_2 L = H_2(L̃) = 0`. ∎

## Theorem 1

Let `X` be a finite 2-dimensional `K(G,1)`. Then `C_*(X̃)` is a free resolution
`0 -> P_2 -> P_1 -> P_0 -> Z -> 0` of ranks `x_2, x_1, x_0`. Let `Y` be a finite connected
2-complex with `π_1 Y ≅ G`. Then `C_*(Ỹ)` gives an exact sequence
`0 -> π_2(Y) -> Q_2 -> Q_1 -> Q_0 -> Z -> 0` of ranks `y_i`, because `H_1(Ỹ) = 0` and
`H_2(Ỹ) = π_2(Y)`.

Schanuel's lemma for two exact sequences of the same length ending in the same module gives

`π_2(Y) ⊕ P_2 ⊕ Q_1 ⊕ P_0 ≅ 0 ⊕ Q_2 ⊕ P_1 ⊕ Q_0`.

So `π_2(Y) ⊕ ZG^a ≅ ZG^b`, with `a = x_2 + y_1 + x_0` and `b = y_2 + x_1 + y_0`. Then
`b - a = χ(Y) - χ(X) = ρ(Y)`.

*Sign.* Suppose `b < a`. Tensoring with `Z` over `ZG` along the augmentation makes `Z^a` a direct
summand of `Z^b`, which is impossible. So `ρ(Y) >= 0`.

*Zero.* Suppose `ρ(Y) = 0`. Then `P := π_2(Y)` is finitely generated projective with
`P ⊕ ZG^a ≅ ZG^a`. Apply `NG ⊗_ZG -`, where `NG` is the group von Neumann algebra, and take von
Neumann dimension. This gives `dim_NG(NG ⊗ P) = 0`. By Kaplansky, the trace of a nonzero idempotent
matrix over `CG` is positive. So `P = 0`, and `Y` is aspherical. The converse is immediate. ∎

(Theorem 1 is the argument of Gersten's work on Euler characteristic and asphericity of
2-complexes, arXiv:1501.06875. It is reproduced here in full so that nothing is imported.)

## Theorem 2

*(a) ⇒ (b).* Let `Z` be a 2-dimensional `K(G,1)` with an aspherical subcomplex `L` inducing `H`.
Since `H` is finitely generated, a finite subcomplex `L' ⊂ L` is π_1-surjective onto `H`. Since `H`
is finitely presented, the kernel of `π_1 L' -> H` is normally generated by finitely many loops. Each
of them bounds in a finite subcomplex of `L`, so some finite `L'' ⊂ L` satisfies `π_1 L'' ≅ H`.

In the same way, since `G` is finitely presented, some finite `Z' ⊂ Z` contains `L''` and satisfies
`π_1 Z' ≅ G`. The composite `L'' -> Z' -> Z` is injective on π_1. By Lemma 0, applied twice
(`Z' ⊂ Z`, then `L'' ⊂ Z'`), both `Z'` and `L''` are aspherical.

*(b) ⇒ (c) (swap by pushout).* Let `Z ⊇ L` be as in (b), and let `K` be any finite 2-dimensional
`K(H,1)`. Both `L` and `K` are aspherical with group `H`, so there is a cellular homotopy
equivalence `f: L -> K` inducing the identity of `H`. Form the pushout `Y = K ∪_f Z` of
`K <- L ⊂ Z`:
- Its cells are the cells of `K` together with the cells of `Z - L`.
- It is a 2-dimensional finite CW complex containing `K`.
- `f` is a homotopy equivalence and `L ⊂ Z` is a cofibration, so `Z -> Y` is a homotopy equivalence
  by the gluing lemma.

So `Y` is a finite aspherical relative presentation containing `K` and inducing `H`, with
`ρ(Y) = 0`.

The same pushout turns any relative presentation `Y' ⊇ L` into one containing `K`, with
`χ(K ∪_f Y') = χ(Y') - χ(L) + χ(K) = χ(Y')`. So `min ρ` over `Y ⊇ K` does not depend on `K`, and
`ρ(H,G)` is well defined.

*(c) ⇒ (d).* Immediate, since `ρ >= 0` by Theorem 1.

*(d) ⇒ (a).* A relative presentation with `ρ = 0` is aspherical by Theorem 1. Its subcomplex `K` is
aspherical and induces `H`.

*(d) ⇔ (e).* Take `Y ⊇ K`. Choose a forest of edges of `Y - K` joining each extra vertex to `K`, and
contract it. This is a homotopy equivalence rel `K`, so we may assume that `Y - K` has no vertices.
Then `Y - K` consists of `|T|` 1-cells and `|R|` 2-cells, `π_1 Y = <H, T | R>`, and
`χ(Y) = χ(H) - |T| + |R|`. So `ρ(Y) = 0` iff `|R| - |T| = χ(G) - χ(H)`.

Conversely, a presentation as in (e) is realized by attaching `|T|` loops and `|R|` 2-cells to
`K`. Each relator is written as a closed edge path in `K^1 ∪ T`. This uses cellular approximation
of a word in `H` by a loop in `K^1`. ∎

## Theorem 2' (relative chains)

Let `Y ⊇ K` have no vertices outside `K`, and let `p: Ỹ -> Y` be the universal cover. Since
`π_1 K -> G` is injective, `p^{-1}K` is a disjoint union of copies of `K̃`, indexed by `G/H`. Each
copy is contractible. So `H_2(p^{-1}K) = H_1(p^{-1}K) = 0` and `H_0(p^{-1}K) = Z[G/H]`.

The long exact sequence of the pair `(Ỹ, p^{-1}K)` gives:
- `H_2^rel = π_2(Y)`;
- `0 -> H_1^rel -> Z[G/H] -> Z -> H_0^rel -> 0`, so `H_1^rel = I_{G/H}`.

The relative chain complex is `0 -> C_2 -> C_1 -> 0`, with `C_i` free on the `i`-cells of `Y - K`.
This yields the exact sequence

`0 -> π_2(Y) -> C_2 -> C_1 -> I_{G/H} -> 0`.

Write `B_1` for the image of `C_2`.
- By Schanuel's lemma, `pd I_{G/H} <= 1` iff `B_1` is projective.
- `B_1` is projective iff `0 -> π_2 -> C_2 -> B_1 -> 0` splits.

This proves the stated equivalence, for every such `Y`.

If `Y` is aspherical then `B_1 ≅ C_2` is free, so every RP pair is admissible. Stable freeness of
`π_2(Y)`, with rank `ρ(Y)`, is Theorem 1 and holds for every `Y`, admissible or not. ∎

## Theorem 3

Let `G = <S | w>` with `w` not a proper power, and let `X` be its presentation complex. By
`non-proper-power-one-relator-complexes-are-aspherical`, `X` is a finite 2-dimensional `K(G,1)`
with `χ(X) = 2 - |S|`.

Let `H` be finitely generated. By `one-relator-groups-are-coherent`, `H` is finitely presented.
The argument in (a) ⇒ (b) above then gives a finite subcomplex `C` of the cover `X_H` with
`π_1 C ≅ H`, and Lemma 0 shows it is aspherical. Each 2-cell `e_j` of `C` (`j = 1..n`) is a lift of
the `w`-cell.

Let `φ: C -> X` be the restricted covering map, which is cellular. Let `M = Cyl(φ|: C^1 -> X^1)`,
a finite 2-complex containing `C^1` and `X^1`. It deformation retracts to `X^1`, so
`π_1 M = F(S)` and `χ(M) = 1 - |S|`. Let `Y_0 = M ∪ {e_j on C^1} ∪ {w-cell on X^1}`. Then:
- `Y_0 ⊇ C`.
- `π_1 Y_0 = F(S) / <<w, u_j>>`, where `u_j ∈ F(S)` is the image of `∂e_j`. That image is a
  conjugate of `w^{±1}`, because `∂e_j` reads `w` in the cover. So `π_1 Y_0 = G`.
- `C -> Y_0` induces `φ_*`, which is injective with image `H`.
- `χ(Y_0) = 1 - |S| + n + 1 = χ(G) + n`.

If `n >= 1`, then `w ∈ <<u_1>>`, so deleting the `w`-cell leaves `π_1 = G` and `C` in place, and
gives a relative presentation `Y_1` with `ρ(Y_1) = n - 1`. If `n = 0`, then `H` is free and
`ρ(Y_0) = 0`. So `ρ(H,G) <= max(n(C) - 1, 0)`. ∎

## Calibration

Take `G = Z^2 = <a,b | [a,b]>` and `H` of index 2. Then `H` is normal. The core is the whole double
cover `X_H`, which is a torus with `n = 2`. So `ρ(H,G) <= 1`.

Suppose `RP(H,G)` held, with a finite aspherical `Y ⊇ K`. Let `Ŷ` be its double cover with group
`H`. Since `π_1 K ⊂ H`, `K` lifts, so its preimage is two disjoint copies `K_1 ⊔ K_2`, each with
`H_2 = Z`. In the 2-dimensional complex `Ŷ`, `H_2(K_1) ⊕ H_2(K_2) = Z^2` injects into
`H_2(Ŷ) = H_2(Z^2) = Z`, which is a contradiction. So `ρ(H,G) = 1`, and Theorem 3 is sharp.

## Why the proposed finite-cover search is not decisive

A 2-cell-injective core inside a finite cover `X̂` realizes `H` in `Ĝ = π_1 X̂`, where
`H <= Ĝ <= G`. Descent (`trees-of-groups-with-realizable-edges-realize-vertices`, part D) goes from
larger ambient groups to smaller ones, so `RP(H,Ĝ)` does not yield `RP(H,G)`. The upward direction
is false in general: `H = Ĝ` of index 2 in `Z^2` has `RP(H,H)`, but not `RP(H,G)`. Any search for
`RP(H,G)` must range over relative presentations `Y ⊇ C` with `ρ(Y) = 0`, which by Theorem 3 means
reducing `Y_1` by `n(C) - 1`, not over covers.

Notation is as in [[kazhdan-double-cones-add-one-sigma1-bit]].  Facts used:

- (F1) **Normal form for amalgams** (Serre, *Trees*, I.1.2).  In `A *_C B` with `C` embedded in both, a
  product `a_1 b_1 a_2 b_2 ...` of length at least 1, whose letters alternate between `A \ C` and `B \ C`,
  is not 1.  `A` and `B` embed.
- (F2) **Pushouts.**  If `C ≤ A` and `C ≤ B` are subgroups, then `(A * B)/<<c = c>>` is the genuine amalgam
  `A *_C B`.
- (F3) **Soficity permanence.**  Subgroups of sofic groups are sofic, and free products of sofic groups are
  sofic (Elek-Szabo, Proc. AMS 139 (2011)).
- (F4) **B. H. Neumann.**  If a finitely presented group is a quotient `F/N` of a finitely generated group
  `F`, then `N` is the normal closure of finitely many elements.

## Part E

The presentation of `P_e` in [[amenable-edge-assemblies-have-delta2-sofic-locus]] has:
- as generators, the vertex generators and the stable letters `tau_eps`;
- as relators, the vertex relators, `tau_eps iota_(eps,o)(x) tau_eps^-1 = iota_(eps,t)(x)` for `x` in the
  **generating tuple** of `E_eps`, and `tau_eps = 1` on the forest.

No relator of `E_eps` occurs.  So the presentation, and hence `P_e`, depends only on the vertex presentations
and on the word tuples `iota_(eps,*)(x)`.  Replacing `E_eps` by the free group on its generating tuple gives
the same presentation.

The normal form (A) of that node holds for any edge groups.  With free edges it reads as follows.
- `P_e` is the genuine graph of groups with vertex groups `V*_v` and edge groups `U_eps`, where `U_eps` is the
  image of the generator tuple in `P_e`.
- The soficity equivalence in (A) needs only that the edge groups **of the genuine normal form** be amenable.
  These are the groups `U_eps`, which are subgroups of `V*_v`.

So the edge class matters only through amenability of the subgroups `U_eps ≤ V*_v`, which is a property of
the vertices.  The equivalence claimed in Part E follows.  Given a KMS-edge propagator, the vertex data
`(V_v, U_eps)` is the vertex-side object.  Conversely, vertex data with amenable finitely generated `U_eps`
defines an assembly with edge group `U_eps`, which may be taken to be a KMS group when `U_eps` is one.  ∎

## (K1)

Let `y ∈ Y \ Gamma` with `[y, Gamma] = 1`, and let `X = Y *_Gamma G`.  Define `phi : G *_Gamma G -> X` by
`g ↦ g` on the first copy and `g ↦ y g y^-1` on the second.  On `Gamma` the two copies agree, because
`y g y^-1 = g` for `g ∈ Gamma`.  So `phi` is well defined.

Take a nontrivial reduced word of `G *_Gamma G`: letters `g_1, g_2', g_3, g_4', ...`, alternating between the
two copies of `G \ Gamma`.  A single letter from `Gamma \ 1` maps to itself and is nontrivial.  Otherwise
its image is

```text
g_1 · y · g_2 · y^-1 · g_3 · y · g_4 · y^-1 ...
```

(with a leading `y` if the word starts in the second copy).  The letters alternate between `G \ Gamma` and
`Y \ Gamma`, since `y^(±1) ∉ Gamma`.  So by (F1) the image is not 1, and `phi` is injective.  By (F3),
`X` is nonsofic when `G *_Gamma G` is.  ∎

## (K2)

`X(H,C) = (H * G)/<<[C, Gamma]>>`.  Apply (F2) twice.
- `L = H *_C (C x Gamma)` is a genuine amalgam, since `C ≤ H` and `C = C x 1 ≤ C x Gamma`.
- `X = L *_Gamma G` is a genuine amalgam, since `Gamma = 1 x Gamma ≤ C x Gamma ≤ L` and `Gamma ≤ G`.
- The presentations agree: the pushout imposes exactly the relations `[c, g] = 1`.
- So `H` and `G` embed in `X`.

*Centraliser.*  Write `X = H *_C M` with `M = (C x Gamma) *_Gamma G`, a genuine amalgam.  Let
`h ∈ H \ C` and `g ∈ Gamma \ 1`.  Then `g ∈ M \ C`, because `(1,g) ∉ C x 1`.  The commutator
`h g h^-1 g^-1` alternates `H \ C`, `M \ C`, `H \ C`, `M \ C`, so by (F1) it is not 1.  Hence
`C_X(Gamma) ∩ H ⊆ C`, and `⊇` holds by construction.

*Dichotomy.*
- If `C = 1`, the relators are trivial and `X = H * G`.  By (F3) this is sofic iff `H` is sofic, since `G` is
  sofic.
- If `C ≠ 1`, take `c ∈ C \ 1`.  In `L`, `c` centralises `Gamma` and `c ∉ Gamma`, because
  `(C x 1) ∩ (1 x Gamma) = 1` inside `C x Gamma ≤ L`.  By (K1), `X` is nonsofic.
- If `H` is nonsofic, `X ⊇ H` is nonsofic.  ∎

## (K3)

- If `C = <k_1..k_m>`, then `X` is presented by the relators of `H` and `G` together with the `m · s`
  relators `[k_i, g_j] = 1`, where `g_1..g_s` generate `Gamma`.  This presentation is finite.
- Conversely, let `X` be finitely presented.
  - Enumerate `C = {c_1, c_2, ...}` and put `C_i = <c_1..c_i>`.  Then `X = (H * G)/N` with `N` the
    increasing union of the normal subgroups `N_i = <<rel(H), rel(G), [C_i, Gamma]>>`.
  - `H * G` is finitely generated, so by (F4) `N` is normally generated by finitely many elements.  These
    lie in some `N_j`, so `N = N_j` and `X = X(H, C_j)`.
  - Every `c ∈ C` centralises `Gamma` in `X = X(H,C_j)`.  By the centraliser clause of (K2), applied to
    `C_j`, this gives `c ∈ C_j`.
  - So `C = C_j` is finitely generated.  ∎

## (K4)

The equivalence is (K2) with `C = <k_e>`.  `C = 1` iff every word of `k_e` is trivial in `H_e`.  This is
`Sigma^0_1`, uniformly in `e`, because the word problem of a finitely presented group is r.e.

Induction.  Each step is one of two kinds.
- A free product of two groups already built.  It is sofic iff both factors are (F3), so the loci
  intersect.
- A cone `X(H, <k>)` on a group `H` already built, which is finitely presented by (K3), with `k` any finite
  tuple of words in `H`.  It is sofic iff `H` is sofic and `[k = 1 in H]` holds, which is `Sigma^0_1`.

A computably bounded conjunction of uniformly `Sigma^0_1` conditions is `Sigma^0_1`.  So the final locus is
`L ∩ S`, where `L` is the intersection of the base loci and `S` is `Sigma^0_1`.

*Corollary.*  If `L` is `Delta^0_2`, then `L ∩ S` is `Delta^0_2`, since `Sigma^0_1 ⊆ Delta^0_2` and
`Delta^0_2` is closed under intersection.  `INF` is not `Delta^0_2` (Post), so there is no reduction.  ∎

## Calibration

`w_(<e,m>) = 1` iff `|W_e| > m`.  So `C_e = 1` iff `|W_e| > m` for every `m`, iff `e ∈ INF`.
- `G(M)` is solvable, hence amenable, hence sofic.
- By (K2), which does not use finite presentation, `X(G(M), C_e)` is sofic iff `e ∈ INF`.
- It is recursively presented, with relators `[w_(<e,m>), g_j]`.

For `C = Phi_e`: `Phi_e = 1` iff `e ∈ INF`, and the same argument applies whenever `G_e` is sofic.  By (K3),
the cone is finitely presented only if `Phi_e` is finitely generated.  ∎

## Survivor

Let `Y = H x Gamma`, `Gamma_psi = {(psi(g), g)}`, and let `(z, d) ∈ Y` centralise `Gamma_psi`.
- Comparing second coordinates gives `d ∈ Z(Gamma)`.
- Comparing first coordinates gives `z ∈ C_H(psi(Gamma))`.
- Conversely, every such pair centralises `Gamma_psi`.
- If `z ≠ 1`, then `(z, 1) ∉ Gamma_psi`, so by (K1) `Y *_(Gamma_psi) G` is nonsofic.
- The amalgam is finitely presented when `H`, `Gamma` and `G` are, because `Gamma_psi ≅ Gamma` is finitely
  generated.

Nothing in (K3) applies here: the centraliser is produced by the direct product, not by relators.  The
positive branch, soficity when `C_H(psi(Gamma)) = 1`, is not covered by any permanence theorem (F3).  This is
the named missing statement.  ∎

**ESTABLISHED (written proof over standard hyperbolic geometry and the Hopf decomposition; see
`research/fpbs-hyperbolic-bb-criterion-obstruction-proof.md`).**

**Why this matters for the flagship.** Bevilacqua--Bowen (arXiv:2510.05459, Theorem 8.1 = `T:general`) show:
if `G` has an imp action that is limit-amenable, partially doubly recurrent (PDR) and of normalized cost `p`, then
`G` has max-cost at most `p`. For exact groups, limit-amenable means amenable (their Theorem `T:exact`), and an
amenable action with infinite, non-atomic ergodic components has normalized cost 1. So for a hyperbolic group the
route to fixed price 1 is exactly this: **find an amenable, PDR imp action with infinite non-atomic ergodic
components.** This is the only published criterion that proves fixed price 1 without any commensurated or normal
amenable structure. It is the obvious route to Sp(n,1) lattices, Kazhdan hyperbolic groups and closed hyperbolic
3-manifold groups. The theorem below removes all the natural candidates at once, uniformly over the group.

**Conventions.**
- `G` is a nonelementary word-hyperbolic group, with a Cayley graph that is `delta`-hyperbolic, basepoint `o = e`, and
  boundary `dG`.
- `beta_xi(p,q) = limsup_{z -> xi} [d(p,z) - d(q,z)]` is the Busemann function. It satisfies
  `beta_{g xi}(gp,gq) = beta_xi(p,q)` exactly.
- `(X,mu)` is an ergodic imp action, and `Con`, `Dis` are the parts of the Hopf decomposition in the sense of
  Bevilacqua--Bowen (Definition `D:Hopf`, Theorem `T:Kaim-Hopf`).
- For `B` in `X` with `0 < mu(B) < infinity`, the **return set** of `x` is `Phi_B(x) = {k in G : k^{-1}x in B}`. It
  satisfies `Phi_B(gx) = g Phi_B(x)`.

**Theorem.** Let `(X,mu)` be an ergodic imp action of `G` with `Con(X)` conull (for example, non-atomic). Suppose it
is PDR. Then:
1. **(No boundary pair.)** There is no measurable `G`-equivariant map from `X` to the unordered pairs of distinct
   points of `dG`.
2. **(No shallow boundary point.)** Let `xi : X -> dG` be measurable and equivariant. Then for every `B` with
   `0 < mu(B) < infinity`, a.e. `x` has `inf_{k in Phi_B(x)} beta_{xi(x)}(ko, o) = -infinity`. So the return set goes
   arbitrarily deep into the horoballs at `xi(x)`.
3. **(Only one radial direction is ruled out.)** With `xi` as in item 2, fix an increasing exhausting sequence
   `B_1, B_2, ...` of sets of finite measure. For some `j`, a.e. `x` has a radial limit point of `Phi_{B_j}(x)`
   different from `xi(x)`. Moreover, the set `Lambda_j(x)` of all such radial limit points is infinite for a.e. `x`.
4. **(Amenable case.)** If `(X,mu)` is amenable, then the Zimmer map `phi : X -> Prob(dG)` satisfies
   `phi(x) = delta_{xi(x)}` a.e., and items 2 and 3 apply to this `xi`.

**The failing step, uniformly.** For each pair `(x,y)` whose boundary data are distinct, the proof builds a
nonempty finite equivariant set `M(x,y)` in `G`:
- In item 1, it is the quasi-centres of the at least three boundary points.
- In item 2, it is the vertices on the geodesic from `xi(x)` to `xi(y)` where the two return-set heights balance.
- In item 3, it comes from the finite set `Lambda_j(x)` together with `xi(x)`.

An equivariant nonempty finite subset of `G` makes that part of `X^2` dissipative. So `Con(X^2)` lies in
`{xi(x) = xi(y)}` (or `{S(x) = S(y)}` in item 1). The relation generated by `Con(X^2)` then cannot be conull,
because a nonelementary group fixes no point and no pair of `dG`.

**Corollary (class killed).** None of the following is PDR for a nonelementary hyperbolic group, with any invariant
Radon measure:
- geodesic-current actions on `d^2 G`, and every imp action with a measurable factor map to `d^2 G` (item 1);
- the horofunction space of a word metric, the horosphere space `dG x Z` with its Busemann cocycle, and every imp
  action with a measurable equivariant coarse horofunction `h_x` based at `xi(x)` (item 2, taking
  `B` inside `{|h_x(o)| <= R}`);
- every amenable action whose Zimmer boundary measure is not a.e. a Dirac mass (item 4);
- the Maharam extension `dG x R` of every quasi-invariant measure class on `dG` whose Radon--Nikodym cocycle
  difference grows coarsely monotonically along geodesics (property (P), proof Step 7), including Patterson--Sullivan
  measures;
- any finite-measure extension of the above (Lemma `L:finitemeasureextension` of Bevilacqua--Bowen).

For surface groups and free groups this is forced anyway, since their cost exceeds 1. For Kazhdan hyperbolic groups,
Sp(n,1) lattices and closed hyperbolic 3-manifold groups, the theorem is new information: it says where a
Bevilacqua--Bowen certificate would have to live.

**Reduction (one direction).** If a hyperbolic group `G` satisfies the Bevilacqua--Bowen criterion, then `G` has an
amenable ergodic imp action with free, non-atomic, infinite components and an equivariant boundary point `xi(x)`
with these properties:
- **(deep)** every finite-measure return set goes infinitely deep toward `xi(x)`;
- **(spreading)** some return set has infinitely many radial limit points other than `xi(x)`;
- **(crossing)** `Con(X^2)` meets `{xi(x) != xi(y)}` in positive measure.
- **(infinite slices, two-sided)** For a.e. `x` in the projection of that crossing part, the slice
  `Y(x) = {y : (x,y)` crossing and conservative`}` has infinite measure. The crossing returns are radially deep toward
  both `xi(x)` and `xi(y)`, so `xi(y)` lies in the radial limit set `Lambda_j(x)` for `mu`-a.e. `y` in `Y(x)`
  (proof, Step 6).

The converse is Bevilacqua--Bowen's theorem, provided the crossing part generates the full relation. Whether such
"deep spreading" actions exist is open; that is the named statement left by this claim.

**Calibration.**
- `F_2` and surface groups have cost > 1, so no action may pass; the theorem agrees.
- `F_2 x F_2` and `SL(3,Z)` pass the criterion (via ONP or Mellick's `G/A`). The proof uses convergence dynamics on
  `dG` and does not apply to them.
- Virtually cyclic `G` is excluded, and must be: `Z` fixes the pair `{+infinity, -infinity}`.

Notation as in the target claim. Write `E_ij(r) = 1 + r e_ij` for `i != j`, and
`[x, y] = x y x^-1 y^-1`. Suppose, for a contradiction, that `rho: Lambda -> GL_N(K)`
is injective, with `K` a number field.

## 0. Finite generation and word length

- `EL_n(R)` is generated by the `E_ij(r)`. For distinct `i, j, k` one has
  `[E_ik(a), E_kj(b)] = E_ij(ab)`, and `E_ij` is additive in `r`. So the finitely
  many `E_ij(1)` and `E_ij(r_l)`, for ring generators `r_l`, generate every
  `E_ij(monomial)`, and so `EL_n(R)`.
- `Lambda` has finite index, so it is finitely generated. Fix a finite symmetric
  generating set `S` of `Lambda` and write `|g|` for word length in `Lambda`.

## 1. A distorted root element for each `a in R`

Let `q = [EL_n(R) : Lambda]`. The subgroup `Lambda ∩ E_13(R)` has index at most
`q` in the abelian group `E_13(R) ≅ (R, +)`. So it contains `E_13(q r)` for every
`r in R`: a quotient group of exponent dividing `q!` kills `q! r`, and replacing
`q` by `q!` does no harm. The same holds for `E_32(R)`. From now on `q` denotes
this multiple.

**Commutator identity.** `e_13 e_32 = e_12`, and the products `e_32 e_13`,
`e_13 e_13`, `e_32 e_32`, `e_12 e_13`, `e_12 e_32` all vanish. Expanding the four
factors gives

```text
[E_13(x), E_32(y)] = E_12(x y).
```

For `a in R` put `g_a = E_12(q^2 a)`, an element of `Lambda`. For `m >= 1`,

```text
g_a^(m^2) = E_12(q^2 m^2 a) = [E_13(q a)^m, E_32(q)^m],
```

so `|g_a^(m^2)| <= 2m (|E_13(q a)| + |E_32(q)|)`. Writing `k = m^2 + r` with
`0 <= r <= 2m` gives `|g_a^k| <= C_a sqrt(k)` for a constant `C_a`. In particular
`|g_a^k| / k -> 0`, and the same holds for `g_a^-1`.

## 2. Eigenvalues are roots of unity of bounded order

Fix a place `v` of `K`, the completion `K_v`, an algebraic closure with the unique
extension of `|.|_v`, and the sup norm on `K_v^N` with its operator norm `||.||_v`.
The operator norm is submultiplicative. Put
`C_v = max(1, max_(s in S) ||rho(s)||_v)`, so `||rho(h)||_v <= C_v^|h|`.

- If `lambda` is an eigenvalue of `rho(g_a)` in the algebraic closure of `K_v`,
  with eigenvector `w`, then `|lambda|_v^k ||w|| = ||rho(g_a)^k w|| <= C_v^(|g_a^k|) ||w||`.
  Taking `k`-th roots and `k -> infinity` gives `|lambda|_v <= 1`.
- The same argument for `g_a^-1`, whose eigenvalues are the `lambda^-1`, gives
  `|lambda|_v >= 1`. So `|lambda|_v = 1`.

Let `lambda` be a root of the characteristic polynomial `chi in K[x]` of
`rho(g_a)`, and put `L = K(lambda)`. Every place `w` of `L` lies over a place `v`
of `K`, and `|lambda|_w = |sigma(lambda)|_v` for some `K`-embedding `sigma` of
`L` into the algebraic closure of `K_v`. Then `sigma(lambda)` is a root of `chi`,
so it is an eigenvalue of `rho(g_a)` over `K_v`. Hence `|lambda|_w = 1` for every
place `w` of `L`.
- At the finite places this makes `lambda` an algebraic integer.
- At the archimedean places, every conjugate of `lambda` has modulus 1.

By Kronecker's theorem `lambda` is a root of unity. Its degree over `Q` is at most
`D = N [K:Q]`. Only finitely many roots of unity have degree at most `D`. Let `e`
be the least common multiple of their orders. Then every eigenvalue of `rho(g_a)^e`
equals 1 for every `a in R`, so `rho(g_a)^e` is unipotent.

## 3. An infinite-rank vector group inside a finite-rank one

- **Commuting unipotents.** For `a, b in R` the elements `g_a^e = E_12(e q^2 a)`
  commute. For a unipotent `u in GL_N(K)` put
  `log u = sum_(j=1)^(N-1) (-1)^(j+1) (u - 1)^j / j`. This is a finite sum in
  `M_N(K)`, it is injective on unipotents with inverse `exp`, and
  `log(u u') = log u + log u'` when `u` and `u'` commute.
- **The map.** `phi: (R, +) -> (M_N(K), +)`, `a -> log rho(E_12(e q^2 a))`, is a
  homomorphism. Its kernel is `{a : e q^2 a = 0}`, because `rho` and `log` are
  injective, so the kernel is torsion. So `phi(R)` has the same torsion-free rank
  as `R`, which is infinite.
- **Contradiction.** `(M_N(K), +)` is a `Q`-vector space of dimension
  `N^2 [K:Q]`, so each of its subgroups has torsion-free rank at most `N^2 [K:Q]`.
  So no injective `rho` exists.

## 4. `Qbar` equivalence

A finitely generated subgroup of `GL_N(Qbar)` has matrix entries in a finitely
generated subfield of `Qbar`, which is a number field. So "linear over `Qbar`" and
"linear over some number field" agree for the finitely generated group `Lambda`.

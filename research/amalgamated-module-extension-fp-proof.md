Notation as in the claim. Put `H = S ⋊ V` and `G = S ⋊ W`. `V` is a retract of the
finitely presented group `H`, hence finitely presented, in particular finitely generated.

**Presentation.** Let `P = H *_V W`, amalgamating `V <= H` with `V <= W`. It is finitely
presented: take finite presentations of `H` and `W` and identify a finite generating set
of `V` in both. Let `G'` be `P` modulo the finitely many relators

    x_j^ε m_(j,l) x_j^(-ε) = x_j^ε·m_(j,l)        (ε = ±1, all j, l),

where both sides are elements of `S <= H` written as words. The inclusions `H <= G` and
`W <= G` agree on `V`, and the relators hold in `G`, where conjugation by `w ∈ W`
restricts to the action on `S`. So there is a surjection `π : G' -> G`.

**Step 1: `S` is normal in `G'`.** Write `S'` for the image of `S <= H` in `G'`. Inside `H`,
`c m c^(-1) = c·m` for `c ∈ V`, `m ∈ S`. For `c ∈ C_j` the relation `c x_j = x_j c` holds
in `W`, hence in `G'`, so

    x_j^ε (c·m_(j,l)) x_j^(-ε) = c (x_j^ε m_(j,l) x_j^(-ε)) c^(-1) = c (x_j^ε·m_(j,l)) c^(-1) ∈ S'.

The elements `c·m_(j,l)` generate `S'`, so `x_j` and `x_j^(-1)` normalize `S'`, and `V`
normalizes `S'` inside `H`. Since `W = <V, x_1, ..., x_r>` and `G'` is generated by `H` and
`W`, `S'` is normal in `G'`.

**Step 2: `G'/S' ≅ W`.** Killing `S` turns `H` into `V`, `P` into `V *_V W = W`, and every
relator into a triviality, since both of its sides lie in `S`.

**Step 3: `π` is injective.** The composite `S -> S' -> S <= G` is the inclusion, so `π` is
injective on `S'`. The maps `G' -> G -> G/S ≅ W` and `G' -> G'/S' ≅ W` agree on the
generators `H ∪ W`, so `ker π <= S'`, and therefore `ker π = 1`. Hence `G ≅ G'` is finitely
presented.

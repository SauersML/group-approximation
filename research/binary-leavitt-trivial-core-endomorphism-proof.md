Notation as in the target.

**Item 1.** `L` is generated as a ring by `s_1, s_2, t_1, t_2`, so for `n >= 3` the group `P`
is generated by the finitely many `e_ij(r)` with `r` in `{1, s_1, s_2, t_1, t_2}`, using
`e_ij(ab) = [e_ik(a), e_kj(b)]` for distinct `i, j, k`. Simplicity for `n >= 3` is
`binary-leavitt-elementary-group-is-simple` (its route is backed by
`GroupApproximation/Leavitt/RootDetectionBinary.lean`). Property (T): `St_n(L)` has (T) for
`n >= 3` because `L` is finitely generated (Ershov--Jaikin-Zapirain, arXiv:0809.4095v2,
Theorem 6.2, source checked in `steinberg-finiteness-kazhdan-citation`), and (T) passes to
the quotient `EL_n(L)`.

**Step 1: `m` is a non-unital ring endomorphism.** `m` is additive, and
`m(x) m(y) = s_1 x t_1 s_1 y t_1 = s_1 x y t_1 = m(xy)` because `t_1 s_1 = 1`. Entrywise, the
same holds for matrices: `m(X) m(Y) = m(XY)` for `X, Y` in `M_n(L)`. Also `m` is injective,
since `t_1 m(x) s_1 = x`.

**Step 2: `F` is an injective homomorphism into `P`.** For `g = I + X`, `h = I + Y`,

    F(g) F(h) = I + m(X) + m(Y) + m(X)m(Y) = I + m(X + Y + XY) = F(gh),

since `gh = I + X + Y + XY`. With `F(I) = I` this makes `F` a monoid endomorphism of
`M_n(L)`, hence a group homomorphism on `GL_n(L)`. It sends the generator `e_ij(r)` to
`e_ij(m(r))`, which lies in `P`, so `F(P) <= P`. It is injective because `m` is.

**Step 3: `F` is not surjective.** Every `F(g)` has off-diagonal entries in `m(L) = s_1 L t_1`.
If `1 = s_1 x t_1`, then `t_2 = t_2 s_1 x t_1 = 0`, contradicting `t_2 s_2 = 1`. So `e_12(1)`
is not in `F(P)`.

**Step 4: the core of `m` is zero.** Write `e_i = s_i` and `e_i^* = t_i`, so that `L` is the
Leavitt path algebra of the rose with two petals. A basis of `L` over `F_2` is the set `B` of
monomials `e_α e_β^*` with `α, β` words in `{1, 2}`, excluding those where `α` and `β` are
both nonempty and both end in `2`. This is the standard normal-form basis of a Leavitt path
algebra with special edge `e_2` (Abrams--Ara--Siles Molina, *Leavitt Path Algebras*,
Section 1.5; cited, not read at source).
- `m(e_α e_β^*) = e_1 e_α e_β^* e_1^* = e_(1α) e_(1β)^*`.
- If `α` and `β` are both nonempty, the last letters are unchanged. If `α` is empty, then
  `1α = 1` ends in `1`. So `m` maps `B` injectively into `B`.
- Hence `m^j(L)` is the span of `m^j(B)`, whose monomials have both words of length at
  least `j`.
- A nonzero `x` has a unique expansion in `B` with finitely many monomials, of lengths at
  most some `ℓ`. It is not in the span of `m^(ℓ+1)(B)`. So the intersection of the
  `m^j(L)` is `0`.

**Step 5: item 4.** By induction `F^j(g) = I + m^j(g - I)`. So if `g` lies in every `F^j(P)`,
then every entry of `g - I` lies in every `m^j(L)`, hence is `0` by Step 4, and `g = I`.

**Unit-group form.** On `L^x`, the same map is `u -> 1 + m(u - 1) = s_1 u t_1 + s_2 t_2`,
since `1 - m(1) = 1 - s_1 t_1 = s_2 t_2`. Steps 1--5 apply verbatim with `n = 1`.

**OPEN.**  Fix one level of the shared BCS and its current first-hit prefix
`C_n`.  For every context, the oriented Schur child ledger consists of one
retained copy over every selector type and one additional exit copy over every
forbidden type.  Construct a finite ordinary-group extension and literal word
transports such that, in every sufficiently accurate normalized-HS matrix
model, all returned retained copies satisfy

```text
P_c <= C_(n+1) + O_HS(sqrt(E))
```

for one common tag-survivor projection `C_(n+1)<=C_n`, while the charged exit
copies lie in the complementary first-hit layer

```text
X_n=C_n-C_(n+1).
```

The transports must agree on the literal next-level shared variables across
overlapping contexts and have constants independent of the matrix dimension.
They must not identify whole context selector centers, which would
classicalize the contextual BCS.

`schur-atom-central-product-has-s3-endpoint-split` and
`two-bit-tag-routing-splits-s3-exit-and-survivor` prove the desired
active/exit placement for one already selected forbidden atom.  They do not
yet show that the full retained one-copy child vector for all selector types
and all contexts can use a single tag square.  In particular, assigning an
independent tag square to every forbidden atom generally intersects several
survivor complements and can delete allowed baseline mass; transporting only
one maximal forbidden atom does not by itself return a complete shared BCS
carrier.

The direct context-atom bridge has an additional algebraic obstruction.
`schur-commutator-tag-is-not-fresh-under-selector-transport` proves that once
the selector tuple is transported, the endpoint commutator `K_a` forces the
first target tag to be the corresponding affine selector word.  Transporting
only the endpoint table leaves the tag fresh but loses the successor context
atom.  A solution must avoid this dichotomy, for example by transporting a
larger finite type chart whose survivor sum is intrinsic without identifying
the nonlinear sum with a scalar endpoint word.

## Attempts

- **Independent tag squares.**  Give each forbidden atom its own survivor
  tag.  This dies because intersecting the several survivor complements can
  delete allowed baseline mass, while selecting only one forbidden atom does
  not return the complete shared carrier.
- **Transport the full selector tuple.**  This preserves the successor
  context atom but dies at
  `schur-commutator-tag-is-not-fresh-under-selector-transport`: the endpoint
  commutator forces the first target tag to be an affine selector word, so it
  is no longer a fresh common tag.
- **Transport only the endpoint table.**  This leaves the tag fresh but loses
  the successor context atom.  The larger finite-type-chart alternative is
  deferred until its survivor sum can be made intrinsic without scalarizing
  the nonlinear selector sum.

Once this claim is established,
`prefix-central-reducing-hull-recombines-context-returns` removes the remaining
multiplicity gauges and `shared-bcs-recombination-via-prefix-reducing-hull`
proves the shared-carrier incidence needed by the first-hit ladder.

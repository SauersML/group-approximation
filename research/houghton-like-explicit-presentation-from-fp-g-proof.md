Lane proof, elementary, not independently reviewed. **Second, independent proof** of the target, written in parallel with (and landed after) the proof on the target node by bh-houghton-presentation, which uses `finitary-mixing-of-fp-highly-transitive-groups-is-fp` and P. Hall's extension lemma. This route instead writes down an explicit finite presentation of `H_n(G)`; its case `n = 2` uses no Houghton-group input at all, and its case `n >= 3` uses only Brown's finite presentation of `H_n`. The two proofs share only the Mallery--Zaremsky inputs (M1)–(M3) and the germ computation (M4), so they cross-check each other.

## Inputs

Mallery--Zaremsky, arXiv:2202.00822, read at source (TeX in `gq/src/bh-map/mz-2202.00822.tex`):
- **(M1)** Theorem `thrm:contain_symfin`: every infinite shift-similar `G <= Sym(N)` contains `FSym(N)`.
- **(M2)** Lemma `lem:strong_shift1_surj`: if `G` is strongly shift-similar then `psi_1 : Stab_G(1) -> G` is an
  isomorphism. Write `theta = psi_1^{-1} : G -> Stab_G(1) <= G`, an injective homomorphism. Concretely `theta(g)`
  fixes `1` and sends `i+1` to `g(i)+1`.
- **(M3)** Proposition `prop:gens`: for `n >= 2`, `H_n(G)` is generated by `H_n` and `G^n`; and `H_1(G) = G`
  (Proposition `prop:H1_equal`).
- **(M4)** `houghton-like-envelopes-have-fp-germs-iff-fp-near-shift-group` item 1: the ray-germ map gives
  `H_n(G)/FSym(X) ≅ Q_n(Ĝ)`, `X = [n] x N`, `Ĝ = Germs(G) ⋊ <s̄>`, with `s̄^{-1} ḡ s̄ = psi_inf(ḡ)` an automorphism.
  So `Q_n(Ĝ) = Germs(G)^n ⋊ Λ` with `Λ = {(s̄^{c_1},...,s̄^{c_n}) : Σ c_k = 0} ≅ Z^{n-1}`.
- **(H)** Houghton groups (recalled in MZ §5.3 and §4, not re-read): `H_m` is finitely generated for `m >= 2`, and
  finitely presented for `m >= 3` (K. S. Brown, J. Pure Appl. Algebra 44 (1987); `H_m` is `F_{m-1}`).

Fix a finite presentation `G = <g_1..g_r | R>`. For `y in G` let `W(y)` be a fixed word in the `g_i`. For a
subgroup copy on ray `k`, write `Φ_k(w)` for the word `w` with letters `g_i^{(k)}`.

**Translations.** For `j != k` let `t_{jk} in H_n` send `(j,1) -> (k,1)`, `(j,m) -> (j,m-1)` for `m >= 2`,
`(k,m) -> (k,m+1)`, and fix other rays. Then `t_{kj} = t_{jk}^{-1}`. For `g in G` acting on ray `k` (identity
elsewhere) one computes `t_{jk} g t_{jk}^{-1} = theta(g)` on ray `k`: it fixes `(k,1)` and sends `(k,m)` to
`(k, g(m-1)+1)` for `m >= 2`. This is **(T)**, valid in `H_n(G)`.

## Case n = 1

`H_1(G) = G` (M3).

## Case n = 2

Put `t = t_{21}`, so `t` pushes `(2,1)` into ray 1 and `t^{-1}` pushes `(1,1)` into ray 2. Let `u` be a word in the
`g_i` for the transposition `(1 2) in FSym(N) <= G` (M1).

**Presentation H\*.** Generators `g_i^{(1)}, g_i^{(2)}, t`. Relations:
- (P1) `R` in the letters `g^{(1)}`, and `R` in the letters `g^{(2)}`;
- (P2) `[g_i^{(1)}, g_{i'}^{(2)}] = 1`;
- (P3) `t g_i^{(1)} t^{-1} = Φ_1(W(theta(g_i)))` and `t^{-1} g_i^{(2)} t = Φ_2(W(theta(g_i)))`;
- (P4) `Φ_2(u) = t^{-2} Φ_1(u) t^2`.

All hold in `H_2(G)`: (P3) is (T) (for ray 2 with `t^{-1} = t_{12}`); for (P4), `t^{-2}` sends `(1,1) -> (2,2)` and
`(1,2) -> (2,1)`. By (M3), and since `H_2 = <t, (1 2)>` with `(1 2)` in the copy of `G` on ray 1, the natural map
`π : H* -> H_2(G)` is onto. The copies give homomorphisms `Φ_k : G -> H*` (by P1), and by (P3) the two
homomorphisms `y -> t Φ_1(y) t^{-1}` and `y -> Φ_1(theta(y))` agree on generators, hence on `G`; likewise
`t^{-1}Φ_2(y)t = Φ_2(theta(y))` for all `y`.

**Step 1: the finitary part.** Put `F_1 = ⋃_{m>=0} t^{-m} Φ_1(FSym(N)) t^m` and
`F_2 = ⋃_{m>=0} t^{m} Φ_2(FSym(N)) t^{-m}`.
- *Increasing.* `t Φ_1(FSym) t^{-1} = Φ_1(theta(FSym)) <= Φ_1(FSym)` since `theta` preserves finite support; so the
  union `F_1` is increasing and `t^{±1} F_1 t^{∓1} = F_1`. Same for `F_2`.
- *Faithful.* `π ∘ Φ_1` is the inclusion of `G` on ray 1, so `Φ_1` is injective on `FSym(N)`, and `π` is injective on
  each piece, hence on the increasing union `F_1`. Its image is `⋃_m FSym(ray 1 ∪ {(2,1),...,(2,m)}) = FSym(X)`
  (`t^{-m}` maps ray 1 onto ray 1 plus the first `m` points of ray 2). So `π|F_1 : F_1 -> FSym(X)` is an isomorphism;
  likewise `F_2`.
- *F_1 = F_2.* By (P4), `Φ_2(τ_{12}) in F_1`. From `t^{-1}Φ_2(y)t = Φ_2(theta(y))` and
  `theta(τ_{a,a+1}) = τ_{a+1,a+2}`, induction gives `Φ_2(τ_{a,a+1}) in F_1` for all `a`, so `Φ_2(FSym(N)) <= F_1`
  and, by `t`-invariance, `F_2 <= F_1`. Symmetrically (P4 read as `Φ_1(u) = t^2Φ_2(u)t^{-2}`) `F_1 <= F_2`.
  Put `F = F_1 = F_2`.
- *Normal.* For `g in G` and `z = t^{-m}Φ_1(y)t^m`: `Φ_1(g) z Φ_1(g)^{-1} = t^{-m}Φ_1(theta^m(g) y theta^m(g)^{-1})t^m`,
  using `t^mΦ_1(g)t^{-m} = Φ_1(theta^m(g))`; this is in `F` since `FSym(N)` is normal in `G`. So `Φ_1(G)` normalizes
  `F = F_1`, and symmetrically `Φ_2(G)` normalizes `F = F_2`; `t` normalizes `F`. Hence `F ⊴ H*`.

**Step 2: the quotient.** `H*/F` is generated by the images of `Φ_1(G)`, `Φ_2(G)` and `t`. Since
`Φ_k(FSym(N)) <= F`, each copy image is a quotient of `Germs(G) = G/FSym(N)`. The images commute (P2). Conjugation
by `t̄` acts on copy 1 by `theta̅ = psi_inf^{-1}`, and `t̄^{-1}` acts on copy 2 by `psi_inf^{-1}`, hence `t̄` acts on
copy 2 by `psi_inf` (an automorphism of `Germs(G)`, M4). So there is an onto homomorphism
`Q' := Germs(G)^2 ⋊ <t̄> -> H*/F` with the same action. The composite `Q' -> H*/F -> H_2(G)/FSym(X) ≅ Q_2(Ĝ)` sends
copy `k` to germs on ray `k` and `t̄` to `(s̄, s̄^{-1})`; it is the standard isomorphism `Q' ≅ Q_2(Ĝ)` (M4). Hence
`Q' -> H*/F` is injective and `H*/F -> Q_2(Ĝ)` is an isomorphism.

**Step 3.** `π` restricts to an isomorphism `F -> FSym(X)` and induces an isomorphism `H*/F -> H_2(G)/FSym(X)`. By
the five lemma `π` is an isomorphism, so `H_2(G)` has the finite presentation (P1)–(P4).

## Case n >= 3

**Presentation H\*.** Generators: a finite generating set of `H_n` with a finite presentation `P_H` (H), and
`g_i^{(k)}` for `i <= r`, `k <= n`. Let `φ_H : H_n -> H*` and `Φ_k : G -> H*` be the resulting homomorphisms.
Relations:
- (Q1) `P_H`;
- (Q2) `R` in the letters `g^{(k)}`, for each `k`;
- (Q3) for each `k`: `Φ_k(u) = φ_H(τ^{(k)}_{12})`, where `τ^{(k)}_{12}` swaps `(k,1),(k,2)`;
- (Q4) `[g_i^{(k)}, g_{i'}^{(l)}] = 1` for `k != l`;
- (Q5) for each `k`: `[g_i^{(k)}, φ_H(c)] = 1` for `c` in a finite generating set of the subgroup
  `H^{(k̂)} <= H_n` of elements fixing ray `k` pointwise; `H^{(k̂)} ≅ H_{n-1}`, finitely generated as `n-1 >= 2`;
- (Q6) `φ_H(t) g_i^{(k)} φ_H(t)^{-1} = Φ_k(W(theta(g_i)))` for the pairs `(k, t) = (1, t_{j1})`, `j = 2..n`, and
  `(k, t) = (j, t_{1j})`, `j = 2..n` (valid by T). For Step 1 fix `t_1 = t_{21}` and `t_k = t_{1k}` (`k >= 2`);
- (Q7) for each `k`, with `j_1 = 2` and `j_k = 1` (`k >= 2`):
  `g_i^{(k)} φ_H(τ_0^{(k)}) (g_i^{(k)})^{-1} = φ_H(τ_{(k,g_i(1)),(j_k,1)})`, where `τ_0^{(k)} = τ_{(k,1),(j_k,1)}`.

All relations hold in `H_n(G)` and `π : H* -> H_n(G)` is onto (M3). `φ_H` is injective, since `π∘φ_H` is the
inclusion. Put `F = φ_H(FSym(X))`, isomorphic to `FSym(X)` via `π`.

**Step 1: identification on ray k.** `Φ_k = φ_H` on `FSym(ray k)`. As in Case 2, (Q6) gives
`φ_H(t_k)Φ_k(y)φ_H(t_k)^{-1} = Φ_k(theta(y))` for all `y in G`. Base: (Q3). Induction: `τ_{m+1,m+2} = theta(τ_{m,m+1})`
in `G` and `= t_k τ_{m,m+1} t_k^{-1}` in `H_n`, so both homomorphisms agree on all adjacent transpositions of ray `k`.

**Step 2: F is normal.** `φ_H(H_n)` normalizes `F`. Fix `k` and `g in G`, `x = Φ_k(g)`. For a transposition
`τ_e`, `e ⊂ X`:
- (a) `e` off ray `k`: `τ_e in H^{(k̂)}`, which `x` centralizes by (Q5). So `x τ_e x^{-1} = τ_e = τ_{ge}`.
- (b) `e ⊂ ray k`: by Step 1, `x φ_H(τ_e) x^{-1} = Φ_k(g τ_e g^{-1}) = φ_H(τ_{ge})`.
- (c) mixed, `e = {(k,a),(l,b)}`, `l != k`. First extend (Q7) from generators to all `g in G`: the set of `g`
  satisfying `x φ_H(τ_0) x^{-1} = φ_H(τ_{(k,g(1)),(j_k,1)})` contains the `g_i`, and is closed under products and
  inverses. Indeed, writing `τ_{(k,g'(1)),(j_k,1)} = α τ_0 α^{-1}` with `α in FSym(ray k)`, `α(1) = g'(1)`, and
  using (b) for `α`, the case of `gg'` follows from those of `g` and `g'`; inverses are the same computation with
  `α(1) = g^{-1}(1)`. Now write `τ_e = (αγ) τ_0 (αγ)^{-1}` with `α in FSym(ray k)`, `α(1) = a`, and
  `γ in FSym(X \ ray k) <= H^{(k̂)}` sending `(j_k,1)` to `(l,b)`. Then
  `x φ_H(τ_e) x^{-1} = φ_H(gαg^{-1}) φ_H(γ) φ_H(τ_{(k,g(1)),(j_k,1)}) φ_H(γ)^{-1} φ_H(gαg^{-1})^{-1} = φ_H(τ_{ge})`,
  by (b), (a) and the extended (Q7).
  So `Φ_k(G)` normalizes `F` (it maps a generating set into `F`, and it is a group). Since `H*` is generated by
  `φ_H(H_n)` and the `Φ_k(G)`, `F ⊴ H*`.

**Step 3: the quotient.** `H*/F` is generated by `φ_H(H_n)F/F ≅ H_n/FSym(X) = Λ` and the copy images, which are
quotients of `Germs(G)` (Step 1: `Φ_k(FSym(ray k)) <= F`). Take `t_{j1}` (`j = 2..n`) among the generators of
`H_n`, so their images generate `Λ`. The copies commute (Q4). `t̄_{j1}` acts on copy 1 by `psi_inf^{-1}` (Q6), on
copy `j` by `psi_inf` (Q6 for copy `j` uses `t_{1j} = t_{j1}^{-1}`; invert the automorphism), and trivially on
copies `l ∉ {1,j}` (Q5: `t_{j1} in H^{(l̂)}`). So `Q' = Germs(G)^n ⋊ Λ -> H*/F` is onto, and the composite with
`H*/F -> H_n(G)/FSym(X) ≅ Q_n(Ĝ)` is the standard isomorphism (M4). As in Case 2, `H*/F ≅ Q_n(Ĝ)` and, by the five
lemma, `π` is an isomorphism. The presentation (Q1)–(Q7) is finite.

## Scope

- Strong shift-similarity is used exactly in (M2), to make `t g t^{-1}` a word in `G`, and in (M4).
- For `G` not finitely presented the relation set (Q2)/(P1) is infinite. This is consistent with the refuted germ
  lifting `houghton-like-envelopes-lift-finite-presentation-from-germs`, where `G = E_nu(Z)` is not finitely
  presented. The argument says nothing about groups `G` that are not finitely presented but have some
  finitely presented `H_n(G)`, such as `H_2`.
- Relies on the classical facts (H), recalled not re-read, only for `n >= 3`; the case `n = 2` is self-contained.

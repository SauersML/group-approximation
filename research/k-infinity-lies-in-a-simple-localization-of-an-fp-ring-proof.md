Lane proof. Notation as in the claim. Write `g·a = g a g^-1`.

**Item 1: the relations hold in T.** `x·t = t_s`, `y·t = t_(1+s) = t + t_s`, the
action of `x` and `y` commutes, and `P` is commutative.

**Item 1: nothing else holds.** Let `T'` be the presented ring.
- The group generated by `x, y` in `T'` maps onto `Z^2 ⊂ T`, and `xy = yx`, so it
  is `Z^2`. Let `L ⊆ T'` be the additive span of the conjugates `g·t`,
  `g ∈ Z^2`. It is a `Z[Z^2]`-module under conjugation, generated by `t`, and it
  satisfies `(y - 1 - x)·t = 0`.
  - So `L` is a quotient of `Z[x^(±1), y^(±1)]/(y - 1 - x) ≅ V`.
  - `L` maps onto the span of the `t_v` in `T`, which is `V`, and the composite
    `V -> L -> V` is the identity. So `L ≅ V`.
- **Commutativity.** Put `t_k = x^k·t` and `c_k = [t, t_k]`. Conjugating by
  powers of `x`, it suffices to show `c_k = 0` for `k >= 1`.
  - `c_1 = 0` is a relation.
  - Suppose `c_j = 0` for `1 <= j <= k`, so `[t_a, t_b] = 0` whenever `|a - b| <= k`.
    Conjugate `c_1 = 0` by `y^k`, using `y^k·t = Σ_(i=0)^k C(k,i) t_i`:
    `0 = Σ_(i,j=0)^k C(k,i) C(k,j) [t_i, t_(j+1)]`.
  - The gaps `j + 1 - i` lie in `[1-k, k+1]`, and only `i = 0, j = k` has gap
    `k + 1`. So `0 = c_(k+1)`.
  - For arbitrary `g, h ∈ Z^2`, `g·t` and `h·t` are conjugate, by one element,
    to `Z`-combinations of the `t_i`. Elements `y^b` with `b < 0` are cleared by
    conjugating with `y^(-b)` first. So `L` is commutative.
- **Normal form.** Let `P'` be the subring generated by `L`. It is commutative
  and generated by `L ≅ V`, so it is a quotient of `Sym(V) = P`; and it maps
  onto `P`. Hence `P' ≅ P`.
  - Every element of `T'` is `Σ_g p_g g` with `p_g ∈ P'`, using
    `g t = (g·t) g`.
  - In `T` the group elements are a basis over `P`. So `T' -> T` is injective.

**Item 2.**
- `S` is `Z^2`-invariant and central in `P`, so `S^-1 T = S^-1 P ⋊ Z^2`, and
  `S^-1 P = Frac(P) = K_∞`.
- **Faithful.** `x^a y^b` sends `t` to `t_(s^a (1+s)^b)`, and
  `s^a (1+s)^b = 1` in `V` only for `a = b = 0`.
- **Simple.** Let `I` be a nonzero ideal of `K ⋊ G`, with `G` acting faithfully
  on the field `K`. Take `α = Σ_g f_g g ∈ I` nonzero of minimal support, and
  multiply by `g_0^-1` and a scalar so that `f_1 = 1`.
  - For `λ ∈ K`, `λα - αλ = Σ_g (λ - g(λ)) f_g g` lies in `I` and has smaller
    support, so it is 0.
  - Hence every `g` in the support fixes every `λ`, so `g = 1` and `α = 1 ∈ I`.
- The skew Laurent ring `K_∞[x^(±1); σ]` is the case `G = Z`, acting by the
  shift, which is faithful.

**Item 3.**
- Let `A ⊆ Frac(P) ⋊ G` be generated by `a_1, ..., a_m`, with
  `a_i = Σ_g f_(i,g) g`.
  - Products of the `a_i` have coefficients in the subring `L_0 ⊆ Frac(P)`
    generated by the `G`-translates of the finitely many `f_(i,g)`.
  - So `A ∩ Frac(P) ⊆ L_0 ⊆ P[1/h(e_1), ..., 1/h(e_r) : h ∈ G]`, where
    `e_1, ..., e_r` are the irreducible factors of the denominators.
- Suppose `Frac(P) ⊆ A`, so `1/q ∈ L_0` for every irreducible `q`.
  - The ring `P[1/h(e_j)]` is a localization of a UFD, so its units are the
    products of the inverted primes and scalars. Hence each irreducible `q` is
    a scalar multiple of some `h(e_j)`.
  - `G` preserves total degree, so `deg q ∈ {deg e_1, ..., deg e_r}`.
- That fails for `q = t^d + 2`, which is irreducible by Eisenstein at `2`, for
  every `d`. So `Frac(P) ⊄ A`.
- For `K_∞ ⋊ Z^2`, the substitutions `t_v -> t_(hv)` are linear. For
  `K_∞[x^(±1); σ]`, `σ` permutes variables. Both preserve degree.

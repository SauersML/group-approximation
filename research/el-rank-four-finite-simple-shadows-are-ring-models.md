**ESTABLISHED (unreviewed).** Let `N >= 4`, let `R` be a unital ring generated by `x_1, …, x_s`, and let
`F = Z<t_1, …, t_s>` with `π: F → R`. Mark `G = EL_N(R)` by `e_ij(1)` and `e_ij(x_m)`. If
`(Q_k, T_k) → (G, T)` with `Q_k` finite nonabelian simple, then for all large `k`:
- there are a finite field `F_(q_k)` and a surjective ring map `ρ_k: F → M_(d_k)(F_(q_k))` with
  `Q_k ≅ PSL_(N d_k)(F_(q_k))`, carrying `T_k` to the images of `e_ij(1)`, `e_ij(ρ_k(t_m))`;
- every finite set of relations of `R` is eventually killed by `ρ_k`.

If `G` is infinite and simple, `d_k → ∞` (`simple-lef-groups-are-limits-of-finite-simple-groups`).

Mechanism:
1. **Cover.** `St_N(F)` is finitely presented, so large approximants are quotients of it.
2. **Level ideal.** The root kernels form one two-sided ideal of finite index, so `Q_k` is a quotient of
   `St_N(A_k)` with `A_k` finite.
3. **Central kernel.** `K_2(N, A_k)` is central (semilocal crossed module), so `Q_k` is a quotient of `E_N(A_k)`.
4. **Radical.** The congruence kernel of the radical is nilpotent, so `Q_k` is a quotient of
   `E_N(A_k/J) = ∏ SL_(N d_i)(F_(q_i))`.
5. **Type.** One factor survives.

Rank three is excluded only because `St_3` over a free ring is not finitely presented (Krstić–McCool, Corollary 2).

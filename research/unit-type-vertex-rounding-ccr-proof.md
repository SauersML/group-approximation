The full derivation is in §§2–4 of the artifact. Outline:

- **Item 1.** `π_n(e_ij(R_+))` is a commuting family of unitaries of order dividing `p`, hence
  finite. So each `A_ij = ker π_n|e_ij(R_+)` has finite index.
  - `I = ∩ A_ij` is an ideal: `e_ij(fa) = [e_ik(f), e_kj(a)]` with `k ∉ {i,j}`, which needs `r >= 3`.
  - `π_n` then factors through `St_r(R_+/I)`, which is finite.
- **Item 2.** In the unit-type part `A_u`, each `y_j = x^(A e_j)` has finite order, so `y_j^(-1)`
  lies in the image of `S`. Hence `x_i = ∏ y_j^((A^(-1))_ij)` lies there too, and the image of `S`
  is `A_u`. So `Λ` and `Γ` have the same image on `range(P_n)`.
- **Item 3.** For a contraction `x ∈ π_n(Λ)'`, `P_n x P_n` commutes with `π_n(Γ)` by item 2.
  Therefore `||x - E x||_2 <= 2 ||x - P_n x P_n||_2 <= 4 ||1 - P_n||_2`.
- **Item 4.** Apply item 2 of `vertex-rounding-reduces-ccr-to-commutant-excess`. Then:
  - `SL_d(Z)` is generated by the `e_ij(1)`;
  - every exponent vector is an `SL_d(Z)`-translate of a nonnegative one, so `EL_r(L)` is
    generated by conjugates of `Γ`;
  - so `G = <Γ, e_ij(1)>`, and `Ad σ(e_ij(1))` preserves `σ(Γ)' ∩ M`.

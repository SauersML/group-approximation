Complete direct proof. Notation as in the target. Everything is checked
componentwise in `End(M_r)`, where all five generators are well defined, since
`l j mod l^r` and `(1+lj)^(-1) mod l^r` depend only on `j mod l^(r-1)`.

**1. Relations.**
- `x` and `x'` are inverse cyclic shifts.
- `x u f_j = l j f_(j-1)` and `(u + l) x f_j = (l(j-1) + l) f_(j-1) = l j f_(j-1)`,
  so `x u = (u+l) x`.
- `u + 1` and `B` are diagonal with inverse entries `1 + lj` and `(1+lj)^(-1)`.
- `u e = e u = 0`, because both are diagonal and `u f_0 = 0`.
- `e` is a coordinate projection, so `e^2 = e`.

**2. Residual finiteness.** `M_r` has `l^(r P_r)` elements, so `End(M_r)` is finite.
An element of `R̄_l ⊆ ∏_r End(M_r)` is zero iff all its components are. Each
projection `R̄_l -> End(M_r)` is a ring homomorphism to a finite ring.

**3. Resolvents.** From `x u x^(-1) = u + l` and `x` invertible,
`x^k u x^(-k) = u + k l` for every `k in Z`, so `x^k (u+1) x^(-k) = u + 1 + k l = u + m`.
Its inverse is `x^k B x^(-k)`.

**4. The corner.**
- *`y_m` lies in the corner.* `e` commutes with `u` (both products are 0), hence with
  `u + m` and with `(u+m)^(-1)`. So `y_m = (u+m)^(-1) e = e (u+m)^(-1) e`.
- *`m y_m = e`.* Since `u e = 0`, `(u+m) e = m e`. Multiplying by `(u+m)^(-1)` gives
  `e = m (u+m)^(-1) e = m y_m`.
- *Commutativity.* The elements `y_m` and `e` all lie in the ring generated by `u`,
  the `(u+m)^(-1)` and `e`, which is commutative.
- *Existence of `θ`.* In the commutative corner subring
  `C = Z[e, y_m : m ≡ 1 mod l]` with unit `e`, every integer `m ≡ 1 (mod l)` is
  invertible. If `l ∤ b` then `b^(l-1) ≡ 1 (mod l)` (Fermat), and
  `b · (b^(l-2) y_(b^(l-1))) = b^(l-1) y_(b^(l-1)) = e`. So every integer prime to `l`
  is invertible in `C`. By the universal property of localization, `n -> n e`
  extends uniquely to a unital ring homomorphism `θ : Z_(l) -> C ⊆ e R̄_l e`.
- *Components.* In the component `r`, `e` is the projection onto `f_0` and `u` acts
  on `f_0` by 0. So `y_m` acts on `f_0` by `m^(-1) mod l^r`, and `θ(c)` acts on `f_0`
  by `c mod l^r` and by 0 on every other `f_j`.
- *Injectivity.* If `c in Z_(l)` is nonzero, then `c ∉ l^r Z_(l)` for `r` large, and
  the component `r` of `θ(c)` is nonzero.

**5. Remarks.**
- *`R̄_l / l R̄_l` is infinite.* The ring map `R̄_l -> ∏_r End(M_r / l M_r)` factors
  through `R̄_l / l R̄_l`. In the factor `r` the image of `x` is a cyclic permutation
  matrix of order `P_r = l^(r-1)`. These orders are unbounded, so the image, and
  hence `R̄_l / l R̄_l`, is infinite.
- *Commutative quotients.* Let `C` be a commutative quotient of `R̄_l` with `ē ≠ 0`.
  Then `ē C` is a finitely generated commutative ring with unit `ē`, and every integer
  `b` prime to `l` is a unit of it (item 4). If its characteristic were 0, the image of
  `Spec(ē C) -> Spec Z` would contain a nonempty open subset, so `ē C / q ē C != 0` for
  all but finitely many primes `q`, contradicting invertibility. If the characteristic
  is `m > 0` and a prime `q != l` divides `m = q m'`, then `q` invertible gives
  `m' ē = 0`, contradicting minimality. So the characteristic is a power of `l`.
- *Dedekind finiteness.* If `a b = 1` in a finite ring then left multiplication by `b`
  is injective, hence bijective, so `b a = 1`. This holds componentwise, hence in
  `R̄_l`. ∎

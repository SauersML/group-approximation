## Lemma 0 (the central projection)

Let `J` be central of order `m | n` in a group `G`, and `omega` faithful of
order `n`. In any unitary representation `pi` of `G`, `pi(J)` has spectrum in
the `m`-th roots of unity, and on the `zeta`-eigenspace

```text
pi(p_omega) = (1/n) sum_k (conj(omega) zeta)^k = [zeta = omega(J)],
```

where `omega(J) = exp(2 pi i j/n)` with `gcd(j,n) = 1`. Since `zeta^m = 1`,
`zeta = omega(J)` forces `n | m`, i.e. `m = n`. So `pi(p_omega) = 0` whenever
`J` has order `< n` in `G`. If `J` has order exactly `n`, the canonical trace
gives `tau_G(p_omega) = (1/n) sum_k conj(omega^k) tau_G(J^k) = 1/n > 0`,
because `tau_G(J^k) = 0` for `0 < k < n`. In particular `p_omega != 0` in
`C[G]` exactly when `J` has order `n`. `p_omega` is a central projection.

## (LC1), from local data to a decoder

Let `phi_c : A_c -> Lambda(D)` and `psi_v : H_v -> Lambda(D)` be the colimit
maps, so `phi_c iota_(v,c) = psi_v` and all of them agree on `<J>`. Each
extends to a *-homomorphism of group algebras sending `p_omega` to `p_omega`.
Put `x_v = psi_v(y_v)`. Then `x_v^* = x_v`, `x_v^2 = psi_v(y_v^2) = p_omega`,
and for `v in V_c`, `x_v = phi_c(iota_(v,c)(y_v))`. The commutation and
constraint relations of `c` hold in `C[A_c] p_omega` and are preserved by
`phi_c`. So `v -> x_v` is a unital *-homomorphism `A(B) -> C[Lambda(D)] p_omega`
(unital meaning `1 -> p_omega`), with readouts in the finite subgroups
`phi_c(A_c)`. When `J` has order `n` in `Lambda(D)`, Lemma 0 gives
`p_omega != 0`, so this is an exact finite-readout decoder.

## (LC1), from a decoder to local data

Let `x_v in C[Lambda] p_omega` be an exact finite-readout decoder with finite
readout subgroups `A_c`. Replacing `A_c` by the finite group `A_c <J>` we may
assume `J in A_c`.

*Supports.* An element of `C[Lambda]` is a finite combination of distinct
group elements with unique coefficients, and `C[A_c]` is the span of `A_c`.
So for `v` in contexts `c_1, ..., c_r` the support of `x_v` lies in
`H_v := A_(c_1) cap ... cap A_(c_r)`, a finite subgroup containing `J`.
Since `p_omega in C[H_v]` and `x_v = x_v p_omega`, `x_v in C[H_v] p_omega`.

*Local data.* Take the `A_c`, the `H_v` with their inclusions
`iota_(v,c)`, and `y_v = x_v`. The context relations hold in `C[Lambda]`, and
the inclusion `C[A_c] -> C[Lambda]` is injective, so they hold in
`C[A_c] p_omega`. This is finite local data `D`.

*Survival.* The inclusions define a homomorphism `theta : Lambda(D) -> Lambda`
compatible with all maps, and the decoder is `theta` applied to the colimit
decoder of the previous paragraph. `J^n = 1` in every `A_c`, hence in
`Lambda(D)`; and `theta(J) = J` has order `n` in `Lambda`. So `J` has order
exactly `n` in `Lambda(D)`. This also proves the factorization clause.

## (LC2)

`Lambda(D)` is presented by the elements of the finitely many finite groups
`A_c`, `H_v`, `<J>` as generators, their multiplication tables, and the
finitely many identifications `iota_(v,c)(h) = h` and those of `<J>`. It is
generated by the images of the `A_c`, since every variable lies in some
context and `J in A_c`.

## (LC3)

1. `p_omega` is central in `C[Lambda]`, so `P = pi(p_omega)` commutes with
   `pi(Lambda)`. If `P != 0`, `v -> pi(x_v)|_(ran P)` is a unital
   *-homomorphism `A(B) -> B(ran P)` with `dim ran P >= 1` finite: a
   finite-dimensional perfect model. So `P = 0`.
2. For a finite quotient `q : Lambda -> Q`, apply 1 to `pi = lambda_Q q`. By
   Lemma 0 applied in `Q`, `lambda_Q(q(p_omega)) != 0` iff `q(J)` has order `n`
   (the regular representation of `Q` contains every character of `<q(J)>`).
   So `q(J)` has order `< n`.
3. Suppose for each prime `p | n` there is a finite quotient `q_p` with
   `q_p(J^(n/p)) != 1`. The diagonal map to `prod_p Q_p` has finite image in
   which the image of `J` has order dividing `n` and a nontrivial `(n/p)`-th
   power for every prime `p | n`, hence order exactly `n`. That contradicts
   2. So some prime `p | n` has `J^(n/p)` in every finite-quotient kernel.
   For `n` prime this is `J` itself, and `J != 1` in `Lambda`.

## (LC4)

Let `D0 = lcm` of all `|A_c|` and `|H_v|`. For every vertex group `G` of the
diagram (including `<J>`) put `rho_G = (D0/|G|) lambda_G`, a representation of
dimension `D0`. For a subgroup `K <= G`, the restriction of `lambda_G` to `K`
is `|G|/|K|` copies of `lambda_K`, so `rho_G|_K` is unitarily equivalent to
`rho_K`.

*One component.* Order the vertices of a tree component of `Inc(D)` by
breadth-first search from a root, and define representations one vertex at a
time. Each later vertex has exactly one earlier neighbour.
- A variable `H_v` whose earlier neighbour is `A_c`: set
  `rho'_(H_v) = rho'_(A_c) iota_(v,c)`.
- A context `A_c` whose earlier neighbour is `H_v`: the representations
  `rho_(A_c) iota_(v,c)` and `rho'_(H_v)` are both equivalent to
  `(D0/|H_v|) lambda_(H_v)`; choose a unitary `W` intertwining them and set
  `rho'_(A_c) = W rho_(A_c) W^*`, so `rho'_(A_c) iota_(v,c) = rho'_(H_v)`.

The root gets `rho_G`. Every edge of the component then satisfies its
compatibility identity literally, because each edge is used exactly once.
All `rho'` restrict to `<J>` as representations equivalent to `rho_(<J>)`.

*Several components.* Fix `rho_(<J>)`. For each component choose a unitary
conjugating its restriction to `<J>` (all equivalent to `rho_(<J>)`, and all
equal inside the component since `J` is central and identified along edges)
onto `rho_(<J>)`, and conjugate the whole component by it. This preserves the
identities inside the component and makes the maps from `<J>` agree.

The family is compatible with every map of the diagram, so the universal
property gives a representation `pi` of `Lambda(D)` on `C^(D0)`. Its
restriction to `<J>` is `(D0/n) lambda_(Z/n)`, which contains the eigenvalue
`omega(J)`. By Lemma 0, `J` has order `n` in `Lambda(D)` and
`pi(p_omega) != 0`, and (LC3.1) with the decoder of (LC1) produces a
finite-dimensional perfect model of `B`. For a source with no such model,
`Inc(D)` therefore cannot be a forest.

For a first-chart letter, commutation gives

```text
pi_(DUC)(i_1(a))=rho_1(a)=D rho_1(a)D^*.
```

For a second-chart letter, the right commutant cancels:

```text
pi_(DUC)(i_2(b))
 =D U C rho_2(b) C^* U^*D^*
 =D U rho_2(b)U^*D^*
 =D pi_U(i_2(b))D^*.
```

Multiplication and inversion preserve this conjugacy identity, proving
`(DCG3)` for every free-product word.  Unitary conjugacy preserves all the
listed spectral and tracial data, which proves `(DCG4)` and the full-relator
firewall.

If `P` is in the algebra generated by `rho_1(A8)`, it commutes with `D`; if
`Q` is in the algebra generated by `rho_2(A8)`, it commutes with `C`.
Therefore

```text
P(DUC)Q=D(PUQ)C,
```

which is `(DCG5)`.  Left and right unitary multiplication preserve singular
values.  Taking hard kernels of stacked mixed blocks gives exactly the
fixed-space intersection/rank-pencil coordinates already isolated in
`atlas-mixed-fixed-spaces-are-rank-pencils`, completing the reduction.

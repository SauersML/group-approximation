Notation as in the claim: `S = St_N(R_L)`, `φ : S -> E_N(R_L)`, and `K_2 = K_2(N, R_L) = ker φ`.

**Item 1.** Let `π : H -> Q` be onto a simple group, with `π(K) ≠ 1`. Then `π(K)` is normal in `Q`, so `π(K) = Q`, and
`Q` is a simple quotient of `K`, hence `Q ≅ K̄`. For `K = S` the unique simple quotient is `PE_N(R_L)`
(`steinberg-groups-of-r-l-are-quasisimple`, item 1). It is not finitely presented (same node, item 3, and
`leavitt-scalar-commutators-block-fp-central-quotients`).

**Item 2.** Let `c : H -> Inn(K) = K/Z(K)` describe the action.
- **The central extension.** Pull back `K -> K/Z(K)` along `c`. This gives
  `E = {(h, k) : c(h) = k Z(K)} -> H`, with kernel `{1} × Z(K)`. The kernel is central: conjugating `(1, z)` by `(h, k)`
  gives `(1, k z k^-1) = (1, z)`. So `E` is a central extension of `H` by the abelian group `Z(K)` with trivial
  action.
- **It splits.** By universal coefficients its class lies in
  `H^2(H; Z(K)) = Ext(H_1 H, Z(K)) ⊕ Hom(H_2 H, Z(K)) = 0`. So there is a homomorphism `σ : H -> K` with
  `h·k·h^-1 = σ(h) k σ(h)^-1` for all `k`.
- **The direct factor.** In `K ⋊ H` put `τ(h) = σ(h)^-1 h`. Then:
  - `τ(h)` centralizes `K`;
  - `τ` is a homomorphism, since `σ(h_1)^-1 h_1 σ(h_2)^-1 h_2 = σ(h_1)^-1 σ(h_1) σ(h_2)^-1 σ(h_1)^-1 h_1 h_2
    = σ(h_1 h_2)^-1 h_1 h_2`;
  - `τ(H) ∩ K = 1`, by projecting to `H`;
  - `K·τ(H) = K ⋊ H`.

  So `K ⋊ H = K × τ(H) ≅ K × H`.

**Item 3: the twists are inner.** Let `u ∈ V`.
- **`D_u` is elementary.** `GL_N(R_L)/E_N(R_L) ≅ K_1(R_L) ≅ Z` for `N >= 3`
  (`leavitt-ge-rings-have-stable-k1-at-rank-three`, item 3). The map `u ↦ [D_u]` is a homomorphism from the simple
  nonabelian group `V` to `Z`, hence trivial. So `D_u ∈ E_N(R_L)`.
- **`Σ^(u)` covers conjugation by `D_u`.** On generators, `D_u e_iN(r) D_u^-1 = e_iN(r u^-1)`,
  `D_u e_Nj(r) D_u^-1 = e_Nj(u r)`, and every other `e_ij(r)` is fixed. Since `u^-1 = u*`, this is the twist formula of
  `leavitt-stabilization-kernels-are-one-step`.
- **So `Σ^(u)` is conjugation by a preimage.** Pick `d ∈ S` with `φ(d) = D_u`. Then `Σ^(u)` and conjugation by `d` both
  cover conjugation by `D_u`. Two automorphisms `α, β` of `S` covering the same automorphism of `E_N` agree:
  - `x ↦ α(x) β(x)^-1` takes values in the central `K_2`;
  - it is a homomorphism, since `α(xy) β(xy)^-1 = α(x) c_y β(x)^-1 = α(x) β(x)^-1 c_y` with `c_y = α(y)β(y)^-1`
    central;
  - it is trivial because `S` is perfect.

  So `V` acts on `S` by inner automorphisms. `H_1(V) = 0` because `V` is simple, and `H_2(V) = 0` by Szymik–Wahl
  (recalled). Item 2 then gives `G ≅ S × V`.

**Item 3(a).** In a simple quotient of `S × V`, the images of the two factors are commuting normal subgroups that
generate it, so one of them is trivial. The quotient is therefore a simple quotient of `S`, which is `PE_N(R_L)`, or of
`V`, which is `V`. `GL_n(Q) ≤ S` dies in `V`-quotients, and `PE_N(R_L)` is not finitely presented (item 1).

**Item 3(b).**
- **`K_2` is central in `G`.** `K_2 ≅ Q^x` is central in `S` (`leavitt-resolvent-k2-stability-holds`, item 3). In
  `G = S × τ(V)` it is central in `G`. By `type-a-actors-have-no-infinite-virtually-central-subgroup`, `G` has no
  faithful action with finitely many orbits on two-element subsets.
- **Ring symmetries.** Let `α` be a ring automorphism of `R_L`, acting on `S` coordinatewise. An anti-automorphism
  composed with transpose-inverse is treated the same way.
  - `K_2 = {{λ, N+1}_N : λ ∈ Q^x}` (`leavitt-resolvent-k2-stability-holds`, item 2), and `α` fixes `Q`, so
    `α{λ, N+1} = {λ, α(N+1)}`.
  - `{λ, u}` for central rational `λ` is the product `[λ]·[u]` of `K_1(Q) ⊗ K_1(R_L) -> K_2(R_L)` (recalled). So it
    depends only on `[u] ∈ K_1(R_L) ≅ Z`, and `α` acts on `K_1(R_L)` by `±1`.
  - Hence `α` acts on `K_2` by `λ ↦ λ^(±1)`. The Leavitt twists act trivially, by item 3.
  - So for `Γ` generated by such symmetries, the kernel of `Γ -> {±1}` has index at most 2, and together with `S` it
    centralizes `K_2`. The same lemma applies.

**Item 3(c).** Let `P = K × H` act genuinely on `N` with infinite supports.
- **Near-faithfulness.** If `ρ_g = ρ_h` in `NearSym(N)`, then `g h^-1` has finite support, so `g = h`.
- **Restriction of a normalization.** Suppose `s^-m ρ(P_0) s^m ≤ ρ(P_0)` for `P_0 ∈ {P, [P,P]}` and some `m ≠ 0`.
  This defines an endomorphism `ψ` of `P_0` with `s^-m ρ_g s^m = ρ_(ψ(g))`. `K` is perfect or equal to `K`, so
  `K ≤ P_0`. The composite `K -> P_0 -> H` is a homomorphism `K -> H`, trivial by hypothesis. So `ψ(K) ≤ K`, and `K`
  with `ρ|_K` (still with infinite supports) satisfies (★) of
  `fw-inputs-admit-no-twisted-normalizing-genuine-shell-action`.
- **Window zero.** For `m > 0` that node, item 1, gives a contradiction. For `m < 0`,
  `fw-descending-shift-power-windows-force-torsion-centre` gives that `Z(K)` has finite exponent.
- **Commuting windows.** The mechanism of `fw-inputs-fail-commuting-shell-windows` (shift invariance, then
  `c_(-1) ≤ c_N·(central)`) uses no finiteness property of `P`. It outputs exactly `s^∓(N+1) ρ([P,P]) s^±(N+1) ≤
  ρ([P,P])`, which falls under the previous bullet.
- **`Hom(S, V) = 1`.**
  - `S` has (T) for `N >= 4` (`steinberg-finite-presentation-and-kazhdan-theorem`), hence FW, and so does any
    image of it.
  - `V` acts properly on a CAT(0) cube complex (Farley, recalled). An FW group fixes a point of any CAT(0) cube
    complex it acts on, so an FW subgroup of `V` is finite.
  - `S` has no nontrivial finite quotient: it is generated by the root subgroups `x_ij(R_L)`, which are `Q`-vector
    spaces, hence divisible.

  So every homomorphism `S -> V` is trivial, and every obstruction above binds `G`.

**Item 4.** The Leavitt pair gives `R ≅ R^2` by `x ↦ (t_1 x, t_2 x)`, with inverse `(y, z) ↦ s_1 y + s_2 z`.
- **All sizes collapse.** Iterating, `R^n ≅ R` for every `n >= 1`. So `End(R^n) ≅ R` and `GL_n(R_L) ≅ R_L^x`.
- **Landing in `E_3`.** By Whitehead's lemma, `diag(u, u^-1) ∈ E_2(R_L)`, so `u ↦ diag(u, u^-1, 1)` embeds `R_L^x` in
  `E_3(R_L)`.
- **Missing the centre.** The image meets the centre of `E_3(R_L)`, which consists of scalar matrices
  (`steinberg-groups-of-r-l-are-quasisimple`, setting), only in `1`. So it embeds in `PE_3(R_L)`, which is simple
  (same node, item 1).
- **All `GL_n(Q)`.** `Q ⊆ R_L` unitally, so `GL_n(Q) ≤ GL_n(R_L) ≅ R_L^x ↪ PE_3(R_L)` for every `n`.

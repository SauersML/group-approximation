Notation as in the target. `||X||_HS` is the unnormalized Hilbert–Schmidt norm, and
`||X||_(2,n) = n^(-1/2) ||X||_HS`. `P = P_n : C^(D) -> C^(d)` (any `D >= d`) is the coordinate
co-isometry onto the first `d = d_n` coordinates, and `E = P*P`.

**Imports (standard).**
- (Mi) Mirsky, *Symmetric gauge functions and unitarily invariant norms*, Quart. J. Math. 11
  (1960): for square matrices `X, Y` with singular values `s_1 >= s_2 >= ...`,
  `Σ_i (s_i(X) - s_i(Y))^2 <= ||X - Y||_HS^2`.
- (Reg) For a finite group `F` with subgroup `H'`, `Reg_F|_(H') ≅ |F:H'| · Reg_(H')`, and
  `π ⊗ Reg_(H') ≅ dim(π) · Reg_(H')` for every finite-dimensional representation `π` of `H'`.
- (FvN) In a finite-dimensional C*-algebra `𝓜`, every `S in 𝓜` is `S = V|S|` with `V` unitary in
  `𝓜`. (The polar partial isometry `v in 𝓜` has `v*v ~ vv*`. In a finite von Neumann algebra this
  gives `1 - v*v ~ 1 - vv*`, and a partial isometry `w in 𝓜` between the complements gives
  `V = v + w`.)

## 0. Corner leakage

**(L)** Let `ρ` be a genuine representation on `C^D`, `D >= d`, and let `x` satisfy
`||Pρ(x)P* - σ(x)||_(2,d) -> 0` with `σ(x)` unitary. Then `||(1 - E)ρ(x)P*||_HS^2 = o(d)`.

*Proof.* `ρ(x)P*` is an isometry from `C^d`, so `||ρ(x)P*||_HS^2 = d`. Hence

```text
||(1-E)ρ(x)P*||_HS^2 = d - ||Pρ(x)P*||_HS^2 = d (1 - ||Pρ(x)P*||_(2,d)^2) = o(d),
```

because `||Pρ(x)P*||_(2,d) -> ||σ(x)||_(2,d) = 1`.

Applied to `x^(-1)` as well, (L) also gives `||Pρ(x)(1 - E)||_HS^2 = o(d)`, since
`Pρ(x)(1-E) = ((1-E)ρ(x^(-1))P*)*`, whenever the hypothesis holds for `x^(-1)`. For `x in H` it
holds for both, because `H` is a subgroup of `A` and of `B`.

## 1. Pad to a common dimension

Let `λ^A_n : A -> U(D^A_n)` and `λ^B_n : B -> U(D^B_n)` be the given roundings. Set
`D = max(D^A, D^B)`, and add trivial summands on the last coordinates so that both act on `C^D`.
Since the first `d` coordinates are untouched, the corner estimates persist, and `D/d -> 1`.
Write `θ^A = λ^A|_H` and `θ^B = λ^B|_H`, which are genuine representations of `H` on `C^D`.

## 2. The edge restrictions are close

**Claim.** `ε_n := max_(h in H) ||θ^A(h) - θ^B(h)||_(2,D) -> 0`.

Fix `h` and put `X = θ^A(h) - θ^B(h)`. Split `C^D = C^d ⊕ C^(D-d)`.
- The corner `PXP*` has `||PXP*||_(2,d) <= ||Pλ^A(h)P* - σ(h)|| + ||σ(h) - Pλ^B(h)P*|| -> 0`, so
  `||PXP*||_HS^2 = o(d)`.
- By (L) for `h` and `h^(-1)`, applied to both roundings, the off-diagonal blocks `(1-E)XP*` and
  `PX(1-E)` have `HS^2 = o(d)`.
- The lower block has `HS^2 <= 4(D - d)`.

So `||X||_HS^2 = o(d) + 4(D - d) = o(D)`. Since `H` is finite, the maximum over `h` also tends to
`0`.

## 3. Balance the multiplicities with o(d) genuine summands

**Multiplicity gap.** Let `Irr(H)` be the irreducible characters of `H`, identify the
representation ring `R(H)` with `Z^(Irr(H))`, and use the `l^1` norm `|.|_1` on it. For `τ in Irr(H)`,

```text
m^A_τ - m^B_τ = |H|^(-1) Σ_h conj(χ_τ(h)) (Tr θ^A(h) - Tr θ^B(h)),     |Tr X| <= D^(1/2) ||X||_HS = D ||X||_(2,D).
```

So `|m^A_τ - m^B_τ| <= dim(τ) D ε_n`, and `δ_n := [θ^B] - [θ^A] in R(H)` has `|δ_n|_1 <= C_H D ε_n`,
where `C_H = Σ_τ dim τ`.

**The lattice.** Let `L_A <= R(H)` be the subgroup generated by the classes `[a|_H]`, where `a` runs over
the finite-dimensional unitary representations of `A`. Define `L_B` in the same way, and put
`L = L_A + L_B`.
- `R(H) ≅ Z^k` is Noetherian, so `L_A` is generated by finitely many of the given generators. Fix
  representations `a_1, ..., a_r` of `A` and `b_1, ..., b_s` of `B` with
  `L_A = <[a_i|_H]>` and `L_B = <[b_j|_H]>`.
- `[θ^A] in L_A`, because `θ^A` is the restriction of `λ^A` padded by trivial summands. Likewise
  `[θ^B] in L_B`. So `δ_n in L`.
- **Bounded preimages.** `L` is free abelian. Choose a basis `e_1, ..., e_t` and write
  `δ = Σ_l y_l(δ) e_l`. The coordinates `y_l` are restrictions of linear functionals on `span_R L`, so
  `|y_l(δ)| <= c |δ|_1`.
- Fix preimages of the `e_l` under
  `Φ : Z^(r+s) -> L,  Φ(c, d) = Σ_i c_i [a_i|_H] - Σ_j d_j [b_j|_H]`.
  Then `δ_n = Φ(c, d)` with `|c|_1 + |d|_1 <= C_1 |δ_n|_1`, where `C_1` depends only on the fixed
  data `(A, B, H, a_i, b_j)`.

**Positivization.** Let `R = Reg_F ∘ q`. This is a genuine representation of `G`, and by (Reg),
since `q|_H` is injective, `R|_H ≅ N · Reg_H` with `N = |F|/|H|`.
- For a finite-dimensional representation `a` of `A`, `R|_A` contains the trivial representation
  (the constants). Put `a' := a ⊗ (R|_A ⊖ 1)`. By (Reg),

  ```text
  (a ⊕ a')|_H ≅ (a ⊗ R|_A)|_H ≅ a|_H ⊗ N·Reg_H ≅ N dim(a) Reg_H ≅ dim(a) · R|_H,
  ```

  so `[a'|_H] = -[a|_H] + dim(a) [R|_H]`.
- Define `b'` for representations `b` of `B` in the same way.

Put

```text
α_n = ⊕_(c_i > 0) a_i^(c_i) ⊕ ⊕_(c_i < 0) (a_i')^(|c_i|) ⊕ (R|_A)^(x),     x = Σ_(d_j < 0) |d_j| dim b_j,
β_n = ⊕_(d_j > 0) b_j^(d_j) ⊕ ⊕_(d_j < 0) (b_j')^(|d_j|) ⊕ (R|_B)^(y),     y = Σ_(c_i < 0) |c_i| dim a_i.
```

Then `[α_n|_H] - [β_n|_H] = Σ c_i [a_i|_H] - Σ d_j [b_j|_H] = δ_n = [θ^B] - [θ^A]`. Check the
negative terms:
- a `c_i < 0` contributes `|c_i|(-[a_i|] + dim(a_i)[R|])`, and the `R`-part is cancelled by
  `(R|_B)^(y)` on the `β` side;
- a `d_j < 0` contributes `-|d_j|(-[b_j|] + dim(b_j)[R|])`, cancelled by `(R|_A)^(x)`.

Hence

```text
θ^A ⊕ α_n|_H  ≅  θ^B ⊕ β_n|_H     as representations of H,                     (BAL)
```

and in particular `dim α_n = dim β_n`. Both dimensions are at most
`C_2(|c|_1 + |d|_1) <= C_3 D ε_n = o(d)`, where `C_2` and `C_3` depend only on the fixed data.

## 4. Conjugate the balanced edge representations by a unitary near 1

Let `M = D + dim α_n`. On `C^M = C^D ⊕ C^(M-D)` put

```text
Λ^A = λ^A ⊕ α_n   (a genuine representation of A),        Λ^B = λ^B ⊕ β_n   (a genuine representation of B),
Θ^A = Λ^A|_H,     Θ^B = Λ^B|_H.
```

By (BAL), `Θ^A` and `Θ^B` are unitarily equivalent. By step 2, and because the last `M - D`
coordinates carry blocks of `HS^2` at most `4(M - D)`,

```text
η_n^2 := max_h ||Θ^A(h) - Θ^B(h)||_(2,M)^2  <=  (D ε_n^2 + 4 dim α_n)/M  ->  0.
```

**Averaged intertwiner.** Put `T = |H|^(-1) Σ_(h in H) Θ^A(h) Θ^B(h)*`.
- Reindexing `k = gh` gives `Θ^A(g) T = T Θ^B(g)` for `g in H`.
- `||T - 1||_(2,M) <= |H|^(-1) Σ_h ||Θ^A(h) - Θ^B(h)||_(2,M) <= η_n`.

**Polar unitary in the commutant.** Fix a unitary `W_0` with `Θ^A(h) = W_0 Θ^B(h) W_0*` for all `h`.
- `S := T W_0*` commutes with `Θ^A(H)`, so it lies in the finite-dimensional C*-algebra
  `𝓜 = Θ^A(H)'`.
- By (FvN), `S = V|S|` with `V` unitary in `𝓜`. Put `U = V W_0`.
- Then `U Θ^B(h) U* = V Θ^A(h) V* = Θ^A(h)`.
- Since `|S| = (W_0 T*T W_0*)^(1/2) = W_0 |T| W_0*`, we get `T = S W_0 = V W_0 |T| = U|T|`.

By (Mi) with `X = T` and `Y = 1`, `|| |T| - 1 ||_HS <= ||T - 1||_HS`. Hence

```text
||U - 1||_(2,M) <= ||U - U|T| ||_(2,M) + ||T - 1||_(2,M) = || 1 - |T| ||_(2,M) + ||T - 1||_(2,M) <= 2 η_n.
```

## 5. Glue

Define `ρ_n = Λ^A` on `A` and `ρ_n = U Λ^B U*` on `B`. On `H` these agree, since
`U Θ^B U* = Θ^A`. By the universal property of `G = A *_H B`, `ρ_n` is a genuine representation
`G -> U(M)`. Also `M >= D >= d` and `M/d -> 1`.

- **`x in A`.** The padding, and `α_n`, act on coordinates beyond `D^A >= d`. So
  `Pρ_n(x)P* = Pλ^A(x)P*`, and `||σ_n(x) - Pρ_n(x)P*||_(2,d) -> 0`.
- **`x in B`.** Put `Y = Λ^B(x)`. Then `UYU* - Y = (U - 1)YU* + Y(U* - 1)`, so
  `||UYU* - Y||_HS <= 2||U - 1||_HS`. Hence

  ```text
  ||P U Y U* P* - P Y P*||_(2,d)  <=  (M/d)^(1/2) · 2 ||U - 1||_(2,M)  <=  4 (M/d)^(1/2) η_n  ->  0,
  ```

  and `PYP* = Pλ^B(x)P*` is within `o(1)` of `σ_n(x)`.

This proves the first assertion of the Theorem.

## 6. All of G when σ_n is an asymptotic representation

Let `𝒢` be the set of `x in G` with `||σ_n(x) - Pρ_n(x)P*||_(2,d) -> 0`. By step 5 it contains
`A ∪ B`, which generates `G`. It is closed under inverses: `Pρ(x^(-1))P* = (Pρ(x)P*)*`, and
`||σ_n(x^(-1)) - σ_n(x)*||_2 -> 0` for an asymptotic representation.

It is closed under products. For `x, y in 𝒢`,

```text
Pρ(xy)P* = (Pρ(x)P*)(Pρ(y)P*) + Pρ(x)(1 - E)ρ(y)P*.
```

- The second term has `HS` norm at most `||(1-E)ρ(y)P*||_HS = o(d^(1/2))`, by (L).
- All the operators involved are contractions, so
  `||XY - X'Y'||_2 <= ||X - X'||_2 + ||Y - Y'||_2` and the first term is `o(1)`-close to
  `σ_n(x)σ_n(y)`.
- That in turn is `o(1)`-close to `σ_n(xy)`.

So `𝒢 = G`.

## 7. Corollary

Let `A` and `B` be flexibly HS-stable, and let `σ_n` be an asymptotic representation of `G`. Its
restrictions to `A` and to `B` are asymptotic representations, so they are flexibly roundable.
Steps 1–6 then give a flexible rounding of `σ_n` on all of `G`.

`ρ_n` is only asserted on the first `d_n` coordinates. No same-dimension (strict) statement is
made. The balance of step 3 genuinely needs extra dimensions, because (BAL) can fail with
`α_n = β_n = 0`.

**ESTABLISHED COMPILER AUDIT.**  Use the saturated finite-packet notation of
`reusable-s3-renewal-is-twisted-radical-or-proper-corner`.  Let `Q` be the
finitely presented automorphic actor, let `Q_sigma` stabilize the active
packet type `sigma`, and write

```text
V_gV_h=omega(g,h)V_(gh).                                (SCR1)
```

The orbit of `sigma` is finite, so `Q_sigma` has finite index in `Q` and is
finitely presented.  The packet action has finite image; the implementers
may therefore be chosen so that `omega` takes values in a finite cyclic phase
group `mu_m`.  Form the ordinary central extension

```text
1 -> mu_m=<z> -> E_sigma=mu_m x_(omega^(-1)) Q_sigma
  -> Q_sigma -> 1.                                     (SCR2)
```

It is finitely presented.  Finite-dimensional representations of `(SCR2)`
on which `z` has the tautological character are exactly the inverse-projective
finite-dimensional representations of the stabilizer.  Thus the exact
projective finite-dimensional radical compiles without circularity into an
ordinary central character which is absent from every exact finite-dimensional
representation.

That exact conclusion does **not** make `E_sigma` nonhyperlinear.  Exact
finite-dimensional invisibility has no general normalized-HS promotion:
`exact-fd-invisibility-has-no-general-hs-robustification` gives a finitely
presented sofic group with a nontrivial central involution killed by every
finite-dimensional representation while its canonical matrix microstates
retain the involution.  Hence the inference

```text
projective fd-radical -> nonhyperlinear central extension              (SCR3)
```

is false without an approximate modulus.

By contrast, suppose the reusable return supplies the dimension-uniform
modulus

```text
tr(B_sigma)<=C sqrt(E)                                 (SCR4)
```

for the fixed nonzero packet corner on `sigma`, as in `(SRD4)`.  Then
`E_sigma` is nonhyperlinear.  Indeed, hyperlinearity would give canonical
matrix microstates for `E_sigma`.  The finite central spectral cut in
`finite-central-hs-sector-decomposition` extracts a tautological-character
block of asymptotic weight `1/m`; on that block the quotient generators are
inverse-`omega` projective microstates.  Tensoring with the fixed packet
implementers cancels the cocycle and inducing over the finite type orbit
produces full return-cell microstates with vanishing energy and a fixed
positive `B_sigma` density.  This contradicts `(SCR4)`.

Equivalently, `(SCR4)` makes `L_(omega^(-1))(Q_sigma)` non-CE and Thom's
central-character criterion applies to `(SCR2)`.  This reformulation is not
an additional assumption; it is the same microstate contradiction.

The circularity boundary is therefore exact:

1. constructing `(SCR2)` from the packet cocycle is routine and
   noncircular;
2. exact projective fd-radical membership proves only exact central-character
   invisibility and is compatible with soficity;
3. proving the dimension-uniform modulus `(SCR4)` already proves that the
   explicit finitely presented group `E_sigma` is nonhyperlinear.

Thus the stabilizer formulation localizes the missing theorem to one
projective sector, but it is not a strictly weaker existence gate than the
original marked groupification problem.  Treating the exact radical as if it
already supplied `(SCR4)` would insert precisely the unproved step.

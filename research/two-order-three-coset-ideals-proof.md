Complete direct proof (artifact Section 3).

1. **Ideals as functions.** `a` lies in `e_K A` iff `[h] a = a` for every `h` in `K`: if `a = e_K y` then
   `[h] a = a`, and conversely `e_K a = 3 a = a`. As a finitely supported function on `G`, such an `a` is constant
   on each set `K w`.
2. **Equal subgroups.** If `K_1 = K_2`, the sum is `e_(K_1) A`, and `1` is not `K_1`-invariant.
3. **Reduction.** Let `K_1 != K_2`, so `K_1 ∩ K_2 = 1`, and suppose `δ_1 = f_1 + f_2` with `f_j` finitely supported
   and constant on the sets `K_j w`. Restricting to `L = ⟨K_1, K_2⟩` keeps both properties, because `K_j w ⊆ L`
   for `w` in `L`.
4. **The graph.** `B` has vertices `K_1 w` and `K_2 w` (`w` in `L`) and one edge for each `w` in `L`, joining `K_1 w`
   to `K_2 w`.
   - Every vertex has degree three.
   - There are no double edges: `K_1 w = K_1 w'` and `K_2 w = K_2 w'` give `w' w^(-1)` in `K_1 ∩ K_2 = 1`.
   - `B` is connected, because `L` is generated by `K_1 ∪ K_2` and `w` and `h w` share a vertex for `h` in `K_1 ∪ K_2`.
   - Right multiplication by `y` in `L` is an automorphism of `B` sending the edge `w` to the edge `w y`. So the
     automorphism group is transitive on edges.
5. **Labels.** `φ(K_j w) = f_j(w)` is well defined, and `φ(K_1 w) + φ(K_2 w) = δ_1(w)` on every edge. So `φ` agrees
   across every edge `w != 1` and differs across the edge `1`. Hence `φ` is constant on each component of `B` minus
   the edge `1`, and the two ends of that edge lie in different components: the edge `1` is a bridge.
6. **Every edge is a bridge.** By edge transitivity, every edge of the connected graph `B` is a bridge, so `B` is a
   tree, and it is three-regular.
   - If `B` is finite this is impossible, since a finite tree has a vertex of degree one.
   - If `B` is infinite, removing an edge of a three-regular tree leaves two infinite components. `φ` is constant on
     each and the two values differ, so one component carries the value `1` on infinitely many vertices. Then `f_1`
     or `f_2` is not finitely supported, a contradiction.
7. **General form (a): odd orders.** Step 1 only needs `|K| = 1` in `F_2`, that is `|K|` odd, and the subgroups are
   nontrivial, so `|K_j| >= 3`.
   - If `K_1 ∩ K_2` contains some `h != 1`, then `K_1 h = K_1` and `K_2 h = K_2`. The equations at `h` and at `1` give
     `φ(K_1) + φ(K_2) = 0` and `= 1`, a contradiction.
   - Otherwise steps 4–6 run verbatim with degrees `|K_1|, |K_2| >= 3`. A finite tree with minimum degree `>= 2` does
     not exist, and in an infinite one both sides of an edge are infinite.
8. **General form (b): free products.** Suppose `L = ⟨K_1, ..., K_r⟩` is the free product of the `K_j` and
   `δ_1 = Σ_j f_j`. Normal forms in the free product make the bipartite incidence graph between elements `w` and
   cosets `K_j w` a tree.
   - Let `S` be the finite nonempty set of cosets where some `f_j` is `1`, and take `c` in `S` at maximal tree distance
     from the element `1`.
   - `c` has `|K_j| >= 3` elements, and at most one of them is closer to `1`. Pick another element `u` of `c`; then
     `u != 1`.
   - Every other coset through `u` is farther from `1` than `c`, so it is not in `S`. So `Σ_j f_j(u) = 1`, while
     `δ_1(u) = 0`, a contradiction.

## Setting and conventions

`G = <t, x, y | xy = yx>`, `t(a,b)` the conjugates of `t` by `x^a y^b`, so that
the normal closure `T` of `t` in `G` is free on `{t(s) : s in Z x Z}` and, for a
set `S subseteq Z x Z`, `T_S = twSub S` is the sub-basis subgroup on `S`
([[boone-base-group-and-lemma-five]], [[free-subbasis-subgroup-calculus]]).
`emb a b P Q : G -> G` is the injective endomorphism `t -> t(a,b)`,
`x -> x^P`, `y -> y^Q`; on the basis of `T` it acts by
`t(p,q) -> t(a + pP, b + qQ)` (`emb_inl`, `indexMap`), and
`G_{ab}^{PQ} = range(emb a b P Q)`.

Let `m = M.size >= 2`. For each residue pair `(a,b)` with `quad a b = some (c,d)`
there is one stable letter `r_i`, `i = 1..n`, with associated subgroups
`A_i = G_{ab}^{mm}` and `B_i = G_{c0}^{m^2,1}` (if `d = R`) or `G_{0c}^{1,m^2}`
(if `d = L`), and `phi_i = emb_target o emb_{ab}^{mm}^{-1}`
([[boone-hnn-tower-embeds-base-group]]). Mathlib's convention is
`r_i a r_i^{-1} = phi_i(a)` for `a in A_i`. The iterated one-letter tower
`G'_M = tower (machineIdentifications M)` is the multiple HNN extension of `G`
with letters `r_1..r_n` (each stage's associated subgroups are the images of
`A_i, B_i` under the injective composite `iota : G -> stage`), so Britton's Lemma
for several stable letters (Lyndon--Schupp, *Combinatorial Group Theory*,
Thm IV.2.1) applies to it with base `G`.

Put `S_i = {(a + um, b + vm) : u, v in Z}` (the residue class of the `i`-th pair),
`sigma_i(a + um, b + vm) = (c + u m^2, v)` for `d = R` and `= (u, c + v m^2)` for
`d = L`. Then `phi_i(t(s)) = t(sigma_i s)` for `s in S_i`, because
`emb_{ab}^{mm}` sends `t(u,v) -> t(a+um, b+vm)` and the target embedding sends
`t(u,v) -> t(c + um^2, v)` resp. `t(u, c + vm^2)`. The classes `S_i` are pairwise
disjoint (distinct residue pairs) and each `sigma_i` is injective on `S_i`.

`H subseteq N x N` is the halting set, read in `Z x Z` as `haltingSetZ`, and
`T_M = twSub H`.

## Step 1. Intersections with the associated subgroups

By Lemma 5 (`Tsub_inf_Gsub`), `T cap A_i = T_{S_i}`. By
`basisSubgroup_inf`, `T_M cap A_i = T_H cap T cap A_i = T_H cap T_{S_i} = T_{H cap S_i}`.
Likewise `T_M cap B_i = T_{H cap sigma_i(S_i)}`: Lemma 5 applied to
`B_i = G_{c0}^{m^2,1}` (resp. `G_{0c}^{1,m^2}`) gives `T cap B_i = T_R` with
`R = {(c + u m^2, v)}` (resp. `{(u, c + v m^2)}`), and `R = sigma_i(S_i)`. Goodness of `T_M` at every letter
([[boone-tower-good-subgroup-transport]], `good_twSub_halting_right/left`,
which rests on `haltsZ_right_iff/left_iff` of
[[modular-machine-halting-invariance]]) is

    phi_i(T_M cap A_i) = T_M cap B_i,   i.e.  sigma_i(H cap S_i) = H cap sigma_i(S_i).

So `psi_i := phi_i restricted` is an isomorphism `C_i := T_{H cap S_i} -> D_i :=
T_{H cap sigma_i S_i}` of subgroups of `T_M`, sending basis to basis by
`sigma_i`.

## Step 2. The subgroup generated by a good subgroup and the letters

Let `Lambda` be the multiple HNN extension of `T_M` with letters `rho_1..rho_n`,
`rho_i c rho_i^{-1} = psi_i(c)` for `c in C_i`. The assignment `T_M ->iota T_M`,
`rho_i -> r_i` respects the relations, so defines `Psi : Lambda -> G'_M` with
image `<T_M, r_1..r_n> = towerSub (twSub H)`, which by Lemma 7
([[boone-halting-subgroup-is-normal-closure]], `towerSub_halting_eq_towerTSub`)
equals `L = towerTSub = <t, r_1..r_n>`.

`Psi` is injective. Let `g in Lambda`, `g != 1`, and write it in reduced form
`g = c_0 rho_{i_1}^{e_1} c_1 ... rho_{i_k}^{e_k} c_k` with `c_j in T_M` and no
pinch, i.e. no `rho_i c rho_i^{-1}` with `c in C_i` and no `rho_i^{-1} c rho_i`
with `c in D_i`. If `k = 0` then `Psi(g) = iota(c_0) != 1` since `iota` is injective.
If `k >= 1`, the image word `c_0 r_{i_1}^{e_1} c_1 ... r_{i_k}^{e_k} c_k` in `G'_M`
has no pinch either: a pinch `r_i c_j r_i^{-1}` in `G'_M` needs `c_j in A_i`,
and `c_j in T_M`, so `c_j in T_M cap A_i = C_i`, which is a pinch in `Lambda`;
symmetrically for `r_i^{-1} c_j r_i` with `B_i` and `D_i`. By Britton's Lemma in
`G'_M`, `Psi(g) != 1`.

Hence `L ~= Lambda`, with `t = t(0,0)` corresponding to the basis element
`t(0,0)` of `T_M` (note `(0,0) in H`).

## Step 3. The halting-computation tree

`Lambda` has the presentation (free base on the basis of `T_M`, one relation per
basis element of each `C_i`):

    generators  t(s) (s in H),  rho_1, ..., rho_n
    relations   rho_i t(s) rho_i^{-1} = t(sigma_i s)   for s in H cap S_i.

Facts about the edges `s -> sigma_i(s)`, `s in H cap S_i`:

(a) For `s = (alpha, beta) in H` (so `alpha, beta >= 0`), `s in S_i` exactly when
`(lo alpha, lo beta)` is the `i`-th residue pair, and then `sigma_i(s)` is
`M.step s` (`step_right`, `step_left`: `(hi alpha * m^2 + c, hi beta)` resp.
`(hi alpha, hi beta * m^2 + c)`, with `alpha = lo alpha + m hi alpha`). So every
`s in H` has at most one outgoing edge, and it has one iff `M.step s` is
defined.

(b) `(0,0)` has no outgoing edge (`quad_zero_zero`), and every `s in H`,
`s != (0,0)`, has one: `M.Halts s` means `M.Reaches s (0,0)`, and a nonempty
computation starts with a defined step.

(c) For `s in H` let `s = s_0 -> s_1 -> ... -> s_k = (0,0)` be the computation
(determined by (a); it reaches `(0,0)` and stops there by (b)), with letters
`i_1, ..., i_k`, and put `w_s = rho_{i_k} ... rho_{i_2} rho_{i_1}`. If `s -> s'` is
the edge from `s` with letter `i`, then `w_s = w_{s'} rho_i` as words.

Define `alpha : Lambda -> F(tau, rho_1, ..., rho_n)` by `t(s) -> w_s^{-1} tau w_s`,
`rho_i -> rho_i`. It respects the relations: for an edge `s -> s' = sigma_i s`,

    alpha(rho_i t(s) rho_i^{-1}) = rho_i rho_i^{-1} w_{s'}^{-1} tau w_{s'} rho_i rho_i^{-1}
                                 = alpha(t(s')).

Define `beta : F(tau, rho) -> Lambda` by `tau -> t(0,0)`, `rho_i -> rho_i`.
Then `alpha beta = id` on generators (`w_{(0,0)}` is empty). And
`beta alpha(t(s)) = w_s^{-1} t(0,0) w_s = t(s)` in `Lambda`, by induction on the
length `k` of the computation from `s`: for `k = 0` it is trivial, and for
`s -> s'` with letter `i`, the relation gives `t(s) = rho_i^{-1} t(s') rho_i =
rho_i^{-1} w_{s'}^{-1} t(0,0) w_{s'} rho_i = w_s^{-1} t(0,0) w_s`. So `alpha` and
`beta` are inverse isomorphisms.

## Conclusion

`L = <t, r_1, ..., r_n> ~= Lambda ~= F(tau, rho_1, ..., rho_n)`, with
`t <-> t(0,0) <-> tau` and `r_i <-> rho_i`. So `t, r_1, ..., r_n` is a free basis
of `L`, of rank `n + 1`. Where the machine enters: determinism gives a unique
outgoing edge, terminality of `(0,0)` makes the computation graph a tree
rooted at `(0,0)`, and the halting set is exactly the set of vertices that reach
the root. A letter whose class meets no halting configuration contributes a
free factor `<rho_i>` with trivial associated subgroup, consistent with the
formula.

**Calibration.** A non-halting cycle `s -> ... -> s` in the step graph would
produce a relation `[w, t(s)] = 1` and a `Z^2` in the lifted subgroup of the
non-halting part; the argument uses only `H`, where such cycles cannot occur,
which is why the halting subgroup (and not `T`) is the one that lifts to a free
group.

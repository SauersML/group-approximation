## 0. Imports and standard facts

**(OW) Ollivier--Wise**, arXiv:math/0409203v1. Verbatim, Theorem 1.1 (p. 5): "For each countable
group Q, there is a short exact sequence 1 → N → G → Q → 1 such that (1) G is torsion-free, (2) G
has a graphical 1/6 presentation, and (3) N has property T and is non-trivial. (4) Moreover, G is
finitely generated if Q is, and finitely presented if Q is." From the construction (p. 5): "Now N is
the subgroup of G generated by x and y. It is normal by construction." Section 2.1 (p. 3): "The
condition Gr'(1/6) implies that the group G is torsion-free, word-hyperbolic, of dimension 2".
Proof of Theorem 1.2 (p. 6), for finitely presented Q: "N is a non-elementary subgroup of the
torsion-free word-hyperbolic group G, and hence N has a trivial centralizer ... hence Q → Out(N) is
injective."

Standard facts (K. Brown, *Cohomology of Groups*, GTM 87):
- **(B1)** VIII.2.1 and VIII.4.3: if `cd Γ ≤ n` and `Γ` is of type FP_n, then `Γ` is of type FP.
  (In a partial resolution by finitely generated projectives of length `n−1`, the next kernel is
  projective by Schanuel since `cd Γ ≤ n`, and it is finitely generated by FP_n.)
- **(B2)** VIII.6.7: if `Γ` is of type FP and `cd Γ = n`, then `H^n(Γ; ZΓ) ≠ 0`.
- **(B3)** VIII.4.8: if `Γ` is of type FP, `H^*(Γ; −)` commutes with arbitrary direct sums.
- **(B4)** Subgroups: `cd Γ' ≤ cd Γ` for `Γ' ≤ Γ` (VIII.2.4).
- **(B5)** Stallings--Swan: a group of cohomological dimension at most 1 is free.
- **(B6)** A nontrivial free group surjects onto `Z`, hence has no property (T)
  (Kazhdan groups have finite abelianisation).
- **(B7)** Lyndon--Hochschild--Serre spectral sequence
  `E_2^{p,q} = H^p(G/N; H^q(N; M)) ⇒ H^{p+q}(G; M)`.

## 1. The group

`Z = <q>` is finitely presented, so (OW)(4) makes `G` finitely presented, and (OW)(1)--(3) plus
Section 2.1 make `G` torsion-free and word-hyperbolic, with an aspherical two-dimensional
presentation complex, so `cd G ≤ 2`. `N = <x, y>` is nontrivial and Kazhdan. Since `Z` is free, the
extension splits: choose `t ∈ G` mapping to `q`. Then `G = N ⋊_φ <t>` with `φ(n) = t n t^{-1}`.
`N` is torsion-free and nontrivial, hence infinite, and by (B4) `cd N ≤ 2`.

## 2. Lemma (dimension jump)

*Let `G` be a group with `cd G ≤ 2`, `N ⊴ G` with `G/N ≅ Z`, and `N` nontrivial and Kazhdan. Then
`N` is not of type FP_2. In particular `N` is not finitely presented.*

*Proof.* Suppose `N` is of type FP_2. By (B1) and `cd N ≤ 2`, `N` is of type FP. Let
`n = cd N`. Then `n ≥ 1`, since only the trivial group has `cd 0`. Put `A = H^n(N; ZN)`, which is
nonzero by (B2).

Choose `t ∈ G` mapping to a generator of `G/N`. As a left `ZN`-module, `ZG = ⊕_{k∈Z} M_k` with
`M_k = ZN·t^k`, and right multiplication by `t^{-k}` identifies `M_k ≅ ZN`. By (B3),
`H^q(N; ZG) ≅ ⊕_k H^q(N; M_k)`, and `H^n(N; M_k) ≅ A` for each `k`.

The `G/N`-action on `H^q(N; ZG)` is induced by the compatible pair (conjugation by `t` on `N`, left
multiplication by `t` on `ZG`). Left multiplication by `t` maps `M_k` onto `t·ZN·t^k = ZN·t^{k+1}
= M_{k+1}`, since `tN = Nt`. Its inverse is left multiplication by `t^{-1}`. So `t` maps
`H^n(N; M_k)` isomorphically onto `H^n(N; M_{k+1})`, and hence, as a `Z[t^{±1}]`-module,
`H^n(N; ZG) ≅ Z[t^{±1}] ⊗_Z A`, which is induced from the trivial subgroup.

Now use (B7) with `M = ZG`. Since `cd Z = 1`, only the columns `p = 0, 1` are nonzero, so the
spectral sequence degenerates at `E_2`, and there is an exact sequence

```text
0 → H^1(Z; H^n(N; ZG)) → H^{n+1}(G; ZG) → H^0(Z; H^{n+1}(N; ZG)) → 0.
```

For an induced module, `H^1(Z; ⊕_k A_k) = coker(t − 1) ≅ A`, via the sum map `⊕_k A_k → A`.
Hence `H^{n+1}(G; ZG) ≠ 0` and `cd G ≥ n + 1`. With `cd G ≤ 2` this gives `n ≤ 1`. So `cd N = 1`,
and `N` is a nontrivial free group by (B5). This contradicts (B6), since `N` is Kazhdan. ∎

Applied to §1, the lemma proves claim item 4.

## 3. Infinite outer order

*First proof.* This is (OW), proof of Theorem 1.2, with `Q = Z`: `Z → Out(N)` is injective, and
it sends `q` to `[φ]`.

*Second proof, independent of Theorem 1.2.* Suppose `φ^r = ad(c)` with `r ≥ 1` and `c ∈ N`. Then
`s = c^{-1} t^r` centralises `N` and maps to `q^r ≠ 0`. So `H = N·<s> ≅ N × Z`. `H` has index `r`
in `G`, so it is finitely presented. `N` is a retract of `H`, and a retract of a finitely presented
group is finitely presented. This contradicts §2.

## 4. Automorphic presentation

`G` is finitely presented and `N` is finitely generated. So by
`fp-mapping-torus-iff-finite-automorphic-presentation`, `N` has a finite two-sided automorphic
presentation with respect to `φ`. With §§1--3, this proves every item of the claim. ∎

## 5. Remarks

- **Class kill of the (AT) region in dimension two.** The lemma of §2 uses only `cd G ≤ 2`. Hence
  every witness `G` of the flagship with `cd G ≤ 2` lies in region (IO): its Kazhdan kernel is never
  finitely presented. This covers witnesses built from one-relator groups, `C'(1/6)` and graphical
  `Gr'(1/6)` presentations, and any group with an aspherical two-dimensional presentation complex.
  An (AT)-type witness, which would answer Alekseev--Thom 6.1, needs `cd G ≥ 3`.
- **Remaining obligations.** For an Ollivier--Wise torus, (S), (Q) and (R) of the claim are
  untouched. (Q) and (R) are genuine hyperbolic-group problems: `G` must fail to be residually
  finite and fail to be MF.

This is the intrinsic branch (IO-int) of the witness region (IO) isolated by
`finite-outer-order-radical-witnesses-cross-alekseev-thom`. It is the only branch of the goal that
is free of Alekseev--Thom Open Problem 6.1 and needs no compression defect.

Take `K`, `phi` as in `automorphic-sofic-kazhdan-kernel-with-full-mf-radical`, generated by the
finite set `X` of (P2), and put

```text
G = K x|_phi Z = < K, t | t k t^-1 = phi(k) >.
```

Check the clauses of `(TFZ1)` for `(G, K)`.

- **Finitely presented.** `K` is generated by the finite set `X` and has the finite two-sided
  automorphic presentation `(FAP1)` for `phi` by (P2). So `G` is finitely presented by the "if"
  direction of `fp-mapping-torus-iff-finite-automorphic-presentation`.
- **Torsion-free.** Let `g in G` have finite order. Its image in `G/K ~= Z` has finite order, so it
  is `0`, and `g in K`. `K` is torsion-free by (P1), so `g = 1`.
- **Sofic.** `K` is sofic by (P1) and `G/K ~= Z` is amenable. So `G` is sofic by
  `sofic-kernel-amenable-quotient-permanence`.
- **Kernel.** `K` is nontrivial, normal in `G` and Kazhdan by (P1).
- **Upper bound `Rad_MF(G) <= K`.** `Z` is residually finite, hence MF by `mf-positive-controls`.
  So the quotient map `G -> Z` is a homomorphism to an MF group, and its kernel `K` contains
  `Rad_MF(G)`.
- **Lower bound `K <= Rad_MF(G)`.** Let `F : G -> M` be any homomorphism to an MF group. Its
  restriction `F|_K : K -> M` is a homomorphism to an MF group. It is trivial because
  `Rad_MF(K) = K` by (P1). So `K <= ker F` for every such `F`, and `K <= Rad_MF(G)`.
- **Quotient.** `G/K ~= Z` by construction.

So `Rad_MF(G) = K` and `(TFZ1)` holds. `(TFZ2)` follows as in the goal statement, since every
homomorphism from `G` to an MF group kills `K = Rad_MF(G)` and so factors uniquely through
`G -> Z`. `∎`

**Remarks.**
- The route does not need `phi` to have infinite outer order. But if `[phi]` has finite order,
  then `K` is finitely presented by `finite-outer-order-radical-witnesses-cross-alekseev-thom`,
  and the pair answers Alekseev--Thom 6.1. The route escapes 6.1 only for infinitely presented `K`.
- The full-radical hypothesis is used only in the lower bound. The complementary branch (IO-ext),
  where `Rad_MF(K)` is a proper subgroup of `K`, is
  `mf-kazhdan-quotientless-mapping-torus-exact-radical`.

The notation is that of the target. Automorphisms act on the left, with
`s(xw) = π_s(x) s|_x(w)`, so `(st)|_x = s|_{t(x)} t|_x`. Sections `r@w`, the tree
coordinates `φ_f` and the sections `s_f(g) = φ_{gf} g φ_f^{-1}` are as in
`fully-self-replicating-tree-groups-give-fg-tits-hosts-proof` (the parent proof). The
only change is the choice of relabellings. We check that every step of the parent
proof which used the parity of `A_{d+1}` goes through with `F`.

## 0. The cocycle

Fix `τ_c ∈ F` with `τ_c(0) = c`, with `τ_0 = 1`. Put `λ_c = τ_c^{-1}|_{C∖{c}} : C∖{c} → X`, so
`λ_0 = id_X`.

**(L_F) Lemma.** For `σ ∈ Sym(C)` and `c ∈ C`, `λ_{σc} ∘ σ ∘ λ_c^{-1} = κ(σ, c)|_X`, where
`κ(σ, c) = τ_{σc}^{-1} σ τ_c`. This fixes `0`, and it lies in `F_0` iff `σ ∈ F`.

*Proof.* `λ_c^{-1} = τ_c` on `X`, and `σ τ_c` maps `X = C∖{0}` onto `C∖{σc}`, where
`λ_{σc} = τ_{σc}^{-1}`. So the composite is `κ(σ, c)` restricted to `X`, and
`κ(σ, c)(0) = τ_{σc}^{-1}(σ c) = 0`. The elements `τ_c` and `τ_{σc}` lie in `F`, so
`κ(σ, c) ∈ F` iff `σ ∈ F`. An element of `F` fixing `0` lies in `F_0`. ∎

The cocycle identity `κ(σρ, c) = κ(σ, ρc) κ(ρ, c)` is immediate. It is not used below.

## 1. Sections

The coordinates `φ_f` and properties (C1), (C2) and (C4) of the parent proof use only
that consecutive colours differ and that `λ_c` is a bijection `C∖{c} → X`. So they hold
verbatim.

**(C3_F).** Let `f = (x, y)` have colour `c_0`. The root permutation of `s_f(g)` is
`λ_{σ_y(c_0)} σ_y λ_{c_0}^{-1}`, where `σ_y` is the local action at `y`. The colour of `gf`
is `σ_y(c_0)`. By (L_F), this root permutation is `κ(σ_y, c_0)|_X`. It lies in
`P = F_0` iff `σ_y ∈ F`.

## 2. Consequences of (S), (B), (A)

(R1) and (R2) of the parent proof use only (S), (B) and "(A): the root permutations of
`R` form the group `P`". So they hold with `P = F_0` in place of `A_d`, and
`R ≅ R ≀_X P`. In particular:

- the rooted permutations `p ∈ P` with trivial sections lie in `R`, by (R1);
- they form the complement of `R^X` under the section map.

## 3. Lemma M, and items 1 to 3

**Lemma M_F.** Let `g ∈ Aut(T)`, and let `F'` be a finite nonempty connected vertex set.
Suppose `σ_w ∈ F` for `w ∈ F'`, and `s_f(g) ∈ R` for every exit edge `f` of `F'`. Then
`g ∈ Γ_R^F`.

*Proof.* This is the parent's Lemma M, with the condition `σ ∈ A_{d+1}` replaced by
`σ ∈ F`. The only facts used there are (C2), (C3), (S) and (R1). Their `F`-versions are
§1 and §2. ∎

- **Item 1.** Word for word as in the parent's §3. The only input is the core `G`.
- **Item 2.** The piece `p_f(r)` has `σ_x = 1 ∈ F`. Its local action at `y` lies in `F` by
  (C3_F), because `s_f(p_f(r)) = r` has root permutation in `P`. Lemma M_F with
  `F' = {x, y}` puts `p_f(r)` in `Γ`. The rest of the parent's §4 is unchanged.
- **Item 3.**
  - *Ball fixator.* `Fix_Γ(B_1(v)) = ∏_c R_Γ(Y_{f_c}) ≅ R^C`, as in the parent.
  - *Local actions.* For `g ∈ Γ_v`, apply (C3_F) at the edges `(y_c, v)`. It gives
    `σ_v ∈ F`.
  - *Lifts.* For `σ ∈ F`, let `g_σ` fix `v` and map `Y_{f_c}` onto `Y_{f_{σc}}` by
    `φ_{f_{σc}}^{-1} φ_{f_c}`. Then `s_{f_c}(g_σ) = 1` for every `c`, and `σ_v = σ ∈ F`. So
    `g_σ ∈ Γ_v` by Lemma M_F with `F' = {v}`. As in the parent, `σ ↦ g_σ` is a
    homomorphism with `g_σ p_{f_c}(r) g_σ^{-1} = p_{f_{σc}}(r)`.
  - *Conclusion.* So `Γ_v = R^C ⋊ F ≅ R ≀_C F`. Every vertex has local action group `F`,
    because every `σ ∈ F` is realized by `g_σ`.

## 4. Item 4

- **`Γ_v ≤ Γ⁺`.** `Fix_Γ(B_1(v)) ≤ Γ_{f_c}`. For `σ ∈ F_c`, `g_σ` fixes `y_c`, so it lies
  in `Γ_{f_c}`. The subgroups `F_c` generate `F` by hypothesis, so `Γ_v ≤ ⟨Γ_f⟩ = Γ⁺`.
  (If `F` is primitive and `F_0 ≠ 1`, then `⟨F_c⟩` is a nontrivial normal subgroup, hence
  transitive. It contains `F_0`, so it has order `|C| · |F_0| = |F|`.)
- **Amalgam.** `Γ_0`, the type-preserving subgroup, has index 2 and acts without
  inversions. `F` is transitive, so `Γ_v` is transitive on the edges at `v`. Hence `Γ_0` is
  edge-transitive, and Bass--Serre theory gives `Γ_0 = Γ_v *_{Γ_f} Γ_{v'}`, generated by
  `Γ_v ∪ Γ_{v'} ≤ Γ⁺`. So `Γ⁺ = Γ_0`.
- **Simplicity.** By Tits' theorem, as in the parent. `Γ⁺ ⊇ R_Γ(Y_f) ≅ R`, and
  `R ⊇ P ≠ 1`, so `Γ⁺ ≠ 1`.
- **Generation.** If `R` is finitely generated, so are `R ≀_C F`, `R × R` and the amalgam.
- **Presentation.** Assume `R` is finitely generated. `R` is a retract of `R^C`, which has
  finite index `|F|` in `R ≀_C F`. So `Γ_v` is finitely presented iff `R` is. An amalgam
  over a finitely generated edge group is finitely presented iff its vertex groups are.
  This is the same standard fact the parent uses. ∎

## 5. Item 5

By §2, `R ≅ R ≀_X F_0` through the section map, and this isomorphism carries the rooted
copy of `F_0` onto the complement. So `self-wreathing-groups-are-not-fp-infinity`
applies with `P = F_0` and its action on `X`. That theorem assumes no transitivity.

- Item 4(a) there: if `F_0^{ab} ≠ 1`, then `R` is not finitely generated.
- Item 4(b) there: if `F_0` is perfect with `H_2(F_0) ≠ 0`, then `R` is not finitely
  presented.

So, with item 4, `Γ⁺` is finitely presented with finitely generated edge groups only if
`H_1(F_0) = H_2(F_0) = 0`.

**The examples.**

- `M_12` is sharply 5-transitive on 12 points. The stabilizer `M_11` is perfect with
  trivial multiplier; the script checks this.
- `M_24` on 24 points has stabilizer `M_23`, whose multiplier is trivial (cited).
- Let `S` be a nonabelian simple group with trivial multiplier. `F = S × S` acts on `S` by
  `(a, b) · x = a x b^{-1}`. This action is faithful, since `Z(S) = 1`, and transitive, with
  stabilizer the diagonal `Δ ≅ S` at `x = 1`. It is primitive, because `Δ` is maximal in
  `S × S`. So `⟨F_c⟩ = F`. For `S = PSL(2,8)` the Schur multiplier is trivial by the ATLAS (cited, not computed here).

## 6. Item 6

Let `P = M_11 = Stab_{M_12}(12)` act on `X = {1, …, 11}`, with root letter `1`, and let
`b = (b, α, β, 1, …, 1)`. The script uses GAP's right actions, `(xw)^s = x^{π_s} w^{s|_x}`,
with `(st)|_x = s|_x · t|_{x^{π_s}}`. The group generated by a set of tree automorphisms
does not depend on this convention.

- **(S) and (A).** The generators have sections in `{1, b, α, β} ⊆ R`. The product and
  inverse formulas propagate this to all of `R`, and they show that every element is
  finite-state. `b` has trivial root permutation, and `M_11` acts at the root.
- **(B).**
  - For `a ∈ P_1 = Stab_P(1)`, the element `h_a = b^{-1} a b a^{-1}` has trivial root
    permutation. Its section at `x` is `s_x^{-1} s_{x^a}`, where `s_x = b|_x`. This is `1`
    at `x = 1`, and it lies in `M_11` for `x ≥ 2`, since `x^a ≠ 1`.
  - So `H = ⟨h_a⟩ ≤ 1 × M_11^{10}`. The script computes `|H| = |M_11|^{10}`, so
    `H = 1 × M_11^{10}`. It also checks all 45 pair projections, which give the same
    conclusion by the pair-projection lemma of the parent's §7.
  - Hence `c@x ∈ R` for all `c ∈ M_11` and `x ≥ 2`. Conjugating by rooted elements gives
    `a^{-1} (c@x) a = c@(x^a)`, hence every `x`.
  - Then `b@1 = b · ((β@3)(α@2))^{-1} ∈ R`, since these pieces have disjoint supports.
  - `{r ∈ R : r@x ∈ R for all x}` is a subgroup containing `M_11` and `b`, so it is `R`.
- **Contraction.** The only state of `b` with a nontrivial section path back to itself
  is `b`, along the letter `1`. So `b` is a bounded automaton, and `R` is contracting
  (Bondarenko--Nekrashevych; cited). `R` is regular branch over itself, so it is not
  finitely presented by Bartholdi's theorem (J. Algebra 268 (2003); cited). The
  self-wreathing theorem alone gives only failure of `FP_k` in the first nonzero degree
  of `M_11`, which is at least 3.

## 7. Item 7

**Congruence quotients.** `R` contains every finitary element of depth `< n` whose vertex
permutations lie in `P`, by (R2) and the rooted copy of `P`. These form `W_n`, and they
map injectively to `R / Stab_R(n)`. Every element of `R` has all its vertex permutations
in `P`, by (S) and (A). So its action on the first `n` levels is that of an element of
`W_n`. Hence `R / Stab_R(n) ≅ W_n`, and `R → W_n` is split by the finitary copy.

**Superperfection.** Induct on `n`, with `W_{n+1} = W_n^X ⋊ P`, `N = W_n^X` and `W_n`
superperfect.

- By Künneth, `H_1(N) = 0`, and `H_2(N) = ⊕_x H_2(W_n) ⊕ ⊕_{x<y} H_1 ⊗ H_1 = 0`. The
  `Tor(H_0, H_1)` terms also vanish.
- In the Lyndon--Hochschild--Serre sequence, `E^2_{pq} = H_p(P; H_q(N))`. The terms of
  total degree 1 and 2 are
  - `E^2_{1,0} = H_1(P) = 0` and `E^2_{2,0} = H_2(P) = 0`;
  - `E^2_{0,1} = E^2_{0,2} = 0` and `E^2_{1,1} = 0`, all because `H_1(N) = H_2(N) = 0`.
- So `H_1(W_{n+1}) = H_2(W_{n+1}) = 0`.

The same computation over `F_p` gives `H_1 = H_2 = 0` with `F_p` coefficients.

**The congruence completion.** `W_∞ = lim W_n`, and continuous homology with `F_p`
coefficients is the direct limit of the duals: `H^j_{cts}(W_∞; F_p) = colim H^j(W_n; F_p)`.
This is `0` for `j = 1, 2`.

So the finite quotients through which the retract argument of item 5 sees `R` carry no
homology in degrees 1 and 2. The same holds for their profinite limit. An obstruction to
`FP_2` for such `R` must come from something these quotients do not see. ∎

## Scope

- Nothing here decides whether a non-contracting fully self-replicating group with
  superperfect root image can be finitely presented. That is a special case of the
  Bartholdi--Grigorchuk--Šunić finitely presented branch-group question.
- Non-split self-branching, where `R^X ⊴ R` has no complement, is not treated. Such
  groups do not arise inside the section-closed hosts: by §2 the rooted copy of `P` is
  always a complement there.

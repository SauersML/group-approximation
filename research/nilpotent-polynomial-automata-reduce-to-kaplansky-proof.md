**Conventions.**
- `G` is a group and `Q` a finite nilpotent group of class `c`.
- `tau(x)(g) = w(x(g m_1), ..., x(g m_k))` with `w in Q * F_k`.
- `e_j` is the exponent sum of variable `j` in `w`, and `alpha = sum_j e_j m_j in Z[G]`.
- `e_ab = exp(Q^ab)`.
- Groups of functions carry pointwise multiplication.

**Step 0. The polynomial function group.**
- `N` is the subgroup of `Q^(Q^G)` generated by:
  - the constants `c_q(x) = q`;
  - the coordinates `pi_g(x) = x(g)`.
- `N` lies in the variety generated by `Q`, so it is nilpotent of class `<= c` and `exp(N)` divides `exp(Q)`.
  Put `e = exp(N)`.
- **(0a) Homomorphisms fixing constants are evaluations.** Let `h : N -> Q` be a homomorphism with
  `h(c_q) = q`, and put `x(g) = h(pi_g)`.
  - Every `F in N` is a word `u` in constants and coordinates, and `h(F) = u(q's, x(g)'s) = F(x)`.
  - So `h = ev_x`.
  - Conversely, every `ev_x` is such a homomorphism.
- **(0b) Pull-backs.** For any map `s : Q^G -> Q^G` whose coordinates `s(-)(g)` lie in `N`, the map
  `F |-> F o s` is an endomorphism of `N` fixing constants, and `ev_x o (- o s) = ev_(s x)`.
  - Put `phi = (- o tau)`. Then `phi(pi_g) = w(pi_(g m_1), ..., pi_(g m_k))` and `ev_x o phi = ev_(tau x)`.
- **(0c) Detecting injectivity and surjectivity.**
  - If `phi` is surjective, then `tau` is injective: `ev_x o phi = ev_x' o phi` forces `ev_x = ev_x'`.
  - If `phi` is bijective, then `tau` is surjective. Given `y`, the map `ev_y o phi^-1` fixes constants, so it
    equals `ev_x` for some `x` by (0a). Then `ev_(tau x) = ev_y`, and evaluating at each `pi_g` gives
    `tau x = y`.

**Step 1. Injective `tau` forces surjective `phi`.**
- Let `P = phi(N)`; it contains all constants. Suppose `P gamma_2(N) != N`.
- `N / P gamma_2(N)` is a nontrivial abelian group of exponent dividing `e`, hence a direct sum of cyclic
  groups, so it maps onto `Z/p` for some prime `p | |Q|`.
- `Q` is nilpotent, so its Sylow `p`-subgroup has nontrivial centre and `Z(Q)` contains a copy of `Z/p`.
- This gives a homomorphism `chi : N -> Z(Q)`, trivial on `P`, with nontrivial image.
- `chi` kills the constants, and `N` is generated by constants and coordinates, so `chi(pi_g) != 1` for
  some `g`.
- Fix `x`. Because `chi` is central-valued, `h = ev_x . chi` (pointwise product) is a homomorphism fixing
  constants. By (0a), `h = ev_x'` with `x'(g) = x(g) chi(pi_g)`, so `x' != x`.
- Since `chi` is trivial on `P`, we get `ev_(tau x') = h o phi = ev_(tau x)`. So `tau x' = tau x`,
  contradicting injectivity.
- Hence `P gamma_2(N) = N`. In a nilpotent group a subgroup that supplements `gamma_2` is the whole group, so
  `P = N`.

**Step 2. The abelian layer is `R/K` and `phi` acts by right multiplication by `alpha`.**
- Let `M = N^ab`, and let `C` be the image of the constants in `M`.
- `R = (Z/e)[G]` maps onto `M/C` by `g |-> [pi_g]`. Call the kernel `K`.
- **`K` is a two-sided ideal.**
  - For `h in G`, the maps `x |-> (g |-> x(h g))` and `x |-> (g |-> x(g h))` pull back as in (0b).
  - They send `[pi_g]` to `[pi_(hg)]` and `[pi_(gh)]`.
  - So `K` is stable under left and right multiplication by `G`.
- **Substitutions act by right multiplication.** For `c in Z[G]` with finite support `h_1, ..., h_r`, let
  `tau_c(x)(g) = prod_i x(g h_i)^(c_(h_i))`, in a fixed order.
  - `psi_c = (- o tau_c)` induces `r |-> r c` on `M/C = R/K`.
  - In particular `phi` induces `phi-bar(r) = r alpha`, because `[w(pi_(g m_1), ...)] = sum_j e_j [pi_(g m_j)]`
    modulo `C`.
- **`K` lies in `e_ab R`.**
  - For `x in Q^G`, let `D_x = ab o ev_x - ab o ev_1 : N -> Q^ab`. It is a difference of homomorphisms into an
    abelian group, so it is a homomorphism.
  - `D_x` kills the constants and sends `pi_g` to `ab(x(g))`. So it factors through `R/K`.
  - Choose `q in Q` whose image in `Q^ab` has order `e_ab`, and let `x` equal `q` at `g` and `1` elsewhere.
  - For `r = sum r_g g in K`, `D_x(r) = r_g ab(q) = 0`, so `e_ab | r_g`.
- **`e_ab R / K` is nilpotent.**
  - Every prime dividing `e` divides `|Q|`.
  - Every prime dividing `|Q|` divides `e_ab`, since a nontrivial `p`-group has nontrivial abelianization.
  - So `e | e_ab^n` for some `n`, and `(e_ab R)^n = e_ab^n R = 0` in `R`.
- **Units lift.** Let `I` be a nilpotent ideal of a ring `S`.
  - If `ab = 1 + i` with `i in I`, then `ab` is a unit.
  - Hence an element that is a unit modulo `I` has a right inverse and, symmetrically, a left inverse. So it
    is a unit of `S`.
  - Therefore `alpha` is a unit of `R/K` if and only if it is a unit of `R / e_ab R = (Z/e_ab)[G]`.
- **Direct finiteness lifts.** Let `I` be nilpotent in `S` with `S/I` directly finite. If `ab = 1` in `S`, then
  `ba = 1 - i` with `i in I`, so `ba` is a unit.
  - Then `a` has the right inverse `b` and the left inverse `(ba)^-1 b`, so `a` is a unit and `ba = 1`.
  - Apply this to `(Z/p^k)[G] -> F_p[G]`, and combine the prime powers by CRT.
  - Result: if `F_p[G]` is directly finite for every `p | |Q|`, then `(Z/e_ab)[G]` is directly finite.
- **Theorem part 2.** If `tau` is injective, then `phi` is surjective by Step 1, so `phi-bar` is surjective.
  - Some `c` has `c alpha = 1` in `R/K`, hence in `(Z/e_ab)[G]`.
  - Under the direct-finiteness hypothesis, `alpha` is then a unit.

**Step 3. A unit `alpha` makes `phi` an automorphism.**
- Assume `alpha` is a unit of `(Z/e_ab)[G]`. By Step 2 it is a unit of `R/K`.
- Lift its inverse to `c in Z[G]`, put `psi = psi_c`, and consider `theta = psi o phi`.
  - `theta` is an endomorphism of `N` fixing constants.
  - On `M/C` it is `r |-> r alpha c = r`.
- **The abelian layer.** Let `theta_1` be the induced map on `M`. Then `theta_1 = id + delta` with
  `delta(M) <= C` and `delta(C) = 0`.
  - So `delta^2 = 0`, and `theta_1` is bijective with inverse `id - delta`.
- **Higher layers.** For `i >= 2` let `gr_i = gamma_i(N)/gamma_(i+1)(N)`.
  - The iterated commutator map `beta_i : M^(tensor i) -> gr_i` is surjective and satisfies
    `gr_i(theta) o beta_i = beta_i o theta_1^(tensor i)`.
  - Write `theta_1^(tensor i) = id + nu`. Then `nu` is the sum, over nonempty subsets `S` of the tensor
    positions, of `delta` in the positions `S` and `id` elsewhere.
  - Any product of `i + 1` of these terms has two subsets that overlap. By `delta^2 = 0` it vanishes, so
    `nu^(i+1) = 0`.
  - Therefore `(gr_i(theta) - id)^(i+1) o beta_i = beta_i o nu^(i+1) = 0`, and `beta_i` is surjective. So
    `gr_i(theta)` is unipotent, hence bijective.
- **Assembling.** The filtration `N = gamma_1 >= ... >= gamma_(c+1) = 1` is finite, and `theta` is bijective on
  every layer. By induction on the layers `theta` is bijective:
  - injectivity: an element of `gamma_i \ gamma_(i+1)` has nontrivial image in `gr_i`;
  - surjectivity: lift layer by layer, from `gr_1` up.
  - So `phi` is injective.
- **The other composite.** `alpha` is a two-sided unit, so `c alpha = 1` in `R/K` as well. The same argument
  applies to `phi o psi`, which acts on `M/C` by `r |-> r c alpha = r`. So `phi o psi` is bijective and `phi` is
  surjective.
- **Theorem part 1.** `phi` is an automorphism, so `tau` is bijective by (0c). This holds for every `G`.

**Step 4. Assembling part 3.**
- Under the hypothesis that `F_p[G]` is directly finite for all `p | |Q|`:
  - `tau` injective => `alpha` has a left inverse (part 2) => `alpha` is a unit (direct finiteness lifts) =>
    `tau` bijective (part 1);
  - `tau` bijective => `alpha` is a unit, by the same chain.
- **Imported hosts.**
  - Sofic groups: `F_p[G]` is directly finite (Elek–Szabó).
  - Unique-product groups: `F_p[G]` has no zero divisors (Strojnowski / Passman), and a domain is directly
    finite. If `ab = 1`, then `(ba - 1) b = 0` gives `ba = 1`.
  - Left-orderable groups are unique-product.
  - Higman's group is left-orderable (Rivas–Triestino, imported).

**Calibration.**
- For `Q = Z/p` we have `N = C + (F_p-linear forms)`, `c = 1`, `K = 0` and `e_ab = p`. The argument reduces to
  the classical equivalence for affine one-track automata.
- The finite-host brute force in `experiments/nilpotent-polynomial-automata-2026-09-17/` confirms
  "bijective iff `alpha` is a unit" with 0 disagreements on nilpotent alphabets.
- The same brute force fails on `S_3` and `A_4`. There Step 1 breaks, because `Z(S_3) = 1` and
  `Z(A_4) = 1` have no central character to shift by, and Step 3 breaks at the non-central layers.

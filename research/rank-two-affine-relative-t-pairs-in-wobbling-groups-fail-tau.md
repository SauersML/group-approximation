## Setting

- `R` is an infinite commutative domain with fraction field `F`, and `A = R²` (column vectors).
- `Λ ≤ GL_2(R)` is any subgroup, and `Γ = Λ ⋉ A` with `(λ, a)(μ, b) = (λμ, a + λb)`. We assume `Γ`
  is generated by a finite set `S`, and write `π: Γ → Λ` for the projection.
- `(Γ, A)` has relative property (T): every unitary representation of `Γ` with almost invariant
  vectors has a nonzero `A`-invariant vector.
- `W(Z)` is the group of bijections of `Z` with bounded displacement. `ρ: Γ → W(Z)` is a
  homomorphism, and `r = max_{s∈S} sup_n |ρ(s)n − n|`.
- For a finite transitive `G`-set `Y` and a finite `Q ⊂ G`, the *gap* of `Q` on `Y` is the largest
  `κ ≥ 0` with `max_{q∈Q} ‖qf − f‖ ≥ κ‖f‖` for all `f ∈ ℓ²_0(Y)` (functions with sum `0`). A group
  has *(τ)* (for all finite-index subgroups) if some finite generating set has gap bounded below on
  all finite transitive `G`-sets.
- For `x ∈ Z`, `A_x` is the stabiliser of `x` in `A`. For a `Γ`-orbit `O`, `O/A` is the set of
  `A`-orbits in `O`. It is a transitive `Λ`-set, since `A` is normal and `Γ/A = Λ`.

## Statement

0. **(Λ is non-amenable.)** `Λ` is not amenable.
1. **(Congruence point kernels on every orbit.)** For every `Γ`-orbit `O ⊂ Z`, finite or infinite,
   there is `d_O ∈ R \ {0}` with `ρ(d_O A)` trivial on `O`. On infinite orbits this uses relative
   (T); on finite orbits it uses only item 0.
2. **(All infinite orbits at once.)** There are at most `2r` infinite orbits. So one `d ≠ 0` (the
   product of the `d_O`) has `ρ(dA)` trivial on their union.
3. **(Faithfulness needs unbounded finite orbits.)** If `ρ` is injective, the finite `Γ`-orbits
   have unbounded size. More precisely, the quotients `|O/A|` are unbounded over finite orbits `O`.
4. **(Precise spectral obstruction.)** If `ρ` is injective, then for every finite `Q ⊂ Λ` the gap of
   `Q` on the `Λ`-sets `O/A` has infimum `0` over the finite `Γ`-orbits `O`. In particular `Λ` fails
   (τ), and so does `Γ`.
5. **(Corollary.)** If `Λ` has (τ), then `Γ` embeds neither in `W(Z)` nor in the topological full
   group `[[X]]` of the full shift `X = {0,1}^Z`, and neither does any group containing a copy of `Γ`.

## Role

- This is a class kill for `full-shift-full-group-has-infinite-normal-relative-t-subgroup`. Every
  witness of the form `Λ ⋉ R²` with `Λ ≤ GL_2(R)`, `R` a domain, `H = R²`, is dead as soon as `Λ`
  has (τ).
- Before this node, the argument for the named candidate `SL_2(F_p[t,t^-1]) ⋉ F_p[t,t^-1]²` used a
  contracting diagonal element and exponential growth of characters on each infinite orbit. Item 1
  needs neither. It uses only that `Λ` is not virtually solvable, which item 0 derives from relative
  (T) itself. So the "base avoids the exponential-growth argument" escape route is closed for every
  rank-two module over a domain.
- The only rank-two survivors are therefore pairs where `Λ` fails (τ) along the specific finite
  `Λ`-sets `O/A`. By item 1 those `Λ`-sets live over congruence quotients: `Γ` acts on each finite
  `O` through `Λ ⋉ (R/d_O R)²`.

## Remarks (not load-bearing)

- The rank lemma (Step 3 of the route) is special to rank two. For `Λ ≤ GL_n(R)` with `n ≥ 3`, a
  finite-index `V ≤ R^n` whose `R`-core spans a proper subspace `W` only forces the stabiliser into
  the group of matrices that are `≡ 1` modulo `W`. That group contains a copy of `GL(W)`, so it is
  not amenable when `dim W ≥ 2`. The argument then needs extra input on co-amenable subgroups of
  `Λ`, for instance (T) for `Λ`, which makes co-amenable subgroups have finite index.
- The named candidate `Γ_p = SL_2(F_p[t,t^-1]) ⋉ F_p[t,t^-1]²` is an instance. Its pair has
  relative (T) by `elementary-linear-semidir-pair-relative-t`. So item 5 applies to it once (τ) for
  `SL_2(F_p[t,t^-1])` is imported. That is a classical S-arithmetic spectral-gap statement, and no
  verbatim citation for it is recorded here. Unconditionally, items 1–4 say that any embedding of
  `Γ_p` in `W(Z)` would make `SL_2(F_p[t,t^-1])` fail (τ) along the finite `Λ`-sets `O/A`.
- By `wobbling-normal-relative-t-subgroups-are-locally-finite`, `A` must also be locally finite, so
  `char R = p > 0`. The statement above does not need this.

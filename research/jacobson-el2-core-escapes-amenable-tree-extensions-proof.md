# Proof

Notation is as in the target. `K = F_2((z^-1))` carries the absolute
value `|f| = 2^{deg f}`, and `SL_2(K)` acts on `P^1(K) = K u {infinity}`
by Möbius maps. `U^+(L) = x_12(L)` and `U^-(L) = x_21(L)`.

## Step 0. Symbol kernel and local finiteness

**(0a) Kernel of the symbol.** `sigma` is well defined, since
`TS -> 1`. It kills `Q`.

* From `T Q = T - TST = 0` and `Q S = S - STS = 0`, the ideal generated
  by `Q` is `I = span{S^a Q T^b}`.
* In `J/I` we have `ST = 1 = TS`. So `J/I` is generated by a unit and its
  inverse, and it is a quotient of `L`.
* `sigma` induces a map back to `L` that inverts this quotient map.

Hence `ker sigma = I`.

**(0b) A faithful finitary representation.** Let `V = F_2^(N)`. Define
`rho` by `S e_i = e_{i+1}`, `T e_i = e_{i-1}` and `T e_0 = 0`.

* `rho(S^a T^b)` sends `e_i` to `e_{i-b+a}` if `i >= b`, and to 0
  otherwise.
* `J` has basis `S^a T^b`: rewrite `TS -> 1`, which has no overlaps.
* Suppose `sum c_ab S^a T^b` acts as zero, and let `b0` be the least `b`
  that occurs. Evaluating at `e_{b0}` gives `sum_a c_{a b0} e_a = 0`. By
  induction on `b0`, `rho` is faithful.
* `rho(S^a Q T^b)` is the matrix unit `e_a (x) e_b^*`.

So `M_2(J)` acts faithfully on `V^2`, and `M_2(I)` acts by finite-rank
matrix units.

**(0c) The kernel `K_J` is locally finite.** Let
`K_J = GL_2(J) ∩ (1 + M_2(I))`, which is the kernel of `sigma` on
`GL_2(J)`. Take finitely many `1 + X_j` in `K_J`. Choose `n` so that
every `X_j` is a combination of matrix units with indices `<= n`. Let
`W_n = span(e_0, ..., e_n)^2`.

* Each `1 + X_j` fixes `e_i` for `i > n`, in both summands, and maps
  `W_n` into itself.
* It is bijective on `V^2`, so it is injective on the finite set
  `W_n`, hence bijective there. So its inverse has the same two
  properties.
* Every element `g` of the generated group therefore has both
  properties, and by faithfulness `g` is determined by `g|_{W_n}`, which
  lies in the finite group `GL(W_n)`.

So the group is finite.

**(0d) The unipotent preimages are locally finite.** Let
`V~^± = GL_2(J) ∩ sigma^{-1}(U^±(L))`. Then `V~^±` is an extension of
`K_J` by a subgroup of `(L,+)`, which is an elementary abelian
`2`-group.

Extensions of locally finite groups by locally finite groups are locally
finite. Let `H` be generated by a finite set. Its image `H-bar` is
finite. So `H ∩ K_J` has finite index in `H`, and by Schreier it is
finitely generated. Being a finitely generated subgroup of `K_J`, it is
finite. Hence `H` is finite.

So `V~^+` and `V~^-` are locally finite.

## Step 1. The symbol image of `E0`

In `SL_2(L)` and in characteristic 2, for a unit `u` put
`w(u) = x_12(u) x_21(u^-1) x_12(u)`. Then `w(u) = [[0,u],[u^-1,0]]`, and

```text
w(z) w(1) = diag(z, z^-1) =: d.
```

Both lie in `sigma(E0)`, because `sigma(x_12(S)) = x_12(z)` and
`sigma(x_21(T)) = x_21(z^-1)`. Conjugation gives

```text
d x_12(f) d^-1 = x_12(z^2 f),    d x_21(g) d^-1 = x_21(z^-2 g).      (1)
```

Starting from `x_12(1)` and `x_12(z)`, the images `x_12(z^k)` appear for
every `k`, and sums give all of `x_12(L)`. The same holds for `x_21`.

So `sigma(E0) ⊇ U^+(L) ∪ U^-(L)`, and hence
`sigma(E0) = E_2(L) = <U^+(L), U^-(L)>`.

Let `V^± = E0 ∩ V~^±`. These are locally finite by (0d), and
`sigma(V^±) = U^±(L)`.

Fix `dt` in `E0` with `sigma(dt) = d`. The symbol `d` normalizes
`U^±(L)`, and `dt` normalizes `E0`. Hence `dt` normalizes `V^+` and
`V^-`.

## Step 2. A projective paradox

**Lemma P.** Let `f` and `f'` be distinct polynomials in `F_2[z]` of
degree at least 1, and let `g` be a polynomial of degree at least 1.
Then no amenable group `Gamma` has a homomorphism to `SL_2(K)` whose
image contains `x_12(f)`, `x_12(f')` and `x_21(g)`.

*Proof.* Split `P^1(K)` into three pieces:

* `X_1 = {|x| > 1} u {infinity}`;
* `X_2 = {|x| < 1}`;
* `X_3 = {|x| = 1}`.

The three maps act as follows.

* `a = x_12(f)` acts by `x -> x + f`. It sends `X_2` into
  `{y : |y - f| < 1}`, and that set lies in `X_1` because `|f| >= 2`.
* `a' = x_12(f')` likewise sends `X_2` into `{y : |y - f'| < 1}`, also
  inside `X_1`.
* These two images are disjoint. By the ultrametric inequality, a
  common point would give `|f - f'| < 1`, while `f - f'` is a nonzero
  polynomial.
* `b = x_21(g)` acts by `x -> x/(gx + 1)`. Let `|x| >= 1`, or
  `x = infinity`, which is sent to `1/g`. Then `|gx| >= 2`, so
  `|gx + 1| = |g||x|` and `|b x| = 1/|g| <= 1/2`. Hence
  `b(X_1 u X_3) ⊆ X_2`.

Now suppose `Gamma` is amenable, with a left-invariant mean `m`. Fix
`x0` in `P^1(K)` and set `mu(Y) = m({gamma : gamma x0 ∈ Y})`. Then `mu`
is a finitely additive probability on `P^1(K)`, invariant under the
image. It satisfies

```text
mu(X_1) >= mu(a X_2) + mu(a' X_2) = 2 mu(X_2),
mu(X_2) >= mu(b(X_1 u X_3)) = mu(X_1) + mu(X_3).
```

So `mu(X_2) >= mu(X_1) >= 2 mu(X_2)`. Hence `mu(X_1) = 0`,
`mu(X_2) = 0` and `mu(X_3) = 0`, which contradicts
`mu(P^1(K)) = 1`. ∎

Lemma P will be applied to two triples:

* (T1) `x_12(z), x_12(z^2), x_21(z)`, all in `E_2(L)`;
* (T2) `x_12(z^2+1), x_12(z^3+z), x_21(z^2+1)`.

## Step 3. Locally finite groups on trees with trivial edge stabilizers

**Lemma F.** Let `Phi` act on a tree `T` without inversions and with
trivial edge stabilizers. Then every nontrivial locally finite subgroup
`M <= Phi` fixes exactly one vertex `v_M`. Every element of `Phi` that
normalizes `M` fixes `v_M`.

*Proof.*

1. *A finite group `F` fixes a vertex.* Take a vertex orbit `F v`. Its
   convex hull is a finite `F`-invariant subtree, and the center of that
   subtree is a vertex or an edge. Because there are no inversions, a
   central edge has both endpoints fixed.
2. *Fixed sets are convex.* An automorphism fixing `u` and `w` fixes the
   geodesic `[u,w]`. So `Fix(F)` is a subtree.
3. *A nontrivial finite `F` fixes exactly one vertex.* `Fix(F)` contains
   no edge, since `F` is not inside an edge stabilizer. So it is one
   vertex `v_F`.
4. *All these vertices agree.* Take nontrivial finite `F_1, F_2 <= M`.
   The group `F' = <F_1, F_2>` is finite, and
   `Fix(F') ⊆ Fix(F_1) ∩ Fix(F_2)`. So `v_{F_1} = v_{F'} = v_{F_2}`.
5. *`M` fixes that vertex and no other.* Every `m != 1` lies in the
   finite group `<m>`, so `M` fixes the common vertex `v`. Any vertex
   fixed by `M` is fixed by every such `F`, so it equals `v`.
6. *Normalizers fix it.* If `h M h^-1 = M`, then `h v` is fixed by `M`,
   so `h v = v`. ∎

## Step 4. Proof of the Theorem

Suppose `E0 <= G` with `G ∈ S`. Let `N` be the amenable normal
subgroup, `pi : G -> Phi = G/N`, and `T` the tree. Put `A = E0 ∩ N`,
which is amenable and normal in `E0`, with `E0/A ≅ pi(E0)`. Note two
facts:

* `sigma(A)` is normal in `sigma(E0) = E_2(L)`.
* `sigma(A)` is amenable, being a quotient of `A`.

**(4a) `pi(V^+) != 1` and `pi(V^-) != 1`.** Suppose `pi(V^+) = 1`. Then
`V^+ ⊆ A`, so `sigma(A) ⊇ U^+(L)`. Normality gives
`sigma(A) ⊇ w(1) U^+(L) w(1)^-1 = U^-(L)`. So `sigma(A)` contains (T1),
and Lemma P contradicts its amenability. The case `V^-` is symmetric.

By (0d), `pi(V^±)` is a nontrivial locally finite group. By Lemma F it
fixes a unique vertex `v±`. Since `dt` normalizes `V^±`, `pi(dt)`
normalizes `pi(V^±)`, and so `pi(dt)` fixes both `v+` and `v-`.

**(4b) Case `v+ = v-`.** The six generators of `E0` lie in
`V^+ u V^-`. So `pi(E0)` fixes `v+` and lies in a vertex stabilizer,
which is amenable. Then `E0` is amenable, as an extension of `A` by
`pi(E0)`. So `sigma(E0) = E_2(L)` is amenable. But it contains (T1),
which contradicts Lemma P.

**(4c) Case `v+ != v-`.** `pi(dt)` fixes the geodesic `[v+, v-]`, which
contains an edge. Edge stabilizers are trivial, so `pi(dt) = 1`, and
`dt ∈ A`. Since `A` is normal, `[dt, y] ∈ A` for every `y ∈ E0`.

Pick `y_f` and `y'_g` in `E0` with `sigma(y_f) = x_12(f)` and
`sigma(y'_g) = x_21(g)`. They exist by Step 1. In characteristic 2,
(1) gives

```text
sigma([dt, y_f])  = x_12(z^2 f) x_12(f)       = x_12((z^2+1) f),
sigma([dt, y'_g]) = x_21(z^-2 g) x_21(g)      = x_21((z^-2+1) g).
```

With `f = 1`, `f = z` and `g = z^2`, the amenable group `sigma(A)`
contains (T2). This contradicts Lemma P.

Every case is contradictory, so `E0` does not embed in any group in
`S`. ∎

## Step 5. Members of `S` and the named groups

**Closure under subgroups.** Let `H <= G ∈ S`. Then `H ∩ N` is amenable
and normal in `H`, and `H/(H ∩ N) ≅ pi(H)`. The group `pi(H)` acts on
the same tree, and its stabilizers are subgroups of the old ones.

**Free products.** Let `Phi = *_i A_i`, with each `A_i` amenable. Its
Bass–Serre tree has two kinds of vertices and one kind of edge:

* vertices are the cosets `gamma A_i` together with the elements
  `gamma` (cosets of the trivial group);
* for each `gamma` and each `i` there is an edge from `gamma` to
  `gamma A_i`.

This graph is connected because the `A_i` generate `Phi`. It has no
circuit by the normal form theorem for free products (Serre, *Trees*,
§I.4). `Phi` acts without inversions, because the action preserves the
vertex type. Edge stabilizers are trivial, and vertex stabilizers are
conjugates of the `A_i` or trivial. So `Phi ∈ S`, with `N = 1`.

**Schafhauser amalgams.** Let `G = G_1 *_N G_2`, with each `G_i`
amenable and `N` normal in both. Then `N` is normal in `G`, and
`G/N ≅ (G_1/N) * (G_2/N)`, because the two presentations agree. `N` is
amenable, so `G ∈ S`.

**The named groups contain `E0`.**

* `EL_2(J)` sits in the upper-left corner of `EL_n(J)`.
* `EL_2(J)` is the left Levi factor inside `W`, `P22(J)` and `H_mix`.

A finitely generated subgroup that contains `E0` and embeds in a member
of `S` would, by closure under subgroups, put `E0` in `S`. Step 4
excludes this. So none of these groups is locally in `S`. ∎

## Remarks

* No normal subgroup theorem is used. The torus `diag(z, z^-1)` is where
  the Laurent ring matters. Over `F_2[z]` the unit torus is trivial and
  the argument stops at (4c). No claim is made about `SL_2(F_2[z])`.
* The mechanism is general. It needs two opposite locally finite
  subgroups `V^±` that generate, together with an element normalizing
  both whose commutators with them carry a paradoxical configuration. So
  it applies to the core of `E_2(R)` for any ring `R` with a surjection
  onto `F_q[z, z^-1]` whose kernel `k` makes `GL_2(R) ∩ (1 + M_2(k))`
  locally finite. Lemma P holds verbatim over `F_q((z^-1))`.
* The theorem says nothing about MF for `EL_2(J)`. That group is LEF by
  [[binary-jacobson-el2-is-lef]], so `S` and LEF are incomparable.

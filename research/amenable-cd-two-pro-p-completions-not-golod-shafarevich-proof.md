Notation as in the target. `P` is the relation module of an `n`-generator presentation of `K`,
so `0 → P → Z[K]^n → Z[K] → Z → 0` is exact. Since `cd K <= 2`, `P` is projective (Schanuel).
`r = rank_Q(Q ⊗_{Z[K]} P)`. Applying `Q ⊗_{Z[K]} −` computes `H_*(K; Q)`, so
`r = n − 1 + χ` and `r < ∞`, because `b_2(K) < ∞`.

## 0. Recalled facts

- **(S1)** *Finite-quotient Swan* (item 1 of `rf-weak-bass-defect-is-degree-two-approximation-defect`,
  from Bass 1963 and Swan 1960). For every finite quotient `F = K/M`, `P_F := Z[F] ⊗_{Z[K]} P`
  is a finitely generated projective `Z[F]`-module with `Q ⊗ P_F ≅ Q[F]^r`.
- **(S2)** Let `A = Z_p` and `F` be finite. Two finitely generated projective `A[F]`-modules
  `X, Y` with `Q_p ⊗ X ≅ Q_p ⊗ Y` are isomorphic. (Serre, *Linear representations of finite
  groups*, §16.1, Cor. 2 of Thm. 34: the map `e : P_A(F) → R_{Q_p}(F)` is injective for any
  complete discrete valuation ring `A` with residue characteristic `p`.)
- **(S3)** For a finitely generated group `Γ` with pro-p completion `G = Γ_p̂`, the map
  `H^1(G; F_p) → H^1(Γ; F_p)` is an isomorphism and `H^2(G; F_p) → H^2(Γ; F_p)` is injective.
  (Standard: the first holds because both sides are `Hom(−, F_p)`. For the second, a class in
  the kernel is a central extension `0 → F_p → E → G` that splits over `Γ`, and so it splits
  over `G` by the universal property of the completion. See Lubotzky, "Group presentation,
  p-adic analytic groups and lattices in SL_2(C)", Ann. Math. 118 (1983), §1.)
- **(S4)** A finitely generated pro-p group `G` has a presentation `1 → R → F → G → 1` with `F`
  free pro-p of rank `d(G)` and `R` generated as a closed normal subgroup by `r(G)` elements,
  all in `Φ(F) = F^p[F,F]`. In the Magnus degree `D`, `D(x) >= 2` for `x ∈ Φ(F)` (Koch; Ershov,
  "Golod–Shafarevich groups: a survey", §3.1).
- **(S5)** (Ershov's survey, §3.1, Def. (i)–(iii).) A pro-p presentation `(X, R)` is
  *Golod–Shafarevich* if `1 − |X| τ + Σ_{ρ ∈ R} τ^{D(ρ)} < 0` for some `τ ∈ (0,1)`. An abstract
  group is GS if its pro-p completion has such a presentation. By Ershov–Jaikin-Zapirain, *Kazhdan
  quotients of Golod–Shafarevich groups*, Proc. LMS 102 (2011), Thm. 1.1 (survey Thm. 12.7), a
  GS abstract group has an infinite quotient with property (T). So it is not amenable.
- **(S6)** (Lubotzky–Mann.) A pro-p group in which every open subgroup is generated by at most
  `s` elements is p-adic analytic, and its dimension is at most `s`, since a uniform open
  subgroup `U` has `dim = d(U)`.

## 1. Item 1: exact Euler characteristics

Let `N` have finite index, `M ⊴ K` its normal core, `F = K/M` and `H = N/M <= F`. For any
commutative ring `k`, `k ⊗_{Z[N]} −` applied to the resolution of `Z` restricted to `N`
computes `H_*(N; k)`. It is a resolution by projective `Z[N]`-modules, because the restriction
of a projective module to a finite-index subgroup is projective. The terms are

> `k ⊗_{Z[N]} P = k ⊗_{Z[H]} P_F`, `k ⊗_{Z[N]} Z[K]^j = k^{j[K:N]}`.

By (S1), `P_F ⊗ Z_p` is a finitely generated projective `Z_p[F]`-module with `Q_p ⊗ (P_F ⊗ Z_p)`
isomorphic to `Q_p[F]^r`. By (S2), `P_F ⊗ Z_p ≅ Z_p[F]^r`. Hence `F_p ⊗ P_F ≅ F_p[F]^r` and
`Q ⊗ P_F ≅ Q[F]^r`, and both are free over the subgroup algebra of `H`. So for
`k ∈ {Q, F_p}`, `dim_k(k ⊗_{Z[N]} P) = r [F:H] = r [K:N]`. The complex computing `H_*(N; k)`
is `0 → k^{r[K:N]} → k^{n[K:N]} → k^{[K:N]} → 0`. Its homology is finite dimensional, and its
Euler characteristic is `[K:N](r − n + 1) = [K:N] χ`. This proves the identity.

`H_2(N; Z)` is the kernel of `Z ⊗_{Z[N]} P → Z^{n[K:N]}`. The group `Z ⊗_{Z[N]} P = Z ⊗_{Z[H]} P_F`
is a direct summand of `Z ⊗_{Z[H]} Z[F]^m` for some `m`, so it is a finitely generated free
abelian group, and so is its subgroup `H_2(N; Z)`. Its rank is `b_2(N; Q)`. By the universal
coefficient theorem, `b_2(N; F_p) = b_2(N; Q) + t_p`, where `t_p` is the `p`-rank of
`tors H_1(N; Z)`.

## 2. Item 2: the Golod–Shafarevich bound

Fix `N` and `p`. Put `G = N_p̂`, `d = d(G)` and `r_G = r(G)`. By (S3), `d = b_1(N; F_p)` and
`r_G <= b_2(N; F_p)`. By item 1, `b_2(N; F_p) = d − 1 + [K:N] χ`. Take the minimal presentation
of (S4). Every relator has degree at least 2, so for `τ ∈ (0,1)`,

> `1 − dτ + H_R(τ) <= f(τ) := 1 − dτ + r_G τ²`.

Suppose `d >= 2` and `d² > 4 r_G`. Then `f(τ) < 0` for some `τ ∈ (0,1)`:

- if `r_G = 0`, take `τ ∈ (1/d, 1)`;
- if `0 < r_G` and `d < 2 r_G`, take `τ = d/(2 r_G) ∈ (0,1)`, where `f = 1 − d²/(4 r_G) < 0`;
- if `d >= 2 r_G > 0`, then `f(1) = 1 − d + r_G <= 1 − d/2 <= 0`. Equality forces `d = 2` and
  `r_G = 1`, which contradicts `d² > 4 r_G`. So `f(1) < 0`, and by continuity `f(τ) < 0` for
  `τ < 1` close to `1`.

So `G` is Golod–Shafarevich, and `N` is a GS abstract group. By (S5), `N` is not amenable. But
`N <= K` is amenable, a contradiction. Hence `d <= 1` or `d² <= 4 r_G <= 4(d − 1 + [K:N] χ)`,
that is, `(d − 2)² <= 4 [K:N] χ`. In both cases `d <= 2 + 2 √([K:N] χ)`, using `χ >= 0`. That
`χ >= 0` follows from the same inequality when `d >= 2`. When `d <= 1`, the bound
`d <= 2 <= 2 + 2√(...)` needs only `[K:N] χ >= 0`, and this holds: by item 1,
`[K:N] χ = 1 − d + b_2(N; F_p) >= 0` when `d <= 1`.
Finally `b_1(N; Q) <= b_1(N; F_p)` by the universal coefficient theorem, since `H_1(N; Z)` is
finitely generated.

## 3. Items 3 and 4

*Item 3.* If `χ = 0`, item 2 gives `d <= 1` or `(d − 2)² <= 0`, so `d <= 2` for every
finite-index `N`. If `d = 2`, then `4 <= 4 r_G <= 4(d − 1) = 4`, so `r_G = 1`. Let `G = K'_p̂` for
a finite-index `K' <= K`. Every open subgroup `V` of `G` is the closure of a subgroup `N <= K'` of
finite index (subnormal of p-power index), and `V ≅ N_p̂`. For this, note that the normal core
in `K'` of a subgroup of p-power index in `N` has p-power index in `K'`, so the pro-p topologies
agree. Hence `d(V) = b_1(N; F_p) <= 2` for every open `V`. By (S6), `G` is p-adic analytic of
dimension at most 2.

*Item 4.* If `K` is a counterexample with finite abelianization, then `b_1(K) = 0` and
`χ = 1 + b_2(K) >= 1`. Items 1 and 2 give the bounds on `b_1(N; F_p)` and `d(K_p̂)`. Also
`b_2(N; Q) = [K:N] χ − 1 + b_1(N; Q)` with `0 <= b_1(N; Q) <= 2 + 2√([K:N] χ)`.

*Calibrations.* `Z²`: `H_1 = Z²`, `d = 2`, `b_2 = 1`. Klein bottle group `⟨a, b | abab^{-1}⟩`:
`H_1 = Z ⊕ Z/2`, and `d = 2`, `b_2(F_2) = 1` at `p = 2`. `BS(1,m) = ⟨a, t | tat^{-1} = a^m⟩`:
`H_1 = Z ⊕ Z/(m−1)`, and `d = 2` exactly when `p | m − 1`. All three have `χ = 0` and meet item 3.
Surface groups of genus `g >= 2` have `d = 2g`, `r = 1` and `d² > 4r`, so they are GS and not
amenable. Their `χ = 2 − 2g` is multiplicative, as item 1 predicts, since item 1 does not use
amenability.

## 4. Where the pro-p route stops

(a) *Direction.* The only input item 2 takes from `K` is an **upper** bound on relations,
`r(N_p̂) <= d − 1 + [K:N] χ`. The Golod–Shafarevich inequality turns few relations into
non-amenability. A counterexample has `χ >= 1`, which means *many* relations relative to
generators. That is compatible with `d² <= 4r`: take `d` bounded and `r ~ [K:N] χ`. So no
argument of the form "item 1 + GS" can refute `χ >= 1`. The GS bound is a constraint on
counterexamples, not a contradiction.

(b) *Perfect covers.* If every finite-index subgroup of `K` has finite pro-p completions for
every `p` (for instance if every finite quotient of `K` is generated by `p'`-elements for all
`p`), items 2–3 carry no information. The pro-p route cannot see such a `K`, and a
counterexample of this kind remains possible.

(c) *What would close it: p-goodness.* The injection (S3) is the only place where information
is lost. Call `N` *p-good* if `H^i(N_p̂; F_p) → H^i(N; F_p)` is an isomorphism for all `i`. This
passes to subnormal subgroups of p-power index (Shapiro). Suppose a counterexample `K` has a
p-good finite-index `N` with `G = N_p̂` infinite. Then:

- `cd_p G <= 2`;
- every open `V` has `1 − d(V) + r(V) = [G:V] · [K:N] χ >= [G:V]`, which is exact Euler
  multiplicativity;
- `d(V)² <= 4 r(V)` by item 2.

`G` cannot be p-adic analytic. A uniform open `U` has `r(U) = C(dim G, 2)`, which is bounded,
while `[G:U]` is unbounded. So `G` would be an infinite, non-analytic pro-p group of cd 2 that is
not GS and has Euler characteristic `>= 1`, multiplicative on open subgroups. The mild groups of
Labute show that `χ > 0` alone is possible in cd 2 (`d = 5`, `r = 6`, `χ = 2`), but those are GS.
The precise pro-p question left open: *does an infinite finitely generated pro-p group of cd 2 with
`χ(G) > 0` have an open subgroup that is Golod–Shafarevich?* A positive answer would show that
every p-good finite-index subgroup of a counterexample has finite pro-p completion.

Notation as in the target. `F` is a finite field. Every step is elementary
linear algebra. The import `jacobson-shift-representation-is-faithful` covers
`F = F_2`, and Step 1 reproves the fact it is used for, for every `F`.

## Step 1. The two boundary actions

**Near action.**
- `V_+ = F^((N)) (x) F^2` has basis `e_(k,i)`, `k >= 0`, `i in {1,2}`.
- `S e_k = e_(k+1)`, `T e_(k+1) = e_k` and `T e_0 = 0`. Then `TS = 1`, so this is
  a `J`-module, and `M_2(J)` acts on `V_+`. Write `g_+` for the action of `g`.

**Far action.**
- `J' = F<S',T' | S'T' = 1>`.
- For an integer `M`, let `V_-^M = F^((k <= M)) (x) F^2`.
- `S' e_k = e_(k+1)` for `k < M`, `S' e_M = 0`, and `T' e_k = e_(k-1)`.
  Then `S'T' = 1`.
- The map `beta : J -> J'`, `S -> T'`, `T -> S'` is a ring isomorphism, since
  `TS = 1` goes to `S'T' = 1`, and the inverse map is defined the same way.
- Write `h_-` for the action of `h in M_2(J')` on `V_-^M`.

**Faithfulness.** The monomials `S^a T^b` span `J`. The operator `S^a T^b`
sends `e_k` to `e_(k+a-b)` if `k >= b`, and to `0` otherwise.
- Suppose `x = sum c_ab S^a T^b` acts as zero, and let `b_0` be the least `b`
  that occurs.
- Then `x e_(b_0) = sum_a c_(a b_0) e_a`. This vector is zero only if every
  `c_(a b_0)` vanishes, a contradiction.
- So the monomials form a basis, `J` acts faithfully on `F^((N))`, and `M_2(J)`
  acts faithfully on `V_+`.
- Mirror-symmetrically, `M_2(J')` acts faithfully on `V_-^M`.

**Laurent normal form.** Let `L(f)` be the Laurent operator of
`f in M_2(A)` on `F^((Z)) (x) F^2`, with `z` acting by `e_k -> e_(k+1)`.
Let `sigma' : J' -> A` be `S' -> z`, `T' -> z^(-1)`.
- For each monomial the discrepancy is confined to a bounded stretch of `k`:
  `S^a T^b e_k = L(z^(a-b)) e_k` for `k >= b`, and the far action of a monomial
  agrees with its Laurent operator for `k <= M - b'`, for the corresponding
  `b'`.
- Hence for every `g in M_2(J)` there are constants `c(g)` and `r(g)`,
  independent of `M`, with:

```text
g_+ e_k = L(sigma g) e_k   for k >= c(g),      supp(g_+ e_k) ⊂ [k - r(g), k + r(g)],   (N1)
h_- e_k = L(sigma' h) e_k  for k <= M - c(h),  supp(h_- e_k) ⊂ [k - r(h), k + r(h)].   (N2)
```

Here `e_k` stands for either `e_(k,1)` or `e_(k,2)`, and `c` and `r` are
computed from the monomials in the entries.

## Step 2. The mirror lift theta : EL_2(J) -> EL_2(J')

**(a) An automorphism from tau.** `tau : J -> J` with `tau(S) = T` and
`tau(T) = S` is an anti-automorphism.
- It respects the relation: `tau(TS) = tau(S) tau(T) = TS = 1`.
- It is an involution.
- For `g in M_2(J)` let `g^tau` be `g` with `tau` applied entrywise and then
  transposed. From `tau(xy) = tau(y) tau(x)`, entry by entry,
  `(gh)^tau = h^tau g^tau`.
- So `g -> (g^tau)^(-1)` is a group automorphism of `GL_2(J)`.
- It sends `e_12(a)` to `e_21(-tau a)` and `e_21(a)` to `e_12(-tau a)`, so it
  preserves `EL_2(J)`.

**(b) Correct by K.** `K = [[0,1],[-1,0]] = e_12(1) e_21(-1) e_12(1)` lies in
`EL_2(F)`, and `K e_21(b) K^(-1) = e_12(-b)`. So
`psi(g) = K (g^tau)^(-1) K^(-1)` is an automorphism of `G` with

```text
psi(e_12(a)) = e_12(tau a),      psi(e_21(a)) = e_21(tau a).                    (L1)
```

**(c) The symbol of psi.**
- `sigma o tau = iota o sigma` on generators, and both sides are ring maps into
  the commutative ring `A`, so the identity holds on all of `J`.
- Hence `sigma(psi g) = K iota(sigma g)^(-t) K^(-1)`.
- For `m in SL_2(C)` over a commutative ring `C`, `m^(-t) = K m K^(-1)`
  (adjugate formula). `K^2 = -1` is central.
- `sigma(g)` lies in `SL_2(A)`, because `G` is generated by elementary
  matrices.
- Therefore

```text
sigma(psi g) = iota(sigma g).                                                    (L2)
```

**(d) The mirror lift.** Put `theta = beta_* o psi : G -> EL_2(J')`, applying
`beta` entrywise.
- `sigma' o beta = iota o sigma`, since `beta(S) = T'` goes to `z^(-1)`.
- So `sigma'(theta g) = iota(sigma(psi g)) = iota(iota(sigma g)) = sigma(g)`.
- `theta` is a homomorphism with the same Laurent symbol as the identity map.
- By (L1), `theta(e_ij(a)) = e_ij(beta tau a)`, with
  `beta tau (S^p T^q) = T'^q S'^p`.

## Step 3. Gluing

For `g in G` and `M >= 1`, let `W_M = span{e_(k,i) : 0 <= k <= M}` and
define the linear map `Phi_M(g)` on `W_M` column by column:

```text
Phi_M(g) e_k = g_+ e_k              if k <= M/2,
Phi_M(g) e_k = (theta g)_- e_k      if k >  M/2.                                  (G1)
```

**Well defined.** Let `B ⊂ G` be finite, with `1 in B` and `B = B^(-1)`.
- Put `R = max r(x)` and `C = max c(x)` over `x in B ∪ BB` and over the
  corresponding `theta(x)`.
- Take `M > 4(R + C) + 4`.
- For `x in B ∪ BB` and `k <= M/2`, `x_+ e_k` is supported in
  `[0, M/2 + R] ⊂ [0, M]`. For `k > M/2`, `(theta x)_- e_k` is supported in
  `[M/2 - R, M]`.
- So `Phi_M(x)` maps `W_M` to itself.

**Middle agreement.** Let `x in B ∪ BB` and let `k` lie within `2R` of `M/2`.
- Then `k >= C` and `k <= M - C`.
- By (N1), (N2) and Step 2(d), both
  `x_+ e_k = L(sigma x) e_k` and `(theta x)_- e_k = L(sigma' theta x) e_k = L(sigma x) e_k`.
- So near the seam `Phi_M(x) e_k` is given by either formula.

**Multiplicativity on B.** Let `x, y in B`, and fix `k <= M/2`.
- `Phi_M(y) e_k = y_+ e_k = sum_j lambda_j e_(k_j)`, with every `k_j <= M/2 + R`.
- For `k_j <= M/2`: `Phi_M(x) e_(k_j) = x_+ e_(k_j)`.
- For `M/2 < k_j <= M/2 + R`: `Phi_M(x) e_(k_j) = (theta x)_- e_(k_j) = x_+ e_(k_j)`,
  by middle agreement.
- Hence `Phi_M(x) Phi_M(y) e_k = x_+ y_+ e_k = (xy)_+ e_k = Phi_M(xy) e_k`,
  using that `V_+` is a representation.
- The case `k > M/2` is the mirror argument with `theta(x) theta(y) = theta(xy)`,
  using middle agreement for columns in `[M/2 - R, M/2]`.

So `Phi_M(xy) = Phi_M(x) Phi_M(y)` for `x, y in B`, and `Phi_M(1) = 1`.
Hence each `Phi_M(x)` is invertible, with inverse `Phi_M(x^(-1))`.

**Injectivity on B.** Let `x != y` in `B`. By faithfulness, `x_+ != y_+`.
We find a column `k <= M/2` with `x_+ e_k != y_+ e_k`; since `Phi_M` agrees
with `x_+` and `y_+` there, this gives `Phi_M(x) != Phi_M(y)`.
- **If `sigma x != sigma y`.** Then `L(sigma x) - L(sigma y)` is a nonzero
  translation-invariant operator, so it is nonzero on the column `e_C`. By (N1),
  `x_+ e_C = L(sigma x) e_C` and `y_+ e_C = L(sigma y) e_C`. Take `k = C <= M/2`.
- **If `sigma x = sigma y`.** Then by (N1), `x_+ e_k = y_+ e_k` for all
  `k >= C`. So the nonzero operator `x_+ - y_+` is nonzero on some column
  `k < C <= M/2`.

**Conclusion.** `Phi_M|_B : B -> GL(W_M) = GL_(2(M+1))(F)` is injective and
multiplicative on `B x B`, and the target is finite. So `G` is LEF.

## Step 4. MF, soficity and the radical

- **MF.** Compose `Phi_M` with the left regular representation of the finite
  group `GL(W_M)`.
  - Distinct group elements `u != v` give `||lambda(u) - lambda(v)|| >= sqrt 2`,
    tested on `delta_1`.
  - Choosing `M_B` along an exhausting sequence of finite sets `B` gives an
    injective homomorphism of `G` into `prod_B U(|GL(W_(M_B))|) / (+)`.
  - So `G` is MF. By definition of the MF radical, `Rad_MF(G) = 1`.
- **Sofic and hyperlinear.** LEF implies both: use the permutation action of
  the finite groups on themselves.
- **The head survives.** `e_12(Q)` is a nonidentity element of `G`, and in this
  model its image is nontrivial.

## Step 5. Why the construction stops at rank two

The only rank-dependent input is (L2), the inner identity
`m^(-t) = K m K^(-1)` on `SL_2`.

**Ranks `n >= 3`.** The same gluing needs a homomorphism
`theta_n : EL_n(J) -> EL_n(J')` with `sigma' o theta_n = sigma`.
- The candidates obtained from `tau` or `beta` induce `iota` composed with
  transpose-inverse on the symbol. That map is an outer automorphism of
  `SL_n(A)` for `n >= 3`.

For `n >= 4` no such `theta_n` can exist at all: `EL_n(J)` is not LEF by
`cohn-elementary-group-is-not-lef`, while the gluing of Step 3 would make it
LEF.

**What the obstruction needs.** A (T)-free proof that `x_13(Q)` dies in norm
coronas of `St_5(J)` must therefore use a relation with three distinct
indices. Every relation among `x_ij(J)` and `x_ji(J)` for one pair `{i,j}`
holds in the LEF group `EL_2(J)`, where the head `e_ij(Q)` survives.

## Step 6. Numerical confirmation

`experiments/rank-two-jacobson-lef-2026-09-17/check_el2_lef.py` implements
`J` in the monomial normal form, together with (G1) and (L1).
- **Main test.** With `M = 90` and 400 random words over 24 coefficient types,
  the product of glued generators equals the gluing computed directly from the
  exact group element, with `theta(g)` recomputed from `g^(-1)` through
  `K (g^tau)^(-1) K^(-1)` rather than from (L1). There were 0 failures.
- **Injectivity.** The words gave 344 distinct elements with 344 distinct
  images.
- **Controls.** Omitting `tau`, or hard truncation, fails the analogous test
  141 and 95 times.
- The script exits 0.

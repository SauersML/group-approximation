Lane proof, not independently reviewed. Notation as in the claim. It follows the proof of
`leavitt-resolvent-ring-is-fp-simple-of-char-zero`, which is the case `k = 0`.

## 1. Tuples and the orbit of G
- Let `Π = Q[t_1..t_k, P_1..P_k, M, C_1..C_k, N]`. Each `σ_x` is a ring endomorphism of
  `Π` fixing `Q[t]`. Let `Σ` be the monoid they generate.
- A *tuple* is an assignment `τ` of elements of `Q[t]` to the registers. For `F ∈ Π`,
  `F(τ) ∈ Q[t]`. For `σ ∈ Σ` put `σ*τ = (σ(Y)(τ))_Y`. Then `σ(F)(τ) = F(σ*τ)` and
  `(σ∘σ')*τ = σ'*(σ*τ)`.
- Let `τ_0 = (P = 0, M = 1, C = 0, N = 0)` and `Reach = {σ*τ_0 : σ ∈ Σ}`. Since
  `σ_v(F) = F(τ_0)` for every `F`, we get `(σ_v ∘ σ)(F) = F(σ*τ_0)`.
- The maps `σ_x*` act on tuples by the formulas of the table. Hence
  `Reach ⊆ Z[t]^k × Mon × Z^k × Z_(>=0)`, where `Mon` is the set of monomials in `t`.
- Conversely `Reach` contains every tuple with `P_i ∈ Z[t]`, `M = 1`, `C ∈ Z^k` and
  `N >= 0`, and every tuple with `P_i ∈ Z`, `M ∈ Mon`, `C ∈ Z^k` and `N >= 0`. To build
  one, set `M` to a monomial with `r` and the `m_j`, add it to `P_i` with `p_i^±`, and
  repeat; then adjust `C` and `N` with `c_i^±` and `n`.
- **Product-set lemma.** A nonzero `F ∈ Π` is nonzero at some tuple with `P_i ∈ Z`,
  `M ∈ {t_1^j : j >= 0}`, `C_i ∈ Z` and `N ∈ Z_(>=0)`, all of which lie in `Reach`. This
  holds because a nonzero polynomial over the domain `Q[t]` cannot vanish on a product of
  infinite subsets of `Q[t]`.
- Let `T = {σ(G) : σ ∈ Σ}`. Then `σ(G)(τ_0) = G(σ*τ_0) = N' + 1 + Σ (t_i − c_i) p_i`
  with `N' >= 0`, which is nonzero at `t = c`. So `T ⊆ Π \ {0}`, and `σ_x(T) ⊆ T`.

## 2. The base ring B and ψ
- Let `S` be the multiplicative monoid generated by `T`, and `B = S^(-1) Π ⊆ Frac(Π)`.
  Each `σ_x` maps `S` into `S`, so it extends to an endomorphism of `B`.
- Put `ψ(b) = diag(σ_x(b))_x ∈ M_d(B)`. It is a unital homomorphism, and it is injective
  because `σ_n` is the restriction of the automorphism `N ↦ N + 1` of `Frac(Π)`.
- **Constants.** Let `q ∈ Z[t]` be nonzero. Pick `c ∈ Z^k` with `q(c) ≠ 0`, and write
  `q = q(c) + Σ (t_i − c_i) p_i` with `p_i ∈ Z[t]`. Let `ε` be the sign of `q(c)`. Then
  `εq = G(τ)` with `τ = (P = εp, M = 1, C = c, N = |q(c)| − 1) ∈ Reach`, so
  `εq = (σ_v ∘ σ)(G) ∈ T` for some `σ`. Hence every nonzero element of `Z[t]`, and in
  particular every positive integer, is a unit of `B`, and `F_k ⊆ B`. Every `σ_x` fixes
  `F_k` pointwise, so `ψ(f) = f·I_d` for `f ∈ F_k`.

## 3. Simplicity of O_ψ
- **ψ-minimality.** Let `I` be a nonzero ψ-saturated ideal and let `b = F/s ∈ I` be
  nonzero. Saturated ideals are stable under every `σ_x`, since `σ_x(b) = ψ(b)_(xx)`.
  By the lemma pick `τ = σ*τ_0 ∈ Reach` with `F(τ) ≠ 0`. Then
  `(σ_v ∘ σ)(b) = F(τ)/s(τ)` lies in `I`. It is a nonzero element of `F_k ⊆ B^x`: each
  factor `σ'(G)` of `s` satisfies `σ'(G)(τ) = G(σ'*τ) ≠ 0`. So `I = B`.
- **Aperiodicity.** Use §5 of `leavitt-resolvent-ring-is-fp-simple-of-char-zero-proof`
  verbatim, with `ψ_u = σ_(u_j) ∘ ... ∘ σ_(u_1)` for a word `u = u_1 ... u_j`.
  - The level comparison leaves coefficients `w_ω ∈ B`, and `ψ_u(w_ω) = 0` unless `u` is
    the length-`|u|` prefix of `ω^∞`.
  - For any word `x`, `ψ_(xv)(w_ω) = w_ω(ψ_x*τ_0)` is a constant, so it is fixed by every
    later letter.
  - Take two distinct letters `y ≠ y'`. At most one of `xvy` and `xvy'` is a prefix of
    `ω^∞`, so `w_ω(ψ_x*τ_0) = 0`. As `x` varies, `ψ_x*τ_0` runs over `Reach`, and the
    lemma gives `w_ω = 0`.
  - Negative degrees follow by the anti-automorphism `s_x <-> t_x`, which is the identity
    on `B`. It is well defined because `ψ` is diagonal and `B` is commutative.
- By `leavitt-nekrashevych-completion-simplicity-criterion` (part 3), `O_ψ` is simple.

## 4. R_k ≅ O_ψ
- **In `R_k`.**
  - By (Cov), (Z) and (L), every `F ∈ Π` satisfies `F s_x = s_x σ_x(F)`,
    `F = Σ_x s_x σ_x(F) t_x` and `t_x F = σ_x(F) t_x`. The first relation extends from
    generators to products.
  - For a word `u = x_1 ... x_r`, put `s_u = s_(x_1) ... s_(x_r)` and
    `t_u = t_(x_r) ... t_(x_1)`. Then `G s_u = s_u ψ_u(G)`, and `t_u Γ s_u` is a two-sided
    inverse of `ψ_u(G)`, since `t_u Γ s_u ψ_u(G) = t_u Γ G s_u = 1` and
    `ψ_u(G) t_u Γ s_u = t_u G Γ s_u = 1`.
  - Every `σ ∈ Σ` is some `ψ_u`, so every element of `T`, hence of `S`, is invertible in
    `R_k`. The image of `Π` is commutative. So `Π -> R_k` extends to `B -> R_k`, and the
    covariance `b = Σ s_x σ_x(b) t_x` passes to inverses. This gives `O_ψ -> R_k`.
- **Back.** `R_k -> O_ψ` fixes `s_x`, `t_x`, `t_j` and the registers, and sends `Γ` to
  `G^(-1) ∈ B`. The relations (Cov) are covariance for the registers.
- Both composites fix the generators, so `R_k ≅ O_ψ` is simple.

## 5. Nonzero, and the embeddings
- **The model.** In the model of the claim, `e_(xξ) = s_x e_ξ`, and (Cov) holds because
  `τ(xξ) = σ_x*τ(ξ)` and `τ(vξ) = τ_0`. The other relations are immediate, and
  `G(τ(ξ)) ≠ 0` since `τ(ξ) ∈ Reach`.
- **Faithful on B.** `b = F/s ∈ B` acts on `e_ξ` by `F(τ(ξ))/s(τ(ξ))`, so the model is
  faithful on `B` by the lemma. Hence `R_k ≠ 0`, `B ⊆ R_k` and `F_k ⊆ R_k`. `F_k` is
  central: each `f` commutes with `B`, and `f s_x = s_x f` and `f t_x = t_x f` by
  `ψ(f) = f I`.
- **Free algebras.** Fix letters `y ≠ y'`. For distinct words `μ` over `{y, y'}`, the
  vectors `s_μ e_(v^∞) = e_(μ v^∞)` are distinct basis vectors, and `f ∈ F_k` commutes with
  `s_μ`. So the words in `s_y, s_(y')` are `F_k`-linearly independent. The prefix code
  `x_i ↦ s_(y')^(i−1) s_y` embeds `F_k<x_1..x_m>`. ∎

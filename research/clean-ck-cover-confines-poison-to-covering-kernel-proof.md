Notation is that of the target. `rho : Gamma ->> Q` is the marked cover of
`ck-steinberg-marked-cover`, built with `g = s in S <= H`. That node gives an
embedding `iota : H -> Gamma` with `rho iota(h) = diag(h, 1, 1, 1)`.

**(a) Clean markings exist.**
1. By `clapham-fp-embedding-preserves-word-problem`, `S` embeds in a finitely
   presented group `H` with solvable word problem.
2. `H` is finitely generated with solvable word problem. By
   `decidable-groups-embed-in-decidable-simple-fa-groups` it embeds in a
   finitely generated simple group `Sigma` with solvable word problem.
3. By `clapham-fp-embedding-preserves-word-problem` again, `Sigma` embeds in a
   finitely presented group `T` with solvable word problem.
4. `Sigma` contains the infinite simple group `S`, so it is nonabelian. Being
   simple and nonabelian, it is perfect. Hence
   `H <= Sigma = [Sigma, Sigma] <= [T, T]`.

So `S <= H <= [T,T]` with `H` and `T` finitely presented and decidable. ∎(a)

**(b) Decidable image.** `T` is finitely generated, so `U` is a finitely
generated ring. `Q = EL_4(U)` is generated by the finitely many elementary
matrices over a finite generating set of `U`.
- `Q` has solvable word problem by `ck-sandwich-ring-diamond-normal-form`,
  item 3, since `T` is decidable.
- Fix a finite generating set `a_1, ..., a_m` of `Gamma`. The images
  `rho(a_i)` are fixed `4 x 4` matrices whose entries are ring words. This is
  finite data.
- Given a word `w` in the `a_i`, multiply the corresponding matrices and
  reduce every entry to Diamond normal form (item 2). Then `w in K` iff the
  result is the identity matrix.

So `K` is recursive. ∎(b)

**(c) Confinement.** Let `c in Gamma \ K`. The quotient `Gamma / K ≅ Q` has
solvable word problem by (b), and `c` survives in it. So `c` is not poisoned.
Contrapositively, every poisoned element lies in `K`.
- **`s` and `S \ {1}`.** For `1 != h in H`, `rho iota(h) = diag(h,1,1,1)`.
  `T -> U^x` is injective by item 1 of `ck-sandwich-ring-diamond-normal-form`,
  so this matrix is not the identity. Hence `iota(H) ∩ K = 1`, and no element
  of `iota(S) \ {1}`, in particular `s`, lies in `K`.
- **Poison-free.** If `Gamma` has solvable word problem, then the quotient
  `Gamma / 1` is decidable and every `c != 1` survives in it.
- **Reduction of the word problem.** Suppose triviality is decidable for words
  lying in `K`. Given `w`, first decide `w in K` by (b). If not, `w != 1`.
  If so, apply the decider. The converse is immediate. ∎(c)

**(d) Regimes.** Let `M` be maximal proper normal in `Gamma`.
- In regimes R2, R3, R4 of `ck-maximal-kernel-four-regimes` one has `K <= M`.
  Every poisoned element lies in `K` by (c), so it is trivial in `Gamma/M`.
- Hence if a poisoned element survives in `Gamma/M`, then `K` is not contained
  in `M`, which is regime R1.
- `Gamma` is a quotient of `St_4(U)` (`ck-steinberg-marked-cover`), and
  `St_n` is perfect for `n >= 3`, since `x_ij(u) = [x_ik(u), x_kj(1)]`. So
  `Gamma` is perfect. By the R1 killer of `ck-maximal-kernel-four-regimes`, if
  `K` has no nonabelian simple quotient, R1 does not occur. Then every maximal
  kernel contains `K`, and no poisoned element survives in any maximal
  quotient. ∎(d)

**Consequence paragraph.** The amalgam refutation of the universal reading
glues a group with an inseparable set, and hence unsolvable word problem, into
the input along `s`. Then `H`, and so `T` and `U`, have unsolvable word
problem. For a clean marking, (c) shows that `s` survives in the decidable
quotient `Q`, so `s` is not poisoned. This is a statement about the mechanism
and is used only as motivation for the restatement. ∎

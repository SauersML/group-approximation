title: Every automatic group has an automatic structure in which each element has exactly one representative
---

Let `G` be an automatic group (Epstein–Cannon–Holt–Levy–Paterson–Thurston, *Word
Processing in Groups*, 1992). Then `G` has an automatic structure `(A, λ, L)` with
uniqueness: the evaluation map `λ|_L : L → G` is a bijection.

This is ECHLPT Theorem 2.5.1 as cited by Engel–Wulff, and it is also stated in Rees's
survey. Citation route: `automatic-structures-with-uniqueness-citation`.

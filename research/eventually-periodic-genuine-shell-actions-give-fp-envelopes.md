Setting and notation as in `genuine-action-shell-envelopes-generalize-the-regular-shell`:
`P` is infinite and generated by a finite set `S`, and `rho: P -> Sym(N)` is an action in
which every `g != 1` has infinite support. Call `rho` **eventually `m`-periodic** if
every `g in S` satisfies `rho_g(n+m) = rho_g(n) + m` for all large `n`.

1. **Finite presentation.** If `rho` is eventually `m`-periodic, then every finite
   `S(M,M') = {e in E_rho : sing(e) ⊆ M, e fixes M' pointwise}` is finitely presented.
   Hence `E_rho` and all its finite pointwise stabilizers on `Omega` are finitely
   presented (Belk–Hyde–Matucci Theorem 2.1), and `P` embeds in a finitely presented
   simple group by item 5 of the generalization claim.
2. **Normal core.** `<tau^k>` is normal in `Q_rho` for some `k >= 1` if and only if `rho`
   is eventually periodic. Then it is central.
3. **Exactly virtually abelian.** `P` has an eventually periodic action with infinite
   supports if and only if `P` is virtually abelian.
4. **One-ended example.** For `P = Z^2` there is an eventually `4`-periodic action with
   `s^-1 rho_g s = rho_(phi(g))` near infinity, `phi(a,b) = (b,-a)`. So
   `R_rho = rho(Z^2) ⋊ <s> ≅ Z^2 ⋊_phi Z` is polycyclic and passes the ascending HNN
   gate with window `N = 0`. Every regular enumeration of the one-ended `Z^2` needs
   `N >= 1` (`one-ended-shell-inputs-admit-no-shift-normalizing-enumeration`).
5. **Twisted normalization forces periodicity.** If `s^-1 rho_g s = rho_(phi(g))` near
   infinity for all `g`, with `phi` an automorphism of finite order `k`, then `rho` is
   eventually `k`-periodic and `P` is virtually abelian. With `phi = id` it is impossible
   for infinite `P`.

## Scope

This is a positive control for the generalized shell, not progress on inputs that are not
virtually abelian (those are already linear). It shows that the one-ended
window obstruction and the virtually cyclic cap of the normal-core method are artifacts of
regular enumerations. Item 3 is also a ceiling: the normal-core method with genuine actions
reaches nothing beyond virtually abelian groups. Twisted normalization by an automorphism of
infinite order, or an injective endomorphism, is not covered by item 5 and is open.

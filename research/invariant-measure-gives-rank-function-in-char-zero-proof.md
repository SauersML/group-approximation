Full derivation in the artifact, Section 3 (unreviewed). Self-contained given standard von Neumann
algebra theory.

**The trace.** Define `τ : A_ℂ(𝒢) → ℂ` by `τ(f) = ∫_X f|_X dμ`.

*Traciality.* It suffices to check `τ(1_B 1_C) = τ(1_C 1_B)` on compact open bisections. The set
`BC ∩ X = {bc : b ∈ B, c ∈ C, bc ∈ X}` is carried bijectively by the range map onto `r(B ∩ C^{-1})`,
and symmetrically `CB ∩ X` onto `r(C ∩ B^{-1}) = s(B ∩ C^{-1})`. So the two values are
`μ(r(B ∩ C^{-1}))` and `μ(s(B ∩ C^{-1}))`, equal because `μ` is invariant and `B ∩ C^{-1}` is a
compact open bisection.

*Faithfulness.* Write `f = Σ_i c_i 1_{B_i}` with the `B_i` pairwise disjoint compact open bisections.
Then `f^*f = Σ_{i,j} c̄_i c_j 1_{B_i^{-1}B_j}`, and `B_i^{-1}B_j` meets `X` only if `B_i` meets `B_j`,
that is only if `i = j`. So `τ(f^*f) = Σ_i |c_i|² μ(s(B_i))`. Minimality makes `μ` of full support,
since finitely many translates of any nonempty compact open cover the compact `X`. Hence
`τ(f^*f) > 0` whenever `f ≠ 0`.

**The von Neumann algebra.** On the GNS space `L²(A_ℂ(𝒢), τ)` each `1_B` acts boundedly, because
`τ((1_B x)^*(1_B x)) = τ(x^* 1_{s(B)} x) ≤ τ(x^* x)`, and a general element is a finite linear
combination. Let `M` be the von Neumann algebra generated by the left action. `τ` extends to a
faithful normal tracial state on `M`, so `M` is finite.

**The rank function.** For `A ∈ M_n(A_ℂ(𝒢)) ⊆ M_n(M)` set `rk(A) = (τ ⊗ Tr_n)(LP(A))`, where `LP(A)`
is the left support projection. This is the Murray–von Neumann dimension of a finite von Neumann
algebra; it satisfies the Sylvester matrix rank axioms, `rk(1) = τ(1) = μ(X) = 1`, and it is faithful
because `τ` is faithful on `M`. Restricting along `A_k(𝒢) ⊆ A_ℂ(𝒢)` for a countable subfield
`k ⊆ ℂ` preserves the axioms and faithfulness, and `rk(1_U) = τ(1_U) = μ(U)`. Stable finiteness then
follows from `algebraic-tarski-for-steinberg-algebras` step 1.

**Coverage of characteristic zero.** A countable field of characteristic zero has transcendence degree
at most `ℵ_0` over `ℚ` and so embeds in `ℂ`.

Standard input used and not re-derived here: that the Murray–von Neumann dimension of a finite von
Neumann algebra satisfies the Sylvester matrix rank axioms.

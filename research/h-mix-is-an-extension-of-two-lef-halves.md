## Setting

- `F = F_2`, `J = F<S,T | TS = 1>`, `Q = 1 - ST`, `I = (Q)`, and
  `A = J/I = F[z, z^-1]` with `S -> z`, `T -> z^-1`.
- `F[S]` is the commutative subring generated by `S`; it is a polynomial ring.
- `L = EL_2(J)`. Double-parabolic elements are `(g, X, B)`, with
  conjugation `X -> g X B^-1`, as in `jacobson-t-oriented-double-parabolic-is-lef`.
- `D = <r_a, r_b>` with `r_a = x_34(1)` and `r_b = x_43(S)`.
- `H_mix = M_2(J) x| (L x D)`.
- `P^S = M_2(J) x| (L x EL_2(F[S]))`, which contains `H_mix`.
- The head is `h = x_13(Q)`.
- `Rad_MF(G)` is the intersection of the kernels of all homomorphisms from `G`
  to unitary groups of `prod M_k / sum M_k`.
- `I_{<=d} = span{S^a Q T^b : a >= 0, b <= d}`.

## Statement

**(A) Dihedral splitting.** `D` is infinite dihedral. `c = r_a r_b` is
`[[1+S, 1], [S, 1]]`, which lies in `SL_2(F[S])`, has trace `S`, and has
infinite order. Put `N = M_2(J) x| L`. Then:
- `H_mix = N x| D`;
- `H' = M_2(J) x| (L x <c>)` has index 2 in `H_mix`;
- `h` lies in `Rad_MF(H_mix)` if and only if it lies in `Rad_MF(H')`;
- `H_mix` is MF if and only if `H'` is MF.

**(B) Finitary half is LEF.** `K = M_2(I) x| (L x EL_2(F[S]))` is LEF. It
contains `h` and `M_2(I) x| (L x D)`.

**(C) Symbol half is LEF.** `Gbar = M_2(A) x| (L x EL_2(F[S]))` is LEF. Here
`L` acts through `EL_2(J) -> EL_2(A)` and `F[S]` acts through `S -> z`.

**(D) Not LEF.** `H_mix`, and hence `P^S`, is not LEF: the five-generator
witness of `p22-double-parabolic-is-not-lef` lies in `H_mix`. So `P^S` and
`H_mix` sit in extensions

```text
1 -> M_2(I) -> P^S -> Gbar -> 1,
```

in which the kernel with its full conjugation action (`K`) is LEF and the
quotient is LEF, while the extension is not LEF.

**(E) Window rigidity.** Let `M` be a right `J`-module, and let `W` be a
finite-dimensional `F`-subspace of the row module `M^2` with `W c` contained
in `W`. Then `W` lies in `(M[delta])^2`, where `M[delta]` is the kernel of
right multiplication by some nonzero `delta` in `F[S]`. As a result:
- For `M = A`, `W = 0`.
- For `M = J`, `W` lies in `I_{<k}^2`, where `k` is the `S`-adic order of
  `delta`.
- The union of all finite-dimensional `c`-stable subspaces of `J^2` is `I^2`.
  The same holds for `D` and for `EL_2(F[S])`, since `I_{<=d}^2` is stable
  under all of `EL_2(F[S])`.

So `M_2(I)` is intrinsic to `(M_2(J), <c>)`: it is the largest submodule that
is locally finite under the right action.

## Consequence for the hole

Take any T-free argument putting `h` into `Rad_MF` of a subgroup `G` of
`EL_5(J)`. Suppose it uses only relations that hold in `K`, or it passes to
the symbol quotient. Then it fails, because `K` is LEF with `h != 1` and
`h` dies in `Gbar`. For `G` inside `P^S`, the argument must therefore use
the extension class of `M_2(J)` over `M_2(I)` as an `L x EL_2(F[S])`
bimodule.

By (E), no model built from finite-dimensional right-invariant row windows
can see that class: those windows lie in `M_2(I)`. This is dual to the
T-oriented evaluation windows. The pigeonhole witness exploits exactly the
infinite orbit of `(1,0)`.

The open question is now sharper. `H'` is an extension by `Z` of the LEF
group `N`. Is `H'` MF, and does `h` survive there? The answer is equivalent to
the spark on `H_mix`, and it is no longer tied to `D` being dihedral.

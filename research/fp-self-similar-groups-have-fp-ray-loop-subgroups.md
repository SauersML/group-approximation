**ESTABLISHED (unreviewed).** Proof: `fp-self-similar-groups-have-fp-ray-loop-subgroups-proof`.
The proof is short and self-contained. The script checks the cocycle formula on the
instance `R''` of `m11-odometer-free-host-is-not-finitely-presented`.

**Setting.** `X` is a finite alphabet containing the letter `1`, and `ξ = 1^∞`. Let
`Ω = X*·1^∞` be the countable set of ends cofinal with `ξ`. Let `G ≤ Aut(X*)` be
self-similar (closed under sections) and generated by a finite set `S`. Write `p_m(η)`
for the length-`m` prefix of an end `η`. Assume:

- **(Ω)** `s(Ω) = Ω` for every `s ∈ S`;
- **(E)** for every `s ∈ S` and `η ∈ Ω`, the sections `s|_{p_m(η)}` are eventually
  constant in `m`, with eventual value `c(s, η) ∈ G`;
- **(F)** the set `C = {c(s, η) : s ∈ S, η ∈ Ω} ∖ {1}` is finite. This holds when every
  `s ∈ S` is finite-state.

The **ray-loop subgroup** is `H_ξ = ⟨C⟩ ≤ G`.

**Theorem.**

1. Every `t ∈ C` fixes the letter `1` and satisfies `t|_1 = t`. Hence `t` fixes `ξ` and
   `h|_{1^m} = h` for every `h ∈ H_ξ` and every `m`.
2. **(Loop obstruction.)** If `G` is finitely presented, then `H_ξ` is finitely presented.
3. The same holds for every periodic ray `(x_1 ⋯ x_p)^∞`, applied to the action of `G` on
   the tree `(X^p)*`.

**Mechanism.** Given any group `Γ̃` with a map `F(C) → Γ̃`, the permutation group
`Ĝ(Γ̃)` generated by the lifts `ŝ` of `s ∈ S` acts on `X* ⊔ (Ω × Γ̃)` by
`(η, γ)^ŝ = (η^s, γ·c̃(s, η))`. It maps onto `G`, and for a word `w` its fibre
coordinate at `η` is the **stable section word** `W_η(w) ∈ F(C)`. When `w` is a
relator of `G`, `W_η(w)` is a relator of `H_ξ`. For a word `W` over `C` itself,
`W_ξ(W) = W`. If `G = ⟨S | r_1, …, r_k⟩`, take `Γ̃ = F(C)/⟨⟨W_η(r_i)⟩⟩`. There are only
finitely many such words. Then `Ĝ(Γ̃)` satisfies every `r_i`, so it is isomorphic to `G`,
and every relator of `H_ξ` already dies in `Γ̃`.

**What it kills.** Take a non-contracting candidate for the Tits route of
`boone-higman-conjecture` that gets infinite order from loop states along a ray. Its
finite presentation needs the loop subgroup at every periodic ray to be finitely
presented. In particular the loop subgroup must not contain a finite-index copy of a
contracting regular branch group. That is exactly how `R'' = ⟨M_11, b, c⟩` dies in
`m11-odometer-free-host-is-not-finitely-presented`. No homological invariant of `G` is
involved: the obstruction lives in the relations of the loop subgroup.

**Calibration.**

- *Contracting groups.* By item 1, every `h ∈ H_ξ` equals its own section at `1^m` for
  all `m`, so `H_ξ` lies in the nucleus and is finite. The theorem is therefore vacuous for
  contracting groups, as it must be: their non-finite presentation (Bartholdi) has a
  different cause.
- *Grigorchuk group* on the ray `2^∞`, regrouped as `(X^3)*`. The loop group is
  `⟨b, c, d⟩ ≅ (Z/2)^2`, which is finitely presented, so there is no obstruction.
- *Lamplighter* `a = (a, b)σ`, `b = (a, b)`. On `1^∞` the loop group is `⟨b⟩ ≅ Z`, which is
  finitely presented, so there is no obstruction. The lamplighter is not finitely presented
  for other reasons, and the theorem only gives a necessary condition.
- *Adding machine* `a = (1, a)σ`. It maps `1^∞` to `0^∞ ∉ Ω`, so (Ω) fails. This is the
  role of (Ω): an odometer carries the ray out of its cofinality class.

Notation as in the target. Modules are left modules, elements of free modules are row vectors,
and a matrix acts by right multiplication. For a ring map `Z[K] → S`, `S ⊗ −` means
`S ⊗_{Z[K]} −`.

## 0. Recalled facts

- **(R1)** `dim_U` is additive on short exact sequences of `U`-modules, and the `dim_U` of a
  directed union of submodules is the supremum of their dimensions (Lück, *L²-invariants*,
  Thm. 6.7). For a matrix `A ∈ M_{k×m}(Q[K])`, `rk_U(A) = dim_U im(r_A : U^k → U^m)`.
- **(R2)** *Lück approximation.* If `K` is residually finite, `(N_i)` is a residual chain and
  `A ∈ M_{k×m}(Q[K])`, then `rk_{F_i}(A) → rk_U(A)` (Lück 1994; stated there for `Z[K]`; for
  `Q[K]` clear denominators).
- **(R3)** *Bass (1963), "Big projective modules are free".* If `F` is a finite group, every
  projective `Z[F]`-module that is not finitely generated is free.
- **(R4)** *Swan (1960).* If `F` is finite and `Q` is a finitely generated projective
  `Z[F]`-module, then `Q ⊗_Z Q` is a free `Q[F]`-module.
- **(R5)** If `K` is infinite, `dim_U(U ⊗ Z) = 0`. If `K` is infinite and amenable, then
  `dim_U H_k(K; U) = 0` for all `k` (Cheeger–Gromov; Lück, Thm. 6.37).
- **(R6)** *Kropholler–Linnell–Lück.* A finitely generated elementary amenable group of cd 2 is
  `BS(1,m)` for some `m ≠ 0`.
- **(R7)** For a finitely generated `K` with `cd_Z K <= 2` and an `n`-generator presentation,
  `0 → P → Z[K]^n →∂_1 Z[K] → Z → 0` (with `e_j ↦ x_j − 1`) is a projective resolution, and `P`
  is countably generated. `P` is generated by the Fox rows of the relators.

## 1. Truncation formulas

Let `C = Z[K]^(ℕ) E` with `E² = E` row-finite. For a ring map `Z[K] → S`, `S ⊗ C` is the direct
summand `S^(ℕ) Ē` of `S^(ℕ)`, where `Ē` is the image of `E`. It is the directed union over `m`
of `im(r_{Ā_m} : S^m → S^(ℕ))`. Since the rows of `A_m` are finitely supported, `Ā_m` has only
finitely many nonzero columns, so each of these images is the image of a finite matrix. Hence, by
(R1) and the analogous facts for `Q`-vector spaces,

> `d(C) = sup_m rk_U(A_m)`, `r(C) = sup_m rank_Q ε(A_m)`,
> `dim_F(Q[F] ⊗ C) = sup_m rk_F(A_m)` for every finite quotient `F`. **(T)**

## 2. Item 1

Let `F = K/N` be finite and put `P_F = Z[F] ⊗ C`. It is a projective `Z[F]`-module, and
`Q ⊗_{Z[F]} P_F = Q ⊗ C` has rank `r = r(C) < ∞`. If `P_F` were not finitely generated, by
(R3) it would be free of infinite rank, and then `Q ⊗_{Z[F]} P_F` would have infinite rank. So
`P_F` is finitely generated, and by (R4) `Q ⊗_Z P_F ≅ Q[F]^k` for some `k`. Applying
`Q ⊗_{Q[F]} −` gives `Q^k ≅ Q ⊗ C`, so `k = r`. Finally `Q ⊗_Z P_F = Q[F] ⊗ C`.

For a finite-index subgroup `H`, let `N` be its normal core and `F = K/N`. Since
`Q ⊗_{Z[N]} Z[K] = Q[F]` as right `Z[K]`-modules,
`Q ⊗_{Z[H]} C = Q ⊗_{Q[H/N]} (Q[F] ⊗ C) ≅ Q ⊗_{Q[H/N]} Q[F]^r`. As a `Q[H/N]`-module,
`Q[F]` is free of rank `[K:H]`. So `rank_Q(Q ⊗_{Z[H]} C) = [K:H] r`. No property of `K` was
used. ∎

## 3. Item 2

*(a) and (b).* By item 1, `dim_{F_i}(Q[F_i] ⊗ C) = r` for every `i`. By (T),
`rk_{F_i}(A_m) <= r` for all `i, m`, and `sup_m rk_{F_i}(A_m) = r` for every `i`. By (R2),
`rk_U(A_m) = lim_i rk_{F_i}(A_m) <= r`. By (T),

> `d(C) = sup_m lim_i rk_{F_i}(A_m) <= r = lim_i sup_m rk_{F_i}(A_m)`,

which is (a) and the interchange formula (b).

*(c).* By (a), `D(C) <= 0` iff `D(C) = 0`. Since `dim_{F_i}(Q[F_i] ⊗ C) = r` for all `i`, Lück
approximation for `C` says `r = d(C)`, i.e. `D(C) = 0`.

Uniform generation. Let `M ≤ C` be generated by `c_1, …, c_k`. Let `B` be the matrix with rows
`c_j`; it has finitely many nonzero columns. The map `Q[F] ⊗ M → Q[F] ⊗ C ⊆ Q[F]^(ℕ)` sends
`e_j ↦ c̄_j`, so its image is `im(r_{B̄})`, of normalized dimension `rk_F(B)`. By (R2) the limit
over `i` is `rk_U(B) = dim_U im(r_B : U^k → U^(ℕ))`. Since `c_j = c_j E`, that image lies in
`U^(ℕ) E = U ⊗ C`, so `rk_U(B) <= d(C)`. Hence uniform generation gives `d(C) >= r − δ` for all
`δ`, i.e. `D(C) = 0`. Conversely, if `D(C) = 0`, then for `δ > 0` choose `m` with
`rk_U(A_m) >= r − δ` (by (T)) and take `M` generated by the rows of `A_m`, i.e. by the elements
`e_j E ∈ C` for `j <= m`. Then `B = A_m`. ∎

## 4. Item 3

Take the resolution (R7) for an `n`-generator presentation. Apply `Q ⊗ −`. The map
`Q ⊗ ∂_1 : Q^n → Q` is zero, since `x_j − 1 ↦ 0`. So the complex
`Q ⊗ P → Q^n → Q` (degrees 2, 1, 0) has `H_0 = Q`,
`H_1 = Q^n / im(Q ⊗ P) = H_1(K; Q)` and `H_2 = ker(Q ⊗ P → Q^n) = H_2(K; Q)`. Hence

> `r(P) = b_2(K) + (n − b_1(K)) = n − b_1 + b_2`, which is finite when `b_2 < ∞`.

Let `H` have index `m`. As `Z[H]`-modules, `Z[K] ≅ Z[H]^m`, so restricting (R7) gives a
projective resolution `0 → res_H P → Z[H]^{nm} → Z[H]^m → Z → 0` of `Z` over `Z[H]`. By item 1,
`rank_Q(Q ⊗_{Z[H]} res_H P) = m r(P) < ∞`. So `Q ⊗_{Z[H]}` of the resolution is a complex of
finite-dimensional `Q`-spaces of dimensions `m r(P), nm, m` in degrees 2, 1, 0. Its homology is
`H_*(H; Q)`. Hence `b_2(H) < ∞`, and taking Euler characteristics,

> `χ_Q(H) = m r(P) − nm + m = m (r(P) − n + 1) = m (1 − b_1 + b_2) = m χ_Q(K)`.

For the defect, `U(K) ≅ U(H) ⊗_{Z[H]} Z[K]` as `(U(H), Z[K])`-bimodules (`[K:H] < ∞`; Lück §6.2).
So `U(H) ⊗_{Z[H]} res_H P ≅ res_{U(H)} (U(K) ⊗ P)`, and `dim_{U(H)} res = m dim_{U(K)}` (Lück,
Thm. 6.29). So `d(res_H P) = m d(P)`. With `r(res_H P) = m r(P)` from item 1, this gives
`D(res_H P) = m D(P)` whenever `d(P) < ∞`.

If `b_1(K) = 0`, then `χ_Q(K) = 1 + b_2(K)`, and `1 − b_1(H) + b_2(H) = m (1 + b_2(K))` gives
`b_2(H) = m(1 + b_2(K)) − 1 + b_1(H) >= m − 1`. ∎

*Remark.* Finite presentability is not used. The only input beyond the resolution is item 1,
i.e. Bass + Swan on the finite quotient `K/core(H)`. This replaces the NFS hypothesis of item 3(c)
of `amenable-cd-two-bass-defect-equals-euler-characteristic` for the multiplicativity of `χ_Q`.

## 5. Item 4

Let `m_i = [K:N_i]` and `F_i = K/N_i`. Order the relators `ρ_1, ρ_2, …`, and let `J_s` be the
`s × n` Fox matrix of `ρ_1, …, ρ_s`. Its rows lie in `P`, and they generate `P` as `s → ∞`
(R7).

*`b_1(N_i)/m_i → 0`.* Apply `Q[F_i] ⊗ −` to (R7). The homology of the result is `H_*(N_i; Q)`.
The image of `Q[F_i] ⊗ ∂_1` is the augmentation ideal of `Q[F_i]`, of dimension `m_i − 1`. So
`dim_Q ker(Q[F_i] ⊗ ∂_1) = n m_i − m_i + 1`. The image of `Q[F_i] ⊗ P` in `Q[F_i]^n` contains
the row space of `J̄_s`, of dimension `m_i rk_{F_i}(J_s)`. Hence

> `b_1(N_i)/m_i <= n − 1 + 1/m_i − rk_{F_i}(J_s)` for every `s`, so
> `limsup_i b_1(N_i)/m_i <= n − 1 − rk_U(J_s)` by (R2).

Now apply `U ⊗ −`. Its homology is `H_*(K; U)`, which has dimension 0 in every degree (R5; `K` is
infinite amenable). So the image of `U ⊗ ∂_1` has dimension `1`, `ker(U ⊗ ∂_1)` has dimension
`n − 1`, and `im(U ⊗ P → U^n)` has dimension `n − 1` (R1). That image is the directed union over
`s` of the row spaces of `J_s` over `U`. By (R1), `sup_s rk_U(J_s) = n − 1`. Letting `s → ∞`
gives `limsup_i b_1(N_i)/m_i <= 0`.

*`b_2`.* By item 3, `1 − b_1(N_i) + b_2(N_i) = m_i χ_Q(K)`. Hence
`b_2(N_i)/m_i = χ_Q(K) − 1/m_i + b_1(N_i)/m_i → χ_Q(K)`. Also `b_2^{(2)}(K) = 0` by (R5).

*`D(P) = χ_Q(K)`.* From the `U`-complex, `ker(U ⊗ P → U^n) = H_2(K; U)` has dimension 0. So
`d(P) = 0 + (n − 1) = n − 1`. With `r(P) = n − b_1 + b_2` (§4), `D(P) = 1 − b_1 + b_2 = χ_Q(K)`.
This recovers item 1 of `amenable-cd-two-bass-defect-equals-euler-characteristic` in this setting.

*`D(P) >= 0`.* This is item 2(a); alternatively it holds because `b_2(N_i) >= 0`. So
`b_1 <= 1 + b_2`. ∎

*Remark.* Residual finiteness enters only through (R2), applied to the finite matrices `J_s`. The
degree-1 limit exists because `P` needs only finitely many generators to fill `ker ∂_1` up to
`L²`-dimension `δ`. The degree-2 limit is exactly where finitely many rows no longer suffice. This
is the interchange of limits in item 2(b).

## 6. Item 5

Throughout, `K` has `cd_Z K <= 2`, so it is torsion-free.

*(a) ⇒ (b), along every residual chain.* Let `K` be finitely generated, residually finite,
amenable, of cd 2. By (a) it is elementary amenable, so by (R6) `K ≅ BS(1,m)`. Each `N_i` has
finite index, so it is finitely generated and elementary amenable, and `cd N_i = cd K = 2`
(Serre: a torsion-free group and its finite-index subgroups have equal cd). By (R6),
`N_i ≅ BS(1, m')` for some `m'`. A one-relator group has `b_2 <= 1`, so `b_2(N_i)/[K:N_i] → 0`.

*(b) along some chain ⇒ (a).* Suppose (a) fails. Let `G` be residually finite, amenable, of
`cd_Z <= 2` and not elementary amenable, hence not solvable. By item 3(i) of
`amenable-cd-two-kropholler-iff-locally-indicable`, `G` contains a finitely generated subgroup `K`
that is amenable, of `cd <= 2`, not solvable and with `H_1(K; Z)` finite. `K` is residually
finite as a subgroup of `G`. It has `cd = 2`, since groups of cd `<= 1` are free and the amenable
ones are `1` or `Z`. Also `b_1(K) = 0`. Fix any residual chain `(N_i)` of `K`.

- If `b_2(K) = ∞`: the transfer `tr: H_2(K; Q) → H_2(N_i; Q)` satisfies `cor ∘ tr = [K:N_i]`, so
  `cor` is onto and `b_2(N_i) >= b_2(K) = ∞`. So (b) fails.
- If `b_2(K) < ∞`: by item 3, `b_2(N_i) >= [K:N_i] − 1`. So (b) fails.

In both cases (b) fails for every residual chain of `K`.

*(b) ⇔ (c), group by group.* Let `K` be finitely generated, residually finite, amenable, of cd 2,
and let `P` be the relation module of a finite generating set. By §5, `d(P) = n − 1 < ∞`, so `P`
lies in the scope of the target.

- If `b_2(K) = ∞`, then `r(P) = ∞` (§4), so WBB fails for `P`. And (b) fails for `K`, by the
  transfer argument.
- If `b_2(K) < ∞`, then by item 4 `D(P) = χ_Q(K) = lim_i b_2(N_i)/[K:N_i]` for every residual
  chain. So `D(P) <= 0` iff `b_2(N_i) = o([K:N_i])`.

The addendum follows from item 3 and item 4 with `b_1 = 0`: the slope is `χ_Q(K) = 1 + b_2(K)`,
and `b_2^{(2)}(K) = 0` by (R5). ∎

## 7. Item 6

Let `U_Γ = U(Γ)`, viewed as a `(U_Γ, Z[K])`-bimodule through `K → Γ`. Then
`U_Γ ⊗ C = U_Γ ⊗_{Z[Γ]} (Z[Γ] ⊗ C)` and `Q ⊗ C = Q ⊗_{Z[Γ]} (Z[Γ] ⊗ C)`. So
`r(P_Γ) = r(P) = n − b_1 + b_2` (§4). Apply `U_Γ ⊗ −` to (R7). The complex
`U_Γ ⊗ P → U_Γ^n → U_Γ` has homology `H_k(K; U_Γ)`, of dimension `β_k`, with `β_0, β_1 <= n`
and `β_2 < ∞` by assumption. So `dim im(U_Γ ⊗ ∂_1) = 1 − β_0`,
`dim ker(U_Γ ⊗ ∂_1) = n − 1 + β_0`, `dim im(U_Γ ⊗ P → U_Γ^n) = n − 1 + β_0 − β_1`, and

> `d_Γ(P_Γ) = β_2 + n − 1 + β_0 − β_1 = n − 1 + χ^{(2)}(K; Γ)`.

Hence `D_Γ(P_Γ) = (n − b_1 + b_2) − (n − 1 + χ^{(2)}) = χ_Q(K) − χ^{(2)}(K; Γ)`. If `K` is
amenable (and infinite), §5 gives `d_K(P) = n − 1` and `D_K(P) = χ_Q(K)`, so
`D_K(P) = D_Γ(P_Γ) + χ^{(2)}(K; Γ)`.

*(a).* For `C = P`, the L²-Swan inequality `rank_Q(Q ⊗ P) <= dim_{U_Γ}(U_Γ ⊗ P)` is
`r(P_Γ) <= d_Γ(P_Γ)`, i.e. `D_Γ(P_Γ) <= 0`. This is WBB for the projective `Z[Γ]`-module `P_Γ`,
and by the formula it is equivalent to `χ^{(2)}(K; Γ) >= χ_Q(K)`. For finite `Γ`, item 1 gives
`Q[Γ] ⊗ P ≅ Q[Γ]^r`, so `D_Γ = 0`. For `Γ = K` it is the target inequality for `P`.

*(b).* The lifting inequality `d_Γ(P_Γ) <= d_K(P)` reads `n − 1 + χ^{(2)}(K; Γ) <= n − 1`. If
both L²-Swan and lifting hold, then `r(P) <= d_Γ(P_Γ) <= d_K(P)`, i.e. `D_K(P) <= 0`. In an
amenable counterexample `D_K(P) = χ_Q(K) >= 1` (an integer `> 0`), so for each infinite `Γ` at
least one of the two fails. Hence no argument that proves L²-Swan and then lifts can reach the
target unless it proves `χ^{(2)}(K; Γ) <= 0` for some `Γ`. That is an `L²`-vanishing statement
for the intermediate cover `K/N`, the analogue of the degree-2 approximation in item 5(b).

*(c).* Take `K = Z² = ⟨x, y⟩`, `N = ⟨x⟩`, `Γ = ⟨ȳ⟩ ≅ Z`, and `M = Z[K]/Z[K](x − 1)`. It is
finitely presented, of projective dimension 1. `U(Z²)` is the ring of measurable functions on
`T²` (up to null sets). `x − 1` vanishes only on a null set, so it is invertible there, and
`U(K) ⊗ M = U(K)/U(K)(x − 1) = 0`. On the other hand `x ↦ 1` in `Γ`, so
`U_Γ ⊗ M = U_Γ` has dimension 1. So `dim_{U_Γ} = 1 > 0 = dim_{U(K)}`. The lifting inequality
therefore fails for finitely presented modules, and any proof of it for projectives must use
projectivity.

*(d).* If `b_1(K) = 0`, then `H_1(K; Z)` is finite (`K` is finitely generated). `H_1(Γ; Z)` is a
quotient of it, so it is finite too. If `Γ` is locally indicable and nontrivial, then `Γ` itself,
being finitely generated, surjects onto `Z`, which is impossible. So `Γ = 1`. The groups for which
`flat-weak-bass-holds-exactly-for-locally-indicable-groups` gives WBB are the virtually locally
indicable ones. Among the quotients `Γ` of such a `K` they are the virtually locally indicable
groups with finite abelianization, and the locally indicable ones are only `Γ = 1`. ∎

## 8. Calibrations

*Flat colimit over `Z`.* Let `K = ⟨t⟩` and `M = colim(Z[K] →·(t−1) Z[K] →·(t−1) ⋯)`. This is a
directed colimit of free modules, hence flat. Then `Q ⊗ M = colim(Q →0 Q →0 ⋯) = 0`. In `U(Z)`,
the measurable functions on `S¹`, `t − 1` is invertible, so `U ⊗ M = colim(U →≅ U →≅ ⋯) ≅ U`.
So `D(M) = 0 − 1 = −1 < 0`, which item 2(a) forbids for projectives. `M` is not projective: it is
`Z[t^{±1}, (t−1)^{-1}]`.

*Finitely generated `C`.* If `C = Z[K]^k E` with `E` a `k × k` idempotent, embed it with zero
rows. Then `A_m = E` for `m >= k`. Both sides of item 2(b) are `lim_i rk_{F_i}(E)`, and
`D(C) = 0`.

*`BS(1,m)`, `Z²`.* The presentation complex of `⟨a, t | t a t^{-1} = a^m⟩` is aspherical, so
`χ_Q = 1 − 2 + 1 = 0`. For `m ≠ 1`, `b_1 = 1` and `b_2 = 0`. For `m = 1` (`Z²`), `b_1 = 2` and
`b_2 = 1`. Item 3 gives `χ_Q(N) = 0` for every finite-index `N`, and item 4 gives `D(P) = 0`,
consistent with Kropholler's theorem for these groups.

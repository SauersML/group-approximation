Notation as in the claim. `𝒢` is Hausdorff, ample and principal, and
`X = 𝒢^(0)` is compact. `A = A_F(𝒢)` consists of the locally constant,
compactly supported `a : 𝒢 → F`, with convolution
`(ab)(γ) = Σ_(αβ=γ) a(α) b(β)`. So `supp(ab) ⊆ supp(a)·supp(b)`.

1. **The orbit module.** Put `V = F^(X)`, with basis `e_x`, and
   `a·e_x = Σ_(s(γ)=x) a(γ) e_(r(γ))`, a finite sum. Associativity is the
   convolution identity:
   `a·(b·e_x) = Σ_(s(β)=x) Σ_(s(α)=r(β)) a(α) b(β) e_(r(αβ)) = (ab)·e_x`.
2. **Annihilation is fibrewise.** Since `𝒢` is principal, `r` is injective on
   `s^(-1)(x)`. So `a·e_x = 0` iff `a` vanishes on `s^(-1)(x)`.
3. **Faithfulness.** If `a ≠ 0`, pick `γ` with `a(γ) ≠ 0` and set `x = s(γ)`.
   The coefficient of `e_(r(γ))` in `a·e_x` is `a(γ) ≠ 0`, by 2.
4. **Annihilator sets are clopen.** `U_a := { x : a·e_x = 0 } = X \ s(supp a)`
   by 2. The support `supp a` is compact open and `s` is an open map, so
   `s(supp a)` is open, and compact, hence closed in the Hausdorff space `X`.
5. **Monotonicity.** If `c = b a` with `b ∈ A`, then `U_a ⊆ U_c`.
6. **Orbit point (claim part 1).** Suppose, for a contradiction, that every
   `x ∈ X` has some `0 ≠ c_x ∈ C` with `c_x·e_x = 0`.
   - Then `x ∈ U_(c_x)`, and the `U_(c_x)` are open by 4. Since `X` is compact,
     finitely many of them, `U_(c_1), ..., U_(c_m)`, cover `X`.
   - Put `d_1 = c_1`. Given `d_j ≠ 0` in `C c_1 ∩ ... ∩ C c_j`, the left Ore
     condition gives `0 ≠ d_(j+1) ∈ C d_j ∩ C c_(j+1)`. Since
     `C d_j ⊆ C C c_i ⊆ C c_i`, this lies in `C c_1 ∩ ... ∩ C c_(j+1)`. No unit
     is used. For a commutative domain one may simply take `d = c_1 ··· c_m`.
   - So `0 ≠ d = d_m ∈ ∩_i C c_i`. By 5, `U_d ⊇ ∪_i U_(c_i) = X`, so `d`
     kills every `e_x`, and `d = 0` by 3. Contradiction.
   - Hence some `x` has `Ann_C(e_x) = 0`, and `c ↦ c·e_x` is an injective
     `F`-linear map on `C`.
7. **Counting (claim part 2).** Let `T` generate `C`, with supports in the
   compact open `K`.
   - A product of `j ≤ n` elements of `T` has support in `K^j`. If `X ⊆ K`
     (which holds when `1_A ∈ T`), then `K^j ⊆ K^n`. In general,
     `C_(≤n) · e_x ⊆ span{ e_(r(γ)) : γ ∈ K^1 ∪ ... ∪ K^n, s(γ) = x }`. Enlarge
     `K` by `X` (still compact open) to get `K^n` alone.
   - `K` is a finite union of compact open bisections, each meeting `s^(-1)(x)`
     at most once, so the count is finite.
   - By 6 the map `C_(≤n) → C_(≤n)·e_x` is injective, and
     `dim C_(≤n) ≤ |K^n ∩ s^(-1)(x)|`.
   - (The claim states `K^n` with `K` taken to contain `X`; this costs nothing.)
8. **Free actions (claim part 3).** Let `𝒢 = X ⋊ G = {(gx, g, x)}`. It is
   principal iff the action is free.
   - Supports of finitely many elements lie in `K = X × S` for a finite
     symmetric `S ∋ e`. Then `K^n ∩ s^(-1)(x) = {(hx, h, x) : h ∈ S^n}`, which
     has `|S^n|` elements. So `dim C_(≤n) ≤ |S^n|`, and `growth(C) ≼ growth(G)`.
   - If `|S^n| ≤ M n^d`, then `GKdim C ≤ d`.
   - For matrices, `M_k(A_F(𝒢)) ≅ A_F(𝒢 × T_k)`, where `T_k` is the pair
     groupoid on `k` points. This groupoid is principal and ample with compact
     unit space `X × [k]`, and its fibre count is `k·|S^n|`.
   - Corners `pAp` are subalgebras, so they are covered by 6 and 7 directly.
9. **Tensor coefficients (claim part 4).** Let `R` be a unital `F`-algebra.
   - `A ⊗_F R ≅ A_R(𝒢)`, the locally constant compactly supported
     `R`-valued functions with the same convolution. Products of values are
     taken in order, so `R` need not be commutative.
   - It acts on `V ⊗ R` by `z·(e_x ⊗ 1) = Σ_(s(γ)=x) e_(r(γ)) ⊗ z(γ)`.
     Items 1–6 go through word for word with values in `R`: annihilation is
     fibrewise, the module is faithful, and `U_z = X \ s(supp z)` is clopen. So
     some `x` makes `c ↦ c·(e_x ⊗ 1)` injective on the Ore domain
     `C ⊆ A ⊗ R`.
   - The generators take finitely many values, which form a finite set
     `Φ ∋ 1` in `R`. A product of at most `n` generators takes values in
     `R'_(≤n)`, the span of the products of at most `n` elements of `Φ`.
   - So `C_(≤n)·(e_x ⊗ 1) ⊆ span{e_(r(γ)) : γ ∈ K^n ∩ s^(-1)(x)} ⊗ R'_(≤n)`,
     and `dim C_(≤n) ≤ |K^n ∩ s^(-1)(x)| · dim R'_(≤n)`.
   - Taking `limsup log(·)/log n` gives `GKdim C ≤ d + GKdim R'` for a free
     action of a group of polynomial growth degree `d`.
10. **Domains of finite GK dimension are left Ore.** Let `D` be a unital domain
    whose finitely generated subalgebras all have finite GKdim. Take
    `a, b ≠ 0` in `D`, let `R` be the subalgebra generated by `1, a, b`, and
    let `W = span{1, a, b}`.
    - Suppose `Ra ∩ Rb = 0`. Then `Σ_i R b a^i` is direct. Take a relation
      `Σ_(i=0)^m r_i b a^i = 0` with the fewest nonzero terms, and cancel
      powers of `a` on the right (as `D` is a domain) so that `r_0 ≠ 0`. Then
      `r_0 b = -(Σ_(i≥1) r_i b a^(i-1)) a ∈ Rb ∩ Ra = 0`, so `r_0 = 0`, which
      is absurd.
    - Right multiplication by `b a^i` is injective and maps `W^n` into
      `W^(2n+1)` for `i ≤ n`. So `dim W^(2n+1) ≥ (n+1) dim W^n`.
    - With `n_k = 2^(k+1) - 1` this gives `dim W^(n_k) ≥ 2^(k(k+1)/2)`, which
      is superpolynomial in `n_k`. That contradicts `GKdim R < ∞`.
11. **Nilpotent groups.** Let `H` be finitely generated and torsion-free
    nilpotent, with Bass–Guivarc'h degree `deg H`.
    - `F[H]` is a domain, because `H` is orderable (Malcev–Neumann).
    - `dim F[H]_(≤n) = |B_H(n)| ≍ n^(deg H)`, so `GKdim F[H] = deg H < ∞`, and
      `F[H]` is left Ore by 10.
    - By 8, an embedding `F[H] ↪ M_k(LC(X,F) ⋊ G)` with `G` acting freely
      forces `growth(H) ≼ growth(G)`, and so `deg H ≤ d` when `G` has degree
      `d`.
    - A nonabelian `H` has `rank(H^ab) ≥ 2` and `rank(γ_2 H/γ_3 H) ≥ 1`, so
      `deg H ≥ 1·2 + 2·1 = 4`.
12. **The `B_Ω` consequences (claim part 5).**
    - A free `Z^d`-action on `Ω` makes `B_Ω = LC(Ω,F) ⋊ Z^d` a case of 8.
      `GKdim F[Z^(d+1)] = d + 1`, and the image of any embedding is a
      commutative domain. So no embedding exists.
    - For `F_2[Z^4] ⊆ B_Ω ⊗ L_∂` with `d = 2`, part 9 gives
      `4 ≤ 2 + GKdim R'`.
    - The algebras `F[u^±]`, `M_n(F[u^±])` and the finitely generated
      subalgebras of the locally finite algebra `LC(∂F_d)` all have GKdim at
      most 1.
13. **Sharpness and limits.**
    - `δ_(e_1)` and `δ_(e_2)` span `F[Z^2]`, because distinct group elements
      are linearly independent.
    - Item 2 fails for `L(1,n)` and `L_∂`, whose groupoids have isotropy at
      eventually periodic points. The fibre counts there also grow
      exponentially.

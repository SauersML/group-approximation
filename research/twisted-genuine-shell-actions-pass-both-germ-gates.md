**ESTABLISHED** (lane proof below; elementary; not independently reviewed; no novelty claimed).

**Statement.** Let `P` be infinite and generated by a finite set `S`, `rho: P -> Sym(N)` an action in
which every `g != 1` has infinite support, `s: n -> n+1`, and `phi: P -> P` an injective
endomorphism with

    s^-1 rho(g) s = rho(phi(g))   near infinity, for every g in S.

Let `G = P *_phi = <P, t | t^-1 g t = phi(g)>`. Then:
1. `t -> s`, `g -> rho(g)` defines an isomorphism `G -> R_rho = <rho(P), s>` (near permutations).
2. `s^-1 rho(P) s <= rho(P)`, so the finite-window gate of
   `shell-ascending-gate-is-a-finite-window-inclusion` holds with `epsilon = 1`, `N = 0`.
3. If `P` is finitely presented, so is `R_rho`, and the isotropy germ group `Q_rho` of `E_rho` is
   finitely presented (`shell-germ-fp-is-an-ascending-hnn-gate`, valid for genuine actions by
   `genuine-action-shell-envelopes-generalize-the-regular-shell` item 3).

**Proof.** The relation holds for all `g in P`, since both sides are homomorphisms in `g` and near
equality is preserved by products. So the map in (1) is a homomorphism. The near index `eta` sends
`s` to `1` and `rho(P)` to `0`. Its kernel in `G` is `K = union_(n>=0) t^n P t^-n`, since
`t^-1 P t = phi(P) <= P`. An element of `K` has the form `t^n g t^-n` and maps to `s^n rho(g) s^-n`,
which is near trivial only if `rho(g)` is, that is, only if `g = 1`. So the map is injective, which is (1).
(2) is the relation itself. For (3), an ascending HNN extension of a finitely presented group over a
finitely generated subgroup is finitely presented.

**Scope.** Nothing here makes `E_rho` itself finitely presented. The two germ conditions are necessary,
not sufficient (`shell-envelope-fp-forces-fp-germ-group`). Existence of such twisted actions for inputs
that are not virtually abelian is open; `automorphism-twisted-shell-actions-have-finitely-many-orbits`
restricts where to look.

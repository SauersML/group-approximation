For unitaries `U,V` on `C^d`, the normalized maximally entangled vector
obeys

```text
<(U tensor conjugate(V))Omega,Omega>=tr(UV^*).             (TQP1)
```

Tensoring two approximate assignments adds their normalized-HS errors, so
the two vertex assignments give an approximate representation `rho_n` of
`A`.  If `a in C`, the amalgamating relators make the right side of `(TQP1)`
tend to one.  If `a notin C`, the word
`i_0(a)i_1(a)^(-1)` is reduced of amalgam length two, hence is nontrivial;
canonical regularity of the full double makes its trace tend to zero.  This
proves `(TQR1)` for every fixed `a`.

The function `1_C` is the positive-definite coefficient of the base vector
in `lambda_(A/C)`, and its GNS representation is precisely that
quasi-regular representation.  Therefore the cyclic subspace generated by
`Omega=(Omega_n)_U` in the Hilbert ultraproduct is unitarily equivalent to
`ell^2(A/C)` with `Omega` corresponding to `delta_C`.

This also explains exactly why property (T) stops.  The vector `Omega` is
`C`-invariant, but

```text
||rho(h)Omega-Omega||^2=2
```

for every `h notin C`.  The representation has no nonzero `A`-invariant
vector in this cyclic subspace.  Property (T) only promotes vectors already
almost invariant under a Kazhdan set of `A`; it does not promote a vector
fixed by a nonnormal, infinite-index subgroup.

For tensor powers, the elementary inequalities

```text
||X_1 tensor ... tensor X_k-Y_1 tensor ... tensor Y_k||_2
 <= sum_j ||X_j-Y_j||_2,

<rho(a)^(tensor k)Omega^(tensor k),Omega^(tensor k)>
 = <rho(a)Omega,Omega>^k
```

give `(TQR2)`.  If `k` is fixed, the ultralimit coefficient is still
`1_C`.  If `k=k_n` grows, retaining vanishing presentation defect requires
at least the corresponding tensor error scale to vanish; retaining
`C`-invariance requires
`k_n(1-Re <rho_n(c)Omega_n,Omega_n>)->0`.  Under those conditions the
`h`-coefficient remains zero rather than tending to one.  Thus amplification
preserves the obstruction.

Fixed exterior powers have the same bounded-degree continuity issue and
cannot change the exact limiting fact that the starting pointed cyclic
module is quasi-regular.  Growing exterior degree has no dimension-free
defect control beyond a degree-dependent Lipschitz bound, so it supplies no
missing implication either.

Equivalently, in block form put

```text
pi_n=pi_(n,0) direct_sum pi_(n,1),
k_n=the block swap.
```

Then `k=(k_n)_U` centralizes `pi(C)` and its commutator coefficient is the
same profile `1_C`.  This is exactly the configuration prohibited by
`no-exact-quasi-regular-leak`.  Hence the tensor route has reached that
named finite-dimensional hole, not a new property-(T) consequence.

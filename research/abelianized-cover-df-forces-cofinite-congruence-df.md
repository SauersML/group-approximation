**ESTABLISHED (written proof; not Lean-verified).**

## Setting

- `F` is free on `x_1, ..., x_n`, `R` is normal in `F`, and `G = F/R`.
- `E = F/[R,R]` and `M = R/[R,R]`, written additively as a `ZG`-module.
- `M` embeds in `ZG^n` by the Lyndon (Fox) embedding
  `0 -> M -> ZG^n -> I_G -> 0`.
- For `m in M \ {0}`, the **content** `c(m) >= 1` is the gcd of the integer
  coefficients of `m` in `ZG^n`.  These are finitely many nonzero integers.
- For an integer `N >= 1`, the **congruence quotient** is
  ```text
  H_N = E / NM = F / [R,R] R^N,        1 -> M/NM -> H_N -> G -> 1.
  ```
  Here `R^N` is the subgroup generated by `N`-th powers of elements of `R`.
- The **MF set** is `calN = { N >= 1 : H_N is MF }`.

## Statement

1. **Purity.**  `M cap N ZG^n = NM` for every `N >= 1`.  Hence
   `M/NM` embeds in `(Z/N)[G]^n`.  For `m != 0`,
   `m in NM` if and only if `N` divides `c(m)`.
2. **Gate.**  For every `N` in `calN`, `Rad_MF(E) <= NM`.  If `calN` is
   infinite, then `E` is MF.
3. **Lattice structure.**  `calN` is closed under `lcm`.  If `G` is not MF,
   then `1` is not in `calN`.
4. **DF forces cofinite congruence DF.**  Suppose `G != 1` and
   `Rad_MF(G) = G`, and suppose DF holds, so that `E` is not MF.  Then `calN`
   is finite.  Moreover:
   - either `calN` is empty;
   - or `Rad_MF(E)` is a nonzero `G`-submodule of `M`, and every element of
     `calN` divides
     ```text
     c_E = gcd { c(m) : m in Rad_MF(E) \ {0} } >= 1.
     ```
   In either case there is an integer `c >= 1` such that `H_N` is not MF for
   every `N` that does not divide `c`.  In particular:
   - `F/[R,R]R^p` is not MF for all but finitely many primes `p`;
   - for every prime `p`, `F/[R,R]R^(p^k)` is not MF for all large `k`.

## Use

- **Refutation route.**  To refute DF for a presentation, it suffices to
  build MF models of the torsion quotients `H_N` for infinitely many `N`.
  In such a model the kernel image has exponent `N`, and its joint spectrum
  is a closed subset of the profinite dual group of `M/NM`.
- **Necessary condition.**  Non-MF-ness of `H_p` for all large primes `p`
  is a consequence of DF that can fail on its own.  Its failure for
  infinitely many `p` refutes DF.  It is a statement about groups whose
  kernel has exponent `p`, where rank-type corona invariants are exact.

## Scope

- The converse is **not** claimed.  Non-MF-ness of every `H_N` does not
  formally give DF, because a model of `E` need not factor through any
  congruence quotient.  A "congruence lifting" principle, that an MF cover
  has infinitely many MF congruence quotients, would make DF equivalent to
  finiteness of `calN`.  It is open.  Rounding the spectrum of the kernel
  image to `N`-th roots of unity is not multiplicative, so it gives no proof.
- The quotients `H_N` have torsion, so they do not feed the torsion-free
  endpoint.  This claim only constrains DF.
- No property of `G` beyond `G != 1` and full radical is used in item 4.
  Items 1 to 3 hold for every finitely generated `G`.

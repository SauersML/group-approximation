Let

```text
J=F_2<S,T | TS=1>,             Q=1-ST,
E=EL_5(J),                     z_Q=x_13(Q),
L=GL_fin(N x {1,...,5},F_2) <= E.
```

Fix two coordinate rays `i!=j`.  Let `P` be their constant Weyl swap and
put

```text
W=[[Q,S],[T,0]],               a=WP
```

on the `i,j` corner.  Then

```text
H=<L,a>=L semidirect Z                                      (JWS1)
```

is LEF.  More precisely, every finite multiplication table in `H` embeds
partially in a finite general linear group by closing a sufficiently long
uninspected part of the `a`-orbit into a cycle.  These models retain the
nonidentity finitary transvection `z_Q`.

Consequently `H` has an injective norm-matrix-corona representation which
does not kill `z_Q`.  If `Htilde` is its full preimage under

```text
St_5(J) -> E,
```

then composition with `Htilde -> H` gives a norm-corona representation of
`Htilde` retaining `x_13(Q)`.

This is a subsystem firewall only.  The full symbol quotient of `E` is
`EL_5(F_2[z,z^(-1)])`, whereas `(JWS1)` retains only the one cyclic actor
generated by `a`.  Relations involving the rest of that Laurent elementary
group are absent, so the construction is not a countermodel to
`binary-jacobson-steinberg-head-root-is-mf-invisible`.

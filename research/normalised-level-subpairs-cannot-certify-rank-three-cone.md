**ESTABLISHED (proposed; unreviewed).**  Derivation: [[normalised-level-subpairs-cannot-certify-rank-three-cone-proof]].
It is a class-killing obstruction for the nonsofic side of [[rank-three-finite-twisted-kazhdan-cone-is-sofic]].
It extends (Y2) of [[net-sandwich-level-subpairs-cannot-certify-rank-three-cone]] from pattern-sandwiched
elementary parts to normalised and finite-index ones.

## Setting

As in [[net-sandwich-level-subpairs-cannot-certify-rank-three-cone]]: `R_+ = F_q[x_1..x_d]`, `R` the Laurent
ring, `Gamma = SL_3(R_+)`, `G = EL_3(R) x| SL_d(Z)`, `psi = ev_0`, `U_k = < e_ab(x^m) : a ≠ b, m ∈ N^d, |m| ≥ k >`.
For `B ≤ G`: `C = B ∩ Gamma`, `E_B = B ∩ EL_3(R)`, `H_B` the projection to `SL_d(Z)`,
`K0 = cone(H_B · R_+^d)`, `Λ = span_(F_q) { g - 1 : g ∈ E_B }`.  A **monomial unit** of a subring `A' ⊆ R` is
`x^m` with `m ∈ N^d \ {0}` and `x^m, x^(-m) ∈ A'`.  For a subring `A'`, `E_3(A') = < e_ab(s) : s ∈ A' >`.

## Theorem

Let `B ≤ G` contain `U_k`.

**(Z1) Coefficient ring.**  If `-e_l ∈ K0` for some `l`, then `Λ = M_3(A_B)` for a unital `F_q`-subalgebra
`A_B ⊆ R` with `σ(A_B) = A_B` for all `σ ∈ H_B`.  So `E_B ≤ SL_3(A_B)`, and `A_B` has the monomial unit
`x^(c e_l)`, `c = 2kN`.  `E_B` is pattern-sandwiched in the sense of the net node exactly when
`E_3(A_B) ≤ E_B`.

**(Z2) Unit commutator.**  Let `A'` be a subring with `x^(-m) ∈ A'` for some `m ∈ N^d \ {0}`.  If `E_B` is
normalised by `E_3(A')`, then `e_ab(1) ∈ E_B` for all `a ≠ b`, and `E_3(A') ≤ E_B`.  No cone hypothesis is
needed.

**(Z3) Finite index.**  Let `A'` be a subring with a monomial unit.  If `E_B ∩ E_3(A')` has finite index in
`E_3(A')`, then `e_ab(1) ∈ E_B` for all `a ≠ b`.

**(Z4) Consequence.**  In each of the following cases `C ⊇ E_3(F_p)`, and `C_F(psi(C)) = 1`.  So no such `B` is a
Kun-Thom certificate for `T_3`: when `H_B` is infinite, (X1), (W2) supply `-e_l ∈ K0`, and when it is finite,
(X2) makes an infranormal `C` normal.

1. `E_B` is normalised by `E_3(A_B)`.  This covers every `E_B` normal in `GL_3(A_B)`, every subnormal subgroup
   of a pattern-sandwiched level subpair that contains `U_k`, and every conjugate `D E_3(A) D^-1` with
   `D ∈ GL_3(Frac R)`, including Picard-twisted `D` with `D A^3 ≅ L^3`, `[L] ∈ Pic(A)[3]`, `[L] ≠ 0`.
2. `E_B` has finite index in `E_(B')` for some `B' ⊇ B` whose elementary part contains `E_3(A')` with a monomial
   unit.  This covers all finite-index subgroups containing `U_k` of the pattern-sandwiched, net and subring
   subpairs of [[net-sandwich-level-subpairs-cannot-certify-rank-three-cone]] and
   [[subring-level-subpairs-cannot-certify-rank-three-cone]], whose traces `C` can be much smaller than theirs.

## Mechanism

1. *(Z1).*  `Λ` is an `Ad(B)`-stable algebra.  By (Y1) it contains every `E_ab` and `I`, so every matrix unit.
   An algebra containing `M_3(F_q)` is `M_3(A)` with `A = { r : r E_11 ∈ Λ }`.  `Ad(u σ)(r I) = σ(r) I`
   gives `σ(A_B) = A_B`, and (Y1) itself puts `x^(± 2kN e_l)` in `A_B`.
2. *(Z2).*  Put `t = x^(n m)` with `n|m| ≥ k`.  Then `e_ac(t) ∈ U_k ≤ E_B`, and `e_cb(t^(-1) s)` normalises
   `E_B` for `s ∈ A'`.  So `[e_ac(t), e_cb(t^(-1) s)] = e_ab(s)` lies in `E_B`, and `s = 1` needs no unit.
   The unit `t^(-1)` cancels the level from the outside, which is the step a span cannot do.
3. *(Z3).*  The normal core `N_0` of `E_B ∩ E_3(A')` in `E_3(A')` has finite index.  Its entry sets
   `K_ab = { r : e_ab(r) ∈ N_0 }` all contain the ideal `𝔞 = K_12 A'`, by the commutator formula.  `𝔞` has
   finite index, so `t^n ≡ 1 mod 𝔞` for the monomial unit `t` and some `n`, with `n` as large as wanted.  Then
   `e_ab(1) = e_ab(t^n) · e_ab(1 - t^n)`, with the first factor in `U_k` and the second in `N_0`.
4. *(Z4).*  `E_3(F_p)` is perfect and absolutely irreducible, so its image in `PSL_3(F_q)` has trivial
   centraliser.  `D E_3(A) D^-1` is normalised by `E_3(A)` because `D` normalises `M_3(A) = Λ`, hence
   `GL_3(A)`, and `E_3(A)` is normal in `GL_3(A)` (Suslin).  Subnormal chains follow by iterating (Z2),
   whose conclusion `E_3(A') ≤ E_(B_i)` is its own hypothesis one step down.

## Calibration

- `B = G`, or any finite-index subgroup of `G` containing `U_k`: (Z3) with `A' = R` gives `e_ab(1) ∈ E_B`.
  This is consistent with (V5) of the invisible-core node.
- `B = U_k`: `E_B = U_k ≤ 1 + M_3(𝔪^k)` does not contain `e_ab(1)`.  So by (Z2) no `e_cb(x^(-m))` normalises
  it, which a direct check confirms.
- The box-level net subpair (Y4) of the net node contains no `U_k`, and indeed escapes (Z2) and (Z3).

## What is left

With a level `U_k` and `H_B` infinite, a certificate now needs `E_B` with all of these properties:

- `E_B` lies in `SL_3(A_B)` and spans `M_3(A_B)`, where `A_B` contains `x_l^(± c)` for every `l` in the
  coordinate set `M` of (W2);
- `E_B` is not normalised by `E_3(A_B)`;
- `E_B ∩ E_3(A')` has infinite index in `E_3(A')` for every subring `A'` with a monomial unit.

In particular `Δ_l = E_B ∩ SL_3(F_q[s, s^-1])`, `s = x_l^c`, contains `E_3(s F_q[s])`, which has finite index
in `SL_3(F_q[s])`, yet has infinite index in the `{0, ∞}`-arithmetic group `SL_3(F_q[s, s^-1])`.  So `E_B` is
a **thin** overgroup of a level.  In the one-variable `S`-arithmetic model, intermediate-subgroup rigidity
of Venkataramana type forbids such overgroups once `Δ_l` is unbounded at `s = 0`.  The open step is a version
of that rigidity for `E_B ⊆ SL_3(A_B)` that spans `M_3(A_B)` and contains `E_3(𝔪^k)`.  This is the one
remaining level-containing class.

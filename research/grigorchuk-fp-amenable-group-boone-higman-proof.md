Lane proof (bh-free-20, 2026-09-18), elementary; not reviewed.

## 1. Lysenok's endomorphism keeps each element as its last section

Recursion of the first Grigorchuk group (sections at `0`, then `1`): `a` swaps the first
letter with trivial sections; `b = (a, c)`, `c = (a, d)`, `d = (1, b)`. All four are
involutions, `bcd = 1`, and `D := ⟨a, d⟩ ≅ D_8`.

For `φ: a ↦ aca, b ↦ d, c ↦ b, d ↦ c` (an injective endomorphism of `𝔊`, landed as
`grigorchuk-ascending-hnn-extension-is-finitely-presented`):

```text
φ(a) = aca = (d, a)    [conjugating (a, d) by the root swap exchanges the sections]
φ(b) = d   = (1, b)
φ(c) = b   = (a, c)
φ(d) = c   = (a, d)
```

So `φ(𝔊)` lies in the level-1 stabilizer, where both section maps are homomorphisms. The
second section of `φ` is a homomorphism `𝔊 → 𝔊` fixing the generators, so it is the
identity. The first section `ψ` is a homomorphism with `ψ(a) = d`, `ψ(b) = 1`,
`ψ(c) = a`, `ψ(d) = a`. Hence `φ(g) = (ψ(g), g)` for every `g`, which is the hypothesis of
`last-section-ascending-hnns-embed-in-rover-nekrashevych-groups` with `σ = φ`.

## 2. The homomorphisms `h_k = ψ ∘ φ^k`

Using `h_{k+1}(x) = h_k(φ(x))` on generators, and `a^2 = d^2 = (ad)^4 = 1`:

| k | a | b | c | d |
|---|---|---|---|---|
| 0 | d | 1 | a | a |
| 1 | dad | a | 1 | a |
| 2 | 1 | a | a | 1 |
| 3 | a | 1 | a | a |
| 4 | a | a | 1 | a |
| 5 | 1 | a | a | 1 |

For example `h_2(a) = h_1(aca) = (dad)·1·(dad) = 1`. Row 5 equals row 2, so `h_{k+3} = h_k`
for `k ≥ 2`. Each row respects `b = cd`, a check that it is a homomorphism.

So for `k ≥ 2` every `h_k(g)` lies in `{1, a}`, and `a` is finitary (a root swap with trivial
sections).

## 3. The extended automaton and its group `S`

As in the lemma, `ĝ = (E_g, g)` and `E_g = (E_{φ(g)}, ψ(g))`, where `E_g` acts on the cone
`0^k1C` by `h_k(g)` and fixes `0^∞`. `E_g` depends only on `(h_0(g), …, h_4(g)) ∈ D^5`, so
`E(𝔊) = {E_g}` is a finite group. Let `A` be the automaton with states:
- `1, a, b, c, d`;
- the elements of `D` together with their sections (all in `𝔊`, finitely many);
- `E_g`, `g ∈ 𝔊` (finitely many);
- `â, b̂, ĉ, d̂`.

The state set is closed under sections: `x̂ ↦ E_x, x`; `E_g ↦ E_{φ(g)}, ψ(g) ∈ D`; `𝔊` is
self-similar. So `A` is a finite automaton and `S = ⟨A⟩` is a finitely generated
self-similar group, generated by `a,b,c,d, â,b̂,ĉ,d̂, E_a,E_b,E_c,E_d` (12 elements; `E` and the
hat are homomorphisms).

**Bounded.** Count the vertices of level `n` with nontrivial section.
- The Grigorchuk states are bounded (at most two per level). So is each element of `D`, a
  bounded word in them.
- For `E_g` the candidates are:
  - `0^n`, with section `E_{φ^n(g)}`;
  - `0^k1w` with `k + 1 + |w| = n`, with section `h_k(g)|_w`.

  For `k ≥ 2` this is nontrivial only when `w` is empty, since `h_k(g) ∈ {1, a}`. That
  leaves the single vertex `0^{n-1}1`. For `k = 0, 1` the element `h_k(g)` lies in `D`, so
  there are boundedly many.
- `x̂ = (E_x, x)` is then bounded as well.

So `A` is a finite bounded automaton, and `S` is contracting (Bondarenko–Nekrashevych;
Nekrashevych, *Self-similar groups*, Thm 3.9.12, cited, not re-read).

Without row 2 onward of the table, `E_a` would carry the non-finitary element `d` on
infinitely many cones, and `A` would have linear activity. The period-3 collapse to
`{1, a}` is what keeps `S` contracting.

## 4. Conclusion

By the lemma, `g ↦ ĝ`, `t ↦ s^{-1}` embeds `H = 𝔊*_φ` in `⟨F, Ŝ⟩ ≤ V_2(S)`, with
`s(1u) = 11u`, `s(01v) = 10v`, `s(00w) = 0w`.

`S` is finite-state and contracting, so `V_2(S)` is a full, contracting RSG (BBMZ
arXiv:2309.06224, Example `ex:rn` and the remark after Definition `def:contracting`, read in
the TeX).
- **BH.** Corollary `cor:RN_BH`: `V_2(S)`, hence `H`, embeds in a finitely presented simple
  group.
- **PBH.** The proof of Proposition `prop:contr_to_simple` shows `V_2(S)` is finitely
  presented and acts faithfully and highly transitively on the orbit of a rational point,
  with finitely generated stabilizers of finite subsets (`prop:fin_gen_stabs`). That is an
  action of type (A), so `H ∈ B_A`. ∎

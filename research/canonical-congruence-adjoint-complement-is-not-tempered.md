**ESTABLISHED (spectral no-go).**  Let `Gamma` be an infinite,
nonamenable, residually finite group with a nontrivial finite quotient

```text
q_0:Gamma ->> Q_0,             H=ker(q_0).
```

Choose a decreasing residual chain of finite-index normal subgroups
`N_n normal Gamma`, with `N_n <= H` and `intersection_n N_n={e}`.  Put
`Q_n=Gamma/N_n` and let

```text
rho_n=lambda_(Q_n):Gamma -> U(l^2(Q_n)).                 (CAT1)
```

The exact representations `(rho_n)` have regular limiting character and
therefore define a trace-preserving embedding

```text
iota:L(Gamma) -> M=prod_omega M_(|Q_n|).
```

For the conjugation representation `alpha=Ad iota` on `L^2(M)`, its
orthogonal complement

```text
K=L^2(M) minus L^2(iota(L(Gamma)))                        (CAT2)
```

contains a copy of the mean-zero finite-quotient Koopman representation
`l^2_0(Q_0)`.  This finite-dimensional representation is not weakly
contained in `lambda_Gamma`.  Consequently

```text
alpha|_(K ominus K^Gamma) is NOT weakly contained in lambda_Gamma.      (CAT3)
```

This applies in particular to `Gamma=SL_3(Z)`.  Thus property `(T)`,
residual finiteness, the congruence subgroup property, character rigidity,
exactness of the reduced group algebra, and Kirchberg's factorization
property cannot imply full-adjoint-complement temperedness for a prescribed
regular embedding: `(CAT1)` already has all of those inputs and is an exact
congruence model.

The construction is not an instability witness.  The group tuple in
`(CAT1)` is already an exact representation, so it is trivially ucp- and
flexibly correctable.  Nor does it refute the selected-vector hypothesis in
`tempered-selected-conjugation-vector-obeys-rcc`.  If `C<A` is profinitely
dense and the same construction is made for `A`, then `C` and `A` have the
same image in `Q_0`; hence the finite-quotient mean-zero sector has no
`C`-fixed vector.  It refutes precisely the tempting stronger assertion
that the *entire* non-`A`-invariant adjoint complement of every canonical
matrix model is tempered.

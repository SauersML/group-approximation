Direct proof (2026-09-13, lane `bh-metabelian`). It follows
`char-zero-polynomial-embedding-via-noether-normalization` step for step, with
`Z` replaced by `F_p`.
- **Sources.** The Stacks Project statements below were read from `algebra.tex`
  on MSI (`/scratch.global/sauer354/bc0/algebra.tex`, with the `tags` file there
  mapping each tag to its label). Quillen's Theorem 4 was read from the journal PDF.
- **Setup.** Let `Γ <= GL_N(K)` be generated by `γ_1, ..., γ_g`, with `char K = p`.

1. **Restriction of scalars.**
   - Let `K_0 ⊂ K` be the field generated over `F_p` by the entries of all `γ_i`
     and `γ_i^-1`. It is finitely generated over `F_p`, so it has a transcendence
     basis `t_1, ..., t_k`, and `d = [K_0 : F_p(t)]` is finite.
   - Left multiplication on a fixed `F_p(t)`-basis of `K_0` is an injective unital
     ring homomorphism `φ : K_0 -> M_d(F_p(t))`. Applied entrywise it is an
     injective unital ring homomorphism `M_N(K_0) -> M_(Nd)(F_p(t))`. So `Γ` embeds
     in `GL_(Nd)(F_p(t))`.
2. **Denominators.** Let `f ∈ F_p[t] \ 0` be a common denominator of the entries of
   the images of the `γ_i^(±1)`, and `A = F_p[t][1/f] ⊂ F_p(t)`. Then `Γ` embeds in
   `GL_(Nd)(A)`, and `A = F_p[t, u]/(g)` with `g = u f - 1`.
3. **Nagata normalization.**
   - **Weights.** Write `f = Σ_a c_a t^a`. Pick an integer `D >= 2` larger than
     every exponent `a_i` with `c_a ≠ 0`, and give `u t^a` the weight
     `w(a) = 1 + Σ_i a_i D^i`. Different `a` have different base-`D` digits, so
     different weights. Let `a*` have the largest weight among the `a` with
     `c_a ≠ 0`, put `W = w(a*)` and `c = c_(a*) ∈ F_p^×`.
   - **Substitution.** Put `s_i = t_i - u^(D^i)` in `A`. Each
     `u t^a = u Π_i (s_i + u^(D^i))^(a_i)` is a polynomial in `u` over `F_p[s]` of
     degree `w(a)` with leading coefficient `1`, and the constant `-1` of `g` has
     degree `0 < W`. So in `A`

     ```text
     0 = g = c u^W + Σ_(j<W) h_j(s) u^j,   h_j ∈ F_p[s_1, ..., s_k].
     ```

   - **Finiteness.** Let `P = F_p[s_1, ..., s_k]` map to `A` by
     `s_i -> t_i - u^(D^i)`. Since `t_i = s_i + u^(D^i)`, `A = P[u]`. Since `c` is a
     unit, dividing by `c` makes `u` integral over `P` of degree `W`. So `A` is
     generated as a `P`-module by `1, u, ..., u^(W-1)`. Unlike characteristic zero,
     nothing is inverted.
   - **Injectivity.** `F_p(t) = Frac(A)` is algebraic over the subfield generated by
     the images of `s_1, ..., s_k`, so those `k` elements are algebraically
     independent and `P -> A` is injective. Regard `P ⊂ A`.
4. **`A` is finite projective over `P`.** Both rings are finitely generated
   `F_p`-algebras, hence noetherian. Fix a prime `q` of `A` and put `p = q ∩ P`.
   - **Regularity.** 00OQ: "A polynomial algebra in n variables over a field is a
     regular ring." `A` is a localization of `F_p[t]`, so each `A_q` is a local ring
     of `F_p[t]`, hence regular (definition 00OD). The same holds for `P`.
   - **Cohen--Macaulay.** 00NQ: a regular local ring "is Cohen-Macaulay".
   - **Normality.** 0BC1: "if k is a field, then k[x_1, ..., x_n] is a UFD". 0AFV:
     "A unique factorization domain is normal." So `P` is normal.
   - **Dimension.**
     - 00H8: for domains `R ⊂ S` with `R` normal and `S` integral over `R`, "the
       going down property holds". So it holds for `P ⊂ A`.
     - 00ON: if going down holds for a map of noetherian rings, then
       `dim A_q = dim P_p + dim A_q/pA_q`.
     - `A_q/pA_q` is a localization of the finite-dimensional `κ(p)`-algebra
       `A ⊗_P κ(p)`, whose primes are all maximal. So its dimension is `0`, and
       `dim A_q = dim P_p`.
   - **Miracle flatness.** 00R4: a local homomorphism of noetherian local rings
     `R -> S` with `R` regular, `S` Cohen--Macaulay and
     `dim(S) = dim(R) + dim(S/m_R S)` is flat. With `R = P_p` and `S = A_q`, the
     dimension condition is the equality just proved, since `m_(P_p) A_q = p A_q`.
   - **Globally.** Flatness is local (00HT), so `A` is flat over `P`. It is finite
     over the noetherian ring `P`, hence finitely presented. 00NX: "M is finitely
     presented and R-flat" is equivalent to "M is finite projective".
5. **Freeness.** D. Quillen, *Projective modules over polynomial rings*, Invent.
   Math. 36 (1976), 167--171, Theorem 4 (p. 169): "If k is a principal ideal domain,
   then any finitely generated projective k[T_1,...,T_n]-module M is free." Take
   `k = F_p`, a field and so a principal ideal domain. Then `A ≅ P^r`, where
   `r = [F_p(t) : F_p(s)]`.
6. **Embedding.** Choose a `P`-basis of `A`. Multiplication by `a ∈ A` has a matrix
   `ψ(a) ∈ M_r(P)`, and `ψ` is an injective unital ring homomorphism. Applying `ψ`
   entrywise gives an injection

   ```text
   Γ <= GL_(Nd)(A) -> GL_(Ndr)(F_p[s_1, ..., s_k]).
   ```

   **For `k = 0`.** `K_0` is a finite field, `A = F_p`, and step 1 alone lands in
   `GL_(Nd)(F_p)`. ∎

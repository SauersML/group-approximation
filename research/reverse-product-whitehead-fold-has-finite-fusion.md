**ESTABLISHED GENUINE COMPLETENESS-READING FINITE FENCE.**  Let

```text
q_i=s_it_i,                    q_0+q_1=A,
q_i^2=q_i,                     q_0q_1=q_1q_0=0.        (RWF1)
```

Use one actual opposite-root pair `(1,4)` and define

```text
C_i=x_14(q_i),                 D_i=x_41(q_i),
J=x_14(A),                     L=x_41(A),
W_i=C_iD_iC_i,                 W_A=JLJ.                (RWF2)
```

Here `C_i` is not an independent fold sign: it is the output of the shared
reverse-product payload path carrying the literal coefficient `s_it_i`.
The fixed root-position transport of that same coefficient supplies `D_i`.
Thus each reverse product occurs inside a noncommuting opposite-root word
before the two branches are compared.

Direct block multiplication gives the genuine two-branch relation

```text
W_0W_1=W_A.                                             (RWF3)
```

Unlike the aggregate row/column Whitehead, the derivation of `(RWF3)` uses
both orthogonality and the completeness equality in `(RWF1)`.  This is the
smallest natural bounded word currently known which satisfies the requested
reverse-product-before-collapse criterion.

It still does not imply `(BAC1)`.  Let `K` be the finite subgroup of
`GL_4(F_2)` generated by

```text
z=x_14(1),             ell=x_41(1),
w=z ell z.                                               (RWF4)
```

In `G=(K^3) semidirect S_3`, with the actor permuting coordinates, put

```text
C_0=(z,z,1),            D_0=(ell,ell,1),
C_1=(z,1,z),            D_1=(ell,1,ell),
J  =(1,z,z),            L  =(1,ell,ell).               (RWF5)
```

Every named arm in the reverse-product payload path is supported on the
same coordinate pattern as its `C_i`, so occurrence sharing is literal
inside each finite packet.  Then

```text
W_0=(w,w,1),            W_1=(w,1,w),
W_A=(1,w,w).                                             (RWF6)
```

Since `w^2=1`, `(RWF3)` holds exactly, while `J!=1`.  The three-packet model
therefore absorbs even this genuinely nonlinear completeness reader by
putting the two reverse products on overlapping but nonidentical payload
supports.

The surviving seam is stronger and now very precise: a new bounded word
must force `D_0,D_1,L` (or another opposite-root family reading the same
coefficients) onto **one indivisible payload reservoir**, rather than allow
the support pattern `(RWF5)`.  Merely sharing every coefficient occurrence
within its branch and then multiplying the two nonlinear outputs still
permits three-character fusion.

No Property `(T)`, Kazhdan input, stability theorem, trace hypothesis, or
literature result is used.

## Setting

Let `K` be a group, `n >= 2`, and `M` a group containing `K`. Write
`A = Aut_K(K * F_n)` for the automorphisms of `K * F_n` restricting to the
identity on `K`, with `F_n = F(x_1, ..., x_n)`. A tuple `m ∈ M^n` is the same as
the `K`-homomorphism `π_m : K * F_n -> M`, `x_i -> m_i`. The group `A` acts on
`M^n = Hom_K(K * F_n, M)` by precomposition, `m . α = π_m ∘ α`. This is the
action of BFFHZ Theorem E when `M = K`, and the action of Attempt 2 on
`fp-simple-groups-embed-in-fp-simple-mif-groups` when `M ⊋ K`.

Call `b ∈ M^n` a **redundant generating tuple** if `⟨K, b⟩ = M` and some
coordinate lies in the subgroup generated by `K` and the other coordinates.
After precomposing with a transvection, that coordinate can be taken to be `1`:
`b = (b_1, ..., b_{n-1}, 1)` with `⟨K, b_1, ..., b_{n-1}⟩ = M`.

## Statement

Let `b = (b_1, ..., b_{n-1}, 1)` with `⟨K, b_1, ..., b_{n-1}⟩ = M`, and let
`Ω ⊆ M^n` be any `A`-invariant set containing `b`.

1. **Stabilizer clause.** If `Stab_A(b)` is finitely generated, then
   `N = ker π_b` is finitely normally generated in `K * F_n`. So `M` is
   finitely presented relative to `K`, and `M` is finitely presented when `K`
   is.
2. **Pair clause, normal subgroups.** If `A` has finitely many orbits on
   `Ω × Ω`, then `M` has only finitely many normal subgroups. In particular
   `Z(M)` is finite.
3. **Pair clause, centralizer.** Under the same hypothesis, `C_M(K)` is finite.

So if `A ↷ Ω` is of type (A) and `Ω` contains a redundant generating tuple for
`M`, then `M` is finitely presented relative to `K`, has finitely many normal
subgroups, and has finite centralizer `C_M(K)`.

## Consequence for Question 3.4 (the class this kills)

Take `K = S`, a finitely presented simple group, and apply the precomposition
route of Attempt 2: act by the finitely presented group `Aut_S(S * F_n)` on
tuples in a simple MIF overgroup `M ⊋ S` to remove the mixed-identity kernel.
Attempt 2 already shows that the point orbits force the subgroups `⟨S, m⟩`
into finitely many values. Once an orbit contains a redundant tuple, the
stabilizer clause fails unless `⟨S, m⟩` is finitely presented. This holds
whenever `Ω` is all of `M^n`, or is the set of all `S`-generating tuples with
`n` larger than the relative rank.

- **Dead members.** Every infinitely presented target dies at the stabilizer
  clause (type (A) (ii)). This includes the simple MIF overgroups from Osin-type
  small cancellation, inductive limits and other non-finitely-presented simple
  MIF overgroups. It also includes any target with unsolvable word problem.
- **Survivors.** A surviving target must already be a finitely presented group
  with finitely many normal subgroups and finite `C_M(S)`, with no nontrivial
  `w ∈ S * F_n` vanishing on the orbit.
- **What the route can still add.** When `M` is a finitely presented simple MIF
  overgroup, Question 3.4 for `S` is already answered. The route adds something
  only for finitely presented targets that are MIF relative to `S` but not known
  to be MIF.

**ESTABLISHED** by `a2-stabilizer-image-presentation-controls-kernel-proof`
(not independently reviewed; no novelty claimed, the arguments are elementary).

Type `[A_2]` is Fournier-Facio--Wu--Zaremsky, arXiv:2603.24687v2, Definition 1.3
with `n = 2`, read from the PDF text on MSI: `G` is of type `F_2` (finitely
presented), every point stabilizer is of type `F_1` (finitely generated), and
the diagonal action of `G` on `S^2` has finitely many orbits. The action need
not be faithful. Sharp embeddings of normal pairs are their Definition 1.6.

**Statement.** Let `G ↷ S` be of type `[A_2]` with kernel `K`, and put
`Q = G/K`, generated by the images of a finite generating set of `G`.

1. **Recursive kernel.** These are equivalent: `K` is recursive; `Q` has
   solvable word problem; `Q` is recursively presented.
2. **One finitely presented stabilizer image suffices.** If `Stab_Q(s)` is
   finitely presented for some `s in S`, then `K` is finitely normally generated
   in `G`, so `Q` is finitely presented, `Q ↷ S` is of type `(A_2)`, and the
   pair `(G, K)` sharply embeds in a type `[A_2]` pair with finitely normally
   generated kernel. In particular `K` is recursive.
3. **What a non-recursive kernel needs.** If `K` is not recursive, then `Q` is
   not recursively presented, and for every `s in S` the group `Stab_Q(s)` is
   finitely generated but not finitely presented.
4. **Hardness is not carried by sharp subgroups.** Every finitely generated
   subgroup `Γ <= G` with `Γ ∩ K = 1` has solvable word problem.

**Consequence for FFWZ Question 5.9 (first part).** The answer is yes for every
type `[A_2]` action with a finitely presented point-stabilizer image. A negative
answer through a non-recursive kernel (item 1 with
`a2-kernel-removal-forces-recursive-kernel`) needs an action image that is not
recursively presented, all of whose point-stabilizer images are finitely
generated but not finitely presented, and whose undecidability is not
witnessed inside any sharply embedded finitely generated subgroup.

**Consequence for FFWZ Question 5.8.** Any type `[A_2]` action whose image is not
finitely presented has no finitely presented point-stabilizer image.

**Not claimed.**
- No type `[A_2]` action with a non-recursive kernel is exhibited.
- A recursive kernel is not shown to be removable.

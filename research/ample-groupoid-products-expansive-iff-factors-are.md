## Setting

- Groupoids are étale with Cantor unit space, and "compactly generated", "expansive
  cover" and "expansive" are as in `nekrashevych-expansive-groupoid-criteria`. Expansive
  means: compactly generated, and some finite cover by bisections of some compact open
  generating set is expansive.
- For groupoids `𝒢_1, 𝒢_2`, the product `𝒢_1 × 𝒢_2` has the product topology and
  coordinatewise operations. Its unit space is `𝒢_1^{(0)} × 𝒢_2^{(0)}`, again a Cantor set,
  and it is étale.
- `G_2` is the Cuntz groupoid over `X = {0,1}^N`:
  `G_2 = {(μz, |μ|-|ν|, νz) : μ, ν finite words, z ∈ X}` with
  `(x,k,y)(y,l,z) = (x,k+l,z)`, `(x,k,y)^{-1} = (y,-k,x)`. Its topology has basis the
  bisections `U_{μ,ν} = {(μz, |μ|-|ν|, νz) : z ∈ X}`.
- `M ⋊ Γ` is the action groupoid `Γ × M` of an action of a group `Γ` on a Cantor set
  `M` by homeomorphisms, with the convention of the import node.

## Statement

1. **Compact generation.** If `S_i` is a compact (open) generating set of `𝒢_i` for
   `i = 1, 2`, then `S = (S_1 × 𝒢_2^{(0)}) ∪ (𝒢_1^{(0)} × S_2)` is a compact (open)
   generating set of `𝒢_1 × 𝒢_2`. Conversely, if `𝒢_1 × 𝒢_2` is compactly generated, so
   are both factors.
2. **Expansivity.** `𝒢_1 × 𝒢_2` is expansive if and only if `𝒢_1` and `𝒢_2` are expansive.
3. **The Cuntz groupoid.** `G_2` is compactly generated by `U_{0,∅} ∪ U_{1,∅}`, and the cover
   `{U_{0,∅}, U_{1,∅}}` is expansive. So `G_2` is expansive.
4. **The host family.** Let `Γ` be finitely generated. Then:
   - `(M ⋊ Γ) × G_2` is compactly generated, for every action on a Cantor set `M`;
   - it is expansive if and only if `Γ ↷ M` is a subshift, i.e. conjugate to a closed
     invariant subset of `F^Γ` for a finite set `F`.

## Consequence for the calibration of nV

- The remark "not ruled out: proofs that use compact generation" in
  `brin-thompson-groups-nv-are-a-t-menable` is settled. The host
  `(M ⋊ Γ) × G_2`, `Γ = Z^3 ⋊ SL_3(Z)`, of
  `amenable-purely-infinite-groupoid-full-group-hosts-kazhdan` is compactly generated, so
  compact generation cannot be what separates `G_2^n` from that host.
- Whether that host is expansive is exactly whether its action `Γ ↷ M` is a subshift. The
  host's `M` is built inside `X' × Z`, with `X'` a closed subset of `T^Γ` and `T` an
  infinite set of cover sequences, so this is not settled here.
- `rs-boundary-groupoid-is-expansive-amenable-kazhdan-host` gives a different world that
  is expansive.

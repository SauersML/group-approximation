**ESTABLISHED EXACT ROW AUDIT.** Order the full-family part of the Atlas
packet exactly as in `atlas_relator_rank5_full_family.generate_relators`.
Apply the following conservative literal filter:

1. discard the one-root `root_*` relations;
2. for an `orth_ij_kl_rs` relation, require one of `ij,kl` to be upper and
   the other lower triangular; and
3. require both displayed coefficient letters `r,s` to differ from `1`.

This removes the positive-root and one-constant-coefficient rows before the
later involutivity and reverse-dictionary/Whitehead families are reached.
The first survivor is the zero-based full-family entry `280`, hence packet
entry `281`,

```text
orth_12_32_ee = [x_12(e),x_32(e)].                    (FMR1)
```

Its translated two-chart word has `52` syllables and Atlas `X`-length `166`.
The MSI replay in the attached artifact reconstructs all `4,612` full-family
rows, checks the source-family counts `(200,2980,1432)`, and verifies these
values without constructing a dense regular representation.

The row cannot authenticate a common multiplicity reservoir. Let
`V_1,V_2,V_3` be arbitrary finite-dimensional spaces over `F_2`, and choose
arbitrary maps

```text
a:V_2 -> V_1,              b:V_2 -> V_3.
```

On `V_1 direct_sum V_2 direct_sum V_3` put

```text
X=1+iota_1 a p_2,          Y=1+iota_3 b p_2.          (FMR2)
```

Both are involutions. Moreover

```text
(iota_1 a p_2)(iota_3 b p_2)=0
=(iota_3 b p_2)(iota_1 a p_2),                        (FMR3)
```

because `p_2 iota_1=p_2 iota_3=0`. Thus `[X,Y]=1`
exactly, for arbitrary and unequal target dimensions. Passing to the left
regular representation of the finite group generated by `X,Y` gives an
exact unitary permutation model with canonical trace on every nonidentity
element of that group.

The same calculation is coefficient-blind. In any finite prefix or
Schrodinger-window realization, replace `a,b` by the actual truncated
coefficient maps labelled by `e`; `(FMR3)` remains exact because it uses only
the rank-five matrix-unit indices. Consequently adjoining `(FMR1)` to the
coherent ultra-deep tower costs zero defect and places no equality, Gram, or
rank constraint between `V_1` and `V_3`.

This is not a model of all `4,648` packet words. It closes only the proposed
use of the first literal non-scalar mixed-direction row. The remaining Atlas
gate must use a coupled family whose effect survives the automatic
same-source/same-target Steinberg identities; merely selecting the first
mixed row does not supply the same-reservoir covariance.

Let `W_5=A5^(G/Gamma) semidirect G` for the pinned Kun--Thom pair.  If
`W_5` were hyperlinear, canonical microstates would exist.  The two-site
classicalization claim would turn them into a two-point approximation at
`(Gamma,hGamma)`, using the fixed `35/72` separating center carrier.
This contradicts `two-point-approximation-fails`.

Hence `W_5` is non-hyperlinear.  It is finitely generated because `G` is
finitely generated, the site action is transitive, and one copy of a finite
generating set of `A5` normally generates all lamp coordinates.  The
embedded binary Kun--Thom wreath also certifies that the chosen group is the
same explicit nonsofic lamp family already pinned in Cairn.

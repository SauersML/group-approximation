Notation is that of the target. Let `P_n = W_n W_n^*`, let `S` be the finite generating set,
and let `M = prod_n M_{k_n} / sum_n M_{k_n}`.

## Step 1. The compression is a *-homomorphism on C*(U) + K

Let `C = C*(U_s : s in S) + K(H)`, and define `Psi(x) = [ (W_n^* x W_n)_n ] in M`.

- **Linearity and units.** `Psi` is linear, contractive and *-preserving, and
  `Psi(1) = 1` because `W_n^* W_n = 1`.
- **Multiplicativity.** `W_n^* x y W_n - W_n^* x W_n W_n^* y W_n = W_n^* x (1 - P_n) y W_n`.
  The set `D = { y : ||[P_n, y]|| -> 0 }` is a C*-algebra, and by hypothesis it contains
  every `U_s` and `U_s^*`. For `y in D`, `(1 - P_n) y W_n = (1 - P_n) y P_n W_n` has norm at
  most `||[P_n, y]||`, which tends to 0. So `Psi(xy) = Psi(x) Psi(y)` for every `x` and every
  `y in C*(U)`.
- **Compacts.** For compact `k`, `P_n -> 0` strongly gives `||k P_n|| -> 0` and
  `||P_n k|| -> 0`. So `Psi(xk) = 0 = Psi(x)Psi(k)`, `Psi(kx) = 0 = Psi(k)Psi(x)`, and
  `Psi(k) = 0`.

So `Psi` is a unital *-homomorphism on `C` that vanishes on `K`.

## Step 2. It descends to theta(O_2)

`C/K` is the C*-algebra generated by the images `rho(s)`. Since `S` generates `V`, it equals
`C*(rho(V)) = theta(C*(u_V))`, and `thompson-v-unitaries-generate-cuntz-algebra` gives
`theta(C*(u_V)) = theta(O_2)`. So `Psi` induces a unital *-homomorphism
`psi : theta(O_2) -> M`.

## Step 3. M has no infinite projection, in particular not 1

Suppose `w in M` with `w^* w = 1`.

1. **Lift.** Lift `w` to a sequence `(w_n)`. Then `||w_n^* w_n - 1_{k_n}|| -> 0`.
2. **Finite dimension.** In `M_{k_n}`, the matrices `w_n^* w_n` and `w_n w_n^*` have the
   same eigenvalues with multiplicity.
3. **Conclusion.** So `||w_n w_n^* - 1|| = ||w_n^* w_n - 1|| -> 0`, and `w w^* = 1`.

## Step 4. Contradiction

Put `T_i = psi(theta(s_i))`. Then `T_0^* T_0 = 1 = T_1^* T_1` and
`T_0 T_0^* + T_1 T_1^* = 1`.

By Step 3, `T_0 T_0^* = 1`, so `T_1 T_1^* = 0` and `T_1 = 0`. This contradicts
`T_1^* T_1 = 1`, since `M != 0` (take `k_n >= 1`). So no matrix compression exists.

## The two named members

- **Tree near-permutations.** `pi_g - sum_k S_{q_k} S_{p_k}^*` is finite rank, and
  `(S_0, S_1)` on `l^2(X*)` is a Cuntz family modulo the rank-one vacuum projection. So the
  tree near-permutations are a lift of the Cuntz-type Calkin model with `theta` induced by
  `(S_0 + K, S_1 + K)`.
- **Quasidiagonal lifts.** Suppose finite-rank projections `P_m` increase to `1` and
  asymptotically commute with the lifts. Then any blocks `P_{m'} - P_m` with `m -> infinity`
  and `rank > 0` form a matrix compression.
- **Both are excluded.** QED.

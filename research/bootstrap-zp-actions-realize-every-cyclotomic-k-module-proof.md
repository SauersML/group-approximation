* **§2.3.**  `C_p` is the mapping cone of the unital equivariant embedding
  `C → C(Z/p)`, the generator set is `C^(Z/p) = {C_p, C, C(Z/p)}`, and
  `K_p = KK^(Z/p)(C_p ⊕ C ⊕ C(Z/p), C_p ⊕ C ⊕ C(Z/p))`.
* **Theorem 2.7** ([7, Theorem 5.10]).  `K_p` is generated by idempotents `1_j`
  and edges `α_jk` (`j ≠ k` in `{0,1,2}`) subject to:
  - `α_jk α_km = 0` whenever `{j,k,m} = {0,1,2}`;
  - `α_01 α_10 = N(1_0 − α_02 α_20)` and `α_10 α_01 = N(1_1 − α_12 α_21)`;
  - `p · 1_2 = N(1_2 − α_20 α_02) + N(1_2 − α_21 α_12)`;

  where `N(t) = 1 + t + ⋯ + t^(p−1)`, `α_12` and `α_21` are odd, and
  `t_0, s_1, t_2, s_2` are the named elements `1 − α α`.
* **Definition 2.8.**  A module is exact if the two cyclic sequences around the
  triangle `M_0, M_1, M_2`, with `α_jk : M_k → M_j`, are exact.
* **Theorem 2.9** ([6]).  For a countable Z/2-graded `K_p`-module `M`, the
  following are equivalent: `M = U(A)` for some `A` in `B^(Z/p)`; `M = U(A)`
  for some `A` in `KK^(Z/p)`; `M` is exact; `M` has a length-one projective
  resolution.
* **Theorem 2.10** ([6]).  For `A ∈ B^(Z/p)` and any separable `C` there is a
  natural exact sequence
  `Ext^1_(K_p)(U(ΣA), U(C)) ↣ KK^(Z/p)(A, C) ↠ Hom_(K_p)(U(A), U(C))`.
* **Proposition 5.1**, one prime.  If one of `Q_0, Q_1, Q_2` is uniquely
  `p`-divisible, all are, and
  `Q = Q(A_X, A_Y, A_Z)` with `Q_0 = A_X ⊕ A_Y`, `Q_1 = A_X ⊕ A_Z`,
  `Q_2 = A_Y ⊕ ΣA_Z`.  Here `A_X` is a `Z[1/p]`-module and `A_Y, A_Z` are
  `Z[1/p, ϑ_p]`-modules.  In this form `α_12 = (1 − ϑ_p)` on `A_Z`, `α_21 = 1`
  on `A_Z`, `N(t_0) = diag(p, 0)` and `N(s_1) = diag(p, 0)`.

**Index bookkeeping.**  `End(C(Z/p)) = K_0(C(Z/p))` has rank `p`, and the
relation `p · 1_2 = N(t_2) + N(s_2)` cannot hold in `Z[G]`.  So vertex 2 is
`C_p`.  Vertices 0 and 1 are `C(Z/p)` and `C`, whose components are
`K_*(Res A)` and `K_*(A ⋊ G)`; the relations `α_01 α_10 = N(t_0)` and
`α_10 α_01 = N(s_1)` identify the translation norm and the regular
representation.  The argument below is symmetric under exchanging the labels
of vertices 0 and 1, so the conclusion does not depend on which is which.
Write it with `M_0 = K_*(Res A)` and `M_1 = K_*(A ⋊ G)`.

**Item 1.**  `U(A)` is exact for every separable `A` (Theorem 2.9, (2) ⟹ (3)).
`Q_0 = 0` is uniquely `p`-divisible, so Proposition 5.1 applies, and
`A_X = A_Y = 0`.  Then `Q_1 = A_Z` is an `O`-module with `s_1` acting as `ϑ_p`,
and `Q_2 = ΣA_Z`.

**Item 2.**  Given `M`, define `Q_0 = 0`, `Q_1 = M`, `Q_2 = ΣM`,
`α_12 = 1 − ϑ` and `α_21 = 1`, with all edges touching vertex 0 zero.  The
relations of Theorem 2.7 hold:
- `s_1 = 1 − α_12 α_21 = ϑ`, `s_2 = ϑ`, `t_2 = 1`, and `t_0 = 1` on `0`;
- `α_10 α_01 = N(s_1) = N(ϑ) = 0`, which matches because both factors are zero;
- `p · 1_2 = N(1) + N(ϑ) = p + 0`;
- all products `α_jk α_km` with `{j,k,m} = {0,1,2}` vanish.

For exactness, one cycle needs `α_12 : M_2 → M_1` bijective, which holds because
`1 − ϑ` is a unit of `O`.  The other needs `α_21` bijective, which holds.  So `Q`
is exact, and Theorem 2.9 (3) ⟹ (1) gives `A ∈ B^G` with `U(A) = Q`.  `Res A`
is KK-equivalent to a type I algebra with `K_* = Q_0 = 0`, so `Res A ≃ 0`.

**Item 3.**  `U(O_2, α) = Q(0, 0, M)` with `M = K_*(O_2 ⋊_α G)`, by item 1.
Take `A` from item 2 with the same `M`.  Theorem 2.10 lifts the isomorphism to
`x ∈ KK^G(A, (O_2, α))`.
- If `x` is invertible, the action is in `B^G`.
- Conversely, suppose `(O_2, α) ∈ B^G`.  The cone `D` of `x` lies in `B^G` and
  has `U(D) = 0`, by the long exact sequence and the five lemma.  Theorem 2.10
  gives `KK^G(D, D) = 0`, so `x` is invertible.
- For any action, the cone `D` has `Res D ≃ 0` and `U(D) = 0`.

**Not claimed.**  Whether a UCT crossed product `O_2 ⋊_α Z_p` forces
`(O_2, α) ∈ B^G` was not settled.  That would need `B^G` to be detected by
restriction and crossed product together.

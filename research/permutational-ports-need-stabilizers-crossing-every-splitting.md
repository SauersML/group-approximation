## Setting

- A group `D` acts by isometries on a geodesic hyperbolic space `Y`. The action is of *general type*
  if `D` contains two loxodromics with disjoint fixed pairs.
- `Λ(·)` is the limit set: the accumulation set in `∂Y` of one, hence every, orbit.
- `D` also acts on a set `X`. For `x ∈ X`, `D_x` is the stabilizer. A subgroup `C ≤ D` is
  *cofinite on `D·x`* if it has finitely many orbits there, that is, if `C\D/D_x` is finite.
- The *Houghton-port criterion* is `cofinite-abelian-subgroups-give-relative-pbh`, item 2. It asks for
  a finitely presented `D` with a faithful action with finitely generated stabilizers, on which some
  `A ≅ Z^n` is cofinite. It yields relative PBH for `D` and all its subgroups.

## Theorem

1. **Cofinite-subgroup lemma.** Let `C ≤ D` be cofinite on `D·x`, and suppose `D_x` has a bounded
   orbit in `Y`. Then some `C`-orbit is coarsely dense in a `D`-orbit, and `Λ(D) = Λ(C)`.
2. **Virtually abelian ports.** If `C` is virtually abelian, then `|Λ(C)| <= 2`. So if `D ↷ Y` is of
   general type and `C` is cofinite on `D·x`, then `D_x` has unbounded orbits in `Y`.
3. **Trees.** Let `D ↷ Y` be of general type with `Y` a simplicial tree, for example the Bass–Serre
   tree of a non-ascending HNN extension or of a nontrivial amalgam with non-elementary tree action.
   In item 2, if `D_x` is finitely generated, it contains an element that is hyperbolic on `Y`.
   In particular, `D_x` lies in no conjugate of a vertex group.
4. **What the port criterion cannot use.** Let `D` satisfy the Houghton-port criterion, and let `D`
   have a general-type action on a tree `Y`. Then the port action `D ↷ X` is none of the following:
   - (a) the action on cosets of a subgroup of a vertex group;
   - (b) an action induced from any action of a vertex group, whose stabilizers lie in conjugates of
     that vertex group;
   - (c) the vertex action on `Y`, whether or not `Y` is locally finite.

   The same holds for type (A) actions, by `type-a-stabilizers-are-hyperbolically-full`.
5. **Osajda's input.** Let `G` be the decidable non-exact group of
   `decidable-residually-finite-non-exact-group-exists`.
   - (a) `G` is infinitely presented. So `G` has no type (A) action, and it cannot itself be the `D`
     of the port criterion.
   - (b) Every orbit and stabilizer condition except finite presentation is free. `FSym(G) ⋊ G`, with
     `G` acting on itself, is generated by `G` and the transpositions `(1 s)` for `s` in a finite
     generating set. It acts faithfully, with one orbit on two-element subsets, and its stabilizers
     are finitely generated by `fp-finitary-permutation-overgroups-are-type-a-actors`, item 2. It is
     not finitely presented: `FSym(G)` is the normal closure of one transposition, so a finite
     presentation would give one of `G`. (Compare `lampshuffler-groups-are-not-fp2-over-q`.)
   - (c) Let `H` be a Higman–Clapham envelope of `G`, which is an HNN extension over machine × input
     (`higman-clapham-envelopes-are-hnn-over-machine-times-input`). Suppose its Bass–Serre action is
     of general type, as it is when the associated subgroups are proper in the base. Then every port
     action and every type (A) action of `H` has stabilizers containing elements that are hyperbolic
     on the Bass–Serre tree, that is, not conjugate into the base `K × G`. The same holds for any
     finitely presented `D ⊇ G` and any general-type action of `D` on a tree. So no action of `G`,
     and no action of the base, pulls up to a port.

## Proof

1. Write `D = ⋃_{i<=k} C g_i D_x`, and let `D_x·y ⊆ B(y, r)`. Then
   `D·y = ⋃_i C g_i D_x y ⊆ ⋃_i N_r(C g_i y)`. Also `d(c g_i y, c y) = d(g_i y, y)`. So
   `D·y ⊆ N_R(C·y)` with `R = r + max_i d(g_i y, y)`. Coarsely equal orbits have equal accumulation
   sets. ∎
2. Pass to a finite-index abelian subgroup `A`. It has the same limit set, since orbits are coarsely
   equal.
   - **If `A` has a loxodromic `a`.** Every `b ∈ A` satisfies `b a b^(-1) = a`, so `b` preserves
     `{a^+, a^-}`.
     - `b` maps a quasi-axis `ℓ` of `a` to a quasi-geodesic with the same constants and the same
       endpoints. By the Morse lemma that quasi-geodesic lies in `N_M(ℓ)`, with `M` uniform in `b`.
     - So `A·y ⊆ N_(M')(ℓ)` for `y ∈ ℓ`, and `Λ(A) = {a^±}`.
   - **If `A` has no loxodromic.** Then `A` has bounded orbits or is horocyclic, with at most one limit
     point (Gromov's classification of actions on hyperbolic spaces, recalled).
   - Now a general-type `D` has infinite `Λ(D)`. By item 1, `D_x` cannot have a bounded orbit. ∎
3. A finitely generated group acting on a tree without hyperbolic elements has a global fixed point
   (Serre, *Trees*, I.6.5, recalled). So item 2 forces a hyperbolic element in `D_x`. Vertex groups
   fix vertices. ∎
4. In (a) and (b) the stabilizers fix vertices of `Y`, and in (c) they are vertex stabilizers. Item 3
   excludes all three, since port actions have finitely generated stabilizers by hypothesis. ∎
5. (a) The definitions. (b) `FSym(G)` is generated by transpositions along the edges of any connected
   graph on `G`, and the Cayley graph is one. The cited node gives the stabilizers. (c) Item 3, with
   `Y` the Bass–Serre tree of `H`, or the given tree of `D`. ∎

## What the permutational route needs at a non-exact input

The ladder for a non-exact decidable input `G`, with the status of each rung:
- **Necessary conditions known on main:** solvable word problem. It holds for Osajda's group. No
  exactness, (RA), entropy or residual-finiteness obstruction is inherited by subgroups of type (A)
  actors (`ra-counterexamples-are-minimal-sets-of-rigid-ambients`, item 5).
- **Relative PBH:** `G ≤ D` finitely presented with a Houghton port faithful on `G`
  (`cofinite-abelian-subgroups-give-relative-pbh`). By item 5(c), `D`'s port stabilizers must cross
  every general-type splitting of `D`.
- **PBH:** kernel removal (`a2-kernel-removable-iff-image-in-type-a2-actor`), or a type (A) action
  directly. Its stabilizers are hyperbolically full (`type-a-stabilizers-are-hyperbolically-full`).
- **Payoff:** `SV_D` is a finitely presented simple non-exact group (`fp-simple-nonexact-group`), and
  the exactness separator's (S1) fails.

No rung is known for Osajda's group, and no rung is obstructed.

## Lesson for general BH

**On the permutational route, orbit conditions are free and only finite presentation costs anything.
That finite presentation cannot be bought from a splitting.**
- Every finitely generated group already lies in a finitely generated group with a faithful, highly
  transitive action with finitely generated stabilizers (item 5(b)).
- A Higman embedding makes the group finitely presented by an HNN extension. In both permutational
  criteria, type (A) and Houghton ports, the stabilizers must then contain elements hyperbolic on
  that HNN's tree.
- So the port has to be built *through the Higman machinery*, never pulled up from the input or its
  base.

Non-exactness plays no role in any of this. At Osajda's input the permutational route is exactly as
hard as for an exact input. It is obstructed only where every input is: a finitely presented
overgroup whose permutation stabilizers see the stable letter.

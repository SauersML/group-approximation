title: A relative Leavitt common-source cell still needs one same-reservoir scalar
---

Relative Leavitt arrows give a clean formal syntax for four context maps
with one source.  A finite root decoder, however, can realize all one-level
coefficient tables while trading label dimension against multiplicity.

Consequently the construction still needs the same selected-source
saturation scalar as the HNN formulation; finite root Fourier tables alone
do not decode actual common-source partial isometries.

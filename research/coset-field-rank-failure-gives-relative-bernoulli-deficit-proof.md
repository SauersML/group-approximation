Lemma numbers refer to the artifact of `bernoulli-field-rank-failure-gives-rokhlin-deficit`. There the variables
are indexed by `G`. Here they are indexed by `H = G/Γ`, with `(gω)(c) = ω(g^{-1}c)` on `Ω_H = (F_Q^m)^H`.

1. **Finite coefficients.** Lemma 1 uses only that `σ_g` renames variables and preserves coefficients and
   degrees, which is true on `H`. It gives `AB = I_d` over `K_H(F_(q_0)) ⋊ G`, with nonzero denominators, for
   some finite `F_(q_0)`. Let `𝒟` and `C = Σ_(D ∈ 𝒟) deg D` be as there. Take `Q` a power of `q_0`.
2. **Covariance on `H`.** `σ_g(x_(c,i))(ω) = ω_i(gc) = (g^{-1}ω)_i(c) = x_(c,i)(g^{-1}ω)`. So
   `σ_g(f)(ω) = f(g^{-1}ω)`, and `σ_g(f)` is defined at `ω` iff `f` is defined at `g^{-1}ω`, as in Section 2.
   Define `(π_ω(a u_g)ξ)(h) = a(h^{-1}ω) ξ(hg)` on `ξ ∈ (F_Q^G)^n`, with `h, g ∈ G` and `ω ∈ Ω_H`.
3. **Lemmas 2 and 3 hold verbatim.** Their proofs use only the covariance identity and that evaluation is a
   ring homomorphism where the finitely many fractions are defined. So `π_(kω)(M)(kξ) = k(π_ω(M)ξ)`, and with
   `Z = {ω ∈ Ω_H : D(ω) = 0 for some D ∈ 𝒟}` and `D_ω = {h ∈ G : h^{-1}ω ∈ Z}`, we get
   `(π_ω(A)π_ω(B)ξ)(h) = ξ(h)` for `h ∉ D_ω`.
4. **Lemma 4 holds.** The coordinates `ω_i(c)` are iid uniform on `F_Q` over distinct pairs `(c, i)`, so
   Schwartz–Zippel gives `μ(Z) <= C/Q`.
5. **Relative partition.** On `X' = (F_Q^d)^G × Ω_H` with `x = (ξ, ω)`, put `η_x = π_ω(B)ξ` and the label
   `ℓ(x) = (η_x(1), ζ(x))`, with `ζ = ξ(1)` if `1 ∈ D_ω` and `ζ = *` otherwise. There is no point coordinate.
   Let `F = B(Ω_H)`.
   - **Generates relative to `F`.** `ω` is `F`-measurable, hence so is `D_ω`. The labels `ℓ(h^{-1}x)` give
     `η_x` everywhere and `ξ` on `D_ω`, as in Lemma 5. Off `D_ω`, `ξ(h) = (π_ω(A)η_x)(h)` by step 3. So
     `x ↦ ((ℓ(h^{-1}x))_h, ω)` is injective and Borel, and `σ(G·P) ∨ F` is everything.
   - **Entropy.** `H(P | F) <= H(η(1)) + H(ζ | F)`. The first term is at most `r log Q`. Given `F`, `ζ` is the
     constant `*` off the `F`-measurable event `{1 ∈ D_ω}` = `{ω ∈ Z}`, and takes at most `Q^d` values on it.
     So `H(ζ | F) <= μ(Z) d log Q <= (Cd/Q) log Q`.
   - So `h_G(X' | F) <= r log Q + (Cd/Q) log Q`. `X'` is ergodic, as a mixing action times the generalized
     Bernoulli action over the infinite transitive `H`. ∎ (Theorem)
6. **Corollary 1.**
   - `G` is residually finite (`kun-thom-free-nonsofic-action`), hence sofic. So
     `h_G(X_(Q,d)) = d log Q` by the sofic item of `seward-per-group-rokhlin-entropy-of-bernoulli-shifts`.
   - **Freeness of `Y`.** When `gcd(r_KT, ℓ - 1) = 1`, the kernel `Z_ℓ` is trivial. By items 1–3 of
     `kt-coset-bernoulli-essentially-free`, each `g ≠ 1` moves infinitely many cosets. Choose cosets `c_j` with
     the pairs `{c_j, g c_j}` pairwise disjoint and `g c_j ≠ c_j`. Then `gω = ω` forces `ω(gc_j) = ω(c_j)` for
     all `j`. These are independent events of probability `Q^(-m) < 1`. So `Fix(g)` is null and `Y` is
     essentially free.
7. **Corollary 2.** `X'` is free (Bernoulli factor) and ergodic, and `Γ` is infinite. By
   `infinite-subgroup-invariant-information-has-zero-outer-entropy`, `h^Rok_G(X') = h_G(X' | F_Γ)`, where `F_Γ` is
   generated by the `Γ`-invariant sets. The coordinate `ω(Γ)` is `Γ`-invariant and its translates generate
   `B(Ω_H)`, so `B(Ω_H) ⊆ F_Γ`. Relative entropy decreases as the factor grows, so
   `h^Rok_G(X') <= h_G(X' | B(Ω_H)) < d log Q`.
8. **Corollary 3.** Suppose `char k = 0`.
   - A rank failure involves finitely many coefficients, so it already occurs over a finitely generated
     subfield `k_0 ⊆ k`, which embeds in `C`.
   - Take `z_(c,i)` iid, for example uniform on the unit disc. Every nonzero polynomial over the countable field
     `k_0` vanishes on a null set, so a.s. the `z_(c,i)` are algebraically independent over `k_0`. They define
     an embedding `K_H(k_0) -> C`.
   - The law of this embedding is `G`-invariant, since `G` permutes the iid coordinates. Its restriction to
     the coefficient field `K_0` is an invariant probability measure on `Emb(K_0, C)`.
   - Survival case (c) then gives the rank condition, a contradiction. ∎

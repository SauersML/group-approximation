## Setting

- `Gamma` is a finite directed graph in which every vertex has out-degree at
  least two. For a vertex `t`, `C_t` is the space of infinite directed paths
  starting at `t`. The ambient space `X` is the disjoint union of `C_r` over a
  finite set of root vertices `r`.
- For a finite path `u` from a root, `C_u` is the cone of paths beginning with
  `u`, `t(u)` is its terminal vertex, and `beta_u: C_(t(u)) -> C_u` is
  `zeta -> u zeta`. The same notation is used for paths starting at any vertex.
- An **eventually self-similar groupoid** is a set `H` of homeomorphisms
  `n: C_s -> C_t` between vertex spaces that contains every identity and is
  closed under composition and inverses, such that for each `n` there is `D_n`
  with the following property: for every path `z` from `s` with `|z| >= D_n`,
  `n(C_z)` is a cone `C_(z')` and `beta_(z')^-1 o n o beta_z` lies in `H`.
  The **vertex group** `H_s` is the set of elements `C_s -> C_s`.
- A group `G <= Homeo(X)` is **eventually H-similar** if each `f` in `G` has a
  depth `D_f` such that for every path `u` from a root with `|u| >= D_f`,
  `f(C_u)` is a cone `C_v` and `beta_v^-1 o f o beta_u` lies in `H`.

## Statement

Let `G` be eventually `H`-similar, and let `K <= G` have property FW (every
commensurated subset of every `K`-set is transfixed). Property (T) implies FW.

1. **Virtual embedding.** Some finite-index subgroup `K_0 <= K` embeds in a
   finite product `H_(s_1) x ... x H_(s_m)` of vertex groups.
2. **Canonical similarities.** If `H` consists of identity maps only, so that
   `G` acts by canonical similarities `u zeta -> v zeta` on all deep cones (the
   Thompson group of the shift of finite type, including the Higman--Thompson
   groups `V_(d,r)`), then `K` is finite.
3. **Synchronous groupoids.** If every `n` in `H` maps each cone `C_z` onto a
   cone `C_(z')` with `|z'| = |z|`, then every vertex group is residually
   finite, so `K` is residually finite.

## Consequences

- Part 3 with one vertex and `d` loops, `H` a self-similar group of tree
  automorphisms, recovers `kazhdan-subgroups-of-rover-nekrashevych-groups-are-rf`.
- A non-residually-finite group with property (T), such as the lattice of
  `deligne-universal-cover-lattice-is-non-rf-kazhdan`, embeds in an eventually
  `H`-similar group only if some vertex group of `H` is not residually finite.
  In particular the local groupoid cannot be synchronous.
- An infinite group with property (T) embeds in no group of part 2.

## Rational similarity groups

For a rational similarity group `S` in the sense of Belk--Bleak--Matucci--Zaremsky
(arXiv:2309.06224), all but finitely many local actions of each element lie in the
nucleus `Nuc_S`.
- **When the argument applies.** Suppose every node of `Γ` has out-degree at least
  two, and every nuclear element is surjective onto its target cone space. Identify
  the clopen set `E` with a finite disjoint union of vertex spaces through a cone
  partition.
  - Deep cones then go onto cones.
  - The source's closure properties LocNuc, InvNuc and ProdNuc make the maps
    generated by the nucleus an eventually self-similar groupoid.
  - Part 1 applies with `H` that groupoid.
- **Full shift, surjective nucleus.** Over the full shift on `d` letters, each
  nuclear element permutes the child cones, because a complete prefix code of size
  `d` is the set of letters. So the nucleus generates a self-similar group of tree
  automorphisms and `S` lies in its Rover--Nekrashevych group.
- **Where the argument breaks.** Nuclear elements need not be surjective. The
  source says, at TeX line 844, "the elements of `Nuc` might not even be
  invertible". When one is not, infinitely many deep cones go onto clopen sets
  that are not cones, and the cone markings are not commensurated.
- **This break is forced.** `rsg-kazhdan-rf-obstruction-implies-hyperbolic-rf`
  shows that residual finiteness of Kazhdan subgroups of contracting rational
  similarity groups would settle Gromov's question.

## Scope

Nothing here assumes contraction, finite generation of `H`, or a finite
presentation. What the argument cannot reach is a group whose elements send
infinitely many deep cones to clopen sets that are not cones, and a groupoid
whose vertex groups are not residually finite. Details are in the linked
artifact. No novelty is claimed; the commensurated-set method is Cornulier's.

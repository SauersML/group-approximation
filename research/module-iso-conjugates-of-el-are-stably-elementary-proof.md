Put `A = diag(X, 1) ∈ M_{(N+1)×(M+1)}(R)` and `B = diag(Y, 1) ∈ M_{(M+1)×(N+1)}(R)`. Then `AB = 1_{N+1}` and
`BA = 1_{M+1}`, so `Ψ(h) = AhB` is a group isomorphism `GL_{M+1}(R) → GL_{N+1}(R)`. For `g ∈ GL_M(R)`,
`Ψ(diag(g,1)) = diag(XgY, 1)`.

Let `c = M+1` and `c' = N+1` be the free indices. Write `x_ki` for the entries of `X`, `y_ik` for those of `Y`, and
`E_ab` for matrix units.
1. For `i ≤ M`, column `i` of `A` is `Σ_{k≤N} E_{k1}x_ki` (supported on rows `1..N`), and column `c` of `A` is `e_{c'}`.
   Row `i` of `B` is `Σ_k y_ik E_{1k}` (supported on columns `1..N`), and row `c` of `B` is `e_{c'}^T`. Hence
   ```text
   Ψ(e_{ic}(r)) = 1 + Σ_{k≤N} E_{kc'} x_ki r = Π_{k≤N} e_{kc'}(x_ki r),
   Ψ(e_{ci}(r)) = 1 + Σ_{k≤N} E_{c'k} r y_ik = Π_{k≤N} e_{c'k}(r y_ik).
   ```
   The factors of each product commute: they share the column `c'`, respectively the row `c'`, and `k ≠ c'`. So both
   lie in `EL_{N+1}(R)`.
2. For distinct `i, j ≤ M`, `e_ij(r) = [e_{ic}(r), e_{cj}(1)]` in `EL_{M+1}(R)`. So
   `Ψ(e_ij(r)) = [Ψ(e_ic(r)), Ψ(e_cj(1))] ∈ EL_{N+1}(R)`.
3. `EL_M(R)` is generated by the `e_ij(r)` with `i ≠ j ≤ M`, and `diag(e_ij(r), 1) = e_ij(r) ∈ EL_{M+1}(R)`. So
   `diag(XgY,1) = Ψ(diag(g,1)) ∈ EL_{N+1}(R)` for all `g ∈ EL_M(R)`. ∎

This is step (3) of the proof of `non-ibn-ring-el-n-full-mf-radical-above-module-rank` (un-middle), stated on its own
for an arbitrary isomorphism, with no use of IBN failure.

Model tests:
- `M = N`, `X = Y = 1`: the lemma says `diag(g,1) ∈ EL_{N+1}`. Correct.
- `R = L_K(1,2)`, `N = 1`, `M = 2`, `X = (s_1 s_2)`: `diag(1 + s_1 r t_2, 1) ∈ EL_2`, although `1 + s_1 r t_2` is not
  in the trivial group `EL_1`. So the stabilization is genuinely needed.

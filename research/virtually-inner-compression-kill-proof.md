## Why sufficient

Notation as in the target.  Write `iota: T -> prod_omega M_(N_k)(F_k)` for the
injective unital ring homomorphism.  Choose representatives
`iota(t) = [phi_k(t)]_k` with `phi_k(1) = 1` and `phi_k(0) = 0`.

**Step 0 (finite exact models).**  Let `F` be a finite subset of `T` and `E`
a finite list of relations `a + b = c` or `a b = c` with `a, b, c in F`, all
holding in `T`.  Since `iota` is a ring homomorphism, each relation of `E`
holds for `phi_k` on an `omega`-large set of `k`.  Since `iota` is injective,
each pair `a != b` in `F` has `phi_k(a) != phi_k(b)` on an `omega`-large set.
Finitely many `omega`-large sets intersect in an `omega`-large set, so some
`k` does all of this at once.  Fix such a `k` and write `phi = phi_k`,
`M = M_N(F)`.

**Step 1 (the chain).**  From `sigma(R) <= R` we get `R <= sigma^{-1}(R)`, and
applying `sigma^{-1}` repeatedly,

```text
R <= sigma^{-1}(R) <= sigma^{-2}(R) <= ... <= sigma^{-m}(R) = v^{-1} R v.
```

Also `sigma^m(R) <= R`, that is `v R v^{-1} <= R`.  It is enough to prove that
`z` commutes with every element of `v^{-1} R v`: that contains
`sigma^{-j}(R)` for `0 <= j <= m`.  For larger `j`, replace `m` by a multiple
`m' = m l >= j`, using `sigma^{m l} = Ad(v^l)` on `S`.

**Step 2 (the finite subset).**  Suppose, for contradiction, that
`b = v^{-1} a v` with `a in R` and `z b != b z`.  Let `r_1, ..., r_n`
generate `R` as a unital ring.  Each element of `R` is the value of a
noncommutative integer polynomial in the `r_i`.  Fix polynomials `p_i` and
`p_0` with

```text
v r_i v^{-1} = p_i(r_1, ..., r_n)   (1 <= i <= n),     a = p_0(r_1, ..., r_n).
```

Let `F` contain `0, 1, -1, v, v^{-1}, z, a, b, zb, bz`, every `r_i`, `z r_i`,
`v r_i`, `v r_i v^{-1}`, `v^{-1} a`, and every intermediate value in a fixed
evaluation of the `p_i` and `p_0` by sums and products.  Here `(x)` denotes
the element `x` of `F`.  Let `E` be the relations recording these
evaluations, together with

```text
v v^{-1} = 1,   v^{-1} v = 1,   z r_i = (z r_i),   r_i z = (z r_i),
v r_i = (v r_i),   (v r_i) v^{-1} = p_i(r),   v^{-1} a = (v^{-1} a),
(v^{-1} a) v = b,   z b = (zb),   b z = (bz),
```

Apply Step 0 and require in addition `phi(zb) != phi(bz)`, which is a pair of
distinct elements of `F`.

**Step 3 (dimension).**  Let `A <= M` be the unital `F`-subalgebra generated by
`phi(r_1), ..., phi(r_n)`.  Put `V = phi(v)`.  The relations give
`V phi(v^{-1}) = 1 = phi(v^{-1}) V`, so `V` is invertible with
`V^{-1} = phi(v^{-1})`.  They also give

```text
V phi(r_i) V^{-1} = p_i(phi(r_1), ..., phi(r_n))  in A.
```

`Ad(V)` is an `F`-algebra automorphism of `M`, so it maps the algebra generated
by the `phi(r_i)` into `A`: `V A V^{-1} <= A`.  Both sides have the same finite
`F`-dimension, so `V A V^{-1} = A` and hence `V^{-1} A V = A`.

**Step 4 (contradiction).**  `phi(a) = p_0(phi(r))` lies in `A`, so
`phi(b) = V^{-1} phi(a) V` lies in `A`.  `phi(z)` commutes with every
`phi(r_i)`, hence with the algebra `A` they generate, hence with `phi(b)`.
Therefore

```text
phi(zb) = phi(z) phi(b) = phi(b) phi(z) = phi(bz),
```

which contradicts `phi(zb) != phi(bz)`.  So `z` commutes with `v^{-1} R v`.

## Why each step is needed

- Step 1 turns the one-sided compression `sigma(R) <= R` into a statement
  about a single conjugation, so that no model of `sigma` itself is needed.
- Step 3 is the only place where approximation enters, and only through the
  finite dimension of `A`.  In an infinite dimensional overring the inclusion
  `v R v^{-1} <= R` can be proper, which is exactly what (G2) wants.

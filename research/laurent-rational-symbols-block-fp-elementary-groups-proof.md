Lane proof (gq-deep-adelic-1), not independently reviewed. The notation is that of the target.

## (a) The boundary map

- **The fibration.** By ABC Theorem 3.6, crossed-product case (Step 1, as quoted in
  `abc-twisted-laurent-k-theory-fibration`),
  `K(R) ≃ NK_+ ⊕ NK_- ⊕ hocofiber(1 - σ_* : K(B) -> K(B))`.
  This holds for any unital ring `B`. The ring `B ⊗ Z = B` is unital, hence H-unital.
- **The map ∂.** Project onto the last summand, then compose with the connecting map
  `hocofiber -> ΣK(B)`. This gives a homomorphism `∂_B : K_2(R) -> K_1(B)` with image in
  `ker(1 - σ_*)`.
- **Naturality.** `∂` is natural for maps of pairs `(B, σ) -> (B', σ')`, that is, ring
  homomorphisms intertwining the automorphisms. The fibration is functorial in the pair; this was
  not re-read at the source.

## (b) The untwisted model

- For `(Q, id)` the ring is `Q[u, u^(-1)]`.
- `Q` is regular, so `NK(Q) = 0` (Lemma 7.2 of the cited node, with `α = id`).
- The decomposition is then the Bass–Heller–Swan splitting
  `K_2(Q[u^(±1)]) = K_2(Q) ⊕ K_1(Q)`, under which `∂{λ, u} = [λ]` up to a universal sign. This is
  the standard computation of the boundary on symbols (Milnor, *Introduction to Algebraic
  K-Theory*; Weibel, *The K-book*, III.4). It was not re-read.

## (c) Transport to R

- `σ` fixes `Q`, so `λ ↦ λ`, `u ↦ u` is a unital ring map `Q[u^(±1)] -> R`. It is a map of pairs
  `(Q, id) -> (B, σ)`.
- It sends the symbol `{λ, u}` to the symbol `{λ, u}_R`. Symbols are natural for ring maps.
- By naturality of `∂`, `∂_B {λ, u}_R = ±[λ]_B`, the image of `λ` under `K_1(Q) -> K_1(B)`.
- So the subgroup of `K_2(R)` generated by the `{λ, u}_R` maps onto the image of `Q^x` in
  `K_1(B)`. By hypothesis that image is not finitely generated, so neither is the subgroup. This is
  part 1.
- **Commutative bases.** For commutative `B`, `det : K_1(B) -> B^x` is a homomorphism with
  `det[λ] = λ`. So the image of `Q^x` in `K_1(B)` maps onto `Q^x`, and it is not finitely
  generated.

## (d) Symbols at finite rank

- For commuting units `a, b` and `N >= 2`, let
  - `w_12(a) = x_12(a) x_21(-a^(-1)) x_12(a)`,
  - `h_12(a) = w_12(a) w_12(-1)`,
  - `{a, b}_N = h_12(ab) h_12(a)^(-1) h_12(b)^(-1)` in `St_N(R)`.
- `h_12(a)` maps to `diag(a, a^(-1), 1, ...)`, and `a, b` commute. So `{a, b}_N` lies in
  `K_2(N, R) = ker(St_N(R) -> E_N(R))`.
- It stabilizes to the symbol `{a, b} ∈ K_2(R) = ker(St(R) -> E(R))`.

## (e) No finite presentation

Suppose `E_N(R)` is finitely presented for some `N >= 3`.

1. **R is finitely generated.** If `E_N(R)` is generated by finitely many matrices, let `R'` be the
   subring generated by their entries. Then `e_12(r) ∈ GL_N(R')`, so `r ∈ R'` for every `r`, and
   `R = R'`.
2. **St_N(R) is finitely generated.** Take the `x_ij(s)` with `s` in a finite ring-generating set
   together with `1`. The `r` with every `x_ij(r)` in the generated subgroup form a subring,
   because `[x_ij(a), x_jk(b)] = x_ik(ab)`. So they are all of `R`.
3. **Neumann.** `E_N(R) = St_N(R)/K_2(N, R)` is a finitely presented quotient of a finitely
   generated group. So `K_2(N, R)` is the normal closure in `St_N(R)` of finitely many elements
   `k_1, ..., k_m` (B. H. Neumann).
4. **Centrality.** In the stable group `St(R)`, `K_2(R)` is central (Kervaire: the centre of
   `St(R)` is `K_2(R)`). So every `St_N(R)`-conjugate of `k_i` has the same image as `k_i`.
   Hence the image of `K_2(N, R)` in `K_2(R)` is generated by the images of `k_1, ..., k_m`, and it
   is finitely generated.
5. **Contradiction.** By (d) that image contains every `{λ, u}`, `λ ∈ Q^x`. By (c) these generate
   a subgroup that is not finitely generated. A subgroup of a finitely generated abelian group is
   finitely generated, so this is a contradiction.

For a finite normal subgroup `C`: if `E_N(R)/C` were finitely presented, then `E_N(R)` would be
too, as an extension of a finitely presented group by a finite group (P. Hall). This proves part 2.

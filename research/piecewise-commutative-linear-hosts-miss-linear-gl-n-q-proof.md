Notation as in the target claim.

1. **`PW_X(L)` is a group, and `Γ ≤ PW_X(H)`.**
   - **Products.** Take `f, g ∈ PW_X(L)`. Put `S = S_g ∪ g^{-1}(S_f)`, which is
     closed and nowhere dense, since `g` is a homeomorphism of `X`. Take `x ∉ S`.
     Choose `U ∋ x` with `g|_U = ℓ|_U` for some `ℓ ∈ F_g`, and `V ∋ g(x)` with
     `f|_V = ℓ'|_V` for some `ℓ' ∈ F_f`. Then `f∘g` equals `ℓ'ℓ` on the open set
     `U ∩ g^{-1}(V)`, which contains `x`. So `F_{fg} = F_f F_g` works.
   - **Inverses.** Put `S = f(S_f)`. For `y ∉ S`, write `x = f^{-1}(y)` and choose
     `U` with `f|_U = ℓ|_U`. Then `f^{-1} = ℓ^{-1}` on the open set `f(U) ∋ y`, so
     `F_{f^{-1}} = F_f^{-1}` works.
   - **Words in the generators.** By induction on word length, every `γ ∈ Γ` has
     some `F_γ ⊆ H`.

2. **Part (a).** Let `γ ∈ Γ` and `ℓ ∈ L` agree on a nonempty open `W ⊆ X`. By
   step 1, `γ` is `H`-piecewise with a closed nowhere dense singular set `S_γ`, so
   `W ⊄ S_γ`. Take `x ∈ W \ S_γ` and an open `U ∋ x` with `γ|_U = h|_U` for some
   `h ∈ H`. Then `h^{-1}ℓ` fixes the nonempty open set `U ∩ W ⊆ X` pointwise. By
   topological freeness `ℓ = h ∈ H`.

3. **Part (b): residual finiteness (Mal'cev's argument).** Let `K ≤ GL_N(R)` be
   generated by `k_1, ..., k_r`, and let `A ⊆ R` be the subring generated by the
   entries of all `k_i^{±1}`.
   - `A` is a finitely generated commutative ring, `K ≤ GL_N(A)`, and `A` is
     Noetherian (Hilbert's basis theorem).
   - Take `1 ≠ k ∈ K` and a nonzero entry `a` of `k − I`. Since `Ann(a) ≠ A`,
     `Ann(a)` lies in a maximal ideal `m`, so `a/1 ≠ 0` in the Noetherian local
     ring `A_m`.
   - By Krull's intersection theorem `a/1 ∉ (m A_m)^j` for some `j`, so
     `a ∉ m^j`.
   - **`A/m` is finite.** Write `F = A/m`; it is a field finitely generated as a
     ring.
     - If `char F = 0`, then `F` is a finitely generated `Q`-algebra, so it is a
       finite extension of `Q` (Zariski's lemma).
     - Its finitely many ring generators are then integral over `Z[1/D]` for some
       integer `D`. So `F` is integral over `Z[1/D]`.
     - A domain over which a field is integral is itself a field, and `Z[1/D]` is
       not one. So this case is impossible.
     - Hence `char F = p > 0`. Then `F` is a finitely generated `F_p`-algebra
       that is a field, so it is finite over `F_p` (Zariski's lemma).
   - Each `m^i/m^{i+1}` is a finitely generated `A/m`-module, hence finite. So
     `A/m^j` is finite.
   - The reduction `GL_N(A) -> GL_N(A/m^j)` has finite image and does not kill
     `k`. So `K` is residually finite.

4. **Divisible groups die in residually finite groups.** Let `D` be a divisible
   abelian group and `φ: D -> F` a homomorphism to a finite group of exponent `e`.
   Every `x ∈ φ(D)` has the form `x = φ(e d) = e·φ(d) = 0`. So `D` lies in the
   kernel of every map to a finite group, and a residually finite group contains
   no nontrivial divisible subgroup.

5. **Conclusion of (b).** Suppose a finitely generated `Γ ≤ PW_X(L)` contains
   every `ρ(g)|_X`. Each `ρ(g)|_X` agrees with `ρ(g) ∈ L` on all of `X`, so
   `ρ(g) ∈ H` by (a). Restriction to `X` is injective on `L`, by topological
   freeness. So `ρ(G) ≤ H` is residually finite by step 3. Since `ρ` is
   injective, `G` is residually finite, which contradicts step 4. For the listed
   groups, the unipotent `{[[1,q],[0,1]]}`, the translations, or the centre of
   `U_3(Q)` is a copy of `(Q,+)` meeting the scalars trivially.

6. **Topological freeness of the instances.**
   - Let `K` be `Q_p` or `R`. An affine map of `K^n` that fixes a nonempty open
     set is the identity: its fixed set is an affine subspace, and a nonempty open
     set affinely spans `K^n`.
   - A projective map of `P^{m-1}(K)` fixes pointwise the union of its projectivized
     eigenspaces. That is a finite union of proper closed subspaces with empty
     interior, unless one eigenspace is everything, i.e. the map is scalar.
   - **Adelic and d-adic.** A nonempty open subset of `A_f^n` (or of
     `∏_p P^{m-1}(Q_p)`, or of `Z_d[1/d]^n = ∏_{p|d} Q_p^n`)
     contains a product `∏_{p∈S} W_p × ∏_{p∉S} Z_p^n` (resp. `P^{m-1}(Q_p)`) with
     each `W_p` open. So an adelic affine (resp. projective) map fixing it pointwise
     fixes a nonempty open set in each coordinate, and is the identity. The point
     `∞` is irrelevant, since every neighbourhood of `∞` contains a nonempty open
     subset of `A_f^n`.
   - **`Aff_1(Q_2) ≀ S_n` on `Z_2^n`.** An element fixing an open box pointwise
     must have trivial permutation part, since the coordinates of a box vary
     independently. Its affine coordinate maps then fix open sets and are the
     identity.

7. **Linearity of the instances.**
   - `Aff_n(R) ≤ GL_{n+1}(R)`.
   - For a commutative ring `R`, conjugation `GL_m(R) -> GL(M_m(R)) ≅ GL_{m^2}(R)`
     has kernel the invertible scalars, because commuting with all matrix units
     forces a scalar. So `GL_m(A_f)/A_f^×` and `PGL_n(R)` are linear.
     `GL_m(A_f)` acts coordinatewise on `∏_p P^{m-1}(Q_p)`, with kernel `A_f^×`.
   - `Aff_1(Q_2) ≀ S_n ≤ GL_{2n}(Q_2)` by block permutation matrices.

8. **Membership of the named groups.**
   - **Cones in coordinates.** With the digits of a sequence read as `2`-adic (or
     `d`-adic) digits, the cone `αC` is `a + d^{|α|}Z_d`. The canonical map
     `αψ ↦ βψ` is `z ↦ b + d^{|β|−|α|}(z − a)`. So `V_d`, `nV`, `Sc(n)` and
     Röver–Nekrashevych groups of affine self-similar groups are piecewise in the
     stated `L` with `S_f = ∅`.
   - **`T`.** `T` is the group of piecewise-`PSL_2(Z)` homeomorphisms of `RP^1`
     with finitely many rational breakpoints (survey Remark 5.5).
∎

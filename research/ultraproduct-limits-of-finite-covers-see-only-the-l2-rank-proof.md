Notation and setting as in `ultraproduct-limits-of-finite-covers-see-only-the-l2-rank`. The
Fox resolution is `0 → P → Z[K]^n →∂_1 Z[K] → Z → 0`, with `P = ker ∂_1` projective because
`cd_Z K <= 2`, and `∂ : P ↪ Z[K]^n` the inclusion. On `P = Z[K]^(ℕ) E` the map `∂` is right
multiplication by the row-finite matrix `E∂` (`ℕ × n`), and `A_m ∂` is a finite `m × n` matrix
over `Z[K]`. `M_m = Z[K]^m A_m ≤ P` is the submodule generated by the first `m` rows of `E`.
Every finitely generated `M ≤ P` lies in some `M_m`, since each element of `P` is `xE` with `x`
finitely supported.

## 0. Numerical input

(a) *`r = χ + n − 1`.* Apply `Q ⊗_{Z[K]} −` to the resolution: `Q ⊗ P → Q^n → Q`, where
`Q^n → Q` is zero. So `H_2(K;Q) = ker(Q ⊗ P → Q^n)`, `H_1(K;Q) = coker`, and
`r = b_2 + (n − b_1) = χ + n − 1`.

(b) *`d(P) = n − 1`.* Apply `U ⊗ −`. The homology is `H_k(K;U)`, of `U`-dimension
`b_k^{(2)}(K) = 0` for all `k` (Cheeger–Gromov; `K` is infinite amenable). Additivity of `dim_U`
along `0 → H_2 → U ⊗ P → U^n → U → H_0 → 0` with `H_1` in the middle gives
`dim_U(U ⊗ P) = n − 1`. By cofinality, `d(P) = sup_m dim_U(U^m A_m) = sup_m rk_U(A_m)`.

(c) *`rk_U(A_m) = rk_U(A_m ∂)` for every `m`.* Let `X_m = U^m A_m ⊆ U ⊗ P`. Right multiplication
by `∂` maps `X_m` onto `U^m A_m ∂`, with kernel `X_m ∩ ker(U ⊗ P → U^n) = X_m ∩ H_2(K;U)`, of
dimension `<= b_2^{(2)}(K) = 0`. So `rk_U(A_m) = dim X_m = dim(X_m ∂) = rk_U(A_m ∂)`.

(d) *Finite covers.* By Shapiro, `Q[F_i] ⊗ (resolution)` computes `H_*(N_i; Q)`, so
`H_2(N_i;Q) = ker(∂̄_i : Q[F_i] ⊗ P → Q[F_i]^n)`, since there is no degree-3 term. By target
item 1 fix `Q[F_i]`-isomorphisms `θ_i : Q[F_i] ⊗ P → Q[F_i]^r`. The image of `Q[F_i] ⊗ M_m` in
`Q[F_i] ⊗ P = Q[F_i]^(ℕ) Ē` is the row space of `Ā_m` (the reduction mod `N_i`); in coordinates
it is the row space of the `m × r` matrix `B_{m,i} = Ā_m θ_i`, and
`dim_{F_i} = rk_{F_i}(Ā_m) = rk_{F_i}(A_m)`. Similarly, let `Δ_i` be the `r × n` matrix of
`θ_i^{-1}` followed by `∂̄_i` (maps act on the right, on row vectors). Then
`B_{m,i} Δ_i = \overline{A_m ∂}` and `rk_{F_i}(Δ_i) = dim_{F_i} im ∂̄_i`.

(e) *Lück approximation* (Lück 1994, matrices over `Q[K]`, any residually finite `K`):
`lim_i rk_{F_i}(A) = rk_U(A)` for every finite matrix `A` over `Q[K]`. By target item 4,
`lim_i b_2(N_i)/[K:N_i] = χ` and `b_1(N_i)/[K:N_i] → 0`.

## 1. Finite-level complementarity (item 3, concrete form)

Fix `m` and write `I_{m,i} = im(Q[F_i] ⊗ M_m → Q[F_i] ⊗ P)` and `H_i = H_2(N_i; Q)`. Then
`H_i ∩ I_{m,i}` is the kernel of `∂̄_i` restricted to `I_{m,i}`, whose image is the row space of
`\overline{A_m ∂}`. So

> `dim_{F_i}(H_i ∩ I_{m,i}) = rk_{F_i}(A_m) − rk_{F_i}(A_m ∂) → rk_U(A_m) − rk_U(A_m ∂) = 0`

by 0(e) and 0(c). Since every finitely generated `M ≤ P` lies in some `M_m`, this is the displayed
`o([K:N_i])` statement of item 3. Together with `dim_{F_i} H_i → χ` (0(e)):

> `dim_{F_i}(H_i + I_{m,i}) → χ + rk_U(A_m)`, and `sup_m (χ + rk_U(A_m)) = χ + n − 1 = r`

by 0(b) and 0(a). So for every `δ > 0` there is an `m` with `H_i + I_{m,i}` of normalized
dimension `>= r − δ` for all large `i`: finitely many relators together with the covers' `H_2`
fill `Q[F_i] ⊗ P` up to `δ`, while each alone falls short, by `n − 1 − rk_U(A_m) + o(1)` and by
`χ` respectively.

## 2. The rank ultraproduct (items 1 and 2 for `R_ω`, item 3)

*The ring.* Each `Q[F_i]` is semisimple, hence von Neumann regular, and so is the product
`Π = ∏_i Q[F_i]`. The normalized rank `rk_{F_i}` is a Sylvester matrix rank function on
`Q[F_i]`, so `rk(x) = lim_ω rk_{F_i}(x_i)` is a Sylvester matrix rank function on `Π`. Its null
set `I_ω = {x : rk(x) = 0}` is a two-sided ideal, and `R_ω = Π/I_ω` is regular with the
faithful rank function `rk_ω`. Over a regular ring, the row space `R^m B` of a matrix is a
finitely generated projective direct summand of `R^k`, and it has rank `rk(B)`. The finitely
generated submodules of `R^k` form a modular lattice closed under `+` and `∩`, on which `rk` is
additive: `rk(X + Y) + rk(X ∩ Y) = rk X + rk Y`. A finitely generated submodule of rank 0 is 0,
because `rk_ω` is faithful. These are standard (Goodearl, *Von Neumann regular rings*, Ch. 1, 2
and 16).

*Matrices over `Q[K]`.* Reduce `A` mod each `N_i` and take the class in `R_ω`. Then
`rk_ω(A) = lim_ω rk_{F_i}(A) = rk_U(A)` by 0(e). The action `Q[K] → R_ω` makes `R_ω` a
`Q[K]`-algebra, and `R_ω ⊗ P = R_ω^(ℕ) E` is projective. Its image-of-first-`m`-generators is
the row space of `A_m`, of rank `rk_U(A_m)`. So `rk_ω(R_ω ⊗ P) = sup_m rk_U(A_m) = n − 1` by
0(b). This is the `R_ω` half of item 1.

*The comparison map.* `θ = (θ_i)` identifies `∏_i (Q[F_i] ⊗ P)` with `Π^r`, so
`V_ω = R_ω ⊗_Π Π^r ≅ R_ω^r`. In these coordinates `Φ` sends the `j`-th generator
`1 ⊗ e_j E` to the class of the `j`-th rows of the `Ā θ_i`, so `Φ(R_ω^m) = R_ω^m B_m` with `B_m`
the class of `(B_{m,i})_i`, and `rk_ω(Φ(R_ω^m)) = lim_ω rk_{F_i}(A_m) = rk_U(A_m)`. Since
`im Φ = ⋃_m Φ(R_ω^m)` (increasing), `rk_ω im Φ = n − 1` and
`rk_ω coker Φ = r − (n − 1) = χ` by 0(a).

*The ultraproduct of `H_2`.* `∂_ω : V_ω → R_ω^n` is right multiplication by the class `Δ` of
`(Δ_i)`. Its kernel `H_ω` is a direct summand of `R_ω^r` of rank

> `r − rk_ω(Δ) = lim_ω (r − rk_{F_i}(∂̄_i)) = lim_ω dim_{F_i} H_2(N_i; Q) = χ`

by 0(e). This proves item 2.

*Complementarity.* `H_ω ∩ Φ(R_ω^m)` is the kernel of right multiplication by `Δ` on
`R_ω^m B_m`, and its image is `R_ω^m B_m Δ`, the row space of the class of `\overline{A_m ∂}`.
So

> `rk_ω(H_ω ∩ Φ(R_ω^m)) = rk_U(A_m) − rk_U(A_m ∂) = 0`,

and this finitely generated module is `0`. As `m` varies these submodules exhaust
`H_ω ∩ im Φ`, so `H_ω ∩ im Φ = 0`. Hence `H_ω → coker Φ` is injective. By additivity,
`rk_ω(H_ω + Φ(R_ω^m)) = χ + rk_U(A_m) ↑ r`, so `H_ω + im Φ` has rank `r` and
`rk_ω H_ω = χ = rk_ω coker Φ`. This proves item 3: `H_ω` embeds in `coker Φ` with full rank.

## 3. The tracial ultraproduct (item 1 for `M_ω`)

`M_ω` is a finite von Neumann algebra with the faithful normal trace
`τ_ω((x_i)) = lim_ω τ_i(x_i)`. Let `u : K → M_ω` be `g ↦ (gN_i)_i`. For `g ≠ 1`, `g ∉ N_i` for
all large `i` (the chain is nested with trivial intersection), so `τ_ω(u(g)) = δ_{g,1}`. Hence
the `*`-homomorphism `C[K] → M_ω` preserves the traces. The GNS space of `τ_ω` restricted to
`C[K]` is `ℓ²(K)`, so the weak closure of `u(C[K])` in `M_ω` is a copy of `L(K)`, and
`i : L(K) ↪ M_ω` is a normal trace-preserving inclusion. By Lück, *L²-invariants*, Thm 6.29,
`M_ω ⊗_{L(K)} −` is faithfully flat and `dim_{M_ω}(M_ω ⊗_{L(K)} Y) = dim_{L(K)} Y` for every
`L(K)`-module `Y`. For a `Q[K]`-module `X`,
`M_ω ⊗_{Q[K]} X = M_ω ⊗_{L(K)} (L(K) ⊗_{Q[K]} X)`, and by flatness
`Tor_k^{Q[K]}(M_ω, X) = M_ω ⊗_{L(K)} Tor_k^{Q[K]}(L(K), X)`. Taking `X = Q` and using that
`dim_{L(K)} = dim_U` on these modules:

> `dim_{M_ω}(M_ω ⊗ X) = dim_U(U ⊗ X)`, `dim_{M_ω} H_k(K; M_ω) = b_k^{(2)}(K) = 0` for all `k`,

and `dim_{M_ω}(M_ω ⊗ P) = d(P) = n − 1`. With §2 this proves item 1. Nothing in this section
uses `χ`, so every number it produces is the same for `χ = 0` and for `χ >= 1`.

## 4. The obstruction (item 4)

Consider the data a limit argument extracts from the Fox resolution `C_*` of `K`:

- the induced complexes `R_ω ⊗ C_*` and `M_ω ⊗ C_*`, and more generally `R_ω ⊗ X`, `M_ω ⊗ X`
  and their `Tor` for `Q[K]`-modules `X`;
- the ranks `rk_ω(A) = rk_U(A)` of matrices over `Q[K]`;
- `L²`-vanishing `b_k^{(2)}(K) = 0` and Lück approximation of each fixed matrix.

By §2 and §3 the rank/dimension profile of the induced complexes is
`(n − 1, n, 1)` on the chain modules, with all homology of rank 0, for every `K` of the setting
with `n` generators, whatever `χ` is. In particular a hypothetical counterexample (`χ >= 1`,
which by target item 5 may be taken with finite abelianization, so that
`b_2(N_i) ~ χ[K:N_i]`) and
an elementary amenable group such as `BS(1,m)` present the same induced profile. So no
inequality between these data forces `χ = 0`. The Euler characteristic enters the limit only
through the non-induced module `V_ω = ∏_ω(Q[F_i] ⊗ P)`, and there only as
`rk_ω coker Φ = rk_ω H_ω = χ` (item 2).

Hence a limit argument proves `χ = 0` iff it proves `rk_ω coker Φ = 0`. By §2,
`rk_ω coker Φ = r − sup_m lim_ω rk_{F_i}(A_m)`, while `lim_ω sup_m rk_{F_i}(A_m) = r` by target
item 2(b). So `rk_ω coker Φ = 0` is the vanishing of the interchange defect of item 2(b) along
`ω`, i.e. uniform generation of `P` (target item 2(c)). That is the target statement for `K`,
with no reduction. The exact failing step is `∏_ω(Q[F_i] ⊗ P) = R_ω ⊗ P` (surjectivity of `Φ`
in rank), which is off by exactly `χ`.

The complementarity of §2 sharpens this. Any element of `V_ω` produced from finitely many
elements of `P` lies in `im Φ`, and `im Φ ∩ H_ω = 0`. So no finite collection of relators, and
no countable union handled one relator at a time, meets the ultraproduct of the covers' `H_2`
at all. The regular summands `Q[F_i]^χ` of a counterexample survive in the limit as a rank-`χ`
summand of `V_ω` transverse to all induced data. The brief's "von Neumann limit of the regular
summands against amenable `L²`-vanishing" therefore compares two objects that are disjoint in
the limit.

## 5. The brief's question (item 5)

The brief asks whether `b_2^{(2)}(K) = 0` can be forced for amenable cd-2 `K`, reading
Cheeger–Gromov as `χ = b_2^{(2)}`. The answer: `b_2^{(2)}(K) = 0` holds for every infinite
amenable group (Cheeger–Gromov), with no condition. The identity `χ = χ^{(2)}(K)` is the
statement `D(P) = 0` (target items 4 and 5), which holds for type `FP_2` and is the open point
otherwise. The correct formula, from §2 and 0(b), is
`χ = rk_ω coker Φ + (b_2^{(2)} − b_1^{(2)} + b_0^{(2)})(K) = rk_ω coker Φ`. So vanishing of
`b_2^{(2)}` decides nothing.

## 6. Calibrations (item 6)

- *Type `FP_2`.* `E` can be taken finite, `P` is finitely generated, and
  `∏_i(Q[F_i] ⊗ P) ⊗_Π R_ω = R_ω ⊗ P`, so `Φ` is an isomorphism, `coker Φ = 0` and `χ = 0`.
  Complementarity then forces `H_ω = 0`, i.e. `b_2(N_i) = o([K:N_i])`, the known Lück
  approximation. Consistent.
- *`K = Z²`.* `n = 2`, `r = 1`, `χ = 0`, `Φ` is an isomorphism, `rk_ω H_ω = 0`. Consistent.
- *Torsion-free lattices `Γ` in `SL_3(Q_2)`.* `Γ` acts cocompactly on the `Ã_2` building, so it
  is of type `F` with cd 2, residually finite (linear) and Kazhdan. Then `b_0^{(2)} = b_1^{(2)} = 0`
  and `χ = b_2^{(2)}(Γ) > 0`. Here `Φ` is an isomorphism and `rk_ω H_ω = χ`, so `H_ω` lies
  inside `im Φ` and complementarity fails. The failure is exactly at 0(c), where
  `b_2^{(2)} = 0` was used. So amenability enters any limit argument only through
  `b_2^{(2)}(K) = 0`. That hypothesis moves `H_ω` from inside `im Φ` to a complement of it,
  but it does not bound its rank.

## 7. What is left

Item 4 shows that the remaining statement is a finite-level one that is not induced from
`Q[K]`: `rk_ω coker Φ = 0`, i.e. for every `δ > 0` a finitely generated `M ≤ P` whose image in
`Q[F_i] ⊗ P` has normalized dimension `>= r − δ` for `ω`-almost all `i`. By §1 this is
equivalent to `dim_{F_i} H_2(N_i; Q) <= δ + o(1)`: the covers' `H_2` must be swallowed by
finitely many relators up to `δ[K:N_i]`. Any proof has to use structure of the covers
themselves, for instance Følner tilings of `F_i`-sets or quasi-tiling entropy arguments applied to
cycles of `H_2(N_i)`, and not only data induced from `K`.

Notation is as in the target. The artifact exits 0.

**Step 1 (1 => 3 => 2).** Let `sigma_k : G -> U(d_k)` be an asymptotic
homomorphism with `||sigma_k(h) - 1|| >= kappa` along a subsequence. Fix a
window `(F, delta)`. For large `k`, put `theta = sigma_k|_W`,
`V = sigma_k(c)*` and `m = 1`.
* `theta` is an `(F u alpha(F), delta)`-model.
* `||theta(alpha(w)) - V* theta(w) V||` is `||sigma(c w c^-1) - sigma(c)
  sigma(w) sigma(c)*||`, which is at most `delta` for large `k`.
So (3) holds, and (3) is (2) with `m = 1`.

**Step 2 (the block model).** Assume the data of (2): `m`, `theta`, `V`, on
a window `F` and with error `delta`. Put `H = C^d`, and on `H^m` define:
* `rho(w) = diag(theta(w), theta(alpha w), ..., theta(alpha^(m-1) w))`;
* `(R xi)_n = xi_(n+1)` for `n < m-1`, and `(R xi)_(m-1) = V* xi_0`.

`R` is unitary. Compute directly:
`R rho(w) R* = diag(theta(alpha w), ..., theta(alpha^(m-1) w), V* theta(w) V)`.
This is an exact identity; the artifact checks it with random blocks. Its
first `m-1` blocks equal those of `rho(alpha w)`. Hence for `w` in `F`:

    (B1)  ||R rho(w) R* - rho(alpha w)|| = ||V* theta(w) V - theta(alpha^m w)|| <= delta.

For `x, y` in `F`, the `n`-th block of `rho(xy) - rho(x)rho(y)` is
`theta(alpha^n x alpha^n y) - theta(alpha^n x) theta(alpha^n y)`, and
`alpha^n x, alpha^n y` lie in `F^(m)`. So:

    (B2)  rho is an (F, delta)-model of W.

Also `||rho(h) - 1|| >= ||theta(h) - 1|| >= kappa`, from block `0`.

**Step 3 (2 => 1).** Every element of `G` is `w c^k` with `w` in `W`. Fix a
finite symmetric `E` in `W` containing `1` and `h`, and an integer `K`. Put
`E_K = {w c^k : w in E, |k| <= K}`. Take (2) for the window
`F = union_{|j| <= 2K} alpha^j(E u E E)` with error `delta`. Build `rho, R`
as in Step 2 and set `rho~(w c^k) = rho(w) R^k`.
* **Iterated seam.** Let `w` satisfy `alpha^j(w) in F` for all `j` between
  `0` and `k`. Telescoping (B1) gives
  `||R^k rho(w) R^-k - rho(alpha^k w)|| <= |k| delta`. For `k < 0`, apply
  (B1) to `alpha^-1 w` in the same way.
* **Multiplicativity.** Let `x = w c^k` and `y = w' c^k'` lie in `E_K`.
  Then `xy = w alpha^k(w') c^(k+k')`, and
  `rho~(x) rho~(y) = rho(w) (R^k rho(w') R^-k) R^(k+k')`.
  The iterated seam and (B2) give
  `||rho~(x) rho~(y) - rho~(xy)|| <= (K+1) delta`.
* So `rho~` is an `(E_K, (K+1)delta)`-model of `G`, and
  `||rho~(h) - 1|| >= kappa`.

Now exhaust `G` by windows `E_K`, with `delta -> 0`. The resulting sequence
is an operator-norm asymptotic homomorphism of `G` that keeps `h`. This
proves (1).

The same computation with `m` blocks and seam error `delta` handles
pseudo-orbits `theta_0, ..., theta_(m-1)` with
`theta_(n+1) ~ theta_n o alpha` up to conjugacy at every step. Conjugating
block by block reduces this to the case
`theta_n = theta_0 o alpha^n` stated here, at the cost of an error `n delta`
in block `n`, on windows enlarged by `alpha^n`. So the chain-recurrence form
and the periodic form are the same condition.

**Step 4 (H' and Corollary 1).** Let `c = x_43(S) x_34(1)`. Its lower-right
block is `C^-1 = [[1,1],[S,1+S]]` (artifact). So
`c^n n(Y) c^-n = n(Y C^n)`.

The first row of `E_11 C^n` is `(a_n, b_n)`, with `(a_0, b_0) = (1, 0)` and
`(a_(n+1), b_(n+1)) = (a_n(1+S) + b_n S, a_n + b_n)`. Induction gives
`deg a_n = n` and `deg b_n <= n - 1`. Hence `c` has infinite order. The
lower-right block of `c^n` is `C^-n`, which is not `I`, while every element
of `W` has lower-right block `I`. So `<c>` meets `W` trivially, and
`H' = W x|_(Ad c) Z`.

For monotonicity: if `phi : H -> K` is a homomorphism, every MF model of
`K` composed with `phi` is an MF model of `H`. So
`phi(Rad_MF(H)) <= Rad_MF(K)`. Apply this to:
* the inclusions `H' <= P <= EL_4(J)`;
* the map `EL_4(J) -> EL_4(L_2)` induced by `S -> s_1`, `T -> t_1`, which

**Step 5 (Corollaries 2 and 3).**

*Corollary 2.* The artifact evaluates each relator exactly as a `4 x 4`
matrix over `J`. For the pigeonhole, let `phi : Gamma_C -> K` be a
homomorphism to a finite group, and let `A` be the subgroup generated by
the `phi(c^k u c^-k)`.
* By `[g,c] = 1` and the second relator,
  `phi(g) phi(c^k u c^-k) phi(g)^-1 = phi(c^k (c u c^-1)(c^-1 u c) c^-k)`,
  which lies in `A`. So `phi(g) A phi(g)^-1 <= A`.
* `A` is finite and conjugation is injective, so equality holds. Hence
  `phi(g^-1 u g)` lies in `A`.
* `phi(e)` centralizes `A`, by `[e,u] = [e,c] = 1`.
* So `phi(x_13(Q)) = [phi(e), phi(g^-1 u g)] = 1`.

No commutation among the conjugates of `u` is needed, so four relators
suffice.

*Corollary 3.* Let `F_0` be the set of prefixes of the four relator words
and of the head word, all rewritten in the normal form `w c^k`. Here `K = 1`.
Let `E` contain the `W`-parts of `F_0`, and take `F` as in Step 3.

Suppose the (PC) data for `(F, delta)` have every `theta(alpha^n w)`
(`n <= m`, `w` in `F`) and `V` equal to permutation matrices, with
`(K+1) delta < sqrt(2)`.
* Then `rho(w)` and `R` are permutation matrices, and so is every value
  of `rho~`.
* Two distinct permutation matrices `P, P'` satisfy
  `||P - P'|| >= ||(P - P') e_i|| = sqrt(2)` for any `i` with
  `P e_i != P' e_i`.
* So the `(K+1) delta`-multiplicativity of `rho~` on `E_K` is exact. The
  generators' images then satisfy the four relators exactly and define a
  homomorphism from `Gamma_C` to a finite symmetric group.
* That homomorphism sends the head to `rho~(h)`, whose block `0` is
  `theta(h)`, which is not `1`. This contradicts Corollary 2.

The bound `delta < sqrt(2)/(4K+2)` stated in the target is stronger than
needed.

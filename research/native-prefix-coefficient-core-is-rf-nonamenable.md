**ESTABLISHED EXACT CLASSIFICATION.**  In the binary Leavitt ring put

```text
a=s_1t_0,                 b=s_00t_1,
A=x_47(a),                B=x_84(b),
n=x_78(1),                m=x_87(1),
H=<n,m,A,B>.                                             (NP1)
```

Let `S` be the unital coefficient subring generated by `a,b`.  There is an
explicit ring isomorphism

```text
S  ~=  I={ [[f,tg],[h,k]] in M_2(F_2[t]) : f(0)=k(0) },  (NP2)
a  |-> E_21,                    b |-> tE_12.
```

Equivalently, the nonzero words in `a,b` are precisely the alternating
words, and a vector-space basis of `S` is

```text
1,
(ba)^r, (ab)^r                         (r>=1),
a(ba)^r, b(ab)^r                       (r>=0).           (NP3)
```

Under `(NP2)` these go respectively to

```text
I_2,
t^rE_11, t^rE_22,
t^rE_21, t^(r+1)E_12.                                  (NP4)
```

Consequently coefficientwise application of `(NP2)` embeds

```text
H <= GL_3(S) <= GL_6(F_2[t]).                            (NP5)
```

Reduction modulo `t^N` gives finite quotients

```text
H -> GL_6(F_2[t]/(t^N)),                                (NP6)
```

and these quotients separate every nonidentity element of `H`.  Thus `H`
is residually finite, hence LEF and operator-MF.  In particular this
infinite-depth prefix core is not the missing MF obstruction and cannot
contain the binary Jacobson rank-three hard core, whose head root belongs
to its nontrivial finite residual.

The classification is not an amenability fence.  Write `c=ba` and
`w=nmn`.  The roots constructed inside `H` satisfy

```text
x_87(c^r) in H,              r>=1,
u_r=w x_87(c^r) w^(-1)=x_78(c^r).                       (NP7)
```

On the first summand in the polynomial realization `(NP2)`, the subgroup

```text
<w,u_1,u_2> ~= C_2 * (C_2 x C_2).                       (NP8)
```

The reduced-word normal form is detected by polynomial degree.  Hence `H`
contains a nonabelian free subgroup and is nonamenable.

This closes the classification left open by the first constant-crossing
audit: the native depth mismatch produces a nonamenable but residually
finite polynomial group.  A Property-`(T)`-free collapse must leave this
linear prefix core and use an additional occurrence that destroys its
polynomial congruence models.

No Property `(T)`, Kazhdan input, stability theorem, trace classification,
finite-word computation, or numerical approximation is used.

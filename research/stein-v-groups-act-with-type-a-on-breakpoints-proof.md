Write `V = V(Γ,Λ,ℓ)` and `X = Γ ∩ [0,ℓ)`. `Γ` is dense, since `Λ ≠ {1}`.

1. **Faithful.**
   - Each `f ∈ V` is `t ↦ μt + c` on pieces, with `c ∈ Γ`, so `f(X) = X`.
   - If `f` fixes `X` pointwise, right-continuity and density of `X` give `f = id`.
2. **Transitive on ordered pairs.** Let `x_1 ≠ x_2` and `y_1 ≠ y_2` be in `X`.
   - Pick `s ∈ Γ`, `s > 0`, smaller than every positive distance among the four points and than `ℓ` minus the
     largest. The intervals `[z, z+s)`, `z ∈ {x_1,x_2,y_1,y_2}`, are then pairwise equal or disjoint.
   - Extend the injection `x_i ↦ y_i` to a permutation `π` of the finite set `{x_1,x_2,y_1,y_2}`.
   - Let `f` translate `[z,z+s)` onto `[π(z), π(z)+s)` for each such `z`, and fix everything else.
   - `f` is a right-continuous bijection with slope 1 and breakpoints and translations in `Γ`. So `f ∈ V` and
     `f(x_i) = y_i`.
   - In particular there is one orbit of 2-element subsets.
3. **A germ contraction.** Let `x ∈ X` and `μ ∈ Λ`, `μ < 1`. Pick `a ∈ Γ`, `a > 0`, with `x + a + μa ≤ ℓ`. Define
   `g_μ`:
   - on `[x, x+a)`: slope `μ` onto `[x, x+μa)`;
   - on `[x+a, x+a+μa)`: slope `μ^{-1}` onto `[x+μa, x+μa+a)`;
   - identity elsewhere.
   The two images tile `[x, x+a+μa)`. All breakpoints lie in `Γ`, since `μΓ = Γ`. So `g_μ ∈ V` fixes `x`, and it
   is linear of slope `μ` on `[x, x+a)`, which it maps into itself. The same construction with `μ^{-1}` in the
   roles swapped gives stabilizer elements of every germ slope in `Λ`.
4. **Point stabilizers are finitely generated.** Let `S = Stab_V(x)`.
   - **Germ map.** Right-continuity gives the right germ `ρ(f) ∈ Λ` at `x`: `f(x+t) = x + ρ(f)t` for small
     `t ≥ 0`. This defines `ρ : S → Λ`, onto by step 3.
   - **Its kernel.** Fix `δ_0 ∈ Γ ∩ (0,a]` and let `K_0 = {f ∈ V : f = id on [x, x+δ_0)}`.
     - The slope-1 gluing `C = [0,ℓ) ∖ [x,x+δ_0) → [0, ℓ−δ_0)` translates `[x+δ_0,ℓ)` by `−δ_0`.
     - It conjugates `K_0` onto `V(Γ,Λ,ℓ−δ_0)`, which is finitely generated by (F2).
   - **Contraction.** Let `f ∈ ker ρ`. Then `f = id` on `[x,x+δ)` for some `δ ∈ Γ ∩ (0,δ_0]`.
     - Put `c = g_μ^k` with `μ^k δ_0 ≤ δ`. Then `c` is linear of slope `μ^k` on `[x,x+a) ⊇ [x,x+δ_0)`.
     - So `c^{-1} f c` fixes `[x,x+δ_0)` pointwise, and `f ∈ c K_0 c^{-1}`.
   - **Generation.** Choose `g_1,…,g_r ∈ S` whose germs generate `Λ`. Then
     `S = ⟨K_0, g_μ, g_1, …, g_r⟩` is finitely generated.
5. **Conclusion.** Steps 1, 2, 4 and (F1) are the four conditions of type (A) in
   `type-a-action-gives-boone-higman-for-subgroups` (Zaremsky, arXiv:2405.18354). Its Corollary B gives the
   subgroup statement. ∎

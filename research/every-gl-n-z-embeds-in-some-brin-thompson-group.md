For every `n >= 1` there is `m >= 1` such that `GL_n(Z)` is isomorphic to a
subgroup of the Brin–Thompson group `mV`.

**Reading.**
- `GL_n(Z) <= GL_(n+1)(Z)` and `jV <= kV` for `j < k`. So this says that for
  each `n` some `mV` contains `GL_n(Z)`, and then every `kV` with `k >= m` does.
- A virtual embedding in `mV` gives an embedding in `mV` (see
  `zaremsky-2-19c-every-gl-n-z-in-some-mv-resolved`). So it is enough to embed a
  finite-index subgroup of `SL_n(Z)`, for instance a torsion-free principal
  congruence subgroup.
- `n <= 2` holds: `GL_2(Z)` is virtually free, and free groups embed in `V`.
  The content starts at `n = 3`.

**Necessary conditions an embedding must meet (for n >= 3, m >= 2).**
- `mV` contains `H_3(Z)`, and the central generator is drift-free
  (`heisenberg-in-nv-forces-drift-free-central-element`). Drift-free distortion
  elements do exist in `mV` (`brin-thompson-mv-contains-a-distortion-element`),
  so this is not an obstruction.
- `mV` contains the infinite Kazhdan group `SL_3(Z)`, so `mV` fails the Haagerup
  property (Problem 2.7). See `some-brin-thompson-group-has-an-infinite-kazhdan-subgroup`.
- Torsion is no obstruction: every finite subgroup of `GL_n(Z)` embeds in `V ≤ mV`,
  and `GL_n(Z)` has no infinite torsion subgroups. (Correction, 2026-09-18, lane
  bh-free-50: this line earlier cited "mV is torsion locally finite" from Kojima–Sheng,
  arXiv:2603.18410, Theorem 1.1, as a fact. Its proof rests on a false two-generator
  criterion, see `kojima-sheng-two-generator-torsion-criterion-fails-in-v`, so that
  statement is open for `m ≥ 2`. Nothing here used it.)

## Attempts

- 2026-09-13 (lane z2-19-glnz-q-2v, unreviewed): **the linear 2-adic action is
  not an nV action.**
  - `GL_n(Z)` acts continuously on the Cantor cube `Z_2^n` by matrices.
  - Identify `Z_2` with `{0,1}^ω` by binary digits, and `Z_2^n` with `C^n`
    coordinatewise. An element of `nV` is then on each rectangle a map
    `x_i ↦ 2^{k_i}(x_i − u_i) + v_i`: coordinatewise dyadic-affine with diagonal
    linear part.
  - The shear `(x, y) ↦ (x + y, y)` agrees with no such map on any open set,
    since its first coordinate depends on `y` everywhere.
  - So any embedding must come from a different action. Digits must move
    between coordinates only through bounded prefix transfers, as in baker's
    maps.
- 2026-09-13, same lane: **the Heisenberg subgroup comes first.** Every
  `GL_n(Z)` with `n >= 3` contains `H_3(Z)`, so a yes needs
  `heisenberg-group-embeds-in-some-brin-thompson-group`.
  - Encodings in which counters sit at bounded depth fail. Left multiplication
    by a generator changes one counter by an unbounded multiple of another,
    which no single element of `mV` (bounded read depth) can do.
  - The encoding has to be computational. The known distortion element of `mV`
    is a reversible Turing machine (SMART) whose powers are cheap words, so the
    natural candidates are groups generated by reversible Turing machines inside
    `2V`.

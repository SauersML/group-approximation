Notation is as in the claim: `G` is `m`-generated with `g^N = 1` for every
`g`, `K = Res_fin(G)`, and `rho : G -> U(Q_d)` is a corona homomorphism.

**Step 0: the finite residual.**

- By `bounded-exponent-fg-group-residual-has-finite-index`, `K` has finite
  index in `G` and no proper finite-index subgroup.
- Every finite-index subgroup `V <= G` contains `K`. Its normal core
  `core_G(V)` is a normal subgroup of finite index, so `K <= core_G(V) <= V`.
- `G/K` is a finite `m`-generated group of exponent dividing `N`. By
  `restricted-burnside-finiteness` it is a quotient of `R(m,N)`, so
  `[G:K] <= |R(m,N)|`.
- By Schreier's lemma (a subgroup of index `j` in an `m`-generated group is
  generated by `j(m-1)+1` elements), `K` is generated by
  `m' <= c(m,N) = |R(m,N)|(m-1)+1` elements `a_1, ..., a_(m')`, and each
  `a_i` has order dividing `N`.

**Step 1: the dichotomy.** If `rho(K) = 1`, then `rho` factors through
`G/K`, and `|rho(G)| <= |G/K| <= |R(m,N)|`. This is case 1.

Suppose `rho(K) != 1`. Every quotient `P` of `K` has no proper finite-index
subgroup: the preimage in `K` of a finite-index subgroup of `P` has the same
index. A nontrivial finite group has the trivial subgroup as a proper
finite-index subgroup. So `rho(K)` is infinite, and hence so is `rho(G)`.

Conversely, if `rho(G)` is infinite, then `rho(K)` is infinite, since
`[rho(G) : rho(K)] <= [G:K] < infinity`, and in particular nontrivial. So
`rho(G)` is infinite exactly in case 2, and the two cases exclude each other.

**Step 2: reblocking the residual.** Assume `rho(K) != 1`, and apply
`gapped-normal-generators-give-a-hyperlinear-quotient` to the group `K` with:

- generating set `S = {a_1, ..., a_(m')}`;
- normal generators `a_1, ..., a_(m')`;
- trivial expressions `s = a_i`, that is `h = 1`, `eps = +1` and `ell_s = 1`,
  so `L = 2m'`;
- the nontrivial corona homomorphism `rho|_K`.

Each `rho(a_i)` is a unitary with `rho(a_i)^N = 1`. By the spectral mapping
theorem its spectrum lies among the `N`th roots of unity, and every `N`th
root `lambda != 1` satisfies `|lambda - 1| >= 2 sin(pi/N) = eta_N`. So
`(GNG0)` holds with `delta = eta_N`; this is part 3 of that claim.

Part 1 of that claim then gives:

- an infinite coordinate set `J`, an index `i*`, and an operator-norm
  asymptotic representation `sigma_n : K -> U(k_n)` (`n in J`) representing
  `rho|_K` after reblocking;
- the bound
  `||sigma_n(a_(i*)) - 1||_(2,tr)^2 >= eta_N^2/(4L) - o(1) = eta_N^2/(8m') - o(1)`.

Part 2 gives, for any free ultrafilter `omega` on `J`, a homomorphism
`pi : K -> U(prod_omega M_(k_n))`, `g -> [sigma_n(g)]`, whose image
`H = pi(K)` is a nontrivial hyperlinear quotient of `K` with
`pi(a_(i*)) != 1`.

**Step 3: properties of `H`.**

- `H` is a quotient of `K`, so `h^N = 1` for every `h in H`.
- `H` is generated by the `m' <= c(m,N)` images of the `a_i`.
- By the preimage argument of Step 1, `H` has no proper finite-index
  subgroup. It is therefore perfect: `H/[H,H]` is a finitely generated
  abelian group of exponent dividing `N`, hence finite, hence trivial.
- Being nontrivial with no proper finite-index subgroup, `H` is infinite.
- **Trace bound.** For a unitary `u`,
  `||u - 1||_(2,tr)^2 = 2 - 2 Re tr(u)`. So the limit trace of `a = a_(i*)`
  satisfies `Re tau(a) <= 1 - eta_N^2/(16 m') <= 1 - eta_N^2/(16 c(m,N))`.

This proves clauses 1 and 2.

**Consequence 3.** Assume every hyperlinear group generated by at most
`c(m,N)` elements, of exponent dividing `N`, is finite. Take `G = B(m,N)`.
The finite residual of `B(m,N)` is the kernel of `B(m,N) -> R(m,N)`, by the
definition of `R(m,N)` in `restricted-burnside-finiteness`.

For any corona homomorphism `rho`, case 2 would produce an infinite such
group `H`. So case 1 holds, and `rho` factors through `R(m,N)`. An
`m`-generated subgroup `Gamma <= U(Q_d)` of exponent dividing `N` is the
image of such a `rho` (send the free generators to the generators of
`Gamma`), so it is finite. That is clause `(A)` of
`corona-restricted-burnside-equals-power-law-moduli` for `(m,N)`. The
established equivalence there gives clause `(B)`, the dimension-free moduli
of `matrix-restricted-burnside-gap` for `(m,N)`.

**Consequence 4.** `hyperlinear-fg-bounded-exponent-groups-are-finite` gives
the hypothesis of Consequence 3 for every `(m,N)`. So every finitely generated
subgroup of `U(Q_d)` of finite exponent is finite, which is
`operator-norm-restricted-burnside`. The graph implication is the route
`corona-burnside-from-hyperlinear-burnside-finiteness`.

For the contrapositive, apply clause 2 to `G = Gamma` and `rho` the inclusion,
for an infinite finitely generated `Gamma <= U(Q_d)` of exponent dividing `N`.
It yields the infinite hyperlinear `H`, which has no finite quotients.

**Consequence 5.**

- The regular representation of the finite group `G/K` is faithful in `U(k)`
  with `k = |G/K|`. Constant sequences embed `M_k` unitally and injectively
  in `prod_n M_k / directSum_n M_k`. The composite `G -> G/K -> U(Q_d)` is
  therefore a corona homomorphism with kernel `K`, so `Rad_MF(G) <= K`.
- If `K` has no infinite hyperlinear quotient, clause 2 never occurs. Then
  `K <= ker rho` for every `rho`, and `Rad_MF(G) = K`.
- If `G` is infinite and simple, its only normal subgroups are `1` (of
  infinite index) and `G`, so `K = G`. A nontrivial `rho` puts us in clause
  2, where `H` is a nontrivial quotient of the simple group `G`, so `H = G`
  and `G` is hyperlinear.

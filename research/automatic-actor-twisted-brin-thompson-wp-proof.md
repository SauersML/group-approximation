Lane proof, elementary, not independently reviewed. Notation as in the target.

## Step 1: actor problems (item 1)

**Bounded length change.** Let `R_i = {s ⊗ γ_i(s)}` be accepted by an automaton with `c` states.
After the shorter word ends, the automaton reads pairs `(#, b)`. The accepted continuation from any
state reached on a valid input is unique, because `R_i` is functional. A unique accepted
continuation has fewer than `c` letters, since a longer one could be pumped. So
`|γ_i(s)| ≤ |s| + c`. The same holds for `γ_i^{-1}`, and hence `|γ(s)| ≤ |s| + cL`.

**Computing `γ_i(s)`.** Output the unique `t` with `s ⊗ t ∈ R_i`. Do forward reachability over the
automaton, restricted to pairs whose first track is `s`, and read the output off one accepting path.
Uniqueness makes every accepting path give the same `t`. This takes polynomial time, and so does
`γ(s)`, by iterating `L` times.

**Identity.** `γ = γ_{i_1}^{±1} ⋯ γ_{i_L}^{±1} ≠ 1` iff some `s ∈ S` has `γ(s) ≠ s`, by
faithfulness. Guess `s` and all the intermediate images `s_1, …, s_L` simultaneously, letter by
letter, as `L+1` padded tracks. Run the `L` automata (and one for `S`) in parallel, and check that
the last track differs from the first somewhere. The configuration is an `O(L)`-tuple of states,
plus `O(1)` bits recording whether a difference has been seen. So nontriviality is in NSPACE`(O(L))`,
and identity is in PSPACE by Savitch. ∎

## Step 2: decomposition of `SV_Γ`

`Γ` normalizes `BV_S`: conjugating a brick map on coordinates `T` by `δ` gives the same brick map
on coordinates `δ(T)`. Also `BV_S ∩ Γ = 1`. A nontrivial coordinate permutation moves some
coordinate `s` to `s' ≠ s`, while an element of `BV_S` maps each coordinate function to itself
outside a finite set and never exchanges coordinates. So `SV_Γ = BV_S ⋊ Γ`, as in Belk--Zaremsky.

Let `K ≤ SV_Γ` be generated by `k_1..k_r`, written as `k_j = b_j δ_j` with `b_j ∈ BV_S` supported on
a finite coordinate set `T_j` and `δ_j` a word in the `γ_i`. For a word
`w = k_{j_1}^{±1} ⋯ k_{j_L}^{±1}`, move all actor letters to the right:

`w = (b'_1)(b'_2)^{η_1} ⋯ (b'_L)^{η_{L-1}} · η_L`

Here `η_t` is the product of the first `t` actor parts, and `b'_t` is `b_{j_t}` or its inverse,
suitably conjugated. Then `w = 1` iff `η_L = 1` in `Γ` and `β := b'_1 (b'_2)^{η_1} ⋯ = 1` in `BV_S`.

## Step 3: the two tests (items 2 and 3)

- **Actor test.** `η_L = 1` is decided in PSPACE by Step 1, and in polynomial time under the
  hypothesis of item 3.
- **Brick test.**
  - Compute the coordinate labels `η_t(T_{j_{t+1}})` by Step 1, in polynomial time. The labels
    are words in `S` of length `O(L)`.
  - Then `β` is a product of `L` brick maps on a set `U` of at most `L·max|T_j|` labeled
    coordinates. Each map is given by a fixed finite table of prefix replacements of depth at most
    `d`.
  - `β ≠ 1` iff some cylinder `[p]` (one prefix per coordinate in `U`, of length at most `dL`) is
    mapped by `β` by a nonidentity prefix replacement `p·t ↦ q·t`. This is an NP certificate: `p`,
    `q`, and a tail such as `1^∞` in the coordinates where `p ≠ q` as maps. Verifying it means
    composing `L` table lookups.
  - So the brick test is in coNP.

Items 2 and 3 follow, since coNP ⊆ PSPACE. ∎

## Remark: where hardness can enter

Every step except the actor test is in coNP, uniformly in `Γ`. So for any actor, automatic or not,
`WP(K)` is in `coNP^{O}`, where `O` is an oracle for the actor's permutational problems (computing
`γ(s)` and deciding `γ = 1`). A twisted Brin--Thompson host is therefore exactly as hard as its
actor's action.

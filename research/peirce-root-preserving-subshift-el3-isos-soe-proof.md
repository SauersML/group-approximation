**Fullness.** `R_Y` is simple (`minimal-subshift-algebra-is-simple-lef-ring`), so `M = M_3(R_Y)` is simple, and every
nonzero idempotent `E` satisfies `MEM = M`. So `E_iME_l ≠ 0` for all `i, l`, because `E_i ∈ E_i M E_l M E_i`.

**The Peirce hexagon.** `P_ij` and `P_kl` commute iff `j ≠ k` and `l ≠ i`. Take `x ∈ E_iME_j` and `y ∈ E_kME_l`.
- If `j ≠ k` and `l ≠ i`, then `xy = 0 = yx`, so they commute.
- If `j = k` and `l ≠ i`, the commutator is `1 + xy`, and such products span `E_iME_jME_l = E_iME_l ≠ 0`. So some pair does not commute.
- The case `l = i`, `j ≠ k` is symmetric.
- If `j = k` and `l = i`, then `(1+x)(1+y) − (1+y)(1+x) = xy − yx`, with `xy ∈ E_iME_i` and `yx ∈ E_jME_j`. It vanishes only if both products do, but products span `E_iME_jME_i = E_iME_i ∋ E_i`.

So the commuting graph on the `P_ij` is the hexagon `P_32 – P_12 – P_13 – P_23 – P_21 – P_31 – P_32`. For `E_k = E_kk` it is the hexagon of the root subgroups.

**Relabelling.** `α` preserves commutation, so it induces an automorphism of the hexagon. Its automorphism group has
order 12, generated by the relabellings `(i,j) ↦ (σi, σj)`, `σ ∈ S_3` (simply transitive on the six vertices),
and the reversal `(i,j) ↦ (j,i)`.
- A relabelling is absorbed by renaming the idempotents `E_k`.
- The reversal is absorbed by precomposing `α` with the graph automorphism `γ(g) = (g*)^{-1}` of `G_X`, where
  `(g*)_ij = τ(g_ji)`:
  - `τ` is an anti-automorphism: for `a = fu^j` and `b = gu^k`, `τ(ab) = u^{-j-k} f (g∘T^{-j}) = τ(b)τ(a)`;
  - so `(gh)* = h* g*`, and `γ` is a homomorphism;
  - `γ(e_ij(r)) = e_ji(τ(r))` in characteristic 2, and `γ² = id`.

So, after renaming and possibly replacing `α` by `α∘γ`, `α(A_ij(R_X)) = P_ij` for all `i ≠ j`.

**Coordinatization.** `α` is injective, so it maps each `A_ij(R_X)` bijectively onto `P_ij`. The idempotents are full.
`peirce-root-homomorphisms-of-e3-are-standard` gives a ring isomorphism `Θ: M_3(R_X) → M` with `α = Θ|_{G_X}` (or
`α∘γ = Θ|_{G_X}`, which is the second form in the claim).

**Orbit equivalence.** `M_3(R_X) ≅ M_3(R_Y)`, and `cantor-crossed-product-matrix-ring-iso-forces-soe` with `m = 3`
gives strong orbit equivalence.

**Converse.** A standard isomorphism `g ↦ hΨ(g)h^{-1}` maps `A_ij` onto the Peirce root groups of `hΨ(E_kk)h^{-1}`.
In the anti form `g ↦ hΨ(g)^{-1}h^{-1}`, with `Ψ` an anti-isomorphism, it maps `A_ij` onto those of `hΨ(E_kk)h^{-1}`
with the labels reversed.

**Model tests.**
- `X = Y`, `α = ` conjugation by `h ∈ GL_3(R_Y)` normalizing `G_Y`: `E_k = hE_kkh^{-1}`.
- `X = (Y, S^{-1})`: the flip isomorphism `fu^j ↦ fu^{-j}` is standard with `E_k = E_kk`.
- `α = γ` on `G_X`: it maps `A_ij` onto `A_ji`, the reversal case, and the claim returns `Θ = id`.

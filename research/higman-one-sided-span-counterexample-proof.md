Conventions: groups act on the left, products are composition, `x^y = y^-1 x y`,
`[x,y] = x^-1 y^-1 x y`. The requirement is only for comparison (the calibration group `G_1` below is
the one in its proof); nothing here depends on it logically.

## Step 0 (the metabelian calibration group `G_1`)

- `H = < a, b | b^a = b^2 > = BS(1,2)`, realized as the affine maps `x -> 2^p x + s` of `Z[1/2]` with
  `a(x) = x/2`, `b(x) = x + 1`. Then `a^-1 b a = b^2`.
- `T = Q[H] ⊗_(Q[<b>]) Q_chi`, where `b` acts on `Q_chi = Q` by multiplication by `1/2`. So
  `hb ⊗ q = h ⊗ q/2`. A basis of `T` is `{ r ⊗ 1 }`, with `r` running over a set `R` of representatives of
  the cosets `H/<b>`. We choose `R` to contain every `a^k` (`k in Z`); these lie in distinct cosets,
  since `a^k in <b>` only for `k = 0`.
- `G_1 = T ⋊ H`, with product `(tau, h)(sigma, k) = (tau + h·sigma, hk)`. Put `c = (1 ⊗ 1, 1)`.
  Then `b^-1 c b = (b^-1 ⊗ 1, 1) = (1 ⊗ 2, 1) = c^2`. So `G_1` satisfies `b^a = b^2` and `c^b = c^2`, and
  `a, b, c` have infinite order.
- `A_1 = <a, c> <= G_1`. The elements `c_k = a^k c a^-k = (a^k ⊗ 1, 1)` are linearly independent in `T`,
  so `A_1 ≅ Z wr Z`. Since `A_1/(A_1 ∩ T)` is cyclic, `A_1' <= T`. It is generated by the conjugates of
  `[c,a] = (-c_0 + c_(-1), 1)` under `a` and `c`, i.e. by the `-c_k + c_(k-1)`.

## Step 1 (the module `L` and the group `G`)

- Let `x = 1 - b - bc in Q[G_1]` and `L = Q[G_1] / Q[G_1] x`, a left `Q[G_1]`-module. Put `ell = [1] in L`.
  So `ell = b ell + bc ell`.
- `G = L ⋊ G_1` with product `(r, g)(s, k) = (r + g s, gk)` and inverse `(r,g)^-1 = (-g^-1 r, g^-1)`.
- Put `a' = (0, a)`, `b' = (0, b)`, `c' = (ell, c)`.
  - `a'` and `b'` lie in the copy `{0} × G_1`, so `b'^(a') = b'^2`.
  - `b'^-1 c' b' = (b^-1 ell, b^-1 c b)` and `c'^2 = (ell + c ell, c^2)`. These agree, because
    `b^-1 ell - ell - c ell = b^-1 (ell - b ell - bc ell) = 0`.

  So `a', b', c'` satisfy the two relations of the "`b` side" of Higman's group, and all have infinite
  order (their images in `G_1` do).
- **Derived length.** `A = <a', c'>` maps onto `A_1` under the projection `G -> G_1`, with kernel in the
  abelian group `L`. `A_1` is metabelian, so `A'' <= L` and `A''' = 1`.

## Step 2 (a harmonic functional on `G_1`)

Let `K = Q(t^(1/2^∞))` be the field of fractions of `Q[t^(±1/2^n) : n >= 0]`. It is a torsion-free
`Q[t^±1]`-module.

- **`mu`.** Define `mu : H -> Z[1/2]` by `mu(r b^n) = 2^-n` for `r in R`, `n in Z`. So `mu(hb) = mu(h)/2`
  and `mu(a^k) = 1`.
- **`lambda`.** Define `lambda : T -> Q` linearly by `lambda(h ⊗ q) = mu(h) q`. It is well defined, since
  `lambda(hb ⊗ q) = mu(h) q/2 = lambda(h ⊗ q/2)`. It satisfies `lambda(c_k) = 1` for all `k`, so
  `lambda(A_1') = 0` (Step 0).
- **`F`.** Fix `m >= 1`. Choose `F(r) in K` for `r in R` with `F(1) = 0` and `F(a^-m) = 1` (other values
  arbitrary). Extend by `F(h b) = F(h) / (1 + t^(mu(h)/2))`, i.e. along each coset `r<b>` by the two-sided
  recursion. The denominators are nonzero in `K`.
- **`f`.** Define `f : G_1 -> K` by `f(tau, h) = t^(lambda(tau)) F(h)`, and extend linearly to
  `f : Q[G_1] -> K`.

**(F1) `f` kills `Q[G_1] x`.** Let `g = (tau, h)`. Then `gb = (tau, hb)` and
`gbc = (tau + hb ⊗ 1, hb)`, and `lambda(hb ⊗ 1) = mu(h)/2`. So

```text
f(g x) = f(g) - f(gb) - f(gbc) = t^lambda(tau) ( F(h) - F(hb) (1 + t^(mu(h)/2)) ) = 0.
```

So `f` descends to a `Q`-linear map `f : L -> K`.

**(F2) Left `A_1'`-invariance.** For `u = (v, 1) in A_1'` and `g = (tau, h)`: `ug = (v + tau, h)`, and
`lambda(v) = 0`. So `f(u m) = f(m)` for every `m in L`.

**(F3) `c`-equivariance.** `c g = (1 ⊗ 1 + tau, h)` and `lambda(1 ⊗ 1) = 1`. So `f(c m) = t f(m)`.

## Step 3 (a homomorphism `A' -> K` that sees the `gamma`-span)

Every element of `A'` has the form `(r, u)` with `u in A_1'` (Step 1). Define
`Phi : A' -> K`, `Phi(r, u) = f(r)`.

- **Homomorphism.** `(r,u)(s,v) = (r + u s, uv)`, and `f(u s) = f(s)` by (F2). So `Phi` is additive.
  Hence `Phi(A'') = 0`, and `Phi` induces a linear map `V = (A'/A'') ⊗ Q -> K`.
- **Equivariance.** Put `gamma = c'^m`, whose `G_1`-part is `c^m`. For `(r,u) in A'`, the conjugate
  `gamma (r,u) gamma^-1` has translation part `s_m ell + c^m r - (c^m u c^-m) s_m ell`, where
  `s_m = 1 + c + ... + c^(m-1)` and `gamma = (s_m ell, c^m)`. Since `c^m u c^-m in A_1'`, (F2) and (F3) give
  `Phi(gamma (r,u) gamma^-1) = t^m Phi(r,u)`. So on `V` the operator `Y^-1` (conjugation by `gamma^-1`
  in the convention `x^y = y^-1 x y`) corresponds to multiplication by `t^m`.
  The same holds on the subgroup `A_m = <alpha, gamma>`, `alpha = a'^m`: `A_m' <= A'` has `G_1`-parts in
  `<a^m, c^m>' <= A_1'`, so `Phi` restricts to a homomorphism `A_m' -> K` that kills `A_m''` and satisfies
  the same equivariance.

## Step 4 (the commutator `z` has infinite `gamma`-span)

Let `z = [gamma, alpha] = gamma^-1 alpha^-1 gamma alpha`. With `gamma = (s_m ell, c^m)` and `alpha = (0, a^m)`:

```text
gamma^-1 = (-c^-m s_m ell, c^-m),    alpha^-1 gamma alpha = (a^-m s_m ell, a^-m c^m a^m),
z = ( c^-m (a^-m - 1) s_m ell ,  [c^m, a^m] ).
```

By (F3), `Phi(z) = t^-m ( f(a^-m s_m ell) - f(s_m ell) )`. For `0 <= i < m`:
- `a^-m c^i = (a^-m ⊗ i, a^-m)` and `lambda(a^-m ⊗ i) = i mu(a^-m) = i`, so `f(a^-m c^i) = t^i F(a^-m) = t^i`;
- `c^i = (1 ⊗ i, 1)`, so `f(c^i) = t^i F(1) = 0`.

Hence `Phi(z) = t^-m (1 + t + ... + t^(m-1)) != 0`.

Now let `V_m = (A_m'/A_m'') ⊗ Q`, let `Y` be the operator induced by `gamma`, and suppose
`sum_j lambda_j Y^j zbar = 0` with finitely many nonzero `lambda_j in Q`. Applying `Phi` gives
`(sum_j lambda_j t^(-mj)) Phi(z) = 0` in the field `K`, so all `lambda_j = 0`. **The `Y`-span of `zbar` in
`V_m` is infinite-dimensional.** ∎

## Step 5 (consequences)

- **`A_m''` is nonzero and has infinite Hirsch length.** `A_m''' = 1`, so `A_m''` is abelian. If
  `A_m'' = 1`, Step 2 of `higman-metabelian-edge-collapse-proof` would make the `Y`-span finite. If
  `h(A_m'') < ∞`, Step 2 of `higman-solvable-by-metabelian-edge-collapse-proof` would. Both steps use only
  the relations `b^a = b^2`, `c^b = c^2` and the hypothesis on `A''`, all of which hold here except the
  hypothesis on `A''`. So `A_m''` is an abelian group of infinite rank.
- **Step 2 of the landed proofs cannot be extended one-sidedly.** For derived length 3 (`A''' = 1`
  with `A''` of infinite rank), the conclusion "the `Y`-span of `zbar` is finite-dimensional" does not
  follow from the `b`-side relations, the infinite order of the generators, and solvability. Any proof
  that a derived-length-3 opposite pair collapses must use both the `b`-side relations
  (`b^a = b^2, c^b = c^2`) and the `d`-side relations (`d^c = d^2, a^d = a^2`) before it bounds
  `A'/A''`. By the automorphism `theta : a -> b -> c -> d -> a`, the mirror example defeats the `d` side
  alone as well.
- **The suggested second-level element.** The brief's candidate `[z, z^alpha]` is not usable as stated:
  `phi(alpha) = b^-P alpha b^P = alpha b^(P - P^2)` is not in `A`, so `phi` of `z^alpha` need not lie in `A`
  at all. The `phi`-invariant pieces of `A` are generated by the `u_k = gamma^(alpha^k)`, with
  `u_k^(b^(P^k)) = u_k^2`.

Notation as in the claim. `Cons_k` is the set of products of at most `k` `Q`-conjugates of elements `r(a)^(+-1)`. The
Nikolov--Segal convention is `[x, g] = x^-1 g^-1 x g` and `y^x = x^-1 y x`. Throughout, `Q = <a>`, so `d(Q) <= |X|` and
`f_i(r, d(Q)) <= F_i(r)`.

## 0. Two standing facts

- **Normal generation.** The normal closure of `R(a)` in `Q` is `Q`, because the quotient is a finite quotient of `G`.
  So the images of `R(a)` generate the abelian group `Q/Q'`, and `Q = Q' <R(a)>`.
- **Commutators against conjugates.** If `y` is a conjugate of some `r(a)^(+-1)`, then
  `[x, y] = (x^-1 y^-1 x) · y` is a product of two such conjugates. So `[Q, y] ⊆ Cons_2`.

## 1. Item (a)

- **`nu <= |X| w`.** Suppose each `a_x` is a product of `w` conjugates of relator values. These at most `|X| w`
  conjugates generate a subgroup containing every `a_x`, hence `Q`.
- **`w <= N_0 + 4 nu F_1(2 nu)`.** Let `s_1, ..., s_nu` be conjugates of relator values generating `Q`. The set
  `Y = { s_i, s_i^-1 }` is a symmetric generating set with at most `2 nu` elements. Theorem 1.2 with `H = Q` gives
  ```text
  Q' = [Q, Q] = ( prod_(y in Y) [Q, y] )^(*f_1)  ⊆  Cons_(2 · 2nu · F_1(2nu)) .
  ```
- **Assembly.** The words `x` and `prod_r r^(n_(x,r))` have equal exponent sums, so they have equal images in `Q/Q'`.
  So `a_x = prod_r r(a)^(n_(x,r)) · c_x` with `c_x in Q'`, and `a_x in Cons_(N_0 + 4 nu F_1(2nu))`.

## 2. Item (b)

- **Promotion.** Let `s_1, ..., s_n` (`n = nu_0(a)`) be conjugates of relator values generating `Q` modulo `Q_0`. Put
  `Y = { s_i^(+-1) } ∪ R(a)^(+-1)`, a symmetric set with `r <= 2(n + |R|)` elements. Then `Q = Q_0 <Y>` by choice of
  the `s_i`, and `Q = Q' <Y>` by section 0. Theorem 1.1 with `K = Q_0` gives `Q = < y_i^(x_ij) : i <= r, j <= f_0 >`.
  Each `y_i^(x_ij)` is a conjugate of a relator value, so `nu(a) <= r F_0(r)`.
- **`nu_0 <= |X| w(abar)`.** Write each image `abar_x` in `Q/Q_0` as a product of `w(abar)` conjugates of images of
  relator values, and lift the conjugators to `Q`. The resulting conjugates generate `Q` modulo `Q_0`.

## 3. Item (c)

Fix `M`, and let `𝒱_M` be the variety generated by the finitely many almost simple groups of order `<= M`. It is
locally finite: the relatively free group `F_(𝒱_M)(X)` embeds in the product of the groups `H^(H^X)` over those `H`.

- **The marked quotient is one of finitely many.** `Q_0` is the intersection of the normal subgroups `T` with `Q/T`
  almost simple, and each such `Q/T` has order `<= M` by hypothesis. So `Q/Q_0` embeds in a product of groups in
  `𝒱_M`. It is `X`-generated, hence a quotient of `F_(𝒱_M)(X)`. So the kernel `U` of `F -> Q -> Q/Q_0` is one of the
  finitely many normal subgroups of `F` containing the verbal kernel of `F -> F_(𝒱_M)(X)`.
- **Fixed words.** Fix such a `U`. `F/U` is finite, so `<<R>> U = F`, by the argument of section 0 applied in `F/U`.
  For each `x` fix `P_x^U`, a product of `k_U(x)` `F`-conjugates of relators with `(P_x^U)^-1 x in U`. Put
  `kappa_U = sum_x k_U(x)`.
- **Evaluation.** In `Q`, `a_x in P_x^U(a) Q_0`. The conjugates of relator values occurring in the `P_x^U(a)` generate `Q`
  modulo `Q_0`. So `nu_0(a) <= kappa_U`.
- **Bound.** Let `kappa(M)` be the largest `kappa_U`. By (b), `nu(a) <= r F_0(r)` with `r = 2(kappa(M) + |R|)`, and (a)
  bounds `w(a)`. All constants depend only on `G`, the chosen words and `M`.

## 4. Item (d)

If `<a>` has no almost simple quotient, then `Q_0 = Q` and `nu_0(a) = 0`. Section 2 with `n = 0` gives
`nu(a) <= 2|R| F_0(2|R|)`, and section 1 gives the bound. Every soluble group qualifies, since its chief factors are
abelian. So does, for example, `Alt(k) wr C_2`, whose only non-abelian chief factor is `Alt(k)^2`.

## 5. Conjugators in a larger group

If `a in Q^X` and `Q` is larger than `<a>`, then conjugators in `<a>` are conjugators in `Q`. So the bounds hold for
`w_Q(a)`. The hypothesis in (c) concerns `<a>`. It holds when `Q` has composition factors of order `<= m`, since
`<a>` then has the same property and an almost simple group `B` with socle `S` has `S` as a composition factor and
`|B| <= |Aut(S)|`.

**0. The self-similar action.** Take `g(x) = ax + b ∈ G_N` and a colour-1 digit `i`. Then
`g(i + 2y) = j + 2(ay + b')`, where `j ≡ ai + b (mod 2)` and `b' = (ai + b - j)/2`. Since `N` is odd,
`ai + b - j ∈ Z[1/N] ∩ 2Z_2 = 2Z[1/N]`, so `b' ∈ Z[1/N]`. So `G_N` acts self-similarly, with restrictions in `G_N`.
- *Pseudo-free.* If `g` fixes a colour-1 word `p` with trivial restriction, then `g` is the identity on the cone
  `C(p)`. An affine map that is the identity on an open set is the identity. On colour-2 words the restriction is
  `g` itself.
- The same holds for any self-similar `H ≤ Aff(Z_2)`.

**1. Reach.**
- *Translations by `Z[1/N]`.* For `c ∈ Z[1/N]`, the natural translation by `c` has no negative-position digits.
  It acts on `X` as `(+c) × id` with `+c ∈ G_N`, and this is a global bisection, so it lies in `2V_{G_N}`.
- *Translations by `Z[1/2N]`.* The shift `u ∈ 2V` is multiplication by `2` in the natural action, so
  `u^{-k}((+c) × id)u^k` is the natural translation by `c/2^k`. As `c` and `k` vary, these cover `Z[1/2N]`.
- *The whole group.* Adding `u` gives the natural action of `Z[1/2N] ⋊ ⟨2⟩`. That action is faithful, and
  `2V_{G_N}` acts faithfully on `X` (step 2). So this subgroup of `2V_{G_N}` is isomorphic to `Z[1/2N] ⋊ ⟨2⟩`.
- *Not finitely generated.* A finitely generated subgroup of `Z[1/2N] ⋊ ⟨2⟩` has translation part inside the
  `Z[t^{±1}]`-module generated by finitely many elements, with `t` acting as `2`. That module lies in
  `(1/M)Z[1/2]` for some `M`, and `(1/M)Z[1/2] ≠ Z[1/2N]` for every `M`, since `N > 1`.

**2. Host.** Run steps A–D of `odometer-2v-is-fp-simple-and-contains-bs12-proof` with `G_N` in place of `⟨a⟩`.
- *A.* Pseudo-freeness makes `D = Λ ⋈ G_N` right cancellative, so condition (F) holds.
- *B, fixed sets.* Suppose `μy ↦ λ(g·y)` is the identity on a cylinder `μνX`. The colour-2 length comparison gives
  `|w_λ| = |w_μ|`. In colour 1, `g|_ν` is onto, so `|p_λ| = |p_μ|` and `g|_ν = 1`. Then `g` strongly fixes `ν`, so
  `g = 1` by pseudo-freeness, and `λ = μ`.
  - So the groupoid is effective, and the full group acts faithfully on `X`.
  - *Hausdorff.* For `g ≠ 1`, the map `x ↦ ax + b` has at most one fixed point in `Z_2`: exactly one if `a ≠ 1`,
    none if `a = 1` and `b ≠ 0`. With degree mismatch, fixed points solve affine equations and are rational.
    Either way the fixed sets have empty interior, so unit-germ sets are `μX` or `∅`.
  - *Normal form.* Every element is `f = h ∏ σ_{μ_i}(g_i)`, with `h ∈ 2V` and `σ_μ(g)` equal to `g` on the cylinder
    `μX` and the identity elsewhere.
- *C, finiteness.* Li, Example ex:ZS (III), applies with `D^*(w,w) = St(G_N, v) = G_N` (rem:ZS-Stab). So `2V_{G_N}`
  is of type `F_n` whenever `G_N` is.
  - `G_3 = ⟨t, a | t a t^{-1} = a^3⟩`, with `a = +1` and `t = ×3`, is `BS(1,3)`. It is a torsion-free one-relator
    group, so its presentation 2-complex is aspherical (Lyndon), and `G_3` is of type `F_∞`.
- *D, perfect and simple.* Fix `g`. All proper `σ_μ(g)` are `2V`-conjugate, as before. Splitting by the first
  colour-2 letter, which `g` fixes with restriction `g`, gives `σ_μ(g) = σ_{μ(ε,0)}(g) σ_{μ(ε,1)}(g)`. So the common
  class `c_g` in the abelianization satisfies `c_g = 2c_g`, hence `c_g = 0`.
  - The same splitting for `μ = ∅` kills the class of `g × id`.
  - With the normal form and the simplicity of `2V`, the full group is perfect.
  - Minimality (from `2V`), pure infiniteness (the same `U`, `V`), effectiveness and Hausdorffness hold, so Matui's
    Theorem simple2 applies and the full group is simple.
- `2V ⊇ (Q,+)` by `rationals-embed-in-brin-thompson-group-2v`, the input already used in the odometer node.

**3. Limit.** Suppose the natural translation `T_q: x ↦ x + 1/q` (`q ∤ 2N'` prime) lies in `2V_H`.
- It acts on colour 1 only: `1/q ∈ Z_2` has no negative-position digits, and carries go upward.
- By the normal form it agrees, on some rectangle `C(p) × C(w)` with image `C(p') × C(w')`, with a basic bisection
  `(p x', w y') ↦ (p' h(x'), w' y')`, where `h ∈ H`.
- Colour 2 is unchanged, so `w' = w`.
- In colour 1, `b + 2^j x' + 1/q = b' + 2^{j'} h(x')` for all `x'`, with `b, b'` the values of `p, p'`.
  - `h` is a tree automorphism, so its slope is a 2-adic unit, forcing `j = j'`.
  - Then `h(x') = x' + (b - b' + 1/q)/2^j` is a translation lying in `H ⊆ Aff(Z[1/N'])`.
- So `(b - b' + 1/q)/2^j ∈ Z[1/N']`, hence `1/q ∈ Z[1/2N']`, which is false for a prime `q ∤ 2N'`.

A finitely generated `H ≤ Aff(Z_2)` whose elements have rational coefficients has all of them in some `Z[1/N']`:
take `N'` to be the product of the denominators of the generators. Since `H` acts by tree automorphisms, every
multiplier is a 2-adic unit, so `N'` may be taken odd. The natural `Q ⋊ ⟨2⟩` contains every `T_q`, so it is not
contained in `2V_H`. ∎

## Imports

- (I1) `thompson-t-is-isomorphic-to-ppsl2z`. A circle homeomorphism conjugates dyadic PL `T` onto
  `PPSL_2(Z)`. Its lift to `R` conjugates `T̄` onto the lift of `PPSL_2(Z)` and fixes `z`. So we may
  work in the Farey model throughout.
- (I2) Classical analysis, recalled and not re-derived here:
  - *Shale (1962).* A bounded real-symplectic `g` on `(H, ω)` with `[g, J_0]` Hilbert–Schmidt is
    implemented on `F` by a unitary `M(g)`, unique up to a phase, with
    `M(g)W(f)M(g)^* = W(gf)`.
  - *Nag–Sullivan (Osaka J. Math. 32, 1995).* For a quasisymmetric `h`, `φ ↦ φ ∘ h` is bounded and
    symplectic on `H^{1/2}(S^1)/R`.
  - *Weil–Petersson criterion.* `[C_h, J_0]` is Hilbert–Schmidt iff `h` lies in the Weil–Petersson
    class (Takhtajan–Teo, Mem. AMS 183, 2006; Hu–Shen). This holds iff `h` is absolutely continuous
    with `log h' ∈ H^{1/2}` (Shen, Amer. J. Math. 140, 2018).
- (I3) Standard Fock-space facts:
  - `‖a(f)ψ‖ ≤ ‖f‖ ‖N^{1/2}ψ‖` and `‖a(f)^*ψ‖ ≤ ‖f‖ ‖(N+1)^{1/2}ψ‖`;
  - `Φ(f) = (a(f) + a(f)^*)/√2`.
  Hence `⟨ψ, Φ(f)²ψ⟩ ≤ 2‖f‖²⟨ψ, (N+1)ψ⟩`. Here `‖f‖` is the one-particle norm, which is
  equivalent to the `H^{1/2}` seminorm.
- (I4) Powers–Størmer: `‖a^{1/2} − b^{1/2}‖_2² ≤ ‖a − b‖_1` for positive trace-class `a, b`.

## Step 1. Farey regularity (W)

- Let `g ∈ PPSL_2(Z)` and let `p` be a breakpoint. It is rational or `∞`.
- Let `A, B ∈ PSL_2(Z)` be the pieces on the left and the right of `p`. By continuity
  `A(p) = B(p)`, so `B^{-1}A` fixes `p`.
- The stabilizer of a cusp `p` in `PSL_2(Z)` is infinite cyclic and generated by a parabolic
  element. It is conjugate in `PSL_2(Z)` to `⟨x ↦ x + 1⟩`.
- A parabolic element has derivative `1` at its fixed point. This holds in any smooth chart,
  because the derivative at a fixed point does not depend on the chart.
- By the chain rule, `A'(p) = B'(p)·(B^{-1}A)'(p) = B'(p)`. So `g'` is continuous and positive.
- It is analytic on each of finitely many closed arcs, so `g'` and `log g'` are Lipschitz.
- The second derivative can jump: `x ↦ x/(1+x)` has second derivative `−2` at `0`. So `C^1` with
  Lipschitz `log g'` is the true regularity, not `C^2`.
- A Lipschitz function is in `H^1 ⊂ H^{1/2}`, so (I2) applies. Each `g` acts on `H` through
  `Sp_res`, and (I2) gives `M`.
- The lift `g̃` is `C^1` with Lipschitz derivative, so `b_g = id − g̃^{-1}` is a `C^{1,1}` periodic
  function and lies in `H`.
- For `g ∈ PSL_2(Z)`, composition with a Möbius map preserves the Dirichlet integral of the
  harmonic extension and commutes with `J_0`. So `M(g)` fixes the vacuum ray.

## Step 2. The displacement cocycle and the Euler cocycle

- *Cocycle.* `b_{gh} = id − h̃^{-1}g̃^{-1} = (id − g̃^{-1}) + (id − h̃^{-1}) ∘ g̃^{-1} = b_g + g·b_h`.
  Changing the lift by `z` changes `b_g` by a constant, which is `0` in `H`.
- *Area identity.* Write `u_f = f̃ − id`.
  - It is a right cocycle: `u_{fg} = u_f ∘ g̃ + u_g`. Also `b_g = u_{g^{-1}}`.
  - Let `D(f,g) = ∫_0^1 (u_f(g̃x) − u_f(x)) dx`. For the section `σ`,
    `A(f̃) = ∫_0^1 u_f`, `β = A ∘ σ` and the Euler cocycle `ε`, one has `ε = D + dβ`. This is the
    computation of Step 3 of `integrably-paired-cup-products-exact-proof`. It uses only
    monotonicity and `f̃(x+1) = f̃(x) + 1`, so it holds verbatim for Farey lifts.
  - `ω` is invariant under composition with any `C^1` lift, by change of variables. The same
    computation gives `ω(u_f ∘ g̃, u_g) = −D(f,g)`.
- *Left area cocycle.* Put `A_L(g,h) = ω(b_g, g·b_h)`. Then

      A_L(g,h) = ω(u_{g^{-1}}, u_{h^{-1}} ∘ g̃^{-1})
               = −ω(u_{h^{-1}} ∘ g̃^{-1}, u_{g^{-1}})
               = D(h^{-1}, g^{-1}).

- *Inversion.* For a cochain `κ` put `κ^ι(g,h) = κ(h^{-1}, g^{-1})`. Then `(dβ)^ι = d(β ∘ inv)`.
  With the section `σ'(g) = σ(g^{-1})^{-1}`, inverting `σ(g)σ(h) = z^{ε(g,h)}σ(gh)` gives
  `ε^ι = −ε'`, where `ε'` is the Euler cocycle of `σ'`. Also `ε' = ε + dm` for an integer
  function `m`.
- Hence `A_L = D^ι = ε^ι − d(β∘inv) = −ε + dγ` for a real function `γ`.

## Step 3. The twisted representations

- For `t ∈ R` put `Π_t(g) = W(√t b_g)M(g)`. By the Weyl relation, Step 2 and (I2),

      Π_t(g)Π_t(h) = W(√t b_g) W(√t g·b_h) M(g)M(h)
                   = e^{−itA_L(g,h)/2} σ_M(g,h) Π_t(gh)
                   = e^{itε(g,h)/2} e^{−it dγ(g,h)/2} σ_M(g,h) Π_t(gh).

  Here `σ_M` is the multiplier of `M`.
- Put `Π'_t(g) = e^{itγ(g)/2}Π_t(g)`. Its multiplier is `e^{itε/2}σ_M`.
- On `HS(F)` define `R_t(g)ξ = Π'_t(g) ξ M(g)^*`. The phases of `M(g)` cancel between the two
  sides, so `R_t` is a projective representation of `T` with multiplier exactly `e^{itε/2}`.
- Hence `ρ_t(σ(g)z^m) = e^{itm/2} R_t(g)` is a unitary representation of `T̄` with
  `ρ_t(z) = e^{it/2}·I = e(t/4π)·I`.
  - Check: `ρ_t(σ(g))ρ_t(σ(h)) = e^{itε(g,h)/2}R_t(gh) = ρ_t(z^{ε(g,h)}σ(gh))`, and `z` is central.
- For `s ∈ S` write `s = σ(p(s))z^{m_s}`. Then
  `ρ_t(s)ξ = λ_s · W(√t b_{p(s)}) M(p(s)) ξ M(p(s))^*`, with `λ_s = e^{it(m_s + γ(p(s)))/2}`.
  So `|λ_s − 1| ≤ K|t|` with `K = max_s |m_s + γ(p(s))|/2`.

## Step 4. The twist bound (1)

- Let `ρ` be a density with `n(ρ) < ∞`. Put `ξ = ρ^{1/2}`, so `‖ξ‖_2 = 1`.
- Fix `s ∈ S` and write `g = p(s)`, `V = M(g)`, `η = VξV^* = (VρV^*)^{1/2}`.
- Split the defect:

      ‖ρ_t(s)ξ − ξ‖_2 ≤ |λ_s − 1| + ‖(W(√t b_g) − 1)η‖_2 + ‖η − ξ‖_2.

- *Middle term.* Put `ρ' = ηη^* = VρV^*`. Then
  `‖(W(a) − 1)η‖_2² = Tr(ρ'(2 − 2cos Φ(a))) ≤ Tr(ρ'Φ(a)²)`, using `1 − cos x ≤ x²/2` in the
  spectral calculus of `Φ(a)`.
  - Next, `V^*Φ(a)V = Φ(g^{-1}a)`, and with `a = √t b_g`, `g^{-1}·b_g = −b_{g^{-1}}`.
  - So by (I3), applied to the spectral decomposition of `ρ`, the middle term is at most
    `2|t| ‖b_{g^{-1}}‖²(1 + n(ρ))`.
  - `S` is symmetric, so `‖b_{g^{-1}}‖ ≤ B`.
- *Last term.* By (I4), `‖η − ξ‖_2 ≤ ‖VρV^* − ρ‖_1^{1/2} ≤ δ(ρ)^{1/2}`.
- Together, with `θ = t/4π`,
  `c(θ) ≤ max_s ‖ρ_t(s)ξ − ξ‖ ≤ K|t| + B√(2|t|(1 + n(ρ))) + δ(ρ)^{1/2}`.

## Step 5. Necessity (2)

- Let `ξ ∈ HS(F)` be a unit vector, and put `ξ' = ρ_t(s)ξ = U ξ V^*`, where `U` is unitary and
  `V = M(p(s))`.
- Then `ξ'^*ξ' = V ξ^*ξ V^*`. So

      ‖V(ξ^*ξ)V^* − ξ^*ξ‖_1 ≤ ‖(ξ' − ξ)^*ξ'‖_1 + ‖ξ^*(ξ' − ξ)‖_1 ≤ 2‖ξ' − ξ‖_2.

- Taking the maximum over `s` gives `δ(ξ^*ξ) ≤ 2 max_s ‖ρ_t(s)ξ − ξ‖`.
- The argument uses nothing about `U` except unitarity. So it applies verbatim to `V' ⊗ M̄` for
  any projective `V'` whose multiplier makes the tensor product a genuine representation of `T̄`.
  This is (3c).

## Step 6. Consequences (3)

- **(a)** Suppose `δ_* = 0`.
  - Densities with `n < ∞` are trace-norm dense.
  - `δ(ρ) ≤ δ(ρ̃) + 2‖ρ − ρ̃‖_1`.
  - So for every `η > 0` there is `ρ` with `δ(ρ) < η²` and `n(ρ) < ∞`.
  - Then Step 4 gives `limsup_{t→0} c(t/4π) ≤ η`, so `c(θ) → 0` as `θ → 0`.
  - Hence `inf_{θ≠0} c = 0`. Part (c) of `lifted-thompson-t-relative-t-forces-dyadic-twist-gap`
    gives a cnd function unbounded on `⟨z⟩`.
- **(b)** Put `t_k = 4π·2^{-k}`. From Step 4 and `(x+y+w)² ≤ 3(x² + y² + w²)`,
  `c(2^{-k})² ≤ 3(K²t_k² + 2B²t_k(1 + A(η_k) + 1) + 2η_k)`. The extra `+1` and the factor `2`
  allow for a near-minimizer of the infimum defining `A`.
  - Take `η_k = k^{-1-ε'}` with `(1+ε')(1−ε) < 1`. Then
    `2^{-k}A(η_k) ≤ 2^{-k}exp(k^{(1+ε')(1−ε)})`, which is summable.
  - So `Σ_k c(2^{-k})² < ∞`, and (B) of `lifted-thompson-t-haagerup-iff-twist-cost-spectral-measure`
    gives that `T̄` is Haagerup.
- **(c)** This is Step 5.

## Checks

- *Sign of the twist.* The sign of `z ↦ e^{±it/2}` depends on the Weyl convention. It is immaterial,
  because `c(−θ) = c(θ)`.
- *Where the PL model fails.* In the PL model `log g'` is a step function, which is not in
  `H^{1/2}`. So `[C_g, J_0]` is not Hilbert–Schmidt and (I2) gives no `M`. Step 1 is the only place
  where the Farey model is used.

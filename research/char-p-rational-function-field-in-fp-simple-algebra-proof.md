Lane proof (bh-algebra, 2026-09-18), not reviewed. It follows
`rational-function-fields-embed-in-fp-simple-rings-proof` step for step; only the orbit
lemma, the constants, and the center are new.

## 1. The orbit
- Let `Π = F_p[t, P]`, a domain. Each `σ_x` is a ring endomorphism of `Π`. For a word
  `u = u_1 ... u_j` put `ψ_u = σ_(u_j) ∘ ... ∘ σ_(u_1)`, so that `ψ_(ux) = σ_x ∘ ψ_u`.
- **Shape lemma.** Every `ψ_u(P)` is either `f P + g` with `f ∈ F_p[t]` monic and
  `deg g < deg f` (read `g = 0` when `deg f = 0`), or a monic element of `F_p[t]`.
  - Start: `P = 1·P + 0`.
  - `σ_(h_a)(fP + g) = (t f) P + (a f + g)`: monic, and `deg(af + g) <= deg f < deg tf`.
  - `σ_m(fP + g) = f(t^2) P + g(t^2)`: monic, degrees doubled.
  - `σ_v(fP + g) = f + g`: monic, since `deg g < deg f` or `(f, g) = (1, 0)`.
  - Letters `h_a`, `v` fix a monic element of `F_p[t]`, and `σ_m` keeps it monic.
  So `T = {ψ_u(P)}` lies in `Π \ {0}`, and `σ_x(T) ⊆ T`.
- **Every monic polynomial is a vacuum value.** `ψ_(h_(a_1) ... h_(a_r) v)(P) = t^r + a_r t^(r-1) + ... + a_1`,
  by induction (`ψ_(h_a v)(P) = t + a`; prepending `h_b` in front composes on the inside as
  `P ↦ tP + b`). Reindexing, every monic `f` of every degree is `ψ_(x_f v)(P)` for a word
  `x_f` in Horner letters. For such words `ψ_(x v)(t) = t`, and `ψ_(xv)(F) = F(t, f_x(t))` for
  `F ∈ Π`, where `f_x = ψ_(xv)(P)`.
- **Evaluation lemma.** If `F ∈ Π` satisfies `F(t, f(t)) = 0` for infinitely many monic `f`,
  then `F = 0`: each `P − f` divides `F` in `F_p[t][P]`, and they are pairwise coprime.

## 2. B and ψ
- Let `S` be the multiplicative monoid generated by `T`, and `B = S^(−1) Π ⊆ F_p(t, P)`. Since
  `σ_x(S) ⊆ S`, each `σ_x` extends to an endomorphism of `B`. Put `ψ(b) = diag(σ_x(b))_x`.
- `ψ` is injective: `σ_(h_0)` is the automorphism `P ↦ tP` of `F_p(t, P)` restricted to `B`.
- **Constants.** Every monic `f ∈ F_p[t]` lies in `T ⊆ S`, so every nonzero element of
  `F_p[t]` is a unit of `B`, and `F_p(t) ⊆ B`. The letters `h_a` and `v` fix `F_p(t)`
  pointwise; `σ_m` acts on it by `t ↦ t^2`.

## 3. Simplicity of O_ψ
- **ψ-minimality.** Let `I` be a nonzero ψ-saturated ideal, `0 ≠ b = F/s ∈ I`. Saturated
  ideals are `σ_x`-stable (`σ_x(b) = ψ(b)_(xx)`). By the evaluation lemma pick a Horner word
  `x` with `F(t, f_x) ≠ 0`. Then `ψ_(xv)(b) = F(t, f_x)/s(t, f_x)` lies in `I`. It is a
  nonzero element of `F_p(t) ⊆ B^x`, because `ψ_(xv)(s) ∈ S ∩ F_p[t]` is nonzero. So `I = B`.
- **Aperiodicity.** Use §5 of `leavitt-resolvent-ring-is-fp-simple-of-char-zero-proof` verbatim
  up to its conclusion: if `y ∈ O_k`, `k > 0`, commutes with the core, then
  `y = Σ s_(νω) w_ω t_ν` with `w_ω ∈ B`, and `ψ_u(w_ω) = 0` unless `u` is the length-`|u|`
  prefix of `ω^∞`. That step only uses that `ψ` is diagonal.
  - For a Horner word `x`, `ψ_(xv)(w_ω) = w_ω(t, f_x) ∈ F_p(t)`, and the letters `h_0 ≠ h_1`
    fix it. Of the words `x v h_0` and `x v h_1` at most one is a prefix of `ω^∞`, so
    `w_ω(t, f_x) = 0` for every Horner word `x`. By the evaluation lemma `w_ω = 0`, so `y = 0`.
  - `k < 0`: the anti-automorphism `s_x <-> t_x`, identity on `B`, is well defined since `ψ`
    is diagonal and `B` commutative.
- By `leavitt-nekrashevych-completion-simplicity-criterion` (part 3), `O_ψ` is simple, and by
  part 2 of `leavitt-nekrashevych-completion-embeds-and-is-fp`, `B ⊆ O_ψ`. In particular
  `O_ψ ≠ 0`.

## 4. R_p ≅ O_ψ
- **In `R_p`.** (Cov), (C) and (L) give `F s_x = s_x σ_x(F)`, `t_x F = σ_x(F) t_x` and
  `F = Σ_x s_x σ_x(F) t_x` for all `F ∈ Π` (the image of `Π` is commutative, and covariance
  passes to products). Hence `F s_u = s_u ψ_u(F)` and `t_u F = ψ_u(F) t_u` for
  `s_u = s_(u_1) ... s_(u_j)`, `t_u = t_(u_j) ... t_(u_1)`. For `G = ψ_u(P) ∈ T`:
  `t_u Γ s_u · ψ_u(P) = t_u Γ P s_u = 1` and `ψ_u(P) · t_u Γ s_u = t_u P Γ s_u = 1`. So every
  element of `S` is invertible, `Π -> R_p` extends to `B -> R_p`, and covariance passes to
  inverses. This gives `O_ψ -> R_p`.
- **Back.** `R_p -> O_ψ` fixes `t, P, s_x, t_x` and sends `Γ` to `P^(−1) ∈ B`. All relations
  hold: (Cov) is covariance in `O_ψ`.
- Both composites fix generators, so `R_p ≅ O_ψ` is simple and contains `B ⊇ F_p(t)`.
  Claim 2's formula is the case `u = x_f v` above.

## 5. The center is F_p
- Let `z` be central. Its graded components commute with the core, so by aperiodicity
  `z ∈ C = O_0`. At a level `n`, `z = Σ_(|μ|=|ν|=n) s_μ Y_(μν) t_ν`, uniquely (criterion,
  part 1). Commuting with the matrix units `s_α t_β` (`|α| = |β| = n`) forces
  `Y_(μν) = δ_(μν) b` for one `b ∈ B`, so `z = z_n := Σ_(|μ|=n) s_μ b t_μ`.
- For `n >= 1`: `z s_y = s_y z_(n−1)` because `t_μ s_y = δ_(μ_1 y) t_(μ')` for `μ = y μ'`.
  Then `s_y z = z s_y` gives `z = t_y s_y z = z_(n−1)`. So `z = z_0 = b`.
- `b s_y = s_y b` gives `σ_y(b) = t_y b s_y = b` for every letter `y`.
  - `σ_v(b) = b` puts `b = F(t,1)/s(t,1) ∈ F_p(t)`.
  - `σ_m(b) = b` says `b(t^2) = b(t)`. If `b = f/g` in lowest terms with
    `D = max(deg f, deg g) >= 1`, then `f(t^2)/g(t^2)` is again in lowest terms (a common root
    `α` would give the common root `α^2` of `f, g`) and has height `2D ≠ D`. So `b ∈ F_p`.
- Conversely `F_p` is central. So the center is `F_p`.

## 6. Free algebras
- The letters `h_0` and `v` fix `F_p(t)`, so `f s_y = s_y f` for `f ∈ F_p(t)` and
  `y ∈ {h_0, v}`, and hence also for `f^(−1)`.
- If `Σ_μ f_μ s_μ = 0` for finitely many distinct words `μ` over `{h_0, v}` with
  `f_μ ∈ F_p(t)`, then each graded component vanishes, and for `|μ| = |μ'|`,
  `t_μ s_(μ') = δ_(μμ')`, so `f_μ = t_μ (Σ f_(μ') s_(μ')) = 0`.
- The prefix code `x_i ↦ s_v^(i−1) s_(h_0)` is injective on words, so it embeds
  `F_p(t)<x_1, ..., x_m>`. ∎

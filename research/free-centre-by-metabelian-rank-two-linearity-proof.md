Elementary and self-contained, apart from Magnus's embedding theorem (the kernel of
`F -> Z^n ⋉ Z[Z^n]^n`, `w ↦ (image of w, abelianized Fox derivatives)`, is `F''`) and
the fundamental formula of Fox calculus.

## Setup

Let `F = F(x, y)` and `R = Z[x^(±1), y^(±1)] = Z[F/F']`, a domain. For a row vector
`a ∈ R^2`, a monomial `g`, a column vector `b ∈ R^2` and `c ∈ R`, write

```text
M(a, g, b, c) = [ 1   a     c ]      (block sizes 1, 2, 1)
                [ 0   g I_2 b ]
                [ 0   0     1 ].
```

Block multiplication gives the group law

```text
M(a,g,b,c) M(a',g',b',c') = M(a' + a g',  g g',  b + g b',  c + c' + a·b').       (L)
```

The matrices `M(0, 1, 0, c)` are central among all matrices `M(a, g, b, c)`, by (L).

Put `rho(x) = M(e_1, x, e_1^T, 0)` and `rho(y) = M(e_2, y, e_2^T, 0)`; these are the
two 4x4 matrices of the claim. Write `rho(w) = M(a(w), g(w), b(w), c(w))`. By (L):
- `g(w)` is the image of `w` in `F/F' = Z^2`, written as a monomial;
- `b(uv) = b(u) + g(u) b(v)` and `b(x_j) = e_j`. So `b(w)_j` is the image in `R` of
  the Fox derivative `∂w/∂x_j`;
- `a(uv) = a(v) + a(u) g(v)`;
- `c(uv) = c(u) + c(v) + a(u)·b(v)`.

## Step 1: rho kills [F'', F]

On `F'`, `g = 1`, so `a` and `b` restrict to homomorphisms into abelian groups and
vanish on `F'' = [F', F']`. Hence `rho(F'') ⊆ {M(0,1,0,c)}`, which is central, so
`rho([F'', F]) = 1`.

## Step 2: conjugation and commutators

For `u ∈ F'` and `h ∈ F` with `m = g(h)`, (L) gives
`a(h u h^(-1)) = a(u) m^(-1)` and `b(h u h^(-1)) = m b(u)`.

For `u, v ∈ F'` (where `g = 1`), (L) reduces to
`M(a,1,b,c) M(a',1,b',c') = M(a+a', 1, b+b', c+c'+a·b')`. A direct computation of
`X Y X^(-1) Y^(-1)` then gives

```text
c([u, v]) = a(u)·b(v) − a(v)·b(u).                                                 (C)
```

## Step 3: the generator e = [x, y]

From the recursions:
- `b(e) = (1 − y, x − 1)^T`;
- `a(e) = x^(-1) y^(-1) (y − 1, 1 − x)`.

So `D := a(e)·b(e) = −x^(-1) y^(-1) ((x − 1)^2 + (y − 1)^2) ≠ 0`.

`F'/F''` is generated, as an abelian group, by the classes of `e^(h) := h e h^(-1)`,
`h ∈ F`. The argument:
- By Magnus, `b` embeds `F'/F''` in `R^2`.
- By the fundamental formula, `(x−1) b_1(u) + (y−1) b_2(u) = g(u) − 1 = 0` for
  `u ∈ F'`.
- The kernel of `(r, s) ↦ r(x−1) + s(y−1)` is `R·(y−1, 1−x)`, because `x − 1` and
  `y − 1` are coprime in the UFD `R`.
- The image of `F'/F''` is an `R`-submodule (Step 2) containing `b(e) = −(y−1, 1−x)`.
- So `b: F'/F'' -> R·b(e) ≅ R` is an isomorphism, and the classes `m·[e] = [e^(h)]` span.

## Step 4: F''/[F'', F] and injectivity of c

In `F/[F'', F]` the subgroup `F''/[F'', F]` is central. So the commutator map
`F' × F' -> F''/[F'', F]` has three properties:
- it is multiplicative in each variable;
- it depends only on the classes mod `F''`;
- it is invariant under conjugation.

By Step 3, `F''/[F'', F]` is therefore generated by the classes of
`[e^(h_1), e^(h_2)]`. Such a class depends only on `m_i = g(h_i)`, and it is the
conjugate by `h_1` of `[e, e^(h_1^(-1) h_2)]`. So `F''/[F'', F]` is generated by the
classes `κ_m := [e, e^(h)]`, with `m = g(h)` ranging over `Z^2`. These satisfy
`κ_1 = 1` and `κ_(m^(-1)) = κ_m^(-1)`; for the second, conjugate
`[e, e^(h^(-1))]` by `h` to get `[e^(h), e] = [e, e^(h)]^(-1)`.

By (C) and Step 2,

```text
c(κ_m) = a(e)·(m b(e)) − (a(e) m^(-1))·b(e) = D (m − m^(-1)).
```

Fix a set `P` of representatives of `(Z^2 \ {0})/±`.
- The Laurent polynomials `m − m^(-1)`, `m ∈ P`, have pairwise disjoint monomial
  supports, so they are Z-linearly independent.
- Multiplication by `D ≠ 0` is injective on the domain `R`.
- So the `D(m − m^(-1))` are independent.

Hence the surjection `ψ: ⊕_{m ∈ P} Z -> F''/[F'', F]`, `δ_m ↦ κ_m`, followed by `c`,
is injective. So `ψ` is an isomorphism, which is the by-product in the claim, and `c` is
injective on `F''/[F'', F]`.

## Step 5: the kernel

Suppose `rho(w) = 1`. Then `g(w) = 1` and `b(w) = 0`, so `w ∈ F''` by Magnus. Then
`c(w) = 0`, so `w ∈ [F'', F]` by Step 4. With Step 1, `ker rho = [F'', F]`. ∎

## Scope

- Only rank 2 is proved. For rank `r`, the same construction (with `R^r`) is defined,
  but `F'/F''` is no longer free and injectivity of `c` is not checked here.
- For `r >= 4`, `c` cannot be injective: `F''/[F'', F]` has 2-torsion (Gupta 1973,
  abstract) and `R` is torsion-free. See
  `free-centre-by-metabelian-groups-linear-iff-residually-finite`.

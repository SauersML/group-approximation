# Shrink each finite witness to the subgroup its labels generate

Internal proof, transcribed from `notes/FALSE_HALO_ACTION_AUDIT.md` (2026-08-10),
lemma `(HAA3)` and theorem `(HAA4)`. Only the final consequence `(HAA5)` uses an
input from elsewhere in the graph, namely `wreath-not-sofic`.

## Step 1 — local target reduction (HAA3)

A finite action test in Alekseev--Bradford Definition 4.1 consists of finite
sets `F subset G` and `E subset Delta`, a finite permutation approximation
`phi:G->Sym(A)`, a large set `S subset A`, and injective partial homomorphisms
`pi_s:E->Lambda`, `s in S`, for one target group `Lambda` in the selected class.

> **Lemma (local target reduction).**  For each such finite witness, `Lambda`
> may be replaced by the subgroup
>
> `Lambda_0=<pi_s(e):s in S, e in E>`.
>
> In particular `Lambda_0` is finitely generated.
>
> **Proof.**  Every partial product, injectivity assertion, and covariance
> identity in the definition is an equality or inequality among elements of
> the finite union of the images in `(HAA2)`.  All those elements lie in
> `Lambda_0`, and the inclusion `Lambda_0->Lambda` is injective.  Thus the
> same maps and the same permutation approximation remain a witness.  End
> proof.

The step is exact: `S` and `E` are finite, so `Lambda_0` is generated by
finitely many elements, and nothing in the definition refers to elements outside
the images.

## Step 2 — collapse (HAA4)

> **Theorem (locally sofic collapse).**  If an automorphism action has
> Alekseev--Bradford witnesses whose target groups are locally sofic, then it
> is already a sofic sofic-action in their sense.
>
> **Proof.**  Apply `(HAA3)` to every finite test.  The resulting target
> `Lambda_0` is finitely generated and lies in a locally sofic group, hence is
> sofic.  These are exactly the same witnesses with the target class changed
> from the original class to the class of sofic groups.  End proof.

The witnesses are not modified — only the class label attached to them changes —
so no approximation parameter degrades.

## Step 3 — the covered alphabets

> Finite-dimensional unitary and Clifford targets are covered by `(HAA4)`.
> Every finitely generated subgroup of `U(n)` is a finitely generated linear
> group and therefore residually finite by Malcev; in particular it is sofic.
> Finite Clifford groups are of course finite.  Direct products and matrix
> amplifications do not change this conclusion at any fixed finite action
> test.

## Step 4 — the Kun--Thom consequence (HAA5)

The lamp group `directSum_(G/Gamma) C_2` is locally finite and `G` is residually
finite, so both factors of `W` are sofic. If the Kun--Thom action admitted
witnesses with locally sofic targets, Step 2 would make it a sofic sofic-action,
and Alekseev--Bradford's semidirect-product theorem for the sofic class
(Corollary 5.2, class (a), transcribed verbatim in the artifact) would give `W`
sofic. That contradicts `wreath-not-sofic`. Hence the action has no
locally-sofic target witnesses.

## Scope, stated openly

This is a statement about Alekseev--Bradford's witness definition, so it
inherits that definition's content; the definition numbers (`4.1` for the finite
action test, `5.2` for the permanence corollary) are as recorded in the audit
and the artifact, and Corollary 5.2 is the item this repository has read
verbatim in the primary source. The theorem constrains *methods*, not the truth
of `hyperlinear-wreath-model`: it says the halo framework cannot produce a first
hyperlinear nonsofic example, not that none exists.

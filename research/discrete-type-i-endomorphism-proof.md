**Step 1: `Phi(z_c) <= z_c`.**  `z_d` is central in `R`, hence commutes with
`Phi(R)`, so `x -> z_d Phi(x)` is a normal `*`-homomorphism from the diffuse
algebra `z_c R` into `z_d R = direct_sum_i M_(k_i)`.  Composing with each
summand gives a normal `*`-homomorphism `D -> M_k` with `D` diffuse.  Its kernel
is `D(1-e)` for a central `e`, and `De` embeds in `M_k`, so it is
finite-dimensional.  `D` has no minimal projections, so `e = 0`.  Thus
`z_d Phi(z_c) = 0`.  Then `Phi(z_d) = 1 - Phi(z_c) >= z_d`, and equal traces
with a faithful trace give `Phi(z_d) = z_d`.

**Step 2: level-by-level matching on `z_d R`.**  `Phi` restricts to a unital
trace-preserving endomorphism of `z_d R = direct_sum_i M_(k_i)`.  Write
`m_i = tau(minimal projection of M_(k_i))`, so `sum_i k_i m_i = tau(z_d)`, and
only finitely many `i` have `m_i >= c` for any `c > 0`.  Let `n_(ji)` be the
multiplicity of `Phi(M_(k_i))` inside `M_(k_j)`.  Unitality gives
`sum_i n_(ji) k_i = k_j`; trace preservation on minimal projections gives
`sum_j n_(ji) m_j = m_i`.

Let `m_*` be the largest value.  For a column `i` with `m_i = m_*`, every
nonzero term `n_(ji) m_j` must have `m_j = m_*` and `n_(ji) = 1`, and exactly
one `j = f(i)` occurs.  For a column with `m_i < m_*`, all rows at level `m_*`
vanish.  So each row `j` at level `m_*` has entries only in level-`m_*`
columns, and `k_j = sum_(f(i)=j) k_i > 0` forces `j` into the image of `f`.
The level is finite, so `f` is a bijection with `k_(f(i)) = k_i`.  Remove the
level and repeat on the next value: its rows see no higher-level columns
(each is used once), and the same count applies.

Hence the inclusion matrix is a permutation with equal ranks, so
`Phi(z_d R) = z_d R`.

**Consequence.**  For a compressor `t`, `Phi_t(R) = sigma(t^(-1) Lambda t)' cap M <= R`,
and `Phi_t` is unital, injective, normal and trace-preserving.  If `R = z_d R`,
every `Phi_t` is onto.  `Ad sigma(gamma)` is the identity on `R` for
`gamma in Lambda`, so the group generated by `Lambda` and the compressors
normalizes `R`.

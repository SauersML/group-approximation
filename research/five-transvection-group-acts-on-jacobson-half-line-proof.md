## Why sufficient

1. **The representation.** On `F_3[Ω]`, `t_i s_j = δ_ij`, and `s_0 t_0 + s_1 t_1 = 1` because every infinite word starts
   with 0 or 1. So `R` acts, and units act invertibly.
2. **Generators.** Each generator is `1 + N` with `N = s_σ t_κ` and `σ, κ` incomparable. So `N^2 = 0` and
   `(1 + N)^(-1) = 1 - N`. `N` replaces a prefix `κ` by `σ` and kills words without the prefix `κ`.
3. **Invariance.** Write `w_(σ,n) = σ 0^n 1^∞`, so `w_(1,0) = 1^∞`.
   - `s_0 t_1`: `w_(1,n) -> w_(0,n)`, and it kills `V_0`.
   - `s_1 t_0`: `w_(0,n) -> w_(1,n)`, and it kills `V_1`.
   - `s_1 t_00`: only `w_(0,n)` with `n >= 1` has prefix `00`, and `w_(0,n) -> w_(1,n-1)`.
   - `s_00 t_1`: `w_(1,n) = 1 0^n 1^∞ -> 0^(n+2) 1^∞ = w_(0,n+1)`.
   - `s_10 t_11`: only `w_(1,0) = 1^∞` has prefix `11`, and `1^∞ -> 10 1^∞ = w_(1,1)`.
   - `s_0 t_10`: only `w_(1,n)` with `n >= 1` has prefix `10`, and `w_(1,n) -> w_(0,n-1)`.

   So `N V ⊆ V` for all five, hence `(1 ± N) V ⊆ V`, and restriction is a homomorphism `Γ_5 -> GL(V)`.
4. **Matrices.** Index copies by `σ`, with `E_ij(x)` sending copy `j` to copy `i` through `x`. Reading item 3:
   - `s_0 t_1 = E_01(1)`, `s_1 t_0 = E_10(1)`, `s_1 t_00 = E_10(T)`, `s_00 t_1 = E_01(S)`;
   - `s_10 t_11` sends `e_0` to `e_1` inside copy 1 and kills everything else, so it is `diag(0, S e)` and
     `x_23(1) -> diag(1, 1 + S e)`;
   - `s_0 t_10 = E_01(T)`, so `x_12(1) -> E_01(T)`, and `z = -1 -> -I`.

   These agree with `Φ(S4) = {E_01(1), E_10(1), E_10(t_0), E_01(s_0)}` of
   `four-transvection-units-have-a-weakly-finite-symbol-image`, under `s_0 -> S`, `t_0 -> T` and `t_1 -> e`.
   **Faithfulness of `J`.** Group a finite relation `sum c_(a,b) S^a T^b = 0` by `d = a - b`. The `e_(n+d)`-coefficient of
   its value on `e_n` is `sum_(b <= n) c_(b+d, b)`, and it vanishes for every `n`, so every `c_(a,b) = 0`.
5. **Separation.** Let `g = z^e x_23(1)^a x_12(1)^b`.
   - `x_12(1)` fixes `1^∞`, which has no prefix `10`, and `x_23(1)^a 1^∞ = 1^∞ + a w_(1,1)`. So
     `g 1^∞ = (-1)^e (w_(1,0) + a w_(1,1))`.
   - `x_12(1)^b w_(1,1) = w_(1,1) + b w_(0,0)`, and `x_23(1)` fixes `w_(1,1)` and `w_(0,0)`, which have no prefix `11`. So
     `g w_(1,1) = (-1)^e (w_(1,1) + b w_(0,0))`.
   - Since `-1 != 1` in `F_3`, these two vectors determine `(e, a, b)`.
6. **Symbol.** `J -> F_3[ζ, ζ^(-1)]` has kernel the ideal generated by `e`, spanned by the matrix units
   `S^a e T^b = E_ab`. A finitely generated subgroup of `GL_2(J) ∩ (I + M_2(M_∞(F_3)))` preserves the span of finitely
   many basis vectors and is the identity outside it, so it is finite. The five generators have unipotent symbols
   `E_01(1)`, `E_10(1)`, `E_10(ζ^(-1))`, `E_01(ζ)`, `I`, so the image lies in `SL_2(F_3[ζ, ζ^(-1)])`, and
   `diag(1, 1 + S e)` has symbol `I`.

Notation is as in the claim. Throughout, `m >= 3` is odd. In `G_{m,M}` a
sample is `(x, a, d, b)`, with `x` uniform in `Z_m`, `d = 0` with probability
`1/2` and `d = +-1` with probability `1/4` each, `a, b` uniform in `[M]`, all
independent, and `y = x + d`. Bits must be equal iff `d = 0`.

## (A1) Value and SDP of the tagged odd cycle

**Value.** Ignoring the tags gives `val(G_{m,M}) >= val(C_m)`. For the other
direction, fix strategies `f(x, a)` and `g(y, b)`. Condition on the tags
`(a, b)`. They are independent of `(x, y)`, so the conditional game is `C_m`
played with `f(., a)` and `g(., b)`, and it is won with probability at most
`val(C_m)`. Hence `val(G_{m,M}) = val(C_m) = 1 - 1/(2m)`.

**SDP.** Let `e` be a unit vector, and let `w_x` be unit vectors orthogonal to
`e` at angle `theta_x = x pi (m-1)/m` in a plane. Put
`u_{x,0} = (e + w_x)/2` and `u_{x,1} = (e - w_x)/2` for every tag.

* The vectors are feasible: `|u_{x,0}|^2 + |u_{x,1}|^2 = 1` and
  `<u_{x,0}, u_{x,1}> = (1 - 1)/4 = 0`.
* An identity edge (`y = x`) contributes `1`.
* A flip edge `(x, y)` contributes
  `<u_{x,0}, u_{y,1}> + <u_{x,1}, u_{y,0}> = (1 - cos(theta_x - theta_y))/2`.

For consecutive `x, x+1` with `x != m-1`, the difference is `(m-1) pi/m`. For
the wrap-around pair `(m-1, 0)` it is `(m-1)^2 pi/m = (m-2) pi + pi/m`, and
`m-2` is odd. In both cases the cosine is `-cos(pi/m)`, so each flip edge
contributes `(1 + cos(pi/m))/2 = 1 - sin^2(pi/(2m))`. Hence

```text
sdp(G_{m,M}) >= 1/2 + (1/2)(1 - sin^2(pi/(2m))) = 1 - sin^2(pi/(2m))/2 >= 1 - pi^2/(8 m^2).
```

## (A2) The ordered value tends to 1

Apply (S1) of `steurer-parallel-repeated-unique-games-rounding` with `k = 2`
and `eps = pi^2/(8 m^2)`. This gives
`opt(G_{m,M}^n) >= 1 - C_1 pi sqrt(n ln 2)/(sqrt(8) m)`. Independently,
players who ignore the tags and play Raz's strategy get
`opt(G_{m,M}^n) >= val(C_m^(x n)) >= 1 - B sqrt(n)/m`, by
`raz-odd-cycle-repetition-lower-bound`.

## (A3) Upper bound on the set-indexed value

Work on the unconditioned product space of `n` iid samples
`(x_j, a_j, d_j, b_j)`, and fix set strategies `alpha, beta`. Let `Win*` be
the event that `Good` holds and the players win.

**Step 1 (Good is likely).** The Alice pairs `(x_j, a_j)` are iid uniform on
`Z_m x [M]`. So are the Bob pairs `(y_j, b_j)`, because `y_j` is uniform and
independent of `b_j`. Each pair of indices collides on one side with
probability `1/(mM)`. So `Pr[not Good] <= n(n-1)/(mM) <= 1/m <= 1/3` when
`M >= n^2`, and

```text
val(G_{m,M}^{{n}})  =  Pr[Win*]/Pr[Good]  <=  2 Pr[Win*].
```

**Step 2 (exchangeability).** Let `F` be the sigma-algebra generated by all
`(x_j, a_j, d_j)` and, for each `z` in `Z_m`, the multiset
`S_z = {b_j : y_j = z}`. Write `J_z = {j : y_j = z}` and `n_z = |J_z|`.

Both parts of `Good` are `F`-measurable. The first is that the `(x_j, a_j)`
are distinct. The second is that each `S_z` has distinct elements.

On `Good` the following are `F`-measurable:

* Alice's set `A`, and hence the bits `f_j = alpha(A)(x_j, a_j)`;
* Bob's set `B = union_z {z} x S_z`, and hence the labelling
  `h_z = beta(B)(z, .)` on `S_z`;
* the required bits `R_j = f_j XOR [d_j != 0]`.

Let `r_z` be the number of `j` in `J_z` with `R_j = 1`. The players win iff
`h_z(b_j) = R_j` for all `z` and all `j` in `J_z`.

The tags `b_j` are iid and independent of `(x, a, d)`. Given `F`, the
assignment `j -> b_j` is therefore a uniformly random bijection `J_z -> S_z`,
independently for each `z`. Permuting indices within the blocks preserves the
law and every generator of `F`.

A uniform bijection matches a fixed 0/1 string with `r_z` ones on `J_z` in
`r_z! (n_z - r_z)!` of the `n_z!` cases, if `h_z` has exactly `r_z` ones, and
in none otherwise. Hence

```text
Pr[Win* | F]  <=  1_{D_A} Phi,     Phi = prod_z 1 / C(n_z, r_z),
```

where `D_A` is the event that the `(x_j, a_j)` are distinct. Note that
`(x, a)` determines the bits `f`, and `d` is independent of `(x, a)`.

**Step 3 (a mixed position is cheap).** Let `W` be the event that every
`R_z = {R_j : j in J_z}` is monochromatic.

* Off `W`, some `z` has `0 < r_z < n_z`, so `Phi <= 1/C(n_z, r_z) <= 1/n_z`.
* The counts `n_z` are `Bin(n, 1/m)`. The Chernoff bound
  `Pr[Bin(n,p) <= np/2] <= e^{-np/8}`, with a union bound over `z`, gives
  `Pr[min_z n_z < n/(2m)] <= m e^{-n/(8m)}`.

So `E[1_{D_A} Phi 1_{not W}] <= 2m/n + m e^{-n/(8m)}`.

**Step 4 (Lemma W: the odd cycle forces a mixed position).** Condition on
`(x, a)`, and hence on `f`. For each `x` let `X_x = {j : x_j = x}` and let
`g = min_x |X_x|`. Then

```text
Pr_d[W | x, a]  <=  6 (3/4)^g.
```

If `g = 0` the bound exceeds 1, so assume `g >= 1`. An index `j` in `X_x`
lands at `x + d_j` with required bit `f_j` if `d_j = 0` and `1 - f_j`
otherwise. Since `m >= 3`, the positions `x-1, x, x+1` are distinct.

*Case 1: some `X_x` is mixed.* Say `X_x` has `u >= 1` indices with `f = 0`
and `w >= 1` with `f = 1`. On `W` there are colours
`c = (c_{x-1}, c_x, c_{x+1})` with every index of `X_x` landing on its
colour.

* An index with `f = 0` fits `c` with probability
  `p_0(c) = (1/2)[c_x = 0] + (1/4)[c_{x+1} = 1] + (1/4)[c_{x-1} = 1]`.
* An index with `f = 1` fits with probability `p_1(c) = 1 - p_0(c)`.

The moves of distinct indices are independent, so

```text
Pr[W | x, a]  <=  sum_c p_0(c)^u p_1(c)^w.
```

The two colourings with `p_0 in {0, 1}` contribute 0, because `u, w >= 1`.
The other six have `p_0 in {1/4, 1/2, 3/4}`, and for them
`p^u (1-p)^w <= (3/4)^(u+w)`. Hence the sum is at most
`6 (3/4)^{|X_x|} <= 6 (3/4)^g`.

*Case 2: every `X_x` is monochromatic,* with colour `e_x`. If `e_z != e_{z-1}`
for every `z`, then `e_z = e_0 + z (mod 2)` and `e_0 = e_m = e_0 + 1`, since
`m` is odd, a contradiction. So some `z`, a function of `(x, a)`, has
`e_z = e_{z-1}`.

At position `z`, stayers from `X_z` require `e_z`, and up-movers from
`X_{z-1}` require `1 - e_{z-1} = 1 - e_z`. So `W` needs `X_z` to have no
stayer, which has probability `(1/2)^{|X_z|}`, or `X_{z-1}` to have no
up-mover, which has probability `(3/4)^{|X_{z-1}|}`. The total is at most
`2 (3/4)^g`. `square`

**Step 5 (assembly).** The group sizes `|X_x|` are also `Bin(n, 1/m)`, so
`Pr[g < n/(2m)] <= m e^{-n/(8m)}`. Using `Phi <= 1`,

```text
E[1_{D_A} Phi 1_W]  <=  6 (3/4)^{n/(2m)} + m e^{-n/(8m)}.
```

With Steps 1 to 3,

```text
val(G_{m,M}^{{n}})  <=  2 [ 2m/n + 2m e^{-n/(8m)} + 6 (3/4)^{n/(2m)} ].   square
```

**Separation.** Put `n = ceil(m^{3/2})`.

* `n (1 - sdp) <= (m^{3/2} + 1) pi^2/(8 m^2) -> 0`, so the bound
  `1 - Psi(n (1 - sdp), 2)` tends to 1 for any `Psi` with `Psi(t, 2) -> 0`.
* By (A2) the ordered value is at least `1 - B m^{-1/4} (1 + o(1)) -> 1`.
* By (A3) the set-indexed value is `O(m^{-1/2}) -> 0`.

So no bound of the stated shape holds for set-indexed repetition. `square`

## (B) The black-box kill transfers

Let `0 < gamma <= 1/8`, and let `m` be as in Part 1 of
`black-box-repetition-sqrt-scale-proof`, so `val(C_m) <= 1 - gamma` and
`1/m <= 4 gamma`.

Let `G'_M` be the disjoint union of `M` copies of `C_m`. A sample is
`(c, x, y)` with `c` uniform in `[M]`, independent of `(x, y) ~ C_m`. Alice
gets `(c, x)` and Bob gets `(c, y)`. Conditioning on `c` shows
`val(G'_M) = val(C_m) <= 1 - gamma`.

**Strategy for `G'_M^{{n}}`.** Let `Dist` be the event that the `n` copy
indices are distinct. It has probability at least `1 - n^2/(2M)`, and it
implies `Good`.

* On `Dist`, both players see the same set of copy indices. They list their
  elements in increasing copy order, which gives the same order on both sides,
  and play Raz's ordered strategy for `C_m^(x n)`.
* Otherwise they answer arbitrarily.

Given `Dist` and the set of copy indices, the sorting permutation is a
function of the `c`'s. The `(x_j, y_j)` are iid and independent of the `c`'s,
so the sorted tuple is iid `C_m`. By `raz-odd-cycle-repetition-lower-bound`,

```text
val(G'_M^{{n}})  >=  Pr[win and Dist]/Pr[Good]  >=  (1 - n^2/(2M)) (1 - B sqrt(n)/m).
```

Let `M -> infinity`. Every universal set bound then satisfies
`F_set(gamma, n) >= 1 - B sqrt(n)/m >= 1 - 4 B gamma sqrt(n)`.

**Completeness certificate.** Let `f, g` be a product strategy with value
`>= 1 - eta`, and restrict it to the sets. Then

```text
Pr[win | Good] >= Pr[win and Good] >= (1 - eta)^n - Pr[not Good].
```

This is the product certificate for `G^{{n}}`. It implies
`(1 - eta)^n >= 1 - eps'`, so `n <= 2 eps'/eta` as in Part 2 of
`black-box-repetition-sqrt-scale-proof`. That part then gives, verbatim with
`F_set` in place of `F`,
`gamma >= min(1/8, (1 - delta') sqrt(eta)/(4 B sqrt(2 eps')))`. `square`

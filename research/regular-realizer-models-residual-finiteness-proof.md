Notation as in the target.

**1 => 2.**
- Choose normal subgroups `K_1 >= K_2 >= ...` of finite index in `G` with trivial
  intersection. Put `X_n = G/K_n` and let `sigma_n(g)` be left multiplication.
  This is a genuine action, and a nontrivial `g` has no fixed points once
  `g not in K_n`. So `sigma_n` is a sofic approximation.
- Every finite image of `G` is the image of `N`
  (`hyperbolic-kazhdan-cover-of-leavitt-unit-group`), so `N K_n = G` and `N` acts
  transitively on `X_n`. The `S`-graph of `X_n` is the Cayley graph of
  `G/K_n = N/(N cap K_n)` with the images of `S`. Finite quotients of the Kazhdan
  group `N` with a fixed generating set have a uniform Cheeger constant, so one
  block and no edit suffice.
- `Pi_B` is `G/K_n` acting by left multiplication, which is regular, and
  `sigma_n(g)` lies in `Pi_B`. So every element is realized exactly, with trivial
  centralizer factor, on all of `X_n`.

**2 => 1.**
1. **Remove the centralizers.** Let `Y_n` be the union of the regular realized
   blocks. By item 6 of `kernel-block-realizer-centralizer-proof`, applied on
   `Y_n`, `sigma|_Y(G) <= Pi`. So for each `t` in a finite generating set `T` of
   `G` containing `S`, there is `p_n(t)` in `prod_(B ⊂ Y_n) Pi_B` agreeing with
   `sigma_n(t)` off `o(|X_n|)` points of `Y_n`.
2. **Regular actions are rigid.** An element of a regularly acting group that
   fixes one point is the identity. So two elements of `Pi_B` that agree at one
   point of `B` are equal.
3. **Exact homomorphisms.** `G` is hyperbolic, hence finitely presented. Fix a
   finite presentation `<T | Rel>`.
   - For `r in Rel`, the product `r(p_n(t))` agrees with `r(sigma_n(t))` off
     `o(|X_n|)` points, and `r(sigma_n(t))` agrees with `sigma_n(1)`, hence with
     the identity, off `o(|X_n|)` points.
   - On a block where `r(p_B(t)) != 1`, it has no fixed point, by step 2. So such
     blocks have total size `o(|X_n|)`.
   - Off `o(|X_n|)` mass, `t -> p_B(t)` satisfies every relator and extends to a
     homomorphism `r_B : G -> Pi_B`.
   - Likewise, on all but `o(|X_n|)` mass `p_B(s)` and `s_B` agree at some point,
     so `r_B(s) = s_B`. Hence `r_B(G) = Pi_B` is generated by the image of `N`.
4. **Separation.** Fix `g != 1` and a word `u` in `T` representing it.
   - `u(p_n(t))` agrees with `sigma_n(g)` off `o(|X_n|)` points, and `sigma_n(g)`
     has `o(|X_n|)` fixed points.
   - A block on which `r_B(g) = 1` consists of fixed points of `u(p_n(t))`. So
     those blocks have total size `o(|X_n|)`.
   - As `|Y_n| >= delta |X_n|`, for `U`-most `n` some block `B ⊂ Y_n` has
     `r_B(g) != 1`. Then `r_B(G)` is a finite quotient of `G` in which `g`
     survives, so `G` is residually finite.
5. **Moreover.** `r_B(G) = r_B(N)` is a finite quotient of `G`, so it is one of the
   `N/L` of `leavitt-cover-finite-quotients-split-over-the-kernel`. ∎

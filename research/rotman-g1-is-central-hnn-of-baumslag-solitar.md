ESTABLISHED.  Let `G_1 = < x, s_1, ..., s_m | s_i^-1 x s_i = x^2 >` (Rotman's
first Boone layer; `m = |A| + 1`, `s_1 = h`).  With `y_i = s_i s_1^-1` for
`i >= 2`,

```text
G_1 = < BS(1,2), y_2, ..., y_m | [y_i, x] = 1 >,   BS(1,2) = < x, s_1 >,   (RG1)
```

a central HNN extension of `BS(1,2)` over `<x>` with `m - 1` stable letters.
Hence `C*(G_1)` is MF (Shulman, Theorem 25 iterated) and `G_1` is regularly
operator-MF realized ([[regular-mf-central-hnn-closure]], `BS(1,2)` being
residually finite).  For `m = 2` this is Higman's non-residually-finite group
`< a, b, c | a^-1 c a = c^2 = b^-1 c b >`, and the identity `(RG1)` gives its
MF-ness without any amalgam theorem.

The instruction automorphism `psi` (`x -> x`, `s_i -> s_i x^-2` for `i >=
2`, `s_1 -> s_1`) reads `psi(y_i) = y_i x^-1`, `psi = id` on `BS(1,2)`.  Its
mapping torus is

```text
G_1 x|_psi Z = < BS(1,2) x <theta>, y_i | y_i^-1 (x, theta) y_i = (x, x^-1 theta) >,   (RG2)
```

an HNN extension of the amenable residually finite group `B' = BS(1,2) x Z`
over `C = <x, theta> ~= Z^2` by the shear `(x, theta) -> (x, x^-1 theta)`,
with `m - 1` stable letters all carrying the same shear.  The finite
quotients `p_n : B' -> (Z[1/2]/mZ[1/2] x| Z/k) x Z/m`, `m` odd and `2^k = 1
mod m`, are cofinal, separate every element of `B'`, and satisfy `ker(p_n o
theta_0) = ker(p_n o theta_1) = mZ x mZ` on `C` for the two edge embeddings.
Therefore [[profinite-synchronized-hnn-is-regular-mf]] applies:
`G_1 x|_psi Z` is regularly operator-MF realized, so `psi` is implemented by
a corona unitary in a corona embedding of `C*(G_1)`.

## Proof

*(RG1).*  `s_i^-1 x s_i = x^2 = s_1^-1 x s_1` gives `s_i s_1^-1 x s_1 s_i^-1
= x`, i.e. `[y_i, x] = 1`; conversely `[y_i, x] = 1` and the `s_1` relation
give `(y_i s_1)^-1 x (y_i s_1) = s_1^-1 x s_1 = x^2`.  The two presentations
are Tietze equivalent.

*(RG2).*  `theta y_i theta^-1 = y_i x^-1` and `[theta, x] = 1` read `y_i^-1
theta y_i = x^-1 theta`, and `theta` centralizes `BS(1,2)`; so the mapping
torus is generated by `B' = BS(1,2) x <theta>` and the `y_i`, each `y_i`
conjugating the pair `(x, theta)` to `(x, x^-1 theta)`.  Both pairs generate
the same subgroup `C`, and the shear is an automorphism of `C`, so `(RG2)` is
an HNN extension with all associated subgroups equal to `C`.

*Synchronization.*  In `BS(1,2) = Z[1/2] x| Z`, the finite quotients are
`Z[1/2]/mZ[1/2] x| Z/k` with `m` odd and `2^k = 1 mod m`; they restrict to
`<x> = Z <= Z[1/2]` as `Z -> Z/m`.  Taking the second factor modulo the same
`m`, the kernel on `C` is `{x^a theta^b : m | a, m | b}`, and the shear
preserves it because `m | b` forces `m | a` iff `m | a - b`.  Cofinality and
separation are the residual finiteness of `B'`.

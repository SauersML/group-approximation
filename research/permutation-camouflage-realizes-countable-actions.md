Let `B` be a perfect countable group with full MF radical, normally generated
by `d`, and put `D=<d>`.  For a nonempty countable `Q`-set `X`, form

```text
K_X=*_(D,x in X) B_x.                                  (PCA1)
```

Every permutation of `X` acts on `K_X` by permuting the vertex groups and
fixing `D` pointwise.  Hence the given action of `Q` defines

```text
W(Q,X)=K_X semidirectProduct Q,
pi_(Q,X):W(Q,X)->Q.                                    (PCA2)
```

Then

```text
Hom(W(Q,X),M) ~= Hom(Q,M)                              (PCA3)
```

naturally for every MF group `M`, and

```text
Rad_MF(W(Q,X))=pi_(Q,X)^(-1)(Rad_MF(Q)).               (PCA4)
```

More generally, for every normal subgroup `N normal W(Q,X)`, the entire MF
semantic closure is pulled back from the visible quotient:

```text
cl_MF^(W(Q,X))(N)
  =pi_(Q,X)^(-1)(cl_MF^Q(pi_(Q,X)(N))).                (PCA4a)
```

If every quotient of `Q` is MF, this becomes

```text
cl_MF^(W(Q,X))(N)=N K_X=N normalClosure(d),
W(Q,X)/N is MF  iff  d in N.                           (PCA4b)
```

The kernel is perfect, has full MF radical, and is normally generated by the
single common element `d`.  If `Q` is MF, it is exactly the MF radical of
`W(Q,X)`.

If `X` is countably infinite, the abstract kernel is the one fixed group

```text
K_infinity=*_(D,n in N)B_n,
```

independently of the action.  Thus every countable permutation action of
`Q` becomes an action on one perfect singly normally generated MF-invisible
kernel, without changing the MF-visible quotient.

If `B` and `Q` are finitely generated and `B!=D`, then

```text
W(Q,X) is finitely generated  iff  X/Q is finite.      (PCA5)
```

Thus every finitely generated group action with finitely many orbits admits
a finitely generated MF-camouflaged realization, even when the hidden kernel
itself is infinitely generated.

Every `Q`-map `p:X->Y` induces a homomorphism

```text
P_p:W(Q,X)->W(Q,Y)                                    (PCA6)
```

which is the identity on `Q`.  This is a faithful functor from nonempty
countable `Q`-sets to split groups over `Q`, and

```text
P_p is injective   iff p is injective,
P_p is surjective  iff p is surjective.                (PCA6a)
```

Its kernel is free, and precomposition with `P_p` is a bijection on
homomorphisms into every MF group.  Thus MF reflection sends this entire
functor to the constant object `Q` and sends every morphism to `id_Q`.  If
`p` is noninjective, even if it identifies only one pair, then

```text
ker(P_p) ~= F_infinity.                                (PCA7)
```

If `B` and `Q` are finitely presented and `X=Q/S` with `S` finitely
generated, then `W(Q,X)` is finitely presented.

Consequently, using a finitely presented full-radical seed and
`Q=F(a,b)`, the transitive sets

```text
X_n=Q/<a^(2^n)>
```

give an infinite tower of finitely presented non-MF groups

```text
... -> W(Q,X_(n+1)) -> W(Q,X_n) -> ... -> W(Q,X_0)    (PCA8)
```

whose bonding maps have kernel `F_infinity`.  Every group in the tower has
universal MF quotient `F(a,b)`, and every bonding map induces an isomorphism
on the complete outgoing representation functor into MF groups.

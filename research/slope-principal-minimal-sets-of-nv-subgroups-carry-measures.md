Let `n >= 1` and `G <= nV`. Let `Z ⊆ C^n` be a minimal closed `G`-invariant set that is
**slope-principal**: `s(g,z) = 0` whenever `g ∈ G`, `z ∈ Z` and `gz = z`. Then `Z` carries a
`G`-invariant Borel probability measure.

## Status

OPEN. No property (T) is assumed.

## Why it is the natural half

- By `nv-point-germ-groups-embed-in-zn-by-slope` (item 1), slope-principality says every
  stabilizer element is the identity near its fixed point in `C^n`, so the germ
  groupoid of `G` on `Z` is principal.
- By item 4 of that claim, no element of `G` compresses a brick meeting `Z` canonically
  into itself.
- On each orbit `O ⊆ Z` the slope cocycle has a well-defined height
  `F: O -> Z^n`, `F(y) - F(gy) = s(g,y)`, because stabilizers have slope zero.
- The two known sources of measure-free minimal sets in `V` are both excluded:
  - ping-pong, whose attracting fixed points have nonzero slope;
  - compressions of a clopen piece into itself by a single canonical map.

## How it can fail on its own

A counterexample need not have property (T). One would be a finitely generated
`G <= nV` with a slope-principal minimal set that has no invariant measure. Examples:
- a free group whose minimal set has only saddle fixed points (needs `n >= 2`);
- a measure-free minimal set with no fixed points at all.

For `n = 1`, the revealing-pair description of elements of `V` (standard, not re-read
at source) shows that every element fixing no point of `Z` with nonzero slope acts on
`Z` with finite order. So the `n = 1` case already asks whether such torsion
subgroups of `V` have measured minimal sets.

## First test

- Take `n = 2` and small subgroups generated by baker-type maps with slope `(-1,+1)`
  and prefix permutations.
- Find their minimal sets.
- For each, decide whether the saddle fixed points lie in the minimal set and whether a
  paradoxical brick decomposition exists.

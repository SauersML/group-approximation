## Setting

- `l` is an odd prime.
- `C_l = Z[u]/(l,u)^l` is the image of `A` in `F_(l,N)` (`N` a multiple of `l^(l−1)`), by the Stirling argument of
  `euler-ring-symbols-in-small-finite-quotients`, Part 4, which holds for `r <= l`.
- `K = Q_l(ζ)`, `𝔭 = (ζ − 1)`, `π = ζ − 1`.

## Statement

1. **The base detects `c_q`.** `u ↦ π` defines a ring map `C_l -> O_K/𝔭^l`, and `K_2(O_K/𝔭^l) ≅ Z/l`. The image
   of `c_q` there is nonzero for every prime `q != l`: its Hilbert symbol is `ζ^(-q)`. So `c_q ≠ 0` in `K_2(C_l)`,
   unlike every `r <= l − 1`.
2. **The crossed-product half is one finite ring.** `τ(π) = π + l` is an automorphism of `O_K/𝔭^l` of order `l`,
   so `F_(l,N) -> G_l = (O_K/𝔭^l) ⋊_τ Z/l`, `u ↦ π`, `X ↦ X`, is a ring map onto a finite ring of order `l^(l+1)`.
   - The orbit-norm detector is blind: `τ_*` has `l`-power order on `K_2(O_K/𝔭^l) = Z/l`, whose automorphism group
     has order `l − 1`. So `τ_* = id`, and `res ∘ ind = l = 0`.
   - For `l = 3`, `G_3 = Z/9[π, X]/(π^2 + 3, 3π, X^3 − 1, Xπ − (π + 3)X)`, of order `81`.
     - `1 + rad(G_3)` is the Heisenberg group of order 27, generated by `ζ = 1 + π` and `X`, with central
       commutator `[X, ζ] = 4`.
     - Hence `K_1(G_3) = {±1} × (Z/3)^2`, and the only scalar classes are `±1`.
     - `K_2(O_K/𝔭^3) = Z/3` is generated by `z = {ζ, −2}` (Dennis–Stein's generator `{1+π, 1+π^2}`). This is
       `Φ_(−2)([ζ])` for the central unit `−2`, in the notation of
       `torsion-k1-modulo-central-scalars-kills-scalar-symbols`.
3. **Open: does `z` survive in `K_2(G_l)`?** If it does, then every `c_q` with `l ∤ q` survives in the finite
   quotient `St_N(D) -> St_N(F_(l,N)) -> St_N(G_l)`, with detection `q ↦ q mod l`. If it dies for every such
   quotient, the `r = l` layer kills `c_q` as well.
   - For `l = 3` this is the question whether `Φ_(−2)([ζ]) = 0` in `K_2(G_3)`. Here `[ζ]` is a non-scalar class of
     order 3 in `K_1(G_3)`.

     - the ScienceDirect PDF endpoints return an HTML bot wall;

     Maazen–Stienstra for local rings) is also walled from MSI. So no presentation of `K_2` valid for residue
     field `F_3` was checked, and none is used.
   - *The Dennis trace is provably blind here (lane proof, elementary).* Let `n ∈ Z` be invertible in a ring `R`.
     Then the Dennis trace `D({a, n}) = (an)^(-1)⊗a⊗n − (an)^(-1)⊗n⊗a` is `n` times a degenerate chain, so it
     is `0` in `HH_2^Z(R)`.
     - `K_2(O_K/𝔭^3) = Z/3` is generated by `{ζ, −2}`, so `D` vanishes identically on it. The calibration required
       before a run fails a priori.
     - The same holds for `z = {ζ, −2}` in `K_2(G_3)`.
   - *The induced-representation detectors are blind* (item 2, orbit norm).
   - *What would decide it.* Either:
     - a presentation of `K_2` for non-commutative local rings with residue field `F_3`, from Kolster or Russell
       read at source, which would let `K_2(G_3)` be computed; or
     - an explicit Steinberg-relation derivation of `z = 0`, verified symbolically; or
     - a detector that sees integer-entry symbols, which rules out Hochschild-type traces.

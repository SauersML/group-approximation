**ESTABLISHED** (lane proof, elementary, not reviewed; no priority claimed).
Let `L = L_(F_2)(1,2)` and `G_L = L^x`.

## 1. A positive instance of the hole

For every perfect subgroup `S <= G_L` (for instance `S = G_L`, or Thompson's `V`),
the triple `T = H = E_4(L)`, `g = e_12(1)` with the sandwich ring
`U = Z[T]<p,q>/(p(1-g)q-1)` witnesses
[[ck-sandwich-ring-has-fp-projective-simple-quotient]] for `S`. Hence the marked
Steinberg cover `Gamma` of [[ck-steinberg-marked-cover]] built from this marking has a
finitely normally generated maximal proper normal subgroup (regime R4 of
[[ck-maximal-kernel-four-regimes]]), with simple quotient `PE_4(L) ≅ G_L`.

*Proof.*
- `L` is a finitely presented ring, and `L_L ≅ L_L ⊕ L_L` (the Leavitt relations).
- For `n >= 3`, `EL_n(L) = GL_n(L)` is simple
  ([[binary-leavitt-elementary-group-is-simple]]). A nontrivial simple group has
  trivial centre, so `PE_4(L) = E_4(L) = GL_4(L)`.
- `M_4(L) ≅ L` (four-leaf prefix code), so `GL_4(L) ≅ G_L`, which is finitely
  presented ([[leavitt-unit-group-finitely-presented]], Khanh arXiv:2609.08428
  Thm 6.1, a literature import).
- So `PE_4(L)` is finitely presented and simple, and items 2--3 of
  [[square-module-ring-hosts-are-sandwich-ring-quotients]] apply to every perfect
  `S <= G_L`. Step (2) ⇒ (1) of [[ck-maximal-kernel-four-regimes]] converts the
  ideal into the kernel. ∎

**What it does and does not give.** Every finitely generated `G <= G_L` runs through
[[boone-higman-via-ck-maximal-kernel]] end to end with this marking (take the simple
core to be `G_L` itself, which contains `G × Z`). That is no new Boone--Higman case,
since `G_L` is already a finitely presented simple overgroup. By Attempt 11 of
[[ck-envelope-has-a-finitely-normally-generated-maximal-kernel]], the existential reading
of the hole ("some envelope of `S` has an fng maximal kernel") is Boone--Higman for `S`
again; this instance is of exactly that kind. What it adds is only that the witness can
be taken to be a CK marked Steinberg cover (a property-(T) cover of `EL_4` of a sandwich
ring), not just the fp simple overgroup with `M = 1`. It says nothing about the
specific-object version, the Clapham marking of the route, which is where the content of
the hole lies.

## 2. Clause (b) contains the stable K_2 budget

Let `R` be a ring with `St_4(R)` finitely presented, as for every candidate `R = U/I`.
If the image of `K_2(4,R) -> K_2(R)` is not finitely generated, then
`ker(St_4(R) -> E_4(R))` is not finitely normally generated in `St_4(R)`, so clause (b)
of [[ck-sandwich-ring-has-fp-projective-simple-quotient]] fails.

*Proof.* `K_2(R)` is central in `St(R)`, so `St_4(R)` acts trivially on it. The image
of the normal closure of finitely many `k_1, ..., k_r in K_2(4,R)` is the subgroup of
`K_2(R)` generated by their images, which is finitely generated. ∎

**Consequence for witnesses.** Steinberg symbols `{u, v}` of commuting units already
live in `K_2(4,R)`. So every obstruction on main whose conclusion is "these symbols
generate an infinitely generated subgroup of stable `K_2`" also excludes the ring as an
R4 witness, in any characteristic. Examples: the `K_2` branch of
[[graded-rings-with-degree-one-units-fail-the-k-budget]], and the symbol arguments
behind the resolvent and Euler rings of the `Z_(l)` work.

**What does not transfer.** The `K_1` halves of those obstructions are stable:
`ker(Q^x -> K_1(R))` not finitely generated. Clause (c) concerns the unstable
`ker(Q^x -> GL_4(R)/E_4(R))` (via `λ ↦ λ I_4`, whose stable class is `4[λ]`). Unstable
`K_1` can be larger, so a characteristic-zero R4 witness can escape a stable `K_1`
obstruction only through rank-four instability of `K_1`. Rings of infinite stable range,
which every non-directly-finite witness has, are exactly where that is possible.

## Scope

- Nothing here decides the hole for a simple core outside `G_L`.
- Part 2 assumes `St_4(R)` finitely presented. For `R` finitely presented this is
  Krstić--McCool at rank four, which this repository imports but has not read; at rank
  `>= 5` the direct proof `steinberg-groups-of-fp-rings-are-fp-in-rank-five` applies.

**ESTABLISHED** (lane proof, not reviewed). Elementary and self-contained. No priority claimed.
- **What it settles.** Kourovka 20.44 (S. Kohl) for every finitely generated subgroup of
  `CT_∅(Z)`, the group generated by class transpositions with 2-power moduli. McDermott
  identified this group with Thompson's `V` (Kohl, J. Group Theory 20 (2017), Remark 1.4).
- **What stays open.** 20.44 for all of `CT(Z)` is still OPEN. With the prime 3 it is 3x+1-hard
  (`ct-z-orbit-transversal-dichotomy-is-collatz-hard`).
- **Source of the viewpoint.** The proof reads the action as a one-stack pushdown rewriting, in
  the spirit of Büchi and Muller–Schupp, but it uses no theorem from that theory.

## Setting

- **Words.** By item 3 of `ct-p-z-is-a-one-vertex-k-graph-full-group` with `P = ∅`, `CT_∅(Z)` is
  the group of permutations of Z that are canonical, `r + 2^a t ↦ s + 2^b t`, on the classes of
  two partitions with 2-power moduli.
- **Integers as sequences.** Write integers as their 2-adic digit sequences, least significant
  digit first.
  - `N_0` is the set of sequences that end in `0^∞`, and the negative integers are those that
    end in `1^∞`.
  - The class `r(2^a)` is the cone `[u]` of sequences that begin with the `a`-letter word `u` of
    `r`.
  - A canonical map is the prefix replacement `uz ↦ vz`.
- **The group.** Let `G = ⟨S⟩` with `S` finite and symmetric. Each `s ∈ S` is given by a
  partition of the Cantor set into cones `[u]` and the prefix replacements `u ↦ v` on them.
- **Depth.** `D` is the largest length of such a `u` or `v`.

**Moves and consumption.** Applying `s` to a sequence `y` replaces the prefix `u` of the piece
containing `y`.
- Fix a sequence `x` and a position `K`. Follow the letter `x_K` along a sequence of moves: while
  it sits at position `p`, a move with `|u| ≤ p` shifts it to position `p − |u| + |v|` and does
  not read it.
- A move with `|u| > p` *consumes* it. Call `K` **consumable from `x`** if some sequence of
  moves consumes `x_K`.
- **Only a prefix matters.**
  - Before `x_K` is consumed, every move reads only letters above it.
  - The consuming move reads at most `D − 1` letters below it.
  - So consumability of `K` depends only on `x[0, K+D)`. Hence the set `C_K` of sequences from
    which `K` is consumable is clopen.
- **Monotonicity.** A move that reads `x_(K+1)` also reads `x_K` if it is still present. So
  `C_(K+1) ⊆ C_K`.

## Theorem

Let `δ_K = μ(complement of C_K)`, where `μ` is the uniform measure on sequences. The sequence
`(δ_K)` is nondecreasing.
1. **Few orbits.** If `δ_K = 0` for all `K`, then every orbit on `N_0` meets `[0, 2^D)`, and
   every orbit on the negative integers meets `[−2^D, 0)`. So `G` has at most `2^(D+1)` orbits
   on Z.
2. **Dense minima.** If `δ_K > 0` for some `K`, choose in each orbit on `N_0` its least element,
   and in each orbit on the negative integers the element of least absolute value. For
   `N ≥ 2^(K+D)` this set of representatives has at least `δ_K N / 2^(K+2)` elements in
   `[0, N]`, and as many in `[−N, −1]`. So it has positive lower density.

In particular every finitely generated subgroup of `CT_∅(Z)` satisfies the dichotomy of
Kourovka 20.44.

## Proof

**1.**
- `C_K` is clopen of measure 1, and a nonempty clopen set has positive measure. So `C_K` is
  the whole Cantor set, for every `K`.
- Let `x = w0^∞ ∈ N_0` with `|w| = ℓ`, and consume position `K = ℓ` along some sequence of moves.
- Just before the consuming move, the tracked letter `0` sits at a position `p < D`. Every letter
  below it is an untouched original `0`.
- So the configuration is `v0^∞` with `|v| = p < D`, an integer in `[0, 2^D)`, in the orbit
  of `x`.
- For negative integers the same argument works with `1^∞`. ∎

**2, step 1: the frozen tail is an orbit invariant.**
- For `x` with some position non-consumable, let `κ(x)` be the least such position. Positions
  beyond it are non-consumable too, by monotonicity.
- Put `T(x) = σ^(κ(x)) x`. The letters of `T(x)` are never touched, so every `y` in the orbit
  has the form `y = v·T(x)`, with `v` the current stack.
- **Claim: `T(y) = T(x)`.**
  - A path from `y` that consumes a letter of `T(x)` would extend the path `x → y` to one that
    consumes it from `x`. So `κ(y) ≤ |v|`.
  - Suppose `κ(y) < |v|`. The letters of `y` from position `κ(y)` on are never touched on the
    reverse path `y → x`. So `x = v'·v[κ(y), |v|)·T(x)`.
  - That letter of `v` is non-consumable from `x`, by the same concatenation argument. Hence
    `κ(x) ≤ |v'| = κ(x) − (|v| − κ(y)) < κ(x)`, which is absurd.
  - So `κ(y) = |v|` and `T(y) = T(x)`.

**2, step 2: counting.**
- Let `N_K = {x ∈ N_0 : K not consumable}` = `{κ(x) ≤ K}`. For `L ≥ K + D`, the integers in
  `[0, 2^L)` are exactly the words of length `L` followed by `0^∞`, and the event depends on the
  first `K + D` letters. So `|N_K ∩ [0, 2^L)| = δ_K 2^L`.
- An orbit `O` meets `N_K` only in points `x` with `⌊x/2^(κ(x))⌋ = T(O)` and `κ(x) ≤ K`. Such an
  `x` is fixed by `κ(x)` and its low `κ(x)` bits, so there are fewer than `2^(K+1)` of them.
- Hence at least `δ_K 2^(L−K−1)` orbits meet `[0, 2^L)`, and their minima are pairwise distinct
  and lie in `[0, 2^L)`.
- For `2^L ≤ N < 2^(L+1)` this gives `δ_K N / 2^(K+2)`. The negative half is identical, with
  `1^∞`. ∎

## Remarks

- **Examples.**
  - `V` itself is in case 1, with one orbit on `N_0`.
  - The element `n ↦ n/2` on `0(4)`, `n − 1` on `2(4)`, `2n + 1` on `1(2)` is in case 2.
    - Its letters below a leading `10` or `01` block are frozen.
    - Its orbit minima are the class `1(4)`.
- **Why one prime is tame.**
  - With one prime, a canonical map is a single-stack operation. The only way to reach deep
    letters is to pop down to them, and whether that is possible is decided by a bounded
    prefix.
  - With two primes (`CT_{{3}}(Z)`), a canonical map between a box with 2-power modulus and
    one with 3-power modulus multiplies each coordinate by a unit of the other prime. Every
    move then carries into arbitrarily deep digits.
  - So "depth reached" is no longer a prefix property. Kohl's `G_T` shows the dichotomy there
    is exactly finiteness of the 3x+1 components.

## Lesson for general BH

**One stack gives a frozen-tail invariant.**
- In a one-base host, a finitely generated subgroup either reaches every deep digit, and then
  has finitely many orbits, or it freezes a clopen positive-measure set of deep digits, and the
  frozen tail is an orbit invariant of positive density.
- The dichotomy is a measure statement about a clopen family `C_K`, decided at bounded depth.

**Two bases destroy it.** The carry makes depth non-local, and orbit statistics become
Collatz-type. This is the same one-base/two-base split as torsion (ray-cocycle pumping) and
Out(CT_P(Z)) (Cobham rigidity). Host constructions that need tame subgroup orbits should stay
inside one-stack (one-base) coordinates.

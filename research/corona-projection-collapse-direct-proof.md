## Direct proof

A second, independent route: the rank-cocycle argument of the involutive
collapse run directly at projection level, with no bootstrap through the
subgroup generated by the sign.

**Exact commuting lifts.**  Enumerate the orbit projections
`p_lambda = pi(lambda) p pi(lambda)^*`.  Inductively, average a
self-adjoint lift of the next projection over the finitely many joint
spectral blocks of the previously corrected lifts — this preserves its
corona class because the classes commute — and round spectrally at `1/2`.
This produces exact projections `P_{lambda,n}` lifting `p_lambda`,
commuting exactly for all `n`, and covariant in operator norm:
`‖U_n(g) P_{lambda,n} U_n(g)^* - P_{g lambda,n}‖ -> 0`.

**The rank pseudometric.**  `d_n(lambda,mu) = rank(P_{lambda,n} -
P_{mu,n})` is the Hamming distance of simultaneous 0/1 labels, satisfies
`Tr|P_{lambda,n} - P_{mu,n}|^2 = d_n(lambda,mu)`, and is eventually
translation invariant: asymptotically equal 0/1-spectrum matrices at
operator distance below `1/2` have equal rank.

**The self-normalized cocycle.**  Suppose some `p_{gamma_0} != p`; then
`d_n(1,gamma_0) >= 1` along a subsequence, so
`r_n = sum_{a in S} d_n(1,a) >= 1` for a Kazhdan generating set `S`.  In
the ultraproduct of the Hilbert spaces `(M_{d_n}, Tr/r_n)` the classes
`c(lambda) = [P_{lambda,n} - P_{1,n}]` are well defined (word-length
bound from translation invariance), carry total generator mass exactly
`1`, and satisfy the exact cocycle identity for the conjugation
representation: the defect matrix has rank `O(r_n)` and vanishing
operator norm, hence vanishing mass at scale `r_n` by
`Tr(M^*M) <= rank(M) ‖M‖^2`.

**Transport and contradiction.**  Property (T) supplies a primitive `w`
for the cocycle.  The compressed generators fix `w` because the
compressed copy centralizes `p`, so the pullback `sigma(s)^* w` is
`L`-fixed; the fixed-space equality of the finite-target Kazhdan calculus
(`kazhdan-projection-finite-target-calculus`, clause 1, in the weighted
ultraproduct) returns `w` itself `L`-fixed, making every `c(a)` vanish —
against total generator mass `1`.  Hence `p_lambda = p` for all
`lambda in L`.

**Relation to the committed route.**  The bootstrap route
(`corona-projection-collapse-proof`) reaches the same target through the
kernel-checked involutive endpoint and is the preferred formalization
path; this route shows the theorem needs nothing beyond the rank-cocycle
engine that endpoint formalizes, and stays available if the witness
bootstrap is ever re-architected.

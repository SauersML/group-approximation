**Imported inputs** (verbatim; standard, used as black boxes).

- **(I1) Sikorav.** A. Suciu, *Sigma-invariants and tropical varieties*,
  arXiv:2010.07499, abstract: "The Bieri-Neumann-Strebel-Renz invariants
  Σ^q(X,ℤ)⊂H^1(X,ℝ) of a connected, finite-type CW-complex X are the vanishing loci
  for Novikov-Sikorav homology in degrees up to q". We use `q = 1` and
  `Σ^1(G; Z) = Σ^1(G)` for finitely generated `G`. This is the same import as input 1
  of `bnsr-invariants-stabilize-at-cohomological-dimension-proof`.
  - There the coefficient ring is `\widehat{ZG}_{-χ}`.
  - Below, vanishing is proved for both signs of `χ` and for both module
    conventions, so the sign and side conventions of the source do not matter.
- **(I2) Bieri–Renz**, as stated in K. Almeida, arXiv:1605.00271v1, §1.1: "Theorem 1.2
  ([8]). Let G be a group of homological type F Pm and H be a subgroup of G containing
  the commutator [G, G]. Then H is of type F Pm if and only if S(G, H) := {[χ] ∈ S(G) |
  χ(H) = 0 } ⊂ Σ m(G, Z)." We use `m = 1` and `H = ker χ`, so `S(G,H) = {[χ],[-χ]}`.
  Artin groups are finitely presented, hence `FP_1`.

**Notation.**
- `a = u1`, `b = u2`, `c = v1`, `e = v2`; `G = A_{K_q}`, `q = 2m + 1`.
- `S_k(z) = 1 + z + ... + z^{k-1}`.
- `X` is the presentation 2-complex of the Artin presentation: generators
  `a, b, c, e`; relators `[a,b]`, `[c,e]`, `r_{ac}, r_{bc}, r_{be}` with `k = 2`, and
  `r_{ae}` with `k = q`, where `r_{xy} = (xy)^k (yx)^{-k}`.
- `N` is the Novikov ring for `χ`: formal sums `Σ n_g g` (`g ∈ G`) such that for every
  `t` only finitely many `g` with `n_g != 0` have `χ(g) < t`. It is a ring containing
  `ZG`.
- `N_{>=s}` is the set of elements supported in `χ >= s`. It is closed under sums and
  products, and `N_{>=s} N_{>=s'} ⊆ N_{>=s+s'}`.

**Step 0 (units of `N`).**
- If `δ ∈ N_{>=1}`, then `1 - δ` is a unit with inverse `Σ_{n>=0} δ^n`. The sum
  converges because `δ^n ∈ N_{>=n}`.
- If `χ(g) > 0`, then `g - 1 = -(1 - g)` is a unit.
- If `χ(g) < 0`, then `g - 1 = -g(1 - g^{-1})` is a unit.
- Hence `a - 1`, `b - 1`, `c - 1`, `e - 1` are units of `N`.

**Step 1 (the complex).** Use `H_i(G; N) = Tor_i^{ZG}(N, Z)` for `i <= 1`. It is
computed by `N ⊗_{ZG} C_*(X̃)`, because `X` is the 2-skeleton of a `K(G,1)`.
- Elements of `C_1 = N^4` are rows `y = (y_a, y_b, y_c, y_e)`.
- `d_1(y) = Σ_x y_x (x - 1)`.
- `d_2` sends the basis element of a relator `r` to its Fox row `(∂r/∂x)_x`.
- All maps are left `N`-linear.
- `H_0 = N / Σ_x N(x - 1) = 0`, because `a - 1` is a unit.

The Fox rows, read in `G` (artifact check (1) does this in the free group ring):
- `[a,b]` gives `(1 - b, a - 1, 0, 0)`, and `[c,e]` gives `(0, 0, 1 - e, c - 1)`;
- `r_{xy}` (`x ∈ {a,b}`, `y ∈ {c,e}`) has `x`-entry `(1 - y) S_k(xy)`,
  `y`-entry `(x - 1) S_k(yx)`, and zeros elsewhere.

**Step 2 (`H_1 = N/L`).** Define `φ : ker d_1 -> N` by `φ(y) = y_a(a - 1) + y_b(b - 1)`.
This equals `-(y_c(c - 1) + y_e(e - 1))`.
- `φ` is left `N`-linear. It is onto: `y = (n(a-1)^{-1}, 0, -n(c-1)^{-1}, 0)` lies in
  `ker d_1` and has `φ(y) = n`.
- `ker φ ⊆ im d_2`. Let `φ(y) = 0` and put `λ = y_b (a - 1)^{-1}`. Since `a` and `b`
  commute in `G`, `(a - 1)^{-1}` commutes with `b - 1`. Then
  `y_a = -y_b(b - 1)(a - 1)^{-1} = λ(1 - b)`, so `(y_a, y_b) = λ·(1 - b, a - 1)`.
  Likewise `(y_c, y_e) = μ·(1 - e, c - 1)` with `μ = y_e (c - 1)^{-1}`. So `y` is
  `λ·row[a,b] + μ·row[c,e]`.
- Hence `H_1 = ker d_1 / im d_2 ≅ N / φ(im d_2)`. Here `φ(im d_2)` is the left ideal
  generated by the `φ`-values of the Fox rows. The commutator rows give `0`
  (`(1-b)(a-1) + (a-1)(b-1) = ab - ba = 0`). The row of `r_{xy}` gives
  `(1 - y) S_k(xy)(x - 1)`, and `1 - y` is a unit. So
  `H_1(G; N) ≅ N / L` with
  `L = N S_2(ac)(a-1) + N S_2(bc)(b-1) + N S_2(be)(b-1) + N S_q(ae)(a-1)`.

**Step 3 (the unit identity).** Put `x = ae` (so `χ(x) = 0`) and
`T = Σ_{j=0}^{m-1} x^{2j}`. In the free group ring `Z F(a,b,c,e)`:

    x^{2m} = S_q(x) - T S_2(ac) + T a b^{-1} S_2(bc) - T a b^{-1} S_2(be).

Proof by hand. `S_2(bc) - S_2(be) = b(c - e)`, so the last two terms equal
`T a (c - e) = T(ac - x)`. The right side is therefore
`S_q(x) - T(1 + ac) + T(ac - x) = S_q(x) - T S_2(x) = S_q(x) - S_{2m}(x) = x^{2m}`.
Artifact check (2) confirms it symbolically for every odd `q <= 41`.

Multiply on the left by `x^{-2m}`. Then `1 = Σ λ_{ij} S_{k_{ij}}(u_i v_j)` in `ZG`,
with coefficients
- `λ_{ae} = x^{-2m}`,
- `λ_{ac} = -x^{-2m}T`,
- `λ_{bc} = x^{-2m} T a b^{-1}`,
- `λ_{be} = -x^{-2m} T a b^{-1}`.

All of them lie in `Z[ker χ]`, because `χ(x) = χ(ab^{-1}) = 0` (artifact check (3)).
So the four dead-edge sums generate the unit left ideal of `Z[ker χ]`.

Now `L` contains
`Σ λ_{ij} S_{k_{ij}}(u_i v_j)(u_i - 1) = δ - 1`, where
`δ = Σ λ_{ij} S_{k_{ij}}(u_i v_j) u_i`.
- Each `λ_{ij} S_{k_{ij}}(u_i v_j)` is supported in `χ = 0`.
- `χ(u_i) = 1`, so `δ ∈ N_{>=1}`.
- By Step 0, `δ - 1` is a unit.

Hence `L = N` and `H_1(G; N) = 0`.

**Step 4 (the other sign and the other side).**
- *The other sign.* `σ : a <-> e, b <-> c` preserves every label of `K_q`, so it is an
  automorphism of `G`. It satisfies `χ ∘ σ = -χ` (artifact check (4)).
  - So `σ` extends to a ring isomorphism `N_χ -> N_{-χ}`.
  - It then gives `Tor_i^{ZG}(N_χ, Z) ≅ Tor_i^{ZG}(N_{-χ}, Z)`.
  - So `H_0` and `H_1` vanish for `-χ` too.
- *The other side.* The anti-involution `g -> g^{-1}` carries `N_χ` to `N_{-χ}` and
  exchanges the left and right module conventions.
  - So vanishing for both signs in the convention above gives vanishing for both
    signs in the other convention.
  - Whatever sign and side convention (I1) uses, `[χ]` and `[-χ]` lie in `Σ^1(G)`.

**Conclusion.** By (I2), `ker χ` is of type `FP_1`, i.e. finitely generated. `Liv^χ` is
disconnected because all four cross edges are dead. ∎

**What the proof shows.**
- Steps 0–2 use only this: each side of the dead cut is a label-2 clique of living
  vertices on which `χ` is constant, and every cross edge is dead. Step 3 is then
  the whole question.
- So a combination `1 = Σ λ_{ij} S(u_i v_j)` with `λ_{ij} ∈ Z[ker χ]`, or more
  generally with `λ_{ij} ∈ N_{>=0}`, puts the dead character in `Σ^1`.
- This is the exact counterpart of the dead-edge ring obstruction
  (`artin-sigma1-dead-edge-ring-obstruction`), which needs a ring in which all those
  sums vanish.
- For even `q` the sums all vanish in `Z` with `ρ(u_i v_j) = -1`. That is a
  commutative ring witness, matching the prime-2 family.
- The case left undecided sits between the two: the dead-edge sums generate a
  proper left ideal, but no ring kills them.

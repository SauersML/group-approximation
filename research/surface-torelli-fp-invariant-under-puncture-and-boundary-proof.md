Two group-theoretic facts are used. Both are proved in Steps 2 and 3 of
`ia-n-fp-iff-outer-torelli-fp-proof`.

- (a) If `G` is finitely presented and `N <= G` is a normal subgroup generated by
  finitely many elements, then `G/N` is finitely presented.
- (b) If `1 -> N -> G -> Q -> 1` is exact with `N` and `Q` finitely presented, then
  `G` is finitely presented.

Together they give: in an extension with finitely presented kernel, the middle
group is finitely presented if and only if the quotient is.

**Marked point.** For `g >= 2` the forgetful map gives the Birman exact sequence
`1 -> π_1(S_g) -> Mod(S_{g,1}) -> Mod(S_g) -> 1`
(Farb–Margalit, *A Primer on Mapping Class Groups*, the section "The Birman exact
sequence"). Marking a point does not
change the surface, so `Mod(S_{g,1})` acts on `H_1(S_g; Z)` through the forgetful
map. Hence `I_{g,1}` is the full preimage of `I_g`: the forgetful map restricts to
a surjection `I_{g,1} -> I_g`, and its kernel is the whole point-pushing subgroup
`π_1(S_g)`, because point-pushing maps become isotopic to the identity after
forgetting the point and so act trivially on `H_1(S_g; Z)`. This gives
`1 -> π_1(S_g) -> I_{g,1} -> I_g -> 1`, and `π_1(S_g)` has the one-relator
presentation `<a_1, b_1, ..., a_g, b_g | [a_1,b_1]...[a_g,b_g]>`. By (a) and (b),
`I_{g,1}` is finitely presented if and only if `I_g` is.

**Boundary component.** Capping the boundary of `S_g^1` with a once-marked disk
gives the exact sequence `1 -> Z -> Mod(S_g^1) -> Mod(S_{g,1}) -> 1`. Its kernel is
generated by the boundary Dehn twist `T_∂` (Farb–Margalit, *Primer*, the capping
homomorphism in the section "Cutting, capping, and including"). The inclusion `S_g^1 -> S_{g,1}` induces the identification
`H_1(S_g^1; Z) = H_1(S_g; Z)`, compatibly with the two actions, so `I_g^1` is the
full preimage of `I_{g,1}`. The twist `T_∂` acts on homology by the transvection
`x -> x + ⟨[∂], x⟩ [∂]`, and `[∂] = 0` because `∂` bounds the surface, so
`T_∂ ∈ I_g^1`. This gives `1 -> Z -> I_g^1 -> I_{g,1} -> 1`. By (a) and (b),
`I_g^1` is finitely presented if and only if `I_{g,1}` is.

Combining the two equivalences proves the claim.

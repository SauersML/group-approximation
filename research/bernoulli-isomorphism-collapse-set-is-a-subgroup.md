Let `G` be a countably infinite group. For `h ∈ [0, ∞]` let `X_h` be a Bernoulli shift
over `G` with base entropy `h`. Its isomorphism class depends only on `h`
(`bernoulli-shifts-with-equal-base-entropy-are-isomorphic`). Define

    D(G) = { d ∈ R : X_h ≅ X_(h+d) for some h ∈ [0, ∞) with h + d ≥ 0 },

and for `d ∈ D(G)` let `W_d` be the set of such `h`.

**Theorem.**
1. **Products.** `X_a × X_b ≅ X_(a+b)` for `a, b ∈ [0, ∞]`. If `X_h ≅ X_(h')`, then
   `X_(h+t) ≅ X_(h'+t)` for every `t ∈ [0, ∞]`.
2. **Upward closure.** If `h ∈ W_d` and `t ≥ 0`, then `h + t ∈ W_d`.
3. **Subgroup.** `D(G)` is an additive subgroup of `R`.
4. **Classification.** Base entropy classifies Bernoulli shifts over `G` if and only if
   `D(G) = {0}`. Equivalently, classification fails if and only if some `X_h` with
   `0 < h < ∞` absorbs a nontrivial Bernoulli factor: `X_h ≅ X_h × X_d` for some
   `0 < d < ∞`.
5. **Total collapse.** If `X_h ≅ X_∞` for some finite `h`, then `X_(h') ≅ X_∞` for
   every `h' ≥ h`, `D(G) = R`, and `h^Rok_sup(G) = 0`.
6. **Threshold and periodicity.** If `0 ≠ d ∈ D(G)`, every `h ∈ W_d` satisfies
   `min(h, h + d) ≥ h^Rok_sup(G)`. For `d_1, …, d_m ∈ D(G)` there is `θ` such that
   `X_h ≅ X_(h')` whenever `h, h' ≥ θ` and `h' − h` lies in the subgroup generated by
   `d_1, …, d_m`.
7. **Permanence.** If `G ≤ G'`, then `D(G) ⊆ D(G')`. If `H ≤ G` has finite index `k`,
   then `k·D(G) ⊆ D(H)`.
8. **Dichotomy hosts.** If `h^Rok_sup(G) ∈ {0, ∞}`, then `D(G) ≠ {0}` forces
   `h^Rok_sup(G) = 0`. This applies when `G` contains `G × G` and finite subgroups of
   unbounded order (`rokhlin-supremum-dichotomy-with-centralized-self-copies`), as for
   the binary Leavitt unit group and Thompson's `V`.

`D(G) = {0}` for every sofic `G`. For no nonsofic group is `D(G)` decided.

**Open structure questions** (recorded here, not claimed):
- whether `D(G)` is closed;
- whether `D(G) ∈ {0, R}`;
- whether `D(G) ≠ {0}` forces `h^Rok_sup(G) = 0` on every group. Item 8 gives this on
  dichotomy hosts, and item 5 gives it when collapse reaches `X_∞`.

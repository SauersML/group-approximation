Notation is as in the target. All modules are left modules. Right multiplication by a
ring element acts entrywise on `N^r`. Since every `f_ρ` has integer entries,
`(σ f_ρ) x = (σ x) f_ρ`.

**Step 0 (levels).**
- Fix `t ∈ G` with `χ(t) = 1`. For `λ ∈ N` and `n ∈ Z`, let `λ_n` be the sum of the terms
  of `λ` at level `n`.
- `λ_n` is a finite sum, because `λ` has only finitely many terms below level `n + 1`. It
  lies in `t^n Z[H] = Z[H] t^n`.
- If `σ ∈ Z[H]`, then `(λσ)_n = λ_n σ`.
- For `g ∈ G` with `χ(g) = c`, `(λ g)_n = λ_{n-c} g`.
- `λ_n = 0` for all `n` below some bound.
- The same holds entrywise for vectors.

**Step 1 (units, and the common right factor).**
- If `χ(g) > 0`, then `1 - g` is a unit of `N`, with inverse `Σ_{n>=0} g^n`. If
  `χ(g) < 0`, then `1 - g = -g(1 - g^{-1})` is a unit. In both cases `g - 1` is a unit.
- Fox calculus for `r = (pq)^k (qp)^{-k}`:
  - Using `(pq)^k (qp)^{-k} = 1` and `S_k(qp) q = q S_k(pq)` in `G`:
    `∂r/∂p = S_k(pq) - S_k(qp) q = (1 - q) S_k(pq)`.
  - Likewise `∂r/∂q = S_k(pq) p - S_k(qp) = (p - 1) S_k(qp)`.
  - The fundamental formula `(∂r/∂p)(p - 1) + (∂r/∂q)(q - 1) = r - 1 = 0` then gives
    `(1 - q) S_k(pq)(p - 1) = -(p - 1) S_k(qp)(q - 1)` in `ZG`.
- For a crossing D relation `ρ` of the star at `v`, write `σ_ρ = S_k(pq)`, as in the table.
- **Claim:** `N g_ρ = N σ_ρ (u - 1)`.
  - If `v = p`, then `χ(v) > 0`, `u = p`, and `g_ρ = σ_ρ (u - 1)` exactly.
  - If `v = q`, then `χ(v) < 0` and `u = q^{-1}`.
    - `1 - q` and `p - 1` are units, so the displayed identity gives
      `N g_ρ = N S_k(qp)(q - 1)`.
    - Now `S_k(qp) = q S_k(pq) q^{-1}`, so
      `S_k(qp)(q - 1) = q σ_ρ q^{-1}(q - 1) = q σ_ρ (1 - q^{-1}) = -q σ_ρ (u - 1)`.
    - `-q` is a unit, so `N g_ρ = N σ_ρ (u - 1)`.
- D relations with `[p] = [q]` have `f_ρ = 0` and are discarded.
- V and W relations have `g_ρ = σ_ρ ∈ Z[H]`. For W, every prefix of `r_{wx}` has level 0.
- Hence `im L_χ = Σ_{ρ∈D} N σ_ρ f_ρ (u - 1) + Σ_{ρ∈V∪W} N σ_ρ f_ρ`.

**Step 2 (telescoping).**
- Let `c = χ(u) > 0`. Suppose `L_χ` is onto, and fix `f ∈ K_r(Z)`. By Step 1,
  `f = A(u - 1) + B` with:
  - `A = Σ_D λ_ρ σ_ρ f_ρ`;
  - `B = Σ_{V∪W} μ_ρ σ_ρ f_ρ`;
  - `λ, μ ∈ N`.
- By Step 0:
  - `A_n = Σ (λ_ρ)_n σ_ρ f_ρ ∈ t^n M_D` and `B_n ∈ t^n M_VW`;
  - `(A u)_n = A_{n-c} u`;
  - `f_0 = f` and `f_n = 0` for `n ≠ 0`.
- Comparing levels:
  - (L_n) `A_{n-c} u - A_n + B_n = 0` for `n ≠ 0`;
  - (L_0) `A_{-c} u - A_0 + B_0 = f`.
- (L_{-mc}) gives `A_{-mc} = A_{-(m+1)c} u + B_{-mc}` for `m >= 1`. Iterating from `m = 1`:
  `A_{-c} u = A_{-(M+1)c} u^{M+1} + Σ_{m=1}^{M} B_{-mc} u^m`.
- For `M` large, `A_{-(M+1)c} = 0`, because `A` is bounded below. So
  **`f = -A_0 + B_0 + Σ_{m=1}^{M} B_{-mc} u^m`.**
- Artifact `telescope_check.py` checks this identity in its general form, with the error
  terms `f_{-mc}` kept. It uses 400 random `A`, `B` in `Z[Z^2 ⋊ Z]^3` and `c = 1, 2, 3`.

**Step 3 (placing the terms).**
- `-A_0 ∈ M_D` and `B_0 ∈ M_VW`.
- For `m >= 1`, write `B_{-mc} = t^{-mc} y` with `y ∈ M_VW`, which is possible by Step 0.
- Then `B_{-mc} u^m = h_m (u^{-m} y u^m)` with `h_m = t^{-mc} u^m`.
- `h_m ∈ H`, because `χ(h_m) = -mc + mc = 0`.
- `u^{-m} y u^m ∈ u^{-m} M_VW u^m`. This is a left `Z[H]`-module, because conjugation by
  `u^{-m}` is a ring automorphism of `Z[H]`, as `H` is normal.
- So `f ∈ M_D + Σ_{m=0}^{M} u^{-m} M_VW u^m`.
- `K_r(Z[H]) = Z[H] ⊗ K_r(Z)` is generated by `K_r(Z)`, and the right-hand side is a left
  `Z[H]`-module. This proves **part 1**.

**Step 4 (parts 2 and 3).**
- **Part 2.** Under (Stab), every term in Step 3 lies in `M_D + M_VW = im L_0`. So `L_0` is
  onto.
- **Part 3.** If all V and W vectors vanish, then `M_VW = 0`.
- Suppose instead that every dead `w` is joined to `v` by an edge of label 2, so `wv = vw`.
  - Then `u` commutes with `w - 1`.
  - For a dead–dead edge `{w,x}`, `∂r_{wx}/∂w` is a `Z`-combination of words in `w` and
    `x`, both of which commute with `u`.
  - So `u^{-m} σ_ρ u^m = σ_ρ` for all `ρ ∈ V ∪ W`, and (Stab) holds with equality.

**Step 5 (part 4).**
- Let `M_VW = 0` and `v ∈ B_1`. Every crossing D relation joins `B_1` (through `v`) to some
  `B_j` with `j >= 2`. Its vector is `±σ_ρ (e_1 - e_j)`.
- So `M_D = {x ∈ K_r(Z[H]) : x_j ∈ I_j for j >= 2}`, since `x_1` is then determined. It
  equals `K_r(Z[H])` iff `I_j = Z[H]` for all `j >= 2`.
- The augmentation `Z[H] -> Z` sends `S_k(pq)` to `k`. So `I_j = Z[H]` forces the halves
  into `B_j` to have greatest common divisor 1.

**Remarks.**
- The converse of part 2 (`L_0` onto ⇒ `L_χ` onto) is part 3 of the held wave-17 criterion.
  It is not needed here.
- The swap toy of wave 19 fails exactly at Step 1: its two generators have the distinct
  right factors `ab·t - 1` and `t - 1`. Step 2 then produces the mixed terms that the w19
  depth hierarchy `R_m` records.
- Without (Stab), part 1 still pins the possible leak to the `u`-conjugates of the V/W
  span.

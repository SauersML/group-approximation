**Imports (textbook, not re-read).**
- (GF) Generic freeness (Eisenbud, *Commutative Algebra*, Thm 14.4): for a finitely generated module `M` over a
  finitely generated commutative ring there is `m >= 1` with `M[1/m]` free over `Z[1/m]`.
- (DVR) Finitely generated modules over the discrete valuation ring `Z_(p)` are of the form
  `Z_(p)^r ⊕ torsion` with torsion of bounded exponent.
- (E) Excision for ideals with local units, Quillen's computation `K_0(S) = Z` for the principal ideal domain
  `S`, and `K_(−1) = 0` for regular rings. These are as in `harmonic-coefficient-rings-are-k-equivalent-to-lc-proof`.

**Part 1.** Let `S_0` be the finite set of primes dividing the `m` given by (GF) for the module at the start. Fix
`p ∉ S_0`, and localize at `p`, which is exact.

Call a `Z_(p)`-module *good* if it has a finite filtration whose quotients are each free or finitely generated.
- The starting module becomes free.
- An extension of a good module by a finitely generated one is good.
- A quotient of a good module `G` by a finitely generated submodule `F` is good. Filter by
  `(G_i + F)/(G_(i−1) + F)`, a quotient of `G_i/G_(i−1)` by a finitely generated submodule. A free module modulo a
  finitely generated submodule is finitely generated plus free, since `F` lies in a direct summand of finite rank.
- So `C_(p)` is good.

In a good module `G`, `∩_e p^e G = 0`. Induct on the filtration `0 -> A -> G -> Q -> 0`, with `Q` free or finitely
generated, whose `p`-torsion has exponent at most `p^n`.
- If `y ∈ ∩_e p^e G`, its image lies in `∩_e p^e Q = 0`, so `y ∈ A`.
- Write `y = p^(e+n) b`. Then the image `q` of `b` satisfies `p^(e+n) q = 0`, hence `p^n q = 0` and `p^n b ∈ A`.
- So `y ∈ p^e A` for every `e`, and `y = 0` by induction.

Now if `x ∈ ∩_e p^e C`, then `x ⊗ 1 ∈ ∩_e p^e C_(p) = 0`. So `s x = 0` for some `s` prime to `p`, contradicting
infinite order. Hence `p ∈ S_0`. ∎

**Part 2.**
- **K_0(B⁺).** For each type, (E) gives `K_0(B⁺) = Z^(N) ⊕ Z`, the indicator classes `LC(N ∪ ∞, Z)`. The boundary
  from `K_1(S)` vanishes because every unit of `S` lifts after a finite correction, and `K_(−1)(B⁺) = 0`. So under
  (P), `K_0(R) = coker(1 − [X])`.
- **Module structure.** Let `t` push indicators forward along `N ↦ N + 1`. The group `G = ⊕_types LC(N ∪ ∞, Z)`
  is a finitely generated `Λ = Z[t]`-module, generated by the classes `[N = 0]` and `[all]` of each type.
- **Relations.** Let `r_k` be the relation from the level-`k` class of a type, and let `K` bound all the shifts and
  exceptional availabilities.
  - For `k >= K`, shifts give `r_(k+1) − t r_k = 0`, and resets add the same fixed vector for every `k`.
  - So `r_(k+1) − r_k = t^(k−K) (t − 1) e` for a fixed `e`. The relation group contains the `Λ`-submodule
    `Λ t^K (t − 1) e`, and is generated by it together with finitely many `r_k` and the relations of the
    finitely many tail classes.
- **Conclusion.** `K_0(R)` is therefore a finitely generated `Λ`-module modulo a finitely generated subgroup, and
  part 1 applies. ∎

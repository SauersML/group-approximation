**ESTABLISHED.** Let `F` be a finite field, `J = F<S,T | TS=1>`, `Q = 1 - ST`,
and `E_n = EL_n(J)`. Write elements of `E_(m+2)` in `2 + m` block form.

**(P1) Column parabolics are LEF.** For `m >= 1` let

```text
G_m = { [[g, X], [0, c]] : g in EL_2(J), X in M_(2 x m)(J), c in GL_m(F) } <= GL_(m+2)(J),
```

and let `G_m^el` be the subgroup with `c in EL_m(F)`; `G_m^el <= E_(m+2)`.
Then `G_m` is LEF, hence sofic, hyperlinear and MF, with `Rad_MF(G_m) = 1`.
In particular

```text
G_1 = J^2 x| EL_2(J) = < x_12(J), x_21(J), x_13(J), x_23(J) > <= EL_3(J)
```

is LEF. It contains both three-index commutator families
`[x_12(a), x_23(b)] = x_13(ab)` and `[x_21(a), x_13(b)] = x_23(ab)`, the
Toeplitz commutator `[x_12(S), x_23(T)] = x_13(1 - Q)`, and the head
`x_13(Q)`. The head has nontrivial image in the local models.

**(P2) Every proper parabolic of EL_3(J) is LEF.** Let `Psi` be a proper closed
set of roots of `A_2` and `U_Psi = < x_alpha(J) : alpha in Psi >`. Then `U_Psi`
is LEF. Every such `Psi` lies in a maximal parabolic set
`{alpha : lambda(alpha) >= 0}`. The maximal parabolic subgroups are conjugate
in `EL_3(F)` either to `G_1` (column type) or to its image under the
automorphism `Theta(g) = (g^tau)^(-1)` of `EL_3(J)` (row type).

**(P3) The head dies in every finite quotient of G_1.** For every finite group
`H` and every homomorphism `pi : G_1 -> H`, `pi(x_13(Q)) = 1`. So `G_1` is LEF
but not residually finite. Hence it is not finitely presented.

**(P4) Sharp generation boundary.**
`< G_1, x_31(1) > = < G_1, x_32(1) > = EL_3(J)`. More generally, `G_m^el`
together with any one reverse constant root `x_(alpha i)(1)`, `alpha > 2`,
`i <= 2`, generates `E_(m+2)`.

## Consequence: every one-parabolic argument dies

Take any argument that the head `x_13(Q)` dies in MF models, finite models or
sofic models. Suppose it uses only relations that hold in a single proper
parabolic of the root system on one index triple, together with any relation
of the Levi `EL_2(J)`. This includes:
- the Whitehead involution, the Fredholm index and the symbol cocycle;
- the compressor `u = [[S, Q], [0, T]]`;
- both three-index commutator families;
- the w7 pair `(K, N) = (G_1, J^2)` with relative-(T)-style projections;
- finite-image module collapse.

Such an argument would kill the head in the LEF group `G_1`, which is
impossible. The invariant that survives is the local embedding

```text
Psi_(M,d)(g, X, c) = [[Phi_M(g), ev_d(X)], [0, c (x) 1_d]].
```

Here `Phi_M` is the mirror-glued model of `binary-jacobson-el2-is-lef` and
`ev_d` evaluates the column on the first `d` basis vectors.

Only (P4) and the dichotomy of
`binary-jacobson-mark-dichotomy-holds-from-rank-two` remain for three indices.
By (P4), an argument confined to one index triple must use the whole group
`EL_3(J)`. By the dichotomy, killing the head there is the same as proving
`EL_3(J)` is not MF. That is open, and strictly stronger than what the
rank-five property (T) route gives. A (T)-free head-collapse proof must
therefore either use two opposite parabolics on some triple together, which is
the full `EL_3(J)`, or use at least four indices. From four indices on,
`EL_n(J)` is already known not to be LEF (`cohn-elementary-group-is-not-lef`),
so there the local-embedding invariant is gone. That non-LEF statement is not a
head-death statement, however.

(P3) makes the separation between finite and MF visible inside `G_1`. Finite
quotients kill the head, because a finite module over `J` makes `S` invertible.
The head nevertheless survives in finite *local* models. So any
exact-quotient or module-collapse mechanism is blind to the difference that
matters.

**OPEN.**  Compile the terminal violations emitted by
`opnorm-support-profile-challenge-library` back to one fixed marked word `w_e`
so that on every nonhalting instance there are finite relator prefixes
`R_(e,N)`, numbers `b_(e,N)->0`, and finite constants `C_(e,N)` satisfying

```text
||w_e(U)-I||_op
 <= b_(e,N) + C_(e,N) Def_(R_(e,N))(U)                  (OSR1)
```

for every finite-dimensional unitary tuple `U` and every fixed depth `N`.
No bound, computability condition, or runtime uniformity is imposed on
`C_(e,N)`.

Conjugacy is a lossless address transport because

```text
||a(U)^(-1) r(U) a(U)-I||_op = ||r(U)-I||_op.
```

The missing part is the semantic return from the addressed terminal
challenge to the same `w_e`; long finite derivations and their arbitrarily
large depthwise constants are allowed by
`depthwise-opnorm-collapse-implies-mf-radical`.

## Attempts

- **Conjugacy-only routing.**  Conjugacy carries a terminal residual through
  an arbitrarily long address with no norm loss, but it only moves that
  residual; it does not prove that failure of the addressed challenge forces
  the original mark toward the identity.  A common-carrier checksum or
  self-similar boundary return is still needed.
- **Uniform proof-area bound.**  Demanding one runtime-independent constant is
  unnecessary and blocks natural long computations.  The active attack is
  instead to prove `(OSR1)` separately at each fixed depth and allow
  `C_(e,N)` to grow arbitrarily.
- **Support-only return.**  Presence of a finite CPU sector identifies where a
  challenge lives, but by itself supplies no algebraic implication back to a
  fixed word.  The return must use more than the anonymous multiplicity or
  support label.

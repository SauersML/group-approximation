**ESTABLISHED** (lane proof, elementary given Matui's theorem; not reviewed; no novelty claimed).
The imported input is Matui, arXiv:1210.5800v3, Theorem `simple2`, read at source: if `G` is an
essentially principal étale groupoid on a Cantor set that is purely infinite and minimal, then
every nontrivial subgroup of `[[G]]` normalized by `D([[G]])` contains `D([[G]])`.

## Statement

Let `G` be as in Matui's theorem, `X = G^(0)`, `F = [[G]]` and `D = D(F)`. For clopen `C`, let `F_C = {g in F : supp g ⊆ C} ≅ [[G|C]]` be the local full group
and `D_C = D(F_C) <= D` its commutator subgroup. Let `Gamma <= F` be **compressible**: for every proper clopen
`E ⊊ X` and every nonempty clopen `C`, some `gamma in Gamma` has `gamma(E) ⊆ C`.

1. **Criterion.** `Gamma ⊇ D` if and only if `Gamma ⊇ D_C` for one nonempty clopen `C`.
2. **Finite index.** `[F : Gamma] < infinity` if and only if `Gamma ⊇ D` and the image of
   `Gamma` in `F/D` has finite index.
3. **Certificates.** It suffices that `Gamma` contain finitely many elements supported in `C` that
   generate `D_C`. For Thompson-type hosts this is a finite list of explicit local elements, for
   example local copies, on one cone, of a generating set of `V = D(V)`.
4. **Compressibility is cheap.** Suppose some `Lambda <= Gamma` acts on a locally finite tree `T` with
   `∂T ≅ X` equivariantly, and is non-elementary with full limit set (for example a free product
   acting on its Bass--Serre tree). Then `Gamma` is compressible, by north--south dynamics of
   hyperbolic elements.
5. **The tree obstruction is exactly equicontinuity.** Suppose `Gamma` acts on `X` through
   automorphisms of a leafless locally finite tree `T` with `∂T ≅ X`, and `C` is a clopen set whose
   complement has interior. Then every element of `Gamma` supported in `C` fixes a half-tree, hence a
   vertex. So it lies in a compact vertex stabilizer and maps no clopen set strictly into itself: an
   equicontinuous homeomorphism of a compact space admits an invariant metric, and an isometric
   self-embedding of a compact metric space is onto. So if `D_C` contains an element mapping a clopen set
   strictly into itself, then `Gamma ⊉ D` and `[F : Gamma] = infinity`.

## Proof

(1) The "only if" direction is trivial, since `D_C <= D`. For "if", let `E` be proper clopen and pick
`gamma` with `gamma(E) ⊆ C`. Then `gamma F_E gamma^-1 = F_(gamma E) <= F_C`, so
`D_E = gamma^-1 D_(gamma E) gamma <= gamma^-1 D_C gamma <= Gamma`. The group `N` generated by all
`D_E`, with `E` proper clopen, lies in `Gamma` and is normalized by `F`, since `f D_E f^-1 = D_(fE)`.
It is nontrivial: `F_E ≅ [[G|E]]` is purely infinite and minimal, hence nonabelian. By Matui, `N ⊇ D`.

(2) If `[F:Gamma] < infinity`, the normal core `K` of `Gamma` meets the infinite group `D` in a
finite-index, hence nontrivial, subgroup normalized by `D`. So `K ⊇ D`. The converse is clear.

(4) Given `E` proper clopen and `C` nonempty, choose a hyperbolic `h in Lambda` whose repelling end
lies in the interior of `X \ E` and whose attracting end lies in `C`. Pairs of hyperbolic fixed points
are dense in `∂T x ∂T`. Then `h^n(E) ⊆ C` for large `n`.

(5) This is as stated.

## Where it applies

- **Unequal-radix shell** (`unequal-radix-free-product-near-group-passes-both-germ-gates`). `H` is
  the full group of a purely infinite minimal effective groupoid. `lambda(A_0 * A_1)` acts on its
  Bass--Serre tree, so `R_nu` is compressible by (4). So `[H : R_nu] < infinity` if and only if
  `R_nu ⊇ D_C` for one cone `C`, plus the abelianization condition. The element of
  `unequal-radix-near-group-has-a-local-expanding-element` is a necessary local ingredient: it
  lies in `Rist(root 1)` and is not tree-type for the digit trees.
- **Twisted `C_2*C_3` shell** (`tree-compatible-fixed-base-enumerations-have-infinite-index`,
  Attempt 1). `<tau, w>` acts on `T_3`, so `R = <tau, w, x_1^-1 a x_1>` is compressible. So
  `R = B` if and only if `R` contains local copies, on one cone, of a generating set of `V`.
- **The known kills.** The equal-radix benchmark (`arithmetic-a5-near-group-is-not-finitely-presented`)
  and tree-compatible enumerations fail (5).

## Lesson for general BH

For any full-group host (Thompson, Röver--Nekrashevych, odometer, `k`-graph, or twisted Brin--Thompson
hosts), finite index of a subgroup is a LOCAL property. It holds exactly when the subgroup contains
the commutator subgroup of the local full group on one clopen set, and compressibility comes for free from
any tree-like piece. The only obstruction mechanism is equicontinuity of rigid stabilizers, of which
tree compatibility is one instance. Any construction that needs a subgroup to be "almost all" of a
full group (shell germ gates, near groups, actor subgroups) can be checked by a finite local
certificate instead of a global generation argument.

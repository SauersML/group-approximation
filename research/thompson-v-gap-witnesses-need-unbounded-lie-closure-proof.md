`sigma : G0 -> U(n)` is a unitary representation, `Gamma = sigma(G0)`, `K = K_sigma` its closure,

## Inputs

  attained and `> 0`, `delta_(n+1) <= delta_n`, and `delta_n` is the minimum of `D` over nontrivial
  irreducibles of dimension `<= n`. Hence every nontrivial representation `rho` of dimension `<= n`
  has `D(rho) >= delta_n`: it has a nontrivial irreducible summand, and the defect of an orthogonal
  direct sum is the maximum over the summands.
- **[S]** `thompson-v-finitely-presented-infinite-simple`: `V` is infinite and simple. Hence:
  - (S1) every homomorphism from `V` to a finite group is trivial, since its kernel is `1` or `V`,
    and `V` is infinite;
  - (S2) `V` is perfect, since it is simple and nonabelian (an abelian simple group is finite). So
    every homomorphism from `V` to an abelian group is trivial.
- **Standard facts** (the closed subgroup theorem and basic Lie theory; see e.g. B. C. Hall,
  *Lie Groups, Lie Algebras, and Representations*, 2nd ed., GTM 222, Chapters 2-3 and 5; and
  Brocker--tom Dieck, *Representations of Compact Lie Groups*, GTM 98, Chapter I). These are recalled,
  not re-read:
  - (L1) a closed subgroup `K` of `U(n)` is a Lie group with Lie algebra
    `l = {X in u(n) : exp(tX) in K for all real t}`;
  - (L2) `K^0` is open in `K`, so `K/K^0` is finite when `K` is compact, and `K^0` is generated by
    `exp(l)`;
  - (L3) `Ad(k) l = l` for `k` in `K`, and `Ad(k)` is a Lie algebra automorphism of `l`;
  - (L4) a continuous homomorphism `f : H -> K` of Lie groups is smooth, with differential `df` a Lie
    algebra homomorphism satisfying `f(exp X) = exp(df X)`. If `H` is compact and `f` is onto, then `df` is onto.
    (It is used only in Step 5, for the amplification corollary.)

Everything else below is proved here.

**Frequent tool (the transfer to finite quotients).** Let `Q` be a group and `f : G0 -> Q` a

`f` is trivial by (S1). If `Q` is abelian, `f` is trivial by (S2).

## Step 0: elementary lemmas

(E1) For unitaries `s, t`, `st - ts = (s-1)(t-1) - (t-1)(s-1)`. Hence
`||[s,t] - 1|| = ||st - ts|| <= 2 ||s-1|| ||t-1||`, where `[s,t] = s t s^(-1) t^(-1)`.

(E2) For unitaries, `||xy - 1|| <= ||x - 1|| + ||y - 1||`, `||x^(-1) - 1|| = ||x - 1||`, and
`||u x u^(-1) - 1|| = ||x - 1||`. For scalars `lambda, mu` of modulus one,
`[lambda x, mu y] = [x, y]`.

**Lemma O (orthogonal moves).** If `w` is unitary, `E` and `E'` are orthogonal subspaces with
`E` nonzero, and `wE` is contained in `E'`, then `||w - 1|| >= sqrt 2`. Indeed, for a unit vector
`v` in `E`, `wv` is orthogonal to `v`, so `||wv - v||^2 = 2`.

**Lemma P (powers).** If `c` is unitary and `c != 1`, then `||c^k - 1|| >= sqrt 3` for some `k >= 1`.
Proof: pick an eigenvalue `e^(i theta)` of `c` with `theta` in `(0, 2 pi)`. Since
`|e^(ik theta) - 1| = |e^(-ik theta) - 1|`, we may replace `theta` by `2 pi - theta` and assume
`theta` is in `(0, pi]`. If `theta >= 2 pi/3`, take `k = 1`. Otherwise let `k` be least with
`k theta >= 2 pi/3`. Then `k theta < 2 pi/3 + theta < 4 pi/3`. In both cases
`||c^k - 1|| >= |e^(ik theta) - 1| = 2 |sin(k theta/2)| >= 2 sin(pi/3) = sqrt 3`.

**Lemma F (a commutator that commutes with its first entry).** Let `x, y` be unitaries and
`c = [x, y]`. If `x c = c x` and `||y - 1|| < sqrt(3)/2`, then `c = 1`.
Proof: `x y x^(-1) = c y`. Induction using `x c = c x` gives `x^k y x^(-k) = c^k y` for all `k >= 1`.
So `||c^k - 1|| = ||c^k y - y|| = ||x^k y x^(-k) - y|| <= ||x^k y x^(-k) - 1|| + ||1 - y|| = 2||y - 1|| < sqrt 3`
for every `k`. By Lemma P, `c = 1`.

**Lemma C (commutator descent in a finite commutator set).** Let `P` be a set of unitaries on a
finite-dimensional space. Assume `P` is closed under products and inverses up to scalars (so `U(1) P` is
a group), and assume its image in the projective unitary group is **finite**. Let `x, y` be in `P`
with `||x - 1|| <= eta` and `||y - 1|| <= eta`, where `eta < 1/2`. Then `xy = yx`.
Proof: by (E2), a commutator of elements of `U(1) P` depends only on their projective classes. So
the set `Cm = {[p, q] : p, q in U(1) P}` is finite, and
`m = min{||g - 1|| : g in Cm, g != 1} > 0` (or `Cm = {1}`). Put `h_0 = y` and `h_(j+1) = [x, h_j]`.
Then `h_j` is in `Cm` for `j >= 1`, and by (E1)
`||h_j - 1|| <= (2 eta)^j eta`. Since `2 eta < 1`, some `h_J` with `J >= 1` has `||h_J - 1|| < m`,
so `h_J = 1`. Now descend. If `h_(j+1) = 1` with `j >= 1`, then `x` commutes with
`h_j = [x, h_(j-1)]`. Also `||h_(j-1) - 1|| <= eta < sqrt(3)/2`, since the bounds `(2 eta)^j eta` are
at most `eta`. So Lemma F gives `h_j = 1`. By induction `h_1 = [x, y] = 1`.

**Lemma A (adjoint contraction).** For `u` unitary and `X` in `M_n(C)`,
`u X u^* - X = (u - 1) X u^* + X (u^* - 1)`. Hence
`||u X u^* - X||_2 <= 2 ||u - 1|| ||X||_2`, using `||AB||_2 <= ||A|| ||B||_2` and
`||BA||_2 <= ||B||_2 ||A||`. So the conjugation operator `Ad(u)` on any `Ad(u)`-invariant real
subspace `m` of `u(n)`, with inner product `<X, Y> = Re tr(X^* Y)`, is orthogonal and satisfies
`||Ad(u)|_m - 1|| <= 2 ||u - 1||`. The complexification of a real linear operator `T` on a real
Hilbert space `m` has the same norm on `m_C = m + i m`, since
`||T(x + iy)||^2 = ||Tx||^2 + ||Ty||^2 <= ||T||^2 (||x||^2 + ||y||^2)`. So the complexified operator
`(Ad(u)|_m)_C` is unitary with `||(Ad(u)|_m)_C - 1|| <= 2 ||u - 1||`.

**Lemma Z (reductive splitting).** Let `l` be a real Lie subalgebra of `u(n)` and `z` its centre.
Then `l = z (+) [l, l]` orthogonally for `<.,.>`, and every automorphism of `l` preserves `z` and
`[l, l]`.
Proof: `<[X, Y], Z> = -<Y, [X, Z]>` for `X, Y, Z` in `u(n)`, because `ad X` is skew for this inner
product. So `Z` in `l` is orthogonal to `[l, l]` iff `<Y, [X, Z]> = 0` for all `X, Y` in `l`. Since
`[X, Z]` lies in `l`, this holds iff `[X, Z] = 0` for all `X` in `l`, that is, iff `Z` is in `z`.
So `z` is the orthogonal complement of `[l, l]` inside `l`. The subspaces are canonical, so every
automorphism preserves them.

## Step 1: imprimitive models (item 1)

Let `C^n = E_1 (+) ... (+) E_k` be orthogonal, with nonzero summands permuted by `Gamma`, and let
`p : G0 -> Sym(k)` be the permutation action. It is a homomorphism. Suppose `D < sqrt 2`. For each
`i`, `w_i E_j = E_(p(r_i) j)`. If `p(r_i) j != j`, Lemma O gives `||w_i - 1|| >= sqrt 2`, which is
impossible. So `p(r_i) = 1` for `5 <= i <= 8`, and `p` is trivial by the transfer tool, since
`Sym(k)` is finite. This proves the main statement of (1): a nontrivial permutation action forces
`D >= sqrt 2`.

(1a) If `sigma` is monomial in an orthonormal basis `e_1, ..., e_n`, the lines `C e_j` form such a
decomposition. If its permutation action is nontrivial, `D >= sqrt 2`. Otherwise every `sigma(g)` is
diagonal, so `sigma` is a sum of characters `chi_j` of `G0`. Some `chi_j` is nontrivial, and by
the transfer tool (abelian target) `chi_j` does not kill all of `r5, ..., r8`. The generators map to
roots of unity of orders dividing 2 or 3. The relations `a^2 = 1`, `b^3 = 1` and `(ab)^4 = 1` force
`chi(b) = chi(b)^4 = chi(a)^(-4) chi(ab)^4 = 1`. Then `(ac)^3 = 1` gives
`chi(c) = chi(a)^(-3) chi(c)^(-2) = chi(a)`, using `chi(a)^2 = chi(c)^2 = 1`. So `chi` takes values in `{+1, -1}`, and
some `chi_j(r_i) = -1`. Hence `D >= |(-1) - 1| = 2`.

(1b) For `sigma = Ind_H^(G0) tau` with `[G0 : H] = k >= 2`, the representation space is the
orthogonal sum of the `k` translates `g W`, one for each coset `gH`, where `W` is the space of `tau`.
`G0` permutes them as it permutes `G0/H`, which is transitive on `k >= 2` points, so the action is
nontrivial.

(1c) Let `sigma` be irreducible with `D < sqrt 2`. Decompose `C^n` under the compact group `K^0`
into isotypic components `E_tau`. These are mutually orthogonal, because `K^0` acts unitarily and
distinct irreducible types are orthogonal. Each `k` in `K` normalizes `K^0`, so `k E_tau = E_(tau^k)`
with `tau^k(h) = tau(k^(-1) h k)`. So `Gamma` permutes the components, and by the main statement it
fixes each of them. Each component is then a nonzero `Gamma`-invariant subspace, so by irreducibility
there is only one. On an isotypic space for the irreducible type `tau`, Schur's lemma makes every
element of `Z(K^0)` act on each copy of `tau` by the same scalar `tau(z)`. So `Z(K^0)` acts by
scalars.

## Step 2: abelian identity component (item 2)

**Reductions.** If `Gamma` is finite modulo scalars, then the image of `K` in `PU(n)` is the closure
of a finite set, hence finite. `K^0` is connected and maps into this finite set, so it maps to the
identity. Hence `K^0` is contained in `U(1) 1`, and in particular it is abelian. If `Gamma` has an
abelian subgroup `H` of finite index, then its closure `H-bar` is abelian by continuity, and `K` is
the union of finitely many closed cosets `gamma H-bar`. So `H-bar` is closed of finite index,
hence open, hence contains `K^0`, and `K^0` is abelian. It therefore suffices to treat the case
where `K^0` is abelian.

**Proof.** Let `sigma` be nontrivial irreducible with `K^0` abelian, and suppose `D < 1/2`. By
(1c), `K^0 = Z(K^0)` acts by scalars. So the map `K -> PU(n)` kills `K^0`, and its image is a
quotient of the finite group `K/K^0` (L2). Thus `U(1) Gamma` is a group with finite image in `PU(n)`.

Let `S` be the set of all `gamma w_i^(e) gamma^(-1)` with `gamma` in `Gamma`, `5 <= i <= 8` and
`e = +1 or -1`. By (E2) every `s` in `S` has `||s - 1|| <= D < 1/2`. Lemma C, applied with
`P = Gamma` and `eta = D`, shows that the elements of `S` commute pairwise. So `N = <S>` is an
abelian subgroup. It is normal in `Gamma`, because `S` is closed under conjugation by `Gamma`.

Let `Z_Gamma` be the intersection of `Gamma` with `U(1) 1`, which is central. Then `N Z_Gamma` is a normal subgroup, and
`Q = Gamma / (N Z_Gamma)` is a quotient of `Gamma / Z_Gamma`, the image of `Gamma` in `PU(n)`,
which is finite. The composite `G0 -> Gamma -> Q` kills each `r_i`, since `w_i` is in `S`. By the
transfer tool it is trivial, so `Gamma = N Z_Gamma`. This group is abelian. An abelian group of
unitaries has a common eigenvector, which spans an invariant line, so irreducibility gives
`n = 1`. Then `sigma` is a nontrivial character of `G0`, and the computation in (1a) gives
`D = 2`. This contradicts `D < 1/2`. Hence `D >= 1/2`.

## Step 3: the adjoint transfer (item 3)

Let `sigma` be nontrivial irreducible. If `D >= 1/2` there is nothing to prove, so assume `D < 1/2`.
Let `m = [l, l]`, so that `N_sigma = dim_R m`. By (L3) and Lemma Z, `Ad(k) m = m` for every `k` in
`K`, and `Ad(k)|_m` is orthogonal for `<.,.>`. Define

```text
rho(g) = ( Ad(sigma(g))|_m )_C     acting on m_C = m + i m,   dim_C m_C = N_sigma .
```

This is a unitary representation of `G0`, and `rho(r_i) = (Ad(w_i)|_m)_C`. By Lemma A,
`D(rho) <= 2 D`.

*Case A: `rho` is nontrivial.* Then `N_sigma >= 1`, and [R] gives `D(rho) >= delta_(N_sigma)`. Hence
`D >= delta_(N_sigma) / 2`.

*Case B: `rho` is trivial* (this includes `N_sigma = 0`). Then `Ad(gamma)` fixes `m` pointwise for
every `gamma` in `Gamma`. Since `Ad` is continuous and `Gamma` is dense in `K`, the same holds for
every `k` in `K`. Now let `Z` be in the centre `z` of `l`. For every `X` in `l`, `[Z, X] = 0`, so
`exp(tZ)` commutes with `exp(X)`. By (L2) `exp(tZ)` then commutes with all of `K^0`. It lies in
`K^0`, being on a continuous path from `1` in `K`. So `exp(tZ)` is in `Z(K^0)` for every `t`. By
(1c), which applies since `D < sqrt 2`, it is a scalar for every `t`, and differentiating at
`t = 0` shows that `Z` is a scalar. So `Ad(k)` also fixes `z` pointwise, and by Lemma Z it fixes
`l = z (+) m` pointwise. Then `k` commutes with `exp(l)`, hence with `K^0` by (L2). So `K^0` is
central in `K`, and in particular abelian. Step 2 gives `D >= 1/2`, which contradicts the
assumption. So Case B does not occur when `D < 1/2`.

Combining the cases gives `D >= min(1/2, delta_(N_sigma)/2)`. If `N_sigma <= N`, then
`delta_(N_sigma) >= delta_N`, since `delta` is nonincreasing and `delta_0 = 2 = delta_1`. So
`D >= c_N`, and `c_N > 0` by [R]. The constant does not depend on `n = dim sigma`.

## Step 4: Lie-irreducibility (item 4)

Let `sigma` be irreducible with `D < 1/4`. By (1c) the space is `tau`-isotypic for one irreducible
unitary representation `tau` of `K^0` on a space `W`. After a unitary change of basis,
`C^n = W (x) C^m` and `h` in `K^0` acts as `tau(h) (x) 1`. By Schur's lemma, the commutant of
`tau(K^0) (x) 1` is `1 (x) M_m(C)`.

*Tensor factorization.* Let `k` be in `K`. The representation `h -> k (tau(h) (x) 1) k^(-1)` of `K^0`
is `h -> tau(k h k^(-1)) (x) 1`, because `k` normalizes `K^0`. It is unitarily equivalent to
`tau (x) 1_m`, so its irreducible type `h -> tau(k h k^(-1))` is `tau`. So there is a unitary `A_k`
on `W` with `A_k tau(h) A_k^(-1) = tau(k h k^(-1))` for all `h`, and `A_k` is unique up to a scalar
by Schur's lemma. Then `(A_k^(-1) (x) 1) k` commutes with `tau(K^0) (x) 1`, so it equals `1 (x) B_k`
for a unitary `B_k`. So `k = A_k (x) B_k`, and `B_k` is unique up to a scalar. By uniqueness,
`k -> [B_k]` is a homomorphism `pi-bar : K -> PU(m)`. For `h` in `K^0`, `h = tau(h) (x) 1`, so `B_h` is a
scalar and `pi-bar(h) = 1`. So `pi-bar(K)` is a quotient of the finite group `K/K^0` (L2). The set
`P = U(1) {B_k : k in K}` is a group with finite image in `PU(m)`.

*Small projective factor.* Write `D = 2 sin(theta/2)` with `0 <= theta < pi`. Take a defect element
`w = w_i = A (x) B`. It is normal, and its eigenvalues are the products `alpha beta` of eigenvalues
of `A` and `B`. Since `||w - 1|| <= D`, each such product is `e^(i phi)` with `|phi| <= theta`. Fix an
eigenvalue `alpha_1` of `A` and an eigenvalue `beta_1` of `B`. Every eigenvalue `beta` of `B`
satisfies `beta/beta_1 = (alpha_1 beta)/(alpha_1 beta_1) = e^(i psi)` with `|psi| <= 2 theta`. So
`B' = beta_1^(-1) B` is a normal unitary in `P` with

```text
|| B' - 1 || <= 2 sin(theta) <= 4 sin(theta/2) = 2 D < 1/2 .
```

Here `sin(theta/2) = D/2 < 1/8` gives `2 theta < pi/2`, so every `e^(i psi)` with `|psi| <= 2 theta`
has `|e^(i psi) - 1| = 2 sin(|psi|/2) <= 2 sin(theta)`, and `sin(theta) = 2 sin(theta/2) cos(theta/2)
<= 2 sin(theta/2)`.

*Frobenius descent.* Let `S` be as in Step 2, and for `s = gamma w_i^(e) gamma^(-1)` in `S` put
`B'_s = B_gamma (B'_(w_i))^e B_gamma^(-1)`. This is a lift of `pi-bar(s)` in `P` with
`||B'_s - 1|| = ||B'_(w_i) - 1|| < 1/2`. Lemma C, with this `P` and `eta = 2D`, shows that the
`B'_s` commute pairwise. Since commutators ignore scalars (E2), all lifts of elements of
`pi-bar(S)` commute pairwise.

Let `N = <S>`, normal in `Gamma`. The group `pi-bar(Gamma) / pi-bar(N)` is finite, and the composite
`G0 -> pi-bar(Gamma) / pi-bar(N)` kills every `r_i`, since `w_i` is in `S`. By the transfer tool it
is trivial, so `pi-bar(Gamma) = pi-bar(N)`. So for every `gamma` in `Gamma`, `B_gamma` is a scalar
times a product of the pairwise commuting `B'_s^(+-1)`. Hence the unitaries `B_gamma`,
`gamma in Gamma`, commute pairwise and have a common eigenvector `e` in `C^m`. The subspace
`W (x) e` is invariant under every `sigma(g) = A_(sigma(g)) (x) B_(sigma(g))`, and it is nonzero.
Irreducibility gives `m = 1`. So `sigma` restricted to `K^0` is `tau`, which is irreducible.

## Step 5: the consequences

*Fixed-group amplification.* Let `M` be a compact Lie group, `phi : G0 -> M` a homomorphism, `pi` a
finite-dimensional unitary representation of `M`, and suppose `pi o phi` is nontrivial. Let `H` be the
closure of `phi(G0)` in `M`, a compact Lie group with `dim H <= dim M`. Decompose `pi o phi` into
irreducible summands `sigma_j` on subspaces `E_j`. Each `E_j` is `pi(H)`-invariant, by continuity and
density. Some `sigma_j` is nontrivial. The map `f_j : H -> U(E_j)`, `h -> pi(h)|_(E_j)`, is a
continuous homomorphism. Its image is compact and contains `sigma_j(G0)` as a dense subgroup, so it
equals `K_(sigma_j)`. By (L4), `df_j` maps `Lie(H)` onto `l_(sigma_j)`, and so it maps
`[Lie H, Lie H]` onto `[l_(sigma_j), l_(sigma_j)]`. Hence `N_(sigma_j) <= dim H <= dim M`, and
item 3 gives `D(pi o phi) >= D(sigma_j) >= c_(dim M)`.

*Shape of witnesses.* Let `sigma_j` be nontrivial irreducibles with `D(sigma_j) -> 0`. Once
`D(sigma_j) < 1/4`, items 1, 2 and 4 show that `sigma_j` is primitive, that `K_(sigma_j)^0` is
nonabelian, and that `sigma_j` restricted to `K_(sigma_j)^0` is irreducible. If `N_(sigma_j) <= N` along a subsequence,
item 3 gives `D(sigma_j) >= c_N > 0` there, a contradiction. So `N_(sigma_j) -> infinity`.

*Transfer inequality.* This is Case A of Step 3, which is the only case once `D < 1/2`.

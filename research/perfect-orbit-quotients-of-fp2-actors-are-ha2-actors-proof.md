**(L1) `FP_2` = finitely presented / perfect.** Let `G = F/R` with `F` free on a
finite set `X_0`. The Magnus–Lyndon sequence of `ZG`-modules
`0 → R/[R,R] → ZG^{X_0} → I_G → 0` presents the augmentation ideal `I_G` by a
finitely generated free module. By Schanuel's lemma `I_G` is finitely presented
iff the relation module `R/[R,R]` is finitely generated. If it is generated by
the classes of `r_1, ..., r_k ∈ R`, put `R_0 = ⟨⟨r_1, ..., r_k⟩⟩` and `Q = F/R_0`,
a finitely presented group. The subgroup `R_0[R,R]/[R,R]` is the
`ZG`-submodule generated by the classes of the `r_i`, which is everything, so
`R = R_0[R,R]`, and `M = R/R_0` satisfies `M = [M,M]`. So `G = Q/M` with `M`
perfect. Conversely, if `G = Q/M` with `Q = F/R_0`, `R_0` normally generated by
`r_1, ..., r_k`, and `M = R/R_0` perfect, then `R = [R,R]R_0`, so the classes of
the `r_i` generate `R/[R,R]` and `G` is `FP_2`.

**(L2) Perfect quotients.** Let `G` be `FP_2` and `K ⊴ G` perfect. By (L1)
`G = Q/M` with `Q` finitely presented and `M` perfect. Let `M'` be the preimage of
`K` in `Q`. Then `[M',M']` contains `[M,M] = M` and maps onto `[K,K] = K`, so
`[M',M'] = M'`. Hence `G/K = Q/M'` is `FP_2` by (L1).

**Proof of the claim.** Write `Nx` for the `N`-orbit of `x`.
- *Action.* For `g ∈ P`, `g(Nx) = (gNg^{-1})gx = N(gx)`, so `P` permutes
  `N`-orbits, and `N` fixes each of them. So `P/N` acts on `X/N`. By hypothesis
  the kernel of `P ↷ X/N` is exactly `N`, so `P/N` acts faithfully. This is item 1.
- *Pair orbits.* The map `X × X → X/N × X/N` is surjective and `P`-equivariant,
  so each `P`-orbit on `X/N × X/N` is the image of a `P`-orbit on `X × X`. There
  are finitely many.
- *Stabilizers.* If `g(Nx) = Nx`, then `gx = nx` for some `n ∈ N`, so
  `n^{-1}g ∈ Stab_P(x)`. Hence `Stab_P(Nx) = N·Stab_P(x)`, and the stabilizer of
  `Nx` in `P/N` is `Stab_P(x)N/N`, a quotient of the finitely generated group
  `Stab_P(x)`. This is item 2.
- *Finiteness.* `P/N` is `FP_2` by (L2), since `N` is perfect. This is item 3.

**Model tests.** With `N = 1` the claim returns the input action, which must
then be faithful: the hypothesis on `N` says exactly that. The hypothesis can
fail: Houghton's group `H_3` acting on its three rays `X` is finitely presented
with two orbits on `X × X` and finitely generated point stabilizers, and
`N = Alt_fin(X)` is perfect, but `N` is transitive, so every element of `H_3`
preserves the single `N`-orbit while `H_3 ≠ N`.

**Primitivity remark.** Let `Alt_fin(X) ≤ P ≤ Sym(X)`, `X` infinite, and
`1 ≠ N ⊴ P`. Pick `n ∈ N` and `x` with `nx ≠ x`, and a 3-cycle `c = (x y z)` with
`y, z` outside `{x, nx, n^{-1}x}`. Then `n c n^{-1} c^{-1} ∈ N` is a nontrivial
product of two 3-cycles, so `N ∩ Alt_fin(X)` is a nontrivial normal subgroup of
the simple group `Alt_fin(X)`, hence all of it, and `N` is transitive on `X`.

**ESTABLISHED** by `free-linear-part-char-p-affine-relative-t-proof` (self-contained; uses only the
spectral theorem for unitary representations of countable abelian groups, the Bruhat–Tits tree of
`SL_2` over a local field (Serre, *Trees*, II.1), and textbook amenability facts). Lane proof by
swarm-0917-w20-w20-nv-follow, not independently reviewed. No priority claimed: this is Burger's
argument for `SL_2(Z) ⋉ Z^2` transposed to the function field, with the tree replacing the
non-amenability of `SL_2(R)` acting on `P^1(R)`.

## Setting

- `p` is a prime, `A = F_p[t]`, `K = F_p((t^{-1}))` with `|t| = p`, `O = F_p[[t^{-1}]]`.
- `M = A^2` (column vectors). `SL_2(A)` acts on `M` by matrix multiplication.
- `Λ ≤ SL_2(A)` is any subgroup and `Γ = Λ ⋉ M`.

## Statement

1. **(Relative (T).)** If `Λ` is not amenable, then `(Γ, M)` has relative property (T): every unitary
   representation of `Γ` with almost invariant vectors has a nonzero `M`-invariant vector.
2. **(No (τ).)** If `Λ` is finitely generated, then `Λ` is virtually free. If moreover `Λ` is
   non-amenable, then `Λ` and `Γ` fail property (τ) with respect to finite-index subgroups: a
   finite-index free subgroup of rank `≥ 2` maps onto `Z`.
3. **(Explicit witness.)** For `p ≥ 3`, `u = e_12(1)` and `v = e_21(t)` generate a copy of
   `Z/p * Z/p` in `SL_2(A)`, which is non-amenable. The `F_p[Λ]`-module generated by `e_1, e_2` is all
   of `M`. So
   `Γ_p^free = ⟨u, v⟩ ⋉ F_p[t]^2`
   is generated by the three elements `u`, `v` and the translation `T_{e_2}` (each of order `p`),
   is residually finite (linear over `F_p(t)`, inside `SL_3(F_p[t])`), and `(Γ_p^free, F_p[t]^2)` has
   relative (T) with an infinite elementary abelian `p`-group as base.
4. **(Consequence.)** No group containing `Γ_p^free` (or any `Λ ⋉ F_p[t]^2` with `Λ` non-amenable)
   has the Haagerup property. In particular `Γ_p^free` embeds neither in Thompson's group `V`
   (Farley: `V` is Haagerup) nor in any Haagerup group.

## Role

- **New survivor class, explicitly populated.** The wave-19 class kills (lane nodes
  rank-two-affine-relative-t-pairs-in-wobbling-groups-fail-tau and
  laurent-elementary-semidirect-product-is-not-in-wobbling-group, held for landing) kill every
  rank-two affine relative-(T) witness `Λ ⋉ R^2` inside `W(Z)` and `[[X]]` **whenever `Λ` has (τ)**,
  and leave exactly the witnesses whose linear part fails (τ). Before this node no such witness with
  relative (T) was recorded. Items 1–3 give one for every prime `p ≥ 3`, generated by three elements
  of order `p`. Its base is locally finite, so it also passes the local-finiteness kill
  (`wobbling-normal-relative-t-subgroups-are-locally-finite`).
- **Refutation route toward `brin-thompson-groups-nv-are-a-t-menable`.** By item 4, an embedding of
  `Γ_p^free` into `[[X]]` or into `2V` refutes the Haagerup property of every `nV`, `n ≥ 2`. This is
  the open claim `free-affine-char-p-group-embeds-in-full-shift-full-group`.
- **Relaxes the lamp criterion.** In `char-p-burger-lamp-realizations-refute-haagerup` the lifted
  linear part had to contain `EL_2(F_p[t,t^-1])` (five cellular automata). By item 1 it suffices to
  lift the two one-sided cellular automata dual to `u` and `v` on `(F_p^2)^N`, with base
  `F_p[t]^2` in place of `F_p[t,t^-1]^2`. See the route, Remark 3.
- **Calibration.** Item 4 for `V` is a sanity check: `V` contains `Z/p * Z/p` and all finite groups,
  yet no `Γ_p^free`. Any construction that would embed `Γ_p^free` must fail for `V`.

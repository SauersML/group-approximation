For an infinite finitely generated P, the following are equivalent:

1. P is virtually cyclic.
2. Some enumeration nu makes every shell generator hat(g), for
   a finite generating set of P, a rational homeomorphism.
3. Some enumeration gives E_nu as a subgroup of the rational
   homeomorphism group in its specified Cantor action.

Thus no enumeration makes the regular shell action of A_5 * A_5,
Z^2, or any other non-virtually-cyclic finitely generated input
finite state in this sense. This does not exclude other rational
actions or abstract embeddings of the input or its shell envelope.
It also does not obstruct finite presentation using a different
kind of argument.

Notation as in the claim. `H` is the preimage of `S`, and `S` has first
coordinate `t^chi(M)`.

**Item 1.**
- `N = H cap Gamma(3)` is the preimage of `S cap ({1} x SL_3(F_5)) = {(1, k) : chi(k) = 0}`.
  So `N >= Gamma(15)` and `N / Gamma(15) = K`.
- *`Gamma(15)` has no nontrivial homomorphism to `Z/2`.* Let `psi` be one. Its kernel
  has finite index in `SL_3(Z)`, so by
  [[sl3z-finite-index-subgroups-are-congruence-subgroups]] it contains `Gamma(n)`
  for some `n`, which we may take to be a multiple of 15. Write
  `n = 3^(a+1) 5^(b+1) k` with `gcd(k, 15) = 1`.
  - Reduction `SL_3(Z) -> SL_3(Z/n)` is onto (the congruence node records this), so
    `Gamma(15) / Gamma(n)` is the kernel of `SL_3(Z/n) -> SL_3(Z/15)`. By the Chinese
    remainder theorem this is `U_3 x U_5 x SL_3(Z/k)`. Here `U_3` is the kernel of
    `SL_3(Z/3^(a+1)) -> SL_3(Z/3)`, a 3-group, and `U_5` is likewise a 5-group.
  - `SL_3(Z/k)` is generated by elementary matrices, and
    `e_ik(x) = [e_ij(x), e_jk(1)]` for distinct `i, j, k`. So it is perfect.
  - So the abelianization of `Gamma(15) / Gamma(n)` has odd order, and `psi = 1`.
- A homomorphism `N -> Z/2` therefore kills `Gamma(15)` and factors through `K`.

**Action of `sigma`.** `h = (t, M)` mod `(3, 5)`, and `h (1, k) h^-1 = (1, M k M^-1)`.
So `sigma` induces conjugation by `M` on `K`, and `sigmabar` on `V`.

**Items 2 and 3: exhaustive computation.**
`experiments/strong-atiyah-sl3z/level15_parity_character.py`, run on MSI with
python3.12 (output in the `.out` file, verbatim):
- it closes the three generators of `P_5` under multiplication mod 5, giving 32
  elements, and takes `K = {chi = 0}`, of order 16;
- it computes `Phi(K)`, the subgroup generated by squares and commutators, of order
  2, so `V = K / Phi(K)` has order 8;
- for each of the 16 elements `M` with `chi(M) = 1` it computes the set
  `{class(M k M^-1 k) : k in K}`, which is `(1 + sigmabar) V` because
  `k -> class(sigma(k) k)` is a homomorphism into the abelian group `V`. That set
  has order 2 in every case, and it never contains `class(M^2)`.

**Item 4.**
- A homomorphism `V -> F_2` is `sigmabar`-invariant iff it vanishes on
  `im(sigmabar - 1) = im(1 + sigmabar)`.
- Since `class(M^2)` is outside that line, some invariant functional takes the
  value 1 on it. Composing with `N -> K -> V` gives `theta_N`, and `h^2 = M^2` mod 5.
- *Independence of `h`.* Replacing `h` by `h n`, with `n` in `N`, changes `h^2` to
  `sigma(n) h^2 n`, whose class differs by `(1 + sigmabar) class(n)`. Inner
  automorphisms of `N` act trivially on `V`.

**Trust surface.** Elementary generation of `SL_3(Z/k)` and surjectivity of reduction
are used as recorded in the congruence node. The finite computation is exhaustive
over a group of order 32.

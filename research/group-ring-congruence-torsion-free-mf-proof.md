## The filtration

Put `S = M_d(Z[G])`.  As an abelian group `S` is free on the matrix units
times the elements of `G`, so `intersection_(n>=1) 3^n S = 0`.  For `B != 0`
let `v(B)` be the largest `s` with `B in 3^s S`; it is finite because `B` has
finitely many integer coefficients.

## Torsion-freeness

Let `U != I` in `(CG1)` and write `U = I + 3^s B` with `s >= 1` and `B` not
in `3S`.  Powers of the single matrix `B` commute with each other, so the
binomial expansion is valid despite noncommutativity of `S`.  For a positive
integer `t` prime to `3`,

```text
U^t - I = 3^s (tB + 3^s C)    for some C in S,
```
and `tB` is not in `3S`, so `v(U^t - I) = s`.  Also

```text
U^3 - I = 3^(s+1) ( B + 3^s B^2 + 3^(2s-1) B^3 ),
```
whose bracket is `B` modulo `3S` because `s >= 1` gives `2s - 1 >= 1`; hence
`v(U^3 - I) = s + 1`.  Iterating,

```text
v(U^(3^k t) - I) = s + k < infinity     (t > 0, 3 not dividing t).
```
So no positive power of `U` is `I`, and `Gamma_d(G)` is torsion-free.

## Finitely generated subgroups are residually finite

Let `L` be generated by finitely many elements, and write those generators
and their inverses as `I + 3D_1, ..., I + 3D_l`; the inverses have this form
because reduction modulo `3` sends them to `I` as well.

Fix `n`.  A word in these generators, expanded and reduced modulo `3^n S`,
is an integer combination of **ordered monomials** in the alphabet
`D_1,...,D_l` of length strictly less than `n` — every longer monomial
carries a factor `3^n` — with coefficients taken modulo `3^n`.  There are
finitely many such monomials and finitely many coefficient tuples, so the
image of `L` in `GL_d(S/3^n S)` is finite.  Note this does not need
`S/3^n S` itself to be finite, which it is not when `G` is infinite.

The kernels of these reductions intersect trivially, since
`intersection_n 3^n S = 0`.  So `L` is residually finite.

## MF

`Z[G]` is countable, so `Gamma_d(G)` is countable, and it is the directed
union of its finitely generated subgroups, each residually finite.  It is
therefore locally residually finite, hence LEF, hence operator MF by the
prerequisite.  Subgroups of MF groups are MF.

Let `(G, w)` violate the conjecture, with `deg_t(w) = m != 0`.

1. **Localize.** By `kl-failure-localizes-to-the-coefficient-subgroup`, the
   finitely generated subgroup `A <= G` generated by the coefficients of `w`
   also violates it: some `1 != a in A` dies in `A_w`. `A` is countable.
2. **Embed.** By `every-group-embeds-in-an-acyclic-group` there is an
   injective `iota : A -> Y` with `Y` countable and acyclic.
3. **Transfer the kill upward.** `iota * id : A * <t> -> Y * <t>` sends `w` to
   `w`, so `deg_t` is unchanged, and it maps `<<w>>` in `A * <t>` into `<<w>>`
   in `Y * <t>`. It therefore descends to a homomorphism `A_w -> Y_w` that
   commutes with the coefficient maps. Since `a` maps to `1` in `A_w`,
   `iota(a)` maps to `1` in `Y_w`, while `iota(a) != 1` because `iota` is
   injective. So `(Y, w)` violates the conjecture, with killed element
   `iota(a)`.
4. **Superperfect.** `H_1(Y) = H_2(Y) = 0`, so the Schur kernel
   `K_2(Y, w) = ker(H_2(Y) -> H_2(Y_w))` is zero.

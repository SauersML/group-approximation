Notation as in the target.  `Q = prod_n M_(k_n) / (+)_n M_(k_n)` is a norm
matrix corona, a *corona homomorphism* is a homomorphism into `U(Q)`, `Rad`
is the MF radical and `S = R_(infinity->2)` is the shadow residual.

**Imported verbatim.**
- (I1) Thompson's `T` is simple, finitely generated, and contains
  elements of finite order.  The rotation by `1/2` is an involution
  (Cannon--Floyd--Parry).

Two standard facts about `Q`, as in
`central-eigencorners-die-over-full-radical-quotients-proof`:
- (L1) unitaries of `Q` lift to sequences of unitaries;
- (L2) projections of `Q` lift to sequences of projections.

## Step 0: two inclusions

- **(R1) `Rad(G) <= S(G)`.**  Let `g in Rad(G)` and let `U_n` be an
  operator-norm asymptotic representation.  Then `[U_n]` is a corona
  homomorphism, so `||U_n(g) - 1|| -> 0`.  This bounds the normalized HS
  norm.
- **(R2) `Res_hyp(G) <= S(G)` for countable `G`.**  Here `Res_hyp` is the
  intersection of the kernels of all homomorphisms `G -> U(R^omega)`.
  Suppose `g notin S(G)`.  Then some asymptotic representation `U_n` and
  some free ultrafilter `omega` give `lim_omega ||U_n(g) - 1||_2 > 0`.  The
  map `h -> [U_n(h)]_omega` into the tracial ultraproduct
  `prod^omega (M_(k_n), tr)` is a homomorphism, because operator-norm
  defects bound HS defects.  It does not kill `g`.  That ultraproduct embeds
  in `R^omega`, so `g notin Res_hyp(G)`.

## Step 1: normal subgroups of `T̄`

Let `N` be normal in `T̄`.  By (I1), `p(N)` is `1` or `T`.
- If `p(N) = 1`, then `N <= <z>`, so `N = <z^m>` for some `m >= 0`.
- If `p(N) = T`, then `N <z> = T̄`.  Since `z` is central,
  `[T̄, T̄] = [N<z>, N<z>] = [N, N] <= N`.  `T̄` is perfect by
  `lifted-thompson-t-perfect-centre-cubically-elliptic`, so `N = T̄`.

## Step 2: item 1 (dichotomy)

`S(T̄)` is normal by `op-to-hs-shadow-residual-functoriality`.  Suppose
`S(T̄) = <z^m>` with `m >= 1`.  Let `lambda` be the dilation of
`lifted-thompson-t-mf-radical-dichotomy`.  It is an injective endomorphism
with `lambda(z) = t_1` and `t_1^2 = z`.  Functoriality for `f = lambda`
gives `lambda(S(T̄)) <= S(T̄)`, so

```text
t_1^m = lambda(z^m) in <z^m> = <t_1^(2m)>.
```

`t_1` has infinite order, so `m in 2m Z`, which forces `m = 0`.  This is a
contradiction.  By Step 1, `S(T̄) in {1, T̄}`.  In particular,
`z in S(T̄)` forces `S(T̄) != 1`, hence `S(T̄) = T̄`. ∎

## Step 3: item 2, main clause

Suppose `S(T̄) = 1`.  By (R2), `Res_hyp(T̄) = 1`.  By
`mf-nonhyperlinear-collapse-structure`, a countable group is hyperlinear
iff its hyperlinear residual is trivial.  So `T̄` is hyperlinear.  `T` is
then hyperlinear too, as a central quotient: Remark 3.4 in
`thom-central-corner-criterion`.

## Step 4: item 2(a) and the first bullet of item 3

Suppose `S(T̄) = T̄`.  The projection `p` is onto, and functoriality gives
`T = p(S(T̄)) <= S(T)`.  By (I1), `T` is finitely generated, and it is
normally generated by one element of finite order: any nontrivial element
normally generates a simple group.  Item 3 of
`gapped-normal-generators-give-a-hyperlinear-quotient` gives
`S(T) = T iff Rad(T) = T`.  So `Rad(T) = T` and `T` is not MF.

For item 2(a), take the contrapositive.  If `T` is MF, then
`Rad(T) = 1 != T`.  So `S(T̄) != T̄`, and by item 1, `S(T̄) = 1`.

## Step 5: item 2(b), a gapped corner makes `z` HS-visible

Let `rho` be a corona homomorphism of `T̄`, and let
`P in rho(T̄)' ∩ Q` be a nonzero projection with `x = rho(z) P - P`
invertible in `PQP`.

- **Corner.**  Exactly as in Step 1a of
  `central-eigencorners-die-over-full-radical-quotients-proof`, lift `P` by
  (L2) to projections `P_n` of rank `r_n`.  Put `J = {n : r_n >= 1}`, which
  is infinite.  Then `PQP ≅ Q_P = prod_J M_(r_n) / (+)_J M_(r_n)`.
  `rho_P(g) = rho(g) P` is a corona homomorphism of `T̄` into `U(Q_P)`.
- **Lifts.**  By (L1), choose unitary lifts `u_n(g) in U(r_n)`, `n in J`,
  of `rho_P(g)`.  Then `u_n` is an operator-norm asymptotic representation.
  `x` is represented by `x_n = u_n(z) - 1`.
- **Inverse bound.**  Let `y = [y_n]` be the inverse of `x` in `Q_P`, with
  lifts chosen so that `||y_n|| <= 2||y||` for large `n`.  Then
  `||y_n x_n - 1|| -> 0`, so for large `n` and every unit vector `xi`,
  `1/2 <= ||y_n x_n xi|| <= 2||y|| ||x_n xi||`.  So every singular value of
  `x_n` is at least `c = 1/(4||y||)`, and
  ```text
  ||u_n(z) - 1||_(2, tr_(r_n))^2 = tr_(r_n)(x_n^* x_n) >= c^2      (n in J large).
  ```

So along every free ultrafilter on `J`, `z` is not killed in normalized HS
norm.  That is, `z notin S(T̄)`.  By item 1, `S(T̄) = 1`.

## Step 6: item 2(c), approximate corner gives gapped corner

Let `q in rho(T̄)' ∩ Q` be a nonzero projection with
`||(rho(z) - lambda) q|| <= eta < |lambda - 1|`, so `lambda != 1`.  Since
`q` commutes with `rho(z)`, the element `(rho(z) - lambda) q` lies in
`qQq`, and

```text
rho(z) q - q = (lambda - 1) q + (rho(z) - lambda) q = (lambda - 1)(q + w),
w = (rho(z) - lambda) q / (lambda - 1),   ||w|| <= eta/|lambda - 1| < 1.
```

`q + w` is invertible in `qQq` by the Neumann series.  So `q` is a gapped
commutant corner, and Step 5 applies.  An exact eigencorner is the case
`eta = 0`.

## Step 7: item 3 (full branch)

Assume `S(T̄) = T̄`.

- **`T` is not MF.**  This is Step 4.
- **Paddings.**  Item 3 of `hs-invisible-corona-maps-are-full-trace-paddings`
  applies to the countable group `T̄` with `R_(infinity->2)(T̄) = T̄`.
- **Corners are HS-invisible.**  For nonzero `P in rho(T̄)' ∩ Q`, Step 5's
  corner construction makes `rho_P` a corona homomorphism into `Q_P`, with
  unitary lifts `u_n`.  `z`, and hence every `g`, lies in `S(T̄)`, so
  `||u_n(g) - 1||_(2, tr_(r_n)) -> 0` along every free ultrafilter on `J`.
  For unitaries, `|1 - tr(u)| <= ||u - 1||_2`, so `tau_omega(rho_P(g)) = 1`.
- **Connected spectrum.**  Let `rho`, `k` and a nonzero projection `P`
  commuting with `rho(lambda^k(T̄))` be given.
  - `rho' = rho ∘ lambda^k` is a corona homomorphism of `T̄`, with
    `rho'(z) = rho(t_k)` and `P in rho'(T̄)' ∩ Q`.
  - `rho'(z)` is central in `rho'(T̄)` and commutes with `P`, so
    `a = rho'(z) P` is a unitary of `PQP`.  It commutes with every
    `rho'(g) P`.  Let `K = sp_(PQP)(a)`, a subset of the unit circle.
  - If `1 notin K`, then `a - P` is invertible in `PQP`.  So `P` is a gapped
    commutant corner of `rho'`, and Step 5 gives `S(T̄) = 1 != T̄`, a
    contradiction.
  - Suppose instead that `K = K_1 ⊔ K_2` with `K_1, K_2` nonempty, closed and
    disjoint.  Relabel so that `1 notin K_1`.  Then `chi_(K_1)` is continuous
    on `K`, and `e = chi_(K_1)(a)` is a nonzero projection in
    `C^*(a, P) <= PQP`.
    - `e` commutes with every element commuting with `a` and `P`, in
      particular with `rho'(T̄)`.
    - Via `C^*(a, P) ≅ C(K)`, one gets `sp_(eQe)(a e) = K_1`.  The spectrum
      is unchanged under the unital inclusion `e C^*(a) e <= eQe`.
    - So `rho'(z) e - e = a e - e` is invertible in `eQe`, and `e` is a
      gapped commutant corner of `rho'`.  This is again a contradiction.

  Hence `K` is connected and contains `1`.  For `k = 0`, `rho' = rho`. ∎

## Step 8: item 4

- `T̄` not hyperlinear gives `S(T̄) != 1` by Step 3, hence `S(T̄) = T̄` by
  item 1, hence `T` is not MF by Step 4.
- `T̄` not MF is `Rad(T̄) = T̄` by `lifted-thompson-t-mf-radical-dichotomy`.
  By (R1), `S(T̄) = T̄`. ∎

## Hygiene

- The proof uses no Property `(T)`, no Kazhdan projection and no
  `mf-implies-hyperlinear` input.
- The only tracial input is the definition of `S` and the ultraproduct in
  (R2).
- The torsion gap for `T` comes from item 3 of
  `gapped-normal-generators-give-a-hyperlinear-quotient`, and it is moved to
  `T̄` by the dilation in Step 2.

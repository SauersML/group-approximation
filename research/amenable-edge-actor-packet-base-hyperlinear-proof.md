**Step 0 (presentation of A).**  Fix a maximal tree `T` of the underlying
graph and an orientation.  For an edge `e: v=o(e) -> w=t(e)` write
`alpha_e:G_e -> G_v`, `omega_e:G_e -> G_w`.  The group
`A=pi_1(Gcal,T)` is generated by the `G_v` and stable letters `t_e`, with
relations those of each `G_v`, `t_e=1` for `e in T`, and

```text
t_e^{-1} alpha_e(g) t_e = omega_e(g)          (g in G_e).     (P1)
```

The vertex and edge groups embed in `A` (Bass--Serre normal form).  Write
`a.n=theta_a(n)` and use `N rtimes A` with product
`(n,a)(n',a')=(n theta_a(n'), aa')`.

**Step 1 (the graph `Gcal_N`).**  Vertex groups `H_v=N rtimes G_v`, edge
groups `H_e=N rtimes G_e` (restricted actions).  Edge maps

```text
alpha^N_e(n,g)=(n, alpha_e(g)),
omega^N_e(n,g)=(theta_{t_e}^{-1}(n), omega_e(g)).              (P2)
```

`alpha^N_e` is plainly an injective homomorphism.  For `omega^N_e`: inside
`N rtimes A`, conjugation `c(x)=t_e^{-1} x t_e` sends `(n,1)` to
`(theta_{t_e}^{-1}(n),1)` and `(1,alpha_e(g))` to `(1,omega_e(g))` by
`(P1)`.  Hence `omega^N_e = c o alpha^N_e` restricted to `N rtimes G_e`,
viewed with image in `N rtimes G_w`, is an injective homomorphism.  (If
`e in T`, `t_e=1` and `(P1)` says `alpha_e=omega_e` inside `A`.)  So
`Gcal_N` is a finite graph of groups on the same underlying graph.

**Step 2 (`AEA1`).**  Let `Pi_N=pi_1(Gcal_N,T)` with vertex maps
`i_v:H_v -> Pi_N` and stable letters `s_e`.

*The map `Phi:Pi_N -> N rtimes A`.*  Send `H_v` to `N rtimes G_v` by
inclusion and `s_e` to `(1,t_e)`.  The relations of `Pi_N` hold: those of
`H_v` trivially; `s_e=1` for `e in T` because `t_e=1`; and
`s_e^{-1} alpha^N_e(x) s_e=omega^N_e(x)` because
`c o alpha^N_e=omega^N_e` (Step 1).  `Phi` is onto since its image contains
`N`, every `G_v` and every `t_e`.

*The map `Psi:N rtimes A -> Pi_N`.*  For `e: v -> w` in `T`, the edge
relation with `s_e=1`, `theta_{t_e}=id` gives `i_v(n,1)=i_w(n,1)`.  The tree
spans all vertices, so `j(n):=i_v(n,1)` is independent of `v`; it is a
homomorphism `N -> Pi_N`.  Define `psi:A -> Pi_N` by
`g in G_v |-> i_v(1,g)`, `t_e |-> s_e`.  The relations of `A` hold: those of
`G_v`; `s_e=1` on `T`; and `(P1)` because
`s_e^{-1} i_v(1,alpha_e g) s_e=i_w(omega^N_e(1,g))=i_w(1,omega_e g)`.

Covariance `psi(a) j(n) psi(a)^{-1}=j(theta_a n)` for all `n`: the set of
`a` satisfying it is a subgroup (if `a` does, apply it to `theta_a^{-1}n` and
conjugate back to get it for `a^{-1}`; products are immediate), so it
suffices to check generators.  For `g in G_v` it is the identity
`(1,g)(n,1)(1,g)^{-1}=(theta_g n,1)` in `H_v`.  For `t_e`, the edge relation
of `Pi_N` gives `s_e^{-1} j(n) s_e=j(theta_{t_e}^{-1}n)`; substituting
`n=theta_{t_e}m` gives `s_e j(m) s_e^{-1}=j(theta_{t_e}m)`.  By the
universal property of the semidirect product,
`Psi(n,a)=j(n)psi(a)` is a homomorphism.

*Inverse.*  `Phi Psi` fixes `(n,1)`, `(1,g)`, `(1,t_e)`, which generate
`N rtimes A`.  `Psi Phi` fixes `i_v(n,g)=i_v(n,1)i_v(1,g)` and `s_e`, which
generate `Pi_N`.  Hence `Phi` is an isomorphism, proving `(AEA1)`.

**Step 3 (`AEA2`).**  Each edge group `N rtimes G_e` is an extension of the
amenable group `N` by the amenable group `G_e`, hence amenable.  Each vertex
group is hyperlinear by `(AEA0)`, and edge maps are injective (Step 1).
`(AEG1)` of `amenable-edge-graph-corners-cannot-groupify-a-nonce-game`
applied to `Gcal_N` gives that `Pi_N ~= N rtimes A` is hyperlinear.

**Step 4 (`AEA3`).**  Put `G=M rtimes A`, hyperlinear by Step 3, and let
`m_0 in G` be an involution, `m_0!=1`.  Since `G` is hyperlinear it embeds in
a tracial matrix ultraproduct with `tau(m_0)=0`, so `||m_0-1||_2^2=2` and
`m_0` is not in `Rad_hyp(G)`.  By `central-d8-mark-radical-equals-seed-radical`
there is `Theta:P(G,m_0) -> U(prod_omega M_(D_k))` with `Theta(J)=-1`, so
`J` is not in `Rad_hyp(P)` (and `P` is hyperlinear by `(CDS3)`, `J!=1` by
`(CDS2)` of `central-d8-seed-preserves-hyperlinearity`).  But a uniform
terminal estimate `(ICR2)` of
`infinite-character-interface-is-marked-radical-certificate` places `J` in
`Rad_hyp(P)`: evaluate it along `Theta`, where `Def_R -> 0` and
`||J-I||_2=2`.  This contradiction proves the first half of `(AEA3)`.  The
energy floor is `(ICR3)` of the same node, whose hypothesis (hyperlinear
base) is now supplied by Step 3.

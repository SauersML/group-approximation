## Setting

Notation of `brin-thompson-nv-haagerup-iff-cocycle-and-kernel-domination`:
- `C = {0,1}^ω`, `n ≥ 1`, and `nV` acts on `C^n`;
- `c: nV → C(C^n, Z^n)` is the exponent cocycle, `c(gh) = c(g)∘h + c(h)`;
- `K = {g : c(g) = 0}` is its kernel.

`λ` is the product Haar (Lebesgue) measure on `C^n`. For a homomorphism `ℓ: Z^n → Z` put
`H_ℓ = {g ∈ nV : ℓ∘c(g) ≡ 0}`. For `v ∈ Z^n` put `D_v = {g ∈ nV : c(g)(x) ∈ Zv for all x}`.
Three cases get names.
- **Jacobian subgroup.** `J = ℓ_+ ∘ c` with `ℓ_+(t) = t_1 + … + t_n`, and `M_n = H_{ℓ_+}`.
- **Diagonal subgroup.** `D = D_{(1,…,1)}`.
- **Full-shift group.** `X = {0,1}^Z` with shift `σ`. `[[X]]` is the group of homeomorphisms
  `f(x) = σ^{k(x)} x` with `k: X → Z` continuous. `Φ: C^2 → X`,
  `Φ(a, b) = … b_1 b_0 . a_0 a_1 …`, is the homeomorphism of `full-shift-topological-full-group-embeds-in-2v`.

## Statement

1. **Subgroups and intersections.** Each `H_ℓ` and each `D_v` is a subgroup of `nV` containing
   `K`. If `ℓ_1, …, ℓ_n` are linearly independent then `H_{ℓ_1} ∩ … ∩ H_{ℓ_n} = K`. In particular
   `M_n ∩ D = K` for every `n ≥ 1`.
2. **Positive directions are Higman–Thompson groups.** Let `v = (p_1, …, p_n)` have all
   `p_i ≥ 1` and `s = p_1 + … + p_n`. The block interleaving
   `Z_v: C^n → ({0,1}^s)^ω` conjugates `D_v` onto the Higman–Thompson group `V_{2^s,1}`. In
   particular `D ≅ V_{2^n,1}` and `K ≤ D`.
3. **The Jacobian subgroup is the measure-preserving subgroup.**
   - (a) `M_n = {g ∈ nV : g_*λ = λ}`.
   - (b) For `n = 2`, `Φ M_2 Φ^{-1}` is the topological full group of the étale groupoid generated by
     the homoclinic relation of `X` and the shift. Its elements are the homeomorphisms that, near
     each point, change finitely many coordinates and then shift.
   - (c) `Φ^{-1} [[X]] Φ ≤ M_2`. The baker's map `Φ^{-1} σ Φ` lies in `M_2`.
   - (d) For `m ≥ n ≥ 2`, `g ↦ g × id` maps `M_n` into `M_m`.
4. **Rank-one split of the cocycle half.** For any subgroups `H_1, H_2` of a group `G`: if `ψ_1` is
   proper modulo `H_1` and `ψ_2` is proper modulo `H_2`, then `ψ_1 + ψ_2` is proper modulo
   `H_1 ∩ H_2`. Hence, with P1 and P2 of `brin-thompson-nv-haagerup-iff-cocycle-and-kernel-domination`,
   ```text
   P1 ∧ P2   ⟺   (Q_J) some cnd function on nV is proper modulo M_n
                 ∧ (Q_D) some cnd function on nV is proper modulo D.
   ```
5. **Two further splits of the goal.** By `haagerup-splits-as-coset-plus-subgroup-properness`,
   `nV` has the Haagerup property iff (Q_J) holds and some cnd function on `nV` is proper on
   `M_n`. The same holds with (Q_D) and `D` in place of (Q_J) and `M_n`.
6. **What the halves see.**
   - (a) *Both halves are non-cubical.* Let `z = id × x_0 × id^{n−2}` be the fibre element of
     supplement (d) of `brin-thompson-nv-haagerup-iff-cocycle-and-kernel-domination`. The powers
     `z^M` lie in pairwise distinct left cosets of `M_n`, and in pairwise distinct left cosets of
     `D`. Every commensurating action is bounded on `⟨z⟩`
     (`brin-thompson-nv-fibre-elements-are-cubically-elliptic`). So no wall count is proper modulo
     `M_n` or modulo `D`.
   - (b) *The gap class sees neither half.* `M_n` and `D` have infinite index. By
     `nv-gap-class-cocycles-are-coboundaries`, a cnd function coming from a gap-class
     representation is bounded, so it is proper modulo neither.
   - (c) *Where the gap-class kill stops.* `M_n` contains no brick-local coordinate copy
     `A_P^{(j)}` of `V`: `A_P^{(j)} ∩ M_n ⊆ K`. On `M_n` the Maharam half-space
     `A = C^n × {t ≥ 0}` in `(C^n × Z, λ ⊗ counting)`, with `g(x, t) = (gx, t − c(g)(x)_1)`, is
     commensurated with finite measure defect. So `ψ_M(g) = ∫ |c(g)(x)_1| dλ(x)` is a cnd function
     on `M_n`, and it equals `N` on the `N`-th power of the baker's map when `n = 2`. The kill of
     `nv-gap-class-cocycles-are-coboundaries` runs through the copies `A_P^{(j)}`, which `M_n`
     lacks, so it does not reach this function. On all of `nV` the same half-space, with the
     invariant measure `λ ⊗ 2^t` that `nV` needs, has a complement of finite measure and gives only
     a bounded function (`brin-thompson-groups-nv-lack-property-t`, Attempts).

## Consequences

- **A new necessary prerequisite that can fail on its own.** By 3(c) and 3(d), the goal
  `brin-thompson-groups-nv-are-a-t-menable` implies that `[[X]]`, the topological full group of the
  two-sided full 2-shift, has the Haagerup property. This is recorded as
  `full-shift-topological-full-group-is-a-t-menable` (OPEN). `[[X]]` is a residually finite group
  of piecewise shifts containing every right-angled Artin group. Its Kazhdan subgroups are finite
  (`full-shift-full-group-kazhdan-subgroups-are-finite`).
- **The kernel K sits in a Higman–Thompson group.** `K ≤ D ≅ V_{2^n,1}`, and Higman–Thompson
  groups carry proper wall counts of Farley type (imported informally here; not used in any
  proof). So P3, and more, would follow from a cnd function on `nV` that dominates such a function
  on `D`: that is the "proper on `D`" half of item 5. The natural extension fails, because
  square-brick walls are broken by the baker's map along infinitely many bricks
  (`brin-thompson-brick-charts-are-not-commensurated`).
- **Distortion lives where it lives.** Every element of `[[X]]` has Jacobian `0`, so it is
  invisible to (Q_J). Whether the Callard–Salo distortion element of 2V can be conjugated into
  `M_2` is not checked here.

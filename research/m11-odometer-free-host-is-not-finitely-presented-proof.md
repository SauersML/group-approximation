**Conventions.**
- Right actions: `(xw)^g = x^{π_g} w^{g|_x}` and `(gh)|_v = g|_v h|_{v^g}`.
- For `g ∈ Aut(X*)` and a vertex `v`, `g@v` acts as `g` below `v` and trivially elsewhere.
- Indices of level-1 vertices are read mod 11.

Facts used from the graph:
- `R_0` is fully self-replicating, i.e. `R_0@x ⊆ R_0` for every `x`, and has root image
  `M_11` (`tits-hosts-for-transitive-local-actions` item 6). By the discussion in
  `fully-self-replicating-tree-groups-give-fg-tits-hosts`, it is therefore regular branch
  over itself.
- `R_0` is generated by a bounded automaton, so it is contracting (Bondarenko–Nekrashevych).
- `b` has order 55, and `R_0^{ab} = Z/55` (`m11-odometer-free-linear-host-h1-is-z55-squared`
  items 2–3). Only the finiteness of `R_0^{ab}` is used below, and that already follows
  because `M_11` is perfect and `b` has finite order.

**Step 1 (loop data).** Take `S = {α^{±1}, β^{±1}, b^{±1}, u^{±1}}`.

- `α` and `β` are finitary. They preserve `Ω = X*1^∞`, and all their sections below the root
  are trivial, so `c(α^{±1}, η) = c(β^{±1}, η) = 1`.
- **`b = (b, α, β, 1, …)`.**
  - It fixes the first letter, so `b` maps `1^k x w` to `1^k x w'`. For `x = 2, 3`,
    `w' = w^{α}` or `w^{β}`, which changes only the first letter of `w`. So `b(Ω) = Ω`.
  - Its section along `1^k x w`, for `x ≠ 1`, is `b` down to `1^k`, then `α`, `β` or `1` at
    `1^k x`, and `1` below that.
  - So `c(b, ξ) = b`, and `c(b, η) = 1` for every other `η ∈ Ω`.
- **`u = (u, b, β^{-1}, 1, …)`.**
  - The section at `1^k 2` is `b`. So the stable section along `1^k 2 w` is `c(b, w)`, which
    is `b` for `w = 1^∞` and `1` for other `w ∈ Ω`.
  - The section at `1^k 3` is `β^{-1}`, which is finitary.
  - Hence `u(Ω) = Ω`, and the nontrivial stable sections are `c(u, ξ) = u` and
    `c(u, 1^k 2 1^∞) = b`.
- Inverses: `c(s^{-1}, η^s) = c(s, η)^{-1}`.

So (Ω), (E) and (F) hold, with `C = {b, u}` and `H := H_ξ = ⟨b, u⟩`. This proves item 1.
Check (4) of the script verifies the resulting cocycle formula: on 2947 random pairs of a word
over `S` and an end `η = v1^∞`, the section at a deep enough prefix of `η` equals `W_η(w)`.

**Step 2 (item 2).**

- `b` and `u` fix level 1, with sections `b = (b, α, β, 1, …)` and `u = (u, b, β^{-1}, 1, …)`.
- So for a word `W` in `b^{±1}, u^{±1}`, the element `h = W(b, u)` fixes level 1, with
  `h|_1 = W(b, u) = h`, `h|_2 = W(α, b)`, `h|_3 = W(β, β^{-1})` and `h|_x = 1` for `x ≥ 4`.
- **Injective.** Suppose `h|_2 = h|_3 = 1`. Then `h = (h, 1, …, 1)`. By induction on `n`,
  `h` fixes every vertex of the form `1^n x w` with `x ≠ 1`. So `h` fixes every vertex and
  `h = 1`.
- So `θ : H → R_0 × ⟨β⟩`, `h ↦ (h|_2, h|_3)`, is an injective homomorphism. Its image is
  generated by `(α, β)` and `(b, β^{-1})`.
- **Image.** `θ(b^{11}) = (α^{11}, β^{11}) = (1, β)`, and check (1) of the script confirms
  `b^{11} = (b^{11}, 1, β, 1, …)`. So the image contains `1 × ⟨β⟩`, and therefore also
  `(α, 1)` and `(b, 1)`. Hence `θ(H) = L × ⟨β⟩ ≅ L × C_5`, with `L = ⟨α, b⟩`.

**Step 3 (item 3).** `L ⊆ R_0` is clear. Let `α^{-j} b α^{j} = b_k`.

- **Generators of `St_L(1)`.** The root image of `L` is `⟨α⟩ ≅ C_11`, since `b` has trivial
  root permutation. By Reidemeister–Schreier with transversal `{α^j}`, `St_L(1)` is
  generated by the eleven conjugates `b_k`.
- **Shape of `b_k`.** Each `b_k` fixes level 1. Its sections are `b` at `k`, `α` at `k + 1`,
  `β` at `k + 2`, and `1` elsewhere (script check (2)).
- **Projections.** For each `x`, the projection `St_L(1) → R_0`, `h ↦ h|_x`, takes the
  generators to `b`, `α`, `β` and `1`. So it is onto `R_0`.
- **Commutators.** Since `11 ≥ 5`, the supports of `b_k` and `b_{k+2}` meet only at `k + 2`,
  where the sections are `β` and `b`. So `[b_k, b_{k+2}] = [β, b]@(k+2)` (script check (2)).
  Hence `g@x ∈ St_L(1)` for every `x`, where `g = [β, b]`.
- **Normal closure.** Conjugate `g@x` by `h ∈ St_L(1)`: the result is `(g^{h|_x})@x`, and
  `h|_x` ranges over all of `R_0`. So `St_L(1) ⊇ N@x`, where `N` is the normal closure of
  `g` in `R_0`.
- **Branch lemma.** The element `g = β^{-1} b^{-1} β b` lies in `St(1)`, because `b` does.
  It moves a level-2 vertex (script check (3)). So there are letters `y, z ≠ z'` with
  `(yz)^g = yz'`.
  - For `k_1, k_2 ∈ R_0`, put `K_i = k_i@yz`. Then `K_i ∈ R_0`, by full self-replication
    applied twice.
  - `[g, K_1] = (K_1^{-1})^{g} K_1`. The first factor is supported below `yz' ≠ yz`, and the
    second is `k_1@yz`.
  - So `[[g, K_1], K_2] = [k_1, k_2]@yz`, and it lies in `N`. Hence `N ⊇ R_0'@yz`.
- **All of level 3.** For every `x`, `L ⊇ (R_0'@yz)@x = R_0'@(xyz)`.
  - Conjugating by `h ∈ St_L(1)` sends `m@(xyz)` to `m'@(x·(yz)^{h|_x})`, with `m' ∈ R_0'`,
    since `R_0'` is normal in `R_0`.
  - `h|_x` ranges over `R_0`, which is transitive on level 2: its root image `M_11` is
    transitive, and `R_0@x ⊆ R_0`.
  - So `L ⊇ R_0'@w` for every `w ∈ X^3`. These subgroups commute, so
    `L ⊇ P := ∏_{w ∈ X^3} R_0'@w`.
- **Index.** Full self-replication gives `St_{R_0}(3) = ∏_w R_0@w ≅ R_0^{X^3}`, of index at
  most `|Aut(X^3)|` in `R_0`. Inside it, `P` has index `|R_0^{ab}|^{11^3} = 55^{1331}`. So
  `|R_0 : L| < ∞`.

**Step 4 (item 4).** Suppose `R''` is finitely presented.

- `R''` is finitely generated by `S` and self-similar (it is generated by a finite
  automaton), and Step 1 gives (Ω), (E), (F). By `fp-self-similar-groups-have-fp-ray-loop-subgroups`
  item 2, `H` is finitely presented.
- By Step 2, `L` is a retract of `H`, so `L` is finitely presented. A retract of a finitely
  presented group is finitely presented, because a retraction `H → L` sends a finite
  presentation of `H` to one of `L`.
- By Step 3, `R_0` contains `L` with finite index, so `R_0` is finitely presented.
- This contradicts Bartholdi's theorem that contracting regular branch groups are not
  finitely presented (cited in `fully-self-replicating-tree-groups-give-fg-tits-hosts`).
  `R_0` is contracting and regular branch over itself. ∎

**Step 5 (item 5).** `R''` is fully self-replicating with root image `M_11`
(`m11-odometer-free-linear-host-h1-is-z55-squared` item 1). So
`tits-hosts-for-transitive-local-actions` applies: `Γ⁺` is finitely generated and simple, and
it is finitely presented iff `R''` is. By Step 4 it is not. ∎

**Sanity check (script check (5)).** For the relators `b^{55}`, `u^{55}` and
`[b, α^{-3} u α^3]` of `R''`, every stable section word `W_η(r)`, at the seven sample ends,
is trivial at depth 3. The non-relator `b^{11}` gives `W_ξ = b^{11} ≠ 1`, as it must. This is
(F1) of the general proof, on the instance.

**Remark (why homology missed it).** `H_1(R'') = (Z/55)^2`, and `H_2(R''; Q)` is still
undecided. It is now also moot for finite presentation. The loop relations of `⟨b, u⟩` enter
the relation module of `R''` only after induction along the orbit `Ω`, and a finite `H_1`
does not see that.

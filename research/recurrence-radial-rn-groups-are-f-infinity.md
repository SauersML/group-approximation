For the arithmetic scalar and matrix recurrence data of the artifact,
construct `K` from the arithmetic base and a finite generating set
of the forward profile group. For every finite root number `r`,
`V_(b,r)(K)` is of type `F_∞`. The displayed self-similar action is
noncontracting, and the theorem does not require `K` itself to have
type `F_∞`. It does not assert this for arbitrary recurrence-labelled
tree actions outside the specified arithmetic/annular hypotheses.

## Attempts

The proposed proof is equality with the finite-germ actor followed
by the shared compact-core SingFix theorem. Finite observation bases,
arithmetic finite-root data, and exact localized full-group membership
are separate unresolved mathematical gates. The old polynomial
tower is a special case, not an assumed theorem in this route.
Section 10 details the equality and noncontraction argument. No
contracting-group theorem supplies the new finiteness conclusion.

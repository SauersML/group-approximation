This proof uses only standard facts, stated where they are used:
- Shapiro's lemma for coinduced modules;
- cohomology of finite groups commutes with direct sums;
- `H^n(C; ZC-free) = 0` for `n >= 1` and `C` finite;
- `H^2` classifies extensions;
- continuous functional calculus.

No claim of the graph is imported.

**Conventions.**
- For a set `X` with a `G`-action and an abelian group `B`, `B^X` is the
  module of all functions `X -> B`, with `(g phi)(x) = phi(g^{-1} x)`.
  `B[X]` is the submodule of finitely supported functions.
- `Z[G/H]` has basis the cosets, with the basis vector of `xH` written as the
  indicator of `xH`.
- For `H <= G`, `B^{G/H}` is the coinduced module `Coind_H^G B`.  Shapiro's
  lemma gives an isomorphism
  `Sh : H^n(G; B^{G/H}) -> H^n(H; B)`: restrict to `H`, then push along the
  `H`-map `ev_H : B^{G/H} -> B` that evaluates at the trivial coset
  (Brown, *Cohomology of Groups*, III.5 and III.6).
- A *derivation* `D : G -> V` satisfies `D(gh) = D(g) + g D(h)`, and
  `H^1(G;V)` is derivations modulo principal ones.

## (A) Root-untwisting

Let `rho : Gamma -> U(Q)` have every `spec rho(e_i) != T`.

1. **The lamp algebra.**  `rho(P)` is a commuting family of unitaries, so
   `B = C*(rho(P)) <= Q` is a commutative unital C*-algebra.  Since `P` is
   normal in `Gamma`, conjugation by `rho(Gamma)` preserves `B`.  Since
   `B` is commutative, `rho(P)` acts trivially on `B`, so `G = Gamma/P` acts
   on `U(B)` by `g . b = rho(g~) b rho(g~)^*` for any lift `g~`.

2. **Principal roots.**  Fix `i`.  Pick `z_i in T \ spec rho(e_i)` and a
   continuous branch `log_i` of the logarithm on `T \ {z_i}`, which is
   continuous on the compact set `spec rho(e_i)`.  Put
   `r_i = exp(log_i(rho(e_i)) / m_i)`, defined by continuous functional
   calculus.  Then `r_i in C*(rho(e_i)) <= B` is unitary and
   `r_i^{m_i} = rho(e_i)`.

3. **`r_i` is `C_i`-fixed.**  `rho(t_i)` commutes with
   `rho(t_i)^{m_i} = rho(e_i)`, hence with all of `C*(rho(e_i))`, hence with
   `r_i`.  Every element of `Gamma` over `C_i` has the form `p t_i^k` with
   `p in P`, and `rho(p)` acts trivially on `B`.  So `s_i . r_i = r_i`.

4. **The root map.**  By step 3, `g . r_i` depends only on the coset
   `g C_i`, which is the basis vector `g e_i`.  So there is a well-defined
   homomorphism of abelian groups
   ```text
   theta : P -> U(B),      theta(g e_i) = g . r_i       (on the coset basis),
   ```
   extended additively-to-multiplicatively.  It is `G`-equivariant by
   construction.  It satisfies `theta(D p) = rho(p)`, which on basis vectors
   reads `(g . r_i)^{m_i} = g . rho(e_i) = rho(g e_i)`.  Here the `G`-action on
   `P` is conjugation in `Gamma`.

5. **Extension to the root pushout.**  Let `P'` be a second copy of `P`,
   with `Gamma` acting through `G`.  Put
   `Gamma' = (P' x| Gamma) / N` with `N = {(D p, p^{-1}) : p in P}`.
   - `N` is normal.  Conjugation by `(0, gamma)` sends `(Dp, p^{-1})` to
     `(D(gamma.p), (gamma.p)^{-1})` because `D` is equivariant, and `P` acts
     trivially on `P'`.
   - `Gamma'` is the pushout extension `1 -> P' -> Gamma' -> G -> 1`, whose
     class is `D_* c`.
   - `(q, gamma) -> theta(q) rho(gamma)` is a homomorphism on `P' x| Gamma`,
     because `rho(gamma) theta(q) rho(gamma)^* = theta(gamma . q)`.  It kills
     `N` by step 4.
   So it descends to `rho' : Gamma' -> U(Q)`, which extends `rho` along
   `Gamma -> Gamma'`, `gamma -> (0, gamma)`.

6. **Splitting and the kill.**  Suppose `c` is root-killable, so
   `D_* c = 0`.  Then `Gamma' -> G` has a homomorphic section `sigma`.
   `rho' o sigma : G -> U(Q)` is trivial, because `Rad_MF(G) = G` means every
   homomorphism from `G` to the unitary group of a matrix corona is trivial.
   Since `Gamma' = P' . sigma(G)`, we get
   `rho(Gamma) <= rho'(Gamma') = theta(P') <= U(B)`, which is abelian.  QED (A).

## (B) One-ended obstruction

Throughout, `G` is finitely generated by a finite symmetric set `S` and is
one-ended.  In particular `G` is infinite.

**Lemma B0 (almost-invariant functions are almost constant).**  Let `B` be
an abelian group and `w : G -> B` a function such that, for every
`g in S`, the function `y -> w(g^{-1} y) - w(y)` has finite support.  Then
`w` is constant outside a finite set.

*Proof.*
1. Let `Lambda` be the graph on `G` with edges `{y, g^{-1} y}` for
   `g in S`.  The map `y -> y^{-1}` is a graph isomorphism from `Lambda` to
   the Cayley graph `Cay(G,S)`, whose edges are `{x, x g}`.  So `Lambda` is
   connected, locally finite and one-ended.
2. Let `K_0` be the finite set of `y` such that `w(g^{-1} y) != w(y)` for some
   `g in S`, and put `K = K_0 u S K_0`.  Then `K` is finite.
3. Every edge `{y, g^{-1} y}` with `y` not in `K_0` joins two vertices with
   equal values of `w`.  An edge with both ends outside `K` is such an edge,
   so `w` is constant on each connected component of `Lambda - K`.
4. Since `Lambda` is locally finite and `K` is finite, `Lambda - K` has
   finitely many components.  Each of them contains a neighbour of `K`.
5. Since `Lambda` is one-ended, exactly one component `U` is infinite.  So
   `G - U` is finite and `w` is constant on `U`.  QED.

**Lemma B1 (finitely supported classes die on finite subgroups).**  Let
`H <= G` be finite and `B` an abelian group.  Then the composite

```text
H^1(G; B[G/H]) -> H^1(G; B^{G/H}) --Sh--> H^1(H; B) = Hom(H, B)
```

is zero.

*Proof.*
1. Let `D : G -> B[G/H]` be a derivation.  Its image under the composite
   is the homomorphism `chi(h) = D(h)(H)`.
2. Define `w : G -> B` by `w(y) = -D(y)(yH)`.
3. For `g, y in G`, use `D(g^{-1} y) = D(g^{-1}) + g^{-1} D(y)` and
   `g D(g^{-1}) = -D(g)`.  Evaluating at `g^{-1} y H` gives
   ```text
   w(g^{-1} y) - w(y) = -D(g^{-1})(g^{-1} y H) = D(g)(yH).        (B1.1)
   ```
4. For `h in H`, use `D(yh) = D(y) + y D(h)` and `(y D(h))(yH) = D(h)(H)`.
   This gives
   ```text
   w(yh) = w(y) - chi(h).                                        (B1.2)
   ```
5. `D(g)` is supported on finitely many cosets, and each coset is finite.
   So by `(B1.1)` the function `y -> w(g^{-1} y) - w(y)` has finite support.
   By Lemma B0, `w` equals a constant `b` outside a finite set `K`.
6. Fix `h in H`.  Right multiplication by `h` is a bijection of the infinite
   set `G`, so some `y` has `y` and `yh` both outside `K`.  Then `(B1.2)`
   gives `b = b - chi(h)`, so `chi(h) = 0`.  QED.

The same argument with `H = 1` gives `H^1(G; B[G]) = 0`.  If `w = b` off a
finite set, then `u = w - b` is finitely supported, and `(B1.1)` gives
`D(g) = g u - u`, which is principal.                             (B1.3)

(In Lemma B0, if `K` is empty then `Lambda` itself is connected and `w` is
constant.)

**Lemma B2 (torsion classes over one induced lattice).**  Let `H <= G` be
finite, `k >= 1`, and `c in H^2(G; Z[G/H])` with `k c = 0`.  Then
`Res_{C'} c = 0` for every subgroup `C' <= G` of prime order `p`.

*Proof.*
1. `Z[G/H]` is free abelian, so
   `0 -> Z[G/H] --k--> Z[G/H] -> (Z/k)[G/H] -> 0` is exact.  Its long exact
   sequence shows that `k c = 0` gives `c = beta(d)` for some
   `d in H^1(G; (Z/k)[G/H])`, where `beta` is the Bockstein.
2. **Orbit decomposition.**  As a `C'`-module, `Z[G/H]` is the direct sum,
   over `C'`-orbits of cosets, of `Z[C'/(C' n xHx^{-1})]`.  Since `|C'| = p`
   is prime, each stabilizer is `C'` or `1`.  So
   ```text
   Z[G/H]|_{C'} = (+)_{xH : C' <= xHx^{-1}} Z  (+)  (free Z[C']-module).
   ```
   Cohomology of a finite group commutes with direct sums, and
   `H^2(C'; free) = 0`.  So `Res_{C'} c = 0` iff `(pi_{xH})_* Res_{C'} c = 0`
   for every coset `xH` fixed by `C'`.  Here `pi_{xH} : Z[G/H] -> Z` takes the
   coefficient at `xH`, and it is `xHx^{-1}`-equivariant.
3. **Reduction to the trivial coset.**  `yH -> y x^{-1} (xHx^{-1})` is a
   `G`-isomorphism `Z[G/H] -> Z[G/xHx^{-1}]` sending `xH` to the trivial
   coset.  Replacing `H` by `xHx^{-1}`, we may assume `xH = H` and
   `C' <= H`.  Then
   ```text
   (pi_H)_* Res_{C'} c = Res^H_{C'} ( (pi_H)_* Res_H c )
                       = Res^H_{C'} Sh( j_* c ),
   ```
   where `j : Z[G/H] -> Z^{G/H}` is the inclusion; note that
   `pi_H = ev_H o j`.
4. **Naturality of the Bockstein.**  Apply it to the map of short exact
   sequences from the `j`-image to `0 -> Z^{G/H} -> Z^{G/H} -> (Z/k)^{G/H} -> 0`,
   and to Shapiro.  This gives
   `Sh(j_* beta(d)) = beta_H( Sh(j_* d) )`, where `j_* d` is the image of `d`
   in `H^1(G; (Z/k)^{G/H})`.
5. By Lemma B1 with `B = Z/k`, `Sh(j_* d) = 0`.  So `(pi_{xH})_* Res_{C'} c = 0`
   for every fixed coset, and `Res_{C'} c = 0`.  QED.

**Proof of (B).**
1. Let `c in H^2(G;P)` with `P = (+)_i Z[G/C_i]`, and suppose every
   component `(p_i)_* c` is torsion.  This holds if `c` is torsion.
   Let `C' <= G` have prime order.  Since `H^2(C'; -)` commutes with direct
   sums, `Res_{C'} c` is zero iff each component
   `Res_{C'} (p_i)_* c in H^2(C'; Z[G/C_i])` is zero, where `p_i` is the
   projection onto summand `i`.  Each `(p_i)_* c` is `k`-torsion, so each
   component vanishes by Lemma B2 (with `k` depending on `i`).
2. **Summands.**  If `A` is a `G`-direct summand of `P`, with `pi iota = id_A`,
   and `c in H^2(G;A)` is torsion, then `iota_* c` is torsion.  So
   `Res_{C'} c = pi_* Res_{C'} iota_* c = 0`.
3. **Lifting.**  `Res_{C'} c = 0` means the restricted extension
   `1 -> A -> Gamma_{C'} -> C' -> 1` splits.  So a generator of `C'` lifts to
   an element of order `p` in `Gamma`.
4. **Root-killable classes are componentwise torsion.**  Since
   `p_i o D = m_i p_i`, the condition `D_* c = 0` gives
   `m_i (p_i)_* c = 0` for every `i`, so step 1 applies.  If `I` is finite,
   then `c` itself is torsion: with `L = lcm(m_i)`, the `G`-map `L/D`
   (multiplying summand `i` by `L/m_i`) satisfies `(L/D) D = L`, so
   `L c = (L/D)_* D_* c = 0`.  QED (B).

## (C) Rational non-splitting of the relation cover

Let `G = F/R` with `F` free on `x_1, ..., x_n`, `g_j` the image of `x_j`, and
`G` one-ended.  Let `S` be a nonzero commutative ring.

1. **Lyndon's sequence.**  Let `d : ZG^n -> I_G` be the map
   `d(e_j) = g_j - 1`.  Its kernel is the relation module `M`, embedded by Fox
   derivatives (Lyndon).
2. **`E` as a pullback.**  Put
   `E_0 = {(q, g) in ZG^n x| G : d q = g - 1}`.  This is a subgroup, because
   `d` is equivariant and `g -> g - 1` is a derivation.
   - `E_0 -> G` is onto, since `d` is onto `I_G`, and its kernel is `M`.
   - The section `g -> (q(g), g)`, for any lift `q(g)` of `g - 1`, has
     cocycle `q(g) + g q(h) - q(gh)`.  This is the connecting image of the
     derivation class `epsilon = [g -> g - 1] in H^1(G; I_G)` under
     `delta : H^1(G; I_G) -> H^2(G; M)`.
   - `x_j -> (e_j, g_j)` defines `F -> E_0`.  It sends `r in R` to its Fox
     vector in `M`, so it kills `[R,R]` and induces `E -> E_0`.
   - That map is the identity on `M` (Lyndon's identification) and on `G`,
     hence an isomorphism of extensions.  So `xi = delta(epsilon)` (this is
     the Magnus embedding).
3. **Tensoring with `S`.**  All modules in the Lyndon sequence and in
   `0 -> I_G -> ZG -> Z -> 0` are free abelian, so both sequences stay exact
   after `(x) S`.  By naturality of connecting maps, the image `xi_S` of `xi`
   in `H^2(G; M (x) S)` equals `delta_S(epsilon_S)`, where
   `epsilon_S = [g -> (g - 1)(x) 1]`.
4. **`delta_S` is injective.**  Its kernel is the image of
   `H^1(G; (SG)^n) = H^1(G; SG)^n`, which is zero by `(B1.3)` with
   `B = S`, because `G` is one-ended.
5. **`epsilon_S` is nonzero.**  In the sequence for
   `0 -> I_G (x) S -> SG -> S -> 0`, the connecting map `S -> H^1(G; I_G (x) S)`
   sends `1` to `epsilon_S`.  Its kernel is the image of `(SG)^G`, which is
   `0` because `G` is infinite.  So `epsilon_S != 0` since `1 != 0` in `S`.
6. Hence `xi_S != 0`.  QED (C).

## Why the three parts fit together

- (A) turns a spectral gap in every lamp into an abelian model, but only
  when the class dies after adjoining roots.
- (B) shows that over a one-ended base with torsion such a class never gives
  a torsion-free cover.
- (C) shows that the canonical torsion-free cover `E` has a class that
  survives every algebraic root extension.

So on the bases relevant to `property-t-free-manuscript-results` (the
one-ended base `St_20(L_(F_2)(1,2))`), gapped-lamp untwisting is powerless
on every torsion-free lamp cover.  Any kill of an injective model must work
on lamps with full circular spectrum.

Notation is as in the target. `|·|` on `Z^n` is the sup norm.

**Step 0 (cocycle and subadditivity).** This is Step 0 of `brin-thompson-exponent-cocycle-proof`,
repeated for completeness.
- *Well defined.* Splitting coordinate `j` of a table brick by one digit `a` gives
  `C(u_j a) → C(v_j a)`, with the same difference. Any two tables have a common refinement, so
  `δ_g` does not depend on the table. It is locally constant with finitely many values.
- *Cocycle.* Refine a table of `h` so that each domain brick is mapped into one table brick of
  `g`. Then `gh` acts on that brick by prefix replacement and the differences add:
  `δ_{gh}(x) = δ_g(hx) + δ_h(x)`. With `h = g^{-1}`: `δ_{g^{-1}}(gx) = −δ_g(x)`.
- *Consequences.* `D(gh) ≤ D(g) + D(h)` and `D(g^{-1}) = D(g)`. If `L` is generated by a finite
  symmetric `S` and `K = max_S D`, then `D(g) ≤ K|g|_L` on `L`. If `g^q x = x`, then
  `δ_{g^{qj}}(x) = j δ_{g^q}(x)` for `j ≥ 0`, by induction on `j`.
- *Slope.* Near a point `p` where `g^q` is `u z ↦ v z`, the slope in
  `infinite-order-elements-of-v-have-hyperbolic-periodic-points` is `2^{|u|−|v|} = 2^{−δ_{g^q}(p)}`.
  So "nontrivial slope" means `δ_{g^q}(p) ≠ 0`.

**Step 1 (T_n is a group; the base map).**
- *Uniqueness and inverses.* `pr_k` is surjective, so `h_k` is determined by `g`. If
  `pr_k ∘ g = h_k ∘ pr_k` with `h_k` bijective, then `h_k^{-1} ∘ pr_k = pr_k ∘ g^{-1}`. Products
  compose the `h_k`. So `T_n` is a group.
- *`h_k ∈ kV`.* On a table brick `B = Π_j C(u_j)` of `g`, the map `h_k` is
  `(u_j z_j)_{j ≤ k} ↦ (v_j z_j)_{j ≤ k}` on `pr_k(B)`. The bricks `pr_k(B)` cover `C^k`; refine
  them to a finite partition into bricks, on each of which `h_k` is still a prefix replacement.
  Since `h_k` is a bijection, the images form a brick partition too. So `h_k ∈ kV`, and on each
  such brick `δ_{h_k}(pr_k x) = (δ_g(x))_{j ≤ k}`.
- *`h_{n−1} ∈ T_{n−1}`.* For `k < n − 1`, `pr_k = pr'_k ∘ pr_{n−1}` with `pr'_k: C^{n−1} → C^k`.
  Then `pr'_k ∘ h_{n−1} ∘ pr_{n−1} = pr_k ∘ g = h_k ∘ pr'_k ∘ pr_{n−1}`, and surjectivity of
  `pr_{n−1}` gives `pr'_k ∘ h_{n−1} = h_k ∘ pr'_k`.
- *Powers.* The base map of `g^m` is `h_{n−1}^m`, so `D(g^m) ≥ D(h_{n−1}^m)`.

**Step 2 (growth, by induction on `n`).** Claim: for infinite-order `g ∈ T_n` there is `Q ≥ 1`
with `D(g^m) ≥ ⌊m/Q⌋` for all `m ≥ 0`.
- *Reduction to a subsequence.* `m ↦ D(g^m)` is subadditive, so by Fekete's lemma
  `lim_m D(g^m)/m` exists and equals `inf_{m ≥ 1} D(g^m)/m`. Hence if `D(g^{Qj}) ≥ j` for all
  `j`, then `inf_m D(g^m)/m = lim_j D(g^{Qj})/(Qj) ≥ 1/Q`, that is, `D(g^m) ≥ m/Q` for all
  `m ≥ 0`. So it suffices to find `Q ≥ 1` with `D(g^{Qj}) ≥ j` for all `j`.
- *Base case `n = 1`.* `T_1 = V`. By `infinite-order-elements-of-v-have-hyperbolic-periodic-points`
  and the slope remark of Step 0 there are `q ≥ 1` and `p` with `g^q p = p`, `δ_{g^q}(p) ≠ 0`.
  So `D(g^{qj}) ≥ |j δ_{g^q}(p)| ≥ j`.
- *Step `n ≥ 2`, case A: `h = h_{n−1}` has infinite order.* `h ∈ T_{n−1}` by Step 1, so by
  induction `D(h^m) ≥ m/Q` for some `Q`, and `D(g^m) ≥ D(h^m)` by Step 1.
- *Case B: `h` has finite order `d ≥ 1`.* Then `pr_{n−1} ∘ g^d = pr_{n−1}`, so
  `g^d(x', y) = (x', F_{x'}(y))` for `x' ∈ C^{n−1}`, `y ∈ C`.
  - On a table brick `P × C(u)` of `g^d` (with `P` a brick of `C^{n−1}`), the first `n−1`
    coordinates are fixed, so the brick map is `(x', u z) ↦ (x', v z)`: a prefix word `w` with
    `w z = w' z` for all `z` has `w = w'`.
  - Refine the bricks `P` to a finite brick partition `P_1, ..., P_s` of `C^{n−1}` such that on
    each `P_i × C` the words `(u, v)` do not depend on `x'`. Then `F_{x'} = F_i` for `x' ∈ P_i`,
    each `F_i` is a bijection of `C` given by prefix replacements (because `g^d` is a bijection
    preserving each fibre), so `F_i ∈ V`.
  - `g^{dj}(x', y) = (x', F_i^j(y))` on `P_i × C`. If every `F_i` had finite order, their orders
    have a common multiple `e`, and `g^{de} = id`, contradicting infinite order of `g`. So some
    `F = F_i` has infinite order.
  - By the base case there are `q ≥ 1` and `p ∈ C` with `F^q p = p` and `δ_{F^q}(p) ≠ 0`. Pick
    `x'_0 ∈ P_i`. Then `g^{dq}(x'_0, p) = (x'_0, p)`, and near this point `g^{dq}` is
    `(x', u z) ↦ (x', v z)` with `u z ↦ v z` the local form of `F^q` at `p`. So the last coordinate
    of `δ_{g^{dq}}(x'_0, p)` is `δ_{F^q}(p) ≠ 0`.
  - By Step 0, `D(g^{dqj}) ≥ |j δ_{F^q}(p)| ≥ j`, so `Q = dq` works.
- In all cases `D(g^m) ≥ m/Q ≥ ⌊m/Q⌋` for all `m ≥ 0`, which is item 2 of the target.

**Step 3 (undistortion, conjugates, permutations).**
- Let `g ∈ L`, `L` finitely generated with symmetric generating set `S`, `K = max_S D`. For
  `g ∈ T_n` of infinite order, `m/Q ≤ D(g^m) ≤ K|g^m|_L`, so `K > 0` and `|g^m|_L ≥ m/(KQ)`.
- *Conjugates.* If `g = k t k^{-1}` with `t ∈ T_n` of infinite order, then
  `D(g^m) ≥ D(t^m) − 2D(k) ≥ m/Q − 2D(k)`, and `|g^m|_L ≥ (m/Q − 2D(k))/K`, which is linear in `m`.
- *Permutations.* A permutation `σ` of coordinates is a homeomorphism of `C^n` normalising `nV`,
  and `δ_{σgσ^{-1}}(σx)` is `δ_g(x)` with coordinates permuted. So `D(σgσ^{-1}) = D(g)`, and the
  same bound holds for `σ T_n σ^{-1}`. ∎

**Remark (where triangularity is used).** For `n ≥ 2` the baker's map
`β(i x, y) = (x, i y)` has `δ_β ≡ (−1, +1)`: it moves exponent from one coordinate into
another. Triangularity is used only in Case B, to turn "the base map has finite order" into
"a power of `g` preserves every fibre of `pr_{n−1}`", which produces a genuine element of `V`
in the last coordinate and hence a hyperbolic periodic point. For non-triangular elements the
base is not a map at all, and nV (n >= 2) does contain distorted elements
(`brin-thompson-mv-contains-a-distortion-element`), so no argument of this shape covers them.

## Why sufficient

**The group.**  `Q = Z[1/2] x| Z` with `(r,n)(s,m) = (r + 2^n s, n+m)`,
`x = (1,0)`, `t = (0,1)`.  Then `t x t^{-1} = (2,0) = x^2`, so `Q = BS(1,2)`.
Put `P = <x>`, `X = Q/P`, `A = (+)_X Z` with `Q` permuting coordinates,
`W = A x| Q` and `c = delta_P`.

**Torsion-free, solvable, three-generated.**  `Q` is torsion-free: a
finite-order element has trivial `Z`-part, hence lies in the torsion-free
group `Z[1/2]`.  A finite-order element of `W` maps to `1` in `Q`, hence lies
in the free abelian `A`, hence is `1`.  `A` is abelian and `Q` metabelian, so
`W` is solvable and therefore elementary amenable.  Finally
`delta_{qP} = q c q^{-1}`, so `W = <x, t, c>`.

**The defect is nontrivial.**  `t P t^{-1} = <x^2> <= P`, so `t` is a
compressor; `P` fixes the coset `P`, so `c = delta_P` is centralized by `P`.
Hence `u = [t c t^{-1}, x]` is a displayed defect generator, and additively

    u = delta_{tP} - delta_{x t P}.

The two cosets differ: `x t P = t P` would force `t^{-1} x t in P`, but
`t^{-1} x t = (1/2, 0)` and `P = <(1,0)>`.  So `u != 1`, of infinite order.

**Strong Atiyah applies.**  `W` is torsion-free elementary amenable, so by
`elementary-amenable-torsion-free-strong-atiyah` it satisfies the conjecture
and `D = D_C(W)` is a division ring.

**The contradiction.**  `C[W] -> U(W)` is injective -- evaluate a finite sum
of left translations on `delta_1` -- so `W` sits faithfully in `D^x` and
`u != 1` there.  Let `E <= D` be the division subring generated by `x, t, c`.
Since those three generate `W`, the faithful copy of `W` lies in `E^x`.  If
`E` were centrally finite, then
`compression-defect-dies-in-centrally-finite-division-rings` applied to
`W -> E^x` with `L = P` would give `u = 1`.  It does not.  Hence `E` is
infinite-dimensional over its center, and since `E` is generated by three
elements, `D` is not weakly locally finite.

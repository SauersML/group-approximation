All unmarked tensor products are over `k`. Let `a_1, ..., a_n` be a commuting independent family in `A`.

## 1. The rings

- `C = k[a_1, ..., a_n] ⊆ A` is the unital subalgebra generated by the `a_i`. By independence, `x_i ↦ a_i` is an
  isomorphism `k[x_1, ..., x_n] -> C`. So `C` is a polynomial ring, hence a domain.
- Let `K = k(y_1, ..., y_n)` and `R = A ⊗ K`. `K` is central in `R`.
- `S = C ⊗ K ⊆ R`. The inclusion is injective because `- ⊗ K` is exact over the field `k`. `S` is commutative,
  and `S ≅ K[a_1, ..., a_n]` is a polynomial ring over `K`.
- `z_i = a_i ⊗ 1 - 1 ⊗ y_i ∈ S`, and `I = z_1 S + ... + z_n S`. The `z_i` are a linear change of the polynomial
  variables of `K[a]`, so they form a regular sequence, and `S / I ≅ K` via `a_i ↦ y_i`.
- Through `C -> S -> S/I ≅ K`, the ring `C` acts on `K` by `a_i ↦ y_i`. This is the fraction-field embedding
  `C ≅ k[y] ⊆ k(y)`. **So `S/I`, restricted to `C`, is `Frac(C)`, which is flat over `C`.**

## 2. The resolution

Let `K_• = K_•(z_1, ..., z_n; S)` be the Koszul complex. It is a free resolution of `S/I` of length `n` over `S`,
with `K_j = Λ^j S^n`.

Put `F_• = R ⊗_S K_•`, a complex of free left `R`-modules with `F_j ≅ R^(binom(n, j))`. Its homology is
`Tor^S_•(R, S/I)`, where `R` is a right `S`-module by right multiplication.

**Lemma. `Tor^S_i(R, S/I) = 0` for `i >= 1`.**
- *R as a base change.* The map `A ⊗_C S = A ⊗_C (C ⊗ K) -> A ⊗ K`, `a ⊗ (c ⊗ κ) ↦ ac ⊗ κ`, is an
  isomorphism of right `S`-modules, with inverse `a ⊗ κ ↦ a ⊗ (1 ⊗ κ)`.
- *Change of rings.* `S = C ⊗ K` is a free `C`-module, so it is flat over `C`. Take a projective resolution
  `P_• -> A` of right `C`-modules. Then `P_• ⊗_C S -> A ⊗_C S` is a projective resolution over `S`. Hence
  `Tor^S_i(A ⊗_C S, M) = H_i(P_• ⊗_C M) = Tor^C_i(A, M)` for every `S`-module `M`.
- *Flatness.* With `M = S/I`, restricted to `C` this is `Frac(C)` (Section 1), which is flat over `C`. So
  `Tor^C_i(A, Frac C) = 0` for `i >= 1`. ∎

So `F_•` is a free resolution of length `n` of `Q := H_0(F_•) = R ⊗_S S/I = R / (R z_1 + ... + R z_n)`. By
the Lemma's identification, `Q ≅ A ⊗_C Frac(C)`.

No hypothesis on `A` as a `C`-module was used. This is the step where earlier attempts needed `A` to be flat
over `C`.

## 3. The top degree does not vanish

The last differential is `F_n = R -> F_(n-1) = R^n`, `r ↦ (± r z_i)_i`.

**The right module `Q'`.** As a left `S`-module, `R = A ⊗ K ≅ (C ⊗ K) ⊗_C A = S ⊗_C A`. So
`Q' = R / (z_1 R + ... + z_n R) = (S/I) ⊗_S R ≅ Frac(C) ⊗_C A = (C \ 0)^(-1) A`, the localization of the left
`C`-module `A`. The class `q` of `1` maps to `1/1`. Now `1/1 = 0` would need `c · 1 = 0` for some nonzero
`c ∈ C`, which is impossible since `c · 1 = c ≠ 0`. So `q ≠ 0`, and `Q' ≠ 0`.

**Tor.** `Tor^R_n(Q', Q) = H_n(Q' ⊗_R F_•) = ker(Q' -> Q'^n, u ↦ (± u z_i)_i)`. Here `q z_i` is the class of
`z_i`, which lies in `z_i R`, so `q z_i = 0`. Hence `0 ≠ q ∈ Tor^R_n(Q', Q)`, and `w.gl.dim R >= n`.

**Ext.** `Hom_R(F_•, R)` ends with `R^n -> R`, `(x_i) ↦ Σ ± z_i x_i`. So
`Ext^n_R(Q, R) ≅ R / (z_1 R + ... + z_n R) = Q' ≠ 0`. Since `F_•` has length `n`, `pd_R Q = n`, and
`l.gl.dim R >= n`.

The mirror construction, with `Q'` resolved by `K_• ⊗_S R`, gives `r.gl.dim R >= n`. ∎

## 4. Non-unital embeddings

Let `φ : k[x_1, ..., x_n] -> A` be an injective `k`-algebra map, not necessarily unital, and put `a_i = φ(x_i)`.
The `a_i` commute. Let `P = c + G ≠ 0`, where `c ∈ k` and `G` has no constant term. Then
`P(a) = c · 1_A + φ(G)`.
- If `c = 0`, then `G ≠ 0` and `P(a) = φ(G) ≠ 0`.
- If `c ≠ 0` and `P(a) = 0`, then `1_A = φ(h)` with `h = -G/c`. So `φ(h^2) = 1_A = φ(h)`, and injectivity gives
  `h^2 = h` in the domain `k[x]`. So `h ∈ {0, 1}`. But `h` has no constant term, so `h = 0`, and then `1_A = 0`,
  contradicting `A ≠ 0`.

So `a_1, ..., a_n` is a commuting independent family. The same holds for the restriction of any injective map
from `k[Z^n] ⊇ k[x_1, ..., x_n]`. ∎

## 5. Sanity checks

- `A = k[x_1, ..., x_n]`: `R` is a localization of `k[x, y]` of Krull dimension `n` at the diagonal, so the bound
  is sharp.
- `A = k(x)[y]` has global dimension `1` but contains `k[x, y]`. The claim gives `gl.dim(A ⊗ k(y_1, y_2)) >= 2`,
  which is correct: `k(x) ⊗ k(y_1, y_2)` is regular of dimension `1`, and adjoining `y` adds one. So the lower
  bound genuinely concerns `A ⊗ K`, not `A`.
- `A = k<x, y>` has only `n <= 1`, by Bergman's centralizer theorem, and `A ⊗ K = K<x, y>` has global dimension
  `1`. This is consistent.

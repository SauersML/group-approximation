Notation: `R = Z[t,t^{-1}]`, `G = SL_2(R)`, `T` the Bruhat–Tits tree of `Q((t))`, edge
`e = [v_0, v_1]` with `Stab_G(v_0) = SL_2(Z[t])`, `Stab_G(v_1) = D SL_2(Z[t]) D^{-1}`,
`Stab_G(e) = C = Gamma_0(t)` (`sl2-laurent-integers-splits-over-gamma0-t`).
Put `U_0 = U_2(Z[t])` and `U_1 = D U_0 D^{-1}`.

**Lemma (sub-amalgam).** Let `H_0 ⊂ Stab_G(v_0)` and `H_1 ⊂ Stab_G(v_1)` be subgroups
with `H_0` transitive on the neighbours of `v_0`, `H_1` transitive on the neighbours of
`v_1`, and `H_0 ∩ C = H_1 ∩ C =: X`. Then `H = <H_0, H_1>` is the amalgam
`H_0 *_X H_1`, and `Stab_H(v_0) = H_0`.

*Proof.* Let `P = H_0 *_X H_1` with Bass–Serre tree `T'`, base edge `[p_0, p_1]`. The
map `f: T' → T`, `f(q·p_i) = q·v_i`, is well defined and `P`-equivariant, since `H_i`
fixes `v_i` and `X` fixes both. The neighbours of `p_0` are `H_0/X`, and `f` sends
`hX ↦ h v_1`. This is onto the neighbours of `v_0` by transitivity, and injective
because `Stab_{H_0}(v_1) = H_0 ∩ C = X`. The same holds at `p_1`, using
`Stab_{H_1}(v_0) = H_1 ∩ C = X`. By equivariance `f` is bijective on every link. A
locally injective map of trees is injective (it maps geodesics to geodesics), and its
image, closed under neighbours, is all of `T`; so `f` is an isomorphism. The kernel of
`P → H` fixes `T'` pointwise, so it lies in `H_0`, which maps injectively; hence
`P ≅ H`, and `Stab_H(v_0) = f(Stab_P(p_0)) = H_0`. ∎

**Derivation.** `U_0 ⊇ E_2(Z[t])` reduces onto `SL_2(Z)`, so it is transitive on the
neighbours of `v_0`; similarly `U_1` at `v_1`. The input
`polynomial-unipotent-subgroup-fricke-compatible` is exactly `U_0 ∩ C = U_1 ∩ C`. By
the lemma, `Stab_{<U_0,U_1>}(v_0) = U_0`. By
`sl2-laurent-unipotent-quotient-is-polynomial-quotient`, `<U_0, U_1> = U_2(R)`, so
`U_2(R) ∩ SL_2(Z[t]) = U_2(Z[t])` and
`G / U_2(R) ≅ SL_2(Z[t]) / U_2(Z[t])`. By
`gmv-sl2-zx-mod-unipotents-has-free-quotients`, this has free quotients of every
finite rank. A group generated by `d` elements has no free quotient of rank `> d`, so
`G` is not finitely generated.

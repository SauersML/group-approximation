Take `sigma: G -> U(M)` from the first prerequisite and put
`R = sigma(Gamma)' cap M` and `K = {g in G : [sigma(g), R] = 0}`.
Then `Gamma <= K`.

**Step 1: `N = <<Gamma>>_G` is not in `K`.**  If `N <= K`, then `R` commutes
with `sigma(N)`.  So `R <= sigma(N)' cap M <= sigma(Gamma)' cap M = R`, giving
`R = sigma(N)' cap M`.  That algebra is normalized by `sigma(G)` because `N` is
normal, contrary to hypothesis.

**Step 2: `L(K) <= L(G)` is relatively embeddable over scalars.**  For each
`g notin K`, choose a projection `p_g in R` not commuting with `sigma(g)`.  The
countable family `{p_g}` has common commutation stabilizer exactly `K`.  No
trace condition is needed.  `ce-stabilizer-criterion-needs-no-trace` (2 => 1),
applied inside the separable Connes-embeddable algebra generated by `sigma(G)`
and the `p_g` (`G` is residually finite, hence hyperlinear), gives the
relative embedding.

**Step 3: `W_K` is hyperlinear.**  Apply
`binary-free-and-ordinary-coset-wreaths-share-hyperlinearity` to the pair
`K <= G`, going from (6) to (1).

**Step 4: `W_K` is nonsofic.**  By `kt-intermediate-coset-wreaths-are-nonsofic`,
since `Gamma <= K` and `N` is not in `K`.

So `W_K` is a hyperlinear nonsofic group.

## Corollary C′

1. **Homomorphism.**
   - `𝒜_N = φ_N(R)` is a unital subring of `End(W_N)`, and `W_N` is a unital `𝒜_N`-module.
   - Matrix multiplication uses only ring operations on entries, and `φ_N` is a unital ring homomorphism. So
     `ρ_N : H → GL_n(𝒜_N)` is a group homomorphism with `ρ_N(e_ij(r)) = e_ij(φ_N(r))`.
   - Hence `ρ_N(H) = ⟨e_ij(x) : x ∈ 𝒜_N, i ≠ j⟩ = EL_n(𝒜_N)`, acting on the finite set `X_N` by additive permutations.
2. **Common gap.** Apply `elementary-group-column-actions-have-orbitwise-gap` with `𝒜 = 𝒜_N`, `W = W_N` and
   `H = EL_n(𝒜_N)`. The group `ρ_N(H) ≤ Sym(X_N)` has orbitwise gap `1/(2n²)`, and so does its restriction to every
   invariant subset. Since `n` is fixed, the gap is common to all `N`.
3. **Kazhdan pair.** `H = EL_n(R)` has property (T) (`elementary-groups-over-fg-rings-have-property-t`, `n ≥ 3`), so
   the finite generating set `A` is a Kazhdan set with some constant `κ > 0`.
4. **Apply Corollary C.** Corollary C of `orbitwise-gap-sofic-approximations-are-local-embeddings` is stated for any
   `ρ_N` whose images have a common orbitwise gap. Its proof uses about `ρ_N` only:
   - that `ρ_N` is a homomorphism into the permutations of a finite set: injective letters in its step 1, invariant
     sets in step 2, and `σ′(g)σ′(h)σ′(gh)^(−1) = ρ_N(k)|_(Z_N)` in step 3;
   - that the gap passes to invariant subsets: step 2;
   - the Kazhdan cutting lemma for the finite `H`-set `X_N`: step 2;
   - Theorem O: step 4;
   - for the simple variant, Consequence 1 of `almost-actions-of-irs-rigid-simple-groups-are-free-or-trivial`: step 5.

   Linearity over a field and semisimplicity are not used there. Steps 1–3 supply the hypotheses, so both
   conclusions hold. ∎

## Host consequence

1. **The cover.** `R_Δ` is generated as a ring by finitely many elements: `u_s^(±1)` for `s` in a finite generating
   set of `Δ`, `u_a`, and `1_{x(e)=1}`. Pick such a finite set `B`. Then `F_2⟨B⟩ ↠ R_Δ` induces `EL_n(F_2⟨B⟩) ↠ G_Δ`,
   since both groups are generated by elementary matrices and the entries lift. So `G_Δ = H/K` with `H = EL_n(F_2⟨B⟩)`.
2. **Column models.** A unital ring homomorphism `φ : F_2⟨B⟩ → End(W)` satisfies `2·id_W = φ(2) = 0`. So `W ≅ F_2^m`,
   `End(W) = M_m(F_2)`, and `φ` is an arbitrary assignment of the letters to matrices.
3. **LEF.** If such models gave a sofic approximation of `G_Δ`, then `G_Δ` would be LEF, by Corollary C′ with
   `R = F_2⟨B⟩`. Here `X_N = W_N^n ≅ F_2^(mn)` is an `F_2`-vector space and `ρ_N : H → GL(X_N)`, so this case is
   Corollary C exactly as stated there, with the common gap supplied by step 2 of C′. The re-reading in step 4 of
   C′ is needed only for general finite abelian `W_N`.
4. **Derived subgroup inside.** `[Δ,Δ] ≤ EL_3(F_2[Δ]) ≤ EL_3(R_Δ) ≤ EL_n(R_Δ) = G_Δ`.
   - The first map is `γ ↦ diag(u_γ,1,1)`: `perfect-groups-embed-in-crossed-product-elementary-groups`, item 3, with `X`
     a point, where `LC(X,F_2) ⋊ Δ = F_2[Δ]`. It is injective by item 1.
   - For the second, `Σ c_δ u_δ ↦ Σ c_δ u_δ` (constants `c_δ ∈ F_2`) is an injective unital ring homomorphism
     `F_2[Δ] → R_Δ`. Injectivity holds because `R_Δ` is the free `LC(2^Δ,F_2)`-module on the `u_ℓ`, `ℓ ∈ L`, and
     `Δ ≤ L`. So `GL_3(F_2[Δ]) ≤ GL_3(R_Δ)`, and elementary matrices go to elementary matrices.
   - The third is the block embedding `M ↦ diag(M, I_(n−3))`, which sends `e_ij(r)` to `e_ij(r)`.
5. **Contradiction.** LEF passes to subgroups, so `[Δ,Δ]` would be LEF.
6. **`EL_3(F_2[Δ])`.** `F_2[Δ]` is generated by the `u_s^(±1)`, so `EL_3(F_2⟨B′⟩) ↠ EL_3(F_2[Δ])`. Steps 2–5 apply
   verbatim, with the first inclusion of step 4.
7. **Examples.** For a finitely generated group `Γ`, `Δ = C(Γ)` is finitely generated and infinite, since `σ` has
   infinite order, and `Γ ≤ [Δ,Δ]` (`groups-embed-in-derived-subgroup-of-half-line-overgroup`, item 1). If `Γ` is not
   LEF, neither is `[Δ,Δ]`. ∎

Lane proof (gq-deep-adelic-1), not independently reviewed.

Suppose `φ : R -> M_k(C)` is a unital ring homomorphism, and let `r_1, ..., r_m` generate `R`.

1. **A finitely generated coefficient ring.** Let `A ⊆ C` be the subring generated by `1` and the
   entries of the matrices `φ(r_1), ..., φ(r_m)`. Then `M_k(A)` is a unital subring of `M_k(C)`
   containing every `φ(r_i)`, so `φ(R) ⊆ M_k(A)`. `A` is a finitely generated commutative ring,
   and `A != 0` because `1_C != 0`.
2. **Every prime is invertible in A.** Let `p` be a prime and `X = φ(1/p) ∈ M_k(A)`. Then
   `p X = φ(p · (1/p)) = I_k`. The `(1,1)` entry gives `p x_11 = 1` in `A`, so `p ∈ A^x`. Hence
   the unital map `Z -> A` extends to a unital map `Q -> A`.
3. **Contradiction.** `A != 0` has a maximal ideal `m`. The field `A/m` is finitely generated as a
   ring, hence finite: a field that is finitely generated as a `Z`-algebra is a finite field (the
   Nullstellensatz over `Z`; e.g. Atiyah–Macdonald, Ch. 5, Exercise 25 and Ch. 7, Exercise 5). But
   `A/m` receives a unital map from the field `Q`, which is injective, so `A/m` has characteristic
   `0` and is infinite. This is a contradiction.

**Items 1--2 ESTABLISHED; item 3 is conditional on (GE) for `R_L`.** Proof in
`leavitt-ge-rings-have-stable-k1-at-rank-three-proof`. Lane proof, not independently reviewed. No priority is claimed.

**Setting.** `R` is a unital ring. It has **(GE)** if for every `n >= 2`, each matrix in `GL_n(R)` is a product of
elementary matrices and invertible diagonal matrices.

**Statement.**
1. **Surjective stability from rank 1.** If `R` has (GE), then every class of `GL_n(R)/E_n(R)`, `n >= 2`, contains a
   matrix `diag(u, 1, ..., 1)` with `u in R^x`. So `GL_m/E_m -> GL_n/E_n`, `A -> A ⊕ I`, is onto for every `1 <= m <= n`.
2. **With a Leavitt pair.** If `R` also has a Leavitt pair, then `GL_n(R)/E_n(R) -> K_1(R)` is an isomorphism for
   every `n >= 3`. Injectivity uses `leavitt-k1-stability-is-one-step`, item 3.
3. **For `R_L`, conditional on (GE).** `GL_n(R_L)/E_n(R_L) ≅ K_1(R_L) ≅ Z`, generated by `diag(N + 1, 1, ..., 1)`, for
   every `n >= 3`. Hence input (S1) of `leavitt-resolvent-frame-complex-route-to-injective-stability` holds: for
   `n >= 4`, `H ⊕ 1 in E_n` implies `H in E_(n-1)`.

## Status of (GE) for `R_L`

- Khanh (arXiv:2609.08428, Lemma `lem:elementary-generation`, read in TeX) attributes GE to Menal--Moncasi (1984,
  Theorem 2.2 and the remark after Corollary 2.3, not read). He states that it applies "to a simple ring in which
  each nonzero `x` admits `y, z` with `yxz = 1`, and requires no regularity assumption".
- **Core elements.** For `R_L` the property holds on the core. A nonzero core element has a nonzero coefficient
  `c = t_μ y s_ν in B⁺`, and `t_2 t_1^k c s_1^k s_2 = c(k)`, which is a nonzero rational for some `k`.
- **Open step.** For arbitrary nonzero `x in R_L`, one must first compress `x` to a nonzero core element by one-sided
  multiplications, `y' x z'`. This is the reduction step in the simplicity proof of
  `leavitt-nekrashevych-completion-simplicity-criterion`, but written as a single product rather than a sum. It is not
  written out here.

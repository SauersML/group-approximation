Notation of the claim. "a.e." means: for every fixed group element (or finite
family of group elements), the set of `a in A_n` where the stated property fails
has proportion tending to `0` along `U`. Finitely many a.e. statements hold
simultaneously a.e.

## 0. Inputs

**(I1) One-color criterion.** By [[mikhailova-one-color-code-proof]] (section
"From one color back to every chart", valid for every transitive action, via GKP
Proposition 2.9 in [[gkp-sofic-action-is-liftable-hamming-chart-family]]):
`G action G/M` is sofic if there are a homomorphism `Phi : G -> prod_U Sym(Omega_n)` and
colorings `c_n : Omega_n -> Nat` such that for every `g in G`,

```text
lim_U mu_n{ p : c_n(Phi_n(g)^-1 p) != c_n(p) } = 0 if g in M, and = 1 if g notin M.
```

The set of `g` with limit `0` is a subgroup, so it suffices to check the value `0` on a
generating set of `M` and the value `1` on each `g notin M`.

**(I2) Structure.** By [[centralizer-hnn-is-free-generalized-wreath]],
`Gamma = F(X) x| K` with `k z_x k^-1 = z_(kx)` and `v = z_(x_0)`, so
`h v h^-1 = z_(hL)`. For `f in F`,

```text
v f v^-1 f^-1 = z_(x_0) z_(f x_0)^-1 .
```

Hence `S = A_Y x| F` with `Y = F.x_0`, `S cap F(X) = A_Y`, and `S` is generated by
`F` together with the elements `z_(x_0) z_(f x_0)^-1`, `f in F`. Moreover
`h L in Y` if and only if `h in FL`.

**(I3) Hub subgroups.** For a set `J` of letters, write `A_J = < p p'^-1 : p, p' in J >`, with `A_empty = 1`.
Choosing `p_0 in J`, the elements `p p_0^-1` (`p != p_0`) together with `p_0` form a basis of `F(J)`.
So `A_J` is a free factor of `F(J)`, and it is finitely generated when `J` is finite.

**Retraction lemma.** For letter sets `J, Z` of a free group, `A_J cap F(Z) = A_(J cap Z)`.

*Proof.* `A_J cap F(Z) <= F(J) cap F(Z) = F(J cap Z)`, using the retraction that deletes the
letters outside `Z`. If `J cap Z` is empty the intersection is trivial. Otherwise fix
`q in J cap Z`, and let `rho : F(J) -> F(J cap Z)` send every letter of `J` outside `Z` to
`q` and fix `J cap Z`. Then `rho` is a retraction, and `rho(A_J) <= A_(J cap Z)`, since each
generator `p p'^-1` goes to a generator or to `1`. For `u in A_J cap F(J cap Z)` we get
`u = rho(u) in A_(J cap Z)`. The reverse inclusion is clear. QED.

**(I4) M. Hall.** Finitely generated subgroups of free groups are closed in the profinite
topology. So for a finite set `P`, a subset `J <= P`, and a radius `r`, there is a finite-index
`H <= F(P)` with `A_J <= H` and `H cap Ball_r = A_J cap Ball_r`.

## 1. The model

Fix radii `r_n -> infinity` slowly. Let `P_n = zeta_n(A_n)` (finite) and, for
`beta in omega_n(A_n)`, put `J_n(beta) = { c in P_n : (beta, c) in R_n }`. By (I4) choose
finite-index `H_beta <= F(P_n)` with

```text
A_(J_n(beta)) <= H_beta,        H_beta cap Ball_(r_n) = A_(J_n(beta)) cap Ball_(r_n),
```

and let `M_n` be the intersection of the normal cores of the finitely many `H_beta`. Then
`T_n = F(P_n)/M_n` is finite, and for every `beta` and every `u in Ball_(r_n)`,

```text
u notin A_(J_n(beta))   implies   u notin A_(J_n(beta)) M_n.            (H1)
```

Put `Omega_n = A_n x T_n` with uniform measure. A letter `p in P_n` acts on `T_n` by left
multiplication by its image. Define

```text
Phi_n(k)(a, t) = (b_n(k) a, t),          Phi_n(v)(a, t) = (a, zeta_n(a) t).
```

**Phi is a homomorphism `Gamma -> prod_U Sym(Omega_n)`.** The relations of `K` hold in the
ultraproduct because `b` is a homomorphism and `Phi_n(k) = b_n(k) x id`. For `l in L`,

```text
Phi_n(l) Phi_n(v) Phi_n(l)^-1 (a, t) = (a, zeta_n(b_n(l)^-1 a) t),
```

which equals `Phi_n(v)(a,t)` for a.e. `a`, by (HC2). So `[v, l]` holds in the ultraproduct.

**Lamps.** For `x = hL`, `Phi(z_x) = Phi(h) Phi(v) Phi(h)^-1` acts by
`(a, t) -> (a, zeta_x(a) t)` with `zeta_x(a) = zeta_n(b_n(h)^-1 a)`. By (HC2) this is independent
of the representative `h`, a.e. For a word `w in F(X)` we get

```text
Phi_n(w)(a, t) = (a, iota_a(w) t),                                         (L1)
```

where `iota_a : F(X) -> F(P_n)` is the substitution `z_x -> zeta_x(a)`, a homomorphism.

**Color.** Define `xi_n(a, t) = ( omega_n(a), A_(J_n(omega_n(a))) t )`. The second coordinate is
the right coset of the image of `A_J` in `T_n`, and it takes finitely many values.

## 2. Invariance on S

*`f in F`.* `xi_n(Phi_n(f)^-1(a,t)) = xi_n(b_n(f)^-1 a, t)`. By (HC1), `omega_n(b_n(f)^-1 a) = omega_n(a)`
a.e., so the color is unchanged a.e.

*`g = z_(x_0) z_(f x_0)^-1`, `f in F`.* By (L1), `Phi_n(g)^-1(a,t) = (a, zeta_n(b_n(f)^-1 a) zeta_n(a)^-1 t)`.
By (HC3) with `k = 1` and with `k = f` (both in `FL`), a.e. both letters `zeta_n(a)` and
`zeta_n(b_n(f)^-1 a)` lie in `J = J_n(omega_n(a))`. Hence their quotient lies in `A_J`, the coset
`A_J t` is unchanged, and `omega_n` is untouched.

By (I2) these elements generate `S`, so by (I1) the displacement coefficient is `0` on all of `S`.

## 3. Displacement off S

Let `g notin S` and write `g = w k` with `w in F(X)`, `k in K`.

*Case `k notin F`.* `Phi_n(g)^-1 (a,t)` has first coordinate `b_n(k)^-1 a`, and by (HC1)
`omega_n(b_n(k)^-1 a) != omega_n(a)` a.e. So the colors differ a.e.

*Case `k in F`.* Then `w = g k^-1 notin S`, so `w notin S cap F(X) = A_Y` by (I2). Here
`Phi_n(g)^-1(a,t) = (b_n(k)^-1 a, iota_a(w)^-1 t)`, and by (HC1) its color is
`(omega_n(a), A_J iota_a(w)^-1 t)` a.e., with `J = J_n(omega_n(a))`. This differs from `xi_n(a,t)`
for every `t` exactly when `iota_a(w) notin A_J M_n`.

Let `X_w = {x_1, ..., x_m}` be the letters occurring in `w`, with `x_i = h_i L`. For a.e. `a`,
the following hold.

- **Injective on letters.** For `i != j`, put `a' = b_n(h_i)^-1 a`. Then
  `zeta_(x_j)(a) = zeta_n(b_n(h_i^-1 h_j)^-1 a')`, and `h_i^-1 h_j notin L`. Since `b_n(h_i)` preserves
  measure, (HC2) gives `zeta_(x_i)(a) != zeta_(x_j)(a)` a.e.
- **Incidence is exact.** By (HC3) and (I2), `zeta_(x_i)(a) in J` if and only if `h_i in FL`, that is,
  if and only if `x_i in Y`.

So `iota_a` restricts to an isomorphism `F(X_w) -> F(iota_a X_w)`, and it carries `Y cap X_w` onto
`J cap iota_a X_w`. Suppose `iota_a(w) in A_J`. Then by the retraction lemma,

```text
iota_a(w) in A_J cap F(iota_a X_w) = A_(J cap iota_a X_w) = iota_a( A_(Y cap X_w) ),
```

so `w in A_(Y cap X_w) <= A_Y`, a contradiction. Hence `iota_a(w) notin A_J`. Its length is at most
`|w| <= r_n` for `n` large, so (H1) gives `iota_a(w) notin A_J M_n`.

In both cases the displacement coefficient is `1`. By (I1), `Gamma action Gamma/S` is sofic. QED.

## 4. Calibrations

**`F = 1`.** Then `Y = {x_0}` and `S = 1`. Given a sofic model `b` of `K action K ⊔ K/L` with exact
regular color `omega'` and `L`-color `zeta`, put `omega = (omega', zeta)` and
`R = {((o, c), c') : c = c'}`. Then (HC1) is exact freeness, and (HC3) reads
`zeta(b(k)^-1 a) = zeta(a)`, which holds a.e. if and only if `k in L = FL`. The theorem then gives
soficity of the regular action of `Gamma = Z wr^*_(K/L) K`, which is GKP Theorem 3.7
([[gkp-free-generalized-wreath-soficity]]) for the regular action. So the method reproduces the known case.

**`N = F cap L` of finite index in `F`.** Let `f_1, ..., f_r` represent `F/N`, so that `FL` is the
union of the cosets `f_i L`. Put `omega(a) = (omega_F(a), {zeta(b(f_i)^-1 a)}_i)`, with the finite set
encoded in `Nat`, and let `R` be membership.

- `F`-invariance of the set: `f f_i = f_(pi i) n` with `n in N <= L`, and (HC2) at the point
  `b(f_(pi i))^-1 a` gives `zeta(b(f f_i)^-1 a) = zeta(b(f_(pi i))^-1 a)` a.e.
- (HC2) at `b(f_i)^-1 a` gives `zeta(b(k)^-1 a) = zeta(b(f_i)^-1 a)` a.e. if and only if `k in f_i L`.

So (HC) follows from soficity of `K action K/F ⊔ K/L`.

**Compiler.** On `INF`, `F / N_e = H_e` is infinite, so neither calibration applies. See the
Attempts of [[compiler-positive-rope-is-not-sofic]] for where a natural (HC_e) candidate fails.

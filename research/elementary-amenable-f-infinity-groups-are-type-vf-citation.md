Citation import, secondary.

**Source.** S. Hughes and D. Kielak, "Coherence for elementary amenable
groups", arXiv:2302.03346v2 (Proc. Amer. Math. Soc. 152 (2024) 977–986). The
LaTeX source `ElementaryAmenable.tex` was read on 2026-09-16.

- **Definitions** (§1): "A group G is type F_n if G admits a model for a
  K(G,1) with finite n-skeleton, type F_∞ if G is type F_n for all n, and type
  F if G admits a finite model for a K(G,1). If G has a finite index subgroup
  of type F, then we say that G is type VF."
- **The statement used** (§1, just before their Corollary): "by
  [KrophollerMartinezPerezNucinkis2009, Theorem 1.1] an elementary amenable
  group of type F_∞ is type VF".
- **The bibliography entry** names P. H. Kropholler, C. Martínez-Pérez and
  B. E. A. Nucinkis, "Cohomological finiteness conditions for elementary
  amenable groups", J. Reine Angew. Math. 637 (2009), 49–62.

**Corroboration (referee, 2026-09-16).** The zbMATH review of the 2009 paper,
Zbl 1202.20055 by O. Talelli, was fetched through the zbMATH API on
2026-09-16. It states the main theorem as a list of equivalent conditions for
an elementary amenable group `G`. Among them are "(v) G is virtually of type
F" and "(viii) G is of type FP_∞". The review does not give the theorem a
number. A group of type `F_∞` is of type `FP_∞`, so (viii) ⇒ (v) is exactly
the statement imported here.

**Not read.** The 2009 paper itself was not read. An arXiv API query on
2026-09-16 for `au:Nucinkis AND ti:amenable` did not return it. Part of the
background has its own verified quote. Kropholler–Martínez-Pérez,
arXiv:1805.10052v2, in the subsection "Cohomological Dimension and
Constructible Groups", say that Kropholler's work "led to a proof that
elementary amenable groups of type FP_∞ over Z are constructible [K2] and to
the construction of classifying spaces for proper actions for such groups, see
[K,KMPN,KM]". There K2 is Kropholler, "On groups of type (FP)_∞", J. Pure
Appl. Algebra 90 (1993) 55–67.

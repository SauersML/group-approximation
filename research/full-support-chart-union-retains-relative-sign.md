**ESTABLISHED FULL-UNION FENCE.**  Retain the support-return notation

```text
E_i=W_i E W_i,            S=W_1W_2,
W_1=W_79(e_0,e_0),        W_2=W_79(e_000,e_000).       (FUS1)
```

Do not discard the cross-relations outside `E_1 intersect E_2`.  In the
exact elementary Leavitt group put

```text
G=<E_1,E_2>.
```

Faithful binary-prefix matrix closure gives

```text
|G|=1024,                 |Z(G)|=4.                    (FUS2)
```

Thus the full union is substantially stronger than the two-pair
intersection packet.  Its cross-commutator table, with rows and columns in
the order `(A_1,A_2,A_3,B_1,B_2,B_3)`, is

```text
0 0 0 d 0 0
0 0 0 0 c 0
0 0 0 0 0 c
d 0 0 0 0 0
0 c 0 0 0 0
0 0 c 0 0 0,                                      (FUS3)
```

where `0` denotes the identity, `c=[A_1,B_1]` is the original Pauli
central sign, and `d` is a second nontrivial central involution.  Hence the
missing pair is not freely glued: the two off-diagonal cross commutators
really are seen by the exact union.

Nevertheless the relative support word remains unauthenticated.  Exact
closure proves

```text
S G S=G,                     S notin G,
SgS != hgh^(-1) for every h in G and some g in G,       (FUS4)
```

so `S` induces an outer involution of `G`.  It fixes all four elements of
`Z(G)` pointwise, and

```text
H=<G,S>=G semidirect <S>,       |H|=2048.               (FUS5)
```

Consequently `H/G=C_2` has the exact sign character

```text
chi|_G=1,                  chi(S)=-1.                   (FUS6)
```

Tensoring any finite-dimensional realization of this packet by `chi`
leaves both complete chart groups, every cross commutator in `(FUS3)`, the
original marked central sign `c`, and the action of `S` by conjugation
unchanged, while replacing the implementing operator for `S` by its
negative.  More generally every word in the odd coset `SG` has the same
unfixed sign.

Therefore adding **all** exact relations among `E_1` and `E_2` does not
authenticate the relative chart gauge.  A successful third-pair return must
leave the finite packet `H`: it needs a new occurrence whose relation has
odd `H/G` parity, or a typed source/target row which detects that parity.
The old two-pair intersection fence was not hiding a missing cross
commutator inside the full union.

This does not refute a mixed occurrence outside `H`, and it does not refute
the Property-T-free non-MF program.  It exactly closes the proposed shortcut
of rigidifying `S` by retaining the full two-chart union.

No Property T, Kazhdan input, trace hypothesis, literature theorem, local
computation, or Lean compilation is used.

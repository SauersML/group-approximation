Use the proper-torus graph cover \(Z_H\to K_{p+1}\), and write
\[
 K=T_s/H\cong C_i.
\]
After choosing one trivialization of each vertex fiber, transport across a
base edge \(u v\) has the form
\[
 k_v=\gamma_{uv}-k_u,\qquad \gamma_{uv}\in K.           \tag{DHM1}
\]
Thus every edge transition is an affine reflection of \(K\). Along a path
of length \(\ell\), the linear part of the monodromy is
\[
 k\longmapsto(-1)^\ell k+\eta.                         \tag{DHM2}
\]
Because \(K_{p+1}\) contains triangles, the cover is a dihedral gain cover,
not a cyclic regular cover in the label coordinate.

In particular a uniform label translation by \(s\in K\) commutes with an
edge reflection only if
\[
 2s=0.                                                  \tag{DHM3}
\]
For odd \(i\), (DHM3) forces \(s=0\); for even \(i\), it permits at most
the unique half-turn. Hence there is no faithful cyclic deck action of
order \(i>2\) to Fourier-diagonalize.

There is a second, independent obstruction at the 2-cell level. Fix a
base cyclic triangle and orient its three edge fibers. The actual
arithmetic complex contains one correlated lifted row
\[
 L_\triangle(f_1,f_2,f_3)
 =f_1(\gamma_1)+f_2(\gamma_2)+f_3(\gamma_3),            \tag{DHM4}
\]
rather than the \(i\) translates \(L_{\triangle,s}\) which a simplicial
cover would contain. If \(i\) is odd and \(\mathbb E\) is a splitting
field for \(K\) over \(\mathbb F_2\), then
\[
 f_j(k)=\sum_{\chi\in\widehat K}
        \widehat f_j(\chi)\chi(k)
\]
turns (DHM4) into
\[
 L_\triangle
 =\sum_{\chi\in\widehat K}\!
   \left(
    \chi(\gamma_1)\widehat f_1(\chi)
   +\chi(\gamma_2)\widehat f_2(\chi)
   +\chi(\gamma_3)\widehat f_3(\chi)
   \right).                                             \tag{DHM5}
\]
Every character occurs in the same scalar row. The missing translated
rows are exactly what would be needed to Fourier transform the row index
and separate the characters. Semisimplicity of
\(\mathbb F_2[K]\) for odd \(i\) therefore does not block-diagonalize
\(\delta_1\).

If \(i=2^\nu m\) with \(m\) odd, then
\[
 \mathbb F_2[K]\cong
 \mathbb F_2[z]/\bigl((z^m-1)^{2^\nu}\bigr),            \tag{DHM6}
\]
whose radical is generated by \(z^m-1\) and has nilpotence length
\(2^\nu\). Inversion preserves this filtration, but the single evaluation
row (DHM4) is not a module map for label translation and hence does not
split into its graded pieces. The even-index filtration is a coordinate
ledger, not an invariant block decomposition of the cubic curl.

The legitimate Fourier symmetry is global right translation by the full
torus on all coset coordinates; it moves the base triangle as well as its
label and leads to the automorphic Hecke blocks already identified in the
right-torus analysis. A proof of binary coboundary soundness must control
the resulting character-coupled matrix. No uniform decoder or
counterexample follows from fiberwise Fourier semisimplicity alone, and
the root remains open.

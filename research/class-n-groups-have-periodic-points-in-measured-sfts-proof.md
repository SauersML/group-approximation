Let `μ` be invariant on `Y`, and `X = supp μ`, a nonempty closed invariant set on which `μ` has full support. Let
`Y` be defined by a finite forbidden set of patterns on the window `W_0`. Theorem N (b) at `W = W_0` gives a
finite invariant `O ⊆ X_(W_0)`, nonempty because `L_(W_0)(X) ≠ ∅`. Every `c ∈ X_(W_0)` has all `W_0`-windows in
`L_(W_0)(X)`, which are allowed in `Y`, so `c ∈ Y`, and `c` has finite orbit. Artifact part 1, Corollary N1.

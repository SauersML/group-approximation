**ESTABLISHED** (lane proof, elementary, not reviewed). No novelty claimed: dense free
subgroups of Polish permutation groups are classical (Dixon for `Sym(N)`), and the
Baire argument below is routine; the mixing shift is the device that makes density
generic here.

Let `C` be the Cantor space, realized as `{0,1}^Z`, and let `σ` be the two-sided shift,
`σ(x)_i = x_{i+1}`. Give `Homeo(C)` the compact-open topology; its basic open sets are
`O(R,R') = {t : t(R_j) = R'_j for all j}` for ordered clopen partitions
`R = (R_1..R_m)`, `R' = (R'_1..R'_m)` of `C` into nonempty sets. Let `Ω` be the set of
proper nonempty clopen subsets of `C`.

## Statement

For a comeager set of `t ∈ Homeo(C)`:
1. `⟨σ, t⟩` is free of rank 2 on `σ, t`;
2. `⟨σ, t⟩` is dense in `Homeo(C)`.

For every such `t`, the group `Γ = ⟨σ,t⟩ ≅ F_2` is finitely presented and dense, and
for every `U ∈ Ω` the stabilizer `Γ_U` is **not finitely generated**. So finite
presentation plus density in `Homeo(C)` does not give finitely generated clopen
stabilizers, and does not give an action of type (A) on clopens.

## Proof of 2 (density is comeager)

`Γ ≤ Homeo(C)` is dense iff for every `k` it is transitive on ordered `k`-partitions of
`C` into nonempty clopens (such partitions determine the basic open sets). For ordered
`k`-partitions `P`, `Q`, the set `E(P,Q) = {t : w(σ,t)P = Q for some word w}` is open.
It is also dense.
- **Mixing.** `σ` is topologically mixing: for nonempty clopens `U, W` there is `N_0`
  with `σ^N(U) ∩ W ≠ ∅` for all `N >= N_0`. (Cylinders fixing coordinates in `[-n,n]`
  meet after any shift by more than `2n`, and every nonempty clopen contains a
  cylinder.)
- **Hitting any basic open set.** Given `O(R,R')`, choose `N`, `M` so large that
  `R_j ∩ σ^N(P_i) ≠ ∅` and `R'_j ∩ σ^M(Q_i) ≠ ∅` for all `i, j`. Define `t` to map each
  nonempty clopen `R_j ∩ σ^N(P_i)` homeomorphically onto `R'_j ∩ σ^M(Q_i)`; nonempty
  clopen subsets of `C` are Cantor spaces, so this is possible.
- **Check.** Then `t(R_j) = R'_j`, so `t ∈ O(R,R')`, and `t σ^N(P_i) = σ^M(Q_i)`. So
  `w = x^{-M} y x^{N}` gives `w(σ,t)P = Q`, and `t ∈ E(P,Q)`.

There are countably many pairs `(P,Q)`, so `∩ E(P,Q)` is comeager, and every `t` in it
makes `⟨σ,t⟩` dense.

## Proof of 1 (freeness is comeager)

For a nontrivial reduced word `w(x,y)`, the set `{t : w(σ,t) ≠ 1}` is open. It is dense.
If `w = x^k` then `w(σ,t) = σ^k ≠ 1`, since `σ` has non-periodic points. Otherwise fix
`O(R,R')` and build a finite injective partial map `τ` that sends points of `R_j` into
`R'_j`, reading `w` from right to left from a starting point `p`.
- A power `x^k` applies `σ^k`, which is total.
- A letter `y^{±1}` at the current point `z` requires `z ∉ dom(τ^{±1})`, and then a
  fresh image (or preimage) is chosen in the required atom `R'_j` (or `R_j`).
- Each fresh point is chosen to avoid finitely many bad points: the points used so far,
  the preimages of used points under the `σ`-power that follows, periodic points of
  that power (a countable set), and, for the last choice, the points sent to `p`. Every
  atom is a Cantor set, hence uncountable, so these choices exist.
- Then the reading visits pairwise distinct points and every `y`-step is defined.
  Because `w` is reduced, `τ` stays injective, and the last point differs from `p`.
- A finite injective partial map respecting the atoms extends to some `t ∈ O(R,R')`,
  atom by atom. This `t` has `w(σ,t)(p) ≠ p`.

Intersecting over the countably many `w` gives a comeager set on which `⟨σ,t⟩` is free
on `σ, t`.

## Proof that clopen stabilizers are infinitely generated

Fix `t` in both comeager sets and `U ∈ Ω`.
- **Finitely many orbits on pairs.** `Homeo(C)` acts transitively on `Ω`, and its orbits
  on `Ω × Ω` are the finitely many Boolean types of pairs: which of `U∩W`, `U−W`,
  `W−U`, `C−(U∪W)` are empty. For `(U,W)`, `(U',W')` of the same type, the set
  `{g : gU = U', gW = W'}` is open and nonempty, so the dense `Γ` meets it. So `Γ` is
  transitive on `Ω` with finitely many orbits on `Ω × Ω`.
- **Conclusion.** `Ω` is infinite. By `free-groups-have-no-pair-finite-actions-with-fg-stabilizers`
  (item 2), `Γ_U` is not finitely generated. ∎

## Consequences

- The stabilizer clause in `permutational-boone-higman-iff-dense-cantor-actors` cannot
  be dropped. This restores the conclusion that
  `fp-dense-cantor-subgroups-need-not-have-fg-clopen-stabilizers` intended, with a
  correct witness in place of the refuted `V * Z`.
- The witness is not in the permutational class through its own clopen action: free
  groups have no type (A) actions on infinite sets at all. It is in `B_A` only through
  overgroups (for example `F_2 ≤ V`).
- Density does not force a locally moving subgroup. For a proper `U ∈ Ω`, density gives
  `g ∈ Γ` with `g(U) ∩ U = ∅` (some homeomorphism maps `U` into a proper clopen subset
  of `C − U`). If `a ≠ 1` and `b` in `Γ` are supported in `U`, then `z = g a g^{-1} ≠ 1`
  commutes with both, having disjoint support. Centralizers of nontrivial elements of a
  free group are cyclic, so `a` and `b` commute. Hence every rigid stabilizer `Γ_U`,
  `U` proper, is abelian (indeed cyclic), as the relation of
  `v-and-a-homeomorphism-never-generate-a-free-product` predicts for any group without
  such relations.

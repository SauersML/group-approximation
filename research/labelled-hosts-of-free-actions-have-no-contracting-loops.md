**ESTABLISHED** (elementary lane proof, bh-invent-06b, 2026-09-18; not reviewed; no priority claimed).
It generalizes items (3), (4a) and (4b) of `free-sft-hosts-admit-no-finite-type-coding`. Contracting loops and
finite codings are as defined there.

## Setting

- `𝒢` is an ample groupoid on a compact space `Z`, and `Λ` a discrete group acting on a compact space `X`
  without isolated points.
- A **Λ-label** on `𝒢` is a continuous groupoid homomorphism `ℓ : 𝒢 → Λ` together with a continuous
  surjection `π : Z → X` such that `π(r(γ)) = ℓ(γ)·π(s(γ))` for every arrow `γ`.
- `π` is **semi-open** if `π(O)` has nonempty interior for every nonempty open `O ⊆ Z`. Open maps (coordinate
  projections) qualify, and so does every factor map onto `X` from a minimal `Λ`-system.

Examples of labelled groupoids (label = the `Λ`-coordinate, `π` = projection to `X`):
- the master-route host `G_V × (Λ ⋉ X)` and all of its subgroupoids;
- any product `ℋ × (Λ ⋉ X)`;
- skew products and fibre extensions `Λ ⋉_c (X × K)`;
- groupoids generated by `Λ ⋉ X` together with germs that preserve the `X`-coordinate. These include `LC(X, V)`,
  the site-conditioned moves `e_a`, Boolean powers, and V-stabilizations.

## Statement

Let `b` be a contracting loop of `𝒢` with source `U` and limit point `p`. Put `x = π(p)` and
`λ = ℓ([b, p])`.
1. **Shadowing.** There are `n_0` and a set `E ⊆ X` with nonempty interior such that
   `π(b^(n_0+m) U) = λ^m E` for every `m ≥ 0`. These sets decrease to `{x}`. So `λ ≠ 1`, `λx = x`, and `x` is an
   attracting fixed point of `λ`.
2. **Corollaries.** `𝒢` has no contracting loop, and hence no finite coding and no finite-type engine of the kinds
   listed in `free-sft-hosts-admit-no-finite-type-coding`, whenever `π` is semi-open and any one of the following
   holds:
   - (a) `Λ` acts freely on `X`;
   - (b) `X` is infinite and minimal, and carries a `Λ`-invariant probability measure. This holds for every
     amenable `Λ`;
   - (c) `Λ ↷ X` is distal, for instance equicontinuous.
3. **Non-centrality.** If `X` is minimal and infinite, the shadowing element `λ` is not central in `Λ`.

## Proof

**Item 1.**
- By item (1) of `free-sft-hosts-admit-no-finite-type-coding`, `b(p) = p`, so `γ := [b, p]` is an isotropy arrow.
  Hence `λx = π(r γ) = π(s γ)`.
- `ℓ` is continuous into a discrete group, so it is locally constant. Choose an open bisection `b' ⊆ b` through `γ`
  with `ℓ ≡ λ` on `b'`, and put `N = s(b')`. Then `π(b(z)) = λπ(z)` for `z ∈ N`.
- `b(U) ⊆ U` gives `b^(n+1)(U) ⊆ b^n(U)`. These compact sets decrease to `{p}`, so `b^n(U) ⊆ N` for all
  `n ≥ n_0`.
- Hence `π(b^(n_0+m+1) U) = λ π(b^(n_0+m) U)`, and so `π(b^(n_0+m) U) = λ^m E` with `E := π(b^(n_0) U)`.
- `b^(n_0)(U)` is a nonempty open set, as `𝒢` is étale. So `E` has nonempty interior when `π` is semi-open.
- For decreasing compact sets, `π(⋂ K_n) = ⋂ π(K_n)`. So `⋂_m λ^m E = {x}`, and then
  `λx ∈ ⋂_m λ^(m+1) E = {x}`.
- If `λ = 1`, then `E = {x}` has nonempty interior, so `x` is isolated. That is a contradiction. ∎

**Item 2.**
- (a) `λ ≠ 1` fixes `x`, which contradicts freeness.
- (b) Minimality gives the invariant measure `μ` full support, so `μ(E) > 0`. The sets `λ^m E` decrease to `{x}`
  and all have measure `μ(E)`. So `μ{x} = μ(E) > 0`. An atom of an invariant measure on an infinite minimal
  system has an infinite orbit of atoms of equal mass, which is impossible.
- (c) `E` contains a point `y ≠ x`, since it has nonempty interior and `X` has no isolated points. Then
  `λ^m y ∈ λ^m E → {x}` and `λ^m x = x`, so `(y, x)` is a proximal pair. That contradicts distality.
- In each case there is no contracting loop. Item (2) of `free-sft-hosts-admit-no-finite-type-coding` then
  excludes finite codings, together with every groupoid Kakutani equivalent to `𝒢`.

**Item 3.** This is the argument of (4b) there.
- Suppose `λ` is central.
- The orbit of `x` is dense, so some `gx ≠ x` lies in the interior of `E`.
- Then `gx = λ^m(gx) ∈ λ^m E` for every `m`, so `gx = x`. That is a contradiction. ∎

## Consequences

**Every passive enlargement of the master-route host fails.** In Track A, finite type can never be obtained
by any of the following, whatever the rigidity or finite type of `X`:
- adjoining to `G_V × (Λ ⋉ X)` germs that respect the `X`-coordinate up to a `Λ`-label;
- taking fibre extensions or skew products over a free, amenable-measured or distal base;
- multiplying by any other groupoid.

The groupoid needs compressing germs **without** a `Λ`-label. The only other way out is compression by `Λ`
itself, which requires attracting fixed points and so non-free actions. That second way is gate E3′
(`v-times-rigid-topologically-free-sft-full-groups-are-fp`).

**Amenable directions.** By 2(b), a labelled host over a minimal infinite `X` with an invariant measure is never
finitely coded, free or not. So in the amenable directions (`Z^d` factors, fibres with an invariant measure)
compression must be unlabelled.

**Unlabelled germs do suffice.** `substitution-inflation-hosts-are-full-contracting-rsgs` adjoins the inflation
germs of a substitution to a free `Z^d`-action and obtains a full contracting RSG, with its contracting loops at
the fixed tilings of the inflation.

## Lesson for general BH

A finite-type finiteness theorem needs contracting loops, and a contracting loop in a labelled groupoid is always
the shadow of a group element with an attracting fixed point. This gives a sharp dichotomy for every
Boone–Higman host built over a `Λ`-space `X`:
- **either** `Λ` itself compresses `X`, with isotropy and attracting fixed points (boundary codings, gate E3′);
- **or** the host contains germs that are not translations of `Λ` at all (inflations, self-simulation maps,
  telescopes).

Freeness, invariant measures and distality each exclude the first option. So over a free SFT the finite-type
route to P2′ exists only through unlabelled self-similarity, which is the host shape of Conjecture SS
(`self-similar-hosts-over-one-ended-parse-shifts`). Everything else is infinite-type, (A_N) in the notation of
`v-times-quantum-rigid-sft-full-groups-are-fp`.

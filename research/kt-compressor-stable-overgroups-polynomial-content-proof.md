Notation as in the claim. For `P ∈ SL_d(Z)` write `P·f` for the ring automorphism
`x^v ↦ x^(Pv)` of `R`. With this convention `(1,P) e_ij(f) (1,P)^(-1) = e_ij(P·f)`.
Then `P·A ⊆ A` iff `P(N^d) ⊆ N^d` iff `P ∈ M_d(N)`. So `Mon` is a semigroup of
compressors of `Γ`, and it contains `I + kE_ab` for all `a ≠ b` and `k ≥ 0`.

## 1. One content ring

Put `S_ij = {f : e_ij(f) ∈ Δ}` for `i ≠ j`. Each `S_ij` is an additive subgroup
containing `A`, because `Γ ≤ Δ`. For distinct `i,k,j` (possible since `r ≥ 3`),
`[e_ik(f), e_kj(g)] = e_ij(fg)` gives `S_ik·S_kj ⊆ S_ij`. Since `1 ∈ A ⊆ S_kj` and
`1 ∈ S_ik`, this yields `S_ik ⊆ S_ij` (change the second index) and `S_kj ⊆ S_ij`
(change the first index). The chain
`(1,2)→(1,3)→(2,3)→(2,1)→(3,1)→(3,2)→(1,2)`, together with its analogues through any
index, consists of such moves, so all `S_ij` coincide. Call the common value `S`. Then
`S·S ⊆ S`, `1 ∈ S` and `A ⊆ S`, so `S` is a subring. `N = EL_r(R)` is generated by the
`e_ij(R)`, so `N ≤ Δ` iff `S = R`. Finally, for `P ∈ Mon`,
`e_ij(P·f) = (1,P)e_ij(f)(1,P)^(-1) ∈ PΔP^(-1) ≤ Δ`, so `P·S ⊆ S`.

## 2. Lemma A

**Lemma A.** Let `S` be an `A`-submodule of `R` with `A ⊆ S`, `P·S ⊆ S` for all
`P ∈ Mon`, and `S ≠ A`. Then `x_j^(-1) ∈ S` for every `j`.

*Proof.* Take `f ∈ S \ A`. Subtract its polynomial part, which lies in `A ⊆ S`, so that
every monomial of `f` has some negative exponent. Choose `i` such that some monomial has
`v_i < 0`, and let `m = min v_i < 0` over the support. Multiply by the monomial `x^u`
with `u_i = −m−1` and, for `k ≠ i`, `u_k` at least the largest `−v_k` in the support.
Subtract the polynomial part again. The result is `h/x_i ∈ S` with
`h ∈ F_q[x_k : k ≠ i]` and `h ≠ 0`, because the monomials that had `v_i = m` survive.

Now fix `j ≠ i`. The two moves below preserve the shape `h/x_i` with `h` a nonzero
polynomial free of `x_i`.

* **R_j.** If `x_j | h`, apply `P = I + E_(ji)`, i.e. `v ↦ v + v_i e_j`. A monomial
  `x^w/x_i` with `w_i = 0` goes to `x^(w−e_j)/x_i`, so `h/x_i ↦ (h/x_j)/x_i`.
* **X_j.** Apply `P = I + E_(ij)`, i.e. `v ↦ v + v_j e_i`. A monomial `x^w/x_i` goes to
  `x^w x_i^(w_j − 1)`. That is a polynomial when `w_j ≥ 1` and is unchanged when
  `w_j = 0`. The unchanged monomials have `i`-exponent `−1`, so no cancellation occurs.
  Subtracting the polynomial part leaves `h|_(x_j=0) / x_i`.

Apply R_j until `x_j ∤ h`, which happens after finitely many steps, and then X_j. The
new `h` is nonzero and free of `x_j`. Later moves for other indices only divide by, or
set to zero, other variables, so they never reintroduce `x_j`. After all `j ≠ i`, `h` is
a nonzero constant and `x_i^(-1) ∈ S`. For `j ≠ i`, `I + E_(ji)` sends `x_i^(-1)` to
`x_i^(-1)x_j^(-1)`, and multiplying by `x_i ∈ A` gives `x_j^(-1) ∈ S`. ∎

**Content rigidity.** If `N ⊄ Δ` then `S ≠ R` by §1. If also `S ≠ A`, Lemma A puts every
`x_j^(-1)` in the subring `S ⊇ A`, so `S = R`, a contradiction. Hence `S = A`.

## 3. Projection dichotomy

`π: G → SL_d(Z)` is a homomorphism and `π((1,P)g(1,P)^(-1)) = Pπ(g)P^(-1)`, so
`Q = π(Δ)` is `Mon`-stable. Let `Q̄` be its Zariski closure in `SL_d(C)` and
`T = {g : gQ̄g^(-1) ⊆ Q̄}`. `T` is Zariski closed and closed under multiplication, and it
contains `Mon`. It therefore contains the Zariski closure `U_ab` of each
`{I + kE_ab : k ∈ N}`. A Zariski-closed subsemigroup of an algebraic group is a
subgroup, so `T` contains the group generated by the `U_ab`, which is `SL_d(C)`. So `Q̄`
is normal in the simple group `SL_d`: either finite central, so `Q ⊆ {±I}`, or all of
`SL_d`.

If `F ≤ SL_d(Z)` is finite and `Mon`-stable, conjugation is injective, so `PFP^(-1) = F`
and `P^(-1)FP = F` for `P ∈ Mon`. Hence `F` is normalized by the group generated by
`Mon`. That group contains all `I + E_ab`, so it is `SL_d(Z)`. A finite normal subgroup
has a finite-index centralizer. That centralizer is Zariski dense (Borel density for the
lattice `SL_d(Z)`), so `F` is central. ∎

## 4. The two instances

`Δ_hl`: `theorem-c-separation-iff-infranormal-coset-wreath` Part 1 (with `G` residually
finite, hence hyperlinear) gives `pΔ_hl p^(-1) ≤ Δ_hl` for all `p ∈ P_Γ ⊇ Mon`.

`Δ' = ∩_(P∈Mon) P^(-1)ΔP`: `PΓP^(-1) ≤ Γ ≤ Δ` gives `Γ ≤ P^(-1)ΔP`. For `Q ∈ Mon` and
`P' ∈ Mon`, put `P = P'Q ∈ Mon`. Then `Q(P^(-1)ΔP)Q^(-1) = P'^(-1)ΔP'`, so
`QΔ'Q^(-1) ≤ ∩_(P') P'^(-1)ΔP' = Δ'`. Hence `Δ'` is `Mon`-stable. ∎

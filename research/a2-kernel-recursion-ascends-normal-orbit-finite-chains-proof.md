Notation is as in the target. From `a2-kernel-removal-forces-recursive-kernel` (a)
we use two facts:
- (a1) for every `i`, membership of a word in `Stab_G(x_i)` is decidable;
- (a2) `K` is co-r.e.

Equality of words in `G` is r.e., because `G` is finitely presented.

**Test for fixed points.** For a word `w` and an encoded point `y = c.x_i`,
`w.y = y` iff `c^-1 w c in Stab_G(x_i)`. By (a1) this is decidable.

**Lemma (commutation test).** Let `M = <A> <= G`, and let `Y` be a finite set of
points with `M.Y = S`. For `g in G`:

```text
g in K   iff   [g, a] in K for every a in A, and g.y = y for every y in Y.
```

*Proof.* The forward direction holds because `K` is normal and acts trivially.

Conversely, `[g, a] in K` says that `g a g^-1` and `a` induce the same permutation of
`S`. So the permutation `ḡ` induced by `g` commutes with `ā` for each `a in A`, and
hence with the permutation `m̄` of every `m in M`. Let `s in S`. Write `s = m.y`
with `m in M` and `y in Y`. Then

```text
g.s = ḡ m̄ (y) = m̄ ḡ (y) = m̄ (y) = s.
```

So `g in K`. ∎

## (1)

Given a word `w`, the lemma gives:

```text
w in W ∩ K   iff   w in W and there is (A, Y) in C such that
                   [w, a] in K_0 for all a in A, and w.y = y for all y in Y.
```

For `⇒`, use the hypothesis of (1) and the fact that `w` fixes every point.

For `⇐`, note `K_0 ⊆ K`, `<A>.Y = S`, and apply the lemma.

The right-hand side is semi-decidable. Dovetail these enumerations:
- the r.e. set `W`;
- the r.e. set `C`;
- for each `a in A`, the r.e. set of words representing `K_0`, applied to the word
  `w a w^-1 a^-1`.

On each candidate, run the decidable fixed-point test on `Y`. ∎

## (2)

**Only if.** `N_0` is generated by finitely many words `u_1, ..., u_r`. A word `w`
represents an element of `N_0` iff it equals in `G` some product of the `u_j^±1`,
which is r.e. So if `K` is recursive, `N_0 ∩ K` is r.e.

**If.** We show by induction on `i` that `N_i ∩ K` is r.e. The case `i = 0` is the
hypothesis.

Assume `N_i ∩ K` is r.e. with `i < k`, and apply (1):
- `W` is the set of words representing elements of `N_(i+1)`, which is r.e. as above;
- `K_0 = N_i ∩ K`;
- `C = {(A_i, Y_i)}`, where `A_i` is a finite generating set of `N_i` and `Y_i` is a
  finite set of `N_i`-orbit representatives.

`N_i` contains `N_0`, so it is orbit-finite, and `Y_i` exists. This is fixed finite
data. Recursion is a non-uniform property, so no algorithm has to find it.

*Hypothesis of (1).* Let `w in N_(i+1) ∩ K` and `a in A_i`. Then
`[w, a] = (w a w^-1) a^-1` lies in `N_i`, because `N_i ⊴ N_(i+1)`. It lies in `K`,
because `K ⊴ G`. So `[w, a] in K_0`, and (1) gives that `N_(i+1) ∩ K` is r.e.

At `i = k` we get that `K` is r.e. By (a2) it is co-r.e., so `K` is recursive.

*The two special cases.*
- If `N_0 ∩ K = 1`, its word set is the set of words trivial in `G`. That set is
  r.e.
- If `N_0 ⊴ G` and the kernel of `N_0 ↷ S` is recursive as a set of `N_0`-words `v`,
  then `N_0 ∩ K` is exactly that kernel. A word `w` represents an element of it iff
  `w = v` in `G` for some such `v`, which is r.e. Take `k = 1`. ∎

## (3)

Let `A_j` generate `M_j`, and let `Y_j` be a finite set of `M_j`-orbit
representatives. Apply (1) with:
- `W` all words;
- `K_0 = {1}`, whose word set is r.e.;
- `C = {(h A_j h^-1, h.Y_j) : h a word, 1 <= j <= q}`.

`C` is r.e.: the point `h.(c.x_i)` is encoded by the word `hc` and the index `i`.

Each pair is valid, because `(h M_j h^-1).(h.Y_j) = h.(M_j.Y_j) = S`.

For `k in K`, choose `h` and `j` with `k` commuting with `h M_j h^-1`. Then
`[k, h a h^-1] = 1` for every `a in A_j`. So `K` is r.e. By (a2) it is recursive. ∎

## (4)

Use `normalizer-extension-of-type-a-actor-is-a2-cover`, parts 1 and 2:
- `G~ = Γ x|_θ F_m ↷ Ω` is of type `[A_2]`;
- its kernel is `K = {(φ(w)^-1, w) : φ(w) in Γ}`;
- its image is `ΓQ`.

Check the hypotheses of (2) with `k = 1` and `N_0 = Γ = {(γ, 1)} ⊴ G~`:
- `Γ` is finitely presented, hence finitely generated;
- `Γ` has finitely many orbits on `Ω x Ω`, and so on `Ω` (restrict to the diagonal),
  so it is orbit-finite;
- an element `(φ(w)^-1, w)` of `K` lies in `Γ` only if `w = 1`, and then it is
  trivial.

So `Γ ∩ K = 1`, and (2) gives that `K` is recursive.

The word problem of `ΓQ`, on the images of the generators of `Γ` and the `q_i`, is
membership in `K` for words in those letters. So it is solvable. Solvability of the
word problem does not depend on the finite generating set. ∎

## (5)

The first bullet is the contrapositive of the "if" part of (2).

For the second bullet, suppose `N_0 ⊴ G` is finitely generated, orbit-finite, and
`N_0 ∩ K = 1`. Then (2) with `k = 1` makes `K` recursive.

The third bullet is the contrapositive of (3). ∎

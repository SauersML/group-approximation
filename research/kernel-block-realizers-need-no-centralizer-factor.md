**ESTABLISHED.** Let `1 -> N -> G -> Q -> 1` be exact with `G` countable and `N`
Kazhdan with finite symmetric generating set `S`. Assume:

- `H_1(Q; Z) = H_2(Q; Z) = 0`;
- every homomorphism `Q -> S_U` is trivial.

Let `sigma : G -> S_U` come from a sofic approximation `sigma_n`, with blocks
`B`, edited generators `s_B`, block groups `Pi_B = <s_B : s in S>` and block
centralizers `C_B = C_(Sym B)(Pi_B)`, as in
`inner-realizers-are-at-least-half-the-sofic-radius`. Let `Pi` and `C` be the
images in `S_U` of the blockwise products `prod_B Pi_B` and `prod_B C_B`.

1. **Commuting products.** `[Pi, C] = 1` and `sigma(N) <= Pi`. So `Pi C` is a
   subgroup of `S_U` and `Pi` is normal in it.
2. **Realized approximations.** Call `sigma` *realized* if `sigma(G) <= Pi C`.
   Concretely: for every `g`, along `U`, `sigma_n(g)` agrees off `o(|X_n|)`
   points with a block-preserving permutation that is `w_B(s_B) c_B` on each
   block, where the words `w_B` may have any length and `c_B in C_B`.
3. **No centralizer factor.** If `sigma` is realized, then `sigma(G) <= Pi`.
   Every element agrees off `o(|X_n|)` points with a permutation that acts on
   each block by a word in the edited kernel generators.

Expansion of the blocks is not used, only that they are `s~`-invariant. The
same conclusion holds on a union of blocks whose mass is bounded below and on
which every generator of `G` is realized.

**Instance.** For the Leavitt cover
`hyperbolic-kazhdan-cover-of-leavitt-unit-group`, `Q = L_(F_2)(1,2)^x` is
integrally acyclic (`binary-leavitt-unit-group-integrally-acyclic`) and has only
trivial sofic morphisms (`leavitt-unit-group-has-only-trivial-sofic-morphisms`).
So in any realized sofic approximation of the cover, all of `G` acts through the
ultraproduct of the kernel's block groups.

Derivation: `kernel-block-realizer-centralizer-proof`.

**Scope.**
- This proves nothing about soficity. It says the unbounded-realizer regime left
  open by `bounded-blockwise-inner-realizers-fail-off-kernel` is the condition
  `sigma(G) <= Pi`, which concerns only the groups generated by the kernel's
  edited generators.
- Where `Pi_B` contains `Alt(B)`, every permutation of `B` agrees with an element
  of `Pi_B` off at most two points (compose with one transposition if needed).
  There realizers exist for every block-preserving element and carry no
  information. `kernel-block-realizers-exist-after-small-re-edit` shows every
  sofic approximation can be re-edited into that form, so the realized regime is
  no restriction at all.

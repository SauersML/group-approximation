**ESTABLISHED** by `mz-antitwisted-germ-fiber-product-proof`.

Let `P` be an infinite finitely generated group and `nu : P -> N` a bijection.
Write `E = E_nu(P) = < rho(P), E_2 > <= Sym(N)`, where `rho(g)(2 nu(h)) = 2 nu(gh)`,
`rho(g)` fixes every odd number, and `E_2` is the group of permutations `pi` with
`pi(x+2) = pi(x)+2` for all sufficiently large `x`. Let

    R = R_nu = < lambda(P), s >,     eta : R -> Z the near index,

be the near shift group of `shell-germ-group-has-index-two-fiber-product`, where
near permutations are taken modulo finitary ones, `lambda_g(nu(h)) = nu(gh)`, and
`s(n) = n+1`, so `eta(s) = 1`. Put `K = ker eta`. Then:

1. `FSym(N)` is the normal closure in `E` of the single transposition `(0 1)`.
   So if `E` is finitely presented, then `Q := E / FSym(N)` is finitely presented.
2. The near-parity map `E -> Z/2` is a well-defined surjective homomorphism.
   Its kernel `E^0` satisfies `E^0 / FSym(N) ≅ F^-`, where

       F^- = { (a,b) in R x R : eta(a) + eta(b) = 0 }.

   The factors are the germs on the evens and on the odds, via `2k <-> k` and
   `2k+1 <-> k`. So `Q` contains `F^-` with index 2, and `Q` is finitely
   presented if and only if `F^-` is.
3. `K` is the normal closure of `lambda(P)` in `R`. The images of `rho(g)`, of
   `omega rho(g) omega` with `omega = (0 1)(2 3)(4 5)...`, and of the `E_2`-element
   `(s, s^-1)` are `(lambda_g, 1)`, `(1, lambda_g)` and `(s, s^-1)`, and they generate `F^-`.
4. `a -> (a, s^-eta(a))` is a homomorphism `R -> F^-` with left inverse the first
   projection. So `R` is a retract of `F^-`, and if `F^-` is finitely presented
   then so is `R`.

Hence `E_nu(P)` finitely presented `==>` `F^-` finitely presented `==>` `R_nu`
finitely presented.

No converse to the first implication is asserted: `E_2` itself contains
`FSym(N) ⋊ <(s,s^-1)>` with index 2, and that subgroup is isomorphic to the Houghton group `H_2`.

Lane proof (swarm-0917-w9-w9-titz-last1, 2026-09-18), not independently reviewed. Notation as in the target. Since `X` is infinite and minimal, `T` has no periodic points. So for `(x,y)` in one orbit there is a unique `n` with `y = T^(-n)x`.

**Product formula.** For `a, b ∈ S`,

    (ab)_n(x) = Σ_m a_m(x) · b_(n-m)(T^(-m)x),

because `a_m u^m b_(n-m) u^(n-m) = a_m (b_(n-m)∘T^(-m)) u^n`.

## Theorem A

**A1 (supports stay in E_R).** Put `P(a) = {(x, T^(-n)x) : a_n(x) ≠ 0}`. Then:
- `P(a+b) ⊆ P(a) ∪ P(b)`;
- `P(1)` is the diagonal;
- `P(ab) ⊆ P(a)∘P(b)`: by the product formula, a nonzero `(ab)_n(x)` needs some `m` with `(x, T^(-m)x) ∈ P(a)` and `(T^(-m)x, T^(-n)x) ∈ P(b)`.

`E_R` is an equivalence relation containing `P(g)` for every `g ∈ Σ`. So `P(a) ⊆ E_R` for every `a` in the ring `R` generated by `Σ`. Hence `E_R` is the relation generated by `∪_(a∈R) P(a)`, and it does not depend on `Σ`.

**A2 (pattern of a point).** Assume `E_R` is bounded by `N`, and let `N_0` bound the degrees of the elements of `Σ`. For `x ∈ X` put:
- `J_x = {j : (x, T^(-j)x) ∈ E_R} ⊆ [-N, N]`, which contains `0`;
- `Π(x) = ( J_x, (g_n(T^(-j)x))_(g ∈ Σ, |n| ≤ N_0, j ∈ J_x) )`.

Since `Σ` is finite and each `g_n` takes finitely many values, `Π` takes finitely many values. Call this set of values `V`.

If `m ∈ J_x`, then `J_(T^(-m)x) = J_x - m`, because the `E_R`-class of `T^(-m)x` equals that of `x`. Hence `Π(T^(-m)x) = θ_m(Π(x))` for a re-indexing map `θ_m`, defined on the patterns `p ∈ V` with `m ∈ J(p)`.

**A3 (induction).** Claim: for every `a ∈ R` there is `Φ_a : V x [-N,N] → F` such that
- `a_n(x) = Φ_a(Π(x), n)` for all `x` and all `|n| ≤ N`;
- `a_n = 0` for `|n| > N`.

The second item holds by A1 and the bound. For the first:
- For `g ∈ Σ`, `g_n(x)` is the `j = 0` entry of `Π(x)`.
- The claim holds for `1`, and it is closed under sums and negatives.
- For products, the terms of the product formula with `a_m(x) ≠ 0` have `m ∈ J_x`, so

      (ab)_n(x) = Σ_(m ∈ J_x) Φ_a(Π(x), m) · Φ_b(θ_m(Π(x)), n - m).

  Here `J_x` is read off from `Π(x)`, and `b_(n-m) = 0` when `|n - m| > N`. So the right side is a function of `(Π(x), n)`.

The ring generated by `Σ` is spanned by `1` and products of generators and their negatives, so the claim holds on all of `R`.

**A4 (conclusion).** `a ↦ Φ_a` is injective on `R`, since `Π` is defined at every point. Hence

    |R| ≤ q^(|V|(2N+1)).

If `(σ, R, z)` were a (G2) witness with `R` finite, then `σ|_R : R → R` would be injective, hence onto. So `σ(R) = R`, `σ^(-1)(R) = R`, and `z` would commute with `σ^(-1)(R)`, a contradiction.

## Half-orbit index

Fix `x ∈ X`, and let `V = F^(Z)` have basis `δ_n`. Put `π(f)δ_n = f(T^n x)δ_n` and `π(u)δ_n = δ_(n+1)`.
- **It is a representation.** `π(u)π(f)π(u)^(-1)δ_n = f(T^(n-1)x)δ_n = π(f∘T^(-1))δ_n`.
- **Banded.** Each `π(a)` maps `δ_n` into `span{δ_(n+j) : |j| ≤ deg a}`.

Let `P` be the idempotent onto `V_+ = span{δ_n : n ≥ 0}` along the negative span, and put `Q = 1 - P`. For banded `A`, both `PAQ` and `QAP` have finite rank.

For `a ∈ S^x` put `A = Pπ(a)P|_(V_+)` and `B = Pπ(a^(-1))P|_(V_+)`. Then

    AB = 1 - Pπ(a)Qπ(a^(-1))P   and   BA = 1 - (finite rank).

So `A` is a Fredholm linear map, with finite-dimensional kernel and cokernel. Put `ind(a) = dim ker A - dim coker A`.

Two standard facts of algebraic Fredholm theory apply to linear maps of vector spaces: the index is additive under composition, and it is unchanged by finite-rank perturbation. Now

    Pπ(ab)P = Pπ(a)Pπ(b)P + Pπ(a)Qπ(b)P,

and the last term has finite rank. So `ind(ab) = ind(a) + ind(b)`, and `ind : S^x → Z` is a homomorphism. It follows that:
- `ind` vanishes on `[S^x, S^x]`, because `Z` is abelian;
- `ind(c) = 0` for `c ∈ LC(X,F)^x`, since `π(c)` is diagonal and invertible and commutes with `P`;
- `ind(u) = -1`, since `A` is the unilateral shift, which is injective with cokernel spanned by `δ_0`.

Over `F_2` this is the index of `binary-subshift-ring-k1-is-half-orbit-index`, but only the homomorphism property is used here.

## Theorem B

**B1 (commutant of a power).** `a u^k = u^k a` if and only if `a_n∘T^(-k) = a_n` for every `n`. This follows by comparing coefficients: `u^k a u^(-k) = Σ (a_n∘T^(-k)) u^n`.

Each `a_n` is locally constant, so its level sets are clopen and `T^k`-invariant. If `T^k` is minimal, a nonempty such set is all of `X`, so every `a_n` is constant. Hence

    C_S(u^k) = F[u^(±1)].

**B2 (units).** `F[u^(±1)]` is a Laurent polynomial ring over a field: `u` is transcendental over `F`, since the coefficients of distinct powers are independent. So it is a domain whose units are the monomials `c u^m` with `c ∈ F^x`.

Now `ind(c u^m) = -m`. So an index-zero unit commuting with `u^k` is a scalar `c ∈ F^x`, which is central in `S`.

**B3 (conclusion).** Let `(σ, R, z)` be a (G2) witness with `u^k ∈ R` and `T^k` minimal. Then `z ∈ C_S(u^k)`, and `ind(z) = 0` because `z ∈ [S^x,S^x]`. So `z` is central, and it commutes with `σ^(-1)(R)`, a contradiction.

If `X` is totally minimal, `T^k` is minimal for every `k ≠ 0`. For a Sturmian subshift the maximal equicontinuous factor is an irrational rotation, which has no nontrivial finite cyclic factor, so this applies.

## Theorem B'

Let `T^k` be non-minimal, and let `M` be a `T^k`-minimal set.
- `M ∪ TM ∪ ... ∪ T^(|k|-1)M` is closed, nonempty and `T`-invariant, so it is all of `X`.
- The sets `T^iM` are `T^k`-minimal, so two of them are either equal or disjoint.
- Let `Y_i = T^iM` for `0 ≤ i < d`, where `d` is the least period of `M` under `T`. Then `d | k`, and the `Y_i` partition `X` into finitely many closed, hence clopen, sets.
- `d ≥ 2`: a proper closed `T^k`-invariant set contains a `T^k`-minimal set, and every `T^k`-minimal set is one of the `Y_i`.
- Each `Y_i` is `T^k`-minimal, so the `Y_i` are the atoms of the algebra of `T^k`-invariant clopen sets.

By B1, `C_S(u^k)` consists of the `a` with every `a_n ∈ span{χ_(Y_i)}`.

The elements `e_ij = χ_(Y_i) u^(i-j) χ_(Y_j)`, for `0 ≤ i, j < d`, satisfy `e_ij = χ_(Y_i) u^(i-j)` and form a complete system of matrix units. The unit `t = Σ_i χ_(Y_i) u^d` is central in `C_S(u^k)`. Its powers are independent over the diagonal, so

    C_S(u^k) ≅ M_d(F[t^(±1)]).

Hence the root `z` of any witness with `u^k ∈ R` is an index-zero unit of this ring.

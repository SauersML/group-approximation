**ESTABLISHED** (lane proof, bh-algebra, elementary, not reviewed).

**Claim.** Let `ψ : A -> M_d(A)` be a unital recursion and `S ⊆ A` a simple unital subalgebra with
`ψ(s) = s I`. Suppose every nonzero `a ∈ A` has a descendant in `S \ 0`, and there is a unital
homomorphism `r : A -> S` restricting to the identity on `S` (a *retraction*). Then:
1. `ρ_j = M_(d^j)(r) ∘ ψ_j : A -> M_(d^j)(S)` separate the points of `A`;
2. every simple subalgebra `C ⊆ A` embeds in `M_(d^j)(S)` for some `j`.

**Proof.** (1) If `ψ_j(a)_(uu') = s ≠ 0` with `s ∈ S`, then `ρ_j(a)_(uu') = r(s) = s ≠ 0`. (2) Some `ρ_j`
is nonzero on `C`, and its kernel on `C` is a proper ideal, hence `0`. ∎

**When the retraction exists.** For a base `(S * K<G>)/J` with `J` inside the ideal generated by `G`,
killing `G` is a retraction. That covers every transducer over constants in which the relations never
mix constants with transducer letters. It includes the lossless monomial hosts (`S = K`, retraction =
augmentation).

**Lesson for general BH.** Boone--Higman (for groups, and for algebras through Bokut-type simple
envelopes) reduces to *simple* inputs. For those, placing the input in the *base* of a self-similar envelope whose base retracts
onto its constants is no better than using the constants themselves: the simple input must already lie in
`M_n(S)`. So recursions help simple inputs only in two ways. One is *mixing* relations, where transducer
letters and constants interact (the kernel `J` leaves the ideal generated by `G`). The other is placing
the input in the completion *outside* the base, as Leavitt letters do for UHF algebras. Inputs that are
residual limits over `S` can sit in the base. This
is the algebra form of the group fact that faithful self-similar hosts see only residually finite
inputs, and it tells general-BH constructions where their power must come from: non-retracting bases.

**ESTABLISHED (proposed; unreviewed).**  Derivation: `rips-segev-witness-pairs-carry-no-zero-divisors-proof`.

Let `G` be torsion-free, `k` a field, and `a, b in G` with `1, a, b, ab` distinct.  Let
`beta = b_1 + b_a a + b_b b + b_ab ab` have all four coefficients nonzero, and let `alpha != 0` in `k[G]`.

- **(T1) Rank one.**  Suppose `b_1 b_ab = b_a b_b`.  Then `beta = b_1 (1 + x a)(1 + y b)` with `x = b_a/b_1` and
  `y = b_b/b_1`, and `alpha beta != 0`.  Over `F_2` the condition always holds.  So **no element of `F_2[G]`
  supported on a translate of `{1,a,b,ab}` is a zero divisor, in any torsion-free group.**  More generally, over
  `F_2`, if a support has the form `S T` with all `|S||T|` products distinct and `|S|, |T| >= 2`, then the element
  factors as `(sum S)(sum T)`.  So a zero divisor of minimal support size never has such a support.
- **(T2) Clean square.**  Suppose `alpha beta = 0`, `h, ha in supp alpha`, and each of the two elements `ha` and
  `hab` has exactly two expressions as a product in `supp(alpha) * supp(beta)`: `ha = (ha)*1 = h*a` and
  `hab = (ha)*b = h*(ab)`.  Then `b_1 b_ab = b_a b_b`, which contradicts (T1).  So every zero-divisor pair with
  `supp beta = {1,a,b,ab}` has no clean square.
- **(T3) Rips--Segev witnesses.**  Let `Gamma` be a generalized Rips--Segev graph for
  `A = sqcup_i {c_i a^l : 0 <= l < C_i}` and `B = {1,a,b,ab}` (Steenbock, arXiv:1307.0981, Steps 1--4), with
  `K` lines.
  - Call an interior index `(i,l)`, `1 <= l <= C_i - 1`, *free* when `v_il` is not a Step 1 target and `w_il` is
    not a Step 2 target.
  - Assume hypothesis **(EE)**: two products of `A B` are equal in `G(Gamma)` only if their positions are glued
    in `Theta'`.

  If a free index exists, which is automatic when `sum_i (C_i - 1) > 4K`, then **for every field `k` there is no
  pair with `supp alpha = A`, `supp beta = B` and `alpha beta = 0`.**

**Class killed, with the failing step.**  The attempt is "promote the encoded non-unique-product witness `(A,B)`
to the supports of a zero-divisor pair".
- Over `F_2` it dies at the factorization `beta = (1+a)(1+b)`.  The factors are non-zero-divisors because
  `k[<a>] = k[Z]` is a domain.  This holds in every torsion-free group, with no small-cancellation input.
- Over any field it dies at a free index.  Steps 1--2 glue only the `4K` line endpoints, while the lines have
  `sum (C_i - 1)` interior indices.  Each free index is a clean square, which forces rank-one coefficients.

A zero divisor in `k[G(Gamma)]` would therefore need one of:
1. a support other than the encoded witness;
2. extra gluings that destroy every clean square, which takes at least `sum (C_i - 1) - 4K` coincidences beyond
   Steps 1--2;
3. a failure of (EE).

**On (EE).**
- (EE) follows from Steenbock's graphical injectivity theorem (Theorem "gi") applied to the graph `Gamma^+`
  built by Steps 1, 2 and 4 without Step 3, which keeps the degree-one `b`-edges.  It suffices that `Gamma^+` has
  a reduced labeling satisfying `Gr'_*(1/6)`.  Every product of `A B` ends a path from `*` in `Gamma^+`, and
  distinct vertices stay distinct.
- I have not checked this for Steenbock's explicit coefficient families.
- (EE) is refutable.  If the encoded pattern admits a full-support kernel vector with `b_1 b_ab = b_a b_b`, then
  by (T1) that pattern is never realized exactly in a torsion-free group.

**Generalization (reduction, not a kill).**  Take `d` free factors and `B = {1, a, b_1..b_{d-1}, ab_1..ab_{d-1}}`.
Clean squares force `beta = (1 + x a)(1 + sum_j y_j b_j)` over any field; over `F_2` this factorization always
holds.  So a zero divisor on that witness reduces to one supported on `{1, b_1, ..., b_{d-1}}`.

**Pattern solutions are genuine (no (EE) needed).**  Glued positions are equal in `G(Gamma)`, so each
coincidence class of `G(Gamma)` is a union of pattern classes.  A pattern kernel vector `alpha` therefore gives
`alpha beta = 0` in `k[G(Gamma)]` whenever the image of `alpha` in `k[G(Gamma)]` is nonzero, which holds when `A`
injects.  So a factorizable `beta` with a nonzero pattern kernel certifies, by (T1), that `G(Gamma)` has torsion,
kills `a` or `b`, or collapses `A`.  (EE) is needed only for the converse: that no zero divisor exists beyond the
pattern solutions.

**Computation** (`rs_witness_nullspace.py`; commands and outputs in `results.txt`).
- *Calibration.*  The finite abelian groups `Z/n x Z/m` (torsion) produce annihilated `beta` (20 over `F_2`, 76
  over `F_3`, 274 over `F_5`).
- *Pattern model.*  Random Steps 1--2 gluings with `K <= 3` and `C_i <= 7` (150 graphs per prime, seed 1), plus a
  300-graph `F_3` run with `C_i <= 9` (seed 2); every `beta` with nonzero coefficients over `F_2, F_3, F_5`:
  - Prediction (T2) had **0 violations** among the 136, 136, 136 and 278 graphs with a free index.  The
    full-support test was decided exactly in every case (`full_undetermined = 0`).
  - With no free index, non-factorizable `beta` **do** admit full-support pattern solutions: 12 `(graph, beta)`
    rows over `F_5` and 1 over `F_3` (seed-2 run).  The free-index hypothesis is sharp at pattern level.
  - For factorizable `beta`, 38 of 150 graphs over `F_2` have a nonzero pattern kernel (42 over `F_3`, 41 over
    `F_5`, 84 of 300 in the seed-2 run).  By the remark above, those random gluings never give a torsion-free
    `G(Gamma)` with `A` embedded and `b != 1`.  So they are not small-cancellation graphs, and the zero pattern kernel for
    factorizable `beta` is a necessary finite test for Steenbock's explicit families.

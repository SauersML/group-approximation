Lane proof, elementary, not independently reviewed. Mallery–Zaremsky (arXiv:2202.00822) statements were read in
the source TeX and are cited by label. Their `N` is `{1, 2, ...}`. Transport everything along `i -> i-1` to our
`N = {0, 1, ...}`; shift-similarity only uses the order of `N`, so this changes nothing.

## 1. Germ criterion

By Definition `def:shift_similar`, `psi_j(g) = s_(g(j))^-1 ∘ g|_(N \ {j}) ∘ s_j`, where `s_j` fixes `i < j` and
sends `i >= j` to `i+1`. So `psi_j(g)(i) = g(i+1) - 1` for all large `i`, and `psi_j(g)` has germ
`s̄^-1 ḡ s̄`. This agrees with the germ shifting map of the source lemma on `psi_infinity`, which is
`psi_infinity(g FSym) = psi_j(g) FSym`.

If `FSym(N) <= G`, then `G` is the full preimage of `Γ = G/FSym(N)`. So `psi_j(g) ∈ G` iff `s̄^-1 ḡ s̄ ∈ Γ`:
- `G` is shift-similar iff `s̄^-1 Γ s̄ ⊆ Γ`;
- `psi_infinity = Ad(s̄^-1)|_Γ`, and it is surjective (Definition `def:strong`) iff `s̄^-1 Γ s̄ = Γ`.

Conversely, every `Γ <= NSym(N)` of index zero has a full preimage in `Sym(N)`: each index-zero near permutation is
represented by a permutation. If `s̄` normalizes `Γ`, that preimage is strongly shift-similar. Every infinite
shift-similar group contains `FSym(N)` (Theorem `thrm:contain_symfin`), so this describes all of them.

## 2. The odometer group

- **The shift is the odometer.** On eventually-zero points, least significant digit first, `a` is `n -> n+1`. So
  the near class of `a` on `N` is `s̄` (`thompson-v-binary-shell-action-passes-both-germ-gates`, Setting).
- **(a) Strong shift-similarity.** `B` acts faithfully by near permutations of `N`, `chi` is its near index, and
  `chi(a) = 1` (`odometer-prefix-groups-have-fg-index-kernels`). So `K = ker chi` is normal in `B` and consists of
  index-zero near permutations, and `s̄ = ā ∈ B` normalizes it. By §1, `G_od` is strongly shift-similar, with
  `Germs(G_od) = K` and `psi_infinity = Ad(ā^-1)`.
- **(b) Finite generation.** `K = < V, t >` (`odometer-prefix-groups-have-fg-index-kernels`). The genuine
  permutations `rho(g)` (`g ∈ V`) have germs in `V <= K`, and `t~` is any permutation with germ `t̄`. So
  `< rho(V), t~ >` maps onto `K`.
  - `V` is 2-transitive on `N`. Given distinct `x, y` and distinct `x', y'`, take `m` beyond the last digit 1 of all
    four points. The length-`m` prefixes `u, w` of `x, y` are then distinct, and likewise `u', w'`.
  - A prefix replacement `u -> u'`, `w -> w'` sends `x -> x'` and `y -> y'`. It extends to an element of `V`: the
    two complements are nonempty clopen sets, which can be cut into equally many cones.
  - So all transpositions are `rho(V)`-conjugate to `(0 1)`, and `FSym(N) <= < rho(V), (0 1) >`. Since `G_od` is
    the full preimage of `K`, `G_od = < rho(V), t~, (0 1) >`.
- **(c) Subgroups.**
  - `rho(V) <= G_od`. Its nontrivial elements have infinite support (`N` is dense), so `rho(V) ∩ FSym(N) = 1`
    and `FSym(N) ⋊ rho(V) <= G_od`. `V` contains nonabelian free groups, so `G_od` is not amenable.
  - `E_2` is generated by slide, flip and `(1 2)` (Observation `obs:E2_fin_gen`). In our indexing these are:
    - flip `= (0 1)(2 3)...`, which is `n -> n xor 1`, that is `rho(σ)` for `σ ∈ V` exchanging the cones `0` and `1`;
    - slide: `n -> n+2` for even `n`, `n -> n-2` for odd `n >= 3`, and `1 -> 0`. For even `n = 0z` this is
      `0z -> 0a(z)`, and for odd `n = 1z` it is `1z -> 1a^-1(z)`. So its germ is the prefix table
      `0 -> 0` (label `a`), `1 -> 1` (label `a^-1`), with `chi = 0`, and it lies in `K`;
    - `(1 2)` is `(0 1)`, which lies in `FSym(N)`.

    So `E_2 <= G_od`.

## 3. `K = [B,B]`

`V` is simple and nonabelian (Cannon–Floyd–Parry, Theorem 6.9, as cited in Nucinkis–St. John-Green
arXiv:1412.7715), hence perfect. Also `B = < V, a >` (`thompson-v-binary-shell-action-passes-both-germ-gates`,
proof of item 2). So every homomorphism from `B` to an abelian group kills `V`, and `B^ab` is cyclic, generated by
the image of `a`. Since `chi(a) = 1`, `chi` induces `B^ab ≅ Z`, and `K = ker chi = [B,B]`.

## 4. Germ gates

- `Ĝ_od = < K, s̄ > = K ⋊ <ā> = B`.
- By `houghton-like-envelopes-have-fp-germs-iff-fp-near-shift-group` item 1, `H_n(G_od)/FSym([n] x N) ≅ Q_n(B)`.
- `B` is of type `F_infinity`: Belk–Hyde–Matucci Theorem 2.12, as imported in
  `odometer-prefix-groups-have-fg-index-kernels`. Item 2 of the germ node then makes `Q_n(B)` finitely presented
  for `n >= 3`.
- For `n = 1`, `H_1(G_od) = G_od` (`prop:H1_equal`), and its germ group is `K`. `FSym(N)` is the normal closure
  of `(0 1)` in `G_od`. So if `G_od` is finitely presented, so is `G_od/FSym(N) = K`. ∎

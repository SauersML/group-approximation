Notation as in the claim. `v(e)` is the `pi`-adic valuation, and all
congruences are entrywise in `M_n(O)`.

**Step 1 (layers).** Fix `j >= 1`.
- (L1) `Gamma_j` is a normal subgroup of `GL_n(O)`.
  - The inverse of `1 + pi^j X` is the convergent series
    `sum_i (-pi^j X)^i`, which lies in `Gamma_j`.
  - Conjugation by `h` in `GL_n(O)` sends `1 + pi^j X` to
    `1 + pi^j hXh^{-1}`.
- (L2) The map `phi_j : Gamma_j --> (M_n(k), +)` given by
  `1 + pi^j X |-> X mod pi` is a surjective homomorphism with kernel
  `Gamma_{j+1}`. Indeed
  `(1 + pi^j X)(1 + pi^j Y) = 1 + pi^j (X + Y + pi^j XY)`, and `j >= 1`.
- (L3) For `h` in `Gamma_1` and `u` in `Gamma_j`, `phi_j(h u h^{-1}) = phi_j(u)`.
  Here `h u h^{-1} = 1 + pi^j hXh^{-1}`, and `hXh^{-1} == X mod pi` because
  `h == h^{-1} == 1 mod pi`.
- (L4) The intersection of all `Gamma_j` is `{1}`. If `T_j` in `Gamma_1`
  satisfy `T_j^{-1} T_{j+1}` in `Gamma_j`, then `T_{j+1} - T_j` lies in
  `pi^j M_n(O)`. `O` is complete, so `T_j` converges to some `T == 1 mod pi`,
  hence `T` is in `Gamma_1`. Also `T_j^{-1} T - 1 = T_j^{-1}(T - T_j)`
  lies in `pi^j M_n(O)`, so `T_j^{-1} T` is in `Gamma_j`.

**Step 2 (substitution).** Let `T` and all `a_i` lie in `Gamma_1`, and let `u` be
in `Gamma_j`. Then `c = w(T ; a)^{-1} w(Tu ; a)` lies in `Gamma_j` and
`phi_j(c) = m phi_j(u)`.

*Proof.* Write `w = y_1 ... y_l` in letters. Let `z_i` be the value of `y_i` at
`(T ; a)`, and `z'_i` its value at `(Tu ; a)`. Then `z'_i = z_i v_i` with:
- `v_i = u` if `y_i = x`;
- `v_i = T u^{-1} T^{-1}` if `y_i = x^{-1}`, since `u^{-1} T^{-1} = T^{-1} (T u^{-1} T^{-1})`;
- `v_i = 1` otherwise.

Put `S_i = z_{i+1} ... z_l`, which is in `Gamma_1`. Induction on `i` from `l`
down to `1` gives
`z_i v_i ... z_l v_l = (z_i ... z_l) (S_i^{-1} v_i S_i) ... (S_l^{-1} v_l S_l)`.
So `c` is the product of the `S_i^{-1} v_i S_i`, each in `Gamma_j` by (L1).
By (L3) and (L2), `phi_j(S_i^{-1} v_i S_i) = eps_i phi_j(u)`, where `eps_i` is
`+1`, `-1` or `0` according to the letter. Since `phi_j` is a homomorphism,
`phi_j(c) = (sum_i eps_i) phi_j(u) = m phi_j(u)`.

**Step 3 (existence in Theorem A).** Put `T_1 = 1`; then `w(T_1 ; a)` is in
`Gamma_1`. Given `T_j` in `Gamma_1` with `w(T_j ; a)` in `Gamma_j`:
1. Since `p` does not divide `m`, `m` is a unit of `O` and nonzero in `k`.
2. By (L2), choose `u_j` in `Gamma_j` with
   `phi_j(u_j) = -m^{-1} phi_j(w(T_j ; a))`, and put `T_{j+1} = T_j u_j`.
3. By Step 2, `w(T_{j+1} ; a) = w(T_j ; a) c` with `phi_j(c) = -phi_j(w(T_j ; a))`.
   So `phi_j(w(T_{j+1} ; a)) = 0`, and `w(T_{j+1} ; a)` is in `Gamma_{j+1}`.

By (L4), `T_j` converges to `T` in `Gamma_1` with `u = T_j^{-1} T` in `Gamma_j`.
Step 2 gives `w(T ; a)` in `w(T_j ; a) Gamma_j = Gamma_j`. This holds for every
`j`, so `w(T ; a) = 1`.

**Step 4 (uniqueness in Theorem A).** Let `T != T'` be roots in `Gamma_1`. By
(L4) there is `j` with `u = T^{-1} T'` in `Gamma_j` but not in `Gamma_{j+1}`.
Step 2 with `c = 1` gives `m phi_j(u) = 0`, so `phi_j(u) = 0`. That puts `u` in
`Gamma_{j+1}`, a contradiction.

**Step 5 (Theorem B).**
- *The system.* Let `Sigma` be the polynomial system over `F` in the entries of
  `n x n` matrices `X, Y`:
  - `XY - 1 = 0`;
  - `W - 1 = 0`, where `W` is `w` with `x |-> X`, `x^{-1} |-> Y`,
    `a_i^{+-1} |->` the matrices `a_i^{+-1}`, whose entries lie in `F`.

  For any field `E` containing `F`, the solutions of `Sigma` over `E` are the
  pairs `(T, T^{-1})` with `T` a root in `GL_n(E)`. Let `I` be the ideal
  generated by `Sigma` in `F[X, Y]`.
- *(N1) Weak Nullstellensatz.* For `E` algebraically closed and an ideal `J` of
  `E[X, Y]`, `J` has a zero over `E` iff `1` is not in `J`.
- *(N2) Descent of membership.* For any field `E` containing `F`, if `1` is in
  `I E[X, Y]` then `1` is in `I`.
  - Take an `F`-basis `(e_lambda)` of `E` with `e_0 = 1`, so that
    `E[X, Y] = (+)_lambda F[X, Y] e_lambda`.
  - If `1 = sum_i c_i f_i` with `f_i` in `I`, expand `c_i = sum_lambda c_{i,lambda} e_lambda`
    with `c_{i,lambda}` in `F[X, Y]`.
  - Comparing `e_0`-components gives `1 = sum_i c_{i,0} f_i`, which is in `I`.
- *The root over `K`.*
  1. By Theorem A there is `T'` in `Gamma_1` with `w(T' ; g iota(a) g^{-1}) = 1`.
  2. Then `T = g^{-1} T' g` satisfies `w(T ; iota(a)) = g^{-1} w(T' ; g iota(a) g^{-1}) g = 1`.
  3. So the transported system `Sigma^iota`, over the field `iota(F)`, has a
     solution over `K`. Its ideal `iota(I)` therefore does not contain `1`:
     evaluating at the solution would give `1 = 0`.
- *Transfer to `L`.*
  1. `iota` induces a ring isomorphism `F[X, Y] --> iota(F)[X, Y]` carrying `I`
     to `iota(I)`, so `1` is not in `I`.
  2. By (N2), `1` is not in `I L[X, Y]`.
  3. By (N1), `Sigma` has a zero over `L`.

**Step 6 (embeddings exist).** `F` is finitely generated over `Q`.
1. Let `y_1, ..., y_d` be a transcendence basis. `Q_p` is uncountable, so it
   contains elements `z_1, ..., z_d` algebraically independent over `Q`.
   `y_i |-> z_i` embeds `Q(y)` into `Q_p`.
2. In characteristic `0`, `F = Q(y)(theta)` for some `theta` with minimal
   polynomial `f`. The transported polynomial `f^iota` has a root `beta` in a
   finite extension `K` of `Q_p`.
3. `Q(y)[X]/(f) --> K`, `X |-> beta`, is a ring map from a field, hence
   injective.

For a prescribed transcendental `z`, the same construction may send `z` to
`1 + p z'` with `z'` in `Z_p` transcendental over `Q`.

**Step 7 (Corollaries C and D).**
1. If `h` is in `GL_n(L)` and `T` is a root for `h a h^{-1}`, then `h^{-1} T h`
   is a root for `a`. So we may assume every `a_i` is upper triangular.
2. Take `iota` as in the hypothesis of D. For C, take any prime `p > |m|` and
   the `iota` of Step 6; there every diagonal entry is `1`.
3. Choose `N >= 1` with `v(iota(e)) >= 1 - N` for every entry `e` of every
   `a_i`. Put `g = diag(pi^{N(n-1)}, ..., pi^N, 1)`.
4. The `(s, q)` entry of `g iota(a_i) g^{-1}` is `pi^{N(q-s)} iota(a_{i,sq})`:
   - for `s < q` its valuation is at least `N + (1 - N) = 1`;
   - on the diagonal it is `iota(d) == 1 mod pi`, since `|iota(d) - 1|_p < 1`;
   - below the diagonal it is `0`.
5. So `g iota(a_i) g^{-1}` is in `Gamma_1`, and Theorem B applies.

The examples of D:
- `z` transcendental: use Step 6 with `iota(z) = 1 + p z'`, for any `p` not
  dividing `m`.
- `3`: take `K = Q_2` and `iota` the inclusion of `Q`, since `|3 - 1|_2 = 1/2`.

**Step 8 (limits of the hypothesis).** Under the hypothesis of B, `iota`
induces an injective homomorphism `GL_n(F) --> GL_n(K)`. So the group generated
by `a` is isomorphic to a subgroup of `Gamma_1`.
- *Torsion.* All torsion of `Gamma_1` has `p`-power order. Let `u^e = 1` with
  `e = p^s e'` and `p` not dividing `e'`. If `u^{p^s} != 1`, it lies in some
  `Gamma_i` but not in `Gamma_{i+1}`. Then `phi_i(u^e) = e' phi_i(u^{p^s}) != 0`,
  a contradiction.
- *Eigenvalues.* Each eigenvalue `lambda` of an element `1 + pi X` of
  `Gamma_1` satisfies `|lambda - 1| <= |pi| < 1`.
- *The two examples.*
  - `iota` fixes `Q`, and `|2 - 1|_p = 1` at every prime, which rules out
    `diag(2, 1)`.
  - `1 + E_12` and `1 + E_21` generate `SL_2(Z)`. It contains
    `(1 + E_12)(1 - E_21)(1 + E_12) = [[0, 1], [-1, 0]]` of order `4`, and
    `[[0, -1], [1, 1]]` of order `6`, so it has torsion of orders `3` and `4`.
    No prime `p` allows both.

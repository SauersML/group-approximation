**ESTABLISHED** (proposed) by `higman-edge-relator-twist-freiheitssatz-proof`.
Items 1, 3, 4 and 5 are proved by hand; the 2-adic arithmetic in them is also checked by
`valuations.py` for e = 3..80. Item 2 uses one certified finite computation in `twist.g`: a class-7
2-quotient of `Abar_8`.

**Setting.**
- `H4(3) = < a, b, c, d | b^a = b^3, c^b = c^3, d^c = d^3, a^d = a^3 >`, where `x^y = y^-1 x y`.
- For `m = 2^e`, `Gamma_e = Gamma(3,m) = H4(3) / << a^m, b^m, c^m, d^m >>`.
- Inside `Gamma_e`: `K1 = <a,b,c>`, `K2 = <c,d,a>`, and the edge group `A = <a,c>`, which is
  `Z/m * Z/m`. The lattice splits as `Gamma_e = K1 *_A K2`, with `[K1:A] = [K2:A] = m`.
- The relator is `R = [a,c]^2 = (a^-1 c^-1 a c)^2`.
- Bars denote quotients by `R`:
  - `Abar_m = A / <<R>>_A = < a, c | a^m, c^m, R >`;
  - `Gammabar_e = Gamma_e / <<R>>`;
  - `Kbar_i` and `Abar` are the images of `K_i` and `A` in `Gammabar_e`.
- Every quotient of `H4(3)/<<R>>` whose four generators have 2-power order is a quotient of some
  `Gammabar_e`. This is the universality item of the tree-lattice description, whose node is pending
  landing.
- Define `t = 3^-1 mod m` and `lambda = lambda_e = 3^t mod m`. Then `lambda = 3` for `e = 3`,
  `lambda = 11` for `e = 4` and `lambda = 27` for `e = 5`; `lambda = 59 mod 64` for `e >= 6`.

**Statement.**
1. **Twist identity.** In any group generated by `a, b, c` in which `b^a = b^3`, `c^b = c^3` and
   `b^m = c^m = 1`:
   `b^-1 [a,c] b = a^-1 c^-lambda a c^3`.
   In particular `S_e := b^-1 R b = (a^-1 c^-lambda a c^3)^2` lies in `A ∩ <<R>>_{K1}`.
2. **The edge Freiheitssatz fails for every m = 2^e >= 8.** `S_e` is nontrivial in `Abar_m`.
   Hence `Abar_m -> Kbar_1` is not injective. The hypothesis "`A/<<R>>_A` embeds in
   `K_i/<<R>>_{K_i}` for infinitely many `m = 2^e`" is therefore false, and the reduction built on it
   cannot be used. For `m = 2, 4` the embedding does hold (the case `m | n + 1`), so among powers of two it
   holds exactly for `m <= 4`.
3. **Abelian bound.** Let `Q` be any quotient of `Gammabar_e`. Then the image of `A` in `Q` has
   abelianization a quotient of `(Z/16)^2`. The same bound holds in every finite 2-quotient of
   `H4(3)/<<R>>`, and hence for the closure of `<a,c>` in its pro-2 completion. The certified
   2-quotients in `twist.g` (`e = 4, 5`) and in `diag_tower-output.txt` (classes 4 to 11) attain
   `(Z/16)^2`. So the bound is sharp, and it explains the value `A^ab = (Z/16)^2` observed from class 4
   on.
4. **Index bound.** In `Gammabar_e`, for every `e`, `d^64` and `b^64` lie in `Abar`. Hence
   `[Kbar_1 : Abar] <= 64` and `[Kbar_2 : Abar] <= 64`. The same holds in every quotient with
   2-power-order generators. So `j(b) = j(d) = 6` is an upper bound, and the observed value 6 is the
   upper bound attained.
5. **The m-regular tree does not survive for e >= 7.** For `e >= 7`:
   - `<<R>>_{Gamma_e}` is not contained in `A`;
   - `Gammabar_e` is not `Kbar_1 *_Abar Kbar_2` with edge index `m`;
   - an amalgam decomposition of `Gammabar_e` over the image of `A` has edge index at most `64 < m`.

   So no proof that `ord(a) = 2^e` in `Gammabar_e` for infinitely many `e` can go through a splitting
   over the image of `<a,c>` of index `m`. Every such proof must see the relation `d^64 in Abar`.

**What survives.** The target question needs `ord(a) = m` in `Gammabar_e` for infinitely many `e`
(or infinite order of `a` directly). These routes remain open:
- the **B-splitting Freiheitssatz**: `L1 = <d,a,b>` embeds in `Gammabar_e`. Over `B = <b,d>`, the
  relator `R` is cyclically reduced of length 8 and is the square of a length-4 element. That is the
  exponent-2 case, which no proper-power Freiheitssatz we know covers here.
- **pro-2 growth of `ord(a)`**, which must be consistent with items 3 and 4.

`ord(a) = 2^e` in `Gammabar_e` is known for `e <= 7`:
- `e <= 5` is certified by the tree-lattice node;
- `e = 6, 7` follows from the class-9 and class-11 rows of
  `experiments/higman-diagonal-pro2-2026-09-18/diag_tower-output.txt`, together with universality.

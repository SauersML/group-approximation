Notation as in the target. Write `N = ker ρ_ψ`.

**Step 0 (states of kernel elements).** If `g ∈ N`, then `π_g = id` and every `g_i ∈ N`.
Indeed `ρ_ψ(g)(iu) = π_g(i) ρ_ψ(g_i)(u) = iu` for all `i` and `u`, so `π_g(i) = i` and each
`ρ_ψ(g_i)` is the identity. Hence expanding a table `(P, P, id, λ)` with labels in `N` at any
cone `p` gives `β(pi) = p π_{λ(p)}(i) = pi` and labels `λ(p)_i ∈ N`: it stays of the same form.

**Step 1 (expansion is injective).** Let `g ≠ h` in `G`, and let `R` be a finite complete prefix
code (a cone partition) of a cone `C`. Claim: expanding the one-cone tables with labels `g` and
`h` on `C` to `R` gives different data. Induct on the depth of `R`. If `R = {C}` the labels
differ. Otherwise `R` refines the level-one partition `{Ci}`. Since `ψ` is injective,
`ψ(g) ≠ ψ(h)`: either `π_g ≠ π_h`, and the bijections of the expanded tables already differ, or
some `g_i ≠ h_i`, and the induction hypothesis applies to `R` restricted to `Ci`.

Two consequences:
- **`G` embeds.** `x_g` is the class of the table on the level-one partition with `β = id`,
  label `g` on `C(1)` and `1` elsewhere. Tables with `β = id` on a common domain multiply
  labelwise (the product rule `λ''(p) = λ(β'(p)) λ'(p)` with `β' = id`), so `g ↦ x_g` is a
  homomorphism. Two tables are equivalent iff they have a common expansion, and by the claim
  the expansions of `x_g` and of the identity table never agree when `g ≠ 1`. So `x_g ≠ 1`.
- **Kernel stages embed.** For a cone partition `P`, the map
  `ι_P : N^P → V_d(G, ψ)`, `λ ↦ [(P, P, id, λ)]`, is a homomorphism by the same product rule,
  and it is injective by the claim applied cone by cone. Let `K_P` be its image.

**Step 2 (directed union).** By the cited node, every element of `K_ψ` has a representative
`(P, P, id, λ)` with labels in `N`, so `K_ψ = ⋃_P K_P`. If `P'` refines `P`, expansion to
`P'` maps `K_P` into `K_{P'}` (Step 0). Any two partitions have a common refinement, so the
union is directed, and every finite subset of `K_ψ` lies in a single `K_P ≅ N^P`.

**Step 3 (the dichotomy).** `K_ψ` is normal in `V_d(G, ψ)`, so `S ∩ K_ψ` is normal in `S`.
- If `S ⊄ K_ψ`, simplicity gives `S ∩ K_ψ = 1`. The composite
  `S → V_d(G, ψ) → V_d(G, ψ) / K_ψ ≅ V_d(H)` is then injective. This is item 1.
- If `S ≤ K_ψ` and `S` is generated by a finite set, that set lies in one `K_P ≅ N^k` by
  Step 2, so `S ≤ K_P`. As `S ≠ 1`, some coordinate projection `N^k → N` is nontrivial on `S`.
  Its kernel meets `S` in a proper normal subgroup, hence trivially, so `S` embeds in `N`.
  This is item 2.
- Item 3 is Step 2 applied to a finitely generated subgroup of `S`.

**Consequences.**
- *1 and 2.* Apply the theorem to `S`, and restrict to `X ≤ S`. If `G` is finitely generated,
  so is `H = ρ_ψ(G)`. For `SL_m(Q)`, `m ≥ 3` odd, simplicity is
  `sl-odd-q-simple-inputs-for-gl-n-q-root`. It is not finitely generated, so only items 1 and 3
  apply.
- *3.* If `S ⊄ K_ψ`, then `Γ~ ≤ S` embeds in `V_d(H)`, which
  `deligne-lattice-embeds-in-no-rover-nekrashevych-group` forbids. So `S ≤ K_ψ`, and item 2
  embeds `S` in `N ≤ G`.
- *4.* `A / (A ∩ K_ψ)` embeds in `V_d(H)` and, as a quotient of a Kazhdan group, has
  property (T). `kazhdan-subgroups-of-rover-nekrashevych-groups-are-rf` makes it residually
  finite.

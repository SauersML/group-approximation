Notation as in the claim. For a matrix `h` over `A`, `h-bar` is its reduction
mod `pi`.

**Step 1 (layers).** Fix `j >= 1`.
- (L1) `Gamma_j` is a normal subgroup of `GL_N(A)`.
  - The inverse of `1 + pi^j X` is the convergent series `sum_i (-pi^j X)^i`.
  - For `h` in `GL_N(A)`, `h (1 + pi^j X) h^{-1} = 1 + pi^j hXh^{-1}`.
- (L2) `phi_j : Gamma_j --> (M_N(kappa), +)`, `1 + pi^j X |-> X-bar`, is a
  surjective homomorphism with kernel `Gamma_{j+1}`, because
  `(1 + pi^j X)(1 + pi^j Y) = 1 + pi^j (X + Y + pi^j XY)`.
- (L3) For `h` in `GL_N(A)` and `u` in `Gamma_j`,
  `phi_j(h u h^{-1}) = h-bar phi_j(u) h-bar^{-1}`, by the formula in (L1).
- (L4) The `Gamma_j` intersect in `{1}`. If `T_j^{-1} T_{j+1}` is in `Gamma_j`
  for all `j`, then `T_j` converges to some `T` with `T_j^{-1} T` in `Gamma_j`:
  the differences lie in `pi^j M_N(A)`, `A` is complete, and
  `T_j^{-1} T - 1 = T_j^{-1}(T - T_j)`.

**Step 2 (substitution).** Let `T` be in `GL_N(A)`, `c` in `GL_N(A)^k` and `u` in
`Gamma_j`. Then `e = w(T ; c)^{-1} w(Tu ; c)` is in `Gamma_j` and
`phi_j(e) = D_{T-bar, c-bar}(phi_j(u))`.

*Proof.* Let `z_i`, `z'_i` be the values of `y_i` at `(T ; c)` and `(Tu ; c)`,
and `S_i = z_{i+1} ... z_l`. Then `z'_i = z_i v_i` with:
- `v_i = u` if `y_i = x`;
- `v_i = T u^{-1} T^{-1}` if `y_i = x^{-1}`;
- `v_i = 1` otherwise.

Downward induction on `i` gives
`z_i v_i ... z_l v_l = (z_i ... z_l) prod_{q >= i} S_q^{-1} v_q S_q`, so
`e = prod_i S_i^{-1} v_i S_i`, a product of elements of `Gamma_j` by (L1). By (L2)
and (L3), `phi_j(e)` is the sum of:
- `S_i-bar^{-1} phi_j(u) S_i-bar` over `y_i = x`;
- `-(S_i^{-1} T)-bar phi_j(u) (T^{-1} S_i)-bar` over `y_i = x^{-1}`.

For `y_i = x^{-1}` we have `T^{-1} S_i = z_i S_i = S_{i-1}`. So the sum is
`D_{T-bar, c-bar}(phi_j(u))`.

**Step 3 (Theorem E).** Put `D = D_{T_0-bar, c-bar}`. Every `T` in `T_0 Gamma_1`
has `T-bar = T_0-bar`, so Step 2 always uses this `D`.
- *Existence.* Put `T_1 = T_0`. Given `T_j` in `T_0 Gamma_1` with `w(T_j ; c)`
  in `Gamma_j`:
  1. By (L2), choose `u_j` in `Gamma_j` with
     `phi_j(u_j) = -D^{-1}(phi_j(w(T_j ; c)))`.
  2. Put `T_{j+1} = T_j u_j`. By Step 2,
     `phi_j(w(T_{j+1} ; c)) = phi_j(w(T_j ; c)) + D(phi_j(u_j)) = 0`, so
     `w(T_{j+1} ; c)` is in `Gamma_{j+1}`.

  By (L4), `T_j` converges to `T` in `T_0 Gamma_1` with `T_j^{-1} T` in
  `Gamma_j`. By Step 2, `w(T ; c)` is in `w(T_j ; c) Gamma_j = Gamma_j` for
  every `j`, so `w(T ; c) = 1`.
- *Uniqueness.* If `T != T'` are roots in `T_0 Gamma_1`, then
  `u = T^{-1} T'` is in some `Gamma_j` but not in `Gamma_{j+1}`. Step 2 with
  `e = 1` gives `D(phi_j(u)) = 0`, so `phi_j(u) = 0`, a contradiction.

**Step 4 (Corollary F).**
1. *Blocks.* Let the adapted basis have blocks of sizes `n_1, ..., n_s`, with
   `a_i` block upper triangular. Then `a_i^{-1}` is block upper triangular
   too, with diagonal blocks the inverses of those of `a_i`.
2. *Degeneration.* Put `A = L[[lambda]]`, `K = L((lambda))`, and
   `g = diag(lambda^{s-1} 1_{n_1}, lambda^{s-2} 1_{n_2}, ..., 1_{n_s})`. The
   `(p, q)` block of `c_i = g a_i g^{-1}` is `lambda^{q-p}` times that of
   `a_i`, and likewise for `c_i^{-1} = g a_i^{-1} g^{-1}`. So `c_i` lies in
   `GL_n(A)`, and `c_i == a_i^ss mod lambda`.
3. *Lifting.* The same holds for `c_i (x) 1_r` and `a_i^ss (x) 1_r`.
   - Let `T_0` in `GL_{nr}(L)`, a subgroup of `GL_{nr}(A)`, be the etale root.
     Reduction mod `lambda` is a ring map `A --> L`, so
     `w(T_0 ; c (x) 1_r) == w(T_0 ; a^ss (x) 1_r) = 1 mod lambda`.
   - The operator is `D_{T_0, a^ss (x) 1_r}`, invertible by hypothesis.
   - Theorem E, with `N = nr`, gives `T` in `GL_{nr}(A)` with
     `w(T ; c (x) 1_r) = 1`.
4. *Back to `a`.* Put `G = g (x) 1_r`. Then `G^{-1} T G` is a root for
   `a (x) 1_r` in `GL_{nr}(K)`, since `w(G^{-1} T G ; G^{-1} c G) = G^{-1} w(T ; c) G`.
5. *Descent to `L`.*
   - Let `I` in `L[X, Y]` be generated by `XY - 1` and the entries of `W - 1`,
     where `W` is `w` with `x |-> X`, `x^{-1} |-> Y` and constants
     `a_i^{+-1} (x) 1_r`.
   - `I` has a zero over an algebraic closure of `K`, so `1` is not in `I`.
   - By the weak Nullstellensatz over the algebraically closed field `L`, `I`
     has a zero `(X, Y)` over `L`, and `T = X` is the root.

**Step 5 (examples).**
1. *Unipotent tuples.* `a^ss = 1` and `T_0 = 1`, so every `S_i = 1` and `D = m id`.
   This is invertible since `m != 0` in `L`.
2. *Triangular tuples.* With the full flag, `a^ss = d` is diagonal. For a
   diagonal root `T_0`, every `S_i` is diagonal, and
   `S^{-1} E_pq S = (S_qq / S_pp) E_pq`. So `D` is diagonal on the basis
   `E_pq`, with eigenvalue `s_pq`, and `s_pp = sum eps_i = m`.
3. *The caution example.* Take `w = x^2 a x^{-1} a^{-1} b`, with letters
   `x, x, a, x^{-1}, a^{-1}`, then `b`.
   - *The diagonal root is not etale.* At `(T_0 ; d) = (1 ; diag(2, 1), 1)` we
     have `psi_12(a) = 1/2`, `psi_12(a^{-1}) = 2` and `psi_12(x) = 1`. The
     suffixes are:
     - after the first `x`: `x a x^{-1} a^{-1} b`, with `psi_12 = 1`;
     - after the second `x`: `a x^{-1} a^{-1} b`, with `psi_12 = 1`;
     - from the `x^{-1}`: `x^{-1} a^{-1} b`, with `psi_12 = 2`.

     So `s_12 = 1 + 1 - 2 = 0`.
   - *No triangular root.* For upper triangular `T` the diagonal of
     `w(T ; a, b)` is `diag(t_11, t_22)`, so `T = 1 + u E_12`. Then
     `T^2 a T^{-1} = [[2, 2u], [0, 1]] (1 - u E_12) = a`, and `w(T) = b != 1`.
   - *An exact root.* Put `T = [[5/2, -4/3], [9/2, -2]]`, with `det T = 1` and
     `T^{-1} = [[-2, 4/3], [-9/2, 5/2]]`.
     1. `T a T^{-1} = [[5, -4/3], [9, -2]] T^{-1} = [[-4, 10/3], [-9, 7]]`.
     2. `T (T a T^{-1}) = [[2, -1], [0, 1]] = b^{-1} a`.
     3. So `T^2 a T^{-1} a^{-1} b = b^{-1} a a^{-1} b = 1`.

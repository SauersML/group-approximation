## Setting

As in `bs-chain-configurations-exist-in-finite-germ-extensions-of-v` and
`pl-chain-germ-group-contains-thompson-f`:
- `Q = ⟨σ, δ, s⟩` is the germ group at `+∞` of the host `Γ̄ = ⟨V, a, b⟩`, where `σ = x+1`, `δ = 2x`
  and `s = [a]` for the odd dyadic square map `a`.
- In the coordinate `x = Λ(y) = 2^⌊y⌋ (1 + {y})`, the germs become `δ = T_1`, `s = D_2` and
  `σ = e_0`, the carry map, with `2^(-y-1) <= e_0(y) - y <= 2^(1-y)`.
- `χ: Q -> Z` is `log_2` of the leading slope in `y`, so `χ(s) = 1` and `χ(σ) = χ(δ) = 0`. Since
  `Q^ab` is cyclic, generated by the image of `s`, `Hom(Q, R) = R χ`.

**Decay order.** Every `h ∈ ker χ` has the form `h(y) = y + q_h + E_h(y)`, with `q_h ∈ R` and
`E_h(y) = O(2^(-y / 2^K))` for some integer `K`. Put `κ(h) ∈ Z ∪ {-∞}` equal to the least such `K`.
Then `κ(σ) = 0` and `κ(s^N σ s^-N) = N`.

## Statement

1. **No ascending HNN structure.** There is no finitely generated `H <= ker χ` and `t ∈ Q` with
   `χ(t) = ±1`, `t H t^-1 ⊆ H` and `ker χ = ⋃_k t^-k H t^k`. In particular, `Q` is not an ascending HNN
   extension of any finitely generated subgroup, with either orientation of the stable letter.
   - It dies at orientation `χ(t) = -1` on the translation part: `q(H)` is a nonzero finitely generated
     subgroup of `R` with `q(H) ⊆ 2 q(H)`.
   - It dies at orientation `χ(t) = +1` on the decay order: `κ` is bounded on `H`, but conjugation by
     `t` raises `κ` by exactly `1` on every element of large decay order.
2. **Restatement.** By the Bieri–Neumann–Strebel–Brown criterion for discrete characters, item 1
   says `Σ^1(Q) = ∅`, since `S(Q) = {[χ], [-χ]}`. This restatement is not used below.
3. **Finite presentation forces F_2.** If `Q` is finitely presented, then `Q` contains a free group
   of rank 2. More precisely, `M_0` contains one, where `M_0 = {h ∈ Q : h(x) - x` is bounded near
   `+∞}` is the group of bounded-displacement germs. `M_0` contains `σ`, `e_1` and the copy of `F` from
   `pl-chain-germ-group-contains-thompson-f`.
4. **General criterion.** The same proof works for every group `P` of germs at `+∞` that satisfies
   all of the following:
   - `P` consists of germs `λ y + q + E(y)` with `λ ∈ 2^Z` and `E = O(2^(-y/2^K))` for some `K`;
   - `Hom(P, R)` is spanned by `χ = log_2 λ`;
   - `P` contains `D_2`;
   - `q` is nonzero on `ker χ`;
   - some `h ∈ ker χ` has finite decay order.

   Every such `P` has `Σ^1(P) = ∅`, and if it is finitely presented it contains `F_2`.

## What this changes

- **A class of engines is dead for Q.** Each approach below would make `Q` an ascending HNN extension
  of a finitely generated subgroup, or a directed union of such stages with a finitely generated
  bottom. Item 1 kills them at the named step.
  - The ascending zoom-tower engine of `zoom-tower-germ-groups-give-f-infinity-germ-extensions`.
  - Every "window group" or "shift-similar" presentation in which a stable letter conjugates a
    finitely generated window group into itself.
  - Brown-type ascending-HNN finiteness arguments with the square map, or any other element of
    `χ`-value `±1`, as stable letter.
  - Any Bieri–Strebel or Σ-invariant finiteness argument with `χ`, for both signs.
- **The hole acquires a necessary prerequisite.** Finite presentation of `Q` is the last hole on the
  concrete host route to `G_1 ∈ B_A`, through `fp-germ-extensions-of-locally-moving-bases-have-fp-germ-groups`
  and `bhm-singfix-condition-forces-fp-germ-groups`, and so for the common vertex group of H4 and the
  base of BG. It now needs the independent statement **`F_2 <= M_0`**.
  - `M_0` is the germ group of bounded-displacement maps. Its known finitely generated pieces are the
    picture groups of `pl-chain-germ-group-contains-thompson-f`. These are subgroups of
    `PL(R) × PL(R)` with finitely many breakpoints, so they have no `F_2` by Brin–Squier (a remark
    only; it is not imported and not used).
  - If `M_0` contains no `F_2`, then `Q` is not finitely presented, so `Γ̄` is not finitely
    presented, and this host is dead for every chain problem.
- **Non-ascending finiteness is forced.** Any proof that `Q` is finitely presented must be a genuinely
  non-ascending HNN or amalgam argument, whose edge groups are proper in the base on both sides.

## What is left

- **Does `M_0` contain `F_2`?** Here `M_0 = {h ∈ Q : h(x) - x` bounded`}`, equivalently
  `ker(χ, q) ∩ {κ <= 0}`.
  - Brin–Squier does not apply directly. Elements of `M_0` have infinitely many breakpoints, and
    conjugates by `s` spread pictures over scale-divergent sites.
  - A ping-pong pair in `M_0` would reopen the host. A proof that `M_0` has no free subgroup, for
    example by an invariant mean on germ pictures, would close it negatively.

## Lesson for general BH

In a PL tower host of a Baumslag–Solitar chain, the top letter (the square map) acts on the error of
a germ by `E(y) ↦ 2 E(y/2)`. That halves its exponential decay rate. The **decay order** `κ` is an
ultrametric size on the kernel of the top character: it is bounded on finitely generated subgroups
and raised by one under conjugation by the top letter. So the kernel is never exhausted by finitely
generated ascending stages. The same mechanism applies to any host whose top letter changes the
decay scale of lower-level defects. Such hosts have empty `Σ^1`, and finite presentation, if true,
has to come with free subgroups.

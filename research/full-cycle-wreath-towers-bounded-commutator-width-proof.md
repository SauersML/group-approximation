Conventions: `p(g)_i = g_(p^-1 i)`, `(f; p)^-1 = (p^-1(f^-1); p^-1)`, `[x, y] = x y x^-1 y^-1`.

## 1. The commutator formula

For `x = (u; alpha)` and `y = (q; beta)`:
```text
x y                 = (u · alpha(q); alpha beta)
x y x^-1            = (u · alpha(q) · gamma(u^-1); gamma),                 gamma = alpha beta alpha^-1
[x, y]              = (u · alpha(q) · gamma(u^-1) · tau(q^-1); tau),         tau = gamma beta^-1 = [alpha, beta]
```
In coordinates, `[x, y] = (f; tau)` means `f_i = u_i · q_(alpha^-1 i) · u_(gamma^-1 i)^-1 · q_(tau^-1 i)^-1`.

## 2. The twisted lemma

Put `g_i = f_i q_(tau^-1 i)` and `v_i = q_(alpha^-1 i)`. The equations read `g_i = u_i v_i u_(gamma^-1 i)^-1`.

- **Along the cycle.** `gamma` is conjugate to `beta`, so it is an `m`-cycle. Write its points as
  `c_0 = i_1, c_1 = gamma^-1(i_1), ..., c_(m-1)`. With `i_2 = gamma(i_1)` the equation gives
  `u_(i_2) = g_(i_2) u_(i_1) v_(i_2)^-1`, and iterating once around the cycle gives
  `u_(i_1) = G u_(i_1) V^-1`, where `G = g_(c_0) g_(c_1) ... g_(c_(m-1))` and `V = v_(c_0) v_(c_1) ... v_(c_(m-1))`.
- **Solvability.** Conversely, if `G = s V s^-1` for some `s`, set `u_(i_1) = s` and define the other `u_i` by
  the recursion. All equations then hold. So the system is solvable iff `G` is conjugate to `V`.
- **Choice of `q`.** Take `q` supported at one point `j`, with `q_j = s`.
  - Then `v_i != 1` only for `i = alpha(j)`, so `V = s`.
  - Also `g_i = f_i` except `g_(tau j) = f_(tau j) s`.
  - Rotating the cyclic product `G` so that it ends with `g_(tau j)` conjugates it to `F s`, where `F` is the
    cyclic product of `f` along `gamma^-1`, ending at `tau(j)`.
- **Conclusion.** The system is solvable iff `F s` is conjugate to `s`, iff `F = t s t^-1 s^-1` for some `t`.
  Given `F = [t, s]`, this choice of `q` works. Any rotation of `F` is a conjugate of `F`, and conjugates of
  commutators are commutators. So the starting point does not matter.

## 3. `c_T <= |T|`

- **The set.** Let `K = {[alpha, beta] : beta conjugate to zeta}`. It is closed under conjugation, and it
  contains `[zeta, zeta] = 1`.
- **Inverses.** `[alpha, beta]^-1 = [beta, alpha] = [alpha^-1, alpha beta alpha^-1]`, and the second entry is again
  conjugate to `zeta`.
- **Generation.** `[T, N]`, `N = <<zeta>>`, is generated by the `[alpha, n]` with `n in N`. Such an `n` is a
  product of conjugates of `zeta^(+-1)`. The identities
  `[alpha, n_1 n_2] = [alpha, n_1] · n_1 [alpha, n_2] n_1^-1` and `[alpha, beta^-1] = beta^-1 [alpha, beta]^-1 beta`
  write these as products of elements of `K`. So `K` generates `[T, N] = [T, T]`.
- **The bound.** `K^j` increases with `j` because `1 in K`, so it reaches `[T, T]` within `|T|` steps.

## 4. Inheritance

Let `x = (f; tau) in [W, W]` and `c = max(c_T, c_H)`.
- **Constraints on `x`.** The map `(f; p) -> (f_1 ... f_m mod [H, H], p mod [T, T])` is a homomorphism
  `W -> H^ab × T^ab`, because the order of the product does not matter modulo `[H, H]`. So
  `tau in [T, T]` and `f_1 ... f_m in [H, H]`.
- **The top.** Write `tau = tau_1 ... tau_c` with `tau_k = [alpha_k, beta_k]` and each `beta_k` conjugate to
  `zeta`. Pad with `[zeta, zeta]`.
- **Placing the pieces.** Fix a coordinate `j'`. For `k >= 2`, let `f^(k)` be supported at the single
  coordinate `(tau_1 ... tau_(k-1))^-1 (j')`, with value `y_k` to be chosen. Then
  `(f; tau) = prod_k (f^(k); tau_k)` forces `f^(1) = f` except at `j'`, where `f^(1)_(j') = f_(j') Y^-1` with
  `Y = y_2 ... y_c`.
- **The defect.**
  - Let `F` be the cyclic product of `f` along `gamma_1^-1`, rotated to end at `j'`. Then `F` lies in `[H, H]`,
    so `F = kappa_1 ... kappa_c` with commutators `kappa_k`, padded with `1`.
  - Choose `y_k = kappa_k` for `k >= 2`. The cyclic product of `f^(1)` is conjugate to
    `F Y^-1 = kappa_1`, a commutator.
  - For `k >= 2`, the cyclic product of `f^(k)` is `y_k`, a commutator.
- **Conclusion.** By the twisted lemma, each `(f^(k); tau_k)` is a commutator, so `x` is a product of `c`
  commutators.

## 5. Towers

Induct on depth. For `d = 1`, `W = T_1`, and Section 3 gives `c_(T_1) <= |T_1|`. For `d > 1`,
`W = H wr T_1`, where `H` is the depth-`(d-1)` tower at a child. By induction every element of `[H, H]` is a
product of `max_(i >= 2) c_(T_i)` commutators. Section 4 gives `max_i c_(T_i)` for `W`.

**(a).**  `ker(S -> H)` is normal in `S` and nontrivial by hypothesis, so by
simplicity it is `S`: the image of `S` in `H` is trivial.  Then `H` is
generated by the image of `t` alone, and the relation `w = 1` reads
`t^m = 1`, so `H` is a quotient of `C_|m|`.

Conversely `pi_m(w) = 1`, because `w` has exponent sum `m`, so `pi_m` factors
through `H`, giving `H ->> C_|m|`.  A quotient of `C_|m|` that surjects onto
`C_|m|` is `C_|m|`, so `H = C_|m|`.

The quotient map `S * <t> ->> H = C_|m|` then kills `S` and sends `t` to a
generator, so its kernel is `N_m` — for any generator, since the generators
of `C_m` are the `t-bar^j` with `gcd(j, m) = 1` and
`deg_t(x) · j = 0 mod m` iff `deg_t(x) = 0 mod m`.  That kernel is `<<w>>`.

**(b).**  If `N_m = <<w>>_{G*<t>}` then
`G_w = (G * <t>)/<<w>> = (G * <t>)/N_m = C_m`.  The composite `G -> G_w` is
the restriction of `pi_m`, which kills `G` by construction, so every element
of `G` dies; `G != 1` makes that a failure of injectivity, and
`deg_t(w) = m != 0` makes the equation nonsingular.

Note (b) uses nothing about `G` beyond `G != 1`, and in particular no
simplicity, no perfectness and no finiteness.

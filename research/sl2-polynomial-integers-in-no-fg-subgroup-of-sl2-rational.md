title: "SL_2(Z[t]) lies in no finitely generated subgroup of SL_2(Q(t))"
---

There is no finitely generated subgroup `Γ ⊂ SL_2(Q(t))` with `SL_2(Z[t]) ⊂ Γ`.

This is Rapinchuk's question as studied by P. Abramenko ("On finite and elementary
generation of SL_2(R)", arXiv:0808.1095, 20 pp.), asked for `R = Z[t]`. It implies
the negative answer to Zaremsky Problem 3.3: `SL_2(Z[t,t^{-1}])` contains `SL_2(Z[t])`,
so it cannot be finitely generated (route
`sl2-laurent-integers-not-fg-via-no-fg-overgroup`).

## Attempts

- **Abramenko's theorem does not cover it.** Per its arXiv abstract (read
  2026-09-13), the answer to "is there a finitely generated `Γ ⊂ SL_2(F)` containing
  `SL_2(R)`?" is negative for `R = R_0[s,t]` with `R_0` a finitely generated domain
  with infinitely many non-associate primes. `Z[t]` is a one-variable polynomial ring
  over such an `R_0`, so it is outside that range. The proof "applies Bass–Serre theory
  and reduces to analyzing which elements of SL_2(R) can be generated by elementary
  matrices with entries in a given finitely generated R-subalgebra of F". For `Z[t]`
  this becomes: for a finitely generated `Z[t]`-subalgebra `S ⊂ Q(t)`, which elements
  of `SL_2(Z[t])` lie in `<E_2(S), SL_2(S)-stabilizers>`? The first case is
  `S = Z[t,t^{-1}]`, i.e. Problem 3.3 itself.
- **Caution.** The claim may be false even if Problem 3.3 has answer no. Finitely
  generated overgroups such as `SL_2(Z[1/N][t,t^{-1}, (t-1)^{-1}])` might exist.
  Whether larger rings of `S`-integers in `Q(t)` make `SL_2` finitely generated is
  unexplored here.

Notation as in the target. All equalities are in `NearSym(N)`. Conjugation by `s^-1` is
an automorphism of `NearSym(N)` sending `c_j` to `c_(j-1)`. Suppose, for contradiction,
that `c_(-1) <= W_N`.

**Step 1: shift invariance.** Conjugating the commutation hypothesis by `s^-1` shows that
`c_(i-1)` and `c_(j-1)` commute for `0 <= i < j <= N`. In particular `c_(-1)` commutes
with `c_0, …, c_(N-1)`.

**Step 2: the centralizer.** The `c_j`, `0 <= j <= N`, pairwise commute, so every
`w ∈ W_N` is a product `w = x_0 x_1 ⋯ x_N` with `x_i ∈ c_i`.
- For `y ∈ c_i`, `w y w^-1 = x_i y x_i^-1`, because every other factor commutes with `y`.
- So `w` centralizes `c_0, …, c_(N-1)` exactly when `x_i ∈ Z(c_i)` for `i <= N-1`.
- By Step 1 and `c_(-1) <= W_N`, every element of `c_(-1)` has this form. Hence
  `c_(-1) <= A·c_N`, where `A = Z(c_0) ⋯ Z(c_(N-1))`.
- `A` is central in `W_N`: each `Z(c_i)` commutes with `c_i` and with every other `c_j`.

**Step 3: the derived subgroup.** Put `α_g = s^-1 ρ_g s`. Write `α_g = a_g y_g` with
`a_g ∈ A` and `y_g ∈ c_N`.
- Since `A` is central, `α_([g,h]) = [α_g, α_h] = [y_g, y_h] ∈ [c_N, c_N] = s^N ρ(P') s^-N`,
  where `P' = [P,P]`.
- `P'` is generated by commutators, so `s^-1 ρ(P') s <= s^N ρ(P') s^-N`, that is,

      s^-m ρ(P') s^m <= ρ(P')   with m = N + 1 >= 1.

**Step 4: `P'` is an admissible input.**
- `P` is finitely generated, and an FW group has no homomorphism onto `Z`: the
  translation action of `Z` on itself commensurates `N` and transfixes it only if some
  translation-invariant subset, which is `∅` or `Z`, is at finite distance from `N`.
  So `P^ab` is finite, and `P'` has finite index, is infinite and finitely generated.
- A finite-index subgroup of an FW group is FW (standard; Cornulier).
- Nonidentity elements of `P'` still have infinite support.
- Since `ρ` is injective into `NearSym(N)`, Step 3 defines an injective endomorphism
  `φ` of `P'` with `s^-m ρ_g s^m = ρ_(φ(g))` for `g ∈ P'`.

**Step 5: window zero for `s^m` fails.** This is item 1 of
`fw-inputs-admit-no-twisted-normalizing-genuine-shell-action`. A direct proof:
- Run Steps 1 to 3 of `fw-inputs-admit-no-twisted-shell-normalization-proof` with `s^m` in
  place of `s`. The group acting on `N × N` is `P'`, through `(ρ_(φ(g)), ρ_g)`.
- One obtains an exactly equivariant injection `s'`, near equal to `s^m`. Its orbit graph
  has `m` infinite forward rays, starting at points `k_1, …, k_m` of the finite
  `ρ(P')`-invariant set `K`. Every other component is finite.
- Step 4 of that proof gives `ρ_g(s'^j k_i) = s'^j(ρ_(φ^j(g)) k_i)`. For large `j` the point
  `ρ_(φ^j(g)) k_i ∈ K` must start an infinite ray.
- So for large `j` every `ρ_g`, `g ∈ P'`, permutes the level `L_j = {s'^j k_1, …, s'^j k_m}`.
- The levels cover a cofinite set, and nonidentity elements have infinite support. So
  restriction embeds `P'` in a product of copies of `Sym(m)`. That product satisfies every
  law of the finite group `Sym(m)`, so its finitely generated subgroups are finite
  (B. H. Neumann: a variety generated by a finite group is locally finite).
- So `P'` would be finite, a contradiction.

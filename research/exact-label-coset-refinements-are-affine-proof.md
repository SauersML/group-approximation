Notation as in the target.

**(G) Goursat.**  For `D <= K x K'`, put `K_1 = pi_1(D)`,
`N = {x : (x,e) in D}` and `N' = {y : (e,y) in D}`.
- `N` is normal in `K_1`, `N'` is normal in `K'_1`, and
  `D = {(x,y) : theta(xN) = yN'}` for an isomorphism
  `theta: K_1/N -> K'_1/N'`.
- The blocks of `D` are `xN x theta(xN)`.
- Those of `cD`, with `c = (c_1, c_2)`, are `c_1 x N x c_2 theta(xN)`, and
  `pi_1(cD) = c_1 K_1`.

**(S1) One affine character per edge.**  Fix an edge `(c,c')` with
`c ∩ c' = {v}`.
- Every block of `cD` lies in `(beta x beta')^(-1)(Acc)`, so
  `x_v o beta_c` is constant on each `B_i`.
- By label exactness distinct blocks carry distinct values, so there are at
  most two blocks and `[K_1 : N] <= 2`.
- Hence there are a homomorphism `chi_v: K_1 -> Z_2` with kernel `N`
  (`chi_v = 0` if `N = K_1`) and a bit `b_v` such that, for `x in K_1`,

  ```text
  x_v(beta_c(c_1 x)) = chi_v(x) + b_v.                               (A1)
  ```

  The reason is that an injection `K_1/N -> Z_2` is affine.

**(S2) Support coset.**
- For a neighbour `c'` and `s` outside `c_1 K_1`, (CS) gives
  `p_c^s p_(c')^(s') = 0` for every `s'`.  Summing over `s'` gives
  `p_c^s = 0`, algebraically.
- So `p_c` is supported on `S_c = ∩_(c') c_1^(c') K_1^(c')`.
- An intersection of left cosets of subgroups is empty or a left coset
  `s_c K_c^~`, where `K_c^~ = ∩ K_1^(c')`.
- `S_c` is nonempty because `sum_s p_c^s = 1 != 0`.  If `A(R) = 0` there is
  nothing to prove.

**(S3) Affine image.**
- For `v in sh(c)`, choose an edge `(c,c')` with `c ∩ c' = {v}`.  Since
  `s_c in c_1 K_1`, (A1) gives, for `k in K_c^~`,

  ```text
  x_v(beta_c(s_c k)) = chi_v(c_1^(-1) s_c) + chi_v(k) + b_v = chi_v(k) + b'_v,
  ```

  because `chi_v` is a homomorphism on `K_1 ⊇ K_c^~`.
- So `Phi_c(s) = beta_c(s)|_(sh(c))` satisfies
  `Phi_c(s_c k) = chi(k) + b'` on `S_c`, with `chi = (chi_v)_v` a
  homomorphism.
- Its image `A_c = chi(K_c^~) + b'` is an affine subspace.
- Every point of `A_c` is `beta_c(s)|_(sh(c))` for some `s`, with
  `beta_c(s) in Allowed_c`.  This proves (EL1).

**(S4) (EL2).**  The pushed-forward variable is
`X_v^(c) = sum_s (-1)^(x_v(beta_c(s))) p_c^s`, and its spectral projections
are functions of the PVM `p_c`.
- **Joint spectrum.**  By (S2) and (S3), the joint spectral measure of
  `(X_v^(c))_(v in sh(c))` lives on `Phi_c(S_c) = A_c`.
- **Consistency across contexts.**  Take an edge with shared `v`.
  - By (R3) of `coset-refinement-forces-rectangular-central-splitting-proof`,
    the block sums of `c` and `c'` agree.
  - Each block carries one value of `v`, the same on both sides.
  - So `X_v^(c) = X_v^(c')`, algebraically: that step uses only (CS) and the
    PVM sums.

**(S5) (EL3).**

- **The pushforward.**  `A(G_(B_R))` is generated by PVMs `(Q_c^a)` over
  `A_c` that agree on shared variables.  Put
  `Q_c^a -> sum_(s : Phi_c(s) = a) p_c^s`.
  - These are PVMs by (S3).
  - Agreement on a shared variable is the identity `X_v^(c) = X_v^(c')` of
    (S4).
  - So this defines a unital *-homomorphism `A(G_(B_R)) -> A(R)`.
- **Lifting `R^U` models.**  Suppose `G_(B_R)` has a perfect `R^U` model
  `(Q_c^a)`.
  - By (EL1), choose for each `a in A_c` an allowed completion
    `kappa_c(a) in Allowed_c` with `kappa_c(a)|_(sh(c)) = a`.
  - Put `P_c^w = sum_(a : kappa_c(a) = w) Q_c^a`.  These are PVMs over
    `Allowed_c`.
  - Two contexts overlap only in shared variables, and the `Q` agree there.
    So the `P` satisfy the rule of `G_B`, and give a perfect `R^U` model.
- **Consequence.**
  - A tracial state on `A(R)` restricts through the pushforward to a perfect
    tracial model of `G_(B_R)`.
  - A perfect `R^U` model of `G_(B_R)` would give one of `G_B`, which is
    excluded.
  - The allowed sets `A_c` are affine, so the support condition (LAS1) of
    `locally-affine-support-bcs-is-exactly-the-lcs-boundary` holds.  That node
    and `lcs-tracial-ru-gap-equiv-nonhyperlinear` then give a binary linear
    system and a finitely presented group, as stated.

Let P be infinite and finitely generated by S, with enumeration nu.
Assume each rho_g, g in S and their inverses, is given by a finite
exception table and positive affine formulas on residue classes:
for some m and all sufficiently large k,

    rho_g(m*k+r)=a_r*k+b_r,       a_r,b_r integers, a_r>0.

Then E_nu=<V,hat(P)> has decidable word problem and hence admits a
recursive presentation on its finite generating set. The algorithm
uses exact arithmetic for germs and finite prefix tables away from
the finitely many possible singular points of an input word.

The regular input P itself has polynomial-time word problem: iterate
these fixed affine maps on index 0 and use freeness of the orbit.
Thus the arithmetic hypothesis is a restricted test class, not an
encoding requirement justified for all decidable inputs. No finite
presentation of E_nu follows from this algorithm.

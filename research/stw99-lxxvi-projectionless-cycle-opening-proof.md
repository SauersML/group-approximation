It is enough to prove that evaluation reflects order. First suppose
`a,b in C(Y,D tensor K)_+` satisfy pointwise comparison, `Y` is a connected
finite graph, and `b` is nowhere zero.

Cut one interior point from each chord of a spanning tree, obtaining a
quotient `q:T -> Y` from a finite tree. Fix an action tolerance `rho>0`.
At every nonzero cut endpoint `e`, stable projectionlessness makes zero
nonisolated in `spectrum(a(q(e)))`. Choose

```text
0 < lambda_e in spectrum(a(q(e))),       lambda_e < rho^2,
```

for all finitely many such endpoints, and only then choose one
`0<delta<min_e lambda_e` below the comparison tolerance. If all cut fibers
vanish, take any sufficiently small `delta`. The finite-tree theorem and the
exact comparison-vector lemma give

```text
y_1^*y_1=(q^*a-delta)_+,       y_1y_1^* in Her(q^*b).     (1)
```

Spectral mapping and equality of nonzero spectra give

```text
0 < lambda_e-delta in spectrum(y_1(e)y_1(e)^*) < rho^2.  (2)
```

At each cut choose one local comparison field downstairs and pull that same
field to both endpoint collars. Stable rank one supplies endpoint alignment
unitaries. Antoine--Dadarlat--Perera--Santiago, Lemma 3.1, changes every
alignment unitary to one of zero `K_1`-class while changing its action on
`y_1` by less than `5 sqrt(lambda_e-delta)<5 rho`.

Since `b` is nowhere zero and `D` is simple, every fiber of
`B=Her(q^*b)` is full. Proposition 2.2 of the same paper applies to the
entire finite endpoint list: all adjusted unitaries have the same image,
zero, in `K_1(D)`, so one unitary in the unitization of `B` realizes all
prescribed endpoint values simultaneously. Multiply `y_1` by it and splice
to the pulled-back local fields on pairwise disjoint collars. Splicing stays
in the closed right ideal generated by `q^*b`. The resulting vector has
equal paired endpoint values exactly, hence descends through `q`, and its
source square approaches `a` as `rho`, the collar widths, and `delta` tend
to zero. Hereditary membership descends because `q^*` is isometric and

```text
(q^*b)^(1/n)q^*c=q^*(b^(1/n)c) -> q^*c.
```

This proves global comparison on `Y`.

For a target which can vanish, fix `epsilon>0` and choose a finite disjoint
union `Y_0=disjoint_union_j Y_j` of connected compact finite subgraphs with

```text
closure(supp((a-epsilon)_+)) contained in int(Y_0),
Y_0 contained in supp(b).
```

Run the cut-to-tree proof on each `Y_j` and then apply
Antoine--Dadarlat--Perera--Santiago, Lemma 2.4. Letting `epsilon` tend to
zero proves the order embedding. The published one-dimensional
lower-semicontinuous realization theorem makes evaluation surjective whenever
it is an order embedding, hence gives the asserted natural isomorphism.

For a simple stably finite pure stably projectionless coefficient, the
first-factor map to `D tensor_min Z` is a coefficient Cu-isomorphism. Its
target is again stably projectionless because that Cu-isomorphism preserves
compact classes. Applying the natural evaluation formula to source and
target proves finite-graph Cu-regularity; Seth--Vilalta separately supplies
purity of the continuous-function algebra.

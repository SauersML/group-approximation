**ESTABLISHED STRUCTURAL EQUIVALENCE.**  Let a ZPC-IRS strategy act on
`(X,mu)` with free involution `J`, let `U` be the group generated by the
unreadable involutions (it commutes with `J`, so acts on `Y=X/<J>`), and let

```text
m : Y -> Menus,      m(y) = the affine equation menu E_(r(y)) selected at y,
```

be the selected-menu map, a coarsening of the finite readable field
`r:Y -> F_2^(S_R)` (`zpc-readable-variables-global-boolean-field`).  `Menus`
is finite because the game is finite.

**(1) Equivalence.**  The orbitwise resource `(ZOM2)` of
`zpc-frozen-equation-menu-has-positive-orbitwise-class` — a positive part `P`
of a readable atom whose entire unreadable orbit satisfies the single menu
selected at its base — exists **iff** the action `U ↷ (Y,mu)` has a
positive-measure ergodic component on which `m` is essentially constant.

**(2) Collapse.**  On any such constant-menu component `Y_c` the unreadable
variables satisfy, almost everywhere, one fixed finite affine `F_2` system
`E_c` together with the same-question and edge commutations, with `J=-1`.
This is a perfect commuting-operator model of the ordinary binary LCS
`L(G,c)=L(S_L,E_c,C)`.  Because `omega*(G)<1`, `L(G,c)` has no perfect
finite-dimensional strategy (a finite-dimensional one, combined with the
deterministic readable answers realizing `c`, would be a perfect
finite-dimensional tailored strategy for `G`).  By
`finite-linear-commutation-system-to-lcs` the solution group of `L(G,c)` is a
finitely presented nonhyperlinear group — obtained without any other input of
the route `zpc-freezing-from-orbitwise-equation-menu`.

**(3) Consequence.**  Hence the orbitwise-menu sub-lemma is not a strict
simplification of `zpc-readable-control-freezing-to-lcs`: securing its
resource is equivalent to exhibiting an unreadable-ergodic component whose
selected menu is essentially constant, and such a component is already a
solved endpoint (a nonhyperlinear group).  The genuine slack in the problem
is exactly the complementary regime, an ergodic action that permutes the
finitely many menus with no constant component; there the orbitwise resource
provably fails, while the finite-translate resource
`perfect-gap-zpc-has-finite-readable-translate-algebra` can still hold (it
permits a transitive atom orbit with a different active menu at each atom).
So effort aimed at closing the non-hyperlinear-group route through this
sub-lemma should move to the finite-translate resource; the orbitwise route
only reaches witnesses that are already ordinary LCS gaps.

This does not refute `zpc-frozen-equation-menu-has-positive-orbitwise-class`:
that claim can still be true for a specially selected witness, but by (1)-(2)
only when the witness carries a constant-menu component, i.e. exactly when the
ambient problem is already solved on that component.

`stw83-problem-lxxxiii-graph-nuclear-dimension` asserts that every graph
C\*-algebra has nuclear dimension at most one, which is Problem LXXXIII of
Schafhauser--Tikuisis--White.  The target asserts the same thing, with the
same quantifier over all graphs and the same bound.  So the implication is
the identity.

This route only connects the ledger root to the sub-graph that already
carries the work on this problem.  That sub-graph includes:
* the finite-graph reduction;
* the ENSW table entries;
* `stw83-canonical-circle-toeplitz-dimension-two-bound`;
* `stw83-circle-ideal-cuntz-quotient-dimension-two-bound`.

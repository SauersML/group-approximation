The group Gamma generated by all current H_i prefix maps, finite
component permutations, and global diagonal A_4 actions controlled
by finitely many U/Z mask coordinates is elementary amenable.
Both the original invariant-code group Lambda and its controlled
enlargement Lambda_tilde are subgroups of Gamma.

The conclusion also holds after adjoining reversible global
diagonal A_4 actions selected by finite full-component data.
An untouched non-u sentinel detects the common tail multiplier,
so the faithful restriction survives these data-dependent controls.

For each finite generating set, a sufficiently large exact-n
non-u stratum is faithful. Its gap coordinates and finite label
tuples identify the action with piecewise lattice isometries on
finitely many orthants. Those groups are elementary amenable by
the known Bieri-Sach theorem; directed unions give the claim.

Every finite-alphabet cellular automaton over these groups is
surjunctive. Thus adding more of the current source symmetries,
even to obtain an infinite memory subgroup, cannot produce a
Gottschalk counterexample. The code and nonlinear reversible
extension remain valid, and an injective linear-feedback extension
could still provide a reversible control.

This does not classify arbitrary component recodings, operations
creating or deleting non-u components, or all Q,F_A centralizers.
It does not resolve Gottschalk's conjecture.

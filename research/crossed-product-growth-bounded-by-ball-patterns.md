**ESTABLISHED (unreviewed).** Let `k` be a field, `P` a group with finite symmetric generating set,
word length `|·|` and balls `B_P(N)`. Let `X ⊆ A^P` be a `P`-subshift (`(p·x)(q) = x(p^(-1) q)`), and
write `L_F(X) = { x|_F : x ∈ X }` for finite `F ⊆ P`. Let `B = LC(X, k) ⋊ P`, with `v_p f v_p^(-1) = f∘p^(-1)`.

1. **Growth bound.** For every finite `S ⊆ B` there are `m, r >= 0` such that, for all `n >= 0`, the span
   `B_(<= n)` of all products of at most `n` elements of `S` (the empty product is `1`) satisfies

   `dim_k B_(<= n) <= |B_P(mn)| · |L_(B_P(mn + r))(X)|`.

2. **Hosted group algebras.** If `G` is a group generated by a finite set `T` and `φ : k[G] -> B` is an
   injective algebra homomorphism (not necessarily unital), then for some `m, r` and all `n`

   `|B_G(n)| <= |B_P(mn)| · |L_(B_P(mn + r))(X)|`.

3. **Meagre fixed points give group algebra embeddings.** Suppose the action is topologically free, and let
   `F(P ⋉ X)` be the group of homeomorphisms `g` of `X` with `g(x) = c_g(x)·x` for a locally constant
   `c_g : X -> P`. Then `c_g` is unique, `u_g = Σ_p χ_(U_p) v_p` with `U_p = { y : c_g(g^(-1) y) = p }`
   (so `g^(-1) y = p^(-1) y` on `U_p`) defines a group homomorphism `F(P ⋉ X) -> B^x`, and for every subgroup `G` in which
   each `g ≠ e` has a fixed-point set with empty interior, `k[G] -> B`, `g |-> u_g`, is injective. So part 2
   applies to `G`.

   The hypothesis cannot be dropped. If `g, h` have disjoint clopen supports, then `(1 - u_g)(1 - u_h) = 0`.

**Remark (general spaces).** If `X` is any compact totally disconnected `P`-space and `S` is finite, the
coefficients of `S` generate a `P`-invariant subalgebra `LC(Y, k)` for a subshift factor `Y` of `X`. Then part 1
holds with `Y` in place of `X`.

**Imports** (verbatim from D. D. Long and A. W. Reid, *Small Subgroups of
SL(3, Z)*, Exp. Math. 20(4) (2011) 412–425, DOI 10.1080/10586458.2011.565258).

- Presentation: "Γ is presented as ⟨x, y, z | z · x · z−1 = x · y,
  z · y · z−1 = y · x · y⟩."
- Prop. 2.1: "Deﬁne a map ρk : Γ −→ SL(3, Z[k]) by ρk(x) = Xk, ρk(y) = Yk,
  ρk(z) = Zk ... Then ρk is a homomorphism", with the matrices displayed in
  the claim.
- Theorem 4.1: "The group ρk(F) (and therefore ρk(Γ)) has ﬁnite index in
  SL(3, Z) for k = 0, 2, 3, 4, 5."

**Identities.** Work over `Q(k)`, where `k` is an indeterminate.

1. `lr_conjugacy.py` solves the linear system `C X_{-1-k} = Y_k C`,
   `C Y_{-1-k} = X_k^-1 C` for a general 3x3 matrix `C`. The solution space is
   `C = c · [[0, 1, -2], [1, 1, -1], [1, 0, 0]]` with `det C = c^3`. With
   `c = 1` both identities are re-checked with sympy's `simplify`, which
   returns the zero matrix (output `lr_conjugacy.out`: "check ... True").
2. `lr_conjugacy_gamma.py` searches words `f` in `F` with
   `C Z_{-1-k} C^-1 = Z_k^e ρ_k(f)`. It first tests numerically at
   `k = 6, 7, 11`. The unique survivor, `e = -1, f = y^-1`, is re-checked
   symbolically in `k` (output `lr_conjugacy_gamma.out`: "symbolic check e=-1
   f=Y: True").

All three identities have polynomial entries in `k`. Specializing `k` to any
integer preserves them. `C` is integral with determinant 1, so `C ∈ SL_3(Z)`.

**Consequences.**

- The images: `C ρ_{-1-k}(F) C^-1` is generated by `Y_k` and `X_k^-1`, so it
  equals `ρ_k(F)`. Adding `Z_k^-1 Y_k^-1`, whose product with `Y_k` is
  `Z_k^-1`, gives `ρ_k(Γ)`.
- The twist: `ρ_{-1-k}(w) = C^-1 ρ_k(s(w)) C` holds on the generators `x, y`,
  hence on all of `F`. Here `s` is the automorphism with `s(x) = y`,
  `s(y) = x^-1`, which is invertible with `s^-1(x) = y^-1`, `s^-1(y) = x`. So
  `ker(ρ_{-1-k}|F) = s^-1(ker ρ_k|F)`.
- Transfer: every property of Theorem 4.1 transfers along `k -> -1-k`, which
  maps `{0, 2, 3, 4, 5}` onto `{-1, -3, -4, -5, -6}`. The fixed-point-free
  involution `k -> -1-k` pairs `1` with `-2` and each `k >= 6` with
  `-1-k <= -7`.

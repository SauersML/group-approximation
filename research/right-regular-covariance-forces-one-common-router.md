Let `L` be a finite group, let `A=C_2^r` be a subgroup of `L` with
`[L:A]>=3`, and write
`lambda,rho` for the left and right regular actions on `ell^2(L)`.  Choose
sign functions

```text
f_1,...,f_s : L -> {+1,-1}
```

and characters `chi_j:A->{+1,-1}` such that

```text
f_j(a x)=chi_j(a) f_j(x)                             (RRC1)
```

and the joint projective left stabilizer is exactly `A`:

```text
{g in L : f_j(gx)/f_j(x) is constant in x for every j}=A.  (RRC2)
```

The functions can be chosen computably: include all sign functions constant
on left `A`-cosets, then include one extension to `L` of each coordinate
character of `A`.  Since the coset set has at least three points, the only
permutation which carries every sign function to itself up to a scalar sign
is the identity.  The invariant functions therefore force `g in A`, and the
character extensions read which `a in A` occurred.

Let `M_f` denote multiplication by `f`.  If a unitary `C` on

```text
ell^2(L) tensor H
```

commutes with every `rho(g) tensor I` and, for some sign vector
`epsilon=(epsilon_j)`, satisfies

```text
C (M_(f_j) tensor I) C^* = epsilon_j M_(f_j) tensor I,  (RRC3)
```

then there is a unique `a in A` with `chi_j(a)=epsilon_j` for all `j`, and

```text
C=lambda(a) tensor V                                  (RRC4)
```

for one unitary `V on H`.  In particular there are no coordinate-dependent
multiplicity gauges.

The statement is uniformly robust under external amplification.  There is a
computable constant `C_(L,f)<infinity` such that if the commutators in `(RRC3)`
and with a fixed generating set of `rho(L)` have normalized Hilbert--Schmidt
norm at most `eta`, then, whenever the indicated joint character is in the
image of `A`,

```text
inf_(V unitary) ||C-lambda(a) tensor V||_2
 <= C_(L,f) eta.                                      (RRC5)
```

The constant depends only on the fixed finite packet, never on `dim(H)`.

This is the common-router part required by the Fanizza compiler.  It does not
yet control additional nonlinear lookup constants lying outside the finite
algebra generated by the right reference action and the multiplier packet.

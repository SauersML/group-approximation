Notation as on the target. Put `W = U`, `k = 1`, `H = Stab_U(χ)` with `χ = χ_[0]`.

1. **`W` finitely presented, `H` finitely generated.** The first by
   `leavitt-unit-group-finitely-presented`, the second by the premise
   `leavitt-unit-clopen-indicator-stabilizer-is-fg`.
2. **The orbit.** Over `F_2` every nonzero `f ∈ M` is the indicator of the nonempty
   clopen set `f^(-1)(1)`, so `U·χ = {χ_A : A ∈ 𝒪}` for a `U`-invariant family `𝒪` of
   nonempty clopen sets. The copy of `V` in `U`
   (`leavitt-cylinder-swaps-generate-thompson-in-el`) acts on `M` by precomposition
   with prefix-replacement homeomorphisms: a cylinder swap unit moves `f` from `[σ]`
   to `[ρ]` and back and fixes the rest. `V` is transitive on ordered partitions of `C`
   into any fixed number of nonempty clopen sets: subdivide cylinders until the parts
   have matching numbers of cylinders, then map cylinders to cylinders. Hence `𝒪`
   contains every proper nonempty clopen set, and `F_2[U/H] -> M`,
   `e_(uH) -> u·χ`, is surjective because indicators of proper nonempty clopens span
   `M`.
3. **Finitely many double cosets.** `H \ U / H` corresponds to the `U`-orbits on
   `𝒪 × 𝒪`. The `V`-orbit of a pair `(A, B)` of nonempty clopens is determined by
   which of `A ∩ B`, `A \ B`, `B \ A`, `C \ (A ∪ B)` are empty (transitivity on ordered
   partitions), so there are at most 16 `V`-orbits, and each `U`-orbit is a union of
   them.
4. **The kernel `K` is finitely generated.** Identify `F_2[U/H]` with `F_2[𝒪]`,
   `e_A -> χ_A`. For disjoint nonempty `A, B` with `A ⊔ B ∈ 𝒪` put
   `r(A,B) = e_A + e_B + e_(A ⊔ B) ∈ K`.
   - **They span `K`.** Let `Σ_q e_(A_q) ∈ K`. Let `P_1, ..., P_r` be the atoms of the
     finite Boolean algebra generated by the `A_q`. If `r = 1` every `A_q = C` and the
     sum has an even number of equal terms, so it is `0`. If `r >= 2`, every nonempty
     union of atoms other than `C` is a proper nonempty clopen, hence in `𝒪`. Splitting
     one atom off at a time, `e_(A_q) ≡ Σ_(P_j ⊆ A_q) e_(P_j)` modulo the `r(A,B)`. So
     the sum is congruent to `Σ_j c_j e_(P_j)` with `Σ_j c_j χ_(P_j) = 0`; the atoms are
     disjoint and nonempty, so every `c_j = 0`.
   - **Finitely many generate.** `V` maps `r(A,B)` to `r(vA, vB)`. By transitivity the
     triples `(A, B, C \ (A ⊔ B))` form one `V`-orbit when `A ⊔ B ≠ C`, and the pairs
     with `A ⊔ B = C` form one more. So `K` is generated as a module by at most two
     elements, `r([00],[01])` and, if `C ∈ 𝒪`, `r([0],[1])`.
5. **Conclusion.** `M ≅ F_2[U/H]/K` with the hypotheses of
   `orbit-finite-quotient-module-extensions-are-fp`, so `M ⋊ U` is finitely presented.

"CE" means Connes embeddable.  Cohomologous cocycles give isomorphic twisted
group von Neumann algebras (`u_g -> b(g)u_g`), so CE depends only on the
class.  Standard facts used: CE passes to von Neumann subalgebras, matrix
amplifications, corners, finite direct sums and tensor products.  A tracial
algebra generated by unitaries `u_g` with `u_g u_h = omega(g,h) u_(gh)` and
`tau(u_g)=delta_(g,e)` is CE iff it has **projective microstates**: for every
finite `F` and `eps>0` there are `d` and unitaries `U_g in M_d` (`g in F`) with
`||U_g U_h - omega(g,h) U_(gh)||_2 < eps` (all of `g,h,gh` in `F`) and
`|tr U_g - delta_(g,e)| < eps`.  Here `||.||_2` and `tr` are normalized.  The
relations reduce every word moment to a single `u_g` up to a phase, so
approximate relations plus approximate traces give approximate `*`-moments,
and conversely.

**HS1.**  *Subgroup:* `u_g -> u_g (x) v_g` embeds `L_(omega eta)` trace-
preservingly into `L_omega (x) L_eta`, and complex conjugation handles
`omega^(-1)`.  *Closedness on `T_0`:* `H^2(Gamma,T)=Hom(H_2(Gamma,Z),T)` since
`T` is divisible.  With `H_2 = Z^b + (finite)`, fix integral cocycles
`x_1..x_b` whose classes pair with a basis of `H_2/torsion` by an invertible
rational matrix.  Then `theta -> [e(sum theta_i x_i)]` maps `R^b` onto `T_0`.
If `theta^n -> theta` with each `e(theta^n . x)` in `E_CE`, then on each fixed
finite window the integers `x_i(g,h)` are bounded.  So
`|e(theta^n . x)(g,h) - e(theta . x)(g,h)| -> 0` uniformly on the window, and
microstates for `theta^n` become microstates for `theta` with vanishing error
(diagonal sequence).  A closed subgroup of a torus is a Lie subgroup; its
identity component is a subtorus whose Lie algebra meets the lattice in a
full-rank sublattice, hence is rational.

**HS2.**  `L_(res omega)(Lambda) subseteq L_omega(Gamma)` is trace-preserving,
which gives `=>`.  For `<=`, write `Gamma = disjoint union t_j Lambda` (`m`
cosets) and `g t_j = t_(sigma_g(j)) h_j(g)` with `h_j(g) in Lambda`.  Put
`M=L_omega(Gamma)` and `N=L_(res omega)(Lambda)`.  `M` is a right Hilbert
`N`-module with orthonormal basis `u_(t_j)`, and left multiplication gives a
normal `*`-homomorphism `Phi : M -> M_m(N)`:

```text
Phi(u_g)_(sigma_g(j), j) = omega(g,t_j) omega(t_(sigma_g(j)), h_j(g))^(-1) v_(h_j(g)).
```

The normalized trace of `Phi(u_g)` is `(1/m) sum_(j : sigma_g(j)=j) tau_N(v_(t_j^(-1) g t_j))`
up to phases, which equals `delta_(g,e)`.  So `Phi` is trace-preserving and
injective, and CE of `N` gives CE of `M_m(N)`, hence of `M`.

**HS3 (tensor induction).**  With the transversal above, define on cochains

```text
TI(omega)(g,g') = prod_j omega( h_(sigma_(g')(j))(g), h_j(g') ).
```

Given `U_h` (`h in F_Lambda`) in `M_d`, set
`W_g = P_(sigma_g) o (U_(h_1(g)) (x) ... (x) U_(h_m(g)))` on `(C^d)^(x m)`,
where `P_sigma` moves slot `j` to slot `sigma(j)`.  Using
`h_j(g g') = h_(sigma_(g')(j))(g) h_j(g')`,

```text
W_g W_(g') = P_(sigma_g sigma_(g')) (x)_j U_(h_(sigma_(g')(j))(g)) U_(h_j(g')).
```

- **Cocycle.**  If `U` is an exact `omega`-projective representation (for
  example the twisted regular one), then `W` is an exact projective
  representation with multiplier `TI(omega)`, so `TI(omega)` is a cocycle.
- **Classes.**  Replacing `omega` by `omega . delta b` multiplies `W_g` by
  `prod_j b(h_j(g))`, changing `TI(omega)` by a coboundary.  So `TI` descends
  to a continuous homomorphism of cohomology.  It maps `e(x)` to
  `e(sum_j x(...))`, so it preserves integral classes; changing the transversal
  conjugates `W`.
- **Defect.**  For unitaries, normalized HS norms multiply on tensors, and
  telescoping gives `||(x)_j A_j - (x)_j B_j||_2 <= sum_j ||A_j - B_j||_2`.  So
  microstates with defect `eps` give defect `<= m eps` for `TI(omega)`, on a
  window `F_Gamma` whose `h_j` values lie in `F_Lambda`.
- **Trace.**  On basis vectors,

  ```text
  tr_(d^m)(P_sigma (x)_j A_j) = prod_(cycles c of sigma) d^(1-|c|) tr_d(A_(c_|c|) ... A_(c_1)).
  ```

  Let `g != e`.  If `sigma_g` has a cycle of length `>= 2`, then
  `|tr W_g| <= 1/d`.  Otherwise every factor is `tr U_(t_j^(-1) g t_j)` with
  `t_j^(-1) g t_j != e`, so it has modulus `< eps`.
- **Dimension.**  Because `Lambda` is infinite, microstates on windows `F`
  containing `F^(-1)F` force `d -> infinity`.  The `U_g` (`g in F`) are nearly
  orthogonal in `(M_d, tr)`, so `d^2 >= |F|/2` for small `eps`.

Hence `TI` sends CE twists to CE twists.

**HS4.**  An isomorphism `alpha` gives `u_g -> u_(alpha(g))`, an isomorphism
`L_(alpha^* omega) = L_omega`.

**HS5.**  `c_g` is an isomorphism between finite-index subgroups.  By HS2
(forward direction), HS4 and HS3, `T_g` maps `E_CE(Gamma)` into itself.
`T_g` is a continuous homomorphism, so it maps the connected subgroup `E^0`
into a connected subgroup of `E_CE(Gamma)` containing `0`, that is into `E^0`.
Differentiating gives `T_g W subseteq W`.

**HS6.**  For integral `x` and `n >= 1`, `L(E_x^(n))` splits over the central
characters of `Z/n` as the finite direct sum of `L_(e(k x/n))(Gamma)`,
`k = 0..n-1`.  So `E_x^(n)` is hyperlinear iff all these sectors are CE.
- If `x in W`, then `exp(R x) subseteq E^0 subseteq E_CE` and all sectors are
  CE.
- If `x notin W`, the circle `{e(t x)}` is a connected subgroup not inside
  `E^0`, so it is not inside `E_CE`.  `E_CE cap circle` is then a closed proper
  subgroup, hence finite cyclic, so some `e(k x/n)` is non-CE.
- `W` is rational and spanned by the integral classes it contains, which gives
  both directions of HS6.

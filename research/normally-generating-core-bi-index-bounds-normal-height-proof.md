**Intermediate subgroups.** If `S <= K <= Gamma` then `K = S K S` is a union
of `(S,S)`-double cosets and contains the trivial double coset `S`. A strict
inclusion `K < K'` of such subgroups adds at least one double coset.
Therefore a strictly monotone chain of intermediate subgroups has at most `r`
members.

**Key step.** Let `N <= N'` be proper normal subgroups with `NS = N'S`.
Since `N` is normal, `NS` is a subgroup. Because `N <= N'`, Dedekind's modular
law gives

    N' ∩ NS = N (N' ∩ S) = N · 1 = N ,

using `N' ∩ S = 1`. But `N' <= N'S = NS`, so `N' = N' ∩ NS = N`.

Hence along a strictly monotone chain `N_1 < ... < N_m` of proper normal
subgroups, the subgroups `N_i S` are intermediate and strictly monotone
(`N_i S <= N_{i+1} S`, with equality excluded by the key step). So `m <= r`.
This holds for ascending and descending chains alike.

**Clause 1.** Ascending and descending chains are bounded. Let `N` be proper
normal and choose `x_1, x_2, ...` in `N` with
`x_i notin <<x_1, ..., x_{i-1}>>`. The normal closures form a strictly
ascending chain of proper normal subgroups, all contained in `N`, starting at
`<<empty>> = 1`. So the process stops after at most `r - 1` choices, and at
that point `N = <<x_1, ..., x_k>>`.

**Clause 2.** Assume `Gamma != 1`, since otherwise there is nothing to prove.
Then `1` is a proper normal subgroup. Extend `1` upward by proper normal
subgroups as long as possible. By the bound this stops at
some `M` with no proper normal subgroup strictly above it, so `Gamma/M` is
simple. `M ∩ S = 1`, so `S -> Gamma/M` is injective. If `Gamma` is finitely
presented, then `Gamma/M` is finitely presented, since `M` is finitely
normally generated by clause 1.

**Clause 3.** A chief series `1 = C_0 < C_1 < ... < C_k = Gamma` consists of
the `k` proper normal subgroups `C_0, ..., C_{k-1}`, so `k <= r`. Chief
series exist: start from `1`, and repeatedly adjoin a minimal normal subgroup
strictly above the current term. Minimal ones exist by the minimal condition,
and the process stops by the bound.

**Clause 4.** If `Gamma` is nonabelian then `Z = Z(Gamma)` is proper. Every
subgroup of `Z` is normal in `Gamma` and proper. So `Z` is an abelian group
satisfying both the maximal and minimal conditions on subgroups. Max makes
`Z` finitely generated, `Z = Z^a x F`. Min excludes a `Z` factor, since
`2^k Z` is a strictly descending chain. So `Z` is finite.

∎

## Where the hypotheses are consumed

`N' ∩ S = 1` is used exactly once, in the key step. Finiteness of `r` is used
exactly once, in the chain bound for intermediate subgroups. Finite
presentation and property (T) are not used at all, except to transport them to
`Gamma/M` in clause 2.

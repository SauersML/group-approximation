Notation is as in the claim. All presentations are finite.

Two standard facts about aspherical complexes are used throughout.

1. The Lyndon identity theorem (`non-proper-power-one-relator-complexes-are-aspherical`): `X` is
   aspherical, so `χ(G) = 2 - |S|`.
2. A subcomplex of an aspherical 2-complex is aspherical. Hence `X_H` and its core `C` are
   aspherical, `π_1 C = H`, and `χ(H) = χ(C) = 1 - r + n`.

**Collapsing a tree.** Collapsing a maximal tree of `C^1` gives a homotopy equivalence
`C → R = ⟨B_0 | u_1, …, u_n⟩`. It is cellular, bijective on 2-cells, and makes `B_0` a free basis
of `F`. Replacing `B_0` by any free basis `B`, and each `u_j` by a cyclic conjugate or its inverse,
changes neither the group `H` nor the elements `φ(u_j)` up to conjugacy and inversion. So all
statements may be checked on the rose presentation `H = ⟨B | u_1, …, u_n⟩`.

## 1. Proof of (E1)

Let `Y = {y_1, …, y_m}` and `B' = B ∖ Y`. Substitute `x = φ(x)` for `x ∈ B'` in
`P_{B'} = ⟨B, S | u_1..u_n, x = φ(x) (x ∈ B')⟩`, which removes the generators `B'`. This gives

`P_{B'} ≅ F(S ∪ Y) / ⟨⟨v_1, …, v_n⟩⟩`, where `v_j = λ(u_j)`.

Here `λ: F → F(S ∪ Y)` is `φ` on `B'` and the identity on `Y`. Now define
`π: F(S ∪ Y) → G` to be the quotient map on `S` and `y ↦ φ(y)` on `Y`. Then

`N = ker π = ⟨⟨ w, y_k^{-1} φ(y_k) (1 ≤ k ≤ m) ⟩⟩`,

since killing `y_k^{-1}φ(y_k)` eliminates `y_k` and leaves `⟨S | w⟩`. Let `M = ⟨⟨v_1, …, v_n⟩⟩`.

**M ⊆ N.** `π(v_j)` is the image of `φ(u_j)`, and `φ(u_j)` is conjugate to `w^{±1}`, so
`π(v_j) = 1`.

**N ⊆ M.**

- *Base.* `u_0` involves no `y_l`, so `v_0 = φ(u_0)`, which is conjugate to `w^{±1}`. Hence
  `w ∈ M`.
- *Induction.* Suppose `w ∈ M` and `y_l ≡ φ(y_l)` mod `M` for all `l < k`. Write
  `u_k ∼ y_k^{ε} c` (cyclic conjugate, `ε = ±1`) with `c` a word in `B ∖ {y_k, …, y_m}`. Then:
  - `v_k ∼ y_k^{ε} λ(c)`, and `λ(c) ≡ φ(c)` mod `M`, since `λ` and `φ` differ only on
    `y_1..y_{k-1}`. So `y_k^{ε} ≡ φ(c)^{-1}` mod `M`.
  - `φ(u_k) ∼ φ(y_k)^{ε} φ(c)` lies in `⟨⟨w⟩⟩ ⊆ M`. So `φ(y_k)^{ε} ≡ φ(c)^{-1}` mod `M`.
  - Therefore `y_k ≡ φ(y_k)` mod `M`.

After step `m`, all generators of `N` lie in `M`. So `M = N`, and `P_{B'} → G` is an isomorphism.

**The inclusion.** The map `H → P_{B'}` sends `x ↦ φ(x)` for `x ∈ B'` and `y ↦ y`. Composed with
`π` it becomes `φ_*: H → G`, which is the inclusion `H ≤ G`. So `P_{B'}` is a relative
presentation `⟨H, T | R⟩` of the pair, with `T = S` and `R = {x = φ(x) : x ∈ B'}`.

**Count.** `|R| - |T| = (r - m) - |S|`, and `χ(G) - χ(H) = (2 - |S|) - (1 - r + n)`, so

`ρ = (r - m - |S|) - (1 - |S| + r - n) = n - 1 - m`.

The relative defect `ρ(H,G)` is the minimum over all relative presentations, so
`ρ(H,G) ≤ n - 1 - m(C)`. For a full chain, `ρ = 0`, and Theorem 2 of
`relative-realization-is-relative-efficiency` gives `RP(H,G)`.

The case `m = 0` is Theorem 3 of that node. □

**Calibration.** Take `G = Z^2 = ⟨a,b | [a,b]⟩` and `H` of index 2 (for instance `⟨a^2, b⟩`).
The core is the whole double cover, with `n = 2` and `ρ(H,G) = 1`, so (E1) must give `m(C) = 0`.
It does: `C` is the torus double cover, and `H_2(C) = Z` is generated by its fundamental class
`e_1 + e_2`. That class has support 2, so (E4) forces `m(C) = 0`, and (E1) claims nothing false.
Free `H` (`n = 0`, no statement) and `H = G` (`n = 1`, `m = 0`, `ρ = 0`) are also consistent.

## 2. Proof of (E2)

Take a full chain, so `n = m + 1` and the cells are `e_0, …, e_m`.

- `y_m` occurs in no `u_j` with `j < m`: for `j ≥ 1` this is the chain condition, and `u_0`
  involves no `y`.
- `y_m` occurs exactly once in `u_m`.

So `u_m` is a free face. The Tietze move that deletes the generator `y_m` together with `u_m`
gives `H ≅ ⟨B ∖ {y_m} | u_0, …, u_{m-1}⟩`, and the remaining words still form a full chain.
Repeating downward gives `H ≅ ⟨B'' | u_0⟩` with `B'' = B ∖ Y`, and `F(B'')` is a free factor of
`F`. By the chain condition, `φ(u_0)` is conjugate to `w^{±1}`.

**Converse.** Let `H ≅ F(B'')/⟨⟨ū⟩⟩`, where `φ: F(B'') → F(S)` is injective, `φ(ū) ∼ w^{±1}`,
and the induced map to `G` is injective.

- *Asphericity.* `ū ≠ 1`, and `ū` is not a proper power: `ū = v^k` would make `φ(ū) = φ(v)^k`
  conjugate to `w^{±1}`, which is not a proper power. So `⟨B'' | ū⟩` is aspherical (Lyndon), and
  `χ(H) = 2 - |B''|`.
- *Presentation.* `⟨H, S | x = φ(x) (x ∈ B'')⟩ = ⟨B'', S | ū, x = φ(x)⟩ ≅ ⟨S | φ(ū)⟩ = G`, and
  `H` maps by the given inclusion.
- *Count.* `|R| - |T| = |B''| - |S|` and `χ(G) - χ(H) = |B''| - |S|`, so `ρ = 0` and `RP(H,G)`
  holds.

This is the setting of (3b) of `two-cell-injective-maps-realize-relative-eg-pairs`, with `Γ` the
rose on `B''` and `u = ū`, after conjugating `ū` so that its label is `w`. That node realizes it by
a 2-cell-injective map, and the Tietze count above realizes it directly. □

## 3. Proof of (E3)

Take `n = 2`, and let `y ∈ B` occur exactly once in `u_1`, with `u_1 ∼ y^ε c` and `c ∈ F(B')`.

**The presentation.** As in §1, `P_{B'} ≅ ⟨S, y | λ(u_0), λ(u_1)⟩`. Here `λ(u_1) ∼ y^ε φ(c)`, and
`y` occurs nowhere else in `λ(u_1)`. So the Tietze move that eliminates `y` via
`y = φ(c)^{-ε}` gives `P_{B'} ≅ ⟨S | ψ(u_0)⟩`, where `ψ` is `λ` followed by that substitution.
That is, `ψ = φ` on `B'` and `ψ(y) = φ(c)^{-ε}`. Under this isomorphism the natural map
`P_{B'} → G` is the identity on `S`.

**Well-definedness.** `ψ(u_0) ∈ ⟨⟨w⟩⟩`. To see this, note that `φ(y)^ε φ(c)` is conjugate to
`φ(u_1)`, so `φ(y) ≡ φ(c)^{-ε}` mod `⟨⟨w⟩⟩`. Hence `ψ(u_0) ≡ φ(u_0)` mod `⟨⟨w⟩⟩`.

**The test.** So `⟨S | ψ(u_0)⟩ → ⟨S | w⟩` is an isomorphism iff `⟨⟨ψ(u_0)⟩⟩ = ⟨⟨w⟩⟩`. By Magnus'
conjugacy theorem for one-relator normal closures in a free group, this holds iff `ψ(u_0)` is
conjugate to `w^{±1}`. This is decidable: cyclically reduce both words and compare cyclic words.

**Defect.** `|R| - |T| = (r - 1) - |S|` and `χ(G) - χ(H) = 1 - |S| + r - 2`, so `ρ = 0`.

**When the test holds.** Eliminating `y` together with `u_1` from the rose presentation of `H`
gives `H ≅ ⟨B' | u_0'⟩`, where `u_0' = u_0[y := c^{-ε}]`. Then
`φ(u_0') = ψ(u_0) ∼ w^{±1}`, and `φ` restricted to `F(B')` is injective. So `H` lies in the
w-one-relator class of (E2).

**When the test fails.** `⟨S | ψ(u_0)⟩` is a one-relator group that maps onto `G` with nontrivial
kernel, and this `P_{B'}` does not present `G`. □

This settles every single-occurrence elimination for `n = 2`. What remains for `n = 2` is only
the non-triangular case, where no basis element occurs exactly once in either word. There the
two-generator-over-`S` presentation `⟨S, y | λ(u_0), λ(u_1)⟩` has to be compared with `G`
directly.

## 4. Proof of (E4)

**Chain complex.** Let `M` be a right `ZH`-module. By the tree collapse, `C_2(C; M) = M^n` with
the cells as basis, and the 2-cycles are the rows `a ∈ M^n` with `a J = 0`. Here `J` is the
`n × r` Fox matrix over `ZH`, with entries the images of `∂u_j/∂x` for `x ∈ B`. The tree collapse
is the identity on 2-chains and induces an isomorphism on `H_2 = Z_2`, so the cycle submodule of
`M^n` is the same for `C` and for the rose.

**Invariance of supports.** Three operations do not change which cells a cycle is supported on.

- *Change of free basis `B → B~`.* By the chain rule, `J~ = J Q`, where `Q` is the Fox Jacobian of
  the change of basis. `Q` is invertible over `ZF`, hence over `ZH`.
- *Conjugating `u_j` by `g`.* In `ZH`, `∂(g u g^{-1})/∂x = g ∂u/∂x`, because `u = 1` in `H`. This
  multiplies row `j` by the unit `g`.
- *Inverting `u_j`.* `∂(u^{-1})/∂x = -∂u/∂x` in `ZH`. This multiplies row `j` by `-1`.

So `J~ = D J Q` with `D` diagonal with unit entries `±h`. Hence `a` is a cycle for `J` iff `a D^{-1}`
is a cycle for `J~`, and `a` and `a D^{-1}` have the same support. So it suffices to compute in
the chain basis `B`, with each `u_k` written in its chain form.

**Triangularity.** For the chain words we have:

- `∂u_j/∂y_k = 0` for `j < k`, since `y_k` does not occur in `u_j` (this includes `j = 0`);
- `∂u_k/∂y_k = ±A_k` for a prefix `A_k` of `u_k`, since `y_k` occurs once in `u_k`.

In `ZH`, `±A_k` is a unit `±h_k`. Since the chain is full, these are all the rows. Let `a` be a
cycle.

- The `y_m`-column of `a J` is `a_m (±h_m) = 0`, so `a_m = 0`.
- Inductively, if `a_j = 0` for all `j > k`, then the `y_k`-column of `a J` is `a_k (±h_k)`, so
  `a_k = 0`.

Hence `a = a_0 e_0`.

**Contrapositive.** A cycle that is nonzero on two cells rules out a full chain, so
`m(C) ≤ n - 2`. By (E1) and Theorem 3, the core route then leaves `ρ ≤ n - 1 - m(C)` with
`m(C) ≤ n - 2`, and no core elimination on `C` reaches defect 0. The cycle module is computable,
for instance over `Z` or over finite quotients of `H`. □

## 5. Proof of (E5)

Let `I = I_{G/H}`, and choose a projective resolution `0 → P_1 → P_0 → I → 0`, which exists since
`pd I ≤ 1`.

**The long exact sequence.** Apply `H_*(G; -)` to `0 → I → Z[G/H] → Z → 0`, using Shapiro's
lemma `H_*(G; Z[G/H]) = H_*(H)`. This gives

`H_2(G;I) → H_2 H → H_2 G → H_1(G;I) → H_1 H → H_1 G`.

**Freeness.** `H_2(G;I) = 0`, and `H_1(G;I) = ker(Z ⊗_G P_1 → Z ⊗_G P_0)`. Each `Z ⊗_G P_i` is
a direct summand of a free abelian group, and a subgroup of a free abelian group is free abelian.
So `H_1(G;I)` is free abelian. Exactness at `H_1 H` gives

`ker(H_1 H → H_1 G) ≅ H_1(G;I) / im(H_2 G)`.

(The vanishing of `H_2(G;I)` also recovers the `H_2`-injectivity of
`relative-eg-pair-base-meets-its-conjugates-in-free-groups`.)

**Degree-one case.** Here `H_2 H → H_2 G` is onto, so `H_2 G → H_1(G;I)` is zero, and
`ker(H_1 H → H_1 G) ≅ H_1(G;I)` is free abelian. Since `w ∈ [F(S),F(S)]`, the image of `H_1 H`
lies in `H_1 G = Z^{|S|}`, which is free. So `H_1 H` is an extension of a free abelian group by a
free abelian group, hence torsion-free.

**Two-cell normal form.** Let `n = 2`. Then `H_1(C) = H_1(H) = Z^r / L` with
`L = ⟨[u_0],[u_1]⟩`.

- `Z^r / L` is torsion-free, so `L` is a direct summand.
- `H_2(C) = ker(Z^2 → Z^r)` equals `H_2(H)`, which is `≅ H_2(G) = Z`: the map is injective by
  the vanishing of `H_2(G;I)` and onto by degree one. So `L` has rank 1, say `L = Zp`, with
  `[u_0] = a p`, `[u_1] = b p`, and `gcd(a,b) = 1` because the two classes generate `L`.
- The kernel `H_2(C)` is generated by `b e_0 - a e_1`.
- The map `H_2(C) → H_2(X) = Z` sends `e_j ↦ ε_j`, where `ε_j = ±1` is the orientation of the
  immersion on `e_j`. Degree one gives `ε_0 b - ε_1 a = ±1`.

By (E4), a full chain, which for `n = 2` is any single-occurrence elimination, needs the
fundamental class to be supported on one cell, that is, `ab = 0`. The constraints
(`gcd = 1`, `ε_0 b - ε_1 a = ±1`) allow `ab ≠ 0`, for example `(a,b) = (1,2)` with
`ε_0 = ε_1 = 1`. So torsion-freeness of `H_1(H)` does not imply eliminability. □

## 6. Scope

**What is ruled out.** Every reduction of the core presentation `Y_1` to defect 0 that keeps the
generators `S` and removes core relations `x = φ(x)` along a triangular (single-occurrence) chain.
Such a reduction succeeds only on w-one-relator subgroups (E2, E3), which realize by one Tietze
move. It is impossible on any core carrying a 2-cycle that uses two cells (E4).

**What is not ruled out.**

- Non-triangular eliminations.
- Presentations with generators beyond `S`.
- Cores other than the minimal one, since `m(C)` may depend on `C`.

For `n = 2` the whole remaining question is whether some basis element `y`, occurring several
times, gives `⟨S, y | λ(u_0), λ(u_1)⟩ ≅ G` via `y ↦ φ(y)`.

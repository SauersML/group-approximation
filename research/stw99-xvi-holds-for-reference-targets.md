Let `D` be a strongly self-absorbing C\*-algebra.

1. (`E = O_2`)  If `[1_D] = 0` in `K_0(D)` — in particular if `D` has
   the ordered `K`-theory of `O_2` — then `D ≅ O_2`.  No
   embeddability or quasidiagonality hypothesis is needed.
2. (`E = Q ⊗ O_∞`)  If `D` is unitally `(Q ⊗ O_∞)_ω`-embeddable and
   has the ordered `K`-theory of `Q ⊗ O_∞` (`K_0 = Q` with the
   all-positive order, `[1] = 1`, `K_1 = 0`), then `D ≅ Q ⊗ O_∞`.
3. (`E = Q`)  If `D` is quasidiagonal and has the ordered `K`-theory
   of `Q` (`K_0 = Q` strictly ordered, `[1] = 1`, `K_1 = 0`), then
   `D ≅ Q`.

So STW Problem XVI is settled affirmatively, with no UCT input, for
the three reference targets; the surviving cases are exactly
`E ∈ {Z, O_∞, M_{J^∞}, M_{J^∞} ⊗ O_∞}` with `J` a proper set of
primes, where the obstruction is `J`-adaptedness of matrix models
(for the second absorption direction) rather than divisibility.

Notation is as in the target. A *brick* of `C^I` (`I` a finite index set) is
`Π_{j∈I} C(u_j)`. An element of `nV` is a bijection `g` of `C^n` with a *table*: a finite
brick partition `{B_i}` such that `g` maps each `B_i = Π_j C(u_j)` onto `B'_i = Π_j C(v_j)` by
`(u_j z_j)_j ↦ (v_j z_j)_j`. The bricks `B'_i` then partition `C^n`.

**Imported facts on property (T)** (Bekka–de la Harpe–Valette, *Kazhdan's Property (T)*,
Cambridge 2008; verbatim as transcribed in `pgl3-nonarchimedean-lattices-property-t-citation`):
- (T1) "Theorem 1.3.4 Let G1 and G2 be topological groups, and let ϕ : G1 → G2 be a continuous
  homomorphism with dense image. If G1 has Property (T), then G2 has Property (T)." So every
  quotient of a discrete Kazhdan group is Kazhdan.
- (T2) "Theorem 1.7.1 Let G be a locally compact group, and let H be a closed subgroup of G such
  that G/H has a finite invariant regular Borel measure. The following are equivalent: (i) G has
  Property (T); (ii) H has Property (T)." For a finite-index subgroup of a discrete group the
  counting measure on `G/H` is finite and invariant, so finite-index subgroups of Kazhdan groups
  are Kazhdan.
- (T3) `discrete-kazhdan-groups-are-finitely-generated`.
- (V) `thompson-v-has-haagerup-property`: every Kazhdan subgroup of `V` is finite.

## Theorem 1

**Step 1.1 (base).** `ρ` is a homomorphism, so `ρ(K) ≅ K/(K ∩ C(X,Λ))` is Kazhdan by (T1).
This is item 1.

**Step 1.2 (kernel).** Suppose `ρ(K)` is finite. Then `K_0 = K ∩ ker ρ` has index `|ρ(K)|` in
`K`, so `K_0` is Kazhdan by (T2) and finitely generated by (T3), say by `f_1, …, f_r`.
- Each `f_k` is locally constant on the compact space `X`, so it takes finitely many values,
  each on a clopen set. Let `X_1, …, X_N` be the nonempty atoms of the common refinement of
  these finitely many clopen partitions.
- Every element of `K_0` is a pointwise product of the `f_k^{±1}`, so it is constant on each
  `X_i`.
- Choose `x_i ∈ X_i` and put `ev(f) = (f(x_i))_i ∈ Λ^N`. Multiplication in `C(X,Λ)` is pointwise,
  so `ev` is a homomorphism. It is injective, because `f ∈ K_0` is determined by its constant
  values on the `X_i`.
- Each coordinate `π_i ∘ ev (K_0)` is a quotient of `K_0`, so it is Kazhdan by (T1).

This is item 2.

**Step 1.3 (iff).**
- *(⇐)* `h ↦ (1,h)` embeds `H`. `λ ↦ (c_λ, 1)`, with `c_λ` the constant map, embeds `Λ`,
  because constants are locally constant and `H` fixes them.
- *(⇒)* Let `K` be infinite and Kazhdan. If `ρ(K)` is infinite, it is an infinite Kazhdan
  subgroup of `H` (Step 1.1). Otherwise Step 1.2 applies. If every coordinate image
  `π_i ∘ ev (K_0)` were finite, `K_0` would embed in a finite product of finite groups, and
  `K` would be finite. So some coordinate image is an infinite Kazhdan subgroup of `Λ`.

## Theorem 2

Write points of `C^n` as `(x,y)` with `x = pr_J(·) ∈ C^J`, `y ∈ C^{J^c}`. Up to reordering
coordinates, a brick of `C^n` is `P × R` with `P` a brick of `C^J` and `R` a brick of `C^{J^c}`.

**Step 2.0 (brick lemma).** Let `k : C^I → C^I` be a bijection, and let finitely many bricks
`P_i` cover `C^I` so that `k|_{P_i}` is a prefix replacement onto a brick. Then `k ∈ |I|V`.
- Let `D` bound all word lengths in the `P_i`, and take the partition of `C^I` into the
  cylinders `Π_j C(t_j)` with `|t_j| = D`.
- Each such cylinder lies in some `P_i`: a point of it lies in some `P_i`, and the words of
  `P_i` are prefixes of the `t_j`.
- On that cylinder, `k` is `(u_j s_j z_j) ↦ (v_j s_j z_j)`, a prefix replacement onto a brick.
- The images are pairwise disjoint because `k` is injective, and they cover because `k` is
  surjective. So they form a table, and `k ∈ |I|V`.

**Step 2.1 (`Fib_J` is a group; preserving fibres suffices).** `pr_J` is surjective, so `h = h_g`
is determined by `g`.
- `h_{gg'} = h_g h_{g'}`, and `pr_J ∘ g^{-1} = h_g^{-1} ∘ pr_J`. So `Fib_J` is a subgroup and
  `g ↦ h_g` is a homomorphism.
- Conversely, let a *subgroup* `K ≤ nV` map every fibre of `pr_J` into a fibre. Then
  `h_g := pr_J ∘ g ∘ s`, with `s(x) = (x, 0^ω…)` a continuous section, is a continuous map with
  `pr_J ∘ g = h_g ∘ pr_J`. It satisfies `h_{gg'} = h_g h_{g'}` and `h_1 = id`, so `h_g` is a
  homeomorphism with inverse `h_{g^{-1}}`. Hence `K ≤ Fib_J`.

**Step 2.2 (`h_g ∈ mV`).** Take a table `P_i × R_i → P'_i × R'_i` of `g ∈ Fib_J`. For
`x ∈ P_i`, `h_g(x) = pr_J g(x,y)`, which is the prefix replacement `P_i → P'_i` applied to `x`.
The `P_i` cover `C^J`, so `h_g ∈ mV` by Step 2.0.

**Step 2.3 (fibre maps).** Let `D` bound the word lengths of all `P_i`. For `x ∈ C^J` let
`P(x)` be the depth-`D` cylinder of `C^J` containing `x`.
- `I(x) = { i : x ∈ P_i }` equals `{ i : P_i ⊇ P(x) }`, so it depends only on `P(x)`.
- For fixed `x`, each `(x,y)` lies in exactly one `P_i × R_i`, and then `i ∈ I(x)`. So the
  bricks `R_i` (`i ∈ I(x)`) partition `C^{J^c}`.
- Define `G_x(y) = pr_{J^c} g(x,y)`. On `R_i`, `i ∈ I(x)`, it is the prefix replacement
  `R_i → R'_i`. So `x ↦ G_x` is constant on each `P(x)`, that is, locally constant.
- `g` maps the fibre over `x` into the fibre over `h_g x`, and `g^{-1} ∈ Fib_J` maps the fibre
  over `h_g x` into the fibre over `x`. The composites are identities, so `G_x` is a bijection of
  `C^{J^c}`. By Step 2.0, `G_x ∈ (n−m)V`.

**Step 2.4 (the isomorphism).**
- *`Φ` lands in `Fib_J`.* Let `(f,h) ∈ C(C^J,(n−m)V) ⋊ mV`. Take a table `Q_i → Q'_i` of `h`.
  `f ∘ h` is locally constant, so by compactness refine the `Q_i` into bricks `Q` on which
  `f ∘ h` is a constant `γ_Q ∈ (n−m)V`, with table `S_{Q,k} → S'_{Q,k}`.
  - On `Q × S_{Q,k}`, `Φ(f,h)` is the prefix replacement onto `h(Q) × S'_{Q,k}`, where `h(Q)` is a
    brick because `Q ⊆ Q_i`.
  - These domain bricks partition `C^n`. `Φ(f,h)` is a bijection: its inverse is
    `(x,y) ↦ (h^{-1}x, f(x)^{-1} y)`. So `Φ(f,h) ∈ nV`.
  - `pr_J ∘ Φ(f,h) = h ∘ pr_J`, so `Φ(f,h) ∈ Fib_J`.
- *`Φ` is a homomorphism.* The computation of `cantor-maps-by-v-next-brin-thompson-embedding-proof`
  applies verbatim with `C` replaced by `C^J`:
  `Φ(f,h) Φ(f',h')(x,y) = (hh'x, f(hh'x) f'(h'x) y)`. At `z = hh'x` this equals
  `Φ(f·(h·f'), hh')(x,y)`, because `(h·f')(z) = f'(h^{-1}z) = f'(h'x)`.
- *`Φ` is injective.* `Φ(f,h) = id` forces `h = id`, and then `f ≡ 1`.
- *`Φ` is onto `Fib_J`.* For `g ∈ Fib_J`, put `h = h_g ∈ mV` (Step 2.2) and `f(z) = G_{h^{-1}z}`
  (Step 2.3). `f` is locally constant because `h^{-1}` is continuous. Then
  `Φ(f,h)(x,y) = (h x, G_x y) = g(x,y)`.

This is item 1.

**Step 2.5.** Item 2 is Theorem 1.3 with `X = C^J`, `H = mV`, `Λ = (n−m)V`.

## Corollaries

- **3.1.** Put `n = 2` and `m = 1` in Theorem 2. Then `Fib_{j} ≅ C(C,V) ⋊ V`, and `V` has no
  infinite Kazhdan subgroup by (V).
- **3.2.** Induction on `n`. `T_1 = V` is covered by (V).
  - For `n ≥ 2`, `T_n ⊆ Fib_{{1..n−1}}`, and each `g ∈ T_n` has base map
    `h_g = h_{n−1} ∈ T_{n−1}`, by item 1 of `brin-thompson-triangular-subgroup-is-undistorted`.
  - So `Φ^{-1}` restricts to an injective homomorphism `T_n → C(C^{n−1}, V) ⋊ T_{n−1}`, a
    subgroup of `C(C^{n−1},V) ⋊ (n−1)V` since `T_{n−1} ≤ (n−1)V ≤ Homeo(C^{n−1})`.
  - Theorem 1.3 with `H = T_{n−1}` and `Λ = V`, together with the induction hypothesis and (V),
    shows that this group has no infinite Kazhdan subgroup, and hence neither has `T_n`.
  - The statement is about isomorphism types, so it holds for every isomorphic copy.
- **3.3.** Apply Theorem 1.3 with `X = C`, `H = V` and `Λ = Γ`, and use (V).
- **4.** Suppose `K' ≤ n_0V` is isomorphic to an infinite Kazhdan `K` and maps fibres of `pr_J`
  into fibres.
  - Then `K' ≤ Fib_J` by Step 2.1, so `Fib_J` contains an infinite Kazhdan subgroup.
  - By Theorem 2.2, `mV` or `(n_0−m)V` does, where `1 ≤ m, n_0 − m < n_0`.
  - This contradicts minimality of `n_0`. (`1V = V` has none by (V).) ∎

## Where it stops

- The proof needs that the *whole* subgroup preserves a fibration: Step 2.1 produces a base
  homomorphism.
- For non-fibred elements, such as the baker's map `(i x, y) ↦ (x, i y)`, `pr_J ∘ g` does not
  factor through `pr_J`. There is then no base quotient at all.
- Subgroups generated by fibred elements for *different* `J` (for example `V × 1` and the
  baker's map) are not covered. They include the full-shift topological full group in `2V`,
  whose Kazhdan subgroups are finite for a different reason (amenable orbits; see
  `kazhdan-subgroups-of-brin-thompson-groups-are-finite`, Attempts).

**ESTABLISHED.**

**Setting.**
- `X ⊆ A^{Z^d}` is a minimal subshift of finite type on which `Z^d` acts freely, with shift `(λ·x)(μ) = x(μ+λ)`, cut out by forbidden patterns on a finite window `K ⊆ Z^d`.
- `Γ ≤ [[Z^d ~ X]]` is generated by a finite set `S`.
- Each `s ∈ S` is `s(x) = f_s(x)·x` for a continuous `f_s : X → Z^d`. So `f_s(x)` is read off from the pattern `x|_{B_R}` for some radius `R`: each generator is a finite *rule* "pattern ↦ vector".

**Models.**
- A *validly coloured `Z^d`-set* is a nonempty set `Ω` with a `Z^d`-action and a colouring `c : Ω → A` such that, at every `ω ∈ Ω`, the pattern `κ ↦ c(κ·ω)` on `K` is not forbidden.
- Its *rule action* is `s_Ω(ω) = f_s(x_ω)·ω`, where `x_ω(μ) = c(μ·ω)`. Computing `s_Ω(ω)` only needs the colours in the `R`-ball around `ω`.
- `Ω` need not be compact, transitive or finite; one tiling of `Z^d`, a disjoint union of tilings, or `X` itself are examples.

**Theorem.** For every validly coloured `Z^d`-set `Ω`:
1. every `s_Ω` is a bijection, and `s ↦ s_Ω` extends to an injective homomorphism `Γ → Sym(Ω)`, so the marked group `(⟨S_Ω⟩, S_Ω)` equals `(Γ, S)`;
2. `Z^d` acts freely on `Ω`, so `Ω` is infinite.

**Instance.** Labbé's shift `Omega_U` is a free minimal nearest-neighbour SFT (`minimal-aperiodic-wang-shift-exists`). `Γ = D([[Z^2 ~ Omega_U]])` is finitely generated (`minimal-z2-subshift-derived-full-groups-are-fg-simple`). The theorem applies with any finite generating set.

**Consequence for finite presentation of `D([[Omega_U]])`.**
- **Isolation lemma.** A finitely generated infinite simple group is finitely presented if and only if it is isolated in the space of marked groups.
  - If it is isolated: the groups `⟨S | relators of length ≤ n⟩` converge to it, so one of them equals it.
  - If it is finitely presented by `⟨S | R⟩` with `s_0 ∈ S` nontrivial: the open set "all of `R` vanish and `s_0 ≠ 1`" contains only quotients in which `s_0` survives, and simplicity makes each of them equal to `Γ`.
- **What this rules out.** A proof that `D([[Omega_U]])` is not finitely presented must produce marked groups converging to `(Γ, S)` and different from it. By the theorem, none of them is the rule group of a validly coloured `Z^2`-set.
- **Where the known proofs sit.** The Grigorchuk--Medynets and Matui arguments for minimal `Z`-subshifts use rule groups on coloured sets:
  - finite Kakutani--Rokhlin models (arXiv:1105.0719, Theorem 5.1);
  - other minimal subshifts `Z` inside the SFT neighbourhood `Y_1` (Matui, math/0404117, Theorem 5.7).
- **What any such argument needs for `Omega_U`.** The approximating models must carry *defects*: points at which the colouring shows a forbidden `K`-pattern.
  - A minimal `Z ⊆ Y_1` with `Z ≠ Omega_U` is not contained in `Omega_U`, so every point of `Z` sees a defect within bounded distance.
  - This proves nothing about finite presentation either way: `labbe-shift-derived-full-group-is-finitely-presented` stays open.

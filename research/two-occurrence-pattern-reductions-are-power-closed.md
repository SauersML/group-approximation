**ESTABLISHED (proposed, 2026-09-18; referee welcome).** Let `H` be any group,
`A` a finite alphabet and `phi : A* -> F(gens H)` a free-monoid homomorphism.
Let `omega(X) = P X^{e1} Q X^{e2} R`, with `e1, e2 ∈ {±1}` and `P, Q, R` fixed
words, and put `L = { v ∈ A* : omega(phi(v)) = 1 in H }`.

1. **Power closure.** Suppose the empty word is in `L`.
   - Then `u ∈ L` implies `u^n ∈ L` for every `n >= 1`.
   - If `e2 = -e1`, then `L = { v : phi(v) ∈ C_H(Q) }`, and `L` is a submonoid of `A*`.
   - Hence no language that contains the empty word and has a word `u ∈ L` with `uu ∉ L` is reducible to any word problem by a two-occurrence pattern. `{ε, a}` is an example. Pattern completeness for r.e. languages, which holds at four occurrences (`type-f-group-receives-re-languages-by-pattern-reductions`), fails at two occurrences for every host.
2. **Word problems: coset realization.**
   - Word problems are submonoids closed under powers, so item 1 does not exclude them.
   - Let `G` be generated by `A`, where `A` is closed under formal inverses, and let `WP(G) = { v : phi(v) ∈ C }` for a subgroup `C ≤ H`. The centralizer `C = C_H(Q)` of item 1 is one example.
   - Then `g -> C phi(g)` is a well-defined injection `G -> C\H`, and `C phi(g) phi(a) = C phi(ga)`. So `G` acts regularly on the `phi(A*)`-invariant set of cosets it reaches.
3. **Amalgam realization.** Let `H` be of type `F` and `S ≤ H` a subgroup of type `F`. Put `K = H *_S (S × <q>)`.
   - Then `K` is of type `F`.
   - `C_K(q) = S × <q>`, and `C_K(q) ∩ H = S`.
   - So if `WP(G) = { v : phi(v) ∈ S }`, then `WP(G)` reduces to `WP(K)` by the two-occurrence pattern `X q X^-1 q^-1`.

**Consequence for the pattern window of Zaremsky 1.1.** Two-occurrence
patterns are never complete for r.e. languages. For word problems they are
equivalent to coset realizations (item 2). They are realized in type `F` groups
by letter-local membership in type `F` subgroups of type `F` groups (item 3).
The two-occurrence case therefore comes down to one question. Is there a type
`F` group `H`, a type `F` subgroup `S` and a monoid homomorphism `phi` with
`WP(G) = phi^{-1}(S)`, for a group `G` with r.e.-complete word problem? This is
Mikhailova's construction with a type `F` subgroup. Mikhailova realizes it in
`F_2 × F_2`, but with an infinitely generated `S` whenever `G` is not finitely
presented. Aanderaa--Cohen--Boone gives membership of `Z^-1 T_0 Z` in a free
subgroup, which has two occurrences of `Z`. That route yields only the
four-occurrence pattern. The same-sign case `X Q X = Q` and three occurrences
remain open.

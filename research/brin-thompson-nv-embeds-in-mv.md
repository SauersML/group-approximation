title: "For 1 <= n <= m the Brin-Thompson group nV embeds in mV by g |-> g x id"
---

For `1 <= n <= m`, the map `g ↦ g x id_{C^{m-n}}` is an injective homomorphism
`nV → mV`. So a subgroup property that passes to subgroups (the Haagerup
property, containing no infinite Kazhdan subgroup, a-T-menability of all
subgroups) holds for `nV` whenever it holds for `mV`. Failure for `2V` gives
failure for every `mV`, `m >= 2`, and `V <= nV` for all `n`.

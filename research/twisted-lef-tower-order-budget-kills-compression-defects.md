## Definitions

Let `K` be a group, `phi` in `Aut(K)`, and `G = K semidirect_phi Z`, with
`t` the generator of `Z` and `t k t^-1 = phi(k)`.  For `L <= G` use
the definitions of `compression-defect-dies-in-finite-dimensions`:

    Comp_G(L) = { s in G : s L s^-1 <= L }
    D_G(L)    = << [ g z g^-1, l ] : g in <Comp_G(L)>, z in C_G(L), l in L >>_G

A map `iota : K -> F` into a group is a *local embedding on* a finite
`B <= K` if it is injective on `B` and `iota(xy) = iota(x) iota(y)`
whenever `x, y, xy` all lie in `B`.

For finite `B <= K` and `P >= 1`, the **phi-tower budget** is

    beta_phi(B, P) = min log_2 |F|

over finite groups `F` and maps `iota : K -> F` that are local
embeddings on `phi^(-m)(B)` for every integer `0 <= m < P`
(`+infinity` if there are none).  Here `iota` needs to embed each
translate separately, not their union.

## Statement

Let `L = <S_L>` with `S_L` a finite subset of `K`.  Let
`s = k t^a` be in `Comp_G(L)` and `z = k' t^b` be in `C_G(L)`.  Let
`B_0 = B_0(s, z, S_L)` be the finite set defined in the proof.

**(OB1) Quantitative kill.**  Suppose there are a finite group `F`, a map
`iota : K -> F` and an integer

    P >= (floor(log_2 |F|) + 1) |a| + |b| + 1

such that `iota` is a local embedding on `phi^(-m)(B_0)` for every
`0 <= m < P`.  Then `s z s^-1` commutes with every `l` in `L`.

**(OB2) Degree zero.**  If `a = 0`, then one local embedding
`iota : K -> F` on the single finite set `B_0 union phi^(-b)(B_0)`
already suffices.  So if `K` is LEF, no compressor lying in `K`
contributes to `D_G(L)`.

**(OB3) Subexponential towers kill the defect.**  Suppose that for every
finite `B <= K`

    liminf_{P -> infinity}  beta_phi(B, P) / P  =  0.        (SUB)

Then `D_G(L) = 1` for every finitely generated `L <= K`.  In particular
this holds for every Kazhdan subgroup `L <= G`, because such an `L` has
finite abelianization and therefore lies in `K`.

**(OB4) Consequence for (EK1).**  Let `(K, phi, L)` be a witness for
`torsion-free-sofic-extrinsic-kazhdan-defect-kernel`, so
`D_G(L) = K x {0}` is nontrivial, and suppose `K` is LEF.  Then (SUB)
fails: some defect generator `[s z s^-1, l] != 1` with `s = k t^a` has
`a != 0`.  For its set `B_0`, every admissible tower of length `P`
satisfies

    log_2 |F|  >=  (P - |b| - 1) / |a| - 1.

So every phi-twisted LEF tower of the witness is exponentially expensive
in its length.

No property `(T)`, torsion-freeness or finite presentation is used in
(OB1)-(OB3).

## What this kills

**Invariant.**  The invariant is the order `|Pi_m|` of the finite group
`Pi_m = < iota(phi^(-m)(S_L)) > <= F` generated by the layer-`m` image of
`L`.

**Where every member dies.**  The approach class is: build LEF-type
(exactly multiplicative) finite models of `K` that are compatible with
`phi` up to a shift, and hope that the compressor defect survives in
them.  Conjugation by the image of `k` injects `Pi_m` into `Pi_(m+a)`.
By Lagrange's theorem every strict step at least doubles the order, so
at most `log_2 |F|` steps along an `a`-chain can be strict.  At a
non-strict step the defect generator is forced to be trivial in `F`, and
local injectivity lifts this back to `K`.

So a LEF witness cannot be detected by any tower of subexponential order.
It must defeat (SUB) by making every tower pay exponentially, as in the
doubling tower, or it must use a non-LEF kernel, which forces genuinely
Hamming, non-exact sofic models.

**Calibration (not part of the claim, not checked here).**  Take
`H = BS(1,2)`, `L = <a>` and `t L t^-1 = <a^2>` in the lamp group
`W = Z^(X) semidirect H` of `infinite-cyclic-compression-lamp-mf`, which
has a nontrivial defect.  Write `W = K semidirect <t>` with
`K = Z^(X) semidirect Z[1/2]`.  Every finitely generated subgroup of `K`
lies in a residually finite lamplighter, so `K` is LEF.  (OB4) then
predicts that every phi-tower of `K` of length `P` has
`log_2 |F| >= P - O(1)`.  This is a falsifiable test of the statement.

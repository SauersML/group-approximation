Assume every 2-generator group embeds in a simple group of type `FP_2`.

**Inputs.** (a) There are continuum many pairwise non-isomorphic 2-generator
groups (B. H. Neumann 1937, as recalled verbatim in Leary arXiv:1610.05813v5,
p. 1: "Neumann had already shown that there are uncountably many 2-generator
groups"). (b) Every `FP_2` group is finitely generated (Leary, same page).

**Item 1.** Let `Γ` be a finitely generated group. It has countably many finite
subsets, so at most countably many finitely generated subgroups, hence at most
countably many isomorphism classes of 2-generator subgroups. If the isomorphism
classes of simple `FP_2` groups formed a countable set, the 2-generator groups
embedding in some simple `FP_2` group would form a countable set of isomorphism
classes. By the assumption that set is all 2-generator groups, contradicting
(a). So there are uncountably many classes. A finitely generated group is a
quotient of a free group of finite rank, of which there are countably many, by
one of `2^ℵ0` normal subgroups, so there are at most `2^ℵ0` classes. Hence
exactly `2^ℵ0`.

**Item 2.** Take a 2-generator group `H` with unsolvable word problem (for
instance a 2-generator group containing a finitely presented group with
unsolvable word problem, by Higman–Neumann–Neumann). By assumption `H ≤ Γ` with
`Γ` simple of type `FP_2`, and `Γ` is finitely generated by (b). Write the two
generators of `H` as words in a finite generating set of `Γ`. Substituting
turns a word in the generators of `H` into a word in the generators of `Γ` that
is trivial in `Γ` exactly when the original is trivial in `H`. So a solution to
the word problem of `Γ` would solve it for `H`, and `Γ` has unsolvable word
problem.

**Equivalence in item 2.** For a finitely generated simple group `Γ`:
- if the word problem is solvable, the set of relators is recursive, so `Γ` is
  recursively presented;
- if `Γ` has a recursively enumerable set of defining relators on finitely many
  generators `x_1, ..., x_k` and is nontrivial, then `w = 1` is semi-decidable by
  enumerating consequences of the relators, and `w ≠ 1` is semi-decidable by
  enumerating consequences of the relators together with `w` until all `x_i`
  appear, which happens exactly when `w ≠ 1` because `Γ` is simple. This is
  Kuznetsov's argument, the recursively presented version of
  `simple-envelope-forces-solvable-word-problem`.
So for simple finitely generated groups, unsolvable word problem is equivalent
to not being recursively presented.

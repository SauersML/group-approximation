**Step 1 (item 1: a profile is a feasible LP point).** Let `v_1..v_s ∈ R^k` have supports in `E` and fix `F`.
Put `E' = E ∪ {1}`, `X = YE' ∪ {1}`, and for `S ⊆ V` define `h(S) = (1/k) dim_K span_K` of the union of the
families `X_g = (u_g e_i)_i` (`x_g ∈ S`) and `Y_g = (u_g v_j)_j` (`y_g ∈ S`).
- **(P)** `S -> dim span(union of families)` is a matroid rank function on families, so it is normalized, monotone
  and submodular: a polymatroid.
- **(I)** The layers `L_g = ⊕_i K u_g e_i` are independent of dimension `k`, so `h(x_g) = 1` and `h(x_X) = |X|`.
- **(D)** By Lemma 1.2 (D), `u_g v_j ∈ ⊕_{e ∈ E} L_{ge} ⊆ span X_{gE'}`, so `h(y_g ∪ x_{gE'}) = h(x_{gE'})`.
- **(T)** By Lemma 1.2 (T), `u_t` is a `σ_t`-semilinear bijection carrying `span_K(S)` onto `span_K(tS)`, so
  `h(tS) = h(S)` for every finite `S`. This includes every `S` with `S, tS ⊆ V`.

The objective at this point is `(1/k)[h(Y_f0) + h(X_1 ∪ Y_F) - h(Y_F)] = (1/k)[h(Y_1) + k - I(X_1;Y_F)] = Phi`,
using (T) for `h(Y_f0) = h(Y_1)` and (I) for `h(X_1) = k`. So `LP_Y(E',F) <= Phi`.

By Lemma 1.2 (E) every finite restriction is a positive multiple of an entropy function. So no valid linear
entropy inequality (Shannon or not) on `V`, combined with (I), (D), (T), can prove `Phi >= 1` at that
configuration when `Phi < 1`.

**Step 2 (item 2).** Suppose `K*G` fails the rank condition. By Theorem 2.3 (via Theorem 2.2 and Lemma 2.1, which
make `F` finite) some twisted linear profile over `K*G` has `Phi < 1`. By Step 1 the configuration `(E', F)` has
`LP_Y < 1` for every finite `Y`, contradicting the hypothesis.

**Step 3 (item 3).** Let `K*G'` fail the rank condition: `AB = I_d` with `A` of size `d x r`, `B` of size
`r x d`, `r < d`.
- **Locality.** Let `H` be generated by the supports of the entries. `K*H` (with `σ`, `α` restricted) is a
  subring containing `A` and `B`, so it fails the rank condition (item 2 of
  `virtually-hughes-free-field-crossed-products-are-stably-finite`, Lemma 4).
- **Finite index.** By hypothesis `H` has a torsion-free subgroup `N` of finite index `n`. By Lemma 5 there,
  `K*H` embeds unitally in `M_n(K*N)`. The images of `A` and `B` are block matrices of sizes `nd x nr` and
  `nr x nd` with product `I_{nd}`, and `nr < nd`. So `K*N` (with restricted `σ`, `α`) fails the rank condition.
- By Step 2 applied to `N`, some configuration at `N` has no finite-window certificate. This contradicts the
  hypothesis on torsion-free groups.

**Step 4 (item 4).** `torsion-free-windows-have-minimal-shannon-certificates` asserts `LP_F >= 1` for every
configuration in every torsion-free group, which is the hypothesis of item 3 with `Y = F`. Its LP fixes `1 ∈ E`,
which `E'` satisfies. A finitely generated linear group in characteristic 0 is virtually torsion-free (Selberg's
lemma, classical), and so are its finitely generated subgroups. □

**Scope.** Items 1–3 use only the established dictionary and the two ring lemmas. No computation is used. The
step where every Shannon or entropic window certificate dies at a rank-failing `K*G` is the final nonnegative
combination: the linear profile satisfies every premise and violates the conclusion.

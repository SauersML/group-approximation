**ESTABLISHED (unreviewed).** Proof: `m11-odometer-free-host-is-not-finitely-presented-proof`.
The proof is by hand. The script checks the identities it uses at finite depth: the shape of
`b^{11}`, the conjugates `b_k` and their commutators, and the ray-loop cocycle on random
words and on relators.

**Setting.** The notation is that of `m11-odometer-free-linear-host-h1-is-z55-squared`.
- `X = {1, …, 11}`, with right actions.
- `α = (1, …, 11)` and `β = (1,2,3,4,8)(5,10,7,11,6)`, so that `⟨α, β⟩ = M_11`.
- `b = (b, α, β, 1, …, 1)` and `R_0 = ⟨M_11, b⟩`.
- `c = (c, bα, 1, …, 1)` and `u = c b^{-1} = (u, b, β^{-1}, 1, …, 1)`.
- `R'' = ⟨M_11, b, c⟩ = ⟨M_11, b, u⟩`.

**Theorem.**

1. **The loop subgroup.** Let `ξ = 1^∞`. The generators `α, β, b, u` satisfy (Ω), (E) and (F)
   of `fp-self-similar-groups-have-fp-ray-loop-subgroups`. The only nontrivial stable
   sections are:
   - `c(b, ξ) = b`;
   - `c(u, ξ) = u`;
   - `c(u, 1^k 2 1^∞) = b`, for every `k ≥ 0`.

   So the ray-loop subgroup is `H = ⟨b, u⟩`.
2. **Structure.** The map `h ↦ (h|_2, h|_3)` is injective on `H`. It sends `b ↦ (α, β)` and
   `u ↦ (b, β^{-1})`. It is an isomorphism `H ≅ L × C_5`, where `L = ⟨α, b⟩ ≤ R_0`.
3. **`L` has finite index in `R_0`.** Indeed `L ⊇ ∏_{|w| = 3} R_0'@w`. This product has
   finite index in `R_0`, because `R_0^{ab} = Z/55` and `R_0 ≅ R_0 ≀_X M_11`.
4. **`R''` is not finitely presented.**
   - If it were, `H` would be finitely presented, by the loop obstruction.
   - Then so would its retract `L`, and so would `R_0`, which contains `L` with finite index.
   - But `R_0` is a contracting regular branch group, and such groups are not finitely
     presented (Bartholdi; cited in `fully-self-replicating-tree-groups-give-fg-tits-hosts`).
5. **The Tits host.** `Γ⁺ = (R'' ≀ M_12) *_{R''×R''} (R'' ≀ M_12)` is a finitely generated
   simple group that is **not finitely presented**. This follows from item 4 and the
   equivalence in `tits-hosts-for-transitive-local-actions`.

**What this says about the Tits route of `boone-higman-conjecture`.**

- `R''` passed every homological test on the graph: `b_1 = 0`, `H_1` finite with primes
  dividing `|M_11|`, no odometer state, and not contracting. It still fails.
- The mechanism is not homological. The infinite-order state `c` gets its infinite order
  along the ray `1^∞`, where it loops through `c ↦ c` and `u ↦ u` while the loop-adjacent
  state is `b`. Every relation of `R''` restricts, along the cofinality class of `1^∞`, to a
  relation of `⟨b, u⟩`. That subgroup is virtually a contracting branch group, so its
  relations are not finitely generated.
- **Design rule.** For any non-contracting candidate `R`, list the loop subgroup at every
  periodic ray: the subgroup generated by the states that return to themselves along that
  ray, together with their stable exits. Each must be finitely presented. In particular,
  none may contain a finite-index copy of a contracting branch group. A candidate whose loop
  subgroups are all finite or virtually free abelian passes this test.
- Such a candidate separates the loop rays. An example (unchecked) is
  `c' = (1, 1, 1, c', bα, 1, …, 1)`. Here the letters `1, 2, 3` carry `b`. The state `c'`
  loops on `4^∞`, and its exit `bα` is trivial along that class. The loop subgroups at the
  two loop rays are then `⟨b⟩ = C_55` at `1^∞` and the cyclic group `⟨c'⟩` at `4^∞`, so the
  test passes. The next step is to decide whether `⟨M_11, b, c'⟩` is fully
  self-replicating, whether `c'` has infinite order, and whether its `H_1` stays finite.

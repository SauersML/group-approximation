Notation as in the target. `R = Z[t,t^{-1}]`, `K = Q(t)`, `D = diag(1,t)`,
`J = [[0,-1],[1,0]]`, `e_1 = (1,0)^T`, `e_2 = (0,1)^T`. For `v ∈ R^2` and `λ ∈ R` put

`u(λ; v) = I + λ v (Jv)^T`.

For `v = (p,-q)^T` one has `Jv = (q,p)^T`, `v(Jv)^T = [[pq,p^2],[-q^2,-pq]]`, and
`u(1;v) = C(p,q)`. Also `u(1;e_1) = E_12(1)`, and `u(-r;e_2) = E_21(r)` because
`Je_2 = -e_1`.

**Lemma 1 (additivity).** `(Jv)^T v = 0`, so `(v(Jv)^T)^2 = 0` and
`u(λ;v) u(μ;v) = u(λ+μ;v)`.

**Lemma 2 (normal form).** Every unipotent `I + N ≠ I` in `SL_2(R)` equals `u(λ;v)`
for some primitive `v` and some `λ ∈ R`.

*Proof.* `R` is a UFD: `Z[t]` is one by Gauss's lemma, and `R` is its localization at
`t`. `N` is nilpotent, so `tr N = det N = 0`, and since `N ≠ 0` it has rank 1 over
`K`. Let `x ∈ R^2` be a primitive vector spanning the column space of `N` over `K`
(divide a nonzero column by the gcd of its entries). If `(a/b)x ∈ R^2` with `a/b` in
lowest terms, then `b` divides both entries of `x`, so `b` is a unit. Hence each
column of `N` is an `R`-multiple of `x`, and `N = x y^T` for some `y ∈ R^2`. From
`tr N = y_1x_1 + y_2x_2 = 0` and `gcd(x_1,x_2) = 1` we get `y = μ(-x_2, x_1)^T` for
some `μ ∈ R`. If `x_1 ≠ 0`, then `x_1 | y_2x_2` gives `x_1 | y_2`; write `y_2 = μx_1`,
and then `y_1 = -μx_2`. If `x_1 = 0`, then `x_2` is a unit and `y_2 = 0`. Now
`(-x_2, x_1)^T = Jx`, so `N = μ x (Jx)^T` and `I + N = u(μ; x)`. ∎

**Lemma 3 (conjugation).** For `Y ∈ SL_2(R)`, `Y u(λ;v) Y^{-1} = u(λ; Yv)`.

*Proof.* A direct computation for `Y = [[a,b],[c,d]]` gives `Y^T J Y = det(Y) J = J`.
Since `J^T = -J`, this gives `(JYv)^T Y = -v^T Y^T J Y = -v^T J = (Jv)^T`, so
`(JYv)^T = (Jv)^T Y^{-1}`. Therefore
`u(λ;Yv) = I + λ Yv (Jv)^T Y^{-1} = Y u(λ;v) Y^{-1}`. ∎

**Lemma 4 (monomial exponents).** Let `v = (p,-q)^T` and `j ∈ Z`. Then:

- `u(t^{2j}; v) = C(t^j p, t^j q)`;
- `u(t^{2j+1}; v) = D C(t^{j+1}p, t^j q) D^{-1}`;
- `D E_12(r) D^{-1} = E_12(t^{-1}r)` and `D E_21(r) D^{-1} = E_21(tr)`, so
  `D^{±1}` normalizes `E_2(R)`.

*Proof.* The first identity is `t^{2j} v(Jv)^T = (t^jv)(J t^jv)^T`. For the second,
`D M D^{-1}` multiplies the `(1,2)` entry by `t^{-1}` and the `(2,1)` entry by `t`.
So `D C(t^{j+1}p, t^jq) D^{-1} = [[1+t^{2j+1}pq, t^{2j+1}p^2],[-t^{2j+1}q^2, 1-t^{2j+1}pq]]`,
which is `u(t^{2j+1}; v)`. The third line is the same entry rule. ∎

**Lemma 5.** Let `V` be a set of primitive vectors that is closed under
`(p,-q) ↦ (t^a p, -t^b q)` for all `a, b ∈ Z`. Then `C(w) ∈ E_2(R)` for all `w ∈ V`
if and only if `u(λ;w) ∈ E_2(R)` for all `w ∈ V` and `λ ∈ R`.

*Proof.* "If" is the case `λ = 1`. For "only if", write `λ = Σ_k c_k t^k` with
`c_k ∈ Z`. By Lemma 1, `u(λ;w) = Π_k u(t^k;w)^{c_k}`. By Lemma 4, each `u(t^k;w)` is
`C(w')` or `D C(w') D^{-1}` with `w' ∈ V`, and `D` normalizes `E_2(R)`. ∎

The sets of all primitive vectors, of unimodular vectors, and of primitive
non-unimodular vectors all satisfy the hypothesis, since `t` is a unit.

**Item 2.**

- *(N) implies the Cohn form.* Let `w = (p,-q)^T` be unimodular. There is
  `Y ∈ SL_2(R)` with `Ye_1 = w`: choose `x, y` with `py + qx = 1` and put
  `Y = [[p,x],[-q,y]]`. By Lemma 3, `C(w) = u(1;Ye_1) = Y E_12(1) Y^{-1}`. This lies
  in `E_2(R)` if `E_2(R)` is normal. The same formula shows that
  `{Y E_12(1) Y^{-1} : Y ∈ G} = {C(w) : w unimodular}`.
- *The Cohn form implies (N).* If `C(w) ∈ E_2(R)` for all unimodular `w`, Lemma 5 gives
  `u(λ;w) ∈ E_2(R)` for all unimodular `w` and all `λ`. For `Y ∈ G`, Lemma 3 gives
  `Y E_12(r) Y^{-1} = u(r; Ye_1)` and `Y E_21(r) Y^{-1} = u(-r; Ye_2)`. The columns
  `Ye_1, Ye_2` of an invertible matrix are unimodular. So conjugates of the generators
  of `E_2(R)` lie in `E_2(R)`, and `E_2(R)` is normal. ∎

**Item 3.** `E_2(R) ⊂ U_2(R)` always. By Lemma 2, `U_2(R)` is generated by the
`u(λ;v)` with `v` primitive. So `U_2(R) ⊂ E_2(R)` holds if and only if every such
`u(λ;v)` is elementary. By Lemma 5 this holds if and only if `C(v) ∈ E_2(R)` for
every primitive `v`. Unimodular vectors are primitive, so this set of conditions is
the unimodular part, which is (N) by item 2, together with the non-unimodular part,
which is (C). ∎

**Item 4.** If `G = U_2(R)`, then (U) holds. Conversely, by
`sl2-laurent-integers-fg-iff-gamma0-t-in-fg-subgroup` (item 1 and the proof of item
2), `G = <Gamma_0(t), w, w'>` with `w, w' ∈ E_2(R) ⊂ U_2(R)`. Since
`Gamma_0(t) ⊂ SL_2(Z[t])`, (U) gives `G ⊂ U_2(R)`. ∎

**Item 5.** Apply Lemma 3 with `λ = 1`. For `v = (n,-f)^T` and `g ∈ R`,
`E_21(-g)v = (n, -(f+ng))^T`, so `C(n, f+ng) = E_21(-g) C(n,f) E_21(g)`. ∎

**Item 1.**

- *If `G = E_2(R)`.* Then `E_2(R)` is normal, so (N) holds. `U_2(R) ⊂ G = E_2(R)`, so
  (C) holds. `SL_2(Z[t]) ⊂ G = E_2(R) ⊂ U_2(R)`, so (U) holds.
- *If (N), (C) and (U) hold.* Item 3 gives `U_2(R) = E_2(R)`. Then (U) gives
  `SL_2(Z[t]) ⊂ E_2(R)`, and by item 3 of
  `sl2-laurent-integers-fg-iff-gamma0-t-in-fg-subgroup`, `G = E_2(R)`. ∎

Each of (N), (C), (U) is thus necessary, and no implication among them is known. The
rings `Z[t]` and `k[x,y]` violate the analogue of (C) (Cohn 1966); `Z[t]` violates the
analogue of (U) (Grunewald–Mennicke–Vaserstein 1994). Those ring-level facts are
context only and are not used above.

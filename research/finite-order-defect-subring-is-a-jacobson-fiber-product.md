**ESTABLISHED.**  Let `R` be unital, `ts = 1`, and suppose `e = 1 - st`
has finite additive order `m >= 2`.  Let `R_0` be the unital subring
generated by `s,t`, let

```text
pi : J_Z = Z<S,T | TS = 1> ->> R_0,     K = ker(pi),
F_Z = M_fin(N,Z),                       D = Z[z,z^(-1)].          (FO1)
```

Then

```text
m F_Z  <=  K  <=  m J_Z.                                          (FO2)
```

The ideal `m J_Z / K` is **central** in `R_0`, and the quotient of `R_0`
by it is `J_(Z/m)`.  More precisely, writing `Lambda = sigma(K) <= mD`
for the symbol image of the kernel,

```text
R_0 = J_(Z/m)  x_((Z/m)[z,z^(-1)])  D/Lambda.                     (FO3)
```

If instead `e` has infinite additive order, then `K = 0`, so `J_Z`
embeds in `R`.

**The centrality is about rings, not groups.**  `m J_Z / K` is a central
ideal of `R_0`.  The kernel of the induced map on elementary groups
consists of matrices and is **not** asserted to be a central subgroup.
So `(FO3)` is not a route through any theorem about central extensions of
groups.

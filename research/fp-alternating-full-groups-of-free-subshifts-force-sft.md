**ESTABLISHED (unreviewed).**

**Setting.**
- `Λ` is an infinite group generated by a finite symmetric set, and `X ⊆ A^Λ` a
  subshift on which `Λ` acts freely, `(λ·x)(μ) = x(μλ)`.
- For a pattern `π` on `B(R)` occurring in `X` and distinct `1, s, t ∈ B(5)`, the rule
  3-cycle `τ(π; 1, s, t)` cycles the disjoint clopen sets `[π] -> s·[π] -> t·[π]` by
  left translation. `S_R` is the finite set of these, for `R >= R_1 + 1`, where `R_1`
  separates every `x` from `u·x`, `1 ≠ u ∈ B(12)`, on `B(R_1)`.

**Theorem G.** If a finitely presented subgroup `Γ ≤ [[Λ ~ X]]` contains `S_R`, then
`X` is a subshift of finite type. Quantitatively, if `Γ = <S | ℛ>` with `S ⊇ S_R`,
relators of length `<= L`, local rules of radius `<= R_S` and displacements `<= D_S`,
then `X` is exactly the set of colourings whose patterns on translates of `B(N)` occur
in `X`, with `N = max(L D_S + R_S, R + 5, R_1 + 12)`.

**Corollary.** If `D([[Λ ~ X]])` or `A([[Λ ~ X]])` is finitely presented, then `X` is
of finite type. Both groups contain `S_R`.

**Consequences.**
- For `Λ = Z`: no nonempty free `Z`-subshift is of finite type, so `D([[Z ~ X]])` is
  never finitely presented, minimal or not (Matui's theorem is the minimal case).
- For Zaremsky Problem 1.10: a derived or alternating full group of a free subshift
  can be a finitely presented infinite simple amenable group only if the subshift is a
  nonempty strongly aperiodic SFT. Labbé's `Omega_U` is one, so the Labbé candidate
  is untouched.
- Not covered: non-free actions, groupoids that are not subshift transformation
  groupoids, and subgroups not containing `S_R`.

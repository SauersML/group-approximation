The notation is that of the target. The first two nodes supply only definitions: `b`, `E_infinity`, the relator and
its lifted value `k`, the window `W_r`, `kappa_r`, the relator cycle `c_r` with `<b, c_r> = k` and
`||c_r||_1 <= 6g-1`, and `beta*_W`. The third node is used only in the remark "What a proof of (SSD) must use".
Write `e(x) = exp(2 pi i x)`.

**Step 0: the twisted regular representation.** On `l^2(Gamma)` put `u_g delta_h = e(t b(g,h)) delta_(gh)`. Each
`u_g` is unitary, since it permutes an orthonormal basis up to phases, and `u_e = 1` because `b` is normalized. We have

```text
u_g u_h delta_l = e(t (b(h,l) + b(g,hl))) delta_(ghl),     e(t b(g,h)) u_(gh) delta_l = e(t (b(g,h) + b(gh,l))) delta_(ghl),
```

and these agree by the cocycle identity `b(h,l) - b(gh,l) + b(g,hl) - b(g,h) = 0`. Hence
`Lambda_t(g, n) = e(tn) u_g` is a unitary representation of `E_infinity`, whose group law is
`(g,m)(h,n) = (gh, m + n + b(g,h))`. It has `Lambda_t(g^) = u_g` and `Lambda_t(zeta) = e(t)`.

Let `A_t` be the C*-algebra generated by the `u_g`, and `tau(x) = <x delta_e, delta_e>`, a state.
- *Tracial property.* `tau(u_g u_h) = 0 = tau(u_h u_g)` unless `h = g^-1`. The cocycle identity at `(g, g^-1, g)`
  gives `b(g, g^-1) = b(g^-1, g)`, so `tau(u_g u_(g^-1)) = tau(u_(g^-1) u_g)`.
- Hence `tau(xy) = tau(yx)` on the span of the `u_g`, since products of `u`'s are scalar multiples of `u`'s. By
  continuity it holds on `A_t`, so `tau` is a tracial state.

**Step 1: the rephasing.** The function `psi -> max_W |b + delta psi|` is convex and piecewise linear in the finitely
many values `psi(x)`, for `x` among the entries and products of the pairs in `W` (normalized, `psi(e) = 0`). It is
bounded below by 0, so it attains its minimum `beta*_W` at some `psi*`. Set `psi*` to 0 off that finite set.

*Positivity of `beta*_W`.* For every normalized `psi`, `<delta psi, c_r> = <psi, d c_r> = 0`, so
`<b + delta psi, c_r> = k`. As `c_r` is supported on `W_r`, which is contained in `W`, this gives
`|k| <= max_W |b + delta psi| * ||c_r||_1`. Hence

```text
beta*_W  >=  |k| / ||c_r||_1  >=  |k| / (6g-1)  >  0.                      (1.1)
```

**Step 2: item 1.** Put `pi_t(g) = e(t psi*(g)) u_g`. It is unital. For all `g, h`:

```text
pi_t(g) pi_t(h) = e(t (psi*(g) + psi*(h) + b(g,h))) u_(gh) = e(t beta(g,h)) pi_t(gh),   beta = b + delta psi*.
```

So the defect `pi_t(g)pi_t(h)pi_t(gh)^*` is the scalar `e(t beta(g,h))`, with zero traceless part. Also
`||pi_t(g)pi_t(h) - pi_t(gh)|| = |e(t beta(g,h)) - 1| = 2|sin(pi t beta(g,h))|`. On `W`, `|t beta| <= |t| beta*_W`,
and `sin` increases on `[0, pi/2]`. So the defect is at most `2 sin(pi |t| beta*_W)` when `|t| beta*_W <= 1/2`.

The relator: scalars cancel in `[A, B] = A B A* B*`, so `[pi_t(a), pi_t(b)] = [u_a, u_b] = Lambda_t([a^, b^])`. Hence
`W_r(pi_t) = Lambda_t(prod [a_i^, b_i^]) = Lambda_t(zeta^k) = e(tk) 1`.

**Step 3: item 2.** Assume `|t| beta*_W <= (1/pi) arcsin(a_g/2)`. By (1.1) and `arcsin x <= (pi/2) x` on `[0, 1]`
(`arcsin` is convex there),

```text
|tk| <= (6g-1) |t| beta*_W <= (6g-1) (1/pi)(pi/2)(a_g/2) = 1/4.
```

So `||W_r(pi_t) - 1|| < 2`, the principal logarithm of `e(tk) 1` is `2 pi i tk 1`, and
`kappa_r^tau(pi_t) = tk tau(1) = tk`.

**Step 4: item 3.** Fix `eps in (0, a_g]` and put `t = t(eps) = arcsin(eps/2)/(pi beta*_W) > 0`.
- Then `t beta*_W = (1/pi) arcsin(eps/2) <= (1/pi) arcsin(a_g/2) <= 1/2`, so Steps 2 and 3 apply.
- The defect on `W` is at most `2 sin(arcsin(eps/2)) = eps`, and `|kappa_r^tau(pi_t)| = |k| t`.
- Dividing, `|k| t/eps = (|k|/(2 pi beta*_W)) * (2 arcsin(eps/2)/eps) = tau_W * (2 arcsin(eps/2)/eps)`.
- Since `arcsin x > x` for `x in (0, 1]`, this is strictly larger than `tau_W`.

By item 4 of `sp4-winding-ratio-sharp-constant-is-gromov-dual`, `beta*_W <= |k|/nu`, so `nu/(2 pi) <= tau_W`. This
gives the statements for `c = tau_W` and for the window-free constant.

**Step 5: item 4.** Fix `eps` and `c'` as stated, and put `t_0 = t(eps)`. The interval `(c' eps/|k|, t_0]` is nonempty,
because `c' eps/|k| < tau_W (2 arcsin(eps/2)/eps) eps/|k| = t_0`. Pick a rational `t` in it.
- Since `0 < t <= t_0`, Steps 2 and 3 give defect `<= 2 sin(pi t beta*_W) <= eps` and winding `tk`.
- `tk` is a nonzero rational number, so `|tk| = j/d` with `j, d > 0` integers, and `|tk| > c' eps`.

**Step 6: item 5.** Let `rho : Gamma -> U(A_t)` be unital and multiplicative on the pairs of `W_r`.
- The pairs `(y, y^-1)` give `rho(y)^* = rho(y^-1)` for every letter `y`.
- The pairs `(p_j, y_(j+1))` give `rho(p_j) rho(y_(j+1)) = rho(p_(j+1))`.
- So the word `W_r(rho)`, written in the letters `rho(y)`, telescopes to `rho(p_(4g)) = rho(e) = 1`.

On the other hand, `W_r(pi_t)` and `W_r(rho)` are products of `4g` unitaries, each of the form `X` or `X^*` with
`X = pi_t(y)`, respectively `rho(y)`, for `y in {a_i, b_i}`. Each `a_i` and each `b_i` occurs twice. Telescoping and
`||X^* - Y^*|| = ||X - Y||` give

```text
|e(tk) - 1| = ||W_r(pi_t) - W_r(rho)|| <= 2 sum_i (||pi_t(a_i) - rho(a_i)|| + ||pi_t(b_i) - rho(b_i)||)
            <= 4g max_(y in {a_i, b_i}) ||pi_t(y) - rho(y)||.
```

**Step 7: the class that dies.** A dimension-free argument proves an inequality `|kappa_r^tau(pi)| <= c eps` for
unital maps with defect `<= eps` on `W`, valid in every `A_t` in the stated range. Step 4 violates it at
`t = t(eps)` whenever `c <= tau_W`, and Step 5 does so even with rational windings.
- *Deficit hole.* The analogue of `Theta(W) < tau_W` asserts such an inequality with `c < tau_W` for all small `eps`.
  Step 4 violates it at each of them.
- *Sublinear hole.* The analogue asserts `c -> 0`. Step 4 violates it too.

This proves every claim of the target except the final remark.

**The final remark.** Suppose `rho : Gamma -> U(d)` has scalar defects on all of `Gamma x Gamma`. Then `rho` is a
projective representation whose multiplier class lies in the finite set `R(Gamma)` of
`sp4-fd-projective-multiplier-is-finite`. If `e(tb)` and `e(t'b)` are cohomologous in `H^2(Gamma, T)`, then
`e((t - t')b)` is a coboundary `delta phi`. Evaluating on the integral cycle `c_r` gives `e((t - t')k) = 1`. So `t`
determines the class for `0 <= t < 1/|k|`. Finitely many classes then leave a punctured neighbourhood of `t = 0`
with no exact finite-dimensional realization of `e(tb)`. This is the sense in which zero traceless defect is
unavailable in `M_d`.

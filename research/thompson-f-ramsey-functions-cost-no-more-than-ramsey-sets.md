**ESTABLISHED** by `thompson-f-ramsey-functions-cost-no-more-than-ramsey-sets-proof`. It is a direct proof from the
definitions quoted in `moore-ramsey-criterion-for-amenability` and the caret-count comparison
`thompson-f-word-length-is-comparable-to-caret-count`. It has not been independently reviewed.

Notation is as in `moore-ramsey-criterion-for-amenability`: `S = {x_0, x_1}`, `R(m, ε) = R_{F,S}(m, ε)` (sets, bound `≤ ε`),
`R̃(m, ε) = R̃_{F,S}(m, ε)` (one function into `[0,1]`, bound `< ε`), `R(m) = R(m, 1/2)`, towers
`exp_0(x) = x`, `exp_{q+1}(x) = 2^{exp_q(x)}`, and values may be `∞`.

**Theorem.** There are constants `c, A ≥ 1` such that for all integers `m ≥ 0`, `T ≥ 1` and all reals `ε ≥ 0`,

`R(m, ε + 2/T) ≤ R̃(m, ε + 2/T) ≤ 2A · R(c(m+T), ε) + A`.

The first inequality (`R(m, ε') ≤ R̃(m, ε')` for every `ε'`) is the trivial direction, since indicators are functions.
The second is the content.

**Three group-level lemmas behind it** (all proved in the route, valid in any finitely generated group).
1. *Threshold dithering.* For every `G` with finite generating set `S_G`, with `G × Z` generated by
   `S_G × {0} ∪ {(e, 1)}`, `R̃_G(m, ε + 2/T) ≤ R_{G×Z}(m + T − 1, ε)`.
2. *Coset push-forward.* If `H ≤ G` with `B_m(H) ⊆ B_{cm}(G)` and `|h|_H ≤ L(|h|_G)` for `h ∈ H` (`L` nondecreasing),
   then `R_H(m, ε) ≤ L(2 R_G(cm, ε))`. The same holds for `R̃` with any number of functions.
3. *An undistorted F × Z.* `H = F_{[0,1/2]} · ⟨x_1⟩ ≅ F × Z`, and `|h|_H ≤ A|h|_F + A` on `H`.

**Corollary (AMP is a statement about sets).** Put AMP_set(D): `R(m, 1/u) ≤ exp_D(R(exp_D(m+u)) + u)` for all `m, u ≥ 1`.
Then AMP(D) ⇒ AMP_set(D), and there is an absolute `k` (depending only on `c, A`) with AMP_set(D) ⇒ AMP(D + k).
So `¬AMP` (the hole `thompson-f-ramsey-amplification-needs-unbounded-tower-overhead`) is equivalent to

`¬AMP_set`: for every `D` there are `m, u ≥ 1` with `R(m, 1/u) > exp_D(R(exp_D(m+u)) + u)`,

which mentions only colorings by sets and the single quantifier order `∀E ∃ν`.

**What this kills.** Every approach to `¬AMP` that works through a gap between balancing sets and balancing
functions (in the census, `R(1, ε) = 7` on `[1/3, 1/2)` while `R̃(1, 1/3) ≥ 12`) can contribute at most the factor
`2A`, a window shift `T` and a precision loss `2/T`. That is elementary overhead, so it cannot carry `¬AMP`. The
whole content of `¬AMP` is precision amplification of 1/2-Ramsey *sets* to 1/u-Ramsey *sets*. With
`thompson-f-ramsey-amplification-is-the-ramsey-reiter-gap`, the three candidate sources of cost in `F` now sit as
follows, each up to elementary overhead.
- "Sets to functions" is free (this claim).
- "Precision 1/2 to 1/u for sets" is exactly `¬AMP` (this corollary).
- "∀E∃ν to ∃ν∀E" sandwiches it: RGAP₂ ⇒ `¬AMP` ⇒ RGAP₁ (the gap claim).

The second and third stay open.

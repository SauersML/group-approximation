Notation is that of the claim. `H` is generated by `g_1, …, g_n`, `cd_Z H <= 2`, and
`0 → P → Z[H]^n → Z[H] → Z → 0` is the standard resolution, with `e_i ↦ g_i − 1` and `P`
projective. `Λ = Q[t^{±1}] = Q[H/L]` through `φ`, and `Q(t)` is its field of fractions.
For a `Λ`-module `M`, `rank_Λ M = dim_{Q(t)} Q(t) ⊗_Λ M`. This is additive on short exact
sequences because `Q(t)` is flat over `Λ`.

## Item 1: the Alexander complex is free

`Λ ⊗_{Z[H]} P` is a direct summand of a free `Λ`-module, so it is projective. `Λ` is a PID, and
every projective module over a PID is free, of any rank (a submodule of a free module over a
PID is free; Kaplansky). Its rank is the rank of `Q ⊗_Λ (Λ ⊗_{Z[H]} P) = Q ⊗_{Z[H]} P`.
Tensoring the resolution with `Q` gives the complex `Q ⊗ P → Q^n → Q`, and the second map is
zero because `g_i − 1 ↦ 0`. So `b_2 = dim ker(Q ⊗ P → Q^n)` and
`b_1 = n − dim im(Q ⊗ P → Q^n)`, hence `dim_Q Q ⊗ P = b_2 + n − b_1 = r`.
(This is the case `N = H` of target item 1.)

By Shapiro's lemma, `H_k(L; Q) = H_k(H; Q[H/L]) = H_k(H; Λ)`. The deck action of `t` on the
left corresponds to the `Λ`-module structure on the right. So `A_k` is the homology of

> `C_Λ : 0 → Λ ⊗ P --∂_2--> Λ^n --∂_1--> Λ → 0`, with `∂_1(e_i) = t^{φ(g_i)} − 1`.

- `A_k = 0` for `k >= 3`, since `C_Λ` has length 2.
- `im ∂_1` is the ideal generated by the elements `t^{a_i} − 1`, where `a_i = φ(g_i)`. It equals
  `(t^d − 1)` with `d = gcd(a_i) = 1`, because `φ` is onto. So `A_0 = Λ/(t − 1) = Q`.
- `Z_1 = ker ∂_1` is a submodule of `Λ^n`, so it is free, and its rank is `n − 1` because
  `im ∂_1 ≅ Λ` has rank 1. `A_1 = Z_1 / im ∂_2` is a quotient of `Λ^{n−1}`, so it is finitely
  generated of rank `ρ_1 <= n − 1`. By the structure theorem over a PID,
  `A_1 ≅ Λ^{ρ_1} ⊕ T_1` with `T_1 ≅ ⊕_j Λ/(f_j)`, a finite sum with each `f_j ≠ 0`. So
  `dim_Q T_1 = Σ deg f_j < ∞`.
- `A_2 = ker ∂_2` is a submodule of the free module `Λ ⊗ P`, so it is free. Its rank is at most
  `r`.

## Item 2: the Alexander formula

Suppose `b_2 < ∞`. Then `r < ∞`. Apply the exact functor `Q(t) ⊗_Λ −` to `C_Λ`. The result is
a complex `Q(t)^r → Q(t)^n → Q(t)` of finite-dimensional `Q(t)`-vector spaces, with homology
`Q(t) ⊗ A_k` of dimensions `ρ_2, ρ_1, 0` in degrees `2, 1, 0` (note `Q(t) ⊗ Q = 0`). The Euler
characteristic of a finite complex equals that of its homology:

> `r − n + 1 = ρ_2 − ρ_1`, and `r − n + 1 = b_2 − b_1 + 1 = χ_Q(H)`.

Suppose `b_2 = ∞`. Then `Λ ⊗ P` is free of infinite rank, and after `Q(t) ⊗` the map to
`Q(t)^n` has infinite-dimensional kernel. So `ρ_2 = ∞`.

## Item 3: zero-or-free, the cyclic tower, and the fibred kill

**(a)** `A_2` is free over `Λ` by item 1. So either `A_2 = 0`, or `A_2 ⊇ Λ` and
`dim_Q A_2 = ∞`. Hence `b_2(L) < ∞` iff `A_2 = 0` iff `ρ_2 = 0`. In that case `b_2(H) < ∞`,
because otherwise `ρ_2 = ∞` by item 2. Item 2 then gives `χ_Q(H) = 0 − ρ_1 <= 0`.

**(b)** `H_m = φ^{-1}(mZ)` contains `L`, and `H_m / L = ⟨t^m⟩ ≅ Z`. The Lyndon–Hochschild–Serre
spectral sequence with quotient `Z` has two columns, so it degenerates into the Wang sequences

> `0 → A_k / (t^m − 1) A_k → H_k(H_m; Q) → ker(t^m − 1 | A_{k−1}) → 0`.

These are sequences of `Q[H/H_m] = Q[Z/m]`-modules, by naturality under conjugation by `t`.

- For `k = 1`: `A_1/(t^m − 1) ≅ (Λ/(t^m − 1))^{ρ_1} ⊕ T_1/(t^m − 1)`, and `t` acts trivially on
  `A_0 = Q`. So `b_1(H_m) = mρ_1 + dim T_1/(t^m − 1) + 1`.
- For `k = 2`: `A_2/(t^m − 1) ≅ (Λ/(t^m − 1))^{ρ_2} = Q[Z/m]^{ρ_2}`. Also `t^m − 1` is injective
  on the free part of `A_1`, because `Λ` is a domain. So
  `b_2(H_m) = mρ_2 + dim ker(t^m − 1 | T_1)`.

Both error terms lie in `[0, dim T_1 + 1]`. So `b_k(H_m)/m → ρ_k`. The submodule
`A_2/(t^m − 1) ⊆ H_2(H_m; Q)` is `Q[Z/m]`-free of rank `ρ_2`, and its codimension is
`dim ker(t^m − 1 | T_1) <= dim T_1`.

**(c)** Suppose `L = ⋃_α L_α` is a directed union with `b_2(L_α) <= c` for all `α`. Homology
commutes with directed colimits, so `H_2(L; Q) = colim H_2(L_α; Q)`. A directed colimit of
vector spaces of dimension at most `c` has dimension at most `c`. Indeed, any `c + 1` elements
of the colimit come from one stage, are dependent there, and so are dependent in the colimit.
Hence `b_2(L) <= c < ∞`, and `χ_Q(H) <= 0` by (a).

For an ascending HNN extension `H = ⟨B, t | t b t^{-1} = θ(b)⟩` with `θ : B → B` injective, let
`φ` kill `B` and send `t ↦ 1`. The kernel is the increasing union
`L = ⋃_{k >= 0} t^{-k} B t^k`, because `t B t^{-1} = θ(B) ⊆ B`. Every term is isomorphic to
`B`. So `c = b_2(B)` works, and no finite generation of `B` is used. (The case
`t^{-1} B t ⊆ B` is symmetric.)

## Lemma E: elementary amenable groups of cd at most 2 have `b_2 <= 1`

Let `E` be elementary amenable with `cd_Z E <= 2`. Then `E` is torsion-free, and
`h(E) <= cd E <= 2` (Hillman). By Hillman–Linnell, an elementary amenable group of finite
Hirsch length is locally-finite-by-virtually-solvable. The locally finite radical of `E` is
trivial, so `E` has a normal solvable subgroup `S` of finite index, with `h(S) = h(E) <= 2`.
Since `H_*(E; Q) = H_*(S; Q)_{E/S}`, we get `b_2(E) <= b_2(S)`.

`S` has a subnormal series `S = S_0 ⊵ S_1 ⊵ … ⊵ S_ℓ = 1` in which every factor is either locally
finite or torsion-free abelian of rank 1. Exactly `h(S)` factors are of the second kind. To get
it, refine the derived series: split each factor into its torsion part and a torsion-free
quotient, then split the torsion-free abelian part of finite rank into rank-1 pieces. Every
subgroup of an abelian group is normal in it, so the series stays subnormal.

*Claim.* For every Q[S]-module `M` with `dim_Q M = d < ∞`,
`dim H_k(S; M) <= C(h(S), k) · d`.

*Proof.* Induct on `ℓ` using LHS for `S_1 ⊴ S`, which gives
`dim H_k(S; M) <= Σ_{p+q=k} dim H_p(S/S_1; H_q(S_1; M))`. By induction each
`H_q(S_1; M)` is finite-dimensional with the stated bound. For the quotient `Q = S/S_1` and a
finite-dimensional module `M'`, there are two cases.

- If `Q` is locally finite, then `H_p(Q; M') = 0` for `p >= 1` (rationally), and `H_0` has
  dimension at most `dim M'`.
- If `Q` is torsion-free abelian of rank 1, it is locally cyclic, so `Q = colim Z`. Then
  `H_p(Q; M') = colim H_p(Z; M')`. This vanishes for `p >= 2`, and for `p = 0, 1` it has
  dimension at most `dim M'`, by the colimit bound of item 3(c).

So the quotient contributes the factor `C(ε, p)` with `ε ∈ {0, 1}`, and Vandermonde's identity
closes the induction. ∎

With `M = Q` and `h(S) <= 2`, this gives `b_2(E) <= b_2(S) <= C(2, 2) = 1`.

## Item 4: the escape-side dichotomy

Let `K` be finitely generated, amenable, of cd at most 2, with finite abelianization, and
`K ≠ 1`. If `cd K <= 1`, then `K` is free and amenable, hence `1` or `Z`, which is excluded. So
`cd K = 2`, and `χ_Q(K) = 1 + b_2(K) >= 1`, read as `∞` when `b_2(K) = ∞`. A finitely generated
group has `b_1 > 0` iff it maps onto `Z`. So exactly one of the following holds: (I) no
finite-index subgroup maps onto `Z`; (II) some finite-index subgroup does.

**(I).** Every finite-index `N` has `b_1(N) = 0`. If `b_2(K) < ∞`, target item 3 gives
`b_2(N) < ∞` and `χ_Q(N) = [K:N] χ`, so `b_2(N) = χ[K:N] − 1`. If `b_2(K) = ∞`, then
`b_2(N) >= b_2(K) = ∞`, by transfer (`H_*(K; Q)` is a direct summand of `H_*(N; Q)`).

Now let `N` be normal with `F = K/N`, and `b_2(K) < ∞`. By Shapiro, `H_*(N; Q)` is the
homology of `Q[F] ⊗ P → Q[F]^n → Q[F] → 0`. By target item 1, `Q[F] ⊗ P ≅ Q[F]^r`. The
homology is `H_2(N)` in degree 2, `0` in degree 1 and `Q` in degree 0. Split this exact complex
over the semisimple ring `Q[F]`. Let `I` be the augmentation ideal and `Z_1` the degree-1
cycles. Then `Q[F]^n ≅ Z_1 ⊕ I`, `Q[F] ≅ I ⊕ Q` and `Q[F]^r ≅ H_2(N) ⊕ Z_1`. Hence
`H_2(N) ⊕ Q ⊕ Q[F]^n ≅ Q[F]^{r+1}`. Cancellation (Krull–Schmidt for finitely generated
semisimple modules) gives `H_2(N) ⊕ Q ≅ Q[F]^{r+1−n} = Q[F]^{χ}`.

**(II).** Let `H` have finite index in `K`, let `φ : H ↠ Z`, and let `L = ker φ`. `L` is amenable
and `cd L <= 2`.

- If `b_2(K) < ∞`, target item 3 gives `χ_Q(H) = [K:H] χ_Q(K) >= [K:H] >= 1`. Item 2 then gives
  `ρ_2 = χ_Q(H) + ρ_1 >= [K:H]`.
- If `b_2(K) = ∞`, then `b_2(H) = ∞` by transfer, and `ρ_2 = ∞` by item 2.

In both cases `A_2 ≅ Λ^{ρ_2} ≠ 0` by item 1, so `b_2(L) = ∞`. Hence `cd L = 2`, and `L` is not
elementary amenable, by Lemma E. `L` is the directed union of its finitely generated subgroups
`L_α`. If their `b_2` were bounded, item 3(c) would give `b_2(L) < ∞`. So `sup b_2(L_α) = ∞`.
Each `L_α` with `b_2(L_α) >= 2` is amenable, of cd 2 and, by Lemma E, not elementary amenable.

`K` is not elementary amenable. In case (II), it contains the non-EA group `L`. In case (I), if
`K` were EA, it would be virtually solvable (Lemma E) and infinite. Descending the derived
series of a finite-index solvable subgroup then gives a finite-index subgroup with infinite
abelianization, contradicting (I). So `H` is not EA either, since EA is closed under finite
extensions and subgroups. `H` is therefore a finitely generated amenable non-EA group of cd 2,
and `amenable-cd-two-ascending-hnn-groups-are-baumslag-solitar` says that no finitely generated
normal subgroup of `H` has a non-torsion quotient. Since `H/L = Z`, `L` is not finitely
generated.

Conversely, the existence of such a `K` whenever Kropholler's question fails in dimension 2 is
item 3(i) of `amenable-cd-two-kropholler-iff-locally-indicable`. We just showed that any such
`K` is itself non-EA, so the equivalence holds.

## Item 5: the class where the question holds

Let `J ≠ 1` be a finitely generated subgroup of `G` with finite abelianization. As in item 4,
`cd J = 2` and `b_1(J) = 0`. By hypothesis there is a finite-index `H <= J` and `φ : H ↠ Z` with
`b_2(ker φ) < ∞`. Item 3(a) gives `b_2(H) < ∞` and `χ_Q(H) <= 0`. By transfer,
`b_2(J) <= b_2(H) < ∞`, so target item 3 applies to `J`:
`χ_Q(H) = [J:H](1 + b_2(J)) >= 1`, a contradiction. So every finitely generated subgroup
`J ≠ 1` of `G` has infinite abelianization and maps onto `Z`. That is, `G` is locally indicable.
Item 1 of `amenable-cd-two-kropholler-iff-locally-indicable` (amenable, locally indicable,
cd at most 2 implies solvable of the listed forms) finishes the proof. The "equivalently" form
is the same argument with `J = K`.

## Item 6: the target's item 6 for `Γ = Z`

Take `N = L` and `Γ = Z`. Then `U(Z)` is the algebra of measurable functions on the circle,
and `Q[t^{±1}] ⊂ Q(t) ⊂ C(t) ⊂ U(Z)`. `U(Z)` is flat over the field `C(t)`, and `C(t)` is flat
over `Λ`. So `H_k(H; U(Z)) = U(Z) ⊗_Λ A_k`, and
`β_k = dim_{U(Z)} U(Z) ⊗_{Q(t)} Q(t)^{ρ_k} = ρ_k` (torsion is killed). Here `β_0 = 0`,
`β_1 = ρ_1` and `β_2 = ρ_2`. Then:

- `χ^{(2)}(H; Z) = ρ_2 − ρ_1 = χ_Q(H)` by item 2, so the target's
  `D_Γ(P_Γ) = χ_Q − χ^{(2)} = 0`. This is the L²-Swan statement 6(a), with equality. Directly:
  `U(Z) ⊗ P` is `U(Z) ⊗_Λ Λ^r`, which is free.
- The lifting inequality 6(b), `χ^{(2)}(H; Z) <= 0`, reads `ρ_2 <= ρ_1`.
- The module structure of 3(b) is the induced structure on the cross-tile remainder along the
  tiles `H_m`. It makes `H_2(H_m)` contain `Q[Z/m]^{ρ_2}`. So in a fibred counterexample the
  whole slope `χ_Q(H) + ρ_1 = ρ_2` sits in a free, induced summand. An argument that uses only
  "induced from the fibre" therefore cannot bound `b_2(H_m)` by `o(m)`.

## Calibrations

Each row is computed directly, and each satisfies `χ = ρ_2 − ρ_1`.

- `Z² = ⟨x, y⟩`, `φ(x) = 0`, `φ(y) = 1`: `L = ⟨x⟩`, `A_1 = Λ/(t − 1)`, `A_2 = 0`, `0 − 0 = 0`.
- `BS(1, m) = ⟨a, t | t a t^{-1} = a^m⟩`: `L = Z[1/m]`, `A_1 = Q` with `t` acting by `m`, that
  is `Λ/(t − m)`, and `A_2 = 0`. So `0 = χ`.
- `F_2 = ⟨a, b⟩`, `φ(a) = 1`, `φ(b) = 0`: `L` is free on the elements `a^k b a^{-k}`, so
  `A_1 = Λ` and `ρ_1 = 1 = −χ`.
- `π_1 Σ_2`, with a primitive `φ`: `L` is free of infinite rank, `A_2 = 0`, and item 2 forces
  `ρ_1 = 2`.
- `F_2 × Z`, projecting onto `Z`: `L = F_2` with trivial `t`, so `A_1 = Q²` is torsion and `ρ = 0`.
- `F_2 × F_2`, with `φ(a_1) = 1` and `φ = 0` on the other generators: `L = F_∞ × F_2`, where
  `F_∞ = ker(F_2 → Z)` has `H_1 = Λ`. By Künneth, `A_1 = Λ ⊕ Q²` and
  `A_2 = H_1(F_∞) ⊗ H_1(F_2) = Λ ⊗ Q² = Λ²`. So `2 − 1 = 1 = χ(F_2 × F_2)`. This is a nonzero
  free `A_2` in a finitely presented, non-amenable group of cd 2.

The last example shows that items 1–3 cannot give `ρ_2 <= ρ_1` without amenability.

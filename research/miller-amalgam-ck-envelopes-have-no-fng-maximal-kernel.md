**ESTABLISHED** by `miller-amalgam-ck-envelopes-have-no-fng-maximal-kernel-proof`.

**Statement.** Let `S` be a finitely generated, computably presented, infinite
simple group that contains an element `t` of infinite order, and let
`1 != s in S`. Then there are:
- a finitely generated recursively presented group `G >= S`; and
- a finitely presented property-(T) group `Gamma >= G` with
  `Gamma = <<s>>_Gamma`, obtained by applying Chatterji--Kassabov Theorem 3
  to `(G, s)`,

such that the following hold.
1. Every nontrivial quotient of `Gamma` has unsolvable word problem.
   Equivalently, every proper normal subgroup of `Gamma` is non-recursive.
2. No maximal proper normal subgroup of `Gamma` is finitely normally
   generated. That is, `Gamma` has no finitely presented simple quotient.

**What this kills.** Call a proof of
`ck-envelope-has-a-finitely-normally-generated-maximal-kernel`
*hypothesis-only* if it uses only the following about `Gamma`:
- `Gamma` is finitely presented and has property (T);
- `Gamma` contains `S` and `Gamma = <<s>>_Gamma`;
- `Gamma` comes from Theorem 3, or from the marked Steinberg cover, for
  *some* finitely generated recursively presented input containing `S`.

Every hypothesis-only proof is dead.
- *Invariant:* WP-poison of the normal generator. Every quotient in which
  `s` survives has unsolvable word problem.
- *Where every member dies:* the step "hypotheses ⇒ a finitely normally
  generated (or even r.e.) maximal kernel".

Zorn over normal subgroups, property (T) and rigidity (Attempts 1–3 of the
hole) all belong to this class.

**Scope for the route.** The route's core does have an element of infinite
order. `boone-higman-via-ck-maximal-kernel` builds `S` from `G0 x Z`, so
`S >= Z`, and the hole read universally is false for the route's own cores.

The route itself is not refuted. It chooses a Clapham `H` with solvable word
problem and can choose a decidable `T`. For such a clean marking,
`clean-ck-cover-separates-trivial-words-from-normal-generators` and
`clean-ck-cover-confines-poison-to-covering-kernel` show that this mechanism
does not transfer.

The hole is therefore only tenable for a specified clean marking. A proof must
use decidability of the marking at some step.

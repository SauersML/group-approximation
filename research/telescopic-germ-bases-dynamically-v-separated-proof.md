Notation as on the claim. Say `g ∈ Homeo(C)` is **V-regular** at `x` if it agrees with a prefix
replacement on a neighbourhood of `x`, and write `Sing(g)` for the points where it is not.
Conjugation by a prefix map `α_n` carries V-regular points to V-regular points. A homeomorphism
with `Sing(g) = ∅` lies in `V`: by compactness there is a finite cone partition on which `g` is a
prefix replacement, which is the definition of `V`.

**Item 1.**
- `T(p)` is a bijection. It preserves each `A_n` and acts there by a homeomorphism. It is
  continuous at `p₀`, because it preserves each neighbourhood `0^N C = {p₀} ∪ ⋃_{n≥N} A_n`. On
  `A_n`, `T(pq) = α_n ρ(σ^n p) ρ(σ^n q) α_n^{-1} = T(p) T(q)`. The formula for the kernel is read off
  annulus by annulus.
- For `n ≥ 1`, `x₀(0^n 1 w) = 0^{n+1} 1 w`, so `x₀ α_n = α_{n+1}`. Hence on `A_n`, `n ≥ 1`,
  `x₀^{-1} T(p) x₀ = α_n ρ(σ^{n+1} p) α_n^{-1} = T(σ p)`.
- The germ at `p₀` is trivial iff `T(p)` is the identity on `0^N C` for some `N`, i.e. iff `p ∈ K_∞`.
  Now `σ(p) ∈ K_∞` iff `p ∈ K_∞`, since both conditions are "eventually `ρσ^n p = 1`". So `σ̄` is
  well defined and injective on `P̄`.
- Now let `ρ(P) ≤ V`. Every element of `⟨V, T(P)⟩` is V-regular off the `V`-orbit of `p₀`. `T(p)` is
  V-regular at every point of that orbit other than `p₀`, since those points lie in annuli where
  `T(p)` acts through `ρ(P) ≤ V`. So the isotropy at `p₀` is generated by the germ `t` of `x₀`, which
  generates the germ group `Z` of `V` at `p₀`, together with the germs of `T(P) ≅ P̄`. The
  relation `t^{-1} p t = σ̄(p)` then gives a surjection `P̄ *_{σ̄} → (germ group)`.
- Injectivity. Every element of the ascending HNN extension has the form `t^a p t^{-b}` with
  `a, b ≥ 0`. Its germ maps `A_n` to `A_{n+a-b}` for large `n`. If it is trivial then `a = b`, and
  `p ∈ K_∞`, so `p̄ = 1`. This is the computation of `dynamically-v-separated-groups-satisfy-boone-higman`
  with `K_∞` made explicit.

**Item 2.**
- On the clopen set `A_n`, `T(p)` is `α_n`-conjugate to `ρ(σ^n p)`, so its singular points there are
  `α_n(Sing ρ(σ^n p))`.
- At `p₀`, if `p ∉ K_∞` then `T(p)` preserves every annulus and acts nontrivially on infinitely many
  of them. The `V`-germs at `p₀` are the germs of `x₀^k`. For `k ≠ 0` these move annuli, and for
  `k = 0` the germ is trivial. So `p₀` is singular.

**Item 3.**
- Since `T(p) ∈ H`, `Sing(T(p))` is finite. The sets `α_n(Sing ρ(σ^n p))` lie in the pairwise
  disjoint `A_n`, so all but finitely many are empty. So `ρ(σ^n p)` is everywhere V-regular, hence
  in `V`, for all `n ≥ N_p`.
- For finitely generated `P`, take `N` to be the maximum over the generators. Then
  `ρσ^n(P) ≤ V` for `n ≥ N`, because `ρσ^n` is a homomorphism.
- If `K_∞ = 1`, then every `p ≠ 1` has `ρσ^n p ≠ 1` for infinitely many `n`. So
  `(ρσ^N)(σ^m p) ≠ 1` for infinitely many `m`, which is dynamical V-separation of
  `(P, σ, ρσ^N)`. Here `σ` is injective, because `K_∞ = 1` forces `ker σ ≤ K_∞ = 1`.
- The biconditional: (⇐) is the cited theorem, which gives a finitely presented finite germ extension
  with germ group `P *_σ`. (⇒) is the part just proved.

**Item 4.** Apply item 3 with `ρ = ι` and `P = ⟨h⟩`. Then `σ^n(h) ∈ V` for large `n`. For finitely
generated `P ≤ H` with `σ(P) ≤ P` and `σ|_P` injective, `σ^N(P) ≤ V` and `σ^N: P → σ^N(P)` is an
isomorphism. `V` acts properly on a CAT(0) cube complex (Farley), so every FW subgroup of `V`,
and in particular every Kazhdan subgroup, is finite. The same conclusion is recorded on main for
the Corollary 2.10 regime.

**Item 5.** If `P` is simple, each `ker(ρσ^n)` is `1` or `P`. A nontrivial germ at `p₀` forces
`ρσ^n ≠ 1`, hence `ρσ^n` injective, for infinitely many `n`.

**Calibration check (Grigorchuk).** In the chart with `0 ↔ 1` exchanged (spine `1^∞`, annuli
`1^n 0 C`), `b` acts on `1^n 0 C` by the section `σ^n`-cycled through `a, a, 1`. That is exactly
`T_{ρ,σ}` with `ρ(b) = ρ(c) = a` and `ρ(d) = 1`. Then `ker ρ = {1, d}`, whose `σ`-conjugates
intersect trivially, so `K_∞ = 1`. The seed lies in `V` (`a` swaps the first letter), so item 1
gives the germ group `(Z/2)² ⋊_σ Z` at the spine for `⟨V, b, c, d⟩`.

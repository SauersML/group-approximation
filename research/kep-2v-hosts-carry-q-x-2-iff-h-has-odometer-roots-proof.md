Notation as in the target. For a word `w` of length `k`, identify `w` with the integer `Σ w_i 2^i`.

**Item 1.** As in Step 1 of `odometer-2v-doubling-has-no-compatible-cube-root-proof`, an element `g` commuting
with `s` has the form `g(x, y) = (x + a(y), v(y))` with `a : C → Z_2` continuous. The fibres `C × {y}` are the
`s`-orbit closures, and the centralizer of `τ` in `Aut(T_2)` is `{τ_z}` (item 2 of
`odometer-root-hosts-are-non-affine-and-non-contracting`, used here in `Homeo(C)` via minimality).

On a rectangle `C(p) × C(w)` of a defining partition, `g` is `(p t, w z) ↦ (p' η(t), w' z)` with `η ∈ H`. So
`p + 2^k t + a(wz) = p' + 2^{k'} η(t)` for all `t`, with `k = |p|` and `k' = |p'|`. Then `η` is an affine map
of `Z_2` of slope `2^{k − k'}` that preserves `Z_2`, so `k = k'`, and `η = τ_(a')` with
`a' = (p − p' + a(wz)) / 2^k`, which is constant on `C(w)`. Hence `a' ∈ T_H`. Also
`a = p' − p + 2^k a' ∈ T_H`, because `T_H` is a group containing `Z` and `(τ_(a'))^(2^k) = τ_(2^k a')`. So `a`
is locally constant with values in `T_H`, and `v ∈ V`. Conversely every such map lies in `2V_H` (take
`η = τ_(a(y))` on each piece) and commutes with `s`.

**Item 2.** If `r ∈ 2V_H` has `r^ℓ = s` and trivial second coordinate, then `r` commutes with `s`, so
`r = (x + a(y), y)` by item 1. From `r^ℓ = s`, `ℓ a(y) = 1`, so `a ≡ 1/ℓ ∈ T_H`. Conversely, if `1/ℓ ∈ T_H`
then `τ_(1/ℓ) × id ∈ 2V_H` (one piece) and `(τ_(1/ℓ) × id)^ℓ = s`.

**Item 3.** For `c ∈ Z_2`, `u (τ_c × id) u^-1 (x_0 x', y) = u(τ_c(x'), x_0 y) = (x_0 τ_c(x'), y)`. As a
`2`-adic integer, `x_0 + 2(x' + c) = (x_0 + 2x') + 2c`. So `u (τ_c × id) u^-1 = τ_(2c) × id`. In the coding
`X ≅ {0,1}^Z`, with the second coordinate read leftwards, `u` is the shift and `τ_c × id` adds `c` with
carries propagating to the right. So the group generated by `u` and `{τ_c × id : c ∈ Z_(2)}` acts through the
affine action of `Z_(2)[1/2] ⋊ ⟨2⟩ = Q ⋊ ⟨2⟩` on `X`. On the dense set of sequences with finitely many
nonzero digits on the left, which is `Q_2`, it is the usual affine action of `Q ⋊ ⟨2⟩` on `Q_2`, and that action
is faithful. So the group is `Q ⋊ ⟨2⟩`. Its elements lie in `2V_H`, as products of the generators.

**Item 4.** If `T_H ⊇ Z_(2)` then `H` contains `τ` and `τ_(1/ℓ)` for every odd prime `ℓ`, and these are the
`ℓ`-th roots of `τ`. Items 4(b)–(d) of `odometer-root-hosts-are-non-affine-and-non-contracting` apply to any
finitely generated such `H`, and `automaton-groups-see-only-smooth-periods` excludes finite-state generation.
A finitely presented `H` is residually finite, as a subgroup of `Aut(T_2)`, and contains `Z_(2)`.

**Item 5.** This is quoted from Li, arXiv:2110.04505v2, Example `ex:ZS` (l.2372 of the e-print): "If `P` is
right cancellative, then `𝔇 ≔ 𝔆 ⋈ 𝔊` is automatically right cancellative up to `=^*`". It needs the
standing assumption `𝔡(g.a) = 𝔡(a)`. The action of `H` sends colour-1 edges to colour-1 edges and fixes
colour-2 edges, and `Z_(≥0)^2` is right cancellative.

**Item 6.** Arrows of the groupoid are germs `[g, z]` of elements `g ∈ 2V_H` at points `z ∈ X`. Near `z`,
`g` has the form `(p x, w y) ↦ (p' η(x), w' y)`.
- *Effective.* Suppose `g` is the identity on an open neighborhood of `z`. Then on a smaller rectangle
  `C(pq) × C(wr)` around `z` we have `p' = p` and `w' = w`, and `η` is the identity on the cone `C(q)`. By local
  faithfulness `η = 1`. So the germ is a unit: no nontrivial germ acts trivially on an open set.
- *Hausdorff.* Suppose two germs `[g_1, z] ≠ [g_2, z]` cannot be separated. Then `h = g_1^-1 g_2` fixes `z`,
  has nontrivial germ at `z`, and is the identity on open sets accumulating at `z`. Near `z`, `h` is
  `(p x, w y) ↦ (p' η(x), w' y)` on one rectangle, with a single `η ∈ H`. Take an open set inside this
  rectangle on which `h` is the identity, and compare there:
  - `w' y' = w y'` for all `y'` in a cone forces `w' = w`;
  - `p' η(x') = p x'` for all `x'` in a cone `C(q)` forces `p' = p`, because `η` maps `C(q)` onto a cone of
    the same level;
  - then `η` is the identity on `C(q)`.

  By local faithfulness `η = 1`. So `h` is the identity on the whole rectangle and its germ at `z` is
  trivial, a contradiction.
- *(F).* This asks that invertible elements of `𝔇` agreeing on a nonempty constructible set
  `X(v; 𝔢) ∈ 𝔛` be equal. Here the invertibles are the elements of `H`, acting by `η × id`. A nonempty set
  `X(v; 𝔢)` is the complement of finitely many rectangles, so it contains a nonempty open set of the form
  `U × C(w')`. Agreement there puts `η_1^-1 η_2` equal to the identity on `U`, so `η_1 = η_2`.
- *Minimal and purely infinite.* `2V` alone makes every orbit dense. Every clopen set contains a rectangle,
  which `2V` bisections map onto two disjoint subrectangles, as in the `H = ⟨τ⟩` case.

**Item 7.** `2V_H` is generated by `2V` and the elements `η_R`, meaning "`η` on a rectangle `R`, the identity
elsewhere", for `η ∈ H`. Indeed each element of `2V_H` is a `2V` element composed with finitely many `η_R`
having disjoint supports.
- Any two proper rectangles `R` and `R'` are exchanged by a `2V` element that is a prefix map from `R` onto
  `R'`, since their complements are nonempty clopen sets and hence `2V`-equivalent. Prefix maps commute with
  `η` acting on the tail, so `η_R` and `η_(R')` are conjugate.
- In the abelianization write `θ(η)` for the class of `η_R`, for a proper rectangle `R`. Splitting
  `R = C(p) × C(w)` into `C(p) × C(w0)` and `C(p) × C(w1)` gives `η_R = η_(R_0) η_(R_1)`, so
  `θ(η) = 2θ(η)` and `θ(η) = 0`. The element `η × id` (the whole of `X`) is `η_(C × C(0)) η_(C × C(1))`, so its
  class vanishes too.
- `2V` is simple and non-abelian, so it lies in the commutator subgroup.

So `2V_H` is perfect. Under item 6, Matui's `simple2` makes `D(2V_H) = 2V_H` simple. Finally,
`u (τ_c × id) u^-1 = τ_(2c) × id = (τ_c × id)^2` gives `[u, τ_c × id] = τ_c × id`.

**Item 8.** This is the quoted text of Li's Example `ex:ZS`. It uses only the degree setting and
`𝔡(g.a) = 𝔡(a)`, both of which hold here.

**Corollary.** Item 3 puts `Q ⋊ ⟨2⟩` in `2V_H`. Li's Example `ex:ZS` (III), with the conditions checked in
items 5, 6 and 8, gives `F_2` for `2V_H` from `F_2` of `St(H, v) = H`. Items 6 and 7 give simplicity.

**Item 9.** From `σ τ_a σ^-1 = τ_b`, `σ(x + na) = σ(x) + nb` for all `n ∈ Z`. Since `a` is a unit, `Za` is dense
in `Z_2`. `σ` is continuous, so `σ(x + ta) = σ(x) + tb` for all `t ∈ Z_2`. Taking `x = 0` and `t = y/a` gives
`σ(y) = σ(0) + (b/a) y`.

**Item 10.** Every translation and every gluing element supplied by item 9 is a Möbius map over `Q_2`, and so
is every element of the pieces. So the generated group is a finitely generated subgroup of `PGL_2(Q_2)`. By
`fg-linear-groups-have-roots-at-finitely-many-primes`, `τ` has roots in it at only finitely many primes.

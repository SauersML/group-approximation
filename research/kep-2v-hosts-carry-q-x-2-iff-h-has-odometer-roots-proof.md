Notation as in the target. For a word `w` of length `k`, identify `w` with the integer `Σ w_i 2^i`.

**Item 1.** As in Step 1 of `odometer-2v-doubling-has-no-compatible-cube-root-proof`, an element `g` commuting
with `s` has the form `g(x, y) = (x + a(y), v(y))` with `a : C → Z_2` continuous. The fibres `C × {y}` are the
`s`-orbit closures, and the centralizer of `τ` in `Aut(T_2)` is `{τ_z}` (item 2 of
`odometer-root-hosts-are-non-affine-and-non-contracting`, used here in `Homeo(C)` via minimality).

On a rectangle `C(p) × C(w)` of a defining partition, `g` is `(p t, w z) ↦ (p' η(t), w' z)` with `η ∈ H`. So
`p + 2^k t + a(wz) = p' + 2^{k'} η(t)` for all `t`, with `k = |p|` and `k' = |p'|`. Then `η` is an affine map
of `Z_2` of slope `2^{k − k'}` that preserves `Z_2`, so `k = k'`, and `η = τ_(a')` with
`a' = (p − p' + a(wz)) / 2^k`, which is constant on `C(w)`. Hence `a' ∈ T_H`. Also
`a = p' − p + 2^k a' ∈ T_H`, because `T_H` is a group containing `Z` and `(τ_(a'))^(2^k) = τ_(2^k a')`. So `a`
is locally constant with values in `T_H`, and `v ∈ V`. Conversely every such map lies in `2V_H` (take
`η = τ_(a(y))` on each piece) and commutes with `s`.

**Item 2.** If `r ∈ 2V_H` has `r^ℓ = s` and trivial second coordinate, then `r` commutes with `s`, so
`r = (x + a(y), y)` by item 1. From `r^ℓ = s`, `ℓ a(y) = 1`, so `a ≡ 1/ℓ ∈ T_H`. Conversely, if `1/ℓ ∈ T_H`
then `τ_(1/ℓ) × id ∈ 2V_H` (one piece) and `(τ_(1/ℓ) × id)^ℓ = s`.

**Item 3.** For `c ∈ Z_2`, `u (τ_c × id) u^-1 (x_0 x', y) = u(τ_c(x'), x_0 y) = (x_0 τ_c(x'), y)`. As a
`2`-adic integer, `x_0 + 2(x' + c) = (x_0 + 2x') + 2c`. So `u (τ_c × id) u^-1 = τ_(2c) × id`. In the coding
`X ≅ {0,1}^Z`, with the second coordinate read leftwards, `u` is the shift and `τ_c × id` adds `c` with
carries propagating to the right. So the group generated by `u` and `{τ_c × id : c ∈ Z_(2)}` acts through the
affine action of `Z_(2)[1/2] ⋊ ⟨2⟩ = Q ⋊ ⟨2⟩` on `X`. On the dense set of sequences with finitely many
nonzero digits on the left, which is `Q_2`, it is the usual affine action of `Q ⋊ ⟨2⟩` on `Q_2`, and that action
is faithful. So the group is `Q ⋊ ⟨2⟩`. Its elements lie in `2V_H`, as products of the generators.

**Item 4.** If `T_H ⊇ Z_(2)` then `H` contains `τ` and `τ_(1/ℓ)` for every odd prime `ℓ`, and these are the
`ℓ`-th roots of `τ`. Items 4(b)–(d) of `odometer-root-hosts-are-non-affine-and-non-contracting` apply to any
finitely generated such `H`, and `automaton-groups-see-only-smooth-periods` excludes finite-state generation.
A finitely presented `H` is residually finite, as a subgroup of `Aut(T_2)`, and contains `Z_(2)`.

Write `q:J -> Q=J/I` for the quotient map and let

```text
I_perp={a in J : aI=Ia=0}.
```

The canonical map `sigma:J -> M(I)` has kernel `I_perp`.  If `tau` is the
Busby map, then

```text
ker(tau)=q(I_perp).
```

Indeed, `tau(q(a))=0` exactly when `sigma(a)` is multiplication by some
element `i in I`; then `a-i` lies in `I_perp` and has the same quotient image
as `a`.  Since `I intersect I_perp=0`, restriction of `q` gives

```text
I_perp isomorphic to ker(tau).
```

Now `ker(tau)` is an ideal of the purely infinite algebra `Q`, hence is
purely infinite.  Therefore `I_perp` is a purely infinite ideal of `J`.
Radical-freeness of `J` forces `I_perp=0`, so `ker(tau)=0`.  This proves both
essentiality and Busby injectivity.  Also `I` cannot be zero, since otherwise
`J=Q` would itself be purely infinite.

Let `C subset J` be nonzero and hereditary.  Essentiality of `I` implies

```text
C intersect I != 0.
```

For if `0 != c in C_+`, then `cIc` cannot vanish: otherwise `c` would
annihilate `I`.  Any nonzero positive element of `cIc` lies in
`C intersect I`.  The same argument inside each nonzero hereditary
subalgebra of `C` shows that `C intersect I` is essential in `C`.

Quotient maps carry hereditary subalgebras to hereditary subalgebras, and

```text
C/(C intersect I) isomorphic to q(C).
```

Thus, when `q(C)` is nonzero, it is a hereditary subalgebra of the purely
infinite algebra `Q` and is purely infinite.  The Morita-hereditary radical
theorem makes `C` and `C intersect I` radical-free, weakly purely infinite,
and non-purely-infinite.  Repeating the annihilator argument proves that this
corner extension is essential as well.

We next translate essentiality into `Cu`.  Given `0 != x in Cu(J)`, represent
it by `a in (J tensor K)_+`.  The stabilized ideal `I tensor K` is essential
in `J tensor K`, so

```text
Her(a) intersect (I tensor K) != 0.
```

Choose a nonzero positive element there.  Its Cuntz class gives
`0 != y in Cu(I)` lying in the principal order ideal generated by `x`; in
particular `y <= infinity x`.  Apply the Morita-hereditary radical theorem to
a nonzero hereditary algebra generated inside this intersection.  It gives
`z in Cu(I)` in the order ideal generated by `y` such that

```text
z < 2z <= ... <= nz = infinity z.
```

Consequently `z <= infinity y <= infinity x`, proving defect-essentiality.

Finally, exactness of the Cuntz semigroup functor identifies

```text
Cu(Q)=Cu(J)/Cu(I).
```

For the quotient order, `bar(u) <= bar(v)` means that there is `w in Cu(I)`
with `u <= v+w`.  Since `Q` is purely infinite,

```text
bar(2x)=bar(x).
```

We can keep the correction inside the principal ideal of `x`.  Let `L` be
the closed ideal of `J` corresponding to the order ideal generated by `x`,
and put `K=L intersect I`.  The image `q(L)` is the ideal of `Q` generated by
`bar(x)`, hence is purely infinite (or zero).  Applying the same quotient
formula to

```text
Cu(q(L))=Cu(L)/Cu(K)
```

gives `w in Cu(K)` satisfying

```text
2x <= x+w.
```

Since `Cu(K)` lies in the principal order ideal generated by `x`, one has
`w <= infinity x`.  Iterating the displayed comparison yields

```text
kx <= x+(k-1)w,
infinity x=nx <= x+(n-1)w.
```

This is the promised exact comparison boundary.  Busby injectivity,
essentiality, and principal support of `w` do not by themselves absorb it;
doing so uniformly would make every class idempotent and settle the remaining
implication.

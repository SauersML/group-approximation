Let `Γ` be finitely generated, perfect and amenable, with finite generating set `S`.

1. **The system.** Gao--Jackson--Seward give a free minimal subflow `X ⊆ 2^Γ`; it is an infinite compact totally
   disconnected metrizable space, and the action is free, so the transformation groupoid is principal, Hausdorff, ample
   and minimal with compact infinite unit space.
2. **The ring.** `R = LC(X,F_2) ⋊ Γ` is the Steinberg algebra of that groupoid. It is simple with centre `F_2`. It is
   finitely generated: the indicator of the clopen set `[x_e = 1]` and its `Γ`-translates `u_γ e u_γ^(-1)` span
   `LC(X,F_2)`, because those cylinders separate points, so `{e} ∪ {u_s : s ∈ S ∪ S^(-1)}` generates `R` as a ring.
3. **The group.** `G = EL_3(R)` is finitely generated by `elementary-groups-over-fg-rings-have-property-t`'s generating
   set and has property (T). It is simple modulo its centre, and over `F_2` the centre is trivial, since central
   elements are scalars from `Z(R)^× = F_2^× = {1}`. It is infinite because `r ↦ e_12(r)` is injective on the infinite
   set `LC(X,F_2)`.
4. **Linear soficity.** `Γ` is amenable and acts minimally on `X`, so `R` has a faithful Sylvester matrix rank function
   coming from a unital embedding into a rank ultraproduct of matrix algebras over `F_2`. The reviewed transfer theorem
   turns that into `F_2`-linear soficity of the projective elementary group, which here is `G` itself.
5. **The embedding.** `Γ` is perfect, so `γ ↦ diag(u_γ,1,1)` is an injective homomorphism `Γ → EL_3(R) = G`.

**Model tests.** For `Γ` finite the subflow is not free, and indeed no statement is claimed. For `Γ = Z` the group is not
perfect and step 5 fails, consistent with `shift-unit-of-subshift-crossed-product-is-not-elementary`. For `Γ = [[T]]'`
every step applies.

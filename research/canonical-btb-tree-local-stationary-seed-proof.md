Install the common regular packet multiplicity vector, tensor it with a
scalar structural assignment having a positive forbidden atom, and take the
full protected seed `e_0` as the root carrier.  Protected wordization makes
`e_0` reducing for the complete carrier menu.  The edgewise Schur theorem
allows the first multiplicity gauge to preserve the `e_0` reservoir, so its
conditioned return lies below `e_0`.  Therefore the prescribed minimal
reducing hull of the root joined with that return is again exactly `e_0`.

Repeat outward along the finite tree.  Since no relator contains two edge
intertwiners, the new gauge choice does not change any earlier edge row.
Regular stationary restriction multiplicities make every edge covariance
table compatible, while the BTB--E5 cut stays positive.  Induction gives
`Q_sigma=e_0` and full overlap at every reached node, proving the claim.

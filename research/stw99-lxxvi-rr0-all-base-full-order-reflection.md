Let D be separable, simple, stably finite, pure, and real rank zero.
For every second-countable locally compact Hausdorff X, the actual
first-factor map

```text
C_0(X,D) -> C_0(X,D tensor Z)
```

induces an order embedding on Cu. In particular, it reflects Cuntz
comparison between arbitrary positive source sections, with no
dimension restriction on X and no compactness or softness restriction
on either global class.

The result does not assert realization of arbitrary mixed target
classes. That surjectivity problem remains necessary for full Cu
regularity of this entire coefficient class and is separate from
the order-reflection theorem proved here.

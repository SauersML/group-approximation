Notation is as in the claim. `K_v = Stab_L(v)` is compact open, `K_0 = SL_2(Z_p)`,
`K(p^k) = ker(K_0 → SL_2(Z/p^k))`, `a_t = diag(p^(-t), p^t)`, `N_+(R) = {[[1,r],[0,1]] : r ∈ R}`
and `N_-(R)` its transpose. Because `Z[1/p] ∩ Z_p = Z`, we have `A ∩ K_v = C^v` for every vertex `v`.

## Step 0. Reductions

- **Every vertex, not just `b`.** Adjacent vertex stabilizers are commensurable in `A`
  (`[C^v : C^v ∩ C^w] = p+1`), and `T` is connected. So `D ∩ C^v` has finite index in `C^v` for
  every vertex `v`.
- **The closure contains a congruence subgroup.** Let `U` be the closure of `D` in `L`. The
  subgroup `Γ := D ∩ C_0` has finite index in `SL_2(Z)`. `SL_2(Z)` is dense in `K_0`, because
  `SL_2(Z) → SL_2(Z/p^k)` is onto. So the closure of `Γ` is a closed subgroup of finite index in
  `K_0`. It is therefore open and contains some `K(p^k)`. Hence `K(p^k) <= U`.

## Step 1. Compact closure: `D` fixes a vertex

Suppose `U` is compact. `U ∩ K_0` is open in `U`, so `U·v_0` is finite and `D·v_0 ⊆ U·v_0` is a
finite `D`-invariant set of vertices. A bounded set in a tree has a unique circumcenter, which is
a vertex or an edge midpoint. It is `D`-invariant. `A` preserves vertex types, so a stabilized edge
has both endpoints fixed. So `D` fixes a vertex.

## Step 2. Noncompact closure: `U = L`

**A hyperbolic element in `U`.** `U ∩ K_0` is open in `K_0`, so it has finite index. Choose finite
sets with `K_0 = ⊔_i (U∩K_0) x_i = ⊔_i y_i (U∩K_0)`.

- By the Cartan decomposition `L = ∪_(t>=0) K_0 a_t K_0`, and each `K_0 a_t K_0` is compact.
- A noncompact `U` lies in no finite union of these double cosets. So there are `u_j ∈ U` and
  `t_j → ∞` with `u_j = k_j a_(t_j) k'_j`.
- Write `k_j = w x_i` and `k'_j = y_(i') w'` with `w, w' ∈ U ∩ K_0`. Then
  `x_i a_(t_j) y_(i') ∈ U`.
- By pigeonhole a single pair `(x, y) = (x_i, y_(i'))` occurs for infinitely many `j`. For two of
  them with `t_j > t_l`,

  ```text
  s := (x a_(t_j) y)(x a_(t_l) y)^(-1) = x a_t x^(-1) ∈ U,   t = t_j - t_l >= 1,  x ∈ K_0.
  ```

**Unipotent contraction.** `K(p^k)` is normal in `K_0` and `x ∈ K_0`, so
`x N_±(p^k Z_p) x^(-1) <= K(p^k) <= U`. We have `a_t N_+(r) a_t^(-1) = N_+(p^(-2t) r)` and
`a_t N_-(r) a_t^(-1) = N_-(p^(2t) r)`. Therefore, for all `m >= 0`,

```text
s^m  x N_+(p^k Z_p) x^(-1)  s^(-m) = x N_+(p^(k-2tm) Z_p) x^(-1) <= U,
s^(-m) x N_-(p^k Z_p) x^(-1) s^m   = x N_-(p^(k-2tm) Z_p) x^(-1) <= U.
```

The unions over `m` give `x N_+(Q_p) x^(-1) <= U` and `x N_-(Q_p) x^(-1) <= U`. Over a field,
`SL_2` is generated by its upper and lower unipotent subgroups. So `U >= x L x^(-1) = L`.

## Step 3. Dense `D`: finite index and transitive vertex groups

Let `j ∈ {0,1}` and `g ∈ L`. The set `g K_(v_j)` is open, so it contains some `d ∈ D`, and then
`d v_j = g v_j`. Hence `D·v_j = L·v_j ⊇ A·v_j`.

For `a ∈ A` pick `d ∈ D` with `d v_j = a v_j`. Then `d^(-1) a ∈ A ∩ K_(v_j) = C_j`. So
`A = D C_j = C_j D`, which means `C_j` is transitive on `A/D`, and
`|A/D| = [C_j : C_j ∩ D] < ∞`.

This proves (V1). (V3) is the transitivity just shown, applied to a finite orbit `A/D`: its
stabilizer has finite index, so its closure is open and noncompact, and Step 2 applies.

## Step 4. The rooted quotient tree

Let `X` be as in (V2) and fix one A-orbit `A/D`. Every `C_0`-orbit is finite, so
`D ∩ C_0 = Stab_(C_0)(D)` has finite index. `A/D` is infinite, so by (V1) `D` fixes a vertex `r`.

**Dictionary.**

| points of `A/D` | orbits of `D` on `T` | size |
|---|---|---|
| the `C_j`-orbit of `aD` | the vertex `v = a^(-1) v_j` | `n_v = [C^v : D_v]`, `D_v = D ∩ C^v` |
| the `B`-orbit of `aD` | the edge `e = a^(-1) e_0` | `m_e = [B^e : D ∩ B^e]` |

Here `e_0 = {v_0, v_1}` and `B^e = Stab_A(e)`. A point lies in the `B`-orbit of `e` and in the
vertex orbits of both endpoints of `e`. The `C^v`-orbit of a vertex is partitioned by the `B`-orbits
of its incident quotient edges, so

```text
n_v = Σ_(quotient edges [e] at [v]) m_e.                               (P1)
```

**Parents.** Every `v != r` has a parent edge `e_p(v)`: the first edge of the geodesic from `v` to
`r`. `D` fixes `r`, so it preserves the parent map, and `D\T` is a rooted tree on the orbits.

- Each quotient edge `[e]` has a unique child endpoint `[c]` with `[e] = [e_p(c)]`.
- Distinct quotient edges have distinct child endpoints. If `c' = dc` then
  `e_p(c') = d e_p(c)`.

**Child identity.**

- `D_c` fixes both `c` and `r`, so it fixes the geodesic between them and `D_c <= B^(e_p(c))`.
- Also `D ∩ B^(e_p(c)) <= D ∩ C^c = D_c`. So the two groups are equal.
- `B^(e_p(c))` has index `p+1` in `C^c`, because `C^c` is dense in `K_c`, which is transitive on
  the `p+1` neighbours of `c`.

Hence

```text
m_(e_p(c)) = [B^(e_p(c)) : D_c] = n_c / (p+1).                         (P2)
```

## Step 5. Proof of (VW)

The windows `P_0` and `P_1` meet finitely many orbits, and both sides of `(VW)` add over orbits. So
fix one orbit, and let `F` be the finite set of quotient vertices making up `P_0 ∪ P_1`, of both
types. Put `W = |P_0| + |P_1| = Σ_(v∈F) n_v`. Split the quotient edges with an endpoint in `F`:

- `I` is the total weight of quotient edges with both endpoints in `F`;
- `∂` is the total weight of quotient edges with exactly one endpoint in `F`.

**The mismatch is `∂`.** A point in the `B`-orbit of `e = {v, w}`, with `v` of type `0`, lies in
`P_0` iff `[v] ∈ F` and in `P_1` iff `[w] ∈ F`. So `|P_0 Δ P_1| = ∂`.

**The bound.**

- By `(P1)`, `W = 2I + ∂`.
- Every edge counted in `I` is the parent edge of its child endpoint, and that endpoint lies in `F`.
  The child map is injective, so `(P2)` gives `I <= Σ_(c∈F) n_c/(p+1) = W/(p+1)`.
- Therefore `∂ = W - 2I >= W (p-1)/(p+1)`.

**Check against the radial-shell firewall.** At `p = 2` with `|P_0| = |P_1| = D` this gives
`|P_0 Δ P_1| >= 2D/3`, so at least `D/3` points on each side are unmatched. That is the constant of
`dyadic-radial-shell-couplings-have-one-third-boundary`, whose spheres are the special case `D` a
congruence subgroup of `C_0`.

The notation is that of the target.  Words are taken in `F = F(x_1,...,x_r)`,
and bars denote images in the group under discussion.

## Cited inputs

- **(C1)** From `abelianized-cover-commutator-is-finitely-generated-perfect`,
  verbatim: "Then `T` is nontrivial and: ... 2. **perfect**, `T = T'`;
  3. **finitely generated**, with `d(T) <= r + s + r^2`".
- **(C2)** From `abelianized-cover-mf-radical-is-union-of-local-cover-radicals`,
  verbatim: "Then `N_L` is finitely normally generated, `U_L N_L = [R,R]`,
  and each `Gamma_L` is a finitely presented group that surjects onto
  `E = F/[R,R]`."  The `N_L` increase with `L`, because the generating set
  `{[u,v] : u, v in R, |u|, |v| <= L}` increases.
- **(C3)** From the same claim, item 3, verbatim: "If `G` has no nontrivial
  finite quotient, then every finite quotient `phi : Gamma_L ->> P`
  satisfies: ... if `P` is non-abelian, then `diam_X(P) >= (L - c + 1)/2`."
  A group with full MF radical has no nontrivial finite quotient, because
  finite groups are MF.

## Step 1: a finite certificate in E

By (C1), choose elements of `T` that generate it, `d <= r + s + r^2` of them.
The map `[F,F] -> [E,E] = T` is onto, so we may lift them to words
`t_1, ..., t_d` in `[F,F]`.  Three families of identities hold in `E`.

- **(i) Commutators of generators.**  For `1 <= i < j <= r`,
  `[x_i,x_j]` lies in `E' = T`.  So there is a word `W_ij` in `d` letters
  with `[x_i,x_j] = W_ij(t)` in `E`.
- **(ii) Conjugation.**  `T` is normal in `E`.  So for each `k`, each sign
  `e = +-1` and each `a`, there is a word `V_(k,e,a)` with
  `x_k^e t_a x_k^(-e) = V_(k,e,a)(t)` in `E`.
- **(iii) Perfectness.**  `T = T'` by (C1).  So each `t_a` is, in `E`, a
  finite product of commutators of elements of `T`, and each of those
  elements is a word in the `t`.  That is, there are words `U_(a,b)` and
  `U'_(a,b)` with
  ```text
  t_a = prod_(b=1)^(m_a) [ U_(a,b)(t), U'_(a,b)(t) ]      in E.
  ```

Each identity says that a specific word of `F` lies in `[R,R]`:

```text
c_ij      = W_ij(t)^(-1) [x_i,x_j],
c_(k,e,a) = V_(k,e,a)(t)^(-1) x_k^e t_a x_k^(-e),
c_a       = ( prod_b [U_(a,b)(t), U'_(a,b)(t)] )^(-1) t_a.
```

This is a finite set `C` of elements of `[R,R]`.

## Step 2: the threshold

By (C2), `[R,R]` is the increasing union of the `N_L`.  The set `C` is
finite, so there is an `L_1` with `C` contained in `N_(L_1)`, and hence in
`N_L` for every `L >= L_1`.  Fix such an `L`.  In `Gamma_L = F/N_L`, every
element of `C` is trivial, so identities (i)--(iii) hold in `Gamma_L` with the
same words.

## Step 3: items 1 and 2 of the target

Let `T_L` be the subgroup of `Gamma_L` generated by `t̄_1, ..., t̄_d`.

- **`T_L` is normal.**  By (ii), `x̄_k^e t̄_a x̄_k^(-e)` lies in `T_L` for
  every `k`, every sign `e` and every `a`.  So conjugation by each `x̄_k^(+-1)`
  maps `T_L` into itself.  These elements generate `Gamma_L`, so `T_L` is
  normal.
- **`T_L = Gamma_L'`.**  Each `t_a` lies in `[F,F]`, so `T_L <= Gamma_L'`.
  Conversely, by (i) the images of the `x̄_i` commute pairwise in the quotient
  `Gamma_L/T_L`.  That quotient is generated by those images, so it is
  abelian, and therefore `Gamma_L' <= T_L`.  This gives item 1, with the
  same bound `d <= r + s + r^2`.
- **`T_L` is perfect.**  In (iii), the words `U_(a,b)(t̄)` and
  `U'_(a,b)(t̄)` lie in `T_L`.  So each generator `t̄_a` lies in `T_L'`,
  hence `T_L = T_L'`.  By induction `Gamma_L^(k) = Gamma_L'` for all
  `k >= 1`.  This is item 2.

## Step 4: items 3 and 4 of the target

- **Item 3.**  Let `phi : Gamma_L -> H` be a homomorphism.  Then
  `phi(Gamma_L)' = phi(Gamma_L')`, and this is generated by the `d` elements
  `phi(t̄_a)`.  It is perfect, because a homomorphic image of a perfect group
  is perfect.  If `H` is solvable, `phi(Gamma_L')` is solvable and perfect,
  and so trivial.  Then `phi` factors through
  `Gamma_L^ab = F/(F' N_L)`.  Since `N_L <= [R,R] <= F'`, this is
  `F^ab = Z^r`.
- **Item 4.**  Let `P` be a nonabelian finite quotient.  Then `P'` is
  nontrivial and, by item 3, perfect and `d`-generated.  A nontrivial finite
  perfect group is not solvable.  So some composition factor of `P'`, which
  is also one of `P`, is a nonabelian simple group.  The diameter bound is
  (C3).  QED

## What the certificate does and does not use

- It uses only that `T = E'` is finitely generated, normal and perfect in
  `E`, together with `U_L N_L = [R,R]`.  The full MF radical enters only
  through (C1), which needs `G` perfect, and through (C3).
- `L_1` exists but is not bounded here in terms of the presentation of `G`.
  It is found by a terminating search.  `[R,R]` is recursively enumerable,
  so one can enumerate candidate tuples `t` with words `W, V, U, U'` and
  membership certificates `c in N_L`.  The search stops, because Step 1
  shows that a valid tuple exists.

The two required nodes give that the host is F_infinity, simple and rigid for any strongly
faithful, minimal, cocompact action with `F_∞^+` edge groups and no fixed end. The target node
checks these hypotheses for the explicit `Λ`. It then computes the path stabilizers in the
Bass–Serre tree, which gives an end stabilizer `Z[1/2]`, and identifies the germ group of the host
at `(ξ, ω)` with that stabilizer. The computations are elementary and written out in full there.

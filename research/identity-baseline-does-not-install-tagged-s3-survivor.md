**ESTABLISHED SCOPE NO-GO.**  Let `R` be one current carrier and let an S3
endpoint copy decompose as

```text
R=P_live orthogonal_sum P_exit.                         (IBS1)
```

Suppose the two-bit tag bridge sends these pieces to

```text
u P_live u^* <= C_(n+1),       u P_exit u^* <= X_n,
C_(n+1) X_n=0.                                         (IBS2)
```

At the scalar level a second untouched child copy gives the exact desired
branching identity

```text
2 tau(R)
 =tau(R)+tau(P_live)+tau(P_exit).                       (IBS3)
```

This observation is useful, but an identity return of the first summand does
not turn `(IBS3)` into a recurrent carrier.

There are only two interpretations of that return.

1. If the identity copy is the same represented subspace `R`, then putting it
   in the next carrier retains `P_exit<=R`.  Hence the previously charged
   exit is still present.  Moreover adjoining the live source before
   transport changes no carrier at all, since `P_live<=R`.

2. If the identity copy means a separately named Schur child `R_0` while
   `(IBS1)` is a second child `R_1`, then `(IBS3)` is a valid local
   two-child ledger.  But the proposed next carrier is

```text
Q_(n+1)=R_0 orthogonal_sum u P_live u^*.                (IBS4)
```

   The tag theorem places only the second summand below `C_(n+1)`.  Unless
   `R_0<=C_(n+1)` is separately authenticated, `(IBS4)` is not a successor
   prefix source and cannot be fed to the next S3 occurrence.  If
   `R_0<=C_(n+1)` is imposed by an exact identity/full-chart/finite-character
   return, it is precisely a companion-free functorial baseline return.
   `companion-free-prefix-return-has-exponential-regular-capacity` then gives

```text
tau(R_0)<=2^(-N)                                        (IBS5)
```

   in the canonical trace at depth `N`, so it cannot supply the fixed-mass
   baseline required by the first-hit contradiction.

The same conclusion holds if the three live endpoint atoms are transported
separately.  Their affine HNN transports prove `(IBS2)` atom by atom, but
they do not put the independent identity child under the same successor
prefix.  Conversely, adding the identity child analytically to the live
union produces the projection in `(IBS4)` but no ordinary group relation
which installs it as the next complete context carrier.

Thus the identity splice solves **only the one-level trace equation**.  It
does not require a scalar reflection for the three-atom S3 survivor, but it
does still require the genuinely nonstationary seam in
`tagged-s3-survivor-installs-next-recurrent-carrier`: a matrix-only
multiplicity/holonomy assertion which places both the untouched child and
the routed survivor in one next occurrence while remaining false in the
canonical regular factor.

## Exact boundary

This is not a no-go for every possible two-child compiler.  It rules out the
specific proposal in which the missing baseline incidence is declared to be
the identity or any other exact trace-neutral finite-chart return.  A live
construction may still use a payload-sensitive multiplicity two-cell, a
Toeplitz/proper-corner recurrence, or a non-prefix reservoir.

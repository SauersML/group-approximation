Notation is as in the claim. Put `T̂ = {I + E_kl ∈ SL_d(Z) : k ≠ l} ⊆ Ĝ`. We check the hypotheses of
`kazhdan-cover-actor-models-normalize-vertex-commutants` and apply it.

1. **`Ĝ` and `P` are defined.** Each `φ_A` is a ring automorphism of `L`, with inverse `φ_(A^-1)`,
   and `φ_A φ_B = φ_(AB)`. The Steinberg group is a functor on rings: a ring map `ψ` sends `x_ij(f)`
   to `x_ij(ψ f)` and respects the Steinberg relations. So `SL_d(Z)` acts on `St_r(L)` by
   automorphisms, and `St_r(L) -> EL_r(L)`, `x_ij(f) -> e_ij(f)`, is equivariant. `P` is that map
   times the identity on `SL_d(Z)`. It is onto because `EL_r(L)` is generated by the `e_ij(f)`, and
   its kernel is `N_St`.
2. **`P(Γ̂) = Γ`.** The images `e_ij(f)`, `f ∈ R_+`, of the generators of `Γ̂` generate
   `EL_r(R_+)` by definition.
3. **`Γ̂` has property (T).** `Γ̂` is the image of `St_r(R_+) -> St_r(L)`. `St_r(R_+)` has property
   (T) by `ershov-jaikin-kassabov-steinberg-groups-have-property-t`: type `A_(r-1)`, rank
   `r - 1 >= 2`, and `R_+` is finitely generated and commutative. Quotients of groups with property (T)
   have property (T).
4. **Lifted compressors.** For `A = I + E_kl` all entries are nonnegative, so `A a ∈ N^d` for
   `a ∈ N^d`, and `φ_A(R_+) ⊆ R_+`. In `Ĝ`, `A x_ij(f) A^-1 = x_ij(φ_A f) ∈ Γ̂` for `f ∈ R_+`. The
   `x_ij(f)` generate `Γ̂`, so `A Γ̂ A^-1 <= Γ̂`.
5. **Generation: `G = <Γ ∪ P(T̂)>`.**
   - `P(T̂)` generates `SL_d(Z)`, since `SL_d(Z)` is generated by elementary matrices (row reduction
     by the Euclidean algorithm; classical).
   - `EL_r(L)` is generated by the `e_ij(λ x^b)`, `λ ∈ F_q`, `b ∈ Z^d`, because `e_ij` is additive.
   - For `b = 0` these lie in `Γ`.
   - For `b ≠ 0` write `b = c b'` with `c >= 1` and `b'` primitive. Integer row reduction carries
     `b'` to `e_1`, so `b' = B e_1` for some `B ∈ SL_d(Z)`, and `b = B (c e_1)` with `c e_1 ∈ N^d`.
     In the semidirect product, `e_ij(λ x^b) = B e_ij(λ x^(c e_1)) B^-1`, a conjugate of an element
     of `Γ` by an element of `<P(T̂)>`.
6. **Apply the cover theorem.** `ρ_n` and (KC) are the claim's hypotheses with `N = N_St`. The
   theorem gives the ultraproduct formula for `σ(Γ)' ∩ prod_U M_(d_n)` and its normalization by
   `σ(G)`. ∎

**Which facts are used.** Only functoriality of Steinberg groups, property (T) of `St_r(R_+)`, and
elementary integer linear algebra. Nothing about the size, centrality or stability of `N_St` is used,
so `r = 3` is covered.

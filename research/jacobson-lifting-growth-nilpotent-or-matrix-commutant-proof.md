Notation as in the target. The only input is the Theorem of `jacobson-compressor-commutant-growth-splits`
(ESTABLISHED), used verbatim in the form of its parts 1 and 2 and of Step 3 of its route:

> 1. **Symbol rigidity.** `rho(g) C_R(Gamma) rho(g)^-1 = C_R(Gamma) = C_R(Gamma')`.
> 2. **Lifting sequence.** For `Delta` equal to `Gamma` or `Gamma'`, the sequence
>    `0 -> M_N(I)^Delta -> A(Delta) -> C_R(Gamma) -> H^1(Delta, M_N(I))` is exact, with last map `delta_Delta`.
>    Moreover `delta_(Gamma') = res o delta_Gamma`.
>
> `B(g) = ker(res o delta_Gamma) / ker(delta_Gamma)`.

## Step 1. Shift formula (Theorem part 1)

- Exactness at `C` gives `ker delta_Delta = rho(A(Delta))` for `Delta` in `{Gamma, Gamma'}`.
- So `ker delta_Gamma = P`, and `ker(res o delta_Gamma) = ker delta_(Gamma') = rho(A(Gamma'))`.
- `A(Gamma') = A(g Gamma g^-1) = g A(Gamma) g^-1`, since `X` commutes with `g gamma g^-1` exactly when `g^-1 X g`
  commutes with `gamma`.
- `rho` is a ring homomorphism, so `rho(A(Gamma')) = h P h^-1 = beta(P)`. Here `P <= C`, so `beta(P)` is defined.
- `Gamma' <= Gamma` gives `A(Gamma) <= A(Gamma')`, hence `P <= beta(P)`.
- Therefore `B(g) = beta(P) / P`.

## Step 2. Saturation trap (Theorem part 2)

- `C` is an `R`-submodule of `M_N(R)`, because scalars `r 1_N` are central. `M_N(R)` is a finitely generated
  module over the noetherian ring `R`, so `C` is a noetherian `R`-module.
- `beta` is `R`-linear, because `h (r X) h^-1 = r (h X h^-1)` for `r in R`.
- Let `Q = R.P`, the `R`-submodule generated by `P`. Then `beta(Q) = R.beta(P)`, which contains `R.P = Q`.
- So `Q <= beta(Q) <= beta^2(Q) <= ...` is an ascending chain of submodules of `C`. It stabilizes:
  `beta^k(Q) = beta^(k+1)(Q)` for some `k`. Applying the bijection `beta^-k` gives `Q = beta(Q)`.
- Hence `beta(P) <= beta(Q) = Q`, and `B(g) = beta(P)/P` is a subspace of `Q/P`.
- If `P` is an `R`-submodule then `Q = P`, so `B(g) = 0`.

## Step 3. Powers (Theorem part 3)

- `g^k Gamma g^-k <= Gamma` by induction on `k`. So `g^k` is a compressor, with symbol `h^k` and automorphism
  `beta^k` of `C`.
- By Step 1 applied to `g^k`, `B(g^k) = beta^k(P) / P`.
- Iterating `P <= beta(P)` gives the chain `P <= beta(P) <= ... <= beta^k(P)`.
- For `1 <= j <= k`, the `F`-linear bijection `beta^(j-1)` of `C` maps `beta(P)` onto `beta^j(P)` and `P` onto
  `beta^(j-1)(P)`. So `beta^j(P) / beta^(j-1)(P) ~= beta(P)/P = B(g)`.
- A space with a filtration of length `k` whose `k` layers each have dimension `d` has dimension `k d`. So
  `dim B(g^k) = k dim B(g)`, and `B(g^k) = 0` exactly when `B(g) = 0`.

## Step 4. Finite order (Theorem part 4)

If `beta^m = id_C`, then `beta^m(P) = P`. So `P <= beta(P) <= beta^m(P) = P`, and `B(g) = 0`.

## Step 5. Reduced commutative symbol commutants (Theorem part 5)

Assume `C` is commutative and has no nonzero nilpotent elements.

- **Base change.** `C` is a submodule of the free module `M_N(R)`, so it is torsion-free. Put `S0 = R \ {0}`.
  Its elements are central non-zero-divisors of `C`, so `C -> C_K = S0^-1 C` is injective. `C_K` is the
  `K`-span of `C` inside `M_N(K)`, and `dim_K C_K <= N^2`.
- **`C_K` is a finite product of fields.** A localization of a reduced commutative ring is reduced: if
  `(c/s)^n = 0` then `t c^n = 0` for some `t in S0`, so `c^n = 0` and `c = 0`. A reduced commutative artinian
  ring is a finite product of fields, by the Chinese remainder theorem applied to its finitely many maximal
  ideals, whose intersection is the nilradical `0`. So `C_K = L_1 x ... x L_r` with each `L_i` a field of finite
  degree over `K`.
- **Automorphisms extend.** Every `R`-algebra automorphism `a` of `C` extends to the `K`-algebra automorphism
  `c/s |-> a(c)/s` of `C_K`. It is well defined because `a` is `R`-linear, and the extension map
  `Aut_R(C) -> Aut_K(C_K)` is an injective homomorphism.
- **`Aut_K(C_K)` is finite.** An automorphism permutes the `r` primitive idempotents. The subgroup fixing them
  all acts factorwise by `K`-automorphisms of the `L_i`. A `K`-automorphism of `L_i` is determined by its values
  on finitely many field generators, each of which must go to one of the finitely many roots in `L_i` of its
  minimal polynomial over `K`. So each `Aut_K(L_i)` is finite, and so is `Aut_K(C_K)`.
- **Conclusion.** `beta` has finite order, so `B(g) = 0` by Step 4. This holds for every compressor `g` of
  `Gamma`, and by the splitting theorem the whole growth `A(Gamma')/A(Gamma)` is then type (a).
- **When this applies.** `C_K` is the commutant of `rho(Gamma)` in `M_N(K)`: if `X in M_N(K)` commutes with
  `rho(Gamma)`, then so does `r X in M_N(R)` for a common denominator `r`. If `K^N` is a direct sum of pairwise
  non-isomorphic simple `K rho(Gamma)`-modules with commutative endomorphism rings `E_i`, Schur's lemma gives
  `C_K = prod_i E_i`, a product of fields. Then `C <= C_K` is commutative and reduced. For an absolutely
  irreducible `rho(Gamma)` this is `C_K = K`, and `C = K cap M_N(R) = R.1`.

## Step 6. The Corollary

Assume `B(g) != 0`.

- By Step 4, `beta` has infinite order. By Step 5, `C` is not both commutative and reduced.
- If `C_K` is semisimple and commutative, it is a finite product of fields, hence reduced, and so is its subring
  `C`. That is excluded. So either `C_K` is not semisimple, which is (N), or it is semisimple and noncommutative,
  which is (M).
- **(N).** The radical of a finite-dimensional algebra is a nilpotent ideal, here a nonzero one consisting of
  intertwiners of `rho(Gamma)`. If `K^N` were a semisimple `K rho(Gamma)`-module, its endomorphism ring `C_K`
  would be semisimple.
- **(M).** `beta` extends to `C_K` (Step 5, third bullet, which uses only `R`-linearity).
  - Its restriction to the center `Z(C_K)`, a finite product of fields, has finite order `m` by the finiteness
    argument of Step 5.
  - So `beta^m` fixes every central idempotent and is `Z(C_K)`-linear on each simple factor `A_i`, which is
    central simple over its center `L_i`.
  - By the Skolem--Noether theorem (every automorphism of a finite-dimensional central simple algebra that fixes
    its center is inner), `beta^m = Ad(w_i)` on `A_i` for some `w_i in A_i^x`.
  - Put `w = sum_i w_i in C_K^x`. For a common denominator `r in S0`, `r w in C` and `Ad(r w) = Ad(w) = beta^m`.
    It normalizes `C` because `beta^m` does, and it has infinite order because `beta` does.
  - `B(g^m) != 0` by Step 3, so the pair `(Gamma, g^m)` realizes shape (M) with inner `beta^m`.
  - For semisimple `rho(Gamma)`, Schur's lemma writes `C_K = prod M_(n_i)(D_i)`, so noncommutativity means some
    `n_i >= 2` or some noncommutative `D_i`.

## Step 7. The two shapes occur at the level of algebras

Let `h = diag(x^-1, x)` in `GL_2(R)`. Then `beta = Ad(h)` sends `[[a, b], [c, d]]` to `[[a, x^-2 b], [x^2 c, d]]`.

- `det h = 1`, so `h` is the symbol of an element of `GL_2(J)`: for instance `h = rho(u)^-1` for
  `u = [[S, Q], [0, T]]`, `Q = 1 - ST`, whose inverse is `[[T, 0], [Q, S]]` because `QS = TQ = 0`.
- (N): `C = {[[a, b], [0, a]] : a, b in R}` is `beta`-stable, `C_K ~= K[e]/(e^2)`, and
  `P = {[[a, b], [0, a]] : a in F, b in x^2 F[x]}` is a unital `F`-subalgebra.
- (M): `C = M_2(R)` and `P = {[[a, b], [0, d]] : a, d in F, b in x^2 F[x]}` is a unital `F`-subalgebra, since
  `[[a, b], [0, d]] [[a', b'], [0, d']] = [[a a', a b' + b d'], [0, d d']]`.
- In both, `beta(P)` is the same set with `b in F[x]`, so `P < beta(P)` and `beta(P)/P ~= F[x]/x^2 F[x]`, of
  dimension 2.

So Steps 1--6 cannot be sharpened by algebra alone. Whether such `P` equals `rho(A(Gamma))` for an actual subgroup
`Gamma` of `GL_N(J)` compressed by `g` is exactly the open residue.

## Step 8. Consequence for DD

Corollary 1 of `jacobson-compressor-commutant-growth-splits` says that if every compressor has finite growth
`dim A(g Gamma g^-1)/A(Gamma)`, then a Kazhdan (or `Hom(D_G, Z) = 0`) infranormal pair has trivial rigid defect.
By the splitting theorem that growth is `(type (a)) + dim B(g)`. Under the hypothesis of Step 5, `B(g) = 0` for
every compressor. So a nontrivial rigid defect of such a pair needs a compressor with infinite type (a) growth.

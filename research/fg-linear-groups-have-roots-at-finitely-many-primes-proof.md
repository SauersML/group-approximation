Direct proof. Let `A` be the subring of `K` generated by the entries of the
generators of `Λ` and of their inverses. Then `A` is a finitely generated domain
over its prime ring, `Λ <= GL_N(A)`, and `F = Frac(A)` is a finitely generated
field. Suppose, for a contradiction, that `P` is an infinite set of primes and
that `y_q ∈ Λ` satisfies `y_q^q = x` for every `q ∈ P`.

**Step 1: every eigenvalue of `x` is a root of unity.**

*Reduction to one field.* Let `λ` be an eigenvalue of `x`, and let `F_1` be `F`
with the eigenvalues of `x` adjoined; this is a finite extension. The
eigenvalues of `x = y_q^q` are `q`-th powers of eigenvalues of `y_q`, so
`λ = μ^q` for some `μ` with `d = [F_1(μ):F_1] <= N`. Taking norms from
`F_1(μ)` to `F_1` gives `λ^d = ν^q` with `ν ∈ F_1`. Hence `λ^{N!}` is a `q`-th
power in `F_1^×` for every `q ∈ P`.

*(a) `λ` transcendental over the prime field `k`.* The `λ`-adic valuation of
`k(λ)` has value group `Z`. Extend it to a discrete valuation `w` of `F_1`:
- extend by the Gauss valuation over a transcendence basis of `F_1/k(λ)`;
- then extend to the finite extension, where the value group contains `Z` with
  finite index.

Then `w(λ^{N!}) = N!·w(λ) ≠ 0`, and it is divisible by every `q ∈ P` in `Z`.
That is impossible.

*(b) `λ` algebraic over `k`.*
- If `char k = ℓ > 0`, `λ` lies in a finite field and is a root of unity.
- If `char k = 0`, then `λ` and each `q`-th root `ν_q` of `λ^{N!}` are algebraic.
  They lie in the algebraic closure `k_0` of `Q` in `F_1`, a number field because
  `F_1` is finitely generated.
  - A finite place `v` of `k_0` with `v(λ) ≠ 0` gives the same contradiction as
    in (a). So `λ` is a unit, and then so is each `ν_q`.
  - By Dirichlet's unit theorem, `log` maps `O_{k_0}^×` onto a lattice. The image
    of `λ^{N!}` is divisible in that lattice by infinitely many primes, so it is
    0.
  - Hence every archimedean absolute value of `λ` is 1. Since `λ` is an
    algebraic integer, Kronecker's theorem makes `λ` a root of unity.

**Step 2: positive characteristic.** By Step 1, `x^M` is unipotent for some
`M >= 1`. In characteristic `ℓ`, `(I + n)^{ℓ^N} = I` for nilpotent `n`, so `x`
has finite order, a contradiction.

**Step 3: characteristic 0, unipotent roots.**
- Put `u = x^M ≠ I`, which is unipotent of infinite order. Put
  `z_q = y_q^M ∈ Λ`, so that `z_q^q = u`.
- The eigenvalues of `z_q` are `q`-th roots of unity lying in extensions of `F`
  of degree `<= N`. Let `k_F` be the algebraic closure of `Q` in `F`. The
  extension `F/k_F` is regular, so
  `[F(ζ_q):F] = [k_F(ζ_q):k_F] >= (q-1)/[k_F:Q]`. Hence for all but finitely
  many `q ∈ P` the eigenvalues all equal 1, and `z_q` is unipotent.
- In characteristic 0, `log` is a bijection from unipotent to nilpotent matrices
  with `log(z^q) = q log z`. So `z_q = exp(L/q)` with `L = log u ≠ 0`
  nilpotent.
- Let `r >= 1` be maximal with `L^r ≠ 0`. Fix an entry `(i,k)` with
  `(L^r)_{ik} ≠ 0`, and put `a_j = (L^j)_{ik}/j! ∈ F` for `0 <= j <= r`, so
  `a_r ≠ 0`. The `(i,k)` entry of `z_q` is `e_q = Σ_{j<=r} a_j q^{-j}`, and it
  lies in `A` for all but finitely many `q ∈ P`.

**Step 4: a valuation separates `q`.**
- Choose `b ∈ A \ {0}` with `b a_j ∈ A` for all `j`, and put
  `A' = A[1/b, 1/(b a_r)]`. This is a finitely generated domain containing `A`
  in which every `a_j` lies and `a_r` is a unit.
- `A'` is a finitely generated `Z`-algebra with fraction field of characteristic
  0. So the image of `Spec A' -> Spec Z` is constructible and contains the
  generic point. It therefore contains all but finitely many primes, and for
  such `q` some maximal ideal `m` of `A'` contains `q`.
- Let `w` be a discrete valuation of `F` whose valuation ring dominates the
  noetherian local domain `A'_m` (Krull–Akizuki). Then:
  - `w >= 0` on `A'`, and `w(q) = e > 0`;
  - `w(a_j) >= 0` for all `j`, and `w(a_r) = 0`.
- In `e_q` the term `j = r` has valuation `-re`, and every other term has
  valuation `>= -je > -re`. So `w(e_q) = -re < 0`. But `e_q ∈ A ⊆ A'`, so
  `w(e_q) >= 0`.
- This holds for all but finitely many `q` in the infinite set `P`, a
  contradiction.

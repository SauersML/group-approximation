Notation as in the target.  Throughout, "action on `(N, tau)`" means an
action by `tau`-preserving `*`-automorphisms, and `||x||_2 = tau(x^* x)^(1/2)`.

## 0. Elementary facts about the pair

**(F1) `A cap K = C`.**  The entries of a matrix in `A cap K` lie in
`Z[1/2] cap Z_2 = Z`.

**(F2) `A` is dense in `L`.**  For `i != j` the elementary group
`e_ij(Z[1/2])` is dense in `e_ij(Q_2)`, because `Z[1/2]` is dense in `Q_2`.
`SL_3` over a field is generated by elementary matrices, so the closed
subgroup `closure(A)` contains all of them and equals `L`.  Hence
`A cap O` is nonempty for every nonempty open `O subset L`.

**(F3) `V = A/C = L/K`.**  The map `aC -> aK` is injective by (F1) and
surjective by (F2), since `gK` is open.  It is `A`-equivariant.

**(F4) `C`-orbits on `V` are `K`-orbits and are finite.**  Let `v = gK`.
`Stab_K(v) = K cap gKg^(-1)` is open in the compact group `K`, so
`|K v| = [K : K cap gKg^(-1)] < infinity`.  For `k in K` the open set
`k Stab_K(v)` meets `C` by (F2) applied inside `K` (`C` is dense in `K`,
again because `e_ij(Z)` is dense in `e_ij(Z_2)` and `SL_3(Z_2)` is generated by
elementary matrices over the local ring `Z_2`), and `c = k k'` with
`k' in Stab_K(v)` gives `cv = kv`.  So `Cv = Kv`.  As `V` is infinite, there
are infinitely many orbits.  Thus
`C \ A / C = C \ V = K \ V = K \ L / K`, the set of relative positions
`lambda`, and `S_lambda(bC) = b C lambda C / C` has `D_lambda` elements.

**(F5) The Hecke graph of `h` is connected.**  `h^(-1) = diag(1/2, 1, 2)` is
obtained from `h` by conjugating with a permutation matrix in `C`, so
`C h^(-1) C = C h C`.  Every `a in A = <C, h>` is a word
`c_0 h^(e_1) c_1 ... h^(e_m) c_m`, so consecutive prefixes give a path
`o, ..., aC` in the graph on `V` whose edges are the pairs in relative
position `ChC`.

## 1. VP1: smooth normal form

Let `alpha` act on `(N, tau)`.  For a compact open subgroup `W < L` put
`N_W = N^(A cap W)`, a von Neumann subalgebra.

*Directedness.*  `W cap W'` is compact open and `N_W, N_(W') <= N_(W cap W')`.
Hence `N_inf = union_W N_W` is a unital `*`-subalgebra.

*Invariance.*  `alpha_a(N_W) = N^(a (A cap W) a^(-1)) = N_(aWa^(-1))`, so
`N_inf` is `A`-invariant.

*Definition of `alphabar`.*  For `g in L` and `x in N_W` choose
`a in A cap gW`, which is nonempty by (F2), and put `alphabar_g x = alpha_a x`.
If `a, a' in gW` then `a^(-1) a' in A cap W`, so `alpha_(a') x = alpha_a x`.
If also `x in N_(W')`, choose `a in A cap g(W cap W')`, which serves for both.
So `alphabar_g` is well defined on `N_inf`.  It is a `tau`-preserving
`*`-homomorphism on each `N_W`, hence on `N_inf`, and it maps `N_W` into
`N_(gWg^(-1))` because `a = gw` gives `aWa^(-1) = gWg^(-1)`.

*Homomorphism.*  Let `x in N_W`, `a' in A cap g'W`, and
`a in A cap g (g' W g'^(-1))`.  Then `alphabar_(g') x = alpha_(a') x` lies in
`N_(g'Wg'^(-1))`, and `alphabar_g alphabar_(g') x = alpha_(a a') x`.  Writing
`a = g g' w g'^(-1)` and `a' = g' w'` gives `a a' = g g' w w' in gg'W`.  So
`alphabar_g alphabar_(g') = alphabar_(gg')`.  For `a in A` one may take
`a in A cap aW`, so `alphabar` restricts to `alpha` on `N_inf`.  In
particular `alphabar_g` is bijective on `N_inf`, with inverse
`alphabar_(g^(-1))`.

*Continuity and extension.*  For `x in N_W` the map `g -> alphabar_g x` is
constant on left cosets `gW`, so it is locally constant.  Let `H` be the
`||.||_2`-closure of `N_inf` in `L^2(N)`.  `alphabar_g` extends to a unitary
`T_g` on `H`, and `g -> T_g` is a homomorphism.  It is strongly continuous
on the dense set `N_inf`, hence on `H`, because the `T_g` are uniformly
bounded.  Put `N_sm = N_inf''`, the weak closure in `N`.  By Kaplansky
density `H = L^2(N_sm)`, and `T_g N_inf T_g^* = N_inf` in `B(H)`, so `Ad T_g`
preserves `N_sm`.  It extends `alphabar_g`, preserves the vector state at
`1^` (since `T_g 1^ = 1^`), which is `tau`, and satisfies
`||Ad T_g(x) - x||_2 = ||T_g x^ - x^|| -> 0` as `g -> e`.  Two normal
automorphisms that agree on the weakly dense `N_inf` agree on `N_sm`, so the
extended `alphabar` restricts to `alpha` on `A`.

*Fixed algebras.*
- `N^C = N_K <= N_inf <= N_sm`, by (F1).
- If `x in N^C` and `k in K`, take `a in A cap kK = C`; then
  `alphabar_k x = alpha_a x = x`.
- If `x in N_sm` is `K`-fixed, then `alpha_c x = alphabar_c x = x` for all
  `c in C`.

So `N^C = (N_sm)^K`.  `L`-fixed elements are `A`-fixed.  Conversely, `A`-fixed
elements lie in `N^C <= N_inf`, and there `alphabar_g x = alpha_a x = x`.  So
`N^A = (N_sm)^L`.

*Certificates.*  Given `(M, u, U)`, set `alpha = Ad u` on
`N = W*(u_a U u_a^* : a in A)`, which is `u(A)`-invariant.
- `U in N^C = N_K`.
- `alpha_a U in N_(aKa^(-1)) <= N_inf`.
- So `N <= N_inf'' = N_sm <= N`.

For `v = gK` put `U_v = alphabar_g U`, which is well defined since `U` is
`K`-fixed.
- `alphabar_(g') U_v = U_(g'v)`, so the joint `*`-distribution of
  `(U_v)_(v in V)` under `tau` is `L`-invariant.
- `U_(ho) = alpha_h U = u_h U u_h^*`, so
  `tau(U u_h U^* u_h^*) = tau(U_o U_(ho)^*)`.
- `M` contains `W*(N, u(A))`, in which `u` implements `alpha`.

This is VP1.

## 2. VP2: commutative coding

Let `A` act on `(Y, mu)` preserving `mu`, with
`(alpha_a f)(y) = f(a^(-1) y)`.  The crossed product trace is
`tau(f u_a) = delta_(a,e) integral f d mu`, and
`tau(U u_h U^* u_h^*) = tau(U alpha_h(U^*))`.

*Existence of a moved invariant set.*  Suppose every `C`-invariant
measurable set is `h`-invariant mod null sets.
- Then every `C`-invariant function is `h`-invariant.
- So `L^infinity(Y)^C` is fixed by `<C, h> = A`.
- Every `C`-invariant unitary `U` then has `U alpha_h(U^*) = 1`.

So a certificate with `U in L^infinity(Y)` forces a `C`-invariant `P` with
`mu(P Delta hP) > 0`.  The converse is the unitary computation below, pulled
back along `Phi`.

*Coding.*  Put `Phi(y)(aC) = 1_P(a^(-1) y)`.
- This is well defined: `(ac)^(-1) y = c^(-1) a^(-1) y`, and `P` is
  `C`-invariant.
- It is measurable, since each coordinate is.
- It is equivariant for `(b omega)(v) = omega(b^(-1) v)`:
  `Phi(by)(aC) = 1_P(a^(-1) b y) = Phi(y)(b^(-1) aC)`.

Put `nu = Phi_* mu`, which is `A`-invariant.  `L` acts on `V` with open
pointwise stabilizers `Fix(F)` of finite sets `F`, hence on `2^V` by
homeomorphisms.  Let `Z` be a cylinder depending on the coordinates in a
finite set `F`, and let `g in L`.
- By (F2) there is `a in A cap g Fix(F)`.
- Write `a = g f` with `f in Fix(F)`; then `fZ = Z`, so `aZ = gZ`.
- Hence `nu(gZ) = nu(aZ) = nu(Z)`.

Cylinders form a pi-system generating the Borel sets, so `nu` is
`L`-invariant.  Further, `Phi^(-1)(E) = P` and
`Phi^(-1)(hE) = {y : 1_P(h^(-1) y) = 1} = hP`, so
`nu(E Delta hE) = mu(P Delta hP)`.

*Embedding.*  `f -> f o Phi` is an `A`-equivariant, trace-preserving, unital
injective normal `*`-homomorphism `L^infinity(2^V, nu) -> L^infinity(Y, mu)`.
The map `sum f_a u_a -> sum (f_a o Phi) u_a` is a `*`-homomorphism of the
algebraic crossed products that preserves the crossed product traces.  It
therefore extends to a trace-preserving embedding of the von Neumann crossed
products.

*The unitary.*  `E` is `C`-invariant because `C` fixes `o`, so
`U = 1_(E^c) + i 1_E` is `C`-fixed.  Then

```text
U alpha_h(U^*) = (1_(E^c) + i 1_E)(1_((hE)^c) - i 1_(hE))
               = 1_(E^c cap (hE)^c) + 1_(E cap hE) + i 1_(E \ hE) - i 1_(hE \ E).
```

Since `nu(E) = nu(hE)`, `nu(E \ hE) = nu(hE \ E)`, and
`tau(U alpha_h(U^*)) = 1 - nu(E Delta hE)`, a real number in `[0, 1]`.  So
`|tau| < 1` iff `nu(E Delta hE) > 0`.

*Triviality.*  If `nu(E Delta hE) = 0`, then `omega(o) = omega(ho)` for
`nu`-a.e. `omega`.
- By `A`-invariance, `omega(bo) = omega(bho)` a.s. for each `b in A`.
- `A` is countable, so a.s. `omega` is constant along every edge `{bC, bhC}`,
  `b in A`.
- The neighbours of `bC` in relative position `ChC` are the `bchC`,
  `c in C`, so these edges are all edges of the Hecke graph of (F5), and that
  graph is connected.
- So a.s. `omega` is constant, i.e. `nu` is supported on
  `{empty set, V}`.
- The converse is clear.

*Refutation.*  If `L^infinity(Y) rtimes A` is Connes embeddable, so is its
subalgebra `L^infinity(2^V, nu) rtimes A`, and item 4 of
`homogeneous-quotient-ce-refutes-arithmetic-commutant-collapse` applies to
the certificate `(L^infinity(2^V, nu) rtimes A, u, U)`.  That item's lifting
uses only the embedding, `u` and a unitary in `u(C)'` not commuting with
`u_h` up to a unimodular trace.  This gives (VP2).

*The two firewalls.*  For `(SH1)`, take `Y = L/Lambda'` and `P` a `K`-orbit.
The coded subset of `V` is `{aC : a^(-1) y in P}`, the vertices whose image
in the finite quotient `K \ L / Lambda'` is the chosen class.  For the coset
Bernoulli shift, the coordinates at distinct vertices are independent, so the
coded set (a `C`-invariant set depending only on the coordinate at `o`) has
i.i.d. membership, and `nu` is a product measure.

## 3. VP3: the real place

Let `pi` be a strongly continuous unitary representation of `G_R = SL_3(R)`
on `H`, and `xi in H^(pi(C))`.  Split `H = H^(G_R) (+) H_1`.  `H_1` is
`G_R`-invariant and contains no nonzero `G_R`-invariant vector, and the
projection `xi_1` of `xi` onto `H_1` is `C`-invariant.
- `C = SL_3(Z)` is an infinite discrete subgroup of `SL_3(R)`, so there are
  `c_n in C` with `c_n -> infinity`.
- By `howe-moore-property-for-simple-lie-and-p-adic-groups`: "every unitary
  representation of `G` either has a nonzero `G`-invariant vector or has all
  matrix coefficients `C_0`", item 1, "connected, noncompact, simple real Lie
  groups with finite center, for instance `SL_n(R)`".  Apply it to the
  representation of `G_R` on `H_1`, which has no nonzero invariant vector, so
  `<pi(g) xi_1, xi_1> -> 0` as `g -> infinity` in `G_R`.
- So `||xi_1||^2 = <pi(c_n) xi_1, xi_1> -> 0`, and `xi_1 = 0`.

Hence `H^C = H^(G_R)`.  Apply this to `H = L^2(N)`, with the unitaries
implementing the point-`||.||_2`-continuous action.  Then
`N^C <= N^(G_R) <= N^A`, so `N^C = N^A`.  Every `U in N^C` commutes with
`u_h` in any tracial covariant extension, and `tau(U u_h U^* u_h^*) = 1`.

*Product case.*  Let `G = G_R x L`, with `A` embedded diagonally and `pi`
continuous.
- `G_R` is normal in `G`, so `H_0 = H^(G_R)` is `G`-invariant, and so is
  `H_1 = H_0^perp`.
- `xi in H^C` has `C`-invariant component `xi_1 in H_1`.
- Choose `c_n -> infinity` in `C < G_R`.  The diagonal images are
  `(c_n, c_n)` with second coordinate in the compact group `K`; pass to a
  subsequence with `c_n -> k` in `K`.
- Put `eta = pi(1, k) xi_1 in H_1`.  Then
  `||xi_1||^2 = <pi(c_n, 1) pi(1, c_n) xi_1, xi_1>`, and
  `|<pi(c_n,1) pi(1,c_n) xi_1, xi_1> - <pi(c_n,1) eta, xi_1>| <= ||pi(1,c_n) xi_1 - eta|| ||xi_1|| -> 0`
  by continuity of `pi` restricted to `L`.
- `H_1` has no `G_R`-invariant vector, so Howe--Moore for `G_R` gives
  `<pi(c_n,1) eta, xi_1> -> 0`.
- So `xi_1 = 0` and `H^C <= H^(G_R)`.

Hence `N^C <= N^(G_R)`, a `G`-invariant von Neumann subalgebra on which `G`
acts through `G/G_R = L`, and every certificate unitary lies in this
`L`-system.  That is the setting of VP1.

*Sources.*
- For a measurable p.m.p. action of a locally compact second countable group,
  the Koopman representation is strongly continuous (standard), so the result
  applies to `L^infinity` of such actions.
- The Gaussian action of a continuous orthogonal representation of `G_R` is a
  measurable p.m.p. `G_R`-action whose restriction to `A` is the Gaussian
  action of the restricted representation.
- Real homogeneous spaces `G_R/Gamma` and `G/Gamma` with `Gamma` a lattice
  carry continuous p.m.p. actions.

This is VP3.

## 4. VP4: C-fixed dimension

If `theta: N_1 -> N_2` is an injective `A`-equivariant `*`-homomorphism,
then `theta(N_1^C) <= N_2^C` injectively, so `d_C(N_1) <= d_C(N_2)`.  For
`(SH1)`, `d_C = r` by item 2 of
`homogeneous-quotient-ce-refutes-arithmetic-commutant-collapse`: "`L^infinity(X)^C = L^infinity(X)^K` is the `r`-dimensional algebra of functions constant on `K`-orbits."

For the coset Bernoulli shift `N = (B, tau_B)^(tensor V)`, with `A`
permuting tensor factors by `alpha_a(x_v) = x_(av)`, take `x in B` with
`tau_B(x) = 0` and `x != 0`, which exists since `B != C`.  For each
`C`-orbit `O` on `V`, finite by (F4), put `s_O = sum_(v in O) x_v`.
- `alpha_c` permutes `O`, so `s_O in N^C`.
- For `O != O'`, `tau(s_O^* s_(O')) = sum tau_B(x^*) tau_B(x) = 0` by
  independence of distinct factors.
- `||s_O||_2^2 = |O| ||x||_2^2 > 0`.

There are infinitely many orbits by (F4), so `d_C(N) = infinity`.  Hence
there is no `A`-equivariant embedding of `N` into `L^infinity(L/Lambda')` or into any
finite-`d_C` system.  This is VP4.

## 5. VP5: finite C-fixed dimension

Let `N = L^infinity(Y, mu)` with `N^C` of dimension `s`, and let
`P_1, ..., P_s` be its atoms.  For `x in N^C` and a relative position
`lambda` (F4), put

```text
T_lambda x = (1/D_lambda) sum_(aC in C lambda C / C) alpha_a(x).
```

- This is well defined, since `x` is `C`-invariant.
- `T_lambda x` is `C`-invariant, since left multiplication by `C` permutes
  `C lambda C / C`.

So `T_lambda 1_(P_j) = sum_i t^lambda_(ij) 1_(P_i)`.  Evaluating at
`y in P_i` gives
`t^lambda_(ij) = D_lambda^(-1) #{aC in C lambda C/C : a^(-1) y in P_j}`, and
`sum_j t^lambda_(ij) = 1` because the `P_j` partition `Y`.

With `omega_y(aC) = j iff a^(-1) y in P_j`, this reads: for `y` in a conull
set `Y_0`,
`#{w in S_lambda(o) : omega_y(w) = j} = D_lambda t^lambda_(omega_y(o), j)`
for all `lambda` and `j`.  Note that `C \ A / C` is countable.

For `v = bC`:
- `S_lambda(v) = b S_lambda(o)`.
- `omega_y(b w) = omega_(b^(-1) y)(w)`.

So the identity at `v` for `y` is the identity at `o` for `b^(-1) y`.  It
holds for all `v` when `y in intersection_(b in A) b Y_0`, which is conull.
This is (VP5).

The coding map `Y -> {1..s}^V` is equivariant, and the argument of Section 2
shows its law is `L`-invariant and its coordinate crossed product embeds.

*Leak criterion.*  Suppose `alpha_h 1_(P_j) = 1_(P_j)` for all `j`.  Then
`N^C` is fixed by `C` and `h`, hence by `A`, so `N^C = N^A`.  Contrapositive:
if `d_C > d_A`, some atom has `mu(P_j Delta hP_j) > 0`, and Section 2 gives a
certificate.  Conversely, a certificate `U in N^C` with
`|tau(U alpha_h U^*)| < 1` is not `A`-fixed, so `d_C > d_A`.  For ergodic
`mu`, `d_A = 1`.  This is VP5.

Notation as in the target. Inputs:
- **[MCG2]** `genus-two-mapping-class-group-homology-and-symplectic-quotient`:
  - `M` is finitely presented;
  - `H_1(M; Z) = Z/10` and `H_2(M; Z) = Z/2`;
  - `pi` is surjective with kernel the Torelli group `K`.
- **[DFR1]** `deligne-triple-cover-finite-residual-is-center`, used only through `z in Res_fin(E_3)`.
- **[DTC2]** `deligne-triple-cover-fd-central-invisibility`: every finite-dimensional unitary
  representation of `E_3` kills `z`.
- **[DSG]** `deligne-sector-gap-is-exactly-nonhyperlinearity`:
  - (1) `E_3` is non-hyperlinear
  - ⇔ (2) the `alpha`-projective presentation defect has a uniform positive lower bound
  - ⇔ (3) the same holds in both nontrivial sectors
  - ⇔ (4) every vanishing-defect almost representation of a finite presentation of `E_3` sends `z`
    asymptotically to `I`.

Also `Gamma = Sp_4(Z)` is finitely presented. [DSG] is formulated for a finite presentation of `E_3`,
and adding the relator `z` presents `Gamma = E_3/<z>`. This is the standing presupposition of the
presentation-based nodes of this cluster, and it is not re-pinned here.

## Step 1: H^2(M; Z/3) = 0

By the universal coefficient theorem,
`H^2(M; Z/3) ~= Hom(H_2(M; Z), Z/3) (+) Ext(H_1(M; Z), Z/3)`. With [MCG2]:
- `Hom(Z/2, Z/3) = 0`;
- `Ext(Z/10, Z/3) ~= Z/gcd(10, 3) = 0`.

So `H^2(M; Z/3) = 0`.

## Step 2: splitting and the quotient description (TS1)

**The pullback.** Put `P = { (m, e) in M x E_3 : pi(m) = p(e) }`, where `p : E_3 -> Gamma`.
- `P` is a subgroup.
- `{1} x <z>` is central in `P`, because `z` is central in `E_3`.
- `P -> M`, `(m, e) -> m`, is surjective with kernel `{1} x <z>`, because `p` is surjective.

So `P` is a central extension of `M` by `Z/3` with trivial action. Central extensions of `M` by `Z/3`
are classified by `H^2(M; Z/3)`, which is `0`. So there is a homomorphism `s : M -> P` with
`pr_M s = id`. Write `s(m) = (m, sigma(m))`. Then `sigma : M -> E_3` is a homomorphism and
`p sigma = pi`.

**The map.** Define `Phi : M x Z/3 -> E_3` by `Phi(m, j) = sigma(m) z^j`.
- **Homomorphism:** `z` is central.
- **Surjective:** given `e`, pick `m` with `pi(m) = p(e)` (`pi` is surjective). Then
  `p(sigma(m)^(-1) e) = 1`, so `e in sigma(m) <z>`.
- **Kernel:** if `Phi(m, j) = 1`, then `pi(m) = p(sigma(m)) = 1`, so `m in K`. For `k in K`,
  `p(sigma(k)) = 1`, so `sigma(k) = z^(c(k))` for a unique `c(k) in Z/3`. Then `Phi(k, j) = 1` iff
  `j = -c(k)`. So `ker Phi = L_c`.
- **The character c:** it is a homomorphism because `sigma` is. It is conjugation invariant because
  `sigma(m k m^(-1)) = sigma(m) z^(c(k)) sigma(m)^(-1) = z^(c(k))`.
- **The mark:** `Phi(1, 1) = z`.

## Step 3: (TS2)

Let `N` be a finite-index normal subgroup of `M`. Suppose `c(K cap N) != Z/3`. Since `3` is prime,
`c(K cap N) = 0`.

**The finite quotient.**
- `c` descends to `cbar : KN/N -> Z/3`, `cbar(kN) = c(k)`. It is well defined: `kN = k'N` with
  `k, k' in K` gives `k^(-1) k' in K cap N`.
- Let `Q = M/N x Z/3`, a finite group. Let `Lbar` be the image of `L_c` in `Q`, which is
  `{ (kN, -cbar(kN)) : k in K }`. It is normal because `L_c = ker Phi` is normal.
- The map `M x Z/3 -> Q -> Q/Lbar` kills `L_c`, so it induces a surjection `E_3 -> Q/Lbar` onto a finite
  group.

**Where z goes.** `z` maps to the class of `(N, 1)`. If `(N, 1) in Lbar`, then some `k in K` has
`kN = N` and `-c(k) = 1`, i.e. `k in K cap N` with `c(k) = -1 != 0`. That is excluded. So `z`
survives in a finite quotient of `E_3`, contradicting [DFR1]. Hence `c(K cap N) = Z/3`. Taking `N = M`
gives `c(K) = Z/3`, so `c != 0`.

## Step 4: (TS3)

**Finite normal generating lists exist.** Let `S` be a finite generating set of `M`, so `pi(S)`
generates `Gamma`. `Gamma` is finitely presented, so by Tietze's theorem it has a finite presentation
`<pi(S) | R_Gamma>` on these generators. Let `W` be the images in `M` of the words `R_Gamma` in `S`.
- `W` lies in `K`.
- `K` is the image in `M` of `ker(F(S) -> Gamma) = <<R_Gamma>>_F`, which is the normal closure of `W`
  in `M`.

**The kernel is normally generated by the corrected generators.** Let `k_1, ..., k_m` normally generate
`K` in `M`, and let `L'` be the normal closure in `M x Z/3` of the elements `(k_i, -c(k_i))`.
- `L'` is contained in `L_c`.
- Conversely, write `k in K` as `prod_j g_j k_(i_j)^(e_j) g_j^(-1)`. Since `(g, 0)` conjugates
  `(k_i, -c(k_i))` to `(g k_i g^(-1), -c(k_i))`, and `c` is an invariant homomorphism, the matching
  product in `L'` equals `(k, -sum_j e_j c(k_(i_j))) = (k, -c(k))`.

So `L' = L_c`. Since `M x Z/3 = < M, z | z^3, [z, M] >`, (TS1) gives the displayed presentation.

## Step 5: (TS4)

Let `rho : M -> U(d)` satisfy `rho(k) = omega^(c(k)) I` for all `k in K`. If this holds only on the
`k_i`, it holds on all of `K`: use normal generation, and note that scalars are central and `c` is an
invariant homomorphism.

Define `rhotilde(m, j) = omega^j rho(m)`. It is a homomorphism `M x Z/3 -> U(d)`, and
`rhotilde(k, -c(k)) = omega^(c(k) - c(k)) I = I`. So it factors through `E_3` with `z -> omega I != I`.
That contradicts [DTC2]. The same argument works with `omega^2`.

## Step 6: (TS5)

**Transfer lemma.** Let `<X | Rel>` and `<X' | Rel'>` be finite presentations of the same group `G`.
Choose words `w_(x')` in `X` for the generators `x'`. Every relator of `X'`, rewritten through these
words, equals in `F(X)` a fixed finite product of conjugates of relators in `Rel`.

For unitary tuples `U` on `X`, put `U'(x') = w_(x')(U)`. The normalized HS norm is unitarily invariant
and satisfies the triangle inequality. So the defect of `U'` on each relator of `Rel'` is at most a
fixed constant times the maximal defect of `U` on `Rel`. Hence vanishing-defect sequences transfer
between finite presentations. Generators common to both presentations can keep their values.

**(⇐) A countermodel makes E_3 hyperlinear.** Take `rho_n` as in (TS5) for `zeta`, on the presentation
of (TS3). Put `phi_n(s) = rho_n(s)` and `phi_n(z) = zeta I`.
- The relators `z^3` and `[z, s]` hold exactly.
- `||phi_n(k_i z^(-c(k_i))) - I||_2 = ||rho_n(k_i) - zeta^(c(k_i)) I||_2 -> 0`.
- The relators `R` have defect `-> 0`.

So `phi_n` is a vanishing-defect sequence with `||phi_n(z) - I||_2 = |zeta - 1| = 3^(1/2)`. Collapse
fails for this finite presentation, hence (transfer lemma) for every finite presentation. By [DSG]
(4 ⇔ 1), `E_3` is hyperlinear.

**(⇒) If E_3 is hyperlinear, a countermodel exists.** By [DSG] (1 ⇔ 2), the `alpha`-projective defect
has no positive uniform lower bound. So there are tuples `U_n` on the generators of a finite
presentation of `Gamma` whose `alpha`-projective relator defects tend to `0`.

In the lifted presentation of `E_3`, with generators the lifts `shat` and `z`, and relators `z^3`,
`[z, shat]` and `r(shat) z^(-a_r)`, set `phi_n(shat) = U_n(s)` and `phi_n(z) = zeta I` for the
primitive cube root `zeta` of that sector. This is a vanishing-defect sequence with `phi_n(z) = zeta I`.
- By the transfer lemma, keeping `z -> zeta I`, get `psi_n` on the presentation of (TS3) with all defects
  `-> 0`.
- Put `rho_n = psi_n` restricted to `S`. The relators `R` have defect `-> 0`, and
  `||rho_n(k_i) - zeta^(c(k_i)) I||_2 = ||psi_n(k_i z^(-c(k_i))) - I||_2 -> 0`.

**Independence of choices.** By the transfer lemma, the countermodel condition does not depend on the
finite presentation of `M` or on the normal generating list. Changing the list rewrites each new
`k'_j` as a fixed product of conjugates of the old `k_i^(+-1)`, and the phases match because `c` is an
invariant homomorphism.

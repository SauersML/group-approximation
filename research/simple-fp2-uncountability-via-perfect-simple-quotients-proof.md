**(1 ⇒ 2).** Let `𝒮` be an uncountable set of pairwise non-isomorphic simple
groups of type FP_2. By `fp2-iff-quotient-of-fp-group-by-perfect-normal-subgroup`,
each `Σ ∈ 𝒮` is `H_Σ/N_Σ` with `H_Σ` finitely presented and `N_Σ` perfect.
There are only countably many finitely presented groups up to isomorphism. So
for some finitely presented `H`, uncountably many `Σ ∈ 𝒮` have `H_Σ ≅ H`.
Transport each `N_Σ` along a chosen isomorphism `H_Σ ≅ H`. The resulting
normal subgroups of `H` are perfect with simple quotients, and they are
pairwise distinct, since equal kernels give isomorphic quotients.

**(2 ⇒ 1).** Let `𝒩` be an uncountable set of perfect normal subgroups of `H`
with simple quotients. Each `H/N` is of type FP_2 by the same claim (⇐), and
simple by hypothesis. `H` is generated by a finite set `X`, so a surjection
`H -> Σ` onto a countable group is determined by the images of `X`, and there
are at most countably many of them. Hence for each isomorphism type `Σ`, at
most countably many `N ∈ 𝒩` satisfy `H/N ≅ Σ`. An uncountable set covered by
countable fibres has uncountably many fibres, so the quotients `H/N`, `N ∈ 𝒩`,
realize uncountably many isomorphism types.

**Remark.** The finite simple quotients of `H` are countably many in number
(finitely many kernels per finite group), so all but countably many members of
`𝒩` have infinite quotients.

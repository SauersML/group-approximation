**ESTABLISHED.** Setting and notation as in
`realized-relative-twists-embed-in-outer-twist-group`: a rigid pair
`Gamma <= G`, `M <= Gamma` normal in `G`, a homomorphism `sigma : G -> S_U`,
`Q_s = N_rel(sigma)/(M_s C_s)`, compressor endomorphisms `eps_t`.

For `q in Q_s` let `R(q) = x M_s C_s` be its set of realizers. Let `F` assign a
number to subsets of `S_U`, invariant under conjugation of the whole subset:
`F(y A y^-1) = F(A)`. Put `size(q) = F(R(q))`. Examples:

- the supremum, infimum or ultralimit average over realizers of any
  conjugation invariant of one permutation: fixed-point proportion, support
  proportion, cycle statistics, the spectral measure of `x`;
- any invariant of the tracial von Neumann algebras generated by realizers.

Then:

1. **Exact invariance.** `size(eps_t(q)) = size(q)` for every `q in Q_s` and
   every compressor `t`. So no such size is strictly monotone along a strict
   compressor self-embedding.
2. **Support proportions are blank on host elements.** If `sigma` is an
   injective trace-zero sofic representation of a host `H` and
   `z in H \ {1}`, then `sigma(z)` has fixed-point proportion `0`. Every
   nontrivial realized class coming from `H` has a realizer with support
   proportion `1`. The halving of Cantor-set supports by corner copies of
   Thompson's `V` inside `C_(R^x)(EL_alpha(R))` is invisible in the model.
3. **What a size must read.** The only data that conjugation by `sigma(t)` does
   not transport is the position of `Gamma_s`:
   `sigma(t)^-1 Gamma_s sigma(t) = sigma(t^-1 Gamma t)`, which contains
   `Gamma_s`. A size argument for `relative-normalization-modulo-kazhdan-kernel`
   has to be a relative invariant of the pair (realizer set, `Gamma_s`), for
   instance cluster data of `Gamma_s`-components. By item 3 of
   `realized-relative-twists-embed-in-outer-twist-group`, that means an
   invariant of the `S_U`-conjugacy class of `sigma|_Gamma`.

Derivation: `conjugation-invariant-sizes-miss-defect-proof`.

**Why this proves nothing about Thompson's V.** Items 1 and 2 use no property
(T) and hold in every host, amenable ones included. There strict
self-conjugations of subgroups are common, as in `BS(1,2)`, where `t` conjugates
`<a>` onto `<a^2>`. So they correctly give no nonsoficity. The property (T)
input must enter through item 3.

Lane proof, elementary. Notation as in the claim.

## 1. Deep points
For `C >= 0` and `V > C`, a **`(C,V)`-deep point** is an `x ∈ Q^x` with exactly one index
`j` such that `v_j(x) < −V`, and `v_k(x) >= −C` for all `k ≠ j`. Put `π(x) = (j, v_j(x))`.
Every pair `(j, v)` with `v < −V` is `π(p_j^v)` for the deep point `p_j^v`.

## 2. The generators
Let `x` be `(C,V)`-deep with `π(x) = (j, v)`.
- **`τ^(±1)`.** Every prime `p` with `v_p(x) < 0` has `v_p(x ± 1) = v_p(x)`, and every
  prime with `v_p(x) >= 0` has `v_p(x ± 1) >= 0`. So `x ± 1` has exactly the same negative
  valuations: it is `(C,V)`-deep with `π = (j, v)`. The value `0` never occurs, since
  `x ± 1 = 0` forces `x = ∓1`, which is not deep.
- **`ι`.** `v_k(−x) = v_k(x)`, so `π` is unchanged.
- **`δ^(±1)`.** Only `v_0` moves, by `±1`. So `δ^(±1) x` is `(C+1, V−1)`-deep (referee a) with
  `π = (j, v ± [j = 0])`.
- **`σ^(±1)`.** `σ` is multiplicative with `v_(k+1)(σ x) = v_k(x)`, so `σ^(±1) x` is
  `(C,V)`-deep with `π = (j ± 1, v)`.

So each generator `γ` has a germ map `φ_γ` on pairs:
- `φ_τ = φ_ι = id`;
- `φ_δ(j, v) = (j, v + [j = 0])`;
- `φ_σ(j, v) = (j + 1, v)`.

It satisfies `π(γ x) = φ_γ(π(x))` on deep points, and deep points with a margin stay deep.

## 3. The germ of an arbitrary element
Let `g ∈ A_1` be a word of length `ℓ` in the generators. If `x` is `(C, C + 3ℓ + 1)`-deep,
then along the word the shallow valuations stay `>= −C − ℓ` and the deep one stays
`< −C − 2ℓ`. So every intermediate point is deep, and `π(g x) = φ_g(π(x))` with
`φ_g = φ_(γ_1) ∘ … ∘ φ_(γ_ℓ)`.
- **Well defined.** The left side depends only on the permutation `g`. For every pair
  `(j, v)` with `v` deep enough there is a deep point `x` with `π(x) = (j, v)`. So two
  words for the same `g` define the same germ `[φ_g]`, the class of maps
  `Z × Z_(< −V) -> Z × Z` modulo agreement for `v ≪ 0`.
- **Homomorphism.** `g ↦ [φ_g]` is a homomorphism into the group of such germs.

The group generated by `[φ_δ]` and `[φ_σ]` is the group of germs
`(j, v) ↦ (j + k, v + e_j)` with `e ∈ ⊕_Z Z` and `k ∈ Z`. That is `Z ≀ Z`:
- `[φ_δ]` is the basis vector at `0`;
- `[φ_σ]` is the shift;
- `σ^k δ σ^(−k) = m_(p_k)` (`gl-n-q-lies-in-prime-shift-permutation-group`, item 2) gives
  the basis vector at `k`.

Distinct `(e, k)` give distinct germs, so this is `Φ`. Then `Φ(m_r) = (v_k(r))_k` by
multiplicativity, which is item 1.

## 4. Items 2 and 3
- **Item 2.** `Φ(τ) = 1`, so `<<τ>>_(A_1) ⊆ ker Φ`. For `r > 0`, `r ≠ 1`, some
  `v_k(r) ≠ 0`, so `Φ(m_r) ≠ 1` and `m_r ∉ <<τ>>`.
- **The quotient map.** By item 1 of `prime-shift-hnn-groups-are-not-finitely-presented`,
  `Π_1 / <<τ>> ≅ Q^x ⋊_σ <s> ≅ Z/2 × (Z ≀ Z)`. It maps onto `A_1 / <<τ>>`, and the
  composite with `Φ` sends `(±r, s^k)` to `((v_j(r))_j, k)`. That is the projection
  `Z/2 × (Z ≀ Z) -> Z ≀ Z`, whose kernel is `<ι>`. So `A_1/<<τ>> -> Z ≀ Z` has kernel `F`
  of order at most `2`.
- **Item 3.** If `A_1` were finitely presented, then so would be `A_1/<<τ>>`, and then so
  would be `(A_1/<<τ>>)/F ≅ Z ≀ Z`, because `F` is finite and hence finitely normally
  generated. But `Z ≀ Z` is not finitely presented (Baumslag, Math. Z. 75 (1961), as cited
  in `prime-shift-hnn-groups-are-not-finitely-presented-proof`). ∎

## 5. The kernel of Π_1 -> A_1
`Φ` composed with `Π_1 -> A_1` agrees with `Π_1 -> Π_1/<<τ>> -> Z ≀ Z` on the generators.
Its kernel is `<<τ>>_(Π_1)` times the preimage of `ι`. Every element of `ker(Π_1 -> A_1)`
lies in this kernel.

## Setting

- `K` is any field, and `R = L_K(1,2)` is generated by `s_0, s_1, t_0, t_1` with `t_i s_j = δ_ij` and
  `s_0 t_0 + s_1 t_1 = 1`.
- For a word `w = w_1...w_k`, put `s_w = s_(w_1)...s_(w_k)`, `t_w = t_(w_k)...t_(w_1)` and `p_w = s_w t_w`.
- `S = span{s_w}` and `T = span{t_w : |w| >= 1}`. They are the free algebras on the `s_i` and on the `t_i`
  (the second without its unit).
- An element `x` has **depth `<= (N', N)`** if `x = Σ λ s_α t_β` with every `|α| <= N'` and every `|β| <= N`.

## Statement

1. **Units in `S + T` are scalars.** `R^× ∩ (S + T) = K^×`.
2. **Deep compressions.** Let `x` have depth `<= (N', N)`, and let `v, v'` be words with `|v| >= N`.
   - Then `t_(v') x s_v ∈ S + T`.
   - If also `|v| >= N'`, then `t_v x s_v ∈ W_N = span{s_w, t_w : |w| <= N}`.
3. **Prefix rigidity.** Let `u ∈ R^×` have depth `<= (N', N)`, and let `u p_v u^(-1) = p_(v')` with `|v| >= N`.
   - Then `u s_v = λ s_(v')` for some `λ ∈ K^×`.
   - So on the tail module, `u` sends `vz` to `λ·v'z`.
   - In particular, if `u` commutes with `p_v` and `|v| >= N`, then `u p_v = λ p_v`. Over `F_2`, `u` is the
     identity on the cylinder `[v]`.
4. **Block collapse over `F_2`.** Let `a, c ∈ R^×` commute and have depth `<= (N, N)`.
   - Let `Q` be any family of idempotents `q = s_v e t_v` commuting with `a` and `c`. Here each `|v| >= N`, and
     `e` is an idempotent of depth `<= (M, M)` for one fixed `M`.
   - Put `I_q = ker(F_2[x^(±1), y^(±1)] -> qRq)`, with `x -> qa` and `y -> qc`.
   - Then `{I_q : q ∈ Q}` is a finite set of ideals.
   - Hence `⋂_Q I_q = 0` only if some single `I_q = 0`.
   - If every `e = 1`, then every `I_q = (x - 1, y - 1)`.

## Consequence for the Laurent-rank fork

A unital `F_2[Z^2] -> R` is a commuting unit pair `(a, c)`. Once one block is known not to be faithful,
the remaining way to build a faithful pair was to spread it over infinitely many invariant pieces with
different kernels, for example `y = x^n` on the `n`-th piece.

Item 4 kills this mechanism for every family of blocks of bounded shape depth. The invariant is the pair of
extreme graded components of the compressed unit. The route dies at item 1: a compressed unit in `S + T`
has its top component in the free algebra `S` and its bottom component in `T`. By the injectivity of
`S`-left and `T`-right multiplication and the `K_0` count `L_0 ≇ L_0^(2^A)`, this unit is a scalar.

So a faithful infinite family of diagonal (cylinder) blocks contributes only the trivial character away from
the finitely many cylinders shorter than the depth.

What survives:
- (i) a single faithful block, which is the original question in a corner `eRe ≅ R`;
- (ii) invariant idempotent families of unbounded shape depth;
- (iii) faithfulness that is not detected on invariant idempotents at all.

By `boundary-tensor-hosts-equal-binary-leavitt-tensor-hosts` (bus, 2026-09-18), the corner Laurent-ring
mechanism is the YES side of the `Z^4` fork of `decidable-algebras-embed-in-z2-sft-boundary-product-hosts`. This
node narrows that side to (i)–(iii).

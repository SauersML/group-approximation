## Setting

- `d >= 2`, `X = {0,…,d−1}`, `C = X^ω`. `V_d` is the Higman--Thompson group of
  homeomorphisms `h` of `C` given by complete prefix codes `{u_i}`, `{v_i}`
  with `h(u_i w) = v_i w`.
- More generally, for a self-similar `G ≤ Aut(X*)`, `V_d(G)` is the
  Röver--Nekrashevych group of maps `h(u_i w) = v_i g_i(w)` with `g_i in G`.
  `V_d = V_d(1)`.
- The **depth** `dep(h)` is the least `D` such that `h` has such a
  representation with all `|u_i|, |v_i| <= D`.
- Put `B(D) = D d^(2D)` and `R_d(D) = (d^(D + 3B(D) + 1))!`, and
  `R♯(L) = R_L(L^2)` for `L >= 2`. These are recursive and non-decreasing in
  `d`, `D` and `L`.
- `FS` is the finite-subgroup profile of `short-expander-subgroups-force-folner-growth`.

## Statement

1. **Depth is subadditive.** `dep(gh) <= dep(g) + dep(h)` and
   `dep(g^(−1)) = dep(g)` in `V_d(G)`.
2. **Finite subgroups are bounded by depth.** Let `G` be self-similar and
   torsion-free (for example `G = 1`). If a finite `Γ ≤ V_d(G)` is generated by
   elements of depth at most `D`, then `|Γ| <= R_d(D)`.
3. **Profile bound.** If `K = <S> ≤ V_d(G)` is finitely generated, `G`
   torsion-free self-similar, and `D_0 = max dep(s)`, then
   `FS_(K,S)(L) <= R_d(D_0 L)` for all `L`. In particular
   `FS_(K,S)(L) <= R♯(L)` once `L >= max(d, D_0)`, so `FS_K ≼ R♯` with one
   recursive `R♯` for every finitely generated subgroup of every such group.
4. **The short-expander mechanism is capped.** For such `K` amenable and any
   `δ > 0`, `X^δ_K <= FS_K ≼ R♯`. So item 4 of
   `short-expander-subgroups-force-folner-growth` can never produce, inside
   these hosts, a witness for E at any `U` with `L·U(L^3) ≽ R♯`.
5. **Brieussel--Zheng witnesses do not embed.** Let `U` be recursive and
   non-decreasing with `U(n) >= R♯(n)` for all `n >= 2`. Then the group `Δ_U` of
   `decidable-amenable-groups-have-no-recursive-folner-bound` embeds in no
   `V_d(G)` with `G` torsion-free self-similar, for any `d`. In particular it
   embeds in no Higman--Thompson group `V_d`, including `V = V_2`.

## Reading

- Sub-question (b) of Attempt 3 on E asked whether every `Δ_U` embeds in one
  fixed Thompson-like group such as `V`. Item 5 says no for all `V_d` and all
  torsion-free Röver--Nekrashevych groups, and item 4 says the same for every
  witness whose Følner growth comes from short finite subgroups.
- The invariant is `FS`. It is monotone under embeddings of finitely
  generated groups, and `FS_(Δ_U) ⋠ U`.
- A host `S` with solvable word problem and `FS_S ≼ R` for a recursive `R` has
  decidable order problem: `g` of length `L` has finite order iff `g^k = 1` for
  some `k <= R(L)`. So any fixed host that could carry every `Δ_U` must have
  `FS` above every recursive function. An undecidable order problem is one way
  to get that.
- Not covered: Brin--Thompson `nV` for `n >= 2`, where pumping fails
  (`brin-thompson-torsion-has-clopen-fixed-sets`), and `V_d(G)` for `G` with
  torsion, where `K_n <= G^(d^n)` can be a large finite group.

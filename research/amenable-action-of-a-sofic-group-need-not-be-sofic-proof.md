Notation as in the target. Kazhdan groups are finitely generated. Fix a finite
generating set `S` of `G_0`.

## (A1) `H` is finitely generated and sofic

`H` is generated by `S ∪ {t}`. `G` is residually finite, hence sofic. The
group `directSum_(n in Z) G_n` is the directed union of finite direct products
of copies of `G`, so it is sofic by
[[elek-szabo-sofic-permanence]] (1). It is normal in `H` with quotient `Z`,
which is amenable, so `H` is sofic by (3) of the same theorem.

## (A2) `K` is co-amenable

For `m in Z` put `x_m = t^m K in X`. Conjugation by `t^m` shifts coordinates
by `m`, so

```text
Stab_H(x_m) = t^m K t^-m = Gamma_m x directSum_(n >= m+1) G_n.        (CA1)
```

For `m <= -1` the coordinate `0` lies in the range `n >= m+1`. So
`G_0 <= Stab_H(x_m)` and `s x_m = x_m` for every `s in S ∪ S^-1`. Also
`t^(±1) x_m = x_(m±1)`. For `N >= 1` put

```text
mu_N = (1/N) sum_(m=-2N)^(-N-1) delta_(x_m),
```

a probability measure on `X`. Then `s_* mu_N = mu_N` for `s in S ∪ S^-1`.
The window `[-2N, -N-1]` moves by one, so
`||(t^(±1))_* mu_N - mu_N||_1 <= 2/N`. By the triangle inequality,
`||g_* mu_N - mu_N||_1 <= 2|g|/N` for every `g in H`, where `|g|` is word
length in `S ∪ S^-1 ∪ {t^(±1)}`. Take a weak-* cluster point `mu` of the
`mu_N` in `ell^infinity(X)^*`. For `f in ell^infinity(X)` we get
`|mu(g.f) - mu(f)| <= limsup ||g_* mu_N - mu_N||_1 ||f||_infinity = 0`. So `mu`
is an `H`-invariant mean, and `K` is co-amenable in `H`.

## (A4) the direct-sum wreath product is nonsofic

`G_0 ∩ K = Gamma_0`. An element of `K` supported in coordinate `0` has its
coordinate in `Gamma`, and `Gamma_0 <= K`. So the `G_0`-orbit
`O = G_0 x_0` is isomorphic, as a `G_0`-set, to `G_0/Gamma_0`, which is
`G/Gamma` under `G ~= G_0`.

Inside `W = (directSum_X Z/2) x| H`, the lamps supported on `O` form the
subgroup `directSum_O Z/2`. The group `G_0` permutes `O`, so it normalizes
this subgroup, and the two meet trivially. Hence they generate

```text
(directSum_O Z/2) x| G_0  ~=  (Z/2) wr_(G/Gamma) G,
```

which is not sofic by Kun--Thom Theorem A ([[kun-thom-nonsofic-wreath]]).
Subgroups of sofic groups are sofic, so `W` is not sofic.

## (A3) the action is nonsofic

Suppose `H ↷ X` were sofic. Then `Z/2` and `H` are sofic (A1), and GKP Theorem
3.6 ([[gkp-wreath-permanence-theorem]]) would make `(Z/2) wr_X H` sofic. That
contradicts (A4). `∎`

## Remarks

1. The same restriction argument gives (A3) directly, through GKP Proposition
   2.15(2),(3) and `coordinate-action-not-sofic`. The route above avoids that
   dependency.
2. Nothing in (A2) uses property (T). The mean is supported on the half-line
   `{x_m : m <= -1}`, where `G_0` acts trivially. That half-line is disjoint
   from the Kun--Thom orbit `G_0 x_0`, because `t^m` does not lie in
   `directSum_n G_n`. So the mean gives the nonsofic orbit measure zero.
3. The construction is uniform. For **any** subgroup `Gamma <= G`, the
   subgroup `Gamma_0 x directSum_(n>=1) G_n` is co-amenable in `G wr Z`, and
   restricting to `G_0` the orbit through `x_0` realizes `G ↷ G/Gamma`. So
   every coset action of every group is an orbit of the restriction to `G_0`
   of an amenable action of `G wr Z`. If `G` is sofic, so is `G wr Z`.

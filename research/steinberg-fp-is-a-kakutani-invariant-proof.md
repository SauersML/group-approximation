## 1. The matrix picture of a full corner

Let `f ∈ R` be full. Write `1 = Σ_{j=1}^n a_j f b_j`, and put `α_j = a_j f ∈ Rf`, `β_j = f b_j ∈ fR`, so that
`Σ_j α_j β_j = 1`. Let `S = fRf`, whose unit is `f`.
- **The maps.** Define `Φ : R -> M_n(S)` by `Φ(r)_{ij} = β_i r α_j`, and `Ψ : M_n(S) -> R` by `Ψ(M) = Σ α_i M_{ij} β_j`.
- **Φ is multiplicative:** `(Φ(r)Φ(r'))_{ij} = Σ_k β_i r α_k β_k r' α_j = β_i r r' α_j`.
- **Φ is injective:** `ΨΦ(r) = Σ α_i β_i r α_j β_j = r`.
- **Its image.** `P := Φ(1)` is idempotent. For `M = PMP` one has `ΦΨ(M) = PMP = M`, so `Φ(R) = P M_n(S) P`.

So `R ≅ P M_n(S) P`.

**P is full in `M_n(S)`.** The ideal it generates is `M_n(I)`, where `I` is the ideal of `S` generated by the entries
of `P`. It contains every entry of `Φ(f) = PΦ(f)P`. Then `f = Σ_{i,j} (f a_i f) Φ(f)_{ij} (f b_j f)` lies in `I`: the
right side is `f(Σ α_i β_i) f (Σ α_j β_j) f`. So `I = S`.

## 2. Full corners of finitely presented algebras are finitely presented

Let `R = k⟨x_1, …, x_m⟩ / (r_1, …, r_l)`, and fix words `φ, A_j, B_j` in the `x`'s representing `f, a_j, b_j`.
Set `α_0 = β_0 = f`, and let `J = {0, …, n}`.

**Generators.**
- **Of `S`.** `S` is spanned by the elements `f w f`, `w` a word. Insert `1 = Σ α_j β_j` between consecutive
  letters. This shows `S` is generated by the finite set `T = {β_j x_i α_{j'}, β_j α_{j'} : j, j' ∈ J}`.
- **Free algebra.** Let `F` be free on symbols `y_{j i j'}` and `z_{j j'}` for these elements, and `π : F -> S` the
  surjection.
- **Matrices over `F`.** Put `X_i = (y_{j i j'})` and `P̃ = (z_{j j'})`, with indices `j, j' ∈ {1, …, n}`.

**Relations.** Let `Q'` be the ideal of `F` generated by the entries of the following finitely many matrices and
elements.
- (a) `P̃^2 - P̃`, and `P̃ X_i P̃ - X_i`.
- (b) `r_k(X_1, …, X_m)`, evaluated in the corner algebra with unit `P̃`, so a constant `c` becomes `c P̃`.
- These first two make `x_i ↦ X_i` a unital homomorphism `θ : R -> P̃ M_n(F/Q') P̃`.
- (c) `(z_{j0} z_{0i})_{j,i} - θ(f)`, where `θ(f) = φ(X)` is a matrix whose entries are explicit elements of `F`.
- (d) `z_{00} - 1`, and `Σ_{i,j} z_{0i} θ(f)_{ij} z_{j0} - 1`.
- (e) `t - ρπ(t)` for each generator `t ∈ {y, z}`, where `ρ` is defined next. For instance
  `ρπ(y_{j i j'}) = Σ_{p,q} z_{0p} [θ(f)θ(B_j) X_i θ(A_{j'})θ(f)]_{pq} z_{q0}`, again an explicit element of `F`.

**The inverse map.** Define `ρ : S -> F/Q'` by `ρ(s) = Σ_{p,q} z_{0p} θ(s)_{pq} z_{q0}`. It is linear.
- **Multiplicative, by (c):**
  `ρ(s)ρ(s') = Σ z_{0p} [θ(s) θ(f) θ(s')]_{pq} z_{q0} = ρ(s f s') = ρ(s s')`.
- **Unital:** `ρ(f) = 1`, by (d).

**All relations hold in `S`.** Applying `π` entrywise to `θ` gives `Φ`. For (a) and (b) this is because `Φ` is a
unital homomorphism onto the corner with unit `P`. For (c): `π(z_{j0} z_{0i}) = β_j f α_i = Φ(f)_{ji}`. For (d): as
in §1. For (e):
- `πρ(s) = Σ f α_p Φ(s)_{pq} β_q f = f s f = s`, so `πρ = id_S`.
- Hence `π(ρπ(t)) = π(t)`, which is (e).

So `π` descends to `π̄ : F/Q' -> S`. By (e), `ρπ̄` fixes every generator. Since `ρπ̄` is an algebra
homomorphism, it is the identity, so `π̄` is injective. Hence `S ≅ F/Q'` is finitely presented.

## 3. Proof of item 1

- **(⇒)** is §2.
- **(⇐)** Suppose `S = fRf` is finitely presented.
  - `M_n(S)` is finitely presented. Its generators are the matrix units and `s e_{11}` for generators `s` of `S`.
    Its relations are:
    - those of `S` in the `(1,1)` corner, with unit `e_{11}`;
    - `e_{11} g e_{11} = g` for each generator `g = s e_{11}`;
    - the matrix-unit relations, including `Σ e_{ii} = 1`.

    Then `s ⊗ 1 = Σ_i e_{i1} (s e_{11}) e_{1i}` commutes with the matrix units, and the presented algebra is
    `S ⊗ M_n(k)`.
  - `P` is a full idempotent there (§1), so by §2 `P M_n(S) P ≅ R` is finitely presented.
- **`M_n(R)`.** Apply this to the full idempotent `e_{11} ∈ M_n(R)`, whose corner is `R`. ∎

## 4. Proof of item 2

**1_U is full.** Let `U ⊆ 𝒢^(0)` be full and clopen.
- Every `x ∈ 𝒢^(0)` is `r(γ)` for some `γ` with `s(γ) ∈ U`. Take a compact open bisection `B_γ ∋ γ` with
  `s(B_γ) ⊆ U`.
- The sets `r(B_γ)` are open and cover the compact unit space, so finitely many do: `B_1, …, B_n`.
- Shrink `B_i` to `B_i ∩ r^{-1}(r(B_i) \ ∪_{j<i} r(B_j))`, still compact open. Then the ranges partition `𝒢^(0)`,
  and `1 = Σ_i 1_{B_i} 1_U 1_{B_i^{-1}}`. So `1_U` is full.

**The corner is the restriction.** `1_U A_k(𝒢) 1_U = A_k(𝒢|_U)`, because a function supported on arrows with source
and range in `U` is a combination of `1_B` with `B ⊆ 𝒢|_U`.

**Conclusion.** By item 1, `A_k(𝒢)` is finitely presented iff `A_k(𝒢|_U)` is. The same holds for `ℋ` and `W`, and
`A_k(𝒢|_U) ≅ A_k(ℋ|_W)`. ∎

## 5. Proof of item 3

**The identification.** `A_k(Λ ⋉ X) = LC(X, k) ⋊ Λ` for a discrete group acting on a Cantor set: map `1_B` for
`B = {(λ, x) : x ∈ V}` to `1_{λV} u_λ`. Continuous orbit equivalence of topologically free actions is an
isomorphism of transformation groupoids (Li), a special case of Kakutani equivalence with `U = X`, `W = X'`.

- **(a)** By `sft-crossed-product-fp-iff-quantum-rigid`, which assumes neither freeness nor minimality, rigidity of a
  `Z^2`-SFT is equivalent to finite presentation of `LC(·, k) ⋊ Z^2`. Apply item 2.
- **(b)** `quantum-rigid-sfts-over-fp-groups-have-fp-crossed-products` makes `LC(X, k) ⋊ Λ` finitely presented.
  - Item 2 transfers this to `LC(X', k) ⋊ Λ'`.
  - `fp-crossed-products-force-finitely-presented-acting-group` then makes `Λ'` finitely presented.
  - `fp-crossed-products-force-sft-over-any-group` makes `X'` of finite type.
- **(c)** Item 2, with `k = F_2`. ∎

## Remark: what the invariance cannot do

A full clopen restriction preserves invariant measures up to scale, so Kakutani equivalence never turns an
amenable, measure-preserving groupoid into a compressive one.
- **Consequence.** The obstruction "an invariant measure blocks compression", which makes `Z^2` rigidity hard,
  cannot be removed by changing the model.
- **What can be changed.** The shape of the transversal: for example, supertile corners, where a self-similarity
  becomes a self-Kakutani equivalence `𝒢|_U ≅ 𝒢`, or return-time towers.

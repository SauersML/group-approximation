Let h>=2 and r>=1. On r copies of the h-adic Cantor set let
B=V_(h,r)(<a>), where a:z->z+1 is the h-adic odometer. An element
has a finite prefix table with a power a^c_i on each leaf. Then

    chi:B->Z,       chi(b)=sum_i c_i

is a well-defined surjective homomorphism. It is the near index of
the induced cofinite action on N, identifying n=r*q+i with root
i in {0,...,r-1} and the nonnegative integer q in the h-adics.
This near action is faithful.

The group B has type F_infinity. Its kernel is finitely generated:
it is generated by V_(h,r) together with one involution exchanging
two proper disjoint cones using odometer labels +1 and -1. No
finite presentation of this kernel is asserted.

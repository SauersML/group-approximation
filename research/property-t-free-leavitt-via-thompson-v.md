Let `pi_n` be an operator-norm asymptotic representation of `Delta`.

1. By `leavitt-mark-is-conjugate-into-thompson-v`, under
   `Delta = GL_20(R) = R^x` there is `u` with `u z u^-1 = v in V <= R^x`.
2. Restricted to `V`, `pi_n` is an operator-norm asymptotic representation
   of `V`.  By `thompson-v-has-full-mf-radical`,
   `||pi_n(v)-1|| -> 0`.
3. Conjugation is asymptotically multiplicative in operator norm, so
   `||pi_n(z)-1|| -> 0`.  Hence `z in Rad_MF(Delta)`.
4. `Rad_MF(Delta)` is normal and `z` normally generates `Delta`, so
   `Rad_MF(Delta) = Delta`.

**Kazhdan hygiene.**  Steps 1 and 3 to 4 are algebra plus KH2.  Step 2 is a
statement about `V`, which has the Haagerup property and so contains no
infinite Kazhdan subgroup.  So (T) cannot occur anywhere in this route,
including inside any proof of its open prerequisite.  The earlier reductions (rank,
ring, Jacobson, EL20) stay inside groups that are themselves normally
generated by Kazhdan subgroups.

**The single hole.**  `thompson-v-has-full-mf-radical` (V is not MF).  It
follows from the hub `thompson-v-not-hyperlinear`
(route `thompson-v-full-mf-radical-from-nonhyperlinearity`), so every
incoming route of that hub (KL violation, bounded unitary width, one-word
ceiling, Thompson F not hyperlinear, rigid defect) now also feeds this goal.

**Relation to the parallel route.**  `property-t-free-leavitt-via-thompson-v-not-mf`, from
swarm-0917-w15-ptl-last1 and landing separately, reaches the goal from the same hole. It uses a
different closing step, simplicity of `Delta` and the Steinberg lift of `V`. This route needs neither of
those, only KH2 and the normal generation by `z` that the goal records. It is also quantitative: the
conjugator `u` is a fixed element, so every operator-norm rate for `pi_n(v) -> 1` transfers to `z`
up to the defect on the fixed words `u`, `u^-1`.

**Direction.**  This is sufficient, not necessary.  `V <= Delta` gives
`Rad_MF(V) <= Rad_MF(Delta)`, which is no information about `V`.  If `V` is
MF, this route dies, together with every T-free argument that uses only the
relations of `V`.

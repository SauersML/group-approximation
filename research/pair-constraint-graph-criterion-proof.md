# Components carry the labels, words carry the paths, prefixes carry the counting

**Item 1, ⟸.**  Let `B` be the set of connected components of `𝒢` restricted
to `S × {p,q}` and `j_s(x) :=` the component of `(s,x)`.  Every equivariance
clause of the definition is the assertion that the two endpoints of one edge
of the restricted graph carry equal labels, which holds because endpoints of
an edge lie in one component; distinctness `j_s(p) ≠ j_s(q)` is the
assumption that the two vertices lie in distinct components.

**Item 1, ⟹.**  Conversely, given valid label data, equality of labels
propagates along each edge of the restricted graph (each edge *is* one
instance of the equivariance clause), hence by induction along any path:
vertices in one component carry one label.  If `(s,p)` and `(s,q)` shared a
component, `j_s(p) = j_s(q)` would contradict distinctness.

**Item 2.**  Traversing an edge generated by `(g, x)` forward moves
`(a, g⁻¹·x) → (φ(g)·a, x)`, i.e. `(a, y) → (φ(g)·a, g·y)` with the
requirement `g·y ∈ {p,q}`; traversing it backward moves
`(a, y) → (φ(g)⁻¹·a, g⁻¹·y)` with `g⁻¹·y ∈ {p,q}`.  A path from `(s,x)` is
therefore precisely a word `(g_1,ε_1),…,(g_k,ε_k)` whose slot trajectory
`x_i = g_i^{ε_i}·x_{i-1}` stays in `{p,q}` — slot-admissibility — with
point trajectory `a_i = φ(g_i)^{ε_i}·a_{i-1}`, `a_0 = s`.  The endpoint is
`(σ(s), v·x)` with `σ` and `v` as defined, since
`x_k = g_k^{ε_k}⋯g_1^{ε_1}·x = v·x` and `a_k = σ(s)`.  Restricting to
`S × {p,q}` restricts all `a_i` to `S`.

**Item 3.**  Let the word have length `k`, value `v` with `v·p = q`, and
`φ(v) = id`.  Because `φ` is a homomorphism, the traversal permutation is
`σ = φ(v) = id`, so for **every** `s ∈ A` the traversal based at `s` is a
path from `(s,p)` to `(s,q)` whose intermediate points are
`a_i = φ(v_i)·s`, `v_i := g_i^{ε_i}⋯g_1^{ε_1}`, `i = 1,…,k-1`.  If `S` is
admissible then by item 1 no such path may lie entirely in `S`, so for each
`s ∈ S` some intermediate point `φ(v_i)·s` lies in `D := A ∖ S`.  For fixed
`i`, the map `s ↦ φ(v_i)·s` is a bijection of `A`, so each `d ∈ D` arises
as `φ(v_i)·s` for exactly one `s`; hence at most `(k-1)|D|` elements of `S`
have a designated intermediate point in `D`, giving

```text
|S| ≤ (k-1)·|D| = (k-1)·(|A| - |S|),   i.e.   |S| ≤ ((k-1)/k)·|A|.
```

Two-point data at precision `ε` demands `|S| > (1-ε)|A|`; combining,
`1-ε < (k-1)/k`, i.e. `k > 1/ε`.  For `A = Q` regular under `π`, freeness
holds and `φ(v) = id ⟺ v ∈ ker π`, which is the stated form.  The
approximate-model remark is immediate: items 1–2 used no property of `φ`,
and in item 3 the traversal permutation differs from `φ(v)` by a
composition of `k` single-letter defects, each moving at most a
defect-fraction of points.

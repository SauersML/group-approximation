**ESTABLISHED.**  In the group `G` of
`dyadic-finite-perturbation-group-elementary-structure`, put

```text
x_0 = Z^3,   x_1 = 2^-1 Z^3,   x_2 = 2^-2 Z^3,
L = Gamma = Z^3 x| SL_3(Z) <= H <= G,
C = Sym{x_0,x_1,x_2} = S_3 <= Sym_fin(X),
u = a^3 (dilation by 8),   ell = t_(e_1).                         (TW1)
```

Then:

1. every element of `Gamma` fixes each of `x_0, x_1, x_2`, so
   `C <= C_G(Gamma)`, and `C` is finite hence locally finite;
2. `u Gamma u^-1 = 8Z^3 x| SL_3(Z) <= Gamma`, and `ell in Gamma`;
3. the supports

```text
Y = {8Z^3, 4Z^3, 2Z^3},      Z' = {e_1+8Z^3, e_1+4Z^3, e_1+2Z^3}   (TW2)
```
   of `uCu^-1` and of `ell u C u^-1 ell^-1` are **disjoint**, so those two
   subgroups commute elementwise;
4. `[C,C] = A_3` is generated by a nonidentity three-cycle.

This is exactly the hypothesis package of
`locally-finite-centralizer-derived-subgroup-is-mf-invisible`, with the
commuting-conjugate relation supplied by disjointness of two
three-element subsets of `X` rather than by any normality or finite-index
assumption.

Definitions are those quoted verbatim in `moore-ramsey-criterion-for-amenability`. For finite sets, a finitely additive
probability measure is a probability vector, and `μν(E) = Σ_{x,y} μ(x)ν(y) 1_E(xy)`. For a function `f`,
`gν(f) = Σ_y ν(y) f(gy)`.

**Two conventions used throughout.**
- *(Supp)* `P(A)ν ⊆ P(B)` holds iff `A · supp ν ⊆ B`. The measure `μν` is supported on `supp μ · supp ν`, and
  point masses `δ_a ∈ P(A)` realize every product `a·y`.
- *(Conv)* For `μ ∈ P(A)`, `μν(E) = Σ_a μ(a)·(δ_aν)(E)` is a convex combination. So
  `sup_{μ,μ' ∈ P(A)} |μν(E) − μ'ν(E)| = max_{a,a' ∈ A} |δ_aν(E) − δ_{a'}ν(E)|`.
  In particular a set witness only needs to be checked on point masses, and `R_{G,S}(m, ε) ≤ R̃_{G,S}(m, ε)`,
  because `< ε` implies `≤ ε` and `1_E` is a function into `[0,1]`.

Isomorphism invariance is used silently. If `φ : G → G'` is an isomorphism, then
`R_{G,S} = R_{G',φ(S)}` and `R̃_{G,S} = R̃_{G',φ(S)}`, because `φ` maps balls to balls and transports sets, functions
and measures.

## Lemma 1 (threshold dithering)

Let `G` have finite generating set `S_G`, and let `H = G × Z` be generated by `S_G × {0} ∪ {(e,1)}`.

**Word metric of H.** `|(g, z)|_H = |g| + |z|`. A word of length `ℓ` for `(g, z)` contains at least `|z|` letters
`(e, ±1)`, and its remaining letters spell `g`. So `ℓ ≥ |z| + |g|`. Concatenating a geodesic for `g` with `|z|`
letters `(e, ±1)` gives equality.

**Claim.** For all `m ≥ 0`, `T ≥ 1` and `ε ≥ 0`, `R̃_G(m, ε + 2/T) ≤ R_H(m + T − 1, ε)`.

**Proof.** Let `n = R_H(m + T − 1, ε)`. If `n = ∞` there is nothing to prove. Let `f : B_n(G) → [0,1]` be given.
- *Dither.* For `k ∈ {0, …, T−1}` put `θ_k = (k + 1/2)/T`. Define
  `E = {(x, z) ∈ B_n(H) : f(x) > θ_{z mod T}}`.
  This is well defined because `(x,z) ∈ B_n(H)` gives `|x| ≤ n`.
- *Witness.* Let `ν ∈ P(B_n(H))` witness that `B_n(H)` is ε-Ramsey with respect to `B_{m+T−1}(H)` for this `E`, and let
  `ν̄` be its image in `G` (the `G`-marginal).
- *Support of `ν̄`.* Take `y ∈ supp ν̄`, with `(y, w) ∈ supp ν`, and take `g ∈ B_m(G)`. Then
  `(g,0) ∈ B_{m+T−1}(H)`, so by (Supp) `(gy, w) ∈ B_n(H)`, and hence `|gy| ≤ n`. So `B_m(G)·supp ν̄ ⊆ B_n(G)`.
  Taking `g = e` also gives `ν̄ ∈ P(B_n(G))`.
- *Rounding count.* For `a ∈ [0,1]` let `c(a) = #{k < T : θ_k < a}`. The condition is `k < aT − 1/2`.
  - If `aT ≤ 1/2`, then `c(a) = 0`.
  - Otherwise `c(a) = ⌈aT − 1/2⌉`, which is at most `T` because `a ≤ 1`.
  - In both cases `|c(a)/T − a| ≤ 1/(2T)`.
- *Averaging over the Z-window.* For `g ∈ B_m(G)` let `μ_g` be uniform on `{(g, s) : 0 ≤ s < T}`. Since
  `|(g,s)|_H = |g| + s ≤ m + T − 1`, we have `μ_g ∈ P(B_{m+T−1}(H))`. Also `(g,s)(y,w) = (gy, s+w)`, and as `s` runs
  over `0, …, T−1`, the residue `(s+w) mod T` runs over every `k` exactly once. Hence
  `μ_gν(E) = Σ_{(y,w)} ν(y,w) · (1/T) Σ_s 1[f(gy) > θ_{(s+w) mod T}] = Σ_{(y,w)} ν(y,w) · c(f(gy))/T`.
  So `|μ_gν(E) − gν̄(f)| ≤ 1/(2T)`, where `gν̄(f) = Σ_{(y,w)} ν(y,w) f(gy)`.
- *Balance.* For `g, g' ∈ B_m(G)`,
  `|gν̄(f) − g'ν̄(f)| ≤ |μ_gν(E) − μ_{g'}ν(E)| + 1/T ≤ ε + 1/T < ε + 2/T`.

So `ν̄` witnesses the defining property of `R̃_G(m, ε + 2/T)` at radius `n`. ∎

*Remark.* The coloring `E` is a dithered picture of all the level sets of `f` at once. The extra `Z` coordinate
carries the threshold, and left multiplication by `G` does not touch it. This is why an abelian factor that commutes
with `G` suffices, and why `F`, which contains an undistorted `F × Z` (Lemma 3), pays only a window shift.

## Lemma 2 (coset push-forward)

Let `H ≤ G` be finitely generated by `S_H` and `S_G`. Suppose `c ≥ 1` has `B_m(H) ⊆ B_{cm}(G)` for all `m`, and `L` is
nondecreasing with `|h|_H ≤ L(|h|_G)` for all `h ∈ H`. Then for all `m` and `ε`,
`R_H(m, ε) ≤ L(2 R_G(cm, ε))`.

**Proof.** Let `n = R_G(cm, ε)` (assume it is finite) and `N = L(2n)`. Let `E ⊆ B_N(H)` be given.
- *Coset coordinates.* In each right coset `Hx` choose a representative `r` of minimal `G`-length. For `x ∈ G`
  write `x = h_x r_x` with `r_x` the chosen representative of `Hx` and `h_x ∈ H`. Then:
  - `|r_x|_G ≤ |x|_G`, so `|h_x|_G = |x r_x^{−1}|_G ≤ 2|x|_G`;
  - for `g ∈ H`, `Hgx = Hx`, so `r_{gx} = r_x` and `h_{gx} = g h_x`.
- *Lifted set.* `E' = {x ∈ B_n(G) : h_x ∈ E}`. Let `ν' ∈ P(B_n(G))` be a witness for `E'`, window `B_{cm}(G)`, and let
  `ν` be the push-forward of `ν'` under `x ↦ h_x`.
- *Support.* Take `g ∈ B_m(H) ⊆ B_{cm}(G)` and `y ∈ supp ν'`. By (Supp) `gy ∈ B_n(G)`, so
  `|g h_y|_G = |h_{gy}|_G ≤ 2n` and `|g h_y|_H ≤ L(2n) = N`. Hence `B_m(H)·supp ν ⊆ B_N(H)`, and `g = e` gives
  `ν ∈ P(B_N(H))`.
- *Balance.* For `g ∈ B_m(H)`: `δ_gν(E) = Σ_y ν'(y) 1_E(g h_y) = Σ_y ν'(y) 1_E(h_{gy}) = Σ_y ν'(y) 1_{E'}(gy) = δ_gν'(E')`.
  The third equality holds because `gy ∈ B_n(G)`, and `gy ∈ E'` iff `h_{gy} ∈ E`. By (Conv) and the witness property
  of `ν'` at the point masses `δ_g, δ_{g'}` (`g, g' ∈ B_{cm}(G)`), `|μν(E) − μ'ν(E)| ≤ ε` for all `μ, μ' ∈ P(B_m(H))`. ∎

The same proof with `f_i ∘ (x ↦ h_x)` in place of `1_{E'}` gives `R̃_H(m, ε, l) ≤ L(2 R̃_G(cm, ε, l))`. This is not
needed below.

## Lemma 3 (an undistorted copy of F × Z)

Elements of `F` are increasing PL homeomorphisms of `[0,1]` with dyadic breakpoints and slopes in `2^Z`. `x_0` is the
standard generator with slopes `2^{±1}, 1, 2^{∓1}` on three standard dyadic intervals. Either sign convention works
below. `x_1` is the identity on `[0,1/2]`, and on `[1/2,1]` it is the copy of `x_0` rescaled by `t ↦ (1+t)/2`.
- `λ(t) = t/2` and `ψ(a) = λ a λ^{−1}` on `[0,1/2]`, the identity on `[1/2,1]`. Then `ψ : F → F_{[0,1/2]}` is an
  isomorphism (dyadic breakpoints and slopes `2^k` are preserved by `λ^{±1}`; the inverse is restriction and
  rescaling).
- `H = ψ(F)·⟨x_1⟩`, generated by `S_H = {ψ(x_0), ψ(x_1), x_1}`.
- `χ(g) = log₂ g'(1^−)`, the log-slope at the fixed point `1`. It is a homomorphism `F → Z` by the chain rule. Since
  rescaling preserves slopes, `χ(x_1) = χ(x_0) = σ ∈ {±1}`. Hence `|χ(g)| ≤ |g|_S`.

**(i) `H ≅ F × Z` via `(a, k) ↦ ψ(a) x_1^k`, with `S × {0} ∪ {(e,1)}` going to `S_H`.** The factors have disjoint
supports `[0,1/2]` and `[1/2,1]`, so they commute and meet trivially. `x_1` has infinite order because
`χ(x_1^k) = σk`.

**(ii) Lipschitz.** With `c = max(|ψ(x_0)|_S, |ψ(x_1)|_S, 1)`, `B_m(H) ⊆ B_{cm}(F)`.

**(iii) Linear lower bound.** Let `h = ψ(a) x_1^k ∈ H` with `|h|_S = r`.
- `|k| = |χ(h)| ≤ r`, since `χ(ψ(a)) = 0`: `ψ(a)` is the identity near `1`.
- *Restriction does not add carets.* Let `N(·)` be the caret count of the reduced tree pair diagram, as in
  `thompson-f-word-length-is-comparable-to-caret-count`. We claim `N(a) ≤ N(h)`.
  - If `h = 1`, then `a = 1`.
  - Otherwise let `(D, R)` be the reduced diagram of `h`. It has at least one caret, so both trees contain the
    root caret, and `1/2` is a breakpoint of both leaf subdivisions. Write `D = root(D_L, D_R)` and
    `R = root(R_L, R_R)`.
  - `h` maps the leaf intervals of `D` affinely and in order onto those of `R`, and `h(1/2) = 1/2`. So the leaves of
    `D_L` go onto the leaves of `R_L`, and after doubling `(D_L, R_L)` is a tree pair diagram of the rescaled
    restriction `λ^{−1} h|_{[0,1/2]} λ = a`.
  - It is reduced. A cancellable caret of `(D_L, R_L)` (a caret with two leaf children at the same leaf positions
    `i, i+1` in both trees) is also a cancellable caret of `(D, R)`, because leaf positions in the left half are the
    same.
  - By uniqueness of reduced diagrams, `N(a) = #carets(D_L) ≤ N(h) − 1`. Uniqueness is the standard fact from
    Cannon–Floyd–Parry (Enseign. Math. 42 (1996), §2), and the imported comparison already presupposes it when it
    speaks of "the reduced tree pair diagram".
- By the imported comparison (constant `K ≥ 1` for `S`), `N(h) ≤ K(r + K)`, so
  `|a|_S ≤ K·N(a) + K ≤ K²r + K³ + K`.
- Hence `|h|_H ≤ |a|_S + |k| ≤ (K² + 1) r + K³ + K`. So `L(r) = A r + A` works, with `A = K³ + K² + K + 1`.
  (The word `ψ(w_a) x_1^k`, with `w_a` a geodesic for `a`, has length `|a|_S + |k|` in `S_H`.) ∎

## The theorem

For `m ≥ 0`, `T ≥ 1`, `ε ≥ 0`:

`R̃_{F,S}(m, ε + 2/T) ≤ R_{F×Z}(m+T−1, ε) = R_{H,S_H}(m+T−1, ε) ≤ L(2 R_{F,S}(c(m+T−1), ε)) ≤ 2A·R(c(m+T), ε) + A`.

- The first step is Lemma 1 with `G = F`.
- The equality is Lemma 3(i) and isomorphism invariance.
- The next step is Lemma 2 with the constants of Lemma 3(ii), (iii).
- The last step uses that `R(·, ε)` is nondecreasing (monotonicity in `A`, from the criterion node).
- The lower bound `R(m, ε + 2/T) ≤ R̃(m, ε + 2/T)` is (Conv). ∎

## The corollary: AMP(D) against AMP_set(D)

**Tower facts.**
- (T1) Each `exp_q` is nondecreasing, `exp_q ≤ exp_{q+1}`, and `exp_q ∘ exp_p = exp_{q+p}`.
- (T2) For `q ≥ 1`, `exp_q` is convex and increasing with `exp_q(0) ≥ 0`. So `exp_q(y) ≥ y·exp_q(1)` for `y ≥ 1`.
- (T3) Given `C ≥ 1`, choose `k` with `exp_k(1) ≥ 2C`. Then `Cy + C ≤ 2Cy ≤ exp_k(y)` for all `y ≥ 1`.

All inequalities below are read in `[0, ∞]`, with `exp_q(∞) = ∞`.

**AMP(D) ⇒ AMP_set(D).** `R(m, 1/u) ≤ R̃(m, 1/u)` by (Conv).

**AMP_set(D) ⇒ AMP(D + 2k)**, where `k` is chosen by (T3) for `C = max(4c + 2, 2A)`.
- Fix `m, u ≥ 1` and put `y = m + u`. Apply the theorem with `T = 4u` and `ε = 1/(2u)`, so `ε + 2/T = 1/u`:
  `R̃(m, 1/u) ≤ 2A·R(m', 1/u') + A`, with `m' = c(m + 4u)` and `u' = 2u`. Note `m' + u' ≤ (4c+2)y ≤ Cy`.
- By AMP_set(D), `R(m', 1/u') ≤ exp_D(R(exp_D(m' + u')) + 2u)`.
- By (T1) and (T3), `exp_D(m' + u') ≤ exp_D(exp_k(y)) = exp_{D+k}(y)`. So with `Q = R(exp_{D+k}(y))`, monotonicity
  of `R` gives `R(exp_D(m'+u')) ≤ Q`.
- `Q + 2u ≤ C(Q + u) ≤ exp_k(Q + u)`, so `R(m', 1/u') ≤ exp_{D+k}(Q + u)`.
- `2A z + A ≤ exp_k(z)` for `z ≥ 1` by (T3), so `R̃(m, 1/u) ≤ exp_{D+2k}(Q + u)`.
- `Q ≤ R(exp_{D+2k}(y))` by (T1) and monotonicity of `R`. Hence `R̃(m, 1/u) ≤ exp_{D+2k}(R(exp_{D+2k}(m+u)) + u)`. ∎

**Equivalence of the negations.** `¬AMP` says that AMP(D) fails for every `D`, and `¬AMP_set` says the same for
AMP_set(D).
- `¬AMP_set ⇒ ¬AMP` by the first implication.
- `¬AMP ⇒ ¬AMP_set` by the second: if AMP_set(D) held, AMP(D + 2k) would hold. ∎

## Remarks (not load-bearing)

- *Set-only form of the double gap.* The claim `thompson-f-ramsey-amplification-is-the-ramsey-reiter-gap` quotes
  `CR(M) ≤ R̃(R̃(1, 1/4M), 1/4M)`. The theorem with `T = 16M` and `ε = 1/(8M)` turns this into
  `CR(M) ≤ Φ_M(Φ_M(1))`, where `Φ_M(x) = 2A·R(c(x + 16M), 1/(8M)) + A`. So RGAP₂ can be stated with set radii only,
  at precision `1/(8M)`.
- *Where this leaves the hole.* The theorem transfers no information between precisions. `R(·, 1/u)` is bounded by
  `R(·, 1/(2u))`-type quantities, never by `R(·, 1/2)`. The whole difficulty of `¬AMP` is therefore the step from
  1/2-Ramsey sets to 1/u-Ramsey sets. By the w9 class kill (window-preserving decoupling dies on `F_2`), any proof of
  either direction of it must use `F`-specific structure or shift windows.
- *Two functions do not dither this way.* Suppose `f_0, f_1` are coded into one set by the parity of a second
  `Z` coordinate. A witness then balances only `ν_e(f_j∘g) + ν_o(f_{1−j}∘g)`, where `ν_e, ν_o` are the even and odd
  parts. If `f_1 = 1 − f_0` and the witness equidistributes parity (`ν̄_e = ν̄_o`), these constraints are vacuous.
  So the lemma says nothing about one function against two functions, which is Towsner's `l`-composition.
- *Other groups.* Lemmas 1 and 2 are group-independent. The theorem, with other constants, holds in any finitely
  generated `G` that contains a copy of `G × Z` with linear distortion. With elementary distortion `L`, the factor
  `2A` becomes `L(2·)`, and the corollary still holds with a larger `k`.

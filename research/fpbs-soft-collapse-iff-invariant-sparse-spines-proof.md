Notation as in the target. `G` is a Cayley graph, so it is unimodular and the
mass-transport principle (MTP) holds. `V(H)` is the vertex set of a subgraph `H`.

## Lemma 0 (no finite invariant sets)

Let `A` be a random vertex set with invariant law. Then
`P(0 < |A| < infinity) = 0`.

*Proof.* On `{0<|A|<infinity}`, send mass `1/|A|` from every vertex `x` to
every `a in A`. The expected mass sent from `o` is
`P(0<|A|<infinity) <= 1`. The mass received at `o` is infinite on
`{o in A, |A|<infinity}`. By the MTP that event has probability `0`, and by
invariance and countability so does `{some vertex lies in a finite nonempty A}`. ∎

## Theorem A, (1) ⇒ (2)

For `t > p_c`, let `I_t` be the unique infinite cluster of `omega_t`. It is an
invariant random connected infinite subgraph, and
`P(o in V(I_t)) = theta(t) -> 0`. ∎

## Theorem A, (2) ⇒ (1)

**Step 1 (levels).** For each `k >= 1`, take a spine `L_k` with
`P(o in V(L_k)) <= 2^-k`. Take these independent over `k`, and independent of
iid uniform labels `lambda^k_x` (`x in V(G)`), of tie-breaking labels, and of
the Bernoulli labels `U_e`.

**Step 2 (connectors).** For `x in V(L_{k+1})` let
`r = r_k(x) = d(x, V(L_k))`, which is finite because `L_k` is nonempty. If
`lambda^k_x < 2^-k/(r+1)`, add one geodesic from `x` to a nearest vertex of
`L_k`. Choose it among the finitely many candidates by the minimal
tie-breaking label, which is equivariant and a.s. well defined. Let `C_k` be
the union of the added geodesics.

* *Density.* Send mass `1` from `x` to each of the at most `r+1` vertices of
  its geodesic, when the geodesic exists. The expected mass sent is at most
  `E[2^-k/(r+1) · (r+1)] <= 2^-k`. By the MTP,
  `P(o in V(C_k)) <= 2^-k`.
* *At least one connector.* For `R >= 0`, let
  `A_R = {x in V(L_{k+1}) : r_k(x) <= R}`. This is an invariant random set,
  so by Lemma 0 it is infinite on `E_R = {A_R ≠ ∅}`. The union of the `E_R`
  has probability one. On `E_R`, conditionally on `(L_k, L_{k+1})`,
  infinitely many independent labels each succeed with probability at least
  `2^-k/(R+1)`, so a.s. some connector exists. Therefore `L_k ∪ C_k ∪ L_{k+1}`
  is connected a.s.

**Step 3 (decreasing spines).** Let `Omega_n = ∪_{k>=n} (L_k ∪ C_k)`. It is
connected, because consecutive levels are joined, and it is infinite. It is
decreasing in `n`, and `P(o in V(Omega_n)) <= 2^(2-n)`. Since
`sum_k P(v in V(L_k ∪ C_k)) < infinity`, Borel--Cantelli gives that a.s.
every vertex lies in only finitely many levels. So `1[v in V(Omega_n)] -> 0`
a.s. for every `v`.

**Step 4 (the family).** Put `omega_t = xi_t` for `t <= p_c`. For `t > p_c`,
put `omega_t = xi_{p_c} ∪ Omega_{n(t)}` with `n(t) = ceil(1/(t-p_c))`.

* (S1): `n(t)` is nonincreasing in `t`, and `xi_t ⊆ xi_{p_c}` for `t <= p_c`.
* (S2): holds by construction.
* *Insertion tolerance, `t>0`.* Put `s = min(t,p_c) > 0` and fix an edge `e`.
  Let `omega'` be `omega_t` computed with `U_e` replaced by `1`. Then `omega'`
  is independent of `U_e`, and `omega_t ∪ {e} = omega' ∪ {e}` whenever
  `U_e <= s`. If `omega_t in A`, then `omega' ∪ {e} = omega_t ∪ {e} in Pi_e A`.
  Hence `P(omega_t in Pi_e A) >= P(U_e <= s, omega' ∪ {e} in Pi_e A)
  = s · P(omega' ∪ {e} in Pi_e A) >= s · P(omega_t in A)`.
* (S4): By `fpbs-critical-no-infinite-cluster`, every cluster of `xi_{p_c}`
  is finite a.s. An infinite cluster of `omega_t` that contains no edge of
  `Omega_{n(t)}` would be a cluster of `xi_{p_c}`, so every infinite cluster
  contains `Omega_{n(t)}`, which is connected. Thus there is exactly one
  infinite cluster, and it exists because `Omega_n` is infinite. Next,
  `theta(t) = P(C_xi(o) ∩ V(Omega_{n(t)}) ≠ ∅)`, where `C_xi(o)` (containing
  `o`) is finite a.s. By Step 3 the finite set `C_xi(o)` eventually misses
  `V(Omega_n)`. Dominated convergence gives `theta(t) -> 0` as `t ↓ p_c`.
* *(S3), ergodicity.* Write the system as `Y x B`, where `B` carries the
  Bernoulli labels `U` and `Y` carries everything else. Decompose the law of
  `Y` into ergodic components `mu_c`. For ergodic `mu_c` and the mixing
  Bernoulli action `nu`, `mu_c ⊗ nu` is ergodic. Every property used above is
  an a.s. property of `Y`, or of `Y` together with the independent `U`:
  connectivity of the `L_k`, existence of connectors, per-vertex finiteness of
  levels, and critical finiteness. So they hold for `mu_c ⊗ nu` for a.e. `c`.
  Choose such a component; there (S2) still holds, since `U` keeps its law. ∎

## Theorem B

Let `N = ker pi`, generated by `n_1..n_m`, which are written as fixed `S`-words
`w_j`. Pick `t0` with `pi(t0) = 1`, written as an `S`-word `w_0`. Let
`M = max_s |pi(s)|` and `C = M · max_j |w_j|`. For a word `w = s_1...s_l` and
a vertex `x`, `P(x,w)` is the path `x, x s_1, ..., x s_1...s_l`. Left
multiplication maps `P(x,w)` to `P(gx,w)`.

* *Sheets.* `Sh_h = ∪_{x in pi^-1(h), j} P(x,w_j)`. Since
  `pi^-1(h) = x_0 N` and `N` is generated by the `n_j`, `Sh_h` is connected
  and contains `pi^-1(h)`. Its vertices have heights in `[h-C, h+C]`, and
  `g Sh_h = Sh_{h+pi(g)}`.
* *Level `k`.* Let `H_k ⊂ Z` be Bernoulli(`2^-k`) (iid labels on `Z`, on which
  `Gamma` acts through `pi`), so it is a.s. unbounded in both directions. For
  `h in H_k`, let `h^+` be the next point of `H_k`. Take iid uniform labels
  `lambda_x` on `V(G)`. For `x in pi^-1(H_k)` with `lambda_x < 2^-k`, let the
  connector be `P(x, w_0^(h^+ - h))`, which runs from `x` to
  `x t0^(h^+-h) in pi^-1(h^+)`. Put
  `L = ∪_{h in H_k} Sh_h ∪ (connectors)`. Its law is invariant.
* *Connected and infinite.* Each sheet is connected. For consecutive
  `h < h^+` there are infinitely many `x in pi^-1(h)` with independent labels,
  so a.s. at least one connector joins `Sh_h` to `Sh_{h^+}`. Since `H_k` is
  bi-infinite, `L` is connected and infinite.
* *Density.* `P(o in V(Sh_h) for some h in H_k) <= P(H_k ∩ [pi(o)-C, pi(o)+C]
  ≠ ∅) <= (2C+1) 2^-k`. If `o` lies on a connector, then `o = x t0^i u` with
  `u` a prefix of `w_0` (at most `|w_0|` choices), `i >= 0`, and no point of
  `H_k` in `(pi(x), pi(x)+i]`. For fixed `(i,u)` the vertex `x` is determined,
  so the probability is at most `2^-k · 2^-k (1-2^-k)^i`. Summing over `i` and
  `u` gives at most `|w_0| 2^-k`. So `P(o in V(L)) <= (2C+1+|w_0|) 2^-k -> 0`. ∎

## Corollary C

* `T_3 x Z`: `pi` is the projection and the kernel is
  `Z/2*Z/2*Z/2`. Hutchcroft (arXiv:1711.02590) gives `p_c < p_u`.
* Closed hyperbolic mapping tori: `Gamma = pi_1(Sigma_g) ⋊_phi Z` with `phi`
  pseudo-Anosov is hyperbolic (Thurston), and the kernel is a surface group.
  Hutchcroft (arXiv:1804.10191, `fpbs-hyperbolic-nonunimodular-critical-l2-gap`)
  gives `p_c < p_{2->2}`, so `||T_{p_c}||_{2->2} < infinity`.
* `F_2 x Z`: the kernel is `F_2`, and Pak--Smirnova-Nagnibeda give some
  generating set with `p_c < p_u`.

*Operator norm under uniqueness.* If `I` is the unique infinite cluster of an
invariant percolation and `theta = P(o in I)`, then
`<1_B, T 1_B> = E #{(x,y) in B^2 : x <-> y} >= E|I ∩ B|^2 >= (E|I ∩ B|)^2
= theta^2 |B|^2`. So `||T||_{2->2} >= theta^2 |B_R| -> infinity`.

A proof of `p_c < p_u` that uses only (S1)--(S4) and Bernoulli facts at
`p <= p_c` would apply verbatim to the family of Theorem A on these graphs.
There `p_u = p_c` for the family, which contradicts nothing about Bernoulli
but refutes the proof's own inference. ∎

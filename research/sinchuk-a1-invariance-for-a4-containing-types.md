**Literature input (source re-read 2026-08-31, arXiv:2412.06944,
version dated 2026-03-22, Theorem 1.1).**  Sergei Sinchuk, *On the
A1-invariance of K2 of Chevalley groups of simply-laced type*, European
Journal of Mathematics (2025), arXiv:2412.06944.

Let `k` be an arbitrary field, let `A` be a regular ring containing `k`,
and let `Phi` be an irreducible simply-laced root system which contains
`A_4` and is not of type `E_8`.  For any lattice defining the corresponding
Chevalley--Demazure group scheme `G`, the canonical polynomial-extension map
is an isomorphism

```text
K2^G(A) -> K2^G(A[t]).                                      (SAI1)
```

For the simply connected linear group of type `A_(r-1)`, this applies to
every `r>=5`.  Iteration gives invariance under adjoining any finite number
of polynomial variables to a regular coefficient ring.  The theorem is
unstable: it concerns the kernel of the fixed-root-system Steinberg map,
not Quillen stable `K2`.

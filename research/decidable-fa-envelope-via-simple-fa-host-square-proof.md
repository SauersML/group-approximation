Let `G` be finitely generated with solvable word problem. Conventions follow
Serre, *Trees*: a group has **property FA** if every action on a tree without
inversions has a fixed vertex. (An action with inversions has none after
barycentric subdivision, so nothing is lost.)

**Step 1 (the factor).** `G x Z` is finitely generated, has solvable word
problem and contains `G`. By `decidable-groups-embed-in-decidable-simple-fa-groups`
it embeds in a finitely generated simple group `S` with property FA and solvable
word problem. `S` contains `Z`, so it is infinite. A finitely generated group
with solvable word problem is computably presented: the set of trivial words is
a recursive set of relators.

**Step 2 (the square).** Put `W = (S x S) ⋊ <sigma>`, `sigma^2 = 1`,
`sigma (x, y) sigma^-1 = (y, x)`. Then `G <= S x 1 <= W`, and `W` is generated by
a finite generating set of `S x 1` together with `sigma`, because
`sigma (s, 1) sigma^-1 = (1, s)`.

**Step 3 (word problem).** Every element of `W` is uniquely `(x, y) sigma^e` with
`e in {0, 1}`. Scan a word left to right keeping `(u, v, e)`, where `u, v` are
words in the generators of `S`. Right multiplication by `(s, 1)^{±1}` gives
`(x s^{±1}, y) sigma^e` when `e = 0` and `(x, y s^{±1}) sigma^e` when `e = 1`,
since `sigma (s,1) sigma^-1 = (1,s)`; right multiplication by `sigma` flips `e`.
The word is trivial iff the final `e` is `0` and `u = 1`, `v = 1` in `S`, which is
decidable by Step 1.

**Step 4 (FA of the square from FA of the factor).** Let `W` act on a tree `T`
without inversions. Write `S_1 = S x 1` and `S_2 = 1 x S`.

1. `X = Fix(S_1)` is nonempty because `S_1 ≅ S` has FA. It is a subtree: if
   `S_1` fixes vertices `u, w`, it maps the geodesic `[u, w]` to a geodesic with
   the same endpoints, which is the same geodesic, and it fixes it pointwise.
2. `S_2` commutes with `S_1`, so it preserves `X`: for `t in S_2`, `s in S_1`,
   `x in X`, `s t x = t s x = t x`. `S_2 ≅ S` acts on the tree `X` without
   inversions and has FA, so it fixes some vertex `v in X`. Hence
   `S x S = S_1 S_2` fixes `v`.
3. `[W : S x S] = 2`, so the orbit `W v = {v, sigma v}` has at most two points.
   `W` permutes these two points, so it maps the geodesic `[v, sigma v]` onto
   itself and fixes its midpoint `p`. If `d(v, sigma v)` is even, `p` is a vertex
   fixed by `W`. If it is odd, `p` is the midpoint of an edge `e`; `W` stabilizes
   the geometric edge `e` and, acting without inversions, fixes both endpoints.

So `W` fixes a vertex, and `W` has property FA.

Take `W_G = W`. All three bullets of the target hold: `W_G` is finitely
generated with solvable word problem, has FA, and is `S wr C_2` with `S`
infinite, finitely generated, computably presented and simple. `∎`

## Remarks

- The route needs neither `fg-perfect-wreath-c2-has-property-fa` (still OPEN)
  nor the Kuznetsov argument of the demoted wreath-square attempt: FA of the
  factor replaces perfectness, and the word problem of `S` is supplied
  directly.
- Step 4 proves, for any group `A`, that `A wr C_2` has FA whenever `A` has FA.
  So `fg-perfect-wreath-c2-has-property-fa` carries content only for factors
  `A` without FA, such as simple groups that split as amalgams.

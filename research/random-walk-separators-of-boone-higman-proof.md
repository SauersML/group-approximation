- (Prod) `boone-higman-type-a-class-closed-under-finite-extensions`, items 1

- (Wr) `permutational-boone-higman-closed-under-wreath-products`, which states

## Item 1. The witness lies in B_A

1. `V` is in `B_A` (Wr, special cases).
2. By (Cube), `Z/2 wr Z ≤ V`. So `Z/2` and `Z` are subgroups of `V`, and both
   lie in `B_A` by subgroup closure (Prod).
3. `Z^3` is in `B_A` by closure under finite direct products (Prod).
4. `W = Z/2 wr Z^3` is in `B_A` by (Wr), with `A = Z/2`, `G = Z^3` and
   `X = Z^3`, where the stabilizers are trivial.
5. By (Prod) item 3, `W` embeds in a finitely presented simple group `S_W`.

`W` is finitely generated by `δ` and `e_1, e_2, e_3`, and it is metabelian,
hence amenable. So `W` lies in every tested family `𝓗` listed in the claim.

**Coordinates.**
- Elements of `W` are pairs `(f, z)`. Here `f : Z^3 -> Z/2` has finite support
  and `z ∈ Z^3`.
- The product is `(f, z)(g, w) = (f + τ_z g, z + w)`, where
  `(τ_z g)(y) = g(y - z)`.
- `δ = (δ_0, 0)` and `e_i = (0, e_i)`.
- `π(f, z) = z` is a surjective homomorphism `W -> Z^3`.
- Right multiplication by `(c δ_0, 0)` with `c ∈ Z/2` adds `c` to the lamp at
  the current position: `(f, z)(c δ_0, 0) = (f + c δ_z, z)`.

## Lemma A. Admissible walks on Z^3 are transient

Let `ρ` be a symmetric, finitely supported probability measure on `Z^3` whose
support generates `Z^3`, and let `S_n` be its walk from `0`. Then

```text
Σ_(n>=0) P(S_n = 0)  <  ∞ .
```

Hence `γ_ρ := P(S_k ≠ 0 for all k >= 1) > 0`. Also, almost surely every finite
set is visited only finitely often.

**Proof.**

*Fourier set-up.* Let `φ(θ) = Σ_z ρ(z) cos(θ·z)` for `θ ∈ T = [-π, π]^3`. It
is real because `ρ` is symmetric, and `|φ| <= 1`. Then
`P(S_n = 0) = (2π)^-3 ∫_T φ^n dθ`. For `0 <= t < 1`, summing the geometric
series gives

```text
G(t) := Σ_n t^n P(S_n = 0) = (2π)^-3 ∫_T dθ / (1 - t φ(θ)) .
```

*Bound on the integrand, uniform in `t`.*
- Where `φ(θ) < 0`, the integrand is at most `1`.
- Where `φ(θ) >= 0`, it is at most `1 / (1 - φ(θ))`.

So it is at most `1 + 1/(1 - φ)`, with the convention `1/0 = ∞` at the zeros
of `1 - φ`. It remains to show `∫_T dθ / (1 - φ) < ∞`.

*Zeros of `1 - φ`.* `φ(θ) = 1` iff `θ·z ∈ 2πZ` for every `z ∈ supp ρ`. Since
`supp ρ` generates `Z^3`, this holds iff `θ·z ∈ 2πZ` for all `z ∈ Z^3`, that is,
iff `θ ∈ 2πZ^3`. In `T` this is only `θ = 0`.

*Near the origin.* Let `M = max_(z ∈ supp ρ) |z|` and `η = π / M`. For
`|θ| <= η`, every `|θ·z| <= π`, and `1 - cos x >= 2x^2/π^2` on `[-π, π]`. So

```text
1 - φ(θ)  >=  (2/π^2) Q(θ),      Q(θ) = Σ_z ρ(z) (θ·z)^2 .
```

Here `Q` is positive definite, because `supp ρ` spans `R^3`. So
`Q(θ) >= λ|θ|^2` for some `λ > 0`.

*Away from the origin.* On the compact set `T ∩ {|θ| >= η}`, the continuous
function `1 - φ` has no zero, so it is at least some `c' > 0`.

*Integrability.* Therefore

```text
∫_T dθ/(1-φ)  <=  (π^2 / 2λ) ∫_(|θ|<=η) |θ|^-2 dθ  +  (2π)^3 / c'
              =   (π^2 / 2λ) 4π η  +  (2π)^3 / c'   <  ∞ .
```

So `G(t)` is bounded uniformly in `t < 1`. By monotone convergence,
`Σ_n P(S_n = 0) = lim_(t↑1) G(t) < ∞`.

*Consequences.*
- The expected number of visits to `0` is `1/γ_ρ` when `γ_ρ > 0`, and it is
  infinite when `γ_ρ = 0`. So `γ_ρ > 0`.
- The expected number of visits to any `y` is at most the expected number of
  visits to `0`, by the strong Markov property at the first visit to `y`. So
  every finite set has finite expected visit count, and it is visited finitely
  often almost surely. ∎

(Context only: this is the classical Pólya--Chung--Fuchs transience of
genuinely three-dimensional walks, as in Spitzer, *Principles of Random Walk*,
T8.1. The proof above does not use it.)

## Lemma B. The range grows linearly

In the setting of Lemma A, let `R_n = |{S_0, ..., S_n}|`. Then
`E R_n >= γ_ρ (n+1)`.

**Proof.** Call `k ∈ {0, ..., n}` a *last visit* if `S_j ≠ S_k` for all
`j > k`. Distinct last visits `k < k'` have `S_k ≠ S_k'`, by definition applied
to `k`. So `R_n >= #{k <= n : k is a last visit}`. By the Markov property at
time `k`, the probability that `k` is a last visit is `γ_ρ`. Take
expectations. ∎

## Item 2. Linear entropy and drift for the switch-walk-switch measure

Let `Y = a s b`, where `a, b` are uniform on `{1, δ}`, `s` is uniform on
`{±e_1, ±e_2, ±e_3}`, and all three are independent. Let `μ_0` be the law of
`Y`.

**Admissibility.**
- *Symmetric:* `Y^-1 = b^-1 s^-1 a^-1 = b s^-1 a`, which has the law of `Y`,
  since `a` and `b` are exchangeable and `s^-1` has the law of `s`.
- *Finite support:* `supp μ_0` has at most 24 elements.
- *Generating:* the support contains every `e_i^(±1)` (take `a = b = 1`) and
  `δ e_1` (take `a = δ`, `b = 1`). So it generates
  `⟨δ, e_1, e_2, e_3⟩ = W`.

**The lamps are fair coins given the path.** Take i.i.d. copies
`Y_i = a_i s_i b_i`. Put `c_i = b_i + a_(i+1)` in `Z/2` for `1 <= i <= n-1`,
writing `δ^c` for `c ∈ Z/2`. Since `δ^2 = 1`,

```text
X_n = δ^(a_1) s_1 δ^(c_1) s_2 δ^(c_2) ... s_(n-1) δ^(c_(n-1)) s_n δ^(b_n) .
```

Relabel the lamp bits by the time at which they are applied:
`ε_0 = a_1`, `ε_i = c_i` for `1 <= i <= n-1`, and `ε_n = b_n`.
- The bits `ε_0, ..., ε_n` are i.i.d. uniform on `Z/2`. Each is a function of
  its own block of the variables `a_1, b_1, a_2, ..., b_n`, and each `c_i` is a
  sum of two independent uniform bits.
- They are independent of `(s_1, ..., s_n)`.

Let `S_i = s_1 + ... + s_i`, which is simple random walk on `Z^3`. By the
coordinate rule for right multiplication by `δ^c`,

```text
X_n = (f_n, S_n),        f_n(y) = Σ_( i <= n : S_i = y ) ε_i .
```

Condition on the path `(S_0, ..., S_n)`.
- Off the range, `f_n` vanishes.
- On the range, the values `f_n(y)` are sums of the bits over the disjoint,
  nonempty index sets `{i : S_i = y}`. So they are `R_n` i.i.d. uniform bits.

Hence `H(X_n | S_0, ..., S_n) = (log 2) E R_n`, since `S_n` is a function of
the path. Let `γ` be the escape probability of simple random walk on `Z^3`,
which is positive by Lemma A. By Lemma B,

```text
H(μ_0^n)  =  H(X_n)  >=  H(X_n | S_0, ..., S_n)  =  (log 2) E R_n  >=  (log 2) γ (n+1).
```

**Drift.** Use the generating set `{δ, ±e_1, ±e_2, ±e_3}`. Only the letter
`δ` changes a lamp, and it changes one. So `|(f, z)| >= |supp f|`. Given the
path, `|supp f_n|` is a sum of `R_n` independent fair bits. Hence
`E|X_n| >= E R_n / 2 >= γ(n+1)/2`. ∎

## Item 3. No admissible walk on W is Liouville

Let `μ` be admissible on `W`, and let `X_n = (f_n, S_n)` be its walk from the
identity.

**Step 1: the base walk.** `S_n = π(X_n)` is the walk of `π_* μ`. That measure
is symmetric and finitely supported, and its support generates `Z^3` because
`π` is onto. So Lemma A applies to it.

**Step 2: the lamps stabilize.** Write each `x ∈ supp μ` as `(g_x, z_x)`, and
let `M` bound the norms of all points of all the `supp g_x`. The update rule
is `f_n = f_(n-1) + τ_(S_(n-1)) g_(Y_n)`. So step `n` changes only lamps within
distance `M` of `S_(n-1)`.

By Lemma A, almost surely each ball `B(y, M)` is visited finitely often.
Since `Z^3` is countable, almost surely every lamp `f_n(y)` is eventually
constant. Let `Φ = lim_n f_n`, a random element of `(Z/2)^(Z^3)`.

**Step 3: the affine action on configurations.** `W` acts on all functions
`Z^3 -> Z/2` by `(g, z)·φ = g + τ_z φ`. This is an action:

```text
(g, z)·((g', z')·φ) = g + τ_z g' + τ_(z+z') φ = ((g,z)(g',z'))·φ .
```

For the walk `u X_n` started at `u ∈ W`, the lamps converge to `u·Φ`.

**Step 4: harmonic functions from lamp events.** Fix `y ∈ Z^3`, and let
`h_y(u) = P(u·Φ(y) = 1)`. Here `Φ` is the limit of the walk from the
identity, so `u·Φ` is the limit of the walk from `u`.

Write `Φ'` for the limit of the shifted walk `(Y_2 ... Y_n)_n`. It is
independent of `Y_1` and has the law of `Φ`. Then `Φ = Y_1·Φ'`, because
dropping the first term does not change a limit. Hence

```text
h_y(u) = Σ_x μ(x) P((u x)·Φ'(y) = 1) = Σ_x μ(x) h_y(u x),
```

so `h_y` is bounded and `μ`-harmonic. The same argument at time `n` gives
`P(Φ(y) = 1 | Y_1, ..., Y_n) = h_y(X_n)`.

**Step 5: Liouville would make `Φ` deterministic.** Suppose `μ` were
Liouville. Then each `h_y` is a constant `c_y`. By Lévy's upward theorem,
`h_y(X_n) -> 1_{Φ(y) = 1}` almost surely. So `1_{Φ(y)=1} = c_y` almost surely,
which forces `c_y ∈ {0, 1}`. Taking all `y` at once, `Φ = φ*` almost surely for
one fixed configuration `φ*`.

**Step 6: the contradiction.**
- By Step 4, `φ* = Φ = Y_1·Φ' = Y_1·φ*` almost surely. So `x·φ* = φ*` for every
  `x ∈ supp μ`, because each such `x` has positive probability.
- The stabilizer of `φ*` is a subgroup containing `supp μ`, hence it is all of
  `W`.
- But `δ·φ* = δ_0 + φ*` differs from `φ*` at the origin.

So `μ` is not Liouville. Steps 5 and 6 used only the constancy of the
functions `h_y`, so some `h_y` is a non-constant bounded harmonic function. ∎

## Item 4. The linear ceiling

`X_n` is a function of `(Y_1, ..., Y_n)`. So
`H(μ^n) <= H(Y_1, ..., Y_n) = n H(μ) <= n log |supp μ|`.
The triangle inequality gives `|X_n| <= Σ_i |Y_i| <= n max_(supp μ) |x|`. ∎

## Item 5. The class kill

Fix `U` and a tested family `𝓗` containing `W`.

**Case `n ≼ U`.** Let `n <= C U(Cn)` for all `n`. Let `H` be any finitely
generated group, `μ` admissible on `H`, `s = |supp μ|`, and
`m = max_(supp μ) |x|`. By item 4:
- `H(μ^n) <= (log s) n <= C max(1, log s) U(Cn)`;
- `L_μ(n) <= m n <= C max(1, m) U(Cn)`.

So every group lies in `Ent_U` and in `Drift_U`, and (S2) fails for both.

**Case `n ⋠ U`.** Suppose `S_W ∈ Ent_U`. Then `W ∈ Ent_U` by subgroup closure.
Since `W ∈ 𝓗` and `μ_0` is admissible on `W`, item 2 gives, for some `C >= 1`,

```text
(log 2) γ n  <=  H(μ_0^n)  <=  C U(Cn),
```

so `n <= C'' U(C'' n)` with `C'' = max(C, C / ((log 2) γ))`. This says
`n ≼ U`, a contradiction. So `S_W ∉ Ent_U`, and (S1) fails. The same argument
with `γ n / 2 <= L_(μ_0)(n)` shows `S_W ∉ Drift_U`.

Drift is defined for one fixed generating set of `W`. Any other finite
generating set changes `L_μ` by a bounded factor and changes `C''` only.

**Liouville classes.** By item 3, no admissible measure on `W` is Liouville.
So `W ∉ Liou_∃ ⊇ Liou_∀`, and hence `S_W` is in neither, by subgroup
closure. (S1) fails for both. ∎

Note that `U` needs no regularity, since the case split `n ≼ U` versus
`n ⋠ U` is exhaustive.

## Item 6. Transfer from Følner functions to return probabilities

Let `H` be amenable, generated by a finite symmetric set `X`, and let `μ` be
admissible with every `x ∈ supp μ` of `X`-length at most `L`. Let `r >= 2L`.
Let `Ω` be a Følner set of size `F_H(r)`, that is, `|Ω \ xΩ| <= |Ω|/r` for
every `x ∈ X`. Put `Ω' = Ω^-1`.

**The Markov operator.** Let `(Pf)(u) = Σ_x μ(x) f(ux)`. It is self-adjoint
on `ℓ^2(H)`, because `μ` is symmetric (substitute `u' = ux`), and
`||P|| <= 1`.

**Lower bound.**

```text
<P 1_Ω', 1_Ω'> = Σ_x μ(x) |Ω' ∩ Ω' x^-1| = Σ_x μ(x) |Ω ∩ xΩ| .
```

For `x = x_1 ... x_l` with `l <= L` and `x_j ∈ X`, the triangle inequality for
set differences gives

```text
|Ω \ xΩ| <= Σ_j |x_1...x_(j-1)Ω \ x_1...x_jΩ| = Σ_j |Ω \ x_jΩ| <= L|Ω|/r .
```

So `<P 1_Ω', 1_Ω'> >= (1 - L/r)|Ω|`.

Let `m` be the spectral measure of the unit vector `1_Ω' / |Ω|^(1/2)` for `P`.
It is a probability measure on `[-1, 1]` with `∫ λ dm >= 1 - L/r >= 1/2`. By
Jensen for the convex function `λ^(2n)`,

```text
<P^(2n) 1_Ω', 1_Ω'>  =  |Ω| ∫ λ^(2n) dm  >=  |Ω| (1 - L/r)^(2n) .
```

**Upper bound.**

```text
<P^(2n) 1_Ω', 1_Ω'>  =  Σ_(u,v ∈ Ω') μ^(2n)(u^-1 v)  <=  |Ω|^2 max_y μ^(2n)(y)  =  |Ω|^2 μ^(2n)(e) .
```

The last equality holds because, by Cauchy--Schwarz and symmetry,

```text
μ^(2n)(y) = Σ_z μ^n(z) μ^n(z^-1 y) <= Σ_z μ^n(z)^2 = μ^(2n)(e) .
```

**Combining.** `μ^(2n)(e) >= (1 - L/r)^(2n) / F_H(r)`. Since
`-log(1-t) <= 2t` for `t ∈ [0, 1/2]`,

```text
-log p_(2n)(μ)  <=  log F_H(r) + 4 L n / r .
```

Given `ε > 0`, choose `r` with `4L/r < ε`. Then
`limsup_n -log p_(2n)(μ) / n <= ε`, so `-log p_(2n)(μ) = o(n)`. ∎

## Item 7. The ceiling for return probabilities is not reached

- **The ceiling is linear.** `p_(2n)(μ) = μ^(2n)(e) >= (μ^2(e))^n`, and
  `μ^2(e) = Σ_x μ(x) μ(x^-1) = Σ_x μ(x)^2 > 0`. So
  `-log p_(2n) <= n log(1 / Σ_x μ(x)^2)`.
- **No amenable group reaches it.** By item 6, `-log p_(2n)(μ) = o(n)` on every
  amenable `H`.

So for `Ret_φ` on amenable tested subgroups, item 5 breaks in its second case.
- If `n ≼ φ`, then `Ret_φ` is everything and (S2) fails, exactly as before.
- If `n ⋠ φ`, item 5 would need an amenable group in `B_A` whose `-log p_(2n)`
  has linear order, and there is none.

Killing `Ret_φ` at (S1) needs an amenable group in `B_A` whose return exponent
beats `φ`. That is a Følner-type question about the sublinear band, and it is
not settled here. ∎

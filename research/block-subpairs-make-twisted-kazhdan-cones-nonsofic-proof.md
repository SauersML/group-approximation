Notation is as in [[block-subpairs-make-twisted-kazhdan-cones-nonsofic]].  Elements of
`G = EL_r(R) x| SL_d(Z)` are written `g sigma` with `g ∈ EL_r(R)` and `sigma ∈ SL_d(Z)`.  Here `SL_d(Z)` acts
on `R` by monomial substitution `x^m ↦ x^(sigma m)`, and on matrices entrywise.

Facts used:
- (F1) Normal form in amalgams (Serre, *Trees*, I.1.2).  Let `A *_C B` be an amalgam.  A product
  `u_1 u_2 ... u_n` with `n ≥ 1`, whose factors alternate between `A \ C` and `B \ C`, is not `1`.
- (F2) Suslin (1977): for a field `k` and `n ≥ 3`, `SL_n(k[x_1..x_d]) = EL_n(k[x_1..x_d])`.
- (F3) Kun-Thom Theorem E, as recorded in [[kun-thom-nonsofic-wreath]], for every prime power `q` and all
  `r, d ≥ 3`.
- (F4) Kun-Thom Theorem A (v3), as recorded in [[kt-pair-group-double-is-nonsofic]]: for a Kun-Thom pair,
  `G *_Gamma G` is nonsofic.
- (F5) Subgroups of sofic groups are sofic.

## (B1) Block subpairs

Fix `S ⊆ {1..r}` with `|S| = 3`, and let `iota_S : M_3(R) -> M_r(R)` place a matrix on the rows and columns in
`S` and put the identity elsewhere.  It is an injective homomorphism `GL_3(R) -> GL_r(R)`.  It maps
elementary matrices to elementary matrices, and it commutes with the entrywise action of `SL_d(Z)`.  Hence

```text
G_S = iota_S(EL_3(R)) x| SL_d(Z)
```

is a subgroup of `G`, and `iota_S x id` is an isomorphism from the Theorem E group `G'` with parameters
`(3, d)` onto `G_S`.  It carries `Gamma' = EL_3(R_+)` onto `Gamma_S = iota_S(EL_3(R_+))`.

*The intersection.*  Let `g sigma ∈ G_S ∩ Gamma`.  Since `Gamma ≤ EL_r(R)` and the semidirect decomposition
is unique, `sigma = 1`.  So `g = iota_S(h)` with `h ∈ EL_3(R)`, and `g ∈ Gamma ≤ M_r(R_+)`.  The entries of
`h` are entries of `g`, so `h ∈ SL_3(R_+)`, and `SL_3(R_+) = EL_3(R_+)` by (F2).  Hence
`G_S ∩ Gamma ⊆ Gamma_S`.  The reverse inclusion holds because `iota_S(EL_3(R_+))` is generated by
elementary matrices over `R_+`.  So `G_S ∩ Gamma = Gamma_S`.

By (F3), `(G_S, Gamma_S)` is a Kun-Thom pair.  Both groups are Kazhdan, and `Gamma_S` is infranormal and not
normal in `G_S`.  By (F4), `G_S *_(Gamma_S) G_S` is nonsofic.

## (B2) Subpair double embedding

Let `A = H x Gamma`, and identify `Gamma_psi ≤ A` with `Gamma ≤ G`, so that `X = X(H, psi) = A *_Gamma G`.
Let `B ≤ G`, put `C = B ∩ Gamma`, and let `h ∈ H \ 1` centralise `psi(C)`.  In `A`, write `h` for `(h, 1)`.

1. *`h` centralises `C` in `X`.*  For `c ∈ C`, the element of `A` representing `c` is `(psi(c), c)`.  Then
   `(h,1)(psi(c), c)(h,1)^-1 = (h psi(c) h^-1, c) = (psi(c), c)`.
2. *`h ∉ Gamma_psi`.*  If `(h, 1) = (psi(g), g)`, then `g = 1` and `h = 1`.
3. *The map.*  Let `B' = h B h^-1`.  By step 1, conjugation by `h` fixes `C` pointwise, so the two inclusions
   `B -> X` and `B -> X`, `b ↦ h b h^-1`, agree on `C`.  They define
   `Phi : B *_C B -> X`.
4. *Injectivity.*  Take a reduced word `w = b_1 b_2' b_3 b_4' ...` in `B *_C B`.  Its factors alternate between
   `B \ C` in the first copy and `B \ C` in the second copy, and it may start or end on either side.  Assume
   it has length at least `1`.  Its image is the product of the terms `b_k` (first copy) and `h b_k h^-1`
   (second copy).  Each `b_k ∈ B \ C` lies in `G \ Gamma`, because `B ∩ Gamma = C`.  Expand every
   second-copy term into the three factors `h, b_k, h^-1`, and merge adjacent `G`-factors.  The product then
   alternates between factors in `G \ Gamma` and factors `h^(±1) ∈ A \ Gamma_psi` (by step 2).  Two
   `G`-factors are adjacent only where a first-copy term meets a second-copy term.  Then the `h^(±1)` of the
   second-copy term separates them, so no merging is ever needed.  By (F1) the image is not `1`.

So `B *_C B ≅ Phi(B *_C B) ≤ X`.  With `B = G_S` and (B1), `X` contains a nonsofic group, so it is
nonsofic by (F5).

## (B3) Rank at least five

Let `r ≥ 5` and `H ≠ 1`.

- *`psi` trivial.*  Take `B = G`, so `C = Gamma`, and any `h ∈ H \ 1`.  Then (B2) embeds `G *_Gamma G`, which
  is nonsofic by (F4).
- *`psi` nontrivial.*  `Gamma = EL_r(R_+)` is generated by the `e_ij(a)` with `i ≠ j` and `a ∈ R_+`.  So
  some `u = e_ij(a)` has `h := psi(u) ≠ 1`.  Since `r - 2 ≥ 3`, choose `S ⊆ {1..r} \ {i, j}` with `|S| = 3`.
  The matrix `u` differs from the identity only in row `i` and column `j`.  Every element of `Gamma_S` is the
  identity outside the rows and columns in `S`.  Hence `u` commutes with `Gamma_S`: for `v = iota_S(y)`,
  both products `u v` and `v u` equal `I + (u - I) + (v - I)`, because `(u - I)(v - I) = 0` and
  `(v - I)(u - I) = 0` as `{i, j} ∩ S` is empty.  So `h = psi(u)` centralises `psi(Gamma_S)`, and (B2) with
  `B = G_S` applies.

## (B4) Rank four

Let `r = 4`, `S = {1,2,3}`, and let `a ∈ F_q^*` with `a^4 ≠ 1`, which exists iff `q - 1 ∤ 4`, that is
`q ∉ {2,3,5}`.  Put `D = diag(a, a, a, a^-3) ∈ SL_4(F_q) ≤ Gamma`.  It is `a` times the identity on the
coordinates in `S`, so it commutes with `Gamma_S`.

- If `psi(D) ≠ 1`, then (B2) applies with `h = psi(D)` and `B = G_S`.
- If `psi(D) = 1`, then for `t ∈ R_+`, `D e_14(t) D^-1 = e_14(a · a^3 · t) = e_14(a^4 t)`.  So
  `[D, e_14(t)] = e_14((a^4 - 1) t) ∈ ker psi`.  Since `a^4 - 1` is a unit, `e_14(R_+) ≤ ker psi`.  The
  monomial matrices of determinant `1` in `SL_4(F_q) ≤ Gamma` conjugate `e_14(t)` to every `e_ij(± t)`.  So
  `ker psi` contains every elementary matrix, hence equals `Gamma`, and `psi` is trivial.  Then the first case
  of (B3) applies verbatim, since it did not use `r ≥ 5`.

*The residue.*  Now let `q ∈ {2,3,5}`.  The centraliser of `iota_S(SL_3(R_+))` in `SL_4(R_+)` is
`{ diag(l, l, l, m) : l, m ∈ R_+^* = F_q^*, l^3 m = 1 }`.  Every `l` satisfies `l^4 = 1`, so `m = l`, and the
centraliser is the scalar centre.  The same holds for every `S`, by permutation symmetry.

## (B5) The finite twisted cone

Let `F = PSL_r(F_q)` and `psi = pi ∘ ev_0`, where `ev_0 : Gamma -> SL_r(F_q)` evaluates at the origin and `pi`
is the projection to `PSL`.

- *`r ≥ 5`.*  With `S = {1,2,3}`, the element `u = e_45(1)` commutes with `Gamma_S`.  Its image `psi(u) = pi(e_45(1))` is
  not central in `SL_r(F_q)`, so it is `≠ 1` in `F`.  (B2) applies.
- *`r = 4`, `q ∉ {2,3,5}`.*  `psi(D) = pi(D)`, and `D` is not scalar because `a ≠ a^-3`.  (B2) applies.
- *`r = 4`, `q ∈ {2,3,5}`.*  Let `x ∈ SL_4(F_q)` have image in `C_F(psi(Gamma_S))`.  Then
  `x y x^-1 y^-1` is scalar for every `y ∈ iota_S(SL_3(F_q)) = ev_0(Gamma_S)`.  The map `y ↦ x y x^-1 y^-1` is a
  homomorphism into the centre, because the centre is central.  `SL_3(F_q)` is perfect, so the map is trivial,
  and `x` commutes with `iota_S(SL_3(F_q))`.  By Schur's lemma on `F_q^3 ⊕ F_q` (absolutely irreducible plus
  trivial), `x = diag(l,l,l,m)`, and `l = m` as above.  So `C_F(psi(Gamma_S)) = 1`.
- *`r = 3`.*  The only block is `S = {1,2,3}`, with `Gamma_S = Gamma` and `psi(Gamma) = F`, which is
  centreless.

## Remark on the kernel of evaluation

`Gamma(0) = ker ev_0` has finite index in `Gamma`, so it is Kazhdan.  A nonnegative `A ∈ SL_d(Z)` sends each
nonconstant monomial to a nonconstant monomial, so `ev_0 ∘ A = ev_0` on `R_+`.  Hence `A` compresses
`Gamma(0)`, and so does `Gamma`, which normalises it.  These compressors generate `G`, so `Gamma(0)` is
infranormal in `G`.  It is not normal, because `SL_d(Z)` moves `e_12(x_1)` outside `Gamma`.  But the
subgroup generated by `Gamma(0)` and `SL_d(Z)` is all of `G`.  It contains `e_13(x_1)`, and `e_32(x_1^-1)`
(the image of `e_32(x_1)` under an `A` with `A e_1 = -e_1`).  Their commutator is `e_12(1)`, and
`ev_0(e_12(1)) ≠ 1`.  So (B2) with `C = Gamma(0)` needs a subgroup `B` that avoids all but a few of the
compressors, as stated in the claim's last section.

Standard permanence used: soficity passes to subgroups, to finite-index
overgroups, and to quotients by finite normal subgroups (for the last, a
finite group is stable in permutations, so the almost-action of the finite
normal subgroup `F` on the model sets can be corrected to a genuine action,
and the induced almost-action of `S/F` on the orbit sets is a sofic
approximation: a point whose `F`-orbit is fixed by `g notin F` is a fixed
point of some `f^(-1) g != e`, a union of `|F|` sets of vanishing density).

**(1)**  If `F <= Z` is finite then `S/F` is sofic, and `S/F -> Q` is again
a central extension of `Q`; so all statements may be made for `Z` torsion
free, and a cover with finite `Z` is impossible (it would make `Q = S/Z`
sofic).

**(2)**  Let `Z = Z` (one coordinate at a time for `Z = Z^k`; if the class
is torsion in a coordinate, project to that coordinate) and suppose
`n c = 0`.  The push-out of the extension along multiplication by `n`,
`S' = (S x Z)/<(z, -n)>` where `z` generates `Z`, is a central extension of
`Q` by `Z` with class `n c = 0`, hence `S' ~= Z x Q`.  The map
`S -> S'`, `s |-> [(s, 0)]`, is injective (its kernel is `Z cap <(z,-n)>`,
trivial in `S`), and its image has index `n`: `S'` is generated by the
image and the class of `(1, 1)`, whose `n`-th power `[(1, n)] = [(z, 0)]` lies
in the image.  So `S` is a finite-index subgroup of `Z x Q`; if `S` were
sofic, then `Z x Q` (finite-index overgroup) and `Q` (subgroup) would be
sofic.

**(3)**  For a finite-index `Q_0 <= Q`, the preimage `S_0 <= S` is sofic (a
subgroup) and is a central extension of `Q_0` with the restricted class;
by (2) that class is non-torsion, else `Q_0`, hence its finite-index
overgroup `Q`, would be sofic.  A non-torsion class in `H^2(Q_0; Z)` maps
to a nonzero class in `H^2(Q_0; Q)` (torsion is exactly the kernel of
rationalization for finitely generated coefficients in each degree, and a
class with `n c = 0` is torsion), so `H^2(Q_0; Q) != 0`.

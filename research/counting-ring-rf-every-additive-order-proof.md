Notation: `R = R_count = Z<u,x,e | xu-ux-x, ue, eu>`, `r_n = e x^n e`. All rings
are unital and associative.

## Step 1. The subring U

Let `U = Z<u,x | xu - ux - x>`. It is the Ore extension `Z[u][x; sigma]` with
`sigma(u) = u+1`, since the only relation is `x f(u) = f(u+1) x`. So `U` is a free
abelian group with basis `u^i x^j` (`i, j >= 0`). By induction,
`x^j u = (u+j) x^j`.

Quotients used below, with `uU` the right ideal and `Uu` the left ideal:

- **`L = U/Uu`.** `Uu` is spanned by `u^i x^j u = u^{i+1} x^j + j u^i x^j`, so
  `u^{i+1} x^j = -j u^i x^j` in `L`. Hence `L` is free with basis the classes of
  `x^a`, `a >= 0`.
- **`Rt = U/uU`.** `uU` is spanned by `u^{i+1} x^j`, so `Rt` is free with basis
  the classes of `x^b`, `b >= 0`.
- **`M = U/(uU + Uu)`.** Here `uU + Uu` is spanned by `u^{i+1} x^j` and
  `j x^j`. So
  `M = (+)_{j >= 0} (Z/j) x^j`, with the convention `Z/0 = Z` (and `Z/1 = 0`).

## Step 2. Normal form of R

`R` is generated by `U` and one symbol `e`, subject only to `ue = 0 = eu`. By
the universal property of tensor rings, `R = T_U(B)`, where `B` is the
`U`-bimodule freely generated by `e` modulo `ue` and `eu`:

```text
B = (U (x)_Z U) / (Uu (x) U + U (x) uU) = L (x)_Z Rt,     a e b <-> a (x) b.
```

A ring map out of `T_U(B)` is a ring map `f` on `U` together with an element
`s = f(e)` satisfying `f(u) s = 0 = s f(u)`. That is exactly a ring map out of
`R`.

A tensor ring is graded, `T_U(B) = (+)_{k >= 0} B^{(x)_U k}`. Using
`Rt (x)_U L = U/(uU + Uu) = M`, one gets

```text
R_0 = U,    R_k = L (x)_Z M^{(x)(k-1)} (x)_Z Rt   (k >= 1).
```

Expanding `L`, `Rt` and `M` in the bases of Step 1, `R_k` is the direct sum,
over tuples `tau = (c_k; c_{k-1}, ..., c_1; c_0)` of nonnegative integers, of
cyclic groups

```text
Z/g(tau) . [x^{c_k} e x^{c_{k-1}} e ... e x^{c_1} e x^{c_0}],
g(tau) = gcd(c_1, ..., c_{k-1})   (gcd of the empty list = 0, so Z/0 = Z).
```

**Proof of (C1).** `r_n = e x^n e` is the basis tensor `(0; n; 0)` in `R_2`, so
its additive order is `g = n`. Directly,
`n r_n = e (u+n) x^n e - e u x^n e = e x^n u e - e u x^n e = 0`. `∎`

## Step 3. Block shift representations

Fix integers `N >= 1`, `n >= 1` with `N | n`, a depth `k >= 0`, and residues
`P_0, ..., P_{k-1}`, `Q_0, ..., Q_{k-1}` in `Z/n`, each `= 0 mod N`. Let

```text
V = (+)_{t=0..k} V_t,     V_t = free Z/N-module on v^t_i, i in Z/n.
```

Define `Z/N`-linear maps of `V`:

- `u v^t_i = (i mod N) v^t_i`, which is well defined because `N | n`;
- `x v^t_i = v^t_{i-1}`;
- `e v^t_i = v^{t+1}_{Q_t}` if `t < k` and `i = P_t`, and `e v^t_i = 0` otherwise.

**The relations hold.**
- `(xu - ux) v^t_i = (i - (i-1)) v^t_{i-1} = x v^t_i`.
- `ue = 0`, because `e` lands on the vectors `v^{t+1}_{Q_t}`, and `u` scales
  them by `Q_t = 0 mod N`.
- `eu = 0`, because `e` reads only the coordinates `v^t_{P_t}`, and `u` scales
  those by `P_t = 0 mod N`.

So `rho = rho_{N,n,P,Q} : R -> End_{Z/N}(V)` is a ring homomorphism into a
finite ring.

**Proof of (C2).** Take `N = n`, `k = 0`, and replace `e` by the self-loop
`e v_i = delta_{i,0} v_0` on the single block. The three relations hold by the
same computation. Since `x^n = 1` on `(Z/n)^{Z/n}`, `rho_n(r_n) = E_00`, whose
additive order is `n`. `∎`

**Evaluating a basis tensor.** Let `tau = (c_k; ...; c_0)` be a basis tensor of
degree `k`, and use the depth-`k` representation. Along the chain
`v^0_{i} -> ... -> v^k_{o}`, the word `x^{c_k} e ... e x^{c_0}` sends `v^0_i` to
`v^k_o` exactly when the index congruences below hold mod `n`, and it gives 0
otherwise:

```text
i - c_0 = P_0,   Q_{t-1} - c_t = P_t   (1 <= t <= k-1),   Q_{k-1} - c_k = o.
```

When they hold, every middle `c_t` is `= 0 mod N`, because `P_t` and `Q_{t-1}`
are. So `N | g(tau)`, and the coefficient of `tau` in `Z/g(tau)` has a
well-defined reduction mod `N`.

The `(v^k_o, v^0_i)` matrix entry of `rho(w_k)`, for `w_k` in `R_k`, is therefore
the sum of the reduced coefficients of the basis tensors satisfying these
congruences. Two facts isolate degrees:

- `e` raises the block index by exactly one;
- `U` preserves each block.

So only the degree-`k` component of an element reaches the block-0 to block-`k`
entries.

## Step 4. Separation (proof of C3)

Let `w` be nonzero in `R`, and pick `k` with `w_k != 0`.

**Case k = 0.** Write `w_0 = sum_j f_j(u) x^j` with `f_j` in `Z[u]`, and pick
`j` with `f_j != 0`. Take depth 0, so `e` acts as 0. There,
`u^i x^j v^0_s = ((s-j) mod N)^i v^0_{s-j}`. A nonzero integer polynomial has a
nonzero value `f_j(s_0)` at some integer `s_0 >= 0`.

Choose `N > |f_j(s_0)|` and `n = N T` with `T > s_0 + max{j' : f_{j'} != 0} + 1`.
The `(v^0_{s_0}, v^0_{s_0+j})` entry of `rho(w)` is
`sum_{j' = j mod n} f_{j'}(s_0) mod N = f_j(s_0) mod N`, which is nonzero.

**Case k >= 1.** Pick a basis tensor
`tau* = (c*_k; c*_{k-1}, ..., c*_1; c*_0)` whose coefficient `a` in
`Z/g*` is nonzero, where `g* = g(tau*)`. Then `g* != 1`.

- If `g* >= 2`, set `N = g*`. Then `a mod N != 0`, and every `c*_t` with
  `1 <= t <= k-1` is `0 mod N`.
- If `g* = 0`, all middle `c*_t` are 0. Choose `N` larger than `|a|` for an
  integer representative `a`.

Let `C` bound every index `c_t` occurring in the finite support of `w_k`, and
set `n = N T` with `T > C + 1`. Take the depth-`k` representation with
`P_t = 0` for all `t`, `Q_{t-1} = c*_t` for `1 <= t <= k-1`, and `Q_{k-1} = 0`.
All of these are `0 mod N`. Read the entry `(v^k_o, v^0_i)` with `i = c*_0` and
`o = -c*_k mod n`.

By Step 3, a basis tensor `tau` of the support contributes to this entry only
if `c_0 = c*_0`, `c_t = c*_t` for the middle indices, and `c_k = c*_k`, all mod
`n`. All indices lie in `[0, n)`, so this forces `tau = tau*`. Hence the entry
equals `a mod N`, which is nonzero.

In both cases `rho(w) != 0` in a finite ring. `∎`

**Machine check.** `experiments/counting-ring-steinberg-2026-09-17/check_counting_ring.py`
verifies the following over `Z/N` with explicit matrices:
- the relations of Step 3;
- (C2) for `n = 2..13`;
- the isolation of Step 4 on random tensors of degree `1..3`, with middle
  indices in `{0, 2, 3, 4, 6}` and indices below 7.

It illustrates the proof and is not needed for it.

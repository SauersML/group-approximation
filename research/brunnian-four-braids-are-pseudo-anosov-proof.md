Full write-up: artifact §2.3–2.4.

**Part 1.**

- *Normal.* Conjugation permutes the strand-deletion maps up to conjugation, so their common
  kernel on `P_4` is normal.
- *Free.* Deleting `p_4` kills a Brunnian braid, so `Brun_4 ⊂ ker(P_4 → P_3) = K_4`, the image of
  the injective push map on the free group `π_1(D_3,p_4)` (Birman exact sequence). For
  `i ≤ 3`, deleting `p_i` sends `push(γ)` to the push along `π_i(γ)`, and that push map is also
  injective. Hence `Brun_4 = push(∩_i ker π_i)`, which is free.
- *Nontrivial.* `[[y_1,y_2],y_3]` is a nontrivial reduced word in `F_3`.
- *Meets the center trivially.* `Δ^{2k}` deletes to `Δ_3^{2k} ≠ 1`.

**Part 2.** Let `1 ≠ Φ ∈ Brun_4`, and use the Nielsen–Thurston trichotomy on `S_{0,5}`.

- **Periodic.** Some `Φ^k` is central, hence Brunnian and central, hence trivial. `B_4` is
  torsion-free, so `Φ = 1`, a contradiction.
- **Reducible.** Some power `Φ^k ≠ 1`, still Brunnian, fixes an essential curve `c`. Viewed in
  `D_4`, `c` encloses three or two punctures.
  - *Three punctures, say `p_1,p_2,p_3`.* The mapping class group of the outer piece (tube, `p_4`)
    rel both boundaries is generated by `T_c` and `T_∂ = Δ_4²`. So `Φ^k = Δ_4^{2a} η` with
    `η ∈ B_3 = ⟨σ_1,σ_2⟩` inside `c`.
    - Deleting `p_4` gives `Δ_3^{2a} η = 1`, so `Φ^k = (Δ_4² Δ_3^{-2})^a`, which is `p_4`
      circling the tube `a` times.
    - Deleting `p_1` gives `Δ_3^{2a} σ_1^{-2a} = (σ_2σ_1²σ_2)^a` on `(p_2,p_3,p_4)`. Its exponent
      sum is `4a`, so `a = 0` and `Φ^k = 1`, a contradiction.
  - *Two punctures, say `p_1,p_2`.* `Φ^k = ψ · σ_1^j`, where `ψ` lies in the mapping class group of
    the disk with holes (tube, `p_3`, `p_4`) rel boundaries.
    - Deleting `p_1` collapses the tube to a puncture. The kernel of that collapse is `⟨T_c⟩`,
      and `T_c = σ_1²`. So `ψ ∈ ⟨σ_1²⟩` and `Φ^k = σ_1^{j'}`.
    - Deleting `p_3` gives `σ_1^{j'} ∈ B_3`, so `j' = 0`, a contradiction.

Hence `Φ` is pseudo-Anosov. ∎

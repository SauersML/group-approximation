Let `G = L_(F_3)(1,2)^x`, `z = −1`, `w = s0 t1 + s1 t0`, `d = s0 t0 − s1 t1`, `eps_- = 2(1 − [z])`
and `e_- = eps_- · 2(1 + [w])`. Let `Γ <= G` contain `z`, `w` and `d`, and put `S_Γ = eps_- F_3[Γ]`.

Suppose some group homomorphism `σ : Γ -> M^x` has `σ(z) != 1`, where `M` is an `F_3`-algebra with
a Sylvester rank function that is positive on nonzero idempotents. Examples of `M` are `M_n(k)` and a
rank ultraproduct over a field `k` of characteristic three. Then `(K_0(S_Γ), [eps_-])` has a state,
and no `b, c` in `S_Γ` satisfy `c e_- b = eps_-`.

Consequences:
- **Support filter.** If `c e_- b = eps_-` holds in `S_-`, then the subgroup
  `<z, w, d, supp b, supp c>` sends `z` to `1` under every such homomorphism. So every
  finite-dimensional representation in characteristic three kills `z`, and so does every finite
  quotient. That subgroup is not residually finite, and `z` lies in its finite residual. This
  complements `ternary-corner-witnesses-need-non-linear-sofic-support`, which concerns
  `<z, w, supp b, supp c>` without `d`. Neither filter implies the other (artifact Corollary 3.2; an
  earlier version said "implies", which was wrong).
- **Global form.** If `G` has a rank model in characteristic three moving `z`, then
  `ternary-anti-invariant-swap-corner-is-full` is false. Such a model is injective, since `G` is perfect
  and `G/<z>` is simple.

Proof: Sections 1–2 of the artifact, route `anti-central-rank-models-kill-ternary-corner-witnesses-proof`.

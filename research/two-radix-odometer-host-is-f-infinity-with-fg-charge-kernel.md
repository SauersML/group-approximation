## Setting

Let `h_0, h_1 >= 2` be coprime and `S` the primes dividing `h_0 h_1`. Put
`Zh = lim Z/(h_0 h_1)^k` and `X = {0,1} x Zh`. A **cone** is a set
`{eps} x (lam + M Zh)` with `M = h_0^i h_1^j` and `0 <= lam < M`. Let `H` be the group of
homeomorphisms of `X` that are, on each piece of some finite partition of `X` into cones,
of the form

    (eps, lam + M t)  |->  (eps', mu + M'(t + g)),        g in Z        (a leaf).

Let `W <= H` be the subgroup of elements with a table in which every carry `g` is `0`.

## Statement

1. `H` and `W` are of type `F_infinity`.
2. The near index `chi : H -> Z` (defined through the dense set of integer points
   `{0,1} x Z_(>=0)`, on which `H` acts by near permutations) is onto, and equals the total
   carry `sum g` of any table. Its kernel is generated by `W` and the single element
   `z = a_(c_1) a_(c_2)^-1`, where `a_c` adds the modulus `M` on the cone `c` and is the
   identity elsewhere, and `c_1, c_2` are any two disjoint cones whose union is not `X`.
   So `ker chi` is finitely generated.
3. Hence `H` is finitely presented and `[chi]`, `[-chi]` lie in `Sigma^1(H)`.

## Proof

*(1)* Let `Lam` be the one-vertex 2-graph whose paths of degree `(i,j)` are the residues
`r mod h_0^i h_1^j`, composed by `(n,r)(n',r') = (n+n', r + M_n r')` (least residues). Unique
factorization is division with remainder, so `Lam` is a finite 2-graph with `h_0` edges of
degree `e_1` and `h_1` of degree `e_2`. Its infinite path space is `Zh`. Let `Lam_2` be two
disjoint copies (vertices `v_0, v_1`). The groupoid `G = R_2 x Z` (pair groupoid on
`{0,1}` times `Z`) acts self-similarly on `Lam_2`: `((eps'<-eps), g)` sends the residue
`r` at `v_eps` to `(g + r) mod M` at `v_eps'`, with cocycle `((eps'<-eps), floor((g+r)/M))`.
This is integer addition, so the axioms of Li §`ss:ZS` hold, and it preserves degree.

Li's Example `ex:ZS` (III) applies with `P = Z_(>=0)^2`:
- `Lam_2` is a finite 2-graph with `#v d^-1(e_j) v in {h_0, h_1}`, both `>= 2`;
- `D = Lam_2 bowtie G` is right cancellative, since `g.r = g'.r` with equal carries
  forces `g = g'` (pseudo-freeness), and degrees and unique factorization handle the path
  part; so condition (F) holds (Li, line 1456);
- `D*(w,w) = St(G, v) = Z` (Remark `rem:ZS-Stab`), which is `F_infinity`;
- `Y = X(v_0; empty) u X(v_1; empty)` is the whole infinite path space.

So `F((I_l(D) x| Omega_inf)_Y^Y)` is `F_infinity`. Its elements act by "remove a prefix, apply
`g`, add a prefix", which is exactly a leaf. The groupoid is effective: a basic bisection
acting trivially on an open set has equal moduli, hence equal degrees (by coprimality),
equal residues and `g = 0`. So this full group is `H`. The same argument with `G = R_2`
(trivial isotropy) gives `W`.

*(2)* Integer points of a cone `lam + M Zh` are `lam + M t`, `t >= 0`, and a leaf misses
exactly `g` of the target's integer points when `g >= 0`, and needs `|g|` extra ones when
`g < 0`. So the near index of an element is `sum g`, and `chi` is a homomorphism. Every
element is `w o prod a_(c_i)^(g_i)` for a cone partition `(c_i)` and `w in W`. Splitting a
leaf into its `h_0` children keeps the total carry (Hermite:
`sum_d floor((g+d)/h_0) = g`), so one may assume at least three cones. If `sum g_i = 0`, then
`prod a_(c_i)^(g_i) = prod_(i>=2) (a_(c_i) a_(c_1)^-1)^(g_i)`, a product of pairs of disjoint
cones with nonempty complement. For such a pair `(c, c')` there is `w in W` mapping
`c_1 -> c` and `c_2 -> c'` by leaves: every clopen set is a finite disjoint union of cones, and
its number of cones mod `gcd(h_0-1, h_1-1)` is well defined (refining a cone to level
`(h_0h_1)^L` gives `h_0^a h_1^b ≡ 1` pieces). Both complements are nonempty with count
`≡ 2 - 2`, and splitting cones adds `h_0 - 1` or `h_1 - 1`, so both complements can be refined
to the same number of cones and matched leaf by leaf. Rigid conjugation gives
`w a_c w^-1 = a_(w c)`, hence `w z w^-1 = a_c a_(c')^-1`. So `ker chi = <W, z>`.

*(3)* `F_infinity` implies finitely presented, and for a finitely presented group with a
character onto `Z`, finite generation of the kernel is `[±chi] in Sigma^1` (Bieri--Neumann--Strebel).

## Consequence for the unequal-radix candidate

For the least-significant-first mixed-radix enumeration `nu` of `A_0 * A_1` with
`|A_i| = h_i + 1` (`unequal-radix-free-product-near-group-passes-both-germ-gates`), every
`lambda_x` lies in `W` and the shift is `s(0,y) = (1,y)`, `s(1,y) = (0,y+1)`. So `R_nu <= H`,
and the near index of `R_nu` is `chi` restricted to it. By
`finite-index-in-a-kernel-fg-near-host-passes-both-germ-gates`, that candidate now reduces to
the single generation question `[H : R_nu] < infinity`.

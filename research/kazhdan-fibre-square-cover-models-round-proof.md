Notation is as in the claim. `||·||_2` is the normalized Hilbert--Schmidt norm on `M_d(C)`,
`<ξ,η> = Tr(η*ξ)/d`.

## 1. The two-sided representation of the fibre square

- **Definition.** For `(a,b) ∈ P` and `ξ ∈ M_d(C)` put `σ(a,b)ξ = ρ(a) ξ ρ(b)*`. This is a
  unitary representation of `P` (it is the restriction to `P` of `ρ ⊗ ρ̄` of `G~ x G~`).
- **Generators of `P`.** Let `(a,b) ∈ P`. Then `a = n b` with `n = ab^{-1} ∈ N`, so
  `(a,b) = (n,1)·Δ(b)`. `N x 1` is normalized by `Δ(G~)`, because
  `Δ(g)(n,1)Δ(g)^{-1} = (gng^{-1},1)`. `N` is the normal closure of `M`, so `N x 1` lies in the
  subgroup generated by `Δ(G~)` and `M x 1`. Hence `Δ(S) ∪ (M x 1)` generates `P`.
- **Displacement of the identity.** `σ(Δ(g))1 = ρ(g)ρ(g)* = 1` exactly. For `m ∈ M`,
  `σ(m,1)1 - 1 = ρ(m) - 1`, of norm `||ρ(m) - 1||_2`. For a word of length `ℓ` in these
  letters the displacement is at most the sum of the letters' displacements, since `σ` is
  isometric. So

  ```text
  δ := max_{x ∈ K_P} ||σ(x)1 - 1||  <=  L · max_{m ∈ M} ||ρ(m) - 1||_2.
  ```

## 2. Invariant vectors live on the kernel's fixed space

- Let `η` be the orthogonal projection of `1` onto the `σ(P)`-invariant vectors. The complement
  of the invariant vectors is a subrepresentation without invariant vectors, so it has no
  `(K_P, κ_P)`-invariant unit vector. The vector `1 - η` lies there and
  `σ(x)(1 - η) - (1 - η) = σ(x)1 - 1`, so `κ_P ||1 - η|| <= δ`.
- For `n ∈ N`, `(n,1) ∈ P` and invariance gives `ρ(n)η = η`. So every column of `η` lies in
  `Fix_N(ρ)`, that is `Eη = η`.
- Left multiplication by `1 - E` is a contraction, hence

  ```text
  1 - tr_d E = ||(1 - E)·1||^2 = ||(1 - E)(1 - η)||^2 <= ||1 - η||^2 <= δ^2/κ_P^2,
  ```

  which is (FS1).
- **Strict rounding.** With (FS1) in hand, `kazhdan-cover-models-round-iff-kernel-fixed-mass-one`,
  §2 ("(c) implies (b)"), rounds `ρ_k∘s` to `π'_k ⊕ 1` with error `<= 2(1 - tr E_k)^{1/2}`. That
  step uses only that `Fix_N(ρ_k)` is `G~`-invariant, not property (T) of `G~`.

## 3. Theorem B: the fibre ring

- **`D` is a finitely generated unital ring.** `D` is a subring of `R x R` containing
  `(1,1)`. Let `y_1, ..., y_s` generate `R`. For `(u,v) ∈ D` write
  `(u,v) = (v,v) + (u - v, 0)`. The first term lies in the subring generated by the
  `(y_j, y_j)`. Since `u - v ∈ I = Σ_l R x_l R`, the second is a sum of terms
  `(r x_l r', 0) = (r,r)(x_l,0)(r',r')`. So `D` is generated by the `(y_j,y_j)` and the
  `(x_l, 0)`.
- **The map.** The two coordinate projections `p_1, p_2 : D -> R` are unital ring maps, so
  `(EL_n(p_1), EL_n(p_2)) : EL_n(D) -> EL_n(R) x EL_n(R)` is a homomorphism. Its image is
  generated by the pairs `(e_ij(u), e_ij(v))` with `u - v ∈ I`.
- **The image is the fibre square.** Write `N = E_n(R,I)` and `P_B = Δ(EL_n(R))·(N x 1)`.
  By §1 (with this `N`) `P_B` is a subgroup, and it is the fibre square over
  `EL_n(R)/E_n(R,I)`.
  - Each generator of the image satisfies
    `(e_ij(u), e_ij(v)) = (e_ij(u - v), 1)·Δ(e_ij(v))`, with `e_ij(u - v) ∈ N`. So the image
    lies in `P_B`.
  - Conversely the image contains `Δ(e_ij(v)) = image of e_ij((v,v))`, and
    `(e_ij(a), 1) = image of e_ij((a,0))` for `a ∈ I`. It is a subgroup containing `Δ(EL_n(R))`,
    so it contains every `Δ(g)(e_ij(a),1)Δ(g)^{-1} = (g e_ij(a) g^{-1}, 1)`, hence `N x 1`, hence
    `P_B`.
- **Property (T).** By `elementary-groups-over-fg-rings-have-property-t` (Ershov--Jaikin-Zapirain,
  quoted there: "Let $R$ be a finitely generated (associative) ring with $1$ and $n\geq 3$ ...
  Then $G$ has Kazhdan's property $(T)$"), applied to `D`, `EL_n(D)` has (T). Property (T)
  passes to quotients, so `P_B` has (T).
- **Finite normal generation.** By `relative-elementary-fng-iff-level-ideal-fg` (proof, first
  paragraph), the finite set `M = {e_ij(x_l)}` normally generates `E_n(R,I)` in `EL_n(R)`. So
  Theorem A applies, with `(K_P, κ_P)` the image of a Kazhdan pair of `EL_n(D)` and `L`
  determined by the words expressing it. None of these depends on `ρ` or `d`.

## 4. Corollary C: split covers

- Put `φ_* = EL_n(φ)` and `s = EL_n(σ)`. Then `φ_* s = id`, and `E_n(R,I) <= ker φ_*`.
- Each generator factors as `e_ij(u) = e_ij(u - σφ(u))·e_ij(σφ(u))` with `u - σφ(u) ∈ I`. So
  `EL_n(R) = E_n(R,I)·s(EL_n(R/I))`, a product of a normal subgroup and a subgroup.
- If `g = h·s(k)` with `h ∈ E_n(R,I)` lies in `ker φ_*`, then `1 = φ_*(g) = k`, so
  `g = h ∈ E_n(R,I)`. Hence `ker φ_* = E_n(R,I)` and `EL_n(R)/E_n(R,I) = EL_n(R/I)`.
- Theorems A and B now give (FS1) for every model of `EL_n(R/I)` pulled back along `φ_*`.
- **Instances.**
  - A unital map `R -> Z` has image containing `1`, so it is onto, and the unit map
    `Z -> R` splits it. `SL_n(Z) = EL_n(Z)` because `Z` is Euclidean (row reduction).
  - `B = F_q[t,1/t]⟨y_1, ..., y_k⟩` is finitely generated (by `t`, `t^{-1}`, the `y_i`, and the
    finite field). The augmentation `y_i -> 0` is split by the inclusion of `F_q[t,1/t]`.
    `F_q[t,1/t]` is a Euclidean domain, so `SL_3(F_q[t,1/t]) = EL_3(F_q[t,1/t])`.

## 5. Sanity checks

- **Central counter-model.** If `N` is infinite central in a Kazhdan `G~`, then
  `P ≅ N ⋊ G~ = N x G~` has abelianization containing `N/[N,G~] = N`. If `N` is infinite,
  then `P` is not Kazhdan and Theorem A is silent. This is consistent with
  `rf-kazhdan-group-not-flexibly-hs-stable`, where such covers do produce non-roundable models.
- **Trivial kernel.** If `M = ∅`, then `P = Δ(G~)`, `N = 1`, `E = 1`, and (FS1) reads `0 <= 0`.

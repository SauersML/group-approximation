**Source for the definition of recurrence (JMBMdlS §4.2, verbatim).** "Here a group action
$G\acts X$ is called \emph{recurrent} if for every symmetric, finitely supported
probability measure $\mu$ on $G$ and every $x_0\in X$, the random walk $(g_nx_0)$ on the
orbit of $x_0$ induced by the left random walk on $G$ is recurrent."

**Step 0 (trivially acting elements).** Let `g ∈ G` act as the identity on `X`. Then
`𝔉(g) = 𝔉(id_X) = id`. For the extended functor this holds because `g` restricts to the
identity on each finite `A ⊆ X`, and the direct-limit maps are natural. So `g` acts
trivially on `𝔉(X)`.

**Step 1 (the cocycle on `θ(N)`).** For `m, n ∈ N`,
`c_(θ(m)θ(n)) = c_(θ(m)) · θ(m)(c_(θ(n))) = c_(θ(m)) c_(θ(n))` by Step 0. So
`ψ := c ∘ θ|_N : N → 𝔉(X)` is a homomorphism. Put `K = ker ψ`.

**Step 2 (`K` is normal in `F`).** First, `N ◁ F`: it is the kernel of the action of `F`
on `X` through `θ`. Let `f ∈ F`, `n ∈ K`, and write `g = θ(f)`, `h = θ(n)`.
- From `1 = c_1 = c_(g g⁻¹) = c_g · g(c_(g⁻¹))` we get `g(c_(g⁻¹)) = c_g⁻¹`.
- Since `h` acts trivially on `𝔉(X)` (Step 0),
  `c_(g h g⁻¹) = c_g · g(c_h) · (gh)(c_(g⁻¹)) = c_g · g(c_h) · g(c_(g⁻¹)) = c_g · g(c_h) · c_g⁻¹`.
- With `c_h = 1` this is `1`. So `fnf⁻¹ ∈ K`, because `fnf⁻¹ ∈ N`.

**Step 3 (item 1).** Assume `N ≠ 1`. There are two cases.
- *`K ≠ 1`.* `K ◁ F` by Step 2. By `nontrivial-normal-subgroups-of-thompson-f-contain-a-copy-of-f`,
  `K` contains a subgroup `F_0 ≅ F`. Then `θ(F_0) ⊆ ker c ∩ θ(F)`.
- *`K = 1`.* `ψ` is injective on `N`. `N ◁ F` and `N ≠ 1`, so the same import gives
  `F_0 ≤ N` with `F_0 ≅ F`, and `ψ(F_0) ≅ F`. The group `F_0` is finitely generated
  (`F` is generated by two elements). Every element of the direct limit `𝔉(X)` lies in the
  image of some `𝔉(A)` with `A` finite, and the finite subsets of `X` are directed. So the
  finitely many generators of `ψ(F_0)` all lie in the image of one `𝔉(A)`, and so does
  `ψ(F_0)`.

In the first case, amenability of `ker c` implies amenability of `F_0 ≅ F`, because
amenability passes to subgroups. In the second case, the image of `𝔉(A)` is a quotient of
`𝔉(A)` and contains `F`, so amenability of `𝔉(A)` implies amenability of `F`. ∎

**Step 4 (item 2).** Let `S` be a finite symmetric generating set of `F` and `μ` the
uniform measure on `θ(S)`. It is symmetric and finitely supported on `G`. For `x ∈ X`, the
`μ`-walk on `G·x` stays in `θ(F)·x` and is the Schreier walk of `θ(F)·x` for `θ(S)`. So
recurrence of `G ↷ X` makes every `θ(F)`-orbit recurrent. As an `F`-set through `θ`, the
orbit `θ(F)·x` is `F/H_x` with `H_x = θ⁻¹(G_x)`.

Suppose no orbit is exotic, i.e. `F′ ⊆ H_x` for every `x`. Then `F′` acts trivially on `X`,
so `F′ ⊆ N`. But `F′ ≠ 1`, since `F` is not abelian. So `N ≠ 1`. Hence either some orbit
is exotic, or `N ≠ 1` and item 1 applies. ∎

**Step 5 (item 3).** Let `F/H` be recurrent with `H ⊇ F_[0,c]`, `0 < c < 1`.
- *No interior fixed point.* By item 3 of `thompson-f-point-orbits-are-transient`, with
  `G = F`, `θ = id` and `p` empty, `H` fixes no point of `(0,1)`.
- *Transporting the rigid subgroup.* For `h ∈ H` and `g ∈ F_[0,c]`, `hgh⁻¹` is the identity
  on `h([c,1]) = [h(c),1]`. So `h F_[0,c] h⁻¹ = F_[0,h(c)]`, where `⊇` follows by applying
  the same to `h⁻¹`. Hence `F_[0,b] ⊆ H` for every `b ∈ H·c`.
- *The orbit reaches 1.* Let `s = sup H·c ∈ [c,1]`. Each `h ∈ H` is an increasing
  homeomorphism with `h(H·c) = H·c`, so `h(s) = s`. So `s` is fixed by `H`, and `s > 0`, hence
  `s = 1`.
- *Conclusion.* Let `g ∈ F` be the identity on `[r,1]` for some `r < 1`. Choose `b ∈ H·c`
  with `b > r`. Then `g ∈ F_[0,b] ⊆ H`.
- *So `H ⊇ F′`.* The elements that are the identity near `1` form the kernel of the
  homomorphism `χ_1 : F → 2^Z`, `g ↦ g′(1^-)`: an element of `F` fixes `1` and is linear on
  some `[r,1]`, so slope `1` there means it is the identity there. The target is abelian,
  so `ker χ_1 ⊇ F′`.
- *The other end.* For `F_[c,1]`, use `inf H·c = 0` and the germ at `0`. ∎

**Step 6 (item 4).** Let `F/H` be an exotic recurrent `F`-set. Each conjugate `H′` is the
stabilizer of another point of the same orbit, so it suffices to treat `H′ = H`.
- *Contains `F`.* This is Corollary 1 of
  `thompson-f-recurrent-orbits-have-stabilizers-containing-f`.
- *Meets every `Z³`.* This is item 2 of
  `recurrent-orbits-force-every-z3-to-meet-the-stabilizer`.
- *No fixed points in rigid copies.* This is item 3 of `thompson-f-point-orbits-are-transient`
  with `G = F` and `θ = id`.
- *No end-rigid subgroup.* By Step 5, `H ⊇ F_[0,c]` or `H ⊇ F_[c,1]` would force
  `H ⊇ F′`, contradicting exoticity. ∎

Notation as in the claim. Fix `v in V`.

**Step 0: `V` acts regularly on each orbit through a finite quotient.**
- Let `omega` be a `V`-orbit and `x in omega`. For `y = u x` with `u in V`,
  `Stab_V(y) = u Stab_V(x) u^(-1) = Stab_V(x)`, because `V` is abelian.
- So `K_omega = Stab_V(x)` is the pointwise stabilizer of `omega`, and
  `V_omega = V / K_omega` acts simply transitively on `omega`.
- In particular `|V_omega| = |omega|`, which is finite by (H1). `V_omega` is an
  `F_p`-vector space of finite dimension. Write `rho_omega : V -> V_omega` for the
  quotient map.

**Step 1: a twisted permutation module.**
- Let `Omega` be the set of `V`-orbits and `D = ⊕_(omega in Omega) V_omega`, the
  restricted direct sum.
- `rho_omega(u) != 0` exactly when `u` moves the points of `omega`. By (H2) the map
  `rho = (rho_omega)_omega` sends `V` into `D`. It is injective, since `V <= Sym(X)`.
- Since `a` normalizes `V`, it maps orbits to orbits: `a(V x) = V (a x)`. Write
  `q(omega) = a(omega)`. Conjugation by `a` carries the pointwise stabilizer of
  `omega` to that of `q(omega)`, so `a K_omega a^(-1) = K_(q omega)`.
- Hence `theta_omega : V_omega -> V_(q omega)`, `rho_omega(u) |-> rho_(q omega)(c(u))`,
  is a well-defined linear isomorphism.
- Define `Phi : D -> D` by `(Phi w)_(q omega) = theta_omega(w_omega)`. `Phi` is a
  linear automorphism of `D`, and `Phi ∘ rho = rho ∘ c`.

**Step 2: infinite `q`-orbits see nothing.**
- Let `O` be an infinite `<q>`-orbit in `Omega`. Fix `omega_0 in O` and put
  `omega_n = q^n omega_0`. The `omega_n` are pairwise distinct and exhaust `O`.
- `Phi` maps `D_O = ⊕_(omega in O) V_omega` to itself, and the projection
  `P_O : D -> D_O` commutes with `Phi`. `Phi^n` maps `V_(omega_0)` isomorphically
  onto `V_(omega_n)`.
- Let `u_1, ..., u_d` be a basis of `V_(omega_0)`. Then
  `(f_1, ..., f_d) |-> sum_i f_i(Phi) u_i` is an isomorphism of `F_p[t, t^(-1)]`-modules
  `F_p[t, t^(-1)]^d -> D_O`, with `t` acting on `D_O` as `Phi`.
- By (H3), for every `n >= 1` there is `w_n in V` with `v = (c - 1)^n w_n`. Applying
  `P_O ∘ rho` gives `P_O rho(v) = (Phi - 1)^n P_O rho(w_n)`.
- So every coordinate `f_i` of `P_O rho(v)` is divisible by `(t - 1)^n` in
  `F_p[t, t^(-1)]` for every `n`. A nonzero Laurent polynomial `t^m g(t)`, with
  `g in F_p[t]` and `g(0) != 0`, has `(t - 1)`-adic valuation at most `deg g`. So
  `f_i = 0`, and `P_O rho(v) = 0`.

**Step 3: finite `q`-orbits force finite order.**
- By (H2), `rho(v)` has finite support. By Step 2, every orbit in that support lies
  in a finite `<q>`-orbit. Let `F` be the union of these `<q>`-orbits: a finite,
  `q`-invariant set.
- `D_F = ⊕_(omega in F) V_omega` is finite by (H1), and `Phi` permutes it. So
  `Phi^e` is the identity on `D_F` for some `e >= 1`.
- Then `rho(c^e(v)) = Phi^e rho(v) = rho(v)`, so `c^e(v) = v` by injectivity of
  `rho`. The `c`-orbit of `v` has at most `e` elements. `∎`

**The two placements of the claim.**
1. *Finitary.* Let `omega` be an infinite `V`-orbit. By Step 0 (which uses only
   commutativity) a nonzero element of `V_omega` moves every point of `omega`. So
   any element of `V` acting nontrivially on `omega` moves infinitely many points,
   which is excluded. Then `V` acts trivially on `omega`, so `omega` is a single
   point, a contradiction. This gives (H1). An element moving finitely many points
   meets finitely many orbits, which gives (H2). Products of finitary permutations
   are finitary, so it suffices that `V` is generated by finitary permutations.
2. *Finite lamps.*
   - A base element `f` acts on `Omega x B` fibrewise, by `(s, b) |-> (s, f(s) b)`.
     The base acts faithfully, since `f(s) b = b` for all `b` forces `f(s) = 1`.
   - For `V <= B^(Omega)` the `V`-orbits lie in fibres `{s} x B`, so they are finite.
   - An element `u in V` moves points only in the fibres over its finite support.
     Each fibre holds at most `|B|` orbits, which gives (H2).

**Sharpness examples.**
- *Without (H2).* In `L = R x| Z^2`, the stabilizer of the coset `gK` is `g K g^(-1)`,
  and its intersection with `R` is `c_g(K)`, of finite index. So the `R`-orbit of
  `gK` has size `[R : c_g(K)]`.
  - *Faithful.* An element `r in R` acting trivially lies in every finite-index
    subgroup of the elementary abelian group `R`, so `r = 0`. An element `(r, z)`
    with `z != 0` moves the coset `K = R` of the summand `L/R`.
  - *(H3).* `c - 1` acts as multiplication by `t - 1`, a unit of `R`.
  - *Infinite orbit.* The powers `t^n` are pairwise distinct.
- *Without (H1).* The affine action of `L` on `R` has the single `R`-orbit `R`, and
  every translation moves points in exactly that one orbit.

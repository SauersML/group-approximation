**ESTABLISHED (exact computation).** Let `G` be a torsion-free group and let
`alpha, beta` be nonzero elements of `F_2[G]` with `alpha beta = 0`. If
`|supp alpha| = 3`, then `|supp beta| >= 22`.

Abdollahi--Taheri (arXiv:1612.00934, Cor 6.2) proved `|supp beta| >= 20`.
Their Thm 6.1 leaves 1120 graphs with 20 vertices. This result excludes all
connected triangle-free cubic graphs with 20 vertices, those 1120 included.
Nielsen--Soelberg (Thm 1.4) prove `|supp beta| >= 19` over any domain, and
remark that the `F_2` bound `>= 20` also follows from theirs; they do not
improve it over `F_2`.

**Search.** `zds3.c` tries every port labelling of every connected
triangle-free cubic graph with 20 vertices, the 97546 outputs of
`nauty-geng -c -t -d3 -D3 20`. That count matches A--T Table 3. The ports at
one vertex are fixed by the `S_3` on port names, which comes from translating
`alpha`. The program prunes by sieves 1, 2, 3, 5 and 6 of §5 of the artifact:
1. two cosets with different tags merge in a partial Todd--Coxeter
   enumeration seeded with the labelled graph;
2. a closed path reads a proper power `w^k`, so `w = 1` is added;
3. the group `<x, y | cycle words>` is finite;
5. the exponent sums of the cycle words have rank less than 2
   (`small-non-up-left-support-has-no-orderable-quotient`);
6. the coset table shows `u^e = 1` with `e >= 2`, so `u = 1` is added.

Each sieve holds in every torsion-free realization. The run `n20.sbatch`
(MSI array job 595808) splits the graphs into 128 geng res/mod shards. No
labelling survives. The search takes 3,995,100,752 nodes, with median 13,212
and maximum 1,237,042 per graph, in 57,017 core-seconds. It prunes
2,511,202,904 labellings by coincidence, 131,737,285 as finite, and 30 by
sieve 6. Every exit code is 0, and no run hits a limit or writes to stderr.

**Controls.**
- `check20.sh` (output `check20.595808.out`). The sorted input graphs equal
  the sorted graphs of the GRAPH lines, 97546 of them, all distinct. Every
  GRAPH line has `surv 0`. All 128 TOTAL lines have `fails 0`, `budget 0`
  and the same options.
- Second pass (`n20b.sbatch`, MSI array job 603674, aggregated by
  `agg20b.sh`). The same shards and binary with root vertex 19, so every
  graph is searched along a different tree. 97546 graphs, no duplicate GRAPH
  lines, no survivors, no limits hit, every exit code 0. It takes
  2,114,114,462 nodes, with median 10,278 and maximum 779,445 per graph, in
  27,276 core-seconds.
- Soundness test (`testgen.g`, `surv.591297.log`, `exp14.593423.log`). The
  input is 99158 components of solutions of `(1 + x + y) beta = 0` over
  `F_2` in 179 finite groups. Sieve 1 prunes no prefix of any of them, at
  coset limits 0 and 4000/64000, and the search reaches every one.
- The same search excludes every graph with at most 18 vertices (7805 at
  `n = 18`), which reproduces A--T's bound without their forbidden
  subgraphs. `zds.c`, which orders vertices by BFS, agrees for `n <= 16`
  along a different search tree.

**Scope.** The inputs are A--T Thm 2.9 and Cor 6.2 (read in the arXiv text),
`nauty-geng`, and the correctness of `zds3.c`. The finite-group test cannot
exercise sieves 2, 3, 5 and 6, because they would prune genuine solutions in
groups with torsion. There is no per-graph proof object; the landed evidence
is the program, the job scripts and the logs. The next case is not settled:
at 22 vertices some labellings survive every sieve (§6 of the artifact).

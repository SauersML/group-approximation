Let

```text
0 -> I -> E --q--> Q -> 0
```

be an extension of C*-algebras.  Suppose that `Q` contains a finite set `F`
which is contained in no singly generated C*-subalgebra of `Q`.  For any
choice of lifts `F_tilde` of the elements of `F`, the set `F_tilde` is
contained in no singly generated C*-subalgebra of `E`.  In particular, `E` is
not singly generated.

If `I` and `Q` are nowhere scattered, then `E` is nowhere scattered as well.
Thus failure of single generation with a finite witness is upward closed under
extensions inside the nowhere-scattered category.

Applied to the Elliott--Li--Niu algebra `A`, every nowhere-scattered extension
with quotient `A` is another counterexample to the general part of STW Problem
XCVI.  This produces non-simple counterexamples without assuming that single
generation itself is extension-permanent (it is not).

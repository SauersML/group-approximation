title: Injective unital inductive limits cannot create non-stable finiteness only at infinity
distinct_from:
  stw99-lxvi-reduced-product-assembles-finite-stages: that assembles already non-stably-finite stages in a nonsimple quotient product; this rules out manufacturing the instability from stably finite stages in an injective inductive limit.
---

Let

```text
A_1 -> A_2 -> ... -> A
```

be a unital inductive system with injective connecting maps.  If every `A_n`
is stably finite, then `A` is stably finite.

More precisely, if `A` is finite but not stably finite, then some `A_n` is
finite but not stably finite, and every later stage has the same two
properties.  Consequently an injective internal-CAR construction for Problem
LXVI cannot begin with stably finite dyadic building blocks and arrange for
matrix infiniteness to appear only in the limit.

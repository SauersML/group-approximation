Notation as in the target. `A = Alt_fin(X)`, and for `Y ⊆ X`, `Alt_fin(Y)` is the set of
elements of `A` fixing `X − Y` pointwise. For finite `D`, `Alt(D) = Alt_fin(D)`.

**Step 0. Standard facts.**
- (a) `A` is `k`-transitive on `X` for every `k`, since `X` is infinite and `Alt(D)` is
  `(|D|−2)`-transitive on `D`.
- (b) *Gluing.* If `D_1, D_2` are finite, `|D_1|, |D_2| ≥ 5` and `|D_1 ∩ D_2| ≥ 2`, then
  `⟨Alt(D_1), Alt(D_2)⟩ = Alt(D_1 ∪ D_2)`.
  - Proof: let `L` be the left side, acting on `D = D_1 ∪ D_2`. It is transitive, since
    each `Alt(D_i)` is transitive on `D_i` and `D_1 ∩ D_2 ≠ ∅`.
  - For `p ∈ D_1 ∩ D_2`, `L_p ⊇ Alt(D_1 − p), Alt(D_2 − p)`. Both are transitive on
    their sets, which have size `≥ 4` and meet in `≥ 1` point. So `L_p` is transitive on
    `D − p`, and `L` is 2-transitive, hence primitive.
  - `L` contains a 3-cycle. By Jordan's theorem (Wielandt, *Finite Permutation Groups*,
    Theorem 13.3: a primitive group containing a 3-cycle contains the alternating group),
    `L ⊇ Alt(D)`. Conversely `L ≤ Alt(D)`.

**Step 1. Item 2.** By (a), `A` is transitive on two-element subsets.

**Step 2. The quotient does not change.** Fix `x ∈ X`.
- `Γ = A·Γ_x`, since `A` is transitive.
- `Γ_x ∩ A = Alt_fin(X − x)`.
- So `Γ_x / Alt_fin(X − x) → Γ / A` is an isomorphism.

**Step 3. The finite set `E`.** Let `Σ` be a finite symmetric generating set of `Γ`.
- For `s ∈ Σ`, pick `π_s ∈ A` with `π_s(s x) = x` (by (a)) and set `s' = π_s s ∈ Γ_x`.
- Pick `D_0 ⊆ X − x` finite, with `|D_0| ≥ 5`, containing:
  - `supp(π_s) − x` and `s^{-1}(supp π_s) − x` for all `s ∈ Σ`;
  - `s^{-1} x` for all `s ∈ Σ` with `s^{-1} x ≠ x` (the Schreier neighbours of `x`);
  - for each `s ∈ Σ`, two points `y_s ≠ z_s` of `X − x` together with `s' y_s, s' z_s`.
- Let `E = {s' : s ∈ Σ} ∪ Alt(D_0)` (finite) and `H = ⟨E⟩ ≤ Γ_x`.

**Step 4. `H` is transitive on `X − x`.** Let `y ∈ X − x`.
- The Schreier graph of `Σ` on `X` is connected, since `Γ` is transitive.
- Take a path from `y` to `x` and stop at its first visit to `x`. Its last vertex is
  some `s^{-1} x ∈ D_0`, and the path before it avoids `x`.
- Consider an edge `u → s u` of that path, with `u, su ≠ x`.
  - If `π_s(su) = su`, then `s' u = su`, so `u` and `su` are in one `H`-orbit.
  - Otherwise `su ∈ supp π_s`, so `su ∈ D_0` and `u ∈ s^{-1}(supp π_s)`, so `u ∈ D_0`.
    Then `u, su` are in one `Alt(D_0)`-orbit, since `Alt(D_0)` is transitive on `D_0`.
- So `y` lies in the `H`-orbit of `D_0`, which is one orbit.

**Step 5. `H ⊇ Alt_fin(X − x)`.**
- Let `𝒟` be the set of finite `D ⊆ X − x` with `|D| ≥ 5` and `Alt(D) ≤ H`. Declare
  `D ~ D'` if `|D ∩ D'| ≥ 2`, and take the equivalence classes of the generated
  equivalence relation.
- `H` permutes `𝒟`: `h Alt(D) h^{-1} = Alt(hD)`. It preserves `~`, so it permutes classes.
- Let `𝒞` be the class of `D_0` and `Y = ⋃𝒞`. For a chain `D_0 ~ D_1 ~ ... ~ D_r` in
  `𝒞`, (b) and induction on `r` give `Alt(D_0 ∪ ... ∪ D_r) ≤ H`, because `D_{j+1}` meets
  `D_0 ∪ ... ∪ D_j` in at least two points. Two such unions both contain `D_0`, so by (b)
  again Alt of their union lies in `H`. Every finite subset of `Y` lies in finitely many
  chain unions, so `Alt_fin(Y) ≤ H`.
- Each generator in `E` fixes `𝒞`:
  - elements of `Alt(D_0)` fix `D_0`;
  - `s' D_0 ∈ 𝒟` contains `s' y_s, s' z_s ∈ D_0`, so `s' D_0 ~ D_0`.
- So `hY = Y` for all `h ∈ H`. Since `Y ⊇ D_0 ≠ ∅` and `H` is transitive on `X − x`
  (Step 4), `Y = X − x`. So `Alt_fin(X − x) ≤ H`.

**Step 6. Item 1.**
- The images of the `s'` in `Γ/A` equal those of the `s`, so `H A = Γ`.
- For `g ∈ Γ_x`, write `g = h π` with `h ∈ H` and `π ∈ A`. Then `π = h^{-1} g` fixes `x`,
  so `π ∈ Alt_fin(X − x) ≤ H`.
- So `Γ_x = H` is generated by the finite set `E`.

**Step 7. Items 3 and 4.**
- Faithfulness holds because `Γ ≤ Sym(X)`.
- Finite presentation is assumed; stabilizers are finitely generated by item 1; orbits
  are finite by item 2.
- Item 4 is Zaremsky's Corollary B, quoted verbatim in
  `type-a-action-gives-boone-higman-for-subgroups`.

ESTABLISHED.  Lemma 3.1 of the OpenAI nonsofic chapter, over
`R = L_(F_2)(1,2)`.

Write `s_a`, `t_a` for the prefix products of a finite binary word `a`,
`e_a = s_a t_a`, and `V_l` for the copy of Thompson's `V` acting by prefix
replacements inside the cylinder `[l]` and fixing its complement.  For a
prefix code `E = (a_1, ..., a_q)`, let `EL_E(R) = <1 + s_(a_i) r t_(a_j) :
i /= j, r in R>` be the elementary prefix group.  Then, with
`alpha = (000, 001, 01)` and the complete nine-leaf code `D` of the chapter,

    V <= EL_D(R),   and   V_l <= EL_alpha(R) whenever l extends some alpha_i.

## The mechanism, and why characteristic two is not a convenience

For incomparable words `rho, sigma` the cylinder swap is the unit

    tau_(rho,sigma) = 1 + e_rho + e_sigma + s_rho t_sigma + s_sigma t_rho,

and these swaps generate `V`.  If `rho = a_i w` and `sigma = a_j w'` extend
different leaves of `E`, then `P = s_rho t_sigma` and `Q = s_sigma t_rho`
factor through those leaves, so `1 + P` and `1 + Q` are elementary `E`-roots,
and

    tau_(rho,sigma) = (1 + P)(1 + Q)(1 + P)

**in characteristic two** -- the cross terms that would otherwise survive are
the ones the coefficient field kills.  This is the same three-factor identity
that writes a transposition as a product of three elementary matrices, and it
is why the construction is run over `F_2` rather than over an arbitrary field.

Two leaves are enough for the rest: if `rho` and `sigma` extend the *same*
leaf `a_i`, pick another leaf `a_j` and use
`tau_(rho,sigma) = tau_(rho,a_j) tau_(sigma,a_j) tau_(rho,a_j)`.  For the
complete code `D`, refine first: choose `k` with every `rho w`, `sigma w`,
`w in {0,1}^k`, extending a leaf of `D`, and use
`tau_(rho,sigma) = prod_w tau_(rho w, sigma w)`.

## The same objects appear in this development

`Leavitt/ThompsonVWitness` builds the cylinder swaps as units of the same
algebra, proves they act on the faithful stream basis as boundary
transpositions, and places them inside the corner subgroups
(`cornerHom_cylinderSwap_mem`, `swapPerm_mem_thompsonV`).  The non-LEF witness
of this repository's own endpoint is generated by exactly these swaps -- see
[[universal-leavitt-el4-nonsofic]] -- so the membership statement above is not
a foreign construction here, only a different code and a different rank.

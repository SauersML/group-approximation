Notation as in the target.
- For a word `α = a_1...a_k` put `s_α = s_(a_1)...s_(a_k)` and `t_α = t_(a_k)...t_(a_1)`.
- For words of one length, `t_α s_β = δ_αβ`.
- For incomparable words (neither a prefix of the other), `t_β s_α = 0`.
- `t_α s_(αζ) = s_ζ`.
- `V ⊂ U` denotes the sums `Σ s_(a_i) t_(b_i)` over bijections of complete prefix
  codes. They are units with inverse `Σ s_(b_i) t_(a_i)`.

**0. The module.**
- *Relations.* The formulas define a representation `π: R → End_K(W)`:
  `t_i s_j δ_ξ = δ_ij δ_ξ`, and `(s_0 t_0 + s_1 t_1) δ_(jξ) = δ_(jξ)`.
- *Injectivity.* `R` is simple (`leavitt-algebras-l-k-1-n-are-simple`) and `π ≠ 0`,
  so `π` is injective.
- *Formulas.* `π(s_α) δ_ξ = δ_(αξ)`. `π(t_β) δ_ξ = δ_ζ` if `ξ = βζ`, and `0` otherwise.

**1. Faithful modulo scalars.** Suppose `u ∈ U` fixes every line. Then `π(u)` is a
scalar `λ`, so `π(u − λ) = 0` and `u = λ ∈ K^×`. Conversely, `K^×` acts trivially.

**2. 2-transitive.**
- *Setup.* Let `([v_1],[w_1])` and `([v_2],[w_2])` be pairs of distinct lines. Then
  `v_i, w_i` are linearly independent.
- *Common length.* Let `Φ ⊂ D` be the union of their supports and `m = |Φ| >= 2`. Pick
  `N` beyond the last `1` of every `ξ ∈ Φ` and write `ξ = p_ξ 0^∞` with `|p_ξ| = N`.
  The `p_ξ` are distinct words of one length.
- *Matrix units.* `e_ξη = s_(p_ξ) t_(p_η)` satisfy `e_ξη e_ξ'η' = δ_ηξ' e_ξη'`. Put
  `P = Σ e_ξξ`.
- *The units.* For `A ∈ GL_m(K)` let `u_A = (1 − P) + Σ A_ξη e_ξη`. Since
  `(1−P) e = e (1−P) = 0`, we get `u_A u_(A^(-1)) = 1`.
- *Action on `span δ_Φ`.* `π(e_ξη) δ_ζ = δ_ηζ δ_ξ` and `π(1−P) δ_ζ = 0` for `ζ ∈ Φ`. So
  `u_A` acts on `span{δ_ζ : ζ ∈ Φ}` by `A`.
- *Conclusion.* `GL_m(K)` sends `(v_1, w_1)` to `(v_2, w_2)`.

**3. Germ columns.** Put `Λ = K[s, s^(-1)]` and `F = ⊕_(q ∈ D) Λ e_q`.
- *Star-free form.* Let `u = Σ c s_α t_β` and `q = c_q 0^∞`. For `k >= max |β|`,
  `u s_(c_q 0^k)` is a `K`-combination `Σ λ_γ s_γ` of monomials without `t`.
- *Independence.* The `s_γ` are linearly independent. Take `τ = 1^M 0^∞` with `M` larger
  than every `|γ|`: the points `γτ` are distinct, since the last `1` of `γτ` sits at
  position `|γ| + M`. So `π(Σ λ_γ s_γ) δ_τ = Σ λ_γ δ_(γτ)`.
- *Definition.* Put `col_q(u) = Σ λ_γ s^(|γ| − |c_q| − k) e_(γ0^∞) ∈ F`. It is
  independent of `k`, because appending `0` to `c_q 0^k` appends `0` to every `γ`.
- *(a) Evaluation.* `π(u) δ_q = Σ_x col_q(u)_x(1) δ_x`.
- *(b) Multiplicativity.* `col_q(uv) = Σ_x col_q(v)_x · col_x(u)`. Pad `k` until every
  monomial `s_γ` of `v s_(c_q 0^k)` has `u s_γ` star-free. The monomials of `u s_γ` give
  `col_(γ0^∞)(u)` shifted by `|γ|`.
- *(c) Unimodular.* If `u ∈ U` then the entries of `c = col_(0^∞)(u)` generate `Λ`.
  Apply (b) to `u^(-1) u = 1`: the `0^∞`-entry is `Σ_x col_x(u^(-1))_(0^∞) c_x = 1`, a
  finite sum.
- *(d) Trivial germ.* `col_(0^∞)(u) = e_(0^∞)` iff `u s_(0^k) = s_(0^k)` for some `k`,
  by independence.

**4. Subgroups.**
- *`H`.* Let `H = Stab_U(δ)`. For `u ∈ H`, (a) gives `c_(0^∞)(1) = 1` and `c_x(1) = 0`
  for `x ≠ 0^∞`, so `(s − 1) | c_x`.
- *`H_k`.* Put `H_k = {u : u s_(0^k) = s_(0^k)} ⊂ H`. The element `g` of the target lies
  in `V`, and `g s_(0^k) = s_(0^(k+1))` for `k >= 1`, so `H_(k+1) = g H_k g^(-1)`. By (d),
  `H^0 := {u ∈ H : col_(0^∞)(u) = e_(0^∞)}` equals `∪_k H_k`, and it lies in `⟨H_1, g⟩`.
- *`H_1 = N ⋊ Q`.* Let `u ∈ H_1` and `P_i = s_i t_i`.
  - *Block form.* `u P_0 = P_0`, so `u = P_0 + P_0 u P_1 + P_1 u P_1`.
  - *The corner unit.* `q = P_1 u P_1` has corner inverse `P_1 u^(-1) P_1`: the product
    is `P_1 u (1 − P_0) u^(-1) P_1 = P_1`.
  - *Factorization.* With `n = P_0 u P_1` and `q'` that inverse,
    `u = (1 + n q')(P_0 + q)`.
  - *`N`.* `N = {1 + s_0 a t_1 : a ∈ R} ≅ (R, +)`.
  - *`Q`.* `Q = {P_0 + s_1 b t_1 : b ∈ U} ≅ U`.
  - *Conjugation.* `(P_0 + s_1 b t_1)(1 + s_0 a t_1)(P_0 + s_1 b t_1)^(-1)
    = 1 + s_0 a b^(-1) t_1`.

**5. `R` is spanned by `U`.** Let `S = span_K U`, a subalgebra containing `1`.
- *Incomparable monomials.* For incomparable `α, β`, `(s_α t_β)^2 = 0`, so
  `1 + s_α t_β ∈ U` and `s_α t_β ∈ S`.
- *Idempotents.* `P_0 = (s_0 t_1)(s_1 t_0) ∈ S` and `P_00 = (s_00 t_1)(s_1 t_00) ∈ S`.
- *`t_0`.* With `g^(-1) = s_0 t_00 + s_10 t_01 + s_11 t_1 ∈ V`:
  - `g^(-1) P_00 = s_0 t_00 = P_0 t_0`;
  - `P_1 t_0 = s_1 t_01 ∈ S`;
  - so `t_0 ∈ S`.
- *`s_0`.* `g P_0 = s_00 t_0`, so `s_0 = s_00 t_0 + s_01 t_1 ∈ S`.
- *Symmetry.* The automorphism exchanging the indices `0, 1` preserves `U`, so
  `s_1, t_1 ∈ S` and `S = R`.

**6. `H_1` is finitely generated.**
- By 4 and 5, `N` is generated by the `Q`-conjugates of `1 + s_0 t_1`, since sums and
  scalar multiples of the `b^(-1)` exhaust `R`.
- `U` is finitely presented: it is a central extension of the finite group `K^×` by the
  finitely presented group `G` (`odd-leavitt-unit-groups-mod-scalars-are-fp-simple`).
- So `H_1 = ⟨Q, 1 + s_0 t_1⟩` is finitely generated.

**7. `H = ⟨H_1, g, w_0⟩`.** Let `u ∈ H` and `c = col_(0^∞)(u)`. Left multiplication by
`y ∈ H` replaces `c` by `col_(0^∞)(yu)`. Put `p* = 10^∞`. All exponents `m ∈ Z` and
`λ ∈ K` are allowed below; products give arbitrary Laurent coefficients.
- **(E1) Rows away from `0^∞`.** Let `x ≠ x'` be in `D ∖ {0^∞}`, `x = b0^∞`,
  `x' = a0^∞`.
  - *Choice.* Take `β = b0^i` and `α = a0^j` with `i, j` large, so that they are
    incomparable, `x` is the only support point in the cone of `β`, and
    `|α| − |β| = m`.
  - *Membership.* `e = 1 + λ s_α t_β` is a unit, and `e ∈ H_k` for large `k`.
  - *Effect.* `c_(x') ↦ c_(x') + λ s^m c_x`, since the monomials `s_(b0^r)` of `x` map to
    `s_(a0^(j+r−i))`.
- **(E2) Into `0^∞`.** `1 + λ s_(0^j) t_(b0^i)`, with `j` beyond the first `1` of `b`,
  lies in `H^0`. It gives `c_(0^∞) ↦ c_(0^∞) + λ s^m c_x`.
- **(E3) From `0^∞` into `p*`.** Assume the support meets the cone `0` only in `0^∞`.
  - *`w_0`.* `n = s_10 t_0 − s_10 t_00` has `n^2 = 0`, and `w_0 δ = δ`.
  - *Effect of `w_0^λ = 1 + λn`.* `n s_(0^r) = s_(10^r) − s_(10^(r−1))`, so it adds
    `λ(s − 1) c_(0^∞)` to `c_(p*)`.
  - *Shifts.* `r = s_0 t_0 + s_100 t_10 + s_101 t_110 + s_11 t_111 ∈ V ∩ H_1` has germ `1`
    at `0^∞` and germ `s` at `p*`. So `r^(-M) w_0^λ r^M` adds `λ(s − 1) s^(-M) c_(0^∞)`.
- **(E4) The shift.** `col_(0^∞)(g^(-m) · s^m e_(0^∞)) = e_(0^∞)`.

**The algorithm.** (E1) and (E2) lie in `H^0 ⊂ ⟨H_1, g⟩`; (E3) lies in `⟨H_1, w_0⟩`.
1. *Clear cone `0`.* Copy each `c_x` with `x ∈ 0{0,1}^N ∖ {0^∞}` to a fresh point of cone
   `1`, and subtract it back (E1).
2. *Gather.* Run the Euclidean algorithm among the remaining rows (E1). This leaves
   `d = gcd` at `p*` and `0` elsewhere. Since `(s−1) | c_x`, write `d = (s − 1) d'`.
3. *Alternate.* With `a = c_(0^∞)`, the column `(a, d)` is unimodular by 3(c), so
   `gcd(a, d') = 1`.
   - Reduce `a` modulo `d` (E2).
   - Reduce `d'` modulo `a`, i.e. `d` modulo `(s−1)a` (E3).

   Measure a Laurent polynomial by its span (top exponent minus bottom).
   - After the first step `span a <= span d'`.
   - After the second `span d' < span a`.

   So the span strictly decreases until `d' = 0`.
4. *Finish.* Then `a` is a unit `λ s^m` of `Λ`, and `a(1) = 1` forces `λ = 1`. Apply
   (E4).

The result `yu` has column `e_(0^∞)`, so `yu ∈ H^0` with `y ∈ ⟨H_1, g, w_0⟩`. Hence
`u ∈ ⟨H_1, g, w_0⟩`, and with 6, `H` is finitely generated.

**8. Line stabilizers.**
- *In `U`.* `Stab_U([δ]) = K^× H`: if `u δ = λ δ` then `λ^(-1) u ∈ H`. Also
  `K^× ∩ H = 1`.
- *In `G`.* The stabilizer is `K^× H / K^× ≅ H`, finitely generated.
- *Every line.* `G` is transitive on lines, so every line stabilizer is conjugate to this
  one. `∎`

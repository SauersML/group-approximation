**Relations used** (from `leavitt-resolvent-ring-is-fp-simple-of-char-zero`): `t_i s_j = δ_ij`, `s_1 t_1 + s_2 t_2 = 1`,
`N s_1 = s_1 (N + 1)`, `N s_2 = 0`, `A = (N + 1)^(-1)`.
- For `f in B`, `f s_1 = s_1 f(N + 1)` and `f s_2 = s_2 f(0)`. For resolvents, `(N + c)^(-1) s_1 = s_1 (N + c + 1)^(-1)`,
  and `(N+c)^(-1) s_2 = c^(-1) s_2` uses `Q ⊆ R_L`.
- Multiplying by `1 = s_1 t_1 + s_2 t_2` gives `t_1 f = f(N+1) t_1` and `t_2 f = f(0) t_2`.

**Item 1.**
- **The embedding.** `q_k q_l = δ_(kl) q_k`, since `t_2 t_1^k s_1^l s_2 = δ_(kl)`.
  `q_k f = s_1^k s_2 t_2 f(N + k) t_1^k = f(k) q_k`, and likewise `f q_k = f(k) q_k`. So
  `f + Σ a_k δ_k -> f + Σ a_k q_k` is a ring homomorphism `B⁺ -> R_L`. It is injective: in the faithful model on
  `Q^(X)` of `leavitt-resolvent-ring-is-fp-simple-of-char-zero`, `q_k` is the projection onto `{N = k}` and `f` acts
  as `f(N)`, and `N` takes every value `k >= 0`. Here `B -> Fun(N, Q)` is injective, because a rational function
  vanishing on `N` is `0`.
- **The letters.**
  - `q_k s_1 = s_1 q_(k-1)` for `k >= 1` and `q_0 s_1 = s_2 t_2 s_1 = 0`, that is `g s_1 = s_1 σ(g)` with
    `σ(g)(n) = g(n+1)`.
  - `q_k s_2 = δ_(k0) s_2`, that is `g s_2 = s_2 g(0)`.
  - Both letters have full availability: `t_1 s_1 = 1 = t_2 s_2`.
  - `B⁺` is the ring `B⁺_T` of `eventually-rational-register-ring-is-regular-supercoherent`, with `T = B`, a
    localization of `Q[t]` closed under `t -> t + 1`.
  - It contains every point indicator. `s_1` has range the whole type and full availability, so it is a spine.
- **Universality.** Let `U` be the universal ring on `B⁺`, the `s_i, t_i` and these relations.
  - The nine relations of `R_L` hold in `U`, so there is a map `R_L -> U`.
  - In `U`, `δ_0 = δ_0 (s_1 t_1 + s_2 t_2) = s_1 δ_0(N+1) t_1 + s_2 δ_0(0) t_2 = s_2 t_2`. Inductively
    `δ_k = s_1 δ_(k-1) t_1 = q_k`. So `U` is generated by the image of `R_L`.
  - The map `U -> R_L` from the embedding above is inverse to it on generators. So `U ≅ R_L`.

**Item 2.**
- **`K_*(B)`.** `B` is the localization of the Dedekind domain `Q[N]` at the primes `(N + c)`, `c >= 1`, all with
  residue field `Q`. Quillen's localization sequence, a colimit over finite sets of primes, and `K_*(Q[N]) = K_*(Q)`
  give `0 -> K_n(Q) -> K_n(B) -> ⊕_(c>=1) K_(n-1)(Q) -> 0`.
  - The pushforwards `K_n(Q[N]/(N+c)) -> K_n(Q[N])` vanish, since `[Q[N]/(N+c)] = [Q[N]] - [Q[N]] = 0` in `G_0` and
    the pushforward is `K_*(Q)`-linear.
  - The sequence splits by `ev_0 : B -> Q`, since `c != 0`, and by the lifts `x -> {x, N + c}` of the residues. Write
    `e_c` for the residue coordinate at `N = -c`.
- **`K_*(B⁺)`.** `J` is an ideal with local units, a directed union of `Q^m`. Excision and colimits give
  `K_n(J) = ⊕_k K_n(Q) δ_k`. The inclusion `B ⊆ B⁺` splits `B⁺ -> B⁺/J = B`, so
  `K_n(B⁺) = K_n(B) ⊕ K_n(J)`. This gives the decomposition `A ⊕ E ⊕ D` of the claim, with `A = K_n(Q)·1`.
- **The transfer.** `[X]` is the sum over the two letters of the substitution maps: `σ_*` for `s_1`, and
  `(1 · ev_0)_*` for `s_2`.
  - On `A`: `σ(1) = 1` and `ev_0(1) = 1`, so `[X] = 2`.
  - On `E`: `σ(N + c) = N + c + 1`, so `σ_* e_c = e_(c+1)`. `ev_0` sends the lift `{x, N+c}` to `{x, c} in A`.
  - On `D`: `σ(δ_k) = δ_(k-1)`, with `δ_(-1) = 0`. `ev_0(δ_k) = δ_(k0)·1`.
- **`1 - [X]`** is block triangular: `A -> A` is `-1`; `E -> E ⊕ A` has `E`-part `1 - t`, `t e_c = e_(c+1)`;
  `D -> D ⊕ A` has `D`-part `δ_k -> δ_k - δ_(k-1)`, `δ_0 -> δ_0`.
  - The `D`-part is unitriangular, with inverse `δ_k -> δ_0 + ... + δ_k`, so it is an isomorphism of `D`.
  - `1 - t` on `E = ⊕_(c>=1) K_(n-1)(Q) e_c` is injective. Its image is the kernel of the sum map
    `E -> K_(n-1)(Q)`, since `(1-t) e_c = e_c - e_(c+1)`.
  - **Kernel.** If `(1 - [X])(a, x, d) = 0`, the `E`- and `D`-parts give `x = 0` and `d = 0`, and then `-a = 0`.
  - **Cokernel.** The image contains `A`. Modulo `A`, the image is `(1 - t) E ⊕ D`. So
    `coker = E / (1 - t)E ≅ K_(n-1)(Q)` through the sum.

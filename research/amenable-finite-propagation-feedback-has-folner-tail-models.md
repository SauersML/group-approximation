Let an amenable group `H` index a finite-dimensional fiber configuration
which satisfies a finite-propagation group-word rule exactly on the infinite
lattice. Compress the site observables and partial translations to a Folner
set `F_n`, completing translations arbitrarily on the boundary. For every
fixed word relator `r`, with propagation set `K_r`,

```text
||r(U_n)-I||_2^2
 <= 4 |boundary_(K_r) F_n|/|F_n| -> 0.                 (AFP1)
```

Diagonalizing the Folner sets over the first `n` rules gives a tracial
matrix-ultraproduct homomorphism satisfying the whole recursively enumerable
local library. Any local marked observable having positive mean-square
density `beta` in the infinite tail retains

```text
||w(U_n)-I||_2^2 >= beta-o(1).                          (AFP2)
```

Hence an amenable shift-local feedback loop with an exact marked safe tail
cannot prove unconditional hyperlinear-radical collapse. It also refutes a
canonical-profile-relative compiler when the tail representation has the
canonical regular character; without that extra trace condition it may only
produce an irrelevant noncanonical representation.

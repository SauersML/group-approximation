**ESTABLISHED SYNTACTIC REDUCTION.**  Let `N_root` be the normal subgroup
generated by the split Steinberg roots and let `W_p in N_root` be the
conditional quarter-turn.  Consider the smallest HNN load row

```text
t W_p t^(-1)=g V,                                      (HRS1)
```

where `g` is a word in the external structural packet and
`V in N_root` is any finite root word.  In the root-kernel quotient,
`W_p=V=1`, so `(HRS1)` is exactly

```text
g=1.                                                    (HRS2)
```

The stable letter disappears from the residual condition.  Consequently:

* if `g=1` in the finite uniform-assignment/role model, that model extends
  with all roots trivial and `t` arbitrary, giving positive `B_f` and zero
  escape at zero defect;
* if `(HRS1)` excludes that model after the roots are killed, the exclusion
  is supplied entirely by the ordinary packet relator `g=1`, not by HNN
  transport.

The normalized-HS statement is equally direct.  For any unitary tuple,

```text
||g-1||_2
 <= ||t W_p t^(-1)-gV||_2+||W_p-1||_2+||V-1||_2.       (HRS3)
```

Thus a dimension-uniform payload floor obtained from `(HRS1)` near the root
kernel already gives the same floor, up to the displayed fixed constants,
for the residual literal packet word `g`.  The HNN letter supplies no new
payload sensitivity there.

In particular every homogeneous HNN row

```text
t W_p^a t^(-1)=W_p^b
```

retains the root-kernel retraction, as do finitely many such rows and rows
with additional killed root words.  A nonhomogeneous HNN attachment can
destroy the retraction only by inserting a packet word which is trivial in
the perfect `B_f=0` representation but has a robust defect on every
payload-positive finite matrix model.  Constructing that word is precisely
an ordinary-word nonlinear-predicate detector, i.e. the original
root-to-payload groupification gate in residual form.

This is not a no-go for a genuinely noncentral packet detector.  It proves
that the stable letter cannot manufacture one: after root substitution the
detector must already be visible as `g`.

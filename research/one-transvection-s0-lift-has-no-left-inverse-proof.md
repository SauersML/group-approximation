## Why sufficient

Artifact Section 1.

1. **Conjugated form.** Put `c = h^(-1) d h` and `Q = P_c = [h^(-1)]P[h]`. For `v in P S_- P`,
   `v P[h]P = v[h]QP`. So a left inverse gives `P = P x Q P` with `x = v[h]`.
2. **Projection.** `E : k[G] -> k[W]`, which keeps the coefficients on `W = <z, d, c>`, is a `k[W]`-bimodule map.
   `P`, `Q` and `eps_-` lie in `k[W]`, so `P = P x' Q P` with `x' = eps_- E(x) in S_-(W)`.
3. **Equivalent idempotent.** `alpha = P x' Q` and `beta = QP` satisfy `alpha beta = P`. So `e = beta alpha` is an
   idempotent equivalent to `P`, and `f = Q - e` is an idempotent.
4. **Residually finite.** `W` is a quotient of `C_2 x (C_2 * C_2)`, so it is virtually cyclic and residually finite.
5. **Counting.** Take a finite quotient `q : W -> K` injective on `supp(f) ∪ {1, z, d, zd, c, zc}`.
   - For `g in {d, c}`, `q(P_g)` is a primitive idempotent of `k[C_2 x C_2]`, and `k[K]` is free over that
     subalgebra. So `dim(q(P_g) k[K]) = |K|/4`.
   - Hence `dim(q(f) k[K]) = 0`, so `q(f) = 0`. By injectivity on `supp(f)`, `f = 0`, that is `e = Q`.
6. **Inverse.** `v' = P x' [h^(-1)] P` satisfies `v'Y = P`, and `Y v' = [h] beta alpha [h^(-1)] = [h] Q [h^(-1)] = P`.
7. **Corollary 2.**
   - Theorem A(2) of `two-piece-left-inverses-are-corner-left-inverses` turns a left inverse of
     `a = [u0]P0 + [u1]P1` into one of `Y_h`, with `h = u0^(-1) u1`.
   - With the inverse `v`, `b' = P0 - P0[h]P1 v + v` is a two-sided inverse of `b = P0 + [h]P1`, and
     `a^(-1) = b'[u0^(-1)]`.
8. **Lifts of s0.** `pi(a) = s0` is not a unit of `L_(F_3)(1,2)`, so `a` is not invertible. By Corollary 2 it is not
   left invertible.

**Independent check** (artifact Section 2). For `h = [[0,1],[-1,s0]]`, all chart entries of `z, d1, h, h^(-1)` lie
in the polynomial ring `F_3[s0]`.
- `s0 -> 0` gives a unital map `S_-(<z, d1, h>) -> M_2(F_3)` with `Y_h -> 0` and `P_(d1) -> diag(0,1)`.
- Projection onto `<z, d1, h>` as in step 2 then contradicts `v Y_h = P_(d1)`.

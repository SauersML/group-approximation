
`K_1(B)` and `K_0(B)` are both infinite cyclic, with `e_B` a generator of
`K_0(B)`.  If `v_0` generates `K_1(B)` and `[V] = m v_0`, then
`e_B = m Delta_gamma(v_0)`, so `m` divides `1` and `[V] = +- v_0`: `[V]`
generates, and `Delta_gamma` is an isomorphism.  The `K_0` component
vanishes because `gamma` fixes both vertex projections, and in any case
`K_0(B) = Z e_B` is generated by the unit, on which the reduced class of
any loop is zero.

Note this is exactly where the padding `u_2 = 2` earns its place: it is
what makes `K_0(B)` cyclic with `[q] = -e_B`, so a single edge action
already realises a unimodular value.

Notation is as in [[atomic-exponent-monoids-kill-monomial-kazhdan-subpairs]] and
[[monomial-origin-level-subpairs-cannot-certify-rank-three-cone]] (cited as (M0)–(M5)).  Throughout, `K0` is
salient, so `0 ∉ P`.  The proof of (M3) in the monomial node has three parts: a grading, the infinite atom
set, and the wreath quotient.  Only the grading used pointedness.  We separate it from the other two.

## (A1)

*Atoms lie in S and are permuted by H.*  `P` is generated by `S` as a semigroup, so an atom `m` is a sum
`s_1 + ... + s_r` with `s_i ∈ S`.  Since `m ∉ P + P`, `r = 1` and `m ∈ S`.  `H · S = S`, so each `σ ∈ H`
maps `P` bijectively onto `P` and `P + P` onto `P + P`.  So `σ` maps `X` onto `X`.

*The wreath quotient.*  This is the (M3) argument word for word, and it uses only `0 ∉ P` and `X ⊆ S`.
`J = F_q[P + P]` is an ideal of `F_q ⊕ F_q[P]`, because `P + (P + P) ⊆ P + P`, and
`F_q[P] · F_q[P] ⊆ J`.  So on the monoid `1 + M_3(F_q[P])`, which contains `Ũ` by (M0),

```text
φ(g) = (g - 1) mod M_3(J)  ∈  M_3(F_q[P] / J) = M_3(F_q[X])
```

is a homomorphism to an additive group, since `(1 + a)(1 + b) - 1 = a + b + ab` with `ab ∈ M_3(J)`.  It is
`H`-equivariant, because `H` preserves `P` and `P + P`.  `φ(e_ij(x^m)) = x^m E_ij` for `m ∈ X` and `0` for
`m ∈ P + P`.  Every `m ∈ X` lies in `S`, so `e_ij(x^m)` is a generator of `Ũ`, and the image of `Ũ` is all of
`⊕_(i ≠ j) F_q[X] E_ij`.  Keeping the `(1,2)` coefficient gives a surjection
`B = Ũ x| H ->> F_q[X] x| H = F_q wr_X H`, with `H` permuting `X`.

*Not Kazhdan.*  The cocycle `b(w) = 1_(wY) - 1_Y` on `Ω = X × F_q`, `Y = X × {0}`, of the monomial node shows
that `F_q wr_X H` is not Kazhdan when `X` is infinite (Cherix-Martin-Valette, Neuhauser).  Property (T) passes
to quotients, so `B` is not Kazhdan.  ∎

## (A2)

Suppose `P` is atomic and `X` is finite.  The kernel `H'` of the permutation action of `H` on `X` has finite
index.  `X` generates `P` and `k e_l ∈ S ⊆ P` for every `l`, so `X` spans `R^d`.  `H'` fixes a spanning set,
so `H' = 1` and `H` is finite.  So if `H` is infinite, `X` is infinite, and (A1) applies.  ∎

## (A3)

*Integral grading gives atomicity.*  Let `λ ∈ Hom(Z^d, Z)` be positive on `P`, so `λ(P) ⊆ Z_(≥1)`.  Induct on
`λ(m)`.  If `m ∈ P` is not an atom, `m = a + b` with `a, b ∈ P`.  Then `λ(a), λ(b) ≥ 1`, so both are
`< λ(m)`, and by induction both are finite sums of atoms.  So `m` is too.

*Rational lineality missing the orthant gives an integral grading.*  Let `L = K ∩ -K` be rational with
`L ∩ R_+^d = 0`.  `H` preserves `K0`, hence `K` and `L`.

1. Choose a rational complement `L'` of `L`.  Then `K = L ⊕ (K ∩ L')`, because `k - ℓ ∈ K` for `k ∈ K`,
   `ℓ ∈ L`.  `K' = K ∩ L'` is closed and pointed, since `K' ∩ -K' ⊆ L ∩ L' = 0`.  So the image `π(K)` of `K` in
   `V̄ = R^d / L` is a closed pointed cone with nonempty interior, because `K ⊇ R_+^d`.
2. Its dual cone in `V̄* = L^⊥` therefore has nonempty interior.  `L^⊥` is a rational subspace, so the interior
   contains a rational point.  Scale it to `λ̄`, integral on the lattice `π(Z^d)`.  Then `λ̄ > 0` on
   `π(K) \ 0`.  Put `λ = λ̄ ∘ π ∈ Hom(Z^d, Z)`.
3. Every `m ∈ P` is `Σ_i σ_i n_i` with `σ_i ∈ H` and `n_i ∈ N^d \ 0`.  Now `n_i ∉ L`, because
   `L ∩ R_+^d = 0`.  `L` is `H`-invariant, so `σ_i n_i ∉ L`, and `π(σ_i n_i) ∈ π(K) \ 0`.  Hence
   `λ(σ_i n_i) ≥ 1` and `λ(m) ≥ 1`.

When `K` is pointed, `L = 0` and this is the grading of (M3).  ∎

## (A4)

(A1)–(A3) are the contrapositives.  If `B` is Kazhdan and `H` is infinite, then `X` is finite by (A1).  Then
`P` is not atomic by (A2), and no integral `λ` is positive on `P` by (A3).  So either `L` is not rational, or
`L ∩ R_+^d ≠ 0`.  The finite-index kernel `H'` of `H` acting on `X` fixes `span X` pointwise.  If
`span X = R^d`, then `H' = 1`, which contradicts `H` infinite.

*Infinite order intervals.*  Take a non-atomic `m_1 ∈ P`, that is, one that is not a finite sum of atoms.  It
is not an atom, so `m_1 = a_1 + m_2` with `a_1, m_2 ∈ P`, and we can take `m_2` non-atomic, since otherwise
`m_1` would be a finite sum of atoms.  Iterating gives `m_1 - m_n ∈ P ∪ {0}` and `m_n ∈ P` for all `n`.  The `m_n`
are distinct: if `m_n = m_j` with `j < n`, then `a_j + ... + a_(n-1) = 0 ∈ P`, which contradicts `0 ∉ P`.

*The Galois candidate (remark, not used).*  For `H = Sym^2 SL_3(Z[√2])` in the basis of the monomial node,
`K0 \ 0` lies in `{ v : v_+ PSD, v_+ ≠ 0 }`.  The lattice is dense at the `+` place, so one expects `P + P = P`
and `X = ∅`.  We do not prove this.  That case is killed anyway by (N1)–(N3) of
[[galois-psd-monomial-subpair-has-no-infranormal-trace]], through infranormality.

## (A5)

`V = Z^3 ⊕ Sym^2 Z^3`, and `g ∈ SL_3(Z)` acts by `(a, X) ↦ (g a, g X g^T)`.

- *Basis.*  The vectors `(0, E_ii)`, `(0, P_ij)` with `P_ij = (e_i + e_j)(e_i + e_j)^T` form a basis of
  `0 ⊕ Sym^2 Z^3` (monomial node, PSD example).  Also `(e_i, 0) = (e_i, E_11) - (0, E_11)`.  So the nine vectors
  are a lattice basis.
- *Salient.*  A nonnegative combination of `h b_i` has PSD second component `Σ c_i g_i X_i g_i^T`, where every
  `X_i ≠ 0`.  That component vanishes only if every `c_i = 0`.  So `K0 \ 0 ⊆ R^3 × (PSD \ 0)`, which contains no
  line.
- *Lineality.*  `e_12(n)` maps `(e_2, E_11)` to `(e_2 + n e_1, E_11)`.  Divide by `|n|` and let `n → ±∞`.  This gives
  `±(e_1, 0) ∈ K`.  The `H`-orbit of `e_1` spans `R^3`, so `L ⊇ R^3 × 0`.  Also `K ⊆ R^3 × PSD` gives
  `L ⊆ R^3 × 0`.  So `L = R^3 × 0`, which is rational, and `L ∩ R_+^9 = 0` because every basis vector has a nonzero second component.
- *Kazhdan.*  `SL_3(Z)` is infinite and Kazhdan.

So this `H` has the cone geometry of (M5) and property (T), and (A3) and (A2) show that `B_(H,k)` is not Kazhdan.  ∎

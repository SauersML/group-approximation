Let `K` be a field, `G` a group generated by `g_1, ..., g_r`, `omega` the augmentation ideal of `K[G]`,
`X = (g_i - 1)^T`, and `rho` a Sylvester matrix rank function on `K[G]` that is not the augmentation rank.

1. `rho(X) > 0`, and `rho_omega(A) := rho(X A)/rho(X)` is a Sylvester rank function (the augmentation quotient).
2. **Fixed-point-free.** If `G` is perfect, then `omega = omega^2`, `rho_omega(X Z) = rho_omega(Z)` for every
   matrix `Z`, `rho_omega` is not the augmentation rank, and `max_i rho_omega(1 - [g_i]) >= 1/r`.
3. **Quasi-globality.** Let `Gamma = <S>` be finitely generated, `X_S = (s - 1)^T`, and suppose the compression
   semigroup `P_Gamma = { g : g Gamma g^-1 <= Gamma }` generates `G` and `Gamma` normally generates `G`. There is
   `m`, depending only on `(G, S)`, such that every Sylvester rank function `psi` on `K[G]` with
   `psi(X Z) = psi(Z)` for all `Z` satisfies `psi(X_S h Z) = psi(X_S Z)` for all `h` in `G` and
   `psi(X_S Z) >= psi(Z)/m` for every `Z`.

In a faithful regular rank ring, `rho_omega` is the normalized rank of the fixed-point-free quotient
`(1-f) sigma (1-f)` of `research/artifacts/two-root-defect-descent-gap-2026-09-12.md` Lemma 2.1, and part 3 with
constant `1` is globality. So part 2 is the class-(A) fixed-point-free normalization that
`research/artifacts/rank-gate-axiom-audit-2026-09-12.md` Remark 4.2 said was missing, and part 3 is globality up
to the factor `1/m`.

Notation as in the claim. `A` is a polynomial ring over a field, so `Pic(A) = 0`,
`A^* = F_q^*`, `R^* = F_q^* · {x^m}`, and unimodular frames over `A` extend to elements of
`SL_r(A)` (Quillen--Suslin).

## 1. Transvection criterion

"Only if" is clear. Conversely, let `h ∈ H` with `hE_ijh^(-1) ∈ M_r(A)` for all `i ≠ j`.
Pick `j ≠ i`. Then `hE_iih^(-1) = (hE_ijh^(-1))(hE_jih^(-1)) ∈ M_r(A)`. Conjugation by `h`
is `R`-linear, so `hM_r(A)h^(-1) ⊆ M_r(A)`. Applied to `h^(-1) ∈ H`, this gives
`Ad(h)(M_r(A)) = M_r(A)`. `Ad(h)` is an `A`-algebra automorphism of the Azumaya algebra
`M_r(A)`. Since `Pic(A) = 0`, Skolem--Noether gives `g ∈ GL_r(A)` with `Ad(g) = Ad(h)` on
`M_r(A)`, hence on `M_r(R) = M_r(A) ⊗_A R`. So `g^(-1)h = λI` with `λ ∈ R^*`, say
`λ = c x^m`. Then `1 = det h = det g · λ^r`, and `det g ∈ F_q^*`, so `x^(rm)` is constant,
`m = 0`, and `h = λg ∈ GL_r(A)`. Hence `h ∈ SL_r(A)`.

## 2. Zero-entry extraction

For `m ≠ n`,

```text
T e_mn(1) T^(-1) = I + (T e_m)(e_n^T T^(-1)) = I + (e_m + v_m u)(e_n − u_n v)^T.
```

Suppose `u_n = 0`. The element is `I + w e_n^T` with `w = e_m + v_m u`, and
`w_n = v_m u_n = 0`. Put `X = w e_n^T`. For `q ≠ n` pick `p ∉ {n, q}` (possible as
`r ≥ 3`). Then `X E_pq = 0`, `E_pq X = w_q E_pn`, and

```text
(I + X) e_pq(1) (I + X)^(-1) = I + E_pq − w_q E_pn = e_pq(1) e_pn(−w_q),
```

because `E_pq E_pn = E_pn E_pq = 0`. So `e_pn(−w_q) ∈ H`, and the content hypothesis gives
`w_q ∈ A`. Hence `δ_mq + v_m u_q ∈ A` for all `q ≠ n`. Since `u_n = 0` as well,
`v_m u ∈ A^r`.

The row statement is the transpose argument. If `v_m = 0`, then
`T e_mn(1) T^(-1) = I + e_m z^T` with `z = e_n − u_n v` and `z_m = 0`. For `p, q ≠ m`,
`p ≠ q`, conjugating `e_pq(1)` by it gives `e_pq(1) e_mq(z_p)`. So `z_p ∈ A` for `p ≠ m`,
and `u_n v ∈ A^r`.

## 3. Two-frame case

Let `c, c'` be the first two rows of `g ∈ SL_r(A)` with `c·u = c'·u = 0`. The conjugate
`gTg^(-1) = (gh)e_ij(1)(gh)^(-1)` has column vector `u' = gu` with `u'_1 = u'_2 = 0`, and
covector `v'^T = v^T g^(-1)`. Part 2 with `n = 1` gives `v'_m u' ∈ A^r` for `m ≠ 1`. With
`n = 2` it gives the same for `m ≠ 2`. So `u'v'^T ∈ M_r(A)`, and
`uv^T = g^(-1)(u'v'^T)g ∈ M_r(A)`. If instead two columns of some `g^(-1) ∈ SL_r(A)` are orthogonal to `v`, the row statement of part 2 gives the same conclusion. Scaling `u` by
a monomial and `v` by its inverse leaves `T` unchanged, so `Syz(u)` may be computed after
clearing denominators.

## 4. The residual class, and what Mon does to it

For `r = 3` and `u = (x_1, x_2, x_3)`, `Syz(u)` is generated by the Koszul relations, whose
entries lie in the maximal ideal `(x_1,x_2,x_3)`. So no syzygy is unimodular and part 3
does not apply. In any rank `r`, take `u` to be `r` distinct monomials of one degree
`k ≥ r − 1` in `x_1, x_2`. They minimally generate a homogeneous ideal, and a unimodular
syzygy `c` would give `c(0)·u ≡ 0` modulo `m·(u)` with `c(0) ≠ 0`, contradicting graded
Nakayama.

The compressors can move `u` out of this class. For `P = I + kE_21`, `P·x_1 = x_1x_2^k` is
divisible by `P·x_2 = x_2`. Then `P·u = (x_1x_2^k, x_2, x_3)` has the unimodular syzygy
`(1, −x_1x_2^(k−1), 0)`. A second compressor `I + lE_32` makes a second zero. Since
`P·T = (P·h)e_ij(1)(P·h)^(-1) ∈ H`, part 3 then gives `P·(uv^T) ∈ M_r(A)` for all such
`P`. **This is exactly where the argument stops.** `P·f ∈ A` does not imply `f ∈ A`
(`P·(x_1x_2^(-1)) = x_1x_2^(k−1)`). The exponents it certifies form the cone
`∩_P P^(-1)(N^d)` over the compressors used. It is strictly larger than `N^d`: for
`P = I + kE_21`, `P^(-1)(N^d) = {w ≥ 0 off index 2 : w_2 + k w_1 ≥ 0}` contains
`(1, −1, 0, …)`. (For the second step, `Q = I + lE_32` gives
`QP·u = (x_1x_2^k x_3^(kl), x_2x_3^l, x_3)`, whose syzygies
`(1,0,−x_1x_2^k x_3^(kl−1))` and `(0,1,−x_2x_3^(l−1))` are rows of an elementary matrix.) To close the
kernel claim one needs compressors that create two zeros in `P·u` and whose cone
`∩ P^(-1)(N^d)` is exactly `N^d`. Alternatively one needs a device that transfers
polynomiality from `P·Y` back to `Y`. ∎

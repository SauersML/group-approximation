## Why sufficient

Since a kernel is normal and `D(H,L)` is the normal closure of its displayed
generators, it suffices to show `rho(u) = 1` for one generator

    u = [ g z g^{-1}, l ],    g in G_comp(L),  z in C_H(L),  l in L.

Write `g = s_1^{e_1} ... s_m^{e_m}` with each `s_i in Comp(L)` and
`e_i = +-1`.  Set

    K = < z, l, s_1, ..., s_m >  <=  H,        L_0 = L n K.

*Each `s_i` compresses `L_0` inside `K`.*  For `a in L_0`: `s_i a s_i^{-1}`
lies in `L` because `s_i` compresses `L` and `a in L`, and it lies in `K`
because `s_i` and `a` do.  Hence `s_i L_0 s_i^{-1} <= L n K = L_0`.  So each
`s_i` is a compressor for the pair `(K, L_0)` and therefore
`g in G_comp^K(L_0)`.

*The other two ingredients survive the restriction.*  `z` centralizes `L_0`
because `L_0 <= L`, and `z in K`; and `l in L n K = L_0`.  Therefore `u` is a
displayed defect generator for the pair `(K, L_0)`, i.e. `u in D(K, L_0)`.

*Now shrink the ring.*  Let `E` be the division subring of `D` generated by
the finite set `{ rho(z), rho(l), rho(s_1), ..., rho(s_m) }`.  Weak local
finiteness makes `E` centrally finite.  Since `K` is generated by
`z, l, s_1, ..., s_m`, we have `rho(K) <= E^x`.  Apply the prerequisite to
the homomorphism `K -> E^x` and the subgroup `L_0 <= K`: it kills
`D(K, L_0)`, so `rho(u) = 1`.

## The one step worth reading twice

Passing from `L` to `L_0 = L n K` is not cosmetic.  The defect is defined
relative to a pair, and shrinking the ambient group could in principle destroy
either the compression property or the centralizing property.  Both survive,
for the reasons above, and that is exactly what makes the local-to-global
reduction legitimate.

## Corollary recorded on the target

If `D(H,L) != 1` then `H` embeds in the multiplicative group of no weakly
locally finite division ring, and `K[H]` embeds in no such division ring for
any field `K`.  Immediate: a faithful embedding would be a homomorphism with
trivial kernel, contradicting the claim.

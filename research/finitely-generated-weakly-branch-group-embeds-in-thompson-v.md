**OPEN** (stated positively; the source expects a negative answer). C. Bodart,
D. D'Angeli, D. Perego and E. Rodaro, *A graph-theoretical characterisation of
subgroups of Thompson's group V*, arXiv:2608.02111v1 (3 Aug 2026), TeX
`Sections/sec7_branch.tex` l.133–135:

> Does any (weakly) branch group embed in Thompson's $V$?

**The authors' context** (l.130, l.150–153):
- Infinite finitely generated torsion groups and groups of intermediate growth do not
  embed in `V`.
- Their Theorem `thm:big_loops` excludes weakly branch groups `G` such that each
  `RStab_G(ℓ)'` is finitely generated, `G` has no free subgroup, and no orbital Schreier
  graph is a quasi-tree. This gives the corollary that the Basilica group does not embed.
- They add: "A positive answer to either question would prove that Thompson's V does
  not contain any finitely generated branch subgroup."

**Lane remark: the literal reading is answered, so the node is the finitely generated
case.** Without finite generation the answer is yes.
- Let `T` be the rooted binary tree, and `Fin(T)` the group of finitary automorphisms:
  those acting trivially below some level.
- Each element acts on `∂T = {0,1}^N` by `uξ ↦ π(u)ξ` for `|u| = n` and a permutation
  `π` of `{0,1}^n`. That is a prefix replacement, so `Fin(T) ≤ V`.
- `Fin(T)` is level-transitive.
- `Fin(T) = rist(n) ⋊ Aut(T_n)`, where `rist(n) = ∏_{|v|=n} Fin(T_v)`. So every
  `rist(n)` has finite index, and `Fin(T)` is a (locally finite) branch group.
- Conversely, a *finitely generated* subgroup of `V` that acts on the standard tree by
  automorphisms is finite: `Aut(T) ∩ V = Fin(T)`, and `Fin(T)` is locally finite. So a
  finitely generated example must carry a branch structure on some other tree.

**Constraints on a finitely generated example** (lane observations, unproved beyond what
is cited):
- It must contain a non-abelian free subgroup, or else fail the other hypotheses of
  `thm:big_loops`.
- It is residually finite, so it contains no infinite simple subgroup.
- Its `V`-action cannot preserve any separating nested sequence of clopen partitions.
  Otherwise the action would be equicontinuous. Infinite-order elements of `V` have
  attracting points, which is recalled here, not re-read. Then `G` would be torsion,
  which is excluded.

## Attempts

**Attempt 1 (bh-branch-in-v, 2026-09-18).** This reduces the question and settles one class. It does not decide the question.

- **Missed prior result.** The source itself already closes one class. In the remark just before its second question, BDPR combine Matte Bon–Nekrashevych–Zheng (arXiv:2607.13776, Theorem B) with their own results on context-free graphs of linear growth. That excludes every contracting self-replicating branch group from `V`. The context above did not record this.
- **Reduction (new; lane proof, unreviewed).** Recorded in `branch-group-embeddings-in-v-are-boundary-sandwiched`.
  - A finitely generated branch group `G` embeds in `V` exactly when some subgroup `H ≤ G_ξ` of a boundary-point stabilizer has a context-free Schreier graph. `H` can then be chosen sandwiched, `⊕_{v∈N(ξ)} K_v ≤ H`.
  - The same holds for non-elementary-amenable weakly branch groups with finitely generated `rist(n)`, via `multi-ended-branch-actions-are-boundary-sandwiched`.
  - So the question is about the groups' own boundary orbital graphs, not about `V`.
- **Settled class.** With finite groups of germs, the sandwiched `H` has finite index in `G_ξ`. An embedding therefore forces an exponential-growth boundary orbit. Hence no finitely generated branch group generated by a bounded automaton embeds in `V`, whether self-replicating or not. The same holds for polynomial activity with finite germs.
- **Recovered and refined.**
  - The Hanoi and Basilica corollaries are recovered.
  - The node's first constraint above is sharpened, for branch examples and for weakly branch ones with finitely generated `rist(n)` that are not elementary amenable: an example must have a boundary-sandwiched context-free Schreier graph of exponential growth; with finite germs this is a finite cover of a boundary orbit. Weakly branch groups without finitely generated `rist(n)` are not covered.
- **Where to look next.**
  - For a positive answer: non-contracting branch groups whose boundary orbital graphs are tree-like of exponential growth. By (b) of the reduction node, any such group embeds.
  - For a negative answer, (a) of the same node reduces the question to showing that no boundary-sandwiched Schreier graph of a finitely generated branch group is context-free.

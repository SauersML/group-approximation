**ESTABLISHED.**  Consider a finite packet/selector attempt to
make one relation between two stable-letter intertwiners vacuous on allowed
BCS assignment sectors and obstructed on forbidden sectors.

If the closed loop is required to equal one literal central packet word on
every representation above a selector character, then its sign as a function
of the selector is affine.  It cannot isolate an arbitrary nonlinear BCS
predicate.  This is `controlled-central-phase-finite-group-barrier` applied
to the loop return.

The Schur construction is the sharp finite-packet escape: the packet
implementers carry a type-dependent projective commutator rather than one
universal scalar group word.  It can detect the nonlinear forbidden sectors,
but the external multiplicity intertwiners carry the inverse cocycle.  One
binary cell forces only parity; finite cocycle rank `2r` forces only the
divisor `2^r`.  The marked regular representation and a fixed amplification
contain the inverse projective modules exactly.

Therefore the two finite alternatives are

```text
literal scalar return       -> affine predicate only,
nonlinear projective return -> fixed multiplicity divisor only.       (SPD1)
```

Neither yields a positive normalized-HS escape fraction from one selected
Reynolds atom.  A proposal outside `(SPD1)` must use data not contained in a
finite packet projective groupoid: an additive multi-path interference block,
an unbounded/self-renewing cocycle rank, or a payload-sensitive proper-corner
relation.

**Item 1 (the lemma).** Choose one vertex `v_1, ..., v_k` from each vertex
orbit. Every edge orbit contains an edge with an endpoint in `{v_i}`, because
an edge `[x, y]` with `x = g v_i` is carried by `g^-1` to `[v_i, g^-1 y]`. For
each of the finitely many edge orbits `ε` fix such a representative
`[v_(i(ε)), a_ε v_(j(ε))]`, with `a_ε ∈ G`. Let `H` be generated by the
stabilizers `G_(v_1), ..., G_(v_k)` and the elements `a_ε`. It is finitely
generated.

Let `W = H·{v_1, ..., v_k}`. We claim that `W` contains every neighbour of each
of its vertices. Let `x = h v_i ∈ W` and let `y` be adjacent to `x`. The edge
`[v_i, h^-1 y]` lies in some orbit `ε`, so
`g [v_(i(ε)), a_ε v_(j(ε))] = [v_i, h^-1 y]` as unoriented edges, for some
`g ∈ G`. There are two cases.
- `g v_(i(ε)) = v_i`. Then `i(ε) = i`, since representatives of distinct
  orbits are distinct, and `g ∈ G_(v_i) ⊆ H`. So
  `h^-1 y = g a_ε v_(j(ε)) ∈ W`.
- `g a_ε v_(j(ε)) = v_i`. Then `j(ε) = i` and `g a_ε ∈ G_(v_i)`, so
  `g ∈ H a_ε^-1 = H`. So `h^-1 y = g v_(i(ε)) ∈ W`.

In both cases `y = h (h^-1 y) ∈ W`. Since `X` is connected, `W` is the whole
vertex set. Now let `g ∈ G`. Then `g v_1 = h v_i` for some `h ∈ H` and some `i`,
and `i = 1`. So `h^-1 g ∈ G_(v_1) ⊆ H`, hence `g ∈ H` and `G = H`.

**Item 2.** For a prime `q`, let `o_q ∈ T_q` be as in item 3. Finitely many
elements of `PGL_2(Q)` lie in the image of `GL_2(Z_q)` for all but finitely many
`q`, because their entries have finitely many primes in their denominators and
determinants. So they fix `o_q` for all but finitely many `q`, and so does the
subgroup they generate. But `e_12(1/q) = [[1, 1/q], [0, 1]]` does not fix
`o_q`. It has determinant 1, and `e_12(1/q) Z_q^2 = λ Z_q^2` would force
`λ ∈ Z_q^x` and `e_12(1/q) ∈ GL_2(Z_q)`, which is false.

So no finitely generated subgroup of `PGL_2(Q)` contains the images of all the
`e_12(1/q)`. The same argument applies to `GL_n(Q)`, `SL_n(Q)`, `PGL_n(Q)` and
`PSL_n(Q)`, using the building of `SL_n(Q_q)` and `e_12(1/q)`. It applies to
`(Q,+)`, `Aff(Q)`, `B_2(Q)` and `U_3(Q)`, using their elementary unipotents
`e_12(1/q)` in `GL_2` or `GL_3`. So none of these groups is finitely generated.
The rest of item 2 follows from item 1.

**Item 3.** Vertices of `X` correspond to Z-lattices in `Q^2` up to
multiplication by `Q^x`. A lattice `L` goes to the classes of `L ⊗ Z_(p)`; the
inverse sends `(x_p)` to `∩_p L_p` for representatives `L_p` with
`L_p = Z_(p)^2` whenever `x_p = o_p`. `GL_2(Q)` acts coordinatewise.

- **Stabilizers.** `gL = λL` gives `λ^-1 g ∈ GL(L)`. So the stabilizer of `[L]`
  is `Q^x·GL(L)` in `GL_2(Q)`, with image `PGL(L) ≅ PGL_2(Z)` in `PGL_2(Q)`. If
  `det g = 1`, then `λ^2 = ±1`, so `λ = ±1` and `g ∈ SL(L)`.
- **PGL_2(Q) orbits.** `GL_2(Q)` is transitive on lattices, so `PGL_2(Q)` is
  transitive on vertices. An edge changes exactly one coordinate `p` by one
  step of `T_p`. Since the action is coordinatewise, this direction `p` is
  invariant. The edges in direction `p` at `o` join `o` to the `p+1`
  neighbours of `o_p` in `T_p`, which correspond to `P^1(F_p)`.
  `PGL_2(Z)` acts on them through reduction mod `p`, and its image contains
  `PSL_2(F_p)`, the image of `SL_2(Z) -> SL_2(F_p)`, which is surjective and
  transitive on `P^1(F_p)`. Since the action is vertex-transitive, every edge
  is a translate of an edge at `o`. So there is exactly one edge orbit for each
  prime.
- **SL_2(Q) orbits.** Write `L = B Z^2` with `B ∈ GL_2(Q)`, and set
  `δ(L) = det B`. Its class in `Q^x/{±1}(Q^x)^2` is unchanged by a change of
  basis (a factor `±1`), by scaling `L` (a factor `λ^2`) and by `SL_2(Q)`
  (a factor 1). This group is identified with the squarefree positive
  integers, so `δ` is an invariant of `SL_2(Q)`-orbits of vertices. The
  lattice `Z ⊕ cZ` realizes the class `c`.

  Conversely, suppose `δ(L) ≡ δ(L')`. Write `det B' = ε λ^2 det B` with
  `ε = ±1` and `λ ∈ Q^x`. Put `k = diag(ε, 1)` and
  `g = λ^-1 B' k B^-1`. Then `det g = 1` and `gL = λ^-1 L'`, so `[L]` and
  `[L']` are in one orbit. Hence the orbits correspond bijectively to the
  squarefree positive integers.

  Edge directions are invariant here too, so there are infinitely many edge
  orbits. The valence of each vertex is `Σ_p (p+1) = ∞`.

**Consequence paragraph.** For a finite set `S` of primes, the finite
subcomplexes supported on `S` have fundamental groups `SL_2(Z[1/S])`. This is
Steps 1--5 of `sl-n-q-is-colimit-of-lattice-stabilizers-proof`. Each such
group is finitely generated and linear over the number field `Q`, so it lies
in `B_A` by `fp-self-similar-subgroups-satisfy-permutational-boone-higman`.

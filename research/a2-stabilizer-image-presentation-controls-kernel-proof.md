Fix a finite presentation `<X | R_G>` of `G`. Words are words in `X^(±1)`. Let
`π : G -> Q = G/K`, and for `s in S` let `H_s = Stab_G(s)`, which is finitely
generated by type `[A_2]`. Since `K` fixes every point, `K <= H_s` and
`Stab_Q(s) = π(H_s) = H_s/K`.

**Input.** By part (a) of `a2-kernel-removal-forces-recursive-kernel`, membership
of a word in `K` is co-r.e.: a word is not in `K` exactly when it moves some
point, and the action is computable from the finite type `[A_2]` data.

**Item 1.**
- *`K` recursive ⇒ solvable word problem.* A word represents `1` in `Q` exactly
  when it lies in `K`.
- *Solvable word problem ⇒ recursively presented.* Take as relators all words
  equal to `1` in `Q`. That set is recursive.
- *Recursively presented ⇒ `K` recursive.* If `Q = <π(X) | T>` with `T`
  r.e., the words equal to `1` in `Q` are the consequences of `T`, an r.e. set.
  That set is `K`. With the Input, `K` is both r.e. and co-r.e., so recursive.

**Item 2.** Let `Y` be a finite generating set of `H_s`, written as words in
`X`. Finite presentability of a finitely generated group does not depend on the
finite generating set (Tietze), so `Stab_Q(s) = <π(Y) | R>` for a finite set `R`
of words in `Y^(±1)`. Let `F(Y)` be free on `Y`, with `F(Y) -> H_s -> Stab_Q(s)`.
The kernel of the composite is the normal closure of `R` in `F(Y)`. Its image in
`H_s` is the kernel of `H_s -> Stab_Q(s)`, which is `K`, because `F(Y) -> H_s` is
onto. The image of a normal closure under an onto map is the normal closure of
the image, so

```text
K = <<R_H>>_(H_s),   R_H = images of R in H_s.
```

Then `K <= <<R_H>>_G <= K`: the first inclusion because `H_s <= G`, the second
because `R_H <= K` and `K` is normal in `G`. So `K = <<R_H>>_G`, and
`Q = <X | R_G ∪ R_H>` is finitely presented, each element of `R_H` rewritten as
a word in `X`.

Now `Q ↷ S` is faithful. Its point stabilizers `π(H_t)` are finitely generated.
Its orbits on `S × S` are the `G`-orbits, finitely many. So it is of type
`(A_2)`. The image `Q` therefore embeds in a group admitting a type `(A_2)`
action, namely itself, and `a2-kernel-removable-iff-image-in-type-a2-actor`
gives the sharp embedding of `(G, K)` into a type `[A_2]` pair with finitely
normally generated kernel. By item 1, `K` is recursive, since `Q` is finitely
presented.

**Item 3.** This is the contrapositive of items 1 and 2.

**Item 4.** Let `Γ <= G` be generated by finitely many words. A word in those
generators is trivial in `Γ` exactly when it is trivial in `G`, which is r.e.
because `G` is finitely presented. Since `Γ ∩ K = 1`, it is nontrivial exactly
when it acts nontrivially on `S`, which is r.e. by the Input. So the word
problem of `Γ` is decidable. (For twisted Brin--Thompson groups this is the
remark of FFWZ, Section 5, that any group sharply embedding in `SV_G` has
solvable word problem.) `∎`

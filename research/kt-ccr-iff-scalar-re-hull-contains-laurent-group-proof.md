Notation is that of the target.  A *canonical CE actor model* is a CE
finite tracial von Neumann algebra `(P, tau)` with unitaries `u_g`,
`g in G`, such that `tau(u_g) = delta_(g,1)`.  By
`relative-embedding-is-commutant-separation` (verbatim: "For a hyperlinear
`A`, intersecting the commutation stabilizers of all `C`-central
projections in all canonical CE actor models gives the least intermediate
subgroup `K_C` with scalar relatively embeddable inclusion into `A`"),
`K_C` is that intersection, is scalar-RE, and is contained in every
scalar-RE `J` with `C <= J <= G`.

## Step 0. Two formal properties of `C -> K_C`

(a) *Equivariance:* `K_(g C g^(-1)) = g K_C g^(-1)` for `g in G`.  If `p`
is `C`-central in a canonical model `(P, u)`, then `u_g p u_g^*` is
`gCg^(-1)`-central in the same model, with commutation stabilizer
`g Stab(p) g^(-1)`.  Running this with `g^(-1)` gives the reverse
inclusion.

(b) *Monotone and idempotent:* if `C <= D` then every `D`-central
projection is `C`-central, so `K_C <= K_D`.  Also `K_(K_C) = K_C`, because
`K_C` is scalar-RE and `K_(K_C)` is the least scalar-RE subgroup
containing `K_C`.  Both properties are stated in
`relative-embedding-is-commutant-separation` ("The map `C -> K_C` is
extensive, monotone, and idempotent").

## Step 1. `CCR(sigma,t)` for all `sigma` iff `Gamma <= K_(Lambda_t)`

Put `Lambda = Lambda_t`.  Since `Lambda <= Gamma` we always have
`sigma(Gamma)' cap M <= sigma(Lambda)' cap M`, so failure of `CCR` means
some `x in sigma(Lambda)' cap M` does not commute with some
`sigma(gamma)`, `gamma in Gamma`.

*Failure gives `Gamma` not in `K_Lambda`.*  One of the self-adjoint parts
`h` of `x` still fails to commute with `sigma(gamma)`, and `h` commutes
with `sigma(Lambda)`.  Let `(p_k)` be the spectral projections
`1_((-inf, a])(h)`, `a` rational.  They lie in the von Neumann algebra
generated by `h`, hence commute with `sigma(Lambda)`.  A unitary commutes
with `h` exactly when it commutes with every `p_k`, so some `p_k` does
not commute with `sigma(gamma)`.  Let `P` be the von Neumann subalgebra
of `M` generated by `sigma(G)` and `h`.  It is separable and sits inside
a tracial matrix ultraproduct, so it is CE.  Trace-faithfulness makes
`(P, sigma)` a canonical CE actor model.  The projection `p_k` is
`Lambda`-central there and is moved by `gamma`.  So
`gamma notin K_Lambda`.

*`Gamma` not in `K_Lambda` gives a failure.*  Pick `gamma in Gamma` not in
`K_Lambda`.  By the definition of `K_Lambda` as an intersection, there are
a canonical CE actor model `(P, u)` and a `Lambda`-central projection `p`
with `[p, u_gamma] != 0`.  Replace `P` by the separable subalgebra
generated by `u(G)` and `p`.  Being CE, it has a trace-preserving
embedding `iota` into a tracial matrix ultraproduct `M`.  Trace-preserving
maps are injective, so `sigma = iota o u` is trace-faithful,
`x = iota(p) in sigma(Lambda)' cap M`, and
`[x, sigma(gamma)] = iota([p, u_gamma]) != 0`.  So `CCR(sigma, t)` fails.

By Step 0(a), `K_Lambda = t K_Gamma t^(-1)`, so
`Gamma <= K_Lambda` iff `t^(-1) Gamma t <= K_Gamma`.  This is item 1.

*Wreath form.*  If `Gamma` is not in `K_Lambda`, then `K = K_Lambda` is
scalar-RE with `Lambda <= K` and `Gamma` not in `K`.  Conversely, any
scalar-RE `K >= Lambda` not containing `Gamma` has `K_Lambda <= K`, hence
`Gamma` not in `K_Lambda`.  By
`binary-free-and-ordinary-coset-wreaths-share-hyperlinearity` (items 1
and 6: the ordinary binary coset wreath over `C <= A` is hyperlinear iff
`L(C) <= L(A)` is relatively embeddable over the scalars), scalar-RE of
`K` is hyperlinearity of `W_K`.  This gives the wreath form of item 1.

## Step 2. The good set is a monoid

Let `S = {s in G : s^(-1) Gamma s <= K_Gamma}`.  If `s in S`, Step 0
gives

```text
s^(-1) K_Gamma s = K_(s^(-1) Gamma s) <= K_(K_Gamma) = K_Gamma .
```

Conversely `s^(-1) K_Gamma s <= K_Gamma` implies `s^(-1) Gamma s <= K_Gamma`.
So `S = {s : s^(-1) K_Gamma s <= K_Gamma}`, which contains `1` and is
closed under products: `(s_1 s_2)^(-1) K_Gamma (s_1 s_2)` is contained in
`s_2^(-1) K_Gamma s_2`, which is contained in `K_Gamma`.  This is item 2.
With Step 1, the compressors satisfying universal (CCR) are exactly the
strict compressors in `S`.

## Step 3. Conjugate cones generate `E`

**Lemma.**  Let `T` be a set of strict compressors and let `H` be the
subgroup generated by `Gamma` and all `t^(-1) Gamma t`, `t in T`.  If the
additive monoid generated by `N^d` and the sets `alpha(t)^(-1) N^d`,
`t in T`, is all of `Z^d`, then `H = E`.

*Proof.*  `H <= E` because `E` is normal and contains `Gamma`.  Since
`t^(-1) e_ij(c x^v) t = e_ij(c x^(alpha(t)^(-1) v))`, the subgroup
`t^(-1) Gamma t` contains `e_ij(c x^u)` for every `u in alpha(t)^(-1) N^d`,
every `i != j` and every `c in F_q`.  Let `Q` be the set of `u in Z^d`
such that `e_ij(c x^u) in H` for all `i != j` and all `c`.  Then `Q`
contains `N^d` and each `alpha(t)^(-1) N^d`.  It is closed under addition:
given `u, w in Q` and `i != k`, choose `j` different from `i` and `k`
(possible since `r >= 3`).  Then

```text
[e_ij(c x^u), e_jk(x^w)] = e_ik(c x^(u+w))
```

lies in `H`.  So `Q = Z^d`.  Every `f in F_q[Z^d]` is a finite sum of terms
`c x^u` and `e_ij` is additive, so `e_ij(f) in H`.  These generate
`E = EL_r(F_q[Z^d])`.  QED

**The finite set.**  For `alpha = I + E_ij` (nonnegative, determinant 1,
not a permutation) we have `alpha^(-1) = I - E_ij`, whose `j`-th column is
`e_j - e_i`.  For `B = [[1,2],[1,3]] (+) I_(d-2)` (nonnegative, determinant
`3 - 2 = 1`, not a permutation) we have `B^(-1) = [[3,-2],[-1,1]] (+) I_(d-2)`,
whose second column is `-2 e_1 + e_2`.  The monoid generated by these
columns and `N^d` contains

```text
(-2 e_1 + e_2) + (e_1 - e_2) = -e_1,   and then   -e_1 + (e_1 - e_i) = -e_i .
```

Here `e_1 - e_2` is column 1 of `I - E_21`, and `e_1 - e_i` is column 1 of
`I - E_i1`.  Together with `N^d` this gives all of `Z^d`.

## Step 4. Items 3 and 4

If `E <= K_Gamma`, then for every strict compressor `t` we have
`t^(-1) Gamma t <= E <= K_Gamma`, since `E` is normal, and Step 1 gives
universal (CCR).  Conversely, suppose universal (CCR) holds for the
`d(d-1) + 1` compressors of Step 3.  Step 1 puts each `t^(-1) Gamma t`
inside `K_Gamma`, so the Lemma gives `E = H <= K_Gamma`.  This proves item
4 and the first equivalence of item 3.

`K_Gamma` is the least scalar-RE subgroup containing `Gamma`.  So
`E <= K_Gamma` holds exactly when every scalar-RE `K >= Gamma` contains
`E`.  By the wreath equivalence cited in Step 1, that says every `W_K`
with `Gamma <= K` and `E` not in `K` is non-hyperlinear.  QED

## Remarks

- The Kun--Thom wreath is non-hyperlinear exactly when `K_Gamma != Gamma`.
  Universal (CCR) asks for the much stronger `K_Gamma >= E`.  Between the
  two lie all the intermediate subgroups missing `E`, for example the
  cone subgroups `EL_r(F_q[C]) rtimes Stab_(SL_d(Z))(C)` for proper
  submonoids `N^d <= C < Z^d`, and the ascending
  HNN subgroups `<Gamma, t>`.  Each of them must fail scalar RE for (CCR)
  to hold.
- If `W_E` is hyperlinear, then `E` is scalar-RE and so `K_Gamma <= E`,
  i.e. universal (CCR) becomes `K_Gamma = E`.  This is not used.  (`W_E`
  embeds in `(Z/2 wr SL_d(Z)) x G` via `(f, g) -> ((f, gE), g)`, which
  would give hyperlinearity from soficity of the two factors.)
- Nothing in Steps 0--2 uses property (T), infranormality or the
  Kun--Thom ring.  Step 3 uses only `r >= 3` and the exponent-monoid
  description of `Gamma`.  So the analytic content of
  `approximate-collapse-for-kt-compressor` lies entirely in deciding
  scalar RE for the intermediate lattice.

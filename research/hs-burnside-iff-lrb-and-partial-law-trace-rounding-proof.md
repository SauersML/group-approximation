**Conventions.** `tr` is the normalized trace and `||a||_2 = tr(a* a)^(1/2)`.
`T2(m,N)` is statement 2 of
`hyperlinear-bounded-exponent-trace-rigidity-iff-finiteness`: every limit trace
of an approximate exponent-N model factors through a finite quotient of `F_m`.
That claim gives `HB(m,N) <=> T2(m,N)`. Everything below is for fixed
`m, N >= 2`.

## Two elementary facts

**(F1) Limit traces are normalized, positive definite, class functions that are
`1` on `N`-th powers.** Let `u^(k)` be an approximate exponent-N model with limit
trace `tau`. Since `F_m` is free, `w ↦ w(u^(k))` is a unitary representation of
`F_m`. For words `w_1, ..., w_n` and scalars `c_i`,
`sum_{i,j} conj(c_i) c_j tr(w_i^{-1} w_j (u^(k))) = tr(A* A) >= 0` with
`A = sum_j c_j w_j(u^(k))`. Also `tr (v w v^{-1})(u^(k)) = tr w(u^(k))` and
`tr e(u^(k)) = 1`. These properties pass to the pointwise limit `tau`. Finally
`|tr h(u^(k))^N - 1| <= ||h(u^(k))^N - I||_2 -> 0`, so `tau(h^N) = 1` for every
`h in F_m`.

**(F2) A residually finite group all of whose finite quotients have order
`<= C` has order `<= C`.** Suppose `Γ` is residually finite with `C + 1`
distinct elements `g_0, ..., g_C`. For each pair `a < b`, pick a finite quotient
in which `g_a^{-1} g_b` survives. The intersection of these finitely many kernels
is a normal subgroup of finite index, since the quotient embeds in a finite
product. The `g_a` stay distinct modulo it, so that finite quotient has order
`>= C + 1`.

## (a) HB(m,N) implies LRB(m,N)

Suppose `LRB(m,N)` fails. Clause 3 of
`local-restricted-burnside-iff-lef-burnside-groups-are-finite` gives finite marked
groups `(Q_n; s^(n))` whose words of length `<= n` satisfy `h^N = 1`, converging
in the space of marked groups to an infinite group `L = F_m / K`.

1. **An eventually exact model.** Let `λ_n` be the left regular representation
   of `Q_n` and put `u^(n)_i = λ_n(s^(n)_i)`, unitary of dimension `|Q_n|`. For
   a fixed word `w`, once `n >= |w|` we have `w(u^(n))^N = λ_n(w(s^(n))^N) = I`.
   So `||w(u^(n))^N - I||_2 -> 0`.
2. **Its trace.** `tr λ_n(g) = 1` if `g = 1` and `0` otherwise. Marked
   convergence means that for each `w`, eventually `w(s^(n)) = 1` iff `w in K`.
   So `tr w(u^(n)) -> tau(w) = 1_K(w)`, and `u^(n)` is an approximate
   exponent-N model.
3. **Contradiction.** By `HB(m,N) => T2(m,N)`, `tau = s o p` for a homomorphism
   `p: F_m -> Q` with `Q` finite. If `p(w) = 1`, then
   `tau(w) = s(1) = tau(e) = 1`, so `w in K`. Hence `ker p ⊆ K`, and `L` is a
   quotient of the finite group `p(F_m)`. This contradicts `L` infinite.

## (b) HB(m,N) implies S(m,N,R) for every R

Let `tau` be a limit trace. By `T2(m,N)`, `tau = s o p` with `p: F_m -> Q`. We
may replace `Q` by `p(F_m)` and assume `p` surjective.

1. **`s` is a normalized positive-definite class function on `Q`.** Every finite
   family in `Q` and every conjugation lifts through `p`, so (F1) passes to `s`.
2. **Character expansion with nonnegative weights.** By the GNS construction,
   `s(g) = <π(g) ξ, ξ>` for a unitary representation `π` of `Q` and a unit vector
   `ξ`. For an irreducible `σ` let
   `P_σ = (dim σ / |Q|) sum_g conj(χ_σ(g)) π(g)`, the orthogonal projection onto
   the `σ`-isotypic part of `π`. Since `s` is a class function,
   `s = sum_σ a_σ χ_σ` with
   `a_σ = (1/|Q|) sum_g s(g) conj(χ_σ(g)) = <P_σ ξ, ξ> / dim σ >= 0`. Put
   `c_σ = a_σ dim σ = ||P_σ ξ||^2`. Then
   `s = sum_σ c_σ χ_σ / χ_σ(1)`, with `c_σ >= 0` and `sum_σ c_σ = s(e) = 1`.
3. **The weighted irreducibles obey the exponent law.** Fix `h in F_m` and put
   `g = p(h^N)`. By (F1), `1 = tau(h^N) = sum_σ c_σ χ_σ(g)/χ_σ(1)`. Each
   `χ_σ(g)/χ_σ(1)` is the normalized trace of a unitary matrix, so it has
   modulus `<= 1`, with real part `1` only when `σ(g) = I`. A convex combination
   equal to `1` forces `σ(g) = I` whenever `c_σ > 0`. So for each such `σ`,
   `σ o p` kills every `N`-th power and factors through `B(m,N)`, hence through
   `Π_R(m,N)` for every `R`: the normal subgroup `N_R` is generated by some of
   those powers.
4. **Rounding the weights.** For an integer `L`, put
   `ρ_L = ⊕_σ (σ o p)^{⊕ a_σ(L)}` with `a_σ(L) = floor(c_σ L / dim σ)`, over the
   `σ` with `c_σ > 0`. Its degree `D_L = sum_σ a_σ(L) dim σ` satisfies
   `D_L / L -> 1`, so `D_L > 0` for large `L`. Also
   `tr ρ_L(w) = sum_σ (a_σ(L) dim σ / D_L) χ_σ(p(w))/dim σ -> s(p(w)) = tau(w)`.
   Each `ρ_L` is a unitary representation of `Π_R(m,N)` that factors through the
   finite quotient `p(F_m)/⋂_{c_σ>0} ker σ` of `B(m,N)`. ∎(b)

## (c) LRB(R_0, C) and S(m,N,R) with R >= R_0 imply HB(m,N)

Let `tau` be a limit trace, and let `rho_j` be the representations given by
`S(m,N,R)`.

1. **Linear images are residually finite.** `Γ_j = rho_j(F_m)` is a finitely
   generated subgroup of `GL_{d_j}(C)`. By
   `finitely-generated-linear-groups-are-residually-finite`, it is residually
   finite.
2. **Their finite quotients are bounded.** Let `q: Γ_j -> Q'` be a finite
   quotient and `t_i = q(rho_j(x_i))`, which generate `Q'`. For `|w| <= R`,
   `w^N in N_R`, so `w(t)^N = 1`. By clause 2 of
   `local-restricted-burnside-iff-partial-burnside-finite-quotients`,
   `LRB(R, C)` holds, so `|Q'| <= C`. By (F2), `|Γ_j| <= C`.
3. **The trace factors through one finite quotient.** `F_m` is finitely
   generated, so it has only finitely many normal subgroups of index `<= C`. Let
   `M` be their intersection, a normal subgroup of finite index. Each
   `ker(F_m -> Γ_j)` has index `<= C`, so it contains `M`, and `tr rho_j(w)`
   depends only on `wM`. Therefore `tau(w) = lim_j tr rho_j(w)` depends only on
   `wM`, so `tau = s o p` with `p: F_m -> F_m/M` finite. This is `T2(m,N)`,
   hence `HB(m,N)`.
4. **Through `R(m,N)`.** Put `K_τ = {w : tau(w) = 1}`. By (F1) and GNS,
   `tau(g) = <π(g)ξ, ξ>` for a unitary representation `π` of `F_m` and a unit
   vector `ξ`. Then
   `|tau(wv) - tau(v)| = |<π(v)ξ, π(w^{-1})ξ - ξ>| <= ||π(w^{-1})ξ - ξ||`,
   and the square of the right side is `2 - 2 Re tau(w)`. So `K_τ` is a
   subgroup, `tau` is constant on its cosets, and `K_τ` is normal because `tau`
   is a class function. It contains `M`, since `tau(w) = s(1) = tau(e) = 1` for
   `w in M`, so it has finite index. It contains every `h^N` by (F1). So
   `F_m/K_τ` is a finite `m`-generated group of exponent dividing `N`, hence a
   quotient of `R(m,N)`, and `tau` factors through it. ∎(c)

## Decomposition

`HB(m,N)` gives `LRB(m,N)` by (a) and every `S(m,N,R)` by (b). If `LRB(R_0, C)`
holds and every `S(m,N,R)` holds, then (c) with `R = R_0` gives `HB(m,N)`. For
the last form: `HB(m,N)` gives some `LRB(R_0, C)` by (a) and `S(m,N,R_0)` by
(b). Conversely, `LRB(R, C)` and `S(m,N,R)` give `HB(m,N)` by (c) with
`R_0 = R`. ∎

## (d) Stability of Π_R at an LRB radius forces non-hyperlinearity

Assume `LRB(R_0, C)`, `R >= R_0`, `B(m,N)` infinite, and `Π_R(m,N)` flexibly
HS-stable. Suppose `Π_R(m,N)` is hyperlinear. It is finitely generated, so by
`hyperlinear-flexibly-hs-stable-group-is-residually-finite` it is residually
finite. Every finite quotient of `Π_R(m,N)` is generated by the images of the
`x_i` and satisfies `w^N = 1` for `|w| <= R`. By clause 2 of
`local-restricted-burnside-iff-partial-burnside-finite-quotients` it has order
`<= C`. By (F2), `|Π_R(m,N)| <= C`. But `Π_R(m,N)` surjects onto `B(m,N)`, which
is infinite, a contradiction. So `Π_R(m,N)` is not hyperlinear.

It is finitely presented, with one relator for each of the finitely many words
of length `<= R`. Strict stability (`D_n = d_n`, `P_n = I`) is the special case
of flexible stability. Strict stability of `Π_R(m,N)` implies `S(m,N,R)`: an
approximate exponent-N model is an asymptotic representation of `Π_R(m,N)`, and
genuine representations at `||.||_2`-distance `-> 0` on the generators are
`||.||_2`-close on every fixed word, hence have the same limit trace. ∎

title: One fixed decidable host has one word-problem time bound, and subgroups inherit it at linear cost
target: fixed-leavitt-hosts-cannot-be-universal-bh-containers
requires:
  - binary-leavitt-unit-word-problem-decidable

---

1. **A bound for the host.** By `binary-leavitt-unit-word-problem-decidable`,
   `U = L_(F_2)(1,2)^x` is finitely generated with a word-problem algorithm.
   A total algorithm has a recursive running-time bound `T` for a fixed
   finite generating set `X`.
2. **Subgroups inherit it.** Let `S <= U` be finitely generated by
   `s_1, ..., s_k`. Write each `s_i` as a word of length at most `c` in `X`.
   A word of length `l` in the `s_i` becomes a word of length at most `c*l` in
   `X`, in time `C*l`. So `S` has a word-problem algorithm in time
   `C*T(C*l) + C*l + C`. This is exactly the form required by
   `complexity-bounded-host-classes-are-not-universal` for the class `K` of
   finitely generated subgroups of `U`, with the single bound `T`.
3. **Apply the principle.** By `complexity-bounded-host-classes-are-not-universal`
   some two-generated group `H` with solvable word problem embeds in no member
   of `K`. A finitely generated group embedded in `U` would be a member of `K`,
   so `H` does not embed in `U`.
4. **Elementary groups and subalgebras.**
   - `E_n(R) <= GL_n(R) = M_n(R)^x`, and `M_n(R) ≅ R` because `R ≅ R^2` as a
     right module. So finitely generated subgroups of `E_n(R)` are finitely
     generated subgroups of `U` up to isomorphism.
   - A unital subalgebra `A <= R` has `A^x <= R^x = U`.
   - In both cases step 3 applies.
5. **Consequence for the route.** Embedding every input into `R`, through a
   group ring or any unital algebra containing the input in its units,
   embeds every input into `U`. That contradicts step 3 for the input `H`.

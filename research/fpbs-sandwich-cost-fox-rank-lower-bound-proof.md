Notation as in the target. Write `M = L(E_a) = L^∞(X) ⋊ F`, with unitaries
`u_g` and faithful normal trace `τ(f u_g) = δ_{g,1} ∫ f dμ`. Then
`u_g 1_D u_g^* = 1_{gD}`. The von Neumann subalgebra generated by the `u_g` is
`N(F)`, and `τ` restricts to its canonical trace. Write `Tr_m` for the trace
`Σ_i τ(x_{ii})` on `M_m(M)`. Rows are `1 × n` matrices, and matrices multiply
as usual.

## 0. Rank of matrices over a finite von Neumann algebra

Let `X ∈ M_{m×n}(M)`, acting from `L²(M)^n` to `L²(M)^m`. Let `LP(X)` be the
projection onto the closure of its range, and `RP(X)` the projection onto
`(ker X)^⊥`. Both lie in the matrix algebras over `M`, because they lie in the
von Neumann algebra generated by `X`, padded to a square. Set
`rk X = Tr_m LP(X)`. Polar decomposition makes `LP(X)` and `RP(X)`
Murray–von Neumann equivalent, so `rk X = Tr_n RP(X)`.

- **(i)** `rk(XY) ≤ min(rk X, rk Y)`. This holds because
  `LP(XY) ≤ LP(X)` and `ker Y ⊆ ker XY`.
- **(ii)** `rk(X+Y) ≤ rk X + rk Y`. This holds because
  `LP(X+Y) ≤ LP(X) ∨ LP(Y)`, and Kaplansky's formula
  `P∨Q − Q ~ P − P∧Q` gives `Tr(P∨Q) ≤ Tr P + Tr Q`.
- **(iii)** A diagonal matrix of projections `diag(r_1, …, r_n)` has rank
  `Σ τ(r_i)`.
- **(iv)** If `X` has entries in `N(F)`, then `LP(X)` and `rk X` are the same
  whether computed in `N(F)` or in `M`. The projection lies in the von
  Neumann algebra generated by `X`, and the traces agree.

## 1. The Fox cocycle on the pseudogroup

For `g ∈ F` let `δ(g) = (∂g/∂f_1, …, ∂g/∂f_q) ∈ (ZF)^{1×q} ⊆ M^{1×q}`. The
Fox rules give:
- `δ(gh) = δ(g) + u_g δ(h)`;
- `δ(g^{-1}) = −u_g^* δ(g)`;
- `g − 1 = δ(g)·(f_1 − 1, …, f_q − 1)^T`, so the rows of `A` are the
  `δ(h_j)`.

Let `φ ∈ [[E_a]]` have domain `D`, and put `D_g = {x ∈ D : φ(x) = g x}`. By
freeness these sets partition `D`. Call `φ` *bounded* if only finitely many
`D_g` are non-null. For bounded `φ`, define

```text
w_φ = Σ_g 1_{gD_g} u_g ∈ M,      r(φ) = Σ_g 1_{gD_g} = 1_{φ(D)},
β(φ) = Σ_g 1_{gD_g} δ(g) ∈ M^{1×q}.
```

Then `w_φ w_ψ = w_{φ∘ψ}`, `w_{φ^{-1}} = w_φ^*`, `w_φ 1_Y = w_{φ|Y}`, and
`w_φ = w_φ 1_D`. For bounded `φ, ψ`:

- **(R1)** `β(φ) = r(φ) β(φ)`.
- **(R2)** `β(φ|_Y) = 1_{φ(Y)} β(φ)`.
- **(R3)** If `φ` and `ψ` have disjoint domains and disjoint ranges, then
  `β(φ ⊔ ψ) = β(φ) + β(ψ)`.
- **(R4)** `β(φ∘ψ) = w_φ β(ψ) + r(φ∘ψ) β(φ)`.
- **(R5)** `β(φ^{-1}) = −w_φ^* β(φ)`.
- **(R6)** For `g ∈ F` acting on all of `X`, `β(g) = δ(g)`.

(R1), (R2), (R3) and (R6) are immediate from the definition, since the range
pieces `gD_g` are disjoint.

*Proof of (R4).* Put `Z_{g,h} = D^ψ_h ∩ h^{-1} D^φ_g`. Then `φ∘ψ` acts by
`gh` on `Z_{g,h}`. Freeness makes `D^{φψ}_k = ⊔_{gh=k} Z_{g,h}`. So

```text
β(φ∘ψ) = Σ_{g,h} 1_{ghZ_{g,h}} δ(g)  +  Σ_{g,h} 1_{ghZ_{g,h}} u_g δ(h).
```

In the first sum, `⊔_h ghZ_{g,h} = gD^φ_g ∩ φ(ψ(dom φψ))`. So the sum is
`r(φψ) Σ_g 1_{gD^φ_g} δ(g) = r(φψ) β(φ)`.

In the second sum, `hZ_{g,h} ⊆ D^φ_g`, so
`1_{ghZ_{g,h}} u_g = u_g 1_{hZ_{g,h}} = w_φ 1_{hZ_{g,h}}`. Also
`⊔_g hZ_{g,h} = hD^ψ_h ∩ D`. Using `w_φ = w_φ 1_D`, the second sum is
`Σ_h w_φ 1_{hD^ψ_h} δ(h) = w_φ β(ψ)`. ∎

*Proof of (R5).* `φ^{-1}` acts by `g^{-1}` on `gD_g`, with range piece `D_g`.
Also `w_φ^* 1_{gD_g} = 1_{D_g} u_{g^{-1}}`. So

```text
β(φ^{-1}) = Σ 1_{D_g} δ(g^{-1}) = −Σ 1_{D_g} u_{g^{-1}} δ(g) = −w_φ^* β(φ).  ∎
```

**Span lemma.** Let `φ_1, …, φ_n` be bounded, with `r_i = r(φ_i)`. Let `ω` be
a word in the `φ_i^{±1}`, and `Y ⊆ dom ω`. Then
`β(ω|_Y) = Σ_i c_i r_i β(φ_i)` for some `c_i ∈ M`.

*Proof.* Induct on the length of the word.
- For a single letter, use (R2) and (R1). For an inverse letter, first use
  (R5) and then (R1): `β(φ_i^{-1}) = −w_i^* r_i β(φ_i)`.
- For `ω = λ∘ω'`, apply (R4). Then `w_λ β(ω')` is in the span by induction,
  and `r(λω') β(λ)` is in the span by the one-letter case.
- (R2) multiplies on the left by a projection, which preserves the span. ∎

## 2. Part (1): every graphing of a sandwich costs at least rk(A)

Let `E_{a|H} ⊆ E ⊆ E_a`, and let `Φ = (φ_i)_{i ≥ 1}` be a graphing
generating `E`. Assume `C(Φ) = Σ_i μ(dom φ_i) < ∞`; otherwise there is
nothing to prove.

1. **Words.** Fix `j`. For a.e. `x`, `h_j x ∈ [x]_E`, because `E ⊇ E_{a|H}`.
   Since `Φ` generates `E`, some word `ω` in the letters `φ_i^{±1}` is defined
   at `x` with `ω(x) = h_j x`. Enumerate the words, and let `X_{j,ω}` be the
   set of `x` for which `ω` is the first such word. These sets partition `X`
   up to a null set.
2. **Truncation.** For `N ≥ 1` and `i ≤ N`, let `φ_i^{(N)}` be `φ_i`
   restricted to `⋃_{|g| ≤ N} D^{φ_i}_g`. It is bounded. Let `Y_j^N` be the
   set of `x` in some `X_{j,ω}` such that:
   - `ω` has length at most `N` and uses only letters with `i ≤ N`;
   - the word `ω^{(N)}` in the truncated letters is still defined at `x`.

   Every `x` uses a finite word, and each step of it is a group element of
   finite length. So `Y_j^N ↑ X` a.e. as `N → ∞`. Fix `ε > 0`, and choose
   `N` with `μ(X ∖ Y_j^N) < ε` for all `j ≤ p`.
3. **Identity.** On `Y_j = Y_j^N`, the one-piece partial isomorphism
   `h_j|_{Y_j}` is the disjoint union, over finitely many `ω`, of the
   `ω^{(N)}|_{Y_j ∩ X_{j,ω}}`. The domains are disjoint, and so are the
   ranges, since `h_j` is injective. Put `P_j = 1_{h_j Y_j}`. By (R6) and
   (R2), the left side of the identity is `P_j δ(h_j)`. By (R3) and the span
   lemma,

   ```text
   P_j δ(h_j) = Σ_{i ≤ N} c_{ji} r_i β(φ_i^{(N)}),   c_{ji} ∈ M,   r_i = r(φ_i^{(N)}).
   ```

4. **Matrix form.** Let `P = diag(P_1, …, P_p)`, `C = (c_{ji})`,
   `R = diag(r_1, …, r_N)`, and let `B` be the `N × q` matrix with rows
   `β(φ_i^{(N)})`. Then `P A = C R B`. By §0 (i) and (iii),

   ```text
   rk(PA) ≤ rk R = Σ_{i ≤ N} μ(φ_i^{(N)}(dom)) ≤ Σ_i μ(dom φ_i) = C(Φ).
   ```

   By (ii), (i) and (iii),
   `rk A ≤ rk(PA) + rk((1−P)A) ≤ C(Φ) + Σ_j τ(1 − P_j) < C(Φ) + pε`.
   By (iv), `rk A` here is the `N(F)`-rank. Let `ε → 0`, then take the
   infimum over `Φ`. This gives `C(E) ≥ rk(A)`. ∎

Nothing about `E` was used beyond `E_{a|H} ⊆ E ⊆ E_a`, and `E ⊆ E_a` is used
only to define `β` on the letters. For the relation of §5 of the
fiber-formula artifact, which is not inside a free `F_2`-action, `β` is
undefined, as it must be.

## 3. Part (2): rk(A) = p when H is compressed with basis h

Let `N = N(F)` and let `θ : N^{1×p} → N^{1×q}` be `v ↦ vA`.

1. **Kernel of θ.** `vA = v LP(A) A`. If `vA = 0`, then `v` vanishes on
   `range(A)`, and hence `v LP(A) = 0`. So
   `ker θ = N^{1×p}(1 − LP(A))`, and `dim_N ker θ = p − rk A`.
2. **Cokernel.** Let `Q = (CF)^{1×q} / (CF)^{1×p} A`, a left `CF`-module.
   Right exactness gives `N ⊗_{CF} Q = coker θ`, and likewise over `D(F)`.
3. **Independence over D(F).** `I_{Q[H]}` is a free left `Q[H]`-module on the
   `h_j − 1`, and `I_{Q[F]}` is free on the `f_k − 1`. Under these bases, the
   canonical map
   `D_Q(F) ⊗_{Q[H]} I_{Q[H]} → D_Q(F) ⊗_{Q[F]} I_{Q[F]}` is `v ↦ vA`. So
   `compressed-subgroups-of-free-groups-are-l2-independent` says the rows of
   `A` are left linearly independent over the skew field `D_Q(F)`.
   Gaussian elimination gives `P' ∈ GL_p(D_Q(F))` and `Q' ∈ GL_q(D_Q(F))`
   with `P'AQ' = [I_p | 0]`.
   `linnell-dimension-equals-skew-field-rank` says `D(F)` is a skew field
   containing `D_Q(F)`. So `P'` and `Q'` stay invertible over `D(F)`, and
   `v ↦ vA` is injective on `D(F)^{1×p}`. Hence
   `dim_{D(F)} (D(F) ⊗_{CF} Q) = q − p`.
4. **Transfer to N.** By `linnell-dimension-equals-skew-field-rank`,
   `dim_N (N ⊗_{CF} Q) = q − p`.
5. **Conclusion.** Apply additivity
   (`lueck-dimension-additivity-cofinality-and-induction`) to
   `0 → ker θ → N^p → N^q → coker θ → 0`. This gives
   `dim ker θ = p − q + (q − p) = 0`, so `rk A = p`. ∎

**Upper bound.** Since `H` is free on the `h_j` and `a|H` is free, the
graphing `{x ↦ h_j x}` is a treeing of `E_{a|H}`, of cost `p`. By
`gaboriau-treeable-free-action-realizes-min-cost` (1),
`C(E_{a|H}) = p`. So `p^F_H(a) ≤ p`, and with part (1),
`p^F_H(a) = p = rk H`.

## 4. Part (3): F_2

Let `K ≤ F_2` be non-cyclic.
1. **A rank-2 subgroup inside K.** `K` contains two non-commuting elements
   `u` and `v`. Then `K' = ⟨u, v⟩` is free, since subgroups of free groups
   are free. It is non-abelian and 2-generated, so it has rank exactly 2 with
   basis `u, v`.
2. **K' is compressed.** Every finitely generated `L ⊇ K'` is non-abelian and
   free, so `rk L ≥ 2 = rk K'`.
3. **Lower bound.** A sandwich `E` for `K` contains `E_{a|K'}`. By part (2),
   `C(E) ≥ 2`.
4. **Upper bound.** The basis of `F_2` gives a treeing of `E_a`, so
   `C(E_a) = 2`. Hence `p^{F_2}_K(a) = 2` for every free `a`. ∎

Notation as in the target. `F = F_m` has basis `x_1, ..., x_m`. A marked group
is a group with a generating tuple `s = (s_1, ..., s_m)`, identified with
`F/ker(x_i -> s_i)`. Words are arbitrary (not necessarily reduced) words in the
`x_i^{±1}`, and `B_r(L)` is the set of values of words of length `<= r`.

**Lemma 0 (LEF models evaluate words).** Let `(L, s)` be marked, `r >= 1`, and
`φ: B_r(L) -> Q` an injective multiplicative model into a finite group as in the
LEF definition. Put `t_i = φ(s_i)` and `Q' = ⟨t_1, ..., t_m⟩`. Then:
- `φ(1) = 1`, since `1·1 = 1` lies in `B_r(L)`, so `φ(1)^2 = φ(1)`;
- `φ(s_i^{-1}) = t_i^{-1}`, since `s_i s_i^{-1} = 1` gives `t_i φ(s_i^{-1}) = φ(1) = 1`;
- for every word `w` of length `<= r`, `w(t) = φ(w(s))`. Induct on length: if
  `w = w' x_i^{±1}` with `|w'| < r`, then `w'(s) ∈ B_{r-1}(L)`,
  `s_i^{±1} ∈ B_1(L)` and `w(s) ∈ B_r(L)`, so multiplicativity applies.

Hence, for words `u, v` of length `<= r`, `u(s) = v(s)` in `L` iff
`u(t) = v(t)` in `Q'` (injectivity of `φ` on `B_r(L)`). In particular `|Q'| >= |B_r(L)|`.

**Clause 2.** Assume `LRB(R, C)`, and let `(L, s)` be an `m`-generated LEF group
of exponent dividing `N`. Fix `r >= NR` and take `φ` on `B_r(L)` as in Lemma 0.
- For a word `h` with `|h| <= R`, the word `h^N` has length `<= NR <= r`, and
  `h(s)^N = 1` in `L`. By Lemma 0, `h(t)^N = (h^N)(t) = φ(1) = 1`.
- So `Q'` is a finite `m`-generated group whose words of length `<= R` satisfy
  the law, and `|B_r(L)| <= |Q'| <= C`.
- This holds for every `r >= NR`, so `|L| <= C`.

Clause 2 gives the forward direction of clause 1.

**Lemma 1 (diagonal limits).** Let `(Q_n, s^(n))` be finite marked groups.
- **Extraction.** `F` is countable, so a diagonal argument gives an infinite set
  `I` of indices such that for every `w ∈ F` the truth value of `w(s^(n)) = 1`
  is constant for all sufficiently large `n ∈ I`. Put
  `K = {w : w(s^(n)) = 1 for all large n ∈ I}`. For finitely many `w`, "large"
  can be taken uniformly, so `K` is a normal subgroup of `F`. Let `L = F/K`,
  marked by the images `s` of the `x_i`.
- **Agreement on balls.** For each `r` there is `n_r` such that for `n ∈ I`,
  `n >= n_r`, the words of length `<= 2r` that are trivial in `Q_n` are exactly
  those trivial in `L` (finitely many words).
- **`L` is LEF.** Given finite `K_0 ⊆ L`, pick `r` with `K_0 ⊆ B_r(L)` and a
  representative word `u_x` of length `<= r` for each `x ∈ K_0`. For `n ∈ I`,
  `n >= n_r`, put `φ(x) = u_x(s^(n))`. If `x ≠ y`, then `u_x^{-1} u_y` has length
  `<= 2r` and is nontrivial in `L`, hence in `Q_n`, so `φ` is injective. If
  `x, y, xy ∈ K_0`, the words `u_x u_y` and `u_{xy}` agree in `L`, have length
  `<= 2r`, hence agree in `Q_n`, so `φ(xy) = φ(x)φ(y)`.
- **Laws pass to `L`.** If a word `w` is trivial in `Q_n` for all large `n ∈ I`,
  then `w ∈ K`.
- **Finite limits bound the sequence.** If `L` is finite, `K` has finite index in
  `F`, so it is normally generated by finitely many words `w_1, ..., w_t`
  (Schreier). For large `n ∈ I` each `w_j` is trivial in `Q_n`, so `Q_n` is a
  quotient of `L` and `|Q_n| <= |L|`.

**Clause 3.** Suppose `LRB(m,N)` fails. Then `LRB(n, n)` fails for every `n`, so
there is a finite marked group `(Q_n, s^(n))` whose words of length `<= n`
satisfy `h^N = 1`, with `|Q_n| > n`. Apply Lemma 1 to get `(L, s)`.
- For any word `h`, `h(s^(n))^N = 1` for all `n >= |h|`, so `h^N ∈ K`. So `L` is
  a quotient of `B(m,N)` and has exponent dividing `N`.
- `L` is LEF.
- If `L` were finite, the last bullet of Lemma 1 would give `|Q_n| <= |L|` for
  large `n ∈ I`, contradicting `|Q_n| > n`. So `L` is infinite.

Clause 3 gives the backward direction of clause 1 (by contraposition).

**Clause 4, first bullet.** If every `m`-generated LEF group of exponent dividing
`N` is finite, clause 1 gives `LRB(m,N)`. Clause 5 of
`local-restricted-burnside-iff-partial-burnside-finite-quotients` then makes `G_k`
non-residually-finite for every sufficiently large `k`.

**Clause 4, second bullet.** Mark `G_k` and `B(m,N)` by the images of the basis.
- **Residually finite groups are LEF.** Given finite `K_0 ⊆ G_k`, a finite
  quotient injective on `K_0` is a multiplicative injective model.
- **The stages converge to `B(m,N)`.** By items 1 and 3 of
  `free-burnside-is-a-limit-of-hyperbolic-groups`, `ker(F -> G_k)` increases with
  union `F^N`. For each `R`, the finitely many words of length `<= 2R` in `F^N`
  lie in `ker(F -> G_k)` for all large `k`, so for such `k` the groups `G_k` and
  `B(m,N)` satisfy the same equalities among words of length `<= R`.
- **Closedness.** Suppose `B(m,N)` is not LEF. Clause 3 of
  `local-approximation-properties-are-marked-closed`, applied to the LEF
  predicate, gives `R` such that every marked group agreeing with `B(m,N)` on
  words of length `<= R` fails LEF. Every sufficiently large `G_k` agrees, hence
  fails LEF, hence is not residually finite. This contradicts the assumption
  that infinitely many `G_k` are residually finite. So `B(m,N)` is LEF, and it is
  infinite by item 4 of the import.

The "in particular" follows because each `G_k` is hyperbolic (item 1). ∎

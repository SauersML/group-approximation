Notation as in the target: `Δ` free with basis `f_1, …, f_q`, `F ⊆ Δ`
finite, `H = ⟨F⟩`, `a` a free p.m.p. action of `Δ` on `(X, μ)`.

**0. H is free of finite rank.** `H` is generated by the finite set `F`, and
subgroups of free groups are free. So `H` has a finite basis
`h_1, …, h_p`, with `p = 0` when `H = 1`. Put `r = π̄(H ≤ Δ)`. The minimum is
over a nonempty set of ranks bounded by `q`, since `Δ` itself is an
overgroup, so it is attained by some `L` with `H ≤ L ≤ Δ` and `rk L = r`.

**1. Lower bound.** Let `A` be the Fox matrix of `h_1, …, h_p` with respect to
`f_1, …, f_q`. Part (1) of `fpbs-sandwich-cost-fox-rank-lower-bound` gives
`C(E) ≥ rk(A)` for every `E` with `E_{a|H} ⊆ E ⊆ E_a`. By
`free-group-minimal-overgroup-rank-is-fox-rank`, `rk(A) = r`. So
`p^Δ_F(a) ≥ r`. For `H = 1`, the bound `r = 0` is trivial.

**2. Upper bound.** `L` has rank `r`, so it is free on some `l_1, …, l_r`.
- If `r = 0`, then `L = 1` and `E_{a|L}` is the diagonal, of cost 0.
- If `r ≥ 1`, then `a|L` is a free action of the free group `L`. So the
  graphing `{x ↦ l_i x : i ≤ r}` has no cycles in any class: a cycle would
  give a non-trivial reduced word in the `l_i` that fixes a point, which
  freeness of `a` excludes on a conull set. It is therefore a treeing of
  `E_{a|L}`, of cost `r`. By `gaboriau-treeable-free-action-realizes-min-cost`
  (1), `C(E_{a|L}) = r`.

Since `H ≤ L ≤ Δ`, the relation `E_{a|L}` lies between `E_{a|H}` and `E_a`.
So `p^Δ_F(a) ≤ r`.

**3. Conclusion.** `p^Δ_F(a) = r` for every free `a`, and `E_{a|L}` attains
it. The value does not depend on `a`. In particular it is the same for the
Bernoulli shift `s_Δ`, which is free because `Δ` is infinite. So
`p^Δ_F(s_Δ) ≤ p^Δ_F(a)`, and that is
`fpbs-relative-sandwich-cost-bernoulli-lower-bound` for `Δ`. ∎

**Where the new input enters.** Part (2) of the Fox-rank node only computes
`rk(A)` for compressed `H`, where `r = rk H`. For non-compressed `H`,
`rk(A) = r < rk H`. The inequality `rk(A) ≤ r` is elementary: the rows of
`A` lie in the `D(Δ)`-span of the Fox rows of a basis of `L`. The equality
`rk(A) ≥ r` is the non-trivial half (14) of Jaikin-Zapirain's Theorem 3.12.
It rests on `L2`-subgroup rigidity of free groups: the `D`-closure `H̃` of `H`
is a subgroup of rank exactly `rk(A)`.

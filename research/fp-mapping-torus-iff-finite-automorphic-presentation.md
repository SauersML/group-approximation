Let `K` be generated by a finite set `X`, let `phi in Aut(K)`, and put

```text
G=K semidirectProduct_phi Z.
```

Then `G` is finitely presented if and only if there are

```text
finite R subset F(X),
word substitutions Phi_+, Phi_- : F(X) -> F(X)
```

which induce the mutually inverse automorphisms `phi,phi^(-1)` of `K` and
such that

```text
K ~= < X | Phi_epsilon_1 ... Phi_epsilon_m(r),
           r in R, m>=0, epsilon_i in {+,-} >.           (FAP1)
```

Equivalently, `K` has a finite invariant `L`-presentation whose substitution
monoid contains word lifts of both directions of `phi`.  Thus a finite
automorphic presentation is not an optional convenience for an infinitely
presented kernel in the split-cyclic target: it is exactly the missing finite
presentability datum.

A group generated by `k` elements is `F_k/W`, where `W` is the set of words in
the free generators and their inverses that represent the identity. The pair
`(k, W)` determines the group up to isomorphism.

- If `W` is recursively enumerable, it is the set of inputs accepted by some
  Turing machine.
- If `W` is co-recursively enumerable, its complement in the countable set of
  words is.

There are countably many Turing machines and countably many `k`, so only
countably many pairs `(k, W)` arise.

Independence of the generating set: if `Y` and `Y'` are finite generating sets,
each element of `Y` can be written as a fixed word in `Y'`. Substitution is then
a computable map on words that carries `Y`-words representing `1` exactly to
`Y'`-words representing `1`. So r.e. and co-r.e. transfer from `Y'` to `Y`.

The consequence follows: an uncountable family of pairwise non-isomorphic
groups can contain only countably many members of this countable set of types.

The notation is that of the target. Automorphisms act on the left, and `Aut(X*)` acts by
`s(xw) = π_s(x) s|_x(w)`. So `(st)|_x = s|_{t(x)} t|_x` and `π_{st} = π_s π_t`. For a word
`w`, `s|_w` is the iterated section, and `r@w` is the element acting as `r` below `w` and
trivially elsewhere.

## 0. Sections on the tree

**Relabellings.** For each `c ∈ C` choose `τ_c ∈ A_{d+1}` with `τ_c(0) = c`, and fix a
bijection `λ_0 : C∖{0} → X`. Put `λ_c = λ_0 ∘ τ_c^{-1}` on `C∖{c}`.

**(L) Parity lemma.** For `σ ∈ Sym(C)` and `c ∈ C`, the permutation
`λ_{σc} σ λ_c^{-1} ∈ Sym(X)` is `λ_0 (τ_{σc}^{-1} σ τ_c) λ_0^{-1}`. Here
`τ_{σc}^{-1} σ τ_c` fixes `0`, and its parity on `C∖{0}` equals the parity of `σ`. So
`λ_{σc} σ λ_c^{-1} ∈ A_d` iff `σ ∈ A_{d+1}`. In particular the condition is independent of `c`.

**Coordinates.** Let `f = (x, y)` be an oriented edge of colour `c_0`. A vertex `u ∈ Y_f` has
a geodesic `y = u_0, u_1, ..., u_n = u` with edge colours `c_1, ..., c_n`. Consecutive
colours differ, since the colouring is legal. Put

`φ_f(u) = λ_{c_0}(c_1) λ_{c_1}(c_2) ⋯ λ_{c_{n−1}}(c_n) ∈ X*`.

This is an isomorphism of rooted trees `(Y_f, y) → X*`, because the colours of the edges
from `u_n` away from `u_{n−1}` are exactly `C∖{c_n}`.

**Sections.** For `g ∈ Aut(T)`, `g Y_f = Y_{gf}`. Put `s_f(g) = φ_{gf} ∘ g ∘ φ_f^{-1} ∈ Aut(X*)`.

- **(C1) Cocycle.** `s_f(gh) = φ_{ghf} g φ_{hf}^{-1} · φ_{hf} h φ_f^{-1} = s_{hf}(g) s_f(h)`.
  Also `s_f(1) = 1` and `s_f(g^{-1}) = s_{g^{-1}f}(g)^{-1}`.
- **(C2) Restriction.** Let `u ∈ Y_f` with `u ≠ y`, and let `f_u` be the last edge of the
  geodesic from `y` to `u`, oriented toward `u`. Then `φ_f(u')` is `φ_f(u) φ_{f_u}(u')`
  for all `u' ∈ Y_{f_u}`, because the colour word of `u'` extends that of `u`, and the
  relabelling at each step uses only the previous colour. The same holds at `gf`, `g u`.
  So `s_f(g)|_{φ_f(u)} = s_{f_u}(g)`.
- **(C3) Root permutations.** The root permutation of `s_f(g)` is
  `λ_{σ_y(c_0)} ∘ σ_y ∘ λ_{c_0}^{-1}`, where `σ_y ∈ Sym(C)` is the **local action** of `g`
  at `y`: `σ_y(c)` is the colour of the image of the edge at `y` of colour `c`. By (L), it
  lies in `A_d` iff `σ_y ∈ A_{d+1}`.
- **(C4) Core.** A colour-preserving `k ∈ G` satisfies `φ_{kf} ∘ k = φ_f` on `Y_f`, so
  `s_f(k) = 1` for all `f`. `G` is generated by the involutions `ι_c` that swap the ends
  of an edge of colour `c` and preserve colours. `G ≅ *_c Z/2` acts simply transitively
  on vertices. An element of `G` fixing a vertex and preserving colours is `1`, so `G` is
  edge-free.

## 1. Consequences of (S), (B), (A)

- **(R1) Recursive membership.** Let `s ∈ Aut(X*)` with `π_s ∈ A_d` and `s|_x ∈ R` for
  every `x`. By (A) pick `t ∈ R` with `π_t = π_s`. Then `u = t^{-1}s` has trivial root
  permutation and sections `u|_x = (t^{-1})|_{s(x)} · s|_x`. Here
  `(t^{-1})|_z = (t|_{t^{-1}(z)})^{-1} ∈ R` by (S), so every `u|_x ∈ R`. So `u = ∏_x (u|_x)@x ∈ R` by (B), and `s = tu ∈ R`.
- **(R2) Pieces.** For `r ∈ R` and a word `w`, `r@w ∈ R`. This follows by induction on
  `|w|`, since `r@(xw') = (r@w')@x`.
- **(R3) All vertex permutations.** Every `s ∈ R` has `π_{s|_w} ∈ A_d` for every word `w`,
  by (S) and (A).
- The section map `R → R ≀_X A_d` is injective. It is onto by (A), (B) and (R1). So
  `R ≅ R ≀_X A_d`.

## 2. Lemma M: finitely supported membership

**Lemma M.** Let `g ∈ Aut(T)` and let `F` be a finite nonempty connected set of vertices.
Suppose that:

- (i) `σ_w ∈ A_{d+1}` for every `w ∈ F`;
- (ii) `s_f(g) ∈ R` for every **exit edge** `f = (x, y)`, meaning `x ∈ F` and `y ∉ F`.

Then `g ∈ Γ_R`.

*Proof.*

- **Local actions off `F`.** A vertex `w ∉ F` lies in `Y_f` for exactly one exit edge
  `f = (x, y)`, the first edge of the geodesic from `F` to `w`.
  - If `w = y`, the root permutation of `s_f(g) ∈ R` is in `A_d`, so `σ_y ∈ A_{d+1}` by (C3).
  - If `w ≠ y`, then by (C2) `s_{f_w}(g) = s_f(g)|_{φ_f(w)} ∈ R` by (S). Its root permutation
    lies in `A_d`, so `σ_w ∈ A_{d+1}` by (C3).

  So `σ_w ∈ A_{d+1}` for every vertex `w`.
- **Induction.** For an oriented edge `f'' = (x'', y'')` put
  `μ(f'') = |Y_{f''} ∩ F| + d(y'', F)`.
  - **Base: `Y_{f''} ∩ F = ∅`.** `F` is connected and lies off `Y_{f''}`, so the geodesic
    from `F` to `y''` ends with `f''`. Let `f` be its exit edge. Either `f'' = f`, or
    `f'' = f_{y''}` with `y'' ∈ Y_f`. In both cases `s_{f''}(g) ∈ R`, by (ii), or by (C2)
    and (S).
  - **Step.** By (C2) with words of length one, `s_{f''}(g)` has sections
    `s_{(y'', z)}(g)` at its letters, for the neighbours `z ≠ x''` of `y''`. Its root
    permutation is in `A_d` by (C3). By (R1) it suffices that every `s_{(y'', z)}(g) ∈ R`.
    - If `y'' ∈ F`: each child half-tree `Y_{(y'', z)}` misses `y''`, so it meets `F` in
      fewer vertices. If `z ∉ F`, connectedness of `F ∋ y''` gives `Y_{(y'', z)} ∩ F = ∅`,
      which is the base case.
    - If `y'' ∉ F` and `Y_{f''} ∩ F ≠ ∅`: then `x'' ∉ F`, since otherwise the connected
      `F` would contain `y''`. So `F ⊆ Y_{(y'', z_0)}` for one child `z_0`, with
      `d(z_0, F) = d(y'', F) − 1`. The other children are base cases.

    In every case `μ` decreases or the base case applies. ∎

## 3. Item 1

- `Γ_R` is closed under products and inverses by (C1), because `R` is a group. It contains
  `G` by (C4).
- `G` is vertex-transitive, so `Γ_R` acts minimally.
- Each `ι_c` swaps the two half-trees of an edge, and every end lies in exactly one of
  them, so `ι_c` moves every end. Hence `Γ_R` fixes no end.
- `T` has valence `d + 1 ≥ 4`, so it is not a line.

## 4. Item 2

- **Pieces.** For `r ∈ R` and `f = (x, y)`, let `p_f(r)` act as `φ_f^{-1} r φ_f` on `Y_f` and
  as the identity off `Y_f`. Since `r` fixes the root, `p_f(r)` fixes `y` and is an
  automorphism.
  - Apply Lemma M with `F = {x, y}`.
  - `σ_x = 1`. By (C3), `σ_y ∈ A_{d+1}`, because `s_f(p_f(r)) = r` has root permutation in
    `A_d`.
  - Exit edges `(y, z)` have sections `r|_{letter} ∈ R` by (C2) and (S).
  - Exit edges `(x, z)` with `z ≠ y` have trivial sections, since `p_f(r)` is the identity
    on those half-trees.

  So `p_f(r) ∈ R_Γ(Y_f)`.
- **Rigid stabilizer ≅ `R`.** An element of `R_Γ(Y_f)` fixes `x` and every neighbour of `x`
  except possibly `y`, hence also `y`. It is determined by its action on `Y_f`, which is
  `s_f`. So `s_f : R_Γ(Y_f) → R` is injective. It is a homomorphism by (C1), since these
  elements fix `f`, and it is onto via `p_f`.
- **(P).** Let `g ∈ Γ_f`. Put `p = p_f(s_f(g)) ∈ R_Γ(Y_f)` and `q = p^{-1}g ∈ Γ_R`. Then `q` is
  the identity on `Y_f`, so `q ∈ R_Γ(Y_{f̄})`. Thus `Γ_f = R_Γ(Y_f) · R_Γ(Y_{f̄})`. The two
  factors have disjoint supports, so they commute and meet trivially. So
  `Γ_f ≅ R × R`.

## 5. Item 3

Let `v` be a vertex, `y_c` its neighbour along the edge of colour `c`, and `f_c = (v, y_c)`.

- **Ball fixator.** Let `g` fix `B_1(v)`. Then `g · (∏_c p_{f_c}(s_{f_c}(g)))^{-1}` fixes
  `B_1(v)` and has trivial sections at every `f_c`, so it is `1`. The pieces have disjoint
  supports. Hence `Fix_Γ(B_1(v)) = ∏_c R_Γ(Y_{f_c}) ≅ R^C`.
- **Local actions.** For `g ∈ Γ_v`, `σ_v ∈ A_{d+1}`. This follows from (C3) applied to the
  sections at the edges `(y_c, v)`.
- **Lift.** For `σ ∈ A_{d+1}`, let `g_σ` fix `v` and map `Y_{f_c}` to `Y_{f_{σc}}` by
  `φ_{f_{σc}}^{-1} φ_{f_c}`. This is an automorphism with local action `σ` at `v`, and
  `s_{f_c}(g_σ) = 1` for every `c`. By Lemma M with `F = {v}`, `g_σ ∈ Γ_v`. The product
  `g_σ g_ρ` agrees with `g_{σρ}` on every `Y_{f_c}`, so `σ ↦ g_σ` is a homomorphism.
- **Conjugation.** `g_σ p_{f_c}(r) g_σ^{-1} = p_{f_{σc}}(r)`, by (C1) and trivial sections.
- **Conclusion.** Every `g ∈ Γ_v` equals `g_{σ_v}` times an element of `Fix_Γ(B_1(v))`. So
  `Γ_v = Fix_Γ(B_1(v)) ⋊ {g_σ} ≅ R ≀_C A_{d+1}`. By vertex-transitivity every vertex has
  local action group `A_{d+1}`.

## 6. Item 4

- **`Γ⁺` is type-preserving.** An automorphism fixing a vertex preserves the parity of
  distances, so `Γ⁺ ≤ Γ_0`, the type-preserving subgroup. `ι_c ∉ Γ_0`, so `[Γ_R : Γ_0] = 2`.
- **`Γ_v ≤ Γ⁺`.**
  - `Fix_Γ(B_1(v)) ≤ Γ_{f_c}`.
  - For `σ` fixing `c`, `g_σ` fixes `y_c`, so `g_σ ∈ Γ_{f_c}`.
  - The point stabilizers generate `A_{d+1}`: for `d + 1 ≥ 5` they generate a nontrivial
    normal subgroup of a simple group, and for `d + 1 = 4` they contain all 3-cycles.
- **`Γ⁺ = Γ_0`.** `Γ_0` acts without inversions. It is transitive on vertices of each type,
  because `G ∩ Γ_0` is, and `Γ_v` is transitive on the neighbours of `v`. So `Γ_0` is
  edge-transitive. By Bass--Serre theory, `Γ_0 = Γ_v *_{Γ_f} Γ_{v'}` for an edge
  `f = (v, v')`. It is generated by `Γ_v ∪ Γ_{v'} ≤ Γ⁺`.
- **Simplicity.** Tits (1970): if `Γ ≤ Aut(T)` has (P), no proper invariant subtree and no
  fixed end, then `Γ⁺` is simple or trivial. `Γ_R` satisfies these hypotheses by items 1
  and 2, and `Γ⁺ ⊇ R_Γ(Y_f) ≅ R ≠ 1`.
- **Finite generation.** If `R` is finitely generated, so are `R ≀ A_{d+1}` and `R × R`.
  Hence the amalgam `Γ⁺` is finitely generated, and so is `Γ_R = Γ⁺ ⋊ ⟨ι_c⟩`.
- **Finite presentation.**
  - `R` is a retract of `R^{d+1}`, which has finite index in `R ≀ A_{d+1}`. So `Γ_v` is
    finitely presented iff `R` is.
  - For an amalgam `A *_C B` with `C` finitely generated, the amalgam is finitely presented
    iff `A` and `B` are. The "if" direction is immediate. The "only if" direction is the
    standard lemma, for instance via Bieri's result that finitely presented factors are
    necessary when the edge group is finitely generated.
  - So `Γ⁺` is finitely presented iff `R` is, and `Γ_R ⊇ Γ⁺` with index 2 follows. ∎

## 7. Item 5

Let `R = ⟨A_5, b⟩`, with `b = (b, α, β, 1, 1)`.

- **(S).** The generators have sections in `{1, b, α, β} ⊆ R`. The formulas
  `(st)|_x = s|_{t(x)} t|_x` and `(s^{-1})|_x = (s|_{s^{-1}(x)})^{-1}` propagate this to `R`.
  The same formulas show that every element has finitely many iterated sections, so all
  elements are finite-state.
- **(A).** `b` has trivial root permutation, and `A_5` acts at the root.
- **(B).**
  - For `a ∈ A_5` with `a(0) = 0`, the element `h_a = b^{-1} a b a^{-1} ∈ R` has trivial root
    permutation, section `1` at `0`, and section `s_j(b)^{-1} s_{a^{-1}j}(b) ∈ A_5` at
    `j = 1, ..., 4`.
  - The script `verify_full_wreath_recursion.py` checks that the subgroup
    `H = ⟨h_a⟩ ≤ 1 × A_5^4` projects onto `A_5 × A_5` for all six pairs of coordinates.
  - **Pair projections suffice.** Let `S` be nonabelian simple and `H ≤ S^n`, with every
    pair projection onto. Induct on `n`, so that `H` projects onto `S^{n−1}`.
    `N = H ∩ (1 × ⋯ × 1 × S)` is normal in `S`, since the last projection is onto.
    - If `N = S`, then `H = S^n`.
    - If `N = 1`, then `H` is the graph of a surjection `θ : S^{n−1} → S`. Its kernel is a
      normal subgroup of `S^{n−1}` with quotient `S`, hence the product of all factors but
      one, say the `i`-th. Then the `(i, n)` projection of `H` is the graph of an
      automorphism, of order `|S| ≠ |S|^2`, a contradiction.

    The script output gives order `3600 = 60^2` for every pair. So `H = 1 × A_5^4`, and
    `c@x ∈ R` for all `c ∈ A_5` and `x ∈ {1, 2, 3, 4}`.
  - Conjugating by root elements gives `a (c@x) a^{-1} = c@a(x)`, hence every `x`. Then
    `b@0 = b · (β@2)^{-1} (α@1)^{-1} ∈ R`.
  - For each `x`, `r ↦ r@x` is a homomorphism, so `{r ∈ R : r@x ∈ R for all x}` is a
    subgroup. It contains `A_5` and `b`, so it is `R`.

## 8. Item 6

- **`FS(G)` is a group.** The edges that point away from `v` but not from `v'` lie on the
  geodesic `[v, v']`, so the definition does not depend on `v`.
  - For products, `s_f(gh) = s_{hf}(g) s_f(h)`, and `hf` points away from `hv` when `f` points
    away from `v`. So the away-sections of `gh` from `v` lie in the product of two finite
    sets.
  - For inverses, `s_f(g^{-1}) = s_{g^{-1}f}(g)^{-1}`, and `g^{-1}f` points away from `g^{-1}v`.
- **`Γ(G, 1) ≤ FS(G)`.** For `ρ = 1`, `v` is regular for `g` iff `σ_v = 1`, because an element
  of `G` is determined by the image of one vertex and preserves colours.
  - If `Y_f` contains no singular vertex, `g` maps colour words to colour words on `Y_f`, so
    `s_f(g) = 1`.
  - The other away edges lie in the finite subtree spanned by `v` and `Sing(g)`.
- **`Γ_R ≤ FS(G)`** when all elements of `R` are finite-state. By (C2), the away-sections
  from `v` are iterated sections of the `d + 1` elements `s_{f_c}(g)`.
- **The counterexample.** In item 5, `Γ_R` acts faithfully and minimally, fixes no end, is
  not on a line, has (P), and has a nontrivial finitely generated edge group. All its
  elements are finite-state over the edge-free `G`. So item 5 of
  `finitely-singular-tree-hosts-have-no-fg-stabilizers` fails for `FS(G)`.
- **Where the filtration fails.** Let `D` be finite on a finite generating set of `Γ_f` and
  satisfy `D(gh) ≤ max(D(g), D(h))` and `D(g^{-1}) = D(g)`. Then `D` is bounded on `Γ_f`.
  - `R_Γ(Y) ≤ Γ_f` is nontrivial for every half-tree `Y ⊆ Y_f`.
  - So no such `D` can satisfy the rigidity property `D(r) ≥ dist(f, Y)` for all
    `1 ≠ r ∈ R_Γ(Y)`.
  - Number of away-states: `states(gh) ⊆ states(g) · states(h)`, which is submultiplicative
    and not ultrametric.
  - Depth of the first nontrivial away-section: for `p_{f'}(b)` with `f'` deep, the first
    edge from `σ` toward `f'` already carries the nontrivial section `b@w`, so the depth
    stays at `0`.

**Scope.** Nothing here decides whether a finitely presented fully self-replicating group
exists. The contracting instance is not finitely presented by the result cited in the
target, which is not re-proved here.

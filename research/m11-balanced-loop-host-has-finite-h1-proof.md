**Conventions.** Right actions: `(xw)^g = x^{π_g} w^{g|_x}` and `(gh)|_v = g|_v h|_{v^g}`.
`g@v` acts as `g` below `v` and trivially elsewhere, and `(gh)@v = (g@v)(h@v)`.

- For finitary `π`, `π^{−1}(g@x)π = g@(x^π)`.
- For `s` fixing level 1, `s^{−1}(g@x)s = (s|_x^{−1} g s|_x)@x`.
- `[g, h] = g^{−1}h^{−1}gh`.
- `bα = (b, α, β, 1, …, 1)·α`, and `R_0 = ⟨M_11, b⟩` is fully self-replicating
  (`tits-hosts-for-transitive-local-actions` item 6). So `g@x ∈ R_0` for `g ∈ R_0`.

**Step 1 (item 1).** `C` fixes level 1, so `C^m|_4 = C^m`, `C^m|_5 = (bα)^m` and
`C^m|_6 = C^{−m}`. By Lemma 1 of `m11-odometer-free-linear-host-h1-is-z55-squared-proof`,
`bα` has infinite order, so `C^m ≠ 1` for `m ≠ 0`. The elements `C^m` are pairwise distinct
and each equals its own section at `4`, so no finite nucleus contains them. Script check (3)
confirms the shape of `C^m` for `m ≤ 12`. ∎

**Step 2 (item 2).** `π_1` fixes `4` and `5` and sends `6 ↦ 7`, so

`π_1^{−1} C π_1 = C@4 · (bα)@5 · (C^{−1})@7`.

Multiplying on the left by `C^{−1} = (C^{−1})@4 · ((bα)^{−1})@5 · C@6` gives
`[C, π_1] = C@6 · (C^{−1})@7`. `π` sends `6 ↦ 4` and `7 ↦ 6`, so
`π^{−1}[C, π_1]π = C@4 · (C^{−1})@6`, and

`C = π^{−1}[C, π_1]π · (bα)@5`.

Script checks (1) and (2) confirm both identities at depth 4. Let `N` be the normal
closure of `M_11 ∪ {b}` in `R°`.

- `[C, π_1] = (π_1^{−1})^C π_1` lies in `N`.
- `(bα)@5 ∈ R_0 ⊆ N`.

So `C ∈ N`, and `N = R°`. `M_11` is perfect, so `H_1(R°; Z)` is generated by `[b]`. The map
`R_0 → R°` is onto on `H_1`, so `H_1(R°; Z)` is a quotient of `H_1(R_0; Z) = Z/55`, by
`m11-odometer-free-linear-host-h1-is-z55-squared`. ∎

**Step 3 (item 3).** Let `Q = {g ∈ R° : g@x ∈ R° for all x ∈ X}`.

- **Subgroup.** `Q` is a subgroup, because `(gh)@x = (g@x)(h@x)`.
- **It contains `M_11` and `b`,** because `R_0` is fully self-replicating.
- **Onto sections.** Fix `x`. The map `St_{R°}(1) → R°` given by `s ↦ s|_x` is a
  homomorphism. Its image contains `b`, `α`, `β` and `C`:
  - take `b^{π}` with `1^π = x`, `2^π = x` or `3^π = x`, for `b`, `α` and `β` respectively;
  - take `C^{π}` with `4^π = x`, for `C`.

  So the image is `R°`.
- **Normal.** Let `g ∈ Q` and `h ∈ R°`. Pick `s ∈ St_{R°}(1)` with `s|_x = h`. Then
  `(h^{−1}gh)@x = s^{−1}(g@x)s ∈ R°`. This holds for every `x`, so `h^{−1}gh ∈ Q`.

So `Q` is a normal subgroup containing `M_11 ∪ {b}`. It contains `N = R°` by Step 2. So
`R°@x ⊆ R°` for every `x`. The sections of the generators are `C^{±1}`, `bα`, `b`, `α`, `β`
or `1`, all in `R°`, so `R°` is self-similar with root image `M_11`. Hence
`St_{R°}(1) = ∏_x R°@x`, and `R° = R°^X ⋊ M_11`. ∎

**Step 4 (item 4).** The automaton has three cycles:

- `b → b` on letter `1`;
- `C → C` on `4`, and `C → C^{−1} → C` on `6`, with `C^{−1} → C^{−1}` on `4`.

Every other path ends in a finitary state, and then in `1`. So (Ω), (E), (F) of
`fp-self-similar-groups-have-fp-ray-loop-subgroups` hold at every periodic ray.

- **Ray `1^∞`.** Nontrivial stable sections arise only along paths that end on the `b`-loop.
  Their value is `b^{±1}`, and it is reached through `bα → b` from `C^{±1}`. So
  `H_{1^∞} = ⟨b⟩ ≅ C_55`, by item 2 of `m11-odometer-free-linear-host-h1-is-z55-squared`.
- **A periodic ray `ζ ∈ {4, 6}^ω`,** regrouped so that its period word contains an even
  number of `6`s. Along the period, `C^{±1}` returns to itself. Every other state leaves the
  alphabet `{4, 6}` or dies. So the stable sections are `C^{±1}`, and `H_ζ = ⟨C⟩ ≅ Z` by
  Step 1.
- **Any other periodic ray.** A state whose section along the period is itself lies on a
  cycle read along the period word. For any other ray there is no such state, so
  `H_ζ = 1`.

All three kinds of loop group are finitely presented. ∎

**Step 5 (item 5).** Take `η = v 4^∞` with `v ∈ {4, 6}*`. The path from `C` along `v` stays
in `{C^{±1}}`, and then loops. So `c(C, η) = C^{±1} ≠ 1`, and the support of `C` in
`X*4^∞` is infinite. At `1^∞`, the path along `v 5 1^∞` gives `C^{±1} → (bα)^{±1} → b^{±1}`,
so the support is infinite there too. The loop-character theorem needs (FS), so it gives
nothing. Step 2 shows that there is nothing to give. ∎

**Step 6 (item 6).**

- **Degree 1.** By Step 2, `H_1(R°; Q) = 0`, and `|H_1(R°; Z)|` divides `55 = 5·11`. Both
  primes divide `|M_11| = 7920`. Item 3 of `fully-self-replicating-fp-infinity-groups-are-acyclic`
  asks, for `FP_{d−1}`, that `R^{ab}` be finite with prime divisors dividing `|P|`, and, for
  finite presentation, that `dim H_1 ≤ 1` over each field. Both hold. That node offers
  nothing in higher degrees without knowing `H_*(R°)`.
- **Activity.** By Step 4, the nontrivial level-`n` sections of `C` include `C^{±1}` at all
  `2^n` words in `{4, 6}^n`. So the activity is exponential, and the Amir–Angel–Virág
  criterion does not apply.
- **The host.** `R°` is finitely generated and fully self-replicating with root image
  `M_11`. So `tits-hosts-for-transitive-local-actions` makes
  `(R° ≀ M_12) *_{R°×R°} (R° ≀ M_12)` a finitely generated simple group, which is finitely
  presented iff `R°` is. ∎

T. Rainone and A. Sims, "A dichotomy for groupoid C*-algebras", arXiv:1707.04516v2 (1 Aug 2017),
Section 6. Read from the arXiv PDF on 2026-09-13.

Verbatim: "Theorem 6.2. Let (S, +) be an abelian monoid equipped with the algebraic ordering, and let θ
be an element of S. Then the following are equivalent: (i) (n + 1)θ ≰ nθ for all n ∈ N, that is θ is
completely non-paradoxical. (ii) There is a non-trivial state ν : S → [0, ∞] with ν(θ) = 1."

The preceding text says a state is a map "which is additive, respects the pre-ordering ≤, and satisfies
ν(0) = 0", and that "A proof can be found in [44]" (S. Wagon, The Banach–Tarski Paradox, CUP 1993).

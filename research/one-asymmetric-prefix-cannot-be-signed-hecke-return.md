**ESTABLISHED SINGLE-INSERTION FENCE.**  Use the matrix-root convention and
the signed constant Hecke pair `(L_0,lambda_0)` of
`signed-hecke-normalizer-has-eight-external-root-returns`.  For every one of
its eight external constant-root normalizer positions `(a,b)`, there is a
constant root `x_ij(1)` in `L_0` whose conjugation by `x_ab(c)` exposes the
coefficient `c` in another root position of `L_0`:

```text
(a,b)   witness (i,j)   exposed position
(7,4)       (4,5)            (7,5)
(8,5)       (5,6)            (8,6)
(9,6)       (7,9)            (7,6)
(2,7)       (7,9)            (2,9)
(4,8)       (2,4)            (2,8)
(7,8)       (8,6)            (7,6)
(5,9)       (4,5)            (4,9)
(8,9)       (2,8)            (2,9).                  (APR1)
```

The Steinberg conjugation formula says that the conjugate is the witness
root times `x_exposed(c)`.  Hence, if `x_ab(c)` normalizes `L_0`, then
`x_exposed(c)` belongs to `L_0`.  But `L_0` is generated by constant
`F_2`-coefficient roots, so all of its elementary-matrix entries lie in
`F_2`.  Injectivity of an elementary root parametrization gives

```text
x_ab(c) in Norm(L_0,lambda_0)  =>  c in {0,1}.         (APR2)
```

In particular, consider the coefficient-sensitive version of an inverse
pair return through a spare index `k`:

```text
[x_(a,k)(s_mu t_i),x_(k,b)(s_j t_nu)]
   =x_(a,b)(delta_(i,j) s_mu t_nu).                   (APR3)
```

The original return has `mu=nu=empty` and `i=j`, hence coefficient one.
If `i!=j`, the commutator is the identity.  If `i=j` and at least one of
`mu,nu` is a nonempty one-letter prefix, its coefficient is a nonconstant
Leavitt matrix unit (a proper branch idempotent in the diagonal case), so
`(APR2)` shows that it does not preserve the signed Hecke carrier.

Nor can known constant returns hide this failure.  If `N` is the normalizer
of the signed pair, `n_-,n_+ in N`, and `n_-x_ab(c)n_+ in N`, then closure of
`N` gives `x_ab(c) in N`.  Thus inserting one asymmetric coefficient root
anywhere among any number of the eight constant external returns still
cannot satisfy the full-Gram return condition `(ESB1)`.

This rules out the smallest nonconstant modification of the inverse-pair
commutator table before any reservoir-gauge equation is reached.  It does
not rule out a product of two or more nonconstant roots which individually
leave the signed normalizer and jointly return.  Such a genuinely paired
coefficient excursion is now the first possible asymmetric ESB word.

No Property T, Kazhdan input, trace assumption, local computation, or
literature theorem is used.

Notation as in `kazhdan-nv-measure-criterion-2026-09-17.md`, Section 0: bricks
`[v] ⊆ C^n`, canonical charts, and the slope cocycle `s(g,x) = |w| - |w'|` for `x` in a
brick `[w]` on which `g` is canonical with image `[w']`.

Let `G <= nV` and `x ∈ C^n`. The **germ group** `Germ_G(x)` is `Stab_G(x)` modulo the
normal subgroup of elements that are the identity on some neighbourhood of `x`. For a
closed `G`-invariant `Z ∋ x`, `Germ_{G,Z}(x)` is defined the same way with
neighbourhoods taken in `Z`.

**Theorem.**

1. *(Slope is a germ invariant.)* `h_x: Stab_G(x) -> Z^n`, `g -> s(g,x)`, is a
   homomorphism. If `g ∈ Stab_G(x)` and `s(g,x) = 0`, then `g` is the identity on a
   neighbourhood of `x` in `C^n`. So `Germ_G(x) ≅ h_x(Stab_G(x))`, a free abelian
   group of rank at most the number of eventually periodic coordinates of `x`.
2. *(Subsystems.)* Let a group `Γ` act on a compact space `X`, let `ρ: Γ -> nV` be a
   homomorphism, and let `ι: X -> Z ⊆ C^n` be a `Γ`-equivariant homeomorphism onto a
   closed `ρ(Γ)`-invariant set. Then for every `x ∈ X`, `Germ_{Γ,X}(x)` is a quotient
   of a subgroup of `Z^n`, so it is abelian and generated by at most `n` elements.
3. *(Separation from SL_3.)* The action of `SL_3(Z[1/p])` on `P^2(Q_p)` has a
   non-abelian point germ group (it contains `SL_2(Z[1/p])` at `[1:0:0]`). So no
   minimal set of any subgroup of any `nV` is conjugate to it, and the same holds for
   every action with a non-abelian point germ group.
4. *(Compression.)* Let `g ∈ nV` be canonical on a brick `B = [w]` with `gB = [wu] ⊊ B`,
   and let `Z` be closed, `g`-invariant, with `Z ∩ B ≠ ∅`. Then `g` fixes a point
   `p ∈ Z ∩ B` with `s(g,p) = -|u| ≠ 0`, where `|u| ∈ N^n \ {0}`.
5. *(Germ types.)* Let `g` fix `z ∈ Z` with `d = s(g,z)`. If `d = 0`, `g` is the
   identity near `z`. If `d ≠ 0` and `d <= 0` coordinatewise, then `g` is canonical on
   every deep brick `B ∋ z` with `gB ⊊ B`. If `d >= 0`, the same holds for `g^{-1}`. The
   remaining case, `d` with coordinates of both signs (a **saddle**), needs `n >= 2`.
6. *(Property (T) stabilizers.)* If `L <= Stab_{nV}(x)` has property (T), then every
   element of `L` is the identity on a neighbourhood of `x`.

**What this changes for the Kazhdan hole.** Call a closed invariant `Z` **slope-principal**
for `G` if `s(g,z) = 0` whenever `g ∈ G`, `z ∈ Z`, `gz = z`. By items 4 and 5, `Z` is
slope-principal iff no `g ∈ G` fixing a point of `Z` has a nonzero slope there. Then no
element compresses a brick meeting `Z` into itself, and in `n = 1` there are no saddles.
Item 3 names the invariant behind "it must use nV" in
`minimal-sets-of-kazhdan-subgroups-of-nv-carry-invariant-measures`: germs at points are
slope vectors. It does not separate `nV` from actions whose point stabilizers are
virtually cyclic, such as boundary actions of hyperbolic groups.

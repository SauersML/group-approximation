ESTABLISHED.  Let `V` be Higman's universal finitely presented group.  For
pairs of words `(u_1, u_2)` in the generators of `V`,

```text
{ (u_1,u_2) : <u_1,u_2> is residually finite }   is Pi^0_3-complete,
{ (u_1,u_2) : <u_1,u_2> is amenable }            is Pi^0_2-complete,
{ (u_1,u_2) : <u_1,u_2> has property (T) }       is Sigma^0_1-complete.   (FA1)
```

So the three levels one, two and three are all realized by natural
properties of two-generated subgroups of a single group whose finite
presentation never changes; only the pair of words does.

Let `S` be an infinite simple group, choose `1 != g in S`, and suppose
`Z[S] <= R <= U` are unital rings such that `1-g` is full in `U`.  (The
direct Chatterji--Kassabov envelope has this form, with

```text
U = Z[G~]<p,q>/(p(1-g)q-1).
```

)  Put `Gamma = EL_n(U)` for `n >= 3`.  For `M <| Gamma` define its
elementary level

```text
lev(M) = { a in U : e_ij(a) in M for every i != j }.
```

Then:

1. `lev(M)` is a two-sided ideal of `U`.
2. If `M` is proper, then `lev(M)` is proper.
3. If `M` is proper, no `1-s` with `1 != s in S` belongs to `lev(M)`.
4. Consequently the composite `S -> U^x -> (U/lev(M))^x` is injective.

DERIVATION
[[ck-envelope-level-ideal-screen-proof]]

## Proof

Write `I = lev(M)`.  The elementary identities

```text
e_ij(a+b) = e_ij(a)e_ij(b),
[e_ki(x),e_ij(a)] = e_kj(xa),
[e_ij(a),e_jk(x)] = e_ik(ax)
```

for pairwise distinct indices show, using normality of `M` and elementary
changes of indices, that `I` is an additive subgroup closed under left and
right multiplication by arbitrary elements of `U`.  Thus `I` is a two-sided
ideal.

If `1 in I`, then `M` contains every `e_ij(1)`.  Commuting these with
`e_jk(u)` and changing indices shows that it contains every `e_ij(u)`, so
`M = EL_n(U)`.  Hence a proper `M` has proper level.

For `1 != s in S`, simplicity gives `g in <<s>>_S`.  The identities

```text
1-ab = (1-a)+a(1-b),
1-a^{-1} = -a^{-1}(1-a),
1-hah^{-1} = h(1-a)h^{-1}
```

therefore put `1-g` in the two-sided ideal of `Z[S]` generated by `1-s`.
Since `1-g` is full in `U`, so is `1-s`.

If `1-s in I`, then `M` contains `e_12(1-s)`.  The same two Steinberg
commutator identities show that the normal closure of `e_12(1-s)` contains
`e_ij(a(1-s)b)` for all `a,b in U` and all `i != j`.  Fullness and additivity
then put every elementary generator in `M`, again forcing `M = Gamma`.
This proves (3).

Finally, if two elements `s,t in S` have the same image in `U/I`, then
`s-t in I`, hence `1-s^{-1}t in I`.  Part (3) forces `s^{-1}t=1`, proving
injectivity.

## What this does and does not close

The lemma makes the surviving ring obstruction canonical: every candidate
maximal kernel has a proper level ideal through which the entire simple core
still embeds.  It also rules out any proof that obtains a maximal kernel by
allowing the coefficient core to collapse invisibly at ring level.

It does **not** prove that `lev(M)` is finitely generated, that `M` is a
congruence subgroup of its level, or that a maximal `M` is finitely normally
generated.  Those implications require a normal-structure/congruence theorem
with finiteness control that is not supplied by the Steinberg identities.
In particular, replacing `M` by the relative elementary subgroup of its
level is not justified for an arbitrary noncommutative ring `U`.

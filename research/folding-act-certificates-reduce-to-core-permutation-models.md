Let `D = (A,S,M,nu,mu)` be a design, `E` a forward-sufficient marked partition of `S x M`,
and `W = (Omega, Pi, p)` a Garden-of-Eden window datum for `mu`. Conventions follow
`strict-automata-live-on-canonical-table-groups`.

An **act model** is a pair of finite sets `V`, `U` with arbitrary maps `b_s : V -> U`,
`a_m : U -> V` and `g_w : U -> U`.
- `V_0` is the set of sites where the `E`-equalities of views hold and the marked class
  returns the site. Views may merge more than `E` does.
- `U_1` is a family of window-good outputs with disjoint windows. Such an output satisfies the
  `Pi`-equalities and has distinguished outputs distinct.

**A. Folding count.** Every act model satisfies

    |V_0| <= |U| - kappa |U_1|,     kappa = -log_|A| (1 - |A|^(-|Omega|)).

So any act model violating it certifies that `(D, E, W)` has no strict realization.

**Lemma 0.** Collapsing `V \ V_0` to one point keeps `V_0`, `U` and `U_1`.

**B. Bijective core.** Let `C(D,E)` be the smallest letter set that:
- contains `1_S`, `1_M` and both letters of every marked pair;
- contains `s` and `m` whenever `(s,m) ~_E (s',m')` with `s'`, `m'` in `C`.

Let `B(D,E)` be the finite presentation on core letters with the core relators of `E`.
Suppose an act model has slack `D_𝔐 = |U| - |V_0|`. Then:
- every core letter agrees with a permutation off `O(3^(|S|+|M|)) (D_𝔐+1)` points;
- these permutations form an almost-multiplicative permutation model of `B(D,E)`, with defect
  of the same order;
- for every distinguished window pair joined by a `Pi`-chain through core letters, the core word
  `h` moves at least `|U_1| - O(r 3^(|S|+|M|)) (D_𝔐+1)` points, where `r` is the chain length.

**B1. Class kill.** Suppose some core-expressible distinguished pair has a core word in the
sofic radical of `B(D,E)`, meaning invisible to almost-multiplicative permutation models. Then
two kinds of certificate fail for `(D, E, W)`:
- (i) every **density family**: act models with `D_𝔐/|V| -> 0` and `|U_1|/|V|` bounded below;
- (ii) every **exact** act (`D_𝔐 = 0`) with a window-good output.

- **Invariant:** the sofic radical of the core table group, evaluated on core words of
  distinguished pairs.
- **Step where every member dies:** the window-good density in A, forced to 0 by B(3).
- **Residual:** sparse-slack certificates with `0 < D_𝔐 < kappa |U_1| = o(|V|)`, or with slack a
  fixed positive fraction of `|V|`. They are excluded only under a linear invisibility modulus
  with `K(1+L_h) kappa < 1`.

**C. Total fold.** Let `≈` on `M` identify letters sharing an `E`-class and letters of marked
pairs with `1`. Let `~` on `Omega x M` be generated by:
- `Pi`;
- `(w,m) ~ (w,m')` for `m ≈ m'`;
- `(w,1) ~ (w',1) ⇒ (w,m) ~ (w',m)`.

If `(w,1) ≁ (w',1)` for every distinguished pair, an explicit exact act with one window-good
output exists, and the design is not strict. This is a decidable rule-level filter. Its
hypothesis is implied by separation in any group quotient killing `S`.

## Attempts

- **Decode, avoid, propagate along the core closure (a-gs-pull-2, 2026-09-17). Refuted by all
  three referees (verdicts 3f86443d, e7bbebc7, and a third lens).**
  - **What checks out:** Theorem A, Lemmas 0, 1, 2 and 3(a)(b), B(1) and Proposition C (read as an
    implication). Lens 3 brute-forced C on 278 random valid triples and found no counterexample.
  - **Composition order (lenses 1 and 2):** B(2) proves `pi_m∘pi_s ≈ pi_m'∘pi_s'`. So
    `x_c -> pi_c` models the opposite presentation, not `B(D,E)`. B(3) evaluates the reversed
    word `e = x_{m_1} x_{m_1'}^-1 ... x_{m_r} x_{m_r'}^-1` (the group element `w^-1 w'`), not
    `h`. For `r >= 2`, invisibility of `h` says nothing about `e`.
    - **Counterexample to B1(ii):** `Q = S_3`, `S = M = Q`, `E` the multiplication table,
      `a = (12)`, `b = (123)`, `c = a^-1 b^-1`, and `Omega = {1, a, ab, abc}`. Here `h = cba = 1`,
      but right multiplication on `Q` is an exact act in which every output is window-good.
  - **Vacuity (lenses 1, 2 and 3):** under the standing hypotheses (`E` forward-sufficient, `W`
    Garden-of-Eden), Theorem A already rules out every certificate with `D < kappa|U_1|`. So B1
    never uses invisibility, the stated Residual is false (A excludes sparse-slack
    certificates), and the "step where every member dies" is misattributed. The hypotheses of
    Proposition C can never all hold together.
  - **Fix needed:** replace `h` by its reversal `e` (or state invisibility for `B^rev`). State
    Theorem B and B1 without forward sufficiency and the Garden-of-Eden property, which the proof
    of B never uses. Remove or restate the Invariant and Residual text.

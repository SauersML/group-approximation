Notation as in the target.

## Item 1

- For each orbit `O_i = σ(M) x_i` and each `x ∈ O_i`, choose `m_x ∈ M` with `σ(m_x) x_i = x`,
  taking `m_(x_i) = 1`. Put `e'_x = m_x e_(x_i) = φ(x) e_x`, with `φ(x) = mu_(m_x)(x_i) ∈ Q^x`.
  Let `δ = diag(φ)`, the change of basis from `(e_x)` to `(e'_x)`.
- Let `m ∈ M`, `x ∈ O_i` and `y = σ_m x`. Then `h = m_y^-1 m m_x` fixes `x_i`, so
  `h e_(x_i) = χ_(x_i)(h) e_(x_i)` and
  `m e'_x = m m_x e_(x_i) = m_y h e_(x_i) = χ_(x_i)(h) e'_y`.
  So in the basis `(e'_x)` every element of `M` is monomial, with weights in
  `W = ⟨χ_(x_1)(M_(x_1)), ..., χ_(x_r)(M_(x_r))⟩`.
- Each `f_j^(±1)` is finitary. In the basis `(e'_x)` its entries are its old entries times
  ratios of values of `φ`: finitely many rationals.
- Let `R` be the subring of `Q` generated by `W` and those entries. Products of column-finite
  matrices over `R` are column-finite over `R`, and `g_j^(±1) = m_j^(±1) f_j^(±1)` in either
  order. So `δ^-1 Γ δ` consists of column-finite matrices over `R`.

## Item 2

- Let `S = ⋃_j supp(f_j)`, where `supp(f)` is the finite set of indices whose row or column in
  `f` differs from that of the identity.
- Moving the monomial factors of a word in the `g_j^(±1)` to the left writes every element of
  `Γ` as `m f`. Here `m ∈ M`, and `f` is a product of conjugates `m' f_j^(±1) m'^-1` with
  `m' ∈ M`. Such a conjugate has support `σ_(m')(supp f_j)`, and the support of a product lies
  in the union of the supports. So `supp(f) ⊆ σ(M) S`.
- Take `y ∉ σ(M) S` and any `x ≠ y`. If `1 + e_xy = m f ∈ Γ`, then `f e_y = e_y`. So
  `(1 + e_xy) e_y = m e_y = mu_m(y) e_(σ_m y)` is a multiple of a single basis vector. But it
  equals `e_y + e_x`, a contradiction.
- Hence `SL_X(Q) <= Γ` forces `X = σ(M) S`, which is a union of at most `|S|` orbits.

## Items 3 and 4

- Assume `SL_X(Q) <= Γ`. By Item 2, Item 1 applies. `δ` is monomial, so it normalizes
  `SL_X(Q)`, and `δ^-1 Γ δ ⊇ SL_X(Q) ∋ 1 + (1/p) e_xy` for every prime `p`. So `R = Q`.
- `R` is generated by `W` and finitely many rationals, and a subring of `Q` is `Z[1/P]`
  for a set of primes `P`. So `W` must involve infinitely many primes.
- `W` is generated by the `r` subgroups `χ_(x_i)(M_(x_i))`. If all of them were finitely
  generated, `W` would involve finitely many primes. So some `χ_(x_i)(M_(x_i))` is not finitely
  generated. It is an abelian quotient of `M_(x_i)`, so `M_(x_i)` is not finitely generated.
  This is Item 3.
- Item 4: if every `M_(x_i)` is finitely generated, `R = Z[1/N]` for some `N`.
  - Suppose `1 + q y ∈ Γ` for all `q ∈ Q`, with `y ≠ 0`. Then `δ^-1 y δ` has a nonzero entry
    `c`, and `qc ∈ Z[1/N]` for all `q ∈ Q`, which is false.
  - A linearly embedded `GL_n(Q)` contains `1 + q ρ(e_12)` (for `n >= 2`) or
    `1 + (q-1)ρ(1)` (for `n = 1`, with `q ∈ Q^x`). Either family gives the same
    contradiction. ∎

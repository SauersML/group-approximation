# Remove each inner packet label by y_i equals k_i inverse r_i

Use `(IP1)` to make `y_i=k_i^{-1}r_i` centralize `K`. The local K labels
commute and multiply to one on every face, so all involution, commutator, and
product relations on the `r_i` become exactly the original face relations on
the `y_i`. This gives mutually inverse presentation maps with
`K x Gamma_H`.

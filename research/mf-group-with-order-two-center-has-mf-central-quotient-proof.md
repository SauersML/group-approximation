## Why sufficient

Let `V_j : Gamma -> U(d_j)` be unitary lifts of a faithful homomorphism
of `Gamma` into a norm matrix corona: `V_j(1) = I`,
`||V_j(g)V_j(h) - V_j(gh)|| -> 0` for all `g, h`, and
`liminf ||V_j(g) - I|| > 0` for `g != 1`.

**Step 1, an exact involution.**  `S_j = V_j(c)` satisfies
`||S_j^2 - I|| -> 0`.  For a unitary with `||S^2 - I|| = delta < 2`, no
eigenvalue has real part zero, and rounding each eigenvalue to the nearer
of `+-1` gives a self-adjoint unitary `J` with `||J - S|| <= delta/sqrt 2`
(for `|lambda| = 1`, `|lambda^2 - 1| = |lambda - 1| |lambda + 1|` and the
larger factor is at least `sqrt 2`).  So `J_j^2 = I` and
`||J_j - S_j|| -> 0`.  Since `c` is central, `||[J_j, V_j(g)]|| -> 0` for
every `g`.

**Step 2, exact commutation with `J_j`.**  Put
`B_j(g) = (V_j(g) + J_j V_j(g) J_j)/2`, which commutes with `J_j` and has
`||B_j(g) - V_j(g)|| -> 0`; for fixed `g` it is eventually invertible,
and its polar unitary `W_j(g) = B_j(g) (B_j(g)^* B_j(g))^(-1/2)` lies in
the C*-algebra generated by `B_j(g)`, so it still commutes with `J_j`,
and `||W_j(g) - V_j(g)|| -> 0`.  Set `W_j(1) = I`, `W_j(c) = J_j`, and
any commuting unitaries on the finitely many exceptional `j`.  Then
`(W_j)` is again a faithful asymptotic representation, and
`W_j(g) = W_j^+(g) (+) W_j^-(g)` on the `+-1` eigenspaces `H_j^(+-)` of
`J_j`.

**Step 3, kill the sign.**  On `(H_j^+ (x) conj H_j^+) (+) (H_j^- (x) conj H_j^-)`
put

```text
Psi_j(g) = ( W_j^+(g) (x) conj(W_j^+(g)) ) (+) ( W_j^-(g) (x) conj(W_j^-(g)) ),
```

omitting empty blocks.  For unitaries `U, V`,
`||U (x) conj U - V (x) conj V|| <= 2 ||U - V||` (insert `V (x) conj U`),
so `||Psi_j(g)Psi_j(h) - Psi_j(gh)|| <= 2 ||W_j(g)W_j(h) - W_j(gh)|| -> 0`,
and `Psi_j(c) = (I (x) I) (+) ((-I) (x) (-I)) = I` exactly.  So `Psi`
defines a corona homomorphism of `Gamma` that factors through
`Gamma/<c>`.

**Step 4, nothing else dies.**  For a finite-dimensional unitary `U`,
diagonalizing gives `||U (x) conj U - I|| = max |lambda - mu|` over
eigenvalues `lambda, mu` of `U`.  If `||Psi_j(g) - I|| -> 0`, each
nonempty block `W_j^(+-)(g)` is within `||Psi_j(g) - I||` of a scalar,
so `W_j(g)` is asymptotically a scalar on each of the two blocks that
every `W_j(h)` preserves; hence `||W_j(g)W_j(h) - W_j(h)W_j(g)|| <=
2 ||Psi_j(g) - I|| -> 0`, i.e. `||W_j([g,h]) - I|| -> 0`.  Faithfulness
of `(W_j)` gives `[g, h] = 1` for all `h`, so `g in Z(Gamma) = <c>`.
Thus `ker Psi = <c>` and `Gamma/<c>` embeds in the norm matrix corona.

**Error bookkeeping.**  If a finite window has multiplicativity,
involution, and central-commutation errors at most `eps < 1/4`, then
`||W_j(g) - V_j(g)|| <= (1 + sqrt 2) eps` on that window and the
multiplicativity error of `Psi_j` is at most `(8 + 6 sqrt 2) eps`,
independent of `d_j`.

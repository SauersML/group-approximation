The matrix calculation `(DCG5)` identifies the subgroup as
`C_N semidirect C_(2K)`.  The size inequalities for `2^m+-1` prove that
`h(2)` has projective order exactly `2K`.  Abelianizing changes the action
relation into `3[u(1)]=0`; because `3|N`, the unipotent summand becomes
`C_3`, independently of the diagonal `C_(2K)` summand.  The fixed set
`mu_3` has no nontrivial sequence converging to one, proving the final
small-character assertion.

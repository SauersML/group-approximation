This is a self-contained derivation. It imports only the definitions of `E_nu(P)` and `E_2` as recorded in
`infinite-shift-higman-compiler` and `fp-bounded-displacement-e2-envelopes-are-eventually-periodic` (`E_m`:
`pi(x+m) = pi(x)+m` for all sufficiently large `x`).

**Near index.** A near permutation of a set `A` is a bijection `f : A \ F -> A \ F'` with `F`, `F'` finite. It is
taken modulo agreement off a finite set, and `eta(f) = |F'| - |F|`. This quantity is well defined on classes and is
additive under composition. For `s(n) = n+1` on `N` we get `F = ∅`, `F' = {0}`, so `eta(s) = 1`.

**Step 1 (FSym is finitely normally generated).** `E_2` contains every finitary permutation, since it satisfies
the periodicity condition beyond its support. So `FSym(N) <= E`. It is normal in `Sym(N)`, hence in `E`. All
transpositions are conjugate inside `FSym(N)` and generate it. So `FSym(N)` is the normal closure in `E` of `(0 1)`.
If `E = <X | S>` with `X` and `S` finite, then `Q = <X | S, w>`, where `w` is a word for `(0 1)`.

**Step 2 (near parity).**

- Let `pi in E_2`. For large `x`, `pi(x) = x + c_{x mod 2}`, with integers `c_0` and `c_1`.
- If `c_0` and `c_1` had different parities, then the tails of both parity classes would map into one class. The
  other class would miss infinitely many values, which is impossible for a bijection.
- So `pi(evens)` differs by a finite set from the evens (`c_0` even) or from the odds (`c_0` odd). The elements
  `rho(g)` preserve the evens exactly.
- Composites of permutations with this property have it again. So `nu_par(pi) in Z/2` (which class the evens go to,
  up to finite sets) is a homomorphism on `E`.
- It is surjective: `omega = prod_k (2k 2k+1)` lies in `E_2` and swaps the classes.
- Put `E^0 = ker nu_par`, so `[E : E^0] = 2`.

**Step 3 (germ map).**

- For `pi in E^0`, restrict `pi` to the evens and to the odds. Modulo finite sets this gives two near permutations,
  transported to `N` by `2k -> k` and `2k+1 -> k`. This defines a homomorphism
  `Phi : E^0 -> NSym(N) x NSym(N)`.
- `Phi(pi) = 1` exactly when `pi` has finite support. So `ker Phi = FSym(N)`, and `E^0/FSym(N) ≅ Phi(E^0)`.
- **Index sum.** Let `D` be the cofinite set of points of the evens and odds mapped into their own classes. Then
  `eta(Phi_1(pi)) + eta(Phi_2(pi)) = |N \ pi(D)| - |N \ D| = |pi(N \ D)| - |N \ D| = 0`.
- **Generators.** `E = <rho(P), E_2^0, omega>`, where `omega` normalizes `E_2^0 = E_2 ∩ E^0` and `omega^2 = 1`. Moving
  the letters `omega` through a word with an even number of them shows
  `E^0 = < rho(P), omega rho(P) omega, E_2^0 >`.
- **Images.** `Phi(rho(g)) = (lambda_g, 1)`, because `rho(g)(2 nu(h)) = 2 nu(gh)` and the odds are fixed.
  `omega rho(g) omega` fixes the evens and sends `2 nu(h)+1` to `2 nu(gh)+1`, so its image is `(1, lambda_g)`.
- For `pi in E_2^0`, both `c_0` and `c_1` are even, so `Phi(pi) = (s^{c_0/2}, s^{c_1/2})`. The index sum forces
  `c_1 = -c_0`.
- Every pair `(s^a, s^-a)` occurs: `sigma = (x -> x+2` on evens, `x -> x-2` on odds `>= 3`, `1 -> 0)` is a bijection
  in `E_2` with `Phi(sigma) = (s, s^-1)`.
- Hence `Phi(E^0) = < (lambda_g,1), (1,lambda_g), (s,s^-1) : g in P >`, which lies inside `F^-`.

**Step 4 (the whole antitwisted product).**

- Let `W = < s^n lambda_h s^-n : n in Z, h in P >`. It is normalized by `s` and contains `lambda(P)`, so it is normal
  in `R`. So `W` is the normal closure of `lambda(P)`.
- `R/W` is generated by the image of `s`, hence cyclic. The map `eta` vanishes on `W` (each `lambda_h` is a
  bijection) and maps `R` onto `Z`. So `R/W ≅ Z` and `W = K`.
- Conjugating by `(s,s^-1)^n` gives `(s^n lambda_h s^-n, 1)`. So `K x 1 <= Phi(E^0)`, and symmetrically `1 x K`.
- For `(a,b) in F^-` with `eta(a) = n`, write `(a,b) = (a s^-n, b s^n)(s^n, s^-n)`. Both first factors lie in `K`.
  So `Phi(E^0) = F^-`.
- `Q^0 = E^0/FSym` has index 2 in `Q`, and finite presentability passes both ways across finite index.

**Step 5 (retract).**

- `iota(a) = (a, s^-eta(a))` is a homomorphism, since `a -> s^-eta(a)` is a homomorphism into the abelian group
  `<s>`. It takes values in `F^-`, and `pr_1 ∘ iota = id`.
- **Lemma.** A retract of a finitely presented group is finitely presented. Let `G = <X | S>` be finite, with
  `r : G -> H` and `i : H -> G` such that `r i = id`. Put `N = << x^-1 i(r(x)) : x in X >>`, so `N <= ker r`.
  - In `G/N`, every generator equals `i(r(x))`, so `i` followed by projection is surjective onto `G/N`.
  - `r` factors through `G/N`, and composing gives `id_H`. So that map is also injective.
  - Hence `G/N ≅ H` and `ker r = N`. `H = <X | S, x^-1 i(r(x))>` is a finite presentation.
- Apply the lemma to `pr_1 : F^- -> R` and `iota`. QED

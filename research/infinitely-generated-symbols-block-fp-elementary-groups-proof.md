Lane proof (gq-deep-adelic-1), not independently reviewed. This is the argument of (e) in
`laurent-rational-symbols-block-fp-elementary-groups-proof`, stated for any ring.

1. **R is finitely generated.**
   - Suppose `E_N(R)` is generated by finitely many matrices, and let `R'` be the subring
     generated by their entries.
   - Then `E_N(R) ⊆ GL_N(R')`. So for every `r`, `e_12(r)` has its entries in `R'`, which gives
     `r ∈ R'`. Hence `R = R'`.
2. **St_N(R) is finitely generated.**
   - Let `T` be a finite ring-generating set, together with `1`. Consider the subgroup generated
     by the `x_ij(t)`, `t ∈ T`.
   - The set of `r` with every `x_ij(r)` in that subgroup is closed under sums, because
     `x_ij(a) x_ij(b) = x_ij(a+b)`. It is closed under products, because
     `[x_ij(a), x_jk(b)] = x_ik(ab)` for distinct `i, j, k` (`N >= 3`).
   - So it is a subring containing `T`, hence all of `R`.
3. **Finite normal generation (B. H. Neumann).** `E_N(R) = St_N(R)/K_2(N, R)` is a finitely
   presented quotient of a finitely generated group. So `K_2(N, R)` is the normal closure of
   finitely many elements `k_1, ..., k_m`.
4. **Stable image.**
   - Let `ι : St_N(R) -> St(R)` be stabilization. `ι` maps `K_2(N, R)` into
     `K_2(R) = ker(St(R) -> E(R))`, which is central in `St(R)` (Kervaire; the centre of `St(R)`
     is `K_2(R)`).
   - So `ι(g k_i g^(-1)) = ι(g) ι(k_i) ι(g)^(-1) = ι(k_i)`.
   - Hence `ι(K_2(N, R))` is generated by `ι(k_1), ..., ι(k_m)`, and it is finitely generated.
     This is the first half of part 1.
5. **Symbols live at rank N.**
   - For commuting units `a, b`, let `w_12(a) = x_12(a) x_21(-a^(-1)) x_12(a)` and
     `h_12(a) = w_12(a) w_12(-1)`. Put `{a, b}_N = h_12(ab) h_12(a)^(-1) h_12(b)^(-1)`.
   - It maps to `diag(ab, (ab)^(-1)) diag(a, a^(-1))^(-1) diag(b, b^(-1))^(-1) = I`, because `a`
     and `b` commute. So `{a, b}_N ∈ K_2(N, R)`.
   - Its stabilization is the symbol `{a, b} ∈ K_2(R)`. So `Sym(R) ⊆ ι(K_2(N, R))`, which
     completes part 1.
6. **Part 2.** A subgroup of a finitely generated abelian group is finitely generated. So if
   `Sym(R)` is not finitely generated, `E_N(R)` is not finitely presented. If `C` is finite
   normal and `E_N(R)/C` were finitely presented, then `E_N(R)` would be finitely presented, as an
   extension of a finitely presented group by a finite group (P. Hall).

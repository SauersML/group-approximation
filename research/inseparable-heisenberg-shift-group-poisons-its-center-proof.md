## 0. Recursively inseparable sets

Let `φ_e` be a standard enumeration of the partial computable functions. Put
`A0 = {e : φ_e(e) = 0}` and `B0 = {e : φ_e(e) = 1}`. These sets are disjoint and recursively
enumerable. Suppose a recursive `R` has `A0 ⊆ R` and `R ∩ B0 = ∅`. Let `e` be an index of the
total computable function that is `1` on `R` and `0` off `R`. If `e in R`, then `φ_e(e) = 1`, so
`e in B0`, which contradicts `R ∩ B0 = ∅`. If `e ∉ R`, then `φ_e(e) = 0`, so `e in A0 ⊆ R`,
which is also a contradiction. Now take `A = A0 + 1` and `B = B0 + 1` inside `{1, 2, ...}`.

## 1. The model: c has order exactly k

Let `C_k = Z/k` (with `C_∞ = Z`) and `V = ⊕_{i in Z} Z e_i`. Let `β : {1,2,...} -> {0,1}` be the
indicator function of `B`. Define a bilinear map `θ : V × V -> C_k` on the basis by

    θ(e_i, e_j) = β(j - i)  if i < j,       θ(e_i, e_j) = 0  if i >= j.

On `H = V × C_k` put `(v,s)(v',s') = (v+v', s+s'+θ(v,v'))`.

- **Group.** This is associative because `θ` is bilinear.
- **Identity and inverses.** The identity is `(0,0)`, and `(v,s)^-1 = (-v, -s+θ(v,v))`.
- **The center.** `c = (0,1)` is central of order `k`.
- **Commutators.** For `x = (v,0)` and `y = (w,0)` we get `xy = (v+w, θ(v,w))` and
  `yx = (v+w, θ(w,v))`. They differ by a central element, so

      [x,y] = x^-1 y^-1 x y = c^{θ(v,w) - θ(w,v)},    in particular   [e_0, e_n] = c^{β(n)}  (n >= 1).

- **The shift.** The shift `σ(e_i) = e_{i+1}` preserves `θ`, because `θ(e_i,e_j)` depends only on
  the order of `i, j` and on `j - i`. So `(v,s) -> (σv, s)` is an automorphism of `H` fixing `c`.
- **The model group.** Let `M = H ⋊ <a>` with `a^-1 x a = σ(x)`, and send `b -> (e_0,0)` and
  `c -> (0,1)`.

Then `a^-n b a^n = (e_n, 0)` and `[b, a^-n b a^n] = c^{β(n)}`. This is `1` for `n in A`, because
`A ∩ B = ∅`, and it is `c` for `n in B`. The relations `c^k`, `[a,c]` and `[b,c]` also hold. So the
assignment defines a homomorphism `Q_k -> M` sending `c` to an element of order `k`. The order of
`c` in `Q_k` divides `k` (there is no condition when `k = ∞`) and is at least the order of its
image, so it is exactly `k`.

`Q_k` has three generators and an r.e. set of relators, because `A` and `B` are r.e.

The script `experiments/ck-poisoned-envelope-2026-09-17/heisenberg_model_check.py` checks
associativity, the inverse formula and `[e_0,e_n] = c^{β(n)}` on random data. It is a sanity
check, not part of the proof.

## 2. Poisoning

Let `π : Q_k -> L` be a homomorphism with `π(c) != 1`, and put `P = π(Q_k)`, generated by
`π(a), π(b), π(c)`. Suppose `P` has solvable word problem with respect to these generators. For
`n >= 1` the word `w_n = [b, a^-n b a^n]` can be computed from `n`. So

    R = { n >= 1 : π(w_n) = 1 in P }

is recursive. It contains `A`, because those relators hold. It is disjoint from `B`, because
there `π(w_n) = π(c) != 1`. That contradicts Section 0. Hence `P` has unsolvable word problem.

Solvability of the word problem does not depend on the finite generating set, and it passes to
finitely generated subgroups. So every finitely generated group containing `P` has unsolvable
word problem, and for an arbitrary group, every finitely generated subgroup containing `P` does. ∎

## Why sufficient

Notation is as in the claim: `F = F(X)` with `X` finite, `K <= R <= F` normal,
`E = F/K`, `C = R/K` central in `E`, `Q = F/R` hyperlinear, and `B_rho` the
ball of radius `rho` in `F`. Centrality of `C` means `[F, R] <= K`.

**(P0) Inputs.**
- (i) Among marked groups on the fixed generating set `X`, the hyperlinear
  ones form a closed set, so the non-hyperlinear ones form an open set
  (`local-approximation-properties-are-marked-closed`). Concretely: if
  `N_n, N` are normal subgroups of `F`, `F/N` is non-hyperlinear, and for
  every `rho` we have `N_n intersect B_rho = N intersect B_rho` for all large
  `n`, then `F/N_n` is non-hyperlinear for all large `n`.
- (ii) Item 4 of `hyperlinear-shadow-schur-cokernel-criterion`: if a
  countable group `G` has `D(G) = Res(G)/[Res(G), G]` not divisible, then
  some finitely generated hyperlinear group has a non-hyperlinear central
  extension by `Z/p`.
- (iii) If `G/C'` is hyperlinear then `Res(G) <= C'`. A group is hyperlinear
  iff `Res(G) = 1`. (Both are (P0) of that proof.)

**(P1) Item 1: cover transport.** Let `S <= R` be normal in `F`. Put
`L = S intersect K`, which is normal in `F`.
- *Diagonal image.* The kernel of `F --> F/K x F/S` is `L`, so `E_S := F/L`
  is the diagonal image of `F` in `E x F/S`.
- *The kernel.* `S/L = S/(S intersect K)` is isomorphic to `SK/K <= R/K = C`
  (second isomorphism theorem). The quotient of `E_S` by it is `F/S`.
- *Centrality.* `[F, S] <= S`, since `S` is normal, and `[F, S] <= [F, R] <= K`.
  Hence `[F, S] <= L`, so `S/L` is central in `F/L`.
- *Finite generation.* Suppose `S` is the normal closure of a finite set
  `Sigma`. Every element of `S` is a product of conjugates `f s^{+-1} f^{-1}`
  with `s in Sigma`, and `f s f^{-1} = s [s^{-1}, f]`, where
  `[s^{-1}, f] in [F, S] <= L`. So `S/L` is generated by the images of
  `Sigma`, and `A_S` is a finitely generated abelian group.
- *Convergence.* Assume `S intersect B_rho = R intersect B_rho`. For
  `w in B_rho` we have `w in K` iff `w in K intersect R`, since `K <= R`; and
  `R intersect B_rho = S intersect B_rho`. Hence
  `L intersect B_rho = K intersect B_rho`, and the same holds on every smaller
  ball. So along any sequence of covers `S_n` whose ball intersections
  stabilize to those of `R`, the marked groups `E_(S_n)` converge to `E`.

This proves (CT1) and item 1.

**(P2) Item 2: gap theorem.** Assume `E` is non-hyperlinear and `Q` is AHC.
- For each `n` choose a hyperlinear finitely presented cover `P_n = F/S_n`
  with `S_n intersect B_n = R intersect B_n`. Then for every fixed `rho` and
  every `n >= rho`, `S_n intersect B_rho = R intersect B_rho`.
- By (P1), the groups `E_n = E_(S_n)` converge to `E`.
- By (P0)(i), `E_n` is non-hyperlinear for some `n`. Fix that `n`.
- `E_n` is a central extension of the hyperlinear group `P_n` by the
  finitely generated abelian group `A_n = A_(S_n) <= C`.
- By (P0)(iii), `Res(E_n) <= A_n`, and `Res(E_n) != 1`. So `Res(E_n)` is a
  nonzero subgroup of a finitely generated abelian group, hence itself a
  nonzero finitely generated abelian group, hence not divisible.
- Because `Res(E_n)` is central, `[Res(E_n), E_n] = 1`, so
  `D(E_n) = Res(E_n)` is not divisible.
- By (P0)(ii), some finitely generated hyperlinear group has a non-hyperlinear
  central extension by `Z/p`.

The first sentence of item 2 is the group `E_n` over `P_n` with kernel `A_n`.

**(P3) Item 3: biography.** Assume the gap hypothesis: item (a) holds, (a')
fails.
- *`Q` is infinitely presented.* Otherwise `S = R` is a hyperlinear finitely
  presented cover agreeing on every ball, so `Q` is AHC. Item 2 would then
  give (a').
- *A radius `rho_0`.* If for every `rho` some hyperlinear finitely presented
  cover agreed with `R` on `B_rho`, then `Q` would be AHC and item 2 would
  give (a'). So some `rho_0` has no such cover: every finitely presented
  cover agreeing on `B_rho_0` is non-hyperlinear. Covers agreeing on a larger
  ball also agree on `B_rho_0`, so the same holds for every `rho >= rho_0`.
- *`Res(E)` is nonzero divisible.* It is nonzero because `E` is not
  hyperlinear. It is central because it lies in `C` by (P0)(iii). So
  `D(E) = Res(E)`. If it were not divisible, (P0)(ii) would give (a').
- *Transported witnesses.* By (P1), for every finitely presented cover
  agreeing on a large ball, `E_S` is a non-hyperlinear central extension with
  finitely generated kernel over a base that, by the previous bullet, is
  non-hyperlinear.

For the reduction to finitely generated pairs, let `E'` be a countable
non-hyperlinear central extension of a hyperlinear `Q'` by `C'`.
- A group is hyperlinear iff all its finitely generated subgroups are, so some
  finitely generated `E_0 <= E'` is non-hyperlinear.
- `C' intersect E_0` is central in `E_0`.
- `E_0/(C' intersect E_0)` embeds in `Q'`, so it is hyperlinear.
- Present `E_0 = F/K` on a finite generating set, and let `R` be the preimage
  of `C' intersect E_0`.

## Why this is the right target

The three dead mechanisms for the divisible gap all enlarge the base or pull
back along a finite-kernel extension. The obstruction there is that an
infinite-order class cannot be made finite by extension. Transport along covers
removes that obstruction outright: the kernel of (CT1) is finitely generated for
structural reasons. Everything left sits in one place, the hyperlinearity of
finitely presented covers of the base. That is also where any proof that the
gap is empty would have to add input.

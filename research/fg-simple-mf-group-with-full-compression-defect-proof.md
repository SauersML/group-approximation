## Step 1. The group Delta

Let `Omega = Z x Z/3`.  Lane `j` is `Z x {j}`.  Let `rho(i,j) = (i, j+1)`.
For `v in Z^3`, let `T_v(i,j) = (i + v_j, j)`, and let `t = T_d` with
`d = (1, 0, -1)`.

`rho T_v rho^-1 = T_(v')` with `v'_j = v_(j-1)`.  So `Q = <t, rho>` is
`T_Lambda x| <rho>`, where `Lambda` is the sum-zero lattice in `Z^3`,
spanned by the cyclic shifts of `d`.  `Q` is virtually `Z^2`.

A nontrivial element of `Q` moves infinitely many points of `Omega`, so
`Q` meets `FSym(Omega)` trivially.  Let
`Delta = FAlt(Omega) x| Q <= Sym(Omega)`.  Then `Delta` is elementary
amenable: it is locally finite by virtually abelian.

**(1a) Order-3 generation.**  Let `b = t rho^-1`.  Then

```text
b^3 = t (rho^-1 t rho) (rho^-2 t rho^2) rho^-3,
```

and this translates lane `j` by `d_j + d_(j+1) + d_(j+2) = 0`.  So
`b^3 = 1` and `b != 1`, and `t = b rho` is a product of two elements of
order 3.

**(1b) Finite generation.**  Let `B = {0,1} x Z/3` and
`H = < T_v Alt(B) T_v^-1 : v in Lambda > <= <Q, Alt(B)>`.

Lemma: if `A` and `C` are finite subsets of `Omega` with `|A| >= 4` and
`|A ∩ C| >= 2`, then `<Alt(A), Alt(C)>` contains `Alt(A ∪ C)`.

Proof.  Pick `p, q` in `A ∩ C` and `x` in `C \ A`.  Then `(p, q, x)` lies
in `Alt(C)`.  `Alt(A)` is 2-transitive on `A` because `|A| >= 4`, so
conjugating gives `(a, a', x)` for all distinct `a, a'` in `A`.  These
elements together with `Alt(A)` generate `Alt(A ∪ {x})`.  Replace `A` by
`A ∪ {x}` and repeat for each point of `C \ A`.

Now take `e = (1,0,-1)` and `f = (0,1,-1)`, which generate `Lambda`.

- `T_v B` and `T_(v+e) B` share 4 points.
- `T_v B` and `T_(v+f) B` share 4 points.
- Every point `(i, j)` lies in some `T_v B`: take `v_j = i` and adjust the
  other coordinates so the sum is zero.

List the elements of `Lambda` in breadth-first order for the generators
`±e, ±f`.  Each new translate then meets the union of the earlier ones in
at least 2 points.  By the lemma, `H` contains `Alt(A_n)` for an
exhausting increasing chain of finite sets `A_n`, and so
`H = FAlt(Omega)`.

Hence `Delta = < rho, b, Alt(B) >`.  `Alt(B) = Alt(6)` is generated by
3-cycles, so **`Delta` is generated by finitely many elements of order 3.**
The artifact checks `b^3 = 1` and `t = b rho` exactly.  It also checks that
the 9 translates with `v` in a box generate `Alt(14)` on their union.

**(1c) The cell.**  Let

```text
u = t,   l = ((0,0),(1,0),(2,0)),   c = ((-3,0),(-2,0),(-1,0)).
```

Since `t` moves lane 0 by `+1`, `l_k = u^k l u^-k = ((k,0),(k+1,0),(k+2,0))`.

- `L = < l_k : k >= 0 >` lies in `FAlt(N x {0})`, so `L` is locally
  finite, and `u L u^-1 = < l_(k+1) > <= L`.
- The support of `c` is disjoint from `N x {0}`, so `c` lies in `C(L)`.
- `u c u^-1 = ((-2,0),(-1,0),(0,0))` shares exactly the point `(0,0)` with
  the support of `l`.  Two 3-cycles that share exactly one point do not
  commute, so `[u c u^-1, l] != 1`.
- `u = t` has infinite order.

The artifact checks the commutations for `k < 20` and the
non-commutation exactly.

## Step 2. The groupoid, and simplicity and finite generation of S

`Delta` is countably infinite.  By (GJS), `2^Delta` has a free minimal
subflow `X`, and `X` is a Cantor space.  Let `G = Delta x| X` be the
action groupoid.

- **Groupoid of germs.** The action is free.  If `g` and `g'` have the
  same germ at `x`, then `g^-1 g'` fixes a point, so `g = g'`.  Hence `G`
  is the groupoid of germs of the action.  It is Hausdorff, etale and
  second countable, and it is effective.
- **Minimal.** The `G`-orbits are the `Delta`-orbits, which are dense
  because `X` is minimal.  Each orbit is infinite, so it has at least 5
  points.
- **Expansive.** `Delta` is finitely generated, and `(Delta, X)` is a
  subshift, being a closed invariant subset of `2^Delta`.  By (E),
  (4) implies (2), so `G` is expansive.

By (N), Theorem 4.1, `S = A(G)` is simple.  By (N), Theorem 5.6, `S` is
finitely generated.

The topological full group `F(G)` consists of the homeomorphisms `h` of
`X` with a locally constant cocycle `gamma_h : X -> Delta` such that
`h(x) = gamma_h(x) x`.  Freeness makes `gamma_h` unique.  The action map
`Delta -> F(G)` is injective, because the action is free and `X` is
nonempty.

## Step 3. Delta lies in S

**Fundamental domains.** Let `K` be a finite group acting freely on a
compact zero-dimensional metrizable space `X`.  Then there is a clopen
`U` with `X = ⊔_(k in K) kU`.

Proof.
1. Each `x` has a clopen neighbourhood `V_x` whose `K`-translates are
   pairwise disjoint, because the points `kx` are distinct and clopen sets
   form a basis.  Take a finite subcover `V_1, ..., V_m`.
2. Set `W_i = V_i \ K(V_1 ∪ ... ∪ V_(i-1))` and `U = ⋃ W_i`.  Each `W_i`
   is clopen.  The translates of `W_i` are disjoint because `W_i <= V_i`.
3. For `j < i`, the sets `K W_i` and `K W_j` are disjoint.  Indeed, if
   `k w` lies in `W_j <= V_j` with `w` in `W_i`, then `w` lies in
   `k^-1 V_j <= K V_j`, which contradicts the definition of `W_i`.
4. The translates cover `X`.  Given `x`, let `i` be the least index with
   `x in K V_i`, and write `x = k v` with `v` in `V_i`.  If `v` lay in
   `K V_j` for some `j < i`, then `x` would too.  So `v` lies in `W_i`.

**Elements of order 3 lie in A(G).** Let `beta` in `Delta` have order 3.
It acts freely on `X`, so the lemma gives a clopen `U` with
`X = U ⊔ beta U ⊔ beta^2 U`.

Put `U_i = beta^i U` for `i` in `Z/3`.  Let `F_(i,j)` be the bisection of
germs of `beta^(i-j)` on `U_j`, which maps `U_j` onto `U_i`.

- Since `beta^3 = 1`, these compose consistently: the composite of
  `F_(i1,i2)` and `F_(i2,i3)`, in the source's product
  `F_(i2,i3) F_(i1,i2)`, is the family of germs of a power of `beta`
  between the two end sets, which is `F_(i1,i3)`.  The same holds in the
  opposite composition convention.
- `F_(i,i) = U_i` are disjoint clopen subsets of the unit space.

So `F` is a degree-3 multisection.  The 3-cycle `(0 1 2)` of `A_3` maps
`U_0 -> U_1 -> U_2 -> U_0`, by `beta` on each piece.  Its image in `F(G)`
is therefore `beta` itself, so `beta` lies in `A(F) <= A_3(G) = A(G)`.

By (1a) and (1b), `Delta` is generated by elements of order 3.  So
**`Delta <= S`**.  The cell of (1c) is a cell in `S`, because commutation
relations are algebraic.  Hence `D_S(L)` is a nontrivial normal subgroup
of the simple group `S`, and `D_S(L) = S`.

## Step 4. S is MF

Let `A = C(X) x|_r Delta`.  Write `u_g` for the canonical unitaries, with
`u_g f u_g^* = f ∘ g^-1`, so `f u_g = u_g (f ∘ g)`.

**(4a) F(G) embeds in U(A).**  For `h` in `F(G)`, let
`X_g = gamma_h^-1(g)`.  These are clopen sets, only finitely many are
nonempty, and they partition `X`.  Put

```text
W_h = sum_g u_g 1_(X_g).
```

- **Multiplicative.** Take `h`, `h'` with cocycle pieces `X_g` and
  `X'_(g')`.  Then

  ```text
  u_g 1_(X_g) u_(g') 1_(X'_(g')) = u_(g g') 1_(g'^-1 X_g ∩ X'_(g')).
  ```

  On `g'^-1 X_g ∩ X'_(g')` we have `h'(x) = g' x` and `h(g' x) = g g' x`.
  So these sets are the cocycle pieces of `h h'` for the value `g g'`,
  and `W_h W_(h') = W_(h h')`.
- **Unitary.** Since `W_id = 1`, each `W_h` is invertible with inverse
  `W_(h^-1)`.  A direct computation gives
  `W_h^* = sum_g 1_(X_g) u_g^* = W_(h^-1)`.
- **Injective.** If `W_h = 1`, then applying `E` gives `1_(X_e) = 1`.  So
  `gamma_h = e` everywhere and `h = id`.

Thus `h -> W_h` is an injective homomorphism `F(G) -> U(A)`.

**(4b) A is quasidiagonal, in fact AF-embeddable.**
- `A` is separable.  It is nuclear because `C(X)` is nuclear and `Delta`
  is amenable, so it is exact.
- `A = C*_r(G)` with `G` etale, Hausdorff, locally compact and second
  countable, so (BL) gives the UCT.
- Faithful trace. `Delta` is amenable, so there is a `Delta`-invariant
  Borel probability measure `mu` on `X`.  Its support is closed, invariant
  and nonempty, so it is all of `X` by minimality.  Then
  `tau = mu ∘ E` is a tracial state:
  `tau(f u_g) = delta_(g,e) ∫ f d mu`, and invariance of `mu` gives the
  trace property.  It is faithful because `E` is faithful and `mu` has
  full support.  It is amenable because `A` is nuclear.
- By (AF), `A` embeds in a unital simple AF algebra `D`.  Let `p` be the
  image of `1_A`.  Then `A` embeds unitally in the corner `pDp`, which is
  again AF.

**(4c) Unital AF algebras embed in the matrix corona.**
1. Write `pDp` as the closure of an increasing union of finite-dimensional
   unital subalgebras `D_n`.
2. Each `D_n` is injective, so there is a conditional expectation
   `phi_n : pDp -> D_n`.  Then `phi_n(x) = x` for `x` in `D_m` with
   `m <= n`.  Because the `phi_n` are contractive and the `D_m` are dense,
   `||phi_n(x) - x|| -> 0` for every `x`.
3. So `x -> [phi_n(x)]_n` is an isometric unital `*`-homomorphism
   `pDp -> prod_n D_n / directSum_n D_n`.
4. Embed `D_n` unitally in `M_(k_n)`.  This gives a unital embedding
   `pDp -> prod_n M_(k_n) / directSum_n M_(k_n)`.

**(4d) Conclusion.** The composite

```text
S <= F(G) -> U(A) -> U(pDp) -> U(prod_n M_(k_n) / directSum_n M_(k_n))
```

is an injective homomorphism, so `S` is operator-MF.  Since `S` is simple
and nontrivial, `Rad_MF(S) = 1`.

**Where the three-lane design matters.** In `A_5 wr Z` and in the
lampshuffler `FAlt(Z) x| Z`, the compressor `t` has infinite order modulo
the derived subgroup, so it need not lie in `A(G)`.  In the two-lane group
`P` of the parent claim, `u^2 = [u, sigma]` is a product of two
involutions, and whether such a product lies in `A(G)` is not settled by
Definition 3.2 alone.

Three lanes with velocities summing to zero make the compressor a
product `b rho` of two elements of order 3.  An element of order 3 that
acts freely is literally a 3-cycle of a multisection.

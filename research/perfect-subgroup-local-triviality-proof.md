Notation as in the claim.

## 0. Point germs of the bases (elementary)

- **V and Higman--Thompson groups.**
  - Let `q` be irrational. A prefix replacement fixing `q` must be the identity near `q`
    (`bhm-corollary-hosts-over-v-are-cover-centralizer-groups`, proof of (a)). So
    `(V)_q = 1`.
  - Let `q = u w^∞` be rational, with `w` primitive. The germs fixing `q` are the period
    shifts, so `(V)_q ≅ Z`.
- **nV.** An `nV`-germ at `x = (x_1, …, x_n)` is a product of prefix replacements, one in
  each coordinate. So `(nV)_x = ∏ (V)_{x_i} ≅ Z^k`, where `k` is the number of rational
  coordinates.
- **Boundary Thompson groups of regular path spaces.** The germ group is `Z` at eventually
  periodic points and `1` elsewhere
  (`germ-rate-homomorphism-tests-germ-extension-finiteness` §1).

All of these are torsion-free abelian.

## 1. Item 1

Let `j_1, …, j_r` generate `J`, and let `p ∈ Fix(J) ∖ ⋃_i sing(j_i)`.

- **The generators have base germs at p.** Each `j_i` agrees near `p` with some `b_i ∈ B`.
  Since `j_i p = p`, also `b_i p = p`. So the germ `[j_i]_p` lies in `(B)_p`.
- **The germ map.** Taking germs at `p` is a homomorphism `γ_p : Stab_G(p) → (G)_p`, and
  `J ≤ Stab_G(p)`. So `γ_p(J)` is generated by elements of `(B)_p`, hence is a subgroup of
  it, and is torsion-free abelian.
- **It vanishes.** `γ_p` factors through `J^{ab}`. That group is finitely generated of
  rank `0`, since `H_1(J; Q) = 0`, so it is finite. Its image in a torsion-free group is
  trivial.
- **Conclusion.** Each `j_i` is the identity on a neighbourhood `U_i` of `p`. So all of `J`
  is the identity on `U = ⋂ U_i`. Hence `p ∈ int Fix(J)`.

So `N_J ⊆ ⋃_i sing(j_i)`, which is finite.

**The centralizer.** For `c ∈ C_G(J)`, `c` maps `Fix(J)` onto itself, and maps its interior
onto its interior, since `c` is a homeomorphism. So `c N_J = N_J`. The kernel of the
resulting action on the finite set `N_J` has finite index. ∎

## 2. Items 2 and 3

- **Item 2.** If `G ≤ B`, every `sing(g)` is empty. So `N_J = ∅` and `Fix(J)` is open;
  being closed as well, it is clopen.
- **Item 3.** `ψ` permutes the finite set `N_J`, so every point of `N_J` has a finite
  `ψ`-orbit. A point `p ∈ Fix(J)` with infinite `ψ`-orbit is therefore not in `N_J`, so it
  lies in `int Fix(J)`. ∎

## 3. Mapping class group facts (recalled)

Sources: Farb--Margalit, *A primer on mapping class groups*, Ch. 3--5; Powell 1978.

- **(M1) Perfectness.** For `h ≥ 3` and `b ≥ 0`, `Mod(S_h^b)` is perfect and generated by
  finitely many Dehn twists about nonseparating curves. For `h ≥ 1` the finite
  nonseparating-twist generation still holds.
- **(M2) Stabilizers of curves.** For a nonseparating curve `d` in `S_g`, the inclusion
  `S_g ∖ N(d) ≅ S_{g-1}^2 ↪ S_g` induces a surjection `Mod(S_{g-1}^2) → Stab^+(d)`. So
  `Stab^+(d)` is generated by finitely many twists `T_e`, where each `e ⊂ S_g ∖ N(d)` is
  nonseparating in `S_g ∖ N(d)`. In particular `T_d`, the image of a boundary twist, is a
  product of such twists.
- **(M3) Complement of a one-holed torus.** If `R ⊂ S_g` is a one-holed torus, then
  `S_g ∖ R ≅ S_{g-1}^1`. `Mod(S_g ∖ R)` acts by homeomorphisms supported in `S_g ∖ R`,
  commutes with `Mod(R)`, and fixes every curve in `R` together with its orientation.

## 4. Item 4

Let `g ≥ 4`. Fix one of the generating twists `T_e` of (M2).

**Step 1: a one-holed torus around d avoiding e.**
- `S_g ∖ (N(d) ∪ e)` is connected, and it contains both sides of `d`.
- So there is a simple closed curve `f` crossing `d` exactly once and disjoint from `e`:
  close up an arc that runs from one side of `d` to the other, avoiding `e`.
- Put `R = N(d ∪ f)`, a one-holed torus. After isotopy `e ⊂ S_g ∖ R`.

**Step 2: the ingredients of item 3.**
- Put `J = Mod(S_g ∖ R) ≅ Mod(S_{g-1}^1)`. It is finitely generated and perfect, since
  `g − 1 ≥ 3` (M1), and it contains `T_e`.
- Put `ψ = T_f ∈ Mod(R)`, which commutes with `J` (M3).
- The curves `T_f^n(d)`, `n ≥ 0`, are pairwise distinct, because
  `i(T_f^n(d), d) = n · i(f, d)^2 = n`.
- `J` fixes `d` and `f`, hence each `T_f^n(d)`, with its orientation. So
  `J ≤ Stab^+(T_f^n d)`, which fixes `p_{T_f^n d} = T_f^n(p_d)` by hypothesis.
- By injectivity these points are pairwise distinct.

**Step 3: conclusion.**
- Item 3 applies to `J`, `ψ` and `p = p_d`, so `J` is the identity near `p_d`. In
  particular `T_e` is.
- Doing this for each of the finitely many generating twists `T_e` of `Stab^+(d)`, and
  intersecting the neighbourhoods, shows that `Stab^+(d)` is the identity near `p_d`. That
  includes `T_d`. ∎

**The finite-index variant.** Replace `J` by `J_L = L ∩ Mod(S_g ∖ R)` and `ψ` by `T_f^N ∈ L`.
The same argument shows that `J_L` is the identity near `p_d` whenever
`H_1(J_L; Q) = 0`. The last generation step is not available for `L`, since the groups
`J_L` need not generate a subgroup containing a power of `T_d`. So nothing more is claimed.

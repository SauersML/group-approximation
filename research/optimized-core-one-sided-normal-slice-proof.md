Since `q` commutes with `T`,

```text
(qR)T(qR)^(-1)=qT^4q^(-1)=T^4,
```

so `(qR,T)` is an exact BS core.  Set

```text
A=XR,        B=XT^2R,        d=XqX,
p=R^(-1)qR, alpha=Ad(A),     beta=Ad(B).              (ONP1)
```

Exactness of the baseline gives `A^2=B^3=1`.  Direct conjugation, using
only `[q,T]=1`, gives the shared terminal factor

```text
alpha(d)=p,
beta^2(d)=B^(-1)dB=R^(-1)T^(-2)qT^2R=p.             (ONP2)
```

Moreover `XR_q=dA` and `XT^2R_q=dB`.  Expanding the two word powers and
using `(ONP2)` therefore yields

```text
u=d alpha(d)=dp,
v=d beta(d) beta^2(d)=d beta(d)p.                    (ONP3)
```

Subtracting the two equalities in `(ONP3)` and using unitary invariance of
normalized Hilbert--Schmidt norm proves the exact identity

```text
||v-u||_2=||d(beta(d)-1)p||_2
          =||beta(d)-1||_2=||d-1||_2=||q-1||_2.      (ONP4)
```

The triangle inequality gives `(ONS4)`.  For `(ONS5)`, choose the baseline
core `(R,T)` as competitor in `(GOI4)`.  Its hybrid tuple `(X,R,T)` is an
exact endpoint, so every induced section edge vanishes, while its core
movement cost is exactly `||qR-R||_2^2=||q-1||_2^2`.  Also the unchanged
first cubic `(XT)^3` is exact.  Hence

```text
G_N(X,b_q)<=||q-1||_2^2
            <=2(||u-1||_2^2+||v-1||_2^2)
            =2 E_end(X,b_q),
```

as claimed.

For the converse parametrization used in `(ONS6)`, let `R_i T R_i^(-1)=T^4`
for `i=0,1` and put `q=R_1R_0^(-1)`.  Then

```text
qT^4q^(-1)=R_1(R_0^(-1)T^4R_0)R_1^(-1)
           =R_1TR_1^(-1)=T^4.
```

Since `T^N=1` and `N` is odd, exponentiation by four is invertible on the
cyclic algebra generated by `T`; hence `[q,T]=1`.  Applying `(ONS5)` with
the baseline implementer `R_0` proves `(ONS6)`.

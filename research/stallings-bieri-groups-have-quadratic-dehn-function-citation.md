Citation import, not a reproof. William Carter and Max Forester, *The Dehn
functions of Stallings–Bieri groups*, arXiv:1509.07539 (v1 24 September 2015,
v2 1 September 2016), published in Mathematische Annalen
(doi:10.1007/s00208-016-1470-6). Read from the v2 PDF, pages 1--2, on
2026-09-13.

- Section 1: "For n ⩾ 1, the Stallings–Bieri group SB_n is defined to be the
  Bestvina–Brady group associated with the right-angled Artin group
  F_2 × ⋯ × F_2, where there are n factors F_2." The Bestvina--Brady group
  `BB_Γ` is the kernel of `φ : A_Γ → Z` sending each standard generator to 1.
- Section 1: "Bieri [5] has shown that SB_n is of type F_{n−1} but not of type
  F_n." Also: "Note that SB_1 and SB_2 are not finitely presented."
- Corollary 4.3: "Suppose Γ = Γ_1 ∗ Γ_2 ∗ Γ_3, so that A_Γ is the product
  A_{Γ_1} × A_{Γ_2} × A_{Γ_3}. Then the Bestvina-Brady group BB_Γ has
  quadratic Dehn function." It is followed by: "In particular, SB_n has
  quadratic Dehn function for every n ⩾ 3."
- Corollary 1.1: "For each n ⩾ 3 there exist groups with quadratic Dehn
  function that are of type F_{n−1} but not of type F_n."

The finiteness statement is Bieri's theorem as Carter--Forester cite it
(their reference [5]). It is consistent with the Bestvina--Brady theorem, since
the join of `n` copies of `S^0` is an `(n−1)`-sphere, which is
`(n−2)`-connected but not `(n−1)`-connected. The proofs were not re-derived
here.

Full details are in the artifact, Sections 2–3. Put `R = Z/m`, `M = C(X, R)` and `t_i g = g ∘ σ^{e_i}`.
The Koszul complex is `M -> M^2 -> M`, with `δ^0 g = ((t_1-1)g, (t_2-1)g)` and
`δ^1(a,b) = (t_1-1)b - (t_2-1)a`.

**Preliminaries.**
- **(P1) Grid.** `ω(u ⊙^i v) = ω(u) ⊙^i ω(v)` forces images in a row to have equal heights, and
  images in a column equal widths. So `ω(x)` is a grid of rectangles.
- **(P2) Continuity.** The set
  `Gr = {(y,k,x) : y = σ^k ω(x), 0 <= k < shape(ω(x_0))}` is compact.
  - Its projection to `y` is closed and shift-invariant and contains `ω(X)`, so it is `X`.
  - By recognizability the projection is injective, hence a homeomorphism.
  - So the centered representation `(k(y), x(y))` depends continuously on `y`.
- **(P3) Iterates.** `ω^n` satisfies the same hypotheses.
  - Two centered `ω^2`-representations `(k,x)` and `(k',x')` of `y` re-center to centered
    `ω`-representations `(k - s_j, σ^j ω(x))` and `(k' - s'_{j'}, σ^{j'} ω(x'))`.
  - Recognizability identifies them. Then `(j, x)` and `(j', x')` are centered representations of
    one point, so `x = x'` and `k = k'`.
  - Induction on `n`.
- **Notation.** `(k_n, x_n)` is the centered `ω^n`-representation, and
  `s_n = min_a min shape(ω^n(a)) -> ∞`. The vertex `p` belongs to the supertile containing the
  unit square at `p`, so a supertile `S` owns the vertex rectangle `V(S)`.

**Degree 2.**
- `H^2` is the coinvariants `M / Σ (t_i - 1) M`.
- If `g` reads `y|_{[-ρ,ρ]^2}` and `s_n > ρ + 1`, then `g = Σ g_{τ,q} 1_{[τ,q]}`, where
  `τ = x_n|_{[-1,1]^2}` and `q = k_n`.
- `1_{[τ,q]} = 1_{[τ,0]} ∘ σ^{-q}`, so `[1_{[τ,q]}] = [1_{[τ,0]}]`. Here `τ` ranges over the
  `3 × 3` patterns of `X`.
- Any finite set of classes has a common radius. So `H^2` is generated by at most `N_{3,3}`
  elements.

**Degree 1.** Let `(a,b)` be a cocycle reading radius `ρ`, and take `s_n > ρ + 2`.
1. **Potential.** `f(σ^p y)`, for `p ∈ V(S)`, is the sum of `(a,b)` along the canonical path in
   `V(S)` from the corner of `S`: horizontal, then vertical.
   - It reads only the collar of `S`, so `f ∈ M` by (P2).
2. **The residual vanishes inside.** Put `ψ = (a,b) - δ^0 f`.
   - An edge inside `V(S)` closes, with the two canonical paths, a loop around unit squares with
     all corners in `V(S)`.
   - The cocycle condition gives `ψ = 0` there.
3. **Crossing edges.** Take `p` in the right column of `V(S)`, with `p + e_1 ∈ V(S')` and
   `p + e_2 ∈ V(S)`.
   - (P1) gives `p + e_1 + e_2 ∈ V(S')`.
   - The square at `p` has `ψ = 0` on its vertical edges, so
     `ψ(p -> p+e_1) = ψ(p+e_2 -> p+e_2+e_1)`.
   - So `ψ` is constant along each boundary between neighbours.
   - That constant reads only the collars of `S` and `S'`, a `4 × 3` (or `3 × 4`) block of `x_n`.
4. **Counting.** `ψ ∈ W_n`, the image of `R^{N_{4,3} + N_{3,4}}` that assigns block-dependent
   constants to crossing edges.
   - Finitely many classes lie in one `W_n`, so every finitely generated subgroup of `H^1` has
     order at most `m^{N_{4,3}+N_{3,4}}`.
   - Hence `H^1` is finite with that bound.

**Integral degree 2.** The same spanning argument over `Z` gives at most `N_{3,3}` generators. ∎

**Model tests.**
- **A trivial model must fail the conclusion.** The Morse substitution times itself acts on
  `X_TM × X_TM`. Integral `H^1` contains `Z[1/2]`, which is not finitely generated, while
  `Z[1/2] ⊗ Z/2 = 0` is consistent with the mod-2 bound. So the integral restriction is necessary.
- **A real object must satisfy it.** For Penrose-type substitutions the bound is consistent with
  `Z^5` and `Z^8` (`penrose-derived-full-group-homology-is-finitely-generated`). Penrose is not
  literally of this rectangular form, and nothing here depends on it.

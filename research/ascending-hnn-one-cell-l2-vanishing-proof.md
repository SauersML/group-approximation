Assume `G ≅ H *_σ = ⟨H, t | t h t⁻¹ = σ(h)⟩`, with `H` generated by `h₁, …, h_d` and `σ` injective.
Steps 1–5 use only this, so they prove `b₁^(2)(H *_σ) = 0` for every ascending HNN extension of a
finitely generated group. Step 6 is where the one-cell hypothesis enters.

## 1. A graph and a cellular self-map

- Let `X` be a wedge of `d` circles, with one 0-cell `v` and 1-cells `x₁, …, x_d`.
- Choose words `w_j` in the `x`'s with `w_j(h₁, …, h_d) = σ(h_j)` in `H`.
- Let `f : X → X` fix `v` and run the `j`-th circle along `w_j`.

`f` maps `X⁰` into `X⁰` and `X¹ = X` into `X¹`, so it is cellular.

## 2. The mapping torus maps onto `G`

`T_f` has:
- one 0-cell `v`;
- 1-cells `x_j` and `τ`, where `τ` is the image of `v × [0, 1]`, a loop because `f(v) = v`;
- 2-cells `x_j × (0, 1)`, with attaching words `x_j τ w_j⁻¹ τ⁻¹`.

So `π₁(T_f) = ⟨x₁, …, x_d, τ | τ⁻¹ x_j τ = w_j⟩`.

The canonical map `p : T_f → S¹`, `(x, s) ↦ exp(2πis)`, gives `p_*(x_j) = 0` and `p_*(τ) = 1`.

Define `φ : π₁(T_f) → G` by `x_j ↦ h_j` and `τ ↦ t⁻¹`.
- **Well defined.** `φ(τ⁻¹ x_j τ) = t h_j t⁻¹ = σ(h_j) = φ(w_j)`.
- **Onto.** `G` is generated by `H` and `t`.

Let `χ : G → Z` send `t ↦ 1` and `H ↦ 0`. It is well defined because every relator has
`t`-exponent sum zero, and it is onto. Put `ψ = −χ`. Then `ψ ∘ φ = p_*` on the generators, so
`p_* = ψ ∘ φ` is a factorization into epimorphisms.

## 3. The finiteness hypotheses

Here `i : π₁(X) → π₁(T_f)` is `x_j ↦ x_j`. The space `Y = G ×_{φ∘i} X̃` is a free `G`-CW complex
with one equivariant 0-cell, `d` equivariant 1-cells, and nothing higher. So its cellular chain
complex is `ZG^d → ZG`.

By item 1 of `lueck-mapping-tori-and-homology-invariance`, `b_p^(2)(Y; N(G))` is the dimension of
`H_p(N(G) ⊗_{ZG} C^c_*(Y))`. That module is a subquotient of `N(G)^{c_p}`, with `c₀ = 1` and `c₁ = d`.
`lueck-dimension-additivity-cofinality-and-induction` supplies additivity, and extends the trace
dimension, so `dim N(G)ⁿ = n`. Hence `b₀^(2)(Y) ≤ 1` and `b₁^(2)(Y) ≤ d`, both finite.

## 4. Vanishing on the covering

Apply item 3 of `lueck-mapping-tori-and-homology-invariance` with `p = 1`. It gives
`b₁^(2)(T̄_f; N(G)) = 0`, where `T̄_f` is the covering associated to `φ`. `T̄_f` is a free `G`-CW
complex, connected because `φ` is onto.

## 5. Comparison with `EG`

`EG` is a contractible free `G`-CW complex, so a `G`-map `u : T̄_f → EG` exists. Build it over
`T̄_f` one skeleton at a time; each extension over a free cell `G × Dⁿ` exists because `EG` is
contractible.

For every subgroup `H' ≠ 1`, both fixed sets are empty, so `u^{H'}` is a homology isomorphism. For
`H' = 1`:
- `H₀(T̄_f; C) = C → H₀(EG; C) = C` is bijective;
- `H₁(EG; C) = 0`, so degree 1 is onto.

Item 2 of `lueck-mapping-tori-and-homology-invariance`, with `n = 1`, gives
`b₁^(2)(T̄_f) ≥ b₁^(2)(EG; N(G)) = b₁^(2)(G)`, the last by item 4. So `b₁^(2)(G) = 0`.

## 6. Asphericity

`contractible-complex-minus-cell-has-cyclic-homology` gives `χ(K) = 0` and `G` infinite. Then
`χ(K) + b₁^(2)(G) = 0`, and `finite-2-complex-with-zero-second-l2-betti-is-aspherical` makes `K`
aspherical.

title: Linear finite-action criterion for sofic-radical membership
---

Let `P = F / normalClosure(R)`, where `F` is finitely generated and `R` is
finite, and let `w` be an element of `F`.  For a nonempty finite `F`-action
`rho`, write `d_rho(g)` for the fraction of points moved by `g`.  The image
of `w` belongs to `Rad_sof(P)` if and only if there is a finite constant
`C >= 0` such that every such action satisfies

\[
d_\rho(w)\leq C\sum_{r\in R}d_\rho(r).
\]

Equivalently, it is enough to require the inequality only for transitive
finite actions.

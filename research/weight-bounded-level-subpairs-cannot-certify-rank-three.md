**ESTABLISHED (proposed; unreviewed).**  Derivation: [[weight-bounded-level-subpairs-cannot-certify-rank-three-proof]].
It is a class-killing obstruction on the nonsofic side of [[rank-three-finite-twisted-kazhdan-cone-is-sofic]].
It closes the E_w-type class that [[level-subpair-line-sections-are-bounded-or-cofinite]] left as the
survivor of the level class.

## Setting

As in [[subring-level-subpairs-cannot-certify-rank-three-cone]]: `R_+ = F_q[x_1..x_d]`, `R` the Laurent ring,
`Gamma = SL_3(R_+)`, `G = EL_3(R) x| SL_d(Z)`, `psi = ev_0`, and `U_k` the level of monomial elementary matrices
of degree `≥ k`.  For `B ≤ G`: `C = B ∩ Gamma`, `E_B = B ∩ EL_3(R)`, `H_B` the projection of `B` to `SL_d(Z)`,
`O = R_+^d` and `K0 = cone(H_B · O)`.  A Kun-Thom certificate is as there: `C_F(psi(C)) ≠ 1`, `B` and `C`
Kazhdan, `C` infranormal and not normal.

For `w ∈ Q^d \ {0}` let `v_w(Σ c_m x^m) = min { <w, m> : c_m ≠ 0 }`, the monomial valuation.  It is discrete.
Let `K_w` be the completion of `Frac R`, `O_w` its valuation ring, and `X_w` the Bruhat-Tits building of
`SL_3(K_w)`, a complete Euclidean building (not locally finite: the residue field is infinite).  Put

```text
W(E_B) = { w ∈ Q^d \ {0} : E_B fixes a point of X_w } .
```

For example `w ∈ W(E_B)` when `E_B ≤ g SL_3(O_w) g^-1` for some `g ∈ GL_3(K_w)`, and in particular when
`E_B ≤ E_w = { g : v_w(g - 1) > 0 }`.

## Theorem

**(Y1) Weight duality, for every `B ⊇ U_k`.**  `W(E_B)` is invariant under `w ↦ σ^T w` for `σ ∈ H_B`, and

```text
W(E_B) ⊆ K0^∨ = { w : <w, v> ≥ 0 for all v ∈ K0 } .
```

In particular `W(E_B) ⊆ Q^d_(≥0)`, and every `w ∈ W(E_B)` vanishes on the lineality space of `K0`.

**(Y2) Survivors are unbounded at every weight that meets the invariant core.**  Let `C` be infranormal, let
`B` be Kazhdan and let `H_B` be infinite.  By (W2) of [[nonneg-generated-kazhdan-groups-have-nonsalient-cones]],
`K0` contains an `H_B`-invariant coordinate subspace `R^M`, `M ≠ ∅`.  Then every `w ∈ W(E_B)` has `w_l = 0` for
all `l ∈ M`.  So `E_B` fixes no point of `X_w` whenever `w ≥ 0` and `w_l > 0` for some `l ∈ M`.

**(Y3) The E_w-type class is dead.**  If `B ⊇ U_k` and `E_B` fixes a point of `X_w` for some `w ∈ Q^d_(>0)`,
then `B` is not a Kun-Thom certificate for `T_3`.  This covers `E_B ≤ E_w`, `E_B` in any conjugate of any
parahoric of `SL_3(K_w)`, and `E_B` with a bounded orbit.  No compressor-invariant valuation is needed: all of
`B` permutes the buildings, so the brief's step ("compressors preserve `v_w`") holds automatically, and the
contradiction comes out of (W2).

## Mechanism

1. *Negative weights.*  If `w_l < 0`, then `a = x_l^n` with `n ≥ k` has `v_w(a) < 0`, and
   `g = e_12(a) e_21(a) ∈ U_k` has `v_w(tr g) = 2 v_w(a) < 0`.  An element fixing a point of `X_w` has a power
   in a vertex stabiliser, so its eigenvalues are integral over `O_w` and its trace lies in `O_w`.  So `E_B`
   fixes no point, and `W(E_B) ⊆ Q^d_(≥0)`.
2. *`B` permutes the buildings.*  The monomial automorphism `σ̂ : x^m ↦ x^(σm)` satisfies
   `v_w ∘ σ̂ = v_(σ^T w)`, so it extends to an isometry `K_(σ^T w) → K_w` and an equivariant isometry
   `X_(σ^T w) → X_w`.  For `t = u σ ∈ B`, `E_B = u σ̂(E_B) u^-1`.  A fixed point of `E_B` in `X_w` moves by
   `u^-1` and then by `σ̂^-1` to a fixed point of `E_B` in `X_(σ^T w)`.
3. *Duality.*  So `σ^T w ≥ 0` for all `σ ∈ H_B`, which is `<w, σ e_i> ≥ 0`, i.e. `w ∈ K0^∨`.
4. *(Y2), (Y3).*  `± e_l ∈ K0` for `l ∈ M` forces `w_l = 0`.  For (Y3), if `C` is not infranormal or `B` is not
   Kazhdan there is nothing to prove.  Otherwise `H_B` is Kazhdan, hence character-free, and nonnegatively
   generated by (X1).  If it is finite, (X2) makes `C` normal.  If it is infinite, (Y2) contradicts `w > 0`.

## Calibration

- `B = G`: `K0 = R^d`, `K0^∨ = 0`, and indeed `EL_3(R)` fixes no point of any `X_w`: it contains
  `e_12(x^m) e_21(x^m)` with `v_w(x^m) < 0`.
- `B = Gamma x| S_d`: `K0 = O`, `K0^∨ = Q^d_(≥0)`, and `Gamma` fixes the base vertex of every `X_w` with
  `w ≥ 0`.  The inclusion (Y1) is sharp here.  `H_B` is finite, so (Y3) is consistent: `C = Gamma` is normal.
- `B = E_w x| Stab(w)`: `E_B ⊇ E_w` fixes the base vertex of `X_w`, `Stab(w)` preserves a positive functional,
  and `K0 ⊆ { <w, ·> > 0 } ∪ 0` is salient.  (W2) then says `Stab(w)` is finite or not nonnegatively
  generated and Kazhdan, as (Y3) requires.
- The one-variable case of [[level-subpair-line-sections-are-bounded-or-cofinite]] is the restriction of `v_w`
  to a monomial line.  (Y1) does not reprove (L1), which uses local compactness; (L1) does not give (Y1),
  which uses the whole weight space.

## What is left

A level-containing certificate `B ⊇ U_k` must now have: `H_B` infinite, Kazhdan, nonnegatively generated,
with invariant core `R^M ⊆ K0`; and `E_B` fixing **no** point of `X_w` for every `w ∈ Q^d_(≥0)` whose support
meets `M`, while `C = E_B ∩ Gamma` fixes the base vertex of all of them, and every monomial line section of
`E_B` is bounded ((L2)).  The E_w-type groups are excluded, so the Laurent part of `E_B` must be unbounded in
every positive-weight building while bounded on every monomial line.  The next step is to show that this is
impossible: an `E_B ⊇ U_k` with no fixed point in `X_(1,..,1)` should contain an element whose `v_(1,..,1)`
unboundedness is carried by a single monomial line after conjugating by `Gamma`, which would reach (L2).
Otherwise, pass to the positive side.

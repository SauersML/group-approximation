1. **Quotient indicators extend.**
   - Fix `K` normal in `Gamma` and write `q : Gamma * <t> -> (Gamma/K) * <t>`
     for the quotient map fixing `t`.
   - `q(w) = w_K` has the same `t`-degree, and `q` induces a homomorphism
     `q_w : Gamma_w -> (Gamma/K)_(w_K)`.
   - Let `delta` be the regular character of `(Gamma/K)_(w_K)`, with
     `delta(x) = 1` iff `x = 1`. It is a character, being the vector state of
     `delta_e` in the left regular representation, which is conjugation
     invariant.
   - So `psi_K = delta o q_w` is a character of `Gamma_w`.
   - For `g in Gamma`, `psi_K(g) = 1` iff the image of `gK` in
     `(Gamma/K)_(w_K)` is trivial. By the hypothesis that
     `Gamma/K -> (Gamma/K)_(w_K)` is injective, this happens iff `g in K`.
   - So `psi_K|_Gamma = 1_K`.
2. **Convex combinations.** If `chi = sum_i c_i 1_(K_i)`, with `c_i >= 0` and
   `sum_i c_i = 1`, then `sum_i c_i psi_(K_i)` is a character of `Gamma_w`
   restricting to `chi`. Characters are closed under convex combinations.
3. **Limits.**
   - The characters of `Gamma_w` form a compact set for pointwise convergence:
     they lie in the product of closed unit discs, and positive definiteness,
     conjugation invariance and `psi(1) = 1` are pointwise closed conditions.
   - Suppose `chi = lim_alpha chi_alpha` pointwise, with each `chi_alpha` in
     the convex hull and extended by `psi_alpha` as in step 2.
   - A cluster point `psi` of `(psi_alpha)` is a character of `Gamma_w`, and
     `psi|_Gamma = lim chi_alpha = chi`. This proves item 1.
4. **Item 2.**
   - Let `(pi_psi, H_psi, xi)` be the GNS triple of `psi`, and
     `L_psi = pi_psi(Gamma_w)''` with trace `<. xi, xi>`. This trace is
     tracial because `psi` is a class function.
   - The von Neumann subalgebra generated by `pi_psi(Gamma)` carries the trace
     `x -> <x xi, xi>`, whose values on `pi_psi(g)` are `psi(g) = chi(g)`.
   - The map `pi_chi(g) -> pi_psi(g)` preserves the trace on the group
     `*`-algebra. So it extends to a trace-preserving `*`-isomorphism from
     `L_chi(Gamma)` onto that subalgebra, by uniqueness of the GNS completion
     of a trace.
   - `T = pi_psi(t)` is a unitary with `w(pi_psi(coefficients), T) = pi_psi(w) = 1`.
   - Conversely, a trace-preserving extension `N` of `L_chi(Gamma)` with a root
     `T` gives `psi(x) = sigma(phi(x))`, where `phi : Gamma_w -> U(N)` sends
     `g -> pi_chi(g)` and `t -> T`. This is a character extending `chi`.
5. **Converse at `K = 1`.** This is proved in the claim.
6. **Consequence.**
   - Forward: apply items 1–3 to every countable `Gamma`, using the conjecture
     for each quotient `Gamma/K` at `w_K`.
   - Reverse: the converse at `K = 1` gives injectivity for countable
     coefficient groups. `kl-failure-localizes-to-the-coefficient-subgroup`
     passes this to all groups, since the coefficient subgroup is finitely
     generated.
   - The consequence therefore also uses that node. It is not listed in
     `requires` because the claim's main statement does not need it.

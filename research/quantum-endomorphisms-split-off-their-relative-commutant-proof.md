This is a self-contained proof. The inputs are standard facts about UHF algebras: a unique trace, the
tensor-splitting over a unital full matrix subalgebra, and mixing of Bernoulli shifts.

**Step 0 (matrix slicing).** Let `B` be a unital full matrix subalgebra `M_k` of a unital C*-algebra `A`, with
matrix units `f_ij`. For `x` in `A` put `x_ij = sum_k f_ki x f_jk`.
- Then `x_ij` commutes with `B`, since `f_ab x_ij = f_ai x f_jb = x_ij f_ab`.
- `x = sum_ij f_ij x_ij`, and `(x^*)_ji = (x_ij)^*`.
- Multiplication `B (x) (B' n A) -> A` is a *-isomorphism.
- The span of the `x_ij`, as `x` ranges over a subspace `S`, is the smallest subspace `V` of `B' n A` with
  `S <= B (x) V`. It is the image of the slice maps, so it does not depend on the matrix units.

**Step 1 (splitting over a finite region).** Let `L` be finite and `B = Phi(A_L)`. This is a unital copy of
`M_(d^|L|)`, because `Phi` is injective.
- `B (x) D <= Phi(A_(G\L))' n A` holds because `B` commutes with `Phi(A_(G\L))`.
- Conversely, let `x` commute with `Phi(A_(G\L))`. The matrix units of `B` also commute with it, so each `x_ij`
  commutes with `Phi(A_(G\L))` and with `B = Phi(A_L)`.
- These generate a dense subalgebra of `Phi(A)`, and `Phi(A)` is closed, so `x_ij` lies in `D` and
  `x = sum f_ij x_ij` lies in `B (x) D`.

**Step 2 (local defect).** `Phi(A_h) <= A_(hN)` commutes with `A_e` unless `e` lies in `hN`, that is, unless `h`
lies in `N^-1`.
- By Step 1 with `L = N^-1`, `A_e <= Phi(A_(N^-1)) (x) D`.
- The matrix units of `Phi(A_(N^-1))` lie in `A_(N^-1 N)`, and `A_e <= A_(N^-1 N)` because `e` is in `N`. So every
  slice coefficient lies in `D n A_(N^-1 N)`, which is finite dimensional.
- The coefficients form a *-closed set (Step 0), so the unital algebra `F` they generate is a finite-dimensional
  C*-algebra.

**Step 3 (criterion).**
- If `F = C`, then `A_e <= Phi(A_(N^-1))`. By equivariance `A_g = alpha_g(A_e) <= Phi(A)` for all `g`. The union of
  the `A_F` is dense and `Phi(A)` is closed, so `Phi` is onto.
- If `Phi` is onto, `D = A' n A = C`, because `A` is simple.
- `F <= D`, so `D = C` gives `F = C`.

**Step 4 (global splitting).** By Step 2 and equivariance (`D` is `alpha`-invariant, because `Phi` is equivariant),
every `A_g` lies in the C*-algebra generated by `Phi(A)` and `D`, which is therefore `A`.
- On `Phi(A_L) (.) D` the multiplication map is injective by Step 0. `Phi(A)` is the inductive limit of these
  matrix algebras, so multiplication is injective on `Phi(A) (.) D`.
- `Phi(A)` is UHF, hence nuclear, so there is only one C*-norm, and `A = Phi(A) (x) D = A (x) D`.
- Since `A` is simple, the ideals of `A (x) D` correspond to those of `D`, so `D` is simple.
- For any trace `t` on `D`, `tau (x) t` is a trace on `A`. Uniqueness of the trace of `A` forces `t` to be unique.

**Step 5 (von Neumann level).**
- `tau o Phi` is a trace on `A`, so `tau o Phi = tau`. Hence `Phi` is isometric for the trace norm and extends to
  a normal endomorphism of `R = pi_tau(A)''`.
- The product `tau|Phi(A) (x) tau|D` is a trace on `A = Phi(A) (x) D`, so it equals `tau`. Hence the trace
  representation is the tensor product of the two trace representations, and `R = Phi(R) (x)bar Q` with
  `Phi(R) = Phi(A)''` and `Q = D''`. `Q` is a factor because the trace of `D` is unique and hence extremal.
- By the commutation theorem, `Phi(R)' n R = 1 (x) Q`.
- The index of `Phi(R) <= Phi(R) (x)bar Q` is `k^2 = dim Q` when `Q = M_k`, and `infinity` otherwise.
- `K_0(A) = Z[1/d]` is detected by the trace, and `tau o Phi = tau`, so `Phi_* = id`. `K_1(A) = 0`.

**Step 6 (mixing).** Let `G` be infinite.
- The shift is mixing on `R`: for local `x`, `y`, the supports of `alpha_g(x)` and `y` are disjoint once `g` is
  outside a finite set, so `tau(alpha_g(x) y) = tau(x) tau(y)`. This extends by density in trace norm.
- Suppose `Q = M_k` with `k >= 2`. `Q` is `alpha`-invariant, and its automorphism group `PU(k)` is compact.
- Take `g_j -> infinity` with `alpha_(g_j)|Q -> theta`, and a minimal projection `p` of `Q`. Mixing gives
  `tau(alpha_(g_j)(p) theta(p)) -> tau(p)^2 = 1/k^2`.
- Convergence gives `tau(theta(p) theta(p)) = tau(p) = 1/k`. This is a contradiction.
- So `Q = C` (then `R = Phi(R)`, `D = C` and `Phi` is onto) or `Q` is infinite dimensional (index infinity).
  For finite `G`, `A` is a matrix algebra and `Phi` is onto by dimension.

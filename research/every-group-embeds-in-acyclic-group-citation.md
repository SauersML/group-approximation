Source: F. Fournier-Facio, C. Löh, M. Moraschini, *Bounded cohomology and
binate groups*, arXiv:2111.04305, TeX source `binate.tex` fetched on MSI on
2026-09-13. Verbatim pins:

- l.316–318, Definition `defi:acyclic`: "A group $\Gamma$ is said to be
  \emph{acyclic} if $\HH_n(\Gamma; \Z) \cong 0$ for all~$n \geq 1$."
- Definition `defi:pseudo:mitotic:groups`: "A group $\Gamma$ is said to be
  \emph{pseudo-mitotic} if all finitely generated subgroups of~$\Gamma$ admit a
  pseudo-mitosis in~$\Gamma$."
- l.637–639, Theorem `thm:pseudo:mitotic:are:acyclic`, cited there as
  Varadarajan, Theorem 1.7: "All pseudo-mitotic groups are acyclic."
- l.682–695, Example `ex:tower` (Binate tower): "Let $H$ be a group. Set
  $H_0 := H$, and construct~$H_{i+1}$ inductively by performing an
  HNN-extension of~$H_i \times H_i$ so that the embedding~$H_i \to H_{i+1}$ is
  a pseudo-mitosis. More precisely, if $$H_{i+1} := \langle H_i \times H_i;
  g_{i+1} \mid g_{i+1}^{-1}(h, h) g_{i+1} = (1, h) : h \in H_i \rangle,$$ then
  $h \mapsto (h, 1)$ is a pseudo-mitotic embedding of~$H_i$ in~$H_{i+1}$. By
  construction, the direct limit of the $H_i$ is pseudo-mitotic."
- l.697: "This example shows that every group embeds into a pseudo-mitotic
  group."

**Embedding.** The direct limit `Y` of `H_0 -> H_1 -> ...` is pseudo-mitotic,
hence acyclic by the theorem, and it contains `H = H_0`.

**Countability (proved here).**
- If `H_i` is countable, so is `H_i x H_i`.
- The associated subgroups of the HNN extension are the diagonal and the
  second factor, both isomorphic to `H_i`, and the stable letter conjugates one
  onto the other. So `H_(i+1)` is generated by the countable set
  `H_i x H_i` together with `g_(i+1)`, and is countable.
- The base group embeds in any HNN extension (Britton's lemma), and
  `h -> (h, 1)` is injective, so each `H_i -> H_(i+1)` is injective.
- A direct limit of a sequence of countable groups along injective maps is
  countable and contains each term.

So a countable `H` embeds in a countable acyclic group.

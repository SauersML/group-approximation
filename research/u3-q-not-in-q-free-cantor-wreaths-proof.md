Direct proof. Not independently reviewed. Notation as in
`u3-q-not-in-q-free-cantor-wreaths`. Write `U = U_3(Q)` and `[a,b,c]` for the
matrix with entries `a` at `(1,2)`, `b` at `(2,3)`, `c` at `(1,3)`, so that
`[a,b,c][a',b',c'] = [a+a', b+b', c+c'+ab']`. Put `X = e_12(Q)`, `Y = e_23(Q)`,
`Z = e_13(Q) = Z(U) = [U,U]`. For `w = [a,b,c]` and `t ∈ Q`:

- `w e_23(t) w^-1 = e_23(t) e_13(at)`, and
- `w e_12(t) w^-1 = e_12(t) e_13(-bt)`.

Suppose `Φ : U -> E` is injective. Write `Φ(u) = (π(u), α_u)` with
`π : U -> Γ` and `α_u ∈ LC(C,H)`. Then `U` acts on `C` through `π`. We use the
product rule `(γ,f)(δ,g) = (γδ, (f∘δ)·g)` and the conjugation rule

    (γ,f)(1,β)(γ,f)^-1 = (1, q ↦ f(γ^-1 q) β(γ^-1 q) f(γ^-1 q)^-1).        (C)

## Step 1. The kernel of π

Let `K = ker π`, so `Φ(K) ⊆ LC(C,H)`.
- `X/(X ∩ K)` embeds in the Q-free group `Γ`, so `X ∩ K` contains some
  `e_12(a) ≠ 1`. Then `[e_12(a), e_23(t)] = e_13(at) ∈ K` for all `t`, so
  `Z ⊆ K`.
- `U/K` is a quotient of `U/Z ≅ Q^2`, hence divisible abelian. It embeds in the
  Q-free group `Γ`, so it is torsion.
- Let `W = K/Z ⊆ Q^2`. Since `Q^2/W` is torsion, there are integers
  `n_1, n_2 >= 1` with `(n_1,0), (0,n_2) ∈ W`. So `k_1 = e_12(n_1)` and
  `k_2 = e_23(n_2)` lie in `K`.
- A set of rational pairs whose denominators are bounded by `M` meets only
  finitely many cosets of `W`, since `W ⊇ n_1 Z × n_2 Z` has finite index in
  `(M!^-1 Z)^2`. So **infinitely many distinct cosets of `W` contain pairs with
  unbounded denominators in one coordinate.**
- `U/K` is divisible, so it has no proper subgroup of finite index. **Every
  finite `U`-orbit on `C` is therefore a fixed point of all of `U`.**

## Step 2. The central characters

For `p ∈ C` let `ψ_p : Q -> H`, `ψ_p(t) = α_{e_13(t)}(p)`. It is the evaluation
at `p` of the homomorphism `t ↦ Φ(e_13(t))` into `LC(C,H)`, so it is a
homomorphism.
- Its image is divisible abelian, hence torsion-free by (H1). So `ψ_p` is
  either `0` or injective.
- `p ↦ ψ_p(1) = α_z(p)`, with `z = e_13(1)`, is locally constant. So
  `O = {p : ψ_p ≠ 0}` is clopen.
- `O` is nonempty. Otherwise `Φ(z) = (1, 1)` is trivial, contradicting
  injectivity.
- `e_13(t)` is central. Rule (C) with `u ∈ U` gives
  `ψ_{π(u)p}(t) = α_u(p) ψ_p(t) α_u(p)^-1`. So `O` is `U`-invariant.

## Step 3. The key relation

Let `w = [a,b,c] ∈ U`, `p ∈ C`, and `p' = π(w)p`. Apply `Φ` to
`w k_2 w^-1 = k_2 e_13(a n_2)` and evaluate at `p'` using (C):

    α_{k_2}(p') · ψ_{p'}(a n_2) = h α_{k_2}(p) h^-1,   h = α_w(p).

By Step 2, `ψ_{p'}(a n_2) = h ψ_p(a n_2) h^-1`. So:

- (R) **If `α_{k_2}(p') = α_{k_2}(p)`, then `ψ_p(a n_2) ∈ [H,H]`.** Indeed
  `h ψ_p(a n_2) h^-1 = α_{k_2}(p)^-1 h α_{k_2}(p) h^-1` is a commutator, and
  `[H,H]` is normal.
- The same holds with `k_1` and `-b n_1` in place of `k_2` and `a n_2`.

Now let `p ∈ O`. Then `ψ_p` is injective, so `ψ_p^-1([H,H])` is a subgroup of `Q`
isomorphic to `ψ_p(Q) ∩ [H,H]`. It is finitely generated by (H2), hence cyclic,
so its elements have bounded denominators. By (R):

- (R') There is no infinite family of `w_i ∈ U`, whose `(1,2)`-entries (or
  `(2,3)`-entries) have unbounded denominators, satisfying
  `α_{k_2}(π(w_i)p) = α_{k_2}(p)` (respectively the same for `k_1`).

## Step 4. Minimal sets

`O` is a nonempty compact `U`-invariant set, so it contains a nonempty closed
invariant set `M` that is minimal (Zorn's lemma). Fix `p ∈ M`, and let `N` be a
clopen neighbourhood of `p` on which `α_{k_1}` and `α_{k_2}` are constant.

- **`M` finite.** Then `p` has a finite orbit, so every `w ∈ U` fixes `p` by
  Step 1. Take `w = e_12(1/j)` for `j = 1, 2, 3, ...`. Then `p' = p`, and (R)
  gives `ψ_p(n_2/j) ∈ [H,H]` for all `j`, contradicting (R').
- **`M` infinite.** A minimal infinite compact set has no isolated points. So
  the orbit of `p`, which is dense in `M`, contains infinitely many distinct
  points `π(w_i)p` of `N`.
  - Distinct points come from distinct cosets `w_i K`.
  - By Step 1 we may pass to a subsequence along which the `(1,2)`-entries, or
    the `(2,3)`-entries, of the `w_i` have unbounded denominators.
  - All `π(w_i)p` and `p` lie in `N`, so `α_{k_2}` (and `α_{k_1}`) takes equal
    values there. This contradicts (R').

Both cases are impossible, so `Φ` does not exist.

## Step 5. The main case

In `U_1 = U(Z,Z,Q)`, a divisible abelian subgroup has divisible image in
`U_1/Z(U_1) ≅ Z^2`, hence trivial image. So it lies in `Z(U_1) = e_13(Q)`,
which gives (H1). Commutators satisfy
`[[a,b,c],[a',b',c']] = e_13(ab' - a'b)` with integer `ab' - a'b`, so
`[U_1,U_1] = e_13(Z)`, which gives (H2). `V` is Q-free (survey
arXiv:2306.16356v3, Theorem 4.4), and `C = {0,1}^N` is compact, metrizable and
totally disconnected.

Let

```text
0 -> I -> A -> Q -> 0                                      (SI1)
```

be an extension of C*-algebras, with `I` stable.  If every bounded
2-quasitrace on `Q` is a trace, then every bounded 2-quasitrace on `A` is a
trace.

No exactness, nuclearity, separability, or splitting hypothesis is imposed
on `(SI1)`.

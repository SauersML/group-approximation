Cauchy--Schwarz turns the near-maximal cyclic overlap into near-maximal
Frobenius norm.  A Birkhoff decomposition then contains one permutation with
at least that overlap.  Normalized entrywise distance to a permutation is
exactly one minus this overlap, and the same trace inequality transfers the
inverse alignment to the return kernel.

**Theorem.** Let `G` be finitely generated with finite symmetric generating set `S`, and let `H <= G` be a
nonsofic subgroup generated by `S_H ⊆ S`. In the coupling on `Omega = [0,1]^E` of
`nonsofic-groups-have-cluster-soficity-threshold-in-pc-pu`, the cluster relation `R_p` of `Cay(G,S)` is
nonsofic for every `p > p_u(Cay(H,S_H))`. Hence

    p_sof(G, S) <= p_u(Cay(H, S_H)).

The same holds for hyperlinearity, with `H` non-hyperlinear.

**Proof** (part 2 artifact, Section 6).
- `H` acts freely and ergodically on `Omega`: edges are moved, and edge stabilizers are finite.
- Moves along open `S_H`-edges generate a subrelation `R^H_p ⊆ R_p`.
- For `p > p_u(Cay(H,S_H))`, the unique infinite cluster in the coset `H` (`fpbs-cluster-count-trichotomy`)
  identifies `R^H_p` on that cluster with the orbit relation of `H ↷ Omega` restricted to a set of positive
  measure.
- That orbit relation is nonsofic because `H` is. Restriction and amplification transfer this to `R^H_p`,
  and a relation containing a nonsofic subrelation is nonsofic.

**Scope.** The bound is useful only when `p_u(Cay(H,S_H)) < p_u(Cay(G,S))`, for instance when `G` has
infinitely many ends. The artifact records that example as a remark, not a claim: its two inputs, `p_u = 1`
for infinitely-ended graphs and Babson--Benjamini's `p_u < 1` for one-ended finitely presented groups, are
not imported here.

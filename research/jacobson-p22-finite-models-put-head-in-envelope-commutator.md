## Setting

Notation of `jacobson-double-parabolic-two-step-models-kill-head`:
- `R` is a ring with `ts = 1` and `q = 1 - st`. The main case is
  `R = J = F_2<S,T | TS=1>`.
- `P = P_{2,2}(R)`, and `n(Y) = [[1,Y],[0,1]]`.
- `L_0 = {x_12(s), x_12(t), x_21(1), x_34(1), x_43(s), x_43(t)}`.
- `E = {0, ±1, ±s, ±t, ±st, ±q}` and `N_0 = n(M_2(E))`.
- `B_* = {1} ∪ L_0 ∪ L_0^(-1) ∪ N_0` and `B_0 = B_*^3`.
- The head is `h = x_13(q) = n(E_11 (x) q)`, which lies in `N_0`.

Let `F` be a group and `sigma : B_0 -> F` a **partial homomorphism**, meaning
`sigma(xy) = sigma(x) sigma(y)` whenever `x, y, xy in B_0`. Put

```text
G_0 = < sigma(L_0 ∪ N_0) >,        Lambda = < sigma(L_0) >,
U*  = < lambda sigma(n) lambda^(-1) : lambda in Lambda, n in N_0 >.       (EC0)
```

`U*` is the **envelope** of the unipotent radical. It is normal in `G_0`.

## Theorem (envelope commutator trap)

If `G_0` is finite, then

```text
sigma(h) in [U*, U*] (U*)^2.                                            (EC1)
```

If `R` has characteristic 2, as `J` does, then `U*` is generated by
involutions, and

```text
sigma(x_13(Q)) in [U*, U*].                                             (EC2)
```

## Corollaries

1. **Abelian envelopes kill the head.** Suppose the `Lambda`-conjugates of
   `sigma(N_0)` commute pairwise. Equivalently,
   `[lambda sigma(n) lambda^(-1), sigma(n')] = 1` for all `lambda in Lambda`
   and `n, n' in N_0`. Then `sigma(x_13(Q)) = 1`.
   - This covers every finite model in which `sigma(N_0)` lies in an abelian
     subgroup normalised by `sigma(L_0)`.
   - In particular it covers every model of the form `A x| F_L`: a finite
     module `A` over a finite model `F_L` of the Levi `EL_2(J) x EL_2(J)`,
     whatever `F_L` is. This is the standard route to LEF for an abelian
     extension, and the one that `jacobson-rank-three-parabolics-are-lef`
     uses for `P_{2,1}(J)`.
   - It covers every exact homomorphism from `P_{2,2}(J)` to a finite group,
     since there `U*` lies in the image of `M_2(J)`. So `P_{2,2}(J)` is not
     residually finite at the head. This proof uses neither property (T) nor
     ideals of `J`.
2. **Loewy length is not the invariant.** The regular module `F_2[A]` of a
   model `A x| F_L` has Loewy length `rank(A) + 1`, which is unbounded, and
   the head still dies there. The consequence paragraph of
   `jacobson-double-parabolic-two-step-models-kill-head` asked only for
   Loewy length at least 3 on every Levi-stable flag. The right invariant is
   `U*^ab`. A head-keeping model needs a nonabelian envelope, and the head
   must be a product of commutators of Levi-conjugates of `sigma(N_0)`.
3. **Where the noncommutation must come from.** Let `sigma` be injective on
   a ball `B_r` of `P`. Take `lambda = sigma(w)` for a word `w`, and
   `n, n' in N_0`, such that `w n w^(-1)` and the products involved lie in
   `B_r`. Then `lambda sigma(n) lambda^(-1)` and `sigma(n')` commute,
   because `M_2(J)` is abelian. So the noncommuting pairs that (EC2)
   requires use elements of the finite Levi image `Lambda` that are **not**
   images of words inside the ball. These are "wrapped" Levi elements.
4. **General parabolics.** The same holds for every configuration of Step 7
   of `jacobson-double-parabolic-two-step-trap-proof`: a unipotent-radical
   root `(i,k)` whose row and column each share a Levi block with a second
   index.

## What this does not do

- It does not decide whether `P_{2,2}(J)` is LEF.
- It says nothing about norm (MF) models. Over `C`, finite-order elements act
  semisimply, so there is no unipotent filtration to run the trap on.
- The degree-2 class of the head in `D_2(U*)/D_3(U*)` is not controlled; see
  `## Attempts` below.

## Attempts

**Degree-two iteration dies at the trap base (swarm-0917-w10-w10-ptl-last1,
2026-09-18).**
- **What the trap needs.** A base vector `v = eps(Y_y)`, with
  `Lambda(b) v` inside the cyclic space of the right-Levi algebra. At the
  level of coefficients this means `b y in y J` for `b = s, t`. `y = 1`
  works.
- **Why degree two fails.** At degree 2 a base must lie in the kernel of the
  degree-1 symbol. The head configuration lives in the finitary ideal
  `(Q) = M_inf(F_2)`.
- **The obstruction.** For `0 != y in (Q)`, the largest row index of `S y`
  is one more than the largest row index of `y`. Right multiplication cannot
  raise row indices. So `S y` is not in `y J`, and the finitary ideal
  contains no trap base.
- **Consequence.** A degree-2 kill must use relations outside the trap's
  configuration.

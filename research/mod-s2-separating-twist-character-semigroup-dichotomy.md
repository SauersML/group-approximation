**ESTABLISHED** through `mod-s2-separating-twist-character-semigroup-dichotomy-proof`. Unreviewed; no novelty claimed.

Let `M = Mod(S_2)`, let `t_s` be a separating Dehn twist, and put `omega = exp(2 pi i/3)`. Let `tr` be the
normalized trace. Define

```text
X  = closure of { tr rho(t_s) : rho a finite-dimensional unitary representation of M }  (in C),
G_2 = X intersected with the unit circle S^1.
```

By (ST1) of `deligne-torelli-character-counts-separating-twists`, all separating twists are conjugate, so `X`
does not depend on `s`.

1. **(D1) Semigroup structure.** `X` is a compact convex subset of the closed unit disc. It contains `1` and
   is closed under multiplication and under complex conjugation.
2. **(D2) Circle part.** `G_2` is a closed subgroup of `S^1`. So either `G_2 = S^1` or `G_2 = mu_m` for some
   `m >= 1`.
3. **(D3) Gap criterion.** For every representation `rho`,
   ```text
   ||rho(t_s) - omega I||_2^2 = 2 - 2 Re(conj(omega) tr rho(t_s)).
   ```
   Hence `mod-s2-exact-representations-have-a-torelli-scalar-gap` holds iff `omega` is not in `G_2`, i.e. iff
   `G_2` is finite of order prime to `3`.
4. **(D4) Tangency criterion.** `G_2 = S^1` iff there are `x_n in X` with the following three properties:
   - `x_n -> 1`;
   - `arg x_n != 0`;
   - `(1 - |x_n|)/|arg x_n| -> 0`.
5. **(D5) Cone condition.** Equivalently, `G_2` is finite iff there are `C > 0` and `r_0 > 0` with
   ```text
   1 - |x|  >=  C |arg x|      for all x in X with |x - 1| < r_0 .
   ```
   So `X` meets a neighbourhood of `1` only inside a Stolz angle.
6. **(D6) Spectral reading.** Write the eigenvalues of `rho(t_s)` as `exp(i phi_j)`, with `|phi_j| <= eps`.
   Put `mu = mean(phi_j)` and `v = variance(phi_j)`. Then
   ```text
   arg tr rho(t_s) = mu + O(eps^3)       and       1 - |tr rho(t_s)| = v/2 + O(eps^4).
   ```
   So (D5) says: honest representations with `rho(t_s)` near the identity in operator norm have spectral
   variance at least `C'|mu|`, up to these error terms. Concentration with variance `o(|mean|)` and
   `eps^3 = o(|mu|)` would give
   `G_2 = S^1`, and then `E_3` would be hyperlinear by (E2) of
   `mod-s2-exact-models-are-fd-character-limits-of-deligne-sectors`.

**Remark.** This remark is not part of the claim. It relies on the chain relation `t_s = (t_a t_b)^6`
(Farb–Margalit, *Primer*, Prop. 4.12) and on `H_1(M) = Z/10` being generated by a nonseparating twist.
Under these, `t_s` maps to `2` in `Z/10`. The linear characters of `M` then place `mu_5` in `G_2`. So on the
finite branch `5 | m`.

**Position.** (D3) and (D5) split the genus-two HS gap into two prerequisites that can fail independently:
- `mod-s2-separating-twist-characters-are-nontangent-at-one` (`G_2` finite);
- `mod-s2-separating-twist-circle-group-has-order-prime-to-three` (on the finite branch, `3` does not divide
  `|G_2|`).

The route is `mod-s2-torelli-scalar-gap-via-nontangency`.

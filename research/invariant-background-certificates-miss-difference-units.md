Setting as in `coset-field-rank-condition-is-lamp-factorization`: `T = L semidirect G = k[Z wr_H G]`, and a
**certificate** is a unital ring map `phi : T -> M`, with `u_g = phi(g)`, used to show that `w I_d` does not
factor through `T^r`. An idempotent `Q in M` is **wandering** if for every `n` there are `g_1, ..., g_n in G`
with `Q u_(g_j^(-1) g_l) Q = 0` for all `j != l`.

**(A) Compression lemma.** If `y = y_1 + ... + y_m` in `M` with `y_i = Q_i y_i` and each `Q_i` wandering, then
for every `d` there are a `d x m` matrix `X` and an `m x d` matrix `Y` over `M` with `XY = y I_d`, and
`rk(y) = 0` for every normalized Sylvester matrix rank function on `M`.

**(B) Support form.** Say `phi` has support form of depth `m` if there are
- a commutative subalgebra `D` of `M` containing all `phi(x_c)`, with `u_g D u_g^(-1) = D`,
- an element `lambda in D` (the background), and
- idempotents `P_c^(i) in D` for `c in H` and `1 <= i <= m`, with `u_g P_c^(i) u_g^(-1) = P_(gc)^(i)` and
  `P_a^(i) P_b^(i) = 0` for `a != b`,

such that `phi(x_c) prod_i (1 - P_c^(i)) = lambda prod_i (1 - P_c^(i))` for every `c`.

If `phi` has support form of depth `m` and every `G`-orbit on `H` is infinite, then for all `c != c'` the element
`y = phi(x_c - x_c')` satisfies (A). Thus `(x_c - x_c') I_d` maps to a matrix factoring through `M^m` for every
`d`, and no normalized Sylvester rank function on `M` sees `x_c - x_c'` as full. Such a certificate cannot refute
any factorization with `r >= m` of `(x_c - x_c') I_d`.

**(C) Nilpotent images.** Suppose `phi` factors through `k[(Z/p^n) wr_H G]` with `char k = p`, or through
`T / J^N`, where `J` is the ideal generated by all `x_c - 1`. Then `phi(x_c - x_c')` is nilpotent, so it is not
full for any Sylvester matrix rank function.

**Coverage.** The marked-site map `Phi_r` of `diagonal-tensor-orbit-corner-induction-proof`, which is the route
to `rf-lamps-preserve-stable-finiteness-for-arbitrary-actions`, sends `n g` to `v_n^(tensor r) u_g`, where
`v_n = 1 + sum_x ([n(x)] - 1) e_x` in the unitization `C`. So `Phi_r(x_c) = tensor_i (1 + (t - 1) e_c^(i))`. This
has support form of depth `r`, with `D = C^(tensor r)`, `lambda = 1` and `P_c^(i) = e_c` in factor `i`. The
residual-two augmentation separation of `kun-thom-binary-wreaths-stably-finite-in-characteristic-two`, transported
to Laurent lamps, passes through the quotients `T / J^N` or finite `p`-lamp quotients, which (C) covers. For the
Kun--Thom coset space `H = G/Gamma`, `Gamma` has infinite index, so the orbit hypothesis holds.

**Dying step and invariant.** The step that fails is the passage to an element that is full: the background is
a `G`-invariant point value, identical at `c` and `c'`, so it cancels the difference unit off a wandering support.
The same invariant kills the point models at `x_(g Gamma) - x_(gamma g Gamma)`.

**Calibration.** For `G = Z` acting regularly on `H = Z`, the ring `k(x_n : n in Z) semidirect Z` is an Ore
domain and has the rank condition. Its marked-site certificates still have support form, so the same failure
occurs. The obstruction limits these methods and is not evidence against the rank condition.

**Reading (not claimed).** A surviving certificate needs a diffuse `G`-invariant background with
`x_c != x_c'` almost surely. One candidate is iid Haar measure on `F_p[[t]]^H`, where every nonzero lamp
polynomial is nonzero almost everywhere, together with a Sylvester rank function on
`L^0(Omega, F_p((t))) semidirect G` that extends the measure. That is a characteristic-`p` dimension theory for a
nonsofic orbit relation.

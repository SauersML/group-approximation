`Λ_h = EL_3(C_h)/Q^x` is simple and contains `GL_n(Q)` for every `n >= 1`
(`harmonic-cuntz-el3-is-fg-simple-over-all-gl-n-q`, parts 1 and 3). If it is
finitely presented (`harmonic-cuntz-simple-group-is-finitely-presented`), it is a
finitely presented simple group containing `GL_n(Q)` for every `n >= 2`.

All groups carry word metrics for fixed finite generating sets. Homomorphisms are Lipschitz. A finite-index
overgroup of an undistorted subgroup is undistorted.

1. **Framed braids.** Let `Y` be a closed disk `D` minus `n` open round disks `Δ_1, …, Δ_n`, which are
   translates of each other. Let `FB_n` be the mapping classes of `Y` that fix `∂D` pointwise and carry
   each `∂Δ_i` onto some `∂Δ_j` by the translation. This is the framed braid group (standard; Ko–Smolinsky,
   Proc. AMS 115 (1992)). Write `T_i` for the twist about `∂Δ_i` and `T_∂` for the twist about `∂D`.
   - `FB_n = Z^n ⋊ s(B_n)`, where `Z^n = ⟨T_1, …, T_n⟩` and `s` is the rigid (blackboard-ribbon) section.
     Capping each hole with a marked disk gives `r: FB_n → B_n` with `r∘s = id`. Conjugation by `s(β)`
     permutes the `T_i` by the permutation of `β`.
   - `τ(a·s(β)) = Σ a_i` is a homomorphism `FB_n → Z`.
   - `T_∂ s(Δ²)^{-1} ∈ Z^n`, since both cap to `Δ²`. It is fixed by conjugation by `s(B_n)`, because `T_∂`
     and `Δ²` are central, so it is `(k, …, k)`. By the ribbon balancing relation `T_∂ = s(Δ²) T_1⋯T_n`,
     `k = 1`; for `n = 1` this is `T_∂ = T_1` in the annulus. Only `k ≠ 0` is used below.
2. **Handles.** Glue a one-holed torus to each `∂Δ_i`, using translates of one parametrization.
   - This gives `S' = S_n^1` (genus `n`, boundary `∂D`). Elements of `FB_n` extend by the matching
     translations, which gives `FB_n → Mod(S')`.
   - Capping `∂D` with a punctured disk gives `S'' = S_{n,1}`, and `FB_n → Map(S'')` factors through
     `Q = FB_n/⟨T_∂⟩`. This is the mapping class group of `Y' = Y ∪ (punctured disk)`, with the holes
     parametrized.
3. **Q is undistorted in Map(S_{n,1}).**
   - `Y'` is cleanly embedded in `S''`. Its boundary curves `c_i = ∂Δ_i` bound one-holed tori, so they are
     essential, non-peripheral and pairwise non-isotopic. The complement consists of `n` one-holed tori, so
     it has no annuli.
   - So the pure part of `Q`, of index `n!`, injects (Farb–Margalit Theorem 3.18) and is quasi-isometrically
     embedded (`subsurface-mapping-class-groups-are-undistorted`).
   - An element of `Q` in the kernel fixes each class `[c_i]`, so it is pure, so it is trivial. The image of
     `Q` is therefore a finite-index overgroup of an undistorted subgroup, hence undistorted.
4. **B_n is undistorted in Q.** Let `b ∈ B_n` with `|[s(b)]|_Q = L`, where `Q` is generated by the images of
   the generators of `FB_n`.
   - Then `s(b) = w T_∂^m` with `|w|_{FB_n} <= L`.
   - Applying `τ`: `0 = τ(w) + mnk`, so `|m| <= |τ(w)| <= C_τ L`.
   - Applying `r`: `b = r(w) Δ^{2m}`, so `|b|_{B_n} <= C_r L + |m||Δ²| <= C L`.
   - So `b ↦ [s(b)]` is injective and a quasi-isometric embedding.
5. **Into Out(F_{2n}).** `Map(S_{n,1})` is a Lipschitz retract of `Out(F_{2n})`
   (`once-punctured-mcg-is-lipschitz-retract-of-out-free`, genus `n >= 1`). With steps 3 and 4,
   `j: B_n → Out(F_{2n})` is a quasi-isometric embedding.
6. **Lift to Aut(F_{2n}).** Fix `p ∈ ∂D`. `Mod(S')` acts on `π_1(S', p) = F_{2n}` with `p` fixed, which is a
   homomorphism `Mod(S') → Aut(F_{2n})`. The inclusion `S' ⊂ S''` identifies the fundamental groups, so its
   composite with `Aut → Out` is `Mod(S') → Map(S'') → Out(F_{2n})`.
   - Put `ι_n = (Mod(S') → Aut(F_{2n})) ∘ (FB_n → Mod(S')) ∘ s`. Then `π∘ι_n = j`.
   - So `|b| <= A|j(b)| + B <= A·Lip(π)·|ι_n(b)| + B`: `ι_n` is injective and a quasi-isometric embedding.
     This is part 1 of the target. By part 2 of `aut-free-groups-quasi-isometrically-embed-in-fp-simple-groups`,
     `ι_n(B_n)` is undistorted in `SV_Γ`.
7. **Surfaces with boundary (part 2).** Let `Σ = S_g^b`, `b >= 1`, and assume `Σ` is neither a disk nor an
   annulus.
   - Cap `∂_1, …, ∂_{b−1}` with one-holed tori, and cap `∂_b` with a two-holed torus `U` whose other boundary
     is `∂S'`. This gives `S' = S_{g+b}^1`.
   - Capping `∂S'` with a punctured disk gives `S_{g+b,1}`. There `Σ` is cleanly embedded, and the complement
     is `b−1` one-holed tori plus one punctured one-holed torus: no disks, no punctured disks, no annuli, no
     isotopic pairs.
   - Steps 3, 5 and 6 then apply verbatim with the pure group `Mod(Σ)` in place of `Q` and `B_n`.
   - The disk has trivial `Mod`. For the annulus, `Mod ≅ Z` is undistorted in `V`
     (`thompson-v-cyclic-subgroups-are-undistorted`).
8. **Part 3.** Undistorted inclusions compose. For `A(B_n)`, restrict `ι_{n+1}` to the finite-index subgroup of
   braids fixing one strand. ∎

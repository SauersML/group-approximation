If `R' = 1`, the established embedding

    G/R' -> ((Z/kZ)^d) wr (G/R)

is an embedding of `G` itself into a sofic restricted wreath product.  Soficity
passes to subgroups, so `G` is sofic.  This is an application of the explicit
embedding and uses no closure claim for arbitrary extensions or semidirect
products.

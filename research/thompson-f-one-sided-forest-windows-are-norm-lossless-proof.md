Notation and the facts used are those of steps 1–2 of
`thompson-f-norm-bound-from-forest-renewal-test-vector-proof`:
- `G = <s_0, s_1> ≅ F`, with `(K f)(x) = sum_g f(x o g)`;
- the maps `h_T`, the blocks, and `E(state)`;
- every move `x -> y` by `g` has `E(y) = E(x) o g`;
- `E(S_n) ⊂ G`, and `E` is injective on `S_n`.

Write `tau_c(t) = t + c`, so `tau_c = s_0^c` lies in `G`. A *standard dyadic interval* is
`[p 2^-q, (p+1) 2^-q]` with `p, q` integers. Below, "length `<= 1`" means `q >= 0`.

**Step 0 (tree maps).** For a finite binary tree `T`, `h_T^{-1}` maps each `[r, r+1]`
(`0 <= r < |T|`) linearly onto the `r`-th leaf interval of `T`, a standard dyadic subinterval of
`[0,1]`. Conversely, every finite partition of `[0,1]` into standard dyadic intervals is the leaf
partition of exactly one tree.
- *Forward.* Induct on `T = (L, R)`. On `[0, |L|]`, `h_T^{-1} = h_L^{-1}(.)/2`. On
  `[|L|, |T|]`, it is `(1 + h_R^{-1}(. - |L|))/2`. Halving a standard dyadic subinterval of `[0,1]`,
  or halving it and adding `1/2`, gives a standard dyadic subinterval of `[0,1/2]` or `[1/2,1]`.
- *Converse.* A standard dyadic interval of length `<= 1/2` lies in `[0,1/2]` or in `[1/2,1]`.
  So a partition other than `{[0,1]}` refines the two halves, and we induct.

**Step 1 (intrinsic test).** Let `g` be any PL homeomorphism of `R`. Then `g ∈ R := ∪_n E(S_n)`
iff all three of the following hold:
- **(a)** `g^{-1}` maps every `[b, b+1]` (`b ∈ Z`) linearly onto a standard dyadic interval of
  length `<= 1`;
- **(b)** `g(0) >= 0`;
- **(c)** every integer `k` with `g(k) < 0` has `g(k+1) = g(k) + 1`.

*Only if.* Let `g = E(T_0..T_{m-1}; i)`.
- **(a).** On `[k, k+1]`, `g` is `t -> a_j + h_{T_j}(t - k)` with `j = i + k`, and `T_j` is a leaf
  outside the window. By Step 0, `g^{-1}` maps each unit interval of the block linearly onto a
  standard dyadic subinterval of `[k, k+1]`.
- **(b).** `g(0) = a_i >= 0`.
- **(c).** Window blocks start at `a_j >= 0`, and blocks right of the window start at
  `>= n`. So `g(k) < 0` forces `i + k < 0`, where the block is the leaf block `[i+k, i+k+1]`.

*If.* Assume (a), (b), (c).
- *The tiles.* The images `g^{-1}([b, b+1])` tile `R` in order. Each one is standard dyadic of
  length `<= 1`, so it lies in a single `[k, k+1]`. Hence the tiling refines `Z`, and every integer
  is a tile endpoint, so `g(Z) ⊂ Z`.
- *Tails.* `g^{-1}` has finitely many breakpoints. Outside a compact set it is a translation, and
  (a) forces that translation to be by an integer. So each `[k, k+1]` holds finitely many tiles,
  and it holds exactly one tile for `|k|` large.
- *Tree maps.* By Step 0 the tiles in `[k, k+1]` are the leaves of a unique tree `T_k`, with
  `T_k` a leaf for `|k|` large. `g` maps the `r`-th tile linearly onto `[g(k) + r, g(k) + r + 1]`.
  So `g(t) = g(k) + h_{T_k}(t - k)` on `[k, k+1]`.
- *The pointer.* Let `k_1 = max{k : g(k) < 0}`. It exists, because `g(k) -> -infinity` and
  `g(0) >= 0`, so `k_1 <= -1`. By (c), `g(k_1 + 1) = g(k_1) + 1`. This is an integer `>= 0` and at
  most `0`, so `g(k_1 + 1) = 0`. Put `i = -(k_1 + 1) >= 0`.
  - `g(-i) = 0`.
  - By (c) all blocks left of `-i` are unit, so `g(k) = k + i` for `k <= -i`.
- *The window.* Pick `m > i` with `T_k` a leaf for all `k >= m - i`. Put `T'_j = T_{j-i}` for
  `0 <= j < m`, and let `n` be their total leaf count.
- *Matching.* Compare `E(T'_0..T'_{m-1}; i)` with `g` on each `[k, k+1]`:
  - for `i + k < 0`, both give the unit block `[i+k, i+k+1]`;
  - for `0 <= j = i + k < m`, `a_j = sum_{l < j} |T'_l| = g(k) - g(-i) = g(k)`, with the same tree;
  - for `j >= m`, `g(k) = g(m-i) + (k - m + i) = n + j - m`.

  So `g = E(T'; i)`. □

*Remarks.*
- *One-sided forests.* Appending a leaf tree to a window does not change `E`, because the new
  tree sits exactly on the old outside leaf block. So `E(S_n) ⊂ E(S_{n+1})`, and `R` is in
  bijection with one-sided pointed forests `(phi; i)`: `phi = (T_0, T_1, ...)` has finitely many
  nontrivial trees, and `i >= 0`. By step 2 of the cited proof, `R ⊂ G`.
- *Positive monoid.* `R` is also the monoid, under composition, generated by `s_0` and
  `y_n = s_0^{n-1} o s_1 o s_0^{-(n-1)}` (`n >= 1`). Composing with `y_n` merges the roots `i+n-1`
  and `i+n`, and every one-sided forest is built from `id` by such merges followed by `s_0^i`.
  Under `x_0 -> s_0`, `x_1 -> s_1` (with the "first, then" product of `model_check.py`), `y_n` is
  the image of `x_n = x_0^{-(n-1)} x_1 x_0^{n-1}`. So `R` is the image of the positive monoid.
  This remark is not used below.

**Step 2 (dyadic refinement).** Let `b ∈ G`. Then:
- `b` is PL with finitely many breakpoints, all dyadic rational;
- its slopes are powers of `2`;
- it is a translation by an integer outside a compact set.

All three hold for `s_0^{±1}`, `s_1^{±1}`, and they are preserved under composition. They are also
preserved under inversion: an affine map `t -> 2^s t + c` with dyadic `c` maps dyadic rationals to
dyadic rationals.

*Claim.* For a finite set `B ⊂ G` there is a partition `Q` of `R` into standard dyadic intervals
of length `<= 1` such that:
- all but finitely many pieces are unit intervals `[k, k+1]`;
- every `b ∈ B` is linear on every piece, and maps it onto a standard dyadic interval of
  length `<= 1`.

*Proof.* Call a standard dyadic interval `J` *good* if every `b ∈ B` is linear on `J` and
`b(J)` is standard dyadic of length `<= 1`.
- *Refinement preserves goodness.* A good `J` has all its standard dyadic subintervals good. An
  affine map of slope `2^s` taking `J` onto a standard dyadic interval takes the standard
  subinterval `[p 2^-q + r 2^-(q+l), p 2^-q + (r+1) 2^-(q+l)]` onto one of the same form.
- *Far out.* Outside a compact set every `b` is an integer translation, so every `[k, k+1]` with
  `|k|` large is good.
- *Deep enough.* Fix `k`. Let `2^e` bound the denominators of all breakpoints and of all
  intercepts `c` of all linear pieces `t -> 2^s t + c` of all `b ∈ B`, and let `s_max` bound the
  slopes' exponents. Every standard dyadic `J ⊂ [k, k+1]` of depth
  `q >= e + max(0, s_max)` is good:
  - no breakpoint lies in its interior;
  - its image `[2^s p 2^-q + c, ...]` has length `2^{s-q} <= 1`;
  - its left endpoint divided by the length is `p + c 2^{q-s}`, an integer.
- So bisecting bad intervals of `[k, k+1]` terminates in a finite good partition. Take this on
  the finitely many bad unit intervals and keep the rest. □

**Step 3 (absorption).** For every finite `A ⊂ G` there is `h ∈ G` with `h o a ∈ R` for all
`a ∈ A`.
- *The partition.* We may assume `id ∈ A`. Apply Step 2 to `B = {a^{-1} : a ∈ A}` to get `Q`.
  Its pieces refine `Z`, so `0` is an endpoint. Number the pieces `Q_j` (`j ∈ Z`) in order, with
  `Q_0` starting at `0`.
- *The map `v`.* Let `v` be the PL homeomorphism mapping each `Q_j` linearly onto `[j, j+1]`.
  For `a ∈ A`, `(v o a)^{-1} = a^{-1} o v^{-1}` maps `[j, j+1]` linearly onto `Q_j`, and then
  linearly onto `a^{-1}(Q_j)`, which is standard dyadic of length `<= 1`. So every `v o a`
  satisfies (a). The case `a = id` gives this for `v` itself.
- *Shifting.* If `g` satisfies (a), so does `tau_C o g` for every `C ∈ Z`. By the first three bullets of
  the *If* part of Step 1, which use only (a), `g` has unit blocks `[g(k), g(k)+1]` for all `k < -M_g`. Take `C >= -g(-M_g)`. Then `g(0) + C >= 0`, and
  `g(k) + C < 0` forces `k < -M_g`, where the block is unit. So `tau_C o g` satisfies (b) and (c).
- *Conclusion.* With `C` large enough for all `g = v o a`, `a ∈ A`, put `h = tau_C o v`. Then
  `h o a ∈ R` by Step 1. In particular `h = h o id ∈ R ⊂ G`. □

This is the common-right-multiple property of the positive monoid, in the PL model. See Step 0 of
`thompson-f-nonamenable-iff-some-monomial-set-doubles-proof`. `absorb_check.py` (part 2) runs this
construction verbatim, in exact arithmetic, on 200 random sets of 13 words of length up to 14, and
checks `h o A ⊂ R` with the Step 1 test.

**Step 4 (edges of `Gamma_R`).** Let `x = E(phi; i) ∈ R`, and represent it in a window whose last
tree lies right of both the pointer and every nontrivial tree.
- *Pointer right and merge.* These are moves inside that window, so
  `x o s_0 = E(phi; i+1)` and `x o s_1 = E(merge)` both lie in `R`.
- *Pointer left.* If `i > 0`, this is a move, and `x o s_0^{-1} ∈ R`. If `i = 0`, then
  `(x o s_0^{-1})(0) = x(-1) = -1`, since `x(t) = t + i` for `t <= -i`. This breaks (b).
- *Split.* If `T_i` is not a leaf, this is a move. If `T_i` is a leaf, `x` maps `[0,1]` linearly
  onto `[a_i, a_i + 1]`, so `(x o s_1^{-1})(1) = x(1/2) = a_i + 1/2`. This is not an integer,
  and Step 1 shows that (a) forces `g(Z) ⊂ Z`. So it breaks (a).

So `Gamma_R`, the induced subgraph of the Cayley graph on `R`, is the one-sided move graph of the
claim. Every vertex has degree `4 - [i = 0] - [T_i is a leaf]`, and distinct generators give
distinct neighbours.

*Windows.* The induced subgraph on `E(S_n)` is exactly the move graph on `S_n`. Take
`x = E(T_0..T_{m-1}; i)` in `S_n`, and a neighbour `x o g` lying in `E(S_n)`.
- *Inside the window.* If the move stays inside `S_n`, it is a move edge of `S_n`.
- *At the edge.* The only other possibilities are pointer right from `i = m - 1`, and a merge of
  `T_{m-1}` with the outside leaf.
  - In the first case the pointer sits on root `m`, while the first `m` roots already carry all
    `n` leaves.
  - In the second case, every prefix of roots containing the new tree `(T_{m-1}, leaf)` carries
    at least `n + 1` leaves.

  Neither is `E` of a state of `S_n`. By Step 1 and the bijection, a state of `S_n` is a prefix of
  roots with exactly `n` leaves that contains the pointer.

`absorb_check.py` (part 1) confirms this for `n <= 7` in exact arithmetic:
- `in_R` holds on all of `E(S_n)`;
- the forbidden moves leave `R`;
- the induced directed edges on `E(S_n)` are exactly the move edges (`absorb_check_n7.out`).

**Step 5 (compression identity).** Let `K_R` be the compression of `K` to `l^2(R)`, so
`(K_R f)(x) = sum over g with x o g ∈ R of f(x o g)`. Clearly `||K_R|| <= ||K||`.

*Reverse inequality.*
- *Reduction to finite nonnegative `f`.* `K` is self-adjoint and has nonnegative matrix entries.
  So `||K|| = sup |<f, K f>| / <f, f>`, and `|<f, K f>| <= <|f|, K |f|>`. Finitely supported
  vectors are dense. Hence `||K||` is the supremum over finitely supported `f >= 0`.
- *Translation into `R`.* Given such an `f` with support `A`, take `h` from Step 3 and put
  `f_h(x) = f(h^{-1} o x)`. Then `f_h` is supported on `h o A ⊂ R`.
- *The quotient is preserved.* `x -> h o x` is a graph automorphism, since
  `h o (x o g) = (h o x) o g`. So `<f_h, K f_h> = <f, K f>` and `<f_h, f_h> = <f, f>`.
- *Compression.* For a vector supported in `R`, `<f_h, K f_h> = <f_h, K_R f_h>`.

Hence `||K_R|| = ||K||`, which is item 3.

**Step 6 (windows increase to the norm; items 1 and 2).**
- *Each window.* By Step 4, `A_n` is the matrix of the compression of `K` to `l^2(E(S_n))`, and
  `rho_n = ||A_n||` by Perron–Frobenius.
- *Monotone.* `E(S_n) ⊂ E(S_{n+1})`, and the compression to a larger set has at least the same
  norm, so `rho_n` is nondecreasing.
- *Exhaustion.* Every finite subset of `R` lies in one `E(S_n)`: pad each window with trailing
  leaves up to a common `n`. So finitely supported vectors on `∪_n E(S_n) = R` are
  exhausted, and `sup_n rho_n = ||K_R|| = ||K||` by Step 5.
- *Kesten.* `F` is amenable iff `||P|| = 1`, that is iff `||K|| = 4`.

**Step 7 (deficiency; item 4).** For `f >= 0` on `R`,
`2 f(x) f(y) = f(x)^2 + f(y)^2 - (f(x) - f(y))^2` on each undirected edge of `Gamma_R`. Summing,
and using the degrees of Step 4,

    <f, K f> = sum_v deg(v) f(v)^2 - energy(f) = 4<f, f> - delta(f) - energy(f).

- *Amenable.* If `F` is amenable, Step 5 gives unit `f >= 0` on `R` with `<f, K f> -> 4`, so
  `delta + energy -> 0`.
- *Converse.* Such vectors force `||K|| = 4`.
- *The cap.* This is the displayed identity with `energy >= 0`. □

## Why sufficient

The soundness method, the check that `Rad_MF` satisfies every rule, and the
intersection lemma are those of
`torsion-free-seeds-need-kernel-descent-or-trace-corner-proof`.  By that
lemma, for `R = Rad_MF intersect P` with `P` a normal-subgroup assignment:

- (F), (D) and (I) hold if they hold for `P`;
- (X) holds if `{P(H) = H}` has the closure properties;
- (S) holds if `P` satisfies (F) and each `P(Q)` is normal.

So it suffices to check `P = U`.  Recall that `T(M)`, the intersection of the
normal `M'` with `M/M'` torsion-free, is the smallest such subgroup, since
`M/T(M)` embeds in a product of torsion-free groups.  Write
`N <|_fi H` for a normal subgroup of finite index.

**Step 0: two properties of `T`.**

- *Functoriality.*  For `f : M -> M'`, the image of `M` in `M'/T(M')` is a
  torsion-free group.  So `f(T(M)) <= T(M')`.
- *Monotonicity.*  For `M' <= M`, the quotient `M'/(M' intersect T(M))`
  embeds in `M/T(M)`, so `T(M') <= T(M)`.

Each `T(N)` is characteristic in `N`.  So for `N <|_fi H` it is normal in
`H`, and hence `U(H)` is normal.  Also `U(H) <= T(N) <= N` for every such
`N`.

**Step 1: (F).**  Let `f : G -> H` and `N <|_fi H`.  Then
`M = f^-1(N) <|_fi G`, and `f(U(G)) <= f(T(M)) <= T(N)` by functoriality
applied to `f|_M : M -> N`.  Intersecting over `N` gives
`f(U(G)) <= U(H)`.

**Step 2: (I).**  Let `E <= H` have finite index.  Let `F` be the family of
`N <|_fi H` with `N <= E`.  Each member is normal of finite index in `E`.

- For every `M <|_fi E`, the core `Core_H(M)` lies in `F`, and
  `T(Core_H(M)) <= T(M)` by monotonicity.
- For every `N <|_fi H`, the subgroup `N intersect Core_H(E)` lies in `F`,
  and its `T` lies in `T(N)`.

So `U(E)` and `U(H)` both equal the intersection of `T(N)` over `N` in `F`.
Hence `U(E) = U(H)`, and `U(H) <= E`, so `U(E) = E intersect U(H)`.  With
`corona-finite-index-radical-heredity`,
`Rad^nat(E) = E intersect Rad_MF(H) intersect U(H) = E intersect Rad^nat(H)`.

**Step 3: (X).**  If `U(H) = H`, then `H <= N` for every `N <|_fi H`.  So `H`
has no proper finite-index subgroup, and then `U(H) = T(H) = H`.
Conversely, if `H` has no nontrivial finite quotient and `T(H) = H`, then
`U(H) = T(H) = H`.  So `{U(H) = H}` is exactly the class `Cl` of
`torsion-free-seeds-need-kernel-descent-or-trace-corner-proof`.  Step (a)1
there shows that `Cl` is closed under extensions, free products, amalgams
and directed colimits.  Intersecting with
`full-mf-radical-groups-form-an-extension-colimit-class` gives (X).

**Step 4: (S).**  This follows from Step 1 and the normality of `U(Q)`, by
the intersection lemma.

**Step 5: (D).**  Let `N` be normal in `H` with `N <= U(H)`, and let
`pi : H -> H/N`.  Step 1 gives `U(H) <= pi^-1 U(H/N)`.  Conversely, let
`pi(x) in U(H/N)` and `M <|_fi H`.

1. `N <= U(H) <= M`, so `M/N <|_fi H/N` and `pi(x) in T(M/N) <= M/N`.
   Hence `x in M`.
2. `N <= U(H) <= T(M)`, so `M/T(M)` is a torsion-free quotient of `M/N`.
   Therefore `T(M/N) <= T(M)/N`, and `x in T(M)`.

Intersecting over `M` gives `x in U(H)`.  So `U(H) = pi^-1 U(H/N)`.

**Step 6: (C).**  A sound (C)-instance gives `K <= Rad_MF(H)` with `K`
generated by elements of finite order.  By (R1) of
`virtually-torsion-free-mf-radical-is-torsion-free`, `K <= N` for every
`N <|_fi H`.  Every element of finite order in `N` dies in the torsion-free
group `N/T(N)`, so `K <= T(N)`.  Hence `K <= U(H)`, and so
`K <= Rad^nat(H)`.  This is the only step that uses the new lemma.  Without
(R1) a torsion element of `Rad_MF(H)` could lie outside some `N`, and then
`T(N)` would say nothing about it.

**Step 7: (A).**  `G = St_20(L)` lies in `Cl` by step (a)6 of
`torsion-free-seeds-need-kernel-descent-or-trace-corner-proof`.  That step
uses `binary-leavitt-elementary-group-is-simple` and the central `K_2`.  By
Step 3, `U(G) = G`.  So `Rad^nat(G) = Rad_MF(G)`, and (A) for `Rad^nat` is
equivalent to (A) for `Rad_MF`.  The bare `U` satisfies (A)
unconditionally.

**Step 8: vanishing.**  Let `E <= H` be torsion-free of finite index.  Then
`N = Core_H(E) <|_fi H` is torsion-free, so `T(N) = 1` and `U(H) = 1`.

**Step 9: nesting.**

- `Rad* <= Rad^nat`.  Let `C <= H` be a `Cl`-subgroup and `N <|_fi H`.
  Then `C intersect N` has finite index in `C`, so it equals `C`.  The image
  of `C` in `N/T(N)` is a torsion-free quotient of `C`, so it is trivial.
  Hence `C <= U(H)`, and `Phi(H) <= U(H)`.
- `Rad^nat <= Rad#`.  Take `N = H` in the intersection defining `U`, which
  gives `U(H) <= T(H)`.

`Rad#` fails (I) on the swap wreath `H = (T_0 x T_0) x| <s>`.  `Rad^nat`
repairs it: `E = T_0 x T_0 <|_fi H` is torsion-free, so `U(H) = 1`.  The
element `(a, a^-1)` lies in `T(H)`, but not in `T(E) = 1`.

**Soundness conclusion.**  Every derivation from (A) by instances of (F),
(S), (X), (D), (I) and (C) proves only statements that are true for
`Rad^nat`.  By Step 8, `Rad^nat` is trivial on every virtually torsion-free
group.  So no such derivation proves `1 != x in R(H)` for any virtually
torsion-free `H`.

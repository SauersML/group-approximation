Notation of the claim. Products act on the left, `(gh)|_x = g|_{h(x)} h|_x`. Every state preserves the
positions of the letters `#`, `$` and `γ`, and maps digits to digits. So the **shape** of a word (the
positions and values of its non-digit letters) is invariant under `C'`.

## 0. Letter rules

The following are read off (CM). A **block** is a maximal digit word `c ∈ {0,1}^n` (possibly `n = 0`).
A word begins with a block `c`, followed by a non-digit letter or by nothing (an infinite block).

- **`A` is increment.** On `c ∈ {0,1}^n` followed by a non-digit letter `x`, `A` adds 1 to `c`, least
  significant digit first, with the carry lost at overflow. Its section after `cx` is:
  - `K|_{...}`, i.e. `K` applied to the rest, if `x = γ` and `c = 0^n` with `n >= 1`;
  - trivial if `c = 1^n` (including `n = 0`), or if `x ∈ {#, $}`;
  - `A` if `x = γ` and `c` is neither `0^n` nor `1^n`.

  *Check.* `A(0v) = 1Z(v)`. `Z` echoes `0`s, becomes `N` at the first `1`, and `N` echoes digits. On
  `γ`, `Z` gives `K` and `N` gives `A`. `A(1^k 0 v) = 0^k 1 N(v)` for `k >= 1`, and
  `A(1^k x v) = 0^k x v` for a non-digit `x`, since `A'|_x = 1`. On `#` and `$`, `Z`, `N` and `A'` have
  trivial sections.
- **`K`.** `K` echoes everything. `K(u # v) = u # A(v)` if `u ∈ {0, γ}^*`. `K` acts trivially on every
  word whose first letter outside `{0, γ}` is `1` or `$`, or that has no such letter.
- **`Z`, `N`** echo everything, with the following sections past the first block `c` and its
  terminator `x`:

  | `c`, `x` | `Z` | `N` | `K` |
  |---|---|---|---|
  | `c = 0^k`, `x = γ` | `K` | `A` | `K` |
  | `c` contains a `1`, `x = γ` | `A` | `A` | `1` |
  | `c = 0^k`, `x = #` | `1` | `1` | `A` |
  | `c` contains a `1`, `x = #`; or `x = $` | `1` | `1` | `1` |

  On an infinite block, all three act trivially.

## 1. Stability, closedness and the germ group at `0^ω`

`S = {A, A', Z, N, K}^{±1}` is closed under sections and inverses. From (CM):

- **Sections at `0`:**
  - `A|_0 = Z` with output `1`;
  - `A'|_0 = N` with output `1`;
  - `Z|_0 = Z`, `N|_0 = N`, `K|_0 = K`, each with output `0`.
- **Sections at `1`:**
  - `A|_1 = A'` with output `0`;
  - `A'|_1 = A'` with output `0`;
  - `Z|_1 = N` and `N|_1 = N`, each with output `1`;
  - `K|_1 = 1`.
- **Inverses:** `(g^{-1})|_x = (g|_{g^{-1}(x)})^{-1}`.

Hence every `s ∈ S` has eventually constant sections along `0^k` and along `1^k`. The eventual states are:

| ray | eventual states and their outputs |
|---|---|
| `0^ω` | `Z^{±1}, N^{±1}, K^{±1}` (output `0`); `A'^{-1}` (output `1`) |
| `1^ω` | `A'` (output `0`); `N^{±1}` (output `1`); `1` (output `1`) |

So `{0, 1}` is a closed family of stable letters (`results.txt`, first 21 lines).

**The loop arrows** `[e, y]`, with `e ∈ S` and `e|_y = e`, are:
- at `0`: `Z`, `N`, `K`;
- at `1`: `N`;
- from `1` to `0`: `A'`;
- together with their inverses.

The groupoid is connected. Take `[A', 1]` as a spanning tree. Then `π_1(Π, 0)` is generated by
`Z`, `N`, `K` and `A' N A'^{-1}`.

A loop state `h` (`h(0) = 0`, `h|_0 = h`) is trivial near `0^ω` only if `h|_{0^k} = h` is trivial. So
the realization map sends `π_1(Π, 0)` onto the germ group, and on germs it is just evaluation in `C'`.
Thus `G_(0^ω) ≅ ⟨Z, N, K, A' N A'^{-1}⟩ ≤ C'`.

**`A' N A'^{-1} = N`.** Compute the sections of `A' N A'^{-1}`:
- at `0`: via `1`, the section is `A' · N · A'^{-1}`;
- at `1`: via `0`, the section is `N · N · N^{-1} = N`;
- at `γ`, `#` and `$`: the sections are `A`, `1` and `1`.

The root permutation is trivial. So `A' N A'^{-1} = (A' N A'^{-1}, N, A, 1, 1)`, while
`N = (N, N, A, 1, 1)`. Hence `X = A' N A'^{-1} N^{-1} = (X, 1, 1, 1, 1)`, which is trivial. This is
checked in `results.txt`. Hence `G_(0^ω) ≅ H = ⟨Z, N, K⟩`.

## 2. `⟨A, K⟩ ≅ Z ≀ Z`

Write `K_n = A^n K A^{-n}`.

**(a) `A` has infinite order, and every relation has `A`-exponent sum `0`.**
- Fix a block length `n` and consider words `c γ v` with `c ∈ {0,1}^n`.
- `A` adds 1 to `c` modulo `2^n`. `K` fixes `c`, since it echoes everything.
- So `c ↦ c + 1` defines a homomorphism `⟨A, K⟩ → Z/2^n` with `A ↦ 1` and `K ↦ 0`.
- A word that is trivial in `⟨A, K⟩` has `A`-exponent sum divisible by every `2^n`, so the sum is `0`.

**(b) Every section past a `#` is a power of `A`.**
- Fix a shape whose first non-block letter outside `{γ}` is a `#`. So the word is
  `P # v`, where `P = c_1 γ c_2 γ ⋯ c_r γ` is a sequence of blocks of fixed lengths.
- Every state reached from `A` or `K` while reading a word of `{0,1,γ}^*` lies in
  `{A, A', Z, N, K, 1}`.
- The sections of these states at `#` are `1, 1, 1, 1, A, 1`.
- So for `g ∈ {A, K}^{±1}`, `g(P # v) = g(P) # A^{ε_g(P)}(v)` with `ε_g(P) ∈ {0, ±1}`.
- Hence on the words of this shape, `⟨A, K⟩` acts through the permutational wreath product
  `⟨A⟩ ≀_{C_P} Sym(C_P)`, where `C_P` is the finite set of block values. Its base group `⟨A⟩^{C_P}` is
  abelian.
- `K` maps into the base: `K` fixes `P`, and multiplies the coordinate at `P = 0` by `A`.
- So every `K_n` maps into the base, and all the `K_n` commute on these words.
- On every other shape (no `#`, or a `1` or `$` before the first `#` in a position where `K` stops),
  `K` acts trivially, and so does every `K_n`, since shapes are `A`-invariant.
  - Precisely: `K` acts nontrivially only on words `u # v` with `u ∈ {0,γ}^*`. `A^{-n}` preserves the
    shape, so `K_n` is supported on shapes with a `#`, and there the previous argument applies.
- Hence `[K_i, K_j] = 1` for all `i, j`. (`results.txt` checks `[K, A K A^{-1}]` and
  `[K, A^3 K A^{-3}]`.)

**(c) The `K_n` are independent.**
- Take the shape `c γ # v` with `|c| = n`. By §0:
  - `A(c, v) = (c + 1, A^{[c = 0]} v)`;
  - `K(c, v) = (c, A^{[c = 0]} v)`.
- So `K_j` acts by `(c, v) ↦ (c, A^{[c = j mod 2^n]} v)`, since the base is abelian.
- Let `∏_{|j| <= M} K_j^{e_j}` be trivial, and choose `2^n > 2M + 1`. At `c = j mod 2^n` it acts on `v`
  by `A^{e_j}`.
- Since `A` has infinite order, every `e_j = 0`.

**(d) Conclusion.**
- By (b), `t ↦ A`, `a ↦ K` defines a surjection `Z ≀ Z = ⟨a, t | [a, t^n a t^{-n}] (n >= 1)⟩ → ⟨A, K⟩`.
- Let `t^m ∏ (t^j a t^{-j})^{e_j}` be in its kernel. By (a), `m = 0`. By (c), all `e_j = 0`.
- So the surjection is an isomorphism.

(`results.txt` also checks that no product of the lamps `K_0..K_3` with exponents in `{-1,0,1}` is
trivial.)

## 3. `H = ⟨Z, N, K⟩ ≅ (Z ≀ Z) × Z`, not finitely presented

**The first-block table of §0 covers everything.** It covers every infinite word except those on which
`Z`, `N` and `K` all act trivially. `Z`, `N` and `K` fix the first block and its terminator, so a word
`w(Z, N, K)` acts as follows:
- on `0^k γ v`: by `w(K, A, K)` on `v`;
- on `c γ v`, with `c` containing a `1`: by `w(A, A, 1)`;
- on `0^k # v`: by `w(1, 1, A)`;
- elsewhere: trivially.

So `w ↦ (w(K,A,K), w(A,A,1), w(1,1,A))` is an injective homomorphism
`H → ⟨A,K⟩ × ⟨A⟩ × ⟨A⟩ ≅ (Z ≀ Z) × Z × Z`. The images of the generators are:
- `Z ↦ (a, 1, 0)`;
- `N ↦ (t, 1, 0)`;
- `K ↦ (a, 0, 1)`.

**Splitting off the centre.** Let `ψ : Z ≀ Z → Z^2` be `t ↦ (1,0)`, `a ↦ (0,1)`.
- `⟨N, K⟩` maps onto the graph `{(g, ψ(g))}` of `ψ`, which is isomorphic to `Z ≀ Z`.
- `c = Z K^{-1} ↦ (1, 1, -1)` is central. Its powers meet the graph trivially, because a graph element
  with first coordinate `1` is `1`.
- So `H = ⟨N, K⟩ × ⟨c⟩ ≅ (Z ≀ Z) × Z`.
- As a check, `[Z, K] = 1` and `[K, N] ≠ 1` in `results.txt`. A random-word test also confirms the
  kernel description `w = 1 ⟺ w(K,A,K) = 1 and e_Z(w) = 0`, which follows from the embedding.

**Not finitely presented.** `Z ≀ Z` is not finitely presented (Baumslag 1961). It is a retract of
`(Z ≀ Z) × Z`, and a retract of a finitely presented group is finitely presented. So `H` is not finitely
presented.

**Proof of part 1.** Apply `nekrashevych-fp-iff-cycle-germ-groups-fp`, part 1, to the closed stable
family `{0,1}` of §1. In lift-ideal form it says: if the relator kernel of `C'` were a finitely
generated lift ideal, then `G_(0^ω) ≅ H` would be finitely presented. So the action is not
lift-presented. By Theorem A, `V_{|X'|}(C')` is not finitely presented.

## 4. The binary encoding, `L ≢ 2 (mod 3)`

**The aligned states.** The code `{100, 101, 110, 111} ∪ 0{0,1}^L` is a complete prefix code. So
reading codes identifies `{0,1}^ω` with `Σ'^ω`, where `Σ' = {0, 1, #, $} ∪ Γ` and `|Γ| = 2^L`. Under
this identification the aligned state `(p, ε)` acts as `p` (Wächter–Weiß, the encoding paragraph). In
particular `⟨(Z,ε), (N,ε), (K,ε)⟩ ≅ H`. §§0–3 never used `|Γ|`, only that all `γ` behave alike.

**Phases along `y_0^ω = (100)^ω` and `y_1^ω = (101)^ω`.** A state `(p, x)` with `x ≠ ε` reads the ray
starting at some residue `r ∈ {1, 2}` modulo 3. Parse from residue `r`:
- On `(100)^ω`, bits at residues `1` and `2` are `0`. So a code starts with `0`, is a γ-code of length
  `L + 1`, and the next code starts at residue `r + L + 1`.
- On `(101)^ω`:
  - at residue `1` the bit is `0`, giving a γ-code and residue `1 + L + 1`;
  - at residue `2` the bit is `1`, giving the code `110 = #` and residue `2` again.
- Residue `0` gives a 3-code and stays at residue `0`. This is the aligned parse.

**Case `L + 1 ≢ 0 (mod 3)`.** Starting from residue 1 or 2, the parse on `(100)^ω` reaches residue `0`
after at most two γ-codes. On `(101)^ω`, residue 1 goes to residue `0` (if `L ≡ 1`) or to residue `2`
(if `L ≡ 0`); residue 2 reads `#` forever.
- Reading `#`: the sections of `Z, N, A, A'` at `#` are `1`, and `K|_# = A`. So after at most two `#`
  every state is `1`.
- Hence, from any start, every state along either ray is eventually aligned or trivial.

**Consequences for level 3.**
- Every eventual state is aligned. From the aligned part, every letter `y_0, y_1` of `X^3` is stable, the
  eventual outputs are the images of the letters `0, 1` under the loop states of §1, and those lie in
  `{y_0, y_1}`. So `{y_0, y_1}` is closed and stable at level 3.
- A misaligned state is never a loop at level `3m`, for any `m`. If `(p,x)|_{y^m} = (p,x)` with
  `x ≠ ε`, then `(p,x)|_{y^{mk}} = (p,x)` for all `k`, but for large `k` that section is aligned or
  trivial.
- So the loop arrows are those of §1 on aligned states: `(Z,ε)`, `(N,ε)`, `(K,ε)` at `y_0`, `(N,ε)` at
  `y_1`, and `(A',ε)` from `y_1` to `y_0`. The computation for `L = 1, 3, 4` (`results.txt`) confirms
  both the loops and `m = 1`.
- As in §1, the germ group of `C` at `(100)^ω` is `⟨(Z,ε),(N,ε),(K,ε)⟩ ≅ H`, which is not finitely
  presented.

**Proof of part 2.**
1. Suppose `V_2(C)` is finitely presented.
2. By `lift-presentability-is-invariant-under-level-regrouping`, `V_8(C)` is finitely presented for the
   level-3 action.
3. `nekrashevych-fp-iff-cycle-germ-groups-fp`, part 1, applied to that action at the family
   `{y_0, y_1}`, then says the germ group at `(100)^ω` is finitely presented.
4. The germ group is a property of the action on the Cantor set and does not depend on the regrouping.
   So it is `H`, which is not finitely presented. This contradicts step 3.

**Proof of part 3.** This is the application in `lift-presentation-passes-to-invariant-subalphabets`,
with `V_2(C)` not finitely presented.

**Case `L ≡ 2 (mod 3)`, part 4.** Here `r + L + 1 ≡ r`. So a γ-phase started at residue 1 or 2 of
`(100)^ω`, or at residue 1 of `(101)^ω`, reads γ-codes forever. Since `K|_γ = K`, the states `(K, x)`
with `x` the matching γ-prefix are loops, and they add germs outside `H`. The computation for `L = 2`
(loops `K_0`, `K_00` at `y_0` and `K_01` at `y_1`) and for `L = 5` (six extra loops, `m = 2`) confirms
this. `results.txt` lists the pairwise commutators for `L = 2`. The structure of `P'` is not determined
here.

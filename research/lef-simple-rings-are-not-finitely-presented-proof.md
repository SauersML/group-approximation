title: A local embedding of the relator ball is an honest homomorphism into a finite ring

Write `R = Z<x_1, ..., x_m> / I`, where `I` is the two-sided ideal generated by
`w_1, ..., w_s`, and let `g_i` be the image of `x_i`.

1. **The ball.** Fix an expression tree for each `w_j`, built from the `x_i`, `0`, `1`, `+`, `-`
   and `·`. Let `F ⊆ R` be the finite set of values at `g = (g_1, ..., g_m)` of all subtrees of
   these trees, together with `0` and `1`.
2. **The local model.** LEF gives a finite unital ring `Q` and an injective partial homomorphism
   `phi : F -> Q`.
3. **Extension to the free ring.** Let `Phi : Z<x_1, ..., x_m> -> Q` be the unital homomorphism
   with `Phi(x_i) = phi(g_i)`. By induction over the trees, `Phi(t) = phi(t(g))` for every subtree
   `t`:
   - at the leaves this is the definition, together with `phi(0) = 0` and `phi(1) = 1`;
   - at an internal node the operands and the result lie in `F`, so `phi` respects the operation.

   Hence `Phi(w_j) = phi(w_j(g)) = phi(0) = 0` for every `j`.
4. **Descent.** `Phi` kills `I`, so it induces a unital homomorphism `Phibar : R -> Q`. Since `R`
   is simple, `0 != 1` in `R`, and injectivity of `phi` on `{0, 1}` gives
   `Phibar(1) = phi(1) != phi(0) = 0`. So `ker Phibar` is a proper two-sided ideal.
5. **Conclusion.** `R` is simple, so `ker Phibar = 0` and `R` embeds in the finite ring `Q`.

For a finitely presented algebra over a finite field `k`, run the same argument with the free
`k`-algebra, trees that may also multiply by scalars, and `k`-linear partial maps. QED

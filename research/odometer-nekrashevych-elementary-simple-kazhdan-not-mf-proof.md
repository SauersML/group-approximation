Details are in `research/artifacts/un-boundary-families-2026-09-13-part2.md`, §2. We check the hypotheses of
`paradoxical-steinberg-elementary-simple-kazhdan-not-mf`.

1. **Pseudo free.** `a^n` fixes a letter iff `n` is even, and `φ(a^(2k), x) = a^k`. So `a^n x = x` with `φ = 1` forces
   `n = 0`.
2. **Hausdorff.** By `exel-pardo-pseudo-free-self-similar-groupoid-hausdorff`, no `g != 1` strongly fixes a path of
   nonzero length. So every `g` has finitely many minimal strongly fixed paths (none for `g != 1`, only the vertex for
   `g = 1`), and `𝒢` is Hausdorff.
3. **Minimal.** With one vertex, `E` is weakly `G`-transitive, so `𝒢` is minimal by the same import.
4. **Effective.** `𝒢` is a groupoid of germs. A germ in the interior of the isotropy is represented by an element
   fixing a neighbourhood pointwise, so it equals a unit germ.
5. **Unit space.** `{0,1}^ℕ` is compact and infinite.
6. **Finitely generated with a full defect.** By `paradoxical-steinberg-families-kazhdan-no-mf-quotient` (F2), the
   algebra is generated by `s_x`, `t_x` and the germ indicators of `a^(±1)`. The `s_x`, `t_x` satisfy the Leavitt
   relations of `L(1,2)`, so `s = s_0` and `t = t_0` give `ts = 1` and `t_1 (1 - s_0 t_0) s_1 = 1`.

The interface theorem gives the statement. For a general pseudo-free one-vertex action with finitely generated `G`
and `|X| >= 2`, steps 2–6 are identical.

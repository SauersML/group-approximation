Complete direct proof.

**Sources for the definitions.** Peterson--Thom, arXiv:0708.4327, Section
`notionsofnormality`, define `wq`-normality by Popa's ascending chains.
Their Lemma `alter`, attributed to Popa, shows that an infinite `H` is
`wq`-normal in `G` if and only if every intermediate subgroup
`H ⊂ K ⊊ G` has some `g in G \ K` with `g K g^(-1) ∩ K` infinite. This is the
definition used here. Their Remark `remark1` states, with no proof, that every
subgroup is `wq`-normal in some almost malnormal subgroup. The argument below
proves that remark. It also adds minimality, uniqueness, infinite index and
the commensurator statement.

**Stabilization.** The chain is increasing. If `W_(beta+1) = W_beta` for some
`beta`, then every later term equals `W_beta`. While the chain has not yet
stabilized, choose `x_beta in W_(beta+1) \ W_beta`. For `beta < beta'` we have
`x_beta in W_(beta') not containing x_(beta')`, so `beta ↦ x_beta` is injective
into the countable set `Gamma`. The chain therefore stabilizes at a countable
ordinal `alpha`, and `W(H) = W_alpha = W_(alpha+1)`.

1. **`H` is wq-normal in `W(H)`.** Let `H <= K < W(H)`, and let `beta` be the
   least ordinal with `W_beta` not contained in `K`. Then `beta != 0`, since
   `W_0 = H <= K`. It is not a limit, since a union of subgroups of `K` lies in
   `K`. So `beta = gamma + 1` with `W_gamma <= K`. `W_(gamma+1)` is generated by
   `W_gamma` and the elements `g` with `g W_gamma g^(-1) ∩ W_gamma` infinite, so
   some such `g` lies outside `K`. Then `g K g^(-1) ∩ K` contains
   `g W_gamma g^(-1) ∩ W_gamma` and is infinite, and `g in W(H) \ K`.
2. **Almost malnormal.** If `g W(H) g^(-1) ∩ W(H)` is infinite, then by
   definition `g in W_(alpha+1) = W(H)`.
3. **Minimality and uniqueness.**
   - Let `M >= H` be almost malnormal. By induction `W_beta <= M` for every
     `beta`. Limits are unions. At a successor step, a generator `g` with
     `g W_beta g^(-1) ∩ W_beta` infinite has `g M g^(-1) ∩ M` infinite, so
     `g in M`.
   - Let `L >= H` with `H` wq-normal in `L`, and put `K = L ∩ W(H)`, so
     `H <= K <= L`. If `K != L`, wq-normality in `L` gives `g in L \ K` with
     `g K g^(-1) ∩ K` infinite. Then `g W(H) g^(-1) ∩ W(H)` is infinite, so
     `g in W(H)` by 2. So `g in K`, a contradiction. Hence `L <= W(H)`.
   - If `W'` has properties 1 and 2, the first bullet gives `W(H) <= W'` and the
     second gives `W' <= W(H)`.
4. **Wq-normal in `Gamma`.** If `W(H) = Gamma`, use 1. If `H` is wq-normal in
   `Gamma`, the second bullet of 3 with `L = Gamma` gives `W(H) = Gamma`.
5. **Infinite index.** Suppose `[Gamma : W(H)]` is finite. Then for every `g`,
   `g W(H) g^(-1) ∩ W(H)` has finite index in `W(H)`, which contains `H` and is
   infinite. So every `g` lies in `W(H)` by 2, and `W(H) = Gamma`.
6. **Commensurator.** Every `g` with `g H g^(-1) ∩ H` infinite is a generator of
   `W_1`. A commensurating element has `g H g^(-1) ∩ H` of finite index in the
   infinite group `H`. A normalizing element has intersection `H`. An element
   centralizing an infinite `S <= H` has intersection containing `S`.

**Consequence.** Assume no infinite amenable subgroup of `Gamma` is wq-normal.
If `Gamma` has no infinite amenable subgroup, then it has no element of infinite
order, since such an element generates `Z`. Otherwise, let `H` be infinite
amenable. `H` is not wq-normal, so `W(H) != Gamma` by 4, and 2, 5 and 6 apply.

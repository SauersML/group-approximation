Notation is that of the target claim. `F_t = F(S ∪ {t})`, and `ε : F_t → Z` sends `t ↦ 1`,
`s ↦ 0`.

## 0. Standard facts

- **(L0)** A finitely generated marked group `(G, X)` is LEF if and only if it is a limit, in
  the space of marked groups, of finite marked groups `(E_i, X)`. (Vershik--Gordon; this is the
  marked-group form of the local-embedding definition.)
- **(L1)** Limits of LEF marked groups are LEF. A limit of limits of finite groups is a limit of
  finite groups, by a diagonal argument on the countable set of words, using (L0).
- **(L2)** A finitely generated residually finite group is LEF. Given a finite ball `A`, one
  finite quotient avoids the finitely many nontrivial elements of `A^-1 A`, and it is then
  injective and multiplicative on `A`.

Convergence of `(H_i, X)` to `(H, X)` means: for every word `u` over `X`, eventually
`u = 1` in `H_i` exactly when `u = 1` in `H`.

## 1. Rewriting to the kernel

Let `Φ, Ψ : F → F` be the endomorphisms `s ↦ w_s` and `s ↦ v_s`. Put `Θ_m = Φ^m` for `m ≥ 0`
and `Θ_m = Ψ^(-m)` for `m < 0`. Write a word `u ∈ F_t` as

```text
u = a_0 t^(e_1) a_1 t^(e_2) a_2 ... t^(e_n) a_n,      a_j ∈ F,
```

let `m_j = e_1 + ... + e_j`, and define the word

```text
ρ(u) = a_0 Θ_(m_1)(a_1) Θ_(m_2)(a_2) ... Θ_(m_n)(a_n) ∈ F.
```

**(R)** Let `Y` be any group generated by the image of `S ∪ {t}` in which

```text
t s t^-1 = w_s   and   t^-1 s t = v_s      for all s ∈ S          (Rel)
```

hold. Then `u = ρ(u) t^(ε(u))` in `Y` for every `u ∈ F_t`.

*Proof.* By (Rel), conjugation by `t` sends `s` to `w_s = Φ(s)`, so `t a t^-1 = Φ(a)` for every
`a ∈ F`, and `t^-1 a t = Ψ(a)` likewise. Hence `t^m a t^-m = Θ_m(a)`. Insert
`t^(-m_j) t^(m_j)` between consecutive blocks and collect: `u = Π_j (t^(m_j) a_j t^(-m_j)) · t^(m_n)`,
and `m_n = ε(u)`. ∎

The word `ρ(u)` depends only on `u`, not on `Y`. Relations (Rel) hold in `G`.

## 2. (c) ⇒ (a)

Let `π_i : F → H_i` and `α_i` be as in (c). Put `G_i = H_i ⋊_(α_i) Z`, marked by `S ∪ {t}` with
`t h t^-1 = α_i(h)`.

1. **Stage tori are LEF.** `H_i` is finitely generated and residually finite, so `G_i` is
   residually finite by `finitely-generated-rf-automorphism-mapping-torus-is-rf`, hence LEF by (L2).
2. **(Rel) holds in `G_i` for large `i`.** First, `t s t^-1 = α_i(π_i s) = π_i(w_s)` by the
   stage-lift condition. Second, `α_i ∘ π_i` and `π_i ∘ Φ` are homomorphisms `F → H_i` that agree
   on `S`, so `α_i(π_i v_s) = π_i(Φ(v_s))`. The word `Φ(v_s) s^-1` is trivial in `K`, because it
   represents `φ(φ^-1(s)) s^-1`. There are finitely many such words, so by convergence there is `i_0`
   with `π_i(Φ(v_s)) = π_i(s)` for all `s` and all `i ≥ i_0`. Then `α_i(π_i v_s) = π_i s`, that is,
   `t^-1 s t = π_i(v_s)` in `G_i`.
3. **Word problem in both tori.** In `G = K ⋊ Z` and in `G_i = H_i ⋊ Z`, every element is uniquely
   `k t^e` with `k` in the kernel. By (R), for `i ≥ i_0`:
   - `u = 1` in `G` iff `ε(u) = 0` and `ρ(u) = 1` in `K`;
   - `u = 1` in `G_i` iff `ε(u) = 0` and `π_i(ρ(u)) = 1` in `H_i`.
4. **Convergence.** Fix `u`. The word `ρ(u) ∈ F` is fixed, so eventually `π_i(ρ(u)) = 1` iff
   `ρ(u) = 1` in `K`. By step 3, eventually `u = 1` in `G_i` iff `u = 1` in `G`. So
   `(G_i, S ∪ {t}) → (G, S ∪ {t})`.
5. By (L1), `G` is LEF. ∎

## 3. (a) ⇒ (b)

By (L0), take finite marked groups `π̂_i : F_t → E_i` with `(E_i, S ∪ {t}) → (G, S ∪ {t})`.

1. **Add the height.** In `E_i × Z` put `σ_i(s) = (π̂_i s, 0)` and `τ_i = (π̂_i t, 1)`, and let
   `W_i = ⟨σ_i(S), τ_i⟩`. Thus `u ↦ (π̂_i u, ε(u))` maps `F_t` onto `W_i`.
2. **The finite kernel.** Let `F_i = W_i ∩ (E_i × {0})`, the kernel of the height map
   `W_i → Z`. It is finite, since `E_i` is finite, and normal in `W_i`.
3. **It is generated by `S`.** Let `B_i = ⟨σ_i(S)⟩ ≤ F_i`. The finitely many relators
   `t s t^-1 w_s^-1` and `t^-1 s t v_s^-1` are trivial in `G` and have height `0`. So for
   `i ≥ i_0` they are trivial in `E_i`, hence in `W_i`. Then
   `τ_i σ_i(s) τ_i^-1 = σ_i(w_s) ∈ B_i` and `τ_i^-1 σ_i(s) τ_i = σ_i(v_s) ∈ B_i`.
   So `B_i` is normalized by `τ_i` and by `σ_i(S)`, hence normal in `W_i`. The quotient
   `W_i / B_i` is generated by the image of `τ_i`, and the height map is injective on it, so
   `W_i = B_i ⋊ ⟨τ_i⟩` and `F_i = B_i`.
4. **The stage lift.** Mark `F_i` by `π_i = σ_i|_F : F → F_i`, which is onto by step 3. Put
   `α_i = Ad(τ_i)|_(F_i)`. This is an automorphism of `F_i`, since `F_i` is normal in `W_i`, and
   `α_i(π_i s) = σ_i(w_s) = π_i(w_s)` by step 3.
5. **Convergence.** For `a ∈ F`: `π_i(a) = 1` iff `π̂_i(a) = 1` in `E_i`, and `a = 1` in `K`
   iff `a = 1` in `G`, since `K ≤ G`. Eventually `π̂_i(a) = 1` iff `a = 1` in `G`. So
   `(F_i, S) → (K, S)` along `i ≥ i_0`. ∎

**(b) ⇒ (c)** holds because finite groups are finitely generated and residually finite.

The stage lift produced in section 3 is inner in `W_i` but need not be inner in `F_i`, and no bound
on its outer order is claimed.

## 4. MF consequence

If `G` is LEF, then `G` is operator MF by `lef-implies-operator-mf`. So the intersection of
kernels of homomorphisms to MF groups is `Rad_MF(G) = 1`. For `K ≠ 1` this contradicts (LK3),
which asks for `Rad_MF(G) = K × {0}`.

## Checked against

- **Why only two relator families.** A general marked limit `G_i → G` need not preserve the
  semidirect structure. Section 2 needs only (Rel) and the split projection to `Z`. Both are finite
  conditions, or built into `G_i`.
- **Non-residually-finite kernel.** `K` itself is never assumed residually finite. The residual
  finiteness in (c) is used stagewise only.

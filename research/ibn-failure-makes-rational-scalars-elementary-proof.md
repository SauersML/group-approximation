Throughout, `Q ⊆ Z(R)` (part 1 of `q-algebra-elementary-quotients-contain-gl-n-q`).
Commutators are `[x,y] = xyx^-1y^-1`.

**Step 0: reduction to `m = 1`.**
- Let `m' >= m`. Adding `R^(m'-m)` gives `R^(m') ≅ R^(m'+k)`, and by induction
  `R^(m') ≅ R^(m'+tk)` for all `t >= 0`. With `t = m'`, `R^(m') ≅ R^(m'(k+1))`.
- So `S = M_(m')(R)` satisfies `S ≅ S^(k+1)` as right `S`-modules: under the Morita
  equivalence, `S^j` corresponds to `R^(m'j)`.
- `Q` sits in `S` as central scalar matrices. By part 5 of
  `q-algebra-elementary-quotients-contain-gl-n-q`, `E_N(S) = E_(m'N)(R)` for `N >= 2`,
  and `λI_N` over `S` is `λI_(m'N)` over `R`.

So part 1 follows from part 3 with `d = k+1`, applied to `S`. Part 2 then follows from
`rational-scalars-obstruct-fp-elementary-hosts`, part 2. Indeed `(Q^x)^k` is not
finitely generated, since the `k`-th powers of distinct primes are independent.

It remains to prove part 3. Let `S ⊇ Q` with `S ≅ S^d`, `d >= 2`.

**Step 1: the Leavitt family and codes.**
- An isomorphism `S^d -> S` and its inverse are a row `(s_1..s_d)` and a column
  `(t_1..t_d)` with `t_i s_j = δ_ij` and `Σ s_i t_i = 1`.
- For a word `w = w_1..w_r` over `{1..d}`, put `s_w = s_(w_1)..s_(w_r)`,
  `t_w = t_(w_r)..t_(w_1)` and `p_w = s_w t_w`, an idempotent.
- If `u`, `v` are incomparable (neither a prefix of the other), then `t_u s_v = 0`.
- For a finite complete prefix code `π`, `Σ_(u∈π) p_u = 1`, and
  `Φ_π(X) = Σ_(u,v∈π) s_u X_uv t_v` is a unital ring isomorphism `M_|π|(S) -> S` with
  `Φ_π(λI) = λ·1` for `λ ∈ Q`.
- Every finite set of pairwise incomparable words extends to a complete code: add the
  words of the maximal length that extend none of them.

Let `L` be the `Q`-span of all `s_u t_v`. It is a subring containing `Q` and every
`s_i`, `t_i`.

**Step 2: one group `G` for all codes.** Put `G_π = Φ_π(E_|π|(L))` for complete codes
with `|π| >= 2`.
- Let `π'` refine `π` by splitting a leaf `u` into `u1..ud`. Then
  `s_x y t_u = Σ_i s_x (y s_i) t_(ui)` and `s_u y t_x = Σ_i s_(ui) (t_i y) t_x`. So each
  coarse elementary unit `1 + s_x y t_u` is a commuting product of fine ones, and
  `G_π ⊆ G_π'`.
- Conversely, let `1 + s_x y t_z` be fine elementary.
  - If `x` and `z` lie under different coarse leaves, `x = a x'` and `z = b z'`, it
    equals `1 + s_a (s_(x') y t_(z')) t_b`, which is coarse elementary.
  - If both lie under one coarse leaf, pick a fine leaf `w` under another coarse leaf
    (`|π| >= 2`). Then `1 + s_x y t_z = [1 + s_x y t_w, 1 + s_w t_z]`, a commutator of
    two coarse elementary units.
- Any two codes have a common refinement. So all `G_π` equal one group `G ≅ E_|π|(L)`.

**Step 3: 3-cycles lie in `G`.** For pairwise incomparable words `a, b, c`, put
`σ = s_b t_a + s_c t_b + s_a t_c + (1 - p_a - p_b - p_c)`.
- Extend `{a, b, c}` to a complete code `π`. Then `σ = Φ_π(P)` for a 3-cycle
  permutation matrix `P ∈ SL_|π|(Z) = E_|π|(Z)`, so `σ ∈ G`.
- Since `σ s_a = s_b` and `t_a σ^-1 = t_b`, we get `σ p_a σ^-1 = p_b`.

**Step 4: diagonal units normalize `G`.** For a word `a` and `λ ∈ Q^x`, put
`d_a(λ) = 1 + (λ - 1) p_a`, a unit with inverse `d_a(λ^-1)`.
- Take a complete code `π` containing `a` with `|π| >= 2`. Then `d_a(λ) = Φ_π(D)` for a
  diagonal `D` with entries in `Q^x`.
- `D e_uv(y) D^-1 = e_uv(D_u y D_v^-1)` with `D_u y D_v^-1 ∈ L`. So `d_a(λ)` normalizes
  `G`.
- Let `Ĝ` be generated by `G` and all `d_a(λ)`. Then `G` is normal in `Ĝ`.

**Step 5: one image for all proper cones.** Fix `λ`. We show that for nonempty words
`a`, the images of `d_a(λ)` in `Ĝ/G` coincide.
- The cones `a` and `11` never cover all infinite words: a cone containing the cones
  `12` and `2` is the whole space.
- So the complement contains disjoint cones `c`, `c'`, both incomparable to `a` and to
  `11`.
- By Step 3, `d_a(λ)`, `d_c(λ)`, `d_(11)(λ)` are conjugate in `G`: use the 3-cycles
  `(a, c, c')` and `(c, 11, c')`.

**Step 6: absorption.** `p_a = Σ_i p_(ai)` with orthogonal summands, and `λ` is central.
So `d_a(λ) = d_(a1)(λ) .. d_(ad)(λ)`.
- For nonempty `a`, write `κ` for the common image. Then `κ = κ^d`, so `κ^(d-1) = 1`,
  and `d_a(λ^(d-1)) = d_a(λ)^(d-1) ∈ G`.
- With `a` running over the one-letter words, `λ^(d-1)·1 = d_1(λ^(d-1)) .. d_d(λ^(d-1))`
  lies in `G`.

**Step 7: all ranks.**
- For the code `π = {1..d}`, `Φ_π^-1(λ^(d-1)·1) = λ^(d-1) I_d ∈ E_d(L) ⊆ E_d(S)`.
- For `N >= 2`, `Φ_π^-1` induces `E_N(S) ≅ E_N(M_d(S)) = E_(dN)(S)` (part 5 of
  `q-algebra-elementary-quotients-contain-gl-n-q`), sending `λ^(d-1) I_N` to
  `λ^(d-1) I_(dN)`.
- The latter is block diagonal with `N` blocks `λ^(d-1) I_d ∈ E_d(S)`, so it lies in
  `E_(dN)(S)`. Hence `λ^(d-1) I_N ∈ E_N(S)`. ∎

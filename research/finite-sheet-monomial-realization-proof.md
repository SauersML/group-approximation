Rank balance makes all coordinate sets in a connected component have the
same cardinality.  Arbitrary identifications with `[D]` turn each Boolean
coordinate into the diagonal sign `(FST3)` and each given edge bijection into
a permutation matrix.  Preservation of the shared sign is exactly the
matrix covariance `(FST4)`.  Since every basis vector at a context is labelled
by an allowed assignment, its forbidden joint spectral projections vanish.
This proves the exact model `(FST3)--(FST5)`.

Tree trivialization writes every chord return as a permutation of the root
fiber, proving `(FST6)`.  The subgroup generated by finitely many
permutations of a finite set is finite.  The relations in `(FST7)` simply
identify basis generators lying in the same `H`-orbit; choosing one generator
per orbit proves that the quotient is free.  The same argument applies to
the disjoint union of every local atom set before root identification.

Diagonal finite-order phase lifts normalize the diagonal sign group, so the
enlarged group remains a finite subgroup of a roots-of-unity monomial group.
Finally, literal equality of every transported shared sign removes the edge
unitaries from the semantics and leaves one finite tuple satisfying all BCS
contexts.  The cited no-CE coherence theorem excludes this second branch for
the target BCS and proves the dichotomy.

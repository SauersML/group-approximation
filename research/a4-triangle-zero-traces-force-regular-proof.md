The presentation

```text
<a,b | a^3=b^2=(ba)^3=1>
```

is the spherical triangle group `(3,2,3)`, hence `A4`.  Its irreducible complex
representations have dimensions

```text
1, 1, 1, 3.
```

Write their multiplicities in the representation generated by `A,B` as
`m0,m1,m2,m3`.  On either nontrivial conjugacy class of order-three elements,
the three one-dimensional characters take the values `1,omega,omega^2` in some
order and the three-dimensional character is zero.  Therefore

```text
0 = tr(A) = m0 + omega m1 + omega^2 m2.
```

Since the `m_i` are real nonnegative integers, the real and imaginary parts give

```text
m0=m1=m2=:t.
```

Every order-two element of `A4` is a double transposition.  The three
one-dimensional characters all take value `1` there, while the
three-dimensional character takes value `-1`.  Hence

```text
0 = tr(B) = m0+m1+m2-m3 = 3t-m3,
```

so `m3=3t`.

But the regular representation decomposes with multiplicity equal to dimension:

```text
Reg(A4) = 1 + chi + chi_bar + 3 rho_3.
```

Thus the given representation is exactly `t Reg(A4)`.

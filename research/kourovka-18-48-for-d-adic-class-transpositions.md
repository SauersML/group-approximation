## The problem

Kourovka Notebook, 21st issue (arXiv:1401.0300v46), Problem 18.48 (S. Kohl), verbatim from the TeX:

> Is it true that there are only finitely many integers which occur as orders of products of two
> class transpositions? (For the definition, see 17.57.)

Here `τ_{r1(m1),r2(m2)}`, for disjoint residue classes `r1(m1)`, `r2(m2)` with `0 ≤ ri < mi`, maps
`r1 + k·m1 ↦ r2 + k·m2` and back, and fixes everything else.

## What is known (read as arXiv abstracts and HTML pages, not quoted verbatim)

- **Horizontal case** (`m1 = m2` and `m3 = m4`): Bardakov–Iskra, arXiv:2409.13341. The orders are
  exactly `{1, 2, 3, 4, 6, 12}`; for example `τ_{0(3),1(3)}·τ_{0(4),2(4)}` has order 12.
- **Slanted cases**: Bardakov–Iskra, arXiv:2504.08595.
  - A common class gives `{1, 3, ∞}`.
  - Equal residues with `m1/m2 ≠ m3/m4` give `∞`.
  - Equal moduli under conditions on the residues give `{1, 2, 3, 6, ∞}`.
  - They state that the remaining equal-residue and equal-modulus cases are open.
- Pan, arXiv:2604.12553, on the group generated by horizontal class transpositions.

## Statement

Let `d ≥ 2`, and let `τ1 = τ_{r1(m1),r2(m2)}` and `τ2 = τ_{r3(m3),r4(m4)}` be class transpositions
whose four moduli are powers of `d`. Then

    ord(τ1·τ2) ∈ {1, 2, 3, 4, 6, ∞},

and each of these six values occurs (already for `d = 2`). In particular 12, which occurs in the
horizontal case, needs moduli that are not powers of a common integer (3 and 4 in the example above).
The same holds for two cylinder-swap involutions in a Higman–Thompson group `V_{d}` acting on `X^ω`.

## Dictionary: d-adic classes are cylinders

Let `X = {0, …, d−1}`. The class `r(d^e)` with `0 ≤ r < d^e` corresponds to the word
`w(r) = r_0 r_1 … r_{e−1}` of the first `e` base-`d` digits of `r`, least significant first.
Every integer, indeed every element of `Z_d = lim Z/d^e`, has an infinite digit sequence, and
`x ∈ r(d^e)` iff that sequence begins with `w(r)`. So:
- two such classes are disjoint iff their words are incomparable (neither is a prefix of the other);
- they are nested iff one word is a prefix of the other.

`τ_{r(d^e),s(d^f)}` sends `r + d^e z ↦ s + d^f z`, i.e. `w(r)·ζ ↦ w(s)·ζ` on digit sequences. So it is
the cylinder swap `(w(r) w(s))` on `X^ω`. `Z` is dense in `X^ω` and these maps are homeomorphisms,
so the order of `τ1·τ2` on `Z` equals its order on `X^ω`.

## Orbit graph

Let `a = (u v)` and `b = (x y)` be cylinder swaps on `X^ω`, with `u ⊥ v` and `x ⊥ y` (incomparable).
Write `[w]` for the cylinder of `w`, and `w ≤ w'` for "w is a prefix of w'". The orbit graph `Γ`
has vertex set `X^ω`, an `a`-edge `{ξ, aξ}` for `ξ ∈ [u] ∪ [v]` and a `b`-edge `{ξ, bξ}` for
`ξ ∈ [x] ∪ [y]`. Each vertex has at most one edge of each label. So the components are paths and
cycles with alternating labels.
- On a path with `s` vertices, `ab = a∘b` acts as an `s`-cycle.
- On a cycle with `2c` vertices, it acts as two `c`-cycles.

If `ab` has finite order `N`, every component is finite with at most `2N` vertices, and
`ord(ab) = lcm` over components of `s`, respectively `c`.

## Lemma 1 (no five-chains)

If `Γ` contains five distinct vertices `v0 –a– v1 –b– v2 –a– v3 –b– v4`, or the same with the labels
exchanged, then `ab` has infinite order.

*Proof.* Renaming `u ↔ v` and `x ↔ y`, assume `v1 ∈ [v] ∩ [x]`. Then `v0 = a v1 ∈ [u]`,
`v2 = b v1 ∈ [y]`, and `v`, `x` are comparable.

**Case A: `v2 ∈ [v]`.** Then `[v]` meets both `[x]` and `[y]`. If `x ≤ v` then `[v] ⊆ [x]`, which
misses `[y]`; so `x = v x'`, and likewise `y = v y'`, with `x'`, `y'` nonempty. Hence
`[x] ∪ [y] ⊆ [v]`. So `v3 = a v2 ∈ [u]` has no `b`-edge, contradicting `v3 –b– v4`.

**Case B: `v2 ∈ [u]`.** Then `y`, `u` are comparable, and `v3 = a v2 ∈ [v]` lies in `[x] ∪ [y]`.
- **B1: `v3 ∈ [y]`.** As in Case A, `[y] ⊆ [v]`, contradicting `v2 ∈ [u] ∩ [y]`.
- **B2: `v3 ∈ [x]`.** There are four subcases, by how `x` compares with `v` and `y` with `u`. In each,
  `ab` has an infinite orbit or orbits of unbounded size, so it has infinite order.
  - **(a) `x ≤ v`, `y ≤ u`.** Write `v = x v'` and `u = y u'`. For `ξ = vθ = x v'θ`, `bξ = y v'θ`. This
    lies in `[u] = [y u']` iff `v'θ ∈ [u']`, and then `(ab)ξ = vψ` with `v'θ = u'ψ`.
    - The chain is such a step with `v3 ≠ v1`. If `|u'| = |v'|` this forces `u' = v'` and `ψ = θ`,
      so `v3 = v1`, which is excluded.
    - If `|u'| < |v'|`, then `v' = u'w` with `w` nonempty, and `(ab)(vθ) = v wθ` for every `θ`. So
      `(ab)^k(vθ) = v w^k θ`, and these points are pairwise distinct unless `θ = w^∞`.
    - If `|u'| > |v'|`, then `u' = v'w` with `w` nonempty, and `(ab)(v wθ) = vθ`. So the point
      `v w^k η`, with `η ∉ [w]`, has an `ab`-orbit of at least `k+1` points.
  - **(b) `x ≤ v`, `u < y`.** Write `v = x v'` and `y = u y'` with `y'` nonempty. For `ξ = vθ`,
    `bξ = u y'v'θ ∈ [u]`, and `(ab)ξ = v y'v'θ`. So `(ab)^k(vθ) = v (y'v')^k θ`, an infinite orbit.
  - **(c) `v < x`, `y ≤ u`.** Write `x = v x'` with `x'` nonempty, and `u = y u'`. For
    `ξ = x u'x'θ`: `bξ = y u'x'θ = u x'θ`, and `(ab)ξ = v x'θ = xθ`. So `x (u'x')^k η`, with
    `η ∉ [u'x']`, has an `ab`-orbit of at least `k+1` points.
  - **(d) `v < x`, `u < y`.** Write `x = v x'` and `y = u y'` with `x'`, `y'` nonempty. For
    `ξ = xθ = v x'θ`: `bξ = u y'θ ∈ [u]`, and `(ab)ξ = v y'θ`, which lies in `[x]` iff
    `y'θ ∈ [x']`.
    - If `|x'| = |y'|`, the chain forces `x' = y'` and `v3 = v1`, which is excluded.
    - If `|x'| < |y'|`, then `y' = x'w`, and `(ab)(xθ) = x wθ` for every `θ`: an infinite orbit.
    - If `|x'| > |y'|`, then `x' = y'w`, and `(ab)(x wθ) = xθ`: the orbits of the points `x w^k η`
      are unbounded.

Exchanging the roles of `a` and `b` treats chains that start with a `b`-edge. ∎

## Lemma 2 (a four-path excludes a three-path)

Suppose `Γ` has a path component `v0 –a– v1 –b– v2 –a– v3` with four vertices. Then
`[x] ∪ [y] ⊆ [u] ∪ [v]`. If the labels are exchanged, then `[u] ∪ [v] ⊆ [x] ∪ [y]`. Either way `Γ`
has no path component with exactly three vertices.

*Proof.* As before, assume `v1 ∈ [v] ∩ [x]`, so `v2 ∈ [y]`.
- If `v2 ∈ [v]`, Case A gives `[x] ∪ [y] ⊆ [v]`.
- Otherwise `v2 ∈ [u]` and `v3 ∈ [v]`, and the ends `v0 ∈ [u]` and `v3` have no `b`-edge.
  - In subcases (a) and (b), `[v] ⊆ [x]`, so `v3` would have a `b`-edge.
  - In (c), `[u] ⊆ [y]`, so `v0` would have one.
  - So (d) holds: `[x] ⊆ [v]` and `[y] ⊆ [u]`.

A three-vertex path `w0 – w1 – w2` has ends carrying one label each. So one end lies in
`([u]∪[v]) ∖ ([x]∪[y])` and the other in `([x]∪[y]) ∖ ([u]∪[v])`. Hence neither union contains the
other, which contradicts the inclusion just proved. ∎

## Proof of the statement

Suppose `ab` has finite order. A path component with at least five vertices contains five distinct
consecutive vertices, and so does a cycle component with at least six. Both are excluded by
Lemma 1. So every path component has `s ≤ 4` vertices, and every cycle has `2c ∈ {2, 4}` vertices.
Hence `ord(ab)` is an lcm of numbers in `{1, 2, 3, 4}`, i.e. one of `1, 2, 3, 4, 6, 12`.
- A factor 4 needs a path component with four vertices, since cycles give `c ≤ 2`.
- A factor 3 needs one with three vertices.
Lemma 2 forbids both at once, so `12` does not occur. ∎

## Examples (d = 2)

- **Order 1:** `τ1 = τ2`.
- **Order 2:** `τ_{0(4),1(4)}·τ_{2(4),3(4)}`. The supports are disjoint and the two maps commute.
- **Order 3:** `τ_{0(2),1(4)}·τ_{0(2),3(4)}`. Every orbit is `{2k, 4k+1, 4k+3}`, which is the path
  `4k+1 –a– 2k –b– 4k+3`.
- **Order 4:** `τ_{0(2),1(2)}·τ_{1(4),3(4)}`. The orbits are the paths
  `4k –a– 4k+1 –b– 4k+3 –a– 4k+2`.
- **Order 6:** `τ_{0(2),1(4)}·τ_{3(4),1(8)}`. The orbits are:
  - for even `k`, the three-point path `2k –a– 4k+1 –b– 2k+3`, since `4k+1 ≡ 1 (mod 8)`;
  - for odd `k`, the two-point path `{2k, 4k+1}`.
  Every integer lies in exactly one of these.
- **Infinite order:** `τ_{0(2),1(4)}·τ_{1(2),0(4)}`. The orbit of 2 is
  `2 → 5 → 8 → 17 → 32 → 65 → …`, which is unbounded.

## Remarks

- **What the proof uses.** Only two facts: the four cylinders are pairwise nested or disjoint, and
  the swaps are prefix replacements that keep the tail. Both fail for mixed moduli: `0(3) ∩ 0(4)`
  is `0(12)`, not one of the two. The horizontal order-12 example has both a three-point path and a
  four-point path, which is exactly what Lemma 2 rules out in the tree case.
- **The general case is genuinely different.** Bardakov–Iskra (arXiv:2504.08595, Introduction) quote
  S. Kohl's computations. Products of two class transpositions can have any order in

      {1, 2, 3, 4, 6, 8, 10, 12, 15, 20, 24, 30, 40, 42, 60, 84, 120, 168, 420},

  and all of these divide 840. So Lemma 1 fails for mixed moduli: longer finite paths and cycles occur.
  The tree theorem above is exactly the part where it survives.
- **Open question (Kourovka 18.48 proper).** Is the set of finite orders exactly the divisors of 840
  that occur above, or some other finite set, or is it unbounded? A proof would have to replace the
  prefix comparisons of Lemma 1 by comparisons of paths of incomparable degree in the one-vertex
  k-graph of `ct-p-z-is-a-one-vertex-k-graph-full-group`.
- **Correction (09-19).** An earlier version of this node conjectured that the general set is
  `{1, 2, 3, 4, 6, 12}`. That is false by Kohl's data above; referee bh-ref-c pointed this out
  (6a7953752c).

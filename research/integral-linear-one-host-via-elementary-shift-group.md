If `Σ = E(Z) ⋊ Z` embeds in a finitely presented simple group `S`, then so does every
`GL_n(Z)`, since `GL_n(Z) ≤ Σ` (item 2 of the required node). `Σ` is finitely generated
with solvable word problem (item 1), so this is one instance of `boone-higman-conjecture`. ∎

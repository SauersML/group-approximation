## Inputs

- (W) `permutational-boone-higman-closed-under-wreath-products`: the iterated
  wreath products `W_k` of `Z` lie in `B_A`, so each embeds in a finitely
  presented simple group. Its special cases list "Iterated wreath products such
  as `Z wr (Z wr (Z wr Z))`".
- (Cav) `recursive-amenable-classes-have-uniform-folner-bounds`, Cavaleri's
  Corollary 3.6, verbatim: "For every recursively enumerable class C of
  finitely generated recursive presentations of amenable groups there exists a
  recursive function U_C such that for every P_i ∈ C: F_(Γ_i,X_i) ≤ U_C
  eventually." Its Følner sets use the same convention as here.
- (T) `iterated-wreath-products-of-z-have-tower-folner-functions`:
  `F_(W_(k+2))` is not `≼ exp_k`.
- (D2) `decidable-amenable-groups-have-no-recursive-folner-bound`: for every
  recursive non-decreasing `U` there is a finitely generated elementary amenable
  `Δ_U` with solvable word problem and `F_(Δ_U) ⋠ U`.

## Lemma 0. Følner bounds pass to finitely generated subgroups

Let `G` be amenable, generated by a finite set `X`, and let `H ≤ G` be
generated by a finite set `Y`. Let `L` be the largest `X`-word length of an
element of `Y`. Then

```text
F_(H,Y)(n)  <=  F_(G,X)(L |Y| n)      for all n.
```

*Proof.*
- *Subadditivity.* `Ω \ xyΩ ⊆ (Ω \ xΩ) ∪ x(Ω \ yΩ)`, so
  `|Ω \ xyΩ| <= |Ω \ xΩ| + |Ω \ yΩ|`.
- *Inverses.* `|Ω \ x^(-1)Ω| = |xΩ \ Ω| = |Ω \ xΩ|`, because `|xΩ| = |Ω|`.
- So if `Ω` is `(L|Y|n)`-Følner for `X`, then
  `|Ω \ yΩ| <= L|Ω|/(L|Y|n) = |Ω|/(|Y|n)` for every `y in Y`.
- *Coset splitting.* Left multiplication by `H` preserves each right coset
  `Hc`. Put `Ω_c = Ω ∩ Hc`. Then `Ω_c \ yΩ_c = (Ω \ yΩ) ∩ Hc`, so
  `Σ_c Σ_y |Ω_c \ yΩ_c| = Σ_y |Ω \ yΩ| <= |Ω|/n = Σ_c |Ω_c|/n`.
- Some `c` with `Ω_c` nonempty therefore has
  `Σ_y |Ω_c \ yΩ_c| <= |Ω_c|/n`. Then `Ω_c c^(-1) ⊂ H` is `n`-Følner for `Y`,
  since right multiplication commutes with left translation. It has size at
  most `|Ω|`. `∎`

So `F_H ≼ F_G`, with constant `L|Y|`.

## Item 1. Hereditary and faithful

- A finitely generated amenable subgroup of a subgroup `K ≤ G` is one of `G`,
  and isomorphisms preserve `≼`-classes. So `P_U` is closed under isomorphism
  and subgroups.
- If `G` is finitely generated and amenable and `G ∈ P_U`, take `H = G`.
- Conversely, if `F_G ≼ U`, then every finitely generated `H ≤ G` is amenable
  and satisfies `F_H ≼ F_G ≼ U` by Lemma 0. The relation `≼` is transitive:
  `f(n) <= C g(Cn)` and `g(m) <= D U(Dm)` give `f(n) <= CD U(CDn)`.

## Item 2. Criterion

**(S2) for `P_U` is equivalent to (S2_U).**
- (⇐) The group in (S2_U) is finitely generated, has solvable word problem, and
  lies outside `P_U` by item 1.
- (⇒) Let `G` have solvable word problem, with `G ∉ P_U`. Then some finitely
  generated amenable `H ≤ G` has `F_H ⋠ U`. A finitely generated subgroup of a
  group with solvable word problem has solvable word problem: rewrite each
  generator of `H` as a fixed word in the generators of `G`.

(S1) for `P_U` is (S1_U) by definition.

If `U` is recursive, then (D2) gives (S2_U) with the witness `Δ_U`.

## Item 3. Tower kill

Let `U ≼ exp_k`.
- By (W), `W_(k+2)` embeds in some finitely presented simple group `S`.
- `W_(k+2)` is finitely generated and elementary amenable.
- If `F_(W_(k+2)) ≼ U`, transitivity would give `F_(W_(k+2)) ≼ exp_k`,
  contradicting (T).
- So `S ∉ P_U`, and (S1_U) fails.

## Item 4. Uniform-family kill

Let `e -> (S_e, Y_e)` be a certified family, and let `Y_e` have `r_e` entries.
- The subgroup `H_e = <Y_e>` has the presentation `P_e`, with generators
  `z_1, ..., z_(r_e)` and relators all words `w(z)` such that `w(Y_e) = 1` in
  `S_e`.
- This relator set is recursively enumerable, uniformly in `e`: enumerate the
  consequences of the relators of `S_e`, and keep those that are words in
  `Y_e`. So `P_e` is a finitely generated recursive presentation, in the usual
  sense of a recursively enumerable relator set, and `e -> P_e` is computable.
- So `C = {P_e}` is a recursively enumerable class of finitely generated
  recursive presentations of amenable groups.
- (Cav) gives a recursive `U_C` and, for each `e`, some `n_e` with
  `F_(H_e, z)(n) <= U_C(n)` for `n >= n_e`.
- Let `U_*(n) = 1 + max_(m<=n) U_C(m)`, which is recursive and non-decreasing,
  and let `M_e = max(1, max_(m<n_e) F_(H_e,z)(m))`. Then
  `F_(H_e,z)(n) <= M_e U_*(n)` for all `n`, so `F_(H_e) ≼ U_*`.

For a general recursively enumerable class of recursive presentations of
amenable groups, the same last two steps apply directly.

The towers form such a class. `W_k` has solvable word problem uniformly in `k`,
since the normal form in `L wr A` is computed recursively from normal forms in
`A` and `L`. So its recursive presentation is computable from `k`, and one
`U_*` bounds every `F_(W_k)`, whatever finitely presented simple groups they
sit in.

## Item 5. Conditional

- Assume Boone--Higman: every finitely generated group with solvable word
  problem embeds in a finitely presented simple group.
- Let `U` be recursive. Replace it by its running maximum `U'`, which is
  recursive, non-decreasing and `>= U`.
- `Δ_(U')` from (D2) embeds in a finitely presented simple group `S`. It is a
  finitely generated amenable subgroup of `S` with `F ⋠ U'`, hence `F ⋠ U`,
  since `F ≼ U ≤ U'` would give `F ≼ U'`.
- So E holds. The contrapositive is the second sentence of item 5.
- Now let `U` satisfy (S1_U). Each `W_k` sits in a finitely presented simple
  group by (W), so `F_(W_k) ≼ U`.
- If `U ≼ exp_j` for some `j`, then `F_(W_(j+2)) ≼ exp_j`, contradicting (T).
  `∎`

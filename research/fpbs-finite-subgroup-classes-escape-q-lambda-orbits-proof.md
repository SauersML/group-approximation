1. **`Q(Lambda)` is empty.** `I(gamma) ⊆ Lambda`, which is finite, so no `I(gamma)` is infinite.
2. **Orbits are points.** The subgroup generated by the empty set is `{e}`, so `<Q(Lambda)> x = {x}`.
3. **Classes are large.** By freeness `lambda -> lambda x` is injective, so the `E_{a|Lambda}`-class `Lambda x` has
   `|Lambda| >= 2` points.
4. **Components contain classes.** The vertices of the infinite-contact class graph are `S`-classes, and for
   `S = E_{a|Lambda}` the vertex through `x` is `Lambda x`. So its component, as a set of points, contains
   `Lambda x`, which is not contained in `{x}`.

This is the referee counterexample from the audit of `fpbs-malnormal-subgroup-relations-finite-contacts` (lens 1,
2026-09-17).

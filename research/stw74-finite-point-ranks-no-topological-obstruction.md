Let `X` be a connected compact Hausdorff space, let `x_1,...,x_t` be distinct
points, and let `e_i in M_N(C)` be projections of ranks `r_i>=1`.  Put

```text
D(X;x,r)={f in C(X,M_N):f(x_i) in C e_i for every i},
L=lcm(r_1,...,r_t),
m_0=max_i L/r_i=L/min_i r_i.
```

Then, for every `k>=1`,

```text
M_k(D(X;x,r)) contains a nonzero projection  iff  k>=m_0.   (FP)
```

There is a sharper vector-bundle statement.  Let

```text
p in M_(kN)(C(X))
```

be any projection of constant rank `d`.  Some ambient unitary conjugate of
`p` belongs to `M_k(D(X;x,r))` if and only if

```text
r_i divides d  and  d/r_i<=k       for every i.          (VB)
```

The conjugate represents the same vector bundle and the same `K_0(C(X))`
class as `p`.  Hence finite point constraints impose no obstruction on any
ambiently representable vector-bundle class beyond the fibre-rank arithmetic
`(VB)`.  Reduced `K`-theory and the dimension or homotopy type of `X` do not
alter the first projection level: the trivial rank-`L` bundle always realizes
the minimum in `(FP)`.

In particular, this applies to every connected finite CW complex, including
all finite `2`-complexes.  The algebra is projectionless exactly when the
marked ranks are not all equal.  If `P` is a projection at the first level
and `C_P` is the algebra generated by its matrix coefficients, then `C_P` is
projectionless and subhomogeneous, `P` is full in `M_(m_0)(C_P)`,
`Prim(C_P)` is compact, and `m_0` remains its first projection level.

Topology can matter only in a different problem: one may prescribe a bundle
class which is not represented by a rank-`d` subbundle of the fixed trivial
`kN`-bundle in the first place, or impose data on a positive-dimensional
closed subset.  Once an ambient projection exists, finitely many constrained
fibres create no additional vector-bundle or `K`-theory obstruction.

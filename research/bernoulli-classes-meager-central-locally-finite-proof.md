Notation as in the target. `b` is a Bernoulli shift with nontrivial finite base `(L, λ)`, and `b_∞` the one with
base `([0,1], Leb)`. For actions `a, c`, `a ≺ c` is Kechris's weak containment by finite-window statistics
(Definition in `research/artifacts/weak-invariant-blindness-for-bernoulli-rokhlin-entropy-2026-09-12.md`).
**Imports**, both from Kechris, *Global aspects of ergodic group actions* (2010), Section 10:
- (K) `a ≺ c` iff `a` lies in the closure of the conjugacy class of `c`, in the window form: if a basic
  neighbourhood of `a` is given by a window whose statistics are realized in `c`, it contains a conjugate of `c`;
- (AW) Abért–Weiss: every Bernoulli action, including `b_∞`, is weakly contained in every free action, so
  `b_∞ ≺ b`. The theorem number is as quoted in the prerequisite.

**Step 1. `E = { a : h(a|P) = 0 }` is a conjugation-invariant `G_δ`.** Fix finite subgroups `F_1 ⊆ F_2 ⊆ ...`
exhausting `P`. For a finite partition `Q`, put `H_m(a, Q) = H_µ(∨_(f in F_m) a(f)Q)`.
- `F_(m+1)` is a union of `[F_(m+1):F_m]` cosets `tF_m`, and `∨_(f in tF_m) a(f)Q = a(t)(∨_(f in F_m) a(f)Q)`.
  So subadditivity gives `H_(m+1)/|F_(m+1)| <= H_m/|F_m|`, and `h(a|P, Q) = inf_m H_m(a, Q)/|F_m|`.
- Each `H_m(·, Q)` is continuous in the weak topology, so `h(·|P, Q)` is upper semicontinuous.
- `|h(a|P,Q) - h(a|P,R)| <= H(Q|R) + H(R|Q)`, so `h(a|P) = sup` over a countable Rokhlin-dense family `D` of
  finite partitions.
- Hence `E = ∩_(Q in D) ∩_k { h(·|P, Q) < 1/k }` is a `G_δ`. It is conjugation invariant.

**Step 2. Bernoulli classes avoid `E`.** For the coordinate partition `Q` at `1_Γ`, the translates by distinct
`f in P` read distinct coordinates, so `H_m = |F_m| H(λ)` and `h(b|P) >= H(λ) > 0`.

**Step 3. Approximants.** Let `a_n = Γ ↷ (L^(Γ/K_n), λ^(Γ/K_n))` with `(γ.x)(tK_n) = x(γ^-1 t K_n)`. The index
`[Γ : K_n]` is infinite, so the space is nonatomic.
- **(3a) `a_n in E`.** A partition read on finitely many coordinates `S` has `∨_(f in F_m) a_n(f)Q` read on
  `F_m S`. `P` is central, so `f t K_n = t f K_n`, and `PS` has at most `|S| [P : K_n]` points. So `H_m` is
  bounded, and `h(a_n|P, Q) = 0`. Such `Q` are dense, so `h(a_n|P) = 0`.
- **(3b) `a_n ≺ b`.** Take a window: finite `W ⊆ Γ` containing `1`, and cylinder sets on coordinates `S` with
  representatives `s~`. `K_n` is locally finite, so the subgroup `F` generated by `K_n ∩ S~^-1 W^(±1) S~` is
  finite, and `F ⊆ K_n`. For `γ in W^(±1)`: `γ s~ F = s~' F` iff `s~'^-1 γ s~ in F` iff `s~'^-1 γ s~ in K_n`.
  So the coincidence patterns of the relevant cosets agree for `Γ/F` and `Γ/K_n`. With i.i.d. labels, the
  generalized Bernoulli shift `c_F` over `Γ/F` realizes the window statistics of `a_n`. `c_F = Coind_F^Γ(L)`,
  with trivial `F`-action, is a factor of `b_∞ = Coind_F^Γ([0,1]^F)` through
  `Coind(θ)`, where `θ: [0,1]^F -> L` is `F`-invariant with law `λ` (a quantile function of `min_f y(f)`).
  Factors are weakly contained, so `a_n ≺ c_F ≺ b_∞ ≺ b`.
- **(3c) Windows of `b` are realized in some `a_n`.** Given a window `(W, S)` for `b`, choose `n` with
  `K_n ∩ S^-1 W^(±1) S ⊆ {1}`, using `∩ K_n = {1}`. Then `γ s K_n = s' K_n` iff `γ s = s'`, and the statistics of
  `b` on the window equal those of `a_n`.

**Step 4. Conclusion.** By (K) and 3b, `[a_n] ⊆ Y`, and by 3a, `[a_n] ⊆ E`. Let `a in Y` and `U` a basic
neighbourhood of `a`. By (K), `U` contains a conjugate `σbσ^-1`, and a basic neighbourhood of it inside `U`.
By 3c and the window form of (K), that neighbourhood contains a conjugate of some `a_n`, which lies in `E ∩ Y`.
So `E ∩ Y` is a dense `G_δ` in the Polish space `Y`, hence comeager. By Step 2 every Bernoulli class lies in
`Y \ E`, so it is meager.

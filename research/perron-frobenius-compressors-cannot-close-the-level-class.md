**ESTABLISHED (proposed; unreviewed).**  Derivation: [[perron-frobenius-compressors-cannot-close-the-level-class-proof]].
Script: `experiments/pf-compressor-halfspace-2026-09-17/check_pf_halfspace.py` (exit 0; log `run.log`).
It is a method obstruction, with a reduction, on the nonsofic side of
[[rank-three-finite-twisted-kazhdan-cone-is-sofic]].  It tests the step proposed at the end of
[[level-groups-need-not-concentrate-on-monomial-lines]]: take a nonnegative `σ ∈ H_B` of infinite order, move a
trace monomial `x^p` with `<w, p> < 0` along the `σ`-orbit onto a monomial ray, and read off a line section with
a pole deeper than `2n`, to reach (L2) of [[level-subpair-line-sections-are-bounded-or-cofinite]].

## Setting

As in [[level-groups-need-not-concentrate-on-monomial-lines]]: `R_+ = F_q[x_1..x_d]`, `R` the Laurent ring,
`Gamma = EL_3(R_+) = SL_3(R_+)` (Suslin), `G = EL_3(R) x| SL_d(Z)`, `psi = ev_0`, `U_k` the level of monomial
elementary matrices of degree `≥ k` (either coefficient convention).  For `B ≤ G`: `C = B ∩ Gamma`,
`E_B = B ∩ EL_3(R)`, `H_B` the projection to `SL_d(Z)`, `O = R_(≥0)^d`, `K0 = cone(H_B · O)`.  A compressor is
`c = u σ ∈ B` (`u ∈ EL_3(R)`, `σ ∈ H_B`) with `c C c^-1 ≤ C`.  `N(E)`, `Ncone(E)`, `W(E)` and `E_θ` are as in
(Z1)-(Z3) there, and `D(E) = Ncone(E)^∨`.

A nonnegative `σ ∈ SL_d(Z)` is **primitive** if some power has all entries positive.  Then its spectral radius
`λ` is `> 1` and irrational, and `σ^T` has a Perron eigenvector `θ_σ ∈ R^d_(>0)`, `σ^T θ_σ = λ θ_σ`, spanning
an irrational ray.  Example for `d = 3`: `σ = [[1,1,0],[0,1,1],[1,1,1]]`, `χ = x^3 - 3x^2 + 2x - 1`,
`λ ≈ 2.3247`, `θ_σ ≈ (0.5698, 1, 0.7549)`.

## Theorem

**(Q1) The σ-step is false: a split counterexample.**  Let `σ ∈ SL_d(Z)`, `d ≥ 2`, be nonnegative and
primitive, `θ = θ_σ`, and `B_σ = E_θ x| <σ> ≤ G`.  Then `σ̂(E_θ) = E_θ`, and:

1. `U_1 ≤ E_(B_σ) = E_θ`, `e_ab(1) ∉ E_θ`, and `psi(C) = 1`, so the centraliser condition holds;
2. `σ` is a compressor of `C = E_θ ∩ Gamma`; `C` is **infranormal** in `B_σ` and **not normal**;
3. `H_(B_σ) = <σ>` is infinite and generated by the nonnegative `σ`, as (X1) demands;
4. for every rational `w ≠ 0` some trace of `E_θ` has a monomial `x^p` with `<w, p> < 0`; yet every trace
   monomial and every `σ`-orbit of one stays in `P_θ = { <θ, ·> > 0 } ∪ 0`, which meets no negative monomial
   ray `-N m`, `m ∈ N^d \ 0`;
5. every element of `B_σ` conjugate into `E_θ`, including every `u_n σ̂^n(g) u_n^-1`, lies in `E_θ`, whose
   line sections `Δ_m`, `m ∈ N^d \ 0`, lie in `SL_3(F_q[t])`: no pole at all.

`B_σ` fails only property (T): it maps onto `Z`.  So the brief's route, and **every argument that uses a
single nonnegative compressor, or any subgroup of `H_B` whose transpose fixes a positive ray**, cannot reach
(L2).  A closing argument must use that `H_B` is character-free.

**(Q2) For a survivor, one primitive compressor exhausts the Newton invariant.**  Let `B ⊇ U_k` and let
`σ ∈ H_B` be nonnegative and primitive.  Then `D(E_B)` is `0` or contains `θ_σ`.  In the second case every
trace of `E_B` is supported in the closed half-space `{ <θ_σ, ·> ≥ 0 }`, as for `E_θ`.  If `K0` contains
`± e_l` for some `l` (the invariant core `M ≠ ∅` of (W2), present in every survivor of (Y2)), the second case
is impossible, so

```text
Ncone(E_B) = R^d,   D(E_B) = 0,   W(E_B) = ∅,
```

and the traces of `E_B` have the same Newton data as those of `EL_3(R)`, which contains `e_ab(1)`.  No invariant
of the Newton cone or of the weight buildings (Z1) separates a survivor from a killed group.

**(Q3) Compressor twists are bounded.**  If `c = u σ` is a compressor of `C ⊇ U_k`, then for all `w ∈ R^d_(≥0)`
and `a ≠ b`,

```text
v_w(u e_a) + v_w(e_b^T u^-1)  ≥  - k · min_i (σ^T w)_i ,
```

with `v_w` of a vector the minimum over its entries.  Equivalently, every off-diagonal rank-one piece
`x^(k σ e_i) (u e_a)(e_b^T u^-1)`, `a ≠ b`, of the twist is a polynomial matrix.  Scaling `u` by a diagonal
monomial matrix changes the pairs `(a, b)` and `(b, a)` in opposite directions, so the diagonal part of the
twist is bounded too, with a bound linear in `w`.

**(Q4) What is left: the twisting class.**  If `B` contains untwisted monomial elements `σ_1, .., σ_r`
(`u = 1`) that generate `H_B`, then `B ⊇ B_(H_B, k)`, and (W2) with (M2) of
[[monomial-origin-level-subpairs-cannot-certify-rank-three-cone]] gives `psi(C) = F`.  So a surviving level
certificate must have **essential twists**: no generating set of nonnegative compressors can be made untwisted,
even after conjugating `B` by `Gamma` (which keeps a level, by (F2) of the w19 proof).

## Mechanism

1. *(Q1).*  `<θ, σ p> = λ <θ, p>`, so `σ` preserves `P_θ`, `S_θ` and `I_θ`, hence `E_θ`.  A polynomial element
   stays polynomial under `σ̂` because `σ ≥ 0`, so `σ` compresses `C`.  For `p ∈ P_θ \ 0`,
   `σ^n p = c λ^n v + o(λ^n)` with `c > 0` and the Perron vector `v > 0` of `σ`, so `σ^n p ∈ N^d` for large `n`.
   Hence each `g ∈ E_θ` has `σ̂^n(g) ∈ SL_3(R_+) ∩ E_θ = C`, and `g = σ^-n σ̂^n(g) σ^n ∈ < C, σ >`.  Not normal:
   `σ^-1 e_ab(x_i) σ = e_ab(x^(σ^-1 e_i))`, and some `σ^-1 e_i ∉ N^d` since `σ` is not a permutation matrix.
2. *(Q2).*  `N(E_B)` is `H_B`-invariant because `tr(u σ̂(g) u^-1) = σ̂(tr g)`, so `D = D(E_B) ⊆ O` is a closed
   `σ^T`-invariant cone.  For `w ∈ D \ 0` the normalised iterates `(σ^T)^n w` converge to the ray of `θ_σ`
   (Perron-Frobenius for primitive `σ^T` and `w ≥ 0`), so `θ_σ ∈ D`.  But `± e_l ∈ K0 ⊆ Ncone` forces
   `(θ_σ)_l = 0`, which a positive vector does not satisfy.
3. *(Q3).*  `u e_ab(x^(σ m)) u^-1 = 1 + x^(σ m) (u e_a)(e_b^T u^-1)` lies in `SL_3(R_+)` for `|m| = k`, and
   `v_w` is additive on outer products because monomial valuations do not cancel.  Take `m = k e_i`; the
   polynomial entries have `v_w ≥ 0` for `w ≥ 0`.
4. *(Q4).*  `C` contains the trace of the split subpair, and `psi` of that trace is already `F`.

## Calibration

- `B = G`: `H_B = SL_d(Z)` contains primitive `σ`, `M = [d]`, and indeed `Ncone(EL_3(R)) = R^d`: (Q2) is sharp.
- `B = Gamma x| S_d`: no primitive element, `D = O`, and `C = Gamma` is normal: (Q2) says nothing, correctly.
- `B_σ` itself: `D(E_θ)` is the ray of `θ`, the second branch of (Q2); its `K0` is salient (it lies in the open
  half-space), so there is no invariant core and (Q2) does not contradict it.  Consistent with Theorem A:
  `B_σ` is not Kazhdan.
- The example `σ` is checked by the script: `det = 1`, `σ^2 > 0`, `χ` irreducible, `θ > 0`, `σ` preserves
  `P_θ` on a box, orbits reach `N^3` within 5 steps, `σ^-1 e_1 = (0, 1, -1)`.

## What is left

The level class of the nonsofic side is reduced to the **twisting class** of the compressors: a survivor needs a
Kazhdan `B ⊇ U_k` generated by `C` and compressors `u_i σ_i` whose twists `u_i` are bounded as in (Q3) but not
removable, with `Ncone(E_B) = R^d` whenever some product of the `σ_i` is primitive.  Diagonal monomial twists
`u = diag(x^δ)` give an affine action of `H_B` on exponents; when `H^1(H_B, Q^d) = 0` (for instance for lattices
of higher rank, by Margulis) they are coboundaries over `Q`.  After a substitution `x ↦ x^N` they should
become the diagonal conjugates killed by [[normalised-level-subpairs-cannot-certify-rank-three-cone]]; this
is not checked here.  The next step is
the general version: show that bounded twists of a character-free `H_B` are coboundaries modulo `E_B`, so that
(Q4) applies.  Otherwise, the positive side.

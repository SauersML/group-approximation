## Statement

Let `S` be a nontrivial simple subgroup of a group `Gamma`, and suppose
`Gamma = <<s>>_Gamma` for some `1 != s in S`. Write
`r = |S \ Gamma / S|` (possibly infinite). Let `N` be a proper normal
subgroup of `Gamma`.

1. **One class per double coset.** For every `g in Gamma`, the set
   `N ∩ SgS` is empty or a single `S`-conjugacy class
   `{a n a^-1 : a in S}`.
2. **Class count.** The `S`-conjugacy classes of `N` inject into
   `S \ Gamma / S`. So `N` is the union of at most `r` such classes, one of
   which is `{1}`. Hence `N` is normally generated in `Gamma` (indeed
   `S`-normally generated) by at most `r - 1` elements.
3. **Centralized part.** `|N ∩ C_Gamma(S)| <= r`. In particular
   `|Z(Gamma)| <= r` when `S` is nonabelian.

Assume now `r < infinity`.

4. **Max-n.** Every ascending chain of normal subgroups of `Gamma`
   stabilizes.
5. **Quotients keep everything.** For every proper `N <| Gamma`, the
   quotient `Gamma/N` is normally generated by `sN`, contains an isomorphic
   copy `SN/N` of `S`, and `|(SN/N) \ (Gamma/N) / (SN/N)| <= r`. If `Gamma`
   is finitely presented then so is `Gamma/N`. If `Gamma` has property (T)
   then so has `Gamma/N`.
6. **Simple quotient.** A maximal proper normal subgroup `M` exists, and
   `Gamma/M` is simple, contains a copy of `S`, and is finitely presented
   whenever `Gamma` is.

## Class of envelopes this kills

A group `Gamma` carries **no** normally generating nonabelian simple core
of finite bi-index if any of the following holds:

- `Gamma` has an infinite central subgroup, or an infinite proper normal
  subgroup centralized by the core (clause 3);
- `Gamma` has an infinite strictly ascending chain of normal subgroups
  (clause 4); for example `Gamma` maps onto `EL_n(U)`, `n >= 2`, for a ring
  `U` with an infinite strictly ascending chain of proper two-sided ideals
  (see the proof, section 4);
- `Gamma` is finitely presented and has a proper quotient that is not
  finitely presented (clauses 2 and 5), for instance a maximal kernel that is
  not finitely normally generated, as in
  `kazhdan-hyperbolic-continuum-non-fng-maximal-kernels`.

In each case the step that dies is clause 2: some proper normal subgroup has
infinitely many core-classes, and each of them occupies its own double coset.

## Consequence for the route

Finite bi-index is strictly more than the route needs. With clause 6 the
envelope already has a finitely presented simple quotient `Gamma/M`
containing the input, so the twisted Brin--Thompson step of
`boone-higman-via-finite-bi-index-envelope` is idle. See
`ck-finite-bi-index-hole-is-kazhdan-boone-higman`.

The required claim gives `n >= 2` and `G` of type `F_n` with no host of type
`F_{n+1}`. This answers the first part negatively. A group of type `F_∞` is of
type `F_{n+1}`, so `G` has no host of type `F_∞` either, which answers the
second part negatively.

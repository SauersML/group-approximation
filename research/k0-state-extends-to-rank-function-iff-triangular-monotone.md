Let `A` be a unital ring and `<=_T` the preorder on matrices generated by minors and triangular steps, as
in `sylvester-rank-functions-iff-no-triangular-certificate`. A state `s` on `(K_0(A), [A])` is the
restriction to idempotents of a Sylvester matrix rank function iff:

    f (+) K <=_T e (+) K,  with e, f idempotent and K any matrix,  implies  s([f]) <= s([e]).

**For the state upgrade.** A weakly finite image `W` of `S_-` carries a Sylvester rank function iff some
state on `(K_0(W), [W])` is `<=_T`-monotone on idempotents. So (U1b)
(`anti-central-weakly-finite-images-carry-rank-functions`) is a monotonicity statement about states.
- **Jordan certificates never violate it.** `nilpotent-jordan-certificates-flatten-to-minors` shows they are
  already minor certificates.
- **Separated steps never violate it.** `separated-triangular-steps-flatten-to-minors` removes them.
- **What remains.** A violation needs a mixed triangular step.

**ESTABLISHED ONE-SIDED-SUPPORT FENCE.**  In the binary Leavitt elementary
group put

```text
P=What_(8,2;2),       J_1=What_(7,8;1),
J_2=What_(8,9;2),     B_2=x_84(s_00t_1),
n=x_78(1),            m=x_87(1),
G_2=<P,J_1,J_2,B_2,n,m>.                              (EBR1)
```

Then the native subgroup `N=<n,m>~=S_3` is a retract of `G_2`.  Explicitly,

```text
rho_2(P)=rho_2(J_1)=rho_2(J_2)=rho_2(B_2)=1,
rho_2(n)=n,                     rho_2(m)=m.             (EBR2)
```

Let

```text
p=s_0t_0,                  A=R/pR.                     (EBR3)
```

The right `R`-submodule `(pR)^20` of the column module `R^20` is invariant
under every generator in `(EBR1)`.  Every entry of

```text
P-I,             J_1-I,             J_2-I,             B_2-I (EBR4)
```

lies in `pR`, so those four generators act identically on the nonzero
additive quotient `A^20`.  The constant roots descend to the standard
transvections `I+E_78,I+E_87`, which generate a faithful `S_3`.  This
quotient action proves `(EBR2)`.

The point is that `B_2` defeats the scalar `qI` corner but not the
one-sided-support quotient:

```text
b_2=s_00t_1,       p b_2=b_2,       b_2 q=b_2,
q b_2=0.                                                (EBR5)
```

An MSI-only faithful-normal-form enumeration through freely reduced length
six finds the cyclic relations

```text
(PJ_1)^3,        (PJ_2)^3,        (J_1J_2)^3,
[B_2,m],         (nm)^3.                              (EBR6)
```

They all reduce correctly under `(EBR2)`.  This is only a bounded
calibration; the module quotient proves compatibility with every word
relation of the actual subgroup.

The coefficient `a_2=s_1t_00` lies outside `pR`, so the module-quotient
argument stops when `A_2` is adjoined.  It is **not** an actual breaker:
`endpoint-native-heads-retain-coordinate-q-s3-retract` proves that the
smaller coordinate corner still kills `A_2`, `B_3`, and both complete
native heads.  The first obvious violations of that sharper corner are
instead `x_84(1)` and `x_47(s_0t_1)`.

No Property `(T)`, Kazhdan input, trace profile, stability theorem, or
numerical approximation is used.

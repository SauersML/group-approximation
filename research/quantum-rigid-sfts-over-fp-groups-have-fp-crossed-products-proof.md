The notation is that of the target. The proof is self-contained.

Fix a word `w_q` in `S` for each `q ∈ B_(2D)`. Let `U` be the `k`-algebra with generators `e_a`
(`a ∈ A`) and `u_s` (`s ∈ S`), and the following finitely many relations.
1. `u_s u_(s^(-1)) = 1` for `s ∈ S`, and `u_ρ = 1` for each relator `ρ ∈ R`.
2. `e_a^2 = e_a`, `e_a e_b = 0` for `a ≠ b`, and `Σ_a e_a = 1`.
3. `[e_a, u_(w_q) e_b u_(w_q)^(-1)] = 0` for all `a, b` and `q ∈ B_(2D)`.
4. `Π_(f ∈ B_D) u_(w_f) e_(α(f)) u_(w_f)^(-1) = 0` for each pattern `α` on `B_D` not occurring in `X`.

By (1), `g -> u_g` is a well-defined homomorphism `Λ -> U^x`. Put `E_a(q) = u_q e_a u_q^(-1)` and let
`C ⊆ U` be the subalgebra they generate. Conjugation by `u_p` sends `E_a(q)` to `E_a(pq)`, so
(2)-(4) translate to Q1-Q3 for the family `E_a(q)`, `q ∈ Λ`.

**Step 1: `C` is commutative.** Let `U` act on `W_0 = U` by left multiplication. The operators
`L_(E_a(q))` form a `D`-quantum family on `W_0`, because `x -> L_x` is a unital algebra map. By
rigidity they commute. The action is faithful, since `U` is unital. So the `E_a(q)` commute.

**Step 2: `C ≅ LC(X, k)`.** The assignment `e_a -> 1_[x(1)=a]`, `u_s -> u_s` respects (1)-(4) in `B`.
In (4), the product is the indicator of a cylinder that misses `X`. This gives `φ : U -> B`.
- Since `C` is commutative and generated by commuting partitions of unity indexed by `Λ`, there is a
  surjection `ψ : LC(A^Λ, k) -> C` with `1_[x(q)=a] -> E_a(q)`.
- Let `p` be a pattern on a finite `F` with `[p] ∩ X = ∅`. Since `D >= r`, the set `X` is defined by
  forbidding the `B_D` patterns absent from `X`. By compactness (König) there is a finite `F' ⊇ F`
  such that every extension `p'` of `p` to `F'` contains a forbidden `B_D` pattern at some translate
  `qB_D ⊆ F'`. Since `C` is commutative, each `ψ(1_[p'])` is a multiple of the `u_q`-conjugate of a
  relator (4), so it is `0`. Hence `ψ(1_[p]) = Σ_(p') ψ(1_[p']) = 0`.
- So `ψ` induces a surjection `ψ' : LC(X, k) -> C`. The composite `φ ψ'` is the identity on the
  generators `1_[x(q)=a]`, so `ψ'` is injective. Hence `ψ'` is an isomorphism, with inverse `φ|_C`.

**Step 3: `φ` is an isomorphism.** Since `u_g C u_g^(-1) = C`, every word in the generators rewrites as
`Σ_g c_g u_g` with `c_g ∈ C`, so `U = Σ_g C u_g`. Now `φ(Σ c_g u_g) = Σ φ(c_g) u_g`. The `u_g` form
a free left `LC(X, k)`-basis of `B`, so this vanishes only if every `φ(c_g) = 0`, that is only if
every `c_g = 0` by Step 2. `φ` is onto, since its image contains the generators of `B`. So `B ≅ U`
is finitely presented. ∎

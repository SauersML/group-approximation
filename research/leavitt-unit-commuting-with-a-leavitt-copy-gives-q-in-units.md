**ESTABLISHED** (lane proof, bh-major-gln, elementary, not reviewed; no priority claimed).

**Setting.** `F` is any field and `L = L_F(1,2)`, with generators `x_0, x_1, y_0, y_1`, relations
`y_i x_j = δ_ij` and `x_0 y_0 + x_1 y_1 = 1`.

**Theorem.** Suppose `t ∈ L^×` has infinite order and commutes elementwise with a unital subring
`D ⊆ L` that is isomorphic to `L`. Then there are units `r_1 = t, r_2, r_3, … ∈ L^×` with
`r_(k+1)^(k+1) = r_k`, and `m/k! ↦ r_k^m` is an injective homomorphism `(Q,+) → L^×`. All `r_k` lie
in the subring generated by `D` and `t^(±1)`.

**Equivalent hypothesis.** For finite `F`, the hypothesis holds exactly when there is a unital ring
embedding `L ⊗_F F[u^(±1)] ↪ L`. Given `t` and `D`, the map `D ⊗ F[u^(±1)] → L`, `d ⊗ u^i ↦ d t^i`, is a
ring map, since `t` commutes with `D`. `D ⊗ F[u^(±1)]` is central simple over `F` tensored with a
commutative ring, so its ideals are `D ⊗ I`. The kernel is therefore `D ⊗ I`, and `I = 0` because an
infinite-order unit over a finite field is transcendental: if `t` were algebraic, `F[t]` would be a
finite ring and `t` would have finite order. The converse is immediate.

## Proof

1. **Leavitt `n`-tuples in `D`.** Write `X_i, Y_i` for the images in `D` of the Leavitt generators.
   For `n ≥ 2` put `z_i = X_1^(i-1) X_0` and `w_i = Y_0 Y_1^(i-1)` for `i < n`, and `z_n = X_1^(n-1)`,
   `w_n = Y_1^(n-1)`.
   - **Orthogonality.** `Y_0 X_1 = Y_1 X_0 = 0` gives `w_i z_j = δ_ij`.
   - **Completeness.** `X_1^(i-1) X_0 Y_0 Y_1^(i-1) = X_1^(i-1) Y_1^(i-1) − X_1^i Y_1^i` telescopes, so
     `Σ_i z_i w_i = 1`.
   - **Matrix units.** `e_ij = z_i w_j` is a unital copy of `M_n(F)` inside `D`.
2. **The relative commutant is again a copy of `L`.** Let `C = {d ∈ D : d e_ij = e_ij d for all i,j}`.
   - **The map.** `θ(a) = Σ_i z_i a w_i` is a unital ring map `D → C`: it is multiplicative since
     `w_i z_j = δ_ij`, and `θ(a) e_kl = z_k a w_l = e_kl θ(a)`.
   - **Injective.** `w_1 θ(a) z_1 = a`.
   - **Surjective.** For `c ∈ C`, `θ(w_1 c z_1) = Σ_i e_i1 c e_1i = c Σ_i e_ii = c`.

   So `C ≅ D ≅ L`, and `C` commutes with `t` because `C ⊆ D`.
3. **Tower.** Set `D_1 = D` and `A_1 = F`. Given a unital `D_k ≅ L` commuting with `t` and with a
   unital matrix algebra `A_k ≅ M_(k!)(F)`:
   - apply steps 1–2 inside `D_k` with `n = k+1`, getting matrix units `E^(k+1)_ij ∈ D_k` and their
     relative commutant `D_(k+1) ⊆ D_k`, with `D_(k+1) ≅ L`;
   - `A_(k+1)`, the subring generated by `A_k` and the `E^(k+1)_ij`, is `≅ A_k ⊗ M_(k+1)(F)`. These are
     commuting unital central simple subalgebras, and `A_k ⊗ M_(k+1)(F)` is simple, so the
     multiplication map is injective;
   - `D_(k+1)` commutes with `A_(k+1)` and with `t`.
4. **Roots by block companions.** Put `r_1 = t`. Suppose `r_k` lies in the subring generated by `A_k`
   and `t^(±1)`; it then commutes with `D_k`, hence with every `E_ij = E^(k+1)_ij`. Define
   `r_(k+1) = Σ_(i=1)^(k) E_(i+1,i) + r_k E_(1,k+1)`.
   - **It is a root.** This is the companion matrix of `X^(k+1) − r_k` over the commuting coefficient
     `r_k`, so `r_(k+1)^(k+1) = r_k Σ_i E_ii = r_k`.
   - **It is a unit.** `r_k` is a unit, so `r_(k+1)^(-1) = r_(k+1)^k r_k^(-1)`.
   - **Induction.** `r_(k+1)` lies in the subring generated by `A_(k+1)` and `t^(±1)`, so the induction
     continues.
5. **The copy of `Q`.** Since `r_k = r_(k+1)^(k+1)`, the cyclic groups `⟨r_k⟩` form an increasing chain,
   and `φ(m/k!) = r_k^m` is a well-defined homomorphism on `Q = ∪_k (1/k!)Z`. If `r_k^m = 1`, then
   `t^m = r_k^(m·k!) = 1`, so `m = 0`. Hence `φ` is injective. ∎

## Consequences

- **Infinite fields (calibration).** A scalar `t = λ ∈ F^×` of infinite order commutes with `D = L`,
  so `(Q,+) ⊂ L_F(1,2)^×` whenever `F^×` has an element of infinite order. This agrees with
  `integral-unit-hosts-for-gl-n-q-reduce-to-finite-fields`: finitely generated pieces reduce to finite
  fields, where scalars have finite order.
- **Finite fields, where the question lives.** For `F = F_p`, `L^×` is the finitely presented simple
  host of the Leavitt route. The theorem says one non-scalar infinite-order unit with a commuting
  Leavitt copy puts `(Q,+)` there. Such a `t` has `C_L(t) ⊇ D ⊗ F[t^(±1)]`, so its centralizer rank
  over `F(t)` is infinite. `leavitt-unit-centralizers-have-finite-rank` therefore predicts that no such
  `t` exists. That OPEN conjecture is the exact thing standing between this mechanism and `(Q,+)`,
  and then `F_p[Q]`, in `L_(F_p)(1,2)`.
- **What it does not give.** Dilations. For `Aff(Q)` or `GL_n(Q)` one would also need units conjugating
  `r_k` to `r_k^q`. Nothing here supplies them.

## Lesson for general BH

Leavitt algebras split every integer for free: one binary pair gives Leavitt `n`-tuples for all `n`
at once, with no invariant mass, since `K_0 = 0`. So the mass-module obstruction that kills Cantor and
Thompson hosts (`no-free-q-odd-action-by-v-has-a-doubling-intertwiner`,
`v-element-invariant-measures-live-on-the-periodic-part`) disappears, and "all primes at once" costs
nothing.

What remains is a single algebraic question: centralizer rank. Can an infinite-order unit commute with a
whole copy of the algebra? This moves the prime problem off the geometry and onto one explicit conjecture
that can be tested (`leavitt-unit-centralizers-have-finite-rank`). The same shape appears in the master
route, where the arithmetic sits in the acting group and never in local data.

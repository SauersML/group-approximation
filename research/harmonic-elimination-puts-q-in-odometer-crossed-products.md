## Setting

- `Γ` is a group and `Γ = Γ_0 ⊋ Γ_1 ⊋ Γ_2 ⊋ ...` a strictly decreasing sequence of finite-index normal
  subgroups.
- `K = lim Γ/Γ_n`, with `Γ` acting by left multiplication. Write `y_n ∈ Γ/Γ_n` for the coordinates of
  `y ∈ K`.
- `X` is a compact space with a `Γ`-action and a continuous equivariant map `π : X -> K`.
- Fix `x_∞ ∈ K`. For `y ∈ K` let `ℓ(y) = sup{n : y_n = (x_∞)_n}`, which is `∞` exactly when `y = x_∞`.
- The **harmonic function** `f_K(y) = 1/(1 + ℓ(y))` (and `f_K(x_∞) = 0`) is continuous for the real
  topology on `Q`: it is locally constant off `x_∞` and tends to `0` at `x_∞`. Put `f = f_K ∘ π`.
- In `C(X, Q) ⋊_alg Γ` use the convention `u_g h u_g^(-1) = h ∘ g^(-1)`, so `u_γ^(-1) f u_γ = f ∘ γ`.

## Statement

Let `R ⊆ C(X, Q) ⋊_alg Γ` be a unital subring containing `f` and `u_γ^(±1)` for every `γ ∈ Γ`, for
example the subring generated by `f` and `u_s^(±1)` for a generating set `S` of `Γ`. Then `Q ⊆ R`.

**Explicitly**, for `M >= 1`:
- Let `T_M ⊆ Γ` be a set of representatives of `Γ/Γ_M` and `d = [Γ : Γ_M]`.
- Let `E_k ∈ R` be the `k`-th elementary symmetric function of the `d` functions `f ∘ γ`, `γ ∈ T_M`.
- For `c ∈ Γ/Γ_M` with `c != (x_∞)_M`, let `ℓ(c) < M` be the largest `j` with `c ≡ x_∞` in `Γ/Γ_j`,
  and let `m_j` be the number of such `c` with `ℓ(c) = j`.

Then

    E_(d-1) - S_M E_d = 1/D_M,   where   D_M = Π_(j<M) (j+1)^(m_j),   S_M = Σ_(j<M) (j+1) m_j.

Every `m_j >= 1`, so `M!` divides `D_M`, and `1/m ∈ R` for every `m <= M`.

## Consequences

- **SL_3(Z) on its congruence odometer.** Take `Γ = SL_3(Z)` and `Γ_n = Γ((n+1)!)`, principal
  congruence subgroups, with `K = SL_3(Ẑ)`. Then the ring generated by one harmonic function and the
  `u_s^(±1)` contains `Q`. This answers question (a) of the remnant in
  `research/artifacts/gq-deep-adelic-1-uhf-class-verdict.md`.
- **Toeplitz extensions.** Any `Γ`-space with an odometer factor, e.g. a Toeplitz subshift, works with the
  pulled-back function.
- **Z-odometers.** The ring generated by `u^(±1)` and one harmonic function on the `2`-adic odometer
  already contains `Q`. It is skew Laurent, so it fails at `K_2`
  (`laurent-rational-symbols-block-fp-elementary-groups`).
- **No clopen sets are used.** The mechanism is compatible with idempotent-poor rings; see the artifact
  for what this means for simplicity.

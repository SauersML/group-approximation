Standard facts used, not re-read: Serre, *Trees*, §5.1--5.2 (the path group `π(𝔾)`;
`π_1(𝔾, v_0)` is its subgroup of loop words at `v_0`; every nontrivial element of it is
represented by a reduced loop word); Britton's lemma for multiple HNN extensions
(Lyndon--Schupp IV.2).

**Setup.** Let `E⁺` be the chosen orientations. `π(𝔾)` is generated by the `G_v` and the
letters `t_e` (`e ∈ E⁺`), with the relations of the `G_v` and
`t_e ι_e^+(c) t_e^(-1) = ι_e^-(c)`. Write `t_ē = t_e^(-1)`, `ι_ē^± = ι_e^∓`. A loop word at
`v_0` is `g_0 t_{e_1} g_1 ⋯ t_{e_n} g_n` with `e_i` oriented edges, `e_1^- = e_n^+ = v_0`,
`e_i^+ = e_{i+1}^-`, `g_0 ∈ G_{v_0}` and `g_i ∈ G_{e_i^+}`. It is **reduced** if `n = 0`
and `g_0 ≠ 1`, or `n ≥ 1` and there is no `i` with `e_{i+1} = ē_i` and
`g_i ∈ ι_{e_i}^+(G_{e_i})`.

**The map.** Define `Θ : π(𝔾) → L` by `α_v` on `G_v` and `t_e ↦ s_e w_e` (`e ∈ E⁺`). The
relation is respected:
`s_e w_e α_{e^+}(ι_e^+ c) w_e^(-1) s_e^(-1) = s_e α_{e^-}(ι_e^- c) s_e^(-1) = α_{e^-}(ι_e^- c)`,
since `s_e` centralizes `C_e`.

**Injectivity on `π_1(𝔾, v_0)`.** Take a reduced loop word with `n ≥ 1` (for `n = 0`, use
that `α_{v_0}` is injective). Its image is a word in `D` and the letters `s_e^(±1)`, one
letter for each `t_{e_i}`. A Britton pinch needs two consecutive letters of one geometric
edge `e` with opposite signs, so `e_{i+1} = ē_i`.
- If `e_i = e ∈ E⁺`: the segment is `s_e (w_e α_{e^+}(g_i) w_e^(-1)) s_e^(-1)`. This is a
  pinch iff `w_e α_{e^+}(g_i) w_e^(-1) ∈ C_e = w_e α_{e^+}(ι_e^+ G_e) w_e^(-1)`, iff
  `g_i ∈ ι_e^+(G_e)`, since `α_{e^+}` is injective. That is excluded.
- If `e_i = ē` with `e ∈ E⁺`: the segment is `s_e^(-1) α_{e^-}(g_i) s_e`. This is a pinch
  iff `α_{e^-}(g_i) ∈ C_e = α_{e^-}(ι_e^- G_e)`, iff `g_i ∈ ι_e^-(G_e) = ι_{e_i}^+(G_{e_i})`.
  That is excluded.

So the image is Britton-reduced with `n ≥ 1` stable letters, and it is not `1`.

**`L ∈ B_A`.** `L` has the same presentation as the star amalgam
`D *_{C_e} (C_e × ⟨s_e⟩)` (`e ∈ E⁺`). Each `C_e` is good in `D`, so by the "Multiple
orbits" clause of `pbh-coset-wreaths-iff-identity-edge-hnns` (finitely many orbits),
`(*_{x∈X} Z^{E⁺}) ⋊ D ∈ B_A`, with `X = ⊔_e D/C_e`. Step 3 of
`cusp-extensions-rel-hyperbolic-pbh-proof` identifies the star amalgam with a subgroup
of it. The argument there uses only that `C_e` centralizes the `e`-th factor.

**Special cases.** (1): the hypothesis holds with `w_e = 1`. (2): the edge is `G_e = C`,
with `ι^+` the inclusion and `ι^- = β|_C`, and `t c t^(-1) = β(c)` in `D`. (3): finite
subgroups are good (case 1 of `pbh-coset-wreaths-iff-identity-edge-hnns`).

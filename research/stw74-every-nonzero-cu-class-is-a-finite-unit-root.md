title: Every nonzero Cuntz class under the LXXIV hypothesis is a finite root of the unit
---

Let `A` be simple and unital, and suppose every nonzero projection in `A` is
infinite.  For every nonzero `x` in `Cu(A)` there is an integer `n>=1` such
that

```text
n x = [1_A].
```

In particular, every nonzero class has a compact finite multiple represented
by a projection.  A counterexample to Problem LXXIV must therefore contain a
finite root of the unit which dominates no nonzero projection class; merely
producing a soft class below the unit does not isolate the obstruction.

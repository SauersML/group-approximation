## Setting and inputs

- `𝔊` is the first Grigorchuk group and `σ : 𝔊 → 𝔊` is Lysenok's injective, non-surjective
  endomorphism. `𝔊^ = ⟨𝔊, t | t^(−1) x t = σ(x) (x ∈ 𝔊)⟩` is the ascending HNN extension
  (`grigorchuk-hnn-extension-is-fp-amenable-non-ea`). Write `G = 𝔊^`.
- `χ : G → Z` sends `t ↦ 1` and `𝔊 ↦ 0`. Let `N = ker χ` and `N_n = t^n 𝔊 t^(−n)`.
- **(I1)** `𝔊` is an infinite, finitely generated 2-group and is not finitely presented
  (`grigorchuk-group-is-just-infinite-torsion-not-fp`).
- **(I2)** Normal form for ascending HNN extensions: `N_0 ≤ N_1 ≤ …`, since
  `t^(−1) 𝔊 t = σ(𝔊) ≤ 𝔊` gives `𝔊 ≤ t 𝔊 t^(−1)`; and `N = ⋃_n N_n`, `G/N = ⟨tN⟩ ≅ Z`.
  Each inclusion is proper because `σ` is not surjective. So `N` is a torsion group and is not
  finitely generated, and every finitely generated subgroup of `N` lies in some `N_n ≅ 𝔊`.
- **(I3)** Grigorchuk–Wilson: every infinite finitely generated subgroup of `𝔊` is abstractly
  commensurable with `𝔊` (R. I. Grigorchuk, J. S. Wilson, J. London Math. Soc. (2) 68 (2003)
  671–682; recalled from the literature, not re-read in this session).
- **(I4)** Only for item 4: the Schur multiplier `H_2(𝔊; Z)` is an infinite elementary abelian
  2-group (R. I. Grigorchuk, "On the system of defining relations and the Schur multiplier of
  periodic groups generated by finite automata", Groups St Andrews 1997 in Bath, LMS Lecture Note
  Ser. 260 (1999); recalled, not re-read; also recalled in the Bartholdi–Grigorchuk–Šunić survey,
  as noted in `grigorchuk-hnn-extension-is-fp-infinity`).

Tree facts (Serre, *Trees*, Ch. I §6), for actions without inversions:

- **(T1)** An automorphism of finite order fixes a vertex.
- **(T2)** A finitely generated group all of whose elements fix a vertex fixes a vertex.
- **(T3)** For a group `H`, `Fix(H)` is a (possibly empty) subtree.
- **(T4)** If an automorphism `g` preserves a subtree `X` and fixes a vertex `u`, then `g` fixes the
  nearest-point projection of `u` to `X`. The projection map `T → X` commutes with every
  automorphism preserving `X`, and `X` has a unique nearest point to `u`.
- **(T5)** Let `g` fix an end `ω`. The Busemann map `β_ω : Stab(ω) → Z` is a homomorphism. If `g`
  fixes a vertex `v`, then `g` maps the ray `[v, ω)` to itself, fixes it pointwise, and
  `β_ω(g) = 0`. If `g` is hyperbolic and fixes `ω`, then `ω` is an end of its axis and
  `|β_ω(g)|` is its translation length, which is nonzero. Every automorphism without inversions is
  elliptic or hyperbolic, so `β_ω(g) = 0` exactly when `g` fixes a vertex.

## Step 1: every vertex stabilizer lies in `N`

Let `G` act on `T` without inversions and without a global fixed vertex. Every element of `N` has
finite order, so by (T1) it fixes a vertex. Each `N_n` is finitely generated, so by (T2)
`F_n := Fix(N_n)` is a nonempty subtree. The `F_n` are decreasing, and `t F_n = Fix(t N_n t^(−1))
= F_(n+1)`.

**Case A: `X := ⋂_n F_n` is nonempty.** Then `X = Fix(N)`. Since `N` is normal, `X` is
`G`-invariant.

- If `t` fixed a vertex `u` of `T`, then by (T4) it would fix a vertex `x` of `X`. But `N` fixes
  `x` too, and `G = ⟨N, t⟩`, so `x` would be a global fixed vertex. Hence `t` is hyperbolic, and so
  is `t^k` for `k ≠ 0`.
- Let `g ∈ G \ N`, so `g = t^k m` with `k ≠ 0` and `m ∈ N`. On `X`, `g` acts as `t^k`, which fixes
  no vertex of `X`. If `g` fixed a vertex of `T`, then by (T4) it would fix a vertex of `X`. So `g`
  fixes no vertex.

Hence every vertex stabilizer lies in `N`.

**Case B: `⋂_n F_n = ∅`.**

1. *An end.* Fix a vertex `v_0` and let `p_n` be its projection to `F_n`. Every geodesic from
   `v_0` to `F_n` passes through `p_n`, and `p_(n+1) ∈ F_(n+1) ⊆ F_n`. So `[v_0, p_n]` is an
   initial segment of `[v_0, p_(n+1)]`.
   - If `d(v_0, p_n)` were bounded, the `p_n` would be eventually constant, equal to some `p`.
     Then `p` lies in every `F_n` for `n` large, hence in all of them, a contradiction.
   - So the segments build a ray `ρ`, with end `ω`. For each `n`, the subray of `ρ` from `p_n` has
     its vertices `p_k` (`k ≥ n`) in `F_n`. By convexity (T3) the whole subray lies in `F_n`.
2. *Uniqueness.* Call an end *admissible* if every `F_n` contains a ray to it.
   - `ω` is admissible by step 1.
   - Suppose two distinct ends are admissible. A subtree containing rays to both contains the line
     between them. Then that line lies in every `F_n`, so `⋂ F_n ≠ ∅`, a contradiction.
3. *`G` fixes `ω`.*
   - `t ω` is admissible: `F_(n+1) = t F_n` contains a ray to `tω`, and `F_(n+1) ⊆ F_n`. So
     `tω = ω`.
   - Each `m ∈ N` lies in some `N_n`. So `m` fixes `F_n` pointwise, and with it a ray to `ω`, so
     `mω = ω`.
   - Hence `G = ⟨N, t⟩` fixes `ω`.
4. *Busemann character.* Let `β = β_ω : G → Z`.
   - `β(N) = 0` by (T5), since torsion elements fix vertices.
   - If `β(t) = 0`, then `β ≡ 0`, so every element of `G` fixes a vertex (T5). `G` is finitely
     generated, so by (T2) `G` has a global fixed vertex, a contradiction.
   - So `β(t) ≠ 0`. Since `G/N ≅ Z`, `ker β = N`. By (T5) every vertex stabilizer lies in
     `ker β = N`.

Step 1 is proved in both cases.

## Step 2: vertex stabilizers are finite or not finitely presented

Let `S = G_v` be a vertex stabilizer and suppose `S` is finitely presented.

1. By Step 1, `S ≤ N`. `S` is finitely generated, so by (I2) `S ≤ N_n ≅ 𝔊` for some `n`.
2. If `S` is infinite, then by (I3) it is commensurable with `𝔊`.
   - Finite presentability passes to finite-index subgroups (Reidemeister–Schreier) and to groups
     containing a finitely presented subgroup of finite index (P. Hall).
   - `𝔊` is not finitely presented (I1), so `S` is not finitely presented, a contradiction.
3. So `S` is finite. ∎

## Step 3: `𝔊` fixes a vertex with an infinite stabilizer

`𝔊` is finitely generated, and every element of `𝔊` has finite order. So by (T1) and (T2) `𝔊`
fixes a vertex `v_*`. The stabilizer `G_(v_*)` contains the infinite group `𝔊`. So by Step 2 it is
not finitely presented. The same holds for every vertex fixed by `𝔊`. ∎

## Step 4: the `FP_2` version

Let `R = Z` or `F_2`.

1. Type `FP_2` over `R` passes to finite-index subgroups and to finite-index overgroups (Brown,
   *Cohomology of Groups*, VIII.5.1).
2. `𝔊` is not of type `FP_2` over `R`.
   - For `R = Z`: type `FP_2` would make `H_2(𝔊; Z)` finitely generated, contradicting (I4).
   - For `R = F_2`: by the universal coefficient theorem,
     `H_2(𝔊; F_2) ⊇ H_2(𝔊; Z) ⊗ F_2`, and the right side is infinite-dimensional by (I4).
     So `H_2(𝔊; F_2)` is not finite-dimensional, and `𝔊` is not `FP_2` over `F_2`.
3. Repeat Step 2 with "`FP_2` over `R`" in place of "finitely presented". Type `FP_2` implies
   finite generation, so steps 2.1 and 2.2 go through unchanged, and Step 3 follows as before. ∎

## Remarks

- **What the proof uses.** Only three properties of `G`:
  - `G` is an ascending HNN extension over a finitely generated base whose kernel `N` is a torsion
    group;
  - every infinite finitely generated subgroup of the base fails to be finitely presented (resp.
    `FP_2`);
  - the base is infinite.

  Any extension with these properties inherits the theorem.
- **Brown's criterion.** On a tree, it needs vertex stabilizers of type `FP_n` and edge
  stabilizers of type `FP_(n−1)` to conclude `FP_n`. By Step 3 it never applies for `n ≥ 2`.
  This covers the Bass–Serre tree of `G` and every other splitting. Examples are any other
  ascending decomposition `G = B' *_(τ)` with base `B' ≤ N`, and any amalgam.
- **Calibration.** `BS(1,2)` violates both inputs: `N = Z[1/2]` is torsion-free, and `Z ≤ N` is
  finitely presented. There Brown's criterion on the Bass–Serre tree does prove `FP_∞`, as it
  should.

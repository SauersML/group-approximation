## Why sufficient

Notation. `e_ij(a)` is the elementary matrix and `[g,h] = g h g^(-1) h^(-1)`. Over every unital ring,

```text
(St1) e_ij(a) e_ij(b) = e_ij(a+b);
(St2) [e_ik(a), e_kj(b)] = e_ij(ab)                    for i, j, k distinct;
(D)   d e_ij(s) d^(-1) = e_ij(a_i s a_j^(-1))           for d = diag(a_1, ..., a_n).
```

**Step 1 (Whitehead).** Put `w(x) = e_12(x) e_21(-x^(-1)) e_12(x)` for a unit `x`. Direct multiplication
gives `w(x) = [[0, x], [-x^(-1), 0]]` and `w(x) w(-1) = diag(x, x^(-1))`. So `diag(x, x^(-1)) in E_2(S)`.
Then

```text
diag(x y x^(-1) y^(-1), 1) = diag(x, x^(-1)) diag(y, y^(-1)) diag((yx)^(-1), yx),
```

so `diag(c, 1, ..., 1) in E_n(S)` for every `c in [S^x, S^x]`. The subgroup `[S^x, S^x]` is
`sigma`-invariant because `sigma` is a ring automorphism.

**Step 2 (transfer).** For admissible `C`, the map

```text
iota : C semidirect_sigma Z -> G_n,     (c, m) |-> (diag(c, 1, ..., 1), m)
```

is an injective homomorphism. Indeed, `sigma` acts entrywise, so
`diag(c,1,..) sigma^m(diag(c',1,..)) = diag(c sigma^m(c'), 1, ..)`, which is the image of the product
`(c,m)(c',l) = (c sigma^m(c'), m+l)`. By `mf-radical-functoriality`,
`iota(U_C) <= Rad_MF(G_n)`.

`U_C` lies in `C x {0}`, and `Rad_MF(G_n)` lies in `E_n(S) x {0}`. Both statements hold because the
projections to `Z` are homomorphisms to a residually finite group, which is MF by
`central-quotients-of-residually-finite-groups-are-mf`.

Put `N = Rad_MF(G_n) cap (E_n(S) x {0})`, regarded as a subgroup of `E_n(S)`. Then `N` is normal in `G_n`,
and hence normalised by `E_n(S)` and by `t`.

**Step 3 (level-ideal lemma).** Let `N <= E_n(S)` be normalised by `E_n(S)`, and put
`J_ij = {a : e_ij(a) in N}` for `i != j`. By (St1), each `J_ij` is an additive subgroup.

Take `i, j, k` distinct. If `e_ik(a) in N`, then

```text
e_ij(ab) = [e_ik(a), e_kj(b)] = e_ik(a) * ( e_kj(b) e_ik(a)^(-1) e_kj(b)^(-1) ) in N.
```

Similarly, if `e_kj(b) in N`, then `[e_ik(a), e_kj(b)] = (e_ik(a) e_kj(b) e_ik(a)^(-1)) e_kj(b)^(-1)`
lies in `N`. Hence

```text
J_ik S <= J_ij,     S J_kj <= J_ij        (i, j, k distinct).
```

With `b = 1` and `a = 1`, this gives `J_ik <= J_ij` and `J_kj <= J_ij`. So one index of a pair can be
replaced by any third index. Because `n >= 3`, every ordered pair is reached from every other by such
moves; for example `(1,2) -> (1,3) -> (2,3) -> (2,1)`. So all `J_ij` equal one set `J`, and the
displayed inclusions make `J` a two-sided ideal.

`E_n(S, J)` is by definition the normal closure in `E_n(S)` of `{e_ij(a) : a in J}`, so it lies in `N`.

If `N` is also normalised by `t`, then `t e_ij(a) t^(-1) = e_ij(sigma(a))` and its inverse give
`sigma(J) = J`.

**Step 4 (unit commutators).** Let `(c,0) in U_C` and `d = diag(c, 1, ..., 1)`. By Step 2, `d in N`.
By (D), for every `s in S`,

```text
[d, e_12(s)] = e_12(c s) e_12(-s) = e_12((c - 1) s),
```

and this lies in `N`, because `N` is normal. With `s = 1`, `c - 1 in J(N)`. So `I_C <= J(N)`.

**Step 5 (the four items).**
1. `J(N)` is a `sigma`-invariant ideal containing `I_C`, and `E_n(S, J(N)) <= N <= Rad_MF(G_n)`. The
   ideal `I_C` itself is `sigma`-invariant. Its generating set `{c - 1}` is `sigma`-stable, because
   `U_C` is normal in `C semidirect Z` and `t (c,0) t^(-1) = (sigma(c), 0)`.
2. If `I_C = S`, then `e_ij(S) <= N`, so `E_n(S) x {0} <= Rad_MF(G_n)`. The reverse inclusion is from
   Step 2.
3. If `U_C != 1`, pick `(c,0) in U_C` with `c != 1`. Then `J(N)` is a nonzero `sigma`-invariant ideal,
   and it equals `S` by `sigma`-simplicity. Conclude as in 2.
4. Write `u_h = sum_i 1_(V_i) u_(gamma_i)` for `h in [[Gamma]]`, where the `V_i` form a clopen partition on
   which `h = gamma_i`. Then `u_h f u_h^(-1) = f o h^(-1)` for `f in LC(Y,k)`. Let `V` be clopen with
   `h(V) cap V = empty`. Then

   ```text
   1_V (u_h - 1) 1_V = 1_V 1_(h(V)) u_h - 1_V = -1_V,
   ```

   so `1_V in I_C` whenever `(u_h,0) in U_C`. Each point of `Y` is moved by some such `h`, so it has a clopen
   neighbourhood displaced by `h`, and every clopen subset of a displaced set is displaced. By
   compactness, `Y` has a finite clopen partition `W_1, ..., W_r` into displaced sets. Hence
   `1 = sum 1_(W_q) in I_C`. Conclude as in 2.

**Step 6 (consequences).**

*(C1).* Let `S` be finitely generated by `s_1, ..., s_r`.
- `E_3(S)` is generated by the `e_ij(+-s_l)`, the `e_ij(1)` and their commutators. By (St1) and (St2),
  the set of `a` with `e_ij(a)` in the generated subgroup for all `i != j` contains `1` and the `s_l`, and is closed under sums and products.
- It is Kazhdan by `ershov-jaikin-kassabov-steinberg-groups-have-property-t`, since `n = 3` and `S` is a
  finitely generated associative ring.
- It is LEF. Take a finite set `F` of `GL_3(S)`, closed under inverses. Take a finite window of `S` that
  contains all entries of `F` and all partial sums and products that compute the entries of products in
  `F F`. Embed this window exactly and injectively in a finite ring `R`. Entrywise, this gives an injective
  map `F -> M_3(R)` that respects every product in `F F` landing in `F`. Each image is invertible, since
  `g g^(-1) = 1` is among those products. So `F` embeds as a partial group in the finite group `GL_3(R)`.
- It is nontrivial, since `e_12(1) != 1` in the nonzero ring `S`.

Item 2 gives `Rad_MF = E_3(S) x {0}`, contradicting (EKL1).

*(C2), finite quotient rings.* Let `M` be an ideal of finite index `m > 1`. A finitely generated ring has
only finitely many ideals of each finite index, because a quotient map to a ring of order `m` is fixed by
the images of the generators. So `sigma` permutes the ideals of index `m`, and the intersection `M'` of the
finite `sigma`-orbit of `M` is a proper, `sigma`-invariant ideal of finite index. Then `G_n` maps to
`E_n(S/M') semidirect Z`. This group is finite-by-`Z` with a finite-order twist, hence virtually
`finite x Z`, hence residually finite, hence MF by `central-quotients-of-residually-finite-groups-are-mf`.
The map is nontrivial on `e_12(1)`, so `e_12(1)` is not in `Rad_MF(G_n)`.

If `S` is residually finite, apply this to the invariant ideals `M'_m` given by the intersection of all
ideals of index at most `m`. These separate points of `S`, so the maps to the groups
`E_n(S/M'_m) semidirect Z` separate points of `G_n`. So `G_n` is residually finite and `Rad_MF(G_n) = 1`.
For `k[Gamma]` with `k` a finite field or `Z`, the augmentation (followed by `Z -> F_2` when `k = Z`) is a
finite quotient ring.

*(C2), amenable and ambient-inner.*
- If `C` is amenable, then so is the countable group `C semidirect Z`. By `amenable-implies-operator-mf` it
  is MF, so `U_C = 1`.
- If `sigma^r = Ad(w)` with `w` a unit of a LEF ring `S' >= S`, then `phi^r = Ad(diag(w,...,w))` on
  `E_n(S)`, inside `GL_n(S')`. That group is LEF by the window argument above, so `G_n` is LEF by (C) of
  `quotient-permuting-and-ambient-inner-mapping-tori-are-lef`. LEF groups are MF by `lef-implies-operator-mf`, so `Rad_MF(G_n) = 1` and
  `U_C = 1`.

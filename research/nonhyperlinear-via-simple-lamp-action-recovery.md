Let `W_K=A5^(G/Gamma) semidirect G` for the pinned Kun--Thom pair.  If `W_K`
were hyperlinear, the recovery claim would make `G action G/Gamma` sofic,
contradicting `coordinate-action-not-sofic`.  Hence `W_K` would be
non-hyperlinear.

The group is finitely generated: `G` is finitely generated, the action on
`G/Gamma` is transitive, and one finite generating set of the lamp `A5` at
the base coset normally generates all lamp coordinates.

**ESTABLISHED** by `fw-inputs-pass-window-zero-only-via-proper-self-embeddings-proof`. Lane proof, elementary modulo the Delorme–Guichardet theorem (property (T) implies property FH), which is used and not reproved. Not independently reviewed. No priority is claimed. Cornulier (arXiv:1901.05065, Prop. "FWcomp", read at source) proves that FW groups have finitely stably realizable completable near actions; the index formula of item 1 is a different statement and was not found there.

## Setting

- `P` is generated by a finite symmetric set `S` and has property FW: every commensurated subset of every `P`-set is transfixed. This means that if `gM △ M` is finite for all `g`, then some `P`-invariant `M'` has `M △ M'` finite.
- Every group with property (T) has FW; the two-line proof is in the route.
- `rho: P -> Sym(N)` is a genuine action whose near action is faithful (every `g != 1` moves infinitely many points), as in `genuine-action-shell-envelopes-generalize-the-regular-shell`. `s: n ↦ n+1`.
- **Window zero with sign `eps` ∈ {1, −1}** means `s^-eps rho(P) s^eps ⊆ rho(P)` in `NearSym(N)`. This is the case `N = 0` of `shell-ascending-gate-is-a-finite-window-inclusion`. Because the near action is faithful, it determines an injective endomorphism `psi` of `P` with `s^-eps rho_g s^eps = rho_(psi(g))` near infinity for every `g`.
- For an endomorphism `alpha`, write `rho∘alpha` for the `P`-set `(N, g ↦ rho_(alpha(g)))`. Write `Fin(rho∘alpha)` for the union of its finite orbits and `I(rho∘alpha)` for the union of its infinite orbits.

## Statement

1. **Index formula.** Let `X`, `Y` be `P`-sets and `f: X ⇀ Y` a near-equivariant partial bijection, with cofinite domain and image and `f(gx) = g f(x)` off a finite set for each `g ∈ S`. Then there are finite `P`-invariant sets `F_X ⊆ X` and `F_Y ⊆ Y`, and a `P`-equivariant bijection `e: X \ F_X -> Y \ F_Y` agreeing with `f` off a finite set. So

       ind(f) = |Y \ im f| - |X \ dom f| = |F_Y| - |F_X|.

2. **One end.** Every infinite orbit of every `P`-set has a one-ended Schreier graph.
3. **Sign +1 is impossible.** If window zero holds with `eps = 1`, for any injective endomorphism `psi`, then every orbit of `rho` is finite.
4. **Sign −1 needs a proper self-embedding.** Suppose window zero holds with `eps = −1` and `rho` has an infinite orbit. Then:
   - `Fin(rho)` is finite;
   - `|Fin(rho∘psi^m)| = |Fin(rho)| + m` for every `m >= 0`;
   - `psi` is not an automorphism, and `[P : psi(P)] = ∞`.
5. **Simple inputs.** Let `P` also be infinite with no proper subgroup of finite index, for example infinite simple. Then window zero forces all of the following:
   - `eps = −1`;
   - `psi` injective with `[P : psi(P)] = ∞`;
   - `psi^m(P)` fixes exactly `|Fix(rho)| + m` points of `N`;
   - there is a nested sequence of points `z_1, z_2, ...` of one infinite orbit, one new point per power of `psi`, with each `psi^m(P)` fixing an initial segment `{z_1, ..., z_i}` and acting transitively on the rest of every orbit.

   If `rho` has finitely many orbits, `P` acts highly transitively on one of them.
6. **Corollaries.**
   - For FW inputs with an infinite orbit, no automorphism twist of any order passes window zero, with either sign, whatever the orbit types.
   - For the reduced inputs of `boone-higman-iff-simple-kazhdan-decidable-inputs`, which are infinite simple Kazhdan groups, the genuine-action shell needs window `N >= 1`. The one exception is a highly transitive, self-similar action through a proper self-embedding of infinite index, as in item 5.

## How this closes the two gaps of `one-ended-schreier-orbits-force-index-zero`

- **Orbits with infinitely many ends.** They do not occur for FW inputs, by item 2. No structure tree is needed: a set of vertices with finite coboundary in a Schreier graph is a commensurated subset of the orbit, so FW transfixes it.
- **One-ended non-free orbits.** No germ is needed: item 1 computes the index globally, and the bookkeeping of finite orbits in items 3–4 does the rest.

For inputs without FW, the non-free one-ended case of that node stays open.

## Calibrations

- **`Z` (not FW).** The zigzag regular action passes window zero with index 1. It violates item 1: the orbit has two ends, so its end sets are commensurated and not transfixed.
- **`Z^2` (not FW).** The eventually periodic window-zero actions of `eventually-periodic-genuine-shell-actions-give-fp-envelopes` have all orbits finite, consistent with item 3 even there.
- **Regular actions of FW inputs.** These are free, so every `psi^m(P)`-orbit is infinite and `Fin(rho∘psi^m) = ∅`. Item 4 then forbids `eps = −1`, and item 3 forbids `eps = 1`. This recovers `one-ended-shell-inputs-admit-no-shift-normalizing-enumeration` for FW inputs.

## Scope and what is not claimed

- Nothing is claimed about window `N >= 1`, about finite presentation of `R_rho`, `Q_rho` or `E_rho`, or about actions whose orbits are all finite. The last case can only occur for residually finite `P`.
- **The surviving configuration of item 5 is not excluded.** Highly transitive faithful actions of Kazhdan groups exist in general; Hull–Osin constructs them for acylindrically hyperbolic groups, a result recalled and not read. Whether a simple Kazhdan group has a highly transitive action in which a point stabilizer contains an infinite-index copy `psi(P)` acting on the complement as `P` acts on the whole orbit is open.
- If that self-similar configuration were constructed with `P` finitely presented, `R_rho ≅ P *_psi` would be finitely presented and would pass the ascending gate with window zero. Finite presentation of the one-point stabilizers `S(M, M')` would still have to be checked.

Notation as in the claim: `Gamma = B*_phi`, `t^-1 b t = phi(b)`, `phi` injective.

**Standard facts about `Gamma`.** `B` embeds in `Gamma` (Britton's lemma). Since
`t^-1 B t = phi(B) <= B`, conjugation gives `B <= t B t^-1`, so
`B <= tBt^-1 <= t^2 B t^-2 <= ...`. Every element of `Gamma` can be written
`t^i b t^-j` with `i, j >= 0` and `b in B`. Its image under the map
`Gamma -> Z`, `B -> 0`, `t -> 1`, is `i - j`. So the kernel `N` of this map is
the increasing union `N = U_{i >= 0} t^i B t^-i`, it is the normal closure of
`B`, and `Gamma / N ≅ Z` is generated by the image of `t`.

**Item 1.** Let `pi: Gamma -> Q` be onto a torsion group. Write `Bbar = pi(B)`
and `tbar = pi(t)`, and let `m >= 1` be the order of `tbar`. Applying `pi` to the
chain gives `Bbar <= tbar Bbar tbar^-1 <= ... <= tbar^m Bbar tbar^-m = Bbar`, so
every inclusion is an equality. Hence `pi(N) = U_i tbar^i Bbar tbar^-i = Bbar`.
Since `N` is normal in `Gamma` and `pi` is onto, `Bbar` is normal in `Q`. The
quotient `Q / Bbar` is the image of `Gamma / N ≅ Z`, generated by the class of
`tbar`, whose order divides `m`, so `|Q : Bbar|` divides `m`. For `b in B`,
iterating the defining relation gives `t^-m b t^m = phi^m(b)` in `Gamma`.
Applying `pi` and using `tbar^m = 1` gives `pi(b) = pi(phi^m(b))`. So every
`b^-1 phi^m(b)` lies in `ker pi`, hence so does their normal closure `M_m` in
`B`, and `pi|_B` factors through `B_{phi^m} = B / M_m`.

**Item 2.** First, `phi(M_m) <= M_m`: `phi(b^-1 phi^m(b)) = phi(b)^-1 phi^m(phi(b))`
is a generator of `M_m`, and `phi(g h g^-1) = phi(g) phi(h) phi(g)^-1` with
`phi(g) in B`. So `phi` induces an endomorphism `phibar` of `B/M_m`. Also
`phibar^m(bM_m) = phi^m(b) M_m = b M_m`, so `phibar^m = id` and `phibar` is an
automorphism of order dividing `m`. Let `H = (B/M_m) x| <s>` with `s` of order
`m`, where `s^-1 x s = phibar(x)`. This is a semidirect product by `Z/m`, since
the action `x -> s x s^-1 = phibar^-1(x)` has order dividing `m`.

- `Gamma -> H`, `b -> bM_m`, `t -> s`, respects `t^-1 b t = phi(b)`, so it is a
  homomorphism. It kills `t^m`, so it induces `alpha: Gamma/<<t^m>> -> H`.
- `H -> Gamma/<<t^m>>`, `bM_m -> bbar`, `s -> tbar`, is well defined:
  `b^-1 phi^m(b) = b^-1 t^-m b t^m` dies modulo `<<t^m>>`, so `M_m` dies too. It
  respects the relations of `B/M_m`, `s^m = 1`, and `s^-1 x s = phibar(x)`, so it
  is a homomorphism `beta`.
- `beta alpha` and `alpha beta` fix the generators, so they are the identity.

Hence `Gamma / <<t^m>> ≅ B_{phi^m} x| Z/m`.

**Item 3.** Suppose `Q` is an infinite torsion quotient of `Gamma`, and let `m`
be the order of `pi(t)`. By item 1, `Bbar` has finite index in `Q`, so `Bbar` is
infinite. Also `Bbar` is a quotient of `B_{phi^m}`, so `B_{phi^m}` is infinite.
This direction does not use that `B` is torsion.

Conversely, let `B` be torsion and `B_{phi^m}` infinite. Then `B_{phi^m}` is
torsion, as a quotient of `B`. In `B_{phi^m} x| Z/m`, every element `x s^j`
satisfies `(x s^j)^m in B_{phi^m}`, so it has finite order. By item 2 this group
is `Gamma/<<t^m>>`, an infinite torsion quotient of `Gamma`. If `Gamma` is
finitely presented, then so is its quotient by the normal closure of one
element. Finite-index subgroups of finitely presented groups are finitely
presented (Reidemeister–Schreier), so `B_{phi^m}` is finitely presented too.

## 0. Imports

- **(M)** `kazhdan-torsion-free-tarski-monster-satisfies-kk`, Theorem items 1--2 and its
  Corollary. These rest on the verbatim import of Olshanskii--Osin--Sapir, *Lacunary hyperbolic
  groups*, arXiv:math/0701365, theorem `ExoticQuotients` part 2, quoted in that node's proof.
  The facts used are these. Let `G` be a torsion-free non-cyclic hyperbolic group with finite
  generating set `S`. Then `G` has a quotient `Q` that is infinite, non-abelian and torsion-free,
  and all of whose proper subgroups are cyclic. Moreover `Q` is the limit of a sequence of
  surjections `G = G(0) -> G(1) -> ...`, each `G(i)` torsion-free hyperbolic (invariant (I1)
  there). If `G` is a torsion-free cocompact `Sp(n,1)` lattice, `n >= 2`, then `Q` is Kazhdan,
  as a quotient of a Kazhdan group.
- **(L)** `local-approximation-properties-are-marked-closed`, Theorem items 1 and 3, applied to
  soficity. Soficity is hereditary. In the space of `k`-generated marked groups it is closed: if
  `H` is not sofic, there is a radius `R` such that every marked group with the same relations of
  length `<= R` as `H` is not sofic.
- **(P)** `torsion-free-hyperbolic-kazhdan-partner-exists`: a torsion-free cocompact lattice
  `Gamma` in `Sp(n,1)`, `n >= 2`, exists (Selberg's lemma). It is non-elementary hyperbolic,
  hence non-cyclic, and Kazhdan.
- **(A)** Textbook fact: an amenable group with property (T) is compact, so a discrete one is
  finite. Reference: Bekka--de la Harpe--Valette, *Kazhdan's Property (T)*, Cambridge 2008,
  Theorem 1.1.6. Also standard: a group containing a finite-index infinite cyclic subgroup is
  amenable, since amenability passes to finite extensions.

Fix `Gamma` from (P) and a monster quotient `Q` of it from (M), with its stages `G(i)`. Write
`S` for the image of a fixed finite generating set of `Gamma`.

## 1. Item 1: no proper finite-index subgroup

By (M), `Q` is infinite, torsion-free, finitely generated by `S`, and Kazhdan.

Let `H < Q` be a proper subgroup of finite index. By (M), `H` is cyclic. `H` has finite index in
the infinite group `Q`, so `H` is infinite, and `H ~= Z`. Then `Q` has a finite-index subgroup
isomorphic to `Z`, so `Q` is amenable. By (A), the Kazhdan amenable discrete group `Q` is finite,
which contradicts infinitude. Hence `Q` has no proper finite-index subgroup.

A nontrivial finite quotient `Q -> F` would have a proper finite-index kernel. So `Q` has no
nontrivial finite quotient.

## 2. Item 2: soficity transfers from the stages

Let `pi : F(S) -> Gamma` be the marking, and put `N_i = ker(F(S) -> G(i))` and
`N = ker(F(S) -> Q)`. The maps `G(i-1) -> G(i)` are surjective quotient maps, and `Q` is their
direct limit. So `N_0 <= N_1 <= ...` and `N = union_i N_i`.

For a radius `R`, the ball `B_R` of `F(S)` is finite. Each `w in B_R ∩ N` lies in some `N_i`, so
there is `i(R)` with `B_R ∩ N = B_R ∩ N_i` for all `i >= i(R)`. The inclusion
`B_R ∩ N_i ⊆ B_R ∩ N` always holds. Hence `(G(i), S) -> (Q, S)` in the space of marked groups.

Suppose every `G(i)` is sofic and `Q` is not. By (L) there is a radius `R` such that every marked
group with the same relations of length `<= R` as `Q` is not sofic. Taking `i >= i(R)` gives a
nonsofic `G(i)`, a contradiction. So `Q` is sofic.

Each `G(i)` is torsion-free hyperbolic by (M), and Kazhdan as a quotient of `Gamma`.

## 3. Item 3: the dichotomy

Suppose (NSH) fails. Then every torsion-free hyperbolic Kazhdan quotient of `Gamma` is sofic, in
particular every stage `G(i)`. By §2, `Q` is sofic. By §1, `Q` is infinite, finitely generated,
torsion-free and Kazhdan, with no nontrivial finite quotient. So `Q` witnesses (SQK).

If (NSH) holds, some `G(i)` is a nonsofic hyperbolic group, which is `nonsofic-hyperbolic-group`.

## 4. Scope

- The argument works for **every** Olshanskii--Osin--Sapir monster quotient of `Gamma`, not only
  the parameter choice of the Kadison--Kaplansky node. It uses only (I1), the conclusions
  "proper subgroups cyclic, torsion-free, infinite", and the direct-limit description.
- By §2, a lemma "the stages `G(i)` are sofic" is enough. It need not hold for all hyperbolic
  groups.
- Nothing about MF-ness, finite presentation or mapping tori of `Q` is used or claimed.
- Not Lean-verified.

**ESTABLISHED (proof in `rational-affine-rn-groups-over-type-f-hosts-are-f-infinity-proof`; lane proof, w15-101;
not independently reviewed).** Imported: Skipper–Witzel–Zaremsky, *Simple groups separated by finiteness
properties*, Invent. Math. 215 (2019), arXiv:1712.05361v3, Theorem 4.15, Lemma 5.3 and Theorem 5.8 (read from the
arXiv PDF on 2026-09-19), and Brown's criterion. Part (5) is OPEN.

## Setting

- `p` is a prime, `m > 1` an integer prime to `p`, `P_m` the set of primes dividing `m`, and
  `U_m = ⟨ℓ : ℓ ∈ P_m⟩ ≤ Q^×_{>0}`, and `U_0` is a subgroup of `Z[1/m]^× = ⟨-1⟩ × U_m`. `BT_ℓ` is the
  `(ℓ+1)`-regular Bruhat–Tits tree of `Q_ℓ`.
- `H(m, U_0) = Z[1/m] ⋊ U_0` acts on `Z_p` by `x ↦ ux + b`. This is a faithful, finite-state, self-similar action on
  the `p`-regular tree `T_p`; each section of `x ↦ ux + b` is `x ↦ ux + b'` with the same `u` and `b' ∈ Z[1/m]`.
- **Main example.** `BS(1,2) = ⟨x + 1, 2x⟩ = Z[1/2] ⋊ ⟨2⟩ = H(2, U_2)` on `Z_3`.
- **Open example.** `H_* = H(6, ⟨2/3⟩) = Z[1/6] ⋊ ⟨2/3⟩` on `Z_5`. It is generated by `t = x + 1` and
  `a = (2/3)x`.

## Statement

1. **`V_3(BS(1,2))` is of type `F_∞`.** `BS(1,2)` is of type `F`, and it is self-similar on `T_3`. SWZ Theorem 4.15
   says that type `F_n` passes from a self-similar `G ≤ Aut(T_d)` to `V_d(G)`.
2. **Full-rank hosts.** If `U_0` has finite index in `U_m`, or in `⟨-1⟩ × U_m`, then `H(m, U_0)` is of type `F_∞`. So
   `V_p(H(m, U_0))` is of type `F_∞`. This includes `V_p(Aff(Z[1/m]))`, for every prime `p ∤ m`.
   - The host acts cocompactly on the product `∏_{ℓ ∈ P_m} BT_ℓ` of Bruhat–Tits trees.
   - Its cell stabilisers are infinite cyclic (or infinite dihedral when `-1 ∈ U_0`).
3. **Corrections to two staged nodes.**
   - (a) `rational-affine-rn-groups-are-not-k-graph-full-groups`, section "Open", says the finiteness of
     `V_p(Z[1/m] ⋊ U_0)` needs a decorated Stein–Farley complex. By (2) this is not true for full-rank `U_0`, and in
     particular not for `V_3(BS(1,2))`. The complex is needed only when `rank U_0 < |P_m|`.
   - (b) `rn-lamplighter-is-a-function-field-stein-group` calls `Aff(Z[1/6])` a group "of length `2`". By (2) it is
     `F_∞`. The contrast with Bux's `Aff(F_q[t, 1/t, 1/(t-1)])` (`F_2`, not `F_3`) is a function-field phenomenon:
     over `Q` the archimedean place gives no Σ-obstruction.
4. **The open host is outside every known criterion.** For `H_*` on `T_5`:
   - `H_*` is finitely generated, finite-state and faithful.
   - It is **not** `FP_2`. By Bieri–Strebel, an `FP_2` metabelian group mapping onto `Z` is an ascending HNN
     extension over a finitely generated base. Here the base would be a finitely generated subgroup of `Z[1/6]`,
     so `6^{-k} Z`. Neither `2/3` nor `3/2` maps such a subgroup into itself. So Scott (FP1) and SWZ 4.15 do not
     apply.
   - It is **not contracting**. Sections preserve the multiplier, so `a^n` has infinitely many distinct multipliers
     `(2/3)^n` among its sections. So Nekrashevych (FP2) does not apply.
   - The action is **not persistent**: `t` fixes no digit. So SWZ 5.8 gives no obstruction.
   - `N ≠ K_∞`, checked by computer (artifact above). The BS relator `a t^3 a^{-1} t^{-2}` and the metabelian
     relators `r_k = [t, a^k t a^{-k}]` for `k = 1, …, 4` lie in `N ∖ K_∞`: each one has a nonempty section at every
     depth. So the lamplighter-type route (`N = K_∞`, from `rover-nekrashevych-fp-iff-finite-lift-presentation`)
     does not apply. This is no obstruction: the same test also gives `N ≠ K_∞` for `BS(1,2)` on `T_3`, where
     `V_3` is `F_∞` by (1).
   - **Same group, other tree.** SWZ Lemma 5.3 turns the action on `T_5` into a faithful, finite-state,
     persistent action of `H_*` on `T_6`. Then `V_6(H_*)` is **not** finitely presented, by SWZ 5.8 or
     `persistent-automata-rn-group-fp-iff-group-fp`.
5. **Open: is `V_5(H_*)` finitely presented?** `V_5(H_*)` is the group of self-homeomorphisms of `Z_5` that are
   piecewise `x ↦ ux + b` on finitely many balls, with `u ∈ ⟨5, 2/3⟩` and `b ∈ Z[1/30]`. This is the Cantor analogue of
   the Bieri–Strebel compact-interval question:
   - `G([0,b]; A, P)` with `Aff(A, P)` not finitely presented (memoir arXiv:1411.2868, Chapter D, Prop. 3 and the
     remark after it);
   - no example of that kind there is known to be finitely generated but not finitely presented.
   - A positive answer would need a decorated Stein–Farley complex. It would be decorated by the horocyclic product of
     `BT_2` and `BT_3` on which `H_*` acts, with the 5-adic splitting as the Stein move.

## Consequence for the target

`rover-nekrashevych-finite-presentation-criteria` asks which `H` give finitely presented `V_d(H)`. Over `Q`, every
affine host of full unit rank gives `F_∞` by transfer. The first rational affine case that the known criteria (FP1,
FP2, SWZ 4.15 and 5.8, `N = K_∞`) leave undecided is `V_5(Z[1/6] ⋊ ⟨2/3⟩)`.

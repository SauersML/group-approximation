## Setting

As in `split-finitary-sl-q-extensions-are-not-fp`: `X` is countable, `V = Q^(X)`, `Mon(X)` is
the group of monomial matrices `m e_x = mu_m(x) e_(σ_m x)`, and `GL_X(Q)` and `SL_X(Q)` are the
finitary groups. Let `Γ <= GL(V)` be generated by `g_j = m_j f_j`, `j = 1, ..., k`, with
`m_j ∈ Mon(X)` and `f_j ∈ GL_X(Q)`. Let `M = ⟨m_1, ..., m_k⟩` act on `X` through `σ`. For
`x ∈ X` write `M_x = {h ∈ M : σ_h x = x}` and `χ_x : M_x -> Q^x`, `χ_x(h) = mu_h(x)`. This is a
homomorphism.

## Statement

1. **Normal form.** Suppose `M` has finitely many orbits on `X`, with base points
   `x_1, ..., x_r`. Then some diagonal matrix `δ` makes every element of `δ^-1 Γ δ` a
   column-finite matrix. Its entries lie in the subring of `Q` generated by
   `χ_(x_1)(M_(x_1)) ∪ ... ∪ χ_(x_r)(M_(x_r))` and finitely many further rationals.
2. **Orbits.** If `SL_X(Q) <= Γ`, then `M` has finitely many orbits on `X`.
3. **Wild stabilizers.** If `SL_X(Q) <= Γ`, then some point stabilizer `M_x` has
   `χ_x(M_x)` not finitely generated. In particular `M_x` has an infinitely generated abelian
   quotient, so `M_x` is not finitely generated.
4. **Tame monomial parts are excluded.** If `M` has finitely many orbits and finitely
   generated point stabilizers, then `δ^-1 Γ δ` has all entries in `Z[1/N]` for some `N`.
   Then `Γ` contains no family `{1 + q y : q ∈ Q}` with `y ≠ 0`. So it contains neither
   `SL_X(Q)` nor any `GL_n(Q)` embedded linearly (`g ↦ 1 - ρ(1) + ρ(g)` for an injective
   ring map `ρ : M_n(Q) -> End(V)`).

## Consequences

- Monomial parts coming from actions with finitely generated stabilizers cannot supply the
  denominators of `Q`. This covers Houghton groups, `F`, `T`, `V` and `nV` on dyadic orbits,
  `BS(1,m)` on `Z[1/m]`, and regular actions of any finitely generated group. The divisibility
  of `GL_n(Q)` can only come through the weights of a point stabilizer whose weight character
  has image involving infinitely many primes.
- Both examples in `split-finitary-sl-q-extensions-are-not-fp` show this: the stabilizer is
  a free abelian group of infinite rank (the Euler diagonals, or Baumslag's `A`). Together with
  that node, a finitely presented host of this shape must be non-split and must have wild
  stabilizers.

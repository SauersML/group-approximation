## Setting: corner constraint systems

Let `Gamma` be a countable group, `J` a central element of finite order `n`,
and `omega` a faithful character of `<J> = Z/n`. Put

```text
p_omega = (1/n) sum_(k=0)^(n-1) conj(omega(J^k)) J^k   in C[Gamma].   (GC1)
```

This is a central projection. A *corner constraint system* over
`(Gamma, J, omega)` is a finite family of contexts, each a finite abelian
subgroup `A_c <= Gamma` with a chosen finite generating set. A *model* is a
tracial state `tau'` on the corner `p_omega C*(Gamma) p_omega`. Answers in
context `c` are characters `chi` of `A_c`, with answer projections

```text
e_chi = (1/|A_c|) sum_(a in A_c) conj(chi(a)) a p_omega                (GC2)
```

and answer distribution `mu_c(chi) = tau'(e_chi)`. The system is
algebraically satisfiable when `p_omega != 0`.

Examples: binary linear constraint systems (the solution group, `n = 2`,
contexts generated by a row's variables and `J`); linear systems over `Z_d`;
coset systems after an affine relabeling
(`relabelable-coset-systems-are-solution-group-corners`); and any finite set
of commuting-observable contexts inside a finitely presented group that also
uses nonabelian ancilla relations.

## (CS1) The canonical model has coset support in every context

If `J` has order exactly `n` in `Gamma`, then `p_omega != 0` and

```text
tau_omega(x) = n tau_Gamma(p_omega x p_omega)                          (GC3)
```

is a tracial state on the corner, where `tau_Gamma` is the canonical trace.
For every finite abelian subgroup `A <= Gamma`,

```text
mu_A(chi) = |A cap <J>| / |A|   if chi = omega on A cap <J>,
mu_A(chi) = 0                   otherwise.                             (GC4)
```

So in every context the canonical model answers uniformly on the coset
`X_A(omega) = {chi in A^ : chi = omega on A cap <J>}`.

## (CS2) Affine decoders force affine-safe source supports

Let `B` be a finite Boolean constraint system: variables `v`, contexts
`V_c`, allowed sets `C_c subseteq F_2^(V_c)`. An *exact trace-level compiler
with affine decoding* from `B` into a corner system over `(Gamma, J, omega)`
consists of, for each source context `c`, a target context `A_(t(c))` and a
map `D_c : A_(t(c))^ -> F_2^(V_c)` such that:

1. `D_c` is affine: `chi -> D_c(chi) - D_c(chi_0)` is a group homomorphism;
2. for **every** model `tau'` of the target, the source observables

   ```text
   X_v = sum_chi (-1)^(D_c(chi)_v) e_chi                               (GC5)
   ```

   computed in any context `c` containing `v` agree across contexts, and the
   assignment `v -> X_v` is a perfect tracial model of `B` in the GNS
   representation of `tau'`.

If such a compiler exists and `J` has order exactly `n`, then `B` has a
perfect tracial model whose support in every context `c` is the affine set

```text
S_c = D_c(X_(A_(t(c)))(omega)) subseteq C_c.                          (GC6)
```

In particular `Aff_F2(S_c) = S_c subseteq C_c` for every `c`, which is
condition (LAS1) of `locally-affine-support-bcs-is-exactly-the-lcs-boundary`.

## Consequences and scope

- If every perfect tracial model of `B` has some context whose support has
  affine hull outside the allowed set, then no exact trace-level compiler
  with affine decoding sends `B` into an algebraically satisfiable corner
  system of **any** kind. `matrix-conj-forces-unsafe-support` supplies such a
  tracial, non-`R^U` source.
- So moving the target from binary linear systems to `Z_d` systems, to
  nonabelian ancilla relations, or to infinite ambient groups adds nothing
  once the decoder is affine and exact on every trace.
- Three escape routes remain, and this claim covers none of them:
  1. non-affine decoders, where source involutions are realized by elements
     of the corner algebra that are not signed group elements (the situation
     of `non-ru-bcs-is-satisfiable-in-a-group-factor`);
  2. decoders that are exact or approximate only on Connes-embeddable target
     models, as in the noisy long-code compilers of Taller--Vidick, which
     lose perfect completeness (`notes/FALSE_PERFECT_COMPLETENESS_MASK_NO_GO.md`);
  3. target algebras that are not central-character group corners.

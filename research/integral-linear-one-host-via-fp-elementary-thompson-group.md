`G_D^E = E(Z; D) ⋊ F` is finitely presented with solvable word problem and contains every
`GL_n(Z)`. If it embeds in a finitely presented simple group, so does every `GL_n(Z)`. ∎

This is an instance of `boone-higman-conjecture` for one explicit finitely presented
input, which is neither linear nor residually finite. So Zaremsky's self-similar affine
method does not apply to it.

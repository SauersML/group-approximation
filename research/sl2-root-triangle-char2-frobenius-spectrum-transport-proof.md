From `kazhdan-hyperbolic-sl2-root-triangles` we use only the data: `A_1 = A_2 = SL_2(k)`, `A_3 = SL_2(F)`,
the six embeddings, and the colimit `Λ`. All vertex groups are simple (`q >= 8`) and generated by their two
edge groups.

**Step 0. Nontrivial means vertex-injective; characteristic ≠ 2 gives dimension >= q - 1.**
- Suppose `ρ|_{A_1}` is trivial. Then `E_12` and `E_13` map trivially, so `ρ(A_2) = ρ(<E_12, E_23>)` is the
  image of the abelian group `E_23`. It is also a quotient of the simple group `A_2`, hence trivial. Likewise
  `ρ(A_3)` is trivial, so `ρ` is trivial. The same argument works from any vertex. So a nontrivial `ρ` is
  nontrivial, hence injective, on every vertex group.
- Suppose `char K ≠ 2`, and extend `K` to be algebraically closed. `ρ(u(k))` is a commuting family of
  involutions, hence diagonalizable, and splits `M` into characters of `(k,+)`.
  - A nontrivial character occurs, since `ρ(u(k)) ≠ 1`.
  - Conjugation by `diag(t, t^{-1})`, `t ∈ k^*`, carries `u(y)` to `u(t^2 y)`. The characters of `(k,+)` are
    `y ↦ χ(cy)` with `c ∈ k` for one fixed nontrivial `χ`, and squaring is onto `k^*`. So the set of
    occurring characters contains all `q - 1` nontrivial ones, and `d >= q - 1`.

From now on `char K = 2` and `K ⊇ F`. Extending `K` does not change anything below.

**Step 1. Frobenius expansion.** Fix a parametrization `p` and put `ρ(p(y)) = Σ_{m=0}^{q-1} y^m R_m`.
- The `R_m ∈ End(M)` are unique: by Lagrange interpolation, the functions `y ↦ y^m`, `0 <= m < q`, form a
  `K`-basis of the functions `k -> K`.
- `y = 0` gives `R_0 = 1`.
- Expand `ρ(p(y)) ρ(p(y')) = ρ(p(y + y'))`. By Lucas's theorem, `(y+y')^n = Σ_{m ⪯ n} y^m y'^{n-m}`, where
  `m ⪯ n` means the binary digits of `m` are a subset of those of `n`.
- The functions `y^m y'^{m'}` with `m, m' < q` form a basis of the functions `k × k -> K`. Comparing
  coefficients:
  - `R_m R_{m'} = R_{m+m'}` if `m` and `m'` have disjoint binary digits;
  - `R_m R_{m'} = 0` otherwise.
- Put `X_a = R_{2^a}` and `X_T = Π_{a ∈ T} X_a` for `T ⊆ Z/f`. Then the `X_a` commute, `X_a^2 = 0`, and
  `R_{m_T} = X_T` with `m_T = Σ_{a ∈ T} 2^a`. So

```text
ρ(p(y)) = Σ_T y^{m_T} X_T = Π_a (1 + y^{2^a} X_a).
```

  Conversely, any such product expansion is this one, so the `X_a` are unique.

**Step 2. Torus weights.** Each standard `p` has a torus `g_t ∈ A_i`, `t ∈ k^*`, with
`g_t p(y) g_t^{-1} = p(t^{2ε} y)` and `ε = ±1`:
- `d_t = diag(t, t^{-1})` for `u`, with `ε = 1`;
- `d_t` for `v`, with `ε = -1`;
- `d_t` for `y ↦ v(sy)`, with `ε = -1`.

Comparing coefficients gives `ρ(g_t) X_T ρ(g_t)^{-1} = t^{2ε m_T} X_T`. The exponents `m_T`, `T ≠ ∅`, are
the integers `1, ..., q-1`. They are distinct mod `q - 1`, and `2` is invertible mod the odd number `q - 1`.
So the characters `t ↦ t^{2ε m_T}` of the cyclic group `k^*` are pairwise distinct, and weight vectors for
distinct characters are linearly independent. Consequences:
- **(W1)** The nonzero `X_T`, `T ≠ ∅`, are linearly independent.
- **(W2)** Put `𝔞_p = span{ ρ(p(y)) - 1 : y ∈ k }`. Then `𝔞_p = ⊕_{T ≠ ∅} K X_T`, because the functions
  `y^m`, `1 <= m < q`, are linearly independent. Also `𝔞_p^2 = ⊕_{|T| >= 2} K X_T`, because
  `X_T X_{T'} = X_{T ∪ T'}` for disjoint `T, T'` and `0` otherwise.
- **(W3)** For `a ∈ S(p)`, the classes `[X_a] ∈ 𝔞_p / 𝔞_p^2` form a basis, and `X_a ≠ 0` iff `[X_a] ≠ 0`. So
  `dim 𝔞_p/𝔞_p^2 = |S(p)|`.

**Step 3. Proof of (a).** With `w = [[0,1],[1,0]]`, `w u(y) w^{-1} = v(y)`, and `d_τ v(y) d_τ^{-1} = v(τ^{-2} y)`.
- At `A_1` and `A_2`: `ρ(v(y)) = ρ(w) ρ(u(y)) ρ(w)^{-1}`. By uniqueness, `X_a^v = ρ(w) X_a^u ρ(w)^{-1}`, so the
  spectra agree.
- At `A_3`: pick `τ ∈ F` with `τ^{-2} = s`, which exists because squaring is bijective on `F`. Then
  `v(sy) = (d_τ w) u(y) (d_τ w)^{-1}` for `y ∈ k`, and the same argument applies.

**Step 4. Proof of (b).** If `S_i = ∅`, then `ρ(p(y)) = 1` for all `y`, contradicting Step 0. The `X_a`,
`a ∈ S_i`, are nonzero, linearly independent by (W1), commuting and nilpotent. So they are simultaneously
strictly upper triangular, and `|S_i| <= d(d-1)/2`.

**Step 5. Proof of (c).** Let `e = (i,j)`, `p = p_i^e`, `p' = p_j^e`, `ψ = ψ_e`.
- In `Λ`, `p(α_i^e x) = p'(α_j^e x)`. With `y = α_j^e x` this reads `ρ(p'(y)) = ρ(p(ψ(y)))` for all `y ∈ k`.
- `ψ` is bijective, so `𝔞_{p'} = 𝔞_p =: 𝔞`. By (W3), `|S_j| = dim 𝔞/𝔞^2 = |S_i|`.
- Modulo `𝔞^2`, Step 1 gives two expansions:
  - `ρ(p(ψ(y))) ≡ 1 + Σ_a ψ(y)^{2^a} X_a = 1 + Σ_c y^{2^c} Σ_{a ∈ S_i} c_{c-a}^{2^a} X_a`;
  - `ρ(p'(y)) ≡ 1 + Σ_c y^{2^c} X'_c`.
  Here exponents are read mod `f`, which is harmless because `y^{2^f} = y` on `k`.
- The functions `y^{2^c}`, `c ∈ Z/f`, are linearly independent. So in `𝔞/𝔞^2`,

```text
[X'_c] = Σ_{a ∈ S_i} c_{c-a}^{2^a} [X_a].
```

- The `[X_a]` with `a ∈ S_i` are a basis (W3). So `[X'_c] ≠ 0` iff some `a ∈ S_i` has `c - a ∈ supp(ψ)`.
  Since `X'_c ≠ 0` iff `[X'_c] ≠ 0` (W3 at `p'`), we get `S_j = S_i + supp(ψ)`.
- For `b ∈ supp(ψ)`, `S_i + b ⊆ S_j` and `|S_i + b| = |S_i| = |S_j|`, so `S_j = S_i + b`.

**Step 6. Proof of (d).**
- By (c), `S_2 = S_1 + b_12`, `S_3 = S_2 + b_23` and `S_3 = S_1 + b_13`. So `S_1 + (b_12 + b_23 - b_13) = S_1`.
- For `b, b' ∈ supp(ψ_e)`, `S_i + b = S_j = S_i + b'`, so `S_i` is stable under `b - b'`. Every `S_i` is a
  translate of `S_1`, so `S_1` is stable too.
- Changing the choice of `b_e` changes `b_12 + b_23 - b_13` by such differences.
- Hence `S_1` is `H`-stable, so a nonempty union of `H`-cosets, and `|H|` divides `|S_1|`.
- For semilinear twists, `ψ_e(y) = λ_e^{-2^{-a_e}} y^{2^{-a_e}}`, so `supp(ψ_e) = {-a_e}` and `H = <-hol> = <hol>`.

**Step 7. Corollaries.**
- **`d = 2`.** Step 4 gives `|S_1| = 1`, so `H = 0`. Each `supp(ψ_e)` is a singleton, so `ψ_e` and
  `φ_e = ψ_e^{-1}` are semilinear, and `hol = 0`.
- **`f` prime.** Some `supp(ψ_e)` has two elements, or `hol ≠ 0`, so `H ≠ 0` and `H = Z/f`. Then
  `S_i = Z/f` and `f <= d(d-1)/2`.
- **`f = 3`, `d = 3`.** `X_0, X_1, X_2` would span a 3-dimensional commutative subspace of the strictly upper
  triangular matrices `n_3`. But `[a E_12 + b E_23 + c E_13, a' E_12 + b' E_23 + c' E_13] = (ab' - a'b) E_13`. So
  a commutative subspace projects to an isotropic subspace of the `(a,b)`-plane for a nondegenerate
  alternating form, of dimension at most 1, and has dimension at most 2. Contradiction, so `d >= 4`.

∎

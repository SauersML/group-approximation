## The group

Bartholdi, *L-presentations and branch groups* (arXiv:math/0007062v3; TeX read at
`$GQ/src/bh-free-20/bart/lpres.tex`, §"An L-presentation for G̃", Theorem `thm:Gt`). The
Grigorchuk supergroup `G̃ = ⟨a, b̃, c̃, d̃⟩ ≤ Aut(T_2)` has `a` the root swap and

```text
b̃ = (a, c̃),     c̃ = (1, d̃),     d̃ = (1, b̃).
```

It admits an ascending finite L-presentation with the single substitution

```text
σ̃:  a ↦ a b̃ a,   b̃ ↦ d̃,   c̃ ↦ b̃,   d̃ ↦ c̃.
```

So `σ̃` induces an endomorphism of `G̃` (it maps the iterated relators into themselves).
By Bartholdi's Theorem `thm:hnn`, `Ĝ = ⟨G̃, t | t^{-1} x t = σ̃(x)⟩` is finitely presented.
`Ĝ` is amenable and not elementary amenable: `G̃` has intermediate growth, a literature input
not re-read; ascending HNN extensions of amenable groups are amenable; and elementary amenable
groups have no subgroups of intermediate growth.

## Statement

`Ĝ = G̃*_σ̃` embeds in the Röver–Nekrashevych group `V_2(S)` of a finite bounded automaton group
`S ≥ G̃`. Hence **`Ĝ` embeds in a finitely presented simple group**, and it lies in the
permutational class `B_A`.

## Proof: check the criterion of `bounded-last-section-ascending-hnns-satisfy-boone-higman`

**Bounded.** `b̃, c̃, d̃` are directed along the ray `1^∞`, with off-ray sections in `{1, a}`.
So `G̃` is generated by a finite bounded automaton.

**Last-section form.** Conjugating by the involution `a` swaps the two sections, so:

```text
σ̃(a) = a b̃ a = (c̃, a),   σ̃(b̃) = d̃ = (1, b̃),   σ̃(c̃) = b̃ = (a, c̃),   σ̃(d̃) = c̃ = (1, d̃).
```

So `σ̃(g) = (ψ(g), g)`, where `ψ` is determined by `ψ(a) = c̃`, `ψ(b̃) = 1`, `ψ(c̃) = a`,
`ψ(d̃) = 1`. Also `σ̃(G̃) ≤ St(1)`.

**(F) finite.** `ψ(G̃) = ⟨a, c̃⟩`. Since `a c̃ a = (d̃, 1)`, we get `(ac̃)^2 = (d̃, d̃) ≠ 1` and
`(ac̃)^4 = 1`. So `ψ(G̃) ≅ D_8`.

**(E) eventually finitary.** Put `h_k = ψ∘σ̃^k`, so `h_{k+1}(x) = h_k(σ̃(x))`. Values on
`(a, b̃, c̃, d̃)`:

| k | a | b̃ | c̃ | d̃ |
|---|---|---|---|---|
| 0 | c̃ | 1 | a | 1 |
| 1 | 1 | 1 | 1 | a |
| 2 | 1 | a | 1 | 1 |
| 3 | a | 1 | a | 1 |
| 4 | 1 | 1 | 1 | a |

For example `h_1(a) = h_0(a b̃ a) = c̃·1·c̃ = 1` and `h_3(a) = h_2(a b̃ a) = a`. Row 4 equals
row 1, so `h_{k+3} = h_k` for `k ≥ 1`, and for `k ≥ 1` all values lie in `{1, a}`, which is
finitary. So (E) holds with `k_0 = 1`.

The criterion applies. ∎

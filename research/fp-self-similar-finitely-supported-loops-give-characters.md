**ESTABLISHED (unreviewed).** Proof: `fp-self-similar-finitely-supported-loops-give-characters-proof`.
The proof is a short cocycle computation. The script checks the cocycle and the character on
the instance `R' = ⟨M_11, b, c'⟩` of `m11-separated-loop-host-has-b1-one`.

**Setting.** As in `fp-self-similar-groups-have-fp-ray-loop-subgroups`. `X` is a finite
alphabet, `y ∈ X`, `ξ = y^∞`, and `Ω = X*·y^∞` is the cofinality class of `ξ`. `G ≤ Aut(X*)`
is self-similar and generated by a finite symmetric set `S`, and (Ω), (E), (F) hold: each
`s ∈ S` preserves `Ω`, has eventually constant sections `c(s, η)` along every `η ∈ Ω`, and
these take finitely many values. `H_ξ = ⟨c(s, η)⟩` is the ray-loop subgroup. Add:

- **(FS)** for every `s ∈ S`, the support `{η ∈ Ω : c(s, η) ≠ 1}` is finite.

**Theorem.**

1. **The loop cocycle.** For every `g ∈ G` and `η ∈ Ω`, the sections `g|_{p_m(η)}` are
   eventually constant, with value `κ(g, η) ∈ H_ξ`. Moreover `κ(gh, η) = κ(g, η) κ(h, η^g)`,
   and `κ(g, ·)` has finite support.
2. **The loop character.** `Φ(g) = Σ_{η ∈ Ω} [κ(g, η)]` is a homomorphism
   `Φ : G → H_ξ^{ab}`.
3. **Consequences.** `Φ(G)` is a finitely generated abelian group, so
   `b_1(G) ≥ rank Φ(G)`. In particular, suppose `t ∈ G` has infinite order, `t|_y = t`,
   `y^t = y`, and `κ(t, η) = 1` for `η ≠ ξ` and `κ(s, η) ∈ ⟨t⟩` for all `s ∈ S`, `η ∈ Ω`.
   Then `H_ξ = ⟨t⟩ ≅ Z`, `Φ(t) = 1`, and `G ↠ Z`.
4. **Finiteness corollary.** Let `G ≅ G ≀_X P` be fully self-replicating with root image
   `P ≤ Alt(X)`, `d = |X| ≥ 4`. If `Φ(G)` is infinite, then `H_1(G; Q) ≠ 0`. So `G` is not
   of type `FP_{d−1}` over `Q`, and not `FP_∞`. Its Tits host of
   `tits-hosts-for-transitive-local-actions` is not of type `FP_{d−1}` over `Q` either,
   by Bieri's Mayer–Vietoris argument for amalgams. If `rank Φ(G) ≥ 2`, then
   `G` is not finitely presented. Both follow from items 3(a) and 3(d) of
   `fully-self-replicating-fp-infinity-groups-are-acyclic`.

**What it kills.** Take a candidate for the Tits route of `boone-higman-conjecture` that
gets infinite order from a loop state whose exits leave the ray's cofinality class through
finitary or bounded states. The ray-loop obstruction of
`fp-self-similar-groups-have-fp-ray-loop-subgroups` is designed around, by keeping loop
groups cyclic. Then (FS) holds and `Φ` is onto `Z`, so the candidate is not `FP_∞`. Every
"separated loop" design is of this kind, for example `R'` of
`m11-separated-loop-host-has-b1-one`. The two obstructions together give a dichotomy for an
infinite-order loop state `t` along `ξ`:

- if its exits return to `H_ξ` infinitely often along `Ω` (so (FS) fails), `H_ξ` can pick
  up a branch group, as for `R''` in `m11-odometer-free-host-is-not-finitely-presented`;
- if they do not, `Φ` sees `t`, and `b_1 ≥ 1`.

An `FP_∞` candidate needs infinitely supported loop cocycles whose loop groups stay finitely
presented.

**Calibration.**

- *Bounded `M_11` group* `R_0 = ⟨M_11, b⟩`, with `b = (b, α, β, 1, …)` and `ξ = 1^∞`. Here
  `C = {b^{±1}}`, with support `{ξ}`. `Φ : R_0 → ⟨b⟩ = Z/55` sends `b ↦ [b]`. This recovers
  `H_1(R_0) = Z/55` of `m11-odometer-free-linear-host-h1-is-z55-squared`.
- *`R'' = ⟨M_11, b, c⟩`* with `c = (c, bα, 1, …)`. (FS) fails at `1^∞`, because
  `c(u, 1^k 2 1^∞) = b` for every `k`. The theorem gives nothing, consistent with
  `b_1(R'') = 0`.
- *Grigorchuk group* on `2^∞`, regrouped as `(X^3)*`. The loop states `b, c, d` exit only
  through `a` and `1`, so (FS) holds and `Φ : G → ⟨b, c, d⟩ = (Z/2)^2`. This is consistent
  with `G^{ab} = (Z/2)^3`.
- *Lamplighter* `a = (a, b)σ`, `b = (a, b)`. Every state has section `b` at `1`, so
  `c(a, η) = c(b, η) = b` at every `η ∈ Ω`, and (FS) fails.

## Why sufficient

*Onto.*  `unitAdditiveSpan_eq_top` (`UnitAdditiveSpan.lean:108`) states that
in every ring carrying a binary Leavitt family the additive subgroup
generated by the unit values is the whole ring.  In characteristic two an
additive combination of units, after cancelling repetitions, is an
`F_2`-linear combination of units, which is `pi` of the corresponding element
of `F_2[G]`.

*No unital ring homomorphism `phi : R -> F_2`.*  From `t_0 s_0 = 1`, both
`phi(t_0)` and `phi(s_0)` are nonzero in `F_2`, hence `1`.  From
`t_1 s_1 = 1`, likewise `phi(t_1) = phi(s_1) = 1`.  Then `t_0 s_1 = 0` reads
`1 = 0`.

*Kernel nonzero.*  If `K = 0` then `pi` is bijective, and transporting the
augmentation `eps : S -> F_2` through `pi^(-1)` gives such a `phi`.

*Kernel not inside `ker(eps)`.*  If `eps(K) = 0` then `eps` factors through
`S/K`, which `pi` identifies with `R` as a ring, again producing `phi`.  So
`eps(K) = F_2` and some `k` in `K` has `eps(k) = 1`.

Both kernel statements use only that `F_2` is a nonzero commutative ring, so
they hold verbatim over any field of any characteristic; only the onto half
uses characteristic two, and only to convert integer combinations into linear
ones.

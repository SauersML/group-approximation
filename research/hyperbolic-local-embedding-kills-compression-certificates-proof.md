## Standard facts used

Let `H` be word-hyperbolic.

- **(E1)** Every subgroup of `H` is either non-elementary or elementary. An
  elementary subgroup is finite or virtually cyclic. Virtually cyclic groups
  are residually finite.
- **(E2)** If `g in H` has infinite order, then `E(g)`, the stabilizer of the
  pair of fixed points `{g^+, g^-}` on the boundary, is virtually cyclic. It
  contains `C_H(g)`. Every infinite elementary subgroup containing `g` lies in
  `E(g)`. A loxodromic element lying in `E(g)` has fixed-point pair
  `{g^+, g^-}`.
- **(E3)** A non-elementary subgroup has finite centralizer
  (`hyperbolic-nonelementary-centralizer-finite`).

The proof of `hyperbolic-nonelementary-centralizer-finite-proof` uses exactly
the same facts.

**Word evaluation.** Let `psi : F -> H` be an injective partial homomorphism
and let `s_1, ..., s_k in F`. Suppose `F` contains `1`, each `s_i^(±1)`, and
every prefix of a word `w` in the `s_i^(±1)`. Then `psi(1) = 1`,
`psi(s_i^-1) = psi(s_i)^-1`, and `psi(w(s)) = w(psi(s))`. The proof is by
induction on the length of the prefix: `psi(1) = psi(1)^2` gives `psi(1) = 1`,
and `psi(s) psi(s^-1) = psi(1)` gives the inverse. From now on every finite set
is enlarged to contain the prefixes of the finitely many words named, so word
evaluation applies.

## Lemma (compression in a hyperbolic group)

Let `Gamma' <= H` be any subgroup and let `t in H` satisfy
`t Gamma' t^-1 <= Gamma'`. Then `t C_H(Gamma') t^-1 = C_H(Gamma')`.

*Proof.* Put `C = C_H(Gamma')`. Every element of `C` commutes with
`t Gamma' t^-1 <= Gamma'`. So

```text
C <= C_H(t Gamma' t^-1) = t C t^-1.                               (*)
```

- *`Gamma'` finite.* Conjugation is injective, so `t Gamma' t^-1 = Gamma'`,
  and `t` normalizes `C`.
- *`Gamma'` non-elementary.* By (E3), `C` is finite. `t C t^-1` is also
  finite with the same number of elements, so (*) is an equality.
- *`Gamma'` infinite elementary.* Take `g in Gamma'` of infinite order. By (E2),
  `Gamma' <= E(g)`. The element `t g t^-1` lies in `Gamma' <= E(g)` and is
  loxodromic, so its fixed pair `t{g^+, g^-}` equals `{g^+, g^-}`. Hence
  `t in E(g)`, and `C <= C_H(g) <= E(g)`, again by (E2). Conjugation by `t` is
  an automorphism of the virtually cyclic group `E = E(g)`.
  - If `C` is finite, (*) is an equality by counting.
  - If `C` is infinite, it has finite index in `E`. Then
    `|E : t C t^-1| = |t E t^-1 : t C t^-1| = |E : C|`, and a subgroup
    inclusion between two subgroups of the same finite index is an equality.

`QED`

## Proof of Theorem R

Let `Gamma = <s_1, ..., s_k> <= K`, `u in P_K(Gamma)`, `z in C_K(Gamma)` and
`gamma in Gamma`. We show that `x_+ = u z u^-1` and `x_- = u^-1 z u` commute
with `gamma`. Together these give `u C u^-1 <= C` and `u^-1 C u <= C`, so
`u C u^-1 = C`. The rest of the statement follows because a group generated by
normalizing elements normalizes.

In `K` fix words:
- `w_i` with `u s_i u^-1 = w_i(s)`;
- a word `v` with `gamma = v(s)`.

Let `F` be the finite prefix-closed set containing:
- `1`, `u^(±1)`, `z`, `s_i^(±1)`;
- `u s_i`, `u s_i u^-1` and the prefixes of `w_i`;
- `z s_i` and `s_i z`;
- `u z`, `x_+`, `u^-1 z` and `x_-`;
- the prefixes of `v`;
- `x_± gamma` and `gamma x_±`.

Take `psi : F -> H` with `H` hyperbolic, and put `t = psi(u)` and
`Gamma' = <psi(s_1), ..., psi(s_k)> <= H`.

1. `t psi(s_i) t^-1 = psi(u s_i u^-1) = w_i(psi(s)) in Gamma'`, so
   `t Gamma' t^-1 <= Gamma'`. By the Lemma, `t` normalizes `C_H(Gamma')`.
2. `psi(z) psi(s_i) = psi(z s_i) = psi(s_i z) = psi(s_i) psi(z)`, so
   `psi(z) in C_H(Gamma')`.
3. `psi(x_+) = t psi(z) t^-1` and `psi(x_-) = t^-1 psi(z) t` both lie in
   `C_H(Gamma')`, and `psi(gamma) = v(psi(s)) in Gamma'`.
4. Hence `psi(x_± gamma) = psi(x_±) psi(gamma) = psi(gamma) psi(x_±) = psi(gamma x_±)`.
   Since `psi` is injective, `x_± gamma = gamma x_±`.

`QED`

The rigid defect of `sofic-groups-kill-rigid-compression-defects` uses
`g in <P_Gamma>` and `z in C(Gamma)`. It is trivial because `g z g^-1` stays in
`C(Gamma)`.

## Proof of Theorem B

Let `A = <a_1, ..., a_p>` and `B = <b_1, ..., b_q>`. For `R >= 1` let
`B_R(A)` and `B_R(B)` be the word balls. Take the prefix-closed finite set
`F_R` containing `B_{2R}(A)`, `B_{2R}(B)`, `a_i b_j` and `b_j a_i`. Take
`psi : F_R -> H` and put `A' = <psi(a_i)>` and `B' = <psi(b_j)>`. Then
`psi(a_i) psi(b_j) = psi(a_i b_j) = psi(b_j a_i) = psi(b_j) psi(a_i)`, so
`[A', B'] = 1`. Word evaluation gives `psi(B_{2R}(A)) <= A'` and
`psi(B_{2R}(B)) <= B'`.

- If `A'` is elementary, it is residually finite by (E1). Choose a finite
  quotient `q : A' -> Q` that is injective on `psi(B_{2R}(A))`. Then
  `q o psi` is an injective partial homomorphism from `B_R(A)` to a finite
  group. It is multiplicative on pairs `x, y` with `xy` in `B_R(A)`, and all
  such products lie in `B_{2R}(A) subset F_R`.
- If `A'` is non-elementary, then `B' <= C_H(A')` is finite by (E3), and `psi`
  restricted to `B_R(B)` is an injective partial homomorphism into a finite
  group.

For every `R`, one of the two cases happens. So one of them happens for
infinitely many `R`, say for `A`. Restriction to a smaller ball preserves an
injective partial homomorphism, and every finite subset of `A` lies in some
ball. So `A` is LEF. `QED`

## Consequences

1. `F` is finitely presented. Cannon--Floyd--Parry, as quoted in
   `thompson-f-is-not-residually-finite`, establishes finite presentability.
   `F` is not residually finite (`thompson-f-is-not-residually-finite`), so
   it is not LEF by `finitely-presented-lef-groups-are-residually-finite`.
   `F` contains commuting copies `F_[0,1/2]` and `F_[1/2,1]` of itself
   (`thompson-f-f-times-z-f-times-f-are-mutual-subgroups`). Theorem B applies.
   The groups `T`, `V` and `L_(F_2)(1,2)^x` contain `F`.
2. The certification in `sofic-groups-kill-rigid-compression-defects` exhibits
   `g`, `z` and `gamma` with `[g z g^-1, gamma] != 1`, for a finitely generated
   (indeed Kazhdan) `Gamma`. Theorem R forbids this in an LEH group.
3. In `one-sided-compression-nonsofic-criterion` and
   `fournier-facio-torsion-free-skeleton`, `J` is finitely generated and not
   LEF, `[Gamma, J] = 1`, and some conjugate of `J` lies in `Gamma`. Subgroups
   of LEF groups are LEF, so `Gamma` is not LEF either, and Theorem B applies.
   The Fournier--Facio case also follows from Theorem R:
   - `t_1 in P(Gamma)` and `J <= C(Gamma)` give `pi(S) = t_1 J t_1^-1 <= C(Gamma) cap Gamma`.
   - `C(Gamma) cap Gamma` is abelian.
   - `S` is infinite simple and nonabelian, a contradiction.

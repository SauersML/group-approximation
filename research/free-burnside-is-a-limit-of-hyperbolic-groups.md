**Literature input.** Let `G` be a non-elementary torsion-free hyperbolic group,
for example the free group `F_m` with `m >= 2`. There is an integer
`n_1 = n_1(G)` such that, for every odd `N >= n_1`, there are surjections

`G = G_0 -> G_1 -> G_2 -> ...`

with the following properties.

1. Each `G_k` acts properly and cocompactly by isometries on a proper geodesic
   hyperbolic space. So each `G_k` is a non-elementary hyperbolic group.
2. The kernel of `G_k -> G_{k+1}` is normally generated by `N`-th powers of
   elements of `G_k`.
3. The direct limit is `G/G^N`. Equivalently, the kernels `ker(G -> G_k)`
   increase, and their union is `G^N`.
4. `G/G^N` is infinite.

For `G = F_m`, the limit is the free Burnside group `B(m,N)`.

**ESTABLISHED** (lane bh-invent-03, 2026-09-19; elementary; not reviewed; no priority claimed). The mechanism is the
familiar one of rational (finite-state, asynchronous) maps, after Grigorchuk–Nekrashevych–Sushchanskii (recalled).
The Farley–Hughes notions are those of arXiv:2010.08035: §3.4, Definition 4.7, Proposition 3.24.

## Statement

**Hypotheses.** Let `S` be an inverse semigroup of partial bijections of a set `X`, and `(𝕊, ℙ)` its maximal
S-structure. Assume:
- (N) `D_S^+` has the compact ultrametric property (FH Def. 3.12: nested, finite complementation);
- (T) there are finitely many domain types;
- (G) every structure group `G_D = 𝕊(D, D)` is **finite**;
- `X` has a root partition into finitely many domains.

Let `Γ ≤ Γ_S` be generated by a finite set `W`.

1. **Rational action.** Each `D` has an address, a word over a finite alphabet in the tree of maximal partitions. On
   addresses, each `s ∈ W` acts by *replace a prefix of bounded length, then run a synchronous finite-state
   transducer on the rest*.
2. **Orbits in quadratic time.** Let `x` lie in a singleton domain (`{x} ∈ D_S`), and let `U` be a finite union of
   domains. Then `w·x ∈ U` is decidable in time `O((|w| + |addr(x)|)^2)`.
3. **Word problem in exponential time.** `WP(Γ)` is decidable in time `2^(O(|w|))`.
4. **Seeds.** Let `Y` be a seed SFT over `Γ` with seed `y_*` and orbit `O`. Suppose some group containing `Γ` equals
   `Γ_S` for such an `S` on `X = O`, with `{y_*}` and the letter cylinders at the identity finite unions of domains.
   Then `w ↦ y_*(w)` is computable in time `O(|w|^2)`. So condition 1 of
   `hard-evaluation-seeds-with-finitely-presented-full-groups` **fails** for every seed that has such a finiteness
   structure.
   - This holds whatever the domains are: balls, sibling pairs, or any equidecomposability classes, as long as
     (N), (T) and (G) hold.

## Proof

**Addresses.**
- **The tree.** By nestedness and FH Cor. 3.20 and Lemma 3.23, the domains inside the root pieces form a tree. Each
  domain's children are its maximal partition. The branching is bounded because by (T) there are finitely many
  types.
- **Canonical maps.** Fix a representative `R_t` of each type `t`, and fix `ι_(t,i) ∈ 𝕊(R_(t_i), C_i)` for each child
  `C_i` of `R_t`. Fix `κ_U` for each root piece `U`. Define recursively `κ_C = κ_N|_(C_i) ∘ ι_(t,i)` for the child
  `C = κ_N(C_i)` of `N`. This is well defined, because S-maps preserve maximal partitions (FH Prop. 3.24).
- **The address of `N`** is the root index followed by its child indices.
- **Pieces inside root pieces.** Every generator piece can be refined to lie in a single root piece. A domain
  properly containing a root piece is partitioned by the root pieces it contains, and that partition refines its
  maximal partition (FH Cor. 3.20).

**1.** An S-map `σ : D -> D'` between domains of type `t` has the state `g = κ_(D')^(-1) σ κ_D ∈ G_t`.
- By Prop. 3.24, `g` permutes the children of `R_t`: `i ↦ π_g(i)`.
- Its restriction to child `i` has the state `ι_(t,π_g(i))^(-1) ∘ g|_(C_i) ∘ ι_(t,i) ∈ G_(t_i)`, which depends only on
  `(g, i)`.
- So `σ` acts by `addr(D)·u ↦ addr(D')·A_g(u)`, where `A` is a synchronous transducer with state set `⊔_t G_t`.
  That set is finite by (G).
- A generator is a finite union of such maps. So on addresses it acts as stated, with prefixes of length at most
  some `d`.

**2.** Apply the letters of `w` one at a time to the finite address of `{x}`.
- **Each step.** Find the unique piece whose address is a prefix. A piece containing `x` is an ancestor of `{x}`.
  Swap that prefix and transduce the tail, in time linear in the current length.
- **Lengths.** Each step changes the length by at most `d`.
- **Reading off `U`.** Membership in `U` is a test on a bounded prefix.

**3.** The action of `w` on addresses extending a prefix `q` of length `Λ = d(|w|+1)` depends only on `q`. It is
`q ↦ q'` followed by a transducer state `g_q`, since piece selection at step `k` reads at most `d(k+1)` original
letters. So `w = 1` iff `q' = q` and `g_q = id` for every such `q`, and every leaf of depth `< Λ` is fixed. There are
at most `r·b^Λ` prefixes to check.

**4.** `y_*(w) = (w^(-1)·y_*)(1)` is read from the letter cylinders at `1`. Apply 2. ∎

## Scope, and the one escape

- **Covered.** Every Farley–Hughes example whose maximal structure groups are finite: `V` and `V_(n,r)`,
  Houghton's `H_n`, Lehnert's `QV`, and T0 (`free-group-houghton-group-is-of-type-f-infinity`). Every hard-actor seed
  built on such an engine is quadratic.
- **Covered by the same argument.** Röver's group and other Röver–Nekrashevych groups `V(G)` with `G` finite-state.
  Their maximal structure groups contain the infinite `G`, but each generator uses only finitely many states.
- **Product structures such as `nV`** are not ultrametric. An analogous multi-address argument gives the same kind
  of cap; compare the coNP cap for compilers in Brin–Thompson groups. That argument is not written out here.
- **The escape: infinite-state structure groups.** FH allow `𝕊(D, D)` infinite of type `F_∞` (their Theorem 8.2).
  - If some element acts on the domain tree with infinitely many states, i.e. is not finite-state, the transducer
    argument breaks. Orbits are then computed relative to the self-similar action of `G_t`.
  - Hardness can enter only here. This is the Röver–Nekrashevych branch
    (`fp-self-similar-groups-with-arbitrarily-hard-word-problem`).
  - So the seed branch and the self-similar branch of `type-a-actors-with-arbitrarily-hard-word-problem` **merge**:
    a hard seed with a finite-type engine needs hard, `F_∞`, self-similar structure groups.

## Lesson for general BH

**Finite-type finiteness engines cannot manufacture hardness.**
- **What they certify.** A Farley–Hughes structure with finitely many domain types and finite structure groups
  certifies only groups that act rationally on the address tree, finite-state after a bounded prefix swap. Such
  groups evaluate orbits in quadratic time and solve their word problems in exponential time.
- **Equidecomposability does not help.** Taking domains up to equidecomposability changes nothing, because any
  admissible finite-type structure is covered.
- **What this closes.** The route "hard seed + finite-type Farley–Hughes certificate" is **closed**. This also
  explains why T0 went through: its seed is finite-state.
- **What remains.** Hardness for the hard-actor and seed-full-group routes must be imported through infinite,
  `F_∞`, self-similar structure groups (Röver–Nekrashevych type), or through finiteness engines that are not of
  Farley–Hughes finite type.

Exactly one holds:

1. all `L(F_r)`, `1 < r <= s < infinity`, are elementarily equivalent, and every
   first-order fundamental group is `R_+`;
2. no two `L(F_r)`, `1 < r < s < infinity`, are elementarily equivalent, and
   `F_fo(L(F_r)) = {1}` for `1 < r < infinity`;
3. there is `alpha in (1, infinity)` with `F_fo(L(F_r)) = alpha^Z` for all
   `1 < r < infinity`.

Literature import, verbatim from the TeX of Goldbring–Pi, arXiv:2305.08168,
Main theorem (l.188–195):

- l.192: "$L(\F_r) \equiv L(\F_s)$ for all $1 < r \leq s < \infty$, and the first-order fundamental group of $L(\F_r)$ is $\bR_+$ for all $1 < r \leq \infty$."
- l.193: "$L(\F_r) \not \equiv L(\F_s)$ for all $1 < r < s < \infty$, and the first-order fundamental group of $L(\F_r)$ is $\{1\}$ for all $1 < r < \infty$."
- l.194: "There is $\alpha\in (1,\infty)$ such that the first-order fundamental group of $L(\F_r)$ is $\alpha^\bb Z$ for all $1<r < \infty$."

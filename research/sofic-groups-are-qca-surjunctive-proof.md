Notation as in the claim. `tr` is the unique normalized trace on `A`. All subalgebras are unital *-subalgebras.

**Finite-dimensional facts used.**
- (F1) If `N <= M_m` is a unital full matrix subalgebra, then `M_m` is generated by `N` and `N^c = N' cap M_m`. The
  multiplication map `N (x) N^c -> M_m` is a *-isomorphism, so `dim N . dim N^c = m^2`. If `N = N_1 (x) N_2` inside
  `M_m`, with both factors full matrix algebras, then `N_2' cap M_m = N_1 (x) N^c`.
- (F2) If `B_1, ..., B_k` are pairwise commuting unital full matrix subalgebras of a C*-algebra, the product map
  `B_1 (x) ... (x) B_k -> C*(B_1, ..., B_k)` is an isomorphism. It is a nonzero *-homomorphism from a simple algebra,
  hence injective.
- (F3) Unital *-homomorphisms out of `A_F`, or out of `A`, are injective because these algebras are simple.

## Part 1. Splitting lemma

Let `alpha(A_e) <= A_M`, `e in M`, and `K = M^-1 M`, so `M^-1 <= K`. For `k notin M^-1` we have `e notin kM`, so
`alpha(A_k) <= A_{kM}` commutes with `A_e`.

Put `C = alpha(A_{M^-1})`, a full matrix algebra (F3) inside `A_K`. Let `E_C(x) = int_{U(C)} u x u^* du` (Haar
measure). Then `E_C` is the trace-preserving conditional expectation of `A` onto `C' cap A`. Since `C <= A_K`, it maps
`A_K` into `A_K`. Averaging a matrix over its unitary group gives its normalized trace, so for `c in C` and
`x in C' cap A` we get `E_C(c x) = tr(c) x`. Fix a trace-orthonormal basis `c_1, ..., c_N` of `C` and `y in A_e`.
Put `q_j = E_C(c_j^* y) in A_K`.

**Claim.** `y = sum_j c_j q_j` and every `q_j` lies in `P = alpha(A)' cap A`.

*Proof.* Take a finite `F` with `F^- = {k : kM <= F}` containing `M^-1` and with `K <= F`. Put
`D_F = alpha(A_{F^-})`. By F3 it is a full matrix algebra, `D_F = C (x) D_2` with `D_2 = alpha(A_{F^- \ M^-1})`.

- `y` commutes with `D_2`. By F1, `y in D_2' cap A_F = C (x) (D_F' cap A_F)`, so `y = sum_j c_j r_j` with
  `r_j in D_F' cap A_F <= C' cap A`.
- Applying `E_C(c_j^* .)` gives `r_j = q_j`. So the `r_j` do not depend on `F`.
- Hence each `q_j` commutes with every `D_F`. The union of the `D_F` over an exhausting family of `F` contains
  `alpha(A_{F_0})` for every finite `F_0`, so it is dense in `alpha(A)`.

Therefore `q_j in P cap A_K`. QED

**Consequences.**
- If `P cap A_K = C1`, then `A_e <= C <= alpha(A)`. By equivariance `A_g <= alpha(A)` for all `g`. The image of a
  *-homomorphism is closed, so `alpha` is onto.
- Conversely, if `alpha` is onto, then `P` is the center of `A`, which is `C1`.
- `lambda_g P = P`, because `alpha` is equivariant. So `P cap A_{gK} = lambda_g (P cap A_K)`.

## Part 2. Sofic groups

Assume `alpha` is strict. By Part 1, `P_K := P cap A_K` is a *-subalgebra with `dim P_K >= 2`.

**Sofic model.** Let `E` be a finite symmetric set containing `e`, `M`, `M^-1`, `K`, `K K^-1`, `K M^-1` and
`M M^-1`. For `delta > 0`, soficity gives a finite set `V` and a map `s : G -> Sym(V)` with `s(e) = id`. Write `v * g = s(g^-1)(v)`.
Call `v` *good* if both hold:
- `g -> v * g` is injective on `E^3`;
- `(v * g) * h = v * (gh)` for all `g, h in E^2`.

Soficity allows at least `(1 - delta)|V|` good vertices. Call their set `V_0`.

For good `v`, the injection `iota_v(g) = v * g` on `E^3` induces a *-isomorphism `Theta_v : A_{E^3} -> A_{v * E^3}`
inside `A_V = (x)_V M_d`. It sends the matrix units at site `g` to those at `v * g`.

**Transport identity.** Let `v` be good, `s in E`, `w = v * s`, and `x in A_e`. Then `alpha(lambda_s x)` is
supported on `sM <= E^2`, and `Theta_v` puts site `sm` at `v * (sm) = w * m`. So if `w` is also good,

```text
Theta_w(alpha(x)) = Theta_v(alpha(lambda_s x)).                         (T)
```

Both sides place the same operators at the same sites `w * m`, because `lambda_s` shifts site `m` to `sm`.

**(a) Local rules commute.** For `w in V_0` put `phi_w = Theta_w o alpha|_{A_e} : M_d -> A_V`. This is a unital
*-homomorphism. Let `w != w'` be good.

- If the supports `w * M` and `w' * M` are disjoint, `phi_w` and `phi_{w'}` commute.
- Otherwise `w * m = w' * m'`. Goodness of `w'` gives `w' = (w' * m') * m'^-1`, and goodness of `w` gives
  `(w * m) * m'^-1 = w * (m m'^-1)`. So `w' = w * s` with `s = m m'^-1 in E`, and `s != e`.
- By (T), `phi_{w'}(x) = Theta_w(alpha(lambda_s x))`. In `G`, `alpha(A_e)` and `alpha(A_s)` commute, since `alpha` is
  a homomorphism and `A_e`, `A_s` commute. `Theta_w` is an isomorphism on `A_{E^3}`, which contains both supports, so
  `phi_w` and `phi_{w'}` commute.

By F2, `D = C*(phi_w(M_d) : w in V_0)` is isomorphic to `M_d^{(x) |V_0|}` and has dimension `d^{2|V_0|}`.

**(b) Relative commutant copies.** For good `v` put `R_v = Theta_v(P_K)`, supported in `v * K`.

- `R_v` commutes with `phi_w` for every good `w`. If `v * K` meets `w * M`, then `v * k = w * m`. As in (a),
  `w = v * s` with `s = k m^-1 in K M^-1 <= E`. By (T), `phi_w = Theta_v o alpha o lambda_s` on `A_e`. Elements of
  `P_K` commute with `alpha(A_s)`, and `Theta_v` is an isomorphism on a region containing `K` and `sM`.
- So `R_v <= D' cap A_V`.
- Choose `S <= V_0` greedily with the sets `v * K` pairwise disjoint. If `v * k = v' * k'` for good `v, v'`, then
  `v' = v * (k k'^-1)` with `k k'^-1 in K K^-1`. So each vertex blocks at most `|K K^-1|` others, and
  `|S| >= |V_0| / |K K^-1|`.
- The `R_v` for `v in S` have disjoint supports, so they generate their tensor product. Its dimension is at least
  `2^{|S|}`, and it lies in `D' cap A_V`.

**(c) Count.** By F1,

```text
d^{2|V|} = dim D . dim(D' cap A_V) >= d^{2|V_0|} 2^{|S|} >= d^{2(1-delta)|V|} 2^{(1-delta)|V|/|KK^-1|}.
```

This needs `2 delta log_2 d >= (1 - delta)/|K K^-1|`, which is false once
`delta < 1/(1 + 2 |K K^-1| log_2 d)`. So `alpha` is onto. QED

Amenable groups and LEF groups are special cases.

**Calibration (Part 4 tree).** The same count applies to the tree algebra. There `|F^-|/|F| -> 1/2` on balls, and the
inequality becomes `p^{2|F|} >= p^{|F|} . p^{|F|}`, an equality. So no contradiction arises, which matches the strict
example.

## Part 3. Clifford sector

On `M_p` put `X|j> = |j+1>` and `Z|j> = zeta^j |j>`, with `zeta = e^{2 pi i/p}`, so `Z X = zeta X Z`. The sites
carry `M_{p^n} = M_p^{(x) n}`. Labels are rows `u = (a, b)` with `a, b in F_p[G]^n` finitely supported, and
`W(u) = (x)_{g,i} X^{a_i(g)} Z^{b_i(g)}`.

For a row `x` let `x^*` be the column with entries `x_i^*`, where `(sum c_g g)^* = sum c_g g^-1`. Put
`beta(u, u') = (b a'^*)_e = sum_{g,i} b_i(g) a'_i(g)`. Then

```text
W(u) W(u') = zeta^{beta(u,u')} W(u+u'),   W(u)^* = zeta^{beta(u,u)} W(-u),
W(u) W(u') W(u)^-1 W(u')^-1 = zeta^{omega(u,u')},   omega(u,u') = beta(u,u') - beta(u',u) = (u J u'^*)_e.
```

Here `J = [[0,-1],[1,0]]` in block form, so `u J = (b, -a)`. The `W(u)` with `u` supported in `F` form a
trace-orthonormal basis of `A_F`.

**Clifford implies symplectic.** Let `alpha(W(u)) = c(u) W(uT)`. Each `c(u)` is nonzero, since `alpha(W(u))` is
unitary.

- Additivity: `alpha(W(u)W(u'))` is a multiple of `W((u+u')T)` and also of `W(uT) W(u'T)`, which is a multiple of
  `W(uT + u'T)`. Distinct labels give orthogonal operators, so `(u+u')T = uT + u'T`. Additivity on an
  `F_p`-module gives `F_p`-linearity.
- Equivariance: `lambda_g W(u) = W(g u)` with left multiplication on labels, so `T(gu) = g T(u)`. So `T` is a left
  `F_p[G]`-module map of rows. It is right multiplication by the matrix whose `i`-th row is `T(e_i)`, a finitely
  supported row because `alpha(W(e_i))` is local.
- Symplecticity: `alpha` fixes scalars and preserves group commutators, so
  `omega(uT, u'T) = omega(u, u') mod p`. Hence `(u (T J T^* - J) u'^*)_e = 0`. Taking `u = g e_i` and `u' = e_j`
  gives that the `(i,j)` entry has coefficient 0 at `g^-1`, for all `g`. So `T J T^* = J`.

**(i) => (ii).** `T J T^* = J` gives `T R = 1` with `R = J T^* J^-1`. Stable finiteness gives `R T = 1`, so
`u -> uT` is bijective. Every `W(v)` is a scalar multiple of `alpha(W(vT^-1))`. The `W(v)` span `A_loc`, so `alpha`
is onto.

**(ii) => (i).** Suppose `AB = 1 != BA` in `M_n(F_p[G])`, and put `T = diag(A, B^*)`.

- Symplectic: `T J T^* = [[0, -AB], [B^* A^*, 0]] = [[0, -1], [1, 0]] = J`.
- `T` preserves `beta` exactly:
  `beta(uT, u'T) = ((b B^*)(a' A)^*)_e = (b B^* A^* a'^*)_e = (b (AB)^* a'^*)_e = beta(u, u')`.
- Define `alpha_T(W(u)) = W(uT)` linearly. By the displayed relations it is unital, multiplicative and
  *-preserving on each `A_F`, with values in `A_{FM}`. Here `M` is the union of the supports of the entries of `T`,
  together with `e`.
- It is compatible with inclusions and isometric (F3), so it extends to a QCA-endomorphism of `A`. It is equivariant
  because `T` acts by right multiplication.
- Not onto: the image is the closed span of `{W(uT)}`. The functional `x -> tr(W(v)^* x)` is norm-continuous and
  vanishes on `W(w)` for `w != v`. So `W(v) in alpha_T(A)` forces `v in L T`, where `L` is the set of all labels.
- If every `(e_i, 0)` were in `L T`, then every `e_i` would be in the row span of `A`, i.e. `CA = 1` for some `C`.
  Then `C = C A B = B` and `BA = 1`, a contradiction. So `alpha_T` is strict.

QED. Stable finiteness of `F_p[G]` means that every `M_n(F_p[G])` is directly finite, so the equivalence runs over
all `n`.

## Part 4. Tree calibration

Let `T_3` be the 3-regular tree and `xi` an end. Every vertex `v` has a parent (toward `xi`) and two children
`c, c'`, and `Aut(T_3, xi)` preserves the parent relation. Let `p` be odd and `h = 2^-1 mod p`.

- **Relations.** Set `alpha(X_v) = X_c X_c'` and `alpha(Z_v) = Z_c^h Z_c'^h`. Both are of order `p`, and
  `Z_c^h Z_c'^h X_c X_c' = zeta^{2h} X_c X_c' Z_c^h Z_c'^h = zeta X_c X_c' Z_c^h Z_c'^h`.
- **Commutation.** Distinct vertices have disjoint children, so their images commute.
- **Extension.** So `alpha` respects the defining relations of `M_p` at each site and commutation between sites. It
  extends to finite regions (F3) and then to the UHF closure, and it is equivariant.
- **Strict.** Images are Weyl operators whose `X`-exponents agree on sibling pairs. By trace orthogonality `X_c` is not
  in the image.
- **Relative commutant.** `X_c X_c'^-1` and `Z_c^h Z_c'^-h` commute with the image. Moreover
  `X_c = (X_c X_c')^h (X_c X_c'^-1)^h`, which is the splitting of Part 1.
- **Trace.** Trace preservation is automatic.

The script checks the sibling block numerically for `p = 3, 5, 7`, including the relative commutant dimension `p^2`.

## Part 5. Seed closure

- **Monotone means invariant.** If `Phi` is unital and `dim(Phi(e)) <= dim(e)` for all idempotents, apply this to
  `1 - e`: `dim(1) - dim(Phi(e)) <= dim(1) - dim(e)`, so equality holds.
- **Diagonal sector.** `dim(u_g 1_U u_g^*) = dim(1_{gU})`, and additivity on disjoint clopens gives a finitely
  additive invariant probability content on clopens. It extends uniquely to a Borel measure `mu`, by compactness of
  `A^G`. Since `Phi_tau(1_U) = 1_{tau^-1 U}`, monotonicity is `tau_* mu = mu`.
- **Surjectivity.** If `mu` has full support and `tau(A^G) != A^G`, pick a nonempty clopen `U` disjoint from the closed
  image. Then `mu(U) > 0 = mu(tau^-1 U)`, a contradiction.
- **Quantum side.** `tr o alpha` is a trace on `A`, so it equals `tr`.

**Item 1** is item 1 of `nontrivial-higman-quotients-keep-all-four-bs-subgroups`.

**Item 2.** Induct on `j`.
- *Base case.* `|g_i^T(0)| = |g_i| = 1`.
- *Iterated relation.* Each relation reads `g_s^-1 g_(s+1) g_s = g_(s+1)^2`.
  Iterating it `N` times gives `g_s^-N g_(s+1) g_s^N = g_(s+1)^(2^N)` for `N >= 0`.
- *Inductive step.* With `s = i + j` and `N = T(j)`:

```text
|g_(i+j+1)^T(j+1)| <= 2 |g_(i+j)^T(j)| + 1 <= 2 (2^(j+1) - 1) + 1 = 2^(j+2) - 1.
```

**Distortion.** Write `r = 2^(j+1) - 1`. The element `g^T(j)` has length at most `r`,
and by item 1 its exponent is an honest exponent of an infinite-order element.

**Consequence.**
- *Setup.* Let `Gamma` be generated by a finite set `U`, and put
  `C = max |psi(g_i)|_U`. Then `|psi(w)|_U <= C |w|_S`.
- *Nontrivial `psi`.* If `psi` is nontrivial, `psi(H4)` is a nontrivial quotient.
  So every `psi(g_i)` has infinite order and inherits the tower bound with length
  scaled by `C`.
- *Conclusion.* A fixed-height iterated-exponential bound on the distortion of
  `<psi(g_i)>` is incompatible with this, so `psi` is trivial.

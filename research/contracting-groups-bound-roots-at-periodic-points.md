not reviewed; no priority claimed). The contracting case of `z-localized-in-automaton-groups-needs-exotic-odometers`
is **reduced, not closed** (item 4).

## Setting

- **Contracting groups.** `Γ <= Aut(T_m)` is self-similar and contracting, with finite nucleus `𝒩`: for every
  `g ∈ Γ` there is `n(g)` such that every section `g|_v` with `|v| >= n(g)` lies in `𝒩`. Every element is then
  finite-state, so a finitely generated `Γ` is an automaton group and the earlier nodes apply.
- **Admissible orders.** An integer `k >= 2` is *`m`-free* if every prime factor of `k` is `> m`.
- **Return sections.** For `a ∈ Aut(T_m)` and a vertex `v` with `a`-orbit of length `c_v`, the *return section* is
  `h_v(a) = a^(c_v)|_v`. A vertex is *good* if `h_v(a)` has infinite order.
- **Good periodic points.** A *good periodic point* of `a` is a boundary point `ξ` with finite `a`-orbit (of length
  `c`) such that `a^c|_(ξ_n)` has infinite order for every `n`.

## Theorem

1. **Good paths exist.** If `a` has infinite order, the good vertices form a subtree without leaves. So `a` has a
   *good path*: a ray `ξ` all of whose vertices are good. The orbit lengths `c_n = c_(ξ_n)` are non-decreasing,
   and each divides the next.
2. **Nucleus pigeonhole.** Let `a ∈ Γ` have a good periodic point. Then at most `|𝒩|^2` `m`-free integers `k` have
   the property that `a` has a `k`-th root in `Γ`.
3. **Consequence for divisible subgroups.** Suppose `Z[1/P]` embeds in `Γ` with `1 ↦ a`, for an infinite set `P`
   of primes, for example `Z_(S)`. Then `a` has no good periodic point:
   along every good path, `c_n → ∞`. So `a` is *odometer-like* on its good part.
4. **Contraction does not make the coding finite-state.**
   - **The example.** Let `m = 6`, let the letters be `(i, j) ∈ {0,1,2} × {0,1}`, and read `X^ω` as `Z_3 × Z_2`
     with product digits. Let `Γ ≅ Z^2` act by translations. This is the self-similar `Z^2` with virtual
     endomorphism `diag(3,2)^-1`, which is faithful and contracting with finite nucleus.
   - **Its behaviour.** For `a = (1,1)`, `c_n = 6^n` and `h_(0^n)(a) = (2^n, 3^n)`, so the return sections are
     unbounded.
   - **The coding.** The canonical orbit coding of `x = 0` is the Chinese-remainder conversion
     `Z_6 → Z_3 × Z_2`, `λ ↦ (λ, λ)`. Its sections `μ ↦ (A + 2^n μ, B + 3^n μ)` are pairwise distinct, so it is
     infinite-state.
   - **It changes rough periods.** `1/ℓ` has period `ord_ℓ(6)` in `Z_6`, but its image has period
     `lcm(ord_ℓ(3), ord_ℓ(2))`.

   So the "exotic odometer" mechanism of that node, an orbit coding that moves large primes in periods, really
   occurs in contracting groups. This element has no roots, since `Γ ≅ Z^2`.

## Where the contracting case stands

A copy of `Z_(S)` in a contracting group, with `1 ↦ a`, needs all of the following:
- `a` is not a translation (`automaton-groups-see-only-smooth-periods`);
- `a` has no good periodic point (item 3);
- every good orbit closure has an infinite-state canonical orbit coding (the exotic-odometer node, item 3),
  which item 4 shows is possible in contracting groups;
- the roots `a^(1/ℓ)`, finitely many sections each, lie in one finitely generated group.

The remaining obstruction to find: bound the return sections `h_(ξ_n)` of the roots along a good path of `a`
with `c_n → ∞`. Item 4 shows that contraction alone does not bound them.

## Lesson for general BH

**A finite nucleus bounds roots wherever an element returns without winding.**
- At a periodic point, the sections of an element and of its roots are plain sections. In a contracting group
  these eventually lie in the finite nucleus.
- A `k`-th root relation between two nucleus elements can hold for only boundedly many `k`, since a torsion-free
  pair `t^k = b = t^(k')` forces `t` to be torsion.
- So divisibility in contracting groups can only live on odometer-like elements, whose return sections wind
  around ever longer cycles.

There, contraction of plain sections says nothing: the return section of a translation of `Z_3 × Z_2` grows like
`3^n`. Its orbit coding is the Chinese-remainder conversion, which moves large primes in periods. That is exactly
the loophole of the automaton-group invariant.

For `GL_n(Q)` hosts, a divisible element of a self-similar group must be odometer-like with an infinite-state
orbit coding, which is what a coding that mixes radices, as the CRT example does, provides. Elements with a
finite-state orbit coding are dead (period invariant), and in contracting groups elements with a good periodic
point are dead (nucleus).

# Proof

Suppose `θ` exists. It is enough to treat `σ_Y` itself, since for an overgroup of `G` the orbit relation of the
restriction is a subrelation.

**0. Diffuse extension.** Coordinatewise factor maps `([0,1],Leb) → (Y,ν)` give a `G`-factor map
`π : Z̃ := ([0,1],Leb)^K → (Y,ν)^K`. Let `c(g,z)` be the unique `g' ∈ G'` with `θ(g·z) = g'·θ(z)`. It is a
measurable cocycle, as in Step 1 of `simple-kazhdan-bernoulli-host-via-popa-superrigidity`. Put
`c̃(g,z̃) := c(g,π(z̃))`, a cocycle for `σ_[0,1]`.

**1. Popa.** `σ_[0,1]` is a generalized Bernoulli action, hence s-malleable. `[G:Γ] = ∞`, because `Γ` lies in
`EL_r(R)`, whose quotient `SL_d(Z)` is infinite. So every `G`-orbit in `K` is infinite, and `σ_[0,1]` is weakly
mixing (criterion quoted in `popa-oe-superrigidity`).
`G` has property (T) (Theorem E), so it is an infinite rigid subgroup of itself, w-normal in itself. These are the
hypotheses checked in steps 1–2 of `kun-thom-action-soe-class-is-rigid-proof`.
By Theorem 0.1 (`popa-bernoulli-cocycle-superrigidity`), there are `φ : Z̃ → G'` and a morphism `ρ : G → G'` with
`c̃(g,z̃) = φ(g·z̃)ρ(g)φ(z̃)^(-1)`. As in Step 4 of `rigid-bernoulli-seed-host-via-popa-and-wq-normal-extension`,
`ψ(z̃) := φ(z̃)^(-1)·θ(π(z̃))` satisfies `ψ(g·z̃) = ρ(g)·ψ(z̃)`.

**2. Torsion puts a root subgroup in the kernel.** `U_R = {e_12(f) : f ∈ R} ≅ (R,+)` is an elementary abelian
`p`-group. So `ρ(U_R)` is finite, and `V := {f ∈ R : ρ(e_12(f)) = 1}` is an additive subgroup of finite index in
`R`. Put `U := e_12(V) <= ker ρ`, which is infinite.

The two host examples: in a virtually torsion-free group a torsion subgroup meets a torsion-free finite-index
subgroup trivially, so it injects into the finite quotient. Over a field `k` with `char k ≠ p`, commuting matrices
of order dividing `p` are simultaneously diagonalizable over the algebraic closure, with `p`-th roots of unity on
the diagonal. So an elementary abelian `p`-subgroup of `GL_n(k)` has order at most `p^n`.

**3. `U` has only infinite orbits on `K`.** On the summand `G`, `U` acts freely. For a coset `gΓ`, write `g = es`
with `e ∈ EL_r(R)` and `s ∈ SL_d(Z)`. Conjugation by `s` is a monomial substitution, so
`sΓs^(-1) = EL_r(R_C)`. Here `C = s'(N^d)` for some `s' ∈ GL_d(Z)` determined by `s` and the substitution
convention, and `R_C = F_q[x^w : w ∈ C]`. Every entry of a matrix in `gΓg^(-1) = e·EL_r(R_C)·e^(-1)` lies in
the `R_C`-submodule `M_e <= R` generated by the finitely many products `e_(ik)(e^(-1))_(lj)`. So
`U ∩ gΓg^(-1) <= e_12(V ∩ M_e)`.

`M_e` is spanned by monomials `x^w` with `w` in a finite union of translates `w_i + C`. Put
`ℓ = (1,...,1)·s'^(-1)` and `v = s'(1,...,1)`. Then `ℓ >= 0` on `C` and `ℓ(v) = d`, so `ℓ` is bounded below on
those translates while `ℓ(−nv) = −nd → −∞`. So for large distinct `n`, `n'`, the element `x^(−nv) − x^(−n'v)` is
not in `M_e`, and `R/M_e` is infinite. Since `[R:V] < ∞`, `V/(V ∩ M_e) ≅ (V + M_e)/M_e` has finite index in
`R/M_e`, so it is infinite. So the `U`-orbit of `gΓ` is infinite.

**4. Contradiction.** All `U`-orbits in `K` are infinite, so `σ_[0,1]|U` is weakly mixing, hence ergodic (Popa's
criterion applied to `U` acting on `K`). `ψ` is `U`-invariant, since `U <= ker ρ`, so it is essentially constant,
say `x_0`. Then `θ(π(z̃)) = φ(z̃)·x_0 ∈ G'·x_0` for a.e. `z̃`, and the countable set `G'·x_0` has full
`μ_A`-measure.
But `μ` has no atoms. `σ_Y` is essentially free and `G` is infinite, so a.e. `G`-orbit is infinite, and `θ` maps
it injectively into a `G'`-orbit. So `G'` is infinite, and an atom would have an infinite free `G'`-orbit of
equal masses. ∎

**Calibration.** With `G' = G` the inclusion is a containment. Step 2 fails there, as it must: `U_R` is an infinite
elementary abelian `p`-subgroup of the host.

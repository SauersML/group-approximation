Let `K` be the group of the first prerequisite and let `C_K` be as in `(CK1)`.
Throughout, the two facts used about `K` are `Rad_MF(K) = K` and
`K = <<t_2,t_3>>` with `t_2, t_3` of finite order; `K` is finitely presented
and nontrivial.

## 1. Membership

**Every MF group is in `C_K`.**  A homomorphism `K -> M` with `M` MF has
countable image, which is a subgroup of an MF group and so is a countable MF
group (`mf-positive-controls`); `Rad_MF(K) = K` makes it trivial.

**Every torsion-free group is in `C_K`.**  This is `(HIT3)`: the first
prerequisite records that every homomorphism from `K` to a torsion-free group
is trivial, because `K` is generated by finite-order elements.

Item 2 follows from item 1: finite and residually finite groups are MF, and a
directed union of residually finite groups is handled either as MF or directly
by item 3.

## 2. Closure properties

**Subgroups.**  Compose with the inclusion: a nontrivial map into a subgroup is
a nontrivial map into the ambient group.

**Arbitrary direct products.**  A map into `prod_i L_i` is trivial exactly when
each coordinate projection of it is, and each coordinate is a map into a member
of the class.

**Directed unions.**  `K` is finitely generated, so the images of a finite
generating set lie in one stage, and the whole image lies in that stage, which
is in the class.

**Arbitrary directed colimits.**  Let `L = colim_j L_j` with every `L_j` in the
class and let `f : K -> L`.  Lift the images of the finitely many generators of
`K` to some stage `L_j`.  Each of the finitely many defining relators of `K`
maps to the identity in `L`, and an equation that holds in a directed colimit
holds at some later stage, so after passing to a common later stage `L_(j')`
those lifts satisfy all relators.  They therefore define `g : K -> L_(j')`
whose composite to `L` is `f`.  Since `L_(j') in C_K`, `g = 1`, so `f = 1`.

Finite presentability of `K` is used twice here: for the finite generating set
and for the finitely many relators.

**Extensions.**  Let `1 -> N -> G -> Q -> 1` with `N, Q in C_K` and let
`f : K -> G`.  The composite `K -> Q` is trivial, so `f(K) <= N`, and the
corestriction `K -> N` is trivial.  Hence `f = 1`.

## 3. Finite-presentation localization of non-membership

Let `L = F/R` be finitely generated with `L not in C_K`, witnessed by a
nontrivial `f : K -> L`.  Write `K = <y_1,...,y_q | s_1,...,s_v>` and choose
words `w_1,...,w_q in F` representing `f(y_1),...,f(y_q)`.  For each `l`, the
element `s_l(w_1,...,w_q)` of `F` maps to `1` in `L`, hence lies in `R`.  Let
`R_0` be the finite set of these `v` elements.  The assignment `y_i -> w_i`
then respects every relator of `K` modulo `<<R_0>>`, so it defines

```text
g : K -> F/<<R_0>>.
```

The composite of `g` with the surjection `F/<<R_0>> ->> L` is `f`, which is
nontrivial, so `g` is nontrivial and `F/<<R_0>> not in C_K`.

Equivalently, membership in `C_K` is expressed by the finitely many
quasi-identities

```text
( s_1(y) = ... = s_v(y) = 1 )  ==>  y_i = 1,        1 <= i <= q,
```

so `C_K` is a quasivariety cut out by finitely many universal Horn sentences.
That is the same shape as `mf-universal-horn-obstruction`, which exhibits one
such sentence valid in every MF group.

## 4. `K` is outside, and there is no torsion-free group outside

The identity map of `K` is nontrivial, so `K not in C_K`.  Item 6's second half
is the definition of `C_K`.  And every torsion-free group is in `C_K` by
section 1, so no torsion-free group is outside it.

## 5. The independence conclusion

Suppose some argument derived "for every group `L` outside the class there is a
torsion-free group outside the class" from a subset of items 1--5 together with
the existence of a nontrivial finitely presented group outside the class.  All
of those hold for `C_K`, with `K` as the witness for the last, and the
conclusion fails for `C_K`, since no torsion-free group lies outside it.  So no
such derivation exists.

This is a statement about the deductive strength of that axiom list.  It does
not assert that a torsion-free transfer for MF is false, and it leaves
`free-abelianized-cover-reflects-mf` exactly where it was.

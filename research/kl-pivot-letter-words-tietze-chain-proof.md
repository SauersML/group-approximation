Notation of the target. `H` is normal in `P0 = H<a>`, since `a` normalizes
`H`. The quotient `P0/H` is cyclic of order `n`, generated by `aH`. All
coefficients of `w` lie in `P0`: `a`, `b in a^(-1)H`, and the coefficients of
`V in H`.

**0. Localization.** Suppose `P0 -> P0_w = (P0 * <t>)/<<w>>` is injective. For
any `G >= P0`, `G * <t> = G *_(P0) (P0 * <t>)`. Imposing `w = 1` in the second
factor gives `G_w = G *_(P0) P0_w`, and the normal form theorem for amalgamated
free products embeds `G`. So it suffices to treat `P = P0`.

**1. The coset kernel is a free product.** Let `psi : P * <t> -> P/H` be the
quotient on `P` and send `t -> 1`. Let `M = ker psi` and `t_i = a^i t a^(-i)`,
`0 <= i < n`.

Claim: `M = H * <t_0> * ... * <t_(n-1)>`, each `t_i` of infinite order.
- `P * <t>` acts on its Bass--Serre tree `T`. The vertices are the cosets `xP`
  and `x<t>`; the edge `x` joins `xP` to `x<t>`, and edge stabilizers are
  trivial.
- `M` is normal of index `n` with `psi(P) = P/H` and `psi(<t>) = 1`, so:
  - the vertices of `M\T` of type `P` correspond to `(P/H)/psi(P)`, which is one
    point;
  - the vertices of type `<t>` correspond to `(P/H)/psi(<t>)`, which is `n`
    points;
  - the edges correspond to `P/H`, which is `n` points.
- A connected graph with `n + 1` vertices and `n` edges is a tree. So `M` is
  the free product of the vertex stabilizers of a lift of it.
- Lift using the edges `a^i`, `0 <= i < n`. They all start at the vertex `P`,
  since `a^i in P`, and end at `a^i <t>`. The stabilizers are
  `M ∩ P = H` and `M ∩ a^i <t> a^(-i) = <t_i>`, because `psi(t_i^k) = 1`.

**2. The relators.** `ab in H` gives `psi(w) = psi(ab) = 1`, so `w in M`. The
cosets of `M` are `M a^i`, so every conjugate `x w x^(-1)` with `x = mu a^i`,
`mu in M`, is an `M`-conjugate of `r_i = a^i w a^(-i)`. Hence
`<<w>>_(P*<t>) = <<r_0, ..., r_(n-1)>>_M`.

Conjugation by `a^j` sends `V(t)` to `V^(j)(a^j t a^(-j))`, so

    r_i = t_i · V^(i+1)(a^(i+1) t a^(-(i+1))) · h_i.

- For `i <= n-2`, `a^(i+1) t a^(-(i+1)) = t_(i+1)`.
- For `i = n-1`, `a^n t a^(-n) = z t_0 z^(-1)`.

Since `psi(<<w>>) = 1`, `P ∩ <<w>> = H ∩ <<w>> = H ∩ <<r_i>>_M`.

**3. Tietze elimination along the chain.** Let
`N = (H * <t_0,...,t_(n-1)>)/<<r_0,...,r_(n-1)>>` and
`L = (H * <s>)/<<R>>`.

Define `theta : H * <t_0,...,t_(n-1)> -> L` as the identity on `H` and
`t_i -> Phi_i(s)`.
- For `i <= n-2`: `theta(r_i) = Phi_i(s) · V^(i+1)(Phi_(i+1)(s)) · h_i = 1`, by
  the definition of `Phi_i`.
- For `i = n-1`: `theta(r_(n-1)) = s · V^(n)(z Phi_0(s) z^(-1)) · h_(n-1) = R(s) = 1`.

So `theta` induces `theta- : N -> L`.

Define `pi : H * <s> -> N` as the identity on `H` and `s -> t_(n-1)`.
- In `N`, the relator `r_i` (`i <= n-2`) says
  `t_i = (V^(i+1)(t_(i+1)) h_i)^(-1)`.
- Downward induction from `pi(Phi_(n-1)(s)) = t_(n-1)` gives
  `pi(Phi_i(s)) = t_i` for every `i`.
- Hence `pi(R) = t_(n-1) · V^(n)(z t_0 z^(-1)) · h_(n-1) = r_(n-1) = 1`, and `pi`
  induces `pi- : L -> N`.

Both composites fix `H`. Also `theta- pi-(s) = s`, and `pi- theta-(t_i) = pi(Phi_i(s)) = t_i`. So
`N ≅ L` by an isomorphism that is the identity on `H`, and

    H ∩ <<r_i>>_M = ker(H -> N) = ker(H -> L) = H ∩ <<R>>_(H*<s>).

With step 2 this is item 1's equality.

**4. Degrees.** `V^(j)(x)` has degree `d · deg(x)`, and `h_i` has degree `0`.
- `deg Phi_(n-1) = 1` and `deg Phi_i = -d · deg Phi_(i+1)`, so
  `deg Phi_0 = (-d)^(n-1)`.
- Hence `deg_s R = 1 + d (-d)^(n-1) = 1 - (-d)^n`. For `n = 1` the chain is empty,
  `Phi_0 = s`, and the formula still reads `1 + d`.

**5. Degree zero.** If `d = 0` then `deg_s R = 1`. Take a cyclically reduced
conjugate of `R` in normal form `g_1 s^(k_1) ... g_m s^(k_m)` with
`g_j in H \ {1}`.
- Every `g_j` has infinite order, because `H` is torsion-free.
- By `klyachko-kl-holds-when-all-coefficients-have-infinite-order`, `H -> L` is
  injective. If the conjugate has no coefficient it is `s^(±1)`, and `L = H`.
- By item 1, `P -> P_w` is injective, and step 0 gives every `G >= P`.

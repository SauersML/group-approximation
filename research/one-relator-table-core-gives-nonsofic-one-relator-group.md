The first prerequisite supplies a strict realization over a table group `U_E`
isomorphic to a one-relator group. That group is not surjunctive. Sofic groups
are surjunctive, which the localization theorem recovers when no window
difference is invisible. So the one-relator group is not sofic, which is the
target.

**ESTABLISHED** (lane proof, not reviewed). Proof route:
`piecewise-projective-breakpoint-ea-proof`.

**Setting.**
- `H` is Monod's group: homeomorphisms `f` of `R` for which there are intervals `I_1, …, I_n` covering `R`
  and `g_i ∈ PSL_2(R)` with `f = g_i` on `I_i`.
- For `f ∈ H`, `sing(f)` is the finite set of points `x ∈ R` near which `f` does not agree with a
  single element of `PSL_2(R)`.
- For `G ≤ H`, put `B(G) = ⋃_{g ∈ G} sing(g)`, the breakpoint set.

**Theorem.** Let `G ≤ H`.
1. `B(G)` is `G`-invariant. If `G` is generated by a finite set `S`, then
   `B(G) = G · ⋃_{s ∈ S} sing(s)`, which is a finite union of `G`-orbits.
2. `G` is amenable if and only if `G ↷ B(G)` is extensively amenable. (If `B(G) = ∅`, then
   `G ≤ Aff_+(R)` is amenable, and EA of the empty action holds vacuously.)
3. *(Hereditary amenability, Juschenko–Matte Bon–Monod–de la Salle.)* For every subgroup `L ≤ G` and
   every `L`-orbit `Y ⊆ R`, the action `L ↷ Y` is amenable.

**What is new.** JMMdlS (arXiv:1503.04977, §8) prove item 2 with `B(G)` replaced by all of `R`. The
recurrence hypothesis of the JNS theorem is needed only on the orbits of singular points, and the
localization pins extensive amenability to the one countable set `B(G)`. That is what makes an explicit
calibrator possible (`lodha-moore-breakpoint-orbit-is-hereditarily-amenable-not-ea`).

**Consequence for F.** In Thurston's model `F = ⟨a, b⟩ ≤ H` has `B(F) = F · 0 = Q`, by the Euclidean
algorithm (see the calibrator route). So `F` is amenable iff `F ↷ Q` is extensively amenable, iff
`F ↷ D` is (`thompson-f-amenable-iff-dyadic-action-extensively-amenable`).

Lane proof, not reviewed. Lean: `GroupApproximation/BooneHigmanLinear/CharZero/ElementaryFactor.lean`,
`ElementaryHost.lean` and `CharPElementaryHost.lean` (landed e5e9cd450a, unbuilt).

Let `H <= GL_n(K)` be generated by the finite set `T`.

1. **Over the field.** Let `a(g) = diag(g, (g^T)^-1, 1, 1)`. It is an injective homomorphism
   `GL_n(K) -> GL_{2n+2}(K)`, and `det a(g) = 1`. Over a field, `SL_N = E_N` by Gaussian
   elimination. So each `a(t)`, `t ∈ T`, is a finite product of elementary matrices `x_ij(c)`,
   `c ∈ K`.
2. **Finite support.** Let `s` be the finite set consisting of:
   - the entries of the `t` and `t^-1`, for `t ∈ T`;
   - all the coefficients `c` of the chosen factorizations.

   Let `B ⊇ s` be a subring. Then `H ⊆ GL_n(B)`, and each `a(t)` is a product of elementary
   matrices over `B`. Since `E_{2n+2}(B)` is a subgroup and `T` generates `H`, `a` maps `H` into
   `E_{2n+2}(B)`. `B ⊆ K` is injective, so the factored map is injective. This proves part 1.
3. **Coordinates.** The coordinate proofs in the required nodes work for every finite set of
   entries.
   - Characteristic 0: `B = Z[s]` embeds by a ring homomorphism in `M_d(Z[1/m][x_1..x_k])`
     (`CharZeroHost.fgSubringCoordinates`).
   - Characteristic p: `B = F_p[s]` embeds by a ring homomorphism in `M_d(F_p[x_1..x_k])`
     (the ring layer of `CharPCoords.charPCoordinates_of_finiteDomainAway`).
4. **Transport of `E_N`.** An injective ring homomorphism `B -> M_d(R)` gives, in turn:
   - an injective map `E_N(B) -> E_N(M_d(R))`, applied entrywise;
   - `E_N(M_d(R)) ≅ E_{N×d}(R)`, by block flattening, since elementary block matrices are
     products of elementary matrices;
   - the stabilization `E_{Nd}(R) -> E_{Nd+r}(R)`, `x ↦ diag(x, 1)`, for any `r`.
   Composing gives parts 2 and 3. In characteristic p, one extra variable is added along
   `F_p[x_1..x_k] ⊆ F_p[x_1..x_{k+1}]`, so that `k >= 1`. ∎

No Suslin, no `SK_1` computation, and no stable range enter.

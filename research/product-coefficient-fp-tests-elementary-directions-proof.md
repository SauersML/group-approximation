Conventions: `H_j(B; M) = Tor_j^{kB}(k, M)` for left modules `M`, computed with a projective
resolution `P_* → k` by right `kB`-modules.

**(a)** Take `P_*` with `P_0, …, P_n` finitely generated projective.

- For a finitely generated projective right module `P`, `P ⊗_{kB} Π_i M_i ≅ Π_i (P ⊗_{kB} M_i)`
  naturally. This holds for `P = kB^m` and passes to direct summands.
- `H_j(B; M)` is the homology of `P_{j+1} ⊗ M → P_j ⊗ M → P_{j−1} ⊗ M` (with `P_{−1} = 0`), and for
  `j ≤ n − 1` all three modules are finitely generated.
- Products are exact in `k`-modules, so homology commutes with products in these degrees.

**(b)** `B` is generated by `s_1, …, s_m`.

- Resolution: `P_0 = kB`, `P_1 = kB^m`, with `P_1 → P_0` sending the `i`-th basis vector to `s_i − 1`
  (up to side conventions). This gives an exact `P_1 → P_0 → k → 0`.
- Let `Z_1 = ker(P_1 → P_0)`. If `Z_1` were finitely generated, a finitely generated free
  `P_2 → Z_1` would make `B` of type `FP_2(k)`. So `Z_1` is not finitely generated.
- Choose a free `P_2` mapping onto `Z_1`.

Let `M = Π_I kB`.

- `P_i ⊗ M ≅ Π_I P_i` for `i = 0, 1`, since these modules are finitely generated and free.
  Products are exact, so `ker(Π_I P_1 → Π_I P_0) = Π_I Z_1`.
- `P_2 ⊗ M → Z_1 ⊗ M` is onto by right exactness. So the image of `P_2 ⊗ M` in `Π_I P_1` is the image
  of `μ_I: Z_1 ⊗_{kB} Π_I kB → Π_I Z_1`, `z ⊗ (λ_i) ↦ (z λ_i)`.
- Therefore `H_1(B; Π_I kB) ≅ coker μ_I`.

Take `I = Z_1` as a set, and the element `ζ = (z)_{z ∈ Z_1}` of `Π_I Z_1`.

- Suppose `ζ = μ_I(Σ_{j=1}^r z_j ⊗ (λ^j_z)_z)`. Then `z = Σ_j z_j λ^j_z` for every `z ∈ Z_1`.
  So `z_1, …, z_r` generate `Z_1`, a contradiction.
- Hence `ζ ∉ im μ_I`, and `H_1(B; Π_I kB) ≠ 0`.
- `Z_1 ⊆ kB^m` is countable when `B` is countable.

**Consequences.**

- If `B` is `FP_2(k)` and the `F_i` are free, then `H_1(B; Π F_i) = Π H_1(B; F_i) = 0` by (a) with
  `n = 2`, since `Tor_1` of a free module vanishes.
- If `K` is `FP_3(k)`, then by (a) with `n = 3`, `H_2(K; Π_I kK) = Π_I H_2(K; kK) = 0`.

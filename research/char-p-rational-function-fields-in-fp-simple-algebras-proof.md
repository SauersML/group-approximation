Lane proof (bh-algebra, 2026-09-18), not reviewed. It follows
`char-p-rational-function-field-in-fp-simple-algebra-proof` (the case `k = 1`). Only the steps that
change are written out. Notation: `Π = F_p[t, registers]`, `ψ_u = σ_(u_j) ∘ ... ∘ σ_(u_1)` for
`u = u_1 ... u_j`, `G = P_k`, `T = {ψ_u(G)}`, `S` the monoid generated by `T`, `B = S^(−1) Π`,
`ψ = diag(σ_x)`. A word `x` with no squaring letter is *flat*: it fixes every `t_i`.

## 1. Values are lex-monic, and every lex-monic polynomial is a vacuum value
- **Model.** States are infinite words `ξ` with infinitely many `v` and finitely many squaring
  letters. At `ξ`:
  - `t_i` takes the value `T_i^(2^(n_i))`, where `n_i` counts the `m_i` in `ξ`;
  - the other registers take the values obtained by applying the substitutions of the letters
    before the first `v`, from right to left, to the vacuum values;
  - this gives `τ(xξ) = σ_x*τ(ξ)`.
  All values lie in `F_p[T_1..T_k]`.
- **Invariant.** For each `j`, the value of `P_j` is lex-monic in `T_1..T_j`, and `A_j`, `M_j` lie
  in `F_p[T_1..T_(j−1)]`, with `M_j` a monomial.
  - `v` and `r` give `1`.
  - `h_a` gives `T_1^(2^n) P_1 + a`.
  - `c_j` copies a lex-monic polynomial in fewer variables.
  - `H_j` gives `T_j^(2^n) P_j + A_j`, which raises the `T_j`-degree and keeps the leading
    `T_j`-coefficient.
  - `m_i` changes no register other than `t_i`.
  So every value of `G` is nonzero, and `T ⊆ Π \ {0}` (an element of `T` evaluates at each state
  to a value of `G`).
- **Every lex-monic `q ∈ F_p[t_1..t_k]` is `ψ_(xv)(G)` for a flat word `x`.**
  - Write `q = c_r t_k^r + ... + c_0`, with `c_r` lex-monic in `t_1..t_(k−1)`.
  - In time order after the vacuum: build `P_(k−1) = c_r` (induction on `k`, using only lower
    registers); copy it with `c_k`.
  - For `i = r−1, ..., 0`: set `A_k = c_i` with `z_k`, then `o_k` and `μ_(k,·)` to form each
    monomial, and `e_k` repeated to add it with its coefficient in `F_p`; then apply `H_k`.
  - `x` is this sequence read backwards. Its letters fix `P_k` except `c_k` and `H_k`.
- **Constants.** Every nonzero polynomial is a scalar times a lex-monic one, so
  `F_p(t_1..t_k) ⊆ B`. Flat letters fix it pointwise, and `σ_(m_i)` acts by `t_i ↦ t_i^2`.
- **Product-set lemma.** Let `0 ≠ F ∈ Π`. Then `ψ_(xv)(F) ≠ 0` for some flat `x`.
  - In time order, flat words realize independently:
    - `P_k` through `P_1`, set in that order, each by the recipe above, with `r` for `P_1`;
    - then every `A_j`, then every `M_j`.
    Setting a lower register never disturbs a higher `P_j`.
  - So the realized register tuples contain a product of infinite subsets of `F_p[t]`: all
    lex-monic polynomials for `P_j`, all polynomials in `t_1..t_(j−1)` for `A_j`, all monomials for
    `M_j`.
  - A nonzero polynomial over the domain `F_p[t]` does not vanish on such a product.

## 2. Simplicity, center, free algebras
- **ψ injective:** `σ_(h_0)` is the automorphism `P_1 ↦ t_1 P_1` of `Frac(Π)`, and `t_1` is a unit
  of `B`.
- **ψ-minimality and aperiodicity:** verbatim from the case `k = 1`, with the evaluation lemma
  replaced by the product-set lemma. The two letters fixing all constants are `h_0 ≠ h_1`, both
  flat, and `ψ_(xv)` kills every register.
- **`R_(p,k) ≅ O_ψ`**, simple, containing `B` and so `F_p(t_1..t_k)`: as in §4 of the case
  `k = 1`, with `Γ ↦ P_k^(−1)`.
- **Center.** As in §5 of the case `k = 1`, a central element is some `b ∈ B` with `σ_x(b) = b`
  for every letter `x`.
  - `σ_v(b) = b` makes `b` register-free, so `b ∈ F_p(t_1..t_k)`.
  - `σ_(m_1)(b) = b` gives `b(t_1^2, t_2, ...) = b` in `K(t_1)`, where `K = F_p(t_2..t_k)`. The
    height argument over the field `K` gives `b ∈ K`. Induct on `i`, so `b ∈ F_p`.
- **Free algebras:** the prefix code `x_i ↦ s_v^(i−1) s_(h_0)` over the flat letters `v, h_0`,
  exactly as for `k = 1`.

## 3. Finitely generated fields (part 2)
- A finitely generated field `E ⊇ F_p` has a transcendence basis `t_1..t_k` with
  `d = [E : F_p(t)] < ∞`.
- Its regular representation is a unital embedding `E -> M_d(F_p(t)) ⊆ M_d(R_(p,k))`, and
  entrywise it embeds `M_n(E<x>)`.
- `M_d` of a finitely presented simple algebra with center `F_p` is again one.

## 4. Countable fields of finite transcendence degree (part 3)
- **Setup.** Write `K ⊇ F = F_p(t_1..t_k)` with `K/F` algebraic and countable, and
  `K = ∪_i E_i` with `[E_i : F] = d_i < ∞` (for `k = 0`, `F = F_p`).
- **Ultramatricial chain.** Choosing bases compatibly along the chain, as in
  `field-envelopes-pass-to-algebraic-closures-proof`, gives
  `K ⊆ colim M_(d_i)(F) ⊆ L_F(1,2)`, unitally. That mechanism uses only `L_F(1,2) ≅ M_r(L_F(1,2))`
  for all `r >= 1`, compatibly, and is characteristic-free.
- **Into the host.** `L_F(1,2) = F ⊗_(F_p) L_(F_p)(1,2) ⊆ R_(p,k) ⊗ L_(F_p)(1,2)`.
- **The host.** It is finitely presented. It is simple with center `F_p ⊗ F_p = F_p`, because
  `R_(p,k)` is simple with center `F_p` and `L_(F_p)(1,2)` is central simple (for `k = 0`,
  `L_(F_p)(1,2)` itself). ∎

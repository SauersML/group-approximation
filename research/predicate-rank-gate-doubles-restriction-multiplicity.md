Let `f : {0,1}^k -> {0,1}`, let `M_f` be the affine matrix of
`boolean-predicate-is-one-rank-jump` with invertible leading block `U_f` of size
`N`, and let

```text
B_f = K(M_f),        A_f <= B_f
```

be the class-two 2-group of `clifford-commutator-rank-is-packet-dimension` and
the subgroup generated by the same `J` and `z_l` together with the `p_i, q_j`
indexed by the leading block.  Fix the sector `J = -1`, `z_l = (-1)^(x_l)`.

Then the `A_f` sector algebra is the full matrix algebra `M_(2^N)(C)` for every
assignment `x`, with a unique simple module `S_x` of dimension `2^N`, and every
irreducible `B_f`-module `T` in the sector satisfies

```text
T restricted to A_f  =  S_x^(direct sum 2^(f(x))).                (PRM1)
```

So a satisfying assignment returns the baseline packet once and a violating
assignment returns it twice.  In multiplicity form, if a finite-dimensional
`B_f`-representation has total irreducible multiplicity `m_B(x)` over `x`, the
multiplicity of `S_x` after restriction is

```text
m_A(x) = 2^(f(x)) m_B(x).                                         (PRM2)
```

**Hilbert dimension is conserved, multiplicity is not.**  This is the whole
point and the whole difficulty.  A violating `B_f`-simple is twice as large, so
`(PRM1)` is invisible to a dimension count; it is visible only against a
*fixed* packet scale.  Any downstream use must therefore compare multiplicities
at a common irreducible size, which is exactly the shape of
`semisimple-packet-multiplicity-collapse`, and is why
`multiplicity-return-transducer` insists on fixed matrix size.

**Why this is not blocked by the selector barrier.**  Every selector character
still occurs, in agreement with `finite-selector-gadget-induction-barrier`; the
predicate has been moved out of the question "does this character exist" and
into the question "how many baseline spin modules sit above it".  The barrier
is a statement about the first question only.

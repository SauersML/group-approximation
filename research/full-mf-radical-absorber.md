Let `A` be a countable group with

```text
Rad_MF(A) = A,
```

let `j : A -> G` be any homomorphism into a countable group, and put

```text
N = normalClosure_G(j(A)).
```

If `pi : G -> G/N` is the quotient map, then

```text
Rad_MF(G) = pi^(-1)(Rad_MF(G/N)).                 (A1)
```

Consequently the induced map on universal MF-visible quotients is an
isomorphism:

```text
G / Rad_MF(G)  ~=  (G/N) / Rad_MF(G/N).          (A2)
```

In particular:

1. if `j(A)` normally generates `G`, then `Rad_MF(G)=G`;
2. adjoining a copy of `A` and any collection of generators and relations
   does not create MF-visible information carried by that copy;
3. for every countable `B`,

   ```text
   Rad_MF(A x B) = A x Rad_MF(B),
   ```

   and the universal MF-visible quotient of `A * B` is
   `B/Rad_MF(B)`;
4. any extension whose kernel is a homomorphic image normally generated by
   `A` has the same universal MF-visible quotient as its base.

Thus a single explicit full-radical group is a reusable **MF absorber**.  It
can be inserted as a normal-generation core in a new construction while the
desired MF-visible quotient is prescribed independently.

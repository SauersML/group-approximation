**ESTABLISHED** (lane proof; not reviewed; no priority claimed).
- **Cited inputs, not read at source this session:**
  - Rips' construction (1982);
  - Cannon–Floyd–Parry: Thompson's `V` is finitely presented;
  - that infinite-index quasiconvex subgroups of hyperbolic groups have limit
    set a proper closed subset of `∂G`;
  - double density of loxodromic fixed pairs in non-elementary hyperbolic
    groups.
- **From main:** `Stab_V(0^∞)` is finitely generated, by
  `v-point-stabilizers-are-ascending-hnn-extensions-of-v` (lane proof).

**1. Counterexample to naive rigidity.**
- **V is highly transitive.** Let `D` be the set of eventually-zero points of
  the Cantor space `C = {0,1}^N`.
  - Every point of `D` is `u0^∞` for some finite word `u`.
  - Given distinct points `u_i0^∞` and `v_i0^∞` for `i ≤ k`, lengthen the `u_i`
    until the cones `u_iC` are disjoint, and likewise for the `v_i`.
  - Complete both families to finite cone partitions of `C` with the same
    number of pieces, subdividing a cone when needed.
  - The prefix replacement with `u_iw ↦ v_iw`, and any matching of the remaining
    pieces, lies in `V` and sends `u_i0^∞ ↦ v_i0^∞`.
  - So `V` is highly transitive on `D`. In particular `K = Stab_V(0^∞)` has
    `K\V/K = {K, V∖K}`, and it is finitely generated by the node above.
- **Rips' construction.** Since `V` is finitely presented, there is
  `1 → N → G → V → 1` with `G` a `C'(1/6)` small-cancellation group, hence
  hyperbolic, and `N` finitely generated (Rips).
- **The subgroup.** Put `H = π⁻¹(K)`.
  - `H` is finitely generated, being an extension of `K` by `N`.
  - `[G:H] = [V:K] = ∞`.
  - `H\G/H ≅ K\V/K` has exactly two elements.
- **What it doesn't give.** The `G`-action on `G/H` has kernel containing
  `N ≠ 1`, so it is not faithful and not of type (A).

**2. The quasiconvex case is rigid.**
- **Statement.** If `G` is a non-elementary hyperbolic group and `H` is an
  infinite-index quasiconvex subgroup, then `H\G/H` is infinite.
- **Proof.**
  - `Λ_H` is a proper closed subset of `∂G`.
  - By double density, some loxodromic has both fixed points in the open set
    `∂G∖Λ_H`.
  - Apply `limit-set-escaping-forces-infinitely-many-double-cosets` to the Cayley
    graph.
- **Free groups.** Every finitely generated subgroup of a free group is
  quasiconvex. So in `F_k` there is no finitely generated infinite-index
  subgroup with finitely many double cosets.

**What this says about the proposed Out(F_n) rigidity theorem.**
- **Core-freeness is needed.** The naive statement fails for hyperbolic groups
  (item 1). For `Out(F_n)` no non-core-free counterexample is known here. The
  same mechanism would give one through any finitely generated normal subgroup
  whose quotient has a suitable subgroup, for example `IA_n` with quotient
  `GL_n(Z)`. The right target is therefore core-free `H`, i.e. a faithful action
  on `G/H`, which is exactly the type (A) setting.
- **The core-free question is open even in hyperbolic groups.** Does a
  non-elementary hyperbolic group have a finitely generated, infinite-index,
  core-free subgroup with finitely many double cosets? No answer here.
- **The quasiconvex analogue for Out(F_n).** It is convex cocompactness in
  `FF_n`. If `∂FF_n` is not compact, which is not proved here, then an
  infinite-index convex cocompact `H` has compact, hence non-dense, limit set,
  and is excluded by the dense-limit-set node.
- **The two arithmetic quotients.** Pulling back through `IA_n` (for Out(F_n))
  or Torelli (for mapping class groups), a finitely generated infinite-index
  subgroup of `GL_n(Z)` or `Sp_{2g}(Z)` with finitely many double cosets would
  give a non-core-free example there. No such subgroup is known to this lane.
  The natural parabolic stabilizers have infinitely many double cosets, by
  arithmetic invariants: for rational lines under `SL_n(Z)`, the index of
  `Zv + Zw` in its saturation distinguishes pair orbits.

Notation as in the claim. `E_ij` denotes a matrix unit and `e_ij(r) = 1 + rE_ij`.

## Step 0. Matrix rings

From `R ≅ R^2` we get `R^k ≅ R^(k-1) ⊕ R ≅ R^(k-1) ⊕ R^2 = R^(k+1)` for `k >= 1`,
so `R_R ≅ R_R^k` for every `k >= 1`. Applying `End(-_R)` gives ring isomorphisms
`phi_k : R -> M_k(R)`. Concretely, an isomorphism `R^k -> R` is given by
elements `x_1, ..., x_k, y_1, ..., y_k in R` with

    y_i x_j = δ_ij,     x_1 y_1 + ... + x_k y_k = 1.

Put `c = (y_1, ..., y_k)^T` (a column) and `r = (x_1, ..., x_k)` (a row). Then
`c r = I_k`, because `(cr)_ij = y_i x_j`.

## Step 1. Rank independence

**(1a) `E_n(M_k(R)) = E_(nk)(R)` inside `GL_(nk)(R) = GL_n(M_k(R))`, for `n >= 2`.**
A block transvection `1 + aE_ij` with `a in M_k(R)`, `i != j`, is the product of
the commuting elementary matrices `e_((i,u),(j,v))(a_uv)`. So `⊆` holds.
Conversely `e_((i,u),(j,v))(s)` with `i != j` is a block transvection. For
`i = j`, `u != v`, choose a block `j' != i` (possible since `n >= 2`) and use

    e_((i,u),(i,v))(s) = [ e_((i,u),(j',w))(s), e_((j',w),(i,v))(1) ],

a commutator of two block transvections. So `⊇` holds.

**(1b)** A ring isomorphism `psi : A -> B` induces, entrywise, an isomorphism
`GL_n(A) -> GL_n(B)` carrying `e_ij(a)` to `e_ij(psi(a))`, hence `E_n(A) ≅ E_n(B)`.

**(1c)** For `m, n >= 2`:

    E_m(R) ≅ E_m(M_n(R)) = E_(mn)(R) = E_n(M_m(R)) ≅ E_n(R),

by (1b) with `phi_n`, (1a) twice, and (1b) with `phi_m^(-1)`. An abstract
isomorphism carries centres to centres, so `PE_m(R) ≅ PE_n(R)`. This proves 1.

## Step 2. The marking

Assume `PE_4(R)` is finitely presented. By
[[projective-elementary-fp-kernel-criterion]] (item 1 ⇒ 2, with `R` finitely
presented and `n = 4`), `T := E_4(R)` is finitely presented. For distinct
`i, j, k` the identity `[e_ij(s), e_jk(1)] = e_ik(s)` shows `T = [T,T]`, so
`H := T <= [T,T]`. The element `g := e_12(1)` is nontrivial.

The ring `Z[T]` is finitely presented. If `T = <X | W>` with `X, W` finite, it is
presented by generators `x, x'` (`x in X`), relations `x x' = x' x = 1`, and
`w = 1` for `w in W`, with each `x^(-1)` read as `x'`. Hence
`U = Z[T]<p,q>/(p(1-g)q - 1)` is finitely presented, by adding two generators
and one relation.

## Step 3. The surjection `U ->> M_4(R)`

The inclusion `T <= GL_4(R) = M_4(R)^x` is a group homomorphism. By the universal
property of the group ring it extends to a unital ring map `Z[T] -> M_4(R)`,
and `1 - g` maps to `-E_12`.

**The relation.** Take `k = 4` in Step 0 and put `P = -c e_1^T` and `Q = e_2 r`,
both `4 × 4` matrices. Then

    P(-E_12)Q = c (e_1^T E_12 e_2) r = c r = I_4,

since `e_1^T E_12 e_2 = 1`. So `p |-> P`, `q |-> Q` defines a unital ring map
`theta : U -> M_4(R)`.

**Surjectivity.** The image contains `e_ij(s) - 1 = sE_ij` for all `s in R` and
`i != j`. It also contains `(sE_ij)(E_ji) = sE_ii`. So it contains every `sE_ij`,
and therefore all of `M_4(R)`.

## Step 4. The kernel is finitely generated

`M_4(R) ≅ R` (Step 0) is finitely presented. We use the ring form of Tietze's
lemma. Let `A = Z<z_1, ..., z_a>/(u_1, ..., u_b)` be finitely presented and
`theta : A ->> B` surjective, with `B` finitely presented. The images
`theta(z_i)` generate `B`.

Suppose `B = Z<y_1, ..., y_c>/(v_1, ..., v_d)`. Choose noncommutative
polynomials with `y_j = f_j(theta(z))` and `theta(z_i) = h_i(y)`. Then `B` is
presented on the generators `z_i` by the finitely many relations

    u_1, ..., u_b,    z_i - h_i(f(z)),    v_l(f(z)).

To see this, the Tietze moves are: add the `y_j` together with the relations
`y_j = f_j(z)` and `z_i = h_i(y)`, and then eliminate the `y_j`. The `u_i` hold
in `B`, so adding them changes nothing.

Let `J` be the ideal of `Z<z>` generated by these relations. It contains
`(u_1, ..., u_b)`, and `Z<z>/J ≅ B` compatibly with `theta`. So
`ker theta = J/(u)` is generated by the finitely many images of
`z_i - h_i(f(z))` and `v_l(f(z))`. Put `I = ker theta`.

Then `U/I ≅ M_4(R) ≅ R`, and by (1b) `PE_4(U/I) ≅ PE_4(M_4(R))`. By Step 0,
`M_4(R) ≅ R` as rings, so `PE_4(U/I) ≅ PE_4(R)`. This proves 2.

## Step 5. The hole

Let `S <= R^x` be perfect. By [[perfect-unit-subgroups-embed-in-elementary-groups]],
`u |-> diag(u,1,1,1)` embeds `S` in `E_4(R) = H`. The hole
[[ck-sandwich-ring-has-fp-projective-simple-quotient]] asks for finitely presented
`H`, `T` with `H <= [T,T]` and `H` containing `S`, a nontrivial `g in H`, and a
finitely generated ideal `I != U` of the resulting `U` with `PE_4(U/I)` finitely
presented and simple.

Steps 2–4 supply all of these. `I != U` because `U/I ≅ R != 0`, since a simple
group `PE_4(R)` is nontrivial. This proves 3.

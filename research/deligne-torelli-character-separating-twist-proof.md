Notation as in the target. Inputs:
- **[TSQ]** `deligne-triple-cover-is-a-torelli-scalar-quotient-of-mod-s2`, items (TS1)–(TS5);
- **[MESS]** `genus-two-torelli-freely-generated-by-separating-twists`, item 3: `K` is generated by Dehn
  twists about essential separating curves.

Standard facts used, not re-pinned:
- (F1) the classification of compact orientable surfaces;
- (F2) for an orientation-preserving homeomorphism `f` and a simple closed curve `a`,
  `T_(f(a)) = f T_a f^(-1)`;
- (F3) the Dehn twist about a separating curve acts trivially on `H_1(S_2; Z)`. Its action is
  `x -> x + <[s], x> [s]`, and `[s] = 0`.

## Step 1 (ST1)

**The two sides of s.** Let `s` be an essential separating simple closed curve. Cutting along `s` gives
compact surfaces `L` and `R`, each with one boundary circle, and `chi(L) + chi(R) = chi(S_2) = -2`.
- Neither side is a disc, because `s` is essential.
- So each side has `chi = 1 - 2 genus <= -1`, which gives `chi(L) = chi(R) = -1`.
- So both sides are genus-one surfaces with one boundary component.

**Moving s to s'.** Let `s'` be another essential separating curve, with sides `L'` and `R'`.
- By (F1) there are orientation-preserving homeomorphisms `L -> L'` and `R -> R'`.
- Composing with a homeomorphism supported in a collar of the boundary, both restrict on the boundary to
  the same orientation-preserving homeomorphism `s -> s'`. Here `s` carries the boundary orientation from
  `L`, which is the reverse of that from `R`, and similarly for `s'`. Any two orientation-preserving
  homeomorphisms of a circle are isotopic, which is what lets the collar adjustment match them.
- Gluing gives an orientation-preserving homeomorphism `f` of `S_2` with `f(s) = s'`. So
  `T_(s') = f T_s f^(-1)` by (F2).

Separating twists lie in `K` by (F3). By [MESS], `K` is generated by twists about essential separating
curves, each conjugate to `t_s`. So `K` is the normal closure of `t_s`.

## Step 2 (ST2)

By (TS1), `c` is a homomorphism `K -> Z/3`, constant on `M`-conjugacy classes. So `c(T_(s')) = c(t_s)`
for every essential separating `s'`, and `epsilon` doesn't depend on `s`.

**epsilon is a unit.** If `epsilon = 0`, then `c` vanishes on all conjugates of `t_s`, hence on their
normal closure `K`. That contradicts `c != 0` from (TS2). Since `3` is prime, `epsilon in {1, 2}`.

**The formula.** For `k = prod_j g_j t_s^(e_j) g_j^(-1)`, apply homomorphism and invariance to get
`c(k) = sum_j e_j c(t_s)`. Such an expression exists by Step 1.
- The Mess basis elements are twists about essential separating curves, so `c(T_x) = epsilon`, and
  `c(prod_i T_(x_i)^(f_i)) = epsilon sum_i f_i`.
- `c` is surjective because `epsilon` is a unit.
- `ker c` is as described because `epsilon` is invertible mod 3.

## Step 3 (ST3)

Apply (TS3) with the one-element normal generating list `k_1 = t_s`, which is valid by Step 1. Since
`c(k_1) = epsilon`, the corrected relator is `t_s z^(-epsilon)`.

## Step 4 (ST4)

By (TS5), with the normal generating list `{t_s}` (valid by Step 1; (TS5) allows any finite normal
generating list), `E_3` is hyperlinear iff there are a primitive cube root `zeta'` and vanishing-defect
tuples with `||rho_n(t_s) - zeta'^(epsilon) I||_2 -> 0`.
- **Forward:** put `zeta = zeta'^(epsilon)`. It is again a primitive cube root, because `epsilon` is a
  unit mod 3.
- **Converse:** given `zeta`, put `zeta' = zeta^(epsilon^(-1))`, with `epsilon^(-1)` taken mod 3.

## Step 5 (ST5)

Suppose `rho : M -> U(d)` has `rho(t_s) = omega^j I` with `j in {1, 2}`. Scalars are central, so
`rho(g t_s g^(-1)) = omega^j I` for all `g`, and `rho` is scalar on `K` by Step 1.

Pick `u` with `u epsilon = j` mod 3, which is possible because `epsilon` is a unit. For
`k = prod g_i t_s^(e_i) g_i^(-1)`,
```text
rho(k) = omega^(j sum e_i) I = omega^(u epsilon sum e_i) I = (omega^u)^(c(k)) I.
```
`omega^u` is a primitive cube root, because `u` is a unit (as `j` and `epsilon` are). So `rho` is
`zeta^(c(k))`-scalar on `K` for `zeta = omega` or `omega^2`, which (TS4) excludes.

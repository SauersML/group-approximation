## Setting

`G = G(M)` is the KMS group of a Minsky machine with `K` counters over `F_p`. `B = G/T` is its
metabelian quotient, presented by G1–G4 on `L_1 ∪ L_2`, with `Q = H_2 ≅ Z^(4K)` spanned by the
letters `a_i, a_i', ã_i, ã_i'`. A *commensuration* is an isomorphism `φ : C_1 -> C_2` between
finite-index subgroups.

## Statement

1. **Structure.** `B = E ⋊ Q` with `E = H_1^(H_2)`, and as `F_p[Q]`-modules
   `E = R_1 ⊕ ⋯ ⊕ R_K ⊕ R_0`, where:
   - `R_i ≅ R := F_p[x^(±1), (1−x)^(-1)]`, via `A_i ↦ 1`, `a_i ↦ x`, `a_i' ↦ x/(1−x)`. The other
     letters act trivially on `R_i`. So the i-th counter block `R ⋊ ⟨a_i, a_i'⟩` is a
     Baumslag–Remeslennikov group.
   - `R_0 ≅ R^(⊗K)`, via `A_0 ↦ 1` and `ã_i, ã_i'` on the i-th factor. The `a`-letters act trivially
     on `R_0`.
   - All the `R_j` are domains.
2. **Rank norm.** For a monomial `q = a^(q_1) a'^(q_2)` of a counter block, `R` is a finitely
   generated `F_p[q^(±1)]`-module iff `q_1 q_2 (q_1 + q_2) ≠ 0`. Its rank is then
   `D(q) = (|q_1| + |q_2| + |q_1 + q_2|)/2`. So `D` is a norm whose unit ball is the hexagon with
   vertices `±(1,0), ±(0,1), ±(1,−1)`.
3. **Rigidity.** Let `φ` be a commensuration of `B`, with induced `ψ ∈ GL_(4K)(Q)`. Then:
   - `ψ` permutes the `K` counter planes `P_i = ⟨a_i, a_i'⟩ ⊗ Q`, together with the `ã`-block when
     `K = 1`;
   - on each counter plane it is a linear isometry of `D`, i.e. one of the 12 symmetries of the
     hexagon;
   - so `ψ` has finite order on the counter lattice. It is never a homothety `λ ≠ 1`: Frobenius
     (`λ = p`), Cartier (`λ = 1/p`) and every Baumslag–Solitar-type scaling are excluded.
4. **Transfer to `G(M)` (conditional).** Suppose a commensuration of `G(M)` maps `T ∩ C_1` onto
   `T ∩ C_2`. Then it descends to `B`, so item 3 holds for it.
   - This lane could not prove that `T` is preserved. The natural characterizations of `T` inside
     the torsion layer fail: `A_i` acts on the configurations with `(A_i − 1)^2 = 0` (G5a, G5c), and
     G6 makes the diagonal `a_i ã_i^(-1)` fix the `x_(q_j)`.
5. **Σ^1 (recalled, consistent).** By the BNS product formula and Bieri–Strebel theory for cyclic
   modules over `Z^2`, `Σ^1(B)^c` is:
   - in each counter plane, the three rays `±{(1,1), (−1,0), (0,−1)}` (one sign choice, depending on
     convention);
   - on the `ã`-block, the sphere image of the product of `K` such tripods.

   These rays are exactly the directions where `D` is not smooth, i.e. where the rank of item 2 is
   infinite. The complement has no antipodal pair, consistent with `B` being finitely presented.
   Item 3 does not depend on this item.

## Proof

**Item 1.**
- By Lemma lBRG and relations G1–G4, `B` is metabelian with abelian normal subgroup
  `E = H_1^(H_2)` of exponent `p` (Lemma lH).
- `E` is the `F_p[Q]`-module generated by `A_0, …, A_K` with the following relations:
  - `A_i` is fixed by the letters of `M_j`, `j ≠ i` (G2);
  - `A_i (a_i^(-1) − 1 − a_i'^(-1)) = 0` (G3);
  - `A_0 (ã_i^(-1) − 1 − ã_i'^(-1)) = 0` for all `i` (G4).
- So `R_i = F_p[a^(±1), a'^(±1)] / (a^(-1) − 1 − a'^(-1))`. Clearing denominators gives
  `a' = a/(1−a)`, which is the ring `R`. The same computation factor by factor gives `R_0`.
- `R` is the coordinate ring of `P^1` minus `{0, 1, ∞}`. It is geometrically integral over `F_p`, so
  tensor powers of it are domains.

**Item 2.**
- `q` is the unit `u = x^(q_1+q_2) (1−x)^(-q_2)`. Its orders at the three punctures
  `x = 0, 1, ∞` are `q_1 + q_2`, `−q_2` and `−q_1`. These are `⟨q, r⟩` for
  `r = (1,1), (0,−1), (−1,0)`.
- `R` is finite over `F_p[u^(±1)]` iff `u : C -> G_m` is proper. That holds iff `u` has a zero or
  pole at every puncture.
- The rank is then the degree of `u`: the sum of the positive orders, which is `D(q)`.
- For a subgroup `M <= R` of finite index, the rank is the same.

**Item 3.**
- **Fixed sets.** For `L <= Λ_1 = C_1/(E ∩ C_1)`, let `F(L)` be the set of fixed points of `L` in
  `E ∩ C_1` (lifts differ by elements of `E`, which acts trivially on `E`). Then
  `φ(F(L)) = F(ψ(L))`.
  - Each `R_j` is a domain, and each nonzero `q ∈ Q_j` acts on `R_j` by a monomial `≠ 1`.
  - So `F(L) = (⊕_(j : π_j L = 0) R_j) ∩ C_1`, and `F(L) ≠ 0` iff `L <= ker π_j` for some `j`.
- **Blocks.** Up to finite index, the maximal `L` with `F(L) ≠ 0` are the `Λ_1 ∩ ker π_j`. So `ψ`
  permutes the subspaces `ker π_j ⊗ Q`, and hence the blocks, since each block is an intersection of
  the others' kernels.
  - Dimensions separate the counter planes (dimension 2) from the `ã`-block (dimension `2K`) when
    `K >= 2`.
  - Applied to `L = Λ_1 ∩ ker π_i`, this gives `φ(R_i ∩ C_1) = R_(σ(i)) ∩ C_2`, semilinear over the
    block map `ψ_i`.
- **Norm.** A semilinear bijection carries `F_p[q^(±1)]`-rank to `F_p[ψ_i(q)^(±1)]`-rank. By item 2,
  `D(ψ_i q) = D(q)` for all generic `q ∈ π_i(Λ_1)`, and so on all of `P_i ⊗ R` by homogeneity and
  continuity.
  - The linear isometries of a hexagonal norm form its symmetry group, of order 12.
  - A homothety `λ` has `D(λq) = λ D(q)`, so `λ = 1`.

**Item 4.** If `φ(T ∩ C_1) = T ∩ C_2`, then `φ` induces an isomorphism
`C_1/(T ∩ C_1) -> C_2/(T ∩ C_2)` between finite-index subgroups of `B`, with the same `ψ`.

## Consequences for (SS-hard)_1

- **Renormalization is dead for KMS (modulo item 4).** No commensuration rescales the counters. So
  a faithful HNN extension of `G(M)` (`faithful-finite-index-hnn-upgrades-to-half-tree-free`, item 4)
  would have to shrink normal subgroups inside the configuration layer `T` at a fixed counter scale.
- **The surviving shape is division.** Calibration: the lamplighter `F_p[x^(±1)] ⋊ Z` has the faithful
  ascending HNN extension given by division by `1 + x`, from `(1+x)F_p[x^(±1)] ⋊ Z` onto the whole
  group. It is faithful because `⋂_k (1+x)^k F_p[x^(±1)] = 0`. The same division works on each
  counter block `R`, for every non-unit `r` (commensurations with `ψ = id`, allowed by item 3). For
  `G(M)` it needs an injective endomorphism of the `C_1`-module `T ∩ C_1` with finite cokernel and
  no divisible part.
- **Tension.** Finite cokernel is natural in Noetherian module layers. KMS hardness sits in the
  configuration module `T`, which is not finitely generated over any Noetherian subring: KMS needs
  solvability class 3, because metabelian groups are easy.
- **Next candidate family.** Finitely presented groups with a hard word problem carried by a
  *Noetherian* module layer:
  - abelian-by-polycyclic groups are the model. They are residually finite (Roseblade–Jategaonkar,
    recalled), and division by an element acting injectively with finite cokernel is available there.
  - The open test is whether such groups reach arbitrarily high word-problem complexity. Mayr–Meyer
    type bounds for Noetherian membership suggest a uniform recursive bound, which would kill this
    family too.
  - If so, hard inputs for finite-type hosts need non-solvable, tree-like (branch-type) vertex
    groups.

## Lesson for general BH

**Rank norms rigidify commensurations; division is the only shrinking left.** A commensuration
preserves the rank of each module layer over every monomial subring. For the KMS counter blocks,
that rank is a hexagonal norm, so counters can be permuted and reflected but never rescaled.
Renormalizing a machine by scaling its counters is impossible, and not only for the Frobenius and
Cartier maps tried before.

What remains is division at fixed scale (the lamplighter-to-Baumslag mechanism). It needs finite
cokernels, which come from Noetherian layers, while unbounded word-problem complexity needs
non-Noetherian ones. So (SS-hard)_1 asks for a vertex group that is non-Noetherian where it is hard
and Noetherian where it shrinks.

## Notation

- `x0 = P` is the base coset.
- `L_j = t^-j P t^j`, for `j >= 0`.  These subgroups increase, because
  `tPt^-1 <= P`.  Their union is `N = ker(ht) = Gamma(3) ltimes Z[1/2]^3`,
  and `H = N semidirect <t>`.
- `Lambda = Gamma(3)`.
- `lambda_x` denotes the lamp `lambda in Lambda` at the site `x`.

## Step 0. The lamp group

`Lambda` is a quotient of `P` (kill `Z^3`), and `P` has property (T) by
`affine-congruence-source-is-kazhdan`.  So `Lambda` has property (T).

It follows that:
- `Lambda_ab` is finite;
- `[Lambda,Lambda]` has finite index, so it is infinite and Kazhdan.

`Lambda` is torsion-free, being a subgroup of the torsion-free `P`.  It is
nonabelian: `[x_12(3), x_23(3)] = x_13(9)`.  It is finitely generated and
residually finite, being linear over `Z`.

## Step 1. Group-theoretic properties

**Finitely generated.**  `H` is generated by the generators of `P` and `t`,
and it acts transitively on `X`.  Every lamp group `Lambda_x` is an
`H`-conjugate of `Lambda_(x0)`.  So finitely many generators of
`Lambda_(x0)`, `P` and `t` generate `W`.

**Torsion-free.**  `H` is torsion-free.  To see this, let
`[[2^h A, v],[0,1]]` have finite order.  The determinant forces `h = 0`.
Then `A^n = 1` forces `A = 1`, since `Gamma(3)` is torsion-free.  Then
`nv = 0` forces `v = 0`.

The base `Lambda^(X)` is torsion-free.  An extension of a torsion-free group
by a torsion-free group is torsion-free.

**Sofic.**  Every `L_j`-orbit on `X` is finite.  This is the finite-index
step of `perfect-lamp-compression-and-finite-orbit-sofic-proof`, applied to
the index-8 embedding of the affine node.

Consequently `Lambda^(X) semidirect L_j` is residually finite.  To see
this, let `(f, g)` be nontrivial.
- If `g != 1`, a finite quotient of the linear group `L_j` separates it.
- If `g = 1`, the support of `f` lies in a finite `L_j`-invariant set `O`,
  a finite union of orbits.  Coordinate projection is an `L_j`-equivariant
  homomorphism onto `Lambda^O semidirect L_j`, and it keeps `f`.  That group
  contains `Lambda^O x ker(L_j -> Sym(O))` with finite index.  This subgroup
  is a product of residually finite groups, so `Lambda^O semidirect L_j` is
  residually finite.

Hence `R = Lambda^(X) semidirect N`, the increasing union of the groups
`Lambda^(X) semidirect L_j`, is LEF, hence sofic.

Finally, `W = R semidirect <t>`.  An extension of a sofic group by an
amenable group is sofic (Elek--Szabo, *On sofic groups*, J. Group Theory
2006).  Here the quotient is `Z`, and nothing beyond this extension step is
needed.

## Step 2. The lower bound on the radical

Apply `kazhdan-centralizer-commuting-conjugates-kill-derived-subgroup`
(KC2) with the following data:
- `G = W`, `L = P` (Kazhdan) and `u = t`, so `tPt^-1 <= P`;
- `C = Lambda_(x0)`, which is Kazhdan;
- `ell = (1, e_1)`, which lies in `P` but not in `tPt^-1`.

The hypotheses hold:
- `C` centralizes `P`.  Each `p in P` fixes `x0`, so
  `p lambda_(x0) p^-1 = lambda_(p x0) = lambda_(x0)`.
- `t C t^-1 = Lambda_(t x0)` and `ell t C t^-1 ell^-1 = Lambda_(ell t x0)`.
- The sites differ: `ell t x0 = t x0` would mean `t^-1 ell t in P`, that is
  `ell in tPt^-1`, which is false.
- Lamps at distinct sites commute, so (KC0) holds.

So `[Lambda,Lambda]_(x0)` lies in `Rad_MF(W)`.  By `H`-conjugation, so
does `[Lambda,Lambda]^(X)`.

## Step 3. The exact radical

Any subgroup `M <= Rad_MF(W)` that is normal in `W` satisfies
`Rad_MF(W) = pi^-1(Rad_MF(W/M))`.  The reason is that every homomorphism
to an MF group kills `M`.  Take `M = [Lambda,Lambda]^(X)`.  Then

```text
W/M = (Lambda_ab)^(X) semidirect H,     Lambda_ab finite abelian.
```

Apply Theorem 3 of `wreath-compression-mf-radical`, from
`notes/COMPRESSION_COLLAPSE_MF_RADICAL.md` Section 4, with:
- lamp `K = Lambda_ab`, which is finite and hence generated by torsion;
- `Gamma = Stab(x0) = P`;
- compressors `t^j`, for `j >= 1`.

The move of its Theorem 2 identifies the site `t^j x0` with `ell t^j x0`,
for `ell in P`.  By `H`-equivariance this identifies `x0` with
`t^-j ell t^j x0`.  So the block subgroup is

```text
J = < P, t^-j P t^j : j >= 1 > = N,
```

and the fibres of `X -> H/N ≅ Z` are exactly the height levels.  Its
factorization gives

```text
Rad_MF(W/M) = ker( (Lambda_ab)^(X) -> (Lambda_ab)^(Z) ),
```

where the map multiplies the lamps over each level.  This holds provided
the quotient `(Lambda_ab)^(Z) semidirect H` is MF.  It is in fact residually
finite:
- it embeds in `H x (Lambda_ab wr Z)` by `(f, g) -> (g, (f, ht(g)))`;
- `H` is residually finite (affine node);
- `Lambda_ab wr Z` is residually finite, because `Lambda_ab` is finite
  abelian.

Both halves of this argument are recorded in Section 5 of the note, for
the `SL_3(Z)`-doubling pair.  The proof uses only:
- that the stabilizer is Kazhdan;
- the compressors;
- residual finiteness of `H`.

All three hold here unconditionally.  Pulling back along `pi` gives the
displayed formula.  `W` is not MF, since `Rad_MF(W) >= [Lambda,Lambda]_(x0)`,
which is nontrivial.

## Step 4. Kazhdan subgroups inside the radical

- `[Lambda,Lambda]_(x0)` is infinite, Kazhdan and torsion-free (Step 0).
- Heights: `t x0` and `ell t x0` both have height `1`, and they are distinct
  (Step 2).  So every level contains two distinct sites `x`, `y`.
- The group `E = {(a,b) in Lambda_x x Lambda_y : ab in [Lambda,Lambda]}`
  lies in the radical by the formula.  Its index in `Lambda x Lambda` is
  `|Lambda_ab|`, so it is Kazhdan.  It projects onto `Lambda` at `x`, via
  `a -> (a, a^-1)`.

## Step 5. The torsion companion

Now take the lamp `SL_3(Z)`.
- It is Kazhdan and perfect.
- It is generated by torsion, because each elementary matrix lies in a copy
  of `SL_2(Z) = <S, ST>`, with `S` and `ST` of orders 4 and 6.

Theorem 3 then applies directly, with `K_ab = 1`, and gives
`Rad_MF = SL_3(Z)^(X)`.  Soficity is Step 1 verbatim, since `SL_3(Z)` is
residually finite.

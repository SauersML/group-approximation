Artifact part 2, §6.

1. **Freeness of the odometer.** If `g` fixes `(x_i Γ_i)` in `←F_r`, then `g ∈ ∩ x_i Γ_i x_i^(-1) = ∩ Γ_i = {e}`.
2. **Topological freeness.** `π` is almost 1-1, so the points with one-point fibres form a dense
   `G_δ`. If `gx = x` at such a point, then `g πx = πx`, so `g = e`.
3. **Minimality.** `X` is the orbit closure of a Toeplitz element `η`. For a finite window `F`, take the
   finite-index normal subgroup `Γ = ∩_(g ∈ F) Γ_g`, where `η` is constant on `Γ_g g`. Every `γ ∈ Γ` is a
   return time of the pattern `η|_F`, so return times are syndetic. So `η` is almost periodic and its
   orbit closure is minimal (Gottschalk).
4. **Ring.** `Σ` is finite, so the translates `u_g χ_[x(e)=a] u_g^(-1)` give all single-site cylinders,
   and products and sums give `LC(X, F_q)`. `R` is generated by `u_(s_i)^(±1)`, the letter cylinders,
   and a primitive element when `q` is not prime. It is simple by artifact part 1, Lemma 2.1.
5. **Matricial.** Unique ergodicity gives (i) of `free-group-crossed-product-matricial-iff-invariant-measure`,
   hence (iii).
6. **Groups.** `GL_m(R)` embeds in `∏_ω GL_(m N_n)(F_q)`. `EL_n(R)` has (T) for `n >= 3` by
   `elementary-groups-over-fg-rings-have-property-t`.

**ESTABLISHED** (lane proof, elementary, proved below; not independently reviewed; no priority claimed).

**Statement.** Let `X = X_1 ⊔ ... ⊔ X_n` with every `X_k` infinite, and let `G_k <= Sym(X_k)` satisfy:
- (a) `G_k` is finitely presented;
- (b) `FSym(X_k) <= G_k`;
- (c) for one (hence every) point `x in X_k`, `Stab_(G_k)(x)` is finitely generated.

Put `G = G_1 x ... x G_n <= Sym(X)` and `B = G · FSym(X)`. Then `B` is finitely presented.

**Proof.** Fix base points `x_k in X_k`, and for `2 <= j <= n` fix `y_j in X_j`. Let `τ_j = (x_1 y_j)`.

*Presentation.* Generators: a finite generating set of `G` plus letters `t_2, ..., t_n`. Relations:
- (R1) a finite presentation of `G` (from (a));
- (R2) `[t_j, u] = 1` for `u` in a finite generating set of `Stab_G(x_1, y_j) = Stab_(G_1)(x_1) x Stab_(G_j)(y_j) x ∏_(k≠1,j) G_k`, finitely generated by (c);
- (R3) for `i,j >= 2`, `i ≠ j`, put `t_ij = t_i t_j t_i` and impose `[t_ij, u] = 1` for `u` in a finite generating set of `Stab_G(y_i, y_j)`;
- (R4) for each `G`-orbit of ordered pairs `(τ, σ)` of transpositions of `X`, one relation `τ σ τ = τ(σ)` for a chosen representative, where every transposition is written as below.

*Writing transpositions.* A transposition inside one `X_k` is an element of `FSym(X_k) <= G_k`, written as a word in
`G`. A transposition `(a b)` with `a in X_1`, `b in X_j` is written `w^-1 t_j w` for any `w in G` with
`w(a) = x_1`, `w(b) = y_j`. One with `a in X_i`, `b in X_j` (`i,j >= 2`) is written `w^-1 t_ij w` with
`w(a) = y_i`, `w(b) = y_j`. Such `w` exist because each `G_k` is transitive on `X_k` by (b).

*Finitely many relations.* `G` acts on ordered pairs of transpositions. An orbit is determined by which `X_k`
contains each of the at most four points and by the coincidence pattern, because each `G_k` is transitive on
ordered 4-tuples of distinct points of `X_k` by (b). So (R4) is finite.

Let `B̃` be the presented group and `π : B̃ -> B` the natural map. It is onto: `FSym(X)` is generated by the
transpositions, and each is a `G`-conjugate of an internal transposition, a `τ_j`, or a `τ_i τ_j τ_i = (y_i y_j)`.

*Step 1: `G` embeds.* By (R1) the subgroup `G̃ <= B̃` generated by the `G`-letters is a quotient of `G` that maps
onto `G`, so `π : G̃ -> G` is an isomorphism.

*Step 2: transpositions are well defined.* Let `T̃ ⊂ B̃` be the set of elements `w^-1 t_j w`, `w^-1 t_ij w`
(`w in G̃`), together with the internal transpositions in `G̃`. If `w, w' in G̃` send `(a,b)` to `(x_1, y_j)`,
then `w' w^-1` maps to `Stab_G(x_1, y_j)`. By Step 1 it is a product of the lifted generators in (R2), so it
commutes with `t_j`, and `w^-1 t_j w = w'^-1 t_j w'`. The same holds for `t_ij` by (R3). So
`π : T̃ -> {transpositions of X}` is a bijection, and it is `G̃`-equivariant for conjugation (by construction for
cross transpositions, and by Step 1 for internal ones).

*Step 3: the finitary part.* Let `K̃ = <T̃>`. By (R4) and `G̃`-equivariance, every relation `τ σ τ = τ(σ)` holds
in `K̃`, for all pairs of transpositions. These relations, with `τ^2 = 1` (a case of (R4)), present `FSym(X)` on
the set of all transpositions. So `K̃` is a quotient of `FSym(X)` mapping onto `FSym(X)` by the identity on
generators, and `π : K̃ -> FSym(X)` is an isomorphism.

*Step 4: injectivity.* `G̃` normalizes `K̃` (it permutes `T̃`), and `t_j in K̃`, so `B̃ = G̃ K̃`. If
`π(w k) = 1` with `w in G̃`, `k in K̃`, then `π(w) in G ∩ FSym(X) = ∏_k FSym(X_k)`. So `w` is a product of internal
transpositions, and `w in K̃`. Then `wk in K̃` with `π(wk) = 1`, so `wk = 1` by Step 3. ∎

**Remarks.**
- Hypothesis (b) cannot simply be dropped: for trivial `G_k`, `B = FSym(X)` is not even finitely generated.
- No shift structure is used. The consumer is `fp-strongly-shift-similar-groups-have-fp-houghton-like-groups`.

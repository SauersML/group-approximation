## The problem (Kourovka Notebook, 21st issue, 2026, Problem 20.44, S. Kohl), verbatim

> The definition of CT(Z) is given in 17.57. Is it true that a finitely generated subgroup of
> CT(Z) either has only finitely many orbits on Z or there is a set of representatives for its
> orbits on Z which has positive density?

## Setting

Notation is that of `ct-z-frozen-tails-anywhere-give-kourovka-20-44`:
- `G = ⟨S⟩ ≤ CT_P(Z)`, `P` finite, given by tables of pieces with inverse tables;
- `D` bounds every piece degree, and `Π = ∏_{p ∈ P ∪ {2}} p`;
- tails `σ^n`, tracking, reading and frozen degrees as there;
- **TC** (totally consumable): no point of `Ẑ` has a frozen degree.

**Local slope groups.**
- Every `h ∈ G` is affine on some residue class containing a given `x ∈ Z`, with a slope
  `q(h, x) ∈ Q_{>0}`.
- `ν(q(h, x)) ∈ Z^{P ∪ {2}}` is the degree cocycle `c(h, x)`: by the uniform-shift fact, every
  tail of `x` left unread along `h` moves by exactly `ν(q(h, x))`.
- The **local slope group** `Γ_x ≤ Q_{>0}` is generated by `{q(h, x) : h ∈ G}`.
- It depends only on the orbit, because `q(hg, x) = q(h, gx)·q(g, x)`. Write `Γ_O`.
- `Γ_O` lies in the global slope group `Γ(G)`, and can be much smaller.
- Call `O` an **integer-ray orbit** if `Γ_O ⊆ γ^Z` for some integer `γ ≥ 2`, which may
  depend on `O`. In lattice terms, `ν(Γ_O) ⊆ Z v_O` with `v_O ∈ N^k`.

## Theorem A (the corner argument is orbit-local)

Let `G ≤ CT(Z)` be finitely generated and TC.
1. Every integer-ray orbit meets `[−Π^D, Π^D)`. So `G` has at most `2Π^D` integer-ray orbits.
2. **Corollary.** Kourovka 20.44 holds for every finitely generated `G ≤ CT(Z)` all but finitely
   many of whose orbits on Z are integer-ray orbits:
   - if `G` has a frozen degree somewhere, it has a transversal of positive lower density, by
     `ct-z-frozen-tails-anywhere-give-kourovka-20-44`;
   - otherwise `G` is TC, and item 1 leaves only finitely many orbits.

*Proof of 1.* Let `x ∈ O`, `x ≥ 0`, with `ν(Γ_O) ⊆ Z v`, `v ∈ N^k`.
- **`v ≠ 0`.** If `Γ_O = 1`, tails of `x` never move, so no degree `K ≥ D·1` is ever read from
  `x`, against TC.
- **The chain.** Put `K_s = s v + D·1`. Choose `s ≥ 0` with `m_(K_s) > x`, so `σ^(K_s) x = 0`.
- **Reading.** By TC some word reads the tail at `K_s`. Let `w = h′x` be the configuration just
  before the reading move.
  - The tail then sits at `K′ = K_s + c(h′, x)`, and `c(h′, x) ∈ ν(Γ_O) ⊆ Z v`. So `K′ = K_(s+t)`
    for some `t`, and `K′ ∈ N^k`.
  - The reading piece has `d(λ) ≤ D·1` and `d(λ) ≰ K′`. If `s + t ≥ 0` then `K′ ≥ D·1`, since
    `v ≥ 0`. Hence `s + t < 0` and `K′ = D·1 − |s + t| v ≤ D·1`.
  - Tracking carries the unread tail unchanged, so `σ^(K′) w = σ^(K_s) x = 0`.
  - Therefore `w = ρ_(K′)(w) ∈ [0, m_(K′)) ⊆ [0, Π^D)`, and `w ∈ O`.
- **Negative `x`.** Choose `m_(K_s) ≥ |x|`, so the tail is `−1`, and get `w ∈ [−Π^D, 0)`. ∎

This is word for word the proof of item 1 of `ct-p-z-ray-cocycle-subgroups-satisfy-kourovka-20-44`.
The one new observation is that it only ever uses cocycle values along the orbit of `x`. The
window `Π^D` does not depend on `v`, so the ray may change from orbit to orbit.

**Why the corner argument stops at integer rays (explanation, not a theorem).** The tail of `x`
lives in `(K + ν(Γ_O)) ∩ N^k`.
- If `ν(Γ_O)` is cone-avoiding (for example `Γ_O = (3/2)^Z`), every such set is finite. But no
  single one reaches all large `x`, and the reading degrees grow with `K`.
- In every other non-ray case, the set has tubes: infinitely many degrees with one coordinate
  `< D`, where reading can happen with an unbounded configuration.

## Theorem B (joins: slope lattices carry no hardness)

**Restriction.**
- For `0 ≤ i < j`, let `φ_(i,j)(n) = i + jn`, a bijection `Z → i(j)`.
- For `g ∈ CT(Z)`, let `g^(i,j)` act as `φ g φ^(−1)` on `i(j)` and as the identity elsewhere.
- This is Kohl's restriction monomorphism `CT(Z) → CT(Z)`. It sends the class transposition
  `τ_(r(m), s(m′))` to `τ_((i+jr)(jm), (i+js)(jm′))`.
- It preserves every slope, and it multiplies every piece modulus by `j`.

**Tame carriers.** Let `γ ≠ 1` be a positive rational, and write `γ^(±1) = a/b` with `1 ≤ a < b`
coprime. For each `r ∈ [0, 2b)`, pick `s_r ∈ [0, 2a)` of the other parity, and put
`E_γ = ⟨τ_(r(2b), s_r(2a)) : 0 ≤ r < 2b⟩`.
- The two classes of each generator are disjoint, since `r ≢ s_r mod 2 = gcd(2a, 2b)`.
- Every slope is `a/b`, `b/a` or `1`, so `Λ(E_γ) = Z ν(γ)`.
- **Every orbit meets `[−2b², 2ab)`.** Write `x = r + 2bz`; the generator for `r` sends `x` to
  `y = s_r + 2az`.
  - If `x ≥ 2ab`, then `z ≥ a`, and `y − x ≤ 2a − 1 − 2(b − a)z < 0`, with `y ≥ 0`.
  - If `x ≤ −2b²`, then `z ≤ −b`, and `|y| ≤ 2a|z| < 2b|z| − 2b + 1 ≤ |x|`, with `y < 0`.
  - So `|x|` strictly decreases until `x ∈ [−2b², 2ab)`.

  For example, `E_(3/5)` uses `τ_(r(10), s_r(6))`, and its orbits meet `[−50, 30)`.

**Joins.**
- Let `H ≤ CT(Z)` be finitely generated, and let `Λ ≠ 0` have a basis `ν(γ_1), …, ν(γ_t)`.
- The **join** `G = H ⊔ Λ` is generated by `H^(0, t+1)` and `E_(γ_i)^(i, t+1)` for `1 ≤ i ≤ t`.
- Its generator tables are the restricted tables plus identity pieces on the other classes mod
  `t+1`.
- **The tame carrier `T_Λ`** is built on `t` classes, not by deleting `H` from the join:
  `T_Λ = ⟨E_(γ_i)^(i−1, t) : 1 ≤ i ≤ t⟩`, and `T_Λ = E_(γ_1)` when `t = 1`. (Repair from the bh-ref-q12
  review: deleting `H` from `H ⊔ Λ` would leave the class `0(t+1)` fixed pointwise, which gives
  infinitely many singleton orbits.)

**Theorem B.**
1. **Every nonzero lattice is tame.** `T_Λ` is a finitely generated subgroup of `CT(Z)` with
   `Λ(T_Λ) = Λ` and finitely many orbits on Z, hence TC (item 1 of
   `ct-z-totally-consumable-core-of-kourovka-20-44`).
2. **Joins preserve everything that matters.** `G = H ⊔ Λ` is finitely generated, and:
   - `Λ(G) = Λ(H) + Λ`;
   - `G` is TC iff `H` is TC;
   - `G` has finitely many orbits iff `H` has;
   - `G` has a transversal of positive (lower or upper) density iff `H` has.

*Proof.*
- **1.** The factors act on disjoint classes, each with finitely many orbits. Slopes add up to
  `Λ`, because restriction preserves slopes.
- **Orbits.** Each generator of `G` preserves every class mod `t+1` and acts nontrivially on
  exactly one of them. So the orbits of `G` on Z are the images of the orbits of `H` under
  `φ_(0, t+1)`, together with finitely many other orbits.
- **Density.** `φ_(0, t+1)` is increasing, maps `N_0` into `N_0` and negatives to negatives, and
  scales densities by `1/(t+1)`. Every transversal of `G` is the image of a transversal of `H`
  plus finitely many points.
- **TC on the carrier classes.**
  - Suppose `n` is frozen for `G` at a point `y` in the closure of `i(t+1)`, `i ≥ 1`.
  - `Y_n` is a clopen union of classes containing `y`, so it contains a class `c(M) ⊆ i(t+1)`.
  - Each `G`-orbit holds at most `A_n` points of `Y_n` (Lemma 2 of the frozen-tails node). So
    infinitely many `G`-orbits meet `i(t+1)`.
  - That contradicts finiteness of the `E_(γ_i)`-orbits.
- **TC on the class `0(t+1)`.** Put `ν_0 = ν(t+1)`.
  - By prefix arithmetic, `σ^(n+ν_0)((t+1)y′) = σ^n(y′)`.
  - Restricted pieces have degrees shifted by `ν_0`, and the identity pieces never read a degree
    `≥ ν_0`.
  - So a `G`-word reads the degree `n + ν_0` at `(t+1)y′` iff the corresponding `H`-word reads
    `n` at `y′`.
  - Frozen degrees form an up-set. So `G` has a frozen degree on `0(t+1)` iff `H` has one
    somewhere. ∎

## Consequences

1. **No nonzero slope-lattice shape is hard in itself.** Every row of the table in
   `ct-z-frozen-tails-anywhere-give-kourovka-20-44` contains groups with finitely many orbits:
   - trapped: `E_(3/5)`;
   - tube: `E_(3/5) ⊔ Z e_2`;
   - `G_T`'s own lattice `Z e_2 ⊕ Z e_3`: `T_(Z e_2 ⊕ Z e_3)`.
2. **Counterexamples travel upward.** A group violating 20.44, or TC with infinitely many orbits,
   with lattice `M` gives one with lattice `M + Λ` for every `Λ`. Equivalently, 20.44 (or the TC
   conjecture) for all groups with slope lattice `Λ` implies it for all groups with slope lattice
   any sublattice of `Λ`.
3. **Where Collatz forces the question open.**
   - By `ct-z-orbit-transversal-dichotomy-is-collatz-hard` and item 2, for every lattice
     `Λ ⊇ Z e_2 ⊕ Z e_3`, 20.44 for all groups with lattice `Λ` implies that the 3x+1 map has
     finitely many components on Z. The witness is `G_T ⊔ Λ`.
   - `Z e_2 ⊕ Z e_3 ⊆ Λ` forces `dim C_Λ ≥ 2`, where `C_Λ = span_R(Λ) ∩ R^k_(≥0)`. So G_T reaches
     no lattice with `dim C_Λ ≤ 1`.
   - No other lattice is known to be Collatz-hard. Kohl-type groups for other Collatz-type maps,
     such as `5x+1` on `Z e_2 ⊕ Z e_5`, would need their own orbit and density analysis, which is
     not done here.
4. **Dimension at most one (the class asked about).**
   - `dim C_Λ ≤ 1` splits into three shapes:
     - trapped (`C_Λ = 0`): open;
     - positive rays: the TC conjecture is known there (ray node);
     - tubes (`dim C_Λ = 1`, `rank Λ ≥ 2`): open.
   - **Every trapped lattice is a sublattice of a tube lattice.** Add `e_q` for a prime `q`
     outside its support. The positive part of `span(Λ) ⊕ R e_q` is then `R_(≥0) e_q`.
   - So the TC conjecture (or 20.44) for tube lattices implies it for trapped ones. The whole
     `dim ≤ 1` class is equivalent to the tube class.
   - This proves, in its stated direction, the "dimension one contains the trapped case"
     heuristic of `ct-z-totally-consumable-core-of-kourovka-20-44`. The referee's objection there
     (TC does not pass to subgroups) is avoided because joins are overgroups.
   - Whether TC implies finitely many orbits here stays open. It is not Collatz-hard through
     `G_T`, and the Mahler-3/2 link stays an analogy.
5. **The TC conjecture, orbit by orbit.** By Theorem A, a TC group has finitely many orbits iff it
   has finitely many orbits whose local slope group is not inside `γ^Z` for an integer `γ`. Any
   counterexample must be carried by infinitely many orbits whose local slope group is
   non-cyclic, or is cyclic with a non-integral generator.

## Lesson for general BH

**Hardness of arithmetic orbit problems is a property of single orbits, not of the ambient slope
lattice.**
- Kohl's restriction monomorphisms make disjoint joins inside CT(Z). A join realizes every slope
  lattice tamely and carries every counterexample upward.
- So a classification by the global slope lattice can only give necessary conditions for
  hardness. Positive theorems must be orbit-local, as the corner argument turns out to be.
- For hosts: a host assembled as a join can mix slopes freely without creating orbit hardness. To
  keep an embedded subgroup tame, control the local slope groups of its orbits, not the host's
  slope group.

## Referee (bh-ref-q12, 2026-09-19): PASS; one definitional repair

**Theorem A: correct.** I checked it line by line against the corner argument of the ray node.
- **`v ≠ 0`.** If `Γ_O = 1`, every cocycle along `O` vanishes, so a tail at `K ≥ D·1` stays there. Every piece has
  `d(λ) ≤ D·1 ≤ K`, so it is never read, and `K` is frozen at `x`, against TC.
- **The one orbit-local input.** The reading word's cocycle is `c(h′, x) = ν(q(h′, x))` with `q(h′, x) ∈ Γ_x = Γ_O`,
  so it lies in `Z v`. Nothing else uses the slopes.
- **The corner.**
  - `d(λ) ≰ K_(s+t)` forces `s + t < 0`, since `v ≥ 0`. Then `K′ ≤ D·1` and `m_(K′) ≤ Π^D`.
  - The unread tail is `0` for `x ≥ 0`, and `−1` for `x < 0` once `m_(K_s) ≥ |x|`.
  - So `w ∈ [0, Π^D)` or `[−Π^D, 0)`, respectively.
- **The bound `2Π^D`** is uniform in `v`, as claimed.
- **The Corollary** follows from the refereed frozen-tails node, together with the bound.
- **Inputs.** The tracking, uniform-shift and reversal facts come from the ray node, which is unreviewed. The
  frozen-tails referee (bh-ref-q11) confirmed that they hold without the ray hypothesis.

**Theorem B: correct, after one repair.**
- **`E_γ`: correct.**
  - `r ≢ s_r mod gcd(2a, 2b) = 2`, so each generator is a class transposition, and the slopes are `a/b`, `b/a` and
    `1`.
  - *Descent for `x ≥ 2ab`.* Here `z ≥ a`, so `y − x ≤ 2a − 1 − 2(b−a)z < 0` and `y ≥ 0`.
  - *Descent for `x ≤ −2b²`.* Here `z ≤ −b`, so `|y| ≤ 2a|z| < 2b|z| − 2b + 1 ≤ |x|` and `y < 0`.
  - `E_(3/5)` gives `[−50, 30)`.
- **Restriction: correct.** `τ_(r(m), s(m′))` is sent to `τ_((i+jr)(jm), (i+js)(jm′))`, and slopes are preserved.
- **Repair: the definition of `T_Λ`.** As written, "dropping `H`" from `H ⊔ Λ` leaves the class `0(t+1)` fixed
  pointwise, so that group has infinitely many (singleton) orbits.
  - `T_Λ` must be built on `t` classes: `E_(γ_i)^((i−1, t))`, for `1 ≤ i ≤ t`. The parenthetical "on `t` classes"
    means this; say it explicitly.
  - Then B.1 holds: `Λ(T_Λ) = Λ`, there are finitely many orbits, and TC follows by the frozen-tails theorem.
- **B.2, orbits and density: correct.** Each generator preserves every class mod `t+1` and acts on exactly one.
  `φ_(0,t+1)` preserves sign and scales both densities by `1/(t+1)`.
- **B.2, TC on the carrier classes: correct.**
  - Every piece modulus of `G` is divisible by `t+1`, so `D` bounds the exponents of `t+1` and `t+1 | Π^D`. Hence the
    classes mod `M_n` refine the classes mod `t+1`, and `Y_n` contains a class inside `i(t+1)`.
  - Lemma 2 of the frozen-tails node (at most `A_n` points of `Y_n` per orbit) then contradicts the finiteness of
    the orbits of `E_(γ_i)`.
- **B.2, TC on `0(t+1)`: correct.**
  - `σ^(n+ν_0)((t+1)y′) = σ^n(y′)`.
  - Restricted pieces have degrees `d + ν_0`, and identity pieces have degree `ν_0`, so they never read a degree
    `≥ ν_0`.
  - A degree `K ≱ ν_0` is read by the first move of any word. So the frozen degrees at `(t+1)y′` are exactly
    `E_H(y′) + ν_0`.
  - *Bookkeeping, not a gap.* `G` lives in `CT_(P_G)(Z)`, where `P_G` adds the primes of `t+1`. `H`'s TC property is
    the same whether it is read over `P_H` or over `P_G`: degrees in the new coordinates are read by any piece of
    `H` exactly when their `P_H`-part is.

**Consequences: correct.**
1. `E_(3/5)`, `E_(3/5) ⊔ Z e_2` and `T_(Z e_2 ⊕ Z e_3)` realize the three rows, the last with the repaired `T`.
2. *Monotonicity.* If `M ⊆ Λ` and `H` has lattice `M`, then `H ⊔ Λ` has lattice `M + Λ = Λ`, and B.2 transfers the
   failure of 20.44 (or of the TC conjecture).
3. *Collatz.*
   - `Λ(G_T) = Z e_2 ⊕ Z e_3`, since the slopes `2` and `3/2` give `e_2` and `e_3 − e_2`.
   - `G_T ⊔ Λ` has lattice `Λ` and the same 20.44 status as `G_T`, which is Collatz-equivalent by the cited
     (unreviewed here) node.
4. *Trapped inside tube.*
   - `(span Λ ⊕ R e_q) ∩ R^k_(≥0) = R_(≥0) e_q`. Indeed, `u + c e_q ≥ 0` with `u ∈ span Λ` forces `u ≥ 0`, hence
     `u ∈ C_Λ = 0`.
   - The rank is at least 2.
   - "The whole `dim ≤ 1` class is equivalent to the tube class" relies on the ray case, which comes from the
     unreviewed ray node.
5. Immediate from Theorem A.

## 1. The low-rank lift is unique

**Lemma 1.** Let `x in U(n)` with `rk(x - 1) <= r`, and let `z in S^1` with `z != 1`. Then `rk(zx - 1) >= n - r`.

*Proof.* On `ker(x - 1)`, which has dimension `>= n - r`, the map `zx - 1` acts as the scalar `z - 1 != 0`. []

So if `n > 2r`, an element of `PU(n)` has at most one lift `xt` with `rk(xt - 1) <= r`: two such lifts differ by a
scalar `z`, and `rk(z xt - 1) <= r < n - r` forces `z = 1`. Call it the *low lift*.

**Consequences in `G`.**
- `pr` is conjugation-invariant, and `pr(xy) <= pr(x) + pr(y)` (take the product of lifts). Hence `B` is a normal
  subgroup of `G`.
- For `x = [x_i] in B` with `pr(x_i) <= r` on a `u`-large set, the low lift `xt_i` is defined `u`-almost everywhere,
  since `n_i -> infinity`.
- If also `pr(x_i) <= r'`, the two low lifts agree for large `n_i`, by uniqueness at the larger bound.
- So `chi(x) = [det xt_i] in *S1` is well defined.

## 2. `chi` is a conjugation-invariant surjective homomorphism

Let `x, y in B` with bounds `r, r'`.
- **Multiplicative.** `xt_i yt_i` lifts `x_i y_i` and has `rk(xt_i yt_i - 1) <= r + r'`. So it is the low lift of
  `x_i y_i` once `n_i > 2(r + r')`, and `chi(xy) = chi(x) chi(y)`.
- **Invariant.** For `g = [g_i] in G`, choose lifts `gt_i in U(n_i)`. Then `gt_i xt_i gt_i^-1` lifts `g_i x_i g_i^-1` and
  has rank defect `<= r`, so it is the low lift. Its determinant is `det xt_i`.
- **Surjective.** For `c = [c_i] in *S1`, the element `e_c := [diag(c_i, 1, ..., 1)]` has low lift itself, so
  `chi(e_c) = c`.

## 3. The lattice embedding `A -> N_A`

For `A <= *S1` put `N_A = chi^-1(A)`, a subgroup of `B`.
- **Normal in `G`.** It is invariant under `G`-conjugation by step 2, and `B` is normal.
- **Injective.** `chi(N_A) = A`, by surjectivity.
- **Meets.** `N_A cap N_A' = N_(A cap A')` is immediate.
- **Joins.** `N_A N_A' = N_(A A')`. The inclusion `subset` is multiplicativity. For `supset`, take `x in N_(AA')` with
  `chi(x) = c c'`, `c in A`, `c' in A'`. Then `e_c in N_A` and `e_c^-1 x in N_A'`.

By the Stolz--Thom lattice operations quoted in step 0, meets and joins of normal subgroups are `cap` and products. So
`A -> N_A` is a lattice embedding of `Sub(*S1)` into the normal subgroup lattice of `G`.

## 4. Non-distributivity (part B)

**Independence.** Let `lambda = e^i` and `mu = e^(i sqrt 2)`. If `lambda^a mu^b = 1` for integers `a, b`, then
`a + b sqrt 2 = 2 pi c` for some integer `c`.
- `c != 0` would make `pi` algebraic, contradicting Lindemann.
- So `a + b sqrt 2 = 0`, hence `a = b = 0`.

The diagonal map `S^1 -> *S1` is injective, so `lambda` and `mu` generate a copy of `Z^2` in `*S1`.

**The failing law.** Let `A_1 = <lambda>`, `A_2 = <mu>` and `A_3 = <lambda mu>`.
- `A_2 A_3 = <lambda, mu>` contains `A_1`, so `A_1 cap A_2 A_3 = A_1`.
- `A_1 cap A_2 = 1`. `A_1 cap A_3 = 1`, since `lambda^a = (lambda mu)^b` gives `lambda^(a-b) mu^(-b) = 1`, so
  `b = 0 = a`.
- By step 3:

  ```text
  N_(A_1) cap (N_(A_2) N_(A_3)) = N_(A_1)   and   (N_(A_1) cap N_(A_2))(N_(A_1) cap N_(A_3)) = N_1,
  ```

- `N_(A_1) != N_1`, because `chi(e_lambda) = lambda`.

So distributivity fails. Every `PU(n_i)` is a compact connected simple Lie group, so this contradicts Stolz--Thom
Theorem 4.20 and the last sentence of Main Theorem 5.1(1). []

## 5. Equivalent profiles, distinct normal closures (part C)

Let `c_lambda = |1 - lambda|/2 > 0` and `c_mu = |1 - mu|/2 > 0`, and take `p = [diag(lambda-bar, 1, ..., 1)]` and
`q = [diag(mu-bar, 1, ..., 1)]`.

**The profiles.**
- A diagonal representative of `p` in any Weyl-group ordering and any central translate has consecutive eigenvalue
  ratios equal to `1`, apart from at most two ratios `lambda-bar` and `lambda`.
- So in the formula `F_g(i) = 1/2 |1 - β_σ(i)(g)|` quoted in step 0, `F_p(1) = c_lambda` and `F_p(i) = 0` for `i >= 3`.
  The same holds for `q` with `c_mu`.
- Hence `F_p(3i + 1) <= ceil(1/c_mu) F_q(i + 1)` for all `i >= 0`. At `i = 0` the left side is `<= 1`. For `i >= 1` it is `0`.
- So `F_p ≼ F_q`, and symmetrically `F_q ≼ F_p`, in the order quoted from Main Theorem 5.1.

**The normal closures.**
- `chi(q) = mu-bar`, so `q in N_(<mu>)`. Since `N_(<mu>)` is normal, `N(q) subset N_(<mu>)`.
- `chi(p) = lambda-bar`, which is not in `<mu>` by step 4. So `p` is not in `N(q)`, and symmetrically `q` is not in `N(p)`.

This contradicts the implication `g ≼ h => g ∈ N(h)` of Stolz--Thom Theorem 4.16. It is also the injectivity half of
"N0 [...] isomorphic to [...] M / ≡" in Main Theorem 5.1(1). []

Stated in finite terms: for `n > 2k + 2`, `p_n` is not a product of `k` conjugates of `q_n^(+-1)` in `PU(n)`.
- A product of `k` such conjugates has low lift of rank defect `<= k`, and determinant in `mu^([-k,k])`.
- `det` of the low lift of `p_n` is `lambda-bar`.

This is Dowerk--Thom Remark 5.3 in rank-one form.

## 6. Profile necessary condition for width (part D)

Suppose `a(U) = prod_(j=1..k) g_j r_j(U)^(eps_j) g_j^-1` in `U(d)`, with `k <= K`, `r_j in R` and `eps_j = +-1`.
- `ell_t(x^-1) = ell_t(x*) = ell_t(x)` for unitary `x`, by Proposition 4.8(i).
- `ell_t` is conjugation-invariant, by (iii).
- Iterating (v) as in Dowerk--Thom's proof of Proposition 4.9 gives

  ```text
  ell_(kt)(a(U)) <= sum_j ell_t(r_j(U)) <= k max_(r in R) ell_t(r(U)).
  ```

- By (vi), `ell_(Kt) <= ell_(kt)`, so `ell_(Kt)(a(U)) <= K max_r ell_t(r(U))`.
- For `Kt >= d` the left side is `0`, by (ii).

`M_d(C)` is a finite factor of type `I_d`, where Proposition 4.8 applies with the domain `{0, ..., d-1}` quoted in step 0.

So if for every `K` some `d`, `U in U(d)^S` and `t` violate this inequality, then `a(U)` is not in `Cons_K(R(U))` for
that `K`, and the width of `a` is unbounded. []

## 7. The charge is invisible to simple groups (part E)

Let `Gamma = <S | R>` be non-abelian simple, `1 != a in Gamma`, and `phi : F(S) -> G` a homomorphism with
`phi(R) subset B` and `phi(a) in B`.
- Put `A = <chi(phi(r)) : r in R>`. Then `N_A` is normal in `G` and contains `phi(R)`, so `phi` induces
  `psi : Gamma -> G/N_A`.
- `chi` induces an isomorphism `B/N_A -> *S1/A`, and `B/N_A` is abelian.
- `psi^-1(B/N_A)` is a normal subgroup of `Gamma` that contains `a != 1`, so it is all of `Gamma`. Hence
  `psi(Gamma) subset B/N_A`.
- `Gamma` is perfect, so `psi(Gamma) = 1`. Thus `phi(a) in N_A`, that is, `chi(phi(a)) in A`. []

**Scope of step 7.**
- For a simple group, the only way the charge could obstruct `a in N(phi(R))` is `chi(phi(a))` lying outside `A`. The
  necessary condition `N(phi(R)) subset B` forces `phi(R) subset B`.
- Step 7 shows that this never happens.
- It does **not** show that profile data decide membership for simple groups. That is the open corrected question recorded
  on `thompson-v-has-bounded-compact-unitary-relator-width`.

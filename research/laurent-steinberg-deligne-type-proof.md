Notation as in the target. `R = F_q[t,t^-1]`, `char = p`, `n >= 3`, `c = {t,a}_α`.

**Item 1.** By `laurent-unstable-k2-splits-by-tame-symbol` (items 1 and 4, `k = F_q`, `X = t`),
`u -> {t,u}_α` is an injective homomorphism `F_q^× -> K_2(n,R)`, with central image. So `c` is
central, lies in `K_2(n,R)`, and has order `|a| = q - 1 >= 2`.

**Item 3.** `R` is a finitely generated commutative ring (by `t` and `t^-1` over `F_p`, together
with a generator of `F_q`). So `St_n(R)` is finitely generated, and it has property (T) by
`ershov-jaikin-kassabov-steinberg-groups-have-property-t`.

**Item 2.** Let `M` be a normal subgroup of finite index in `St_n(R)`.

- *Step 1 (reduction to a finite ring).* By `steinberg-rf-forces-ring-rf`, the quotient
  `St_n(R) -> St_n(R)/M` factors through `St_n(R) -> St_n(Λ)` for a finite quotient ring
  `Λ = R/J`.
  - Directly: `J = {r : x_12(r) ∈ M}` has finite additive index. Conjugation by Weyl elements and
    `[x_ik(r), x_kj(s)] = x_ij(rs)` show that `J` is the level of every root subgroup and is an
    ideal.
  - The kernel of `St_n(R) -> St_n(R/J)` is the normal closure of the `x_ij(J)`, by comparing
    presentations.
- So it suffices to show that the image `c_Λ = {t̄, ā}_α` is trivial in `St_n(Λ)`. It is a
  symbol, so `c_Λ ∈ K_2(n,Λ)`, and `c_Λ^(q-1) = 1`.

- *Step 2 (products).* For `n >= 3`, `St_n(A × B) ≅ St_n(A) × St_n(B)`.
  - The maps `x_ij(a) -> x_ij((a,0))` and `x_ij(b) -> x_ij((0,b))` are homomorphisms.
  - Their images commute. For `(k,l) ≠ (j,i)`, this is the commutator relations, since
    `(a,0)(0,b) = 0`. For the opposite root, pick `m ∉ {i,j}` and write
    `x_ji((0,b)) = [x_jm((0,b)), x_mi((0,1))]`. Both factors commute with `x_ij((a,0))` by the
    first case.
  - The resulting map `St_n(A) × St_n(B) -> St_n(A × B)` is inverse to the projections on
    generators.
  - `SL_n` also splits over products, so `K_2(n, A × B) = K_2(n,A) × K_2(n,B)`.

- *Step 3 (`c_Λ` lies in the radical kernel).* `Λ` is finite and commutative, so
  `Λ/rad(Λ) = ∏ k_i` with the `k_i` finite fields.
  - By Step 2, `K_2(n, ∏ k_i) = ∏ K_2(n, k_i) = 0`. This is
    `laurent-unstable-k2-splits-by-tame-symbol` item 3 with `quillen-k-theory-of-finite-fields`.
  - The image of `c_Λ` in `St_n(Λ/rad)` is a symbol, so it lies in `K_2(n, Λ/rad) = 0`.
  - Hence `c_Λ ∈ N = ker(St_n(Λ) -> St_n(Λ/rad))`.

- *Step 4 (structure of `N`).* By the presentation comparison of Step 1, `N` is the normal closure
  of `{x_ij(m) : m ∈ rad(Λ)}`, so it is generated as a group by conjugates of such elements.
  - Each has order dividing `p`, since `x_ij(m)^p = x_ij(pm) = 1` and `pΛ = 0`.
  - So `N^ab` has exponent dividing `p`.
  - The image of `N` in `SL_n(Λ)` lies in `1 + M_n(rad)`. This is a finite `p`-group, since
    `(1+X)^(p^s) = 1 + X^(p^s)` in characteristic `p` and `X` is nilpotent.
  - Put `Z = N ∩ K_2(n,Λ)`. Then `[N : Z] = p^e` for some `e`, and `Z` is central, by
    `semilocal-steinberg-groups-have-central-k2` (`Λ` is finite).

- *Step 5 (transfer).* For a central subgroup `Z` of finite index `m` in `N`, the transfer
  `V : N -> Z` is a homomorphism with `V(z) = z^m` for `z ∈ Z` (Schur). `V` factors through
  `N^ab`, so `V(N)` has exponent dividing `p`.
  - `c_Λ ∈ Z`, so `c_Λ^(p^(e+1)) = V(c_Λ)^p = 1`.
  - Together with `c_Λ^(q-1) = 1` and `gcd(p, q-1) = 1`, this gives `c_Λ = 1`.

So `c ∈ M`. This holds for every finite-index normal `M`, so `c ∈ ker_RF` and `c ≠ 1`.

**Item 4.** For `q` odd, `J = c^((q-1)/2)` has order two. It is central and lies in `ker_RF` by
items 1 and 2. `St_n(R)` is finitely generated by item 3. This is the definition quoted in
`bdl-deligne-type-two-norm-inapproximability`.

**Item 5.** By `laurent-unstable-k2-splits-by-tame-symbol` item 1 with `k = F_q`,
`K_2(n,R) = K_2(n,F_q) × {t, F_q^×}_α`. The first factor is `0` by item 3 and
`quillen-k-theory-of-finite-fields`, so `K_2(n,R) = ⟨c⟩ ≅ Z/(q-1)`.
- `⟨c⟩ ⊆ ker_RF` by item 2.
- `St_n(R)/K_2(n,R) = E_n(R) ⊆ SL_n(R)` is a finitely generated linear group, hence residually
  finite (Mal'cev, `finitely-generated-linear-groups-are-residually-finite`). So `ker_RF ⊆ K_2(n,R)`. ∎

Step 5 is where finiteness of `Λ` and characteristic `p` are both used. Over `Z[t,t^-1]` the argument
does not apply as written, because `Λ` may have characteristic divisible by the order of the symbol.

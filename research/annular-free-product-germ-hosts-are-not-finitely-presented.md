**Setting.** Notation of `rf-groups-have-free-product-germs-over-v`. `G` is generated by
`g_1, ..., g_k`, and `S_V` is a finite generating set of `V`. *Annular data* is a
sequence `ρ_n` assigning to each `g_i` an element `ρ_n(g_i) ∈ V`. It defines `ĝ_i`
fixing `p` and acting on `A_n` by `α_n ρ_n(g_i) α_n^(-1)`, and the marked group
`Γ_ρ = <S_V, ĝ_1, ..., ĝ_k>`.

**Theorem.**
1. **Local rigidity of finitely presented hosts (general).** Let `x_1, ..., x_k` be
   homeomorphisms of `C`, each locally in `V` off a finite set `sing(x_i)`, and suppose
   `Γ = <S_V, x_1, ..., x_k>` is finitely presented, with defining relators of length at
   most `R_0`. If homeomorphisms `x'_1, ..., x'_k` satisfy every such relator in place of
   the `x_i`, then `x'_i = x_i` for all `i`. So a finitely presented group generated by
   `V` and finitely many elements that are `V`-local off finitely many points is pinned
   down by its short relations among all such markings. Consequently `Γ` is not
   finitely presented as soon as it admits **deep perturbations**: for every `R`, some
   `x' != x` satisfying all relations of `Γ` of length at most `R`. For annular data this says
   `ρ` is the only data satisfying the length-`R_0` relations.
2. **Ping-pong data is not rigid.** Let `ρ` be a realization from
   `rf-groups-have-free-product-germs-over-v` with `G != 1`. For every `R` there is
   `L(R)` such that for each `L >= L(R)`, some `ρ'` has the following properties:
   - it differs from `ρ` only on the annulus `A_L`, by conjugating `Q_L` inside `X_L`;
   - it is again such a realization;
   - a word of length at most `R` is trivial in `Γ_ρ` exactly when it is trivial in
     `Γ_ρ'`.
3. **So the hosts are not finitely presented.** For every nontrivial finitely generated
   residually finite `G` and every realization, `<V, Ĝ>` is not finitely presented. It
   equals the full closure `Γ` of the host node, by localization, so `Γ` is not
   finitely presented either. This covers the calibration cases `G = Z/2` and `G = Z`.

**What this says for Problem 5.3(12).** Item 1 is a necessary condition on every host
of this kind, whatever its germ groups. The actions at every depth must be pinned down
by finitely many relations, whose short words only see a bounded window of depths. In a self-similar host the relations
`g = (states)` carry depth `n` to depth `n + 1`. The finite quotients of a residually
finite group give independent depths, so short relations cannot see one deep annulus,
and that annulus can be changed. So annular hosts that use residual finiteness through
independent finite quotients are dead in both finiteness tests, the germ complex and the
host itself. A working annular host must relate depth `n + 1` to depth `n` by a finite
rule, which is the virtual endomorphism shape of
`fp-rf-boone-higman-via-fp-self-similar-overgroups`.

**Lesson for general BH.**
- *Principle.* Finite presentation of a Thompson-like host is a locality principle: short
  relations see only bounded depth near each singular point, so everything deeper must
  be forced by a finite rule. Item 1 turns this into a test that works for any finite
  germ extension of `V`: construct a deep perturbation that no short relation can see.
- *Where the test should bite.* Its natural targets are hosts whose deep structure is
  chosen independently at each depth: unrelated finite quotients, aperiodic sequences
  such as the Grigorchuk `ω`, or shells built stage by stage. It is carried out here only
  for the ping-pong annular hosts. For the others, deep perturbations have not been
  constructed.
- *The design rule.* A universal Boone--Higman host cannot store the input level by
  level. It must compile the input's algorithm into a finite rule that transports
  depth `n` to depth `n + 1`. Self-similarity, a virtual endomorphism, is the known form
  of such a rule. The open question is which other finite depth-transport rules exist
  and preserve finite presentation.

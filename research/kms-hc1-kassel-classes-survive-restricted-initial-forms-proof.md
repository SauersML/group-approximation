Notation of the target claim. Fix `p >= 5`, `m >= 1`, and set `n = 3mp`.
Everything is over `F_p`. For `X t^k` with `X` in `gl_3`, "height" means
`(j-i)+3k` on `E_ij t^k`. Height is additive under matrix products.

## 1. The two filtrations of `I_1` are the height filtration

Let `H_k` be the set of elements of `I_1` of the form `1+Y`, where every
monomial of `Y` has height `>= k`. By (D) of
`kms-hc1-a2-pro-p-completion-is-iwahori-criterion`, `P_k(I_1) = H_k`. The
Zassenhaus filtration always satisfies `P_k <= D_k`. Conversely, Lazard's
formula gives `D_k = prod_{i p^j >= k} gamma_i^{p^j}`, and `gamma_i <= P_i = H_i`.
If `x = 1+Y` lies in `H_h`, then `x^p = 1+Y^p` lies in `H_{ph}`, because `p`
divides the other binomial coefficients. Iterating, each generator of
`gamma_i^{p^j}` with `i p^j >= k` lies in the subgroup `H_k`. So
`D_k = H_k`.

On `gr_H`, the bracket induced by the group commutator is the matrix
commutator of initial forms. The map `x -> x^p` induces
`Y-bar -> (height-ph part of Y^p) = Y-bar^p`. This is `0` on a root vector
`E_ij t^k`, since `E_ij^2 = 0`. It is `h^p t^{pk} = h t^{pk}` on a diagonal
`h t^k` with `F_p` entries. So `gr_D(I_1)` is `L_p` with this p-map, and
`gr_P(I_1)` is `L_p` with `pi = 0`: `pi` maps degree `k` to degree `k+1`, but
`x^p` lies in `H_{pk}` and `pk >= k+2`. In both gradings the degree-`n` piece
has dimension `dim (L_p)_n`. Both are generated by degree 1, which is
`span(a,b,c)` with `a = E_12`, `b = E_23`, `c = t E_31`:
`gr_D` of a finitely generated pro-p group is generated by `gr_1` as a
restricted Lie algebra (Jennings–Quillen), and `gr_P` is generated by `gr_1`
as an `F_p[pi]`-Lie algebra (Lazard), because
`P_{k+1} = P_k^p [P_k, G]`. With `pi = 0` and the p-map above, this means
`L_p` is generated by `a, b, c` both as a restricted Lie algebra and as an
ordinary Lie algebra.

## 2. `N` is a Lie algebra

Let `L = L_p/(height > n)` and `N = L + F_p z`, with
`[x,y]_N = [x,y]_L + omega(x,y) z` and `z` central. Here
`omega(X t^a, Y t^b) = a tr(XY) [a+b = mp]`.

*Degree.* `omega(X t^a, Y t^b)` is nonzero only if `a+b = mp` and
`tr(XY) != 0`. Then `X` and `Y` have opposite root weights, or both are
diagonal, so the heights add to `3a+3b = n`. So `z` has degree `n`, and the
bracket is graded.

*Alternating.* `omega(Y t^b, X t^a) = b tr(XY) = (mp - a) tr(XY) = -omega(X t^a, Y t^b)`
mod `p`.

*Cocycle.* Take `x = X t^a`, `y = Y t^b`, `w = W t^c` with `a+b+c = mp`,
and put `T = tr([X,Y]W)`. `T` is invariant under cyclic permutation of
`(X,Y,W)`. The cyclic sum of `omega([x,y],w)` is

```text
(a+b) T + (b+c) T + (c+a) T = 2mp T = 0   (mod p).
```

For all other triples, each term `omega([x,y],w)` vanishes by degree. So
`omega` is a 2-cocycle. Jacobi in `N` follows: its `L`-component is Jacobi in
`L` (the truncation is by a graded ideal), and its `z`-component is the
cocycle identity, because `z` is central. `restricted_kassel.py` checks this
on every basis triple of total height `n`.

*Not a coboundary.* Consider `[E_12 t, E_21 t^{mp-1}]_L` and
`[E_12 t^2, E_21 t^{mp-2}]_L`. Both equal `(E_11 - E_22) t^{mp}`. The factor
`E_21 t^{mp-2}` has height `3mp - 7 >= 1`. But `omega` takes the values `1`
and `2` on these two pairs. So `omega != f o [ , ]_L` for every linear `f`,
since `1 != 2` in `F_p`.

## 3. The restricted structure (Jacobson's criterion)

**Jacobson's theorem** (Lie Algebras, Ch. V §7, Thm 11; Strade–Farnsteiner
Thm 2.2.3). Let `N` be a Lie algebra over a field of characteristic `p` with
basis `(e_i)`. Suppose that for each `i` some `y_i` in `N` has
`(ad e_i)^p = ad y_i`. Then `N` has a unique p-map with `e_i^[p] = y_i`.

Use the basis `{E_ij t^k}`, `{h_1 t^k, h_2 t^k}` and `z`, with
`h_1 = E_11 - E_22` and `h_2 = E_22 - E_33`. Take
`y = 0` for root vectors and for `z`, and `y = h t^{pk}` for `h t^k`
(read as `0` when `3pk > n`).

- `e = z`: `ad z = 0`.
- `e = E t^k` a root vector. Since `z` is central, induction on `j` gives
  `(ad_N e)^{j+1} x = (ad_L e)^{j+1} x + omega(e, (ad_L e)^j x) z`.
  On `gl_3`, `(ad E)^r X = sum_s binom(r,s) (-1)^s E^{r-s} X E^s`. Since
  `E^2 = 0`, every term vanishes for `r >= 3`, so `(ad_L e)^3 = 0`. For
  `p >= 5`, `p - 1 >= 3`, so `(ad_N e)^p = 0 = ad_N(0)`.
- `e = h t^k`. For a root vector `x = X t^l`,
  `[e,x]_N = alpha(h) X t^{k+l}`, because `tr(hX) = 0`. So
  `(ad_N e)^p x = alpha(h)^p X t^{pk+l} = alpha(h) X t^{pk+l}`. This equals
  `[h t^{pk}, x]_N`, whose `z`-part is `omega(h t^{pk}, X t^l) = 0`. For
  `x = h' t^l` diagonal, `[e,x]_N = k tr(hh') [k+l = mp] z`. This is central,
  so `(ad_N e)^p x = 0` for `p >= 2`. On the other side,
  `[h t^{pk}, h' t^l]_N = pk tr(hh') [...] z = 0`.
  Both sides kill `z`. Truncation at height `> n` is compatible with all of
  these identities, because `ad` is graded.

So `N` is a restricted Lie algebra. It is graded: `deg(e^[p]) = p deg e` on
the basis. The quotient map `N -> L` is a restricted map, where `L` carries
the p-map of §1. The script checks every instance with
`deg x + p deg e <= n`; all other instances are `0 = 0` by degree.

*Relator initial forms.* `a, b, c` are basis root vectors, so
`a^[p] = b^[p] = c^[p] = 0`. The six Serre words have degree `3 < n`. There
`omega` vanishes, so they equal their values in `L_p`, which are `0`
(`[[E_12,E_23],E_12] = [E_13,E_12] = 0`, and so on).

## 4. Generation, and the surjections `Lambda_p ->> N`, `Lambda^P_p ->> N`

Let `S` be the restricted subalgebra of `N` generated by `a, b, c`. Its image
in `L` is the restricted subalgebra generated by `a, b, c`, which is all of
`L` by §1. So `N = S + F_p z`.

Suppose `z` is not in `S`. Then `S` is a complement to `F_p z` and a Lie
subalgebra. Write the inverse of `S -> L` as `sigma(x) = x + f(x) z`. Then
`[sigma x, sigma y]_N = sigma([x,y]_L)` gives `omega(x,y) = f([x,y]_L)`, and
§2 rules this out. So `S = N`.

Therefore `a -> a`, `b -> b`, `c -> c` defines a restricted map
`FreeRes(a,b,c) -> N`. It is onto, and by §3 it kills `a^[p]`, `b^[p]`,
`c^[p]` and the six Serre words. So it factors through a graded surjection
`Lambda_p ->> N`.

The same argument with ordinary Lie subalgebras applies. `L` is generated by
`a, b, c` as a Lie algebra (§1), and `omega` is not a coboundary. With
`pi = 0`, `N` is a Lie algebra over `F_p[pi]` in which `pi a = pi b = pi c = 0`
and the Serre words hold. This gives `Lambda^P_p ->> N`. This half needs only
§2, and is the Kassel class of
`kms-hc1-iwahori-h2-serre-plus-kassel-all-degrees` read in the mixed model.
§3 is what is new: the restricted relations `a^[p] = 0`, of degree `p`, do not
kill the class.

Since `dim N_n = dim L_n + 1 = dim (L_p)_n + 1`, statement (M) follows.

## 5. Proof of (O)

Let `F^` be the free pro-p group on `a, b, c`, and let `R` be the closed normal
subgroup generated by the nine relators, so that `Gamma^ = F^/R`. For
`G = F^/R` we have `D_k(G) = D_k(F^) R / R`, and likewise for `P_k`. This is
because both series are verbal: they are generated by values of the words
defining `D_k` and `P_k`, which are images of such values in `F^`. Hence

```text
gr_D(Gamma^) = gr_D(F^) / J,   J_k = { initial forms of elements of R cap D_k(F^) in degree k },
```

and `J` is a graded restricted ideal. `gr_D(F^) = FreeRes(a,b,c)`
(Lazard / Jennings). The initial form of `a^p` is `a^[p]`, of degree `p`, and
the initial form of `[a,b,a]` is the Lie word `[[a,b],a]`, of degree 3. So `J`
contains the ideal `I` generated by the nine initial forms, and
`FreeRes/I = Lambda_p`.

Now assume `Gamma^ = I_1`. Then `gr_D(Gamma^) = gr_D(I_1)`, whose degree-`n`
piece has dimension `dim (L_p)_n` by §1. By (M) this is less than
`dim (Lambda_p)_n`. So `J_n` strictly contains `I_n`: some `r` in `R` has
initial form of degree `n` outside `I`.

For `P` the argument is the same. `gr_P(F^)` is the free Lie algebra over
`F_p[pi]` (Lazard, `p` odd), the initial form of `a^p` is `pi a` in degree 2,
and the resulting quotient is `Lambda^P_p`.

The methods listed in (O) all compute with, or bound, `FreeRes/I`,
`FreeLie_{F_p[pi]}/I^P`, or `u(Lambda_p) = gr F_p<<X>>/(initial forms)`, where
the last identification uses Quillen `gr F_p[G] = u(gr_D G)`. By (M), each of
them sees at least one extra dimension in degree `3mp`, so none of them can
prove `Gamma^ = I_1`. This is the exact failure step.

## 6. Proof of (S)

In `N`, take the restricted subalgebra generated by `a` and `b`. It is
`V_ab = span(E_12, E_23, E_13)`: `E_13^[p] = 0`, `ad E_13` kills `E_12` and
`E_23`, and `omega` vanishes on it because all heights are at most `2 < n`.
Similarly `V_bc = span(E_23, t E_31, t E_21)` and
`V_ca = span(t E_31, E_12, t E_32)`. Each `V_v` meets `F_p z` trivially and
maps isomorphically onto its image in `L`. So the inclusions `V_v -> N` are
restricted splittings over the three vertex subalgebras. On the pairwise
intersections, `F_p a`, `F_p b` and `F_p c`, they agree, since they are
literal inclusions. By §2 the extension `N -> L` is not split. So the graded
analogue of the central-extension statement in (S) is false in every Kassel
degree. Any proof of the group statement must use an input that does not
factor through `gr_D` or `gr_P`.

## 7. Machine check

`restricted_kassel.py p m` builds `N` explicitly and checks four things:

- Jacobi on all basis triples of total height `n`;
- Jacobson's identity `(ad e)^p x = [e^[p], x]` for all basis `e`, `x`;
- the relator initial forms in `N`;
- the non-coboundary witness of §2.

`restricted_kassel.out` records PASS for `(p,m) = (5,1), (7,1), (5,2), (11,1), (7,2)`,
and also `(3,1)`. Those runs cover degrees 15, 21, 30, 33 and 42. The proof
above holds for every `p >= 5` and `m >= 1`. The script is a check of the
hand computation, not a part of the proof.

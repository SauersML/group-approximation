**ESTABLISHED** through `affine-2v-hosts-reach-z-1-2n-by-doubling-but-not-q-proof`. Lane proof. Reviewed:
gq-referee-a PASS, proof-gap lens
(`research/artifacts/gq-referee-a-affine-2v-hosts-reach-z-1-2n-by-doubling-but-not-q.md`, 7dac5c057; nits N1–N3
applied). Its inputs are the same verbatim Li and Matui theorems as `odometer-2v-is-fp-simple-and-contains-bs12`.
No novelty is claimed for Boone–Higman of the groups reached: `Z[1/2N] ⋊ ⟨2⟩ ≤ Aff(Z[1/2N]) ≤ GL_2(Z[1/2N])` is a
subgroup of a finitely generated linear group. The content is the host and the limit.

**Setting.**
- `X = C × C` is read as `{0,1}^Z`: colour 1 holds the digits at positions `0, 1, 2, …` and colour 2 those at
  `-1, -2, …`. On `X`, `Q_2` acts by addition, with carries only upward. `u(x, y_0y) = (y_0x, y)` is the shift,
  i.e. multiplication by 2. This is a faithful action of `Q_2 ⋊ ⟨2⟩`, and hence of `Q ⋊ ⟨2⟩` (the **natural
  action**).
- For odd `N > 1`, `G_N = Z[1/N] ⋊ ⟨p : p | N prime⟩` acts on `Z_2` by `x ↦ ax + b`. It acts self-similarly on
  colour 1 of the product 2-graph `Λ = F_2^+ × F_2^+`. Each `g ∈ G_N` fixes every colour-2 edge, with restriction
  `g`, as `a` does in the odometer case. `2V_{G_N}` is the topological full group of
  `I_l(Λ ⋈ G_N) ⋉ X`. More generally, `2V_H` is defined in the same way for any self-similar `H ≤ Aff(Z_2)`.

**Statement.**
1. **Reach.** `Z[1/2N] ⋊ ⟨2⟩`, in its natural action, lies in `2V_{G_N}`. This copy is generated by `u ∈ 2V`,
   which gives the dilation `2`, and the elements `(+c) × id` with `c ∈ Z[1/N]`. The group `Z[1/2N] ⋊ ⟨2⟩` is not
   finitely generated. Whether `2V_{G_N}` itself is generated by `2V` and `{g × id : g ∈ G_N}` is not claimed: the
   odometer node's trick `q s = σ_{(1,∅)}` is specific to `+1`, and perfectness does not need it.
2. **Host.** `2V_{G_N}` is simple, contains `2V ⊇ (Q,+)`, and is of type `F_n` whenever `G_N` is (Li,
   Example ex:ZS (III)). For `N = 3`, `G_3 = Z[1/3] ⋊ ⟨3⟩ ≅ BS(1,3)` is of type `F_∞` (torsion-free one-relator,
   Lyndon). So `2V_{G_3}` is an `F_∞` simple group containing `Z[1/6] ⋊ ⟨2⟩`, `BS(1,2)`, `BS(1,3)` and `2V`.
3. **Limit.** Let `H ≤ Aff(Q)` be finitely generated, act on `Z_2` (multipliers are 2-adic units, translations
   2-adic integers), and act self-similarly and pseudo-freely on colour 1. Its elements are then `x ↦ ax + b` with
   `a, b ∈ Z[1/N']` for some odd `N'`. For every prime `q ∤ 2N'`, the translation `x ↦ x + 1/q` of the natural action
   is not in `2V_H`. Hence **the natural action of `Q ⋊ ⟨2⟩` lies in no `2V_H` with `H ≤ Aff(Q)` finitely
   generated.** Coefficient groups in `Aff(Z_2)` with irrational 2-adic coefficients are not covered.

**Against the prime-mixing obstructions** (`research/artifacts/gq-gq-obstructions-0918-writeup.md`, Part II).
- *Blocks it:* item 9, `finite-state-mobius-pieces-see-finitely-many-primes`. Item 3 above is that mechanism, run in
  the product host. The colour-1 pieces lie in `Aff(Z[1/N'])`, so the host sees only the primes of `N'`.
- *Escapes it:* item 20, `torus-amalgams-of-adelic-groups-are-not-finitely-presented`. `2V_{G_N}` is a groupoid full
  group, not an amalgam `Γ *_C B`. The same "one prime set at a time" behaviour appears instead as item 3: each
  finite truncation `Z[1/2N] ⋊ ⟨2⟩` has its own host, and the colimit over `N` has none among these.
- *Escapes it:* the restricted-product (adelic finite support) obstruction. That concerns coordinatewise hosts
  `∏′(G_i, K_i)` acting on buildings, and `2V_{G_N}` acts on one Cantor set, not coordinatewise.
- *Not triggered:* item 8, `p-adic-dilation-normalizers-act-by-power-maps`. `Q ⋊ ⟨2⟩` has one dilation, and no
  element conjugating one prime dilation to another is needed. That item constrains prime-shift designs for the
  full `Aff(Q)`, not this step.

**Not decided.** Whether some other ("wild") copy of `Q ⋊ ⟨2⟩` lies in `2V_{G_N}` or in `2V_τ`, for example one
built from the mixed-radix root tower `Q_τ` of `odometer-2v-is-fp-simple-and-contains-bs12`, item 5.
- Heuristic, not proved: there the odd roots are carried by a fractional counter, read most-significant-first in
  colour 2. A dilation acting as `×2` on it must double a mixed-radix fraction, which carries from the far end of
  the tape and is not a bounded prefix operation.
- Item 3 does not apply to non-affine finitely generated `H`: a finitely generated self-similar group containing
  all translations by `Z_(2)` is not excluded. Such an `H` would also need finite presentation for the host to be
  finitely presented.

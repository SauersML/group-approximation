Fix `t >= L/2 >= 1` and write `R = R_t(G,S)`, `d = d_S`.

**Connected.** `t >= 1`, so `R` contains the Cayley graph `Cay(G,S)`, which is
connected.

**Edges reduce to Cayley paths.** Let `{g,h}` be an edge of `R`, with
`k = d(g,h) <= t`, and choose a geodesic `g = p_0, p_1, …, p_k = h` in
`Cay(G,S)`. For `0 <= i < k` the set `{g, p_i, p_{i+1}}` has diameter
`<= max(d(g,p_i), d(g,p_{i+1}), 1) <= k <= t`, so it spans a simplex of `R`.
Gluing these triangles (a fan at `g`) gives a homotopy rel endpoints from the
edge path `p_0 p_1 … p_k` to the edge `g h`. So every edge loop of `R` is
homotopic to an edge loop in `Cay(G,S)`. Every loop in a simplicial complex is
homotopic to an edge loop, so `π_1(R, 1)` is generated by edge loops of
`Cay(G,S)` at `1`.

**Cayley loops are null-homotopic.** An edge loop at `1` in `Cay(G,S)` reads a
word `w` over `S` that is trivial in `G`. Then `w` is freely equal to a product
of conjugates `u_j r_j^{±1} u_j^{-1}` with `r_j ∈ R`. Free insertion or deletion
of `s s^{-1}` is a homotopy of edge paths in any graph, so the loop of `w` is
homotopic to the concatenation of the loops of the conjugates. Each such loop
runs along `u_j` to the vertex `g_j` (the value of `u_j`), around the relator
loop at `g_j`, and back along `u_j`. It is null-homotopic once the relator loop
is. The relator loop visits `g_j, g_j s_1, …, g_j s_1⋯s_ℓ = g_j` with
`ℓ <= L`. Any two of these vertices are joined by an arc of the loop of length
`<= ℓ/2`, so the vertex set has diameter `<= L/2 <= t` and spans a simplex of
`R`. A loop inside a simplex is null-homotopic. Hence `π_1(R) = 1`.

**Every finite generating set.** If `G` is finitely presented and `S'` is any
finite generating set, then `G` has a finite presentation over `S'`
(Neumann's theorem that finite presentability does not depend on the finite
generating set: rewrite a finite presentation over `S` via Tietze moves), so
the above applies to `S'`. ∎

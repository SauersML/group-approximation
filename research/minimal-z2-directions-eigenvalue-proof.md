## Why sufficient

**Lemma.**
- Suppose `θ(v) = 0`.  Then `f(v·y) = f(y)`, so `f` is constant along `v`-orbits.
- `f` is continuous and every `v`-orbit is dense, so `f` is a constant `c`.
- `c ≠ 0` because `f ≠ 0`.
- Then `c = e^(2πiθ(g)) c` for all `g`, so `θ = 0`.

**Corollary A.**
- Let `π : Y -> Z^2/Λ` be a factor map, and fix `y`.
- The closure of the `v`-orbit of `y` is `Y`, so its image is all of `Z^2/Λ`.
- That image is the orbit of `π(y)` under `⟨v⟩`, because the target is finite and discrete.
- So `v + Λ` generates `Z^2/Λ`, which is therefore cyclic.
- `Z^2/NZ^2 ≅ (Z/N)^2` is not cyclic for `N ≥ 2`.

(Alternatively, apply the Lemma to the character `θ(a,b) = (b_0 a - a_0 b)/N` with `v = (a_0,b_0)`.)

**Corollary B.**
- Let `π : Y -> R^2/Γ` be a factor map with `π(g·y) = π(y) + g`.
- Each `χ ∈ Γ* = {χ ∈ (R^2)* : χ(Γ) ⊆ Z}` gives the continuous eigenfunction `e^(2πiχ(π(y)))`, with eigenvalue
  `θ_χ(g) = χ(g) mod 1`.
- **Entries in F.**  A basis matrix of `Γ` has entries in `F`, and so does its inverse transpose.  So `Γ*` is a
  rank-2 lattice inside `F^2`, and `χ(v) ∈ F` for every `χ ∈ Γ*`.
- **A killed character.**  The homomorphism `Z × Γ* ≅ Z^3 -> F`, `(n, χ) ↦ n + χ(v)`, lands in a `Q`-vector
  space of dimension `2`.  So it has a nonzero kernel element `(n_0, χ_0)`.
  - `χ_0 ≠ 0`, since otherwise `n_0 = 0`.
  - So `χ_0(v) = -n_0 ∈ Z`, i.e. `θ_(χ_0)(v) = 0`.
- **The character is nontrivial.**  `θ_(χ_0)` is trivial exactly when `χ_0(Z^2) ⊆ Z`, i.e. when `χ_0 ∈ Z^2`.
  That is excluded by `Γ* ∩ Q^2 = 0`.
- So the Lemma forbids `v` from acting minimally.

**Jeandel–Rao computation.**
- `Γ_0 = ⟨(φ,0), (1,φ+3)⟩` has entries in `Q(√5)`.
- If `χ ∈ Γ_0* ∩ Q^2`, then `χ_1 φ ∈ Z` with `χ_1` rational, so `χ_1 = 0`.  Then `χ_2(φ+3) ∈ Z`, so `χ_2 = 0`.

**ESTABLISHED** by `higman-b-side-derived-closure-bottom-layer-proof` (obstruction).

**Statement.** Let `G_b = < a, b, c | b^a = b^2, c^b = c^2 >` and `F = <a, c> <= G_b` (free of rank 2).
Put `P = F ∩ ncl_(G_b)(c)`, the normal closure of `c` in `F`. For every `k >= 1`,

```text
ncl_(G_b)(F^(k)) ∩ F  <=  P^(k-1)  <=  F^(k-1).
```

More generally, `ncl_(G_b)(N) ∩ F <= P^(k-1)` for every normal subgroup `N` of `F` with `N <= P^(k-1)`.

**Corollary (free solvable top).** In the universal group `G_b / ncl(F^(k))`, which carries the
`b`-side relations and `A^(k) = 1` for `A = <a,c>`, the generators `a, b, c` have infinite order and
`A / A^(k-1)` is the free solvable group of rank 2 and derived length `k-1`. Every group generated by
`a, b, c` satisfying `b^a = b^2`, `c^b = c^2` and `A^(k) = 1` is a quotient of this one. By the
automorphism `theta^2 : a -> c, b -> d, c -> a, d -> b` of Higman's group, the same holds for the `d` side
`< c, d, a | d^c = d^2, a^d = a^2 >`, with `P_d = ncl_F(a)` in place of `P`.

**Calibration for `k = 3`.** `free_metabelian_top.py` shows that the explicit group of
`higman-one-sided-span-bound-fails-at-derived-length-three` already realizes a free metabelian top.
With the coset function `F(p, s0) = S^-p`, the commutator module `A_m'/A_m'' ⊗ Q` carries a functional
that intertwines `alpha` and `gamma` with independent scalars `S^m, t^m` and is nonzero on `z`. So the
module is free of rank 1 over `Q[X^±, Y^±]`, which is exactly what the corollary predicts.

**What this kills.** Take any collapse argument for an opposite pair of derived length `k`
(`A^(k) = 1`) that derives consequences from one Baumslag--Solitar side before using the other. The
consequences it can extract inside `A` all lie in the bottom layer `A^(k-1)`. So:
- no one-sided bound on `A'/A''`, or on any `A^(i)/A^(i+1)` with `i < k-1`, exists for any `k >= 3`.
  The landed collapse proofs escape this for a reason. For `A'' = 1` the layer they bound, `A'/A''`,
  is the bottom layer. The hypothesis `h(A'') < ∞` is a finiteness assumption on the layers below,
  and it is not implied by any derived length.
- The induction "collapse derived length 3, then induct" cannot be run layer by layer from the top.
  Each inductive step must either work in the bottom layer `A^(k-1)/A^(k)` or couple both sides.

**What it does not kill.** A one-sided bound on the bottom layer `A^(k-1)/A^(k) ⊗ Q` is not excluded.
Nor is a two-sided argument. The two-sided question is whether alternately closing under the `b` side
and the `d` side keeps `F^(k)` inside `P^(k-1) ∩ P_d^(k-1)`. This theorem controls each single step,
but not the alternation, because `ncl_b` can leave `P_d^(k-1)`.

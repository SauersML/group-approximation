**ESTABLISHED.** Let `Gamma` be a countable group and `H <= Gamma` an infinite
subgroup. Use the intermediate-subgroup definition: `H` is wq-normal in a
subgroup `L >= H` when every proper subgroup `K` of `L` containing `H` admits
some `g in L \ K` with `g K g^(-1) ∩ K` infinite. Call `M <= Gamma` almost
malnormal when `g M g^(-1) ∩ M` is finite for every `g notin M`.

Build a chain of subgroups by transfinite recursion:
* `W_0 = H`;
* `W_(beta+1)` is generated by `W_beta` together with every `g in Gamma` for
  which `g W_beta g^(-1) ∩ W_beta` is infinite;
* `W_lambda` is the union of the `W_beta` with `beta < lambda`, for limit
  ordinals `lambda`.

The chain stabilizes at a countable ordinal. Call the final subgroup the
**wq-normal hull** `W(H)`. Then:

1. `H` is wq-normal in `W(H)`.
2. `W(H)` is almost malnormal in `Gamma`.
3. `W(H)` is contained in every almost malnormal subgroup of `Gamma` that
   contains `H`, so it is the smallest one. It also contains every subgroup
   `L >= H` in which `H` is wq-normal. So it is the only subgroup with
   properties 1 and 2.
4. `H` is wq-normal in `Gamma` if and only if `W(H) = Gamma`.
5. If `W(H) != Gamma`, then `W(H)` has infinite index in `Gamma`.
6. `W(H)` contains every `g` with `g H g^(-1) ∩ H` infinite. In particular it
   contains the commensurator and the normalizer of `H`, and the centralizer of
   every infinite subgroup of `H`.

**Consequence for the class without amenable wq-normal subgroups.** Let `Gamma`
be a countable group none of whose infinite amenable subgroups is wq-normal, as
in `fpbs-no-amenable-wq-normal-class-nonuniqueness`. Then exactly one of the
following holds.

* **(R0)** `Gamma` has no infinite amenable subgroup. It is then a torsion
  group, since an element of infinite order generates a copy of `Z`.
* **(R1)** `Gamma` has an infinite amenable subgroup. For each such `H`, the
  hull `W(H)` is a proper almost malnormal subgroup of infinite index. It
  contains the commensurator of `H`, and `H` is wq-normal in it.

This sharpens the "Structure of the class" paragraph of
`fpbs-residual-price-one-non-ah-class-nonuniqueness`. There the witness of
non-wq-normality is some intermediate subgroup. Here it can be taken to be the
canonical smallest witness `W(H)`.

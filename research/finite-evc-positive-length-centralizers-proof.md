Full proof: Theorem 4 and Corollaries 5 and 6 of
`research/artifacts/finite-evc-commensurator-restriction-2026-09-16.md`.

1. **Unimodularity.** `g` has infinite order, because `ℓ(1) = 0`. Let `y` be in `N_G[<g>]`.
   The infinite cyclic group `E = y<g>y^{-1} ∩ <g>` is generated by `yg^ay^{-1}` and also by
   `g^b`, so `yg^ay^{-1} = g^{±b}`. Invariance and homogeneity give `|a|ℓ(g) = |b|ℓ(g)`, so
   `|a| = |b|`. Hence `Δ_{<g>}(y) = [y<g>y^{-1} : E]/[<g> : E] = 1`, and `y` is in
   `N_G(<g^{|a|}>)`.
2. **Stabilization.** `N_G[<g>]` is therefore the directed union of the `N_G(<g^a>)`, `a >= 1`.
   It is finitely generated by `finite-evc-model-restricts-to-commensurators`, so it equals
   `N_G(<g^M>)` for some `M`.
3. **Centralizers.** `ℓ(g^k) = kℓ(g) > 0`, so step 1 applies to `<g^k>`, and
   `finite-evc-unimodular-weyl-groups-have-finite-efin` gives (ii).
4. **Products with `Z`.** Take `g = (q,1)` and `φ` the projection. Then
   `Z_G(g) = Z_Q(q) × Z`, and `(x,m) ↦ xq^{-m}` induces `Z_G(g)/<g> ≅ Z_Q(q)`.
5. **Ascending HNN extensions.** Let `φ(t) = 1` and `φ(H) = 0`, with kernel
   `K = ∪_i t^{-i}Ht^i`.
   - For `g = ht`, conjugation by `g` is `ψ = ι_h∘ι_t` on `K`, and
     `ψ(t^{-i}Ht^i) <= t^{-(i-1)}Ht^{i-1}`. So a `ψ`-fixed `k` in `t^{-i}Ht^i` equals
     `ψ^i(k)`, which lies in `H`.
   - Since `G = K ⋊ <g>`, we get `Z_G(g)/<g> ≅ Fix(ι_h∘θ)`. Apply (ii) with `ℓ = |φ|`.
   - `φ` forces `N_G[<t>] = ∪_a Z_G(t^a)`, and `Z_G(t^a) = Fix(θ^a) ⋊ <t>` by the same
     containment. So `N_G[<t>] = Per(θ) ⋊ <t>`.
   - Step 2 gives `N_G[<t>] = Z_G(t^M)`, so `Per(θ) = Fix(θ^M)`. This group has index `M` in
     `Z_G(t^M)/<t^M>`, which has type `F_infinity` by (ii).

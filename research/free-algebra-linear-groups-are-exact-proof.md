Fix a finite field `k`, a finite set `X`, `n ≥ 1` and a finitely generated
`Γ ≤ GL_n(k<X>)`. If `n = 1` then `Γ ≤ k<X>^* = k^*` is finite, so assume
`n ≥ 2`. Write `deg` for total degree on `k<X>`, with `deg 0 = −∞`.

## 1. A skew field with a degree valuation

Let `F_X` be the free group on `X` with a bi-invariant total order `<_F`
(Clay–Rolfsen Theorem 3.4). Put `Λ = F_X × Z` and order it
lexicographically with the `Z`-coordinate first: `(a, m) < (b, p)` iff `m < p`,
or `m = p` and `a <_F b`. Multiplication is componentwise, so this order is
left and right invariant. By the Malcev–Neumann import,
`D = k((Λ; <))` is a division ring containing `k[Λ]`. The field `k` is
central in `D`, and so is any central element of `Λ`.

**The valuation.** For `0 ≠ f ∈ D` let `ω(f)` be the `Z`-coordinate of the
least element of `supp(f)`. That element exists because the support is
well-ordered. Since the order compares `Z`-coordinates first, `ω(f)` is the
minimum of the `Z`-coordinates occurring in `supp(f)`. Put `ω(0) = ∞`.

For `m ∈ Z`, write `f = f_m + f_{>m}`, where `f_m` is the part of `f`
supported on `F_X × {m}`. Then:

- `ω(f + g) ≥ min(ω(f), ω(g))`, because supports only merge.
- `ω(fg) = ω(f) + ω(g)`. Let `m = ω(f)` and `p = ω(g)`. Every product of a
  support element of `f` with one of `g` has `Z`-coordinate at least `m + p`,
  with equality exactly for `supp(f_m) · supp(g_p)`. So the `(m+p)`-level part
  of `fg` is `f_m g_p`. That part is nonzero, because `f_m, g_p ≠ 0` and `D` is
  a domain.

So `ω : D^* → Z` is a surjective discrete valuation of the skew field `D`,
and it is non-trivial.

**The ring `D0[s]`.** Let `D0` be the set of series supported on
`F_X × {0}`. It is the subring `k((F_X; <_F))`, which is a division ring by the
same import. In fact `D0 = {f : f = f_0}`, and it is closed under inverses:
if `f = f_0` then `ω(f^{-1}) = −ω(f) = 0`, and the level-`p` part of `f^{-1}`
vanishes for `p > 0` because `f · f^{-1} = 1`.

Let `s = (1, −1) ∈ Λ`, which is central. Distinct powers `s^i` shift the
`Z`-level by `−i`. So `Σ d_i s^i` with `d_i ∈ D0` vanishes only if every `d_i`
vanishes, and the subring `D0[s] ⊂ D` is a polynomial ring in the central
indeterminate `s`. On `D0[s]` we have `ω(Σ d_i s^i) = −max{i : d_i ≠ 0}`,
that is `ω = −deg_s`. Since `D0` is a domain, `deg_s` is additive.

**The embedding.** Define `ι : k<X> → D` by `x ↦ (x, −1) = x̄ · s`, where
`x̄ = (x, 0)`. A word `w = x_1 ⋯ x_d` goes to `(w, −d)`. Distinct positive
words are distinct elements of `F_X`, so distinct monomials go to distinct
group elements, and `ι` is injective. It lands in `D0[s]`, and a polynomial of
degree `d` goes to a polynomial in `s` of `s`-degree `d`, because its top
homogeneous part is the level-`(−d)` part. Hence
`ω(ι(p)) = −deg(p)`. We identify `k<X>` with its image.

The composite `ε ∘ ι` is the augmentation `k<X> → k`, `x ↦ 0`, where
`ε : D0[s] → D0` is `s ↦ 0`. The map `ε` takes the constant term, so it is a
ring homomorphism: the constant term of a product is the product of the
constant terms.

## 2. A finite-index subgroup inside `SL_n(D)`

Let `R = D0[s]`. Every nonzero coefficient lies in the division ring `D0`, and
`s` is central. So for `a, b ∈ R` with `b ≠ 0` there are `q, q' ∈ R` with
`deg_s(a − q b) < deg_s b` and `deg_s(a − b q') < deg_s b`: repeatedly cancel
the leading term by `c s^j` on the left, or on the right. Write `E_n(R)` for
the group generated by elementary matrices `1 + r e_ij` (`i ≠ j`).

**Lemma.** Every `A ∈ GL_n(R)` factors as `A = E · diag(g_1, …, g_n) · E'`
with `E, E' ∈ E_n(R)` and `g_i ∈ D0^*`.

*Proof.* Induct on `n`; the case `n = 1` is the claim that `R^* = D0^*`,
which is the case `n = 1` of the argument below.

- **Column.** Left multiplication by an elementary matrix adds a left multiple
  of one row to another. Run the Euclidean algorithm on two nonzero entries of
  the first column: always reduce the entry of larger (or equal) `s`-degree by
  a left multiple of the other. It stops when one of them is zero. Repeat until
  the first column has exactly one nonzero entry `g`, in some row `i`. If
  `i ≠ 1`, add row `i` to row `1`, then subtract row `1` from row `i`. Now the
  first column is `g e_1`. No row swaps are used.
- **Unit pivot.** The new matrix `A'` is still invertible. Comparing the
  `(1,1)` entries of `A'^{-1} A' = 1` gives `(A'^{-1})_{11} g = 1`. Since
  `deg_s` is additive, `deg_s g = 0`, so `g ∈ D0^*`.
- **Row.** Right multiplication by an elementary matrix adds a right multiple
  of one column to another. Subtract column `1` times `g^{-1} a'_{1j}` from
  column `j`, for each `j ≥ 2`. This clears the first row and leaves the first
  column alone, giving `diag(g, A_2)`. Here `A_2 ∈ GL_{n−1}(R)`, because a
  block-diagonal matrix is invertible exactly when its blocks are.
- Apply induction to `A_2` and embed its factors block-diagonally. ∎

**Determinant.** Let `det : GL_n(D) → D^*/[D^*, D^*]` be the Dieudonné
determinant. It kills elementary matrices and sends `diag(g_1, …, g_n)` to the
class of `g_1 ⋯ g_n`. These are its defining properties: it is a homomorphism
to an abelian group, trivial on elementary matrices, with
`diag(1, …, 1, a) ↦ [a]`. The matrix `diag(1, …, g_i, …, 1)` is conjugate to
`diag(1, …, 1, g_i)` by a signed permutation matrix, and signed permutation
matrices lie in `E_n`. Apply `ε` entrywise; it is a ring homomorphism, so it
takes the factorization of the lemma to
`ε(A) = ε(E) · diag(g_1, …, g_n) · ε(E')`, with `ε(E), ε(E') ∈ E_n(D0)` and
`ε(g_i) = g_i`. Therefore

    det(A) = [g_1 ⋯ g_n] = det(ε(A))   for every A ∈ GL_n(R).

**The subgroup `Γ_1`.** Entries of matrices in `Γ` and of their inverses lie
in `k<X> ⊂ R`, so `Γ ≤ GL_n(R)`. On `Γ` the map `ε` is `A ↦ A(0)`, the
augmentation, which is a homomorphism `Γ → GL_n(k)`. Its kernel `Γ_1` is
normal and has index at most `|GL_n(k)| < ∞`. So `Γ_1` is finitely generated.
For `A ∈ Γ_1` we get `det(A) = det(1) = 1`. By (10.2.2) of the Bruhat–Tits
import, `SL_n(D)` is the kernel of the Dieudonné determinant. Hence
`Γ_1 ≤ SL_n(D)`.

## 3. The Bruhat–Tits building of `SL_n(D)`

Apply the Bruhat–Tits import to the skew field `K = D`, the right vector
space `D^n` (dimension `n ≥ 2`), the group `G = SL_n(D)` and the discrete,
non-improper valuation `ω` of §1. This gives a Tits system `(G, B, N, S)`
whose Weyl group `W` is the affine Weyl group of type `Ã_{n−1}`. That is a
Coxeter group, and `S` is finite with `n` elements.

**Chambers.** Let `C = G/B` and define `δ_C(gB, hB) = w` iff
`g^{-1} h ∈ BwB`. By (1.2.7) the double cosets `BwB` partition `G` and
`w ↦ BwB` is injective, so `δ_C` is a well-defined map `C × C → W`. It does
not depend on representatives, because `(gb)^{-1}(hb') = b^{-1}(g^{-1}h)b'`.
Since `(BwB)^{-1} = Bw^{-1}B`, we have `δ_C(hB, gB) = δ_C(gB, hB)^{-1}`.

**W-distance axioms** (the W-metric definition of a building of type `(W, S)`
used by Dymara–Schick):

- **WD1.** `δ_C(gB, hB) = 1` iff `g^{-1}h ∈ B` iff `gB = hB`.
- **WD2.** Let `δ_C(gB, hB) = w` and `δ_C(g'B, gB) = s ∈ S`. Then
  `g'^{-1}h = (g'^{-1}g)(g^{-1}h) ∈ BsB · BwB`. By (T3),
  `BsB · BwB = B(sBw)B ⊂ BwB ∪ BswB`, so `δ_C(g'B, hB) ∈ {w, sw}`. If
  `ℓ(sw) = ℓ(w) + 1`, then (1.2.8) gives `BsB · BwB = BswB`, so
  `δ_C(g'B, hB) = sw`.
- **WD3.** Let `δ_C(gB, hB) = w` and `s ∈ S`. Choose `n_s, n_w ∈ N` over `s`
  and `w`, and write `g^{-1}h = b n_w b'` with `b, b' ∈ B`. Put
  `g' = g b n_s^{-1}`. Then `g'^{-1} g = n_s b^{-1} ∈ BsB`, so
  `δ_C(g'B, gB) = s`. And `g'^{-1} h = n_s b^{-1} b n_w b' = n_s n_w b'`, which
  lies in `BswB` because `n_s n_w` lies over `sw`. So `δ_C(g'B, hB) = sw`.

So `(C, δ_C)` is a building of type `(W, S)`. By the Dymara–Schick import,
`(C, d)` with `d = ℓ ∘ δ_C` has finite asymptotic dimension. Left
multiplication by `G` preserves `δ_C`, since `(xg)^{-1}(xh) = g^{-1}h`. So
`Γ_1 ≤ G` acts on `(C, d)` by isometries.

## 4. Coarse stabilizers are finite

Take the base chamber `x0 = B ∈ C`, and let the Bruhat–Tits data be built on
the standard basis `e_1, …, e_n` of `D^n`, so that the `g_ij` of (10.2.7) are
ordinary matrix entries. For `R ≥ 0`,

    W_R(x0) = {γ ∈ Γ_1 : ℓ(δ_C(B, γB)) ≤ R} = Γ_1 ∩ M_R,
    M_R = ⋃_{w ∈ W, ℓ(w) ≤ R} BwB.

The set of `w` with `ℓ(w) ≤ R` is finite, because `S` is finite. So the image
of `M_R` in `B\G/B` is finite, and `M_R` lies in the Tits-system bornology
`ℬ` of (3.1.3)–(3.1.4). Since `φ^ω` is discrete, (8.1.7) says `ℬ` is the
bornology defined by `φ^ω`. Since `G = SL_n(D)` lies in `Ker δ`, (10.2.7) says
that bornology is `𝒮`. So there is `c = c(R)` with `ω(g_ij) ≥ −c` for all
`g ∈ M_R` and all `i, j`.

For `γ ∈ W_R(x0)` the entries `γ_ij` lie in `k<X>`, and §1 gives
`−deg(γ_ij) = ω(γ_ij) ≥ −c`, that is `deg(γ_ij) ≤ c`. There are only finitely
many elements of `k<X>` of degree at most `c`, because `k` and `X` are finite.
So `W_R(x0)` is finite, and `asdim W_R(x0) = 0` in the word metric of `Γ_1`.

## 5. Conclusion

- `Γ_1` is finitely generated (§2) and acts isometrically on `(C, d)` (§3),
  and `asdim (C, d) = m < ∞` (Dymara–Schick). Every `W_R(x0)` has
  `asdim 0` (§4). So Bell–Dranishnikov Theorem 2 gives `asdim Γ_1 ≤ m`.
- By Willett Corollary 2.2.11, `Γ_1` with a word metric has property A. For a
  finitely generated group, property A is equivalent to exactness (the
  Kirchberg–Wassermann node), so `Γ_1` is exact.
- `Γ/Γ_1` is finite, hence amenable, hence exact. `Γ` is an extension of
  `Γ/Γ_1` by `Γ_1`, so `Γ` is exact by the Kirchberg–Wassermann node. Since
  `Γ` is finitely generated, it also has property A.

This proves the target for every finitely generated `Γ ≤ GL_n(k<X>)`. The
subgroup `EL_3(F_2<x,y>)` is generated by the finitely many elementary
matrices `1 + x e_ij`, `1 + y e_ij`, `1 + e_ij`, so it is covered. ∎

**Remark.** `Γ_1` itself has finite asymptotic dimension. Finite asymptotic
dimension passes to finite-index overgroups, which are quasi-isometric, so
`Γ` does too. The route above only needs exactness.

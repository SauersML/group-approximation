**OPEN.**

**Statement (Local Boone--Higman).** Let `E = {u_1, ..., u_d}` and
`N = {v_1, ..., v_k}` be words in the free group on `y_1, ..., y_n`. If the
system `u_i(y) = 1, v_j(y) ≠ 1` has a solution in some finitely generated group
with solvable word problem, it has a solution in some finitely presented simple
group.

**Equivalent forms.** Write `fps` for the class of finitely presented simple
groups.
1. Every finitely generated group `G` with solvable word problem satisfies every
   universal sentence without constants that holds in all members of `fps`.
   - Proof of equivalence: a quantifier-free formula is, in disjunctive normal
     form, a disjunction of systems as above.
   - A solution in any group generates a finitely generated subgroup, and
     finitely generated subgroups of groups with solvable word problem have
     solvable word problem.
2. Every marked finitely generated group with solvable word problem is a limit,
   in the space of marked groups, of marked finitely generated subgroups of
   members of `fps`. Basic clopen sets there are exactly the solution sets of
   such systems (CGP arXiv:math/0511714, proof of Proposition
   `prop skeleton dense`, TeX lines 794–797).

**Why it matters.** By `boone-higman-iff-isolated-hosts-and-local-boone-higman`,
`boone-higman-conjecture` holds iff both this claim and
`every-decidable-group-embeds-in-an-isolated-group` hold. The two halves can fail
separately as far as is known:
- this one is about the universal theory `Th_∀(fps)` and allows a different host
  for every finite piece;
- the other is about overgroups and does not mention simple groups.

So if Boone--Higman fails, either some decidable group has no isolated overgroup,
or some universal sentence `¬Σ` holds in every finitely presented simple group and
fails in some isolated group with solvable word problem. This names the invariant
that the counterexample direction must find on this branch: a single universal
first-order sentence, given by a finite presentation and a finite discriminating
set (`isolated-embedding-is-one-existential-sentence`).

**Known cases.** Every group locally embeddable into groups known to embed in
finitely presented simple groups satisfies the statement. This includes the
following.
- Groups that are limits of subgroups of hyperbolic groups, by
  `hyperbolic-groups-satisfy-boone-higman`.
- Groups that are locally embeddable into finite groups. Every finite group embeds
  in Thompson's `V`: the symmetric group `Sym(m)` permutes the `m` cones of a
  partition of the Cantor set. This is a hand remark.
- In particular every residually finite group. For a finite set of nontrivial
  elements, a finite quotient in which they survive is a finite solution of the
  corresponding system.

## Attempts

1. **Where a separating sentence must live (2026-09-17, lane
   swarm-0917-w4-bh-heretic).** *Constraints, no candidate.* Let `Σ = (E, N)` be
   satisfiable in a decidable group and in no member of `fps`.
   - **No finite solution, and so no residually finite witness.** `V` contains
     every finite group (hand remark above).
   - **No solution in a hyperbolic group**, by
     `hyperbolic-groups-satisfy-boone-higman`.
   - **Tame quotients.** Let `P = ⟨y | E⟩`. Some quotient of `P` has solvable word
     problem and keeps every `v_j` nontrivial: the subgroup generated by a
     solution. No quotient of `P` that embeds in a member of `fps` keeps every
     `v_j` nontrivial.
   - **The universal-sentence class is not degenerate.** CGP, TeX lines 732–736,
     quoting Miller: "there exists a non-trivial finitely presented group $G$ such
     that the only quotient of $G$ having solvable word problem is $\{1\}$". Write
     `G = ⟨y | E⟩` with the generators numbered so that `y_1 ≠ 1` in `G`. Then `∀y (E(y) = 1 → y_1 = 1)`
     holds in every finitely generated group with solvable word problem, and so
     in every member of `fps`, but fails in `G`. So universal sentences do detect
     word-problem obstructions on quotients. This lemma asks whether they detect
     anything beyond solvable word problem.
2. **Other invariant classes named in the counterexample brief.** *Each dies at a
   named step, as a separating invariant for the whole conjecture.*
   - **Undecidability of the order/torsion problem.** Dies because it is not
     forced: the finitely presented simple group `2V` has undecidable torsion
     problem (Belk--Bleak arXiv:1405.0982, recorded in
     `research/artifacts/ideas-2026-09-13/bh/bh-cellular-automata.md`,
     constraint C4). A contracting-host second witness also exists. Bartholdi--Mitrofanov
     arXiv:1710.10109, Theorem B2 with Theorem C, give a contracting automaton
     group with undecidable order problem. Belk--Matucci arXiv:2405.10234,
     Theorem 1, embed it in a finitely presented simple group. This is read from
     the PDFs, not re-verified here.
   - **Dehn function relative to the word problem.** Killed on main:
     `a-recursive-function-is-no-fp-simple-dehn-lower-bound`,
     `fp-simple-dehn-functions-realize-every-recursive-lower-bound`.
   - **Cohomological finiteness of the input.** Dies at "forced". Any forced
     property must hold for every finitely generated subgroup of a member of
     `fps`.
     - Finite groups lie there, so no bound `cd ≤ m` is forced.
     - `Z ≀ Z` embeds in Thompson's `F ≤ V` and is not finitely presented, so
       type `FP_2` is not forced. This is a standard fact, not re-cited here.
   - **Uniform complexity bounds.** Survive only as the negation of
     `fp-simple-groups-with-arbitrarily-complex-word-problem`, which is a
     statement about hosts, not a hereditary property of one input.

   What is left for a single input is the universal theory. By
   `isolated-embedding-is-one-existential-sentence`, that theory is complete for
   isolated inputs.
3. **Does this claim imply `every-decidable-group-embeds-in-an-isolated-group`?**
   *Open.* Local embeddability of `G` gives a host for each finite piece but no
   single finitely discriminable finitely presented overgroup. No argument in
   either direction was found.

**ESTABLISHED** (lane proof below; elementary; not independently reviewed; no novelty claimed).

1. **Ray lemma.** Let `Gamma <= NearSym(N)` be generated by a finite set `S` with `s Gamma s^-1 <= Gamma`.
   Choose genuine lifts of `S` and let `Sigma` be their Schreier graph on `N`. Then either `Gamma = 1`, or all
   but finitely many points of `N` lie in finitely many infinite components of `Sigma`.
2. **Baumslag–Solitar exclusion.** Let `a ∈ NearSym_0(N)`, `|m| >= 2`, and suppose that
   `s a s^-1 = a^m` or `s^-1 a s = a^m`. Then `a = 1`. So no near-faithful near action of `BS(1,m)`, and no
   group containing it, sends the stable letter to `s^(±1)`.

**Proof of 1.** Words `w_g` represent `s g s^-1` (`g ∈ S`), and the relation `s(gx) = w_g(s x)` holds
off a finite set `F`. Delete the edges at `F`; the components of what is left are the *pieces*. Only
finitely many components (the touched set `T`) are cut, each into finitely many pieces. `s` maps each
piece into one component `f(piece)`. Write `x_n = n`, so `x_(n+1) = s(x_n)`, and take `n0 > max F`.
- If the ray meets `T` infinitely often, then between visits it follows `f` from one of finitely many
  successors of pieces of `T`. A path that never returns to `T` can be taken only once. So after `n0` it
  visits finitely many components.
- If it meets `T` finitely often, it eventually follows `f` deterministically. Either the component
  sequence is eventually periodic (finitely many components again), or all later components are
  distinct. In that case each has one point visited after some time, so all but finitely many points
  lie in singleton components and `Gamma` is near trivial.

In the first two cases, finitely many components cover `N` cofinitely, and the finite ones among them
contain finitely many points.

**Proof of 2.** Let `E(b)` be the number of ends of the Schreier graph of one near permutation `b`. It is
a near invariant, and conjugation by `s^(±1)` preserves it. An infinite `a`-orbit is a line, and it splits
into `|m|` lines of `a^m`, so `E(a^m) = |m| E(a)`. Hence `E(a) ∈ {0, ∞}`.
- *Case `s a s^-1 = a^m`.* `Gamma = <a>` satisfies `s Gamma s^-1 <= Gamma`. If `a != 1`, item 1 gives finitely
  many lines covering `N` cofinitely, so `0 < E(a) < ∞`, a contradiction.
- *Case `s^-1 a s = a^m`.* `s` maps each `a^m`-orbit onto an `a`-orbit (off finitely many points). This
  defines a parent map `p` on `a`-orbits, and the ray passes from `p(C)` to `C`. The argument of item 1
  with `p` in place of `f` gives the same dichotomy. Revisiting a component forces a `p`-cycle, and a ray
  that leaves a `p`-cycle never returns to it. Returns through the finitely many touched orbits come
  from finitely many predecessors. So `a = 1` or finitely many lines cover `N` cofinitely, and the latter
  contradicts `E(a) ∈ {0, ∞}`.

**Scope.** Only cyclic bases are excluded. Item 1 is the general constraint for proper-endomorphism
twists. The infinite-order twist in `thompson-v-binary-shell-action-passes-both-germ-gates` is an
automorphism of `ker chi` and is not affected.

**Implementing the shift.**
- For `m >= 1` let `c_m` be the permutation of `[-m-1, m+1]` with `c_m(k) = k+1` for `-m-1 <= k <= m` and
  `c_m(m+1) = -m-1`.
- Let `w_m ∈ ⊗_{k=-m-1}^{m+1} M_2 ⊆ R` be the unitary that permutes tensor factors by `c_m`, so
  `Ad w_m (⊗_k x_k) = ⊗_k x_{c_m^-1(k)}`.
- Let `x` be an elementary tensor supported in `[-m, m]`, so `x_{-m-1} = x_{m+1} = 1`. Then `Ad w_m(x)` has
  coordinate `x_{k-1}` at each `k` in `[-m, m+1]`, and `x_{m+1} = 1` at `-m-1`. That is `s(x)`. By linearity,
  `Ad w_m = s` on the subalgebra supported in `[-m, m]`.
- Put `v = (w_m)_ω`, a unitary in `R^ω`.
  - For finitely supported `y`, `Ad w_m(y) = s(y)` once `m` is large, so `Ad v(y) = s(y)`.
  - For `x ∈ R` and finitely supported `y`: `Ad w_m` and `s` are `‖·‖_2`-isometric, so
    `‖Ad w_m(x) - s(x)‖_2 <= 2‖x - y‖_2` for large `m`.
  - Density of finitely supported tensors then gives `Ad v(x) = s(x)` for every `x ∈ R`.

**The enlargement.**
- Let `A` be the von Neumann algebra generated by coordinates `k >= 0` inside `R`.
- Then `v* A v = s^-1(A)` is the von Neumann algebra of coordinates `k >= -1`, i.e. `M_2 ⊗ A` with the new `M_2`
  at coordinate `-1`.
- It contains `A` properly, and `A ⊆ M_2 ⊗ A` has Jones index `2² = 4`.

**Group form.**
- Let `P_-` be the group generated by `σ_x` and `σ_z` at every coordinate `k < 0`, and let `z = σ_x` at
  coordinate `0`. Put `u = v*`.
- `Ad u = s^-1` on `R`, so `u P_- u^-1 = s^-1(P_-) ⊆ P_-` (coordinates `k < -1`).
- `z` commutes with `P_-`. But `uzu^-1 = σ_x` at coordinate `-1` does not commute with `γ = σ_z` at `-1`, which
  lies in `P_-`. So `[uzu^-1, γ] ≠ 1`.
- The countable group `<P_-, u, z> <= U(R^ω)` is hyperlinear, and `P_-` is locally finite. ∎

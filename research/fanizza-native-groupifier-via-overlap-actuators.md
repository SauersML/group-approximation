For fixed machine index `m`, attach the effective overlap actuator to every
predicate context of the finite BCS `B_m`, amalgamating only the original
shared BCS involutions.  Exact allowed assignments have zero forbidden mass
in every context, so actuator clause 3 supplies the HALT-side exact extension
after countable amplification.

For a finite matrix tuple of relator-error scale `eta`, exactify each fixed
finite packet.  Equations `(ORA2)` give

```text
q_c<=C_c sqrt(eta)
```

for every context.  There are only finitely many contexts at fixed `m`, so
their total forbidden probability, all packet-rounding losses, and all
shared-variable consistency losses are bounded by one computable modulus
`omega_m(eta)->0`.  Exactify the context containing the native signal and
compare its signal involution to the original shared word to obtain another
computable modulus `nu_m(eta)->0`.

These are precisely the two computable vanishing moduli requested in
`(NSG1)--(NSG2)`.  Fanizza NONHALT soundness then collapses the native word,
and the existing route
`nonhyperlinear-from-fanizza-native-signal` reaches the root goal.

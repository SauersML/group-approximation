Full derivation in the artifact, §§2–4.

- **Relations.** Evaluating on `g b_i` gives `ts = 1`, `st = 1 - e` with `e` the projection on `b_0`, `es = te = 0`,
  `e M_f = M_f e`, `s M_f = M_{alpha(f)} s` and `t^m M_f s^m = M_{alpha^{-m}(f)}`.
- **Normal form.** `R = span{ s^i M_a t^j : a in A_+ }`, and this span is closed under products.
- **Defect ideal.** `J = span{ s^i M_a e t^j }` is isomorphic to `M_inf(A_+)` through the matrix units `s^i e t^j`.
- **Quotient.** For `m >= max j`, `x(g b_m) = sum_d F_d alpha^d(g) b_{m+d}`, which defines `pi(x) = sum_d F_d u^d`.
  This is a surjective ring map onto `LC(Y,F_2) x| Z`. Its kernel is `J`, via the telescoping
  `s^i M_a t^j - s^{i+1} M_{alpha^{-1}(a)} t^{j+1} = s^i M_a e t^j`.
- **Radical in one step.** `J <= d(R) <= hh(R)`. The quotient is LEF, since minimal subshifts satisfy the cycle
  condition, hence directly finite, so `hh(R) <= J`.
- **Groups.**
  - (T) from EJZ, since `R` is finitely generated.
  - `EL_n(R,J) <= Rad_MF` from the torsion-defect proposition at the genuine pair `(s,t)`, with `2e = 0` and `n >= 4`.
  - Congruence kernel: `g == I` modulo `J` gives `g = (I - pI) + h` with `h in GL_n(B)`, where
    `B ~= prod M_N(F_2)` is finite and `p` is a local unit. `GL_n(B) = prod SL_{nN}(F_2)` is generated by
    transvections, so `g in EL_n(R,J)`.
  - Upper bound: `EL_n(R/J)` is LEF, hence MF.
- **Quotient group.** `R/J` is the Steinberg algebra of a free minimal transformation groupoid, so
  `EL_n(R/J)/Z` is simple. The centre lies in `F_2^x = 1`, and the quotient ring is finitely generated.

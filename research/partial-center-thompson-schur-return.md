Construct one finite repeating cell coupling the fixed Fanizza BCS context,
the translation-symmetrized full Schur reset, and the Thompson--Clifford tape
so that at every derived level `n`:

1. the current context selectors control the Schur predicate packet, but no
   relation makes them commute with future Fanizza contexts;
2. the corrected `Q`-child branch types are paired by the established branch
   flip and become the newly addressed Thompson Pauli coordinate;
3. the old selector character is consumed by the translation reset, and an
   HNN selector chart transports the reset endpoint to the next Fanizza
   context;
4. the complete returned type vector differs from the next input vector by

   ```text
   C(n+1)^k sqrt(E),                                           (PCT1)
   ```

   using `thompson-pauli-prefix-rounding-has-polynomial-cost`; and
5. the infinite amplified marked BCS representation extends across the
   repeating cell with its marked word nonidentity.

Only the noncentral branch coordinate is added to the nested Clifford factor.
The old selector center is not included in the factor to whose commutant the
next packet is assigned.  This is the mandatory partial-center condition
identified by `schur-violation-density-is-in-the-spin-commutant` and
`nested-schur-multiplicity-wire-globalizes-selectors`.

Together with the exact Schur child identity and the balanced selector vector
of the full reset, `(PCT1)` gives the violation-oriented recurrence
`(SVG1)--(SVG3)` with polynomial error.  This claim is now the precise
algebraic renewal gate for the Thompson route; spin-factor independence is no
longer incorrectly asked to reset selector density.

## Attempts

- **Endpoint subgroup calculation.**  Inside the finite full reset, take the
  group generated by the corrected `Q` child and its branch flip.  On every
  active sector the flip pairs the two genuine child simples, so their
  two-dimensional type coordinate is the candidate new Thompson Pauli cell.
  The next exact calculation is the intersection of this endpoint group with
  the old selector center.  The construction is accepted only if that
  intersection is `<J>`; retaining any `z_i` would reproduce `(NSG1)`.
- **Endpoint result: negative.**  The whole `Q` child contains every `z_i` and
  fails the intersection test.  The smaller group `<J,q_*,eta>` passes it and
  is a Pauli `D_8`, but
  `branch-flip-pauli-extraction-cancels-schur-surplus` proves that its `M_2`
  action recombines the two child branches and destroys the factor-two
  current.  Hence the stated Thompson return cannot satisfy clauses 2 and 4
  simultaneously.
- **Finite covariance syntax.**  Once the endpoint passes the intersection
  test, identify its Pauli pair with the base Thompson lamp and centralize the
  pointwise stabilizer of the addressed site.  Thompson high transitivity
  reduces all site, pair, and incidence relations to finitely many orbit
  representatives.  Diagonal covariance with the BCS shift then propagates
  the single base cell with polynomial area.
- **Completeness test.**  Use the established HNN selector chart only after
  the endpoint reset.  Britton normal form preserves the marked BCS subgroup
  if both endpoint maps are injective.  If the branch-flip endpoint is not
  isomorphic to a fresh baseline chart, this attack dies; no equality of raw
  nonisomorphic Schur tables will be imposed.

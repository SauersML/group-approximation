Notation is that of the claim. `deg : G -> Z` is the quotient map, and `deg s = 1`.

## Step 0: conjugation bookkeeping

- For every `X <= G` and `g in G`: `g C_G(X) g^-1 = C_G(g X g^-1)`, and likewise with `K`
  in place of `G`, since `K` is normal.
- `N` is normal in `K`, and `s` normalizes `K`, so every `A_j` is normal in `K`.
- For `u = k s^m` with `k in K`: `u A_j u^-1 = k A_(j+m) k^-1 = A_(j+m)`.
- Hence `g C_K(A_j) g^-1 = C_K(A_(j + deg g))`. Each `C_K(A_j)` is normal in `K`, because
  `A_j` is normal in `K`.

## Step 1: (IS0)

Let `M <= G` be Kazhdan with `L` infranormal in `M`. Apply
`sofic-groups-kill-rigid-compression-defects` with `H = G`, `Gamma = L` and the Kazhdan group
`M`:

```text
[g z g^-1, gamma] = 1     for all g in M, z in C_G(L), gamma in L.
```

Conjugating by `g^-1` gives `[z, g^-1 gamma g] = 1`. So `z` commutes with every `M`-conjugate of
every element of `L`, and therefore with `<<L>>^M`.

With `M = K`, this gives `C_G(L) <= C_G(N)`. Conversely `L <= N` gives `C_G(N) <= C_G(L)`.
So `C_G(L) = C_G(N)`.

## Step 2: (IS1)

Let `u in Comp_G(L)`, `c in C_G(L)`, `l in L`.
- Since `u L u^-1 <= L` and `u K u^-1 = K`, we get
  `u N u^-1 = <<u L u^-1>>^K <= <<L>>^K = N`.
- By Step 1, `c in C_G(N)`. So `u c u^-1 in C_G(u N u^-1)`.
- If `u` is not strict, then `u N u^-1 = N`, so `u c u^-1 in C_G(N) <= C_G(L)` and
  `[u c u^-1, l] = 1`.
- If `deg u = 0`, then `u in K` normalizes `N`, so `u` is not strict.
- A strict `u` of degree `m` satisfies `A_m = u N u^-1 < N`, strictly, by Step 0.

## Step 3: (IS2)

Suppose `D_G(L) != 1`. By Step 2 some generator is nontrivial, so a strict `u` exists, of degree
`m != 0`, with `A_m < N`.

- *Non-Hopfian quotient.* Conjugation by `u` is an automorphism of `K` carrying `N` onto `A_m`.
  It induces `K/N = K/A_m`. The natural map `K/A_m -> K/N` is onto with kernel `N/A_m != 1`.
  Composing gives a non-injective surjection `K/N -> K/N`.
- *Consequences.* Finite groups are Hopfian, so `K/N` is infinite. It is Kazhdan as a quotient
  of `K`. So `N != K`, `L` does not normally generate `K`, and `K` is not simple.
- *One sign.* Iterating `A_(j+m) = s^j A_m s^-j <= A_j` gives `A_(j+p) <= A_j` for every `p` in
  the additive semigroup generated by the degrees of compressors fixing or shrinking `N`. The
  inclusion is strict when a strict degree is used, since conjugation by `s^j` preserves strict
  inclusion.
  - Suppose a strict degree `m > 0` and some compressor degree `m' < 0` both exist.
  - Then `A_(m|m'|) < A_0`, using the strict degree `|m'|` times.
  - And `A_(-m|m'|) <= A_0`, using `m'` `m` times. Conjugating by `s^(m|m'|)` gives
    `A_0 <= A_(m|m'|)`.
  - These contradict each other.
  - So all strict degrees, indeed all nonzero compressor degrees, share one sign.

Replacing `s` by `s^-1` if necessary (this changes nothing in the claim), assume every strict
degree is positive. Let `P` be the semigroup they generate and `g` its gcd. Then

```text
A_(j+p) <= A_j     for all j in Z, p in P.                                   (P)
```

(`N` is nontrivial here, because `D_G(L) != 1` forces `L != 1`. So `1 < N < K` and `K` is not
simple.)

## Step 4: defects live in kernel centralizers of translates

Let `u = k s^m` be strict, with `c in C_G(L)` and `l in L`. Put `x = u c u^-1`.
- By Step 2, `x in C_G(A_m)`.
- `l in K` normalizes `A_m`. For `a in A_m`, put `a' = l^-1 a l in A_m`. Then
  `[x,l] a [x,l]^-1 = x l x^-1 a' x l^-1 x^-1 = x l a' l^-1 x^-1 = x a x^-1 = a`.
- So `[x,l] in C_G(A_m)`. Also `[x,l] in K`, since `K` is normal and `l in K`.
- Therefore every nontrivial generator of `D_G(L)` lies in `C_K(A_m)` with `m in P`.

By Step 0, the `G`-conjugates of `C_K(A_m)` are the normal subgroups `C_K(A_j)` of `K`. Hence

```text
D_G(L) <= < C_K(A_j) : j in Z >.                                             (C)
```

## Step 5: (IS3)

Suppose `g = 1` and `D_G(L) = K`.
- *Finite product.* `K` is Kazhdan, hence finitely generated. A product of normal subgroups is
  a subgroup, so the right side of (C) is the increasing union of finite products. Each of the
  finitely many generators of `K` lies in one of them, so
  `K = C_K(A_(j_1)) C_K(A_(j_2)) ... C_K(A_(j_r))`.
- *Central intersection.* Put `B = A_(j_1) ∩ ... ∩ A_(j_r)`. Each factor `C_K(A_(j_i))`
  centralizes `B`, so `K` centralizes `B`, and `B <= Z(K)`.
- *Frobenius bound.* Since `gcd P = 1`, every integer `>= F` lies in `P`, for some `F`. Take
  `J = max_i j_i + F`. By (P), `A_J <= A_(j_i)` for all `i`, so `A_J <= B <= Z(K)`.
- *Central source.* `Z(K)` is characteristic in `K`, and `s` normalizes `K`. So
  `N = s^-J A_J s^J <= Z(K)`. Then `L` is central, so `N = <<L>>^K = L`.
- *Finite source.* `L` is abelian and Kazhdan, hence finite. So `N` is finite.
- *Contradiction.* A conjugate of a finite group has the same order, so `A_m < N` is impossible.
  No strict compressor exists, and by Step 2, `D_G(L) = 1 != K`.

## Step 6: (IS4)

Assume a strict compressor exists; otherwise `D_G(L) = 1` by Step 2 and there is nothing to
prove. Let `t = s^g` and `G_g = deg^-1(gZ) = K <t>`.

- *Strict compressors live in `G_g`.* Every strict degree lies in `P`, which is contained in
  `gZ`.
- *The G_g-part of the defect.* Let `X` be the set of nontrivial generators of `D_G(L)`. By
  Steps 2 and 4, `X` is contained in `G_g`, and each element of `X` lies in some `C_K(A_m)` with
  `m in P`. Let `D'` be the normal closure of `X` in `G_g`.
- *Bound on `D'`.* The `G_g`-conjugates of `C_K(A_m)` are the groups `C_K(A_(m+Jg))`, by
  Step 0. So `D' <= U = < C_K(A_(Jg)) : J in Z >`.
- *Properties of `U`.* `U` is normal in `K`, and `t U t^-1 = U`.
- *`U` is proper.* Suppose `U = K`. Repeat Step 5 verbatim, with the translates `A_(Jg)` and the
  semigroup `P/g` in place of `P` (its gcd is 1), and with `t` in place of `s`. It gives a
  translate `A_(Jg) <= Z(K)`, so `N` is finite. That contradicts the existence of a strict
  compressor.
- *Reassembling `D_G(L)`.* `G` is the disjoint union of the cosets `s^rho G_g`, for
  `0 <= rho < g`. For `x in X` and `h in G_g`,
  `(s^rho h) x (s^rho h)^-1 = s^rho (h x h^-1) s^-rho`. So

  ```text
  D_G(L) = < s^rho D' s^-rho : 0 <= rho < g > <= U_0 U_1 ... U_(g-1),   U_rho = s^rho U s^-rho.
  ```

  The last product is a subgroup, since each `U_rho` is normal in `K`. Conjugation by `s`
  permutes the `U_rho` cyclically, because `s^g U s^-g = U`.

If `D_G(L) = K`, then `K = U_0 ... U_(g-1)`, where each `U_rho` is proper and normal in `K`. When
`g = 1` this says `U = K`, which is impossible. So `g >= 2`.

## Step 7: the corollary

Let `K` be finitely generated.
- *Two maximal normal subgroups multiply to `K`.* If `M_1 != M_2` are maximal normal subgroups,
  then `M_1 M_2` is normal and strictly contains `M_1`, so `M_1 M_2 = K`.
- *A unique maximal normal subgroup contains everything proper.* Suppose `M` is the unique
  maximal normal subgroup. Every proper normal subgroup lies in a maximal one: an increasing
  union of proper normal subgroups is proper, because a finite generating set cannot lie in it.
  So every proper normal subgroup lies in `M`, and every finite product of proper normal
  subgroups lies in `M`, hence is not `K`.

So "`K` is not a finite product of proper normal subgroups" is equivalent to "`K` has a unique
maximal normal subgroup". Under it, Step 6 gives `D_G(L) != K`. A simple `K` has the unique
maximal normal subgroup `1`.

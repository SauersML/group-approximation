Complete derivation in the artifact, §2 (Lemma 1 and Theorem A). Summary:

**Setup.**
- `σ_k : Δ → Sym(V_k)` is a sofic approximation. `v` is `K`-good if `σ_k` is multiplicative and free on the finite set
  `K` at `v`. Write `v·h = σ_k(h^(-1))v`.
- `E_k = 2^(V_k) × V_k`, and for `p = (c,v)` the partial configuration is `x_p(h) = c(v·h)`.
- `π_k(s)(c,v) = (c, v·s^(-1))` for `s ∈ S`, and `π_k(a)(c,v) = (c + 1_v, v)`. `π_k(ℓ)` is the product along a fixed
  word for `ℓ`, and `U_ℓ` its permutation matrix.
- `D_k(f)e_p = f(x_p)e_p`, read on a window of `f`. Then `Φ_k(Σ f_ℓ u_ℓ) = Σ D_k(f_ℓ)U_ℓ`.

**Proof.**
1. **Lemma 1.** `L ↷ 2^Δ` is minimal: finite modifications are dense. It is topologically free: for `ℓ = λδ` with
   `δ ≠ e`, a coordinate outside a given window and outside `supp λ` can be chosen to break `ℓx = x`, using that `Δ` is
   infinite. `R` is finitely generated by the `u_s`, `u_a` and `1_{x(e)=1}`.
2. **Localization.** If `v` is `K`-good and `K` contains all partial products, then:
   - `x_(π(ℓ)p) = ℓ·x_p` on the windows;
   - `π(ℓ)π(ℓ′)p = π(ℓℓ′)p`;
   - `ℓ ↦ π(ℓ)p` is injective on the finite support.
3. **Multiplicativity.** `U_ℓ D(g) U_ℓ^(-1) = D(g∘ℓ^(-1))` and `U_ℓU_(ℓ′) = U_(ℓℓ′)` on columns with good base points.
   So the defect `Φ_k(rs) − Φ_k(r)Φ_k(s)` is supported on `2^(|V_k|)·#{bad v} = o(N_k)` columns.
4. **Faithfulness.**
   - For `r = Σ_(ℓ∈F) f_ℓ u_ℓ ≠ 0`, choose `ℓ_0` and a nonempty clopen `U` with `f_(ℓ_0)∘ℓ_0` constant and nonzero on
     `U`, and `U ∩ ℓU = ∅` for `ℓ ∈ F^(-1)F∖{e}` (Lemma 1).
   - Over good `v` the colouring `c` is uniform, so exactly `ν(U)2^(|V_k|)` colourings put `x_(c,v)` in `U`.
   - Rows `π(ℓ_0)p`, for these columns `p`, meet no other selected column: a coincidence `π(ℓ)p′ = π(ℓ_0)p` forces
     `U ∩ ℓ_0^(-1)ℓU ≠ ∅`, hence `ℓ = ℓ_0`.
   - So `Φ_k(r)` contains a scalar identity block of size `ν(U)N_k − o(N_k)`.

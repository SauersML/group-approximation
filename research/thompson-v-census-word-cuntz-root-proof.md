## Step 0: the leaf homomorphism

The leaves `l = (00, 01, 1)` form a complete prefix code. So the isometries `s_00, s_01, s_1` have orthogonal ranges with
`s_00 s_00^* + s_01 s_01^* + s_1 s_1^* = 1`. It follows that

```text
Phi(M) = sum_(i,j) M_ij s_(l_i) s_(l_j)^*
```

is a unital `*`-homomorphism `M_3(C) -> O_2`, since `s_(l_i)^* s_(l_j) = delta_ij`. Let `a` and `c` permute leaves as the
permutations `alpha = (0 1)` and `gamma = (0 2)` of indices. Then

```text
U_a = sum_i s_(l_alpha(i)) s_(l_i)^* = Phi(P_a),     U_c = Phi(P_c),
```

with `(P_g)_(g(i), i) = 1`. It follows that

```text
U_c Phi(X) U_a Phi(X) U_a Phi(X)^(-1) = Phi(P_c X P_a X P_a X^(-1))     for X in U(3).
```

So item 1 reduces to a `3 x 3` equation.

## Step 1: the 3 x 3 root

Split `R^3 = R 1 ⊕ W`, with `W = 1^perp`. The permutation matrices fix `1`. On `W` they act as the dihedral group `D_3`, and
each transposition is the reflection `r_phi` across a line at angle `phi`. The axes of `a` and `c`, at angles `alpha_0`
and `gamma_0`, differ by `+-pi/3` mod `pi`.

Look for `X = 1 ⊕ r_xi`. Then `X^(-1) = X`. Because `r_phi r_psi` is the rotation `R(2(phi - psi))`,

```text
r_gamma0 r_xi r_alpha0 r_xi r_alpha0 r_xi = R(2(gamma0 - xi)) R(2(alpha0 - xi)) R(2(alpha0 - xi)) = R(2 gamma0 + 4 alpha0 - 6 xi).
```

This is the identity iff `xi = (gamma0 + 2 alpha0)/3 mod pi/3`. That forces `xi - alpha0 = +-pi/9 mod pi/3`, so solutions
exist. On `R 1` all factors are `1`, so `X = 1 ⊕ r_xi` solves `P_c X P_a X P_a X^(-1) = I`.

Such an `r_xi` is not in `D_3`, because transposition axes sit at `alpha0 + k pi/3`. So `X` is not a permutation matrix,
consistent with `cantor-homeomorphisms-miss-a-unimodular-root`.

The closed form in the claim is one of these solutions. `exact_root_check.py` verifies exactly, in `Q(zeta_9)` through
minimal polynomials, that:
- `X^T X = I`;
- `X = X^T`;
- `P_c X P_a X P_a X^T = I`;
- no permutation matrix is a root.

Its output is `out_exact_root_check.txt`: `PASS`, with `trace X = 1` and `det X = -1`, as `1 ⊕ r_xi` requires. The entries
lie in `Q(cos 2 pi/9)`, since `cos(2 pi/9 + 2 pi m/3)` are the Galois conjugates of `cos(2 pi/9)`.

## Step 2: T and the Leavitt algebra

`T = Phi(X)` is unitary, and self-adjoint because `X` is real symmetric. By Step 0 it is a root in `O_2`.

The `K`-algebra generated by `s_i` and `s_i^*` is a quotient of `L_K(1,2)`. That algebra is simple, so the quotient is
`L_K(1,2)` itself. `Phi` restricted to `M_3(K)` lands in it, so `T` is a unit of `L_K(1,2)`. The canonical `U_g` have
`0/1` coefficients and lie in the same unit group.

Transposing the equation gives `X^(-1) P_a X P_a X P_c = I`, the reversed word. So the convention for composing in `V` is
irrelevant.

## Step 3: item 2 (any unital C\*-ambient)

Let `F' <= V` be finite and `rho : V -> U(B)` a homomorphism. The group algebra `C[F']` is a finite-dimensional
C\*-algebra `⊕_pi M_(d_pi)`, and `g ↦ (pi(g))_pi` for a complete list of irreducible unitary representations.

The `*`-homomorphism `C[F'] -> B` given by `g ↦ rho(g)` has image `A = C*(rho(F'))`, which is finite-dimensional and
hence closed. This image is `A ≅ ⊕_(pi in S) M_(d_pi)`, where `S` is the set of blocks not in the kernel, and
`rho(g) ↔ (pi(g))_(pi in S)`.

Let `w in F' * <t>` be nonsingular in `t`. `nonsingular-equations-preserve-matrix-certificates` records the
Gerstenhaber--Rothaus assertion: "for a word `w(S,t)` nonsingular in `t`, projection of `w(U,T)=I` onto all coefficient
tuples `U in U(d)^S` is surjective". So for each `pi in S` there is `t_pi in U(d_pi)` with
`w(pi(F'), t_pi) = I`. Then `T = (t_pi)_(pi in S) in U(A) <= U(B)` satisfies `w(rho(F'), T) = 1`.

## Step 4: item 3

`gl3_fp_roots.py` runs over all of `GL_3(F_p)` for `p = 2, 3, 5` and tests `P_c X P_a X P_a = X`. It finds `0` roots in
each case (`out_gl3_fp_roots.txt`).

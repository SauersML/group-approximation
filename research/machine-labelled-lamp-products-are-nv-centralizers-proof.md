Lane proof (bh-invent-11, 2026-09-18), not reviewed.

**What is reused.** The notation, Lemmas 1–3 (completion, history, mirrored orbit) and the
no-return property come from `nv-machines-realize-linear-time-lamp-centralizers-proof`.

**What changes.**
- The lamp group sits on new coordinates that the machine never touches.
- There are `r` emission states instead of one.
- The detector acts on the lamp coordinates instead of a spare bit.

## 1. Layout

Take the stack layout of the reused proof on coordinates `1..n`, and append coordinates
`E = (n+1, ..., n+n')`. No rule of any machine reads or writes `E`. Write points as `(y, e)` with
`e ∈ C^(n')`.
- **The lamp group.** For `k ∈ K ≤ n'V`, let `k^0 ∈ (n+n')V` act as `(y, e) ↦ (y, k(e))` on the
  brick `V_0 × C^(n')` and trivially elsewhere. Here `V_0` is the initial cylinder with copy
  bit `1`, a condition on coordinates `1..n` only.
- **Detectors.** For `s ∈ n'V` and a state `q`, let `s^q` act as `(y, e) ↦ (y, s(e))` on
  `{state q} × C^(n')` and trivially elsewhere.

Both are brick maps piece by piece, so they lie in `(n+n')V`. `k ↦ k^0` is injective, because `V_0`
is nonempty and `K` acts faithfully on `C^(n')`.

## 2. Machines with labels

For each `j` and each sign, fix a verifier for the corresponding NLIN₁ set, with constants
`c_j^±`. Take `C >= max c_j^± + 2`.
- **Choosing a label.** A branch first reads its label `j ∈ {1..r}` from a label tail, in a fixed
  number `ℓ` of steps, absorbed into the reading phase.
- **Emission.** The branch then runs phase R, phase T with verifier `j`, and emission exactly as
  before, with its own emission state `q_j`.
- **The two directions.** `f_+` uses the verifiers for positive times and `f_-` those for
  negative times. Put `a = σF` as before.

As before, `V_i = a^i(V_0)` are pairwise disjoint.
- For `i >= 1`, some point of `V_i` is in state `q_j` iff `i = C·s` and `j ∈ Φ(s)`.
- For `i <= -1`, the same holds with `i = -C·s` and `j ∈ Φ(-s)`.

`a` never touches `E`, so every `V_i` is `E`-saturated: `V_i = V_i' × C^(n')`.

## 3. The embedding of K ≀ Z

- **Lamps.** Put `k_t = a^(Ct) k^0 a^(-Ct)`. It acts as `k` on the `E`-coordinates of
  `V_(Ct)` and trivially elsewhere.
- **The wreath product.** Distinct `t` give disjoint invariant supports. `a^C` shifts them, and
  no nonzero power of `a^C` preserves `V_0`. So `G = ⟨a^C, K^0⟩ ≅ K ≀ Z`.

## 4. The detector

Write `S_j = {s_(j,1), ..., s_(j,ρ_j)}`. The emission of label `j` is duplicated into `ρ_j`
states `q_(j,1), ..., q_(j,ρ_j)`, chosen by one more tail symbol, so that every point in state
`q_j` is split into these copies. Put

```text
m = ∏_(j, ι) s_(j,ι)^(q_(j,ι))  ∈ (n+n')V .
```

The factors have disjoint supports (distinct states), so `m` is well defined. It preserves every
`V_i`, since `V_i` is `E`-saturated.

## 5. The centralizer

**Lamp elements.** Let `f = ∏_t (f_t)_t ∈ ⊕ K`. Both `f` and `m` preserve each `V_(Ct)` and act
there on `E` only, so `[m, f] = 1` iff `[m|_(V_(Ct)), (f_t)_t] = 1` for every `t`.
- **On one piece.** Let `P_(j,ι) ⊆ V_(Ct)` be the set of points in state `q_(j,ι)`. By §2 it is
  nonempty iff `j ∈ Φ(t)`, and it is `E`-saturated. There `m` acts as `s_(j,ι)` on `E`, and
  `(f_t)_t` acts as `f_t` on `E`.
- **Commuting.** Two homeomorphisms that act only on the `E`-factor of a set `P × C^(n')` with
  `P ≠ ∅` commute there iff they commute on `C^(n')`. Off the pieces `m` is trivial.
- **So:** `[m, f] = 1` iff `f_t ∈ ⋂_(j ∈ Φ(t)) C_K(S_j) = D(t)` for every `t`, i.e. iff
  `f ∈ C_Φ`.

**Shifted elements.** Suppose `h = a^(Cp) f` with `p ≠ 0` commutes with `m`.
- For `k ∈ D(t)`, `h k_t h^(-1) = (f_(t+p) k f_(t+p)^(-1))_(t+p)` commutes with `m`, so
  `f_(t+p) D(t) f_(t+p)^(-1) ⊆ D(t+p)`.
- Outside the finite support of `f`, this reads `D(t) ⊆ D(t+p)`. Using `h^(-1)` gives the reverse
  inclusion.
- So `D(t) = D(t+p)` for all but finitely many `t`, contradicting the assumption that `D(·)` is
  not eventually periodic.

Hence `C_G(m) = C_Φ`. ∎

## 6. Consequences

`NV` with `N = n + n'` lies in `B_A` (`permutational-boone-higman-iff-full-cantor-hosts`).
So condition (e) of `pbh-coset-wreaths-iff-identity-edge-hnns` holds for `(K ≀ Z, C_Φ)`, and
(a)–(d) give the list in the target.

**Recovering the earlier theorem.** Take `K = Z/2` generated by a toggle `e` of one coordinate,
`r = 1` and `S_1 = {e'}` with `C_K(e') = 1`. This is `nv-machines-realize-linear-time-lamp-centralizers`
with `U_A = C_Φ`, for `A = {t : Φ(t) = ∅}`.

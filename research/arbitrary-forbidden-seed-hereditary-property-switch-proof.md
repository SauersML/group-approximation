# Arbitrary forbidden seeds and hereditary properties

## Scope

This theorem concerns standard recursively enumerated group presentations.
The negative seed is supplied by a finite presentation, but the ray-switch
output is an enumerated presentation.  No finite-output Higman compiler is
used or claimed here.

That distinction is essential.  The present finite-output MF-safe compiler
still has an unresolved compatibility step at its asymmetric HNN/amalgam
layer.  The theorem below is unconditional because it does not cross that
boundary.

## Parametric switch theorem

Let `d` be an arbitrary code for a finite group presentation, and write

```text
E_d = Carrier(d).
```

There is a jointly computable function

```text
switchCode : FinitePresentationCode × ProgramCode
           -> EnumeratedPresentationCode
```

such that, for every program code `c`, the group `G(d,c)` presented by
`switchCode(d,c)` satisfies

```text
InfiniteDomain(c) -> G(d,c) is isomorphic to 1,
FiniteDomain(c)   -> G(d,c) is isomorphic to E_d.             (S1)
```

Thus every fixed seed `d` produces a family with at most two isomorphism
types.  The result is uniform in the syntax of `d`; no theorem about the
group `E_d` is needed to construct the code.

## Construction

Write

```text
n = genCount(d) > 0
```

and let the generator alphabet be

```text
Nat × Fin(n).
```

At stage `j`, insert a copy of every relator of `d`.  If the Boolean event at
stage `j` is false, insert the bridge relations

```text
(j,g) = (j+1,g)                 for every g : Fin(n).
```

If the event is true, insert the kill relations

```text
(j,g) = 1                       for every g : Fin(n).
```

The standard numerical alphabet uses the bijection

```text
(j,g) |-> j*n + g.
```

When decoding a raw generator address, reduce it modulo `n`.  This reduction
is load-bearing: the finite-presentation syntax interprets every raw index
through `letterOf d`, so merely copying the raw relator list without the
modulo convention would not preserve its semantics.

An address for the relator enumerator decodes into one of three families:

1. a copied seed relator;
2. a bridge relation enabled exactly at a false event;
3. a kill relation enabled exactly at a true event.

Disabled or out-of-range addresses enumerate the empty word.  Multiplication,
remainder, list lookup, bounded event evaluation, and the three finite word
constructors are primitive recursive.  A universal partial-recursive program
and `s-m-n` therefore give `switchCode`, jointly computable in `(d,c)`.

## Semantic proof

If events occur arbitrarily far out, every generator at every stage can be
walked along false bridges until it reaches a true stage, where it is killed.
The presented group is generated by these named generators, so it is
subsingleton and hence explicitly isomorphic to `PUnit`.

If events have a last cut `J`, all stages before `J` die and all stages from
`J` onward are joined by false bridges.  The stage-`J` inclusion gives

```text
stageHom : E_d -> G(d,c).
```

The collapse map sends a generator before `J` to `1` and a generator at or
after `J` to the corresponding generator of `E_d`.  Copied seed relators,
bridges, and kills all map to `1`, so it descends to

```text
collapseHom : G(d,c) -> E_d.
```

The two maps are inverse on generators.  This proves the second branch of
`(S1)`.

The dovetail event stream has unbounded events exactly when the source
program has infinite domain, and a last cut exactly when its domain is
finite.  This proves `(S1)` for every program code.

## Abstract property theorem

Let `P` be a property of groups.  Assume:

```text
Hereditary(P): if H embeds in K and P(K), then P(H),
Positive(P):   P(1),
Forbidden(P): not P(E_d).                                    (P1)
```

Heredity implies isomorphism invariance: transport in either direction along
a group equivalence.

Define the property restricted to the switch family by

```text
SwitchP_d(c) := P(G(d,c)).
```

Then

```text
SwitchP_d(c) iff InfiniteDomain(c).                           (P2)
```

For the forward implication, suppose `P(G(d,c))`.  If the domain were finite,
`(S1)` would identify `G(d,c)` with `E_d`; heredity along the inverse
equivalence would give `P(E_d)`, contradicting `Forbidden(P)`.

For the reverse implication, an infinite domain identifies `G(d,c)` with the
trivial group.  Transport `Positive(P)` across that equivalence.

Taking complements and the exhaustive finite/infinite dichotomy also gives

```text
not SwitchP_d(c) iff FiniteDomain(c).                         (P3)
```

Since `InfiniteDomain` is `Pi^0_2`-complete and `FiniteDomain` is
`Sigma^0_2`-complete under computable many-one reductions,

```text
SwitchP_d      is Pi^0_2-complete,
not SwitchP_d  is Sigma^0_2-complete.                        (P4)
```

No effectiveness assumption on the semantic predicate `P` is required.
On this family its truth value is identified pointwise with the effective
index sets `INF` and `FIN`.

## Global hardness and promises

For enumerated-presentation codes define

```text
PCode(q) := P(Carrier(q)).
```

The computable map `c |-> switchCode(d,c)` and `(P2)` prove

```text
Pi02Hard PCode,
Sigma02Hard (not PCode).                                     (P5)
```

These are hardness statements only.  A global arithmetical upper bound for
arbitrary presentation codes does not follow from the switch.

More generally let `S` be an isomorphism-invariant promise property with

```text
S(1),
S(E_d).
```

Every compiler output satisfies `S`, because `(S1)` leaves only those two
isomorphism types.  Hence the same reductions prove

```text
Pi02HardUnder SCode PCode,
Sigma02HardUnder SCode (not PCode).                           (P6)
```

The promise is range-restricted: every output of the many-one reduction must
satisfy `SCode`.  It is not encoded by silently conjoining `SCode` with the
target predicate.

## Arbitrary finitely presented semantic seeds

Let `E` be any finitely presented group.  Adequacy of the concrete finite
presentation coding gives a code `d` and a group equivalence

```text
Carrier(d) ~= E.
```

If `P(E)` fails, heredity transports that failure to `Carrier(d)`: otherwise
an equivalence would transport `P(Carrier(d))` back to `P(E)`.  The preceding
construction therefore gives a fixed computable compiler `switchCode(d,-)`
with exact branches `1` and `E` and conclusions `(P2)`--`(P5)`.

The choice of a code for an abstract semantic `E` is noncomputable in `E` as
a type.  Uniform computability is correctly stated on explicit finite
presentation syntax: `(d,c) |-> switchCode(d,c)` is computable.

## MF specialization

Take

```text
P(H) := IsOperatorMF(H).
```

Operator-MF passes to subgroups, and the trivial group is finite and hence
Operator-MF.  Therefore every finitely presented non-Operator-MF group `E`
is a valid forbidden seed, and

```text
IsOperatorMF(G(E,c))     iff InfiniteDomain(c),
not IsOperatorMF(G(E,c)) iff FiniteDomain(c).                 (MF1)
```

Thus one arbitrary finitely presented non-MF group universally amplifies to
maximal second-level recognition hardness on standard recursively enumerated
presentations.

If `E` is additionally sofic, choose the promise `S = IsSofic`.  The trivial
group is sofic, so every output is sofic and `(P6)` gives the sofic-promise
hardness theorem.  Non-MF alone does not imply soficity; this extra premise
cannot be omitted.

## Relation to the existing Markov abstraction

`AdianRabinGeneral.MarkovData P` is stronger than the switch needs.  It
contains subgroup heredity, truth on every countably generated free group,
positive syntax, and a forbidden finite presentation.  Its forbidden field
and hereditary field supply `(P1)`, while its free-group clause at the empty
alphabet supplies the trivial positive branch.

Consequently every existing `MarkovData P` instance obtains the full
second-level switch theorem, not merely the classical undecidability theorem.
The extra Markov fields remain necessary for the Adian--Rabin construction,
but are not prerequisites of the ray switch.

## Finite-presentation boundary

The argument above does not prove that recognition on finite-presentation
codes is `Pi^0_2`-complete.  Such a promotion requires a jointly computable
finite-output compiler `R(d,c)` satisfying

```text
InfiniteDomain(c) -> P(Carrier(R(d,c))),
FiniteDomain(c)   -> E_d embeds in Carrier(R(d,c)).            (F1)
```

For any subgroup-hereditary `P`, `(F1)` and `not P(E_d)` would imply the same
truth table and hardness immediately.  This implication can be formalized as
an abstract compiler theorem.  It must not be instantiated until the
finite-output compiler and its positive-branch MF-safety are proved.

In particular, the unresolved asymmetric HNN/amalgam compatibility cannot be
hidden behind Higman embedding or a literature citation.  The recursive
switch theorem is unconditional; the finite-output endpoint remains a
separate research obligation.

## Dependency audit

The unconditional proof uses only:

1. the concrete finite-presentation syntax and its adequacy theorem;
2. elementary presented-group universal properties;
3. primitive-recursive raw-word manipulation and `s-m-n`;
4. the internally proved `INF`/`FIN` completeness theorem;
5. the stated subgroup-heredity, positive, and forbidden clauses.

It uses no Higman embedding theorem, Adian--Rabin literature theorem,
nonlocal-game theorem, MF-safe asymmetric HNN theorem, or property-specific
feature of the literal group `E`.

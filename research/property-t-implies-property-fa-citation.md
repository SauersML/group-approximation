Y. Watatani, *Property T of Kazhdan implies property FA of Serre*, Math. Japon.
27 (1982), no. 1, 97--103.

A property-(T) group `G` is finitely generated with finite abelianization. For an
isometric action of `G` on a tree, the length function `g -> d(gx_0, x_0)` is a
conditionally negative definite function; property (T) forces every conditionally
negative definite function to be bounded, so the action has bounded orbits and,
on a tree (a complete CAT(0) space), a global fixed point. Hence `G` has property
FA. The statement and this argument are standard; see also
Bekka--de la Harpe--Valette, *Kazhdan's Property (T)*, Section 2.

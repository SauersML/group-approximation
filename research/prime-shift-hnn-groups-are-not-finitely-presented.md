**ESTABLISHED (2026-09-18)** through
`prime-shift-hnn-groups-are-not-finitely-presented-proof`. Lane proof, not
independently reviewed; the inputs are Baumslag's wreath product theorem and
standard Bass--Serre theory.

**Setup** (notation of `gl-n-q-lies-in-prime-shift-permutation-group`).
- `N_n(Q)` is the monomial group and `α` its prime-shift automorphism.
- `Π_n = GL_n(Q) *_(N_n(Q)) (N_n(Q) ⋊_α <s>)` is the HNN group. Since `α` is an
  automorphism of the whole edge group, the HNN extension is this amalgam.
- `Π_n` maps onto `K_n`, sending `s` to `σ_n`. For `n = 1` put
  `Π_1 = Aff(Q) *_(Q^x) (Q^x ⋊_σ <s>)`, which maps onto `A_1`.
- Write `τ = (x -> x+1)` and `δ = (x -> 2x)`, and `m_r = (x -> r x)`.

**Statement.**
1. For every `n >= 1`, `Π_n` is finitely generated and **not finitely
   presented**. The normal closure of the single element `x_12(1)` (of `τ` when
   `n = 1`) has quotient `Q^x ⋊_σ <s> ≅ Z/2 × (Z ≀ Z)`.
2. **Finite presentation needs a hidden relation.**
   - If `A_1` is finitely presented, then some dilation `m_r`, `r in Q_>0 \ {1}`,
     lies in the normal closure of `τ` in `A_1`.
   - If `K_n` (`n >= 2`) is finitely presented, then some `diag(r,1,...,1)`,
     `r in Q_>0 \ {1}`, lies in the normal closure of `x_12(1)` in `K_n`.
   - In either case `Π_n -> K_n` (resp. `Π_1 -> A_1`) is not injective.
3. **Finitary permutations need a hidden relation.** If `Π_1 -> A_1` is
   injective, then `A_1` contains no nontrivial finitary permutation of `Q`.
   Since `A_1` is 2-transitive, hence primitive, Jordan--Wielandt gives the
   converse direction: `A_1` contains `Alt_fin(Q)` if and only if it contains one
   nontrivial finitary permutation. So `Alt_fin(Q) <= A_1` forces
   `ker(Π_1 -> A_1) != 1`. The citation is Wielandt 1960; see Dixon--Mortimer,
   *Permutation Groups*, §3.3. The theorem number is not pinned.
4. **Abelianization.**
   - `Π_1^ab = Π_n^ab = Z/2 × Z × Z`. For `n = 1` it is generated by `ι`, `δ` and
     `s`, and `τ` maps to `0`. For `n >= 2` the generators are the images of
     `diag(-1,1,...,1)`, `diag(2,1,...,1)` and `s`.
   - `A_1^ab` and `K_n^ab` are quotients of this group. They equal it if the
     surjection is injective.
   - Neither is computed here. No homomorphism of `A_1` onto `Z` has been
     constructed.

**The single open question.** Everything above turns on whether
`Π_1 -> A_1` and `Π_n -> K_n` are injective, that is, whether the prime shift
satisfies relations with the affine group beyond `σ m_a σ^-1 = m_(σ(a))`.
- If they are injective, `A_1` and `K_n` are not finitely presented, have no
  finitary elements, and have abelianization `Z/2 × Z^2`. The prime-shift route to
  type (A) is then dead in this form.
- If they are not, the relation must mix translations with the shift, and by
  item 2 finite presentation requires one of a specific kind.

## Attempts

- **Injectivity.** Evaluating a reduced word `f_1 σ^(a_1) ⋯ f_m σ^(a_m)`
  (`f_i(0) != 0`, `a_i != 0`) on large primes needs control of the factorization
  of `α P + β` along the trajectory. That is a prime-pattern problem of
  Dickson type, which is not attempted.

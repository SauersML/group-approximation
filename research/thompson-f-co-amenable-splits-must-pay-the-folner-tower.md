**ESTABLISHED** by `thompson-f-co-amenable-splits-must-pay-the-folner-tower-proof`. It is a direct proof, and its
only import is Moore's Theorem 1.1 (`thompson-f-folner-function-exceeds-every-tower`). Theorem 1 is the standard
product argument for Følner sets of extensions, adapted to Schreier graphs. It has not been independently reviewed.

**Conventions.** These are Moore's conventions (arXiv:0905.1118v7):
- `Γ` is a finite symmetric generating set of `F`, `|g|` is word length, and `B(L)` is the ball of radius `L`.
- A finite nonempty `A ⊆ F` is `ε`-Følner if `Σ_{γ∈Γ} |Aγ Δ A| < ε|A|`.
- `Føl_F(n)` is the least size of a `1/n`-Følner set.

For `K ≤ F`:
- `X = K\F` is the space of right cosets. `F` acts on it on the right, the base point is `o = K`, and `d_X` is
  the Schreier-graph distance, with edges `x — xγ`.
- A finite nonempty `E ⊆ X` is `ε`-Følner if `Σ_γ |Eγ Δ E| < ε|E|`. Its radius is `rad(E) = max_{x∈E} d_X(o, x)`.
- The **coset profile** is `S_K(n) = min{ |E| + rad(E) : E ⊆ X is 1/n-Følner }`.
- The **relative Følner function** `Φ_K(L, η)` is the least `|Φ|` over finite nonempty `Φ ⊆ K` with
  `|Φc Δ Φ| ≤ η|Φ|` for every `c ∈ K ∩ B(L)`.

Each quantity is `∞` if no such set exists.

**Theorem 1 (coset composition; valid in every finitely generated group).** Let `E ⊆ X` be `ε`-Følner, let
`L = 2·rad(E) + 1`, and let `Φ ⊆ K` witness `Φ_K(L, η)`. Then there is an `(ε + |Γ|η)`-Følner set
`A ⊆ F` with `|A| = |E|·|Φ|`. It is `A = ⊔_{x∈E} Φ t_x`, where each `t_x` is a geodesic coset representative.

**Corollary 2 (Moore transferred).** Let `C` be Moore's constant for `Γ`. For every `m ≥ 1`, every `K ≤ F` and
every `(C^{−m}/2)`-Følner `E ⊆ K\F`,

`|E| · Φ_K(2·rad(E) + 1, C^{−m}/(2|Γ|)) ≥ exp_m(0)`.

**Corollary 3 (the tower must be paid).** No `K ≤ F` and `k ≥ 1` satisfy both of the following:
- `S_K(n) ≤ exp_k(n + k)` for all `n ≥ 1`;
- `Φ_K(L, 1/n) ≤ exp_k(L + n + k)` for all `L, n ≥ 1`.

Since `exp_k(y)` is nondecreasing in `k` for `y ≥ 1`, this also rules out bounds `exp_a(n + a)` and
`exp_b(L + n + b)` with different `a` and `b`.

So for every co-amenable amenable `K ≤ F`, at least one of the coset profile `S_K` and the relative Følner function
`Φ_K` is bounded by no fixed tower. If `S_K(n) ≤ exp_{k_0}(n + k_0)`, then the bound on `Φ_K` fails for every
`k ≥ k_0`, and monotonicity in `k` covers the smaller `k`. If `F` is not amenable, then no subgroup of `F` is both amenable and
co-amenable, and the corollary is vacuous but true.

**Corollary 4 (intrinsic form).** Let `K` be generated by a finite symmetric set `T`, and let its distortion be
`Δ_K(L) = max{ |k|_T : k ∈ K, |k|_Γ ≤ L }`. Then `Φ_K(L, η) ≤ Føl_{K,T}(⌈Δ_K(L)/η⌉)`. So the following cannot all
be elementary:
- `S_K`;
- `Føl_{K,T}`;
- `Δ_K`.

**Corollary 5 (polynomial-growth coset spaces).** Suppose `|B_X(o, r)| ≤ D·r^d` for all `r ≥ 1`. Then
`S_K(n)` is bounded by a polynomial in `n`. So if `K` is amenable, `Φ_K(L, 1/n)` is bounded by no fixed tower
`exp_k(L + n + k)`: any such `K` has
Følner sets, relative to its `F`-metric, that are as expensive as those of `F` up to a bounded tower.

**Remark (the other direction).** For every `K`, the minimal size of a `1/n`-Følner subset of `K\F` is at most
`Føl_F(n)`: push a Følner set of `F` forward and use the coarea formula. So the coset-size profile never exceeds
`F`'s. Corollary 3 says the tower that `F` carries must reappear in one of three places:
- the radius of the coset Følner sets, meaning they sit far from the base coset;
- their size;
- the relative Følner sets of `K`.

**What this kills.** The class is every proof of `thompson-f-is-amenable` through
`thompson-f-amenable-via-exotic-co-amenable-subgroup`, or through any co-amenable split `K ≤ F` with `K` amenable,
in which both of the following are elementary, meaning bounded by a fixed tower in the parameters:
- the Følner sets exhibited for `F/K`, in size and in distance from `K`;
- the Følner sets exhibited for `K`, measured against elements of `F`-length `L`.

Every member dies at Corollary 3, because Theorem 1 assembles the two families into elementary-size Følner sets of
`F`, and that contradicts Moore's Theorem 1.1. Three typical members:
- a Schreier graph of polynomial or other controlled growth, paired with a bounded-depth elementary amenable or
  solvable `K` that is undistorted;
- an "explicit tiling" of `F/K` by `Z^d`-type boxes near the base coset;
- any quantitative rate for P1 together with any quantitative rate for P2.

This corrects the sentence in `thompson-f-amenable-via-exotic-co-amenable-subgroup` saying that both prerequisites
"escape the tower barrier as stated". That is true only of the qualitative statements. Any proof of P1 that
supplies Følner sets of `F/K`, combined with any proof of P2 that supplies Følner sets of `K`, re-enters the
barrier through the pair `(S_K, Φ_K)`.

**What is left.** A successful co-amenable split must do one of three things:
- (a) exhibit an F-free amenable `K ≤ F` with a relative Følner function beyond every tower, which is a new
  phenomenon in its own right, because every F-free subgroup the graph classifies is elementary amenable;
- (b) use Følner sets of `F/K` that are non-elementary in size or radius, which is then as hard as Moore's problem
  for `F`;
- (c) prove P1 or P2 non-constructively, by invariant means without Følner rates. Even then the rates exist, and
  Corollary 3 applies to them.

**ESTABLISHED (unreviewed).** Proof: `tits-hosts-for-transitive-local-actions-proof`.
The instance in item 6 is certified by the attached GAP script.

**Setting.** Let `C` be a finite set of colours with `|C| = d + 1 ≥ 3`, let `0 ∈ C`, and
let `F ≤ Sym(C)` be transitive, with point stabilizers `F_c`. Assume `F_0 ≠ 1` and
`F = ⟨F_c : c ∈ C⟩`. The second condition holds whenever `F` is primitive (and `F_0 ≠ 1`)
or simple. Put `X = C∖{0}` and let `P = F_0`, acting on `X`.

A subgroup `R ≤ Aut(X*)` is **fully self-replicating with root image `P`** if it is
closed under sections (S), contains `r@x` for all `r ∈ R`, `x ∈ X` (B), and has root
permutation group exactly `P` (A). Then the section map is an isomorphism `R ≅ R ≀_X P`.

**The relabelling cocycle.** Choose `τ_c ∈ F` with `τ_c(0) = c` (transitivity), and
put `κ(σ, c) = τ_{σc}^{-1} σ τ_c` for `σ ∈ Sym(C)`. Then `κ(σ, c)` fixes `0`, and
`κ(σ, c) ∈ F_0` iff `σ ∈ F`. It is a cocycle: `κ(σρ, c) = κ(σ, ρc) κ(ρ, c)`. This is the
Krasner--Kaloujnine cocycle of `F` over `F_0`. With the relabellings `λ_c = τ_c^{-1}` on
`C∖{c}`, it replaces the parity lemma of the `A_{d+1}` construction.

**The host.** Let `T = T_{d+1}`, with a legal edge colouring by `C` and the edge-free
colour-preserving core `G ≅ *_{c ∈ C} Z/2`. The relabellings give half-tree coordinates
and sections `s_f(g) ∈ Aut(X*)` at oriented edges `f`. Put
`Γ_R^F = {g ∈ Aut(T) : s_f(g) ∈ R for every oriented edge f}`.

**Theorem.** Let `R` be fully self-replicating with root image `P = F_0`.

1. **Group.** `Γ_R^F` contains `G`, acts vertex-transitively, and fixes no end.
2. **Tits' (P).** `Γ_f = R_Γ(Y_f) × R_Γ(Y_{f̄})`, and `s_f : R_Γ(Y_f) ≅ R`. So `Γ_f ≅ R × R`.
3. **Vertex groups.** `Γ_v ≅ R ≀_C F`, with local action `F` at every vertex.
4. **Simplicity and presentation.** `Γ⁺ = (R ≀_C F) *_{R × R} (R ≀_C F)` is the
   type-preserving subgroup, of index 2, and it is simple. If `R` is finitely generated,
   then `Γ⁺` is finitely generated, with finitely generated edge groups, and `Γ⁺` is
   finitely presented iff `R` is.
5. **Obstruction.** By `self-wreathing-groups-are-not-fp-infinity`, applied to
   `R ≅ R ≀_X F_0`:
   - if `H_1(F_0) ≠ 0`, no such `R` is finitely generated;
   - if `F_0` is perfect with `H_2(F_0) ≠ 0`, no such `R` is finitely presented.

   So **a finitely presented section-closed Tits host with local action `F` and finitely
   generated edge groups requires `F_0` to be superperfect** (`H_1 = H_2 = 0`). Examples that pass: `M_12` on 12 points
   (`F_0 = M_11`), `M_24` on 24 points (`F_0 = M_23`), and `S × S` acting on `S` by
   `x ↦ a x b^{-1}` for a superperfect simple `S` such as `PSL(2,8)` (504 points,
   `F_0 = S` diagonal). The Schur multipliers of `M_23` and `PSL(2,8)` are trivial by the
   ATLAS (cited). The script checks only `M_11`.
6. **Instance for `M_12`.** Let `X = {1, …, 11}` with the natural action of
   `P = M_11 = Stab_{M_12}(12)`. The root letter is `1`. Take the 11-cycle `α` and the element `β`
   of order 5 printed by the script, and put `b = (b, α, β, 1, …, 1)`. It has sections at the
   letters `1, 2, 3` and trivial root permutation. Then `R = ⟨M_11, b⟩` is fully
   self-replicating with root image `M_11`. So `Γ⁺` is a **finitely generated simple
   Tits-(P) group on `T_{12}` with local action `M_12` and edge groups `R × R`**. Its
   point-stabilizer local action lies outside every case of item 5.
7. **Blindness in degree 2.** If `F_0` is superperfect, every congruence quotient
   `R / Stab_R(n) ≅ W_n = F_0 ≀ ⋯ ≀ F_0` is superperfect. So is every retract `W_n` used in
   item 5. No argument through these finite groups, their homology or the congruence
   completion can obstruct `FP_2`.

**Reduction.** Items 4 and 5 give a two-directional statement.

**A finitely presented simple Tits-(P) group of the section-closed form `Γ_R^F`
exists iff some superperfect point stabilizer `F_0` of a transitive `F` carries a
finitely presented fully self-replicating `R`.**

- The instance of item 6 is generated by a bounded automaton. So it is contracting, and
  Bartholdi's theorem (contracting regular branch groups are not finitely presented;
  cited) kills it.
- The surviving search space is therefore the **non-contracting** fully
  self-replicating groups with superperfect root image, such as `M_11`, `M_23` or `PSL(2,8)`.
- By item 7, a proof that none is finitely presented must use their infinite-order
  structure, not their finite quotients.

**Calibration.**

- `F = A_{d+1}` recovers `fully-self-replicating-tree-groups-give-fg-tits-hosts`. There
  the cocycle takes values in `A_d`, which is the parity lemma.
- `F = Sym(C)` with `R = Aut_{Sym(d)}(X*)` gives the Burger--Mozes group `U(Sym(d+1))`.
- A regular `F` has `F_0 = 1`. Then `R = 1` and `Γ_R^F = G`, which has no (P)-simple
  subgroup. This is why `F_0 ≠ 1` is assumed.
- For `F = M_12`, the script confirms that `M_12` is generated by its point stabilizers,
  and that `M_11` is transitive on 11 points, perfect, and has trivial Schur multiplier.

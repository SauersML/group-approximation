- **The problem** (Kourovka 18.47, S. Kohl; the text below matches the 21st issue as extracted from the
  notebook LaTeX). Is it algorithmically decidable whether a group generated by three given class transpositions
  (a) has only finite orbits on `Z`? (b) acts transitively on the set of nonnegative integers in
  its support?
- **What this settles.** (a) with "three" replaced by "finitely many" is undecidable, already
  for class transpositions with `{2,3,5,7,11,13}`-smooth moduli.
- **What stays open.** (a) for three generators, or for any fixed number, and all of (b). The number
  of generators below grows with the machine (see Remark 3).

## Theorem

An algorithm takes a reversible 2-counter machine `M` (Kari–Ollinger conventions, as in
`ct-z-finite-cycle-problems-are-undecidable`) and outputs a finite set `S_M` of class
transpositions with `{2,3,5,7,11,13}`-smooth moduli such that:
1. `⟨S_M⟩` has only finite orbits on `Z` iff every configuration of `M` is periodic;
2. `⟨S_M⟩` is finite iff `M` is uniformly periodic.

By Kari–Ollinger Theorem 3 (periodicity of complete 2-RCM is undecidable), property 1 is undecidable
for groups generated by finitely many given class transpositions. By Theorem 4 (uniform periodicity
is decidable), property 2 is decidable on this family. So the undecidability sits exactly in the
**infinite** groups all of whose orbits are finite.

## Lemma 1 (splitting into two disjoint-support families). Not independently reviewed.

Let `S` be a set of involutions of a set `Ω`, and `S = S_1 ⊔ S_2`, where the elements of each
`S_j` have pairwise disjoint supports. Put `σ_j = ∏_{s ∈ S_j} s`, a well-defined involution since the
factors commute and have disjoint supports. Then `⟨S⟩` and `⟨σ_1, σ_2⟩` have the same orbits on `Ω`.

*Proof.* The orbits of a group generated by a set `T` of involutions are the connected components of
the graph `Γ_T` on `Ω` with edges `{x, t(x)}`, `t ∈ T`. For each `x` at most one `s ∈ S_j`
moves `x`, and then `σ_j(x) = s(x)`; otherwise `σ_j(x) = x`. So `Γ_S` and `Γ_{σ_1,σ_2}` have
the same non-loop edges. ∎

## Lemma 2 (dihedral orbits). Standard.

For involutions `σ_1, σ_2` and `g = σ_2 σ_1`, every element of `⟨σ_1, σ_2⟩` is `g^k` or `g^k σ_1`,
since `σ_1 g σ_1 = g^{-1}` and `σ_2 = g σ_1`. So the orbit of `x` is `⟨g⟩x ∪ ⟨g⟩σ_1x`. Hence all
orbits are finite iff every cycle of `g` is finite. Moreover the orbit sizes are bounded iff the
cycle lengths of `g` are bounded, i.e. iff `g` has finite order. ∎

## Lemma 3 (bounded orbits force finiteness). Standard.

A finitely generated `G ≤ Sym(Ω)` all of whose orbits have size at most `B` is finite. It
embeds in `∏_O Sym(O)`, a product of subgroups of `S_B`, so it lies in the variety generated by
`S_B`. A variety generated by a finite group is locally finite: its free group of rank `r` embeds in
`S_B^{(S_B^r)}`. ∎

## Proof of the Theorem

Take the data of `ct-z-finite-cycle-problems-are-undecidable` for `M`: the periodic set `X` of
odd codes, the bijection `f : X → X`, the modulus `L = 2·3²·5²·7^{N+1}·11·13`, the set
`K = {c : c(L) ⊆ X}`, and the multipliers `λ_c > 0` with `f(c(L)) = (λ_c c)(λ_c L)`. Put

    S_M = { τ_{c(L), 2c(2L)} , τ_{2c(2L), (λ_c c)(λ_c L)} : c ∈ K }.

- **Class transpositions.** In each pair the two classes are disjoint: `c(L)` and `f(c(L))` are
  odd, and `2c(2L)` is even. The moduli divide `2·λ_c L`, so they are `{2,…,13}`-smooth.
- **Two disjoint-support families.** That node proves that the supports within
  `S_1 = {τ_{c(L),2c(2L)}}` are pairwise disjoint, and likewise within
  `S_2 = {τ_{2c(2L),f(c(L))}}`. The products are its involutions `s_1` (`n ↔ 2n` on `X`) and
  `s_2` (`2n ↔ f(n)`), and `F_M = s_2 s_1`.
- **Property 1.** By Lemma 1, `⟨S_M⟩` has the orbits of `⟨s_1, s_2⟩`. By Lemma 2 these are all
  finite iff `F_M` has only finite cycles, which by part 1 of that node's Theorem holds iff every
  configuration of `M` is periodic.
- **Property 2.** By Lemmas 2 and 3, `⟨S_M⟩` is finite iff its orbits are bounded, iff `F_M` has
  finite order, iff `M` is uniformly periodic (that node's Remark "Finite order").
- **Computability.** `S_M` is computed from the table of `M` by finite checks mod `L`, as in that
  node. ∎

## Remarks

1. **One generator can be saved.** `S_1` may be replaced by the single class transposition
   `τ_{1(2),2(4)}` (that is, `n ↔ 2n` on all odd `n`). Every class `2c(2L)` lies in `2(4)`, since
   `c` is odd and `4 | 2L`. The new product maps `n ↦ f(n)` on `X` and `2n ↦ 2f^{-1}(n)` on `2X`. It swaps
   `n ↔ 2n` for odd `n ∉ X`, and fixes `0(4)`, so its cycles are finite iff those of `f` are.
2. **The reduction goes both ways.** For any `g ∈ CT(Z)` written as `g = σ_2σ_1`, with each `σ_j` a
   product of disjoint class transpositions, 18.47(a) for the group those transpositions generate is
   exactly 21.74(b) for `g`. In particular, for a triple in which two transpositions have disjoint
   supports, 18.47(a) is 21.74(b) for the single element `τ_k τ_i τ_j`. Kohl's Collatz triple
   `⟨τ_{1(2),4(6)}, τ_{1(3),2(6)}, τ_{2(3),4(6)}⟩` is not of this kind: all three supports overlap
   pairwise.
3. **Why three generators is different.** `|S_M| = 2|K|`, or `1 + |K|` after Remark 1, and `|K|`
   grows with the number of states and instructions of `M`. A fixed number of class transpositions
   gives maps with a fixed number of affine pieces. Undecidability there would be an analogue of
   the generalized Collatz problem for a *fixed* modulus. Kurtz–Simon settle that only with the
   modulus as part of the input. For three generators the orbit graph is 3-edge-coloured with at
   most six moved residue classes, and neither decidability nor undecidability is known to us.
4. **Structure of the hard instances.** For `M` periodic but not uniformly periodic, `⟨S_M⟩` is
   an infinite, residually finite, non-periodic subgroup of `CT_P(Z)`, `P = {3,5,7,11,13}`. It
   contains `F_M` of infinite order, and all its orbits on `Z` are finite.

## Attempts: compressing to three generators (bh-k1847, 2026-09-19; not reviewed)

- **Family 1 compresses to one class transposition.** Remark 1: `S_1` can be replaced by
  `τ_{1(2),2(4)}`.
- **Family 2 cannot become a single class transposition by any simultaneous conjugation, if (P2)
  holds.** Suppose some bijection `h` of `Z` made both `h s_1 h⁻¹` and `h s_2 h⁻¹` class
  transpositions. Then `F_M` would be conjugate to a product of two class transpositions. Take `M`
  periodic but not uniformly periodic. Then `F_M` has infinite order and only finite cycles
  (Remark 4). So the compression is impossible whenever:
  - **(P2)** a product of two class transpositions with only finite cycles has finite order.

  (P2) is **conjectural**. It fits the finite order sets known for horizontal and `d`-adic pairs
  (`kourovka-18-48-for-d-adic-class-transpositions`). Proving (P2) would show that any
  three-generator undecidability must use a third generator in an essential way.
- **Shape of a three-generator reduction.** By Remark 2, a triple containing a disjoint pair is
  21.74(b) for the three-letter word `τ_k τ_i τ_j`. So a new three-generator result needs one of:
  - 21.74(b) undecidable already for products of three class transpositions;
  - the pairwise-overlapping shape of Kohl's Collatz triple.
- **Obstruction in general.** Three class transpositions are given by 12 integers and move at most
  six residue classes, each by one canonical affine map. So a uniformly undecidable family would
  have to encode the machine program in the arithmetic of a bounded number of affine pieces, not
  in their number. This is an analogue of reachability for one-dimensional piecewise affine maps
  with boundedly many pieces, a well-known open problem (Koiran–Cosnard–Garzon; two dimensions is
  undecidable). The analogy is heuristic; no reduction either way is claimed.

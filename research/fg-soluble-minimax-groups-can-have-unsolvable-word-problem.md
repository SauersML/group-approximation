**ESTABLISHED.** The existence statement is quoted from the literature. The explicit family is a
lane proof (elementary; not independently reviewed; no priority claimed).

## Source

Kropholler–Lorensen, *Virtually torsion-free covers of minimax groups*, arXiv:1510.07583v3, p. 3 (read
in the PDF). They write `𝔐` for virtually soluble minimax groups, `𝔐_1` for the virtually
torsion-free ones, and `𝔐_∞` for the rest:
- "there are uncountably many nonisomorphic, finitely generated 𝔐_∞-groups (see either [16, p. 104]
  or Proposition 7.12 below)", where [16] is Lennox–Robinson, *The Theory of Infinite Soluble
  Groups* (2004);
- "The word problem, for instance, is solvable for every finitely generated group in 𝔐_1 (see [2]).
  However, since the number of possible algorithms is countable, there exist uncountably many
  nonisomorphic, finitely generated 𝔐_∞-groups with unsolvable word problem." Here [2] is
  Cannonito–Robinson, Bull. London Math. Soc. 16 (1984).

## The explicit family

Let `R = Z[1/p]` and `H(R) = {(α, β, γ)}` with `(α,β,γ)(α',β',γ') = (α+α', β+β', γ+γ'+αβ')`. Let
`P = (H(R) × H(R)) ⋊ ⟨t⟩`, where `t` acts on both factors by `(α, β, γ) ↦ (α/p, pβ, γ)`. For
`u ∈ Z_p` put

    K_u = {(0,0,x) × (0,0,y) : x, y ∈ R, x − u y ∈ Z_p},     G_u = P / K_u.

1. `G_u` is a finitely generated soluble minimax group of derived length 3. Its finite residual is
   `Z(H × H)/K_u ≅ C_(p^∞)`, central, and `t` acts trivially on it.
2. `G_u` has solvable word problem if and only if `u` is computable.
3. So for every non-computable `u`, `G_u` embeds in no finitely generated group with solvable word
   problem. In particular it embeds in no finitely presented simple group and in no Abels-type host
   whose corner lattice is computable.

## Proof

1. **The group.** `P` is generated by `t` and `a_i = (1,0,0)`, `b_i = (0,1,0)` in factor `i`, since
   `t^k a_i t^{-k} = (p^{-k},0,0)` and `t^{-k}b_it^k = (0,p^{-k},0)`, and commutators give the centre.
   - `K_u` is central and `t`-invariant, since `t` fixes the centre `R^2`. So it is normal.
   - `K_u ⊇ Z^2`, and `(x, y) ↦ x − uy mod Z_p` maps `R^2` onto `Q_p/Z_p`, because `x ↦ x mod Z_p`
     already maps `R` onto it. So `R^2/K_u ≅ C_(p^∞)`.
   - `G_u` has a series with cyclic or quasicyclic factors (refine `R ⊃ Z` in each coordinate), so
     it is minimax. It is soluble of derived length 3.
   - The central `C_(p^∞)` has no finite quotients, so it lies in the finite residual. `G_u` modulo
     it is `P/Z(H × H)`, which is linear over `Q`, so residually finite. Hence the finite residual is
     exactly `R^2/K_u`.
2. **Word problem.**
   - A word in the generators is evaluated in `P` by exact arithmetic in `R`. It is trivial in `G_u`
     iff its `t`-exponent and all `α`, `β` coordinates vanish and its centre coordinate `(x, y)`
     satisfies `x − uy ∈ Z_p`.
   - Write `y = p^{-n}y_0` with `y_0 ∈ Z`. This needs `u` modulo `p^n`, which is computable when `u`
     is. So `u` computable gives solvable word problem.
   - Conversely, `[a_i(α), b_i(β)] = c_i(αβ)` in this multiplication, so
     `[a_1(p^{-n}), b_1(c)]·[a_2(p^{-n}), b_2(1)]` is the central element `(p^{-n}c, p^{-n})`. It lies
     in `K_u` iff `p^{-n}(c − u) ∈ Z_p`, that is, iff `c ≡ u mod p^n`.
   - Testing `c = 0, …, p^n − 1` with a word-problem oracle computes `u mod p^n`. So solvable word
     problem gives `u` computable.
3. **Consequences.**
   - A finitely generated subgroup of a finitely generated group with solvable word problem has
     solvable word problem.
   - Finitely presented simple groups have solvable word problem (Kuznetsov; see
     `simple-envelope-forces-solvable-word-problem`).
   - The hosts `(𝐀_n(O_K[1/m]) · Δ)/e_1n(L)` of `partial-torus-abels-quotients-are-isolated`, with
     `L` given by generators, have solvable word problem: evaluate the matrix and test corner
     membership in `L`. ∎

## Uncountably many

For fixed `P`, only countably many `K` have `P/K` isomorphic to a given finitely generated group,
since homomorphisms between finitely generated groups are countable. The `K_u` are pairwise
distinct. So the `G_u` fall into `2^(ℵ_0)` isomorphism classes, recovering the uncountability
quoted above. Lennox–Robinson p. 104 and Kropholler–Lorensen Prop. 7.12 are presumably of the same
kind; they were not read.

## Lesson for general BH

For non-residually-finite soluble minimax groups, solvability of the word problem is extra data, not
structure.
- The radical is reached from torsion-free sections through `p`-adic functionals such as
  `x − uy`, and their digits are the word problem.
- So the Boone–Higman question for the class is: every such group with solvable word problem, for
  instance `G_u` with `u` computable, embeds in a finitely presented simple group.
- Any host family must realize arbitrary computable `p`-adic linking data. Whether hosts whose corners are
  defined over number fields reach computable transcendental `u` is open.

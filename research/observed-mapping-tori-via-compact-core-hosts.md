The first prerequisite supplies the host with all compact-core data
and a faithful embedding of the mapping torus. The second gives a
faithful oligomorphic clopen actor of type `F_k`, with all finite-subset
stabilizers of type `F_k`, using BHM arXiv:2407.03149v1 Theorem 2.1.
Belk–Zaremsky arXiv:2001.04579 Theorem D and cited Theorem 3.4 give the
simple type `F_k` envelope and two finite-order generators. Both new
prerequisites remain OPEN, so no unconditional result is established.

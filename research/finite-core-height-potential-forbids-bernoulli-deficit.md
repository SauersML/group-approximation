Let `G` be a countable group, `|A| = q >= 2`, and `(k, E, F, psi)` a configuration as in
`bernoulli-rokhlin-deficit-has-a-finitary-witness`, with value `Phi`. Put `Q = {1} ∪ E ∪ FE`.

A *height potential* is a pair `a : F -> Z_(>=0)`, `b : E -> Z_(>=0)` for which the rules
`ht(1) = 0`, `ht(e) = b(e)` and `ht(fe) = a(f) + b(e)` define a function on `Q`. That is, two
expressions naming the same element of `G` get the same height. Its *core* is the subgroup `K_Z`
generated by the zero letters `a^-1(0) ∪ b^-1(0)`.

**Theorem.** If the configuration admits a height potential with finite core, then `Phi >= log q`.

**Consequence (filter).** In every Bernoulli Rokhlin deficit witness over any group, every height
potential of the pattern has an infinite core.
- Read pairs `fe = 1` are zero letters, and the read bound gives `m >= 2`. So the core always contains
  a nontrivial read letter.
- In particular the positive letters may generate a nonsofic group, where
  `sofic-radical-localizes-bernoulli-deficit-witnesses` gives nothing.
- In a torsion-free subgroup the finite-core hypothesis never holds for `m >= 2`. So the filter bites
  only on witnesses whose core meets torsion.

**Proof idea.**
- *Functional count.* The Gromov--Weiss count runs on any finite set with arbitrary self-maps
  `T_f, S_e`. It needs only that most points see an injective chart of `Q` with the right
  coincidences, and it gives `log q <= Phi + beta(log|R|/k + log q)`.
- *Germ model.* A point at level `r` is a coloring of the finite region `K_Z B(r)` together with a
  padding word of length `r`. Each letter restricts the translated coloring to the region `lambda`
  times its height lower down.
- *Coincidences.* Zero letters preserve regions because the core is finite. The height potential
  makes `S_e T_f` depend only on the element `fe`, so every coincidence of the pattern holds exactly.
- *Separation.* Random colorings separate distinct points of the same height.

## Why sufficient

Notation: `K = F_S/N`, and `1 -> <t> -> Ktilde -> K -> 1` is central with `t` of infinite order.
Fix lifts `shat ∈ Ktilde` of the generators `s ∈ S`. Then `Ktilde` is generated by
`Shat ∪ {t}`, because every element is `w(shat)·t^a`. The norm is the operator norm.

**Step 1 (the relator).** By (ii), `t^d ∈ [Ktilde, Ktilde]` for some `d ≠ 0`.
- Write `t^d = ∏_l [u_l, v_l]` with `u_l = w_l(shat) t^{a_l}` and `v_l = w'_l(shat) t^{b_l}`.
- `t` is central, so `[u_l, v_l] = [w_l(shat), w'_l(shat)]`.
- Put `zhat = ∏_l [w_l, w'_l] ∈ [F_S, F_S]`. Then `zhat(shat) = t^d`.
- The map to `K` kills `t`, so `zhat ∈ N`.

**Step 2 (the winding is an integer and locally constant).** Let
`U_n = {a ∈ U(n)^S : ‖zhat(a) − 1‖ < 1}`.
- For `a ∈ U_n` the eigenvalues of `zhat(a)` lie in `{|λ − 1| < 1}`, which avoids `−1`. So the
  principal logarithm is continuous there, and `W(a) = (1/2πi) Tr log zhat(a)` is continuous on
  `U_n`.
- `exp(2πi W(a)) = det zhat(a) = 1`, because `zhat(a)` is a product of commutators.
- So `W` is integer-valued and locally constant on `U_n`.
- If `zhat(a) = 1` then `W(a) = 0`.

**Step 3 (homotopy).** Let `a, b ∈ U(n)^S` with `max_s ‖a(s) − b(s)‖ ≤ δ` and
`‖zhat(b) − 1‖ ≤ η`, and suppose `η + |zhat| δ < 1`, where `|zhat|` is the word length. Put
`a^τ(s) = b(s) exp(τ H_s)` for `τ ∈ [0,1]`, where `H_s = log(b(s)^* a(s))` is skew-hermitian with
spectrum in `i[−π, π]`.
- For `|θ| ≤ π` and `τ ∈ [0,1]`, `|e^{iτθ} − 1| = 2|sin(τθ/2)| ≤ 2|sin(θ/2)| = |e^{iθ} − 1|`.
  So `‖a^τ(s) − b(s)‖ ≤ ‖a(s) − b(s)‖ ≤ δ`.
- Telescoping the word, `‖zhat(a^τ) − zhat(b)‖ ≤ |zhat| δ`. So `a^τ ∈ U_n` for every `τ`.
- By Step 2, `W(a) = W(b)`.

**Step 4 (scalar-twisted models).** Use (i). For each `i` take `ℓ_i -> ∞` with
`ℓ_i ≥ |zhat| + |d| + 4`, and a finite group `E_i` with a map from the ball of radius `ℓ_i` of
`Ktilde`, in the word metric of `Shat ∪ {t}`. The map is injective on the ball and multiplicative
whenever both factors and the product lie in it. Replace `E_i` by the subgroup generated by the
images `shat_E` and `t_E`.
- `[t, shat] = 1` has length 4, so `t_E` commutes with every generator and is central in `E_i`.
- `t^k ≠ 1` in `Ktilde` for `k ≠ 0`. By injectivity on the ball, `t_E` has finite order
  `m_i > ℓ_i`.
- `zhat(shat) t^{-d} = 1` has length at most `ℓ_i`, so `zhat(shat_E) = t_E^d`.
- The character `t_E ↦ e^{2πi/m_i}` of `<t_E>` occurs in the restriction of the regular
  representation of `E_i`. So some irreducible `σ_i` of `E_i`, of dimension `n_i`, has
  `σ_i(t_E) = e^{2πi/m_i}·1`, by Schur's lemma since `t_E` is central.
- Put `b_i(s) = σ_i(shat_E)`.

*(b_i) is an asymptotic representation of `K`.* Fix `r ∈ N`. In `Ktilde`, `r(shat) = t^{e(r)}`
for a fixed integer `e(r)`. Once `ℓ_i ≥ |r| + |e(r)|`, this relation holds in `E_i`, and
`r(b_i) = e^{2πi e(r)/m_i}·1`, which tends to `1` as `m_i -> ∞`.

*Nonzero winding.* `zhat(b_i) = e^{2πi d/m_i}·1` and `|d|/m_i < 1/2`. So
`W(b_i) = n_i d / m_i`, which is nonzero because `d ≠ 0`.

**Step 5 (conclusion).** Suppose `K` were LS. Apply it with `R = {zhat}` to `(b_i)`. That gives
`c_i` with `zhat(c_i) = 1` and `δ_i = max_s ‖b_i(s) − c_i(s)‖ -> 0`.
- Put `η_i = ‖zhat(b_i) − 1‖ = |e^{2πi d/m_i} − 1|`, which tends to `0`.
- For `i` large, `η_i + |zhat| δ_i < 1`. Step 3 then gives `W(b_i) = W(c_i) = 0`, which
  contradicts Step 4.
- The same argument works for any finite `R ⊇ {zhat}`.

**Corollary (perfect K).**
- If the extension splits, `Ktilde = K' × <t>` with `K' ≅ K`. Then `[Ktilde,Ktilde] ⊆ K'`, which
  meets `<t>` trivially.
- Conversely, suppose `<t> ∩ [Ktilde,Ktilde] = 1` and `K = [K,K]`. Then `[Ktilde,Ktilde]` maps onto
  `[K,K] = K`, with kernel `[Ktilde,Ktilde] ∩ <t> = 1`. So it is a complement of `<t>`, and it is
  normal. The extension splits.

**Perfectness of the w20 kernels.** Suppose `K` is Kazhdan with no nontrivial finite quotient.
`K^{ab}` is a finitely generated abelian group with (T), hence finite. It is a finite quotient
of `K`, hence trivial.

## Remarks

- **(R1) What is used.** Only operator-norm continuity of `Tr log`, Schur's lemma, and the
  definition of LEF. No Kazhdan, soficity or torsion hypothesis is used, and no citation beyond
  standard facts.
- **(R2) General form, and the MF weakening.** Steps 2, 3 and 5 use only this: some asymptotic
  representation `(b_i)` of `K` has `W_zhat(b_i) ≠ 0` for infinitely many `i`. Any such sequence
  refutes (LS) for `R = {zhat}`. The LEF hypothesis (i) is one way to produce it.
  - It is open whether an MF model of `Ktilde` produces one.
  - An MF model need not send `t` to scalars.
  - Cutting down to spectral subspaces of the image of `t` needs an operator-norm conditional
    expectation, which (T) does not supply.
- **(R3) Torsion classes are invisible.** For perfect `K`, `H^2(K;Z) = Hom(H_2(K;Z), Z)`. A
  nonsplit `Z`-extension exists exactly when this group is nonzero. Finite central extensions
  give scalars of bounded order, which do not tend to `1`. So (WK) says nothing about perfect
  `K` with `Hom(H_2(K;Z), Z) = 0`.

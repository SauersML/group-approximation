**ESTABLISHED** (lane proof, short corollaries of `leavitt-stabilization-kernels-are-one-step`
and `leavitt-surjective-k2-stability-implies-injective`, plus the classical extra-index
lemma proved inline; not reviewed; no novelty claimed).

## Statement

Let `R` be a unital ring with a Leavitt pair, `N >= 3`, `j = j_N : St_N(R) -> St_(N+1)(R)`,
`U_N = ker j_N`. For an index `i` let `St_N^(î)` be the subgroup generated by the `X_ab(r)`
with `a, b ≠ i`. For an index `i` and an idempotent `p`, let `H_p^(i)` be the subgroup
generated by the `X_ab(r)` with `a, b ≠ i`, the `X_ai(r)` with `r ∈ Rp`, and the `X_ib(r)`
with `r ∈ pR` (so `H_p^(N) = H_p` of the cited node).

1. **Extra-index lemma (classical).** For every ring and `n >= 2`, `j_n(K_2(n,R))` is central
   in `St_(n+1)(R)`.
2. **Halving corners at every index.** For every Leavitt pair `(g, h)` in `R` (`g*g = h*h = 1`,
   `g*h = h*g = 0`, `gg* + hh* = 1`) and every index `i`: `U_N ∩ H_(gg*)^(i) = 1`.
3. **Index-deleted subgroups.** If `N >= 4`, then `U_N ∩ St_N^(î) = 1` for every `i`.
4. **Symbols.** If `N >= 4`, every product of unstable symbols `{u,v}_N = [h_12(u), h_13(v)]`
   (`u, v` commuting units) is central in `St_N(R)` and is trivial iff its image in `K_2(R)`
   is trivial.

So a nontrivial element of `U_N` (if any exists) is never supported on `N - 1` indices, and
no word representing it has, at any index, all its row and column coefficients inside one
half `gg*` of a Leavitt pair. For `R_L`, part 4 recovers that the rational symbols
`{λ, N+1}_N` form a central subgroup `≅ Q^x` of `St_N(R_L)` (`N >= 4`), matching the section
`S` of `leavitt-surjective-k2-stability-implies-injective`; and `St_N(R_L)/C` is not finitely
presented for any central `C ⊇ S`, by the group lemma of
`leavitt-scalar-commutators-block-fp-central-quotients` (part 0), since `St_N(R_L)` is perfect.

## Proof

*Part 1.* Let `P = ⟨X_(a,n+1)(r) : a <= n⟩ <= St_(n+1)(R)`. The generators commute pairwise, so
`v ↦ Π_a X_(a,n+1)(v_a)` is a homomorphism `R^n -> P` onto `P`. For `a ≠ b <= n`, the Steinberg
relations give `X_ab(s) X_(b,n+1)(r) X_ab(-s) = X_(a,n+1)(sr) X_(b,n+1)(r)` and
`X_ab(s)` commutes with `X_(c,n+1)(r)` for `c ≠ b`. So `j_n(y)` acts on `P` through the image
`g` of `y` in `E_n(R)`, by `v ↦ g v`. For `k ∈ K_2(n,R)`, `g = 1`, so `j_n(k)` centralizes `P`;
symmetrically it centralizes `Q = ⟨X_(n+1,a)(r)⟩`. Since `X_ab(r) = [X_(a,n+1)(r), X_(n+1,b)(1)]`
for `a ≠ b <= n`, `P ∪ Q` generates `St_(n+1)(R)`, and `j_n(k)` is central.

*Part 2.* `U_N = ker j_N` does not depend on the Leavitt pair, and it is normal. The cited
node, item 1, applied to the pair `(g, h)` gives `U_N ∩ H_(gg*) = 1` at the last index.
For another index `i`, conjugate by a lift `w ∈ St_N(R)` of a signed permutation matrix
moving `N` to `i` (products of `w_ab(1) = X_ab(1) X_ba(-1) X_ab(1)`); this carries `H_(gg*)`
onto `H_(gg*)^(i)` up to signs of coefficients, and fixes `U_N` setwise.

*Part 3.* By symmetry (conjugating as in part 2) take `i = N`, so `St_N^(N̂) = j_(N-1)(St_(N-1)(R))`.
If `k = j_(N-1)(y) ∈ U_N`, then `y ∈ K_2(N-1, R)` (as `E_(N-1)(R) -> E_N(R)` is injective) and `y`
has trivial stable image, so `y ∈ U_(N-1) = ker j_(N-1)` by the one-step node (valid since
`N - 1 >= 3`). Hence `k = 1`.

*Part 4.* Each `{u,v}_N` involves only indices `1, 2, 3 <= N - 1`, so it is `j_(N-1)` of the same
symbol in `St_(N-1)(R)`, which lies in `K_2(N-1, R)`; by part 1 it is central. A product `σ` of
such symbols also lies in `St_N^(N̂)`, and if its stable image is trivial then `σ ∈ U_N`, so
`σ = 1` by part 3.

For the last sentence: `S` is central, contained in `[St_N, St_N] = St_N` (perfect for
`N >= 3`), and `≅ Q^x` is not finitely generated.

The first prerequisite gives `c ebar b = 1` in `F_3[PG]`, and `(ebar b) c != 1` because
`ebar != 1`. So `F_3[PG]` is not directly finite. By the second prerequisite, `PG`
is not `F`-linear sofic for any field `F` containing `F_3`. With `F = F_3` this is a
group that is not linear sofic over some field.

The failure localizes. The subgroup generated by the supports of `b`, `c` and
`wbar` already has a non-directly-finite group algebra over `F_3`, so it is a finitely
generated non-`F_3`-linear-sofic subgroup.

*Verified independently by `gk-vf-linear` (2026-09-12): the extension to fields containing `F_3` and the localization to the subgroup generated by the supports both hold. See Section 3 of the linear-family verification artifact.*

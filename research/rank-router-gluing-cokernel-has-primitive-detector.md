**OPEN.**  Assume `pointed-router-local-section-system`.  Form the finite
abelian group/lattice of overlap coordinates for its local router sections.
Let `C0` be the integral lattice of local source-gauge choices and `C1` the
integral lattice generated by all overlap rank and mixed-moment discrepancies;
let

```text
d:C0 -> C1                                                   (RGC1)
```

be the change-of-section map.  After quotienting torsion-free redundant
coordinates, the residual gluing module

```text
Q_glue = C1 / d(C0)                                          (RGC2)
```

has a primitive homomorphism

```text
gamma_glue: Q_glue -> Z                                     (RGC3)
```

with the following properties.

1. **Source zero.**  The local sections induced by the distinguished perfect
   commuting source have gluing class `q_src` with
   `gamma_glue(q_src)=0`.
2. **Completeness on the pointed face.**  For canonical matrix microstates
   satisfying `gamma_glue=o(1)` in normalized coordinates, the overlap class
   is a source-gauge coboundary up to `o(1)`; after applying those local
   gauges, all local sections glue to one common rank-router packet.
3. **Tensor exclusion.**  The exact tensor-closure configuration
   `(HRT1)--(HRT3)` has a class `q_tens` with
   `gamma_glue(q_tens) != 0` after the same normalization.  Thus the zero
   face is not tensor closed.
4. **Finite detectability.**  `gamma_glue` is represented by a fixed finite
   integer linear combination of the available source rank/mixed-moment
   coordinates, so its zero face can be imposed as a finite pointed moment
   condition.

A stronger acceptable outcome is that `Q_glue` itself is cyclic and
`gamma_glue` identifies its free part.  A refutation is equally informative:
if the source and tensor witness have the same class in every such finite
quotient, then no pointed face built from the present rank/moment vocabulary
can solve `source-specific-pointed-rank-router-face`.

This is deliberately a quotient by **local source gauge**, not by all exact
ordinary-group representations.  Quotienting by the latter would erase the
tensor witness and recreate the categorical no-go.

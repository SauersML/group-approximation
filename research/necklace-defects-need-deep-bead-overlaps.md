**ESTABLISHED.** The setting is that of `infranormal-kernel-sources-die-in-sofic-mapping-tori`:
- `G` is a countable sofic group, `K` is normal in `G` with `G/K = Z`, and `s in G` has degree 1;
- `K` is a nontrivial Kazhdan group;
- `L <= K` is a Kazhdan subgroup that is infranormal in `K`;
- `N = <<L>>^K`, `A_j = s^j N s^-j` (normal in `K`), and `D_G(L)` is the intrinsic defect (ICD1).

Suppose `D_G(L) = K`. By that node a strict compressor exists. After replacing `s` by `s^-1`,
every strict degree is positive. Let `P` be the semigroup the strict degrees generate, and let
`g = gcd P`; that node proves `g >= 2`. For `M in Z` put

```text
B_M = A_(Mg+1) A_(Mg+2) ... A_(Mg+g-1),        E_M = N ∩ B_M.        (deep beads, overlap)
```

Then:

1. **(NB1) Bead factorization.** `K = A_(j_0) A_(j_1) ... A_(j_(g-1))` for every choice of integers
   with `j_rho = rho (mod g)`.
2. **(NB2) Central core.** `A_(Jg) ∩ A_(Jg+1) ∩ ... ∩ A_(Jg+g-1) <= Z(K)` for every `J`.
3. **(NB3) Deep-overlap generation.** For every `M`, every nontrivial defect generator
   `[u c u^-1, l]` is a `K`-conjugate of `[x, e]` with `x in G` and `e in E_M`. Hence

   ```text
   K = D_G(L) = <<E_M>>^G     for every M in Z,        and   N/E_M = K/B_M.
   ```

4. **(NB4) Amenable-overlap kill.** If for some `M` the overlap `E_M` lies in the amenable
   radical of `K`, then `D_G(L) = K` is impossible. Two cases:
   - **Two beads.** If `g = 2`, then `E_0 = A_0 ∩ A_1` is central by (NB2), so every necklace
     with two beads dies.
   - **Commuting beads.** If for some `M` and every `1 <= rho <= g-1` the commutator
     `[N, A_(Mg+rho)]` lies in `Z(K)`, then `E_M <= Z_2(K)`. In particular this holds when all
     these pairwise intersections `N ∩ A_(Mg+rho)` are central.

**Corollary (kill).** In a sofic mapping torus `G = K semidirectProduct Z` of a Kazhdan kernel, a
Kazhdan source infranormal in `K` has `D_G(L) != K` in each of these cases:
- `K` has a unique maximal normal subgroup (the parent node);
- the strict degree gcd is 1 (the parent node);
- the strict degree gcd is 2 (new);
- some deep overlap `E_M` is amenable, for example central or contained in `Z_2(K)` (new).

None of this uses torsion-freeness, finite presentation or the absence of finite quotients.
Soficity enters only through the root normalization (IS0) of the parent node.

## What this kills

- **(EK1) and (SCZ1), infranormal sources, two-bead necklaces.**
  `torsion-free-sofic-extrinsic-kazhdan-defect-kernel` and
  `split-cyclic-kazhdan-defect-exact-mf-radical`. A witness with an infranormal source now needs
  all of the following:
  - at least three beads, `g >= 3`;
  - for every `M`, a non-amenable deep overlap `E_M = N ∩ B_M` whose normal closure in `G` is the
    whole of `K`;
  - for every `M`, some `rho` with `[N, A_(Mg+rho)]` not central.
  The killed class includes every "swap two halves of the kernel" design with `g = 2`: for
  example, `K` a central product of two copies of a Kazhdan group exchanged by `s`, with `s^2`
  strictly compressing one half.
- **Invariant.** The overlap `E_M` of the source closure `N` with the deep other beads `B_M`. Its
  normal closure `<<E_M>>^G` is an upper bound for the defect.
- **Step where every member dies.** Split `l = a e` with `a in A_m` and `e in E_M`, using (NB1)
  with the index `m = deg u` in the zero residue class. The root `x = u c u^-1` centralizes
  `A_m`, so `[x, l] = a [x, e] a^-1`. An amenable characteristic overlap then traps the defect in
  the amenable radical of `K`. A Kazhdan group equal to its amenable radical is finite, and a
  finite `N` cannot be strictly compressed.

## Calibration: (NB3) bites beyond the central tests

Let `H` be an infinite Kazhdan group and `phi in Aut(H)`. Let `N_0` be normal in `H` with
`phi(N_0) < N_0`. Take `K = H x H x H` with `s(h_0,h_1,h_2) = (phi h_2, h_0, h_1)`, so
`s^3 = phi x phi x phi`. Take a source with `N = N_0 x H x 1`, in a sofic `G`. Then:
- `A_1 = 1 x N_0 x H` and `A_2 = H x 1 x N_0`;
- the strict degrees are multiples of 3; assume one equals 3 (for example when `s^3`
  compresses `L`), so `g = 3`;
- (NB1) holds, and `A_0 ∩ A_1 ∩ A_2 = 1`, so (NB2) holds;
- the pairwise intersection `N ∩ A_2 = N_0 x 1 x 1` is not central when `N_0` is noncentral.

When `N_0` is non-amenable and not in `Z_2(H)`, this is a three-bead configuration that every
test of (NB4) misses. But `E_M = N_0 x phi^M N_0 x 1`. Its normal closure in `G` lies in `(H^+)^3`, where
`H^+ = union_k phi^-k (N_0)`, and `H^+` is proper because `H` is finitely generated. So (NB3)
fails, and `D_G(L) != K` for every such source.

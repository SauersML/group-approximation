Notation as in the target. `S` is a finite symmetric generating set of `G`. Lane proof by bh-q14-lift, not
independently reviewed.

**Refining tables.** If `f(u w) = v h(w)` on `C_u` with `h ∈ Aut(X^*)`, then on each `C_{ux}` (`x ∈ X`)
`f(ux w) = v h(x) · h|_x(w)`. So any table of `f` refines to finer cone partitions, and the entries of the
refinements are sections `h|_y` of the original entries. The inverse `f^{-1}` is the table
`v_i w ↦ u_i h_i^{-1}(w)`.

**Item 1 (`H_G` is finitely generated and finite-state).**
- Fix a table for each `s ∈ S`. Its entries are finitely many finite-state automorphisms.
- Let `T` be the closure of these entries under sections and inverses. It is finite: a finite-state
  automorphism has finitely many sections, and `(h^{-1})|_x = (h|_{h^{-1}(x)})^{-1}`.
- By the refinement remark, every table entry of every `s ∈ S`, at every refinement, lies in `T`.
- **Products.** Given tables of `g` and `k`, refine the table of `k` so that each image cone `C_{v}` lies
  inside a cone of `g`'s table. On `C_u` the product `gk` then acts by `(g`'s entry, sectioned at the
  appropriate word`)·(k`'s entry`)`. So table entries of products are products of sections of entries, and
  every table entry of every element of `G` lies in `⟨T⟩`.
- Conversely `T` consists of table entries. Hence `H_G = ⟨T⟩`, a finitely generated self-similar group of
  finite-state automorphisms, generated by the finite section- and inverse-closed set `T`.

**Item 2, first inclusion (`[[G]] ≤ V_d(H_G)`).**
- Each `s ∈ S` is a table over `T`. The tables over a self-similar group form a group, by the product
  computation above. So `G ≤ V_d(H_G)`.
- **`V_d(H_G)` is full.** Let `f` be a homeomorphism locally agreeing with `V_d(H_G)`.
  - By compactness there are a finite clopen partition `{P_j}` and `f_j ∈ V_d(H_G)` with `f = f_j` on `P_j`.
  - Refine to a cone partition `{C_{u_i}}` such that each `C_{u_i}` lies in one `P_j`, and inside one cone of
    a table of that `f_j`. Then `f(u_i w) = v_i h_i(w)` with `h_i ∈ H_G`, a section of an entry of `f_j`.
  - The cones `C_{v_i}` are the images of a partition under a bijection, so they partition `X^ω`. Hence `f` is
    a table over `H_G`, and `f ∈ V_d(H_G)`.
- So `[[G]] ≤ V_d(H_G)`.

**Item 2, second inclusion (`V_d(H_G) ≤ [[G]]`).**
- **`V_d ≤ [[G]]`.** Take `c ∈ V_d` with table `(u_i → v_i, 1)`. If the partition is `{C_∅}`, then `c = 1`.
  Otherwise every `u_i` and `v_i` is nonempty, so `C_{u_i}` and `C_{v_i}` are proper cones. The RSG property
  gives `g_i ∈ G` mapping `C_{u_i}` to `C_{v_i}` by the canonical similarity, which is `c` on `C_{u_i}`. So `c`
  locally agrees with `G`, and `c ∈ [[G]]`.
- **Cone copies.** For `h ∈ T` and a nonempty word `w`, let `L_w(h)` act as `w x ↦ w h(x)` on `C_w` and as the
  identity elsewhere.
  - Choose `s ∈ S` and a refined table entry `(u → v, h)` of `s`, with `u, v` nonempty; refine once if
    necessary.
  - Choose `a, b ∈ V_d` with `a = ` the canonical similarity `C_w → C_u` on `C_w`, and `b = ` the canonical
    similarity `C_v → C_w` on `C_v`. These exist because `u`, `v`, `w` are nonempty.
  - Then `b s a` agrees with `L_w(h)` on `C_w`: `w x ↦ u x ↦ v h(x) ↦ w h(x)`. Off `C_w`, `L_w(h)` is the
    identity. So `L_w(h)` locally agrees with `[[G]]`, hence with `G`, and `L_w(h) ∈ [[G]]`.
  - `L_w` is a homomorphism on `H_G`, so `L_w(H_G) ≤ [[G]]`.
- **Every table.** A table over `H_G` with partition `{C_{u_i}}` (refined once if it is `{C_∅}`) equals
  `c · ∏_i L_{u_i}(h_i)`, where `c ∈ V_d` has table `(u_i → v_i, 1)`. The factors `L_{u_i}(h_i)` have disjoint
  supports and commute. So `V_d(H_G) ≤ [[G]]`.

**Item 3.** `H_G` is a finite-state self-similar group generated by the finite set `T`, which is closed under
sections and inverses. That is exactly the setting of Theorem A in `rover-nekrashevych-fp-iff-finite-lift-presentation`,
with `S := T`. So `V_d(H_G) = [[G]]` is finitely presented iff the relator kernel `N = ker(F(T) → H_G)` is
`⟨⟨R⟩⟩_lift` for a finite `R`. By Theorem A's Consequence 3 the condition does not depend on the finite
self-similar generating set.

**The characterization.** If `G` is full, then `G = [[G]] = V_d(H_G)`. Conversely, `V_d(H)` for a finitely
generated finite-state self-similar `H` is a full locally synchronous RSG. It is full by the fullness step,
and an RSG because `V_d ≤ V_d(H)`.

**Consequences.** These follow directly from item 3 and the Consequences list of Theorem A, whose items 1 and 2
give the Scott, Nekrashevych and `K_∞` cases. The counterexample dichotomy is the contrapositive of item 3,
restricted to finitely presented `G`.

**Setup.** Let `Q = (A * B)/<<ab>>` and let `π: A * B -> Q` be the quotient map.

1. **`π(a) = 1`.**
   - Since `π(ab) = 1`, we have `π(a) = π(b)^{-1}`.
   - `π(a)^m = π(a^m) = 1`.
   - `π(a)^n = π(b)^{-n} = π(b^n)^{-1} = 1`.
   - Choose integers `r, s` with `rm + sn = 1`. Then
     `π(a) = π(a)^{rm+sn} = (π(a)^m)^r (π(a)^n)^s = 1`.

   So `π(a) = 1`, and hence `π(b) = π(a)^{-1} = 1`.

2. **`π` kills `A`.** The restriction `π|_A: A -> Q` is a homomorphism. Its kernel
   is normal in `A` and contains `a`, so it contains `<<a>>_A = A`. Thus
   `π(A) = 1`, and in the same way `π(B) = 1`.

3. **`Q` is trivial.** `A * B` is generated by `A ∪ B`, so `Q` is generated by
   `π(A) ∪ π(B) = {1}`. Hence `Q = 1`, which says `<<ab>> = A * B`.

If `A` or `B` is nontrivial, then `A * B` is nontrivial and has normal rank at
least 1, so the normal rank is exactly 1. ∎

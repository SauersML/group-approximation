**Conventions.**
- `W_d` is a tower as in the theorem, acting on a rooted tree with root label group `T = T_1`.
- `H` is the subtree group at a child, a tower of depth `d - 1`, and `W_d = H^m ⋊ T` with
  `(f; p)(g; q) = (f p(g); pq)` and `p(g)_i = g_(p^-1 i)`.
- `c = c(m)` bounds the commutator width of every tower with vertex degrees `<= m`.
- A *letter* is `C r(a)^(+-1) C^-1` with `C in W_d`, and a block is *balanced* if it is a product of
  pairs `(r, r^-1)`.

**The template.** For each `x`,
```text
T_x  =  prod_r r^(n_(x,r))  ·  prod_(r in R) [ (r r^-1)^(|T|) (r r^-1)^(m-1) (r r^-1)^(2c) ] ,
```
with `|T| <= m!`. We show that every `a_x` is a value of `T_x` with conjugators in `W_d`.

## 1. Reduction to root-acting tuples

Let `j_0` be the least level at which `<a>` acts nontrivially. If there is none, `a = 1`, and all
conjugators `1` give `1`.
- *Relators act at the same level.* If every `r(a)` fixed level `j_0` pointwise, the images of `a` in the
  finite quotient acting on levels `<= j_0` would satisfy all relators. They would define a
  homomorphism from `G`, hence be trivial, and `<a>` would fix level `j_0`.
- *Product structure.* `a` lies in the stabilizer of level `j_0 - 1`, which is the direct product of the
  subtree groups `W(v)`, `v in Omega_(j_0 - 1)`. Relator values restrict: `r(a)^(v) = r(a^(v))`.
- *Coordinatewise.* Choose conjugators coordinatewise inside each `W(v)`. The exponent block evaluates
  coordinatewise. A coordinate with `a^(v) = 1` takes all conjugators `1`, and each balanced pair cancels.
- *Recursion.* Apply this reduction again to each coordinate `a^(v)`, a tuple in a tower of smaller depth.
  By induction on depth, it suffices to realize `T_x` for a tuple `a` in a tower `W = H^m ⋊ T` whose
  root tuple `p` is nontrivial.

## 2. Root-acting tuples

Some `r* in R` has `tau := r*(p) != 1`, since otherwise `p` defines a homomorphism `G -> T`. For every
`r != r*`, take all conjugators in its blocks equal pairwise, so those blocks are `1`.

**Exponent block.** `A = prod_r r(a)^(n_(x,r))`. Put `y = A^-1 a_x`, with root label `y_0 in T`.

**Top block.** Let `C = tau^T`.
- `C C^-1` contains `1`. `S_j = (C C^-1)^j` increases with `j`, and its union is the subgroup generated by
  `C C^-1`. That subgroup is normal and nontrivial, because `|C| >= 2` in the centerless group `T`. So
  it is `T`.
- The chain stabilizes after at most `|T|` steps, so `(C C^-1)^(|T|) = T`.
- Choose `pi_j in T` so that the root labels of the letters `(1; pi_j) r*(a)^(+-1) (1; pi_j)^-1` multiply
  to `y_0`. Let `e` be the inverse of the block's value times `y`. Then `e in H^m`.

**Dipole lemma** (as in `simple-nonsofic-width-over-bounded-base-symmetric-wreath-proof`). If a letter
has value `(g; sigma)` with `sigma(i) != i`, then
```text
[(k at i; 1), (g; sigma)]  =  (k at i,  g_(sigma i) k^-1 g_(sigma i)^-1 at sigma(i); 1) ,
```
and this is a letter followed by a letter of the opposite sign.

**Dipole block.**
- *The graph.* `Gamma` has vertex set `[m]` and edges `{i, sigma(i)}`, `sigma in C`.
  - It is `T`-invariant, so its components form a block system for `T`.
  - Each `sigma in C` maps every vertex into its own component, so it stabilizes each component. So does
    the subgroup generated by `C`, which is `T`.
  - `T` is transitive, so `Gamma` is connected.
- *The spanning tree.* Fix a spanning tree with root `i_0`, and for each tree edge `{i, i'}` a `pi in T` with
  `pi tau pi^-1` mapping one endpoint to the other.
- *The block.* The block is `m - 1` commutators as in the lemma, one per edge, with parameter `k_edge`.
- *Solving.* Strip leaves: when a non-root vertex `i` has a single unsolved incident edge, the equation
  at coordinate `i` reads `known · (bijective function of k_edge) · known`, so it determines `k_edge`.
- *The defect.* At the end, `e = D_1 ... D_(m-1) · (z at i_0)` for a unique `z in H`.

**Defect block.**
- *Commutators.* `H` is a tower, hence perfect (`iterated-simple-wreath-bounded-commutator-width`), so
  `z = prod_(t <= c) [k_t, l_t]`.
- *Four letters each.* Choose a letter `L = (1; pi) r*(a) (1; pi)^-1` whose root label moves `i_0`. With
  `u = [(k at i_0; 1), L]`, the lemma gives `u = (k at i_0, k' at sigma(i_0); 1)`. So
  `[u, (l at i_0; 1)] = ([k, l] at i_0; 1)`. Its value is `u · ((l at i_0) u^-1 (l at i_0)^-1)`, four
  letters with signs `+, -, +, -`.
- *The block.* `4c = 2 · 2c` letters realize `(z at i_0)`.

**Assembly.** `a_x = A · (top block) · D_1 ... D_(m-1) · (defect block)`. The letter count is
`sum_r |n_(x,r)| + 2|T| + 2(m - 1) + 4c`. Padding the other relators' blocks gives the bound stated on
the claim.

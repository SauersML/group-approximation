The notation is that of [[monomial-twisted-level-subpairs-cannot-certify-rank-three]].

Conventions:

- `[A, B] = A B A^-1 B^-1`.
- An element of `G` is written `(u, σ)` with `u ∈ EL_3(R)` and `σ ∈ SL_d(Z)`.  The product is
  `(u, σ)(u', σ') = (u σ̂(u'), σ σ')`, so `(u, σ) (g, 1) (u, σ)^-1 = (u σ̂(g) u^-1, 1)`.
- `e_ij(t) = 1 + t E_ij`, where `E_ij` is the matrix unit.
- Two elementary identities are used throughout: `e_ij(s) e_ij(t) = e_ij(s + t)`, and for distinct
  `i, j, l`, `[e_ij(s), e_jl(t)] = e_il(s t)`.
- `U_k = E_3(J_k)` is generated by the `e_ab(t)` with `t ∈ J_k = (x^m : m ∈ N^d, |m| ≥ k) ⊆ R_+`.  It is
  also generated by the `e_ab(α x^m)` with `|m| ≥ k`.

## 1. The loop identity

**Lemma 1.1.**  Let `u ∈ SL_3(R)`, let `x, y, z` be the three indices in some order, and suppose

```text
(u^-1)_(yx) = (u^-1)_(zx) = 0   and   (u^-1)_(yz) = 0 .                                      (*)
```

Then for all `β, t, t' ∈ R`,

```text
[[ e_xy(β), u e_yz(t) u^-1 ], u e_zy(t') u^-1 ]  =  e_xy( β t t' · (u^-1)_(xx) u_(yy) · u_(xx) (u^-1)_(yy) ) .
```

*Proof.*  Conjugation by `u` is an automorphism, so the left side equals `u [[M, e_yz(t)], e_zy(t')] u^-1`
with `M = u^-1 e_xy(β) u = 1 + β p q^T`.  Here `p = u^-1 e_x` is column `x` of `u^-1`, and `q^T = e_y^T u` is
row `y` of `u`.

- By (*), `p = p_x e_x` with `p_x = (u^-1)_(xx)`.  So `q^T p = (u u^-1)_(yx) = 0` and
  `M^-1 = 1 - β p q^T`.
- `M e_y = e_y + β p_x u_(yy) e_x`, and `e_z^T M^-1 = e_z^T`, because `e_z^T p = 0`.
- Hence `M e_yz(t) M^-1 = 1 + t (M e_y)(e_z^T M^-1) = e_yz(t) e_xz(t β p_x u_(yy))`.  The two factors commute,
  since `E_yz E_xz = E_xz E_yz = 0`.
- So `[M, e_yz(t)] = e_xz(s)` with `s = β t p_x u_(yy)`, and `[e_xz(s), e_zy(t')] = e_xy(s t')`.

It remains to conjugate back:

```text
u e_xy(r) u^-1 = 1 + r (u e_x)(e_y^T u^-1) .
```

- The first condition of (*) says that column `x` of `u^-1` is a multiple of `e_x`.  Equivalently, `u e_x`
  is a multiple of `e_x`, namely `u_(xx) e_x`.
- With `(u^-1)_(yx) = (u^-1)_(yz) = 0`, row `y` of `u^-1` is `(u^-1)_(yy) e_y^T`.

So `u e_xy(r) u^-1 = e_xy(r u_(xx) (u^-1)_(yy))`, which is the claim.  ∎

**Corollary 1.2 (monomial twists).**  Let `c = (u, σ) ∈ G` with `u = D π` monomial, where `π e_a = e_(πa)` is
a permutation matrix and `D = diag(d_1, d_2, d_3)` has monomial unit entries.  Let `a = π^-1 y` and
`b = π^-1 z`.  Then

```text
[[ e_xy(β), c e_ab(t) c^-1 ], c e_ba(t') c^-1 ]  =  e_xy( β σ̂(t) σ̂(t') ) ,
```

and in particular `e_xy(β x^(σ(m + m')))` for `t = x^m`, `t' = x^(m')`.

*Proof.*  `c e_ab(t) c^-1 = D π e_ab(σ̂ t) π^-1 D^-1 = e_yz(d_y d_z^-1 σ̂ t)`, and similarly
`c e_ba(t') c^-1 = e_zy(d_z d_y^-1 σ̂ t')`.  Apply Lemma 1.1 with `u = 1`, which trivially satisfies (*).
The product of the two twist factors is `1`.  ∎

This is check (A) of the script, with random signed monomial `u`, random `σ` and random exponents.  The
direct computation `[e_xy(β), e_yz(λ s)] = e_xz(β λ s)` and `[e_xz(β λ s), e_zy(λ^-1 s')] = e_xy(β s s')` is the
whole mechanism: the twist `λ = d_y / d_z` is a function on the edge `y → z`, and the loop `y → z → y`
multiplies it by its reverse.

**Corollary 1.3 (Borel twists).**  Order the indices `y < z < x`.  Let `u` be lower triangular for this order,
meaning `u_(ij) = 0` whenever `i` precedes `j`, with monomial unit diagonal.  Then `u^-1` is lower triangular
too, so (*) holds for `(x, y, z)`.  Since `(u^-1)_(xx) = u_(xx)^-1` and `(u^-1)_(yy) = u_(yy)^-1`, the factor
in Lemma 1.1 is `1`.  So for `c = (u, σ)`:

```text
[[ e_xy(β), c e_yz(t) c^-1 ], c e_zy(t') c^-1 ]  =  e_xy( β σ̂(t) σ̂(t') ) .
```

Now take another ordered pair `(x', y') ≠ (x, y)`, with third index `z'`.  Then (*) for `(x', y', z')`
requires a zero at `(u^-1)_(y'x')`, `(u^-1)_(z'x')` and `(u^-1)_(y'z')`.  If `x'` is not last in the order,
some index `i` follows `x'`.  If `x'` is last but `y'` is not first, then `y' = z` and `z' = y`.  For a
generic lower-triangular `u` all subdiagonal entries of `u^-1` are nonzero, so (*) fails in both cases.
Script check (C) takes `u = [[1,0,0],[f,1,0],[x_3^-1, f^2, 1]]` with `f = x_1^-1 + x_2^-2` and
`σ = e_12(1)`.  It confirms that the double commutator is elementary for `(x, y) = (3, 1)` only.

## 2. Walking to a constant: proof of (T1)

**`H_mon(B)` is a subgroup.**  `N` is a group, and `σ̂(N) = N` because `σ̂` maps monomial units to monomial
units.  If `(D, σ), (D', σ') ∈ B` with `D, D' ∈ N`, then `(D, σ)(D', σ') = (D σ̂(D'), σ σ') ∈ B` and
`(D, σ)^-1 = (σ̂^-1(D^-1), σ^-1) ∈ B`, with both twists in `N`.  (A monomial matrix of determinant `1` lies in
`EL_3(R)`, by the Whitehead lemma and the signed permutation matrices of determinant `1`.)

**The relation.**  Suppose `K0(H_mon)` contains a line `R v`, `v ≠ 0`.  Then `v` and `-v` are nonnegative
combinations of vectors `h e_i`, `h ∈ H_mon`.  Adding the two expressions gives a nontrivial vanishing
nonnegative combination.  The vectors are integral, so the combination may be taken rational, and after
clearing denominators, with integer coefficients.  Repeat each term according to its coefficient:

```text
σ_1 e_(i_1) + σ_2 e_(i_2) + ... + σ_J e_(i_J) = 0 ,     σ_j ∈ H_mon ,  J ≥ 2 .
```

Apply `σ_1^-1` and put `τ_j = σ_1^-1 σ_j ∈ H_mon` and `l_j = i_j`:

```text
e_(i_1) + Σ_(j=2..J) τ_j e_(l_j) = 0 .                                                       (R)
```

**The walk.**  Fix an ordered pair `(x, y)` with third index `z`, and `α ∈ F_q`.

- For each `j`, pick `c_j = (D_j π_j, τ_j) ∈ B` with a monomial twist, and put `a_j = π_j^-1 y` and
  `b_j = π_j^-1 z`.
- Start with `g_1 = e_xy(α x^(2k e_(i_1)))`.  It lies in `U_k ≤ B`, because `|2k e_(i_1)| = 2k ≥ k`.
- For `j = 2, .., J`, set

  ```text
  g_j = [[ g_(j-1), c_j e_(a_j b_j)(x^(k e_(l_j))) c_j^-1 ], c_j e_(b_j a_j)(x^(k e_(l_j))) c_j^-1 ] .
  ```

  The inner elements `e_(a_j b_j)(x^(k e_(l_j)))` and `e_(b_j a_j)(x^(k e_(l_j)))` lie in `U_k`.  So all
  entries of the double commutator lie in `B`.

By Corollary 1.2 and induction, `g_j = e_xy(α x^(p_j))`, where `p_j = 2k e_(i_1) + Σ_(2 ≤ j' ≤ j) τ_(j') (2k e_(l_(j')))`.
By (R), `p_J = 0`, so `e_xy(α) = g_J ∈ B`.  This holds even though the intermediate exponents `p_j` need not
lie in `N^d`: the identity of Corollary 1.2 holds over the Laurent ring.  Since `e_xy(α) ∈ SL_3(F_q) ≤ Gamma`,
we get `e_xy(α) ∈ C`.

**Conclusion.**  The `e_xy(α)` generate `SL_3(F_q)`, which `psi = ev_0` maps onto `F = PSL_3(F_q)`.  So
`psi(C) = F` and `C_F(psi(C)) = Z(F) = 1`.  This proves (T1).

The same walk runs under Corollary 1.3 when all the `c_j` have lower-triangular twists for a fixed order
`y < z < x`, with `a_j = y` and `b_j = z`.  The lower-triangular matrices with monomial unit diagonal form a
`σ̂`-invariant group, so the lifts of `τ_j = σ_1^-1 σ_j` are again of this kind.  This gives `e_xy(α) ∈ C`,
the first statement of (T5).

Script check (B) runs this recipe for `d = 3`, `k = 1` and `H = SL_3(Z)`.  The generators are lifted with a
diagonal twist `u_1` and a twisted signed permutation `u_2`.  The composite `c_τ = c_12 c_21^-1` lifts
`τ = e_12(1) e_21(-1)`, and `τ(2 e_1) = -2 e_2`.  So (R) reads `e_2 + τ e_1 = 0`, and one loop with `m = m' = e_1` walks `e_xy(x_2^2)` to `e_xy(1)`.  The script
confirms this for all six ordered pairs.

## 3. Finite index does not change the cone: proof of (T2)

Let `H ≤ GL_d(Z)` be generated by `H_+ = H ∩ M_d(N)`, and let `H' ≤ H` have finite index.  Here `K0` is the
convex cone `cone(H · O)` itself, with no closure taken.  `K0(H') ⊆ K0(H)` is clear.

Let `H_0 = ∩_(h ∈ H) h H' h^-1` be the normal core of `H'`.  It is normal and of finite index in `H`, and
`H_0 ≤ H'`.  Put `K' = K0(H_0) ⊆ K0(H')`.

1. `h K' = K'` for `h ∈ H_0`, since `H_0 · O` is `H_0`-stable.
2. Let `g ∈ H_+`.  For `h ∈ H_0`, `g h O = (g h g^-1)(g O) ⊆ (g h g^-1) O ⊆ H_0 O`, since `g O ⊆ O` and
   `g h g^-1 ∈ H_0`.  So `g K' ⊆ K'`.
3. `H / H_0` is finite, so `g^n ∈ H_0` for some `n ≥ 1`.  Then
   `K' = g^n K' ⊆ g^(n-1) K' ⊆ .. ⊆ g K' ⊆ K'`.  All inclusions are equalities, and `g K' = K'`,
   `g^-1 K' = K'`.
4. `H_+` generates `H`, so `h K' = K'` for all `h ∈ H`.  Since `O ⊆ K'`, `h O ⊆ K'`, and `K0(H) ⊆ K'` because
   `K'` is a convex cone.

So `K0(H) = K0(H') = K0(H_0)`.  ∎

*Sharpness.*  Nonnegative generation is needed.  For `H = < A, -1 > ≤ GL_2(Z)` with `A = [[2,1],[1,1]]`,
`K0(H) ⊇ O ∪ -O = R^2`.  The index-2 subgroup `< A >` has `<w, A^n e_i> = λ^n w_i > 0` for the Perron vector
`w = (φ, 1)` of the symmetric `A` and every `n ∈ Z`.  So `K0(< A >) \ 0` lies in the open half-plane
`<w, ·> > 0`, and `K0(< A >)` is salient.  Here `H_+ = { A^n : n ≥ 0 }` does not generate `H`.  Script
check (E) illustrates the lemma on the congruence subgroup `Gamma(2)` of `SL_3(Z) = < e_ij(1) >`.  An LP
finds `-e_1` as a nonnegative combination of columns of words of length `2` in the generators `e_ij(± 2)`,
so `K0(Gamma(2))` already contains the line `R e_1`, as it must.

## 4. Relative levels: proof of (T4)

Put `I = J_(2k)`.  For `n ≥ 3` and any commutative ring `A` with ideal `I`, the relative elementary group
`E_n(A, I)` has the following properties:

- It is the normal closure of `E_n(I)` in `E_n(A)`.
- It is generated by the `z_ij(t, r) = e_ji(r) e_ij(t) e_ji(-r)`, `t ∈ I`, `r ∈ A`.
- It is normal in `GL_n(A)`.

These are due to Suslin and Vaserstein.  For `A = R_+` a polynomial ring over a field, Suslin's theorem
`SL_3(R_+) = E_3(R_+)` gives normality in `Gamma` directly.

So it suffices to show `z_ij(t, r) ∈ U_k` for `t ∈ J_(2k)` and `r ∈ R_+`.

- `t ↦ z_ij(t, r)` is additive, so it is enough to take `t = α x^m` with `|m| ≥ 2k`.
- Split `m = m_1 + m_2` with `|m_1|, |m_2| ≥ k`, and put `b = α x^(m_1)` and `c = x^(m_2)`, both in `J_k`.
- For `l` the third index, the identity

  ```text
  z_ij(b c, r) = [ e_il(b) e_jl(r b),  e_lj(c) e_li(-r c) ]
  ```

  holds.  It is script check (D), symbolically in `b, c, r`.  It is the commutator
  `[1 + b v e_l^T, 1 + c e_l w^T]` with `v = e_i + r e_j` and `w^T = e_j^T - r e_i^T`, where `w^T v = 0`.
- All four factors lie in `U_k`, since `b, r b, c, r c ∈ J_k`.

Hence `U_(2k) ≤ E_3(R_+, J_(2k)) ≤ U_k`.  For `γ ∈ Gamma`, normality gives
`γ^-1 U_(2k) γ ≤ E_3(R_+, J_(2k)) ≤ U_k ≤ B`, so `U_(2k) ≤ γ B γ^-1`.  ∎

## 5. No virtually monomially twisted certificate: proof of (T3)

Let `B ⊇ U_k` be a Kun-Thom certificate, and let `γ ∈ Gamma` be such that `H_mon(B')` has finite index in
`H_B`, where `B' = γ B γ^-1`.

1. *Same projection, same certificate status.*  `γ ∈ EL_3(R)` projects to `1`, so `H_(B') = H_B`.  Also
   `B' ∩ Gamma = γ C γ^-1` and `psi(γ C γ^-1) = psi(γ) psi(C) psi(γ)^-1`.  So
   `C_F(psi(C)) ≠ 1` iff `C_F(psi(B' ∩ Gamma)) ≠ 1`.  By (T4), `B' ⊇ U_(2k)`.
2. *Nonnegative generation.*  `C` is infranormal, so `H_B` is generated by its nonnegative elements, by (X1) of
   [[subring-level-subpairs-cannot-certify-rank-three-cone]].
3. *`H_B` is infinite.*  Otherwise (X2) of the same node makes `C` normal in `B`, contrary to the definition.
4. *A line.*  `B` is Kazhdan, so its quotient `H_B` is Kazhdan and therefore character-free.  By (W2) of
   [[nonneg-generated-kazhdan-groups-have-nonsalient-cones]], `K0(H_B)` contains a line.
5. *Transfer.*  By (T2), with `H = H_B` and `H' = H_mon(B')`, `K0(H_mon(B')) = K0(H_B)` contains a line.
6. *Contradiction.*  (T1), applied to `B' ⊇ U_(2k)`, gives `psi(B' ∩ Gamma) = F`.  Hence `C_F(psi(C)) = 1`,
   and `B` is not a certificate.  ∎

**The listed cases.**

- *Untwisted lifts on a finite-index `H_1 ≤ H_B`.*  `1 ∈ N`, so `H_1 ≤ H_mon(B)`.
- *Diagonal monomial twists* `diag(c_i x^(δ_i(σ)))` on a finite-index subgroup, with `δ` arbitrary.  This
  is not assumed to be a cocycle modulo anything, or bounded.  Each twist is in `N`.
- *Signed permutation times diagonal monomial twists.*  These are in `N`.
- *Twists in a `σ̂`-invariant `W ≤ SL_3(R)` with `[W : W ∩ N] < ∞`.*
  - Let `H_1 ≤ H_B` be the finite-index subgroup of `σ` with a lift `(w, σ) ∈ B`, `w ∈ W`.  It is a subgroup,
    since `W` is `σ̂`-invariant.
  - The lifts form the subgroup `L = B ∩ (W x| SL_d(Z))`.
  - `(W ∩ N) x| SL_d(Z)` has index `[W : W ∩ N]` in `W x| SL_d(Z)`.  The left coset of `(w, σ)` is determined
    by `w (W ∩ N)`, because `σ̂(W ∩ N) = W ∩ N`.
  - So `L ∩ ((W ∩ N) x| SL_d(Z))` has finite index in `L`.  Its image, a finite-index subgroup of `H_1`, lies
    in `H_mon(B)`.
  - Finite `W`, such as `SL_3(F_q)` with trivial `σ̂`-action, are included.
- *Conjugates.*  By step 1, with `B'` in place of `B`.

## 6. Scope

What the loop mechanism needs is (*) for **one** ordered pair `(x, y)` at a time, over a set of lifts whose
projections have a line in their cone.  Monomial twists satisfy (*) for every pair after the relabelling
`a = π^-1 y`, `b = π^-1 z`.  Lower-triangular twists satisfy it only for the lowest root.  A general twist
satisfies it for no pair.

- The first two cases give (T1) and (T5).
- In the general case, `u e_yz(t) u^-1` is a rank-one transvection `1 + t v w^T` along a moving flag.  Its
  commutators with `e_xy(β)` spread over all root groups.

So the remaining certificates are those whose `H_B` has, for every `γ`, only an infinite-index monomially
lifted part.  Among them, those with a finite-index subgroup of lower-triangular lifts for one order already
have `X_xy(F_q) ≤ C`.  The open test is whether such a `C` can also keep `psi(C)` inside `C_F(X_xy)`.

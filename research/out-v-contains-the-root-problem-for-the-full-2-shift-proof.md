**Inputs** (TeX line numbers in the artifact).
- **(BBCO)** Belk--Bleak--Cameron--Olukoya, arXiv:2006.01466.
  - Corollary `cor:mainresult`: `Aut(X_n^Z, σ_n)/<σ_n> ≅ L_n`, with `L_n = O_n ∩ SL_n` (§ "The groups `O_n` and `L_n`").
  - Theorem `Thm:splittingtheorem-Belk` and its proof: `dim(σ_n) = n`. If `n` is not a proper power, `Aut` is the
    internal direct product of `<σ_n>` and `dim^-1(<n>^c)`, and the latter is isomorphic to `L_n`.
  - `O_(n,r) ≅ Out(G_(n,r))`, with `O_(n,n-1) = O_n` (quoted there from BCMNO).
- **(BLR)** `Aut(Σ^Z)` is residually finite. Boyle--Lind--Rudolph 1988, as quoted by Salo, arXiv:2305.17946v2.
- **(Open)** Salo, same paper: whether `Z[1/2]` embeds, and whether an element of infinite order can have roots of
  infinitely many orders, are open. The latter is attributed to Boyle 2008.

**Item 1.** For `n = 2`, `G(2) = <2>` is generated by `dim(σ) = 2`, so `<2>^c = 1`. By (BBCO), `Aut = <σ> × ker(dim)`
and `ker(dim) ≅ L_2`. Here `ker(dim)` is the group of inert automorphisms.

**Item 2.**
- Subgroups of residually finite groups are residually finite, and `(Q,+)` has no nontrivial finite quotient. So
  `Q` does not embed in `Aut`, nor in `L_2`.
- If `D ≅ Q` lies in `O_2`, then `D ∩ L_2` is a residually finite subgroup of `D`, so `D ∩ L_2 != D`.
- `D` contains an element outside `L_2`, which violates the Lipschitz constraint SL3 on some circuit, since
  `L_2 = O_2 ∩ SL_2` and `SL_2` is defined by SL3 alone.

**Item 3.**
- Let `π : Aut -> L_2` be the quotient map, with kernel `<σ>`. If `h^n = g` in `Aut`, then `π(h)^n = π(g)`.
- **`π(g) != 1` when `I` is infinite.** Suppose `π(g) = 1`. Then `g = σ^j` with `j != 0`, since `g` has infinite
  order. Then `dim(h_n)^n = 2^j` in `<2> ≅ Z` for each `n in I`, so `n` divides `j`. That is impossible for infinitely
  many `n`.
- **`Z[1/2]`.** If `E ≅ Z[1/2]` lies in `Aut`, then `E ∩ <σ>` is `0`. Otherwise some `σ^j`, `j != 0`, would have
  `2^k`-th roots in `E` for all `k`, contradicting the divisibility argument above. So `π` is injective on `E`.
  Conversely, `L_2 ≅ ker(dim) ⊂ Aut`.

**Item 4.** This follows from item 3 and the inclusion `L_2 ⊂ O_2`. The "all orders" version is the case `I = N`.

**The periodic-orbit remark.**
- By (BBCO), Proposition after Theorem "periodic orbit representation": every `T in O_2` acts bijectively on prime
  cyclic words, and this action is faithful. So a copy `D` of `Q` acts faithfully on that countable set.
- A finite `D`-invariant set carries an action of `D` through a finite quotient, which is trivial.
- If every orbit were finite, `D` would act trivially. So some orbit is infinite. Each length contains finitely many
  cyclic words, so an infinite orbit contains words of unbounded length.

Notation as in the claim: `X` countably infinite, `Alt_fin(X) <= Gamma <= Sym(X)`,
`Gamma = <g_1, ..., g_k>`, `N = Gamma ∩ FSym(X)`, `Q = Gamma/N`.

## Item 1 (pairs)

`Gamma` is a permutation group, so the action is faithful. `Alt_fin(X)` is
highly transitive on the infinite set `X`: given distinct `x_1..x_n` and
distinct `y_1..y_n`, choose a finite `F` containing all of them with
`|F| >= n + 2`. Some permutation of `F` sends each `x_i` to `y_i`. Composing
with a transposition of two points of `F` outside `{y_i}` makes it even
without changing the values at the `x_i`. So the ordered pairs `(x, x)` form
one orbit and the pairs `(x, y)` with `x ≠ y` form another.

## Item 2 (stabilizers)

**Reduction to `FSym(X) <= Gamma`.**
- Let `tau` be a transposition and put `Gamma' = <Gamma, tau>`.
- Since `FSym(X)` is normal in `Sym(X)` and `FSym(X) = Alt_fin(X) ∪ tau Alt_fin(X)`, we get `Gamma' = Gamma · FSym(X)`, and `[Gamma' : Gamma] <= 2`.
- Hence `Gamma_x = Gamma'_x ∩ Gamma` has index at most 2 in `Gamma'_x`.
- A finite-index subgroup of a finitely generated group is finitely generated (Schreier).
- `Gamma'` is finitely generated. So it suffices to treat `Gamma'`, which contains `FSym(X)`.

From now on `FSym(X) <= Gamma`. Fix `x ∈ X` and put `Y = X \ {x}`.

**Step 1: lifts.**
- For each `i`, let `f_i` be the transposition `(x, g_i x)`, or the identity when `g_i x = x`.
- Put `h_i = f_i g_i`. Then `h_i ∈ Gamma_x`, and `h_i` differs from `g_i` only at the at most two points `y` with `g_i y ∈ {x, g_i x}`.
- Put `H = <h_1, ..., h_k> <= Gamma_x`.

**Step 2: `Gamma_x = <FSym(Y), H>`.**
- `Gamma_x ∩ FSym(X) = FSym(Y)`.
- Let `g ∈ Gamma_x` and let `pi : Gamma → Gamma/FSym(X)` be the quotient map.
- `pi(g)` is a word `w` in the `pi(g_i) = pi(h_i)`. So `g = w(h) f` with `f ∈ FSym(X)`.
- Both `g` and `w(h)` fix `x`, so `f` fixes `x`, i.e. `f ∈ FSym(Y)`.

**Step 3: `H` has finitely many orbits on `X`.**
- Let `𝒢` be the graph on `X` with edges `{y, g_i y}` for all `y ∈ X` and all `i`. Its components are the orbits of `Gamma`. Indeed, a path from `y` to `s_m ⋯ s_1 y` with `s_j ∈ {g_i^{±1}}` uses edges `{z, s z}`, and `{z, g_i^{-1} z} = {w, g_i w}` for `w = g_i^{-1} z`.
- `Gamma ⊇ FSym(X)` is transitive, so `𝒢` is connected.
- Let `𝒢_H` be the graph with edges `{y, h_i y}`. Its components are the `H`-orbits.
- Let `E_0` be the set of edges `{y, g_i y}` with `h_i y ≠ g_i y`. It has at most `2k` elements.
- Every edge of `𝒢` outside `E_0` is an edge of `𝒢_H`.
- Deleting one edge from a graph raises the number of components by at most one. So `𝒢 \ E_0` has at most `1 + 2k` components.
- Each component of `𝒢_H` is a union of components of `𝒢 \ E_0`, so `H` has at most `1 + 2k` orbits on `X`, hence finitely many on `Y`.

**Step 4: finitely many transpositions regenerate `FSym(Y)`.**
- Let `a_1, ..., a_r` represent the `H`-orbits on `Y`, and let `Σ = {h_i^{±1}}`.
- Let `T` be the finite set of transpositions `(a_j, s a_j)` with `s ∈ Σ` and `s a_j ≠ a_j`, together with `(a_1, a_j)` for `2 <= j <= r`.
- `H` fixes `x`, so `T ⊆ FSym(Y) ⊆ Gamma_x`. Put `L = <H, T> <= Gamma_x`.
- For `u ∈ H`, `L` contains `u (a_j, s a_j) u^{-1} = (u a_j, u s a_j)`.
- Let `E` be the set of pairs `{u a_j, u s a_j}` for `u ∈ H` and `s ∈ Σ` with `s a_j ≠ a_j`, together with the pairs `{a_1, a_j}`. The transposition of every pair in `E` lies in `L`.

**`(Y, E)` is connected.**
- Let `b ∈ H a_j` and write `b = t_1 t_2 ⋯ t_m a_j` with `t_l ∈ Σ`.
- Put `p_l = t_1 ⋯ t_l a_j`, so `p_0 = a_j` and `p_m = b`.
- With `u = t_1 ⋯ t_{l-1}`, either `t_l a_j = a_j` and `p_l = p_{l-1}`, or `{p_{l-1}, p_l} = {u a_j, u t_l a_j} ∈ E`.
- So `b` is joined to `a_j`, and `a_j` is joined to `a_1`.

**Edge transpositions of a connected graph generate `FSym` of its vertex set.**
- It is enough to prove this for a finite connected graph, since every finite subset of `Y` lies in a finite connected subgraph: take a union of paths to `a_1`.
- Induct on the number of vertices, using a leaf `l` of a spanning tree with neighbour `p`.
- By induction the edge transpositions give `Sym(V \ {l})`. For every `q ∈ V \ {l, p}` this contains `(q p)`, and `(q p)(l p)(q p) = (l q)`.
- So all transpositions involving `l` are present, and with `Sym(V \ {l})` they give `Sym(V)`.

**Conclusion.** Hence `FSym(Y) <= L`. Also `H <= L`, so `L = Gamma_x` by Step 2, and `Gamma_x` is generated by the finite set `{h_i} ∪ T`. ∎

## Item 3 (type (A))

By items 1 and 2, the action is faithful, has finitely many orbits of pairs and
has finitely generated point stabilizers. So it is of type (A) exactly when
`Gamma` is finitely presented. The consequence for subgroups is Zaremsky's
Corollary B, imported as `type-a-action-gives-boone-higman-for-subgroups`.

## Item 4 (quotient)

**Which subgroup `N` is.**
- `N` is normal in `Gamma` and contains `Alt_fin(X)`.
- Since `[FSym(X) : Alt_fin(X)] = 2`, `N` is `Alt_fin(X)` or `FSym(X)`.

**Normal generators.**
- All 3-cycles are conjugate in `Alt_fin(X)`: two 3-cycles lie in some `Alt(F)` with `|F| >= 5`, where 3-cycles form one class.
- 3-cycles generate `Alt_fin(X)`, so `Alt_fin(X)` is the normal closure of one 3-cycle.
- `FSym(X)` is the normal closure of a 3-cycle and a transposition.

**Conclusion.** A quotient of a finitely presented group by the normal closure of
finitely many elements is finitely presented: add them as relators.

## Item 5 (subgroups)

- For `H <= Gamma`, `H ∩ N` is normal in `H`, and it lies in `FSym(X)`, which is locally finite: finitely many finitary permutations generate a subgroup of `Sym(F)` for a finite `F`.
- The composite `H → Gamma → Q` has kernel `H ∩ N`.
- If `H` has no nontrivial locally finite normal subgroup, then `H ∩ N = 1` and `H` embeds in `Q`. ∎

**INVALIDATED PROPOSAL.**  Work inside the normalized six-leaf packet and
combine a bounded number of R2--R5 identities to replace the second private
output by a different exact transposition, while retaining its contextual
three-cycle and the common pivot.  Then use that replacement as the output
of the mixed R2 cell.

`fixed-leaf-semantics-forbid-mixed-r2-splice` shows that the second
three-cycle and common pivot already force its input and output to be
`(j p)` and `(j q)`.  The latter centralizes the first input `(i p)`, so it
cannot conjugate that input to `(p q)`.  Adding exact finite-leaf relations
cannot change this support calculation.  The remaining open route must be
an analytic collapse theorem for small matrix models, not an exact
permutation-word manufacture inside the fixed packet.

## Why sufficient

The hypothesis gives a properly infinite unit, so
`elementary-rank-descent-to-two` applies with `m = 4` and supplies
`Psi : EL_4(R) -> EL_2(R)` whose value at `e_12(1)` normally generates
`EL_2(R)`.

Let `rho : EL_2(R) -> M` with `M` an MF group.  Then `rho . Psi` is a
homomorphism from `EL_4(R)` to an MF group, so
`full-complementary-idempotent-elementary-full-mf-radical` makes it trivial.
In particular `rho(Psi(e_12(1))) = 1`, and the kernel of `rho`, being
normal, contains the normal closure of that element, which is `EL_2(R)`.

For `n >= 2` apply the descent principle: each root subgroup of `EL_n(R)`
sits inside a standard two-coordinate copy of `EL_2(R)`, the restriction of
any homomorphism to an MF group is trivial there, and the root subgroups
generate `EL_n(R)`.

For the finitely generated variant, run the rank-four theorem on the unital
subring `S` generated by `v_0,v_1,w_0,w_1`, which is countable and satisfies
the hypothesis with witness `w_1(1-v_0w_0)v_1 = 1`.  The elements `S_i, T_i`
lie in `S`, so `Psi` is defined on `EL_4(S)`, and its image still contains
the normal generator; the conjugators used in the normal closure may be
taken from all of `EL_2(R)`.

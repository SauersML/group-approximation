Let `K` be any group, let `z!=1` be an element of `K`, and let

```text
w(t;k_1,...,k_m)
```

be a word with constants in `K`.  There is no design with both of the
following properties.

1. For some `a in K`, evaluation in the finite packet gives

   ```text
   w(a;k_1,...,k_m)=z.                                 (SLN1)
   ```

2. For every unitary representation `sigma` of `K` and every unitary `V`,
   the same word on the second-layer multiplicity is identically trivial:

   ```text
   w(V;sigma(k_1),...,sigma(k_m))=I.                   (SLN2)
   ```

The conclusion remains true if `(SLN2)` is only demanded for one faithful
unitary representation of the free product `K*Z`.

Consequently no modification of the balanced lookup word alone can remove
the remaining multiplicity action in
`hyperoctahedral-router-interface-for-fanizza`.  A successful return must add
relations coupling the router multiplicity to the constant-packet
multiplicity, or isolate a packet type on which the latter action is trivial.

Write `S = P_1 ∪ P_2 ∪ {2}`, `H = ⟨CT_(P_1), CT_(P_2)⟩`, and `G = CT_(P_1 ∪ P_2)`. A class `a(m) = a + mZ` (`0 <= a < m`) is *S-smooth* when every prime factor of `m` is in `S`. `H ⊆ G` is clear. Since `G` is generated by the class transpositions `τ_(A,B)` with `A, B` disjoint S-smooth classes, it suffices to put each of these in `H`. Note `CT_∅ ⊆ CT_(P_1) ∩ CT_(P_2) ⊆ H` (2-power moduli).

**0. Canonical maps.** For classes `C = c(M)`, `D = d(M')` call `c + Mk ↦ d + M'k` the canonical map `C -> D`; `τ_(C,D)` is the canonical map on `C` and its inverse on `D`.
- (a) Composites of canonical maps are canonical.
- (b) A canonical map `C -> D` restricts to a canonical map from every subclass `(c + Ms)(Mt)` of `C` onto the subclass `(d + M's)(M't)` of `D`.
- (c) If `σ` is a bijection of `Z` that is canonical on disjoint classes `A` and `B`, then `σ τ_(A,B) σ^-1 = τ_(σA, σB)`: on `σA` it is the composite `σA -> A -> B -> σB` of canonical maps, symmetrically on `σB`, and the identity elsewhere.

**1. Moduli divisible by 4.** For disjoint `A = a(m)`, `B = b(n)` and `d >= 1`, `τ_(A,B) = ∏_(i<d) τ_((a+mi)(dm), (b+ni)(dn))`, a product of commuting class transpositions of pairwise disjoint classes, since the canonical map `A -> B` sends `a + m(i + dj)` to `b + n(i + dj)`. With `d = 4` every generator of `G` is a product of class transpositions whose moduli are S-smooth and divisible by 4.

**2. Normalization by CT_∅.** Let `A = a(2^α t)`, `B = b(2^β u)`, with `t, u` odd, `α, β >= 2`, `A ∩ B = ∅`. Their 2-cylinders `C_A = a(2^α)`, `C_B = b(2^β)` (reduced residues) are nested or disjoint. In each case some `g ∈ CT_∅` is canonical on `C_A` and on `C_B` (hence on `A` and `B`, by 0(b)) and maps them into classes contained in `0(2)` with modulus divisible by 4:
- both already inside `0(2)`: `g = 1`;
- nested, `C_A ⊆ C_B ⊆ 1(2)` (or the reverse): `g = τ_(C_B, D)` with `D ⊆ 0(2)` a cylinder of depth `>= 2`;
- disjoint: apply one class transposition `τ_(C, D)` to each cylinder `C ⊆ 1(2)`, with targets `D ⊆ 0(2)` of depth `>= 2`, pairwise disjoint and disjoint from the cylinders of the pair that lie in `0(2)` (possible, as those cylinders have depth `>= 2`); the transpositions involved have pairwise disjoint supports.
By 0(c), `τ_(A,B) = g^-1 τ_(gA, gB) g`. The classes `gA, gB` are disjoint, S-smooth, with even residues and moduli divisible by 4. So it suffices to treat such pairs.

**3. The transport.** Let `A = a(M)`, `B = b(N)` be disjoint S-smooth classes with `a, b` even and `4 | M, N`. Two classes meet iff their residues agree modulo the gcd of the moduli, so `A, B` are disjoint at some prime `r ∈ S`: their images in `Z/r^e` differ for the `r`-part `r^e` of `gcd(M, N)`. Every `r ∈ S` lies in `P_1 ∪ {2}` or in `P_2 ∪ {2}`; by symmetry assume `r ∈ P_1 ∪ {2}`.
- Factor `M = M_1 M_2`, `N = N_1 N_2`, where `M_1, N_1` are the parts with primes in `P_1 ∪ {2}` (so `4 | M_1, N_1`) and `M_2, N_2` the parts with primes in `P_2 \ P_1`. Put `a' = a mod M_1`, `b' = b mod N_1` (both even), `e = (a − a')/M_1 ∈ [0, M_2)`, `f = (b − b')/N_1 ∈ [0, N_2)`.
- The `(P_1 ∪ {2})`-shadows `a'(M_1) ⊇ A` and `b'(N_1) ⊇ B` are disjoint, because `r | gcd(M_1, N_1)` separates them.
- **Step in `CT_(P_2)`.** `g_2 = τ_(0(4), X) τ_(2(4), Y)` with `X = (1 + 4e)(4M_2)`, `Y = (3 + 4f)(4N_2)`. The four classes are pairwise disjoint (residues `0, 2, 1, 3` mod 4), and all moduli are `(P_2 ∪ {2})`-smooth.
- **Step in `CT_(P_1)`.** `g_1 = τ_(1(4), a'(M_1)) τ_(3(4), b'(N_1))`. The four classes are pairwise disjoint (two odd, two even, and the even ones disjoint by the shadow remark), and all moduli are `(P_1 ∪ {2})`-smooth.
- **Composite.** `σ = g_1 g_2 ∈ H`. By 0(b), `σ(4k) = g_1(1 + 4(e + M_2 k)) = a' + M_1(e + M_2 k) = a + Mk`, and `σ(2 + 4k) = g_1(3 + 4(f + N_2 k)) = b' + N_1(f + N_2 k) = b + Nk`. So `σ` is canonical from `0(4)` onto `A` and from `2(4)` onto `B`.
- By 0(c), `τ_(A,B) = σ τ_(0(4), 2(4)) σ^-1 ∈ H`, since `τ_(0(4),2(4)) ∈ CT_∅`.

If instead `r ∈ P_2 \ P_1`, exchange the roles of `P_1` and `P_2` (factor off the primes of `P_1 \ P_2`, step first in `CT_(P_1)`, then in `CT_(P_2)`).

**4. Conclusion.** Steps 1–3 put every generating class transposition of `G` in `H`, so `H = G`. The incomparability hypothesis of 21.75 is not used; if `P_1 ⊆ P_2` the statement is trivial. ∎

**Calibration.** The example in the target (`P_1 = {3}`, `P_2 = {5}`, `τ_(3(12),6(20))`) runs steps 2–3 by hand: `g = τ_(3(4),0(8))` gives `gA = 0(24)`, `gB = 6(20)`, disjoint at `r = 2`; then `M_1 = 24, M_2 = 1, e = 0`, `N_1 = 4, N_2 = 5, b' = 2, f = 1`, so `X = 1(4)`, `Y = 7(20)`, `g_1 = τ_(1(4),0(24)) τ_(3(4),2(4))`.

Let `L = L_K(E)` be purely infinite simple, and `P, Q` nonzero finitely generated projective
right `L`-modules with `[P] = [Q]` in `K_0(L)`.
- Then `P ⊕ L^n ≅ Q ⊕ L^n` for some `n >= 1`.
- In the group `V(L)*` the class `[L^n]` cancels, so `[P] = [Q]` in `V(L)*`, that is, `P ≅ Q`.

This route needs no graph-theoretic input beyond the hypothesis of the claim. That hypothesis holds,
for example, for finite sinkless cofinal graphs with condition (L), by Abrams--Aranda Pino
(arXiv:math/0509496).

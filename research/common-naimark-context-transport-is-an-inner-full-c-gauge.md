Let `K` be the finite qutrit outcome group, let `A` contain PVMs
`(p_(x,s))_(s in K)`, and use the common Naimark amplification

```text
M=A tensor M_(|K|),
e_a=1 tensor E_a,
c_x=sum_s p_(x,s) tensor lambda(-s),
d_(x,a)=c_x e_a c_x^*.                                  (NCG1)
```

For contexts `x,y` and an outcome shift `t`, put

```text
u_(y,t,x)=c_y(1 tensor lambda(t))c_x^*.                   (NCG2)
```

Then

```text
u_(y,t,x) d_(x,a) u_(y,t,x)^*=d_(y,a+t).                 (NCG3)
```

Thus every context/outcome transport furnished by the known common
packet is inner on the amplified occurrence algebra.

There are only two ways to combine this transport with the fixed
full-`C` target.

First, keep the rank-`16` projection `Q_h` in the separate
`288`-dimensional head.  Then `u_(y,t,x)` commutes with `Q_h`,
the raw defect return is the tensor return already covered by the
bounded-Jacobson normal form, and

```text
rank(Q_h tensor 1_N)=16N,        dim(H_h tensor C^N)=288N,
rank(Q_h tensor supp|B|)=16 rank(supp|B|).               (NCG4)
```

The target density is exactly `1/18`, but the cross-Gram singular
values are merely repeated sixteen times.

Second, make the context transport act on the same qutrit packet as the
named target atom.  Every `u_(y,t,x)` belongs to the
translation-circulant algebra

```text
A tensor span{lambda(d):d in K}.                          (NCG5)
```

If it preserves even one fixed atom `e_b`, then necessarily

```text
u_(y,t,x)=v tensor 1
```

for a unitary `v in A`, and `(NCG3)` forces

```text
v p_(x,s) v^*=p_(y,s+t)                 for every s.      (NCG6)
```

So either the canonical action moves the named full-`C` target, in
which case it fails the target typing, or the two context PVMs were
already inner conjugate up to relabelling.  In the latter case the raw
covariance can be untwisted by replacing `S,T` with
`u^*S,Tu`; the target atom is fixed and the return is again Morita
neutral.

For the literal losing coefficient

```text
B_(y,b;x,a)=e_b c_y^* e_r c_x e_a,                       (NCG7)
```

inner transport only conjugates its Gram and spectral support.  If
`B^*B R >= delta/2 R`, then the separated rank-`1/18` return has

```text
(Q_h tensor B)^*(Q_h tensor B)(Q_h tensor R)
 >=delta/2 (Q_h tensor R).                               (NCG8)
```

The singular floor survives, but no second invariant appears.

Therefore the natural context-router action does not supply the missing
non-Morita raw holonomy.  An escape must use an action not generated by
the common router and Pauli translations, while preserving the fixed
full-`C` target and exact perfect completeness.  No such action and no
nonhyperlinearity conclusion are proved here.

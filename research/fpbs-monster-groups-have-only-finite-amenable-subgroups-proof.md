**1. Tarski monster.**
- `T` is infinite, torsion, and all its proper subgroups are cyclic. A torsion
  cyclic group is finite, so every proper subgroup is finite.
- `T` is nonamenable, so every amenable subgroup is proper, hence finite.
- `T` is nonabelian, since an abelian group is amenable. Choose noncommuting
  `x` and `y`. Then `<x,y>` is not cyclic, so it is not proper: `T = <x,y>`.

**2. Free Burnside group.**
- `B(m,n)` is infinite and nonamenable by Adian (`n >= 1003 >= 665`). It is
  generated by `m` elements and is torsion of exponent `n`.
- Let `S <= B(m,n)` be noncyclic. By `thm:atabekyan`, `S` contains a copy of
  `B(∞,n)`, which contains a copy of `B(2,n)`: the first two free generators
  generate it, since killing the remaining generators is a retraction
  `B(∞,n) -> B(2,n)` that is the identity on them.
- `B(2,n)` is nonamenable by Adian, so `S` is nonamenable.
- So every amenable subgroup of `B(m,n)` is cyclic, hence finite because `n` is
  an exponent.

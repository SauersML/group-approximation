Notation as in the target. `r_1 = b^-1 a^2 b a^2` and `r_2 = a^-1 b^2 a b^2`
are the relators of `P`. The exponent sums of `a` and `b` are `(4, 0)` in
`r_1` and `(0, 4)` in `r_2`.

**Step 1 (the signs are defined and gauge invariant).** In `P` each relator is
`1`. So its image in `Z^c[P]`, computed from `abar`, `bbar` and their inverses,
is `+-1bar`, and `kappa_i` is defined. A cohomologous cocycle
`c' = c * dh` with `h: P -> {+-1}` gives the isomorphism
`Z^(c')[P] -> Z^c[P]`, `gbar -> h(g) gbar`. It sends `abar -> h(a) abar` and
`bbar -> h(b) bbar`. The relator word therefore picks up
`h(a)^(sum of a-exponents) h(b)^(sum of b-exponents) = 1`, since both sums are
even. So `kappa` depends only on `[c]`.

**Step 2 (kappa is a homomorphism).** For cocycles `c, c'` the map
`Z^(c c')[P] -> Z^c[P] (x)_Z Z^(c')[P]`, `gbar -> gbar (x) gbar'`, is a unital
ring homomorphism: both sides multiply basis elements by `c(g,h) c'(g,h)`. It
sends `1bar` to `1 (x) 1` and each relator word to the tensor of the relator
words, so `kappa(c c') = kappa(c) kappa(c')`.

**Step 3 (values and bijectivity).**
- **Models.** For `e_1, e_2 in {0, 1}` let `f(g) = s^(e_1 it(g)) t^(e_2 jt(g))`
  in `R = Z[s,t]/(s^4+1, t^4+1)`. By Steps 2–4 of
  `promislow-twisted-integral-rings-gardam-units-proof`, `gbar -> f(g) g` is a
  ring isomorphism onto a subring of `R[P]`, for the cocycle representing
  `e_1 beta(rho_1) + e_2 beta(rho_2)`. Then `abar = s^e_1 a` and `bbar = t^e_2 b`.
- **Signs of the models.** Scalars are central and `b^-1 x b = x^-1`, so
  `bbar^-1 abar^2 bbar abar^2 = s^(2 e_1) x^-1 s^(2 e_1) x = s^(4 e_1) = (-1)^e_1`.
  Likewise `abar^-1 bbar^2 abar bbar^2 = t^(4 e_2) = (-1)^e_2`. So `kappa` takes
  all four values and is onto.
- **Injectivity, without counting.** Let `Pt_c = {+-gbar}`, a central extension
  of `P` by `<-1>`; its class is `[c]`. Any central extension
  `1 -> <zeta> -> E -> P -> 1` with `zeta` of order 2 is generated by lifts
  `at, bt` of `a, b` and `zeta`, with `rt_i = zeta^(f_i)`. The `f_i` do not
  depend on the lifts, because the exponent sums are even. So `E` is a quotient of
  `Et = <at, bt, zeta | zeta central, zeta^2 = 1, rt_1 = zeta^(f_1), rt_2 = zeta^(f_2)>`.
  The kernel of `Et -> P` is generated by `zeta` and the `rt_i`, all powers of
  `zeta`, so it is `<zeta>`. Since `zeta != 1` in `E`, the map `Et -> E` is an
  isomorphism. So `(f_1, f_2) = kappa` determines the extension, and `kappa` is
  injective on `H^2(P; Z/2)`.

This gives item 1, and recovers `|H^2(P; Z/2)| = 4` (Step 8 of the cited route)
independently.

**Step 4 (item 2).** Apply `phi` to `bbar^-1 abar^2 bbar = kappa_1 abar^-2`, which
is `r_1` rearranged. With `h = phi(abar)` and `k = phi(bbar)^-1` it reads
`k h^2 k^-1 = kappa_1 h^-2`, since `phi` is unital and `phi(-1bar) = -1`. The
second relator, rearranged as `abar^-1 bbar^2 abar = kappa_2 bbar^-2`, gives the
other case.

**Step 5 (item 3).** Let `g = h^2`, so `k g k^-1 = -g^-1`.
- **Degree 1.** Here `A = F` is commutative, so `g = -g^-1` and `h^4 = g^2 = -1`.
- **Degree 2.** Every element satisfies `X^2 - trd(X) X + nrd(X) = 0`. `trd` and
  `nrd` are conjugation invariant, `nrd` is multiplicative, `nrd(-X) = nrd(X)`
  and `trd(X^-1) = trd(X)/nrd(X)`.
  - Comparing norms, `nrd(g) = nrd(g)^-1`, so `nrd(g) = +-1`. As
    `nrd(g) = nrd(h)^2` with `nrd(h) in F`, the case `nrd(g) = -1` makes `-1` a
    square in `F`.
  - Otherwise `nrd(g) = 1`, and comparing traces gives `trd(g) = -trd(g)`, so
    `trd(g) = 0` and `g^2 = -1`, i.e. `h^4 = -1`.
- **The factor of `X^4 + 1`.** If `h^4 = -1`, the minimal polynomial of `h` over
  `F` divides `X^4 + 1`. Its degree is at most 2, since `h` satisfies a
  polynomial of degree `deg A`.
  - A root `r` gives `(r^2)^2 = -1`.
  - A quadratic factor `(X^2 + pX + q)(X^2 - pX + q')` forces `q + q' = p^2`,
    `p(q' - q) = 0` and `q q' = 1`. If `p = 0` then `-q^2 = 1`; if `p != 0` then
    `q = q' = +-1` and `p^2 = +-2`.
  - So `-1`, `2` or `-2` is a square.
- **Formally real `F`.** `-1` is not a square. If `-2 = w^2` then
  `-1 = (w/2)^2 + (w/2)^2`, impossible. So `2` must be a square, i.e.
  `sqrt(2) in F`.

Combined with Step 4, a nonzero class admits no unital homomorphism into such
an algebra.

**Step 6 (item 4).**
- **The target is excluded.** `D(Q(t))` is the cyclic algebra
  `(Q(t)/Q(t + t^-1), t -> t^-1, -1)`, central simple of degree 2 over
  `Q(t + t^-1)` (the paragraph "The quotients" of
  `promislow-integral-units-have-monomial-definite-line-shadows`).
  - `Q(t + t^-1)` is purely transcendental over `Q`, hence formally real.
  - Its elements algebraic over `Q` lie in `Q`, so `sqrt(2)` is not in it.
  - `D(Z)` is a subring (basis `t^m, t^m u` over `Z`).
  - So Step 5 excludes homomorphisms `Z^c[P] -> D(Z)` for `[c] != 0`.
- **Class 0 has them.** For `[c] = 0`, compose `Z^c[P] = Z[P]` (item 2 of the
  cited twisted claim) with the shadows.
- **Where the class enters Step 1 of the Parseval route.** That step verifies
  exactly `kappa = (1, 1)` for the three assignments: both relators go to `-1`
  on both sides, with no sign. Steps 2–4 of that route are statements about
  `D(Z)` and about arbitrary ring homomorphisms into it.

**Step 7 (item 5).**
- **Relator values.** Under `abar -> zeta_8^e_1 u` and
  `bbar -> -zeta_8^e_2 t^-1 u`, `abar^2 -> -zeta_8^(2 e_1)` and
  `bbar^2 -> -zeta_8^(2 e_2)` are central. So
  `rt_1 -> zeta_8^(4 e_1) = (-1)^e_1` and `rt_2 -> (-1)^e_2`, which is `kappa`.
- **The homomorphism.** By the presentation of `Et` in Step 3 the assignment
  extends to a homomorphism `Pt_c -> D(Z[zeta_8])^x` with `-1 -> -1`. Hence it
  extends to a unital ring homomorphism from `Z^c[P] = Z[Pt_c]/(zeta + 1)`.
- **Same as the gauge map.** On `abar, bbar` it agrees with the composite of
  `gbar -> zeta_8^(e_1 it(g) + e_2 jt(g)) g` and shadow `C`, so the two maps are
  equal.
- **The witness.** For `h = zeta_8 u`: `h^2 = -zeta_8^2` and
  `-h^-2 = zeta_8^-2 = -zeta_8^2`.

**Checks.** `class_shadow_check.py` (log in the artifact) recomputes Step 3 in
`R[P]` with the affine model of `P`, and Step 7 in monomials of
`D(Z[zeta_8])`. On the box `|m| <= 4` of `D(Z)^x` it finds no solution of
`k h^2 k^-1 = -h^-2`, as Steps 5–6 predict.

QED

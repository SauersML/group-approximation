**Setting.** `L = L_Z(1,2)` is the binary Leavitt algebra over `Z`: generators
`x_0, x_1, y_0, y_1` with `y_i x_j = delta_ij` and `x_0 y_0 + x_1 y_1 = 1`. For a
binary word `w`, `x_w` and `y_w` are the products along `w` (with `y_w` read in
reverse, so that `y_w x_w = 1`). Thompson's group `V` embeds in the unit group
`U(L)` by permutation units: if `g` maps the cones of a complete prefix code
`(e_i)` canonically onto those of `(d_i)`, then `v_g = sum_i x_{d_i} y_{e_i}`.

**Statement.** Let `t = 1 + x_{01} y_{00}` in `U(L)`. The subgroup `<V, t> <= U(L)`
is finitely generated and contains a subgroup isomorphic to `(Q,+)` in which `1`
maps to `t`. It is explicit: there are `a_1 = t, a_2, a_3, ... in <V, t>` with
`a_{k+1}^{k+1} = a_k`, and `m/k! -> a_k^m` is an injective homomorphism
`Q -> U(L)`. Hence for every commutative ring `A` of characteristic 0, the unit
group of `L_A(1,2) = A (x) L` contains `(Q,+)` inside a finitely generated
subgroup.

**Consequences for the root `gl-n-q-embeds-in-fp-simple-group`.**
- **The Leavitt unit-group family is alive at the group level.** Contrast
  `fg-subrings-of-integral-form-algebras-omit-q`: no finitely generated subring
  of such an algebra carries `Q` ring-linearly. Here divisibility comes instead from
  *transvection splitting plus cyclic rotation of cone blocks*. A transvection is a
  product of `k+1` commuting copies of itself on refined cones; a `V`-rotation of
  those copies, times one copy, is a `(k+1)`-st root. This is a linear analogue of
  Belk–Hyde–Matucci's roots in `T-bar`, and it happens inside the `Z`-form.
- **The host candidate passes O1–O4.** `<V, t>` contains:
  - `V`, so it is not residually finite;
  - every `GL_r(Z)`, acting on a proper cone configuration by `u(Gamma, M)` (see
    the proof), in particular `SL_3(Z)`, whose elementary unipotents are
    exponentially distorted (already inside `Z^2 x| SL_2(Z) <= SL_3(Z)`);
  - `(Q,+)`.

  So none of O1–O4 excludes it as a host for `n >= 3`, unlike `V` and `VA`.
- **Limit of this copy.** `t` is not conjugate to `t^p` for any prime `p` in
  `Aut_Z(LC(C,Z)) >= U(L)`. The cokernel of `t - 1` on locally constant
  `Z`-valued functions on the Cantor set `C` is torsion-free, while that of
  `t^p - 1 = p x_{01} y_{00}` has `p`-torsion. So no element of `U(L)` acts on this
  copy of `Q` by multiplication by `p`, and the copy does not extend to `Aff(Q)`
  by conjugation. Whether `U(L_A(1,2))`, or a finitely presented subgroup of it,
  contains `Aff(Q)` or `GL_2(Q)` is open.
  It is now settled for copies through `t`: by
  `aff-q-in-integral-unit-hosts-reduces-to-finite-fields`, part 3, no finitely
  generated subgroup of any characteristic-0 `L_K(1,2)^x` contains an `Aff(Q)`
  with `t` among its translations. By part 1 there, any `Aff(Q)` at all in such a
  host already lives in some `L_(F_p)(1,2)^x`.
- **Relation to the finite-field reduction.** Modulo any prime `p` the transvection
  `t` has order `p`, so every reduction map of
  `integral-unit-hosts-for-gl-n-q-reduce-to-finite-fields` sends this copy of `Q`
  onto a torsion quotient of `Q`. That claim transfers `(Q,+)` to a finite field
  only through a copy of `SL_n(Q)`, and this example shows the hypothesis cannot
  be dropped by reducing a given copy of `(Q,+)`.

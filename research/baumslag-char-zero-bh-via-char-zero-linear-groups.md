**Embedding.** Define

```text
r -> [[1, r], [0, 1]]   (r in R = Z[x^±1,(1+x)^-1]),
s -> diag(1+x, 1),   t -> diag(x, 1),
```

in `GL_2(Q(x))`. Conjugating the unipotent matrix by the diagonal ones
multiplies `r` by `1+x` and by `x`, which matches the action in
`B = R x| Z^2`.

- **Injective.** An element `(r, s^a t^b)` maps to
  `[[(1+x)^a x^b, r], [0, 1]]`. This is the identity only when `r = 0` and
  `a = b = 0`, because `x` and `1+x` are multiplicatively independent.
- **Finitely generated.** The image is generated by the images of `a`, `s`
  and `t`.

So `B` is a finitely generated linear group over a field of characteristic
zero, and the root `char-zero-linear-groups-satisfy-boone-higman` would give
the target.

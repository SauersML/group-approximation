Let `G` be a group and `w in G * <t>` with `deg_t(w) = m != 0`.

1. **Localize.**  Let `A <= G` be the subgroup generated by the finitely many
   coefficients occurring in `w`, say `a_1, ..., a_k`.  Write
   `w = W(a_1, ..., a_k, t)` for a word `W in F_k * <t>`, with
   `deg_t(W) = m`.  By `kl-failure-localizes-to-the-coefficient-subgroup` it
   is enough to show `A -> A_w = (A * <t>)/<<w>>` is injective.
2. **Tracial root.**  `A` is countable, so `M = L(A)`, with its canonical
   trace, is a separable tracial von Neumann algebra.  Apply
   `tracial-algebras-solve-nonsingular-equations-in-extensions` to `M`, to the
   unitaries `lambda(a_1), ..., lambda(a_k)`, and to `W`.  It gives
   `(N, sigma)`, a trace-preserving embedding `iota : L(A) -> N`, and
   `T in U(N)` with `W(iota lambda(a_1), ..., iota lambda(a_k), T) = 1`.
3. **A representation of `A_w`.**  Define `phi : A * <t> -> U(N)` by
   `a -> iota(lambda(a))` and `t -> T`.  Then `phi(w) = 1`, so `phi` factors
   through `A_w`.
4. **Faithful on `A`.**  The left regular representation is faithful,
   because `lambda(a) delta_e = delta_a`, and `iota` is injective.  So
   `phi|_A` is injective, and so is `A -> A_w`.  By step 1, `G -> G_w` is
   injective.

**Scope.**  This route uses the tracial root theorem only at the regular trace
of `A`.  By `kl-yields-tracial-roots-for-quotient-indicator-traces`, that case
is equivalent to the conjecture for `A`, so the route is a reformulation at
that trace.  The general root theorem is stronger, and is what one would
prove if a root source for tracial algebras were found.

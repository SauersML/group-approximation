**ESTABLISHED** (citation; route `bell-generalized-cobham-theorem-citation`). Not reproved here.

**Statement** (Bell, Theorem 1.4, verbatim up to typesetting): "Let R be a commutative ring, let k and l be
multiplicatively independent positive integers, and let {f(n)} be a sequence which is both (R,k)- and
(R,l)-regular. Then {f(n)} satisfies a linear recurrence over R."

**Definitions used** (Bell, Definitions 1.2 and 1.3):
- For a sequence {f(n)} with values in an R-module, M_R({f(n)}; k) is the R-module generated by all sequences
  {f(k^i n + j)}_{n ≥ 0} with i ≥ 0 and 0 ≤ j < k^i. The sequence is (R,k)-regular if this module is finitely
  generated. Bell notes that no Noetherian hypothesis on R is needed.
- f: N → M satisfies a linear recurrence over R if there are m ≥ 1 and c_1, …, c_m ∈ R with
  f(n) = Σ_{i=1}^m c_i f(n − i) for n ≥ m.

**Integer-valued form** (Bell, Theorem 1.5): an integer-valued sequence is both k- and l-regular, for k, l
multiplicatively independent, if and only if Σ f(n) x^n ∈ Z[[x]] is the expansion of a rational function whose
poles are all roots of unity.

**Use on main.** `ct-z-normalizers-are-2-and-3-regular`, item 3, needs exactly Theorem 1.4 with R = Q,
k = 2, l = 3: its item 2 puts the 2- and 3-kernels of the normalizer sequence Φ inside a Q-space of dimension
≤ 2P, so M_Q(Φ; 2) and M_Q(Φ; 3) are finitely generated. Theorem 1.4 then gives a linear recurrence over Q, and
that node's own Fatou–Kronecker remark (integer values, polynomial growth) makes Φ eventually quasi-polynomial.

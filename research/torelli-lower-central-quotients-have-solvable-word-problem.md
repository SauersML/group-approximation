**ESTABLISHED** (lane proof, elementary; not reviewed; no priority claimed, since
the extension lemma is folklore).

**Statement.** For `g >= 3` and every `c >= 1`, the finitely generated group
`Q_{g,c} = Mod(S_g)/T_g[c+1]` has solvable word problem.

**Extension lemma.** Let `1 -> N -> G -> H -> 1` be exact, with `G` generated
by a finite set `S`, `N` finitely generated with solvable word problem, and `H`
finitely presented with solvable word problem. Then `G` has solvable word problem.

*Proof.* Choose the following finitely many pieces of data:
- words `n_1,…,n_k` over `S` generating `N`;
- a finite presentation `H = <S | R>` on the images of `S` (any finite
  generating set of a finitely presented group carries one);
- for each `r ∈ R`, a word `nu_r` in the `n_i` with `r = nu_r` in `G` (possible
  because `r ∈ N`);
- for each `s ∈ S^{±1}` and each `i`, a word `mu_{s,i}` in the `n_j` with
  `s n_i s^{-1} = mu_{s,i}` in `G` (possible because `N` is normal).

Given a word `w` over `S`:
1. Decide whether `w = 1` in `H`. If not, then `w ≠ 1` in `G`.
2. Otherwise `w` lies in the normal closure of `R` in `F(S)`. Enumerate products
   `∏ u_j r_j^{±1} u_j^{-1}` until one is freely equal to `w`. This search
   terminates.
3. Rewrite each factor `u r u^{-1}` as a word in the `n_i`. Start from `nu_r` and
   conjugate letter by letter from the right end of `u`, using the `mu_{s,i}`.
   This gives a word `v` in the `n_i` with `w = v` in `G`.
4. Decide whether `v = 1` in `N`.

The algorithm uses only the finitely many fixed data above; their existence is
all that solvability requires.

**Application.**
- `Q_{g,c}` is generated by the image of a finite generating set of `Mod(S_g)`.
- `N = N_{g,c} = T_g/T_g[c+1]` is finitely generated because `T_g` is, for
  `g >= 3` (Johnson; Nowak Theorem A, arXiv:2609.12196 l.193).
- `N` is nilpotent. Finitely generated nilpotent groups are finitely presented and
  residually finite, so their word problem is solvable.
- `H = Sp_2g(Z)` is finitely presented (an arithmetic group) and linear over `Z`,
  so its word problem is solvable.
- The lemma applies.

**Consequence.** For `g >= 3` and `c >= 2`, `Q_{g,c}` is a finitely generated group
with:
- solvable word problem (this node);
- property (T) (Nowak);
- not linear over any field (Nowak);
- not residually finite (`torelli-lower-central-quotients-are-not-residually-finite`).

So it is a genuine input for Boone–Higman
(`torelli-lower-central-quotients-satisfy-boone-higman`).

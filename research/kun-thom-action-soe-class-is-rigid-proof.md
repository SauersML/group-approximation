# Proof

**1. The action.** `σ` is the generalized Bernoulli action over `K = G/Γ ⊔ G` with base
`([0,1], Leb)`.
* Nonsofic: Kun--Thom Corollary D (`kun-thom-nonsofic-wreath`) applies to every nontrivial
  standard base, so `G ↷ ([0,1],Leb)^(G/Γ)` is not sofic; it is a factor of `σ`, and factors
  of sofic actions are sofic (Kun--Thom p. 7).
* Free: every `g ≠ e` moves every point of the summand `G`, so `|{k : gk ≠ k}| = ∞`
  (Popa p. 5).
* Weakly mixing: `[G:Γ] = ∞` (Step 0 of `kun-thom-free-nonsofic-action-proof`), so every
  `G`-orbit in `K` is infinite (Popa p. 4).
* s-malleable: generalized Bernoulli (Popa p. 3).

**2. Hypotheses of Theorem 0.1.** `G` has property (T), so `H = G` is an infinite rigid
subgroup; it is w-normal in itself (the chain of consecutive normal inclusions is trivial),
and `σ|H = σ` is weakly mixing. Theorem 0.3 needs in addition that `G` has no nontrivial
finite normal subgroup, which is assumed, and that `σ` is free.

**3. SOE rigidity.** Theorem 0.3 gives `n = 1/t ∈ ℕ`, `Λ_0 <= Λ` of index `n`, `δ : G ≅ Λ_0`,
and `Y_0` of measure `1/n`, fixed by `Λ_0`, with `θ|Λ_0` on `Y_0` conjugate to `σ` through `δ`.
* If `n >= 2`, `Y_0` is a `Λ_0`-invariant set with `0 < ν(Y_0) < 1` and `Λ_0` is infinite. A
  mixing action has every infinite subgroup ergodic (take `A = B = Y_0` and `λ → ∞` in `Λ_0`).
  So `θ` is not mixing.
* If `n = 1`, `θ|Λ_0 = θ` is conjugate to `σ`. The function `x ↦ x_Γ` is `Γ`-invariant and
  nonconstant, `Γ` is infinite, so `σ` and hence `θ` are not mixing.

**4. Embedding rigidity.** Theorem 0.4 gives `t <= 1`, `Λ_0 ≅ G` and a `Λ_0`-invariant `Y_0` of
measure `t` with `θ|Λ_0` on `Y_0` conjugate to `σ`. If `t < 1` the argument of step 3 applies.
If `t = 1`, `θ|Λ_0` is conjugate to the non-mixing `σ`, and mixing passes to restrictions to
subgroups, so `θ` is not mixing.

**Instance (sketch, not consumed).** For the Theorem E pair with `q = 2`, a finite normal
subgroup `N` of `G = EL_r(R) ⋊ SL_d(Z)` meets `EL_r(R)` in a finite normal subgroup, which is
central by the sandwich classification of normal subgroups of `EL_r` over commutative rings
(`r >= 3`), hence trivial since the only unit `λ` of `F_2[x^(±1)]` with `λ^r = 1` is `1`. Its
image in `SL_d(Z)` is central, so `N` is generated by some `(A, −I)` commuting with `EL_r(R)`;
but conjugation by `A` is `R`-linear while the substitution `x ↦ x^(-1)` is not. So `N = 1`.

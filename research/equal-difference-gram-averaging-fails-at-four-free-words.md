**ESTABLISHED POSITIVE/NEGATIVE BOUNDARY.**  Let

```text
q:A -> C^*_r(G)
```

be a unital quotient.  First, if `H<=G` is amenable, then the inclusion
`C^*_r(H)->C^*_r(G)` has a ucp lift through `q`.  Indeed `C^*_r(H)` is
nuclear, so the Choi--Effros lifting theorem applies to that inclusion.
Consequently every finite Fourier operator system contained in one amenable
subgroup lifts.  This includes all finite and infinite cyclic charts.

For a finite subgroup `H`, the lift can be seen directly from word-unitary
lifts `v_h in A`.  Put

```text
Phi(k)=|H|^(-1) sum_(t in H) v_t^* v_(tk).              (EDA1)
```

For `g,h in H`, changing variables `u=tg` gives

```text
Phi(g^(-1)h)
 =|H|^(-1) sum_(t in H) v_(tg)^*v_(th).                (EDA2)
```

Thus `[Phi(g^(-1)h)]_(g,h in H)` is an average of Gram matrices, hence is
positive; `Phi(1)=1`; and `q(Phi(k))=lambda_k`.  Therefore `Phi` is an
`A`-valued positive-definite function and its ucp extension is a section on
`C^*(H)=C^*_r(H)`.  Equivalently, averaging over the genuine left-translation
action of the whole finite subgroup is a completely positive conditional
expectation on the index matrix.

The superficially more general operation "average all entries having the
same group difference" is **not positive**.  This already fails on four
words.  In the free group on `a,b`, index rows and columns by

```text
f_1=1,       f_2=a,       f_3=b,       f_4=ba.          (EDA3)
```

The only off-diagonal repeated differences are

```text
f_1^(-1)f_2=f_3^(-1)f_4=a
```

and the inverse pair.  Start with the scalar unitary Gram matrix

```text
G=xi xi^*,                 xi=(1,1,1,-1)^T.             (EDA4)
```

The two entries in the `a`-class are `G_(1,2)=1` and `G_(3,4)=-1`.
Replacing every entry by the arithmetic mean of its equal-difference class
therefore gives

```text
T(G)=
[ 1  0  1 -1 ]
[ 0  1  1 -1 ]
[ 1  1  1  0 ]
[-1 -1  0  1 ].                                           (EDA5)
```

For `x=(1,1,-1,1)^T`,

```text
x^* T(G) x=-4.                                            (EDA6)
```

Hence `T` is not even positive, despite starting from a Gram matrix of
scalar unitaries.  Positivity in `(EDA2)` survives because all entries are
averaged by one common permutation action on a translation-closed index
set.  It does not survive independent averaging of truncated collision
classes.

There is also a global amenability fence.  On `B(ell^2(G))`, the matrices
whose `(g,h)` entry depends only on `g^(-1)h` form the corresponding group
von Neumann algebra (up to choosing left versus right conventions).  A
unital completely positive projection from all matrices onto this Toeplitz
subalgebra would be a conditional expectation, hence would make the group
von Neumann algebra injective.  For a discrete group this is equivalent to
amenability of `G`.  Thus a global cp "equal-difference Toeplitzizer" cannot
exist for the nonamenable binary Leavitt unit group.  The finite-window
lifting question could still have noncoherent window-by-window solutions;
the fence rules out only a single global averaging operator.

The binary Leavitt unit group contains a free subgroup generated by prefix
ping-pong units, so the literal four-word pattern `(EDA3)` occurs inside the
candidate group.  Its finite prefix permutation subgroups and every other
amenable subgroup are harmless by the first paragraph, but their local
sections do not furnish the missing cross-chart matrix order.  Merely
covering a finite word set by cyclic or amenable subgroups carries no such
compatibility (every finite word set has the tautological cover by cyclic
subgroups).

This is a screening result, not a four-word nonlifting theorem.  The scalar
matrix `(EDA4)` proves that Gram positivity alone cannot justify the proposed
collision average.  A special Leavitt construction could still succeed only
by producing a common completely positive symmetry/conditional expectation
on the actual near-cover Gram matrices, or by directly verifying all matrix
orders of the concrete Fourier operator system.  The Leavitt prefix
self-similarity supplies finite amenable orbit averages, but it does not turn
the nonamenable free four-word window into a translation-closed amenable
chart.

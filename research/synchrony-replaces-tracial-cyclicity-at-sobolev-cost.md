Let `A` be generated by a finite unitary set `X`, and let `phi` be a state on
`A tensor A` satisfying

```text
||x tensor 1-1 tensor x||_phi <= sqrt(epsilon)    for every x in X.  (SYC1)
```

If `omega_X` reverses every star-monomial, then every star-polynomial `u`
satisfies

```text
||u tensor 1-1 tensor omega_X(u)||_phi
  <= ||u||_(1,1) sqrt(epsilon).                                 (SYC2)
```

Consequently, for a monomial `u` and `a in A`,

```text
| ||u^* a u tensor 1||_phi-||a tensor 1||_phi |
  <= ||a||_A deg(u) sqrt(epsilon).                              (SYC3)
```

There is also a relator-decomposition transfer.  If `R` is a set of
star-polynomial relations, the left restriction `tau(a)=phi(a tensor 1)` is
an `(epsilon,R)`-state, and `f` has an `R`-decomposition of size `Lambda`,
then

```text
||f||_tau <= Lambda sqrt(epsilon).                              (SYC4)
```

Thus polynomial filling or ideal-decomposition cost remains polynomial when
tracial cyclicity is replaced by approximate synchrony; it is not necessary
to round the state to a trace first.

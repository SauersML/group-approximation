## Construction

`𝔊` is countable and finitely generated (item 1 of
`grigorchuk-group-is-just-infinite-torsion-not-fp`). Apply Theorem 1.1 of
`ollivier-wise-kazhdan-rips-construction` with `Q = 𝔊`. This gives `1 → N → Γ → 𝔊 → 1` with:

- `Γ` torsion-free with a graphical `Gr'(1/6)` presentation, so `cd Γ ≤ 2`;
- `N` with property (T);
- `Γ` finitely generated, because `𝔊` is (part (4) of that theorem).

## Item 3: the quotient

- `𝔊` is infinite, finitely generated, torsion and just-infinite, by items 1–2 of
  `grigorchuk-group-is-just-infinite-torsion-not-fp`.
- `𝔊` is amenable, because it is a subgroup of the amenable HNN extension `𝔊^` of
  `grigorchuk-hnn-extension-is-fp-amenable-non-ea`, and subgroups of amenable groups are amenable.

## Item 2: the kernel

- **Finitely generated.** A countable group with property (T) is finitely generated
  (Kazhdan; see Bekka–de la Harpe–Valette, Theorem 1.3.1). `N` is countable, because `Γ` is.
- **Nontrivial and infinite.** If `N = 1`, then `Γ ≅ 𝔊` is a nontrivial torsion group, which
  contradicts torsion-freeness. So `N ≠ 1`, and a nontrivial torsion-free group is infinite.
- **Not amenable.** An amenable group with property (T) is finite.
- **`cd N = 2`.** `N ≤ Γ`, so `cd N ≤ 2`. If `cd N ≤ 1`, then `N` is free (Stallings–Swan), and
  nontrivial. A nontrivial free group has infinite abelianisation, so it does not have property
  (T). Hence `cd N = 2`.

## Item 1: `cd Γ = 2`

`cd Γ ≥ cd N = 2`, and `cd Γ ≤ 2`.

## Item 4: the collapse

`N` is infinite and finitely generated. So `U(N) ⊗_{ZN} Z` is a finitely presented `U(N)`-module
of dimension `b_0^(2)(N) = 0`, hence zero. This is fact (J) of
`cd-two-torsion-quotient-out-embedding-proof`, which uses neither amenability nor cd.

Then `H_0(N; U(Γ)) = U(Γ) ⊗_{U(N)} (U(N) ⊗_{ZN} Z) = 0`.

The "Collapse", "Generators" and "Averaging" paragraphs of item 2 in that proof use only this
vanishing and the finite orders of the generators `q_i` of `Γ/N`. So they apply verbatim and give
`H_1(Γ; U(Γ)) ≅ V / Σ_i (1 − e_i) V`.

The statement `e_i V ≠ 0` in that item uses the counterexample hypothesis, which is not available
here, and is not claimed. ∎

## Why this is class-killing

Statement (A) of `cd-two-torsion-quotient-counterexamples-embed-in-out` asks for no pair `(G, N)`
with:

- `G` finitely generated amenable, `cd G = 2`;
- `N ⊴ G` finitely generated;
- `G/N` infinite and torsion.

The pair `(Γ, N)` satisfies every hypothesis except amenability of `G`. It still has:

- `G/N` amenable;
- `N` finitely generated and infinite, with `cd N = 2`;
- `G` torsion-free.

So an argument that derives a contradiction from those inputs alone would also refute the
existence of `(Γ, N)`. It is therefore invalid.

The one input that separates the two situations is amenability of `N`. By Kesten–Følner for
extensions, amenability of `G` given amenable `G/N` is the same as amenability of `N`. It enters
`cd-two-torsion-quotient-counterexamples-embed-in-out` only through the EA-radical theorem
(item 1).

## On the remark and the open point

**Not `FP_2`, recalled.**

- Grigorchuk, *On the system of defining relations and the Schur multiplier of periodic groups
  generated by finite automata* (Groups St Andrews 1997, LMS Lecture Note Ser. 261, 1999), gives
  `H_2(𝔊; Z) ≅ (Z/2)^∞`. So `𝔊` is not `FP_2`. This was not re-read here.
- **Lemma.** If `G` is `FP_2` and `N ⊴ G` is finitely generated, then `G/N` is `FP_2`.
  - By Bieri–Strebel, `G = P/K` with `P` finitely presented and `K` perfect.
  - Lift generators of `N` to `n_1, …, n_k ∈ P`. Then `G/N = (P/⟨⟨n_j⟩⟩)/K̄`, where `K̄` is the
    image of `K`.
  - `K̄` is perfect, and `P/⟨⟨n_j⟩⟩` is finitely presented. So `G/N` is `FP_2`, again by
    Bieri–Strebel.
- Hence `Γ` is not `FP_2`.

**When `V = 0`.** Suppose `N` is `FP_2`.

- Then `H_1(N; U(N))` is a finitely generated projective `U(N)`-module of dimension
  `b_1^(2)(N)`.
- `b_1^(2)(N) = 0` for property (T) groups (Bekka–Valette).
- So `H_1(N; U(N)) = 0`. By flatness of induction, `V = U(Γ) ⊗_{U(N)} H_1(N; U(N)) = 0`.

Ollivier–Wise do not control finiteness properties of `N`, so this case is not decided here.

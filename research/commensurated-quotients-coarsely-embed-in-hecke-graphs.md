**ESTABLISHED (proposed, 2026-09-18; referee welcome).** Setting as in
`commensurated-witnesses-survive-browder-but-die-when-linear`: `F` free of
finite rank with basis `S`, `N ⊴ F`, `P = F/N` with the word metric from
`S`. A **commensurated witness** is a group `Λ ⊇ F` and a subgroup `Σ ≤ Λ`
commensurated by `F` with `Σ ∩ F = N`. No finiteness type, torsion-freeness
or normality is assumed. Put `C = ⟨F, Σ⟩`; `C` commensurates `Σ`.

**Hecke graph.** `Hk = Hk(C, Σ; S)` has vertex set `C/Σ`, and `xΣ` is joined
to `xtΣ` for every `t ∈ T = Σ S^{±1} Σ`. It is well defined, connected,
locally finite (the neighbours of `Σ` are `⋃_s ΣsΣ/Σ`, of size
`Σ_s [Σ : Σ ∩ sΣs^{-1}]` counted over `s ∈ S^{±1}`), and `C` acts on it by
automorphisms.

**Theorem.**

1. **Coarse embedding.** The map `φ : P -> Hk`, `fN ↦ fΣ`, is well defined,
   injective, `F`-equivariant and 1-Lipschitz. It is a coarse embedding:
   `d(φ(p), φ(q)) ≥ ρ(d_P(p, q))` with `ρ(r) = min{d(Σ, φ(p)) : |p| ≥ r}`, and
   `ρ(r) -> ∞`. In particular `|B_P(r)| ≤ |B_Hk(r)|` for every `r`.
2. **Completion.** Let `G` be the closure of `C` in `Sym(C/Σ)` and
   `K = Stab_G(Σ)`. Then `G` acts on `Hk` vertex-transitively with compact
   open stabilizers, so `Hk` is a Cayley–Abels graph of `G`, `G` is
   compactly generated, and `G` is quasi-isometric to `Hk`.
3. **General cut-outs.** For any cut-out `(H, K, ρ)` of `N` (a locally
   compact `H`, compact open `K`, `N = F ∩ ρ^{-1}(K)`), let `H_0` be the open
   subgroup generated by `K` and `ρ(S)`. Then `P` coarsely embeds in `H_0`
   (with any proper compatible left-invariant metric, e.g. its Cayley–Abels
   graph `H_0/K`).
4. **Descent of coarse invariants.** Hence `P` inherits from `Hk` (or from
   `H_0`) every property of bounded-geometry metric spaces that passes to
   subspaces under coarse embeddings: property A, finite asymptotic
   dimension (`asdim P ≤ asdim Hk`), coarse embeddability into Hilbert space
   or into `ℓ^p`, finite decomposition complexity, and growth bounds.
5. **Exactness descent (dynamical form).** If `H` is amenable at infinity
   (a topologically amenable continuous action on a compact space), then
   `P` is exact. This needs no metric.

**Consequence for `N_U`.** `P = U` contains:
- `Z^n` for every `n`, so `asdim Hk = ∞`;
- Osajda's recursively presented non-exact group
  (`recursive-residually-finite-non-exact-groups-exist`), by the Higman
  embedding, so `Hk` does not have property A and `H` is not amenable at
  infinity;
- Sapir's closed aspherical 4-manifold group, which coarsely contains an
  expander (Sapir, JAMS 27 (2014); external), so `Hk` does not coarsely
  embed in Hilbert space.

So `N_U` has **no** cut-out, and no commensurated witness of any finiteness
type, torsion or not, in a host `H` of any of the following kinds.

| Host `H` (or `H_0`) | Why it dies | Earlier kill it subsumes |
|---|---|---|
| amenable, or amenable at infinity | item 5 + Osajda | amenable kill |
| `Aut` of a locally finite tree; tree cut-outs | asdim 1 | tree kill |
| closed subgroups of `∏ GL_{d_j}(k_j)`, any local fields | exact (amenable action on `G/B`) | linear, `p`-adic, char. `p` kills |
| acting properly on a locally finite building (any type) | finite asdim (Dymara–Schick) | building kill |
| acting properly on a finite-dimensional locally finite CAT(0) cube complex | finite asdim (Wright) | cube kill |
| compactly generated Gromov-hyperbolic tdlc groups | finite asdim (Roe) | new |
| Haagerup hosts, e.g. Neretin groups `N_{d,k}` | coarse embedding in Hilbert space (Sapir) | `haagerup-cut-out-completions-force-haagerup-quotients` |
| products and extensions of the above, e.g. `SL_3(Q_p) × N_{d,k}` | CE into Hilbert space passes to finite products | new: has non-compact (T) subgroups, so the Haagerup kill misses it |

Items 1–4 and the Osajda kill are internal to the graph. The
Hilbert-space kill cites Sapir's theorem; the row entries cite standard
theorems listed in the route.

**Almost-automorphism hosts (the brief's test).** An almost-automorphism
group `AAut(Δ)` of a locally finite tree or building is a host for `N_U`
only if its Cayley–Abels graph coarsely contains `U`: it must have infinite
asymptotic dimension, no property A and no coarse embedding in Hilbert
space. For trees (Neretin) this fails (Genevois–Lonjou–Urech: Haagerup). For
right-angled and Kazhdan (`Ã_2`) buildings the three coarse properties of
`AAut(Δ)` are **open**. A closed `Aut(Δ)` with (T) inside `AAut(Δ)` defeats
the Haagerup kill but not this one. So the test "does `AAut(Δ)` contain a
compact-by-`SL_3(Z)` closed subgroup" is replaced by the sharper necessary
test "is `AAut(Δ)` coarsely non-embeddable in Hilbert space".

**Sharpness (the gate is not a kill).**
- If `Σ ⊴ C`, then `Hk` is the Cayley graph of `C/Σ` and `P ≤ C/Σ`, so item
  1 is vacuous. This is the normalized case, handled by
  `type-f-weyl-groups-have-bounded-elementary-abelian-ranks`.
- Non-discrete, torsion-free, type F pairs with non-A Hecke graphs exist.
  Take `Λ = Γ × BS(1,2)` with `Γ` Sapir's aspherical 4-manifold group and
  `Σ = 1 × ⟨a⟩`. Then `Hk = Cay(Γ) × Hk(BS(1,2), ⟨a⟩)`. It coarsely contains
  an expander, and the completion `Γ × (Q_2 ⋊ Z)` is not discrete.
- So the loophole for `N_U` is exactly a commensurated torsion-free type F
  pair whose Hecke graph coarsely contains `U`, with `N_U = Σ ∩ F`.
- `Z/2 ≀ Z` has asdim 1 and property A, and it is a cut-out in
  `Aff(F_2((t))) × Aff(F_2((1/t)))`. No host-side invariant can exclude it.
  Only the finiteness type of `(Λ, Σ)` can.

**V inside Neretin (secondary question).** `V` is Haagerup, and whether it
is exact is open (`every-cocf-group-is-exact`). So the argument of item 5 gives: if some
closed `D ≤ N_{d,k}` has a compact open normal `M` with `D/M ≅ V`, and
`N_{d,k}` is amenable at infinity, then `V` is exact. The question stays
open.

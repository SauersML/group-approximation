Fix `n >= 3`. Write `A = A(B̃_n)` and `W = W(B̃_n)`. Let `M`, `N`, `P`, `Y_m`,
`Z_m` and `f` be as in `b-tilde-artin-complement-fibres-over-configuration-space`.

**1. W acts freely on M.**
- `W` is generated by the affine reflections in the hyperplanes `u_k = c` and
  `u_i ± u_j = c`, with `c ∈ Z`. It acts on `C^n` by the same formulas.
- Suppose `w ∈ W` fixes `u = x + iy ∈ M`, with `x, y ∈ R^n`. Write
  `w(v) = w_0(v) + t` with `w_0` linear. Then `w(x) = x` and `w_0(y) = y`.
- The stabilizer `W_x` is generated by the reflections in the hyperplanes
  through `x`. This is standard for discrete affine reflection groups; see
  Bourbaki, *Lie*, Ch. V §3.
- The map `w ↦ w_0` is injective on `W_x`. Its image is the reflection group of
  the root subsystem `Φ_x = {α ∈ B_n | α(x) ∈ Z}`, which is closed under its own
  reflections because the Cartan integers are integers.
- By Steinberg's theorem, the stabilizer of `y` in that finite group is
  generated by the `s_α` with `α ∈ Φ_x` and `α(y) = 0`.
- If `w ≠ 1`, such an `α` exists. Then `α(u) = α(x) ∈ Z`, so `u` lies on a
  hyperplane of the arrangement. That is impossible for `u ∈ M`.

**2. Translations.**
- Each generating reflection has the form `u ↦ w_0(u) + v`, with `w_0` a signed
  permutation and `v ∈ D_n = {v ∈ Z^n | Σ v_i even}`:
  - `u_k = c` sends `u_k` to `2c − u_k`;
  - `u_i − u_j = c` sends `(u_i, u_j)` to `(u_j + c, u_i − c)`;
  - `u_i + u_j = c` sends `(u_i, u_j)` to `(c − u_j, c − u_i)`.
- `D_n` is invariant under signed permutations, so `W <= W(B_n) ⋉ D_n`. Both `W`
  and `Z^n` preserve `M`.
- The reflections in `u_i ∓ u_j = 0` and in `u_i ∓ u_j = 1` compose to the
  translations by `e_i ± e_j`. So the translation subgroup is
  `T = W ∩ Z^n = D_n`, and `[Z^n : T] = 2`.
- The reflections through `0` lie in `W`, so the linear-part map `W → W(B_n)` is
  onto. Its kernel is `T`, so `[W : T] = 2^n · n!`.

**3. A finite-index subgroup inside π_1(Y_(n+1)).**
- `M` is connected, being the complement of a locally finite union of complex
  hyperplanes.
- `W` acts on `M` freely and properly discontinuously by step 1; `Z^n` does so
  by translations.
- So `M/T → M/W` and `M/T → M/Z^n` are connected coverings of degrees
  `2^n · n!` and `2`.
- `M` is the full preimage of `N` under `u ↦ e^(2πiu)`, so `M/Z^n ≅ N`.
- Hence `A_T := π_1(M/T)` has index `2^n · n!` in `π_1(M/W) ≅ A`, and embeds in
  `π_1(N) ≅ π_1(P) <= π_1(P × C^×) ≅ π_1(Y_(n+1))`.

**4. The fibre group.**
- Take `m = n + 1`. The fibre `F` of `f : Y_(n+1) → Z_(n+1)` has genus
  `g = (3n−3)·2^(n−2) + 1` and `p = 3·2^(n−1)` punctures.
- So `π_1(F)` is free of rank `r = 2g + p − 1 = 3n·2^(n−1) + 1 >= 37`.
- The sequence `1 → π_1(F) → π_1(Y_(n+1)) → π_1(Z_(n+1)) → 1` is exact.
- `Conf_(n+1)(C) ≅ C × Z_(n+1)` via
  `(x_0, …, x_n) ↦ (x_0; x_1 − x_0, …, x_n − x_0)`. So
  `π_1(Z_(n+1)) ≅ P_(n+1)`, the pure braid group.

**5. The centreless-kernel embedding.**
- **Lemma.** Let `K ⊴ G` with `Z(K) = 1`. Then `g ↦ (c_g|_K, gK)` is a
  homomorphism `G → Aut(K) × G/K`, and its kernel is `K ∩ C_G(K) = Z(K) = 1`.
- A free group of rank `>= 2` is centreless, so
  `π_1(Y_(n+1)) ↪ Aut(F_r) × P_(n+1)`.

**6. Into one Aut(F_m).**
- `P_(n+1) <= B_(n+1) <= Aut(F_(n+1))`, by Artin's faithful representation.
- `Aut(F_a) × Aut(F_b) <= Aut(F_a * F_b) = Aut(F_(a+b))`, acting factorwise.
- So `A_T <= Aut(F_m)`, with `m = r + n + 1 = 3n·2^(n−1) + n + 2`.

**7. Inducing up.**
- A group with a subgroup `H` of index `k` embeds in `H ≀ S_k`
  (Krasner--Kaloujnine).
- `Aut(F_m) ≀ S_k` acts faithfully on `F_(mk) = F_m * ⋯ * F_m`, with `k` factors:
  the base group acts factorwise and `S_k` permutes the factors. So
  `Aut(F_m) ≀ S_k <= Aut(F_(mk))`.
- With `k = 2^n · n!` this gives `A <= A_T ≀ S_k <= Aut(F_M)`, where `M = mk`.
- For `n = 3`: `r = 37`, `m = 41`, `k = 48` and `M = 1968`.

**8. Permutational Boone--Higman.**
- `Aut(F_M)` satisfies the permutational property
  (`aut-free-groups-satisfy-permutational-boone-higman`).
- That property asks for an embedding in some group with a type (A) action, so
  it passes to subgroups.
- Therefore `A` has it.

**9. A finitely presented simple envelope.**
- By `type-a-action-gives-boone-higman-for-subgroups` (Zaremsky,
  arXiv:2405.18354, Corollary B), every subgroup of a group with a type (A)
  action embeds in a finitely presented simple group. So `A` embeds in one.
- This also follows directly from BFFHZ Theorem A for `Aut(F_M)`.

QED

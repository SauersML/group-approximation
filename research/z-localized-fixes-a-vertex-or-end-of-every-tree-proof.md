**Standard inputs (Serre, *Trees*, §I.6; not re-read).**
- An automorphism without inversions is elliptic or hyperbolic.
- A hyperbolic `g` has an integer translation length `ℓ(g) >= 1`, with `ℓ(g^q) = q ℓ(g)`.
- The fixed set of an elliptic element is a nonempty subtree.

**Part 1.**
- If `b = c^q`, then `ℓ(b) = q ℓ(c)` when `c` is hyperbolic, so `q <= ℓ(b)`.
- The element `a` has `q`-th roots for infinitely many `q`, so it cannot be hyperbolic, and neither can any power
  of `a`. Hence `a` is elliptic, and so is each power `a^n`.
- `A` has rank one, so every `b ∈ A` satisfies `r b = n a` for some integers `r >= 1` and `n`. A nonzero multiple of a
  hyperbolic element is hyperbolic, so `b` is elliptic too.

**Part 2.**
- Choose finitely generated subgroups `A_1 ⊆ A_2 ⊆ ...` with union `A`. For `Z[1/P]`, take `A_k = ⟨1/m_k⟩` with
  `m_k` the product of the first `k` primes of `P`.
- Each `A_k` is cyclic and generated by an elliptic element, so `S_k = Fix(A_k)` is a nonempty subtree, and
  `S_1 ⊇ S_2 ⊇ ...`.
- If `∩ S_k ≠ ∅`, then `A` fixes a vertex.
- Otherwise, a decreasing sequence of nonempty subtrees with empty intersection determines a unique end `ω`: the
  geodesics from a base vertex to `S_k` are nested and define a ray `(v_j)`, and each `S_k` contains a tail of it
  (standard; Serre, *Trees*, §I.6.5). Each `A_k` fixes `S_k` pointwise, so `A` fixes `ω`.
- Each `a ∈ A` lies in some `A_k`, so it fixes a tail `(v_j)_(j >= J)`. Hence `A = ∪_j (A ∩ Stab(v_j))`.
- The sets `A ∩ Stab(v_j)` increase, because an element fixing `v_j` and `ω` fixes the ray from `v_j` to `ω`. Any
  other ray to `ω` shares a tail with this one.

**Part 3.** Apply part 2 to the Bass–Serre tree. Vertex stabilizers are conjugates of vertex groups, and the
stabilizer of an edge `[v_j, v_(j+1)]` contains `Stab(v_j) ∩ Stab(v_(j+1)) ⊇ A ∩ Stab(v_j)`. ∎

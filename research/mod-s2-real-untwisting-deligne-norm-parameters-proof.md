Notation as in the target. Inputs:
- **[H]** `genus-two-mapping-class-group-homology-and-symplectic-quotient`: `H_1(M;Z) = Z/10`,
  `H_2(M;Z) = Z/2`, and `1 -> K -> M -> Gamma -> 1`.
- **[ST1]** from `deligne-torelli-character-counts-separating-twists`: the separating twists form one
  conjugacy class of `M`, it lies in `K`, and `K` is its normal closure. The normal closure of a single
  conjugacy class is the subgroup generated by that class, so `K` is generated by separating twists.
- **[P]** `deligne-sep7-norm-parameter-closed-subgroup`: the definitions of `b`, `c_theta` and `P_op`,
  with `U_n(e) = I`. Also, `b` is normalized (`b(e,g) = b(g,e) = 0`) and integral, and `P_op` is a
  closed subgroup of `R/Z`, so it is finite or all of `R/Z`.
- **[DTC]** `deligne-triple-cover-fd-central-invisibility`: `E_3`, the preimage of `Gamma` in the
  connected three-fold cover, has no finite-dimensional unitary representation with `rho(z) != 1`.
- **[CL]** `deligne-sep7-all-cover-mf-radical-classification`:
  `Rad_MF(E_3) = {z^k : exp(2 pi i k theta) = 1 for all theta in P_op cap (1/3)Z/Z}`.

Cochain convention: for a 1-cochain `u` with trivial coefficients, `(du)(x,y) = u(x) + u(y) - u(xy)`.

## Step 1: existence and uniqueness of f

By universal coefficients for the group `M`,

```text
H^2(M;R) = Hom(H_2(M;Z), R) (+) Ext(H_1(M;Z), R) = Hom(Z/2, R) (+) Ext(Z/10, R) = 0,
```

since `R` is torsion-free and divisible. So the real 2-cocycle `beta(m,m') = b(pi m, pi m')` equals
`df` for some `f : M -> R`. Two solutions differ by a homomorphism `M -> R`. Such a homomorphism
factors through `H_1(M;Z) = Z/10`, so it is zero. Hence `f` is unique.

## Step 2: properties of f

- *Unit.* `(df)(e,e) = f(e) = b(e,e) = 0`.
- *Additivity on K.* For `k in K`, `(df)(m,k) = b(pi m, e) = 0` and `(df)(k,m) = b(e, pi m) = 0`. So
  `f(mk) = f(m) + f(k)` and `f(km) = f(k) + f(m)`. In particular `f|_K` is a homomorphism.
- *Invariance.* Using `f(e) = 0`, `(df)(m, m^-1)` gives `f(m) + f(m^-1) = b(pi m, pi m^-1)`. Also
  `(df)(mk, m^-1)` gives `f(mk) + f(m^-1) - f(mkm^-1) = b(pi m, pi m^-1)`. Subtracting and using
  `f(mk) = f(m) + f(k)` gives `f(mkm^-1) = f(k)`.
- *Common value.* By [ST1] all separating twists are conjugate, so `f(t_s) = r` for all `s`.
- *Character.* `chi = exp(2 pi i f)` satisfies `chi(m)chi(m') chi(mm')^-1 = exp(2 pi i b) = 1`, since
  `b` is integral. So `chi` is a homomorphism `M -> T`. It factors through `Z/10`, so it takes values
  in the tenth roots of unity. Hence `exp(2 pi i r) = chi(t_s)` is a tenth root of unity, and
  `a := 10 r` is an integer. The one-dimensional representations `chi` and `chi-bar` witness `r` and
  `-r` in `Z_op`.

## Step 3: 3 does not divide a

Again by universal coefficients,
`H^2(M;Z/3) = Hom(Z/2, Z/3) (+) Ext(Z/10, Z/3) = 0`. So there is `h : M -> Z/3` with
`dh = b o (pi x pi) mod 3`. The computation of Step 2, done mod 3, gives:
- `h(e) = 0`;
- `h(mk) = h(m) + h(k)` for `k in K`;
- `h|_K` is a conjugation-invariant homomorphism.

Put `omega = exp(2 pi i/3)` and `phi = exp(2 pi i f/3) omega^(-h)`. Then

```text
phi(m) phi(m') phi(mm')^-1 = exp(2 pi i b/3) omega^(-b) = 1,
```

so `phi` is a character of `M` and takes values in the tenth roots of unity. On a separating twist,
`exp(2 pi i r/3) = phi(t_s) omega^(h(t_s))`.

Suppose `3 | a`. Then `r/3 = (a/3)/10`, so `exp(2 pi i r/3)` is a tenth root of unity. Hence
`omega^(h(t_s))` is both a tenth and a third root of unity, so `h(t_s) = 0`. By [ST1], `K` is
generated by separating twists, so `h|_K = 0`. Then `h(mk) = h(m)`, and `h` descends to
`hbar : Gamma -> Z/3` with `d hbar = b mod 3`, because `pi` is surjective.

Now let `E' = Gamma x Z/3` with product `(g,j)(g',j') = (gg', j + j' + b(g,g'))`. This is
`E_infinity/<z^3>` for the integral extension `E_infinity` of [P] and [CL], that is, `E_3`, with
`z = (e,1)`. The map `(g,j) -> omega^(j + hbar(g))` is a homomorphism, because
`b(g,g') + hbar(gg') - hbar(g) - hbar(g') = b - d hbar = 0 mod 3`. It sends `z` to `omega != 1`, which
contradicts [DTC]. So `3` does not divide `a`, and in particular `r != 0`.

Since `f|_K` is a homomorphism, `K` is generated by separating twists, and `f = r` on each of them,
`sigma = f|_K / r` is an integer-valued homomorphism `K -> Z`. For
`k = prod_j t_(s_j)^(e_j)` it gives `sigma(k) = sum_j e_j`. This proves (U1).

## Step 4: Z_op is a closed subgroup (U2)

Operations on witnesses:
- `0` is witnessed by the trivial representation;
- `-alpha` is witnessed by the complex conjugate `V_n-bar`;
- `alpha + alpha'` is witnessed by `V_n (x) V'_n`, since `||A (x) B - A' (x) B'|| <= ||A - A'|| + ||B - B'||`
  for contractions.

*Closure.* Enumerate `M = {m_1, m_2, ...}`. If `alpha_j -> alpha` with witnesses `V^(j)_n`, choose
`n_j` so that every defect on pairs among `m_1, ..., m_j` is below `1/j`, and
`||V^(j)_(n_j)(t_s) - exp(2 pi i alpha_j) I|| < 1/j`. Then `W_j = V^(j)_(n_j)` witnesses `alpha`.

## Step 5: the dictionary (U3)

`c_theta` depends only on `theta mod 1`, because `b` is integral.

**(P to Z).** Let `U_n` witness `theta mod 1` in `P_op`, and put
`V_n(m) = exp(-2 pi i theta f(m)) U_n(pi m)`. Then `V_n(e) = I`, and

```text
V_n(m)V_n(m') - V_n(mm')
  = exp(-2 pi i theta (f(m)+f(m'))) [U_n(pi m)U_n(pi m') - c_theta(pi m, pi m') U_n(pi(mm'))],
```

because `f(m) + f(m') - f(mm') = b(pi m, pi m')`. So the defects are equal pair by pair. Also
`V_n(t_s) = exp(-2 pi i theta r) U_n(e) = exp(-2 pi i theta r) I` exactly. Hence `-r theta` lies in `Z_op`.

**(Z to P).** Let `V_n` witness `alpha = -r theta mod 1` in `Z_op`, and fix a section
`s : Gamma -> M` with `s(e) = e`. Asymptotic multiplicativity gives
`||V_n(m^-1) - V_n(m)^*|| -> 0`. For a fixed `k = prod_(j <= L) m_j t_s^(e_j) m_j^-1` in `K` it
therefore gives

```text
||V_n(k) - exp(2 pi i alpha sigma(k)) I||_op -> 0.                       (Z1)
```

Put `U_n(g) = exp(2 pi i theta f(s(g))) V_n(s(g))`, so that `U_n(e) = I`. For fixed `g, h` let
`k = s(g)s(h)s(gh)^-1`, which lies in `K`. By Step 2,
`f(s(g)) + f(s(h)) = f(k s(gh)) + b(g,h) = f(k) + f(s(gh)) + b(g,h)`, and `f(k) = r sigma(k)`. Using
asymptotic multiplicativity and (Z1),

```text
U_n(g)U_n(h) ~ exp(2 pi i theta (f(k) + f(s(gh)) + b(g,h))) exp(2 pi i alpha sigma(k)) V_n(s(gh))
             = c_theta(g,h) exp(2 pi i sigma(k) (theta r + alpha)) U_n(gh),
```

with `~` meaning an `o(1)` operator-norm error. Since `theta r + alpha` is an integer and `sigma(k)`
is an integer, the extra phase is `1`. So `U_n` witnesses `theta mod 1` in `P_op`.

*Well-definedness.* Replacing `theta` by `theta + 1` changes `-r theta` by `-r`, which lies in
`Z_op` by Step 2. Since `Z_op` is a subgroup, the criterion does not depend on the lift of
`theta mod 1`. This proves (U3).

## Step 6: consequences (U4)

- *If `1/3` lies in `P_op`.* Take `theta = 1/3`. By (U3), `-a/30` lies in `Z_op`, so
  `10 * (-a/30) = -a/3` does too. Since `3` does not divide `a`, this is a primitive element of
  `(1/3)Z/Z`, so `1/3` lies in `Z_op`.
- *If `1/3` lies in `Z_op`.* Take `theta = 10/3`, which is `1/3 mod 1`. Then
  `-r theta = -a/3` lies in the subgroup generated by `1/3`, hence in `Z_op`. By (U3), `1/3` lies in `P_op`.
- *The radical.* By [CL], `Rad_MF(E_3) = C_3` iff `P_op cap (1/3)Z/Z = 0`. Since `P_op` is a subgroup,
  this holds iff `1/3 notin P_op`, hence iff `1/3 notin Z_op`. As `Z_op` is a subgroup, this says that
  neither `exp(2 pi i/3)` nor `exp(-2 pi i/3)` is a point-norm limit scalar of a separating twist.
- *Full circle.* If `P_op = R/Z`, every `alpha` equals `-r theta` for `theta = -alpha/r`, because `r != 0`,
  so `Z_op = R/Z`. Conversely, if `Z_op = R/Z`, (U3) puts every `theta` in `P_op`.
- *Finiteness.* Closed subgroups of `R/Z` are finite or everything, and [P] gives the same for `P_op`,
  so `P_op` is finite iff `Z_op` is finite.

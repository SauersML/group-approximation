**ESTABLISHED (lane bh-kd2p-2, 2026-09-19): a lane proof. Not independently reviewed.** KD2_p stays **OPEN**.
The hypothesis (V) below is stated explicitly; it holds for the Kochloukova–Sidki shape, and whether it holds
for every product Frobenius–Möbius map is a remark, not a claim.

Notation and relations as in `kms-configuration-lift-needs-non-contracting-counters` (KMS arXiv:1204.6506v5
§4.1): the configuration module `T` (abelian, written additively, with `Q` acting on the right), generated by
`x_u`, `u = q_j w`, `w` a divisor of `A_0 ⋯ A_K`; the top `Q = B_1 × ⋯ × B_K × B_0`; `B_0 = ⟨ã_i, ã_i', A_0⟩`
with counter group `U_0 = ⟨ã_i, ã_i'⟩ ≅ ℤ^{2K}` and lamp module `R_K`. Nothing below uses the machine relations
G8 beyond the fact that they are relations in `T`, so everything holds for every machine `M`, in particular
for `K = 2` and the trivial machine.

## Setting

- `H` is the domain of the virtual endomorphism `F : H → G(M)`, `U_H = H ∩ U_0`, and `A_0 ∈ H`.
- Modulo `T`, `F` induces the top map `f̄`. Its counter part `ψ = f̄|_{U_H}` takes values in `U_0`.
- **Route (A)** (`kms-lamp-mixing-dies-on-br-relation`, Step 3): `F(A_0) = f̄(A_0) ∈ R_K` and
  `F(u) = t_u·ψ(u)` for `u ∈ U_H`, with `t ∈ Z^1(U_H, T)` for the action of `U_H` on `T` through `ψ`.
- **Route (B)**: central lamp mixing, `F(A_0) = τ·f̄(A_0)` with `τ ∈ T_0`.
- `T_0 ⊆ T` is the span of the grades whose word contains `A_0`, a `Q`-submodule, and `T_{¬0} = T/T_0`.

## Lemma 1. The two module structures

**(a) `B_0` fixes `T_0` pointwise.** This is Step 1 of `kms-lamp-mixing-dies-on-br-relation` (refereed, bh-ref-g,
28f69471d1), from G5c and G2.

**(b) On `T/T_0`, each counter satisfies `ã_i − 1 = ã_i'` as an operator.**
- Let `x_u` with `A_0 ∉ u`. By G5a, `x_u = x_{q_j}·∏_{k∈w}(A_k − 1)`; the `A_k` (`k ≥ 1`) commute with each other
  and with `ã_i` (G2).
- So `x_u·ã_i = x_{q_j}·ã_i·∏(A_k − 1) = x_{q_j}·a_i·∏(A_k − 1)` by G6.
- Hence `x_u(ã_i − 1) = x_{q_j}(a_i − 1)∏(A_k − 1) = x_{q_j}·a_i'·∏(A_k − 1)` (G5b, since `q_j` lacks `A_i`)
  `= x_{q_j}·ã_i'·∏(A_k − 1)` (G6) `= x_u·ã_i'`.
- Modulo `T_0`, `A_0` acts trivially (G5a: `x_u(A_0 − 1) = x_{uA_0} ∈ T_0`), so `T/T_0` is spanned by the
  `x_u·r` with `A_0 ∉ u` and `r ∈ F_p[B_1 × ⋯ × B_K]`. Since `ã_i` commutes with `r`, the identity passes to them.

So `U_0` acts on `T/T_0` through the commutative ring `R'_K = F_p[v_i^{±1}, (v_i − 1)^{-1}]`, with `ã_i ↦ v_i`
and `ã_i' ↦ v_i − 1`. For `g = ∏ ã_i^{m_i}ã_i'^{n_i} ∈ U_0` write `τ_g = ∏ v_i^{m_i}(v_i − 1)^{n_i}`.

## Lemma 2. Vanishing of `H^*(U_H, T/T_0)`

Let `I ⊆ R'_K` be the ideal generated by `τ_{ψ(g)} − 1` for `g ∈ U_H`, and
`V_T(ψ) = { z ∈ (F̄_p ∖ {0,1})^K : τ_{ψ(g)}(z) = 1 for all g ∈ U_H }`.

**Claim.** `I · H^n(U_H, T/T_0) = 0` for every `n`. In particular, if `V_T(ψ) = ∅` then `H^n(U_H, T/T_0) = 0`.

**Proof.**
- For `g ∈ U_H`, multiplication by `ψ(g) − 1` on `M = T/T_0` commutes with the `U_H`-action, because `U_H`
  acts through the commutative ring `R'_K`. So it induces an endomorphism of `H^n(U_H, M)`.
- That endomorphism is `c(g)_* − 1`, where `c(g)_*` is the map induced by the compatible pair
  (conjugation by `g` on `U_H`, `m ↦ m·ψ(g)`). For any group and any element of it this pair induces the
  identity on cohomology, and conjugation is trivial on the abelian `U_H`. So `ψ(g) − 1` acts as `0`.
- Hence `I` annihilates `H^n`. If `V_T(ψ) = ∅`, the Nullstellensatz for the finitely generated `F_p`-algebra
  `R'_K` gives `I = R'_K`, so `1` annihilates `H^n`. ∎

**When is `τ − 1` a unit (one coordinate, `p` odd).** For `τ = v^m(v − 1)^n`, `τ − 1` is a unit of `R'_1` iff
every solution of `τ(v) = 1` lies in `{0, 1, ∞}`.
- `n = 0`: `v^m = 1` has only `v = 1` iff `m = ±p^f`.
- `m = −n`: `(v/(v − 1))^m = 1` has no finite solution iff `m = ±p^f`.
- `m = 0`: `v = 2` always solves `(v − 1)^n = 1`, so never a unit.
- `m, n, m + n` all nonzero: `τ = 1` has a finite solution off `{0, 1}`, so not a unit.

So the good single-coordinate images are `ã_j^{±p^f}` and `(ã_j ã_j'^{-1})^{±p^f}`.

**Hypothesis (V).** `V_T(ψ) = ∅`. It holds as soon as `ψ(U_H)` contains a good single-coordinate element.
- **Kochloukova–Sidki shape** (`kms-configuration-lift-needs-non-contracting-counters`, Part 2:
  `ã_1^p ↦ ã_2 ↦ ⋯ ↦ ã_K ↦ ã_1`): `ψ(ã_2) = ã_1` is good, so (V) holds.
- **Remark, not a claim.** In the product Frobenius–Möbius class of `kms-top-every-counter-cycle-must-contract`,
  the image of a domain generator is a Möbius–Frobenius image of one coordinate. For the sign-free Möbius maps
  `s ↦ s` and `s ↦ s/(s − 1)`, the image of the `ã`-type generator is good. I have not checked this against
  that node's exact parametrisation (`e_i`, `j_i`, `π`, `σ_i`), so (V) for the whole class is open.

## Theorem. Under (V), route (A) is route (B) in disguise

Assume (V).

**(i) Cohomology.** `H^1(U_H, T) ≅ Hom(U_H, T_0)`.
- From `0 → T_0 → T → T/T_0 → 0`: `H^0(U_H, T/T_0) → H^1(U_H, T_0) → H^1(U_H, T) → H^1(U_H, T/T_0)`.
- Both outer terms vanish by Lemma 2.
- `U_H` acts trivially on `T_0` (Lemma 1(a), since `ψ(U_H) ⊆ U_0`), so `H^1(U_H, T_0) = Hom(U_H, T_0)`.
- Concretely: every cocycle is `t = t' + δs` with `t' ∈ Hom(U_H, T_0)`, `s ∈ T` and `δs(u) = s(ψ(u) − 1)`.

**(ii) Conjugation.** Let `F` be a route-(A) lift with cocycle `t = t' + δs`, and put `F'' = c_s ∘ F`, the lift
conjugated by `s` (chosen with the sign convention that removes `δs`).
- **Counters:** `F''(u) = t'_u·ψ(u)`, with `t'_u ∈ T_0`.
- **The lamp `A_0`:** `F''(A_0) = f̄(A_0)·[f̄(A_0), s]`, and the commutator is `s(f̄(A_0) − 1)` up to sign. Modulo
  `T_0`, lamps of `B_0` act trivially on `T` (Lemma 1(b), second bullet), so this lies in `T_0`. Call it `τ`.
- By Lemma 1(a), `T_0` is central in `T ⋊ B_0`. So `F''(A_0) = τ·f̄(A_0)` is a **central lamp mixing**
  (route (B)), and `F''(u) = t'_u ψ(u)` is a **central counter twist**.
- Conjugating a lift by an element of `G(M)` does not change its core (bh-ref-g, 28f69471d1, review of
  `kms-lamp-mixing-dies-on-br-relation`, Step 3).

**(iii) Central counter twists are invisible on the torsion part.**
- Write `F'' = χ·F_B` on `H ∩ (T ⋊ B_0)`, where `F_B` has counter components `0` and the same lamp and `T`
  images, and `χ` is `t'` composed with the projection onto `U_H`.
- `χ` is a homomorphism into the centre of `T ⋊ B_0`, since `t'` is a homomorphism with central values. So
  `F''` and `F_B` are both homomorphisms, and they agree on the torsion part `H ∩ (T ⋊ R_K)`, where `χ = 0`.
- Hence a subgroup `N ⊆ H ∩ (T ⋊ R_K)`, normal in `G(M)`, is `F''`-invariant iff it is `F_B`-invariant.

**Conclusion.** Under (V), a route-(A) lift separates a core lying in the torsion part only if the route-(B)
lift `F_B` with `F_B(A_0) = τ f̄(A_0)`, `τ = s(f̄(A_0) − 1) ∈ T_0`, does. The counter cocycle contributes nothing
else.

**Corollary (counter-pair domains).** For domains containing a counter pair `(u, 1 − u)`, as
Kochloukova–Sidki's does, `kms-lamp-mixing-dies-on-br-relation` Step 1 (refereed PASS with scope repair) forces
`τ = 0`. Its argument uses only that the counter images conjugate lamps as elements of `B_0` do, which holds for
`F_B`. So under (V), every counter-mixed lift over such a domain is conjugate to a top-preserving lift plus a
central counter twist, and it does not separate a torsion core. **Both routes die for counter-pair domains.**

## What is left for KD2_p

- **Route (B) on power-type domains** (bh-ref-g: not excluded). With `τ` central in `T ⋊ B_0`, a lamp `b` in the
  domain goes to `F(b) = τ^{ε(b)}·f̄(b)`, where `ε` is the `U_H`-invariant character through which the
  augmentation factors in bh-ref-g's criterion (evaluation at a point `z` where all domain counters equal 1).
  At the top level the invariant subspace of the old core is
  `N = { b ∈ 𝔟 : ε(f̄^n(b)) = 0 for all n ≥ 0 }`.
  Route (B) separates the top-level core only if no nonzero invariant ideal survives these countably many
  conditions. This is the concrete question for `K = 2`; it is **not** settled here.
- **Lifts violating (V)**: `V_T(ψ) ≠ ∅`, e.g. every image counter of `ã'`-type `ã_j'^{±p^e}` (then `v_j = 2`
  is a common point). There `H^1(U_H, T/T_0)` is supported on the finite set `V_T(ψ)` and may be nonzero.
- **Mixing into other grades or into `B_1, …, B_K`** is not covered: the hypothesis `ψ(U_H) ⊆ U_0` is used in
  (i).

## Lesson

**Counter cocycles are lamp mixing in disguise.** Once some image counter `g` has `g − 1` invertible on the
configurations below `A_0`, conjugating by `T` moves all of a counter cocycle's `T`-data into one central lamp
shift `τ ∈ T_0`. So a KMS lift can only separate the top's core through the lamps, and for counter-pair domains
it cannot.

**ESTABLISHED** (lane proof below, given the cited nodes; not independently reviewed; no novelty claimed).

**Setting.** Identify `N` with the eventually-zero sequences in `{0,1}^N`, least significant digit
first, so that the 2-adic odometer `a: z -> z+1` restricts to the shift `s: n -> n+1` of `N`. Thompson's
group `V = V_(2,1)` acts on `{0,1}^N` by prefix replacements. Let `B = V_(2,1)(<a>)` with near index
`chi`, as in `odometer-prefix-groups-have-fg-index-kernels`.

1. **Genuine action.** Each `g ∈ V` maps `N` onto `N`. The restriction `rho: V -> Sym(N)` is faithful,
   and every `g != 1` has infinite support.
2. **Near group.** `R_rho = <rho(V), s>` is isomorphic to `B`, through the faithful near action of `B` on `N`.
3. **Both gates.** The shell germ group `Q_rho` and the fiber product `F_rho = R_rho ×_Z R_rho` are finitely
   presented, and the finite-window gate holds.
4. The same holds for any finitely generated `Gamma <= NearSym_0(N)` with `V <= Gamma <= ker chi`, via
   `shell-envelopes-depend-only-on-the-near-image`. For `Gamma = ker chi` the window is `N = 0`, because
   `ker chi` is normal in `B`.

**Proof.**
- (1) A replacement `w y -> w' y` sends an eventually-zero `y` to an eventually-zero sequence, and every
  eventually-zero point of the cone `w'` has this form. So `g(N) = N`. Faithfulness and infinite supports
  hold because `N` is dense and `g != 1` moves a nonempty open set.
- (2) `<V, a> = B`: with `sigma ∈ V` swapping the cones `0` and `1`, `sigma a` acts as `a` on the cone `1` and
  trivially on the cone `0`. Conjugating by `V` places `a` on any cone, and products give every prefix
  table with odometer labels. The near action of `B` on `N` is faithful
  (`odometer-prefix-groups-have-fg-index-kernels`), and it sends `a` to `s` and `V` to `rho(V)`.
- (3) `B` is of type `F_infinity`, and `ker chi` is finitely generated (same node). So
  `ker(eta) = ker chi` is itself a finitely generated `s`-invariant base, and the ascending gate of
  `shell-germ-fp-is-an-ascending-hnn-gate` holds with equality. That gate applies to genuine actions by
  item 3 of `genuine-action-shell-envelopes-generalize-the-regular-shell`, which makes `Q_rho` finitely
  presented. `F_rho` is finitely presented by `shell-germ-group-has-index-two-fiber-product`. In
  window form, `ker chi` is generated by finitely many `a^j V a^-j`, so `s^-1 V s` lies in some `W_N`.
- (4) The near group is again `B` (it contains `<V, s>`) and the same argument applies.

**Scope and meaning.** Every input reached this way embeds in `B`, which already embeds in a finitely
presented simple group. So there is no Boone–Higman content. The result shows that the germ gates are not
the obstruction for inputs that are not virtually abelian once the action is allowed to be non-regular.
The remaining content of the shell route is finite presentation of the envelope itself
(`v-binary-shell-envelope-is-finitely-presented` is the first test) and reaching inputs outside `B`.

**Conventions.**

- Right actions: `(xw)^g = x^{π_g} w^{g|_x}` and `(gh)|_v = g|_v h|_{v^g}`.
- For a word `w = s_1 ⋯ s_n` over `S`, `w|_v = s_1|_{v_1} ⋯ s_n|_{v_n}`, where `v_1 = v` and
  `v_{i+1} = v_i^{s_i}`.
- The same formula defines the image of an end `η` and the points
  `η_1 = η`, `η_{i+1} = η_i^{s_i}`.
- Enlarge `S` to `S ∪ C ∪ S^{-1} ∪ C^{-1}`. This is still finite by (F), and generates `G`,
  since `C ⊆ G` by self-similarity.
- (Ω), (E) and (F) still hold for the enlarged set, with the same `C ∪ C^{-1}`. For
  `t = c(s, η_0)` and `η ∈ Ω`, the sections of `t` along `η` are sections of `s` along an
  end of `Ω`. For inverses, `c(s^{-1}, η^s) = c(s, η)^{-1}`.
- Put `C^± = C ∪ C^{-1}`. Words are sequences of elements of the enlarged symmetric set,
  so no formal inverses occur.
- `F(C)` denotes the free group on letters `t̂`, one for each `t ∈ C^±`. For `s` in the
  enlarged set and `η ∈ Ω`, let `ĉ(s, η)` be the letter of `c(s, η)` when
  `c(s, η) ≠ 1`, and the empty word otherwise.

**Step 1 (item 1).** Let `t = c(s, η)`, with `η = v1^∞`. Choose `m` so large that
`s|_{p_m(η)} = s|_{p_{m+1}(η)} = t`, and that the `(m+1)`-st letter of `η^s` is `1`. The
second condition is possible because `η^s ∈ Ω` by (Ω).

- Since `p_{m+1}(η) = p_m(η)·1`, we have
  `p_{m+1}(η)^s = p_m(η)^s · 1^{t}`.
- This vertex is `p_{m+1}(η^s)`, whose last letter is `1`. So `1^t = 1`.
- Also `t|_1 = (s|_{p_m(η)})|_1 = s|_{p_{m+1}(η)} = t`.

So every `h ∈ H_ξ` fixes `1` and has `h|_1 = h`. The set of such `h` is a subgroup,
because `(gh)|_1 = g|_1 h|_1` when `g` fixes `1`. By induction `h|_{1^m} = h`, and `h`
fixes `ξ`. ∎

**Step 2 (stable section words).** For a word `w = s_1 ⋯ s_n` and `η ∈ Ω`, put
`W_η(w) = ĉ(s_1, η_1) ĉ(s_2, η_2) ⋯ ĉ(s_n, η_n) ∈ F(C)`. Let `ev : F(C) → G` be the
evaluation map.

- **(F1)** For all large `m`, `w|_{p_m(η)} = ev(W_η(w))` in `G`. Indeed, `p_m(η)^{s_1 ⋯ s_{i−1}} = p_m(η_i)`,
  and by (E) each factor `s_i|_{p_m(η_i)}` equals `c(s_i, η_i)` once `m` is large. In
  particular, if `w = 1` in `G`, then all its sections are trivial, so
  `W_η(w) ∈ N_H := ker(ev)`.
- **(F2)** If `W` is a word over `C^±`, then `W_ξ(W) = W`. Each letter fixes `ξ` by
  Step 1, so `η_i = ξ` for every `i`. Also `c(t, ξ) = t`, since `t|_{1^m} = t`.
- **(F3)** For fixed `w`, the set `{W_η(w) : η ∈ Ω}` is finite. Each such word has length
  at most `|w|`, and its letters come from the finite set `C^±`.

**Step 3 (the covering permutation group).** Let `Γ̃` be any quotient of `F(C)`, and write
`γ ↦ γ̄` for the quotient map. Put `Y = X* ⊔ (Ω × Γ̃)`. For `s` in the enlarged `S`, let
`ŝ` be the permutation of `Y` defined by:

- `v^ŝ = v^s` on `X*`;
- `(η, γ)^ŝ = (η^s, γ · \overline{ĉ(s, η)})` on `Ω × Γ̃`.

This is a bijection, by (Ω) and because right multiplication is invertible. Let `Ĝ` be
the group generated by the `ŝ`. It has two properties.

- `X*` is `Ĝ`-invariant, so restriction to `X*` is a homomorphism `ρ : Ĝ → G` with
  `ρ(ŝ) = s`. It is onto.
- By induction on `|w|`, `(η, γ)^{ŵ} = (η^w, γ · \overline{W_η(w)})`.

**Step 4 (item 2).** Suppose `G = ⟨S | r_1, …, r_k⟩` is a finite presentation. Any finite
presentation can be rewritten over any finite generating set.

- Let `Γ̃ = F(C) / ⟨⟨W_η(r_i) : 1 ≤ i ≤ k, η ∈ Ω⟩⟩`. By (F3) this is a finite set of
  relators.
- Each `r̂_i` is trivial on `Y`. It is trivial on `X*` since `r_i = 1` in `G`, so it fixes
  every end. On the fibre, `W_η(r_i)` dies in `Γ̃` by construction.
- Hence `s ↦ ŝ` extends to a homomorphism `φ : G → Ĝ`, which is onto.
- Since `ρ ∘ φ = id_G`, the map `φ` is also injective, and so it is an isomorphism.
- Now let `W ∈ N_H`, a word over `C^±` that is trivial in `G`. Then `φ(W) = Ŵ = 1`.
  Evaluating at `(ξ, 1)` and using (F2) gives `(ξ, \overline{W}) = (ξ, 1)`. So `W` dies
  in `Γ̃`.
- Therefore `N_H ⊆ ⟨⟨W_η(r_i)⟩⟩`. By (F1), `W_η(r_i) ∈ N_H`, so equality holds.

So `H_ξ = F(C)/N_H` is finitely presented. ∎

**Step 5 (item 3).** The action of `G` on `(X^p)*` is again self-similar and faithful, with
the same sections at vertices of length divisible by `p`. The ray `(x_1 ⋯ x_p)^∞` becomes
`ξ = y^∞` for the letter `y = x_1 ⋯ x_p`. Apply item 2. ∎

**Remarks.**

- Nothing about contraction, branching or homology is used. The only input is that
  relators of `G` have eventually constant sections along `Ω`, and that these sections are
  words in the loop letters.
- The covering group `Ĝ(F(C))` shows the obstruction is sharp in one sense. Take
  `Γ̃ = F(C)`. Then `Ĝ(F(C))` satisfies every relator `r` of `G` all of whose stable section
  words `W_η(r)` are freely trivial. A finite presentation must therefore include enough
  relators to generate `N_H` from their stable section words.

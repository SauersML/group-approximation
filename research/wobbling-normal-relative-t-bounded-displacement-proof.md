Notation as in the target. `Γ` acts on `ℓ²(Z)` by `(gf)(n) = f(g^{-1}n)`. Let `V^H` be the space of
`H`-invariant vectors and `P` the orthogonal projection onto it.

**Step 0 (normality makes `P` equivariant).** If `v ∈ V^H`, `g ∈ Γ` and `h ∈ H`, then
`hgv = g(g^{-1}hg)v = gv`. So `V^H` is `Γ`-invariant, and so is its orthogonal complement.
Hence `P` commutes with `Γ`, and for every `ξ` and `g`,
`‖g(1−P)ξ − (1−P)ξ‖ = ‖(1−P)(gξ − ξ)‖ ≤ ‖gξ − ξ‖`.

**Step 1 (distance to `V^H`).** The restriction of `ℓ²(Z)` to `(1−P)ℓ²(Z)` is a unitary
representation of `Γ` with no nonzero `H`-invariant vector. So for every nonzero `η` in it there is
`q ∈ Q` with `‖qη − η‖ ≥ ε‖η‖`. Apply this to `η = (1−P)ξ` and use Step 0:

`ε ‖ξ − Pξ‖ ≤ max_{q∈Q} ‖qξ − ξ‖`   for every `ξ ∈ ℓ²(Z)`.

**Step 2 (tent vectors).** Fix `x ∈ Z` and an integer `R ≥ D`. Put `f(y) = max(0, R − |y − x|)`
and `ξ = f/‖f‖`.
- `‖f‖² = R² + 2 Σ_{j=1}^{R−1} j² = R² + (R−1)R(2R−1)/3 = (2R³ + R)/3`.
- Let `g ∈ W(Z)` with `d(g) ≤ D`. Then `(gf − f)(y) = f(g^{-1}y) − f(y)`. Also
  `|g^{-1}y − y| = |m − g(m)| ≤ D` with `m = g^{-1}y`. Since `f` is 1-Lipschitz, `|(gf − f)(y)| ≤ D`.
  The difference vanishes unless `y` or `g^{-1}y` lies within `R − 1` of `x`, and then `y` lies in
  `(x − R − D, x + R + D)`, which has `2R + 2D − 1` integers. So `‖gf − f‖² ≤ D²(2R + 2D)`.
- Hence, for `q ∈ Q`,
  `‖qξ − ξ‖² ≤ 3D²(2R+2D)/(2R³+R) ≤ 3D²(R+D)/R³ ≤ 6D²/R²`, using `D ≤ R`.

**Step 3 (upper bound on `H`).** By Steps 1 and 2, `‖ξ − Pξ‖ ≤ √6 D/(εR)`. For `h ∈ H` we have
`hPξ = Pξ`, so
`‖hξ − ξ‖ ≤ ‖h(ξ − Pξ)‖ + ‖Pξ − ξ‖ = 2‖ξ − Pξ‖`, and hence `‖hξ − ξ‖² ≤ 24D²/(ε²R²)`.

**Step 4 (lower bound for a far move).** Suppose `h ∈ H` and `|h(x) − x| ≥ R`. Evaluate at
`y = h(x)`: `(hξ)(y) = ξ(x) = R/‖f‖`, while `ξ(y) = 0`, because `|y − x| ≥ R`. So

`‖hξ − ξ‖² ≥ R²/‖f‖² = 3R²/(2R³ + R) ≥ 1/R`,

where the last step is `3R² ≥ 2R² + 1`, true for `R ≥ 1`.

**Step 5 (conclusion, item 1).** Steps 3 and 4 give `1/R ≤ 24D²/(ε²R²)`, that is `R ≤ 24D²/ε²`.
Take `R = B = ⌊24D²/ε²⌋ + 1`. Then `R ≥ D`, because `ε ≤ 2` gives `24D²/ε² ≥ 6D² ≥ D`. (We may
assume `ε ≤ 2`: shrinking `ε` keeps `(Q, ε)` a Kazhdan pair, and `‖qξ − ξ‖ ≤ 2` always.) Since
`R > 24D²/ε²`, no `h ∈ H` and no `x` satisfy `|h(x) − x| ≥ R`. So `d(h) ≤ B − 1 < B`. The point
`x` was arbitrary, and nothing used finite generation of `Γ` or `H`.

**Step 6 (items 2 and 3).**
- Every point of `Hx` lies in `(x − B, x + B)`, so `|Hx| ≤ 2B − 1` and `Hx` lies in an interval of
  length `< 2B`.
- `H` acts faithfully on `Z`, so `h ↦ (h|_O)_O` embeds `H` in `∏_O Sym(O)`, with
  `|O| ≤ 2B − 1`. The order of each `h|_O` divides `lcm(1, …, 2B−1)`, and hence so does the
  order of `h`.
- Let `H' ≤ H` be generated by a finite set `S'`. Each restriction `H' → Sym(O)` is determined, up
  to relabelling `O` as `{1, …, |O|}`, by an element of `S_k^{S'}` with `k ≤ 2B − 1`. So only
  finitely many kernels occur. Each has finite index, and their intersection is trivial. So `H'`
  is finite.

**Step 7 (`[[X]]`).** Step 6 of `wobbling-normal-relative-t-locally-finite-proof` embeds `[[X]]` in
`W(Z)` along a dense orbit. Relative (T) and normality pass to the isomorphic image of `Γ`.

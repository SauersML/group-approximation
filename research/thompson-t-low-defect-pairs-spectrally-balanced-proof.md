Notation as in the target. `pi : G0 -> T` is the quotient map,
`N = ker pi = <<r_1, r_2, r_P>>` (normal closure in `G0`). For a word `w`
write `w_k = w(A_k, B_k)`.

## Step 0. The character simplex of T

Item 4 of `no-proper-character-groups-avoid-amenable-orbit-full-groups`
(Dudko--Medynets Theorem 3 with `R = F'`, `N(R) = T` because `T` is
simple) says that the indecomposable characters of `T` are exactly the
trivial character `1` and the regular character `delta_e`.

The set `Ch(T)` of characters (normalized positive-definite class
functions) is convex and compact in the topology of pointwise convergence.
Its extreme points are, by definition, the indecomposable characters. By
Krein--Milman, `Ch(T)` is the closed convex hull of `{1, delta_e}`, that is
the segment

    Ch(T) = { a 1 + (1-a) delta_e : a in [0,1] }.

## Step 1. The limit functional is a character of T (item 1)

Define `phi_k(w) = tau(w_k)` for words `w` in `alpha, beta`. Each `phi_k`
is a normalized positive-definite class function on `G0`, since it is the
normalized trace of a unitary representation of `G0` (exact relations
`A^4 = B^3 = 1`). Put `phi = lim_omega phi_k`, which exists because
`|phi_k| <= 1`. Pointwise limits keep the three properties, so `phi` is a
character of `G0`.

*phi is constant on cosets of N.* Let `u in N`. Write
`u = prod_(i=1)^L g_i s_i g_i^-1` with `s_i in {r_1^(+-1), r_2^(+-1), r_P^(+-1)}`
and `g_i in G0`. Unitary conjugation preserves `||. - 1||`, and
`||XY - 1|| <= ||X - 1|| + ||Y - 1||` for unitaries. So
`||u_k - 1|| <= L D(A_k,B_k) -> 0`. Then for every word `v`,

    |phi_k(uv) - phi_k(v)| = |tau((u_k - 1) v_k)| <= ||u_k - 1|| -> 0.

So `phi(uv) = phi(v)`, and `phi` descends to a character of `T`. By
Step 0 it equals `a 1 + (1-a) delta_e` for one `a in [0,1]`, which is
item 1.

## Step 2. The T-line (item 2)

`pi(alpha)` is the rotation by `1/4`, of order exactly `4` in `T`.
`pi(beta)` has order exactly `3`, since `3` is prime and `pi(beta) != e`
(`T` is not cyclic, and `alpha, beta` generate it). `pi(beta alpha)` has
order exactly `5`: `r_P = (ba)^5` holds in `T`, `5` is prime, and
`pi(ba) != e` (else `T` would be generated by `pi(alpha)` and be cyclic).

For `A` with `A^4 = 1` the eigenvalue fractions are recovered from traces
of powers:

    f_A(j) = (1/4) sum_(t=0)^3 i^(-jt) tau(A^t).

As `k -> omega`: `tau(A^0) = 1` and `tau(A^t) -> a` for `t = 1,2,3`,
because `pi(alpha)^t != e`. With `sum_(t=1)^3 i^(-jt) = 4 [j = 0] - 1`
this gives `f_A(0) -> (1+3a)/4` and `f_A(j) -> (1-a)/4` for `j != 0`. The
same computation for `B`, with `pi(beta)^t != e` for `t = 1,2`, gives
`(1+2a)/3` and `(1-a)/3`.

For `C_k = B_k A_k`, the moments are `tau(C_k^t) -> 1` if `5 | t` and
`-> a` otherwise, because `pi((ba)^t) = e` iff `5 | t`. These are the
moments of `nu = a delta_1 + (1-a) * (uniform on mu_5)`. Measures on the
circle are determined by their moments. The `C_k` are unitary, so their
spectral measures lie on the circle, and moment convergence gives weak
convergence to `nu`. ∎ (item 2)

## Step 3. Uniform gap off the line (item 3)

Suppose item 3 fails for some `S` and `eta`. Then there are pairs
`(A_k, B_k)`, of any dimensions `n_k`, with `D(A_k,B_k) < 1/k` and some
`w^(k) in S` with `|tau(w^(k)_k) - tau(A_k)| >= eta`. `S` is finite, so
one `w` occurs for infinitely many `k`. Pass to that subsequence and take
`omega` on it. Step 1 gives `lim_omega tau(w_k) = a = lim_omega tau(A_k)`,
because both `w` and `alpha` are nontrivial in `T`. This contradicts
`|tau(w_k) - tau(A_k)| >= eta`.

The fraction statement follows. The T-line is the image of `[0,1]` under
the continuous map `a -> ((1+3a)/4, (1-a)/4, ..., (1+2a)/3, (1-a)/3, ...)`.
By item 2 applied to every sequence, any `D -> 0` sequence has fractions
converging along `omega` to a point of the line. So fractions `eta`-far
from the line force `D >= c(eta) > 0`, by the same subsequence argument.
∎ (item 3)

## Step 4. Dimension count at irreducible points (item 4)

**Pairs of G0.** Let `O_A`, `O_B` be the conjugacy classes of `A`, `B` in
`U(n)`. They have real dimensions `n^2 - sum_j m_A(j)^2` and
`n^2 - sum_j m_B(j)^2`, where `m` are the eigenvalue multiplicities, since
the centralizer of `A` is `prod_j U(m_A(j))`. Up to conjugacy, the pairs
with these spectra form `O_A x O_B`, on which `PU(n)` acts by
simultaneous conjugation. At an irreducible pair the stabilizer in `PU(n)`
is trivial (Schur), so its orbit has dimension `n^2 - 1`. The orbit lies
in `O_A x O_B`, so

    (n^2 - sum m_A^2) + (n^2 - sum m_B^2) >= n^2 - 1.

Divide by `n^2`:

    1 - sum_j f_A(j)^2 - sum_j f_B(j)^2 >= -1/n^2.        (*)

Irreducible nontrivial pairs with `D -> 0` have `n_k -> infinity`. By item
1 of the criterion `delta_n > 0` for each `n`, and `delta_n` is
nonincreasing, so a bounded-dimension sequence has `D >= delta_N > 0`.
Take `omega`-limits in (*) with item 2. We have
`sum_j f_A(j)^2 -> ((1+3a)^2 + 3(1-a)^2)/16 = (1+3a^2)/4` and
`sum_j f_B(j)^2 -> ((1+2a)^2 + 2(1-a)^2)/9 = (1+2a^2)/3`. This gives

    1 - (1+3a^2)/4 - (1+2a^2)/3 >= 0,   i.e.   5/12 >= (17/12) a^2,

so `a <= sqrt(5/17)`.

**Exact representations of Delta(4,3,5).** Now `C = BA` also satisfies
`C^5 = 1`. All determinants are `1`, since `Delta(4,3,5)` is perfect. In its
abelianization `4a = 3b = 5(a+b) = 0`, so `a+b` has order dividing
`gcd(12, 5) = 1`. Then `a = -b` is killed by both `4` and `3`, so `a = 0`.
Consider

    Phi : O_A x O_B x O_C -> SU(n),   Phi(A', B', C') = B' A' C'^-1,

whose fibre over `1` is the set of exact representations with these
spectra. At a point with `BA = C`, tangent vectors are `[xi, A]`,
`[eta, B]`, `[zeta, C]` with `xi, eta, zeta in u(n)`. After right
translation to `T_1 SU(n) = su(n)`, the differential is

    dPhi = (1 - Ad_B) eta + Ad_B (1 - Ad_A) xi - (1 - Ad_C) zeta.

An `X in su(n)` orthogonal to the image for the trace form must satisfy
two conditions. From all `eta`, it satisfies `Ad_B^-1 X = X`, so
`X` commutes with `B`. From all `xi`, `Ad_B^-1 X` commutes with `A`,
hence so does `X`. So `X` lies in the commutant of `{A, B}`, which is the
scalars at an irreducible point. Since `X` is traceless, `X = 0`, and
`dPhi` is surjective.

Near an irreducible point, then, `Phi^-1(1)` is a manifold of dimension
`dim O_A + dim O_B + dim O_C - (n^2 - 1)`. `PU(n)` acts on it with trivial
stabilizer, so

    sum_(x = A,B,C) (n^2 - sum_j m_x(j)^2) >= 2(n^2 - 1).

Take the limit with item 2, using
`sum_j f_C(j)^2 -> ((1+4a)^2 + 4(1-a)^2)/25 = (1+4a^2)/5`. We get

    (1-a^2)(3/4 + 2/3 + 4/5) >= 2,   i.e.   (133/60)(1 - a^2) >= 2,

so `a^2 <= 13/133`. For exact representations the `n_k -> infinity`
step is the same, since `D` is still defined on them. ∎ (item 4)

## Step 5. Class kill (item 5)

If `tau(g_k) -> 1` along `omega` for one word `g` with `pi(g) != e`, then
Step 1 gives `a = 1`, which item 4 excludes for nontrivial irreducible
sequences.
- *Near-central pairs.* `||[A^2,B] - 1|| = ||A^2 B - B A^2||`, and
  `[alpha^2, beta] != e` in `T`: otherwise `T` would be a quotient of
  `G0 / <<r_P, [alpha^2, beta]>>`. That group is a central extension of
  `<a, b | a^2, b^3, (ba)^5> = A_5` by `<a^2>`, of order at most `2`, so
  it has order at most `120` (it is the binary icosahedral group `2I`).
  But `T` is infinite. `|tau(u) - 1| <= ||u - 1||`, so
  `tau -> 1`.
- *Trivial-heavy pairs.* `f_A(0) -> 1` gives `tau(A) -> 1`, and
  `f_B(0) -> 1` gives `tau(B) -> 1`.
- *2-norm trivial pairs.* `||A - 1||_2 -> 0` gives `tau(A) -> 1`.

∎ (item 5)

## Step 6. Sharpened criterion (item 6)

*If.* A sequence with `D -> 0` and `tau(A_k) -> 0` has `A_k != 1` for
large `k`, so the pairs are nontrivial. Then no `epsilon_0` makes every
`epsilon_0`-pair trivial, and `T` is MF by item 3 of
`thompson-t-mf-iff-opnorm-z4-z3-defect-gap-vanishes`.

*Only if.* Suppose `T` is MF. By item 3 of the criterion there are
nontrivial irreducible pairs `(A_k, B_k)` with `D_k := D(A_k,B_k) -> 0`.
By item 4, their limit weight satisfies `a <= sqrt(5/17) < 0.55`.

- *Tensor powers.* For `m >= 1` put `A_k^(m) = A_k^(tensor m)` and
  `B_k^(m) = B_k^(tensor m)`. These still satisfy `A^4 = B^3 = 1`. For
  every word, `w(A^(m), B^(m)) = w(A,B)^(tensor m)`, so
  `tau(w(A^(m), B^(m))) = tau(w(A,B))^m`. Also
  `||X^(tensor m) - 1|| <= m ||X - 1||` for unitaries `X`, by the
  telescoping bound from Step 1. So `D(A_k^(m), B_k^(m)) <= m D_k`.
- *Choice of m.* Take `m_k -> infinity` with `m_k D_k -> 0`, for example
  `m_k = max(1, floor(D_k^(-1/2)))`.
- *Limit.* Fix a word `w` with `pi(w) != e`. Along `omega`,
  `tau(w_k) -> a < 0.55`, so the set of `k` with `|tau(w_k)| < 0.6`
  belongs to `omega`. On that set `|tau(w_k)^(m_k)| < 0.6^(m_k)`, which
  tends to `0`. So the tensored sequence has `D -> 0` and
  `lim_omega tau = delta_e`.
- *A genuine sequence.* The words form a countable set, so a diagonal
  choice along `omega` extracts an honest sequence with
  `tau(w) -> 0` for every `w != e` in `T`.

Balanced spectra then follow from item 2 with `a = 0`. ∎ (item 6)

## Step 7. Spectral shape (item 7)

Let `h = sum_g c_g g` in `C[T]` with `h^* = h`. Fix word lifts `w_g`, and
put `H_k = (1/2)(X_k + X_k^*)` where `X_k = sum c_g (w_g)_k`.

- *Moments.* `H_k^p` is a fixed noncommutative polynomial in the
  `(w_g)_k` and their adjoints. By Step 1, `tau(H_k^p)` tends to the
  value of `a 1 + (1-a) delta_e` on `h^p`, that is
  `a epsilon(h)^p + (1-a) tau_L(h^p)`, where `epsilon(h) = sum c_g` and
  `tau_L` is the trace of `L(T)`.
- *Weak convergence.* `||H_k|| <= sum |c_g|` is bounded, so the spectral
  measures live on one compact interval. Moment convergence there gives
  weak convergence to `a delta_(epsilon(h)) + (1-a) mu_h`.
- *The generator Laplacian.* For `h = alpha + alpha^-1 + beta + beta^-1`,
  `epsilon(h) = 4`. By Kesten's criterion, non-amenability of `T`
  (`thompson-t-is-not-amenable`) gives `||lambda(h)|| < 4`, so `mu_h` is
  supported in `[-4, 4 - gap]`.

So the eigenvalues of `H_k` near `4` are asymptotically a fraction
exactly `a` of the spectrum. ∎ (item 7)

## Scope

- All statements except item 4 hold for any low-defect sequence, with no
  irreducibility assumption.
- Items 3 and 6 are non-effective, because they go through an ultralimit.
- Nothing here proves or refutes `thompson-t-has-full-mf-radical`. The
  content is a set of constraints that every MF model of `T` must satisfy.
  An MF model can be assumed regular in trace and balanced in spectrum.
  Families with a trivial-heavy limit are excluded as irreducible
  witnesses.

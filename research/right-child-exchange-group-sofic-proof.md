Artifact Sections 1–4. Conventions: `S[μ] = s_(μ_1)...s_(μ_k)` and `T[μ] = t_(μ_k)...t_(μ_1)`, which is the `s_μ t_ν` of
the depth-monotone artifact.

1. **Root.** `iota_A(r) = S[A]rT[A] + 1 - e_A` is an injective unital ring homomorphism with `iota_A(b_root) = b_A` and
   `iota_(A1) = iota_A ∘ iota_1`. So `Gamma_b(A) ≅ Gamma_b(root)`.
2. **Kernel.** Let `Σ = {x, y, x1, y1}`, all involutions, and `N_b = <b^j s b^-j : j in Z, s in Σ>`.
   * `b^(±1)` permutes the generators of `N_b`, and `Σ ⊆ N_b`. So `N_b` is normal, and `Gamma_b / N_b` is generated by
     the image of `b`.
   * A finite subset of `N_b` lies in `b^J Lambda_(2J) b^-J`, where `Lambda_n = <b^-j s b^j : 0 <= j <= n, s in Σ>`.
3. **Frame.** `r -> (t_i r s_j)` is an isomorphism `R -> M_2(R)`. In it `iota_1(r) = diag(1, r)`, `b = iota_1(beta)` with
   `beta = [[s_0, s_1t_1],[0,t_0]]` and `beta^-1 = [[t_0,0],[s_1t_1,s_0]]`. Moreover `y = iota_1(1 + S[0]T[1])`,
   `x1 = iota_1(x)` and `y1 = iota_1(y)`.
   * For `g = [[1,m],[0,d]]` one has `beta^-1 g beta = [[1, t_0 m t_0],[0, s_0 d t_0 + s_1t_1 + s_1t_1 m t_0]]`.
   * Induction on `j` gives the closed forms of Statement item 3; artifact Lemma 2 carries the proof.
   * `b^-j x b^j = [[1, t_0 beta^j],[0,1]] = 1 + s_0 t_0 beta^j t_1`.
4. **Weights.** Grade by `deg s_0 = (1,0)`, `deg s_1 = (0,1)` and `deg t_i = -deg s_i`. Then `R^ω_≤ = ⊕_(ω·d <= 0) R_d`,
   and `iota_1` preserves degree. Fix `n >= 1` and `ω = (1,n)`.
   * The monomials of the `y`, `x1` and `y1` conjugates have degrees `(1-2j,-1)`, `(-1-2i,0)`, `(-2j,-1)`, `(-2-2i,0)`
     and `(1,-1)`, all with `ω·d <= 0`.
   * `beta` has components with `ω·d in {1, 1-n, -1}`, so `beta^j` has `ω·d <= j`. The factor `t_1` contributes `-n`,
     so `b^-j x b^j in R^ω_≤` for `j <= n`.
   * The generators are involutions, so `Lambda_n <= (R^ω_≤)^x`.
5. **Residual finiteness.** `Lambda_n` is finitely generated. By `depth-monotone-leavitt-subalgebras-are-stably-finite`
   with `K = F_2` and letter weights `ω(0) = 1`, `ω(1) = n` (its `a` and `b`, unrelated to the element `b`), it is
   residually finite. The same claim makes `(R^ω_≤)^x` sofic, so its subgroup `Lambda_n` is sofic
   (`elek-szabo-sofic-permanence`, subgroups).
6. **Soficity.** By step 2, `N_b = ∪_J b^J Lambda_(2J) b^-J` is an ascending union of sofic subgroups, so it is sofic
   (`elek-szabo-sofic-permanence`, direct limits). `Gamma_b / N_b` is cyclic, hence amenable, and
   `sofic-kernel-amenable-quotient-permanence` makes `Gamma_b` sofic. Subgroups inherit soficity, and
   `<x,y,u,beta> ≅ iota_1(<x,y,u,beta>) = <y, x1, y1, b>`. Steps 2, 5 and 6 with `Σ` replaced by any finite symmetric
   `S`, under the hypothesis of item 4, give item 4.
7. **Consequence.** For `B` disjoint from `[A]`:
   * elements `1 - e_A + e_A r e_A` and `1 - e_B + e_B r' e_B` commute and meet trivially, so
     `H_B = Gamma_b(A) × iota_B(D_8)`;
   * `H_B` is sofic by `sofic-kernel-amenable-quotient-permanence`, since its normal subgroup `Gamma_b(A)` is sofic
     with finite quotient;
   * `b_A` has infinite order: `b^-n x b^n - 1` sends `δ_(10z)` to `δ_(0^(n+1)z)`, so these conjugates are pairwise
     distinct;
   * `sofic-subgroups-carry-independent-cylinder-defects` gives the fixed-point-free model with
     `rk(D_A D_B) = (3/8)^2`.

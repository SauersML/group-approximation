**ESTABLISHED** (proof: `subshift-compression-witnesses-unbounded-support-proof`, elementary and self-contained).

**Setting.**
- `q` is a prime power, `F = F_q`, and `(X,T)` is an infinite minimal subshift, hence a free minimal Cantor system.
- `S = LC(X,F) x_T Z`. Elements are finite sums `a = Σ_n a_n u^n` with `a_n ∈ LC(X,F)` and `u f u^(-1) = f∘T^(-1)`.
- A **(G2) witness** is a triple `(σ, R, z)` as in `simple-ring-with-centralizer-compressing-automorphism`:
  - `σ ∈ Aut(S)` and `R ⊆ S` is a finitely generated subring with `σ(R) ⊆ R`;
  - `z ∈ [S^x, S^x]` commutes with `R` but not with `σ^(-1)(R)`.
- For a finite generating set `Σ` of `R`, the **support relation** `E_R` is the equivalence relation on `X` generated by the pairs `(x, T^(-n)x)` with `g_n(x) ≠ 0` and `g ∈ Σ`.
- `E_R` is **bounded** if some `N` has `|n| ≤ N` whenever `(x, T^(-n)x) ∈ E_R`.
  - This does not depend on `Σ`: every `a ∈ R` has its support pairs in `E_R` (proof, step A1).
  - Boundedness is equivalent to `R ⊆ A_F(H)` for a compact open subgroupoid `H` of `Z x X`. The proof never uses this.

**Theorem A (bounded support kills).** If `E_R` is bounded, then `R` is finite. Hence no (G2) witness has bounded `E_R`, for any `σ`.

**Theorem B (unit powers kill).** Let `z ∈ S^x` commute with some `u^k`, `k ≠ 0`, where `T^k` is minimal. If `ind(z) = 0`, then `z ∈ F^x` is central. Here `ind: S^x → Z` is the half-orbit index homomorphism, with `ind(u) = -1`. Consequences:
- No (G2) witness has `u^k ∈ R` with `T^k` minimal.
- If `X` is totally minimal (for example Fibonacci or any Sturmian subshift), no (G2) witness has any nonzero power of `u` in `R`.

**Theorem B' (reduction for the remaining powers).** Suppose `u^k ∈ R` with `T^k` not minimal. Then the `T^k`-invariant clopen sets form a finite Boolean algebra with atoms `Y_0, ..., Y_(d-1)`, where `d | k`, `2 ≤ d ≤ |k|`, and `T` permutes the atoms cyclically. Moreover:
- `C_S(u^k) = { Σ_n a_n u^n : a_n ∈ span_F {χ_(Y_i)} } ≅ F^d x_(Z/d) Z ≅ M_d(F[t^(±1)])`, with `t` corresponding to `u^d`.
- So the root `z` of any such witness is an index-zero unit of the Laurent matrix ring `M_d(F[t^(±1)])`.

**What dies (class kill).** On the ring `S`, independently of `σ`:
- every compressed subring whose generators interact only within bounded windows of an orbit. This covers every finitely generated subring of a Kakutani–Rokhlin tower algebra, of `LC(X,F)`, or of any compact open subgroupoid algebra;
- every compressed subring containing `u^(±1)`, or `u^k` with `T^k` minimal.

In each case the step where every member dies is:
- **A:** finiteness forces `σ(R) = R`.
- **B:** the commutant of `R` inside `ker(ind)` is scalar.

**What survives.** A witness `R` must be infinite, and its support relation must have unbounded displacement. Either `R` contains no power of `u`, or it contains only powers `u^k` for which `T^k` is non-minimal, and then the root lies in `M_d(F[t^(±1)])`, where `d` is the order of a finite cyclic factor of `(X,T)`.

Notation is as in the claim. The relations used throughout are:

```text
S'S = 1,   P = 1 - SS',   P^2 = P,   PS = S - SS'S = 0,   S'P = S' - S'SS' = 0.
```

## (a) Description of C(S,S')

Let `T ∈ C(S,S')`. Then `T` commutes with `SS'`, hence with `P`, and

```text
T - Φ(T) = T - S T S' = T - T S S' = T P = P T P.
```

So `T - Φ(T) ∈ PAP`.

Conversely, suppose `T - S T S' = X` with `X ∈ PAP`, so `X = PXP`.
- *Left multiplication by `S'`.* `S'T - S'S T S' = S'T - T S'` equals `S'X = S'PXP = 0`. Hence `S'T = TS'`.
- *Right multiplication by `S`.* `TS - S T S'S = TS - ST` equals `XS = PXPS = 0`. Hence `TS = ST`.

So `T ∈ C(S,S')`.

## (b) The compression is a homomorphism

Take `T_1, T_2 ∈ C(S,S')`. Both commute with `P`, so

```text
κ(T_1 T_2) = P T_1 T_2 P = P T_1 P · P T_2 P = κ(T_1) κ(T_2).
```

The map `κ` is `k`-linear with `κ(1) = P`, the unit of `PAP`.

*Kernel.* By (a), `κ(T) = T - Φ(T)`, so `κ(T) = 0` iff `T = Φ(T)`.

*Image.* By (a), `κ(T) = (1 - Φ)(T) ∈ PAP`, so the image lies in `PAP ∩ (1 - Φ)(A)`. Conversely, let
`X ∈ PAP` with `X = T - Φ(T)` for some `T ∈ A`. By (a), `T ∈ C(S,S')`, and `κ(T) = T - Φ(T) = X`.

## (c) Detection

Let `T ∈ C(S,S')`; in particular `TS = ST`. Suppose `F(S, T) = 0` for some nonzero `F ∈ k[x, y]`. Write
`F = Σ_i x^i p_i(y)` and let `i_0` be the least `i` with `p_i ≠ 0`. Then:

```text
0 = Σ_{i >= i_0} S^i p_i(T).
```

1. *Left multiplication by `S'^(i_0)`.* Since `S'^(i_0) S^i = S^(i - i_0)` for `i >= i_0`, this gives
   `0 = Σ_{i >= i_0} S^(i - i_0) p_i(T)`.
2. *Left multiplication by `P`.* Since `P S^j = 0` for `j >= 1`, this gives `0 = P p_(i_0)(T)`.
3. *Transfer to the corner.* `P` commutes with `T`, so `P p_(i_0)(T) = P p_(i_0)(T) P = κ(p_(i_0)(T))`. By (b)
   this equals `p_(i_0)(κ(T))`, computed in `PAP` with `κ(T)^0 = P`.

So `p_(i_0)(κ(T)) = 0` with `p_(i_0) ≠ 0`, and `κ(T)` is not transcendental. Contrapositively, if `κ(T)` is
transcendental, no nonzero `F` has `F(S, T) = 0`.

## (d) The Toeplitz tensor square

**Step 1: a basis and a faithful module for J.** Using `yx = 1`, every word in `x, y` reduces to some `x^i y^j`,
so these span `J`. Let `V` have basis `e_0, e_1, ...`, with `x e_n = e_(n+1)`, `y e_n = e_(n-1)` for `n >= 1`,
and `y e_0 = 0`. Then `yx = 1` on `V`, so `V` is a `J`-module, and `x^i y^j e_n = e_(n - j + i)` if `n >= j`,
and `0` otherwise.

Suppose `a = Σ c_(ij) x^i y^j` acts as zero. Let `j_0` be the least `j` with some `c_(ij) ≠ 0`, and apply `a` to
`e_(j_0)`. The terms with `j > j_0` vanish, so `0 = Σ_i c_(i j_0) e_i`, which is impossible. Hence
`{ x^i y^j }` is a basis of `J`, and `J` acts faithfully on `V`.

**Step 2: matrix units.** Put `E_(mn) = x^m p y^n`. Now `p e_0 = e_0` and `p e_s = e_s - x y e_s = 0` for
`s >= 1`. So `E_(mn) e_r = δ_(rn) e_m`: the `E_(mn)` act as matrix units on `V`.

**Step 3: faithfulness on V ⊗ V, and an essential vector.** `J ⊗ J` has basis `x^i y^j ⊗ x^k y^l` and acts on
`V ⊗ V`. Let
`a = Σ c_(ijkl) x^i y^j ⊗ x^k y^l ≠ 0`. Choose indices as follows:
1. `j_0` is the least `j` occurring with a nonzero coefficient;
2. `l_0` is the least `l` occurring with a nonzero coefficient and `j = j_0`.

Apply `a` to `e_(j_0) ⊗ e_(l_0)`.
- Terms with `j > j_0` vanish, and so do terms with `j = j_0` and `l > l_0`.
- By minimality no other terms occur except `j = j_0, l = l_0`.

So `a(e_(j_0) ⊗ e_(l_0)) = Σ_(i,k) c_(i j_0 k l_0) e_i ⊗ e_k`, and this is nonzero because the `e_i ⊗ e_k` are
independent. In particular `J ⊗ J` acts faithfully on `V ⊗ V`.

**Step 4: every nonzero ideal contains p ⊗ p.** With `a` as in Step 3, pick `(m, n)` such that the coefficient
`γ = c_(m j_0 n l_0)` is nonzero. By Step 2 the element

```text
b = (E_(0m) ⊗ E_(0n)) · a · (E_(j_0 0) ⊗ E_(l_0 0))
```

acts on `V ⊗ V` as follows. It sends `e_0 ⊗ e_0` to `γ e_0 ⊗ e_0`, and it kills every other basis vector
`e_r ⊗ e_s`. That is also how `γ (E_(00) ⊗ E_(00)) = γ (p ⊗ p)` acts.

By faithfulness (Step 3), `b = γ (p ⊗ p)`. So `p ⊗ p` lies in the ideal generated by `a`.

**Step 5: the equivalence.**
- *From 2 to 1.* Given `S, S', R, R'` as in (d)2, the assignment `x ⊗ 1 ↦ S`, `y ⊗ 1 ↦ S'`, `1 ⊗ x ↦ R`,
  `1 ⊗ y ↦ R'` respects `yx = 1` in each factor. The images of the two factors commute, so it defines a unital
  homomorphism `f : J ⊗ J -> A`, with `f(p ⊗ p) = (1 - SS')(1 - RR') ≠ 0`. By Step 4 the kernel of `f` is an ideal
  not containing `p ⊗ p`, so it is zero.
- *From 1 to 2.* Take the images of `x ⊗ 1`, `y ⊗ 1`, `1 ⊗ x`, `1 ⊗ y`. Their defect product is the image of
  `p ⊗ p ≠ 0` under an injective map, so it is nonzero.

**Step 6: transcendence of κ(R).** `R, R' ∈ C(S,S')`, and by (b) `r = κ(R)` and `r' = κ(R')` satisfy
`r'r = κ(R'R) = P`. Moreover `P` and `Q = 1 - RR'` commute, so

```text
e := P - r r' = P - P R R' P = P (1 - RR') P = P Q.
```

This is nonzero, and it satisfies `e r = r - r r' r = 0` in `PAP`. Suppose `q(r) = Σ_(j >= j_0) c_j r^j = 0` with
`c_(j_0) ≠ 0`. Left multiplication by `r'^(j_0)` gives `Σ_j c_j r^(j - j_0) = 0`. Left multiplication by `e`
then gives `c_(j_0) e = 0`, which is a contradiction. So `κ(R)` is transcendental, and (c) makes `S` and `R`
algebraically independent. The same follows directly from 1, since `x ⊗ 1` and `1 ⊗ x` are independent in
`J ⊗ J`: the monomials `x^i ⊗ x^k` are distinct basis elements.

## (e) Leavitt consequences

**1. From L ⊗ L to J ⊗ J.** Let `f : L ⊗ L -> L` be unital, and put `S = f(s_0 ⊗ 1)`, `S' = f(t_0 ⊗ 1)`,
`R = f(1 ⊗ s_0)` and `R' = f(1 ⊗ t_0)`. These satisfy the relations of (d)2 except possibly the defect condition.
Their defect product is

```text
(1 - SS')(1 - RR') = f(s_1 t_1 ⊗ s_1 t_1) = f(s_1 ⊗ s_1) f(t_1 ⊗ t_1).
```

Now `f(t_1 ⊗ t_1) · f(s_1 ⊗ s_1) = f(1 ⊗ 1) = 1`. So the right-hand side is an idempotent `g h` with `h g = 1`,
and `g h = 0` would force `1 = h g = h g h g = h (g h) g = 0`. So the defect product is nonzero, and (d) gives a
unital embedding `J ⊗ J -> L`.

**2. From C_u to C(S,S').** Let `u` be a unit and `z ∈ C_u`, so `z` commutes with `u s_i` and with `t_i u^(-1)`
for `i = 0, 1`. This is the formula in `leavitt-endomorphism-relative-commutants-are-finite`; the commutation with
`t_i u^(-1)` is item 3 of the Relative commutants attempt on `no-unital-map-from-leavitt-tensor-square-to-leavitt-over-f2`,
reproved here as `t_i u^(-1) z = Σ_j t_i u^(-1) z u s_j t_j u^(-1) = Σ_j t_i s_j z t_j u^(-1) = z t_i u^(-1)`.

With `S = u s_0` and `S' = t_0 u^(-1)`, we get `z ∈ C(S,S')` and `P = 1 - u s_0 t_0 u^(-1) = u s_1 t_1 u^(-1)`.
Suppose `P q(z) = 0`. Since `P u s_1 = u s_1`, and `z` commutes with `u s_1` and with `t_1 u^(-1)`,

```text
0 = t_1 u^(-1) · P q(z) · u s_1 = t_1 u^(-1) u s_1 q(z) = q(z).
```

So if `z` is transcendental, then `q(κ(z)) = κ(q(z)) = P q(z) ≠ 0` for every nonzero `q`, i.e. `κ(z)` is
transcendental. ∎

## Numerical sanity check (not used in the proof)

`experiments/leavitt-toeplitz-commutant-2026-09-17/toeplitz_scout.py` computes `C(S,S')` in the boxes `(N, L) = (2, 3)`
and `(3, 4)` over `F_2`, for `S = u s_0` with eight transvection and permutation units.
- Every one gives `dim = 1`, the scalars.
- The flip unit is a control: it gives `dim = 4`, `κ` injective on the box, and every compression `c` has
  `dim span{P, c, c^2, ...} <= 2`, i.e. a relation of degree `<= 2`, as Cayley–Hamilton forces inside `M_2(F_2)`.
- The detector sees `s_0` as transcendental up to the tested degree.

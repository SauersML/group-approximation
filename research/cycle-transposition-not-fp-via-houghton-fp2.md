Words act right to left. For a word `w` of length `l` in `sigma^(+-1)` and
`tau`, let `e(w)` be its exponent sum in `sigma`. Let `w_inf` be the
permutation of `Z` given by the same word with `sigma_inf(x) = x+1` and
`tau_inf = (0 1)`.

**Step 1: the two facts from step 2 of `cycle-transposition-lef-group-proof`.**
Let `n >= 4l+5`, and let `x~` be the representative of `x in Z/n` in
`(-n/2, n/2]`.
- (F1) If `|x~| >= l+2`, then `w_n(x) = x + e(w)`.
- (F2) If `|x~| <= l+1`, then `w_n(x) = w_inf(x~) mod n`, and the integer path
  stays in `[-2l-1, 2l+1]`, which maps injectively to `Z/n`.

The same path argument gives `w_inf(x) = x + e(w)` for integers `|x| >= l+2`,
because the integer path never meets `{0,1}`.

**Step 2: the map `phi : Gamma -> Sym(Z)`, `w -> w_inf`, is a homomorphism
with kernel `L = Gamma ∩ (+)_n Sym(Z/n)`.**
- *Well defined.* Let `w` be trivial in every coordinate `n >= 4l+5`. Points of
  both kinds exist. By (F1), `e(w) ≡ 0 mod n` with `|e(w)| <= l < n`, so
  `e(w) = 0`. By (F2), `w_inf` fixes every `|x| <= l+1`. For `|x| >= l+2`,
  `w_inf(x) = x`. So `w_inf = id`.
  - In particular, a word trivial in `Gamma` has `w_inf = id`, so `phi` is well
    defined and multiplicative.
  - The same computation shows `L <= ker phi`, since an element of `L` is
    trivial in all large coordinates.
- *Kernel.* Conversely, if `w_inf = id`, then `e(w) = 0`. By (F1) and (F2),
  `w_n = 1` for every `n >= 4l+5`, so `w in L`. Hence `ker phi = L`.
- *Image.* The image is generated by `x -> x+1` and `(0 1)`. It contains all
  the conjugates `(k, k+1)`, which generate `FSym(Z)`, together with the shift.
  So it is `FSym(Z) x| <t>`.

**Step 3: `L` is locally finite and normal.** It is the intersection of
`Gamma` with the normal restricted direct sum. A finitely generated subgroup of
`(+)_n Sym(Z/n)` lies in finitely many coordinates, so it is finite.

**Step 4: conclusion.** Suppose `Gamma` is finitely presented, or merely of
type `FP_2` over `Q`. By `fp2-over-q-descends-along-locally-finite-kernels`,
`Gamma/L` is of type `FP_2` over `Q`. By Step 2, `Gamma/L` is `FSym(Z) x| Z`,
which by `houghton-h2-is-not-fp2-over-q` is not of type `FP_2` over `Q`. This
is a contradiction. `∎`

**ESTABLISHED (unreviewed).** Elementary; complete proof below.

**Setting.** `Gamma` is a group with a finite generating set `X`. It is
normally generated by a finite set `F` of words, and it is recursively
presented. Words are identified with the elements they represent when
nothing is lost. Define
- `Max(Gamma)`, the set of maximal proper normal subgroups;
- `Rad(Gamma)`, their intersection;
- `NG_Gamma`, the set of words `w` with `<<w>> = Gamma`.

A **radical poison** for `Gamma` is a computable sequence of words `w_n`
together with disjoint, recursively inseparable sets `A, B ⊆ N` such that
- `w_n ∈ Rad(Gamma)` for `n ∈ A`, and
- `w_n ∈ NG_Gamma` for `n ∈ B`.

It is a **level-one poison** if moreover `w_n = 1` for `n ∈ A`. That is the
notion killed for clean markings in
[[clean-ck-cover-separates-trivial-words-from-normal-generators]].

**Theorem.**

1. **(Recursive maximal kernels.)** For `M ∈ Max(Gamma)` the following are
   equivalent: `M` is r.e. as a set of words; `M` is recursive; `Gamma/M` is
   recursively presented on `X`. If `Gamma` is finitely presented and `M` is
   finitely normally generated, these hold.
2. **(Radical separability.)** If some `M ∈ Max(Gamma)` is r.e., then `M` is
   a recursive set of words with `Rad(Gamma) ⊆ M` and `M ∩ NG_Gamma = ∅`.
   Hence a radical poison forbids every r.e. maximal kernel. If `Gamma` is
   finitely presented, it forbids every finitely normally generated maximal
   kernel.
3. **(Transfer to a quotient.)** Let `rho : Gamma ->> Q` be surjective, with
   `Q` generated by `rho(X)` and kernel `K`. Put
   `Rad_K(Gamma) = ∩ { M ∈ Max(Gamma) : K <= M }`.
   - (a) `Rad_K(Gamma) = rho^{-1}(Rad Q)`. As sets of words,
     `NG_Gamma ⊆ NG_Q`. The r.e. maximal kernels containing `K` are exactly
     the preimages of the r.e. members of `Max(Q)`, and as word sets they are
     the same set.
   - (b) A radical poison for `Q` forbids every r.e. maximal kernel of
     `Gamma` that contains `K`. No computability of `K` is used.
   - (c) If every maximal kernel of `Gamma` contains `K`, then
     `Rad(Gamma) = rho^{-1}(Rad Q)` and `NG_Gamma = NG_Q` as word sets. So
     `Gamma` has a radical poison iff `Q` has one, and `Gamma` has an r.e.
     maximal kernel iff `Q` has an r.e. maximal normal subgroup.
   - (d) If `K` is recursive and every maximal kernel contains `K`, then `K`
     separates `Rad(Gamma)` from `NG_Gamma` iff `Rad(Q) = 1`.
4. **(Ring form for elementary groups.)** Let `U` be a unital ring, `n >= 3`,
   and `Q = E_n(U)`. For `N ∈ Max(Q)` let `J(N) = { a ∈ U : x_12(a) ∈ N }`,
   and put `BM(U) = ∩_{N ∈ Max(Q)} J(N)`. A **ring poison** is a computable
   sequence `u_n ∈ U` with recursively inseparable `A, B` such that
   `u_n ∈ BM(U)` for `n ∈ A` and `U u_n U = U` for `n ∈ B`. Then
   `w_n = x_12(u_n)` is a radical poison for `Q`.

**Application to clean Chatterji--Kassabov markings.** Take `Gamma ->> Q =
EL_4(U)` the marked Steinberg cover of [[ck-steinberg-marked-cover]] for a
clean marking.
- A ring poison in the sandwich ring `U` forbids finitely normally generated
  maximal kernels in regimes R2, R3 and R4 of [[ck-maximal-kernel-four-regimes]]
  simultaneously. If the R1 killer holds (`K` has no nonabelian simple
  quotient), it forbids all of them, and the clean hole is refuted.
- A radical poison has no WP-poisoned element in the sense of
  [[clean-ck-cover-confines-poison-to-covering-kernel]]. For `n ∈ B` the word
  `w_n` survives in the decidable group `Q`. Neither the confinement theorem
  nor the recursive kernel of `rho` excludes it unless `Rad(EL_4(U)) = 1`, by
  3(d).
- So the computability obstruction left for a clean marking is not confined to
  the covering kernel. It is a question about the maximal normal subgroups of
  `EL_4(U)`, and in its sufficient ring form about the "Brown--McCoy level
  radical" `BM(U)` of the finitely presented, decidable sandwich ring.

**Not claimed.** No radical poison or ring poison is constructed, for `U` or
for any decidable group. Separability of `Rad(Gamma)` from `NG_Gamma` is not
claimed to be sufficient for an r.e. maximal kernel.

## Proof

**Step 0 (maximal envelopes).** Every proper normal subgroup `N` of `Gamma`
lies in some `M ∈ Max(Gamma)`. The union of a chain of proper normal
subgroups containing `N` is proper: if it contained the finite set `F`, one
member would contain `F` and so equal `Gamma`. Zorn applies. Hence a word `w`
lies in `NG_Gamma` iff it lies in no maximal kernel. In particular
`Rad(Gamma) ∩ NG_Gamma = ∅` when `Gamma != 1`.

**Step 1.** Let `M ∈ Max(Gamma)` be r.e. For each word `w`, the normal
closure `<<M ∪ {w}>>` is r.e., uniformly in `w`. To enumerate it, run through
products of conjugates of elements of `M ∪ {w}` and of the r.e. relators of
`Gamma`, and reduce freely. By maximality, `w ∉ M` iff `<<M ∪ {w}>> = Gamma`
iff `F ⊆ <<M ∪ {w}>>`, which is an r.e. condition. So the complement of `M` is
r.e., and `M` is recursive.

For the presentation equivalence:
- If `M` is r.e., then `Gamma/M = <X | R ∪ M>` is a recursive presentation.
- Conversely, the trivial words of a recursively presented `<X | R'>` form an
  r.e. set, and for `Gamma/M` that set is `M`.

If `Gamma` is finitely presented and `M = <<f_1, ..., f_k>>`, then `M` is r.e.
as a normal closure of a finite set. (Equivalently, `Gamma/M` is finitely
presented by [[fp-quotient-iff-kernel-finitely-normally-generated]].)

**Step 2.** Let `M ∈ Max(Gamma)` be r.e. By Step 1, `M` is recursive. It
contains `Rad(Gamma)` by definition. It misses `NG_Gamma`, since `<<w>> <= M`
is proper for `w ∈ M`. Given a radical poison, `C = { n : w_n ∈ M }` is
recursive, contains `A` and misses `B`. This contradicts inseparability.

**Step 3.**
- *(a)* The maximal kernels of `Gamma` containing `K` are the preimages of
  the members of `Max(Q)` (correspondence theorem). A word `w` lies in
  `rho^{-1}(N)` iff `rho(w) ∈ N`, so the word sets coincide. This gives the
  statement about r.e. kernels, and taking intersections gives
  `Rad_K(Gamma) = rho^{-1}(Rad Q)`. If `<<w>> = Gamma`, then
  `<<rho(w)>> = Q`.
- *(b)* Let `M ⊇ K` be an r.e. maximal kernel and `N = rho(M) ∈ Max(Q)`.
  - For `n ∈ A`, `w_n ∈ Rad(Q) ⊆ N`, so `w_n ∈ M`.
  - For `n ∈ B`, `<<rho(w_n)>> = Q` is not contained in `N`, so `w_n ∉ M`.
  
  By Step 1 in `Gamma` (which is recursively presented), `M` is recursive, and
  `{ n : w_n ∈ M }` separates `A` from `B`.
- *(c)* If `Max(Gamma)` consists of kernels containing `K`, then
  `Rad(Gamma) = Rad_K(Gamma)`. Also `Q` is normally generated by `rho(F)`, so
  Step 0 holds in `Q`. Then
  `w ∈ NG_Gamma` iff `w` lies in no `rho^{-1}(N)` iff `rho(w)` lies in no `N`
  iff `w ∈ NG_Q`. So the defining sets of a radical poison are literally the
  same for `Gamma` and `Q`.
- *(d)* By (c), `K ⊆ rho^{-1}(Rad Q) = Rad(Gamma)`. The set `K` separates
  `Rad(Gamma)` from `NG_Gamma` iff `Rad(Gamma) ⊆ K` iff `Rad(Q) = 1`. The
  disjointness `K ∩ NG_Gamma = ∅` is automatic.

**Step 4.** The Steinberg commutator relations `[x_ij(a), x_jk(b)] = x_ik(ab)`
for distinct `i, j, k` hold in `E_n(U)`, `n >= 3`. A commutator of an element
of a normal subgroup with any element stays in that subgroup.
- *`A` side.* If `u ∈ BM(U)`, then `x_12(u) ∈ N` for every `N ∈ Max(Q)`, so
  `x_12(u) ∈ Rad(Q)`.
- *`B` side.* Let `N_0 = <<x_12(u)>>`. Then `[x_31(r), x_12(u)] = x_32(ru)` lies
  in `N_0`, and so does `[x_32(ru), x_21(s)] = x_31(rus)`. If `UuU = U`, write
  `1 = sum_k r_k u s_k`. Since `x_31` is additive, `x_31(1) ∈ N_0`. Conjugation
  by products of the `x_ij(1)` moves `x_31(1)` to every `x_ij(±1)`, and
  `[x_ij(1), x_jk(a)] = x_ik(a)` then gives every elementary generator. So
  `N_0 = E_n(U) = Q`, that is `x_12(u) ∈ NG_Q`.
- `Q` is normally generated by the single element `x_12(1)`, so Steps 0–2
  apply to `Q` (recursively presented when `U` is decidable, as for a clean
  marking).

**Application.** For a clean marking, `Gamma` is finitely presented, so 3(b)
and Step 4 give the first bullet. In the CK setting every maximal quotient
contains the infinite simple core, so it is nonabelian. The R1 killer of
[[ck-maximal-kernel-four-regimes]] then forces `K <= M` for all `M`, and 3(c)
applies. The second bullet is 3(d) together with the observation that for
`n ∈ B`, `rho(w_n) ∈ NG_Q` is nontrivial in the decidable group `Q`. ∎

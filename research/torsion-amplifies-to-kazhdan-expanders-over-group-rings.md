**Setting.** Let `G = <S>` be finitely generated, with `S` symmetric. Let
`Λ_G = EL_3(F_2[G])` be the subgroup of `GL_3(F_2[G])` generated by the
elementary matrices `e_ij(r)`, `i ≠ j`, `r in F_2[G]`. Put

```text
δ_0 = 1 / (4 · 592^2) = 1/1401856.
```

**Statement.**
1. `Λ_G` is generated by the finite set `Σ_G = { e_ij(1), e_ij(s) : i ≠ j, s in S }`.
2. For every `m >= 1`,
   `X^(δ_0)_(Λ_G, Σ_G)(max(12, 2m^2)) >= 2^(TO_(G,S)(m))`.
   Here `X^δ` and `TO` are the profiles of
   `finiteness-decidable-iff-finite-subgroup-profile-recursive`.
   The witnesses are the finite groups `EL_3(F_2[<g>])` for torsion `g`, on the
   twelve generators `e_ij(1), e_ij(g)`.
3. For `G = 2V`, the profile `X^(δ_0)_(Λ_(2V))` exceeds every recursive
   function infinitely often. If `G` has solvable word problem, so does `Λ_G`,
   which is standard: multiply matrices over `F_2[G]` and compare entries with
   the word problem of `G`.

**Reading for E.**
- *Short expanders past every recursive bound exist in a finitely generated
  group with solvable word problem, namely `Λ_(2V)`.* This removes any
  suspicion that the short-expander profile is recursively bounded for
  decision-theoretic reasons in groups with solvable word problem.
- *But they live in a Kazhdan group.* `Λ_(2V)` contains `EL_3(F_2[<g>])` for
  every `g in 2V`. For `g` of infinite order this is `EL_3(F_2[t, t^-1])`. That
  group is infinite with property (T), by the same EJZ bound, and hence not
  amenable. So the witnesses of item 2 sit inside non-amenable subgroups.
- *Non-amenability is forced.* By
  `amenable-recursive-groups-have-recursive-expander-profile`, no finitely
  generated amenable group with solvable word problem has this growth.
- *Two gates remain for the single-host route to E.* The first is host
  expansion: getting this growth inside a finitely presented simple group,
  which would follow from an embedding of `Λ_(2V)`. The second is amenable
  localization into subgroups that vary with `U`. Both are recorded on
  `fp-simple-short-expander-profiles-escape-recursive-bounds`.

title: A shared multiplicity commutator builds the hybrid predicate row on one selected type
---

Any finite Boolean truth table can be encoded by a signed-permutation
commutator.  Covariant implementers introduce one arbitrary multiplicity
commutator, but placing the same factor on both D8 roles makes the final
role-swap commutator cancel it exactly.

This robustly constructs nonlinear hybrid rows on one selected packet type.
Promotion of that selected type to one common cross-context source remains
the only alignment problem.

Notation: `K=F_2((t))`, `O=F_2[[t]]`, `L1=SL_2(F_2[t,1/t])`, `C1=SL_2(F_2[t])`,
`w=[[0,1],[1,0]]`, `u_p=e_12(p)`, `v'_p=e_21(p)`, `x=[[0,1],[t,0]]`,
`theta(g)=x g x^(-1)`.  One computes `theta([[a,b],[c,d]]) = [[d,c/t],[tb,a]]`,
so `theta` is an involution of `L1` with `theta(u_p)=v'_(tp)`.

## 1. The amalgam

`SL_2(K)` acts on its Bruhat--Tits tree without inversion and transitively
on edges.  `L1` is dense in `SL_2(K)` (it contains the elementary matrices
over the dense subring `F_2[t,1/t]`, and these generate `SL_2(K)`), and
vertex and edge stabilizers are open, so `L1` is also edge-transitive.  The
stabilizer of `v_0=[O^2]` is `L1 ∩ SL_2(O) = C1`, since
`F_2[t,1/t] ∩ O = F_2[t]`.  The matrix `x` maps `O^2` to the adjacent lattice
`O ⊕ tO`, so the stabilizer of `v_1 = x v_0` is `C1' = theta(C1)`, and the
edge stabilizer is

```text
B0 = C1 ∩ C1' = { g in C1 : g_21 in t F_2[t] }.
```

The structure theorem for a group acting on a tree with a segment as strict
fundamental domain (Serre, *Trees*, Ch. I §4) gives `L1 = C1 *_(B0) C1'`.

## 2. `B0` is generated by `V=U(F_2[t])` and `V'=theta(V)=U^-(tF_2[t])`

Let `g=[[a,b],[c,d]] in B0`.  Then `a(0)d(0)=1`, so `a(0)=1`.  Left
multiplication by `u_p` sends `a -> a+pc`, and by `v'_(tq)` sends
`c -> c+tqa`; both keep `a(0)=1` and `t | c`.  While `c != 0`: divide
`c/t = q a + r`, `deg r < deg a`, and replace `c` by `tr` (degree `<= deg a`);
then divide `a = p (tr) + r'`, `deg r' < deg(tr)`, and replace `a` by `r'`.
Every two steps `deg a` strictly drops, and when `a=1` one step makes
`c=0`.  Then `ad=1` over `F_2[t]` forces `a=d=1`, so the remaining matrix is
`u_b in V`.  Hence `g in <V,V'>`.

## 3. The directed system

Put `V_n={u_p : deg p<=n}`, `V'_n = {v'_(tq): deg q <= n-1}`,
`B0,n = <V_n,V'_n>`, and

```text
Gamma_n = C1 *_(B0,n) C1',    H_n = C1 <= Gamma_n.
```

The identity maps of the factors give `q_n: Gamma_n -> Gamma_(n+1)` and
surjections `p_n: Gamma_n -> L1`.  By §1–2, `L1` is presented by the
relations of `C1`, of `C1'`, and the identifications of the letters of
`V ∪ V'`.  Any element of `ker p_n` is a product of conjugates of finitely
many such identifications, all inside `V_N ∪ V'_N` for some `N`, so it dies
in `Gamma_N`.  Also `q_n(H_n)=H_(n+1)`, `p_n(H_n)=C1`, and the union of the
images is `C1`.  This is the data of item 3 of
`sofic-coset-actions-pass-to-marked-colimits`.

## 4. Retracting a window

Over `F_2` the units of `F_2[t]` are trivial, so Nagao reads
`C1 = S_3 *_(Z/2) V` with `S_3=SL_2(F_2)=<w,u_1>` and `Z/2=<u_1>`.  The
linear projection `V -> V_m` killing `u_(t^k)` for `k>m` fixes `u_1`, so it
extends to a retraction `r_m: C1 -> C1,m = S_3 *_(Z/2) V_m` that is the
identity on `C1,m`.  Put `r'_m = theta r_m theta: C1' -> C1',m`.

For `m>=n+1`, `B0,n` lies in both truncations: `V_n <= V_m`;
`V'_n = w (tV_(n-1)) w <= C1,m`; and `theta(B0,n) = <V'_(n+1), V_(n-1)>`
lies in `C1,m`, so `B0,n <= theta(C1,m) = C1',m`.  Both retractions are the
identity on `B0,n`, so they induce

```text
rho_m: Gamma_n -> Delta_(n,m) = C1,m *_(B0,n) C1',m ,     rho_m(C1) = C1,m.
```

## 5. Separability transfers to `Gamma_n`

Let `g_1,...,g_k in Gamma_n \ C1`.  Write each in reduced form, with
letters alternately in `C1\B0,n` and `C1'\B0,n`.  Since `g_i notin C1`, the
form is not a single letter from `C1`.  Choose `m>=n+1` so that all letters
lie in `C1,m ∪ C1',m`.  Then `rho_m` fixes every letter, the words remain
reduced in `Delta_(n,m)`, and the normal form theorem gives
`rho_m(g_i) notin C1,m`.  By `sl2-laurent-f2-amalgam-approximants-separate-the-vertex`
there is a finite-index normal `N` in `Delta_(n,m)` with
`rho_m(g_i) notin C1,m N` for all `i`.  With `N_Gamma = rho_m^(-1)(N)`, if
`g_i = c y` with `c in C1`, `y in N_Gamma`, then
`rho_m(g_i) in C1,m N`, a contradiction.  So `C1` is separable in
`Gamma_n`.

## 6. Conclusion

Item 1 makes every `Gamma_n action Gamma_n/C1` sofic, and item 3 passes
soficity to `L1 action L1/C1`.  The atlases are genuine finite actions of
the truncated amalgams.  For `L1` they are approximately multiplicative
only on each window, as co-density forces.

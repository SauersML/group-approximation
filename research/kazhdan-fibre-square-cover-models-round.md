**ESTABLISHED.**

**Setting.** `G~` is a finitely generated group with finite generating set `S`.
`N` is a normal subgroup normally generated by a finite set `M`, and `Q = G~/N`.
The **fibre square** is

```text
P = G~ x_Q G~ = {(a,b) : aN = bN}  <=  G~ x G~.
```

`P` is generated by the diagonal `Δ(S)` together with `M x {1}`.

**Theorem A (automatic fixed mass).** Suppose `P` has property (T), with a Kazhdan pair
`(K_P, κ_P)`. Let `L` be the largest word length of an element of `K_P` in the letters
`Δ(S) ∪ (M x 1)`. Let `ρ : G~ -> U(d)` be any unitary representation, and let `E` be the
projection onto `Fix_N(ρ)`. Then

```text
1 - tr_d(E)  <=  (L/κ_P)^2 · max_{m ∈ M} ||ρ(m) - 1||_2^2.                         (FS1)
```

Together with `kazhdan-cover-models-round-iff-kernel-fixed-mass-one`, §2, a sequence of models
`ρ_k∘s` pulled back from `G~` with `ρ_k(m) -> 1` for `m ∈ M` rounds **strictly**.
(For `m ∈ N` fixed, `m` is a finite product of conjugates of elements of `M^{±1}`, so
`ρ_k(m) -> 1` as well, and (KC1) of that node holds.)

**Theorem B (elementary ring covers).** Let `R` be a finitely generated associative ring with
`1`, let `I` be a two-sided ideal generated as an ideal by `x_1, ..., x_r`, and let `n >= 3`.
Put `G~ = EL_n(R)` and `N = E_n(R,I)`, the normal closure of the `e_ij(a)` with `a ∈ I`.
Then the fibre square `EL_n(R) x_{EL_n(R)/E_n(R,I)} EL_n(R)` is a quotient of
`EL_n(D)`, where

```text
D = R x_{R/I} R = {(u,v) ∈ R x R : u - v ∈ I}
```

is a finitely generated ring. So it has property (T), and (FS1) holds with
`M = {e_ij(x_l)}` and constants depending only on `(R, I, n)` and the chosen generators.

**Corollary C (split ring covers; every ring cover of SL_n(Z)).** Suppose in addition that
the quotient map `φ : R -> R/I` has a unital ring section `σ`. Then
`ker(EL_n(φ)) = E_n(R,I)`, so every model of `EL_n(R/I)` pulled back along `EL_n(φ)` rounds
strictly, with the rate (FS1).
- Every unital ring map `R -> Z` is onto and split by the unit map `Z -> R`. So for every
  finitely generated ring `R` over `Z` and every `n >= 3`, no model of
  `SL_n(Z) = EL_n(Z)` pulled back from `EL_n(R)` along `R -> Z` witnesses flexible HS
  instability.
- The same holds for the Laurent host `SL_3(F_q[t,1/t]) = EL_3(F_q[t,1/t])` along every
  augmentation of a finitely generated `F_q[t,1/t]`-algebra, for example
  `F_q[t,1/t]⟨y_1, ..., y_k⟩ -> F_q[t,1/t]`.

Derivation: `kazhdan-fibre-square-cover-models-round-proof`.

**Reading.**
- **What an instability witness at a Kazhdan cover now needs.** For a cover `G~ -> Q` with `G~`
  Kazhdan, `P ≅ N ⋊ G~` (conjugation action), and `P/(N x 1) ≅ G~`. So `P` fails (T) exactly
  when the pair `(P, N x 1)` fails relative property (T). A witness of flexible HS instability
  of `Q` pulled back from `G~` therefore needs a cover whose fibre square is **not** Kazhdan.
  - The central mechanism of `rf-kazhdan-group-not-flexibly-hs-stable` is of this kind: there
    `N` is infinite central and `P ≅ N x G~` has infinite abelianization.
  - Elementary ring covers are never of this kind (Theorem B).
  - An abelianization check does not separate the cases at `SL_3(Z)`. By the five-term sequence,
    `P^ab = N/[N,G~] x G~^ab`, and `N/[N,G~]` is finite once `H_1(G~)` and `H_2(Q)` are. Both
    are finite for every Kazhdan cover of `SL_3(Z)` (`H_2(SL_3(Z);Z)` is finite by van der
    Kallen; import, not re-read, and used only in this remark), so any surviving witness is
    invisible to abelianization.
- **Correction to a sketch.** The last bullet of `laurent-sl3-central-covers-never-witness-instability`
  argues that relative (T) of `(R^2 ⋊ EL_2(R), R^2)` forces fixed mass 1. Relative (T) controls
  the fixed space of each root subgroup `e_ij(I)` and of any fixed finite set of conjugates. It
  does not control the fixed space of their normal closure `E_n(R,I)`, which is generated by
  infinitely many conjugates. Theorem B supplies the missing uniformity: the Kazhdan pair of
  `EL_n(D)` bounds the fixed mass of the whole normal closure at once. For non-split
  `R -> F_q[t,1/t]` the theorem leaves the layer `ker(EL_3(φ))/E_3(R,I)`, which is untouched here.
- **Scope.** This does not decide `sl3-z-weakly-ucp-stable`. Models of `SL_3(Z)` that are not
  pulled back from any cover with Kazhdan fibre square, for example the restriction to
  `SL_3(Z)` of approximate representations of an ambient non-Kazhdan group, are not covered.

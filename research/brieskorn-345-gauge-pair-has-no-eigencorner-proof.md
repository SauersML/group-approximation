Notation is as in the target.  `||·||_2` is the unnormalized
Hilbert--Schmidt norm, `τ` the normalized trace of `M_N`, `rk` the rank.
`L(g) e_h = e_(gh)` on `l^2(G)`.  For a finite group `G` generated by
`α, β`, `|g|` is the word length for `Σ = {α^(±1), β^(±1)}`, so
`| |s g| - |g| | <= 1` for `s in Σ`.

**Classical, recalled.**
- (C1) Poincaré.  Since `1/3 + 1/4 + 1/5 < 1`, `Δ` is a cocompact Fuchsian
  group in `PSL_2(R)`.  In it `a`, `b` and `ba` are elliptic of orders
  exactly `4`, `3` and `5`, and it is non-elementary.  This is also
  recalled in `lifted-thompson-t-is-a-quotient-of-a-brieskorn-lattice`.
- (C2) A connected algebraic subgroup of `SL_2(C)` is either solvable or
  equal to `SL_2(C)`.
- (C3) A non-elementary Fuchsian group contains a non-abelian free group.
  So does each of its finite-index subgroups.

## Step 1: the lifted triangle group is integral

Let `Δ̃ ≤ SL_2(R)` be the full preimage of `Δ` from (C1), and let `A_0` and
`B_0` be lifts of `a` and `b`.
- Their images have orders `4` and `3`, so `A_0^4 = ±I`.  If `A_0^4 = I`,
  the eigenvalues of `A_0` are `±i` (they are not `±1`, since `A_0 != ±I`),
  so `A_0^2 = -I` and the image of `A_0` would have order `2`.  Hence
  `A_0^4 = -I`, so `-I in <A_0>`, and `<A_0, B_0> = Δ̃`.
- `Δ̃` has no common eigenvector in `C^2`.
  - A real common eigenvector gives a fixed point on `RP^1`.
  - A non-real one gives a fixed point in `H^2`.
  - Either way `Δ` would be elementary, contradicting (C1).

Let `a_0` be an eigenvalue of `A_0` with eigenvector `e_1`, and let `b_0^(-1)`
be an eigenvalue of `B_0` with eigenvector `e_2`.  They are roots of unity,
of orders dividing `8` and `6`.
- `e_1` and `e_2` are independent, since there is no common eigenvector.
- In the basis `(e_1, e_2)`, `A_0 = [[a_0, s], [0, a_0^(-1)]]` with `s != 0`,
  for otherwise `e_2` would be a common eigenvector.
- `B_0 = [[b_0, 0], [t, b_0^(-1)]]`.
- Rescale `e_1` so that `s = 1`.  Then `tr(A_0 B_0) = a_0 b_0 + t + (a_0 b_0)^(-1)`.

Now `tr(A_0 B_0)` is an eigenvalue sum of a finite-order matrix, so it is a
sum of roots of unity and an algebraic integer.  Hence `t` is an algebraic
integer.  Let `L = Q(a_0, b_0, t)`, a number field of degree `n`.  After this
conjugation,

```text
Γ := <A, B> ≤ SL_2(O_L),    A^(±1), B^(±1) in SL_2(O_L),    Γ ≅ Δ̃,    Γ/{±I} ≅ Δ.
```

**Restriction of scalars.**  Choose a `Z`-basis of `O_L ≅ Z^n`.  The regular
representation turns `M_2(O_L)` into a subring of `M_(2n)(Z)`, and `Γ` into
`Γ' ≤ GL_(2n)(Z)`, generated by the symmetric set `S = {A^(±1), B^(±1)}`.
So SGV Theorem 1 applies with `q0 = 1`.

**The Zariski closure has perfect identity component.**  Let `H` be the
Zariski closure of `Γ'` and `H°` its identity component.
- Over `C`, `L ⊗ C ≅ C^n` through the `n` embeddings `σ_j : L -> C`.  This
  conjugates `Γ'` to `{diag(σ_1(g), ..., σ_n(g)) : g in Γ}`, inside
  `prod_j SL_2(C)`.
- `Γ_0 = Γ ∩ H°` has finite index in `Γ`.  Each `σ_j` is injective, so
  `σ_j(Γ_0)` contains a non-abelian free group.  Indeed `Γ_0/{±I}` has
  finite index in `Δ`, so it contains one by (C3), and a free subgroup
  lifts.  So `σ_j(Γ_0)` is not virtually solvable.
- `pr_j(H°)` is a connected algebraic subgroup of `SL_2(C)` containing
  `σ_j(Γ_0)`.  By (C2), `pr_j(H°) = SL_2(C)`.
- So the Lie algebra `h ≤ (+)_j sl_2` of `H°` projects onto each summand.
  The radical of `h` projects to a solvable ideal of `sl_2`, which is `0`.
  So `rad(h)` lies in the intersection of the kernels, which is `0`, and `h`
  is semisimple.
- Hence `[H°, H°]`, a closed connected subgroup whose Lie algebra contains
  `[h, h] = h`, equals `H°`.  So `H°` is perfect.

**Expansion.**  By SGV Theorem 1, there is `c_0 > 0` with
`c(G(π_q(Γ'), π_q(S))) >= c_0` for all primes `q`.
- The Cayley graph has degree at most `4`.  Each vertex of Lubotzky's vertex
  boundary `∂Y` receives at most `4` edges of SGV's edge boundary.  So
  `ε >= c_0/4`.
- Inversion `g -> g^(-1)` carries the convention `y in Sx` to `y in xS`,
  since `S` is symmetric.  So the value of `ε` does not depend on the
  convention.
- `π_q(S)` has `4` distinct elements for `q >= q_1`.  Proposition 1.11 (ii)
  with `k = 4` then gives one Kazhdan constant `κ > 0` for every
  `π_q(Γ')` with respect to `π_q(S)`.

**The finite models.**  Put `G_q = π_q(Γ') / <π_q(-I)>`, a quotient of
`Γ/{±I} = Δ`, and let `α, β` be the images of `A, B`.
- A unitary representation of `G_q` with no fixed vector pulls back to one
  of `π_q(Γ')` with no fixed vector.  So `κ` is a Kazhdan constant for
  `G_q` with respect to `Σ`.
- For `1 <= k <= 3`, `A^k ∓ I` is a non-zero matrix over `O_L`.  A non-zero
  element of `O_L` lies in `q O_L` for only finitely many primes `q`, since
  its norm is a non-zero integer.  So for large `q`, `α` has order exactly
  `4`.  In the same way `β` has order exactly `3`, and `βα` has order
  exactly `5`.
- `Γ` is infinite and `⋂_q ker π_q = 1`.  So `N_q = |G_q| -> infinity`
  along the primes.

Enlarge `q_1` so that all of this holds for `q >= q_1`.  The script checks
the corresponding facts for `G = PSL_2(F_p)`, `p = 31, 41, 71, 79`: the
orders, generation, and `κ >= sqrt(2(1 - λ_2)) >= 0.31`.  Those `PSL_2(F_p)`
are quotients of `Δ` of the same kind, and they illustrate this step; the
proof does not use them.

## Step 2: a gauge field with prescribed flux

Fix `q >= q_1` and write `G = G_q`, `N = N_q`, `R = R_q`, `φ = φ_q`.
Unknowns are real phases `θ_a(g)` and `θ_b(g)`, for `g in G`.  Put

```text
X e_g = e^(i θ_a(g)) e_(αg),        Y e_g = e^(i θ_b(g)) e_(βg).
```

So `X = M_a L(α)` and `Y = M_b L(β)`, with `M_a`, `M_b` diagonal.

**Faces.**  `α`, `β` and `βα` act freely by left multiplication, with orbits
of sizes `4`, `3` and `5`.  Call these orbits a-faces, b-faces and P-faces.
There are `N/4`, `N/3` and `N/5` of them, `47N/60` in all.  Following the
basis vectors gives

```text
X^4 e_h   = e^(i Φ_a(h)) e_h,      Φ_a(h) = Σ_(j<4) θ_a(α^j h),
Y^3 e_h   = e^(i Φ_b(h)) e_h,      Φ_b(h) = Σ_(j<3) θ_b(β^j h),
(YX)^5 e_h = e^(i Φ_P(h)) e_h,     Φ_P(h) = Σ_(j<5) [θ_a(g_j) + θ_b(α g_j)],  g_j = (βα)^j h.
```

Each `Φ` depends only on the face of `h`: it is a sum over a whole orbit.
So all three are exactly diagonal.  Let `F : R^(2N) -> R^(faces)` send `θ`
to the face sums `(Φ_a, Φ_b, Φ_P)`.

**The image of `F`.**  Let `x in ker F^T`.
- Each a-edge `g` lies in the a-face of `g` and the P-face of `g`.
- Each b-edge `h` lies in the b-face of `h` and the P-face of `α^(-1) h`.

So `F^T x = 0` says the following, with `f(g) = x_P(P-face of g)`:

```text
x_a(a-face of g) = -f(g),        x_b(b-face of h) = -f(α^(-1) h).
```

- The first equation makes `f` constant on `α`-orbits: `f(αg) = f(g)`.
- The second makes `f(α^(-1) h)` constant on `β`-orbits of `h`.  With
  `g = α^(-1) h`, that is `f(α^(-1) β α g) = f(g)`.
- `f` is `βα`-invariant by definition.  So
  `f(βg) = f(βα · α^(-1) g) = f(α^(-1) g) = f(g)`.

Hence `f` is invariant under `α` and `β`, which generate `G`, so `f` is
constant.  Therefore `ker F^T` is spanned by `σ = (+1 on a- and b-faces,
-1 on P-faces)`, and

```text
im F = σ^⊥ = { c : Σ_a c + Σ_b c - Σ_P c = 0 }.
```

The script confirms `dim ker F^T = 1` exactly, by union--find with parity.

**Targets.**  Pick a vertex `v_f` in each face `f`.  Put `c_a(f) = φ(v_f)`,
`c_b(f) = φ(v_f)` and `c_P(f) = 3φ(v_f)`.
- Let `S = <σ, c>` and choose `m in Z` with `δ = S - 2πm in (-π, π]`.
- Subtract `2πm` from one a-face target.  This changes no exponential.
- Then subtract `σ_f δ / (47N/60)` from every face target.

The result `c'` lies in `σ^⊥`, so `c' = Fθ` for some `θ`.  Every
exponential `e^(i c'_f)` is within `ε = 60π / (47N)` of `e^(i c_f)`.

**Defects.**  Use `|e^(ix) - e^(iy)| <= |x - y|` and the fact that `φ` is
`π/R`-Lipschitz for the word metric.
- The a-face of `h` is `{α^j h}`, whose points are within distance `2` of
  `h`.
- The b-face of `h` is within distance `1` of `h`.
- The P-face of `h` is `{(βα)^j h : |j| <= 2}`, within distance `4` of `h`.

Hence

```text
||X^4 - D|| <= 2π/R + ε,   ||Y^3 - D|| <= π/R + ε,   ||(YX)^5 - D^3|| <= 12π/R + ε,
||X^4 - Y^3|| <= 3π/R + 2ε,          ||(YX)^5 - X^12|| <= 18π/R + 4ε.
```

For the second line, `||X^12 - D^3|| <= 3 ||X^4 - D||`.  These are the
bounds asserted by the script.

**Corona representation.**  `R_q -> infinity` and `ε_q -> 0`.  So in `Q`,
`X^4 = Y^3 = u = [(D_q)]` and `(YX)^5 = u^3 = X^12`, and `x -> X`, `y -> Y`
defines `Θ : Λ -> U(Q)` with `Θ(c) = u`.
- `φ(e) = π`, so `||D_q - 1|| = 2` and `||u - 1|| = 2`.
- `sp(D_q) = {e^(iπ(1 - j/R))}`, for `0 <= j <= R`.  Every distance up to
  `R` occurs, because `|B_R| < N`.  The mesh `π/R -> 0`, so `sp(u)` is the
  whole arc `{e^(iθ) : 0 <= θ <= π}`.

**The weight.**  Put `w = |D - 1|^2`, so `0 <= w <= 4`.  It is supported on
the ball of radius `R - 1`, which has at most `Σ_(j<R) 4^j < 4^R <= N^(1/2)`
points.  So

```text
τ(w) <= 4 N^(-1/2) -> 0.                                          (1)
```

## Step 3: the modulus vector of an almost commuting projection is flat

This step does not use that the phases come from `u`.  That is the
difference from `torus-knot-k34-expander-pair-has-no-eigencorner-proof`.
There, `P` was first moved to commute with `L(α)`, `L(β)` through `D = g(u)`;
here `D` is not a function of `u`.

Let `P` be a projection in `M_N` of rank `r >= 1`, with
`||[P, X]||, ||[P, Y]|| <= η`.  Put `s in R^G`, `s_h = ||P e_h||`, so
`||s||_2^2 = tr P = r`.
- **Almost invariance.**  `X e_g` is a unimodular multiple of `e_(αg)`.  So
  `s_(αg) = ||P X e_g||` and `s_g = ||X P e_g||`, and hence
  `|s_(αg) - s_g| <= ||[P, X] e_g||`.  Summing squares over `g`,

  ```text
  ||L(α) s - s||_2 <= ||[P, X]||_2 <= (2r)^(1/2) η,
  ```

  because `[P, X]` has rank at most `2r`.  The same holds for `β` and `Y`.
  `L(s^(-1)) v - v = -L(s^(-1))(L(s) v - v)` gives the same bound for
  `α^(-1)` and `β^(-1)`.
- **Gap.**  Write `s = s̄ 1 + s_0` with `s_0 ⊥ 1`.  The left-regular
  representation on `1^⊥` has no non-zero fixed vector, and it fixes `1`.
  So Definition 1.9 with the constant `κ` of Step 1 gives

  ```text
  κ ||s_0||_2 <= max_(σ in Σ) ||L(σ) s - s||_2 <= (2r)^(1/2) η.
  ```

- **Diagonal of a weight.**  For diagonal `w >= 0`,
  `tr(P w P) = Σ_h w_h <P e_h, e_h> = ||w^(1/2) s||_2^2`.  Also
  `|s̄| <= ||s||_2 / N^(1/2) = (r/N)^(1/2)` and `||w||_∞ <= 4`.  Hence

  ```text
  tr(P w P)^(1/2) <= |s̄| (N τ(w))^(1/2) + 2 ||s_0||_2
                  <= r^(1/2) τ(w)^(1/2) + 2 (2r)^(1/2) η / κ,
  ( tr(P w P) / r )^(1/2) <= τ(w)^(1/2) + 2 sqrt(2) η / κ.                 (2)
  ```

  The constant is independent of `q` and `r`.

## Step 4: no eigencorner

Let `P in {X, Y}' ∩ Q` be a nonzero projection with `||(u - λ) P|| <= ε'`.
The case `ε' = 0` is an exact eigencorner.
- Lift `P` to projections `P_q`.  Then
  `η_q = max(||[P_q, X_q]||, ||[P_q, Y_q]||) -> 0`.
  `limsup ||(D_q - λ) P_q|| <= ε'`, because `D_q` lifts `u`.
  `P_q != 0` for infinitely many `q`, because `||P|| = 1`.
- Along those `q`, put `r = rk P_q`.  Then
  `||(D_q - 1) P_q||_2 >= |λ - 1| r^(1/2) - ||(D_q - λ) P_q||_2`.  Also
  `||(D_q - λ) P_q||_2 <= r^(1/2) ||(D_q - λ) P_q||`.  And
  `||(D_q - 1) P_q||_2^2 = tr(P_q w_q P_q)`.  So

  ```text
  |λ - 1| - ||(D_q - λ) P_q|| <= ( tr(P_q w_q P_q) / r )^(1/2).
  ```

- By (2) and (1), the right side is at most
  `2 N_q^(-1/4) + 2 sqrt(2) η_q / κ -> 0`.

Hence `|λ - 1| <= ε'`.  With `ε' = 0` this gives `λ = 1`, which is the
claim.  Running the same estimate with a fixed `η` gives the quantitative
form `|λ - 1| <= ε' + 2 sqrt(2) η / κ` stated in the target.  ∎

## Remarks

- **What the proof uses.**
  - `Θ(c)` is realised by exactly diagonal matrices `D_q` in the permutation
    basis, with `τ(|D_q - 1|^2) -> 0`.
  - `X_q` and `Y_q` are unimodular multiples of permutation matrices whose
    permutation group has a uniform Kazhdan constant.

  The flux data enter only through the existence of `Θ`.
- **Why the flux is balanced.**  The obstruction to `F θ = c` is the single
  number `<σ, c>`.  It is of order `N · (1/4 + 1/3 - 3/5) = -N/60` times the
  average of `φ`, which is the Euler number `-1/60` of `Σ(3,4,5)` over
  `S^2(3,4,5)`.  It is not zero, but it only needs to vanish modulo `2π`.
  Spreading the remainder over the `47N/60` faces costs `O(1/N)` per face.
  This is where perfectness of `Λ` is bypassed.  A single diagonal `D`
  cannot carry the flux, as the scalar ansatz shows, but a gauge field can.
- **Descent to `T̄` fails.**  The script checks that the Thompson relator
  `[βαβ, α^2 βαβ α^2]` is non-trivial in `PSL_2(F_p)`.  So it is
  non-trivial in `Δ`, and its lift is not `±I` in `Γ`.  For large `q` it is
  then non-trivial in `G_q`.  Its word in `X_q, Y_q` is a phase-weighted
  permutation with no fixed point, so it is at distance at least `1` from
  `1`.

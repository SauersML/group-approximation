## Source

Kourovka Notebook, 21st issue (2026), Problem **21.74** (S. Kohl), verbatim: "Is it
algorithmically decidable whether a given element `g ∈ CT(Z)` (a) permutes a nontrivial
partition of `Z` into residue classes? (b) has only finite cycles? (c) has no finite
cycles?"

Parts (b) and (c) are undecidable by `ct-z-finite-cycle-problems-are-undecidable`
(bh-free-58). This node is about (a).

## Conventions

- `Ẑ` is the profinite integers. A *box* is the closure `r + mẐ` of a residue class
  `r(m)`.
- Two classes meet iff their boxes meet, and a nonempty intersection of classes is a class
  (CRT). Every clopen subset of `Ẑ` is a finite disjoint union of boxes.
- By `ct-p-z-is-a-one-vertex-k-graph-full-group` (item 3, applied to `CT_P(Z)` for finite
  `P`, whose union is `CT(Z)`), `CT(Z)` is exactly the set of permutations of `Z` that are
  piecewise canonical (`r + tm ↦ s + tn`) with respect to two partitions of `Z` into finitely
  many residue classes.
- Each `g ∈ CT(Z)` extends to a homeomorphism `ĝ` of `Ẑ`, given by the same affine formulas.
  Since `Z` is dense and boxes are clopen, `g` permutes a residue-class partition iff `ĝ`
  permutes the partition of `Ẑ` into the corresponding boxes.
- Say `g` is **YES** if it permutes a partition of `Z` into at least two residue classes.

## Results

**Theorem 1 (YES is r.e.).** Given `g` and a finite residue-class partition `𝒫`, it is
decidable whether `g` permutes `𝒫`. Hence the set of YES elements is recursively enumerable.

*Proof.*
- `g` is affine and injective on each class mod `m = Mod(g)`.
- The image of a class `r(d)` under an injective affine map `n ↦ (an + b)/c` is the class
  with difference `|ad/c|`. That difference is a nonzero integer, because consecutive terms
  are integers.
- So for `U ∈ 𝒫`, `g(U)` is an explicit finite union of classes. Equality of two finite
  unions of classes is checked mod the lcm of their moduli.
- Enumerate all finite residue-class partitions. ∎

**Theorem 2 (finite order ⇒ YES).** Every `g ∈ CT(Z)` of finite order is YES. This includes
`g = 1`, which permutes `{0(2), 1(2)}`.

*Proof.*
- Let `g^N = 1`, and let `D` be an even common multiple of `Mod(g^j)` for `j < N`.
- Let `𝒫_D` be the partition into the `D` classes mod `D`. Since `g^j` is affine on each of
  them, `g^j(𝒫_D)` is again a residue-class partition (proof of Theorem 1).
- Let `𝒬` be the common refinement of `𝒫_D, g(𝒫_D), …, g^{N−1}(𝒫_D)`. Its parts are
  nonempty intersections of classes, hence classes.
- `g` maps `g^j(𝒫_D)` onto `g^{j+1}(𝒫_D)`, and `g^N(𝒫_D) = 𝒫_D`. So `g` maps each atom
  `⋂_j U_j` onto the atom `⋂_j g(U_j)`, i.e., `g` permutes `𝒬`.
- `𝒬` refines `𝒫_D`, so it has at least `D ≥ 2` parts. ∎

**Theorem 3 (clopen straightening: the conjugacy closure of YES).** For `g ∈ CT(Z)` the
following are equivalent.
1. `g` is conjugate in `CT(Z)` to a YES element.
2. `ĝ` permutes a partition of `Ẑ` into at least two clopen sets.
3. For some `k ≥ 1`, `ĝ^k` leaves invariant a clopen set `W` with `∅ ≠ W ≠ Ẑ`.

*Proof.*
- **1 ⇒ 2.** If `cgc^{-1}` permutes boxes `B_i`, then `ĝ` permutes the sets `ĉ^{-1}(B_i)`.
- **2 ⇒ 3.** Take `k = n!`.
- **3 ⇒ 2.** The Boolean algebra generated by `W, ĝW, …, ĝ^{k−1}W` is finite and
  `ĝ`-invariant. So `ĝ` permutes its atoms, and there are at least two of them.
- **2 ⇒ 1.**
  - Let `ĝ` permute `W_1, …, W_n` (`n ≥ 2`), and write `W_i` as a disjoint union of `a_i`
    boxes.
  - Pick any box partition `B_1, …, B_n` of `Ẑ`, and split each `B_i` into `a_i` boxes by
    2-digits.
  - Let `ĉ` map the `j`-th box of `W_i` canonically onto the `j`-th box of `B_i`. Then `ĉ`
    maps `Z` onto `Z` and is piecewise canonical, so `c = ĉ|_Z ∈ CT(Z)` by the convention
    above.
  - `cgc^{-1}` permutes the classes `B_i ∩ Z`. ∎

Property 3 is a conjugacy invariant of the homeomorphism `ĝ`. It says that `ĝ` is not
*totally clopen-indecomposable*. Like YES, it is r.e.

**Theorem 4 (a NO criterion for `CT_∅(Z)`).**
- **Setup.** Let `g ∈ CT_∅(Z)`, so all moduli are powers of 2. Write `Ẑ = Z_2 × Ẑ_odd`.
  - On a piece `r(2^α) → s(2^β)`, `ĝ(a, c) = (g_2(a), F(c))`, with
    `F(c) = 2^{β−α}c + (s − 2^{β−α}r)`.
  - The 2-adic coordinate therefore evolves autonomously under a homeomorphism `g_2` of
    `Z_2`.
- **Hypotheses.** Suppose:
  - **(A)** `g_2` has fixed points `α_1, …, α_r` with basins
    `Bas_i = {a : g_2^n(a) → α_i}` whose union is dense in `Z_2`, and the only ball of `Z_2`
    containing any `Bas_i` is `Z_2` itself;
  - **(B)** for two pieces `P, Q`, the composite `F_Q^{-1} F_P` is a translation
    `c ↦ c + u` with `u = ±2^j`.
- **Conclusion.** Then `g` is not YES.

*Proof.*
1. **The 2-adic part of each class is `Z_2`.**
   - Let `g` permute a partition into classes `U = U_2 × U_odd` (a ball times a box), and let
     `k` be the order of the induced permutation.
   - A nonempty open `U_2` meets some `Bas_i`. The `g^k`-orbit of a point of `U` stays in
     `U`, and its 2-adic coordinates tend to `α_i`. Since `U_2` is closed, `α_i ∈ U_2`.
   - Fix `c ∈ Ẑ_odd`. The classes with `c ∈ U_odd` have disjoint `U_2`'s covering `Z_2`.
   - If one of them has `α_i ∈ U_2`, it contains every `(b, c)` with `b ∈ Bas_i`. Indeed,
     the class through `(b, c)` also has `α_i` in its 2-adic part, so both classes contain
     `(α_i, c)`, and they coincide.
   - So `U_2 ⊇ Bas_i`, and `U_2 = Z_2` by (A).
   - Every class of the partition therefore has the form `Z_2 × C_i`, with odd modulus.
2. **The odd parts are invariant under a translation.**
   - A piece `P` has an open 2-adic image. So `F_P(C_i) ⊆ C_{π(i)}` for every `i`.
   - `F_P` is a bijection and `π` is a permutation, so `F_P(C_i) = C_{π(i)}`, with the same
     `π` for every piece.
   - By (B), each `C_i` is invariant under `c ↦ c + u`.
3. **Conclusion.** `uZ` is dense in `Ẑ_odd`, so the closed set `C_i` is all of `Ẑ_odd`. The
   partition is trivial. ∎

`ψ` itself (`ct-z-north-south-element-has-no-finite-cycles`, item 2) has this shape: there
the odd-modulus step is a congruence computation.

**Theorem 5 (YES is not a conjugacy invariant, even in `CT_∅(Z) ≅ V`).**
- **The elements.** Let `ψ`, `ψ_{0(2)}` and `ψ_{1(2)}` be as in
  `ct-z-north-south-element-has-no-finite-cycles`, and put `c = τ_{1(4),2(4)}`. Define
  - `h = ψ_{0(2)} ψ_{1(2)}` (ten class transpositions);
  - `g = c h c` (twelve).
- **The claim.** `h` permutes `{0(2), 1(2)}`, so it is YES. Its conjugate `g` is not YES.

*Proof that `g` is not YES.* This checks the hypotheses of Theorem 4.
- **The pieces of `g`.**
  - `c` maps `0(2)` onto `A = 0(4) ∪ 1(4)` and `1(2)` onto `B = 2(4) ∪ 3(4)`.
  - So `ĝ` restricted to `Â` is `φψ̂φ^{-1}`, with `φ(a) = 2a` (`a` even) and `2a − 1`
    (`a` odd).
  - Likewise `ĝ` restricted to `B̂` is `φ'ψ̂φ'^{-1}`, with `φ'(a) = 2a + 2` (`a` even) and
    `2a + 1` (`a` odd).
- **(A).**
  - By item 2 of that node, `ψ̂` on `Z_2` has the fixed point `−2/3`, which attracts every
    point except `−1/3`.
  - So `g_2` has attracting fixed points `φ(−2/3) ∈ A_2` and `φ'(−2/3) ∈ B_2`, whose basins
    are `A_2` and `B_2` minus one point each.
  - A ball containing the first basin contains residues `0` and `1` mod 4, and a ball
    containing the second contains residues `2` and `3`. Either way the ball is `Z_2`.
- **(B).**
  - On `0(4)`: `z = 2n` with `n` even, so `ψ(n) = 4n + 2`, and `c` fixes the image. Hence
    `g(z) = 4z + 4`.
  - On `5(8)`: `c(z) = z + 1 = 2n` with `n ∈ 3(4)`, so `ψ(n) = 4n + 2`, and `c` fixes
    `2ψ(n) ∈ 0(4)`. Hence `g(z) = 4z + 8`.
  - Spot checks: `g(0) = 4` and `g(5) = 28`.
  - `F_2^{-1}F_1(c) = (4c + 4 − 8)/4 = c − 1`, so `u = −1`. ∎

## What this says about 21.74(a)

- **Two layers.** (a) splits into a dynamical layer and a coordinate layer.
  - The **dynamical layer** is property 3 of Theorem 3. It is conjugacy-invariant and r.e.
  - The **coordinate layer** asks whether the invariant clopen structure can be chosen to
    consist of boxes. Theorem 5 shows this layer is real: `h` and `g` are the same dynamical
    system, yet one is YES and the other is not.
- **Consequence.** No conjugacy invariant decides (a). So a solution of 21.73 (conjugacy in
  `CT(Z)`) would not by itself settle (a).
- **A source of property 3.** Let `n ∈ Z` lie on a finite cycle of length `N`. Then `ĝ^N` is
  `x ↦ n + λ(x − n)` near `n`, for some `λ ∈ Q_{>0}`.
  - If `λ = 1`, then `ĝ^N` is the identity on a small box around `n`, and the orbit of that
    box is a proper invariant clopen set.
  - In multiplicative counter-machine encodings (slope `p^{±1}` per counter step),
    periodic configurations have `λ = 1`, because the counters return.
- **Gap for undecidability.**
  - In `F_M` and `H_M` of `ct-z-finite-cycle-problems-are-undecidable`, the set `X ∪ 2X`
    is a proper invariant union of classes. So both satisfy property 3 whatever `M` does,
    and both are conjugate to YES.
  - Finite-order certificates (Theorem 2) cannot carry undecidability either. `F_M` has
    finite order iff `M` is uniformly periodic, and that is decidable (Kari–Ollinger
    Thm. 4, as recorded in that node).
  - An undecidability proof must therefore couple machine and garbage into one
    clopen-indecomposable system. In that system an invariant box structure must appear
    exactly when the machine does something Σ₁, for instance has a periodic configuration
    whose `λ = 1` neighbourhood is a box orbit.
- **Gap for decidability.** One needs a Σ₁ NO-certificate. Theorem 4 is one for autonomous
  2-adic dynamics. The general case needs the analogue over the multi-prime `k`-graph, where
  the base is not autonomous.

## Lesson for general BH

In a full clopen-transitive host (here `CT(Z)`, where pure infiniteness and `K_0 = 0` make
all nonempty clopen sets equivalent), "clopen" and "box" are the same up to conjugacy
(Theorem 3).
- **Stabilizer realizations are free to be box-adapted.** Any construction that realizes a
  subgroup as the stabilizer of a clopen set may take that set to be a single box after one
  conjugation. This covers `wreaths-over-clopen-stabilizer-cosets-lie-in-b-a` and the
  permutational wreath program.
- **Box-defined element properties split in two.** Such a property is either a disguised
  dynamical invariant or it is not conjugacy-invariant at all. Hosts should be judged by
  their dynamical invariants, since the coordinates can always be conjugated away.

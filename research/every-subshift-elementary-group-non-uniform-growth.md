OPEN. Known cases: constant-length-2 substitution subshifts (`substitution-subshift-elementary-groups-non-uniform-growth`).

## Progress
- **Piecewise dyadic level models** (sk-growth-gx-sturmian, unreviewed): `piecewise-dyadic-level-models-give-non-uniform-growth`. Every zero-entropy infinite minimal subshift with clopen piecewise translations of one set onto `2^k` sets partitioning `X`, at infinitely many scales, has `G_X` of non-uniform exponential growth. This contains the constant-tower case (sk-free-8 Corollary A2).
  - The argument: partial translations give dyadic matrix units, the corner is the induced crossed product, and Krieger's embedding theorem recodes the corner binary.
  - Krieger is now an import node `krieger-subshift-embedding-theorem`, read verbatim from a secondary source (arXiv:2606.25475, Theorem 1). That closes A2's verification gate at secondary level.
- **Boundary of the matrix route** (sk-growth-gx-sturmian, unreviewed): `matrix-decompositions-of-subshift-rings-need-divisible-unit`. `M_3(R_X) ≅ M_(3·2^n)(A)` forces `2^(−n) ∈ μ(K^0)`, so for Sturmian `X` no scale `n ≥ 1` exists.

## Attempts
- **Constant towers** (sk-free-8). The engine `el-small-ball-generating-sets-from-grigorchuk-levels` needs `R_X ≅ M_(2^n)(R_n)` for all `n`, with each `R_n` generated by boundedly many elements.
  - Constant towers of height `2^n` exist iff `X` factors onto the dyadic odometer.
  - A Sturmian `X` has no rational eigenvalues, so no constant towers, and this route does not start.
- **Odometer factor with zero entropy** (sk-free-8, artifact part 2, Corollary A2).
  - The induced systems `(V_n, T^(2^n))` are aperiodic, expansive and of zero entropy. Krieger's embedding theorem (ETDS 2 (1982) 195–202) recodes them as binary subshifts, so `R_n` has 3 ring generators and the engine applies.
  - The recorded gate was that Krieger's statement had been recalled through secondary sources. It is now verbatim at secondary level in `krieger-subshift-embedding-theorem`, and G1 above generalizes this case.
- **Non-constant Kakutani–Rokhlin towers** (idea, sk-free-8).
  - `R_X` is then not a matrix ring over one corner: levels of towers with different heights cannot be exchanged by units, so the type-1 permutation matrices do not exist.
  - Possible repair: run the engine inside one tower corner `EL_3(eR_Xe)` and add generators linking to the complement, whose conjugates must stay separated from type 2–4 supports.
  - Dies at: the linking generators are moved by the level permutations, so their supports are not separated.
- **Remainder summand** (sk-growth-gx-sturmian artifact part 1 §3). If the unit is not `2^n`-divisible, `M_3(R_X) = End(P^(m2^n) ⊕ Q)` with a single remainder point `Q`.
  - Generation needs `e_(p,q)` and `e_(q,p)` root elements. Their conjugates share `q`, and `[e_(a,q)(x), e_(q,b)(y)] = e_(a,b)(xy)` puts root elements at unseparated pairs, so the commuting-supports lemma and the counting fail.
  - `Q` can be neither split equally nor made orthogonal to `P`.
  - Dies at: the single defect point.
- **Other odometers.** A `p`-adic odometer factor would need a `p`-ary tree group with sublinear inverted-orbit growth (a Bartholdi–Erschler analog); not checked.

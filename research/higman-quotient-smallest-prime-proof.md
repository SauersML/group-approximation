Notation as in the target. `x^y = y^-1 x y`, and `Q = H4/N` with `N != H4`.

**Step 1 (Baumslag--Solitar kernels).** Let `B = < s, x | x^s = x^2 >`, and let
`rho : B -> Q` be a homomorphism with `rho(x)` of infinite order. Then `rho` is
injective.

- *`x` has infinite order in `B`, and `x^(2^i - 1) != 1` for `i != 0`.* The
  affine maps `x(t) = t + 1` and `s(t) = t/2` of `R` satisfy
  `s^-1 x s (t) = 2(t/2 + 1) = t + 2`, so they define a homomorphism
  `B -> Aff(R)` in which `x` has infinite order.
- *The normal closure `M` of `x` is abelian.* Put `U_j = s^j <x> s^-j`. From
  `s^-1 x s = x^2` we get `x = (s x s^-1)^2`, so `U_j <= U_(j+1)`. Also
  `U_(-j) <= <x>` for `j >= 0`. So `U = union_j U_j` is an increasing union of
  cyclic groups, hence abelian. It is invariant under conjugation by `s^(+-1)`
  and by `x`, so it is normal. It contains `x` and lies in `M`, so `U = M`.
- *`B = M <s>`.* `B/M` is generated by the image of `s`.
- *`ker(rho)` meets `M` trivially.* An element of `M` has the form
  `s^j x^k s^-j`. If `rho` kills it, then `rho(x)^k = 1`, so `k = 0`.
- *`ker(rho)` lies in `M`.* Put `K = ker(rho)`. Both `K` and `M` are normal, so
  `[K, M] <= K cap M = 1`. Let `g = s^i m` be in `K`, with `m` in `M`. Then
  `x = g x g^-1 = s^i x s^-i`, because `M` is abelian. If `i > 0`, conjugating by
  `s^-i` gives `x^(2^i) = x`. If `i < 0`, conjugating by `s^i` gives
  `x^(2^(-i)) = x`. Both contradict the first bullet, so `i = 0` and `g` lies in
  `K cap M = 1`.

**Step 2 (finite order propagates).** Conjugating `b^a = b^2` by `a^(j-1)`
repeatedly gives `a^-j b a^j = b^(2^j)` for `j >= 0`. If `a` has finite order
`k` in `Q`, then `b = b^(2^k)`, so `b^(2^k - 1) = 1`. The same argument along
`c^b = c^2`, `d^c = d^2`, `a^d = a^2` shows that if one generator has finite order,
then all four do, and their orders satisfy

```text
o_b | 2^(o_a) - 1,   o_c | 2^(o_b) - 1,   o_d | 2^(o_c) - 1,   o_a | 2^(o_d) - 1.
```

**Step 3 (smallest primes).** Suppose the four orders are finite.

- *Some order is 1.* Say `o_a = 1`. Then `o_b | 1`, and so on around the cycle,
  so every generator is trivial, `Q = 1` and `N = H4`.
- *All orders exceed 1.* They are odd, since each divides a number `2^o - 1`. Let
  `p_a, p_b, p_c, p_d` be their smallest prime divisors. Since `p_b` divides
  `2^(o_a) - 1`, the multiplicative order `r` of `2` modulo `p_b` divides `o_a`.
  Also `r > 1`, because `p_b` does not divide `2 - 1`. So `r >= p_a`, while
  `r <= p_b - 1` by Fermat. Hence `p_a < p_b`, and by the same argument
  `p_b < p_c < p_d < p_a`, a contradiction.

So `N != H4` forces all four generators to have infinite order, which is item 1.

**Step 4 (item 2).** Apply Step 1 to the pairs `(s, x) = (a, b), (b, c), (c, d), (d, a)`.
Each relation `x^s = x^2` holds in `H4`, and `rho(x)` has infinite order by item 1.
The four subgroups are copies of `BS(1,2)`; the case `N = 1` of Step 1 shows
this.

**Credit.**
- **Step 1.** Kassabov--Kuperberg--Riley (arXiv:1712.07191) state that "If
  $m \not= \pm 1$, then the image of $a$ in any proper quotient of $\BS(1,m)$ is
  finite" and sketch a proof by normal forms (TeX l.1183–1184). The proof above
  avoids normal forms.
- **Step 3.** This is a smallest-prime argument for the absence of finite
  quotients. The same paper credits "A beautiful argument due to Higman" with
  showing that there are none (l.1250). Higman's paper was not read here, so no
  attribution of Step 3 is claimed.
- **Step 2** is immediate.

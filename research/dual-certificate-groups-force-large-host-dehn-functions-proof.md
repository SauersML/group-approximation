Fix total recursive `f`. Put `F(n) = 2^(n (n + f(n))^2)`. This is total recursive.
Let `A` be a recursive set such that every Turing machine deciding `A` runs more
than `F(i)` steps on almost every `i` (`almost-everywhere-hard-recursive-sets-exist`).

**Step 1: the subgroups `L_B`.** Let `phi: F(a, b) -> Z` send `a ↦ 0`, `b ↦ 1`.
Its kernel is freely generated by the `x_i = b^i a b^(-i)` with `i ∈ Z`: this is
Reidemeister–Schreier with transversal `{b^i}`. For `B ⊆ N` let `L_B` be the
subgroup generated by the `x_i` with `i ∈ B`. It is a free factor of `ker phi`.
So for `j ∈ N`, `x_j ∈ L_B` iff `j ∈ B`.

- If `B` is recursive, membership of a reduced word `w` in `L_B` is decidable.
  Check that the exponent sum of `b` in `w` is zero. Then rewrite `w` in the `x_i`
  (read `w` left to right, tracking the running `b`-exponent `i`, and replace
  each `a^(±1)` by `x_i^(±1)`). Finally check that every index used lies in `B`.

**Step 2: `G_B` and its commutators.** `G_B = <a, b, t | t x_i t^(-1) = x_i, i ∈ B>`
is the HNN extension of `F(a, b)` along the identity of `L_B`.

- **Britton's lemma** (Lyndon–Schupp, Ch. IV §2; not re-read): a word with at
  least one `t^(±1)` and no pinch `t w t^(-1)` or `t^(-1) w t` with `w ∈ L_B` is
  not trivial.
- Let `u_j = t x_j t^(-1) x_j^(-1)`. If `j ∈ B` then `u_j = 1`, by a relation. If
  `j ∉ B`, the only candidate pinch is `t x_j t^(-1)`, and `x_j ∉ L_B` by Step 1.
  So `u_j ≠ 1`.
- `|u_j| = 2(2j + 1) + 2 = 4j + 4`.
- **Word problem for recursive `B`.** Repeatedly find a pinch (decidable by Step 1)
  and replace `t^(±1) w t^(∓1)` by `w`, which strictly lowers the number of `t`
  letters. When no pinch is left, the word is trivial iff it has no `t` letter and
  freely reduces to the empty word.

**Step 3: `H_f`.** Let `H_f = G_A * G_(N \ A)` on generators `a, b, t, a', b', t'`.
It is finitely generated, and its word problem is solvable: `A` and `N \ A` are
recursive, and a free product of groups with solvable word problem has solvable
word problem by the normal form. Let `v_i = t' x'_i t'^(-1) x'^(-1)_i` in the
second factor. By Step 2:

- `u_i = 1` iff `i ∈ A`;
- `v_i = 1` iff `i ∉ A`;
- `|u_i| = |v_i| = 4i + 4`.

**Step 4: the area search.** Let `P = <X | R>` be a finite presentation and
`iota: H_f -> P` an injective homomorphism. Choose words over `X` for the images
of the 6 generators, and let `lambda >= 1` be their maximal length. Let `U_i` and
`V_i` be the resulting words for `u_i` and `v_i`, so `|U_i|, |V_i| <= 8 lambda i`
for `i >= 1`. By injectivity, exactly one of `U_i`, `V_i` is trivial in `P`.
Let `rho = max(1, max_(r ∈ R) |r|)`.

Algorithm `𝒜` on input `i >= 1`:

- Compute `U_i` and `V_i`.
- For `N = 0, 1, 2, ...` and each `W ∈ {U_i, V_i}`, list every product of `N`
  conjugates `g r^(±1) g^(-1)` with `r ∈ R` and `|g| <= |W| + rho N`. If one
  freely equals `W`, stop and output `1` iff `W = U_i`.

*Correctness.* A match shows `W = 1` in `P`, and only the correct certificate is
trivial.

*Halting and time.* Let `W` be the trivial certificate, `l = |W| <= 8 lambda i`,
and `N* = Area(W) <= delta_P(l) <= delta_P(8 lambda i)`, since Dehn functions are
non-decreasing. Step 1 of `dehn-function-bound-gives-word-problem-time-bound-proof`
writes `W` freely as a product of `N*` relator conjugates with conjugators of
length at most `l + rho N*`. So `𝒜` stops at some stage `N <= N*`.

- Stage `N` lists at most `(2|R| (2|X| + 1)^(l + rho N + 1))^N` products.
- Each product is freely reduced in time polynomial in its length.
- Computing `U_i`, `V_i` takes time polynomial in `i`.

Hence, for a constant `c` depending only on `P`, `iota`, the chosen words and the
machine model, `𝒜` runs within `2^(c (8 lambda i + delta_P(8 lambda i))^2)` steps
on every `i >= 1`.

**Step 5: the lower bound.** Suppose `delta_P(8 lambda n) < f(n)` for infinitely
many `n`. For each such `n >= c (8 lambda)^2` the running time of `𝒜` is at most
`2^(c (8 lambda n + f(n))^2) <= 2^(c (8 lambda)^2 (n + f(n))^2) <= 2^(n (n + f(n))^2) = F(n)`.
So `𝒜` decides `A` within `F(n)` steps on infinitely many inputs. This contradicts
the choice of `A`. Hence some `n_0` has `f(n) <= delta_P(8 lambda n)` for all
`n >= n_0`.

Let `M = max(f(0), ..., f(n_0))` and `K = max(8 lambda, M)`. For `n >= n_0`,
`f(n) <= delta_P(8 lambda n) <= K delta_P(Kn)`. For `1 <= n < n_0`,
`f(n) <= M <= Kn`. So `f(n) <= K delta_P(Kn) + Kn` for all `n >= 1`.

The group `H_f` depends only on `f`, not on `P`. `∎`

**Where the recorded obstruction does not apply.** Attempt 2 of
`fp-simple-dehn-functions-realize-every-recursive-lower-bound` says the
diagram-enumeration algorithm needs a Dehn bound at the length being decided.
`𝒜` needs no such bound. It searches both certificates by increasing area, so it
always halts, and it only has to be fast on the infinitely many lengths where
`delta_P` is small. Almost-everywhere hardness rules out exactly that.

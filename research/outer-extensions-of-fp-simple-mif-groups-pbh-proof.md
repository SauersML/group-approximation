The full proof is in the artifact, §§2--7. The condensed version follows.

**Notation.**
- `S` is finitely presented, simple and MIF. So `S` is infinite, centreless and
  nonabelian.
- `n ≥ 2`, `A = Aut_S(S * F_n)` and `X = Hom_S(S * F_n, S)`.
- For `β ∈ Aut(S)`, `hat(β)` is `β` on `S` and the identity on `F_n`.
- `iota_s` is conjugation by `s ∈ S` on `S * F_n`, and `c_s = iota_s|_S`.

**1. Lemma (W): MIF word endomorphisms.** Let `u ∈ S * ⟨x⟩` induce an endomorphism
of `S`.
1. `v = u(xy) · u(y)^-1 · u(x)^-1 ∈ S * ⟨x, y⟩` vanishes at every point of `S^2`.
   By MIF, `u(xy) = u(x) u(y)` in `S * ⟨x⟩ * ⟨y⟩`.
2. Write `u = s_0 x^{e_1} s_1 ⋯ x^{e_k} s_k` in reduced form. If `k = 0`, then
   `u = s_0 = s_0^2`, so `u = 1`.
3. If `k ≥ 1`, the reduced form of the left side has `2 Σ|e_i|` free syllables. The
   right side is `s_0 x^{e_1} ⋯ x^{e_k} (s_k s_0) y^{e_1} ⋯ y^{e_k} s_k`, which is
   reduced and has `2k`. So all `e_i = ±1`.
4. Each block `(xy)^{±1}` on the left contains both an `x`- and a `y`-syllable. On
   the right every `x`-syllable precedes every `y`-syllable. So `k = 1`.
5. Comparing first free syllables gives `e_1 = 1`.
6. Comparing `s_0 x y s_1` with `s_0 x (s_1 s_0) y s_1` gives `s_1 = s_0^-1`.

**2. The enlarged actor.**
- Let `Γ_B = {γ ∈ Aut(S * F_n) : γ(S) = S, γ|_S ∈ B}` and `ρ(γ) = γ|_S`. Then
  `Γ_B = A ⋊ hat(B)` with `ker ρ = A`.
- `Γ_B` acts on `X` by `γ · f = ρ(γ) ∘ f ∘ γ^-1`. On `A` this is the inverse of
  BFFHZ's precomposition action, so it has the same stabilizers, orbits and kernel.
- `A` is finitely presented by Theorem E. When `B/Inn(S)` is finitely presented, `B`
  is finitely presented, being an extension of `Inn(S) ≅ S` by `B/Inn(S)`. Then
  `Γ_B` is finitely presented. This is used only in step 4.

**3. The kernel `K`.**
- **(a)** `iota_s ∈ K`, because `s f(s^-1 w s) s^-1 = f(w)`.
- **(b)** `K ∩ A = 1`. This is faithfulness in Theorem E.
- **(c)** `ρ(K) = Inn(S)`. Let `γ ∈ K`, `β = ρ(γ)`, and `w = γ^-1(x_1)`.
  - Kill `x_2, …, x_n` in `w` to get `u ∈ S * ⟨x⟩`.
  - Test on `f_t : x_1 ↦ t, x_k ↦ 1`. This gives `β(u(t)) = t` for all `t ∈ S`.
  - So `u` induces the automorphism `β^-1`, and `β` is inner by (W).
- **(d)** By (b) and (c), `ρ|_K` is injective with image `Inn(S)`, which the
  `iota_s` already cover. So `K = {iota_s} ≅ S`, generated by `iota` of finitely many
  generators of `S`.
- **(e)** `hat(β) ∈ K` forces `β(f(x_1)) = f(x_1)` for all `f`, so `β = 1`. Hence
  `B ↪ Λ_B := Γ_B/K`.

**4. Type (A) for `Λ_B`, when `B/Inn(S)` is finitely presented.**
- **Faithful.** By construction.
- **Finitely presented.** `Γ_B` is finitely presented and `K` is finitely generated.
- **Stabilizers.** For `f ∈ X`, `ρ : Stab_{Γ_B}(f) → B` is onto. Given `β`, choose
  `α ∈ A` with `α · (hat(β) · f) = f`, by transitivity (BFFHZ Lemma 2.1, the map
  `x_j ↦ f'(x_j) f(x_j)^-1 x_j`). The kernel `Stab_A(f)` is finitely generated by
  Theorem E, so `Stab_{Γ_B}(f)` is finitely generated. Then so is
  `Stab_{Λ_B}(f) = Stab_{Γ_B}(f)/K`.
- **Pair orbits.** `A` embeds in `Λ_B` by (b), and it already has finitely many
  orbits on `X x X` by Theorem E.

So `B ∈ B_A`, and `type-a-action-gives-boone-higman-for-subgroups` gives solvable
word problems and finitely presented simple envelopes for all subgroups. This proves
(W), (K) and (A).

**5. Corollaries.**
- **(O).** For `1 → S → I → Q → 1` with `Q ↪ Out(S)`:
  - the conjugation map `I → Aut(S)` has kernel `C_I(S)`;
  - an element of `C_I(S)` maps to a `q ∈ Q` that is trivial in `Out(S)`, so `q = 1`,
    and the element lies in `Z(S) = 1`;
  - so `I ≅ B` with `Inn(S) ≤ B` and `B/Inn(S) ≅ Q`. Apply (A).
- **(S).** Take `B` to be the preimage of the finitely presented subgroup of
  `Out(S)`.
- **(E).**
  - If `G` embeds in an extension as in (O), then `G ∈ B_A` by (O), since `B_A` is
    closed under subgroups.
  - Conversely, if `G ∈ B_A`, then BFFHZ Theorem C, (i) ⇒ (iv)
    (`fp-simple-highly-transitive-groups-satisfy-pbh`), embeds `G` in a finitely
    presented simple MIF group `S`. Take `Q = 1`.
- **(R).**
  - If the kernel `S` is MIF, then `I ∈ B_A` by (O).
  - If `S` is finite, then `Q ≤ Out(S)` is finite, so `I` is finite. A finite group
    is a type (A) actor on itself.
  - If `S ∈ B_A` and `Q` is finite, then `I ∈ B_A` by
    `boone-higman-type-a-class-closed-under-finite-extensions` (finite-index
    overgroups).
  - Each of these contradicts `G ∉ B_A`.

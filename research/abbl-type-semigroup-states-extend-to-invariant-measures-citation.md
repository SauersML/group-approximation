P. Ara, C. Bönicke, J. Bosa and K. Li, "The type semigroup, comparison and almost finiteness for ample
groupoids", arXiv:2001.00376, Section 2. Read from the arXiv PDF on 2026-09-13.

Verbatim: "Lemma 2.3. Let G be an ample second countable groupoid. Then each f ∈ F (S(G)) can be
extended to a Borel invariant measure µf ∈ UM(G). Moreover, the restriction of the measure µf to the
open set V := ∪K, where K ranges over all the compact open subsets of G(0) such that f([1K]) < ∞, is
unique and regular."

Also verbatim from the same section:
- "For a preordered monoid (S, +, ≤) we denote by F (S) the set of all unnormalized states on S, that is
  the set of all the monoid homomorphisms S → [0, ∞]."
- The type semigroup is presented with generators `[U]` and the relations "(1) [∅] = 0, (2)
  [A ∪ B] = [A] + [B] if A, B ∈ K and A ∩ B = ∅, (3) [s(V )] = [r(V )] for each compact open bisection
  V of G".

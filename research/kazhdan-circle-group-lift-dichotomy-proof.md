**Inputs.**

- The two required claims:
  - `bdhv-central-extension-property-t`: a countable group with finite abelianization
    whose quotient by a central subgroup is Kazhdan is itself Kazhdan.
  - `discrete-kazhdan-groups-are-finitely-generated`.
- Three standard facts from Bekka--de la Harpe--Valette, *Kazhdan's Property (T)*,
  re-read on 2026-09-16:
  - **Corollary 1.3.5.** Every homomorphism from a Kazhdan group to `R` or `Z` is
    constant.
  - **Corollary 1.3.6.** A discrete Kazhdan group has finite abelianization. So every
    abelian quotient is finite.
  - **Theorem 1.7.1.** For a subgroup of finite index in a discrete group, one has
    property (T) if and only if the other does.
- The covering lemma (artifact, Lemma 0):
  - `Homeo_Z(R) ⊂ Homeo_+(R)`;
  - `p : Homeo_Z(R) → Homeo_+(S^1)` is onto;
  - `ker p = ⟨T⟩ ≅ Z` is central.

  The proof uses only the path-lifting property of `R → R/Z` and the fact that
  `F(x+1) - F(x)` is a continuous integer-valued function.

**Proof.** Let `G ⊂ Homeo_+(S^1)` be Kazhdan. Then `G` is finitely generated by
`discrete-kazhdan-groups-are-finitely-generated`. Hence `Ĝ` is finitely generated too,
by `T` and lifts of generators of `G`.

*Case 1: some homomorphism `φ : Ĝ → R` has `φ(T) ≠ 0`.* Rescale so that `φ(T) = 1`,
and put `K̂ := ker φ`.

- *Injectivity.* If `x ∈ K̂` and `p(x) = 1`, then `x = T^n` and `0 = φ(x) = n`, so
  `x = 1`. Thus `p|K̂` is injective.
- *Normality.* `K̂` is normal in `Ĝ`, and `p` maps `Ĝ` onto `G`. So `K := p(K̂)` is
  normal in `G`.
- *Finite index.* Since `p^{-1}(K) = K̂⟨T⟩`, we have `G/K ≅ Ĝ/K̂⟨T⟩`. Now `φ`
  identifies `Ĝ/K̂` with `φ(Ĝ) ⊂ R` and carries `K̂⟨T⟩/K̂` onto `φ(⟨T⟩) = Z`. So
  `G/K ≅ φ(Ĝ)/Z` is abelian, hence finite by Corollary 1.3.6.

So (A) holds.

*Case 2: every homomorphism `Ĝ → R` kills `T`.*

- Each such homomorphism factors through `Ĝ/⟨T⟩ ≅ G`, so it is zero by Corollary 1.3.5.
- `Ĝ^{ab}` is a finitely generated abelian group `Z^r ⊕ F` with `F` finite, and
  `Hom(Ĝ, R) ≅ R^r`. Hence `r = 0` and `Ĝ^{ab}` is finite.
- `⟨T⟩` is central, `Ĝ/⟨T⟩ ≅ G` is Kazhdan and `Ĝ` is countable. By
  `bdhv-central-extension-property-t`, `Ĝ` is Kazhdan.

So (B) holds.

*Exclusivity.* Suppose (A) holds with `K = p(K̂)`.

- `K̂ ∩ ⟨T⟩ = 1`, because `p` is injective on `K̂`.
- `⟨T⟩` is central and `K̂` is normal in `p^{-1}(K) = K̂⟨T⟩`. So
  `p^{-1}(K) ≅ K̂ × Z`.
- `[Ĝ : p^{-1}(K)] = [G : K] < ∞`.

If `Ĝ` were Kazhdan, then the finite-index subgroup `K̂ × Z` would be Kazhdan
(Theorem 1.7.1). But it maps onto `Z`, contradicting Corollary 1.3.5. So (B) fails. ∎

The artifact gives Lemma 0 in full, and a remark identifying Case 1 with the vanishing
of the real Euler class.

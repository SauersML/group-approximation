Let `A` be a simple unital C*-algebra in which every nonzero projection is
infinite.  Then the following are equivalent:

1. `A` is purely infinite;
2. `Cu(A)` has property (QQ): whenever `m x` is properly infinite for some
   positive integer `m`, the element `x` is properly infinite.

In fact, property (QQ) forces every nonzero Cuntz class to equal `[1_A]`.
No separability, nuclearity, algebraicity, comparison, cancellation,
stable-rank, or real-rank hypothesis is used.

More sharply, if `A` is a counterexample and `D` is its full projectionless
hereditary corner, then every nonzero class represented in `D` witnesses
failure of property (QQ): it is not properly infinite although a finite
multiple of it is the properly infinite unit class.  The failure persists
with one fixed multiplicity along every uniform spectral root tower in `D`.

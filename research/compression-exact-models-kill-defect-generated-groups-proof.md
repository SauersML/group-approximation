Throughout, `d` is a bi-invariant length distance on the target group: normalized
Hamming distance on `Sym(X)`, normalized rank distance on `GL_d(k)`, or normalized
Hilbert--Schmidt distance on `U(d)`. We use only:

```text
d(ab, a'b') <= d(a,a') + d(b,b'),     d(g a g^-1, g b g^-1) = d(a,b).      (BI)
```

## Step 1. Exact death of the defect

Let `rho` be a model with `rho(t) G rho(t)^-1 <= G`, where `G = G_rho` is the finite group
generated by the `rho(p_i)`, and `rho(c)` commutes with every `rho(p_i)`.

- Conjugation by `rho(t)` is injective, so `|rho(t) G rho(t)^-1| = |G|`. An inclusion of
  finite sets of equal size is an equality, so `rho(t) G rho(t)^-1 = G`.
- `rho(c)` commutes with the generators of `G`, hence with `G`.
- So `rho(t) rho(c) rho(t)^-1` commutes with `rho(t) G rho(t)^-1 = G`. Since `p_0` is a
  word in the `p_i`, `rho(p_0) in G`.
- Hence `rho(sigma) = [rho(t) rho(c) rho(t)^-1, rho(p_0)] = 1`.

If `W_t` holds exactly, then `rho(t) rho(p_i) rho(t)^-1 = rho(w_i) in G`, so the inclusion
hypothesis holds.

**Linear case (C).** Replace `G` by the unital algebra `A` generated by the `rho(p_i)`.
It is finite-dimensional, and `x -> rho(t) x rho(t)^-1` is an injective linear map, so
inclusion forces equality. The rest is unchanged.

## Step 2. Normal generation spreads the kill

By `(DG)`, for each `s in S` there are `m_s >= 0`, words `u_(s,j)` and signs `e_(s,j)`
with

```text
v_s := s^-1 prod_(j<=m_s) u_(s,j) sigma^(e_(s,j)) u_(s,j)^-1   in N.
```

For a model `rho`, bi-invariance `(BI)` gives

```text
d(rho(s), 1) <= d(rho(v_s), 1) + m_s d(rho(sigma), 1).                         (NG)
```

In a sofic (or hyperlinear, or linear-sofic) approximation, `d(rho_n(v_s),1) -> 0`
because `v_s in N`. If also `d(rho_n(sigma),1) -> 0`, then `d(rho_n(s),1) -> 0` for
every `s`. By `(BI)`, `d(rho_n(w),1) <= |w| max_s d(rho_n(s),1) -> 0` for every word
`w`.

If `Q != 1`, pick `w notin N`. In an approximation `d(rho_n(w),1) -> 1` (Hamming,
rank), or `-> sqrt 2` (Hilbert--Schmidt, since the normalized trace tends to `0`).
This is a contradiction.

This proves (A) and (C): Step 1 gives `rho_n(sigma) = 1` along the subsequence.

## Step 3. Proof of (B): round the centralizer

Let `rho_n` restrict to a genuine action `tau_n` of the Kazhdan group `P_0` on `X_n`,
with Kazhdan pair `(S_P, kappa)`, `S_P = {p_i^(+-1)}`. Put
`eps_n = max_i d_H([rho_n(c), rho_n(p_i)], 1)`. Then

```text
|{x : rho_n(c) tau_n(s) x != tau_n(s) rho_n(c) x}| <= eps_n |X_n|
```

for `s in S_P`. Commuting with `p_i^-1` follows by conjugating the commutator.

Once `eps_n < kappa^2/C'`, `kazhdan-almost-centralizers-round-in-finite-actions` gives an
exactly `tau_n`-equivariant permutation `c'_n` with `d_H(rho_n(c), c'_n) <= C eps_n/kappa^2`.

- `G_n = tau_n(P_0)` is finite, and `rho_n(t)` normalizes it by hypothesis.
- `c'_n` centralizes `G_n`.
- By Step 1, applied to the model that agrees with `rho_n` except `c -> c'_n`,

  ```text
  sigma'_n := [rho_n(t) c'_n rho_n(t)^-1, rho_n(p_0)] = 1 .
  ```

- The letter `c` occurs twice in `sigma`, so by `(BI)`,

  ```text
  d_H(rho_n(sigma), 1) = d_H(rho_n(sigma), sigma'_n) <= 2 d_H(rho_n(c), c'_n) <= 2C eps_n/kappa^2 -> 0.
  ```

Step 2 then finishes the proof.

## Step 4. Proof of (D)

**(1) The defect lies in every residual.** Let `f : H -> F` be a homomorphism to a finite
group, or a finite-dimensional representation. Composing with `F(S) -> H` gives a model
satisfying `W_t` and `W_c` exactly, so Step 1 gives `f(sigma) = 1`. Hence `sigma` lies in
the finite residual `H^fr` and in the finite-dimensional residual.

**(2) The kernel is not co-sofic.**
- A finite `H`-action has finite-index stabilizers.
- A finite-index subgroup contains its normal core, which is a finite-index normal
  subgroup, so it contains `H^fr`, which contains `sigma`.
- So the invariant random subgroup of a finite action is supported on the set
  `U_sigma = {L in Sub(H) : sigma in L}`. This set is clopen in the Chabauty topology.
- Every weak limit is therefore supported on `U_sigma`. If `delta_(ker pi)` were such a
  limit, then `sigma in ker pi`, and `(DG)` would give `Q = 1`.

**(3), (4) Pulled-back approximations.**
- "Pulled back from genuine actions" means homomorphisms `rho_n : H -> Sym(X_n)` (or
  `GL_(d_n)`, `U(d_n)`) with `d(rho_n(m),1) -> 0` for `m in ker pi` and `d(rho_n(h),1)`
  tending to the diameter value for `h notin ker pi`.
- By (1), `rho_n(sigma) = 1`.
- Step 2 runs verbatim in `H`: `(NG)` holds with `v_s in ker pi` for any finite
  generating set of `H`. So all of `Q` acts asymptotically trivially, and `Q = 1`.

## Checks

- **No use of property (T) in (A), (C), (D).** The only invariant is the size of `G` (or
  the dimension of `A`).
- **Where (T) enters (B).** Only to round the centralizer. Normalization by `rho(t)` is
  still assumed exactly.
- **Calibration against E.** `E` is sofic and not residually finite, and its marked defect
  dies in all finite quotients. Step 1 applied to `H = E` is consistent with this: sofic
  approximations of `E` are not genuine actions, and they are not exact on the
  normalization step.
- **The LEF simple Kazhdan group.** It has homomorphisms from a finitely presented Kazhdan
  cover onto finite groups whose kernels converge to the true kernel. Its kernel lies in
  no defect-generation relation, so `(DG)` is exactly the clause that separates the two
  cases.

**Inputs.**
- (S) For a commutative ring `R` and `N >= 3`, Steinberg symbols in `K_2(N, R)` satisfy:
  - (S1) bimultiplicativity;
  - (S2) `{u,v} = {v,u}^(-1)`;
  - (S3) `{u,−u} = 1`;
  - (S4) `{u,1−u} = 1`.

  Source: Dennis–Stein, LNM 342, p. 249, read at the source.
- (St) Let `J` be an ideal in the Jacobson radical of a commutative ring `R` that is additively generated by
  units. Then `ker(K_2(N,R) -> K_2(N,R/J))` is generated by the symbols `{v, 1+w}`, with `v ∈ R^x` and `w ∈ J`.
  Also, `K_2(N, R)` of a semilocal `R` is generated by symbols. Source: p. 252, read at the source.
- (DS12) For a DVR `O` with finite residue field of characteristic `p`, `K_2(O/P^m)` is cyclic of order `p^t`, with
  `t = [m/e − 1/(p−1)]` clamped to `[0, r]`, where `p^r = |μ_(p^∞)|` of the completion. Source: p. 254, read at the
  source.
- (M) Morita invariance: `K_2(M_m(R)) ≅ K_2(R)`, and the diagonal inclusion `R^m -> M_m(R)` induces the sum map.
  Textbook.
- (AH) Artin–Hasse: in `K = Q_l(ζ)`, `(ζ, β)_l = ζ^(Tr(log β)/l)` for `β ∈ U^(1)`, up to a sign convention.
  Textbook, not re-read.
- (Lv) Level bounds for `K = Q_l(ζ)`, where `e = l − 1` and `el/(l−1) = l`. Textbook, not re-read.
  - `U^(n) ⊆ K^(x l)` for `n > l`.
  - `(U^(i), U^(j))_l = 1` for `i + j > l`.

**Part 1, `l` odd.** Work in `K_2(N, C)` with `N >= 3`.
- *(a) The group `1 + F_l y`.* Since `y^2 = ly = 0`, `(1+ay)(1+by) = 1 + (a+b)y`. So `(1+y)^a = 1 + ay`, and
  `(1+y)^l = 1`.
- *(b) Symbols inside `1 + F_l y` vanish.*
  - By (S1), `{1+y, −1}` has order dividing 2 and dividing `l`, so it is `1`.
  - By (S3) and (S1), `{1+y, 1+y} = {1+y, −1}^(-1) = 1`.
  - Hence `{1+ay, 1+by} = {1+y, 1+y}^(ab) = 1`.
- *(c) Symbols with integers reduce to one class.* Put `χ(s) = {1+y, s}` for `s ∈ (Z/l^2)^x`.
  - `χ(s)^l = 1`, so `χ` kills the roots of unity of order `l − 1`.
  - Write `s = ω(1+bl)`, with `ω` such a root of unity. Then `χ(s) = χ(1+l)^b`, because `(1+l)^b = 1 + bl`.
  - The Fermat quotient `L(s) = (s^(l−1) − 1)/l mod l` equals `−b`. So `χ(s) = z^(−L(s))` with
    `z = {1+y, 1+l}`.
- *(d) A Steinberg relation kills `z`.*
  - Take `t ∈ Z/l^2` with `t` and `1 − t` units. Put `x = t(1+y)`. Then `1 − x = (1−t)(1 − t'y)` with
    `t' = t/(1−t)`.
  - (S4) and (S1) give `1 = {t, 1−t}{t, 1−t'y}{1+y, 1−t}{1+y, 1−t'y}`.
    - The first factor is `1` by (S4) and the last by (b).
    - `1 − t'y = (1+y)^(−t')`, so `{t, 1−t'y} = χ(t)^(t')` by (S2).
  - Hence `χ(t)^(t') χ(1−t) = 1`, that is `z^E = 1` with `E ≡ −(t L(t) + (1−t) L(1−t))/(1−t) mod l`.
  - Since `s L(s) ≡ (s^l − s)/l` and `binom(l,k)/l ≡ (−1)^(k−1)/k mod l`,
    `t L(t) + (1−t) L(1−t) ≡ (t^l + (1−t)^l − 1)/l ≡ −P(t)`, where `P(t) = Σ_(k=1)^(l−1) t^k/k ∈ F_l[t]`.
    So `E ≡ P(t)/(1−t)`.
  - `P` has degree `l − 1`, and `P(0) = 0`. Also `P(1) = Σ 1/k ≡ 0`, because the inverses permute `F_l^x`.
    - So `P` has at most `l − 3` roots in `F_l ∖ {0,1}`, a set of `l − 2` elements. Some `t_0` there has
      `P(t_0) != 0`. For `l = 3`, `t_0 = 2` and `P(2) = 1`.
    - With `t = t_0`, `E` is a unit mod `l`. Since `z^l = 1`, it follows that `z = 1`.
- *(e) The symbols.* `π_q ↦ 1 + y + ql = (1+y)(1+ql)`, because `ly = 0`. So
  `c_q ↦ {1+y, 1+y}·χ(1+ql) = 1·z^q = 1`.

**Part 1, `l = 2`.** `q` is odd, so `2q ≡ 2 mod 4`. Since `2y = 0`, `−y = y`. So `1 + y + 2q = 3 + y = −(1+y)`, and
`c_q ↦ {1+y, −(1+y)} = 1` by (S3).

**Part 1, conclusion.** `C ⊆ F_(2,l)` is a ring map, and Steinberg symbols are natural. So `c_q ↦ 1` in
`K_2(N, F_(2,l))`. ∎

**Part 2.** Let `l` be odd, `e = l − 1`, `n >= l + 1`, and write `h` for the `l`-th Hilbert symbol of `K`.
- *The map.* `u ↦ ζ − 1` sends `π_k` to `ζ + kl`, which is `≡ ζ mod 𝔭^(l−1)` and hence a unit. So it defines
  `A -> O_K -> O_K/𝔭^n`.
- *`h` is defined on `K_2(O_K/𝔭^n)`.*
  - `K_2(N, O_K) -> K_2(N, O_K/𝔭^n)` is onto, since both groups are generated by symbols of units (St) and units
    lift.
  - By (St), with `J = 𝔭^n`, the kernel is generated by symbols `{v, 1+w}` with `w ∈ 𝔭^n`. By (Lv), `1 + w` is an
    `l`-th power, so `h` kills the kernel.
  - By (DS12), with `r = 1` since `Q_l(ζ_l)` has no primitive `l^2`-th root of unity, `K_2(O_K/𝔭^n)` is cyclic of
    order `l^t`, where `t` is `[(n−1)/(l−1)]` clamped to `[0,1]`, so `t = 1`. A nontrivial value of `h` therefore
    makes `h` an isomorphism onto `μ_l`.
- *The value.*
  - `c_q ↦ {ζ, ζ + ql}`, and `ζ + ql = ζ(1 + qlζ^(-1))`.
  - `h(ζ, ζ) = h(ζ, −1) = 1`, since `−1 = (−1)^l`.
  - By (AH), `h(ζ, 1 + qlζ^(-1)) = ζ^(T/l)` with `T/l = Σ_(k>=1) (−1)^(k+1) q^k l^(k−1) Tr(ζ^(-k))/k`.
    - The term `k = 1` is `q Tr(ζ^(-1)) = −q`.
    - For `k >= 2`, `v_l(l^(k−1)/k) >= 1`, because `k − 1 − v_l(k) >= 1` for `l >= 3`, and `Tr(ζ^(-k)) ∈ Z`.
  - So `T/l ≡ −q mod l`, and the value is `ζ^(-q)`. It is nontrivial for `q != l`. ∎

**Part 3.**
- *The orbit module.* Let `V = ⊕_(i ∈ Z/m) (O_K/𝔭^n) e_i`.
  - `a ∈ A` acts on `e_i` by `φ_i(a)`, where `φ_i(u) = ζ − 1 + il`. Each `φ_i` is a ring map as in Part 2.
  - `φ_(i+m) = φ_i`, because `ml ∈ 𝔭^n`.
  - `x` shifts the basis, `e_i ↦ e_(i−1)`. Then `x a x^(-1)` acts on `e_i` by `φ_(i+1)(a) = φ_i(σ a)`, which is the
    defining relation of `D = A[x^(±1); σ]`. The opposite convention reverses the shift.
  - So `ρ_m : D -> End(V) = M_m(O_K/𝔭^n)` is a ring map.
- *The image of `c_q`.*
  - `ρ_m(π_0)` and `ρ_m(π_q)` are diagonal. By (M), the image of `c_q` in `K_2(O_K/𝔭^n)` is
    `Π_i {φ_i(π_0), φ_i(π_q)}`.
  - Write `φ_i(π_0) = ζ(1 + ilζ^(-1))` and `φ_i(π_q) = ζ(1 + (i+q)lζ^(-1))`.
  - Expand `h` bimultiplicatively:
    - `h(ζ, ζ) = 1`;
    - `h(1 + ilζ^(-1), 1 + (i+q)lζ^(-1)) = 1` by (Lv), since both factors lie in `U^(l−1)` and `2(l−1) > l`;
    - by Part 2, `h(ζ, 1 + (i+q)lζ^(-1)) = ζ^(−(i+q))` and `h(1 + ilζ^(-1), ζ) = ζ^i`.
  - So each factor has value `ζ^(-q)`, and the product is `ζ^(-qm)`.
- *Why `l | m`.* `v_𝔭(ml) = (l−1)(1 + v_l(m))`. This is `>= n >= l + 1` only if `v_l(m) >= 1`. So `ζ^(-qm) = 1`,
  and since `h` is an isomorphism (Part 2) the image of `c_q` in `K_2(M_m(O_K/𝔭^n))` is trivial.
- *The commutative part still sees `c_q`.* `ρ_m(A)` is diagonal, and reading the `0`-th entry is a ring map
  `ρ_m(A) -> O_K/𝔭^n`. It sends `c_q` to `{ζ, ζ+ql}`, which has value `ζ^(-q) != 1`. ∎

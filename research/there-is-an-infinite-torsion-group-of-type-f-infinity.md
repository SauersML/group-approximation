**OPEN.** There is an infinite group `Q` of type F∞ (a `K(Q,1)` with finitely
many cells in each dimension) in which every element has finite order.

This is the form "(or F∞)" of Zaremsky Problem 1.11. It implies
`there-is-a-finitely-presented-infinite-torsion-group` through
`fp-infinite-torsion-group-from-f-infinity-example`.

**Constraint.** A torsion group of type F∞ has infinite cohomological
dimension, since nontrivial finite subgroups force `cd = infinity`. So no
finite-dimensional classifying space can be used, and an example needs an
action on an infinite-dimensional contractible complex with finite stabilizers
(Brown's criterion) or an equivalent algebraic route.

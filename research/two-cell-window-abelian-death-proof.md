Section 4 of the artifact.

For `Omega = {1, d}` the set `Omega^(-1) Omega` is `{1, d, d^(-1)}`. The window
localization puts a nontrivial element of the sofic radical in it, and the
radical is a subgroup, so `d` itself lies in `Rad_sof(H)`.

The quotient `H -> H^(ab)` has abelian image, abelian groups are amenable, and
amenable groups are sofic. The sofic radical is the kernel of soficization, hence
is contained in the kernel of every homomorphism onto a sofic group. So
`d in [H,H]`.

By the holonomy normal form the host is generated by the memory letters, and its
abelianization is `Z^(M \ {1}) / L` with `L` the image of the integral cycle
space under `e -> e_(m') - e_m`. The image of `d = m_1 m_2^(-1)` there is
`e_(m_1) - e_(m_2) + L`, so it vanishes exactly when that vector lies in `L`.

The corollary is the same computation against `psi : e_m -> 1`, which is defined
on the abelianization when no identification is anchored: `psi(d) = 1` for a
single memory letter, while `[H,H]` lies in `ker psi`.

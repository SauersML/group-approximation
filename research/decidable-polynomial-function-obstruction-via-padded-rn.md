Use the explicit transitive-orbit lamp presentation and polynomial-kernel
reduction in the artifact's subsidiary proofs. Finite double-coset lists make
stabilizer membership decidable. Some orbit kernel is not c.e.; otherwise
all finitely many co-c.e. orbit kernels and their intersection would be
recursive. The finite lamp presentation gives a finitely presented decidable
W=C₂ wr_O E. The word [x c x⁻¹,g] is a mixed identity exactly when g fixes
O pointwise, making the evaluation kernel non-c.e. It is co-c.e. because
W has decidable word problem and all substitutions can be enumerated.
This proves the target conditional on the new actor, without importing a
separate wreath-product finite-presentation theorem. The target's existing
alternative derivation is unchanged; this route does not certify the actor.

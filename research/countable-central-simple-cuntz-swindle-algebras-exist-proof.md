Lane proof (swarm-0917-w20-w20-bh-follow, 2026-09-20). This proof uses only linear algebra and
cardinal arithmetic.

**Setup.**
- Let `X` be a set with `|X| = ℵ_1`, and let `V = K^(X)` have basis `e_x`.
- Fix bijections `g : N × X -> X`, which exists since `ℵ_0 · ℵ_1 = ℵ_1`, and `π : N -> N × N`.
- `rank(a) = dim(aV)`, and `I = {a : rank(a) ≤ ℵ_0}`.

**Step 1: `I` is an ideal, and `Q` is uniformly simple.**
- *Ideal.* `rank(a + b) ≤ rank a + rank b` and `rank(x a y) ≤ rank a`. The sum of two countable
  cardinals is countable, so `I` is a two-sided ideal. Also `rank(1) = ℵ_1`, so `1 ∉ I` and `Q ≠ 0`.
- *Uniform simplicity.* Let `a ∉ I`, so `dim aV = ℵ_1`.
  - Choose a complement `C` of `ker a`. Then `a|_C : C -> aV` is bijective, so `dim C = ℵ_1 = dim V`.
  - Choose a linear bijection `y_0 : V -> C`, and let `y` be `y_0` viewed in `End(V)`.
  - Choose a complement `D` of `aV`. Put `x = y_0^(-1) (a|_C)^(-1)` on `aV` and `x = 0` on `D`.
  - Then `x a y v = y_0^(-1) (a|_C)^(-1) a y_0 v = v` for every `v`, so `x a y = 1` in `End(V)`.
- Hence every nonzero element `q` of `Q` has `x q y = 1`, and `Q` is simple.

**Step 2: `Z(Q) = K`.** Let `a ∈ End(V)` with `a − λ ∉ I` for every `λ ∈ K`.

*(2a) Choosing independent pairs.* We build vectors `(v_α)_(α < ω_1)` by transfinite recursion so
that the family `{v_α, a v_α : α < ω_1}` is linearly independent.
- Suppose `v_β` has been chosen for all `β < α`. Put `W = span{v_β, a v_β : β < α}`. Its dimension
  is countable because `α` is countable.
- Let `p : V -> V/W` be the projection and `C` a complement of `W`. We claim some `v ∈ C` has
  `p(v)` and `p(av)` independent.
- If not, then for every nonzero `v ∈ C` we have `p(av) = λ_v p(v)`, since `p(v) ≠ 0`.
  - So the map `T = p ∘ a ∘ (p|_C)^(-1)` of `V/W` has every nonzero vector as an eigenvector.
  - Hence `T = λ · id` for one `λ`. For independent `e, f`, `λ_(e+f)(e + f) = λ_e e + λ_f f`
    forces `λ_e = λ_f`. For `f = c e` with `c ≠ 0`, `T f = c λ_e e = λ_e f`.
  - Then `(a − λ) C ⊆ W`, so `(a − λ)V ⊆ (a − λ)W + W` has countable dimension. That says
    `a − λ ∈ I`, a contradiction.
- Take `v_α = v`. Since `v_α, a v_α` are independent modulo `W`, the enlarged family stays
  independent.

*(2b) A commutator of full rank.*
- Let `U = span{v_α, a v_α}` and choose a complement `U'`.
- Define `b` by `b v_α = 0`, `b(a v_α) = v_α`, and `b = 0` on `U'`.
- Then `[a, b] v_α = a b v_α − b a v_α = −v_α` for every `α`, so `rank [a, b] = ℵ_1` and
  `[a, b] ∉ I`.

*(2c) Conclusion.* Any central `a + I` therefore has `a − λ ∈ I` for some `λ`. Also `K -> Q` is
injective because `1 ∉ I`, so `Z(Q) = K · 1`.

**Step 3: the swindle and the unit.**
- *Cuntz pair.* Define `s_1 e_x = e_(g(0,x))` and `s_2 e_(g(n,x)) = e_(g(n+1,x))`. Their adjoints are:
  - `s_1^* e_(g(n,x)) = δ_(n0) e_x`;
  - `s_2^* e_(g(n,x)) = e_(g(n−1,x))` for `n ≥ 1`, and `s_2^* e_(g(0,x)) = 0`.

  Then `s_i^* s_j = δ_ij`, and `s_1 s_1^* + s_2 s_2^*` is the sum of the basis projections onto
  `n = 0` and `n ≥ 1`, which is `1`.
- *Decomposition.* Put `w_n = s_2^n s_1`, so `w_n e_x = e_(g(n,x))` and
  `w_n^* e_(g(m,x)) = δ_(nm) e_x`.
- *The endomorphism.* Define `σ(a)` on the basis by `σ(a) e_(g(n,x)) = w_n a e_x`. Equivalently
  `σ(a) = Σ_n w_n a w_n^*`, a sum that is finite on each basis vector.
  - `σ(1) = 1`, and `σ(c) w_n = w_n c` for every `c`.
  - So `σ(a) σ(b) e_(g(n,x)) = σ(a) w_n b e_x = w_n a b e_x = σ(ab) e_(g(n,x))`, and `σ` is a unital
    homomorphism.
- *The swindle.*
  - `σ(a) s_1 = σ(a) w_0 = w_0 a = s_1 a`.
  - `σ(a) s_2 e_(g(n,x)) = w_(n+1) a e_x = s_2 w_n a e_x = s_2 σ(a) e_(g(n,x))`.

  Multiplying by `1 = s_1 s_1^* + s_2 s_2^*` on the right gives (S):
  `σ(a) = s_1 a s_1^* + s_2 σ(a) s_2^*`.
- *The unit.* Put `u e_(g(k,x)) = e_(g(n, g(m,x)))`, where `π(k) = (n, m)`.
  - The map `(k, x) -> (n, m, x) -> g(n, g(m, x))` is a bijection of the basis, so `u` is a unit.
  - On any vector `z`, `u w_k z = w_n w_m z`.
  - So `u σ(a) e_(g(k,x)) = u w_k a e_x = w_n w_m a e_x`.
  - And `σ²(a) u e_(g(k,x)) = σ²(a) w_n w_m e_x = w_n σ(a) w_m e_x = w_n w_m a e_x`.
  - Hence `σ² = Ad(u) σ` on `End(V)`.
- *`σ` preserves `I`.* `σ(a) V = Σ_n w_n a V`, so `rank σ(a) ≤ ℵ_0 · rank a`. This is countable when
  `rank a` is. So `σ(I) ⊆ I`.
- *Descent.* `σ` induces a unital endomorphism of `Q`. The Cuntz relations, (S) and `σ² = Ad(u) σ`
  are identities in `End(V)`, so they hold in `Q`.

**Step 4: countable closure (`K` countable).**
- For `T ⊆ Q`, write `⟨T⟩_σ` for the unital subalgebra generated by `∪_(n ≥ 0) σ^n(T)`. It is
  `σ`-closed, and it is countable-dimensional when `T` is countable.
- Using Steps 1 and 2, fix two choices:
  - for each `q ∈ Q \ {0}`, elements `x_q, y_q` with `x_q q y_q = 1`;
  - for each `q ∈ Q \ K`, an element `b_q` with `[q, b_q] ≠ 0`.
- Build the chain:
  - `T_0 = ⟨s_1, s_2, s_1^*, s_2^*, u, u^(-1)⟩_σ`;
  - `T_(j+1) = ⟨T_j ∪ {x_q, y_q : 0 ≠ q ∈ T_j} ∪ {b_q : q ∈ T_j \ K}⟩_σ`.

  Each `T_j` is countable because `K` is.
- `Q_0 = ∪_j T_j` is an increasing union of `σ`-closed unital subalgebras, so it is one, of
  countable dimension.
- *Simplicity.* Each nonzero `q ∈ Q_0` lies in some `T_j`, and `x_q, y_q ∈ T_(j+1)`.
- *Centre.* Each `q ∈ Q_0 \ K` has `b_q ∈ Q_0` with `[q, b_q] ≠ 0`. So `Z(Q_0) = K`.
- The swindle identities are universal, so they hold in `Q_0`. Also `σ(u)^(-1) = σ(u^(-1)) ∈ Q_0`.

(For uncountable `K` the same closure gives dimension `|K|`.)

**Step 5: consequences.**
- *Universality.* Part 4 of `finitely-presented-cuntz-swindle-algebras-exist` applies to
  `(Q_0, s, σ, u)`, because `u` and `σ(u)` are units and `σ² = Ad(u) σ`.
- *K-theory.* Item 1 of `cuntz-swindle-factors-kill-k-theory-of-every-tensor` applies because its
  only hypothesis is the swindle structure.
- *The remark on `⟨σ(J)⟩`.* Let `J` be an ideal of a swindle algebra `A` with `σ² = Ad(u) σ`.
  - `j = s_1^* σ(j) s_1` gives `J ⊆ ⟨σ(J)⟩`.
  - `σ(A σ(J) A) = σ(A) u σ(J) u^(-1) σ(A) ⊆ ⟨σ(J)⟩`, so `⟨σ(J)⟩` is `σ`-invariant.
  - Every `σ`-invariant ideal containing `J` contains `σ(J)`.

  So `⟨σ(J)⟩` is the smallest `σ`-invariant ideal containing `J`. ∎

**Why the countable-dimension version fails and this one does not.**
- With `dim V = ℵ_0`, the only proper nonzero ideal is the finite-rank ideal `Fin`, and
  `rank σ(a) = ℵ_0 · rank a` leaves `Fin`.
- With `dim V = ℵ_1`, the ideals of `End(V)` are `0 ⊂ Fin ⊂ I ⊂ End(V)`. That list is classical and
  is not used above: only Step 1 is used. The point is that `I` is closed under countable repetition.

This is the whole trick. It is not effective, and it says nothing about finite generation.

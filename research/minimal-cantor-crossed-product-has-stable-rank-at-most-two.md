**OPEN.** Let `k` be a field, `(X,T)` a minimal homeomorphism of the Cantor set, and `R = LC(X,k) ⋊_T Z`. Is
`sr(R) ≤ 2`? Is it `1`?

If yes, `standard-normal-structure-makes-simple-ring-el-simple` gives simplicity of `EL_3(R)/Z` from Vaserstein's
Theorem 4 in a few lines. For subshift rings that conclusion is already reached without stable rank, through
Stepanov's condition (b) (`subshift-elementary-group-simple-stepanov-proof`). So the question stays open only as ring
theory.

## Attempts

- **Direct limits (works for the odometer only).** The 2-adic odometer algebra is `⋃_n M_(2^n)(k[t^{±1}])`
  (artifact §2.1), so its stable rank is ≤ 2. For a subshift, `u` and the letter cylinders already generate `R`.
  So `R` has no exhaustion by finite-type subrings containing `u`.
- **Morita / matrix formula (circular).** `R ≅ End_S(S^h ⊕ Q)` with `S = e_Y R e_Y` an induced crossed product of the
  same type. Vaserstein's formula would give ≤ 2 once there is a uniform finite bound on sr over all minimal Cantor
  crossed products. No a priori finite bound is known, and corners do not bound sr (`Z[x]` is a corner of `M_2(Z[x])`).
- **Stafford's bound by Krull dimension.** It does not apply, since `R` is not Noetherian.
- **Large subalgebra.** `A_Y`, generated by `LC(X)` and `u e_(X∖T^{-1}Y)`, is locally matricial, so it has stable rank 1.
  Elements of degree `≤ w` differ from `A_Y` only in a band of width `2w` around the cuts. The C*-proof
  (Putnam; Archey–Phillips arXiv:1505.00725) uses norm approximation and has no exact algebraic analogue here.
- **Via exchange.** If `R` is an exchange ring with cancellative `V(R)`, separativity gives `sr ∈ {1,2,∞}` (AGOP 1998,
  recalled), and stable finiteness should rule out `∞`. See `minimal-cantor-crossed-product-is-an-exchange-ring`.
- **No obstruction found.** The Laurent pairs that are not reducible in `k[u^{±1}]` become reducible in `R`, through
  nilpotent tower shifts such as `1 + u e_(X∖T^{-1}Y)`.
- **Laurent pairs are stable (established, unreviewed; sk-algebraic-putnam 2026-09-13).** If `aR + qR = R` with `0 ≠ q ∈ F[u^{±1}]`, then `a + qc ∈ GL_1(A_𝒫) ⊆ R^×` for some `c`. See `minimal-cantor-crossed-products-stabilize-laurent-pairs`. The proof lifts the residue map `V → F[u]/(q_0)` of `a` blockwise to invertible matrices. So every unimodular row over `F[u^{±1}]` is stable in `R`, while `(1+u, Φ_5(u))` is not stable in `F_2[u^{±1}]`. General second entries `b` stay open: `bR` is not characterized columnwise, and for `b = e_W` it is the set of elements with vanishing rows off `W`.
- **Reduced to the exchange property (established, unreviewed; sk-algebraic-putnam 2026-09-13).** `R` has internal cancellation, and every regular element is unit-regular (`cantor-crossed-product-idempotent-pairs-are-stable`). So, by Camillo–Yu (Comm. Algebra 22 (1994), quoted via arXiv:1402.4706), `sr(R) = 1` as soon as `R` is an exchange ring (`minimal-cantor-crossed-product-is-an-exchange-ring`). Unconditionally, unimodular pairs `(a,b)` complete to units whenever `b` is a Laurent polynomial in `u` or an idempotent.

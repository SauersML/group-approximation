Write `R = C_h`. By `harmonic-cuntz-ring-is-purely-infinite-simple`, `R` has a binary
Leavitt family `L = (s_0, s_1, t_0, t_1)`, two-sided division (`hdiv`), centre `Q`,
and unital embeddings `M_r(Q) ⊂ R` and `L_Q(1,2) ⊂ R`.

## Part 1 (simplicity)

This is the ring-general reading of Steps 1–2 of
`leavitt-unit-groups-over-every-field-simple-mod-scalars-proof`. The Lean lemmas
cited are stated for an arbitrary `[Ring R]` in `Leavitt/RootDetectionBinary.lean`
and `Leavitt/ElementaryNormalGeneration.lean`.

Let `N ⊴ EL_n(R)`, `n >= 3`, contain some `g` that is not a central scalar matrix.
- **Off-diagonal case.** If `g^(-1)` has a nonzero off-diagonal entry, then
  `exists_elGen_mem_of_offDiag_inv hcard (exists_split_annihilator L hdiv)` gives a
  nonzero root `e_ij(x) ∈ N`. It uses only `L` and `hdiv`.
- **Diagonal case.** If `g^(-1)`, hence `g` (`elMat_inv_offDiag`), is diagonal, then
  either some `[g, e_kl(a)] = e_kl(d_k a d_l^(-1) - a)` is a nonzero root in `N`, or
  `g` commutes with every root. In the latter case
  `exists_unit_elMat_eq_diagonal_of_commute_elGen` and
  `elMat_diag_central_unit_of_commute_elGen` give `g = λI` with `λ` a central unit.
  That is excluded.
- **Generation.** So `N` contains a nonzero root `e_ij(x)`. By `hdiv`, `x` has a
  sandwich `a x b = 1`, and `elementaryGroup_normal_eq_top_of_elGen_mem` gives
  `N = EL_n(R)`.

The central units of `R` are `Q^x`, so the central scalar matrices are `λI`,
`λ ∈ Q^x`. `EL_3(R)` is not contained in them, since `e_12(1)` is not scalar. So
`Λ_h` is simple, and it is infinite by part 3.

## Part 2 (generation)

`R` is generated as a unital ring by the six operators. For `n >= 3`:
- `e_ij(a)e_ij(b) = e_ij(a + b)`;
- `[e_ij(a), e_jk(b)] = e_ik(ab)` for distinct `i, j, k`.

So every `e_ij(r)` lies in the subgroup generated by the listed `e_ij(x)`.

## Part 3 (GL_n(Q))

- **Embedding.** The unital injective ring map `M_r(Q) -> R` induces an injective
  group map `EL_3(M_r(Q)) -> EL_3(R)`.
- **Block form.** `M_3(M_r(Q)) = M_(3r)(Q)`, and `EL_3(M_r(Q))` contains every
  `e_((i,a),(j,b))(q)` with `i ≠ j`. It also contains the within-block ones, as
  commutators `[e_((i,a),(j,c))(q), e_((j,c),(i,b))(1)]`. So
  `EL_3(M_r(Q)) = E_(3r)(Q) = SL_(3r)(Q)`, since `Q` is a field.
- **No scalars.** The map `M_(3r)(Q) -> M_3(R)` is unital and injective, so the
  image of `g` is `λI` only if `g = λI_(3r)`. In `SL_(3r)(Q)` that forces `λ = ±1`.
- **GL_n(Q).** The block-diagonal map in the claim is an injective homomorphism into
  `SL_(3r)(Q)`, and its last diagonal entry `1` excludes `-I`.

## Part 4 (Λ, V, SL_3(Z))

- **Setup.** `L_Q(1,2) ⊂ R` unitally. The three-leaf code `{0, 10, 11}` identifies
  `L_Q(1,2)^x ≅ GL_3(L_Q(1,2))` and sends `λ` to `λI`. By
  `leavitt-gl-equals-el-and-perfect-unit-group`, `GL_3(L_Q(1,2)) = EL_3(L_Q(1,2))`.
- **Embedding.** So `L_Q(1,2)^x ≅ EL_3(L_Q(1,2)) ⊂ EL_3(R)`, with `Q^x` mapping onto
  scalar matrices. An element mapping to `λI` in `M_3(R)` is `λI` already in
  `M_3(L_Q(1,2))`, so `Λ ↪ Λ_h`.
- **V and SL_3(Z).** `Λ` contains `V` and `SL_3(Z)`
  (`leavitt-unit-groups-over-every-field-are-simple-mod-scalars`).

## Part 5 (word problem)

By part 6 of the ring claim, the matrix of a word over `R` is computable, with
decidable equality of entries. The word is trivial in `Λ_h` iff:
- its matrix is diagonal with equal diagonal entries `d`; and
- `d` commutes with the six generators.

Then `d ∈ Q` by the centre computation. All of these are finitely many zero tests.

## Part 6 (Z)

- **Z is all of Q^x.** Every `λI`, `λ ∈ Q^x`, lies in `EL_3(L_Q(1,2)) ⊂ EL_3(R)`. So
  `Z = Q^x · I`, and `Q^x ≅ Z/2 × ⊕_p Z` is not finitely generated.
- **Neumann.** If `G` is finitely presented and `N ⊴ G`, then `G/N` is finitely
  presented iff `N` is the normal closure of finitely many elements (B. H. Neumann).
  A central `N` is the normal closure of a finite set only if it is finitely
  generated.
- So if `EL_3(R)` were finitely presented, `Λ_h` would not be.

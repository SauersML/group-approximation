**ESTABLISHED (proposed; unreviewed).**  Derivation: [[monomial-twisted-level-subpairs-cannot-certify-rank-three-proof]].
Script: `experiments/monomial-twist-loops-2026-09-17/check_twist_loops.py` (exit 0; log `run.log`).
It is a class-killing obstruction on the nonsofic side of [[rank-three-finite-twisted-kazhdan-cone-is-sofic]].
It answers the step left by (Q4) of [[perron-frobenius-compressors-cannot-close-the-level-class]]: whether
bounded twists over a character-free `H_B` are coboundaries modulo `E_B`.  For monomial twists the question is
moot.  They never need to be removed, because they cancel around loops.

## Setting

As in [[perron-frobenius-compressors-cannot-close-the-level-class]]: `R_+ = F_q[x_1..x_d]`, `R` the Laurent ring,
`Gamma = SL_3(R_+)`, `G = EL_3(R) x| SL_d(Z)` with `σ g σ^-1 = σ̂(g)`, `σ̂(x^p) = x^(σ p)`, `psi = ev_0`,
`F = PSL_3(F_q)`.  `U_k = E_3(𝔪^k)` is generated by the `e_ab(α x^m)`, `α ∈ F_q`, `m ∈ N^d`, `|m| ≥ k`.
For `B ≤ G`: `C = B ∩ Gamma`, `E_B = B ∩ EL_3(R)`, `H_B` the projection to `SL_d(Z)`, `O = R_(≥0)^d`,
`K0(H) = cone(H · O)`.

`N ≤ SL_3(R)` is the group of **monomial matrices**: one nonzero entry `c x^δ` (`c ∈ F_q^×`, `δ ∈ Z^d`) in
each row and column.  It contains the diagonal monomial torus and the signed permutation matrices, and
`σ̂(N) = N`.  The **monomially lifted part** of `B` is

```text
H_mon(B) = { σ ∈ H_B : B ∩ N σ ≠ ∅ } ,
```

a subgroup of `H_B`, because `(D σ)(D' σ') = D σ̂(D') σ σ'`.  Twists are taken modulo `E_B`: `σ ∈ H_mon(B)` as
soon as one element of the coset `E_B · uσ` is monomial.

## Theorem

**(T1) Loop theorem.**  Let `B ⊇ U_k`.  If `K0(H_mon(B))` contains a line, then `e_ab(α) ∈ C` for all
`a ≠ b` and `α ∈ F_q`.  So `SL_3(F_q) ≤ C`, `psi(C) = F` and `C_F(psi(C)) = 1`.  No condition is put on
`E_B` beyond `U_k ≤ E_B`.  None is put on the twists either: no bound, no cohomology class, and no compressor
condition.

**(T2) Finite index does not change the cone.**  If `H ≤ GL_d(Z)` is generated by `H ∩ M_d(N)` and `H' ≤ H`
has finite index, then `K0(H') = K0(H)`.

**(T3) Consequence.**  Call `B ⊇ U_k` **virtually monomially twisted** if `H_mon(γ B γ^-1)` has finite index
in `H_B` for some `γ ∈ Gamma`.  No such `B` is a Kun-Thom certificate for `T_3`.  This holds in particular in
the following cases:

- `H_B` has a finite-index subgroup with untwisted lifts `σ ∈ B`.  This is (Q4), now up to finite index.
- the lifts have diagonal monomial twists `diag(x^δ(σ))`, for an arbitrary cocycle `δ`.  The coboundary
  step, `H^1(H_B, Q^d) = 0`, and the substitution `x ↦ x^N` asked for after (Q4) are not needed.
- the twists are signed permutation matrices times diagonal monomial matrices.
- the twists lie in a `σ̂`-invariant subgroup `W ≤ SL_3(R)` with `[W : W ∩ N] < ∞`.  For example `W` may be
  finite, such as the constant twists `W = SL_3(F_q)`.
- any of these holds after conjugating `B` by some `γ ∈ Gamma`.  Such a conjugate contains `U_(2k)`, by (T4).

**(T4) Levels survive conjugation by `Gamma`.**  `E_3(R_+, 𝔪^(2k)) ≤ U_k`.  So `γ^-1 U_(2k) γ ≤ U_k` and
`γ B γ^-1 ⊇ U_(2k)` for every `γ ∈ Gamma`.

**(T5) Borel twists reach only the lowest root.**  Order the indices `y < z < x` and let `u` be lower triangular
for this order, with diagonal entries monomial units.  Suppose `B ⊇ U_k` contains lifts `u_σ σ` of this kind
for all `σ` in a subgroup `H_1 ≤ H_B` with a line in `K0(H_1)`.  Then `e_xy(α) ∈ C` for all `α`.  The loop
into a pair `(x', y')` through `z'` closes for a twist `u`, with the twist cancelling, as soon as
`(u^-1)_(z'x') = (u^-1)_(y'x') = (u^-1)_(y'z') = 0`.  For a lower-triangular `u` this holds only for
`(x', y') = (x, y)`.  For the scripted generic Borel twist the loop closes into no other pair, so the
mechanism gives only this root.  That leaves room for `psi(C) ≤ C_F(X_xy)`, where `X_xy = psi(e_xy(F_q))`.  In
that case `X_xy ≤ C_F(psi(C))`, and the centraliser condition of a certificate holds.

## Mechanism

1. *The loop.*  Take a monomial `c = D π σ ∈ B` with `π e_a = e_(π a)` and `D = diag(d_i)`.  Then
   `c e_ab(t) c^-1 = e_(πa πb)(d_(πa) d_(πb)^-1 σ̂ t)`.  Conjugate the pair `e_ab(x^m)`, `e_ba(x^m')` from `U_k`,
   with `{πa, πb} = {y, z}`.  The two twist factors are inverse to each other.  So for the third index `x`,

   ```text
   [[ e_xy(β), c e_ab(x^m) c^-1 ], c e_ba(x^m') c^-1 ]  =  e_xy( β x^(σ(m + m')) ) .
   ```

   The twist cancels, as a coboundary would, but without being one: a loop `y → z → y` telescopes any
   function `δ_y - δ_z`.
2. *Walking to a constant.*  A line in `K0(H_mon)` gives integers `n_s ≥ 1` with `Σ n_s σ_s e_(i_s) = 0`.
   Applying `σ_1^-1` gives `0 = e_(i_1) + Σ_j τ_j e_(l_j)` with `τ_j ∈ H_mon`.  Start with
   `e_xy(α x^(2k e_(i_1))) ∈ U_k` and insert the loops of the `τ_j` with `m = m' = k e_(l_j)`.  The exponent
   walks to `0`, and the result is `e_xy(α) ∈ B ∩ Gamma`.
3. *(T2).*  Let `K' = K0(H_0)` for the normal core `H_0` of `H'`.  A nonnegative `g ∈ H` has `g K' ⊆ K'`, because
   `g O ⊆ O` and `g H_0 = H_0 g`.  Also `g^n ∈ H_0`, so `g^n K' = K'`, which forces `g K' = K'`.  So `K'` is
   `H`-invariant and contains `O`.
4. *(T3).*  An infranormal `C` makes `H_B` nonnegatively generated, by (X1) of
   [[subring-level-subpairs-cannot-certify-rank-three-cone]].  If `B` is Kazhdan, `H_B` is finite, and then `C`
   is normal by (X2), or `K0(H_B)` has a line by (W2) of [[nonneg-generated-kazhdan-groups-have-nonsalient-cones]].
   (T2) passes the line to `H_mon`, and (T1) applies to `γ B γ^-1`, where `psi(γ C γ^-1) = F`.
5. *(T4).*  `z_ij(bc, r) = e_ji(r) e_ij(bc) e_ji(-r)` is the commutator
   `[e_ik(b) e_jk(r b), e_kj(c) e_ki(-r c)]`.  Both factors lie in `E_3(𝔪^k)` when `b, c ∈ 𝔪^k`.

## Calibration

- `B = G`: `H_mon = SL_d(Z)`, and `e_ab(1) ∈ G` indeed.  `B_(H,k)` with trivial twists: (T1) is (M2).
- The script builds lifts of the generators `e_12(1)`, `e_21(1)` of `SL_3(Z)` with a diagonal twist and a
  signed-permutation twist.  The composite lift of `τ = e_12(1) e_21(-1)`, with `τ(2 e_1) = -2 e_2`, yields
  `e_xy(1)` for all six pairs from `e_xy(x_2^2) ∈ U_1`, exactly as in step 2.
- `B_σ = E_θ x| <σ>` of (Q1): `H_mon = <σ>` has a salient cone (it lies in `{ <θ, ·> > 0 } ∪ 0`), so (T1) is
  silent, correctly, since `psi(C) = 1` there.
- (T2) fails without nonnegative generation: `H = <A, -1>` with `A = [[2,1],[1,1]]` has `K0(H) = R^2`, while
  `K0(<A>)` is salient.  The index-2 subgroup `<A>` loses the line.

## What is left

A level certificate now needs **essential non-monomial twists**: for every `γ ∈ Gamma`, `H_mon(γ B γ^-1)` has
infinite index in the infinite, nonnegatively generated Kazhdan group `H_B`.  By (T5), the next class is
unipotent (Borel) twists `u_σ ∈ U^-(R)` with Laurent entries.  There the loops still produce
`X_xy(F_q) ≤ C` for the lowest root, but nothing more.  The test is whether `psi(C)` can stay inside
`C_F(X_xy)`: a Kazhdan `B = < U_k, u_i σ_i >` with lower unitriangular `u_i` and `psi(C) ≤ C_F(e_31(1))`.
If it can, it is the first candidate certificate with a genuine twist.  Otherwise, run a loop calculus for
parabolic twists.

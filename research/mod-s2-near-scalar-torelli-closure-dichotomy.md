**ESTABLISHED** through `mod-s2-near-scalar-torelli-closure-dichotomy-proof`. Unreviewed; no novelty
claimed (Peter-Weyl and determinants only).

**Setting.** `M = Mod(S_2)`, `K` its Torelli group, `c : K -> Z/3` the Deligne character of
`deligne-torelli-character-counts-separating-twists` (so `E_3 = M / ker c`), `t_s` a separating twist,
`omega = exp(2 pi i/3)`. Fix an honest `rho : M -> U(d)` and put

```text
eps   = ||rho(t_s) - omega I||_op ,
G     = cl rho(M) ,     H = cl rho(K) ,     S = cl [H, H]      (closed subgroups of U(d)),
V_ab  = (C^d)^(tensor a)  tensor  (conj C^d)^(tensor b) ,  rho_ab the tensor word on it,
D(rho) = min { a + b : a - b not 0 mod 3, V_ab^S != 0 }   (min of the empty set = infinity).
```

**Statement.**

1. **(CD1) The Torelli closure is the Deligne-kernel closure.** `H = cl rho(ker c)`. Equivalently, with
   `g_x = omega^-1 rho(t_x)` for the separating twists `t_x`, the closed group topologically generated by
   the `g_x` (all within `eps` of `I`) is `mu_3 . H` and contains `omega I`.
2. **(CD2) Dichotomy.** Exactly one of the following holds:
   - (a) `omega I in S`;
   - (b) `D(rho) < infinity`.
3. **(CD3) Torelli-abelianization by a tensor word.** If `V_ab^S != 0` with `a - b = +-1 mod 3`, then
   `sigma = rho_ab |_(V_ab^S)` is an honest Torelli-abelian representation of `M`, and
   ```text
   || sigma(t_s) - omega^(+-1) I || <= (a + b) eps ;
   ```
   replacing `sigma` by its conjugate in the case `-1` gives an approximant of `omega` itself.
4. **(CD4) Determinant bound.** If some irreducible `H`-subrepresentation `W` of `C^d` has
   `3 not | dim W`, then `D(rho) <= dim W`. Hence in case (a) every irreducible `H`-constituent of `rho`
   has dimension divisible by 3 (in particular `3 | d`).
5. **(CD5) Consequence for the reduction.** Put `c_ab = inf { ||sigma(t_s) - omega I|| : sigma honest,
   Torelli-abelian }` (so `1/3 notin Z_ab` iff `c_ab > 0`). Every honest `rho` outside case (a) satisfies
   ```text
   D(rho) . ||rho(t_s) - omega I||  >=  c_ab .
   ```
   So if `1/3 in Z_hon` but `1/3 notin Z_ab`, there are honest `rho_j` with `eps_j -> 0` each of which is
   either in case (a) or has `D(rho_j) >= c_ab / eps_j -> infinity` (so, by (CD4), every irreducible
   `H_j`-constituent of dimension prime to 3 has dimension at least `c_ab / eps_j`).

**Beyond determinants.** Determinants of Torelli constituents see only `dim W mod 3`. (CD2) goes past
them. It also covers `rho` all of whose Torelli constituents have dimension divisible by 3, as long as
`omega I notin S`; there some character of `H/S` other than a determinant detects `omega`. And (a) is
exactly the class on which **every** tensor word fails, so no tensor-word argument can do better.

**What is left of `mod-s2-near-scalar-reps-reduce-to-torelli-abelian`.** Two precise residuals:
- **(R-a)** near-`omega` honest representations with `omega I in cl[H,H]`: a compact group topologically
  generated by one `M`-conjugacy class of `eps`-near-identity unitaries whose closed derived subgroup
  contains `omega I`;
- **(R-b)** a uniform bound on `D(rho) eps` along near-`omega` sequences outside (R-a).

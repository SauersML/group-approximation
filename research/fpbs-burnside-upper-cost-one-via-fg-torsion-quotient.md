Written derivation. It is Section 5 of the linked artifact.

Fix odd `n` in the common range of the premises, and `m >= 3`. Let
`G = B(m,n)` with free generators `x_1, ..., x_m`, and let `N` be the normal
closure of `x_1`.

1. **The split.** By `fpbs-burnside-normal-closure-split`:
   - `N` is infinite;
   - `G/N ≅ B(m-1,n)`.

   So the quotient is infinite, generated by `m-1` elements, and of exponent
   `n`.
2. **Bounded cost.** By `fpbs-burnside-common-upper-cost`, every free p.m.p.
   action of `N` has cost at most `c_n <= 2`.
3. **The outer kernel is finite.**
   - If `pi(gamma)` lies in the outer kernel `Q_0`, then `c_gamma = c_a` on `N`
     for some `a in N`. So `a^-1 gamma` centralizes `N` and has the same
     image. Hence `Q_0 = pi(C_G(N))`.
   - `C_G(N) <= C_G(x_1)`, which is cyclic by
     `fpbs-burnside-embedding-input`.
   - A cyclic subgroup of a group of exponent `n` has order dividing `n`.
   - So `Q_0` is finite and has no infinite amenable subgroup.
4. **`G` has fixed price one.**
   `fpbs-bounded-cost-fg-torsion-quotient-price-one` gives this, so
   `C^*(B(m,n)) = 1`.
5. **Conclusion.** `fpbs-burnside-common-upper-cost` identifies `c_n` with
   `C^*(B(m,n))`. So `c_n = 1`, as in step 4 of
   `fpbs-burnside-upper-cost-one-via-normal-closure`.

**Comparison.** This replaces the full normal-subgroup premise of that route
by its finitely generated torsion case with finite outer kernel.

This is dependency bookkeeping for a written deduction, not a formal
verification.

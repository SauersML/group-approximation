**Standard inputs (not re-read for this route).**
- **(F1) Farb--Margalit**, *A Primer on Mapping Class Groups*:
  - capping a boundary component `β` with a once-punctured disc is a
    homomorphism whose kernel is generated by the twist `T_β` (Prop. 3.19);
  - the Birman exact sequence: if `χ(S_(h,j)) < 0`, forgetting the last
    puncture gives `1 → π_1(S_(h,j)) → PMod(S_(h,j+1)) → PMod(S_(h,j)) → 1`,
    whose kernel is the point-pushing subgroup `Push(π_1(S_(h,j)))` (Thm 4.6);
  - `PMod(S_(0,j))` is trivial for `j ≤ 3`, and
    `Mod(S_(1,0)) ≅ PMod(S_(1,1)) ≅ SL_2(Z)`;
  - `T_a^k = T_b^k` with `k ≠ 0` forces `a = b`, and for `g ≥ 3` a mapping
    class of `S_g` fixing every isotopy class of simple closed curve is trivial.
- **(F2) Virtual cohomological dimension**, as cited in
  `rank-lower-bounds-for-free-group-hosts-of-out-fm-and-mcg-proof`:
  - `vcd Mod(S_h) = 4h − 5` for `h ≥ 2` (Harer);
  - vcd does not depend on the torsion-free finite-index subgroup chosen
    (Serre), so it is inherited by finite-index subgroups;
  - `vcd` does not increase on passing to subgroups;
  - `vcd SL_2(Z) = 1`, since it is virtually free.
- **(F3) Surface groups.** The fundamental group of a punctured surface is free.
  Subgroups of free groups are free (Nielsen--Schreier). Abelian subgroups of the
  fundamental group of a closed surface of genus `≥ 2` are cyclic. All these
  groups are torsion-free.

**Step 1: trivial centre.** Let `L_1 ≤ Mod(S_g)`, `g ≥ 3`, have finite index,
and let `z ∈ Z(L_1)`.
1. For every simple closed curve `c` some power `T_c^k`, `k ≥ 1`, lies in `L_1`,
   because the cosets `T_c^i L_1` cannot all be distinct.
2. So `T_(z(c))^k = z T_c^k z^-1 = T_c^k`, which gives `z(c) = c` by (F1).
3. So `z` fixes every curve and `z = 1` by (F1).

Every finite-index subgroup of `Mod(S_g)` therefore has trivial centre.

**Step 2: pure classes.** `Mod^±(Σ′)` acts on the finite set of punctures and on
the finite set of boundary components, and has an orientation character. The
kernel of these actions and of the character has finite index. Let `L_1` be its
preimage under `ι`, a finite-index subgroup of `L`.

**Step 3: boundary.** There are two standard conventions.
- **Boundary allowed to move.** A boundary component then behaves as a puncture,
  and the pure orientation-preserving classes form `PMod(S_(h,m))` (standard).
  Put `L′ := L_1` and `ρ′ := ι|_(L_1)`.
- **Boundary fixed pointwise.** Cap the `b` boundary components one at a time
  with once-punctured discs. By induction, the composite of `ι` with the first
  `i` cappings is injective on `L_1`.
  - The kernel of the next capping is generated by a boundary twist (F1). That
    twist is supported in a collar of its boundary component, so it is central in
    the pure group of the current surface.
  - The current image of `L_1` is isomorphic to `L_1`. By Step 1 it has trivial
    centre, so it meets that central kernel trivially.
  - Every surface met has `χ < 0`, so any small-surface hypothesis of the
    capping statement is met. Each such surface still has a boundary component,
    and one with `χ ≥ 0` would be a disc, a once-punctured disc or an annulus.
    Their pure mapping class groups are trivial or infinite cyclic, so they
    cannot contain the copy of `L_1`.

  After `b` steps put `L′ := L_1` and let `ρ′` be the composite. It is injective
  and lands in `PMod(S_(h,m))` with `m = n + b ≥ 1`.

This proves item 0. The forgetful maps `PMod(S_(h,i+1)) → PMod(S_(h,i))` are
homomorphisms for every `i`: fill in the puncture, and isotopies extend. Since
`ρ′_i` factors through `ρ′_(i+1)`, if `ρ′_i` is injective then so is
`ρ′_(i+1)`.

**Step 4: vcd of the guest.** `vcd L′ = 4g − 5 ≥ 7` by (F2).

**Step 5: shape A.** Suppose `ρ′_0: L′ → Mod(S_h)` is injective.
1. `vcd Mod(S_h) ≥ 7`. For `h = 0` the group is trivial, and for `h = 1` it is
   `SL_2(Z)` with vcd 1. So `h ≥ 2` and `4h − 5 ≥ 4g − 5`, that is `h ≥ g`.
2. `m ≥ 1`, so `ρ′_1: L′ → PMod(S_(h,1)) = Mod(S_h, ∗)` is defined, and forgetting
   `∗` sends it to `ρ′_0`.
3. `s := ρ′_1 ∘ (ρ′_0)^-1` is a homomorphism `ρ′_0(L′) → Mod(S_h, ∗)` whose
   composite with the forgetful map is the inclusion. So the Birman sequence
   splits over `ρ′_0(L′)`.

**Step 6: shape B.** Suppose `ρ′_0` is not injective. Let `j` be the largest
index with `ρ′_j` not injective. Then `0 ≤ j < m`, because `ρ′_m = ρ′` is
injective, and `ρ′_(j+1)` is injective.
1. **`χ(S_(h,j)) < 0`.** Otherwise, since `j + 1 ≤ m`, `(h, j)` is one of
   `(0,0)`, `(0,1)`, `(0,2)` or `(1,0)`.
   - For `h = 0` the group `PMod(S_(0,j+1))` is trivial by (F1). But it contains
     the copy `ρ′_(j+1)(L′)` of the infinite group `L′`.
   - For `(1,0)` it is `PMod(S_(1,1)) ≅ SL_2(Z)`, whose vcd is 1 by (F2). But it
     contains a copy of `L′`, of vcd `≥ 7`.

   So `j ≥ 3` if `h = 0`, and `j ≥ 1` if `h = 1`.
2. **Kernel.** `K := ker ρ′_j` is normal in `L′`, and nontrivial by the choice of
   `j`. Write `p` for forgetting the last puncture of `S_(h,j+1)`, so that
   `ρ′_j = p ∘ ρ′_(j+1)`. Then `ρ′_(j+1)(K) = ρ′_(j+1)(L′) ∩ ker p`, and
   `ρ′_(j+1)` is injective on `K`. By Step 6.1 and (F1),
   `ker p = Push(π_1(S_(h,j))) ≅ π_1(S_(h,j))`.
3. **Structure of `K`.**
   - If `j ≥ 1`, then `S_(h,j)` is punctured, and `K` is free by (F3). If `j = 0`,
     then `K` embeds in `π_1(S_h)` with `h ≥ 2`.
   - In both cases `K` is torsion-free and has no subgroup `Z^2` (F3). Being
     nontrivial and torsion-free, `K` is infinite.
4. **`K` is not cyclic.** Suppose `K = <k> ≅ Z`.
   - Conjugation gives a homomorphism `L′ → Aut(Z) = {±1}`. Its kernel `L″` has
     index at most 2 in `L′`, so finite index in `Mod(S_g)`.
   - `k` commutes with `L″`, so `k ∈ Z(L″)`, which is trivial by Step 1.
   - That contradicts `k ≠ 1`.
5. **Quotient.** `L′/K ≅ ρ′_j(L′) ≤ PMod(S_(h,j))`.

**Exactly one.** A says that `ρ′_0` is injective and B says that it is not.

**Converse for A.** If `h ≥ 2`, `ρ_0: L′ → Mod(S_h)` is injective and `ρ_1` is a
lift to `Mod(S_h, ∗)`, then `ker ρ_1 ≤ ker ρ_0 = 1`. So `ρ_1` embeds the
finite-index subgroup `L′ ≤ Mod(S_g)` in `PMod(S_(h,1)) ≤ Mod^±(S_(h,1))`, a
surface with one puncture.

**Genus at most one.** Step 5.1 shows that A forces `h ≥ g ≥ 3`, so hosts of
genus `≤ 1` have shape B. `∎`

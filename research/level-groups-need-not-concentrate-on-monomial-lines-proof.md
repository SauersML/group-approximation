title: Proof that fixed points of level groups in weight buildings are read off the trace Newton cone, that unboundedness concentrates on monomial curves, and that E_θ is unbounded at every weight while pole-free on every monomial line
---

Notation as in [[level-groups-need-not-concentrate-on-monomial-lines]].  Throughout, `E` is a level group:
`U_k ≤ E ≤ SL_3(R)`.  Fix `w ∈ Q^d \ 0`; `O_w ⊂ K_w` is the valuation ring of the completion, a complete
discrete valuation ring (`v_w` has value group `(1/N) Z` for a common denominator `N` of `w`).

## Step 0. Two facts used below

**(F1) Monomial valuations do not cancel.**  For `f = Σ c_p x^p ∈ R`, `v_w(f) = min { <w, p> : c_p ≠ 0 }`.
This is the definition of `v_w`; it is a valuation because the initial form (the sum of the terms attaining
the minimum) of a product is the product of the initial forms, and `R` is a domain.

**(F2) Elementary groups over an ideal.**  For a commutative ring `A`, an ideal `J` and `n ≥ 3`, the group
`E_n(J) = < e_ab(j) : j ∈ J >` contains the relative elementary group `E_n(A, J^2)`.  Proof: `E_n(A, J^2)` is
generated by `e_ba(r) e_ab(y) e_ba(-r)` with `y ∈ J^2`, `r ∈ A`.  For `y = bc`, `b, c ∈ J`, pick `k ∉ {a, b}`:
`e_ab(bc) = [e_ak(b), e_kb(c)]`, and conjugation by `e_ba(r)` sends `e_ak(b)` to `e_ak(b) e_bk(rb)` and
`e_kb(c)` to `e_kb(c) e_ka(-cr)`, both in `E_n(J)`.  Sums of such `y` are handled by multiplying.

For `A = F_q[t]`, `J = t^n A`, `E_3(A, J^2)` has finite index in `SL_3(A)` (Bass-Milnor-Serre: for `n ≥ 3` and a
Dedekind ring of arithmetic type the relative elementary group equals the principal congruence subgroup).  So
`E_3(t^n F_q[t])` has finite index in `SL_3(F_q[t])`; this is the hypothesis of (L1) of
[[level-subpair-line-sections-are-bounded-or-cofinite]], which that node uses in the same way for `Δ_m`.

## Step 1. The trace criterion (Z1)

*Spanning.*  For `a ≠ b` and `|m| ≥ k`, `e_ab(x^m) - 1 = x^m E_ab`.  Let `Λ` be the `O_w`-span of `E` inside
`M_3(K_w)`.  Since `E` is a group, `Λ` is closed under multiplication.  Its `K_w`-span contains `x^m E_ab`
and the products `x^(2m) E_ab E_ba = x^(2m) E_aa`, hence all matrix units: it is `M_3(K_w)`.  Choose
`g_1, .., g_9 ∈ E` forming a `K_w`-basis of `M_3(K_w)` (possible since `E` spans).  The trace form
`(X, Y) ↦ tr(XY)` is nondegenerate on `M_3(K_w)`, so the Gram matrix `D = (tr(g_i g_j))` is invertible.

*(⇐, bounded traces give a lattice; Bass's lemma).*  Assume `tr(g) ∈ O_w` for all `g ∈ E`.  Then
`tr(λ) ∈ O_w` for all `λ ∈ Λ`, by linearity.  Let `h_1, .., h_9` be the trace-dual basis,
`tr(h_i g_j) = δ_ij` (it exists because `D` is invertible).  Every `λ ∈ Λ` is `λ = Σ_j tr(λ g_j) h_j`, and
`λ g_j ∈ Λ`, so the coefficients lie in `O_w`.  Hence `Λ ⊆ Σ_j O_w h_j`, a free module of rank 9, and `Λ` is
finitely generated (`O_w` is noetherian).  The `O_w`-module `L = Λ · O_w^3 ⊆ K_w^3` is then finitely generated, torsion-free,
contains `O_w^3` (as `1 ∈ Λ`), so it is a lattice, and `g L = L` for `g ∈ E`.  So `E` fixes the vertex `[L]`.

*(⇒, a fixed point bounds traces).*  `SL_3(K_w)` acts on `X_w` preserving types, so the stabiliser of any
point fixes the vertices of its support facet, and lies in the stabiliser `g SL_3(O_w) g^-1` of a lattice
class `[g O_w^3]`.  Elements of `g SL_3(O_w) g^-1` have trace in `O_w`.

*(Newton form).*  By (F1), `v_w(tr g) ≥ 0` iff `<w, p> ≥ 0` for every `p ∈ supp(tr g)`.  Taking all `g ∈ E`,
`w ∈ W(E)` iff `w ∈ N(E)^∨ = Ncone(E)^∨`.

*(Invariance).*  For `u σ ∈ G` with `σ ∈ SL_d(Z)` and `σ̂(x^m) = x^(σ m)`:
`tr(u σ̂(g) u^-1) = σ̂(tr g)`, whose support is `σ supp(tr g)`.  If `B ⊇ U_k` normalises `E_B`, then
`N(E_B)` is `H_B`-invariant.  For `|m| ≥ k`, `tr(e_12(x^m) e_21(x^m)) = 3 + x^(2m)`, so `2m ∈ N(E_B)`.  Hence
`Ncone(E_B) ⊇ cone(H_B · O) = K0` up to closure, and `W(E_B) ⊆ K0^∨`, which is (Y1). ∎(Z1)

## Step 2. Curve concentration (Z2)

Let `a ∈ Z^d_(>0)` be primitive and `φ = φ_a`.  Since every `a_i > 0`, `φ(R_+) ⊆ F_q[t]` and
`φ(x^m) = t^(<a, m>)` with `<a, m> ≥ |m|`.  The numerical semigroup generated by `a_1, .., a_d` has finite
complement (as `gcd(a) = 1`), so there is `n` such that every `j ≥ n` equals `<a, m>` for some `m ∈ N^d`
with `|m| ≥ k` (take `m = m_0 + k e_1` with `<a, m_0> = j - k a_1` for `j` large).

*Coefficient convention.*  We read `U_k` as generated by `e_ab(c x^m)`, `c ∈ F_q`, `|m| ≥ k`, which is the
convention under which (L2) of [[level-subpair-line-sections-are-bounded-or-cofinite]] gets
`Δ_m ⊇ E_3(t^n F_q[t])`.  With coefficient `1` only, `U_k` has coefficients in `F_p` (products and powers of
`e_ab(x^m)` never leave `F_p`), and both (L2) and (Z2) should be read with `q = p`, which the open question
allows.  Either way `φ(U_k) ⊇ E_3(t^n F_q[t])`, which has finite index in `SL_3(F_q[t])` by (F2).

So `φ(E)` contains the group `Γ_0 = E_3(t^n F_q[t])` of (L1), and (L1) gives: `φ(E)` has finite index in `SL_3(F_q[t^(±1)])`, or it fixes a vertex at `t = 0` and
has pole order at most `2n`.

*Unbounded images from unbounded traces.*  Suppose `a ∉ W(E)`.  By (Z1) there is `g ∈ E` and `p ∈ supp(tr g)`
with `<a, p> < 0`.  Let `Σ = supp(tr g)`, a finite set.  The set
`U_g = { a' ∈ R^d_(>0) : min_(p ∈ Σ) <a', p> < 0 }` is an open cone containing `a`.  Off the finitely many
hyperplanes `<a', p - p'> = 0` (`p ≠ p'` in `Σ`), the minimum of `<a', ·>` on `Σ` is attained at one point
`p_0`, so for primitive integral `a'` there, `φ_(a')(tr g)` has the nonzero term `c_(p_0) t^(<a', p_0>)` of
lowest degree, which is negative.  A bounded subgroup of `SL_3(F_q((t)))` has traces in `F_q[[t]]`, so
`φ_(a')(E)` is unbounded, hence of finite index.

For a survivor of (Y2), `W(E_B)` lies in `{ w : w_l = 0 for l ∈ M }`, so it misses the open orthant.  Every
primitive `a > 0` lies in some `U_g`, and inside `U_g` the exceptional directions lie in finitely many
hyperplanes.  So the exceptional set is contained in a locally finite union of rational hyperplanes of the
open orthant. ∎(Z2)

## Step 3. The counterexample E_θ (Z3)

Fix `θ ∈ R^d_(>0)`, `d ≥ 2`, with `Q`-linearly independent coordinates (e.g. `θ = (1, 2^(1/d), .., 2^((d-1)/d))`,
independent over `Q` since `X^d - 2` is irreducible).  Then
`<θ, p> ≠ 0` for all `p ∈ Z^d \ 0`, and `θ` lies in no proper rational subspace of `R^d`.

*The monoid and the ring.*  `P_θ = { p : <θ, p> > 0 } ∪ {0}` is closed under addition and `P_θ ∩ -P_θ = {0}`.
`S_θ = F_q[P_θ]` is the span of `x^p`, `p ∈ P_θ`, a subring of `R` containing `R_+` (as `N^d ⊆ P_θ`).  Its
augmentation `ε : S_θ → F_q`, `x^p ↦ 0` for `p ≠ 0`, is a ring homomorphism because `P_θ \ 0` is an ideal of
the monoid (a sum with a nonzero element of `P_θ` is nonzero, by pointedness).  `I_θ = ker ε`.

*(1)*  `E_θ = E_3(S_θ, I_θ)` is the normal closure in `E_3(S_θ)` of `{ e_ab(y) : y ∈ I_θ }`.  It contains
`e_ab(c x^m)` for `m ∈ N^d \ 0`, so `U_1 ≤ E_θ` (with either coefficient convention).  It lies in the kernel
`SL_3(S_θ, I_θ)` of `ε`, so `e_ab(1) ∉ E_θ`.  `E_θ ∩ Gamma ⊆ SL_3(R_+, R_+ ∩ I_θ)`, and `R_+ ∩ I_θ` is the
maximal ideal at the origin, so `ev_0(E_θ ∩ Gamma) = 1`.

*(2)*  By Suslin's normality theorem, `E_n(A, J)` is normal in `GL_n(A)` for every commutative `A`, ideal `J`
and `n ≥ 3`.  With `A = S_θ ⊇ R_+`: `E_θ` is normalised by `SL_3(S_θ) ⊇ Gamma`.

*(3)*  Let `w ∈ Q^d \ 0`.  The open cone `V = { p ∈ R^d : <θ, p> > 0, <w, p> < 0 }` is empty only if
`{ <θ, ·> > 0 } ⊆ { <w, ·> ≥ 0 }`, i.e. `w ∈ R_(≥0) θ`; that is impossible for rational `w ≠ 0`, because
`θ` is not proportional to a rational vector (`d ≥ 2`).  A nonempty open cone contains lattice points; pick
`p ∈ V ∩ Z^d`.  Then `p ∈ P_θ \ 0`, `g = e_12(x^p) e_21(x^p) ∈ E_θ` and `tr g = 3 + x^(2p)`.  By (F1),
`v_w(tr g) = min(v_w(3), 2 <w, p>) = 2 <w, p> < 0` (the constant has value `0` or `∞`).  By (Z1), `E_θ` fixes
no point of `X_w`.  So `W(E_θ) = ∅`.

*(4)*  Let `m ∈ Z^d \ 0` be primitive and `t = x^m`.  Replace `m` by `-m` if needed so that `<θ, m> > 0`, and
put `s = x^m` (so `s = t^(±1)`).  A monomial `s^j` is in `S_θ` iff `j <θ, m> > 0` or `j = 0`, iff `j ≥ 0`.  So
`S_θ ∩ F_q[s^(±1)] = F_q[s]` and `I_θ ∩ F_q[s] = s F_q[s]`.  An element of `Δ_m` has entries in
`F_q[s^(±1)]`, lies in `SL_3(S_θ)` and is `≡ 1 mod I_θ`; so `Δ_m ≤ SL_3(F_q[s], s F_q[s])`.  It fixes the
standard vertex of the `s`-adic building, and has pole order `0` at `s = 0`.  For `m ∈ N^d \ 0` this is the
`t = 0` end of (L2).  Since `E_θ` is `Gamma`-invariant (2), the line sections of `γ E_θ γ^-1 = E_θ` are the
same: no `Gamma`-conjugate of an element of `E_θ` has a pole on any monomial line either.

*(5)*  Let `a ∈ Z^d` be primitive and `j ∈ Z`.  The affine lattice `{ p ∈ Z^d : <a, p> = j }` is a translate of
the rank-`(d - 1)` lattice `a^⊥ ∩ Z^d`, which spans `a^⊥`.  The functional `<θ, ·>` is nonzero on `a^⊥` (else
`θ ∈ R a`, impossible), so it takes arbitrarily large values on this affine lattice.  Pick `p` there with
`<θ, p> > 0`.  Then `e_ab(c x^p) ∈ E_θ` for all `c ∈ F_q` and `φ_a(e_ab(c x^p)) = e_ab(c t^j)`.  These generate
`E_3(F_q[t^(±1)]) = SL_3(F_q[t^(±1)])` (a Euclidean ring).  So `φ_a(E_θ) = SL_3(F_q[t^(±1)])`. ∎(Z3)

## Step 4. The normaliser kills E_θ (Z4)

*Newton cone of `E_θ`.*  Every `g ∈ E_θ ≤ SL_3(S_θ)` has `tr g ∈ S_θ`, so `N(E_θ) ⊆ P_θ`.  By (3),
`2p ∈ N(E_θ)` for every `p ∈ P_θ \ 0` (`tr(e_12(x^p) e_21(x^p)) = 3 + x^(2p)`).  So
`Ncone(E_θ) = H_θ := { v : <θ, v> ≥ 0 }`, a closed half-space.

*Normalisers.*  If `u σ ∈ G` normalises `E_θ` then, by the invariance in Step 1,
`σ H_θ = Ncone(u σ̂(E_θ) u^-1) = H_θ`.  Since `σ H_θ = { v : <σ^(-T) θ, v> ≥ 0 }`, this says
`σ^T θ = λ(σ) θ` with `λ(σ) > 0`.  So `pr(N_G(E_θ))` lies in `S = { σ ∈ SL_d(Z) : σ^T θ ∈ R_(>0) θ }`, and
`λ : S → R_(>0)^×` is a homomorphism.  If `λ(σ) = 1`, the fixed space of `σ^T` is a rational subspace
containing `θ`, hence `R^d`, so `σ = 1`.  So `S` embeds in `R_(>0)^×` and is abelian.

*Consequence.*  Let `B ⊇ U_k` with `E_B = E_θ`.  Then `H_B ≤ S` is abelian.  If `B` is Kazhdan, then so is its
quotient `H_B`, which is therefore finite; then (X2) of [[subring-level-subpairs-cannot-certify-rank-three-cone]] makes `C` normal in `B`, or `C` is not
infranormal.  Either way `B` is not a certificate.  The argument used only `pr(N_G(E_B))`.

*The obstruction.*  Items (1)-(5) show that `E_θ` satisfies, as a level group: no fixed point in any `X_w`;
cofinite image on every monomial curve; pole-free sections on every monomial line, for every
`Gamma`-conjugate; `e_ab(1) ∉ E_θ`; `ev_0(E_θ ∩ Gamma) = 1`.  So each implication listed in (Z4) of the claim
has `E_θ` as a counterexample, and the line-concentration step proposed by
[[weight-bounded-level-subpairs-cannot-certify-rank-three]] is false.  Any proof that the level class is empty
must use the action of `H_B` on `E_B`, as Step 4 does for `E_θ`. ∎

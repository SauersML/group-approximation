## Why sufficient

**The internal basis.**  By the prerequisite, `J` acts faithfully on
`V = Z^((N_0))` by the shift, `e` is the projection onto `Z v_0`,
`f_(ij)` sends `v_j` to `v_i`, and since `te = es = 0` a reduced
monomial times `e` times a reduced monomial is `0` or a matrix unit; so
`I = M_fin(N_0, Z)` and `J/I = S`.  `EL_n(J)` acts faithfully on
`V^n` with basis `{1,..,n} x N_0`, and a matrix lies in the symbol
kernel iff it differs from the identity by an element of `M_n(I)`, i.e.
iff it is a finitary integral automorphism.  So the symbol kernel is
contained in `GL_fin(Z)`.

**(SK1), inclusion `>=`.**  The relative root `x_(ij)(a f_(uv))`,
`a in Z`, `i != j`, is the transvection adding `a` times the basis
vector `(j, v)` to `(i, u)`.  For a transvection inside one external
coordinate `i`, between internal indices `u != v`, pick `k != i` and any
`w` and compute in the `(i,k)` block with `a = f_(uw)`, `b = f_(wv)`:
`ab = f_(uv)`, `ba = delta_(vu) f_(ww) = 0`, `aba = 0`, so

```text
[x_(ik)(f_(uw)), x_(ki)(f_(wv))] = [[1 + ab, 0],[0, 1]] = diag(.., 1 + f_(uv), ..).
```

Both factors are relative roots, so the commutator lies in `E_n(J, I)`.
Integral row reduction shows the finitary transvections generate
`SL_fin(Z)`.

**(SK1), inclusion `<=`.**  For `g = I + h` with `h` of finite rank on
`V^n (x) Q`, define `det_fin(g)` as the determinant of `g` on any
finite-dimensional subspace containing the image of `h` and invariant
under `g` (such as the span of the image of `h` together with any finite
block on which `g` is the identity); enlarging the subspace multiplies
by `1`, and `det_fin(k g k^-1) = det_fin(g)` for every automorphism `k`
since `k h k^-1` has finite rank and the determinant on the transported
subspace is the same.  Each relative root has `det_fin = 1`, so the
normal closure `E_n(J, I)` lies in `SL_fin(Z)`.

**(SK3).**  `U = [[s, e],[0, t]]` has inverse `[[t, 0],[e, s]]`:
`U U^-1 = [[st + e, es],[te, ts]] = I` using `e = 1 - st`, `es = te = 0`,
`ts = 1`.  `U` is elementary by the manuscript's six-factor
factorization (`lem:ring-compression-cell`).  `D = diag(-1,1)` normalizes
`EL_2(J)` because `D x_12(r) D^-1 = x_12(-r)` and `D x_21(r) D^-1 =
x_21(-r)`, so `[U, D] = U (D U^-1 D^-1) in EL_2(J)`.  Multiplying,

```text
U D U^-1 D = [[s, e],[0, t]] [[t, 0],[-e, s]] = [[st - e, 0],[0, 1]] = diag(1 - 2e, 1),
```

and `1 - 2e` fixes `v_j` for `j >= 1` and sends `v_0` to `-v_0`.

**(SK2).**  The symbol kernel contains `SL_fin(Z)` by (SK1) and `eta`
by (SK3), and `GL_fin(Z)` is generated by `SL_fin(Z)` and any one
element of determinant `-1`.  Combined with the first paragraph, the
kernel is exactly `GL_fin(Z)`.

**(SK4).**  `EL_n(J) -> EL_n(S)` is onto (elementary generators lift),
so `T_n -> EL_n(S)` is onto with kernel `GL_fin(Z)/SL_fin(Z) = C_2`,
which is normal of order two, hence central.  Injectivity of
`T_n -> T_(n+1)`: an element of `EL_n(J)` that lies in `SL_fin(Z)` on the
larger basis has finitary determinant `1`, which it already had on the
smaller basis.

title: "An F_infinity group of finite cd with vanishing reduced K_0(ZG) is of type F"
---

If `G` is of type `F_∞`, `cd G < ∞` and `K̃_0(ZG) = 0`, then `G` is of type F.

So any negative answer to Zaremsky's Problem 1.21
(`zaremsky-1-21-g-times-z-type-f-implies-g-type-f`) is a torsion-free, finitely
presented group of type FP with `K̃_0(ZG) ≠ 0`. It would refute the vanishing of
`K̃_0(ZG)` for torsion-free groups, which is part of Conjecture 1.3 of W. Lück and
H. Reich, *The Baum–Connes and the Farrell–Jones conjectures in K- and
L-theory* (arXiv:math/0402405), read verbatim on 2026-09-13: "For every torsion
free group G we have K_n(ZG) = 0 for n ≤ −1, K̃_0(ZG) = 0 and Wh(G) = 0." Their
text says the K-theoretic Farrell–Jones conjecture implies Conjecture 1.1, which
for `R = Z` is equivalent to Conjecture 1.3.

Classes where the K-theoretic Farrell–Jones conjecture is proved, so where
Problem 1.21 has answer yes for every member of type `F_∞` with finite `cd`
(titles and abstracts read on arXiv 2026-09-13; theorem numbers not re-read):

- hyperbolic groups: Bartels–Lück–Reich, arXiv:math/0701434;
- virtually solvable groups: Wegner, arXiv:1308.2432;
- lattices in virtually connected Lie groups: Kammeyer–Lück–Rüping, arXiv:1401.0876;
- mapping class groups: Bartels–Bestvina, arXiv:1606.02844;
- cocompact CAT(0) groups: Bartels–Lück, arXiv:0901.0442. The abstract read only
  states the Borel conjecture; the needed K-theory statement is to be checked.

The conjecture passes to subgroups, finite products and directed colimits
(Lück–Reich, §5.4, table of contents read; statements not re-read), so a
counterexample lies outside the class those operations generate.

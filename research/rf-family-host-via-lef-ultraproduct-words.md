This route is independent of Wilson's theorem.

- **Theorem U.** Finitely generated residually finite groups are LEF, so a countable set of them is a countable set of countable LEF groups. Part (a) of `simple-kazhdan-lef-host-for-recursive-lef-groups` gives one host for all of them.
- **Corollary U′.** The example classes are countable up to isomorphism by the counting already recorded in the target claim. □

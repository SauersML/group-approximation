Notation is as in the target. All scripts are in `experiments/higman-pro2-order-of-a-2026-09-19/`,
and `results.txt` holds their outputs.

## 1. The cap

Let `x^y = x^3`, where `x` has order `2^e`. Then `x^(y^j) = x^(3^j)` for all `j`. If `y^(2^m) = 1`, then
`x = x^(3^(2^m))`, so `2^e` divides `3^(2^m) - 1`.

- For `m = 0` this is `3 - 1 = 2`, so `x^2 = 1`.
- For `m >= 1`, `v_2(3^(2^m) - 1) = v_2(3 - 1) + v_2(3 + 1) + m - 1 = m + 2` (lifting the exponent), so
  `x^(2^(m+2)) = 1`.

In a 2-quotient of `Gamma_k` apply this along `b -> c -> d -> a` (the relations `c^b = c^3`, `d^c = d^3`,
`a^d = a^3`).

- For `k >= 1`: `ord(c) | 2^(k+2)`, then `ord(d) | 2^(k+4)`, then `ord(a) | 2^(k+6)`.
- For `k = 0`: `c^2 = 1`, then `ord(d) | 8`, then `ord(a) | 32`.

This is the cap of `higman-j-odometer-models-restrict-to-single-cycle-models`, restated with the
`m = 0` case made exact.

## 2. The p-quotient computation

`grow2.g` with `loop2.g` (or `loop3.g`) runs GAP's own lower exponent-2 central p-quotient loop
(`lib/pquot.gi`: `DefineNewGenerators`, `ComputeTails`, `EvaluateConsistency`, `LiftEpimorphism`,
`IncorporateCentralRelations`) on `G/<<EXTRA>>`. With `KEEP` larger than every layer it adds nothing, so
it computes the full `P_cl`. The only additions are two things.

- Checkpoints. `loop2.g` saves a workspace after each class. `loop3.g` saves after each phase of a
  class, so that one class may span several 1200 s runs.
- Order tracking. Let `x` have order `2^e` in `P_cl`. Then `x^(2^e)` lies in the new central
  elementary abelian layer of `P_(cl+1)`. Its coordinates there are the tail vector `TailOfPower`,
  read from the collector before the layer relations are imposed. So `ord(x)` doubles at class
  `cl + 1` if and only if that tail is not in the span of the layer relations. This is exactly what
  `loop2.g` tests.

As an independent check, `loop2.g` rebuilds the pc group at the end, verifies the relators, and
recomputes the orders from scratch. This check was done for `G''` at class 11
(`relators hold: true ords recomputed [128,128,128,128]`) and for all truncated runs. `pqx.g`
computes `P_cl` directly with GAP's `EpimorphismPGroup`. It gives the `Gamma_1` (`b2`) and
`Gamma_2` (`b4`) rows of Section 5, and `mono.g` starts from the same function.

## 3. Monolithic reduction and the certified models (item 2)

Let `Q` be a finite 2-group generated by the images of `a,b,c,d`, with `ord(a) = 2^e`, and put
`z = a^(2^(e-1))`.

- If `Omega_1(Z(Q))` has rank `r > 1`, pick `K <= Omega_1(Z(Q))` of rank `r - 1` with `z` not in `K`.
  This is a complement of `<z>` when `z` lies in `Omega_1(Z(Q))`, and any rank `r - 1` subgroup
  otherwise. Then `K` is normal and `z` is not in `K`, so `Q/K` still has `ord(a) = 2^e` and is still a
  quotient of the same group.
- The loop stops when `Omega_1(Z(Q))` has rank 1. Then every nontrivial normal subgroup of the 2-group
  `Q` meets `Z(Q)`, hence contains the unique central involution. So `Q` is monolithic, and a subgroup
  is core-free if and only if it avoids that involution.

`mono.g` runs this from `P_8(Gamma_1)` and `P_12(Gamma_1)`. It writes the final group as a pc
presentation (`GapInputPcGroup`) together with the exponent vectors of the images of `a,b,c,d`.

- `model-b1-a32-pc.g`: order `2^14`, orders `(32,1,2,8)`. The reduction from `P_8(Gamma_1)` kills `b`,
  so this is a 2-quotient of `Gamma_0`, which attains the `k = 0` cap 32.
- `model-b2-a128-pc.g`: order `2^111`, orders `(128,2,8,32)`. This is a quotient of `Gamma_1` and
  attains the `k = 1` cap for `c`, `d` and `a` at once.

`check-model.g` reads a model file on its own and checks everything from scratch:

- the five relators of `G` hold on the four images;
- the images generate the group;
- the orders;
- `Omega_1(Z)` has rank 1.

Output (`results.txt`): `|MQ| = 2^14 ... relators hold: true generated: true ords [32,1,2,8] socle rank
1` and `|MQ| = 2^111 ... relators hold: true generated: true ords [128,2,8,32] socle rank 1`.

Together with Section 1, the maximum of `ord(a)` over finite 2-quotients is exactly 32 for `b = 1` and
exactly 128 for `b^2 = 1`.

`permsmall.g` finds a core-free subgroup by growing `H` inside its normaliser one index-2 step at a time
while `z` stays outside. Faithfulness is not assumed: the script checks that the permutation image
has the full order `|MQ|` and satisfies the relators. For the `2^14` model this gives the faithful
action on 256 points `model-b1-a32-perm.g`, in which `a` has a 32-cycle.

## 4. Rotation symmetry (item 3)

`sigma: a -> b -> c -> d -> a` maps the four Higman relators of `H4(3)` to one another. It maps
`[a,c]^2` to `[b,d]^2`, and `[b,d]^2` to `[c,a]^2 = ([a,c]^-1)^2`. So it preserves the normal
closure of `{[a,c]^2, [b,d]^2}` and induces an automorphism of `G''`.

The terms of the lower exponent-2 central series are verbal, so `sigma` induces an automorphism of
every `P_cl(G'')` that carries `a` to `b` to `c` to `d`. So the four orders are equal. `P_cl(G'')` is a
quotient of `P_cl(G)`, so `ord(a)` in `P_cl(G)` is at least the common order.

## 6. The reduction

If `Gamma_k` has a 2-quotient with `ord(a) = 2^(k+6)` for every `k >= 1`, then that quotient is also a
2-quotient of `G`. So `ord(a)` is unbounded over the 2-quotients of `G`, and `a` has infinite order in
the pro-2 completion. The converse is not claimed.

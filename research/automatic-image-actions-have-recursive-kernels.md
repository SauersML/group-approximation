**ESTABLISHED** by `automatic-image-action-kernel-proof`
(self-contained; not independently reviewed; the decidability of first-order
theories of automatic structures, Khoussainov-Nerode 1995, is folklore and implies
it, but no novelty is claimed and no citation is used).

**Definitions.** Fix a finite alphabet `Σ` and a padding symbol `⋄` not in `Σ`.
For words `x_1, ..., x_r` over `Σ`, the convolution `x_1 ⊗ ... ⊗ x_r` is the word
over `(Σ ∪ {⋄})^r` of length `max |x_i|` whose `i`-th track is `x_i ⋄^(...)`. A
relation `R ⊆ (Σ*)^r` is *synchronous rational* if `{x_1 ⊗ ... ⊗ x_r : (x_i) ∈ R}`
is a regular language.

Let `G` be generated by `g_1, ..., g_m` and act on a set `S`. An *automatic
presentation* of the action consists of:
- a regular language `L ⊆ Σ*` and a surjection `ν : L -> S`;
- a synchronous rational equivalence `~ ⊆ L × L` with `x ~ y` iff `ν(x) = ν(y)`;
- for each `i`, a synchronous rational relation `E_i ⊆ L × L` with
  `ν(y) = g_i ν(x)` for every `(x, y) ∈ E_i`, and whose domain is `L`.

**Statement.** Given an automatic presentation (as finite automata), the kernel
`K` of `G ↷ S` is recursive: there is an algorithm that, given the automata and a
word `w` in `g_i^(±1)`, decides whether `w` acts trivially.

**Consequences.**
1. If a type `[A_2]` action has an automatic presentation, its image `G/K` has
   solvable word problem. So a counterexample to `a2-action-kernels-are-recursive`,
   and a witness for `some-a2-action-has-a-nonrecursive-kernel`, must have a
   non-automatic image action. Every member of the class dies at the one step where
   kernel membership is the emptiness of the regular language
   `graph(w) \ ~`.
2. In `type-a-hnn-realization-with-unsolvable-word-problem`, if `Γ ↷ X` has an
   automatic presentation in which the graph of the intertwiner `π` is synchronous
   rational, then `⟨Γ, π⟩ ≤ Sym(X)` has solvable word problem. So the realization
   must use an intertwiner that is non-synchronous-rational in *every* automatic
   presentation of `Γ ↷ X` in which `Γ` acts synchronously.
3. The class is not vacuous. Permutations given by finitely many prefix
   replacements `u_j t -> v_j t` on a regular normal form, with `|v_j| - |u_j|`
   bounded, are synchronous rational (a bounded buffer). This covers the tail-class
   actions of `F`, `T`, `V`, `nV` on eventually-constant sequences, and Houghton
   translations on rays `i a^k`. It includes the Boolean-translation and
   Houghton attempts recorded on `type-a-hnn-realization-with-unsolvable-word-problem`.
4. The only known source of hardness, the Theorem C actor of
   `a2-kernel-removal-forces-recursive-kernel` (c), multiplies coordinates
   (`(γ_1, γ_2) -> (γ_1 γ_2, γ_2)`). It lies outside the class whenever its action
   is non-automatic, which is consistent with Consequence 1. Whether it can be
   automatic for a non-virtually-abelian `Γ` is not addressed here.

**Scope.** Neither finite presentation nor type `[A_2]` is used. What is used is
only that the universal sentence `∀s: w s = s` is decided by the automata.

**Setting.** `D_1, …, D_n` are finite subsets of `Z^r` containing 0. `Λ(D; t)` is the pure complex generated by
the full assignments with `Σ x_i = t`, as in the rank-one node.

## 1. The naive statement fails

Take `r = n − 1`, `D_i = {0, e_i}` for `i < n`, and `D_n = {0, −(e_1 + ⋯ + e_{n−1})}`.
- The zero-sum full assignments are exactly "all 0" and "all nonzero".
- So `Λ(D; 0)` is two disjoint `(n−1)`-simplices, which is disconnected for every `n`.

So no bound tending to infinity holds without restricting how the `D_i` vary with `n`.

## 2. Decoupled directions: linear connectivity

**Proposition.** Suppose there are `Q`-linearly independent `u_1, …, u_k ∈ Z^r` such that each
`D_i ⊆ Z·u_{c(i)}` is an interval `{a·u_{c(i)} : −a_i ≤ a ≤ b_i}` with `a_i + b_i ≥ 1`. Let `n_c = #c^{-1}(c)`.
Then

  `conn Λ(D; 0) ≥ Σ_{c : n_c ≥ 1} (⌊n_c/2⌋) − 2 ≥ (n − k)/2 − 2`.

*Proof.*
- By independence, a full assignment has sum 0 iff the sum over each class `c^{-1}(c)` is 0. So
  `Λ(D; 0) = ∗_c Λ(D_{c^{-1}(c)}; 0)`, and each factor is a rank-one interval level-set complex.
- By Theorem L each factor is `(⌊n_c/2⌋ − 2)`-connected.
- Connectivity of joins adds, plus 2 per join: `conn(X ∗ Y) ≥ conn X + conn Y + 2`.
- Links of faces are joins of the same kind, so the inflation step of the rank-one node goes through. ∎

**Consequence.** Let `L` be a bounded full contracting RSG. Suppose its defect group has a finite-index subgroup
`⊕_c Z u_c` such that every singular point's defect set lies in a single `Z u_c` and is an interval. Then `L` is
`F_∞`, by the argument of the rank-one node with this Proposition in place of Theorem L.

## 3. The bounded-family conjecture (what RSGs need)

**Conjecture C_r.** Fix a finite family `𝔇` of finite subsets of `Z^r` containing 0. Then there are `c > 0` and
`C` such that every nonempty `Λ(D; 0)` with all `D_i ∈ 𝔇` is `(c·n − C)`-connected.

- **Why it is the right form.** In an RSG, `D_p` depends only on the B-orbit of `p`, and there are finitely many
  orbits. So the defect sets range over a finite family.
- **Why it is plausible.** For fixed `𝔇`, the zero-sum condition is a condition on the counts of each type.
  Sumsets of many copies of a set containing 0 fill the lattice points of a cone away from its boundary
  (Khovanskii-type saturation). This restores the nesting used in Theorem L, away from the boundary.
- **Status of the pentagon.** Its defect lattice contains the independent `y_0, …, y_4` with index a power of 2,
  and half-integer vectors occur (`gq-bh-finf-hyp-pentagon-three-checks.md`). So it is not literally decoupled, and
  it needs C_r or a finer basis.

## Lesson for general BH

Vector-valued flux is harmless only if it cannot form long "cycles": many different directions summing to zero.
A bounded family of defect sets forbids those cycles in the limit, and it is exactly what finitely many orbits of
singular points provide. So C_r, not an unrestricted `Z^r` lemma, is the statement to prove.

## Referee (bh-ref-q12, 2026-09-19): items 1 and 2 PASS

- **Item 1: correct.**
  - `Σ ε_i e_i + x_n = 0` forces all `ε_i = 0` when `x_n = 0`, and all `ε_i = 1` otherwise.
  - So the level set is `{0, all nonzero}`, and `Λ(D;0)` is two disjoint `(n−1)`-simplices.
  - The rank is `r = n − 1`, so the family of defect sets is unbounded, as the node says. This is what makes
    Conjecture C_r the right replacement.
- **Item 2: correct.**
  - Independence splits the zero-sum condition by class. A partial assignment is completable iff each class
    restriction is. So `Λ(D;0) = ∗_c Λ_c` exactly.
  - Each `Λ_c` satisfies Theorem L (width 0, `|D_i| ≥ 2`, `∅ ∈ Λ_c`).
  - Milnor's join bound gives `Σ_c ⌊n_c/2⌋ − 2 ≥ (n − k)/2 − 2`.
  - Links are joins of rank-one level-set complexes, so the inflation bound
    `min_F (conn lk F + |F|) ≥ Σ_c ⌊n_c/2⌋ − 2` holds, as in the rank-one node.
- **Consequence: correct.** It needs every `D_p` inside the free subgroup `⊕_c Z u_c`, which makes the zero-sum
  condition there equivalent to the one in `⟨Δ⟩`. Cocompactness, the stabilizers and contractibility of `K_0` do
  not depend on the defect group. So the `F_∞` argument of the rank-one node applies unchanged.
  - The `SV_L` clause stays conditional, as before.
- **Not checked.** The pentagon lattice statement cites `gq-bh-finf-hyp-pentagon-three-checks.md`, which is not
  reviewed here.

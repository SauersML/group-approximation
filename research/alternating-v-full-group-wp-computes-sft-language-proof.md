Notation as in the target. Commutators are `[g, h] = g h g^(-1) h^(-1)`. For a
clopen `U ⊆ X` write `ρ_U` as in the target; `ρ -> ρ̂` is an injective
homomorphism `S_5 -> V`, since prefix replacement between the five cylinders
composes like the permutations.

**Membership (clause 1).**
- `ρ_U` is given by the compact open bisection consisting of the prefix
  replacement germs of `ρ̂` times the unit arrows over `U`, together with the
  unit arrows over `C × (X \ U)`. Its source and range are all of `C × X`.
- `φ_λ` is given by the bisection `{(1_c, (λ, x))}`, as in step 5 of
  `boone-higman-via-v-times-aperiodic-sft-full-groups`.

So `E ⊆ F(T)`. By `v-times-ample-full-groups-are-generated-by-transpositions`,
`F(T) = A(T)`, hence `Q ≤ A(T)`.

**Lemma A (fibrewise calculus).** For clopen `U, W ⊆ X`, `ρ, τ ∈ S_5` and
`λ ∈ Λ`:
- (a) `[ρ_U, τ_W] = ([ρ, τ])_(U ∩ W)`;
- (b) `φ_λ ρ_U φ_λ^(-1) = ρ_(λU)`;
- (c) `ρ_U = 1` iff `ρ = 1` or `U = ∅`.

*Proof.* Every element involved preserves the `X`-coordinate except `φ_λ`.
- (a) On the fibre `C × {x}`, `ρ_U` acts as `ρ̂^([x ∈ U])` and `τ_W` as
  `τ̂^([x ∈ W])`. Their commutator on the fibre is `[ρ̂, τ̂] = ([ρ,τ])^` when
  `x ∈ U ∩ W`, and is `1` otherwise, because one of the two factors is trivial
  there.
- (b) Take `(c, y)` and put `x = λ^(-1) y`. Then `φ_λ ρ_U φ_λ^(-1)` sends
  `(c, y)` to `(ρ̂(c), y)` if `x ∈ U`, i.e. `y ∈ λU`, and fixes it otherwise.
- (c) If `ρ != 1`, then `ρ̂` moves some point `c` of one of the five cylinders.
  For any `x ∈ U`, the point `(c, x)` is moved. `∎`

For `g ∈ Λ` and `a ∈ A`, `λ U_a = { y : y(λ) = a } =: U_(λ, a)`, since
`y = λx` has `y(λ) = x(e)`.

**Lemma B (Barrington).** Every 5-cycle `ρ ∈ A_5` is a commutator `[ρ_1, ρ_2]`
of two 5-cycles.

*Proof.* Exhaustive check over the 24 five-cycles, script
`experiments/hard-minimal-sft-full-groups-2026-09-17/a5_commutator_5cycles.py`
(output `five-cycles: 24 not commutators of two five-cycles: 0`). Fix once and
for all a table `ρ -> (ρ_1, ρ_2)`. `∎`

**Construction (clause 2).** Fix the 5-cycle `ρ* = (1 2 3 4 5)`. For a 5-cycle
`ρ` and a pattern `p : F -> A` with each `g ∈ F` given by an `S`-word `u_g`, define
the word `W_ρ(p)` over `E^(±1)` by recursion on `m = |F|`.
- `m = 1`, `F = {g}`: put `W_ρ(p) = u_g ρ_(U_(p(g))) u_g^(-1)`, reading each
  letter `s` of `u_g` as `φ_s`.
- `m >= 2`: split `F` into `F_1`, `F_2` of sizes `⌈m/2⌉` and `⌊m/2⌋`, and put
  `W_ρ(p) = [W_(ρ_1)(p|F_1), W_(ρ_2)(p|F_2)]` with `(ρ_1, ρ_2)` from Lemma B.

Put `W(p) = W_(ρ*)(p)`.

*Value.* Let `[p] = ∩_(g ∈ F) U_(g, p(g))` be the cylinder of `p`. By induction
on `m`, `W_ρ(p) = ρ_([p])` in `F(T)`:
- for `m = 1` by Lemma A(b), since `u_g` evaluates to `φ_g`;
- for `m >= 2` by Lemma A(a), because `[ρ_1, ρ_2] = ρ` and
  `[p|F_1] ∩ [p|F_2] = [p]`.

By Lemma A(c), `W(p) = 1` iff `[p] = ∅`. And `[p] = ∅` iff `p` occurs at the
identity in no configuration. By shift invariance of `X`, that holds iff `p`
occurs nowhere in `X`.

*Length.* Put `h(m) = ⌈log_2 m⌉` and `L(m) = max |W_ρ(p)|` over `|F| = m`.
- `L(1) <= 2r + 1`.
- `L(m) <= 2 L(⌈m/2⌉) + 2 L(⌊m/2⌋) <= 4 L(⌈m/2⌉)`, where `L` is taken
  non-decreasing by padding the bound.
- `h(⌈m/2⌉) = h(m) - 1` for `m >= 2`.

So `L(m) <= 4^(h(m)) (2r+1) <= 4 m^2 (2r+1)`.

*Time.* The recursion tree has depth `h(m)`. Each level copies and inverts
words whose total length is at most the output length. With `n = m + r`,
writing `W(p)` takes `O(n^3 log n) ⊆ O(n^4)` steps after parsing the input.

**Complexity transfer (clause 3).**
- Let `Γ ⊇ Q` be generated by a finite set `S_Γ`. Fix `S_Γ`-words for the
  finitely many elements of `E`, and let `K` be their maximal length.
- For a pattern of size `n = m + r`, the substituted word has length at most
  `12 K n^3`, since `4 m^2 (2r+1) <= 12 n^3`. It is trivial in `Γ` iff `W(p)`
  is trivial in `F(T)`, because `Q ≤ Γ`.
- Deciding it within `C R(C l) + C l + C` with `l <= 12 K n^3` costs, for
  `n >= 12 C K` and using `R(n) >= n` and monotonicity, at most
  `C R(n^4) + C n^4 + C`.
- Adding the `O(n^4)` generation time gives `C' R(n^4) + C'` for some constant
  `C'`. Finitely many small `n` go into a table.

So the language is in `F(R_4)` with `R_4(n) = R(n^4)`.

For `Λ = Z^2`, a row word `r_0 ... r_(n-1)` is the pattern on
`F = {(i, 0) : 0 <= i < n}` with `u_((i,0)) = e_1^i`. So `m = n` and `r < n`,
and the row language is in `F(R_4)` after renaming `n`. `∎`

**What is used.**
- Finite type, minimality and freeness of `X` are not used.
- Simplicity and finite presentation of `A(T)` are not used.
- The only import is `F(T) = A(T)`, which puts `Q` inside the alternating group.
  Without it, clause 3 still holds for every finitely generated `Γ` containing
  `Q` inside `F(T)`.

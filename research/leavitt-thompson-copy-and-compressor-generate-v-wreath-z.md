**ESTABLISHED.**  Use the configuration of
`openai-nine-leaf-leavitt-configuration`: `R = L_(F_2)(1,2)`, compressor `u`,
and `J = V_(1000)`, the copy of Thompson's `V` supported on the cylinder
`[1000]`.  Then:

1. For `k >= 1`, `u^k [1000] = [0^(k+2) 1]` and `u^(-k) [1000] = [1^(k+1) 000]`.
   These cylinders are pairwise disjoint, so the copies
   `V_k = u^k J u^(-k) = V_(u^k [1000])`, `k in Z`, pairwise commute and
   generate their direct sum.
2. `<J, u> = (directSum_(k in Z) V_k) semidirect <u> ~= V wr Z`, with `u`
   acting as the shift.
3. `<J, u>` is hyperlinear if and only if `V` is hyperlinear.

**What this settles about the tower.**  In a nontrivial model, the commuting
layers `sigma(V_k)''` of `leavitt-kazhdan-relative-commutant-has-no-type-one-part`
and the shift `Ad sigma(u)` realize a model of `V wr Z`.  So an argument that
excludes faithful models using only the relations of `<J, u>` proves `V`
nonhyperlinear.  By `thompson-v-nonhyperlinearity-selects-stable-steinberg-branch`
that would already select the stable branch.

Otherwise the argument must use the Kazhdan subgroup `Gamma`, i.e. the
commutants `A_k = sigma(Gamma_k)' cap M`.  `V` is a-T-menable (Farley), so no
Kazhdan rigidity is available inside `<J, u>`.  This is the precise sense in
which property (T) of `Gamma` has to carry any tower exclusion that does not go
through the Thompson lane.

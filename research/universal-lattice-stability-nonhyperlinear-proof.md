## Setting

- `S` is a finitely generated unital ring, `n >= 3`, and `I` is a finitely generated two-sided ideal
  with `S/I` simple and infinite.
- `Γ = E_n(S)` and `Q_I = Γ / E_n(S,I)`, with `π : Γ -> Q_I` the quotient map.
- `Γ` is finitely generated: if `c_0 = 1, c_1, ..., c_r` generate `S` as a ring, then the elements
  `x_ij(c_l)` generate `Γ`. This uses `x_ij(a+b) = x_ij(a) x_ij(b)` and, for `k` distinct from `i`
  and `j` (which needs `n >= 3`), `x_ij(ab) = [x_ik(a), x_kj(b)]`.
- `||X||_2 = (tr X*X)^(1/2)` with `tr` the normalized trace. For a unitary `U`,
  `||U - 1||_2^2 = 2 - 2 Re tr U`.

**Import.** From `relative-elementary-quotients-inherit-flexible-hs-stability`, used verbatim: if
`Γ` is flexibly HS stable, then so is `Q_I`.

## Step 1. Every finite quotient of `Q_I` is trivial

Let `φ : Γ -> F` be a homomorphism to a finite group with `E_n(S,I) <= N = ker φ`. Put

```text
J = { a in S : x_12(a) in N }.
```

1. **Additive and of finite index.** `a -> φ(x_12(a))` is a homomorphism `(S,+) -> F` with kernel
   `J`. So `J` is an additive subgroup and `[S : J] <= |F|`.
2. **Independent of the position.**
   - For `i != j`, the monomial matrices `w_kl = x_kl(1) x_lk(-1) x_kl(1)` lie in `Γ`.
   - Conjugating by a product of them sends `x_12(a)` to `x_ij(±a)`.
   - `N` is normal and `J = -J`, so `x_ij(a) in N` if and only if `a in J`, for every pair `i != j`.
3. **Two-sided ideal.** Let `a in J` and `s in S`. Since `n >= 3`,

   ```text
   x_13(s a) = [x_12(s), x_23(a)],        x_13(a s) = [x_12(a), x_23(s)].
   ```

   In each commutator one factor lies in the normal subgroup `N`, by 2, so the commutator does too.
   Hence `sa` and `as` lie in `J`.
4. **Contains `I`.** `x_12(I) ⊆ E_n(S,I) ⊆ N`.
5. **Equals `S`.**
   - `J/I` is a two-sided ideal of the simple ring `S/I`, so `J = I` or `J = S`.
   - `S/J` is finite by 1, while `S/I` is infinite, so `J != I`.
   - Hence `J = S`.
6. **Conclusion.** By 2 and 5, every `x_ij(s)` lies in `N`, so `N = Γ` and `φ` is trivial.

## Step 2. Every finite-dimensional unitary representation of `Q_I` is trivial

Let `ψ : Q_I -> U(N)` be a representation.

- `H = ψ(Q_I)` is a finitely generated linear group, because `Q_I` is a quotient of the finitely
  generated group `Γ`.
- By Malcev's theorem, `H` is residually finite.
- Every finite quotient of `H` is a finite quotient of `Q_I`, so it is trivial by Step 1.
- Hence `H = 1`.

This is item 1 of the target, and it uses no stability.

## Step 3. Asymptotic representations of `Q_I` are asymptotically trivial

Assume `Γ` is flexibly HS stable, and let `σ_k : Q_I -> U(d_k)` be an asymptotic representation.

- By the import, `Q_I` is flexibly HS stable. So there are representations
  `λ_k : Q_I -> U(D_k)` with `D_k >= d_k` and isometries `P_k : C^(d_k) -> C^(D_k)` such that

  ```text
  || σ_k(x) - P_k* λ_k(x) P_k ||_2 -> 0     for every x in Q_I.
  ```

- By Step 2, every `λ_k` is trivial, so `P_k* λ_k(x) P_k = P_k* P_k = 1`.
- Hence `||σ_k(x) - 1||_2 -> 0` for every `x`. This is item 2 of the target.

## Step 4. Nontrivial quotients of `Q_I` are not hyperlinear

Let `G = Q_I / M` with `G != 1`, and suppose `G` is hyperlinear.

- `G` is countable, being finitely generated. So there are maps `τ_k : G -> U(d_k)` with
  - `||τ_k(gh) - τ_k(g) τ_k(h)||_2 -> 0`, and
  - `tr τ_k(g) -> 0` for every `g != e`.
- Then `σ_k = τ_k ∘ (Q_I -> G)` is an asymptotic representation of `Q_I`.
- Pick `x in Q_I` whose image `g` in `G` is not `e`.
  - By Step 3, `||σ_k(x) - 1||_2 -> 0`, so `Re tr τ_k(g) = 1 - ||σ_k(x) - 1||_2^2 / 2 -> 1`.
  - But `tr τ_k(g) -> 0`, a contradiction.

**The group `E_n(S/I)`.**
- The reduction map `Γ -> E_n(S/I)` is onto, since elementary generators lift.
- It kills every `x_ij(a)` with `a in I`, and hence their normal closure `E_n(S,I)`. So `E_n(S/I)` is
  a quotient of `Q_I`.
- It is nontrivial and infinite, because `a -> x_12(a)` is injective on the infinite ring `S/I`.
- So `E_n(S/I)` is not hyperlinear. This completes item 3.

## Step 5. The instance

Let `S = Z<x_1..x_4>` and `I = (2, x_(2+i) x_j - δ_ij, x_1 x_3 + x_2 x_4 - 1)`.

- **`I` is finitely generated.** It is generated by `1 + 4 + 1 = 6` elements.
- **The quotient is the Leavitt algebra.**
  - `S/I = F_2<x_1, x_2, x_3, x_4 | x_(2+i) x_j = δ_ij, x_1 x_3 + x_2 x_4 = 1>`.
  - Set `y_i = x_(2+i)`. This is exactly the presentation of `L_(F_2)(1,2)` in
    `leavitt-algebras-l-k-1-n-are-simple`, so `S/I` is simple.
- **The quotient is infinite.**
  - Write `R = S/I`. The maps `r -> (r x_1, r x_2)` and `(u, v) -> u y_1 + v y_2` are mutually
    inverse left-module maps between `R` and `R^2`, by the defining relations.
  - If `R` were finite-dimensional over `F_2`, then `dim R = 2 dim R` would give `R = 0`.
  - But `R != 0`, since a simple ring is nonzero. So `R` is infinite.
- **Variants.**
  - Replacing `2` by a prime `p` gives `L_(F_p)(1,2)`, which is simple by the same import.
  - Over `S = F_p<x_1..x_4>`, drop the generator `p`.
  - For rank `k > 4`, add the generators `x_5, ..., x_k` to `I`.
- **The cover is a residually finite Kazhdan group.**
  - `Z<X>` is a residually finite ring. For `f != 0`, pick a coefficient `c != 0` and a prime `p`
    not dividing `c`. Then `f` survives in `F_p<X> / (monomials of length > deg f)`, which is a
    finite ring.
  - So `E_n(Z<X>) <= GL_n(Z<X>)` is residually finite: an element `g != 1` has a nonzero entry of
    `g - 1`, and it stays nonzero in `GL_n` over a suitable finite quotient ring.
  - `E_n(Z<X>)` has property (T) for `n >= 3` by `ershov-jaikin-kassabov-steinberg-groups-have-property-t`.

## Remarks

- **What is actually used.** Only the import and the fact that `S/I` is simple and infinite. So the
  argument applies to any finitely generated cover `S` of any finitely presented, simple, infinite
  ring, for example the Leavitt algebras `L_K(1,n)` over finite fields `K`. The free
  algebra is universal among such covers.
- **Where it could fail.** The only nontrivial input is the descent claim. Steps 1–4 are
  elementary, so this route cannot be the weak point of the dichotomy.

## Setting

As in `free-actions-in-rover-nekrashevych-hosts-have-zero-drift`:
- `g ∈ V_d(K)`, with `K ≤ Aut(T_d)` self-similar;
- `δ_g` is the depth drift, `Δ_n = δ_(g^n)`, and `L` is a depth beyond which `g^(±1)` maps cones to cones by prefix
  replacement composed with elements of `K`.

`μ` is the uniform Bernoulli measure on `∂T_d`. `K` preserves it, so `μ(g^n B) = ∫_B d^(−Δ_n) dμ` for every
Borel set `B`.

## Statement

1. **Escaping drift gives periodic points.** If `Δ_n(x) → +∞` or `Δ_n(x) → −∞` for some `x`, then `g` has a
   periodic point.
2. **Compression gives periodic points.** If `g(W) ⊊ W` for some clopen `W`, then `g` has a periodic point.
3. **Consequences for free actions.** Let `H ≤ V_d(K)` act freely. Then for every `h ∈ H` of infinite order:
   - no clopen set is compressed by `h`;
   - no orbit of `h` has drift escaping to `±∞`;
   - every `h`-invariant measure has zero mean drift (the previous node).

   In particular `H` admits no ping-pong on clopen sets, since ping-pong requires some element to map a clopen
   set strictly inside itself. With the previous node, a free subgroup of `V_d(K)` acting freely, with `K`
   contracting, must be generated by **conservative elements whose drift cocycle is not a coboundary**.

## Proof

**1, case `Δ_n(x) → +∞`.**
- Call `a` a *future-minimum time* if `Δ_j(x) >= Δ_a(x)` for all `j >= a`. Since `Δ_n → +∞`, there are infinitely
  many, `a_1 < a_2 < …`, with strictly increasing values `Δ_(a_i)`.
- Fix `m >= L`. By pigeonhole, two points `u = g^(a_i) x` and `u′ = g^(a_k) x` with `i < k` lie in one cone
  `C_(u|m)`.
- For `a_i <= j <= a_k`, the image of `C_(u|m)` under `g^(j − a_i)` is the cone of depth
  `m + Δ_j − Δ_(a_i) >= m >= L` around `g^j x`, by induction.
- So `g^(a_k − a_i)` maps `C_(u|m)` onto a cone of depth `m + (Δ_(a_k) − Δ_(a_i)) > m` around `u′ ∈ C_(u|m)`,
  that is, strictly inside `C_(u|m)`. It does so by a prefix lengthening composed with a tree automorphism: a
  strict contraction of the ultrametric. It has a fixed point.

**1, case `Δ_n(x) → −∞`.**
- Use *record-low times* `a`, where `Δ_a < Δ_j` for all `j < a`. There are infinitely many, with strictly
  decreasing values.
- Take two record lows `u = g^(a_i)x` and `u′ = g^(a_k)x` (`i < k`) in one cone `C_(u′|m)`.
- For `a_i <= j <= a_k`, `Δ_j >= Δ_(a_k)`. So `g^(−(a_k − a_i))` carries `C_(u′|m)` through cones of depth at least
  `m` onto a cone of depth `m + (Δ_(a_i) − Δ_(a_k)) > m` around `u ∈ C_(u′|m)`.
- This is a strict contraction of `C_(u′|m)` into itself, so it has a fixed point. ∎

**2.**
- `A = W \ g(W)` is a nonempty clopen set, and the sets `g^n(A)` (`n >= 0`) are pairwise disjoint.
- So `Σ_n μ(g^n A) = ∫_A Σ_n d^(−Δ_n(x)) dμ(x) <= 1`, and `μ(A) > 0`.
- Hence `Σ_n d^(−Δ_n(x)) < ∞` for `μ`-almost every `x ∈ A`, which means `Δ_n(x) → +∞`. Apply item 1. ∎

**3.**
- If `h` has infinite order and `h^p x = x`, then `h^p ≠ 1` has a fixed point, which contradicts freeness. So `h` has
  no periodic points, and items 1 and 2 apply. (Torsion elements are excluded: for them every point is periodic.)
- Ping-pong on clopen sets `U_±`, `V_±` needs `g(∂T \ U_−) ⊆ U_+` with `U_+ ⊊ ∂T \ U_−`, which is a compression.
- The last clause is item 3 of `free-actions-in-rover-nekrashevych-hosts-have-zero-drift`. ∎

## What remains, and the circle analogy

**The circle analogy.** The odometer host `V_2(Z)` is the group of piecewise 2-adic affine homeomorphisms of
`Z_2`, with slopes in `2^Z`, and there the depth drift is `−log_2(slope)`. Its conservative twisted-drift elements
are the 2-adic analogues of piecewise-linear circle homeomorphisms with irrational rotation number and singular
invariant measure. On the circle such elements exist, but no free group acts freely (Hölder's theorem).

**Open (exact residue for synchronous contracting hosts).** Does some `V_d(K)` with `K` contracting contain `F_2`
acting freely? By this node and the previous one, such an `F_2` would be a non-ping-pong free group of
conservative elements, with twisted drift. That would be a Cantor analogue of a free group of circle rotations,
which Hölder forbids on the circle and no known theorem forbids here.

**Asynchronous RSGs** (nucleus maps that are not cone-to-cone, such as the fault moves of
`substitution-inflation-hosts-are-full-contracting-rsgs`). The proofs above use one fact: the local map on a deep
cone is a prefix change composed with an isometry. For a general nucleus they go through only if the output lag
`|γ| − |p̄(γ)|` of nucleus maps `p` is bounded below. That bound was not established.

## Lesson for general BH

In Thompson-like hosts with tree-automorphism units, **every compression creates a periodic point**: the Bernoulli
measure turns a compressed clopen set into an orbit whose drift escapes, and escaping drift into a
cone-contraction.
- **So free actions are purely conservative there.** The usual source of free subgroups, ping-pong on clopen sets,
  is unavailable.
- **The remaining free-group mechanism is sharp.** It would have to be rotation-like, which Hölder forbids on the
  circle.
- **This is a concrete, checkable obstruction** to keeping freeness in fibre-compressed Track A hosts, and it
  points again to E3′, with isotropy.

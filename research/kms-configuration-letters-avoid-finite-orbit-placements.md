## Setting

The setting is that of `kms-configuration-modules-avoid-abelian-lamp-bases`:
- `G = G(MM_k)` is the Kharlampovich--Myasnikov--Sapir group of a Minsky machine with
  `k >= 1` glasses and commands `0, ..., N` (Bull. Math. Sci. 7 (2017), §4.1);
- `T` is the normal subgroup generated by the configuration letters `x(u)`;
- `a = a_1` and `a' = a'_1`.

For a command `j`, let `V_j` be the subgroup of `T` generated by the conjugates
`g x(q_j) g^(-1)` with `g in <a, a'>`.

## Statement

Let a group `Gamma` act on a set `X`, and let `iota : G -> Gamma` be a homomorphism
such that `iota(V_j)` acts faithfully on `X`. Then at least one of the following
holds:

1. some `iota(V_j)`-orbit on `X` is infinite;
2. `iota(x(q_j))` moves points in infinitely many `iota(V_j)`-orbits.

## Consequences

1. **Finitary placements.** If `iota(V_j)` acts faithfully, then `iota(x(q_j))` does
   not act on `X` as a finitary permutation.
2. **Finite lamps, abelian or not.** Let `B` be a finite group, `Q` a group acting on a
   set `Omega`, and `iota : G -> B^(Omega) x| Q` injective. Then `iota(x(q_j))` is not
   in the base `B^(Omega)`.
   - Together with `kms-configuration-modules-avoid-abelian-lamp-bases`, no configuration
     letter can sit in the base of a permutational wreath product whose lamp group is
     finite or abelian.
   - So for these groups, "metabelian quotient into a type (A) actor, configuration
     module into lamps" fails for every finite lamp group, not only the abelian ones.

## What is left

Placements in which `V_j` has an infinite orbit, or elements moving infinitely many
orbits. An example is translation, as in the self-similar affine hosts. Those hosts
already hold Baumslag's group `F_p[t^(±1), (t-1)^(-1)] x| Z^2`, which is the subgroup
`<x(q_j), a, a'>` of `G` (see the artifact). So the lemma cannot be pushed to all
placements.

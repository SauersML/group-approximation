  faithful trace vanishing on the non-torsion image of `x`.

  with positive and negative values.

  vector at some finite stage.  So faithful stage representations have
  eventually positive rank values; negative values likewise.

  values of both signs.  Direct sums with a faithful model of `A`, with
  multiplicities chosen per `n`, produce a faithful model with value `0`.

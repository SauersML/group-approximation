Notation as in the target. Imports: (I1) `T` is simple and infinite, hence perfect
(Cannon-Floyd-Parry, *Introductory notes on Richard Thompson's groups*; standard, theorem
number not re-checked);
(I2) for dyadic rationals `a < b` and `c < d` there is a PL homeomorphism `[a,b] → [c,d]` with
finitely many dyadic breakpoints and slopes in `2^Z` (standard; the same fact that makes `F`
act transitively on dyadic intervals); (I3) part 2 of
`commensurating-loxodromics-split-their-centralizers`.

## Step 1. Item 1 (roots of z)

For `n = 1` take `ĝ = z`. Let `n ≥ 2`. Put `p_j = j/2^m` for `0 ≤ j ≤ n`, where `2^m ≥ n`, and
change `p_n` to `1`, so `0 = p_0 < p_1 < ... < p_{n-1} < p_n = 1` are dyadic. Put
`A_j = [p_j, p_{j+1})` for `0 ≤ j ≤ n−1`.
- By (I2) pick dyadic PL homeomorphisms `φ_j : A_j → A_{j+1}` for `0 ≤ j ≤ n−2`. Put
  `φ_{n−1} = (φ_{n−2} ∘ ... ∘ φ_0)^{-1} : A_{n−1} → A_0`, again dyadic PL.
- Let `g` be `φ_j` on `A_j`. It is a bijection of `S^1` that preserves the cyclic order of the
  arcs and is increasing on each, so it is an orientation-preserving PL homeomorphism with dyadic
  breakpoints and slopes in `2^Z`. So `g ∈ T`.
- `g^n` restricted to `A_j` is a cyclic rearrangement of `φ_{n−1} ∘ ... ∘ φ_0`, which is the
  identity on `A_0`. So `g^n = 1`.
- Let `ĝ` be the lift of `g` with `ĝ(0) = p_1`. On `[0,1)` it maps `[p_j, p_{j+1})` onto
  `[p_{j+1}, p_{j+2})` for `j ≤ n−2` and `[p_{n−1}, 1)` onto `[1, 1 + p_1)`. So `ĝ^j(0) = p_j`
  for `j ≤ n−1` and `ĝ^n(0) = 1`.
- `ĝ^n` lifts `g^n = 1`, so it is a translation by an integer, and `ĝ^n(0) = 1` makes it `z`.

## Step 2. Item 2 (perfect)

`T̄ → T` is onto with kernel `⟨z⟩`, and `[T̄,T̄]` maps onto `[T,T] = T` by (I1). So
`T̄ = [T̄,T̄]·⟨z⟩`, and `Ab = T̄/[T̄,T̄]` is cyclic, generated by the class `[z]`. Write it
additively.
- Take `ĝ` from Step 1 for some `n ≥ 2`. Then `[ĝ] = m[z]` for some integer `m`, and
  `[z] = n[ĝ] = nm[z]`. So `(nm − 1)[z] = 0`.
- `nm − 1 ≠ 0` because `n ≥ 2`. So `Ab` is finite cyclic, of order `d` say, and `d` divides
  `nm − 1`. Then `gcd(d, n) = 1`.
- If `d ≥ 2`, take `n = d`: then `d = gcd(d, d) = 1`, a contradiction. So `d = 1`.

Hence `T̄` is perfect, and every homomorphism to an abelian group, in particular to `R`, is `0`.

## Step 3. Item 3 (no finite-index subgroups)

Let `K ≤ T̄` have finite index, and let `N ⊆ K` be its normal core, of finite index. The image of
`N` in `T` is normal of finite index. `T` is infinite and simple (I1), so the image is `T`. Hence
`T̄ = N·⟨z⟩`, and `T̄/N` is generated by the image of `z`, so it is abelian. By Step 2 it is
trivial. So `K = N = T̄`.

## Step 4. Item 4

`z` is central in `S = T̄`, which is perfect (Step 2) and has no proper finite-index subgroup
(Step 3). Part 2 of `commensurating-loxodromics-split-their-centralizers` applies to every
`G ⊇ T̄` and every commensurating action of `G`. For an action on a CAT(0) cube complex take `X`
the half-spaces and `A` those containing a vertex `v`; then `ℓ(z^N)` is the combinatorial
distance from `v` to `z^N v`, so the orbit is bounded. ∎

## Remark (sanity check, not load-bearing)

The rotation quasimorphism `rot : T̄ → R` is not a homomorphism, as Step 2 requires. Take
`f ∈ F` with `f(1/4) = 3/4` and `r` the rotation by `1/2`. Then `r ∘ f^{-1}` fixes `3/4`, so it
and `f` both have lifts with rotation number `0`, while their product `r` has lifts with rotation
number in `1/2 + Z`, never `0`.

**Setting.**
* `R` is a unital ring with elements `t s = 1`; `q = 1 - st`. Then
  `qs = 0`, `tq = 0`, and `s q != 0` exactly when `st != 1`
  (because `t (s q) = q`).
* All matrices are in `EL_3(R)`; `x_ij(r)` is the elementary matrix.

**Certificate.** Eight elements of `EL_3(R)`, each an explicit elementary word:
* `a1 = x_13(1)`, `a2 = x_13(s)`, `a3 = x_31(1)`, `a4 = x_31(t)`;
* `c = [x_12(s), x_21(q)] = diag(1+sq, 1, 1)`;
* `d = diag(1-qt, 1, 1)`, with `d^{-1} = [x_12(q), x_21(t)]`;
* `g = x_12(s) x_21(-t) x_12(s) x_21(1) x_12(-1) x_21(1) = diag(u, 1)`,
  where `u = [[s,-q],[0,t]]` and `u^{-1} = [[t,0],[-q,s]]` (the P22 Levi
  compressor, placed on indices 1,2);
* `e = [x_21(s), x_12(q)] = diag(1, 1+sq, 1)`.

Put `U = a2 a4^{-1} a2 a1^{-1} a3 a1^{-1}`, the same compressor on indices
1,3: `U = [[s,-q],[0,t]]` on `(1,3)`. Let `A = <a1, a2, a3, a4, c, d>`.

**Relations.**
* **(C1)** `g a1 g^{-1} = a2`.
* **(C2)** `g a2 g^{-1} = c U a1 U^{-1}` (both sides equal `x_13(s^2)`).
* **(C3)** `g a3 g^{-1} = a4`.
* **(C4)** `g a4 g^{-1} = U a3 U^{-1} d^{-1}` (both sides equal `x_31(t^2)`).
* **(C5)** `g c g^{-1} = U c U^{-1}`.
* **(C6)** `g d g^{-1} = U d U^{-1}`.
* **(Z1-Z6)** `e` commutes with `a1, a2, a3, a4, c, d`.
* **(W)** `g^{-1} a1 g = x_13(t) x_23(-q)` and
  `[e, g^{-1} a1 g] = x_23(-sq)`, which is `!= 1` when `st != 1`.

The right-hand sides of (C1)-(C6) are words in the generators of `A`, so
(C1)-(C6) say `g A g^{-1} <= A`.

**Theorem.** Let `Gamma_3 = <g, e, a1, a2, a3, a4, c, d | C1-C6, Z1-Z6>`
(8 generators counting `g` and `e`; 12 relators) and `w = [e, g^{-1} a1 g]`.
* (a) For every homomorphism `phi : Gamma_3 -> F` to a finite group,
  `phi(w) = 1`.
* (b) The map `Gamma_3 -> EL_3(R)` given by the certificate sends `w` to
  `x_23(-sq)`, which is nontrivial whenever `st != 1`.
* (c) Hence `EL_3(R)` is not LEF whenever `R` is not directly finite
  (has `ts = 1 != st`). In particular `EL_3(J)` is not LEF, and neither is
  `EL_3(k<S,T|TS=1>)` for any nonzero coefficient ring `k`. `Gamma_3` is a finitely presented
  group that is not residually finite.

**The mechanism in one line.** In a finite image, `Ad phi(g)` maps the
finite group `phi(A)` injectively into itself, so onto. Then
`phi(g^{-1} a1 g)` lies in `phi(A)`, which `phi(e)` centralizes, so `phi(w) = 1`.
In `EL_3(R)` itself the inclusion `g A g^{-1} < A` is proper, since
`g^{-1} a1 g` has a nonzero `(2,3)` entry and so is not in `A` (the
elements of `A` are supported on the index set `{1,3}`, see the proof).

## Consequences

1. **The rank-three LEF question is settled negatively.** Together with
   `binary-jacobson-el2-is-lef` and `cohn-elementary-group-is-not-lef`,
   `EL_n(J)` is LEF exactly for `n <= 2`.
2. **`EL_3(J)` is not LEA.** By `jacobson-elementary-groups-are-lea-only-if-lef`
   (EL_3(J) is Kazhdan, so LEA iff LEF). Every soficity route for
   `EL_3(J)` through amenable or finite local embeddings is dead; only
   genuinely non-amenable sofic approximations remain.
3. **No partial mirror lifts at rank three.** By (L1) of
   `jacobson-el3-lef-from-local-mirror-lifts`, some finite ball of
   `EL_3(J)` has no partial iota-lift. The ball containing the prefixes of
   the 12 relators of `Gamma_3` and of `w` suffices.
4. **Parabolic threshold is sharp at rank three.** Every proper parabolic
   of `EL_3(J)` is LEF (`jacobson-rank-three-parabolics-are-lef`), yet
   `EL_3(J)` is not. The obstruction needs the full group: the image of
   `Gamma_3` contains `x_12`, `x_21`, `x_13` and `x_31` letters.
5. **The finite presentation of `EL_3(J)` is no longer needed for non-LEF.**
   `binary-jacobson-el3-is-finitely-presented` stays open, but its
   non-LEF motivation is discharged.

## Class kill

**Class.** Head-keeping models `sigma` of `EL_3(R)` (`st != 1`) in which the
subgroup `sigma(A)` has a co-Hopfian hull `H` centralized by `sigma(e)`
and with `Ad sigma(g)` mapping `H` into itself. This includes:
* finite quotients, and LEF partial models on the ball of `Gamma_3`;
* (for `R = J`) amenable local embeddings are excluded wholesale, not
  model by model: `EL_3(J)` is Kazhdan, so LEA would imply LEF;
* finite-dimensional linear representations over any field, when `H` is
  taken as the Zariski closure of `sigma(A)` (a closed subgroup of
  `GL_n(k)` mapped into itself injectively by conjugation is mapped onto
  itself, by dimension and component count). This is consistent with, and
  here made explicit on one element, the fact from Malcev's theorem that
  the finitely generated group `EL_3(J)`, which contains the infinite
  simple finitary kernel, has no faithful finite-dimensional representation.

**Invariant.** The endomorphism `Ad sigma(g)` of `H`; relations (C1)-(C6)
put it into `H`.

**Step where every member dies.** Co-Hopficity of `H` makes `Ad sigma(g)|_H`
onto, so `sigma(g)^{-1} sigma(a1) sigma(g)` is in `H`, which `sigma(e)`
centralizes, so `sigma(x_23(-sq)) = 1`.

## Why the rank-four trap does not restrict (remarks, not used in the theorem)

A restriction of `Gamma_pig` (P22) to rank three would need two Levi blocks.
What makes rank three work instead:
* conjugation by `g` maps the (1,3)-block copy of `GL_2(R)` into itself by
  `Psi(M) = D M D* + (1 - D D*)`, with `D = diag(s,1)` and `D* = diag(t,1)`,
  an injective, non-surjective ring-corner endomorphism (route, Step 2);
* on the generators of `A`, `Psi` agrees with `Ad U`, a word in `A`, up to
  the diagonal correctors `c` and `d`, which also lie in `A`; this is what
  keeps `Psi(A)` inside `A`.

The centralizer of `g` in `EL_3(J)` is `{diag(u^k, d') : k in Z,
d' in J^x}` (route, Step 6). So in rank three there is no commuting
Levi block to play the role of `r1, r2` in P22: the part of `C(g)` acting
on column 3 is `diag(1,1,d')`, which moves `x_13(r)` only to
`x_13(r d'^{-1})`. Every unit of `J` has symbol `1` (index `0`), so these
moves are never contractions like `r -> s r`. The trap above
avoids this by using elements (`a3, a4, c, d`) that do not commute with `g`
and whose `g`-conjugates are rewritten by (C2)-(C6) instead.

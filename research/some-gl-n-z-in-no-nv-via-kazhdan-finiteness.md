- `SL_3(Z)` is generated by elementary matrices, since `Z` is Euclidean, so
  `SL_3(Z) = EL_3(Z)`.
- By `elementary-groups-over-fg-rings-have-property-t` with `R = Z` and `n = 3`,
  `SL_3(Z)` has property (T). It is infinite.
- If `GL_3(Z)` embedded in some `mV`, its infinite Kazhdan subgroup `SL_3(Z)`
  would be an infinite Kazhdan subgroup of `mV`, contradicting
  `kazhdan-subgroups-of-brin-thompson-groups-are-finite`.

So `n = 3` witnesses the claim.

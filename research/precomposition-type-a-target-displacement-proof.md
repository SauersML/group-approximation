Notation is as in the claim. `K ≤ M`, `n >= 2`, `A = Aut_K(K * F_n)`, and
`b = (b_1, ..., b_{n-1}, 1)` with `⟨K, b_1, ..., b_{n-1}⟩ = M`. Put
`π = π_b` and `N = ker π`. Composition is `αβ = α ∘ β`.

## 0. Two families of automorphisms

For `i ≠ j` and `w ∈ K * F(x_k : k ≠ i)`, the maps below fix `K` and every
`x_k` with `k ≠ i`, and act on `x_i` as shown. Each is an automorphism with an
explicit inverse.

- `λ_{i,w}: x_i -> x_i w`, with inverse `x_i -> x_i w^{-1}`.
- `κ_{i,w}: x_i -> w x_i w^{-1}`, with inverse `x_i -> w^{-1} x_i w`.

The inverses work because `w` does not involve `x_i`, so it is unchanged by
either map. At a tuple `m`, `m . λ_{i,w}` replaces `m_i` by `m_i w(m)`, and
`m . κ_{i,w}` replaces `m_i` by `w(m) m_i w(m)^{-1}`, where `w(m)` is the
evaluation.

## 1. Stabilizer clause

**The stabilizer.** `α ∈ Stab_A(b)` iff `π ∘ α = π`. Then for every
`g ∈ K * F_n` we have `π(α(g)) = π(g)`, so `α(g) g^{-1} ∈ N`. Let
`D = ⟨⟨ α(g) g^{-1} : α ∈ Stab_A(b), g ∈ K * F_n ⟩⟩`. Then `D ⊆ N`.

**D is finitely normally generated.** Let `α_1, ..., α_k` generate
`Stab_A(b)`. Close the list under inverses; it stays finite. Put
`E = ⟨⟨ α_j(x_i) x_i^{-1} : all i, j ⟩⟩ ⊆ D`.

*(a) One generator, all `g`.* Fix `α = α_j`. The set `{g : α(g) g^{-1} ∈ E}`
is a subgroup, by two identities:

- `α(gh)(gh)^{-1} = [α(g) g^{-1}] · g [α(h) h^{-1}] g^{-1}`;
- `α(g^{-1}) g = g^{-1} [α(g) g^{-1}]^{-1} g`.

This subgroup contains `K`, since `α(s) s^{-1} = 1`, and every `x_i`. So it is
all of `K * F_n`.

*(b) All of the stabilizer.* Every `α ∈ Stab_A(b)` is a product of the `α_j`.
For a product,
`(αβ)(g) g^{-1} = [α(β(g)) β(g)^{-1}] · [β(g) g^{-1}]`. By induction on word
length and (a), `α(g) g^{-1} ∈ E` for every `α` and `g`. So `D = E`, which is
finitely normally generated.

**D contains N.**
- **`x_n ∈ D`.** Since `π(x_n) = b_n = 1`, the automorphism `λ_{1,x_n}` fixes
  `b`: it changes `b_1` to `b_1 · 1`. So
  `λ_{1,x_n}(x_1) x_1^{-1} = x_1 x_n x_1^{-1} ∈ D`, hence `x_n ∈ D`.
- **`N_n ⊆ D`.** Let `N_n = N ∩ (K * F(x_1, ..., x_{n-1}))`. For `w ∈ N_n`,
  `λ_{n,w}` fixes `b`: it changes `b_n = 1` to `1 · w(b) = 1`. So
  `x_n w x_n^{-1} ∈ D`, hence `w ∈ D`.
- **`N = ⟨⟨x_n⟩⟩ N_n`.** The quotient `(K * F_n)/⟨⟨x_n⟩⟩` is
  `K * F(x_1, ..., x_{n-1})`. The map `π` factors through it because
  `π(x_n) = 1`. The kernel of the induced map is the image of `N_n`, so
  `N = ⟨⟨x_n⟩⟩ N_n`.

Hence `N ⊆ D`, so `N = D` is finitely normally generated. Then
`M ≅ (K * F_n)/N` is finitely presented relative to `K`. If `K` has a finite
presentation `⟨Y | R⟩`, then `M = ⟨Y, x | R, finitely many relators⟩`. This
proves clause 1.

**Transfer along orbits.** Suppose `b'` is redundant with `b'_n ∈ ⟨K, b'_1, ..., b'_{n-1}⟩`,
say `b'_n = w(b')` with `w ∈ K * F(x_1, ..., x_{n-1})`. Then
`b' . λ_{n,w^{-1}}` has last coordinate `1`, and stabilizers along an orbit are
conjugate. So the hypothesis may be checked at any redundant tuple, as the claim
says.

## 2. Pair invariant

For `m, m' ∈ M^n`, let `H(m, m') ≤ M × M` be the image of
`π_m × π_{m'}: K * F_n -> M × M`. It is generated by `(s, s)` for `s ∈ K` and
`(m_i, m'_i)`. For `α ∈ A`,
`(π_m ∘ α) × (π_{m'} ∘ α) = (π_m × π_{m'}) ∘ α`, and `α` is surjective. So `H` is
constant on `A`-orbits of pairs, and so is
`L(m, m') = {y ∈ M : (1, y) ∈ H(m, m')}`.

## 3. Normal subgroups (clause 2)

Let `ℓ ∈ M`. Since `⟨K, b_1, ..., b_{n-1}⟩ = M`, there is
`w ∈ K * F(x_1, ..., x_{n-1})` with `w(b) = ℓ`. Then
`b^ℓ := b . λ_{n,w} = (b_1, ..., b_{n-1}, ℓ)` lies in `Ω`. Put
`H = H(b, b^ℓ)`.

- **`H` contains `Δ(M) · (1 × ⟨⟨ℓ⟩⟩_M)`.** `H` contains `(s, s)` and
  `(b_i, b_i)` for `i < n`, which generate the diagonal `Δ(M)`. It also contains
  `(1, ℓ)` and its `Δ(M)`-conjugates `(1, g ℓ g^{-1})`. So it contains the set
  displayed.
- **That set is a subgroup containing the generators.** `1 × ⟨⟨ℓ⟩⟩` is
  normalized by `Δ(M)`, and the generators of `H` lie in the product. So `H`
  equals the product.
- **`L(b, b^ℓ) = ⟨⟨ℓ⟩⟩_M`.** If `(1, y) = (g, g)(1, z)` with `z ∈ ⟨⟨ℓ⟩⟩`, then
  `g = 1` and `y = z`.

Distinct normal closures `⟨⟨ℓ⟩⟩` therefore give pairs in distinct orbits. If
there are finitely many orbits on `Ω × Ω`, then `M` has finitely many normal
subgroups of the form `⟨⟨ℓ⟩⟩`. Every normal subgroup `L` is the join of the
`⟨⟨ℓ⟩⟩` with `ℓ ∈ L`, so it is a join of members of a finite family. So `M` has
finitely many normal subgroups. Every subgroup of `Z(M)` is normal, so `Z(M)`
has finitely many subgroups and is finite.

## 4. Centralizer (clause 3)

Let `c ∈ C_M(K)`. Then `c b c^{-1}` lies in the orbit of `b`, by the following
moves.

1. **Put `c` in the free slot.** Precompose by `λ_{n,w}` with `w(b) = c`, which
   gives `(b_1, ..., b_{n-1}, c)`.
2. **Conjugate the first `n - 1` coordinates.** For `i = 1, ..., n-1` in turn,
   precompose by `κ_{i,x_n}`. This replaces `m_i` by `c m_i c^{-1}` and leaves
   the others alone. The result is `(c b_1 c^{-1}, ..., c b_{n-1} c^{-1}, c)`.
3. **Empty the free slot.** `⟨K, c b_i c^{-1} : i < n⟩ = c ⟨K, b_i : i < n⟩ c^{-1} = M`,
   because `c` centralizes `K`. So some `v ∈ K * F(x_1, ..., x_{n-1})` evaluates
   to `c^{-1}` at the current tuple. Precomposing by `λ_{n,v}` gives
   `(c b_1 c^{-1}, ..., c b_{n-1} c^{-1}, 1) = c b c^{-1}`.

Now `H(b, c b c^{-1}) = {(g, c g c^{-1}) : g ∈ M}`, the graph of `inn(c)`.
It contains the generators `(s, s) = (s, c s c^{-1})` and
`(b_i, c b_i c^{-1})`, and it is a subgroup. The graph determines `inn(c)`.

- **Distinct orbits.** Classes of `C_M(K)` modulo `Z(M) ∩ C_M(K)` give pairs in
  distinct orbits. Finitely many pair orbits force `C_M(K) / (Z(M) ∩ C_M(K))`
  to be finite.
- **Conclusion.** `Z(M)` is finite by §3, so `C_M(K)` is finite.

## 5. Sanity checks

- **BFFHZ case.** `M = K = G` is finitely presented simple MIF, and
  `b = (1, ..., 1)`. The conclusions hold: `G` is finitely presented, has two
  normal subgroups, and `C_G(G) = Z(G) = 1`.
- **`K = 1`, `M = Z`.** Take `b = (1, 0, ..., 0)` in additive notation. The
  action of `Aut(F_n)` on `Z^n` factors through `GL_n(Z)`. The stabilizer of
  `b` is the preimage of the stabilizer of `e_1`, an extension of a finitely
  generated affine group by the finitely generated `IA_n` (Magnus). So it is
  finitely generated, and clause 1 correctly allows the finitely presented `Z`.
  Clause 3 fails, since `C_Z(1) = Z` is infinite. Correspondingly, the invariant
  `L(b, b^ℓ) = ℓZ` takes infinitely many values, so the pair orbits are
  infinite. The checks are consistent.
- **Where `H` is the whole graph in §4.** `H` projects onto `M` in the first
  coordinate, so it is not a proper subgroup of the graph.

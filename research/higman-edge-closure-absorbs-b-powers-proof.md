Conventions: `x^y = y^-1 x y`, `H4(n)` and `A_M = <a^M, c^M>` as in the target. **[U]** is
`higman-power-pair-collapse-is-base-uniform-up-to-torsion` (item 1 there: for every quotient and
every `M`, `A_M` is free on `a^M, c^M` or `A_M / A_M'` is finite).

## Step 0 (orders in a finite image are prime to n)

Let `Q` be finite. Since `a^-1 b a = b^n`, the elements `b` and `b^n` are conjugate, so they have the
same order, and `gcd(n, ord(b)) = 1`. In the same way `gcd(n, ord(c)) = 1` (from `c^b = c^n`),
`gcd(n, ord(d)) = 1` and `gcd(n, ord(a)) = 1`. So `n` is a unit modulo each of these orders. For
`k ∈ Z` write `n^k` also for the residue it defines modulo the relevant order; this is meaningful
for `k < 0` too.

## Step 1 (the two commutation rules)

In a finite image, for all integers `k, nu`:

```text
(R1)  b^k a^nu = a^nu b^(k n^nu),
(R2)  b^k c^mu b^-k = c^(mu n^-k).
```

For (R1): `a^-1 b a = b^n` gives `a^-nu b a^nu = b^(n^nu)` for `nu >= 0`. For `nu < 0`, conjugate
the case `-nu` back: `a^nu b^(n^(-nu)) a^-nu = b`, so `a^-nu b a^nu` is the unique element
`x ∈ <b>` with `x^(n^(-nu)) = b`, namely `b^(n^nu)` (the power map `x -> x^(n^-nu)` is a bijection
of `<b>` by Step 0). So `a^-nu b^k a^nu = b^(k n^nu)` for all `nu`, which is (R1).

For (R2): `b^-1 c b = c^n` gives `b^-k c b^k = c^(n^k)` for `k >= 0`, hence
`b^k c b^-k = c^(n^-k)` for `k >= 0`. The case `k < 0` is the same argument with the roles
exchanged, and raising to the power `mu` gives (R2). Note that `c^(mu n^-k)` lies in `<c^M>` when
`M | mu`.

## Step 2 (item 1: finite absorption)

Let `w = x_1^(eps_1) ... x_r^(eps_r)` with each `x_i ∈ {a^M, c^M}` and `eps_i = ±1`. Put
`K_0 = 1`, and `K_i = K_(i-1) n^(±M)` if `x_i = a^M` with sign `±`, and `K_i = K_(i-1)` otherwise,
as residues modulo `ord(b)`. Then `K_r = n^(M e)` with `e = e_{a^M}(w)`, so that
`M e = e_a(w)`.

Claim: `b w = w_r b^(K_r)` with `w_r ∈ A_M`. Induct on `i` with `b x_1^(eps_1)...x_i^(eps_i) =
w_i b^(K_i)`, `w_i ∈ A_M`. For the step, multiply on the right by `x_(i+1)^(eps_(i+1))`:
- if it is `a^(±M)`, then (R1) gives `b^(K_i) a^(±M) = a^(±M) b^(K_i n^(±M))`, and
  `w_(i+1) = w_i a^(±M)`;
- if it is `c^(±M)`, then (R2) gives `b^(K_i) c^(±M) = c^(±M n^(-K_i)) b^(K_i)`, and
  `w_(i+1) = w_i c^(±M n^(-K_i)) ∈ A_M`.

Here `n^(-K_i)` is taken modulo `ord(c)`. This is legitimate because `b^K` for `K` a residue mod
`ord(b)` is a well-defined element, and it conjugates `c` to `c^(n^-K)` read modulo `ord(c)`. That
holds because `n^(ord b) ≡ 1 mod ord(c)`: `b^(ord b) = 1` acts trivially.

If `w = 1` in `Q`, then `b = w_r b^(n^(e_a(w)))`, so `b^(1 - n^(e_a(w))) = w_r ∈ A_M`. If
`e_a(w) >= 0`, this is `b^-(n^(e_a(w)) - 1) ∈ A_M`. If `e_a(w) = -t < 0`, raise to the power
`n^t`: `b^(n^t - 1) ∈ A_M`. In both cases `b^(n^|e_a(w)| - 1) ∈ A_M`.

The statement for `d` is the same computation with the pair `(d; c, a)` in place of `(b; a, c)`,
using `c^-1 d c = d^n` and `d^-1 a d = a^n`: `d` passes `c^nu` by multiplying its exponent by `n^nu`,
and passes `a^mu` by replacing it with `a^(mu n^-k)`. This gives `d^(n^|e_c(w)| - 1) ∈ A_M`.

The index form follows because the image of `b` in `<b> / (<b> ∩ A_M)` has order dividing
`n^|e_a(w)| - 1`.

## Step 3 (item 2: profinite absorption)

Let `Q` be any quotient, and `w` a relation of `A_M` in `Q`. For any finite quotient `Q -> Q_f`, the
word `w` is still a relation of the image of `A_M`, with the same exponent sums, and Step 2 applies
to `Q_f` (itself a finite quotient of `H4(n)`). So the two powers lie in `A_M N` for every
finite-index normal `N` of `Q`, which is the profinite closure.

For a profinite group `K` and `pi : H4(n) -> K`, apply Step 2 to the finite subgroup of `K/U`
generated by the images of `a, b, c, d`, for each open normal `U`. The powers lie in `pi(A_M) U` for
all `U`, hence in `cl(pi(A_M)) = ∩_U pi(A_M) U`.

## Step 4 (item 3: the edge-closure criterion)

Let `pi : Q -> K` be as in item 3, with no positive power of `pi(b)` in `cl(pi(A))`. The group
`pi(Q)` is a quotient of `H4(n)`. Let `w` be any relation of its edge image `pi(A)` on
`pi(a), pi(c)`. By Step 3 (with `M = 1`), `pi(b)^(n^|e_a(w)| - 1) ∈ cl(pi(A))`. Since
`n^t - 1 >= 1` for `t >= 1`, the hypothesis forces `e_a(w) = 0`. So the exponent-sum map
`F(a,c) -> Z`, `w -> e_a(w)`, factors through `pi(A)`, and `pi(A) / pi(A)'` is infinite. By **[U]**
item 1, `pi(A)` is free on `pi(a), pi(c)`. The composite `F(a,c) -> A -> pi(A)` is then an
isomorphism, so `F(a,c) -> A` is injective and `A` is free on `a, c`. If instead no power of `pi(d)`
lies in the closure, the same argument with `e_c` applies.

For `K = Aut(T)`, `T` a locally finite rooted tree: `Aut(T)` is profinite, with the level stabilizers
as a base of open normal subgroups.

## Step 5 (item 4: uniform absorption)

If `A` is not free, then by **[U]** item 1 `A / A'` is finite. Let `Y` be the order of `a A'`, so
`a^Y = u` with `u ∈ A'`. The word `w = a^Y u^-1` (for a fixed product of commutators `u`) is a
relation with `e_a(w) = Y` and `e_c(w) = 0`. Step 3 gives `b^(n^Y - 1) ∈ cl(A)`. Symmetrically,
`c^Y' ∈ A'` gives `d^(n^Y' - 1) ∈ cl(A)`.

In a finite image put `beta = b^m` and `delta = d^m'`. Then:
- `beta^a = (b^a)^m = b^(nm) = beta^n`;
- `c^beta = c^(n^m)`, from `b^-k c b^k = c^(n^k)`;
- `delta^c = delta^n`;
- `a^delta = a^(n^m')`.

So the finite group `A_f` is generated by `a, c`, contains `beta` and `delta`, and receives
`H(n, n^m, n, n^m')`. (`amenable` implies `not free`, because `F_2` is not amenable.)

## Step 6 (what it kills)

- **Exact factorizations.** If `cl(pi A) ∩ cl(pi B) = 1` and `pi(b)` has infinite order, then
  no `pi(b)^m`, `m >= 1`, lies in `cl(pi A)`. Step 4 then makes `A` free.
- **Coprime families.** If `gcd(|A_f|, ord(b_f)) = 1`, then `<b_f> ∩ A_f = 1`, and Step 2 gives
  `ord(b_f) | n^Y - 1`.
- **Trees.** This is Step 4 with `K = Aut(T)`. For `T` binary and `n` odd, `cl(A)` is pro-2 and
  `v_2(n^Y - 1)` is finite, so `cl(A)` contains `b^(2^s)` with `s = v_2(n^Y - 1)`.

## Step 7 (calibration, computed)

`absorb_test.g` computes the lower exponent-2 central quotients of `H4(3)/<<[a,c]^2>>` up to class 10.
- By **[U]**, `A` is not free there (since `[a,c]^2 != 1` in `F_2`), so `A^ab` is finite.
- The quotients `A_k^ab` are `(Z/2)^2, (Z/4)^2, (Z/8)^2, (Z/16)^2`, and then `(Z/16)^2` constantly
  through class 10. This is consistent with `Y = 16` 2-adically.
- Step 2 predicts `b^(2^s) ∈ A_k` for `s = v_2(3^16 - 1) = v_2(16) + 2 = 6`, for every `k`.
- The computed least exponent is `s = 1, 2, 3, 4, 5, 6, 6, 6, 6, 6`, identical for `d`. Meanwhile
  `ord(b_k)` reaches 128, so `<b_k> ∩ A_k` is a nontrivial proper subgroup at class 10.
- Both predictions hold exactly.

`pro2_structure.g` covers the unrelated control, the universal pro-2 quotients of `H4(3), H4(5),
H4(7)` up to class 6. It gives `A_k ∩ B_k = 1`, `|G_k| = |A_k||B_k|`, `|A_k| = |F_2/P_k(F_2)|`, and
generator orders `2^k`. No absorption is visible, and none is forced.

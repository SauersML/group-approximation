## Setting

`B` is a finite Boolean constraint system and `A(B)` its synchronous algebra,
generated by self-adjoint involutions `x_v` with context commutation and
constraint relations. `Gamma` is a finitely generated group with decidable
word problem, for example `Delta = St_20(L_(F_2)(1,2)) ~= R^x` by
`leavitt-corner-host-is-the-simple-leavitt-unit-group` and
`binary-leavitt-unit-word-problem-decidable`. A **corner model of `B` in
`Gamma`** is a nonzero projection `q in C[Gamma]` together with a unital
star homomorphism `A(B) -> qC[Gamma]q`. For a fixed element `z != 1` one may
also fix `q = P_z = (1-z)/2`.

`F |-> G_F` is Lin's computable coRE reduction into finite synchronous games
and `B_F` the Mastel--Slofstra one-hot / losing-pair BCS of `G_F`.

## Statement

**(FH1) Corner models are semidecidable.** Uniformly in `B` (and in a
word-problem algorithm for `Gamma`), the predicates "`B` has a corner model
in `Gamma`" and "`B` has a corner model into `P_z C[Gamma] P_z`" are
`Sigma^0_1`. In particular `LNC3` of
`agent-leavitt-not-bcs-negative-root-corner` is a `Sigma^0_1` sentence: if it
is true it has a finite certificate (a support and real-algebraic
coefficients), and if it is false its falsity is `Pi^0_1`.

**(FH2) The diagonal source.** For every such `Gamma` there is an explicitly
specified machine `M_dag` (a Kleene fixed point) such that `M_dag` does not
halt, and `G_dag = G_(M_dag)`, `B_dag = B_(M_dag)` satisfy:
1. `omega_co(G_dag) = 1`, so `A(B_dag)` has a tracial state;
2. `omega_q(G_dag) <= 1/2`, so `A(B_dag)` has no finite-dimensional
   representation and every tracial state on `A(B_dag)` is non-Connes-embeddable;
3. `B_dag` has no corner model in `Gamma`.

The same holds simultaneously for any uniformly computable sequence of hosts
with uniformly decidable word problems. For a recursively presented host the
fixed-projection version holds whenever `z != 1` is known.

**(FH3) Class kill.** Consequently the following are false for every fixed
decidable host, and for `Delta = R^x` in particular:
- "every finite BCS with a tracial state and no Connes-embeddable trace (or
  with `omega_co = 1` and a quantum gap) has a corner model in `Gamma`";
- "for every non-halting `F`, `B_F` has a corner model in `Gamma`";
- any partial computable procedure that on every non-halting `F` (even on every
  `F` with a proof of non-halting) outputs corner data for `B_F` in `Gamma`.

## Consequence for the hole

Every route to `LNC3` whose only information about `B_loop` is its value
profile proves the same statement for `B_dag` and is therefore wrong. That
profile is: tracial, no CE trace, no matrix model, a Mastel--Slofstra
conversion of a synchronous game with `omega_co = 1` and `omega_q <= 1/2`.
`B_dag` shares all of it. The same holds for routes that only use membership
in a compiled family indexed by non-halting machines (FH3).
`B_loop` comes from Lin's Bell-separation reduction rather than the coRE
reduction, but `B_dag` has the same value profile. So
`R^x` is not a universal no-CE host, and a proof of `LNC3` has to use
features of the specific loop source that `B_dag` lacks. This does not decide
`LNC3`: `B_loop` itself may still have a corner model, and by (FH1) such a
model would be a finite object. The hole stays OPEN.

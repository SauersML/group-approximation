The proposed Property-`(T)`-free computation-capacity architecture separates
into the following established or conditional pieces.

1. `gatewise-cook-levin-rank-is-baseline-plus-unsat` proves, for every complete
   Boolean circuit-wire assignment,

   ```text
   rank_F2 R_C=m+UNSAT_C
   ```

   and the associated exact Schur--Clifford restriction multiplicity is
   `2^UNSAT_C`.  This is a sectorwise finite-group identity.
2. `predicate-rank-gate-doubles-restriction-multiplicity` and the fixed packet
   Schur dictionary turn an authenticated rank bit into exact local
   multiplicity pressure.  They do not identify multiplicity spaces belonging
   to different gate occurrences.
3. `gram-branching-capacity-with-overlap`,
   `rational-supercritical-branch-certificate`, and
   `strongly-connected-branching-gives-rational-pressure` prove the scalar
   finite-capacity endpoint.  Once typed partial isometries on common carrier
   projections give `x>=Ax-e` and marked survival gives `y.x>=c`, they imply

   ```text
   Def(U) >= kappa*c / sum_j(y_j C_j)
   ```

   whenever `e_j<=C_j Def(U)`.
4. `one-sided-pvm-leakage-controls-schreier-multiplicity` proves the parallel
   atomic-Schreier endpoint.  After one exact globally indexed character PVM
   and its actor leakage have been decoded, square-root multiplicities obey

   ```text
   ||f-sf||_2^2 <= 2L_s,
   mass(Omega) <= (2/kappa) sum_s L_s.
   ```

None of these statements decodes bounded local normalized-HS matrix relations
to one common finite multiplicity/resource register.  In the circuit lane the
missing output is a common decomposition on which all occurrences of a logical
symbol have the same packet factor and every rank/Schur gate acts on the same
multiplicity factor.  In the lamp lane it is one globally indexed finite
character PVM with actor leakage controlled by the original fixed word
defects.  Classical PCP/LTC soundness supplies neither operator conclusion.

The closest existing open targets are
`bounded-template-average-blr-occurrence-decoder` on the growing affine-table
side and `fixed-scale-contextual-multiplicity-holonomy` /
`multiplicity-return-transducer` on the Schur-return side.  The established
`signed-character-expansion-decodes-operator-parallelograms` demonstrates a
dimension-uniform same-Hilbert affine-PVM decoder for a bounded-character
left--right code, but `bounded-degree-left-right-character-code-has-bounded-dimension`
prevents that bare code from carrying the required growing computation
register.  On the lamp side,
`finite-covariance-energy-sees-only-character-restrictions` shows why bounded
word windows do not by themselves control fine global character transport.

Accordingly the load-bearing new theorem would be a dimension-uniform
normalized-HS **multiplicity-register operator LTC**: a fixed finite-template,
perfect-completeness occurrence test whose defect `epsilon` produces the
common resource-register decomposition above with leakage and cross-Gram error
`omega(epsilon)->0`, independently of matrix dimension and encoded computation
size.  Proving only this decoded resource interface is sufficient; globally
classicalizing every actor or every group word is not required.

This audit establishes no nonhyperlinear group and no unconditional MF
conclusion.  It uses no Property `(T)` input and no literature input.

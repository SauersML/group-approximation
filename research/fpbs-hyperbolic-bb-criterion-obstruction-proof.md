Full written proof. Imported inputs:
- **(H1)** Standard facts about `delta`-hyperbolic locally finite graphs.
  - Any two distinct points of `dG` are joined by a bi-infinite geodesic.
  - Two geodesics with the same endpoints are `8 delta`-close.
  - `beta_xi(p,q)` is 1-Lipschitz in `p`.
  - `beta_xi(p,q) = beta_xi(p,r) + beta_xi(r,q) + O(delta)`.
  - Along a geodesic `gamma` from `xi` to `eta` (so `gamma(t) -> xi` as `t -> -infinity`), `beta_xi(gamma(t),o) = t + a`
    and `beta_eta(gamma(t),o) = -t + b`, each up to `O(delta)`.
- **(H2)** Convergence dynamics: if `U`, `V` are closed disjoint subsets of `dG`, there is `R0 = R0(U,V)` such that
  `g xi in U` and `g eta in V` imply `d(g^{-1}o, gamma) <= R0` for every geodesic `gamma` from `xi` to `eta`.
- **(H3)** Quasi-centres. There are `C` and `K` such that for pairwise distinct `a, b, c` in `dG`, the set `Q(a,b,c)`
  of vertices within `C` of all three sides of an ideal triangle on `a, b, c` is nonempty and has at most `K`
  elements. `Q(ga,gb,gc) = g Q(a,b,c)`.
- **(H4)** Bevilacqua--Bowen, Theorem `T:Kaim-Hopf`: the restriction of an imp action to `Con` is infinitely
  conservative. So every positive-measure subset `E` of `Con` has `Ret(E,z)` infinite for a.e. `z` in `E`.
- **(H5)** Zimmer: an amenable imp action of a countable group admits, for each compact metrizable `G`-space `K`, a
  measurable equivariant map `X -> Prob(K)`.
- **(H6)** A nonelementary hyperbolic group has no finite orbit on `dG`.

Measurability of every construction below is routine (countable unions and choices over the countable group), and is
not repeated.

## Step 0: finite equivariant sets force dissipation

**Lemma 0.** Let `D` be a `G`-invariant measurable subset of an imp `G`-space `(Z,m)`. Suppose `M : D -> {finite
nonempty subsets of G}` is measurable with `M(gz) = g M(z)`. Then `D ∩ Con(Z)` is null.

*Proof.*
- Let `E = {z in D : e in M(z)}`. Since `M(z)` is nonempty, `D` is the union of the translates `hE` over `h in G`.
  So if `D ∩ Con` is not null, some translate of `E` meets `Con` in positive measure, and hence so does `E` (both
  `Con` and `m` are invariant).
- For `z` in `E`, `gz` lies in `E` iff `e in gM(z)` iff `g^{-1} in M(z)`. So `Ret(E,z)` is contained in `M(z)^{-1}`,
  which is finite.
- This contradicts (H4) applied to `E ∩ Con`.

## Step 1: no boundary pair (item 1)

Let `S : X -> {unordered pairs of distinct points of dG}` be equivariant.
- Let `D = {(x,y) : S(x) != S(y)}`, which is invariant in `X^2`. On `D` the union `S(x) ∪ S(y)` has 3 or 4 points.
- Set `M(x,y)` to be the union of `Q(a,b,c)` over the pairwise distinct triples in `S(x) ∪ S(y)`. This is finite,
  nonempty and equivariant by (H3).
- By Lemma 0 applied to `Z = X^2`, the set `D ∩ Con(X^2)` is null. So `Con(X^2)` lies in the equivalence relation
  `{S(x) = S(y)}` up to a null set.
- Hence the relation generated by `Con(X^2)` also lies in it. PDR would make `{S(x) = S(y)}` conull for
  `mu x mu`. Then `S` is a.e. constant, so its value is a `G`-invariant pair. This contradicts (H6).

## Step 2: no shallow boundary point (item 2)

Let `xi : X -> dG` be equivariant, and let `B` have finite positive measure.
- By ergodicity, `GB` is conull, so `Phi_B(x)` is nonempty a.e.
- Put `c_B(x) = inf_{k in Phi_B(x)} beta_{xi(x)}(ko,o)`, taking values in `[-infinity, infinity)`.
- Since `Phi_B(gx) = g Phi_B(x)` and `beta_{g xi}(gko,o) = beta_xi(ko, g^{-1}o) = beta_xi(ko,o) + O_g(1)`, the set
  `{c_B = -infinity}` is invariant. By ergodicity it is null or conull.

Suppose it is null. Define `F_x(p) = sup_{k in Phi_B(x)} beta_{xi(x)}(p, ko)` for `p` in `G`.
- **Finite, coarse horofunction.** By (H1), `F_x(p) = beta_{xi(x)}(p,o) - c_B(x) + O(delta)`, so `F_x` is finite.
  It is 1-Lipschitz, as a finite supremum of 1-Lipschitz functions.
- **Exactly equivariant.**
  `F_{gx}(gp) = sup_{k in Phi_B(x)} beta_{g xi(x)}(gp, gko) = F_x(p)`.

Let `D = {(x,y) : xi(x) != xi(y)}`. For `(x,y)` in `D`, let `T(x,y)` be the set of vertices lying on some geodesic
from `xi(x)` to `xi(y)`, and set
`M(x,y) = {p in T(x,y) : |F_x(p) - F_y(p)| <= C1}` with `C1 = 1 + 40 delta`.
- **Equivariant.** `T(gx,gy) = gT(x,y)` and `F_{gx}(gp) = F_x(p)`, so `M(gx,gy) = gM(x,y)`.
- **Nonempty.** Fix a geodesic `gamma` from `xi(x)` to `xi(y)`. The function `f(t) = F_x(gamma(t)) - F_y(gamma(t))`
  changes by at most 2 per unit step. By (H1), `f(t) = 2t + const + O(delta)`, so it tends to `-infinity` and
  `+infinity` at the two ends. Hence `|f(t)| <= 1` at some integer `t`.
- **Finite.** Every `p` in `T(x,y)` is within `8 delta` of `gamma`, say near `gamma(t_p)`. Then
  `F_x(p) - F_y(p) = 2 t_p + const + O(delta)`. So `|F_x - F_y| <= C1` confines `t_p` to a bounded interval, and
  local finiteness finishes.

Lemma 0 gives `Con(X^2) ⊂ {xi(x) = xi(y)}` mod null. As in Step 1, PDR would force `xi` to be a.e. constant, which
gives a fixed boundary point and contradicts (H6). So under PDR, `c_B = -infinity` a.e., which is item 2.

## Step 3: a radial limit point different from `xi(x)` exists, and there are infinitely many (item 3)

A point `zeta` is a **radial limit point** of `K ⊂ G` if, for some `R`, infinitely many `k` in `K` lie within `R` of a
geodesic ray from `o` to `zeta`.
- Rays from `o` and from `go` to the same point are eventually `O(delta)`-close, so the radial limit set of `gK` is
  `g` applied to that of `K`.
- Let `Lambda_j(x)` be the set of radial limit points of `Phi_{B_j}(x)` other than `xi(x)`. It is equivariant, and its
  cardinality (in `{0, 1, 2, ..., infinity}`) is invariant, hence a.e. constant.

**Claim A.** If `Lambda_j(x)` is empty a.e. for every `j`, the action is not PDR.

*Proof.*
- Suppose `Con(X^2) ∩ D` is not null. Choose closed disjoint `U`, `V` from a countable basis and `j` such that
  `A = Con(X^2) ∩ (B_j x B_j) ∩ {xi(x) in U, xi(y) in V}` has positive measure.
- By (H4), a.e. `z = (x,y)` in `A` has infinitely many `g` with `gz` in `A`.
- For each such `g`, (H2) gives `d(g^{-1}o, gamma) <= R0` for a geodesic `gamma` from `xi(x)` to `xi(y)`. Only
  finitely many group elements have `g^{-1}o` in any bounded set. So the points `g^{-1}o` go to infinity inside the
  `R0`-tube of `gamma`, and a subsequence converges radially to `xi(x)` or to `xi(y)`.
- Now `gx` is in `B_j`, so `g^{-1}` is in `Phi_{B_j}(x)`. Likewise `g^{-1}` is in `Phi_{B_j}(y)`.
- So the common radial limit point is a radial limit point of both return sets. It differs from `xi` of one of the
  two coordinates, so `Lambda_j` is nonempty on a positive-measure set. This contradicts the hypothesis.
- Hence `Con(X^2)` lies in `{xi(x) = xi(y)}`, and we conclude as in Step 2.

**Claim B.** If `Lambda_j(x)` is finite and nonempty a.e., the action is not PDR.

*Proof.* `F(x) = Lambda_j(x) ∪ {xi(x)}` is equivariant and has at least 2 points.
- If it has exactly 2 points, it is a boundary pair map, and Step 1 applies.
- If it has at least 3 points, the union of `Q` over its triples is a finite nonempty equivariant subset of `G`.
  Lemma 0 on `Z = X` makes `Con(X)` null, contradicting the hypothesis.

Claims A and B give item 3.

## Step 4: amenable actions (item 4)

By (H5) there is an equivariant `phi : X -> Prob(dG)`. The number of points in `supp phi(x)` is invariant, hence
a.e. constant.
- **At least 3 points.** Then `phi(x)^3` gives positive mass to pairwise distinct triples. Put
  `w_x(p) = phi(x)^3{(a,b,c) distinct : p in Q(a,b,c)}`.
  - Then `sum_p w_x(p)` lies in `[phi(x)^3(distinct), K]`, so `w_x` is a nonzero element of `l^1(G)`.
  - Its maximum is attained on a finite nonempty set `M(x)`, and `w_{gx}(gp) = w_x(p)` makes `M` equivariant.
  - Lemma 0 contradicts `Con(X)` being conull.
- **Exactly 2 points.** The support is a boundary pair map, which Step 1 rules out.

So `phi(x) = delta_{xi(x)}`, and Steps 2 and 3 apply to this `xi`.

## Step 5: the corollary

- **Horospherical actions.** Suppose `h_x` is a measurable equivariant coarse horofunction based at `xi(x)`, meaning
  `h_{gx}(gp) = h_x(p)` and `|h_x(p) - h_x(q) - beta_{xi(x)}(p,q)| <= C`.
  - Choose `R` and `B` in `{x : |h_x(o)| <= R}` with finite positive measure.
  - If `k` is in `Phi_B(x)`, then `|h_x(ko)| = |h_{k^{-1}x}(o)| <= R`. So
    `beta_{xi(x)}(ko,o) >= -R - |h_x(o)| - C`, and `c_B(x) > -infinity`.
  - Step 2 then shows the action is not PDR.
  - The horofunction space of a word metric on a hyperbolic group is of this type: non-finite horofunctions are
    `O(delta)`-close to Busemann functions at a unique boundary point. Finite horofunctions form atomic orbits with
    finite stabilizers, which lie in `Dis`.
- **Factors to `d^2 G`.** An action with a factor map to `d^2 G` has a boundary pair map, which Step 1 rules out.
- **Finite-measure extensions.** PDR passes to and from finite-measure extensions by Bevilacqua--Bowen Lemma
  `L:finitemeasureextension`(3).
- **Non-ergodic actions.** PDR holds iff it holds on a.e. ergodic component (their Lemma `L:conserv-erg-dec`), and
  Steps 1--4 apply componentwise.

## Step 6: crossing slices have infinite measure, and crossing returns are two-sided

Let `C = Con(X^2) ∩ {xi(x) != xi(y)}`, and assume it is not null. By Fubini, the slice
`Y(x) = {y : (x,y) in C}` has positive measure for a positive-measure set of `x`. Since `C` is invariant,
`Y(gx) = gY(x)`, and the set `{x : 0 < mu(Y(x)) < infinity}` is invariant.

**(6a) Slices are infinite.** Suppose `0 < mu(Y(x)) < infinity` on a positive-measure set. By ergodicity this holds
a.e. on the projection of `C`, which is a positive-measure invariant set.
- Put `psi(x) = xi_*(mu|Y(x)) / mu(Y(x))`, an equivariant element of `Prob(dG)`, because `mu` is invariant.
  Its support avoids `xi(x)` a.e.
- If `supp psi(x)` has at least 3 points, the `w`-maximum construction of Step 4 makes `Con(X)` null.
- Otherwise `supp psi(x) ∪ {xi(x)}` has 2 or 3 points. Two points give a boundary pair map, which Step 1 rules out.
  Three points give a finite quasi-centre set, and Lemma 0 applies.

Hence under PDR, `mu(Y(x)) = infinity` for a.e. `x` with `mu(Y(x)) > 0`.

**(6b) Crossing returns are two-sided.** Let `A` be a positive-measure subset of `C ∩ (B_j x B_j)` with
`xi(x) in U` and `xi(y) in V`, as in Claim A.
- For `z` in `A`, `Phi_A(z)` lies in the `R0`-tube of a geodesic `gamma` from `xi(x)` to `xi(y)`. Put
  `t(k) = beta_{xi(x)}(ko,o)`.
- Suppose `inf_{k in Phi_A(z)} t(k) > -infinity` on a positive-measure set. Put
  `M(z) = {k in Phi_A(z) : beta_{xi(x)}(ko, k'o) <= 1 + C2 delta for all k' in Phi_A(z)}`.
  - `M(z)` is exactly equivariant, since `beta_{g xi}(gko, gk'o) = beta_xi(ko, k'o)`.
  - It is nonempty: take `k` with `t(k) <= inf t + 1`, using the coarse cocycle identity (H1).
  - It is finite: its elements satisfy `t(k) <= inf t + O(delta)` and lie in the tube.
  - Lemma 0 on `Z = X^2` then contradicts `A ⊂ Con(X^2)`.
- The same holds for `sup`.

So a.e. crossing pair returns to `A` radially toward both `xi(x)` and `xi(y)`. In particular the return set of `x`
has radial deep returns toward `xi(x)`, as well as radial returns toward the directions `xi(y)`, `y in Y(x)`.
Taking the countably many sets `A` that cover `C`, we get: for a.e. `x`, the point `xi(y)` lies in
`Lambda_j(x)` for `mu`-a.e. `y` in `Y(x)` (for large `j`). So the radial return directions of `x` carry the whole
infinite measure `xi_*(mu|Y(x))`.

## Step 7: proper height differences, and Maharam extensions

**Lemma 7.** Let `xi : X -> dG` be measurable and equivariant, and let `tau : X -> R` be any measurable function. For
`(x,y)` in `D = {xi(x) != xi(y)}`, fix a geodesic `gamma` from `xi(x)` to `xi(y)`. Suppose that for a.e. `(x,y)` in `D`,
`f_{x,y}(p) = tau(p^{-1}x) - tau(p^{-1}y)` tends to infinity in absolute value as `p` leaves bounded sets inside
the `R`-tube of `gamma`, for every `R`. That is, for all `R` and `N`, only finitely many `p` with
`d(po,gamma) <= R` have `|f_{x,y}(p)| <= N`. Then the action is not PDR.

*Proof.*
- Suppose `Con(X^2) ∩ D` is not null. Choose `U`, `V`, `j` as in Claim A of Step 3, and `R1` such that
  `A = Con(X^2) ∩ (B_j x B_j) ∩ {xi(x) in U, xi(y) in V, |tau(x)| <= R1, |tau(y)| <= R1}` has positive measure.
- By (H4), a.e. `z = (x,y)` in `A` has infinitely many `g` with `gz` in `A`. By (H2), `p = g^{-1}` satisfies
  `d(po, gamma) <= R0`. Since `p^{-1}x = gx` and `p^{-1}y = gy` lie in `A`'s coordinates, `|f_{x,y}(p)| <= 2 R1`.
- These infinitely many `p` leave every bounded set, which contradicts the hypothesis. So `Con(X^2)` lies in
  `{xi(x) = xi(y)}` mod null, and PDR fails exactly as in Step 1, using (H6). For a non-ergodic action, apply this
  to a.e. ergodic component (Bevilacqua--Bowen `L:conserv-erg-dec`); the hypothesis passes to a.e. component by
  disintegration.

The height `h_x(p) = tau(p^{-1}x)` is always exactly equivariant: `h_{gx}(gp) = h_x(p)`. So the lemma says that under
PDR, **no** measurable coordinate on `X` separates two crossing points coarsely monotonically along their geodesic.

**Maharam extensions.** Let `nu` be a quasi-invariant probability measure on `dG` with Radon--Nikodym cocycle `r`,
and let `X = dG x R` carry the Maharam action `g(eta,t) = (g eta, t + r(g,eta))` with its invariant measure. Take
`xi(eta,t) = eta` and `tau(eta,t) = t`. Then `f_{x,y}(p) = t - t' + r(p^{-1},eta) - r(p^{-1},eta')`.

**Property (P) for `nu`.** For `nu x nu`-a.e. `(eta,eta')` with `eta != eta'` and a geodesic `gamma` from `eta'` to `eta`, put
`e(p) = r(p^{-1},eta) - r(p^{-1},eta')`. Property (P) asks for a sign `sigma = +-1`, a constant `lambda >= 1` and a
function `c(R)` with two properties:
- `sigma (e(gamma(u)) - e(gamma(s))) >= (u-s)/lambda - c(0)` for `u >= s`;
- `|e(p) - e(gamma(u))| <= c(R)` whenever `d(po, gamma(u)) <= R`.

Under (P), `f_{x,y}` is proper on every tube, so Lemma 7 applies and the Maharam extension is not PDR.
- (P) holds for Patterson--Sullivan measures of the word metric, where `r` is `v` times a Busemann function up to a
  bounded error. This is the horospherical case of Step 5 again.
- (P) holds, by the Morse lemma (imported), whenever `r(p^{-1},eta)` is a nonzero multiple of the Busemann function
  of a `G`-invariant, Gromov hyperbolic, roughly geodesic metric `d'` that is quasi-isometric to `d`, up to bounded error.
- **Conditional application.** For the harmonic measure of a symmetric finitely supported admissible random walk,
  Ancona's inequality and exponential decay of the Green function give (P) for the Martin cocycle. These inputs are
  imported and not proved here. Under them, Maharam extensions of harmonic measures are not PDR.

So a Maharam test object for the surviving case needs a quasi-invariant measure class whose Radon--Nikodym cocycle
**fails (P)**: along a positive-measure set of crossing geodesics, the cocycle difference must return to bounded
values infinitely often.

## Where the argument stops

The surviving case has three features:
- `phi = delta_xi`;
- every return set is deep toward `xi(x)`;
- some return set has infinitely many radial limit points other than `xi(x)`.

In that case neither a height (Step 2) nor a finite set of directions (Step 3) is equivariantly available, and
Lemma 0 cannot be fed. Maharam extensions `dG x R` of quasi-invariant measure classes on `dG`, with a
Radon--Nikodym cocycle that fails property (P) of Step 7, are the natural test objects. Step 7 already kills
every measure class whose cocycle is coarsely monotone along geodesics.

Notation of the target. `beta(x, r) = theta k_r` is a real 2-cochain on `Y_X`, and `a` is a real
1-cochain on edges, lifted from `R/Z` arbitrarily.

**Step 1: the relator unitaries are diagonal.** Since the permutations satisfy every `r` exactly,
`rho(r~(S))` is diagonal. Its entry at `x` is `exp(2 pi i (delta a)(x, r))`, where
`(delta a)(x, r)` is the signed sum of `a` along the loop reading `r` at `x`. The central relators
`[z, s]` and `z^n` hold exactly. Write

```text
(delta a - beta)(x, r) = c(x, r) + m(x, r),     c in [-1/2, 1/2],  m in Z.
```

Then `eta_r^2 = (1/d) sum_x |exp(2 pi i c(x,r)) - 1|^2 = (1/d) sum_x 4 sin^2(pi c(x,r))`. Since
`|sin(pi t)| >= 2|t|` for `|t| <= 1/2`,

```text
(1/d) sum_x c(x, r)^2 <= eta_r^2 / 16.                                     (P1)
```

**Step 2: one cycle gives a quantized test.** Let `Sigma` be an integral 2-cycle on `Y_X`. Since
`partial Sigma = 0`, `<delta a, Sigma> = <a, partial Sigma> = 0`. Hence

```text
<c, Sigma> = -theta <k, Sigma> - <m, Sigma>,
|<c, Sigma>| >= dist(theta <k, Sigma>, Z) = nu(Sigma).                      (P2)
```

**Step 3: deck translates (item 1).** Let `X = Gamma/N` with `N` normal. Right multiplication by
`Gamma/N` commutes with the left action, so it acts on `Y_X` by cellular automorphisms. They preserve
cell types, `k`, and mass, and act simply transitively on vertices. Let `Sigma_gamma` be the
translates, `d` of them. For a fixed cell `(x, r)`,

```text
sum_gamma |n^(Sigma_gamma)_(x, r)| = sum_(y in X) |n^Sigma_(y, r)| =: mu_r(Sigma),
sum_r mu_r(Sigma) = |Sigma|_1.
```

Apply `(P2)` to each translate, then the triangle inequality, Cauchy--Schwarz and `(P1)`:

```text
d nu(Sigma) <= sum_gamma |<c, Sigma_gamma>|
            <= sum_(x, r) mu_r(Sigma) |c(x, r)|
            <= sum_r mu_r(Sigma) d ((1/d) sum_x c(x,r)^2)^(1/2)
            <= sum_r mu_r(Sigma) d eta_r / 4
            <= d |Sigma|_1 max_r eta_r / 4.
```

Dividing by `d` gives `(MCF1)`.

**Step 4: transitive quotients (item 2).** Let `X = Gamma/Lambda`, `N` the normal core, and
`p : X' = Gamma/N -> X` the equivariant projection. Pull the model back:
`a'(x', s) = a(p(x'), s)`. The pulled-back model is monomial over the exact `Gamma`-set `X'`, and its
phase cochain is `c(p(x'), r)`. Every fibre of `p` has the same size `[Lambda : N]`, so the
normalized defects are unchanged. Item 1 on `X'` gives item 2.

**Step 5: arbitrary finite Gamma-sets (item 3).** The model is the orthogonal sum over the orbits
`X_i`, with `d_i = |X_i|`, and `eta_r^2 = sum_i (d_i/d) eta_r(i)^2`. So

```text
max_r eta_r^2 >= (1/|R|) sum_r eta_r^2 >= (1/|R|) sum_i (d_i/d) max_r eta_r(i)^2
             >= (1/|R|) min_i (4 nu(Sigma_i) / |Sigma_i|_1)^2.
```

**Step 6: existence of detecting cycles (item 4).**
- `Y = Y_(Gamma/N)` is a finite 2-complex. By the universal coefficient theorem, with `R/Z` divisible,
  `H^2(Y; R/Z) = Hom(H_2(Y; Z), R/Z)`.
- Suppose no integral 2-cycle is detecting. Then the class of `theta k mod Z` is zero, i.e.
  `theta k = delta a mod Z` for some `a : edges -> R/Z`.
- The monomial model with these phases has every `eta_r = 0`. So it is a genuine representation of
  `Gamma_n` on `l^2(Gamma/N)` with `z -> zeta I`.
- Its image is finitely generated and linear, hence residually finite
  (`finitely-generated-linear-groups-are-residually-finite`). If `zeta^2 != 1`, some finite quotient
  separates the image of `z^2` from `1`. That is a finite quotient of `Gamma_n` not killing `z^2`,
  contradicting `(DR2)` of `deligne-covers-of-sp2g-z-have-finite-residual-2z`.

**Step 7: the limits stated in the target.**
- **Monotonicity.** `Gamma/N' -> Gamma/N` for `N' <= N` is a cellular covering `Y' -> Y`. It pushes
  integral cycles forward without increasing mass or changing `<k, .>`.
- **Growth.** Let `sys(N)` be the least `S`-word length of a nontrivial element of `N`, and
  `L = max_r |r|`. Let a detecting cycle have mass `A`.
  - Restricting `Sigma` to a connected component of its support gives a cycle, and `theta <k, .>` is
    additive. So some component `K` carries a detecting cycle. `K` has at most `A L` edges.
  - `pi_1(K)` is generated by edge loops of length at most `2AL + 1` (spanning tree plus one edge).
    Such a loop maps to an element of `pi_1(Y) = N` of word length at most `2AL + 1`. If
    `2AL + 1 < sys(N)`, all of these are trivial, so `K` lifts to the Cayley complex `X~`, and the
    cycle lifts to an integral 2-cycle there.
  - `X~` is simply connected, so its integral 2-cycles are spherical. `k` vanishes on spherical cycles:
    an identity among relations lifts to `Gamma~` with total exponent `sum +-k_r`, which must be `0`
    because `z` has infinite order in `Gamma~`.
  - Hence `A_0(N) >= (sys(N) - 1) / (2L)`, and `sys(N) -> infinity` along any chain of finite-index
    normal subgroups with trivial intersection.

Direct proof. Lane proof, not independently reviewed. Write `R = R_T` and `E = 1 - ST`.

1. **`E` is idempotent.** `E^2 = 1 - 2ST + S(TS)T = 1 - ST = E`.
2. **Shift rule.** For every integer `c`, `(N+c)S = S(N+c+1)`: this is `NS = S(N+1)` plus
   `cS = Sc`. Iterating it gives `(N+1)S^(m-1) = S^(m-1)(N+m)` for `m >= 1`.
3. **The vacuum.** `NE = N(1 - ST) = 0`, so `(N+m)E = mE` for every integer `m`.
4. **Inverses of integers in the corner.** Put `r_m = E T^(m-1) A S^(m-1) E` for `m >= 1`.
   Since `m·1` is central,

       r_m · m = E T^(m-1) A S^(m-1) (mE)
               = E T^(m-1) A S^(m-1) (N+m) E        (step 3)
               = E T^(m-1) A (N+1) S^(m-1) E        (step 2)
               = E T^(m-1) S^(m-1) E                (A(N+1) = 1)
               = E^2 = E                            (TS = 1, step 1).

   So `m r_m = r_m m = E`. In the unital ring `C = E R E` (unit `E`), every positive
   integer `m·E` is invertible, with inverse `r_m`.
5. **The homomorphism.** The unital map `Z -> C`, `1 ↦ E`, sends every nonzero integer to
   a unit, so it extends uniquely to a unital ring homomorphism `Q -> C`, and
   `1/m ↦ r_m`. Its kernel is an ideal of the field `Q`, so it is injective as soon as
   `E ≠ 0` in `R`.
6. **`E ≠ 0`.** The concrete model on `Q^(N)` (shifts `S`, `T`, number operator `N`,
   resolvent `A = (N+1)^(-1)`) satisfies the four relations:
   - `TS = 1`;
   - `NS f_k = (k+1) f_(k+1) = S(N+1) f_k`;
   - `1 - ST` is the projection onto `f_0`, and `N f_0 = 0`;
   - `A(N+1) f_k = f_k`.

   So it defines a ring homomorphism `ρ: R -> End_Q(Q^(N))` with `ρ(E) ≠ 0`. Hence
   `E ≠ 0`. ∎

**Model structure (used only in the Limits remark).** In the model:
- `ρ(r_m) = (1/m)·ρ(E)`;
- `ρ(E R E) = Q·ρ(E)`;
- the ideal generated by `ρ(E)` is the ring of finitary matrices over `Q`, since
  `S^a (q E) T^b` are the matrix units scaled by `q`.

That ring is simple, and its left annihilator in `End_Q(Q^(N))` is zero. So an ideal `M`
of the image that meets it trivially satisfies `MJ = 0`, hence `M = 0`.

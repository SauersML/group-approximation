# Proof

The notation is as in [[matrix-unit-rank-models-normalize-laurent-commutants]]. Write
`n_ij(a) = sigma(x_ij(a)) - 1` for `a` in `R`.

**Step 0. Matrix units.** `sigma|Delta` satisfies `N_23 N_12 = 0`. In characteristic two
`N_12^2 = sigma(x_12(1))^2 - 1 = 0` is automatic. By
[[el3-unit-root-matrix-units-iff-two-root-identities]] there are pairwise orthogonal
idempotents `p_1, p_2, p_3` in `M` with

```text
n_ij(1) = u_ij in p_i M p_j,   u_ij u_jk = u_ik,   u_ij u_ji = p_i   (i, j, k distinct).
```

Put `p = p_1 + p_2 + p_3` and `f = 1 - p`.

**Step 1. Propagation.** Proposition 6 of
`research/artifacts/el3-rank-ring-rigidity-2026-09-12.md` applies to `sigma|Delta`, for any
ring `M` of characteristic two. It gives a unital ring homomorphism
`C : R -> p_1 M p_1` with

```text
n_ij(a) = u_i1 C(a) u_1j      for all a in R, i != j,
```

where `u_11 = p_1`. This is the meaning of `C(a) E_ij` there. Its proof shows every
`n_ij(a)` has no entries in the `f` row or column.

**Step 2. The diagonal copy.** Define `D : R -> pMp` by

```text
D(a) = sum_i u_i1 C(a) u_1i .
```

- `D` is additive.
- `D(1) = sum_i u_i1 u_1i = sum_i p_i = p`.
- `D` is multiplicative, because `u_1i u_k1 = 0` for `i != k` and `u_1i u_i1 = p_1`. So
  `D(a) D(b) = sum_i u_i1 C(a) p_1 C(b) u_1i = D(ab)`.
- `D(a) u_ij = u_i1 C(a) u_1i u_ij = u_i1 C(a) u_1j = n_ij(a)`.
- For any `j != i`, `n_ij(a) u_ji = u_i1 C(a) u_1j u_ji = u_i1 C(a) u_1i`. So

  ```text
  D(a) = sum_i n_(i,j(i))(a) u_(j(i),i)      (j(i) any index != i).
  ```

**Step 3. The commutant of `Gamma` contains `D(R_+)`.** Let `z` in `M` commute with
`sigma(Gamma)`.
- `z` commutes with each `u_ij = sigma(x_ij(1)) - 1`, since `x_ij(1)` is in `Gamma`.
- For `a` in `R_+`, `z` commutes with `n_ij(a) = sigma(x_ij(a)) - 1`.
- By the last display of Step 2, `z` commutes with `D(a)`. Also `z` commutes with
  `p = sum_i u_ij u_ji`, hence with `f`.

**Step 4. Inverse closure.** Let `T = { a in R : z D(a) = D(a) z }`.
- `T` is a subring of `R`, since `D` is a unital ring homomorphism into `pMp` and `z`
  commutes with `p = D(1)`.
- `T` contains `R_+` by Step 3.
- Let `s` be in `S`. Put `v = D(s) + f` and `w = D(s^-1) + f`. Since `D(s) D(s^-1) = p`
  and `D(R) f = f D(R) = 0`, `v w = w v = 1`. The element `z` commutes with `v`, so it
  commutes with `v^-1 = w`, and hence with `w - f = D(s^-1)`. So `s^-1` is in `T`.
- `R` is generated by `R_+` and these inverses, so `T = R`.

**Step 5. Conclusion.** For `a` in `R`, `n_ij(a) = D(a) u_ij`, and `z` commutes with both
factors. So `z` commutes with `sigma(x_ij(a))`. These elements generate `Delta`, so
`C_M(sigma Gamma) <= C_M(sigma Delta)`. The reverse inclusion holds because
`Gamma <= Delta`. For `g` in `G`,

```text
sigma(g) C_M(sigma Delta) sigma(g)^-1 = C_M(sigma(g Delta g^-1)) = C_M(sigma Delta),
```

which gives part 2. QED

## Part 3: the general form

Assume `(H1)` and `(H2)` of the claim, with `M` any unital ring and `R` any unital ring.
Let `z` commute with `sigma(Gamma)`.

- **`z` commutes with `E(a)` for `a` in `R_+`.** Each `n_(i,i+1)(a)` and `N_(i+1,i)` is
  `sigma` of an element of `Gamma`, minus 1.
- **An idempotent.** Put `e = E(1)`. By `(H1)`, `e^2 = e` and `E(a) = e E(a) = E(a) e`.
  The element `z` commutes with `e`.
- **Inverse closure.** For `s` in `S`, put `v = E(s) + 1 - e` and `w = E(s^-1) + 1 - e`.
  Then `v w = E(1) + (1 - e) = 1 = w v`, because `E(s)(1 - e) = E(s) - E(s)E(1) = 0`, and
  likewise on the other side. So `z` commutes with `w`, hence with `E(s^-1)`.
- **Conclusion.** `{a : z E(a) = E(a) z}` is a subring containing `R_+` and `S^-1`, so it
  is all of `R`. By `(H2)`, `z` commutes with every `n_ij(a)`, so `z` is in
  `C_M(sigma Delta)`.

**The matrix-unit case satisfies `(H1)` and `(H2)`.**
- `n_(i,i+1)(a) N_(i+1,i) = u_i1 C(a) u_(1,i+1) u_(i+1,i) = u_i1 C(a) u_1i`, so
  `E = D` from Step 2.
- `D` is a ring homomorphism, and `n_ij(a) = D(a) u_ij`.

**Natural ⊕ dual ⊕ trivial.** Take `R` commutative.
- Let `rho_1(x_ij(a)) = 1 + E_ij (x) C_1(a)` on `F^3 (x) W_1`, where `C_1` is a ring
  homomorphism into `End(W_1)`.
- Let `rho_2(g) = rho'(g^(-T))`, where `rho'` is of the same form on `F^3 (x) W_2` with
  `C_2`. Then `rho_2(x_ij(a)) - 1 = -E_ji (x) C_2(a)`. Let `rho_3` be trivial on `Delta`.
- In `sigma = rho_1 (+) rho_2 (+) rho_3`, the blocks of `E(a)` are:
  - on `rho_1`: `sum_i E_(i,i+1) E_(i+1,i) (x) C_1(a) = 1 (x) C_1(a)`;
  - on `rho_2`: `sum_i E_(i+1,i) E_(i,i+1) (x) C_2(a) = 1 (x) C_2(a)`. The two signs
    cancel.
  - on `rho_3`: `0`.
- So `E` is a ring homomorphism, and `E(a) N_ij` equals `n_ij(a)` blockwise.
- **Violation.** The `rho_2` block has `N_23 N_12 = E_32 E_21 (x) 1 = E_31 (x) 1 != 0`,
  and the `rho_1` block has `N_32 N_21 != 0`.
- The conclusion is not blockwise. Part 3 controls `z` with arbitrary off-diagonal
  blocks between `rho_1`, `rho_2` and `rho_3`.
- `(H1)` and `(H2)` are exact identities in `M`. So an ultraproduct of approximate models
  in which they fail only at rank `o(n)` is covered too.

## Why the dead approaches did not see this

- The Hamming and Hilbert--Schmidt proofs of normalization round almost-invariant
  objects using property (T). In rank that rounding is dead over every field
  ([[kazhdan-rank-rounding-fails-over-every-field]]). The argument above uses no rounding.
- Hilbert--Schmidt attempts to pass from `EL_3(R_+)` to the Laurent vertex stall because
  `x^(-1)` is a polynomial of unbounded degree in finite quotients
  ([[laurent-vertex-rounds-for-every-model]]). In a ring, inverting a commuting unit costs
  nothing.

## Calibration

- **Honest module models.** `rho_N` of
  [[bowen-chapman-ambient-rank-models-do-not-round-peripheral]] has `u_ij = 1 (x) E_ij`,
  so it satisfies the identity. That node's box projection `p` is an exact commutant of
  `Gamma` in the ultraproduct. The theorem predicts that it also commutes with
  `e_ij(x_l^(-1))`. It does: a box is almost invariant under `-e_l` translations exactly
  as under `+e_l`. This matches that node's remark that `p` is consistent with
  normalization.
- **Regular models.** Claim C of `research/artifacts/el3-two-root-identities-2026-09-12.md`
  shows that regular representations of finite quotients violate the identity. The
  theorem says nothing about them, as it must: permutation-type models are where the
  Kun--Thom defect of the sofic row is decided.

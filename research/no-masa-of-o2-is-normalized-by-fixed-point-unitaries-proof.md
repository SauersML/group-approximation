Standard inputs, all textbook: the power series of `exp`; continuous functional
calculus; existence of irreducible representations of a nonzero C\*-algebra
(GNS of a pure state); Schur's lemma for irreducible representations; von
Neumann's bicommutant (density) theorem for nondegenerate \*-algebras; the
classification of closed subgroups of `R`. Simplicity, outerness and strong
approximate innerness are not used. `O_2 = C*(s_1, s_2)` with
`s_i* s_i = 1 = s_1 s_1* + s_2 s_2*`.

**Two facts about a masa `D` of a unital C\*-algebra `A`.**
- (M1) `1 ∈ D`, since `D + C1` is abelian and contains `D`.
- (M2) `D' ∩ A = D`. Let `x ∈ A` commute with `D`. Because `D = D*`, so does
  `x*`, and hence so do `Re x` and `Im x`. If a self-adjoint `y` commutes with
  `D`, the \*-algebra generated by `D ∪ {y}` is commutative, so its closure is
  an abelian C\*-subalgebra containing `D`. Maximality gives `y ∈ D`. Hence
  `x = Re x + i Im x ∈ D`.

## Item 1

Let `h = h*` with `e^{ith} D e^{-ith} ⊆ D` for `t ∈ (0, ε)`. From the power
series, `‖e^{ith} − 1 − ith‖ ≤ (|t|‖h‖)^2 e^{|t|‖h‖}`. Hence, for `d ∈ D`,

```text
e^{ith} d e^{-ith} = d + it[h,d] + O(t^2)        in norm, as t → 0.
```

The quotients `(e^{ith} d e^{-ith} − d)/t` lie in `D` for `t ∈ (0, ε)`, and they
converge in norm to `i[h,d]`. Since `D` is closed, `δ(d) := [h,d] ∈ D`. So `δ`
is a linear map `D → D` with `‖δ(d)‖ ≤ 2‖h‖‖d‖`, satisfying Leibniz's rule
`δ(xy) = δ(x)y + xδ(y)`.

All of `x, y, δ(x), δ(y)` lie in the commutative algebra `D`. By induction,
`δ(d^n) = n d^{n−1} δ(d)` for `n ≥ 1`, and `δ(1) = 0`. Take `d = d* ∈ D` and
`s ∈ R`. The unitary `e^{isd} = Σ (is)^n d^n / n!` lies in `D` by (M1). Since
`δ` is bounded, applying it termwise gives `δ(e^{isd}) = is e^{isd} δ(d)`.
Therefore

```text
|s| ‖δ(d)‖ = ‖is e^{isd} δ(d)‖ = ‖δ(e^{isd})‖ ≤ 2‖h‖       for every s ∈ R,
```

so `δ(d) = 0`. Self-adjoint elements span `D`, so `h` commutes with `D`, and
`h ∈ D` by (M2). ∎

## Item 2

Let `β ∈ Aut(A)` with `β^p = id` and `A^β` commutative, and let
`π : A → B(H)` be irreducible. Write `k ∈ Z/p` for indices, which is
consistent because `β^p = id`. Set:
- `σ_k = π ∘ β^k`. Each `σ_k` is irreducible, since it has the same image as `π`.
- `ρ = ⊕_{k ∈ Z/p} σ_k` on `K = ⊕_{k ∈ Z/p} H`.
- `U` the unitary shift on `K` with `(Uξ)_k = ξ_{k+1}`, so `U^p = 1`.

**Step 1: the shift implements `β`.** Since `(U*ξ)_k = ξ_{k−1}`,

```text
(U ρ(a) U* ξ)_k = σ_{k+1}(a) ξ_k = π(β^k(β(a))) ξ_k = (ρ(β(a)) ξ)_k,
```

so `U ρ(a) U* = ρ(β(a))`. For block-diagonal operators the same computation
gives `U (⊕_k T_k) U* = ⊕_k T_{k+1}`.

**Step 2: the fixed points of `N` are abelian.** Let `N = ρ(A)''`. Each `σ_k` is
nondegenerate, so `ρ` is too, and by the density theorem `N` is the WOT-closure
of `ρ(A)`. Since `U ρ(A) U* = ρ(A)`, the automorphism `θ = Ad U` preserves
`ρ(A)'` and `N`. The map `E(T) = (1/p) Σ_{j=0}^{p−1} U^j T U^{−j}` is a finite
sum of WOT-continuous maps. It sends `N` into `N^θ` and is the identity on
`N^θ`, so `N^θ = E(N)`. Moreover `E(ρ(a)) = ρ(E_β(a))`, where
`E_β(a) = (1/p) Σ_j β^j(a) ∈ A^β`.

If `T = WOT-lim ρ(a_λ)`, then `E(T) = WOT-lim ρ(E_β(a_λ))`. So `N^θ` lies in
the WOT-closure of `ρ(A^β)`. That set is commutative: for each `x` in a
commutative set, `y ↦ xy − yx` is WOT-continuous, and multiplication is
separately WOT-continuous, so commutation passes to WOT-limits one variable at
a time. **Hence `N^θ` is abelian.**

**Case (i): `π ∘ β` is not unitarily equivalent to `π`.**

*The `σ_k` are pairwise inequivalent.* Suppose `σ_j ≅ σ_k` with
`m = k − j ≢ 0 (mod p)`. Substituting `a = β^{−j}(b)` in an intertwining
relation gives `π ≅ π ∘ β^m`. Precomposing with `β^{(r−1)m}` and using
transitivity gives `π ≅ π ∘ β^{rm}` for all `r ≥ 1`. Since `p` is prime we can
choose `r ≥ 1` with `rm ≡ 1 (mod p)`, and then `π ≅ π ∘ β`, a contradiction.

*`N` is block diagonal.* Write `T ∈ ρ(A)'` as a matrix `(T_{jk})` with
`T_{jk} σ_k(a) = σ_j(a) T_{jk}`. For `j ≠ k`, Schur's lemma gives
`T_{jk} = 0`: `T_{jk}* T_{jk} ∈ σ_k(A)' = C1`, so a nonzero `T_{jk}` is a
multiple of a unitary intertwiner, which is impossible. Also
`T_{kk} ∈ σ_k(A)' = C1`. So `ρ(A)'` is the algebra of block-diagonal scalars
`⊕ λ_k 1_H`, and `N = ρ(A)''` is the algebra of all block-diagonal operators
`⊕ T_k` with `T_k ∈ B(H)`.

*Conclusion.* By Step 1, `θ(⊕ T_k) = ⊕ T_{k+1}`, so
`N^θ = {⊕_k T : T ∈ B(H)} ≅ B(H)`. This is abelian only if `dim H = 1`.

**Case (ii): `π ∘ β = W π(·) W*` for a unitary `W ∈ B(H)`.**

*Normalize `W`.* By induction `π ∘ β^k = W^k π(·) W^{−k}`. At `k = p` this gives
`W^p ∈ π(A)' = C1`, say `W^p = c1` with `|c| = 1`. Replacing `W` by `c^{−1/p} W`
(any `p`-th root) still implements `β`, and now `W^p = 1`.

*Diagonalize `ρ`.* Define `V` on `K` by `(Vξ)_k = W^k ξ_k`, which is
well-defined for `k ∈ Z/p` and unitary. Then

```text
V (⊕_k π(a)) V* = ⊕_k W^k π(a) W^{−k} = ⊕_k σ_k(a) = ρ(a).
```

The commutant of `{⊕_k π(a)}` is `C1 ⊗ M_p`, whose commutant is `B(H) ⊗ 1`.
Hence `N = V (B(H) ⊗ 1) V*`, that is, `N = Ψ(B(H))` for the injective
\*-homomorphism

```text
Ψ(T) = ⊕_k W^k T W^{−k}.
```

*Transfer `θ`.* By Step 1,
`θ(Ψ(T))_k = W^{k+1} T W^{−(k+1)} = Ψ(W T W*)_k`, so `θ ∘ Ψ = Ψ ∘ Ad W` and
`N^θ = Ψ({W}')`.

*Count dimensions.* `W` is unitary with `W^p = 1`, so
`W = Σ_{ζ^p = 1} ζ P_ζ` with spectral projections
`P_ζ = (1/p) Σ_j ζ^{−j} W^j` summing to `1`. Hence
`{W}' = ⊕_ζ B(P_ζ H)`. This is abelian only if every `P_ζ H` has dimension at
most `1`, so `dim H ≤ p`.

In both cases `dim H ≤ p`.

**No finite-dimensional representations of `O_2`.** Let `π : O_2 → M_n` be a
representation, `P = π(1)` and `m = Tr P`. Each `π(s_i)` satisfies
`π(s_i)* π(s_i) = P`, so `Tr(π(s_i) π(s_i)*) = Tr(π(s_i)* π(s_i)) = m`. Taking
traces in `π(s_1)π(s_1)* + π(s_2)π(s_2)* = P` gives `2m = m`. So `m = 0`, hence
`P = 0` and `π(x) = π(1 · x) = 0` for all `x`.

`O_2 ≠ 0` has an irreducible representation, which is nonzero and so
infinite-dimensional, in particular of dimension greater than `p`. By the
contrapositive of what was just proved, `O_2^α` is not commutative. ∎

## Item 3

**No masa is normalized by all `e^{ih}`.** Suppose a masa `D ⊆ O_2` satisfies
`e^{ih} D e^{−ih} = D` for every self-adjoint `h ∈ O_2^α`. Fix such an `h`.
Every `th` with `t ∈ R` is again self-adjoint in `O_2^α`, so item 1 (with
`A = O_2`) gives `h ∈ D`. Thus `(O_2^α)_sa ⊆ D`. Since `α` is a
\*-homomorphism, `Re x, Im x ∈ O_2^α` for `x ∈ O_2^α`, so `O_2^α ⊆ D`. That
makes `O_2^α` commutative, contradicting item 2.

**No masa is invariant under `U_0(O_2^α)`.** For self-adjoint `h ∈ O_2^α` the
path `t ↦ e^{ith}`, `t ∈ [0,1]`, lies in `U(O_2^α)`, so `e^{ih} ∈ U_0(O_2^α)`.
Invariance of `D` under `Ad u` for all `u ∈ U_0(O_2^α)` would therefore
contradict the previous paragraph.

**Quantitative form.** Let `D` be any masa. By the first paragraph some
self-adjoint `h ∈ O_2^α` is not in `D`. Let

```text
T = {t ∈ R : e^{ith} D e^{−ith} = D}.
```

- *`T` is a subgroup.* `0 ∈ T`, `T` is closed under addition by composing, and
  closed under negation by applying `Ad e^{−ith}`.
- *`T` is closed.* Let `t_n ∈ T` with `t_n → t`. For `d ∈ D`,
  `e^{ith} d e^{−ith} = lim e^{it_n h} d e^{−it_n h} ∈ D`, because `D` is
  norm-closed and `t ↦ e^{ith}` is norm-continuous. Hence
  `e^{ith} D e^{−ith} ⊆ D`. The same argument with `−t_n → −t` gives
  `e^{−ith} D e^{ith} ⊆ D`, the reverse inclusion.
- *`T ≠ R`.* Otherwise item 1 gives `h ∈ D`.

Hence `T = aZ` for some `a ∈ (0, ∞)`, or `T = {0}`, in which case put `a = ∞`.

*Injectivity.* If `0 ≤ s < t < a` and `e^{ish} D e^{−ish} = e^{ith} D e^{−ith}`,
applying `Ad e^{−ish}` gives `t − s ∈ T ∩ (0, a) = ∅`, a contradiction. ∎

## Item 4

**Uncountable families.** `Ad u` is an automorphism of `O_2`, so it maps masas
to masas and Cartan subalgebras to Cartan subalgebras: normalizers go to
normalizers, and a faithful conditional expectation `F` onto `D` becomes
`Ad u ∘ F ∘ Ad u*` onto `u D u*`.

Now let `D` be an `α`-invariant Cartan subalgebra (or masa) and
`u ∈ U(O_2^α)`. Then `u D u*` is again one, and it is `α`-invariant:
`α(u D u*) = α(u) α(D) α(u)* = u D u*`.

Take `h` and `a` from the quantitative form of item 3 for this `D`. Each
`e^{ith}` lies in `U(O_2^α)`, and the subalgebras `e^{ith} D e^{−ith}` for
`t ∈ [0, a)` are pairwise distinct, which gives uncountably many. Every member
of the family is a masa, so by item 3 none is invariant under all of
`U_0(O_2^α)`.

**No natural choice.** Let `𝒜` and `Φ` be as in the claim, and fix `α ∈ 𝒜`.
Take a self-adjoint `h ∈ O_2^α` and set `u = e^{ih}`.
- `u ∈ U_0(O_2)`, via the path `t ↦ e^{ith}`.
- `α(u) = e^{iα(h)} = u`, since a \*-homomorphism commutes with the continuous
  functional calculus.

Therefore

```text
Ad u ∘ α ∘ Ad u* (x) = u α(u)* α(x) α(u) u* = α(x),
```

so naturality forces `Φ(α) = u Φ(α) u*`. As `h` is arbitrary, the masa `Φ(α)`
satisfies `e^{ih} Φ(α) e^{−ih} = Φ(α)` for every self-adjoint `h ∈ O_2^α`,
contradicting item 3. Only `α ∈ 𝒜` itself was used, and `α(Φ(α)) = Φ(α)` was
never needed.

**The examples are conjugation-closed.** The `U_0(O_2)`-orbit of a single
automorphism with `α^p = id` is closed under conjugation because
`U_0(O_2)` is a group.

Now let `α` be outer and strongly approximately inner: `α^p = id`, `α^k` is
not inner for `0 < k < p`, and (Izumi's definition, as quoted in
`ghs-z2-commuting-rokhlin-dimension-one-dual-sai-citation`) for each `k` there
is a unitary `v_k` in the sequence algebra `(O_2^α)_∞` with
`α^k(x) = v_k x v_k*` for all `x ∈ O_2`. Let `u ∈ U(O_2)` and
`β = Ad u ∘ α ∘ Ad u*`.
- *Order `p`.* `β^k = Ad u ∘ α^k ∘ Ad u*`, so `β^p = id`.
- *Outer.* If `β^k = Ad w` for some `0 < k < p`, then `α^k = Ad(u* w u)`, a
  contradiction.
- *Strongly approximately inner.* `β(u y u*) = u α(y) u*`, so
  `O_2^β = u O_2^α u*`, and `Ad u` (applied entrywise to representing
  sequences) maps `(O_2^α)_∞` onto `(O_2^β)_∞`. The unitaries
  `w_k = u v_k u* ∈ (O_2^β)_∞` satisfy
  `w_k x w_k* = u v_k (u* x u) v_k* u* = u α^k(u* x u) u* = β^k(x)`.
  The same computation with `v_n = u u_n u*` handles the variant definition
  that uses honest unitaries `u_n ∈ O_2^α` with `Ad u_n → α` pointwise. ∎

## Item 5

Let `α^2 = id` on a C\*-algebra `B`, and call an abelian C\*-subalgebra `C`
invariant if `α(C) ⊆ C`. Then `α(C) = C`, since `C = α(α(C)) ⊆ α(C)`.

**Maximal elements exist.** The family of invariant abelian C\*-subalgebras is
nonempty, as it contains `{0}`. For a chain, the closure of the union is a
C\*-subalgebra. It is abelian because commutation passes to norm limits, and
invariant because `α` is continuous. Zorn's lemma gives a maximal element
`B_0`.

**A maximal element is a masa.** Suppose not, and let `C ⊋ B_0` be abelian. Pick
`x ∈ C ∖ B_0`.
- *A self-adjoint element outside `B_0`.* One of `Re x, Im x ∈ C`, call it
  `y`, lies outside `B_0`. Then `y` is self-adjoint and commutes with `B_0`.
- *Split into eigenparts.* `α(y)` is self-adjoint and commutes with
  `α(B_0) = B_0`. Put `y_± = (y ± α(y))/2`. These are self-adjoint, commute
  with `B_0`, satisfy `α(y_±) = ±y_±`, and sum to `y`. So one of them, call it
  `z`, is not in `B_0`.
- *Contradiction.* The \*-algebra generated by the commuting self-adjoint set
  `B_0 ∪ {z}` is commutative and mapped into itself by `α`. Its closure is an
  invariant abelian C\*-subalgebra that strictly contains `B_0`, contradicting
  maximality. ∎

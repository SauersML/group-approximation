# Simple stably finite algebras with algebraic Cu have projection-exhausted closure rigidity

Let `A` be separable, simple, and stably finite, with algebraic `Cu(A)`.
If countably generated Hilbert `A`-modules satisfy

```text
[E]=[F]=sup_n c_n,
K(F) has a projection approximate identity,
```

for compact increasing `c_n`, then `E` and `F` are isomorphic.

This is the remaining coherence hinge after compact-class realization.
Brown--Ciuperca, arXiv:0811.0958, Question 5.1 asks the symmetric version
without assuming that either module is projection-exhausted. The nested
model construction makes the two formulations equivalent on the closure
of compact elements: compare each of the two arbitrary modules to the same
projection-exhausted model. The display is useful because it gives the
obstruction an explicit asymmetric normal form.

Finite stable rank, projection cancellation, or hereditary `K_1`
surjectivity would advance XXXI if it implied this claim. None of those
implications is currently asserted.

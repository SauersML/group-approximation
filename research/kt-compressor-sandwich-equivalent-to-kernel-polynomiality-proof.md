Notation as in the claim. For `P ∈ SL_d(Z)`, `P·f` is the automorphism `x^v ↦ x^(Pv)` of
`R`, and `(1,P)(g,1)(1,P)^(-1) = (P·g, 1)`, with `P` acting entrywise. We use Suslin's
theorem `SL_r(A) = E_r(A) = EL_r(A)` for `r ≥ 3` (Suslin 1977, polynomial rings over a
field), and `P·A ⊆ A ⇔ P ∈ M_d(N)`.

## 1. The kernel is admissible

`H = Δ ∩ N` contains `Γ ≤ N`. `N` is normal in `G`, so `PHP^(-1) ≤ PΔP^(-1) ∩ N ≤ H`
for `P ∈ Mon`. The root contents of `H` are those of `Δ`, since `e_12(f) ∈ N`. So `H` is
admissible.

**(S) ⇒ (K).** An admissible `H ≤ N` is an admissible subgroup of `G`, so (S) gives
`H = Γ ≤ SL_r(A)`.

## 2. Polynomial kernel forces Δ = Γ

Assume `H ≤ SL_r(A)`, so `H = Γ` by Suslin. Let `(g,P) ∈ Δ` with `g ∈ N`. For `a ∈ A` and
`i ≠ j`,

```text
(g,P)(e_ij(a),1)(g,P)^(-1) = (g · e_ij(P·a) · g^(-1), 1) ∈ Δ ∩ N = H ≤ SL_r(A).
```

Put `B = P·A`, a subring of `R` containing `1`. For `c ∈ B`,
`g e_ij(c) g^(-1) − I = c·gE_ij g^(-1) ∈ M_r(A)`. Taking `c = 1` gives
`gE_ji g^(-1) ∈ M_r(A)`. The product `(c·gE_ij g^(-1))(gE_ji g^(-1)) = c·gE_ii g^(-1)` lies in
`M_r(A)`. Summing over `i` (with any `j ≠ i`) gives `c·I = g(cI)g^(-1) ∈ M_r(A)`, so
`c ∈ A`. Hence `P·A ⊆ A` and `P ∈ M_d(N)`.

`(g,P)^(-1) = (P^(-1)·g^(-1), P^(-1)) ∈ Δ` as well, so `P^(-1) ∈ M_d(N)` too. A matrix
with nonnegative integer entries whose inverse also has nonnegative integer entries is a
permutation matrix: each row of `P^(-1)P = I` is a nonnegative combination of rows with
disjoint supports, so both matrices are monomial with entries `1`. So `π(Δ)` is a finite
group of permutation matrices.

By `kt-compressor-stable-overgroups-have-polynomial-content` Part 3, a finite `Mon`-stable
subgroup of `SL_d(Z)` is central, so `π(Δ) ⊆ {±I}`. The only permutation matrix in
`{±I}` is `I`. So `π(Δ) = {I}`, `Δ = H = Γ`.

**(K) ⇒ (S).** If `Δ` is admissible, `H` is admissible by §1, so `H ≤ SL_r(A)` by (K), and
§2 gives `Δ = Γ`.

For the weaker version of (S), where `Δ` is compressed by a semigroup `T ⊇ Mon`, the
kernel is again `T`-stable, and §2 used only `(g,P)^(±1) ∈ Δ` and Part 3 for `Mon`.

## 3. Entry-ring dichotomy

Let `I = I(H)` be the `A`-span of all entries of all `h ∈ H`. The identity gives `1 ∈ I`,
so `A ⊆ I`. For `h, h' ∈ H` and `k ≠ l`,

```text
h·e_kl(1)·h' − h·h' = h E_kl h',     (h E_kl h')_(ij) = h_(ik) h'_(lj).
```

Both products lie in `H`, so their entries lie in `I`, and `h_(ik)h'_(lj) ∈ I` whenever
`k ≠ l`. For `k = l`, pick `m ≠ k`. Row `m` of `e_(mk)(1)h' ∈ H` is `h'_(m·) + h'_(k·)`, so
`h_(ik)(h'_(mj) + h'_(kj)) ∈ I`, and `h_(ik)h'_(mj) ∈ I` by the case `k ≠ m`. Hence
`h_(ik)h'_(kj) ∈ I`. So every product of an entry of `h` with an entry of `h'` lies in
`I`, `I·I ⊆ I`, and `I` is a subring. For `P ∈ Mon`,
`P·H ≤ H` gives `P·I ⊆ I`. Lemma A of
`kt-compressor-stable-overgroups-polynomial-content-proof` applies to the `A`-module `I`:
either `I = A`, or `I` contains every `x_j^(-1)` and then, being a ring, `I = R`.
`I = A` means `H ≤ M_r(A) ∩ SL_r(R) = SL_r(A)`.

The `A`-span `Λ` of `H` is a ring containing `M_r(A)` (the span of `E_r(A)`), hence a
sub-bimodule `M_r(J)` for an additive subgroup `J`. Since `E_ii Λ E_jj` is `J E_ij` and
the entries of `Λ` span `I`, `J = I`. ∎

## 4. Calibration: one variable

Let `F = F_q((t))`, `O = F_q[[t]]`, `K = SL_r(O)`, and `SL_r(F_q[t]) ≤ H ≤ SL_r(F_q[t^(±1)])`
with `H ≠ SL_r(F_q[t])`. Let `L` be the closure of `H` in `SL_r(F)`.

* `F_q[t]` is dense in `O`, and `K` is generated by elementary matrices over the local
  ring `O` together with diagonal matrices in `SL_r(O)`, each of which is a product of
  elementary matrices over `O`. Elementary matrices over `F_q[t]` are dense among those
  over `O`, so `L ⊇ K`.
* `H ∩ K = SL_r(F_q[t^(±1)] ∩ O) = SL_r(F_q[t])`, so some `h ∈ H` lies outside `K`, and
  `L ⊋ K`.
* `K` is a maximal subgroup of `SL_r(F)`. By the Cartan decomposition `h ∈ K t^λ K` with
  `t^λ = diag(t^(λ_1),…,t^(λ_r))`, `λ_1 ≥ … ≥ λ_r`, `Σλ_i = 0`, `λ ≠ 0`. So
  `⟨K, h⟩ ∋ t^λ`. Conjugating `e_(r1)(O) ≤ K` by `t^(nλ)` gives `e_(r1)(t^(n(λ_r − λ_1))O)`
  for all `n ≥ 1`, whose union is `e_(r1)(F)`. Permutation matrices with signs lie in `K`,
  so `⟨K,h⟩` contains every `U_ij(F)` and equals `E_r(F) = SL_r(F)`.

So `L = SL_r(F)`. For `γ ∈ SL_r(F_q[t^(±1)])`, the open set `γK` meets `H`, say at `h`.
Then `γ^(-1)h ∈ SL_r(F_q[t^(±1)]) ∩ K = SL_r(F_q[t]) ≤ H`, so `γ ∈ H`. Hence
`H = SL_r(F_q[t^(±1)])`.

For `d ≥ 2` the second step fails. Let `ν` be any valuation of `Frac(R)` with `A ⊆ O_ν`.
On monomials `ν(x^v) = ⟨w,v⟩` for some `w ∈ R^d_(≥0)`. If `w = 0` then `R ⊆ O_ν`.
Otherwise some `w_i > 0`, and for `j ≠ i` and large `n` the monomial
`x_i^n x_j^(-1)` lies in `R ∩ O_ν` but not in `A`. So `SL_r(A)` is never the stabilizer
`SL_r(R ∩ O_ν)` of a vertex, and the density trick yields only
`H·SL_r(R ∩ O_ν) = SL_r(R)`. This is where the compressors have to enter in (K). ∎

**ESTABLISHED** (proposed; proof in `contracting-torsion-interior-at-finite-radius-proof`).

**Setting.** Let `J <= Aut(X*)` be generated by a finite symmetric set `S`
of automorphisms that is closed under sections (`s|_x in S u {1}`), for
example the states of a finite automaton. Write `|g|` for the word length in
`S`, and let `N = ker(F(S) -> J)`. Assume:

- *contracting at level `n`*: there are `lambda < 1` and `C` with
  `|g|_v| <= lambda |g| + C` for all `g in J` and `v in X^n`;
- *self-replicating at a vertex `x_0 in X`*: every `s in S` equals `g|_{x_0}`
  for some `g in St_J(1)`. Fix such a `g` and a word `h_s` for it, and put
  `H = max_s |h_s|`.

Put `m = max(1, ceil(2C/(1-lambda)))` and
`rho_0 = max(2m + C, ceil(2(lambda m + C)/(1-lambda)), H + 1)`.
For `rho >= 1` let `G_rho = < S | all words of length <= rho in N >`.

**Theorem (radius reduction).** The following are equivalent:

1. `J` is a quotient of a finitely presented torsion group;
2. `G_rho` is torsion for some `rho`;
3. `G_rho0` is torsion.

If they fail, `J` is a limit, in the space of marked groups, of groups with
elements of infinite order. More precisely, there are normal subgroups
`<<N_{<= rho0}>> = M_0 <= M_1 <= ... <= N` with `U M_k = N` and every
`F/M_k` non-torsion.

**Both directions for Zaremsky Problem 1.11.** Let `J` be an infinite torsion
group of this kind: the first Grigorchuk group, Gupta-Sidki, GGS, or any
contracting finite-state self-replicating torsion group. Then:

- if `G_rho0(J)` is torsion, it is a finitely presented infinite torsion
  group (it maps onto `J`), and Problem 1.11 has a positive answer;
- if `G_rho0(J)` has an element of infinite order, then no finitely presented
  cover of `J` is torsion, and no counterexample can have `J` as a quotient.

So, over the whole contracting self-replicating class, the construction
route "find a finitely presented torsion cover of a known torsion group" is
equivalent to the torsion of one explicit finitely presented group per `J`.
A single element of infinite order in `G_rho0` settles that `J` negatively.
For self-similar spinal groups, the stronger base `A * B` of
`self-similar-spinal-groups-not-fp-torsion-quotients` already settles it
negatively.

**Prior work.** The mechanism is that of Benli-Grigorchuk-de la Harpe,
arXiv:1206.2072, Theorem 1.9 (pinned in
`research/artifacts/hl-intermediate-growth-pins-2026-09-13.md`): for a
contracting faithful self-replicating group, free subgroups or largeness of a
standard contracting cover pass to every finitely presented cover. The
direction (1) => (3) here is the analogue for elements of infinite order.
What is added is the torsion form of the transfer, the equivalence, and an
explicit radius. For the self-similar spinal class the dichotomy is resolved
without any radius by `self-similar-spinal-groups-not-fp-torsion-quotients`.

**Calibration.** The theorem would be wrong if it could hold for a nontrivial
finite `J`, since such a `J` is a finitely presented torsion quotient of itself.
The hypotheses exclude this. Suppose `J != 1` is self-replicating at `x_0`.
If `St_J(1) != J`, then `|J| > |St_J(1)| >= |J|` is impossible for finite `J`.
If `St_J(1) = J`, every section again lies in `J`, so `J` fixes every level
and `J = 1`. For the adding machine `a = (1, a) sigma`, with `S = {a, a^-1}`,
`St_J(1) = <a^2>` and `a^2 = (a, a)`. The hypotheses hold with `n = 1`,
`lambda = 1/2`, and `G_rho = Z` is non-torsion for every `rho`. The theorem
then correctly says that `Z` is not a quotient of a finitely presented
torsion group.

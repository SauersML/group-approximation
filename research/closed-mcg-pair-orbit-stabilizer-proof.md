Standard inputs, not re-proved. Sources: Farb--Margalit, *A Primer on Mapping
Class Groups*, Chapters 3, 4 and 13; Fathi--Laudenbach--Poénaru for measured
laminations. Statement numbers were not re-checked against the book in this pass.
- **(F1) Twists and intersection.** For an essential simple closed curve `a`, an
  integer `n` and simple closed curves `b, c`,
  `|i(T_a^n(b), c) − |n|·i(a,b)·i(a,c)| ≤ i(b,c)`. By bilinearity over components
  and continuity of `i` on measured laminations, `i(T_a^n μ, μ) = |n|·i(a,μ)²` for
  every multicurve or measured lamination `μ`, since `i(μ, μ) = 0`.
- **(F2) Centre.** `Mod(Σ)` is generated by Dehn twists, `h T_c h⁻¹ = T_{h(c)}`,
  `Z(Mod(Σ)) = 1` for `g ≥ 3`, and `T_a^k = T_b^k` with `k ≠ 0` forces `a = b`.
- **(F3) Nielsen--Thurston.** An infinite-order `ψ` is pseudo-Anosov or has a
  nonempty canonical reduction system `C(ψ)`, with `C(hψh⁻¹) = h·C(ψ)` and
  `C(ψ⁻¹) = C(ψ)`.
- **(F4) Laminations.** A pseudo-Anosov `ψ` has measured laminations `λ±` with
  `ψλ± = k^{±1}λ±`, and `[λ+], [λ−]` are its only fixed points in projective
  measured lamination space. Both fill: `i(a, λ±) > 0` for every essential curve
  `a`, and `i(λ+, λ−) > 0`.

Every `x ∈ Mod(Σ)` has a power in `G`, because `G` has finite index. Orbits of `G`
on `(G·x) × (G·x)` correspond to double cosets `H\G/H`, `H = Stab_G(x)`. Double
coset finiteness passes to finite-index subgroups `H0 ≤ H`, since each `HfH` is a
finite union of `H0`-double cosets.

**Two-element subsets.** For `|S| ≥ 2` there are finitely many orbits on `S × S`
iff there are finitely many orbits of two-element subsets.
- **Forward.** Every two-element subset is the image of an ordered pair.
- **Converse.** If `x1, x2, …` lie in distinct orbits, the subsets `{x1, xj}`
  lie in distinct orbits, so there are finitely many orbits on `S`. The diagonal
  contributes one orbit for each of these, and each orbit of subsets gives at
  most two orbits of ordered pairs.

**(a)** Assume the action is faithful. The diagonal is invariant, so there are
finitely many orbits on `S`. The kernel `N_f` of the action on the union of the
finite orbits has finite index. The kernel `K_∞` of the action on `S_∞` meets
`N_f` trivially, so `K_∞` is finite and normal.
For `n ∈ K_∞`, `C_G(K_∞)` has finite index, so it contains some `T_c^k`, `k ≠ 0`,
for every curve `c`. Then `T_{n(c)}^k = n T_c^k n⁻¹ = T_c^k`, so `n(c) = c` by (F2).
So `n` commutes with every twist and `n = 1` by (F2). Since `G` is infinite,
`S_∞ ≠ ∅`.

**(b), finite.** `|HfH| ≤ |H|²` and `G` is infinite, so there are infinitely many
double cosets.

**(b), normal.** `H\G/H = G/H`, which is in bijection with the infinite orbit.

**(b), reducible.** Let `H` fix the multicurve `M`, and put `ι(f) = i(M, fM)`.
Then `ι(h f h′) = i(h⁻¹M, f h′M) = i(M, fM)`, so `ι` is constant on double
cosets. Choose a curve `a` with `i(a, M) > 0` and `N ≥ 1` with `T_a^N ∈ G`. By
(F1), `ι(T_a^{Nm}) = Nm·i(a,M)²` is unbounded, so there are infinitely many
double cosets.

**(b), virtually cyclic.**
1. **Normal cyclic subgroup.** `H` has a normal infinite cyclic subgroup `⟨ψ⟩`:
   intersect the finitely many conjugates of a finite-index cyclic subgroup.
2. **Reducible case.** If `ψ` is not pseudo-Anosov, then `C(ψ) ≠ ∅` and `H` fixes
   `C(ψ)` by (F3). This is excluded by the reducible case.
3. **Pseudo-Anosov case.** Otherwise `H` permutes the projective classes
   `[λ+], [λ−]` of (F4). Let `H1 ≤ H`, of index at most 2, fix both. For
   `h ∈ H1`, `hλ+ = tλ+` and `hλ− = sλ−`, and invariance of `i` gives `ts = 1`.
4. **Invariant.** Put `Φ(f) = i(λ+, fλ+)·i(λ−, fλ−)`. For `h, h′ ∈ H1` the scale
   factors of `h⁻¹` and `h′` cancel between the two factors, so `Φ(h f h′) = Φ(f)`.
5. **Unboundedness.** By (F1) and (F4), `Φ(T_a^{Nm}) = (Nm)²·i(a,λ+)²·i(a,λ−)²` is
   unbounded. So `H1\G/H1` is infinite, and hence so is `H\G/H`. `∎`

## The group P_G(r)

Let X = N × {1, …, r} ("the loops"; x = (i, j) is the i-th loop on ray j) and let H_r ≤ Sym(X) be the Houghton
group. Let G be any group and Q = G * F(X). An automorphism α ∈ Aut_G(Q) (fixing G pointwise) is
**eventually rigid** if there are a finite E ⊂ X, σ ∈ H_r and words w_1, …, w_r ∈ Q such that

    α(x) = w_j σ(x) w_j⁻¹   for every x ∈ X ∖ E on ray j.

These form a subgroup P_G(r) ≤ Aut_G(Q). (Inverse: α⁻¹(σx) = w′_j x w′_j⁻¹ with w′_j = α⁻¹(w_j)⁻¹ for x far out;
composition: w_j(αβ) = α(w_j(β))·w_j(α).) Each w_j is determined by α, since two words conjugating infinitely many
distinct basis letters to the same elements differ by an element centralizing two distinct letters, hence by 1.
The germ σ is determined up to FSym(X).

Elements of P_G(r):
- **basis permutations** σ ∈ H_r (all w_j = 1, E = ∅);
- **finitary automorphisms** Aut_G(G * F(E)) for finite E, extended by the identity on X ∖ E (σ = 1, w_j = 1);
- **slides** slide_j^E(u), for u ∈ G * F(E): x ↦ u x u⁻¹ for x on ray j outside E, identity elsewhere. Then
  u ↦ slide_j^E(u) is an injective anti-homomorphism, and slide_j^E(u) and slide_j^{E∪{y}}(u) differ by the finitary
  partial conjugation of the letter y.

**Finite generation.** If G is generated by a finite set S and r ≥ 2, then P_G(r) is generated by the finitely many
elements: generators of H_r; the Nielsen move x_1 ↦ x_1x_2 and the inversion x_1 ↦ x_1⁻¹; c_s: x_1 ↦ s⁻¹x_1s and
ρ_s: x_1 ↦ x_1s (s ∈ S); slide_j(s) and slide_j(x_1) (s ∈ S, 1 ≤ j ≤ r). Proof: multiply α by an element of H_r to
make its germ finitary, then by a finitary permutation to make it trivial; kill each w_j by slides (products of
FSym-conjugates of the listed slides, up to finitary corrections); what is left lies in some Aut_G(G * F(E′)), which
is generated by BFFHZ's generating set X (types (i)–(v), arXiv:2503.21882v2 §1), and every element of that set is a
product of FSym(X)-conjugates of the listed generators.

## The embedding

Take the (0,1)-rigid structure on Γ_r, so the core is a tree, each piece is a segment carrying one loop, and
π_1(Γ_r, p) = F(X) for any base point p on the spine, with loops tethered along the tree.

**Theorem.** There is an injective homomorphism PB_r → P_1(r) ≤ P_G(r) whose image lies in
P⁰ = {α ∈ P_1(r) : w_1(α) = 1}. Hence PB_r ≤ P_G(r) for every G, and B_r contains PB_r with index r!.

Proof.
- **The lift.** For f ∈ PB_r, pick p on the spine of ray 1 beyond a defining graph of f. Then f(p) lies on that spine,
  and ρ_f denotes the spine path from p to f(p). Put f_*(γ) = ρ_f · f(γ) · ρ_f⁻¹. This does not depend on p, because f
  maps spine paths far out on ray 1 to spine paths. It is multiplicative, because ρ_{fg} = ρ_f · f(ρ_g) for p far
  enough out.
- **The image is eventually rigid.** Outside a defining graph, f maps pieces to pieces by the markings. So f_*(x) =
  σ(x) exactly for loops x far out on ray 1, and f_*(x) = w_j σ(x) w_j⁻¹ on ray j, where w_j is the loop comparing
  f(tether) with the tether of σ(x). Here σ ∈ H_r is the induced permutation of far-out loops. So f_* ∈ P⁰.
- **Well-defined on proper homotopy classes.** Properly homotopic f, f′ have the same outer class. Their lifts both
  fix infinitely many ray-1 letters exactly, so they differ by an inner automorphism fixing a letter, which is
  trivial.
- **Injective.** If f_* = id then [f] = 1 in Out(π_1), so f is properly homotopic to the identity. This is
  Algom-Kfir–Bestvina, "Groups of proper homotopy equivalences of graphs and Nielsen realization", Contemp. Math. 812 (2025), Theorem 3.1, as quoted in HKUW (arXiv:2508.21264v1, Theorem
  `thm:AB_Alexander`); I read the quotation, not the original.

## Remarks

- **Other Houghton-type groups, same host (trust note, not checked at source).** The same based-at-an-end lift embeds:
  - the surface Houghton group S_r in P_G(2r), with each handle giving two rays of letters a_i, b_i;
  - the braided Houghton group in P_G(r), with puncture loops as letters.
  Both use injectivity of Map(S) → Out(π_1 S) for these infinite-type surfaces, which is cited, not re-read. The
  handlebody and doubled-handlebody Houghton groups are not covered, since disk twists act trivially on π_1.
- **Why G.** For G = 1 the group P_1(r) = Inn(F(X)) ⋊ P⁰ has no useful faithful highly transitive action. The factor
  G supplies the BFFHZ homomorphism-set action (`eventually-rigid-g-automorphism-groups-act-with-type-a-except-fp`).

## Lesson for general BH

BFFHZ's actor Aut_G(G * F_n) has an asymptotically rigid version, P_G(r), which contains every Aut(F_n), the Houghton
shifts, and the graph, surface and braided Houghton groups at once. Houghton-type groups that live in Aut(π_1) based
at an end are all subgroups of this one kind of group, so one theorem about P_G(r) covers the whole family.

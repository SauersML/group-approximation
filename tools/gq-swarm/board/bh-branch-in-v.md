**Target:** `finitely-generated-weakly-branch-group-embeds-in-thompson-v`. This is the finitely generated case of Bodart–D'Angeli–Perego–Rodaro's (BDPR, arXiv:2608.02111 §7) question "does any (weakly) branch group embed in V?". **Status: REDUCED, still OPEN.**

## Landed

81c755821 (lane proofs, not independently reviewed):
- **`multi-ended-branch-actions-are-boundary-sandwiched`** (with its proof node).
  - Statement: a faithful multi-ended action of a weakly branch group with finitely generated `rist(n)` has stabilizer `H` with `⊕_{v∈N(ξ)} K_v ≤ H ≤ G_ξ`.
  - This is the Matte Bon–Nekrashevych–Zheng (MNZ) "first key step" (arXiv:2607.13776), extended from branch to weakly branch groups. The extension replaces MNZ's `l-quotient-rist` step by "`rist(n)` is not virtually abelian".
- **`branch-group-embeddings-in-v-are-boundary-sandwiched`** (with its proof node).
  - A finitely generated branch group `G` embeds in `V` exactly when some subgroup of some `G_ξ` has a context-free Schreier graph. The same holds for weakly branch groups with finitely generated `rist(n)` that are not elementary amenable.
  - With finite germs, `H` has finite index in `G_ξ`, so the boundary orbit has exponential growth.
  - Consequence: no finitely generated branch group generated by a bounded automaton embeds in `V`. Examples: Hanoi `H^(m)`, Skipper `G_n`, Grigorchuk, Gupta–Sidki, Fabrykowski–Gupta.
  - The Basilica result is recovered.
- **Artifact** `gq-bh-bh-branch-in-v-sources.md`: sources read at source, with md5s.
- **Question node:** Attempt 1 appended. The source's own closing remark, which the node had not recorded, already excludes contracting self-replicating branch groups.

## Open leads

- **Positive answer.** Find a non-contracting finitely generated branch group, with finite germs, whose boundary orbital graph `Σ_ξ`, or a finite cover of it, is context-free: tree-like with exponential growth. Any such group embeds in `V`, by part (b) of the reduction node.
- **Negative answer.** Show that no boundary-sandwiched Schreier graph of a finitely generated branch group is context-free. Two sub-steps:
  - rule out tree-like graphs of germs with infinitely many ends when germs are finite;
  - handle infinite germs.
- **Weakly branch groups without finitely generated `rist(n)`.** Not covered: MNZ's reduction lemma needs a finitely generated normal subgroup.
- **Bishop–Schesler spinal branch groups** (UNOWNED row 55). If their boundary orbits have subexponential growth and their germs are finite, the corollary puts them outside `V`. This is not checked.

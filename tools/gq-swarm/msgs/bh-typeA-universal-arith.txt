Arithmetic piece identifications are capped: machine-universal maps live in orbits, not words

Answers the Conway/piecewise-affine suggestion for the merged R-b + R-c target, and the answer is negative. Take any frame class in which composites of n elements have description size 2^O(n) and identity is testable in polynomial time. This covers finite transducers, RCWA/Conway/class-transposition maps, and integer piecewise-affine or projective maps. Such a class gives operad groups with single-exponential word problem whatever the Ore condition or spine, so the class of such hosts is not universal. Residue-class operads even have unary squares (CRT), so Ore is automatic and R-b cannot occur. Machine universality of these maps lives in iterates (orbits, cycles, reachability), which the word problem never asks. The merged target is therefore exactly a finite Ore Lambda-substitution for a Lambda with hard word problem, and the mortal machine belongs in its Ore condition.

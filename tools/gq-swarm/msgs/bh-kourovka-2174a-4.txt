Monomial elements of CT(Z) have decidable torsion, so machine step maps give no unsolvable torsion problem

A monomial element (n -> lambda n on each piece) is a counter machine, so its finite order is uniform
periodicity, which is decidable (Kari-Ollinger Thm 4). Every counter-machine step map built from class
transpositions is monomial, so the group generated by a universal reversible machine's step maps has
solvable torsion problem. Torsion is also decidable when all moduli are powers of 2 (reduction to V).
An unsolvable torsion problem needs non-monomial pieces with a modulus that is not a power of 2.

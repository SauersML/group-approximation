Exclude every analytic coding of Kodama's n-adic Lodha-Moore groups; recast Garrido-Reid's question as fragmentation

In an analytic tree coding, a contracting recursion y g_u = g_v y pushes every
breakpoint of y to the fixed point of g_u. For n >= 3, Kodama's y has a finitary
branch y(0kz) = kz that pins it to g_0^{-1}, and the rule y(00z) = 0y(z) then
forces g_0 to fix an interval. So no digit recoding, Farey, Stern-Brocot or PL
coding makes G_0(n) piecewise projective or piecewise analytic.

Nekrashevych's A(G) is exactly the subgroup generated by commutators of pairs
supported in a clopen set with two disjoint translates. So Garrido-Reid's
question, whether D is simple, is equivalent to fragmenting global commutators
into local ones. Both question nodes get Attempts entries and stay open.

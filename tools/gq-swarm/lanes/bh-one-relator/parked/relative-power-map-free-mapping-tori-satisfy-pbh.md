elementary, on top of the landed (T); not yet refereed; no priority claimed).

## Statement

Let `F = X * Z` with `X = F(x_1, …, x_r)`, `r ≥ 1`, and `Z = F(z_1, …, z_s)`, `s ≥ 0`. Let
`𝓜 ⊆ End(F)` be the monoid generated by:
- **(P) power maps** `ρ_m : x_i ↦ x_i^(m_i)`, `z_j ↦ z_j`, for integers `m_i ≠ 0`;
- **(Π) permutations** `x_i ↦ x_(π(i))`, `z_j ↦ z_j`, for `π ∈ S_r`;
- **(A) relative automorphisms**, the group `Aut_X(F)` of automorphisms of `F` fixing every
  `x_i`.

Every `φ ∈ 𝓜` is injective, and the ascending HNN extension `F*_φ` lies in `B_A`. So
`F*_φ` has solvable word problem and embeds in a finitely presented simple group
(`type-a-action-gives-boone-higman-for-subgroups`).

## Members

- **Permuted power maps** (`s = 0`): the family of
  `power-map-free-mapping-tori-satisfy-permutational-boone-higman`, including `BS(1,m)` and
  the Druţu--Sapir group.
- **Mutanguha's non-hyperbolic example.** `ψ(a) = aba`, `ψ(b) = bab` on `F(a,b)`. In the
  basis `c = ab`, `z = a` one gets `ψ(c) = c^3` and `ψ(z) = c z`. So `ψ = λ ∘ ρ` with
  `ρ(c) = c^3`, `ρ(z) = z` and `λ(c) = c`, `λ(z) = c z`, which lies in `Aut_(⟨c⟩)(F)`.
  Hence `F*_ψ ∈ B_A`. It contains `BS(1,3) = ⟨ab, t⟩` and is not hyperbolic
  (`mutanguha-ascending-hnn-hyperbolicity-criterion`).
- **Letter multiplications.** `x ↦ x^m`, `z_j ↦ w_j z_(τ(j))^(±1) w'_j` with `w_j, w'_j ∈ X`,
  `τ ∈ S_s`, such as `⟨x, y, t | t x t^{-1} = x^2, t y t^{-1} = y x⟩` (the "mixing step" of
  `pbh-class-closed-under-relative-holomorphs`).

## Not reached

Endomorphisms whose `BS(1,d)` subgroups do not come from a power map on an invariant free
factor fixed in this way. A test case not settled here: `φ(a) = a^2`, `φ(b) = b a b^{-1}` on
`F(a,b)`, whose mapping torus contains `BS(1,2) = ⟨a, t⟩`.

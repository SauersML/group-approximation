Run compression: a letter fixed by every state can be deleted without changing the group

If every state of an automaton fixes a letter x, reading each maximal run of x's through its class modulo the eventual period of the section map gives a faithful finite-state action of the same group, by the same states, on the alphabet (X - x) x {0..p+q-1}. Persistent letters are the special case where the compressed action is just the restriction to the other letters, so persistence never obstructs a group. The linear-activity spine-Grigorchuk automaton, whose three-letter Nekrashevych group is not finitely presented, compresses to a bounded contracting automaton on four letters, so the same group has a finitely presented V_4 and a self-similar Boone-Higman host.

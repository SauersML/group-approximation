Direct proof (2026-09-18, lane bh-openq-papers). Not independently reviewed. Conventions as in
`wreaths-over-clopen-stabilizer-cosets-proof`; `x_0 = H ∈ G/H`.

**1. Generators.** Let `S` generate `G` and `T` generate `L`. For `ℓ ∈ L`, let `δ_ℓ` be the
function `x_0 ↦ ℓ` and `x ↦ 1` otherwise. The group `L ≀_{G/H} G` is generated by `S` together
with `{δ_t : t ∈ T}`, because `g δ_ℓ g^(-1) = g·δ_ℓ` is the function `g x_0 ↦ ℓ` and `G` is
transitive on `G/H`.

**2. The test word.** Fix `t ∈ T` with `t ≠ 1` (possible since `L ≠ 1`). For a word `u` in
`S^(±1)`, put `c_u = δ_t · u δ_t^(-1) u^(-1)`, a word in the generators computable from `u`. As a
function on `G/H`:
- if `u x_0 = x_0`, then `c_u = δ_t δ_t^(-1) = 1`;
- if `u x_0 ≠ x_0`, then `c_u` takes the value `t ≠ 1` at `x_0` (and `t^(-1)` at `u x_0`), so
  `c_u ≠ 1`.

Since `u x_0 = x_0` iff `u ∈ H`, a word-problem algorithm for `L ≀_{G/H} G` decides membership
in `H`. This proves item 1.

**3. The countermodel.** Take `G = F_k`, `H = N = ker(F_k ->> B)`, `L = Z`.
- Membership in `N` is the word problem of `B`, which is unsolvable. By item 1, `Z ≀_{F_k/N} F_k`
  has unsolvable word problem.
- It is finitely generated by step 1.
- A finitely generated subgroup of a finitely presented simple group has solvable word problem
  (`simple-envelope-forces-solvable-word-problem`). A subgroup of a group with a type (A)
  action has solvable word problem (`type-a-action-gives-boone-higman-for-subgroups`). So
  `Z ≀_{F_k/N} F_k ∉ B_A`.
- `Z ≤ V` and `F_k ≤ V`. `V` has a type (A) clopen action by
  `fp-clopen-transitive-full-cantor-groups-have-type-a-actions`, applied to `D = V`, which is
  full and clopen transitive (see `lamp-wreaths-over-cyclic-cosets-of-f2-proof`, step 0). So
  `Z, F_k ∈ B_A`. ∎

**REFUTED** (2026-09-18, lane bh-free-08, lane proof, not reviewed) by `fp-decidable-group-whose-e-is-not-recursively-presented`: some finitely presented `G` with solvable word problem has non-r.e. `J_1(G)`, so `E(G)` is not recursively presented. Asked on MathOverflow, question 412219 (2021), "Is E(G) recursively presented
for finitely presented G?", read through the StackExchange API on 2026-09-18.
- **The group:** for a group `G`, let `E(G) ≤ G^G` be the subgroup generated by the
  constant maps `c_g` and the identity map.
- **Known:** the question records that M. Zaremsky showed `E(F_2 × F_2)` is not finitely
  presented.
- **The question:**

> If G is finitely presented, does this imply that E(G) is recursively presented?

**Reformulation (lane proof, elementary, not reviewed).** Consider the homomorphism
`G * <x> -> G^G` that sends `g` to `c_g` and `x` to the identity map. Its image is `E(G)`.
Its kernel is `J_1(G) = {w : w(a) = 1 for all a in G}`, the one-variable mixed identities
of `G`. Hence

    E(G) ≅ (G * Z) / J_1(G),

which is exactly the rank-one quotient in BFFHZ Question 3.3; see
`bffhz-q33-is-normal-finite-generation-of-mixed-identities`. Consequences for a finitely
presented `G`:
1. `E(G)` is recursively presented iff `J_1(G)` is recursively enumerable as a set of
   words. If the presentation is recursive, the trivial words form an r.e. set, and
   conversely `J_1(G)` itself is then an r.e. set of relators.
2. If `G` has solvable word problem, then the complement of `J_1(G)` is r.e.: search for
   `a` with `w(a) ≠ 1`. So in that case `E(G)` is recursively presented iff `J_1(G)` is
   decidable, iff `E(G)` has solvable word problem.
3. `E(G)` is finitely presented iff `J_1(G)` is finitely normally generated in `G * Z`.
   On main this fails for Thompson's `T`
   (`thompson-t-mixed-identities-are-not-finitely-normally-generated`). But `J_1(T)` is
   decidable (`thompson-t-mixed-identity-problem-is-decidable`), so `E(T)` is recursively
   presented with solvable word problem.

**What an answer needs.**
- **Negative:** a finitely presented `G` with solvable word problem whose one-variable
  mixed-identity problem is undecidable. Identities such as `[x^m, g] = 1` encode
  "`g` commutes with all `m`-th powers", which does not reduce to finitely many
  generator checks.
- **Positive:** a uniform enumeration of mixed identities for all finitely presented
  groups.

**Tractability.** Medium to high, on the logic side (bh-logic, bh-bbmz-problems).

## Attempts

1. **Finitely generated version: answered negatively** (bh-openq-lists, 09-18).
   `fg-decidable-group-whose-e-is-not-recursively-presented` builds a 3-generator group
   `Γ` with a recursive presentation and a solvable word problem such that `J_1(Γ)` is
   not r.e. So `E(Γ)` is not recursively presented, and it embeds in no finitely
   presented group.
   - **The group:** `Γ = (N_2 ⋊ Z) *_C (C × Z)`, where `N_2` is free nilpotent of class 2
     on the `t`-shifts of one generator.
   - **The rows:** the derived subgroup splits into `t`-invariant rows `R_d`, one per
     commutator distance `d`. These are normal subgroups of the base, each a single
     conjugation orbit, and they are pairwise independent.
   - **The encoding:** `c` centralizes exactly the recursive set of basis commutators
     indexed by `H`. The words `[c, x^{-1} [a_0, a_d] x]` then encode "row `d` lies in
     `H`", a Π₁-complete property.
2. **What finite presentation would need.** The construction relies on two facts in the
   host `P`: each row `R_d` is normal in `P`, and the element `c` centralizes a prescribed
   recursive set of rows. Mixed identities do not pass to overgroups. So embedding `Γ` in
   a finitely presented group (Clapham, Higman) loses the (⇐) direction, because
   conjugates of `[a_0, a_d]` by new elements leave `R_d`. Retracts do not help either:
   restricting `x` only gives `J_1(P) ∩ (Γ * <x>) ⊆ J_1(Γ)`. Two constructions would
   answer the finitely presented question:
   - a finitely presented `P ⊇ Γ` that normalizes every row `R_d`, for example with `Γ`
     normal in `P` and `P` acting row-preservingly;
   - a direct finitely presented group with infinitely many independent normal subgroups,
     each a single conjugation orbit that behaves like a free abelian row.

   Finitely generated metabelian groups satisfy max-n (P. Hall), so the second option
   needs a non-metabelian finitely presented group. Neither was found.
3. **Finitely presented version: answered negatively** (bh-free-08, 09-18).
   `fp-decidable-group-whose-e-is-not-recursively-presented` gives a finitely presented
   `G` with solvable word problem whose `J_1(G)` is co-r.e. but not r.e. A variant makes
   `J_1(G)` `Π_2`-complete.
   - **How it avoids the gap in Attempt 2:** it does not try to keep a mixed identity alive in
     an overgroup. The quantifier that carries the information ranges over one cyclic
     subgroup `⟨a⟩`, and "`w_e(a^n) = 1` for all `n`" survives Clapham's embedding.
   - **Mihailova step:** a Mihailova subgroup `M` of a mapping torus `(F × F) ⋊_{(id,ψ)} Z`,
     with `ψ: z ↦ zα`, turns "for all `n`" into membership in the normal core `Core_K(M)`.
   - **Amalgam step:** the amalgam `K *_M (M × Z)` turns core membership into a one-variable
     mixed identity `[x^{-1} c x, b]`.

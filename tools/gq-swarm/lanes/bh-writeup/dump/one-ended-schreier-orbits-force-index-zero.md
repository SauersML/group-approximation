**ESTABLISHED** by `one-ended-schreier-orbits-force-index-zero-proof`. Lane proof, elementary, not independently reviewed, no priority claimed. The end trichotomy for locally finite vertex-transitive graphs (Halin) and Stallings' theorem are used, not reproved.

## Setting

`P` is an infinite group generated by a finite symmetric set `S`, and `rho: P -> Sym(N)` is a genuine action whose near action is faithful: every `g != 1` moves infinitely many points. This is the setting of `genuine-action-shell-envelopes-generalize-the-regular-shell`. For an orbit `A`, let `Gamma_A` be its Schreier graph: vertices `A`, edges `{x, rho_g x}` for `g ∈ S`. Each `Gamma_A` is connected, locally finite and vertex-transitive, because `P` acts transitively on `A` by graph automorphisms.

Let `phi ∈ Aut(P)`. A partial bijection `sigma` of `N`, with cofinite domain and image, is *`phi`-twisted near-equivariant* if for every `g ∈ S`

    sigma(rho_(phi(g)) x) = rho_g sigma(x)

for all but finitely many `x`. Its index is `ind(sigma) = |N \ im(sigma)| - |N \ dom(sigma)|`. Call `sigma` *shift-like* if `N` is, up to a finite set, a single forward orbit `{sigma^k(x_0) : k >= 0}`; the shift `s: n ↦ n+1` is shift-like of index `1`.

The window-zero gate of the shell route asks for `s^-1 rho_g s = rho_(phi(g))` near infinity, which is exactly the statement that `s` is `phi`-twisted near-equivariant. So a window-zero witness is a shift-like twisted near-equivariant partial bijection of index `1`. See `shell-ascending-gate-is-a-finite-window-inclusion` and item 5 of `eventually-periodic-genuine-shell-actions-give-fp-envelopes`.

## Statement

1. **Fixed points are finite in number.** If some `phi`-twisted near-equivariant `sigma` is shift-like, then `Fix(rho) = {x : rho_g x = x for all g}` is finite.
2. **Germ rigidity on free orbits.** Let `A` be a free orbit whose Schreier graph is one-ended, and let `sigma` be `phi`-twisted near-equivariant. Then `sigma` agrees, off a finite set, with the labelled bijection `theta: A -> A'` onto a single orbit `A'`, given by `theta(rho_(phi(w)) x_0) = rho_w y_0` for `y_0 = sigma(x_0)`. In particular `A'` is free and the contribution of `A` to `ind(sigma)` is `0`.
3. **Index zero.** Suppose all but finitely many points of `N` lie in free orbits with one-ended Schreier graphs. Then every `phi`-twisted near-equivariant partial bijection has index `0`, for every `phi ∈ Aut(P)`. In particular there is no window-zero witness, whatever the order of the twist.
4. **Infinite simple inputs are one-ended.** An infinite finitely generated simple group is one-ended, and it has no proper subgroup of finite index.
5. **Free actions of simple inputs are dead.** Let `P` be infinite, finitely generated and simple, and let `rho` be free, that is `Stab(x) = 1` for every `x`. Then no window-zero witness exists.
6. **No orbit with two ends.** If `P` is infinite and simple, no `Gamma_A` has exactly two ends.
7. **The surviving shape.** Let `P` be infinite, finitely generated and simple, and let a genuine action with faithful near action pass the window-zero gate for some `phi ∈ Aut(P)`. Then some orbit has a nontrivial point stabilizer, and, since a Schreier graph with one end obeys item 2's rigidity only in the free case, the live possibility is an orbit whose Schreier graph has infinitely many ends. Two ends and finite orbits are excluded, by item 6 and by items 1 and 4.

## Consequences for the shell route

- Item 3 settles the case left open by item 5 of `eventually-periodic-genuine-shell-actions-give-fp-envelopes`, a twist of infinite order, for free actions with one-ended orbits. The order of the twist plays no part in the argument.
- The dividing line is the ends of the orbits, not the ends of the input. `Z^2` is one-ended yet has a window-zero genuine action, whose orbits are finite.
- For the reduced inputs of `boone-higman-iff-simple-kazhdan-decidable-inputs`, which are infinite simple, items 4–6 leave exactly one shape: a non-free orbit, and the natural candidate is one whose Schreier graph has infinitely many ends.

## Calibrations

- **`P = Z`, zigzag.** The Cayley graph has two ends and `ind(s) = 1` with `phi` the inversion. `Z` is not simple, so item 6 does not apply, and item 3's hypothesis fails at "one-ended".
- **`P = Z^2`, eventually periodic.** All orbits are finite, so item 3 does not apply and the landed window-zero witness stands.
- **Regular actions.** For the left regular action the orbit is free with Cayley graph, so item 3 recovers `one-ended-shell-inputs-admit-no-shift-normalizing-enumeration` and the case `tau = 1` of `one-ended-near-regular-actions-have-a-realization-defect`.

## Scope and what is not claimed

- Only automorphism twists are treated. An injective endomorphism with image of infinite index changes the source graph to a Schreier graph of that image, which can have more ends.
- **The non-free gap.** For a non-free orbit with one-ended Schreier graph, the proof gives only that `sigma` maps it onto a cofinite subset of a single orbit. Whether the per-orbit deficit must vanish is open; the obstacle is that the labelled germ need not extend across loops of the Schreier graph that leave the one infinite component.
- Nothing is claimed for orbits with infinitely many ends, where the germ is genuinely not unique: the complement of a finite set has several infinite components and `sigma` may use a different germ on each. That freedom is what makes the two-ended case of `Z` possible.
- Nothing here bears on window `N >= 1`, or on finite presentation of `R_rho`, `Q_rho` or `E_rho`.
- **Expected, not proved.** For an input with property (T), an orbit whose Schreier graph has infinitely many ends should be impossible: the Dunwoody structure tree of such a graph would give an unbounded action of `P` on a tree, while property FA gives a fixed point. With that, item 7 would close the window-zero gate for every reduced input of Boone–Higman, and the genuine-action shell would need window `N >= 1` exactly as the regular shell does.

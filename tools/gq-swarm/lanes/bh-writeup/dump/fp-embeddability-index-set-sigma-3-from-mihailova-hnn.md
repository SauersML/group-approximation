## Σ_1-hardness

- **The fixed group.** Fix a finitely presented `U_0` and words `w_n` with
  `w_n = 1` iff `n ∈ K`, the halting set (Novikov–Boone).
- **Rabin's construction.** Rabin's construction (Lyndon–Schupp IV.4) computes
  from `w` a finite presentation `R_w` such that:
  - `R_w = 1` if `w = 1`;
  - `U_0 ≤ R_w` if `w ≠ 1`.
- **The reduction.**
  - If `n ∈ K`, then `R_{w_n} = 1`, which lies in `EMB_fp`.
  - If `n ∉ K`, then `R_{w_n}` contains `U_0`, whose word problem is undecidable.
    So it lies outside `EMB_fp` by Kuznetsov.

  Hence `K ≤_m EMB_fp`.

## Mihailova HNN extensions

Let `Q = ⟨X | R⟩` be finite with `|X| = m ≥ 2`, let `C = M(Q)`, and let
`H = H(Q)`.

1. **Finite presentation.** `F × F` is finitely presented and `C` is generated by
   the finitely many `(x,x)` and `(r,1)`. So `H` is finitely presented, and
   uniformly computable from `Q`.
2. **Membership equals the word problem.** Mihailova: `(u,v) ∈ C` iff `u =_Q v`.
   So membership in `C` is Turing-equivalent to `WP(Q)`, uniformly.
3. **`WP(H) ≤_T WP(Q)`.** Britton's lemma: reduce pinches `s^{±1} c s^{∓1}` for
   `c ∈ C`. This uses membership in `C` and the word problem of `F × F`, and the
   associated isomorphism is the identity.
4. **`WP(Q) ≤ WP(H)`.** For `u ∈ F`: if `(u,1) ∈ C`, then `[s,(u,1)] = 1`.
   Otherwise `s (u,1) s^{-1} (u,1)^{-1}` is Britton-reduced, hence `≠ 1`. So
   `u =_Q 1` iff `[s,(u,1)] = 1` in `H`.

## The reduction under MH

- **The family.** Let `i ↦ U_i` be the splitting lemma of
  `boone-higman-is-equality-of-two-sigma-3-index-sets-proof`: cofinite `U_i` when
  `W_i` is cofinite, noncomputable `U_i` otherwise.
- **The finite presentations.** Let `Q_i` be the finitely presented
  Higman–Clapham overgroup of the recursively presented `G_{U_i}`. Its word problem
  is Turing-equivalent to `U_i`, uniformly. That uniformity is cited, not re-read.
  Map `i ↦ H(Q_i)`.
- **Cofinite `W_i`.** `U_i` is computable, so `Q_i` is decidable. By MH, `H(Q_i)`
  lies in `EMB_fp`.
- **Coinfinite `W_i`.** `WP(Q_i)` is undecidable, so `WP(H(Q_i))` is undecidable
  by item 4. So `H(Q_i)` lies outside `EMB_fp` by Kuznetsov.
- **Conclusion.** `COF ≤_m EMB_fp`, and `COF` is `Σ_3`-complete. ∎

Notation as in the claim. Replacing `s` by `s^-1` exchanges the two values of `eps`, so
take `eps = 1`, `t = s`, `W = W_N = <c_0, ..., c_N>`. All equalities are in the near
permutation group, that is, up to finitary permutations.

**Textbook inputs, not reproved.**
- (H) Higman--Neumann--Neumann: for an injective endomorphism `psi` of a group `W`, the
  base `W` embeds in the HNN extension `W *_psi`, and the base kernel of its natural
  retraction to `Z` is the increasing union of the conjugates `t^n W t^-n`, that is, the
  direct limit of `W --psi--> W --psi--> ...`.
- (F) A mapping torus of a finitely presented group is finitely presented: if
  `W = <X | Rel>` with `X` and `Rel` finite, then
  `W *_psi = <X, t | Rel, t^-1 x t = w_x (x in X)>`, where `w_x` is any word representing
  `psi(x)`. This is a finite presentation.

**Step 0. `eta` and the splitting.**
`eta(lambda_g) = 0` for every `g`, since each `lambda_g` is a permutation of `N`, and
`eta(t) = 1`. So `eta(t^m) = m` is nonzero for `m` nonzero, giving
`<t> intersect ker(eta) = 1` and `R = ker(eta) x| <t>`. Step 0 of
`shell-ascending-gate-finite-window-proof` gives `ker(eta) = <c_k : k in Z>`.

**Step 1. `psi` maps `W` into `W`.**
The window inclusion is `t^-1 lambda(P) t <= W`, that is `c_(-1) <= W`. Conjugating the
window inclusion by `t` gives `c_0 <= <c_1, ..., c_(N+1)> = t W t^-1`. For
`1 <= j <= N` the conjugate `c_j` lies in `t W t^-1` as well, since
`c_j = t c_(j-1) t^-1` and `c_(j-1) <= W`. Hence `W <= t W t^-1`, that is
`psi(W) = t^-1 W t <= W`. `psi` is injective because conjugation is.

**Step 2. `ker(eta)` is the ascending union of the `t^n W t^-n`.**
By Step 1 the subgroups `W_((n)) = t^n W t^-n`, `n >= 0`, form an increasing chain.
`c_k <= W_((n))` for `0 <= k <= N + n`, so the union contains every `c_k` with `k >= 0`.
For `k < 0` argue downward: `c_(-1) <= W` is the window inclusion, and if
`c_(-m) <= W` for some `m >= 1` then conjugating the window inclusion by `t^-m` gives
`c_(-m-1) <= <c_(-m), ..., c_(N-m)> <= W`, because every generator on the right is one of
`c_(-m), ..., c_(-1)` or one of `c_0, ..., c_N`, all of which lie in `W`. So `c_k <= W`
for every `k <= 0`, and `ker(eta) = <c_k : k in Z> = union_(n >= 0) W_((n))`.

**Step 3. `R` is the mapping torus.**
Let `M = W *_psi` and let `pi: M -> R` be the homomorphism that is the identity on `W`
and sends `t` to `t`; it is well defined because `t^-1 w t = psi(w)` holds in `R`, and it
is onto because `R = <lambda(P), t>` and `lambda(P) = c_0 <= W`. Both `M` and `R` carry
retractions to `Z` killing `W` and sending `t` to `1`, and `pi` respects them, so `pi`
restricts to a map of base kernels. By (H) the base kernel of `M` is the direct limit of
`W` along `psi`, realized inside `M` as the increasing union of the `t^n W t^-n`. By
Step 2 the base kernel of `R` is the increasing union of the same conjugates, with the
same transition maps: under the isomorphisms `W -> W_((n))`, `w -> t^n w t^-n`, the
inclusion `W_((n)) <= W_((n+1))` is `psi`, because
`t^n w t^-n = t^(n+1) (t^-1 w t) t^-(n+1)`. So `pi` is an isomorphism on base kernels and
on the quotients `Z`, hence an isomorphism. This is item 1.

**Step 4. Item 2.**
Each `c_(eps*j)` is a conjugate of `lambda(P)`, which is generated by the finitely many
`lambda_g`, `g in S`. So `W` is generated by the `(N+1)|S|` elements
`t^j lambda_g t^-j`, `0 <= j <= N`, and is finitely generated. If `W` is finitely
presented then `R = W *_psi` is finitely presented by (F). The window inclusion is item
(2) of `shell-ascending-gate-is-a-finite-window-inclusion`, so by that claim the ascending
clause of `shell-germ-fp-is-an-ascending-hnn-gate` holds with `B = W`; both clauses of
that gate now hold, so `Q` is finitely presented, and `F_nu` is finitely presented by
`shell-germ-group-has-index-two-fiber-product`.

**Step 5. Item 3.** This is the contrapositive of the implication in Step 4.

**Step 6. The calibration.**
For `P = Z` with the zigzag enumeration, `s lambda_1 s^-1 = lambda_(-1)` near infinity is
recorded in `one-ended-shell-inputs-admit-no-shift-normalizing-enumeration`. Hence
`s lambda(Z) s^-1 = lambda(Z)`, which is the window inclusion for `eps = -1` and `N = 0`
with `W = lambda(Z)` infinite cyclic, and `psi` is inversion. Item 1 gives
`R_nu = Z x|_(-1) Z` and item 2 gives `Q` finitely presented. Here the union of Step 2 is
constant, which the gate allows.

**Step 7. The spiral corollary.**
`square-spiral-z2-enumeration-passes-the-finite-window-gate` gives the window for
`eps = 1`, `N = 2`, and `square-spiral-z2-near-shift-group-is-not-finitely-presented`
gives that `R_nu` is metabelian and not finitely presented. Item 3 then says `W_2` is not
finitely presented, and `W_2 <= R_nu` is metabelian and finitely generated by Step 4.

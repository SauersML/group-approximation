## Setting

`C = {0,1}^N` is the full binary shift (one vertex, two loops), `V ≤ Homeo(C)` is
Thompson's group, and `N(V)` is its normalizer in `Homeo(C)`. By Rubin's theorem
`N(V) ≅ Aut(V)`, and `V` is centreless, so `Out(V) = N(V)/V`. By BCMNO,
`Out(V) ≅ O_2`, the group of minimal bi-synchronizing core transducers. Every
`t ∈ N(V)` is given by a bi-synchronizing transducer, so it is rational. For `t ∈ N(V)`
put

    Γ_t = ⟨V, t⟩ .

## Statement

1. **Structure.** `Γ_t = V⟨t⟩`, `V ⊴ Γ_t`, and `Γ_t/V` is the cyclic group generated by the
   class of `t` in `Out(V)`. In particular `Γ_t ≅ V ⋊ Z` when that class has infinite order.
   `Γ_t` is finitely presented.
2. **RSG.** `Γ_t ≤ R_{Γ,C}` and `Γ_t` is an RSG (it contains `V`).
3. **Contracting iff finite outer order.** `Γ_t` is contracting iff the class of `t` in
   `Out(V)` has finite order. Its nucleus contains the nuclei of all `t^m`, and
   `|N_{t^m}| = |core(t^m)|`, which is unbounded for `t` of infinite order (Olukoya's core
   growth).
4. **Not full.** If `t` has infinite order in `Out(V)`, then `Γ_t ≠ [[Γ_t]]`. Explicitly, the
   homeomorphism equal to `t` on the cone `C_0` and to a suitable element of `V` on `C_1`
   lies in `[[Γ_t]] − Γ_t`.
5. **Type (A).** `Γ_t` acts on the proper nonempty clopen subsets of `C` with type (A):
   faithful, finitely many orbits of pairs, and clopen stabilizers `(V × V) ⋊ Z` (or
   finite extensions of `V × V`), which are finitely generated. So `Γ_t ∈ B_A`.
6. **Existence.** `Out(V)` has elements of infinite order, for example the exponential core
   growth examples of Olukoya, arXiv:2004.00516.

## Consequence for Question 1.4

For `t` of infinite order in `Out(V)`, `Γ_t` is a finitely presented, non-contracting,
non-full RSG. By item 3, `[[Γ_t]]` is non-contracting as well
(`contracting-rsgs-have-fp-full-closures`, item 1), so BBMZ Theorem B does not decide
whether it is finitely presented. `fp-rsgs-have-fp-full-closures` for this family is
exactly: **is `[[Γ_t]]` finitely presented?** Item 5 shows the family carries no Boone--Higman
content: `Γ_t` already lies in `B_A`, so only Question 1.4 is at stake.

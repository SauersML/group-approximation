# Universal shear innerization and the symmetric-double reduction

Date: 2026-08-13

## 1. The twisted central-radical double

Let `G` be a countable group and let

```text
s in Rad_sof(G)
```

have infinite order.  Adjoin a central involution `z` and put

```text
K = G times <z>,
C = <s> times <z> <= K.
```

The formula

```text
alpha(s)=z s,                  alpha(z)=z                 (SI1)
```

defines an involutive automorphism of `C`.  Let

```text
J = K *_(C,alpha) K                                      (SI2)
```

denote the twisted symmetric double, with the convention that its edge
relation is

```text
j_1(c)=j_2(alpha(c)),           c in C.                  (SI3)
```

The common image of `z` is a nontrivial central involution in `J`.  Moreover,

```text
z in Rad_sof(J).                                         (SI4)
```

Indeed, both vertex embeddings are injective by the normal-form theorem for
amalgamated free products, so `z` remains nontrivial.  It is central in both
vertices and fixed by `alpha`, hence central in `J`.  If `Phi:J->S` and `S`
is sofic, each restriction `Phi o j_i|G` kills `s`.  Applying `Phi` to

```text
j_1(s)=j_2(zs)
```

therefore gives `1=Phi(z)`.  This proves `(SI4)`.

Consequently, operator-norm MF for `J` is already enough to produce a
hyperlinear nonsofic image: round the central involution in matrix
coordinates, compress to a nonzero negative spectral corner, and pass to the
normalized Hilbert--Schmidt ultraproduct.  Centrality makes the compression
asymptotically multiplicative and the image of `z` is exactly `-1`.

## 2. A universal module which makes the twist inner

Let

```text
R = F_2[G],
I = ker(epsilon:R->F_2),
A = R / I(1+s).                                         (SI5)
```

Write `v` for the class of `1` and put

```text
z_A=(1+s)v.                                             (SI6)
```

The calculation in `FALSE_MACKEY_SPLIT_COCYCLE.md`, Theorem 6, proves that
`z_A` is nonzero, has order two, and is fixed by all of `G`.  Form

```text
E=A semidirect G                                        (SI7)
```

for the left regular module action, and let

```text
tau=(v,1) in E.                                         (SI8)
```

Since `A` has exponent two, `tau` is an involution.  With the semidirect
product law

```text
(a,g)(b,h)=(a+g b,gh),
```

one obtains the exact identity

```text
tau^(-1)(0,s)tau
  =(v,1)(0,s)(v,1)
  =(v+s v,s)
  =(z_A,s).                                             (SI9)
```

Also `tau` fixes `z_A`, because `A` is abelian.  Thus conjugation by `tau`
implements `(SI1)` on

```text
C_A=<s> times <z_A> <= E.                              (SI10)
```

The subgroup generated by the canonical copy of `G` and `z_A` is naturally
isomorphic to `K=G times <z>`.  Under this identification, `C_A` is `C`.

## 3. Embedding into an untwisted symmetric double

Let

```text
D=E *_C E                                               (SI11)
```

be the ordinary symmetric double, and write `i_1,i_2` for its vertex maps.
Define maps on the two vertices of `J` by

```text
f_1(k)=i_1(k),
f_2(k)=i_2(tau^(-1) k tau),             k in K.         (SI12)
```

For `c in C`, equation `(SI9)` says `alpha=Ad(tau)|C`, and hence

```text
f_2(alpha(c))
 =i_2(tau^(-1)alpha(c)tau)
 =i_2(c)
 =i_1(c)
 =f_1(c).                                               (SI13)
```

The universal property gives a homomorphism

```text
F:J -> D.                                               (SI14)
```

This homomorphism is injective.  The point needed for the amalgam normal-form
theorem is edge reflection.  For the first vertex it is immediate.  For the
second, if `k in K` and `tau^(-1)k tau in C`, then

```text
k in tau C tau^(-1)=C,
```

because `tau` normalizes `C`.  Thus neither vertex map sends a nonedge
syllable into the edge, and every reduced word in `J` remains reduced in
`D`.

We have therefore proved

```text
K *_(C,alpha) K  embeds in  E *_C E.                   (SI15)
```

This is useful because Shulman's symmetric-amalgam theorem applies to the
right-hand side: if `E` is weak/operator MF, then `E *_C E` is weak/operator
MF, and hence so is its subgroup `J`.

## 4. Exact limitation: this is not yet an analytic reduction

The construction removes the involutive edge twist as a separate algebraic
problem, but it does not make the remaining MF assertion easier for free.
The same element `z_A` satisfies

```text
z_A=[tau,s] in Rad_sof(E).                              (SI16)
```

Indeed every homomorphism from `E` to a sofic group kills the restriction of
`s`, and therefore kills its commutator with `tau`.  It follows that

```text
E weak/operator MF
  ==> a hyperlinear nonsofic image already exists.      (SI17)
```

So using Shulman's theorem after `(SI15)` does not bypass the open step:
proving its hypothesis for `E` is itself a complete radical-collision
endpoint.  In particular, one must not cite the symmetric-double theorem as
though it established MF for the universal shear extension.

What `(SI15)` genuinely establishes is the following clean separation of
tasks:

1. phase locking and twist innerization are exact group theory;
2. the sole unresolved issue is a matrix approximation of the universal
   module extension `(SI7)` which retains `(SI16)`;
3. any such approximation immediately solves hyperlinear versus sofic,
   without an additional amalgamated-free-product argument.

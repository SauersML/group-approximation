# Binary extension fibers reduce to one conditional-variance estimate

Date: 2026-08-14

## 1. Outcome

Each binary layer of the raw-to-comb synchronization gate has a sharper
scalar form.  Once the extension-character PVM and a named diagonal binary
routing statistic are exact, no separate combinatorial decoder theorem is
needed for that statistic.  Fiberwise majority decoding is canonical up to
ties, and its total error is equivalent within a factor of two to conditional
two-copy branch disagreement.

Let `pi:X->Y` be the restriction map from extension characters to source
characters.  Give the finite extension atoms nonnegative masses `mu(x)`.  If
`r:X->{0,1}` is the exact raw routing label, put

```text
m_y,b = sum_{pi(x)=y, r(x)=b} mu(x),
alpha_y = m_y,0 + m_y,1.                             (BFD1)
```

The best deterministic decoder on the source atom `y` chooses the majority
branch.  Its error is

```text
e_y = min(m_y,0,m_y,1).                              (BFD2)
```

Two conditionally independent extension atoms over `y` disagree in branch
with mass

```text
d_y = 2 m_y,0 m_y,1 / alpha_y                       (BFD3)
```

when `alpha_y>0`, and contribute zero when `alpha_y=0`.  Elementary
arithmetic gives

```text
e_y <= d_y <= 2 e_y.                                 (BFD4)
```

The inequalities sum over fibers without any common-rank or minimum-mass
assumption.  They are formalized source-first in
`GroupApproximation/Leavitt/FiniteBinaryFiberDecoder.lean` as
`majority_pairDisagreement_sandwich`,
`sum_majorityError_le_two_mul_sum_conditionalVariance`, and the companion
finite-family summation theorems.  This source was not locally or remotely
compiled in this iteration.

## 2. Operator-algebra form

Let `(E_x)` be the exact extension-character PVM and set

```text
F_y = sum_{pi(x)=y} E_x,
B   = sum_{r(x)=1} E_x.                              (BFD5)
```

The `F_y` generate the coarse source-character algebra `A_Y`.  On a fiber of
trace `alpha_y`, the trace-preserving conditional expectation is

```text
E_{A_Y}(B) F_y = (m_y,1/alpha_y) F_y.                (BFD6)
```

Consequently

```text
||B-E_{A_Y}(B)||_2^2
  = sum_y m_y,0 m_y,1 / alpha_y
  = (1/2) sum_y d_y.                                (BFD7)
```

Combining `(BFD4)` and `(BFD7)` gives the exact useful estimate

```text
total majority-decoder error
    <= 2 ||B-E_{A_Y}(B)||_2^2.                       (BFD8)
```

Thus the statement “the raw branch label is asymptotically a deterministic
function of the source character” is reduced to

```text
||B-E_{A_Y}(B)||_2 -> 0.                             (BFD9)
```

This is a single conditional-expectation/membership estimate, not a
whole-map rounding theorem.

## 3. What a group relation must now prove

The exact no-signaling box in
`FALSE_NONSIGNALING_PAIRED_QUOTIENT_SHORTCUT.md` shows that `(BFD9)` does not
follow from pairing values and matching marginals.  A successful group word
must force the raw branch projection `B` into the coarse source algebra
generated by the comb fibers.

There are two equivalent high-yield formulations:

1. prove the conditional variance `(BFD7)` is `o(1)` directly; or
2. construct a source-algebra element `A` with `||B-A||_2=o(1)`, since
   conditional expectation is the `L^2`-best approximation and then
   `||B-E_{A_Y}(B)||_2<=||B-A||_2`.

The second formulation makes the next word search concrete.  Search for a
cross-root multiplication word whose extension-character Fourier transform
is the binary branch indicator, modulo a term with vanishing normalized-HS
norm.  Local Pauli normalizers cannot do this because they act inside each
extension packet and leave the multiplicity centralizer free.  The word must
couple the raw router to the comb restriction map.

For a finite response window one must apply `(BFD9)` to every binary routing
decision used to assemble its response map and control the sum of their
errors.  Only after those decisions are known to be compatible with the
cross-root multiplication table does majority decoding give the
multiplication-coherent character decoder.  Deterministic coarsening then
gives whole-map PVMs, tree gluing gives the common latent-map law, and the
robust `1/36` floor closes the contradiction.  The scalar theorem does not by
itself construct the named branch statistics or prove their compatibility.

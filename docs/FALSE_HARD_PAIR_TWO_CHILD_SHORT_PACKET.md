# The hard 11/30 prefix packet is one-sided at short word depth

Date: 2026-08-13

## Outcome

The infinite-projection certificates attached to boundary classes `11` and
`30` do not already contain a short two-child/Cuntz certificate.  For each of
the six distinct hard prefix pairs `(q,l)`, exhaustive exact Leavitt
arithmetic through mixed-word depth seven finds matrix-unit corners from a
base cylinder to its `0` child, but none to its `1` child.  Therefore none of
the six pairs gives two complementary child isometries at this depth.

The depth-seven calculation enumerates `60,240` distinct reduced Leavitt
values across the six pairs.  The smallest-growth representative, pair index
`1`, was also searched through depth nine: `39,364` distinct values still
give no `1`-child corner.  A bounded depth-ten run exceeded the deliberately
short 50-second MSI limit and was stopped; it supplies no mathematical
evidence and is not archived as a result.  The exact search is implemented by
`experiments/atlas_hard_pair_two_children.py` and archived in
`experiments/atlas-hard-pair-two-children-depth7.json` and
`experiments/atlas-hard-pair-1-depth9.json`.

The bounded search itself closes only the short-certificate route.  The
subsequent eventual-zero germ construction now supplies the all-depth
theorem: no hard pair, nor the algebra generated by all six hard pairs, can
contain the complementary-child equivalence.  See
`FALSE_HARD_PACKET_EVENTUAL_ZERO_GERM.md`.

## Exact test

Let

```text
D=(000,001,010,011,10,11).
```

The earlier projection certificates place every cylinder projection `p_a`,
`a in D`, in the star algebra generated by `q,l`.  Hence a word `w` with a
corner

```text
p_(a i) w p_a = (a i) a*       or
p_a w p_(a i) = a (a i)*
```

certifies Murray--von Neumann equivalence of `p_a` and its child `p_(a i)`.
The script reduces every word up to the requested length in

```text
q, l, q*, l*
```

by exact characteristic-two Leavitt multiplication and tests all twelve
base/child corners.  The numbers of distinct reduced values are:

| class/orientation | distinct values | two-child base |
|---|---:|---|
| 11, forward rotation 0 | 7596 | none |
| 11, forward rotation 3 | 4907 | none |
| 11, inverse rotation 6 | 17424 | none |
| 30, forward rotation 3 | 9590 | none |
| 30, forward rotation 6 | 4907 | none |
| 30, inverse rotation 3 | 15816 | none |

Every hit ends in `0`.  For example, depending on the orientation the scan
recovers corners for `000 -> 0000`, `010 -> 0100`, or `10 -> 100`; it never
recovers `a -> a1`.

## Combining both boundary classes still does not branch at one letter

The six pairs contain sixteen distinct values after adjoining stars.  Put all
six packets together and form the support graph on `D` using every value that
already lies in the six-cylinder chart.  Its components remain

```text
{000,010,10},       {001,011,11}.
```

Using these combined support components to bridge endpoints, an exhaustive
one-letter corner scan finds only

```text
000 -> 0000,        010 -> 0100.
```

There is still no complementary child and no two-child base.  Thus merely
putting the two hard boundary classes side by side does not produce the
uniform trace contradiction.

## Consequence for the hyperlinear attack

One proper child equivalence is a unilateral-shift obstruction.  It proves
failure of stable finiteness in an exact coefficient algebra, but it does not
by itself give a dimension-independent normalized Hilbert--Schmidt gap:
finite shift truncations can put the missing complement in vanishing rank.
Two complementary child equivalences would instead give the uniform
Leavitt/Cuntz trace obstruction immediately.

The exact scan therefore supports the following routing decision.

* Do not cite the existing `11`/`30` infinite projection as a hyperlinear
  contradiction.
* Do not spend more time on a one-letter union of the two boundary classes.
* A live finite-multiplicity proof must use a genuinely additional relation:
  a raw compressor or interior word which crosses the missing `1` branch, or
  a quantitative index-to-phase mechanism which prevents the unilateral
  defect from escaping into vanishing rank.

The current endpoint remains the projection-recovery/fiber-identification
gate in `ATLAS_RELATIVE_PERFECTNESS_AND_COEFFICIENT_ENDPOINT.md`.  The
properly infinite packet escapes the germ obstruction because its parent
`p_11` is killed by that quotient.  Recovering `p_11,p_001` in one finite
multiplicity algebra remains the live task.

## Reproduction

Run on a node with the repository's Python dependencies:

```text
python experiments/atlas_hard_pair_two_children.py \
  --max-depth 7 \
  --target-bit 0 --target-bit 1 \
  --all-pairs \
  > experiments/atlas-hard-pair-two-children-depth7.json

python experiments/atlas_hard_pair_two_children.py \
  --max-depth 9 \
  --target-bit 0 --target-bit 1 \
  --pair-index 1 \
  > experiments/atlas-hard-pair-1-depth9.json
```

The computation is exact; floating-point arithmetic and numerical tolerances
are not used.

# A phase-safe toric gap implies a nonhyperlinear group

Status: proved conditional reduction; no toric game satisfying the final gap
hypotheses is presently known.

## 1. Setup

Watts--Helton--Klep associate to a finite nonlocal game a universal game
algebra

```text
U = C[G]
```

and call a game *torically determined* when it is determined by finitely many
relations

```text
h_i - 1,                 h_i = beta_i g_i,
```

where `g_i in G` and `beta_i` is a scalar phase.  Let `B` be the subgroup of
the unit circle generated by the finitely many phases.  This note assumes
`B` is finite, as it is for root-of-unity constraint games.

It is useful to replace scalar notation by the augmented group

```text
Gtilde = B times G
```

and regard each clause as the group element

```text
h_i = (beta_i,g_i) in Gtilde.
```

Put

```text
H = <h_i,h_i^(-1)> <= Gtilde,
N = normal_closure_(Gtilde)(H).
```

Watts--Helton--Klep's Theorem 5.12 says that the game has a perfect
commuting-operator strategy exactly when

```text
H intersect B = {1}.
```

Here `B` means the central copy `B times {1}`.  Their theorem is an exact
subgroup-membership criterion; it does not assert the stronger condition

```text
N intersect B = {1}.
```

Primary source:

- A. B. Watts, J. W. Helton, and I. Klep,
  [Noncommutative Nullstellensaetze and Perfect Games](https://arxiv.org/abs/2111.14928),
  especially Theorem 5.12.

## 2. The phase-safe normal-closure theorem

The stronger condition is exactly enough to groupify a two-player toric gap.

> **Theorem (phase-safe toric groupification).**  Let `Gcal` be a finite
> two-player torically determined game whose phase group `B` is finite.  If
>
> ```text
> N intersect B = {1}
> ```
>
> and
>
> ```text
> omega_qa(Gcal) < 1,
> ```
>
> then the finitely presented group
>
> ```text
> Q = Gtilde/N
> ```
>
> is nonhyperlinear.

The first condition already implies `H intersect B={1}`, so Theorem 5.12
also gives `omega_qc(Gcal)=1`.  Thus the hypotheses describe a perfect
commuting versus finite-dimensional gap whose scalar phase survives normal
groupification.

### Proof

Because `N intersect B={1}`, the central finite group `B` embeds in `Q`.
The group `Q` is finitely presented: a finite game's universal group is
finitely presented, `B` is finite, and `N` is normally generated by the
finite clause list.
Let

```text
chi : B -> T
```

be the defining character that sends the abstract phase `beta` to the same
complex scalar.  In `L(Q)` form its central spectral projection

```text
p_chi = |B|^(-1) sum_(b in B) conjugate(chi(b)) lambda_Q(b).
```

The copy of `B` is central in `Q`, so `p_chi` is central.  Character
orthogonality gives

```text
p_chi^2 = p_chi = p_chi^*,
lambda_Q(b) p_chi = chi(b) p_chi,
tau_Q(p_chi) = 1/|B| > 0.
```

Assume for contradiction that `Q` is hyperlinear.  Then `L(Q)` is Connes
embeddable, and the positive central corner

```text
M = p_chi L(Q)
```

is Connes embeddable with its normalized trace.

Write `q:Gtilde->Q` for the quotient map.  The assignment

```text
rho(g) = p_chi lambda_Q(q(1,g))       (g in G)
```

is a unital star representation of the universal game algebra into `M`.
For every clause `(beta_i,g_i) in N`, its image in `Q` is the identity, so

```text
lambda_Q(q(1,g_i))
    = lambda_Q(q(beta_i,1))^(-1).
```

On the `chi` corner this becomes

```text
beta_i rho(g_i) = p_chi.
```

Thus every determining element `beta_i g_i-1` annihilates the normalized
trace vector of `M`.  The resulting tracial commuting strategy is perfect.

It remains only to record why Connes embeddability puts this two-player
tracial correlation in `C_qa`.  Embed `M` into a tracial matrix ultraproduct
and lift Alice's and Bob's finitely many PVMs to exact matrix PVMs

```text
E_(a,n)^x,    F_(b,n)^y in M_(d_n).
```

On the Hilbert--Schmidt space `M_(d_n)`, use left multiplication for Alice
and right multiplication for Bob:

```text
A_(a,n)^x(X) = E_(a,n)^x X,
B_(b,n)^y(X) = X F_(b,n)^y.
```

These are exact commuting PVMs.  Under
`M_d = C^d tensor conjugate(C^d)` they are an ordinary finite-dimensional
tensor-product strategy.  At the normalized identity vector,

```text
<1, A_(a,n)^x B_(b,n)^y 1>
    = tr_(d_n)(E_(a,n)^x F_(b,n)^y),
```

which converges to the perfect corner-trace correlation.  Hence
`omega_qa(Gcal)=1`, contradicting the assumed gap.  Therefore `Q` is
nonhyperlinear.  QED.

No stability or approximate-representation decoder is used.  The finite
central phase projection turns a hypothetical hyperlinear embedding directly
into a Connes-embeddable perfect trace.

## 3. Normal clauses are a sufficient special case

Suppose the exact clause subgroup itself is normal in `Gtilde`.  Then `N=H`,
so Watts--Helton--Klep's perfectness condition

```text
H intersect B={1}
```

is already the phase-safe normal-closure condition.  Consequently:

> **Corollary (normal toric gap).**  A finite two-player torically determined
> game with finite phase group, normal clause subgroup, and
> `omega_qc=1>omega_qa` gives an explicit finitely presented nonhyperlinear
> group.

This is broader than asking in advance for a linear-system game.  The new
compiler target can be stated as:

```text
one finite two-player toric game
+ perfect commuting completeness
+ uniform finite-dimensional gap
+ phase-safe normal closure.
```

Perfect LCS groupification is one structured way to achieve the last line,
but it is not the only logically possible one.

### A tracial toric model certifies phase survival

There is a second sufficient criterion which is often more natural for
synchronous games.  Suppose there is a tracial state `tau` on a
representation of the full universal game algebra such that every clause
satisfies

```text
||beta_i pi(g_i)-1||_(2,tau)=0.
```

Extend `pi` to `Gtilde=B times G` by making `b in B` act as its defining
complex scalar.  In the trace GNS von Neumann algebra, each clause is then
equal to the identity.  The group kernel of this representation is normal,
so it contains `N`, the normal closure of the clauses.  If `b in N intersect
B`, then

```text
1=pi(b)=chi(b)1.
```

The defining character `chi:B->T` is faithful because `B` is literally a
subgroup of the unit circle.  Hence `b=1`, proving

```text
N intersect B={1}.
```

Consequently:

> **Corollary (tracial toric gap).**  A finite two-player torically
> determined game with finite phase group, a perfect tracial model of its
> full universal game algebra, and `omega_qa<1` yields an explicit finitely
> presented nonhyperlinear group.

This criterion packages the normal-closure calculation into trace-kernel
normality.  It is potentially useful because the known `C_qc` versus `C_qa`
separations can be put in synchronous/tracial form.  The remaining issue is
to make their determining relations toric in the same tracial algebra.

### Synchrony does not supply normality for free

For a synchronous game, perfect strategies can be described by tracial states
on the associated one-player synchronous algebra; see Paddock--Slofstra,
[Satisfiability problems and algebras of boolean constraint system games](https://arxiv.org/abs/2310.07901).
It is tempting to argue that a trace vector fixed by the clauses is fixed by
all their conjugates.  That statement is correct when the clauses themselves
live in the tracial one-player group algebra.

The Watts--Helton--Klep toric clauses, however, live in the full universal
game group containing the commuting player copies.  Passing from a perfect
synchronous strategy to the one-player trace moves the second player's
operators to an opposite algebra.  This preserves the two-player
correlations but reverses word order on that copy.  It does not identify the
normal closure of the original two-player clauses with the trace-kernel ideal
of the synchronous algebra.

Therefore synchrony alone does not prove `N intersect B={1}`.  A compiler
must preserve the clauses in a genuine tracial group quotient, or certify
phase survival separately.

## 4. A toric gap must have an infinite, infinite-index clause subgroup

There are two further exact restrictions on any possible toric gap.

Because `H intersect B={1}`, projection to the game group is injective on
`H`.  Put

```text
K = projection_G(H) <= G.
```

For every `k in K` there is a unique phase `chi_H(k)` such that

```text
(chi_H(k),k) in H.
```

This defines a one-dimensional character `chi_H:K->B`, and `H` is its graph.

### Finite-index clauses

If `[G:K]<infinity`, induce the inverse character from `K` to `G`:

```text
pi = Ind_K^G(conjugate(chi_H)).
```

This is finite dimensional.  Its distinguished coset vector satisfies

```text
beta_i pi(g_i) psi = psi
```

for every clause.  The determining property therefore gives a perfect
finite-dimensional strategy.  Hence a `qc=1>qa` toric gap requires

```text
[G:K]=infinity.
```

### Finite clauses

For a finite game, the universal game group `G` is a finite direct product,
over the players, of free products of finite cyclic groups.  It is residually
finite.  If `H`, equivalently `K`, were finite, residual finiteness would give
a finite quotient

```text
r:G->F
```

that is injective on `K`.  Transfer `chi_H` to `r(K)`, induce that character
to the finite group `F`, and pull the resulting finite-dimensional
representation back to `G`.  Its distinguished vector again satisfies every
clause exactly.  Therefore a toric `qc=1>qa` gap also requires

```text
|H|=|K|=infinity.
```

Combining the two restrictions:

```text
toric qc/qa gap
    => H is infinite
    => projection_G(H) has infinite index in G.
```

This rules out both finite clause packets and finite-coset induced shortcuts.

## 5. Why exact subgroup membership is not enough

The phase-safe hypothesis is genuinely stronger than the exact toric
Nullstellensatz.  Abstractly,

```text
phase notin H
```

does not imply

```text
phase notin normal_closure(H).
```

Here is a finite model.  Let

```text
Ghat = C_2 times A_5,
```

write `b` for the central generator of `C_2`, choose an involution `a in A_5`,
and put `H=<ba>`.  Then `H intersect <b>={1}`.  But `b` lies in the normal
closure of `H`: two distinct conjugates give a nontrivial element

```text
(b a)(b a^x)=a a^x in A_5.
```

The intersection of the normal closure with the simple group `A_5` is then
all of `A_5`; it contains `a`, and hence also `b=(ba)a`.

So normal closure can kill exactly the scalar phase whose subgroup
nonmembership supplied the perfect vector strategy.

## 6. Audited endpoint

The toric route is now sharper than the previous "perfect LCS or nothing"
formulation:

```text
phase-safe toric qc/qa gap
    => explicit finitely presented nonhyperlinear group.
```

The remaining missing object is one finite two-player torically determined
game with

1. finite phase group;
2. `omega_qa<1`;
3. scalar phase surviving the normal closure of its clauses.

For the third item it is enough to provide a perfect trace representation of
the full toric universal group.  A synchronous trace on a different
one-player/opposite-algebra presentation does not automatically qualify.

[MIP*=RE](https://arxiv.org/abs/2001.04383) supplies finite two-player games
whose commuting correlations separate from `C_qa`, but no verified compiler
currently turns one of those games into a torically determined game while
preserving both the perfect gap and phase-safe normal closure.
Watts--Helton--Klep supply the exact subgroup criterion, not that compiler.
The new gain is that full LCS syntax is not logically necessary: normal toric
syntax, or merely a phase-safe normal-closure certificate, is enough.

This is consistent with the current LCS frontier: Taller--Vidick's
[RE-hardness theorem for LCS games](https://arxiv.org/abs/2507.22444) has
completeness `1-epsilon`, and they explicitly note that reaching perfect
completeness would imply a nonhyperlinear group.

### 41.1 Section 1, Theorem A and Corollary A.1

- **Honest idempotents.**
  - `eps_-^2 = 4(2 - 2[z]) = 8(1 - [z]) = eps_-`. The same computation gives `P_d^2 = P_d`, and `[d] P_d = -P_d`.
  - `d1^2 = 1 + 3 s1 t1 = 1` and `pi(P1) = -2 p1 = p1`.
  - `[d0] = -[d1]` in `S_-`, so `P0 + P1 = 4 = 1`, `P0 P1 = 4(1 - [d1]^2) = 0` and `pi(P0) = 2(2 + p1) = p0`.
- **Theorem A(1).** `v = P'vP'` gives `vP = 0`.
  - `c'P = P + vP - PhvP = P`, and `c'hP' = PhP' + P' - PhP' = P'`.
  - So `c'b = 1` with `b = P + hP'`, and `a = u0 b` gives `(c' u0^(-1)) a = 1`.
- **Theorem A(2).** `C = c u0` has `Cb = 1`.
  - Multiplying by `P` and by `P'` on the right gives `CP = P` and `ChP' = P'`.
  - So `P'CP = 0` and `P' = P'C(P + P')hP' = (P'CP') hP'`.
  - Both directions are identities in any unital ring, as the route says.
- **Corollary A.1.**
  - `pi(a) = u0 p0 + u1 p1 = s00 t0 + s01 t1 = s0`, which is not invertible, so a left inverse `c` has `ac != 1`.
  - Then `1 - ac != 0` gives `J_1(S_-) != 0`.
  - With `P0 = -(1 + [d1])` and `P1 = -(1 - [d1])`, `a = -[u0] - [u0 d1] - [u1] + [u1 d1]`.

### 41.2 Proposition B, Construction C and Proposition D

- **Proposition B.**

- **Construction C.**

  - `h s1 = s0 + s10` and `u0 s10 = s01 - s00`, so `u1 s1 = s01`.

### 41.3 Proposition E and its corollaries

- **Ring map.** `rho(z) = (-1)^3 = -1`, so `rho(eps_-) = 2 . 2 = 1`, and `rho` is unital on `eps_- F_3[H]`.
- **Odd part.** `psi0*(d1) = psi0(d1)^T` acts on `V+*` and `V-*` by `+1` and `-1`. So `rho(d1)` acts on `W_(abc)` by
  `abc`, and `rho(P1) = 2(1 - rho(d1))` is `0` on even blocks and `4 = 1` on odd blocks.
- **Compression.** `v = P1 v P1` and `v Y_h = P1` give `rho_O(v) rho_O(h) = 1_O`, so `rho_O(h)` is onto.
- **Missing block.**
  - `g V+ = V-` kills the block `V+ -> V+` of `g`.
  - `g^(-1) V- = V+`, so for `f in V-*` the `V-*`-component `f o g^(-1) o pi-` of `psi0*(h) f` vanishes.
  - Into `W_(++-)`, the blocks from `(++-)` and `(+-+)` have first factor `0`, the block from `(-++)` has second
    factor `0`, and the block from `(---)` has third factor `0`.
  - `g : V+ -> V-` is bijective and `V != 0`, so `dim V+ = dim V- >= 1`, and `W_(++-) != 0`.
- **Why a tensor cube.**
  - `psi0` sends `Y_h` to the `V- -> V-` block of `g`. For `GL_2(phi)` this is `phi(s0)`, invertible under `s0 -> 1`.
  - The one-sided-inverse argument of `swap-separated-pairs-avoid-finitely-represented-supports` gives only
    bijectivity of `rho_O(h)`. The contradiction comes from the block computation.
- **Corollary E.1.**
  - `t0 d1 s0 = 1`, `t1 d1 s1 = 2 = -1`, and the off-diagonal entries vanish, so `d1 = diag(1,-1)`.
  - The entries of `h` and `h^(-1)` lie in `{0, ±1, s0}`.
  - `psi0(h) = [[0,I],[-I,phi(s0)]]` sends `(x, 0)` to `(0, -x)`.
- **Instances.**
  - `F_3[s0]` and `F_3<s0,s1>` are polynomial and free: distinct words in the `s_i` are distinct normal-form
    monomials.
  - In `T = F_3<s0,t0>`, the monomials `s0^a t0^b` are independent and multiply through `t0 s0 = 1`, so
    `s0, t0 -> 1` is well defined.
  - `F_3<s0,t0,t1>`:
    - the monomials `s0^a t_nu` have no `s1 t1` junction, so they are independent;
    - they are closed under multiplication through `t0 s0 = 1` and `t1 s0 = 0`;
    - so `s0, t0 -> 1`, `t1 -> 0` is well defined.
- **Corollary E.2.**
  - `h s0 = -s1` and `h^(-1) s1 = -s0`, so the displayed chart entries vanish.
  - `d1` is diagonal in the `C`-chart, with sign `-1` on words beginning with `1`.
  - `psi0(h) V+ ⊆ V-` and `psi0(h)^(-1) V- ⊆ V+`, so `psi0(h) V+ = V-`.
- **What escapes.**
  - In a finite-dimensional representation, `t1 s1 = 1` makes `s1` invertible, `t0 s1 = 0` then gives `t0 = 0`,
    and that contradicts `t0 s0 = 1`.
  - `g0 = [[s0, s1 t0],[0, t1]]`, and `[[t0,0],[s0 t1, s1]]` inverts it on both sides, using `t0 s1 = t1 s0 = 0`.
- **Claim D.3 follows from Proposition E.**
  - If `w = Y_k Y_h - P1` were nilpotent, `(P1 + w)^(-1) Y_k` would be a left inverse of `Y_h` supported in
    `GL_2(T)`.
  - I did not re-derive the trace display `tr rho(w) = -1`.

## 0. Summary

**Notation.**
- `R = L_(F_3)(1,2)`, `G_3 = R^x`, `z = −1`, `x = 1 + s_00 t_01`, and `G_3 = ⟨V, x⟩`
  (`leavitt-prime-field-units-generated-by-v-and-one-transvection`). Write `p_α = s_α t_α`.
- `E` is the signed diagonal, generated by the reflections `τ_α = 1 − 2 p_α = 1 + p_α`, and `H = E ⋊ V`.
  `ev : F_3[H] -> R` is the evaluation `[g] -> g`.
- For a Sylvester matrix rank function `rk` on an algebra containing `[z]`, put `e_± = (1 ± [z])/2` and
  `β = rk(e_−) = rk(1 − [z])`. The target asks for `β > 0` on `F_3[G_3]`.
- For a clopen `c`, `P_c^± = (1 ± [τ_c])/2 ∈ F_3[E]`. In characteristic three `P_c^− = [τ_c] − 1`.
  For a complete prefix code `C` and signs `ε ∈ {±}^C`, `q_ε = ∏_(c ∈ C) P_c^(ε_c)`.

**Results.**
1. **Reduction** (Section 1). The target holds iff link 1
   (`sylvester-rank-functions-on-ternary-leavitt-units-kill-minus-one`) and the V gate
   (`thompson-v-ternary-rank-functions-are-augmentation`) have the same truth value. It fails iff link 1 holds
   and `F_3[V]` has a detecting rank function. No Hamming-model version of the extension exists for any `V`,
   and averaging from `V` is unavailable.
2. **The evaluation lift dies at order three** (Section 2.2). `X_ev = 1 + ([τ_00] − 1)[w]` has `ev(X_ev) = x`
   and `rk(X_ev^3 − 1) >= β/4` for every rank function on `F_3[H]`.
3. **The Fock lift passes the local relations and dies at splitting** (Sections 2.3–2.4).
   `X_F = 1 + [w] P_00^+ P_01^−` is a unit of order three in `F_3[H]` with `ev(X_F) = x`. It satisfies the sign
   relations `τ_00 x τ_00 = x^(−1) = τ_01 x τ_01` and the support and centralizer relations exactly. It fails the
   splitting relation `x = x_0 x_1`, `x_i = 1 + s_(00i) t_(01i)`, with defect at least `β/16` in every rank
   function on `F_3[H]`.
4. **Reading** (Section 2.5). In every z-moving completion the parities of disjoint cylinders are independent,
   while `ev` sees orthogonal cylinder idempotents. The order relation exposes this at one depth. Conditioning on
   parity patterns repairs one depth and moves the conflict to the depth-changing relation `x = x_0 x_1`.

Sections 3–5 (unipotent classes, the functorial Fock action, the obstructing relation) land separately.

## 1. Reduction

### 1.1 Logical position

- **Known direction.** A rank function on `F_3[G_3]` with `β > 0` restricts to `F_3[H]` with `β > 0`. Its
  restriction to `F_3[V]` is not the augmentation (`signed-thompson-z-moving-rank-functions-match-v-rank-functions`,
  (1) ⟹ (2)), hence detecting (`simple-group-rank-functions-are-augmentation-or-detecting`).
- **Truth table.** Link 1 says no rank function on `F_3[G_3]` has `β > 0`. By the dichotomy, the V gate says no
  rank function on `F_3[V]` is detecting. The known direction is "V gate ⟹ link 1"; the target is
  "link 1 ⟹ V gate". So the target is equivalent to "link 1 ⟺ V gate".
- **Consequences.**
  - The target fails exactly when link 1 holds and `F_3[V]` has a detecting rank function. An unconditional
    refutation would therefore prove link 1 and give `V` a detecting ternary rank function.
  - If the V gate holds, the target holds vacuously. An unconditional proof must construct `β > 0` on
    `F_3[G_3]` from an arbitrary detecting function on `F_3[V]`.
  - Target plus link 1 gives the V gate, which makes `V` nonsofic (Consequences of the transfer node).

### 1.2 No Hamming-model extension, for any V

The normal subgroups of `G_3` are `1`, `⟨z⟩` and `G_3`: `PG_3` is simple and `G_3` is perfect. Let `ρ` be a
homomorphism from `G_3` into a metric ultraproduct of finite symmetric groups. If `ker ρ = 1`, `G_3` is sofic,
against `d-ary-leavitt-groups-nonsofic-over-finite-fields` (`k = F_3`, `d = 2`). If `ker ρ = ⟨z⟩`, `PG_3` is
sofic, against `projective-leavitt-unit-groups-mod-scalars-are-nonsofic`. So `ρ` is trivial.

Hence no nontrivial Hamming model of `V` extends to `G_3`, whether or not `V` is sofic. An extension in the
target must give `x` genuinely linear data, not a permutation profile. This is the Hamming form of Attempt 2 on
the target node.

### 1.3 No averaging from V

Inducing or averaging a rank function over `G_3/V` needs `V` co-amenable in `G_3`. `G_3` has property (T)
(`leavitt-gl-equals-el-and-perfect-unit-group`), and a co-amenable subgroup of a Kazhdan group has finite index.
But `[G_3 : V]` is infinite: `GL_(2^n)(F_3) <= G_3` meets `V` in `S_(2^n)`, and `[GL_(2^n)(F_3) : S_(2^n)]` is
unbounded.

## 2. Lifts of x into F_3[H]

A *lift* of `x` is an `X ∈ F_3[H]` with `ev(X) = x`. If an extension `σ` of a rank function sent `x` to an
element rank-equal to a lift `X`, then `X` would satisfy every relation of `G_3` in rank. Sections 2.2–2.4 test
the two natural lifts.

### 2.1 Haar values

**Lemma 2.1.** Let `rk` be a Sylvester matrix rank function on `F_3[H]` with `β = rk(e_−)`. Let `C` be a complete
prefix code with `n` cells and `ε ∈ {±}^C` with an odd number of minus signs. Then `rk(q_ε) >= β 2^(1−n)`.

*Proof.* `e_−` is central and `[z] e_− = −e_−`. Put `r(a) = rk(a e_−) <= rk(a)`. On idempotents, `r` is additive
on orthogonal families and invariant under conjugation by units, with `r(e_−) = β`. This is the setting of
`anti-central-rank-models-see-haar-measure-on-signed-diagonal` (its Scope), which gives `r(q_ε) = β 2^(1−n)`.
The argument, for completeness:
- **Even patterns vanish.** `C` partitions the Cantor set, so `∏_(c ∈ C) [τ_c] = [z]` and
  `q_ε [z] = (∏ ε_c) q_ε`. Multiplying by `e_−` gives `(∏ ε_c + 1) q_ε e_− = 0`, so `q_ε e_− = 0` when
  `∏ ε_c = +1`.
- **Invariance.** Any bijection between complete prefix codes of equal size is realized by some `v ∈ V` acting by
  prefix replacement, and `[v][τ_c][v]^(−1) = [τ_(v(c))]`. So `r(q_ε) = r_n(k)` depends only on `n` and the number
  `k` of minus signs.
- **Refinement.** `[τ_c] = [τ_(c0)][τ_(c1)]` gives `P_c^− = P_(c0)^+ P_(c1)^− + P_(c0)^− P_(c1)^+` and
  `P_c^+ = P_(c0)^+ P_(c1)^+ + P_(c0)^− P_(c1)^−`. Splitting a minus cell gives `r_n(k) = 2 r_(n+1)(k)` for odd
  `k <= n`. Splitting the plus cell of a pattern with `n − 1` minus signs gives
  `r_n(n−1) = r_(n+1)(n−1) + r_(n+1)(n+1)`.
- **Induction.** `r_1(1) = r(P_X^−) = r(e_−) = β`, so `r_n(k) = β 2^(1−n)` for all odd `k`. ∎

### 2.2 The evaluation lift

Let `w ∈ V` exchange `00a <-> 01a` and fix `1`. In `R`, `p_00 w = s_00 t_01`, and
`ev(P_00^−) = τ_00 − 1 = p_00`. So `X_ev := 1 + P_00^− [w]` is a lift of `x`.

**Proposition 2.2.** `X_ev^3 = 1 + P_00^− P_01^− [w]`. Hence `rk(X_ev^3 − 1) = rk(P_00^− P_01^−) >= β/4`.

*Proof.* Put `N = P_00^− [w]`. Since `w = w^(−1)` and `w τ_00 w = τ_01`, `[w] P_00^− [w] = P_01^−`. So
`N^2 = P_00^− P_01^−` and `N^3 = P_00^− P_01^− P_00^− [w] = P_00^− P_01^− [w]`, as `F_3[E]` is commutative.
In characteristic three `(1 + N)^3 = 1 + N^3`. `[w]` is a unit, and on the code `{00, 01, 1}`,
`P_00^− P_01^− = q_(−,−,+) + q_(−,−,−)`. Lemma 2.1 gives `rk >= rk(q_(−,−,−)) >= β/4`. ∎

**Where it dies.** In `R`, `ev(N^2) = p_00 w p_00 w = p_00 p_01 = 0`: disjoint cylinders carry orthogonal
idempotents. In every z-moving completion the parities of `00` and `01` are independent (Lemma 2.1), and
"both minus" has rank at least `β/4`. The order relation `x^3 = 1` sees the conflict.

### 2.3 The Fock lift

Put `e_(+−) = P_00^+ P_01^−`, `N_F = [w] e_(+−)` and `X_F = 1 + N_F`.

**Proposition 2.3.** In `F_3[H]`:
- **(a)** `ev(X_F) = x`.
- **(b)** `N_F^2 = 0`, so `X_F` is a unit of order three with `X_F^(−1) = 1 − N_F`.
- **(c)** `[τ_00] X_F [τ_00] = X_F^(−1) = [τ_01] X_F [τ_01]`, matching `τ_00 x τ_00 = x^(−1) = τ_01 x τ_01` in `R`.
- **(d)** `X_F` commutes with `[τ_c]` whenever `c ∩ (00 ∪ 01) = ∅` or `c ⊇ 00 ∪ 01`. It also commutes with `[v]`
  for every `v ∈ V` with `v(00a) = 00u(a)` and `v(01a) = 01u(a)` for one `u` (arbitrary on `1`). In `R`, `x`
  commutes with the same elements.

*Proof.*
- **(a)** `ev(P_00^+) = −(1 + τ_00) = 1 − p_00` and `ev(P_01^−) = p_01`, so `ev(e_(+−)) = p_01` and
  `ev(N_F) = w p_01 = s_00 t_01`.
- **(b)** `e_(+−) [w] = [w] e_(−+)` with `e_(−+) = P_00^− P_01^+`. So `N_F^2 = [w]^2 e_(−+) e_(+−) = 0`, and
  `(1 + N_F)(1 − N_F) = 1`, `(1 + N_F)^3 = 1 + 3 N_F = 1`.
- **(c)** `[τ_00][w] = [w][τ_01]`, `[τ_01] e_(+−) = −e_(+−)` and `e_(+−) [τ_00] = e_(+−)`, so
  `[τ_00] N_F [τ_00] = −N_F`. Symmetrically `[τ_01][w] = [w][τ_00]` and `[τ_00] e_(+−) [τ_01] = −e_(+−)`. In `R`,
  `(1 + p_00) s_00 t_01 (1 + p_00) = 2 s_00 t_01 = −s_00 t_01`, and likewise for `τ_01`.
- **(d)** These `[τ_c]` and `[v]` commute with `[w]` and fix `[τ_00]`, `[τ_01]` under conjugation. In `R`,
  `p_c s_00 t_01 p_c` is `s_00 t_01` or `0` with `p_c s_00 t_01 = s_00 t_01 p_c`. For `v`,
  `v s_00 = s_00 ū` and `t_01 v^(−1) = ū^(−1) t_01` with `ū = t_00 v s_00 ∈ V`. ∎

### 2.4 Splitting

For `i ∈ {0, 1}` choose `v_i ∈ V` with `v_i(00a) = 00ia` and `v_i(01a) = 01ia`. In `R`,
`x_i := v_i x v_i^(−1) = 1 + s_(00i) t_(01i)`, `x_0 x_1 = x_1 x_0`, and

```text
x = x_0 x_1     (splitting)
```

because `s_000 t_010 + s_001 t_011 = s_00 (s_0 t_0 + s_1 t_1) t_01` and the cross terms vanish. An extension `σ` of
a rank function on `F_3[V]` must send `x_i` to `σ(v_i) σ(x) σ(v_i)^(−1)`. So a lift `X` forces
`X_i = [v_i] X [v_i]^(−1)` and must satisfy `X = X_0 X_1` in rank.

For `X_F`, `X_i = 1 + [w_i] f_i`, where `w_i = v_i w v_i^(−1)` exchanges `00ia <-> 01ia` and fixes the rest, and
`f_i = P_(00i)^+ P_(01i)^−`. Neither depends on the choice of `v_i`.

**Proposition 2.4.** `D := X_F − X_0 X_1` lies in `ker(ev)`, and `rk(D) >= β/16` for every Sylvester matrix rank
function on `F_3[H]`.

*Proof.* `ev(D) = x − x_0 x_1 = 0`. `w_1` fixes `000` and `010` pointwise, so `f_0 [w_1] = [w_1] f_0`, and
`w_0 w_1 = w`. Hence

```text
X_0 X_1 = 1 + [w_0] f_0 + [w_1] f_1 + [w] f_0 f_1,
D       = [w] (e_(+−) − f_0 f_1) − [w_0] f_0 − [w_1] f_1.
```

Let `g = P_000^+ P_001^− P_010^− P_011^+`. Since `[τ_00] = [τ_000][τ_001]` acts on `g` by `−1`, `e_(+−) g = 0`. The
factor `P_001^−` gives `f_1 g = 0`, and `f_0 g = g`. So `D g = −[w_0] g`, and

```text
rk(D) >= rk(D g) = rk(g) >= rk(q_(+,−,−,+,−)) >= β/16
```

by Lemma 2.1 on the code `{000, 001, 010, 011, 1}`. ∎

### 2.5 Reading

- **Two lifts of one particle.** Both lifts turn the one-particle operator `s_00 t_01` into parity data. `X_ev`
  uses the minus projection of `00` alone, and the independence of disjoint parities breaks the order relation.
  `X_F` conditions on the pattern `(+, −)` and moves the whole subtree `01` onto `00`. That is one fermionic mode
  per cylinder: exact at one depth, sign-covariant, of order three.
- **Why splitting.** Splitting refines `00 = 000 ∪ 001`. The parity of `00` is a product of two independent
  parities, and "move one mode" is not a monomial move of whole subtrees at the finer depth. The defect `β/16`
  is carried by the pattern `(+, −, −, +)`, where the coarse lift does nothing and the fine lift moves `010`
  onto `000`.
- **What is tested.** Among the relations of `⟨V, x⟩`, monomial lifts die at the order relation (`X_ev`) and at
  the depth-changing relation `x = x_0 x_1` (`X_F`). `X_F` satisfies the sign, support and centralizer relations
  exactly.
- **Not claimed.** That every lift fails, or that `σ(x)` must be rank-equal to an element of `F_3[H]`. An
  extension may send `x` outside the closure of `F_3[H]`, as the functorial Fock action does (Section 4).

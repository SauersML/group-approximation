**Derivation** (artifact Section 1).

1. **Kernel.**
   - `π(S^a T^b) = z^(a-b)`, so the kernel of `J_F -> F[z,z^(-1)]` is spanned by the `E_kl = S^k Q T^l`, `Q = 1 - ST`.
   - `QS = 0` and `TQ = 0` give `E_kl E_mp = δ_lm E_kp`. So the kernel is `M_fin(N, F)`, and
     `L_n <= GL_fin(N x {1,...,n}, F)`.
2. **Linear quotient.**
   - `H/(H ∩ L_n) = π(H) <= SL_n(F[z,z^(-1)])`.
   - This is residually finite through the finite rings `F[z]/(z^N - 1)`.
   - This gives items 1–3 and excludes finitely generated infinite simple subgroups.
3. **Simple sections.** Suppose `H/M` is infinite simple with `M` locally finite.
   - Then `H ∩ L_n <= M` and `π(H)/π(M) = H/M`.
   - Torsion in `GL_n(F[z,z^(-1)])` has bounded exponent. The characteristic coefficients lie in `F`, so eigenvalues
     lie in `F_(|F|^k)` with `k <= n`, and unipotent parts have order `<= p^r`.
   - So the Zariski closure `𝐌` of `π(M)` has unipotent identity component.
   - If `π(H) <= 𝐌`, then `H/M` is virtually nilpotent.
   - Otherwise `π(H) ∩ 𝐌 = π(M)`, and `H/M` embeds in the linear group `N(𝐌)/𝐌`, so it is residually finite.
   - Either case contradicts simplicity.
4. **Examples.**
   - `V` and `T` are finitely generated infinite simple (`thompson-v-finitely-presented-infinite-simple` for `V`).
     So is `R^x` (`binary-leavitt-unit-group-is-simple`).
   - `EL_3(C_2)` maps onto `EL_3(L_(F_2)(1,2)) = R^x` (`leavitt-gl-equals-el-and-perfect-unit-group`). Its kernel lies
     in `1 + M_3(I)`, where `I` is the ideal generated by `1 - s_0 t_0 - s_1 t_1`. `I` is spanned by matrix units, so
     the kernel is locally finite.
   - Torsion-free groups have no nontrivial locally finite normal subgroup.
5. **Monolith.** `C_E(L) = 1`, by the argument of `binary-jacobson-self-centralizing-kernel-proof` in rank three.
   Since `L` is simple, every nontrivial normal subgroup contains `L`.


## 3. Where the Toeplitz relation is load-bearing

Write `J = F_2<s0, t0> ⊂ R` for the subalgebra generated by `s0` and `t0`. It is a copy of the Jacobson algebra
`F_2<S, T | TS = 1>` (the embedding `J -> R` is recorded with `cohn-elementary-group-rank-radical-is-trivial-or-everything`).
Write `R_0 = ∪_j M_(2^j)(F_2)` for the degree-zero subalgebra; the root groups `x_ij(R_0)` are constant units.

**Theorem 3.1** (`toeplitz-pair-and-weyl-elements-generate-jacobson-el3`).
- (a) `<x_12(t0), x_23(s0), EL_3(F_2)> = EL_3(J)`.
- (b) `<x_12(t0), x_23(s0), x_ij(R_0) : i != j> = EL_3(R) = R^x`.
- The same holds over `F_3`, with `J_3 = F_3<s0, t0>`, `EL_3(F_3)` in (a), and `G = L_(F_3)(1,2)^x` in (b).

*Proof.*
1. **One coefficient set.** Let `G'` be the generated group and `C_ij = {r : x_ij(r) in G'}`.
   - Each `C_ij` is an additive subgroup, because `x_ij(a) x_ij(b) = x_ij(a+b)`.
   - Signed permutation matrices lie in `EL_3` of the prime field, and `pi x_ij(r) pi^(-1) = x_(pi(i) pi(j))(± r)`.
   - So all `C_ij` equal one set `C`.
2. **`C` is an algebra.** For distinct `i, j, k`, `[x_ij(a), x_jk(b)] = x_ik(ab)`, so `C` is closed under products.
3. **(a).** `C` contains `1`, `t0` and `s0`, so it contains `J`. Hence `G' ⊇ EL_3(J)`, and the generators lie in `EL_3(J)`.
4. **(b).** `C` also contains `R_0 ∋ p = s0 t1 + s1 t0`, and `p s0 = s1`, `t0 p = t1`. So `C` contains `s0, s1, t0, t1`,
   which generate `R`. So `G' = EL_3(R)`, and `EL_3(R) = R^x` (`leavitt-gl-equals-el-and-perfect-unit-group`). ∎

**Corollary 3.2 (the load-bearing configuration).**
- **The frames.** For disjoint cylinders `A` and `B`, the frames `iota_A(EL_3(J))` and `iota_B(EL_3(J))` commute and meet
  trivially. Their product contains `D_A`, `D_B`, both Toeplitz commutators and the constant Weyl elements at `A` and `B`,
  and it is sofic iff `EL_3(J)` is sofic.
- **If `EL_3(J)` is sofic.** Theorem 2.1 then gives a free rank model of that product with `rk(D_A D_B) = (3/8)^2`. It has
  no fixed vector, since `EL_3(J)` contains elements of infinite order such as `x_12(s0) x_21(1)`
  (`leavitt-right-child-frames-generate-infinite-order-units`).
- **So** a relation-only strict deficit from Toeplitz and constant-Weyl data at two disjoint cylinders would prove
  `EL_3(J)` nonsofic.
- **Status of `EL_3(J)`.** The symbol map `EL_3(J) -> EL_3(F_2[z, z^(-1)])` has locally finite kernel
  (`jacobson-amenable-symbol-subgroups-are-amenable`), and its image is finitely generated and linear, hence residually
  finite. No permanence result on main covers extensions with an amenable kernel and a residually finite quotient, so
  the soficity of `EL_3(J)` is undecided here. Literature not checked.
- **With the level constants.** By Theorem 3.1(b) the Toeplitz pair and the constant root groups generate all of `R^x`.
  So the correction that nontrivial models must make to the truncated compressors
  (`rank-models-are-exact-representations-at-moving-finite-levels`) involves every relation of `R^x`. It isolates no
  smaller certificate.

**Remark 3.3 (characteristic three).**
- **Covered by the anti-central firewall.** Over `F_3`, `x_12(t0)` has order 3 and `<x_12(t0), x_23(s0)>` is the
  Heisenberg group of order 27. Together with `z` it is a finite subgroup containing `z`, so it is covered by
  `anti-central-sofic-data-cannot-force-defect-submultiplicativity`.
- **Where it can bite.** The Toeplitz relation is load-bearing only inside `<iota_A(EL_3(J_3)), iota_B(EL_3(J_3)), z>`,
  which is sofic iff `EL_3(J_3)` is.
- **Not computed:** the compression of item 2 of `ternary-anti-central-disjoint-defects-have-a-strict-deficit` on the
  independent anti-central profile.

## 4. Where it stops

- **No deficit from the Toeplitz relation alone.** The relation is finite-subgroup data, and the sofic firewall covers
  every configuration whose generated subgroup is known to be sofic.
- **Moving levels.**
  - In the normal form `rank-models-are-exact-representations-at-moving-finite-levels`, the compressor corrections
    commute with each fixed level group, in both orders (checked in Section 55 of
    `research/artifacts/gk-vf-linear-verification-2026-09-12.md`).
  - `D_A D_B` lies in the level algebra. So a correction never enters the defect product as a factor.
  - Any effect of the Toeplitz relation on `rk(D_A D_B)` passes through the choice of level representations, that is,
    through how successive levels intertwine along the compressors. No mechanism forcing a deficit was found.
- **Open inputs a proof could use:**
  - a certificate that `EL_3(J)` (or `EL_3(J_3)`) is nonsofic, used through relations at two disjoint frames;
  - or the global inputs (defect gap, near-minimal independence) combined with relations of a nonsofic subgroup
    containing both frames.

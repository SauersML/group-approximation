## 0. Setting and inputs

- `X = {0,1}^N`, with `V` acting by prefix replacement. Clopen `q`-cycles and clopen-cycle subgroups are as in [TS].
- `F` is any field and `rk` a Sylvester matrix rank function on `F[V]` with `rk(1) = 1`. Ranks are not normalized by
  matrix size. `phi(Y) = 1 - rk col(Y)` for a finite list `Y`, and `phi_V = phi(1 - [s] : s in S)` for a finite
  generating set `S`.
- For a finite group `G` and a matrix `M = sum_x M_x [x]` over `F[G]`, with `M_x` scalar:
  - `rk_aug(M) = rank(eps(M))`, where `eps(M) = sum_x M_x`;
  - `rk_reg(M) = rank(lambda(M))/|G|`, where `lambda(M) = sum_x M_x ⊗ lambda(x)` and `lambda(x)` is the permutation
    matrix of left multiplication by `x` on `G`.
- **Inputs.**
  - **(T)** [TS] Theorem 1.3, valid for abstract rank functions by [FR] Section 3.1. Let `q != char F` be an odd prime,
    `F' = F(mu_q)`, and `rk'` the scalar extension of [FR] Section 0. Then there is `a_q` with
    `rk'(e_chi) = a_q [chi = 1] + (1 - a_q)/|P|` for every clopen-cycle subgroup `P` of exponent `q` and every
    character `chi` of `P`.
  - **(Phi)** `v-rank-torsion-constant-equals-global-fixed-rank`: `a_q = phi_V`.
  - **(CP)** `finite-subgroups-of-thompson-v-permute-a-canonical-partition`. A finite `G <= V` permutes the pieces of
    a finite cylinder partition `P_G` by prefix replacements. If `gQ = Q`, then `g` is the identity on `Q`.
- **Sylvester facts**, beyond the axioms (including block additivity `rk diag(A, B) = rk(A) + rk(B)`) and (S1)–(S6)
  of [FR] Section 0:
  - **(S7)** If an idempotent `e` commutes with every entry of a rectangular matrix `M`, then
    `rk(M) = rk(Me) + rk(M(1 - e))`.
    *Proof.* Put `U_k = [[e I_k, (1 - e) I_k], [(1 - e) I_k, e I_k]]`, so `U_k^2 = 1`. Then
    `U_m diag(M, 0) U_n = diag(Me, M(1 - e))`. Conclude by (S1) and block additivity. ∎
  - **(S8)** If every element of `Y` lies in the left ideal generated by `Y'`, then `phi(Y) >= phi(Y')`, by (S5) and
    deleting rows. So `phi(Y) >= phi_V` for every list `Y` in the left augmentation ideal of `F'[V]`.
  - **(S9) Matrix units.** Let `E_(g,h)`, for `g, h` in a finite set `I`, satisfy
    `E_(g,h) E_(k,l) = delta_(h,k) E_(g,l)`, and put `E = sum_g E_(g,g)`. For a scalar matrix `x` indexed by
    `{1..n} x I`, let `x(E) = (sum_(g,h) x_((i,g),(j,h)) E_(g,h))_(i,j)`. Then `rk'(x(E)) = rank(x) rk'(E)/|I|`.
    *Proof.*
    - `x -> x(E)` is multiplicative, and `u(E) + (1 - E) I_n` is a unit when `u` is invertible.
    - Write `x = u d v` with `d = diag(1^r, 0)`. Then `x(E) = (u(E) + 1 - E) d(E) (v(E) + 1 - E)`, and `d(E)` is
      diagonal with `r` of the `E_(g,g)` in total on its diagonal.
    - `E_(g,g) = E_(g,h) E_(h,h) E_(h,g)`, so all the `rk'(E_(g,g))` are equal, each `rk'(E)/|I|`.
    - Conclude by (S1), block additivity and (S3). ∎

## 1. A second derivation of [CG] Theorem 1.1

**Theorem 1.1** ([CG] Theorem 1.1). Let `G <= V` be finite. For every matrix `M` over `F[G]`,
`rk(M) = phi_V rk_aug(M) + (1 - phi_V) rk_reg(M)`.

*Proof.* Fix an odd prime `q != char F`, put `a = a_q = phi_V`, let `n` be the size of `M`, and let `k >= 1`.
- **Step 0: a q-group that G permutes.** Let `P = P_G`.
  - In one piece `Q` of each `G`-orbit on `P`, choose `k` clopen `q`-cycles with disjoint supports in a proper clopen
    subset of `Q`. They generate `T_Q ≅ (Z/q)^k`.
  - For `Q' = gQ`, put `T_(Q') = g T_Q g^(-1)`. This is well defined, since the stabilizer of `Q` is the identity on
    `Q`.
  - `B = prod_(Q in P) T_Q ≅ (Z/q)^(k|P|)` is a clopen-cycle subgroup, since a product of nonzero powers of disjoint
    clopen `q`-cycles is a clopen `q`-cycle.
  - `G` normalizes `B` and permutes its factors the way it permutes `P`.
- **Step 1: characters.** For `psi` in `B^`, put `e_psi = |B|^(-1) sum_b psi(b)^(-1) [b]`.
  - By (T), `rk'(e_psi) = a [psi = 1] + (1 - a)/|B|`, and `[g] e_psi [g]^(-1) = e_(g psi)`.
  - Let `Omega_fix` be the characters with nontrivial stabilizer in `G`. For a `G`-orbit `O` outside it, put
    `E_O = sum_(psi in O) e_psi`, and let `D = sum_(psi in Omega_fix, psi != 1) e_psi`.
  - These and `e_1` are orthogonal idempotents with sum `1`, commuting with `F'[B]` and `F'[G]`. By (S7),
    `rk'(M) = sum_O rk'(M E_O) + rk'(M D) + rk'(M e_1)`.
- **Step 2: free orbits.** Fix `psi` in `O` and put `E_(g,h) = [g h^(-1)] e_(h psi) = e_(g psi) [g h^(-1)]`.
  - Since `e_(h psi) [k l^(-1)] = [k l^(-1)] e_(l k^(-1) h psi)` and `O` is free,
    `E_(g,h) E_(k,l) = delta_(h,k) E_(g,l)`. Also `sum_g E_(g,g) = E_O`.
  - `[x] E_O = sum_h E_(xh,h)`, which is `lambda(x)(E)`. So `M E_O = lambda(M)(E)`, and (S9) gives
    `rk'(M E_O) = rk'(E_O) rk_reg(M)`.
- **Step 3: fixed characters.** Let `h != 1`. Then `hQ != Q` for some piece `Q`, and a character fixed by `h` has its
  `T_(hQ)` component determined by its `T_Q` component. So `|Omega_fix| <= |G| |B| q^(-k)`, and
  `rk'(M D) <= n rk'(D) <= n |G| (1 - a) q^(-k)`.
- **Step 4: the trivial character.** Let `x` be in `G`.
  - `1 - e_1 = |B|^(-1) sum_b (1 - [b])` and `1 - [x]` lie in the augmentation ideal, so
    `phi(1 - e_1, 1 - [x]) >= a` by (S8).
  - By (S7) with `e = e_1`, then (S5), `rk' col(1 - e_1, 1 - [x]) = rk'((1 - [x]) e_1) + rk'(1 - e_1)`.
  - So `rk'((1 - [x]) e_1) <= rk'(e_1) - a = (1 - a)/|B|`.
  - Since `M e_1 = eps(M) e_1 - sum_x M_x (1 - [x]) e_1`, (S2) puts `rk'(M e_1)` within `n |G| (1 - a)/|B|` of
    `rank(eps(M)) rk'(e_1)`.
- **Step 5: assembly.** `sum_O rk'(E_O) = 1 - rk'(D) - rk'(e_1)`, which is within `(|G| + 1)(1 - a) q^(-k)` of `1 - a`.
  So `|rk(M) - (1 - a) rk_reg(M) - a rk_aug(M)| <= 3n(|G| + 1)(1 - a) q^(-k)` for every `k`, and the left side is 0. ∎

**Remark 1.2 (differences from [CG] Section 1).**
- **Parameters.** [CG] places one `q`-cycle per cylinder and lets `q -> infinity`. Here `q` is fixed and the number
  `k` of cycles per piece grows.
- **Free orbits.** [CG] Step 4 uses the equivalence `f_O ~ I_|G| ⊗ e_chi`. Here the corner is presented by matrix
  units, and (S9) computes its rank.
- **Trivial character.** [CG] Step 3 bounds the column `col(e(1 - [g]) : g in G)`. Here Step 4 handles one `g` at a
  time.
- **Inputs.** They are the same: (T), (Phi) and (CP). So this is a cross-check, not a verification.

## 2. Endomorphism-invariant models on p-cycle trees

Let `char F = p`, and let `E` be an elementary abelian `p`-group with basis `(tau_i)_(i in I)`. Examples in `V`:
- disjoint clopen `p`-cycles whose supports leave a nonempty complement (`E_infinity` of the law node);
- the trees `E_n = <tau_w : |w| = n>` of [TS], with refinement `tau_w = tau_(w0) tau_(w1)`.

**Construction.** Let `L = F(t_i : i in I)` and `lambda : E -> (L, +)` with `lambda(tau_i) = t_i`. For `1 <= m <= p`,
put `exp_m(z) = sum_(j<m) z^j/j!` and

```text
rho_m : F[E] -> L[u]/(u^m),   [g] -> exp_m(lambda(g) u),        rk_m(M) = rank_L rho_m(M) / m.
```

- `exp_m(a u) exp_m(b u) = exp_m((a + b) u)` modulo `u^m`, because `j!` is invertible for `j < m <= p`. So `rho_m` is
  a ring homomorphism, and `rk_m` is a Sylvester rank function on `F[E]`.
- `rk_1` is the augmentation. For `p = 2`, `rk_2` is the model of [CG] Section 3 (`1 + lambda_i e_12`).

**Lemma 2.1 (coherence).** For every injective homomorphism `sigma : E' -> E` of such groups,
`rk_m^E(sigma M) = rk_m^(E')(M)`. This covers disjoint-support endomorphisms, the refinements `E_n -> E_(n+1)`, and
automorphisms.

*Proof.* The matrix `c` of `sigma` over `F_p` has independent columns. `rho_m(sigma M)` comes from `rho_m(M)` by
substituting `t'_j -> sum_i c_(ij) t_i`. Complete the finitely many columns involved to an invertible matrix. The
substitution is then an automorphism of a polynomial ring, so it extends to an embedding of fraction fields, and
rank is preserved under field embeddings. ∎

**Lemma 2.2 (profiles).** For `g != 1` and `j >= 1`, `rk_m((1 - [g])^j) = max(m - j, 0)/m`. For
`E_r = <tau_1, ..., tau_r>`, `phi_(E_r)(rk_m) = 1/m` for every `r`.

*Proof.* `lambda(g) != 0`, so `1 - exp_m(lambda(g) u)` is `u` times a unit. The column `(1 - [tau_i])_(i <= r)` maps
to `(u w_i)` with units `w_i`, whose image has dimension `m - 1`. ∎

**Proposition 2.3.**
1. **Every Frobenius-allowed profile is coherent.** Mixtures of `rk_1, ..., rk_p` are invariant under all injective
   homomorphisms. They realize every drop sequence `d_0 >= ... >= d_(p-1) >= 0` with sum `1`, which is everything
   [FW] Proposition 4.2(b) allows. The vertices of that polytope are `(1/m)(1^m, 0^(p-m))`, the drops of `rk_m`.
2. **The single-element law fails for `p >= 3`.** For `2 <= m < p`, the profile of `rk_m` is not
   `(1 - phi)(p - j)/p` for any `phi`: `j = m` forces `phi = 1`, and then `j = 1` fails. For `p = 2` the profiles
   agree with the law at `phi = 0`, and [CG] Section 3 decides the next test through the joint fixed rank.
3. **Ultralimits of the `A/m^2` models.** Take `F = F_p`, `I` countable and `m = 2`.
   - Enumerate the matrices over `F_p[E]` as `M_1, M_2, ...` with sizes `n_i <= i`.
   - At stage `k`, choose the values `lambda_k(tau_i)` uniformly in `F_(p^k)`. The generic minors have degree at most
     `2 n_i`. By Schwartz–Zippel, all `rho_2(M_i)` with `i <= k` specialize to their generic ranks with probability
     at least `1 - k(k + 1)/p^k`.
   - So `rk_2` is an ultralimit of finite models. On `E_r`, with `A = F_p[E_r]` and `m` its augmentation ideal, each
     is `F_(p^k) ⊗ A/m^2` divided by the kernel of the linear map `m/m^2 -> F_(p^k)` induced by `lambda_k`. That is
     the law node's `A/m^2`, cut down to dimension `2` by a generic hyperplane. Unlike `A/m^2`, its normalization
     does not change with `r`.
4. **No extension to V.** By Theorem 1.1, a rank function on `F[V]` has `phi_(E_r) = phi_V + (1 - phi_V) p^(-r)`. A
   mixture `sum_m w_m rk_m` has `phi_(E_r) = sum_m w_m/m` for every `r`. So it extends only if `w_1 = 1`.

**Premise audit.** On `F[E]`, `rk_m` satisfies the Sylvester axioms, every identity of `F[E]`, and every
`V`-conjugacy among single elements or basis-shaped tuples of `E` (Lemmas 2.1 and 2.2).
- **For `2 <= m < p`,** its induced extension to the wreath configuration `W = E_p ⋊ <s>` breaks single-element
  `V`-conjugacy, the first premise to fail. Here `s` is a clopen `p`-cycle with `s tau_i s^(-1) = tau_(i+1)`, indices
  mod `p`.
  - Restricted to `F[E_p]`, the induced module `F[W] ⊗_(F[E_p]) rho_m` gives the average of `rk_m` over the cyclic
    shifts. By Lemma 2.1 that average is `rk_m`.
  - Restricted to `<s>`, the module is free (Mackey), so `s` gets the regular profile `(p - j)/p`. But `tau_1`, which
    is conjugate to `s` in `V` ([TS] Lemma 1.1), gets `max(m - j, 0)/m`.
- **For `m = p`,** single elements match. Item 4 excludes it, and every `m >= 2`, using a clopen `q`-cycle subgroup
  with `q != p`, which no `p`-group such as `E` or `W` contains.
- **Consequence.** No argument confined to `p`-groups of `V` and their injective endomorphisms forces the law for
  `p >= 3`, or trivial-plus-regular restrictions for any `p`. The law needs another prime.

## 3. The ternary gate at `<x_0, x_1, s>`

**Convexity** ([CG] Section 4.4).
- Rank functions on `F_3[V]` form a convex set containing `rk_aug`, and `phi_V` is affine on it.
- If `phi_V(rk) < 1`, then `(rk + rk_aug)/2` has `phi_V` in `[1/2, 1)`. And `phi_V = 1` gives `rk = rk_aug` by
  [FR] Corollary 1.3(3).
- So the gate is equivalent to `phi_V in {0, 1}` for every `rk`. Asking whether the law plus `x_0`, `x_1` conjugation
  forces that is asking the gate itself.

**What is settled over `F_3`.**
- **Locally finite subgroups.** Every rank function is `phi_V rk_aug + (1 - phi_V) rk_reg` on every locally finite
  subgroup (Theorem 1.1). In particular `rk((1 - [s])^j) = (1 - phi_V)(3 - j)/3`.
- **Wandering elements.** For `x` as in [FR] Setup 2.2 and nonzero `q` in `F_3[t]`, `rk(q([x])) >= 1 - phi_V`
  ([FR] Theorem 2.3).
- **3-groups alone don't give the law.** By Section 2 with `p = 3` and `m = 2`, the brief's level-coherent
  counter-model exists. Its first broken premise is single-element `V`-conjugacy at `E_3 ⋊ <s>`.
- **Inert.** The first two items hold for the augmentation rank and, on each sofic configuration, for the sofic ranks
  of [FW] Lemma 1.1 (`phi_V = 0`). So by [FW] Theorem 1.2 neither can decide the gate.

**Step 2 of the brief: OPEN.** I found neither a rank identity on `F_3[<x_0, x_1, s>]` that forces `phi_V = 1`, nor a
non-augmentation rank function on `F_3[V]`. A proof must use matrices that mix infinite-order elements with
`3`-torsion, beyond single polynomials in `[x]` and matrices over locally finite subgroups.

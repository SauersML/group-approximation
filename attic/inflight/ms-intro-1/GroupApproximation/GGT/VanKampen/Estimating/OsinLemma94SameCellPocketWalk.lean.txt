# The X-pocket of Lemma 9.4, Case 1, at walk level: islands and value-one lobes

Osin (math/0411039v3, §9), Lemma 9.4, Case 1, across one relator cell `Π`, relator-cell branch.
`OsinLemma94SameCellPocketPinch` states the X-pocket at the face piece `X` itself.  Excising a lobe
from the pocket walk leaves a walk that is not `invDarts X`, so this module states the pocket at
walk level.  The walk is `s ++ invDarts B`, where `s` is a sublist of `invDarts X` with the same
value, the walk is a closed dart walk, and the exterior face is off its side.

The polygon face is an unselected `G`-face.  Its cutting paths have the face on both sides
(`OsinLemma94RealizedPolygons.cutting_internal`), and the face walk runs along each of them twice.
So `X` can read `X₁ t X₂ t⁻¹ X₃`, around an island that the face surrounds.  Such an island
repeats a vertex on `s`, and it is the lobe at that vertex.

The shapes of the walk `s ++ b`, with `b = invDarts B`:
* a lobe of `s` that reads an element other than `1` (`PocketWalkIslandShape`): an island holding a
  relator cell or a selected region;
* a lobe of `s` that reads `1` (`PocketWalkValueOneLobeShape`): excised by
  `IsClosedDartWalk.excise` and `listVal_dartWord_excise_of_lobe_eq_one`, keeping the value of `s`
  and so the norm bound of the loop cut;
* a repeated vertex on `b`, or a vertex of `s` on `b` (the shapes of `OsinLemma94SameCellPocketPinch`
  at `s`);
* otherwise the walk repeats no vertex.  A dart together with its reverse on such a walk forces the
  walk `[d, alpha d]`, which reads `1` (`IsClosedDartWalk.listVal_eq_one_of_alpha_mem`), so the walk
  is simple.

`osinLemma94CaseOneXWalk_of_shapes` proves the walk-level statement from the five named statements,
and `osinLemma94CaseOneXPocket_of_walkShapes` gives the X-pocket at `X`.  In particular the spur and
face-bubble shapes need no statement of their own.  `OsinLemma94CaseOnePocketWalkClosedStatement`
(the pocket walk `invDarts X ++ invDarts B` is closed) is the one combinatorial input of the bridge.

## Manuscript status

Infrastructure for `thm:hull` (tex 2121, Hull's small cancellation theorem, through Osin's
Lemma 9.4, Case 1).  It certifies no printed sentence on its own.
-/

/-! ## Two list facts -/

/-- A list whose image repeats an entry has two positions `i < j` with equal images. -/
theorem exists_lt_getElem_eq_of_not_nodup_map {α β : Type*} (f : α → β) {l : List α}
    (h : ¬ (l.map f).Nodup) :
    ∃ (i j : ℕ) (hij : i < j) (hj : j < l.length), f (l[i]'(by omega)) = f l[j] := by
  rw [List.nodup_iff_injective_get] at h
  simp only [Function.Injective, not_forall] at h
  obtain ⟨a, b, hab, hne⟩ := h
  simp only [List.get_eq_getElem, List.getElem_map] at hab
  have ha : (a : ℕ) < l.length := by simpa only [List.length_map] using a.isLt
  have hb : (b : ℕ) < l.length := by simpa only [List.length_map] using b.isLt
  rcases lt_or_gt_of_ne (Fin.val_ne_of_ne hne) with hlt | hlt
  · exact ⟨a, b, hlt, hb, hab⟩
  · exact ⟨b, a, hlt, ha, hab.symm⟩

/-- Positions of a list whose images are equal are equal, when the image repeats nothing. -/
theorem getElem_eq_of_nodup_map {α β : Type*} (f : α → β) {l : List α} (h : (l.map f).Nodup)
    {i j : ℕ} (hi : i < l.length) (hj : j < l.length) (heq : f l[i] = f l[j]) : i = j := by
  rw [List.nodup_iff_injective_get] at h
  have hi' : i < (l.map f).length := by simpa only [List.length_map] using hi
  have hj' : j < (l.map f).length := by simpa only [List.length_map] using hj
  have hfin := @h ⟨i, hi'⟩ ⟨j, hj'⟩ (by simpa only [List.get_eq_getElem, List.getElem_map] using heq)
  exact congrArg Fin.val hfin

/-! ## A vertex-simple walk meeting a dart and its reverse reads `1` -/

section SpurTwo

variable {G : Type u} [Group G] {Lambda : Type w} {W : Set (List (RelLetter G Lambda))}
  {Delta : DiscDiagram.{u, w, v} W}

/-- **A closed dart walk that repeats no vertex and meets a dart together with its reverse reads
`1`.**  The reverse of the dart at position `i` starts at the next position, and the dart at `i`
starts where its reverse ends.  With no repeated vertex this forces two positions, the walk
`[d, alpha d]` or `[alpha d, d]`. -/
theorem IsClosedDartWalk.listVal_eq_one_of_alpha_mem {walk : List Delta.toCombMap.Dart}
    (hw : IsClosedDartWalk Delta.toCombMap walk)
    (hnd : (walk.map Delta.toCombMap.vertexOf).Nodup) {d : Delta.toCombMap.Dart}
    (hd : d ∈ walk) (had : Delta.toCombMap.alpha d ∈ walk) :
    RelLetter.listVal (dartWord Delta walk) = 1 := by
  obtain ⟨i, hi, rfl⟩ := List.mem_iff_getElem.mp hd
  obtain ⟨j, hj, hji⟩ := List.mem_iff_getElem.mp had
  have hpos : 0 < walk.length := by omega
  have hinv : Delta.toCombMap.alpha walk[j] = walk[i] := by
    rw [hji, Delta.toCombMap.alpha_involutive]
  -- `j` is the position after `i`
  have hj_next : j = if i + 1 < walk.length then i + 1 else 0 := by
    by_cases hi1 : i + 1 < walk.length
    · rw [if_pos hi1]
      refine getElem_eq_of_nodup_map _ hnd hj hi1 ?_
      rw [hji]
      exact hw.vertexOf_alpha_getElem hi1
    · rw [if_neg hi1]
      refine getElem_eq_of_nodup_map _ hnd hj hpos ?_
      rw [hji]
      have hlast : i = walk.length - 1 := by omega
      simpa only [hlast] using hw.vertexOf_alpha_getElem_last hpos
  -- `i` is the position after `j`
  have hi_next : i = if j + 1 < walk.length then j + 1 else 0 := by
    by_cases hj1 : j + 1 < walk.length
    · rw [if_pos hj1]
      refine getElem_eq_of_nodup_map _ hnd hi hj1 ?_
      rw [← hinv]
      exact hw.vertexOf_alpha_getElem hj1
    · rw [if_neg hj1]
      refine getElem_eq_of_nodup_map _ hnd hi hpos ?_
      rw [← hinv]
      have hlast : j = walk.length - 1 := by omega
      simpa only [hlast] using hw.vertexOf_alpha_getElem_last hpos
  have hne : j ≠ i := by
    intro hij
    subst hij
    exact Delta.toCombMap.alpha_fixedPointFree walk[j] hji.symm
  -- so the walk has two darts, `walk[0]` and its reverse
  have hlen : walk.length = 2 := by
    split_ifs at hj_next hi_next <;> omega
  have hrev : walk[1] = Delta.toCombMap.alpha walk[0] := by
    have hij : (i = 0 ∧ j = 1) ∨ (i = 1 ∧ j = 0) := by
      split_ifs at hj_next hi_next <;> omega
    rcases hij with ⟨rfl, rfl⟩ | ⟨rfl, rfl⟩
    · exact hji
    · rw [← hinv, Delta.toCombMap.alpha_involutive]
  have hsplit : walk = walk.take 1 ++ walk.drop 1 := (List.take_append_drop 1 walk).symm
  have htake : walk.take 1 = [walk[0]] := by
    apply List.ext_getElem
    · rw [List.length_take, hlen]
      rfl
    · intro m h1 h2
      have hm : m = 0 := by
        rw [List.length_singleton] at h2
        omega
      subst hm
      simp only [List.getElem_take, List.getElem_singleton]
  have hdrop : walk.drop 1 = invDarts Delta [walk[0]] := by
    apply List.ext_getElem
    · rw [List.length_drop, hlen, invDarts, List.length_map, List.length_reverse,
        List.length_singleton]
    · intro m h1 h2
      have hm : m = 0 := by
        rw [invDarts, List.length_map, List.length_reverse, List.length_singleton] at h2
        omega
      subst hm
      simp only [List.getElem_drop, invDarts, List.reverse_singleton, List.map_cons,
        List.map_nil, List.getElem_singleton, Nat.add_zero]
      exact hrev
  rw [hsplit, htake, hdrop, dartWord_append, RelWord.listVal_append,
    listVal_dartWord_invDarts, mul_inv_cancel]

end SpurTwo

/-- A lobe of the face part reads an element other than `1`: an island holding a relator cell or
a selected region. -/
abbrev PocketWalkIslandShape (s _b : List Delta.toCombMap.Dart) : Prop :=
  ∃ (i j : ℕ) (hij : i < j) (hj : j < s.length),
    Delta.toCombMap.vertexOf (s[i]'(by omega)) = Delta.toCombMap.vertexOf s[j] ∧
      RelLetter.listVal (dartWord Delta ((s.drop i).take (j - i))) ≠ 1

/-- A lobe of the face part reads `1`. -/
abbrev PocketWalkValueOneLobeShape (s _b : List Delta.toCombMap.Dart) : Prop :=
  ∃ (i j : ℕ) (hij : i < j) (hj : j < s.length),
    Delta.toCombMap.vertexOf (s[i]'(by omega)) = Delta.toCombMap.vertexOf s[j] ∧
      RelLetter.listVal (dartWord Delta ((s.drop i).take (j - i))) = 1

end Shapes

/-- **The pocket walk is closed.**  From the rotation `X q⁻¹ Y p⁻¹` of a face walk and the rotation
`q B p A` of the carrier of the cell, the walk `invDarts X ++ invDarts B`, when nonempty, is a closed
dart walk.  It chains inside `X` and inside `B`, and `X` ends where `B` begins, since both meet the
arcs `p` and `q` at their ends. -/
def OsinLemma94CaseOnePocketWalkClosedStatement : Prop :=
  ∀ {G : Type u} [Group G] {Lambda : Type w} {W : Set (List (RelLetter G Lambda))}
    (Delta : DiscDiagram.{u, w, v} W) (f : Delta.toCombMap.Face) (j : Fin Delta.rCellCount)
    (sourceArc targetArc : CyclicArc (cellDarts Delta j)) (X Y : List Delta.toCombMap.Dart)
    (r : ℕ),
    (Delta.faceBoundary f).darts.rotate r =
      X ++ targetArc.reverseDarts ++ Y ++ sourceArc.reverseDarts →
    0 < sourceArc.length → 0 < targetArc.length →
    ∀ (n : ℕ) (B A : List Delta.toCombMap.Dart),
      (cellDarts Delta j).rotate n = targetArc.darts ++ B ++ sourceArc.darts ++ A →
      invDarts Delta X ++ invDarts Delta B ≠ [] →
      IsClosedDartWalk Delta.toCombMap (invDarts Delta X ++ invDarts Delta B)

/-- **The walk-level statement gives the X-pocket at `X`**: take `s = invDarts X`. -/

    OsinLemma94CaseOneXPocketStatement.{u, w, v} := by
  intro G _ Lambda D hhyper lambda c mu hlambda hlambda1 hc hmu hmu1
  obtain ⟨e0, he0⟩ := hwalk D hhyper lambda c mu hlambda hlambda1 hc hmu hmu1
  refine ⟨e0, fun eps heps => ?_⟩
  obtain ⟨r0, hr0, h0⟩ := he0 eps heps
  refine ⟨r0, hr0, fun rho hrho => ?_⟩
  intro W hW Delta cuts hleast hpos hbelow S hcard hmin P hmax k C hback hcut hkind j sourceArc
    targetArc X Y r hj htrav hs ht hsource htarget hX hY n B A hPi hXB hout _
  have hne : invDarts S.diagram X ++ invDarts S.diagram B ≠ [] := by
    intro hnil
    apply hXB
    have hlen := congrArg List.length hnil
    simp only [List.length_append, invDarts, List.length_map, List.length_reverse,

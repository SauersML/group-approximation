# The subdiagram enclosed by a closed walk along a bridge

Osin, arXiv:math/0411039v3, §9, proof of Lemma 9.7(b): "it is easy to show that `Φ_M` can not
contain loops either.  The only difference is that the subdiagram `Ξ` will be bounded by `st`,
where `l(s) < ε` and `t` is a subpath of `∂Π_1`."

In Case 1 of Lemma 9.4 the side along the polygon face `f` can run through a cutting path `t` of
`f`, around an island that `f` surrounds, and back along `t⁻¹`.  The faces enclosed by the walk
then fall into two parts joined only along `t`, where `f` lies on both sides.  So the complement
of the enclosed faces is no disc region, the walk is not a simple closed walk, and the pocket
region of `OsinPocketRegion` does not apply.  The subdiagram bounded by the walk is a singular
disc: the enclosed faces joined along `t`, with `t` a bridge on its boundary.

* `EnclosedFaceSet Δ faces outerWalk`: the outside walk `outerWalk` lists, once each, the reverses
  of the boundary darts of `faces`, together with the bridge darts, the edges with both faces off
  `faces` whose two darts the walk both uses.  It is a closed dart walk, and it turns like a
  noncrossing walk at every vertex (the turning condition of `IsNoncrossingClosedWalk`, whose
  clause `alpha_not_mem` is dropped so that bridges are allowed).
* `ClosedWalkEnclosedSubdiagramStatement`: for such a walk there is a disc diagram that reads the
  inverse walk, carries relator cells with the words of the cells of `Δ` inside `faces`, at most
  as many, at least one when `faces` holds a cell, and is least area when `Δ` is.
* `enclosedSubdiagram_leastAreaCut`: the three facts the loop cut consumes, from these clauses.

For a simple walk the enclosed face set is a pocket region, and the clauses of the statement are
those of `PocketRegion.diagram_boundaryWord`, `PocketRegion.diagram_rCellCount_le` and
`PocketRegion.diagram_leastArea`.  `ClosedWalkIslandModel` tests the statement at the smallest
island configuration.

namespace GroupApproximation.GGT.VanKampen

universe u w v

open Embedded SimpleClosedWalkSides

variable {G : Type u} [Group G] {Lambda : Type w} {W : Set (List (RelLetter G Lambda))}

/-- **A face set enclosed by an outside walk.**  `faces` avoids the exterior face.  The walk is a
nonempty duplicate-free closed dart walk whose darts are based off `faces` and are either reverses
of boundary darts of `faces` or bridge darts, whose reverse the walk also uses.  At every walk dart
`d`, rotating from `alpha d`, the first dart met on an edge of the walk is a walk dart. -/
structure EnclosedFaceSet (Delta : DiscDiagram.{u, w, v} W)
    (faces : Finset Delta.toCombMap.Face) (outerWalk : List Delta.toCombMap.Dart) : Prop where
  outerFace_not_mem : Delta.outerFace ∉ faces
  ne_nil : outerWalk ≠ []
  nodup : outerWalk.Nodup
  chain : outerWalk.IsChain fun d e =>
    Delta.toCombMap.vertexOf (Delta.toCombMap.alpha d) = Delta.toCombMap.vertexOf e
  closes : Delta.toCombMap.vertexOf (Delta.toCombMap.alpha (outerWalk.getLast ne_nil)) =
    Delta.toCombMap.vertexOf (outerWalk.head ne_nil)
  mem_iff : ∀ d, d ∈ outerWalk ↔ Delta.toCombMap.faceOf d ∉ faces ∧
    (Delta.toCombMap.faceOf (Delta.toCombMap.alpha d) ∈ faces ∨
      Delta.toCombMap.alpha d ∈ outerWalk)
  turn_mem : ∀ d ∈ outerWalk, ∀ m : ℕ, 0 < m →
    walkKeep Delta.toCombMap outerWalk
      ((Delta.toCombMap.sigma ^ m) (Delta.toCombMap.alpha d)) →
    (∀ k, 0 < k → k < m → ¬ walkKeep Delta.toCombMap outerWalk
      ((Delta.toCombMap.sigma ^ k) (Delta.toCombMap.alpha d))) →
    (Delta.toCombMap.sigma ^ m) (Delta.toCombMap.alpha d) ∈ outerWalk

open scoped Classical in
/-- **The enclosed subdiagram of a closed walk** (Osin's `Ξ`, joined along the bridges of the
walk).  For a face set enclosed by an outside walk there is a disc diagram `Ξ` that reads the
inverse walk.  Its relator cells carry the words of distinct cells of `Δ` inside the face set, it
has at most as many cells as `Δ` has inside, at least one when the face set holds a cell, and it
is least area when `Δ` is. -/
def ClosedWalkEnclosedSubdiagramStatement : Prop :=
  ∀ {G : Type u} [Group G] {Lambda : Type w} {W : Set (List (RelLetter G Lambda))}
    (Delta : DiscDiagram.{u, w, v} W) (faces : Finset Delta.toCombMap.Face)
    (outerWalk : List Delta.toCombMap.Dart), EnclosedFaceSet Delta faces outerWalk →
    ∃ Xi : DiscDiagram.{u, w, v} W,
      Xi.boundaryWord = dartWord Delta (invDarts Delta outerWalk) ∧
      Xi.rCellCount ≤ (Delta.relatorCells.filter fun C => C.face ∈ faces).length ∧
      ((∃ C ∈ Delta.relatorCells, C.face ∈ faces) → 0 < Xi.rCellCount) ∧
      (∃ ι : Fin Xi.rCellCount ↪ Fin Delta.rCellCount, ∀ j : Fin Xi.rCellCount,
        (cell Xi j).word = (cell Delta (ι j)).word ∧ (cell Delta (ι j)).face ∈ faces) ∧
      (Delta.LeastArea → Xi.LeastArea)

open scoped Classical in
/-- **The least-area enclosed cut.**  A disc diagram with the count and area clauses of the
enclosed subdiagram, for a least-area `Δ` with a relator cell inside the face set and one outside,
is least area and has at least one and fewer relator cells than `Δ`. -/
theorem enclosedSubdiagram_leastAreaCut {Delta : DiscDiagram.{u, w, v} W}
    {faces : Finset Delta.toCombMap.Face} {Xi : DiscDiagram.{u, w, v} W}
    (hcount : Xi.rCellCount ≤ (Delta.relatorCells.filter fun C => C.face ∈ faces).length)
    (hpos : (∃ C ∈ Delta.relatorCells, C.face ∈ faces) → 0 < Xi.rCellCount)
    (hlea : Delta.LeastArea → Xi.LeastArea) (hDelta : Delta.LeastArea)
    {C C' : RelatorCell Delta.toCombMap Delta.outerFace W}
    (hC : C ∈ Delta.relatorCells) (hCf : C.face ∈ faces)
    (hC' : C' ∈ Delta.relatorCells) (hC'f : C'.face ∉ faces) :
    Xi.LeastArea ∧ 0 < Xi.rCellCount ∧ Xi.rCellCount < Delta.rCellCount := by
  refine ⟨hlea hDelta, hpos ⟨C, hC, hCf⟩, ?_⟩
  have hout : 0 < (Delta.relatorCells.filter (fun C => C.face ∉ faces)).length :=
    List.length_pos_of_mem (List.mem_filter.mpr ⟨hC', by simpa using hC'f⟩)
  have hsplit : Delta.relatorCells.length =
      (Delta.relatorCells.filter (fun C => C.face ∈ faces)).length +
        (Delta.relatorCells.filter (fun C => C.face ∉ faces)).length := by
    rw [List.length_eq_length_filter_add (l := Delta.relatorCells)
      (fun C => decide (C.face ∈ faces))]
    simp only [decide_not]
  show Xi.rCellCount < Delta.relatorCells.length
  omega

open scoped Classical in
/-- **Relator cells inside an enclosed face set of a least-area diagram**, the singular form of
`DiscDiagram.LeastArea.length_filter_mem_le`.  In a least-area diagram, a filling of the inverse
outside walk of an enclosed face set needs at least as many relators as the face set has relator
cells.  The disc-region form glues the shorter filling back through `IsDiscRegion`, which a face
set joined along a bridge does not have. -/
def EnclosedLeastAreaFilterStatement : Prop :=
  ∀ {G : Type u} [Group G] {Lambda : Type w} {W : Set (List (RelLetter G Lambda))}
    (Delta : DiscDiagram.{u, w, v} W), Delta.LeastArea →
    ∀ (faces : Finset Delta.toCombMap.Face) (outerWalk : List Delta.toCombMap.Dart),
      EnclosedFaceSet Delta faces outerWalk →
      ∀ {m : ℕ}, RelatorDefectBudget.IsRelatorProduct (RelLetter.listVal '' W) m
          (RelLetter.listVal (dartWord Delta (invDarts Delta outerWalk))) →
        (Delta.relatorCells.filter fun C => C.face ∈ faces).length ≤ m

open scoped Classical in
/-- **The least-area clause from the singular filter bound.**  A disc diagram that reads the
inverse outside walk of an enclosed face set of a least-area `Δ`, with at most as many relator
cells as the face set holds, is least area. -/
theorem leastArea_of_enclosedLeastAreaFilter
    (hfilter : EnclosedLeastAreaFilterStatement.{u, w, v})
    {Delta : DiscDiagram.{u, w, v} W} (hlea : Delta.LeastArea)
    {faces : Finset Delta.toCombMap.Face} {outerWalk : List Delta.toCombMap.Dart}
    (hE : EnclosedFaceSet Delta faces outerWalk) {Xi : DiscDiagram.{u, w, v} W}
    (hword : Xi.boundaryWord = dartWord Delta (invDarts Delta outerWalk))
    (hcount : Xi.rCellCount ≤ (Delta.relatorCells.filter fun C => C.face ∈ faces).length) :
    Xi.LeastArea := by
  intro m hm
  have hm' : RelatorDefectBudget.IsRelatorProduct (RelLetter.listVal '' W) m
      (RelLetter.listVal (dartWord Delta (invDarts Delta outerWalk))) := by
    rw [← hword]
    exact hm
  exact hcount.trans (hfilter Delta hlea faces outerWalk hE hm')

end GroupApproximation.GGT.VanKampen

# The Step C half of Lemma 2 at rank `n`, for the degree-`e` family, in the glue's spelling

Lane `lix-oddside-n` (lead rulings of 2026-09-11 21:35 and 22:10).

`CharClass/LIXLemmaTwoGenGlue.lean` (lane `lix-evenside-n`) names the Step C half as
`Gen.StepCHalf n dd b topClass`: for every continuous corner unitary `G` of `V` carrying the
`e₀`-section to `b`, the top class of the mapping torus is nonzero.  Its consumer
`Gen.lemmaTwoFor_powers_of_stepC_modP` asks for it at `b = KGen.bVecK n (e − 1)` for every
exponent `e` with `p ∤ e` and every stage `j`.

This file states, at `p = 2`, exactly that half from the `k`-zero Step C of
`CharClass/LIXKGenStepCWired.lean`, with the data that Step C still takes collected into ONE named
proposition `KGen.KZeroStepCData` per corner unitary.  The excision/chart identification at every
zero is DISCHARGED here, by `KGen.lixKRelModelIso` (`CharClass/LIXKGenBaseChart.lean`); every
remaining field of `KZeroStepCData` is an open leaf with a named route (see `LIXKGenStepCWired`'s
header), so this is a reshaping of those leaves, not their discharge.

## Main declarations

* `KGen.KZeroStepCData` — the open data of the `k`-zero Step C at one `G` and one class `gamma`.
* `KGen.stepCHalf_two_of_kZeroStepCData` — `Gen.StepCHalf n dd (bVecK n k) topClass` for
  `k + 1` odd, from that data at the top class of every corner unitary.
* `KGen.stepCHalf_two_powers` — the exponent-facing form at every stage `j`, for every odd `e`.
-/

noncomputable section

/-- **The open data of the `k`-zero Step C at rank `n`, for one corner unitary `G` and one class
`gamma`**: `H^{2r}(N; F₂)` is a line; a relative class `u` of the bundle pair whose section pullback
splits into local classes, all nonzero; and `u` restricting to `π^* gamma`.  The identification of
each single-puncture relative group with the local model is not data: it is
`KGen.lixKRelModelIso`. -/
def KZeroStepCData (n k : ℕ) (dd : Fin ℓ → ℕ)
    {G : Gen.baseM n dd → Matrix (Gen.VIdx n dd) (Gen.VIdx n dd) ℂ}
    (hGc : Continuous G) (hGu : ∀ m, IsCornerUnitary (Gen.Vmat n m) (G m))
    (hGe : ∀ m, G m *ᵥ Sum.elim (aVecK n m) 0 = Sum.elim (bVecK n k m) 0)
    (gamma : cohomologyZMod2 (lixN n dd) (2 * lixRank n dd)) : Prop :=
  Nonempty (cohomologyZMod2 (lixN n dd) (2 * lixRank n dd) ≃ₗ[ZMod 2] ZMod 2) ∧
  ∃ (u : relCohomology (ZMod 2) (lixTotalPair n hGc hGu) (lixPuncturedInTotal n hGc hGu)
      (2 * lixRank n dd))
    (xloc : ∀ i : Fin (k + 1), relCohomology (ZMod 2) (lixN n dd)
      ({lixKZero n k dd i}ᶜ : Set (↥sphereOne × Gen.baseM n dd)) (2 * lixRank n dd)),
    LocalSplit (fun i => lixKRho n k dd i (2 * lixRank n dd))
        ((lixKSRel n k hGc hGu hGe (2 * lixRank n dd)).hom u) xloc ∧
      (∀ i, xloc i ≠ 0) ∧
      (lixJE n hGc hGu (2 * lixRank n dd)).hom u
        = (lixPiStar n hGc hGu (2 * lixRank n dd)).hom gamma

/-- **The Step C half at `p = 2`, for the `k`-section with `k + 1` odd.** -/
theorem stepCHalf_two_of_kZeroStepCData (n k : ℕ) (hodd : Odd (k + 1)) (dd : Fin ℓ → ℕ)
    (hdd : ∀ j, 0 < dd j)
    (topClass : (↥sphereOne × Gen.baseM n dd →
      Matrix (Gen.VIdx n dd ⊕ Gen.VIdx n dd) (Gen.VIdx n dd ⊕ Gen.VIdx n dd) ℂ) →
        cohomologyZMod2 (lixN n dd) (2 * lixRank n dd))
    (hdata : ∀ (G : Gen.baseM n dd → Matrix (Gen.VIdx n dd) (Gen.VIdx n dd) ℂ)
      (hGc : Continuous G) (hGu : ∀ m, IsCornerUnitary (Gen.Vmat n m) (G m))
      (hGe : ∀ m, G m *ᵥ Sum.elim (aVecK n m) 0 = Sum.elim (bVecK n k m) 0),
      KZeroStepCData n k dd hGc hGu hGe
        (topClass (mappingTorus (Gen.Vmat n) G circHoriz circHeight))) :
    Gen.StepCHalf n dd (bVecK n k) topClass := by
  intro G hGc hGu hGe
  obtain ⟨absLine, _u, _xloc, hsplit, hx, hclass⟩ := hdata G hGc hGu hGe
  exact lixK_topClass_ne_zero_two_odd n k hodd hdd hGc hGu hGe absLine
    (chart := fun _ => relCohomology (ZMod 2) (TopCat.of (Fin (lixRank n dd) → ℂ))
      (puncturedSet (lixRank n dd)) (2 * lixRank n dd))
    (fun i => lixKRelModelIso n k dd i (2 * lixRank n dd)) (fun _ => Iso.refl _) hsplit hx
    hclass

/-- **The exponent-facing form**, at every stage `j` of the rank-`n` tower and every odd exponent
`e`, at the section `bVecK n (e − 1)` the glue consumes. -/
theorem stepCHalf_two_powers (n : ℕ) [NeZero n] (e : ℕ) (he : Odd e) (j : ℕ)
    (topClass : (↥sphereOne × Gen.baseM n (LIX.Gen.lixDD n j) →
      Matrix (Gen.VIdx n (LIX.Gen.lixDD n j) ⊕ Gen.VIdx n (LIX.Gen.lixDD n j))
        (Gen.VIdx n (LIX.Gen.lixDD n j) ⊕ Gen.VIdx n (LIX.Gen.lixDD n j)) ℂ) →
        cohomologyZMod2 (lixN n (LIX.Gen.lixDD n j)) (2 * lixRank n (LIX.Gen.lixDD n j)))
    (hdata : ∀ (G : Gen.baseM n (LIX.Gen.lixDD n j) →
        Matrix (Gen.VIdx n (LIX.Gen.lixDD n j)) (Gen.VIdx n (LIX.Gen.lixDD n j)) ℂ)
      (hGc : Continuous G) (hGu : ∀ m, IsCornerUnitary (Gen.Vmat n m) (G m))
      (hGe : ∀ m, G m *ᵥ Sum.elim (aVecK n m) 0 = Sum.elim (bVecK n (e - 1) m) 0),
      KZeroStepCData n (e - 1) (LIX.Gen.lixDD n j) hGc hGu hGe
        (topClass (mappingTorus (Gen.Vmat n) G circHoriz circHeight))) :
    Gen.StepCHalf n (LIX.Gen.lixDD n j) (bVecK n (e - 1)) topClass := by
  have hodd : Odd (e - 1 + 1) := by
    rw [Nat.sub_add_cancel he.pos]
    exact he
  exact stepCHalf_two_of_kZeroStepCData n (e - 1) hodd (LIX.Gen.lixDD n j)
    (LIX.Gen.lixDD_pos n j) topClass hdata

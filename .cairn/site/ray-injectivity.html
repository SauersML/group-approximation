Statement

ray_injective (formalized). A strict compressor has no power in Γ, so the ray t⁻ⁿΓ is infinite and the Γ-fixed set is infinite. The complement of the collapse results: finite models fail because a finite fixed set equals its own image; the genuine action escapes because strictness forces infinitude.

Statement

Fix a finite group H, a defect set X ⊆ H, a target set T ⊆ H that is n-separated from X, and a separation constant c > 0. Four facts.

1. The truncation is removable. Glebsky's length is min{d(1,·)/n, 1} for d the word metric of the Cayley graph Γ(H, X^H). Replace it by ℓ'(h) = 1 − exp(−d(1,h)/n). If d is conditionally negative definite so is ℓ' (Schoenberg: exp(−td) is positive definite, and 1 minus a normalized positive definite function is conditionally negative definite). The profile is unchanged: ℓ' ≈ 1/n on defects, ℓ' ≥ 1 − e⁻¹ > 0.63 on n-separated elements. So the whole question is whether the untruncated conjugation-invariant word metric is conditionally negative definite. 2. Glebsky's length is the pointwise maximum of the admissible ones. If ℓ is any invariant length with ℓ ≤ 1/n on X, then subadditivity and conjugation invariance give ℓ(x₁^{g₁}···x_k^{g_k}) ≤ k/n, so ℓ ≤ d(1,·)/n pointwise. He therefore takes the length that separates best and has the least reason to be conditionally negative definite. 3. Conjugation-invariant word metrics are not conditionally negative definite in general, and the smallest nonabelian case already fails. The 𝔽₂-rank length on GL₂(𝔽₂) recorded as the calibrating failure in hilbert-embeddable-length-hyperlinearity is such a word metric: GL₂(𝔽₂) ≅ S₃, and rank(g−1)/2 is half the word metric with respect to the transposition class, d = (0,1,1,1,2,2). Expanding d = a·1 + b·sgn + c·χ gives c = −2/3, a = 7/6, b = +1/6 > 0. So the upper endpoint of the admissible interval can fail, and any repair must go strictly below it. (The cyclic case is safe: min{k, m−k} on ℤ/m has nonpositive coefficients at every nontrivial character.) 4. Feasibility is a finite linear program. Every constraint on the class function ℓ is linear: ℓ(1) = 0 and ℓ ≥ 0; subadditivity ℓ(gh) ≤ ℓ(g) + ℓ(h) (finitely many inequalities); ℓ ≤ 1/n on X and ℓ ≥ c on T; and conditional negative definiteness, which by the character criterion is "the coefficient of every nontrivial irreducible is ≤ 0". So for each candidate H the existence of a Hilbert embeddable witnessing length is decidable, and an infeasibility certificate is an LP dual: a positive combination of character functionals and subadditivity relations forcing a positive coefficient.

This converts hilbert-embeddable-witness-for-kun-thom-wreath from "inspect Glebsky's metric" into "decide a linear program on the finite groups his Proposition 5 supplies", and it explains why item 3 is not fatal — the failing length is only the endpoint of the interval the program searches.

5. The separation constraint collapses, and the program becomes a character ratio. By hilbert-embeddable-amplification the separation level is free: tensoring the realizing representation sends defect δ ↦ √δ and separation c ↦ 1 − e^{−c/√δ} → 1, so ℓ ≥ c on the targets may be weakened to ℓ > 0 on the targets. What remains is the interaction of ℓ ≤ ε on X with the cone alone, and by hilbert-embeddable-is-representation-realized the cone is generated by the ψ_χ. For a single defect element x and the mark w, maximizing Σ a_χ ψ_χ(w) subject to Σ a_χ ψ_χ(x) ≤ 1, a ≥ 0 is an LP whose optimum sits on an extreme ray, i.e. on a single irreducible. Hence

   R(K, x, w) = sup_ℓ ℓ(w)/ℓ(x) = max_{χ ≠ triv} (χ(1) − Re χ(w))/(χ(1) − Re χ(x)),

a ratio read straight off the character table, and a Hilbert embeddable witness exists along a family of models iff R → ∞ along it. (For several defect elements the denominator is a max of linear functionals and the optimum may mix, but the single-defect case already fixes the shape.)

The ratio is unchanged if the normalized generators g_χ = 1 − Re χ/χ(1) are used instead of ψ_χ = χ(1) − Re χ, since ψ_χ = χ(1)·g_χ and a positive rescaling of cone generators cannot change the maximum of a ratio of two linear functionals over the cone. The normalized form is the one to state, because by cairn-survivor's correction it is the dimension-free one: the LP is a program in the normalized multiplicity vector λ on the simplex, with defect constraint Σ λ_χ (1 − Re χ(x)/χ(1)) ≤ δ and separation constraint Σ λ_χ Re χ(y)/χ(1) ≤ 1 − c. In that form the character-gap collapse is one line: if |χ(x)|/χ(1) ≤ c < 1 for all nontrivial χ and all x ≠ 1, then Re φ(x) ≤ 1 − (1−c)(1 − λ_triv), so φ ≈ 1 on X forces λ_triv ≈ 1, hence φ ≈ 1 everywhere and there is no separation. 6. The exactly-zero-defect case is dead, so the question is genuinely asymptotic. ℓ(x) = 0 forces ψ_χ(x) = 0 for every χ in the support of ℓ, i.e. x ∈ ker π_χ, i.e. ℓ factors through K/⟨⟨X⟩⟩; then ℓ(w) > 0 requires w ∉ ⟨⟨X⟩⟩, which is a genuine finite-quotient witness and is forbidden (finite-quotient-blindness). So R = ∞ at finite level is impossible, and everything depends on the rate at which R grows.
